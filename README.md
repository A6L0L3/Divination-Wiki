- **性质**：传统文化与术数知识的整理、汇编与重构，属学习研究资料（详见文末说明）。

## 各库内容

### 00.缘起
三部网络小说的精读与实修笔记——《奇门风水大天师》（分层、起局、验证与避坑）、《天眼风水师》（三层调衡实修）、《测字有术》（字镜心法分阶训练）。本库后续所有分支，都从这三篇「把小说还原成可练习方法」的笔记长出来。

### 01.山 · 拳法（01.01）
以八段锦、五禽戏、易筋经、灵剑子、峨眉十二桩、十二段锦等导引原典与太极拳、八卦掌、苌氏武技书、拳经拳法备要四部拳学为底本，按现代训练科学语言重组成 21 个板块（板块0—20）：底层公理、桩功、呼吸气法、各式动功、劲法发劲、四大拳学体系、养生日课与训练处方化。

### 02.医 · 中医（02.01）
22 个板块（板块0—21）覆盖：元气阴阳五行与藏象、经络奇经、病因病机、四诊、五套辨证坐标系、本草（性味×方向×归经）、方剂语法、伤寒六经、温病卫气营血与三焦、针灸艾灸、内外妇儿急症、治未病。附 32 篇医典读书笔记（《黄帝内经》《伤寒杂病论》《本草纲目》《针灸甲乙经》等）。

### 03.命 · 推命
- **四柱八字**：12 篇系统知识库（阴阳五行、干支、十神、旺衰、格局、用神、神煞、大运流年、六亲实战）+ 26 篇命典笔记（《渊海子平》《滴天髓》《穷通宝鉴》《三命通会》等），另设「盲派四柱八字实战知识库」子库（22 篇）。
- **紫微斗数**：24 篇，从安星法、十四主星、四化飞星到格局论、分域断法、大限流年、表述伦理。
- **七政四余**：18 篇，重在天文筑基（三重坐标系）、十一曜、二十八宿躔度、排盘七步、恩用仇难与十二步批盘工作流。

### 04.相
- **地相**：26 篇，气论与五行河洛二十四山、三合水法、立向分金、格龙三层、玄空三元九运、八宅与金锁玉关、阳宅外局内形、现代城市转译与完整实操 SOP。
- **人相**：21 篇，形骨、神与眼神、情态刚柔、气色、声音言语、动相、微习惯与八观八验，延伸到量化评分卡、识人流程、招聘面试与合作用人实战、边界伦理。
- **星相**：16 篇，星官体系解码、盖天宣夜浑天三种宇宙模型、晷影交食历法等实测层、分野与纪年、星占逻辑建构、谶纬支流。

## 库内体例

各分支目录统一采用三层组织：

1. **`XX系统知识库.md`**——合订本，一篇读完全体系；
2. **`系统知识库/`**——板块单篇（板块0 学习路径 → 板块1…N 主题，二级编号形如 `0_1`、`12_3`），可按主题独立查阅；
3. **`读书笔记/`**——所据原典的单本笔记。

各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。所据古籍原书（PDF/EPUB 等）不在本仓库内，本仓库仅收录整理笔记与知识库。
