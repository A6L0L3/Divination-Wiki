- **山**：修炼、丹法、吐纳、符咒、导引。对应古代神仙方术，先秦方仙道、后世道教内丹外丹。《汉书・艺文志》“神仙” 类。

- **医**：中医、草药、针灸、祝由。属于方技，先秦《黄帝内经》，《汉书・艺文志》方技略。

- **命**：推命，四柱八字、紫微斗数、七政四余。属于数术，汉唐星命之学。

- **相**：相人（面相手相）、相地（风水堪舆）。古称形法，《汉书・艺文志》数术略形法类。

- **卜**：卜筮，六爻、梅花易、龟卜、占卦。源头是《周易》，先秦卜筮体系延续而来。
