【原著】这是一种**信息导引式自我调理方法**：用**先天八卦序数（1—8）**配以 **0**，按易医原理组合成"配方"，通过**默念**调节身心状态。

```latex
      象（八卦所取万物之象）
            │
            ▼
      数（先天八卦序数 1—8，配以 0）
            │
            ▼
      卦（以数为卦）
            │
            ▼
      象（以卦应象）
            │
            ▼
      调（默念：不出声、唇舌微动、意念专注）

```

**八字口诀**：**象以定数，数以征象；以数为卦，以卦应象，以象调身。**

### 0_4 案例小故事：两份笔记，两种命运

> **【案例小故事 · 抄方的人与辨证的人】**
>
> 两位读者几乎同时开始学象数疗法，起点完全相同：都在第 1 周背会了对应表，都在第 2 周学会了 0 的用法。
>
> **第一位读者**的做法是"抄"。他建了一个文档，标题叫"秘方收藏"，每看到一组配方就复制进去：失眠七方、降压五方、腰痛三方、美容两方。三个月后，他的文档里有 200 多组数字，但他自己说："念哪个都不太对，念哪个也不太敢。"
>
> 问题出在哪里？他抄的每一组方，都是**别人在某一种证候下取的**。他不知道那组方背后的辨证结论是什么，也就无法判断它跟自己的情况是否匹配。他把"字典"当成了"处方单"。
>
> **第二位读者**的做法是"推"。她只记了六组 A 级基础方，然后每遇到一个不适，就按七步流程走一遍：先写主诉，再写辨证结论，再选路线取数，再排君臣佐使，再调 0，再试念，最后记录。三个月后，她的日记本里只有 9 组自己取过的方，但每一组旁边都写着三行字：**辨证结论、试念体感、四周后的趋势结论**。
>
> 到了第三个月末，两人遇到了同一件事：都因为换季开始睡不好。
>
> + 第一位读者翻出"失眠七方"，挨个试，一周换了四张方，越念越烦躁；
> + 第二位读者翻出自己的旧日记，发现三个月前她曾经为"心脾两虚"取过 `30·80`，当时的辨证结论与现在高度一致（多梦易醒、食少乏力），于是她**先用回老方，只把 0 的个数微调了一次**，连记七天入睡自评。
>
> **推导**：
>
> **结论**：两人的差别不在"谁的方子更好"，而在**有没有锚点**。辨证结论就是锚点；没有锚点，换一百张方也只是在漂。**这也是本知识库把"辨证"放在"配方"之前的全部理由。**

```latex
  抄方路径：症状 ──► 查表 ──► 抄方 ──► 换方 ──► 再换方（无锚点，越试越乱）
  辨证路径：症状 ──► 辨证 ──► 取数 ──► 试念 ──► 记录 ──► 微调（有锚点，可复盘）

```

### 1_1 案例小故事：那一分钟，他选择了继续念

> **【案例小故事 · 停念那一分钟】**
>
> 一位中年读者自述血压偏高，从网上抄了一组"降压方"，每天睡前念。
>
> **前两天**：念完觉得"挺安静"，他把这理解为"有效"。
>
> **第三天**：念到一半开始**头胀、心慌**。他心里闪过一个念头——"网上说这是排病反应，是在修复，再坚持一下就好了"。于是他继续念了二十分钟，还特意加了时长，想"让药力走完"。
>
> **当天夜里**：整夜心悸，无法入睡。第二天测量，血压明显高于平时。他吓坏了，跑去做检查，所幸没有大碍，但医生明确告诉他：**血压的问题必须规范管理，任何放松练习都不能替代监测与用药。**
>
> **事后复盘**，他一共犯了三个错：
>
> **推导**：在这个体系里，**"停"的动作优先级高于"念"的动作**。原著答疑里说得很清楚——"默念出现头晕、胸闷、胃不适，停念即缓解"。这句话的重点在**"即"**：停了就缓解，说明不适本身就是停止的信号，而不是需要克服的关卡。
>
> **结论**：会停的人，才有资格谈坚持。**"宁可错停，不可硬撑"不是保守，而是这个体系能长期安全运行的前提。**

```latex
  错误一：用"排病反应"覆盖了"停念信号"
          头胀 = 头部不适，心慌 = 心区不适 —— 两条都命中停念硬规则

  错误二：把"放松练习"当成了"治疗手段"
          高血压是明确诊断的慢病，象数练习只能是放松练习

  错误三：抄方不辨证
          他不知道那组方的取数依据，也就无从判断它是否适合自己的证候

```

### 1_2 六条红线（硬规则）

| # | 红线 | 具体做法 |
| --- | --- | --- |
| 1 | **急危重症立刻就医** | 胸痛胸闷、呼吸困难、高热惊厥、急性外伤出血、意识改变、突发剧烈头痛、疑似中风，第一时间拨打 120 或去医院 |
| 2 | **不替代诊疗** | 慢病、久病、进行性加重的症状，先明确诊断，再考虑是否辅以放松练习 |
| 3 | **处方药不减不停** | 降压、降糖、抗血小板、抗凝、抗精神病、抗癫痫、激素类药物，不因"念数见效"自行减量或停药 |
| 4 | **三类高危禁用或仅辅助** | 孕妇、精神疾病与重度认知障碍者、婴幼儿及昏迷者；后两类宜由旁人轻柔代念，本人不自行默念 |
| 5 | **默念异常即停** | 头部胀痛眩晕、胃部绞痛恶心、心慌心悸、胸闷气短、烦躁，立即停念，静待平复，换方或就医 |
| 6 | **不宣称疗效** | 分享时禁用"治疗、治愈、根治、降压降糖、疗效"等表述 |

#### 1_2_1 逐条展开

**第一条为什么排在最前**：急危重症的判断窗口极短，而默念带来的放松感**可能掩盖正在恶化的症状**。胸痛、呼吸困难、突发剧烈头痛、意识改变这类信号，任何"先念一会再说"的想法都是在消耗时间。

**第三条为什么最容易被突破**：慢病管理的难点在于"感觉良好"与"指标平稳"并不总是同步。有人念了一阵子、睡得好了、情绪松了，就自行减了降压药——这是本知识库最反对的操作。**任何减药停药，必须由主治医生决定。**

**第四条为什么单列**：孕妇、婴幼儿、精神与认知障碍者这三类人群的共同点是**自我反馈能力受限**——要么无法准确描述体感，要么无法及时停止。因此风险收益比与普通人完全不同。

### 1_5 服药调整原则

【辨析】网络教程里有"轻症见效后可逐步减药停药"的说法，**本知识库明确反对自行操作**：

| 情况 | 做法 |
| --- | --- |
| 轻症、亚健康、普通慢性不适 | 默念与规范治疗并行，**任何减药由医生决定** |
| 危重、长期药物依赖 | **严禁骤然停药**；随身体好转、指标平稳，**由主治医生指导循序渐进调整** |
| 高血压、糖尿病、心脏病等慢病 | 象数练习**绝不替代药物与监测** |

> 一句话：**象数练习可以加在生活里，但不可以减在药单上。**

### 1_8 案例小故事：她把"3 天原则"用对了

> **【案例小故事 · 第三天，她停了】**
>
> 一位读者因为受凉后鼻塞，自己按"肺主皮毛、开窍于鼻"的思路取了一组方，试念 15 分钟没有不适，于是开始持念。
>
> **第一天**：鼻塞略缓，她记录"通气自评 6 分"。

**第二天**：持平，记录 6 分。
**第三天**：鼻塞加重，还开始流黄涕、轻微头痛，记录 4 分。

> 她翻出板块1 的停止信号卡，看到"3 天以上无改善 → 停念并就医"，当天就停了念，第二天去了耳鼻喉科，诊断是**急性鼻窦炎**，需要用规范治疗。
>
> 事后她说了一句很清醒的话："**这三天日记没白记，它让我知道自己不是在好转，而是在拖。**"
>
> **推导**：
>
> **结论**：**红线不是限制你去做，而是帮你在对的时点停下来。** 而要让红线真正起作用，前提是——**你得有记录**，否则你判断不了"有没有改善"。这也是板块13 的日记被反复强调的真实原因。

```latex
  无记录：第一天"好像好点" → 第二天"差不多" → 第三天"可能要严重一点"
           → 记忆偏差让人总觉得"在好转"

  有记录：6 → 6 → 4，趋势下行，且出现新症状（黄涕、头痛）
           → 触发"3 天 + 新症状"双重信号 → 停念就医

```

### 2_1 案例小故事：为什么"皮肤病"要取"2"

> **【案例小故事 · 荨麻疹取数】**
>
> 一位患者反复皮肤瘙痒数月，风团时起时消，遇风加重。
>
> **第一条思路（错）**：按"病名"想——"皮肤痒，那就治皮肤"，于是往皮肤上堆数字，取了几个跟"表、外、皮"有关的数，念了十天，毫无改善。
>
> **第二条思路（对）**：按藏象推——
>
> 关键点在于：**真正的依据是"肺主皮毛"这条藏象理论，不是"皮肤病属肺"这种简化口号。**
>
> 更进一步，同是皮肤病，兼症不同，配方会分岔：
>
> **结论**：象数疗法的"数"从来不是病名对应的，而是**辨证结论对应的**。先懂理论，才懂取数。**同一个"皮肤病"，因体质与兼症不同，配方完全不同**——这就是"辨证取数"与"对病套方"的分歧起点。

```latex
  皮肤瘙痒 ──► 中医讲"肺主皮毛"
            ──► 皮肤的毛病要从肺论治
            ──► 肺属兑卦，兑的先天数是 2
            ──► 取 2，并以 0 加强疏风达表之意
            ──► 0002

```

| 兼症 | 辨证偏向 | 取数走向 |
| --- | --- | --- |
| 疹色淡、乏力、便溏、苔腻 | 脾虚湿困 | 在 2 的基础上加 8（坤脾），健脾祛湿 |
| 疹色红、遇热加重、口干 | 风热偏盛 | 走"风邪"取 5（巽），疏风清热 |
| 病程久、夜间痒甚、皮肤干燥 | 血虚风燥 | 往肝血（4）与肾水（6）上想，养血润燥 |

### 2_4 阴阳：奇偶即阴阳

【原著】象数疗法把阴阳简化到极致——**奇数为阳，偶数为阴**：

| 属性 | 数字 | 对应卦 |
| --- | --- | --- |
| **阳数** | 1、3、5、7 | 乾、离、震、艮 |
| **阴数** | 2、4、6、8 | 兑、巽、坎、坤 |

#### 2_4_1 易错提醒：5 是阴数

> 震4 与巽5 虽同属木，但 **4 为阳木、5 为阴木**。初学者常把 5 当作阳数，取数时阴阳基调就会整体跑偏。

#### 2_4_2 用法：调其偏性，而非单向进补

```latex
  寒者、虚者、阳气不足 ──► 配方偏阳（多用阳数，或加奇数个 0 助阳通）
  热者、燥者、阴虚火旺 ──► 配方偏阴（多用阴数，或加偶数个 0 滋阴清热）

```

> 【辨析】这是**全书最容易用错的地方**。初学者最常见的错误是"看到虚就猛堆补数"，结果补气太过反而头晕烦躁。**原则是"损有余补不足"，调平衡而非单向进补。**

## 板块3 · 五行生克与「0」的规则

> 地基的第二块。五行生克是**配数的语法**，`0` 是**全书的微调旋钮**。

读完本板块，你应当能：**背出相生相克链、说出四个高频套路、讲清 0 的三条规则、会用例证判断力度**。

### 3_1 案例小故事：0 的个数，就是剂量

> **【案例小故事 · 从 7000 退到 70，从 600 进到 6000】**
>
> 原著里有两则看起来"方向相反"的验案，初学者常常看糊涂：
>
> **第一则：坐骨神经痛。**

患者左侧坐骨神经痛，手足欠温，舌暗苔润，脉虚。取 7（艮，主左足与关节）直取病所。
但最初用的是 `7000`——三个 0，温通祛邪之力很峻。用下来发现**正气受损**，于是**减为 **`70`，力道适中，反而收效。

> **第二则：腰扭伤。**

患者腰部急性扭伤，取 6（坎，腰为肾之府）。最初用 `600`，偏阴偏缓，患者并非阴虚，力道不够；于是**加到 **`6000`，温通止痛之力才够。

> **同一个"7"，一个从三个 0 退到一个 0；同一个"6"，从一个 0 进到三个 0。为什么？**
>
> **推导**：**0 的个数不是装饰，它调的是"剂量"。** 判断该加还是该减，依据的不是"病重不重"，而是**患者的正气能不能承受这个力道**。
>
> **结论**：这就是原著里那条心法——**"力过则减、力不足则加"**。它比任何一张配方表都更值得记住，因为它解决的是"我该怎么调"而不是"我该念什么"。

```latex
  案一：病邪虽在，但患者"脉虚"→ 正气不足 → 力过则伤正 → 减 0
  案二：急性扭伤，需温通直达 → 力不足则不达 → 加 0

```

### 3_2 五行生克：配数的语法

【原著】五行不只是分类标签，更是**配数时的推导规则**。必须背熟两件事：五行归属（见板块2）与生克关系。

#### 3_2_1 相生与相克链

```latex
  相生（顺势，配方常态）：
      木(4/5) → 火(3) → 土(7/8) → 金(1/2) → 水(6) → 木(4/5)

  相克（逆势，用于清、泻、散、降）：
      木(4/5) → 土(7/8) → 水(6) → 火(3) → 金(1/2) → 木(4/5)

```

#### 3_2_2 四个高频套路（多数配方逃不出这几个）

| 目的 | 套路 | 典型配方 | 逻辑 |
| --- | --- | --- | --- |
| **虚则补其母** | 水生木、金生水、土生金 | 脾虚 → 8 配益肺 2 = **820** | 培土生金 |
|  |  | 肝血不足 → 4 配补肾 6 = **640** | 肾水涵木 |
|  |  | 肾阳虚 → 6 配益肺 2 = **20·650** | 兑金生肾水 |
| **我克为用** | 借克者以疏泄 | **160** | 金克木，借肺金以疏肝 |
| **克者为病（被克者反制）** | 肝火上炎 | **003** | 水（00）克火（3），清热降火 |
| **扶土抑木** | 健脾为主兼疏肝 | **650·30·820** | 最经典的基础方 |

> 【原著·经验】**"多数情况下，各象数之间应保持相生关系。"** 这是关键提醒：配方**优先走相生链路**；生克乘侮只在需要"泻、清、散、降"时才用，且**中病即止**——初学者宁可温和相生，不要动辄相克攻伐。

#### 3_2_3 黄金律：相生是常态，相克要收手

```latex
  ┌──────────────────────────────────────────────────┐
  │  相生：补、养、调、和 ──► 可常态使用               │
  │  相克：清、泻、散、降 ──► 中病即止，不可久用        │
  │                                                  │
  │  自检问句：我用相克，是为了"清泻散降"吗？           │
  │           目标达成后，我收回了吗？                  │
  └──────────────────────────────────────────────────┘

```

### 3_3 「0」的三条规则：全书的微调旋钮

【原著】`0` 不属于八卦，其功能是**强化信息波能量、通经气、调阴阳**。用好 0，配方才算"活"。

```latex
                  ┌──────────── 0 的三条规则 ────────────┐
                  │                                      │
                  │  第1步 看个数：偶数个 0 偏阴 / 奇数个 0 偏阳 │
                  │  第2步 看位置：0 在前偏清降 / 0 在后偏温通   │
                  │  第3步 看多少：0 越多力越峻，体虚者慎用      │
                  │                                      │
                  └──────────────────────────────────────┘

```

#### 3_3_1 规则一：看个数——奇偶分阴阳

| 个数 | 偏性 | 适用方向 |
| --- | --- | --- |
| **偶数个 0**（00、0000） | 偏阴 | 滋阴、清热、凉血、缓急 |
| **奇数个 0**（0、000） | 偏阳 | 温通、助阳、散寒、行气 |

#### 3_3_2 规则二：看位置——前后分偏性

| 位置 | 偏性 | 例 |
| --- | --- | --- |
| **0 在象数之前** | 整体偏阴、偏清降 | `050`、`007` |
| **0 在象数之后** | 整体偏阳、偏温通 | `500`、`7000` |
| **前后都加** | 力量最强，多用于急症、顽疾 | `00500`——缓解后须及时调整，**不宜长期久念** |

#### 3_3_3 规则三：看多少——0 越多力越"峻"

```latex
  0 少 ──► 温和持久，适合长期、慢病
  0 多 ──► 冲击力强，起效快但易"有过"
  体质虚弱者 ──► 慎用过多 0

```

## 板块4 · 藏象与两条主脉

> 地基的第三块。象数疗法取的是**中医藏象**，不是解剖器官。

读完本板块，你应当能：**说出每个脏腑的功能与常见病理方向、记住"脾=8、胃=7"、会用两条跨脏腑主脉减少记忆量**。

### 4_1 案例小故事：把"6"当成万能肾数

> **【案例小故事 · 为什么他的"补肾方"没用】**
>
> 一位读者腰痛，自己配了 `6000`。他的逻辑看起来无懈可击：
>
> 念了两周，毫无改善。他很困惑："6 明明就是肾，为什么没用？"
>
> 后来有人问了他三个问题：
>
> 第一，**你的腰痛点在哪里，什么性质？** 他说是"整个腰以下发沉、发酸，久坐加重，活动后略缓"。

第二，**你的舌苔和二便怎么样？** 他说是"舌苔偏腻，大便经常不成形"。
第三，**你有没有怕冷、夜尿多这些肾虚表现？** 他想了想说："没有，反而怕热、容易出汗。"

> 三个答案合起来，指向的是另一个结论：
>
> **推导**：**问题不在"6 对不对"，而在"有没有辨证"。** 6 确实是肾数，但这位读者的腰痛**病机在脾与气滞**，6 只能作为引经药，不能作为君药。
>
> **结论**：**"记住某数对应某脏"只是入门，"判断这一脏是不是当下的主要矛盾"才是本事。** 这也是板块5 要先讲辨证的原因。

```latex
  腰痛 ──► "腰为肾之府" ──► 肾属坎，数为 6 ──► 补肾 ──► 6000

```

```latex
  舌苔腻 + 大便不成形 + 身体发沉 ──► 脾虚湿困
  久坐加重、活动后缓 ──► 气滞
  无典型肾虚表现 ──► 病不在肾

  正确思路：路线二（脾/湿，取 8）+ 路线一（腰取 6，作引经直达）
           ──► 80·600

```

## 板块5 · 辨证：对证不对病

> 这是整套方法的**分水岭**。

读完本板块，你应当能：**用起手四问拆解任何不适、写出一句可操作的辨证结论、识破"按病名套方"的陷阱**。

---

### 5_1 为什么先讲辨证

【原著】"辨证施治"开宗明义：**必须坚持以阴阳五行学说为纲领的辨证原则**。

**证 = 证候**，是对疾病**当前状态**的判断，不是病名。同一个病名在不同人身上、甚至同一个人的不同阶段，证都可能不同；反过来，不同病名若病机相同，反而可以同方。

```latex
  病名是静态标签 ──► "失眠""头痛""腰痛"
  证候是动态判断 ──► "心脾两虚""阴虚阳亢""寒湿痹阻"
                        ↑
                  象数疗法真正对治的东西

```

---

### 5_2 案例小故事：三个人，三种失眠

> **【案例小故事 · 失眠的三张方】**
>
> 一次线下交流里，三个人先后问了同一个问题："我失眠，该念什么？"
>
> **第一位，三十多岁的职场妈妈。**

她说：入睡还行，但**多梦易醒**，一晚上醒三四次，醒了很难再睡；白天**心悸健忘**，记性差；**吃得少、浑身乏力**，脸色偏黄。舌淡，脉细弱。

> **第二位，五十多岁的男教师。**

他说：**虚烦不眠**，躺下脑子里停不下来；伴**头晕耳鸣、腰酸**，夜里**盗汗**，手心脚心热。舌红少苔，脉细数。

> **第三位，四十出头的销售主管。**

他说：最近两个月睡不好，**急躁易怒**，一点小事就上火；**口苦**，早上起来尤其明显；**舌红苔黄**，脉弦数。

> **三个人，同一个"失眠"，三张完全不同的方。**
>
> **推导**：如果给他们同一张"失眠专用方"，至少有两个人方向是错的。而第三位若用了第一位的 `30·80`，等于在心脾两补的方向上再加把火——**越补越烦**。
>
> **结论**：**象数疗法的核心不是"数字"，而是"辨证"；数字只是辨证结果的编码形式。** 网上"失眠专方 40 个"式的清单，问题不在方子本身，而在它跳过了辨证这一步。

```latex
  多梦易醒 + 心悸健忘 ──► 心（心藏神）
  食少乏力 + 面色少华 ──► 脾（脾主运化，气血生化不足）
  结论：心脾两虚 ──► 君 30（养心安神），佐使 80（健脾益气）──► 30·80

```

```latex
  虚烦不眠 + 盗汗 + 五心烦热 ──► 阴虚
  头晕耳鸣 + 腰酸 ──► 肾（腰为肾之府、肾主耳）
  结论：心肾不交 ──► 400（或走心肾相交主脉 20·650·30·80）

```

```latex
  急躁易怒 + 脉弦 ──► 肝（肝主疏泄、在志为怒）
  口苦 + 舌红苔黄 + 脉数 ──► 化火
  结论：肝郁化火 ──► 400·60

```

### 5_3 起手四问

第一步不是找"病名"，而是回答这四个问题：

| 问什么 | 怎么问 | 为什么重要 |
| --- | --- | --- |
| **虚实** | 神疲乏力、喜按（虚）还是胀痛拒按、有力（实）？ | 定"补其母"还是"疏泄清泻" |
| **寒热** | 畏寒肢冷、喜温（寒）还是口干面红、舌红苔黄（热）？ | 定配方的阴阳基调 |
| **病位** | 在哪一脏哪一腑，或哪一个部位？ | 定"本脏数"，这是取数的锚点 |
| **病势** | 向上（呕、咳、头晕、面赤）还是向下（泻、遗、下陷、乏力）？ | 定"升提"还是"沉降" |

---

### 5_4 八纲简化版：从辨证到取数倾向

| 维度 | 辨什么 | 取数倾向 |
| --- | --- | --- |
| 阴阳 | 整体偏寒偏热、偏虚偏实 | 定配方阴阳基调（数字奇偶与 0 的多少） |
| 寒热 | 畏寒肢冷 vs 口干面红 | 寒 → 温通（阳数、0 后置）；热 → 清降（偶数 0、0 前置） |
| 虚实 | 神疲乏力 vs 胀痛拒按 | 虚 → 补其母（相生）；实 → 疏泄或清泻 |
| 脏腑 | 病在何脏何腑 | 定"本脏数"，取数锚点 |
| 表里 | 在表（皮毛、经络）vs 在里（脏腑） | 表 → 循经取数；里 → 藏象取数 |

---

### 5_5 用一句话代替病名

**句式模板**：

```latex
  病位（本脏）+ 性质（寒/热/虚/实）+ 病机（生克关系）+ 病势（升/降）

  例一："心脾两虚、气血不足，神失所养"
  例二："肾阴亏虚、水不涵木、虚火上扰"
  例三："肝郁化火、火性上炎"
  例四："脾虚湿困、兼气机郁滞"

```

| 错误写法 | 正确写法 |
| --- | --- |
| "我有高血压" | "阴虚阳亢、上实下虚、心肾不交" |
| "我失眠" | "心脾两虚、气血不足" |
| "我便秘" | "脾虚气弱、推动无力"，或"肠胃燥热、津液不足" |

> **写不出这句话，就先别取数。**

### 5_6 常见辨证错误对照表

| 错误 | 表现 | 后果 | 修正 |
| --- | --- | --- | --- |
| **按病名取数** | "失眠就念某某方" | 方向可能完全相反 | 先写辨证结论，再取数 |
| **只看部位不看脏腑** | "腰痛就是 6" | 病机在脾湿时无效 | 部位取数作引经，脏腑定君药 |
| **见虚就猛补** | 一上手全是补数 | 补而生壅，头晕烦躁 | 损有余补不足，补中寓疏 |
| **忽略寒热** | 虚寒证却用清降方 | 越念越寒、越念越沉 | 先定寒热，再定 0 的奇偶与位置 |
| **忽略病势** | 上逆之证反用升提 | 头晕、面赤加重 | 向上者降，向下者升 |

## 板块6 · 取数路线（上）：八卦之象与藏象

本板块讲**最常用、最先用的两条**：路线一（八卦之象）与路线二（藏象理论）。
读完本板块，你应当能：**看到部位症状直接取象、看到脏腑功能失调直接取本脏数，并说清两者的区别**。

### 6_1 路线一：按八卦之象取数——哪里痛取哪个象

> **逻辑**：**躯体部位 → 归入八卦 → 取该卦数。**

| 部位 | 对应卦数 | 取数示例 |
| --- | --- | --- |
| 头、颈、脊柱（督脉） | 乾 1 | 头痛取 1（如 `10`、`010`） |
| 口、齿、咽喉 | 兑 2 | 牙痛取 2（如 `720`） |
| 眼、血脉、神志 | 离 3 | 目涩取 3（如 `030`） |
| 足、筋、下肢 | 震 4 | 足疾取 4，前后加 0 通经 |
| 股、肩颈、风邪 | 巽 5 | 肩颈取 5（如 `50·70`） |
| 腰、耳、肾 | 坎 6 | 腰痛取 6（如 `6000`） |
| 手、关节、胃、止逆 | 艮 7 | 膝与关节取 7（如 `70`） |
| 腹、肌肉、脾 | 坤 8 | 腹胀取 8 |

**适用边界**：急性痛证、形体局部问题。**这是入门最容易上手的一条，也是网络教程最热衷的一条。**

> 【原著·经验】膝关节取 7、腰膝取 6、头部取 1——验案中几乎案案都用这一招。

**注意**：同一部位可能有多卦可归（如"足"既归震 4，也归艮 7），此时以**具体位置与兼症**定夺。

### 6_2 案例小故事：同样是牙痛，一个取 2，一个取 7

> **【案例小故事 · 牙痛的两条路】**
>
> 两位读者都在群里问"牙痛怎么取数"，回答却完全不同。
>
> **第一位**：**上牙龈肿痛三天**，疼痛剧烈，伴随口臭、口渴喜冷饮、大便干，舌红苔黄。
>
> **第二位**：**牙齿隐隐作痛，午后加重**，牙齿有松动感，伴腰酸、耳鸣，无明显红肿，舌红少苔。
>
> **推导**：
>
> **结论**：**"牙痛取 2"只对了一半。** 路线一告诉你"病所在哪里"，但**要不要以它为主角，要看路线二的辨证结果**。两条路线不是二选一，而是**先定病所，再定主次**。

```latex
  部位：齿 ──► 兑 2（兑主口、齿、咽喉）
  兼症：口渴喜冷饮、大便干、苔黄 ──► 胃火（足阳明胃经入上齿）
  结论：部位取 2 直达病所，兼以 7（艮 · 胃）清降和胃
       ──► 720（7 和胃降火为佐，2 直达齿部为君）

```

```latex
  部位：齿 ──► 兑 2
  兼症：牙齿松动 + 腰酸 + 耳鸣 + 隐痛 ──► 肾虚（"齿为骨之余"，肾主骨）
  结论：病根不在齿而在肾 ──► 君 6（补肾），使 2（引经达齿）
       ──► 走 640 类方，或以 6 为主、2 为引

```

```latex
  第一位：实证、火证、局部为主 ──► 清降 + 直达病所（2 为主角）
  第二位：虚证、肾虚、病根在里 ──► 补肾为主，齿部仅为引经（6 为主角）

```

### 6_3 路线二：按藏象理论取数——哪个脏病取哪个数

> **逻辑**：**脏腑 → 本脏卦数 → 结合虚实寒热加减。**

| 症状 | 藏象依据 | 本脏数 | 示例 |
| --- | --- | --- | --- |
| 皮肤病、鼻塞、咳喘 | 肺主皮毛、肺主气、开窍于鼻 | 2（兑） | `0200` |
| 目涩、抽筋、情绪郁怒 | 肝藏血、主筋、开窍于目 | 4（震） | `640` |
| 失眠、心悸、多梦 | 心主血脉、藏神 | 3（离） | `30·80` |
| 腹胀、泄泻、乏力、湿困 | 脾主运化、主肌肉 | 8（坤） | `80·20·650` |
| 腰酸、耳鸣、尿频、畏寒 | 肾藏精、主水、主耳 | 6（坎） | `6000`、`20·650` |
| 胃痛、呃逆、恶心 | 胃主受纳腐熟、主降 | 7（艮） | `70·80` |

#### 6_3_1 虚实加减的两种基本手法

```latex
  虚则补其母（走相生）：本脏虚，补其母脏
      例：肝(木)虚 ──► 补肾(6) ──► 640

  实则泻其子或疏泄：本脏实，泻其子脏或借克者疏泄
      例：肝火上炎 ──► 003（以被克者反制，水克火）

```

> 四脏完整的"补母泻子"速查表见板块12，此处只保留原则与示例。

> 【原著·经验】**"健脾明目 380"**是被反复引用的"明星基础方"——3（离 · 目与心）+ 8（坤 · 脾）+ 0，火生土、心脾同调。**记住一组 **`380`**，等于记住了"藏象 + 五行生克"的完整逻辑。**

### 6_4 象 与 藏象：两条路线的区别与配合

| 概念 | 指向 | 回答的问题 | 典型用法 |
| --- | --- | --- | --- |
| **象（路线一）** | 八卦所取的自然与形体之象：头、足、关节、腹 | **病在哪里** | 定"引经"，直取病所 |
| **藏象（路线二）** | 脏腑的生理功能与病理影响：心主神、脾主运化 | **病机是什么** | 定"君药"，治本 |

**同是"眼"，取 3 到底因为"目归离"还是"心主血脉上注于目"？**

实操中两者常重合——"肝开窍于目"指向 4，"心主血脉"指向 3，"离为目"也指向 3。**不必纠结哪个更"正宗"，能自圆其说、试念舒适即可。**

```latex
  配合方式：
      病所在表、在局部 ──► 路线一为主，路线二为辅
      病在脏腑、在功能 ──► 路线二为主，路线一作引经
      两者皆明显 ──► 路线二定君，路线一定使

```

### 7_1 案例小故事：把五段二十位的方，砍成两段

> **【案例小故事 · 减法的勇气】**
>
> 一位初学者拿着一张网上流传的"颈椎方"来问："这组方有五段二十多位，念了半个月，脖子没见好，倒是越念越累，能不能帮我看看？"
>
> 那张方大致是这样的结构：督脉一段、肾一段、肝一段、脾胃一段，末了还加了一段"通络"的，每段三到四位，中间还夹着好几个 0。
>
> 问题不在数字本身，而在**它没有主次**：
>
> 后来他按三步重做了一遍：
>
> **第一步，回到辨证。** 他的主诉是"颈肩僵硬、转头受限、久坐加重、偶有头晕"，寒热不明显，虚中夹实，病位在**颈肩（巽 5 所主）与督脉（乾 1 所主）**，兼有**肝气不舒（4）**。
>
> **第二步，定君臣。** 主症是颈肩僵硬——**这就是君**，取 5；兼症是久坐致气机郁滞，取 4 为臣；头晕与神志相关，取 3 为佐使。
>
> **第三步，做减法。** 0 只在需要温通处后置一个，其余删掉；段数控制在两段。
>
> 三周后他的反馈是："脖子还是那样，但我终于知道自己在念什么了，也知道不舒服时该减哪一段。"
>
> **推导**：**"字数精简不冗长"是原著明确要求**，不是审美偏好。原因很实际——
>
> **结论**：**减法是这个体系里最被低估的能力。** 原著方剂普遍在 2–4 段、每段 2–4 位，这不是巧合，而是"可定位、可调方"的工程要求。

```latex
  五段并列 ──► 谁都是君 ──► 等于没有君 ──► 力量分散，无从判断哪段起了作用
  前后皆 0 ──► 力峻 ──► 本用于急症顽疾 ──► 长期持念易"有过"

```

```latex
  成方：450·30（一类可行结构，仍需试念验证）

```

```latex
  方子越长 ──► 变量越多 ──► 出问题时无法定位是哪一段造成的
  方子越短 ──► 主次越清 ──► 试念反馈越干净，调方越精准

```

### 7_2 路线三：按"君臣佐使"配伍——配方的结构学

【原著】借鉴中药方剂结构，配方讲究主次：

| 角色 | 作用 | 位置 | 例（`260·050·380`） |
| --- | --- | --- | --- |
| **君** | 针对主症、主脏 | **配方最前** | `260`（养肾）为君 |
| **臣** | 协助君、加强疗效 | 中段 | `050`（通肺、行气）为臣 |
| **佐使** | 调和、护正、兼顾兼症 | 末段 | `380`（健脾、养心）为佐使 |

#### 7_2_1 结构原则

+ **一元结构**：单段，如 `010`、`640`、`380`，用于轻症、单纯证型；
+ **多元结构**：两段及以上，以**居中圆点 **`·`** 分隔**，**不可用逗号或顿号替代**，如 `650·3820`、`640·380`；
+ **单元内宜相生、不宜相克**；单元之间可以相克（如 `40·70` 的抑木扶土）；
+ 配完自查一句：**"这条链从头到尾，五行关系说得通吗？"** 说不通的配方，先别试。

> 【辨析】配方的君臣佐使**只决定"顺序与主次"，不赋予数字额外神秘属性**。它的实用价值是：**逼你在组方前想清楚"主症是什么、次要矛盾有哪些"**——本质是辨证训练。

### 7_3 路线四：按经络循行取数

> **逻辑**：**症状所在经络 → 该经络对应的卦数 → 循经取数。**

| 经络 | 取数 | 应用示例 |
| --- | --- | --- |
| 足阳明胃经（夹鼻上行） | 7 | 鼻症取 `07` 通鼻 |
| 督脉（行于脊里、上达巅顶） | 1 | 坐骨神经痛取 `010·80` |
| 足太阳膀胱经（腰背、下肢后侧） | 6 | 腰腿不适取 6 类方 |
| 足少阳胆经（循身侧、肩颈） | 5 | 肩颈不适取 5 类方 |

> 【辨析】这条路线**要求熟悉十二经脉循行，门槛最高**。普通自学者先掌握上表四个高频对应就够日常使用，不必死磕全部经络。

### 7_4 路线五：按五行生克取数——复杂与慢性的调衡

> **逻辑**：不针对单一脏腑，而是**调整个五行链的平衡**，多用于久病、多脏同病、虚实夹杂。

【原著·核心示范】`650·30·820`：

```latex
  6(坎水·肾) 5(巽木·阳木)  ──► 650：温振肾阳（阳木助 6 温通）
  3(离火·心) 0             ──► 30 ：通心气、益心阳
  8(坤土·脾) 2(兑金·肺) 0  ──► 820：培土生金，健脾益气

  整体方义：
      温肾(君) ──► 通心(臣) ──► 健脾益肺(佐使)
      肾水 ──► 心火 ──► 脾土 ──► 肺金，层层相生

```

> 【原著·经验】**生克路线的黄金律**："多数情况下，各象数之间应保持相生关系。"相克（如 `003` 水克火、`160` 金克木以疏泄）只在需要"清、泻、散、降"时用，**且中病即止，不可久用**。

### 7_5 五条路线怎么选：决策图与口诀

```latex
                     ┌─ 症状 = 局部、躯体部位明确 ──────► 路线一（八卦之象）
                     │
                     ├─ 症状 = 脏腑功能失调 ───────────► 路线二（藏象·最常用）
                     │
    先辨证 ──────────┼─ 多脏同病、久病、需整体调衡 ────► 路线五（五行生克）
                     │
                     │        ↑ 以上三条定"用哪些数"
                     │
                     └─ 定结构 ────────────────────────► 路线三（君臣佐使·定段序）
                          + 微调阴阳与力度 ────────────► 用 0（三条规则）
                          + 循经加强（可选）───────────► 路线四（经络循行）

```

**最简口诀**：

```latex
  脏腑定数 · 生克定链 · 君臣定序 · 0 定阴阳

  藏象定脏腑，卦象定部位，经络定路线，五行定组合，0 定力度与寒热

```

> 【辨析】五条路线**不是选择题，而是组合使用**——先定"用哪些数"，再定"怎么排"。

### 7_7 常见组方错误对照表

| 错误 | 表现 | 修正 |
| --- | --- | --- |
| **无的放矢** | 配方里没有主症对应的本脏数 | 回到"病位"，补上本脏数 |
| **堆砌数字** | 五段以上、单段超过 5 位 | 砍掉一半再看 |
| **乱用相克** | 没有"清泻散降"需求却用相克链 | 改回相生链路 |
| **阴阳跑偏** | 虚寒证用了一堆偶数 0 | 改奇数 0，或把 0 后置 |
| **标点错误** | 用逗号、顿号分隔段 | 必须用 `·` |
| **抄方不辨证** | 网上抄"专方"直接用 | 先写辨证结论再取数 |
| **主次不分** | 两段以上却无君臣之分 | 按主症重新排序 |

### 8_1 案例小故事：走完一遍七步，他还调了两次

> **【案例小故事 · 一位读者的取数全过程】**
>
> 某读者长期伏案，主诉是：**颈肩僵硬、情绪易郁、偶尔头晕、睡眠浅**。
>
> **第一轮（10 分钟）**
>
> **第二轮（第 10 天，出现新问题）**
>
> 他发现念完后**入睡反而变慢了**，有点"精神"的感觉。回到第二步重新辨证：他的"睡眠浅"到底是心脾两虚还是心神被扰？这次他注意到两个之前忽略的细节——**晚上念的时候思维很活跃，且口略干**。
>
> **第三轮（第 21 天）**
>
> 颈肩明显松快，但"睡眠浅"改善有限。他做了一个关键判断：**主症已经变了**——从"颈肩僵硬"变成"睡眠浅"。于是他把君药从疏肝（4）换成了养心（3）。
>
> **推导**：
>
> **结论**：**七步不是走一次就结束，而是循环。** 真正让他受益的不是那组方，而是**第 7 步"调"所依赖的记录**——没有记录，他既发现不了"入睡变慢"，也判断不了"主症已经变了"。
>
> **整个过程第一轮不到 10 分钟，关键是"辨证在前、试念在后"。**

```latex
  第1步 记：颈肩僵硬（主症）+ 情绪郁、头晕、睡眠浅（兼症）+ 诱因：久坐
  第2步 辨：颈肩属"肩颈与风邪" → 巽 5
        情绪郁 → 肝 4
        头晕、睡眠浅 → 心 3
        寒热偏中、虚中夹实 → 基调偏温通
  第3步 取：路线二（肝与心藏象）为主 + 路线一（肩颈取 5）
  第4步 配：疏肝(4)为君 + 养心(3) + 肩颈通络(50) → 430·50
  第5步 查：有本脏数(4) ✓  走相生(4→3) ✓  君臣有序 ✓  0 暂不加 ✓  精简(2段) ✓
  第6步 试：单组试念 15 分钟 → 无明显不适
  第7步 调：坚持一周，颈肩松快、情绪略舒 → 维持原方

```

```latex
  调整思路：原方整体偏温通（4 为阳木、50 偏阳），对"入睡"不利
  微调：把末段改为偏清降的结构，0 的个数与位置相应调整

```

```latex
  第 1 轮：主症颈肩 ──► 君在 4（疏肝通络）
  第 2 轮：反馈偏亢 ──► 调 0 的偏性（温通 → 偏清降）
  第 3 轮：主症转移 ──► 改君（4 → 3）

```

### 8_2 七步流程图

```latex
   第1步 记 ──► 第2步 辨 ──► 第3步 取 ──► 第4步 配 ──► 第5步 查 ──► 第6步 试 ──► 第7步 调
     │                                                  │
```

| 步骤 | 动作 | 关键要点 |
| --- | --- | --- |
| **「1」 记** | 记录主症 + 兼症 + 诱因 | 什么部位、什么性质（胀痛、刺痛、隐痛）、何时加重、伴随什么 |
| **「2」 辨** | 辨八纲：寒热虚实、阴阳、脏腑、表里 | 定基调（偏温或偏清）、定本脏数 |
| **「3」 取** | 选 1–2 条路线取数 | 脏腑病走路线二；局部病走路线一；复杂走路线五 |
| **「4」 配** | 定君臣佐使 + 加 0 调阴阳 | 君在前，字数精简，以 2–4 段为宜 |
| **「5」 查** | 自查"配方结构五问"（见 8_4） | 防常见错误 |
| **「6」 试** | 新配方先试念 10–20 分钟 | **不可跳过**，细则见板块9 |
| **「7」 调** | 据体感加减或换方，记录变化 | 病是活的，方随证转 |

### 8_3 逐步细化要点

#### 8_3_1 第一步"记"：把主诉写成可辨证的材料

```latex
  必填四项：
    部位：具体到哪里（左膝内侧、后颈、上腹）
    性质：胀痛 / 刺痛 / 隐痛 / 酸沉 / 冷痛 / 灼热
    时间：何时加重（晨起、午后、夜间、久坐后、进食后）
    伴随：睡眠、情绪、食欲、二便、口渴、畏寒或怕热

```

#### 8_3_2 第二步"辨"：输出一句辨证结论

按板块5 的句式：**病位 + 性质 + 病机 + 病势**。写不出，就回到第一步补材料。

#### 8_3_3 第三步"取"：一次只选 1–2 条路线

```latex
  局部形体病 ──► 路线一（必要时加路线四循经）
  脏腑功能病 ──► 路线二
  多脏同病 ──► 路线五
  无论选哪条 ──► 都要过路线三定结构

```

#### 8_3_4 第四步"配"：先排主次，再调 0

```latex
  顺序：君（主症本脏数）→ 臣（协助君）→ 佐使（兼症与护正）→ 加 0
  段数：控制在 2–4 段；单段 2–4 位
  分隔：用 · ，不用逗号或顿号

```

#### 8_3_5 第六步"试"：不可跳过

试念的细则、记录卡与判定标准见**板块9**。

#### 8_3_6 第七步"调"：三类调整方式

| 调整方式 | 适用 | 做法 |
| --- | --- | --- |
| **维持** | 体感舒适，指标趋势向好 | 不动方，坚持记录 |
| **微调** | 有效但不够，或略有过 | 只改一处：改一个 0，或换一段顺序 |
| **换方** | 辨证结论已变，或试念不通过 | 回到第二步重新辨证 |

### 8_4 配方结构自查五问（写完配方必过一遍）

#### 8_4_1 第一问：有"本脏数"吗？

主症对应脏腑的数是否出现？**没有就是"无的放矢"。**

```latex
  自检动作：指着配方问——"我这次主要想解决什么？对应的数在哪一位？"
  反例：主诉腹胀，配方里只有 3 和 6，没有 8 → 缺少本脏数

```

#### 8_4_2 第二问：走相生还是相克？

**优先相生链路**；用了相克，理由是否充分（清、泻、散、降）？

```latex
  自检动作：把相邻两个数的五行写出来，看是相生还是相克
  反例：无"清泻散降"需求，却用了相克链 → 改回相生

```

#### 8_4_3 第三问：君臣佐使顺序对吗？

主症（君）是否在最前？段与段之间用的是 `·` 还是逗号？

```latex
  自检动作：把三段分别标上"君/臣/佐使"，看能否说出各自理由
  反例：兼症在前、主症在后 → 语序错误，需重排

```

#### 8_4_4 第四问：0 用得合适吗？

奇偶（阴阳）、前后（偏性）、多少（峻缓）三条，是否都对得上证候？**体虚者慎用过多 0。**

```latex
  自检动作：
    个数：偶数个偏阴、奇数个偏阳 —— 与我的寒热判断一致吗？
    位置：前偏清降、后偏温通 —— 与我的病势判断一致吗？
    多少：0 越多越峻 —— 我的正气承受得住吗？

```

#### 8_4_5 第五问：精简吗？

超过 4 段或单段超过 5 位，**多半是堆砌了，试着砍掉一半再看**。

```latex
  自检动作：删掉一段，看主症是否还有对应；若仍成立，说明那段本就多余

```

## 板块9 · 实操（下）：默念规范·试念·感应·场景

> 本板块解决"怎么念"的问题：**读法、方式、节奏、时长、试念流程、感应判断、场景落地**。

读完本板块，你应当能：**正确地念出任何一组配方、独立完成一次规范的试念、分清该继续还是该停**。

---

### 9_1 读法：数字怎么读

+ 1–8 正常读：**一、二、三、四、五、六、七、八**；**0 读"零"**；
+ **1 不读"幺"，0 不读"洞"**，避免方言数字混淆；
+ **分隔圆点 **`·`** 不发音，仅停顿约 1 秒**；
+ 例：`650·3820` 读作"六五零（停一秒）三八二零"，**不读成"六百五十"**；
+ 0 有几个读几个："00"读"零零"，"000"读"零零零"；
+ 可用自己最熟悉的语言或方言默念，不分语种与民族。

---

### 9_2 方式与姿势

+ **唇舌微动、无声默念**（不出声），身心放松、意念专注；
+ 【原著精神】"可施治于日常行、走、坐、卧之中"，**不限时间、地点与姿势**；
+ 可辅以"抄写配方随身带、放枕边"作静心辅助，但**不能替代默念**；
+ 默念时保持安静、心神安定即可。

---

### 9_3 速度与节奏

【民间拓展，主流做法】**匀速舒缓，约 1 秒 1 个数**；多元之间停顿约 1 秒；循环往复，不快不慢。

```latex
  示例：640 · 380

  念法：六 — 四 — 零 —（停 1 秒）— 三 — 八 — 零 —（停 1 秒）— 循环
  节奏：每字约 1 秒，呼吸自然，不憋气、不赶拍

```

---

### 9_4 时长与时机

+ 【民间拓展】**每次 10–30 分钟，每日累计约 30 分钟以上**；**睡前、晨起、闭目入静时**更易放松；
+ **慢病可延长至 1–2 小时/日**，但**贵在坚持而非久熬**——过度默念反致气机紊乱、头晕胸闷。

```latex
  时长判断标准（比分钟数更重要）：
      念完更松、更静 ──► 时长合适
      念完头胀、心慌、烦躁 ──► 过长或配方偏性不对，缩短并重新辨证
      念完无感 ──► 正常，不必加时，继续记录

```

---

### 9_5 新配方试念：硬性流程，务必执行

+ **单组配方单独试念 10–20 分钟**，全程感受身体状态；
+ **无头晕、心慌、胸闷、气短、胃部不适、恶心烦躁 → 可长期持念**；
+ **多组备选 → 逐组试念，选体感最舒适、最放松的一组**；
+ **试念出现任何不适 → 立即停念**，不适会自行消退，随后换方。

#### 9_5_1 试念记录卡（每次试念填一张）

```latex
  配方：__________________
  来源：□自拟（辨证结论：____________）  □基础方衍生  □他人提供

  时长：________ 分钟

  体感（勾选并描述）：
    □ 头：清爽 / 昏沉 / 胀痛  ____________
    □ 心：平稳 / 心慌 / 胸闷  ____________
    □ 胃：舒适 / 恶心 / 绞痛  ____________
    □ 其他：酸麻胀热、窜动、困倦  ____________

  判定：□ 通过（可持念）   □ 不通过（停念换方）   □ 需就医
  备注：______________________________________

```

### 9_6 身体感应：好反应还是要停

【民间拓展，综合经验，供参考】——**判断是否继续的唯一硬标准仍是板块1 的六条红线**。

| 类型 | 表现 | 处理 |
| --- | --- | --- |
| **良性正常感应**（可继续） | 头脑清爽、身体轻松、原有酸胀痛减轻；局部酸麻胀热、跳动、经络窜动、关节弹响 | **继续默念** |
| **不良异常感应**（立即停） | 头部胀痛眩晕、胃部绞痛恶心、心慌心悸、胸闷气短、烦躁 | **立刻停念**，静待平复，换方或就医 |
| **无感**（正常） | 无明显体感 | **坚持即可**，反应小不等于无效 |

> 【辨析】网络上流行的"**排病反应**"说法（默念中症状短暂加重等于修复过程）**缺乏循证支持**：
>
> 第一，原著验案中确有"初念不适、调方后愈"的记录——**这说明"不适"在原著里是"调方信号"，不是"硬撑理由"**；

第二，**底线是：只要出现心、头、胃三大不适，一律停念**，不因"排病反应"硬撑。宁可错停。

### 9_7 三个高频生活场景的落地做法

```latex
  通勤路上（5–15 分钟）
    · 只念已通过试念的老方，不在通勤时试新方
    · 闭目或目视前方固定点，唇舌微动，不影响正常呼吸
    · 到站即停，不追求"念满时长"

  办公间隙（3–5 分钟，可多次）
    · 颈肩僵硬时，先起身活动 1 分钟，再默念
    · 用"分段计数法"：念满 20 遍为一组，避免心算分神
    · 若念完反而烦躁，说明时段或配方不合适，改到睡前

  睡前（15–30 分钟）
    · 最推荐的试念与持念时段
    · 念完立即记"入睡自评（0–10 分）"，便于做趋势对比
    · 若念完反而精神亢奋：缩短时长，或把 0 调为偶数个（偏阴）

```

### 9_8 案例小故事：试念十分钟，救了后面三周

> **【案例小故事 · 那十分钟没白花】**
>
> 一位读者为自己"脾虚湿困"的腹胀取了一组方，自认为思路清楚——腹胀归脾，取 8；湿困需温化，0 后置加强温通；再佐一段宣肺的 2。写成 `820·80` 之类的结构，看起来挑不出毛病。
>
> 按照流程，他没有直接持念，而是**先单独试念 15 分钟**。
>
> 停念后静坐了几分钟，闷感自行消退。他第二天做了一次调整：**减少 0 的个数、把段数从两段减到一段**，再试念 15 分钟，全程舒适。
>
> **推导**：
>
> **结论**：**试念是这个体系里成本最低、收益最高的一个动作。** 十分钟换来三周不走弯路。而它的价值还有一层——**它让你第一次拥有"干净的单变量反馈"**：只有一组方、只有十五分钟，出了任何体感都能定位到这组方。

```latex
  第 5 分钟：腹部有轻微温热感，他记下"良性，温热"
  第 9 分钟：开始觉得"胸口有点闷"，他记下"心区？观察"
  第 12 分钟：闷感未消，且有点烦躁 ──► 立即停念

```

```latex
  若跳过试念：直接持念三周 ──► 每周都闷 ──► 他会把"闷"归因为"腹胀没好"
                                       ──► 继续加量或换更复杂的方
                                       ──► 越走越远

  有了试念：15 分钟就暴露问题 ──► 定位到"0 太多、段太杂"
                             ──► 一次微调解决

```

## 板块10 · 调方、调护与特殊场景

> 本板块解决"念了一段时间以后怎么办"：**调方节奏、平台期、康复巩固、生活调护、特殊场景处理**。

读完本板块，你应当能：**判断该微调还是换方、处理效果变平、把念数放进生活方式里、正确处理代念与贴数**。

---

### 10_1 案例小故事：念了三周没效，问题出在"换得太勤"

> **【案例小故事 · 一周换四张方的人】**
>
> 一位读者主诉"入睡困难"。第一个星期，他自己取了一组方，念了两天，觉得"没什么感觉"，于是去群里问，别人给了第二组；念了两天还是没感觉，又从网上找了第三组；周末一位朋友推荐了第四组。
>
> 一周四张方。到第七天，他说了一句很典型的话：**"每一张都像有用，又都像没用。"**
>
> 后来有人让他做一件事：**只留第一组，连念两周，每天只记一个数字——入睡自评。**
>
> 两周后的曲线是这样的：
>
> 他这才意识到：**第一组方其实在第 4 天就开始起作用了，只是"起了作用"和"感觉明显"之间隔了好几天。** 他之前每一张方都只念两天，等于每一张都在"起效前"被换掉。
>
> **推导**：
>
> **结论**：原著精神是**一组方子先念到位，效果减弱时只做微调**（改一个 0、换一段顺序），而非整体推翻。**实操建议：选定一组后至少坚持 1–2 周并完成完整记录，再决定是否换方。**

```latex
  第 1–3 天：5 分（基线水平，无变化）
  第 4–6 天：5 分、6 分、5 分（开始波动）
  第 7–10 天：6 分、7 分、6 分、7 分（缓慢上行）
  第 11–14 天：7 分、7 分、8 分、7 分（趋于稳定）

```

```latex
  频繁换方 ──► 每次都从零开始 ──► 永远停在"起效前"区间
  固定一方 ──► 跨过起效滞后 ──► 得到可判断的趋势曲线

```

### 10_2 调方节奏：三组判断规则

| 情况 | 判断 | 动作 |
| --- | --- | --- |
| **体感舒适，指标向好** | 方对证 | **不动方**，坚持记录 |
| **有效但不够，或略有过** | 方向对，力度偏 | **微调**：只改一处（改一个 0，或换一段顺序） |
| **辨证结论已变，或试念不通过** | 方向不对 | **换方**：回到第二步重新辨证 |

```latex
  微调的优先级（从最小改动开始）：
      第1步 改 0 的个数（奇偶）
      第2步 改 0 的位置（前后）
      第3步 换一段的顺序
      第4步 减掉一段
      第5步 整体重取 —— 这是最后一步，不是第一步

```

---

### 10_3 不适时的微调方向（经验参考）

| 试念不适 | 常见调整方向（经验，非定论） |
| --- | --- |
| 头晕（偏阳、上火） | 减一个 0，或改偶数个 0 以偏阴 |
| 胸闷（偏阴、凝滞） | 调 0 的个数以助阳，或换段序 |
| 胃不适 | 减 0、减段，换成更温和的组合 |

> ⚠️ 以上属经验归纳。**一旦头、心、胃出现明显不适，第一动作永远是"停念"**，微调是停念之后的第二步。

---

### 10_4 平台期：为什么念久了效果变"平"

正常现象——初期病象明显，体感强；持续念后进入"平台期"。此时可：

1. **微调 0 的个数或位置**；
2. **调整默念时段**（睡前改为晨起，或相反）；
3. **回到辨证，看看证候是否已经改变**——**证变了，方就该变**。

```latex
  平台期三步排查：
      第一步：是"力度"问题吗？──► 微调 0
      第二步：是"时段"问题吗？──► 换时段
      第三步：是"证候"问题吗？──► 重新辨证，必要时改君

```

> 【辨析】"次声波"的解释要清醒看待——**"数字通过次声波治病"这一因果链并无科学证据**。把它理解为"专注 + 放松 + 规律作息"的冥想训练，更稳妥。

### 10_5 康复巩固与收尾

【民间拓展】症状消失后，**继续原方巩固一段时间**再渐停。

```latex
  收尾节奏建议：
      症状消失 ──► 原方继续巩固一段 ──► 减少单次时长 ──► 减少频次 ──► 停
      收尾期间仍要记录主指标，若指标回落则回到上一档

```

### 10_6 调护：把"念数"放进生活方式里

【辨析】原著真正的落脚点其实是"调"——象数疗法要求"配方准确 + 诚信坚持"，但**坚持不等于硬扛**。

```latex
  ┌────────────── 每日调护四件套 ──────────────┐
  │                                            │
  │  作息：规律作息，不熬夜（尤其 23 点前）      │
  │  饮食：少生冷、少肥甘厚味（护脾土、化痰湿）  │
  │  情志：不郁不怒（肝木 4、5 最易扰动）        │
  │  记录：时长 + 睡眠 + 情绪 + 饮食（单变量）   │
  │                                            │
  └────────────────────────────────────────────┘

```

### 10_7 特殊场景处理

| 场景 | 做法 | 级别 |
| --- | --- | --- |
| **代念**（婴幼儿、昏迷、神志不清、记忆极差者） | 旁人握其手掌，或贴近耳部轻柔念诵 | 【原著·经验】 |
| **贴数/置数**（上班族、学生、婴幼儿、需长效） | 配方写在胶布上，贴于丹田或患处附近，或随身放置 | 【民间拓展】 |
| **心前区（胸口）** | **禁止贴敷** | 【辨析】安全共识 |
| **康复巩固** | 症状消失后继续原方巩固一段时间再渐停 | 【民间拓展】 |
| **搭配其他疗法** | 可与针灸、推拿、艾灸、食疗、作息调整同用，不冲突 | 【民间拓展】 |
| **磁疗床垫与家电"干扰磁场"** | 属民间说法，无科学依据；保持安静、心神安定即可，不必刻意购置或规避所谓"能量产品" | 【辨析】 |

> 说明：上表中"贴数/置数"的做法，原著中并无严格论述，属民间发挥。**心前区禁止贴是安全共识；配方贴敷不可替代正规治疗。**

## 板块11 · 验案精讲

> 验案是全书的**实战题库**。

**正确读法是"盖住配方自己先取数，再对答案"**，而不是抄方。
读完本板块，你应当能：**看到一段证候描述，推导出合理配方，并说清每一步的理由**。

---

### 11_1 案例小故事：盖住答案的那一刻，学习才真正开始

> **【案例小故事 · 先取数，再对答案】**
>
> 只给你这一句证候：**"左侧坐骨神经痛，手足欠温，舌暗苔润，脉虚。"**
>
> **请先自己取一轮数，再看下文。**
>
> 多数人会这样推导：
>
> **原著答案正是 **`70`**。**
>
> 但真正有价值的不是"猜中了"，而是这个过程中你被迫做的三件事：
>
> 有意思的是，原著在这个案子里还记录了一个**反例**：最初用的是 `7000`，力道偏峻，**祛邪的同时正气受损**，于是退到 `70`。
>
> **推导**：这说明验案里那些"最终方"往往是**调整后的结果**，而不是第一版就完美。
>
> **结论**：**验案不是"秘方集"，而是"辨证训练题"。** 读验案学的是思维方式，不是方子本身。

```latex
  第一步，定病所：坐骨、下肢、关节 ──► 归艮 7（艮为山，主手、背、关节）
  第二步，定性质：手足欠温 + 脉虚 ──► 偏寒、正气不足
  第三步，定力度：正气不足，力过则伤正 ──► 温通力适中，不用重 0
  第四步，成方：7 + 单 0 后置 ──► 70

```

```latex
  第1步 你必须把"坐骨神经痛"翻译成"部位 + 性质"，而不是停在病名上
  第2步 你必须判断"力道"，而不只是判断"用哪个数"
  第3步 你必须在看到答案前，先给出一个可以被验证的自己的答案

```

---

### 11_2 读案三步法

```latex
  第1步 盖住配方，只读证候
```

### 11_4 四条取数心法

#### 11_4_1 心法一："直取病所"优先

> 局部、形体病，**先用八卦之象取数直达病位**（膝取 7、腰取 6、头取 1），简单有效——**路线一是地基**。

**故事印证**：案 1 坐骨神经痛直接用 `70` 取病所，不绕脏腑，干净利落。

#### 11_4_2 心法二："力过则减、力不足则加"

> `7000`（过峻）退为 `70`（适中）；`600`（力不足）进为 `6000`（加力）。**0 的个数就是在调"剂量"。**

**故事印证**：案 1 弃 `7000` 用 `70`、案 3 弃 `600` 用 `6000`——**同一个方向，0 的个数决定力度**。

#### 11_4_3 心法三："补有过则改疏"

> 骨质增生案中 `650·380` 引起腿脚麻（补脾有过、气滞），改 `650·30·80`（以 3 通心脉代 8 之补脾）而愈。**提示：补益太过反成壅滞，此时应减补、加疏。**

**这是全书最反直觉的一条**——初学者总觉得"补得不够"，原著却反复演示"补过了要往回撤"。

```latex
   补 ──► 有效 ───────────► 继续
   补 ──► 胀、麻、闷、烦躁 ──► 减补 + 加疏（通心脉、疏肝气、行气机）

```

#### 11_4_4 心法四："久病、经络堵塞甚，需多次调方"

> 全身风湿痛案"初试几次均不适，经几次调方渐感舒适"——**不要指望一组方包打天下，要接受"试—调—再试"的迭代过程**。

**故事印证**：案 5（全身风湿痛）与案 6（疔毒善后）都经历了"先攻后调、多次换方"——**调方不是失败，而是正常流程**。

### 11_5 验案的局限（务必知悉）

【辨析】**验案的局限必须说清**：这些病例均为**作者单方临床观察**，缺少随机对照、盲法与长期随访，且病例经过筛选（有效者更容易被记录）。

> 原著自述的"千余例观察、有效率高"一类数据**出自作者自报，未经独立重复验证，不可当作疗效证据引用**。

### 13_1 案例小故事：记了三周之后，她才第一次"看见"规律

> **【案例小故事 · 记了三周后的变化】**
>
> 一位读者起初凭"感觉"念数：今天念 `640`，明天听人说 `380` 好就换 `380`，后天又看到一篇帖子推荐另一组。两周下来，她的总结是："**好像有点用，又说不清。**"
>
> 后来她开始记象数日记。规则很简单：**每天睡前只填三个格子——配方、时长、入睡自评（0–10 分）。**
>
> 三周后，她把那 21 行数字摊在桌上，第一次看见了规律：
>
> 三条规律里，最有价值的其实是第三条——**同一个方，在不同时段的效果并不一样。**
>
> **推导**：
>
> **变化不在于方子变了，而在于她开始"单变量追踪"了。**
>
> **这正是日记的唯一真实价值：把"玄学"变成"可观察实践"。**

```latex
  睡前念 30·80 的那几天：入睡自评稳定在 7–8 分
  念其他方的那几天：入睡自评在 5–6 分浮动
  中午念 30·80 的那几天：入睡自评与不念时差别不大

```

```latex
  凭感觉：变量混乱（配方变、时段变、时长变）──► 无法归因
  记日记：配方与时段被拆开记录 ──────────────► 能看出"方 × 时段"的交互

```

### 13_2 可直接吸收的"操作细化"

### 13_5 单变量追踪：日记的真正用法

> 【辨析，实操方法论】日记的价值不在"记"，而在"**控制变量地分析**"。

```latex
     记录 ──► 观察趋势 ──► 只改一个变量 ──► 再记录 ──► 比较 ──► 决定
       ▲                                                        │
       └────────────────── 回到辨证重新审视 ───────────────────┘

```

#### 13_5_1 一次只变一个因素

换方时**只换配方，其他不变**（时段、时长、作息照旧），这样才能判断变化是不是配方带来的。

| 变量 | 做法 |
| --- | --- |
| 配方 | 一次只换一组，且只改一处（换一段，或改一个 0） |
| 时段 | 要改时段，就先固定配方 |
| 时长 | 要改时长，就先固定配方与时段 |
| 作息与饮食 | 尽量稳定，有变动就在日记里标注 |

#### 13_5_2 看趋势，不看单次

```latex
  ❌ "今天念了 640，腰不痛了"
     ──► 单次，可能是自愈或自然波动

  ✅ "连续 5 天睡前念 640，腰痛自评从 6 分降到 3 分"
     ──► 趋势，才有参考意义

```

#### 13_5_3 设"对照期"

可先用 1 周 A 方、再 1 周 B 方，**同一指标**对比，比"混着试"清楚得多。

### 13_6 四周验证协议（想认真验证就用这个）

```latex
  第 1 周  基线期：不念（或只保持规律作息），每天记录主指标
  第 2 周  试方 A：固定时段与时长，只增加"默念 A 方"这一个变量
  第 3 周  洗脱期：停念，回到基线状态（避免前一阶段的残留影响）
  第 4 周  试方 B 或重复 A：与第 2 周同条件，比较同一指标

```

**执行要点**：

| 要点 | 说明 |
| --- | --- |
| **指标唯一** | 四周只盯一个主指标（如入睡自评），其余只作备注 |
| **条件恒定** | 时段、时长、作息尽量不变；变动一次就在日记里标注 |
| **样本足够** | 每周至少 5 天有效记录，否则不进入比较 |
| **允许无结论** | "四周下来看不出差别"是完全正常且诚实的结果 |

> ⚠️ 再次强调：即便日记显示"有效"，也**不能据此宣称疗效**——更可能是放松、规律作息、安慰剂效应的综合结果。**日记的真正产出是"自我觉察能力"，不是"治病证据"。**

---

### 13_7 结果怎么读：四种可能的归因

【辨析】默念后"感觉好转"，可能来自以下任一项或多项叠加：

1. **放松与专注效应**（默念本身即冥想训练）—— 最可信的解释；
2. **安慰剂效应**（对"数字能量"的信念）；
3. **自愈与回归均值**（许多症状本就会波动缓解）；
4. **疾病自然病程**。

**无论归因如何，只要遵循红线、不替代医疗、配合正规治疗，作为辅助放松练习并无不妥。** 但若据此宣称"念数治病、可停西药"，则既是**安全危险**，也是**逻辑错误**。

### 13_8 案例小故事：一个诚实的"无结论"

> **【案例小故事 · 四周之后，他说"看不出来"】**
>
> 一位读者严格执行了四周验证协议，主指标是"午后疲劳自评"。
>
> 他把这四行数字发到群里，问："这算有效吗？"
>
> 群里有人替他"解读"：第 2 周和第 4 周都比基线高，说明有效。也有人说：差别只有零点几分，说明没用。
>
> 他自己最后给出的结论是：**"看不出来。"**
>
> **推导**：
>
> **结论**：**"看不出来"不是失败，它是这套方法能给出的最有价值的结果之一。** 因为它意味着你没有被安慰剂牵着走，也没有把自然波动当成疗效。
>
> 而这份清醒，恰恰来自日记——**没有那 20 行数字，他大概率会说"我觉得有点用"。**

```latex
  第 1 周（基线，不念）：5、6、5、5、6     平均 5.4
  第 2 周（试方 A）　　：6、5、6、6、5     平均 5.6
  第 3 周（洗脱，停念）：5、6、5、6、5     平均 5.4
  第 4 周（重复 A）　　：6、6、5、6、6     平均 5.8

```

```latex
  差值（0.2–0.4 分）远小于日常波动幅度（同周内就有 5 与 6 的起伏）
  ──► 无法把这点变化归因到配方上
  ──► 诚实的结论是"证据不足"，而不是"有效"或"无效"

```

### 14_1 案例小故事：同一张方，两个人念出两种结论

> **【案例小故事 · 同方不同命】**
>
> 两位读者在群里交流，发现彼此念的是同一组方，都是 `640`。
>
> **第一位**说："太神了，我念了三天，眼睛干涩明显好转。"
>
> **第二位**说："我念了两周，一点感觉都没有，是不是我体质特殊？"
>
> 细问之下，两人的情况是这样的：

```latex
  第一位：长期使用屏幕，目干涩、夜间小腿抽筋、舌淡、脉细
          ──► 肝血不足，走"滋水涵木"正对证

```

>   第二位：目干涩，但伴口苦、易怒、舌红苔黄、脉弦数

          ──► 是肝火上炎，不是肝血不足

> 更值得玩味的是第二位的第二个问题——**"是不是我体质特殊？"** 这个问题本身就暴露了一个常见误区：**把"没效"归因于体质，而不去检查辨证是否正确。**
>
> **结论**：**"别人念有效"从来不是"我也该念"的理由。** 唯一能作为理由的，是**你自己的辨证结论与那张方的取数依据是否一致**。

```plain

**推导**：`640` 是"补肾水以养肝木"的方，走的是**补**的路子。第一位是虚证，补之有益；第二位是**实火**，补之如同添柴。

```

```text
  同一张方：对第一位是"对证"，对第二位是"反证"
  差别不在方，在辨证

```

### 14_2 五组必须想清楚的关系

#### 14_2_1 辨析一：先天数 vs 其他数字体系

【原著】象数疗法**只用先天八卦序数**（乾1 兑2 离3 震4 巽5 坎6 艮7 坤8），**不混用**河图数、洛书数、地支数、五行数字。这是"卦—数"对应的唯一标准。

| 体系 | 举例 | 能否用于象数疗法 |
| --- | --- | --- |
| 先天八卦序数 | 乾1、兑2、离3、震4、巽5、坎6、艮7、坤8 | ✅ 唯一标准 |
| 河图数 | 一六为水、二七为火一类 | ⛔ 不可混用 |
| 洛书数 | 戴九履一一类 | ⛔ 不可混用 |
| 地支数、五行数字 | 子为一、寅为一类 | ⛔ 不可混用 |

> **网上用"1=水、2=火"等河图体系来解释象数疗法，是张冠李戴。**

#### 14_2_2 辨析二：辨证取数 vs 套方（全书最重要的辨析）

```latex
  ✅ 原著立场：辨证取数 ──► 因人、因时、因证变化 ──► 病是活的，方也要活
  ❌ 网络主流：症状 ──► 查表 ──► 抄方（"失眠专方 40 个"一类）

```

**两者效果的天壤之别不在"方子好坏"，而在"有没有经过辨证与试念两道关"。**
宁可用简单路线自己取一组 `70`，也不用网上抄来的二十位数"神方"。

| 维度 | 辨证取数 | 套方 |
| --- | --- | --- |
| 起点 | 辨证结论 | 病名 |
| 出错时 | 能定位到"辨证错"还是"取数错" | 无从定位 |
| 调方时 | 有锚点，可微调 | 只能整张换掉 |
| 可迁移性 | 高，能推新的方 | 无，只会抄 |

#### 14_2_3 辨析三：「气场共振」假说 vs 可验证的放松效应

| 说法 | 性质 | 该怎么看待 |
| --- | --- | --- |
| 默念产生次声波，与宇宙八卦场共振从而治病 | **假说**，无科学证据 | 不作为行动依据 |
| 默念带来专注、放松、呼吸变缓 | **可观察的效应** | 这是更稳妥的解释 |
| 借象收心、以静调气 | **可操作的描述** | 可以放心使用 |

> 【辨析】**"气场""共振"是假说，不是结论。** 默念能带来的更可能是**专注、放松、规律作息与自我觉察**——这些本身确有健康价值，**不需要借用"量子""磁场"这类词来解释**。

#### 14_2_4 辨析四：结构语言 vs 玄学语言

| 概念 | 结构语言（推荐） | 玄学语言（应避免） |
| --- | --- | --- |
| 君臣佐使 | 决定顺序与主次，逼你想清主次矛盾 | 给数字赋予神秘等级 |
| 数字顺序 | 承载结构信息，改动要基于辨证变化 | "换一位就出事" |
| 0 的个数 | 调节力度与阴阳偏性的旋钮 | "0 是宇宙本源能量" |
| 相生相克 | 取数的推导规则与收手准则 | "五行相克会伤身"式的恐吓 |

> 【辨析】**"能自圆其说、试念舒适即可"是实操原则**，但这不等于"什么解释都行"——解释要能**指导你下一步做什么**（加 0 还是减 0、继续还是停），解释不了动作的，就是玄学语言。

#### 14_2_5 辨析五：自我观察 vs 疗效宣称

| 日记能证明的 | 日记不能证明的 |
| --- | --- |
| 我的主指标在这几周的变化趋势 | 这组方"治好了"某个病 |
| 我在某个时段念更放松 | 这组方对别人也有效 |
| 我念完出现头心胃不适，应当停 | 不适是"排病反应"所以应坚持 |

> 【辨析】默念后"感觉好转"可能来自四种原因：**放松与专注效应、安慰剂效应、自愈与回归均值、疾病自然病程**（详见板块13 的 13_7）。**无论归因如何，只要遵循红线、不替代医疗，作为辅助放松练习并无不妥**；但若据此宣称"念数治病、可停西药"，则既是安全危险，也是逻辑错误。

### 14_3 两个高频疑问

#### 14_3_1 "数字顺序能随便换吗？"

【辨析】**不能随意换。** 配方中数字的顺序承载"君臣佐使"结构（君在前、臣在中、佐使在后），`4300` 与 `3400` 表达的脏腑主次不同。

> **但也不必过度神秘化**：调整的核心依据是**辨证结论**，而非"换一位就出事"。换方前先问"我的辨证变了没有"，比纠结数字位置更根本。

#### 14_3_2 "关于 0 的说法，不同地方不一致，听谁的？"

【辨析】关于"0 的个数奇偶"与"前后位置"的表述，在不同转述中确实存在细微出入。**处理原则有三条**：

```latex
  第1步 以原著的三条规则为准（个数、位置、多少）
  第2步 两可时，以"试念体感"为准 —— 同一证候试两个方向，取更舒适者
  第3步 体虚者一律慎用过多 0，前后皆加 0 的结构不宜长期久念

```

> 这三条合起来，正是"辨证取数"的核心精神：**配方是活的，人是活的，病也是活的。**

### 14_5 三点核心结论

1. **这套方法的真正价值在"辨证训练"，不在"数字清单"**——即便不默念，这套"把症状翻译成脏腑、五行、气机"的翻译能力也值得学。
2. **"气场""共振"是假说，不是结论**——默念能带来的更可能是专注、放松、规律作息与自我觉察，这些本身确有健康价值，不需要借用"量子""磁场"来解释。
3. **最值得保留的三个动作**：

```latex
   第1步 每天固定 30 分钟专注默念（正念训练）
   第2步 写辨证日志（症状追踪）
   第3步 坚持"不舒服就停、有病先看医生"（风险意识）

```

> **一句话边界**：象数疗法的价值，不在"数字能治病"这个未经证实的前提，而在"**借象收心、以静调气、辨证迭代**"这套自我觉察的练习。

## 板块15 · 版本层级与研读顺序

> 本板块解决三件事：**不同版本的层级怎么分、按什么顺序读才不重复不遗漏、延伸内容读到什么程度停**。

核心目的只有一个：**避免把后期发挥误认成原著核心**。

### 15_1 案例小故事：一段被张冠李戴的引文

> **【案例小故事 · 一段被张冠李戴的引文】**
>
> 网络上有段"八卦象数"论述流传很广，被许多教程当成"原著核心"反复引用，甚至有人用它来推导理论边界。
>
> 细查之下却发现：它出自一本**晚出的延伸读物**——比增补版晚了十几年才出版的续编类作品，书中收录的是后期大量的实例与发挥。

```latex
  误认路径：网络引文 ──► 被当作"原著核心"
                     ──► 据此推导理论与边界
                     ──► 判断失真（把后期发挥当最初骨架）

```

>   正确路径：引文 ──► 溯源到"延伸读物"

                 ──► 降级为参考
                 ──► 回到原著骨架重建认知

```plain

若混为一谈，后果是具体的：**你会以为某个后期才出现的说法，是这套方法一开始就有的基础设定**，于是把它写进自己的推导前提里，越推越偏，还浑然不觉。

**推导**：**版本厘清，本质是"可靠性溯源"的第一步。** 就像引用一句话之前要先知道是谁说的、在哪说的、什么时候说的——**同一句话，出自原著和出自后期发挥，分量完全不同。**

**结论**：本知识库开篇就做版本对照、收尾又单列本板块，原因正在于此。**读什么、信几分，取决于它来自哪一层。**

```

### 15_5 答疑精选（理解原著精神的窗口）

> 【原著·答疑，整理自作者公开答复】

**问：为什么不叫"功法"而叫"疗法"？**
答：它不像一般气功那样有一套动作，也不对调身、调心、调意作严格要求；它"自然、自由、自为"，且讲究**因人取数、辨证施治**，故称"疗法"。

**问：默念为什么不限时间、地点与姿势？**
答：八卦象数被视为天道、物道、人道的缩影，是"天人合一"的媒介，故可贯穿于行、走、坐、卧之中。

> 【辨析】答疑中"偏阳、偏阴"一类对应属作者经验归纳，**不可当作机械公式**——实操第一原则仍是"试念体感 + 板块1 红线"。默念中出现不适如何处理，详见板块9 与板块10。
