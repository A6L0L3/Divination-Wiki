## 板块0 · 学习路径和建议

初学运气最常见的失败不是"看不懂"，而是"看懂了却串不起来"：概念一个个都认识，给一个年干支却排不出盘；表背得挺熟，遇到"某年为何多雨多病"仍说不出所以然。这块板块专门解决次序问题，先给一张全局路线图，再给一份可落地的四周任务表，然后点明最容易走错的几个岔口，最后用一份自检清单告诉你"什么程度算过关"。它不讲任何推算细节，细节从板块1 开始。

---

### 0_1 学习路径

#### 0_1_1 学习路径总览

运气的学习不是"读完就会算"的直线，而是"打底、备零件、装配、应用沉淀"的循环推进。把整套知识想成盖房子：先确认图纸与地基（学科定位、历史源流、干支工具），再逐块烧砖（五运、六气、运气相合、胜复郁发），然后把砖拼成一面完整的墙（某年运气格局推演），最后才谈得住进去、用起来（养生、辨证、疫病、方药）。

```text
打底（定位 / 源流 / 干支）
        │
        ▼
备零件（五运 / 六气 / 相合 / 胜复郁发）
        │
        ▼
装配（某年格局完整推演）
        │
        ▼
应用沉淀（养生 / 辨证 / 疫病 / 方药 / 古籍 / 现代 / 笔记）
        │
        └──────► 复盘纠偏，回到上一层补漏
```

四个阶段各有明确产出，缺一环就会在后面卡住：

```text
阶段        对应板块            该阶段的硬产出
打底        板块1、板块2        能默写干支并讲清运气为何属"医"
备零件      板块3 至板块6       每块一张能自己画出来的表
装配        板块7              一份可复盘的某年排盘记录
应用沉淀    板块8 至板块10      一份病案对照笔记与一页术语速查
```

第1阶段立地基，产出是能默写天干地支、讲清运气为何落在"医"而非"命"。第2阶段备零件，每块都对应一两张彼此咬合的表，重点不是背表，而是理解"表从哪来、喂给谁"。第3阶段装配，把零件串成一次完整推演，缺了它，前面背得再熟也只是散装知识。第4阶段应用沉淀，把结论接回临床与文献，并持续用复盘修正理解。

需要提醒的是，这四个阶段并不是一次走完就结束。真正熟练的人常在"装配"与"应用"之间来回：排一次盘、对一次实际气候、发现偏差、回到零件层补漏，再重新装配。路线图右侧那条回到上层的箭头，就是这个意思。

#### 0_1_2 新手入门顺序（四周版）

下面是一份可落地的四周节奏，每天约四十分钟，重在"建立手感"而非速成。已有阴阳五行与节气基础者，可压缩为两到三周；零基础则不建议跳周，因为跳过任何一周都会在第三周的相合判断上暴露出来。

第1周：通读学科定位与历史源流，并把十天干、十二地支、阴阳属性背熟。产出是能不看资料默写天干地支顺序，并讲清"阳干配阳支、阴干配阴支"的配对逻辑。这一周不碰排盘，只解决"这是什么东西、凭什么能算"。

第2周：拿下岁运（天干化五运口诀）与司天在泉（地支化气口诀）。产出是给定任意年干支，能立刻说出岁运五行与太过不及，以及司天、在泉各是什么气。这是全库性价比最高的一周，两张口诀覆盖了年度推演一半的信息量。

第3周：学习运气相合的特殊格局与胜复郁发的动态机制。产出是能判定天符、岁会、太乙天符，并说清"胜、复"自我纠偏为何能解释某些突发疫病。本周开始出现"多个条件叠加"的判断，是最容易混淆的一周。

第4周：完整走通两三个虚拟年份的推演流程，并亲手绘制一张当年运气格局表。产出是一份自己能解释、能核对、能复盘的排盘记录。本周不追求结论漂亮，只追求流程不缺步。

> （虚构教学案例，不对应真实人物）阿岚照这份四周计划自学。第1周她卡在"为什么甲己化土而不是化火"，后来读到岁运源于五音建运、角徵宫商羽配属的推演逻辑，才明白化运并非任意规定，而有一套音律太少之别的推导。她把这句"卡点—解惑"写进错题本，几个月后反成了带新人的讲解素材。第4周她第一次独立排盘时漏了"在泉"，答案只对了一半，于是给自己加了一条规矩：排盘必须先写"司天—在泉"一对，再补间气。

四周只是起步，不是终点。有人四周走完仍觉得"会背不会用"，这很正常，因为"用"需要真实气候与病案的对照，那属于板块8 的内容。四周的真正目标只有两个：干支与口诀内化，推演流程不缺步。

### 0_2 使用建议与边界声明

#### 0_2_1 常见误区

误区一，把运气当"中医算命"。运气的落点是气候与发病的趋势提示，不是个人吉凶祸福。它看的是"那年天地之气偏哪边、人易得什么病"，不是"你哪年发财"。一旦把年干支当成个人命运的密码，后续所有推演都会滑向不可验证的方向，也就失去了讨论的基础。

误区二，机械套用某年某气。同一甲子年份，南北地域、海拔、微气候差异巨大，原典本身也强调不可拘泥数字，须观察实际气象物候。把格局直接当作必然结论，是最常见的误用；正确做法是把格局当"倾向假设"，再用当年的实际气候去校正它。

误区三，只背表不推演。会背口诀不算会，能对着任意年干支独立推一遍、再核对一遍，才算真正掌握。规则的复用能力比记忆本身更重要，因为表可以查，判断力只能练。

误区四，跳过胜复直接谈病。不少人学完五运六气就急着解释"某年为何某种病多"，却忽略胜复郁发这套纠偏机制，于是把"某气偏胜"直接等同于"某病必发"。少了动态调节这一层，结论往往过于绝对。

四个误区的共同根源是同一个：把运气当成一套"查表得结论"的静态知识。它实际是一套"按规则推演、再按现实校正"的动态方法，前者可以背，后者必须练。

#### 0_2_2 边界声明

运气可以算，但不可以替人下诊断。三条边界写在最前面：

- **推演是规则，结论是倾向**：年干支可精确复现，但它对当年气候与疫病的"预测"属传统经验范畴，现代证据尚不充分，只能当"倾向假设"，须用实际气象物候校正。
- **不谈个人吉凶**：运气看的是"那一年天地之气偏哪一边、人易得哪一类病"，不涉个人祸福；一旦滑向个人命理，整套推演就失去可讨论的基础。
- **不替代诊疗与公卫指引**：凡涉用药、针刺、防疫措施，一律以正规医疗与公共卫生指引为准，本库只作"因时制宜"的辅助维度。

完整的读法约定与三层标记规则，见「README · 导览」的 README_2 与 README_4。

### 0_3 前置知识与关键气节点

前置知识只有两项，但都不可省。第一项是基础阴阳五行生克：要知道木火土金水的相生相克顺序，以及"太过""不及"在五行关系里的直观含义。第二项是二十四节气的名称与先后顺序，因为运气的每一步都锚定在节气上，节气不清，步次就无从谈起。

其中六个节气尤其关键，它们是主运、主气起止的锚点，建议单独背下来：

```text
气节点    节气区间含义              在推演中的作用
大寒      终之气末 → 初之气始       主运初运起、主气初之气起（全年起点）
春分      初之气末 → 二之气始       主气二之气起
小满      二之气末 → 三之气始       主气三之气起
大暑      三之气末 → 四之气始       主气四之气起
秋分      四之气末 → 五之气始       主气五之气起
立冬      五之气末 → 终之气始       主气终之气起
```

这六个节点串起来，正好把一年切成六段，每段约六十天。记住"大寒起、立冬收尾"这一头一尾，中间的春分、小满、大暑、秋分就很容易按顺序挂上去。若这几项不熟，建议先补再进，否则后面每一步都会绊住。

还有一项容易被忽略的前置：分不清"运"与"气"的层次。运是五段（木火土金水各主七十三日有余），气是六段（风热火湿燥寒各主六十日有余），两者步数不同、起点相同。初学时先把这条差异背成一句话，后面做相合判断就不会把五步与六步错配。

### 0_4 自检清单

第1步，能否不看表，由任意年干支直接说出岁运五行与太过不及？这是检验"天干化五运"是否内化的第一关。

第2步，能否由任意年支直接说出司天与在泉？能脱口而出，说明"地支化气"的配对已经牢靠。

第3步，能否默画主运五步、主气六步的起止节气与五行属性？这一步考的是对"常"的气候递变是否成图在胸。

第4步，能否判定一个给定年份是否属于天符、岁会或太乙天符？注意区分天符比的是司天、岁会比的是岁支本身。

第5步，能否用完整流程对某年格局做出"结论加边界"的小结？即既写出趋势提示，也写明"须结合地域与辨证、不可机械套用"。

五项全过，基础即合格，可放心进入应用与古籍环节；任一项卡住，回到对应零件板块重练即可，不必整体回炉。若五项里只卡在第5步，说明规则已会、分寸未立，建议先去板块8 看几个完整应用示例再回来重答。

### 0_5 四周之后：从路径到板块的衔接

四周走完，最容易出现"断档"：任务表结束了，人却停在那里。衔接的办法是把学习切换成"周更闭环"，每周只做一件事，但四件事轮转不停。

```text
排一张盘 ──► 写一段推演理由 ──► 对照实际气候 ──► 记一条偏差 ──┐
   ▲                                                            │
   └──────────────── 下周带着这条偏差重排 ◄──────────────────────┘
```

具体节奏是：第5周起，每周挑一个自己想要的年干支（不必是当下年份，虚拟年份同样有效），排出岁运、司天在泉、主客运与主客气；然后写三到五句推演理由，说明"为何这样判"；接着对照该年真实的气候与物候描述（可查气象记录、可查地方志），找出至少一条与推演不符之处；最后把偏差写进错题本，下周重排时优先修正这一类错误。

> （虚构教学案例，不对应真实人物）阿岚在第五周做"年度卡片"时发现，自己反复把"岁运太过"与"司天之气"混为一谈，导致同一张卡前后矛盾。她把两者写在一张纸的两端，中间画一条竖线：左边只写"全年基调，看天干"，右边只写"上半年主气，看年支"，以后每次下笔前先看这张纸。三个月后她排盘的返工率明显下降，也第一次体会到"错题本比笔记更重要"。

衔接时还要注意板块顺序的两个例外。其一是板块9（大司天与辨疑）不必等全部学完才读，走完板块7 之后就可以先读一遍，提前建立"这套模型有边界"的意识；其二是板块10（笔记法、术语、延伸）应当边学边用，不必留到最后，否则学完再补笔记，等于把最需要记录的体感丢掉了。

最后给出一个可执行的判断：如果你能在不看资料的情况下，用十五分钟排完一张年盘并写出三条带边界的结论，就已经越过入门线，可以按自己感兴趣的方向（临床、文献、教学）分流深读，而不必再照着四周表走。

### 0_6 案例小故事：同一张四周表，两种走法

**背景**：两个人同一年开始学运气，用的是同一份四周计划，每天各四十分钟，都坚持了四周，谁也没缺课。

**经过——第一个人**：他把四周当成背诵任务。第1周背干支，第2周背两句口诀，第3周背天符岁会的判定条件，第4周照着书上的例子抄了两份排盘。四周结束时，他能一口气背出天干地支，也能复述"甲己化土"，但给他一个没见过的年干支，他要从头想很久，且常常在"在泉"这一步停住。

**经过——第二个人**：她每周只多做一件事——把当周的产出写成一句话。第1周写"为什么阳干只能配阳支"，第2周写"岁运为何由五音建运推出"，第3周写"我这次把天符和岁会判混了，错在把司天当成了岁支"，第4周写一份带边界的排盘小结，末尾加一句"本年为倾向提示，须以实际气候校正"。

**转机**：三个月后，两人被问同一道题——给一个年干支，说出岁运、司天在泉，并判断该年易发何类病证。第一个人答得很快，岁运与司天都对，在泉说错了；第二个人慢一些，三项全对，还补了一句"土太过则湿盛，脾困者多，但这是倾向，要看当年实际雨水与个体体质"。差别不在记性，在第一个人手里只有结论，第二个人手里有一条可以复盘的链。

**复盘**：四周计划的四个阶段各有硬产出——能默写干支、能脱口说出岁运与司天在泉、能判相合格局、能走完一次排盘。这些产出的用处不是交作业，而是让错误留下痕迹：写下来的错，下次能改；只在脑子里过的错，下次照错。第一个人并非不努力，他只是把"学过"当成了"学会"。

**落点**：运气的门槛不在记住多少口诀，而在能否把一次推演完整地写出来、再完整地挑出错。板块0 给的是路线，路线本身不产生能力，产生能力的是路线上那几件必须交出来的东西。
