## 板块4 · 六气：主气·客气·司天在泉

六气解决的是"一年六段时令各主什么气候"这一半问题，它由地支开启，分成主气（固定）、客气（随岁支而变）两层，并由"司天、在泉、间气"标出上下左右的位置。本板块要拿下地支化气表、主气六步表，以及司天在泉的排盘位置。读完后你应能拿到任意年支，立刻说出司天在泉，并把一年六步的"常"与"变"画出，为板块5的运气相合提供"气"这一半的零件。

### 4_1 六气与地支对应（司天在泉的根）

六气以"三阴三阳"配六种气化：厥阴风木、少阴君火、少阳相火、太阴湿土、阳明燥金、太阳寒水。按年支定司天、在泉的规则名为"地支化气"，它是整张客气排盘的根——年支直接给出当年"天之气"（司天）与"地之气"（在泉），二者相对而立。拿到年支先定司天，在泉即其"对冲之气"（三阴对三阳），不必另记。

下表一次列清六组年支的司天、在泉与三阴三阳属性：

| 年支（司天） | 司天气 | 在泉气 | 三阴三阳 |
| --- | --- | --- | --- |
| 子、午 | 少阴君火 | 阳明燥金 | 二阴司天，二阳在泉 |
| 丑、未 | 太阴湿土 | 太阳寒水 | 三阴司天，三阳在泉 |
| 寅、申 | 少阳相火 | 厥阴风木 | 一阳司天，一阴在泉 |
| 卯、酉 | 阳明燥金 | 少阴君火 | 二阳司天，二阴在泉 |
| 辰、戌 | 太阳寒水 | 太阴湿土 | 三阳司天，三阴在泉 |
| 巳、亥 | 厥阴风木 | 少阳相火 | 一阴司天，一阳在泉 |

口诀务必记牢：**子午少阴君火天，阳明燥金应在泉；丑未太阴湿土天，太阳寒水在泉边；寅申少阳相火天，厥阴风木应下年；卯酉阳明燥金天，少阴君火在泉联；辰戌太阳寒水天，太阴湿土在泉前；巳亥厥阴风木天，少阳相火在泉牵。** 实操要点：先由年支锁定司天（上半年主气），再用"三阴三阳相对"推出在泉（下半年主气）；传统认为，司天在泉定下后，整年的客气骨架便已成型，后续只需排布其余各步。

### 4_2 主气——一年六步固定序列

主气一年分六步，每步约 60 天 87.5 刻，从大寒起算，按"厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水"的相生次序固定运行，年年如此，不受年支影响。它体现一年正常的气候递变：初之气风气盛、二之气火渐升、三之气火最盛、四之气湿当令、五之气燥当令、终之气寒当令，对应春温、夏热、长夏湿、秋燥、冬寒的常规节奏。

| 气序 | 名称 | 时段（约） | 气候特点 |
| --- | --- | --- | --- |
| 初之气 | 厥阴风木 | 大寒至春分 | 风气偏盛 |
| 二之气 | 少阴君火 | 春分至小满 | 火热渐升 |
| 三之气 | 少阳相火 | 小满至大暑 | 火热最盛 |
| 四之气 | 太阴湿土 | 大暑至秋分 | 湿气当令 |
| 五之气 | 阳明燥金 | 秋分至小雪 | 燥气当令 |
| 终之气 | 太阳寒水 | 小雪至大寒 | 寒气当令 |

记忆主气的方法与主运同构：把六步看成"春→夏→长夏→秋→冬→再回春"的翻版，起点永远锁在大寒后的厥阴风木，顺序与三阴三阳相生一致。主气是"常"的参照轴，4_3的客气、4_4的司天在泉，都要叠加在这条基准线上读"偏了多少、移到哪步"。

### 4_3 客气——随岁支而变

客气的六步同样走"厥阴→少阴→太阴→少阳→阳明→太阳"的三阴三阳相生顺序，但每步的起点随司天而变，因此每年不同，体现气候的"变"。排客气的唯一锚点是：司天之气永远固定在"三之气"（即全年第三步主气的位置），其余五步再按三阴三阳相生顺序，以司天为基准向前倒推、向后顺排环绕一周。传统认为，客气反映当年气候的异常波动，是"因时制宜"里"变"的那一维。

具体排法分三步：第1步，由年支查得司天，把它放在三之气；第2步，三之气之前（二之气、初之气）按相生逆推，三之气之后（四、五、终之气）按相生顺推；第3步，核对终之气应恰好是"在泉"的对侧位置，若不符说明排错。注意一个常见坑：客气顺序与主气顺序的"相生链"相同，差别只在起点被司天平移——所以司天落点一旦错，整年客气全错。

### 4_4 司天、在泉、间气

司天位于"上"，统管上半年（约大寒至大暑），代表当年的天之气，由年支决定；在泉位于"下"，统管下半年（约大暑至大寒），与司天相对，代表地之气。二者一上一下、一前一后，把一年分成上下两半的气化主轴。间气则是围绕司天、在泉的"左右各一"：司天左间、司天右间、在泉左间、在泉右间，共四间气，反映六步中除司天在泉之外的次要气化，填实整张客气盘的边角。

下面用 ASCII 把司天、在泉与四间气的位置关系画成一张排盘示意，便于对照排客气：

```text
                 ┌──────────────┐
                 │   司天（上）   │  ← 年支定，统上半年，固定占三之气
                 │   统上半年     │
       ┌─────────┴──────┬───────┴─────────┐
       │ 司天左间(二气)  │  司天右间(四气) │
       └─────────┬──────┴───────┬─────────┘
                 │              │
                 └──────┬───────┘
                 ┌──────────────┐
                 │   在泉（下）   │  ← 与司天相对，统下半年，占终之气对侧
                 │   统下半年     │
       ┌─────────┴──────┬───────┴─────────┐
       │ 在泉左间(五气)  │  在泉右间(初气) │
       └────────────────┴──────────────────┘

  （六步顺时针：初气→二气→三气[司天]→四气→五气→终气[对应在泉侧]）
```

读这张盘的方法是：先定司天压在三之气，再定在泉在与之相对的终气侧，四间气补齐其余四步。传统认为，司天在泉定出后，该年上下半年的气化主轴便清晰，间气则用于细化各步的偏性。参见板块3可知，运与气两部分各自排完后，要到板块5才正式"相合"成格局。

> （虚构教学案例，不对应真实人物）阿岚第一次排客气时，把"司天在第三步"记成"司天在第一步"，导致整年客气全错。她后来用一句话锚定："司天永远压在三之气（少阳相火那个位置）上，其余五步围绕它轮。"这个锚点写进笔记后，她再没排错过，后来带新人时也直接拿这条当口诀。

### 4_5 案例：一个年支，定三样东西

（规则示例，可逐字核对）取年支为巳的年份。年支一到手，三样东西立刻确定。

司天：巳亥之岁，厥阴风木司天，统摄上半年（初之气至三之气）。
在泉：司天与在泉相对，厥阴司天则在泉为少阳相火，主管下半年（四之气至终之气）。
间气：左右间气按六步顺序排布，司天与在泉之间各有两间，逐年轮转。

三样定完，才轮到客气——客气不是另取一个数字，而是由司天在泉这套框架推出来的。初学最常见的错，是先算客气、后补司天，结果六步全乱。

**落点**：六气推演的顺序是"年支→司天→在泉→间气→客气六步"，不可倒。倒着做，每一步都算得出，合起来却对不上。

### 4_6 本板块自检
第1步，给定任意年支，能否不查表立刻说出司天与在泉，并背出"子午少阴君火天，阳明燥金应在泉"等地支化气口令？

第2步，能否默画主气六步的起止节气与名称，并说明它为何"年年固定、体现常"？

第3步，给定某司天（如卯年阳明燥金），能否排出客气六步，且确认第三步必为司天、终气侧必为在泉？

第4步，能否解释间气"左右各一"分别处在哪几步，以及司天、在泉如何"上下相对"统管半年？

四关全过，再进板块5（运气相合）与板块6（气化失常）。
