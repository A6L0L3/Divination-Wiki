## 板块5 · 运气相合与特殊格局

板块3讲"运"、板块4讲"气"，二者各自独立成体系。本板块把"运"（岁运）与"气"（司天、在泉、岁支所化之气）合到同一年，得到若干被称为"格局"的特殊组合。格局的本质，是判断某一年天地气化"偏在哪一行、聚在哪一层、偏激还是平和"。掌握格局，目的不在贴吉凶标签，而是为后面的推演流程（参见板块7）与临床接口（参见板块8）提供一个"气化强度"的定性坐标。下面先给总表，再讲推演要点与易错点，随后借《玄珠密语》补一层细辨，最后给出可手算的速判流程。

### 5_1 六类格局总表

下表把六类格局的判定条件与气化学意义并列排出。读表时抓住一个核心动作：**先把岁运五行算出来（记为A），再把司天五行、岁支五行、在泉五行分别算出来（记为C、B、D），然后两两比对**。所有格局，都是A与B、C、D之间"是否同五行"以及"阴阳年属性"的组合结果。

| 格局 | 判定条件 | 气化学意义 |
| --- | --- | --- |
| 天符 | 岁运五行（A）与司天之气五行（C）相同 | 天气与岁运上下相合，传统认为气化偏盛、来势较集中 |
| 岁会 | 岁运五行（A）与岁支本身五行（B）相同 | 运气与岁支相合，传统认为气化专一、方向明确 |
| 太乙天符 | 同时是天符又是岁会（A、C、B三者五行皆同） | 传统认为气化最剧，是六十年中需重点留意的节点 |
| 同天符 | 阳年（岁运太过）且岁运五行（A）与在泉之气五行（D）相同 | 运气与在泉相合，偏盛之气借下半年地气再加成 |
| 同岁会 | 阴年（岁运不及）且岁运五行（A）与在泉之气五行（D）相同 | 运气与在泉相合，偏弱之气得下半年地气相扶 |
| 平气 | 岁运太过被司天所克，或岁运不及被司天所助 | 气化趋于平和，传统认为灾病相对较轻 |

六类之中，前五种是"运与气（或运与支）相合而偏"的格局，最后一种是"运被气制约或扶持而回归中和"的格局，性质刚好相反，判定时不能混为一谈。需要强调：天符、岁会、太乙天符、同天符、同岁会都属"同气相聚"，传统认为这类年份气化偏激、疫病与气候异常的发生概率相对更高；而平气属"制化归和"，是六十年里相对安稳的一类。这种"偏激—平和"的二分，正是格局表最该记住的底层逻辑。

### 5_2 推演要点与常见坑

天符与岁会最容易混淆，关键在"比什么"：天符比的是**司天之气**（C，由年支所化的上半年天气），岁会比的是**岁支本身五行**（B，年支自身的五行属性）。同一个"年支"，既能化出司天之气，本身又有五行属性，二者常常不同（例如辰戌之支本气为土，但其司天为太阳寒水），所以天符与岁会是两套独立的判定，初学者常把"岁支等于司天"误用，导致漏判或错判。

太乙天符是天符与岁会的重叠，要求A、C、B三者五行完全相同，六十年中仅出现数次。传统认为这类年份气化最剧，是重点防范节点，但"剧"不必然等于"凶"，它只说明气化集中、波动幅度大，落到人体仍须结合地域与体质来看，不可一见太乙天符就断言大疫。

同天符与同岁会看的是**在泉**（D）而非司天，并且要严格区分阴阳年：阳年（岁运太过）才可能是同天符，阴年（岁运不及）才可能是同岁会。常见坑是忘了这一阴阳门槛，把"岁运与在泉同"直接叫同天符或同岁会，结果太过、不及判反。平气的判定则要看"司天对岁运的作用方向"：太过之年若被司天之克气所制、不及之年若被司天之同气所助，便成平气；它不是一个独立的"同气相聚"格局，而是从太过或不及里"中和"出来的一类，推演时容易把它和前面的格局抢答，其实二者性质相反。

### 5_3 天符岁会的细辨

七篇已列出天符、岁会、同天符、同岁会、太乙天符诸种格局，而早期运气专书《玄珠密语》在七篇之上又做了一层"细辨"：把偏原理性的格局，转译成更贴近"某年某格、易见某气某病"的逐年对照表，方便习医者按年检索、按格备防。

细辨的价值在于"可核"。格局判定部分（岁运与司天、岁支、在泉的五行相合关系）直接来自七篇，属可验证的算法层；而附加的"某格主某灾某病"之类断言，则多为托名附益，属存疑或附会层，读时必须分层甄别，不能连骨带肉一口吞下。

```text
天符岁会格局判定（原理来自七篇，可验）
------------------------------------------------------------
格局      判定条件（五行相合）              示例思路
天符      岁运干 与 司天支 五行同          岁运土、司天湿土
岁会      岁运 与 岁支 五行同              岁运木、年支寅卯
同天符    阳年(太过)岁运 与 在泉 五行同    太过金运、在泉燥金
同岁会    阴年(不及)岁运 与 在泉 五行同    不及水运、在泉寒水
太乙天符  岁运、司天、岁支 三者五行皆同    气专而盛，重点防范
------------------------------------------------------------
细辨加料（须甄别）：
  · 同格之年附加的"主某灾某病"断言 → 多为附会层，存疑存档
  · 格局本身（五行相合判定）        → 属可验层，按年核查
```

因此读《玄珠密语》这一层，正路是"先抽骨、再剔赘"：把格局判定与逐年对照的"骨"留下，把灾异断言的"赘"另置一栏。这样既不丢它的可操作价值，也不被它的直断口吻带偏。懂得这一点，格局才真正成为"气化强度"的标尺，而不是一张"某年必某病"的判决书。

> （虚构教学案例，不对应真实人物）阿岚整理某几个年份的格局时，发现一个"天符"年与传统所说的"燥气偏盛"并不总对得上。她没有急着否定，而是把"格局判定（可验）"与"某格主某病（存疑）"分两栏记：判定一栏照五行相合关系逐年核，断言一栏只标"待验"。师傅看后说："你这一分栏，等于给玄珠的细辨做了一次去芜存菁。"阿岚由此明白，细辨不是加密的预言，而是把原理铺成可逐年查对的表。

### 5_4 格局速判流程

下面给出一套可手算的速判流程。拿到任意年干支，先拆出A（岁运五行）与B、C、D（岁支五行、司天五行、在泉五行），再按顺序逐格过，遇到"是"即标记对应格局，可同时命中多个（如天符加岁会即太乙天符）。

```text
取 年干支
   │
   ├─ 年干 → 岁运五行 (A) + 定 太过/不及（阴阳年）
   └─ 年支 → 岁支五行 (B) ／ 司天五行 (C) ／ 在泉五行 (D)
            │
            ├─ A == C ?  → 是：天符
            ├─ A == B ?  → 是：岁会
            ├─ A==C 且 A==B ? → 是：太乙天符
            ├─ 阳年 且 A==D ? → 是：同天符
            ├─ 阴年 且 A==D ? → 是：同岁会
            └─ 太过被司天克 ／ 不及被司天助 ? → 是：平气
            │
            └─ 以上皆否 → 普通年（非常格之年）
```

这套流程的顺序有讲究：先判天符、岁会，再判二者的叠加（太乙天符），因为它们都基于A与C、B的关系；再判同天符、同岁会，因为要引入"阴阳年"和"在泉"两个新条件；最后判平气，因为它依赖"司天对岁运的制化方向"这一相对隐蔽的关系。按此顺序走，既不易漏，也不会把平气和"同气相聚"类混在一起。需要提醒：普通年（非常格之年）在六十年里占大多数，格局并非每年都有，无特殊格局不等于"无气化倾向"，常规岁运、司天在泉仍照常分析。

### 5_5 案例：戊午是天符，还是岁会

（规则示例，可逐字核对）戊午年，三处同时指向火：戊癸化火，岁运为火，戊为阳干故属火运太过；午为少阴君火司天；午本身在五行属火。

于是三种判定同时成立——岁运与司天同气，是天符；岁运与年支五行同气，是岁会；两者兼具，是太乙天符。同一个年份，答案取决于你拿哪两样在比。

再看丁卯：丁壬化木，岁运为木；卯属木，岁运与年支同气，是岁会；但卯年司天为阳明燥金，与木运不同气，故不是天符。两字之差，格局完全不同。

**落点**：天符比的是"岁运与司天"，岁会比的是"岁运与年支"，太乙天符是二者叠加。判定之前先问"我在比哪两样"，比记十二个年份的名单可靠得多。
