# 板块1 · 理论根基与经典源流

初学者最容易在运气门口犯迷糊：它到底是不是算命？它和天文历法、和命理八字是什么关系？它的理论底气又从哪来？本板块先回答"五运六气是什么、不是什么"，再交代它的宇宙论前提与历史来路，最后把七篇大论的内在逻辑串成一条链。读通这一块，后面学推演才不会把结论用错地方。

## 1_1 一句话界定：时间医学，不是算命

五运六气不是"算命"，而是以干支为推演工具，研究"天体运动—气候变化—物候表现—人体疾病"之间关联链条的传统医学理论。它的方法论可浓缩为一句话：把时间（年、节、气）翻译成气化属性，再把气化属性读成健康与养生的提示。

要紧的是"翻译"二字。运气并不直接断言某个人必定生什么病，而是先把某年的干支转换为一套"运"与"气"的符号，再据这套符号推断当年的气候偏性与发病趋势。所以严格说，它是"时间医学"与"气象医学"的古人版本，定位为传统医学的参考模型，而非预测个人命运的术数。

## 1_2 三个核心概念：五运、六气、六十甲子

理解运气，先抓住三个层次：五运、六气、六十年周期。三者由粗到细、由静到动，共同构成推演的完整骨架。

五运，指木、火、土、金、水五类气化，由天干决定，主管一年之中气化的"常"与"变"，内部再分岁运（全年基调）、主运（一年五步固定序列）、客运（随岁运而迁的五步变化）三层。六气，指厥阴风木、少阴君火、少阳相火、太阴湿土、阳明燥金、太阳寒水六类气化，由地支决定，推演一年六段时令的气候特征，内含主气、客气、司天、在泉。周期，则是五运与六气相合后形成的六十年甲子循环，把单年格局装进一个可回看、可对照的总框架。

| 层面 | 内容 | 说明 |
| --- | --- | --- |
| 五运 | 木、火、土、金、水 | 由天干决定，含岁运、主运、客运三层 |
| 六气 | 风、君火、相火、湿、燥、寒 | 由地支决定，含主气、客气、司天、在泉 |
| 周期 | 六十年甲子 | 运与气相合，成六十年循环的总格局 |

记忆窍门：天干管"运"、地支管"气"，运讲一年之内五行的递变，气讲一年之内六段时令的特征，两者叠加才能读出某年相对完整的天时画像。

## 1_3 学科交叉坐标与相邻边界

五运六气处在"医、术数、天文历法"三者的交叉地带，但它的本位在医——落脚点是气候、物候、发病、养生与用药，而不是命理吉凶或一事一占。认清这个坐标，学的时候才不跑偏。

```text
        天文历法（干支、节气、交节时刻）
                  │
                  ▼
        术数框架（阴阳五行、三阴三阳、生克）
                  │
                  ▼
        医学本位（气候—物候—发病—养生—用药）
```

天文历法提供"算具"：干支纪年、二十四节气、交节时刻，是推演的时间底座。术数框架提供"语法"：阴阳五行、三阴三阳、相生相克，是把时间转成气化的规则系统。医学本位才是这套符号的"归宿"——所有推算最终都要回答"人该怎么防、怎么养、怎么治"。

与相邻领域的边界必须主动划清。与命理术数（如八字、铁板神数）相比，双方都用天干地支作运算符号，但运气只推年度与时令的天时气化，不排个人命局、不论富贵穷通；拿运气的岁运去断人财运，是越界误用。与伤寒、温病学说相比，运气提供"因时"的维度，伤寒温病提供"辨证"的维度，二者是天时与病机的配合，而非替代，临床须以辨证论治为主、运气为辅。与现代气象学相比，运气是古人在无仪器条件下对气候节律的符号化归纳，现代气象靠实测数据与物理模型，二者可对照互参，但不可等同。与天文历法本身相比，干支、节气是运气借来的时间尺，运气在尺上又叠加了五行气化的解释层，已超出纯历法范畴。

> （虚构教学案例，不对应真实人物）一位爱好者初学时把运气和八字命理混为一谈，拿着自己的八字追问"我哪年走土运、会不会发财"。阿岚用上面的坐标图告诉他：运气看的是"那年天地之气偏哪边、人易得什么病"，不判个人财运；若把运气当命理，就跨出了它的本位，结论也不可靠。

## 1_4 宇宙论根基：太始天元册的气本体论

运气为什么能用五运阴阳去统摄气候？这个问题在七篇之前的更古老文献里已有答案。《太始天元册》是一部早佚的古天文之书，今仅存零星引文，最著名的一段是"太虚寥廓，肇基化元，万物资始，五运终天，布气真灵，总统坤元，九星悬朗，七曜周旋，曰阴曰阳，曰柔曰刚，幽显既位，寒暑弛张，生生化化，品物咸章"。它正是运气学追溯自身宇宙论源头时必提的"失传经典"。

据现存引文推究，此书主张一条宇宙生成链：太虚之气化育本元，本元分作五运阴阳，五运阴阳再化生万物，其中便包括岁气与人形。这条链等于宣布"气"是唯一本体，形质、动静、寒暑皆是其显化。读懂这一层，才明白运气不是外在地"给气候贴标签"，而是内在地认为气候本就是气化之流。

```text
〔现存引文〕                          〔复原框架〕
"太虚寥廓，肇基化元"          →   [太虚]  本体论起点（本始之气）
"万物资始，五运终天"          →   [化元]  化育本元 → [五运阴阳] 天地之道
"应天之气，动而不息"          →   [五运·动]  岁运右迁
"应地之气，静而守位"          →   [六气·静]  六期环会
                                      ↓
                            [岁气·万物（含人形）]  气化所生
```

浓缩成一句：太虚（本始之气）→ 化元（化育本元）→ 五运阴阳（天地之道）→ 岁气·万物（含人形）。七篇借这部书的口吻说"五运阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始"，把五运阴阳抬到"道"的高度——它不只是推算工具，而是宇宙运行的根本节律。运气七篇之所以敢以干支推演全年气化，底气正来自这种"五运阴阳即天道"的本体论自信。

读这部佚书有一条铁律：严格区分"引文"与"推断"，绝不把推断当原典。原典只说得出百余字，便只认百余字；多出来的体系，必须老老实实标"推"。这既是读佚书的纪律，也是运气学"尊重来源、克制发挥"的品格。

## 1_5 从七篇到现代：历史源流

一套理论，只有知道它从哪来、被谁确立、如何被使用与质疑，才能真正读懂它的分量与边界。

运气学说的理论根脉，是《黄帝内经·素问》中被称为"运气七篇大论"的七篇文章：《天元纪大论》《五运行大论》《六微旨大论》《气交变大论》《五常政大论》《六元正纪大论》《至真要大论》。这七篇系统论述了天干化运、地支化气、主客运气、胜复郁发等核心规则，是后世一切运气著作的总源头。它们在《素问》中自成一套严密的符号体系，篇幅大半由推演规则与格局判定构成，后世研究普遍认为可能并非与其余篇章同期成书，而是被整合进来的专门内容。学习者须明白：七篇才是"原著"，后人著作都是对它的翻译与发挥。

唐代王冰整理《素问》时，将运气七篇补入正文，并附上《刺法论》《本病论》两篇遗篇，后者专论疫疠与运气的关系。后世普遍把这一事件视为运气学说正式确立的标志——在此之前，运气内容零散依附；在此之后，它有了明确的经典归属与文本载体。遗篇在宋代才广泛流传，真伪历代有争议，但内容确与运气、疫病密切相关，不可因"疑伪"而轻弃其学术价值。

北宋时期，运气完成了从"一家之说"到"国家考试与官方医典组成部分"的跃迁：太医局把运气列为考试科目，官修《圣济总录》把六十年运气图置于全书首卷并附运气方药，使运气格局第一次拥有了"国家版本"的权威图谱。进入金元明清，运气从"推演框架"进一步走向"病机解释工具"：刘完素以"亢害承制"阐发火热病机，主张"六气皆从火化"，开温病学派一源；明代汪机《运气易览》把纷乱的干支化运、司天在泉整理得条理分明，成为最常用的入门读本；王肯堂《医学穷源集》以"大司天"理论注解医案；明清医家又对"是否该机械套用"持续争鸣，出现《运气商》《运气辩》一类纠偏之作。这一阶段的主旋律是"既应用、又反省"，而非一边倒的信仰。

近几十年，运气被重新作为时间医学、气象医学与疫病预测模型加以研究：研究者把六十年周期与历年气候、流行病学数据对照，回测流感、呼吸道与消化道传染病的高发年份。但学界对推演刻板化的弊端多有反思，统计学验证结果也不一，现代研究的共识倾向是——把运气当作"可检验的传统参考模型"而非"可盲信的定律"。

```text
先秦两汉   运气七篇大论（理论根，藏在《素问》中）
     │
唐代       王冰补注 + 遗篇（文本确立）
     │
北宋       太医局设科 + 圣济总录首卷运气图（制度化）
     │
金元明清   刘完素阐发病机 / 汪机整理入门 / 王肯堂医案 / 诸家争鸣
     │
现代       时间医学 · 气象医学 · 疫病建模（回测与反思）
```

## 1_6 七篇大论的总纲与内在逻辑链

七篇并非七本互不相关的独立著作，而是一套分工明确、首尾相贯的"总论—零件—五运—六气—纪年—治则"体系。

《天元纪大论》是总纲，提出"天以六为节、地以五为制，五六相合而成岁"的根本框架，回答"运"与"气"为何能配成一套年际模型，并首次点出"太过、不及"之纪。《五运行大论》用"五气经天"解释五行之气如何运行于天，明确太过不及由天干阴阳决定，并首次引入"客运"，使模型具备"常中有变"的层次。《六微旨大论》定义六气及其标本中气关系，提出"升降出入"与"气交"，指出人与万物居处其中，"气交之分，人气从之"，这是岁气作用于人体的理论枢纽。《气交变大论》逐运讲解五运太过、不及之年的气候偏差与"灾眚"方位，用"德、化、政、令、灾、变"描述每运的正常与失常，把抽象"运"转成可观察的气候异常。《五常政大论》把每运分为平气、太过、不及三类常态（"三纪"），并补充"地域高下"对运气表现的影响，提醒模型须与地理结合。《六元正纪大论》以六气为"六元"，给出六十年每一年的司天在泉、左右间气、客主加临及宜忌，是七篇中最像"检索手册"的一篇。《至真要大论》提炼"病机十九条"，讲司天在泉淫胜时的治法，是从推演落到"该怎么治"的桥梁。

```text
天元纪（总纲：五六相合）
     │
     ├── 五运行（五运零件 · 客运）
     └── 六微旨（六气零件 · 气交升降）
               │
     ┌─────────┴─────────┐
  气交变（五运太过不及）  五常政（三纪 · 地域修正）
     └─────────┬─────────┘
               ▼
     六元正纪（六十年逐年总表）
               │
               ▼
     至真要（病机十九条 · 治则方药）
```

这条链的逻辑是层层递进的：总纲立"五六相合"，五运行与六微旨分别备齐"五运零件"与"六气零件"，气交变与五常政专论五运的常变与地域修正，六元正纪把零件组装成六十年逐年总表，至真要则把逐年气候偏性翻译成病机与方药的临床语言，形成"框架→零件→五运→纪年→治则"的闭环。明了这条线索，就不会把七篇读成七堆散材，而能把它当作一部有开头、有中段、有落点的"运气学总论"来用。

## 1_7 源流与方法论启示

启示一：先读七篇原文，再读后人整理。后人如汪机、王肯堂是"翻译者"，七篇才是"原著"。顺序若反，容易把后人的取舍与发挥误认为原典本意，基础会虚。建议以七篇为根，以《运气易览》为过门槛的阶梯，再逐步扩展。

启示二：重视"争鸣"而非只信"定论"。运气历来有"该不该套用"的争论，从明清诸家到现代学界都在泼冷水。学习者应带着"参考模型"的眼光入门，而非"铁律"的眼光——既能用它的框架观察天时，也始终记得它的边界。

启示三：知其哲学前提，方能用得不虚。七篇的"算法"背后是《太始天元册》的"气本体论"：正因为天地万物同出一气，气候才可被五运阴阳统摄。懂得这一层，运气就不是一堆口诀，而是一套"以气观天、以时观人"的世界观；同时也更该克制——世界观不等于预测公式。

> （虚构教学案例，不对应真实人物）阿岚在读到"北宋把运气列为考试科目"时，联想到今天中医执业考试也考运气基础。她由此明白：运气并非玄虚，而是古人医者必须掌握的公共知识框架，正如今天医生要懂流行病学基础。这个类比帮她把"古代考试"与"现代执业"打通，学习动力明显增强；她也在笔记里补了一句"知其源、守其界"，提醒自己别把公共框架用成个人预言。
