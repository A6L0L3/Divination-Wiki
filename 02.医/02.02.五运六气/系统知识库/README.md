# 五运六气系统知识库 · 总纲

> **一句话定位**：一套可手算、可复盘、可自检的运气整理稿——先立地基，再备零件，随后装配成一次完整的年度推演，最后落到应用、古籍、方法与边界。

五运六气（简称运气学说）是中医学里建立在"天人相应"思想之上，以阴阳五行、干支纪年为框架，推演天时气化运行规律，进而讨论气候、物候、疫病与养生诊疗的一门"时间医学、气象医学"。本知识库把散落在经典、注家与临床医案里的运气内容，重新拆成一条可执行的认知路线：先立地基，再备零件，随后装配成一次完整的年度推演，最后落到应用、古籍、方法与边界。

本 README 只做四件事：说明这套库是什么、约定怎么读、给出板块索引、划清使用边界。真正的入门次序、每周任务与自检题，都在紧接其后的板块0 里展开；推演规则与理论则从板块1 起逐块铺开。

## README · 导览

### README_1 这是什么库

这不是一部古籍译注，也不是一本运气临床手册，而是一套"可手算、可复盘、可自检"的整理稿。它的组织逻辑是把运气拆成三种颗粒度：最小的颗粒是干支与口诀（板块2），中间颗粒是五运、六气与相合格局（板块3 至板块5），最大的颗粒是一次完整的年度推演（板块7）。三者串起来之后，才谈得上养生、脉诊、方药与逐年病源（板块8），也才谈得上去读古籍里的运气专论（相关内容已融合进各主题板块）。

因此全库不设"古籍导读"专章。太始天元册的宇宙论、七篇大论的总纲、玄珠密语的脉应气、运气易览的图表法、圣济总录的运气方、医学穷源集的逐年病源与大司天、运气商与运气辩的辨疑，都按内容性质分派到对应主题里，避免读完一堆"某书讲什么"却仍不会推一年。

### README_2 三层区分与阅读约定

读运气第一件事，是把三类内容分开放，否则极易把"能算的"和"传统说的"混为一谈。本库统一用三层标记：

- **规则层**：干支、五运、六气的推算规则与表格，可逐字手算复核，属可验证的操作性内容。
- **传统主张层**：吉凶、病候、格局含义等，属该体系的经典与传统说法，文中以"传统认为、原文所述"标示，不包装成已验证结论。
- **编辑推断层**：学习路径、练习节奏、教学案例、结构编排等，为整理者的建议，可讨论、可修改。

阅读约定统一如下：全书一级标题只有书名一行；导览独立成篇、不占板块编号，其小节写作 README_1、README_2 依次递增；正文共十一个板块，从板块0 排到板块10，板块标题写作"## 板块N · 主题"，板块内单元写作"### N_Y 名称"，Y 从1 递增，单元内小节写作"#### N_Y_Z"，Z 从1 递增；分步骤统一用"第1步、第2步"或「1」「2」，不使用带圈数字；图表统一用 ASCII 代码块呈现，便于纯文本环境阅读与二次修改；凡涉具体时间，一律用"某年、近几十年"等模糊表述，不落确定年份。凡标"（虚构教学案例，不对应真实人物）"的故事，都只用于演示读法，不作任何诊疗依据。

### README_4 用法与边界

主干阅读建议按板块顺序推进，板块0 与板块10 首尾呼应：前者给进度表，后者给工具箱。板块9、板块10 属贯穿性模块，宜在走完应用之后回看，用来校准态度与方法。各板块自成单元，串联需要时回看上面的索引即可。

必须反复申明边界：运气的推演规则可精确复现，但它对具体年份气候与疫病的预测效力属传统经验范畴，现代证据尚不充分。本库所有"某气主某病、某年易病某脏"等表述，均为传统主张或教学示例，仅供学习研究，不构成任何诊疗、预防或健康建议；实际应用请遵正规医疗与公共卫生指引，并把运气仅作为"因时制宜"的辅助维度。

另需注意版本关系：本库是把早先的完整版与十篇古籍读书笔记融合压缩后的成果，古籍的独有理论与方法已并入相应主题，不再单独成篇；若需追溯某条说法的原始出处，仍应回到对应的古籍文本核对，本库只提供整理后的读法与用法。
