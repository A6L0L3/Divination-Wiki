## 板块7 · 运气推演流程与图表工具

板块2到板块6分别给了工具、五运、六气、格局、胜复郁发这些"零件"。本板块是装配车间：先把零件串成一次完整的"某年运气格局推演"，再补上一套"把算法画成图表"的工具法（以明代汪机《运气易览》的图表化、逐年甲子表、客主加临填图为代表），让推演既能手算复核，也能照图查检。学会这一套，你拿任意年干支都能独立走一遍，得到一份"趋势提示"而非"预测结论"。务必记住：运气推演是传统医学的参考模型，下文所有"趋势判断"都只作学习演示，不构成对任一年份气候或疫病的预测。

### 7_1 八步推演 SOP

第1步，取年干支。确定你要推演的年份对应的干支，例如"癸卯"。这是全部推演的起点，后续每一步都从这两个字拆出。

第2步，推岁运。用天干化五运规则（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火）定出岁运五行，再看天干阴阳定太过不及：阳干为太过，阴干为不及。癸属阴干、戊癸化火，故岁运为"火不及"。

第3步，定司天在泉。用年支查地支化气表：子午少阴君火、丑未太阴湿土、寅申少阳相火、卯酉阳明燥金、辰戌太阳寒水、巳亥厥阴风木。年支决定司天（上半年主气，固定在客气三之气），其对冲之气即为在泉（下半年主气）。卯年司天为阳明燥金，在泉为少阴君火。

第4步，排主运。主运一年五步固定不变，从大寒起按木→火→土→金→水相生顺序：初运木、二运火、三运土、四运金、终运水。年年如此，体现"常"。

第5步，排客运。客运初运与岁运相同，之后按五行相生顺排。岁运为火，则客运为：初运火、二运土、三运金、四运水、终运木。它体现当年在"常"之上的异常增减，即"变"。

第6步，排主气与客气并做客主加临。主气六步固定：厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水。客气以司天固定在三之气，按三阴三阳顺序环绕排布其余五步；再把客气六步叠到主气六步之上，逐气比较"客胜主"或"主胜客"，即为客主加临，用于判断该步气候偏向。

第7步，判格局。把岁运五行（A）与司天（C）、岁支（B）、在泉（D）比对，依板块5的速判流程判定天符、岁会、太乙天符、同天符、同岁会或平气；若皆否则为普通年。同时看有无明显的胜、复、郁、发之势（参见板块6）。

第8步，出趋势判断。综合以上岁运太过不及、司天在泉、客主加临、格局与胜复郁发，写出"该年气化偏在哪、需留意哪类病证"的趋势提示。这一步必须标注"参考模型、须结合辨证与地域"，不得写成确定性断言。

### 7_2 推演链总图

下面用字符图把从"年干支"到"临床应用"的完整链路画出来，帮助建立整体记忆。图里"运"这一支和"气"这一支在顶端分叉，到"运气相合"处汇合，再经胜复郁发进入应用。

```text
            年干支
          ╱        ╲
     天干              地支
       │                 │
       ▼                 ▼
    岁运              司天 / 在泉
  (五行 +            (客气之根)
   太过不及)              │
       │                 │
       ├─→ 主运五步       ├─→ 主气六步
       └─→ 客运五步       └─→ 客气六步
              │                 │
              └────────┬────────┘
                       ▼
              客主加临 + 运气相合 → 格局判定
                       │
                       ▼
                胜复郁发（动态机制）
                       │
                       ▼
          趋势判断（参考模型，非预测）
                       │
                       ▼
        临床应用：养生 / 辨证 / 疫病 / 方药
```

这张图的读法：先分叉（运与气各算各的），再汇合（客主加临与格局判定），最后经动态机制落到应用。任何一步漏算，下游都会错，所以推演时建议严格按顺序走，不要跳步。

### 7_3 完整虚构推演案例（可复盘）

以下案例以"癸卯"年为例进行完整推演演示。案例主角为虚构人物阿岚（青年中医），全部内容属虚构教学案例，不对应真实人物，也不构成对任一年份的气候或疫病预测。

第1步，取年干支：癸卯。

第2步，推岁运：癸化火，癸为阴干，故岁运为"火不及"。

第3步，定司天在泉：卯年，司天为阳明燥金，在泉为少阴君火。

第4步，排主运：初运木（大寒起）→二运火→三运土→四运金→终运水。

第5步，排客运：岁运为火，故初运火→二运土→三运金→四运水→终运木。

第6步，排主气与客气并客主加临：
主气六步：初厥阴风木、二少阴君火、三少阳相火、四太阴湿土、五阳明燥金、终太阳寒水。
客气六步（司天阳明燥金固定在三之气，按三阴三阳顺序环绕）：初少阳相火、二太阴湿土、三阳明燥金（司天）、四太阳寒水、五厥阴风木、终少阴君火（在泉）。
客主加临要点：三之气客气阳明燥金加临主气少阳相火，金克火，传统认为该步燥气偏胜、暑热受抑；终之气客气少阴君火加临主气太阳寒水，火加水，传统认为该步寒中带温、暖冬倾向。

第7步，判格局：岁运火（不及），司天阳明燥金（金）——A≠C，非天符；岁支卯本气为木——A≠B，非岁会；在泉少阴君火（火）——A==D，且岁运为阴年（不及），故判定为"同岁会"。无平气（火不及，司天为金，既非同气所助、亦非被克成制化，按规则不归平气）。无显著太过的胜气，但火不及之年传统认为"所胜（金）乘之、所不胜（水）侮之"的趋势存在，可留意后期是否有相应复、郁结构。

第8步，趋势判断（参考模型，不构成预测）：癸卯为火不及之同岁会年，上半年燥金司天偏显、下半年君火在泉相扶岁运。传统认为此类年份需留意火气不足相关的心系、阳气布散不及，以及燥气偏胜伤津之象；同时同岁会使偏弱之火得在泉相扶，整体不至于过衰。此判断仅为学习演示的趋势提示，具体到个体仍须辨证论治，且须结合当年地域实测气候，不可见"同岁会"即断言某病必发。

> （案例小结，阿岚口吻）癸卯推下来，我记三句话——"岁运火不及、上半年燥金当令、下半年君火在泉扶火"。但这是参考模型下的趋势提示，不是预测；落到人身上仍要四诊合参。我已把这张推演表作为教学存档，并标注"虚构教学案例，不对应真实人物，趋势判断不构成预测"，待日后复盘真伪。

### 7_4 图表化工具：逐年甲子表与客主加临填图

七篇古奥、术语密集，多数人初学运气其实都经由"图表化"的梯子上去。明代汪机《运气易览》的功劳正在此：它几乎不发明新理论，而把七篇里散落的算式重组成可查、可填、可练的图与表，并辅以编者按语校正偏差。其编排是"图—表—按"三段式：先列运气诸图定框架，再附甲子逐年表供查检，最后以按语贯穿始终点出活看之处。

逐年甲子表，是把六十年每一年的岁运、司天在泉、主客等项预先排好的"运气年历"。它既是查询工具，也是检验工具：你自己推完某年格局，翻到对应干支那一栏一核，便知哪一步出错。

```text
取年干支
   │
   ├─ 查岁运（天干化运 · 太过/不及）
   ├─ 查司天在泉（地支化气）
   ├─ 查客主加临（填入六步图）
   └─ 得本年气候倾向（常 + 变）
```

客主加临填图，是《运气易览》反复演练的核心工夫：主气年年固定、显"常"；客气随岁支而变、显"变"，二者叠加才构成某年实际的气候倾向。能否填对这张图，是检验是否读懂"运与气相合"的试金石。

```text
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
(客气由司天在泉推：司天定三气，在泉定终气，余顺推)
标注： 主客同气 = 相得；主客异气 = 相争（易偏）；
       相争处宜回看汪机"愚按"的活看提醒
```

汪机的"愚按"是全书最珍贵的部分，多处提醒"大率如此，不可执一"。这是早期对"机械运气论"的自觉纠偏——他承认格局有常，却也强调地域、时差、人体差异会让同一年甲子呈现不同结果。读这套图表，最该带走的是"信而不迷"：图能帮你查，但查到的不是铁律，而是参考模型。

> （虚构教学案例，不对应真实人物）阿岚刚接触五运六气，被"客主加临"六个步骤绕得头晕，背了三天仍分不清司天定的是哪一气、在泉又管哪一步。老师没有让她继续死记，而是翻开《运气易览》那张客主加临图说："你别背，照图来。先把今年的年支告诉我。"她报出年支，依"地支化气"一栏查得司天在泉：司天定三之气，在泉定终之气，其余按三阴三阳顺序顺推。她把六步客气逐一填进图里，再与主气一行对照，发现上半年君火司天与主气相争，那一格明显"打架"。她正要惊慌，老师指了指图旁"愚按"——"大率如此，不可执一"，冲突年份正该活看，不能见相争就断为灾。阿岚忽然松了口气："这书像给七篇配了张地图，我以前直接往地形里钻，所以迷路。"

### 7_5 歌诀与查表法

《运气易览》把天干化运、地支司天、主气次序等都编成便于记诵的歌诀，这些歌诀本质上是推演图的"压缩版"。用它们巩固记忆，有一个"背诀、填图、查表"三步加固法，比孤立硬背条文高效得多。

```text
天干化五运（岁运）：
  甲己 -> 土   乙庚 -> 金   丙辛 -> 水
  丁壬 -> 木   戊癸 -> 火
  阳干(甲丙戊庚壬)为太过，阴干(乙丁己辛癸)为不及

地支司天（简括）：
  子午 -> 少阴君火司天，阳明燥金在泉
  丑未 -> 太阴湿土司天，太阳寒水在泉
  寅申 -> 少阳相火司天，厥阴风木在泉
  卯酉 -> 阳明燥金司天，少阴君火在泉
  辰戌 -> 太阳寒水司天，太阴湿土在泉
  巳亥 -> 厥阴风木司天，少阳相火在泉
```

第1步先背诀：把"甲己化土乙庚金"这类句子念熟，让口诀成为条件反射。第2步再填图：合上卡片，在空白的运气图里凭记忆把对应内容填回去，填不出的就是没背牢处。第3步后查表：回到甲子表核验，确认自己填的与表一致。这三步层层互相加固，记诵效率明显高于硬背。卡片可按"天干卷""地支卷""主气卷"分袋收纳，每月抽测一袋，长期下来基本能做到看到任意干支便脱口报出岁运与司天。

### 7_6 实用验证与自测

学了要验，验了要测。推演的正确性，不靠感想，靠能不能独立推对、再与权威表核对。下面给出两张可直接使用的自测模板。

```text
【客主加临 自测】
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
操作：
  第1步 取年支 -> 查司天(定三气)、在泉(定终气)
  第2步 余四步按 厥阴->少阴->太阴->少阳->阳明->太阳 顺推填入
  第3步 填完核对甲子表，不一致则回查"地支->司天"一步
```

```text
【五运速查 自测】
取年干 -> 依"甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火"定岁运
       -> 依阳干太过、阴干不及判盛衰
       -> 与甲子表该年岁运栏对照
例：年干为"丙"，丙辛化水，丙为阳干 -> 水运太过，核对表栏是否一致。
```

自测判分不在"答得准不准运"，而在"链路完不完整、断得克不克制"。凡能独立走完八步、填对客主加临图、并主动标注"参考模型"者方算读通；凡一见干支便只报岁运、略去主客气者，须回头重练第4至第6步。

### 7_7 本板块自检

第1步，能否不看提示，对任意给定年干支（如"壬寅""戊午"）独立完成八步推演并写出结论？

第2步，能否默画出 7_2 的推演链总图，并讲清"运""气"两支在何处汇合？

第3步，能否像 7_3 那样，写出一份带"结论加边界声明"的推演小结，明确标注趋势判断属参考模型、不构成预测？

第4步，能否在推演中同时完成"客主加临"的比对，而不只停留在岁运与司天在泉？

第5步，能否用"背诀、填图、查表"三步法，把任意一旬的干支与对应岁运、司天在泉默填一遍？
