# README · 五运六气系统知识库

五运六气（简称运气学说）是中医学里建立在"天人相应"思想之上，以阴阳五行、干支纪年为框架，推演天时气化运行规律，进而讨论气候、物候、疫病与养生诊疗的一门"时间医学、气象医学"。本知识库把散落在经典、注家与临床医案里的运气内容，重新拆成一条可执行的认知路线：先立地基，再备零件，随后装配成一次完整的年度推演，最后落到应用、古籍、方法与边界。

本 README 只做四件事：说明这套库是什么、约定怎么读、给出板块索引、划清使用边界。真正的入门次序、每周任务与自检题，都在紧接其后的板块0 里展开；推演规则与理论则从板块1 起逐块铺开。

## 这是什么库

这不是一部古籍译注，也不是一本运气临床手册，而是一套"可手算、可复盘、可自检"的整理稿。它的组织逻辑是把运气拆成三种颗粒度：最小的颗粒是干支与口诀（板块2），中间颗粒是五运、六气与相合格局（板块3 至板块5），最大的颗粒是一次完整的年度推演（板块7）。三者串起来之后，才谈得上养生、脉诊、方药与逐年病源（板块8），也才谈得上去读古籍里的运气专论（相关内容已融合进各主题板块）。

因此全库不设"古籍导读"专章。太始天元册的宇宙论、七篇大论的总纲、玄珠密语的脉应气、运气易览的图表法、圣济总录的运气方、医学穷源集的逐年病源与大司天、运气商与运气辩的辨疑，都按内容性质分派到对应主题里，避免读完一堆"某书讲什么"却仍不会推一年。

## 三层区分与阅读约定

读运气第一件事，是把三类内容分开放，否则极易把"能算的"和"传统说的"混为一谈。本库统一用三层标记：

- **规则层**：干支、五运、六气的推算规则与表格，可逐字手算复核，属可验证的操作性内容。
- **传统主张层**：吉凶、病候、格局含义等，属该体系的经典与传统说法，文中以"传统认为、原文所述"标示，不包装成已验证结论。
- **编辑推断层**：学习路径、练习节奏、教学案例、结构编排等，为整理者的建议，可讨论、可修改。

阅读约定统一如下：README 独立成篇，不占板块编号，其小节不编号；正文共十一个板块，从板块0 排到板块10，一级标题写作"板块N · 主题"，板块内二级小节写作"N_Y 名称"，Y 从1 递增；分步骤统一用"第1步、第2步"或「1」「2」，不使用带圈数字；图表统一用 ASCII 代码块呈现，便于纯文本环境阅读与二次修改；凡涉具体时间，一律用"某年、近几十年"等模糊表述，不落确定年份。凡标"（虚构教学案例，不对应真实人物）"的故事，都只用于演示读法，不作任何诊疗依据。

## 用法与边界

主干阅读建议按板块顺序推进，板块0 与板块10 首尾呼应：前者给进度表，后者给工具箱。板块9、板块10 属贯穿性模块，宜在走完应用之后回看，用来校准态度与方法。各板块自成单元，串联需要时回看上面的索引即可。

必须反复申明边界：运气的推演规则可精确复现，但它对具体年份气候与疫病的预测效力属传统经验范畴，现代证据尚不充分。本库所有"某气主某病、某年易病某脏"等表述，均为传统主张或教学示例，仅供学习研究，不构成任何诊疗、预防或健康建议；实际应用请遵正规医疗与公共卫生指引，并把运气仅作为"因时制宜"的辅助维度。

另需注意版本关系：本库是把早先的完整版与十篇古籍读书笔记融合压缩后的成果，古籍的独有理论与方法已并入相应主题，不再单独成篇；若需追溯某条说法的原始出处，仍应回到对应的古籍文本核对，本库只提供整理后的读法与用法。

# 板块0 · 学习路径与入门次序

初学运气最常见的失败不是"看不懂"，而是"看懂了却串不起来"：概念一个个都认识，给一个年干支却排不出盘；表背得挺熟，遇到"某年为何多雨多病"仍说不出所以然。这块板块专门解决次序问题，先给一张全局路线图，再给一份可落地的四周任务表，然后点明最容易走错的几个岔口，最后用一份自检清单告诉你"什么程度算过关"。它不讲任何推算细节，细节从板块1 开始。

## 0_1 学习路径总览

运气的学习不是"读完就会算"的直线，而是"打底、备零件、装配、应用沉淀"的循环推进。把整套知识想成盖房子：先确认图纸与地基（学科定位、历史源流、干支工具），再逐块烧砖（五运、六气、运气相合、胜复郁发），然后把砖拼成一面完整的墙（某年运气格局推演），最后才谈得住进去、用起来（养生、辨证、疫病、方药）。

```text
打底（定位 / 源流 / 干支）
        │
        ▼
备零件（五运 / 六气 / 相合 / 胜复郁发）
        │
        ▼
装配（某年格局完整推演）
        │
        ▼
应用沉淀（养生 / 辨证 / 疫病 / 方药 / 古籍 / 现代 / 笔记）
        │
        └──────► 复盘纠偏，回到上一层补漏
```

四个阶段各有明确产出，缺一环就会在后面卡住：

```text
阶段        对应板块            该阶段的硬产出
打底        板块1、板块2        能默写干支并讲清运气为何属"医"
备零件      板块3 至板块6       每块一张能自己画出来的表
装配        板块7              一份可复盘的某年排盘记录
应用沉淀    板块8 至板块10      一份病案对照笔记与一页术语速查
```

第1阶段立地基，产出是能默写天干地支、讲清运气为何落在"医"而非"命"。第2阶段备零件，每块都对应一两张彼此咬合的表，重点不是背表，而是理解"表从哪来、喂给谁"。第3阶段装配，把零件串成一次完整推演，缺了它，前面背得再熟也只是散装知识。第4阶段应用沉淀，把结论接回临床与文献，并持续用复盘修正理解。

需要提醒的是，这四个阶段并不是一次走完就结束。真正熟练的人常在"装配"与"应用"之间来回：排一次盘、对一次实际气候、发现偏差、回到零件层补漏，再重新装配。路线图右侧那条回到上层的箭头，就是这个意思。

## 0_2 新手入门顺序（四周版）

下面是一份可落地的四周节奏，每天约四十分钟，重在"建立手感"而非速成。已有阴阳五行与节气基础者，可压缩为两到三周；零基础则不建议跳周，因为跳过任何一周都会在第三周的相合判断上暴露出来。

第1周：通读学科定位与历史源流，并把十天干、十二地支、阴阳属性背熟。产出是能不看资料默写天干地支顺序，并讲清"阳干配阳支、阴干配阴支"的配对逻辑。这一周不碰排盘，只解决"这是什么东西、凭什么能算"。

第2周：拿下岁运（天干化五运口诀）与司天在泉（地支化气口诀）。产出是给定任意年干支，能立刻说出岁运五行与太过不及，以及司天、在泉各是什么气。这是全库性价比最高的一周，两张口诀覆盖了年度推演一半的信息量。

第3周：学习运气相合的特殊格局与胜复郁发的动态机制。产出是能判定天符、岁会、太乙天符，并说清"胜、复"自我纠偏为何能解释某些突发疫病。本周开始出现"多个条件叠加"的判断，是最容易混淆的一周。

第4周：完整走通两三个虚拟年份的推演流程，并亲手绘制一张当年运气格局表。产出是一份自己能解释、能核对、能复盘的排盘记录。本周不追求结论漂亮，只追求流程不缺步。

> （虚构教学案例，不对应真实人物）阿岚照这份四周计划自学。第1周她卡在"为什么甲己化土而不是化火"，后来读到岁运源于五音建运、角徵宫商羽配属的推演逻辑，才明白化运并非任意规定，而有一套音律太少之别的推导。她把这句"卡点—解惑"写进错题本，几个月后反成了带新人的讲解素材。第4周她第一次独立排盘时漏了"在泉"，答案只对了一半，于是给自己加了一条规矩：排盘必须先写"司天—在泉"一对，再补间气。

四周只是起步，不是终点。有人四周走完仍觉得"会背不会用"，这很正常，因为"用"需要真实气候与病案的对照，那属于板块8 的内容。四周的真正目标只有两个：干支与口诀内化，推演流程不缺步。

## 0_3 常见误区

误区一，把运气当"中医算命"。运气的落点是气候与发病的趋势提示，不是个人吉凶祸福。它看的是"那年天地之气偏哪边、人易得什么病"，不是"你哪年发财"。一旦把年干支当成个人命运的密码，后续所有推演都会滑向不可验证的方向，也就失去了讨论的基础。

误区二，机械套用某年某气。同一甲子年份，南北地域、海拔、微气候差异巨大，原典本身也强调不可拘泥数字，须观察实际气象物候。把格局直接当作必然结论，是最常见的误用；正确做法是把格局当"倾向假设"，再用当年的实际气候去校正它。

误区三，只背表不推演。会背口诀不算会，能对着任意年干支独立推一遍、再核对一遍，才算真正掌握。规则的复用能力比记忆本身更重要，因为表可以查，判断力只能练。

误区四，跳过胜复直接谈病。不少人学完五运六气就急着解释"某年为何某种病多"，却忽略胜复郁发这套纠偏机制，于是把"某气偏胜"直接等同于"某病必发"。少了动态调节这一层，结论往往过于绝对。

四个误区的共同根源是同一个：把运气当成一套"查表得结论"的静态知识。它实际是一套"按规则推演、再按现实校正"的动态方法，前者可以背，后者必须练。

## 0_4 前置知识与关键气节点

前置知识只有两项，但都不可省。第一项是基础阴阳五行生克：要知道木火土金水的相生相克顺序，以及"太过""不及"在五行关系里的直观含义。第二项是二十四节气的名称与先后顺序，因为运气的每一步都锚定在节气上，节气不清，步次就无从谈起。

其中六个节气尤其关键，它们是主运、主气起止的锚点，建议单独背下来：

```text
气节点    节气区间含义              在推演中的作用
大寒      终之气末 → 初之气始       主运初运起、主气初之气起（全年起点）
春分      初之气末 → 二之气始       主气二之气起
小满      二之气末 → 三之气始       主气三之气起
大暑      三之气末 → 四之气始       主气四之气起
秋分      四之气末 → 五之气始       主气五之气起
立冬      五之气末 → 终之气始       主气终之气起
```

这六个节点串起来，正好把一年切成六段，每段约六十天。记住"大寒起、立冬收尾"这一头一尾，中间的春分、小满、大暑、秋分就很容易按顺序挂上去。若这几项不熟，建议先补再进，否则后面每一步都会绊住。

还有一项容易被忽略的前置：分不清"运"与"气"的层次。运是五段（木火土金水各主七十三日有余），气是六段（风热火湿燥寒各主六十日有余），两者步数不同、起点相同。初学时先把这条差异背成一句话，后面做相合判断就不会把五步与六步错配。

## 0_5 自检清单

第1步，能否不看表，由任意年干支直接说出岁运五行与太过不及？这是检验"天干化五运"是否内化的第一关。

第2步，能否由任意年支直接说出司天与在泉？能脱口而出，说明"地支化气"的配对已经牢靠。

第3步，能否默画主运五步、主气六步的起止节气与五行属性？这一步考的是对"常"的气候递变是否成图在胸。

第4步，能否判定一个给定年份是否属于天符、岁会或太乙天符？注意区分天符比的是司天、岁会比的是岁支本身。

第5步，能否用完整流程对某年格局做出"结论加边界"的小结？即既写出趋势提示，也写明"须结合地域与辨证、不可机械套用"。

五项全过，基础即合格，可放心进入应用与古籍环节；任一项卡住，回到对应零件板块重练即可，不必整体回炉。若五项里只卡在第5步，说明规则已会、分寸未立，建议先去板块8 看几个完整应用示例再回来重答。

## 0_6 四周之后：从路径到板块的衔接

四周走完，最容易出现"断档"：任务表结束了，人却停在那里。衔接的办法是把学习切换成"周更闭环"，每周只做一件事，但四件事轮转不停。

```text
排一张盘 ──► 写一段推演理由 ──► 对照实际气候 ──► 记一条偏差 ──┐
   ▲                                                            │
   └──────────────── 下周带着这条偏差重排 ◄──────────────────────┘
```

具体节奏是：第5周起，每周挑一个自己想要的年干支（不必是当下年份，虚拟年份同样有效），排出岁运、司天在泉、主客运与主客气；然后写三到五句推演理由，说明"为何这样判"；接着对照该年真实的气候与物候描述（可查气象记录、可查地方志），找出至少一条与推演不符之处；最后把偏差写进错题本，下周重排时优先修正这一类错误。

> （虚构教学案例，不对应真实人物）阿岚在第五周做"年度卡片"时发现，自己反复把"岁运太过"与"司天之气"混为一谈，导致同一张卡前后矛盾。她把两者写在一张纸的两端，中间画一条竖线：左边只写"全年基调，看天干"，右边只写"上半年主气，看年支"，以后每次下笔前先看这张纸。三个月后她排盘的返工率明显下降，也第一次体会到"错题本比笔记更重要"。

衔接时还要注意板块顺序的两个例外。其一是板块9（大司天与辨疑）不必等全部学完才读，走完板块7 之后就可以先读一遍，提前建立"这套模型有边界"的意识；其二是板块10（笔记法、术语、延伸）应当边学边用，不必留到最后，否则学完再补笔记，等于把最需要记录的体感丢掉了。

最后给出一个可执行的判断：如果你能在不看资料的情况下，用十五分钟排完一张年盘并写出三条带边界的结论，就已经越过入门线，可以按自己感兴趣的方向（临床、文献、教学）分流深读，而不必再照着四周表走。

# 板块1 · 理论根基与经典源流

初学者最容易在运气门口犯迷糊：它到底是不是算命？它和天文历法、和命理八字是什么关系？它的理论底气又从哪来？本板块先回答"五运六气是什么、不是什么"，再交代它的宇宙论前提与历史来路，最后把七篇大论的内在逻辑串成一条链。读通这一块，后面学推演才不会把结论用错地方。

## 1_1 一句话界定：时间医学，不是算命

五运六气不是"算命"，而是以干支为推演工具，研究"天体运动—气候变化—物候表现—人体疾病"之间关联链条的传统医学理论。它的方法论可浓缩为一句话：把时间（年、节、气）翻译成气化属性，再把气化属性读成健康与养生的提示。

要紧的是"翻译"二字。运气并不直接断言某个人必定生什么病，而是先把某年的干支转换为一套"运"与"气"的符号，再据这套符号推断当年的气候偏性与发病趋势。所以严格说，它是"时间医学"与"气象医学"的古人版本，定位为传统医学的参考模型，而非预测个人命运的术数。

## 1_2 三个核心概念：五运、六气、六十甲子

理解运气，先抓住三个层次：五运、六气、六十年周期。三者由粗到细、由静到动，共同构成推演的完整骨架。

五运，指木、火、土、金、水五类气化，由天干决定，主管一年之中气化的"常"与"变"，内部再分岁运（全年基调）、主运（一年五步固定序列）、客运（随岁运而迁的五步变化）三层。六气，指厥阴风木、少阴君火、少阳相火、太阴湿土、阳明燥金、太阳寒水六类气化，由地支决定，推演一年六段时令的气候特征，内含主气、客气、司天、在泉。周期，则是五运与六气相合后形成的六十年甲子循环，把单年格局装进一个可回看、可对照的总框架。

| 层面 | 内容 | 说明 |
| --- | --- | --- |
| 五运 | 木、火、土、金、水 | 由天干决定，含岁运、主运、客运三层 |
| 六气 | 风、君火、相火、湿、燥、寒 | 由地支决定，含主气、客气、司天、在泉 |
| 周期 | 六十年甲子 | 运与气相合，成六十年循环的总格局 |

记忆窍门：天干管"运"、地支管"气"，运讲一年之内五行的递变，气讲一年之内六段时令的特征，两者叠加才能读出某年相对完整的天时画像。

## 1_3 学科交叉坐标与相邻边界

五运六气处在"医、术数、天文历法"三者的交叉地带，但它的本位在医——落脚点是气候、物候、发病、养生与用药，而不是命理吉凶或一事一占。认清这个坐标，学的时候才不跑偏。

```text
        天文历法（干支、节气、交节时刻）
                  │
                  ▼
        术数框架（阴阳五行、三阴三阳、生克）
                  │
                  ▼
        医学本位（气候—物候—发病—养生—用药）
```

天文历法提供"算具"：干支纪年、二十四节气、交节时刻，是推演的时间底座。术数框架提供"语法"：阴阳五行、三阴三阳、相生相克，是把时间转成气化的规则系统。医学本位才是这套符号的"归宿"——所有推算最终都要回答"人该怎么防、怎么养、怎么治"。

与相邻领域的边界必须主动划清。与命理术数（如八字、铁板神数）相比，双方都用天干地支作运算符号，但运气只推年度与时令的天时气化，不排个人命局、不论富贵穷通；拿运气的岁运去断人财运，是越界误用。与伤寒、温病学说相比，运气提供"因时"的维度，伤寒温病提供"辨证"的维度，二者是天时与病机的配合，而非替代，临床须以辨证论治为主、运气为辅。与现代气象学相比，运气是古人在无仪器条件下对气候节律的符号化归纳，现代气象靠实测数据与物理模型，二者可对照互参，但不可等同。与天文历法本身相比，干支、节气是运气借来的时间尺，运气在尺上又叠加了五行气化的解释层，已超出纯历法范畴。

> （虚构教学案例，不对应真实人物）一位爱好者初学时把运气和八字命理混为一谈，拿着自己的八字追问"我哪年走土运、会不会发财"。阿岚用上面的坐标图告诉他：运气看的是"那年天地之气偏哪边、人易得什么病"，不判个人财运；若把运气当命理，就跨出了它的本位，结论也不可靠。

## 1_4 宇宙论根基：太始天元册的气本体论

运气为什么能用五运阴阳去统摄气候？这个问题在七篇之前的更古老文献里已有答案。《太始天元册》是一部早佚的古天文之书，今仅存零星引文，最著名的一段是"太虚寥廓，肇基化元，万物资始，五运终天，布气真灵，总统坤元，九星悬朗，七曜周旋，曰阴曰阳，曰柔曰刚，幽显既位，寒暑弛张，生生化化，品物咸章"。它正是运气学追溯自身宇宙论源头时必提的"失传经典"。

据现存引文推究，此书主张一条宇宙生成链：太虚之气化育本元，本元分作五运阴阳，五运阴阳再化生万物，其中便包括岁气与人形。这条链等于宣布"气"是唯一本体，形质、动静、寒暑皆是其显化。读懂这一层，才明白运气不是外在地"给气候贴标签"，而是内在地认为气候本就是气化之流。

```text
〔现存引文〕                          〔复原框架〕
"太虚寥廓，肇基化元"          →   [太虚]  本体论起点（本始之气）
"万物资始，五运终天"          →   [化元]  化育本元 → [五运阴阳] 天地之道
"应天之气，动而不息"          →   [五运·动]  岁运右迁
"应地之气，静而守位"          →   [六气·静]  六期环会
                                      ↓
                            [岁气·万物（含人形）]  气化所生
```

浓缩成一句：太虚（本始之气）→ 化元（化育本元）→ 五运阴阳（天地之道）→ 岁气·万物（含人形）。七篇借这部书的口吻说"五运阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始"，把五运阴阳抬到"道"的高度——它不只是推算工具，而是宇宙运行的根本节律。运气七篇之所以敢以干支推演全年气化，底气正来自这种"五运阴阳即天道"的本体论自信。

读这部佚书有一条铁律：严格区分"引文"与"推断"，绝不把推断当原典。原典只说得出百余字，便只认百余字；多出来的体系，必须老老实实标"推"。这既是读佚书的纪律，也是运气学"尊重来源、克制发挥"的品格。

## 1_5 从七篇到现代：历史源流

一套理论，只有知道它从哪来、被谁确立、如何被使用与质疑，才能真正读懂它的分量与边界。

运气学说的理论根脉，是《黄帝内经·素问》中被称为"运气七篇大论"的七篇文章：《天元纪大论》《五运行大论》《六微旨大论》《气交变大论》《五常政大论》《六元正纪大论》《至真要大论》。这七篇系统论述了天干化运、地支化气、主客运气、胜复郁发等核心规则，是后世一切运气著作的总源头。它们在《素问》中自成一套严密的符号体系，篇幅大半由推演规则与格局判定构成，后世研究普遍认为可能并非与其余篇章同期成书，而是被整合进来的专门内容。学习者须明白：七篇才是"原著"，后人著作都是对它的翻译与发挥。

唐代王冰整理《素问》时，将运气七篇补入正文，并附上《刺法论》《本病论》两篇遗篇，后者专论疫疠与运气的关系。后世普遍把这一事件视为运气学说正式确立的标志——在此之前，运气内容零散依附；在此之后，它有了明确的经典归属与文本载体。遗篇在宋代才广泛流传，真伪历代有争议，但内容确与运气、疫病密切相关，不可因"疑伪"而轻弃其学术价值。

北宋时期，运气完成了从"一家之说"到"国家考试与官方医典组成部分"的跃迁：太医局把运气列为考试科目，官修《圣济总录》把六十年运气图置于全书首卷并附运气方药，使运气格局第一次拥有了"国家版本"的权威图谱。进入金元明清，运气从"推演框架"进一步走向"病机解释工具"：刘完素以"亢害承制"阐发火热病机，主张"六气皆从火化"，开温病学派一源；明代汪机《运气易览》把纷乱的干支化运、司天在泉整理得条理分明，成为最常用的入门读本；王肯堂《医学穷源集》以"大司天"理论注解医案；明清医家又对"是否该机械套用"持续争鸣，出现《运气商》《运气辩》一类纠偏之作。这一阶段的主旋律是"既应用、又反省"，而非一边倒的信仰。

近几十年，运气被重新作为时间医学、气象医学与疫病预测模型加以研究：研究者把六十年周期与历年气候、流行病学数据对照，回测流感、呼吸道与消化道传染病的高发年份。但学界对推演刻板化的弊端多有反思，统计学验证结果也不一，现代研究的共识倾向是——把运气当作"可检验的传统参考模型"而非"可盲信的定律"。

```text
先秦两汉   运气七篇大论（理论根，藏在《素问》中）
     │
唐代       王冰补注 + 遗篇（文本确立）
     │
北宋       太医局设科 + 圣济总录首卷运气图（制度化）
     │
金元明清   刘完素阐发病机 / 汪机整理入门 / 王肯堂医案 / 诸家争鸣
     │
现代       时间医学 · 气象医学 · 疫病建模（回测与反思）
```

## 1_6 七篇大论的总纲与内在逻辑链

七篇并非七本互不相关的独立著作，而是一套分工明确、首尾相贯的"总论—零件—五运—六气—纪年—治则"体系。

《天元纪大论》是总纲，提出"天以六为节、地以五为制，五六相合而成岁"的根本框架，回答"运"与"气"为何能配成一套年际模型，并首次点出"太过、不及"之纪。《五运行大论》用"五气经天"解释五行之气如何运行于天，明确太过不及由天干阴阳决定，并首次引入"客运"，使模型具备"常中有变"的层次。《六微旨大论》定义六气及其标本中气关系，提出"升降出入"与"气交"，指出人与万物居处其中，"气交之分，人气从之"，这是岁气作用于人体的理论枢纽。《气交变大论》逐运讲解五运太过、不及之年的气候偏差与"灾眚"方位，用"德、化、政、令、灾、变"描述每运的正常与失常，把抽象"运"转成可观察的气候异常。《五常政大论》把每运分为平气、太过、不及三类常态（"三纪"），并补充"地域高下"对运气表现的影响，提醒模型须与地理结合。《六元正纪大论》以六气为"六元"，给出六十年每一年的司天在泉、左右间气、客主加临及宜忌，是七篇中最像"检索手册"的一篇。《至真要大论》提炼"病机十九条"，讲司天在泉淫胜时的治法，是从推演落到"该怎么治"的桥梁。

```text
天元纪（总纲：五六相合）
     │
     ├── 五运行（五运零件 · 客运）
     └── 六微旨（六气零件 · 气交升降）
               │
     ┌─────────┴─────────┐
  气交变（五运太过不及）  五常政（三纪 · 地域修正）
     └─────────┬─────────┘
               ▼
     六元正纪（六十年逐年总表）
               │
               ▼
     至真要（病机十九条 · 治则方药）
```

这条链的逻辑是层层递进的：总纲立"五六相合"，五运行与六微旨分别备齐"五运零件"与"六气零件"，气交变与五常政专论五运的常变与地域修正，六元正纪把零件组装成六十年逐年总表，至真要则把逐年气候偏性翻译成病机与方药的临床语言，形成"框架→零件→五运→纪年→治则"的闭环。明了这条线索，就不会把七篇读成七堆散材，而能把它当作一部有开头、有中段、有落点的"运气学总论"来用。

## 1_7 源流与方法论启示

启示一：先读七篇原文，再读后人整理。后人如汪机、王肯堂是"翻译者"，七篇才是"原著"。顺序若反，容易把后人的取舍与发挥误认为原典本意，基础会虚。建议以七篇为根，以《运气易览》为过门槛的阶梯，再逐步扩展。

启示二：重视"争鸣"而非只信"定论"。运气历来有"该不该套用"的争论，从明清诸家到现代学界都在泼冷水。学习者应带着"参考模型"的眼光入门，而非"铁律"的眼光——既能用它的框架观察天时，也始终记得它的边界。

启示三：知其哲学前提，方能用得不虚。七篇的"算法"背后是《太始天元册》的"气本体论"：正因为天地万物同出一气，气候才可被五运阴阳统摄。懂得这一层，运气就不是一堆口诀，而是一套"以气观天、以时观人"的世界观；同时也更该克制——世界观不等于预测公式。

> （虚构教学案例，不对应真实人物）阿岚在读到"北宋把运气列为考试科目"时，联想到今天中医执业考试也考运气基础。她由此明白：运气并非玄虚，而是古人医者必须掌握的公共知识框架，正如今天医生要懂流行病学基础。这个类比帮她把"古代考试"与"现代执业"打通，学习动力明显增强；她也在笔记里补了一句"知其源、守其界"，提醒自己别把公共框架用成个人预言。

# 板块2 · 基础工具：天干地支与六十甲子

在正式推演"运"与"气"之前，必须先备齐两套算具——天干与地支。它们既是纪年的符号，也是把"某一年"翻译成"某种气化属性"的接口：天干通往五运（岁运），地支通往六气（客气与司天在泉）。本板块不追求死记，而是把干支的阴阳配对规则讲透，让你拿到任意年干支都能立刻判断合法与否、阴阳归属，为板块3、板块4 的推演打底。

## 2_1 十天干

十天干即甲、乙、丙、丁、戊、己、庚、辛、壬、癸，是古人用于循环纪序的十枚"序数钉"。它的用法不止于纪年，也纪月、纪日、纪时，但在五运六气里最关键的作用是"取年干定岁运"——天干是全年气化基调的钥匙。掌握天干，重点不在背下这十个字，而在记住它们的奇偶位次：排在第1、3、5、7、9位的甲、丙、戊、庚、壬为阳，排在第2、4、6、8、10位的乙、丁、己、辛、癸为阴。

理解天干阴阳的窍门是"看位置不看字义"。天干本身没有吉凶，所谓阳干、阴干只是序数的奇偶属性；板块3里"阳干为太过、阴干为不及"的总纲，正是直接借用这套奇偶划分，所以这里把位次记牢，后面岁运部分就能秒判。

## 2_2 十二地支

十二地支即子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥，与十二生肖、十二月、十二时辰一一相配，是另一套循环刻度。在运气学说里，地支承担"取年支定六气"的任务：年支决定该年的司天、在泉与客气排布，是"气"这一半推演的起点。地支同样按序数定阴阳，第1、3、5、7、9、11位的子、寅、辰、午、申、戌为阳，第2、4、6、8、10、12位的丑、卯、巳、未、酉、亥为阴。

地支比天干多两枚，因此与天干相配时会出现"十个天干走完一轮、十二个地支还没走完"的差速。这个差速正是六十甲子循环的根源——天干每转六轮（6×10=60）、地支每转五轮（5×12=60）才会重新对齐，理解这一点，后面讲六十甲子就不会觉得是凭空而来的规则。

## 2_3 干支纪年与六十甲子

天干与地支依次相配，且严格遵守"阳干配阳支、阴干配阴支"的配对法则，由此生成六十个互不重复的组合，称为六十甲子，构成六十年一大循环。配对从"甲子"起头：甲（阳）配子（阳）、乙（阴）配丑（阴），一路顺推，到"癸酉"完成第一旬（十天），再换"甲戌"开第二旬，直至"癸亥"收尾，共六十组。五运六气的所有推演都落在这"某年的干支"之上——取天干推五运，取地支推六气，干支就是整座运气大厦的地基。

## 2_4 阴阳属性速记

天干阴阳：序号单数为阳，即甲、丙、戊、庚、壬；序号双数为阴，即乙、丁、己、辛、癸。地支阴阳：同样序号单数为阳，即子、寅、辰、午、申、戌；序号双数为阴，即丑、卯、巳、未、酉、亥。一个统一口诀是"奇配奇、偶配偶"——只要天干序号的奇偶与地支序号的奇偶一致，这个组合才合法，否则在六十甲子里不可能出现。

还有一句便于口诵的整段口诀："甲丙戊庚壬阳，乙丁己辛癸阴；子寅辰午申戌阳，丑卯巳未酉亥阴。"把天干、地支各自的阴阳各自记成一组，再套用"奇偶同配"的配对法则，就能对任意组合做合法性检验，不必依赖背表。这套阴阳判定是后面板块3"太过、不及"与板块4"司天在泉"的共同前置功夫。

> （虚构教学案例，不对应真实人物）阿岚初背六十甲子总串错"阳干配阴支"。她改用"奇配奇、偶配偶"的口诀（天干序号奇偶等于地支序号奇偶）后，立刻能判断"甲子合法、甲丑非法"。她把这条纠错记进错题本，标注根源是"没抓住奇偶配对规则"，后来带新人时直接拿这条当教材。

# 板块3 · 五运：岁运·主运·客运·太过不及

五运解决的是"一年内天地之气如何按五行递运"这一半问题，它由天干开启，分成三层：统管全年的岁运、年年固定的主运、随岁运而变的客运。本板块要拿下两张核心表（天干化五运、主运五步）加一套"太过—不及—平气"的总纲。读完后你应能拿到任意年干，立刻说出全年基调，并把一年五步的"常"与"变"并排画出来，为板块5的运气相合做准备。

## 3_1 岁运（中运、大运）——全年基调

岁运由年天干决定，统管全年的气候与发病总趋势，是五运里最核心的一层，又称中运或大运。其规则名为"天干化五运"或"五运建元"，本质是把十个天干两两分组，每组归入一行：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火。拿到年干后先定"化哪一行"，再看是阳干还是阴干——阳干为太过、阴干为不及，这是判断全年盛衰的总开关。

下表把天干、化运与阴阳一次性列清，建议背熟：

| 天干 | 化运 | 阴阳属性 | 气化倾向 |
| --- | --- | --- | --- |
| 甲、己 | 土 | 甲阳土、己阴土 | 甲太过、己不及 |
| 乙、庚 | 金 | 庚阳金、乙阴金 | 庚太过、乙不及 |
| 丙、辛 | 水 | 丙阳水、辛阴水 | 丙太过、辛不及 |
| 丁、壬 | 木 | 壬阳木、丁阴木 | 壬太过、丁不及 |
| 戊、癸 | 火 | 戊阳火、癸阴火 | 戊太过、癸不及 |

口诀务必记牢：**甲己化土，乙庚化金，丙辛化水，丁壬化木，戊癸化火。** 实操有一个易错点：甲与己虽同化土，但甲是阳土（太过）、己是阴土（不及），五行相同而阴阳相反，推全年盛衰时绝不能混为一谈。传统认为，岁运统一年之常变，是后续主运、客运以及板块5格局判定的"母本"。

## 3_2 主运——一年内五步固定序列

主运把一年切成五步，每步约 73 天零 5 刻，从大寒节起算，按"木→火→土→金→水"的五行相生顺序固定运行，年年如此，不受年干影响。它体现气候的"常"——正常的温、热、湿、燥、寒递变节奏，相当于一年气候的"基准钟摆"。下表给出五步的起止与五行归属：

| 运序 | 名称 | 起算约点 | 五行（气化） |
| --- | --- | --- | --- |
| 初运 | 木运 | 大寒起，约73日 | 木（风） |
| 二运 | 火运 | 春分后 | 火（热） |
| 三运 | 土运 | 芒种后 | 土（湿） |
| 四运 | 金运 | 处暑后 | 金（燥） |
| 终运 | 水运 | 立冬后 | 水（寒） |

记忆主运有个省力法：把五步看成"春温→夏热→长夏湿→秋燥→冬寒"的翻版，起点永远锁在大寒后的木运，顺序与五行相生完全一致，所以只要记住"大寒起木、相生接龙"八个字，五步就不会乱。下面用 ASCII 把主运链画成一条固定轨道，方便对比后面客运的"滑动"：

```text
  风          热          湿          燥          寒
```

## 3_3 客运——随岁运而迁

客运同样分五步、同样走"木火土金水"相生顺序，但区别在于：它的初运必须等于当年岁运，之后才依次相生接龙，因此每年不同，体现气候的"变"。也就是说，客运的"骨架"由岁运锚定，主运的"骨架"由节气锚定——一个随年而滑、一个年年钉死，二者叠合才构成一年的运气全貌。

举例说明方法：壬年岁运为木（阳木太过），则客运初运为木，二运火、三运土、四运金、终运水；若换成丁年（木不及），客运初运仍为木，但整体气象转向"木弱"，余步顺推。排客运的标准动作只有两步——第1步，查年干得岁运五行，作为客运初运；第2步，按相生顺序写出后续四步。传统认为，客运反映正常气候之上的当年异常增减，是"因时制宜"里"变"的那一维；若客运初运恰与主运某步重合，则该时段本气被双重强化，值得留意。

## 3_4 太过、不及与平气

岁运有阴阳，便有盛衰两态：阳干之年为"太过"，气化有余、本气偏胜；阴干之年为"不及"，气化不足、本气偏衰。二者都会打破五行平衡，机制可用"乘"与"侮"描述——太过时本气乘其所胜、反侮所不胜；不及时所胜之气来乘、所不胜之气来侮。具体说，传统认为太过之年本气所胜之脏易伤、所不胜之脏被侮；不及之年则本气偏衰，反被所胜乘、被所不胜侮。

"平气"是第三种状态：当岁运本应太过，却被当年司天之气所克，或本应不及却被司天之气所助，干支五行相互制约，使气化转为平和，称平气之年，传统认为气候相对正常、灾病较轻。下面用 ASCII 把三者关系一次列清：

```text
岁运（由年天干定）
   │
   ├─ 阳干 → 太过 → 本气偏胜 → 乘所胜、侮所不胜
   │
   ├─ 阴干 → 不及 → 本气偏衰 → 被所胜乘、被所不胜侮
   │
   └─ 逢司天制/助 → 平气 → 气化平和 → 灾病较轻
```

理解这套机制的关键是"动态而非定局"：太过与不及不是吉凶断语，而是提示"哪一行偏强、哪一行偏弱、哪些脏腑需多留意"的坐标。传统认为，平气之年虽相对安和，但仍须结合地域与主客气综合判断，不可一见平气便断言无病。

> （虚构教学案例，不对应真实人物）壬年（阳木太过）时，阿岚推得"木气偏胜、脾土易伤"。她留意到门诊里消化偏弱、腹泻的患者略增，便在记录卡里写下"壬年木太过—脾土受病"的趋势观察，并特意标注"这只是趋势提示，须结合患者实际辨证，不能见壬年就断言必病脾"。这正是对"传统主张勿机械套用"的实操化。

# 板块4 · 六气：主气·客气·司天在泉

六气解决的是"一年六段时令各主什么气候"这一半问题，它由地支开启，分成主气（固定）、客气（随岁支而变）两层，并由"司天、在泉、间气"标出上下左右的位置。本板块要拿下地支化气表、主气六步表，以及司天在泉的排盘位置。读完后你应能拿到任意年支，立刻说出司天在泉，并把一年六步的"常"与"变"画出，为板块5的运气相合提供"气"这一半的零件。

## 4_1 六气与地支对应（司天在泉的根）

六气以"三阴三阳"配六种气化：厥阴风木、少阴君火、少阳相火、太阴湿土、阳明燥金、太阳寒水。按年支定司天、在泉的规则名为"地支化气"，它是整张客气排盘的根——年支直接给出当年"天之气"（司天）与"地之气"（在泉），二者相对而立。拿到年支先定司天，在泉即其"对冲之气"（三阴对三阳），不必另记。

下表一次列清六组年支的司天、在泉与三阴三阳属性：

| 年支（司天） | 司天气 | 在泉气 | 三阴三阳 |
| --- | --- | --- | --- |
| 子、午 | 少阴君火 | 阳明燥金 | 二阴司天，二阳在泉 |
| 丑、未 | 太阴湿土 | 太阳寒水 | 三阴司天，三阳在泉 |
| 寅、申 | 少阳相火 | 厥阴风木 | 一阳司天，一阴在泉 |
| 卯、酉 | 阳明燥金 | 少阴君火 | 二阳司天，二阴在泉 |
| 辰、戌 | 太阳寒水 | 太阴湿土 | 三阳司天，三阴在泉 |
| 巳、亥 | 厥阴风木 | 少阳相火 | 一阴司天，一阳在泉 |

口诀务必记牢：**子午少阴君火天，阳明燥金应在泉；丑未太阴湿土天，太阳寒水在泉边；寅申少阳相火天，厥阴风木应下年；卯酉阳明燥金天，少阴君火在泉联；辰戌太阳寒水天，太阴湿土在泉前；巳亥厥阴风木天，少阳相火在泉牵。** 实操要点：先由年支锁定司天（上半年主气），再用"三阴三阳相对"推出在泉（下半年主气）；传统认为，司天在泉定下后，整年的客气骨架便已成型，后续只需排布其余各步。

## 4_2 主气——一年六步固定序列

主气一年分六步，每步约 60 天 87.5 刻，从大寒起算，按"厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水"的相生次序固定运行，年年如此，不受年支影响。它体现一年正常的气候递变：初之气风气盛、二之气火渐升、三之气火最盛、四之气湿当令、五之气燥当令、终之气寒当令，对应春温、夏热、长夏湿、秋燥、冬寒的常规节奏。

| 气序 | 名称 | 时段（约） | 气候特点 |
| --- | --- | --- | --- |
| 初之气 | 厥阴风木 | 大寒至春分 | 风气偏盛 |
| 二之气 | 少阴君火 | 春分至小满 | 火热渐升 |
| 三之气 | 少阳相火 | 小满至大暑 | 火热最盛 |
| 四之气 | 太阴湿土 | 大暑至秋分 | 湿气当令 |
| 五之气 | 阳明燥金 | 秋分至小雪 | 燥气当令 |
| 终之气 | 太阳寒水 | 小雪至大寒 | 寒气当令 |

记忆主气的方法与主运同构：把六步看成"春→夏→长夏→秋→冬→再回春"的翻版，起点永远锁在大寒后的厥阴风木，顺序与三阴三阳相生一致。主气是"常"的参照轴，4_3的客气、4_4的司天在泉，都要叠加在这条基准线上读"偏了多少、移到哪步"。

## 4_3 客气——随岁支而变

客气的六步同样走"厥阴→少阴→太阴→少阳→阳明→太阳"的三阴三阳相生顺序，但每步的起点随司天而变，因此每年不同，体现气候的"变"。排客气的唯一锚点是：司天之气永远固定在"三之气"（即全年第三步主气的位置），其余五步再按三阴三阳相生顺序，以司天为基准向前倒推、向后顺排环绕一周。传统认为，客气反映当年气候的异常波动，是"因时制宜"里"变"的那一维。

具体排法分三步：第1步，由年支查得司天，把它放在三之气；第2步，三之气之前（二之气、初之气）按相生逆推，三之气之后（四、五、终之气）按相生顺推；第3步，核对终之气应恰好是"在泉"的对侧位置，若不符说明排错。注意一个常见坑：客气顺序与主气顺序的"相生链"相同，差别只在起点被司天平移——所以司天落点一旦错，整年客气全错。

## 4_4 司天、在泉、间气

司天位于"上"，统管上半年（约大寒至大暑），代表当年的天之气，由年支决定；在泉位于"下"，统管下半年（约大暑至大寒），与司天相对，代表地之气。二者一上一下、一前一后，把一年分成上下两半的气化主轴。间气则是围绕司天、在泉的"左右各一"：司天左间、司天右间、在泉左间、在泉右间，共四间气，反映六步中除司天在泉之外的次要气化，填实整张客气盘的边角。

```text
  （六步顺时针：初气→二气→三气[司天]→四气→五气→终气[对应在泉侧]）
```

读这张盘的方法是：先定司天压在三之气，再定在泉在与之相对的终气侧，四间气补齐其余四步。传统认为，司天在泉定出后，该年上下半年的气化主轴便清晰，间气则用于细化各步的偏性。参见板块3可知，运与气两部分各自排完后，要到板块5才正式"相合"成格局。

> （虚构教学案例，不对应真实人物）阿岚第一次排客气时，把"司天在第三步"记成"司天在第一步"，导致整年客气全错。她后来用一句话锚定："司天永远压在三之气（少阳相火那个位置）上，其余五步围绕它轮。"这个锚点写进笔记后，她再没排错过，后来带新人时也直接拿这条当口诀。

## 4_5 本板块自检

第1步，给定任意年支，能否不查表立刻说出司天与在泉，并背出"子午少阴君火天，阳明燥金应在泉"等地支化气口令？

第2步，能否默画主气六步的起止节气与名称，并说明它为何"年年固定、体现常"？

第3步，给定某司天（如卯年阳明燥金），能否排出客气六步，且确认第三步必为司天、终气侧必为在泉？

第4步，能否解释间气"左右各一"分别处在哪几步，以及司天、在泉如何"上下相对"统管半年？

四关全过，再进板块5（运气相合）与板块6（气化失常）。

# 板块5 · 运气相合与特殊格局

板块3讲"运"、板块4讲"气"，二者各自独立成体系。本板块把"运"（岁运）与"气"（司天、在泉、岁支所化之气）合到同一年，得到若干被称为"格局"的特殊组合。格局的本质，是判断某一年天地气化"偏在哪一行、聚在哪一层、偏激还是平和"。掌握格局，目的不在贴吉凶标签，而是为后面的推演流程（参见板块7）与临床接口（参见板块8）提供一个"气化强度"的定性坐标。下面先给总表，再讲推演要点与易错点，随后借《玄珠密语》补一层细辨，最后给出可手算的速判流程。

## 5_1 六类格局总表

下表把六类格局的判定条件与气化学意义并列排出。读表时抓住一个核心动作：**先把岁运五行算出来（记为A），再把司天五行、岁支五行、在泉五行分别算出来（记为C、B、D），然后两两比对**。所有格局，都是A与B、C、D之间"是否同五行"以及"阴阳年属性"的组合结果。

| 格局 | 判定条件 | 气化学意义 |
| --- | --- | --- |
| 天符 | 岁运五行（A）与司天之气五行（C）相同 | 天气与岁运上下相合，传统认为气化偏盛、来势较集中 |
| 岁会 | 岁运五行（A）与岁支本身五行（B）相同 | 运气与岁支相合，传统认为气化专一、方向明确 |
| 太乙天符 | 同时是天符又是岁会（A、C、B三者五行皆同） | 传统认为气化最剧，是六十年中需重点留意的节点 |
| 同天符 | 阳年（岁运太过）且岁运五行（A）与在泉之气五行（D）相同 | 运气与在泉相合，偏盛之气借下半年地气再加成 |
| 同岁会 | 阴年（岁运不及）且岁运五行（A）与在泉之气五行（D）相同 | 运气与在泉相合，偏弱之气得下半年地气相扶 |
| 平气 | 岁运太过被司天所克，或岁运不及被司天所助 | 气化趋于平和，传统认为灾病相对较轻 |

六类之中，前五种是"运与气（或运与支）相合而偏"的格局，最后一种是"运被气制约或扶持而回归中和"的格局，性质刚好相反，判定时不能混为一谈。需要强调：天符、岁会、太乙天符、同天符、同岁会都属"同气相聚"，传统认为这类年份气化偏激、疫病与气候异常的发生概率相对更高；而平气属"制化归和"，是六十年里相对安稳的一类。这种"偏激—平和"的二分，正是格局表最该记住的底层逻辑。

## 5_2 推演要点与常见坑

天符与岁会最容易混淆，关键在"比什么"：天符比的是**司天之气**（C，由年支所化的上半年天气），岁会比的是**岁支本身五行**（B，年支自身的五行属性）。同一个"年支"，既能化出司天之气，本身又有五行属性，二者常常不同（例如辰戌之支本气为土，但其司天为太阳寒水），所以天符与岁会是两套独立的判定，初学者常把"岁支等于司天"误用，导致漏判或错判。

太乙天符是天符与岁会的重叠，要求A、C、B三者五行完全相同，六十年中仅出现数次。传统认为这类年份气化最剧，是重点防范节点，但"剧"不必然等于"凶"，它只说明气化集中、波动幅度大，落到人体仍须结合地域与体质来看，不可一见太乙天符就断言大疫。

同天符与同岁会看的是**在泉**（D）而非司天，并且要严格区分阴阳年：阳年（岁运太过）才可能是同天符，阴年（岁运不及）才可能是同岁会。常见坑是忘了这一阴阳门槛，把"岁运与在泉同"直接叫同天符或同岁会，结果太过、不及判反。平气的判定则要看"司天对岁运的作用方向"：太过之年若被司天之克气所制、不及之年若被司天之同气所助，便成平气；它不是一个独立的"同气相聚"格局，而是从太过或不及里"中和"出来的一类，推演时容易把它和前面的格局抢答，其实二者性质相反。

## 5_3 天符岁会的细辨

七篇已列出天符、岁会、同天符、同岁会、太乙天符诸种格局，而早期运气专书《玄珠密语》在七篇之上又做了一层"细辨"：把偏原理性的格局，转译成更贴近"某年某格、易见某气某病"的逐年对照表，方便习医者按年检索、按格备防。

细辨的价值在于"可核"。格局判定部分（岁运与司天、岁支、在泉的五行相合关系）直接来自七篇，属可验证的算法层；而附加的"某格主某灾某病"之类断言，则多为托名附益，属存疑或附会层，读时必须分层甄别，不能连骨带肉一口吞下。

```text
天符岁会格局判定（原理来自七篇，可验）
------------------------------------------------------------
格局      判定条件（五行相合）              示例思路
天符      岁运干 与 司天支 五行同          岁运土、司天湿土
岁会      岁运 与 岁支 五行同              岁运木、年支寅卯
同天符    阳年(太过)岁运 与 在泉 五行同    太过金运、在泉燥金
同岁会    阴年(不及)岁运 与 在泉 五行同    不及水运、在泉寒水
太乙天符  岁运、司天、岁支 三者五行皆同    气专而盛，重点防范
------------------------------------------------------------
细辨加料（须甄别）：
  · 同格之年附加的"主某灾某病"断言 → 多为附会层，存疑存档
  · 格局本身（五行相合判定）        → 属可验层，按年核查
```

因此读《玄珠密语》这一层，正路是"先抽骨、再剔赘"：把格局判定与逐年对照的"骨"留下，把灾异断言的"赘"另置一栏。这样既不丢它的可操作价值，也不被它的直断口吻带偏。懂得这一点，格局才真正成为"气化强度"的标尺，而不是一张"某年必某病"的判决书。

> （虚构教学案例，不对应真实人物）阿岚整理某几个年份的格局时，发现一个"天符"年与传统所说的"燥气偏盛"并不总对得上。她没有急着否定，而是把"格局判定（可验）"与"某格主某病（存疑）"分两栏记：判定一栏照五行相合关系逐年核，断言一栏只标"待验"。师傅看后说："你这一分栏，等于给玄珠的细辨做了一次去芜存菁。"阿岚由此明白，细辨不是加密的预言，而是把原理铺成可逐年查对的表。

## 5_4 格局速判流程

下面给出一套可手算的速判流程。拿到任意年干支，先拆出A（岁运五行）与B、C、D（岁支五行、司天五行、在泉五行），再按顺序逐格过，遇到"是"即标记对应格局，可同时命中多个（如天符加岁会即太乙天符）。

```text
取 年干支
   │
   ├─ 年干 → 岁运五行 (A) + 定 太过/不及（阴阳年）
   └─ 年支 → 岁支五行 (B) ／ 司天五行 (C) ／ 在泉五行 (D)
            │
            ├─ A == C ?  → 是：天符
            ├─ A == B ?  → 是：岁会
            ├─ A==C 且 A==B ? → 是：太乙天符
            ├─ 阳年 且 A==D ? → 是：同天符
            ├─ 阴年 且 A==D ? → 是：同岁会
            └─ 太过被司天克 ／ 不及被司天助 ? → 是：平气
            │
            └─ 以上皆否 → 普通年（非常格之年）
```

这套流程的顺序有讲究：先判天符、岁会，再判二者的叠加（太乙天符），因为它们都基于A与C、B的关系；再判同天符、同岁会，因为要引入"阴阳年"和"在泉"两个新条件；最后判平气，因为它依赖"司天对岁运的制化方向"这一相对隐蔽的关系。按此顺序走，既不易漏，也不会把平气和"同气相聚"类混在一起。需要提醒：普通年（非常格之年）在六十年里占大多数，格局并非每年都有，无特殊格局不等于"无气化倾向"，常规岁运、司天在泉仍照常分析。

## 5_5 本板块自检

# 板块6 · 气化失常：胜复郁发·病机·疫疠

板块5讲的是"运与气相合"得到的静态格局，但运气学说真正解释"为何有些年份看似平和却突然出事"的，是一套动态机制：胜、复、郁、发。当某一年某一气偏盛或偏衰，天地气化并不会静止接受，而是进入一场自我调节、也可能自我调节失败的博弈。本板块把这套机制与两条落点接起来：一条通向人体病机（以《素问玄机原病式》的"火热"发挥为代表），一条通向群体疫疠（以《刺法论》《本病论》遗篇的"五疫、三年化疫"为代表）。读通这一块，才能把"格局"读成"气候突变与疫病突发"。

## 6_1 胜、复、郁、发：四个概念

胜气，指某一气偏胜、太过，因而"乘"它所胜之气，导致被乘的一方受伤。例如木气太过则乘土，使土气（脾胃相关）受抑而病。胜气是动态失衡的"第一推手"，它出现的前提是某气有余，方向总是"强凌弱"。

复气，指被胜之气在后期发动的报复性偏胜。胜气逞强之后，被抑的一方并不会长久沉默，到一定阶段会反过来偏胜，形成"胜、复"的自我纠偏循环。传统认为这套循环是天地气化维持平衡的内在机制，复气越强，往往意味着前期被压抑越深。

郁气，指某一气被抑遏而不发、在气候层面蓄积待发的状态。胜气乘之、复气未至之间，被抑之气处于"憋住"的阶段，表面平静，实则能量在积累。郁是"发"的前奏，也是最难从静态格局表里看出来的隐藏变量。

发气，指郁极而爆发的那一口气，多表现为剧烈的气候突变（如久旱突涝、久寒突暖）或集中性的疫病暴发。发气是郁气积累到临界后的释放，传统认为它是"伏气""时疫"突然显现的直接动因，也是解释"无特殊格局之年却突发疫病"的关键。

四者串起来的逻辑是：偏盛生胜，胜极成郁，郁久必发，发后由复来纠。它们不是四个并列的孤立名词，而是一条有时间先后的因果链。

## 6_2 动态机制图

下面用字符图把"胜—复—郁—发"的循环画出来。箭头方向表示气化博弈的推进，而非单纯线性顺序：复气纠偏之后，若新的偏盛又起，循环会再次开启，所以它是"动态循环"而非"一次性流程"。

```text
某气偏盛（太过）
      │
      ▼
  胜气：乘其所胜 → 所胜受伤、被抑
      │
      ▼
  郁气：被抑之气蓄积不发（表面平静，能量积累）
      │
      ▼
  发气：郁极而发 → 气候突变 / 疫病集中暴发
      │
      ▼
  复气：被胜一方后期报复性偏胜 → 自我纠偏
      │
      └──────────► 纠偏后若再现偏盛，循环重启
```

这张图要说明的核心观点是：运气学说不是静态格局学，而是一套"动态气化博弈"模型。静态格局（板块5）只告诉你某年气化偏在哪一行，却无法解释"为何偏偏在某一季突然暴发"——那往往是郁久而发的"发气"在起作用。所以读运气，永远要把"格局"和"胜复郁发"叠在一起：格局是底色，胜复郁发是底色之上的波动与突变。

## 6_3 病机十九条的"火热"再诠释

胜复郁发解释的是"气"如何失衡；要把失衡接到具体的人，需要一座桥，这座桥就是病机。金元医家刘完素（后世称刘河间）的《素问玄机原病式》，正是把《至真要大论》病机十九条重新发挥、建立"以热为枢纽"病机体系的代表作。他不重"算岁运、排客气"，而把七篇给出的"天气模型"转化为"天气致病的病机模型"，是运气从推演走向治病的关键节点。

其核心命题是"六气皆从火化"：风、湿、燥、寒诸气初感未必即热，然一经"郁滞"便多转归为热。于是原本分散的"分类学"条文，被编织成一条"以热为归宿"的动力学线索，使医生面对复杂证候时先找"热"、再辨"郁"。

```text
风(木) ─┐
湿(土) ─┼──→ 气机郁滞 ──→ 化火(热甚) ──→ 伤阴 · 动风 · 闭窍
燥(金) ─┤                          ↑
寒(水) ─┘              五志过极(怒喜悲恐思)亦归此
        （亢害承制：亢极则物极而反，寒极似热、燥极生风）
```

必须守住一个分寸：原文所述是"多从"而非"尽从"。化火的前提是气机郁滞、无从疏泄；若表气尚通、津液未伤，则未必化火。以"诸湿肿满，皆属于脾"为例，底本重"属脾"之常，刘氏补"湿郁不化、多从热化"之变，治法由温燥转向清化——同一条文，一静一动，正是"发挥"的典型写法。

```text
十九条原意：  诸湿肿满，皆属于脾        （脾失健运，水湿停聚）
刘氏发挥：    湿郁不化 → 多从热化 → 治当清化，非徒健脾
对照结论：    刘氏在"脾"之外补了"郁→热"一环，治法由温燥转向清化
```

## 6_4 五志过极与亢害承制

常被忽略但极关键的一点是：刘氏全书的哲学底座来自七篇"亢则害，承乃制"——气亢盛到极点，反会生出制约它的变化，而"化火"正是这种亢逆之一象。原文所述其逻辑为：六气本平，亢则为害；寒极似热、燥极生风，皆因亢逆太过、物极而反，故表面寒象深处可能藏着热机。这正是"六气皆从火化"能成立的深层依据，使这句话不至于沦为一句武断口号。

与天气化火并行的，是"人气"化火。"五志过极皆为热甚"把怒、喜、悲、恐、思五种情志走到极端时，气皆郁结而内生热，首次把心理应激纳入运气病机体系。天时能化火，人心过极亦能化火，二者在"郁而生热"上殊途同归。

```text
怒(肝)→气上    喜(心)→气缓
悲(肺)→气消    恐(肾)→气下
思(脾)→气结  ──→ 气机郁结 ──→ 五志过极皆热甚
```

对应"火热"病机，其治则取向为"辛凉解表、寒凉清里"：解表用辛凉以透达，清里用寒凉以泻火。它并非"见热就下"，而是讲究分层——表未全入则辛凉透之，里已化火则寒凉清之，表里同病则双解并行。要扣住"郁"字来理解：辛凉是为郁闭的表邪开一条凉透之路，寒凉是把已成之热直折下来，二者都服务于"散热存阴"。

> （虚构教学案例，不对应真实人物）阿岚是北方某镇药铺的年轻学徒，某年冬春之交镇上外感发热者渐多。她初起恶寒、头痛、身楚，照旧法喝辛温姜汤发汗，三日后反身热增高、咽痛目赤、心烦口渴、大便数日未行、舌红苔薄黄而干。她翻出《原病式》细想"寒邪入里、郁而化火"，据"辛凉透表、微清其里"调护数日，身热渐缓、咽痛减轻、大便得行。师傅点评时特别提醒："刘氏说的是'多从'而非'必从'；若见湿重身困、舌淡苔腻者，是湿未化热，照搬清凉便误。"阿岚遂在笔记补一行："六气皆从火化，是有条件的转化，条件是郁滞；无郁则不化，临证必合舌脉。"

## 6_5 五疫与三年化疫：遗篇的疫病专论

胜复郁发在人群层面的极端表现，就是疫疠。《素问》遗篇《刺法论》《本病论》专论此事，它把七篇"气化失常、胜复郁发、迁正退位"的框架，落到"五疫"病种与"气交失序"的群体发病观上，是七篇在瘟疫方向上的专门补遗。

《本病论》先讲"疫从何来"：所谓"本病"，并非个人调养失当所致，而是"气交之间，运气乖违"所生的大众之病。它反复强调天地上下之气当交而交、当迁而迁；一旦"不迁正、不退位""上下不交"，气便郁滞不行，进而在人群中表现为成片发病。《刺法论》则讲"疫如何防"，给出刺五脏之俞以调气、避让毒气等古代方技，并留下"正气存内，邪不可干，避其毒气"的著名文段。

```text
        五运不承 + 六气不交
               │
               ▼
         气交失序（上下不交）
               │
               ▼
         气机郁滞不行
               │
               ▼
         民病 · 五疫（相染）
```

五疫指因五运乖违而起的五类疫疠：木疫、火疫、土疫、金疫、水疫，各与一运相应，疠气多从口鼻（天牝）而入，具有"相染"的群体特征。

```text
        五运乖违（刚柔失守 / 不承）
   ┌─────┬─────┬─────┬─────┬─────┐
   木    火    土    金    水   （五运）
   │     │     │     │     │
 木疫  火疫  土疫  金疫  水疫  （五疫）
   └─── 疠气从口鼻（天牝）入，民病相染 ───┘
```

遗篇最具辨识度的创说，是"刚柔失守"与"三年化疫"：岁运之干（刚）与司天在泉之纪（柔）未能相应相守，便埋下郁气；此类失守往往当年不发，郁气蓄积，至第三年方骤然成疫。这把七篇"郁极而发"的抽象机制，具体化为可逐年推求的疫病时间窗，把"年度运气"与"跨年疫病"连了起来。

```text
正常：  司天(上) ═交═ 在泉(下)   → 气交和，民不病
失序：  司天(上) ╳不交╳ 在泉(下) → 升降不前，气郁为疫
              ↑
   刚柔失守（根基错位）→ 郁气潜伏 → 至三年 → 化疫暴发
```

传统认为，遗篇推演的关键在于"先判失守、再定时窗、后定何疫"：当年岁运与司天在泉不相应为失守，失守后留心第三年的化疫可能，再据失守之运判定木火土金水哪一疫当先。它与七篇"郁发"互证，是"胜复郁发"在疫病专题上的一次展开。

## 6_6 气交失序到民病的因果链

把病机与疫疠两层合起来看，运气解释"病"有一条共同的因果骨架：气化偏性先化为相应病机，再由病机外显为具体症状或群体发病。对个体，是"运、气→病机→症状"的三段链；对群体，是"运气乖违→气交失序→郁滞→民病五疫"的四段链。两条链同源，只是尺度不同——一个落在人身上，一个落在人群上。

```text
个体： 运/气偏性 ──→ 病机（参十九条）──→ 症状
群体： 运气乖违 ──→ 气交失序 ──→ 气郁不行 ──→ 民病 · 五疫
                    （刚柔失守 / 升降不前 / 三年化疫）
```

读古籍时务必区分"某运易致某病之倾向"与"某运必生某病"，后者是典型误读。遗篇的"三年化疫"也可能被读成确定预言，其实它属古人参考模型，非确定性疫病预报。把这条链当"相关性素材"与"思维训练"，每遇一条先问"倾向是否吻合、已验还是未验"，再论可否取法，才不至于被表层说法带偏。

## 6_7 临床与疫病接口的边界

胜复郁发、火热病机、五疫三年化疫，三者都是"把气化失衡接到病"的尝试，但边界必须讲清。其一，胜复郁发属传统解释框架，用于说明"为何突然暴发"，提供的是"因时制宜"的辅助维度，不能替代辨证论治。其二，《原病式》的"六气皆从火化"是"多从、有条件"的转化，条件是郁滞，临证须合舌脉，若把"多从"读成"必从"、把"宜凉"读成"概用凉"，便偏离本意。其三，遗篇的刺法、避毒气属古代方技与特定历史条件下的观念，现代防疫以流行病学与公共卫生为准，针刺类操作必须由合格中医师施行，不可据古籍自行操作。

现代研究者常以历年运气格局回溯呼吸道、消化道传染病高发年份，并重点留意的正是"有无明显郁—发结构"。但这类回测结果不一，既受样本量限制，也受气候、人口流动、公共卫生等多因素干扰。因此疫病接口只能当作"公共卫生的线索之一"，用于提示监测重点，绝不能当作疫情预报，更不构成防疫或诊疗建议。落到个人，仍是"避其毒气、固护正气"的常规防护，运气只提示哪类病性在该年更须留意。

## 7_1 八步推演 SOP

第1步，取年干支。确定你要推演的年份对应的干支，例如"癸卯"。这是全部推演的起点，后续每一步都从这两个字拆出。

第2步，推岁运。用天干化五运规则（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火）定出岁运五行，再看天干阴阳定太过不及：阳干为太过，阴干为不及。癸属阴干、戊癸化火，故岁运为"火不及"。

第3步，定司天在泉。用年支查地支化气表：子午少阴君火、丑未太阴湿土、寅申少阳相火、卯酉阳明燥金、辰戌太阳寒水、巳亥厥阴风木。年支决定司天（上半年主气，固定在客气三之气），其对冲之气即为在泉（下半年主气）。卯年司天为阳明燥金，在泉为少阴君火。

第4步，排主运。主运一年五步固定不变，从大寒起按木→火→土→金→水相生顺序：初运木、二运火、三运土、四运金、终运水。年年如此，体现"常"。

第5步，排客运。客运初运与岁运相同，之后按五行相生顺排。岁运为火，则客运为：初运火、二运土、三运金、四运水、终运木。它体现当年在"常"之上的异常增减，即"变"。

第6步，排主气与客气并做客主加临。主气六步固定：厥阴风木→少阴君火→少阳相火→太阴湿土→阳明燥金→太阳寒水。客气以司天固定在三之气，按三阴三阳顺序环绕排布其余五步；再把客气六步叠到主气六步之上，逐气比较"客胜主"或"主胜客"，即为客主加临，用于判断该步气候偏向。

第7步，判格局。把岁运五行（A）与司天（C）、岁支（B）、在泉（D）比对，依板块5的速判流程判定天符、岁会、太乙天符、同天符、同岁会或平气；若皆否则为普通年。同时看有无明显的胜、复、郁、发之势（参见板块6）。

第8步，出趋势判断。综合以上岁运太过不及、司天在泉、客主加临、格局与胜复郁发，写出"该年气化偏在哪、需留意哪类病证"的趋势提示。这一步必须标注"参考模型、须结合辨证与地域"，不得写成确定性断言。

下面用字符图把从"年干支"到"临床应用"的完整链路画出来，帮助建立整体记忆。图里"运"这一支和"气"这一支在顶端分叉，到"运气相合"处汇合，再经胜复郁发进入应用。

## 7_3 完整虚构推演案例（可复盘）

以下案例以"癸卯"年为例进行完整推演演示。案例主角为虚构人物阿岚（青年中医），全部内容属虚构教学案例，不对应真实人物，也不构成对任一年份的气候或疫病预测。

第1步，取年干支：癸卯。

第2步，推岁运：癸化火，癸为阴干，故岁运为"火不及"。

第3步，定司天在泉：卯年，司天为阳明燥金，在泉为少阴君火。

第4步，排主运：初运木（大寒起）→二运火→三运土→四运金→终运水。

第5步，排客运：岁运为火，故初运火→二运土→三运金→四运水→终运木。

第6步，排主气与客气并客主加临：
主气六步：初厥阴风木、二少阴君火、三少阳相火、四太阴湿土、五阳明燥金、终太阳寒水。
客气六步（司天阳明燥金固定在三之气，按三阴三阳顺序环绕）：初少阳相火、二太阴湿土、三阳明燥金（司天）、四太阳寒水、五厥阴风木、终少阴君火（在泉）。
客主加临要点：三之气客气阳明燥金加临主气少阳相火，金克火，传统认为该步燥气偏胜、暑热受抑；终之气客气少阴君火加临主气太阳寒水，火加水，传统认为该步寒中带温、暖冬倾向。

第7步，判格局：岁运火（不及），司天阳明燥金（金）——A≠C，非天符；岁支卯本气为木——A≠B，非岁会；在泉少阴君火（火）——A==D，且岁运为阴年（不及），故判定为"同岁会"。无平气（火不及，司天为金，既非同气所助、亦非被克成制化，按规则不归平气）。无显著太过的胜气，但火不及之年传统认为"所胜（金）乘之、所不胜（水）侮之"的趋势存在，可留意后期是否有相应复、郁结构。

第8步，趋势判断（参考模型，不构成预测）：癸卯为火不及之同岁会年，上半年燥金司天偏显、下半年君火在泉相扶岁运。传统认为此类年份需留意火气不足相关的心系、阳气布散不及，以及燥气偏胜伤津之象；同时同岁会使偏弱之火得在泉相扶，整体不至于过衰。此判断仅为学习演示的趋势提示，具体到个体仍须辨证论治，且须结合当年地域实测气候，不可见"同岁会"即断言某病必发。

> （案例小结，阿岚口吻）癸卯推下来，我记三句话——"岁运火不及、上半年燥金当令、下半年君火在泉扶火"。但这是参考模型下的趋势提示，不是预测；落到人身上仍要四诊合参。我已把这张推演表作为教学存档，并标注"虚构教学案例，不对应真实人物，趋势判断不构成预测"，待日后复盘真伪。

## 7_4 图表化工具：逐年甲子表与客主加临填图

七篇古奥、术语密集，多数人初学运气其实都经由"图表化"的梯子上去。明代汪机《运气易览》的功劳正在此：它几乎不发明新理论，而把七篇里散落的算式重组成可查、可填、可练的图与表，并辅以编者按语校正偏差。其编排是"图—表—按"三段式：先列运气诸图定框架，再附甲子逐年表供查检，最后以按语贯穿始终点出活看之处。

逐年甲子表，是把六十年每一年的岁运、司天在泉、主客等项预先排好的"运气年历"。它既是查询工具，也是检验工具：你自己推完某年格局，翻到对应干支那一栏一核，便知哪一步出错。

```text
取年干支
   │
   ├─ 查岁运（天干化运 · 太过/不及）
   ├─ 查司天在泉（地支化气）
   ├─ 查客主加临（填入六步图）
   └─ 得本年气候倾向（常 + 变）
```

客主加临填图，是《运气易览》反复演练的核心工夫：主气年年固定、显"常"；客气随岁支而变、显"变"，二者叠加才构成某年实际的气候倾向。能否填对这张图，是检验是否读懂"运与气相合"的试金石。

```text
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
(客气由司天在泉推：司天定三气，在泉定终气，余顺推)
标注： 主客同气 = 相得；主客异气 = 相争（易偏）；
       相争处宜回看汪机"愚按"的活看提醒
```

汪机的"愚按"是全书最珍贵的部分，多处提醒"大率如此，不可执一"。这是早期对"机械运气论"的自觉纠偏——他承认格局有常，却也强调地域、时差、人体差异会让同一年甲子呈现不同结果。读这套图表，最该带走的是"信而不迷"：图能帮你查，但查到的不是铁律，而是参考模型。

> （虚构教学案例，不对应真实人物）阿岚刚接触五运六气，被"客主加临"六个步骤绕得头晕，背了三天仍分不清司天定的是哪一气、在泉又管哪一步。老师没有让她继续死记，而是翻开《运气易览》那张客主加临图说："你别背，照图来。先把今年的年支告诉我。"她报出年支，依"地支化气"一栏查得司天在泉：司天定三之气，在泉定终之气，其余按三阴三阳顺序顺推。她把六步客气逐一填进图里，再与主气一行对照，发现上半年君火司天与主气相争，那一格明显"打架"。她正要惊慌，老师指了指图旁"愚按"——"大率如此，不可执一"，冲突年份正该活看，不能见相争就断为灾。阿岚忽然松了口气："这书像给七篇配了张地图，我以前直接往地形里钻，所以迷路。"

## 7_5 歌诀与查表法

《运气易览》把天干化运、地支司天、主气次序等都编成便于记诵的歌诀，这些歌诀本质上是推演图的"压缩版"。用它们巩固记忆，有一个"背诀、填图、查表"三步加固法，比孤立硬背条文高效得多。

```text
天干化五运（岁运）：
  甲己 -> 土   乙庚 -> 金   丙辛 -> 水
  丁壬 -> 木   戊癸 -> 火
  阳干(甲丙戊庚壬)为太过，阴干(乙丁己辛癸)为不及

地支司天（简括）：
  子午 -> 少阴君火司天，阳明燥金在泉
  丑未 -> 太阴湿土司天，太阳寒水在泉
  寅申 -> 少阳相火司天，厥阴风木在泉
  卯酉 -> 阳明燥金司天，少阴君火在泉
  辰戌 -> 太阳寒水司天，太阴湿土在泉
  巳亥 -> 厥阴风木司天，少阳相火在泉
```

第1步先背诀：把"甲己化土乙庚金"这类句子念熟，让口诀成为条件反射。第2步再填图：合上卡片，在空白的运气图里凭记忆把对应内容填回去，填不出的就是没背牢处。第3步后查表：回到甲子表核验，确认自己填的与表一致。这三步层层互相加固，记诵效率明显高于硬背。卡片可按"天干卷""地支卷""主气卷"分袋收纳，每月抽测一袋，长期下来基本能做到看到任意干支便脱口报出岁运与司天。

## 7_6 实用验证与自测

学了要验，验了要测。推演的正确性，不靠感想，靠能不能独立推对、再与权威表核对。下面给出两张可直接使用的自测模板。

```text
【客主加临 自测】
       初气    二气    三气    四气    五气    六气
主气： 风木    君火    相火    湿土    燥金    寒水
客气： ____     ____     ____     ____     ____     ____
操作：
  第1步 取年支 -> 查司天(定三气)、在泉(定终气)
  第2步 余四步按 厥阴->少阴->太阴->少阳->阳明->太阳 顺推填入
  第3步 填完核对甲子表，不一致则回查"地支->司天"一步
```

```text
【五运速查 自测】
取年干 -> 依"甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火"定岁运
       -> 依阳干太过、阴干不及判盛衰
       -> 与甲子表该年岁运栏对照
例：年干为"丙"，丙辛化水，丙为阳干 -> 水运太过，核对表栏是否一致。
```

自测判分不在"答得准不准运"，而在"链路完不完整、断得克不克制"。凡能独立走完八步、填对客主加临图、并主动标注"参考模型"者方算读通；凡一见干支便只报岁运、略去主客气者，须回头重练第4至第6步。

## 7_7 本板块自检

第1步，能否不看提示，对任意给定年干支（如"壬寅""戊午"）独立完成八步推演并写出结论？

第2步，能否默画出 7_2 的推演链总图，并讲清"运""气"两支在何处汇合？

# 板块8 · 临床应用：养生·脉诊·方药·逐年病源

## 8_1 临床应用总原则与应用红线

运气学说落到生活与诊室，定位始终是"因时制宜的参考模型"：它给出的是天时层面的趋势提示，而不是替代望闻问切的结论。无论养生调摄、诊病辨证、疫病预判还是用药选方，四个接口都只是上游的参考输入，最终必须汇入"四诊合参、辨证论治"的主流程。养生接口讲"偏盛则制、偏衰则助"，辨证接口讲"因时定病势方向"，疫病接口讲"提示风险年与主要病性"，方药接口讲"法随气转、寒温燥润"。四者合用，才能把某年运气格局接到真实的人身上，而不是停在纸面推演。

把运气接到任何实际应用，都必须守住三条边界，越线即把"参考模型"误用成"铁律"。红线一：勿刻板。同一甲子年，南北地域、沿海内陆、高原平原的实际气候与物候可能截然不同，原典本身也强调"不以数推，以象之谓"，拿到格局就套"某年必病某脏"是典型的机械套用。红线二：勿代医。运气不能替代辨证论治，它只是"因时制宜"的辅助维度，任何用它覆盖望闻问切、否定个体辨证的做法都越了线。红线三：证据待验证。现代统计学对其预测力验证结果并不一致，表述必须克制归因，不可把趋势提示说成确定结论。下面这张图展示四个接口如何汇入主流程，运气只作参考输入。

```text
             运气结论（天时提示，仅参考模型）
         ┌──────────┬──────────┬──────────┐
         │          │          │          │
       养生        辨证        疫病        方药
   偏盛则制    因时制宜    提示风险年    法随气转
   偏衰则助    定病势方向  与主要病性    寒温燥润
         │          │          │          │
         └──────────┴────┬─────┴──────────┘
                         ▼
            必须汇入"辨证论治"主流程
            （四诊合参 · 个体为本）
                         │
                         ▼
            ⚠ 红线：勿刻板 / 勿代医 / 证据待验证
            ⚠ 全部应用均不构成诊疗建议
```

> （虚构教学案例，不对应真实人物）阿岚在社区做健康科普，逢"湿土太过"之年，她在讲座里建议大家"少贪凉、重护脾、饮食避黏腻"，同时明确说明"这只是趋势提醒，不是诊断，真不舒服要就医"。后来一位听众因脾虚湿困就诊，回头说"你那次提醒挺及时"。阿岚在笔记里如实写下：这次"巧合"不能证明运气可预测个体发病，只能说明"趋势提示加健康宣教"本身有公共价值，且全程不构成诊疗建议。

## 8_2 养生与节气针药日历

临床使用的第一步，是把六十年运气格局翻译成"何时用针、何时用药"的节律表，让抽象的"气"接通到具体的针与药，并直接对接历法节点。先由年干支定岁运与司天在泉，再把全年切成可排进日历的具体条目，读者不必先通晓全部推演，只要查得所在年份属哪运、何气主令，便能据表行事。"纪"是推算，"用"是施行，二者相须而成，书名先"纪"后"用"次序不可颠倒。

用针一端的核心是"气旺则避、气衰则刺"：某藏之气当令过盛，则泻其有余而避助其势；气衰则补其不足以助其用，把"治未病"落到具体时令的针法上。用药一端以司天在泉定所宜之味，某气司天则其所胜之味为宜、所不胜之味为避，例如燥金司天之年宜辛润以行其气、避苦燥以助其虐，这就是运气方学的雏形。下面两图分别演示"纪→用"如何展开，以及一年四时分到宜避两栏的日历排法。

```text
某年：岁运=木太过(太角)  司天=___  在泉=___
  ├─ 推算(纪)：木气偏盛，木胜则土受克
  ├─ 用针(用)：春木旺 → 泻肝之有余、避辛散过助
  └─ 用药(用)：所胜在土 → 夏当实脾，宜甘缓、避酸收
```

```text
年：____   运：____   司天：____   在泉：____
春：宜____   避____     夏：宜____   避____
秋：宜____   避____     冬：宜____   避____
说明：空格处依当年岁运与司天在泉填列；
      "宜"取所胜之味，"避"取所不胜之味。
```

> （虚构教学案例，不对应真实人物）阿岚素来对"运气能否指导生活"将信将疑。某年开春她查得岁运属木太过，依书把"春泻肝、夏实脾"记上日历，打算逐季核对体感。春季木旺，她照"气旺则避"少做助肝升发之事，饮食偏甘缓以实脾土；入夏依"木胜克土"重点护脾，避酸收、宜甘淡。一年下来记录多称"舒缓"，次年木运不及反向操作亦见节律变化。师傅提醒：你走的是"先纪后用、边读边验"的正路，且"宜避"只是时令参考，差异因人而异，绝不可代医。

## 8_3 脉诊与运藏相应

运气要真正"可上手"，关键一步是把无形的"气"转成"可摸到的脉"和"可辨的藏"。五运分别落到肝、心、脾、肺、肾五藏：木运应肝、火运应心、土运应脾、金运应肺、水运应肾，岁运太过则本藏气实、不及则本藏气虚，且太过者本藏实而乘其所胜，不及者本藏虚而所不胜乘之。例如土运太过传统认为脾实湿盛、易生壅滞，土运不及则脾虚而风木乘之，这类"运偏则藏虚实随之"的说法，临床味明显比单纯框架推演更浓。

脉象随当年岁运、司天在泉而变化，构成"脉应气"的观察法。更细一层，司天统上半年气化、多应于寸部，在泉统下半年气化、多应于尺部，把时间（上下半年）与空间（寸尺部位）叠进脉诊，使运气有了逐年、逐季的"手感"对照。下面两张图分别是运藏对应表与脉气逐年实测模板，验证时须分上下半年分别记录，并始终以"倾向"而非"必然"对待。

```text
五运 → 五藏 对应表（太过则本藏实、不及则本藏虚，乘侮随之）
------------------------------------------------------------
岁运   天干    太过(太X·本藏实)        不及(少X·本藏虚)
木     丁壬    肝实、风盛、脾受克        肝虚、燥金乘之
火     戊癸    心实、热盛、肺受克        心虚、寒水乘之
土     甲己    脾实、湿盛、肾受克        脾虚、风木乘之
金     乙庚    肺实、燥盛、肝受克        肺虚、火热乘之
水     丙辛    肾实、寒盛、心受克        肾虚、湿土乘之
------------------------------------------------------------
用法：先由年干定岁运与太过/不及，再查本行得"本藏虚实"，
      并留意"所胜受克、所不胜乘之"的继发态势。
```

```text
年份：____    岁运：____(太过/不及)    司天：____    在泉：____
------------------------------------------------------------

------------------------------------------------------------

  春：____    夏：____    秋：____    冬：____
------------------------------------------------------------
吻合度：  □ 全符   □ 部分   □ 不符
若不符： 回查"运之太少"或"气之标本"，并记录可能之
         地域、体质干扰因素，不作硬判。
```

## 8_4 方药与气味配伍

从"说理"走向"开方"，靠的是把气化偏性直接焊死在方剂与药味上，形成可检索的运气方数据库：以六十年甲子逐年给出岁运、司天在泉、客主加临，再对接成方，即某年宜用何方何药。其编排始终遵循"运＋气→病机倾向→选方"的链条，而非孤立列方。气味配伍随当年运气偏性调整，例如土运偏盛之年多佐苦燥以祛湿，木运不及之年多辛甘以助木，把"司天定味"的思路落成具体成方，使"运—气—味—方"形成闭环。

这类官方集成的价值，在于把原本分散的运气推演收拢成一部人人可查的准绳，降低了学习门槛，也固定了一套可查可核的用方范式，标志着运气从"秘传推演"到"制度性知识"的跃迁。但其局限也正来自标准化：过度依赖"按年查方"容易导向机械套用，忽略辨证论治的根本。把它当数据库检索可以，当诊疗模板则危险，真正可取的态度是借其方味规律反观临床、佐以辨证。下面两张图演示运方对照与逐年方册结构。

```text

丙寅   水太过    少阳相火  厥阴风木   辛温散寒·防寒热错杂     辛·温
丁卯   木不及    阳明燥金  少阴君火   辛甘助木·佐酸敛         辛·甘·酸
```

> （虚构教学案例，不对应真实人物）阿岚整理运气文献时，想验证"方随运变"是否真能在书里查到规律。她抽取六个年份制成对照卡，按"运太过泻其胜、运不及补其虚"逐格写出主味取向，再把同属土运的甲子与己巳并排：甲子湿盛取苦燥，己巳土衰取甘温，一泻一补、气味翻转；又比二者司天差异，发现君火与风木让上方在"清上"与"疏风"上各有侧重。她由此确认方味确随岁运翻转、随司天在泉微调，本书的价值在"数据库式对照"，不在"照条目开方"。

## 8_5 逐年病源与三段链辨证

把逐年运气格局与具体病证相系，核心是一本"逐年病源"年历：把六十年每一甲子配出一类易发病证，列出"本年何藏易伤、何证易发"的清单。真正有价值的不是清单本身，而是潜含其下的推理链——运气偏性先化为相应病机（参病机十九条），再由病机外显为具体症状，即"运／气→病机→症状"三段链。读懂这条链，才不会被"某年必某病"的表层说法带偏，知道书中所言原是"偏性→趋势→易罹"的层层推进。

附案演示的最大价值，在于示范一种思维：如何把眼前一证放回当年运气大背景中去定位、去取法，重点在"为什么这么断、为什么这么治"的推理，而非只抄方药。读时务必区分"某运易致某病之倾向"与"某运必生某病"，后者是典型误读。把逐年病源定位为"相关性素材"与"思维训练本"，每遇一条先问"倾向是否吻合、已验还是未验"，再论可否取法。下面两图演示单年病源链与逐年查法。

```text
某年运气偏性(如阳土太过·湿盛)
        │
        ▼
相应病机(诸湿肿满皆属于脾 → 脾湿困中州)
        │
        ▼
外显症状(身重、泄泻、脘痞、肢体酸楚)
        │
        ▼
附案验证(同年门诊见脾湿证 → 温化燥湿取效 → 回注"穷源")
```

```text
取 生年/病年干支
        │
        ▼
查 岁运(天干化五运·太过/不及) + 司天在泉(地支化六气)
        │
        ▼
得 "易病"清单(何藏易伤·何证易发)
        │
        ▼
对照 实际病历/体质 → 标 [倾向符 / 已验 / 未验]
```

> （虚构教学案例，不对应真实人物）阿岚发现外祖母生于"岁运土太过、太阴湿土在泉"之年，书言该年湿气偏盛、易脾困，而外祖母晚年常诉身重、食后脘痞、逢梅雨便泻。她铺开三段链：岁干化土太过、岁支化太阴湿土在泉为"运／气"层；断为"脾湿困中州"之机；外显身重、泄泻、脘痞之"症"。其母同运却幼有燥咳、皮肤干痒，阿岚推敲为居地高燥、外燥引动肺金，恰是"不可执一"的活证据。她在笔记里把外祖母标"倾向符·已验"，母亲标"倾向未显·同运异病"，并立自规：必先写全链再标吻合档，绝不略去中间病机、绝不断言必发。

## 8_6 疫病预测要点

疫病是运气最受关注、也最需慎言的接口。其底层逻辑是：气化偏激或郁久而发的年份，传统认为更易出现集中性的时行疾病，故须提前防范。运气以岁运太过不及、司天在泉、胜复郁发这套机制，推断某年某时是否有疫病暴发风险及主要病性（寒、热、湿、燥等），《素问》遗篇专论"疫疠"与运气的关系，提出"正气存内，邪不可干"等名言，并载有避疫、调护、刺法等内容，是把"胜复郁发"接到疫病这一最现实落点的关键。

需要清醒的是，现代研究者常以历年运气格局回溯验证呼吸道、消化道等传染病高发年份，看某些格局是否与疫情峰值对应，但这类回测至今结果不一，既受样本量限制，也受气候、人口流动、公共卫生等多因素干扰。因此疫病接口只能当作"公共卫生的线索之一"，用于提示监测重点，绝不能当作疫情预报，更不构成防疫或诊疗建议。落到个人，仍是"避其毒气、固护正气"的常规防护，运气只提示哪类病性在该年更须留意。

## 8_7 笔记方法（多场景）

把运气接到日常，最怕"读时热闹、过后糊涂"。下面四类场景覆盖日历、脉气、方味、病源，核心是"每年一表、每季一核"，把推算与体感连成可累积的个人资料。

日历标注场景：在纸历或电子历上，把当年岁运、司天在泉标于年初，再于每季记一体感关键词（如"春易醒早""夏乏纳差"）。半年回看，便能粗略看出自身节律与年气是否合拍，重在养成记录习惯，不急于下结论。针药对照场景：把"某气→宜某味、避某味"列成速查卡贴于厨房或药箱旁，饮食起居即查即避，把"用药"一脉直接接入生活，也最不易与医疗处方混淆。

脉气对照场景：把"运／气→应脉"做成一页速查表，左侧列岁运、司天在泉，右侧列预言脉象，下方留四季实测栏，每年填一次，逐年累积成"气—脉"档案；记录坚持"原样填、慢下判"，不符先记"不符"并附注可能原因。方味归类场景：把"泻某藏""补某藏"的方集中归类，归纳成"某偏性→某类方味"的法则，标注"传统立法"提醒自己这是气化偏好而非定论。年代病源对照场景：把本人与家人出生年、发病年代入逐年病源表，分"书言"与"实际"两栏，并强制拆成"运／气→病机→症"三行检验逻辑断点，所有结论一律标"倾向"而非"必"，附"已验／未验／存疑"三档。

## 8_8 实用验证（自测与对照日志）

学了要验，验了要测。下面三张模板分别覆盖针药日历、脉气对照、运病相关性，帮助把"纪用、脉应气、穷源"之法从理解推进到会用。所有记录均属个人参考，不构成健康判断，亦不替代专业诊疗。


# 板块9 · 大司天·古籍方法论与争议辨析

前面各板块一路在讲"怎么用"：算岁运、排客气、判格局、落应用。但一套能用的模型，若没有"刹车"和"放大镜"，迟早会被用歪。本板块补上两件东西：一件是"放大镜"——大司天，把六十年甲子再放大到更长的历史时段，看气化如何跨代叠加；另一件是"刹车"——明清《运气商》《运气辩》一脉的商榷与辨疑，给整套运气学装上安全阀。最后落到现代研究与争议，把"参考模型、勿机械套用"的底线讲透。

## 9_1 大司天：把六十年放大到长周期

一般运气书以六十年甲子为最大周期，逐年推岁运、司天在泉。而明代王肯堂《医学穷源集》引入的"大司天"观，则把六十年格局再放大一层，叠为更长时段的整体气运背景（传统以三元一百八十年为一套来论）。原文所述，每一长周期各有其主导气化，如同一张"大气候底图"，用以解释为何某些病证在某一历史阶段格外多见。

它的意义不在于"换一套算法"，而在于"多一个尺度"。逐年小运气回答"某年偏哪一行"，大司天回答"某代处于哪一种大气运段"。二者一纵一横，合起来才构成本书"通代而又能逐年"的解释力：某代之所以多某类病证，可由大背景与当年小运气合参而得。这也是《医学穷源集》从"逐年手册"升格为"通代医案注解"的关键。

## 9_2 大司天如何叠加逐年运气

大司天的用法，是把"长周期定底、逐年定变、病机定证"三层递进地叠起来。传统认为，大司天提供"势"，当年运气提供"机"，二者会合方能断"证"；读图时宜先纵后横，先认大背景，再查小运气，最后才落到症状与治法。

```text
长周期(大司天):  ──[土运主令段]────────────[火运主令段]──
                    │(底图·大气运背景)
逐年小运气: 自甲子、乙丑、丙寅起，循六十甲子逐年轮转，至癸亥而复始
                    │叠加
                    ▼
        本年实际气化 = 大司天底图 + 当年岁运司天
                    │
                    ▼
        穷源断病: 在此大背景下, 今年偏性为何 → 易发何证
```

要注意，大司天只是"把尺度拉长"，并不改变逐年推演的规则。它最容易滑向决定论——仿佛某一长周期的人"注定"多某病。正确的读法是：大司天提供的是一个更宽的趋势背景，具体到个人仍须回到当年运气、地域、体质与脉证，层层合参，而不是拿"大司天"三字直接断人。

> （虚构教学案例，不对应真实人物）阿岚整理家谱时，发现外祖母生于一个"岁运土太过、太阴湿土在泉"的年份，晚年常诉身重、食后脘痞、逢梅雨便泻。她叠上大司天背景，发现外祖母所属甲子恰落于"土运主令段"，长周期与当年小运气同向叠加，湿势更彰，脾困倾向尤显。但她母亲同生于土运相近之年，却幼有燥咳、皮肤干痒——阿岚推敲为居地高燥、外燥引动肺金，正是"同运异病"的活证据。她由此确认：大司天能解释"为何某代多湿病"，却不能替个人下判决。

## 9_3 脉证为本：运气是"大略"而非"定数"

明清之际，运气学由官修科举、图解普及走向民间泛用。普及带来便利，也带来滥用：村医、儒生皆能背歌诀，却未必懂得其适用边界，坊间渐生"某年必某病""天符之年必大疫"之类的机械套用。医家见其流弊，起而反思，《运气商》《运气辩》即在此"滥用与反弹并存"的氛围中应运而生，专司"挑刺"与"划界"。

其核心主张是：不否定运气框架本身，而是否定"执运气以断病"的滥用。运气所言是"概然而非必然"的群体倾向，是"大略"而非"定数"——岁运、司天在泉可参考一年气候与发病的群体倾向，却断不得具体某人的必然之病。真正落到人身，必以脉、证、体质、地域为实据，把运气从"判决者"降为"提醒者"。

这一立场与中医"三因制宜"完全合拍：因时（运气）、因地（方土）、因人（体质）三者，运气只是"因时"一维，须与他二维合参，方能落到辨证论治。舍脉证而执运气，正是书中所反复纠正的偏失。打个比方：偏"信"的运气书是造车与开车，偏"疑"的商辩之书是装刹车与立交规；没有车，刹车无的放矢；没有刹车，车越快越险。

## 9_4 同运异病：最有力的反例法

《运气商》《运气辩》最锋利的武器，是"同运异病"四字：取同一干支之年，南人、北人、老者、幼者所病各不相同，足证"同运"绝不推出"同病"。它是"大略说"最直观的注脚，也是破除"某运必某病"的最短路径。

```text
同运之年（示意：金运值年）
┌──────────┬──────────┬───────────────┐
│ 对象     │ 地域     │ 所病（示意）   │
├──────────┼──────────┼───────────────┤
│ 南人     │ 湿热之地 │ 咳而痰黏       │
│ 北人     │ 燥寒之地 │ 皮肤干燥燥咳   │
│ 小儿     │ 体质未充 │ 惊惕不安       │
│ 老者     │ 精血已亏 │ 肠燥便秘       │
└──────────┴──────────┴───────────────┘
结论：四人同运，病象四出 → "金运必肺弱"之断，仅可言"偏燥"
      不可言"必"，更不可舍脉证而直断。
```

掌握此法，便拥有一个取之不尽的反绝对化"弹药库"：每记一条运气结论，随手补一例同年异病，断言的锋芒立刻被磨平为参考。收集反例，比收集正例更能护住读法的清醒——正例容易让人相信"果然准"，反例才让人记得"只是偏"。

> （虚构教学案例，不对应真实人物）阿岚初学运气，渐入迷障，逢人便说"今年金运，人人肺弱"。师傅递来《运气辩》"同运异病"一条：同一金运之年，南人咳而痰黏、北人燥而皮干、小儿惊惕、老者肠秘，四人同运而病象四出。阿岚一时哑然，原先那句斩钉截铁的"人人肺弱"竟站不住脚。师傅说："《商》《辩》专治你这种'刚学会就绝对化'的病。它不否认金运偏燥，却提醒你——偏燥是群体气候的'大略'，落到个人还得看地域、体质、脉证。"阿岚遂把结论由"人人肺弱"改为"今岁偏燥，肺燥者宜润，然必合脉证而断"。

## 9_5 可信分层与断言压力测试

商辩之学的总方法，是"分层划界"：把运气内容拆为可信与不可信两堆，而不是整体接受或整体推翻。原文所述把"气候大势、年际倾向"放入可信堆，把"个体之病、必发之断"放入不可执堆，实据则永远压在最底。这条线画在"群体、年际"与"个体、当下"之间，也画在"气候"与"诊断"之间。全书千言，终归一"界"字——有界，运气方为良药；无界，运气反成迷药。

```text
┌──────────────────────────────┐
│ 运气可参（上层·群体·年际）    │
│   气候大势 · 气化偏盛偏衰      │
│   年际发病倾向 · 司天在泉提醒  │
├──────────────────────────────┤
│ 运气不可执（下层·个体·当下）  │
│   个体必发之断 · 舍脉证之断    │
├──────────────────────────────┤
│ 实据优先（地基·永远压底）      │
│   脉证 · 体质 · 地域           │
└──────────────────────────────┘
```

与分层配套的，是一套"断言压力测试"：对任意一条运气断言做四步拷问——先取断言，再搜反例，次判相关强弱，终定结论。凡通不过测试的"必"字句，一律降为"倾向"或推翻。

```text
待验断言：某运必某病
→ 第1步 取同年若干（如该岁运所值诸年）
→ 第2步 搜反例：同年不同病者 __ 例 / 同病不同运者 __ 例
→ 第3步 概然性：□强相关 □弱相关 □无
→ 第4步 结论：降为"倾向"（可参） / 推翻（不可执）
规则：凡断言，先搜反例再采信；个体之断必合脉证。
```

把这两件工具内化成习惯，笔记里的"必"字会越来越少，"参""合""察"字会越来越多——这正是商辩之书想要培养的读法。

## 9_6 现代研究与争议

近几十年，学界把运气学重新当作时间医学、气象医学与疫病预测模型来研究：研究者以历年运气格局（岁运太过不及、司天在泉、胜复郁发）回测流感、呼吸道与消化道传染病的高发年份，试图以现代实证检验其经验性规律。也有从"生物节律、时间医学"角度解读气化的学者，把六步、五运视作人体顺应自然周期的节律框架。

但争议同样清楚。其一，统计学验证结果不一，运气是否具备稳定、可重复的预测力仍存分歧，能观察到的多是弱相关，远不足以构成确定预测。其二，同一甲子年不同地域、海拔、微气候差异巨大，机械套用往往失真，原典本身也强调"不以数推，以象之谓"。其三，古人的"六气皆从火化""某年易发某病"多是经验趋势，缺统计方法，宜作"历史、思维素材"，不宜直接当作流行病预测结论。

因此现代研究的共识倾向是——把运气当作"可检验的传统参考模型"而非"可盲信的定律"。传统认为的"太乙天符之年气化偏剧、须重点防范"等主张，在此语境下应被理解为值得回测的线索，而非确定的灾病预言。有意思的是，商辩之学在明清写下的"概然非必然""实据优先"，放在今天竟与循证医学、统计学思维遥相呼应：古人早已把"相关不等于因果""群体概率不等于个体结局"的边界写在前头。

## 9_7 本板块自检

第1步，能否用自己的话说清"大司天"是什么、它如何叠加到逐年运气之上，并指出它的边界？

第4步，能否用"可信分层"图与"断言压力测试"四步，对一条"某年必某病"的断言做一次检验？

# 板块10 · 笔记方法·术语索引·学习延伸

本板块是整套知识库的"工具箱"与出口。前面板块把工具、零件、装配、应用、古籍与方法逐一铺开，这里把它们收拢成三样可长期使用的东西：一套多场景笔记法，让运气从"看懂"变成"能推、能查、能复盘"；一张术语与口诀速查表，遇到陌生词随时回查；一条继续深入的阶梯与一道不可逾越的边界。读到这里，你手里已有完整的推演工具，接下来要做的，是把工具用对地方、用对分寸。

## 10_1 多场景笔记法

运气最怕"读时热闹、过后糊涂"。下面四类场景覆盖阅读、实盘、复盘、输出，核心是"每年一表、每季一核"，把推算与体感连成可累积的个人资料。

场景一，阅读笔记。建议用"三栏法"：左栏抄原文关键句（保留原字、加引号），中栏写自己的转述（用自己的话把规则或主张重说一遍），右栏写"这对应哪个板块的哪条规则"。好处是强迫你每读一句都把原典挂到规则树上，避免"读了好像懂了、合上书全忘"。例如左栏抄"甲己化土"，中栏写"年干为甲或己的年份，岁运属土"，右栏标"对应板块3的天干化五运表"。

场景二，实盘记录卡。固定一张表，每推一年就填一张，字段包括年干支、岁运、司天在泉、格局、趋势判断、实际观察、复盘结论。关键纪律是"实际观察"与"复盘结论"不能空着——推完不追踪，等于没推。这张卡随年份积累，几个月后就是你的私人运气实证档案。

场景三，复盘笔记。只记三件事：哪条我推对了、哪条我推错了、错的根因写到哪一层。根因务必分层——是"规则层"（口诀记错、步序排错），还是"套用层"（规则没错但硬套到个体或地域），还是"归因层"（把巧合当成运气灵验）。分层写根因，才能让下一次不再犯同一类错。

场景四，教学输出。试着把某一板块讲给旁人听，讲不顺处就是没读透处。输出时优先讲"这块解决什么、给下一块供了什么零件"，而非堆砌术语；定期把零散笔记重组成一条"全库主线"图，是检验整体是否打通的最简办法。

> （虚构教学案例，不对应真实人物）阿岚的错题本里有一条——"曾把司天排到初之气，导致整年客气全错"。她记的错层是"规则层"，纠正动作写的是"锚定：司天永远压在三之气（少阳相火那个位置），其余五步围绕它轮"。三个月后她带新人，直接把这条当教材讲。她说："错题本不是耻辱册，是最高效的讲义。"

## 10_2 排盘记录卡模板

下面这张 ASCII 排盘卡可直接抄到笔记本或电子文档，每推一年填一份。字段覆盖了从年干支到复盘结论的完整链，其中"趋势判断"属传统经验主张（第二层），"实际观察"与"复盘结论"须事后补填并克制归因。

```text
┌──────────────────────────────────────────────────┐
│ 年干支：__________        推演日期：__________    │
│ 岁运（五行/太过不及）：________________________    │
│ 司天：__________      在泉：__________            │
│ 主运五步：木→火→土→金→水（起大寒，固定）        │
│ 客运五步：初运=岁运，后按相生：________________  │
│ 主气六步：厥阴→少阴→少阳→太阴→阳明→太阳（固定）│
│ 客气六步（三之气=司天）：______________________  │
│ 格局判定：天符/岁会/太乙天符/同天符/同岁会/平气  │
│ 趋势判断（传统主张，第二层）：________________  │
│ 实际观察（事后填）：____________________________  │
│ 复盘结论（对/错/根因分层）：____________________  │
│ 边界声明：运气为参考模型，不构成诊疗建议。        │
└──────────────────────────────────────────────────┘
```

使用要点：填"客运五步"时先锚定初运等于岁运，再顺五行相生排；填"客气六步"时务必把司天压在第三步（三之气）上，其余五步围绕它按三阴三阳相生排布，这是最高频的出错点。

## 10_3 实用验证四步与错题本

学了要验，验了要测。验证分四步，层层收紧。

第1步，内部验证（重算）。推完一遍后重新手算：干支是否取对、天干化岁运五行与太过不及是否对、地支定司天在泉是否对、主客运气步序与客气第三步是否对齐。这一步只查"规则层"有无算术与排步错误。

第2步，交叉验证（对照权威运气图）。拿权威运气图谱核对同年份的岁运、司天在泉与格局，看是否一致。若不一致，优先怀疑自己的推演，回头定位错在哪一步，而不是怀疑原典。这一步把个人推演挂到公共权威上校准。

第3步，外部验证（克制归因）。把"趋势判断"与当年实际气候、疾病就诊情况对照，但只记"吻合、不吻合"，不轻易写"运气灵验"。若吻合，要追问是否混杂了地域、气温、人口流动等因素；若不吻合，老老实实记"本次不支持该主张"。外部验证的目的不是证明运气"准"，而是积累你自己的证据清单。

第4步，边界声明。每次写结论都附一句"此为参考模型、须结合辨证与地域、不构成诊疗建议"。这一步看似形式，实则是防止自己与读者把趋势提示误读成确定结论的最后一道闸门。

```text
┌──────────────────────────────────────────────┐
│ 日期：__________                              │
│ 我原先的判断：______________________________  │
│ 实际结果：____________________________________│
│ 错在哪一层（规则层/套用层/归因层）：__________ │
│ 纠正动作：____________________________________│
└──────────────────────────────────────────────┘
```

错题本的填写纪律：错层必须选"规则层""套用层""归因层"之一，不可写"我粗心"这种无效归因；"纠正动作"要写成可复用的动作，例如"锚定：司天永远在三之气""重背：甲己化土而非化火"，而不是"下次注意"。错题本积累到十条以上，你对该板块的掌握度会明显超过只背表不记错的人。

## 10_4 核心术语速查

下表把运气学说最常出现的十五个术语压缩成"一句话即懂"的解释，重点放在"它是什么、管哪一段、与其他术语的关系"。

| 术语 | 一句话解释 |
| --- | --- |
| 岁运（中运、大运） | 由年天干决定的全年气化基调，分太过与不及，统管一年的气候与发病总趋势。 |
| 主运 | 一年分五步、从大寒起按木火土金水相生固定运行的气化序列，体现气候的正常递变（即"常"）。 |
| 客运 | 以值年岁运为初运、随后按五行相生排列的五步异常气化序列，体现当年气候的增减变化（即"变"）。 |
| 司天 | 由年地支决定的上半年（约大寒至大暑）主气，固定在客气三之气，代表当年"天之气"。 |
| 在泉 | 与司天相对、统管下半年（约大暑至大寒）的主气，代表当年"地之气"。 |
| 主气 | 一年分六步、从厥阴风木起按相生固定运行的气化序列，体现一年正常的气候次第。 |
| 客气 | 随年支而变、以司天为三之气环绕排布的六步异常气化，反映当年气候的异常起伏。 |
| 天符 | 岁运五行与司天之气五行相同，传统认为天气与岁运相合、气化偏盛的格局。 |
| 岁会 | 岁运五行与岁支本身五行相同，传统认为运气与岁支相合、气化专一的格局。 |
| 太乙天符 | 既是天符又是岁会（岁运、司天、岁支三者五行皆同），传统认为气化最盛、须重点防范的格局。 |
| 同天符、同岁会 | 阳年（太过）岁运与在泉之气五行相同为同天符，阴年（不及）岁运与在泉之气五行相同为同岁会，均为运气与在泉相合的特殊格局。 |
| 平气 | 岁运本应太过却受司天之气克制、或本应不及却受司天之气扶助而气化转趋平和的年份，传统认为灾病较轻。 |
| 胜气、复气 | 某气偏胜而乘其所胜称为胜气，被抑之气后期报复性偏胜称为复气，二者构成气化自我纠偏的循环。 |
| 郁气、发气 | 气机被抑蓄而不发为郁气，郁极而骤然爆发为发气，常表现为气候突变或疫病的集中发生。 |
| 大司天 | 把六十年甲子周期进一步推演为更长时段的整体气化格局，用以观照较长的气候与疾病变迁。 |

记忆提示：这十五个词可分三组来抓。第一组"岁运、主运、客运"是"运"这一半的三个层次，分别对应全年基调、常序、变序；第二组"司天、在泉、主气、客气"是"气"这一半，司天在泉看上下半年、主气客气看常变；第三组"天符、岁会、太乙天符、同天符同岁会、平气"是运与气相合后的特殊格局，而"胜气复气、郁气发气"是格局之下的动态调节机制，"大司天"则是把周期拉长的放大视角。

## 10_5 口诀速查

下面四组口诀是本库推演的"最小可运行指令集"。每组先给口诀，再给一条解析窍门，让你不只是背下句子，而是知道它从哪来、怎么用。

天干化运（定岁运）：甲己化土，乙庚化金，丙辛化水，丁壬化木，戊癸化火。解析：甲己为何化土而非他行，传统推演上源自"五音建运"中宫音属土、配属甲己之太少，其余四组再按方位与相生关系依次推出。记忆时抓住"土居中、木火金水绕之"的环路即可；落到年份上，阳干为太过、阴干为不及。

地支化气（定司天在泉）：子午少阴君火天，丑未太阴湿土天，寅申少阳相火天，卯酉阳明燥金天，辰戌太阳寒水天，巳亥厥阴风木天。解析：最关键的锚点是"司天永远固定在客气三之气"，拿到年支先定司天，在泉即其三阴三阳之对冲。例如子午年司天为少阴君火，则在泉必为阳明燥金；先记司天六句，再记"对冲即是在泉"，比硬背十二句更省力。

主运起序（一年五步之常）：初运木（大寒起）→二运火→三运土→四运金→终运水。解析：主运的"骨架"由节气锚定，年年不变，起点永远是大寒后的木运，体现温→热→湿→燥→寒的正常递变，与五行相生同序，所以记住"大寒起木、顺生到底"，五步就不会乱。

主气起序（一年六步之常）：初之气厥阴风木→二之气少阴君火→三之气少阳相火→四之气太阴湿土→五之气阳明燥金→终之气太阳寒水。解析：主气六步同样由节气锚定，起点永远是大寒后的厥阴风木，可记作"风→君火→相火→湿→燥→寒"，与一年时令递变严丝合缝。它与主运的区别在于：主运五步、主气六步；但二者的"常序"都不随年份改变，改变的是客运与客气。

## 10_6 学习延伸路径与边界

对运气学说有了整体框架之后，建议按"原典、临床、制度与方书、反思"四层逐层加深。顺序最好不要颠倒：先有原典根基，才看得懂后人发挥；先接通临床，才明白推演为了什么；先看制度与方书，才知道体系如何被系统化；最后用反思层收口，避免学了体系反被体系绑住。

第1步，原典层（打地基）：以《素问》运气七篇大论为总根，先读《六元正纪大论》《至真要大论》概览全貌，再回头啃《天元纪大论》《五运行大论》打基础；配明代汪机《运气易览》作入门阶梯，把干支化运、地支化气、主客运气的基本框架先在脑中搭稳。目标是"能对着任意年干支说出岁运与司天在泉"。

第2步，临床层（接通病机）：读金代刘完素《素问玄机原病式》，看运气如何被用作"火热病机"的解释工具；再读明代王肯堂《医学穷源集》，看大司天如何注解真实医案。关键是把"格局"翻译成"人易得什么病、该往哪个脏腑留意"。

第3步，制度与方书层（看系统如何被官方化）：翻北宋官修《圣济总录》的运气卷，看六十年运气图与对应的"运气方"如何被写成国家版图谱；再参考唐代《元和纪用经》，了解运气与用方的最早结合方式。这一层让人明白：运气曾被整编成可查可用的公共知识框架，如同今天医生要懂的流行病学基础。

第4步，反思层（保持清醒）：读明清诸家《运气商》《运气辩》等争鸣之作，正视"该不该逐年机械套用"的长期争论，把"参考模型、勿刻板、勿代医"内化为阅读一切运气材料的默认姿态，让体系为你所用，而不被体系所用。

还必须强调与相邻知识库的衔接：本库与命理（如铁板神数）共享干支与阴阳五行的工具语言，但落点截然不同——本库的本位在医，把年干支翻译成"运"与"气"，再读成气候、发病与养生的医学提示；命理的落点则是个人命局推演，关心一生的吉凶穷通。二者可以对照的是"同一组干支怎么被使用"的工具逻辑，但结论层面不可混为一谈：拿运气的"某年湿土太过、脾土易伤"去追问"我哪年发财"，已经跨出了运气的本位。

边界声明须重申：五运六气的推演规则（天干化运、地支化气、主客运气步序、格局判定）属可手算复现的符号体系，结果稳定可核对；但它对具体年份气候与疫病的预测效力属传统经验范畴，现代统计验证结果并不一致。本库所有"某气主某病""某年易病某脏""某格局须重点防范"等表述，均为传统医学主张或教学示例，仅供学习与研究中对照参考，不构成任何诊疗、预防或健康建议；真正涉及健康决策时，请以正规医疗与公共卫生指引为准，并把运气仅作为"因时制宜"的辅助维度。

## 10_7 一句话收束

学会运气，不是学会预言某一年，而是学会用一套严谨的干支符号，把"天时"翻译成"该在哪些方面多留意"的健康提示，并始终记得它只是参考模型，真正的主角是辨证论治与理性判断。
