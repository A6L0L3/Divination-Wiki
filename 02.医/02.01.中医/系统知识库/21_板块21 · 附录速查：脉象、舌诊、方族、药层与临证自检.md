### 21_1 脉象速查表

**四纲坐标**：浮沉定表里 · 迟数定寒热 · 有力无力定虚实 · 滑涩定气血

| 脉 | 指感 | 主病 | 现代常见对应 |
| --- | --- | --- | --- |
| **浮** | 举之有余，按之不足 | 表证；久病见之为虚阳外浮（逆） | 外感初起 |
| **沉** | 重按始得 | 里证 | — |
| **迟** | 一息不足四至（偏慢） | 寒证 | 窦性心动过缓 |
| **数** | 一息五至以上（偏快） | 热证（须先静息确认） | 发热、甲亢、贫血 |
| **滑** | 如盘走珠，往来流利 | 痰饮、食积、实热；孕妇为常 | 痰湿体质、积食 |
| **涩** | 如轻刀刮竹，艰涩不畅 | 气滞血瘀、精血亏虚 | 冠心病、术后血瘀、慢性疲劳 |
| **弦** | 端直以长，如按琴弦 | 肝郁、疼痛、痰饮 | 高血压、肝胆病、紧张状态 |
| **紧** | 弹指如转索，左右弹手 | 寒邪束表、剧痛 | 肾结石绞痛、外感寒邪 |
| **结** | 缓而时一止，止无定数 | 阴盛气结 | 各类早搏、窦房阻滞 |
| **代** | 动而中止，良久复来，止有定数 | 脏气衰（**重证，非必死**） | 规律二联律 / 三联律、房室阻滞 |
| **促** | 数而时止，止无定数 | 阳盛热实 | 快速房颤、室上速伴早搏 |
| **芤** | 浮大中空，如按葱管 | 失血、伤阴 | 大出血、严重脱水 |
| **洪** | 来盛去衰，如波涛汹涌 | 气分热盛 | 高热、甲亢 |
| **细** | 细如线，应指明显 | 气血两虚、湿证 | 贫血、慢性消耗 |
| **濡** | 浮而柔细 | 虚证、湿证 | — |
| **弱** | 沉细无力 | 气血不足 | 慢性虚弱 |
| **伏** | 推筋着骨始得 | 邪闭、厥证、痛极 | 休克、剧烈疼痛 |
| **牢** | 沉而实大弦长 | 阴寒内实、癥瘕 | 肿瘤、疝气 |

> **四时修正**：春弦、夏洪、秋毛、冬石——**脱离季节谈脉象，十有八九是错的。**
>
> **平脉基准（速记）**：四至五至、从容和缓、节律均匀、尺脉沉取有力。
>
> **操作纪律**：每次诊脉至少两侧各满五十次搏动再下结论，单侧不足一分钟会漏判节律异常。

### 21_2 舌诊卡

**观察顺序**：舌质（看正气）→ 舌苔（看邪气）→ 舌形（看形质）→ 舌态（看风痰经络）

| 舌象 | 主病 | 常见病机 |
| --- | --- | --- |
| 舌淡白而胖嫩、边有齿痕 | 阳虚、气虚、水湿 | 脾肾阳虚，水湿不化 |
| 舌淡白而瘦薄 | 气血两虚 | 化源不足 |
| 舌红、苔黄 | 实热 | 邪热亢盛 |
| 舌红、少苔或无苔 | 阴虚 | 阴液亏耗 |
| 舌绛（深红） | 热入营血 | 温病深重阶段 |
| 舌紫暗、有瘀点 | 血瘀 | 气滞寒凝或热结 |
| 舌体胖大、苔白腻 | 寒湿、痰饮 | 脾阳不运 |
| 舌苔厚腻（无论黄白） | 湿浊、食积、痰饮 | 中焦壅滞 |
| 舌苔剥落（地图舌） | 胃气阴两伤 | 久病、小儿常见 |
| 舌体歪斜 | 风痰阻络 | 中风先兆或后遗 |
| 舌体震颤 | 肝风内动 | 气血亏虚或热极生风 |

> **自学纪律**：固定光线与时段（晨起空腹、自然光）；**看趋势，不看单次**。

### 21_3 体质卡（九种）

| 体质 | 主要特征 | 调养方向 |
| --- | --- | --- |
| **平和质** | 精力充沛、睡眠好、适应力强 | 维持即可，不折腾 |
| **气虚质** | 容易疲乏、气短、自汗、易感冒 | 健脾益气，忌过劳大汗 |
| **阳虚质** | 畏寒肢冷、喜热饮、大便溏 | 温补脾肾，忌生冷 |
| **阴虚质** | 手足心热、口干咽燥、盗汗、便秘 | 滋阴润燥，忌辛辣熬夜 |
| **痰湿质** | 形体肥胖、身重困倦、苔腻 | 化痰利湿，重在运脾 |
| **湿热质** | 面垢油光、口苦口臭、苔黄腻 | 清热利湿，忌油腻辛辣 |
| **血瘀质** | 面色晦暗、易有瘀斑、刺痛固定 | 活血化瘀，注意气机 |
| **气郁质** | 情绪低落、胸胁胀、善太息 | 疏肝理气，运动与社交 |
| **特禀质** | 过敏、先天禀赋异常 | 避免过敏原，扶正固表 |

> **用法提示**：体质是"底色"，不是诊断。可兼夹（如气虚兼痰湿）。急性病仍按当下证型处理。

### 21_4 方剂家族速查（完整展开见板块8）

```plain
【补气】 四君子 → 六君 → 异功 → 香砂六君 ｜ 四君 + 山药扁豆等 → 参苓白术散
【补血】 四物 → 桃红四物 ｜ 四物 + 四君 = 八珍 → 十全大补 → 人参养荣
【补阴】 六味 → 知柏 / 杞菊 / 都气 / 麦味
【补阳】 肾气丸（六味 + 桂附）→ 右归 ｜ 理中 → 附子理中

【清热】 白虎（气分）→ 竹叶石膏（气阴两伤）｜ 清营 → 犀角地黄（血分）
【解表】 麻黄（表实）/ 桂枝（表虚）/ 银翘散（风热表重）/ 桑菊饮（风热咳重）

【理血】 血府逐瘀（气滞血瘀）｜ 补阳还五（气虚血瘀）｜ 归脾（心脾两虚）
【固涩】 玉屏风（表虚自汗）｜ 四神丸（五更泻）｜ 金锁固精类（肾虚不固）
【安神】 天王补心（心肾阴血亏虚）｜ 酸枣仁汤（肝血不足虚烦）
【疏肝】 柴胡疏肝散（纯气滞）｜ 逍遥散（气滞 + 血虚脾弱）｜ 一贯煎（肝阴虚）
```

### 21_5 药层速查（按功效分类的常用药）

| 类别 | 代表药 | 使用提示 |
| --- | --- | --- |
| **补气** | 人参、党参、黄芪、白术、山药、甘草 | 气虚夹湿者注意配伍运脾药，防滞 |
| **补血** | 当归、熟地、白芍、阿胶、龙眼肉 | 滋腻，脾虚者须配健脾 |
| **补阴** | 沙参、麦冬、天冬、百合、枸杞、女贞子 | 阴虚而无湿者宜；苔腻者慎用 |
| **补阳** | 附子、肉桂、干姜、鹿茸、杜仲、淫羊藿 | **附子须先煎减毒**，实热阴虚忌 |
| **解表** | 麻黄、桂枝、荆芥、防风、薄荷、桑叶、菊花 | 辛温辛凉方向的选错是常见失误 |
| **清热** | 石膏、知母、黄连、黄芩、黄柏、栀子、金银花、连翘 | 辨清气分血分与所在脏腑 |
| **化痰** | 半夏、陈皮、茯苓、贝母、瓜蒌、竹茹 | "治痰先治气"，常配理气药 |
| **理气** | 陈皮、枳壳、香附、柴胡、木香、砂仁 | 辛燥，气虚阴虚者慎用 |
| **活血** | 川芎、丹参、桃仁、红花、当归、益母草 | 孕妇慎用或禁用 |
| **利水渗湿** | 茯苓、猪苓、泽泻、薏苡仁、车前子 | 津液不足者不宜久服 |
| **安神** | 酸枣仁、柏子仁、远志、龙骨、牡蛎、朱砂 | **朱砂属矿物药，不作自用推荐** |

> **药物"方向"速记**：花叶质轻者多升浮（解表、升阳）；子实质重者多沉降（泻下、降气、潜降）。

### 21_6 艾灸常用穴（居家安全区）

| 穴 | 定位 | 主要作用 | 适合 |
| --- | --- | --- | --- |
| **足三里** | 外膝眼下约四横指，胫骨旁 | 健脾和胃、补益气血 | 脾胃虚弱、乏力 |
| **关元** | 脐下约四横指（腹正中） | 培补元气、温肾固本 | 虚寒、畏寒 |
| **气海** | 脐下约两横指 | 益气助阳 | 气虚乏力 |
| **中脘** | 脐上约四横指 | 和胃健脾 | 胃胀、纳差 |
| **神阙** | 肚脐中央 | 温阳健脾 | 虚寒腹泻（隔姜 / 隔盐） |
| **命门** | 后腰正中，与脐相对 | 温补肾阳 | 腰膝冷痛 |
| **大椎** | 低头时颈后最高骨突下方 | 解表散寒、通阳 | 易感冒、颈肩僵 |
| **三阴交** | 内踝尖上约四横指，胫骨后缘 | 健脾养血、调肝补肾 | 气血不足（**孕期慎用**） |

> **安全须知**：孕妇腹部腰骶部禁灸；实热、阴虚火旺者不宜温灸；糖尿病或皮肤感觉迟钝者慎灸；每穴温和灸十至十五分钟，以温热潮红为度，**不追求起泡**。

| 狼毒畏 | 密陀僧 |

> **立场说明**：十八反十九畏是传统经验禁忌的总结，历代也有反用取效的记载。它们的作用是**提示风险、要求审慎**，不是绝对的物理禁忌。
>
> **对自学者的要求**：不必背诵，但遇到这些组合应视为**需要专业判断的信号**，不自行尝试。

#### 其他禁忌

+ **妊娠禁忌**：巴豆、牵牛、大戟、斑蝥、麝香、三棱、莪术、水蛭等活血破气有毒之品
+ **证候禁忌**：麻黄对表虚自汗、阴虚盗汗不宜；石膏对脾胃虚寒不宜
+ **人群禁忌**：矿物药（朱砂、雄黄、轻粉等）一律不进入自用方案；儿科用药涉及牛黄、朱砂、巴豆等者同

### 21_8 临证自检清单（最该抄出的一页）

面对任何问题，按这十步走，不许跳步：

| 步 | 检查项 | 判定 |
| --- | --- | --- |
| 1 | **是否属于红线情况？**（急重症、神志异常、妊娠、婴幼儿、有毒药物、慢病调药） | 是 → 立即就医，不自行处理 |
| 2 | **望神**（得神 / 少神 / 失神 / 假神） | 失神、假神 → 优先级提到最高 |
| 3 | **望色望形**（两颧浮红 vs 满面通红；胖瘦） | 辨真假寒热 |
| 4 | **舌诊**（质、苔、形、态） | 记录并与既往对比 |
| 5 | **问诊关键三问**（怕冷还是怕热？有汗还是无汗？渴不渴喜冷喜热？） | 定寒热表里 |
| 6 | **问诊补充**（二便、睡眠、时间规律、情绪、既往治疗反应） | **"吃了寒凉药加重"是重要线索** |
| 7 | **切诊**（浮沉迟数有力无力；沉取为准） | 验证，不用于开局定调 |
| 8 | **三角验证**（问诊 / 望诊 / 切诊是否一致） | **不一致处是线索，不是噪声** |
| 9 | **出证型**（病位 + 病性两词即可） | 写不出证型 → 不许翻方书 |
| 10 | **选方并检查禁忌**（君臣剂量比、配伍禁忌、证候禁忌） | 有疑 → 挂起不判 |

### 案例小故事：贴在墙上的那张速查表

一位实习生把脉象、舌诊、方族速查表打印贴在诊室墙上，用起来极顺手，第一个月就敢开方了。

半年后带教老师发现：他遇到表上有的证，处理得很快；遇到表上没有的，就完全卡住，只会问"老师这个该用什么方"。

老师把那张表撕下来，让他先写辨证，写完才准看表。三个月后他开方慢了一半，但方子开始有自己的逻辑。

**落点**：速查表是拐杖，不是腿。用它起步、用它校验，不要用它替代辨证——辨证这一步，任何表都替不了你走。
