## 板块8 · 方剂：配伍的语法与剂量的方向性

> **单味药是零件，方剂是整机**。本板块的核心洞见是两条：**配伍有语法**（辛开苦降、甘温除热、培土生金等固定句式）；**剂量即方向**（君药与佐药的用量比，直接暴露了作者判断的主要矛盾）。
>
> 末尾的禁忌一节讲"什么不能搭"——**会用方的人很多，知道什么不能同用的人太少**。

### 8_1 君臣佐使：不是礼貌排序，是病机权重的量化

君臣佐使最常见的误读，是把它当成"地位排行"。实际上它是**病理严重程度的量化表达**。

> **读方的最有效方法**：拿到任何一张方，先看"君药用量 / 佐药用量"的比值，就能反推出作者判断这个病的**主要矛盾在哪**。这是最被低估的读方方法。

《医方集解》里最精彩的示范是六味地黄丸的"钱氏加减法"：

> 血虚阴衰 → 熟地为君；精滑头昏 → 山茱为君；小便多少不调 → 茯苓为君；小便淋沥 → 泽泻为君；心虚火盛及有瘀血 → 丹皮为君；脾胃虚弱、皮肤干涩 → 山药为君。言为君者，其分用八两，地黄只用臣分两。

**这是全书的金矿**：同一个骨架，把主药从三两提到八两，整张方的重心就跟着转移了。**方不变，君臣易位，治的病就变了。**

```plain
   六味地黄丸（同一骨架，君臣易位 → 主治改变）

   熟地 升为君 ──→ 主治转向：血虚阴衰
   山茱 升为君 ──→ 主治转向：精滑头昏
   茯苓 升为君 ──→ 主治转向：小便多少不调
   泽泻 升为君 ──→ 主治转向：小便淋沥
   丹皮 升为君 ──→ 主治转向：心虚火盛、有瘀血
   山药 升为君 ──→ 主治转向：脾胃虚弱、皮肤干涩
   （其余五味退为臣分两）

```

> **可落地的训练动作**：拿到任何一张方，先标出君臣佐使，再问——"如果我把臣药加倍变成君，这张方会变成治什么？"练熟这个思维，临床加减就不再是碰运气。

### 8_2 药对：把方拆成"对"而不是"单"来记

《医方集解》全书最高明的部分，是讲清了药与药之间的**张力关系**。掌握这几组关系，等于拿到了化裁的钥匙：

| 关系 | 药对 | 机制 |
| --- | --- | --- |
| **散与收** | 桂枝 ↔ 芍药 | 发汗中寓敛汗，和营中有调卫 |
| **补与泻** | 熟地、山茱萸 ↔ 泽泻、丹皮 | 补少阴之虚，兼泻浊 |
| **升与降** | 桔梗 ↔ 枳壳 | 一升一降，宽胸利膈 |
| **辛甘化阳** | 桂枝 + 甘草 | 辛散与甘缓合力化生阳气 |
| **酸甘化阴** | 芍药 + 甘草 | 酸收与甘缓合力化生阴液 |
| **气血并调** | 当归、川芎 + 陈皮、枳壳 | 血分与气分同调 |

**基础药对储备（必须先背熟）**：

+ 疏肝基础对：柴胡 + 白芍
+ 健脾基础对：参 + 白术 + 茯苓 + 甘草（四君子）
+ 调和营卫对：桂枝 + 白芍
+ 燥湿化痰对：半夏 + 陈皮 + 茯苓（二陈）
+ 理气健脾对：陈皮 + 枳壳
+ 养血基础对：当归 + 川芎 + 白芍 + 地黄（四物）

> **判断自己读懂与否的标准**：能不能一句话说出"这味药是和谁配对的、解决结构里的哪一处失衡"。说不出来，就是死记硬背。

### 8_3 方剂家族树：比分类更高效的记忆单位

与其逐首死背方歌，不如**先立若干"基础方"节点，再沿加减关系生长出全树**。

```plain
四君子汤（补气基础方）
  ├─ +半夏、陈皮 = 六君子汤（祛痰补气）
  │     ├─ 减半夏 = 异功散
  │     └─ +木香、砂仁 = 香砂六君子汤（温胃散寒）
  └─ +山药、扁豆等 = 参苓白术散（健脾渗湿，培土生金）

四物汤（补血基础方）
  ├─ +桃仁、红花 = 桃红四物汤（养血活血）
  └─ +四君 = 八珍汤（气血双补）
        └─ +黄芪、肉桂 = 十全大补汤
              └─ 加减 = 人参养荣汤（气血两虚偏重心悸失眠）

六味地黄丸（补肾基础方）
  ├─ +知母、黄柏 = 知柏地黄丸（滋阴降火）
  ├─ +枸杞、菊花 = 杞菊地黄丸（养肝明目）
  ├─ +五味子 = 都气丸（纳气平喘）
  └─ +麦冬、五味 = 麦味地黄丸（肺肾两虚之咳喘）

肾气丸（六味 + 桂附，温补肾阳）
  └─ 减"三泻" + 鹿胶、杜仲等 = 右归丸（纯补无泻）

理中丸（温中祛寒）
  └─ +附子 = 附子理中丸（脾肾双温）

二陈汤（燥湿化痰基础方）
  ├─ +竹茹、枳实等 = 温胆汤（清胆和胃化痰）
  └─ +天麻、白术 = 半夏白术天麻汤（风痰眩晕）

小柴胡汤（和解少阳）
  └─ 去参、枣，加大黄、枳实等 = 大柴胡汤（少阳阳明合病）

桂枝汤（调和营卫）
  ├─ 加重桂枝 = 桂枝加桂汤（平冲降逆，治奔豚）
  └─ 倍芍药 + 饴糖 = 小建中汤（温中补虚、和里缓急）

```

**记忆效率的关键**：一棵家族树记下来，等于记住了十几首方，而且**自动带出了加减逻辑**。

### 8_4 配伍的"语法"：几种固定句式

配伍不是随意堆药，它有若干固定句式。掌握句式，就能读懂陌生方剂，也能自己组方。

| 句式 | 含义 | 代表方 | 适用 |
| --- | --- | --- | --- |
| **辛开苦降** | 辛温（开）与苦寒（降）同用，调畅气机、消痞散结 | 半夏泻心汤 | 寒热错杂、痞满呕利 |
| **甘温除热** | 用甘温之品治气虚发热，而非苦寒直折 | 补中益气汤 | 气虚发热（劳累后热、自汗、脉虚大） |
| **培土生金** | 健脾以益肺，不直接治肺 | 参苓白术散 | 脾虚久咳、反复外感 |
| **滋水涵木** | 补肾阴以制肝阳 | 杞菊地黄丸 | 肝阳上亢之眩晕（本在肾阴亏） |
| **培土抑木** | 健脾以平肝气之横逆 | 痛泻要方 | 肝脾不和之痛泻 |
| **补气生血** | 重用补气药以生血（有形之血不能速生） | 当归补血汤（黄芪五倍于当归） | 血虚发热、气血两虚 |
| **益气活血** | 大剂量补气药配少量活血药 | 补阳还五汤（黄芪用量极重） | 气虚血瘀之中风后遗 |
| **阴中求阳** | 补阳方中配补阴药 | 肾气丸（桂附配地黄、山茱萸） | 阳虚证 |
| **阳中求阴** | 补阴方中配补气 / 温药 | 补阴方佐参芪之类 | 阴虚证 |
| **散收并用** | 散邪与收敛同用，防散之太过 | 桂枝汤（桂枝配芍药）、小青龙汤（干姜细辛配五味芍药） | 表证兼虚、久咳 |

> **最值得体会的一条**：**当归补血汤**里黄芪用量五倍于当归。它的逻辑是"有形之血不能速生，无形之气所当急固"——大出血后气随血脱，此时补气比补血更急。这就是"剂量即方向"的最直观体现。

### 8_5 《医方集解》：以法统方的二十一门

《医方集解》是清初汪昂（字讱庵）所著，成书于康熙二十一年，全书三卷，**以法统方分二十一门**，载正方三百八十余首、附方三百余首。它的原创贡献正是"以法统方"——现代方剂学教材的章节体系即脱胎于此。

二十一门的排布顺序本身就是一张诊疗地图：

```plain
   补养 → 发表 → 涌吐 → 攻里 → 表里 → 和解 → 理气 → 理血
     → 祛风 → 祛寒 → 清暑 → 利湿 → 润燥 → 泻火 → 除痰
     → 消导 → 收涩 → 杀虫 → 明目 → 痈疡 → 经产
   （末附"救急良方""勿药元诠"）

```

> **这个顺序藏着治疗优先级**：先扶正（补养居首，因"不治已病治未病"），再祛邪（汗吐下三途），再调气血、御六淫，最后才是专科与救急。
>
> **书末附"勿药元诠"尤其意味深长**——全书以"可以不药"收尾，这是一位医家敢说真话的底气。

**作者局限（必须提前知道的"坑"）**：汪昂是儒士而非职业医生，没有长年坐馆应诊的经历。这意味着《医方集解》的方义推演极精，但临床实操细节偏薄。**读它必须与医案书配合使用**——前者教你想清楚，后者教你做出来。

### 8_6 《汤头歌诀》：先解其义，后诵其文

汪昂另著《汤头歌诀》，刊于康熙三十三年。书名中"汤头"二字，就是"方剂的套路、规格"——前人制方，某方某药各有成规，加减虽有变通，治法不逾正则。全书选录常用方剂三百余首，编为约二百首方歌，**分为二十类**，每方以七言歌诀概括方名、药味、功效、主治、加减、剂量、剂型，并附简要注释。

#### 三种常见误读

| 误读 | 真实情形 | 本书的立场 |
| --- | --- | --- |
| 它是"方剂学教材" | 它是**方剂启蒙书**，成书早于现代学科体系 | 当索引与骨架，不当全部知识 |
| 背熟歌诀就能开方 | 歌诀只给"方剂轮廓"，不给"病机判断" | 歌诀是钥匙，**辨证才是锁孔** |
| 是过时的古文 | 其分类逻辑与配伍范式至今仍是《方剂学》教材的底层结构 | 它是活的思维工具，而非文物 |

#### 二十类目录（按功效分门）

| 卷 | 类别 | 主方 / 附方 | 卷 | 类别 | 主方 / 附方 |
| --- | --- | --- | --- | --- | --- |
| 1 | 补益之剂 | 10 / 7 | 11 | 祛寒之剂 | 12 / 2 |
| 2 | 发表之剂 | 14 / 8 | 12 | 祛暑之剂 | 5 / 10 |
| 3 | 攻里之剂 | 7 / 4 | 13 | 利湿之剂 | 13 / 8 |
| 4 | 涌吐之剂 | 2 / 6 | 14 | 润燥之剂 | 13 / 2 |
| 5 | 和解之剂 | 9 / 5 | 15 | 泻火之剂 | 27 / 9 |
| 6 | 表里之剂 | 8 / 5 | 16 | 除痰之剂 | 10 / 5 |
| 7 | 消补之剂 | 7 / 6 | 17 | 收涩之剂 | 9 / 2 |
| 8 | 理气之剂 | 11 / 8 | 18 | 杀虫之剂 | 2 / — |
| 9 | 理血之剂 | 13 / 6 | 19 | 痈疡之剂 | 6 / 2 |
| 10 | 祛风之剂 | 12 / 4 | 20 | 经产之剂 | — |

> **一个必须建立的元认知**：歌诀压缩的是"方证对应"——方剂的适用边界被押成了韵。学习的第一原则应是**先解其义，后诵其文**。把方歌当顺口溜死背，就是"小和尚念经，有口无心"；真正要到病人身上发挥作用、自己组方，必须先把配伍逻辑拆开。

> **两本书怎么配合**：《汤头歌诀》是"记住轮廓"的韵文本，《医方集解》是"弄清为什么"的推演本。一快一慢，一记一思，缺一不可。

### 8_7 八阵：另一种分类维度

张景岳以兵法"八阵"重构方剂分类，把补、和、攻、散、寒、热、固、因八法统摄全部方论。它不是静态的"八格抽屉"，而是动态的**八种作战模式**：

| 阵名 | 兵法对应 | 核心使命 | 临床本质 |
| --- | --- | --- | --- |
| 补阵 | 粮草补给 | 填补根本 | 虚证——正气不足 |
| 和阵 | 外交斡旋 | 调和平乱 | 虚实之间——不宜猛攻猛补 |
| 攻阵 | 正面决战 | 攻逐实邪 | 实证——邪气盛 |
| 散阵 | 边防驱逐 | 解表散邪 | 表证——邪在肌表 |
| 寒阵 | 水攻灭火 | 清热泻火 | 热证——阳亢伤阴 |
| 热阵 | 火攻驱寒 | 温里散寒 | 寒证——阴极亡阳 |
| 固阵 | 城防加固 | 收敛固涩 | 滑脱——元气不固 |
| 因阵 | 特种机动 | 因证制宜 | 杂证——难以归类者 |

> **关键洞见**：面对一个病症，先判断该用哪一阵（战略决策），再从该阵中选方（战术执行），最后随证加减（临场应变）。
>
> **用药如用兵的立论根基**在于："药不执方，合宜而用，此方之不必有也；方以立法，法以制宜，此方之不可无也。"——方既不可执，又不可废，解决之道是建立一套**检索逻辑**，这就是八阵的本质。

景岳把八阵分为两套：**古方八阵**收录历代经典名方一千五百余首，是"前人经验的精华提炼"；**新方八阵**是他的自拟方一百八十余首，是"补充古法未备之处"。**古方是"经典教材"，新方是"临床笔记"**，二者互为参照。八阵之外另列妇人、小儿、痘疹、外科四方，照顾专科特殊性。

### 8_8 三层方根体系：把方剂挂回辨证链条

《中医内科方剂索引》最容易被"按笔画罗列"的形式带偏。真正要建立的，是三层认知骨架。

**第一层 · 基础方（药出有理）**：一个治法的最小完整单元，是后续所有加减的"种子"

| 治法 | 基础方 |
| --- | --- |
| 外感风寒表实 | 麻黄汤 |
| 外感风寒表虚 | 桂枝汤 |
| 表邪未解、邪热壅肺之喘咳 | 麻杏石甘汤 |
| 伤寒少阳证 | 小柴胡汤 |
| 阳明气分热盛 | 白虎汤 |
| 疏肝理脾 | 四逆散 |
| 阳明腑实证 | 大承气汤 |
| 中焦脾胃虚寒 | 理中丸 |
| 脾胃气虚 | 四君子汤 |
| 补血调经 | 四物汤 |
| 补气生血 | 当归补血汤 |
| 肝肾阴虚 | 六味地黄丸 |
| 燥湿化痰 | 二陈汤 |
| 湿滞脾胃 | 平胃散 |
| 温阳利水 | 真武汤 |

**第二层 · 代表方（治出有法）**：在基础方上体现明确治法取向

逍遥散（疏肝健脾）、半夏泻心汤（寒热平调、辛开苦降）、补中益气汤（补气升阳、甘温除热）、越鞠丸（气血痰火湿食六郁）、补阳还五汤（益气活血）、杏苏散（清宣凉燥）、苓桂术甘汤（中阳不足痰饮）。

**第三层 · 常用方（方出有名）**：直接对应内科常见证型的"一线方"

小青龙汤（外寒内饮喘咳）、银翘散（风热表证）、桑菊饮（风热犯肺咳嗽）、痛泻要方（肝脾不和痛泻）、竹叶石膏汤（热病后期气阴两伤）、龙胆泻肝汤（肝胆实火上炎）、泻白散（肺热喘咳）、清胃散（胃火牙痛）、玉女煎（胃热阴虚牙痛）、当归六黄汤（阴虚火旺盗汗）、当归四逆汤（血虚温经散寒）、小建中汤（调和阴阳、柔肝理脾）、
参苓白术散（脾虚湿盛泄泻）、生脉散（气阴两虚）、玉屏风散（表虚自汗）、完带汤（脾虚肝郁湿浊下注）、归脾汤（心脾气血两虚）、一贯煎（阴虚肝郁胁痛）、肾气丸（补肾助阳）、四神丸（命门火衰五更泻）、天王补心丹（心肾阴血亏虚神志不安）、半夏厚朴汤（痰气互结梅核气）、苏子降气汤（上实下虚咳喘）、旋覆代赭汤（胃虚痰阻气逆）、
橘皮竹茹汤（胃虚有热呃逆）、川芎茶调散（外感风邪头痛）、牵正散（风痰阻络）、消风散（风疹湿疹）。

> **读书法**：不要按笔画死记，要把每一个方"挂"到三层中的某一层。看到一个新方，先问三句话——它**继承自哪个基础方**？它**突出哪种治法**？它**主治哪种内科证型**？

### 8_9 配伍禁忌：什么不能搭

**会用方的人很多，知道什么不能同用的人太少。** 完整卡片见板块21，这里只给判断原则与风险类别。

### 8_10 案例小故事：一首方，君臣易位变成三张方

**背景**：桂枝汤（桂枝、芍药、生姜、大枣、甘草）是《伤寒论》第一方，被后世称为"群方之魁"。很多人记住了它的五味药，以为"记住组成 = 记住方"。

**经过**：一位学方剂不久的年轻医生，在门诊接连遇到两位病人。

第一位是位五十来岁的女性，主诉"一阵阵有气从小肚子往上冲到胸口，冲上来时心慌得厉害，过后又平复如常"。发作没有规律，情绪紧张时容易触发。

第二位是个瘦弱的男学生，主诉"肚子隐隐作痛，绵绵不休，喜温喜按"，伴心悸、面色少华、容易疲倦、食欲一般。

年轻医生看了两遍，觉得这两位都"有点像桂枝汤证"——毕竟都有心悸、都偏虚。于是都开了桂枝汤原方。两周后，两位都回来说：没什么变化。他百思不得其解：辨证没错啊，方子也是经方啊。

**转机**：带教老师看了两张处方，只改了用量和一味药——

+ **第一位**改为**桂枝加桂汤**：加重桂枝用量。桂枝本有平冲降逆之功，加重之后，全方重心从"调和营卫"转向"温通心阳、平冲降逆"，正对"气从少腹上冲心"的奔豚
+ **第二位**改为**小建中汤**：倍用芍药、再加饴糖（重用甘味）。全方重心从"解肌发表、调和营卫"转向"温中补虚、和里缓急"，正对"腹中急痛、心悸、虚劳"

两人改方后，症状都在一周内明显缓解。而两人当初吃的，其实都是原方——只是比例不对。

**复盘**：三张方的药物组成几乎相同，差别只在一味药的用量和一味新加的药。这说明**方剂的本质不是"药的集合"，而是"剂量关系构成的结构"**。背组成不背剂量，等于记住了零件清单却不知道装配比例。

用一句可以记住的话收尾：**看方先看比例，不看比例等于没看方。**

### 8_11 本板块的笔记动作与验证

**笔记动作**：每学一首方，写一张"方解卡"，固定七栏：出处、组成（带剂量）、君臣佐使标注、剂量比、配伍语法（属于哪种句式）、主治证型、加减要点。**合上书能重画剂量比，才算过关。**

**验证方法（三选一）**：

1. **君臣易位推演**：把六味地黄丸中的泽泻提到君药分量，说出这张方会转向主治什么（答案：小便淋沥）。
2. **句式识别**：说出半夏泻心汤属于哪种配伍句式，并解释其机制（答案：辛开苦降——干姜、半夏之辛开，芩、连之苦降，治寒热错杂之痞）。
3. **家族树补完**：不看书，默写出四君子汤至少四条加减分支（六君、异功、香砂六君、参苓白术散）。
