## 板块19 · 综合实战：一个病例走完全流程

> **这一板块是整套知识库的"结业考试"**：用一个完整病例，把前面各板块的工具串起来走一遍。
>
> **本章案例为教学演示，不构成医疗建议。** 所有方药方向仅为推演示范，实际用药须经执业医师辨证。

---

### 19_1 病例呈现

**主诉**：女，四十二岁，反复头面烘热、口腔溃疡半年，伴下肢冰凉、大便溏薄。

**既往经过**：曾自行服用"清火"类中成药，初服稍缓，久则胃脘胀满、食欲下降、溃烂面更难愈合。

---

### 19_2 四诊采集（按固定顺序，不跳步）

**望**：面色偏白，两颧午后泛红（**浮红，非满面通红**）；舌淡胖、边有齿痕、苔白微腻，舌尖略红；唇色淡。

**闻**：语声偏低弱，无口臭。

**问**：

- 寒热？自觉上火，但**喜温恶凉**，冬天症状加重
- 汗？白天动则汗出（自汗倾向），夜间不明显
- 饮食？纳差，食后腹胀，喜热饮
- 二便？大便溏薄、日一至二次，小便清长
- 睡眠？入睡可但易醒
- 时间规律？**入暮后烘热加重，清晨觉疲乏但烘热轻**

**切**：脉浮取略数，中取无力，**沉取细弱，尺部尤甚**。太溪穴按压酸软，太白穴局部发凉。

#### 19_2_1 三个独立信源的交叉检查

| 信源 | 指向 | 提示 |
| --- | --- | --- |
| 问诊（喜温恶凉、便溏、自汗、入暮加重） | 阳虚 / 脾肾不足 | 偏虚、偏寒 |
| 望诊（舌淡胖齿痕、苔白腻、颧红浮于表） | 气虚夹湿，虚阳上浮 | 偏虚 |
| 切诊（沉取细弱、尺部尤甚、太溪酸软） | **肾气不足** | 病位在下焦 |

> **不一致点（最重要的线索）**：病人主诉"上火"，但三个信源全都指向虚寒。
>
> **这个矛盾不是要抹平的噪声，而是破题的钥匙。**（原理见板块18）

### 19_3 辨证推演

#### 19_3_1 第一步｜八纲粗筛

| 纲 | 判断 | 依据 |
| --- | --- | --- |
| 阴阳 | **阴证**（虽有热象但为假象） | 喜温恶凉、病程久、脉沉取无力 |
| 表里 | **里** | 病程半年、无表证 |
| 寒热 | **本寒标热**（真寒假热） | 下肢冰凉、便溏 vs 头面烘热 |
| 虚实 | **虚** | 脉沉取无力、病程半年、久服寒凉更甚 |

#### 19_3_2 第二步｜排除误诊（对举法）

**是实火还是虚火？**
实火当见：满面通红、口渴喜冷、便秘、脉洪实有力。
本例：颧红浮于两颧（非满面）、喜热饮、便溏、脉沉取无力 → **全部不符，非实火**。

**是阴虚火旺还是阳虚浮火？**
阴虚当见：盗汗、五心烦热、舌红少苔、脉细数。
本例：自汗而非盗汗、舌淡胖而非红瘦、喜温恶凉、苔白腻 → **非阴虚，是阳虚浮火**。

#### 19_3_3 第三步｜用景岳的时间辨证法验证

景岳的规律是：**阳虚者朝轻而暮重**（白天阳气得天时之助尚可支撑，入暮阳衰则症状加重）。

本例**入暮烘热加重、清晨减轻** → 偏阳虚，与景岳所论相合。

#### 19_3_4 第四步｜定位病机

- **病位**：脾（纳差、便溏、舌淡胖齿痕）+ 肾（尺部沉弱、太溪酸软、下肢冰凉）
- **病性**：阳气虚，虚阳浮越于上 → **上热下寒**
- **关键机制**：中焦脾胃阳虚，气机升降枢纽失职，阳气不能下归，反浮于上 → 头面烘热、口疮；下部失于温煦 → 肢凉、便溏
- **呼应《褚氏遗书》**：阳气虚弱不能正常运行阴气，则阳气独治而为热——**这个"热"是气运行被打断的结果，不是热邪有余**

#### 19_3_5 第五步｜检查是否有奇经 / 络病参与

病程半年、反复发作、久服清火药无效 → 符合《奇经八脉考》"越补越漏、久治不愈"的奇经病特征。

可考虑：病涉任督（颧红浮于表、腰膝下肢症状），中期可酌加固摄之品。**但这一步是"锦上添花"，不是主线**——主线仍是脾肾阳虚、虚阳上浮。

```plain
   脾肾阳虚（本）
        │
        ├── 中焦升降枢纽失职 ──→ 阳气不归其位
        │                            │
        │                            ▼
        │                    虚阳浮越于上 ──→ 头面烘热、口疮（标热）
        │
        └── 下部失于温煦 ────────────────→ 下肢冰凉、便溏（本寒）

```

### 19_4 立法与选方

#### 19_4_1 治则

**温补脾肾之阳，引火归元；兼顾中焦升降；佐以固摄。**

三条要点：

1. **不可用苦寒直折**——虚火不是火邪有余，苦寒只会更伤阳气（病人已经验证了：久服清火药后胃胀、纳差、溃疡更难愈合）
2. **补阳须"阴中求阳"**——温阳方中配补阴 / 补精之品（如桂附配熟地之例），否则阳无依附，暂热复凉
3. **护住中焦**——脾虚不运时，温补药本身也可能成为负担，须配运脾理气之品

#### 19_4_2 方药方向（仅为推演示范）

| 层次 | 方向 | 思路 |
| --- | --- | --- |
| **温补肾阳** | 肾气丸类方向（桂附配地黄、山药、山茱萸等） | "阴中求阳"的典范结构 |
| **温运脾阳** | 理中类 / 附子理中方向 | 恢复中焦升降枢纽 |
| **引火归元** | 少量温热药下行 + 佐以潜降 | 使浮越之阳归位，而非清其上热 |
| **固摄（可选）** | 病程久者酌加固涩之品 | 对应久病"越治越漏"的特征 |
| **运脾防滞** | 配陈皮、砂仁之类 | 防止温补药滋腻碍脾 |

> **关键的用药逻辑**：不是"清上热、温下寒"两面下手，而是**温下为主、上热自降**。因为上热的根源是阳气不在其位，把下焦温起来、把中焦枢纽修好，浮越之阳自会归位。这就是"治病求本"。
>
> **剂量与有毒药物（附子等）一律须由执业医师处方，本处不作任何克数建议。**

#### 19_4_3 为什么不能用清热药：误治代价分析

| 处理 | 短期 | 长期 |
| --- | --- | --- |
| 苦寒清热 | 热象暂减（阳气被压） | **阳气更伤 → 浮火更甚 → 溃疡更难愈合 + 脾胃受损** |
| 温补引火归元 | 可能短暂"热加重"的错觉 | 阳归其位，烘热与口疮逐步消退 |

> **这个"短暂加重"是临床常见的现象**，需要在治疗前与病人说明——否则病人一见热象加重就自行停药或改回清火药，前功尽弃。

### 19_5 复诊与调整

#### 19_5_1 复诊看什么（按优先级）

| 指标 | 期望变化 | 意义 |
| --- | --- | --- |
| **大便** | 由溏薄转成形 | 脾阳恢复的最直接证据 |
| **胃纳** | 纳增、食后腹胀减轻 | 中焦运化恢复 |
| **下肢温度** | 由冰凉转温 | 阳气达于四末 |
| **烘热频率与程度** | 发作减轻 | 浮阳渐归 |
| **睡眠** | 易醒改善 | 神气渐安 |
| **舌象** | 齿痕变浅、苔腻渐化 | 脾虚与湿象改善 |
| **脉象** | 沉取渐有力，尺部改善 | 肾气渐复 |

> **判断疗效的正确顺序**：**先看本（便、纳、肢温），再看标（烘热、口疮）**。标症改善通常滞后于本症，若只盯着"溃疡好了没有"，容易过早否定有效的方向。

#### 19_5_2 调整的原则

1. **方向不变，微调剂量与配伍**——慢性病见效慢，不宜频繁改方
2. **脾胃为先**——若出现纳差腹胀加重，先处理中焦，减温补之量
3. **随季节调整**——冬季可稍加重温补，夏季宜减轻温燥之品（"用热远热"）
4. **中病即止与长期调养的界限**——急则治标（症状重时集中处理），缓则治本（症状缓解后转为丸剂或食疗长期调）

### 19_7 完整流程图

```plain
   采集 ──→ 望（颧红浮于表·舌淡胖齿痕）
      │     闻（语声低弱）
      │     问（喜温恶凉·便溏·自汗·入暮加重）
      │     切（沉取细弱·尺部尤甚）
      ▼
   三角验证 ──→ 三源一致指向虚寒，与主诉矛盾 ──→ 矛盾即线索
      ▼
   八纲粗筛 ──→ 阴 · 里 · 本寒标热 · 虚
      ▼
   对举排除 ──→ 非实火（无满面红·不渴冷饮·便溏·脉无力）
      │         非阴虚（无盗汗·舌不红瘦·喜温）
      ▼
   时间验证 ──→ 入暮加重 ──→ 阳虚（相合）
      ▼
   定位病机 ──→ 脾肾阳虚 + 中焦升降失职 ──→ 虚阳浮越（上热下寒）
      ▼
   立法 ──→ 温补脾肾 · 引火归元 · 阴中求阳 · 运脾防滞
      ▼
   选方 ──→ 肾气丸类 + 理中类方向（温下为主，不清上热）
      ▼
   复诊 ──→ 先看便、纳、肢温；再看烘热、口疮

```

### 19_8 如果她当初第一步就做对：一条对照路径

把时间倒回半年前，看看哪些节点可以改写结局。

| 节点 | 她实际做的 | 如果做对，会是什么 |
| --- | --- | --- |
| **第一次溃疡时** | 直接判为"上火"，服清热药 | 先问三句：怕冷还是怕热？渴不渴、想喝凉的还是热的？早上重还是晚上重？——**喜温恶凉 + 入暮加重**这两条立刻指向虚寒 |
| **服清火药"稍缓"时** | 视为方向正确的证据 | 视为**警告**：寒凉只能暂时压住浮阳，压得住说明不是实火；若真是实火，清热当彻底缓解而非"稍缓" |
| **出现胃胀纳差时** | 以为是"药太凉伤了胃"，继续服 | 视为**关键证据**：脾胃已伤，说明本虚；此时应立即停清火、就医 |
| **半年不愈时** | 继续加大清热力度 | 触发"久病思奇经 / 换坐标系"的检查（板块3），并做三角验证 |

> **最值得记住的一条**：她其实拥有全部线索——**喜温恶凉、久服寒凉更甚、入暮加重、大便溏薄**，每一条都指向虚寒。她缺的不是信息，而是**一个把信息组织起来核对的流程**。这正是本知识库要提供的东西：**不是更多知识，而是一个每次都照走的顺序。**

### 19_9 案例小故事：同一位失眠病人，两位医生

同一位四十岁女性，主诉失眠三个月。

第一位医生听完主诉就开安神方，两周无效，加量，仍无效。

第二位医生按流程先问：几点入睡、几点醒、醒后能否再睡；再问饮食、二便、月经、情绪与工作压力。问到第四句才发现，她近半年晚饭常推迟到九点以后，且"胃中嘈杂、嗳气"。

按"胃不和则卧不安"从脾胃入手，先调饮食时间、再和中消滞，两周后入睡时间提前，安神药始终没用上。

**落点**：流程的全部价值，在于把"直接开方"挡在第一步之前。四诊不全，方子越对症越容易跑偏。

### 19_10 本板块的笔记动作与验证

**笔记动作**：自己走一遍。找一个真实问题（或古籍医案），用 19_7 的流程图完整推演一遍，写出每一步的判断与依据。**关键约束：不许跳过"三角验证"与"对举排除"两步**——这两步最容易被省略，也最有价值。

**验证方法（三选一）**：

1. **矛盾识别**：这个病例中，哪一个信号最先提示"主诉不可靠"？（答案：喜温恶凉 + 久服清火药后反而加重）
2. **阴阳判断**：说出三条支持"阳虚"而非"阴虚"的证据（自汗非盗汗 / 舌淡胖非红瘦 / 喜温恶凉）。
3. **治则理解**：为什么不直接"清上热、温下寒"两面下手？（答案：上热是阳气不归位所致，温下使阳归其位则上热自降，清上反更伤阳）
