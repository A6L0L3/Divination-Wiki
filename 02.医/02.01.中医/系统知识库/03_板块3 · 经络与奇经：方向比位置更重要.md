## 板块3 · 经络与奇经：方向比位置更重要

> **经络是调控网络，不是血管神经**。本板块解决两个问题：十二经怎么走（方向），以及当常规思路失效时该换哪套坐标系（奇经）。
>
> 穴位的定位细节与刺灸操作在板块11展开，本板块不重复。

### 3_1 十二经：一条必须先记住的方向规则

《铜人针灸经》里有一条底层设定，必须先看懂：

> 手三阳之脉从手至头，手三阴之脉从手至胸；足三阳之脉从足至头，足三阴之脉从足至胸。是谓日夜循环，阴阳会合。

**方向错了，后面迎随补泻全部反着做。**

```plain
                     头（诸阳之会）
                           ▲
        手三阳 ↑            │            ↑ 足三阳
                           │
    手 ───────────────────────────────────→ 足
                           │
        手三阴 ↓            │            ↓ 足三阴
                           ▼
                     胸（阴之所聚）

```

- **阴经向心、阳经离心**（头为诸阳之会，胸为阴之所聚）
- **临床取穴的隐藏红利**：四肢末端穴位的作用域可以覆盖远端脏腑。井穴在指（趾）端而能治五脏满闷，原理就在此处——**经气由此出入，是流量最大的"关卡"**

### 3_2 五输穴：经络上最高频的操作接口

> 所出为井，所流为荥，所注为俞，所过为原，所行为经，所入为合。

以肺经为例：井**少商** → 荥**鱼际** → 输**太渊** → 经**经渠** → 合**尺泽**。

> **一个高频记忆错误**：很多人把**列缺**当成肺经原穴——错。列缺是络穴，**肺经的原穴是太渊**。
>
> 规律是：**阴经"以输代原"，输穴就是原穴**（太渊既是肺经输穴，也是肺经原穴）；**阳经在输穴之后另有独立原穴**（如大肠经输穴是三间，原穴却是合谷）。这也是为什么阴经五输是"井荥输经合"五个，阳经却是"井荥输原经合"六个。

#### 3_2_1 五输主病：可直接做成卡片贴在工作台上

| 穴类 | 主治 | 典型穴 | 适用场景 |
| --- | --- | --- | --- |
| **井** | 心下满（满闷）、急救醒神 | 少商、隐白 | 急救、神志、五脏满闷 |
| **荥** | 身热 | 鱼际、内庭 | 热证、咽喉肿痛 |
| **输** | 体重节痛 | 太渊、太白 | 关节痛、湿重 |
| **经** | 喘咳、寒热 | 经渠、复溜 | 咳喘、外感寒热 |
| **合** | 逆气而泄（胃肠病） | 尺泽、足三里 | 胃肠病、气机上逆 |

#### 3_2_2 气血在五输中的流注意象

```plain
   井（源头·气血初出）→ 荥（小流）→ 输（灌注）→ 经（畅行）→ 合（汇入）
   指趾末端 ─────────────────────────────────────→ 肘膝关节
   病愈深者，取穴愈下（合穴治脏腑）；病在表浅者，取穴愈上（井荥治热、治神）

```

> **《难经》的补充**：第六十二至六十八难专论俞穴，提出"井主心下满、荥主身热、俞主体重节痛、经主喘咳寒热、合主逆气而泄"的应用纲领，并把五输配五行（阴经井木、荥火、俞土、经金、合水；阳经井金、荥水、俞木、经火、合土），成为后世"补母泻子"针法的理论基础（见板块11）。

### 3_3 奇经八脉：八条"蓄水池"经络

《奇经八脉考》是李时珍在滑寿《十四经发挥》基础上的进一步精核。全书最有解释力的一句话在总说：

> **正经犹夫沟渠，奇经犹夫湖泽。正经之脉隆盛，则溢于奇经。**

| 概念 | 对应物 | 功能 |
| --- | --- | --- |
| 十二正经 | 沟渠（主干河道） | 如环无端的常规气血循环 |
| 奇经八脉 | 湖泽（蓄水池） | 收容"流溢之气"，蓄溢调节 |
| 奇经为病 | 湖泽淤塞或决口 | 溢则妄行，虚则失守 |

> **这个隐喻的临床含义极其关键**：正经的病是"河道堵了"，奇经的病是"水库出了问题"——**溢、蓄、摄、固的功能失常**。
>
> 因此，所有反复发作、久治不愈、越补越漏的慢性病（崩漏、遗精、久泻、内伤发热、痿证），当常规辨证无效时，思维就该转向奇经。**这是留给临床的第一条金钥匙。**

#### 3_3_1 八个字的空间坐标系

李时珍给八脉建立了一个空间模型，务必先记住：

| 脉 | 方位 | 功能定位 |
| --- | --- | --- |
| 阳维 | 表（乾） | 维系一身之表 |
| 阴维 | 里（坤） | 维系一身之里 |
| 阳跷 | 左右之阳（东） | 主肢体左右之阳 |
| 阴跷 | 左右之阴（西） | 主肢体左右之阴 |
| 督脉 | 身后之阳（北） | 阳脉之海 |
| 任脉 / 冲脉 | 身前之阴（南） | 阴脉之海 / 十二经之海 |
| 带脉 | 横向约束（六合） | 总束诸脉 |

```plain
                    督（身后·阳脉之海）
                          ▲
                          │
     阳维（表）  ←────────┼────────→  阴维（里）
                          │
                    任（身前·阴脉之海）
                          │
                    冲（十二经之海）
                          │
        ══════════ 带脉（横向总束诸脉）══════════
                          │
              阳跷（肢体之阳）/ 阴跷（肢体之阴）

```

**一个颠覆性的结构安排**：全书的排列顺序是阴维、阳维、阴跷、阳跷、冲、任、督、带——把**二维推到最前**。这不是编排癖好，而是李时珍认定的核心判断：**二维主一身表里，是营卫的维系者**。抓住二维，就抓住了八脉的总纲。

#### 3_3_2 什么时候该启用奇经这把备用钥匙

| 信号 | 含义 |
| --- | --- |
| 病程长、反复发作 | 常规坐标系已反复试过 |
| 多方常规辨证均只取效一时 | 不是辨证不细，是层次不对 |
| **越补越漏** | 补得进但兜不住——典型的固摄失司 |
| 症状涉及腰、胞胎、带下、遗精、久泻 | 与冲任督带直接相关 |

> **落地提示**：奇经不是第一选择，而是**常规思路失效时的备用坐标系**。启用它的前提是——你已经认真走完了脏腑辨证，而它确实解释不了"为什么兜不住"。
>
> **《难经》的先导**：奇经八脉理论在《难经》第二十三至二十九难中首次系统化，提出"人脉隆盛，入于八脉而不环周，故十二经亦不能拘之"，正是"沟渠湖泽"之喻的先声。

### 3_4 一个常被忽略的细节：穴位是"姿势下的坐标"

《铜人针灸经》大量篇幅是"取穴姿势"（正坐、俯伏、挺腹、端身、两手相重支额）而非抽象论述。夏竦序的核心论点其实是教学法："传心岂如会目，著辞不若案形"——口传心授不如直接看模型，文字描述不如对照实体。

> **这一条的实践含义**：**穴位不是一个坐标，而是一个"姿势下的坐标"**。歪个头、挺个腹，位置就变了。凡遇"前顶，甄权《针经》云一寸，今依《素问》一寸五分为定"一类校语，不要跳过——那是古人已经替你做过一次循证审查。

### 3_5 案例小故事：两位久泻病人的两次取穴

**背景**：某年秋末，一位针灸医生在一个月内接连遇到两位慢性腹泻的病人，病程都在数月以上。两人年龄相仿，都被前医用过"止泻"的常规穴位。

**经过——第一位（五更泻）**：男，五十余岁。每天凌晨四点多必被腹痛憋醒，泻后痛减，大便清稀不成形，平日畏寒、手脚凉，腰以下尤其怕冷，舌淡胖有齿痕，脉沉迟。前医取足三里、三阴交，行常规针刺，留针二十分钟。三次之后，腹泻次数由每日三次减为两次，但畏寒未改，凌晨仍必起，他自己说"好像只好了三分之一"。

**经过——第二位（紧张即泻）**：男，三十余岁，公司职员。腹泻与情绪高度相关：一遇到汇报、赶 deadline 就腹痛欲泻，泻后痛减，平时大便基本成形，只是容易腹胀、嗳气、善太息，脉弦。前医同样取足三里、三阴交，同样留针二十分钟，同样疗效平平。

**转机**：医生给两人各自加了一组穴，但方向完全相反——

- 第一位：加用**温灸**，取关元、命门、神阙（隔姜灸）。理由是他的病机在**肾阳不足、命门火衰**（凌晨为阳气初生之时，阳微不能胜阴寒，故五更即泻）。针刺虽可调气，但"寒者热之"，非温灸不足以补火。两周后五更泻渐止，畏寒明显改善。
- 第二位：加取**太冲**（肝经原穴）与背部肝俞，并把留针期间的重点放在引导呼吸与放松上。理由是他的病机在**肝木乘脾**（情绪紧张则肝气横逆犯脾）。三阴交、足三里补的是脾胃，但没解决"谁来犯脾"这个源头。数次之后，随着情绪平稳，腹泻渐止。

**复盘**：两位病人取了同样的主穴，差别不在穴位，而在于**接口接在哪条经、用补还是用泻、要不要加灸**。穴位只是接口，真正决定疗效的是背后的辨证。用一句可以记住的话收尾：**同穴可以治异病，异病不可同法。**

### 3_6 本板块的笔记动作与验证

**笔记动作**：画一张"八脉坐标图"。中心画任督（前后），横向画带脉，两侧画阴阳维、阴阳跷，每脉旁只写一个功能词。贴在工作台上，遇到久病不愈的案子就看一眼，提醒自己还有这套备用坐标系。

**验证方法（三选一）**：

1. **方向测试**：说出足三阳经的走向（从足至头），并解释为什么四肢末端的井穴能治疗远端脏腑的病。
2. **五输主病**：默写出井、荥、输、经、合各自的主治（心下满 / 身热 / 体重节痛 / 喘咳寒热 / 逆气而泄）。
3. **奇经启用条件**：给出"半年反复出血、三种常规辨证都只取效一时、越补越烦"，说出你该转向哪套坐标系以及理由。
