## 板块6 · 辨证：五套坐标系，把症状翻译成证型

> **这是整套知识库的分水岭**：前面几个板块都是在"采集"，到这里才第一次做"判断"。
>
> 辨证的产出物是**证型**，而证型才是选方的直接依据——**没有证型，方子再多也没有挂靠的地方**。

---

### 6_1 为什么需要五套坐标系

辨证的本质是**定位 + 定性**。五套坐标系不是五选一，而是**看问题的五个切面**：

| 坐标系 | 定位什么 | 最适合 | 出处 |
| --- | --- | --- | --- |
| **八纲** | 总纲（表里寒热虚实阴阳） | 一切病证的第一层分类 | 景岳全书"二纲六变" |
| **六经** | 外感寒邪的六个圈层 | 伤寒、外感病 | 伤寒论（见板块9） |
| **卫气营血** | 温邪的深浅刻度 | 温病（横向深度） | 温热论（见板块10） |
| **三焦** | 温病的上下分区 | 温病（纵向位置） | 温病条辨（见板块10） |
| **脏腑 + 气血津液** | 具体病位与物质基础 | 内伤杂病 | 金匮要略、类证治裁 |

```plain
   八纲（总纲·必用）
        │
        ├──→  外感？ ──→ 寒邪为主 ──→ 六经
        │                温邪为主 ──→ 卫气营血 + 三焦（两套叠加）
        │
        └──→  内伤？ ──→ 脏腑 + 气血津液
                              │
                              └──→ 久病不愈 ──→ 再考虑奇经（板块3）

```

**使用顺序**：八纲定总纲 → 外感病用六经或（卫气营血 + 三焦）→ 内伤病用脏腑 + 气血津液 → 复杂病两套叠加 → 久病入络或越补越漏时启用奇经。

---

### 6_2 八纲：第一层粗筛

八纲的核心是**阴阳统摄表里寒热虚实**。景岳的表述最清楚：阴阳为二纲，表里、寒热、虚实为六变。

```plain
                    阴阳（总纲）
                    ┌───┴───┐
                 表/里  寒/热  虚/实
                    │      │      │
                  病位   病性   邪正之势

```

#### 一个高频误判提醒：虚实最容易看错

+ **大实似虚**：真实证表现出虚象（如热结旁流——下利清水，实为燥屎内结）
+ **大虚似实**：真虚假实之腹胀（脾虚不运的胀满，用健脾法而非攻下）

> **反治法两个经典场景**（务必记住，这是辨证能力的试金石）：
>
> + **通因通用**：大承气汤治热结旁流——表面下利，实为热结，用峻下热结之法
> + **塞因塞用**：脾虚腹胀用健脾法——表面是"塞"（胀满），实则因虚而塞，补之自通

**虚实的四个判断抓手**：

| 抓手 | 偏实 | 偏虚 |
| --- | --- | --- |
| 病程 | 短、起病急 | 长、起病缓 |
| 声音气息 | 洪亮、气粗 | 低弱、气短 |
| 疼痛 | 拒按、胀痛持续 | 喜按、隐痛时作 |
| 脉 | 有力 | 无力（**沉取无力最可靠**） |

> **脉的"沉取无力"是判断虚证最可靠的单一指标**。浮取可能偏数（虚性亢奋），中取可能似有力，沉取才是真实底子。

### 6_3 对举法：用"反过来"的方法找病根

《类证治裁》最精妙的辨证技巧是**对举**——不孤立地看一个症状，而是把它放进对立面里比较。这是最高效的辨证捷径。

| 维度 | 对举组 | 怎么问 |
| --- | --- | --- |
| 寒热 | 恶寒 vs 恶热 | 想多穿还是想少穿？ |
| 汗 | 自汗 vs 盗汗 | 白天动则汗出，还是睡中出汗？ |
| 渴 | 口渴喜冷 vs 口不渴喜热 | 想喝冰的还是热的？ |
| 二便 | 秘结 vs 溏薄 | 干还是稀？ |
| 时间 | 朝重 vs 暮重 | 早上重还是傍晚重？ |
| 疼痛 | 喜按 vs 拒按 | 按着舒服还是怕按？ |

> **林珮琴的"虚损两分法"是这一技巧的典范**。他把古人啰嗦千百字的虚证，一句话砍成两截：
>
> + **阳虚证**：怯寒、少气、自汗、喘乏、食减无味、呕胀飧泄 → 病位在**脾肺** → 主方方向：四君、保元、建中、养营、归脾
> + **阴虚证**：怔忡、盗汗、咳血、吐衄、淋遗、崩漏、经闭、骨蒸 → 病位在**心肝肾** → 主方方向：补心、三才、六味、大造、固本
>
> **落地用法**：遇到一个说不清病名的虚损病人，别慌。先问三个问题——怕冷还是怕热？自汗还是盗汗？食少还是纳呆？三个答案一拼，阳虚阴虚的轮廓就出来了，用药方向立刻缩小一半。

### 6_4 脏腑 + 气血津液：内伤杂病的主坐标系

内伤杂病没有六经那样的标准传变路径，靠的是**定位（哪个脏腑）+ 定性（气血津液哪一层失常）**。

| 步骤 | 动作 | 例 |
| --- | --- | --- |
| 1 | 定病位（脏腑） | 心悸失眠 → 心；胁胀易怒 → 肝 |
| 2 | 定病性（气血津液的失常类型） | 气虚 / 血虚 / 气滞 / 血瘀 / 痰湿 / 津伤 |
| 3 | 定虚实与标本 | 本虚标实？虚多实少？ |
| 4 | 出证型（四个字或六个字的组合） | 心脾两虚、肝郁脾虚、痰热壅肺 |

> **一个提速技巧**：证型不必追求古雅，能指导选方即可。"肝郁脾虚"四个字已经足够指向逍遥散方向。辨证卡住时，往往是因为想一步到位写出完美的证型名——先把"病位 + 病性"两个词拼出来，剩下的交给板块8。

### 6_5 辨证的推演五步法（可直接套用）

把上面的工具串成一个固定流程，每次照走：

```plain
   第一步  八纲粗筛    ── 阴阳 / 表里 / 寒热 / 虚实
        │
   第二步  排除误诊    ── 用对举法排除最像的那个错答案
        │
   第三步  时间验证    ── 朝重还是暮重？白天还是夜间？（景岳法）
        │
   第四步  定位病机    ── 病位在哪 + 病性是什么 + 关键机制
        │
   第五步  交叉验证    ── 三个信源一致吗？不一致处是不是线索？

```

**第二步"排除误诊"是本流程最容易被跳过、也最有用的一步**。它的操作方式是：先列出与当前表现最像的证型，然后逐条检查它的必备条件是否满足。比如"上火"，先列出实火与虚火，再检查：实火当见满面通红、口渴喜冷、便秘、脉洪实有力——一条都不符，就可以排除。

### 6_6 案例小故事：两个"胃痛"的分岔

**背景**：初冬，同日来了两位病人，都是胃痛，年龄相仿，病程都不长。如果只看主诉，很可能开出同一类方。

**经过——第一位**：男，三十岁。疼痛剧烈，位置固定，拒按，遇冷加重，热敷稍缓，伴呕吐清水，口不渴，舌淡苔白滑，脉紧。前一天晚上有明确的饮冷史：加班后吃了一大份冰镇水果。

**经过——第二位**：女，三十四岁。隐隐作痛，时作时止，喜按，按压后舒服，劳累后加重，伴纳差、便溏、乏力、气短，舌淡胖有齿痕，脉沉细无力。病程已有数月，近两个月单位赶项目，经常错过饭点。

**转机**：

+ 第一位：八纲 → 里、寒、实；脏腑 → 胃；病性 → 寒邪凝滞，气机被遏。方向：**温中散寒、祛邪**（良附丸、理中类方向）。邪去则痛止，一二剂可见分晓
+ 第二位：八纲 → 里、虚、偏寒；脏腑 → 脾胃；病性 → 脾胃气虚（气虚为本，寒为标）。方向：**健脾益气**（黄芪建中汤、四君类方向）。须缓图，不能以止痛为唯一目标

**复盘**：第一位是"邪气实"（寒邪骤袭），第二位是"正气虚"（气虚日久）。一个要温散祛邪，一个要补益扶正。**若把第二位当成寒实证用峻温燥烈之品，短期可能止痛，久则耗气伤阴，痛必复来且更频。**

这就是"同病异治"的实际含义——**病名相同，证型不同，治法相反**。而分岔点就在两个最朴素的问句上：**痛处喜按还是拒按？发病急还是缓？** 这两个问题不需要任何仪器，问一句就能把两类病人分开。

### 6_7 本板块的笔记动作与验证

**笔记动作**：做一张"五套坐标系对照卡"。一张纸上画五个小格，每格只写三行：这把尺子量什么、最适合什么病、关键判断词是什么。贴在案头，辨证卡住时就看一眼。

**验证方法（三选一）**：

1. **对举三问**：给出"自汗、怕冷、食少"，判断偏阳虚还是偏阴虚，并说出主方方向（对照 6_3 的虚损两分法）。
2. **反治法识别**：给出"下利清水、腹痛拒按、脉滑实"，判断是虚是实，并说出治法名称（答案：真实证，热结旁流，通因通用）。
3. **完整推演**：用 6_5 的五步法，对一个真实的身边问题走一遍全程，写出最终的"病位 + 病性"两词结论。
