## 板块7 · 本草：药物 = 性味 × 方向 × 归经

> **辨证之后是选药**。一味中药由三个维度定义：**性味**（寒热温凉 + 酸苦甘辛咸，决定"干什么活"）、**方向**（升降浮沉，决定"往哪走"）、**归经**（决定"作用于哪"）。
>
> **三缺一，选药就是猜。**

```plain
                    ┌─────────────────┐
                    │      一味药      │
                    └────────┬────────┘
           ┌─────────────────┼─────────────────┐
           ▼                 ▼                 ▼
      性（四气）         味（五味）         归经
      寒/热/温/凉      酸苦甘辛咸淡      入某经某络
           │                 │                 │
      决定去哪方向       决定干什么活       决定作用于哪
           │                 │                 │
           └────────→ 叠加"升降浮沉" ←─────────┘
                     （往哪走：升浮 / 沉降）

```

### 7_1 三品分类：不是好坏榜，是用途分层

《神农本草经》最值钱的部分只有两条：**一套分类（三品）** 和 **一组规则（序录十三条）**。药物条目不过是这套框架下的填充物。

> 上药一百二十种为君，主养命以应天，无毒，多服久服不伤人，欲轻身益气、不老延年者，本上经。中药一百二十种为臣，主养性以应人，无毒有毒，斟酌其宜，欲遏病、补虚羸者，本中经。下药一百二十五种为佐使，主治病以应地，多毒，不可久服，欲除寒热邪气、破积聚、愈疾者，本下经。

| 维度 | 上品（君·应天） | 中品（臣·应人） | 下品（佐使·应地） |
| --- | --- | --- | --- |
| **核心目的** | 养命、延年 | 养性、遏病补虚 | 治病、攻邪 |
| **毒性** | 无毒，可久服 | 有无毒，须斟酌 | 多毒，不可久服 |
| **用药姿态** | 长期调养 | 阶段性干预 | 中病即止 |
| **典型药物** | 人参、甘草、地黄、茯苓、枸杞、山药 | 当归、百合、麻黄、黄芩、黄连 | 大黄、附子、乌头、巴豆、甘遂 |
| **现代类比** | 营养补充剂 / 药食同源 | 处方药（调理类） | 处方药（攻伐/有毒类） |

#### 三个必须辨析清楚的点

1. **三品的"君臣佐使" ≠ 方剂里的"君臣佐使"。** 三品是按**药物整体属性**做的纵向分层；方剂里的君臣佐使是按**方中地位**做的横向分工。下品药在某一方剂里完全可以当君药（如附子在四逆汤中为君）。
2. **上品 ≠ 绝对安全，下品 ≠ 绝对禁用。** 上品久服也需辨证（人参吃多了也上火助湿）；下品虽毒，却是攻坚救命的"特种兵"。区别只在**使用时长与剂量控制**。
3. **理性看待时代烙印**：上品大量出现"轻身、不老、延年、神仙"，这是汉代神仙方术与道家养生思想的影响。补益合理，成仙是传说。

> **读法提示**：原书成书于东汉，托名神农，实为先秦至汉代药物经验的系统总结；原书已佚，今本为历代辑佚本（以孙星衍、孙冯翼辑本为代表），载药三百六十五种。初读建议选"经文 + 白话 + 按语"三段式版本，先抓主治核心一句，其余别名、产地、炮制后读。

### 7_2 四气五味：中药的经纬度系统

#### 四气 = 方向盘（决定去哪个方向）

| 性 | 作用方向 | 适用 | 代表 |
| --- | --- | --- | --- |
| 寒凉 | 清热、泻火、解毒、凉血、滋阴 | 热证（发热、口渴、红肿） | 黄连、石膏、地黄 |
| 温热 | 散寒、温里、助阳、回阳、通络 | 寒证（怕冷、腹痛、肢凉） | 附子、干姜、肉桂 |
| 平性 | 作用缓和，双向调节 | 多用于调养打底 | 甘草、茯苓、山药 |

**核心口诀：疗寒以热药，疗热以寒药。** 这是辨证用药的总开关，比记住任何一味药都重要。

判定标准只有一个：**用药后的反应 + 所治证候的寒热**。能消除热证的，就是寒凉药；能消除寒证的，就是温热药。"平性"不是没药性，而是偏性小、适合久服和打底。

#### 五味 = 功能键（决定干什么活）

| 味 | 核心作用 | 形象记忆 | 代表 |
| --- | --- | --- | --- |
| **辛** | 能散、能行（发散、行气、活血） | "打开通道" | 麻黄、桂枝、川芎 |
| **甘** | 能补、能和、能缓（补益、调和、缓急） | "滋养 + 和事佬" | 甘草、熟地、党参 |
| **酸（涩）** | 能收、能涩（收敛、固涩） | "关上门" | 乌梅、龙骨、牡蛎、赤石脂 |
| **苦** | 能泄、能燥、能坚（清泄、燥湿、降泄） | "往下压 + 烘干" | 黄连、大黄、栀子 |
| **咸** | 能下、能软（泻下、软坚散结） | "化开硬块" | 芒硝、海藻、昆布 |
| **淡**（附） | 能渗、能利（渗湿利水） | "把水排走" | 茯苓、猪苓、泽泻 |

> **实用反推规律**：看到功效词就能反推味。
>
> + "散结"多半咸（海藻、昆布、芒硝）
> + "收涩止泻"多半酸涩（乌梅、赤石脂）
> + "通便"苦或咸（大黄、芒硝）
> + "利水渗湿"多淡（茯苓、泽泻）

### 7_3 升降浮沉：最容易被忽略的一层

《药性赋》看似只讲寒热，其实**通篇都在暗写升降浮沉**——只是没点破。而这一层，恰恰是"同是清热，为什么选 A 不选 B"的真正答案。

**四条判断法则**：

| 维度 | 升浮（向上、向外） | 沉降（向下、向内） |
| --- | --- | --- |
| 四气 | 温、热 | 寒、凉 |
| 五味 | 辛、甘、淡 | 苦、酸、咸 |
| 部位质地 | 花、叶、质轻 | 子、实、质重 |
| 代表 | 麻黄、升麻、黄芪 | 大黄、芒硝、苏子、枳实 |

```plain
   升浮（向上向外）              沉降（向下向内）
   ┌──────────────┐            ┌──────────────┐
   │ 花·叶·质轻    │            │ 子·实·质重    │
   │ 辛·甘·淡      │            │ 苦·酸·咸      │
   │ 温·热         │            │ 寒·凉         │
   ├──────────────┤            ├──────────────┤
   │ 解表·升阳     │            │ 泻下·降气     │
   │ 散寒·通窍     │            │ 清热·潜降     │
   │ 麻黄·升麻     │            │ 大黄·苏子     │
   └──────────────┘            └──────────────┘

```

**临床用法**：病位在上在表（头面、肌表），用升浮药载药上行；病位在下在里（下焦、肠道），用沉降药引药下行。**这个维度常常比"寒热"更能解释选药的差异。**

> **一个经典例子**：同样治头痛，羌活（辛温升浮）善治太阳经头痛（后头牵项），白芷（辛温升浮）善治阳明经头痛（前额），柴胡（苦辛微寒，升散）善治少阳经头痛（两侧）。差别不在寒热，而在**归经 + 升浮到达的部位**。

### 7_4 归经与引经报使

归经说明药物作用于哪条经络、哪个脏腑。**同是清热，清哪个脏腑的热，由归经决定**：

| 归经 | 清热代表药 | 主治 |
| --- | --- | --- |
| 肺经 | 黄芩、桑白皮、石膏 | 肺热咳喘 |
| 心经 | 黄连、莲子心 | 心火烦躁、口舌生疮 |
| 肝经 | 龙胆草、夏枯草、柴胡 | 肝火目赤、胁痛 |
| 胃经 | 石膏、知母、黄连 | 胃火牙痛、消谷善饥 |
| 肾经 | 知母、黄柏、生地 | 肾虚火旺、骨蒸 |

**引经报使**：方中加一味引经药，把整方的药力带到特定部位。这是方剂"靶向性"的古代实现：

+ 桔梗——载药上行（舟楫之剂）
+ 牛膝——引血下行
+ 柴胡——引药入少阳、升举清阳
+ 升麻——引药上行、升阳举陷

### 7_5 《药性赋》的正确读法：索引地图，不是说明书

《药性赋》旧题金元时期作品，作者不详，历来列为中医"四小经典"之一。它把常用中药按**寒、热、温、平**四性编成韵文，四言六言，对仗押韵。全赋分四章，各章药数传统口径为**寒性六十六种、热性六十种、温性五十四种、平性六十八种**。

> **必须知道的一件事**：它不是"用药说明书"，而是一张**索引地图**。赋文只告诉你"这味药最擅长干什么"，几乎不写剂量、禁忌、炮制和真伪优劣。
>
> **正确打开方式**：以赋为纲搭骨架，再以本草专著（现代《中药学》教材、《中华本草》）填血肉。

#### 读赋的三步法

1. **先定位四性**：这味药是寒是热是温是平？决定它的适用方向
2. **再补五味与归经**：赋文常不写，需查本草专著补齐
3. **最后找配对**：这味药常和谁一起用？（见板块8的药对）

> **记忆技巧**：不要单味背，要**按"功效簇"背**。比如清热药一簇（石膏、知母、黄连、黄芩、黄柏、栀子），记住它们各自的"独家位置"——石膏清气分实热、知母清润兼顾、黄连清心胃、黄芩清肺与少阳、黄柏清下焦、栀子清三焦之火并利小便。

### 7_6 采集时节与产地：被现代教材删掉的一维

《千金翼方》本草卷有一句极重要的话：

> 凡药皆须采之有时日，阴干曝干则有气力。若不依时采之，则与凡草不别，徒弃功用，终无益也。

**这句话把"药材"从名词变成了"时间与地点的函数"**。现代中药房标准化的副作用，恰恰是孙思邈最警惕的——同一味药，采错节气，药效可能大打折扣。他按出产地把进御药材分列各州，又提出"天下物类皆是灵药"的观念。

《本草纲目》延续了这一"格物"精神。李时珍给自己定的任务是"考释性理，实吾儒格物之学"，要解决宋明以来本草知识的三大病：**舛（错）、谬（误）、遗漏**。

| 项目 | 数据 |
| --- | --- |
| 编撰时间 | 嘉靖三十一年至万历六年，历时二十七年，稿凡三易 |
| 全书卷数 | 五十二卷 |
| 收载药物 | 一千八百九十二种（一说一千八百九十七种），较旧本新增三百七十四种 |
| 附方 | 一万一千零九十六首，其中八千一百六十首为李时珍亲自收集 |
| 药图 | 一千一百零九幅（一说一千一百六十幅） |
| 引用文献 | 经史百家四百四十种，医书二百七十七种，合计七百一十七种 |

#### 《本草纲目》的两条线

| 线 | 内容 | 现代读法 |
| --- | --- | --- |
| **"是何物"之线** | 辨明药材的真伪、形态、产地、采收（占全书九成篇幅） | 学博物与辨伪意识 |
| **"如何用"之线** | 药性理论与临证指南（序例与"百病主治药"） | **按症状反向检索**，最实用 |

| 你的目标 | 建议主攻章节 | 读法 |
| --- | --- | --- |
| 学养生食疗 | 序例 + 谷、菜、果、木部 | 通读粥、茶、果实条 |
| 学药性思维 | 序例的"脏腑虚实标本用药式""升降浮沉" | 精读 + 对照日常食材 |
| 了解成书精神 | 王世贞原序 + 李时珍自序 | 速读，建立整体感 |
| 临证参考 | "百病主治药"部分 | **按症状反向检索** |

### 7_7 毒性药物与安全红线

**必须明确的一条**：本板块涉及的所有有毒药物，均为文献与理论学习材料。

| 类别 | 代表 | 风险提示 |
| --- | --- | --- |
| 有毒的温里药 | 附子、乌头 | 需先煎减毒，剂量与煎法均须专业把控 |
| 有毒的攻下药 | 大黄（相对安全）、甘遂、巴豆、芫花 | 峻下逐水，中病即止 |
| 矿物药 | 朱砂、雄黄、轻粉、铅白霜 | **一律不作任何自用推荐** |
| 有毒的儿科用药 | 牛黄、朱砂、麝香、巴豆 | **一律不进入家庭方案**（见板块14） |

**三条不可逾越的红线**：

1. 不自行使用任何有毒药物，包括"外用"
2. 不自行使用含矿物药的方剂（无论内服外用）
3. 不按古方剂量自行折算抓药（经方剂量换算存在多种考证口径，差距可达数倍）

### 7_8 落地：厨房药箱（药食同源的安全区）

这是普通人真正能安全上手的部分。以下均为药食同源品，性味平和，可作日常调理（仍需适量，且不适合所有人）：

| 药 | 性味 | 方向 | 适合 | 不适合 |
| --- | --- | --- | --- | --- |
| **山药** | 甘平 | 补脾肺肾 | 脾虚纳差、久泻、乏力 | 湿盛胀满者暂不宜 |
| **薏苡仁** | 甘淡微寒 | 利水渗湿健脾 | 湿重、水肿、苔腻 | 孕妇慎用；津液不足者不宜久服 |
| **茯苓** | 甘淡平 | 渗湿健脾宁心 | 脾虚湿盛、失眠 | 小便过多者不宜 |
| **陈皮** | 辛温苦 | 理气健脾燥湿 | 脘腹胀满、痰多 | 阴虚燥咳、气虚者慎用 |
| **生姜** | 辛微温 | 解表散寒温中止呕 | 外感风寒、胃寒呕吐 | 阴虚内热、热证忌 |
| **大枣** | 甘温 | 补中益气养血 | 脾虚乏力、血虚 | 痰湿、腹胀者不宜多 |
| **山楂** | 酸甘微温 | 消食化积活血 | 肉食积滞 | 胃酸过多、空腹不宜 |
| **枸杞** | 甘平 | 滋补肝肾明目 | 肝肾阴虚、视力模糊 | 外感发热、脾虚湿滞慎用 |
| **莲子** | 甘涩平 | 补脾止泻益肾固精 | 脾虚久泻、心悸失眠 | 便秘者不宜 |
| **百合** | 甘微寒 | 养阴润肺清心安神 | 阴虚燥咳、虚烦失眠 | 风寒咳嗽、脾虚便溏不宜 |

> **用法原则**：药食同源品的优势是"偏性小"，代价是"力弱"。它们适合**长期调养与轻微失衡**，不适合急性病症。急病仍须就医。

### 7_9 案例小故事：一味甘草的两种角色

**背景**：甘草是最常被误解的药。在多数人印象里，它是方子里的"和事佬"，负责调和诸药，可有可无。于是有人顺理成章地想：既然它能调和，又能"补气"，那天天泡水喝岂不是养生？

**经过**：一位四十来岁的男性，因工作应酬多、常觉疲乏，听人说甘草泡水"补气解毒"，便每天抓一大把泡水喝，有时还加些别的一起煮。前两个月他确实觉得"胃里舒服些"。到第四个月，问题来了：先是袜子勒出深印、下午脚踝浮肿；接着血压比往常高了一截；人反而更累，稍动就喘。

他以为是"湿气重"，自行加了利水之品；利了几天肿消一些，停了又起。如此反复两个月，舌苔越来越腻，脉也变得濡缓无力。

**转机**：医生追问他的日常饮品，才把这味"最无害的药"找出来。其实甘草至少有两个完全不同的角色——

+ **炙甘草（蜜炙）**：甘温，偏于补脾益气、缓急止痛。在炙甘草汤中用量较大，是治"脉结代、心动悸"的主药之一，取的是甘温益气以复脉
+ **生甘草**：甘平偏凉，偏于清热解毒、润肺止咳。治咽喉肿痛的桔梗汤，取的就是清热解毒之性

同一个"甘草"，炮制一变，性味方向就变。更关键的是它有明确的禁忌：**湿盛胀满、水肿者不宜，且不宜长期大量服用**。这位病人的浮肿与血压升高，正是长期大量服用甘草的结果，中医文献中对此早有记载。

停药并调理一段时间后，浮肿与血压逐步回落。

**复盘**：药物的"性味 × 方向 × 归经"不是静态标签，**炮制、剂量、配伍、服用时长都会改变它的实际角色**。甘草在方中"调和诸药"时用量通常很小，那是配伍中的甘草；单独大量久服，那是完全不同的另一味东西。

这也是为什么"以药套病"（听说某药治某病就单味久服）是中医疗效最不可靠的方式——**药性只在配伍中才完整，脱离配伍的"单药长期服用"，本质上是在做一场没有对照组的人体试验。**

### 7_10 本板块的笔记动作与验证

**笔记动作**：建立"药性卡片"，每味药一张，固定六栏：性、味、方向（升降浮沉）、归经、独家位置（一句话）、常用配对。关键约束是——**"独家位置"一栏必须写出它和同类药的区别**（如"黄柏清下焦，与黄芩清肺不同"）。

**验证方法（三选一）**：

1. **反推测试**：给出"软坚散结"功效，说出它多半属于什么味、代表药有哪些（答案：咸味，海藻、昆布、芒硝）。
2. **同类辨析**：说出黄连、黄芩、黄柏三味药的清热位置差异（心胃 / 肺与少阳 / 下焦）。
3. **厨房实践**：选一味药食同源品，连续一周在日常饮食中使用，记录身体的变化（舌苔、二便、睡眠），体会它的偏性方向与强度。
