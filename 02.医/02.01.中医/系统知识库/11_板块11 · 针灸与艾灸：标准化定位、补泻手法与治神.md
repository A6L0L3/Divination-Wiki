## 板块11 · 针灸与艾灸：标准化定位、补泻手法与治神

> **从"药"转到"外治"**。本板块的结构是递进的：**先把穴位定准 → 再学怎么干预 → 然后知道什么不能碰 → 最后是一份普通人能安全自用的居家方案**。
>
> 贯穿全篇的那根线，是《灵枢》的四个字——**"上守神"**。经络走向与五输穴的原理见板块3，本板块不重复。
>
> **安全前置**：针刺是侵入性医疗行为，须在合法资质与规范场所内进行。本板块涉及的针刺深度、要害穴均属文献学习材料；普通人可安全使用的部分，只有按揉与温和艾灸。

### 11_1 《针灸甲乙经》：一本可以拿来照着扎的说明书

很多人打开《针灸甲乙经》会犯困：满篇"某穴在某某下两旁各一寸五分，刺入五分，留七呼，灸三壮"。但**这恰恰是它的核心价值**——它把散落在《内经》各处的针灸条文，第一次整理成了"可操作流程"。

| 维度 | 《黄帝内经》 | 《针灸甲乙经》 |
| --- | --- | --- |
| 性质 | 理论奠基（兼带少量操作） | 操作规范（兼带理论框架） |
| 穴位 | 约一百六十个，名称不统一、位置模糊 | **三百四十九个**（双穴三百、单穴四十九），厘定归经 |
| 好比 | 工程学的"原理教科书" | 设备的"维修保养手册" |

#### 11_1_1 穴位的"完整身份证"

《甲乙经》对每个穴位的记录格式高度统一：

```plain
   穴名（含别名）│ 精确位置 │ 取穴姿势 │ 归经/交会 │ 针刺深度 │ 留针时长 │ 艾灸壮数 │ 主治 │ 禁忌

```

举一个完整样本（天突穴）：

> 天突，一名玉户，在颈结喉下二寸，中央宛宛中，阴维、任脉之会，**低头取之**。刺入**一寸**，留**七呼**，**灸三壮**。

| 字段 | 含义 | 现代对应 |
| --- | --- | --- |
| 低头取之 | **取穴姿势是关键操作前提** | 体位决定定位准确性 |
| 刺入一寸 | 精确到分的深度 | 毫米 |
| 留七呼 | "呼"是计息单位 | 留针时长 |
| 灸三壮 | "壮"是艾柱单位 | 灸量 |

> **实操启示**：今天的针灸教学虽然单位换了（改用毫米），但这个"身份证格式"一个字都没变。**初学者不妨拿书里任意一个穴，对照自己身上的位置逐条验证**——这是最快的"穴位定位肌肉记忆"训练法。

#### 11_1_2 两个沿用至今的分类逻辑

1. **头面躯干——按部位排**（从头到脚分区列举）
2. **四肢——按经脉排**（从阴到阳，从肘到手 / 膝到足）

这套"分部 + 分经"双轨制，一直到今天还是针灸教材的编排方式。

> **版本意识**：《铜人针灸经》七卷本是元代书商从《太平圣惠方》卷九九《针经》析出，属"图经"的实用摘录；真正的源头是北宋天圣年间王惟一奉诏所撰《铜人腧穴针灸图经》，并铸铜人两具。《四库提要》明言四库所藏七卷本"不著撰人名氏"，且"虽冠铜人之名，实与铜人无涉"。**它是王惟一书系的下游实用本，价值在"可照搬"，不在"原创性"。**

### 11_2 补泻：从理念变成可复用的手法

《灵枢》第一篇《九针十二原》是全书的"总纲"，所有技法都从这四句话出发：

> **凡用针者，虚则实之，满则泄之，宛陈则除之，邪胜则虚之。**

| 状态 | 判断依据 | 处置原则 |
| --- | --- | --- |
| **虚**（正气不足） | 乏力、怕冷、气短、脉细弱 | 补——把正气扶起来 |
| **满/实**（邪气壅盛） | 胀痛、上火、堵闷、脉有力 | 泻——把邪气排出去 |
| **宛陈**（陈旧瘀血） | 久痛、刺痛、瘀青、舌暗 | 除——把瘀滞疏通开 |
| **邪胜**（邪气占上风） | 高热、剧痛、病势凶猛 | 虚之——急攻以安正 |

#### 11_2_1 徐疾补泻：最好上手的一种

> **徐而疾则实，疾而徐则虚。**

- **补法（治虚）**：慢进针、快出针，出针后**按住针孔**——把正气留住
- **泻法（治实）**：快进针、慢出针，出针后**不按针孔**——让邪气外泄

> **延伸到日常按摩也成立**：虚弱的人按揉宜轻柔、时间稍长、按完收敛；实证淤堵处可稍重、点按放散。

#### 11_2_2 迎随补泻：方向不能搞反

迎随是依经脉循行方向施术：**顺经而刺为补，逆经而刺为泻**。前提是记牢板块3那条方向规则——手三阴从胸走手、手三阳从手走头、足三阳从头走足、足三阴从足走胸。**方向记反，补泻全反。**

#### 11_2_3 开阖与呼吸补泻（补充两种）

| 手法 | 补 | 泻 |
| --- | --- | --- |
| **开阖** | 出针后按闭针孔 | 出针时摇大针孔、不按 |
| **呼吸** | 呼气时进针、吸气时出针 | 吸气时进针、呼气时出针 |

#### 11_2_4 得气：疗效的唯一标准

> **凡刺之要，气至而有效。**

针刺是否有效，不看扎得多准，而看是否"**得气**"——针下产生酸、麻、胀、重的经气感应，医者手下有沉紧感。

> **延伸到养生**：按揉穴位时追求那种"酸胀得气"的感觉，比随便蹭几下有效得多。这也是判断"按对了没有"的实用标准。

### 11_3 《难经》的针法：补母泻子与治未病

《难经》第六十九难至八十一难专论针法，其中两条最可迁移。

#### 11_3_1 补母泻子（六十九难、七十五难）

依据五输穴配五行（见板块3），按"虚则补其母，实则泻其子"取穴：

```plain
   例：肺（属金）虚证 → 补其母（土）→ 取肺经五输中属土的穴（太渊）
       肝（属木）实证 → 泻其子（火）→ 取肝经五输中属火的穴（行间）

```

> **落地价值**：它把"补泻"从手法层面推进到了选穴层面——**同样是补，选哪个穴本身就有补泻方向**。这是五输穴理论的直接应用。

#### 11_3_2 治未病（七十七难）

> 所谓治未病者，见肝之病，则知肝当传之与脾，故先实其脾气，无令得受肝之邪，故曰治未病焉。

这与《金匮要略》"见肝之病，知肝传脾，当先实脾"是同一条原则（见板块4），只是落在针法上——**针刺时也可以提前"布防"**。

#### 11_3_3 另一条常被引用的原则（八十一难）

"无实实，无虚虚，损不足而益有余"——**不可对实证再用补法、对虚证再用泻法**。这是一条朴素却极容易被违反的安全原则，与《灵枢》十六字宪法互为表里。

### 11_4 治神：进针之前那几分钟

《针灸大成·针邪秘要》是一篇被长期误读的文献。若把它当成符咒文献，它荒谬；若把"病因模型"与"操作方法"剥离，它惊人地现代。

原文开篇列出一组症状：凡男妇或歌或笑，或哭或吟，或多言，或久默，或朝夕嗔怒，或昼夜妄行，或口眼俱邪，或披头跣足，或裸形露体，或言见鬼神。

| 原文描述 | 可观察维度 | 关键提示 |
| --- | --- | --- |
| 或歌或笑、或哭或吟 | 情感表达失控、易变 | 情感维度 |
| 多言 / 久默 | 言语量两个极端 | 注意"沉默型" |
| 朝夕嗔怒 | 激惹性增高 | 攻击风险 |
| 昼夜妄行 | 节律颠倒、睡眠缺失 | **常是首个可干预靶点** |
| 口眼俱邪 | 肌张力或面肌不对称 | 需先排除器质病变 |
| 披头跣足、裸形露体 | 社会功能与自我照护丧失 | 自知力缺失 |
| 言见鬼神 | 幻觉、妄想性体验 | 不可当真，也不可硬驳 |

> **核心结论**：这篇文献的核心不是"驱邪"，而是**"治神"——在针落下之前，先把患者和医者的状态调到可治疗区间**。
>
> 关键证据是：全文**没有一个治疗穴位**，全部是"如何进入治疗"的准备动作。《针邪秘要》与《孙真人针十三鬼穴歌》是"术前总则 + 术中方案"的上下篇关系，合读才完整。

**"治神"的现代读法**：把所有"神/鬼/符/咒"还原为可观察的变量——注意力、情绪、呼吸、肌张力、预期。这是一套**针对高唤醒、低依从性患者的术前准备流程**。

| 古代说法 | 可操作变量 | 现代动作 |
| --- | --- | --- |
| 定神 | 注意力 | 安静环境、减少干扰、眼神接触 |
| 安神 | 情绪唤醒度 | 平稳语调、不反驳妄想、给予可预期性 |
| 调息 | 呼吸频率 | 引导缓慢呼吸，降低交感兴奋 |
| 松形 | 肌张力 | 舒适体位，先放松再施术 |

> **上文所列风府、会阴、舌下等穴，风险明确，非专业者严禁自行操作。**（详见板块15）

### 11_5 灸法：普通人最能安全上手的部分

灸法的核心优势是**温通**——适合虚证、寒证、慢性病的长期调理。

#### 11_5_1 常用保健穴（可自用，且相对安全）

| 穴 | 定位 | 主要作用 | 适合 |
| --- | --- | --- | --- |
| **足三里** | 外膝眼下约四横指，胫骨旁 | 健脾和胃、补益气血、强壮 | 脾胃虚弱、乏力、免疫力低下 |
| **关元** | 脐下约四横指（腹部正中） | 培补元气、温肾固本 | 虚寒、畏寒、元气不足 |
| **气海** | 脐下约两横指 | 益气助阳 | 气虚、乏力 |
| **中脘** | 脐上约四横指 | 和胃健脾 | 胃胀、纳差、消化不良 |
| **神阙** | 肚脐中央 | 温阳救逆、健脾 | 虚寒腹泻（多用隔盐灸或隔姜灸） |
| **命门** | 后腰正中，与脐相对处 | 温补肾阳 | 腰膝冷痛、畏寒 |
| **大椎** | 低头时颈后最高骨突下方 | 解表散寒、通阳 | 易感冒、畏寒、颈肩僵 |
| **三阴交** | 内踝尖上约四横指，胫骨后缘 | 健脾养血、调肝补肾 | 气血不足（**孕期慎用**） |

> **安全须知**：
>
> + 孕妇腹部、腰骶部禁灸；三阴交等穴孕期慎用
> + 面部、大血管处、关节部位不宜直接瘢痕灸
> + 糖尿病患者、皮肤感觉迟钝者慎灸（易烫伤而不自知）
> + 实热证、阴虚火旺者不宜温灸（会加重）
> + 每次每穴温和灸十至十五分钟，以皮肤温热潮红为度，**不追求起泡**

#### 11_5_2 居家温补的三条实操建议

1. **温和灸优于瘢痕灸**：悬起温和灸（艾条离皮肤约三厘米，保持温热舒适）最安全，不起泡、不留疤
2. **先辨证再灸**：灸法偏温，**适合虚寒，不适合实热与阴虚火旺**。舌红少苔、五心烦热、口干盗汗者不宜
3. **灸后注意保暖避风**：灸后毛孔开张，受风受凉易致不适

### 11_6 禁忌：什么情况下不能针灸

| 类别 | 内容 |
| --- | --- |
| **部位禁忌** | 风府、哑门、会阴、舌下等深部要害穴，风险极高，非专业者严禁操作 |
| **状态禁忌** | 过饥、过饱、醉酒、极度疲劳、大汗后、情绪剧烈波动时不宜针刺 |
| **人群禁忌** | 孕妇腹部腰骶部禁针禁灸；婴幼儿囟门未闭处禁针 |
| **病证禁忌** | 大出血、休克、高热神昏等急重症，优先现代急救，不依赖针灸 |
| **皮肤禁忌** | 感染、溃疡、瘢痕、肿瘤局部禁针 |

> **一条总原则**：**凡涉及神志异常、急重症、深部要害穴，一律交专业医师，不在家庭环境尝试。**

### 11_7 案例小故事：同是胃痛，补泻相反

**背景**：同一周内，两位病人都因"胃脘不适"来求针灸治疗，疼痛部位几乎相同，若只看主诉，很容易用同一套手法、同一组穴。

**经过——第一位**：女，四十岁，教师。素来乏力、纳差、便溏，胃脘隐隐作痛，喜温喜按，喝热水舒服，舌淡胖有齿痕，脉沉细无力。病程数月，站久了或讲课多时加重。她说："就是那种钝钝的疼，说不上多疼，但一直在。"

**经过——第二位**：男，二十二岁，学生。前一天晚上聚餐暴饮暴食，第二天胃脘胀痛剧烈，拒按，嗳腐吞酸，口气重，大便两日未行，舌红苔厚腻，脉滑有力。他说："胀得衣服都不敢系紧。"

**转机**：医生给两人用了部分相同的穴（中脘、足三里），但手法与配穴完全不同——

- 第一位：脾胃气虚（虚证）→ 行**补法**（轻刺激、久留针、出针后按闭针孔），并加用温和灸中脘、足三里，嘱其回家可自灸
- 第二位：食积实证 → 行**泻法**（较强刺激、出针不闭针孔），加取内庭（荥穴，主身热、消谷善饥之类实热证），不用灸

第一位三次后疼痛渐消、纳食转佳；第二位仅一次，胀痛大减，排便后基本平复。

**复盘**：**若把补泻用反**——虚证用泻法，越治越虚，她那种"钝钝的疼"会变成整日不休；实证用补法（尤其误用温灸），越补越胀，等于"闭门留寇"。

这就是《灵枢》十六字宪法"虚则实之，满则泄之"的实际分量——**它不是一个原则性口号，而是决定疗效方向的操作开关**。而分岔点同样朴素：痛处喜按还是拒按？发病急还是缓？问两句，方向就定了。

### 11_8 本板块的笔记动作与验证

**笔记动作**：做一张"穴位身份证卡"。每穴一张，固定七栏：定位（含取穴姿势）、归经、穴性（五输属哪一类）、主治、刺法深度、灸量、禁忌。**把"取穴姿势"这一栏强制填上**——这是最容易被忽略却最决定准确性的一栏。

**验证方法（三选一）**：

1. **补泻方向测试**：给出"久病乏力、喜按、脉沉细无力"，判断该补还是该泻，并说出出针后是否按闭针孔（答案：补，按闭针孔）。
2. **得气判断**：用自己的话解释"得气"是什么，以及它在日常按揉中如何应用（答案：酸麻胀重的经气感应；按揉追求酸胀感，而非随便蹭几下）。
3. **安全自查**：列出三个你自己或家人适合温和灸的穴位，并说明为什么（须同时说明不属于实热 / 阴虚火旺）。
