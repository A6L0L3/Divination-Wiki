## 板块4 · 病因病机：疾病从哪来、往哪走、卡在哪

> **有了地图，现在可以推演疾病了**：本板块回答三个问题——病从哪来（病因）、在体内如何变化（病机）、往哪发展（传变）。
>
> **其中"传变"一节最值钱**，因为它决定了你是"治现在的病"还是"治三步后的病"。

---

### 4_1 三因分类：定位疾病的起点

《金匮要略》把一切疾病归为三条路径，比宋代陈无择的"三因说"早了数百年：

```plain
   1. 内所因    ── 经络受邪，传入脏腑（由外入内、由浅入深）
   2. 外所中    ── 四肢九窍、血脉相传，壅塞不通（皮肤外感）
   3. 不内外因  ── 房室、金刃、虫兽所伤（意外损伤）

```

**这条分类的现代价值在于"快速定位起点"**：是内伤为主、外感为主，还是意外损伤？定位不同，治疗路径完全两样。

> **落地用法**：接诊（或自我判断）时先用十秒钟做一次归因筛选。
>
> + 起病急、有明确诱因（受凉、暴食、外伤）→ 外因 / 不内外因，祛邪为主
> + 起病缓、与情绪、作息、年龄相关 → 内伤，调脏腑为主
> + 慢性病急性发作 → 内伤为本，外邪为标，标本兼顾

---

### 4_2 六淫：六种外邪的识别特征

六淫（风、寒、暑、湿、燥、火）不是六种物质，是**六类致病模式的归纳**。识别它们的抓手是"致病特点"，而非"病因本身"：

| 邪气 | 致病特点 | 识别信号 | 治法方向 |
| --- | --- | --- | --- |
| **风** | 善行数变、轻扬开泄、动摇不定 | 起病急、病位游走、瘙痒、震颤、汗出恶风 | 祛风（治风先治血，血行风自灭） |
| **寒** | 收引凝滞、易伤阳气 | 疼痛剧烈而固定、遇寒加重、肢冷、脉紧 | 温散 |
| **暑** | 炎热升散、耗气伤津、多夹湿 | 夏季发病、高热汗多、口渴乏力、胸闷呕恶 | 清暑益气，兼顾化湿 |
| **湿** | 重浊黏滞、趋下、缠绵难愈 | 身重困倦、苔腻、病程长、下肢肿、分泌物黏浊 | 化湿 / 燥湿 / 利湿，重在运脾 |
| **燥** | 干涩、易伤津液 | 口鼻咽干、干咳少痰、皮肤干、大便干、舌干少津 | 润燥（注意凉燥与温燥之别） |
| **火** | 炎上、耗气伤津、生风动血 | 高热、面赤、口渴、烦躁、出血、舌红绛 | 清热泻火 / 滋阴降火 |

> **一个高频混淆点**：燥邪分温燥与凉燥。
>
> + **温燥**（初秋，兼热象）：发热、微恶风、口干渴、舌边尖红 → 桑杏汤方向
> + **凉燥**（深秋，兼寒象）：恶寒重、无汗、口不甚渴、苔白 → 杏苏散方向
>
> **方向一旦搞反，越治越重。**

#### 六淫的现代来源对照

古人的六淫来自气候，现代人的六淫很多来自人造环境与生活方式：

| 邪 | 现代来源 | 常见表现 |
| --- | --- | --- |
| **寒** | 空调直吹颈背、大量冷饮、冬季露踝 | 颈肩僵痛、痛经、腹泻 |
| **湿** | 久坐少动、居住潮湿、甜腻饮食、熬夜伤脾 | 身重、苔腻、大便黏、反复湿疹 |
| **燥** | 长时间空调暖气环境、用嗓过度 | 咽干、干咳、皮肤干痒 |
| **火** | 长期熬夜、辛辣、情绪压抑化火 | 口疮、失眠、目赤、便秘 |

> **这个对照的用处**：当你无法从"受没受凉"判断病因时，改问"生活方式里哪一项在持续输出这类邪气"。很多慢性病的病因不是一次性的外邪，而是**日复一日的生活方式在持续供邪**。

### 4_3 三大病理产物：痰、瘀、郁

这是临床上最该优先排查的三项。它们的共同特点是：**既是病理产物，又是新的致病因素**——会形成恶性循环。

```plain
   脾虚不运 ──→ 湿聚 ──→ 痰（随气升降，无处不到）
                             │
   气滞 / 气虚 ──→ 血行不畅 ──→ 瘀（久痛、肿块、舌暗）
                             │
   情志不遂 ──→ 气机郁结 ──→ 郁（气郁→血郁→痰郁→火郁→湿郁→食郁）
                             │
                             ▼
                    互相滋生，形成闭环

```

#### 痰：水液代谢失常的浓缩物

《医方集解》论二陈汤时有一个极精到的定义：

> 脾虚不能健运，则生痰饮。稠者为痰，稀者为饮，水湿其本也。得火则结为痰，随气升降，在肺则咳，在胃则呕，在头则眩，在心则悸，在背则冷，在胁则胀，其变不可胜穷也。

**这段话的实操价值在于**——痰不是一个固定的东西，而是**"水湿 + 火 + 气"三者的动态产物**。所以治痰不能只盯着化痰药，要问三件事：

1. **湿从哪来？**（脾虚不运 → 健脾燥湿）
2. **火从哪来？**（谁在煎熬它 → 清热或滋阴）
3. **气顺不顺？**（气顺则痰自降 → 理气）

| 痰的类型 | 特征 | 治法 | 代表方方向 |
| --- | --- | --- | --- |
| 湿痰 | 痰白稀、苔白腻、身重 | 燥湿化痰 | 二陈汤 |
| 热痰 | 痰黄稠、苔黄腻、口渴 | 清热化痰 | 清气化痰类方 |
| 寒痰 | 痰白泡沫、畏寒、苔白滑 | 温化寒痰 | 温肺化饮类方 |
| 燥痰 | 痰少而黏、难咳、咽干 | 润燥化痰 | 润肺化痰类方 |
| 风痰 | 眩晕、抽搐、口眼歪斜 | 熄风化痰 | 半夏白术天麻汤方向 |

#### 瘀：血行不畅的产物

识别要点：刺痛（固定不移）、肿块、肌肤甲错、唇舌紫暗、脉涩。

> **"久病必瘀"是临床上很实用的一条经验**——慢性病拖到一定时间，即使辨证主体不是瘀，也值得在方里加一二味活血药。

#### 郁：六郁之说

《医学三字经》引朱丹溪的"杂病法，四字求"——**气、血、痰、郁**是极实用的杂病入门框架。越鞠丸主治"六郁"（气、血、痰、火、湿、食），核心在于**气郁为先**：气郁则血郁、痰郁、火郁相继而生。

> **落地用法**：面对一个说不清病名的杂病，先问"情绪通不通"。气机一通，后面几郁常自动缓解。

### 4_4 传变：治现在的病，还是治三步后的病

这是本板块最值钱的部分。疾病不是静止的，它沿着固定路径移动。知道路径，就能提前布防。

#### 路径一：由表入里（伤寒六经）

```plain
   太阳（表）──→ 阳明（里热）──→ 少阳（半表半里）
        │                                      │
        └──────────→ 太阴 ──→ 少阴 ──→ 厥阴（三阴递进，正气渐衰）

```

#### 路径二：卫气营血的由浅入深（温病）

```plain
   卫（表浅·功能失常）──→ 气（里热）──→ 营（扰心神）──→ 血（动血伤阴）

```

#### 路径三：由上及下（三焦）

```plain
   上焦（肺·心包）──→ 中焦（脾胃·大肠）──→ 下焦（肝肾）

```

#### 路径四：五行相传（五脏之间）

《金匮要略》第一篇给出了最经典的传变规律：**一脏有病，会传它所克制的那脏**。肝木克脾土，所以肝病大概率先伤脾。

> **"治未病"的操作流程**（本板块最可落地的一条）：
>
> 1. 判断当前病位（如肝）
> 2. 推出它下一步会传哪（肝病传脾）
> 3. 在治疗主病的同时，给"未病之地"留一两味药作保险（疏肝方里配健脾药）
>
> 这就是"上工"与"中工"的分水岭——中工治已病的肝，上工同时稳住未病的脾。
>
> 另一句要配套记住的原文是"四季脾旺不受邪，即勿补之"——脾不虚时不必猛补，以免闭门留寇。

#### 路径五：由浅入深的痧毒分层（急症）

《痧胀玉衡》给出一套急症的分层路径，逻辑同样通用：**肌肤（气分）→ 血肉（血分）→ 肠胃经络脏腑**。由浅入深的递进，正是分层处理的依据（详见板块15）。

```plain
                    病邪深入方向
   肌肤 ──────→ 血肉 ──────→ 肠胃经络 ──────→ 脏腑
   （气分）      （血分）       （气机闭遏）      （内攻心君）
     │            │              │                │
    刮           放             药               药 + 刮放

```

> **统一规律**：五种路径都遵循同一个原则——**由外向内、由浅入深、由实致虚、由功能失常到物质损伤**。记住这一条，就能在没有现成模板时也推得出方向。

### 4_5 病机的三个"卡点"

疾病久治不愈，通常卡在三个地方。排查顺序如下：

| 卡点 | 表现 | 处理方向 |
| --- | --- | --- |
| **气机不通** | 胀、闷、嗳气、情绪相关、症状随情绪波动 | 理气为先，气行则血行痰化 |
| **脾胃不运** | 纳差、便溏、苔腻、服补药反而胀满 | 先运脾再进补，否则补药成负担 |
| **正气不支** | 久病、疲乏、脉无根、攻邪后更虚 | 转为扶正，或攻补兼施 |

> **一个高频陷阱**：虚证病人直接进补，越补越胀。原因多半是**气机不通或脾不运化**，补药变成了新的"湿"和"滞"。此时正确顺序是：**先通（理气、化湿）→ 再补**，或补中有通（如补中益气汤配陈皮）。

### 4_6 案例小故事：两个人同一天腹泻

**背景**：夏末秋初，同一天上午，门诊来了两位病人，主诉一字不差，都是"腹泻"。如果只看主诉，很容易开同一个方子。

**经过——第一位（急）**：男，二十八岁，前一天晚上在路边摊吃了两大盘冰镇西瓜加烧烤。来时腹痛剧烈、泻下急迫、肠鸣辘辘，泻后痛减不明显，手脚发凉但不至于畏寒，苔白腻，脉紧。发病至今不到二十四小时。他自述从前胃肠一直很好，很少闹肚子。

**经过——第二位（缓）**：男，四十五岁，腹泻已两年。每天清晨必泻一次，大便稀溏、夹有不消化物，遇紧张或出差加重，平时疲乏、纳差、手脚凉，舌淡胖有齿痕，脉沉细。他说这两年也断断续续吃过药，时好时坏。

**转机**：医生给两人做了同一件事——十秒钟的归因筛选——却得出两个完全不同的结论。

+ 第一位：**起病急、有明确诱因**（寒凉伤中）→ 归外因兼不内外因 → **祛邪为主**，温中散寒，一两剂可止。邪去则正安，不必久服。
+ 第二位：**起病缓、与作息年龄相关** → 归内伤 → 病位在脾肾（命门火衰，清晨阳气微而不能胜阴寒）→ **扶正为主**，须从温补脾肾入手长期调（四神丸、附子理中方向），且要配合起居与饮食的改变。

**复盘**：**同样是"腹泻"，起点不同，一个是急症，一个是慢病。** 十秒钟的归因筛选就能把两者分开：问"急还是缓""有没有诱因"两句即可。

跳过这一步直接对症止泻，后果是：第一位可能自愈而误以为药有效（他的病本有自限性）；第二位则永远好不了——因为止泻药只处理了结果，没处理"命门火衰"这个因。用一句可以记住的话收尾：**对症处理能止住一次腹泻，却止不住一个病。**

### 4_7 本板块的笔记动作与验证

**笔记动作**：做一张"病因溯源表"。每遇到一个真实问题（自己的或家人的），填三栏：起病方式（急/缓）、可能诱因（外邪/情志/饮食/劳倦/意外）、所属三因。积累十份之后，你会发现自己的归因能力明显变快。

**验证方法（三选一）**：

1. **十秒归因**：给出三个场景——"淋雨后次日恶寒发热""常年便溏遇紧张加重""搬重物后腰痛"，分别判断属于哪一类因，以及以祛邪为主还是调脏腑为主。
2. **六淫反推**：给出"皮肤干痒、咽干、干咳少痰、大便干"，判断是温燥还是凉燥，并说出选方方向（温燥用桑杏汤方向，凉燥用杏苏散方向）。
3. **传变预演**：一位肝郁病人，预判下一步最可能传哪一脏，并说出你会在方里加哪一类药作保险（答案：传脾，加健脾药）。
