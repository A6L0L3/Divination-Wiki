### 12_1 内科杂病的四个高地

《金匮要略》的价值在于**病—证—方三位一体**。全书二十五篇、二百六十二首方剂，覆盖四十余种病种，但真正的价值不在"方子多"，而在"方子少而精准"——**每一条条文都是一个标准化诊断流程，每一首经方都是一套专属治疗方案**。

#### 12_1_1 高地一：胸痹心痛 → 冠心病、心绞痛的最早系统论述

核心病机：**"阳微阴弦"**

- **阳微**：寸脉微，上焦阳气虚衰
- **阴弦**：尺脉弦，下焦阴寒痰浊壅盛
- 两者相遇 → 胸阳被遏，不通则痛

> **现代对应**：冠状动脉供血不足、心肌缺血、脂质斑块沉积。可以理解为**上边供血不够（阳虚），下边垃圾太多（痰浊阴弦），堵在中间**。

| 方剂 | 病机 | 现代对应 |
| --- | --- | --- |
| 瓜蒌薤白白酒汤 | 胸阳不振，痰阻胸中 | 稳定型心绞痛，胸闷心悸为主 |
| 瓜蒌薤白半夏汤 | 痰浊更甚，痰气互结 | 痰浊血瘀型，伴咳喘、体胖痰多 |
| 枳实薤白桂枝汤 | 气结痰凝，胸满而痛 | 胸闷气憋明显，情绪诱因大 |
| 乌头赤石脂丸 | 阴寒极盛，心痛彻背 | 寒凉体质，冬季发作加重 |

> **两个致命细节**：汉代剂量换算（见板块9）；**附子需要先煎减毒**。这两个看起来是"考据"，其实是疗效和安全性的分水岭。
>
> **红线**：胸痛持续不缓解、放射至左臂或下颌，须按心血管急症处理，立即呼叫急救（见板块15）。

#### 12_1_2 高地二：痰饮咳嗽 → 哮喘、慢支、代谢综合征的总开关

**"温药和之"四个字，是全书最重要的治疗原则之一**——痰饮属寒，要用温药（而非寒凉清热）来化解。

射干麻黄汤"咳而上气，喉中水鸡声"的描写，精准对应支气管哮喘、慢性喘息性支气管炎。

> **现代延伸**：痰饮病本质是"水液代谢失常"。所以苓桂术甘汤不仅能治慢性支气管炎，还能改善高血脂、肥胖、代谢综合征——**同一个方子，对付的是"水湿代谢紊乱"这个底层问题**。这就是"异病同治"的实际含义。

#### 12_1_3 高地三：百合病 → 神经官能症、焦虑、更年期的精神地图

原文描述如下：

> 百合病者，百脉一宗，悉致其病也。意欲食复不能食，常默默，欲卧不能卧，欲行不能行，欲饮食或有美时，或有不用闻食臭时，如寒无寒，如热无热，口苦，小便赤，诸药不能治，得药则剧吐利，如有神灵者，身形如和，其脉微数。

病位在心肺，病机是**阴虚内热**。诊断特征不是某一个症状，而是**"矛盾感"的集合**——想吃饭又吃不下、想睡又睡不着、想动又动不了。这种"什么都想但又都做不好"的状态，恰恰是焦虑、抑郁、更年期障碍的典型表现。

> **落地提示**：遇到主诉一长串、但各项检查都正常的病人，想一想百合病。它的抓手不是"哪个症状"，而是**症状之间的矛盾性**。原文"身形如和，其脉微数"八个字尤其关键：外表看着没大病，只有脉象泄露了阴虚内热。

#### 12_1_4 高地四：肝病的辨治总则

肝病的表达永远是"堵"和"逆"——因为它"只管疏通、不主管"（见板块2）。

| 类型 | 表现 | 方向 |
| --- | --- | --- |
| 肝气郁结 | 胁胀、善太息、情绪抑郁、脉弦 | 疏肝理气（柴胡疏肝散方向） |
| 肝郁脾虚 | 胁胀 + 纳差便溏疲乏 | 疏肝健脾（逍遥散方向） |
| 肝火上炎 | 口苦、目赤、易怒、头痛、脉弦数 | 清肝泻火（龙胆泻肝汤方向） |
| 肝阳上亢 | 眩晕、耳鸣、头重脚轻、脉弦有力 | 平肝潜阳（天麻钩藤饮方向） |
| 肝血不足 | 眩晕、视物模糊、爪甲不荣、月经量少 | 养血柔肝（四物汤、杞菊地黄方向） |
| 肝阴不足 | 胁肋隐痛、咽干、舌红少苔 | 滋阴柔肝（一贯煎方向） |

### 12_2 血证：唐容川的三个突破

《血证论》为清代唐宗海（字容川，四川彭县人）所著，成书于光绪十年（1884），凡八卷。作者因父、妻相继为血证所苦，遍览方书而自悟，终成此书。它第一次把"出血性疾病"当作一个**独立的系统学科**来建构：有生理、有病机、有治法次第、有分部位证治、有兼见证、有方解。

#### 12_2_1 突破一：定位先于定性

把一切血证收拢为四类——血上干（吐、咳、衄）、血外渗（汗血、血箭、刀伤）、血下泄（便血、尿血、崩漏）、血中瘀（瘀血、蓄血、经闭），以及失血兼证（痨、嗽、发热、怔忡）。卷一立总纲，卷二至卷五按"血的去向"分证，卷六专论兼见诸证，卷七、卷八详解方剂。

> **实操启示**：面对任何出血或瘀血症，先判断它属于哪一类，再定治法方向。**这个"定位先于定性"的思路，比一上来辨寒热虚实更优先。**

#### 12_2_2 突破二：治血必治气、治血先治火

> 人之一身，不外阴阳，而阴阳二字，即是水火，水火二字，即是气血。水即化气，火即化血。气与水，本属一家，治气即是治水；血与火，原是一家，知此乃可与言调血矣。

- **气结则血凝，气虚则血脱，气迫则血走**——气的三种失常，对应血的三种病变
- **气盛即为火盛，火升故血升，火降即血降**——所以"泻火即是止血"
- 治气的关键在**脾胃**（后天气血生化之源），治火的落脚点常在**阳明胃腑**

> **这是全书最可落地的一条总纲**：上消化道出血、咳血、鼻衄，只要见"气火上冲"之势（面赤、心烦、脉数有力），核心动作永远是**降气、降胃、降火**，而不是堆砌止血炭药。

#### 12_2_3 突破三：脾阴学说，打破"补脾只补脾阳"的偏见

李东垣之后，医家重脾胃者多只知温补脾阳。唐容川用一个著名比喻扳正了这个偏：

> 譬如釜中煮饭，釜底无火固不熟，釜中无水亦不熟也。

- 脾阳虚 → 水谷不化（釜底无火）→ 四君子、理中辈
- **脾阴虚 → 水谷仍不化（釜中无水）**→ 当以润燥、益血、滋脾阴，如麦冬养荣汤、甲己化土汤、四君子加黄精山药玉竹

他甚至给出一个颠覆性的比例判断：**当补阳者十之二三，当补阴者十之八九**。这对后世"阴虚内热型出血"的诊治影响极大——今天见慢性失血、口干、脉细数、大便干结者，思路多从此出。

### 12_3 治血四步法

```plain
   第一步  止血 ──── 急则治标，但不可骤用止涩（防留瘀）
        │
   第二步  消瘀 ──── 离经之血即为瘀，不去则变证丛生
        │
   第三步  宁血 ──── 消除出血原因（清火、降气、补脾等）
        │
   第四步  补虚 ──── 气血亏虚者，善后调补

```

> **"离经之血即为瘀"是全书最锋利的一句**。血一旦离开脉道，就变成了病理产物（瘀），不去则会阻碍新血归经、变生他病。所以**止血之后必须消瘀**，这也是为什么唐容川反对一见出血就堆砌收涩止血药。

#### 12_3_1 出血部位 → 脏腑归属

| 出血表现 | 指向脏腑 | 机理 |
| --- | --- | --- |
| 吐血、呕血 | 胃（因怒火逆者属肝） | 气逆血升 |
| 衄血、咯血 | 肺 | 火风暑燥犯肺 |
| 痰涎中带血丝 | 脾 | 脾虚不摄 |
| 唾血、咳血成块 | 肾 | 房劳伤肾，火载血升 |
| 尿血、便血 | 肾 / 大肠膀胱 | 阴虚阳搏或湿热下陷 |
| 耳、目、齿缝出血 | 肝肾 / 胃肾 | 相火扰动或胃火上冲 |

> **四句铁律**（《类证治裁》）：**不可骤用止涩，不可专行腻补，不可轻用苦寒，不可妄用攻伐。**
>
> **红线**：任何明显出血（呕血、咯血、便血量大）均须立即就医，不以本板块内容自行处理。

### 12_4 异病同治：同一病机，不同病名

这是中医最有解释力的部分，也是最能体现"辨证论治"四个字的地方。

| 病机 | 可表现的病名 | 共同方方向 |
| --- | --- | --- |
| **中气下陷** | 胃下垂、子宫脱垂、久泻、脱肛、气虚发热 | 补中益气汤 |
| **水湿代谢紊乱** | 慢支、眩晕、血脂异常、肥胖、水肿 | 苓桂术甘汤类 |
| **肝脾不和** | 肠易激、痛泻、经前腹泻 | 痛泻要方 |
| **痰气互结** | 梅核气（咽中如有物阻）、部分结节 | 半夏厚朴汤 |
| **心脾两虚** | 失眠、心悸、月经量少、崩漏、贫血 | 归脾汤 |
| **肾气不固** | 遗尿、滑胎、久泻（五更泻）、遗精 | 补肾固涩类 |

> **用法提示**：遇到一个久治不愈的问题，横向问一下"这个病机还会在哪些病名下出现"，往往能找到新思路。**病名是标签，病机才是把手。**

### 12_5 案例小故事：一个"上火"半年的病人

**背景**：女，四十二岁，反复头面烘热、口腔溃疡半年，伴下肢冰凉、大便溏薄。

**经过**：她自判为"上火"，自行服用"清火"类中成药。初服稍缓——这"稍缓"很要命，因为它给了她一个错误的正反馈：方向是对的，只是药力不够。于是久服，久服之后出现胃脘胀满、食欲下降，而溃烂面反而更难愈合。半年下来，人瘦了一圈，天冷时下肢冰凉更明显。

**转机**：改用三个独立信源重新采集——

- **望**：面色偏白，两颧午后泛红（**浮红，非满面通红**）；舌淡胖有齿痕、苔白微腻，舌尖略红
- **问**：自觉上火，但**喜温恶凉**，冬天症状加重；白天动则汗出，夜间不明显；纳差、食后腹胀、喜热饮；大便溏薄、小便清长；**入暮后烘热加重，清晨疲乏而烘热轻**
- **切**：脉浮取略数、中取无力，**沉取细弱，尺部尤甚**

三个信源全部指向虚寒，与"上火"的主诉相矛盾。而这个矛盾，正是破题的钥匙。

**复盘**：她不是实火，而是**虚阳上浮**——中焦脾胃阳虚，气机升降枢纽失职，阳气不能下归而浮于上。久服寒凉之所以加重，正是因为苦寒进一步损伤了阳气，"越清越虚、越虚越浮"。

### 12_6 本板块的笔记动作与验证

**笔记动作**：建立"病机—病名对照表"。横轴写病机（中气下陷、水湿代谢紊乱、肝脾不和等），纵轴写病名。每学一个新病机，就往表里填一行。**这张表是"异病同治"能力的训练场**。

**验证方法（三选一）**：

1. **阳微阴弦**：解释"阳微阴弦"的含义，并说出它对应的现代疾病与胸痹的方证方向。
2. **治血四步**：默写出止血、消瘀、宁血、补虚四步，并解释为什么"不可骤用止涩"。
3. **脾阴学说**：用"釜中煮饭"的比喻，说明脾阴虚与脾阳虚的治法差异。
