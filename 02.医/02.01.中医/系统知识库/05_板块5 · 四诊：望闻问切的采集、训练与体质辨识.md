## 板块5 · 四诊：望闻问切的采集、训练与体质辨识

> **本板块解决一个问题**：面对一个人，你怎么把他身上散乱的信息，采集成一份**可用于辨证的结构化清单**？
>
> 顺序是固定的：**先望（不打扰、不干扰）→ 再闻问（听他说）→ 最后切（用脉验证）**。这个顺序不能颠倒——尤其不能把脉放在最前面，因为**脉是四诊之末，是验证工具，不是判断起点**。

---

### 5_1 为什么顺序不能颠倒

《濒湖脉学》的序里有一句被反复忽略的话：

> 世之医病两家，咸以脉为首务，不知脉乃四诊之末，谓之巧者尔。上士欲会其全，非备四诊不可。

意思是：医生与病人都把脉当第一要务，却不知脉诊是四诊里排最后的一项，只是"巧"而已。高明的人要掌握全局，非四诊齐备不可。

**顺序的原理**：望诊不打扰病人、不受医生主观引导；闻问能听到主诉与病史；切诊最容易被主观预期污染（你已经听了主诉，再去摸脉，很容易"摸出"你预想的脉）。所以脉的正确角色是**验证与补漏**，而不是开局定调。

```plain
     望（客观·不打扰）
          │
          ▼
     闻 → 问（听主诉·问病史）
          │
          ▼
     切（验证·补漏）
          │
          ▼
   三源交叉验证（不一致处即线索，见板块18）

```

---

### 5_2 望诊：先看"神"，再看"色"，最后看"形"

望诊排第一不是习惯，而是因为**它是唯一不需要患者配合、也不受医生主观干扰的通道**。三个递进层次：

#### 5_2_1 第一层：望神（最重要，也最容易被跳过）

神是生命活动的外在表现。看三样：目光是否灵动有神、神志是否清楚、反应是否灵敏。

| 状态 | 表现 | 意义 |
| --- | --- | --- |
| **得神** | 目光有神、神志清、反应灵敏 | 虽病不重，预后好 |
| **少神** | 精神萎靡、目光乏神 | 正气已伤 |
| **失神** | 目光呆滞、神志模糊、面色晦暗 | 精气衰败，病情重 |
| **假神** | 久病重病之人突然精神转好、面红如妆、食欲陡增 | **这是回光返照，不是好转，是危象** |

> **为什么先望神**：《灵枢》说"粗守形，上守神"。一个"失神"的病人，哪怕症状清单看着平常，优先级也要立刻提上来。

#### 5_2_2 第二层：望色

《金匮要略》第一篇给出了可直接对照的条目：鼻头色青 → 腹中痛；色微黑 → 有水气；色黄 → 胸上有寒；色白 → 亡血；又曰"目正圆者痉，不治"。

| 面色 | 主病 | 典型场景 |
| --- | --- | --- |
| 青 | 寒证、痛证、瘀血、惊风 | 剧烈腹痛、小儿惊风 |
| 赤（满面通红） | 实热 | 高热、肝阳上亢 |
| 赤（两颧潮红） | **虚热、虚阳上浮** | 结核病、更年期、久病之后 |
| 黄（鲜明如橘） | 阳黄——湿热 | 急性黄疸型肝炎 |
| 黄（晦暗如烟熏） | 阴黄——寒湿 | 慢性肝病、胆道梗阻 |
| 白（淡白无华） | 血虚、气虚、失血 | 贫血、大出血后 |
| 白（㿠白虚浮） | 阳虚水泛 | 肾病水肿 |
| 黑（晦暗） | 肾虚、寒证、瘀血、水饮 | 慢性肾病、肾上腺皮质功能减退 |

> **实操提醒**：突然面色㿠白 + 口干却不想喝水 → 警惕脱血脱水；眼睑浮肿 + 面色黑黄 → 警惕水气或肾病。**这些不是玄学，是有依据的体征。**

> **"两颧潮红 vs 满面通红"是临床最实用的一条鉴别**：前者是虚火浮于表（颧红、浮浅、午后明显），后者是实热充斥（满面、深红、持续）。这条鉴别在板块19的实战病例里会再次出现，而且是破题的关键。

#### 5_2_3 第三层：望形

看体型胖瘦、姿态动静。《类证治裁》把虚损一刀砍成两截，靠的就是形体与寒热偏好：

- 形体肥胖、肌肉松软 → 多偏**气虚痰湿**
- 形体瘦长、皮肤干燥 → 多偏**阴虚火旺**

### 5_3 舌诊：最客观、最可自学的观察窗口

舌诊是四诊里**客观性最强、最适合普通人自学**的一项。原因有三：舌象直观可见、变化相对稳定、且能反复对比。中医认为"舌为心之苗""舌为脾胃之外候"——心主血脉开窍于舌，脾胃化生的精微上输濡养舌体并滋生舌苔；肝经络舌本、肾经挟舌本、肺系连舌体，**五脏经络皆通于舌**。

《黄帝内经》已有舌诊记载，元代《伤寒金镜录》是现存最早的舌诊专著，明清温病学派进一步把舌诊推向成熟。

#### 5_3_1 舌诊的观察顺序（固定）

```plain
   1. 舌质（舌体本身）     ──→ 看正气：虚实、寒热
   2. 舌苔（舌面覆盖物）   ──→ 看邪气：表里、深浅、湿浊
   3. 舌形（胖瘦齿痕裂纹） ──→ 看形质：气虚、血虚、阴虚
   4. 舌态（歪斜震颤僵硬） ──→ 看风、痰、经络

```

#### 5_3_2 速查表

| 舌象 | 主病 | 常见病机 |
| --- | --- | --- |
| 舌淡白而胖嫩、边有齿痕 | 阳虚、气虚、水湿 | 脾肾阳虚，水湿不化 |
| 舌淡白而瘦薄 | 气血两虚 | 化源不足 |
| 舌红、苔黄 | 实热 | 邪热亢盛 |
| 舌红、少苔或无苔 | 阴虚 | 阴液亏耗 |
| 舌绛（深红） | 热入营血 | 温病深重阶段 |
| 舌紫暗、有瘀点 | 血瘀 | 气滞寒凝或热结 |
| 舌体胖大、苔白腻 | 寒湿、痰饮 | 脾阳不运 |
| 舌苔厚腻（无论黄白） | 湿浊、食积、痰饮 | 中焦壅滞 |
| 舌苔剥落（地图舌） | 胃气阴两伤 | 多见于久病、小儿 |
| 舌体歪斜 | 风痰阻络 | 中风先兆或后遗 |
| 舌体震颤 | 肝风内动 | 气血亏虚或热极生风 |

> **自学的两个纪律**：
>
> 1. **固定光线与时段**：晨起空腹、自然光下观察最准。刚喝过牛奶、咖啡、吃过有色食物会染色
> 2. **看趋势，不看单次**：连续记录七天，看舌象随什么变化（睡眠、饮食、情绪）。单次舌象的信息量有限，趋势才有价值

### 5_4 闻与问：怎么问才问得出东西

#### 5_4_1 闻诊

听声音、嗅气味。语声低弱无力多为虚，洪亮有力多为实；口臭多胃热或食积，腥臭多寒湿或疮疡。

#### 5_4_2 问诊：十问歌的原文与现代化改写

传统"十问歌"全文如下：

> 一问寒热二问汗，三问头身四问便，五问饮食六问胸，七聋八渴俱当辨，九问旧病十问因，再兼服药参机变，妇人尤必问经期，迟速闭崩皆可见，再添片语告儿科，天花麻疹全占验。

这份歌诀的顺序是按传统习惯排的。下面给一份按"信息密度"重排的现代版本，更适合快速上手：

| 序号 | 问什么 | 为什么问 | 鉴别指向 |
| --- | --- | --- | --- |
| 1 | **怕冷还是怕热？** | 第一刀切寒热 | 恶寒重 → 表寒；恶热 → 里热 |
| 2 | **有汗还是无汗？** | 表实表虚的分水岭 | 无汗 → 表实；有汗 → 表虚或里热 |
| 3 | **渴不渴？喜冷喜热？** | 津液与寒热 | 口渴喜冷 → 热；口不渴或喜热 → 寒 |
| 4 | **二便**（次数、性状、颜色、感觉） | 脾胃与肾的直接报告 | 溏薄 → 脾虚；干结 → 津伤或热结；清长 → 虚寒 |
| 5 | **饮食口味**（纳差、腹胀、喜恶） | 脾胃运化 | 食后胀 → 脾虚不运 |
| 6 | **睡眠**（入睡、易醒、多梦、时间规律） | 心神与阴阳 | 易醒 → 血虚或胆热；嗜睡 → 痰湿或阳虚 |
| 7 | **症状的时间规律**（早上重还是晚上重） | 景岳时间辨证 | 暮重 → 阳虚；夜半烦热 → 阴虚 |
| 8 | **情绪与压力** | 肝的疏泄 | 郁结 → 气滞，是杂病第一因 |
| 9 | **女性：经带胎产** | 气血与冲任 | 周期、量、色、质 |
| 10 | **既往治疗经过与反应** | 极重要，常被漏 | **吃了寒凉药加重的，多半不是实热** |

> **第 10 问的价值被严重低估**。一个人说自己"上火"，但如果他说"吃清火的中成药就胃胀、溃疡更难好"，这条信息比他说的"上火"本身更可靠。这是板块19实战病例的破题点。

### 5_5 脉诊：怎么练（九十天训练方案）

#### 5_5_1 先立骨架：浮沉迟数有力无力

《濒湖脉学》列二十七脉，但李时珍自己明确说"浮沉迟数，脉之纲领"。后世"浮沉分表里，迟数辨寒热，有力无力定虚实"就是由此化出。

二十七脉的阴阳属性，原书分列如下（这是全书的"索引"，先记阴阳，再记体状，才不会乱）：

- **阳脉（8）**：浮、数、实、长、洪、紧、动、促
- **阴脉（15）**：沉、迟、涩、虚、短、微、缓、革、濡、弱、散、细、伏、结、代
- **阳中阴（3）**：滑、芤、弦
- **阴中阳（1）**：牢

| 纲领 | 辨什么 | 核心提问 |
| --- | --- | --- |
| 浮 / 沉 | 病位深浅 | 轻按即得，还是重按始得？ |
| 迟 / 数 | 病性寒热 | 一息几至？慢于四至还是快于五至？ |
| 有力 / 无力 | 邪正虚实 | 按下去是充实，还是豁空？ |
| 形 / 势 / 律 | 气血津液状态 | 宽窄、滑涩、长短、节律整齐否？ |

```plain
   位（浮沉）─┐
   数（迟数）─┼──→ 五母脉练成条件反射 ──→ 再叠加形（洪细微弦紧滑涩）
   力（虚实）─┘                              与律（促结代）

```

> **最重要的学习建议**：初学者绝不该二十七脉齐头并进，而应先把**浮沉迟数有力无力**这"五母脉"练成条件反射，再逐个叠加。

#### 5_5_2 独取寸口与三部九候

《脉经》确立了"独取寸口"，理论基础来自《难经》："寸口者，脉之大会，手太阴之动脉也。"——寸口是全身经脉之气的交汇点（肺朝百脉）。《脉经》由西晋太医令王叔和编纂，是我国现存最早的脉学专著，首次系统归纳二十四种脉象。

| 部位 | 对应 | 提示 |
| --- | --- | --- |
| **寸**（腕横纹近掌侧） | 上焦（心、肺） | 寸脉微 → 上焦阳气虚 |
| **关**（桡骨茎突处） | 中焦（肝、脾、胃） | 关脉弦 → 肝郁 |
| **尺**（近肘侧） | 下焦（肾、命门） | **尺脉沉取有力是平脉标准之一**，尺弱 → 肾气不足 |

#### 5_5_3 九十天训练方案

| 阶段 | 时间 | 动作 | 目标 |
| --- | --- | --- | --- |
| 第一阶段 | 第 1–30 天 | 每天只摸自己（或固定一人）的脉，只回答四个问题：浮还是沉？快还是慢？有力还是无力？流利还是艰涩？ | 建立"手感基线"，认识平脉 |
| 第二阶段 | 第 31–60 天 | 每天加摸一个不同年龄 / 体型的人，记录差异；重点练浮沉与有力无力 | 感知个体差异，识别虚实 |
| 第三阶段 | 第 61–90 天 | 每次诊前先写预判（从望问诊得出），再摸脉验证；记录"预判与脉象一致 / 不一致" | 建立交叉验证习惯 |

> **操作规范**：让被诊者静坐五分钟，排除运动、情绪、饮食干扰；医者同步深呼吸，让自己心率降到平稳状态才能准确计数。**每次诊脉至少两侧各满五十次搏动**再下结论——单侧把脉不足一分钟会漏判节律异常。
>
> **平脉基准**：一息四至五至（约 60–90 次/分）、从容和缓、节律均匀、**尺脉沉取有力**。
>
> **季节修正**：春弦、夏洪、秋毛、冬石——**脱离季节谈脉象，十有八九是错的。**

### 5_6 体质辨识：九种体质的自测

体质是"长期稳定的偏性"，与"当下的证型"不同：证是变量，体质是底色。知道自己（或家人）的体质，很多日常调养问题就不用反复纠结。

| 体质 | 主要特征 | 常见倾向 | 调养方向 |
| --- | --- | --- | --- |
| **平和质** | 精力充沛、睡眠好、适应力强 | 少病 | 维持即可，不折腾 |
| **气虚质** | 容易疲乏、气短、自汗、易感冒 | 反复外感、脏器下垂 | 健脾益气，忌过劳大汗 |
| **阳虚质** | 畏寒肢冷、喜热饮、大便溏 | 寒证、水肿、痛经 | 温补脾肾，忌生冷 |
| **阴虚质** | 手足心热、口干咽燥、盗汗、便秘 | 虚火、失眠、干咳 | 滋阴润燥，忌辛辣熬夜 |
| **痰湿质** | 形体肥胖、身重困倦、苔腻 | 代谢综合征、血脂血糖异常 | 化痰利湿，重在运脾 |
| **湿热质** | 面垢油光、口苦口臭、苔黄腻 | 痤疮、黄疸、泌尿系感染 | 清热利湿，忌油腻辛辣 |
| **血瘀质** | 面色晦暗、易有瘀斑、刺痛固定 | 心脑血管病、痛经、肿块 | 活血化瘀，注意气机 |
| **气郁质** | 情绪低落、胸胁胀、善太息 | 抑郁倾向、乳腺甲状腺问题 | 疏肝理气，运动与社交 |
| **特禀质** | 过敏、先天禀赋异常 | 哮喘、荨麻疹、过敏性鼻炎 | 避免过敏原，扶正固表 |

> **用法提示**：体质是"底色"，不是诊断。一个人可以同时是气虚兼痰湿。判断体质的意义在于**长期调养的方向**，急性病仍要按当下的证型处理。

### 5_7 三个独立信源：把采集变成可验证的

三个信源的独立性，是采集质量的保证：

| 信源 | 采集内容 | 独立性来源 |
| --- | --- | --- |
| 问诊 | 主诉、寒热、汗、二便、睡眠、时间规律 | 病人主观报告 |
| 望诊 | 神色形、舌象 | 医者客观观察 |
| 切诊 | 脉象、穴位压痛 / 温度 | 医者触觉 |

> **三者不一致时，先怀疑自己的采集，而不是挑一个顺眼的信。**
>
> **不一致点往往是最重要的线索**。板块19的实战病例里，病人主诉"上火"，但三个信源全都指向虚寒——这个矛盾不是要抹平的噪声，而是破题的钥匙。其原理见板块18。

### 5_8 案例小故事：一次漏诊的教训

**背景**：一位五十岁的男性，因"最近总累"来就诊。这是最难处理的一类主诉——没有具体部位，没有伴随症状的主动描述，而且听起来太普通。

**经过——第一次看诊**：医生听完这四个字，便请他伸手，开始摸脉。指下细弱无力，于是判为气虚，开了补中益气汤思路的方子，嘱服两周。

两周后复诊，病人说："疲乏没减，好像更闷了。"医生当时以为是药效未显，又原方续服一周。第三周，病人自觉胸闷加重，夜里也睡不踏实，这才换了医生。

**经过——第二次看诊**：另一位医生换了采集顺序。

先**望**：面色偏晦暗、唇色偏暗；再看舌——舌质暗红、舌边有数枚瘀点。这一条本来最客观、最容易发现，却被第一次的诊疗整个跳过了。

再**问**：除了疲乏，还有没有别的？病人这才想起来：左侧胸胁有一处固定位置的隐痛，夜间加重，有时夜里会被憋醒。他此前没说，是因为"以为累了都这样"。

最后**切**：脉细而涩——不是单纯的细弱，指下往来艰涩，如轻刀刮竹。

**转机**：三个信源合起来指向**血瘀**，而非单纯气虚。改以活血化瘀为主、益气为辅，症状才逐步缓解。

**复盘**：第一次的问题有两处。一是**把脉放在了最前面**，而且只摸了一个维度（力），忽略了流利度；二是**跳过了望诊**，舌上的瘀点就这样被漏掉了。而病人之所以没主动说胸痛，是因为他自己也不认为这跟"累"有关——这正是单靠问诊必然出现的盲区。

用一句可以记住的话收尾：**任何一次"听完主诉就摸脉"的诊疗，都已经在冒险。** 望诊之所以排第一，就是因为它不需要病人知道什么该说。

### 5_9 本板块的笔记动作与验证

**笔记动作**：建立"四诊采集模板"，每次练习填一份。模板固定八栏：神、色、舌质、舌苔、寒热、汗、二便、脉（浮沉迟数有力无力）。强迫自己按望 → 闻问 → 切的顺序填写，不许跳序。

**验证方法（三选一）**：

1. **五母脉测试**：连续七天，每天记录自己脉象的浮沉、迟数、有力无力，看是否稳定；若七天结果差异很大，说明手感尚未建立。
2. **舌象趋势记录**：连续七天晨起观察（或描述）舌象，并同时记录前一晚的睡眠与饮食，找出相关性。
3. **三角验证演练**：找一个真实问题，分别写下问诊、望诊、切诊三个信源各自的指向，检查是否一致；若不一致，写出你对不一致的解释。
