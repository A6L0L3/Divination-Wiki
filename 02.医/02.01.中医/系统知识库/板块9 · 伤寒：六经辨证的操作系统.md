## 板块9 · 伤寒：六经辨证的操作系统

> **外感病的第一套操作系统**。伤寒看六经——**横着走，由表入里**。
>
> 本板块的目标不是背条文，而是建立一种能力：面对一个外感病人，**在三分钟内锁定病位与病机，并开出第一张方向正确的方子**。

---

### 9_1 六经不是六个病，是六个"切面"

很多人初读《伤寒论》最大的误解，是把"六经"理解为六条经络上的巡诊路线。这是致命的起点偏差。

张仲景借用了《内经》的"六经"之名，却赋予全新内涵——**六经是人体由外到内、由浅深切出的六个圈层，每一层是一种"气化状态"，而非一个固定器官**。

| 切面 | 层级 | 性质 | 关键词 |
| --- | --- | --- | --- |
| 太阳 | 最表层·藩篱 | 阳·表 | 营卫不和、正邪交争于表 |
| 阳明 | 里热·腑实 | 阳·里 | 燥、实、津伤 |
| 少阳 | 半表半里·枢纽 | 阳·枢 | 气机郁滞、枢机不利 |
| 太阴 | 中焦·脾胃 | 阴·表（三阴之始） | 湿、脾阳虚、寒湿 |
| 少阴 | 根基层·心肾 | 阴·里 | 阳气衰微 / 阴虚火旺 |
| 厥阴 | 最深·阴阳交争 | 阴·枢 | 寒热错杂、风从内生 |

```plain
   三阳（正盛邪实，易治）        三阴（正虚邪陷，难治）
   ┌──────────────────┐        ┌──────────────────┐
   │ 太阳（表·营卫）    │        │ 太阴（脾·寒湿）   │
   │ 阳明（里·燥实）    │        │ 少阴（心肾·衰微） │
   │ 少阳（枢·郁滞）    │        │ 厥阴（枢·寒热错杂）│
   └──────────────────┘        └──────────────────┘
        ▲                                ▲
        │                                │
        └──────── 由表入里、由浅入深 ─────┘

```

> **核心洞见**：每一经不是一个症状，而是一整片"圈层的气化状态"。
>
> **三阴病的本质不是"病更重"，而是"根基更虚"**——同样的便秘，阳明是热盛津伤的燥结，少阴是阳气衰微推动无力，治法截然相反。

### 9_2 底层公理：四条线先刻进脑子

无论条文多么繁杂，所有条文最终都落在四根柱子上。

1. **阴阳为纲**：先分阴阳，再谈别的。三阳病多阳证（实、热），三阴病多阴证（虚、寒）
2. **表里为界**：病在哪一层
3. **寒热为性**：是热还是寒
4. **虚实为势**：正邪谁占上风

> **实操口诀（背这个，比背条文有用）**：
>
> + 恶寒发热 + 汗出 → 营卫不和 → 桂枝汤方向
> + 恶寒发热 + 无汗 → 表闭寒郁 → 麻黄汤方向
> + 口渴 + 大汗 + 脉洪 → 热盛津伤 → 白虎汤方向
> + 口苦咽干目眩 → 枢机不利 → 小柴胡汤方向

### 9_3 太阳病：营卫的微观拆解（最容易上手的一章）

太阳病的全部病机，根源只有一个词——**营卫失调**。把这个理搞透，太阳篇就通了。

#### 营与卫的本质

+ **营**行于脉中，属阴，主"疏"、主释放，禀肝血疏泄之性
+ **卫**行于脉外，属阳，主"密"、主固摄，禀肺气收敛之性
+ **正常状态**：营疏卫密，一疏一密、一收一泄，维持气机出入平衡

```plain
   正常： 卫（密·固摄）  ←→  营（疏·释放）      平衡
   中风： 卫不密（汗出）  →   营外泄             营卫不和 → 桂枝汤
   伤寒： 卫被遏（无汗）  →   营郁滞             表实闭郁 → 麻黄汤

```

#### 风邪与寒邪的不同进门方式

**风邪**偏开泄，伤人则卫不固、营外泄 → 汗出、恶风、脉浮缓 → **表虚** → 桂枝汤（调和营卫）。

**寒邪**偏收引，伤人则卫被遏、营郁滞 → 无汗、恶寒、脉浮紧 → **表实** → 麻黄汤（发汗解表）。

> **这一组对比是整个太阳篇的钥匙**：同样是"恶寒发热"，**有汗与无汗是分水岭**。
>
> 用反了会怎样？表实无汗用桂枝汤，汗出不透、邪留不去；表虚有汗用麻黄汤，发汗太过、亡阳伤津。

#### 太阳病的完整方阵

一个太阳切面里藏着的完整方阵：

| 方 | 病机 | 抓证 |
| --- | --- | --- |
| 麻黄汤 | 太阳表实 | 恶寒、发热、无汗、头身痛、脉浮紧 |
| 桂枝汤 | 太阳表虚（营卫不和） | 发热、汗出、恶风、脉浮缓 |
| 麻杏石甘汤 | 表邪未解、邪热壅肺 | 汗出而喘、口渴、脉浮数 |
| 小青龙汤 | 外寒内饮 | 恶寒、无汗、喘咳、痰多清稀 |
| 五苓散 | 太阳蓄水 | 小便不利、微热、消渴、或水入即吐 |
| 桃核承气汤 | 太阳蓄血 | 少腹急结、小便自利、其人如狂 |

### 9_4 阳明与少阳：里热与枢纽

#### 阳明：里热、燥、实、津伤

| 类型 | 病机 | 抓证 | 方方向 |
| --- | --- | --- | --- |
| **阳明经证** | 无形邪热弥漫（气分热盛） | 大热、大汗、大渴、脉洪大 | 白虎汤 |
| **阳明腑证** | 燥屎内结 | 痞满燥实、日晡潮热、谵语、手足濈然汗出、脉沉实 | 承气汤类 |

> **白虎与承气的分界**：一个治"无形之热"（经证，热邪弥漫未与糟粕相结），一个治"有形之结"（腑证，燥屎已成）。简单判断：**看大便与腹诊**——便秘、腹满硬痛、潮热谵语是腑证；大渴大汗脉洪大而大便尚可，是经证。

#### 少阳：半表半里、枢机不利

**抓证**：口苦、咽干、目眩 + 往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕、脉弦。

> **"但见一证便是，不必悉具"**——这是少阳病最实用的一条诊断原则。只要见到"口苦、咽干、目眩、往来寒热、胸胁满"等任一特征性表现，且有少阳趋势，即可考虑和解少阳。
>
> **少阳的用药红线**：少阳病禁汗、禁下、禁吐，只宜**和解**——小柴胡汤是正治。

**小柴胡汤的加减法是《伤寒论》里最完整的临床加减示范**，原文列举如下：

| 兼见证 | 加减 |
| --- | --- |
| 胸中烦而不呕 | 去半夏、人参，加栝楼实一枚 |
| 渴 | 去半夏，加人参（加重）、栝楼根 |
| 腹中痛 | 去黄芩，加芍药 |
| 胁下痞硬 | 去大枣，加牡蛎 |
| 心下悸、小便不利 | 去黄芩，加茯苓 |
| 不渴、外有微热 | 去人参，加桂枝，温覆取微汗 |
| 咳 | 去人参、大枣、生姜，加五味子、干姜 |

> **把这一条加减读完，等于读完一部加减法教程**——它示范了"主证不变、兼证随加"的完整思路。

### 9_5 三阴：根基更虚，不是病更重

| 经 | 病机 | 抓证 | 方方向 |
| --- | --- | --- | --- |
| **太阴** | 脾阳虚、寒湿内停 | 腹满而吐、食不下、自利益甚、时腹自痛、脉弱 | 理中丸类（温中健脾） |
| **少阴寒化** | 阳气衰微 | 脉微细、但欲寐、四肢厥冷、下利清谷 | 四逆汤类（回阳救逆） |
| **少阴热化** | 阴虚火旺 | 心中烦、不得卧、舌红少苔、脉细数 | 黄连阿胶汤类（滋阴降火） |
| **厥阴** | 寒热错杂、上热下寒 | 消渴、气上撞心、心中疼热、饥而不欲食 | 乌梅丸类（寒热并用） |

> **少阴病"但欲寐"三个字极有分量**：不是困，是精神极度衰惫、似睡非睡、呼之能应随即又睡。这是阳气衰微、心神失养的表现，属于需要高度警惕的状态——**发现此类表现应尽快就医，不作自行处理**。

**四逆汤与理中丸的分界**是三阴辨证的实用练习：同是下利，理中丸治"自利不渴"（太阴，寒湿在中焦）；四逆汤治"下利清谷、四肢厥冷、脉微细"（少阴，阳气衰微在下焦）。**差别在于有没有"厥冷"和"脉微"**——有，就到了少阴。

### 9_6 方证对应：抓主证，不追求条文全对

《伤寒论》的临床用法，后世总结为"**有是证，用是方**"。它的操作方式是抓"主证"——那一个或几个决定性的指征，而不是要求所有症状都对上。

| 方 | 主证（决定性指征） |
| --- | --- |
| 桂枝汤 | 汗出、恶风、脉浮缓 |
| 麻黄汤 | 无汗、恶寒、脉浮紧 |
| 白虎汤 | 大热、大渴、大汗、脉洪大 |
| 承气汤类 | 痞满燥实、潮热谵语、脉沉实 |
| 小柴胡汤 | 往来寒热、胸胁苦满、口苦脉弦 |
| 理中丸 | 自利不渴、腹满、寒多 |
| 四逆汤 | 四肢厥冷、下利清谷、脉微细 |
| 五苓散 | 小便不利 + 口渴（或水入即吐） |
| 当归四逆汤 | 手足厥寒、脉细欲绝（血虚寒凝，非阳气衰） |

> **当归四逆汤与四逆汤的鉴别是经典分水岭**：两者都治"四肢厥冷"。四逆汤之厥是**阳气衰微**（脉微细、下利清谷、但欲寐），当归四逆汤之厥是**血虚寒凝**（脉细欲绝、手足厥寒而身无大寒大热、或见肢体疼痛）。一个回阳，一个养血通脉。

### 9_7 经方剂量：必须知道的争议

《伤寒论》的剂量换算是一个无法绕开、也无法自行解决的问题。

> **必须先知道它存在争议**：主流考证有"一两约合十余克"的大剂量说（依据汉代衡器实物），也有"经方一两约合三克"的小剂量说（认为经方剂量另有一套权衡）。各家依据不同，**结论差距可达四五倍**。

**实操立场**：

1. 这不是可以自己拍板的数字
2. 经方剂量必须在执业医师指导下使用，且需结合患者体质、年龄、病势与地域调整
3. **自行按某一换算系数照方抓药，是中医自学最危险的行为之一**——尤其在涉及附子、乌头、细辛、大黄等药物时
4. 另一个常被忽略的安全点：**附子需要先煎减毒**

> 这也是为什么本知识库中的古方剂量一律标注古制（如"三两"），不换算、不推荐现代克数——**正是为了避免"照方抓药"的危险**。

### 9_8 案例小故事：一场误用寒凉的感冒

**背景**：冬夜，一位二十来岁的男青年加班后冒雨骑车回家，到家已浑身湿透。当夜即觉恶寒，第二天发热，自测体温三十八度多。

**经过——自行处理**：他的判断很朴素——"发热就是上火"。家里备有清热类中成药，于是按说明书服用。连服两日，热未退，他以为剂量不够，又加量。

第三日，情况变了：热未退，反增咳嗽、气喘，痰白而清稀、泡沫多；恶寒更甚，裹着被子仍觉冷；至始至终**无汗**。舌淡苔白滑，脉浮紧。到这时他才觉得不对，来就诊。

**转机**：重新推演——

+ **八纲**：表（恶寒、无汗）、寒（痰白清稀、舌淡苔白滑、喜热）、实
+ **六经**：太阳表实 + 内有水饮
+ **误治分析**：清热寒凉之品用于表寒证，一伤阳气、二冰伏表邪。寒邪本该从表而解，被寒凉一压，出路被堵；阳气既伤，内饮无从温化，遂上逆为咳喘

方向修正为**解表散寒、温化水饮**（小青龙汤方向）。因方中含细辛、五味子等药物，须由执业医师处方并交代煎法。服药后得微汗，恶寒渐解，咳喘随之减轻。

**复盘**：同样是"发热"，寒邪所致者要辛温解表，温邪所致者要辛凉清解。**方向判断错误时，越"对证"地清热，越把邪气往里压**——他加量服用那一步，正好把病推深了一层。这正是叶天士说"若论治法则与伤寒大异也"的原因（见板块10）。

用一句可以记住的话收尾：**"发热"从来不是治法依据，"为什么发热"才是。** 而区分它们的第一个问题，永远是"怕冷重不重、口渴不渴"。

### 9_9 本板块的笔记动作与验证

**笔记动作**：做一张"六经主证表"。每经只写三行：一句话病机、决定性主证（不超过三个）、代表方方向。这张表的价值在于**逼自己放弃"记住所有症状"的企图**，转而抓决定性指征。

**验证方法（三选一）**：

1. **有汗无汗测试**：给出"发热、恶寒、汗出、脉浮缓"与"发热、恶寒、无汗、脉浮紧"，分别说出方方向与误用的后果。
2. **三阴鉴别**：给出"下利清谷、四肢厥冷、脉微细"与"手足厥寒、脉细欲绝、身无寒热"，判断分别是四逆汤还是当归四逆汤，并说明机制差异。
3. **经腑分界**：给出"大渴、大汗、脉洪大、大便尚通"与"潮热、谵语、腹满硬痛、便秘"，判断白虎还是承气。
