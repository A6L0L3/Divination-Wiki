## 板块15 · 急症与外治：分层判断、截断病势、及时上送

> **本板块处理的是"来不及慢慢辨证"的场景**。急症的特点是时间压力大、信息不完整、后果不对称——所以它的核心不是"治好"，而是**分层判断、截断病势、及时上送**。
>
> **红线前置**：本板块内容以文献理解与识别为主。凡涉及高热神昏、抽搐、大出血、昏迷、精神行为显著改变，**第一动作永远是送医或呼叫急救**，不以本板块内容自行处理。

### 15_1 《痧胀玉衡》：一部被书名耽误的急救手册

《痧胀玉衡》三卷，清·郭志邃（字右陶，嘉兴人）著，刊于康熙乙卯年（1675）。书名里的"玉衡"取自北斗第五星，喻**权衡轻重、决断生死**——这个书名本身就说明，作者要处理的不是养生保健，而是**急症分诊**。

#### 15_1_1 先解决一个误读：它不只是"刮痧书"

| 卷次 | 内容 | 对应的现代思维 |
| --- | --- | --- |
| 卷上·玉衡要语 | 痧源、痧脉、痧分表里、三法、禁忌、看症法 | 病因学 + 诊断标准 |
| 卷中·玉衡脉法 | 四十余种痧脉变异辨析 | 鉴别诊断（脉症不合） |
| 卷下·痧症类 | 四十余种痧症分证 + 治验 | 分证分型 + 病案 |
| 续刻 | 痧症变端、杂症兼痧 | 急症识别（隐藏在其他病中的痧） |

**最容易被漏掉的两点**：

1. **"痧"不是一种病，而是一种致病因素与病理状态**。郭氏的意思可以转述为：痧没有固定的脉，凡是脉与所患之症不相应的，就是痧的脉；痧也没有固定的症，凡是按本症治疗无效的，都要考虑痧。
→ 这等于把"痧"变成了一个**干扰项诊断**：**当常规治法无效时，要反过来怀疑"是不是有痧"**。
2. **"痧胀"的核心病机是"毒瘀内壅、气机闭遏"**。传变路径固定：**肌肤（气分）→ 血肉（血分）→ 肠胃经络脏腑**。这个由浅入深的递进，正是全书所有操作的分层依据。

> **读这本书的正确姿势**：把它当成一本"**当常规思路失效时，如何识别并处理气血闭遏**"的决策手册，而不是一本刮痧操作指南。

#### 15_1_2 总纲：刮、放、药三法分层

> 痧在肌肤者，刮之而愈；痧在血肉者，放之而愈；痧之深而重者，胀塞肠胃，壅阻经络，直攻乎少阴心君，非药不能救醒，非药莫能回生。则刮放之外，又必用药以济之，然后三法兼备。

| 病位 / 层次 | 病机 | 首选治法 | 判断信号 |
| --- | --- | --- | --- |
| **肌肤 · 气分** | 痧毒尚浅，在表 | **刮** | 胸中闷、作呕、腹痛初起；刮之即起痧点 |
| **血肉 · 血分** | 痧毒入血，瘀阻 | **放**（刺痧筋出血） | 欲吐不吐、欲泻不泻、盘肠吊痛；见青紫筋 |
| **肠胃经络 · 脏腑** | 痧毒内攻，昏迷不醒 | **药**（兼刮放） | 发晕、扶之不起、放痧不出或仅见血点 |

```plain
   肌肤（气分）──→ 血肉（血分）──→ 肠胃经络脏腑
       │                │                  │
      刮               放              药 + 刮放
       │                │                  │
   截断病势          给瘀毒出路        非药不能回生
       └──────── 逐级升级，不是并列备选 ────────┘

```

> **操作含金量极高的三句话**：
>
> + "肌肤痧用油盐刮之，则痧毒不内攻"——刮痧的首要目的不是"出痧好看"，而是**截断病势、阻止痧毒向里传变**。这是"治未传"思想，不是"把皮肤刮红"
> + "血肉痧有青紫筋，刺之则痧毒有所泄"——放痧的首要目的也不是"放血"，而是**给瘀毒一个出口**
> + "刮之放之不效，即当用药治之"——三法不是并列备选，而是**逐级升级**。停留在低层级反复操作，就是延误

**"痧"的现代识别价值**：郭氏"脉症不合即疑痧"是一条极有迁移价值的思路——**当症状与体征对不上、当常规治疗无效时，先怀疑自己的判断框架，而不是加大剂量继续原来的方案**。这与板块18的三角验证是同一种思维。

### 15_2 神志急症：十三鬼穴与治神

#### 15_2_1 古人在治什么

《备急千金要方》中的十三鬼穴歌开篇：「百邪颠狂所为病，针有十三穴须认。」

"颠狂"就是今天说的神志失常——狂躁、哭笑无常、登高而歌、弃衣而走、突然昏厥、幻听妄语。古人对这种"查不出器质性病变、却把人折腾得不像人样"的病，归因为"鬼神作祟"。

> **"鬼"不是实指，而是古人认知边界的标签：当医学解释不了的时候，就说是鬼。**

| 古代表述 | 对应现代医学 |
| --- | --- |
| 癫（沉默痴呆、胡言乱语） | 抑郁发作、精神分裂症 |
| 狂（躁动打骂、登高弃衣） | 躁狂发作、双相障碍 |
| 痫（突然昏仆、抽搐吐沫） | 癫痫 |
| 颠狂所为的"百邪" | 癔症、惊恐障碍、重度失眠 |

**核心病机只有三个字：痰、火、惊。** 痰浊蒙心则神不守舍，痰火扰心则狂躁不安，惊则气乱神散则昏厥失语。

#### 15_2_2 十三穴的排列逻辑

从头到足，由上而下：鬼宫（人中）→ 鬼信（少商）→ 鬼垒（隐白）→ 鬼心（大陵）→ 鬼路（申脉）→ 鬼枕（风府）→ 鬼床（颊车）→ 鬼市（承浆）→ 鬼窟（劳宫）→ 鬼堂（上星）→ 鬼藏（会阴）→ 鬼臣（曲池）→ 鬼封（海泉）。

这遵循了**"先督后任、先上后下、先急救穴后远端穴"**的针灸逻辑：头面部的督脉、任脉穴在前（醒脑、调任督），四肢末端的穴在后（泄热、通关），最后以舌下收尾（开窍、利咽）。另有"男从左起女从右起"的说法，是阴阳对称的体现。

歌诀里还埋着一个深浅梯度：入三分的有鬼宫（人中）、鬼信（少商）、鬼市（承浆）；入二分的有鬼垒（隐白）、鬼心（大陵）、鬼枕（风府）、鬼窟（劳宫）、鬼堂（上星）、鬼藏（会阴）；入五分的有鬼心（大陵）、鬼床（颊车）；用火针的有鬼路（申脉）、鬼臣（曲池）；点刺出血的有鬼封（海泉）。

> **安全红线（务必读）**：本方法涉及**风府、会阴、舌下（海泉）**等要害部位，风险明确。**非专业者严禁自行操作**，也不得在非医疗场所尝试。神志异常者须优先送精神科或急诊，排除器质性病因后再考虑任何中医介入。

#### 15_2_3 对非专业者可迁移的部分：面对高唤醒者的四个动作

1. **降噪**：减少环境与言语刺激，不要与之争辩其妄想内容
2. **定呼吸**：引导缓慢呼吸，降低交感兴奋
3. **保安全**：移除危险物品，注意"昼夜妄行"提示的节律紊乱与"朝夕嗔怒"提示的攻击风险
4. **早送医**：神志异常不属家庭处理范围

（治神的完整原理见板块11。）

### 15_3 救急良方：文献层面的认识

《医方集解》末附"救急良方"，《千金翼方》也有大量急症内容。这些文献的价值在于**古人在没有现代急救条件下的应对策略**，今天应作医学史与思路阅读，不作为自用方案。

| 场景 | 古籍思路 | 现代对应动作 |
| --- | --- | --- |
| 卒然昏倒、不省人事 | 掐人中、针刺急救穴、温灸脐部 | **呼叫急救、平卧、保持呼吸道通畅、不喂水喂药** |
| 大出血 | 止血、益气固脱（气随血脱，急当益气） | **压迫止血、紧急送医** |
| 误食毒物 | 催吐、解毒方 | **保留样本、立即就医或联系中毒控制中心** |
| 中暑高热 | 移至阴凉、清凉之剂 | 物理降温、补液、重症送医 |
| 溺水 | 倒水、复苏法 | 现代心肺复苏 |

> **必须明确的立场**：现代急救（心肺复苏、止血、中毒处理、气道管理）在这些场景下优于任何古籍方案。学习古籍急症内容的价值在于**理解古人的分层思路与"截断病势"的思维**，不是替代现代急救。

### 15_4 刮痧的准确定位

刮痧是普通人最容易接触到的外治法，也是最容易被误用的一种。给它一个准确的定位：

| 项目 | 说明 |
| --- | --- |
| **作用层次** | 肌肤（气分），最浅一层 |
| **核心目的** | 截断病势、疏通表层气机，不是"排毒" |
| **适用** | 感受外邪初起的胸闷、恶心、身困（须先排除急重症） |
| **不适用** | 高热神昏、抽搐、大出血、昏迷、孕妇腰腹、皮肤破损、凝血功能障碍、服用抗凝药物者 |
| **操作要点** | 单向、适度，以出痧为度而不追求重紫；避风保暖；刮后补水 |
| **停止信号** | 症状不缓解或加重 → 立即停止并就医，不要反复加重操作 |

> **最重要的一条**：**刮痧是"最浅一层"的手段**。它处理不了血分层与脏腑层的问题。反复刮而不效，说明病在更深的地方——此时正确的动作是就医，而不是加大力度继续刮。

### 15_5 红线清单：什么时候必须送医

把散在各处的红线集中在这里，作为本板块的行动总则：

| 表现 | 动作 |
| --- | --- |
| 神志不清、昏迷、叫不应 | 立即呼叫急救 |
| 抽搐、牙关紧闭、口吐白沫 | 立即就医，不撬牙关、不塞东西入口 |
| 大出血（呕血、咯血、便血量大、外伤出血不止） | 立即就医 |
| 胸痛持续不缓解、放射至左臂或下颌 | **按心血管急症处理，立即呼叫急救** |
| 高热伴神志改变、颈项强直 | 立即就医 |
| 呼吸困难、喘促不能平卧 | 立即就医 |
| 婴幼儿囟门膨隆或明显凹陷、精神极差 | 立即就医 |
| 孕妇任何腹痛、阴道出血 | 立即就医 |
| 突然的言语不清、肢体无力、口角歪斜 | **按卒中处理，立即呼叫急救（时间窗极关键）** |

> **一句话总则**：**急症的第一动作是识别与转送，不是治疗。** 中医在急症领域的价值主要是"识别分层"与"辅助处理"，而不是替代急救体系。

### 15_6 案例小故事：一次"常规思路失效"的识别

**背景**：盛夏，一支六七人的户外施工队在午后连续作业。收工时，两位工人先后出现胸闷、恶心、腹痛，症状几乎一模一样，工友们都说是"中暑"。

**经过——第一位**：被扶到阴凉处，喝了些水，又按"胃肠型感冒"的思路服了藿香正气类制剂，休息一晚。第二天仍旧胸闷恶心，且渐觉头晕加重、浑身发沉。他以为"没休息够"，又躺了一天。

**经过——第二位**：起病相似，但程度略重，伴轻微神志朦胧——别人问他话，他要愣一下才答，答得也不太清楚。

**转机**：

- 第一位：这是"以本症治之不效，皆为痧之症"的典型场景。按痧症分层重新判断——胸闷恶心、腹痛初起而**神志清楚**，属肌肤气分层次，宜用刮法疏通表层气机、截断病势。刮后胸膈即觉宽松，头晕随之减轻。
- 第二位：刮之胸膈略松，但随即又闷，且神志朦胧渐明显。按三法分层，这已不是肌肤层能解决的——病已向内传变。**正确动作是停止刮痧、立即送医**，而不是加大力度继续刮。后来证实为重症中暑，所幸送医及时。

**复盘**：两个病例的起病几乎相同，差别只在于病邪停留的层次。第一个停在浅层，浅层手段有效；第二个已经向内传变，继续用浅层手段就是延误。

三法分级的真正价值，在于给了你一个**"什么时候该停手"的判断标准**——它不教你治得更多，而是教你何时不再自己治。用一句可以记住的话收尾：**会用浅层手段不算本事，知道什么时候不能用才算。**

### 15_7 本板块的笔记动作与验证

**笔记动作**：写一页"红线卡"，把 15_5 的表抄下来贴在显眼处。这张卡片的价值不在于记住疾病知识，而在于**在慌乱时能有一个不需要思考的动作清单**。

**验证方法（三选一）**：

1. **三法分级**：给出"胸闷恶心初起、神清"与"刮后稍松随即复闷且神志朦胧"两种情况，判断分别属于哪一层、该怎么处理（答案：前者肌肤层用刮；后者已深入，停止刮痧立即送医）。
2. **干扰项诊断**：用自己的话说出"脉症不合即疑痧"的思路，并举一个它可能有用的场景（如常规治疗无效的持续胸闷）。
3. **红线演练**：说出三个"看到就必须呼叫急救"的表现（对照 15_5 表）。
