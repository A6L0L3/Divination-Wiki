# 中医系统知识库 · 总纲

> **副标题**：以三十三部经典为底本的结构化重构 · 二十二个板块 · 一套可自查、可训练、可上手的操作系统
>
> **一句话定位**：这不是典籍摘要汇编，而是把三十三部经典打碎后，按"一个临床决策是怎么做出来的"这条主线重装出来的操作系统。

## README · 导览

### README_1 这套库解决什么问题

学中医最常见的失败，不是记不住，而是**记住了却用不上**。背得下三百首方歌，面对一个真实的病人依然卡在"他症状差不多，到底用哪一张方"。

原因是：经典是按"作者想说的"排的，不是按"学习者要懂的"排的。《伤寒论》条文前后跳跃，《难经》八十一难主题打散，《景岳全书》六十四卷包罗万象——这些文本本质是**临床笔记的汇编**，不是按学科编好的教材。于是学习者手里握着一堆碎片，却没有一张能把碎片插进去的底板。

本知识库要提供的就是这张底板。它的组织原则只有一条：

> **从"采集信息"到"做出判断"到"落地处理"，把每一步都变成一个可重复执行的动作。**

### README_3 五种读法：按目的选路径

| 你的目的 | 建议路径 |
| --- | --- |
| **完全零基础，想知道中医在讲什么** | 板块0 → 板块1 → 板块16 → 板块21 |
| **想建立能看病的思维链** | 板块0 → 板块1 → 板块4 → 板块5 → 板块6 → 板块19 |
| **已有基础，想补方药与专科** | 板块7 → 板块8 → 板块9 → 板块10 → 板块12 → 板块21 |
| **想学外治与自我调理** | 板块5（舌诊体质）→ 板块11 → 板块16 → 板块21 |
| **想训练思维方式本身** | 板块6 → 板块17 → 板块18 → 板块20 |

**唯一不建议的读法**：从第一页硬啃到最后一页。这套东西是**按问题反查**设计的——带着一个真实问题跳进来，用书里的框架套一遍，体会完全不同。

### README_4 使用说明：内部节奏

二十二个板块遵循同一套节奏，读熟之后你就知道每一节该期待什么：

```plain
   骨架  ──→  这一块到底在解决什么问题（不读这层，后面全是散的）
    │
   原文  ──→  古人说了什么、为什么这么说（抠原理，不复述）
    │
   落地  ──→  今天怎么用（给动作、给表格、给判断点）
    │
   案例  ──→  背景 → 经过 → 转机 → 复盘（完整四段）
    │
   验证  ──→  怎么知道自己真的会了（三个可选动作，做完打勾）

```

**关于案例小故事**：每篇案例都按"背景 — 经过（含误治）— 转机（关键抓手）— 复盘（可迁移教训）"四段完整展开。其中医家本人的验案（孙思邈、钱乙、傅青主、叶天士、徐灵胎等）属史实记载；标注为"教学演示"的案例是构造的，只用于演示推演路径，不参与疗效判断。

### README_5 把知识变成自己的

读完全部板块却不输出任何东西，等于没读。板块20给出完整的笔记方法与验证工具，这里先给出最核心的一条：

> **验证前移。** 学脉就在自己身上摸满九十天，学药就在厨房里尝（限药食同源品），学方就把君臣佐使的剂量比抄一遍、合上书重画一遍。没有输出的学习，等于没学。

### README_6 安全前置（务必先读）

本知识库是**文献研读与思维训练材料，不构成医疗建议**。所有方剂、剂量、针刺操作均须由具备资质的执业人员完成。

涉及以下情况，**一律优先就医，不以本文件内容自行处理**：

- 急症与重症：高热神昏、抽搐、剧烈疼痛、大出血、喘促不宁
- 神志异常：谵语、昏迷、精神行为显著改变
- 妊娠期、哺乳期、婴幼儿、高龄体弱者
- 任何有毒药物（附子、乌头、朱砂、雄黄、马钱子、巴豆等）与十八反十九畏涉及的组合
- 慢性病（高血压、糖尿病、心脑血管病、肝肾疾病）的用药调整

**关于剂量**：文中出现的古方剂量一律标注原书古制（如"三两"），不作现代克数换算。原因是经方剂量换算存在多种考证口径，结论差距可达四五倍；自行按某一系数照方抓药，是中医自学最危险的行为之一。

**关于现代研究**：文中提及的现代研究仅用于说明"中医正在被如何研究与验证"，不代表相关疗法已被证实有效，亦不构成对任何诊疗方案的推荐。

### README_7 体例说明

- 全书一级标题只有书名一行
- 导览独立成篇、不占板块编号，其小节写作 README_1、README_2 依次递增
- 正文共二十二个板块，从板块0 排到板块21，板块标题写作"## 板块N · 主题"，板块内单元写作"### N_Y 名称"，Y 从1 递增，单元内小节写作"#### N_Y_Z"，Z 从1 递增
- 分步骤统一用"第1步、第2步"或「1」「2」，不使用带圈数字
- 所有插图均为 ASCII 字符画，以代码块形式呈现，语雀、Typora 等支持 Markdown 的编辑器均可直接渲染
- 文中引文完整呈现；确需节略处改为白话转述，不使用省略号代替原文
- 文中涉及的其他板块只给名称，不作跳转链接，避免离线阅读时的死链
- 历史成书年份为可考史实，予以保留；涉及未来安排的地方一律只给相对时间，不写具体年份
- 板块之间互不重复：同一知识点只在其主属板块完整展开，其他板块只作一句话指引
