## 板块9 · 坐功：十二段锦与十六段锦

坐功不是把立式功法"坐着做完"，而是把收心、通络、生津、归元串成一条完整回路。本板块以十二段锦为核心，以十六段锦和八段锦坐功为扩展：先解决坐姿与顺序，再落实每一段的次数、呼吸、体感与常见错误，最后给出工位版与验证方法。坐卧之间的静定、卧功与偏差处理，另见板块10。

### 9_1 厘清定位：坐式内敛与站式外放互补

**坐功的第一原则是"先收摄、后流通、再归元"。** 十二段锦又称"坐式八段锦""文八段锦"，全部或绝大多数动作取坐姿完成；立式八段锦则借站步、开合与升降形成较大外放动作。两者并非高低关系：立式偏通经、舒展与负重稳定，坐式偏收神、局部导引与低强度内养，可按日交替。若上午练立式八段锦，晚间或工作间隙练十二段锦，通常比长期只练一种更容易兼顾"通"与"养"。

**十二段锦的源流，不是一人一时的发明，而是"歌诀—图说—规范本"的积累。** 南宋曾慥《临江仙》附注已见"钟离先生八段锦"之名，可视为坐式雏形；明初朱权《活人心法》载八段锦导引法，含叩齿、摇天柱等内容；明代冷谦《修龄要指》、高濂《遵生八笺》进一步整理；清乾隆年间徐文弼《寿世传真》首次以"十二段锦"定名，并为各节增补详解；清光绪年间王祖源《内功图说》将其编入出版，流传更广；2010年国家体育总局健身气功管理中心编创新版。版本脉络如下：

| 时代 | 文献/事件 |
| --- | --- |
| 南宋 | 曾慥《临江仙》附注："钟离先生八段锦" |
| 明初 | 朱权《活人心法》：八段锦导引法（叩齿、摇天柱等） |
| 明代 | 冷谦《修龄要指》、高濂《遵生八笺》整理定型 |
| 清乾隆 | 徐文弼《寿世传真》首次定名"十二段锦"，分节详解 |
| 清光绪 | 王祖源《内功图说》图诀编入、广传 |
| 2010年 | 健身气功管理中心新版 |

古本与新版应分工使用。古本主要来自《寿世传真》《内功图说》，以五言歌诀统领，兼存存想、咽津等内养语言；新版将动作规范、口令与教学次序整理得更明确。本板块以古本歌诀为理解骨架，以新版动作名称为操作索引，不把"龙虎""火""河车"等比喻误读成必须出现的主观幻象。

| 版本 | 主要形态 | 优势 | 本板块用法 |
| --- | --- | --- | --- |
| 古本 | 五言歌诀、分节注解 | 保留完整次序与内养逻辑 | 精读歌诀、解释机理 |
| 新版 | 十二动作＋预备势＋收势 | 名称、角度、教学清晰 | 对照动作、记录次数 |

**"十二段"不能被误拆成十二个孤立动作。** 新版为教学方便，把部分内容重新分节；古本歌诀则把生津、咽津、河车搬运穿插在完整回路中。因此，本文件记录次数时以古本"总诀—段落"为准，实操时兼容新版动作名称，不机械争论"哪一段是第几式"。

### 9_2 总诀全录与结构拆解

**总诀本身就是流程地图。** 练前应把歌诀读熟，但不需要逐字训诂；关键是明白"先静、后动、再收"的方向。古本原文如下：

> 闭目冥心坐，握固静思神。叩齿三十六，两手抱昆仑。

左右鸣天鼓，二十四度闻。微摆撼天柱，赤龙搅水津。
鼓漱三十六，神水满口匀。一口分三咽，龙行虎自奔。
闭气搓手热，背摩后精门。尽此一口气，想火烧脐轮。
左右辘轳转，两脚放舒伸。叉手双虚托，低头攀足频。
以候神水至，再漱再吞津。如此三度毕，神水九次吞。
咽下汩汩响，百脉自调匀。河车搬运毕，想发火烧身。
旧名八段锦，子后午前行。勤行无间断，万病化为尘。

末尾"以上系通身合总行之，要依次序，不可缺，不可乱"，是操作硬约束。它意味着：第一段未把身、心、息收到基本稳定，就不要急着进入头颈导引；中段未做开合拉伸，不宜直接跳到河车；最后一段未完成收束，也不算一次完整练习。

**结构分段（流程地图）**：

| 段落 | 歌句范围 | 现代训练任务 | 自检重点 |
| --- | --- | --- | --- |
| 起·收摄安神 | 自"闭目冥心坐"至"两手抱昆仑" | 正坐、握固、闭目、掩耳、微息 | 脊竖直、舌抵腭、身不靠 |
| 承·和畅气血 | 自"鸣天鼓"至"低头攀足频" | 头颈、肩臂、腰背、下肢导引 | 上体稳定、幅度可控、次数准确 |
| 转·周天收束 | 自"以候神水至"至"想发火烧身" | 再漱吞津、河车搬运 | 9咽可核算、温热感不硬造 |
| 合·行功要诀 | 自"旧名八段锦"至"万病化为尘" | 收功、连续练习 | 不省略静养与起身 |

**结构的关键不是"神秘路线"，而是节律切换。** 起段降低外界输入；承段用轻刺激增加血循环与关节活动；转段借吞咽、呼吸和温和注意把兴奋往回收；合段以坚持、节律代替一次高强度。把这条回路练顺，后续接十六段锦、工位版或峨眉明字桩，都更容易稳定。

### 9_3 练习前准备

**准备时间通常比增加次数更能决定质量。** 每次总时长以20—30分钟为宜，初学可先完成15分钟完整回路，再逐步补足。优先早晨或上午，因清醒后容易形成稳定锚点；"子后午前"只是古法提示，现代人不必因此夜间强练。每天1次即可，连续约4周再回头比较情绪、睡眠与肩颈紧张，不宜以单次"感觉多好"判断。

| 项目 | 可执行标准 |
| --- | --- |
| 时间 | 每日1次；每次20—30分钟，初学15分钟起 |
| 时段 | 早晨或上午优先；"子后午前"不刻板 |
| 频次 | 连续4周观察趋势，不追求一天两练 |
| 环境 | 安静、避风、光线柔和；避开饭后1小时内 |
| 坐姿 | 散盘、单盘、双盘或端坐硬凳；臀下垫高2—3厘米 |
| 穿着 | 宽松，不束腰腹；摘眼镜、手表等束缚 |
| 舌位 | 舌尖轻抵上腭，除吞咽外贯穿全程 |
| 连续性 | 先保证每周稳定完成，再提高精度 |

坐姿决定后面能否放松。盘坐时坐骨向下放稳，骨盆不前倾、后倾过多；端坐硬凳时，脚掌踏实，膝约90度，不跷腿。臀下垫高2—3厘米的目的，是减少腰部为"坐直"而持续用力。脊梁竖直不是挺胸憋气，而是头顶有轻上领、下颌微收、腰肋自然展开；后背可靠不靠物，肩不耸、肘不夹。

**坐姿结构（简图）**：

```plain
头正、下颌微收
     │
肩沉、肘坠、手结定印或握固
     │
脊梁竖直，不后仰、不前弓
     │
腰不软、腹不紧、臀下垫高
     │
坐骨坐实；盘坐则双膝下沉

```

**五事自检口诀**："脊竖直、腰不软、身不靠、舌抵腭、臀垫高"。每次闭眼前扫一遍；有一项未满足就先调整。对初学者而言，准备30秒，远胜中途反复纠正姿势。

**"神水九次吞"必须按三次分度核算。** 第五段为第1度，作3咽；第十一段说"再漱再吞津，连前一度，此再二度"，后二度每度3咽，共6咽。算法固定为：

| 度 | 咽数 |
| --- | --- |
| 第1度 | 3咽 |
| 第2度 | 3咽 |
| 第3度 | 3咽 |
| **合计** | **9次吞** |

不能误把"三度"写成"3＋3＋3＝9"后，又把第九段"叉手双虚托"也算作一次吞津。第九段是拉伸动作，不产生咽津；真正统计的是第五段1度、第十一段2度。每次练习可在心中简单标记"度一／度二／度三"，避免匆忙中漏算。

**高频错误应在准备阶段就预设纠正。**

| --- | --- | --- |

| 鸣天鼓 | 低头、夹肘、食指无弹力 | 上体中正，耳孔掩实，食指滑弹 |

### 9_5 三段重点深解

十二段锦能否形成完整回路，关键不在把十二段都做完，而在起收、生津与归元三个转折是否清楚。下面三段分别落实"三调"如何起步、津液如何按流程分度，以及热能和河车怎样以轻守收束。

#### 冥心、握固与竖脊：先把"三调"落在身体上

**冥心不是压灭念头，而是停止把念头续写成故事。** 原典要求闭目、收心、握固、竖脊。实践中，发现走神即把注意力放回呼吸、坐垫压力或手部触觉；不必责备自己，也不利用"空白"竞赛。杂念被评判后会更多，被轻轻放回锚点则会逐渐减少。

握固的具体做法是：拇指屈掐无名指根，其余四指自然收于掌心，松紧如轻握棉团。它并非越紧越好，主要作用是给手部一个低强度触觉锚点。竖脊的意义在于：胸廓不受挤压，呼吸较易深长；腰颈不过度塌陷，头颈与腰背的张力相对均匀。由此可见，第一段不是仪式，而是后续"以意引气"的前提。

#### 赤龙搅水津：把"生津四件套"做成可重复流程

**舌、齿、耳、咽属于同一组低剂量基础件。** "赤龙"是舌，"神水"是津液。操作时舌尖先轻抵上腭，再沿上下、左右缓慢搅动；待满口后鼓漱36次，使两腮、舌下均有湿润感；随后一口分三咽，每次吞咽有声、连续，意想随下落至小腹。唾液增多、咽喉润泽即为有效，不必追求"满口溢出"。

龙虎之说在此是吞咽与气机下行的隐喻。现代可理解为：轻柔口腔刺激增加唾液，分次吞咽配合呼气，使注意与咽喉、膈肌动作同步，帮助从头部兴奋转向安静。若口干明显，可先做搅津，不必强行36次；有口腔溃疡或张口疼痛者，降低搅动强度。

生津四件套的完整操作与次数见板块3。本板块只规定它在十二段锦中的调用顺序：

```plain
叩齿36 → 掩耳抱颈、鼻息9 → 鸣天鼓48 → 撼天柱各24
   ↓
搅津＋鼓漱36 → 第1度分3咽
   ↓
第六、七段热能闭环
   ↓
第十一、十二段：再2度共6咽 → 河车收束

```

#### 热能闭环：第六、七段是从肢体到收摄的转折点

**搓手—摩腰—存想构成一组"外热—导热—归位"的训练。** 第六段以双手搓热，掌心含空地摩擦后腰肾俞区域；第七段借温和观想，把注意从分散动作收向脐下。这里的"火"宜理解为局部温热、放松与注意归位，不是必须发热。

| 环节 | 内容 |
| --- | --- |
| 搓手 | 外热 |
| 摩腰 | 导热至肾俞 |
| 存想引热归小腹 | 归位 |

初学者若没有热感，可先用中指或无名指轻点脐下，建立位置条件反射；有温热则顺其自然，没有也不补做、不加力。过度追求热感会造成皱眉、憋气和头部紧张，反而背离收摄目标。

#### 河车搬运：只走"似守非守"的任督意象

**第十二段的路线应画成闭环，而不是把某一点抓死。** 古本从尾闾起，经腰间、脊背、后颈、脑后到头顶；再经额上、太阳、耳根、两颊、喉下、心窝、肚脐回到丹田。

```plain
头顶 → 额上 → 太阳/耳根 → 两颊 → 喉下 → 心窝 → 肚脐 → 丹田
  ↑                                                              │
  │                                                              │
尾闾 → 腰间 → 脊背 → 后颈 → 脑后 ───────────────────────────────┘

```

练习时可采用"呼吸＋路线"的轻锚：吸气时不追热，呼气时让注意沿前侧缓慢落到小腹；一圈未完成就回到呼吸，不必从头数圈。所谓"想发火烧身"，只在身心已经稳定、自然出现温热时顺势觉察；初学若强行制造热、光、流窜感，应立即回到自然呼吸与外部环境。河车搬运5分钟即可，状态好可到10分钟，坐不住就收功，绝不把耐力当作功夫深浅。

### 9_6 十六段锦与八段锦坐功

**十六段锦的价值，在于把多套导引"标准化"为十六条。** 冷谦《修龄要指》自言"取诸家要约切当者十六条"汇编成篇。原典对行功时机的描述是："凡行导引，常以夜半及平旦将起之时，此时气清腹虚，行之益人。先闭目握固，冥心端坐，叩齿三十六通。"现代不必拘泥夜半，可将"平旦将起"转化为晨起床上或椅上练习。

十六段锦以坐式为主，适合体力较弱、久坐人群和短时练习。其普遍格式是"一个动作＋二十四次＋去某一处邪气"，但具体段次、动作存在版本差异，不宜把不同图谱强行统一。实操原则如下：

1. 先端正坐姿，完成握固、叩齿与调息；
2. 每段动作展开时吸气，收回时呼气；
3. 次数按体力可为24或减半为12，宁少而准；
4. 最后一段以搅津、鼓漱、咽津收束，不可省；
5. 若出现头晕、胸闷，立即停止并恢复自然呼吸。

**八段锦坐功与"导引却病要诀"高度重叠。** 《万寿仙书》所载八段锦坐功，可提取为：抱昆仑＋鸣天鼓、撼天柱、赤龙搅水津＋漱津三咽、背摩后精门、叉手双虚托＋低头攀足。这些动作也反复出现在十二段锦、十六段锦、冷谦导引要诀中，因此可称为"通用基础模块"。

| 标准件 | 主要部位 | 常用次数 | 可独立使用场景 |
| --- | --- | ---: | --- |
| 叩齿 | 齿、颌 | 36 | 晨起、久坐前 |
| 鸣天鼓 | 耳、枕部 | 左右各24 | 头胀、用脑后 |
| 撼天柱 | 颈、肩 | 左右各24 | 久坐颈肩紧张 |
| 搅海、鼓漱、咽津 | 口腔、咽喉 | 鼓漱36；分度咽 | 口干、练前练后 |
| 摩肾堂 | 后腰 | 24—36 | 久坐、畏寒不适 |

**"记一套，通全书"的要点是固定顺序，而不是每次都做全套。** 顺序固定为：叩齿→鸣天鼓→撼天柱→搅海→鼓漱→分咽→摩腰→收功。当天若已完整练十二段锦，不必重复追加相同次数；只有碎片时间，才从中取2—3项。

**工位8分钟版应优先保住顺序和收功。**

| 时间 | 内容 |
| --- | --- |
| 0:00—1:00 | 端坐竖脊，闭目握固，自然呼吸 |
| 1:00—3:00 | 叩齿36；掩实耳孔，鸣天鼓左右各24 |
| 3:00—4:00 | 微撼天柱，左右各12 |
| 4:00—6:00 | 搅津＋鼓漱36；分3咽，意送小腹 |
| 6:00—7:00 | 搓手24；摩后腰肾俞区24 |
| 7:00—8:00 | 搓掌浴面18；睁眼，活动手脚再起身 |

此流程不是医疗处方，只是低强度动作组合。工位版可每天做，但若与完整十二段锦同日练习，建议把闭气、强意念段落留在正式练习，工位版只保留轻刺激与收束。

### 9_7 安全提示

**安全边界必须先于"古法原汁原味"。** 低头攀足以腰背不出现疼痛、腿后不出现锐痛为限。腰椎疾病、椎间盘突出、急性腰痛者，可减小弯腰幅度，或改为坐位前伸、温和腘绳肌拉伸；出现下肢麻痛立即停止。膝痛者不勉强腿伸直，可在膝下垫软枕。

闭气类段落尤其需要个体化。高血压、冠心病、脑血管病史、青光眼、孕期或饭后饱胀者，不做长时间闭气；可将"闭气搓手热"改为自然吸气后缓慢搓手，仍保留摩擦与温煦的逻辑。任何情况下，一旦出现头晕、胸闷、心悸、视物模糊、恶心，立即停止，恢复自然呼吸；症状持续或加重应及时就医。

**"用意要轻"是贯穿全篇的安全阈值。** 热感、跳动、唾液增多都可观察，但不需要追逐；没有则不强补。若练后反而头痛、紧张、失眠加重，应先减时间、减闭气、增动功，再检查坐姿与次数。坐功可辅助生活节律，不替代医疗、药物或心理诊疗。

### 9_8 案例小故事：徐文弼定名与初学者的"完整一遍"

**案例小故事：徐文弼定名十二段锦（原典记载类）**

**背景：**《寿世传真》在清乾隆年间首次把这套坐式导引明确称为"十二段锦"，并为各节增补详解；此前相关内容多以八段锦、导引要诀等名称散见。

**困境：** 一位初学读者把新版每式单独练完即结束，常漏掉第十一、十二段的再漱吞津与河车收束。他的动作数量没错，却把"十二段"当成了十二个并列动作。

**转折：** 他按古本总诀把练习改写成四段回路，并在吞津、河车两处设置最少记录。关键不是背熟全部古文，而是确认"第1度3咽＋后二度6咽＝9咽"，以及河车是否做到似守非守。

**落地启示：** 今天练十二段锦，应先以完整回路为目标，再谈动作优美。练时身上应有"脊背稳定、吞咽清楚、腰背温热或放松、收功后不头晕"的感觉；若只剩八分钟，优先做通用基础模块，不可把省略版误称为完整十二段锦。自检方法：练完当场合上歌诀，复述四段结构与12段顺序，核算吞津三度是否共9咽；若顺序断裂或次数不清，下一次就从第一段重新开始，不跳段追赶。

### 9_9 练习场景示例：工位版与完整版的边界

**练习场景示例：工位版与完整版的边界（示例情景，非原典记载）**

**背景：** 一位久坐办公者每天只有两段碎片时间，想把工位8分钟版和晚间十二段锦合并，结果晚间重复鸣天鼓、咽津后感到头部紧绷。

**困境：** 问题不在动作错误，而在"碎片化练习"被误当成完整正式练习，又在同一天机械叠加相同次数。重复追热、反复意守头部，使原本的放松流程变成持续输入。

**转折：** 他把流程明确分层：工位版只做叩齿、鸣天鼓、撼天柱、搅海咽津、摩腰和浴面；晚间正式十二段锦保留完整次数与河车搬运。若白天已练工位版，晚间可减少重复项的次数，不以"次数越多越好"累加。

**落地启示：** 今天执行时，应先确认当天属于"碎片维护"还是"完整回路"。工位版的体感目标是颈肩稍松、口中润泽、起身平稳；完整十二段锦才是九咽与河车收束的正式场景。重复动作一旦带来紧张，减量比加量更安全。自检方法：练后用手触摸后颈与肩，若肌肉比练前更硬或头部有压迫感，说明重复过度，次日应去掉重叠项。

### 9_11 本板块的验证方法

**验证标准是"回路通畅、剂量清楚、练后能稳"。** 不把特殊感觉作为进阶门槛，而以动作完整性、坐姿稳定、呼吸舒适和长期趋势作判断。

| 项目 | 自检方式 | 达标线 |
| --- | --- | --- |
| 次序 | 合上歌诀，复述四段结构 | 能说出12段顺序与每段次数 |
| 吞津算法 | 当场核算三度 | 第1度3＋后二度6＝9咽 |
| 坐姿 | 靠墙正坐，检查后脑、肩胛、骶骨接触 | 头顶不刻意顶墙；身不靠椅背 |
| 头顶不起伏 | 缓慢完成头颈动作时自拍或他人观察 | 无大幅上下点头 |
| 热能闭环 | 核对搓手、摩腰、存想三段 | 三段都完成，无刻意追热 |
| 河车 | 问"是否强行看见热气" | 答案应为"否" |
| 收功 | 检查搓掌浴面、静养、慢起身 | 不省略静养3—5分钟 |
| 连续性 | 统计4周练习天数 | 每周约5天为有效节律 |
| 长期趋势 | 比较入睡耗时、夜间觉醒、肩颈自评 | 4周后至少一项改善或稳定 |

进阶不以"能坐更久"为唯一指标。更稳妥的进阶是：先做到顺序完整，再做到呼吸不促、腰背不僵，最后才增加河车时间。若练满4周仍无客观改善但练习规律，应先检查坐姿、剂量、闭气和安全边界，而不是盲目加量。

### 9_12 本板块收束

板块9的核心判断是：十二段锦的价值不在某个单独动作，而在"收摄—流通—归元"的完整回路。十二段逐段齐全——从冥心握固、叩齿鸣鼓、撼天柱、生津吞津、背摩精门、温煦脐轮、摇转辘轳、叉手双虚托、低头攀足，到再漱吞津、河车搬运——其中"神水九次吞"的算法（第1度3咽＋后2度各3咽＝9咽）是不可省略的剂量硬约束。十六段锦与工位8分钟版则提供了低门槛的扩展与碎片场景。

今天练习时，应始终以"完整回路"为目标：第一段把身、心、息收到基本稳定，中段让头颈、肩臂、腰背、下肢依次得到导引，转段借吞咽与温和注意完成归元，合段以坚持与节律代替一次高强度。若时间有限，宁可只做通用基础模块（叩齿→鸣天鼓→撼天柱→搅海→鼓漱→分咽→摩腰→收功），也不能省略收束。工位版与完整版应明确分层，重复动作一旦带来紧张，减量比加量更安全。

安全边界的核心是"用意要轻"：热感、跳动、唾液增多都可观察但不追逐，没有则不强补。闭气段落对高血压、心血管疾病等人群必须改为自然呼吸。若练后反而头痛、紧张、失眠加重，应减时间、减闭气、增动功，再检查坐姿与次数。坐功可辅助生活节律，但不替代医疗、药物或心理诊疗。

生津四件套的完整操作见板块3，静坐卧功的次第与偏差处理见板块10，峨眉十二桩体系中幽、明二桩与坐功的衔接见板块8。通用问题见板块20。
