## 板块13 · 劲法与发劲：从局部用力到整体传导

步法解决了"脚下的事"，接下来解决"力怎么传出去"。

"劲"是整个传统拳法里最难讲清、也最核心的概念。它难讲，是因为古人用"气""意""神"来描述；但它并不玄——**去掉术语，"劲"就是"力量在身体里传递的效率"。**

这一板块把四部拳典的劲法理论，翻译成可检验、可训练的具体内容。其中苌氏二十四字全表是权威详版；板块16 保留苌氏独有论述，并指向本节。

### 13_1 太极十三势：八法五步的实操整合

**十三势不是十三种姿势，是十三种方法，是太极拳的"字母表"。**

#### 八法（八种劲法）

| 名称 | 性质 | 核心动作 | 通俗比喻 | 身体要领 |
| --- | --- | --- | --- | --- |
| **掤** | 四正·守 | 向外向上撑展 | 逆水行舟 | 掤在两臂——圆撑之力，全身如弓张 |
| **捋** | 四正·化 | 顺势牵引引带 | 顺水推舟 | 捋在掌中——以掌知觉，探听虚实 |
| **挤** | 四正·进 | 以小臂贴靠前推 | 人群拥挤 | 挤在手背——腰胯催动，整体前拥 |
| **按** | 四正·压 | 双掌前下推按 | 按压浮球 | 按在腰攻——**以腰为主力，掌为出口** |
| **采** | 四隅·拿 | 抓腕肘后牵下带 | 摘果分叉 | 采在十指——十指嵌牢，旋转交错 |
| **挒** | 四隅·分 | 横向错劲分拨 | 撕裂帛布 | 挒在两肱——手臂与腿交错发力 |
| **肘** | 四隅·发 | 屈臂以肘尖顶撞 | 肘击近战 | 肘在屈使——屈回小臂，腰胯催发 |
| **靠** | 四隅·撞 | 肩背贴击 | 肩膀冲撞 | 靠在肩胸——肩头靠胸，膀靠腰肋 |

**四正与四隅的关系**：四正（掤捋挤按）是**基础框架**，对应四个正方向，是"守"的根本；四隅（采挒肘靠）是**变化补充**，对应四个斜角，是"用"的发挥。**先练四正至纯熟，再学四隅——如同先学会走路再学跑步。**

**五步**：进、退、顾、盼、定，详见板块12。五步是"位置方法"，八法是"用力方法"，两者合为十三势。

#### 十三势整合训练推荐顺序

**十三势实操整合训练的四个阶段（推荐顺序）**

| 阶段 | 时间 | 内容 | 具体做法 |
| --- | --- | --- | --- |
| 阶段1 | 前 3 个月 | 单劲练习 | 每次练拳前单独练"掤"劲 5 分钟，双臂如抱球缓缓外撑，体会整体张力；再依次练捋、挤、按 |
| 阶段2 | 3—12 个月 | 四正推手 | 与搭档练习掤捋挤按的循环推手，固定顺序、慢速进行，体会劲力转换 |
| 阶段3 | 1 年后 | 四隅补充 | 加入采挒肘靠；先在拳架中找（斜飞势含挒劲、进步栽捶含肘劲），再在推手中用 |
| 阶段4 | 长期 | 五步融入拳架 | 在日常套路中有意识检查每个动作属于进、退、顾、盼、定中的哪一种，培养方位意识 |

#### 练习场景示例：先熟四正，再求变化

**背景：**一位练习者前 3 个月只练"掤"——双臂如抱球，缓缓向外撑展 5 分钟，体会全身整体张力的形成。到第 4 个月进入四正推手时，他发现"按"不再是手臂下压，而是腰胯下沉催动双掌，搭档明显感到"掌不重但推不动"。

**困境：**最初几周，他的手掌虽然触到对方，肩却先耸、肘也外翻，结果对方只需顺势偏一点，自己便失去支点。身体给出的信号是前臂酸、后腿不参与，说明发力链只在末端工作。

**转折：**他退回到"掤—捋—挤—按"的慢速循环，每次只练一个劲 5 分钟；推手中先把腰胯下沉、双掌留根，再让对方轻推自己前臂，以检验是否"掌不重而推不动"。

**落地启示：**今天单练任一劲，应先问脚底是否蹬实、腰胯是否带动、手掌是否只是出口；练后前臂可热，但肩颈不应紧锁。可按"柔—柔—刚—停"逐步推进，若快做时只有手臂酸，就退回慢速传导筛查。

#### 案例小故事（原典记载类）：先求"三尖到"，再求发力

**背景：**苌乃周《苌氏武技书》把"三尖到"列为过气与发劲的共同检验标准：眼睛、拳头、脚尖不先不后，一齐俱到。许多初学看到这句话后，会先追求掌快、拳重，以为速度与声音代表劲法已经练成。

**困境：**一次慢速自查中，练习者发现脚已落地、肩已前送，但拳面与视线仍落后；快做时更明显——手像甩出去，脚却没完成蹬转。此时若只反复挥拳，断点不会消失，反而会把肩、腕练得更紧。

**转折：**他把动作拆回"根动—传导—落点"：先让脚底蹬实、胯转正，再让肩胛下沉、肘不失位，最后拳面与视线同时到位。速度只按"柔—柔—刚—停"的口令推进，每次只查一个断点。等到慢速也能感到脚底、腰、拳面同步绷紧，才把时序压缩到一拍。

**落地启示：**今天练单劲或对墙推按时，应先问"眼睛、拳头、脚尖是否同时到位"，再问"力大不大"。正确体感是脚底蹬实、腰胯像轴、掌根同时受载；若只有手臂酸、后腿没参与，就是典型断劲。宁可长期慢练，也不要跳过一阶直接求快。

### 13_2 走与粘：单人练习法

> 人刚我柔谓之走，我顺人背谓之粘。动急则急应，动缓则缓随。

**"走"与"粘"不是对立的，而是同一动作的两个面：走得越好，粘得越牢。粘即是走，走即是粘。**

#### 单人练习法（无需搭档）

| 步骤 | 名称 | 操作 |
| --- | --- | --- |
| 1. | 单练"走"（不顶） | 面墙站立 → 掌心轻贴墙面 → 缓慢推墙（想象对方来力）→ 手臂将伸直时，不顺抗，而是"顺着推力方向微微回收转身" → 让墙面的"力"落空。反复练"不顶" |
| 2. | 单练"粘"（不丢） | 同上姿势 → 但不收回 → 始终贴着墙面滑动，如手掌被胶水粘在墙上 → 墙面移动到哪里，手掌跟到哪里。体会"不丢" |
| 3. | 走粘合一（中间无停顿） | 先做"走"（对方推我，我化开）→ 紧接着做"粘"（化开的同时贴上对方）→ 关键：两者之间没有任何停顿 → 这就是"粘即是走，走即是粘"的体感 |

**自检口诀**："走要化得空、粘要贴得牢；化了就贴、贴了就化，中间不落脚。"

### 13_3 八卦四德八能：把"劲"翻译成动词

#### 四德：顺、逆、和、化

| 德 | 原文释义 | 现代训练语言 |
| --- | --- | --- |
| **顺** | 手足顺其自然往前伸 | 动作方向与结构对位，不加对抗 |
| **逆** | 气力往回缩 | 蓄势、回收、含劲 |
| **和** | 气力中正无乖 | 发力过程中身体不失平衡 |
| **化** | 化后天之气力归于丹田 | 把对抗中获得的动能转化为自身蓄能 |

#### 八能：搬、拦、截、扣、推、托、带、领

| 能 | 操作对象 | 动作含义 |
| --- | --- | --- |
| **搬** | 敌之手足肩胯 | 横向移开其支撑结构 |
| **拦** | 敌之手足（如研肘） | 纵向阻挡并破坏其发力链 |
| **扣** | 敌两手并胸、小腹 | 下压合住，锁死其重心 |
| **截** | 敌之手足、臂、腿 | **在其动作起点处截断** |
| **推** | 敌两手并身 | 单手或双撞掌，破坏其后倾平衡 |
| **托** | 敌两手 | 平托或上托，逆转其下压意图 |
| **领** | 敌身或两手 | 向左右、上下引领，使其失中 |

> **实操要点**：**八能不是八个招式，是八种"力的操作方式"。** 练习时不要追求记住哪一手对哪一手，而要训练一个判断习惯——**先识别对方力的方向，再选择顺或逆**。这是"顺逆和化"从理论进入手脚的唯一通道。

#### 三角手：八卦掌手法的几何特征

> 掌使一面不为功，至少仍须两面通。**一横一直三角手**，使人如在我怀中。

"三角手"是两臂与躯干构成三角形支撑，**任何一面受力都能向另外两面传导**。练掌势时若发现自己手臂总在一条直线上推拉，就是"一面掌"，**劲路必然断**。

```plain
      后手
       /\
      /  \
     /    \      ← 任一面的力都能传导到另两面
    /______\
  前手      躯干
  (三角支撑，非直线推拉)

```

#### 身法十六诀与"手快脚慢"的检验

> 手法步法紧相随，手到步落力必微，手脚俱到腰乏力，去时迟缓抽难回。

这一条直接对应**"手快脚慢"**——手掌到了，脚还在后面，此时劲力只能停在手臂上，无法从地面传导上来。**检验标准：练掌势时若有轻飘感，九成是步没跟上。**

> 未曾动梢先动根，手快不如半步跟。进退出入六半步，制手避招而安神。

"动根"指从脚底、从腰启动；"半步"是八卦掌的核心距离单位。

### 13_4 苌氏二十四字全表（权威详版）

#### 原典两条自我说明

1. **"阴阳字之祖，应为气之先"**——二十四字以阴阳为总纲，其余二十二字都是阴阳的展开；
2. **"次序休紊乱，大势须分辨"**——二十四字有固定次序，不可随意颠倒；但"大势"要看清楚，也就是要在整体中理解单字。

> 苌乃周还在序中说：冬日清闲，"就二十四而扩充之，每一而分为八，共合一百九十二，纵横奇变，于此毕具"——**二十四字是母题，可衍生出 192 种变化**。

#### 三种用法

| 用法 | 操作 | 判定标准 |
| --- | --- | --- |
| **用法1 · 劲法词典** | 练任何动作时问："这一势属于哪个字？"是"开"还是"入"？是"牵"还是"推"？ | 能归类，说明开始理解劲路 |
| **用法2 · 单势库** | 二十四个单势是散手，可拆出来单练 | 单势练熟后必须回到组合与对练 |
| **用法3 · 阴阳展开表** | 按阴阳分组：1-6 偏升降承停、7-12 偏开合发放、13-18 偏牵引粘随、19-24 偏闪惊进退 | 它就是"阴阳 = 可反转性"公理的一份完整清单 |

### 13_5 过气论：力量传递的"管道疏通手册"

> 落点坚硬，猛勇莫敌，赖全身之气尽聚一处也。然有用之而气不去、气去而牵扯不利，未知过气之法也。盖人身之气，发于命门（气之源），著于四末（气之注），流行之道路总要**无壅滞、无牵扯**。

**结构类比**：把身体想成一根管子。落点是管口，命门是气源。**管子的任何一处弯折、堵塞，气就到不了口。**"过气"就是保证管子全程通畅。

```plain
        命门（气之源）
             │
             ▼
  ┌──────────────────────┐
  │  管道：胯→腰→肩→肘→腕  │
  │  任一弯折 = 气止于此    │
  └──────────────────────┘
             │
             ▼
        四末（气之注 / 落点）

```

#### 过气疏通规则表

| 情形 | 阻碍在哪 | 解法 |
| --- | --- | --- |
| 直撞手，气入前 | 不勒后手、撑后肘 | 勒后手、撑后肘 |
| 上冲手 | 下手不插、肩不下脱 | 下手插、肩下脱 |
| 分摆 | 胸不开 | 开胸 |
| 合抱 | 胸不开 | 开胸 |
| 直起 | — | 须勾其脚 |
| 直落 | — | 须缩其顶 |

#### 实操｜过气筛查（对镜 5 分钟）

| 步骤 | 操作 | 常见断点 |
| --- | --- | --- |
| 1. | 做一次冲拳发力，慢速回放 | — |
| 2. | 顺着自己的动作问："从脚底到拳面，有没有哪一寸是松掉的？" | — |
| 3. | 常见断点三处 | 胯→腰：只用手臂发力，胯没转 → 气止于肩 |
|  |  | 肩→肘：耸肩、肘外翻 → 气止于肘 |
|  |  | 肘→腕：腕塌陷 → 气止于腕 |
| 4. | 找到断点后，只练这一段的通路，不要从头完整打 | 孤立打通再组合，这是最高效的纠错法 |

> **一句贯穿全书的提醒**：**落点是"一点"，但这一点的力量来自"全体"。一尖不到，全体不到。**

**刚柔节拍器口令**："柔—柔—刚—停"，熟练后压缩到一拍，但**内部时序不变**。

### 13_6 整劲检验：对墙推按

#### 发劲时序全链路（本板块最该记住的一张图）

```plain
脚底蹬地（根动）
    ↓
转胯拧腰（枢纽传导）
    ↓
松肩（蓄）→ 长腰（传导）→ 跟步（完成）
    ↓
肩胛下沉 → 肘不外翻 → 腕不塌陷（管道通畅）
    ↓
落点：一瞬间全身一紧（刚），定住1秒

```

#### 四家对同一条链的表述

| 典籍 | 表述 |
| --- | --- |
| **苌氏** | "三尖到：眼睛、拳头、脚尖，不先不后，一齐俱到"；气发于命门、著于四末 |
| **八卦掌** | "未曾动梢先动根，手快不如半步跟"；"松膀长腰跟步钻" |
| **太极拳** | "其根在脚，发于腿，主宰于腰，形于手指"；"按在腰攻——以腰为主力，掌为出口" |
| **拳经** | "力由足起，宰于腰，形于手"；"撑前箭后"（后脚蹬地启动） |

#### 对墙推按检验（核心验证）

| 环节 | 操作／标准 |
| --- | --- |
| **准备** | 距墙一臂远，双手掌根贴墙 |
| **动作** | 缓缓推墙（3秒走完），全程自查 |
| **检验** | 能否感到"力从脚底 → 传到掌根"，且中途无断点 |
| **达标** | 手掌、前臂、肩、背、臀、后腿在同一时刻绷紧 |
| **失败信号1.** | 只有手臂酸 → 胯未转 |
| **失败信号2.** | 腰部先紧后松 → 时序错 |
| **失败信号3.** | 后腿未蹬 → 根未动 |
| **失败信号4.** | 掌根发虚 → 腕塌陷 |

#### 发劲三阶训练

| 阶段 | 练法 | 达标标准 |
| --- | --- | --- |
| **一阶·打通管道** | 慢速做发劲动作（3 秒走完），全程自查十二节有无断点 | 过气筛查无断点 |
| **二阶·加入时序** | 按"柔—柔—刚—停"节拍器做，体会松紧切换 | 落点瞬间感到脚底与掌根同时绷紧 |
| **三阶·压缩到一拍** | 把 4 拍压成 1 拍，内部时序不变 | 动作变快，但管道不塌、落点仍实 |

> **最常见的失败模式**：直接从一阶跳到三阶——动作快了，但力还停在手臂上。**这是"练了十年不出劲"的根本原因。** 判断方法：快做时若感觉不到脚底参与，退回二阶。

### 13_8 本板块的验证方法

| 项目 | 自检方式 | 达标线 |
| --- | --- | --- |
| **对墙推按传导** | 距墙一臂推按，闭眼体会力线 | 清晰感到"脚底→掌根"，中途无断点 |
| **同时绷紧** | 对墙推按时逐处自查 | 掌、前臂、肩、背、臀、后腿同一时刻绷紧 |
| **过气筛查** | 慢速冲拳＋录像回放 | 胯→腰→肩→肘→腕无断点 |
| **三尖到** | 发劲定式对镜 | 眼、拳、脚尖不先不后一齐俱到 |
| **节拍器时序** | 按"柔-柔-刚-停"发劲 | 落点瞬间脚底与掌根同时绷紧 |
| **压缩到一拍** | 4 拍压成 1 拍重测传导 | 管道不塌、落点仍实 |
| **八法区分** | 随机抽一字，2 秒内说出性质／动作／要领 | 八法全部可即时对应 |
| **二十四字归类** | 任意拳势归入某字并说明理由 | 能归类即说明理解劲路 |
| **走粘合一** | 面墙走粘连续 10 轮 | 中间无停顿 |

**进阶验证（数月尺度）**：连续练习单劲 3 个月后，进入四正推手，若能"按在腰攻"——搭档感到掌不重但推不动，且全程无耸肩、无憋气，说明已从"局部用力"转入"整体传导"。**若 3 个月后对墙推按仍只有手臂酸，退回一阶慢速筛查，重点查胯→腰断点——这是最常见的"不出劲"原因。**

**自检口诀（贯穿全部劲法）**："根在脚、宰于腰、形于手；管道通、时序对、落点实。"

### 13_9 案例小故事（二）：从"用力"回到"过气"

**背景：**一位练习者能熟练背诵二十四字，也能把八法逐字归类。他在对墙推按时却始终只有前臂和手掌发酸，搭档轻推其肩时，他整条身体会随推力后移，无法形成稳定支点。

**困境：**问题在于他把"劲"理解为局部肌肉用力，每次发劲都先耸肩、扣肘，试图用手臂"顶出去"。过气筛查的断点清单显示：胯→腰段完全松掉，力量从未从脚底传导上来。他越快做，手臂越紧，落点反而越虚。

**转折：**他按"柔—柔—刚—停"回到一阶：慢速 3 秒走完一次推按，每半秒自问"现在脚底有没有蹬、腰有没有转、肩有没有松"。前两周只允许自己练到"腰胯催动"这一步，不追求掌根力度。

**落地启示：**今天对墙推按时，先把速度放到最慢，确认手掌、前臂、肩、背、臀、后腿能在同一时刻绷紧。正确体感是脚底蹬地的反作用力沿着一条连续管道传到掌根，中途没有任何一处"松掉"。若只有手臂酸、后腿不参与，说明仍在一阶，不应压缩到一拍。自检方法：每次推按后逐一口述传导链六个部位，任一处缺席即重做。

### 13_10 本板块收束

板块13 的全部内容最终收敛为一条传导链——脚底蹬地、胯腰转换、肩肘不失位、落点同时俱到。
太极八法提供劲法分类，八卦四德八能把劲转为动词，苌氏二十四字则是判断每一势性质的共同词典；
"三尖到"与对墙推按只检验一件事：力量是否真正由全身传到一点。凡只靠手臂完成的发力，都不是整劲；
只要传导链还有断点，就应退回慢速，不应急于求快或求重。三尖照与十二节的通用校准见板块1，苌氏独有的"阴阳=可反转性"与"肝起肺落"呼吸模型见板块16，去双重与虚实转换的步法语境见板块12。
板块13 的传导链直接支撑板块14 太极八法的推手运用、板块15 八卦掌的走转发力，以及板块16 苌氏过气论的结构验证。
