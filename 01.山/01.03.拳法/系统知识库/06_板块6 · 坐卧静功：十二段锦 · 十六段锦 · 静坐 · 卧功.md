## 板块6 · 坐卧静功：十二段锦 · 十六段锦 · 静坐 · 卧功

本板块合并坐功（十二段锦、十六段锦）与静坐、卧功及偏差处理。坐功是“动后之养”，把导引的“通”收束为坐式的“养”；静坐与卧功进一步把练习延伸到睡前与恢复；偏差处理给出停止信号与纠偏流程。站（板块3—5）与坐（本板块）是互补的两半，不要只练一半。

坐功不是把立式功法"坐着做完"，而是把收心、通络、生津、归元串成一条完整回路。本板块以十二段锦为核心，以十六段锦和八段锦坐功为扩展：先解决坐姿与顺序，再落实每一段的次数、呼吸、体感与常见错误，最后给出工位版与验证方法。坐卧之间的静定、卧功与偏差处理，另见板块6。

### 6_2 厘清定位：坐式内敛与站式外放互补

**坐功的第一原则是"先收摄、后流通、再归元"。** 十二段锦又称"坐式八段锦""文八段锦"，全部或绝大多数动作取坐姿完成；立式八段锦则借站步、开合与升降形成较大外放动作。两者并非高低关系：立式偏通经、舒展与负重稳定，坐式偏收神、局部导引与低强度内养，可按日交替。若上午练立式八段锦，晚间或工作间隙练十二段锦，通常比长期只练一种更容易兼顾"通"与"养"。

**十二段锦的源流，不是一人一时的发明，而是"歌诀—图说—规范本"的积累。** 南宋曾慥《临江仙》附注已见"钟离先生八段锦"之名，可视为坐式雏形；明初朱权《活人心法》载八段锦导引法，含叩齿、摇天柱等内容；明代冷谦《修龄要指》、高濂《遵生八笺》进一步整理；清乾隆年间徐文弼《寿世传真》首次以"十二段锦"定名，并为各节增补详解；清光绪年间王祖源《内功图说》将其编入出版，流传更广；2010年国家体育总局健身气功管理中心编创新版。版本脉络如下：

| 时代 | 文献/事件 |
| --- | --- |
| 南宋 | 曾慥《临江仙》附注："钟离先生八段锦" |
| 明初 | 朱权《活人心法》：八段锦导引法（叩齿、摇天柱等） |
| 明代 | 冷谦《修龄要指》、高濂《遵生八笺》整理定型 |
| 清乾隆 | 徐文弼《寿世传真》首次定名"十二段锦"，分节详解 |

| --- | --- | --- | --- |

**"十二段"不能被误拆成十二个孤立动作。** 新版为教学方便，把部分内容重新分节；古本歌诀则把生津、咽津、河车搬运穿插在完整回路中。因此，本文件记录次数时以古本"总诀—段落"为准，实操时兼容新版动作名称，不机械争论"哪一段是第几式"。

### 6_3 总诀全录与结构拆解

**总诀本身就是流程地图。** 练前应把歌诀读熟，但不需要逐字训诂；关键是明白"先静、后动、再收"的方向。古本原文如下：

> 闭目冥心坐，握固静思神。叩齿三十六，两手抱昆仑。

左右鸣天鼓，二十四度闻。微摆撼天柱，赤龙搅水津。
鼓漱三十六，神水满口匀。一口分三咽，龙行虎自奔。
闭气搓手热，背摩后精门。尽此一口气，想火烧脐轮。
左右辘轳转，两脚放舒伸。叉手双虚托，低头攀足频。
以候神水至，再漱再吞津。如此三度毕，神水九次吞。
咽下汩汩响，百脉自调匀。河车搬运毕，想发火烧身。
旧名八段锦，子后午前行。勤行无间断，万病化为尘。

末尾"以上系通身合总行之，要依次序，不可缺，不可乱"，是操作硬约束。它意味着：第一段未把身、心、息收到基本稳定，就不要急着进入头颈导引；中段未做开合拉伸，不宜直接跳到河车；最后一段未完成收束，也不算一次完整练习。

**结构分段（流程地图）**：

| 段落 | 歌句范围 | 现代训练任务 | 自检重点 |
| --- | --- | --- | --- |
| 起·收摄安神 | 自"闭目冥心坐"至"两手抱昆仑" | 正坐、握固、闭目、掩耳、微息 | 脊竖直、舌抵腭、身不靠 |
| 承·和畅气血 | 自"鸣天鼓"至"低头攀足频" | 头颈、肩臂、腰背、下肢导引 | 上体稳定、幅度可控、次数准确 |
| 转·周天收束 | 自"以候神水至"至"想发火烧身" | 再漱吞津、河车搬运 | 9咽可核算、温热感不硬造 |
| 合·行功要诀 | 自"旧名八段锦"至"万病化为尘" | 收功、连续练习 | 不省略静养与起身 |

**结构的关键不是"神秘路线"，而是节律切换。** 起段降低外界输入；承段用轻刺激增加血循环与关节活动；转段借吞咽、呼吸和温和注意把兴奋往回收；合段以坚持、节律代替一次高强度。把这条回路练顺，后续接十六段锦、工位版或峨眉明字桩，都更容易稳定。

### 6_4 练习前准备

**准备时间通常比增加次数更能决定质量。** 每次总时长以20—30分钟为宜，初学可先完成15分钟完整回路，再逐步补足。优先早晨或上午，因清醒后容易形成稳定锚点；"子后午前"只是古法提示，现代人不必因此夜间强练。每天1次即可，连续约4周再回头比较情绪、睡眠与肩颈紧张，不宜以单次"感觉多好"判断。

| 项目 | 可执行标准 |
| --- | --- |
| 时间 | 每日1次；每次20—30分钟，初学15分钟起 |
| 时段 | 早晨或上午优先；"子后午前"不刻板 |
| 频次 | 连续4周观察趋势，不追求一天两练 |
| 环境 | 安静、避风、光线柔和；避开饭后1小时内 |
| 坐姿 | 散盘、单盘、双盘或端坐硬凳；臀下垫高2—3厘米 |
| 穿着 | 宽松，不束腰腹；摘眼镜、手表等束缚 |
| 舌位 | 舌尖轻抵上腭，除吞咽外贯穿全程 |
| 连续性 | 先保证每周稳定完成，再提高精度 |

坐姿决定后面能否放松。盘坐时坐骨向下放稳，骨盆不前倾、后倾过多；端坐硬凳时，脚掌踏实，膝约90度，不跷腿。臀下垫高2—3厘米的目的，是减少腰部为"坐直"而持续用力。脊梁竖直不是挺胸憋气，而是头顶有轻上领、下颌微收、腰肋自然展开；后背可靠不靠物，肩不耸、肘不夹。

**坐姿结构（简图）**：

```plain
头正、下颌微收
     │
肩沉、肘坠、手结定印或握固
     │
脊梁竖直，不后仰、不前弓
     │
腰不软、腹不紧、臀下垫高
     │
坐骨坐实；盘坐则双膝下沉

```

**五事自检口诀**："脊竖直、腰不软、身不靠、舌抵腭、臀垫高"。每次闭眼前扫一遍；有一项未满足就先调整。对初学者而言，准备30秒，远胜中途反复纠正姿势。

**"神水九次吞"必须按三次分度核算。** 第五段为第1度，作3咽；第十一段说"再漱再吞津，连前一度，此再二度"，后二度每度3咽，共6咽。算法固定为：

| 度 | 咽数 |
| --- | --- |
| 第1度 | 3咽 |
| 第2度 | 3咽 |
| 第3度 | 3咽 |
| **合计** | **9次吞** |

不能误把"三度"写成"3＋3＋3＝9"后，又把第九段"叉手双虚托"也算作一次吞津。第九段是拉伸动作，不产生咽津；真正统计的是第五段1度、第十一段2度。每次练习可在心中简单标记"度一／度二／度三"，避免匆忙中漏算。

### 6_6 三段重点深解

十二段锦能否形成完整回路，关键不在把十二段都做完，而在起收、生津与归元三个转折是否清楚。下面三段分别落实"三调"如何起步、津液如何按流程分度，以及热能和河车怎样以轻守收束。

#### 冥心、握固与竖脊：先把"三调"落在身体上

**冥心不是压灭念头，而是停止把念头续写成故事。** 原典要求闭目、收心、握固、竖脊。实践中，发现走神即把注意力放回呼吸、坐垫压力或手部触觉；不必责备自己，也不利用"空白"竞赛。杂念被评判后会更多，被轻轻放回锚点则会逐渐减少。

握固的具体做法是：拇指屈掐无名指根，其余四指自然收于掌心，松紧如轻握棉团。它并非越紧越好，主要作用是给手部一个低强度触觉锚点。竖脊的意义在于：胸廓不受挤压，呼吸较易深长；腰颈不过度塌陷，头颈与腰背的张力相对均匀。由此可见，第一段不是仪式，而是后续"以意引气"的前提。

#### 赤龙搅水津：把"生津四件套"做成可重复流程

**舌、齿、耳、咽属于同一组低剂量基础件。** "赤龙"是舌，"神水"是津液。操作时舌尖先轻抵上腭，再沿上下、左右缓慢搅动；待满口后鼓漱36次，使两腮、舌下均有湿润感；随后一口分三咽，每次吞咽有声、连续，意想随下落至小腹。唾液增多、咽喉润泽即为有效，不必追求"满口溢出"。

龙虎之说在此是吞咽与气机下行的隐喻。现代可理解为：轻柔口腔刺激增加唾液，分次吞咽配合呼气，使注意与咽喉、膈肌动作同步，帮助从头部兴奋转向安静。若口干明显，可先做搅津，不必强行36次；有口腔溃疡或张口疼痛者，降低搅动强度。

生津四件套的完整操作与次数见板块2。本板块只规定它在十二段锦中的调用顺序：

```plain
叩齿36 → 掩耳抱颈、鼻息9 → 鸣天鼓48 → 撼天柱各24
   ↓
搅津＋鼓漱36 → 第1度分3咽
   ↓
第六、七段热能闭环
   ↓
第十一、十二段：再2度共6咽 → 河车收束

```

#### 热能闭环：第六、七段是从肢体到收摄的转折点

**搓手—摩腰—存想构成一组"外热—导热—归位"的训练。** 第六段以双手搓热，掌心含空地摩擦后腰肾俞区域；第七段借温和观想，把注意从分散动作收向脐下。这里的"火"宜理解为局部温热、放松与注意归位，不是必须发热。

| 环节 | 内容 |
| --- | --- |
| 搓手 | 外热 |
| 摩腰 | 导热至肾俞 |
| 存想引热归小腹 | 归位 |

初学者若没有热感，可先用中指或无名指轻点脐下，建立位置条件反射；有温热则顺其自然，没有也不补做、不加力。过度追求热感会造成皱眉、憋气和头部紧张，反而背离收摄目标。

#### 河车搬运：只走"似守非守"的任督意象

**第十二段的路线应画成闭环，而不是把某一点抓死。** 古本从尾闾起，经腰间、脊背、后颈、脑后到头顶；再经额上、太阳、耳根、两颊、喉下、心窝、肚脐回到丹田。

```plain
头顶 → 额上 → 太阳/耳根 → 两颊 → 喉下 → 心窝 → 肚脐 → 丹田
  ↑                                                              │
  │                                                              │
尾闾 → 腰间 → 脊背 → 后颈 → 脑后 ───────────────────────────────┘

```

练习时可采用"呼吸＋路线"的轻锚：吸气时不追热，呼气时让注意沿前侧缓慢落到小腹；一圈未完成就回到呼吸，不必从头数圈。所谓"想发火烧身"，只在身心已经稳定、自然出现温热时顺势觉察；初学若强行制造热、光、流窜感，应立即回到自然呼吸与外部环境。河车搬运5分钟即可，状态好可到10分钟，坐不住就收功，绝不把耐力当作功夫深浅。

### 6_7 十六段锦与八段锦坐功

**十六段锦的价值，在于把多套导引"标准化"为十六条。** 冷谦《修龄要指》自言"取诸家要约切当者十六条"汇编成篇。原典对行功时机的描述是："凡行导引，常以夜半及平旦将起之时，此时气清腹虚，行之益人。先闭目握固，冥心端坐，叩齿三十六通。"现代不必拘泥夜半，可将"平旦将起"转化为晨起床上或椅上练习。

十六段锦以坐式为主，适合体力较弱、久坐人群和短时练习。其普遍格式是"一个动作＋二十四次＋去某一处邪气"，但具体段次、动作存在版本差异，不宜把不同图谱强行统一。实操原则如下：

1. 先端正坐姿，完成握固、叩齿与调息；
2. 每段动作展开时吸气，收回时呼气；
3. 次数按体力可为24或减半为12，宁少而准；
4. 最后一段以搅津、鼓漱、咽津收束，不可省；
5. 若出现头晕、胸闷，立即停止并恢复自然呼吸。

**八段锦坐功与"导引却病要诀"高度重叠。** 《万寿仙书》所载八段锦坐功，可提取为：抱昆仑＋鸣天鼓、撼天柱、赤龙搅水津＋漱津三咽、背摩后精门、叉手双虚托＋低头攀足。这些动作也反复出现在十二段锦、十六段锦、冷谦导引要诀中，因此可称为"通用基础模块"。

| 标准件 | 主要部位 | 常用次数 | 可独立使用场景 |
| --- | --- | ---: | --- |
| 叩齿 | 齿、颌 | 36 | 晨起、久坐前 |
| 鸣天鼓 | 耳、枕部 | 左右各24 | 头胀、用脑后 |
| 撼天柱 | 颈、肩 | 左右各24 | 久坐颈肩紧张 |
| 搅海、鼓漱、咽津 | 口腔、咽喉 | 鼓漱36；分度咽 | 口干、练前练后 |
| 摩肾堂 | 后腰 | 24—36 | 久坐、畏寒不适 |

**"记一套，通全书"的要点是固定顺序，而不是每次都做全套。** 顺序固定为：叩齿→鸣天鼓→撼天柱→搅海→鼓漱→分咽→摩腰→收功。当天若已完整练十二段锦，不必重复追加相同次数；只有碎片时间，才从中取2—3项。

**工位8分钟版应优先保住顺序和收功。**

| 时间 | 内容 |
| --- | --- |
| 0:00—1:00 | 端坐竖脊，闭目握固，自然呼吸 |
| 1:00—3:00 | 叩齿36；掩实耳孔，鸣天鼓左右各24 |
| 3:00—4:00 | 微撼天柱，左右各12 |
| 4:00—6:00 | 搅津＋鼓漱36；分3咽，意送小腹 |
| 6:00—7:00 | 搓手24；摩后腰肾俞区24 |
| 7:00—8:00 | 搓掌浴面18；睁眼，活动手脚再起身 |

此流程不是医疗处方，只是低强度动作组合。工位版可每天做，但若与完整十二段锦同日练习，建议把闭气、强意念段落留在正式练习，工位版只保留轻刺激与收束。

### 6_8 安全提示

**安全边界必须先于"古法原汁原味"。** 低头攀足以腰背不出现疼痛、腿后不出现锐痛为限。腰椎疾病、椎间盘突出、急性腰痛者，可减小弯腰幅度，或改为坐位前伸、温和腘绳肌拉伸；出现下肢麻痛立即停止。膝痛者不勉强腿伸直，可在膝下垫软枕。

闭气类段落尤其需要个体化。高血压、冠心病、脑血管病史、青光眼、孕期或饭后饱胀者，不做长时间闭气；可将"闭气搓手热"改为自然吸气后缓慢搓手，仍保留摩擦与温煦的逻辑。任何情况下，一旦出现头晕、胸闷、心悸、视物模糊、恶心，立即停止，恢复自然呼吸；症状持续或加重应及时就医。

**"用意要轻"是贯穿全篇的安全阈值。** 热感、跳动、唾液增多都可观察，但不需要追逐；没有则不强补。若练后反而头痛、紧张、失眠加重，应先减时间、减闭气、增动功，再检查坐姿与次数。坐功可辅助生活节律，不替代医疗、药物或心理诊疗。

### 6_9 案例小故事：徐文弼定名与初学者的"完整一遍"

**案例小故事：徐文弼定名十二段锦（原典记载类）**

**背景：**《寿世传真》在清乾隆年间首次把这套坐式导引明确称为"十二段锦"，并为各节增补详解；此前相关内容多以八段锦、导引要诀等名称散见。

**困境：** 一位初学读者把新版每式单独练完即结束，常漏掉第十一、十二段的再漱吞津与河车收束。他的动作数量没错，却把"十二段"当成了十二个并列动作。

**转折：** 他按古本总诀把练习改写成四段回路，并在吞津、河车两处设置最少记录。关键不是背熟全部古文，而是确认"第1度3咽＋后二度6咽＝9咽"，以及河车是否做到似守非守。

**落地启示：** 今天练十二段锦，应先以完整回路为目标，再谈动作优美。练时身上应有"脊背稳定、吞咽清楚、腰背温热或放松、收功后不头晕"的感觉；若只剩八分钟，优先做通用基础模块，不可把省略版误称为完整十二段锦。自检方法：练完当场合上歌诀，复述四段结构与12段顺序，核算吞津三度是否共9咽；若顺序断裂或次数不清，下一次就从第一段重新开始，不跳段追赶。

### 6_10 练习场景示例：工位版与完整版的边界

**练习场景示例：工位版与完整版的边界（示例情景，非原典记载）**

**背景：** 一位久坐办公者每天只有两段碎片时间，想把工位8分钟版和晚间十二段锦合并，结果晚间重复鸣天鼓、咽津后感到头部紧绷。

**困境：** 问题不在动作错误，而在"碎片化练习"被误当成完整正式练习，又在同一天机械叠加相同次数。重复追热、反复意守头部，使原本的放松流程变成持续输入。

**转折：** 他把流程明确分层：工位版只做叩齿、鸣天鼓、撼天柱、搅海咽津、摩腰和浴面；晚间正式十二段锦保留完整次数与河车搬运。若白天已练工位版，晚间可减少重复项的次数，不以"次数越多越好"累加。

**落地启示：** 今天执行时，应先确认当天属于"碎片维护"还是"完整回路"。工位版的体感目标是颈肩稍松、口中润泽、起身平稳；完整十二段锦才是九咽与河车收束的正式场景。重复动作一旦带来紧张，减量比加量更安全。自检方法：练后用手触摸后颈与肩，若肌肉比练前更硬或头部有压迫感，说明重复过度，次日应去掉重叠项。

### 6_12 本板块的验证方法

**验证标准是"回路通畅、剂量清楚、练后能稳"。** 不把特殊感觉作为进阶门槛，而以动作完整性、坐姿稳定、呼吸舒适和长期趋势作判断。

| 项目 | 自检方式 | 达标线 |
| --- | --- | --- |
| 次序 | 合上歌诀，复述四段结构 | 能说出12段顺序与每段次数 |
| 吞津算法 | 当场核算三度 | 第1度3＋后二度6＝9咽 |
| 坐姿 | 靠墙正坐，检查后脑、肩胛、骶骨接触 | 头顶不刻意顶墙；身不靠椅背 |
| 头顶不起伏 | 缓慢完成头颈动作时自拍或他人观察 | 无大幅上下点头 |
| 热能闭环 | 核对搓手、摩腰、存想三段 | 三段都完成，无刻意追热 |
| 河车 | 问"是否强行看见热气" | 答案应为"否" |
| 收功 | 检查搓掌浴面、静养、慢起身 | 不省略静养3—5分钟 |
| 连续性 | 统计4周练习天数 | 每周约5天为有效节律 |
| 长期趋势 | 比较入睡耗时、夜间觉醒、肩颈自评 | 4周后至少一项改善或稳定 |

进阶不以"能坐更久"为唯一指标。更稳妥的进阶是：先做到顺序完整，再做到呼吸不促、腰背不僵，最后才增加河车时间。若练满4周仍无客观改善但练习规律，应先检查坐姿、剂量、闭气和安全边界，而不是盲目加量。

### 6_13 本板块收束

板块6的核心判断是：十二段锦的价值不在某个单独动作，而在"收摄—流通—归元"的完整回路。十二段逐段齐全——从冥心握固、叩齿鸣鼓、撼天柱、生津吞津、背摩精门、温煦脐轮、摇转辘轳、叉手双虚托、低头攀足，到再漱吞津、河车搬运——其中"神水九次吞"的算法（第1度3咽＋后2度各3咽＝9咽）是不可省略的剂量硬约束。十六段锦与工位8分钟版则提供了低门槛的扩展与碎片场景。

今天练习时，应始终以"完整回路"为目标：第一段把身、心、息收到基本稳定，中段让头颈、肩臂、腰背、下肢依次得到导引，转段借吞咽与温和注意完成归元，合段以坚持与节律代替一次高强度。若时间有限，宁可只做通用基础模块（叩齿→鸣天鼓→撼天柱→搅海→鼓漱→分咽→摩腰→收功），也不能省略收束。工位版与完整版应明确分层，重复动作一旦带来紧张，减量比加量更安全。

安全边界的核心是"用意要轻"：热感、跳动、唾液增多都可观察但不追逐，没有则不强补。闭气段落对高血压、心血管疾病等人群必须改为自然呼吸。若练后反而头痛、紧张、失眠加重，应减时间、减闭气、增动功，再检查坐姿与次数。坐功可辅助生活节律，但不替代医疗、药物或心理诊疗。

生津四件套的完整操作见板块2，静坐卧功的次第与偏差处理见板块6，峨眉十二桩体系中幽、明二桩与坐功的衔接见板块5。通用问题见板块11。
立式动功解决"通"，坐卧静功解决"养"。板块6已经完成坐姿导引的回路，本板块进一步处理"坐定之后如何收、卧下之后如何过渡、出现异常如何停"。核心不是追求特殊境界，而是把调身、调息、调心做成可观察、可收束、可停止的流程。

### 6_14 功法二 · 静坐、卧功与偏差处理

### 6_15 为什么需要专门的静坐与卧功

**动功能解决"通而不稳"，静功才能解决"通后归位"。** 峨眉十二桩的结构是"前实后虚，前动后静"：前十桩偏站功、动功，后两桩为幽、明二桩，属于坐卧静功。这一结构不是把训练难度降低，而是避免只练开合、不练收敛。动功之后若没有静功，身体容易停留在兴奋、松散或反复起念；静功若没有动功基础，又容易变成昏沉、僵硬和硬熬时间。

**"前动后静"应成为每日顺序，而不是两个孤立栏目。** 清晨可先以动功或十二段锦打开身体，再用静坐收束；晚间可先以温和动功或通用基础模块降速，再进入幽字桩、明字桩或普通静坐。体力弱、无法久坐者，可从卧功过渡；时间紧者，至少完成"调身—3分钟守息—搓掌浴面—慢走"。

| 状态 | 更适合的起点 | 不宜强求 |
| --- | --- | --- |
| 身体紧张、思绪乱 | 动功／十二段锦片段 | 直接长时静坐 |
| 久坐后腰背酸 | 轻伸展＋端坐 | 双盘硬撑 |
| 体力弱、睡前难静 | 幽字桩仰卧 | 复杂观想 |
| 已有静坐基础 | 明字桩／普通静坐 | 强行意守头部 |

静坐与卧功的共同原则，是把注意力强度控制在低位。板块1_7强调"似守非守"与外部注意焦点；本板块不重复其理论，只把它落实为坐姿、呼吸、守息和停止信号。站桩反应图谱见板块2，十二段锦的完整导引回路见板块6。

### 6_16 静坐三调与次第

**三调的顺序是"先调身，再调息，最后调心"。** 身不安，呼吸难稳；呼吸不稳，强行"空念"只会把紧张藏在安静表象下。每次静坐开始前，至少花两分钟把姿势与下颌、肩、手、骨盆逐项放回中立位。

```plain
调身：稳定骨架、解除紧绷
   ↓ 身安则呼吸易稳
调息：自然、细长、均匀
   ↓ 息稳则注意力有锚点
调心：不追随、不评判、不续写
   ↓ 心松则反应不必追逐
收功：搓掌浴面、慢走、归位

```

#### 调身：七支坐法的实操取舍

**"七支坐法"应先求稳定、舒适、可维持，再谈盘腿形式。** 散盘、单盘、双盘或端坐硬凳都可，关键不是姿势名称，而是能维持15分钟而不持续疼痛。

| 部位 | 要点 | 常见错误 |
| --- | --- | --- |
| 臀 | 垫高2—3厘米 | 完全平坐致腰部代偿 |
| 骨盆 | 略前倾，坐骨坐实 | 后仰靠背、骨盆后倒 |
| 脊柱 | 竖直、自然延展 | 挺胸憋气、猫背缩颈 |
| 下颌 | 微收，后颈轻上领 | 仰头、低头 |
| 肩 | 沉肩、肘坠 | 耸肩、夹肘 |
| 手 | 定印或握固 | 手悬空、握拳过紧 |
| 眼 | 垂帘或微睁 | 用力闭眼、东张西望 |
| 舌 | 轻抵上腭 | 长时间离开或用力顶 |

端坐硬凳时，脚掌平放，膝约90度，不跷腿；椅背仅作临时辅助，最终应能做到"身不靠"。盘坐时若膝明显高于髋，可在膝下垫支持物，不让腰为保持正直持续用力。舌抵上腭贯穿全程，仅在说话、饮水、吞咽时暂时离开。

#### 调息：从自然呼吸到"听不到呼吸声"

**初学只练"自然、细长、均匀"，不追腹式、逆腹式。** 第一步把注意力放在鼻孔或上唇的气流感；第二步默数吸气与呼气长度，使呼略长于吸或两者大致相等；第三步只在呼吸自然变细后，观察一呼一吸的整体节律。所谓"听不到呼吸声"，是避免过度用力，不等于屏住呼吸。

数息法操作如下：鼻吸时默数1，鼻呼时默数2，数至10后回到1；数错或走神就从1重新开始。数息的目的不是训练记忆，而是给注意力一个低强度任务。随息法不再数数，只跟随"吸气开始—中段—结束—呼气开始—中段—结束"的自然流动；发现跟随中断，回到鼻腔气流即可。

#### 调心：不追随、不评判、不续写

**调心不是把念头压成空白，而是停止把念头接成连续剧情。** 念头出现时，不责备、不分析、不延伸；只标记"想、听、痒、紧"，再把注意力放回呼吸、坐垫压力或脚底接触。若杂念很强，可将锚点从"小腹"改为环境声音或呼气长度，降低内守强度。更深入的似守非守与注意焦点，见板块1_7。

**15分钟静坐流程表（可直接执行）：**

| 时间 | 内容 |
| --- | --- |
| 0:00—2:00 | 调身：检查臀、脊、肩、舌、手 |
| 2:00—5:00 | 调息：自然呼吸；数息或随息 |
| 5:00—13:00 | 守息：只守呼吸／气流／呼气长度 |
| 13:00—15:00 | 收功：放松注意，搓掌，浴面，睁眼 |
| 15:00之后 | 慢走3分钟，再进入日常活动 |

守息阶段不必刻意制造热、光、流窜感。若呼吸自然变慢，就顺势慢；若焦虑明显，可把呼气延长约一秒，但不追求"一分钟几次"的硬指标。收功不可省，否则容易起身头晕、心神不定。

### 6_17 坐法选择与进阶

**坐法应从"能稳定坐住"开始，而不是从双盘开始。** 散盘门槛最低，适合初学与短时练习；单盘可增加髋、膝牵拉，但左右应轮换；双盘只适合关节活动度与持续练习基础均足够者；端坐硬凳则最适合膝痛、踝痛或久坐后无法盘坐的人。没有哪一种坐法天然更高级。

| 进阶方向 | 特点 |
| --- | --- |
| 端坐硬凳 → 散盘 → 单盘 → 双盘 | 从最稳定到仅在有基础时选择 |

每次时长建议从10分钟起步；连续约两周能基本稳定后，再增加至15分钟；此后每约两周增加5分钟，最终以20—30分钟为常见区间。增加时长的前提不是"硬坐得住"，而是收功后头脑清晰、身体放松。若每次最后五分钟都在忍耐疼痛，应回到短时长或多分段。

**腿麻不是"通关信号"，而是应处理的压迫信号。** 轻度针刺感可在保持姿势、转为自然呼吸后观察；若麻感持续上升、影响起身，或伴随疼痛、发凉，应换腿、伸直或结束。硬扛会把"养"变成"耗"，也可能造成踝、膝关节不适。腰骶不稳者可在臀下持续垫高；肩颈持续紧张者优先检查下颌与肘，不应靠耸肩维持"端正"。

### 6_18 卧功：峨眉幽字桩

**幽字桩是全体系中唯一的仰卧桩，也是从动功进入静功的桥梁。** 峨眉十二桩口诀总纲为"天地之心，龙鹤风云，大小幽明"，其中幽与明配对：幽偏过渡，明偏归宿；前十桩主站功、动功，幽、明二桩主静定。完整十二桩体系见板块5。

```plain
前十桩（站功、动功）
       ↓
 幽字桩（仰卧）
 过渡：降速度、松身体
       ↓
 明字桩（静坐）
 归宿：守息、收摄

```

#### 姿势与呼吸

仰卧于床或平稳垫面，双脚自然分开约与肩宽，脚尖朝外；双手置于身体两侧，掌心朝上，手指微曲。枕高以使颈背大致中立为宜，过高会使下颌前伸，过低会使后颈紧张。臀部、肩背与后脑均匀接触支撑面，不刻意挺腰。

呼吸可按"吸—悬—呼"执行：鼻吸时腹壁自然扩张，感受气沉小腹；悬息约3—5秒，重点是自然停留、不憋闷；口或鼻缓慢呼气，小腹回收，如肚脐轻贴向背后。呼气末可极轻地提会阴，若有若无，不做强收缩。若悬息引起头胀、心慌，直接改为"吸—呼"两拍。

#### 适用与限制

幽字桩适合体力弱、无法久坐、睡前难静、动功后需要过渡的人群。每次10—20分钟；只做5分钟也比强行长坐更有可执行性。它不同于普通睡眠：保持轻度觉察，不做复杂观想；出现明显睡意时，可转成睡前放松，不必坚持"桩功形态"。

**卧功安全提示：**

+ 睡前练习后避免受凉，尤其覆盖腹部、肩颈；
+ 饭后不宜立即仰卧练习，至少间隔约1小时；
+ 胃食管反流、打鼾明显或夜间呼吸困难者，上半身适当垫高；
+ 孕期、严重腰椎病、心脑血管病等，按个人情况咨询专业人员；
+ 练中或练后出现胸闷、心悸、头晕，立即停止并恢复自然呼吸。

幽字桩的功能可概括为"先降速度，再转静坐"。身体由站转卧，呼吸由动转细，注意力由外界动作转回呼吸和身体接触；只有这一步完成后，才适合进入更安静的明字桩或普通静坐。若躺下后立即昏沉，可先睁眼数分钟，或把练习缩短为呼吸三轮。

### 6_19 静坐中的常见偏差与处理

**偏差处理的第一原则是"先降低注意力强度，再恢复身体活动"。** 本节只列静坐特有或高发的问题；站桩、动功反应另有专门板块。所有"表现—原因—处理"都以可观察行为为准，不以玄学解释替代。

| 问题 | 常见表现 | 主要原因 | 处理方式 |
| --- | --- | --- | --- |
| 强压念头 | 越想静越乱，头部紧、烦躁 | 把冥心误作压念 | 改不追随；回到呼吸、声音或脚底 |
| 昏沉 | 点头、垂头、嗜睡 | 疲劳、饭后、时段不当 | 睁眼、抬下颌；缩短时长，改上午 |
| 掉举 | 思绪跳跃、身体躁动 | 过度内守、兴奋、焦虑 | 先动功；改随息、数息；换外部焦点 |
| 追求气感 | 头胀、热流乱窜、紧张 | 用意过重、追逐感受 | 停止观想；自然呼吸、睁眼、走动 |
| 腿麻硬扛 | 麻木持续上升 | 把不适当作修行 | 换腿、伸直或结束；改端坐 |
| 收功省略 | 头晕、心悸、心神不定 | 气血未归位即起身 | 搓掌浴面、拍打四肢、慢走3分钟 |
| 情绪释放 | 突然低落、想哭 | 副交感释放或旧情绪被激活 | 停止强守；散步5分钟，必要时求助 |

**昏沉与掉举不能共用一种处方。** 昏沉是清醒度不足，应打开眼帘、检查枕头高度、缩短时长；掉举是注意力过度活跃，应先做身体动作再坐，或把锚点换成数息。两者都可用"每日固定时段"改善：长期在极度疲劳的睡前追求深度静坐，通常只会积累失败经验。

**"停止信号"应提前写在练习清单上。** 出现头晕、视物模糊、胸闷、心悸、恶心、强烈恐惧、不受控动作或疼痛持续，应立即停止，恢复自然呼吸；若在卧功中发生，先转为侧卧或坐姿。症状持续、反复发作或影响日常生活，应就医或寻求专业心理帮助。特殊感受可以观察，但不能追逐；身体不适没有"练过去就好"的豁免权。

### 6_20 静坐反应图谱

**把反应分成"正常、临界、停止"，比把一切体感归为"得气"更安全。** 静坐常见温热、发胀、肌肉微颤、手脚微热微麻、唾液增多、打哈欠、流泪、肠鸣与情绪起伏；这些变化若随收功减轻，通常属于正常适应。关键不在现象名称，而在是否可逆、是否可控、是否影响日常功能。

| 类别 | 常见反应 | 判断标准 | 处理 |
| --- | --- | --- | --- |
| 正常 | 温热、发胀、微麻、肠鸣、哈欠、唾液增多 | 短暂、可波动、收功后缓解 | 保持自然呼吸，不改守 |
| 正常 | 情绪释放、落泪 | 不持续失控、不影响生活 | 停止强守，散步5分钟 |
| 姿势性 | 肩颈酸痛、腰背酸 | 与坐姿、时长直接相关 | 调整姿势、缩短时间 |
| 临界 | 头胀、局部热感持续增强 | 随用意加重、不易回落 | 停止观想，改外部焦点 |
| 临界 | 明显气感、跳动、紧张 | 注意力被牢牢吸引 | 睁眼、起身、恢复动功 |
| 停止 | 头晕、胸闷、心悸、视物模糊、恶心 | 任何一项出现 | 立即停止，必要时就医 |
| 停止 | 强烈恐惧、失控、症状持续 | 影响日常功能 | 暂停静功，寻求专业帮助 |

静坐特有部分不应照抄站桩反应。站桩更多是下肢负荷、重心与肌肉张力；静坐更多来自头部紧张、呼吸控制、久坐压迫与情绪波动。因此，静坐问题优先检查：是否憋气、是否死守头部、是否硬撑腿麻、是否饭后即练、是否省略收功。

### 6_21 睡前20分钟流程

**睡前流程的目标是把"动作—呼吸—静定"连成一条下降曲线，而不是再练一轮高强度。** 睡前1小时不做剧烈动功，也不进行竞争性训练。以下为可执行链：

| 时间节点 | 内容 |
| --- | --- |
| 前60分钟 | 停止剧烈运动与强刺激信息 |
| 前20分钟 | 温和动功／十二段锦通用基础模块（约5—8分钟） |
| 前12分钟 | 幽字桩仰卧，吸—悬—呼三轮或5—10分钟 |
| 前5分钟 | 明字桩／普通静坐，守呼吸，不强求入静 |
| 临卧 | 搓掌浴面、放松四肢，侧卧或自然仰卧 |

睡前通用基础模块可选择：撼天柱各12次、搓手摩腰24次、搅津鼓漱后分咽；动作幅度宜小，不做闭气强意念。若当天已完成板块6完整十二段锦，睡前只做幽字桩与短坐即可，不必重复全套。慢呼吸与六字诀的规范见板块2。

**流程中的"降级开关"比理想流程更重要。** 只有五分钟时，可只做：仰卧调身→自然呼吸三轮→搓掌浴面→侧卧；有十分钟时，加幽字桩；有二十分钟时，才接明字桩或静坐。凡出现胃食管反流，抬高上半身；凡练中嗜睡，直接结束并睡眠；凡焦虑明显，不强迫闭眼，可先随环境声呼吸。

### 6_22 案例故事：冷谦"先醒心，后醒眼"与傍晚静坐

**案例小故事：冷谦"先醒心，后醒眼"（原典记载类）**

**背景：**《修龄要指》晨起脚本强调"先醒心，后醒眼"，即意识先恢复、再处理感官与动作。这个原则反过来也适用于从忙碌转入静坐：先把注意力从信息中收回，再闭眼深坐。

**困境：** 一位傍晚练习者下班后直接闭眼静坐，希望十分钟内"清空脑子"。结果耳中仍有会议对话、肩颈持续紧，前五分钟频繁换腿，后五分钟又因没达到预期而烦躁。她把问题归为"杂念太多"，实则尚未完成从活动到安静的过渡。

**转折：** 她改为先走动两分钟，再做撼天柱、搓手摩腰等温和动作；闭眼前先让视觉、听觉各稳定一分钟，再进入数息。关键不是压制残留思绪，而是把锚点设在呼气与脚底接触上，走神一次就回到一次。

**落地启示：** 今天静坐前应确认"心已醒、身已稳"。练习中应有呼吸渐细、肩颈松开、腿麻能及时处理的感觉；若连续十分钟只感到紧绷，应先改短时长、动功过渡和外部焦点，而非把强忍当作功夫。自检方法：每次收功后问自己三个问题——呼吸是否全程无憋气、腿麻是否在上升前已处理、起身是否无头晕；三项皆"是"才算合格静坐。

### 6_23 练习场景示例：峨眉幽字桩的过渡定位

**练习场景示例：幽字桩的过渡定位（示例情景，非原典记载）**

**背景：** 峨眉十二桩把幽、明二桩安排在站功、动功之后，形成"幽为过渡、明为归宿"的配对。幽字桩采用仰卧，适合把全天的高张力活动逐步降下来。

**困境：** 一位体力较弱者尝试直接盘坐静心，每次不到五分钟就因腰背酸、腿部压迫而中断。他把失败理解为"不够有毅力"，于是延长准备姿势、硬压杂念，结果下一次更排斥练习。

**转折：** 他改从幽字桩开始：仰卧检查脊柱与肩颈，只做三轮吸—悬—呼，呼气时把注意放在小腹回落；待呼吸变慢、身体不再频繁翻身，再坐起五分钟。练习从"必须坐住"变成"先过渡、再收敛"，连续性反而恢复。

**落地启示：** 卧功不是动功的弱化版，而是为静坐建立入口。今天练习时应有"仰卧后颈均匀受力、呼吸不憋、起身时不晕"的体感；若躺下即睡，可缩短至五分钟并先活动；若仍需更高强度静定，再由幽过渡到明，不跳过身体准备。自检方法：练完幽字桩后坐起，若能自然进入三分钟数息而不烦躁，说明过渡有效；若仍频繁翻身或思绪狂奔，应先延长动功降速阶段。

### 6_25 本板块的验证方法

**静坐有效性的首要指标是"更稳定"，不是"更神奇"。** 可以把15分钟静坐设为共同基线：10分钟适应后可增加到15分钟；15分钟内不因烦躁而中断，不出现追逐特殊感受，收功后能完成搓掌、浴面、慢走，即算基本达标。

| 项目 | 自检方式 | 达标线 |
| --- | --- | --- |
| 坐姿 | 对镜或录像检查脊柱、肩、下颌 | 15分钟内无明显塌陷、耸肩 |
| 不烦躁 | 15分钟静坐中是否多次中断 | 能坐满，或只作1—2次温和调整 |
| 呼吸 | 是否出现听不到的粗重声 | 自然、细长、无憋气 |
| 腿麻处理 | 出现麻感后的选择 | 立即换腿、伸直或结束，不硬扛 |
| 追逐反应 | 问"是否被热感、跳动吸引" | 答案应为"否" |
| 收功 | 检查搓掌、浴面、慢走 | 三步完整，起身不头晕 |
| 静息呼吸 | 静坐前后各计数1分钟呼吸次数 | 数周后趋势下降或稳定 |
| 睡眠 | 记录入睡潜伏期与夜间觉醒 | 4周后至少一项改善或稳定 |
| 停止信号 | 对照头晕、胸闷、心悸等清单 | 任一项出现即停 |

静坐后可使用"一分钟呼吸计数"作客观趋势：静坐前后各安静坐一分钟，数完整呼吸次数。若长期练习后静息频率下降、心率无异常、清醒度提高，说明放松反应稳定。若追求深长呼吸反而胸闷、头晕，应回到自然呼吸。睡眠指标只作自评参考，不能替代医学诊断。

### 6_26 本板块收束

板块6的核心判断是：静坐、卧功与偏差处理共同服务于一条安全路径——先动后静、先身后心、先低强度后稳定时长。三调的次第（调身→调息→调心）不能颠倒；幽字桩负责从动功到静功的过渡，明字桩负责最终收束；偏差处理的七类常见问题（强压念头、昏沉、掉举、追求气感、腿麻硬扛、收功省略、情绪释放）都指向同一原则：先降低注意力强度，再恢复身体活动。

静坐的坐姿选择应从"能稳定坐住"开始——端坐硬凳→散盘→单盘→双盘，出现疼痛、腿麻立即退回前一档。每次时长从10分钟起步，以收功后头脑清晰为增加前提，不以硬熬为标准。幽字桩作为仰卧过渡，每次5—20分钟即可，关键是"先降速度，再转静坐"，为体力弱或无法久坐者提供可行入口。

静坐反应图谱的"正常—临界—停止"三级分类，与板块2的站桩反应图谱互补而不重复：静坐更多来自头部紧张、呼吸控制、久坐压迫与情绪波动，优先检查是否憋气、是否死守头部、是否硬撑腿麻、是否饭后即练、是否省略收功。六类偏差的处理核心都是"先降低注意力强度，再恢复身体活动"——昏沉者打开感官、缩短时长；掉举者先做动功、换外部焦点；追求气感者停止观想、恢复自然呼吸。

睡前20分钟流程应按"降级开关"思维执行：有时间做完整链条（温和动功→幽字桩→明字桩），时间少则只做仰卧调身与呼吸三轮。每次练习的收功不可省略——搓掌浴面、慢走3分钟，是防止起身头晕、心神不定的必要步骤。任何停止信号出现后立即停止，症状持续或加重应就医。

静坐三调的完整理论见板块1_7；十二段锦的导引回路见板块6；峨眉十二桩体系见板块5；呼吸与气法的安全边界见板块2；通用排错、禁忌分级与长期记录见板块11。静坐最稳健的用法，是把每一次练习都当作可观察、可收束、可停止的流程——不追求特殊境界，不追逐热麻跳动，只确认身安、息稳、心松、收功完整四项同时达标。
