## 板块7 · 动功组合与通用纠错

前四套古典功法——八段锦、五禽戏、易筋经、灵剑子十六势——和两套现代新编——大舞、导引养生功十二法——已经铺开。**这一板块解决最后一个、也是最日常的问题：怎么选、怎么组合、怎么纠错。**

如果说前面板块是"认识每一味药"，这一板块就是"开处方"——**把功法服务于具体目标，而不是让练习者服务于功法**。同时，它把六套功法共通的十个错误一次讲透，使练习者能在任意一套功法中自查。后续可衔接板块6 的坐卧静功、板块11 的训练处方化与板块11 的排错日志。

### 7_1 两套新编功法概览：大舞与导引养生功十二法

四套古典功法之外，国家体育总局健身气功管理中心还组织编创了多套新功法。它们不是"古法"，但**在现代教学体系、动作规范与普及度上有优势**，适合作为原典路线的补充。其中两套与本文主线最相关：

| 功法 | 编创单位 | 编创思想 | 动作特点 | 与古典功法的关系 |
| --- | --- | --- | --- | --- |
|**健身气功·大舞** |武汉体育学院 |以古代文献"**通利关节，以舞宣导**"为指导思想，取材马王堆汉墓出土《导引图》中具"舞"形态的图像 |注重全身各关节的**屈伸、环转**等运动，融合舞蹈元素；讲究以神引舞、以舞导气、刚柔相易、身韵圆和 |与五禽戏同为"仿生／象形"路线，但更强调**关节全方位活动**与律动性 |
| **健身气功·导引养生功十二法** | 北京体育大学 | 精选张广德教授自 1974 年起编创的 50 余套导引养生功中的 12 个动作；以脏腑经络、阴阳五行、气血理论为指导 | 把导引与养生、肢体锻炼与精神修养融为一体，是**经络动功** | 与八段锦同为"按脏腑经络编排"的路线，可作为八段锦的进阶替代 |

#### 什么时候考虑它们

+ 练八段锦久了想换口味，又不愿放弃"按经络编排"的逻辑 → 试**导引养生功十二法**；
+ 关节活动度明显受限，觉得现有功法"太安静" → 试**大舞**，其关节屈伸、环转幅度更大，律动感更强；
+ 想要一套动作规范、有团体标准、便于跟学跟练的入门版本 → 两套都是理想选择。

#### 选用建议（三看）

1. **看目标**：要关节全方位活动、律动愉悦 → 大舞；要经络调理、循经导引 → 导引养生功十二法；
2. **看基础**：完全新手、要最大兼容性 → 先从八段锦／导引养生功十二法入手；有一定柔韧基础 → 再上大舞、易筋经；
3. **看可得性**：优先选择有**官方教学版视频／教材**的版本，动作细节严格以官方教学版为准，不依赖文字描述自行发挥。

> ⚠ **重要提示**：本板块只写定位与选用逻辑，**不虚构具体动作细节**。大舞与导引养生功十二法的每一势名称、路线、呼吸配合、剂量，均以官方教学版为准。练习前务必找到对应教材或权威教学视频对照，本知识库不替代教学视频。

> **选型的核心心法**：没有"哪套更好"，只有"哪套更对目标"。**本库的一贯立场是"主一套，辅一势"——新功法是补缺口的，不是用来收集的。**

### 7_2 如何选功法：一主一辅与按目标选

六套功法的呼吸逻辑、动作顺序和训练目标并不相同，同时入门只会互相干扰。因此，选型应先确定"主一套"，再以针对性单势补短板，而不是按流行程度收集功法。

#### 一主一辅原则

**为什么不能同时入门多套？** 因为每套功法都有自己的"呼吸逻辑"和"动作顺序"：八段锦是"开合拔长"，五禽戏是"仿生劲力"，易筋经是"伸筋拔骨"，灵剑子是"四季时令"。同时入门两套，容易出现呼吸规则混淆、动作顺序打架、哪套都没吃透。

**正确做法**：

+ **主一套**：选定一套作为每日主修，新手建议从**八段锦**或**导引养生功十二法**开始，逻辑清晰、规范完整；
+ **辅一势**：从其他功法挑 1—2 式作为"加强项"，针对性补短板。

#### 按目标选（对症选功法）

| 目标 | 优先组合 | 机理 | 剂量 | 预期周期 |
| --- | --- | --- | --- | --- |
| **久坐颈肩腰背** | 八段锦第 1＋4＋6 式；易筋经第 2 势；灵剑子"叉手争力""托石单举" | 拉伸脊柱、改善腰背肌张力 | 每日 1—2 次，每次 10—15 分钟 | 4—8 周 |
| **睡眠／焦虑／压力** | 十二段锦全套（睡前）；六字诀；慢呼吸 | 抑制交感、增强副交感 | 每晚睡前 20 分钟 | 4 周可见变化 |
| **平衡／防跌倒** | 五禽戏全套（尤其鸟戏、鹿戏）；单腿站立；站桩；太极五步 | 强化本体感觉、下肢力量 | 每周 3—5 次，每次 20—30 分钟 | 8—16 周 |
| **代谢／血糖／体重** | 完整八段锦或五禽戏，长期规律 | 有氧＋肌力＋柔韧复合 | 每周 ≥ 5 天，每次 30—40 分钟 | 12 周以上 |
| **情绪低落／情志不舒** | 八段锦第 2＋7 式；六字诀"嘘"；五禽戏虎戏 | 疏肝理气、宣肺疏泄 | 每日 1 次，春季加重 | 8—12 周 |
| **关节活动度受限** | 大舞全套；灵剑子十六势（四季选 4 势） | 关节屈伸环转、全身拉伸 | 每日 1 次，每次 15—20 分钟 | 8—12 周 |

#### 两条铁律

1. **不要同时入门两套技击拳法**：同理，也不要把八段锦、五禽戏、易筋经都当"主修"。**主一套吃透，再谈拓展**；
2. **目标变了，组合才变**：上面处方不是永久方案。当"久坐颈肩"改善后，可以换目标，如转向平衡、情志，再相应调整组合。**定期复盘比盲目坚持更重要。**

> ⚠ **以上为习练参考，不构成医疗建议。** 有明确疾病者请在医师指导下进行，切勿以练功替代诊疗。

#### 练习场景示例：碎片日程里的一主一辅

**背景：**一位程序员连续工作后颈肩发紧、肩背酸沉，时间被会议切碎，很难一次练完八段锦。他把"主一套"定为八段锦，保留完整晨练；把"辅一势"定为易筋经开肩扩胸与灵剑子叉手争力，试图在每个间隙补足训练。

**困境：**第一周他试图在每个会议间隙重练整套功法，结果不是被打断，就是做得匆忙。耸肩、憋气反而加重，晚间又因未完成"完整计划"而焦虑，第二天索性放弃。身体信号是颈肩更紧、呼吸更浅，说明训练结构压过了身体反馈。

**转折：**他不再追求每次练全套，而是把处方改为：晨起完整主修 12 分钟；工位只拆两势，每势 3 组，单次不超过 3 分钟。练前先放下手机，练中只查"肩是否下沉、呼吸是否自然"这一项；被打断时记录实际完成量，不再补练原计划。

**落地启示：**处方化的关键不是排满动作，而是把动作嵌入真实日程。今天可从"主一套完整＋两个辅势"开始；练时颈肩应逐渐松开，而不是越练越紧。若连续两周无法完成静功或纠错项，应先减处方，再谈加量；记录中须写明日期、实际完成量、疼痛级别与次日恢复，不用"练得差不多"代替数据。

### 7_3 动功通用纠错 TOP 10

这十条是所有立式导引动功的**共通错误**——无论练哪一套，都在这张表里。每一条都严格按"表现＋为什么错＋怎么纠正"自查。完整身体校准与逐节筛查见板块1；此处只保留组合训练最常出现的执行错误。

**TOP 10 错误严重度排行（★ 表示风险／影响程度）**

| 错误 | 严重度 | 后果 |
| --- | --- | --- |
| 耸肩 | ★★★★★ | 力断、气上浮、头胀 |
| 憋气 | ★★★★★ | 血压波动、头晕胸闷 |
| 塌腰撅臀 | ★★★★☆ | 腰椎剪切、腰痛 |
| 膝盖超脚尖／内扣 | ★★★★☆ | 膝关节损伤 |
| 动作快于呼吸 | ★★★★☆ | 呼吸紊乱、越练越紧 |
| 只动手臂不动腰胯 | ★★★☆☆ | 动力链断裂、局部代偿 |
| 求幅度不求张力 | ★★★☆☆ | 摆造型、筋膜没被牵拉 |
| 定势无停顿 | ★★★☆☆ | 失去"伸筋拔骨"的剂量 |
| 下落甩臂 | ★★★☆☆ | 关节冲击、失去控制 |
| 练时刷手机想工作 | ★★☆☆☆ | 注意力涣散、练而无功 |

#### 1. 耸肩（最普遍，几乎人人有）

+ **表现**：肩颈紧绷、肩峰上提、耳朵贴近肩膀；练完肩颈酸痛头胀。
+ **为什么错**：肩一耸，力量传导从"脚→腰→肩→手"的整条链在肩处断裂，而且"气上浮"致头胀。
+ **纠正**：每势定住时**主动下沉双肩**，想象肩膀挂了重物往下坠；舌抵上腭、收下颏辅助；对镜练，看到肩颈线条放松才算过。**"松肩沉肘"四个字，是六套功法的共同总纲。**

#### 2. 憋气（最危险）

+ **表现**：脸发红、青筋突起、练完头晕胸闷；下蹲／发力时习惯性地屏息。
+ **为什么错**：憋气会使胸腔压力骤升、血压剧烈波动，心血管与脑血管风险明确。
+ **纠正**：**初学全程自然呼吸**，鼻吸鼻呼，听不到呼吸声；动作熟练后再尝试"起吸落呼"。出现任何头晕胸闷，立即停止、恢复自然呼吸。**宁可不配呼吸，不可强行憋气。**

#### 3. 塌腰撅臀

+ **表现**：站桩或马步时腰往前塌、臀往后撅，腰椎前凸加大；练完腰酸。
+ **为什么错**：腰椎被置于剪切力最大的位置，长期如此必伤腰；且塌腰必然伴随含胸，整条脊柱的"对拉"被破坏。
+ **纠正**：**微收尾闾**，想象尾骨轻轻指向地面，收小腹、脊柱竖直；靠墙站立检验，后脑、肩胛、骶骨三点贴墙。"含胸拔背"的"拔背"就是治塌腰的。

#### 4. 膝盖超脚尖或内扣

+ **表现**：下蹲／弓步时髌骨超过脚尖，甚至脚趾被挡住；膝盖往内侧塌陷。
+ **为什么错**：膝关节承受的压力远超安全范围，髌骨与半月板长期受损；**膝盖内扣还会连带骨盆歪斜**。
+ **纠正**：**膝与脚尖永远同向**，弓步时膝盖对准第二、三脚趾方向；下蹲幅度以"膝不超过脚尖、大腿无疼痛"为界；膝关节不适者改**高桩微蹲**。

#### 5. 动作快于呼吸

+ **表现**：一套动作赶进度，一个呼吸没完动作已换两势；呼吸变得急促。
+ **为什么错**：动功的"伸筋拔骨"依赖缓慢、持续的张力，动作太快等于没拉伸；呼吸被动作打乱，交感兴奋，越练越紧。
+ **纠正**：**动作速度服从呼吸速度**。一个定势至少停留 3—5 个呼吸，约 15—30 秒；若呼吸跟不上，说明动作太快，主动放慢。**定势停留 30 秒，比匆匆做十下都管用。**

#### 6. 只用手臂不动腰胯

+ **表现**：所有旋转、侧屈都靠手臂完成，腰胯像焊死一样不动。
+ **为什么错**：动力链断裂。真正的力量与拉伸来自"起于脚、发于腰、形于手"，腰不动等于把全部负荷压在肩肘腕，拉伸也触及不到深层筋膜。
+ **纠正**：**凡是旋转、侧屈，都以腰带肩、以肩带臂**，易筋经九牛尾、灵剑子排山斜身都是如此。练习时把手臂当"被动末端"，主动发力点在腰胯。

#### 7. 求幅度不求张力

+ **表现**：动作做得"到位"——手能摸到地、腿能劈得很开，但身体松垮，没有"被拉开"的感觉。
+ **为什么错**：**幅度是外形，张力才是目的。** 没有张力的"到位"只是摆造型，筋膜完全没被牵拉。易筋经"伸筋拔骨"、灵剑子"闭气为之则妙"，本质都要"极力"——是**有控制的张力**。
+ **纠正**：找到牵拉感后**微微回退一点点**，避免疼痛，然后**保持张力停留**。"紧的幅度"比"大的幅度"更重要。

#### 8. 定势无停顿

+ **表现**：每个动作都"滑"过去，不停在定势上，整套练完像在做广播体操。
+ **为什么错**：定势停顿是"伸筋拔骨"的**剂量**——拉伸需要时间，每个拉伸累计约 60 秒才有效，详见板块3 五禽戏中的拉伸剂量说明。不停顿就等于没给药。
+ **纠正**：**每个定势停留 3—5 个呼吸，约 15—30 秒**，把"停顿"当作动作的一部分，而不是"耽误时间"。这也是八段锦、易筋经共同的要求。

#### 9. 下落甩臂

+ **表现**：举手后下落时靠重力"砸"下来，手臂拍打身体；动作失控、关节有撞击感。
+ **为什么错**：失去离心控制，肩关节与肘关节反复受冲击；且"甩"的动作把刚建立的张力瞬间释放，等于白练。
+ **纠正**：**沿原路缓慢返回，全程有控制**，想象手臂在黏稠液体里移动；下落时同样保持肌肉舒缓而持续的用力。**"起与落都用同样的力"——这是"力"这条总纲的真义。**

#### 10. 练时刷手机想工作

+ **表现**：一边练一边看消息、想待办；练完完全不记得练了什么。
+ **为什么错**：**心为君主**——注意力涣散时，呼吸模式紊乱、肌肉募集不到位，练的是"形"而不是"功"。灵剑子"心正则神调"、板块1 的"意守下丹田"都说的是同一件事。
+ **纠正**：**练功前把手机放到视线之外、开启勿扰**；用"动作＋呼吸＋意念"三同步强制收心。若实在静不下来，先做 3 分钟静心时间再开始。

### 7_4 组合编排三原则与一周示例

组合不是把若干套路随机拼凑，而是让顺序、动静比例和单势拆用共同服务于当日目标。三条原则先建立约束，下面的周示例再演示如何把这些约束落到真实日程。

#### 原则一：顺序不可乱

每套功法的顺序都是**递进设计**，不要随意调换：

| 功法 | 顺序逻辑 |
| --- | --- |
| **八段锦** | 三焦 → 肺肝 → 脾胃 → 心肾 → 肾腰 → 肝 → 全身（从调气到固本） |
| **五禽戏** | 虎开腰背 → 鹿活腰胯 → 熊稳中轴 → 猿灵四肢 → 鸟调平衡 |
| **易筋经** | 起（立柱开胸）→ 开（四肢拉开）→ 转（核心脊柱）→ 合（折叠收束） |
| **灵剑子** | 按四季分配，本季主脏 + 补脾，脾贯穿四季 |

**编排顺序的铁律**：先开僵（拉伸热身）→ 再活腰（旋转侧屈）→ 后稳中轴（沉降定桩）→ 终平衡（整合收束）。**把高强度势放中段，收束势（如掉尾、摩腹、引气归元）必须放在最后。**

#### 原则二：动七静三

这是板块11 提到的 FITT 框架下的时间分配原则：**动功占七成，静功（站桩见板块2、坐卧静功见板块6）占三成。**

+ **动七**：以立式导引动功为主——八段锦、五禽戏、易筋经、灵剑子等，每次 15—30 分钟；
+ **静三**：以站桩、十二段锦、呼吸吐纳为辅，每次 10—20 分钟。

**为什么要"静"？** 因为动功练的是"形与筋"，静功练的是"呼吸与注意力"——**两者缺一不可**。只动不静，气血易浮、难以沉淀；只静不动，气血不畅、筋骨不活。**"动以养形，静以养神"是这个比例的根本依据。**

平衡训练的剂量逻辑与此相同：应逐步缩小支撑面、减少手部辅助并加入可控扰动，不能停留在原地站立。具体周期与指标见板块8 与板块11，本节不重复展开。

#### 原则三：单式可拆，急时有用

**一主一辅的真正威力在于"单式可拆"**——遇到具体问题，不必练全套，拆出对应一两势应急：

| 场景 | 拆用动作 |
| --- | --- |
| 久坐两小时颈肩僵 | 灵剑子第 2 势"叉手争力"＋易筋经第 2 势"开肩扩胸"，工位上 3 分钟搞定 |
| 饭后腹胀 | 八段锦第 3 势"单举"（饭前练更佳）＋灵剑子第 6 势"托石单举" |
| 情绪烦躁 | 五禽戏虎戏＋六字诀"嘘" |
| 晨起昏沉 | 鸣天鼓＋摩面 |

> **这是"处方化"的日常价值**：不需要每次都练 30 分钟全套，**零散的 3 分钟单势，积少成多同样有效——前提是动作正确。**

#### 一周编排示例（以"久坐颈肩＋睡眠焦虑"为例）

下面示例**只是示范逻辑，不是标准处方**。可按自己的目标替换主功法与加强势。

| 日次 | 主功法（动七） | 辅势／静功（静三） | 当日重点 |
| --- | --- | --- | --- |
| 周一 | 八段锦全套 12 分钟 | 易筋经第 2 势×3（3 分钟）＋站桩 10 分钟 | 开肩、定桩 |
| 周二 | 五禽戏全套 15 分钟 | 灵剑子"叉手争力"×2（3 分钟）＋静呼吸 10 分钟 | 平衡＋呼吸 |
| 周三 | 八段锦全套 12 分钟 | 易筋经第 7 势×3（4 分钟）＋站桩 10 分钟 | 脊柱旋转 |
| 周四 | 休息／仅"鸣天鼓＋摩面"5 分钟 | 轻量不硬练 | 恢复 |
| 周五 | 导引养生功十二法全套 20 分钟 | 六字诀 5 分钟 | 经络调理 |
| 周六 | 大舞全套 15 分钟 | 单腿站立平衡 5 分钟 | 关节＋平衡 |
| 周日 | 八段锦全套 12 分钟 | 十二段锦（睡前静功）15 分钟 | 收束整合 |

**每日固定**：晨起叩齿吞津 3 分钟＋睡前腹式呼吸 5 分钟。

**每周剂量检查**：动功 ≥ 5 天，静功 ≥ 3 天，单次 20—40 分钟。

**编排的四条微调规则**：

1. **强度交替**：前一天练高强度（易筋经、五禽戏），后一天练舒缓（八段锦、静功），避免连续两天高负荷；
2. **症状驱动**：哪天颈肩特别僵，当天就多加"开肩扩胸＋叉手争力"，不必死守原计划；
3. **时间窗分配**：晨起练主动功（八段锦、五禽戏），睡前练静功（十二段锦，见板块6），工位上做灵剑子的坐式导引；
4. **每周复盘一次**：看"一主一辅"是否仍对症，目标变了就调整组合，见 11_2。

### 7_5 案例小故事（一）：从"样样都练"回到一主一辅

**背景：**
一位退休教师希望改善颈肩与睡眠，第一个月同时买了八段锦、五禽戏、易筋经和十二段锦教学视频。他每天早起先练一套八段锦，上午跟练五禽戏，傍晚又学易筋经，睡前再拆出十二段锦的吐纳段落。

**困境：**
第二周，他开始出现肩颈比练前更紧、夜间难以入睡的情况。检查动作时发现，问题不在某套功法本身：时而按八段锦的"开合"呼气，时而按另一套节奏屏息；练五禽戏时又把虎戏的俯仰速度套到易筋经定势上。身体没有得到明确的顺序和节律，反而持续处于切换、追赶的状态。

**转折：**
他停下来重做选型，只保留**八段锦为主一套**，每周五改练导引养生功十二法作为对照；易筋经第 2、7 势与灵剑子叉手争力只作辅势，每天各练 3 组。TOP 10 自查也每周只攻一项：第一周只查耸肩，第二周再加憋气。

**落地启示：**

今天练习时，应先确认"主一套"并连续执行至少 4 周；辅势只对准一个缺口，不能把补短板变成另开一套。
练完最直观的感受应是颈肩逐渐松开、呼吸自然，而不是身体某处更紧或需要强迫自己追进度。
若一周中出现两次以上头晕、胸闷、关节不适，应减少套数和幅度，先回到自然呼吸与基础定势。
自检方法：每周末核对"主一套"是否完整练满5天、辅势是否不超过2个、TOP 10中是否有一项明显改善；
三项中任两项未达标，说明组合过重，应削减而非加量。

### 7_6 案例小故事（二）：用停顿把"做完"变成"练到"

**背景：**
一位久坐办公者把动功当作晨间打卡：八段锦 12 分钟必须一次不落，动作速度跟随视频口令。前两周他完成了次数，却总觉得肩颈"活动过了"，没有真正松开。

**困境：**
录像自查时，TOP 10 中的第 5、8、9 项同时出现：动作总在换势前滑过去，定势几乎没有停留；手臂举起后迅速落下，腰部也没有参与旋转。问题在于他把"次数"当成唯一目标，结果每个姿势只完成了外形。

**转折：**
他把计划改为：整套时长不变，但每个定势至少停留 3 个呼吸；旋转、侧屈先由腰带肩，下落沿原路控制 3 秒。原本 12 分钟的完整练习，因动作更实，有时只完成 6 势，他却第一次感到拉伸在停留中持续加深。

**落地启示：**
动功的有效性不在赶完多少势，而在每个定势是否留住张力。练时可把"停留 3—5 个呼吸、下落 3 秒、头顶不掉、肩不窜高"作为当次检查点。如果停留后肩颈或腰背出现锐痛，应减小幅度并停止该势，而不是用忍痛换取次数。每次练后至少记录定势停留、耸肩、憋气和次日疼痛四项，才能判断停顿是否真正改善质量。自检方法：对镜或录像回看，确认每个定势在顶点处有至少15秒的清晰停顿，且全程无甩臂、无憋气。

### 7_7 本板块的笔记方法

组合是否对症，不能靠"今天练得很努力"判断，而要回到处方、执行与反馈的闭环。下面模板刻意同时记录主辅功法、TOP 10 自查和最严重的一条，避免把练习日志写成动作清单。

组合与纠错这一板块，笔记的重点是**"处方＋执行＋反馈"的闭环**——选了什么组合、执行得如何、身体反馈怎样，据此调整下一轮处方。

#### 可抄的填空模板

【辅一势】第 1 个：____（来自__板块/功法）重复：____遍
         第 2 个：____                  重复：____遍
【静功（静三）】站桩__min / 十二段锦__min / 呼吸__min

**四个记录要点**：

1. **"主一套辅一势"必须写进笔记**——防止不知不觉"同时入门三套"，这是选型纪律的最有效保障；
2. **TOP 10 自查每天只抓"最严重的一条"**——一次改十个错误等于一个都改不掉；本周重点改耸肩，下周再攻憋气，逐条击破；
3. **"动七静三"要算比例**——很多人只动不静，记下来才发现自己缺了静功，这是组合编排最常见的漏洞；
4. **每周复盘"目标是否仍对症"**——目标变了，组合必须跟着变。这是"处方化"区别于"死练一套"的关键。

### 7_8 本板块的验证方法

一套组合练了数周却不见效，原因通常不在"还不够刻苦"，而在安全、执行、纠错或目标某一层失配。因此验证应从"有无异常"逐层上升到"目标是否前进"，任何一层不达标都先修该层。

组合的验证，本质上是**"处方是否有效"的检验**，分四层：安全性、执行度、纠错进度、目标达成。

#### 第一层：安全验证（每日，零容忍）

| 验证项 | 达标线 |
| --- | --- |
| 全程无强行憋气 | 呼吸自然，无头晕胸闷 |
| 无关节疼痛（膝、腰、肩） | 练习后无明显疼痛，次日无加重 |
| 无新的不适出现 | 不出现头晕、心悸、异常麻木 |
| "动七静三"中静功未缺席 | 每周静功 ≥ 3 天 |

**任何一项不达标，先减量或暂停，排查动作问题，而不是硬撑。** 安全是所有验证的前提。

#### 第二层：执行度验证（每周）

这是"能不能长期坚持"的检验——板块11 与板块11 都强调：**收益依赖持续，不依赖强度。**

| 指标 | 达标线 |
| --- | --- |
| 练习天数 | ≥ 5 天／周 |
| 单次时长 | 20—40 分钟（动＋静合计） |
| 连续性 | 无连续 3 天中断 |
| 定势停留 | 每个定势 ≥ 3 个呼吸（约 15 秒） |

**如果连续两周不达标，问题不在"意志力"，而在"处方太重"。** 应降低难度、缩短时长，把可持续性放在第一位。

#### 第三层：纠错进度验证（每两周，对照 TOP 10）

**这是本板块最有特色的验证——用客观指标看"错误有没有减少"，而不是看"练得熟不熟"。**

| 错误项 | 第0周 | 第2周 | 第4周 | 第6周 | 趋势 |
| --- | --- | --- | --- | --- | --- |
| 耸肩 | ✓ |  |  |  |  |
| 憋气 | ✓ |  |  |  |  |
| 塌腰撅臀 | ✓ |  |  |  |  |
| 膝盖超脚尖／内扣 | ✓ |  |  |  |  |
| 动作快于呼吸 | ✓ |  |  |  |  |
| 只动手不动腰胯 | ✓ |  |  |  |  |
| 求幅度不求张力 | ✓ |  |  |  |  |
| 定势无停顿 | ✓ |  |  |  |  |
| 下落甩臂 | ✓ |  |  |  |  |
| 练时刷手机 | ✓ |  |  |  |  |

**目标：6 周内至少 6 项转为已改善。方法：每周只攻 1 项，对镜／录像自查。**

**客观检测手段（推荐）**：

+ **录像回看**：每月录一次完整练习，慢放对照 TOP 10，比肉眼自查可靠得多；
+ **对镜检查**：重点查耸肩、塌腰、膝盖内扣三项，侧面镜最有效；
+ **呼吸监测**：练中是否能轻松交谈——能，说明强度合适；不能，说明太快或憋气。

#### 第四层：目标达成验证（以月为单位）

回到 11_2 的"按目标选"，用对应指标检验处方是否有效：

| 目标 | 验证指标 | 达标线（数月） |
| --- | --- | --- |
| 久坐颈肩腰背 | 颈肩紧自评、坐位体前屈 | 紧度下降 ≥ 1 分，柔韧改善 |
| 睡眠／焦虑 | 入睡时长、睡眠量表 | 入睡时长缩短，量表改善 ≥ 1 分 |
| 平衡／防跌倒 | 单腿闭眼站立时间 | 提升 ≥ 30% |
| 代谢／体重 | 腰围、空腹血糖 | 腰围下降，血糖趋稳（需医学监测） |
| 情志 | 情绪自评、压力量表 | 下降 ≥ 1 分 |
| 关节活动度 | 关节活动范围测量 | 明显改善 |

> **达标线的意义**：如果连续 2—3 个月，第四层指标**没有任何改善**，说明要么处方不对（回到 11_2 重新选型）、要么执行度不达标（第二层有问题）、要么存在需要医学处理的基础疾病（应就医，而非加大练功量）。

#### 组合有效性的三条判据（一句话总结）

1. **安全无异常**（第一层零异常）；
2. **可持续**（第二层达标，每周 ≥ 5 天）；
3. **目标在前进**（第四层指标有改善趋势）。

三条都满足，说明这套组合有效，继续深化；**任何一条不满足，先修那一条，而不是盲目加量。**

### 7_9 本板块收束

板块7 的核心判断是：动功组合的本质不是"练更多"，而是"练得更对症"。一主一辅防止贪多嚼不烂，动七静三保证形神兼顾，单式可拆让处方能嵌入真实日程；
TOP 10 纠错则把六套功法的共通错误浓缩为可逐条自查的执行清单。组合编排的三原则（顺序不可乱、动七静三、单式可拆）与一周示例共同构成处方化思维的操作框架。
到此，立式导引动功的主干已经闭环。
