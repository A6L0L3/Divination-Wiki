## 板块8 · 峨眉十二桩：从站桩到通达气脉

本板块把《峨眉十二桩》由"两三个常用桩式"还原为一套有源流、有次第、有体感、有验证的练功体系。十二桩不是十二个静止姿势，而是十二条由身形、呼吸、意念共同打开的气脉通路；前十桩以动练形调气，后两桩以静收束归根。学习顺序是先立身形、再合呼吸、最后随顺气脉，宁可少练一式，不可跳级求"气感"。

### 8_1 源流与基本定位

峨眉十二桩，又称"峨眉十二庄"，相传为南宋峨眉山金顶临济宗白云禅师创编。它依托峨眉派武术，观察天地、鸟兽与人体活动之象，参采佛家禅修与道家导引，并结合医学阴阳五行观念，故被称为融道、释、医、武于一体的体系。古汉语中"庄"通"桩"，本义为四通八达的道路，因此十二桩即十二条通达气脉的道路。

每一桩都是完整短拳式练功法：有起式、固定动作序列、呼吸配合与收式。若只模仿外形，仍属普通肢体活动；身形、呼吸、心神三层同步，才接近原典所说的"庄"。它与峨眉六大专修静功合称"峨眉临济气功"：十二桩以动开路，六大专修静功以静归元，二者不可偏废。

**传承脉络（表）**：

| 时间 | 事件 |
| --- | --- |
| 南宋 | 白云禅师创编十二桩（相传） |
| 清·康熙元年 | 姜一怀得真传，落户南充（出山门） |
| 1959 | 周潜川《峨眉十二桩释密》首次公开 |
| 1982—1988 | 傅伟中《峨眉十二桩述真》系统阐述 |
| 2008 | 峨眉武术列入国家级非遗 |

传承史说明功法由秘传走向公开，不等于任意流传版本都等同历史原貌。练习时应尊重原典口诀，同时以身体安全与可重复性为最终标准；版本不同时，写明所从教材，不强行拼接。

#### 8_1_1 十二桩不是"站得更久"

十二桩多数式子兼有步型转换、手臂圆弧、掌指变化与屈伸拧转。把每桩改成静止站法，虽能练耐力，却会丢失升降、开合与通行的训练目的。

| 层次 | 内容 |
| --- | --- |
| 第一层 | 神与桩合：动作路线清楚、身形不散 |
| 第二层 | 神与气合：呼吸跟上，升开吸、降合呼 |
| 第三层 | 神与脉合：气脉自运，意念退为旁观 |

一般练习者能稳定完成第一层，再进入第二层前二至三层已属良好。第三层不是靠想象"冲关"，而是火候积累后的顺势上进。周潜川强调不可超越次第：身架未稳，呼吸必被动作拖拽；呼吸未熟，强求气脉只会加重紧张。

### 8_2 十二桩名称与排列逻辑

总纲口诀为"天地之心，龙鹤风云，大小幽明"。前十桩为站功、动功，后两桩为坐卧功，形成"前实后虚、前动后静"的整体结构。

| 序号 | 桩名 | 主要气机 | 侧重 |
| --- | --- | --- | --- |
| 1 | 天字桩 | 升 | 益气升阳，母桩 |
| 2 | 地字桩 | 降 | 益阴潜阳，母桩 |
| 3 | 之字桩 | 升降开合 | 强腰固肾，舒带脉 |
| 4 | 心字桩 | 升降开合 | 调心宁神，最难 |
| 5 | 大字桩 | 开 | 精神内守，以大化小 |
| 6 | 小字桩 | 合 | 收敛心神，以小制大 |
| 7 | 拿云桩 | 开 | 开阔舒展，行气为主 |
| 8 | 鹤翔桩 | 动静兼备 | 轻灵飘逸，平衡协调 |
| 9 | 游龙桩 | 动 | 灵动多变，身法拧转 |
| 10 | 旋风桩 | 动 | 迅猛灵活，攻防兼备 |
| 11 | 幽字桩 | 静 | 卧功，空灵内敛 |
| 12 | 明字桩 | 静 | 坐功，明心见性 |

**两两配伍（配对结构）**：

| 配对 | 关系 | 训练方向 |
| --- | --- | --- |
| 天 ↔ 地 | 升降 | 天地二桩为母桩，其余十桩皆其变化 |
| 大 ↔ 小 | 开合 | 大开与小合 |
| 风 ↔ 云 | 通行 | 行气与开阔 |
| 龙 ↔ 鹤 | 动静 | 灵动与飘逸 |
| 之 ↔ 心 | 腰腿心神 | 强腰与宁神 |
| 幽 ↔ 明 | 归宿 | 由动入静，由身归心 |

两两配伍的意义，是让身体先学会一对相反方向：天与地练升降，大与小练开合，风与云练通行，龙与鹤练动静，之与心练腰腿心神，幽与明由动入静。天地二桩为母桩，包含蛇形蛹动、三通臂、三吐纳、脚下八法等基本功；其余桩式可视为升降开合的专项展开。

#### 8_2_1 初学顺序

初学必须先练天地桩，至少形成升降、呼吸、收束的稳定循环，再进入其余十桩。建议如下：

| 顺序 | 内容 |
| --- | --- |
| 1 | 天地桩合练：升降、身形、自然呼吸 |
| 2 | 之字桩 + 小字桩：腰腿稳定、精细控制 |
| 3 | 大字桩 + 鹤翔桩：精神内守、单腿平衡 |
| 4 | 心字桩 + 游龙桩：心神集中、身法拧转 |
| 5 | 拿云桩 + 旋风桩：开阔行气、变化协调 |
| 6 | 幽字桩 / 明字桩：以静收束（不作强求） |

### 8_3 核心原理：三乘九步与四个关键概念

峨眉十二桩的进阶不是靠"气感"推动，而是由身形、呼吸、意念三层次第约束。下面先给出三乘九步的总框架，再依次界定文势与武势、大小练形、吐纳诀和"舍气从脉"四个概念。

#### 8_3_1 三乘九步

三乘即神与桩合、神与气合、神与脉合；九步是每一乘内的渐进火候。教材不必把每一层名称机械固化，但必须守住递进逻辑：形不正，气不顺；气不顺，脉难安。

#### 8_3_2 文势与武势

文势以祛病强身为目的，适合普通养生人群、体弱者与初学者，强调放松、呼吸与稳定性。武势兼具防身御敌与传统诊治定位，适合体质健壮、已有站桩与步型基础者。判断标准应看当前能力与恢复状态，不看志向高低。

#### 8_3_3 大练形与小练形

大练形是按完整式子或整套练习，使气血无处不到，如"全面大扫除"；小练形针对某一脏腑、部位或病所反复操作，如"精准手术刀"。二者是整体与局部的统一，不能以小练形替代身形基础，也不能只练全套而忽略局部问题。

#### 8_3_4 吐纳四字诀的定位

峨眉四字诀为嘶、嘿、嘘、唏，对应升、降、开、合。升降是基础，天字桩练升降，大字桩练开合。完整口型、操作与次数表见板块3，本处不重复。

**必须区分峨眉四字诀与六字诀。** 峨眉"嘘"是开气，"唏"是合气；六字诀"嘘"主疏肝，口型、次数与适用范围不同。初学只练熟一套，不宜并行混用。

#### 8_3_5 "舍气从脉"

气脉自然发动后，放弃主观强导，让气按自身规律运行。它不是放弃觉察，而是从"驾驶员"转为"旁观者"。标准是似守非守：过松则散乱，过紧则压迫身体。出现局部刺痛、胀热不退或头晕，应退回自然呼吸、散步放松；偏差处理见板块10。

### 8_4 身体操作总纲：三挺三扣三圆

这一总纲适用于全部十二桩，可作为开始前的扫描项、动作中的微调项与结束后的复盘项。

| 类别 | 内容 | 操作判断 |
| --- | --- | --- |
| 三挺 | 挺颈头悬 | 头顶似有绳轻提，下颌微收，不硬拔 |
| 三挺 | 挺腰脊竖 | 脊柱自然伸展，腰不塌、背不驼 |
| 三挺 | 挺膝有力而不僵 | 膝关节稳定，不锁死、不较劲 |
| 三扣 | 扣肩含胸 | 肩前下微合，胸不挺、不压呼吸 |
| 三扣 | 扣齿 | 上下齿轻合，口部放松 |
| 三扣 | 扣脚 | 五趾如轻抓地，足底均匀受力 |
| 三圆 | 虎口圆 | 虎口张开，掌心含空 |
| 三圆 | 腋下圆 | 腋窝如虚挟球，不夹紧 |
| 三圆 | 裆下圆 | 两腿内侧有圆弧感，不强行夹裆 |

**身体总纲（简图）**：

```plain
头悬（挺颈）
   │
肩扣 ─┼─ 腋下圆
   │
脊竖（挺腰）─ 掌心空
   │
膝不锁
   │
脚扣地 ─ 裆下圆

```

总纲不是"更用力"，而是建立均匀张力。自检口诀：

```plain
头顶悬，脊骨竖，膝不锁；
肩微扣，齿轻合，脚趾抓；
虎口圆，腋不夹，裆不塌。

```

### 8_5 逐桩精解与实操要点

#### 8_5_1 天字桩

核心口诀："象天则地，圆空法生，大小开合，唯妙于心。如如不动，是真阴阳；宝斯不动，发用乃常。"

白话解析：效法天地规律，动作走圆弧、留虚空；圆中生法，空中容变。表面不动的内在，才是真阴阳交泰。不是用意压迫气脉，而是意到、神到后，气脉随开合升降自然发动。

| 步骤 | 动作 | 呼吸意念 |
| --- | --- | --- |
| 1 | 立正转平肩裆，脚尖微内扣 | 自然呼吸，全身放松 |
| 2 | 两掌如抱球前起至肩平，大指齐眉 | 吸气（嘶），气纳膻中 |
| 3 | 两臂向左右弧形展开成一字 | 继续吸气，肩胛自然展开 |
| 4 | 纳气填胸，会阴轻收 | 嘶纳不急 |
| 5 | 鹰爪→虎爪→通臂→翻肘 | 神存五指，随指吐气 |
| 6 | 弯腰、屈膝、落掌同步 | 呼气（嘿），气沉丹田 |
| 7 | 双手合十如童子拜佛，缓缓上升复原 | 吸气（嘶），升气归位 |

**天字桩气机（升降示意）**：

```plain
合十上升 ── 气由下而上 ── 任督二脉上升为主
挥圆展开 ── 开气 ── 纳气填胸
下腰落掌 ── 降气 ── 气沉丹田
童子拜佛复原（一升一降为一循环）

```

**"全身不可着力量"是首要原则。** 臂肘挥圆不靠肩臂硬撑，而由肩、肘、腕、指贯通带动；注意力主要留在五指与圆弧，即"臂肘挥圆不着力，神存五指起小娘"。体感上应是肩颈松开、胸廓展开、手掌轻微胀热，而非手臂僵硬。

**常见错误**：

| 错误 | 正确 |
| --- | --- |
| 手臂用力撑开 | 松肩沉肘，气领手走 |
| 憋气硬撑 | 呼吸自然，不急不慌 |
| 弯腰弓背 | 脊竖如塔，腰松不塌 |

自检口诀："手走圆弧如抱球，肩不耸来肘不僵；吸气升开气归胸，呼气落下送丹田。"

#### 8_5_2 地字桩

地字桩是天字桩的镜像反转。口诀："地字庄与此相反，不同起手左右张。开平一字合中脉，下降童子拜佛庄。升降开合同一理，阴阳反正细推详。"

天字桩开平、上升，以童子拜佛起；地字桩合中脉、下降，以童子拜佛落。二者合练称"天地合诀"，一升一降完成水火既济。每日晨起各练3—5遍，遍数依呼吸不乱为准。

```plain
天桩：开平 → 上升 → 童子拜佛起
            ↕ 升降开合同理
地桩：合中脉 → 下降 → 童子拜佛落

```

体感上应是头顶轻提、足底踏实、呼气顺畅，而非靠塌腰制造"下沉"。若下降时憋气或膝痛，应减小幅度、恢复自然呼吸。

#### 8_5_3 之字桩

口诀："左腿屈前，右腿后直，弓箭裆诀，地盘之义。左阳右阴，脉路紧记。伸腰嘶纳，下腰壮气。左手拿云，绕眉钩地。右掌翻圆，阳偎腰际。"

| 要素 | 内容 |
| --- | --- |
| 步型 | 弓箭裆，前腿屈、后腿直，左右可换 |
| 手型 | 一手拿云，弧形上举过眉；一手钩地，按于腰际 |
| 呼吸 | 伸腰吸气（嘶），下腰呼气（嘿） |
| 主脉 | 肾俞、命门 |
| 侧重 | 舒带脉横络，强腰固肾 |

**"三尖相对"是鼻尖、前膝尖、前脚尖一线，保证结构不散。** "三角连续，义取三才"指动作走三角路径，而非直线来回。体感上，腰侧从腋下到胯骨应有连续牵拉带，命门附近可有温热充实感。现代类比中，它训练核心稳定、髋膝踝对位与腰椎旋转，但不可降格为单纯核心训练，呼吸与开合仍是核心。

传统解说视之为攻防结合的核心桩式，主攻中路、断肘折腕。今日练习只需理解手步协同与拧转结构，不脱离条件作对抗。

**常见错误**：

| 错误 | 正确 |
| --- | --- |
| 膝超脚尖、内扣 | 膝与脚尖方向一致，重心居中 |
| 只动手臂不转腰 | 以腰带肩，手随腰走 |
| 三尖错位、身体前栽 | 鼻尖—膝尖—脚尖一线 |

自检口诀："前弓后直地盘义，拿云钩地两路分；伸腰一嘶下腰嘿，三尖相对腰眼温。"

#### 8_5_4 心字桩

心字桩为十二桩最难者。口诀："**底本实有的六诀**（《峨眉十二桩》）：

| # | 诀文 |
| --- | --- |
| 一 | 象天则地，圆空法生，大小开合。唯妙于心。 |
| 二 | 如如不动，是真阴阳，宝斯不动，发用乃常。 |
| 三 | 唯气与脉，不动动生，意动神到，开合升降。 |
| 四 | 开合一如，结丹在兹。静如秋月，动若飙风，彬彬克敌，分寸之中。 |
| 五 | 轻若鸿毛，重逾泰山，用中无形，体用一焉。 |
| 六 | 人唯脉与气，双修弗可缺。不修亦在动，随运天地中。修使若燃灯，常和住春风。 |

> **原文校准**：本库此前所引"十二庄中，庄内藏诀，万法由心，变化斯之"一段，
> **底本《峨眉十二桩》无此文**。现据底本改为实有的六诀全文。"

难点有三：心念难集中；地盘功夫深，需单腿下蹲至臀近脚跟；升降开合节奏复杂，含"连环太极圈"。因此必须分阶段。

**阶段一：连环太极圈。** 半阴阳掌起，阴掌先划大圆，由胸前螺旋向下；阳掌再划小圆，逐渐收向腰眼。先大后小，一环连一环；至腰眼变握拳贴腰，含肩缩项。体感是路线连续、肩不抬起、腰眼有收敛感。

**阶段二：曲腿下腰。** 重心脚落实，另一脚虚伸；腰与大腿缓缓下屈，气沉丹田。初学者可扶墙单腿蹲、使用高凳或减少蹲幅，绝不直接硬压。

**心字桩进阶**：

```plain
阶段一：连环太极圈 → 路线清楚、呼吸自然
阶段二：曲腿下腰   → 腿能负重、膝无痛
阶段三：地盘稳定   → 左右交替、开合跟随
        （只按能力渐进，不追求一次到位）

```

**常见错误**：

| 错误 | 正确 |
| --- | --- |
| 一上来深蹲到底 | 扶墙辅助，减小幅度 |
| 低头憋气强求静 | 路线优先，呼吸自然 |
| 只记口诀不做圈 | 先练连环太极圈 |

自检口诀："大圈接小圈，圈圈连腰眼；心念跟着手，身形莫慌乱。"

#### 8_5_5 大字桩与小字桩

大字桩练"开"，但不是把手脚张到最大，而是身形舒展后精神内守。口诀"以大化小"是以开阔状态收摄散乱心神。练习时双臂与胸廓自然展开，脊柱中正，目光回收，体会外部虽广、内心有归处。可理解为天字桩的"静化版"：天桩练动中升降，大字桩练静中守一。

小字桩练"合"，核心是精细控制。口诀："小字与大字，诀里俱藏庄。反正相辅用，参修莫相忘。天地十二式，苦练重小字。"

**"小"的三层含义**：

| 层次 | 含义 |
| --- | --- |
| 小动作 | 指关节、掌指一节节运动 |
| 小练形 | 针对具体部位反复调练 |
| 以小制大 | 以精细变化化解粗蛮用力 |

实操中，从小指开始依次屈伸，再带动其余手指；翻转手掌、鹰虎爪变化时，先求关节分明，再求连贯。体感是手指与前臂有轻微麻热、牵拉或"一节带一节"的流动，而非握拳紧绷。大字桩与小字桩合练，先以大补小，再以小摄大。

**常见错误**：

| 错误 | 正确 |
| --- | --- |
| 大字桩用力外撑 | 舒展而有回收之意 |
| 小字桩握拳一把抓 | 指节依次屈伸，如蚕爬行 |
| 只练大架子 | 每天单独练蛹动、描太极 |

#### 8_5_6 拿云桩

拿云桩主"开"，桩势开阔，行气为主。动作方向上，"虎口托天"如双手托物上举，"袖底钩地"如掌翻转后向下钩引；两掌沿圆弧运行，重点在开胸、扩背、肩胛不耸。

体感目标：胸廓两侧与后背自然展开，脊柱纵向延伸，手掌可有胀热或轻浮感。肩颈僵硬者先做小幅挥圆；胸椎活动不足者不后仰代偿；手腕不适时减小翻掌幅度。

原典载有"大开拿阴肘、掉身背挤敌"等攻防含义，但具体掌形、步型与转换路线版本有异。拿不准时写明"以所在传承教材为准"，不硬编细节。安全提示始终是：动作扩大不能牺牲呼吸与关节安全。

#### 8_5_7 鹤翔桩

鹤翔桩动静兼备，取鹤之轻灵、飘逸，强调平衡协调。后世传承口诀说"鹤性不争，喻诸凤德；法寓化解，攻守两得"，落实到练习是不主动蛮抗，先求独立稳定、虚实分明。（此类桩诀出自后世传承教材，各本字句互有出入，以所在传承为准。）

基本结构可由天字桩起，转虚步；两手挥圆，神存指尖；再进入单腿独立与鹰虎爪变化；最后以弓步旋转化合掌回环。单腿支撑是检验髋部稳定、足底抓地与躯干控制的手段，不是目的。

体感目标：支撑腿有扎根感但不锁膝，悬空腿放松不抽搐，转身换势时呼吸仍平稳。初学者每侧10秒，逐渐至30秒以上。

```plain
鹤翔桩安全递进
扶椅背平衡 → 单腿10秒 → 单腿30秒 → 加入手部变化
（任何阶段头晕、膝痛即退回上一级）

```

#### 8_5_8 游龙桩

游龙桩主"动"，练身法拧转。后世传承口诀："首起天字，继变鹤翔。形似丁字，气壮丹田。阴阳互用，启闭两施。俯仰反正，用诀在斯。"

动作由天字桩起，转入鹤翔步或虚步；前俯、环抱、平脊、仰势，并左右弓箭转换。"形似丁字"即前脚内扣、后腿伸直，形成稳定支撑。俯仰反正指前俯后仰、左右转动，使脊柱多方向连续活动。

体感目标：脊柱有逐节延伸、回旋感，而非单纯弯腰；腰胯如轴，手步随之；转身时足底仍踏实。腰椎不适者减小俯身幅度，头晕者不做快速起伏。

#### 8_5_9 旋风桩

旋风桩主"动"，传统定位为迅猛灵活、攻防兼备，有"旋风拿云、擒拿化封闭"等含义。它是十二桩中变化较强者，必须先完成天地桩与步型基础，否则最易伤膝、扭腰、憋气。

建议分三阶段：

| 阶段 | 内容 |
| --- | --- |
| A | 原地转身步法，不配手部 |
| B | 加入慢速掌法，做到手到脚到 |
| C | 稳定、无痛前提下逐渐加快 |

体感目标：转身以腰胯为轴，头与躯干不脱节；支撑脚如桩扎地，重心转换清楚；丹田稳定，不靠胸部急促起伏。转后需要停下喘气、膝有刺痛或脚踝发软，说明速度超过控制能力。

#### 8_5_10 幽字桩与明字桩

幽字桩是唯一以仰卧为主的桩式，是从动入静的桥梁，适合体力较弱者与睡前收束。仰卧后双脚自然分开、脚尖朝外，双手置体侧、掌心朝上、手指微曲；呼吸缓慢自然，呼气时可轻微提会阴，但应若有若无，不可用力。

体感目标：身体由外动逐渐安静，腹背四肢均匀放松，杂念减少；不应追求强烈光热或漂浮体验。每次可从5—10分钟起步。静坐次第、呼吸深度与偏差处理见板块10。

明字桩为坐功，跏趺坐、单盘或散盘均可，关键是脊柱竖直、下颌微收、不压迫腿部。传统定位为"明心见性"：身形与气息稳定后，由动归静、由调身进入调心。先调息、再调心，最后只是清楚安住，不把特殊体验当成必须结果。

| 桩 | 形式 | 功能 |
| --- | --- | --- |
| 幽字桩 | 仰卧、宽坦、从动入静 | 桥梁 |
| 明字桩 | 正坐、中正、由身归心 | 归宿 |

```plain

        ↓

        ↓
```

选桩不是越多越好。以周为单位，保留天地桩为每日必修，再选1—2个重点桩式打磨。完整十二桩可在数月或更长的周期内逐步覆盖；一天练全往往只得到疲劳，得不到体感。

### 8_7 案例故事：姜一怀得传与出山门

**案例小故事：姜一怀得传与出山门（原典记载类）**

**背景：** 传承资料记载，清康熙元年，武举姜一怀获得峨眉十二桩真传后落户南充。此前，十二桩主要流传于较封闭的传承圈，完整口诀、身形、呼吸与收式并不容易为外界所得。

**困境：** 有志练习者面对的难题不是"多学几个姿势"，而是功法长期隐传后，实战、养生与口诀之间缺少可通行的教学路径；若只凭片段描述模仿，很容易只剩外形，失去升降开合的次第。

**转折：** 功法随姜一怀出山门，进入更广阔的地域与家族延续。传承的扩展并不自动保证理解正确，却使后人有条件对照完整教法，逐步分辨身形、呼吸与意念的先后关系。

**落地启示：** 今天学习天地桩，应先把升降路线、呼吸节律和收束次序做清楚，再追求所谓"得秘传"的神秘感。练习中应检查三挺三扣三圆，确认挥圆时肩颈松开、呼气自然下落；若只记口诀而不核对身形，传承名称再响也无助于稳定体感。

### 8_8 案例故事：周潜川公开与次第不可越

**案例小故事：周潜川首次公开与初学者的呼吸边界（示例情景，非原典记载）**

**背景：** 1959年，周潜川著《峨眉十二桩释密》，首次将长期秘传的十二桩公之于众。原典口诀简练，"嘶、嘿、嘘、唏"与"舍气从脉"等内容又把身形、呼吸、意念交织在一起，初学者往往难以确定从何入手。

**困境：** 一位现代练习者读至"气脉自运"后，便在天地桩中刻意想象热流运行。他的呼吸很快被动作拖拽，出现屏息、头胀与收功后烦躁；身体信号表明注意力已过度集中在"气感"，身架反而松散。

**转折：** 他没有继续增加观想，而是回到公开文本强调的次第：先稳定平肩裆与升降路线，再让呼吸自然跟随开合；只有在身形不散、呼吸不乱后，才把意念降为旁观。练习改为每天天地桩各三遍，每遍只检查路线、肩颈与呼气。

**落地启示：** 今天读到"吐纳四字诀"或"舍气从脉"，不应立刻追求强烈气感。天地桩中应有手走圆弧、肩颈松开、呼气时小腹自然回落；若局部刺痛、胀热不退、头晕或情绪紧张，应退回自然呼吸与放松站桩。公开文本的价值在于可学习，更在于它保留了"不可超越次第"的安全边界。

### 8_9 本板块的笔记方法

笔记要建立"动作—体感—剂量—反应"的反馈链。每次记录日期状态、练了什么、身体发生什么、下次如何调整；不写空泛的"感觉很好"，而要具体描述部位、性质、持续时间与动作条件。

```plain
【日期】______ 【时段】晨起 / 午后 / 睡前
【状态】睡眠：好 一般 差；疲劳：低 中 高；情绪：______
【基础】平肩裆站桩 ____ 分；三挺三扣三圆：是 / 否

【主练】
1. ______ 桩  遍数/时间 ______  动作难点：______
   呼吸：自然 / 嘶嘿 / 嘘唏（未稳定写"自然"）
2. ______ 桩  遍数/时间 ______  动作难点：______

【体感】
性质：温热 / 胀 / 麻 / 轻松 / 沉重 / 无特别变化
部位：头 / 颈肩 / 胸 / 腰 / 腿 / 手 / 足底
描述：______（例：腰侧横向牵拉，呼气后松开）

【结束】精神：清爽 / 一般 / 疲劳；头晕、心悸、关节痛：______
【偏差】有 → 停止、自然呼吸、散步；无 → 写"无"
【调整】降低幅度 / 减慢 / 减量 / 换桩 / 维持：______

```

每月检查三类趋势：同样式子能否用更少用力完成；呼吸能否自然跟随开合；练习后恢复是否改善。若只有数量增加、质量不变，应回到天地桩与身体总纲，不继续堆积桩式。

### 8_10 本板块的验证方法

验证要客观、可操作，不以主观"气感"为唯一标准。以下为日常、阶段、进阶三级测试；未达标是回退信号，不是失败。

**日常自检（每次）**：

| 序号 | 内容 |
| --- | --- |
| 1 | 站定30秒内找出至少2处三挺三扣三圆偏差并修正 |
| 2 | 一次动作做到"开吸合呼、上吸下呼"，中途不憋气 |
| 3 | 结束后头不胀、胸不闷、膝无痛；2分钟后呼吸趋于平稳 |

**阶段测试（每4—8周）**：

| 序号 | 内容 |
| --- | --- |
| 4 | 平肩裆自然呼吸站桩8分钟，肩颈不持续紧张 |
| 5 | 天字桩连续5遍，路线与呼吸不乱 |
| 6 | 之字桩左右各5次，三尖相对，无膝痛 |
| 7 | 小字桩蛹动或描太极30秒，指节依次清楚 |

**进阶测试（基础稳定后）**：

| 序号 | 内容 |
| --- | --- |
| 8 | 鹤翔桩单腿独立每侧30秒，躯干不大幅摇晃 |
| 9 | 心字桩阶段一左右各3次，路线连续、呼吸自然 |
| 10 | 游龙桩完成3个缓慢转换，脊柱有伸展旋转、无头晕 |
| 11 | 旋风桩原地转身5次，脚不拖地、膝不内扣 |

达标线只是教学参考。年龄、伤病或体能不足者应按安全范围调整。若出现胸痛、明显心悸、持续头晕、视物异常、关节刺痛、恐惧感或练习后长时间失眠，应停止并按板块10处理。峨眉十二桩的可靠验证，是长期站坐行止中能否保持中正、放松、清醒。

呼吸吐纳的细化见板块3，坐卧静功的次第与偏差处理见板块10，动作与组合的通用纠错见板块11，训练剂量与周期安排见板块19。把十二桩当作长期身体教育，而非短期"得气"技术，才是这一体系最稳健的用法。

### 8_11 本板块收束

峨眉十二桩的核心不是十二个静态姿势，而是十二条由身形、呼吸、意念共同打开的气脉通路。天地二桩为母桩，确立升降与呼吸的基本循环；之、心二桩练腰腿与心神，大、小二桩练开合与精细控制，拿云、鹤翔、游龙、旋风四桩各有所主，幽、明二桩以静归元。前十桩以动练形调气，后两桩以静收束归根，形成"前实后虚、前动后静"的完整结构。

今天练习时，应以三乘九步为递进框架：先求"神与桩合"——动作路线清楚、身形不散；再求"神与气合"——呼吸自然跟上、升开吸降合呼；最后才谈"神与脉合"——气脉自运、意念退为旁观。三挺三扣三圆是贯穿全部桩式的身体总纲，每次练习前后都应扫描一遍。天地桩是最优先的基本功，至少形成稳定的升降、呼吸、收束循环后，才进入其余桩式；心字桩最难，必须分阶段从连环太极圈起步，绝不一次深蹲到底。

"舍气从脉"是高级阶段的操作原则：气脉自然发动后放弃主观强导，从"驾驶员"转为"旁观者"。但出现局部刺痛、胀热不退或头晕时，应立即退回自然呼吸与放松站桩。吐纳四字诀（嘶、嘿、嘘、唏）的完整操作见板块3，峨眉"嘘""唏"与六字诀不可混用。选桩以周为单位，保留天地桩为每日必修，再选1—2个重点桩式打磨；一天练全十二桩往往只得到疲劳，得不到体感。

呼吸与气法的基础定义和安全边界见板块3，坐卧静功的次第与偏差处理见板块10，动作组合的通用纠错见板块11，训练剂量与周期安排见板块19。峨眉十二桩最稳健的用法，是把每一桩都当作可验证的身体教育：身形中正、呼吸不乱、体感明确、收束完整，四项同时达标才是合格的桩功练习。若只追求所谓"得气"而忽视外形与呼吸，再响亮的传承名称也无法支撑长期进步。
