## 板块3 · 立式导引动功（一）：八段锦 · 五禽戏

本板块把两套最易入门、也最常每日坚持的立式导引动功——八段锦与五禽戏——放在一起。两者都靠“对拉拔长”建立张力，但八段锦是八式递进的“全身调理处方”，五禽戏是仿生五戏的“舒展筋骨”。先八段锦、后五禽戏，或二选一为主、另一套为辅均可；通用身法与呼吸以板块2为准。

本板块进入内养路线的主干，先讲**八段锦**——它是四套古典立式导引功法里结构最清晰、最容易每日坚持的一套。整套动作柔和缓慢、圆活连贯，核心不在“摆造型”，而在**对拉拔长**的张力感。读完后，应能看懂每一式在练什么、练对了身上该有什么感觉，并把它开成一张可执行的处方。

通用身法与呼吸原则以基础板块为准；本板块只处理八段锦特有的路线、幅度、节奏与处方搭配。三尖照、十二节、筋膜九态、二争力等通用原理，见板块1；呼吸模式、配合表与安全边界，见板块2。


### 功法一 · 八段锦

### 3_1 源流与版本流变：口诀定型，动作标准化

**八段锦的传承，是“口诀先定、动作后规范”的过程。** 理解这一点，就不会被各种“古传版本”带偏。

“锦”是珍贵华美之意。八段锦由八段各自独立、又前后连贯的导引术组成，动作舒展、柔和缓慢、圆活连贯，强调**抻筋拔骨 + 松紧结合 + 呼吸配合**。

它**不是舞蹈，不是广播操，也不是拉伸操**。舞蹈求好看，拉伸操求幅度，而八段锦求的是**对拉拔长**的张力感——每一个定势都是一个持续存在的“二争力”：一上一下、一左一右、一前一后，两端同时用力，脊柱居于正中。

**案例小故事：通行口诀定型于清光绪初年（原典文献记载）**

**背景：**八段锦口诀至清光绪初年，由无名氏编成今日通行之八句，全文如下：

> 两手托天理三焦，左右开弓似射雕。

调理脾胃须单举，五劳七伤往后瞧。
摇头摆尾去心火，两手攀足固肾腰。
攒拳怒目增气力，背后七颠百病消。

**困境：**口诀在传承中曾出现异文。南宋记载为“左肝右肺如射雕”“东肝单托西通肾”，体现的是中医“肝左升、肺右降”的脏腑思想；若直接把后世版本倒推为唯一古本，容易忽略源流变化。

**转折：**后世动作规范以通行口诀为纲，逐步把动作、呼吸与意念统一；学术研究再回头辨析南宋异文与清代定本的关系。

**落地启示：**今天练习以国家体育总局推广版为动作规范。练前可先默念本式口诀，把“托天理三焦”的具体路线在脑中过一遍；练时检查外形三点是否在线、对拉线是否持续、呼吸是否顺畅。口诀是索引，不是念字口诀替代动作训练。

口诀在传承中曾出现异文。**南宋**记载为“左肝右肺如射雕”“东肝单托西通肾”，体现的是中医“肝左升、肺右降”的脏腑思想——把五脏方位直接写进口诀。

```plain
版本流变示意
─────────────────────────────────────────────────────
  南宋异文         →  左肝右肺如射雕 / 东肝单托西通肾
                     （五脏方位入口诀）
                        │
  清光绪初年无名氏   →  今日通行八句口诀定型
                        │
  国家体育总局推广版 →  动作·呼吸·意念三者统一规范
                        │
  《八段锦》团体标准  →  以推广版为蓝本，统一技术标准
─────────────────────────────────────────────────────
       口诀有异文，但功法内核一致

```

**本板块的动作规范以国家体育总局推广版为准**，它把动作、呼吸、意念做了统一规范，也是《八段锦》团体标准（以推广版为蓝本）所采用的版本。练现代版不必纠结“哪句是古本”，按推广版结构练即可；想做学术考证时，再回头辨析异文。

### 3_2 设计逻辑：八式是一张“从调气到固本”的处方单

**八段锦不是八个动作的随机排列，而是一条递进链。** 这也是它最容易被忽略、却最重要的一部分。

```plain
递进链：从“调气机”到“固根本”
──────────────────────────────────────────────────────
  第1式        第2式        第3式        第4·5式
  三焦(气)  →  肺肝(开合) →  脾胃(中焦) →  心肾(水火)
      │
  第6式        第7式        第8式
  肾腰(藏)  →  肝(疏泄)  →  全身(整合)
──────────────────────────────────────────────────────
  先理气机 → 再调开合 → 安脾胃 → 交心肾 →
  固肾腰  → 疏肝气   → 整合全身

```

这条链的意义：**三焦（气）→ 肺肝（开合）→ 脾胃（中焦）→ 心肾（水火）→ 肾腰（藏）→ 肝（疏泄）→ 全身（整合）**。它是从“调气机”入手，经肺肝、脾胃、心肾，终于固肾与全身整合——一套有逻辑递进的“全身调理处方”，**不建议随意调换顺序**。

| 目标 | 优先组合 | 对应机理 |
| --- | --- | --- |
| 久坐颈肩腰背 | 第1 + 第4 + 第6式 | 拉伸脊柱、牵拉大椎与膀胱经 |
| 睡眠 / 焦虑 | 第5 + 第8式 + 预备桩功 | 抑制交感、增强副交感 |
| 消化不良 | 第3式（饭前练） | 升清降浊，促进胆汁分泌 |
| 疏肝理气 | 第2 + 第7式（春季） | 宣肺疏肝、疏泄肝气 |
| 固肾藏精 | 第6 + 第8式（冬季） | 固腰健肾、温养命门 |

> 以上为习练参考，不构成医疗建议；有明确疾病者请在医师指导下辨证施功。

### 3_3 四条总纲与“一句话检验”

**四条总纲比任何一招都重要，是判断“练对没”的唯一标尺。**

| 维度 | 要求 | 常见反面 |
| --- | --- | --- |
| **身**（调身） | 百会上领、含胸拔背、沉肩坠肘、松腰敛臀、腋下虚空 | 耸肩、塌腰、挺胸、八字脚 |
| **息**（调息） | 鼻吸鼻呼，深、长、细、匀，以听不到呼吸声为宜；起吸落呼、开吸合呼 | 憋气、喘粗气、动作快于呼吸 |
| **力**（松紧） | 定势时肌肉舒缓而**持续**用力，保持抻拉，其余时间放松 | 全程松懈（软塌），或全程紧绷 |
| **心**（调心） | 意注动作路线与对拉效果，不用力监控身体 | 头胀、胸闷、逐秒检查“气感” |

**初学者最重要的一条**：先练“自然呼吸”，动作顺了再过渡到腹式呼吸，**绝不为了配合呼吸而憋气**。呼吸是八段锦的“操作技术”，呼与吸之间可有短暂屏息，但以“不憋气为度”。

> **一句话检验**：做动作时，身体里有没有一条“被拉开的线”？如果没有，就只是在摆造型。

这条线在各式里的方向不同：第1式是**纵向**（掌根到脚底），第2式是**横向**（两肩胛双向撑开），第3式是**上下对拉**。找线的过程，就是把“外形”转化成“体感”的过程——**动作不到位而张力到位，仍有效；幅度到位而松懈，则无效。**

### 3_4 预备势：整套功法的地基

> **核心判断**：八段锦“起于桩、行于桩、终于桩”，每个招式也是起于桩、行于桩、终于桩。预备势做不好，后面全白搭。

预备势先解决站立、放松与呼吸三件事；更完整的身法清单见板块2，此处只保留动作路线。

#### 四步分解

1. **并步站立**：中指腹轻贴裤缝（风市穴），目视前方；
2. **开步**：重心移至右腿，左脚向左开步，与肩同宽，**脚尖朝前、两脚平行**（先落脚尖，脚跟再外撑下落，避免八字脚）；
3. **侧摆**：两臂内旋，向两侧摆起与髋同高，掌心向后，手臂与身体约成 45°；
4. **抱球**：屈膝，两臂外旋向前合抱，屈肘屈腕成抱球状，**掌心朝内、与脐同高，指尖相对间距约 10–20 厘米**。

#### 身体校准清单（逐部位自查）

| 部位组 | 校准要求 | 自检结果 |
| --- | --- | --- |
| 头／颈／面 | 后顶上领、下颌微收、颈部竖直；舌轻贴上腭、齿唇轻闭、眉宇嘴角放松 | □是 □否 |
| 肩／肘／腕 | 沉肩、坠肘、松腕、舒指；腋下虚空可塞一虚拳，拇指放平 | □是 □否 |
| 胸／腹／腰 | 胸部舒展、腹部放松、命门放松、收髋敛臀；重点治“塌腰” | □是 □否 |
| 腿／脚 | 膝盖微屈不超脚尖、重心略后；如坐高凳，重心不在膝上 | □是 □否 |

#### 站桩时间与进阶

+ 初学每次 **2–3 分钟**，一周后可增至 **15–20 分钟**，每日 1–2 次；
+ 一般站到 **3–4 分钟**会出现肩部酸痛、想放弃，此时可放下上肢休息 1–2 分钟再抱球，**不要硬扛**；
+ **松与紧是节奏，不是形容词**：定势时舒缓而持续地用力，其余时间放松；全程软塌或全程紧绷都是错的。

#### 收势三步（不可省）

叠掌于丹田（**男右手在外，女左手在外**），掌心对应气海穴，静立 30 秒–1 分钟，再搓掌浴面、活动膝关节。

> 收功随意、练完立刻走动，等于前面全功“散掉”——这是新手最普遍的损耗点。

| 步骤 | 动作 | 要点 |
| --- | --- | --- |
| 1 | 两掌从体侧上提（吸）→ 翻掌下按至丹田（呼） | 动作连贯，不憋气 |
| 2 | 叠掌于肚脐（男右手在外／女左手在外），静立 30 秒–1 分钟 | 自然呼吸，不刻意守点 |
| 3 | 搓掌浴面、活动膝关节 | 让身体由低耗状态平稳恢复 |

### 3_5 八式逐解：动作 · 机理 · 体感 · 纠错

设计逻辑讲完，下面进入逐式拆解。每一式都按“身体动作／机理对译／体感目标／易错与纠正／自检口诀”五段对译；第五式、第六式、第八式另附必要安全提示。

#### 第一式｜两手托天理三焦

**身体动作**

1. 两掌腹前交叉，掌心向上；
2. 抬至胸前（膻中高度）**翻掌向上**；
3. 两腿徐缓伸直，两掌向上托起——**抬头，目视两掌**（手眼相合）；
4. 继续上托至肘伸直，**下颌内收**，两臂贴耳，略停；
5. 十指慢慢分开，两臂向两侧下落，捧于腹前。

**机理对译**：三焦分上（胸膈以上）、中（胸膈至脐）、下（脐以下）三部，主司“疏布元气、流行水液”。上托拔伸腰背、提拉胸腹，促使气机流通、水液布散；通三焦经、心包经，激活任督二脉，扩张胸腔、加深呼吸，按摩上中下三焦脏器，对驼背、塌肩、颈椎病有预防作用。

**体感目标**：掌根到脚底有一条纵向被拉开的线；胸腔打开后呼吸自然变深。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 先抬头看手、后上举（顺序颠倒） | 手到胸高才目视手掌，手眼相合，再撅颏抬头跟着手上走 |
| 两臂向前倾斜过大 | 沿身前垂线直线上举，伸直时微向前即可 |
| 上举不充分、肘未伸直 | 抬头看手时慢慢伸直肘，头回正**继续**上托至头顶正上方 |
| 分手时猛力拉开 | 先松肩、微屈肘、坐腕撑指，拇指尖对顶助力慢慢分开 |
| 耸肩、挺肚、翘臀 | 掌根发力上撑，小腹微收，脚趾抓地 |

**自检口诀**：_翻掌托天看手走，肘直贴耳收下巴；落时一节节松开。_

**安全提示**：颈部不适者不必过度仰头，以舒适范围上托；重点保持肘直、脊柱延展和呼吸顺畅。

#### 第二式｜左右开弓似射雕

**身体动作**

1. 重心右移，左脚开步，两腿自然伸直；两掌胸前**搭腕**（左掌在外，与膻中同高，距胸约 30 厘米）；
2. 右掌屈指成**龙爪**，左臂内旋坐腕成**八字掌**；
3. 两腿屈膝成**正马步**；左掌向左推出（腕与肩平），右爪平拉至肩前，“拉弓射箭”；**目视推掌食指方向**。

**机理对译**：展肩扩胸、抒发胸气、疏理肝气；马步刺激足阳明胃经，改善颈肩僵硬、胁痛、肺活量不足。关键细节：定势瞬间下颌微收别仰头，**转头不转肩**，上半身始终中正。

**体感目标**：胸廓横向撑开，背部肩胛有向中间合拢又向外撑开的“双向”感。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 侧开步后两膝弯曲、交叉过高过近 | 开步后两膝**自然伸直**，腕部交叉、指尖与肩平 |
| 八字掌／爪手指弯曲过度 | 中指、无名指、小指**只屈一二指节，第三指节伸直**；拇指第一指节屈收 |
| 重心偏向拉弓手、成偏马步 | 正身屈膝成**正马步**，重心勿向拉弓侧移动 |
| 拉弓手打开时向前划平弧 | 以肘为轴，爪变掌先**向上**摆（指尖过头）再向侧落至肩高，划约 180° 上圆弧 |
| 端肩、弓腰、八字脚 | 沉肩坠肘、上体中正、两脚跟外撑 |

**自检口诀**：_八字掌推食指看，龙爪拉弓肘对齐；马步正中肩下沉。_

#### 第三式｜调理脾胃须单举

**身体动作**

1. 重心稍升起；左臂内旋上抬与胸同高；
2. 左掌翻转上托至头左上方（肘微屈，**中指尖与肩井穴在同一垂直线上**），力达掌根，掌心斜上；
3. **同时**右掌下按至右胯旁约 10 厘米，力达掌根，掌心朝下；
4. 沉肩下落，两掌回收腹前。

**机理对译**：脾主升清、胃主降浊。一手上举一手下按，上下对拉，**升清降浊**，直接牵拉脾胃、肝胆经，并对腹腔脏器形成按摩；拉伸脊柱、减少脊柱侧弯，饭前练习可促进胆汁分泌。

**体感目标**：上下两手的“对拉感”**持续存在不消失**，从掌根一直连到腰腹。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 上举手偏前或偏侧 | 充分展肩，**中指垂线落在肩井穴**，手贴耳边下落即正确 |
| 上举手不平、掌心朝前上 | 掌根上撑、掌心斜朝上，指尖朝对侧 |
| 掌指方向不正、肘无弯曲度 | 两掌放平、指尖摆正、肘关节稍屈 |
| 两手一快一慢、下落甩臂 | 沿原路同步返回，两手同时到位 |

**自检口诀**：_一手托天一手按，掌根用力对拉长；路线原路慢放回。_

#### 第四式｜五劳七伤往后瞧

**关键概念**：

+ **五劳**：心、肝、脾、肺、肾五脏之劳损；
+ **七伤**：喜、怒、忧、思、悲、恐、惊七情之伤。

合在一起，近似今天的“**亚健康**”——长期劳顿、未及修养而致的累积损伤。

**身体动作**

1. 两腿徐缓挺膝伸直；两肩下沉，两臂伸直，掌心朝后；
2. 两臂外旋上摆至体侧约 45°，掌心朝斜后上方；**同时头向左后方转动**，展肩扩胸，略停，**目视左斜后方**；
3. 松腰沉髋，头转正，两臂内旋，两掌按于胯旁。

**机理对译**：转头牵拉**大椎穴**，调整颈椎这条“大脑—脏腑交通要道”，刺激背部腧穴、带脉、冲脉，改善脑与颈部血液循环，增强免疫调节能力。

**体感目标**：颈椎被拉长，肩胛骨向两侧**打开**（不是夹后背）。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 上体后仰、转头又转体 | **转头不转体**，上半身稳稳朝前，固定同侧肩，眼从肩峰后视 |
| 只转头、不旋臂（无拉伸感） | 两臂向外旋开，肩胛骨**向两侧打开**（不是夹后背） |
| 转头幅度不足、速度过快 | 幅度尽量大、速度尽量慢，目光落向斜后方 |

**自检口诀**：_起身旋臂肩胛开，头转体正看后方；颈椎拉长是关键。_

#### 第五式｜摇头摆尾去心火

**核心概念**：心火 = 思虑过度、阳热内盛。“降心火须得肾水”，**心肾相交、水火既济**——上身前俯、尾闾摆动，使心火下降、肾水上升。

**身体动作（整套最难，需拆成轨迹）**

1. 右脚开步约**三脚宽**，两腿伸直；两掌上托至胸高翻掌分托至头斜上方；
2. 屈膝下蹲成**马步**；两掌扶于膝关节上方；
3. **重心右移 → 上体右倾约 45° → 俯身右转（目视右脚尖）→ 重心左移，上体俯身左旋至左斜前方（目视右脚跟）**；
4. 右髋右送，尾闾向右→前→左→后画圆转回正后方；**胸微含，头向左后转，目视上方**；
5. **下颌与尾闾同时内收**，重心下降成马步。

**机理对译**：以腰胯为轴，牵拉任督二脉，刺激大椎穴、命门穴，引心火下行、强壮肾水，缓解心烦、失眠、口疮、多梦。

**体感目标**：**尾闾像握着一支笔在画一个圆**，头部是被这个圆“带”过去的；颈部与尾闾形成一条对拉的长线。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 光甩脑袋不动胯 | **尾闾画圆带动头部**，头部顺势转动，不用主动猛甩 |
| 摇转时挺胸展腹、上体后仰 | 胸微含，上体不低于水平，尾闾与颈部**对拉拔长** |
| 颈部僵直、尾闾弧度小 | 颈椎肌肉尽量放松、伸长，下颌不有意内收或上扬 |
| 髋膝不稳 | 固定髋膝，下盘要稳，双膝不晃 |

> ⚠️ **安全提示**：此式活动较剧烈，**高血压、心脏病、脑动脉硬化者慎做**；可改为左右各旋转一圈即可，头部不必过低。

**自检口诀**：_尾闾画圆头跟随，胸含颈松髋下沉；不甩头不挺肚。_

#### 第六式｜两手攀足固肾腰

**身体动作**

1. 两掌沿**后背向下摩运**（过腰、过臀、至脚外踝）→ 至脚踝时**两膝挺直**，两小臂帮助下腰；
2. 双手经脚外侧置于脚面，**旋腕盖于脚面**；
3. **塌腰 → 翘臀 → 以臂带动上体起身**，先手臂前上送，再立身；
4. 两掌沿原路返回。

**机理对译**：前屈后伸，刺激**督脉与足太阳膀胱经**，调动肾间动气，对生殖、泌尿系统及腰背部肌肉均有调理；改善腰酸、乏力、尿频、手脚麻木。

**体感目标**：后背有一条线从颈一路被“抹”到脚踝；起身时是手臂先发力，不是腰硬扛。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 摩运时低头、屈膝 | 不低头、**膝关节伸直**；手到环跳穴之后再俯身 |
| 起身用腰硬扛、先起身再举臂 | **以臂带身**，先塌腰再翘臀，手臂前上送带动立起 |
| 摩运未到环跳就提前弯腰 | 严格按“先摩后背 → 再俯身”顺序，路线不可省 |

> ⚠️ **安全提示**：高血压患者头部勿过低，防止局部血液循环障碍；**腰椎疾患者减半幅度**。摸不到脚面可手扶小腿或膝后，保持膝直、脊柱延展即可，**严禁弓背代偿**。

**自检口诀**：_先摩后背再俯身，膝直不低头；起身手臂先送力。_

#### 第七式｜攒拳怒目增气力

**核心概念**：**肝主筋，开窍于目**。攒拳怒目即疏泄肝气、强筋壮骨，尤宜于久坐少动、气血郁滞之人。

**身体动作**

1. 开步成马步；两手握固（拇指抵无名指根）收于腰侧；
2. 小臂贴肋**缓慢前冲**，力达拳面，**眼睛睁圆目视拳**；
3. 先五指伸直 → 充分**旋腕一周** → 再屈指用力抓握收回。

**机理对译**：疏通肝、胆经，刺激手足三阴三阳腧穴与督脉，增强臂、腰、腿力与眼力。出拳配合“呵”字诀吐气可加强疏泄之力。

**体感目标**：出拳时力从脚底经腰到拳面；回收时旋腕与抓握能感到前臂整条链在拧紧。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 冲拳时上体前扑、端肩、掀肘 | 小臂贴肋前送、头向上顶、上体立直、肘微屈、力达拳面 |
| 出拳离身体太远 | 贴肋前送，腰动腿不晃，脚趾抓地 |
| 回收时旋腕不明显、抓握无力 | 先伸直五指 → 充分旋腕 → 再用力抓握 |

**自检口诀**：_贴肋出拳眼看拳，旋腕抓握收有力。_

#### 第八式｜背后七颠百病消

**身体动作**

1. **提踵**：提肛、收腹、脚趾抓地、肩下沉、百会上领，拔伸脊柱；
2. **落踵**：脚跟轻落（落到七分时，用余力去震动），让振荡从脚底传导至全身；
3. 反复 7 次为一组（3×7 数理）。

**机理对译**：脚趾为足三阴、足三阳交汇处，抓地可调节相应脏腑；全身颤动按摩五脏六腑、贯通气血、去邪扶正，恰好作为整套的收功。所谓“百步走不如抖一抖”。

**体感目标**：震动从脚跟“传”到头顶，是传导感而非撞击感；牙齿不应有咯噔的撞击感。

**易错与纠正**

| 常见错误 | 纠正 |
| --- | --- |
| 上提时端肩、重心不稳 | 两腿并拢、脚趾抓地、提肛收腹、肩向下沉、百会上顶 |
| 猛跺脚（以为越响越好） | **轻落、用余力震**，振动传导而非撞击 |

> ⚠️ **安全提示**：骨质疏松、膝关节或腰椎问题者，改为**不震的轻落**，或省略此式。

**自检口诀**：_提肛收腹顶百会，轻落七分余力震。_

#### 八式动作路线小结

**八式递进：从“线”到“全身”**

| 式 | 对拉内容 | 作用 |
| --- | --- | --- |
| 1. 托天 | 纵向对拉（掌根↔脚底） | 开 |
| 2. 开弓 | 横向对拉（左右肩胛双向） | 开 |
| 3. 单举 | 上下对拉（掌根↔掌根） | 升清降浊 |
| 4. 后瞧 | 颈椎拉长 + 肩胛打开 | 松颈 |
| 5. 摆尾 | 尾闾画圆 ↔ 头部对拉 | 水火既济 |
| 6. 攀足 | 后背一线（颈→脚踝） | 固肾 |
| 7. 攒拳 | 脚底→腰→拳面 整链传导 | 疏肝 |
| 8. 七颠 | 脚跟→头顶 振动传导 | 整合收功 |

> 每一式都有一条“被拉开的线”——找不到线，就是摆造型。

### 3_6 剂量、常见偏差与“一主一辅”搭配

**剂量：练多少算够**（中国中医科学院望京医院专家建议，可与循证研究互证）：

+ **初学者**：每日 1 次，适应后增至 2 次；
+ **有基础者**：每日不少于 2 次，单次 10–15 分钟；
+ **每周频次**：不少于 3 天；
+ 每式先 **3 遍**，熟练后 **6 遍**；整套 10–12 分钟。

**强度自检（最实用的一条）**：练时**微微出汗、可轻松交谈**；练后精神愉悦、次日体力良好 = 负荷合适。**出现明显疲劳、头晕、心悸、关节疼痛加重 = 过量，下次减 30%。**

#### 四周进阶计划

| 周次 | 重点 | 内容 | 剂量与要求 |
| --- | --- | --- | --- |
| 第1周 | 立骨架 | 预备势 + 138式 | 站桩 2 分钟起，三式各 3 遍；只求“对拉感”，不求幅度 |
| 第2周 | 补完整 | 加入 246式 | 全式过一遍，各 3 遍；6.式手摸不到脚面不必强求 |
| 第3周 | 合呼吸 | 自然呼吸 → 腹式呼吸 | “起吸落呼、开吸合呼”；定势可短暂停息，绝不憋气 |
| 第4周 | 加意念 | 意随气走 | 单式增至 6 遍，整套 10—15 分钟；固定每日时段 |

> 频率大于单次时长：每周不少于 3 天，比“周末猛练一次”有效得多。

#### 时间窗与常见偏差

+ 清晨为佳，**饭后 1–2 小时**练习；**忌空腹、忌饱食**；
+ 碎片化场景：单式可随时抽练（如久坐后做第1、4式），无需整段时间；
+ **幅度小有用，“张力（对拉）”比“幅度”更重要。**

#### “一主一辅”搭配建议

本库一贯立场是**主一套，辅一势**——选定一套为主修（建议新手从八段锦开始），再从其他功法挑 1–2 式作“加强项”：

| 主修 | 辅式（按需加练） | 适用 |
| --- | --- | --- |
| 八段锦全套 | 易筋经第2势（开肩扩胸） | 圆肩驼背、久坐肩颈僵 |
| 八段锦全套 | 五禽戏鹿戏（鹿抵+鹿奔） | 腰胯僵硬、侧屈受限 |
| 八段锦全套 | 六字诀“嘘”字 | 情志不舒、肝郁 |

#### 八段锦专属疑问速答

+ **第八式要跺多响？** 不以响声为目标；脚跟轻落，靠余力形成全身传导即可。骨质疏松或膝腰不适者可以不震。
+ **能不能只练一两式？** 可以。久坐后练第1、4、6式，餐后不适练第3式，均属合理拆用；但整套顺序不可随意替换后再声称是完整八段锦。
+ **饭前还是饭后？** 常规在饭后 1–2 小时练；第3式如需助消化，可在饭前或餐后间隔足够时间做，避免饱腹弯腰。
+ **摸不到脚面怎么办？** 手扶小腿或膝后，保持膝直、脊柱延展，**严禁弓背代偿**。
+ **呼吸配合不上？** 宁可动作慢一点迁就呼吸，**也不憋气**。呼吸模式与切换条件见板块2。

#### 必须避开的情形

+ **第五式**高血压、心脏病、脑动脉硬化者慎做，可简化或跳过；
+ **第六式**高血压患者头部勿过低；
+ **膝盖**：全程避免膝关节超过脚尖，避开膝关节 110°–150° 的爆发性动作；
+ 练后头晕、心慌**立即停止**；有慢性病请在医师指导下辨证施功。

通用练习疑问、禁忌分级与纠错流程见板块11。

**练习场景示例：最小闭环也能练出张力（示例情景，非原典记载）**

**背景：**一名伏案工作者每天只有十二分钟，无法完成全套八段锦，于是把练习压缩为预备势、第1、4、6式和收势。

**困境：**第一周他虽然完成了最小闭环，但第6式一摸不到脚面就急着弓背够脚，导致腰部紧张、呼吸变快。

**转折：**他把目标从“摸到脚面”改为“保持膝直与后背一线”，手只扶住小腿，并在呼气时让肩背再放松一点；第1、4式则分别检查纵向线与肩胛横向打开。

**落地启示：**时间不足时，优先保留完整结构、呼吸与收势，不追求最大幅度。今天每次做第1式都问“掌根到脚底是否连线”，第4式问“肩胛是否向两侧打开”，第6式问“起身是否由手臂带动”；只要三条线持续、呼吸自然，短练习也能形成有效积累。

### 3_7 本板块的笔记方法

**案例小故事：呼吸跟动作，而不是节拍器压呼吸（原典文献引申，练习情景为示例情景，非原典记载）**

**背景：**一名习练者练第三式“调理脾胃须单举”时，刻意追求“上托吸、下落呼”，把呼吸节奏当成必须完成的硬任务。

**困境：**她数着呼吸做动作，呼气末总是吸不回来，到最高点已轻微头晕，整套练完肩颈比开始时更紧。

**转折：**老师指出八段锦原典与通行教学的共同原则是“先自然呼吸，绝不因配合而憋气”。她随即停止计数，先把上托、按掌和脊柱路线练顺，再让呼吸自然延长。

**落地启示：**呼吸应服从正确、放松的动作结构，而不是反过来让动作被数字切割。今天若呼吸跟不上，就退回自然呼吸，先检查耸肩、速度和幅度；只有动作舒展、呼吸平稳后，才把“吸四、呼六”轻轻贴上。

#### 笔记方法正文：记“体感”，不记“套路”

多数人记八段锦，只记动作顺序——这是最低效的记法。真正该记的是**每一式的那条“线”找到了没有**。

**记录原则**：每次练完 3 分钟内写下，只记三栏——**线（张力）、呼吸、偏差**。宁少勿多，长期才能坚持。

### 3_8 本板块的验证方法

**动作测试（练后可自检，不依赖他人）**：

| 验证项目 | 动作与条件 | 计分 |
| --- | --- | --- |
| 验证一：纵向对拉线（第1式） | 对镜侧立，上举至顶点；耳、肩、髋、膝踝大致一条垂线，肘伸直、下颌内收、无挺肚翘臀 | 达标计1分 |
| 验证二：正马步中正（第2式） | 侧视；两膝不过脚尖、髋角≈膝角、上半身不俯，保持30秒不晃、肩下沉 | 达标计1分 |
| 验证三：颈椎拉长（第4式） | 靠墙站立，后脑勺贴墙；转头时墙不离开后脑，目视斜后方、肩胛向两侧打开 | 达标计1分 |
| 验证四：脊柱逐节（第6式） | 坐位前屈，标记手指可达位置；两周后标记下移≥2cm，且无弓背代偿 | 达标计1分 |

| 项目 | 达标线（数周后可自查） |
| --- | --- |
| 站桩稳定性 | 预备势不动，能稳定站 **3 分钟**，肩不持续酸痛 |
| 呼吸配合 | 整套**不打乱呼吸节奏**，练完不喘 |
| 动作测试总分 | 以上 4 项 **≥3 分** |
| 体感指标 | 第1式有纵向线、第2式有横向撑开、第6式后背一线连续 |
| 强度指标 | 练时微汗可交谈、练后神清气爽、次日体力良好 |

**进阶触发条件**（同时满足才进入下一阶段）：

1. 站桩 3 分钟稳定；
2. 动作测试 ≥3 分；
3. 整套可在 10–15 分钟内自然完成，无需中途停下调整呼吸。

> 若任一项未达标，不急着加遍数——先把“线”找清楚。八段锦的收益依赖“持续”，不依赖“强度”：**停练即消退**。编排计划时，把“能不能长期做”放在第一位，宁可每天 12 分钟，不要周末一次 90 分钟。

### 案例小故事：做反了的"双手托天"

一位办公室族练八段锦半年，最常做的一式是"双手托天理三焦"，因为听说它能缓解肩颈。结果肩颈越来越紧，转头都受限。

让他做一遍给人看：两手上举时肩膀跟着一起耸上去，胸廓外翻，腰也塌了——整式变成了"耸肩＋挺腰"。

改法只有三个要点：掌根向上撑而非手指用力、肩胛主动下沉、肋骨不外翻。方向一换，他第一次感到肋间被拉开，而不是肩颈被顶住。两周后转头幅度明显改善。

**落点**：八段锦的每一式，功效藏在"方向"里。方向错了，做得再多、再标准，也只是给错误部位增加负担。

### 3_9 本板块收束

八段锦的精髓不在动作，在“对拉”；顺序就是处方；松紧是节奏；呼吸是门槛；效果靠剂量而非单次强度。它区别于跑步的核心价值，不是燃脂，而是**把交感神经从高亢状态拉回“休息—消化”模式**，同时改善脊柱灵活性与关节活动度——这是久坐人群真正缺的东西。

作为辅助调理手段，它对失眠、焦虑、颈肩腰背、代谢指标有临床与循证支持，但**不能替代药物治疗与规范诊疗**。呼吸细节见板块2；坐卧静功衔接见板块6；处方化编排见板块11；通用纠错见板块11；与其他功法的组合见板块7。具体剂量、禁忌与验证以本板块为准，凡涉及闭气、努劲及慢性病者，一律按板块2的安全边界处理。

如果每日只能练一次，优先保留“预备势—第1、4、6式—收势”的最小闭环，而不是在疲劳状态下硬走完整八式。这套最小闭环能够覆盖纵向线、颈椎拉长与后背一线，也最不容易因赶进度而牺牲呼吸和身法。今天练完，至少应能回答三个问题：第一式有没有从掌根连到脚底，第四式肩胛是否向两侧打开，第六式起身是否由手臂带动；若其中一项长期缺失，下次的唯一改进点就落在那里。

一次练多少遍并不决定长期收益，**能否持续找到张力、保持自然呼吸并按时收功，才决定练习是否真正积累**；
这正是“先校准、再完整，先规律、后加量”的全部含义。记日志、做验证与进阶之间的关系，将在后续板块继续收紧：先有客观记录，才能判断是否达到进阶触发条件；
没有记录时，所谓“练熟了”往往只是动作速度变快，而不是结构、体感与呼吸同时改善。
因此每次练后只记录最想改的一件事，每周回看重复三次以上的偏差，把练习从模糊重复改造成可追踪的修正过程。

若准备将八段锦与其他功法组合，应遵循“主一套、辅一势”：选定八段锦为主修后，只从易筋经、五禽戏或六字诀中挑选一个针对性补充；同一阶段避免三套功法并行、呼吸口径彼此冲突。组合时应把难度大、注意力需求高的内容放在状态较好的前半段，把收束与呼吸练习放在后半段；若练习时间不足，宁可保留收势，也不以压缩收功来换取更多动作。

**每日练习速查卡**

```plain
[  ] 时段：____点  |  饭后间隔：≥1h  |  环境：避风、安静
[  ] 预备势站桩 2–3 分钟（脚平行 / 命门松 / 如坐高凳）
[  ] 全套 × 1–2 遍（固定顺序，不调换）
      第1步 托天理三焦    第2步 开弓似射雕    第3步 单举调脾胃
      第4步 后瞧五劳伤    第5步 摆尾去心火*   第6步 攀足固肾腰
      第7步 攒拳增气力    第8步 七颠百病消
      *高血压/心脏病者慎做，可简化
[  ] 收势：叠掌丹田 30s–1min → 搓掌浴面 → 活动膝踝
[  ] 自检：微汗可交谈 / 无头晕心悸关节痛 = 今日剂量合适

```

**本板块收束**：八段锦的最终检验不在“能不能全套划下来”，而在**每一式能不能找到线、守住线、并把线带到下一式**。预备势决定起点，八式的顺序本身就是一张从调气到固本的处方单，收势不是可省的形式而是回路的闭合。练习中若呼吸紊乱、肩颈代偿或收功被省略，即使完成八式也不算合格训练；若每次结束仍能微汗可交谈、呼吸顺畅、收功完整，这套最小闭环就能支撑长期积累。呼吸与六字诀的细化见板块2，坐功的衔接见板块6，与其他功法的组合见板块7，按目标开处方见板块11，通用问题与排错见板块11。

持续练习的目标是让八段锦从“需要刻意控制的动作序列”转为“身体会自动维持的张力与节奏”，而不是追求更复杂的姿势或更强的酸痛。
只要每次练习结束仍能保持微汗可交谈、呼吸顺畅、收功完整，这套最小闭环就足以形成长期积累。
反之，即使完成全套八式，若呼吸紊乱、肩颈代偿或收功被省略，也不能视为合格训练。由此看，八段锦的难度不在动作数量，而在**每一式能否稳定地找到线、守住线、并把线带到下一式**；
这条连续不断的对拉感，才是整套功法从第一式贯穿到第八式的真正主线。
本板块接着讲**五禽戏**——它和八段锦同属立式导引动功，但设计思路完全不同：八段锦重"对拉调脏"，五禽戏重"**仿生取意、动而不极**"。读完本板块，应能分清"学动物外形"与"练五种劲力模式"的本质差别，并把十式按原文动词逐一对译到身体感受上。

身法、呼吸、收功的通用规范已有基础板块，本板块只在十式口令、神态与动作路线确有差异处展开。


### 功法二 · 五禽戏

### 3_10 破题：不是"动物体操"

**多数人接触五禽戏的第一反应——"学动物动作"，只对了一半，而且恰恰是那不重要的半。**

把它放回诞生的语境，骨架立刻清晰：

+ **理论母本**是《庄子》的"二禽戏"——"熊经鸟伸"，古人早已用熊的攀援、鸟的伸翅来导引身体；
+ **创编逻辑**出自华佗那段著名的话（载《后汉书·方术列传·华佗传》《三国志·华佗传》）：

> "人体欲得劳动，但不当使极耳。动摇则谷气得销，血脉流通，病不得生，譬如户枢终不朽也。"

**这句话才是全篇的"文眼"。** 五禽戏的核心主张不是"多动"，而是**动而不极**——在运动与不过度之间取一个精确的平衡点。顺着这个逻辑往下推，五个设计意图就成立了：

1. **以动代静**：用肢体运动取代静态久坐，解决"谷气不销、血脉不通"；
2. **以仿生取意**：每种动物对应一种**劲力模式与精神状态**（威、舒、沉、灵、捷），不是外形像，而是"劲"和"意"像；
3. **以导引调脏**：形、神、意、气合一，由外动引动内调；
4. **以汗出为度**：练到微微出汗即止，这是华佗亲自定的**强度红线**；
5. **以单戏应急**："体有不快，起作一禽之戏"——哪不舒服就单练哪一戏，本就可拆可分。

**所以五禽戏的本质是**：一套以仿生动作为外壳、以"不过度"为强度标尺、以五脏为靶点的**中等强度有氧 + 柔韧 + 平衡复合训练**。把它当体操练，练的是外形；把它当导引练，练的是"形—神—意—气"的结构。

### 3_11 必须点破的版本问题

**我们今天练的，是经过现代人"站起来"重构过的版本。** 这一点读书时必须区分，否则要么误读原文，要么迷信"原汁原味"。

| 版本 | 动作形态 | 结构依据 |
| --- | --- | --- |
| 陶弘景《养性延命录》记载 | **四肢着地、俯身攀悬**为主 | 虎戏"四肢距地，前三掷，却二掷"；鹿戏"四肢距地，引项反顾"；熊戏"正仰，以两手抱膝下"；猿戏"攀物自悬，伸缩身体"；鸟戏"双立手，翘一足，伸两臂"——**五戏原文皆非站立式** |
| 2003 年国家体育总局《健身气功·五禽戏》 | **站立式**，十式 | 顺序依《三国志》，动作数依《养性延命录》"每戏两动" |

也就是说：读原文时**别用今天站姿去套**（原文虎戏"四肢距地"是爬行俯身），练现代版时也**别以为自己练的就是华佗原样**。现代站立版的价值在于可普及、易教学，但它确实改变了发力结构——尤其是虎戏的"扑"、熊戏的"晃"，从四肢着地改为站立后，腰背脊柱承担了更多负荷，这正是现代版更需注意腰部保护的原因。

**原文那条最容易被忽略的总纲**：

> "夫五禽戏法，**任力为之，以汗出为度**。有汗以粉涂身，消谷食，益气力，除百病。"

三层意思，逐层递进：

1. **任力为之**——量力而行，不硬撑（按自身体能取六到七成强度）；
2. **以汗出为度**——出汗就是剂量终点，到即收功；
3. **消谷食，益气力，除百病**——先助消化、再增气力、最后祛病，明确的**由表及里、由浅入深**三级效应。

> ⚠️ **关于"以粉涂身"**：这是汉代出汗后扑粉防受凉的习俗，**现代无需照搬**。真正该继承的是"汗出即止"，该舍弃的是"必须扑粉"。

**"以汗出为度"的三层次（实操转译）**：

| 层次 | 标尺 | 具体标准 |
| --- | --- | --- |
| 第一层·量的标尺 | 微汗 = 终点 | 皮肤潮润、后背微湿；未出汗→剂量不足；大汗淋漓→已过极 |
| 第二层·感的标尺 | 练后"神清气爽" | 留有余力（约六七成），是华佗"不当使极"的量化 |
| 第三层·频率的标尺 | 宁可每天20分钟 | 不要一周一次2小时；对应"户枢终不朽"：持续转动，而非一次猛转 |

反证：练到精疲力竭 = 已越过"极"的边界 = 违背文眼。

**单戏应急（原文"体有不快，起作一禽之戏"的现代用法）**：久坐后腰僵 → 单练虎戏（虎举+虎扑）；餐后腹胀 → 单练熊戏（熊运）；肩颈紧 → 单练鸟戏（鸟伸）。**哪不舒服练哪一戏，是五禽戏本有的"拆分式"用法**，不必每次都走完整十式。

### 3_12 原文精读：五戏各自的动词与身体意图

版本问题交代清楚后，才能回到原文本身。原文极简、几乎全是动词，读法就是把每个动词翻译成一个"身体意图"，而不是死抠姿势。

#### 虎戏 · 四肢距地，前三掷、却二掷，长引腰

> "虎戏者，四肢距地，前三掷，却二掷，长引腰，侧脚仰天，即返距行，前、却各七过也。"

| 关键词 | 身体意图 |
| --- | --- |
| 前三掷、却二掷 | 向前扑腾、向后蹬撑，形成**前后方向的推力** |
| 长引腰 | **充分拉伸脊柱**——这是虎戏的核心 |
| 侧脚仰天 | 侧翻仰头，开胸展背 |
| 各七过 | 每侧七次，左右均衡 |

**一句话译读**：虎戏练的是脊柱的"**伸—扑—引**"，抓的是**腰、背、髋链的爆发与伸展**。现代版"虎举 + 虎扑"正由此演化。

#### 鹿戏 · 引项反顾，左右伸脚

> "鹿戏者，四肢距地，引项反顾，左三右二，左右伸脚，伸缩亦三亦二也。"

| 关键词 | 身体意图 |
| --- | --- |
| 引项反顾 | 伸长脖子回头看——颈与腰的**旋转拧转** |
| 左右伸脚 | 单侧伸展下肢 |
| 左三右二 | 左右次数不对称，暗含"纠偏"意味 |

**一句话译读**：鹿戏练的是**颈—腰—胯的拧转与侧屈**，抓的是脊柱的**旋转自由度**。现代版"鹿抵 + 鹿奔"正是由此演化。

#### 熊戏 · 抱膝举头，左右擗地

> "熊戏者，正仰，以两手抱膝下，举头，左擗地七，右亦七；蹲地，以手左右托地。"

| 关键词 | 身体意图 |
| --- | --- |
| 正仰抱膝 | 仰卧抱膝，骨盆与腰腹归位 |
| 左擗地七，右亦七 | 左右各推地七次——**躯干侧倾 + 支撑** |
| 蹲地，以手左右托地 | 蹲姿双手撑地 |

**一句话译读**：熊戏练的是**腰腹稳定与躯干侧移**，像熊重心沉沉地左右晃。现代版"熊运 + 熊晃"保留了这个"沉"字。

#### 猿戏 · 攀物自悬，伸缩身体

> "猿戏者，攀物自悬，伸缩身体，上下一七；以脚拘物自悬，左右七；手钩却立，按头各七。"

| 关键词 | 身体意图 |
| --- | --- |
| 攀物自悬 | 悬挂、悬吊——**肩与背的纵向拉伸** |
| 伸缩身体 | 上下伸缩，脊柱逐节起伏 |
| 以脚拘物 | 脚勾物悬挂，**核心与髋的悬吊控制** |
| 手钩却立，按头 | 钩手后立、按头——**颈肩肘腕的精细控制** |

**一句话译读**：猿戏练的是**悬吊、伸缩、抓握**——全身的**灵敏与协调性**，现代版"猿提 + 猿摘"继承了"提踵、钩手、顾盼"。

#### 鸟戏 · 翘一足，伸两臂，扬眉鼓力

> "鸟戏者，双立手，翘一足，伸两臂，扬眉鼓力，各二七；坐伸脚，手挽足趾各七；缩伸二臂各七也。"

| 关键词 | 身体意图 |
| --- | --- |
| 翘一足 | 单腿独立——**平衡** |
| 伸两臂、扬眉鼓力 | 展臂、提眉发力——**开胸扩背** |
| 手挽足趾 | 手勾脚趾——**后链拉伸** |
| 缩伸二臂 | 两臂伸缩——**肩背节律** |

**一句话译读**：鸟戏练的是**单腿平衡 + 开胸展臂**，抓的是**肺的宣发与上肢节律**，现代版"鸟伸 + 鸟飞"。

#### 合起来看：五戏是一套"完整处方"

| 戏 | 原文核心动词 | 现代式 | 主练的身体能力 |
| --- | --- | --- | --- |
| 虎 | 长引腰、扑掷 | 虎举、虎扑 | 脊柱伸展、腰背力量 |
| 鹿 | 引项反顾、伸脚 | 鹿抵、鹿奔 | 拧转、侧屈、腰胯 |
| 熊 | 抱膝、擗地、托地 | 熊运、熊晃 | 腰腹稳定、躯干侧移 |
| 猿 | 自悬、伸缩、钩手 | 猿提、猿摘 | 悬吊、灵敏、精细 |
| 鸟 | 翘足、伸臂、挽趾 | 鸟伸、鸟飞 | 平衡、开胸、节律 |

**编排顺序逻辑（不要打乱）**：

| 顺序 | 戏 | 主练 | 关节层级 |
| --- | --- | --- | --- |
| 1 | 虎 | 脊柱 | 大关节 |
| 2 | 鹿 | 拧转 | 中关节 |
| 3 | 熊 | 核心 | 中轴 |
| 4 | 猿 | 四肢 | 末端 |
| 5 | 鸟 | 整合 | 平衡 |

先开僵、再活腰、后稳中、次灵巧、终平衡。打乱顺序 = 跳过"稳定性"直接练"灵敏" = 易伤。

**实操推论**：学新套路时若熊戏（稳定性）没过关就上猿戏（灵敏），脚下发飘、顾盼失焦——这是顺序被打乱的典型后果。教学上应先虎→鹿→熊打地基，再猿→鸟求精。

### 3_13 五行五脏的两套对应体系与分歧说明

**"一禽对应一脏"是最常见的框架，但存在版本分歧——很多资料含糊带过，练的人应该知道。**

#### 体系 A（最主流，国家体育总局教材、多数中医教材采用）

| 禽 | 五行 | 脏 | 核心功效 |
| --- | --- | --- | --- |
| 虎 | 木 | **肝** | 疏肝理气、强筋明目 |
| 鹿 | 水 | **肾** | 强腰补肾、壮督脉 |
| 熊 | 土 | **脾** | 健脾和胃、祛湿 |
| 猿 | 火 | **心** | 养心益智、安神 |
| 鸟 | 金 | **肺** | 宣肺宽胸、调呼吸 |

理论支撑：虎"虎视眈眈、力达指尖"应肝（肝主筋、在体合筋、其华在爪、开窍于目）；鹿"腰为肾之府、命门开合"应肾；熊"脾主肌肉、运化"应脾；猿"心主血脉神志"应心；鸟"肺主气、朝百脉"应肺。

#### 体系 B（华佗五禽戏传承部分流派）

体系 B 不按"一禽一脏"直接配属，而是依**五行相生序**（肺金→肾水→肝木→心火→脾土）推演五戏的配属关系：以相生为链条，让五戏的练习顺序与气机流转方向一致，而不是让某一戏固定对应某一脏。因推演起点不同，其配属结果与体系 A 出现差异——部分流派记为虎—肾、鹿—肝，其余三戏则依相生次序顺推，各支记载并不统一。

| 禽 | 体系B配属 |
| --- | --- |
| 虎 | 肾（部分流派） |
| 鹿 | 肝（部分流派） |
| 熊 | 脾 |
| 猿 | 心 |
| 鸟 | 肺 |

**要点**：体系 B 的价值不在"虎到底主肾还是主肝"的定论，而在于它提示了另一种编排逻辑——**按气机流转的顺序练，而不是按脏腑清单练**。

#### 两套都认同的"实操有效对应"

两套体系都能在各自理论闭环里自圆其说。对普通习练者，**不必纠结"虎到底主肝还是主肾"**——真正该抓的是两套都认同的这条共识：

| 禽 | 实操有效对应（动作—靶点） |
| --- | --- |
| 虎 | 腰背脊柱 |
| 鹿 | 腰胯肾督 |
| 熊 | 脾胃中焦 |
| 猿 | 心神与协调 |
| 鸟 | 肺与呼吸 |

**这是实操层面的"有效对应"——有现代运动科学可解释，不依赖流派。** 五行五脏是传统文化的解释框架，动作—靶点关系才是可以验证的部分。把精力放在后者，收益更高。

### 3_14 十式实操：预备势、五戏十式与收势

以下采用**站立式标准版**：预备势 + 五戏十式 + 收势，全套约 12–18 分钟。每一式给到口令、呼吸、易错点三层。通用沉肩、坠肘、松腰与呼吸原则，不再逐式重复。

#### 预备势：先把自己"摆正"

**七种手型先认全**（手型错了，劲力路径全错）：

| 手型 | 做法 | 用于 |
| --- | --- | --- |
| 掌 | 五指自然伸展，掌心含空 | 通用 |
| 空拳 | 四指卷握、拇指压上 | 虎举（握）、攒握 |
| 虎爪 | 五指撑开，第二、三指节屈曲 | 虎扑 |
| 鹿角 | 中指、无名指内扣，其余伸展 | 鹿抵、鹿奔 |
| 猿钩 | 五指撮拢如钩 | 猿提、猿摘 |
| 握固 | 拇指抵无名指根，四指握包 | 猿摘收势、桩功 |
| 鸟翅 | 掌成侧立，手腕上翘 | 鸟伸、鸟飞 |

> 检验：每个手型在"劲力终点"都应感到指根／掌根有张力。

**身法三要**：松腰、沉肩、坠肘；膝盖**永远微屈不锁死**。

**起势调息**：两掌上提（吸）→ 胸前翻合 → 下按（呼），重复 3 次。

> 🔑 **起势口诀**：上提，下按。先把呼吸"叫醒"，再动身。

**呼吸总原则**：鼻吸鼻呼，**开 / 升 / 展 → 吸，合 / 落 / 收 → 呼**，全程不憋气。初学 **1–2 周只用自然呼吸**，动作与呼吸一旦冲突，立刻放弃配合——强行配合是初学者头晕、放弃的主因。

#### 虎戏 · 虎举（威猛刚劲）

**口令**：握拳 → 举 → 握拳 → 拉（上下为一次，共 3 次）

+ 两掌上托如托重物，提胸收腹（吸）；下落如拉双环，含胸松腹（呼）；
+ 两手沿**垂直线**运行，眼随手动；
+ 十指撑开 → 屈指 → 握拳三环节要分明。

**体感目标**：练完腰背有**牵拉后的发热感**。

**易错**：耸肩憋气；三环节不明显；两拳上下不在一条直线。

**自检口诀**：_握拳上举如托重，垂直线路眼随掌；三节分明不憋气。_

#### 虎戏 · 虎扑（脊柱蠕动）

**口令**：提 → 伸 → 按 → 提 → 扑（左右各 1 遍）

+ 关键在**脊柱蠕动**：屈膝含胸（蓄）→ 伸膝、送髋、挺腹、挺胸（发）→ 前俯至躯干与地面接近平行，手臂前伸、臀部后引，充分拉伸脊柱；
+ 下扑时力达指尖，**前扑呼气**。

**体感目标**：脊柱像波浪一样一节节向前推，最后指尖有"窜出去"的感觉。

**易错**：猛地弯腰用腰"砸"下去；前伸时屈膝、低头、弓背；躯干未与地面平行。

> ⚠️ 腰椎疾患者幅度减半；前伸时核心必须收住，勿用腰椎代偿。

**自检口诀**：_含胸蓄劲脊蠕动，送髋挺腹节节扑；指尖有窜腰不砸。_

#### 鹿戏 · 鹿抵（拧转侧屈）

**口令**：迈步 → 转腰 → 下视 → 还原（左右各 1 遍）

+ 腰部**侧屈拧转**，侧屈一侧压紧，另一侧借上举手臂后伸充分牵拉；
+ **后脚跟要蹬实**，形成前后对抗力；目视后脚跟，带动颈椎旋转；
+ 转体后伸时呼气。

**体感目标**：腰部有**酸胀后松开**的感觉。

**易错**：侧屈拧转幅度不够；**转头不足、不目视后脚跟**；上步角度不准、重心未在前腿。

**自检口诀**：_迈步转腰目视跟，侧屈拧转前后争；腰酸后松是真到。_

#### 鹿戏 · 鹿奔（双重弓形）

**口令**：上步 → 后坐 → 前移 → 收回（左右各 1 遍）

+ 提腿前迈有弧度，落步轻灵；重心后移时**低头、弓背、收腹**（身体成"竖弓"），两臂内旋成鹿角；
+ 重点体会**"横弓"（两臂）+"竖弓"（躯干）**的双重弓形。

**体感目标**：后背像一张被拉满的弓，胸腹之间有一股"含住"的劲。

**易错**：弓步两脚前后成直线（应前后错开约一脚宽）；两臂内旋前伸时直臂、手腕相碰；后坐时未低头弓背收腹。

**自检口诀**：_上步后坐成竖弓，两臂内旋横弓张；前后错步背如弦。_

#### 熊戏 · 熊运（全套路最复杂、功效最大）

**口令**：右 → 上 → 左 → 下（再反向，左右各 1 遍）

+ 两掌成"熊掌"垂于腹下，**以腰腹为轴心划立圆**，直径约 30 厘米；
+ 向上提拉时舒展胸廓（吸），向下挤压时含胸实腹（呼）——一个完整熊运配一次呼吸；
+ **下肢要保持稳定，不要随腰腹摇晃**。

**体感目标**：腹腔内部有被"晃动、按摩"的感觉，而不是皮肤表面被摩擦。

**易错**：

| 编号 | 常见错误 |
| --- | --- |
| 1. | 腰腹没走立圆、下肢跟着晃（**最常见**） |
| 2. | 两掌划圆变主动运动，反过来领着腰腹走 |
| 3. | 两掌贴腹太紧变成"摩腹"，失去划圆的弧劲 |
| 4. | 直膝或屈膝超过脚尖 |

**自检口诀**：_腰腹画圆下肢稳，上提舒展下含实；腹内按摩不摩皮。_

#### 熊戏 · 熊晃（沉稳中轴）

**口令**：提髋 → 落步 → 后坐 → 前靠（左右各 1 遍）

+ **提髋带动单腿**（不是抬膝），前落时脚底发出**沉实的钝响**；
+ 两肩相向运动、上下相错，**以肩带臂**；前靠后坐时同侧腰部压实，借以**按摩内脏**；
+ 提髋（吸）→ 落步（呼）→ 后坐（吸）→ 前靠（呼）。

**体感目标**：重心左右倒手时，腰腹像装满水的袋子跟着晃，肩是被动的。

**易错**：

| 编号 | 常见错误 |
| --- | --- |
| 1. | 未提髋，或提髋同时提膝（变成"抬腿走"） |
| 2. | 落步全脚掌重重跺地（应**轻缓沉稳**，脚尖先向前） |
| 3. | 前移后坐时重心未转换 |
| 4. | 未拧腰晃肩挤压胁肋 |

> ⚠️ **初学者关键提醒**：熊晃最容易练错成"用膝盖硬扛重量"。力量来自**腰腹核心的提落**，膝盖只是被动支撑。落脚越重，膝盖压力越大。

**自检口诀**：_提髋落步如载物，重心倒换肩带臂；腰腹自晃膝不扛。_

#### 猿戏 · 猿提（精细控制）

**口令**：上提 → 左转 → 回正 → 下按（左右各 1 遍）

+ 两掌体前分开 → 屈腕撮拢成"猿钩"上提至胸 → **耸肩、缩胸、夹肘、提髋、收腹、提踵**一并到位（吸）→ 头水平左转；
+ 头转正 → 沉肩、落脚跟、变掌下按（呼）。

**体感目标**：像猴子警觉地探头张望——**机灵而不紧张**。心跳略升、精神转清醒，是"心主神明"被调动的信号。

**易错**：头**不是水平转动**（上下点头就错了）；身体各部位收紧/放松的**顺序错误**；重心不稳。

**自检口诀**：_钩手上提六处齐，头转水平肩下沉；机灵不紧神转醒。_

#### 猿戏 · 猿摘（手眼协调）

**口令**：退步（目随掌动）→ 摘桃 → 收回（左右各 1 遍）

+ 退步与上步方向呈 **45°**；摘桃时手臂走弧形；
+ "托桃状"：上手虎口朝后，下手掌心对肘尖，胸正对前方；
+ 重点表现猿猴**顾盼的眼神**。

**体感目标**：眼到、手到、步到，三者同时——**只动手臂不动步、眼神没跟着"果实"走，都是错的**。

**易错**：退步与上步未成 45°；摘桃时手臂未走弧形、后点步两膝未伸直；托桃手型不标准。

**自检口诀**：_退步摘桃四十五，眼手步到同时住；弧形托桃神顾盼。_

#### 鸟戏 · 鸟伸（平衡与节律）

**口令**：上举 → 前伸 → 后举平衡（左右各 1 遍）

+ 两掌腹前相叠 → 上举时**提肩、缩项、挺胸、塌腰** → 前伸 → 单腿后举成**反弓**；
+ 两掌成"鸟翅"，两臂摆至**侧后方 45°**。

**体感目标**：支撑脚像扎进地里，身体却轻得要飘起来。支撑腿**微微发抖是正常的**（股四头肌在等长收缩），说明平衡肌群正在被训练——站不稳就扶墙，稳定性是练出来的，不是硬扛出来的。

**易错**：上举时未提肩缩项挺胸塌腰；摆腿时腿未伸向正后方、支撑腿未伸直；平衡时身体未成反弓状。

**自检口诀**：_提肩缩项成反弓，后举腿向正后方；脚扎地中身欲轻。_

#### 鸟戏 · 鸟飞（开胸与呼吸）

**口令**：提膝展臂 → 下落（左右各 1 遍）

+ **支撑腿必须伸直**，上提腿大腿尽量高于水平；
+ 展翅时**肩膀下沉、不耸肩**——这是鸟戏最容易犯的错；
+ 手腕相碰、两臂僵硬摆动都要避免。

**体感目标**：两臂的起落带动胸廓开合，像风箱一样拉动呼吸。

**易错**：支撑腿屈膝；耸肩；两臂摆动僵硬不柔和。

**自检口诀**：_支撑腿直肩下沉，提膝展臂如鸟翔；起落带动胸开合。_

#### 收势：引气归元（别练完就走）

1. 并脚松静站立，调息 3–5 次，意守丹田；
2. 两掌体侧上举至头顶（吸）→ 缓慢下按至腹前（呼），气沉丹田；
3. **搓手浴面**，轻揉眼眶、双耳；
4. 两手自然下垂，**闭目养神约 1–3 分钟**，再缓缓睁眼。

> 🔑 **收势的意义**：把练习中"散开"的气血重新归于丹田。跳过失血归元的收势，是很多人练完反而心慌、虚乏的原因。完整收功方法见基础板块。

#### 十式"靶感受"校验表

| 戏 | 练对后的靶感受 |
| --- | --- |
| 虎戏 | 腰背牵拉后发热 |
| 鹿戏 | 腰部酸胀后松开 |
| 熊戏 | 腹部轻微震动/按摩感（内脏被温和挤压） |
| 猿戏 | 心跳略升、精神转醒 |
| 鸟戏 | 支撑腿微抖、呼吸通畅 |

练习数月后，五种感受一个都没有 → 几乎可以确定：动作只是"形似"，神、意、气三层全部缺位 → 该回去重修"形"，而非继续追进度。

### 3_15 强度红线、单戏应急与三条可迁移总纲

#### 强度红线（汗出即止）

这是华佗亲自定的剂量终点，也是全套路唯一不可突破的红线：

+ **练时**：微微出汗、可轻松交谈（自觉用力程度约 3–4 级 / 10 级制）；
+ **练后**：神清气爽、关节灵活 = 正常；某关节固定酸痛、肿胀，或连续数日异常疲倦 = 强度或动作有问题，必须调整；
+ **立即停止信号**：关节疼痛、头晕、胸闷、心慌。

> **频次优于单次时长**：每周 3–5 次、每次 20–30 分钟的规律练习，远胜"一周一次 2 小时"。这与八段锦证据一致——**停练即消退**。

#### 单戏应急（体有不快，起作一禽之戏）

| 症状 | 选哪一戏 | 作用 |
| --- | --- | --- |
| 久坐腰僵／腰背紧 | 虎戏（虎举 + 虎扑） | 开腰背脊柱 |
| 腰胯僵硬／侧屈差 | 鹿戏（鹿抵 + 鹿奔） | 活腰胯肾督 |
| 消化不良／腹胀 | 熊戏（重点熊运） | 稳中轴、按摩内脏 |
| 心神不宁／反应钝 | 猿戏（猿提 + 猿摘） | 调心神与协调 |
| 气短／呼吸浅 | 鸟戏（鸟伸 + 鸟飞） | 调肺与呼吸 |

> 用法：单戏各 3—5 遍，10—15 分钟即可，不必走全套。

#### 三条可迁移总纲（跳出具体动作）

1. **动而不极**——华佗原文，一切运动处方的剂量哲学：取六七成，留有余力；
2. **外动内静、刚柔相济**——各流派最大公约数：练动作时神要内守，动作走弧、不用蛮力；
3. **汗出即止、量力而行**——最早的"个体化强度标准"，比心率区间更朴素也更普适。

> 这三条不只适用于五禽戏，放到跑步、力量训练、八段锦乃至任何运动处方里都成立。**华佗那句"人体欲得劳动，但不当使极耳"，抵得过所有复杂的口诀。**

#### 进阶路线与四周处方

| 阶段 | 时间 | 内容 | 目标 |
| --- | --- | --- | --- |
| 阶段0 | 第1周 | 只学预备势+起势调息+收势，每次5min | 松腰、沉肩、坠肘，呼吸自然绵长 |
| 阶段1 | 2–3周 | 一次一戏(两式)，顺序：熊→鸟→鹿→虎→猿 | 每天1次，10–15min |
| 阶段2 | 4–6周 | 五戏十式完整走一遍，左右各1遍 | 全套12–18min |
| 阶段3 | 第7周起 | 按需加量：腰痛加虎鹿，腹胀加熊 | 每周3–5次，每次20–30min封顶 |

**处方化（按目标）**：

| 目标 | 方案 | 周期 |
| --- | --- | --- |
| 平衡/防跌倒 | 五禽戏全套，重点鸟戏、鹿戏 | 8–16周 |
| 代谢/血糖 | 完整五禽戏，长期规律 | 12周以上 |
| 情志不舒 | 虎戏 + 八段锦第2/7式 | 8–12周 |

#### 安全边界（三类最高频损伤机制）

| 损伤 | 高危动作 | 根因 | 纠正 |
| --- | --- | --- | --- |
| 膝关节疼痛 | 鹿抵、熊晃 | 屈膝拧转时膝盖超脚尖、力线不正 | 膝盖不超脚尖第二趾；减小步幅与拧转 |
| 腰劳损 | 虎扑、猿提 | 塌腰后仰时核心没收紧，用腰椎代偿 | 收腹、脊柱逐节动，不猛砸 |
| 气血虚乏 | 全套 | 意念过重、呼吸用力、练到精疲力竭 | 留有余力，"练到 70%"就收 |

**绝对禁忌与暂停信号**：

+ **暂停练习**：急性病、发烧、急性腰扭伤、明确骨关节炎症发作期；空腹、过饱、过劳、情绪剧烈波动时；
+ **需专业指导后再练**：严重心血管疾病、高血压危象、严重骨质疏松、骨折未愈合、孕期；
+ **练中立即停止**：关节疼痛、头晕、胸闷、心慌。

**特殊人群降级**：

| 人群 | 降级方案 |
| --- | --- |
| 膝关节退行性病变 | 猿戏跳跃改原地踮脚；降低重心起伏 |
| 骨质疏松 | 虎扑、鹿转幅度减半 |
| 平衡差 / 易眩晕 | 鸟戏全程扶墙；单腿独立时间缩短 |
| 术后 / 体弱 | 先只练熊运、鸟伸等低强度式，每式3–5次 |

原则：幅度减半 > 省略 > 硬扛。

通用排错、禁忌分级与异常体感处理见板块11。

### 3_16 案例故事：华佗以"户枢不朽"论劳动之度

**案例小故事：户枢不朽与五禽戏的强度红线（原典记载类）**

**背景：**《后汉书·方术列传·华佗传》《三国志·华佗传》记载，华佗对学生吴普谈及养性之理，主张人体需要活动，并以"户枢不朽"设喻：经常转动的门轴不易被蠹蚀。

**困境：** 汉末士人常见两种偏失：一类久卧静坐，血脉与谷气皆不畅；另一类虽有劳作，却一味求多求猛，同样伤身。吴普面对的不是"要不要动"，而是找不到"动到哪里为止"的尺度。

**转折：** 华佗把判断落在"但不当使极耳"一句：劳动应当持续发生，却不可越过身体能够恢复的上限；运动的价值正在于持续、有度，而不在短时猛烈。

**落地启示：** 今天练五禽戏，仍应把六七成用力、微汗即止当作剂量终点。熊运时应感到腰腹被温和晃动、下肢保持稳定，而不靠下肢左右甩动制造幅度；全套练完应是神清气爽，不是虚脱。若已大汗、关节固定酸痛或次日更疲倦，说明越过"极"，应把遍数、幅度和呼吸强度同时下调。

### 3_17 案例故事：久坐者的单戏拆分练习

**练习场景示例：久坐后的单戏拆分（示例情景，非原典记载）**

**背景：** 一位长期伏案、体检提示血脂偏高的练习者，开始每天练完整五禽戏，并希望尽快取得效果。他把进度等同于运动量，练虎扑时追求更低幅度，练鹿抵时追求更强拧转。

**困境：** 练习约三周后，他出现膝前隐痛和练后腰背发僵，睡眠反而变差。身体给出的信号是：局部酸痛不在练习后缓解，而呈持续加重；他却仍把"出汗更多"理解为练得更到位，准备再加一遍全套。

**转折：** 他把"以汗出为度"设为不可突破的终点：全套改为一遍，虎扑只在腰背能够逐节延伸时做到大腿微酸即起身；收势后增加约 3 分钟慢走与自然呼吸，并把练习拆成单戏。

**落地启示：** 今天练习应先检查三个信号：一是后背微微潮湿而非大汗；二是熊运时腹腔有按摩感、膝不承重代偿；三是练后十分钟精神转清，而非想躺倒。颈腰僵硬优先练鹿戏与熊戏，平衡差优先练鸟戏；单戏各 3–5 遍、10–15 分钟即可，不必每次完成全套。

### 3_19 本板块的验证方法

#### 第一层：形—神—意—气—体感 五级校验

| 层级 | 校验标准 | 不到位的表现 |
| --- | --- | --- |
| 形 | 手型、步型、路线正确 | 手型含糊、路线走直不走弧 |
| 神 | 有虎威／鹿舒／熊沉／猿灵／鸟捷 | 五戏"一张脸"，全是体操 |
| 意 | 有对应意念对象 | 脑子在想别的事 |
| 气 | 呼吸与动作自然相随 | 憋气、越练越喘 |
| 体感 | 练后有明确局部感受 | 整套毫无感觉 |

> 校验顺序：从"形"起，逐层往上；下层不过关，不要急着练上层。

#### 第二层：四项功能测试（客观、可量化）

| 测试 | 方法 | 达标线 |
| --- | --- | --- |
| 测试一：虎戏脊柱蠕动 | 四点跪位→逐节弓背(猫)→逐节塌腰(牛)，10次 | 能明确感到"一节一节"动，无卡顿→计1分 |
| 测试二：鹿戏拧转幅度 | 坐位，固定骨盆，转头看肩后 | 目视可越过肩峰线→计1分 |
| 测试三：熊戏单腿提髋 | 扶墙，单腿"提髋"而非"抬膝" | 能连续10次不靠膝盖发力→计1分 |
| 测试四：鸟戏单腿站立 | 睁眼单腿站，双手叉腰 | ≥30秒不落地→计1分（闭眼≥10秒=平衡优秀，加1分） |

### 3_20 本板块收束

五禽戏的精髓不在"仿形"，而在"取意"——五种劲力模式与五种精神状态的对译，才是它区别于一般动物体操的核心。华佗的"动而不极"是全程不可突破的强度红线，汗出即止、留有余力、频率优先于单次时长，这三条决定了练习能否长期积累。十式的编排顺序从大到小、从稳到灵，熊戏稳定性未过关就上猿戏灵敏，必然脚下发飘、腰部代偿。

今天练习时，应让每一戏都出现明确的"靶感受"：虎戏腰背发热、鹿戏腰酸胀后松、熊运腹腔被温和按摩、猿提精神转醒、鸟戏支撑腿微抖。若五种感受长期缺失，说明只练了外形，应退回"形"重练动作模式，而非继续加遍数。呼吸配合不上时立即退回自然呼吸，绝不憋气。

五禽戏是中等强度的复合运动与专注力训练，有效的部分大部分能被现代运动科学解释，但**不能替代药物治疗与规范诊疗**。目标是**平衡与下肢能力**优先五禽戏，目标是**日常活动与步行**优先八段锦。呼吸配合细节见板块2，按季节与病症开成处方见板块11，通用纠错见板块11，与其他功法的组合见板块7。

若每日只能练一次，优先保留"预备势 +熊运+ 鸟伸+收势"的最小闭环，覆盖腰腹稳定、单腿平衡与完整呼吸。这套最小闭环最不容易因赶进度而牺牲神态与呼吸。每次练完至少应能回答三个问题：熊运时下肢是否稳定、腹腔是否有按摩感？鸟伸时支撑腿是否有持续微抖？收势后是否神清气爽而非虚脱？若其中一项长期缺失，下次的唯一改进点就落在那里。

**五禽戏真正的"秘传"，是华佗那句"人体欲得劳动，但不当使极耳"——动而不极（剂量）× 仿生取意（动作设计）× 形神意气（执行标准）× 汗出即止（终点信号）。** 把它神化成"包治百病"是错的，贬成"花式体操"同样错了。作为辅助手段，它对平衡、下肢功能、柔韧、心肺与情绪有实证支持，选功时记住——**持续、到位、有余力，才是五禽戏全部方法论的落脚点**。
