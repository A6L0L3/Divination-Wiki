## README · 传统拳法系统知识库：从立形到致用

> 一套把古典拳论、导引养生原典与现代运动科学对译之后，可以直接照着练、照着记、照着验的完整学习体系。

### 这是什么

市面上的传统拳法资料，大多停在两种状态：要么是原文的翻译与注解，读得懂却练不出来；要么是动作图解与视频，跟得下来却不知道为什么。

本知识库要解决的，正是中间那一段——**把"古文在说什么"翻译成"今天怎么练、练对了身上有什么感觉、练错了怎么改"**。

它以十余部原典为底本（八段锦、五禽戏、易筋经、灵剑子、峨眉十二桩、十二段锦、十六段锦、万寿仙书、修龄要指，以及太极拳、八卦掌、苌氏武技书、拳经拳法备要四部拳学），再按现代训练科学的语言重新组织：结构对位、动力链、筋膜负荷、呼吸模式、剂量—效应、周期化、动作学习。

**它不是百科，是一条路。** 路分四阶：立形 → 通法 → 求劲 → 致用。绝大多数人卡住，不是因为功法不好，而是因为**顺序错了**——跳过了底座。

### 三条路线，先选一条

知识库覆盖三种目标，走法不同，不要混着走。

| 路线 | 目标 | 主修板块 | 每周频次 |
| --- | --- | --- | --- |
| **内养路线** | 改善健康、慢病调理、睡眠情绪 | 板块0—2（底座）+ 板块3—6（选一套为主）+ 板块11 | 5 天/周，每次 20—30 分钟 |
| **技击路线** | 学拳、懂劲、能应 | 板块0—2（底座）+ 板块8—10（一家通到底） | 5—6 天/周，每次 40—60 分钟 |
| **处方路线** | 针对具体问题开方（颈腰、平衡、代谢） | 板块0—2、板块11 | 按处方执行，通常 3—5 天/周 |

三条路共享同一个底座：**板块0 到板块2**。这一段的收益密度最高——现代人的颈肩腰问题、睡眠问题、呼吸浅短问题，大多在 8—16 周内就有明确改善。

**阅读顺序的四条建议**：

1. 第一次读，从板块0 读到板块2，不要跳。这一段决定后面所有功法的质量。
2. 练功法时，板块3—5 任选一套为主、一套为辅，**不要同时入门两套技击拳法**。
3. 站功（板块3—5）与坐功（板块6）是互补的两半：动功解决"通"，静功解决"养"，不要只练一半。
4. 遇到卡住、停滞、伤痛、坚持不下去，直接翻板块11。

### 四个通用约定

**一、先立形，再谈气。** 结构没对，走圈就是白走；走圈没稳，手法一定散。所有"气感""内功"的说法，都必须回到可验证的身体操作上——躯干中轴、筋膜张力、呼吸时序、发力传导。古人说"先把外形做对，里头的东西自己会长"，说的就是这件事。

**二、不憋气是底线。** 四家功法（八段锦、易筋经、八卦掌、太极拳）在这一点上意见完全一致：初学先自然呼吸，动作顺了再过渡到腹式呼吸。呼吸是配角，为了配合呼吸而憋气，是把好事练成负担。

**三、只处理症状，不追求境界。** 温热、发胀、唾液增多、肠鸣、打哈欠都是正常反应，不理会、不追逐。所有让你想去"追求"的特殊感受，都是岔路；所有让你难受的反应（头晕、胸闷、锐痛），都是停止信号。

**四、酸胀是功，锐痛是伤。** 温热酸胀可以继续；关节内某一点持续酸痛要减幅；锐痛、刺痛、电击感、撕裂感立即停止。这一条判断力，比学会任何一式都重要。

### 笔记方法总则

每个板块末尾都有独立的笔记方法小节，可以直接抄用。全库统一的原则是**"五分钟内填完，只记能改的东西"**。

一次练习记五样：

```plain
日期：____   身体状态（睡眠/情绪/旧伤）：____

1. 今日内容（勾选 + 时长）：
   □ 站桩 ____分钟   □ 动功 ____（____分钟）
   □ 静功 ____（____分钟）   □ 步法 ____（____分钟）
2. 强度自觉（1—10）：____   出汗：□ 无 □ 微汗 □ 大汗
3. 有无不适（部位 + 级别 1—5）：____________
4. 今日唯一改进点（只写一条）：____________
5. 体感关键词（如"托天式找到线了""换掌还是晃"）：____________

```

三条纪律：

+ **只写一条改进点。** 写三条等于没写——下次练习你只会盯住一条。
+ **体感关键词必须有。** "今天练了八段锦"是流水账；"托天式找到线了"才是练功记录。
+ **每 4 周测一次功能指标**（闭眼单腿站立、30 秒坐站、坐姿体前屈、静息呼吸频率、睡眠质量、颈肩腰不适自评），进步看不见，是放弃的头号原因。

### 验证方法总则

全库所有"验证"都遵循同一条标准：**可观察、可复现、有达标线**。不靠感觉判断"今天状态好不好"，而是靠测试。

四道基础检验（详见板块0_8）：

| 检验 | 达标线 | 对应底座 |
| --- | --- | --- |
| 靠墙站立 | 脚跟、臀、肩胛、后脑贴墙，腰隙可插一掌，呼吸不耸肩 | 结构对位 |
| 仰卧呼吸 | 手放腹部被顶起、肩膀不动；呼气时长达吸气 1.5—2 倍 | 呼吸模式 |
| 无极桩 10 分钟 | 情绪平稳、无憋气、结束后腿部充实而非酸痛 | 桩功定力 |
| 闭眼单腿站立 | 左右各稳定 30 秒 | 本体感觉与平衡 |

### 安全红线

+ 高血压、心脏病、脑动脉硬化者：八段锦第五式慎做或改幅度；所有头位低于心脏、闭气努气的练习一律不做。
+ 腰椎疾患者：深前屈类动作（两手攀足、打躬势、低头攀足）减半幅度或以温和伸展替代。
+ 膝关节有恙者、无基础的年长者：不练低桩（深屈膝马步）。要练下肢，选中高桩或靠墙静蹲。
+ 有明确疾病者：练功是生活方式与康复训练的**补充**，不能替代诊断、检查、药物与必要治疗。
+ 出现头晕、胸闷、心悸、视物模糊、恶心：立即停止，恢复自然呼吸；症状持续请就医。

### 一个提醒

一到三阶的总时长约 2—4 年。这不是吓退你，而是说明一件事：**"三个月出功"的广告，卖的一定不是这里写的东西**。反过来，一阶（立形）只要 8—16 周，却是收益密度最高的一段。

古典的说法是"勤行无间断，万病化为尘"；现代的说法是——干预停止后，收益会消退；频率比单次时长更重要。**练下去，是这套体系里唯一无法被替代的技术。**
