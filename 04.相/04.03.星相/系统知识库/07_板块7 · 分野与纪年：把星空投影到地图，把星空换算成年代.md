## 板块7 · 分野与纪年：把星空投影到地图，把星空换算成年代

> **承上启下**：板块 4 至 6 确立了"哪些记载可信"。现在进入古人最富想象力的一步操作——**把可信的观测，通过一套映射规则，投射到人间**。

这个投射有两个方向：**空间上**是分野（哪颗星管哪块地），**时间上**是岁星纪年（哪颗星管哪一年）。二者共用同一套"十二次"骨架，因此放在同一个板块讲。

### 7_1 分野的原理与三套并行的对应系统

分野不是一套系统，而是**三套叠在一起**的对应系统。混淆它们是分野研究的常见错误。

| 系统 | 划分依据 | 单元数 | 用途 | 主要出处 |
| --- | --- | --- | --- | --- |
| **二十八宿分野** | 二十八宿对应十二州国 | 28 → 12 | 最常用，操作性最强 | 《汉书·天文志》《史记·天官书》 |
| **十二次分野** | 黄道十二等分对应十二古国 | 12 对 12 | 与岁星纪年、节气配合 | 《周礼》系统、《晋书·天文志》 |
| **五星主候** | 五星对应邦国 | 5 → 多国 | 判断"哪颗星管哪国" | 《汉书·天文志》 |

```latex
┌────────────────────────────────────────────────┐
│  十二次（12 等分 · 宽格）                      │
│   ┌────────────────────────────────────────┐   │
│   │ 二十八宿（28 不等分 · 细格）           │   │
│   │  ┌──────────────────────────────────┐  │   │
│   │  │ 五星主候（责任人分配）           │  │   │
│   │  │ 秦→太白  吴楚→荧惑               │  │   │
│   │  │ 燕齐→辰星                        │  │   │
│   │  └──────────────────────────────────┘  │   │
│   └────────────────────────────────────────┘   │
└────────────────────────────────────────────────┘

```

### 7_5 岁星纪年、太岁与超辰：把星空换算成年代

#### 1. 基本原理

木星（岁星）约 12 年运行一周天。古人把周天分为十二次，木星每年大致行经一次，于是**用它所在星次来纪年**：

```latex
岁星在星纪 → "岁在星纪"
岁星在玄枵 → "岁在玄枵"
十二年一轮回

```

《左传》《国语》中已有这类记载，春秋战国时期通行。

#### 2. 方向难题与"太岁"的发明

麻烦在于：**岁星运行方向是自西向东，而传统的十二辰（子、丑、寅）是自东向西排列**。方向相反，用起来极不方便。

解决办法极具想象力——**假想一个与岁星反向运行的天体，叫"太岁"（又称岁阴、太阴）**，用十二辰来标记它的位置，方向问题被绕过去了：

```latex
岁星在星纪（丑）  →  太岁在寅  →  称"太岁在寅"

```

#### 3. 岁名对照表

| 岁名 | 太岁（岁阴） | 岁星居辰 | 十二次 | 岁星晨出月份与伴出星宿 |
| --- | --- | --- | --- | --- |
| 摄提格 | 寅 | 丑 | 星纪 | 正月，与斗、牵牛 |
| 单阏 | 卯 | 子 | 玄枵 | 二月，与婺女、虚、危 |
| 执徐 | 辰 | 亥 | 娵訾 | 三月，与营室、东壁 |
| 大荒落 | 巳 | 戌 | 降娄 | 四月，与奎、娄 |
| 敦牂 | 午 | 酉 | 大梁 | 五月，与胃、昴、毕 |
| 协洽 | 未 | 申 | 实沈 | 六月，与觜觿、参 |
| 涒滩 | 申 | 未 | 鹑首 | 七月，与东井、舆鬼 |
| 作噩 | 酉 | 午 | 鹑火 | 八月，与柳、七星、张 |
| 阉茂 | 戌 | 巳 | 鹑尾 | 九月，与翼、轸 |
| 大渊献 | 亥 | 辰 | 寿星 | 十月，与角、亢 |
| 困敦 | 子 | 卯 | 大火 | 十一月，与氐、房、心 |
| 赤奋若 | 丑 | 寅 | 析木 | 十二月，与尾、箕 |

**十岁阳**（对应十天干）：阏逢（甲）、旃蒙（乙）、柔兆（丙）、强圉（丁）、著雍（戊）、屠维（己）、上章（庚）、重光（辛）、玄黓（壬）、昭阳（癸）。

于是"甲寅年"可以雅称为"**阏逢摄提格**"。这就是《史记·历书》"太初元年，岁名'焉逢摄提格'"的由来。

#### 4. 超辰：这套系统为何崩塌

**根本缺陷**：木星实际恒星周期约 **11.86 年**，不是整 12 年。

```latex
累积误差约 86 年超前一次（一个星次）＝"超辰"（超次）

```

纪年与天象从此逐渐脱节。

**修补尝试**：西汉刘歆在《三统历》中创设"**超辰法**"，设定每 144 年岁星行经 145 个星次来做调整。但这种打补丁的方式使纪年越来越复杂。

**最终解决**：东汉章帝**元和二年（公元 85 年）**颁行《四分历》，**正式废止依赖天象的岁星纪年，确立连续、简便的干支纪年**，一直沿用至今。

#### 5. 这条脉络的意义

| 层面 | 意义 |
| --- | --- |
| **思想史** | 人类早期把"天体运行"直接用作"时间标尺"的典型尝试，也是一次**因精度不足而被更抽象的符号系统（干支）取代**的经典案例 |
| **方法论** | 干支纪年是纯符号、不依赖观测、永不失准；岁星纪年依赖观测、会累积误差。**抽象符号战胜了具体天象**——与历法史上"定气取代平气"是同一种进步逻辑 |
| **文化遗存** | 书画题款中的"岁次某某"仍存其遗意；"太岁"从纪年概念演变为民间信仰中值守的神祇 |
| **实用技能** | 读《左传》《国语》《史记》中的"岁在某次"，须用本表换算，并注意超辰问题 |

### 7_6 分野操作流程：五步推演法

古人拿到一条异常天象，实际是这样操作的：

```latex
Step 1 · 记录天象
        "荧惑守心"——火星在心宿停留并逆行
              ↓
Step 2 · 定位星宿
        心宿在二十八宿中属东方苍龙，对应十二次中的"大火"
              ↓
Step 3 · 查分野
        大火 → 宋 · 豫州（《汉书》体系：房、心 → 豫州宋）
              ↓
Step 4 · 查主候星
        宋郑候岁星，占房、心；此处为荧惑犯心，属"不该主管的星侵入"
              ↓
Step 5 · 出占辞
        心为天王（明堂），荧惑为罚星 → 王者有灾 / 大人易政

```

**关键鉴别点**：Step 1 至 3 是规则操作（可复现），Step 4 至 5 是解释操作（可争议）。分野推演的"客观性"只存在于前三步。

### 7_8 案例小故事：平城之围与"月晕参毕"

**起因**：《天官书》里有一条记载——"平城之围，月晕参、毕七重"。

平城之围是汉初的一件大事：刘邦被围于平城（今山西大同）。而这条记载说，事前天象已经发出了预警。

**把这条记载拆开看**

```latex
真实天象：月亮运行到参、毕二宿附近，出现月晕
          （这一层很可能是真的——月晕是常见的大气光学现象）
    ↓ 定位
参、毕在二十八宿中属西方白虎
    ↓ 查分野（《汉书》体系：昴、毕 对应 冀州 · 赵）
对应地域：冀州、赵地
    ↓ 对照史实
平城正在这一区域 —— 刘邦在此被围
    ↓ 追认
"月晕参毕"被记为平城之围的预警

```

**这里有个逻辑陷阱**

分野体系中"昴、毕对应冀州赵"的对应，与平城的地理位置天然吻合。所以这条记载看起来"特别准"。

但把问题反过来问一句：**是先有对应，还是先有事件？**

汉代疆域广阔，重大军事事件多半发生在几个核心区域；而分野表把全天二十八宿分配给了十二州国——只要天象足够多、事件足够多，总会有"落在同一区"的组合被记住，而"落在别处"的组合被遗忘。

```latex
被记住的：月晕参毕 ↔ 平城之围（落在同一区 → 应验 → 传抄）
被遗忘的：某年月晕角亢 ↔ 兖州无事（落在别的区 → 未应验 → 不传）
        ↓
幸存者偏差：留下的全是"应验"的案例

```

**这个故事的完整教训**

```latex
一、分野"应验"的案例之所以看起来多，
    是因为命中被记录、未命中被遗忘。
二、判断分野推演是否真的有效，要看它有没有被系统统计过，
    而不是看个案有多巧。
三、所以做占验解剖时必须补一个"替代问"：
    同样的天象，在同一时期被记录过几次？是否每次都"应验"了？

```

> **可迁移的经验**：遇到"某某预言精准命中"的说法，先别被个案说服，先问一句**"没命中的那些去哪了"**。这个追问方式同样适用于今天的任何"神预测"叙事——包括各种"我早就说过会这样"的事后断言。

### 7_9 本板块的笔记方法：分野推演练习卡 + 自制转盘

**练习卡（每条天象记载填一张）**

| 步骤 | 你要填的内容 | 常见错点 |
| --- | --- | --- |
| 一、天象 | 原文 + 现代回算是否支持 | 跳过回算直接推演 |
| 二、定位星宿 | 该宿属哪一象？对应十二次的哪一次？ | 四象归属记错 |
| 三、查分野 | 据哪套体系？对应哪一州国？ | 混用不同体系 |
| 四、查主候星 | 该国由哪颗星主管？此星是主管星还是"侵入者"？ | 忘记查主候星 |
| 五、出占辞 | 用通例还是特例？出自哪类占辞规则？ | 把特例当通例 |
| 六、反事实检验 | 若此事未发生，这天象还值得记吗？ | 不做反向检验 |

**自制实体转盘（半天可完成）**

```latex
材料：硬卡纸 3 张 + 双脚钉 1 枚 + 尺规
做法：
一、剪三个同心圆盘（直径约 24 / 18 / 12 厘米）
二、外盘写二十八宿（按四象分组，注意觜窄井宽，可用等分示意但注明"非等分"）
三、中盘写十二次，内盘写十二州国 + 主候星
四、中心打孔，用双脚钉串起
五、背面写"所据版本：《汉书·天文志》"
用法：随机给定一天象（如"客星犯紫宫""荧惑守心"），转动转盘走完五步

```

> **验收小标准**：能不看表独立完成 3 条天象的分野五步推演，并说清每一步的所据版本，第三阶即达标。
