## 板块3 · 宇宙模型：盖天、宣夜、浑天与《灵宪》

> **承上启下**：板块 2 给了星空这张"地图"。下一个问题自然是——**承载这张地图的"天"，本身是个什么东西？**

汉代人对这个问题给出了三个竞争答案。理解它们的优劣，是理解《灵宪》突破性的前提；而理解《灵宪》，又是读懂板块 4 至 6 全部实测数据的理论背景。

---

### 3_1 三说对比：一场关于"天地长什么样"的辩论

| 学说 | 核心模型 | 能解释 | 解释不了 | 命运 |
| --- | --- | --- | --- | --- |
| **盖天说** | 天如盖笠，地如覆槃（天在上覆盖，天圆地方） | 日出日落的方位变化、昼夜 | 天体如何从地平线下回到东方？存在"天不掩地"的几何矛盾 | 早期主流，后被取代 |
| **宣夜说** | 天无定形，日月星辰浮于虚空，靠"气"推动 | 天体各自运动、不共属一个硬壳 | 缺乏可测算的几何结构，无法用于历法推算 | 哲学上有洞见，实用性不足 |
| **浑天说** | 天体如蛋壳，地如蛋黄，乘气而立；天球旋转，地居其中 | 周日旋转、四季、日月食、天体出没 | 精度依赖观测与仪器 | 成为主流，张衡是关键推动者 |

两种模型的几何差别，一眼可见：

```latex
盖天说                       浑天说
┌─────────────────────────────┐    ┌─────────────────────────────┐
│   天如盖笠                  │    │   天体如蛋壳                │
│   地如覆槃                  │    │   地如蛋黄                  │
│ （天圆地方）                │    │ （乘气而立 · 天球绕极旋转） │
└─────────────────────────────┘    └─────────────────────────────┘

盖天说解释不了：天体如何从地平线下回到东方？（几何上矛盾）
浑天说可以回答：天球绕极旋转，出没自然可解，且可被计算
→ 可计算性战胜直观性，这是浑天说胜出的真正原因

```

**浑天说胜出的真正原因**，不是它"更哲学"，而是**它能被测算**。一个宇宙模型要有用，必须回答三个可量化问题：

1. 某颗星今晚几点升起来？（时间）
2. 太阳现在在哪个宿？（位置）
3. 下一次月食是什么时候？（预测）

盖天说回答不了，宣夜说不想回答，浑天说能回答——所以浑天说赢。**这是科学史上一再出现的规律：可计算性战胜直观性。**

### 3_2 《灵宪》的三阶生成论：从无到有的宇宙剧本

《灵宪》是汉代最完整的宇宙演化论述，其骨架是一个三阶段模型：

| 阶段 | 名称 | 原文要义 | 状态描述 | 哲学定位 |
| --- | --- | --- | --- | --- |
| 第一阶段 | **溟涬**（道之根） | "太素之前，幽清玄静，寂漠冥默，不可为象，厥中惟虚，厥外惟无" | 纯粹的无，但"道根"已藏其中 | 无形无象 |
| 第二阶段 | **庞鸿**（道之干） | "太素始萌，萌而未兆，并气同色，浑沌不分" | 元气已萌但未成形，混沌一体 | 有物浑成、先天地生 |
| 第三阶段 | **太元**（道之实） | "元气剖判，刚柔始分，清浊异位。天成于外，地定于内" | 阴阳二分，清阳为天、浊阴为地，天地交感生育万物 | 万物生成 |

生成链条：

```latex
  溟涬（无）          庞鸿（气）          太元（形）
 ┌──────────┐        ┌──────────┐        ┌──────────┐
 │ 幽清玄静 │  ───►  │ 并气同色 │  ───►  │ 元气剖判 │
 │ 寂漠冥默 │  自无  │ 浑沌不分 │  有物  │ 刚柔始分 │
 │ 厥中惟虚 │  生有  │ 萌而未兆 │  成体  │ 清浊异位 │
 └──────────┘        └──────────┘        │ 天成于外 │
    道之根              道之干           │ 地定于内 │
                                         └──────────┘
                                            道之实

```

**源流溯源（避免"张衡独创"的误解）**：

+ "溟涬""庞鸿""太初""太素"等概念，可上溯至西汉晚期《易纬·乾凿度》
+ "清气生天、浊气生地"的表述，在《论衡·谈天》《白虎通·天地》中已有
+ 战国楚竹书《恒先》已出现"浊气生地，清气生天"的类似说法

> **结论**：《灵宪》的价值不在于"发明了什么"，而在于**第一次把散落的宇宙论资源综合成一个自洽的三阶体系**。这是典型的"集大成式创新"。

### 3_3 有限与无限：一次超前的边界意识

《灵宪》给出了一组极具张力的表述：

+ **可测的有限**："八极之维，径二亿三万二千三百里"——给出具体的可测量时空尺度
+ **承认的无限**："宇之表无极，宙之端无穷"——明确承认超出此范围的世界无法确知
+ **认知谦卑**："过此而往者，未之或知也。未之或知者，宇宙之谓也。"

```latex
┌──────────────────────────────────────────┐
│              未知（宇之表无极）          │
│      ┌────────────────────────────┐      │
│      │      可测范围              │      │
│      │      八极之维 · 有径可量   │      │
│      │    （日月星辰运行其间）    │      │
│      └────────────────────────────┘      │
│         过此而往者，未之或知也           │
└──────────────────────────────────────────┘

```

> **读书心法**：这三句话是《灵宪》的"哲学封顶"。读任何古代宇宙论，都要问一句——**它给未知留位置了吗？** 给未知留位置的模型，往往比"什么都敢解释"的模型更接近科学精神。

### 3_4 暗虚：中国最早的月食正确解释

《灵宪》原文：

> **当日之冲，光常不合者，蔽于地也。是谓暗虚。在星星微，月过则食。**

翻译成现代语言：

> 在太阳正对面的方向上，本该有光却常常见不到光，是因为被地球遮挡了。这个影子区域叫"暗虚"。星星经过它只是变暗，月亮经过它就会发生月食。

几何示意：

```latex
                 ☀ 太阳
                  ╲
                   ╲  光线
                    ╲
                ┌──────┐
                │ 地球 │
                └──────┘
                     ╲＿＿＿＿ 地影（暗虚）
                              ╲
                               ●  月球进入 → 月食
                                · 星星经过 → 只是变微

```

**这段的价值**：

1. **正确识别了月食的成因**——月球进入地球影子
2. **区分了月食与星微**——同样是进入地影，月亮能看出"食"（明显缺蚀），星星只是变暗一点，说明作者理解"视直径 / 视亮度差异"这个关键区别
3. **把月食从"天谴"变成了"几何现象"**——这是从占验思维走向物理思维的关键一步

**现代复述练习（强烈建议动手做一遍）**：

```latex
练习：用现代语言重述"暗虚"理论，要求：
一、不用任何阴阳术语
二、说清三个要素：光源（日）、遮挡物（地）、被照物（月）
三、解释为什么不是每个月都有月食（提示：白道与黄道有约 5 度夹角）
四、用一句话说明"在星星微，月过则食"的天文学原理

```

### 3_5 近天则迟、远天则速：一个被低估的分类洞见

《灵宪》把五星按运行快慢分成两组：

| 组别 | 行星 | 书中的分类 | 现代对应 |
| --- | --- | --- | --- |
| 速度快者 | 水星、金星 | 附于月，属阴 | **内行星**（轨道在地球以内） |
| 速度慢者 | 火星、木星、土星 | 附于日，属阳 | **外行星**（轨道在地球以外） |

> **这个分类与现代天文学的内行星 / 外行星之分恰好吻合**。虽然"近天 / 远天"是距地远近的直觉表述，且阴阳配属属于时代范式，但**分类结果本身是对的**——这说明分类背后有真实的观测基础：内行星的视运动确实更快，且始终不离太阳附近。

**方法论启示**：这是"错误的理论框架 + 正确的观测基础 = 部分正确的结论"的典型案例。读古籍时，要把**结论、框架、观测基础**三者拆开评价，不能因为框架过时就连结论一起否掉。

### 3_6 必须合读：《灵宪》与《浑天仪注》的分工

一个极易被忽略的事实：**《灵宪》不是完整的浑天说。**

| 文本 | 侧重 | 核心内容 | 局限 |
| --- | --- | --- | --- |
| **《灵宪》** | **生成论** | 宇宙从哪来、演化几阶段、结构尺度 | 保留了"地体于阴故平以静"的**盖天说残余**，不是地圆说 |
| **《浑天仪注》** | **结构论** | "浑天如鸡子，天体圆如弹丸，地如鸡中黄" | 完成真正的球形大地模型 |

> **合读的必要性**：只读《灵宪》，你会以为张衡还主张地是平的；只读《浑天仪注》，你会错过他的宇宙演化思想。**两篇互补，才是一个完整的张衡。**

### 3_7 时代局限清单（诚实面对）

《灵宪》不是完美文本。以下三处必须标注为"时代范式，非科学结论"：

| 局限 | 原文 | 性质 |
| --- | --- | --- |
| **阴阳机械比附** | 日为阳故日中有三足乌（奇数）；月为阴故月中有四足兔（偶数） | 数字象征，非观测 |
| **星体生成论** | "星也者，体生于地，精成于天"——把恒星视为地上山岳之气的升华 | 星占术的理论基础，错误 |
| **盖天残余** | "地体平而静"、"千里差一寸" | 旧说残留 |

> **两种极端都要避免**：一是用现代天文标准苛责古人（"这也不对那也不对，所以没价值"）；二是把阴阳附会也美化成"科学预见"（"三足乌其实是太阳黑子"）。

正确姿态是**在汉代语境中看它的突破性，在现代标准下看它的局限性**。

### 3_8 案例小故事：同一个"三足乌"，三种读法

《灵宪》里有这么一句：日为阳，故日中有三足乌；月为阴，故月中有四足兔。

同一句话，三位读者读出了三种完全不同的东西。

**第一位读者：全盘否定**

他看到"三足乌""四足兔"，直接下结论：奇数配阳、偶数配阴，纯粹的数字象征，说明这本书的科学性有限。然后他把整本书归为"哲学幻想"，后面的内容草草翻过。

**代价**：他错过了《灵宪》里真正有价值的部分——三阶生成论、暗虚说、五星分类。因为一句附会，否定了一整本书。

**第二位读者：全盘美化**

另一位读者读到同一句，兴奋地论证"三足乌其实是古人对太阳黑子的观测记录"，并进一步推论"汉代已有太阳黑子的系统观测"，写成一篇长文四处分享。

**问题**：把数字象征说成观测记录，等于用现代的合理性去覆盖古代的思维方式。这样读，你永远看不出古人真正的推理逻辑是什么——你只是在给古人换一套现代衣服。

**第三位读者：拆开评价**

第三位读者把三个层次分开处理：

```latex
观测基础：古人长期目视太阳（日出日没、薄雾天气），
          确实可能见过黑子   → 观测基础：有可能存在
理论框架：日为阳（奇数）→ 三足乌；月为阴（偶数）→ 四足兔
                              → 这是阴阳数字象征，不是观测推论
结论状态：数字配属属于时代范式，不能当作科学结论；
          也不要因为它框架过时，就连可能的观测基础一起否掉

```

**结果**：他既没把《灵宪》神化，也没把它扔掉——他能看到：这本书在一个过时的框架里，做了一次严肃的体系化尝试。

**更关键的一步**：同样的方法用在"五星分类"上，价值立刻放大——**框架（阴阳）是错的，但分类结果（内外行星）是对的**，因为分类背后站着一个真实的观测基础（内行星视运动确实更快，且始终不离太阳附近）。

```latex
三种读法的差别，在于有没有做这个三分：
    观测基础 / 理论框架 / 结论状态
不做三分 → 只能给出"太荒唐"或"太超前"的整体定性
做了三分 → 能同时承认局限与价值，还能救回被误杀的结论

```

> **可迁移的经验**：任何一句让你觉得"太荒唐"或"太超前"的原文，都先做这个三分拆解再下判断。这不仅能救回一整本书，也是后面读《天官书》《天文志》时反复要用到的工具。
