## 板块1 · 认知地基：星相的四副面孔与一条主脉

> **承上启下**：板块 0 给了计划，但在接触任何一本具体原典之前，必须先解决一个根本问题——**"星相"到底是什么？**

答案不是一个，是四个叠在一起的层。绝大多数误读，都源于只看见其中一层。

---

### 1_1 四副面孔：同一个"星相"，四种完全不同的知识类型

| 层 | 名称 | 核心问题 | 判定标准 | 代表内容 | 今天的对应学科 |
| --- | --- | --- | --- | --- | --- |
| **第一层** | **实测天文学** | 天体在哪里、什么时候出现 | 可测量、可重复、可回算 | 晷影数据、交食周期、五星行度、星表 | 天文学、天体测量学 |
| **第二层** | **宇宙论** | 天地是什么结构、从哪里来 | 可自洽、可比较，但不可直接验证 | 三阶生成论、浑天说 | 宇宙学、科学思想史 |
| **第三层** | **政治星占** | 天象对应哪个人、哪块地、哪件事 | 有规则、有操作流程，但预测力不可靠 | 分野体系、五星占、日食占 | 政治史、知识社会学 |
| **第四层** | **民间谶纬** | 谁将得天下、何时改朝换代 | 模糊编码 + 事后附会 | 隐语歌谣类文本 | 民间文化史、传播学 |

四层的关系不是"迷信程度递增"，而是**证据强度递减**：

```latex
                  ▲ 证据强度
                  │
      第一层 实测 │ ████████████████  可回算、可证伪
      第二层 模型 │ ███████████       可自洽、可比较
      第三层 投射 │ ███████           有规则、难证伪
      第四层 叙事 │ ███               模糊、不可证伪
                  └──────────────────────────────────► 叙事自由度

```

> **关键判断**：四层的差异是**知识生产方式的差异**。第一层靠仪器，第二层靠模型，第三层靠规则，第四层靠叙事。

混淆它们是星相阅读的头号错误——用第四层的标准嘲笑第一层（"古人真迷信"），或用第一层的标准要求第四层（"预言准不准"），都读不出东西。

### 1_2 一条主脉：四段源流与它们的接榫点

中国星相知识不是一堆散点，而是一条有清晰接榫关系的演化链。

**第一段：史官记录 → 体系化（战国至西汉）**

+ 战国甘德、石申、巫咸三家各有星官分法，用于星占
+ 司马迁《史记·天官书》第一次**综合三家、统一成"五宫二十八宿"体系**——这是中国第一个完整的星空划分体系
+ 班固《汉书·天文志》改"天官书"为"天文志"，调整五星次序、提升日的地位、重排异星位置，为后世正史立范式

**第二段：宇宙论登场（东汉）**

+ 张衡《灵宪》把"星空是什么"升级为"宇宙从哪来、什么结构"
+ 关键进步：从"记录天象"到"建立模型解释天象"，并给出月食成因（暗虚）的正确解释
+ 同期张衡创制漏水转浑天仪——**观测技术与理论模型第一次同步推进**

**第三段：星占制度化（魏晋至唐宋）**

+ 三国吴太史令**陈卓总合甘、石、巫咸三家星官，定为 283 官、1464 星**，成为后世星图与浑象的标准
+ 唐代《开元占经》集成前代占辞，《步天歌》以韵文把三垣二十八宿唱成认星口诀——星占知识开始"口诀化、可传播化"
+ 东晋虞喜发现岁差、北齐张子信发现日行不均、隋刘焯创立定气——**实测精度持续逼近真实**

**第四段：民间化与谶纬化（唐末至明清民国）**

+ 星占知识从官方天文机构下沉到民间
+ 《推背图》《烧饼歌》这类文本出现：**不再依赖真实观测，只借用星相的符号与权威**，用拆字、谐音、象征编码政治情绪
+ 层累增补成为常态：每经历一次社会动荡，就有人往里加新谶语

```latex
第一段 ──► 第二段 ──► 第三段 ──► 第四段
 观测      建模       标准化     叙事化

 从记录到建模 ────────┐
                      └── 从建模到标准化 ──┐
                                          └── 从官方实证到民间叙事
 每一次下沉：实证成分递减，叙事成分递增

```

> **接榫点提示**：这条主脉解释了为什么"同一部书里既有精确数据又有荒诞附会"——因为它们来自不同的历史层，被后人装订在了一起。

### 1_3 术语地基：28 个必须先掌握的核心词

**A 组 · 星空与坐标**

> **原文校准（表述收窄）**：框架判断本身正确——三垣作为完整分区体系晚出，《天官书》属五宫体系。
> 但《天官书》**本文中已出现"太微""天市"二名**：
> 南宫「衡，**太微**，三光之廷。匡卫十二星，藩臣」；东宫「旗中四星**天市**；中六星曰市楼」。
> 故准确表述应为：**三垣作为完整分区体系晚出，书中虽有太微、天市之名，但所指与后世三垣不同**。
> 本库此前"三垣不可用来解读《天官书》"一句过强，易被误读为原书无此二名，现予收窄。

| 术语 | 释义 | 常见误用 |
| --- | --- | --- |
| **星官** | 中国式的"星座"，一组恒星的最小命名单位（如北斗七星是一个星官） | 与西方 constellation 不完全等价，星官大小差异极大 |
| **五宫** | 《天官书》的中宫 + 东苍龙、南朱鸟、西咸池、北玄武 | 早期框架，不能与三垣混用 |
| **三垣** | 紫微垣、太微垣、天市垣，环绕北极的三大天区 | 定型较晚（隋唐以后成熟），**作为分区体系不可用来解读《天官书》** |
| **二十八宿** | 沿黄道—赤道带划分的 28 个区段，是日月五星的"坐标格子" | 不是 28 个星座，宿的宽度（距度）差异很大 |
| **距星 / 距度** | 每宿选定的基准星，以及该宿在赤经上跨越的度数 | 历代距星有过调整，古今对照时须注明年代 |
| **四象** | 青龙（东）、朱雀（南）、白虎（西）、玄武（北），各统七宿 | 方位对应的是特定观测季节的传统，不是绝对方位 |
| **十二次** | 黄道带的十二等分（星纪至析木），与十二辰、十二国对应 | 与十二辰是**逆向**配对，极易记反 |

**B 组 · 天体与运行**

| 术语 | 释义 | 常见误用 |
| --- | --- | --- |
| **七政 / 七曜** | 日、月 + 五星 | 有时"七曜"另含星期含义 |
| **五纬** | 岁星（木）、荧惑（火）、填星（土）、太白（金）、辰星（水） | "填星"与"镇星"通用，非笔误 |
| **赢缩** | 行星早出为"赢"（客），晚出为"缩"（主） | 是占验规则，不是天文异常描述 |
| **逆行 / 留** | 行星视运动由顺转逆的转折阶段，占验中多视为凶 | 现代解释为地球与行星公转速度差造成的**视运动** |
| **中道 / 九行** | 中道即黄道（日行轨迹）；月有九行，指月行轨迹的九种分类 | "九行"是分类法，不是说月亮有九条轨道 |
| **会合周期** | 行星、地球、太阳三者回到同一相对位置的时间 | 与行星自身的恒星周期不同 |
| **岁差** | 春分点（冬至点）沿黄道缓慢西移的现象 | 古今对照不做岁差改正必然出错 |

**C 组 · 仪器与历法**

| 术语 | 释义 | 常见误用 |
| --- | --- | --- |
| **仪 vs 象** | **仪**用于观测天体坐标（浑仪、简仪）；**象**用于演示天象运转（浑象，类似天球仪） | 常把"浑天仪"笼统指代二者 |
| **圭表 / 晷影** | 立表测日影，用于定节气、定纬度、定方向 | 八尺表是汉制标准 |
| **交食周期** | 日月食重复出现的周期规律 | 三统历 135 朔望月与沙罗周期 223 朔望月，是两套不同精度的方案 |
| **平气 / 定气** | 平气按时间等分回归年；定气按黄经每 15 度一气 | 现代农历用**定气**，与古代长期使用的平气不同 |
| **岁星纪年 / 太岁** | 以木星（岁星）所在星次纪年；太岁是与岁星反向运行的假想天体 | 二者方向相反，配套使用 |
| **超辰** | 木星实际周期约 11.86 年而非 12 年，约 86 年累积误差一星次 | 这是岁星纪年被废止的根本原因 |
| **漏刻** | 滴水计时的器具，也是浑象的动力源 | 与"更点"是两套时间系统 |

**D 组 · 占验与谶纬**

| 术语 | 释义 | 常见误用 |
| --- | --- | --- |
| **分野** | 天上星区与地上州国的对应系统 | 不同文献的分野表有差异，引用必须标版本 |
| **异星 / 妖星** | 彗星、新星、流星、极光等异常天象的统称 | 古人归为一类，现代需分属彗星、变星、流星、磁暴等不同现象 |
| **客星** | 突然出现又消失的星，多对应新星/超新星 | 1054 年天关客星即著名一例 |
| **望气 / 候岁** | 望气：通过云气形态占测兵事；候岁：在特定日子占测年成 | 前者含战场侦察经验，后者含物候学成分 |
| **谶 / 纬** | 谶是预言隐语，纬是附会经义的阐释文本 | 二者常合称，但生成机制不同 |
| **层累** | 文本在流传中被不断增补改写，形成"越晚越详细"的现象 | 是判断谶纬文本成书年代的核心概念 |
| **倒填日期** | 把已发生的事写成"事先的预言" | 识别伪预言的第一指标 |
| **望气之"气"** | 云气的形态分类（如骑兵之气卑而布、步兵之气搏） | 与哲学上的"元气"是两回事，勿混为一谈 |

### 1_4 通用分析模型：观测—建模—投射—叙事

这四层是理解一切星相文本的通用解剖刀。**任何一段星相文字，都可以拆成这四步**：

```latex
第1步 观测层（Observed）  ：实际看到了什么？——可回算、可验证
        ↓ 建模
第2步 模型层（Modeled）   ：用什么框架解释它？——宇宙结构、运行规律
        ↓ 投射
第3步 投射层（Projected） ：把它对应到谁、哪块地、什么事？——分野、星官—职官对应
        ↓ 叙事
第4步 叙事层（Narrated）  ：最终讲成了一个什么故事？——占辞、史书记载、民间谶语

```

**四问速查法**（拿到任何一段星相记载，按序问）：

1. **观测层**：这个天象今天能回算复现吗？能 → 记为"实"；不能 → 记为"疑"
2. **模型层**：它依据的是盖天、浑天还是星占规则？模型是否自洽？
3. **投射层**：它用哪套分野？这套分野属于哪个文献系统？
4. **叙事层**：谁记录下来的？记录者有什么立场？记录发生在事件之前还是之后？

> **实操价值**：把"这段是真是假"这个模糊问题，转成四个可分别回答的具体问题。绝大多数争议会自然消解。

### 1_6 案例小故事：一条"日食"记载的四种读法

**起因**：史书上有一条极常见的记载，六个字——"某年某月，日有食之"。看起来平平无奇。

但同一条记载，用四种不同的眼光去读，会读出四个完全不同、甚至互相矛盾的答案。

**读法一：只读叙事层——"古人真迷信"**

如果只看到最后被写进史书、并引发朝堂动作的那一段，你会读到：日食发生后，皇帝下诏罪己、减膳、求直言，三公被问责"理阴阳不称职"。

于是你得出结论：古人把自然现象当成上天的惩罚，真是迷信。
——这个结论不算错，但它只覆盖了链条的最后一段。

**读法二：只读观测层——"不过是次日食"**

如果用现代星表回算，你会发现那次日食确实发生了，日期、见食区域都能对上。

于是你得出结论：这不就是一次普通的日食吗，有什么好说的。
——这个结论也不算错，但它把后面三段全都抹掉了。

**读法三：四层全走一遍——看见"转手"**

```latex
观测层：某年某月某日，某地可见一次日食
        → 可用现代星表回算，结论可能是：实 / 疑 / 伪
   ↓
模型层：日食是怎么发生的？
        → 浑天说框架下，日月各行其道，月掩日则食
        → 《灵宪》既已用"暗虚"解释月食，同理可推日食为月掩日
   ↓
投射层：按分野，日食发生在某宿 → 对应某州国
        → 又因"日变修德"的规则，指向君主自身而非臣下
   ↓
叙事层：史官写下"日食，京师不见，郡国皆见"
        → 朝堂据此下诏罪己、减膳、求直言
        → 政争中被用来攻击三公"理阴阳不称职"

```

**读法四：只比较两极——"两头真，中间假"**

还有一种读法最微妙，也最接近历史现场：天象是真的，政治后果也是真的，但**把它们连起来的那条因果，是事后加上去的**。这就是板块 8 要解剖的东西。

**为什么这个例子重要**：一次自然现象，先被解释为可理解的天体运行（模型），再被分配给人间责任方（投射），最后变成一次具体的政治行动（叙事）——**星相知识真正的运转方式，就藏在这三步转手里**。而三步之间任何一个环节的"松动"（天象其实是伪造的、分野用的是另一套体系、记录写在事件之后），都会让最终结论走样。这正是后面板块做辨伪时的入手处。

> **可迁移的经验**：拿到任何一条记载，先别急着判真假，先把它拆成四层、分别给每层评级。你会发现"真假"从来不是一个整体判断，而是四个局部判断的叠加——这正是 1_4 那把解剖刀的用法。

### 1_7 本板块的笔记方法：术语卡 + 四问速查卡

**术语卡（正面写术语，背面写三件事）**

```markdown

## 术语：分野

- 一句话释义：天区与州国的对应系统
- 判定标准：有规则、有操作流程，预测力不可靠（第三层 · 投射）
- 常见误用：不同文献分野表有差异，引用必须标版本
- 我见过它的一次：（填入你读到的一条原文）

```

**四问速查卡（每读一段原文填一次）**

| 四问 | 你的答案 |
| --- | --- |
| 一、观测层：能回算吗？ | 实 / 疑 / 伪 |
| 二、模型层：依据什么框架？ | 盖天 / 浑天 / 星占规则 |
| 三、投射层：用哪套分野？ | 某某体系（注明出处） |
| 四、叙事层：谁记的、什么立场、事前还是事后？ |  |

> **验收小标准**：连续 20 段原文都能填出这张表，第一阶才算过关。填不出第三问，说明术语还没过关；填不出第四问，说明你只是在翻译，没在读。
