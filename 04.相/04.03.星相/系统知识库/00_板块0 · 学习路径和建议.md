## 板块0 · 学习路径和建议

> **本板块解决什么问题**：在接触任何具体知识之前，先把**顺序、工具、验收标准**钉死。

星相知识的失败通常不是"不够努力"，而是"顺序错了"——先背宿名、先读谶纬、先验证预言，三条路都会返工。

### 0_2 使用建议与边界声明

**三条使用建议**：

1. **先分类型，再谈对错**：读到任何一条星相记载，先判断它属于实测、建模、投射还是叙事（四副面孔见 `1_1`）；类型不同，检验标准就不同。
2. **原典优先，二手让路**：引用务必回到原典并标注版本与出处——同一条天象在不同典籍里常被改写，二手转述尤甚。
3. **十周按表走，不跳级**：每周只完成当周任务并填路径卡，工具与验收口径见 `0_5` 与 `0_6`。

**边界声明（三条）**：

1. **性质**：星相含古代天文实测（可验证）与谶纬占验叙事（传统话语）两层，本库对两层分别标注，不作混同；占验部分属传统文化内容，未经现代科学检验。
2. **效力**：它能提高阅读史料、理解古人宇宙观与政治叙事的能力；**不能预测人事吉凶**，也不能作为任何现实决策的依据。
3. **用途**：天象记录、历法推算与仪器复原部分可供天文史与科技史研习；分野、星占与谶纬部分仅作思想史与文化研究材料（批判口径见 `README_6`）。

### 0_3 新手入门顺序：三先三不先

**先做的三件事**

1. **先建立模型，再进入细节**——先弄懂"星空＝朝廷"这个总隐喻，再去背二十八宿。没有模型，宿名是 28 个无意义音节；有了模型，它们是 28 个行政区的名字。
2. **先读实测，再读占验**——晷影长度、交食周期、五星行度是可验证的硬知识，先拿下它们，判断力就有了锚点；占验层是软知识，需要锚点才能不被带着跑。
3. **先读正史天文志，再读谶纬**——前者是官方、成体系、可考据的；后者是民间、层累、真伪混杂的。顺序颠倒，你会用《推背图》的逻辑去理解《天官书》，整个认知就歪了。

**暂时别做的三件事**

1. **别从《推背图》流传最广的批注本入手**——它是民国年间伪托的本子，你学到的"标准答案"本身就是二手附会。
2. **别一上来就背二十八宿全称表**——先记住四象分组（东方苍龙、北方玄武、西方白虎、南方朱雀各七宿）和每组的第一宿，其余随用随查。
3. **别急着"验证预言准不准"**——在掌握层累机制之前做验证，只会强化错误直觉。

### 0_7 学习自检五问（每次读完一段原文都问一遍）

1. **这是观测，还是解释？**——原文这句话是可测量的事实，还是事后赋予的意义？
2. **这是原文，还是后人的注？**——尤其在《天官书》里，正文与论赞是两种声音。
3. **这是哪个年代的文本？**——成书年代与所记事件年代，谁在前？
4. **这条记录有没有被回算验证过？**——能验的验，不能验的标注为"待考"。
5. **它今天还能迁移到哪儿？**——想不出迁移点，说明这段还没真正读懂。

### 0_9 案例小故事：两条各花三周的弯路

**故事一：从谶纬批注本入门的三周**

**起因**：一位读者对"预言"感兴趣，想知道古人到底算准过没有。他没有先看书目，直接在网上买了流传最广、带"标准答案"的谶纬批注本。

**三周里他做了什么**：

+ **第一周**：照着批注一条条对历史——第二象画了一盘 21 颗果子、第 4 颗没有把儿，批注说这是唐朝 21 帝、第 4 位是武则天；第三象"日月当空"合为"曌"。他越对越兴奋，把对应关系抄满了半个本子。
+ **第二周**：开始背这些对应，还四处找"更准"的解读帖，觉得自己在接近真相。
+ **第三周**：信心十足地翻开《史记·天官书》，想看看"正史怎么说"。

**撞墙**：一翻开就懵了——北斗归中宫、紫宫即紫微垣，跟他背的那套"三垣"怎么都对不上。他先怀疑原文有错，又怀疑自己买到了盗版，最后甚至怀疑司马迁写错了。

**真正的原因**：两个错叠在了一起。一是**框架用错了时代**——《天官书》是五宫体系，"三垣"要到隋唐以后才成熟，差了近一千年。二是**底本本身就是二手的**——他手上那本批注本，据考证是民国年间伪托之作，他背的"标准答案"本就是后人的附会。

**他后来怎么补的**：退回板块 1，先把"四层"和术语过一遍；再退回板块 2，改用五宫框架重读《天官书》；最后才回到谶纬。同样的内容重走一遍只花了两周，但这一次他分得清哪句是原文、哪句是后人加的。

**故事二：先背二十八宿全称表的三周**

**起因**：另一位读者走的是"苦功路线"。他听说二十八宿是星相的地基，于是打印了一张全称表，打算先背下来再往下读。

**三周里他做了什么**：

+ **第一周**：每天早起背一遍——角亢氐房心尾箕、斗牛女虚危室壁、奎娄胃昴毕觜参、井鬼柳星张翼轸。第五天能默写。
+ **第二周**：开始混。"奎娄胃昴毕觜参"和"井鬼柳星张翼轸"总是错位，四象归属也开始打架。
+ **第三周**：基本全忘。他很沮丧，觉得自己记性差，一度想放弃。

**转折点**：有人问他一句——"角宿是什么？"他答："东方苍龙第一宿。"对方又问："那它是干什么的？"他答不上来。

**他后来怎么改的**：换了顺序。先记住"星空＝朝廷"这个总隐喻，再记住四象分组和每组第一宿，然后给每一宿找一个"行政职能"——角是龙角即天关、昴是华夷分界所在、井主水事、轸是车厢、心是天王明堂。

**结果**：同样的三周，宿名从 28 个无意义音节，变成了 28 个有地址、有职能的行政区。他后来再没忘过。

**两条弯路的对照**

```latex
弯路一：框架错代   → 勤奋越多，错得越深（而且错得越自信）
弯路二：知识无挂钩 → 背多快，忘多快（而且会怀疑自己记性差）
        ↓
共同解药：先定框架的年代，再入细节；
          先给知识找挂钩，再谈记忆

```

> **可迁移的经验**：入门阶段最大的风险不是"不够用功"，而是**用错框架而不自知**——框架错了，你越努力就越自信地错下去，而且会把责任推给原文、推给版本、推给记性。所以本库把"立骨架"放在第一阶、把谶纬放到最后：不是谶纬不重要，而是它最容易让新手在第一周就建立错误直觉；而错误直觉一旦建立，后面每一课都得先拆掉再重建。

### 0_10 本板块的笔记方法：路径卡

学习路径本身也需要被记录和修正。建议做一张**路径卡**，每次阶段性复盘时更新：

```markdown

## 路径卡 · 第__周

- 本周实际读了：（板块 / 篇章）
- 硬产出：（文件名或一句话描述）
- 卡住的地方：（具体写不出来的那一题）
- 卡住的原因：□ 术语不懂 □ 框架用错 □ 缺实测锚点 □ 原文真伪未辨
- 下一步调整：（如：把交食提前 / 补一张术语卡）

```

**为什么必须写"卡住的原因"**：星相学习中的卡壳，绝大多数属于上述四种原因之一。归类之后你会发现，自己反复卡在同一个原因上——那就是真实短板，而不是"记性差"。
