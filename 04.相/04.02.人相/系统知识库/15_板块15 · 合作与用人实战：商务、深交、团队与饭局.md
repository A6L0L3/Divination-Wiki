## 板块15 · 合作与用人实战：商务、深交、团队与饭局

> **本板块定位**：把通用流程落地到商务合作、婚恋深交、团队用人三类场景，并单列"饭局识人"这一高效观察场。
>
> **通用前提**：观察用于生成追问方向与调整自己的行动，不用于审判他人。

---

### 15_1 商务合作（30天版）

| 阶段 | 动作 | 观察重点 |
| :--- | :--- | :--- |
| **第1步 · 饭局** | 组一次饭局（**最有效的观察场**） | 点菜（是否顾及他人）、进食（开大合小）、敬酒（笑容真伪）、**结账时对服务人员的态度** |
| **第2步 · 谈判** | 谈具体条款 | 模仿同步（提诉求的好时机）、脚尖方向、原则性议题上的微反应 |
| **第3步 · ****⭐****️ 小额试探** | 先做一单小额、短周期、可交付的合作 | **这是最可靠的方法**（对应"工作样本测试"） |
| **第4步 · 第三方口碑** | 向其过往合作方打听 | 承诺兑现率、利益冲突时的选择、对待弱者的口碑 |
| **第5步 · 30天复盘** | 卡片B打分 + 红线排查 | 输出决策 |

#### 案例一：一次"上错菜"暴露的合作风险

两位公司负责人在饭局上谈一个合作，气氛很好，条款也谈得差不多了。

席间服务员上错了一道菜。其中一位立刻提高音量："你们怎么回事？这也太不专业了！"服务员连连道歉，他还在继续数落。

另一位负责人当时没多想，只觉得"这人比较较真"。

但因为有了这个印象，他在后续的小额试探中**特意加了一个观察点**：观察对方在项目出问题时的第一反应。

果然，项目进行到第三周出了一次小延期。对方的第一反应是：全盘推给合作方，措辞激烈，并且在没有核实的情况下就发了一封指责邮件。

他最终没有推进大合作。理由写得很清楚：

```plain
证据一（微习惯，饭局低利害场景）：对服务人员的态度
证据二（行为选择，工作压力场景）：出问题时的归因方式
证据三（第三方口碑）：前合作方提到"出了问题很难沟通"

三个证据来自三个维度、三个场景，方向一致。
结论：不是能力问题，是协作风险高。

```

> 这个案例展示了完整的多维度交叉验证：**不是因为一顿饭就否定了一个人，而是饭局提供了第一条线索，后续两次观察完成了验证。**

### 15_2 婚恋与深交（90天版）

| 观察点 | 具体做法 | 为什么关键 |
| :--- | :--- | :--- |
| **冲突时的反应** | 观察一次小分歧的处理方式 | ⭐️ 顺境看不出人品，**冲突才是人性的显影液** |
| **金钱观** | 消费结构、分账态度、对"占便宜"的反应 | 金钱是价值观最直接的显影 |
| **对待家人** | 与父母、兄弟姐妹的相处 | 对最亲近之人的方式，是关系的底色 |
| **长期一致性** | ⭐️ 三个月内言行是否一致 | 短期可表演，长期难 |
| **对待弱者** | 对服务员、动物的态度 | 最强单一指标 |

#### 深交场景的三个"自然实验"时刻

1. **一起赶时间时**（错过车、排队久）→ 看压力下的情绪基线
2. **一起处理一次小意外**（点错菜、走错路）→ 看归因方式与幽默感
3. **对方疲惫时** → 看修养的底线（人在疲惫时最容易露出真实底色）

#### 案例二：三个月才看清的一件事

一位朋友分享过她的经历。

恋爱初期，她觉得对方"温柔、体贴、从不发脾气"。两人相处了两个月，几乎没有过任何争执——他总是让着她，说话也温和。

转折发生在第三个月。两人一起赶高铁，因为堵车，检票口提前关闭，他们错过了那班车。

她当时很慌，正在查改签。而对方当场变了脸，先是对她冷嘲热讽——"我早说了要提前出门，你非要磨蹭"——然后转身对车站工作人员大声发难，要求"给个说法"。

她当时没有发作，只是默默记下了这件事。回家后她在日志里写：

> **"在低压力场景下温和，在赶时间 + 出错的场景下会攻击与迁怒。"**

但她没有立刻下结论。她知道单次行为可能是意外。

接下来的三个月里，类似场景出现了三次：一次是餐厅上菜慢，一次是导航走错路，一次是她自己生病打乱了行程。三次的反应完全一致——**先攻击最亲近的人，再迁怒外部。**

行为签名稳定了。她在第六个月选择了结束关系。

她后来说过一句话：**"我不是因为他发一次脾气就否定他。我是因为三次同样的情境下，他的反应完全一致。"**

> 这就是"多次聚合"的力量：单次行为可能是意外，三次同样的反应就是模式。**而"赶时间 + 出错"这个特定情境，是所有关系里最值得观察的一种。**

### 15_3 团队用人（配置版）

#### 决策层与执行层的配置思路

| 层级 | 需要的类型 | 理由 |
| :--- | :--- | :--- |
| **核心决策层** | ⭐️ **"逆合型"**（敢于内部碰撞但目标一致） | "此逆而合者，其贵非常"——**能驾驭矛盾的人才更出色** |
| **执行层** | **"顺合型"**（配合流畅、减少摩擦） | "顺者多富"——配合流畅带来效率 |
| **识别方法** | ⭐️ **观察一个人被否定时的反应** | 立刻反击 = 纯刚；默默退缩 = 纯柔；**表面接受但暗中调整策略 = 外柔内刚** → **第三种最值得重用** |

#### 五形与岗位适配

| 主形 | 适配方向 |
| :--- | :--- |
| **木** | 教育、创作、策划、研究 |
| **火** | 创业、开拓、演艺、先锋业务 |
| **土** | 实业、后勤、长期资产管理 |
| **金** | 管理、风控、执行攻坚 |
| **水** | 外交、公关、资源整合 |

#### ⭐️ 管理者的"尽责性优先"原则

现代研究一致显示，尽责性是预测工作绩效最稳定的人格维度。**在"能力强但不靠谱"与"能力中等但极靠谱"之间，长期看后者往往产出更高**——因为能力可以培养，而尽责性极难改变。

#### 案例三：把"纯刚"的人放对了位置

一位团队负责人手下有位技术骨干，能力很强，但有个问题：**一点就炸**。方案被否定时会当场反驳，声音越来越大，协作部门怨声载道。

负责人试过沟通、试过提醒，都没用。他一度考虑调岗或劝退。

后来他换了个思路——不再试图改造这个人，而是**调整任务结构**：

1. 把他从需要大量横向协同的岗位，调到**独立攻坚**的技术难题上
2. 明确规定：涉及跨部门的结论，需经二次确认后再发出
3. 给他配了一个擅长沟通的搭档，负责对外同步

一年后，这位骨干攻下了三个关键技术点，协作投诉基本消失。

负责人在复盘里写了一句话：**"刚柔不可改，但场景可设计。"**

> 这个案例与板块3里"把冲劲型放错位置"的案例是同一条原则的正反两面：**静态特质（无论是五形还是刚柔）的正确用法是"匹配"，不是"改造"。**

### 15_4 饭局识人：一个被低估的高效观察场

饭局之所以高效，是因为它同时具备三个条件：**时间较长、可能摄入酒精（降低防御）、有服务人员（提供弱者场景）**。

#### 饭局七个观察时刻

| 时刻 | 观察什么 | 信号 |
| :--- | :--- | :--- |
| **入座** | 是否顾及他人座位、是否主动照顾 | 默认是否以自我为中心 |
| **点菜** | 是否问忌口、是否只点自己爱吃的 | 共情与视角切换能力 |
| **进食** | 开大合小、不挑不拣 vs 挑剔、出声 | 自律与教养的自动化层面 |
| **敬酒** | 笑容是否真诚（眼轮匝肌是否参与） | 社交表演 vs 真实情绪 |
| **对服务人员** | ⭐️ 语气、是否道谢、出错时的反应 | **最有价值的单一指标** |
| **结账** | 是否清楚、是否占小便宜 | 利益面前的默认设置 |
| **散场** | 是否帮忙收拾、是否照顾他人回家 | 无人监督时的修养 |

> ⚠️ **打折提醒**：饭局属于**群体场景**，证据打7折；若饮酒，后半程接近无效采样。
>
> ⭐️ **核心规则**：**饭局上不拍板，饭局后的小额合作才算数。**

---

### 15_5 本板块小结

+ **商务合作**：饭局 → 谈判 → ⭐️小额试探 → 第三方口碑 → 30天复盘；三维度交叉才下结论。
+ **婚恋深交**：冲突、金钱、家人、三个月一致性、对待弱者；"赶时间 + 出错"是最值得观察的情境。
+ **团队用人**：决策层用"逆合型"，执行层用"顺合型"；**尽责性优先**；刚柔不可改但场景可设计。
+ **饭局**：七个观察时刻，证据打7折，不拍板。
+ 三类场景的共同原则：**观察是为了调整自己的行动（设计条件、设边界、选匹配），不是为了给人下判决。**
