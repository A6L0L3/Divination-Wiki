## 板块13 · 笔记与验证：让判断可以被检验

> **本板块解决两件最容易被忽略的事**：**观察笔记怎么记**、**判断怎么验证**。
>
> 很多人的理由是"记在脑子里"。但记忆会**自动美化自己的判断**（后见之明偏差）。**先记录、后验证**是唯一可靠的做法。

---

### 13_1 观察日志：标准模板（可直接复制）

```markdown

## 观察日志 · [姓名/代号]

**日期**：
**场合**：正式 / 放松 / 压力 / 群体 / 一对一
**情境条件**：有无利害关系？有无权力落差？是否跨文化？
**采样有效性**：有效 / 打折（___折）/ 无效（原因：___）

### 一、客观记录（只记事实，不记判断）

- 三停比例：上:中:下 ≈ ___
- 五形归属：主形 ___ + 兼形 ___
- 形与骨：颧骨 ___；形神是否匹配 ___
- 神与眼神：稳定性(1-5) ___；清澈度 ___；收放感 ___
- 气色：面色 ___；印堂 ___；与个人基线对比 ___
- 声音：声 ___；音 ___；语速与填充词 ___
- 动相：行/坐 ___；微习惯（对服务人员 / 时间观念）___
- 言语：我们vs我 ___；细节密度 ___；归因方式 ___

### 二、谨慎解读

- 行为签名："在___条件下，他会___"（条件句，不用标签）
- 支撑证据（≥3个，来自不同维度）：1)___ 2)___ 3)___
- **反向证据**：___
- 情境解释排查：是否可能是情境 / 角色 / 利害关系所致？___

### 三、待验证项（禁止写死结论）

- 需要再验证的：___
- 计划验证方式：小额试探 / 换情境观察 / 第三方印证
- 复评日期：___

```

### 13_2 记笔记的四条纪律

| 纪律 | 内容 | 为什么 |
| :--- | :--- | :--- |
| **1. 先事实后判断** | 客观记录栏只写可验证的事实（"停顿两次""句尾音量下坠"），不写结论（"他心虚"） | 结论会污染后续的反向证据收集 |
| **2. 强制写反向证据** | 每份日志必须至少写一条与判断相反的证据 | 对抗确认偏误 |
| **3. 必带情境标注** | 场合、利害关系、权力落差、文化基线 | 没有情境的证据无法校正 |
| **4. 用条件句** | "在X条件下，他会Y" | 条件句可证伪，标签不可 |

#### 记录频率建议

+ **日常**：每次重要会面后 5 分钟内补记（记忆衰减最快在头30分钟）
+ **关键关系人**：建立独立页面，累积式更新
+ **复盘**：每月回看一次，每季度做一次命中率统计

---

### 13_3 五种验证方法（按可靠性从高到低）

#### ⭐️ 方法一：小额试探（最可靠）

**原理**：用真实任务替代观察。对应"工作样本测试"，是所有方法里效度最高的一类。

| 要素 | 做法 |
| :--- | :--- |
| **规模** | 小：一单短期、可交付、出问题也能承受的合作 |
| **关键** | 必须有**明确交付物 + 明确时间节点** |
| **观察点** | 交付质量、沟通主动性、出问题时的第一反应 |
| **判读** | 小额合作中的表现，比任何静态观察与谈吐都真实 |

#### ⭐️ 方法二：承诺兑现率统计（最硬）

可量化、可追踪、无法辩解。为每位核心关系人统计近6个月的兑现率与"未兑现是否提前告知"。

```plain
兑现率 > 80% 且提前告知率高   → 可靠
兑现率 50-80%                 → 需结构化跟进（明确节点 + 定期跟进）
兑现率 < 50% 且不告知         → 触发红线排查

```

#### 方法三：换情境观察（破除表演层）

在**至少三种不同情境**下观察同一个人：正式场合、放松场合（饭局）、压力场合（被批评 / 赶时间）。

记录"表演层"与"底图层"的差距。**差距本身就是信息**——差距大说明此人表演动机强，需要在低利害场景下重采。

#### 方法四：熟人盲测（校准个人偏差）

找5个你非常了解的人，先写观察记录，**再**对照已知事实。两周内即可校准你的偏差系数。

**常见偏差自检**：

+ 我是否对"话少"的人打分系统性偏低？
+ 我是否对"长得好 / 声音好听"的人给光环？
+ 我是否总把"紧张"误读为"心虚"？
+ 我是否对与自己相似的人天然更有好感？

#### 方法五：双盲练习（找认知盲区）

与同伴对同一个陌生人各自独立记录，当场比对。**分歧点就是你的认知盲区。**

### 13_5 案例一：一份日志如何避免了第二次误判

一位 HR 记录过两份相邻时间的日志，对象都是同一位候选人。

**日志一（面试场景，第1天）**

```plain
客观记录：
- 眼神稳定，可对视3秒以上
- 表达流畅，语速均匀
- 描述上一段项目时，给出了两个具体数字
- 被追问"这个数是怎么算出来的"时，停顿约2秒，说"我记得是按月活口径，但具体公式我不太确定"

谨慎解读（一级·假设）：
- 假设：表达能力强于实操能力
- 反向证据：他主动承认"我不太确定"，这在面试中是需要底气的
- 待验证项：做工作样本测试，看现场分析能力

```

**日志二（工作样本测试，第5天）**

给了一份真实的用户数据，要求给出三条结论与支撑依据。

```plain
客观记录：
- 30分钟内交回，三条结论条理清晰
- 结尾主动加了一句备注：
  "这两条结论的样本口径可能有问题，我只取了活跃用户，
   如果把沉默用户算进来结论会变，我不太确定该用哪个口径"

```

**回填表（第5天）**

```plain
待验证项：现场分析能力是否弱于面试表现
预期：细节答不上来，或交不出东西
实际：准时交付，且主动标注了样本口径的不确定性
是否命中：否（原假设被证伪）
偏差原因：把"谨慎"误读成了"不熟练"

```

HR 在回填表末尾写了一句话：**"细节密度偏低被证伪——他不是不会，是谨慎。而且主动标注不确定性，是高尽责性信号。"**

最终这位候选人被录用，后来成了团队里数据质量把关最严的人。

> 这个案例的关键不是"看人准"，而是三件事：

第1步 她把判断写成了**可证伪的假设**，而不是结论；
第2步 她记下了**反向证据**（主动承认不确定）；
第3步 她在5天内**真的去验证了**，并把结果回填。

### 13_6 案例二：两万块的小单，避开两百万的错

一位创业者讲过他的"小额试探"习惯。

他每次考虑一个重要合作方，都不会在第一次谈完就定，而是先给一个**两周内、金额很小、出了问题完全能承受**的任务。他管这叫"两万块的试探"。

有一次，一位合作方在饭局上表现得非常好：懂行业、有资源、承诺清晰，还主动说"我们可以先做一期试试"。

按过去的习惯，他可能当场就定了。但这次他给了一个很小的单：两周内交付一份行业梳理，明确要求"包含三个竞品的定价对比"。

结果是：对方**准时交付**，而且中途主动同步了两次风险——一次是说某个竞品的定价数据拿不到公开渠道，一次是说原定的三个竞品里有一个已经转型，问要不要换。

他据此推进了大合作。三年下来，合作顺畅。

他说过一句很实在的话：**"两万块的小单，帮我避开了一次两百万的错。而且它帮我避开的不是'坏人'，是'不合适'——很多人不是不可靠，只是跟我的节奏不合。"**

> 这个案例补充了一个重要认知：**小额试探的价值不只是"防坏人"，更是"验匹配"。** 大多数人不是坏，只是不合适。

---

### 13_7 本板块小结

+ **笔记四纪律**：先事实后判断、强制反向证据、必带情境、用条件句。
+ **记录频率**：会面后5分钟内补记；关键关系人独立页面；每月回看、每季统计。
+ ⭐️ **验证方法排序**：小额试探 > 承诺兑现率 > 换情境 > 熟人盲测 > 双盲。
+ **回填与复盘**：验证必须回填；季度做命中率统计与偏差分布。
+ 判断的价值不在"对"，而在**可被检验**。
