## 板块12 · 识人流程：从30秒到30天的作业主线

> **本板块定位**：把前面所有维度串成一条**可执行的时间线**。知识不缺，缺的是"什么时候看什么"的顺序感。
>
> **本板块讲"流程时间线 + 三层九问"；笔记怎么记、判断怎么验证，见板块13。**

---

### 12_1 总流程：五阶段时间线

```plain
【阶段一】远观 5秒        → 三停、五岳、五形、整体姿态、气色总览
      ↓
【阶段二】近察 30秒       → 五官成破、眼神质量、印堂状态
      ↓
【阶段三】对话 5-15分钟   → 断点采样、声音、言语内容、动相
      ↓
【阶段四】情境校正        → 标注情境、跨情境比对、行为签名
      ↓
【阶段五】验证 1-3次      → 小额试探、八观八验、卡片B评分

```

#### 每个阶段的产出物与禁止事项

| 阶段 | 产出 | 禁止 |
| :--- | :--- | :--- |
| 远观 | 一句"基本盘"描述 | 禁止推性格 |
| 近察 | 形、神、气色的分项记录 | 禁止断吉凶 |
| 对话 | 假设清单 + 追问方向 | 禁止把假设当结论 |
| 情境校正 | 行为签名（条件句） | 禁止贴标签 |
| 验证 | 卡片B评分 + 决策 | 禁止跳过此阶段做重大决策 |

### 12_2 三个时间颗粒度的操作法

| 时长 | 做什么 | 对应工具 |
| :--- | :--- | :--- |
| **30秒**（初见） | 远观：站姿、步态、三停、五形、整体气色 → "基本盘"一句话 | 静态扫描法（板块2） |
| **3分钟**（近察 + 寒暄） | 近看眼神、印堂、脸色；听开口第一声；观察坐姿与手势 | 板块4 + 板块7 + 板块8 |
| **30天**（验证） | 跨三种情境观察；统计承诺兑现；做一次小额试探 | 卡片B（板块10）+ 八观八验（板块8） |

#### 30秒扫描清单（可打印随身）

```plain
┌──────────────────────────────────────────────┐
│                 30秒远观扫描                 │
│ 第1秒：站姿与肩架 —— 端 / 塌 / 僵            │
│ 第2秒：步态重心   —— 稳 / 飘 / 急            │
│ 第3秒：体型归属   —— 木瘦/火尖/土厚/金方/水圆│
│ 第4秒：三停比例   —— 匀 / 上长 / 中长 / 下长 │
│ 第5秒：整体气色   —— 明润 / 枯暗 / 浮散      │
│ 输出：一句"基本盘"描述，不推性格             │
└──────────────────────────────────────────────┘

```

#### 3分钟近察清单

```plain
┌──────────────────────────────────────────────┐
│                  3分钟近察                   │
│ 眼神：稳定性 / 清澈度 / 收放感               │
│ 印堂：明 / 暗 / 有无竖纹                     │
│ 面色：明润 / 枯暗（对比个人基线）            │
│ 声音：开口第一声 / 句尾收音 / 语速           │
│ 动相：坐姿 / 手势开放度 / 脚尖方向           │
│ 输出：分项记录 + 追问方向，不下结论          │
└──────────────────────────────────────────────┘

```

### 12_3 三层九问：把三套方法论合流

传统经验中有三套流程可以合并使用：

| 来源 | 流程 |
| :--- | :--- |
| 七维总纲 | 远观（容貌 / 气色）→ 近察（神骨）→ 对话（声音 / 情态 / 刚柔） |
| 孔子识人法 | **视其所以**（看清浊）→ **观其所由**（观贤愚）→ **察其所安**（察心术） |
| 行为验证法 | 八观八验（行为选择） |

#### 合并为"三层九问"

**第一层 · 视其所以（看清浊）—— 远观与近察阶段**

1. 他的整体是"清"还是"浊"？（举止从容有序 vs 混乱浮散）
2. 形与神是否相称？（形好神散要扣分）
3. 当下气色与他的个人基线相比，是正常还是异常？

**第二层 · 观其所由（观贤愚）—— 对话阶段**

4. 他描述过去经历时，细节密度高不高？经不经得起追问？
5. 遇到压力追问时，第一反应是解释、回避还是反击？
6. 他如何归因？成功归内 / 失败归外，还是相反？

**第三层 · 察其所安（察心术）—— 验证阶段**

7. 在**有利益冲突**的场合，他如何选择？
8. 在**无利害、无人监督**的场合，他如何对待弱者？
9. 他在**困境**中的底线在哪里？（观其难）

> 这九问的输出不是"他是好人 / 坏人"，而是**一个带条件的行为签名 + 一份待验证清单**。

#### 九问速查卡

```plain
┌──────────────────────────────────────────────┐
│                   三层九问                   │
│ 第一层 · 视其所以（看清浊）                  │
│   1 清 or 浊？                               │
│   2 形神相称吗？                             │
│   3 气色对比个人基线，正常吗？               │

│   5 压力下第一反应：解释/回避/反击？         │

│                                              │

│   7 有利益冲突时怎么选？                     │
│   8 无人监督时怎么对待弱者？                 │
│   9 困境中的底线在哪？                       │
│                                              │
│ 输出：行为签名 + 待验证清单（不是结论）      │
└──────────────────────────────────────────────┘

```

### 12_4 案例一：一次完整走完五阶段的招聘

某公司要招一位客户成功负责人，HR 和用人部门一起走了一次完整流程，我们把他们的记录还原如下。

**阶段一 · 远观（候选人从等候区走来）**
记录："步态稳，肩架端，体型偏方正（金形倾向），三停大致匀称，面色偏暗。"
输出："基本盘：形整、步稳；当下气色偏暗。"

**阶段二 · 近察（开场3分钟）**
记录："眼神可自然对视3秒以上，但收放感一般（偏外放）；印堂无明显竖纹；开口第一声从容，句尾收得住；坐姿稳定，无小动作。"
输出："神偏'露而不浮'，声稳，动相好。气色偏暗需追问原因。"

**阶段三 · 对话（30分钟结构化 + 10分钟压力测试）**
记录：

+ 讲上一个项目时，给出了具体数字（"续约率从61%提到78%，用了七个月"），且被追问两次都答得上细节
+ 压力测试（追问离职原因）时，第一反应是停顿一秒，然后直接解释，没有回避也没有反击
+ 描述团队成绩时，通篇用"我们"，但能清楚说出自己具体做了什么

输出："言语细节密度高、归因健康、压力下反应模式是'直接解释'。三项同向。"

**阶段四 · 情境校正**
标注："本次为正式面试（高利害 + 权力落差），动相与神的两项打5折。"
行为签名（初稿）："在被突然追问时，他会先停顿一秒再直接解释，不回避也不反击。"

**阶段五 · 验证**

+ 工作样本：现场给一组客户流失数据，要求给出三条结论 → 交付合格
+ 背调：前东家反馈"交付稳定，但跨部门沟通偏直接"
+ 承诺兑现（试用期内）：八次承诺，八次兑现，其中一次提前告知了延迟

**结论（卡片B）**：八观八验 34/40，承诺兑现 28/30，压力反应 13/15，对待弱者 12/15 → **87/100**，录用。

> 这次流程的价值在于：**每一个阶段的产出都是明确的、可追溯的。** 如果后来判断出错，他们能一眼看出是哪个阶段出了问题。这是"凭感觉"做不到的。

#### 案例二：卡在第三层的那次合作

一位做会展服务的创业者在一次行业活动上认识了一位潜在合作方。

两人聊得很投机，对方当场提出了合作意向，说下周就可以签。创业者用"三层九问"在心里过了一遍：

**第一层 · 视其所以（看清浊）—— 通过**
举止从容，说话有条理，气色明润。九问的前三问都能给出正面描述。

**第二层 · 观其所由（观贤愚）—— 通过**
他问了几个过去项目的具体情况，对方给出了时间、规模、合作方名称，被追问两次也都答得上。归因方式是"成功归团队 + 自己做了什么"，比较健康。

**第三层 · 察其所安（察心术）—— 卡住了**
他发现自己没法回答三个问题：

+ 在**有利益冲突**的场合，这个人怎么选？（没见过）
+ 在**无人监督**的场合，他怎么对待弱者？（没见过）
+ 他在**困境**中的底线在哪？（没见过）

按流程，前两层只需要几十分钟，第三层需要**时间**。他当时做了一个决定：不拒绝，也不签，而是说"我们先做一单小的，跑通了再说大的"。

对方对这个提议反应冷淡，说"要不就按大的来，小单没什么意思"。

创业者坚持了小单。后来他从第三方渠道了解到：这位合作方此前有两次在项目出问题时把责任推给下游供应商的记录。

他最终没有推进。事后他在日志里写：

> **"前两层我半小时就能过，第三层我一个月都未必能过。我不是因为他不好才停——我是因为我还没看到第三层。"**

> 这个案例说明流程里最重要的一条纪律：**第三层（察其所安）通常需要时间和情境，无法在一次会面里完成。** 跳过它直接下结论，是绝大多数误判的根源。流程的意义恰恰在于**让你知道自己在第几层**。

### 12_5 本板块小结

+ **五阶段**：远观 → 近察 → 对话 → 情境校正 → 验证，每阶段有明确产出与禁止事项。
+ **三个颗粒度**：30秒基本盘、3分钟近察、30天验证。
+ **三层九问**：视其所以（看清浊）→ 观其所由（观贤愚）→ 察其所安（察心术）。
+ 流程的意义不在"更准"，而在**可追溯**——出错时能定位到具体环节。
