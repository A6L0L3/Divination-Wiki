## 观形知神 · 人相识人系统知识库

### README · 总体概览与使用说明

> **这套知识库要解决一件事**：把散落在传统识人经验与现代行为观察方法里的碎片，重构成一套**有顺序、有权重、有证据规则、有情境校正、有校准机制**的识人系统。
>
> **它不是判断他人命运的工具。** 传统经验里真正值钱的部分，不是"某种鼻型必富、某种眼型必贱"的断语，而是四样东西：**一套分层观察的次序**、**一条反对单点定罪的纪律**、**一套情境校正的方法**、**一面反观自己的镜子**。断语会过时，这四样不会。

---

### 一、使用前提（三条必须遵守）

1. **所有判断一律读作"倾向与概率"**，不读作"定论与宿命"
2. **所有健康相关表述只是就医提示**，不构成医学诊断；身体不适应就医，不做面部推断
3. **严禁**将本知识库内容用于招聘录用、晋升、信贷审批、司法判断、保险定价等涉及他人重大权益的决策依据——这既是科学要求，也是法律与伦理底线

### 四、三条贯穿全书的铁律

1. **三证据原则**：任何一个实质性判断，至少三个来自**不同维度**的独立证据同向
2. **五不看原则**：酒、怒、病、色、乱五种状态不采样；表演场景、跨文化场景、权力落差场景三类场景证据打折
3. **条件句原则**：把"他是什么人"改写成"他在什么条件下会怎样"

### 五、权重总序（一眼记住先后顺序）

```plain
神与眼神（最难伪装）  ★★★★★
长期行为与微习惯      ★★★★★
情态与刚柔（初见最真）★★★★
气色（短期难控制）    ★★★★
声音（可训练难突变）  ★★★
动相（习惯性动作）    ★★★
骨相（定底盘不定吉凶）★★★
五官形态（可修饰）    ★★

```

> **核心逻辑**：**越难伪装的东西，越接近真实。** 语言最容易伪装，眼神与长期行为最难伪装。

### 六、一个总公式（全书骨架）

```plain
底盘（形与骨）  ×  内核（神与气、情态与刚柔）
  ×  状态（气色）  ×  表达（声音 + 动相 + 言语）  ×  情境

```

**为什么是乘法**：任何一项严重塌陷，整体都会塌。一名形骨俱佳、口齿伶俐的候选人，若在压力追问下眼神涣散、细节前后矛盾，乘出来接近零。
