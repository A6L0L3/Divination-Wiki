## 板块3 · 形与骨（下）：骨相、十二宫与五形兼体

> **本板块接续板块2**，讲静态底盘的另外三块：**骨相四处**、**十二宫坐标系**、**五形兼体**。
>
> **正确用法**：这三块都用于定"基本盘"与生成假设，**不用于定吉凶、不用于录用决策**。

### 3_1 骨相：被低估的"根本相"

传统经验给出极精炼的结构判断：**"骨为君、肉为臣、气为帅、色为兵。"**

+ **骨（君）**：底层架构，最难改变，决定气质框架
+ **肉（臣）**：附丽于骨，影响饱满度与亲和力
+ **气（帅）**：统摄全局的生命力
+ **色（兵）**：最表层的即时信号

#### 四处关键骨

| 骨 | 位置 | 传统解读 | 现代转译 |
| :--- | :--- | :--- | :--- |
| **额骨** | 额头 | 阔而平 → 少年根基稳 | 早期发育与教育基础 |
| **颧骨** | 两颊 | 丰而隐 → 中年权柄足 | 权力欲与掌控力（**关键指标**） |
| **腮骨** | 下颌角 | 圆而收 → 晚年有承载 | 坚韧度与承载力 |
| **枕骨** | 后脑 | 凸而隆 → 先天禀赋厚 | 意志力与定力的传统象征 |

> 传统"九贵骨"（天庭骨、枕骨、顶骨、太阳骨、眉骨等）可作文化知识了解，**实操价值有限，不建议作为判断依据**。

#### 颧骨：被严重忽视的权力指标

> "颧为两岳，所以佐土星（鼻）而行运也；**无颧中运不发，纵有鼻亦为无辅。**"

| 颧骨状态 | 传统断语 | 现代解读 |
| :--- | :--- | :--- |
| 高而有肉包 | 有权且公正 | 有掌控力且有分寸 |
| 高而露骨无肉 | 乖戾、好勇、主刑冲 | 权力欲强但缺乏柔性，易生冲突 |
| 低 / 凹下 | 无权、做事游移 | 掌控力与主导性偏弱 |
| 横张 / 偏斜 | 行事偏激 | 需结合眼神与行为判断，不可单凭此项定性 |

#### 案例一：把"冲劲型"放错了位置

一位高管要组建新业务团队，特意挑了一位业务强人做二把手，理由很明确：**要用他的冲劲打开局面**。这位强人颧骨高而露，说话斩钉截铁，开会时常常直接拍板。

半年后出了问题：这位二把手与三个协作部门全部闹翻——市场部说他"不打招呼就改需求"，产品部说他"当众否定我们的方案"，客服部说他"出问题时第一反应是甩锅"。

高管很苦恼：这个人能力明明很强，为什么到处是摩擦？

复盘时他换了个角度看：**不是能力不行，而是"高而露骨无肉"所暗示的那种权力欲，缺乏柔性缓冲。** 在需要大量横向协同、需要反复说服别人的岗位上，这类配置的冲突成本极高。

他没有辞退这个人，而是把他调去负责一条**独立攻坚**的业务线——目标明确、边界清晰、不需要天天跟别人协调。

调整后的半年，冲突大幅减少，那条业务线反而成了当年增长最快的一块。

> 这个案例的重点不在"颧骨准不准"，而在于：**把静态特征转译成"岗位匹配问题"，才是形与骨的正确用法。** 看骨相不是为了给人下判决，而是为了给能力找对位置。

### 3_2 十二宫：面部的人生坐标系

十二宫是把面部分区对应人生不同领域的坐标系。以下为精简版实操指南。

#### 前四个核心宫位

##### 命宫（印堂）—— 总开关

+ **位置**：双眉之间，山根之上
+ **宜**：宽大（主智量）、方骨（主大贵）、丰隆（主富贵）、高突（主奇贵）、明润（主顺遂）
+ **忌**：两眉交锁、竖纹破印、凹陷低平
+ **实战应用**：印堂是气色变化的"晴雨表"。印堂发亮，多主近期状态上行；印堂发暗或有杂纹侵入，提示精神压力大或面临重大决策困境（详见板块5）。

##### 财帛宫（鼻）—— 聚与守的显示器

+ **位置**：鼻之全体，以准头（鼻头）为核心
+ **宜**：鼻高耸隆起、端正不偏、鼻头圆润有肉、鼻翼饱满
+ **忌**：鹰嘴尖削、鼻孔朝天、鼻翼单薄
+ **实战应用**：鼻与地阁（下巴）互相朝迎者为上格——代表**"有进有守"**，既能赚钱又能存钱。

##### 夫妻宫（奸门 / 鱼尾）

+ **位置**：眼尾两侧
+ **宜**：丰满（主贤德）、光润（主康健）
+ **忌**：十字纹、坑陷
+ **⚠ 伦理提醒**：此宫的传统断语**不作为对他人的判断依据**，尤其不能出口。合规用途仅作文化知识了解。

##### 官禄宫（额中 / 天庭）

+ **位置**：额头正中，上发际至眉心
+ **宜**：宽阔饱满、骨骼隆起
+ **忌**：窄小低陷、纹路杂乱
+ **实战应用**：在青年运限中占据关键位置（约15-30岁），额头宽阔光洁者多在早年获得较好的事业发展平台。

#### 其余八宫速查

| 宫位 | 位置 | 核心指向 | 关键判断标准 |
| :--- | :--- | :--- | :--- |
| 父母宫 | 额之左右（日月角） | 与父母缘分 | 左日角看父，右月角看母 |
| 兄弟宫 | 眉毛 | 手足关系与情缘 | 眉清而长主有情，短促主缘薄 |
| 田宅宫 | 眉与眼之间 | 不动产与家业 | 宽阔明亮主有产 |
| 子女宫 | 下眼睑（卧蚕） | 子嗣缘分 | 饱满明润主子女贤良 |
| 疾厄宫 | 山根（两眼之间） | 健康状态 | 丰隆无纹主健康 |
| 迁移宫 | 上额两端（驿马位） | 出行与迁动 | 饱满主出行顺利 |
| 奴仆宫 | 面颊下端至下巴 | 下属与社交 | 饱满开阔主得助力 |
| 福德宫 | 天仓至地阁一带 | 精神幸福与晚年 | 丰满圆润主福禄 |

#### 十二宫总断口诀与阶段提醒

```plain
额管少年十五前，眉眼三十定姻缘，
鼻主中年三十至五十，口耳地阁管暮年。

```

> ⚠ **伦理红线**：十二宫中关于婚姻、子嗣、六亲的传统断语，**在现代场景下不作为对他人的判断依据**。它的合规用法是：作为自我观察与"人生阶段提醒"的参考（详见板块16）。

#### 关于传统体系中的女相与童相

传统相学中有专论女性与儿童的部分（如系统化的女相理论与儿童相法），在相学史上属于填补空白的开创性工作。但需要明确两点：

1. **其中的性别刻板内容（针对女性的贬抑式判断）在现代完全失效**，应明确剔除（详见板块18的"应剔除内容"清单）
2. **其方法论内核仍有参考价值**——即"不同人群应有不同的观察基线"。这个思路本身是成立的：正如板块1所述，跨文化、跨代际场景需要不同的基线，不同性别、不同年龄段同样如此

> **现代转译**：不学它的断语，学它的**"先确认基线，再看特征"**这一条方法。

### 3_3 五形：一套体型—气质类型学

五形是一套基于五行的人格—体质分类系统，堪称传统版的类型学工具。

| 五行 | 形质特征 | 性格倾向 | 声音特征 | 适宜气色 |
| :--- | :--- | :--- | :--- | :--- |
| **木形** | 清秀而瘦，骨骼挺拔 | 正直进取，有规划 | 条达清亮 | 青润 |
| **火形** | 尖露而锐，面型上宽下窄 | 热情急躁，行动力强 | 尖锐高亢 | 赤红 |
| **土形** | 浊厚而深，体型敦实 | 稳重守信，反应偏慢 | 沉厚有力 | 黄润 |
| **金形** | 方正而坚，轮廓分明 | 刚毅果断，重义轻财 | 清越铿锵 | 白皙 |
| **水形** | 圆肥而清，体态柔润 | 灵活多变，善于应变 | 柔和圆润 | 黑润 |

#### 兼体取法：处理"纯形极少"的现实

纯粹的单一体型极为罕见，大多数人都是两形或三形相兼。处理规则：

1. **两形相兼**：取分数多者为主，少者为客
2. **两形相等**：则为"相争相混之局"，格局降低
3. **三形相兼**：必须区分主体、兼体、辅佐，再论生克制化
4. **三形相匀**：是为"混乱之局"，需要查其出生时令节气辅助判断

#### 实操五步

1. **远观整体体态**——高瘦倾向木，矮胖倾向水 / 土，棱角分明倾向金，尖削倾向火
2. **近看面部轮廓与肤色**，验证初步判断
3. **听声音**，与形质做交叉验证（金形声清越、土形声沉厚）
4. **判断主形与兼形比例**，确定格局层次
5. **根据生克关系**推断其人生各阶段的顺逆倾向

#### 五形与场景适配

| 主形 | 性格关键词 | 适配方向 |
| :--- | :--- | :--- |
| **木** | 仁：仁慈博爱、有才华、有规划 | 教育、策划、文化艺术、研究 |
| **火** | 礼：热情急躁、好虚荣、行动力强 | 演艺、创业、先锋开拓 |
| **土** | 信：稳重迟钝、讲信用 | 基建、后勤、长期资产管理 |
| **金** | 义：刚毅果断、重义气 | 管理、风控、执法、执行攻坚 |
| **水** | 智：灵活机变、情商高 | 外交、公关、资源整合 |

> ⚠ 五形分类是一种**认知脚手架**，用于快速建立初始印象与岗位匹配假设，**不是定型判决**，更不可用于录用决策。

#### 案例二：用五形给两个人换了个位置

一家公司有两位销售，业绩都不差，但客户类型完全不同。

**小李**：个子高瘦，手指修长，说话条达清亮，喜欢先把方案想清楚再打电话。他签的单大多是**周期长、决策链复杂的大客户**——他愿意花三个月跟进一个单，客户也愿意跟他深聊。

**小王**：身形偏圆润，面色偏润，说话柔和圆转，反应极快。他的单大多是**短平快、靠关系与临场反应拿下的**，一周能签三四单，但大客户基本留不住。

公司原本按"业绩数字"给他们排位，两人都不舒服。

后来管理者用五形框架重新理解这件事：小李偏**木形**（清瘦、有规划、条达），适合长周期、重方案的客户；小王偏**水形**（圆润、灵活、善应变），适合高频、重关系的场景。

调整很简单：**小李专做大客户，小王专做快单与渠道维护**。半年后两人业绩都涨了，抱怨也少了。

> 这个案例的关键不在"分型准不准"，而在：**类型学的价值是"匹配"，不是"评级"。** 五形不告诉你谁更强，只提示谁更适合哪种场景。

### 3_4 静态底盘的三条使用纪律

1. **只用一句话输出**：静态底盘的合规产出是"一句基本盘描述"，不是性格判决。例如："三停匀称、五岳朝拱、形神相称"——到此为止，不再往下推。
2. **必须交叉验证**：任何静态特征都要与神（板块4）、气色（板块5）、行为（板块8）交叉后才能写入日志。
3. **不得用于决策**：在招聘、晋升、信贷等涉及他人权益的场景中，静态特征不得作为依据；它的唯一合法用途是**生成追问方向**。

### 3_5 本板块小结

+ **骨相四处**：额骨、颧骨、腮骨、枕骨；颧骨是最被忽视的权力指标，但需转译为岗位匹配问题。
+ **十二宫**：前四宫（命宫、财帛、夫妻、官禄）加其余八宫速查；涉私德的宫位不可对他人使用。
+ **五形兼体**：纯形极少，按主形 + 兼形处理；价值在**场景匹配**，不在评级。
+ **三条纪律**：一句话输出、必须交叉、不得用于决策。
