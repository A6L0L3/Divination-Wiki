## 板块11 · 量化评分卡：把印象变成可复盘的数字

> **本板块定位**：整套系统的"结算层"。前面采集并经情境校正的证据，在这里汇总、加权、对冲，输出一个**可记录、可比较、可复盘**的结论。
>
> **方法论来源**：传统"加减乘除"与四维百分制，结合现代多因素决策与人事选拔研究重构。

---

### 11_1 两套评分卡：初见卡 vs 长期卡

**绝大多数人误用识人术的根源，是拿"初见印象"去下"长期结论"。** 因此必须强制拆分两套卡：

| 卡片 | 用途 | 性质 |
| :--- | :--- | :--- |
| **卡片A · 初见评估卡**（30分钟以内） | 快速生成假设与追问方向 | ⭐️ **假设生成器**，不是结论 |
| **卡片B · 长期合作卡**（3个月以上） | 重大决策（合作、托付、深交、录用） | ⭐️ **结论生成器** |

> **铁律**：**卡片A的任何分数，都不能直接作为重大决策的依据。**

卡片A唯一的合法用途是：1. 生成追问方向；2. 决定是否值得继续投入观察。**只有卡片B才输出结论。**

#### 关于"承诺兑现率"：头号指标

它可量化、可追踪、无法辩解，且预测力极强。**建议为每一位核心关系人默默统计这个数字。** 半年后，这个数字会告诉你关于这个人的一切。

现代研究也支持这一点：尽责性（守诺、自律、有条理）是预测工作绩效最稳定的人格维度。

### 11_4 为什么"结构化"永远胜过"凭感觉"

这一节回答一个关键问题：**辛辛苦苦练观察力，到底值不值？**

人事选拔领域积累了近百年的效度研究，两版经典元分析给出的预测效度对比：

| 选拔方法 | 经典元分析 | 保守修正版 |
| :--- | :--- | :--- |
| **工作样本测试**（让候选人做实际工作） | .54 | .33 |
| **结构化面试**（同一套问题 + 统一评分标准） | .51 | .42 |
| **一般认知能力测试** | .51 | .31 |
| **非结构化面试**（自由聊、"看文化契合度"） | .38 | **.19** |
| **工作年限** | .18 | .18 |
| **学历** | .10 | — |

（两版数值差异源于统计修正方法的保守程度不同，非证据本身变化。）

#### 四条对识人直接有用的结论

1. **"结构化"与"非结构化"的差距巨大**（.42 vs .19）。同样是"聊一聊"，**有没有固定的问题清单和统一的评分标准**，效果差了两倍多。→ 这就是为什么强调流程与评分卡，而不是"凭直觉"。
2. **工作样本最有效**。→ 这正是"**小额试探**"的科学依据（见板块12）。
3. **"经验年限"和"学历"的预测力很低**（.18 / .10），远低于多数人的直觉。→ 别被简历上的年头唬住。
4. **面试的价值不在"看人"，而在"结构化地采集行为证据"**。→ **追问过去的具体行为，而不是评价当下的感觉。**

> ⚠️ **合规红线重申**：这些现代方法的有效性，恰恰反衬出**面相判断的合规风险**。在招聘等场景中，面相特征不得作为决策依据；观察只用于生成追问方向。

### 11_5 加减乘除：四类运算的实际应用

| 运算 | 思考方式 | 触发条件 | 举例 |
| :--- | :--- | :--- | :--- |
| **加法** | 优势叠加 | 多个维度同向为正 | 神清 + 形整 + 声稳 → 基本盘扎实 |
| **减法** | 短板效应 | 某一维度严重塌陷 | 五官端正但眼神涣散 → **精神分几乎归零**，总分大幅下调 |
| **乘法** | 组合联动 | 特定特征配对才生效 | 鼻好 + 地阁好 = 能赚**且**能守（1+1>2） |
| **除法** | 对冲消解 | 吉凶同现 | 印堂宽阔（吉）但有竖纹破（凶）→ 先成后败 |

#### 完整演算示例：案例甲

```plain
【原始打分】
神清目定(22/25) + 三停匀称(13/15) + 气色偏暗(7/15)
+ 声音沉稳(13/15) + 动相良好(17/20) + 言语有条理(8/10)
= 80分

【情境校正】
本次为正式面试场景（高利害），动相分打7折 → 17×0.7 ≈ 12/20
调整后总分 = 75分

【减法复查】
气色单维度塌陷（7/15，明显低于其他项）→ 触发减法复查
追问发现：近两个月项目压力极大、睡眠不足

【最终判断】
"人的基本面不错，当下状态不佳"
建议：不因这次表现否定能力，择期在非压力场景重测

```

#### 完整演算示例：案例乙

```plain
【原始打分】
神采外露但收不住(11/25) + 五官匀称(12/15) + 气色明润(13/15)
+ 声音有冲劲但句尾散(9/15) + 动相良好(15/20) + 言语细节密度低(4/10)
= 64分

【情境校正】
饭局场景（群体 + 放松），动相打7折 → 15×0.7 ≈ 11/20
调整后总分 = 60分

【簇集复查】
言语细节密度低 + 被追问时转移话题 + 承诺模糊
→ 三个维度同向（言语 / 神 / 行为）

【最终判断】
"表达能力强于交付可信度"
建议：先做一次小额试探，不做重大托付

```

### 11_6 红线否决：有些信号不需要凑齐三条证据

三证据原则是一般规则，但存在例外——**当出现以下红线信号时，可直接否决或立即止损**：

| 红线 | 说明 | 处理 |
| :--- | :--- | :--- |
| 🚩 **反复说谎并被证实** | 不是"记错"，而是被事实证伪的多次虚构 | 直接否决，不再投入观察 |
| 🚩 **系统性不兑现承诺** | 兑现率长期低于一半，且不提前告知 | 降级关系，不再托付关键事项 |
| 🚩 **对弱者的恶意** | 对服务人员、下属、动物表现出真实的恶意而非一时情绪 | ⭐️ 最强单一否决项 |
| 🚩 **攻击性失控** | 冲突中出现威胁、报复、破坏性行为 | 立即设立边界，必要时终止关系 |
| 🚩 **为利出卖关系** | 为利益主动出卖合作伙伴、朋友、前东家 | 直接否决 |

> **为什么这些可以"一票否决"**：因为它们属于**高诊断性信息**——一次真实的恶意行为，比一百次礼貌更能揭示一个人的底线（详见板块15的印象更新机制）。

### 11_7 案例一：一份评分卡救回的一次错误录用

某公司两位面试官对同一位候选人产生了严重分歧：

+ **面试官 A 打 82 分**：理由是"谈吐极佳、气场强、眼神稳、声音有底气"
+ **面试官 B 打 58 分**：理由是"问到具体数据时答不上来，承诺也很模糊"

两人争论了半小时，谁也说服不了谁。

后来 HR 做了一件事：让他们**不要争论结论，而是把各自的分数字段摊开逐项比对**。

比对结果很清楚——分歧全部集中在两项：

```plain
A 的高分来源：神与眼神（22/25）、声音（13/15）
  → 这两项在"面试表演场景"下失真系数最高

B 的低分来源：言语内容（4/10）、动相中的微习惯项
  → 这两项几乎不受表演影响

```

按情境折扣规则，A 的两项应当打折（高利害场景打5折）。调整后两人的分数变成 65 / 62，**结论一致**：

> **进入小额试探，不直接录用。**

后来他们给候选人安排了一次工作样本测试：现场给一份真实数据，要求给出三条结论和支撑依据。

结果是：候选人的现场分析能力明显弱于面试表现——他能讲，但讲出来的东西经不起追问。

HR 在复盘里写：**"如果没有评分卡，这场争论大概率会以'谁职级高听谁的'收场。评分卡做的事情不是让我们变聪明，而是让我们把分歧摆到了桌面上。"**

#### 案例二：被"年限"和"学历"骗走的三年

一家公司招一位运维负责人，收到了两份差别很大的简历：

+ **候选人甲**：名校硕士，同岗位八年经验，简历上项目名很漂亮
+ **候选人乙**：普通本科，五年经验，其中两年还是在做技术支持

面试环节，甲明显更好——表达流畅、术语精准、对行业趋势说得头头是道。面试官几乎当场就想定了。

但公司那年刚好引入了结构化面试 + 工作样本测试。工作样本的题目很土：**给一台"出故障"的测试服务器，一小时内定位问题并给出处理方案。**

结果是反过来的：

```plain
甲：讲了二十分钟理论，实际动手时连日志在哪都没找到，
    最后说"这种问题一般让下面的人处理"

乙：十五分钟定位到是磁盘 inode 耗尽，给出了临时清理方案
    和长期监控方案，还顺手指出了测试环境里另一个隐患

```

公司最终录用了乙。三年后，乙把运维团队从2人带到7人，线上事故率下降明显。而甲后来去了另一家公司，据业内反馈，一年多就换了岗位。

HR 在复盘里引用了那组数据：

```plain
工作年限的预测效度：.18
学历的预测效度：.10
工作样本测试的预测效度：.33-.54
结构化面试的预测效度：.42

```

她写了这么一句：**"我们差点为一个漂亮的简历多付三年的成本。真正救了这次招聘的，不是我们的眼光，是我们逼着自己加了那道一小时的上机题。"**

> 这个案例不是要否定年限与学历——它们有筛选成本上的价值。它要提醒的是：**当"简历印象"与"实际工作样本"冲突时，永远采信工作样本。**

### 11_8 本板块小结

+ **两套卡**：卡片A生成假设（不可用于决策），卡片B输出结论。
+ **卡片A**六维度加权：神25 / 动相20 / 形骨15 / 气色15 / 声音15 / 言语10，并做情境折扣。
+ **卡片B**行为主导：八观八验40 / 承诺兑现率30 / 压力反应15 / 对待弱者15。
+ **结构化远比凭感觉可靠**：.42 vs .19；工作样本与小额试探效度最高；年限与学历预测力很低。
+ **加减乘除**：加法叠加、减法短板、乘法联动、除法对冲。
+ **红线否决**：反复说谎、系统性不兑现、对弱者恶意、攻击性失控、为利出卖关系。
