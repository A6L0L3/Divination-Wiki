# 阳宅十书：一本把"住得对"拆到十层的明代人居手册

> 💡 《阳宅十书》不是某一派大师的独门秘籍，而是明代万历年间王君荣对前代阳宅经验的**系统汇编**——把唐宋到明代流传的各种住宅选址、营建、布局经验分门别类，辑成十论，故名"十书"。清代《古今图书集成》全文收录，民间风水先生几乎人手一册，堪称中国古代的"住宅使用说明书"。
>
> 读它的关键，是**别把它当玄学口诀背**，而要当成一套**"外局定基—内形为用—时序护航—调理补位"**的人居环境评价体系来拆解。全书十论依次是：论宅外形、论福元、论大游年、论穿宫九星、论元空装卦、论开门修造、论放水、论宅内形、论选择、论符镇。逻辑上层层递进，从大环境一路推进到室内每一寸空间。

## 板块1 · 全书的"第一性原理"：外局不行，内饰再贵也白搭

《阳宅十书》开篇"论宅外形"甩出一句定调的话：**"人之居处，宜以大地山河为主。若大形不善，总内形得法，终不全吉。"**

这句话是全书的"第一性原理"，后面九论都是在它之下的展开：

+ **外局是体，内形是用**：小区大环境不行，屋里装修再豪华也白搭
+ **来龙气势最大，关系人祸福，最为切要**：住宅不是孤立存在，而是镶嵌于大地山河的动态格局之中
+ **内形补救有限度**：内部布局再精巧，也难以弥补外部环境的根本性缺陷

🎯 **现代转译**：你去看房，别光看样板间的奢华装修。先站到主卧和客厅的窗前，把四周360度看一遍——有没有高压线、垃圾站、医院太平间、寺庙教堂、笔直冲过来的路、尖角对着你的楼？**窗外环境比你家里的摆件重要一万倍**。

## 板块2 · 论宅外形：四象俱全，是为最贵

"论宅外形"给出了一套极具画面感的理想空间模型：

> **凡宅左有流水谓之青龙，右有长道谓之白虎，前有污池谓之朱雀，后有丘陵谓之元武，为最贵地。**

这四象翻译到现代语境，其实是一套非常务实的环境评估：

| 方位 | 四象 | 理想形态 | 现代对应意义 |
| --- | --- | --- | --- |
| 东（左） | 青龙 | 流水 | 东侧有河流/绿化带，生机盎然 |
| 西（右） | 白虎 | 长道 | 西侧有道路通达，便于联系 |
| 南（前） | 朱雀 | 污池/开阔地 | 南侧开阔明亮，有发展空间 |
| 北（后） | 玄武 | 丘陵 | 北侧有高地山峦，能遮挡风寒 |

**背后的环境科学**：后有靠山可挡北风，前有明堂利于采光排水，左右有道路水系便于交通。这是先民在长期居住实践中总结出的**均衡、稳定、充满生机的微环境模型**。

### 2_1 外形吉凶的硬指标

《阳宅十书》用歌诀+条文的形式，给出了非常具体的外形判断标准：

**✅**** 吉形**

+ 前后有水环抱贵，左右有路亦如然（但遇返跳必须忌）
+ 宅东有流水达江海为吉；南有大路主富贵
+ 南北长、东西狭为吉；前窄后宽稳，前低后高世出英豪
+ 宅周树木枝叶向宅为吉
+ 地面滋润光泽阳气者吉
+ 水木金土四星龙，此作住基终吉利

**❌**** 凶形（"十不居"）**

+ 不居当冲口处（道路直冲）
+ 不居寺庙、祠社、窑冶、官衙
+ 不居草木不生之地
+ 不居故军营战地
+ 不居正当水流冲射之处
+ 不居山脊冲处
+ 不居大城门口处
+ 不居对狱门处
+ 不居百川汇口处
+ 不居北有大路之处（凶）

### 2_2 现代选址的外形核查清单

把上面的古文内化为**现代买房/选址可执行的核查项**：

1. **看身后**：楼后是否有更高的楼或山体作为"靠山"？还是一望无际的空旷或深谷？
2. **看前方**：楼前是否有开阔地、绿地、水面？还是被另一栋楼紧贴压迫？
3. **看左右**：左右是否有建筑或绿化形成环抱？还是被"夹刀"或完全孤露？
4. **看水流**：附近河流/道路是否环抱楼宇？还是反弓冲射？（**反弓=弓背朝宅，大凶**）
5. **避直冲**：楼前是否有道路直冲？是否有尖角建筑冲射？
6. **避特殊场所**：半径500米内是否有寺庙、教堂、医院太平间、垃圾站、高压线塔？
7. **看地势**：小区地势是否前低后高？还是前高后低（"长幼昏迷"）？
8. **看土质**：地块是否滋润有光泽？还是干燥贫瘠、草木不生？
9. **看形状**：地块是否南北长东西短？还是东西长南北短（初凶后吉）？

> ⚠️ **特别提示**：宅前忌开新塘，谓之"血盆照镜"；门稍远可开半月塘。现代转译——楼前正前方不要有大型水池/游泳池正对大门，可在侧前方设置半月形水景。

## 板块3 · 论福元与大游年：人宅相配的理气内核

从第二论到第五论，进入"理气"层面——把人的出生年份换算成"东四命/西四命"，再对应"东四宅/西四宅"；以伏位为起点，把九星（贪狼、巨门、禄存、文曲、廉贞、武曲、破军、左辅、右弼）排到八个方位上，分出"生气、延年、天医"等吉位和"祸害、六煞、五鬼、绝命"等凶位。

这部分**对现代普通读者的实操价值有限**，原因有二：

1. **卦理推演复杂**：论穿宫九星专为解决四合院"进深很长"的房子，按院落进数逐层排九星——这套方法对现代公寓几乎失效
2. **元空装卦趋近玄空派理论**：比较复杂，民间实用度不如前几步

📌 **但有一个核心思想值得提取**：**人宅相配**。住宅布局应服务于人，兼顾功能合理性与居住舒适度。这提示我们：

+ 长辈住宅子的吉位（安静、采光好、远离动线）
+ 子女住宅子的生气位（采光充足、有成长性）
+ 厨房、卫生间等"功用空间"安排在相对次要的方位
+ 卧室避开"凶位"（噪音大、视距差、动线干扰多的位置）

## 板块4 · 论开门修造：门是住宅的"气口"

《阳宅十书》第六论专门讲门。**古人认为"门为气口"，大门方位决定家运**。

### 4_1 门的实操要点

1. **门须避直冲**：大门不可正对道路直冲、不可正对其他门
2. **门尺有吉凶**：修门讲究尺寸，运用门光星等法则
3. **门向有讲究**：详细记载大门开在哪个方位、什么日子动工
4. **截路分房**：《阳宅十书》明确指出——"近世术者概以大门定宅吉凶，不知大门只是游年一节。宅中所居，祖孙、父子、兄弟、男女众多，祸福岂以大门能定？"因此要采用**截路分房法**：一处大宅院，中间有墙门隔阻的，即另起游年。

### 4_2 现代转译：入户门的五大核查

+ **不对冲**：入户门不正对电梯门、楼梯口、其他住户的门
+ **不直穿**：入户门不正对阳台窗（"穿堂煞"的现代版——气直泄）
+ **不压迫**：入户门上方无横梁压顶，门前无尖角冲射
+ **有缓冲**：入户后有玄关或小段走廊作为"气口缓冲"，不要一开门就直视整个客厅
+ **分房而论**：大户型/复式，各独立空间区域要单独看门位与气口，不能只凭大门定吉凶

> 💡 **现代楼宇的"截路分房"应用**：总宅（整户）是个大气场，单间（各卧室/书房）是个小气场。看风水要总论和分论结合——先看整套房子的外局和气口，再看每个房间的门口、床位、灶位。

## 板块5 · 论放水：排水方向里藏着居住智慧

第七论"论放水"看似讲玄虚的"水主财"，**实则包含大量可取的古代排水智慧**。

### 5_1 放水的实操法则

1. **走向忌直流**：排水沟不可直穿过院，不可从房下经过，最好是曲折如生蛇流出
2. **忌横穿直穿**：无论直穿、横穿、八字分流、斜出均不吉
3. **忌穿房门**：忌从房门下流过，忌从房间下流过，穿大门流出最凶
4. **要求绕边**：排水道必须绕边流过，不可自宅之中心横穿或直穿
5. **阳山放阳，阴山放阴**：排水道的出口只能在天干方位（所谓"放水只从天上去"）

### 5_2 现代转译：家装排水的硬指标

把古代放水智慧转译为现代家装的可执行标准：

+ ✅ 地漏、下水道走向宜**曲折有情**，不宜笔直冲出
+ ✅ 卫生间排水不可**直穿卧室下方**
+ ✅ 厨房、卫生间的污水管不可**横穿客厅、餐厅上方**
+ ✅ 阳台排水不可**正对大门直泄**
+ ✅ 整套房子的排水总管宜**沿建筑边缘布置**，不走房屋中心
+ ❌ 避免"水破天心"——排水管从房屋正中心穿过

> 📌 这些规则的本质，是保证宅内不致过分潮湿、避免噪音传递、防止漏水殃及下层空间。**是实打实的建筑科学**。

## 板块6 · 论宅内形：厅堂、卧室、厨房的布局心法

第八论"论宅内形"是全书最具实操价值的章节之一。它明确："造屋从来有次第，先内及外起自堂"——强调主次关系，强调结构美和均衡美。

### 6_1 厨灶（火路）的定位

《阳宅十书》对炉灶位置有专门论述，核心原则：**厨灶应放在宅的凶位，以熏煞气**。

具体方位（节选）：

+ 乾宅坐丙、震宅庚
+ 兑宅癸位、巽宅辛
+ 坎宅坐甲、离宅修乙
+ 艮宅坐乙、坤宅壬

📌 **现代转译**：厨房不宜设在住宅的**正中位置**（"火烧心"），宜设在相对次要的方位；炉灶不宜正对水槽（水火相冲），不宜正对冰箱门，不宜紧贴卧室墙（油烟与热气渗透）。

### 6_2 厅堂的主次秩序

"厅堂门庑先立位，东厢西塾及庖厨"——明确厅堂是第一主体空间，应先确定方位，再布置东西厢房、厨房、庭院。

**现代户型转译**：

+ 客厅是住宅的"气场中枢"，宜方正、明亮、开阔
+ 客厅不宜狭长如走廊
+ 客厅不宜被横梁分割
+ 客厅不宜正对卫生间门或厨房门

### 6_3 卧室的安床法则

综合《阳宅十书》内形篇与后世实操经验，卧室安床有严格的"禁区"：

| 床位摆放 | 吉凶 | 现代解释 |
| --- | --- | --- |
| 床下有化粪池 | 凶 | 管道渗漏、湿气重 |
| 床安于梁下 | 凶（压梁） | 心理压迫感 |
| 床位左右冲门口 | 凶 | 隐私缺失、动线干扰 |
| 床位正前方冲厕所门 | 凶 | 异味、湿度 |
| 床位正前方不冲厨房灶位 | 凶（骑灶） | 油烟热气上升 |
| 床位不安于冷气前方 | 凶 | 直吹感冒、不利健康 |
| 床位正前方不安放镜子 | 凶 | 睡眠干扰、心理不适 |
| 床位不放于炉灶之上、下 | 凶 | 火灾隐患、热辐射 |
| 床位不靠厕所之墙 | 凶 | 防潮、隔音 |
| 床位不安在卧室门入口处之边 | 凶 | 缺乏私密感 |

### 6_4 青龙头与白虎头

《阳宅十书》提出了一个有趣的概念：住宅内有北房、东房而无西房为"青龙头"，反之则为"白虎头"。

> 歌曰：此屋名为青龙头，必主长房衣食愁；此屋名为白虎头，必主小房衣食愁。

📌 **现代转译**：户型要均衡，不可左重右轻或右重左轻。采光、空间分配要左右对称，避免一侧极度饱满而另一侧极度空虚。

### 6_5 宅内形的现代核查清单

综合以上，现代户型内部布局的核查清单：

**方正与均衡**

+ ✅ 户型整体方正，不缺角、不歪斜
+ ✅ 左右均衡，无"青龙头/白虎头"现象
+ ✅ 空间主次分明，厅堂为尊

**厅堂**

+ ✅ 客厅方正明亮，不被横梁切割
+ ✅ 客厅不直对卫生间门、厨房门
+ ✅ 客厅有良好通风采光

**卧室**

+ ✅ 床头有实墙可靠（"背后有靠"）
+ ✅ 床头不靠窗、不靠门
+ ✅ 床不正对镜子、不正对梁
+ ✅ 床不紧贴卫生间墙
+ ✅ 主卧不与厨房相邻（尤其炉灶侧）

**厨房**

+ ✅ 不在住宅正中心
+ ✅ 炉灶不正对水槽、冰箱、门
+ ✅ 厨房不直接正对大门

**卫生间**

+ ✅ 不在住宅正中心
+ ✅ 门不正对客厅、餐厅、卧室门
+ ✅ 有良好通风采光（明卫优于暗卫）

**动线与气口**

+ ✅ 入户有缓冲，不直穿全屋
+ ✅ 动线流畅，无"穿堂"直泄
+ ✅ 排水管不走房屋中心

## 板块7 · 论选择与论符镇：时序与调理

第九论"论选择"讲解起工、上梁、入宅等关键节点的择吉方法；第十论"论符镇"介绍八卦镜、石敢当、符咒等化解煞气之法。

这两论**对现代读者的实操价值相对有限**：

+ 择吉更多属于民俗文化范畴
+ 符镇（八卦镜、石敢当等）属于心理安慰层面的调理手段

📌 **但"论符镇"有一条核心思想值得提取**：**调理补位**。《阳宅十书》承认——当外形有缺陷时，可以通过"镇"的方法来补救。现代转译就是：

+ 门外有直冲→用屏风、玄关缓冲
+ 窗外有尖角→用窗帘、植物柔化
+ 户型有缺陷→用家具、隔断重新组织空间
+ 光线不足→用照明设计补足
+ 通风不畅→用新风系统改善

**本质是用设计手段弥补先天不足**，这是完全现代且科学的思路。

## 板块8 · 把《阳宅十书》压缩成一份"购房/装修核查表"

综合全书十论，把《阳宅十书》的精华内化为一份**现代购房与装修可执行核查表**：

### 8_1 🏘️ 外局核查（对应"论宅外形"）

- [ ] 楼后有更高建筑/山体作为靠山
- [ ] 楼前有开阔地/绿地/水面
- [ ] 左右有建筑或绿化形成环抱
- [ ] 无道路直冲、无尖角冲射
- [ ] 500米内无寺庙、教堂、医院太平间、垃圾站、高压线
- [ ] 附近河流/道路环抱楼宇，非反弓
- [ ] 地块前低后高，非前高后低
- [ ] 地块南北长东西短，非东西长南北短

### 8_2 🚪 气口核查（对应"论开门修造"）

- [ ] 入户门不对电梯、不对楼梯、不对他户门
- [ ] 入户门不直对阳台窗（无穿堂直泄）
- [ ] 入户门上方无横梁压顶
- [ ] 入户有玄关或缓冲空间
- [ ] 各房间门不直冲床位、炉灶

### 8_3 🛋️ 内形核查（对应"论宅内形"）

- [ ] 户型方正不缺角
- [ ] 客厅方正明亮，不被横梁切割
- [ ] 客厅不直对卫生间门/厨房门
- [ ] 主卧床头有实墙可靠
- [ ] 床头不靠窗、不靠门、不靠卫生间墙
- [ ] 床不正对镜子、不正对横梁
- [ ] 厨房不在住宅正中心
- [ ] 炉灶不正对水槽、冰箱、门
- [ ] 卫生间不在住宅正中心
- [ ] 卫生间门不正对客厅/餐厅/卧室门

### 8_4 💧 排水核查（对应"论放水"）

- [ ] 排水管不从房屋中心直穿
- [ ] 排水管不从卧室下方穿过
- [ ] 卫生间排水不横穿客厅/餐厅上方
- [ ] 阳台排水不正对大门直泄
- [ ] 整套房子排水总管沿建筑边缘布置

### 8_5 👨👩👧 人宅相配（对应"论福元"）

- [ ] 长辈居安静、采光好的房间
- [ ] 子女居采光充足、有成长性的房间
- [ ] 厨房、卫生间等功用空间在相对次要方位
- [ ] 卧室避开噪音大、视距差、动线干扰的位置

## 板块9 · 读《阳宅十书》的三条心法

### 9_1 心法一：外局优先，内形补救有限

"若大形不善，总内形得法，终不全吉。"——这是全书第一铁律。**买房时对外局的考察，权重应占70%以上**；装修布局的补救，最多占30%。

### 9_2 心法二：形势为主，卦例为次

《阳宅十书》虽然包含了福元、大游年、穿宫九星、元空装卦等复杂的理气内容，但全书**真正的骨架是"形势"**——外形吉凶的判断，靠的是直观的环境形态评估，不是死套卦例。

对现代读者而言：**与其纠结大门朝哪个度数，不如先把窗外环境看清楚**。前者是术，后者是道。

### 9_3 心法三：中正有序，阴阳平衡

全书推崇方正规整的格局，强调阴阳平衡（采光/动静/干湿协调），拒斥歪斜、壅塞、失衡的空间形态。

这条原则**完全适用于现代建筑学**：

+ 方正户型 > 异形户型
+ 动静分区清晰 > 功能混杂
+ 干湿分离 > 水汽弥漫
+ 采光通风均衡 > 阴暗潮湿

## 板块10 · 全书总诀：一句抵万句

把十论收回来，《阳宅十书》真正想讲的，其实就是这几句话：

> 📜 **"人之居处，宜以大地山河为主。若大形不善，总内形得法，终不全吉。"**

📜 **"凡宅左有流水谓之青龙，右有长道谓之白虎，前有污池谓之朱雀，后有丘陵谓之元武，为最贵地。"**
📜 **"造屋从来有次第，先内及外起自堂。"**
📜 **"近世术者概以大门定宅吉凶，不知大门只是游年一节。"**

**外局为体，内形为用，理气为补，择吉为助**——这十六个字，是《阳宅十书》的真正心传。

王君荣在编纂此书时秉持着"阳宅之法，不专一家，故博采群书，以备参考"的开放态度。这提示我们：读《阳宅十书》，**不要把它当成迷信口诀来背，而要把它当成一套古典人居环境学来研读**。书中的"青龙白虎""气口""放水""截路分房"，剥去玄学外壳后，内核全是**对通风、采光、噪音、视距、动线、湿度、空间秩序**的千年经验总结。

真正读懂《阳宅十书》的人，不是拿着罗盘满屋子转的风水先生，而是**懂得如何挑选一处好环境、如何组织一个好户型、如何让家人住得安心舒适**的生活家。
