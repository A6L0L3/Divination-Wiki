## 板块1 · 为什么这本书值得精读

在众多堪舆古籍中，《入地眼全书》最突出的特点是**反玄虚、重验证**。作者直言批判当时庸师滥用的“双山长生水法”，主张回归河洛正理，强调“往古冢间考证”——用自己的亲手扦葬且“至今不替”的古迹来验证理论。

全书把复杂的风水体系高度凝练为**“龙、穴、砂、水、向”五大核心要素**，构建了从宏观环境选择到微观布局调整的完整操作体系。

**本书与传统风水文化的关系定位**：

+ 它属于峦头派风水四大经典之一
+ 与《撼龙经》《催官篇》的理论高峰不同，它是真正将理论与实地勘察完美结合的“实战手册”
+ 贯穿全书的底色是**“峦头为体，理气为用；无真峦头，理气无从附丽”**

> ⚠️ 读书前先立住一条铁律：**离开山形水势去谈分金理气，都是屋里先生**。书里反复警示：若舍峦头而重理气，“开卷了然，登山茫然”。

**案例**：作者开篇即直斥当时庸师滥用的“双山长生水法”，主张回归河洛正理，并以“往古冢间考证”立论——理论与实地互证，故全书以“峦头为体，理气为用”立骨；读此书须先立一条取舍标准：凡断语不能在现场指出对应山形与水势、说清取象来历者，一律不采，这正是它反玄虚的实操锋芒。

全书以天星、龙法、穴法、砂法、水法、向法、阳宅诸卷为序次，大体可窥原貌：

## 板块3 · 五十字诀：全书的“操作总纲”

辜托长老把整套方法论压缩成五十字诀，这是全书的“源代码”：

> **龙要起伏屈曲活动为主；砂要缠护抱穴朝案分明；穴要气脉窝藏穴晕为的；水要逆朝横收平净为佳；向要净阴净阳依水所立。**

这五十字不是格言，是**五步操作指令**——每一步都有动词、有标准、有验收条件。下面把每一句拆成可执行项。

**案例**：“水要逆朝横收平净为佳”八字可拆为五项验收：逆朝（水逆势来朝）、横收（横抱过穴）、平（水面平缓）、净（水清不浊）、佳（合向且水口关锁），五项齐备方可议“依水所立”。

## 板块4 · 龙法：寻龙不是找山，是找“活的气脉”

### 4_1 🎯 核心标准

龙者，山之脉也。“龙要起伏屈曲活动为主”——屈曲灵动为活龙，粗直崩破为死龙。

### 4_2 实操三看

1. **看出身（祖山）**：山脉起祖处是否雄浑有力。高山龙以绵延不绝为强，平洋龙以水绕屈曲为强。
2. **看行度（过峡）**：龙脉过峡要细，**蜂腰鹤膝为佳**，要“单清过脉”，避阴阳驳杂。过峡处是辨认真龙的关键——“不拘阴来阳来，总在到头一节，结局后来龙束咽过小峡处为主，此是真龙”。
3. **看变换（剥换）**：由老变新、由粗变细，五星九星依次剥换。

### 4_3 九星辨龙（快速判断法）

| 类别 | 星名 | 山形特征 | 在龙局中的角色 |
| --- | --- | --- | --- |
| **三吉** | 贪狼 | 笋状（木） | 宜作贵人 |
|  | 巨门 | 圆顶（土） | 宜作帐慎 |
|  | 武曲 | 平顶方（金） | 宜行龙结穴 |
| **四凶** | 廉贞 | 火焰（火） | 宜作祖宗 |
|  | 禄存 | 蜈蚣（土） | 宜关拦 |
|  | 文曲 | 蛇形（水） | 宜过峡 |
|  | 破军 | 旗状（金） | 宜关拦 |
| **佐星** | 左辅 | 马鞍状（金） | 宜夹从 |
|  | 右弼 | 无形（水） | 宜夹从 |

> 💡 口诀：“廉贞宜作祖宗，巨门宜作帐慎，贪狼宜作贵人，武曲宜行龙结穴，文曲宜过峡，辅弼宜夹从，破军禄存宜关拦。”

### 4_4 平洋龙特殊处理

平洋无山，“以水为龙”——水曲则龙生、水直则龙死，水聚则龙住、水散则龙行。

**案例**：过峡处两山夹持、细而不长、旁有低山护送，方为蜂腰鹤膝的“单清过脉”；若峡长而散、阴阳驳杂，纵来势雄大亦非真龙——故辨龙先看结局一节的束咽处。

## 板块5 · 穴法：寻龙容易点穴难

### 5_1 🎯 核心标准

“穴要气脉窝藏穴晕为的”。真穴必砂环水抱，有证佐（如虾须水、蝉翼砂）。

### 5_2 四形定穴（窝钳乳突）

+ **窝穴**：藏于凹处、圆净平整、气聚其中
+ **钳穴**：口部环抱、中间平坦、龙虎交锁
+ **乳穴**：形如乳头、端正圆净、气从乳出
+ **突穴**：顶圆体正、高出周围、气聚于顶

### 5_3 点穴实操四步

1. **认龙为先**：龙不真，穴再好也没用
2. **观四势**：玄武垂头（后山端正高大）、朱雀翔舞（前山开阔平整）、青龙蜿蜒（左砂环抱）、白虎驯伏（右砂低伏）
3. **察穴晕**：真穴必有“穴晕”——生气凝结的微茫痕迹，土色温润、草木茂盛、气场稳定
4. **验证佐**：看有无虾须水、蝉翼砂、明堂是否合理

### 5_4 穴忌四字

> ⚠️ **露、偏、破、空**
>
> + 露：无遮无挡，风散气泄
> + 偏：不正，气脉偏颇
> + 破：土崩石裂，气脉受损
> + 空：无气，形同虚设

### 5_5 四落定位

初落、腰落、末落、分落——龙脉在哪一“落”结穴，决定了穴位的相对位置与力量大小。

**案例**：以一处窝形穴场为验：穴顶前方无遮蔽而致气随风散，即犯“露”；落脉偏离龙脊中线则为“偏”；穴基土崩见石裂即为“破”；四围空荡唯见穴形而无穴晕者即为“空”——四字犯其一便须弃去，此后再论初落、腰落、末落、分落亦无所施。

## 板块6 · 砂法：缠护抱穴，朝案分明

### 6_1 🎯 核心标准

“砂要缠护抱穴朝案分明”。砂指穴场周围的山峦丘阜（青龙、白虎、玄武、朱雀、案山、朝山）。

### 6_2 四灵砂吉格

| 方位 | 砂名 | 吉格要求 | 忌 |
| --- | --- | --- | --- |
| 后 | 玄武 | 垂头俯伏、端正高大 | 空缺、低陷 |
| 前 | 朱雀 | 翔舞有情、开阔平整 | 高压、闭塞 |
| 左 | 青龙 | 蜿蜒高耸、环抱穴场 | 高压、昂头、反背 |
| 右 | 白虎 | 驯服低伏、护穴有情 | 尖射、高昂、空缺 |

### 6_3 朝案砂要诀

+ **案山**（明堂前近山）：端正圆净、朝拱穴场，忌破碎、斜飞、高压
+ **朝山**（远处山）：秀丽挺拔、远朝有情，忌孤露、尖射、空缺
+ 口诀：“案宜近而低，朝宜远而高”

### 6_4 拔砂实操

1. **用人盘消砂**：二十八宿所居二十四山方位，拔砂要诀在用“人盘”
2. **辨砂形**：秀砂圆润清秀主富贵，粗砂顽恶尖射主凶灾
3. **看方位**：二十四山各有砂法（如乾砂主贵等）
4. **三关一局诀**：综合应用吊冲之法、暗生之法

> 💡 砂之发福速度慢于水（“砂迟发，水速行”），但若砂好而水恶（如右边恶水），仍会致衰败。

**案例**：案山宜近而低、朝山宜远而高——近案反高于朝山则迫而塞，远朝反矮于近案则尊卑倒置；两者一颠倒，明堂纵开亦不成局，此即“朝案分明”之义。

## 板块7 · 水法：逆朝横收，平净为佳

### 7_1 🎯 核心标准

“水要逆朝横收平净为佳”。水性动，属阳，管事速，故有“朝贫暮富”之说。

### 7_2 五大水局（吉凶排序）

1. **逆朝局**：水逆势朝穴——上吉
2. **横抱局**：水横过穴前、环抱如玉带——上吉
3. **合襟局**：水前后合襟交抱——中吉
4. **顺水局**：水顺穴而流——次吉
5. **无水局**：干旱无润——下（平洋另有“无水也要有唇”之变）

### 7_3 吉水 vs 凶水

| 吉水特征 | 凶水特征 |
| --- | --- |
| 屈曲有情 | 直冲穴场 |
| 玉带环腰 | 反弓背穴 |
| 九曲入明堂 | 割脚贴身 |
| 水清平缓 | 湍急浑浊 |
| 水口关锁紧密 | 水口空旷无收 |

> 📌 平洋水法精要：“水东来则气东来，水西来则气西来，龙随水转，向依水立”。

### 7_4 纳水原则

水本身无吉凶，吉凶取决于“方位与向”的配合：

+ **阳水来立阳向、阴水来立阴向 → 吉**
+ **阴水来立阳向 → 凶**
+ 即“纳吉则吉，纳凶则凶”

### 7_5 水口关锁

水口是气的出入口，“关锁紧密（北辰、华表、禽星）可聚财气，空旷无拦则财散人离”。

**案例**：穴前水自右来而向左横抱，如玉带环腰，为横抱局上吉；若水顺穴直去而不作回环，则成顺水局，只主朝贫暮富，须俟时运以催；水局之吉，全在有情二字。

## 板块8 · 向法：净阴净阳，依水所立

### 8_1 🎯 核心标准

“向要净阴净阳依水所立”。素有“无绝地，有绝水，无绝水，有绝向”之说——立向正确与否对风水格局有关键影响。

### 8_2 立向铁律

1. **盘古立向正为诀，三七相兼祸即侵**：坟面与穴内分金不同，关乎外收堂气。三七分处带煞，不可相兼；七三分或五五分的组合则可考虑兼立
2. **净阴净阳为吉**：如壬字纳甲于离卦，离为中女；子属坎卦，为中男。中男配中女，阴阳相配，用之为吉
3. **向依水立**：立向需依水势而定

### 8_3 翻卦掌诀（向法核心算法）

通过黄石公翻卦掌诀，取净阴净阳与向相配，依据水的来去判断吉凶：

+ 翻得**辅、武、贪、巨**四卦上 → 吉
+ 翻得**破、禄、文、廉**四卦上 → 凶

### 8_4 分房断诀（水法配向的实用分支）

水之来去关乎祸福，对应房分兴衰：

+ **右水到左** → 先发长房
+ **左水到右** → 先发二房
+ **当面水朝来** → 先发三房

**实例**：子山午向，若卯山水来 → 长四房先发；乙辰水去 → 二五房后发；午水当面朝来 → 三六房先发。

**案例**：向法可在一宅上验足：某宅子山午向，水自卯方来、于午方朝堂、末从乙辰方去。以翻卦掌诀推此坐向，得辅、武、贪、巨四吉卦之一为吉；再以分房断诀核对——卯水来长四房先发，午水朝三六房先发，乙辰水去二五房后发；水之来去与房分应验相合，方见“依水所立”非虚言。

## 板块9 · 阳宅：从阴宅到人居的迁移应用

### 9_1 阳宅基本要素

门、路、灶、井的布局原则，配合游星与宫星生克关系，应用七政九曜等方法。

### 9_2 阳宅选址要点

+ 与阴宅风水有异同比较
+ 注重住宅与周围环境的关系
+ 户型布局的吉凶判断

### 9_3 现代高层阳宅的“三盘”测量法

沿用罗盘“三盘三针”法：

1. **地盘**：用于立向——阳宅太极点在宅中；阴宅太极点在坟顶中央
2. **人盘**：用于消砂——看山峰、楼、树、墙、堆砌物、塔、烟囱等
3. **天盘**：用于纳水——看水的来去或路的走向（如水、河、溏、池、井、厕所、养鱼、门窗、路或平地等）

**测量阳宅坐向的步骤**：

1. 将罗盘持平，贴近或将罗经边缘平行于被测量物之边缘
2. 滑动转盘，使磁针之钗形头与罗经底座红在线之两点契合
3. 以定位透明线所压之层读出方向

> 💡 高楼大厦，应当以大厦主结构之坐向为依归，再以单位户门气口与电梯出口与大厦大门气口、楼梯口方位论吉凶。

**案例**：测一高层住宅，以罗盘地盘正针定其坐向，人盘消邻栋与树木之砂，天盘纳小区道路与排水之水，再于户内以门为气口校验冲与穿——即是“三盘三针”在阳宅的用法。

## 板块10 · 可落地的“入地眼”实操清单

把全书浓缩成一份**上山下乡都能用的自查表**：

### 10_1 🔍 寻龙自查（卷二）

- [ ] 祖山是否雄浑有力、绵延不绝？
- [ ] 过峡是否蜂腰鹤膝、单清过脉？
- [ ] 剥换是否由老变新、由粗变细？
- [ ] 是否避开阴阳驳杂？
- [ ] 平洋龙是否“水绕屈曲、地势起伏”？

### 10_2 🎯 点穴自查（卷三）

- [ ] 是否落在“窝钳乳突”四形之一？
- [ ] 是否有穴晕（土色温润、草木茂盛）？
- [ ] 玄武是否垂头、朱雀是否翔舞？
- [ ] 是否避开了“露、偏、破、空”四忌？
- [ ] 有无虾须水、蝉翼砂等证佐？

### 10_3 🛡️ 砂法自查（卷四-五）

- [ ] 青龙是否蜿蜒环抱？（忌高压、昂头、反背）
- [ ] 白虎是否驯伏低伏？（忌尖射、高昂、空缺）
- [ ] 案山是否近而低、朝山是否远而高？
- [ ] 水口是否有关锁（北辰、华表、禽星）？
- [ ] 砂形是否圆净秀丽？（忌粗顽尖射）

### 10_4 💧 水法自查（卷六-七）

- [ ] 水形是否屈曲有情、玉带环腰？
- [ ] 是否避开了直冲、反弓、割脚、湍急浑浊？
- [ ] 水口是否关锁紧密？
- [ ] 阳水来是否立阳向、阴水来是否立阴向？
- [ ] 平洋地区是否“水绕屈曲、地势起伏”？

### 10_5 🧭 立向自查（卷八-九）

- [ ] 是否做到净阴净阳相配？
- [ ] 是否避开了三七相兼的分金带煞？
- [ ] 向是否依水势而立？
- [ ] 翻卦掌诀推算是否为辅武贪巨四吉卦？
- [ ] 分房断诀下，水来去是否符合预期房分配合？

**案例**：自查点穴一栏，若穴场土色灰白、寸草不生，即“空穴无晕”，纵四山环抱亦不取；反之土色温润、草木自生，纵形貌平淡亦为有气之证。

## 板块11 · 学《入地眼》最容易踩的五个坑

1. **重理气、轻峦头，本末倒置**：死磕分金、挨星、净阴净阳，完全不看山形龙脉、砂水环抱。没有真峦头做基础，理气再精也是空中楼阁。
2. **死背口诀，不辨实地**：把“水抱边有穴，水反边无穴”等口诀当万能公式，不管山龙、平洋、阴宅、阳宅直接硬套。同样的水形，在高山与平地、老宅与新楼里，判断逻辑完全不同。
3. **砂水乱配，吉凶颠倒**：把逼压、反背的恶砂当成护砂，把反弓、直冲的凶水当成抱水。砂的高低远近、水的来去缓急，都要和龙穴匹配。
4. **误认假穴，错判龙身**：只看山形圆润、看似有情就当真穴，忽略龙身剥换、穴星起顶、气脉窝藏等关键细节。
5. **照搬古法，不融现代**：直接照搬古法，把高楼当山、马路当水却不懂变通。城市里的楼栋、电梯、户型，都要按书里的峦头逻辑重新解读。

> 📌 守住“峦头为本、实地验证、古法活用”这三点，才能避开大坑，学到真东西。

**案例**：以坑二“死背口诀，不辨实地”为例：“水抱边有穴，水反边无穴”在高山论的是砂水抱穴之形，若径直搬到平原便错——平洋无山，所抱者只剩水，须改用书中五大水局（逆朝、横抱、合襟、顺水、无水）与“水东来则气东来，水西来则气西来”去验；口诀是索引，不是公式。

## 板块12 · 现代环境下的“入地眼”转换规则

古代的山野阴宅、乡村阳宅，转换成现代城市环境时，可按以下对应关系重新解读：

| 古代峦头要素 | 现代城市对应物 |
| --- | --- |
| 山（砂） | 周边楼房、电塔、高层建筑 |
| 水 | 道路、街道、河流、水池 |
| 龙脉 | 城市主干道、连续建筑群形成的“脊线” |
| 明堂 | 小区广场、楼宇前的开阔空间 |
| 穴场 | 具体户型的核心区域 |
| 罗盘量测 | 阳台、窗户、入户门的方向定位 |

**平原/城市变通总则**：高一寸为山，低一寸为水。以道路、沟渠、建筑为砂水。

**案例**：老城一进巷宅，北面为多层砖楼（玄武）、南面为开阔街面（朱雀）、东西为邻墙与门洞（青龙白虎），按“高一寸为山、低一寸为水”判读即成一局，不必拘于真山真水。

## 板块13 · 阅读路径建议

针对不同读者，给出三条进阶路径：

**🟢**** 入门路径**（建立峦头直觉）：
龙法卷二 → 穴法卷三 → 砂法卷四-五 → 水法卷六，配合实地观察身边的山形水势。

**🟡**** 进阶路径**（掌握理气应用）：
在上述基础上 + 天星卷一 → 向法卷八-九 → 阳宅卷十，开始用罗盘做实测。

**🔴**** 精研路径**（融会贯通）：
反复研读全书 + 往古冢间考证（寻找书中提及的古迹实地验证）+ 对照《撼龙经》《催官篇》交叉印证。

> ⚠️ 辜托长老在书中毫不避讳地自承“学问不佳，文理不通”，但他力倡破除迷执，主张回归河洛正理，强调必须“往古冢间考证”。这种实事求是、不搞神神叨叨的学术态度，在风水学史上极为罕见，也是本书最值得现代读者继承的精神。

**案例**：一条可落地的次序：先读卷二龙法，上本地认一脉自远山奔来、于某处束咽过峡的地形；再读卷三穴法，带罗盘到束咽处前后找“窝钳乳突”之形，以“露偏破空”四字当场排除；然后读卷四至五砂法、卷六至七水法，最后回头读卷一天星与卷八至九向法，用三盘三针收定坐向——先形后气，次第不可倒。

## 板块14 · 写在最后的读书心得

《入地眼全书》最打动人的，不是它断言“这样扦葬必出富贵”，而是它反复强调：

> “看地至此，要知山水之病，切不可胡说乱扦。”

这句话揭示了全书的底层逻辑——**它是一部教人如何看地形、辨方位的技术指南，更蕴含着古人对大自然的深深敬畏**。它告诉我们，真正的风水不是逆天改命的法术，而是顺应自然规律、追求人与环境和谐共生的智慧。

从这个意义上说，《入地眼全书》的价值远超风水本身。它是一套**关于如何观察环境、理解空间、做出判断**的完整思维训练。即便剥离掉所有玄学外壳，“龙穴砂水向”五字诀依然提供了一种**审视人居环境的系统框架**——看起伏、找聚散、辨环抱、察流动、定朝向——这套框架在现代城市规划、建筑选址、景观设计中，依然有其参考价值。

学会用“入地之眼”看世界，也许才是这本千年古籍留给我们最宝贵的财富。

**案例**：书中自承“学问不佳，文理不通”，却坚持“往古冢间考证”，主张以亲手扦葬、至今不替的旧墓验证理论——这种自我设限，正是一部技术书能站住脚的原因。
