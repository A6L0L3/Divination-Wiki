# 玉尺经：一把衡量"龙水向"是否合局的尺

> 💡 《玉尺经》书名本身就是方法论——"玉尺"不是实体测量工具，而是衡量、裁度地理条件的象征。它要解决的，是峦头（形势）与理气（方位生克）如何配合的问题：龙真、水善、向合，三者如尺量般精准契合，才是真结作。
>
> 传世的《玉尺经》常见版本多以赋文形式呈现，通常可分为《造微赋》《天机赋》《逐吉赋》三篇，托名唐代杨筠松（另有说是元代刘秉忠述、明代刘基解）。读这本书，最忌把它当吉凶口诀集背——它的真正价值，在于提供了一套"**审势 → 乘气 → 品配阴阳 → 择优避凶**"的完整判断链条。

## 板块1 · 全书的"第一性原理"：龙水向三者合窍

《玉尺经》开篇就抛出总纲：

> 尝考寻龙之法，首看龙气之盛衰，次察向水之吉凶，审召瑞邀祥之妙，察阴阳朝应之情。

这句话定下了全书的判断顺序：

1. **先看龙气盛衰**——来龙有没有"气势"。吉龙站在远处看，清秀舒适，星峰端正秀丽、起伏有致；恶龙则让人心惊肉跳，如入孤坟野谷。
2. **再察向水吉凶**——坐向与水法是否合局。
3. **审召瑞邀祥**——通过龙水配合，把吉气"召"进来。
4. **察阴阳朝应**——龙、砂、水、向之间的阴阳配合与朝应关系。

🎯 **核心要义**：龙、水、向三者必须"合窍"。经中四大局口诀"乙丙交而趋戌，辛壬会而聚辰，斗牛纳丁庚之气，金羊收癸甲之灵"，说的正是龙与水必须归于同一个墓库（水口），才能"元窍相通"。

📌 **现代转译**：把住宅/地块放到一个大环境里看，背后要有连绵地势（龙），前方要有环抱水路或道路（水），建筑朝向要能与山水格局呼应（向）。三者各吹各的调，再豪华也是废局。

## 板块2 · 《造微赋》：从形势看"结作"的条件

《造微赋》的重点是观察山川形势如何形成可供判断的局面。这里的"龙、穴、砂、水"不是神秘标签，而是四种具体的地形观察对象：

### 2_1 龙：山脉地势的连续性

"万山一贯起自昆仑"——龙，是山脉、地势或地形延续形成的整体脉络。观察要点：

+ **看连续性**：龙脉不是孤立的山头，而是从远祖山一路绵延而来的整体脉络
+ **看剥换**：星峰秀丽端正、起伏有致、旖旎如蛇
+ **看气势**：吉龙让人感觉清秀舒适，恶龙让人犹入孤坟野谷

📌 **平洋地区的龙**：平原旷野看似无龙，但其冈阜分布、地势起伏皆根于龙脉。"察冈阜之所来，则知平原之发迹"——平原寻龙，要看微地形与水道的配合。

### 2_2 穴：能聚合环境条件的位置

穴不是地图上任意一点，而是指被认为能够承接形势与气脉的结作位置。真穴的判别：

+ **穴后有一丝气脉行至穴前**：无论起脊或草蛇灰线，细细认知才可确定。"富贵出在龙身上，来龙若无真气脉，穴前空叠万重山"
+ **窝钳乳突四形**：窝、钳、乳、突四大穴情
+ **龙阳则阴结，龙阴则阳结**：窝、钳之穴在其中寻乳突；乳、突之穴在其中寻窝、钳
+ **急龙寻其缓，缓龙寻其急**

⚠️ **关键警示**：窝若无脉，必犯淋头水，此为阴窝非龙穴。窝钳之穴要千万小心，别以为藏风即是龙穴。

### 2_3 砂：穴场周边的空间围合

砂是穴场周围具有护卫、朝应或遮蔽作用的山体或地势。阅读相关句子时，应先问"它在描述龙、穴、砂还是水"，再判断句子是在说形态、位置还是组合关系。

### 2_4 水：来去、聚散、曲直

水包括河流、沟渠、道路走向及环境中的流动因素。考察要点：

+ **来去**：水从何方来、向何方去
+ **聚散**：是否潴蓄停聚、还是散漫无忌
+ **曲直**：是否屈曲有情、还是直硬倾流

《造微赋》强调：观察水，必须考察其来去、聚散、曲直与周边地势的配合。

## 板块3 · 《天机赋》：理气配合的三大法则

《天机赋》的重点，是把坐向、方位、五行和水法放在相互作用中观察。三大核心法则：

### 3_1 法则一：生旺墓吊合三方

"生旺墓吊合三方，而孟仲季之攸分公位。十二宫配属于五行，而贪武破之天星始定。"

这是三合水法的基石。**三合水法四大局**：

| 局 | 口诀 | 长生 | 帝旺 | 墓库（水口） |
| --- | --- | --- | --- | --- |
| **火局** | 乙丙交而趋戌 | 艮寅 | 丙午 | 辛戌 |
| **水局** | 辛壬会而聚辰 | 坤申 | 壬子 | 乙辰 |
| **金局** | 斗牛纳丁庚之气 | 巽巳 | 庚酉 | 癸丑 |
| **木局** | 金羊收癸甲之灵 | 乾亥 | 甲卯 | 丁未 |

📌 **操作逻辑**：

+ 看来龙属哪一局（用七十二龙格龙）
+ 看水口落在哪一库
+ 龙与水必须同归于一个墓库，才能"元窍相通"
+ 立向时，向要与龙、水相合

### 3_2 法则二：阴阳品配

"三吉六秀主富贵之枢机，而阴阳品配为作用之玄奥。"

《玉尺经》明确"贵阳龙而取旺相"、"贱阳龙而避孤虚"——地理家贵阳龙而取旺相，虽丑未巳龙为所弃；贱阳龙而避孤虚，纵寅甲申亦见难容。

阴阳品配的核心：

+ **阴必吉而阳必凶，气使然焉**
+ **孤阴不长、独阳不生**：阴龙必配阳水，阳龙必配阴水
+ **龙阳则阴结，龙阴则阳结**

### 3_3 法则三：三吉六秀

"三吉六秀主富贵之枢机。"

+ **三吉**：指长生、临官、帝旺三方。这三方的砂秀丽有情，主大吉。
+ **六秀**：指胎、养、生、冠、临、旺六个宫位，即十二长生宫中的六个吉方。这六方的砂水秀丽有情，均主大吉。

三吉六秀方宜见秀丽砂峰，凶方宜低伏。**三吉六秀方若有龙脉砂峰配合，可以催官荐元、发科甲拱富贵**。

> 💡 注意：三吉六秀必须与峦头形势相合才有用。"峦头吉是指砂峰外形要端正而无破面歪斜，理气吉是指三吉六秀要合消砂之要求"——峦头为体，理气为用，若峦头不真，理气再好也是虚妄。

## 板块4 · 《逐吉赋》：取吉避凶的组合条件

《逐吉赋》归纳取吉和避凶时所观察的组合条件。它明确了一个核心原则：**吉象需要与整体格局共同成立**，不能把一个方位词单独译成吉凶。

### 4_1 砂峰形态的吉凶判别

《逐吉赋》给出了非常具体的砂峰形态判别：

**✅**** 吉砂形态**

+ **剑戟牙刀**：六秀方见此类形态，"因之而取贵"
+ **龟鹤琴剑**：三吉方见此类形态，"得以文雅"
+ **文笔峰**：端正大方、星峰秀丽
+ **旌旗峰**：端庄挺拔

**❌**** 凶砂形态**

+ **掀裙舞袖**：出现在沐浴之方，主妇女淫乱
+ **偃月卧尸**：出现在黄泉之地，主少亡横死
+ **抱头侧面、躲躲闪闪**：主出奸阴邪淫之人
+ **似山非山、星散不聚**：皆非吉砂而是凶砂
+ **刀砂遇八曜**：主杀身之祸

### 4_2 水法格局的吉凶判别

《天机赋》与《逐吉赋》对水法有系统论述：

**✅**** 吉水格局**

+ **生旺交合格**：长生水先朝堂，会帝旺水，合流归墓而去，主先发人丁后发富贵
+ **帝旺水朝**：主富贵显达
+ **元辰水到**：功名白手
+ **垣星入局**：三合的长生、临官和帝旺三方水同到，主大官贵

**❌**** 凶水格局**

+ **冲生破旺格**：长生水逆来冲破帝旺，或帝旺水逆来冲破长生——虽发福但终不足取
+ **墓冲生旺格**：墓水逆来破帝旺，立见贫穷；流破长生必主败绝
+ **旺神投沐格**：帝旺水来而流归沐浴方去——虽得富贵，难免因淫乱致家道中落
+ **四墓交流格**：辰戌丑未四墓之位水直冲朝堂，主中小二房瘟痨痼疾孤寡败绝
+ **生旺带煞格**：生旺水虽朝堂，却从八曜关煞方流来，发福后必遭刑戮暴死

### 4_3 天干地支的水流法则

《玉尺经》有一条极重要的水法原则：

> **天干位上宜来，须防流破；地支位上宜去，切忌朝归。**

+ **天干方**（甲乙丙丁庚辛壬癸、乾巽艮坤）：水宜从天干方来，不宜从天干方流破
+ **地支方**（子午卯酉、寅申巳亥、辰戌丑未）：水宜从地支方去，切忌朝归

这条法则的本质是"水从天上去，龙从地下来"——水喜天干行度，龙喜地支行度。

## 板块5 · 可落地的"玉尺经形势水法核查十则"

把三篇赋文的要义内化为可带去现场的核查清单：

### 5_1 🔍 龙脉核查（3 则）

1. **看气势**：远观来龙是否清秀舒适、星峰端正、起伏有致？
2. **看剥换**：龙脉是否有星体变换、脱煞变嫩？
3. **看入首**：入首之处的方位是否在三吉六秀方？是否"阴遇阳、阳遇阴"的孤虚之位？

### 5_2 🔍 穴场核查（2 则）

4. **看气脉**：穴后是否有气脉行至穴前？窝钳之穴是否犯淋头水？
5. **看阴阳结作**：龙阳则阴结（窝钳），龙阴则阳结（乳突）；急龙寻其缓，缓龙寻其急

### 5_3 🔍 砂水核查（3 则）

6. **看砂形**：穴场周围的砂峰是否端正秀丽？三吉六秀方是否有吉砂拱卫？沐浴方、黄泉方、八煞方是否有凶砂（掀裙舞袖、偃月卧尸、刀砂）？
7. **看水形**：来水是否曲折悠扬、停蓄有情？去水是否之玄屈曲、归库无声？
8. **看水口**：水口是否在辰戌丑未四墓库方之一？是否被砂山关锁？

### 5_4 🔍 理气核查（2 则）

9. **看龙水配合**：来龙属哪一局？水口归哪一库？龙与水是否"元窍相通"？（乙丙→戌、辛壬→辰、丁庚→丑、癸甲→未）
10. **看坐向**：立向是否与龙、水、砂合局？是否犯了冲生破旺、旺神投沐等凶格？

## 板块6 · 把《玉尺经》转译为现代选址语言

古代风水语言要落到今天的建筑选址、景观规划上，需要做一次现代转译：

### 6_1 "审势"→ 环境整体评估

+ **龙** = 地块背后的地势延续性。高楼为山（静、阴），要有连绵起伏的楼群或山体作为背景
+ **砂** = 左右护卫。左右建筑或绿化要形成环抱，而非反背走飞
+ **穴** = 建筑基底。要选在气脉聚合处，避开"淋头水"（上坡直冲下来的车流/水流）
+ **水** = 道路、河流、水系。要屈曲有情，忌直冲反弓

### 6_2 "乘气"→ 微气候与空间舒适度

+ **清主贵，浊主贱**：环境清爽（空气清新、水质清洁、噪音低）→ 宜居；环境浑浊（污染源附近、噪音大、水质差）→ 不宜居
+ **阴阳品配**：建筑体量（阴）与开放空间（阳）要均衡搭配。纯阴（全是高楼无绿地）或纯阳（全是广场无建筑）都不合局

### 6_3 "三吉六秀"→ 景观优势方位

+ 把"三吉六秀方宜见秀丽砂峰"转译为：**在基地的吉方（视具体山水格局而定），宜保留或营造优美的景观节点**（如秀丽的山峦、挺拔的树木、雅致的建筑）
+ 在凶方（沐浴、黄泉、八煞方），宜低伏、宜遮蔽，不宜高突

### 6_4 "天干宜来，地支宜去"→ 排水与道路设计

+ **进水/进路**宜从"天干"方位（开阔、明朗的方位）引入
+ **出水/出路**宜从"地支"方位（相对隐蔽的方位）导出
+ 本质是：**进水要明、出水要暗；进水要缓、出水要曲**

### 6_5 "四大局"→ 龙水向的整体合局

现代大中型项目选址，可以把"四大局"作为一种**整体性校验思维**：

+ 地块的"来龙"方向（背后地势来源）
+ 地块的"水口"方向（前方水流/道路去向）
+ 建筑的"立向"（主轴线朝向）

三者要形成一个**闭合的、互相对应的系统**，而不是各吹各的调。

## 板块7 · 读《玉尺经》的三条心法

### 7_1 心法一：形势为体，理气为用

《玉尺经》虽然精于理气推演，但它的根基是形势。"峦头不真，理气再好也是虚妄"。**现代读者务必先学会看形势**——龙脉是否连绵、穴场是否藏聚、砂水是否有情——再谈理气配合。

### 7_2 心法二：关系大于标签

《玉尺经》的术语不是孤立的吉凶标签。"单独看到'水吉''向吉'或'某方宜某象'，不能马上得出完整结论，因为传统判断通常还会参考地形总势、空间关系、来龙去脉和具体情境"。

一个方位是吉是凶，必须放在"龙水向"的整体关系网中判断。**脱离上下文摘录一句口诀，往往会削弱原文真正要表达的条件关系**。

### 7_3 心法三：贵阳贱阴，取其旺相

《玉尺经》明确"贵阳龙而取旺相，虽丑未巳龙为所弃"——取旺相之气，避孤虚之位。**现代转译**：选址要选"有生机"的环境——有山有水、有树有绿、有活动有生气；避开"孤虚"之地——孤山独露、四野空旷、荒芜人烟、死气沉沉。

## 板块8 · 全书总诀：一句抵万句

把三篇赋文收回来，《玉尺经》真正要讲的，其实就是这几句话：

> 📜 "尝考寻龙之法，首看龙气之盛衰，次察向水之吉凶，审召瑞邀祥之妙，察阴阳朝应之情。"

📜 "乙丙交而趋戌，辛壬会而聚辰，斗牛纳丁庚之气，金羊收癸甲之灵。"
📜 "三吉六秀主富贵之枢机，而阴阳品配为作用之玄奥。"
📜 "天干位上宜来，须防流破；地支位上宜去，切忌朝归。"

**龙真、水善、向合、砂秀**——这八个字，是《玉尺经》的真正心传。

《玉尺经》给的不是公式，而是尺规。它教我们用一把"玉尺"去衡量：龙脉是否真？水法是否善？坐向是否合？砂峰是否秀？四者皆合，才是真结作；有一不合，便是瑕疵；多数不合，便是废局。

卜应天在《雪心赋》里说"水若屈曲有情，不合星辰亦吉"；《玉尺经》则进一步告诉我们——**屈曲有情只是基础，龙水向的理气配合才是高阶**。两者结合，才是完整的中国传统人居环境智慧。

## 板块9 · 📋 附：《玉尺经》核心要义速记卡

**总纲**：首看龙气盛衰，次察向水吉凶，审召瑞邀祥，察阴阳朝应

**三大赋文**：

+ 《造微赋》：从外在形势看结作条件（龙、穴、砂、水）
+ 《天机赋》：从关系网络理解理气（生旺墓三方、十二宫）
+ 《逐吉赋》：归纳取吉避凶的组合条件（砂水配合、三吉六秀）

**四大局水法**：

+ 火局：乙丙交而趋戌
+ 水局：辛壬会而聚辰
+ 金局：斗牛纳丁庚之气
+ 木局：金羊收癸甲之灵

**三吉六秀**：

+ 三吉：长生、临官、帝旺三方
+ 六秀：胎、养、生、冠、临、旺六宫

**水法铁律**：

+ 天干位上宜来，地支位上宜去
+ 水喜天干行度，龙喜地支行度
+ 水从天上去，龙从地下来

**阴阳品配**：

+ 阴龙配阳水，阳龙配阴水
+ 龙阳则阴结，龙阴则阳结
+ 孤阴不长，独阳不生

+ 吉：剑戟牙刀（六秀方）、龟鹤琴剑（三吉方）、文笔、旌旗
