## 板块1 · 总纲：一句话理解全书的灵魂

《葬经》开篇即立极：

> 葬者，藏也，乘生气也。

短短九字，包含三层意思：

+ **葬 = 藏**：安放遗骸，使其得其所
+ **乘 = 承接、顺应**：不是改造自然，而是找到自然中已有的“生气”并与之对接
+ **生气**：阴阳之气行乎地中，噫而为风，升而为云，降而为雨，行乎地中则为生气

全书所有判断标准，都是这一句的展开。**读《葬经》若只记一句，就是这一句。**

### 1_1 生气的运行规律

| 运行状态 | 地形表现 | 葬法应对 |
| --- | --- | --- |
| 气之行 | 因地之势 | 原其起——追溯来龙 |
| 气之聚 | 因势之止 | 乘其止——葬于停顿处 |

气不是静止的，它在地中随山势行走，遇到地形的“止”（停顿、收束、兜抱）才聚而不散。**所以“葬”的关键动作，是在气“止”的地方落穴。**

**案例**：郭璞“葬者，藏也，乘生气也”九字，对应今日选址便是——先在区域内找到气“止”的地方（势来形止），再看此处土是否细坚润泽（气聚之地必有其征），而非先看朝向吉凶。

## 板块2 · “风水”二字的最早定义

> 气乘风则散，界水则止。古人聚之使不散，行之使有止，故谓之风水。

这是“风水”一词在文献中的首次明确提出，包含两个互补的操作：

1. **聚之使不散** → 藏风（防气被风吹散）
2. **行之使有止** → 得水（用水把气拦截住）

由此导出《葬经》最著名的方法论排序：

> **风水之法，得水为上，藏风次之。**

为什么“得水”排第一？因为水既能“界气”（把气拦住），又是生气旺盛的外在表征——水源长、流量大，与生气的旺盛成正比。**无水则气难聚，故水为先。**

### 2_1 外气与内气的配合

> 外气行形，内气止生。

+ **外气**：外在的山水形势（砂、水、龙脉）
+ **内气**：地中运行的生气

外气横行环绕，内气才能在穴中停聚滋生。这解释了为什么单有“好土”不够，必须有外围的山水配合才能成穴。

**案例**：“气乘风则散，界水则止”——同一背风山坡，有水横界者气聚于穴前，纯以土丘遮风者仍会泄散；故“得水为上，藏风次之”不是修辞，是两条并列的操作。

## 板块3 · 形势论：千尺为势，百尺为形

《葬经》给出了一套**尺度化的观察方法**：

+ **势**（千尺为势）：远观千尺之外的山川走向，看龙脉的总体气势与来向
+ **形**（百尺为形）：近察百尺之内的场地形态，看穴场的具体格局

判断标准：

> **势来形止，是谓全气。全气之地，当葬其止。**

远处的势奔涌而来，在近处形成停驻聚合的地形，这就是“全气”之地——生气充盈的吉地，应当在“止”的地方落穴。

📌 **操作口诀**：先观势（宏观龙脉走向），再定形（微观穴场格局），最后校方位。势若为凶，形再美、方再准也难以挽回。

**案例**：山外远望，山脉自远而来至近处顿止，方为全气；若近看只是一片散乱而远山之气未曾收，即是势未至而形先就，虽有穴形也不可葬。

## 板块4 · 四灵格局：玄武、朱雀、青龙、白虎

《葬经》以四象构建理想的立体空间：

> 葬以左为青龙，右为白虎，前为朱雀，后为玄武。**玄武垂头，朱雀翔舞，青龙蜿蜒，白虎驯俯。**

翻译成现代选址语言：

+ **玄武（后靠）**：背后有山，且山势饱满低垂，如靠椅之背 → 有依托
+ **朱雀（前方）**：前有开阔明堂或屈曲之水，朝山有情 → 有发展空间
+ **青龙（左护）**：左侧砂山蜿蜒舒展 → 有护卫
+ **白虎（右护）**：右侧砂山温顺俯伏，不高压欺主 → 有平衡

**反向验证（凶格）**：

+ 玄武不垂 → 拒尸（背后空旷或无靠）
+ 朱雀不舞 → 腾去（前方水直冲或反弓）
+ 青龙踞 → 嫉主（左砂过高欺主）
+ 白虎蹲 → 卸尸（右砂过低或空缺）

> 💡 一句验证口诀：**背有靠、左右护、前有照、水口锁** —— 基本符合《葬经》的空间要求。

**案例**：以一处宅基作四灵验：后倚丘陵而山不垂头，是玄武不垂的“拒尸”；前临直渠、水直撞而来，是朱雀不舞的“腾去”；左首邻丘高出数丈反扑向穴，是青龙踞的“嫉主”；右侧地势全无、低陷见沟，是白虎蹲的“卸尸”——四灵反验出三凶，纵然朝南向阳、明堂开阔，亦不足取。

## 板块5 · 五不葬：五种绝对避开的地形

《葬经》明确列出五种不可葬之山：

| 类型 | 含义 | 为何不可葬 |
| --- | --- | --- |
| **童山** | 不生草木的秃山 | 生气薄弱，无以生和 |
| **断山** | 被凿断或挖深的山 | 气脉中断，势不连贯 |
| **石山** | 无土的顽石山 | 气因土行，无土则气不行 |
| **过山** | 龙脉仍在奔腾未停之山 | 势未止，气不聚 |
| **独山** | 孤立无脉、无砂水会聚之山 | 气以龙会，独则无会 |

经曰：**“童、断、石、过、独，生新凶，消已福。”**

这五条是《葬经》给出的**硬性负面清单**，比正面寻找“吉地”更容易执行，是现代选址中**最先应该排查的红线**。

**案例**：五不葬中最易踩的是“过山”——谓脉气仍在奔走未停之地；故选地须避开正在山坡中段、最易被误认作“背山好风”的滚龙之地，而取其顿挫已收之肩。

## 板块6 · 土质与深浅：看不见的底层判断

### 6_1 土质的辨察

> 土欲细而坚，润而不泽，裁肪切玉，备具五色。

理想的葬土特征：

+ **细腻而坚实**（非松散沙砾）
+ **温润而不湿腻**（非水泉砂砾）
+ **色泽**：黄润为佳，红黄相间次之；灰黑污湿为凶

**凶土三忌**：

+ 干如栗粟（松散无凝聚力）
+ 湿如割肉（水泉砂砾，湿润腐败）
+ 水泉砂砾（地质不稳）

### 6_2 深浅的法则

> 藏于涸燥者宜深，藏于坦夷者宜浅。

+ **高垄阴地（涸燥）**：气沉于下 → 宜深葬以取沉气
+ **平支阳地（坦夷）**：气浮于上 → 宜浅葬以取浮气

核心原则是**“浅深得乘，风水自成”**——深浅不是机械尺寸，而是要契合生气所在的深度。

**案例**：土质当场可验——掘一尺见黄土润而颗粒细匀者为佳，见灰黑污湿、夹砂砾水泉者即“湿如割肉”，其地不宜葬；而深浅之判在“涸燥宜深、坦夷宜浅”，高垄深处取沉气，平处浅取浮气。

## 板块7 · 可落地的选址检查清单

把《葬经》的抽象原则转译为现代可执行的操作步骤：

### 7_1 🔍 第一步：大范围排查（势的层面）

1. 登高望远，观察方圆数公里的山水走向
2. 确认龙脉是否**连绵起伏、蜿蜒有情**，而非孤立断绝
3. **排除五不葬**：童山、断山、石山、过山、独山一律不选
4. 观察“势”是否在预选区域有**停顿、收束**的迹象

### 7_2 🔍 第二步：中范围验证（形的层面）

5. 检查**四灵格局**：
    - 后有无靠山（玄武垂头）
    - 左右有无护砂（青龙蜿蜒、白虎驯俯）
    - 前方有无开阔明堂或有情朝水（朱雀翔舞）
6. 观察水势：**环抱水为吉，反弓水为凶**；水宜屈曲慢流，忌直射湍激
7. 确认是否为“势来形止”的全气之地

### 7_3 🔍 第三步：小范围精察（穴的层面）

8. **土质检测**：挖探坑观察——
    - 土色是否黄润细腻？
    - 是否见水泉砂砾或朽骨臭泥？
    - 是否具备“细而坚、润而不泽”的特征？
9. **深浅判定**：
    - 高垄之地 → 深葬
    - 平夷之地 → 浅葬
10. **方位校准**：在势吉形真的前提下，结合八卦方位做最后微调（坐北朝南为经典格局）

### 7_4 🔍 第四步：综合判断

> ⚠️ 若势（大格局）为凶，再好的形和方位都难以挽回。

若势吉形真，方位只是锦上添花。

**案例**：走一遍三步：第一步望百里，见山脉自西北奔来至村北顿止、两侧无余脉续出，势已收，非断非独；第二步近看，后丘低垂、前有田畴、左右土岗环抱，唯西南水反弓向外，形中已带“腾去”；第三步掘土一尺，土色灰白夹砂砾且渗水泉，即犯“湿如割肉”。合断：非独山之凶，而是水反弓与土不洁相累，不宜葬。

## 板块8 · 现代视角的解读与祛魅

读《葬经》需要建立两层认知：

**第一层：作为环境选址的经验智慧**

+ “藏风得水”对应 microenvironment 的微气候调节：背山挡北风、面水调节湿度、左右砂山形成小盆地效应
+ “土质细坚”对应地质稳定性与排水性要求
+ “四灵格局”本质是对**地形包裹感、安全性、视野开阔度**的综合考量
+ “五不葬”是具有实际工程意义的负面清单（秃山无植被、断山地质不稳、石山难开挖、过山无聚气感、独山无屏障）

**第二层：作为文化哲学的宇宙观**

+ “气感而应，鬼福及人”体现了魏晋时期的“天人感应”思想
+ “铜山西崩，灵钟东应”是用共振现象类比气脉相通
+ 这些**吉凶祸福、荫庇后人的具体断言，属于传统神秘主义范畴**，应作为文化现象理解，而非科学结论

📌 **理性的读法**：把《葬经》当作**古代环境心理学与景观选址的经验的总结**来读，吸收其“顺势而为、藏风聚气、审势定形”的智慧内核，剥离其“荫庇后人”的迷信外壳。

**案例**：四灵格局可作环境评估读——玄武垂头即后有屏障挡北风，朱雀翔舞即前有开阔便于采光排水，青龙白虎即左右成小盆地效应；剥去“荫庇后人”，剩下的仍是一套可测的微气候模型。

## 板块9 · 核心要义速记卡

> 🎯 **一句话**：葬者乘生气也

🎯 **两件事**：藏风（聚之使不散）+ 得水（行之使有止）
🎯 **三层级**：势（千尺）→ 形（百尺）→ 方（校准）
🎯 **四灵格局**：玄武垂头、朱雀翔舞、青龙蜿蜒、白虎驯俯
🎯 **五不葬**：童、断、石、过、独
🎯 **六凶**：阴阳差错、岁时之乖、力小图大、凭福恃势、僭上逼下、变应怪见
🎯 **土质标准**：细而坚、润而不泽、裁肪切玉、备具五色
🎯 **深浅法则**：涸燥者宜深，坦夷者宜浅

**案例**：速记卡“六凶”一组最能提示人事——阴阳差错、岁时之乖、力小图大、凭福恃势、僭上逼下、变应怪见，其中“僭上逼下”即砂高压穴、势大欺主，与今日“高楼欺邻、光煞压窗”同一病症。

## 板块10 · 写在读后

《葬经》虽仅两千余字，却构建了堪舆学完整的理论骨架：**从“气”的哲学本体，到“形势”的观察方法，再到“四灵”的空间格局，最后落到“土质深浅”的工程细节**——逻辑链条严密，递进清晰。

它的真正价值不在于“荫庇后人”的吉凶承诺（这属于时代局限），而在于提供了一套**系统化的环境评估框架**：教人如何**宏观看势、中观看形、微观看质**，如何在自然中寻找那个“止”的点。

这套思维方法，对今天的**建筑选址、景观设计、人居环境评估**仍有启发——好的环境，必然是“藏风得水、四灵俱全、土质细坚”的，这与现代人对宜居社区的理解，在底层逻辑上并无二致。

**案例**：读《葬经》所得最大实惠，是把选址拆成三段动作——宏观看势、中观看形、微观看质；今日看一栋住宅的位置好坏，亦是先看区域水系山势，次看周边围合，最后才看脚下土质与排水。

> 💡 读《葬经》的正确姿态：取其山水之智，舍其祸福之妄；学其系统之思，祛其迷信之壳。如此，两千年的古老智慧才能真正照进现代人的生活。
