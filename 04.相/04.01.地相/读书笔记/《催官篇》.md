## 板块1 · 前言：这是一部讲「乘气」的书，不是讲「方位吉凶」的书

很多人翻开《催官篇》，第一反应是查表：亥龙配什么向、巽方见什么砂。查完觉得「玄之又玄」，合上仍不知何处下手。问题不在于这本书难，而在于读法错了——**它是一部关于「乘气」的操作手册，却被当成了方位断语的字典。**

全书以七言歌诀写成，分评龙、评穴、评砂、评水四章，又以「二十四山—天星—阴阳五行」为共同语言，把龙脉、穴位、山峰、水流四者串成一条闭环：**认龙 → 定穴 → 配向 → 消砂 → 纳水 → 乘气**。任何一环断掉，前面所有的「吉」都只是纸面吉。

《四库全书总目》对它的评价很到位：其说「颇具悬解」，解释寅甲二龙主疯跛时，能从「木盛生风、星应尾箕而好风、震为足、风淫末疾」一路推下来，言之成理，而非侈谈休咎。这正是读它的正确姿态——**要追每一句断语的推导链，不要背结论。**

本文的路线是：先拆全书的结构逻辑（第一部分），再逐章做原文精读与原理还原（第二部分），最后把歌诀翻译成一套可执行的现场流程与检查清单（第三部分）。读完后你应当能拿着罗盘，对着一段真实的龙脉，说出「为什么吉、吉在哪一节、哪一节一破全破」。

## 板块2 · 第一部分：先把骨架看清——全书的三条暗线

在逐句解经之前，必须先看见三条贯穿四章的暗线。否则评龙章背一堆龙名、评穴章记一堆坐向，永远是散的。

### 2_1 暗线一：天星是「坐标」，不是「神煞」

书中几乎不用「亥方」「艮方」这样的裸方位，而代之以星名：亥称天皇（紫微垣）、艮称阳枢（天市垣）、巽称太乙（太微垣）、酉称少微、丙称阴枢、丁称南极……

这层包裹**不是为了神秘化，而是为了给出可推导的属性**。每一组星名背后都绑定着五行、所主之事与对应关系：

| 方位 | 天星称谓 | 垣局/属性 | 所主 |
| --- | --- | --- | --- |
| 亥 | 天皇、紫微 | 紫微垣（帝王之星） | 官禄、功名、权力，全书第一贵 |
| 艮 | 阳枢、天市 | 天市垣（财库） | 财富、人丁、商业 |
| 巽 | 太乙、太微、阳璇 | 太微垣（尚书之府） | 文章、科举、学术 |
| 丙 | 阴枢、天贵 | 火，南极照临 | 权力之贵、赦文（消灾） |
| 丁 | 南极 | 寿星所出 | 长寿、福报 |
| 酉 | 少微、阳关 | 少微垣（西掖） | 地方文名、清贵翰苑 |
| 庚 | 天汉、天潢 | 武库 | 武贵、财富 |
| 辛 | 天乙、阴璇 | 天乙之居 | 寿、文章、如花女人 |

记住这张表，书中 90% 的「某龙某穴」立刻变得可读：**不是"亥龙好"，而是"亥龙属水、带天皇贵气，所以要配出某类向、避某类砂"。**

> **干货拓展①｜纳甲是天星的语言规则**

为什么「阳璇（巽）—阴璇（辛）」「阳枢（艮）—阴枢（丙）」总是成对出现？因为八卦纳甲：艮纳丙、巽纳辛、乾纳甲、坤纳乙、坎纳癸申子辰、离纳壬寅午戌、震纳庚亥卯未、兑纳丁巳酉丑。纳甲即「同气」，所以艮龙喜丙、巽龙喜辛，本质是**本宫与所纳之位互相催发**。理解纳甲，比背任何口诀都省事。

### 2_2 暗线二：三吉六秀是「优选池」，不是「万能钥匙」

书中明确把二十四山分阴阳，并给出优选框架：

+ **三吉龙**：亥（天皇）、震（阳衡）、庚（天汉）——主极品贵、武权、名宦；
+ **六秀龙**：艮、巽、辛、丙、兑、丁——主秀气、文名、旺财旺丁。

原文说「天皇天市龙第一，巽辛兑丁官可必」，又说「四神八将应位起，三火并秀三阳冲」。看上去是在堆吉位，实际在讲一件事：**格局的等级取决于「贵龙 + 贵砂贵水同到」的叠加度**。一条亥龙，若八方无峰、三阳无水，最多算「龙真」，谈不上催官。

这里必须破除一个常见误读：**三吉六秀是「候选名单」，不是「见之即吉」。** 同一章紧接着就写「廉贞作祖为官疾」「阴枢南极及天汉，行龙受穴最荣吉」——同在六秀里的丁、丙，也要看是「行龙」还是「受穴」、有没有驳杂之气。吉位只是入场券，纯度才决定名次。

### 2_3 暗线三：整本书的动词只有四个——剥换、挨加、收放、乘气

四章看似各论一事，其实共用一套动作术语：

+ **剥换**（评龙）：粗老之山一路脱煞换嫩，龙气由杂转纯；
+ **挨、加、偏、倚**（评穴）：气从何方入，穴就向何方偏移分毫；
+ **收、放**（评砂评水）：吉砂收而用之，凶砂放而避之，水口关锁；
+ **乘气**（全篇归宿）：最终要「乘得生气」，而非「占得好方位」。

结尾两句是全书的眼：「详观砂水定品秩，收放乘气为真机。土圭测位勿草草，心意消息毋昏欺。」——**罗盘测位不可草率，心中体察不可自欺**。这已经不是术，是心法。

> **过渡**：三条暗线看清后，下面进入逐章拆解。顺序上先做「辨龙」，因为它是整座楼的地基——地基一错，后面的配向、消砂、纳水都是在精致地放大错误。

## 板块4 · 评龙章：先辨「来龙」贵贱，再谈一切

**本章核心命题**：龙脉的贵贱，不取决于山高不高，而取决于**有没有剥换、纯不纯、落脉偏正如何**。

### 4_1 原文精读：三组关键句

**① 起手三句定格局**

> 催官第一天皇龙，剥龙换入天市东。少微阳璇左关局，廉贞起祖峰崇崇。

白话：催官第一等格局，是亥方天皇龙；龙脉层层剥换，行至艮（天市）一方；左侧有兑（少微）、巽（阳璇）关拦护局；祖山出廉贞火星，峰峦叠起。

**原理还原**：这一句里藏着三个判断标准——

+ 「**剥龙换**」：龙脉必须脱煞换嫩。老龙不剥换，煞气未除，纵然高大不为吉；
+ 「**左关局**」：砂水环护有情，龙气才收得住；
+ 「**廉贞起祖**」：火星作祖，主官贵显赫，且廉贞为「帝之所由出」，有生生不息之意。

**实操抓手**：野外认龙，先看**过峡与剥换**。如果一条山脉从头到尾都是同一粗顽石质、毫无变化，直接降级，不必再看向。剥换的痕迹（由粗到细、由石到土、由直硬到屈曲）才是「真龙脱煞」的证据。

**② 格局总纲：四神八将 + 三火 + 三阳**

> 四神八将应位起，三火并秀三阳冲。三阳洋朝入庚震，食邑开府应三公。

+ **四神**：乾坤艮巽四正方位有峰（一说指四金龙辰戌丑未，依派别而异，现场需统一口径）；
+ **八将**：甲庚壬丙乙辛丁癸八干位有星峰相应；
+ **三火**：午（天官火）、丙（地禄火）、丁（人爵火）——主秀贵；
+ **三阳**：巽、丙、丁（主文章福寿，为全书最贵之水）。

**原理还原**：「三阳」不是任意三条水流，而是**向首的临官、帝旺方位见水朝**。巽为五尚书照临（文章之府），丙丁为南极老人星出没之所（五福受命之司），天道贵南而贱北，故三阳水「水之至贵者也」。

**③ 立向铁律：亥龙配丙向**

> 阳枢穴癸为正向，天皇太微为正向。

后句即「亥龙立丙向」，全书第一催官局。原文进一步说明：亥（紫微）照龙、丙（太微）照向，天市（艮）居左、少微（酉）居右，四垣齐备，故为「正向」。

> **原理还原（这是全书最容易卡住的地方）**：

亥在赖公五行属**水**，丙属**火**，若按「水生木、火生土」的通用生克，水火不能相生，反而相克——那为何亥龙偏配丙向？

> 关键在于：**赖公配向的优先级是「阴阳纯一 + 纳甲/天星对应」，而非正五行相生**。亥为天皇（紫微垣，至尊），丙为阴枢（天贵、南极），二者在**天星层级上构成「照龙—照向」的君臣对应关系**；同时亥龙属阴、丙向亦属阴（净阴），符合「阴龙阴向」。所以「亥—丙」成立的根基是**阴阳纯一 + 天星配对**，不是「水生火」。
>
> 这也解释了为什么书中反复强调「净阴净阳」——**一旦阴阳驳杂，再好的天星配对也白搭。** 此点详见第三章拓展。

**④ 驳杂之戒：全书最长、也最被忽视的一段**

> 亥山一丈可致富，巽水一勺可救贫。辛山十丈富相亲，难养过房异姓人。

这一组讲的是**「纯一」的分寸**：亥山「一丈」即隔辛亥一穴便成癸亥水穴，纯则致富；辛山「十丈」暗喻隔了辛酉、己酉、丁酉、乙酉四穴，气杂则「难养过房」。**吉位也怕混杂，气不纯则福力打折。**

> 龙辨中抽左右落，吉凶官职定荣削。左落乾亥如双行，乾多亥少那堪作。右落乾亥如同行，亥多乾少堪裁度。

这一段是全章的实操精华，讲的是**「中抽 / 左落 / 右落」**三类落脉：乾亥双行，若乾多亥少则气杂不可作，亥多乾少尚可裁度；壬亥双行同理。判据只有一句话——**主脉占几成**。

**实操抓手**：在**过峡处或父母山顶**下罗盘，看入首束气落在二十四山哪一字；若骑缝（如乾亥各半），先看左右护砂哪边有力，再定「可裁 / 不可裁」。**骑缝之脉一律降级处理，不抱侥幸。**

**⑤ 全书最硬的一句**

> 衰病绝乡为福薄，死墓混杂家流离。冠官生旺胎养位，不须更论阴阳比。

这段话常被断章取义。**「不须更论阴阳比」是有前提的**：只有在龙脉落于冠带、临官、生旺、胎养等位（即「在局内」）时，才不必再纠结阴阳比例；若已落在衰、病、绝、死、墓，纯阴纯阳也没用。**优先序是：生旺死绝 > 阴阳纯驳。** 这是评龙章真正的核心结论。

### 4_2 本章方法论提炼

| 判断项 | 吉的标准 | 凶的信号 | 现场怎么做 |
| --- | --- | --- | --- |
| 剥换 | 粗老脱煞、由石到土、层层变化 | 一路粗顽、毫无变换 | 追过峡，无剥换即淘汰 |
| 纯度 | 一卦独行、中抽单行 | 双行骑缝、气杂 | 乾亥/壬亥看孰多，多者可裁 |
| 生旺 | 冠官生旺胎养位 | 衰病死绝墓 | 先定十二位，再论阴阳 |
| 祖山 | 廉贞起祖 | 无祖或祖山破碎 | 追溯少祖、祖山星辰 |
| 关拦 | 左关/右关局成、砂水护有情 | 直去无收 | 查砂水是否回头顾祖 |

> **干货拓展②｜四大局的底层框架**

《催官篇》本质上是**正五行风水**的成形之作。它把地理分为四大局：东方木局、南方火局、西方金局、北方水局（二阴二阳），每局十二龙（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养），共四十八条龙、六十穴。坐穴按进气位置又有**正向、左腧、右腰、左耳、右耳、中脑**之分（如子下含甲子、丙子、戊子、庚子、壬子，正向为戊子，余各有所指）。

> 这意味着：**「三吉六秀」是快速筛选层，「四大局十二位」才是精确判定层**。实务中应先归局、定龙在十二宫中位次，再谈吉凶。只背三吉六秀而不入局，是这本书最常见的读法陷阱。

## 板块5 · 评穴章：乘气分毫定祸福——「挨、加、偏、倚」四法

**本章核心命题**：穴不点正中，气从何方来，穴就向何方偏。**龙真而穴假，等于前面的辨龙全部作废。**

### 5_1 原文精读：以亥龙三穴为例

> 催官第一天辅穴，天皇气从右耳接。穴宜挨左微加乾，天皇气贯穴天池。（壬山丙向）

天皇气射天厩星，微挨西兽加壬行。天厩穴空始为吉，耳受左气官班荣。（乾山巽向）
天皇气冲穴北道，挨左立穴为枢要。稍加乾位细推祥，右耳乘气勿冲脑。（癸山丁向）

**白话**：亥（天皇）龙气从右耳进入，穴位就要**稍挨左边、借乾宫之气**；气从左耳入，则挨右。并且特别警告「**勿冲脑**」——偏倚过度，气直射穴顶，反成凶。

**原理还原**：这一段讲的是一个极具体的技术——**「挨加」**。穴位不是落在主脉正下方，而是根据龙气入射的左右、高低，作毫厘级的偏移，以「借邻宫天星之气补全格局」。同一亥龙，因落脉偏正不同，可立壬山丙向、乾山巽向、癸山丁向三局，各有「耳受/腰受」之别。书中明言：**耳受气者为上，腰受气者为次**。

**实操抓手**：

1. **先定龙脉中轴**（过峡—入首—落脉一线）；
2. **辨气从何入**：右耳来气 → 穴挨左；左耳来气 → 穴挨右；腰脉来 → 穴接腰；
3. **「微加」的分寸**：偏移量以「一线之内」为准，口诀是「分金避空亡」——**宁偏不正中，但绝不过度**；
4. **测脉的粗细**：脉宽则穴放（略开），脉紧则穴收（收窄），贵在「乘得生气」。

> 二十四龙诸吉穴的完整配向表（亥龙五向、艮龙八向、巽龙三向……）是本章主体，篇幅所限不逐条抄录，但**必须掌握两个规律**：
>
> + **每龙有多向，差异只在「左落/右落/中抽」**——同一龙脉，落脉偏一点，配向就变；
> + **每向必带「挨加某宫」**——这是本章的命门，漏掉「微加」二字就等于没读懂。

**② 另一句被低估的话**

> 壬癸背一面九离，河洛理数无相连。四垣四兽各正位，五气顺逆相凭依。（子山午向）

讲的是**河图洛书与顺逆**的配合：四垣（亥、艮、巽加中天）各居正位，五气的顺行与逆行互为凭依。提醒我们：**配向不是单看「向方吉」，而是看「四垣是否各安其位、五气顺逆是否合局」。** 一座穴若向方极吉但四兽偏废，仍属次品。

### 5_2 本章易错点清单

+ ❌ **正中下针**：以为「龙脉正下方就是穴」，结果龙气从耳入、穴却挡在脑，气不贯；
+ ❌ **只记坐向不记挨加**：背下「亥龙丙向」，现场却不知微加乾/加壬，福力大减；
+ ❌ **混淆「左右」**：罗盘上的「左」对应实地方位的「右」，古今表述易反，**必须以罗盘实测为准，不可仅凭文字左右下判断**；
+ ❌ **忽视深浅**：脉紧穴收、脉宽穴放，深浅不合则气散。

> **过渡**：龙认对了、穴点准了，接下来是「外局」——砂与水。这两章常被当成附庸，实则是**决定「发贵还是只发富」的关键分水岭**。

## 板块6 · 评砂章与评水章：砂主贵、水主富，二者缺一不成催官

### 6_1 评砂章：砂是「官阶」的刻度

> 催官之砂惟四方，云霄屹立官爵强。四维低峰叠叠起，千仓万箱耀州里。

**原理还原**：砂看两件事——**天星到位 + 形体有情**。乾坤艮巽（四神）有峰屹立云霄，主官爵强；四维低峰叠叠（不逼压），主财富丰盈。判断顺序是：**先看天星方位对不对，再看形体秀不秀**。

> 一峰秀出一登科，双峰兄弟应双举。阳璇双峙美无度，同玑入云生宰辅。

**实操抓手（砂的定量读法）**：

+ **峰数 → 人数**：一峰出一登科，双峰应兄弟同举，这是「以形定量」的典型；
+ **峰高 → 官阶**：奇峰列秀、三角并峙 → 科甲魁名；高耸入云 → 宰辅三公；低圆方正 → 仅富而已；
+ **峰形 → 品类**：文笔峰（尖秀）→ 文贵；旗鼓砂（方正如旗）→ 武贵、将军；探头、捶胸、反背之砂 → 淫乱盗贼。

> **吉砂三十三格、凶砂二十五格**（旧注归纳）：吉如「四神全、八将备、三角峙、禄马聚」；凶如「五星受制、四杀擅权（辰戌丑未四位高压恶山）、八门缺（八卦之位凹陷）」。其中**「四杀擅权」「八门缺」是最该优先排查的两项**——比什么文笔峰都更要紧。

> **干货拓展③｜临官砂是砂法的天花板**

八龙四局各有其**临官砂峰**：如乾山巽向、亥山巳向，临官砂在坤位。**只有临官砂高耸入云，才主「官高且掌权柄」**；若临官砂低小，只能主「富行百里」。临官砂宜正体光圆、有情顾穴，且本峰之后第二、三层层层稍高，称为「临官奇异之峰」。

> **实操动作**：立向定好后，**先找本局的临官方**，看该方有无高耸秀峰。有，则催官有望；缺，则只能论富。这是砂章里性价比最高的一个检查点。

**原文警示句**：

> 龙神带得四金行，必主寡夭并尼僧。……枢玑阳旋山若陷，官不食禄名虚称。

「四金」指辰戌丑未，「山陷」即应位空缺。意思是：**吉星到位还要看高低**——枢、玑、阳璇诸峰若低陷，纵然方位对，也只是「官不食禄」的虚名。对应到实操：**缺则补（人工堆砂、植树）、陷则避（改向或降格）**。

### 6_2 评水章：水是「催发速度」的开关

> 催官之水唯三阳，水朝砂秀官爵强。来宜宽阔去宜迟，湾环屈曲水回翔。

**原理还原**：三阳（巽、丙、丁）水朝 + 砂秀 = 官爵强。**水的形体同样有讲究**：来处宜宽阔、去处宜迟缓，湾环屈曲、之玄曲折为吉；直去直来、冲心射胁为凶。

> 三阳无砂水不贵，只主烟亲发财利。……穴乘兑亥，阳璇朝，玉堂金马多名誉。

**原理还原**：这句是全篇最被低估的一句——**「三阳若无砂，贵禄不起，火星不秀拔，总有好水，不过富而不贵」**。也就是说：**水是催发的发动机（山静水动，水应验最快），砂是官阶的刻度，二者必须并朝**。只水无砂 → 发富不发贵；只砂无水 → 贵而迟发。

> **干货拓展④｜归元水 / 催官水**

以龙立向时，有「**归元水**」之说：震龙见庚、巽龙见辛、离龙见壬、坤龙见乙癸、兑龙见辛、乾龙见甲壬、坎龙见癸、艮见丙，以上八局，**向方见水朝即为催官水（归元水）**。例：亥龙立丙向，则巽（阳璇）方见水朝堂，即为催官水。

> **验证动作**：定好坐向后，立即查**向方与临官方是否有水来朝**。这是「评水章」在现场唯一必须先做的事。

> 二宫有水名赦文，永无凶祸临家门。

**原理还原**：**冠带、临官二宫有水来，名为「赦文水」**——冠带为小赦文，临官为大赦文；乙辛丁癸为阴干赦文，甲庚丙壬为阳干赦文。有水朝堂，主「永远无凶祸、晚景荣华、出孝义之子」。

**总诀（水法心法）**：

> 水法多端要审详，来去屈曲最为良。之玄曲折流出去，富贵荣华世代昌。直去直来终不吉，冲心射胁主刑伤。

对照今天的形峦判断，这句话依然是最实用的那条：**水宜弯环抱穴、宜有来有去、宜关锁；忌直流、忌冲射、忌反弓。**

### 6_3 砂水合论：一套优先级

全书反复暗示一个优先级，整理如下（**从根到叶**）：

> **龙真 > 穴的 > 砂水有情 > 理气合局**

+ 理气无峦头不灵（坐向再准，砂飞水走也是假）；
+ 峦头无理气不准（形局完美，理气不合则迟发或发而有损）；
+ **理气是锦上添花的微调工具，不是根本。**

这也是为什么评龙章要用「四龙剥换为上吉……详观砂水定品秩，收放乘气为真机」收尾——**一切最终都回到「乘生气」三个字。**

> **过渡**：四章原理理清后，下面把它们压成一套可以带去现场的流程与清单。

## 板块7 · 第三部分：可落地实操——从读到做的六步流程

> 说明：以下内容是把歌诀翻译为现代操作语言，**适用于山地阴宅寻龙点穴及阳宅大环境勘定**。现代城市、公墓、平原环境需做类比转换（见后文），不可生硬套用。

### 7_1 步骤一｜定来龙（格龙）——「入首」是唯一真值

| 项目 | 操作 | 工具 |
| --- | --- | --- |
| 位置 | 龙脉过峡处 或 父母山顶 | 罗盘（地盘正针） |
| 动作 | 下罗盘，看龙从二十四山何字入首 | 记录「某龙」 |
| 判据 | 开面者真、不开面者假；有无剥换 | 目测 + 追脉 |

**输出**：如「亥龙入首」。同时追溯**少祖山、祖山星辰**（是否廉贞起祖）。

> ⚠️ 关键细节：入首指「龙脉结穴前最后一段束气的脊线」，不是远祖山。**只看过峡到入首这几节，不必追到源头。**

### 7_2 步骤二｜辨纯度与生旺——先定「在局 / 不在局」

1. **纯度**：中抽单行 > 左落/右落 > 双行。双行则看主脉占比（亥多乾少可裁，乾多亥少不可作）；
2. **归局**：把来龙归入四大局之一，定其在**十二宫（长生→养）**中的位次；
3. **优先序**：先看是否落在**冠、临官、生旺、胎养**等位 → 若在，则「不须更论阴阳比」；若落**衰病死绝墓**，直接降级。

> 这是把第一章 1.2 提炼成的现场动作，一句话：**生旺死绝的判定必须先于阴阳纯驳。**

### 7_3 步骤三｜点穴——按「耳 / 腰 / 脑」接气，并做挨加

1. 在穴位中心下罗盘，定**坐山朝向**；
2. 辨龙气从**左耳 / 右耳 / 左腰 / 右腰 / 脑**何方进入；
3. 套用本章规则：
    - 右耳来气 → 穴挨左，微加邻宫；
    - 左耳来气 → 穴挨右；
    - 腰脉来气 → 穴接腰；
    - **严禁「气冲脑」**（过度偏移致气直射穴顶）；
4. 脉宽穴放、脉紧穴收；深浅随龙脉粗细。

**输出**：如「亥龙，气从右耳接，穴挨左微加乾，立壬山丙向」。

### 7_4 步骤四｜立向配局——净阴净阳是第一关

**铁律**：阳龙立阳向、阴龙立阴向；阴阳驳杂 → 败财损丁。

净阳十二山：乾、甲、坤、乙、子、癸、申、辰、午、壬、寅、戌
净阴十二山：卯、庚、亥、未、巽、辛、艮、丙、酉、丁、巳、丑

> **四线禁用（兼向必查）**：山界缝、卦线空亡、分金孤虚、纳音相克。**兼向只允许「阳兼阳、阴兼阴」，绝不可阴阳互兼。**

口诀：「辛戌乾亥亥壬家，丑癸艮寅怕虎牙……此是劫煞定不差」——兼向若踩中**辛戌、乾亥、亥壬、癸丑、艮寅、甲卯、卯乙、辰巽、巽巳、丙午、午丁、未坤、庚申、酉辛**等线，一律不可用。

> **干货拓展⑤｜三盘分工（避免乱盘）**
>
> + **地盘正针**：格龙 + 立向（定坐山朝向、收砂纳水）；
> + **人盘中针**：消砂（以坐为我，论生旺奴煞泄）；
> + **天盘缝针**：纳水（看来去水、水口）。
>
> 常见错误是「用地盘测来去水」，导致阴阳判错。**水一定用天盘，砂一定用人盘。**

**参考：亥龙五向速查**

| 来龙/落脉 | 坐向 | 接气要点 |
| --- | --- | --- |
| 亥龙·右落 | 壬山丙向 | 气从右耳接，穴挨左微加乾 |
| 亥龙·左落 | 乾山巽向 | 微挨西兽加壬行 |
| 亥龙 | 癸山丁向 | 气冲北道，挨左，稍加乾，勿冲脑 |
| 亥龙 | 丑山未向 | 挨加邻宫（依中抽/左右落定） |
| 亥龙 | 酉山卯向 | 气贯左耳 |

### 7_5 步骤五｜消砂纳水——先找「临官砂」与「归元水」

**消砂**：以人盘中针测主要山峰所在方位 → 对照本局**临官砂峰** → 高耸入云则催官有望，低陷破碎则降格。

**纳水**：以天盘缝针测来水、去水、水口 → 查三项：

1. **三阳水**（巽、丙、丁）是否来朝；
2. **归元水 / 催官水**（本龙对应的向方水）是否朝堂；
3. **赦文水**（冠带、临官二宫有水）是否具备。

**形体校验**：水来宜宽、去宜缓、湾环屈曲为吉；直去直来、冲心射胁、反弓为凶。**砂水必须并朝**——只有水无砂，富而不贵。

### 7_6 步骤六｜乘气校验 + 化解——四重闭环

按**龙 → 穴 → 砂 → 水**顺序逐项复核，任何一环缺失都记录为「待化解项」：

| 问题 | 化解思路（传统做法） |
| --- | --- |
| 临官方无峰 / 峰低陷 | 人工补砂、植树造景、或改立向 |
| 凶砂逼近（探头、捶胸、反背） | 避开、遮挡、或降格不用 |
| 水直去无收 | 设水口关锁、湾环导引 |
| 阴阳驳杂 / 踩空亡线 | 调整分金兼向、避开劫煞线 |
| 四杀擅权（辰戌丑未高压恶山） | 优先级最高，通常改址优于化解 |

**最后一步（也是最容易被跳过的一步）**：依来龙所属卦的**催贵用事日干支**择日下葬/安碑（如乾卦取丙子、丙午、丙寅等六组，艮卦取庚子、庚寅、庚辰等六组），并参考**太阳到山/到向**以激活龙气。

> 原则：催官一派主张**「即点即葬」**，不特别选年月，重在日时；净阴净阳要求「阳龙用阳课、阴龙用阴课」。

### 7_7 实操速查：吉凶组合对照（现场测量后查表）

| 类别 | 吉的组合（例） | 凶的组合（例） | 可能应事 |
| --- | --- | --- | --- |
| 龙向 | 亥龙丙向、艮龙庚向 | 辰龙戌向、戌龙辰向 | 吉主官贵速发；凶主争斗灾病 |
| 砂法 | 巽方文笔峰、丙方旗鼓砂 | 乾方捶胸砂、坤方探头砂 | 吉主文武功名；凶主淫乱盗贼 |
| 水法 | 庚方来水、弯环入堂 | 子午方水直冲、癸方水斜飞 | 吉主财富汇聚；凶主意外破财 |
| 特殊 | 龙身带御街、玉印贵格 | 水口劫煞、黄泉 | 吉主极品大贵；凶主夭折横祸 |

### 7_8 现代环境的类比转换（重要）

古法生于山地田园，**城市与公墓不可生搬**：

+ **龙**：以道路为「虚水龙」，主干道、高速可视作大龙，小区内路为支龙；观察其来去、交汇、环抱；
+ **穴**：大楼、小区中心或住宅本身即穴场，**纳气口（大门、阳台）能否收到生旺之气**是关键；
+ **砂**：周围建筑视为砂——**前方案高楼如「逼压探头」，宜避；背后高楼如「靠山」则吉**；
+ **水**：道路走向、排水、真实水流类比水法，**环抱有情吉、反弓直冲凶**。

> 类比的核心不变：**龙真穴的、砂环水抱、关锁有情**。变的只是「山」和「水」在现代的具体载体。

### 7_9 应期推断（进阶，避免机械对应）

吉凶组合的「应验时间」不可硬套，传统上有三层口径：

1. **以龙向组合定「品类」**（发贵/发富/发丁），不含时间；
2. **结合三元九运**，如当下旺星飞临相关宫位，则可能在此运内应验；
3. **以实际形峦的强弱定迟速**——形局真而理气合则速发，形局弱则迟发或发而有损。

**结论**：不要把某条断语绑定「某年必发」。应期是「运 + 形 + 理」三者合参的结果，单看任何一项都不可靠。

## 板块8 · 第四部分：读完之后的五条总纲

1. **全书主语是「乘生气」，不是「吉方位」**。方位只是乘气的接口，气不纯、气不贯，方位再好无用。
2. **结构是递进闭环**：辨龙（根）→ 点穴（干）→ 消砂 + 纳水（枝叶花果）。**顺序不可颠倒，前一步错了后面越做越错。**
3. **纯度 > 一切花哨**：剥换、单行、生旺位、净阴净阳，本质都在讲「气要纯」。全书最长的段落都在讲「双行驳杂」，足见作者真正在意的是什么。
4. **砂与水必须合看**：三阳无水则贵不显，三阳无砂则富而不贵；临官方有峰、向方有水朝，才是完整的催官局。
5. **理气是微调，峦头是根本**——龙真穴的之后，理气才「锦上添花」；没有真龙，再精的分金也只是精确的错误。

## 板块10 · 附录 B：二十四龙诸吉穴（节录 · 以龙立向总纲）

> 原则：**耳受气者为上，腰受气者为次**；每龙有多向，取决于「左落 / 右落 / 中抽」。

+ **亥龙五向**：壬山丙向、乾山巽向、癸山丁向、丑山未向、酉山卯向；
+ **艮龙八向**：癸山丁向、壬山丙向、甲山庚向、乙山辛向、卯山酉向、乾山巽向、亥山巳向、丑山未向；
+ **巽龙三向**：乙山辛向、巳山亥向、坤山艮向；
+ **兑（酉）龙三向**：坤山艮向、乾山巽向、亥山巳向；
+ **震（卯）龙四向**：甲山庚向、乙山辛向、癸山丁向、巳山亥向；
+ **丙龙四向**：巳山亥向、甲山庚向、乙山辛向、坤山艮向；
+ **丁龙二向**：坤山艮向、巳山亥向。

其余壬、子、癸、丑、寅、甲、乙、辰、巳、午、未、坤、申、庚、辛、戌、乾诸龙各有定穴，可据「入首左右落 + 耳腰受气」二诀现场推演，不必死记。
