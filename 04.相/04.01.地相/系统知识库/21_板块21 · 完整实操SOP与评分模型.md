## 板块21 · 完整实操SOP与评分模型

### 21_1 本块定位

零件都齐了，现在总装。这一块把前面各块压缩成可直接执行的流程：**先排除、后优选；先形势、后理气；先大势、后分金**。

### 21_2 总流程七步

```plain
第1步 审势 → 第2步 寻龙 → 第3步 察砂 → 第4步 观水 → 第5步 点穴 → 第6步 立向 → 第7步 复核

```

| 步骤 | 核心动作 | 输出 | 不通过则 |
| --- | --- | --- | --- |
| **1. 审势** | 登高或卫星图看大势，排除五不葬 | 大势判断 | **终止** |
| **2. 寻龙** | 追剥换、过峡、缠护，格入首 | 龙的品级分 | 降级或终止 |
| **3. 察砂** | 人盘消砂，定生旺财泄杀 | 砂法记录表 | 记录为待改造项 |
| **4. 观水** | 天盘纳水，看来去、水口、凶形 | 水法记录表 | 命中凶形则终止 |
| **5. 点穴** | 定四形、走点穴四步、选杖法定深浅 | 穴位与杖法 | 犯穴病则终止 |
| **6. 立向** | 七步立向流程加分配分金 | 坐向与分金 | 犯空亡或八煞则重定 |
| **7. 复核** | 三查原则：形势查、理气查、时间查 | 一页纸结论 | — |

### 21_3 否决式筛查：先排除，后优选

**这是所有实操中最省时间的一步。** 按顺序过这六道闸，任一命中即出局：

| 闸门 | 检查项 | 参考板块 |
| --- | --- | --- |
| **闸 1** | 五不葬：童、断、石、过、独 | 板块3 |
| **闸 2** | 十大穴病任一命中（贯顶、破面、漏腮、折臂、坠足、绷面、饱肚、割脚、虎蹲、龙踞） | 板块3 |
| **闸 3** | 凶水八形任一命中且无法化解 | 板块9 |
| **闸 4** | 十不居（阳宅）任一命中 | 板块17 |
| **闸 5** | 孤龙无缠、无剥换、骑缝驳杂（龙品级分偏低） | 板块4 |
| **闸 6** | 穿山七十二龙压线空亡（龙气断） | 板块12 |

> **心法**：**新手总想找"吉"，老手先找"凶"。**

排除法比优选法可靠得多，因为**凶是确定的，吉是有条件的**。

```plain
   否决式筛查流程

   第1步 五不葬？ ── 命中 ──→ 出局
   第2步 穴病？   ── 命中 ──→ 出局
   第3步 凶水形？ ── 命中且不可化解 ──→ 出局
   第4步 十不居？ ── 命中 ──→ 出局
   第5步 孤龙无缠？ ── 命中 ──→ 出局
   第6步 穿山空亡？ ── 命中 ──→ 出局（一票否决）
                ↓ 六闸全过
          进入优选与评分

```

### 21_4 打分模型（实用化加权评分卡）

把龙、穴、砂、水、向五项量化，形成可比较的分数：

| 维度 | 权重 | 评分要点 | 得分 |
| --- | --- | --- | --- |
| **龙** | 30 | 出身(15) + 剥换(20) + 过峡(15) + 起伏(10) + 缠护(20) + 水口(10) + 入首清纯(10)，折算百分 | /30 |
| **穴** | 25 | 四形是否成形、穴晕有无、虾须蝉翼、是否犯四忌、杖法是否对号 | /25 |
| **砂** | 20 | 四灵是否齐全、龙虎是否平衡、案朝是否得位、消砂生克 | /20 |
| **水** | 15 | 水形、来去方位、水口关锁、是否犯凶形 | /15 |
| **向** | 10 | 净阴净阳、分金旺相、龙水向三合、不犯八煞 | /10 |
| **合计** | **100** |  |  |

**判读**：

| 分数 | 判读 | 处理 |
| --- | --- | --- |
| **85 到 100** | 上地 | 可作重要选择 |
| **70 到 84** | 中地 | 可用，注意短板项 |
| **55 到 69** | 小地或小吉 | 只作权宜 |
| **低于 55** | 不建议 | 弃 |
| **任一闸门命中** | 直接 0 分 | 不参与评分 |

> ⚠️ 评分卡是**辅助决策工具**，不是真理机器。它的价值在于**强制你逐项检查、不遗漏**，而不是给出一个精确数字。不同派别权重可自行调整，但**调整后必须一致适用**，不能对同一批对象用两套权重。

### 21_6 阴宅 SOP（山地流程）

1. **卫星图预勘** → 圈 3 到 5 个候选区；
2. **现场审势**，排除五不葬；
3. **追龙脉**：祖山 → 少祖 → 父母 → 入首，记录剥换链；
4. **找过峡**，确认蜂腰鹤膝与护送；
5. **格龙两层**：过峡或束咽处下罗盘用地盘正针加穿山七十二龙格远脉；穴后八尺处用天盘缝针加透地六十龙察近气；
6. **按"乘金相水穴土印木"四步点穴**，避开十大穴病；
7. **人盘消砂、天盘纳水**；
8. **定局（四大局）**，确认水口归库；
9. **立向（净阴净阳）加分配分金**（取丙庚或丁辛）；
10. **定深浅**（脉浮沉急缓）；
11. **复核四灵与藏风**，写报告。

### 21_7 阳宅（自建房或别墅）SOP

1. **地块外局十二问**；
2. **确认靠山、明堂、龙虎、水口**；
3. **定建筑基底（"穴位"）**，避开低洼积水与山脊冲处；
4. **测主干结构坐向**，定局立向；
5. **大门定位**（气口五项核查）；
6. **内部功能分区**：动区（客餐厨）在外、静区（卧书）在内；
7. **厨卫定位**（厨房边角或次要方、卫生间边角有排风）；
8. **排水路径设计**（不走中心、不穿卧室下、不直泄大门）；
9. **微气候优化**（日照、通风、噪声、湿度）；
10. **缺陷化解**（以实压虚）。

### 21_9 案例故事：一票否决省下的三天

某次踏勘，一行四人要在一片山区选一处安置点，预定的工作时间是三天。带队的是一位有二十年经验的老手。

#### 第一天上午：他没有急着上山

他做了两件事：

1. 在驻地用卫星图做了两小时预勘，圈出**五个候选区**；
2. 开车沿山脚走了一圈，做了一次大势观察。

#### 结果在第一道闸就停下了

| 闸门 | 发现 |
| --- | --- |
| **闸 1（五不葬）** | 三处候选区中有两处是**过山**（龙脉仍在奔腾未停，处于坡面径流通道，无驻留条件）；另一处是**断山**（被采石场切开，断面上可见明显开挖痕迹，边坡不稳） |
| **闸 3（凶水八形）** | 剩余一处虽不命中五不葬，但沟口正对**直冲水**，且两侧无遮挡可化解 |

**结论：该区域不适合做安置点，建议另选片区。**

同行的一位年轻队员当场表示不满意，原话是：**"我们连罗盘都没拿出来，这样就放弃了？"**

#### 带队者的回答

他说了一段后来被队员记在笔记本第一页的话：

> "你在这片山上花三天，能测出很精确的数据。但如果这片山根本不聚气，那些数据就是废纸。
>
> 我们先确认'这里能不能用'，再决定要不要花三天。现在五分钟就确认了不能用，省下的两天半，够我们把相邻片区走完两遍。"

#### 后续发生了什么

| 时间 | 动作 |
| --- | --- |
| 第一天下午 | 改到相邻片区，找到两个合格候选区 |
| 第二天 | 完成格龙与立向 |
| 第三天上午 | 复核、写报告 |
| **结果** | **原本三天的任务，两天完成，且结论更可靠** |

更关键的是：省下的一天里，他们**把相邻片区多走了一遍**，这直接让候选区从两个增加到三个，最终选择的质量也更高。

#### 复盘要点

**第1步 否决式筛查最大的价值是"省时间"。** 在错误的地方花三天做精细测量，不如花半天确认"这里根本不能用"。**省下的时间还能提高最终结论的质量——这是双重收益。**

**第2步 "凶是确定的，吉是有条件的"。** 五不葬、穴病、凶水形是**确定性的排除项**；而"某某方位大吉"往往需要一堆前提同时成立。**排除法比优选法可靠，原因就在这里。**

**第3步 先排除、后优选，是这套方法论最硬的一条。** 无论你是否接受它的吉凶体系，这条都能提升环境判断力——因为它本质上是一种**资源分配策略**。

**第4步 那位年轻队员的问题，恰恰是新手最常犯的错**：把"测量"当成了"判断"。**测量是手段，判断才是目的。** 罗盘拿出来之前，判断已经可以开始——而且应该先开始。

> **给自己留的一句**：每次出门前先问自己——**我今天要确认的是"能不能用"，还是"有多好"？** 顺序错了，一天就白跑了。
