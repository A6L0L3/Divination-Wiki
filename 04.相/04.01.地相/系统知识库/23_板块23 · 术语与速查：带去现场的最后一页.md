## 板块23 · 术语与速查：带去现场的最后一页

### 23_1 本块定位

供现场翻阅——术语、口诀、数字、误区。

建议**单独打印**这一块，随工具包携带。

### 23_2 核心术语速查

#### 气论类

| 术语 | 释义 |
| --- | --- |
| **生气** | 阴阳之气行乎地中者，是全部判断的核心对象 |
| **乘生气** | 承接、顺应自然中已有的生气，而非改造自然 |
| **藏风得水** | 聚之使不散（藏风）、行之使有止（得水）；**得水为上，藏风次之** |
| **外气 / 内气** | 外气行于形（山水形势），内气止而生（地中生气） |
| **形止气蓄** | 地形收敛环抱停顿，气才能蓄住 |
| **势 / 形** | 千尺为势（远观动态的），百尺为形（近察静态的） |
| **太极点** | 复杂地形中"相对静止"的核心点；静中求动，动中求静 |
| **向背** | 向者有情，背者无情；判断砂水吉凶的第一标准 |

### 23_3 口诀总集（按主题）

#### 总纲

+ 葬者，藏也，乘生气也
+ 气乘风则散，界水则止。风水之法，**得水为上，藏风次之**
+ 千尺为势，百尺为形；**势来形止，是谓全气**
+ 理寓于气，气囿于形
+ **山旺人丁水旺财**
+ 独阳不生，独阴不成

#### 龙

+ **龙神二字寻山诀，神是精神龙是质**
+ 寻龙先寻祖与宗，不认祖宗枉费功
+ 一剥一换大生小，从大换小最奇异
+ 寻龙千万看缠山，**一重缠是一重关**
+ 廉贞宜作祖宗，巨门宜作帐慎，贪狼宜作贵人，武曲宜行龙结穴
+ **行到平阳莫问龙，只看水绕是真龙**
+ 凡看山，到山场，先问水

#### 穴

+ 穴总三停，山分八卦
+ **真龙藏嫩，怪石露凶**
+ 龙阳则阴结，龙阴则阳结；**急龙寻其缓，缓龙寻其急**
+ **宁可无穴，不点病穴**
+ 顺缓逆急，缩顶离虚；没沉穿横，斗贴截骑；对刚缀麓，顿垒犯险

#### 砂水

+ 砂如美女，不宜凶恶；弯环抱穴，富贵荣华
+ **案宜近而低，朝宜远而高**
+ 水口有关拦，富贵出自然；水口无遮拦，家财总耗散
+ **明堂容万马，水口不通舟**
+ 来不欲冲去不直，横不欲反斜不急
+ **水法最多难尽述，无非屈曲有情意**
+ 乙丙交而趋戌，辛壬会而聚辰，斗牛纳丁庚之气，金羊收癸甲之灵
+ 坐下若无真气脉，面前空叠万重山

#### 消砂

+ 子午卯酉太阳火，甲庚丙壬太阴火；乾坤艮巽本属木，乙辛丁癸便是土；辰戌丑未四金地，寅申巳亥皆属水
+ 角奎井斗原属木，轸壁箕参是水神；氐女胃柳土之位，亢牛鬼娄是金神
+ **生奴比旺官贵兴，煞泄绝度绝人丁**

#### 双山水法

+ 坤壬乙（水局）｜艮丙辛（火局）｜巽庚癸（金局）｜乾甲丁（木局）
+ **格龙看正五行；纳水看双山五行；立向看向上五行**

#### 格龙三层

+ **先识穿山虎，方行透地龙；穿山观其脉，透地定其穴**
+ 穿山辨龙，透地乘气，分金立向

#### 向与分金

+ 地盘立向、人盘消砂、天盘纳水
+ **甲壬阳孤乙癸虚，戊己龟甲是空亡；唯有丙丁庚辛旺，四十八金是珠宝**
+ 无绝地，有绝水，无绝水，有绝向
+ **分金差一线，富贵不相见**
+ 乾坤艮巽可兼本宫右，子午卯酉可兼本宫左

### 23_5 常见误区速查

| 误区 | 正确做法 |
| --- | --- |
| 把断语当结论背 | 追推导链，每条口诀补一句"它的适用前提是什么" |
| 只看形状不看向背 | **砂的吉凶不在形状，而在向背** |
| 把干水当抱水 | 干水气旷，与宅不亲；**取枝不取干** |
| 把临水当得水 | 还要看距离、水势、是否割脚 |
| 用山龙法套平洋 | 平洋"判然不相合"，**平洋的青龙白虎就是水本身** |
| 三盘混用 | 立向只用地盘，消砂只用人盘，纳水只用天盘 |
| 一局用多套理气 | **一局只用一套理气；形势是共用地基** |
| 金锁作最终判决 | 它只是**快速筛查层** |
| 拿单房间起卦断全家六亲 | 古法以全屋太极分八方 |
| 用装修解决选房问题 | 结论必须分成"可改造项"与"不可改造项" |
| 只测一次就定坐向 | 三次取一致加换点复核（差异小于 1 度） |
| 在错误数据上选分金 | **测量规范优先于技法** |
| 把吉凶承诺当科学定论 | 分清"环境经验"与"文化信仰"两层 |

### 23_6 微型案例：现场翻到这一页的三分钟

一个新手第一次独立去看一块地，站在地头有点懵——他知道要看龙、穴、砂、水，但**站了十分钟不知道先干什么**。

他做了一件事：把这一页（术语速查）拿出来，从上往下扫了三分钟，然后用里面的三句话给自己列了动作清单：

| 翻到的一句话 | 变成的动作 |
| --- | --- |
| **"童、断、石、过、独"** | 先绕地块走一圈，专门找这五样有没有（**先排除**） |
| **"背有靠、左右护、前有照、水口锁"** | 站到地块中心转三百六十度，四项逐项打勾 |
| **"来不欲冲去不直，横不欲反斜不急"** | 找到水（或路）的来去方向，看它是朝我弯还是背我弯 |

**三分钟后的收获**：他不再是"不知道看什么"，而是有了三个能立刻执行的动作。

**这一页的正确用法**：

1. **出门前**——扫一遍口诀总集，把今天要用的三条抄到手背上；
2. **现场卡住时**——不要硬想，翻到术语表，用"名词"把眼前的东西**叫出名字**（叫不出名字就看不懂）；
3. **回来后**——对照数字速查，检查自己记的度数、间距、比例有没有写错。

> **提醒**：这一页提供的都是**提示**，不是结论。**任何一条口诀，都要回到现场核对其适用前提**——这也是它必须与板块24（理性边界）一起用的原因。
