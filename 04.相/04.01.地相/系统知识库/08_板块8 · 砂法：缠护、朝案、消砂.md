## 板块8 · 砂法：缠护、朝案、消砂

### 8_1 本块定位

穴位定了，接着看穴场周围有什么在护卫它、朝应它、遮蔽它。这些环绕穴场的山丘与凸起物，统称"砂"。

**砂管人丁贵寿，水管财禄富贵**（"山旺人丁水旺财"）。本块先讲砂。

### 8_2 砂的定义与判别

**砂**指穴场周围具有护卫、朝应或遮蔽作用的山体、丘阜或凸起物。

**判别口诀**：**高一寸为砂，低一寸为水**。

| 类别 | 判定 | 典型物 |
| --- | --- | --- |
| **砂**（高、凸、实） | 高一寸为砂 | 高楼、假山、大树、高柜、墙体、承重柱、凸起物、实体建筑、变电房、烟囱、塔 |
| **水**（低、凹、虚、流） | 低一寸为水 | 空地、马路、河流、湖泊、低洼、阳台、窗户、空缺、空旷处、鱼缸、通道 |

**室内判别小窍门**：厨房、卧室高柜、电视墙、承重柱作"砂"论；卫生间、阳台、通道、楼梯口、鱼缸、空调低处作"水"论。

### 8_3 四灵砂的吉格标准

| 方位 | 砂名 | 吉格要求 | 忌 |
| --- | --- | --- | --- |
| **后** | 玄武 | 垂头俯伏、端正高大 | 空缺、低陷 |
| **前** | 朱雀 | 翔舞有情、开阔平整 | 高压、闭塞 |
| **左** | 青龙 | 蜿蜒高耸、环抱穴场 | 高压、昂头、反背 |
| **右** | 白虎 | 驯服低伏、护穴有情 | 尖射、高昂、空缺 |

**龙虎平衡的关键句**：

> **"龙强虎弱，宜避昂头；虎强龙弱，切忌欺主。"**

哪边强，都不能抬头欺压，要低头、环抱、有情。龙虎砂若向外反背无情，主后代不和。

### 8_4 案山与朝山：一近一远，一低一高

| 类型 | 位置 | 要求 | 禁忌 |
| --- | --- | --- | --- |
| **案山** | 明堂前近山 | 端正圆净、朝拱穴场 | 破碎、斜飞、高压 |
| **朝山** | 远处朝拜之山 | 秀丽挺拔、远朝有情 | 孤露、尖射、空缺 |

> **口诀**：**"案宜近而低，朝宜远而高"**；**"特来朝者为案，横列护者为砂"**——端正朝向穴场的是案山，横向排列护卫的是护砂。

### 8_5 砂形吉凶速判

| 吉砂形态 | 凶砂形态 |
| --- | --- |

| 弯腰、朝穴 | 探头、逼压 |

| 剑戟牙刀（六秀方）、龟鹤琴剑（三吉方）、文笔峰、旌旗峰 | 掀裙舞袖（沐浴方）、偃月卧尸（黄泉方）、抱头侧面、刀砂遇八曜 |

> **口诀**：**"砂如美女，不宜凶恶；弯环抱穴，富贵荣华。"**

### 8_6 砂祸：十八种关系错位

砂的吉凶**不在形状，而在"向背"**。以下是十八种砂祸，本质都是**关系错位**：

> 尖射、破透顶、探头、身反向、顺水走、高压穴、相斗、破碎、直强、狭逼、低陷、乱斜、粗大、瘦弱、短缩、昂头、背面、断腰

| 砂祸 | 本质（关系错位在哪） |
| --- | --- |
| 尖射、直强 | 该柔的却锐利直冲 |
| 身反向、背面、顺水走 | 该朝我的却背我 |
| 高压穴、探头、昂头 | 该低的却高，该退的却前 |
| 低陷、短缩、瘦弱 | 该护的却护不住 |
| 破碎、粗大、乱斜 | 该整的却散乱 |
| 狭逼、断腰、相斗 | 该容的却逼迫 |

> **论砂的灵魂**：**砂的吉凶不在形状，而在"向背"**。朝向对的凶形也能效力，朝向错的吉形也是祸端。
>
> **迁移用法**：评价人、事、物，不要被表面的"形状"（头衔、外形、标签）迷惑，要看它与周边要素的**向背关系**——是护卫还是压制？是朝向还是背反？

### 8_7 消砂的数学基础：两套五行

消砂用**人盘**（中针）——它比地盘正针**逆时针偏 7.5 度**，专管静态砂体的吉凶。但要用它，得先搞清它用的是哪套五行。

#### 1. 人盘二十四山五行（日常够用）

> **子午卯酉太阳火，甲庚丙壬太阴火；**

**乾坤艮巽本属木，乙辛丁癸便是土；**
**辰戌丑未四金地，寅申巳亥皆属水。**

| 二十四山分组 | 人盘五行 | 记忆要点 |
| --- | --- | --- |
| 子、午、卯、酉 | **火**（太阳火） | 四正位 |
| 甲、庚、丙、壬 | **火**（太阴火） | 四干 |
| 乾、坤、艮、巽 | **木** | 四维卦 |
| 乙、辛、丁、癸 | **土** | 四阴干 |
| 辰、戌、丑、未 | **金** | 四墓库支 |
| 寅、申、巳、亥 | **水** | 四长生支 |

#### 2. 二十八宿五行（本源，精细时用）

人盘五行其实是从二十八宿宿度五行简化而来：

| 四象 | 七宿（含五行与禽名） |
| --- | --- |
| **东方青龙（木）** | 角木蛟、亢金龙、氐土貉、房日兔、心月狐、尾火虎、箕水豹 |
| **南方朱雀（火）** | 井木犴、鬼金羊、柳土獐、星日马、张月鹿、翼火蛇、轸水蚓 |
| **西方白虎（金）** | 奎木狼、娄金狗、胃土雉、昴日鸡、毕月乌、觜火猴、参水猿 |
| **北方玄武（水）** | 斗木獬、牛金牛、女土蝠、虚日鼠、危月燕、室火猪、壁水貐 |

**宿度五行口诀**：

> 角奎井斗原属木，轸壁箕参是水神；

氐女胃柳土之位，亢牛鬼娄是金神；
翼室觜尾火最旺，房虚昴星四君火，张心危毕相火临。

> **总诀**：**生奴比旺官贵兴，煞泄绝度绝人丁。**

### 8_8 消砂操作：五步与五格判定

**操作步骤**：

1. 用**地盘正针**定出坐山（"我"），查出坐山的人盘五行或宿度五行；
2. 用**人盘中针**测砂峰（山、高楼、塔、电杆、大树等）所在方位，查出其五行；
3. 以坐山为**主**、砂峰为**宾（客）**，看二者生克；
4. 结合砂形复核：端正有情则增吉，歪斜破败则加凶；
5. 定处理策略：吉砂宜高大秀美并保留，凶砂宜低平、遮蔽或化解。

| 关系 | 名称 | 别名 | 主应 |
| --- | --- | --- | --- |
| 砂生坐山（他生我） | **生砂** | 印砂、奴砂 | 学业、文昌、科甲、催官 |
| 砂同坐山（比和） | **旺砂** | 比砂 | 旺人丁、文昌科甲，大吉 |
| 坐山克砂（我克他） | **财砂** | — | 主财富 |
| 坐山生砂（我生他） | **泄砂** | — | 损健康、家业败落 |
| 砂克坐山（他克我） | **煞砂** | 鬼砂、杀砂 | 血光、牢狱、短寿，主凶 |

**示例（坐子向午）**：子山人盘五行属火（子午卯酉太阳火）

+ 坤方有砂 → 坤属木 → 木生火 = **生砂**，吉（利文昌科甲）；
+ 寅方有砂 → 寅属水 → 水克火 = **煞砂**，凶（宜遮蔽化解）；
+ 癸方有砂 → 癸属土 → 火生土 = **泄砂**，凶（主耗散）。

> ⚠ **两条口径纪律**：

第1步 不同流派对"我"的认定不同——有的以**坐山**为"我"，有的以**局**（三合局五行）为"我"。**一局之内只能采用一种，中途不得更换。**
第2步 **宿吉形凶亦凶，宿凶形吉难救**。五行生克只占一半权重，砂的**形态**（端正或歪斜、有情或反背）必须同时参看。

### 8_9 砂之五看：吉凶不是单看方位

同一座砂，远近高低不同，结论可能完全相反。复核五要素：

| 看 | 要点 | 常见误判 |
| --- | --- | --- |
| **方位** | 落在哪一山、哪一宫 | 只记"东边有山"，不记具体度数 |
| **远近** | 距离多远（压迫还是护卫） | 把远处秀峰当护卫，或把近处高楼当吉砂 |
| **高低** | 相对穴场的高度差 | 把"高压"当"有靠" |
| **大小** | 体量与穴场的比例 | 大砂压小穴，反成逼压 |
| **先后** | 是原有的还是新建的 | 新建高楼改变了既有格局 |

### 8_10 案例故事：变电房的两种身份

某小区里有一座独立变电房，箱体方正、约两层高。它到底算"砂"还是不算砂？两位来看的人给出了两个方向相反的答案。

#### 第一位：按五行格推，判"不凶"

他的推算链条是完整的：

| 步骤 | 内容 |
| --- | --- |
| 定坐山 | 用地盘正针测出该栋坐山 |
| 查坐山五行 | 按人盘二十四山五行定"我" |
| 测变电房方位 | 用人盘中针测出变电房落在**乾方** |
| 查乾方五行 | 乾坤艮巽本属**木** |
| 看生克 | 木与坐山为比和或相生关系 |
| 结论 | **旺砂或生砂，格上不凶** |

从纯推算看，这个结论没有问题。

#### 第二位：按"五看"复核，判"要用，但要处理"

他没有推翻推算，而是补了三件事：

| 看 | 现场实况 | 权重 |
| --- | --- | --- |
| **距离** | 变电房距最近一栋住宅约二十五米 | **最高**——近到能听见、能感到 |
| **高低** | 略低于住宅窗台，但顶部散热孔正对一侧卧室窗 | 中 |
| **形态** | 箱体方正，本身不凶；但散热孔格栅与设备噪声是问题 | 中 |
| **用途** | 变电设备，持续低频噪声，业主心理顾虑重 | **高** |
| **先后** | 变电房与住宅同期建设，非后来插入 | 低 |

他用一个简单动作把争论结束了——**测噪声**。

| 时段 | 测量位置 | 数值 | 判定 |
| --- | --- | --- | --- |
| 夜间 | 最近卧室窗外一米 | 低频噪声明显高于小区背景值 | 属**声煞** |
| 日间 | 同上 | 略高于背景值 | 可接受 |

#### 处理：分层做，先做可验证项

| 层 | 措施 | 验收方式 |
| --- | --- | --- |
| 第一层 | 变电房靠住宅一侧加隔声处理，散热孔改向并加消声百叶 | **复测噪声**，达到小区背景值附近 |
| 第二层 | 变电房与住宅之间加密植绿化带，兼顾视线遮挡 | 视觉干扰下降 |
| 第三层 | 该侧卧室不设长期停留位置（书桌、床头挪位） | 功能避让 |
| 第四层 | 向物业提出设备维护与定期检测要求（可验证的安全项） | 有据可查 |
| **不做** | 不摆任何"化煞器物"——它不改变任何一个可测指标 | — |

#### 复盘要点

**第1步 格吉形凶亦凶，宿凶形吉难救。** 生克推算只占一半权重，**形态与用途**必须同时参看。第一位算得没错，但只算了一半。

**第2步 砂的"用"比"形"更影响居住。** 一座方正的小房子，如果是变电房、泵房、垃圾站，它的**功能属性**会盖过形态属性。判断城市里的砂，先问"它是干什么的"。

**第3步 距离是权重最高的一项。** 同样一座变电房，一百米外是背景噪声，二十五米内是生活质量问题。**任何砂的判断，先把距离量出来。**

**第4步 用可验证指标终结争论。** 两位吵的是吉凶，测的是分贝。分贝能测、能复测、能验收——**凡是能用仪器说话的地方，就不要用术语争。**

**验证方法**：

1. **换点复测**：站在穴场与站在砂体下方各测一次方位，确认读数一致；
2. **照片比对**：同一方位拍广角与长焦各一张——广角看关系，长焦看形态；
3. **季相复核**：冬季落叶后，夏季被树遮住的砂体会暴露出来，结论可能改变。
