## 板块13 · 理气流派地图：五套坐标系，只许用一套

### 13_1 本块定位

到此，形势（峦头）这一半完成了。另一半是理气——给这块地加上**方位坐标与时间坐标**。

但五套流派各有自己的坐标系。本块先画地图，再讲混用的边界。

### 13_2 理气在做什么

| 层面 | 解决的问题 |
| --- | --- |
| **形势（峦头）** | 这块地**好不好** |
| **理气** | 在什么**方位**、什么**时间**、接哪一股气更好 |

理气给形势加上了**方位坐标与时间坐标**。

⚠ **始终记住**：理气是在真峦头上做微调。**峦头不真，理气再好也是虚妄。**

### 13_3 三合派：以龙水向合局为核心

| 项目 | 内容 |
| --- | --- |
| **工具** | 四大局、十二长生、双山五行、天盘缝针纳水 |
| **逻辑** | 龙、水、向三者必须"元窍相通"，同归一个墓库 |
| **强项** | 水法系统严密，实操性强，与形势派结合好 |
| **弱项** | 不强调时间维度（元运） |
| **适合** | 山地、乡村、有水口可辨的地块 |

### 13_4 三元玄空派：加入时间坐标

| 项目 | 内容 |
| --- | --- |
| **工具** | 三元九运、挨星、山向星飞布、城门诀 |
| **时间体系** | 180 年为一正元，分上中下三元，每元 60 年、每运 20 年 |
| **核心判断** | 到山到向（旺山旺向）为吉，上山下水为凶 |
| **强项** | 时间维度明确，适合城市阳宅与阶段性调整 |
| **弱项** | 对形势判断要求高，纯算术易偏离 |

> 传统术数以二十年为一运、三元九运为一个完整周期。各派对当前所处运次依自身传承推算。这类周期表述属于传统文化框架内的内容，宜作文化理解，不作精确预测依据。

### 13_5 天星派（催官体系）

| 项目 | 内容 |
| --- | --- |
| **工具** | 二十四山天星、纳甲、三吉六秀、净阴净阳 |
| **逻辑** | 以天星垣局对应地脉，以"照龙—照向"建立君臣对应关系 |
| **强项** | 断语精细，可推导（每一句断语都有推导链） |
| **弱项** | 术语体系庞大，学习曲线陡（详见板块14） |

### 13_6 八宅派（大游年）

| 项目 | 内容 |
| --- | --- |
| **工具** | 东四命或西四命、东四宅或西四宅、九星游年 |
| **逻辑** | 人宅相配，以大门（或坐山）为伏位起游年 |
| **强项** | 简单易用，适合室内功能分区参考 |
| **弱项** | 对现代高层公寓适配性差（穿宫九星专为合院进深设计） |

> ⚠ **重要限制**：古法以**全屋太极**分八方，不能拿单个小房间起卦断全家六亲。

### 13_7 金锁玉关（过路阴阳）

| 项目 | 内容 |
| --- | --- |
| **工具** | 一二三四要砂、六七八九要水；二十四山断语 |
| **逻辑** | 洛书九宫阴阳消长，走一圈即可快速断六亲兴衰 |
| **强项** | 简、准、快，适合现场第一道筛查 |
| **弱项** | **不管元运、不辨龙穴真假**，只是快速筛查层 |

### 13_8 五派对照与混用边界

| 流派 | 坐标核心 | 时间维度 | 最适场景 | 是否可作最终判决 |
| --- | --- | --- | --- | --- |
| **三合** | 龙水向合局、四大局 | 无 | 山地、乡村、有水口 | 可 |
| **玄空** | 三元九运、挨星飞布 | **有** | 城市阳宅、阶段调整 | 可 |
| **天星** | 天星垣局、纳甲 | 无 | 精细断语、可推导 | 可 |
| **八宅** | 命卦配宅 | 无 | 室内功能分区 | 仅供参考 |
| **金锁** | 八方砂水 | 无 | 快速筛查 | 只是第一道筛子 |

**混用铁律**：

| 可以做 | 不可以做 |
| --- | --- |
| 形势层各派通用（峦头是共用地基） | 同一局同时用两套理气定坐向 |
| 用金锁做初筛，再用三合或玄空精确定层 | 一半校正磁偏角、一半不校正 |
| 用八宅做室内功能分区参考 | 拿单个房间起卦断全家六亲 |

> **一句话**：**一局只用一套理气；形势是共用地基。**

### 13_9 案例故事：三派同时看一套房

一位购房者拿着三份结论互相矛盾的报告来问：到底该听谁的？

| 流派 | 结论 | 依据 |
| --- | --- | --- |
| **三合** | 凶——水口不合局 | 去水方位与来龙不同归一库 |
| **玄空** | 吉——旺星到向 | 按当前元运排盘，向星当旺 |
| **金锁** | 凶——乾方见砂 | 乾宫宜水，实际见高楼 |

三份报告都"有依据"，而且**它们量的根本不是同一件事**。

#### 第一步：先回到形势，这是共用地基

不管用哪套理气，先把形势这一层做完，因为它是所有人共用的地基：

| 检查 | 结果 |
| --- | --- |
| 外局十二问 | **零命中** |
| 七煞扫描 | **零命中**（无路冲、无反弓、无穿堂、无天斩） |
| 四象核验 | 后有靠、前有明堂、左右均衡 |
| 户型 | 方正，无严重缺角 |

**形势层过关。** 这一步做完后，问题已经从"这房子能不能买"变成了"买下来之后怎么调"。

#### 第二步：一局只用一套理气，其余降为"提示项"

他的处理是：

| 流派 | 定位 | 怎么用 |
| --- | --- | --- |
| **玄空** | 选为**定层**（本局的主坐标系） | 用来分配功能：动区放向方、静区放坐方 |
| **三合** | 降为**提示项** | 水口不合局 → 落到具体动作：排水路径与去水口处理 |
| **金锁** | 降为**快速筛查** | 乾方见砂 → 落到具体动作：该侧做隔声与视线处理，不做摆件 |

#### 第三步：把所有冲突翻译成"可改造"与"不可改造"

| 流派结论 | 翻译成 | 能否改造 |
| --- | --- | --- |
| 三合：水口不合局 | 排水走侧边、去水口加沉砂与绿岛 | **可改造**（装修阶段可解决） |
| 玄空：旺星到向 | 向方保持开敞明亮，作为公共活动区 | **可改造**（布局阶段可解决） |
| 金锁：乾方见砂 | 该侧加隔声与遮挡，卧室避让该方位 | **可改造**（部分） |
| 无 | 楼间距、地块形状、周边规划 | **不可改造**（只能靠选房规避） |

**结论：这套房可以买。** 因为三条流派结论全部落在"可改造"一侧，而不可改造项为零。

#### 复盘要点

**第1步 一局只用一套理气。** 三合定局、玄空挨星、金锁断砂水同时上，等于用三把不同的尺子量同一段布，读数当然打架。**形势是共用地基，理气是可选的一套坐标。**

**第2步 流派冲突往往是因为它们在量不同的东西。** 三合量的是"龙水向是否同局"（空间关系），玄空量的是"什么时间接哪股气"（时间关系），金锁量的是"八方砂水是否颠倒"（快速筛查）。**它们不是互相否定的答案，是三种不同的提问。**

**第3步 把冲突翻译成"可改造/不可改造"，问题就变小了。** 三个流派吵的是吉凶，业主需要知道的是**"我能不能改"**。这一步翻译，是把玄学报告变成决策文件的关键。

**第4步 不可改造项为零，才是真正的绿灯。** 可改造项再多也不怕，因为装修阶段能解决；**只要有一项不可改造的硬伤，再好的理气结论都要打折。**

> **决策树一句话**：先看形势（有没有硬伤）→ 再选一套理气（定层）→ 其余流派的意见全部翻译成具体动作 → 最后只问一句：**这些动作，哪些是装修能解决的？**

### 13_10 流派选择决策树

```plain
   你的场景是什么？

   ├─ 山地 / 乡村 / 有水口可辨 → 三合派（龙水向合局）
   ├─ 城市阳宅 / 关心阶段性旺衰 → 三元玄空派
   ├─ 需要精细断语 / 追推导链 → 天星派
   ├─ 室内功能分区 → 八宅派（仅参考）
   └─ 现场快速筛查 → 金锁玉关（仅初筛）

   ⚠ 无论选哪一派：
      第1步 先过形势关（板块3）
      第2步 一局只用一套理气
      第3步 记录所用流派与口径，便于复盘

```

**笔记方法**：每份勘验记录必须写明**"本次用哪一派、磁偏角如何处理、以何为'我'"**。缺了这三项，三个月后你自己都看不懂当时的结论是怎么来的。
