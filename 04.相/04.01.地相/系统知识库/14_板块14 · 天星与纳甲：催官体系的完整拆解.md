## 板块14 · 天星与纳甲：催官体系的完整拆解

### 14_1 本块定位

理气五派中，天星派体系最庞大、推导链最长，也是被误读最深的一派。单独拆开讲，重点是**追推导链而非背结论**。

### 14_2 定位：它是"操作手册"，不是"断语字典"

很多人翻开催官体系，第一反应是查表——亥龙配什么向、巽方见什么砂。查完觉得玄之又玄，合上仍不知何处下手。问题出在读法：**它是一部关于"乘气"的操作手册，却被当成了方位断语的字典。**

正确姿态：**追每一句断语的推导链，不要背结论**。全书以"二十四山—天星—阴阳五行"为共同语言，把龙脉、穴位、山峰、水流串成一条闭合的推导链：

```plain
认龙 → 定穴 → 配向 → 消砂 → 纳水 → 乘气

```

**任何一环断掉，前面所有的"吉"都只是纸面吉。**

**全书的动词只有四个**——剥换、挨加、收放、乘气。四章看似各论一事，其实共用一套动作术语：

| 动词 | 出在哪 | 含义 |
| --- | --- | --- |
| **剥换** | 评龙 | 粗老之山一路脱煞换嫩，龙气由杂转纯 |
| **挨加** | 评穴 | 气从何方入，穴就向何方偏移分毫 |
| **收放** | 评砂评水 | 吉砂收而用之，凶砂放而避之，水口关锁 |
| **乘气** | 全篇归宿 | 最终要"乘得生气"，而非"占得好方位" |

结尾两句是全书的眼：**"详观砂水定品秩，收放乘气为真机。土圭测位勿草草，心意消息毋昏欺。"**——罗盘测位不可草率，心中体察不可自欺。这已经不是术，是心法。

### 14_3 二十四山天星称谓表

书中几乎不用"亥方""艮方"这样的裸方位，而代之以星名。**这层包裹不是为了神秘化，而是为了给出可推导的属性**——每一组星名背后都绑定着五行、所主之事与对应关系：

| 方位 | 天星称谓 | 垣局或属性 | 所主 |
| --- | --- | --- | --- |
| **亥** | 天皇、紫微 | 紫微垣（帝王之星） | 官禄、功名、权力，全书第一贵 |
| **壬** | 天辅 | 辅弼之位 | 辅佐、承接 |
| **乾** | 天厩 | 天厩星 | 乾山巽向为天厩穴 |
| **癸** | 北道、天道 | 北方之道 | 癸山丁向为北道穴 |
| **艮** | 阳枢、天市 | 天市垣（财库） | 财富、人丁、商业 |
| **巽** | 太乙、太微、阳璇 | 太微垣（尚书之府） | 文章、科举、学术 |
| **丙** | 阴枢、天贵 | 火，南极照临 | 权力之贵、赦文（消灾） |
| **丁** | 南极 | 寿星所出 | 长寿、福报 |
| **酉** | 少微、阳关 | 少微垣（西掖） | 地方文名、清贵翰苑 |
| **庚** | 天汉、天潢 | 武库 | 武贵、财富 |
| **辛** | 天乙、阴璇 | 天乙之居 | 寿、文章 |
| **震（卯）** | 阳衡 | 阳衡之位 | 三吉之一，主武权名宦 |

> 各本对二十四山天星的称谓**略有出入**，上表择其有据可依者列出；其余山向以本派传承为准，**不必强求统一**。

**记住这张表的意义**：不是"亥龙好"，而是"亥龙属水、带天皇贵气，所以要配出某类向、避某类砂"。**属性可读 → 关系可推 → 结论可验**。

### 14_4 纳甲：天星体系的语言规则

为什么"阳璇（巽）—阴璇（辛）""阳枢（艮）—阴枢（丙）"总是成对出现？因为**八卦纳甲**：

> 艮纳丙、巽纳辛、乾纳甲、坤纳乙；

坎纳癸申子辰、离纳壬寅午戌、震纳庚亥卯未、兑纳丁巳酉丑。

**纳甲即"同气"**。所以艮龙喜丙、巽龙喜辛，本质是**本宫与所纳之位互相催发**。

> **理解纳甲，比背任何口诀都省事。** 见到"某龙喜某向"，先查它是不是纳甲同气——一查就通。

### 14_5 三吉六秀：是"优选池"，不是"万能钥匙"

| 类别 | 内容 | 主应 |
| --- | --- | --- |
| **三吉龙** | 亥（天皇）、震（阳衡）、庚（天汉） | 极品贵、武权、名宦 |
| **六秀龙** | 艮、巽、辛、丙、兑、丁 | 秀气、文名、旺财旺丁 |

原文说"天皇天市龙第一，巽辛兑丁官可必"。看上去在堆吉位，实际在讲一件事：**格局的等级取决于"贵龙加贵砂贵水同到"的叠加度**。一条亥龙，若八方无峰、三阳无水，最多算"龙真"，谈不上催官。

⚠ **必须破除的误读**：**三吉六秀是"候选名单"，不是"见之即吉"**。同在六秀里的丁、丙，也要看是"行龙"还是"受穴"、有没有驳杂之气。**吉位只是入场券，纯度才决定名次。**

### 14_6 四大局十二位：精确判定层

催官体系本质是正五行风水的成形之作。它把地理分四大局（东方木局、南方火局、西方金局、北方水局，二阴二阳），**每局十二龙**（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养），**共四十八条龙、六十穴**。

坐穴按进气位置又有**正向、左腧、右腰、左耳、右耳、中脑**之分。

**这意味着**：

| 层级 | 作用 |
| --- | --- |
| **三吉六秀** | **快速筛选层** |
| **四大局十二位** | **精确判定层** |

> 实务中应**先归局、定龙在十二宫中的位次，再谈吉凶**。只背三吉六秀而不入局，是这本书最常见的读法陷阱。

### 14_7 配向的两个规律：耳受为上，挨加有度

以亥龙三穴为例，讲的是一个极具体的技术——**"挨加"**：

> 天皇气从右耳接，穴宜挨左微加乾

天皇气射天厩星，微挨西兽加壬行
天皇气冲穴北道，挨左立穴为枢要

**规律一：耳受为上，腰受次之。**

| 气从哪来 | 穴怎么放 |
| --- | --- |
| 气从**右耳**来 | 穴**挨左** |
| 气从**左耳**来 | 穴**挨右** |
| **腰脉**来 | 穴**接腰** |

**规律二：挨加的分寸**。偏移量以"**一线之内**"为准，口诀是"**分金避空亡**"——**宁偏不正中，但绝不过度**。

⚠ 特别警告"**勿冲脑**"：偏倚过度，气直射穴顶，反成凶。

**测脉的粗细处理**：脉宽则穴**放**（略开），脉紧则穴**收**（收窄），贵在"乘得生气"。

```plain
   【耳受 vs 冲脑】

     气从左耳来          气直冲脑顶
        ↓                    ↓
    ╭───╮                ╭───╮
   ╱  ●  ╲ ← 穴挨右      ╱  ●  ╲ ← 穴正中，被顶冲
  │   ★    │            │   ★    │
   ╲      ╱              ╲      ╱
    ╰───╯                ╰───╯
     吉（耳受）            凶（冲脑）

```

### 14_8 纯度优先律：生旺死绝大于阴阳纯驳

最硬的一句：

> **"衰病绝乡为福薄，死墓混杂家流离。冠官生旺胎养位，不须更论阴阳比。"**

这段话常被断章取义。**"不须更论阴阳比"是有前提的**：

+ 只有当龙脉**落在冠带、临官、生旺、胎养等位**（即"在局内"）时，才不必再纠结阴阳比例；
+ **若已落在衰、病、绝、死、墓，纯阴纯阳也没用**。

**优先序**：**生旺死绝大于阴阳纯驳**。

**纯度分寸的实操判据**（中抽、左落、右落）：

> 左落乾亥如双行，乾多亥少那堪作。

右落乾亥如同行，亥多乾少堪裁度。

判据只有一句话——**主脉占几成**。

**现场动作**：在**过峡处或父母山顶**下罗盘，看入首束气落在二十四山哪一字；若骑缝（如乾亥各半），先看左右护砂哪边有力，再定"可裁或不可裁"。**骑缝之脉一律降级处理，不抱侥幸。**

### 14_9 六步操作清单

把歌诀翻译成可执行的操作步骤：

| 步骤 | 动作 | 验收标准 |
| --- | --- | --- |
| **1. 认龙** | 追过峡、看剥换、辨中抽或左右落 | 有清晰剥换链；非骑缝驳杂；在生旺位 |
| **2. 定穴** | 辨气从何入（耳、腰、脑） | 耳受为上；不冲脑 |
| **3. 配向** | 按纳甲同气配向，依挨加规律偏移 | 偏移在一线之内，不压空亡 |
| **4. 消砂** | 人盘消砂，看吉砂是否收得住 | 生旺砂到位，煞砂有制 |
| **5. 纳水** | 天盘纳水，看来去与水口 | 水归库，关锁有情 |
| **6. 乘气** | 复核纯度与深浅，确认乘得生气 | 生旺死绝合格；深浅得宜 |

### 14_10 案例故事：亥龙的三穴

一条入首在亥方的龙，三个人给出了三个穴，各有依据，互不相让：

| 方案 | 立向 | 依据 |
| --- | --- | --- |
| **甲** | 壬山丙向 | "天皇气从右耳接，穴宜挨左微加乾" |
| **乙** | 乾山巽向 | "天皇气射天厩星，微挨西兽加壬行" |
| **丙** | 癸山丁向 | "天皇气冲穴北道，挨左立穴为枢要" |

三个人背的是同一段歌诀，却各取一句。**问题不在谁背得对，而在于"气到底从哪入"这件事，他们都没有到现场下盘确认过。**

#### 第一步：先判入首纯度，再谈配向

复核者先在**过峡处**与**父母山顶**各下一次罗盘，看入首束气究竟落在哪一字：

| 检查 | 结果 |
| --- | --- |
| 入首落字 | 骑缝——**乾亥各半** |
| 左护砂 | 弱，断续 |
| 右护砂 | 强，连续且向内弯 |

**骑缝之脉一律降级处理。** 但降级不等于弃用，还要看"主脉占几成"：

> 左落乾亥如双行，**乾多亥少那堪作**；右落乾亥如同行，**亥多乾少堪裁度**。

现场右护砂有力，判断为**右落**，亥多乾少——**可裁度**。这一步做完，丙方案（癸山丁向）先被排除，因为它对应的是另一种进气方向。

#### 第二步：判"气从哪入"，决定往哪边挨

| 进气位置 | 穴怎么处理 | 级别 |
| --- | --- | --- |
| 从**右耳**来 | 穴**挨左** | **耳受为上** |
| 从**左耳**来 | 穴**挨右** | 耳受为上 |
| 从**腰**来 | 穴**接腰** | 腰受次之 |

现场测得气从右耳方向入，因此**穴宜挨左**，对应甲方案：**壬山丙向，微加乾**。

#### 第三步：挨加的分寸——"勿冲脑"

这一步是最容易做坏的。偏移量以**"一线之内"**为准：

| 做法 | 判定 |
| --- | --- |
| 微偏一分（一线之内） | 正确——乘得生气 |
| 不偏（正中） | 易压空亡，气不纯 |
| **偏倚过度** | **"冲脑"——气直射穴顶，反成凶** |

复核者用一根测杆在穴场比了三次，确认偏移量既躲开了中线，又没有越出一线。

#### 复盘要点

**第1步 三吉六秀是候选名单，四大局十二位才是精确判定层。** 三个人都停在"亥龙是天皇、第一贵"这一层，**没有人下到局里去定龙在十二宫中的位次**——这是催官体系最常见的读法陷阱。

**第2步 纯度优先于阴阳。** 判断顺序是：**先看生旺死绝，再看阴阳纯驳**。龙若落在衰、病、绝、死、墓，纯阴纯阳也没用。

**第3步 骑缝之脉一律降级，不抱侥幸。** "乾多亥少那堪作"是一句很硬的判词：主脉占几成，决定能不能用。

**第4步 挨加的分寸是"一线之内"。** 宁偏不正中，但绝不过度。**偏倚过度就是"冲脑"，吉立即转凶。**

> **可迁移的一句**：三个人吵的是"哪句歌诀对"，而真正的答案是**现场下盘的结果**。凡是可以用一次测量终结的争论，都不要靠背口诀来赢。
