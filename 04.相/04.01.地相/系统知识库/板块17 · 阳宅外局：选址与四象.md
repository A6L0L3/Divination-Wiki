## 板块17 · 阳宅外局：选址与四象

### 17_1 本块定位

前面各块以山地语言为主。从这一块起转向阳宅——**人住的房子**。

核心原则不变，要素表达全变：**山变楼、水变路、穴变户**。本块讲**外局**（小区与地块层面），下一块（板块18）讲内形（户型与室内）。

### 17_2 阳宅第一性原理：外局不行，内饰再贵也白搭

开篇定调：

> **"人之居处，宜以大地山河为主。若大形不善，总内形得法，终不全吉。"**

| 要点 | 含义 |
| --- | --- |
| **外局是体，内形是用** | 小区大环境不行，屋里装修再豪华也白搭 |
| **来龙气势最大** | 住宅不是孤立存在，而是镶嵌于大地山河的动态格局之中 |
| **内形补救有限度** | 内部布局再精巧，也难以弥补外部环境的根本性缺陷 |

> 🎯 **现代转译**：看房别光看样板间。**先站到主卧和客厅窗前，把四周 360 度看一遍**——有没有直冲过来的路、尖角对着的楼、垃圾站、高压线塔？**窗外环境比你家里的摆件重要得多。**

### 17_3 外局四象与十不居

#### 理想空间模型

> **凡宅左有流水谓之青龙，右有长道谓之白虎，前有污池谓之朱雀，后有丘陵谓之元武，为最贵地。**

| 方位 | 四象 | 理想形态 | 现代意义 |
| --- | --- | --- | --- |
| 东（左） | 青龙 | 流水 | 东侧有河流或绿化带，生机盎然 |
| 西（右） | 白虎 | 长道 | 西侧有道路通达，便于联系 |
| 南（前） | 朱雀 | 开阔地 | 南侧开阔明亮，有发展空间 |
| 北（后） | 玄武 | 丘陵 | 北侧有高地山峦，能挡风寒 |

**背后的环境科学**：后有靠山可挡北风，前有明堂利于采光排水，左右有道路水系便于交通。这是先民在长期居住实践中总结出的**均衡、稳定、充满生机的微环境模型**。

#### 十不居（硬性排除）

+ 不居当冲口处（道路直冲）
+ 不居寺庙、祠社、窑冶、官衙
+ 不居草木不生之地
+ 不居故军营战地
+ 不居正当水流冲射之处
+ 不居山脊冲处
+ 不居大城门口处
+ 不居对狱门处
+ 不居百川汇口处
+ 不居北有大路之处

#### 吉形

+ 前后有水环抱、左右有路（但遇"返跳"必须忌）
+ 宅东有流水达江海为吉；南有大路主富贵
+ **南北长、东西狭为吉**；**前窄后宽稳**；**前低后高**世出英豪
+ 宅周树木枝叶向宅为吉
+ 地面滋润光泽阳气者吉
+ 水木金土四星龙作住基终吉利

> ⚠️ **特别提示**：宅前忌开新塘，谓之"血盆照镜"；门稍远可开半月塘。现代转译——楼前正前方不要有大型水池或游泳池正对大门，可在**侧前方**设置半月形水景。

### 17_4 住宅如身体：一个整体而非砖瓦堆砌

**住宅是一个"类生命体"**：

| 身体部位 | 住宅对应 | 现代含义 | 出问题时的表现 |
| --- | --- | --- | --- |
| **身体** | 形势（整体格局） | 户型形态与外部环境 | 缺角、异形、压迫 |
| **血脉** | 泉水 | 给排水、水路走向 | 漏水、返潮、堵塞 |
| **皮肉** | 土地 | 地基、土壤环境 | 沉降、潮湿 |
| **毛发** | 草木 | 周边绿化 | 荒芜、枯死 |
| **衣服** | 舍屋 | 建筑本体 | 外墙剥落、保温差 |
| **冠带** | 门户 | 入口、气口 | 门冲、穿堂、压迫 |

> **关键推论**：任何"部位"出问题，整体都不安。**门户不正、井灶不当、墙院不完，都是系统性缺陷，而非局部瑕疵。**

### 17_5 五虚五实：古代版住宅品质评估表

| 五虚（劣宅） | 五实（优宅） | 现代指标 |
| --- | --- | --- |
| 宅大人少 | 宅小人多 | 人均面积匹配（三口之家约 90 到 120 平方米为宜） |
| 门大内小 | 宅大门小 | 入户门宽约 1.0 到 1.2 米，与内部空间比例协调 |
| 墙院不完 | 墙院完全 | 户型方正、墙体完整、少异形缺角 |
| 井灶不处 | 宅小六畜多 | 功能齐全，厨卫到位、收纳充足 |
| 宅地多屋少、庭院广 | 宅水沟东南流 | 土地利用率高；排水方向合理 |

📌 **底层逻辑**：反对铺张空洞，追求**紧凑、完整、有用**的空间品质。放到今天，就是反对"面子工程"式的豪宅化。

> **尺度匹配铁律**："宅大人少"不是说大房子不好，而是说**空间尺度必须与使用强度匹配**。三口之家选 90 到 120 平方米为宜，不必盲目追大；买了大户型，要通过家具布置、功能填充让空间"实"起来。

### 17_6 楼盘评估：外局十二问

看房时逐项打勾，记录否决项：

1. 楼后是否有更高建筑或山体作靠？还是一望无际的空旷或深谷？
2. 楼前是否有开阔地、绿地、水面？还是被另一栋楼紧贴压迫？
3. 左右是否有建筑或绿化形成环抱？还是被"夹刀"或完全孤露？
4. 附近河流或道路是否环抱楼宇？还是反弓冲射？
5. 是否有直路冲窗、冲门？
6. 是否有尖角建筑（及其他楼的墙角）正对自家？
7. 半径 500 米内有无寺庙、教堂、医院太平间、垃圾站、高压线塔、变电站？
8. 小区地势是否前低后高？是否处于低洼积水区？
9. 地块是否方正完整？有无被道路切割成三角、刀把形？
10. 土质或地面是否滋润有光泽？还是干燥贫瘠、草木不生？
11. 是否有楼间距过窄（小于前排楼高 × 1.2）导致的常年遮挡？
12. 是否紧邻高架、铁轨、快速路（持续低频震动加噪声）？

> **打分法**：十二问中每命中一条"否决项"，直接记录；命中 3 条以上建议放弃该盘。

### 17_7 现代七煞：古法煞气的当代清单

| 煞 | 形态 | 现代本质 | 处理 |
| --- | --- | --- | --- |
| **路冲**（水直冲） | 窗外有直路冲来 | 噪声、灯光、气流直灌 | 厚实窗帘、隔音窗、玄关缓冲 |
| **反弓**（反弓水） | 道路如弓背对宅 | 车流离心噪声、夜间车灯扫射 | 绿化带、隔音屏障、避免选此侧 |
| **穿堂**（龙气直泄） | 大门直对阳台或后窗 | 空气直流、无停留，冬冷夏热 | 玄关、屏风、半高隔断 |
| **天斩** | 正对两楼之间的窄缝 | 狭管效应，风速骤增，噪声集中 | 避免正对；厚重窗帘加双层玻璃 |
| **光煞** | 对面玻璃幕墙反射强光 | 眩光、热辐射 | 遮阳帘、Low-E 玻璃、绿植 |
| **声煞** | 变压器、水泵、电梯井的低频噪声 | 持续低频噪声影响睡眠 | 远离设备间；隔音改造 |
| **逼压** | 前方高楼紧贴、层高过低 | 视野与心理压迫 | 选高楼层或错位楼栋；浅色加通透设计 |

### 17_8 案例故事：两个楼盘的十二问

一位购房者在两个楼盘之间犹豫。两套房总价接近，第一印象的差距非常大：

| 楼盘 | 第一印象 | 单价 |
| --- | --- | --- |
| **甲** | 新盘，售楼处体面，样板间装修考究，园林示范区很漂亮 | 略高 |
| **乙** | 交付多年，外立面发旧，入户大堂普通 | 略低 |

样板间的差距让人很难不动心。他按"外局十二问"给两个楼盘各打了一遍勾。

#### 甲的十二问结果

| 区块 | 检查项 | 结果 |
| --- | --- | --- |
| 靠与明堂 | 楼后是否有更高楼栋或山体作靠 | 后排为待建空地，无靠 |
| 靠与明堂 | 楼前是否开阔 | 前排楼栋间距偏窄 |
| 左右 | 左右是否有建筑或绿化环抱 | 一侧临路，一侧空缺 |
| **水与路** | 附近道路是否环抱，还是反弓冲射 | 主干道在外侧弯过，本盘位于**弯弧外侧** |
| **冲煞** | 是否有直路冲窗冲门 | **命中**：一条支路正对目标楼栋侧面 |
| **尖角** | 是否有尖角建筑正对 | 无明显命中 |
| 周边 | 五百米内有无寺庙、医院太平间、垃圾站、高压线塔、变电站 | 有一处高压线走廊，距离约三百米 |
| 地势 | 是否前低后高，是否处于低洼积水区 | 场地整体偏低 |
| 地块 | 是否方正完整，有无被路切成三角、刀把形 | **命中**：地块被两条路切成不规则形 |
| 土质 | 地面是否滋润有光泽 | 新施工，植被未成 |
| 间距 | 楼间距是否小于前排楼高的一点二倍 | **命中**：间距不足 |
| 噪声 | 是否紧邻高架、铁轨、快速路 | **命中**：紧邻城市快速路 |

**甲命中五条，其中三条属于不可改造项**（反弓、地块形状、紧邻快速路）。

#### 乙的十二问结果

| 区块 | 检查项 | 结果 |
| --- | --- | --- |
| 靠与明堂 | 后排有更高楼栋，前方为小区中心花园 | ✅ 有靠有明堂 |
| 左右 | 左右均有楼栋，间距均衡 | ✅ |
| 水与路 | 小区道路环形，非反弓 | ✅ |
| 冲煞 | 无直路冲门冲窗 | ✅ |
| 尖角 | 无 | ✅ |
| 周边 | 五百米内有一处变电站 | ⚠️ **记录待察** |
| 地势 | 场地略高于周边道路 | ✅ |
| 地块 | 方正 | ✅ |
| 土质 | 绿化成熟，大树存活良好 | ✅ |
| 间距 | 间距充足 | ✅ |
| 噪声 | 内部道路，车流少 | ✅ |

**乙只命中一条，且属"记录待察"而非"命中即出局"**。

#### 那条"待察"项怎么处理的

他没有凭印象下结论，而是做了三件事：

| 动作 | 结果 |
| --- | --- |
| 查变电站的环评与距离 | 距离约二百八十米，超出一般防护距离 |
| 在不同时段测噪声 | 夜间接近背景值，与小区其他位置无显著差异 |
| 询问已入住业主 | 多年无相关投诉 |

**结论：该项降级为"无实质影响"，但不从记录中删除**——报告里保留了原始记录与复核结论，因为未来情况可能变化。

#### 最终选择：乙

他在报告最后写了一段话，大意是：

```plain
甲的五条命中项里，有三条是我买完之后无论花多少钱都改不了的：
  反弓的路、被切割的地块、紧邻的快速路。
  而这三条，恰恰是每天都会影响生活的东西。

乙的问题只有一条，而且我把它查清楚了。
  外立面旧、大堂旧，这些是"面子"，不是"里子"。

```

#### 复盘要点

**第1步 样板间是"内形"，十二问是"外局"。** 外局是体，内形是用。**大形不善，总内形得法，终不全吉。**

**第2步 命中项要分两类：命中即出局，与记录待察。** 前者（反弓、地块形状、紧邻快速路）直接决定取舍；后者（变电站、高压线）必须**实测后才能定性**。把它们写成同一类，是评估报告最常见的失真。

**第3步 不可改造项的数量，才是真正的决策依据。** 可改造项再多也不怕，装修阶段能解决；**不可改造项只要有一条，就要在房价里打折——而这个折扣不会写在合同里。**

**第4步 "面子"与"里子"要分开计价。** 外立面、大堂、样板间是可以被时间抹平的差异；朝向、间距、噪声、地块形状是**时间抹不平的**。

> **一句可迁移的话**：看房那天，把样板间的灯关掉，站到窗前把四周三百六十度看一遍。**窗外的东西值多少钱，比屋里的东西值多少钱重要得多。**

### 17_9 阳宅外局记录卡

| 区块 | 检查项 | 结果 |
| --- | --- | --- |
| **十不居** | 是否命中 |  |
| **十二问** | 逐项 + 否决项数量 |  |
| **七煞** | 路冲、反弓、穿堂、天斩、光煞、声煞、逼压 |  |
| **四象** | 靠、明堂、左护、右护 |  |
| **五虚五实** | 逐项对照 |  |
| **结论** | 可改造项 / 不可改造项 |  |

**验证方法**：

1. **昼夜各看一次**：白天看采光与视野，夜间看噪声与灯光（很多煞只有晚上才显现）；
2. **设备运行时测**：电梯、水泵、变压器在运行时才产生噪声，看房时务必要求"开机状态"体验；
3. **雨天复看**：渗水、返潮、排水问题只在雨天暴露；
4. **问已入住的业主**：噪声、渗水、物业这些"体感问题"，业主比任何理论都准。
