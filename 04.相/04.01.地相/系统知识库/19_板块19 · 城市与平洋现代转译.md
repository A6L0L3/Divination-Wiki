## 板块19 · 城市与平洋现代转译

### 19_1 本块定位

古法多论山川，而今人多居城市。这一块做完整的现代转译——把"龙穴砂水向"五个字，翻译成楼盘、户型、办公室能直接用的检查项。

它也是板块5（平洋龙法）与板块17、18（阳宅）的**综合应用层**。

### 19_2 转译原则

> **形峦定场，理气微调。** 无论环境如何变化，"龙穴砂水向"的五要框架不变，变的是具体要素的现代表达。

| 古法要素 | 现代城市转译 | 操作要点 |
| --- | --- | --- |
| **龙** | 道路为虚水龙；主干道、快速路视作大龙，小区内路为支龙 | 观察其来去、交汇、环抱 |
| **穴** | 大楼、小区中心或自家住宅 | 重在纳气口（大门、阳台）能否收到生旺之气 |
| **砂** | 周围建筑视为砂 | 检查前后左右建筑的"向背"关系，用人盘中针消砂 |
| **水** | 真实水流、道路走向、人流方向 | 宜环抱有情，忌直冲反弓，用天盘缝针纳水 |
| **向** | 大楼坐向、入户门朝向 | 以龙水定局，净阴净阳立向 |

### 19_3 城市寻龙五步

| 古法 | 现代 | 自检问题 |
| --- | --- | --- |
| **认祖山** | 找区域制高点或主干山脉 | 城市依傍的主山系或最高地形在哪？ |
| **辨星峰** | 看楼宇形态 | 楼形方正？有无严重缺角、尖削？ |
| **看过峡** | 看小区入口或单元门 | 入口有无保安亭、绿化带关拦？是否直冲？ |
| **查缠护** | 看左右相邻建筑 | 左右是否有楼环抱？有无反弓路、尖角冲射？ |
| **锁水口** | 看小区出口道路 | 出口有无绿化或建筑弯曲拦截？是否直泄无收？ |

### 19_4 公墓与高层阴宅的转译要点

| 场景 | 转译方法 |
| --- | --- |
| **公墓** | 整体园区视为"大龙"，园区主干道为干水，墓区支路为枝水；仍遵循"**取枝不取干**"——临主干道第一排不如内湾区；后排有靠（园区山体或围墙）优于边缘无靠；避开排水沟直冲、低洼积水、边角无护之位 |
| **高层中的立极** | 以所在楼层单元的**入户门与主要采光面**定太极点；下方楼层与上方楼层视为"地基"与"天"，避开正下方为车库出入口、设备层、变电站的位置 |

### 19_5 完整评估演练（八步框架）

```plain
第1步 卫星图预勘：标注区域主脉（主干山脉或主干道）、水系、绿地
第2步 现场外局十二问：逐项打勾，记录否决项
第3步 罗盘测量：测整栋主结构坐向 + 自家入户门坐向（各测 3 次取一致值）
第4步 八方砂水普查：按"一二三四要砂、六七八九要水"快速筛查
第5步 精确定层：选一套理气（三合水口定局 / 玄空元运 / 天星），定局、立向、分金
第6步 户型四象核验：玄武靠、朱雀明堂、龙虎均衡、明堂聚气
第7步 七煞扫描：路冲、反弓、穿堂、天斩、光煞、声煞、逼压
第8步 输出一页纸结论：优势项 / 否决项 / 可改造项 / 不可改造项

```

> 📌 **输出要点**：把结论分成**"可改造"（装修能解决）**与**"不可改造"（只能靠选房规避）**两类。

### 19_6 城市选房 SOP（九步）

```plain
Step 1  卫星图看小区在城市中的位置：是否在主脉余气区、两水夹角内湾
Step 2  外局十二问逐项打勾，记录否决项
Step 3  避开七煞（路冲、反弓、穿堂、天斩、光煞、声煞、逼压）
Step 4  楼栋选择：后排有靠优于前排临街；错位楼栋优于正对高楼；
        避开临街、避开设备层或变电站上方、避开车库出入口上方
Step 5  楼层选择：兼顾采光（楼间距 ≥ 1.2 倍楼高）与噪声（避开设备层与临街低层）
Step 6  户型核验：四象（靠、明堂、龙虎均衡）+ 方正 + 厨卫位置 + 动线
Step 7  测坐向（门向与采光面各测 3 次），做八方砂水普查
Step 8  定层：选一套理气（金锁快筛 → 三合水口定局 或 玄空元运），出结论
Step 9  输出一页纸：可改造项 / 不可改造项 / 建议

```

### 19_7 案例故事：一次完整的城市选房

某人要在三个备选房源之间做决定。三套房总价相近，各有各的卖点，也各有各的拥趸——家人推荐甲，中介推荐丙，他本人偏向乙但说不出理由。

于是他按九步 SOP 把三套各走了一遍，每一步都记在表上。

#### 甲房源：地铁口

| 步骤 | 结果 |
| --- | --- |
| 1. 卫星图 | 位于两条主干道交叉口的内侧，三面临路 |
| 2. 十二问 | 命中 2 条：紧邻城市快速路、正对路口 |
| 3. 七煞 | **路冲 + 声煞** 命中 |
| 4. 白天复看 | 站在客厅窗前能听见路口刹车声 |
| 5. **夜间复看** | 夜间车灯周期性扫射卧室墙面；实测噪声高于另两套 |
| 6. 楼栋 | 临街第一排，无退让 |
| **结论** | 通勤优势真实，但两条硬伤属于**不可改造项** |

他在记录里写了一句话：**"地铁口省下的二十分钟，是用每天的噪声换的。"**

#### 乙房源：学区

| 步骤 | 结果 |
| --- | --- |
| 1. 卫星图 | 位于老小区腹地，四周有楼环抱，南侧为小学操场 |
| 2. 十二问 | **零命中** |
| 3. 七煞 | **零命中** |
| 4. 户型四象 | 主卧靠实墙、客厅南向正对操场、左右均衡、无穿堂 |
| 5. 坐向 | 测得坐向，落在分金吉格 |
| 6. 八方普查 | 基本合局 |
| 7. **业主访谈** | 问了三位已入住业主：无渗水投诉，物业尚可，唯一抱怨是无电梯 |
| 8. **规划图核查** | 小学操场属教育用地，南侧**不会起高楼** |
| **结论** | 唯一硬伤是房龄偏老，管道需更换 |

#### 丙房源：高楼层视野

| 步骤 | 结果 |
| --- | --- |
| 1. 卫星图 | 位于新区，周边多处在施工 |
| 2. 十二问 | 命中 1 条：周边地块被道路切成不规则形 |
| 3. 七煞 | 暂无命中，但施工噪声为阶段性 |
| 4. 楼层 | 二十六层，采光极好 |
| 5. 坐向 | 测得坐向为**兼向**，超出中线三度半以上 |
| 6. **规划图核查** | 东侧空地规划为商业用地，**未来可能起高楼** |
| **结论** | 视野是当前的，不是永久的；兼向与施工期是加分项的反面 |

**丙这一条最关键**：他原本最心动的是"视野好"，但规划图显示东侧的开阔是**暂时的**。这一条把丙从"性价比最高"打回了"不确定性最高"。

#### 最终选择：乙

**他自己写的决策记录**：

```plain
优势项：
  · 十二问零命中、七煞零命中
  · 南向正对小学操场 —— 明堂开阔，且教育用地不会盖楼（永久开阔）
  · 户型四象齐备，分金在吉格
  · 业主访谈无实质投诉

减分项：
  · 房龄偏老，管道需更换        —— 可改造
  · 无电梯                      —— 不可改造，但本套在三楼

不可改造项：
  · 无（三个房源里唯一的一个）

一句话结论：
  甲和丙的问题都属于"买定离手、改不了"；
  乙的问题只有一个房龄，而房龄是可以用钱解决的 —— 管道换掉就行。

```

#### 复盘要点

**第1步 "可改造项"与"不可改造项"的分类，是这次决策的关键。** 三个房源里，只有乙的所有问题都属于可改造项。**这个分类比任何单项评分都管用。**

**第2步 乙最大的优势是"南向正对小学操场"** —— 古法叫"明堂开阔"，现代语境叫**永久开阔、不会遮挡**。这种**结构性优势**比任何装修都值钱，而且**查规划图就能确认**。

**第3步 甲的问题不是"不好"，而是"通勤优势与噪声代价绑定"。** 如果他对噪声不敏感，甲其实是合理选择。**评估的价值在于把代价说清楚，而不是替人做决定。**

**第4步 三个附加动作决定了这次判断的质量**：夜间复看（甲的噪声）、业主访谈（乙的渗水）、规划图核查（丙的视野）。**这三件事都不花钱，但每一项都改变了一条结论。**

> **给自己的作业**：下次看房，把"白天 + 夜间 + 工作日 + 周末"这四个组合凑齐，**再问一位已入住的业主，再查一次规划图**。五件事做完，你对这套房的判断会超过大多数只看过一次的人。

**验证方法**：

1. **昼夜双看**：白天看采光、视野、楼间距；夜间看灯光、噪声、车灯扫射；
2. **工作日加周末各看一次**：人流与车流模式完全不同；
3. **与已入住业主聊**：噪声、渗水、物业这些"体感问题"，业主比任何理论都准；
4. **查规划图**：确认周边空地未来的用途——今天是绿地，五年后可能是高楼。
