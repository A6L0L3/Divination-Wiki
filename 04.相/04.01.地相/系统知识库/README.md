# 地相系统知识库 · 分卷索引

## README · 形势、理气与现场实操

> 副题：从「气、势、形」三个原点出发，把龙、穴、砂、水、向拆成可执行动作的一套系统手册

### README_1 本库是什么

这是一套把传统地相（堪舆）知识**重新结构化**的操作手册。

它不提供可以背诵的吉凶断语，而是交付一条完整的判断链：

```plain
气（原理） → 势与形（宏观与中观） → 龙穴砂水（四大技术）
→ 向（收口） → 理气（时空校准） → 现代转译（应用） → 复盘验证（迭代）

```

读完并能执行这套流程后，你应该能够：拿到一段真实的地形（或一套待买的住宅），说出它**为什么可用、可用在哪一节、哪一节一破全破**。

> ⚠️ 传统地相学说属民俗文化与环境经验体系。本库供文化研究、人居环境评估与方法论参考之用，其中涉及吉凶祸福的表述应作文化现象理解，不宜当作科学定论或效验承诺。

### README_2 为什么需要一张路径图

这门学问最容易被读坏，原因不在它难，而在它的**知识分布是倒挂的**：

+ 最流行的口诀（"某某方见水发财""某向大吉"）处在链条最末端；
+ 而支撑这些口诀的形势判断、气机推理，却藏在很少有人读的正文里。

结果是背了一堆结论，手上没有判断力。所以本库刻意把顺序重排为：**先立原理，再练形势，最后才给理气**。

这也解释了为什么立向（板块11）被放在龙穴砂水（板块4—9）之后——**向是给前面四样东西收口的，不是起点**。

### README_4 三条使用铁律

| 铁律 | 说明 |
| --- | --- |
| **先排除，后优选** | 凶是确定的，吉是有条件的。五不葬、十大穴病、凶水八形、十不居这四张负面清单应该最先过 |
| **先看形，再论气** | 形势（峦头）是体，理气是用。形势不及格时，任何理气结论都直接作废 |
| **一局只用一套理气** | 三合、玄空、天星、八宅、金锁各有坐标系，不可混用；形势是它们唯一的共用地基 |

### README_6 本库的三条写作纪律

为了让你拿到的是**能用的东西**而不是**能背的东西**，本库在写作上守了三条纪律：

1. **每条口诀都补前提**。凡出现断语，必附一句"它的适用前提是什么"。脱离前提的口诀是废话。
2. **每个结论都配排除项**。凡给出"吉"的判断，必同时给出"什么情况下它不成立"。
3. **每块知识都配现场动作**。凡讲原理，末尾必落到一个可执行的检查动作或记录卡。

> **一句话**：本库想交付的不是"知道亥龙配丙向"，而是"拿到一段真实地形，能说出为什么吉、吉在哪一节、哪一节一破全破"。
