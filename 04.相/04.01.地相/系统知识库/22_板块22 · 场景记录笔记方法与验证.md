## 板块22 · 场景记录笔记方法与验证

### 22_1 本块定位

这一块专讲"怎么记"和"怎么验"。

技术学了一堆，如果记不下来、验不了，就永远停在"听说过"的层面。**笔记是把别人的知识变成自己能力的唯一通道。**

### 22_2 为什么笔记决定成长速度

同样学三年，两个人差距可以非常大。差别往往不在读了多少书，而在**记了多少、验了多少**。

| 类型 | 表现 | 三年后 |
| --- | --- | --- |
| **只记结论** | 笔记本上写满"某某方见水发财""某向大吉" | 背了一堆断语，遇到真实地块仍然无从下手 |
| **记过程加验结果** | 每页都有草图、读数、当时的判断、后来的事实 | 建立了自己的判断权重，能说出"为什么吉、吉在哪一节" |

> **核心原则**：**记判断链，不记断语**。一条断语脱离了前提就是废话；一条判断链哪怕结论错了，也能帮你找到错在哪一步。

### 22_4 三种场景笔记法

#### 方法一：速写笔记（现场用，5 分钟一页）

**适用**：初勘、快速踏勘、看房。

**格式**：只画加只记关键词，不写完整句子。

```plain
   【速写模板】

   地点：______  时间：______  天气：______

   ┌── 方位草图（画八方位 + 主脊线 + 水流向）──┐
   │                                          │
   │        北（靠：___）                      │
   │   西（___）          东（___）            │
   │        南（明堂：___ / 水口：___）        │
   │                                          │
   └──────────────────────────────────────────┘

   第一印象（一个词）：______
   最明显的优点：______
   最明显的硬伤：______
   是否值得复勘：□是 □否

```

> **要点**：速写笔记最重要的不是"全"，而是**记下第一印象**。第一印象往往最准，容易被后来的细节淹没。

#### 方法二：对照笔记（复盘用，同一地块多次勘验）

**适用**：同一地块旱季与雨季、白天与夜间、不同季节的复勘。

**格式**：左右两栏对比。

```plain
   【对照模板】

   项目        第一次（____季）    第二次（____季）    差异与反思
   ─────────────────────────────────────────────────
   水位或湿度      ______             ______          ______
   植被状态        ______             ______          ______
   风向风速        ______             ______          ______
   人流或车流      ______             ______          ______
   原判断          ______             ______          ______
   是否修正        □是 □否           修正内容：______

```

#### 方法三：复盘笔记（事后用，最重要）

**适用**：每次勘验后一周内完成。

**格式**：判断对事实的对照。

```plain
   【复盘模板】

   当时的判断：________________________
   判断依据（列举 2 到 3 条）：
      第1步 ______________
      第2步 ______________
      第3步 ______________

   后来的事实：________________________

   对照结果：□完全应验 □部分应验 □未应验 □反向
   哪一条依据错了：______
   修正后的判断规则：________________________

```

> 📌 **心法**：**复盘笔记的价值不在于"验证古法灵不灵"，而在于"校准你自己的判断权重"**。同一条口诀，对别人准、对你可能不准，因为你们的现场观察习惯不同。

### 22_5 照片与草图规范

**照片三原则**：

| 原则 | 做法 |
| --- | --- |
| **广角看关系** | 每个方位拍一张广角，记录它与穴场的整体关系 |
| **长焦看形态** | 关键砂体、水口拍长焦，记录形态细节 |
| **固定机位** | 复勘时用同一机位、同一焦段拍摄，才能做前后对比 |

**草图三要素**：

| 要素 | 做法 |
| --- | --- |
| **方位** | 必须标北，用标准方位符号 |
| **比例** | 不必精确，但相对远近要大致正确（可标步数或米数） |
| **标注** | 主脊线、水流向、砂体、穴点、测量点都要有符号 |

```plain
   【草图符号约定】

   主脊线：━━━━    支脉：─────
   水流向：～～～→   水口：▓
   穴点：  ★        测量点：⊙
   砂（高）：▲▲▲    水（低）：＿＿＿
   建筑：  ███      道路：═════

```

### 22_6 验证四法

这是把"经验"变成"能力"的核心工具。

| 方法 | 做法 | 能发现什么 |
| --- | --- | --- |
| **换点验证** | 同一目标，换测量点（抬高或平移 1 米）再测 | 磁场干扰、单点偶然误差 |
| **换季验证** | 旱季与雨季、冬与夏各勘一次 | 水位变化、植被遮挡、风向变化、积水问题 |
| **换人验证** | 请另一位同好独立勘验，再对照结论 | 个人偏见、观察盲区 |
| **换派验证** | 用另一套理气重新推演，对照结论 | 单一流派的适用边界 |

> ⚠️ **验证的纪律**：

第1步 **换点验证是必做的**（每次测量都要做）；
第2步 **换季验证对平洋与水法最重要**（旱季看似干爽的地块，雨季可能是泄洪通道）；
第3步 **换派验证只在形势及格后做**（形势不及格时，任何理气结论都无意义）。

### 22_8 案例故事：两本笔记的差距

两个人同期开始学，都记笔记。三年后，两人的差距并不在"谁去的地方多"，而在**笔记里记的是什么**。

#### 甲的笔记：记结论

翻开甲的笔记本，格式高度统一：

| 场景 | 甲的笔记 |
| --- | --- |
| 某山地 | "某年某月，某地，脉弱，凶。" |
| 某宅 | "坐向不合，建议改门。" |
| 某地块 | "水口无收，不取。" |

三年下来记了近百条，**每一条都是一句判断**。

问题在他自己发现：有一次他重看两年前的一条"吉"的记录，完全想不起来**当时为什么判吉**。同样的地形，他现在的看法已经变了，但**没有依据可以对照**——既无法确认当时错了，也无法确认现在错了。

#### 乙的笔记：记证据、过程与待验

乙的每一页都是三栏：

| 栏 | 内容 |
| --- | --- |
| **看到什么** | 脉从西北来，在 A 处收窄约二十米，两侧有低山夹持；雨后 B 处有两道细水交会 |
| **推断什么** | 判断过峡在 A，落点可能在 B（依据：虾须水交会） |
| **待验证什么** | 下次雨后复看 B 处是否仍有交会；挖探坑看土色是否为黄润细土 |

三年下来，乙的笔记里**每一条推断后面都跟着一条"待验证"**。

#### 差距出现在第三年

| 场景 | 甲 | 乙 |
| --- | --- | --- |
| 遇到相似地形 | 翻笔记找"上次怎么判的"，找到的只有结论，无法复用 | 翻笔记找"上次依据是什么"，直接照着再做一遍 |
| 发现自己常错在哪 | 说不出来 | 能列出一张表：**过峡判断失误 5 次、水口漏看 7 次、土质未验 4 次** |
| 被人质疑时 | "我当时是这么记的" | "我当时依据这三条，其中第二条后来被证伪了" |

**乙那张"常错在哪"的表，是本块真正想交付的东西**——它是私人定制的能力短板地图，任何人给不了你，只能自己积累。

#### 乙的三条笔记纪律

| 纪律 | 做法 |
| --- | --- |
| **记证据，不记结论** | 结论会变，证据不会。写"虾须水在 B 处交会"，不要只写"穴在 B" |
| **每次留一条待验证** | 下一次到现场（或下一次雨后）专门去证伪它 |
| **照片要有参照物与方位** | 一张没有参照的照片，一周后连自己都认不出位置 |

#### 复盘要点

**第1步 笔记的价值在于"可复用"，而结论不可复用。** 同一条结论换个场景可能就错了；**依据可以照搬，结论不能照搬。**

**第2步 每次留一条"待验证"，是把笔记变成实验记录的关键。** 有验证的笔记会自我修正，没有验证的笔记只会自我重复。

**第3步 季度复盘只统计一件事：自己最容易在哪一步犯错。** 这个统计出来的分布，比多看十本书更值钱。

**第4步 照片与草图的规范不是形式主义。** 缺了参照物与方位，照片就只是一张图；有了它们，照片就是**可以带回去复查的证据**。

> **一句话**：甲的笔记是一百个答案，乙的笔记是一百个实验。**三年之后，答案会过期，实验不会。**

### 22_9 从笔记到能力：三阶段成长路径

| 阶段 | 笔记特征 | 能力标志 |
| --- | --- | --- |
| **第一阶段·抄** | 记术语、抄口诀、画符号 | 能说出基本术语，但不会用 |
| **第二阶段·记链** | 每页都有"因为某形、所以某气、故用某法"的判断链 | 能独立完成一次完整勘验 |
| **第三阶段·验错** | 大量记录"我错在哪、为什么错" | 能说出"吉在哪一节、哪一节一破全破" |

> **一句话**：**笔记的终点不是"记全"，而是"记错"**。当你开始系统记录自己的错误时，你才真正开始长本事。
