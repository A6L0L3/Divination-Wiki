## 板块15 · 玄空三元九运：给地加上时间坐标

### 15_1 本块定位

三合派给了方位坐标（板块10），天星派给了推导链（板块14）。这一块讲**时间坐标**——三元玄空派。

它回答的问题是：这块地"现在"接哪一股气更好。

### 15_2 时间坐标：三元九运

| 概念 | 内容 |
| --- | --- |
| **正元** | 180 年为一正元 |
| **三元** | 分上、中、下三元，每元 60 年 |
| **九运** | 每运 20 年，三元共九运，周而复始 |
| **运星** | 每运有一颗当令星入中宫主宰 |

> 📌 传统术数以二十年为一运、九运循环为一个完整周期。各派对当前所处运次依自身传承推算。这类周期表述属于传统文化框架内的内容，宜作文化理解，不宜作为精确预测或投资依据。

### 15_4 洛书元旦盘（固定空间基准）

元旦盘是**固定不变**的空间基准，所有飞星都在此基础上排布：

```plain
   ┌─────────┬─────────┬─────────┐
   │  四绿    │  九紫    │  二黑    │
   │  (东南)  │  (南)    │  (西南)  │
   ├─────────┼─────────┼─────────┤
   │  三碧    │  五黄    │  七赤    │
   │  (东)    │  (中)    │  (西)    │
   ├─────────┼─────────┼─────────┤
   │  八白    │  一白    │  六白    │
   │  (东北)  │  (北)    │  (西北)  │
   └─────────┴─────────┴─────────┘

   飞星轨迹（洛书步法）：
   中 → 乾 → 兑 → 艮 → 离 → 坎 → 坤 → 震 → 巽 → 中
    5    6    7    8    9    1    2    3    4    5

```

> **记忆法**：无论哪颗星入中，永远按"中—乾—兑—艮—离—坎—坤—震—巽"这条固定路线顺飞。

### 15_5 排盘四步

| 步骤 | 动作 | 说明 |
| --- | --- | --- |
| **1. 定坐向** | 罗盘（地盘正针）测出坐山与向首 | 记录三次读数取一致值 |
| **2. 排运盘** | **当运星入中宫**，按洛书轨迹顺飞九宫 | 得到九宫的"运星" |
| **3. 排山盘与向盘** | 坐山所在宫的运星入中，按阴阳定顺逆挨排 → **山盘**；向首所在宫的运星入中，同样挨排 → **向盘** | 山管人丁，向管财禄 |
| **4. 叠加综合** | 叠加运盘、山盘、向盘，配合流年飞星 | 看山星与向星是否"到山到向" |

### 15_6 四种基本格局

| 格局 | 含义 | 主应 |
| --- | --- | --- |
| **到山到向** | 山星到坐山、向星到向首 | 丁财两旺，最吉 |
| **上山下水** | 山星下水（到向）、向星上山（到坐） | 丁财两败，最凶 |
| **双星到向** | 山向两星同到向首 | 旺财不旺丁 |
| **双星到坐** | 山向两星同到坐山 | 旺丁不旺财 |

```plain
   【到山到向 vs 上山下水】示意

   到山到向（吉）              上山下水（凶）
   ┌───────────┐              ┌───────────┐
   │  坐山      │              │  坐山      │
   │  山星★     │ ← 山星到坐   │  向星★     │ ← 向星跑到坐山
   ├───────────┤              ├───────────┤
   │  向首      │              │  向首      │
   │  向星★     │ ← 向星到向   │  山星★     │ ← 山星跑到向首
   └───────────┘              └───────────┘
      丁财两旺                    丁财两败

```

### 15_7 下卦与替卦

| 类型 | 判定 | 排盘方式 |
| --- | --- | --- |
| **正山正向** | 坐向在中线左右 **3.5 度**以内 | 用**下卦** |
| **兼向** | 超出 3.5 度 | 用**替卦（起星）** |

**替卦口诀**（决定用何星入中）：

> 子癸并甲申，贪狼一路行；

壬卯乙未坤，五位为巨门；
乾亥辰巽巳，连戌武曲名；
酉辛丑艮丙，天星说破军；
寅午庚丁上，右弼四星临。

> 💡 **两套口径的一致性**：三合的分金吉格（丙丁庚辛）与玄空的中线 3.5 度，结论基本一致——**正中不取，微偏取吉**是共同原则。

### 15_8 城门诀与流年飞星

| 概念 | 含义 | 用法 |
| --- | --- | --- |
| **城门诀** | 向首两旁的水口（气口）若得当运旺星，可作补充 | 当"到山到向"不可得时，用城门诀补救 |
| **流年飞星** | 每年有一颗星入中宫飞布 | 用于**年度微调**（如当年五黄方宜静不宜动） |

> ⚠️ **五黄、二黑所在方位宜静不宜动**（忌动土、开门、安床）。此为传统术数框架内的表述，属文化解释，不作科学预测或投资依据。

### 15_9 案例故事：旺星到向的办公室

一家公司搬入新办公楼。老板按玄空排了一次盘，结论是"旺星到向"，很高兴，认为搬对了。

半年后的实际结果是**一半应验、一半没应验**。

#### 排盘结论与实际的对照

| 项目 | 排盘结论 | 半年实际 |
| --- | --- | --- |
| 财（业务） | 旺星到向，主旺财 | **应验**——新签合同明显增加 |
| 人（团队） | 山星下水，不旺丁 | **应验**——人员流失率上升，加班抱怨增多 |

他后来才注意到，自己排到的其实是**双星到向**——山向两星同到向首，**旺财不旺丁**，而不是最理想的"到山到向"。

#### 现场核对：把玄空结论落到可验证项

复核者做了一件事：把排盘结论与现场物理条件逐项对照，看二者是否一致。

| 检查项 | 现场实况 | 与排盘是否一致 |
| --- | --- | --- |
| 向方（临街一侧） | 开敞、明亮、人流车流方向明确 | 一致——**旺气确在此方** |
| 坐方（内侧） | 临设备间与电梯井，噪声与振动偏大 | 一致——**此处确实不旺** |
| 二黑、五黄所落方位 | 一处是茶水间，一处是打印区 | 一致——**都是动区，非久留之地** |

三项一致，说明排盘与现场并不矛盾。**玄空在这里的作用不是"预言吉凶"，而是"告诉人把什么功能放在哪里"。**

#### 处理：用"分配"代替"化解"

| 位置 | 原用途 | 调整为 |
| --- | --- | --- |
| **向方**（旺星到向） | 一部分用作仓库 | 改为接待、洽谈、开放办公区（动区） |
| **坐方**（山星所在） | 销售团队工位 | 改为档案、午休、静默工位（静区），并加隔声处理 |
| 设备间一侧 | 主管办公室 | 迁走，改为储藏 |
| 二黑、五黄方位 | 打印区 | 保持"动而不留"：不设长期工位，不动土、不改造 |

**关键认识**：这些调整**没有一个是在"化解煞气"**，全部是**功能再分配**。这也正是玄空派最实用的部分——它是一套**空间分配工具**。

#### 复盘要点

**第1步 "到山到向"与"双星到向"是两种格局，不要混为一谈。** 前者丁财两旺，后者**旺财不旺丁**。看到"旺星到向"就以为一切大吉，是常见的读盘错误。

**第2步 玄空是分配工具，不是改命工具。** 它的可操作输出是"什么功能放什么方位"，而不是"摆什么就转运"。

**第3步 可验证的部分只有采光、通风、噪声、动线。** 排盘说向方旺，向方确实开敞明亮——这部分可以核对；至于"旺财"能否兑现，属于**文化解释框架**，不应作为投资依据。

**第4步 时间坐标会变，布局要随运复核。** 元运一换，旺方就变。所以玄空布局不是一次定终身，**每隔一段时间要重新排一次**，至少要在大的装修改动时复核。

> **一句提醒**：老板半年后自己总结了一句——**"排盘告诉我财在人不在，我该做的是把人留住，而不是再去找一个更旺的向。"** 这句话把玄空放回了对的位置。
