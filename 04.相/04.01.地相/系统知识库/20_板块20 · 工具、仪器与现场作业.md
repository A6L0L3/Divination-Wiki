## 板块20 · 工具、仪器与现场作业

### 20_1 本块定位

道理都懂了，还得手上有准头。这一块讲仪器与现场作业——**罗盘怎么用才不出错，误差从哪来，怎么排除**。

### 20_2 罗盘结构速览

一个三合或综合盘的核心圈层（由内到外）：

| 层序 | 名称 | 功能 |
| --- | --- | --- |
| 1 | **天池**（指南针） | 磁针加海底线加水平气泡，罗盘的心脏 |
| 2 | **地盘正针（内盘）** | 二十四山加一百二十分金加七十二龙，用于格龙立向 |
| 3 | **人盘中针** | 逆偏 7.5 度，配二十八宿五行，用于消砂 |
| 4 | **天盘缝针** | 顺偏 7.5 度，配双山三合五行，用于纳水 |
| 5 | **外盘（方形托盘）** | 带十字天心十道线，用于对齐被测物中轴线 |

   罗盘圈层示意（由内到外）

        ╭───────────────╮
        │   ┌───────┐   │  ← 外盘（天心十道线）
        │   │ 天池  │   │

### 20_3 罗盘测量的标准动作（六步）

| 步骤 | 动作 | 要点 |
| --- | --- | --- |
| **1. 清场** | 手机、钥匙、手表、磁扣腰带、车钥匙全部放下 | 保持 3 米以上距离；远离配电箱、变压器、电梯机房（≥5 米）；室内测量离钢筋混凝土墙 1.5 米以上 |
| **2. 定点** | 按测量目的选立极点 | 测整户门向：大门外 1 到 3 米、与门中轴线对齐；测内部布局：房屋几何中心；测阴宅：墓碑前明堂中心 |
| **3. 调平** | 双手分握外盘两侧，罗盘置胸腹之间保持水平 | 天池气泡必须居中；也可放在无磁性支架或木凳上（稳定性更高） |
| **4. 对齐** | 外盘一条边或天心十道线与被测物中轴线**完全平行** | 测门向则与门框立面平行 |
| **5. 纳针** | 转动内盘，使磁针与天池海底线**完全重合**（"叠针"） | 静针后轻弹盘边，观察磁针是否迅速回正——迟滞不归位说明磁针老化或顶针磨损 |
| **6. 读数** | 视线垂直盘面避免视差 | **天心十道线靠近被测物、朝向测量者身体的一端为"坐山"**；连续测 3 次，读数一致才算有效 |

### 20_4 磁偏角：要不要校正

这是自学最容易踩的坑，存在两种立场：

| 立场 | 主张 | 适用 |
| --- | --- | --- |
| **传统古法（八宅、形势派主流）** | 历来直接用磁针取地盘正针，**不校正磁偏角**；强行校正反而违背古法传承 | 形势、八宅、三合古法 |
| **现代实测派** | 主张校正为地理真北，因山脉走向、河流流向均按真北坐标 | 玄空飞星、精细分金 |

**若需校正，操作逻辑**：

| 磁偏角类型 | 旋转方向 | 典型地区 |
| --- | --- | --- |
| **西偏**（我国大部分地区） | 罗盘**顺时针**旋转对应角度 | 东北约西偏 5 到 8 度、华北约 3 到 5 度、江南约 1 到 3 度 |
| **东偏** | 罗盘**逆时针**旋转对应角度 | 少数地区 |

> ⚠ **关键决定**：**先确定你用的是哪一套体系，再决定是否校正，并全程保持一致**。同一份报告里一半校正一半不校正，是致命错误。

### 20_5 卫星图与等高线预勘（省钱省时的第一步）

出门之前先把功课做完：

| 步骤 | 动作 |
| --- | --- |
| **1. 看大势** | 打开地形图或等高线图，找到区域最高点与主脊线，判断来龙方向 |
| **2. 找过峡** | 主脊线上的收窄处，就是潜在的束气点 |
| **3. 看水口** | 找水系汇流与出路，判断关锁情况 |
| **4. 圈选候选区** | 把可能的结穴区（枝水内湾、两水夹角、山窝台地）标出来，再去实地验证 |

> **优势**：卫星图能解决"看得不够高"的问题——很多在地面看不清的主脉走向，在图上是一目了然的连续线条。

### 20_6 六大误差源与排除

| 误差源 | 表现 | 排除方法 |
| --- | --- | --- |
| **金属干扰** | 读数反复跳动、不同位置差异大 | 清空随身金属；远离钢筋墙 1.5 米；换开阔处复测 |
| **未调水平** | 读数系统性偏移 | 重看气泡；用三脚架或支架 |
| **视差** | 同一位置读数不一致 | 视线垂直盘面；或用带镜面的罗盘 |
| **磁针老化** | 摆动迟滞、不归位 | 轻弹盘边测试；必要时维护或更换 |
| **磁偏角未统一** | 与地图坐标对不上 | 先定流派口径，全程一致 |
| **单点测量** | 数据偶然性大 | 同一位置测 3 次取一致值；换点位交叉验证 |

### 20_7 交叉验证法（最重要的一条）

> **读数后，将罗盘抬高或平移 1 米再次测量。两次结果差异应小于 1 度；若差异明显，说明磁场干扰严重，必须更换测点。**

**完整的验证链**：

```plain
   一次有效测量 =
       清场 ✓
     + 调平 ✓
     + 三次读数一致 ✓
     + 换点（抬高或平移）复核小于 1 度 ✓
     + 双向核对（坐与向相差 180 度）✓

```

### 20_9 案例故事：跳动十度的磁针

一次现场测量，同一个门向，换了三个位置量出三个读数，最大相差十度。同行的年轻人说了一句很危险的话：**"那就取中间值吧。"**

带队的师傅没有取中间值，而是把整套动作重做了一遍。他的判断是：**读数不一致时，问题一定在测量，不在房子。**

#### 第一步：按六大误差源逐项排查

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 1. 清场 | 放下手机、钥匙、车钥匙、皮带扣，退到三米外 | 读数仍跳 |
| 2. 远离干扰源 | 检查周边：门口有一处**弱电箱**，五米内有配电间 | **可疑** |
| 3. 离钢筋墙 | 原测点紧贴混凝土墙，退到一点五米外 | 读数稳定一些 |
| 4. 调平 | 确认天池气泡居中 | 已居中 |
| 5. 换点位 | 移到院中开阔处测 | **读数一致** |
| 6. 交叉验证 | 抬高并平移一米复测 | 两次差异小于一度 |

**问题定位**：干扰来自门口弱电箱与**钢质门框**，加上原测点紧贴钢筋墙体。

#### 第二步：换工具、换方法

| 处理 | 原因 |
| --- | --- |
| 改用木凳做支架 | 手持稳定性差，且人体携带金属 |
| 罗盘远离门框一米以上 | 避开钢质门框 |
| 同一位置连续测三次 | 取一致值 |
| 换点位再测一次 | 交叉验证 |

**最终结果**：三次读数完全一致，与院中开阔处测得的数值吻合。而"取中间值"得到的那个数，**与真实值差了将近八度**——足以让坐向从一个山跨到另一个山。

#### 第三步：把口径固定下来

他在记录卡上写明了三件事：

| 记录项 | 内容 |
| --- | --- |
| 所用盘 | 地盘正针（立向用） |
| 磁偏角处理 | 本局按所选流派口径统一处理，全程一致 |
| 测点描述 | 院中开阔处，距墙体三米，木凳支架，三次一致 |

**这三行记录比读数本身更重要**——因为没有口径的读数，半年后自己都看不懂。

#### 复盘要点

**第1步 仪器与现场冲突时，一定重测。** 罗盘不会"大概对"。**读数不一致，问题必在测量环节**，而不是"房子特殊"。

**第2步 单点测量不可靠。** 同一位置测三次取一致值，再换点位交叉验证，两次差异应小于一度。**这两步是硬性动作，不是可选项。**

**第3步 误差来源有优先级：金属干扰 > 未调平 > 视差 > 磁针老化。** 排查按这个顺序走，效率最高。

**第4步 "取中间值"是最危险的一种偷懒。** 它把一个**可查明的系统误差**伪装成了随机误差，然后用平均值把它固定下来。**任何需要"取中间值"的读数，都应该判定为无效并重测。**

> **一句话**：读数不准时，不要怀疑房子，不要取平均值——**换点位，重测，直到三次一致为止。**
