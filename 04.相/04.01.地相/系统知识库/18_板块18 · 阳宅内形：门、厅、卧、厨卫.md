## 板块18 · 阳宅内形：门、厅、卧、厨卫

### 18_1 本块定位

上一块讲外局（板块17）。这一块讲**内形**——户型与室内。

外局决定"能不能买"，内形决定"住得舒不舒服"。两者的关系是：**外局是体，内形是用；内形补救有限度**。

### 18_2 户型的四象核验（把四灵搬进室内）

| 四象 | 核验内容 |
| --- | --- |
| **玄武（靠）** | 主卧、沙发是否靠实墙或山墙？是否有"背后有靠"的安全感？ |
| **朱雀（朝）** | 客厅前方是否开阔？阳台外是否有"明堂"？ |
| **青龙白虎（护）** | 户型左右是否均衡？有无一侧完全空缺或被电梯井占据？ |
| **明堂聚气** | 客厅是否方正开阔？有无穿堂风直进直出？ |

### 18_3 气口：门的五大核查

古人认为"**门为气口**"，大门方位决定纳气。但同时警醒：

> **"近世术者概以大门定宅吉凶，不知大门只是游年一节。宅中所居，祖孙、父子、兄弟、男女众多，祸福岂以大门能定？"**

所以要**截路分房**——大宅院中间有墙门隔阻的，另起游年；现代户型则是**总论（整套房外局与气口）加分论（每个房间的门口、床位、灶位）**结合。

#### 入户门核查五项

- [ ] **不对冲**：不正对电梯门、楼梯口、其他住户门
- [ ] **不直穿**：不正对阳台窗（穿堂，气直泄）
- [ ] **不压迫**：上方无横梁压顶，门前无尖角冲射
- [ ] **有缓冲**：入户后有玄关或小段走廊（宽 1.2 到 1.5 米的镂空屏风或矮柜最佳）
- [ ] **不对门**：不对卫生间门、厨房门、卧室门；开门不见灶、不见厕

### 18_4 客厅（气场中枢，宜阳宜动）

| 宜 | 忌 |
| --- | --- |
| 方正明亮，窗地比 ≥ 1:6 | 被横梁切割 |
| 不狭长如走廊 | 狭长如走廊 |
| 沙发背后**必须靠实墙** | 沙发背后是窗或通道 |
| 前方留开阔空间（明堂） | 不正对卫生间门或厨房门 |
| 家具对称、少尖角 | 层高低于 2.6 米时做复杂吊顶（宜无主灯设计） |

### 18_5 卧室（养气区，宜阴宜静）

| 床位摆放 | 判定 | 现代解释 |
| --- | --- | --- |
| 床下有化粪池 | 不宜 | 管道渗漏、湿气重 |
| 床安于梁下 | 不宜 | 心理压迫感 |
| 床位左右冲门口 | 不宜 | 隐私缺失、动线干扰 |
| 正对厕所门 | 不宜 | 异味、湿度 |
| 正对厨房灶位（骑灶） | 不宜 | 油烟热气 |
| 床位在冷气前方 | 不宜 | 直吹不适 |
| 正前方放镜子 | 不宜 | 睡眠干扰 |
| 床靠厕所之墙 | 不宜 | 防潮、隔音 |
| **床头靠实墙** | **宜** | 安全感、防风 |

其他：面积 **12 到 20 平方米**为佳（过大显空）；主卧门不直接开在客厅电视墙附近；色调低饱和度。

### 18_6 厨房（火位）

| 宜 | 忌 |
| --- | --- |
| 不宜设在住宅正中心；宜在相对次要方位 | 设在户型正中（"火烧心"） |
| 灶台与水槽间距 ≥ 60 厘米（水火分离） | 灶正对水槽、冰箱或门 |
| 灶靠实墙、不靠窗不靠门 | 灶台上方有横梁 |
| 工作三角（冰箱—水槽—灶台）总边长 4 到 6 米 | 工作三角边长过长或过短 |

### 18_7 卫生间（水位）

| 宜 | 忌 |
| --- | --- |
| 优先设在户型边角，忌正中心 | 设在户型正中心 |
| 干湿分离、有独立排风管道、门常关 | 门正对客厅、餐厅、卧室门、大门 |

### 18_8 排水与放水：古代智慧里的建筑科学

看似讲"水主财"，实则包含大量可取的排水智慧：

| 古法要求 | 现代硬指标 |
| --- | --- |
| 排水不可直穿过院、不可从房下经过，宜曲折 | 地漏、下水道走向宜设存水弯，不宜笔直冲出 |
| 忌横穿、直穿、八字分流、斜出 | 排水管不走房屋中心 |
| 忌从房门下、房间下流过 | 卫生间排水不直穿卧室下方 |
| 必须绕边而出 | 排水立管靠外墙或管井布置 |

> **"宅水沟东南流"** 的本质是**排水方向合理**——结合地势与市政管网走向，避免倒坡、避免直冲。

### 18_9 修造次第：先刑祸，后福德

明确操作法则：

> **"先修刑祸，后修福德即吉；先修福德，后修刑祸即凶。"**

| 古法 | 现代含义 |
| --- | --- |
| **先解决负面问题，再锦上添花** | 装修时先处理漏水、通风、隔音、动线这些"刑祸"（痛点），再考虑装饰、软装这些"福德"（增益） |
| **资源投入有先后** | 把预算优先砸在基础工程和功能完善上，而非表面豪华 |
| **以实压虚** | 用充实的功能区去压制或化解户型缺陷 |
| **顺应来路** | 改扩建要顺应原有空间脉络与动线逻辑，不要随意打通、错位开门（"犯抵路"） |

> **"修来路即无不吉，犯抵路未尝安"** —— 新空间要从原有空间的自然延伸关系中"长"出来，而非硬生生嫁接。很多人装修时随意改动线，结果住进去总觉得别扭，这就是"犯抵路"。

**举例**：如果从东方进入此宅居住，日后扩建时**往西方拓展就叫"抵路"（违背来路），往东方拓展就叫"来路"（顺应来路）**。

#### 季节性方位禁忌与十二月生气流转

书中提出季节性的方位禁忌——"**凡欲修造动治，须避四王神**"：春三月不修东方、夏三月不修南方、秋三月不修西方、冬三月不修北方，另有各月对应的方位禁忌。表面是神煞，实质是**顺应自然的施工时序**——春季东方木气生发，不宜动土伤根；这与现代生态学的"施工避开生物繁育季"有相通之处。

**现代转译**：装修改造要考虑季节因素——雨季不修屋顶、冬季慎做湿作业、夏季避开高温时段做重体力施工。

另有"生气死气之位"的月度流转（正月子在子癸、二月丑艮等，逐月推移）。这套体系的本质，是强调**时间与空间的动态配合**——同一个方位，在不同时间有不同属性。

**现代启示**：家居布局不是一次定终身，而应随家庭生命周期动态调整。孩子出生、老人入住、居家办公需求出现，都意味着空间需要重新配置。

### 18_10 案例故事：装修解决不了的选房错误

一对夫妻买完房、装修设计稿都出好了，才请人来看。图纸上有四个问题，其中两个是**装修解决不了的**。

#### 图纸上的四个问题

| 问题 | 层位 | 属于什么 |
| --- | --- | --- |
| 主卧正对两栋楼之间的窄缝 | 外局 | **天斩**（狭管效应、噪声集中） |
| 入户门直对阳台窗 | 内形 | **穿堂**（气直进直出） |
| 厨房位于户型正中 | 内形 | 火位居中，油烟与动线穿越全屋 |
| 主卧床头靠卫生间墙 | 内形 | 隔声与防潮风险 |

#### 第一步：先分类，再动手

| 问题 | 能否用装修解决 | 处理方式 |
| --- | --- | --- |
| 穿堂 | ✓ **可改造** | 加玄关或半高隔断，形成缓冲 |
| 厨房居中 | ⚠ **部分可改** | 位置不能动，但可改开门方向、加强排风、做干湿分离 |
| 床头靠厕墙 | ✓ **可改造** | 床头换到实墙一侧，靠厕墙那一面做衣柜或收纳 |
| **天斩** | ✗ **不可改造** | 只能缓解，不能消除 |

**分类这一步决定了预算怎么花。** 把钱砸在不可改造项上，是最常见的浪费。

#### 第二步：先刑祸，后福德

他们原本的装修预算分配是：四成做风格造型，三成做主材，三成做基础工程。调整后：

| 时间尺度 | 措施 | 原预算归属 |
| --- | --- | --- |
| **立即做** | 卫生间防水重做、管道更换、排风系统升级 | 从"风格造型"挪过来 |
| **立即做** | 靠厕墙一侧加隔声与防潮处理 | 基础工程 |
| **立即做** | 玄关缓冲、厨房门向调整、增加排风 | 基础工程 |
| **可缓** | 背景墙、吊顶造型、装饰柜 | 原"风格造型" |
| **缓解而非解决** | 天斩方向改用双层玻璃、厚重窗帘、封窗处理 | 单项列支 |

**"先修刑祸，后修福德即吉"**——先处理漏水、隔声、通风、动线这些痛点，再谈装饰与软装。**顺序反了，钱花了，住进去还是不舒服。**

#### 第三步：对不可改造项，写明"缓解不等于解决"

报告里关于天斩那一栏是这样写的：

| 层 | 措施 | 效果上限 |
| --- | --- | --- |
| 第一层 | 双层玻璃、厚重窗帘 | 降低噪声与视觉干扰 |
| 第二层 | 该侧不设长期停留位置（床头、书桌挪走） | 减少暴露时长 |
| 第三层 | 阳台封闭并加绿植 | 弱化直视感 |
| **明确告知** | 以上均属**缓解**，不消除狭管效应本身 | — |

这一段是整份报告里最重要的一句。**不写清楚，业主会以为问题已经解决；写清楚了，他至少知道自己买的是什么。**

#### 复盘要点

**第1步 先刑祸后福德。** 漏水、隔声、通风、动线是"刑祸"，装饰与软装是"福德"。**预算优先砸在基础工程与功能完善上，而非表面豪华。**

**第2步 分类决定预算。** 把每一项写成"可改造 / 部分可改 / 不可改造"三档，钱就不会花错地方。

**第3步 "以实压虚"是缓解，不是消除。** 用充实的功能区去压制或化解户型缺陷，效果真实但有限。**报告里必须写明上限，不能含糊。**

**第4步 把这次的教训写成下次的必检项。** 他们后来列了一张选房必检清单，第一条就是"**站到主卧和客厅窗前，把四周三百六十度看一遍**"。这条不花一分钱，却能挡掉一半的错误。

> **一句话**：装修能解决的是"内形"，解决不了的是"外局"。**选房阶段漏掉的东西，装修阶段补不回来——只能缓解。**

**验证方法**：

1. **静默五分钟**：关灯、关音乐，在主要房间各站五分钟，听噪声、感风向、闻气味；
2. **夜间看房**：光煞、车灯扫射、路灯眩光只在夜间显现；
3. **雨天看房**：渗水、返潮、排水问题只在雨天暴露；
4. **开关设备**：看房时要求电梯、水泵、空调处于运行状态。
