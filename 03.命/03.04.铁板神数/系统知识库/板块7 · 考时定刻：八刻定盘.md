# 板块7 · 考时定刻：八刻定盘

> 本板块是铁板神数区别于其他术数的关键一步。前面几个板块解决"这个人是什么命"，本板块解决"这个人与同八字之人差在哪里"。它把"时辰"再切细，切到"刻"，甚至切到"分"。

---

## 7_1 为什么必须定刻

本书序论已经点明理由："往往有八字相同，而富贵各异……皆因未识真机，刻分耳。"这句话的意思是：八字只精确到"时辰"，一个时辰长达两小时，其间出生的人，四柱完全相同，但真实命运可能大不相同。差别不在八字，而在更细的时间刻度上。

原书给出的解决办法是："每一时须推八刻，每一刻又推十五分，推到的准，时刻自然全较，悉合祸福吉凶，丝毫无爽。"也就是说，一个时辰分八刻，一刻再分十五分。这样，一个时辰就被切成 8×15=120 个更细的时段。

这里需要做一个诚实的分层说明。"同八字不同命"是一个观察性的说法，属于第2层的传统主张，其因果解释（差别源于刻分）并未得到现代验证。但"把时辰细分为刻与分"这一操作本身，是可复核的历法技术（第1层），本板块重点讲的是后者。

---

## 7_2 一时八刻与九十六刻

一天十二个时辰，每个时辰八刻，合为九十六刻。这是本板块最基本的算术，也是最便于验证的一点。

```text
   一日一夜
   ├─ 子时（8刻）
   ├─ 丑时（8刻）
   ├─ 寅时（8刻）
   ├─ 卯时（8刻）
   ├─ 辰时（8刻）
   ├─ 巳时（8刻）
   ├─ 午时（8刻）
   ├─ 未时（8刻）
   ├─ 申时（8刻）
   ├─ 酉时（8刻）
   ├─ 戌时（8刻）
   └─ 亥时（8刻）
       12 时辰 × 8 刻 = 96 刻
       每刻 15 分 → 96 × 15 = 1440 分
```

原书"起八刻数例"一节，正是为这九十六刻各配一组干支。其结构是一张 12 行（时辰）× 8 列（刻）的大表，每一格填一组干支。表的读法是：先定出生在哪个时辰，再看落在该时辰的第几刻，然后从格里取出该刻的干支。

## 7_3 起八刻数例

原书此表以草书写就，字迹连绵，逐格转写极易出错。为保证准确，本知识库不逐格抄录全部九十六刻的干支，而是给出这张表的"结构说明"与"查法"，并建议学习者直接以所据底本的原表为准。这样做，是为了避免把看不清的字当成定论，符合本知识库"不编造"的原则。

表的结构可概括为三点。

第一点，纵轴是十二时辰，从子到亥；横轴是初一至初八刻，每时辰八格。

第二点，每一格是一组干支。同一时辰内，八刻的干支按六十甲子的顺序推进；跨时辰时，接续推进，不重置。

第三点，表的用途是"定位"：给定一个出生时辰，再结合"考刻"所得的刻次，查出该刻干支，作为后续纳甲、纳音的输入。

```text
        初1刻  初2刻  初3刻  初4刻  初5刻  初6刻  初7刻  初8刻
  子时 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │
  丑时 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │
  寅时 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │
   …   │  …  │  …  │  …  │  …  │  …  │  …  │  …  │  …  │
  亥时 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │ 干支 │
        （共 12 行 × 8 列 = 96 格，逐格查底本原表）
```

需要强调：上表只示意结构，格内"干支"二字并非实值。真正的干支须查底本。任何声称"凭记忆即可默出全部九十六刻"的说法，都应存疑。

## 7_4 乾宫流度与坤宫流度

原书在八刻表之后，又有"乾宫流度""坤宫流度"两节。"流度"是卦宫之中气数流转的刻度，按十二地支的顺序，给出每个节点所对应的状态。它的作用，是把"刻"与"卦宫"进一步绑定：不仅知道第几刻，还知道这一刻落在哪个卦宫的哪一段流转上。

```text
   乾宫流度（示意）
   子 → 丑 → 寅 → 卯 → 辰 → 巳 → 午 → 未 → 申 → 酉 → 戌 → 亥
   │    │    │    │    │    │    │    │    │    │    │    │
   起点 ……………………………………………………………………………… 终点（循环）

   坤宫流度（示意）
   子 → 丑 → 寅 → 卯 → 辰 → 巳 → 午 → 未 → 申 → 酉 → 戌 → 亥
   （与乾宫同一地支序列，但所配状态不同）
```

乾、坤两宫之所以单列，是因为它们在八卦中居"父母"之位，统摄其余六卦。流度的具体节点状态，同样以底本为准。

## 7_5 定刻实操流程

把上述内容落成可执行步骤，大致如下。这是一套"整理者建议的流程"（第3层），并非原书明文规定的唯一做法。

第1步，定四柱。先排出年、月、日、时四柱，得到基础八字。

第2步，定时辰。确认出生落在十二时辰的哪一个。

第3步，定刻次。这是最需要经验的一步。传统做法是结合"六亲信息"逆推：先假定若干刻次，各排一盘，再与已知的家庭情况（父母、兄弟、配偶等）比对，取吻合度最高者。原书所谓"考刻"，即指此。

第4步，取刻干支。按定下的刻次，查 7_3 的表，取出该刻干支。

第5步，接入后续。把刻干支并入纳甲、纳音与卦数，进入 板块8 的装配流程。

第6步，复核。用另一组已知信息反查，确认刻次是否稳定；若不稳定，回到第3步重来。

## 7_6 考刻验证案例（虚构）

以下为虚构情境，用于演示考刻流程，不对应任何真实人物。

某人自称生于"午时"，但午时跨两小时，究竟落在哪一刻并不清楚。操作者先按午时初刻排一盘，发现盘中"兄弟"宫的信息与来人所言的兄弟数目不符；再按午时五刻排一盘，父母宫的信息仍对不上；直到按午时七刻排盘，六亲信息才大体吻合。操作者据此暂定七刻，并记下"待验"。

数日后，来人补充了一条此前未提的家庭信息，操作者用该信息反查，七刻之盘仍能对应，遂确认刻次。整个过程的关键，不是"一次算准"，而是"多次比对、逐步收敛"。

这个案例说明：定刻不是一锤定音，而是一个"假设—比对—修正"的循环。它更像调试，而不像宣判。这也是本知识库把 板块10 的"复盘与纠错"单列的原因。

## 附：关于"刻"的一个常见误解

有人以为"八刻"是把两小时八等分，每刻十五分钟。从算术上看，两小时除以八，确为十五分钟，这与原书"一刻推十五分"的"分"不是同一层级：原书的"分"是把一刻再细分，而不是"分钟"。读者在换算现代时间时，应把"刻"理解为时段单位，把"分"理解为更细的时段单位，不要与现代的"分钟"直接等同。
