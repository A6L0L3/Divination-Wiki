## 板块6 · 紫微安星体系

> 本板块讲"铺盘面"。本书借用紫微斗数的十二宫与星曜，把前几个板块得到的卦与数落进一张可视的盘里。需要先说明：紫微斗数本身有一套完整的体系，本板块只讲本书实际用到的部分，即十二宫、安身命、主星与辅星安放、五行局、庙旺、长生与大限。

---

### 6_1 十二宫与身命

十二宫是命盘的骨架。地支在盘上的位置是固定的，十二宫则依"命宫"的位置依次排布。本书所列的十二宫为：命宫、兄弟、妻妾（夫妻）、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、相貌。其中"相貌"在多数流派中与"父母"宫同位，"奴仆"亦称"交友"。

十二宫在盘上的排法是逆时针的：命宫之后，依次为兄弟、夫妻、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、相貌，绕盘一周回到命宫之前。

```text
        ┌──────┬──────┬──────┬──────┐
        │  巳  │  午  │  未  │  申  │
        │      │      │      │      │
        ├──────┼──────┴──────┼──────┤
        │  辰  │             │  酉  │
        ├──────┤   中宫      ├──────┤
        │  卯  │  （身宫）    │  戌  │
        ├──────┼──────┬──────┼──────┤
        │  寅  │  丑  │  子  │  亥  │
        └──────┴──────┴──────┴──────┘
```

盘上"子"在下、"午"在上、"卯"在左、"酉"在右，是紫微斗数的通行排法。读者只需记住：十二个地支位是固定的，十二宫则随命宫而转。

---

### 6_2 安身命与起五更

"安身命"是铺盘的第一步：先定命宫，再定身宫。本书有"安身命例"与"起五更例"两节，其法以生月与生时为准，顺逆推数。原文表述较简，且抄本字迹多有漫漶，其大意是：以正月起某宫，顺数至生月，再以生时顺逆推之，所止之宫为命宫；身宫另有一路推法。

对学习者而言，此处不必强记每一步的起止，只需理解其结构：命宫由"月"与"时"共同决定，身宫亦由月时决定但取法不同。具体起止口诀，应以所据底本为准，不同抄本常有差异。

---

### 6_3 十四主星安星歌

十四主星分两组安放：紫微系与天府系。本书收有两首安星歌，与通行紫微斗数一致。

紫微系歌诀为："紫微天机逆行旁，隔一阳武天同当，又隔二位廉贞地，空三复见紫微郎。"这首歌讲的是：以紫微为起点，天机逆行一位，隔一位是太阳，再隔一位是武曲，接着是天同，再隔二位是廉贞。按此顺序，紫微、天机、太阳、武曲、天同、廉贞六星可依次落位。

天府系歌诀为："天府太阴与贪狼，巨门天相及天梁，七杀空三破军位，八星顺数细推详。"这首歌讲的是：天府起，太阴、贪狼、巨门、天相、天梁、七杀顺行，七杀之后空三位是破军。按此顺序，天府、太阴、贪狼、巨门、天相、天梁、七杀、破军八星可依次落位。

两组相加，正好十四主星。需要说明，紫微与天府在盘上的对应关系（所谓"紫府同宫"或"紫府对宫"）决定了整张盘的骨架，安星时须先定紫微，再定天府。

---

### 6_4 辅星与煞星安星诀

除十四主星外，本书还收有多首辅星与煞星的安星诀。以下择要列出，均按通行规则整理。

禄存诀：甲禄在寅、乙禄在卯、丙戊禄在巳、丁己禄在午、庚禄在申、辛禄在酉、壬禄在亥、癸禄在子。口诀为"甲禄到寅宫，乙禄到卯，丙戊禄在巳，丁己禄在午，庚禄居申，辛禄在酉，壬禄在亥，癸禄居子"。

擎羊陀罗诀：擎羊在禄存前一位，陀罗在禄存后一位。即所谓"禄前擎羊，禄后陀罗"。

天马诀：寅午戌马在申，申子辰马在寅，巳酉丑马在亥，亥卯未马在巳。这是按三合局取马的方法。

文昌文曲诀、左辅右弼诀：本书有"安文昌文曲星诀""安左辅右弼星诀"两节，其法以生时或生月起宫，顺逆推之。左辅多从正月起辰顺行，右弼多从正月起戌逆行，具体起止以底本为准。

天魁天钺（贵人）诀：本书有"安天乙贵人"一节，按年干取贵人方位。这类星曜在判断"助力"时有象征意义，属传统取象。

---

### 6_5 五行局与紫微定位

紫微斗数把命盘分为五种"局"，称五行局：水二局、木三局、金四局、土五局、火六局。局的数字（二、三、四、五、六）决定了起运的岁数，也决定了紫微星如何定位。

五行局由命宫的纳音五行决定：命宫纳音属水则水二局，属木则木三局，属金则金四局，属土则土五局，属火则火六局。这一步把 板块2 的纳音与紫微盘接了起来。

紫微星的定位，依"局数"与"生日"两个输入。原书以图的形式给出定位表（所谓"紫微星定局图"），其结构是：横轴为生日，纵轴为局数，交会处即紫微所在之宫。下图示意其结构，具体宫位须查底本原图。

```text
        生日 →
  局数  1  2  3  4  5  6  7  8 …  30
  ┌──────────────────────────────────┐
水二│                                  │
木三│        紫微落宫查此表             │
金四│                                  │
土五│                                  │
火六│                                  │
  └──────────────────────────────────┘
        纵：五行局   横：农历生日
```

读者若手边只有文字而无原图，可用"局数除生日"的余数法推算，但此法在不同流派间有出入，稳妥的做法仍是查底本原图。

### 6_6 星曜庙旺利陷

同一颗星落在不同宫位，其"力量"不同。紫微斗数以"庙、旺、得地、利、益、平和、不得地、落陷"八个等级来描述星曜的强弱。本书收有一张较大的庙旺利陷表，横向为十二地支，纵向为各星。

为便于理解，这里摘录其判读逻辑，而非全表。所谓"庙"，指星曜在该宫最为得力；"旺"次之；"得地""利""益"依次递减；"平和"为中性；"不得地""落陷"则力量受限。判读时，同一颗星在"庙"与在"落陷"，其象征意义可能截然相反。

```text
   强 ◀───────────────────────────────────────▶ 弱
   庙    旺    得地   利    益    平和   不得地   落陷
   │      │      │     │     │      │       │       │
  最得力  很得力  较得力  尚可  略助  中性    受限     最受限
```

需要提醒：庙旺利陷的具体分等，各流派、各抄本并不完全一致。本书的表可作为一家之言，不宜当作唯一标准。

### 6_7 十二长生与安大限

十二长生描述一种"气"的循环，依次为：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。本书按五行局分起长生：火局、木局、土局、金局、水局各有其起长生之宫，再依阳男顺行、阴男逆行等规则排布。

安大限则是给命盘分段：以命宫为起点，每十年行一宫，阳男阴女顺行、阴男阳女逆行。原书"安大限诀"讲的就是这套十年一位的推法。大限的作用，是把静态的命盘切成时间段，使判读可以落到"某十年"。

```text
   长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养 → （循环）
    ▲                                                                          │
    └──────────────────────────────────────────────────────────────────────────┘
```

十二长生与安大限同属"时间轴"工具，与 板块7 的定刻相呼应：一个把一生切成年段，一个把时辰切成刻段。

#### 附：一个关于安星的教学案例（虚构）

以下为虚构情境，不对应真实人物。

有学习者按歌诀安好了十四主星，却发现盘面怎么看都不顺，星辰挤在一两宫里。整理者检查后发现：他把"紫微天机逆行"的"逆行"理解成了顺时针。一步之差，六颗星全错位。重新按逆行安放后，盘面立刻舒展。

这个案例说明：安星歌的每个字都是指令，"顺""逆""隔一""空三"都不能含糊。建议初学时每安一星就在纸上标出序号，安完再对照歌诀逐句复核。
