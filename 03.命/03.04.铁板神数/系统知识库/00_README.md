# 铁板神数知识库 · README 总览

> 本知识库以一部旧题宋人邵康节所著的《铁板数神机妙算》抄本为主要依据，系统梳理"铁板神数"这一传统术数的符号体系、取数规则与排盘逻辑。全书分为十三个板块（板块0 至 板块12），读者既可从头通读，也可按板块单独查阅。

---

## 一、这套知识库要解决什么问题

学习者面对此类古籍时，通常会卡在三个地方。本知识库针对这三处逐一拆解。

第一个问题是"看不懂表"。原书大半篇幅由纳音表、纳甲表、八刻表、星曜庙旺表构成。这些表并不是孤立的数据，它们彼此咬合，构成一条从"生辰"到"卦数"再到"判读"的链条。本知识库把每张表放回它所在的位置，说明它"从哪来、喂给谁"。

第二个问题是"不知道每一步为什么这样做"。原书多为口诀与结论，少有推导。本知识库在保留口诀原意的前提下，补足每一步的动机：为什么要配卦，为什么要定刻，为什么同一八字会有不同命。

第三个问题是"学完落不了地"。本知识库为每个关键环节配了可复盘的记录模板与可自检的验证方法，让学习者能把一次排盘完整地写下来、核对一遍、再回头修正。

## 三、三个层次的区分（请务必先读）

本知识库涉及的陈述，按可信度分为三层。阅读时请始终分清自己在看哪一层，不要把后两层当成已验证的结论。

| 层次 | 内容性质 | 判断标准 | 举例 |
| --- | --- | --- | --- |
| 第1层：可复核的事实 | 文献记载、可复现的计算规则、表格数据 | 对照原书可逐字核对；按规则手算可复现 | "六十甲子纳音中，甲子乙丑为海中金"；"河洛配数中，甲己子午为九" |
| 第2层：传统主张 | 该体系对命运的断言与判读 | 属于传统术数的信仰性说法，未经现代科学检验 | "某宫逢某星主富贵"；"定刻可辨同八字之异" |
| 第3层：编辑推断 | 本知识库整理者的学习建议、教学示例、流程编排 | 属整理者的经验性建议，可讨论、可修改 | "建议先学板块2 再学板块6"；文中的虚构教学案例 |

需要特别说明：铁板神数是一套历史悠久的传统术数。它把天文历法、干支五行、卦爻纳音等符号组织成一套自洽的推演体系，这套体系的内部规则是可以精确复现的（第1层）；但它对人事吉凶的预测效力，属于传统信仰范畴，至今没有可靠证据支持（第2层）。本知识库如实呈现该体系的规则与说法，不等于认同其预测结论。凡属第2层的内容，文中会以"原文所述""传统认为"等措辞标示；凡属第3层的教学示例，会明确标注为"虚构教学案例"。

## 四、如何使用这套知识库

第1步，先读本 README 与 板块0，建立整体地图与学习顺序。

第2步，按板块0 给出的路线推进。零基础者建议从 板块1、板块2、板块3 打底，不要一上来就背八刻表。

第3步，学到 板块4 至 板块7 时，务必边读边手抄表格。本知识库中的表都经过重排，但"手抄一遍"仍是记住它们最有效的方式。

第4步，进入 板块8 后，用 板块10 的模板完整走一遍虚拟案例，再回头对照 板块9 的判读主题。

第5步，随时用 板块11 查术语，用 板块12 找延伸读物。

## 五、排版与符号约定

本知识库统一了以下几处写法，以便在纯文本环境下阅读。

其一，凡原书用带圈数字（如黑圈一、黑圈二）之类编号处，一律改写为"第1步""第2步"或"「1」「2」"，避免带圈字符在部分字体下显示不清。

其二，凡图示（河图、洛书、九宫、十二宫盘、八刻盘等），一律用等宽代码块以字符绘制，保证在不支持图片的环境里也能看清结构。

其三，凡引用古籍原文，用引号标出并尽量保留原字；凡本知识库的转述与解释，用正常行文，不加引号。

其四，文中不设"下一节请看某板块"之类的跳转提示，各板块自成单元，需要串联时请回看上面的知识地图。
