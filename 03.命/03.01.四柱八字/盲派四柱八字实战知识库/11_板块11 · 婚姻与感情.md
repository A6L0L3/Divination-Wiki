# 板块11 · 婚姻与感情

> 本板块讲配偶星与配偶宫的配合关系，核心方法是**星宫同看、以穿害最验**。

## 11_1 配偶星与配偶宫

### 基本定位

```plain
男命：看财星（正财为妻）/ 食伤
女命：看官杀（正官为夫）/ 财星
星与宫的分工：配偶星定「这个人是谁、状态如何」，配偶宫（日支）定「关系落在什么位置、结构稳不稳」。
只看星容易把「配偶本人」和「婚姻关系」混为一谈；只看宫又不知道这个位置对应的人怎么样。两套定位互相校验，是底线要求。
```

### 宫位受伤的三种作用力（按验度排序）

```plain
穿害  最验（「暗着来」的破坏，慢性、说不清的矛盾积累）
冲    次之
刑    又次之
看到夫妻宫被穿，即使别的都好也要多问一句。
```

### 判断流程

```plain
第1步  定配偶星（男看财、女看官杀；不显则活看）
第2步  定配偶宫（日支）
第3步  查星的状态：有没有？被克？被合走？入墓？被穿？
第4步  查宫的状态：被冲？被穿？被刑？伏吟？
第5步  星宫组合定性
第6步  查应期（见板块 7）
前三步是「搜集材料」，第四步是「看结构」，最后两步是「定结论、定时间」。
```


## 11_2 星宫四象限

判断婚姻要同时看「星」和「宫」，两者组合出四种情况。

| 配偶星状态 | 宫好 | 宫坏 |
| :--- | :--- | :--- |
| **星好** | 婚姻顺 | 配偶本人好，但婚姻环境 / 关系有波折 |
| **星坏** | 配偶条件或缘分有缺，但婚姻结构稳 | **星宫同伤**——最凶，主婚变 |

### 四象限的实务解读

```plain
星好宫好  →  婚姻顺，配偶得力
星好宫坏  →  配偶本人不错，但两人关系或家庭环境有张力
星坏宫好  →  配偶条件或缘分有缺，但婚姻结构能维系
星坏宫坏  →  星宫同伤，婚变概率显著升高
即便是「星宫同伤」，也只说「概率显著升高」，不说「一定离婚」。现代婚姻受太多非命理因素影响——当事人意愿、经济条件、子女因素、法律环境都会改变结果。
```


## 11_3 多次婚姻的五大标志

```plain
标志一  星宫同伤（配偶星与夫妻宫同时受伤）
标志二  配偶星被合走 / 被穿坏 / 入墓
标志三  伏吟重现（夫妻宫或配偶星复吟）
标志四  桃花逢绊 / 逢冲
标志五  官杀混杂（女命）或财星混杂（男命）
```

### 逐条详解

#### 标志一：星宫同伤

```plain
最强信号
    配偶星受伤 + 夫妻宫受伤
    →  婚变概率显著提高
```

#### 标志二：配偶星被合走 / 穿坏 / 入墓

```plain
被合走  →  配偶有外情，或缘分被别人夺走
被穿坏  →  配偶关系中有暗伤，或配偶健康、运势受损
入墓    →  缘分收藏、配偶不得力、或配偶长期不在身边
```

#### 标志三：伏吟重现

```plain
夫妻宫伏吟  →  婚姻事反复
配偶星复吟  →  多段缘分
```

#### 标志四：桃花逢绊 / 逢冲

```plain
桃花逢绊  →  感情被牵扯、纠缠不清（走不开）
桃花逢冲  →  感情生变、来得快去得快（留不住）
```

#### 标志五：官杀混杂 / 财星混杂

```plain
女命官杀混杂  →  感情不专、多段缘分
男命财星混杂  →  异性缘较旺之象
```


## 11_4 婚外情的三种常见结构

### 结构一：正财被合走 + 偏财在主位

```plain
正财在月干被他干合走  →  妻缘被夺 / 妻有外情
偏财在时支归禄（主位）  →  自己主动寻求外遇
两象叠加  →  主妻子之外另有女人
```

### 结构二：官杀混杂，杀强官弱

```plain
女命官杀混杂
    正官（夫）弱、七杀（情人）强
    →  主情人势力大于丈夫
杀星合入配偶宫  →  外遇对象进入家庭
```

### 结构三：桃花 + 合

```plain
桃花逢合  →  感情纠葛
    合到主位  →  自己有外情
    合到宾位  →  配偶有外情
```

### 表达纪律

```plain
涉及婚姻、感情第三方的推断
    正确  「这个结构在婚姻上容易有波折，需要多留意沟通」
    正确  「配偶星被合走，建议关注关系中的第三方因素」
    错误  「你一定离婚」
    错误  「你克夫 / 你妻子有外遇」
```


## 11_5 特殊婚配的取象

### 嫁远方 / 年龄悬殊

```plain
年上主远方  →  配偶星在年柱 = 远方之人
水主六数    →  距离的象
满盘伤官    →  女犯伤官嫁老夫（盲师口诀，倾向性规律非绝对）
```

### 终身未婚

```plain
妻星入墓不开
    +
日时禄印相生（自身自足，不需要配偶）
    →  终身未婚之象
```

### 晚婚的象

```plain
配偶星落时柱        →  正缘来得晚
配偶宫被合住        →  早年被牵绊，冲开或解合之年才有正缘
配偶星入墓待开      →  开库之年应婚
初运走忌神运        →  前几步运不成婚，换运后才稳定
```

**判断次序：** 先看配偶星落哪一柱（年月偏早、日时偏晚），再看有没有被合住或入墓；两者同现，晚婚的倾向更明确。

### 异地婚与年龄悬殊

| 结构 | 取象 | 边界条件 |
| :--- | :--- | :--- |
| 配偶星在年柱 | 远方之人、异地缘 | 年柱被冲则距离更远或聚少离多 |
| 配偶星坐驿马 | 配偶走动多、两地分居 | 驿马被合则不动 |
| 女命满盘伤官 | 嫁年长之人（盲师口诀） | 倾向性规律，不是绝对 |
| 官星坐印 | 对方有资历、年龄偏长 | 印被坏则转为依赖而非年龄差 |

### 入赘与招赘

```plain
夫星极弱又被合去他处  →  男方入赘或依附女家
妻星入墓而妻宫为他星占据  →  婚配形式非常规
```

招赘类婚配的判断要格外谨慎——「非常规」不等于「不好」，只是形式与主流不同。表达时用「婚配形式可能与传统路径不同」，不用「不正常」。

> 完整故事见板块 18_13「奇异的婚配」与 18_14「招婿女命」。


## 11_6 盘例一：星宫同毁

```plain
坤造：辛丑  甲午  乙未  丙戌
大运：乙未  丙申  丁酉  戊戌
现实反馈：婚变，后因车祸离世
```

### 推理链（做功 → 象法 → 应期）

```plain
做功层面：夫宫未土穿害夫星午火（午未穿），是「宫穿星」的做功方式，力量最重。
         丑未戌三刑把土气彻底引动，等于给做功加了放大系数。
应期层面：戊戌大运，戌再引动丑未戌三刑，土刑齐则穿害之力达到最大，车祸之灾在此运中兑现。
```

### 结构图

```plain
夫宫（未）──穿──▶  夫星（午）     =  星宫同伤
    ＋
比劫争夫（竞争者多）
    ＋
丑未戌三刑（引动）
    ＋
午火（心血）被晦灭
    =
婚姻失败 + 突发之灾
```

### 星宫状态、应期依据与表达纪律

```plain
星宫状态：夫宫未穿夫星午，星宫同时被毁；比劫争夫，夫星孤立无援。典型「星宫同伤」，非单点受伤。
应期依据：三刑全见才引动——原局已有丑未戌只缺一步；戊戌运补足戌，三刑齐，穿害之力被彻底放大。关键是「等大运补齐原局所缺那一支」。
表达纪律：即便看到「心血被晦灭」这样的凶象，出口仍是「这个结构在婚姻与健康上都值得高度留意」，不说「配偶会出事」「你会出车祸」。
可复用规则：
规则：夫宫穿夫星 = 星宫同伤，婚姻最危险的组合
边界：
  ✓ 看穿的力量（有无解救、力量对比）
  ✓ 看有没有三刑、冲提纲等放大因素
  ✓ 看凶象是否涉及生命机能（决定严重程度）
纪律：
  ✓ 说「婚姻结构张力极大，需要用心经营」
  ✗ 不说「你会离婚 / 配偶会出事」
```


## 11_7 盘例二：三次婚姻，晚年孤独

```plain
坤造：癸卯  戊午  癸丑  丁巳
大运：己未  庚申  辛酉  壬戌
现实反馈：三次婚姻，晚年孤独
```

### 推理链（做功 → 象法 → 应期）

```plain
做功层面：丑午穿是「宫穿星」，夫宫直接伤害夫星；夫星午（月令）、巳（时支藏干）两现，且午被丑穿、巳被亥冲，星多而皆伤。
应期层面：己未运冲丑（宫被冲），第一段婚姻动摇；辛酉、壬戌运金水旺而财星受制，第二、三段先后破裂。
```

```plain
夫宫穿夫星  →  婚姻结构有暗伤
    ＋
夫星多现且皆受伤  →  多段缘分
    ＋
时柱财星被晦  →  晚年孤寂
    =
多段婚姻 + 晚年孤独
```

### 星宫状态、应期依据与表达纪律

```plain
星宫状态：夫星两现（午、巳），丑午穿，巳亥冲——星多而各受一伤。这不是「一次婚姻的大波折」，而是「多段关系各自失败」。
应期依据：关键不在某一柱，而在「每段大运对应破坏一个夫星」——未运冲宫，酉戌运制财。逐段对应才读出「三次」。
表达纪律：即使数出三个夫星，也只能说「感情经历会比较丰富，需要用心经营」，不说「你会结三次婚」。
可复用规则：
规则：夫星多现且皆受伤，主多段缘分
操作：
  ✓ 数出配偶星在天干、地支藏干中的出现次数
  ✓ 逐个检查状态（被克？被合？入墓？被穿？）
  ✓ 被坏的次数 ≈ 失败的段数（倾向，非精确）
纪律：
  ✓ 说「感情经历会比较丰富，需要用心经营」
  ✗ 不说「你会结三次婚」
```


## 11_8 盘例三：正财被合与偏财归禄

```plain
乾造：壬寅  丁未  丙子  癸巳
大运：戊申  己酉  庚戌  辛亥
现实反馈：婚后多次出轨，情人不断
```

### 推理链（做功 → 象法 → 应期）

```plain
做功层面：丁壬合是「合走正财」——妻子的位置被别的力量牵走；巳火归禄于时支主位，是「偏财主动进入自己」；子穿未，婚姻宫本身就有穿害的做功。
应期层面：庚戌、辛亥运财星旺地，偏财得力，外缘最盛；戌运与寅合火，巳火归禄之力更足。
```

```plain
丁（正财=妻）被壬合走  →  妻子这边缘分被夺
    ＋
巳（偏财=情人）落在时支主位  →  外面的人进了自己家
    ＋
子穿未（婚姻宫不稳）  →  婚姻结构本身有问题
    =
婚外情多发
```

### 星宫状态、应期依据与表达纪律

```plain
星宫状态：正财被合走、偏财归主位、婚姻宫被子穿——三个象都指向同一件事，属「多象并见」的强信号。
应期依据：辛亥运天干辛金为偏财透出，地支亥水助官杀，财官两旺而正财丁火受壬合不归——此运外缘最盛。
表达纪律：说「感情上容易出现第三方因素，需要多用心」，不说「你一定出轨」「你妻子有外遇」。
两套体系对照：
盲派：正财被合走 + 偏财在主位 = 妻外有人 / 自己外遇
子平：正偏财混杂，感情不专
两派殊途同归
可复用规则：
规则：正财被合走 + 偏财落主位 → 婚姻外另有缘分
边界：
  ✓ 看合走正财的是谁（被谁夺）
  ✓ 看偏财落在主位还是宾位（主位=自己主动）
  ✓ 看婚姻宫有没有同时受穿冲（决定婚姻稳定性）
纪律：
  ✓ 说「感情上容易出现第三方因素，需要多用心」
  ✗ 不说「你一定出轨」
```


## 11_9 盘例四：终身未婚

```plain
乾造：乙巳  己卯  庚辰  丁丑
大运：戊寅  丁丑  丙子  乙亥
现实反馈：终身未婚，修道之人
```

### 推理链（做功 → 象法 → 应期）

```plain
做功层面：卯木入辰墓，是「妻星入库且库不开」；辰、丑二土生庚金，日时形成「禄印相生」，是「自身有根、自给自足」。两个做功方向相反——一个收住缘分，一个自给自足。
应期层面：此造属原局结构决定的倾向——大运只是强化（丁丑运印更旺、乙亥运财星受克）。
```

### 结构拆解

```plain
妻星（卯木，庚金以木为财）
    →  入辰墓（日支辰）
    →  库不开（原局无戌冲、无酉合之外的开库方式）
日时：庚辰、丁丑
    辰、丑皆湿土，生庚金（印生身）
    →  自身有根有庇护
```

### 星宫状态、应期依据与表达纪律

```plain
星宫状态：妻星入墓且库不开，配偶宫辰土为印库——宫本身也是「收藏、内守」性质，与星的状态互相印证。
应期依据：原局定格局，大运定深浅。此造属「原局倾向」，不靠大运触发；若问「什么时候最明显」，则看财星最弱的运。
表达纪律：说「婚姻缘分偏晚 / 对婚姻的需求感不强」，不说「你一辈子结不了婚」。现实中此造反馈是修道，属「主动选择不婚」而非「求而不得」。
可复用规则：
规则：妻星入墓不开 + 日时禄印相生 → 终身未婚之象
边界：
  ✓ 必须确认墓库不开（见板块 6 闭库三步）
  ✓ 看日时是否有「自足」结构（禄、印生身）
  ✓ 这只是倾向，不是「命中注定不婚」
纪律：
  ✓ 说「婚姻缘分偏晚 / 对婚姻的需求感不强」
  ✗ 不说「你一辈子结不了婚」
```


## 11_10 盘例五：杀强官弱，杀合入宫

```plain
坤造：辛亥  庚寅  丙子  癸巳
大运：辛卯  壬辰  癸巳  甲午
现实反馈：婚内与上司有染，后离婚再嫁
```

### 推理链（做功 → 象法 → 应期）

```plain
做功层面：癸水正官虚浮坐巳被耗，是正官被「耗」；壬水七杀藏亥得禄，是七杀得力；寅亥合把亥中壬水直接合入日支寅——杀星通过合做功进入配偶宫。
应期层面：壬辰运七杀透干（壬水当令），辰与亥拱水，杀星力量最大；癸巳运正官透干却坐巳被耗，此消彼长，关系重组。
```

```plain
癸（正官=夫）虚浮被耗  →  丈夫弱
    ＋
壬（七杀=情人）得禄  →  情人强
    ＋
寅亥合 → 杀合入配偶宫  →  情人进家
    =
婚外情，且最终改嫁
```

### 星宫状态、应期依据与表达纪律

```plain
星宫状态：官杀两现而一弱一强——这是「两个男人」的象；寅亥合把强的那一个合入日支，等于「外缘进入婚姻位置」。
应期依据：壬辰运杀透而辰助水，杀星力量最强，外情在此运成形；癸巳运官星透出却坐巳被耗，同时引动离婚与再嫁的判断。
表达纪律：传统断语「杀重官轻、去官留杀」带有强烈道德评判色彩。现代表达用「感情结构复杂、关系容易重组」，只描述结构，不做道德审判。
两套体系对照：
盲派：杀星合入配偶宫 = 情人进家
子平：杀重官轻 = 去官留杀，易失贞节或改嫁
两派殊途同归
```


## 11_11 婚姻判断的完整流程

```plain
第1步  定星（不显则活看，见板块 4）
第2步  定宫
第3步  查星宫关系（生 / 克 / 冲 / 穿 / 合 / 墓）
第4步  数一数星的段数（多现 = 多段缘分）
第5步  查应期（伏吟、冲合、墓库、到位）
第6步  现代校正（死亡类、道德类断语要软化）
第7步  出口（倾向性表述，重大事项留余地）
```

### 表达纪律总表

| 想说的 | 应该说 | 不该说 |
| :--- | :--- | :--- |
| 婚姻有波折 | 婚姻结构张力较大，需要更多经营 | 你一定离婚 |
| 配偶缘分弱 | 与配偶的缘分偏薄，需要多用心 | 你克夫 / 克妻 |
| 感情有第三方 | 感情上容易出现第三方因素 | 你出轨 / 你配偶有外遇 |
| 婚姻次数多 | 感情经历会比较丰富 | 你会结三次婚 |
