# 板块7 · 应期三定律与实战应用
> 应期回答「什么时候」。盲派的答案围绕两个字：**状态**——状态改变的那一刻就是应期。  
> 三条定律的主出处就在本板块，别处若有简写，一律以本板块为准。

## 7_1 应期的本质：状态改变
### 一句话原理
```plain
原局  =  有什么（基因）
岁运  =  什么时候触发它（开关）

应期  =  状态改变的那一刻
```

不是「流年出现了什么神煞」就应事，而是**原局里已有的那个象，在流年被激活、被改变状态**的那一刻才应事。原局没有的象，岁运再怎么照也照不出来。

```plain
原局如镜，岁运如光
    镜中无物，光照亦空
```

### 状态改变的四种形式
```plain
形式一  重现   →  原局有的字又出现了（到位）
形式二  解开   →  原局合住的被冲开、原局冲着的被合住（合冲互报）
形式三  开合   →  库被打开或关闭（墓库三态）
形式四  转化   →  虚变实、实变虚（虚实改变）
```

前三种就是本板块的三定律，第四种已在板块 6 讲过，此处只做串联。


## 7_2 定律一：到位
「到位」是最基础、最高频的一条。

### 定义
```plain
原局已有的字，在流年再次出现  =  引动
```

### 扩展：禄与原身也算到位
结合板块 3 的换象工具，「到位」的判断范围扩大了一倍：

```plain
不只原字重现算到位：
    流年见某字的禄    →  该字到位
    流年见某字的原身  →  该字到位
```

**举例：**

```plain
原局有寅  →  流年见甲（寅的原身）= 寅到位
原局有庚  →  流年见申（庚的禄）  = 庚到位
```

很多人只盯着「原字重现」，漏掉禄与原身这两条路，命中率会少一半。

### 到位的三种形式总结
| 形式 | 例子（原局有寅） |
| :--- | :--- |
| 原字重现 | 流年见寅 |
| 原身到位 | 流年见甲 |
| 禄到位 | 原局有甲，流年见寅 |

三种形式效力并不完全相同。原字重现最直接，禄与原身到位属于「换象层面的到位」，需要原字与禄、原身之间存在真实的结构关系（同气、拱合、互根）才能成立，不能见到禄位就机械套用。


## 7_3 定律二：合冲互报
本定律讲「反向触发」——稳定的等被打破，对峙的等被收束。

### 定义
```plain
原局有合  →  以冲为应
原局有冲  →  以合为应
```

**常用场景：**

```plain
场景一  婚姻合作之应（原局有合，逢冲年成婚或合作破裂）
场景二  合绊太紧需冲开之局（被绊住了，冲开才有动作）
```

### 落点吉凶怎么定
```plain
随被引动之字的喜忌与宫位定：
    引动的是喜用、落主位  →  倾向于吉
    引动的是忌神、落宾位  →  需细辨
```

合冲互报只负责「找年份」，不负责「定吉凶」。同一场冲，可能冲开合绊带来解脱，也可能冲散根基带来损失，必须回到喜忌才能定性。

### 为什么「合待冲、冲待合」
原理是**状态的反转**：

```plain
原局有合  =  两股力量被绑在一起（稳定态）
    →  需要「冲」来打破稳定  →  逢冲之年应事

原局有冲  =  两股力量在对峙（不稳定态）
    →  需要「合」来收束      →  逢合之年应事
```


## 7_4 定律三：墓库三态
前两条定律讲「字」的引动，本条讲「库」的开合。库的开闭本身属于结构判断，见板块 6_3；本节只讲它在应期上的用法。

### 三态回顾（完整定义见板块 6_3）
```plain
入墓收  →  暂时失去
出墓放  →  重新启用
冲开则发  →  能量释放
```

### 应期角度的用法
墓库在应期上提供三个触发点：

```plain
触发点一  入墓之年  →  该字暂时失效，主「失去、收藏、隐匿」
触发点二  出墓之年  →  该字重新可用，主「恢复、启用、出现」
触发点三  冲库之年  →  库中所藏释放，主「突发、兑现」
```

**吉凶判断：** 冲开之年放出喜用 = 得财官；放出忌神 = 反招灾。已在板块 6 详述，此处不重复。

### 墓库逢值、逢冲皆为应期
```plain
墓库逢值  →  流年再见这个库支  =  应期
墓库逢冲  →  流年冲这个库支    =  应期
```

判断顺序是先看库本身开不开（见板块 6_5），再看流年给不给触发点，两步缺一不可。


## 7_5 应期八句口诀（必背）
三条定律压缩成八句话，是本板块的记忆锚点。

```plain
合待冲，冲待合
墓待开，开待闭
虚待实，实待虚
伏吟待值，反吟待冲
```

### 逐句对照
| 口诀 | 机制 | 对应定律 |
| :--- | :--- | :--- |
| 合待冲 | 原局有合，逢冲而应 | 定律二 |
| 冲待合 | 原局有冲，逢合而应 | 定律二 |
| 墓待开 | 库要冲刑才开 | 定律三 |
| 开待闭 | 开后有闭的时机 | 定律三 |
| 虚待实 | 虚透之字通根变实为应 | 虚实转化 |
| 实待虚 | 实字被伤变虚为应 | 虚实转化 |
| 伏吟待值 | 伏吟等重现之年 | 定律一 |
| 反吟待冲 | 反吟等相冲之年 | 定律二 |

### 补充抓手
```plain
墓库逢值、逢冲  →  应期
虚透逢值        →  应期
```

八句口诀是检索目录，不是断语本身。查到一句对应得上，只能说明「这个年份值得重点检查」，最终还要回到象法与喜忌才能落结论。


## 7_6 实战应用一：婚恋
婚恋判断最容易混淆「感情引动」与「正式成婚」，本节专门拆开。

### 两条要分开表述
```plain
恋爱引动  ≠  正式成婚
```

很多人见流年配偶星出现就断「今年结婚」，结果只是谈了个恋爱。

### 分层判断
```plain
第一层  流年配偶星透干  →  多为感情引动之年
        （只是引动，不等于成婚）

第二层  宫星齐动 + 有正式之合  →  才到谈婚论嫁的门槛
        （宫 = 夫妻宫被引动；星 = 配偶星被引动；
          正式之合 = 合得住、合得正）
```

**判断顺序：**

```plain
第1步  配偶星有没有在流年透干 / 到位？      →  有：感情引动
第2步  夫妻宫有没有同时被引动？              →  有：进入婚姻议题
第3步  有没有正式之合（合得住、不被冲散）？  →  有：可谈婚期
```

### 合在婚姻中的双向性
```plain
合  =  缘分到来信号
冲  =  生离死别信号
```

但要注意：合也可能是「合绊」（被牵制、关系僵住），要看合的是喜是忌、有没有被冲开。


## 7_7 实战应用二：灾厄
灾厄看的是「激」。本节两条抓手：**小激大发**与**三合缺一**。

### 小激大发
```plain
全局一党成势的五行为「病」
    →  流年来「激」（小激大发）
    →  应在该五行所主领域
```

判定要点：「成势」不是简单数个数，要看该五行是否得令、得地、得党；「小激」则是流年仅投下一粒同党或一粒引信。若原局该党本就不成势，流年再激也难成大灾。完整机制与疾病场景用法见板块 13_2。

### 三合缺一
```plain
三合缺一神者
    →  流年填入第三神
    →  往往是大事件引爆点
```

原局有寅午（半合火局）缺戌，流年见戌，三合成立，能量瞬间引爆。

### 灾厄应期的检查顺序
```plain
第1步  定全局的病（哪一行成势为病）
第2步  找流年有没有来激它
第3步  检查三合局有没有被填齐
第4步  看有无解救（决定严重程度）
```


## 7_8 实战应用三：六亲
六亲场景的关键是「应谁」——同一信号落在宫位还是落在运上，应的人完全不同。

### 宫位与运上的区别
```plain
宫位伏吟  →  应六亲事
运上伏吟  →  应自己事
```

同样一个伏吟，出现在哪个位置，应的人就不同。

### 信号对照
```plain
冲  →  生离死别的信号
合  →  缘分到来的信号
```

### 父母缘薄五个触发点
```plain
父母星入墓
父母星被穿坏
父母星被合走
伏吟
冲提纲（月令）
```

现代语境下，这些触发点更多应「健康问题、关系疏远、长期分离」，而非古代语境中的死亡。完整论述见板块 12_5。


## 7_9 象法定事、理法定时
三个场景讲完，本节回到总纲，把「象法」与「理法」两条腿的关系说清。

### 两句话概括整个应期体系
```plain
象法定事  （命局结构决定会发生什么事）
理法定时  （生克旺衰、岁运引动决定什么时候发生）
```

### 为什么必须两者结合
```plain
只用象法：知道会发生什么事，但说不准什么时候
    例：「这个人有破财之象」——哪一年？不知道

只用法理：知道什么时候有变动，但说不准是什么事
    例：「某某年有冲」——冲出什么事？不知道

两者结合：某某年冲财星，且财星为忌 → 该年破财
```

### 完整的应期判断流程
```plain
第1步  定象：命局里有什么象（做功结构 + 取象）
第2步  定事：这个象对应什么事（婚 / 财 / 病 / 官非）
第3步  定人：落在谁身上（宾主 + 六亲定位）
第4步  定时：用三定律找引动的年份
第5步  校验：多重证据是否齐备、有没有解救
第6步  出口：倾向性表述，留有余地
```


## 7_10 盘例一：丧父的应期
本例演示「到位 + 死绝 + 墓库」在六亲应期上的组合使用。

### 盘面
```plain
乾造：甲辰  丙寅  戊戌  壬子
大运：乙丑  甲子  癸亥  壬戌
现实反馈：幼年丧父
```

### 第一步：定父星
```plain
父星  =  偏财
    此造壬水为偏财，透于时干
    子水为壬水之根，在时支
```

### 第二步：查父星状态
```plain
子水偏财被戌土克（日支戌土克子水）
    又被寅木泄（月支寅木泄水生火）

    →  财星被克、被泄
    →  死绝无生机
```

既没有生扶，又被两头消耗——这是判断六亲受损的基础结构。

### 第三步：定应期
```plain
应期落在甲子运

    甲子运  →  子水（父星）在大运重现  =  到位
    →  原局已有的子水被引动
    →  而原局的子水本已死绝
    →  引动之时即应期
```

### 推理链
```plain
父星壬水、子水
    ↓ 状态
被戌克 + 被寅泄 = 死绝
    ↓ 应期
甲子运：子水到位（定律一）
    ↓
引动已死绝之父星
    ↓
应：幼年丧父
```

### 可复用规则
```plain
规则：六亲星死绝（被克且被泄、无生扶）时，
      该星到位之年即为应期
操作要点：
  ✓ 先确认该星是否真的「死绝」（有没有生扶、有没有解救）
  ✓ 再找它到位的年份（原字 / 禄 / 原身）
  ✓ 死绝之星逢到位，往往是应期而非吉期
纪律：
  ✓ 现代语境下，「丧父」可能应「父亲缘薄、长期分离、
    健康出问题」，不可直接断死亡
  ✓ 表达方式：「与父亲的缘分需要留意」优于「父亡」
```


## 7_11 盘例二：合住夫星的应期
本例演示定律二（合冲互报）在婚姻应期上的用法。

### 盘面
```plain
坤造：戊戌  乙丑  庚戌  丙子
大运：甲子  癸亥  壬戌  辛酉
现实反馈：二婚，普通职员
```

### 第一步：定夫星与夫宫
```plain
女命以官杀为夫
    丙火七杀透于时干
    戌中藏丁火（正官）

夫宫  =  日支戌
```

### 第二步：查结构
```plain
子丑合（时支子水与月支丑土相合）
    →  夫星的根基被牵制

丑戌刑（月支丑与日支戌）
    →  夫宫与月令相刑
```

两条线同时存在：一是「合」（子丑合），二是「刑」（丑戌刑）。合主牵制、刑主内部结构不安。

### 第三步：合冲互报的应用
```plain
原局有合（子丑合）
    →  以冲为应

子午冲
    →  逢午年冲子，子丑合被冲开
    →  合被解开之年 = 婚姻状态变化之年
```

### 推理链
```plain
夫星丙火、丁火（藏戌中）
    ↓ 结构
子丑合（牵制）+ 丑戌刑（夫宫不安）
    ↓ 定律二
原局有合，以冲为应
    ↓
逢冲之年，合被解开
    ↓
应：婚姻关系重组
```

### 可复用规则
```plain
规则：原局有合牵制配偶星 / 夫妻宫时，
      逢冲之年往往是婚姻状态变化之年
操作要点：
  ✓ 先找出原局牵引配偶星或夫妻宫的那个「合」
  ✓ 再找冲开这个合的年份
  ✓ 解开不等于「变坏」，要看合住的是喜是忌
边界：
  ✓ 合住喜用 → 冲开为吉
  ✓ 合住忌神 → 冲开为凶
纪律：说「关系需要经历调整」优于「你一定离婚」
```


## 7_12 本板块落地清单
```plain
□ 理解应期的本质是「状态改变」
□ 记住「原局如镜，岁运如光」——先确认原局有没有这个象
□ 掌握到位定律，且知道禄与原身也算到位
□ 掌握合冲互报，理解「稳定的等被打破、对峙的等被收束」
□ 会背应期八句口诀
□ 能区分「恋爱引动」与「正式成婚」
□ 理解「小激大发」与「三合缺一」（小激大发详述见板块 13_2）
□ 知道「宫位伏吟应六亲、运上伏吟应自己」
□ 理解「象法定事、理法定时」
```

## 7_13 笔记作业
拿一个你熟悉的案例，把它的每一条应期都标出来：

```plain
用到了哪条定律？___
引动的是哪个字？___
这个字在原局的什么位置？___
是原字重现、禄到位，还是原身到位？___
有没有解救？___
```

逐条列表，你会发现大多数应期都能归入这几类。做完十个案例后，建立自己的「应期命中率统计」。
