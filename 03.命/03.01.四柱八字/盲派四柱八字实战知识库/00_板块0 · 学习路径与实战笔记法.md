## 板块0 · 学习路径与实战笔记法

### 0_1 学习路径：三条路线与停留条件

总纲已给出三条路径的顺序，此处只补每条的**停留条件与跳步边界**。

#### 0_1_1 路径 A · 零基础

```plain
第1步之后  能独立排出一张盘、标出十神、说出日主强弱
第2步之后  连续三张盘，都能写出「某体制某用，成果归主位/宾位」
第3步之后  能对自己的盘给出至少两个应期窗口，并说明理由
第4步之后  每个专项领域至少有 3 条自己的案例记录
```

第 1 步不可跳。零基础直接进板块 1，会把「做功」读成另一种旺衰。

#### 0_1_2 路径 B · 已有子平基础

```plain
第1步之后  看到任何十神，第一反应是「它在制谁」而不是「它是喜是忌」
第2步之后  能用效率表给一组作用定出相对力度，并回到原局校验力量对比
第3步之后  能对一件事给出至少两层同指的象（共象原则）
```

最大的风险是「换皮不换骨」：表面上开始讲做功，脑子里还是旺衰喜忌。检验办法——随便拿一张盘，问自己「这个十神是喜是忌」，如果这个问题先跳出来，说明切换还没完成。

#### 0_1_3 路径 C · 已接触过盲派

```plain
第1步之后  效率表能不看笔记说出相对力度，且每次都记得校验力量对比
第2步之后  能说出「穿反」的触发条件，并且能在证据不足时主动不翻
第3步之后  能在五分钟内排完一次流年十二神并给出归类
```

#### 0_1_4 速读方案

完整顺序见总纲「三条学习路径」。此处只补一句提醒：**速读的价值在于先建立「一条链怎么走完」的整体感，而不是记住碎片规则。** 速读完之后，回头补板块 5、6、10、11、12 收益最大。

### 0_2 使用建议与边界声明

**使用建议**

- 先读完本板块的 0_1，确定自己走路径 A、B 还是 C，再决定从哪个板块起步。
- 地基层（板块1～4）必须按顺序过一遍。跳过「做功」直接学「穿害」，会把穿害当成孤立的凶符号去套。
- 每个单元读完立刻在一张真实八字上走一遍该单元的固定动作，只读不练等于没学。
- 板块末尾的「落地清单」与「笔记作业」不要跳过，它们决定你是真会还是假会。
- 表达纪律（0_7）优先于断准率：断得准不等于该说，先说该说的。

**边界声明**

本库是盲派命理技法的整理性教材，内容属民俗术数与文献研读范畴，不具备现代科学意义上的可验证预测效力，不构成医疗、法律、财务、婚恋或职业选择的决策建议。

使用本库时遵守四条：

1. 不预测生死。凡涉及寿元、重大疾病、意外的时间性断言，一律不采信、不转述。
2. 不用绝对化与等级化表述。「克夫」「克妻」「贫贱」「孤寡」「夭折」一类古法用语，只在说明原法脉口径时引用，实际论述一律降档为「关系张力较大」「资源偏紧」「支持系统较弱」等可讨论的说法。
3. 不作替代性判断。健康交给医生，财务交给专业顾问，法律交给律师。命理分析只提供一种理解处境的视角。
4. 不制造焦虑。分析的目的，是让人更清楚自己能做什么，而不是更担心自己会遭遇什么。

最好的姿态是：把「做功」当结构学，把「取象」当类比推理，把「命例」当案例读——既不盲从，也不轻慢。

### 0_3 为什么方法比内容先学

绝大多数人学命理的失败点，不在「没听懂」，而在「没留下来」。

```plain
听完觉得通透      →  三个月后只剩一句口诀
断对一次很兴奋    →  没记录，第二次遇到同样结构仍不认识
断错一次很懊恼    →  没复盘，同一个坑掉进第三次
```

内容决定你能断什么，方法决定你能不能持续进步。所以本板块排在最前，要求你在进入板块 1 之前就把三个文件建好。

#### 0_3_1 三个必须先建的文件

```plain
文件一  正例库    →  记录规则成立、推断应验的命例
文件二  反例库    →  记录规则失效、推断落空的命例（最重要）
文件三  自身追踪档案  →  给自己或熟人建的逐年追踪记录
```

反例库最重要：只记成功的命例，会得到一个永远正确的幻觉系统；记下失败与含糊的那几次，才是真正涨功力的地方。

#### 0_3_2 三个文件怎么建（具体动作）

```plain
第1步  建三个文档，命名就是上面三个名字
第2步  每个文档开头写一句话说明用途（防止后来往里乱塞）
第3步  正例库与反例库共用同一条记录模板（见 0_5），
        区别只在「应验情况」填「中」还是「不中」
第4步  自身追踪档案按年份追加，每年固定时间写一次
        （建议生日或立春前后）
第5步  第四个可选文件：口诀卡 / 规则卡（见板块 15 笔记作业）
```

### 0_4 四层架构怎么安排节奏

总纲已给出四层架构图，此处只回答一个问题：**每层该怎么安排时间、什么时候算过关。**

#### 0_4_1 为什么必须分层推进

这四层是依赖关系，不是并列关系：

```plaintext
方法层不通  →  学完就忘（没有记录与验证习惯）
地基不通    →  技法变成孤立的凶符号（见穿害、墓库）
技法不通    →  专项只断得出「吉凶」，断不出「什么事、哪一年」
专项不通    →  实战板块的故事只能当小说看，学不到链条
```

最常见的失败姿势是跳读：今天翻穿害，明天看串宫，后天读婚姻——每个都看了点，但没有任何一条能走完从「谁制谁」到「应哪一年」的完整链。

#### 0_4_2 每层的节奏建议

| 层级 | 建议占总学时 | 过关标准（达不到就别往下走） |
| :--- | :--- | :--- |
| 第 0 层（本板块） | 5% | 三个文件建好，并已记下第一个命例 |
| 第 1 层（板块1～4） | 25% | 拿任意一张盘，30 秒内能说出「谁在制谁、成果归谁」 |
| 第 2 层（板块5～8） | 30% | 能对同一件事给出应期窗口，并说明用的是哪条定律 |
| 第 3 层（板块9～14） | 25% | 官、财、婚、亲、病、灾六个领域各走完一条完整链 |
| 第 4 层（板块15～20） | 15% | 能用八步流程批完一张陌生盘，并写出每条结论有几条证据 |

按每周 5～7 小时投入估算，走完全库约需 4～6 个月；已有子平基础走路径 B 可压缩到 2～3 个月。这只是量级参考，真正的节奏由过关标准决定。

#### 0_4_3 每层内部的推进方式

每层内先粗后细，不要「读完一层再进下一层」：

```plain
第1遍  粗读全层，只求知道每块在解决什么问题
第2遍  精读，配合自己的盘对照，逐条做笔记
第3遍  做题式回顾：遮住结论，看四柱自己推一遍
```

前两遍是「看懂」，第三遍才是「会用」，也最容易被跳过。

### 0_5 场景笔记法：命例怎么记才不白记

#### 0_5_1 核心原则：记录「结构 + 应验」，不记录「感觉」

下面这种记法没有任何可复用信息，应避用：

> 今天算了一个女命，婚姻不好，我说了她离婚，她很惊讶。

三个月后翻到这页，既不知道原局长什么样，也不知道当时依据哪条规则。

#### 0_5_2 场景笔记模板（直接照抄使用）

```plain
┌────────────────────────────────────────────────────────┐
│  【命例编号】婚姻-007                                   │
│  【四柱】坤造：辛丑 甲午 乙未 丙戌                      │
│  【大运】乙未 丙申 丁酉 戊戌                            │
│  【现实反馈】婚变、车祸                                 │
│                                                         │
│  【我当时的判断】                                        │
│    第1条 夫宫未土穿害夫星午火 → 宫星同伤                │
│    第2条 比劫争夫                                         │
│    第3条 丑未戌三刑 → 引动突发之灾                      │
│                                                         │
│  【应验情况】第1条中；第2条中；第3条应车祸。             │
│  【反例/偏差】我最初把三刑断成「事业波折」，实际应血光。 │
│  【可复用规则】夫宫穿夫星 = 星宫同伤，是婚姻最危险组合； │
│               三刑落点优先往「突发/血光」方向考虑。      │
│  【下次如何快速认出】看到「宫穿星」立即检查有无三刑、    │
│                      冲提纲                            │
└────────────────────────────────────────────────────────┘
```

#### 0_5_3 六个字段的填写要点

| 字段 | 填什么 | 常见错误 |
| :--- | :--- | :--- |
| 命例编号 | 领域-序号（如 财富-012） | 不编号，事后无法归类检索 |
| 四柱大运 | 完整干支，标明乾坤 | 只记日柱，回不去原局 |
| 现实反馈 | 对方确认过的事实 | 混入自己的推测当事实 |
| 我的判断 | 当时说的每一条，逐条列 | 只记「我断对了」 |
| 应验情况 | 逐条标 中 / 不中 / 存疑 | 选择性记录，只留中的 |
| 可复用规则 | 抽象出一句可迁移的话 | 停留在具体干支，无法迁移 |

最关键的一栏是「反例/偏差」。建议反例单独建文件，按「判断错在哪一层」分类：

```plain
地基错  →  做功方向认错（谁制谁搞反了）
技法错  →  应期定错（引动方式判断失误）
专项错  →  六亲定错（身份或宫位对不上）
表达错  →  说得太满（本该说倾向，说成了断言）
```

每记一条反例就归一次类。积累到二十条以后，会看到自己的错误集中在哪一层——那就是下一步的补习重点。

#### 0_5_4 三种场景的差异化记法

#### 0_5_5 场景一 · 当面批命（信息实时流动）

现场对方会不断给反馈，笔记要「边听边补」。建议纸笔或手机备忘录，先用速记符号：

```plain
○  =  对方明确确认
△  =  对方含糊 / 未置可否
×  =  对方否认
？  =  我没敢问 / 没问到
```

事后半小时内补全完整模板。超过半小时，现场的细节（表情、停顿、追问）会大量丢失。

#### 0_5_6 场景二 · 案例研读（看书 / 看别人断命）

重点不是抄结论，而是先遮住解析，自己断一遍，再对照：

```plain
第1步  只看四柱，写下你自己的三条判断
第2步  看反馈事实，看自己中了几条
第3步  看原解析，对比你和他用的路径差异
第4步  记下「他想到了我没想到的那一点」，这是本例最大收获
```

#### 0_5_7 场景三 · 自己的盘长期追踪（最有价值的一类）

给自己或熟人建档，每年固定时间追加一条记录：

```plain
【某年 · 岁运】流年干支 + 当时大运
【当年发生】客观事件（换工作 / 搬家 / 生病 / 结婚）
【年初预判】我当时怎么说的
【年末校准】中 / 不中，差在哪
```

连续记录若干年之后，会得到一份任何书本都给不了的东西：**你自己这套读盘方式的真实准确率分布**，以及个人容易在哪个环节出错。

### 0_6 三遍验证法：一条规则怎么才算「学会」

听到一条规则（比如「穿倒禄神主大灾」）到真正能用，中间要过三遍。

#### 0_6_1 第一遍 · 正例验证（找 5 个能对上的）

在案例库里找至少 5 个符合该规则的命例，确认规则确实能解释现象。检验标准是：每找到一例，问自己「如果只给我四柱、不看结果，我能用这条规则推出这件事吗」。能，才算数；看答案才恍然大悟的，不算。

#### 0_6_2 第二遍 · 反例搜索（刻意找对不上的）

这一步绝大多数人会跳过，但它决定了你是「会算命」还是「会背口诀」。

主动找「符合规则但事情没发生」的盘，然后追问差在哪。差异通常来自四个方面：

```plain
差异1  力量对比不同    →  制方不够强，制不住
差异2  有解救          →  被穿之字有生扶、有合住
差异3  宫位不对        →  受伤的字不在该宫位，落点不在那个人身上
差异4  被更大的结构盖过 →  另一组做功主导全局
```

如果一个规则你找不到任何反例，通常不是它完美，而是你案例量不够。

#### 0_6_3 第三遍 · 边界标定（写下适用条件）

把规则的适用条件写成一句可检查的话：

| 规则 | 模糊表述（不可用） | 边界化表述（可用） |
| :--- | :--- | :--- |
| 穿倒禄神 | 主大灾 | 禄神为主位之体且无生扶、被穿方力量占优时主大灾；若禄有强根或被合住，降级为劳碌或伤病 |
| 财库冲开 | 主发财 | 财为喜用、库中藏财、原局或岁运有刑冲开库且库未被合闭时主发财；财为忌或库被合闭则反主财来财去 |
| 官杀混杂 | 婚姻不好 | 女命官杀同现且无制化、夫宫同时受穿冲时主感情多变；有印化或官杀一方入库则从轻 |

在笔记里给每条规则建一个「边界栏」，随着案例积累不断往里加条件。半年后回看，最初写下的规则会被改得体无完肤——这正是进步。

#### 0_6_4 三遍的时间分配（经验参考）

```plain
第1遍 正例验证  →  约占 30% 精力，但耗时最短
第2遍 反例搜索  →  约占 50% 精力，最费时也最值
第3遍 边界标定  →  约占 20% 精力，但决定这条规则能不能迁移
```

多数人把 90% 的精力花在第一遍，结果是：规则背得滚瓜烂熟，一遇到反例就懵。

### 0_7 表达纪律：怎么说比说什么更重要

这一节不直接提升断命能力，但直接决定你能不能长期做这件事、会不会伤到人。

#### 0_7_1 四条硬纪律

**纪律一 · 不作模棱两可、两头都能圆的说法。**

「你这两年可能有变动，也可能没有」是零信息量的废话。能给出现象对应的具体方向时就说清楚，没有把握的部分坦率说明「这一块我没看出来」。

**纪律二 · 概率表述，不作绝对断言。**

应期推演给的是概率较高的观察窗口，不是确定的时间表。尤其涉及生死、重病、亲人大故，必须以倾向性表述呈现。

**纪律三 · 重大事项必须证据链完整才出口。**

涉及健康、亲情变故等重大推断，证据不足宁可不断。检查清单：

```plain
□ 被制 / 被穿的是谁？身份定准了吗？
□ 制方与被制方的五行各主什么？
□ 宫位对得上吗？
□ 有没有解救？
□ 有没有第二条独立证据支持同一结论？
□ 我能不能说清「如果不是这样，会是什么样」？
```

少于四条成立的，只说倾向，不说结论。

**纪律四 · 不越界给专业建议。**

五行脏腑对应是传统文化象法参考，不构成任何医疗建议。遇到健康指向，正确说法是「这个方向建议留意、可以做个检查」，而不是「你肝有病」。

**现代断语软化表（9 条完整版）见板块 15_8**，此处不重复。

#### 0_7_2 学习心态：三要三不要

```plain
要：把每个不准的盘当成最贵的教材
要：优先积累你最常接触人群的案例
要：定期回头改自己一年前写下的规则

不要：用单一案例证明某条规则必然成立
不要：为了显得准而事后调整说法
不要：在没建立证据链前对重大事项表态
```

### 0_9 笔记作业

#### 0_9_1 作业一 · 三个文件落地（进入板块 1 前必做）

按 0_3 的动作建好三个文件，并在每个文件里写下第一条记录。第一条不必是别人——用自己的盘或熟人的盘即可。

#### 0_9_2 作业二 · 一条规则的边界标定

选一条你自认为「已经会了」的规则（例如「财库冲开主发财」或「穿倒禄神主大灾」），按 0_6 走完三遍：

```plain
第1步  找 3～5 个正例，记录四柱与反馈
第2步  刻意找 1～2 个「符合规则但没发生」的盘，写下差异
第3步  把规则改写成一句带条件的边界化表述
```

做完你大概率会发现：原来那条「已经会了」的规则，其实有一半条件没写过。

#### 0_9_3 作业三 · 一次表达纪律自查

翻出你最近一次给人断命（或给自己推盘）的记录，逐条对照 0_7 的四条纪律，标出：

```plain
□ 有没有说过两头都能圆的模糊话？
□ 有没有把倾向说成了断言？
□ 有没有在证据不足时说了重大事项？
□ 有没有越界给过医疗 / 法律 / 投资建议？
```

有就改，改完写进笔记。**这三个作业总共不超过两小时，但它们决定了后面二十个板块学完能留下多少。**
