# 板块15 · 断语口诀集锦
> 把前面板块的规则压缩成可速查的口诀。  
> **口诀是索引，不是结论——用之前必须回原局校验条件。**  

## 15_1 命学六大要诀（终极心法）

### 口诀全文
```plain
一、干支配置
二、宾主理论
三、应期法则
四、十神意向
五、贼捕理论
六、气势论
```

### 逐条详解

#### 要诀一 · 干支配置
**建立立体信息提取模式。**
```plain
基础三项：
    干支互通
    虚实
    禄与原身关系

补充：干支自合
    如丁亥、戊子等
    自合主内心矛盾、自我约束或夫妻恩爱（视位置而定）
```

#### 要诀二 · 宾主理论
**区分自我与他人、内部与外部。**
```plain
要点：宾主可动态转换
    例：年柱官星被日主合  →  官由宾变主，为我所用
```

#### 要诀三 · 应期法则
**合冲刑穿墓库皆有应期。**
```plain
秘传口诀：
    合待冲，冲待合
    墓待开，开待闭
    虚待实，实待虚
    伏吟待值，反吟待冲
```

| 口诀 | 机制 | 典型场景 |
| :--- | :--- | :--- |
| 合待冲 | 原局有合，逢冲而应 | 合住的财等冲来解 |
| 冲待合 | 原局有冲，逢合而应 | 冲开的字等合来收 |
| 墓待开 | 库要冲刑才开 | 辰戌丑未逢冲刑 |
| 开待闭 | 开后有闭的时机 | 库开了再看何时闭 |
| 虚待实 | 虚透之字通根变实为应 | 虚财逢值变实 |
| 实待虚 | 实字被伤变虚为应 | 实根被冲拔掉 |
| 伏吟待值 | 伏吟等重现之年 | 岁运再见同字 |
| 反吟待冲 | 反吟等相冲之年 | 岁运逢冲 |


#### 要诀四 · 十神意向
**活论十神，不拘泥于固定六亲。**
```plain
要点：十神可互为表里
    财  可为父，亦可为妻
    官  可为夫，亦可为子女（女命）
```

#### 要诀五 · 贼捕理论
```plain
制去忌神（贼）时，得忌神之喜
捕神旺，喜贼神出现
有捕无贼，反凶
修正版：贼捕需原局成势，岁运引发方验
        若原局贼捕力量悬殊，则为假结构
```

#### 要诀六 · 气势论
```plain
五行失衡时，顺势而为
得势之命，病神即为成就之源
有势无病，反为贱
秘传警示：气势不可逆，逆势而行必遭灾
```
逆势的岁运往往是人生最凶的节点。

## 15_2 批命技巧（精选与注解）

### 核心断语
```plain
1.  劫财带七杀，局主易违法
    注：劫财为胆大，七杀为暴力，组合无制则易触犯规则边界
2.  伤官见了官，常走牢狱边
    注：伤官见官，为祸百端，尤其官杀为用时
        但力量相当才凶；伤官能制住官反成贵格
3.  比劫夺了财，当心妻有灾
    注：男命比劫夺财，妻星受损
        但身强制得住则反主发财，须辨力量
4.  七杀贴了身，事业难称心
    注：七杀攻身无制，主压力、小人、疾病
5.  食神两不伤，子女能隆昌
    注：食神为子女星，不受枭印夺、刑冲穿，则子女贤孝
6.  喜神得力临太岁，人变聪明事如意
    忌神得势临太岁，人变混账事也悖
    注：强调流年对心性、运势的直接影响
7.  败运切勿心不甘，当心因贪把船翻
    注：运势低迷时应守不宜攻，贪则致祸
8.  财官印绶，分偏正以推详
    食伤比劫，察旺衰而定夺
    注：十神需分阴阳、辨旺衰，不可混为一谈
```

第 1 条最严格：劫财须贴身、七杀须无制；若七杀有印化或食伤制，转为贵格。第 2 条看力量对比；第 3 条看身强不强。

### 断语使用三原则
```plain
原则一  断语是压缩的经验，使用前要展开条件
原则二  一条断语不能单独下结论，必须回原局校验
原则三  现代语境要软化
```

## 15_3 秘传断语分类

按十神与宫位分类，并对带古代语境或道德评判的句子做现代校正。**凡涉及生死、灾祸的传统断语，一律以「方向性提示」替代「确定性断言」**。

### 印星类
```plain
印绶逢生，母贤子孝
印绶被克，母病子忧
```
### 官杀类
```plain
官杀有制，威震边疆
```
### 财星类
```plain
财星被劫，妻有灾
```
```plain
「财星入墓，父先亡」
    古代：主父早亡
    现代：可能仅主父病、父缘薄、父亲长期不在身边
    不可机械套用
```
### 食伤类

### 比劫类

### 墓库类

### 六亲宫位类

## 15_5 两套体系的总纲口诀

### 总纲：弃旺衰，重做功
```plain
不以日主旺衰论吉凶
而以命局表达的「象」和「做功」效率定贵贱
注解：旺衰仅用于判断「体」能否承受「用」，不是取用神的依据
```
### 原局与岁运
```plain
八字为体（车），岁运为用（路）
    原局定层次，岁运定应期
「原局如镜，岁运如光」——镜中无物，光照亦空
```
### 真假与虚实
```plain
虚透为象，落实为质
「虚看名，实看利；虚怕克，实怕坏」
```
### 象法为尊
```plain
干支、十神、宫位皆为「象」
    命理本质是「读象」而非「算数」
象有万千，唯「做功之象」与「宾主之象」为核心
```
## 15_6 做功效率补充规则

### 分级规则
```plain
制用  >  化用  >  合用
阳制阴  >  阴制阳
同柱做功  >  异柱  >  遥隔
```
### 功分大小、效分久暂
```plain
制尽      =  大功
制不尽    =  小功
原局有功  =  久功
岁运之功  =  暂功
```
### 废功三型
```plain
体弱不能制用
用神太重制不住
制神被坏
```

## 15_8 现代断语软化对照表

全库软化主表，是 15_7 索引里所有涉及生死、灾祸、道德评判的断语出口前必须过一遍的一关。**主表共 10 条**，各专项对照：婚姻见板块 11、六亲见板块 12_10、健康见板块 13_9。

| 传统断语 | 现代表述 | 软化要点 |
| :--- | :--- | :--- |
| 财星入墓，父先亡 | 与父亲缘分偏薄 / 父亲健康需留意 | 「先亡」改为「缘分偏薄或健康留意」 |
| 年柱受克，父母早亡 | 与父母缘分偏薄 / 早年聚少离多 | 「早亡」改为「缘分偏薄、聚少离多」 |
| 比劫重重，克父损妻 | 与父亲、妻子的缘分张力较大 | 去掉「克」字，改为中性描述 |
| 官杀混杂，为人好色 | 异性缘较旺，感情选择较多 | 去掉道德评判，改为中性事实 |
| 日支穿害，妻离子散 | 婚姻结构张力较大，需要用心经营 | 「离散」改为「张力较大」 |
| 时柱伏吟，子女缘薄 | 与子女缘分偏晚或聚少离多 | 「缘薄」本身已较中性，补上「偏晚」 |
| 禄神当财，体力劳动 | 技术工种、自由职业、靠自身技能 | 「体力劳动」窄化，扩为「技能型职业」 |
| 常走牢狱边 | 这个阶段在规则边界上需要格外谨慎 | 「牢狱」改为行为建议 |
| 命克子女 | 与子女的缘分需要多用心（绝不用「克」字） | 彻底去掉「克」字 |
| 食神两不伤，子女能隆昌 | 子女缘分方向较好，关系多融洽 | 把断语式表达转为倾向性描述 |

**软化三原则：**
```plain
原则一  把「死亡」软化为「健康需留意 / 缘分偏薄」
原则二  把道德评判（好色、克夫）改为中性描述
原则三  把结果断言改为行为建议
```

## 15_9 口诀使用的三条防错纪律

### 纪律一：口诀必须展开条件
```plain
错误用法：
    看到「伤官见官」  →  断牢狱
正确用法：
    看到伤官见官 → 展开
    检查：力量对比如何？官为用还是为忌？有没有印？
    力量相当且官为用  →  倾向官非
    伤官能制住官      →  反成贵格
```
不展开条件就套口诀，等于跳过「谁制谁」直接下结论。

### 纪律二：现代断语要软化
使用 15_8 对照表，出口前先过一遍。三步：第 1 步找出死亡、灾祸、道德评判词汇；第 2 步对照 15_8 换成中性表述；第 3 步检查有没有「绝对会」「一定」，有就改成「倾向」「值得留意」。

### 纪律三：断语不能脱离做功
```plain
口诀是「果」，做功是「因」
不知道因（谁制谁、制得成不成）就用果（断语）直接下结论
    →  必然出错
```

## 15_11 笔记作业

做一张自己的「口诀卡」，每张卡一条口诀，写三部分：
```plain
正面：口诀原文
背面：第1条 展开条件（什么情况下成立）
      第2条 反例（什么情况下不成立）
      第3条 我自己的实战案例 1-2 条
```
口诀卡做到三十张，断命速度会有质的提升。**背面的第 2 栏（反例）最容易空着，但恰恰最有价值**——没有反例的口诀，就是会被滥用的口诀。

做卡顺序建议：先做 15_2 的八条核心断语，再做 15_3 的分类口诀，最后做 15_5 的总纲口诀。
