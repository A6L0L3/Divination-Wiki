# 板块20 · 盲派实战批断八步流程

> 这是全库的收官板块，把前面十九个板块缝合起来的总流程。  
> 学完技法后真正上手时最容易犯的错不是「不会」，而是**「不知道先干什么」**。

### 八步总览

```plain
第1步  看全局气势成党    →  谁家人多？势力版图长什么样？
第2步  定宾主、分体用    →  年月是外场，日时是自家
第3步  定做功方向与效率  →  用什么手段取目标？制得干净吗？
第4步  寻根基、找出处    →  目标落在家里还是家外？几个人分？
第5步  六亲定位与健康    →  沿关系网认人，不机械背十神表
第6步  推虚实与应期      →  状态改变那一刻就是应期
第7步  行业与事件取象    →  把干支组合翻译成现实画面
第8步  复核与出口        →  多点互证、倾向表述、证据不足宁可不断
```

**前三步建立全局观（上），中间三步走进具体人事（中），最后两步翻译成现实画面并按纪律出口（下）。**

### 八步衔接关系

```plain
【上三步】第1步画势力版图，第2步分自家与外场，第3步定做功方向
    →  不碰细节，只画框架
【中三步】第4步财官落点，第5步六亲病位，第6步应期窗口
    →  把框架填成人和事
【下两步】第7步翻译成现实画面，第8步按纪律说出口
    →  决定结论能不能交付
```

**口诀：先有框架、再填人事、最后出口。** 跳过上三步直接看细节，容易一叶障目；跳过中三步直接取象，容易空泛不实。

## 20_1 第1步 · 看全局气势成党

先把八个字当成八个人，每人属于金木水火土五个家族之一（**地支里藏着的也算数**）。第一眼不研究单个字的吉凶，而是**眯起眼看整张势力版图**：哪家人数最多？有没有坐上好位置（月令、日支）？

数票法的本质是**用票数代替直觉**。

### 操作：数票法

```plain
第1步  把八个字按五行归类（地支按本气算一票）
第2步  哪个五行拿到三票以上、且月令归它或有生它的字贴身  →  成党
第3步  出现两大阵营对峙  →  做功结构就浮出水面了
```

> 五行与刑冲合害基础见板块 1、2；两党的做功方式见板块 2 效率表。

### 微实例：庚寅 辛巳 庚申 己卯

| 层次 | 年柱 | 月柱 | 日柱 | 时柱 |
| :--- | :--- | :--- | :--- | :--- |
| 天干 | 庚 | 辛 | 庚 ★ | 己 |
| 地支 | 寅 | 巳 | 申 | 卯 |
| 藏干 | 甲 丙 戊 | 丙 戊 庚 | 庚 壬 戊 | 乙 |

```plain
数票：
金  =  庚、辛、庚、申  共四票，还坐着日主的椅子（日支申为庚禄）
    →  成党，且是「自己人」的党
木  =  寅、卯  共两票，恰好是金所克之财  →  被围攻的目标
```

金党围攻木财党，中间隔一个巳火。**后面七步的所有推演都站在这张势力图上。**

### 易错点

```plain
误把地支藏干漏算  →  一漏就漏一到两票，势力版图可能整个反转
口诀：天干四个加地支本气，先数票再发言
```

### 自检问句

```plain
第1句  我数清楚了几票？谁超过三票？
第2句  成党的是「自己人」（日主同类）还是「对家」？
第3句  有没有明显的两大阵营对峙？
第4句  势力版图有没有反常识的地方？（比如水命却火票最多）
```


## 20_2 第2步 · 定宾主、分体用

**宾主看宫位，体用看十神身份——同一个字有两层身份，要分开判。**

```plain
宾主（宫位）：
    年月两柱  =  宾位  =  父母兄弟、社会外场
    日时两柱  =  主位  =  自己、配偶、子女的小家

体用（十神身份）：
    印、比劫、食伤、禄  =  「体」  =  我方能调遣去干活的力量
    财、官杀            =  「用」  =  要去获取的目标
```

**例：时干正财** → 十神层面属「用」（是钱），宫位层面坐在主位（钱在家门口）。两层结论同时成立，不矛盾。

记住：体用问「它是什么身份」，宾主问「它在谁的地盘」——两个问题，两套答案。

> 完整规则见板块 1。

### 微实例：以体取用

```plain
癸亥  庚申  壬申  丙午
    年支亥  =  壬水日主之禄  =  「体」的主力之一
    时柱午  =  火  =  财星  =  「用」
        ↓
    亥（体）去制午（用）  →  一次「以体取用」
```

### 易错点

```plain
把体用和宾主混为一谈
    →  错把「用神」当「主位」，错把「财星在日时」当「财是体」
口诀：体用问身份，宾主问地盘，各答各的
```

### 自检问句

```plain
第1句  财官落在主位还是宾位？（自家用还是外面分）
第2句  我的「体」有哪几个字？哪个最得力？
第3句  我要取的「用」是哪个字？被谁制？
第4句  有没有体用颠倒的地方？（比如财当体、比劫当用）
```


## 20_3 第3步 · 定做功方向与效率

盯着势力图问：**我的「体」制了哪个「用」？用的什么手段（制用、化制、合制、墓制、双制五选一或并存）？制得干不干净？**

**「制得干净」的程度决定层次**（「贼被捕」）：食伤把官杀制得干净 = 秩序建立 = 一官清透显贵。

效率不是越高越好，而是**恰到好处**。

> 效率量化表见板块 2；比劫制财双面性见板块 10；贼捕清贵断法见板块 9。

### 微实例 · 同构不同命

这是全库最有教学价值的一组对照——两造都是比劫围攻财星，结构相似，力量不同，结果天壤之别：

```plain
造一：庚寅  辛巳  庚申  己卯
    三重金党，还坐着申禄  →  扛得住
    现实：开门店卖装修材料，发财但辛苦、走动多

造二：癸亥  庚申  壬申  丙午
    单禄势薄去制财  →  勉强制
    现实：凭本事挣辛苦钱，辽宁远赴深圳打工，积蓄有限
```

| 层次 | 年柱 | 月柱 | 日柱 | 时柱 |
| :--- | :--- | :--- | :--- | :--- |
| 天干 | 癸 | 庚 | 壬 ★ | 丙 |
| 地支 | 亥 | 申 | 申 | 午 |
| 藏干 | 壬 甲 | 庚 壬 戊 | 庚 壬 戊 | 丁 己 |

**「同构不同命」值得反复体会：** 命理里没有「某个组合必然如何」这回事——力量对比一变，结论就完全不同。**先判扛不扛得住。**

### 易错点

```plain
只认结构、不称力量
    →  看到「比劫制财」就断发财，不看扛不扛得住
口诀：同构必比力量，结构相同结论可以相反
```

### 自检问句

```plain
第1句  我的体是几票？用的用是几票？谁多谁少？
第2句  用的是五结构里的哪一种？
第3句  制得干净吗？（有无反制、有无通关）
第4句  扛得住吗？这一句回答不了就别往下断
```


## 20_4 第4步 · 寻根基、找出处、看份额

盯住财官目标，问三个问题：**它们从哪个字透出、根扎在哪（出处）？一共几份、几个人分（份额）？落在日时主位还是年月宾位（家里家外）？**

**家里家外 = 三种生存形态：**

```plain
财官在家里（日时）  →  自己做生意、当老板
财官在家外（年月）  →  给别人打工
财官与国家体制字样相联（配印星、官星空位信号）  →  吃皇粮
```

**「吃皇粮」的认定：** 财官与国家体制的字样相联，且配印星、官星空位信号，多应体制内岗位。例：某造财官齐透而与官印相生 → 命主为国税局收银类岗位。

> 家里家外完整口径见板块 1 宾主一节；份额算法与手足计数共用一套工具，见板块 12 计数四步法。

### 易错点

```plain
只看透干、不看根扎在哪
    →  财官透在年月就断打工，忘了看根
口诀：出处与根扎要一起看，透干只是表象
```

### 自检问句

```plain
第1句  财官从哪个字透出？根在哪一支？
第2句  落在主位还是宾位？
第3句  财官有几份？有没有被合走、被冲散？
第4句  命主是老板、打工还是皇粮？（三种形态先定性）
```


## 20_5 第5步 · 六亲定位与健康

盲派认六亲**不靠背十神对照表**，而是沿穿害线问：**谁被穿了？他和日主或宫位是什么关系？关系决定身份。**

十神表只告诉你「理论上的关系」，穿害线告诉你「实际发生了什么」。理论归理论，命盘上实际发生的关系才是真相。

### 微实例 · 一线卯辰穿，同时伤三人

```plain
某造：月支卯为乙木日主的建禄位 = 兄弟宫，兼自己的根；与时支辰相穿
    一线卯辰穿，同时伤及三人：
    第1步  兄弟宫受伤        →  兄夭折
    第2步  卯为食神丁的原神  →  原神受损，且穿反翻转性别  →  生男非女
    第3步  卯是自己禄根      →  禄被穿，自身劳碌
```

> 此例三条推断均经现实求证，属实证命例。穿害关系网见板块 5；计数四步法见板块 12；病位双机制见板块 13。

**速查：**

```plain
计数四步：刃禄独立加法 → 透干优先 → 藏干本气补位 → 空亡穿害减损
病位速查：金亢乘木 → 筋骨；水亢克火 → 血压、血液、心血管；火亢无制 → 自灼心血
```

### 易错点

```plain
机械套十神表认六亲
    →  只看「偏财为父」，不看穿害线的实际关系
口诀：穿害线定关系，十神只作辅助定位
```

### 自检问句

```plain
第1句  命盘里有哪几条穿害线？各穿了谁？
第2句  每条穿线对应哪个宫位、哪个六亲？
第3句  有没有一穿多应的情况？
第4句  病位落在哪个五行？受害的脏腑方向是？
```


## 20_6 第6步 · 推虚实与应期

```plain
天干无根无生  =  虚  →  才华、名声、表象
天干有根有生  =  实  →  实际财富、权力根基
```

**虚实的改变本身就是应期：** 喜虚之字通根变实 → 该象落实；喜实之字虚透 → 失去保障。再配三条定律精确定年：**到位、合冲互报、墓库开闭**。

> 虚实原理与三定律见板块 7；墓库开闭见板块 6；串宫压运流年快扫见板块 8。

### 微实例 · 一位老师连中三刀

```plain
坤造：甲午  丙子  乙丑  辛巳
```

| 断语 | 现实反馈 |
| :--- | :--- |
| 婚期：不是 1976 便是 1977 年结婚，77 年底怀孕，怀的是女孩 | 77 年春节结婚，78 年生女 |
| 损胎：伤官处病地，合子息宫辛金绝地；申年胎到，应在庚申 | 1980 年计划生育，打掉儿子 |
| 母病：心血管、妇科疾病有手术之象；2005 年有住院之象 | 05 年住院；09 年血管手术 |

**三断全部落在具体年份。** 应期不是模糊的「某段时间」，而是可以精确到年的。敢锁定 1976 或 1977、敢锁定 1980 庚申、敢锁定 2005，这才是应期的正确姿态。

### 易错点

```plain
只看大运流年冲合，不看虚实转化
    →  冲对了年份却断错吉凶方向
口诀：虚实变则事变现，先定喜忌再定应期
```

### 自检问句

```plain
第1句  哪些是实字、哪些是虚字？（无根无生为虚）
第2句  哪个字要变实？哪个字一变实就出事？
第3句  哪一步大运流年引动了这个变化？
第4句  应期窗口能精确到几年内？给的是区间还是单点？
```


## 20_7 第7步 · 行业与事件取象

把干支组合翻译成生活画面：**这个人做什么行当？事件长什么样？** 铁律只有一条：**单一象不下结论，多象互证才定象。**

火可以代表餐饮，也可以代表电力、互联网、照明——单凭一个火字，什么都能对上，等于什么都没说。

**三种取象各一句：**

```plain
带象：干生支的十二柱，支带有干之象
    例：官杀带财帽（戊申、庚子）= 管钱的官 = 财政银行方向
共象：干支象 + 宫位象 + 十神象，两类以上同指
    例：时上丁火 = 眼睛（丁有目之象 + 时柱孔窍之象 + 食神窍之象）
化象：两象会合生化新象
    例：阴木生火 = 丝线加工 = 织物服装
```

**穿害延伸：** 命局有穿害结构者，父亲行业或可往「穿」「连接」「架构」方向取象（例：钢管脚手架出租工程）。此属象法延伸线索之一，不作铁断。

> 象法四原则见板块 3；行业取象完整示范见板块 10。

### 易错点

```plain
单一象定行业
    →  看到「火」就断餐饮、「金」就断金融，过于武断
口诀：三象共指才定象，单象只作线索
```

### 自检问句

```plain
第1句  我用了几种取象方法？（带象 / 共象 / 化象）
第2句  有没有两类以上的象同指同一结论？
第3句  行业判断有没有反例？命盘上存不存在矛盾线索？
第4句  这个象是「线索」还是「结论」？说出来时有没有加「多主」「之象」？
```


## 20_8 第8步 · 复核与出口纪律

**三条出口铁律：**

```plain
第1步  多点互证
    任何结论至少两条独立推理线指向同一处，单点不下断
第2步  倾向性表述
    说「多主」「之象」「方向」，不说「一定」「必然」
第3步  证据不足宁可不断
    推断可以缺席，错误不能出席
```

前七步是「找答案」，第八步是「检查答案能不能说」。很多失误不是算错，而是算对了但证据只有一条、说得太绝对、或不该说。

### 易错点

```plain
算完就出口，跳过硬纪律
    →  技术判断没错，表述把人吓到或误导
口诀：算对不等于可以说，出口前必过三条铁律
```

### 自检问句

```plain
第1句  我这条结论有几条独立证据？（少于两条就该降格为线索）
第2句  有没有用「多主」「之象」「方向」这类倾向表述？
第3句  有没有哪条推断证据不足，应该删掉不说？
第4句  有没有越界到医疗、生死等不该下断的地方？
```


## 20_9 全盘实战示范：五断全验的一造

这是第8步的活教材——**每一断都有技法出处，每一条都经现实检验。**

学的人不应该只记结论，更应该记住**每一条推断是从哪条技法推出来的**。

### 盘面

```plain
坤造：甲午  丙子  乙丑  辛巳
```

| 层次 | 年柱 | 月柱 | 日柱 | 时柱 |
| :--- | :--- | :--- | :--- | :--- |
| 天干 | 甲 | 丙 | 乙 ★ | 辛 |
| 地支 | 午 | 子 | 丑 | 巳 |
| 藏干 | 丁 己 | 癸 | 己 癸 辛 | 丙 戊 庚 |

```plain
乙木生子月  →  寒木喜火
时透辛杀坐巳，年透甲劫
    ↓
气势与做功方向已在盘面点出：食伤制杀
```

盲派老师不另排强弱格局，五断集中在家庭六亲、虚实病位、应期窗口三段。

### 五断逐条拆解

**断一 · 定六亲星**

```plain
七杀当父看
    时干辛杀虚透  →  主名气
    月干丙坐巳中本气，丙辛一合，父母宫见丙
        ↓
    断：父亲有名气
```

**断二 · 数量象法**

```plain
兄弟姐妹三四个，排行第三
（以区间形式给出，恰含实际人数）
```

**断三 · 子女宫查病地**

```plain
伤官处在病地，合到子息宫辛金绝地  →  有损儿之象
申年胎到  →  应在 1980 庚申
```

**断四 · 婚期窗口**

```plain
不是 1976 便是 1977 年结婚
1977 年底怀孕，怀的是女孩
```

**断五 · 母星病位**

```plain
母亲身体不好
    心血管或妇科方面疾病，有手术之象
    2005 年有住院之象
```

### 五断对照表

| 盲派老师断语 | 现实反馈 | 判定 |
| :--- | :--- | :--- |
| 兄弟姐妹三四个，排第三 | 四个，排老三：上有哥姐下有弟 | 命中 |
| 七杀虚透逢丙辛合，父有名气 | 父亲是当地有名的医生 | 命中 |
| 伤官病地合绝地，1980 庚申年损胎 | 1980 年计划生育，打掉儿子 | 命中 |
| 76 或 77 结婚，77 年底怀女 | 77 年春节结婚，78 年生女 | 命中 |
| 母身体不好——心血管或妇科疾病有手术之象，2005 住院之象 | 05 年住院；09 年血管手术，子宫肿瘤待手术 | 命中 |

### 三点启示

**启示一 · 数量断语用区间：** 「兄弟姐妹三四个」实际是四个——以区间形式给出，恰含实际人数，这是数量类断语的正确姿态。

**启示二 · 应期可以精确到年：** 婚期 76 或 77（两年候选留余地），损胎 1980 庚申（精确到年），母病 2005 住院（精确到年）。

**启示三 · 五断都有技法出处：**

## 20_10 八步流程速查卡

```plain

第3步  定向：体制了哪个用？什么手段？制得干净吗？扛得住吗？
第4步  找落点：财官在家里还是家外？几个人分？
第5步  认人：沿穿害线找六亲；数量用计数四步；病位看受害五行

第7步  取象：带象、共象、化象；多象互证才定象
第8步  出口：两点互证；说「多主」「之象」；没把握就不断
```
