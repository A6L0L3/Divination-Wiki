## 板块10 · 财富与职业取象

> 本板块把「制财」翻译成**具体行业**和**财富量级**。
> 核心两问：**财是虚是实（定级别）？这组做功像什么（定行业）？**
> 应期落点统一交板块 7 处理。

### 10_1 财富级别：三道分水岭

盲派判断财富量级不看「财星喜不喜」，而看**财的虚实、财库的开闭、做功的持续性**这三道关口。

#### 10_1_1 第一道：财的虚实

```plain
财星虚透  →  名气、小财、面子工程
财星落实  →  大财、实业（不动产、股权、实物资产）
虚神得地则实：虚财在岁运得根可转实，量级跳一档
实财失根则降级：大运流年被冲克、合走、化泄无根时，量级回落一档
```

#### 10_1_2 第二道：财库开闭

```plain
财库开则发  财库闭则滞
开库检查三步（见板块 6）：
第1步 有没有刑冲（原局或岁运）？
第2步 库有没有被合住 / 被盖头（闭库）？
第3步 库里藏的是喜是忌？（库开而藏忌，开库之年反而破财，此步不能省）
全部通过才算开库。
```

#### 10_1_3 第三道：做功效率与持续性

```plain
效率：财制印、食伤生财、比劫去财 → 皆为富
      排序：合制 > 双制 > 穿制 > 遥隔无功
持续：原局有功＝久功（抗周期）  岁运之功＝暂功（运过则止）
效率回答「一次赚多少」，持续性回答「能留多久」——区分「实业家」与「暴发户」的关键。
```

#### 10_1_4 财富级别判断表

| 检查项 | 高量级 | 低量级 |
| :--- | :--- | :--- |
| 财的虚实 | 落实（有根） | 虚透（无根） |
| 财库 | 开（三步全过） | 闭（被合 / 盖头） |
| 做功效率 | 合制、双制 | 穿制、遥隔 |
| 力量对比 | 制方明显占优 | 双方接近 |
| 持续性 | 原局有功（久功） | 仅岁运之功（暂功） |
| 结构形态 | 串联、无废功 | 相悖、有功反被破 |

#### 10_1_5 四种典型的富命结构

```plain
第1步 比劫制财      →  劳碌发财（出力气、靠团队）
第2步 食伤生财      →  经商、技术求财
第3步 财制印        →  房地产、财务、审计
第4步 财库冲开      →  开库之富（往往大财）
四种结构可叠加；「劳碌」不可省；富命也有破财运，量级只说常态。
```

### 10_2 比劫制财做功的双面性

「比劫制财」最容易被误判——它可以是发财，也可以是破耗，差别全在日主扛不扛得住。

#### 10_2_1 双面性对照

| 日主状态 | 比劫与财的关系 | 现实表现 |
| :--- | :--- | :--- |
| 身强（扛得住） | 做功得财 | 劳碌奔波，凭本事挣辛苦钱；逢比劫得地之运反主进财；合伙分利 |
| 身弱（扛不住） | 做功破局 | 钱财经手难积存；财被分薄、为他人作嫁；逢比劫得地之运更凶 |

#### 10_2_2 正反面判别次序（先看力量，后论喜忌）

```plain
第1步  数比劫（含禄、刃）的票数，看是否成党
第2步  看日主有没有根、有没有印生
第3步  判身强身弱（能否扛住对峙）
第4步  才论喜忌（决定赚了舒不舒服，不是能不能赚）
第5步  看大运比劫是否得地（身强→进财，身弱→更凶）
次序不能颠倒，颠倒后最常见错误就是「一见比劫就说夺财破财」。
```

#### 10_2_3 正面路径（合伙得财、身强制得住）

**成立条件（须同时满足）：**

```plain
条件一  比劫成党（两柱以上，或坐禄＋透干）
条件二  日主有根有生，气足
条件三  财星有根可制
条件四  制方明显占优
正面结果：合伙得财、团队分利、规模取胜。比劫是「帮手」不是「分财者」。但「劳碌」不可省。
```

#### 10_2_4 反面路径（财被分薄、身弱制不住）

**成立条件（任一即转反）：**

```plain
条件一  比劫不成党（单禄、单透）
条件二  日主无根、无生，气弱
条件三  财星太旺而制方势薄
条件四  岁运再逢比劫得地
反面结果：财被分薄、为他人作嫁、财来财去、求财越勤越散。比劫从「帮手」变成「分财者」。
```

#### 10_2_5 两个实战案例对照

**案例A · 比劫成党制得住财**

```plain
庚金日主
    年月庚辛双透、又坐申禄
        ↓
    三重金党围攻寅卯木财星
现实：开门店卖装修材料
      发财命，但赚钱辛苦、走动多
```

**案例B · 单禄势薄制财劳碌**

```plain
壬水日主
    年支亥禄去制时柱午火财星
现实：凭本事挣辛苦钱
      从辽宁远赴深圳打工，走动多年，积蓄有限
两造对比：案例A 三重金党+坐禄→扛得住→发财（但辛苦）
          案例B 单禄势薄→勉强制→劳碌（难积存）
```

#### 10_2_6 示意盘例（反面路径）

**案例C · 身弱比劫得地，财被分薄**

```plain
乾造（示意盘例）：甲戌  乙亥  丁丑  庚戌
    丁火生于亥月，水旺火弱；甲乙木浮无根
    戌、丑、戌皆湿土泄火；庚金偏财虚透无根
大运：丙子  丁丑  戊寅  己卯
    戊寅、己卯木得地，比劫成党
        → 看似帮身，实则分财
反馈（示意）：合伙做建材，投入大、回款慢，
        利润被合伙人分走大半；自己跑业务最勤，到手有限。
推理链：
第1步  丁火生亥月，水旺火弱无根 → 身弱
第2步  庚金偏财虚透无根 → 财星虚，无可制之厚财
第3步  甲乙木浮无根，不成党 → 制方势薄
第4步  身弱＋势薄 → 反面路径 → 财被分薄、为他人作嫁
第5步  比劫得地之运 → 分财者又来，财来财去
```

**可复用规则：** 身弱比劫得地之年不是进财年，而是「分财者到位」年，务必反看；若再逢财星虚透，则薄利甚至白忙。**本造为示意设计，用于说明反面路径，不与真实命例混用。**

#### 10_2_7 核心判断（与板块 4_4 误区二互补）

```plain
看到「比劫制财」→ 先判：日主能否扛住这场对峙？
扛得住（身强、成党、有根有生）→ 做功得财（劳碌发财、合伙分利）
扛不住（身弱、不成党、无根无生）→ 被财所困（破耗、财被分薄、财来财去）
反直觉：同一句「比劫得地」吉凶相反——身强时帮手到位→进财；身弱时分财者来了→更凶。
```

### 10_3 职业定位口诀

口诀是入口，不是结论——**行业靠「象 + 势」结合**。

#### 10_3_1 七条定位口诀

```plain
杀印相生  宜武职（军警、司法、安保）
官印相生  宜文职（行政、管理、公务员）
食伤生财  宜经商（贸易、销售、创业）
伤官配印  宜技艺（设计、研发、技术专家）
财制印    主房产 / 财务（地产、审计）
印制食伤  主教育 / 文化（教师、学术）
比劫去财  主团队 / 中介（合伙、承包）
禄神当财  主体力 / 俸禄（技术工种、自由职业）
口诀读法：前面是「结构」，后面是「功能」。行业＝结构×功能×五行，口诀只完成前两步。
```

#### 10_3_2 结构与五行的交叉表

| 结构 | 五行 | 行业方向 |
| :--- | :--- | :--- |
| 食伤生财 | 火 → 土 | 能源、地产、餐饮 |
| 食伤生财 | 水 → 木 | 物流、贸易、种植 |
| 食伤生财 | 金 → 水 | 金融、贸易、咨询 |
| 比劫去财 | 金 / 水 | 五金机械 / 物流劳务中介 |
| 印制食伤 | 木 | 教育、文化、学术 |
| 财制印 | 土 | 房产、建筑、物业 |
| 禄神当财 | 金 | 技术工种、自由职业 |

### 10_4 行业象法：从结构到具体形态

#### 10_4_1 取象三步法

```plain
第1步  定做功结构（谁制谁）
第2步  提取结构特征 + 转成五行物象
第3步  共象校验（至少两层同指，见板块 3）
```

#### 10_4_2 结构特征与行业对应

| 结构特征 | 动作象 | 行业方向 |
| :--- | :--- | :--- |
| 冲 | 动、运输、奔波 | 物流、运输、出差型工作 |
| 穿 | 连接、架构、暗中穿行 | 建筑架构、连接件、管道 |
| 合 | 合作、捆绑、撮合 | 合伙、中介、渠道代理 |
| 库 | 收藏、存储、积蓄 | 仓储、金融、典当 |
| 刑 | 纠缠、打磨、反复 | 精密加工、法律、调解 |

#### 10_4_3 拱象定行业

```plain
地支半合（拱）出的象，可直接回答「做什么工作」
    申子拱 ＝ 执法、金融之象（金＝刚硬规则司法，水＝流通钱财）
    寅午拱 ＝ 能源、文化、餐饮之象
    亥卯拱 ＝ 文教、木作、种植之象
拱象法不依赖做功结构，做功不明显时可用拱象救场。
```

| 造 | 现实 | 取象 |
| :--- | :--- | :--- |
| 坤 戊申 甲子 丁丑 辛亥 | 银行职员 | 申子半合，金水主钱币流通 |

#### 10_5_2 驿马的特殊象

```plain
驿马逢冲  →  跌倒、出行、奔波

官带驿马  →  升迁、调动
印带驿马  →  外出求学
「财带驿马」主跑出来的钱，实务中常对应「靠车吃饭」：物流司机、销售跑区、跨区域采购。
```

### 10_7 盘例二：金火交铸的钢铁象

#### 10_7_1 盘面

```plain
乾造：甲辰  丁卯  庚申  庚辰
大运：戊辰  己巳  庚午  辛未
现实反馈：钢厂技术骨干，中层管理
```

#### 10_7_2 推理链与结构拆解

```plain
庚金（金）+ 丁火（火）
    ↓ 金火交炼 → 钢铁
    ↓ 庚申坐禄（技术、动手）→ 钢厂技术骨干
    ↓ 杀刃平衡（管理）→ 中层管理

结构拆解：
羊刃驾杀：申金禄神做功，辰土湿土生身（力量有源）
金被火炼：庚申坐禄 + 卯财生丁杀 → 钢铁象
丁火正官合身、庚金自坐禄 → 技术岗而非纯管理
```

### 10_8 盘例三：多象叠加定出的具体科室

#### 10_8_1 盘面

```plain
坤造：戊午  甲寅  壬辰  辛亥
大运：癸丑  壬子  辛亥  庚戌
现实反馈：妇产科医生，副主任医师
```

#### 10_8_2 三层取象

```plain
第1层  辰为水库  →  血室、阴户（干支物象 + 宫位）
第2层  寅午合火  →  孕育（火主生发）
第3层  食神制杀  →  医技（技术制服病邪）
三层同指  →  妇产科
```

#### 10_8_3 取象精细度与象层数

| 收敛层数 | 可断粒度 | 示例 |
| :--- | :--- | :--- |
| 一层 | 大类 | 医疗 |
| 两层 | 方向 | 外科 / 妇科 |
| 三层 | 细分 | 妇产科 |
| 四层以上 | 具体岗位 | 妇产科副主任医师 |

#### 10_8_4 可复用规则

```plain
规则：取象的精细度 = 收敛到同一点的象的层数
    一层→大类  两层→方向  三层→细分
纪律：
  ✓ 每层象都要能独立成立，不互相「抄答案」
  ✓ 三层同指也仍用倾向性表述
  ✗ 不为了凑层数硬拉象
```

### 10_9 盘例四：几个职业象的速查示范

### 10_11 盘例：体弱多病与贫困的反向印证

#### 10_11_1 盘面

```plain
乾造：壬寅  辛亥  丙子  己亥
大运：壬子  癸丑  甲寅  乙卯
现实反馈：体弱多病，贫困
```

#### 10_11_2 推理链

```plain
官杀攻身：壬水七杀透干，亥子水势滔天 → 水多火熄
印星无力：无木生扶（寅被亥合）→ 丙火无依
做功无功：无制财、无生财结构 → 求财无门、无路径
「水多火熄，气浊神枯」——冬火微弱，无木生扶，主贫病。
```

#### 10_11_3 可复用规则

```plain
规则：官杀攻身无制 + 印星无力 + 无求财路径 → 主贫病
判断清单：
  □ 官杀有没有被制化？
  □ 印星有没有力、有没有被坏？
  □ 日主有没有根？
  □ 调候用神有没有？（冬火喜木）
  □ 原局有没有制财、生财的做功？
纪律：
  ✓ 说「身体与事业都需要更多积累」
  ✗ 不说「你一辈子穷」
```

### 10_12 现代职业引申（时代转换）

同一组象，古代是打铁，现代可能是电焊。**时代转换的关键是抓「功能」不抓「物件」。**

#### 10_12_1 时代转换的核心口径

```plain
功能 ＝ 这个象在「做什么事」
物件 ＝ 这个功能在古代 / 现代分别叫什么
例：金火交炼
    古代：用火加工金属 → 打铁
    现代：仍用火加工金属 → 钢铁、机械、电焊
    结论：功能不变，物件升级
例：水木相生 → 古代舟船 → 现代物流、快递、航运
例：印制食伤 → 古代私塾先生 → 现代教师、编辑、内容审核
一句话：物件会过时，功能不过时。
```

| :--- | :--- | :--- |

| 金火交炼 | 打铁、铸铜 | 钢铁、机械、电焊、五金、冶金 |

#### 10_12_3 现代新兴行业的取象思路

```plain
网络、电子、互联网  →  火（电子）+ 水（流动、虚拟）
金融、投资          →  金（金融）+ 水（流通）
咨询、中介          →  水（信息）+ 合（撮合）
自媒体、创作        →  食伤（表达）+ 火（传播）
物流、快递          →  水（流动）+ 驿马
直播、电商           →  火（传播）+ 财（交易）
新能源、环保        →  木（生发）+ 火（能源）
人工智能、数据       →  金（逻辑）+ 水（信息流）
方法：把新兴行业拆成「功能模块」再配五行。直播＝传播（火）＋交易（财），AI＝逻辑计算（金）＋信息流（水）。
```

### 10_13 财富职业的完整判断流程

这一节只负责「量级＋行业」，**应期交板块 7 处理**。

```plain
第1步  定财星：有没有？虚还是实？
第2步  定做功：谁在制财？什么方式？效率多高？
第3步  定库：有没有财库？开还是闭？
第4步  定持续性：原局有功还是仅岁运之功？
第5步  取行业象：结构特征 + 五行物象 + 共象校验
第6步  时代转换：古代象 → 抓功能 → 现代职业
第7步  定级别：综合虚实、开闭、效率、持续性
第8步  查应期：应期推演统一见板块 7
第9步  出口：倾向性表述
静态结论＋应期才是完整判断。
```

#### 10_13_1 出口的措辞示范

```plain
正确  「这个结构适合在走动、连接的行业里求财，物流、贸易这类方向值得留意」
正确  「财星落实且有库，倾向于实业积累而非虚名」
正确  「比劫制财求财要靠出力、靠团队，留意分成比例」
错误  「你一定是做物流的」
错误  「你有几千万资产」
错误  「你比劫夺财，肯定破财」
```

**▲实操**：拿一张陌生盘，按「财富职业的完整判断流程」的步骤完整走一遍，把每一步的判断依据写下来；卡住的那一步就是没学会的地方。
