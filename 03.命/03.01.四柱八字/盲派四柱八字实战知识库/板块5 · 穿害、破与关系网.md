# 板块5 · 穿害、破与关系网
> 穿害是盲派关系网技法的核心，回答：**这条暗线串起了哪个六亲、哪件事。**

## 5_1 穿害基础：六组与性质
### 六组穿害（必背）
```plain
子未    丑午    寅巳
卯辰    申亥    酉戌
```

### 穿害的核心性质
**穿 = 暗中伤害、扭曲、变形。**

| 作用 | 性质 | 典型象 |
| :--- | :--- | :--- |
| 冲 | 正面、激烈、突发 | 变动、分离、急性事件 |
| 穿 | 暗中、扭曲、持续 | 慢性病、暗疾、关系别扭 |
| 破 | 破坏、不完整 | 破损、瑕疵、先好后坏 |

### 穿害的四种典型后果
```plain
穿倒羊刃 / 禄神  →  大灾、手术、牢狱、死亡
                   口诀：「穿倒正印归西去」
穿坏夫妻宫      →  婚变、丧偶、感情痛苦
穿坏财官        →  破财、丢官、事业受损
穿害本身        →  扭曲、变形、暗中伤害
```

### 穿的效率（回顾板块 2 效率表）
| 穿害组 | 效率 | 备注 |
| :--- | :--- | :--- |
| 丑午、子未 | 50% 偏高 | 效率高，后果重 |
| 卯辰、酉戌 | 30% | 象法意义大于做功意义 |
| 寅巳、申亥 | 生多穿少 | 一般不算做功 |

寅巳、申亥「生多穿少」，既有相生又有穿害，一般按相生论，只在特定条件下论穿。

### 五行象义补充
```plain
卯辰穿  =  木土相战  →  脾胃方向、肢体伤残
申亥穿  =  金水相生却带害  →  聪明反被聪明误
```


## 5_2 穿线定六亲
### 核心方法
**不机械套用十神六亲，而是沿着穿害线找身份。**

```plain
第1步 谁被穿了？
第2步 被穿的这个字与日主是什么关系？
第3步 它在哪个宫位？
```

十神六亲是静态映射，沿穿线走找到的是**真正在发生作用的那条关系**。

### 经典一线：卯辰穿
```plain
卯  =  日主之禄  →  代母亲
辰  =  财        →  代父亲
卯辰相穿  →  一条线同时伤及父母宫与父母星
```

**这就是「一线多断」：** 一条穿害线同时给出两条信息（父母宫受损 + 父母星受损）。

### 穿害定六亲生死
穿害不仅能定六亲的**身份与关系**，还可推其**生死大限**——这是最深也最容易失手的一层。

```plain
穿害关系网 + 实主位反局
        ↓
    六亲生死大限的倾向性判断
```

**成立前提（缺一不可）：**

```plain
第1步  被穿的是六亲星，且穿的力度足够强
第2步  叠加实主位反局（见 5_6）
第3步  无解救（无合、无生扶）
```

**典型结构：卯辰穿的一线三断**

```plain
某造：月支卯为乙木日主的建禄位
        =  兄弟宫 + 自己的根
      与时支辰相穿

    一条卯辰穿，同时推出三事：
    第1步  兄弟宫受伤  →  兄夭折
    第2步  卯为食神丁的原神，原神受损
        且穿反翻转性别  →  应男非女
    第3步  卯为自己禄根  →  禄被穿，自身劳碌
```

> 此例三条推断均经现实求证，属实证命例。

### 定六亲的三步操作
```plain
第1步  找出命局里所有的穿害线
第2步  对每条线，问「被穿的字代表谁」
       （十神 + 宫位 + 禄/原身三重定位）
第3步  判断这条线的落点（伤在哪个人、哪件事上）
```

同一个被穿的字在不同命局里落点可能完全不同——可能是六亲、可能是自己、可能是事业。落点要看全局势力对比（见 5_6）。


## 5_3 连体取象
### 定义
**星与其坐支形同连体：坐支是这颗星的原神或根基。**

```plain
核心推论：伤其座 = 伤其人
```

因为坐支是这颗星的「根」，根被伤，星就站不住。

### 经典示例
```plain
财星戊土坐巳火
    ↓
巳为戊的原神（火生土）
    ↓
原局见寅木穿巳
    ↓
穿伤财星之座（巳）
    ↓
直指：父亲或妻子根基受损
```

### 连体取象的检查清单
```plain
□ 这颗星的坐支是什么？
□ 坐支是不是它的原神 / 根基？（查生克关系）
□ 这个坐支有没有被穿、被冲？
□ 被谁穿 / 冲？穿方的力量够不够？
□ 被伤的这颗星代表谁？
□ 有没有解救（有没有别的字生扶它）？
```

### 连体取象 vs 直接取象
```plain
直接取象：财星被克  →  财上出问题
连体取象：财星的坐支（原神）被穿  →  财的根基被毁
                                  →  更深层、更严重
```

只看到「星被克」而没看到「根被穿」，会严重低估事情的程度。


## 5_4 穿定病灶方向
### 基本方法
**以穿害双方的五行判断病灶所属系统的方向。**

```plain
木受穿  →  多留意肝胆系统养护之象
火受穿  →  心脑血管方向
土受穿  →  脾胃方向
金受穿  →  肺、呼吸道方向
水受穿  →  肾、泌尿方向
```

### 两个取象维度的区分（易混，必看）
脏腑五行对应（本节）与体象结构（板块 13_1）分属不同层面，指向不同关注方向，可共存不冲突。

### 表达纪律（重要）
```plain
属传统文化象法参考，不构成任何医疗建议
正确  「这个方向建议留意，可以做个检查」
错误  「你肝有病」
```

涉及健康的推断，给方向、不给诊断。

### 穿与冲在疾病上的区别
```plain
穿  →  慢性病、暗疾、长期损耗
冲  →  急性病、外伤、突发
```

板块 13 会在此基础上展开完整疾病判断流程。

### 穿定病灶方向的判断次序
```plain
第1步  定穿方与被穿方（明确「谁穿谁」）
第2步  定被穿方五行所属系统（查藏干，落到对应系统）
第3步  看穿的力度与性质（轻 = 方向性提示；重 + 无解救 = 需重点留意）
第4步  查全局同五行是否有第二处受损（有 → 可信度上升）
第5步  与体象结构交叉（见板块 13_1）：指向一致只增强倾向，不叠加成「确诊」
第6步  输出方式固定为倾向性提示，只说「建议留意」，不给诊断
```

第 1、2 步定方向，第 3、4 步定强度，第 5 步做交叉，第 6 步定口径。跳步的结果通常是「看到穿就报器官」。

### 穿与破在取象上的差异
穿与破都属「非正面作用」，但取象层次不同，不能混用：

| 对比项 | 穿 | 破 |
| :--- | :--- | :--- |
| 来源 | 来自外部的暗中作用 | 来自内部的不完整 |
| 性质 | 扭曲、变形、慢性损耗 | 破损、先好后坏 |
| 疾病取象 | 有，按五行定方向 | 一般不定方向，只主缺陷 |
| 人事取象 | 关系别扭、暗疾式损耗 | 事情有瑕疵、先成后败 |
| 做功意义 | 丑午、子未效率高，可算做功 | 一般不算做功 |

**一句话区分：** 穿是「外面有人暗着使力」，破是「里面自己就不完整」。


## 5_5 穿反技法
### 定义
**穿的力量足够强时，六亲的性别、长幼属性可能被翻转。**

```plain
例：食神本主女儿
    穿反 → 翻作儿子之象
```

### 触发条件（严格）
```plain
条件：触发条件精细，必须多重证据齐备才可采用

具体要求：
    ✓ 穿的力量确实足够强
    ✓ 有多条独立证据支持翻转后的结论
    ✓ 翻转后的解释能通盘说得通
```

穿反误用代价大：一次误断会摧毁整套判断的可信度。

### 穿反的使用流程
```plain
第1步  确认穿的力量足够强（力量对比明显）
第2步  列出被穿之字的本来属性（性别、长幼）
第3步  尝试翻转，看能否得到更合理的解释
第4步  收集至少两条独立证据支持翻转
第5步  证据不足 → 不翻，按本来属性断
```

### 穿反技法的误用警示与自查清单
以下六条是高频误用，逐条自查：

```plain
误用一  力量不足就翻        →  先量化力量对比，差距不明显就停
误用二  单一证据就翻        →  没有第二条独立证据就按本来属性断
误用三  用翻转结果反推成立  →  翻转须是象法上的必要性，非表述需要
误用四  翻转后不做通盘校验  →  重新走一遍全局势力对比，通盘要说得通
误用五  把穿反当常规手段    →  先按常规断，翻转是最后一层，不是第一层
误用六  铁断性别长幼        →  一律倾向性表述，保留余地
```

六条全过才敢用；任一条不过，就按本来属性断。


## 5_6 实主位反局
### 定义
**单一的穿害未必成灾；叠加天干之克、且日时主位的党羽对立成反局时，灾害才会放大。**

### 三个放大条件
```plain
条件一  单一的穿害  →  未必成灾
条件二  叠加天干之克  →  灾力增强
条件三  日时主位党羽对立成反局  →  灾害放大
```

### 灾害落点会转移
```plain
全局势力对比变化时，灾害的落点会转移：
    可能从六亲转向自身，也可能反向
```

**判断方法：**

```plain
第1步  看主位（日时）的力量够不够（有没有根、有没有党）
第2步  主位力强  →  灾落六亲（自己扛得住，冲击转到别人身上）
第3步  主位力弱或成反局  →  灾落自身（自己扛不住）
```

### 表达纪律
```plain
涉及重大事项的推断必须证据链完整，并以倾向性表述呈现
绝不绝对化
```


## 5_7 地支破：不完整与内部矛盾
### 常见破组
```plain
子卯破、卯午破等
```

### 破的性质
```plain
破  =  破坏、不完整、先好后坏、内部矛盾
```

**与穿的区别：**

```plain
穿  =  来自外部的、暗中的伤害
破  =  内部的、自身的不完整
```

### 破的典型象
| 象 | 含义 |
| :--- | :--- |
| 破损 | 事情有瑕疵、不圆满 |
| 先好后坏 | 开始时顺利，后来出问题 |
| 内部矛盾 | 关系内部有裂痕，不是外部打击 |


## 5_8 盘例：卯辰穿的「一线三断」
穿害技法最经典的完整推理链示范——一条穿线同时给出三条推断。

### 结构
```plain
某造（乙木日主）
    月支卯  =  乙木日主的建禄位
    时支辰
    卯辰相穿
```

### 卯的多重身份
```plain
身份一  卯是月支        →  兄弟宫
身份二  卯是乙木的禄    →  自己的根
身份三  卯是食神丁火的原神  →  丁的原神
```

一个字三重身份——这是穿害能「一线多断」的原因。

### 三条推断的推理链
```plain
【推断一】兄弟宫受损 → 兄夭折
    卯为兄弟宫（月支），卯被辰穿 → 兄弟宫受损

【推断二】原神受损 + 穿反 → 应男非女
    卯为食神丁火的原神，原神受损
    穿反翻转性别（食神本主女儿 → 翻作儿子）

【推断三】自身劳碌
    卯为自己禄根，禄被穿 → 自身劳碌
```

### 结构图
```plain
                    ┌──→ 兄弟宫受损 ──→ 兄夭折
                    │
    卯（被辰穿）───┼──→ 丁火原神受损 + 穿反 ──→ 应男非女
                    │
                    └──→ 自己禄根被穿 ──→ 自身劳碌
```

### 可复用规则
```plain
规则：一条穿害线可以同时断多个六亲 / 多件事
操作要点：
  ✓ 先列出被穿之字的所有身份（十神、宫位、禄/原神）
  ✓ 每个身份对应一条推断
  ✓ 逐条检查证据是否充分
  ✓ 证据不足的那条宁可不断
纪律：此类重型推断实战中仍须证据链完整方可出口
```


## 5_9 本板块落地清单
```plain
□ 能背出六组穿害（子未、丑午、寅巳、卯辰、申亥、酉戌）
□ 能区分冲 / 穿 / 破三者的性质差异
□ 能说出穿与破的取象差异（外源性 vs 内部不完整）
□ 会沿穿线定六亲（三步操作）
□ 理解连体取象：伤其座 = 伤其人
□ 会按判断次序走穿定病灶方向（六步）
□ 知道穿定病灶的脏腑与体象两层面不冲突（详述见板块 13_1）
□ 知道穿反的严格条件，并按六条自查清单逐项过
□ 能判断灾害落点（主位力强落六亲、主位弱落自身）

```

## 5_10 笔记作业
**作业一：做一次穿定病灶方向的完整推演。** 找一个带穿的盘，按 5_4 的六步次序走一遍，记录「穿方 / 被穿方 → 被穿方五行所属系统 → 穿的力度 → 全局同五行第二处受损与否 → 与体象层面是否交叉 → 倾向性表述」，最后对照板块 13 的脏腑取象表看口径是否一致。

**作业二：做一次穿反误用自查。** 找三条自己或他人「翻转性别 / 长幼」的推断，逐条过 5_5 的六条误用清单，标出哪几条未通过。未通过的那条一律改为按本来属性断，并记录改后的结论与原有结论的差异。

**作业三：做一次穿线定六亲的三步操作。** 对一个已知盘找出全部穿害线，逐条列出被穿之字的三重身份（十神 / 宫位 / 禄·原神），判断落点，检查有无解救，最后用已知反馈校准。

**作业四：整理一条「一线多断」笔记。** 模仿 5_8 的结构图，把自己处理过的最复杂的一条穿害线画成树状，确保一个身份只对应一条推断、证据不足的分支明确标注「不断」。
