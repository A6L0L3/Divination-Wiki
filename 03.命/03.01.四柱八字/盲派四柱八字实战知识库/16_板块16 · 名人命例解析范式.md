## 板块16 · 名人命例解析范式

> 名人命例的价值在于**反馈完整、时间线清晰**，可看推理链如何走完。
> 统一范式：定势 → 定病 → 定药 → 看运 → 验应 → 提启示。
> 表达纪律：涉及已故人物与健康议题，仅作结构与取象层面分析，不作绝对化断言、不构成医疗结论。

### 16_1 解析范式：六步拆解法

顺序不能颠倒：先定势，再定病，再定药，然后看运、验应、提启示。

```plain
第1步  定势  →  哪一行在命局里最强（得令、得地、得党）
第2步  定病  →  失衡点在哪（过剩的、为害的）
第3步  定药  →  有没有字能制化它
第4步  看运  →  岁运是助病还是助药
第5步  验应  →  对照已知事实，看推断与事实是否吻合
第6步  提启示  →  抽象出可复用的规则
```

**第 5 步是名人命例独有的优势：** 名人的人生节点公开且相对确定，普通命例的反馈往往模糊、不完整。

**第 6 步最容易漏。** 只有抽象成可复用的规则，案例才真正变成工具。

### 16_2 袁世凯：官禄格与病药说

定势—定病—定药三段式最清晰：火土成势是势，金水为病，食神制杀、燥土脆金为药。

#### 16_2_1 命造

```plain
乾造：己未  癸酉  丁巳  丁未
```

#### 16_2_2 六步拆解

#### 16_2_3 第 1 步 · 定势

```plain
丁火日主
    坐巳（归禄）
    时支未（火之余气）
    年干己、年支未
→  丁火归禄得势（火土成势）
```
**依据：** 得令（巳火当位）、得地（坐禄）、得党（未土火之余气，己未土）。

#### 16_2_4 第 2 步 · 定病

```plain
以金水为病
    月支酉金（财）、月干癸水（杀）
    金水在火土旺局里是被制一方
    但酉金当令之月，金水有力量，构成对峙
```
**病不在「有金水」，而在「金水有力量但被火土包围」。**

#### 16_2_5 第 3 步 · 定药

```plain
局中食神制杀、燥土脆金为药
    食神（土）制癸水（杀）
    燥土（未）脆酉金
→  有药可去病，即「贵在去病」的标准结构
```

#### 16_2_6 第 4 步 · 看运

| 大运 | 作用 | 病 / 药 | 应事 |
| :--- | :--- | :--- | :--- |
| 戊辰 | 晦火生金 | 助病 | 罢官 |
| 丁卯 | 禄到制金 | 助药 | 当选总统 |
| 丙辰 | 夺光晦火 | 助病 | 忧愤而终 |

**同一命局，三段运走出三个节点——「原局定层次、岁运定应期」的直观演示。**

#### 16_2_7 第 5 步 · 验应

三段运的推断与公开史料相吻合，可作为推理链有效性的实证。

#### 16_2_8 第 6 步 · 启示

```plain
伟人皆有势，贵在去病
```
**成就不来自平衡，来自把势里的「病」去掉。**

#### 16_2_9 可复用规则

```plain
规则：得势之命，看「病」有没有药、运有没有助药
操作：
    第1步 定势（哪一行最强）
    第2步 定病（哪一行是失衡点）
    第3步 定药（谁能制化它）
    第4步 运助药 = 上升期；运助病 = 低谷期
纪律：不铁断具体职位，只说「权柄之象」与起落节奏
```

### 16_3 希腊船王：禄神怕财星坏

上一例看病有没有药，这一例看「禄怕什么」——根受损不靠病药链条，靠根本身的稳定性。

#### 16_3_1 命造

```plain
乾造：乙巳  己丑  己未  庚午
```

#### 16_3_2 六步拆解

#### 16_3_3 第 1 步 · 定势

```plain
己土日主
    年支巳（火）、月支丑、日支未（土）
    时支午（火）
→  火土成势
```

#### 16_3_4 第 2 步 · 定病

```plain
火土成势，制金水
    时干庚金（伤官）、水（财）藏在丑中
→  以金水为病
```

#### 16_3_5 第 3 步 · 定药

```plain
火土本身即是药（火土成势制金水）
→  巨富之象
```

#### 16_3_6 第 4 步 · 看运

```plain
壬午运  →  时支午火为禄，大运午火 = 禄神复吟（重见）
    →  「禄走了」
```
**「禄走了」是禄神复吟的取象。** 禄为命根，一份足够，两份反成重见之象。

#### 16_3_7 第 5 步 · 验应

```plain
壬午运期间：丧子，自身亦亡故
```
**公开史料记载其于壬午运对应年份去世、期间经历丧子。** 「禄神复吟」与「财星坏禄」两条同时出现，对应自身与子女两个方向。

#### 16_3_8 第 6 步 · 启示

```plain
禄神为命根
    最怕复吟（重见）
    最怕财星来坏
```
**禄被财坏是「根基被资源反噬」。**

#### 16_3_9 以禄当财的禁忌（关联板块 9）

```plain
当命局以禄当财时：
    禄不可受损  →  禄破则寿夭或贫
    禄怕财星来坏  →  财坏禄主因财致祸
```
**本案正是「禄怕财坏」的例证：** 壬水（财）在大运出现，与午火（禄）形成水克火。

#### 16_3_10 可复用规则

```plain
规则：禄神重见（伏吟）主寿终，尤其在老年运
操作：
    第1步 找出命局的禄在哪
    第2步 查大运 / 流年有没有重复出现
    第3步 查有没有财星来坏禄
    第4步 两条同时出现 → 高度警惕
纪律：生死类推断必须多条证据，倾向性表述
```

### 16_4 阎锡山：旺忌弱制

前两例的病都有药去制，这一例的七杀太旺制不住：**忌神太旺不可强攻，只能智取。**

#### 16_4_1 命造

```plain
乾造：癸未  辛酉  乙酉  丁丑
```

#### 16_4_2 六步拆解

#### 16_4_3 第 1 步 · 定势

```plain
乙木日主
    月支酉金（当令）、日支酉金
    月干辛金
→  秋木，金旺（七杀极旺）
```

#### 16_4_4 第 2 步 · 定病

```plain
七杀（金）过旺为病
    乙木生于酉月，金当令
    双酉 + 辛透  →  众杀攻身
```

#### 16_4_5 第 3 步 · 定药

```plain
用丁火食神弱制众杀
    时干丁火（食神）
    只有一个丁火，且不得令
    →  这是「弱制」
```

#### 16_4_6 第 4 步 · 看运

```plain
弱制结构贯穿一生
→  平衡、周旋、长久
```

#### 16_4_7 第 5 步 · 验应

```plain
史实：长期割据一方、善周旋、得长寿
```

#### 16_4_8 第 6 步 · 启示

```plain
忌神太旺，不可强攻，只可智取（弱制 / 化泄）
```
```plain
旺制  →  激怒七杀  →  反遭其害
弱制  →  维持平衡  →  长期周旋
```
**面对强大的忌神，维持一个它翻不了脸的平衡。**

#### 16_4_9 可复用规则

```plain
规则：忌神太旺时，弱制优于旺制
判断：
    第1步 评估忌神的力量（得令？多现？）
    第2步 评估制方力量（得令？有根？）
    第3步 制方远弱于忌神  →  弱制结构  →  主平衡、周旋、长久
    第4步 强行旺制  →  激怒忌神  →  主突发波折
```

### 16_5 某企业家：内食神格

病药、禄神、弱制之后看「格局类型」。内食神格是食伤藏支不透的结构，主实业、主被「用」而非主动「取」。

#### 16_5_1 命造

```plain
乾造：壬寅  丙午  甲午  己巳
```

#### 16_5_2 六步拆解

#### 16_5_3 第 1 步 · 定势

```plain
甲木日主
    月支午、日支午、时支巳
    月干丙火
→  木火成势（火在四支占三，压倒性强）
```

#### 16_5_4 第 2 步 · 定病

```plain
火势过旺（木生火，火成党）
    需要泄（火生土）而非再助
```
**病的判断依据是「需要什么」。**

#### 16_5_5 第 3 步 · 定药

```plain
地支午火食神成党，不透干  →  内食神格
火土相生，食神生财          →  主实业致富
```
**内食神格定义见板块 9_5：** 食伤藏支不透、食神成党而藏，主谋划、实业、主「被吃」；外食神（透干）主销售、口才、技艺，主「去吃人」。食神生财是火的出口，做功成立。

#### 16_5_6 第 4 步 · 看运

```plain
行土金运  →  发财（食神生财，财富兑现）
行水运    →  破财（水火交战，坏食神）
```

#### 16_5_7 第 5 步 · 验应

```plain
行土金运发财，行水运破财
另有类似命造行水运失利，印证内食神格忌印
```

#### 16_5_8 第 6 步 · 启示

```plain
内食神格
    喜行财运（食神生财）
    忌行印运（印制食神，坏局）
```
**内食神格与印是核心矛盾：** 印（水）克食神（火），直接坏了做功主体。

#### 16_5_9 内食神格要点（关联板块 9）

```plain
内食神（食伤藏支不透）  =  企业家（被人吃），主谋划、实业
外食神（食伤透干）      =  销售（去吃人），主口才、技艺
```

#### 16_5_10 可复用规则

```plain
规则：内食神格喜财运、忌印运
操作：
    第1步 确认食伤是否透干（透 = 外，藏 = 内）
    第2步 内食神：看财有没有被生到
    第3步 行印运（印制食神）→ 坏局
纪律：这是倾向性规律，须结合全局
```

### 16_6 某官员：杀印相生

内食神格看食伤，这一例看官杀配印——杀生印、印生身，一路相生到日主，是贵格的标准形态之一。

#### 16_6_1 命造

```plain
乾造：庚子  己卯  丙寅  壬辰
```

#### 16_6_2 六步拆解

#### 16_6_3 第 1 步 · 定势

```plain
丙火日主
    月支卯木（印，当令）、日支寅木（印）
→  印星当令得势
```

#### 16_6_4 第 2 步 · 定病

```plain
年干庚金财星坏印  →  财克印是病
时干壬水七杀      →  杀本为压力
```
**病是「财星坏印」。** 庚金财星克印，是「根基被财所伤」；壬水七杀本是压力源，本造里被转化成药。

#### 16_6_5 第 3 步 · 定药

```plain
时干壬水七杀生印（杀生印、印生身）
→  杀印相生，主贵
```
**最关键一处：** 七杀在别的格局里是病，这里被印星转化，成了「生印之源」。杀→印→身一路相生，压力转化为权柄与资源。组合原型见板块 9_1。

#### 16_6_6 第 4 步 · 看运

```plain
行印运  →  升迁（助起印星）
行财运  →  罢官（财克印，断了官的根基）
```

#### 16_6_7 第 5 步 · 验应

```plain
行印运升迁，行财运罢官
有类似命造行财运丢官，印证官杀配印的喜忌
```

#### 16_6_8 第 6 步 · 启示

```plain
杀印相生格
    喜印
    忌财
```
**印是「转换器」，把杀的压力转成身的资源。** 转换器一被财克掉，压力直接压到日主。**所以看杀印相生格，第一件事是查有没有财星坏印。**

#### 16_6_9 与板块 9 的呼应

```plain
组合 1：官杀配印
    印化杀，主权柄
    喜印，忌财（财坏印则官源断）
```

#### 16_6_10 可复用规则

```plain
规则：官杀配印格，喜印忌财
操作：
    第1步 确认杀印相生的链条是否完整（杀 → 印 → 身）
    第2步 查有没有财星坏印
    第3步 行印运 = 上升；行财运 = 需要谨慎
纪律：不铁断具体职位与年份
```

### 16_7 霍金：水泛木浮

前五例都是事业、权柄、财富方向，这一例转向健康取象。**涉及健康议题，仅作结构与取象层面分析，不作绝对化断言，也不构成医疗结论。**

#### 16_7_1 命造

```plain
乾造：壬午  壬寅  壬子  庚子
大运：癸卯  甲辰  乙巳  丙午
```

#### 16_7_2 六步拆解

#### 16_7_3 第 1 步 · 定势

```plain
三壬透干 + 双子  →  水势滔天
无戊土制水（无堤坝）
仅庚金生水（助其势）
→  水势成党、无制
```
**水党极旺，既无制又得生。**

#### 16_7_4 第 2 步 · 定病

```plain
水势滔天无制为病
    无戊土作堤坝
    庚金再生水助势
→  病在「水无约束、越积越多」
```

#### 16_7_5 第 3 步 · 定药

```plain
原局无土作堤（无戊己土），无明字可制水
寅木被水泡烂  →  木主筋脉  →  筋脉方向受损
```

#### 16_7_6 第 4 步 · 看运

```plain
癸卯运  →  木运，水有泄处（水生木），水势得疏
甲辰运  →  辰为湿土，可蓄水；甲木又泄水
乙巳运  →  巳火耗水，水势开始受制
丙午运  →  火土并旺，水被制
```
**前三步运是「疏导型」**，水势有所缓解；到火土运，水开始被正式制约。岁运只能阶段性改善，不能根除。

#### 16_7_7 第 5 步 · 验应

```plain
公开史料记载其二十余岁即出现运动神经元类疾病的征兆
大运阶段与健康状态的变化方向，在取象层面与命局结构吻合
```
**表达纪律：** 只做取象层面的结构对应，不将其与任何具体疾病作因果断言，不构成医疗结论。

#### 16_7_8 第 6 步 · 启示

```plain
水势滔天无土制  →  木被泡烂  →  筋脉方向需留意
```
**核心是「失衡的五行会侵蚀它所克的五行」。** 水无制就去过度克木，木（筋脉）首当其冲。命理给的是方向性提示。

#### 16_7_9 可复用规则

```plain
规则：水势滔天无土制 → 木被泡烂 → 筋脉方向需留意
边界：
  ✓ 看有没有土作堤坝（有戊土则大幅缓解）
  ✓ 看有没有木火运疏导
  ✓ 这只是方向性提示，不替代医学
纪律：涉及健康的取象，只说「方向值得留意」
```

### 16_8 张雨生：刃旺逢冲

上一例是「水无制」，这一例是「旺极无泄」。水无制是「散」，火无泄是「憋」。

#### 16_8_1 命造

```plain
乾造：丙午  甲午  丁酉  戊申
大运：乙未  丙申  丁酉  戊戌
```

#### 16_8_2 六步拆解

#### 16_8_3 第 1 步 · 定势

```plain
火旺成势
    年柱丙午、月柱甲午、日主丁火
→  火党极旺，全局以火为势
```
**火在年月日三柱连成一片，是全局压倒性的势。**

#### 16_8_4 第 2 步 · 定病

```plain
旺火无处泄为病
    火成党而无可生、可泄之处
    酉金（财）在日支，被旺火所克
    申酉金主车马、筋骨
```
**病是「旺极无泄」。**

#### 16_8_5 第 3 步 · 定药

```plain
原局无明字泄火
    戊土在时干，但被申金所泄，泄火之力有限
→  药力不足
```
**唯一能泄火的戊土又被申金泄掉，泄火这条路几乎不通。**

#### 16_8_6 第 4 步 · 看运

```plain
丁酉运  →  酉金伏吟（日支酉金重见）
         →  禄被穿害，旺火遇湿土晦灭
         →  能量反噬
```
**「刃旺逢冲，十有九凶」**——旺火遭湿土晦灭，能量反噬。**酉金为车，逢穿则覆；申酉为金，主筋骨、车马。**

#### 16_8_7 第 5 步 · 验应

```plain
公开史料记载其在丁酉运期间遭遇车祸去世
命理取象上：旺火无泄 + 禄被穿 + 酉金为车逢伏吟，三项同应
```
**表达纪律：** 仅作取象层面的结构分析，不作任何绝对化断言。

#### 16_8_8 第 6 步 · 提启示

```plain
旺极无泄 + 禄被穿  →  能量反噬
```
**「能量反噬」值得记住：** 旺到极处的能量没有出口，会反过来伤害自己。这是灾祸类命例里常见的机理。

#### 16_8_9 可复用规则

```plain
规则：旺极无泄 + 禄被穿 → 能量反噬
判断：
  ✓ 找最旺的那一行
  ✓ 看它有没有出口（生、泄）
  ✓ 看禄 / 身有没有被穿被冲
  ✓ 无出口 + 禄受损 = 高风险结构
纪律：灾祸类只给倾向与行为建议
```

### 16_9 名人命例的共同规律

七个案例各有结构，合起来抽出四条共性。

#### 16_9_1 规律一：大人物必有势

```plain
回看这些案例：
    袁世凯    火土成势
    船王      火土成势
    阎锡山    金旺成势（忌神旺）
    企业家    木火成势
    官员      印星当令
    霍金      水势滔天
    张雨生    火党极旺

没有一个「平衡温和」的命局
```
**「伟人皆有势，贵在去病」**——有势又有药才是大格局。

#### 16_9_2 规律二：运的作用比原局更戏剧化

```plain
同一个命局：
    助药的运  →  登上顶峰
    助病的运  →  跌入谷底
袁世凯：戊辰运罢官，丁卯运当总统（同一命局，天上地下）
```
**「原局定层次、岁运定应期」要分开看。** 差别只在那一个字。

#### 16_9_3 规律三：禄与寿元是硬约束

```plain
船王：禄神复吟 → 亡（无论财富多少，禄走了就走了）
禄神为命根，最怕复吟与财星坏
```
**财富、权柄都救不了禄。**

#### 16_9_4 规律四：旺忌不可强攻

```plain
阎锡山：旺杀弱制 → 长久（若强行旺制 → 激怒七杀）
这条既是命理，也是人生策略
```
**面对旺忌，智取优于强攻。**

### 16_10 名人命例的研读方法

四条规律是从案例里提炼的，这一节讲怎么自己提炼规律。

#### 16_10_1 三遍研读法

```plain
第1遍  遮住解析，自己断（只看四柱 + 大运，写下三条判断）
第2遍  对照已知事实（看中了几条，哪条对、哪条错）
第3遍  看推理路径（重点看「他想到了我没想到的那一点」）
```
**第 2 遍的「错」比第 1 遍的「对」更有价值。**

#### 16_10_2 建名人命例库的建议

```plain
按「势」分类归档：火土成势 / 金水成势 / 木火成势 / 水势滔天
每例记录：
    第1步 势在哪一行
    第2步 病是什么
    第3步 药是什么
    第4步 关键大运与对应事件
    第5步 我的收获（一句话）
```
**按「势」分类比按「职业」分类更有用。** 命例库要留「反例」位——每类势下面记一条「同类但结果不同」的反例，注明差别在哪。反例是命例库最有价值的部分。

### 16_11 本板块落地清单


### 16_12 笔记作业

用六步拆解法完整拆解一个你感兴趣的名人命例，写成一页笔记。第 5 步（验应）要对照公开史实逐条核对，不准的地方要如实记录。

**笔记模板：**
```plain
命造：_____________
第1步 定势：____________________
第2步 定病：____________________
第3步 定药：____________________
第4步 看运：____________________
第5步 验应（对照公开史实）：
        说中了：________________
        没说中：________________
第6步 提启示（一句话规则）：____
```
**「没说中」一栏不要空着。** 它比「说中」更能暴露判断逻辑的漏洞——是势定错了，还是病定错了，还是运的喜忌判断反了，一栏就看得出来。
