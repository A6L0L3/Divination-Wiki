# 板块1 · 盲派世界观：做功、宾主、体用

> 本板块是整套体系的语法起点。三件事必须先钉死：
> **做功 = 谁制谁；宾主 = 年月是外面、日时是家里；体用 = 印比食伤禄是工具、财官是要取的目标。**

## 1_1 两种世界观：做功 vs 扶抑

### 核心分野一句话

子平问「日主旺不旺、喜什么忌什么」，盲派问「命局里谁在制谁、制得干不干净、成果落在谁门内」。

| 维度 | 子平（扶抑为纲） | 盲派（做功为纲） |
| :--- | :--- | :--- |
| 核心问题 | 日主旺衰 → 格局 → 用忌 | 做功：谁制谁、制得是否彻底、宾主谁为主体 |
| 六亲定义 | 静态十神映射 | 关系网取象：看哪个字与日主/宫位发生关系 |
| 吉凶落点 | 大运流年喜忌 | 应期模型：到位、合冲、墓库、虚实 |
| 断事路径 | 以喜忌岁运推吉凶与应期 | 以做功取象直读事件、领域与年份 |

### 一纵一横，不是二选一

```plain
子平  →  先定旺衰、再立格局取用忌（给你一张「地图」）
盲派  →  直接观察谁在制谁、事情怎么做成（给你一个「放大镜」）
```

正确做法是双轨并行、互为印证：先用子平搭好框架（大致什么层次、喜忌方向），再用盲派视角把具体人事讲透（这一年发生了什么事、落在谁身上）。只用子平容易停在「今年不顺」这种层面；只用盲派则容易只见树木不见森林。

### 思维切换的实操动作

把内部提问从这一句换成这一句：

```plain
「这个十神是我的喜还是忌？」        ← 子平式
「这个十神在制谁？制得干不干净？成果归谁？」   ← 盲派式
```

练习：随便拿一张盘，把十神表盖住，只问三遍「谁在制谁」，把答案写下来，再和十神喜忌的结论对照。四五张盘之后就会自然切换。

## 1_2 做功：命局里正在发生的「工作」

### 定义

**做功 = 命局中一个字对另一个字的制约与获取。** 看三件事：谁制谁、用什么制、制得是否彻底。

### 功神与废神

```plain
参与做功的十神        →  功神
与做功无关的闲散之神  →  废神

功神多者  →  才干强、人生有戏
废神多者  →  平庸、能量无处安放
```

「废神多」不等于穷，而是「有力没处使」。判断成就要看功神组成的那条链通不通、通到哪里，而不是功神的数量。

### 看盘操作顺序（固定动作，不要跳步）

```plain
第1步  分宾主  →  年月为宾、日时为主
第2步  定体用  →  印比食伤禄为体、财官为用
第3步  论做功  →  哪个体制了哪个用、制得干不干净
```

「谁制谁」里的「谁」，必须先有身份才有意义。一张盘上看到金克木，如果不知道这个木是体还是用、落在宾位还是主位，连「这是赚钱还是破财」都判断不了。

## 1_3 宾主：四柱的两大阵营

### 坐标图

```plain
        ┌───────────────┬───────────────┐
        │     年柱       │     月柱       │
        │               │               │   ← 宾位（家外）
        ├───────────────┼───────────────┤
        │     日柱       │     时柱       │
        │    （日元）    │               │   ← 主位（家里）
        └───────────────┴───────────────┘
         父母·兄弟·社会·他人    自己·配偶·子女
```

| 坐标 | 宫位 | 代表 |
| :--- | :--- | :--- |
| 主位（家里） | 日柱、时柱 | 自己、配偶、子女的小家庭 |
| 宾位（家外） | 年柱、月柱 | 父母、兄弟、社会环境与他人 |

### 两处易错点

**易错点一：宫位和十神身份是两回事，必须分开判。**

同一个字，属「体」还是「用」看十神身份，落「宾」还是「主」看宫位。两层结论同时成立，不矛盾。

> 例：时干正财
>
> + 十神层面：正财属「用」（要取的目标）
> + 宫位层面：时柱属「主位」（落在自家门内）
> + 读作「我要取的东西就在自己家里」——往往意味着目标离自己近。

**易错点二：宾主可以动态转换。**

典型情形：**年柱的官星被日主合住，这个官就由宾变主，为我所用。**

```plain
年柱官星（宾）  ──合──▶  日主（主）
结果：外面的权力被我拉进自家门内 = 我掌了这个权
```

### 吉凶分野口诀

```plain
制家外（年月）的比劫印  →  吉（向外做功，成果归自家门内）
制家里（日时）的比劫印  →  动自身根基，领域应在自己或婚姻
                            吉凶随被制之字的喜忌走：制忌得吉，制喜招损
```

口诀怎么用：看到一组制，先问「被制的是哪一边的」。制外面的是开拓、是挣钱；制家里的是内耗、是伤自己人。但制家里不一定是凶——被制的那个字本身是忌神，制掉它反而是好事。

## 1_4 体用：做功的攻守双方

### 体与用的清单

```plain
【体】= 可以调遣去干活的力量
    印星 · 比劫 · 食神 · 伤官 · 禄
    对应：自己、身体、工具、单位、思想

【用】= 要去获取的对象
    财星 · 官杀
    对应：财富、地位、目标、欲望
```

### 正向做功与反向做功

```plain
正向做功：主位之体  ──制──▶  宾位之用
    「用自己的力量挣外面的钱权」，路径顺、成果稳

反向做功：宾位之物  ──制──▶  主位
    「外面的东西反过来作用于我」，效率反而更高，
    但常伴随对主位的消耗，须防代价
```

反向做功效率高，是因为它直接作用于主位，省去了「把成果搬回家」这一步。代价是主位（自己、家庭）要承受这个作用力，典型体现为「靠平台、靠别人给的资源起家，但自己也因此被绑住」。

### 体用的分层提醒（必记）

```plain
体用  →  看十神身份（印比食伤禄 vs 财官）
宾主  →  看宫位（日时 vs 年月）
```

这两套是正交的。每次判断都要问两遍：「这个字的十神身份是什么？它在哪个宫位？」

## 1_5 功神、废神与结构评价三句话

### 结构串联、相悖、复合

| 结构形态 | 判断 | 含义 |
| :--- | :--- | :--- |
| **结构串联** | 功与功首尾接力 | 层次上升，前一个功的成果变成后一个功的工具 |
| **结构相悖** | 两组功互相打架 | 层次下降、内耗，力量互相抵消 |
| **复合结构** | 多套独立做功并存 | 多重职业或换行业之象 |

串联：食伤生财（功一）→ 财生官（功二）→ 官生印（功三），一条链走通，能量没有中断。

相悖：一组是比劫制财，另一组是官杀制比劫，两组互相拆台。这类人常表现为「想干的干不了、能干的没机会」。

### 废功：看起来有功，其实白干

三种情况都叫废功，主劳碌贫贱：

```plain
废功一：体弱不能制用    →  工具太软，制不动目标
废功二：用神太重制不住  →  目标太大，工具不够
废功三：制神被坏        →  干活的工具自己被打残了
```

区分「功小」和「废功」：功小是制住了但效率不高，属于小成；废功是根本没制住，属于白忙。判断要点看制方有没有根、有没有被穿破。

## 1_6 演示：三步走读一张盘

下面用一张盘完整演示「分宾主 → 定体用 → 论做功」的固定动作。完整格局解析见板块 9（过河拆桥格）。

### 盘面

```plain
乾造：庚戌  己卯  戊子  癸亥
大运：庚辰  辛巳  壬午  癸未
现实反馈：房地产巨富，资产数千万

        年柱      月柱      日柱      时柱
天干    庚        己        戊 ★      癸
地支    戌        卯        子        亥
```

### 第 1 步 · 分宾主

```plain
宾位（家外）  =  年柱庚戌、月柱己卯 →  社会环境、外部资源、他人
主位（家里）  =  日柱戊子、时柱癸亥 →  自己、配偶、自己的事业成果
```

### 第 2 步 · 定体用

```plain
【体】戊土日主、己土劫财、戌土比肩、庚金食神
【用】子水正财、亥水偏财、癸水正财、卯木正官
```

注意一个细节：戌在年支（宾位），但它是戊土的比肩（体的身份）。这正是 1_4 说的「体用看身份、宾主看宫位」两层正交——**戌是落在宾位的「体」，意味着我的力量延伸到了外面去干活。**

### 第 3 步 · 论做功

```plain
关系一  卯木官星  ──统摄──▶  子水财星（两者都落在宾位）
关系二  年支戌土  ──合制──▶  卯木官星（我的体力去制外面的官）
推论：制住官，就拿到了官所统摄的财 = 制官得财
```

核心逻辑：不是直接去制财，而是制住管财的那个官。这是「过河拆桥」的精髓——过河（制官）之后，桥（被制的一方）就完成了使命。

### 第 4 步 · 成果归谁

```plain
被制的是宾位的官（卯）
制它的戌虽在年支，但与日主戊土同气
    →  成果最终落在主位门内
    →  主「我把外面的钱搬回了自己家」
```

### 从这张盘能提炼的通用动作

```plain
第1步 遇到「官星统摄财星」的结构，优先看制官，而不是看制财
第2步 判断成果归属，看制方与日主是否同气、是否与主位有关联
第3步 制方落在宾位不等于成果归别人，关键看它与日主的关系
```

## 1_7 两套体系的角色转换预览

同一个十神在子平和盲派里读出来的东西常常不同，根子在提问方式不同（板块 4 详细展开）。这里看两个最典型的例子。

### 例一 · 七杀

```plain
子平：七杀是攻身之物，身弱见杀 = 压力、小人之象
盲派：有制化为权柄，无制则残
同样是七杀，结论可以完全相反。判断动作：先看它有没有被制，再谈吉凶。
```

### 例二 · 比劫

```plain
子平：比劫夺财，见比劫 = 破财、竞争
盲派：比劫制财 = 劳碌发财
同样是比劫围攻财星，身强制得住就是挣钱，不是破财。
```

切换心法：看到任何一个十神，不要先在脑子里跳出「它是吉是凶」，而是问「它旁边有谁、它在对谁做什么」。

### 一个必要的术语澄清

盲派所说的「旺衰」，既不是十二长生中的「衰」，也不是旺相休囚死里的「旺」，而是体系内部对日主能量强弱的独立判断标准。

```plain
弃旺衰，重做功
旺衰仅用于判断「体」能否承受「用」，不是取用神的依据
```

旺衰不是不用，而是换个用法——不拿来定吉凶，只拿来确认「工具扛不扛得住目标」。

## 1_8 从扶抑思维切换到做功思维的常见卡点

学盲派最容易翻车的，不是记不住术语，而是脑子还在用子平的提问习惯。下面五条是最常见的卡点。

### 卡点一：先入为主地给每个字贴「喜 / 忌」标签

**症状：** 一看到七杀就觉得凶，被喜忌结论绑住，看不到制化关系。

**纠正：** 先把十神标签盖住，问三遍「谁在制谁」，等制化关系读出来了，再回头用旺衰验证「体能不能扛住用」。

### 卡点二：只论生克，不算宾主

**症状：** 能说出「金克木」，但说不出金在年月还是日时、成果落在家里还是外面。

**纠正：** 每读一组生克，立刻补一句「这组制落在宾位还是主位」，否则「制外面」和「制家里」的吉凶方向完全相反。

### 卡点三：把「做功」当成孤立的吉凶判语

**症状：** 背下「食伤制官杀 = 贵」，看到这组关系就断贵，忘了问制干净没有、落点在哪。

**纠正：** 做功是结构不是结论，回答「在干什么」，吉凶再看效率（板块 2）、宾主落点和应期（板块 7）。

### 卡点四：用喜忌解释一切，结果互相矛盾

**症状：** 同一个字在这步断喜、那步断忌，越推越乱。

**纠正：** 两套体系分工不同：子平定方向和大局，盲派定事件和量级，结论分开放。

### 双轨并行的操作建议

```plain
第1步  先用子平：定旺衰喜忌，给盘一个大致层次判断
第2步  再用盲派：分宾主 → 定体用 → 论做功，读出事件与结构
第3步  交叉校验：两者吉凶方向是否一致，不一致先回盘面找矛盾
```

## 1_9 应期模型一瞥

本节只做概念骨架，完整法则见板块 7。先记住四个抓手：

```plain
到位      原局已有的字在流年再次出现 = 引动
          含原字、禄、原身三类
合冲互报  原局有合以冲为应，原局有冲以合为应
墓库三态  入墓收、出墓放、冲开则发
虚实改变  喜虚之字通根变实 = 该象落实（多应凶险）
          喜实之字虚透 = 失去保障之期
```

应期 = 状态改变的时刻。原局是「有什么」，岁运是「什么时候触发它」。到位的三类形态及其判定规则统一放在板块 7_2「定律一：到位」，此处不展开。

## 1_11 笔记作业

找三张你熟悉的盘，各写一段 100 字以内的「做功描述」，格式固定为：

```plain
[某体] 以 [某方式] 制 [某用]，成果落在 [主位/宾位]，因此主 [方向]
```

写完后检查：格式里的四个空是否都填得上？填不上的那一项，就是你需要回看的小节。
