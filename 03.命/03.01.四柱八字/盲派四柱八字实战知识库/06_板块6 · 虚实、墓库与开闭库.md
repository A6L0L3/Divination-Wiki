# 板块6 · 虚实、墓库与开闭库
> 本板块回答两个问题：**财是真是假？库开没开？** 这是判断财富量级的第一道分水岭。

## 6_1 虚实真义
### 核心规则：虚实只论一柱内部
```plain
天干无根无生  =  虚
天干有根有生  =  实
地支永远论实
```

**最容易被搞错：** 虚实**只在单一柱内部**讨论（这个天干在它的坐支有没有根），不是对整个命局论强弱。

### 虚与实的含义对照
| 状态 | 含义 | 主什么 |
| :--- | :--- | :--- |
| **虚** | 无根无生 | 才华、名声、表象、远方、精神层面 |
| **实** | 有根有生 | 实际的财富、权力、根基、身体、近处、物质层面 |

### 进阶变例（基础阶段先不用）
```plain
地支被合化或穿破时，亦可论虚
```

基础阶段先守住「地支永远为实」，等合化、穿破技法学透之后再启用这个变例。

### 与旺衰的区别（必记）
```plain
旺衰  =  看全局气势强弱（一个字在整个命局里的能量状态）
虚实  =  只看单柱内部干支关系（这个天干有没有根）
```

一个天干可以全局很旺但坐支无根（虚浮），也可以全局不旺但坐支强根（实）。盲派口诀里的「旺衰」是体系内部独立判断日主能量强弱的口径，既非十二长生的衰，也非旺相休囚死的旺。

### 三句虚实心法
```plain
虚看名，实看利
虚怕克，实怕坏
虚神得地则实，实神被伤则虚
```

第三句讲动态转化：虚的东西行运得到根就变实，实的东西被冲克掉根就变虚。虚实转化本身提供应期线索，应期用法见板块 7_4。


## 6_2 财官虚透
### 核心规则
```plain
财官虚透  →  不主钱财权力本身，主挣钱能力与名气
财官落实  →  主实际的财富权力
```

**举例：**

```plain
财星虚透  →  挣钱能力强、有经商头脑、有名望
          但：实际拥有未必厚（看得见摸不着）
财星落实  →  实打实的财富、实业
```

### 虚实改变即应期（关键）
```plain
喜虚之字，行运通根变实  →  该象落实
    注意：因该字本属所忌，故多为凶险应期

喜实之字，行运虚透  →  失去保障的信号
```

「喜虚之字变实为什么是凶？」这个字本来就是命局所忌，虚着时只是影子，通根变实后忌神从影子变成实体，所以应凶。

### 财富级别的判断要点
```plain
财星虚透  →  名气、小财
财星落实  →  大财、实业
```

**看财是「虚」还是「实」，是判断财富量级的第一道分水岭。** 完整的财富判断见板块 10。

### 虚实的其他取象
```plain
虚  →  远方、精神层面、表象
实  →  近处、物质层面、身体
```


## 6_3 墓库三态
### 三种状态
```plain
入墓收  →  暂时失去
出墓放  →  重新启用
冲开则发  →  能量释放
```

**冲开则发的吉凶判断：**

```plain
吉凶视库中藏干喜忌而定：
    放出喜用  →  得财官
    放出忌神  →  反招灾
```

看到「财库冲开」就断发财，但如果库里藏的是忌神，冲开反而是灾。必须先确认库里藏什么。

### 墓库的三种处境
```plain
开库  →  能量可用（财官可取出）
闭库  →  能量封存（有等于无）
冲坏  →  库被冲散（物毁）
```

区分「开库」与「冲坏」：冲的力量适中 = 开库可取物；冲得太狠 = 库散物毁。即口诀后半句「冲刑能开亦能坏，须辨喜忌方无误」。

### 开库的方式
```plain
冲开：辰戌冲、丑未冲
刑开：丑戌刑、寅巳申三刑
```

### 墓库秘传口诀
```plain
财官临库，不冲不发
墓库宜开不宜闭，开则发福闭则滞
冲刑能开亦能坏，须辨喜忌方无误
```


## 6_4 闭库：最常被漏掉的检查
### 两种闭库情形
```plain
闭库一  库被合住
    例：辰酉合  →  闭辰库
    被合住的库打不开，里面的东西取不出来

闭库二  库被盖头
    例：壬辰  →  水盖土库
    天干盖在地支库上，把库封住了
```

### 闭库检查三步（必查）
看到命局里有库，按下图顺序检查：

```plain
看到有库
    ↓
查一：有没有刑冲（原局或岁运）？
    无  →  闭库，不发
    ↓
查二：库有没有被合住 / 被盖头？
    有  →  闭库，不发
    ↓
查三：库里藏的是喜是忌？
    忌  →  冲开反招灾
    ↓
全部通过  →  开库则发
```

三步是硬流程，任何一步不过关都不能断「开库发财」。命理里大量的「有财库却没钱」，问题都出在查一或查二。

### 多而墓之
```plain
同类五行多见  →  则入墓
```

某一行在命局里出现太多，反而会「入库收藏」，不再积极发挥作用。


## 6_5 库的开闭与终身锁死
### 开闭库判断流程（逐步化）
三态定义与开门方式已在 6_3 交代，这里只讲判断顺序与边界：

```plain
第1步  确认库里藏的是什么
       （辰藏戊乙癸、戌藏戊辛丁、丑藏己癸辛、未藏己丁乙）
       明确取出的是喜还是忌

第2步  查原局有无开门条件
       透干 / 刑冲 / 岁运填实三者任一即属「可开」

第3步  查有无闭库情形
       库被合住、被盖头、被穿破，一律按闭库处理

第4步  原局不开  →  查九步大运有无开库运
       有  →  等待引动，断「到某步运才有转机」
       无  →  进入第5步

第5步  判终身锁死
       原局无门 + 九步大运无开库运  →  该领域终身被锁
```

**流程的关键在第 3 步。** 很多「原局明明有冲却还是不发」的盘，问题不在第 2 步，而在第 3 步——库其实被合住了，冲的力量进不去。

### 终身锁死：库不开且无开库运
```plain
⚠️  九步大运无一开库运
        ↓
    该领域终身被锁
        ↓
    不是「晚到」，而是「不来」
```

| 情形 | 性质 | 断语 |
| :--- | :--- | :--- |
| 空亡 | 可待填实 | 「时机会晚，但会到」 |
| 库不开、但有开库运 | 等待引动 | 「到某步运才有转机」 |
| 库不开、九步运皆无 | 真锁死 | 「这个领域难以兑现」 |

### 盘例：妻宫坐财库不开
```plain
某造：日支辰为水库，兼妻宫
    全局无戌冲辰
    九步大运亦无辰戌冲
        ↓
    水库终身不开
```

**盲派老师据此断为标准单身命造：**

```plain
女人缘不断，但留不住
一生难以成婚
```

桃花可以有，但如果妻宫的库终身锁死，缘分就只是过眼云烟。

> 说明：此造属理论推导，未经命主现实反馈验证。用真实反馈检验后，方可作为可复用结论记录。

### 空亡 vs 库不开：为什么性质完全不同
```plain
空亡  =  这个位置暂时是空的
        流年填实，它就回来了
        →  有希望，只是要等

库不开  =  这个领域的门从来没打开过
        且有生之年没有打开的机会
        →  不是慢，是没有
```

遇到库不开又无开库运，必须如实说明这个领域难以兑现——**不能给虚假的希望**。

### 闭库被漏掉的典型场景
以下四种是实战中最容易「看到库就断能开」的漏检场景，每种都配一条自查问句：

| 场景 | 盘象表现 | 漏检结果 | 自查问句 |
| :--- | :--- | :--- | :--- |
| 库被合住 | 辰酉合、卯戌合 | 合住锁死，冲不进来 | 这个库有没有被任何字合住？ |
| 库被盖头 | 壬辰、癸丑 | 天干封顶，取不出 | 库上坐的天干是不是盖头？ |
| 库被穿破 | 丑被未穿、戌被辰冲过 | 库散物毁，不算开库 | 这个库有没有被穿破？ |
| 库被隔位冲 | 辰戌分居两头无引动 | 有冲无引，等于不开 | 冲力有没有字搭线引动？ |

四种场景的共同特征：表面都有「库」，甚至都有「冲」，但库的能量并没有真正释放。漏检的根源通常是只查第 2 步、不查第 3 步。

### 可复用规则
```plain
规则：库的开闭决定该领域能否兑现

判定顺序：
    第1步 库中五行有没有透干？（透 = 有钥匙）
    第2步 原局有没有刑冲？
    第3步 九步大运有没有开库运？
    第4步 流年有没有填实库中五行之禄？

边界：
    ✓ 库中所藏是喜是忌要分开看
      放出喜用得财官，放出忌神反招灾
    ✓ 透干开库与冲开可并存，钥匙越多越易开
纪律：
    ✓ 库不开且有生之年无开库运 → 如实说明难兑现
    ✗ 不用「晚一点会有的」给虚假希望
```


## 6_6 虚实在十神上的通用表现
虚与实不只用于财官，所有十神都适用：

| 十神 | 虚透时主什么 | 落实时主什么 |
| :--- | :--- | :--- |
| 财 | 挣钱能力、名气、面子工程 | 实际资产、实业 |
| 官 | 有名望、虚职、头衔 | 实权、实际职位 |
| 印 | 有名声、学历名义 | 实际学识、真实庇护 |
| 食伤 | 才华外露、能说会道 | 实际产出、技术落地 |
| 比劫 | 人脉广但不得力 | 实际可得的助力 |

**通用原则：** 虚透主「看起来有」，落实主「真的有」。断事时先确认虚实，再谈吉凶大小。


## 6_7 虚实与墓库的交叉检查
虚实与墓库是两套独立的工具，但在「库里的字虚不虚、实不实」这一处会交叉。本节给出交叉检查的边界，避免把两套口径混在一起。

### 交叉检查表
| 情形 | 库的状态 | 字的虚实 | 综合判断 | 注意事项 |
| :--- | :--- | :--- | :--- | :--- |
| 开库 + 藏干落实 | 已开 | 实 | 该领域可兑现，且有实质 | 需再辨藏干喜忌 |
| 开库 + 藏干虚透 | 已开 | 虚 | 有名声、表象，实质不足 | 不可按「大富」断 |
| 闭库 + 藏干落实 | 闭 | 实 | 有实底但取不出 | 常见「有财库却没钱」 |
| 闭库 + 藏干虚透 | 闭 | 虚 | 名实皆弱，该领域最弱 | 多为锁死或方向性提示 |
| 透干开库 + 藏干实 | 开（透干） | 实 | 门已开、物已出，最稳 | 透干本身就是钥匙 |
| 冲开 + 藏干虚 | 开（冲） | 虚 | 冲开了但物不厚 | 容易高估 |
| 合住 + 藏干实 | 闭（合） | 实 | 有实底被合住 | 合解之年才有机会 |
| 盖头 + 藏干虚 | 闭（盖） | 虚 | 两层皆不利 | 需岁运同时解盖并引动 |

### 交叉检查的三个结论
```plain
结论一  开闭库决定「能不能取出」
       虚实决定「取出的是什么分量」

结论二  开库不保证富足
       库已开但藏干虚透，仍只是名声层面

结论三  闭库不必然贫
       库虽闭但藏干落实，说明有实底，
       只等岁运引动——这与「终身锁死」是两回事
```

「闭库 + 藏干落实」与「终身锁死」都表现为当前取不出，但前者有开库运、后者没有。判断时先辨虚实，再辨开闭，最后才谈应期。

### 虚实与墓库不可混用的三处
```plain
混淆一  把「虚透」当成「闭库」
       虚透是天干无根，闭库是地支被封存
       二者对象不同，不可互换

混淆二  把「透干」当成「开库」
       透干只说明有钥匙，不必然等于库已开
       还要看有没有引动

混淆三  把「实神被伤则虚」当成「库被冲坏」
       前者是天干根被伤，后者是地支库被冲散
       两者都可致「失去」，但机制不同，断语不同
```


## 6_8 盘例：虚财得禄根支撑
本例演示「虚神得地则实」这条动态转化规则。

### 盘面
```plain
坤造：戊申  丙辰  壬午  丙午
藏干：  戊庚壬  戊乙癸  己丁    己丁
大运：乙卯  甲寅  癸丑  壬子
现实反馈：实业致富，非虚名
```

### 第一步：看财的虚实
```plain
壬水日主，丙火为偏财（火为水之财）
    丙火双透（月干、时干）
    表面看：财星很显眼
```

### 第二步：查根
```plain
丙火的根在哪？
    午  =  丙火的禄（火禄在午）
    日支午、时支午  →  双禄

结论：丙火虽透在天干，但地支有两个午作根
    →  财星落实，不是虚透
```

### 第三步：关键判断——午是谁的禄
```plain
午火既为丙火（财）的禄，又为丁火之禄
此造日主壬水，午中藏丁、己
    午为财之禄根，撑起天干双丙
    →  虚财得禄根支撑
    →  虚财转实
```

### 第四步：结论
```plain
「虚神得地则实」
    午火禄神撑财，虚财转实
    →  故为实业之富，而非虚名
```

### 可复用规则
```plain
规则：财星透干看似虚浮时，先查地支有没有禄根
    ✓ 有禄根  →  虚财转实，主实业致富
    ✗ 无禄根  →  确实是虚财，主名气大、实财薄

边界条件：
  ✓ 禄根不能被冲、被穿、被合化
  ✓ 财为喜用（财为忌则禄根反而助纣为虐）
  ✓ 大运流年引动禄根之年，往往是财富兑现之期
关联口诀：财星有禄，实业之富
```
