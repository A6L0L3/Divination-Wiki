### README_1 本库定位、全库地图与三条学习路径

#### 这套体系在回答什么

传统子平问「日主旺不旺、喜什么忌什么」，本体系问另外三个问题。

```plain
谁在制谁？        →  做功（who）
干的是什么事？    →  象法（what）
什么时候发生？    →  应期（when）
```

三者是流水线，不是并列关系：

```plain
     做功                象法                 应期
  ┌─────────┐       ┌─────────┐        ┌─────────┐
  │ 谁制谁   │  →    │ 什么画面 │   →    │ 哪一年   │
  │ 制得净吗 │       │ 什么行业 │        │ 什么引动 │
  │ 成果归谁 │       │ 哪个人   │        │ 什么状态 │
  └─────────┘       └─────────┘        └─────────┘
      骨架               血肉                落点
```

**缺少任意一环，断语都会失真：** 只有做功，说得出「他能发财」，说不出干什么发、什么时候发；只有象法，画面很花，但没有力量对比支撑，容易变成联想；只有应期，知道「某年有冲」，却说不清冲出什么事。

一句话记住这条流水线：**做功定有无，象法定形态，应期定时间。**

#### 三条学习路径

选一条就走完，中途不要横跳——混着走最容易半途而废。

##### 路径 A · 零基础

```plain
先补子平地基（日元强弱 → 十神 → 格局 → 用忌，本库不讲）
    ↓
板块1 → 2 → 3 → 4 连读，建立语法感
    ↓
板块5 → 6 → 7 → 8 学技法，边学边拿自己的盘对照
    ↓
板块9 → 10 → 11 → 12 → 13 → 14 专项突破，一个吃透再换下一个
    ↓
板块15 → 16 → 17 → 18 → 19 用案例倒逼，回头补漏洞
    ↓
板块20 八步流程收官，拿真实盘完整走一遍
```

零基础必须先补子平：盲派不问旺衰、直接读象，但「不问」的前提是「已经会问过」。

##### 路径 B · 已有子平基础

```plain
板块1（重点做一次思维切换：从「喜忌」到「谁在制谁」）
    ↓
板块2（效率表当字典查，不要背）
    ↓
板块3、4（从「断吉凶」跨到「断事情」的桥）
    ↓
板块5 → 6 → 7 → 8（补齐盲派工具箱）
    ↓
板块9 以后（专项与实战）
```

核心动作：把提问方式从「这个十神是喜是忌」换成「这个十神在制谁、制得干不干净」。

##### 路径 C · 已接触过盲派

```plain
板块2 效率表 + 板块7 应期三定律 → 查漏
    ↓
板块5 的「穿反」与「实主位反局」是分水岭，重点攻
    ↓
板块8 串宫压运单独练
    ↓
板块16 → 19 拔高，看完整链条
    ↓
板块20 八步流程：把散落的技法串成一条可执行的流水线
```

### README_3 核心心法、文档体例与表达纪律

#### 核心心法速览（正式学习前先记住这八句）

```plain
1.  弃旺衰，重做功
    旺衰只用来判断「体」能不能承受「用」，不用来取用神

2.  八字为体（车），岁运为用（路）
    原局定层次，岁运定应期

3.  原局如镜，岁运如光
    镜中无物，光照亦空 —— 原局没有的象，岁运照不出来

4.  虚看名，实看利；虚怕克，实怕坏
    虚透主名气才华，落实主实际拥有

5.  虚神得地则实，实神被伤则虚
    虚实可以互相转化，转化本身就是应期

6.  合待冲，冲待合；墓待开，开待闭
    虚待实，实待虚；伏吟待值，反吟待冲

7.  得势之命，病神即为成就之源
    伟人皆有势，贵在去病；气势不可逆，逆势必遭灾

8.  象法定事，理法定时；象法是皮肉，理法是筋骨
    二者合一，方为完整之学
```

术语陷阱：盲派口诀里的「旺衰」既不是十二长生中的「衰」，也不是旺相休囚死里的「旺」，而是体系内部独立判断日主能量强弱的口径。三套概念互不相干，学习初期就要钉死。
