# 板块12 · 六亲、父母与子女

> 本板块讲父母、子女、兄弟这条线，重点解决一个实务难题：**六亲星不显或被坏时，怎么换角度找它。**

## 12_1 六亲星与宫位

### 基本定位

```plain
父母宫  =  年柱
兄弟宫  =  月柱
夫妻宫  =  日支
子女宫  =  时柱

父星  =  偏财（活论：财、官、食皆可）
母星  =  正印（偏印在正印缺席时代母）
子女  =  男命官杀、女命食伤

十神定「是谁」，宫位定「在哪个位置」，两者对上结论才稳。
只用一个会出问题：只看十神可能这个星被坏得厉害读不出信息；只看宫位又不知道这个位置对应的人是谁。
两套定位互相校验，是六亲判断的底线要求。
```

### 秘传口诀（完整展开见板块 15_3）

```plain
年柱受克，父母早亡
月令逢冲，兄弟有损
日支穿害，妻离子散
时柱伏吟，子女缘薄
```

**现代校正：** 这组口诀全部需要软化——「早亡」在现代可能只是缘薄、不在身边、关系疏远；「妻离子散」可能只是聚少离多。完整软化表见 12_10。

## 12_2 六亲数量象法：计数四步法

「兄弟姐妹几个」是盲派一口断风格的代表技法，也是六亲判断中最容易「说得太满」的地方。

> **前置声明：** 所有数字都是**倾向性线索**，不是精确统计。数量一律用「约」「三四个」这类区间表述。
>

### 手足计数四步法

```plain
第1步 刃禄独立加法
    一禄加二，二禄各加一
    男命：一刃加三，二刃各加四
    女命：一刃加四，二刃各加三

第2步 透干优先
    中和偏弱  →  以比劫透干位数计
    身旺      →  以官杀透干位数计

第3步 藏干本气补位
    天干无比劫（或官杀）可计时
    →  转用地支藏干本气补位（只取本气，余气中气不计）

第4步 空亡穿害减损
    坐支空亡、受穿害者  =  折损位
    →  从总数中减去
```

**第1步为什么是「独立」的？** 禄和刃本身就代表「自己身体的延伸」，计数独立于比劫之外单独累加——这一步不依赖日主强弱，先加进去再说。

### 第1步详解：刃禄独立加法

```plain
禄的加法
    命中出现一个禄  →  加 2
    命中出现两个禄  →  各加 1（共 2）

刃的加法
    男命：一个羊刃  →  加 3；两个羊刃  →  各加 4
    女命：一个羊刃  →  加 4；两个羊刃  →  各加 3
```

**演算示例一（禄）：** 某乾造日主为甲，地支见寅（禄）。寅只出现一次，按「一禄加二」计 +2。

**演算示例二（刃，男命）：** 某乾造日主为甲，地支见卯（羊刃）。卯只出现一次，按「男命一刃加三」计 +3；若再见第二个卯，则按「二刃各加四」计 +8。

**演算示例三（刃，女命）：** 某坤造日主为乙，地支见寅（羊刃）。寅只出现一次，按「女命一刃加四」计 +4。

### 第2步详解：透干优先

这一步**依赖日主强弱**——先判日主档位，再决定数什么：

```plain
日主中和偏弱  →  数「比劫透干」的位数（比劫是同类，偏弱则同类即为手足）
日主身旺      →  数「官杀透干」的位数（身旺则克我者为兄弟之数）
```

**演算示例（中和偏弱）：** 某造日主庚金偏弱，天干见庚、辛两透，比劫透干共 2 位 → 此步计 +2。

**演算示例（身旺）：** 某造日主甲木身旺，天干见庚、辛两透（官杀），官杀透干共 2 位 → 此步计 +2。

### 第3步详解：藏干本气补位

前两步都数不到时，转看地支藏干：

```plain
地支藏干中的「本气」  →  当作一位计数
注意只取本气，余气、中气不计
```

**演算示例：** 某造天干无比劫、无官杀可计，地支见子（藏癸水为本气）。癸水一位可计 → 此步计 +1。

**为什么只取本气？** 数量象法要的是「明确、不含糊」的线索。余气、中气力量弱、易争议，计入会让结果发散，反而失去参考价值。

### 第4步详解：空亡穿害减损

```plain
折损位判定：
    坐支落入空亡  →  折损一位
    坐支受穿害    →  折损一位
总数  =  前几步之和  −  折损位数
演算示例：前三步合计得 5，其中一位坐支落空亡、一位坐支受穿害 → 折损 2 位 → 约 5 − 2 = 3，表述「约三个」。
```

### 偏弱 / 极弱 / 真从格三档辨别

前几步有一个前提：**先判日主处在哪一档。**

```plain
第一档：普通偏弱
    辨别：生扶较少，但印星或比劫尚有一二根气
    公式：比劫 + 印枭一齐计（含印变体）

第二档：极弱
    辨别：生扶寥寥、弱极近从，但尚未入从格（有根而未去，或从格条件不齐）
    公式：只取比劫，不含印

第三档：真从格
    辨别：从格条件齐备（无根、无生扶、或全局一气）
    公式：另按从格论，不用此计数
```

**辨别要点：** 关键看「有没有根」。有根（哪怕一根）但弱 → 属极弱档；完全无根、全局从 → 真从格。**三套口径不可混用。**

### 完整演算示例（四步串起来）

```plain
某坤造（女命）日主乙木，中和偏弱：
第1步  见一个禄  →  +2
第2步  比劫透干两位  →  +2
第3步  天干已有比劫可计，此步跳过
第4步  其中一位坐支受穿害  →  −1
合计：2 + 2 − 1 = 约 3 个
出口：「手足约三四个」
```

### 子女线索

```plain
男命：传统上以官杀透干位数作子女数量的观察线索
    官星与日主干支五合  →  古称「子女随己」之象
关于女命：女命子女数量象法的可靠口诀与足够案例支撑均不足，本知识库暂按「未备」处理，不硬凑规则。
这是全库少见的「坦承未备」之处，保留这种坦率比硬凑一条规则更有价值。
```

### 折损信号

| 信号 | 观察方向 |
| :--- | :--- |
| 羊刃逢冲 | 兄弟缘薄或聚少离多 |
| 比劫坐空亡 | 同胞折损或生离 |
| 月支本气为七杀、伤官、偏印 | 兄弟缘分多有波折 |

### 表达纪律（数量类）

```plain
✓  数量一律用「约」「三四个」这类区间
✓  能给方向就给方向
✓  没把握就坦率说明「这个未看」
✗  不报精确数字（「你正好三个」）
✗  模糊话不如明说——宁可说「未看」，不要含糊其辞
```


## 12_3 活论父星

### 为什么能活看

```plain
父星可以活看：财、官、食皆可代表父亲
原理：「父亲」这个角色的本质是「供养者 / 权威者」。命局里哪个字承担了这个功能，哪个字就可以当父星看。
```

### 什么情况下需要活看

```plain
触发条件：
    第1条 偏财在命局中不显
    第2条 偏财虽显但被坏得厉害（被克、被合走、入墓）
    第3条 从偏财读出的信息与现实明显不符
```

### 活看的操作顺序

```plain
第1步  先看偏财（正统定位）
第2步  偏财可用 → 直接读
第3步  偏财不可用 → 换看能代表「供养者 / 权威者」的字（如正财、官杀、食伤中承担该功能者）
第4步  用宫位校验（年柱为父母宫）
第5步  用现实反馈校准（对方确认过的信息）
十神层面的活论见板块 4_3。
```


## 12_4 借子女星看父母（核心技法）

这是一条在父星不显时**极验**的活论技法，也是本板块最有实操价值的内容。

### 方法

```plain
男命：以官杀为子女  →  官杀之财 = 父
女命：以食伤为子女  →  食伤之财 = 父
简化记忆：子女星所克的五行 = 父星
```

**推导逻辑：**

```plain
男命：官杀为子女星，子女星的财星（官杀所克者）即为父星
     例：男命以金为官杀（子女）
         金克木 → 木为官杀之财 → 木可看父
女命：食伤为子女，食伤所克者（食伤之财）即为父星
     例：女命以火为食伤（子女）
         火克金 → 金为食伤之财 → 金可看父
```

### 使用场景与纪律

```plain
使用场景：当偏财不明显、或被坏得厉害时，直接用「子女星所克之五行」看父亲，往往能找到准确的应期
使用纪律：
✓ 这是「绕路」技法，只在正路走不通时用
✓ 用之前先用已知的父母信息校准一次
✓ 结论仍要以倾向性表述出口
✗ 不要所有盘都用它，正统偏财可用时不必绕路
```

### 盘例：父星死绝（应期推演见板块 7_10）

```plain
乾造：甲辰  丙寅  戊戌  壬子
大运：乙丑  甲子  癸亥  壬戌
现实宫位：幼年丧父
父星  =  偏财壬水（透时干）、子水（时支根）
状态：子水被戌土克（日支戌克子），又被寅木泄（月支寅泄水生火）
    →  两面受敌，无生扶
    →  财星死绝无生机
关键点：一边被克、一边被泄，又没有生扶——这是判断六亲受损程度的基础结构。
本盘例的应期推演已在板块 7_10 完整演示，此处只讲六亲层面的结构，应期部分不再重复。
可复用规则：
规则：六亲星被克且被泄、又无生扶 = 死绝之象
判断清单：
  □ 有没有被克？被谁克？
  □ 有没有被泄？被谁泄？
  □ 有没有生扶？（有生扶则大幅减轻）
  □ 有没有解救？（合住克方、制住克方）
现代校正：
  ✓ 说「与父亲的缘分需要留意」
  ✗ 不说「父亡」
```


## 12_6 父母离异与过继

缘分薄之外，还有一类常见问题：父母离异、跟谁生活；以及过继、改姓。这类判断的核心不是「吉凶」，而是「归属」。

### 父母离异的取象

```plain
财印交战  →  父母不和
    财星被合走  →  父亲离开
    印星得化泄有情  →  随母
「印财同宫相战，父母异路」
判断「跟谁」的方法：谁有解救就跟谁
    印星（母）虽被冲，但得化泄有情  →  随母
    财星（父）直接被合走，无回旋    →  父离开
```

### 盘例：父母离异

```plain
乾造：丙午  庚寅  壬申  辛亥
大运：辛卯  壬辰  癸巳  甲午
现实反馈：父母离异，随母生活
财星午火被暗合  →  父被合走
印星申金被寅冲  →  母这边有动荡
    但印星得亥水化泄有情  →  母这边有解救
应：父母离异，随母生活
为什么是「随母」？印星（母）虽被冲但得亥水化泄有情——母这边有解救；财星（父）直接被合走——父那边没有回旋。
```

### 过继的取象

```plain
月令食神入墓  →  与原生家庭的缘分被收藏
时柱提供新生机  →  新的家庭
「印被冲则离祖，时柱得地则继他姓」
「日时为新家」：时柱代表后来的、新的家庭。时柱得地有力，往往意味着后半程或新的家庭环境更好。
```

### 盘例：过继

```plain
乾造：癸巳  癸亥  庚辰  壬午
大运：壬戌  辛酉  庚申  己未
现实反馈：幼年被过继他人抚养
月令食神入墓  →  原生家庭缘分被收藏
时柱提供新生机  →  新的家庭环境
应：幼年过继
```


## 12_7 子女星与子女宫

### 基本定位

```plain
男命：官杀为子女
女命：食伤为子女
子女宫  =  时柱
```

### 子女优劣的判断

```plain
食伤（子女星）的状态：
    不受枭印夺、不受刑冲穿  →  子女贤孝
    被枭印夺（枭神夺食）    →  子女有损
    带三刑                  →  六亲易出问题
「凡带三刑者，六亲易出问题」——三刑是子女星最怕见到的结构之一。
```

### 子女数量与性别

```plain
数量的象：看子女星的个数与状态
性别的翻转：穿反技法（见板块 5）
    食神本主女儿  →  穿反翻作儿子
纪律：穿反需多重证据齐备才可采用，拿不准就不翻。
```


## 12_8 子女受损的不同方式

子女星被坏的方式不同，应事方向也不同——这是把「子女有问题」进一步翻译成「什么问题」的关键。

| 被坏方式 | 方向 |
| :--- | :--- |
| 伤官坏局 | 神经、精神方面 |
| 禄被冲 | 腿疾、肢体 |
| 禄逢墓绝 | 身体重病、行动受限 |

### 可复用规则

```plain
规则：子女星被坏的方式决定应事方向
边界：
  ✓ 这是倾向性规律，不是必然
  ✓ 现代医疗条件下，很多情况可以干预
  ✓ 表达方式：「与子女的缘分张力较大，需要多用心」
纪律：绝不用「命克子女」这类说法
```


## 12_9 盘例：连体取象看子女宫

本例演示「伤其座即伤其人」（板块 5）在子女判断上的应用。

### 结构示意

```plain
某造，日时丑未戌三刑
子女星（女命以食伤为子女）
    食伤星的坐支 = 其原神 / 根基
    ↓
坐支被刑、被穿
    ↓
子女星的根基受损
    ↓
应：子女健康或缘分需要留意
```

### 判断清单

```plain
□ 子女星是什么？（男官杀、女食伤）
□ 它坐在哪个支上？
□ 这个坐支是不是它的原神 / 根基？
□ 这个坐支有没有被刑、被穿、被冲？
□ 有没有解救（有没有别的字生扶它）？
□ 它在哪个宫位（时柱为子女宫）？
```

### 可复用规则

```plain
规则：子女星的坐支被坏 = 子女根基受损，重于星被克
操作：
  ✓ 先确认坐支是不是该星的原神 / 根基
  ✓ 再确认被坏的方式（刑、穿、冲）
  ✓ 最后找有没有解救
纪律：
  ✓ 说「子女方面需要多用心」
  ✗ 不说「子女会有灾」
```


## 12_10 现代校正：六亲断语软化表

涉及六亲的断语，在现代语境下必须大幅软化——这一节是全板块表达纪律的集中清单。

| 传统断语 | 现代表述 |
| :--- | :--- |
| 年柱受克，父母早亡 | 与父母的缘分偏薄，或早年与父母聚少离多 |
| 财星入墓，父先亡 | 与父亲缘分偏薄 / 父亲健康需留意 |
| 比劫重重，克父损妻 | 与父亲、妻子的缘分张力较大 |
| 日支穿害，妻离子散 | 婚姻结构张力较大，需要用心经营 |
| 时柱伏吟，子女缘薄 | 与子女的缘分偏晚或聚少离多 |
| 命克子女 | 与子女的缘分需要多用心（绝不使用「克」字） |

### 为什么必须软化

```plain
原因一  医疗与生活条件改变：同样的象，古人应死亡，现代人可能只是健康小问题
原因二  家庭结构改变：「缘薄」在现代常表现为异地、忙碌、关系疏远，而非生离死别
原因三  语言的伤害性：「克夫」「克子」这类词会给当事人带来真实的心理负担与关系伤害
核心原则：命理描述的是结构，不是判决。给方向、给提醒，不给标签。
```


## 12_11 六亲判断的完整流程

把「星宫定位 → 数量计数 → 活论绕路 → 应期触发 → 现代校正」五条线收敛成一条流程。

```plain
第1步  定六亲星（正统定位）
第2步  查状态（有没有？被克？被合？入墓？被穿？）
第3步  状态不可用 → 活看（换字）或借子女星绕路
第4步  用宫位校验
第5步  找应期触发点（入墓、被穿、被合、伏吟、冲提纲）
第6步  现代校正软化
第7步  出口（倾向性表述）
```
