## 板块13 · 疾病与病灶取象

> 先记住一句话：**五行脏腑对应属传统文化象法参考，不构成任何医疗建议。**

### 13_1 五行脏腑对应

#### 13_1_1 对应表

```plain
木  →  肝胆系统（另：木主筋骨，属体象维度）
火  →  心脑血管、血液
土  →  脾胃
金  →  肺、呼吸道
水  →  肾、泌尿系统
表中是「系统方向」，不是西医病名。同一五行会因观察层级不同而有不同落点：木可以是肝胆，也可以是筋骨；金可以是肺系，也可以是皮毛与手术。
```

#### 13_1_2 两个维度的区分（易混，必看）

```plain
维度一  脏腑五行对应：按五行论脏腑系统
       例：木受穿 → 肝胆系统方向
维度二  体象结构：按五行论身体结构
       例：木主筋骨、脊柱
两个维度分属不同的取象层面，可共存不冲突：
   一个人可以同时「木受穿（肝胆系统方向需留意）」和「木主筋骨（筋骨易伤）」
```

#### 13_1_3 常见取象对照

| 象 | 方向 |
| :--- | :--- |
| 金为忌旺 | 手术、金属器物 |
| 水土混杂 | 脾胃 |
| 子卯刑 | 肝 |
| 火金战 | 血糖代谢方向（古称消渴） |
| 水泛木浮 | 筋脉、脊柱 |
| 木过旺无金制 | 肝木亢极 |
| 燥土脆金 | 肺系 |

#### 13_1_4 子水被穿与血糖代谢方向

「子水被穿，消渴之疾」：子水对应胰窍，被穿则血糖代谢方向需留意（古称消渴，不对应现代医学中的某一确定诊断）。

```plain
读象三层表达
第1层  象法依据：子水、胰窍、被穿
第2层  方向提示：血糖代谢方向建议留意
第3层  行动建议：建议正规医院检查，不自行推断病名
```

### 13_2 疾病的核心判断：全局的「病」在哪

#### 13_2_1 方法

```plain
全局一党成势的五行为病
    流年来激（小激大发）
    →  应在该五行所主领域
```

#### 13_2_2 判断步骤（完整展开见板块 7_7「小激大发」）

```plain
第1步  找全局最成势的那一行（得令、得地、得党）
第2步  判断它是不是「病」（过剩为害，还是不足受欺）
第3步  确认它所对应的脏腑 / 体象方向
第4步  找岁运有没有来激它（小激大发：命局里某一党已成势，流年轻轻一激就引发大反应，如堆满干柴的房间一点火星就着）
失衡一  过旺成病：某一行太旺，克制它所对应的脏腑（例：水旺 → 火受克 → 心脑血管方向）
失衡二  过弱成病：某一行太弱，它所对应的脏腑先天不足（例：金弱 → 金所对应的肺系偏弱）
```

#### 13_2_3 疾病取象五步流程

```plain
第1步  定象：找出异常五行与其对应方向
第2步  定病：判断过旺成病或过弱成病
第3步  定源：找出成党、受穿、受克或受合的源头
第4步  定引：找岁运引动，没有引动只作倾向
第5步  定护：判断有无解救，决定轻重与缓急
前四步定象与引动，第五步定轻重；任何一步缺失，都不得把倾向说成结果。
```

**▲实操**：拿一张真实八字，先判断全局的「病」落在哪一柱、哪个十神，再写出你的依据与不确定之处；走满三张盘回看，重复出错的那一步就是没真懂的地方。

### 13_3 穿与冲在疾病上的区别

```plain
穿  →  慢性病、暗疾、长期损耗
冲  →  急性病、外伤、突发
```

| 作用 | 病程 | 特点 |
| :--- | :--- | :--- |
| 穿 | 慢性 | 拖得久、查不出明确原因、反复 |
| 冲 | 急性 | 突发、来得猛、有明显诱因 |
| 破 | 缺损 | 功能不全、先天薄弱 |

#### 13_3_1 三类作用的可复用规则

```plain
规则：以穿冲定病程性质，以生克定病灶方向
边界：
  ✓ 穿多作慢性耗损，冲多作急性变动
  ✓ 破主结构缺损，需与穿的暗耗区分
  ✓ 合住不等于消失，只是暂时不发作
纪律：
  ✓ 说「这一结构长期耗损，建议持续关注」
  ✗ 说「你一定得慢性病」
```

**▲实操**：在一张真实八字上找出「穿与冲在疾病上的区别」所说的三种表现，各写一句干支依据；找不出的那种，就是理解还停在概念上的部分。

### 13_4 星亢害其类：六亲病位映射

这一节讲**六亲的病灶**——如何从命局看出母亲、父亲的健康倾向。

#### 13_4_1 核心法则：亢害

```plain
某个六亲之星成党极旺
        ↓
    病灶应在「受害五行」所主的系统上
「受害五行」有两种可能：
第1步 亢星所克之五行：例：金亢乘木 → 木主筋骨 → 筋骨伤损
第2步 亢极自灼的本位：例：火海成党 → 火主心血 → 亢极自灼心血
```

#### 13_4_2 亢害法则的两个推演示例

**推演一：亢星所克之五行——土亢乘水**

```plain
前提：土星成党极旺，且水弱无救
映射链：土为母星（印）→ 土亢 → 土旺克水 → 水为受害五行 → 水主肾、泌尿系统
落点：不说「必患肾病」，而说「水受旺土所克，这一方向建议留意」
```

**推演二：亢极自灼本位——木海成党**

```plain
前提：木星成党极旺，且全局无金制、无火泄
映射链：木亢无制 → 亢极自灼 → 木主肝胆、筋脉 → 本位自伤
        木火相生又太燥时 → 肝木亢极兼血热方向
落点：先看木自身系统，再看木过旺会否伤土、耗水
```

#### 13_4_3 三案验证（原文实证）

| 案例 | 母星状态 | 母亲实际病症 | 映射关系 |
| :--- | :--- | :--- | :--- |
| 案A | 金成党极亢 | 骨病手术多次 | 金亢乘木——木主筋骨，受克则筋骨伤损 |
| 案B | 火海成党极旺 | 心脏病卒 | 火主心血——炎上无制，亢极自灼其类 |
| 案C | 水极亢坐长生 | 高血压经常心痛 | 水亢克火——火主血压血液，受克则心血为病 |

```plain
案A  金成党极亢 → 金旺克木 → 木主筋骨 → 观察骨与筋骨
案B  火海成党无泄 → 亢极自灼本位 → 火主心血 → 观察心脑血管
案C  水极亢坐长生 → 水旺克火 → 火主血压血液 → 观察血压与心血
```

#### 13_4_4 双机制分岔（极重要）

**两套机制必须分开判定，不可混用。**

```plain
机制一 · 星亢法
    适用：某星成党极旺
    路径：找受害五行（亢星所克者，或亢极自灼本位）
机制二 · 寒湿法
    适用：星不亢，但全局水寒土湿、金水无火暖局
    路径：走气候体质路线，观察怕冷、妇科寒证、脾胃虚寒、腰膝冷痛
判断顺序：
    先问：某个六亲之星成党极旺了吗？
    是 → 走机制一（星亢法）
    否 → 再问：全局是不是寒湿失衡？
          是 → 走机制二（寒湿法）
          否 → 两套都不成立，另寻路径
```

#### 13_4_5 星亢法与寒湿法对照

| 对照项 | 星亢法 | 寒湿法 |
| :--- | :--- | :--- |
| 适用条件 | 某六亲之星成党极旺 | 星不亢，但水寒土湿、金水无火 |
| 主要路径 | 亢星所克者，或亢极自灼本位 | 气候失衡，走体质与寒湿方向 |
| 输出方向 | 受害五行所主的具体系统 | 畏寒、虚寒、湿滞类体质倾向 |
| 观察重点 | 亢星、受害五行、宫位 | 水火调候、燥湿分布、暖局之神 |
| 易混点 | 把「旺」直接当病名 | 把正常寒暖当严重寒湿 |
| 缓解信号 | 有制、有泄、受害五行得生 | 有火暖局、燥湿趋于平衡 |

#### 13_4_6 对称规则：父星同理

```plain
母星（印）成党极旺  →  看母亲病灶
父星（财）成党极旺  →  看父亲病灶
父星注意点：男命财星既主父，又主妻 → 必须结合宫位锁定
    年柱  →  应父母
    日支  →  应配偶
判定三问：该星落在哪个宫位？全局还有没有同类星重复？岁运引动的是宫位还是十神？
若岁运只冲年柱财星，不必直接断言配偶有恙；若日支与年财同时受引，才可分别提示父母与配偶方向。
```

#### 13_4_7 可复用规则

```plain
规则：星亢害其类——亢星所克之五行主的系统即病灶方向
操作：
    第1步 找六亲之星（母看印、父看财）
    第2步 判断它是否成党极旺
    第3步 找受害五行（所克者）或亢极自灼本位
    第4步 确认宫位（一星多义时锁定六亲）
    第5步 若星不亢，改查全局是否寒湿，走机制二
纪律：
    ✓ 只描述五行所主的系统方向（如「筋骨骨节」「心血系统」）
    ✗ 不下具体西医病名
    ✓ 引导命主正规就医
    ✓ 属传统文化参考，不构成医疗建议
```

### 13_5 盘例一：土浊水，血糖代谢方向

#### 13_5_1 盘面

```plain
坤造：乙未  戊子  庚申  丙戌
大运：己丑  庚寅  辛卯  壬辰
现实反馈：中年患糖尿病
```

#### 13_5_2 推理链

```plain
土浊水
    子水食神被未穿（子未穿）
    戊土盖头（戊土盖在子水上）
    →  胰腺方向受损
「子水被穿，消渴之疾」→ 子水对应胰窍，被穿则血糖代谢方向需留意
```

#### 13_5_3 结构拆解

```plain
子水（食神）
    ↓ 被未土穿（子未穿）
    ↓ 被戊土盖头（天干克地支）
根基受损
    ↓
子水所对应的方向出问题
    ↓
应：血糖代谢（胰）方向
```

#### 13_5_4 应期与可复用规则

```plain
应期判断：
    原局已有子未穿、土浊水，属「伏病」
    壬辰运辰土再引水土，湿浊加重
    流年逢子、亥、辰，病气易被引动
可复用规则：子水被穿 + 土浊水 → 血糖代谢方向需留意
边界：
  ✓ 看穿的力量与有无解救
  ✓ 看调候是否同时失效（叠加则程度加重）
纪律：
  ✓ 说「血糖代谢这个方向建议留意，可以做个体检」
  ✗ 不说「你会得糖尿病」
```

### 13_6 盘例二：木多火塞，肝木亢极

#### 13_6_1 盘面

```plain
乾造：癸亥  甲寅  丁卯  壬寅
大运：癸丑  壬子  辛亥  庚戌
现实反馈：肝癌
```

#### 13_6_2 推理链

```plain
木多火塞
    亥卯合木（亥卯相合）+ 众木（甲、寅、寅）
    肝木亢极自焚
「母慈灭子，木过旺自焚」：生我者（木生火，木是火的母）太多，反而把火闷死了。
「肝木过亢无金制，主痈疽癌肿」
```

#### 13_6_3 应期与可复用规则

```plain
应期判断：
    原局木已极旺，庚金远隔且弱
    辛金虽透，相较旺木仍是金弱木坚
    庚戌运戌为燥土、金气增强，反而激怒旺木
可复用规则：木过旺无金制 → 肝木亢极方向需留意
边界：
  ✓ 看有没有金来制（有金制则大幅减轻）
  ✓ 看岁运有没有激怒旺神（金来反被克则爆发）
纪律：
  ✓ 说「肝这个方向建议定期检查」
  ✗ 不说「你会得肝癌」
```

### 13_7 盘例三：燥土脆金，肺系方向

#### 13_7_1 盘面

```plain
乾造：戊戌  乙卯  庚申  丙戌
大运：丙辰  丁巳  戊午  己未
现实反馈：肺癌
```

#### 13_7_2 推理链

```plain
燥土脆金
    禄神（申）被摧
「金衰火旺，五行偏枯」
辰戌冲激  →  土克金
庚为肺  →  应肺系方向
```

#### 13_7_3 结构拆解

```plain
庚金（日主，金主肺系）
    ↓ 被旺火克（丙火透干，火旺）
    ↓ 被燥土脆（戌为燥土，脆金而非生金）
金气受损
    ↓
肺系方向出问题
```

#### 13_7_4 应期与可复用规则

```plain
应期判断：
    原局戌燥土双见，丙火透干，金已偏弱
    丙辰、丁巳运火土增势
    辰戌冲再动燥土，金气更损
可复用规则：燥土脆金 + 火旺克金 → 肺系方向需留意
边界：
  ✓ 区分燥土（戌、未）与湿土（辰、丑）
  ✓ 看金有没有根（有根则耐受度高）
  ✓ 看有没有水来调候（有水则火势受制）
纪律：
  ✓ 说「肺与呼吸道这个方向建议留意」
  ✗ 不说「你会得肺癌」
```

### 13_8 疾病应期（完整应期法则见板块 7）

```plain
全局一党成势的五行为「病」
    →  流年来「激」（小激大发）
    →  应在该五行所主领域
应期检查顺序：
第1步  定全局的病（哪一行成势为病）
第2步  找流年有没有来激它
第3步  检查三合局有没有被填齐（三合缺一）
第4步  看有无解救（决定严重程度）
四类应期与轻重：
第1类  岁运助旺：忌神得令、得地 → 最易被引动
第2类  岁运激怒：制神出现却力量不足 → 易爆发
第3类  合冲到位：三合被填、六冲发生 → 引动明确
第4类  解救存在：有印、有根、有泄 → 程度下降
应期只能判断「倾向与窗口」，不能据此预告具体发病时间；同时仍须遵守健康表达纪律。
```

### 13_9 表达纪律（健康类）

#### 13_9_1 三条硬底线

```plain
底线一  不替代医学：「建议检查」≠「你有病」
底线二  不绝对断言：给方向，不给诊断、不给时间表
底线三  不在对方脆弱时直断：讳辞有时是人道，但笔记要如实记录（见板块 0 的讳辞原则）
```

#### 13_9_2 措辞对照表

| 想说的 | 应该说 | 不该说 |
| :--- | :--- | :--- |
| 肝有问题 | 肝这个方向建议留意，可以做个检查 | 你肝有病 |
| 心肺弱 | 心脑血管 / 肺系方面值得关注 | 你会得心脏病 / 肺癌 |
| 有重病象 | 这个阶段身体需要格外留意，建议体检 | 你某某年有大病 |

#### 13_9_3 一个实用技巧：先问后断

```plain
健康类推断的正确顺序：
第1步  先问「你平时哪方面不太舒服？」
第2步  用对方的回答校准你的方向判断
第3步  再给出「这个方向建议留意」的提示
好处：避免空断带来的恐慌；用反馈验证取象是否准确；把单向断言变成双向交流。
```

### 13_11 笔记作业

建立「健康取象专项库」，每个案例按以下顺序记录，不可只记结论：

```plain
第1步  先记四柱、大运、流年与对方实际反馈
第2步  找出最成势或最弱的那一行
```
