## 板块14 · 灾祸、牢狱与寿元

> 全库最需要谨慎表达的一块。涉及灾祸、牢狱、生死寿元的推断，**必须证据链完整，且以倾向性表述呈现**。
> 灾祸判断与疾病判断共用「护卫 / 解救」这一层逻辑；健康视角见板块 13，本板块不再重复五行脏腑对应。
> 先立一条总原则：**先看有没有护卫，护卫决定严重程度。**

### 14_1 灾祸总论：护卫决定严重程度

#### 14_1_1 核心原则

```plain
同样的冲 / 穿 / 刑：
    有护卫  →  事情发生但损失可控
    无护卫  →  损失放大，甚至危及生命
这是灾祸判断里最容易被忽略、也最关键的一条。
```

#### 14_1_2 三个对照案例

| 案例 | 作用 | 护卫 | 结果 |
| :--- | :--- | :--- | :--- |
| 某造 | 酉为车，丑午穿禄 | 无 | 人亡 |
| 壬申 辛亥 壬辰 己酉 | 辰为车，申亥穿 | 部分 | 人伤（脊柱） |
| 乙卯 戊子 庚寅 丙戌 | 寅为车，申运冲寅 | 丙火护主 | 人安车损 |

**关键差异就在「有没有护卫」：** 第三例「丙火护主」，所以人安车损；第一例没有护卫、且禄被穿，所以人亡。

#### 14_1_3 判断护卫的三个问题

```plain
第1步 日主有没有根、有没有印生？
第2步 被冲 / 被穿的那个字，有没有别的字生扶它？
第3步 伤官 / 食神 / 印星有没有起到通关或护卫的作用？
三个问题里有一个成立，严重程度就要往下降一档。
```

#### 14_1_4 护卫判断清单（可操作化）

每项成立计 1 分，三项计 3 分；分数为 0 时倾向最重，分数为 2 至 3 时倾向明显减轻。这只是判断严重程度的辅助方法，不代表绝对结果。

| 判断问题 | 成立（正向例） | 不成立（反向例） | 结论 |
| :--- | :--- | :--- | :--- |
| 日主有根、有印生？ | 日主自坐禄、印透护身，冲中可自持 | 日主虚浮无根，仅见比劫远隔 | 有根则抗冲，无根则受创更重 |
| 被冲、被穿之字有生扶？ | 申被寅冲但得辰生、亥拱 | 申孤立无援，又被巳合寅冲 | 有生扶则缓冲，无援则易折 |
| 食伤、印星能通关护卫？ | 丙火在旁化杀护主 | 枭印夺食、通关之神被坏 | 通关成则减祸，被夺则增祸 |

```plain
操作顺序：
第1步  列出三问各自的正反例
第2步  分别计分，不凭印象总评
第3步  再看岁运是否又增护卫或夺走护卫
第4步  综合判定为轻、中、重三级倾向
特别注意岁运改分：原局有印不代表一生都有护，流年冲掉印、合走根，护卫就可能暂时消失。
```

### 14_2 车祸的取象

#### 14_2_1 车象

```plain
车  =  酉金、辰、寅等
    具体读哪个，看命局里哪个是车象
逢穿  →  车覆
逢冲  →  车损、出行事故
读车象不是固定「酉就是车」，而是看命局里哪个字承担了「车」这个功能，通常是驿马或被冲的那个动象之字。
```

#### 14_2_2 相关断语

```plain
「酉金为车，逢穿则覆」
「驿马逢冲，血光之灾」
```

#### 14_2_3 判断流程

```plain
第1步  找出命局里的车象
第2步  看它有没有被穿、被冲
第3步  看有没有护卫（决定人安还是人伤）
第4步  找应期（冲合、到位），完整应期法则见板块 7
```

**▲实操**：用「车祸的取象」的方法在同一张盘上取三个象，逐个写明干支依据，再挑一个最能落地的写进命例卡。

### 14_3 水火之厄

```plain
溺水  →  水旺克火、禄被水克
煤气 / 火厄  →  水火相加之象
「禄被水克应水灾」：禄（身体）被水克，就应在水灾，是象法里「以象定事」的典型。
```

#### 14_3_1 判断流程

```plain
第1步  定全局的水火状态（哪一受过旺）
第2步  看禄 / 印有没有被克
第3步  看有没有护卫或解救
第4步  找应期（见板块 7）
```

#### 14_3_2 水厄与火厄的区分

```plain
水厄（溺水、水患、酒毒、肾系急症）
    水旺灭火、禄神被水克、水多金沉
    象：江河湖海、流动失控、沉没

火厄（烧伤、火灾、爆炸、电击）
    火旺熔金、禄神被火焚、火炎土燥
    象：焚毁、爆裂、灼伤

水火相加（最凶）
    水火交战而无通关  →  如煤气中毒、爆炸、触电落水
    关键看有没有土来通关、有没有木来泄水生火
```

**现代场景对应：** 古代断语里的「溺水」在现代可能应于涉水活动、船运、游泳或与水相关的作业；「火厄」则可能应于厨房、焊接、电路、化工。**给方向不给具体事故**，且必须先看有无解救。

#### 14_3_3 解救的三种情形

```plain
有护卫    →  禄印有生扶，灾来有缓冲
有通关    →  水火之间有木或土调和，战而不烈
有合住    →  凶神被合，暂时不发作（待冲之年）
```

三者皆无，才进入「严重程度较高」的判断区间。即使如此，出口仍须保留余地。

### 14_4 牢狱五大标志

```plain
标志一  官杀作忌无制化，且贴身克身
标志二  食伤作用神被枭印夺尽
标志三  食伤与官杀交战（伤官见官），且力量相当
标志四  金水沉陷（金见水沉、水多金沉），主暗昧、牢狱
标志五  穿倒羊刃 / 禄神，且无解救
五标志须同时满足「局中已成结构」和「岁运引动」两层，且先查有无制化与解救。
```

#### 14_4_1 逐条详解

#### 14_4_2 标志一：官杀作忌无制化

```plain
成立条件：
    官杀为忌神，对日主不利
    无印化、无食伤制
    官杀贴身克身（月干、时干或日支相邻）
    岁运再见官杀或引动原局官杀
不成立条件：
    有印星化杀生身
    有食伤制杀且制化得力
    官杀虽透但远在年柱、不贴身
    岁运制住官杀、转成用神
「贴身」很重要：官杀在年柱远，影响小；在月干、时干贴着日主，压力直接。
```

#### 14_4_3 标志二：食伤被枭印夺尽

```plain
成立条件：
    食伤原本是命局的生机或作用之神
    枭印出现并克制食伤
    食伤无根、无财破枭、无比劫分印
    岁运再见枭印或夺食结构被引动
不成立条件：
    食伤并非命局关键用神
    有财星制枭护食
    有比劫泄枭，使其不专夺食
    原局虽有枭印，但岁运不见夺食
「枭神夺食」为什么主牢狱？食伤主自由表达与行动，被枭印夺尽 = 失去自由。
```

#### 14_4_4 标志三：伤官见官，力量相当

```plain
成立条件：
    伤官与官杀同时出现
    两者力量接近，谁也制不住谁
    无财通关、无印缓冲、无合解交战
    岁运再引动交战，冲突外显
不成立条件：
    伤官有力制住官杀（伤官去官）
    官杀有力制住伤官，且日主能受生受护
    有财星通关，伤官生财、财再生官
    合住一方，交战实际不成立
这一条最考验判断力：同样的「伤官见官」，制得住是贵，制不住是祸。差别全在力量对比。
```

#### 14_4_5 标志四：金水沉陷

```plain
成立条件：
    金水一片，金沉水底、不得火暖
    全局晦暗无光，缺少调候与泄路
    财、印、食伤难作正当通路
    岁运再增水、埋金，暗昧性质被引动
不成立条件：
    有火暖局，金水各得其用
    有木泄水、有土制水，金有出路
    金水虽多，但格局另有清贵组合
    岁运引入暖神，沉陷被解
「沉陷」的象：金沉在水底，见不到光 = 暗无天日 = 牢狱。
```

#### 14_4_6 标志五：穿倒羊刃 / 禄神

```plain
成立条件：
    羊刃或禄神被穿倒
    无合解救、无印护根、无岁运补根
    被穿之神又是身体或全局关键
    岁运再冲穿，破损被引动
不成立条件：
    虽有穿，但同时有合解或六合解救
    羊刃本为忌，制伏后反成权柄
    禄根另在月令、日支有根基
    岁运补根、通关，破损不成立
「穿倒正印归西去」：正印被穿倒，主大凶。印是庇护，庇护倒了，人就没依靠了。
```

#### 14_4_7 牢狱判断的统一口径

```plain
第1步  先确认属于五标志中的哪一条
第2步  检查成立条件与不成立条件
第3步  看制化之神是否存在、是否被岁运引动
第4步  有解救则降为倾向，无解救才提高关注
第5步  至少三条独立证据指向同一方向
引动方式：官星被冲 → 官方行动；忌神到位 → 出事；岁运激怒旺神 → 爆发。
完整案例见板块 18（牢狱命定、黑道头目、小偷与盗贼、少年犯四个完整故事）。
```

#### 14_4_8 表达纪律（牢狱类）

```plain
✓  「这个阶段在规则、法律边界上需要格外谨慎」
✓  「冲动行事容易带来麻烦，宜守不宜攻」
✗  「你会坐牢」
✗  「你有牢狱之灾」
牢狱类断语的伤害性极大，且容易变成自我实现的暗示。给「行为建议」而非「结果断言」，是更负责的做法。
```

### 14_5 死亡信息与寿元

#### 14_5_1 四大标志

```plain
标志一  禄神重见（伏吟）：「禄走了」主寿终
标志二  寿元星（食神 / 禄 / 印）入墓被坏
标志三  用神尽毁，体用俱伤
标志四  冲提纲（月令），老年逢之主亡
```

#### 14_5_2 逐条详解

#### 14_5_3 标志一：禄神重见（伏吟）

```plain
成立条件：
    禄神在大运或流年再次出现
    原局禄根本已受冲、受穿或被合化
    无印生、无比劫帮扶
    岁运又无解救，伏吟被引实
不成立条件：
    禄神虽重见，但另有根基与护卫
    重见之字被合住、转化，不形成伏吟
    全局气脉顺畅，伏吟仅主反复而非寿损
「禄神为命根，最怕复吟与财星坏」：禄是自己的根，根重复出现意味着「根要走了」。
```

#### 14_5_4 标志二：寿元星入墓被坏

```plain
成立条件：
    寿元星为食神、禄或印
    入墓且同时被刑、冲、穿、克
    无冲墓、无合墓、无生扶出墓
    岁运再填墓或再坏寿元星
不成立条件：
    虽入墓但墓库被冲开、有生扶出墓
    寿元星另在他支有根
    墓中还有救应之神（如印护食）
```

#### 14_5_5 标志三：用神尽毁，体用俱伤

```plain
成立条件：
    体（印、比、食伤、禄）与用（财、官）同时受损
    全局无可扶、无可救
    大运连续破坏关键结构
    流年再无通关、解救之神
不成立条件：
    虽然局部受损，但另有用神可用
    岁运出现新的通关之神
    原局尚有暗根、伏吟之外有救
```

#### 14_5_6 标志四：冲提纲

```plain
成立条件：
    提纲为月令
    老年大运或流年冲月令
    月令本为命局关键，冲之全局动摇
    无合解、无岁运补救
不成立条件：
    冲提纲但月令非关键用神
    有合解冲（如子午冲遇丑合子）
    中青年逢冲，更多主变动而非寿元
    岁运另有护卫，提纲损伤被缓冲
```

#### 14_5_7 寿元证据层级

```plain
第一层  原局结构：四标志是否真实成立
第二层  岁运引动：是否恰好走到对应大运、流年
第三层  护卫情况：印、根、食伤能否解救
第四层  多重校验：至少三条独立证据指向同一结论
缺少任何一层，都应降级为「健康或重大变动需留意」，不得直接断言寿元。
```

#### 14_5_8 表达纪律（生死类，最高级别）

```plain
涉及生死的推断：
    ✓  证据链必须完整（至少三条独立证据指向同一结论）
    ✓  以倾向性表述呈现
    ✓  绝不主动提及，除非对方明确问到相关方向
    ✓  考虑对方承受能力
    ✗  绝对化断言
    ✗  给具体时间点
    ✗  在对方脆弱时直断
回顾板块 0 的讳辞原则：有时讳辞是人道，但笔记里要如实记录「我当时没敢直断」，不事后美化。
```

**▲实操**：拿一张真实八字，按本单元的「死亡信息与寿元」完整走一遍：先写下你的结论，再写依据的干支，最后写你不确定的地方。走满三张盘回看，重复出错的那一步就是没真懂的地方。

### 14_6 盘例一：翻车，脊柱受损

#### 14_6_1 盘面

```plain
坤造：壬申  辛亥  壬辰  己酉
大运：庚戌  己酉  戊申  丁未
现实反馈：翻车，脊柱骨折
```

#### 14_6_2 推理链

```plain
辰为车
    申亥穿
    水多木折
「驿马逢冲，血光之灾」
水泛木浮  →  对应脊柱损伤（木主筋脉脊柱）
```

#### 14_6_3 结构拆解

```plain
车象（辰）被申亥穿所引动
    ↓
水势滔天（壬、申、亥、辰）
    ↓
木（筋脉、脊柱）被水泡 / 被折
    ↓
应：翻车，脊柱骨折
```

#### 14_6_4 护卫与应期

```plain
护卫判定：
    日主壬水虽旺，但被申亥穿、辰土混浊
    全局金水一片，木无根、火不透
    无明现通关或缓冲，故结果偏重
应期：
    戊申运申金引动申亥穿，车象与水势同步被引
    流年逢寅冲申、或再填水势时，风险窗口出现
    完整应期法则见板块 7
学习点：落点是「脊柱」，用的是「木主筋脉脊柱」这条体象维度的取象（区别于脏腑维度）。两个维度的区分见板块 13。
```

### 14_7 盘例二：车损人安

#### 14_7_1 盘面

```plain
乾造：乙卯  戊子  庚寅  丙戌
大运：丁亥  丙戌  乙酉  甲申
现实反馈：车祸轻伤，车辆报废
```

#### 14_7_2 推理链

```plain
寅为车
    申运冲寅
「七杀有制化为权」
    丙火护主
    →  人安车损
关键：同样遭遇车祸，此造丙火（七杀）有制反成护卫，结果是「车损人安」——正印证了 14_1 的原则。
```

#### 14_7_3 应期与可复用规则

```plain
应期判断：
    原局寅为车象，申寅相冲是潜在冲车结构
    甲申运申金到位，冲寅被引动
    丙火透干，七杀有制，故人安而车损
    完整应期法则见板块 7
可复用规则：断灾祸先看有没有护卫
判断清单：
  □ 日主有没有根、有没有印生？
  □ 官杀有没有被制化（制住则反成护卫）？
  □ 被冲的那个字有没有生扶？
三条里有一条成立  →  严重程度降一档
```

### 14_8 盘例三：溺水

#### 14_8_1 盘面

```plain
坤造：丁酉  壬子  丁卯  辛亥
大运：癸丑  甲寅  乙卯  丙辰
现实反馈：乙卯运庚午年溺水亡
```

#### 14_8_2 推理链

```plain
禄印双毁
    子卯刑
「杀重身轻，印被财坏」
禄被水克  →  应水灾
```

#### 14_8_3 应期与可复用规则

```plain
应期判断：
    原局子水旺而禄印受损，溺水之象已伏
    乙卯运木旺，水泛木浮，禄根不稳
    庚午年官杀与火金介入，关键结构被进一步引动
    无有效护卫，故结果最重
    完整应期法则见板块 7
可复用规则：水旺克火、禄被水克 → 水厄方向需留意
边界：
  ✓ 看水是否成势、火是否有根
  ✓ 看禄与印有没有被坏
  ✓ 看岁运有无木泄水、土制水或火暖局
纪律：
  ✓ 说「近水活动、涉水出行需要格外谨慎」
  ✗ 说「你会溺水」
```

### 14_9 盘例四：寿元与四库

#### 14_9_1 盘面

```plain
乾造：庚辰  己丑  癸未  壬戌
大运：庚寅  辛卯  壬辰  癸巳
现实反馈：68岁病逝
```

#### 14_9_2 推理链

```plain
四库全（辰戌丑未俱全）
    禄印俱损
「气浊神枯，用神被拔」
「四库全」为什么凶？四库都是土，土多则浊；且四库互相冲刑，内部不安定。
```

#### 14_9_3 应期与可复用规则

```plain
应期判断：
    原局辰戌丑未并见，土重气浊
    禄印受损，关键结构先天不稳
    壬辰、癸巳运再动土局与根基，寿元方向风险上升
    即使有此类结构，仍只能作倾向判断，不预告时间点
    完整应期法则见板块 7
可复用规则：四库全 + 禄印俱损 → 全局失衡，寿元方向需留意
边界：
  ✓ 看四库之间是否形成冲刑（内部不安定）
  ✓ 看禄与印有没有被坏
  ✓ 看有没有解救
纪律：
  ✓ 生死类只给倾向，不给时间点
  ✓ 绝不主动提及
```

### 14_10 灾祸判断的完整流程

四组盘例已分别展示车祸、水厄与寿元。本节把护卫、成立条件、证据校验和出口表达统一成可复用的七步流程。

```plain
第1步  定全局的失衡点（哪一行成势为病）
第2步  定灾祸类型（车象？水火？刑伤？）
第3步  找有没有护卫 / 解救（决定严重程度，灾祸判断的核心）
第4步  定性质（急性冲 / 慢性穿）
第5步  定应期（见板块 7：流年激病、寿元星被坏、伏吟、墓库）
第6步  多重证据校验（至少三条独立证据）
第7步  出口（给方向不给诊断，倾向性表述）
```

#### 14_10_1 三条不可逾越的底线

```plain
底线一  不制造恐慌：「这个阶段宜守不宜攻」≠「你有灾」
底线二  不绝对断言生死：给倾向，不给时间表
底线三  给行为建议而非结果断言：「规则边界上需要谨慎」≠「你会坐牢」
```

#### 14_10_2 寿元表达禁区清单

```plain
✗ 不主动宣布寿元结论
✗ 不给具体年份、月份或日期
✗ 不把四标志之一单独当作定论
✗ 不用「必亡」「寿终」「大限」等恐吓措辞
✗ 不在对方情绪脆弱时继续展开
✓ 可提示健康方向、建议正规体检与就医
✓ 可给「宜守、宜稳、避免高危活动」的行为建议
```

**▲实操**：拿一张陌生盘，按「灾祸判断的完整流程」的步骤完整走一遍，把每一步的判断依据写下来；卡住的那一步就是没学会的地方。
