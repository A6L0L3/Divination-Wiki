## 板块3 · 象法基础：带象、换象、共象、化象

> 象法是把干支符号翻译成生活画面的技术。做功告诉你「这个命局在干什么」，象法告诉你「干的到底是什么事」。

### 3_1 象法总纲：读象而非算数

#### 3_1_1 核心观念

干支、十神、宫位皆为「象」。**命理的本质是读象，不是算数。**

象有万千，但只有两类是核心：

```plain
核心象一：做功之象  （谁制谁）
核心象二：宾主之象  （成果归谁）
```

其余的象（干支物象、宫位象、神煞象）都是辅助，用来给核心象「填肉」。

#### 3_1_2 三个必记的虚实心法

```plain
虚透  =  象  →  主名气、才华、表象、远方、精神层面
落实  =  质  →  主实质、身体、落地之事、近处、物质层面

虚看名，实看利
虚怕克，实怕坏
```

虚透之字（无根无生）本来就只是个「名」，再被克一下，名就没了——所以「虚怕克」。实字（有根有生）是实打实的东西，最怕被「坏」（穿、破、冲掉根）——所以「实怕坏」。

#### 3_1_3 象法的定位

```plain
命局  =  基因（有什么）
岁运  =  触发器（什么时候触发）

「原局如镜，岁运如光」
    镜中无物，光照亦空
```

原局没有的象，岁运再怎么照也照不出来。学象法最容易犯的错误就是看到流年某个字就开始编故事——先回原局确认这个象在不在。

**微实例：** 1_6 用一张盘（乾造 庚戌 己卯 戊子 癸亥）走完「分宾主 → 定体用 → 论做功」。按本节口径复读一遍会发现顺序不能颠倒：先定「谁制谁」（做功之象），再定「成果归谁」（宾主之象），最后才轮到干支物象去填肉。前两步不定，第三步的象一定落空。

### 3_2 带象

#### 3_2_1 什么是带象

**干生支的十二柱，支带有干之象。**

```plain
甲午  乙巳  丙戌  丙辰  丁未  丁丑
戊申  己酉  庚子  辛亥  壬寅  癸卯
```

这十二柱的共同点：天干生地支，于是地支「带上了」天干的信息，一个柱同时表达两层意思。

#### 3_2_2 最有用的两种带象

#### 3_2_3 官杀带财帽

```plain
戊申、庚子  =  管钱的官
    象：财政、银行方向
    解读：官杀（权力）戴着财（钱）的帽子 = 管钱的权力
```

#### 3_2_4 印带官杀帽

```plain
壬寅、癸卯  =  有权的文化官员
    象：校长、书记方向
    解读：印（文化、学历）戴着官杀（权力）的帽子 = 有权的文化人
```

#### 3_2_5 带象的成立条件（易漏）

```plain
条件：带象必须与主位发生关联才论
     →  该柱落在日时，或与日柱发生合冲刑穿

孤立存在的带象不作数
```

这是带象最常被误用的地方。看到年柱有个戊申就断「金融」，但年柱是宾位、又和日主没关系，这个象就不落在命主身上。

### 3_3 换象：禄与原身

#### 3_3_1 十干禄位（必背）

```plain
甲禄在寅      乙禄在卯
丙禄在巳      丁禄在午
戊禄在巳      己禄在午
庚禄在申      辛禄在酉
壬禄在亥      癸禄在子
```

其中丙与戊共禄于巳，丁与己共禄于午。

#### 3_3_2 原身

**原身 = 地支在天干做事。** 禄是天干在地支的「家」（根），原身是地支在天干的「代言人」。两者互通，可以互相换位理解。

#### 3_3_3 半禄与四墓库

```plain
半禄：丁未、癸丑
    原因：丙戊半通禄、丁己半通禄，巳为双原身所致

四墓库（辰戌丑未）没有原身
    这是硬规则：墓库不参与原身的换算
```

#### 3_3_4 换象最核心的用途：应期工具

禄与原身出现，即为「到位」的一种形态。

```plain
原局有寅  →  流年见甲（寅的原身）= 寅到位
原局有庚  →  流年见申（庚的禄）  = 庚到位
```

到位的三种形态（原字到位、禄到位、原身到位）及其边界条件，完整法则统一放在板块 7_2「定律一：到位」，本板块只记骨架。

#### 3_3_5 口径提醒（易混，3 行记住）

```plain
天干通地支  →  取地支本气 / 墓库定位（戊通戌、己通丑），用于板块 8 排星
十干禄      →  禄位口径（戊禄在巳、己禄在午），用于换象与原身
两套名字接近、用途不同，切勿混用
```

**▲实操**：用「换象」的方法在同一张盘上取三个象，逐个写明干支依据，再挑一个最能落地的写进命例卡。

### 3_4 共象原则

#### 3_4_1 定义

**干支象 + 宫位象 + 十神象，两类以上指向同一事物即可定象。**

```plain
单独一个象  →  只是线索
两个象同指  →  倾向成立
三个象同指  →  可以定象
```

#### 3_4_2 经典示例：时上丁火 = 眼睛

```plain
第1象  干支象：丁火有「目」之象
第2象  宫位象：时柱有「孔窍」之象
第3象  十神象：丁为食神，食神有「窍」之象

三象同指  →  定象：眼睛
```

任何一个单独的象都有太多种可能。丁火可以象眼睛、灯火、心脏、文书。只有加上宫位（孔窍）和十神（窍）的限定，才收敛到「眼睛」这一个答案。

#### 3_4_3 共象的实操流程

```plain
第1步  列出这个字的三层象：干支物象、宫位象、十神象
第2步  找交集：有没有一个事物同时被两层以上指向
第3步  有交集 → 定象；无交集 → 只作倾向，不断
```

#### 3_4_4 象法纪律（必须遵守）

```plain
纪律一：单一象不下结论
纪律二：多象互证再定象
纪律三：定象结果以倾向性表述呈现
```

纪律三是保护自己的。即便三象同指，说出来的也应该是「这个方向值得留意」，而不是「你一定是干这个的」。

**▲实操**：用「共象原则」的方法在同一张盘上取三个象，逐个写明干支依据，再挑一个最能落地的写进命例卡。

### 3_5 化象原则

#### 3_5_1 定义

**两个象经会合生化成复合新象。**

与共象的区别：

```text
共象  =  多个象指向同一事物（求交集）
化象  =  两个象反应生成新事物（起化学反应）
```

#### 3_5_2 经典示例：阴木生火 = 丝线加工

```plain
阴木（乙、卯）  象：丝线、纤维、柔软的植物
火              象：加工、炎上、转化

阴木生火  →  丝线被加工  →  织物、服装
    →  可断：纺织、刺绣相关行业
```

#### 3_5_3 化象的构造思路

```plain
原料象  +  加工象  =  成品象

例：金（金属）+ 火（熔炼）= 钢铁、机械
例：水（流动）+ 木（生长）= 物流、贸易
例：土（承载）+ 木（架构）= 建筑、土木
例：水（钱币）+ 金（金融）= 银行、财务
```

#### 3_5_4 化象用于取象的三步

```plain
第1步  找出命局里最有力的那组生 / 制关系
第2步  把「被生的一方」读成原料，「生它的一方」读成加工方式
第3步  合成成品象，再对应到现代行业
```

注意时代转换：古代「金火交炼」是打铁，现代是钢铁、机械、电焊。象要跟着时代走，完整行业取象见板块 10。

**▲实操**：用「化象原则」的方法在同一张盘上取三个象，逐个写明干支依据，再挑一个最能落地的写进命例卡。

### 3_6 干支自合与干支互通

#### 3_6_1 干支自合

**自合 = 天干与坐支藏干相合**，即「自己合自己」。

| 自合柱 | 藏干构成 | 象义 | 注意 |
| :--- | :--- | :--- | :--- |
| **丁亥** | 亥中壬（官）、甲（印） | 丁壬合，官印相生，主贵气、自律 | 官印同宫 |
| **戊子** | 子中癸（财） | 戊癸合，财来就我，主富足、精明 | 戊土克之，财星受制 |
| **辛巳** | 巳中丙（官） | 丙辛合，官来合身，主名誉、婚姻 | 官星有情 |
| **壬午** | 午中丁（财）、己（官） | 丁壬合，财官双美，主富贵、姻缘 | 财官同宫 |
| **癸巳** | 巳中戊（官）、丙（财） | 戊癸合，官财相生，主稳定、务实 | 官财同源 |

#### 3_6_2 自合的取象

```plain
自合主：内心矛盾、自我约束，或夫妻恩爱（视位置而定）
落在日柱（自己）        →  内心矛盾、自我约束、自我要求高
落在夫妻宫 / 合到配偶星  →  夫妻恩爱、关系紧密
```

天干与坐下藏干本为一体，现在天干去合自己坐下的藏干——等于自己在跟自己较劲，内耗感强、自我要求高。

#### 3_6_3 干支互通表（背诵级）

干支互通是象法的底层字典，核心内容已在 3_3（禄与原身）给出，建立在三个支点上：

```plain
支点一  十干禄位（甲寅、乙卯、丙巳、丁午、戊巳、己午、
                庚申、辛酉、壬亥、癸子）
支点二  地支原身（地支在天干做事，即禄位的反向）
支点三  四墓库无原身（辰戌丑未不参与换算，硬规则）
```

#### 3_6_4 干支互通在取象上的具体用法

互通不只是应期工具，更是**扩象工具**——同一个象可以借禄、原身「借道」表达。

```plain
用法一  借道扩象
    例：原局有申无庚 → 申的金气借原身庚透出，金象落在申与庚两处
用法二  借道找关联
    例：某柱有寅、另一柱有甲 → 寅甲互通，两柱多出一层隐性关联
用法三  借道补象
    例：金象不明显但有申酉 → 借申之原身庚，金象成形
```

口诀：互通是「借道」，不是「新增」。前提是原局确有那个地支，不能凭空借出。

#### 3_6_5 自合与互通的区别（易混点，必记）

| 维度 | 干支自合 | 干支互通（禄与原身） |
| :--- | :--- | :--- |
| 关系本质 | 天干与坐支藏干相合（合） | 天干与禄位 / 原身互换（换） |
| 发生位置 | 限定在同一柱内 | 不限柱，全命局可换 |
| 主要用途 | 取性格与关系象（内心矛盾、夫妻） | 扩象、找关联、应期到位 |
| 作用方向 | 一柱之内自我作用 | 跨柱借道 |
| 例 | 丁亥、戊子、辛巳等五柱 | 寅与甲、申与庚互认 |

自合是「自己和自己合」（同一柱、取性格关系象），互通是「换个名字用」（全命局、取扩象与应期）。

**常见误用：** 看到戊子就当成「戊与巳互通」。错。戊子是自合（戊合坐下子中癸），戊与巳才是互通（戊禄在巳）。一个是合藏干，一个是认禄位，不是一回事。

#### 3_6_6 背诵建议

先背禄位（十组），再理解原身（禄位的反向），最后记住墓库例外。不必一次背完，用三十张盘练下来自然就熟了。

**▲实操**：拿一张真实八字，按本单元的「干支自合与干支互通」完整走一遍：先写下你的结论，再写依据的干支，最后写你不确定的地方。走满三张盘回看，重复出错的那一步就是没真懂的地方。

### 3_7 象法纪律与常见误用

#### 3_7_1 五条纪律

```plain
第1条 单一象不下结论（至少两层同指）
第2条 原局没有的象，岁运照不出来（镜中无物，光照亦空）
第3条 带象必须与主位有关联才论
第4条 四墓库无原身，不参与原身换算
第5条 结果以倾向性表述呈现，不铁断
```

#### 3_7_2 三种最常见误用

**误用一：见象就断，不管宫位和关联。** 看到年柱有金融象就断命主做金融。年柱是宾位，与日主无关联的话，这个象是别人的、是社会环境的。

**误用二：用象法替代做功。** 象法是「填肉」，做功是「骨架」。没有做功支撑的取象，就是凭空联想。正确顺序：先定做功，再取象。

**误用三：象越取越花，忘了收敛。** 一个字能取十个象，高手和新手的区别在于**会不会收敛**。收敛靠的是共象（求交集）和做功（定主次）。

#### 3_7_3 收敛练习：三层提问法

发现自己发散时，用这三个问题把自己拉回来：

```plain
问题一  这个象在原局里有没有？（没有就删掉）
问题二  它落在宾位还是主位？（宾位的不属于命主）
问题三  它和做功链条有没有关系？（无关的是次要象）
```

三个问题问完，通常只剩下一两个象站得住。
