# 板块8 · 串宫压运十二神
> 串宫压运是盲派的流年快断工具：**完全不看五行生克，只按十二神的排列组合读一年吉凶。**  
> 它与生克系统并行不悖：生克管大势，串宫管年运快照，两套并用互校。

## 8_1 十二神顺序与起法
### 十二神顺序（必背）
```plain
 1          2          3          4          5          6
太岁   →   青龙   →   丧门   →   六合   →   官符   →   小耗

 7          8          9         10         11         12
大耗   →   朱雀   →   白虎   →   贵神   →   吊客   →   病符
```

**记忆口诀（按顺序串读）：**

```plain
太岁青龙丧门六合官符小耗
大耗朱雀白虎贵神吊客病符
```

### 起法：以流年地支起太岁，顺排十二神
```plain
规则：流年地支 = 太岁
      从太岁开始，按十二地支顺序顺排十二神
```

**示例（卯年）：**

```plain
地支：  卯      辰      巳      午      未      申
星：    太岁    青龙    丧门    六合    官符    小耗

地支：  酉      戌      亥      子      丑      寅
星：    大耗    朱雀    白虎    贵神    吊客    病符
```

从流年地支起太岁，然后按地支顺序依次配上十二神。

### 天干通地支（用于天干定位）
```plain
甲通寅    乙通卯    丙通巳    丁通午    戊通戌
己通丑    庚通申    辛通酉    壬通亥    癸通子
```

**口径提醒（易混，必看）：**

```plain
此处「通」  =  取地支本气 / 墓库定位（戊通戌、己通丑）

与十干禄不同：
    十干禄：戊禄在巳、己禄在午（禄位口径）

两套口径用途不同：
    天干通地支  →  用于串宫压运排星（本板块起例）
    十干禄      →  用于换象与原身（见板块 3）
```

混用一次，星排错一位，后面整年读象都会偏。

### 四柱分四季
```plain
年  =  春      月  =  夏
日  =  秋      时  =  冬

天干  =  管上半季
地支  =  管下半季
```

一年被切成八个时间段，可以更细地定位「这件事大概发生在哪个时段」。

### 大运十二神：一年的根本基调
```plain
大运十二神  =  一年的根本基调
    大运凶  →  全年基调偏凶
```

大运基调不好，流年再好的星也要打折。


## 8_2 归类速查表
### 六大类
| 类别 | 相关星 |
| :--- | :--- |
| **破财** | 大耗、小耗、丧门 |
| **贵人** | 青龙、六合、贵神 |
| **是非官非** | 朱雀盖头、白虎、官符配凶 |
| **婚恋喜庆** | 六合、青龙、贵神、官符配吉 |
| **疾病** | 病符、白虎力弱、小耗、丧门 |
| **孝服老人** | 丧门与吊客同现，或两者多见 |

### 逐类解读
#### 破财类：大耗、小耗、丧门
```plain
大耗  =  大额支出、重大损耗（「大出血」）
小耗  =  小额破财、日常损耗（「细水长流地漏财」）
丧门  =  因丧事、孝事而破财（被动花钱）
```

#### 贵人类：青龙、六合、贵神
```plain
青龙  =  喜庆、吉庆、有好事
六合  =  合作、婚姻、人际和谐
贵神  =  贵人相助、逢凶化吉
```

#### 是非官非类：朱雀盖头、白虎、官符配凶
```plain
官符  =  与官方、文书、职位相关（中性，配吉则吉、配凶则凶）
朱雀  =  口舌、是非、争吵
白虎  =  凶灾、血光、意外
```

「官符配吉主婚恋喜庆」与「官符配凶主官非」并不矛盾——正式文书既可以是升职令，也可以是结婚证。

#### 婚恋喜庆类
```plain
六合      →  合作、婚姻之象
青龙      →  喜庆
贵神      →  有人帮忙撮合
官符配吉  →  正式文书（领证）
```

#### 疾病类
```plain
病符      =  生病、健康出问题
白虎力弱  =  不是大凶灾，但身体有伤
小耗      =  小病小痛
丧门      =  重病、老人健康
```

#### 孝服老人类
丧门与吊客同现，或两者多见 → 主孝服、老人之事。不一定要同现，出现得多就有这个象。


## 8_3 吉凶盖头规则
同一颗星盖在另一颗星上，吉凶会翻转。本节讲三条盖头规则。

### 三条规则
```plain
规则一  吉星被凶星盖头  =  凶
规则二  凶星被吉星盖头  =  减半或不凶
规则三  白虎不可被任何星盖头  =  盖必见凶
```

### 「盖头」是什么
盖头指天干对地支的压制关系——某个柱的天干（星）盖在它下面的地支（星）上，上面的星影响下面的星的吉凶表现。

### 盖头规则速查图
```plain
        ┌─────────────┐
        │  天干（盖）  │  ← 上面的星
        ├─────────────┤
        │  地支（被盖）│  ← 下面的星
        └─────────────┘

吉盖吉    →  吉
吉盖凶    →  凶减半 或 不凶   ← 规则二
凶盖吉    →  凶               ← 规则一
凶盖凶    →  大凶
白虎被盖  →  必见凶           ← 规则三（例外）
```

### 规则三要特别注意
白虎是唯一「不可被盖」的星，吉星盖它也见凶，凶星盖它更凶。白虎的凶性刚猛直接，不像其他凶星可被吉星缓冲。遇到白虎，只能提前防范。

### 太岁落支的特殊规则
```plain
流年太岁落在地支  →  即为凶论

这里的「凶」特指：动象大、压力重、事体多变动
具体吉凶方向仍须回归原局喜忌与盖头组合综合判定
```


## 8_4 进阶：胎元、命宫、身宫
把同一套十二神排到胎元、命宫、身宫上，观察窗口就从四柱 4 个扩展到「四柱 + 三宫」共 7 个，形成多点互证。

### 胎元：取法、示例、含义
胎元是受胎之月的干支，取法——月干顺进一位、月支顺进三位（均按六十甲子次序向前数）：

```plain
胎元  =  月干顺进一位  +  月支顺进三位
```

**示例（甲子月）：**

```plain
月干甲  →  顺进一位  →  乙
月支子  →  顺进三位（子→丑→寅→卯）→  卯
胎元  =  乙卯
```

**易错提示：** 天干顺进一位、地支顺进三位，位数不同，不要都按「一位」算；顺进是向前数，不要逆推。

**在串宫里的角色：** 胎元代表先天禀赋与根基，读的是「这一年对先天根基的影响」，与其他六点同参。

### 命宫：取法、示例、易错提示
通行口诀是「卯起正月，顺数到生月，落宫逆行回卯」：

```plain
第1步  从「卯」起正月，顺数到生月，得到该月落的地支
第2步  把这个地支放在「生时」上，从生时支逆数，数到卯为止
       落点所在的地支 = 命宫
```

**示例（生月五月、生时子时）：**

```plain
第1步  卯起正月：卯(正)、辰(二)、巳(三)、午(四)、未(五)
       生月五月落「未」

第2步  把「未」放到生时「子」上，从子逆数回卯：
       子(未)、亥(申)、戌(酉)、酉(戌)、申(亥)、
       未(子)、午(丑)、巳(寅)、辰(卯)  ← 数到卯停
       落点为「辰」，故命宫 = 辰
```

**易错提示：**

```plain
易错一  月份按节气划分，不是按农历初一
易错二  第1步顺数、第2步逆数，方向别搞反
易错三  数到「卯」就停，不要继续往下数
```

手工推算出错率较高，排盘后用工具核对一遍再取用。

**在串宫里的角色：** 命宫代表性格重心与主太极点，读的是「这一年落在命主主太极点上是什么星情」，偏向内在的、持续性的倾向。

### 身宫：取法、对应关系、角色
身宫与命宫同构，仅行进方向相反：命宫顺数、身宫逆数。

```plain
身宫取法  =  与命宫同构，仅「顺数 / 逆数」方向相反
身宫又称「真我」：代表行为动机与更深层的自我参照
```

两者从同一组生月落点出发、行进方向相反，一个偏「性格定性」、一个偏「行为取向」。实务中先看命宫定基调，再看身宫定动机，互相校验。

### 七点观察法
```plain
四个柱：年、月、日、时
三个宫：胎元、命宫、身宫
    =  共七个观察点
```

```plain
        ┌──────┬──────┬──────┬──────┐
        │ 年柱  │ 月柱  │ 日柱  │ 时柱  │   ← 四柱
        └──────┴──────┴──────┴──────┘
        ┌──────┬──────┬──────┐
        │ 胎元  │ 命宫  │ 身宫  │           ← 三宫
        └──────┴──────┴──────┘

        共七个观察点 → 排同一套十二神 → 多点互证
```

### 七点如何与大运、流年同参
```plain
第1层  大运十二神  →  根本基调（权重最高）
第2层  流年十二神  →  排到七点上，得七个读象
第3层  七点互证    →  看七点是否指向同一件事
```

单看四柱等于只听一个证词，加上三点等于多问三个证人。七点同排一套星，若四五点都指向同一件事，可信度远高于单点。

### 使用纪律（核心）
```plain
多点互相印证才下判断
不凭单点铁断
```

七个点里只有一个点显示凶，其余都吉，那这个凶大概率不成立；反之，多个点同时指向同一件事，可信度就高。


## 8_5 与大运同参
### 两个层级的权重
```plain
大运十二神  =  根本基调（权重最高）
流年十二神  =  当年天气（叠加在大运之上）
```

**判断顺序：**

```plain
第1步  先看大运十二神（定基调）
    大运凶  →  全年基调偏凶，流年吉星也要打折
    大运吉  →  基调好，流年凶星的破坏力也有限
第2步  再看流年十二神（定当年的具体事件）
第3步  结合原局喜忌（定吉凶的实际方向）
```

### 串宫与生克的互校
```plain
串宫凶 + 生克也凶  →  高度可信，重点防范
串宫凶 + 生克吉    →  以生克为主，可能是有惊无险、虚惊一场
串宫吉 + 生克凶    →  以生克为主，可能是苦中作乐、表面风光
两套矛盾          →  以生克（原局喜忌）为主，串宫为辅
```

串宫是快断工具，不是最终裁决。最终的定性仍要回到原局生克。


## 8_6 完整操作流程
```plain
第1步  排流年十二神（以流年地支起太岁，顺排到四柱地支）
第2步  排大运十二神（定全年基调）
第3步  （进阶）排胎元、命宫、身宫的十二神
第4步  逐柱读象（结合归类速查表）
第5步  应用盖头规则（逐柱检查天干盖地支的关系）
第6步  七点互证（多个点指向同一象 → 可信；单点 → 不作数）
第7步  与原局生克互校
第8步  出口（倾向性表述，留有余地）
```

### 快速上手建议
**时间不够时的最小操作：**

```plain
只做第 1、2、4 步
    =  排流年星 + 看大运基调 + 查归类表
    →  已经能给出一年的大致方向
```

熟练之后再逐步加入盖头规则、三宫、互校。


## 8_7 演示：排一次十二神
用一个示例演示完整排法（不涉及具体命主，纯操作方法演示）。

### 设定
```plain
假设流年为卯年
命造四柱地支为：年支申、月支亥、日支寅、时支巳
```

### 第 1 步：起太岁
```plain
卯年  →  卯 = 太岁
```

### 第 2 步：顺排十二神到十二地支
```plain
地支：  卯      辰      巳      午      未      申
星：    太岁    青龙    丧门    六合    官符    小耗

地支：  酉      戌      亥      子      丑      寅
星：    大耗    朱雀    白虎    贵神    吊客    病符
```

### 第 3 步：查四柱各落何星
```plain
年支申  →  小耗
月支亥  →  白虎
日支寅  →  病符
时支巳  →  丧门
```

### 第 4 步：查归类
```plain
年柱小耗  →  破财类 + 疾病类
月支白虎  →  是非官非类（且白虎不可被盖）
日支病符  →  疾病类
时支丧门  →  破财类 + 疾病类 + 孝服类
```

### 第 5 步：初步读象
```plain
初读：这一年白虎落在月支（兄弟宫 / 社会环境位），
      且病符落日支（自己 / 配偶位），
      破财类星出现两处（小耗、丧门）

倾向：健康与环境压力方面需要留意，支出偏多
```

### 第 6 步：必须做的后续
```plain
第1步 看大运十二神（定基调，可能大幅修正上述读象）
第2步 应用盖头规则（看天干之星如何盖地支之星）
第3步 检查白虎是否被盖（白虎被盖必见凶）
第4步 七点互证（加上胎元、命宫、身宫）
第5步 回到原局生克互校（串宫为辅，生克为主）
第6步 倾向性表述出口
```

### 演示的三个提醒
```plain
提醒一  单点不作数
    读到「破财类星两处」，若其他五点都不支持，这个象不一定成立

提醒二  白虎要单独标记
    白虎无论被什么星盖都见凶，发现白虎先做防范提示

提醒三  千万别跳过第 6 步
    只做前五步就下结论，是串宫压运最常见的误用
```
