# 板块2 · 做功五结构与效率量化

> 板块 1 讲了「做功是什么」，本板块把它拆开：**具体有哪几种做法、哪种效率更高、拿到一张盘从哪下手。**效率表第一次不必全记，先当字典用。

## 2_1 五种做功结构

### 结构总表

| 结构 | 形式 | 常见组合 |
| :--- | :--- | :--- |
| **制用结构** | 体直接克制对方（最关键） | 比劫制财、财制印、印制食伤、食伤制官杀、官杀制比劫 |
| **化制结构** | 以化代制，化敌为友 | 化官生印、化杀生印 |
| **合制结构** | 以合作制 | 日元合财合官、羊刃合杀、食神合官、伤官合枭 |
| **墓制结构** | 以库收藏，待机而发 | 财官临库，喜刑冲开库 |
| **双制结构** | 两套制用并存且串联（最高端） | 比劫与食伤同制财官并制其原神 |

### 逐一拆解

#### 制用结构（最常见、最根本）

**形式：** 体直接克制对方，靠力量直接压过去。

```plain
比劫制财    →  出力气挣钱
财制印      →  用钱、资源换取资质、房产
印制食伤    →  用规范、学识去约束表达（教师、管理）
食伤制官杀  →  用技术、才华制服压力与权力（权柄来源）
官杀制比劫  →  管人、管团队
```

判断要点：制方有没有力、被制方有没有根。制方无根 = 制不住；被制方无根 = 一制就死。

#### 化制结构

**形式：** 不硬碰，而是把对方「化」过来为我所用。

```plain
化官生印  →  权力转化为资质、名声
化杀生印  →  压力、危机转化为学识、庇护（最典型的贵格之一）
```

与制用的区别：制用是「我把你打服」，化制是「我把你变成我的资源」。化制更省力、更高明，但对位置要求更严——必须有化神在中间且不受伤。

#### 合制结构

**形式：** 以合作制，用合住的方式控制对方。

```plain
日元合财合官  →  财官主动来找我，我伸手就能拿到
羊刃合杀      →  以刚制刚，武职、外科、高风险的象
食神合官      →  以才华、口才取得职位
伤官合枭      →  以偏才制偏门
```

合制效率往往很高，但需要条件——合财要身旺，合官要官强。合不住的合叫「合绊」，反而是牵制。

#### 墓制结构

**形式：** 财官临库，靠刑冲开库取用。财官藏在库里，不冲不发。

```plain
开库吉凶视库中所藏喜忌：
    放出喜用  →  得财官
    放出忌神  →  反招灾
```

三种状态：入墓收、出墓放、冲开则发。完整内容见板块 6。

闭库的情况要特别检查：库被合住（如辰酉合闭辰库）、被盖头（如壬辰，水盖土库）则为闭，闭则不发。很多人看到「有财库」就断富，问题往往出在库是闭着的。

#### 双制结构（最高端）

**形式：** 两套制用并存且串联。比如比劫与食伤同制财官，并且制其原神——既制了目标，又断了目标的补给。

为什么最高端？因为它制得更彻底：单制是「制住人」，双制是「制住人 + 断其粮草」，层次通常明显高出一截。

### 记忆口诀

```plain
直接制住    =  硬干
用合化      =  巧取
用墓库      =  收着等时机
两套一起制  =  高手局
```

## 2_2 十神做功价值排序

### 排序表（从大到小）

```plain
官杀  最大  ←  能制比劫者管人，多主权位
印    第二
比劫  第三  ←  体力劳动
食伤  第四
财    最小
```

### 怎么用这个排序

```plain
例：食伤制官杀  →  制的是「最大」的官杀  →  量级高，主权柄
例：比劫制财    →  用「第三」的比劫制「最小」的财
                    →  量级中等，主劳碌得财
```

重要限制：排序只用于估计方向，不作绝对富贵断语。制住了官杀不等于一定能当多大官，还要看制得干不干净、落在宾位还是主位、岁运有没有配合。

### 效率分级的补充规则

```plain
制用  >  化用  >  合用          （方式维度）
阳制阴  >  阴制阳               （阴阳维度）
同柱做功  >  异柱  >  遥隔       （距离维度：越近越有力）
```

「同柱做功效率最高」这条特别实用：同一柱内的干支互相作用（如天干克地支、干生支），力量最直接、不打折。

### 功分大小、效分久暂

```plain
制尽      =  大功
制不尽    =  小功

原局有功  =  久功（一辈子都有）
岁运之功  =  暂功（运过则止）
```

这一条是判断「爆发户 vs 长久富贵」的关键。原局有功的人，财富地位是结构自带的，可持续；全靠岁运引发的人，运一过就打回原形。

## 2_3 做功效率量化表

### 完整表格

| 作用方式 | 效率 | 备注 |
| :--- | :--- | :--- |
| 巳申合、巳酉合 | 最高 | — |
| 天干五合 | 高 | 需合财身旺、合官官强 |
| 丑未冲、辰戌冲 | 90% | 墓库能量最大 |
| 丑戌刑 | 80% | — |
| 寅申冲、巳亥冲 | 60% | — |
| 丑午穿、子未穿 | 50% 偏高 | — |
| 子午冲、卯酉冲 | 50% | 需一方力量占优 |
| 卯辰穿、酉戌穿 | 30% | 象法意义大于做功意义 |
| 寅巳、申亥 | 生多穿少 | 一般不算做功 |
| 申子、午未、亥卯、寅午 | 不做功 | 只论相生 |
| 寅巳申三刑全现 | 另论·高级刑伤功 | 力度远超单一冲穿；本表其余各行仅论两两相见的作用 |

### 三个使用要点

**要点一：先定「谁在制谁」，再查表。**

```plain
第1步 确定命局里哪一组力量在制另一组
第2步 找出它们的作用方式（冲？合？穿？刑？）
第3步 查表得到相对力度
第4步 回到全局校验：这个力度在这个命局里能不能成立
```

**要点二：表给的是相对力度，不是自动结果。**

最关键的备注是「**需一方力量占优**」。以寅申冲为例，表上标 60%，但如果双方力量接近，就不能单凭寅申冲直接断发财——60% 只是说「这组冲属于中等偏上力度」，成不成立还要看力量对比。

**要点三：注意「三刑全现」的例外。**

寅巳申三刑全现时，力度远超单一的寅申冲或巳申合，属于高级刑伤功，要另论。表上其余各行只论两两相见的情况。

### 纳音兼论：做功计数的校正技法

六十甲子纳音（如甲子乙丑海中金、丙寅丁卯炉中火）在盲派里**只作校正，不作主轴**——它用来对上面这份效率表的「份量」做微调，不单独定吉凶。

```plain
用法：正五行定做功方向，纳音五行做加减校正
    某一柱纳音与正五行同气  →  这一组做功的份量上提
    某一柱纳音与正五行相悖  →  这一组做功的份量打折

例：日柱正五行为金，纳音亦为金（如甲子乙丑海中金见金气）
    →  金这一党更实，制财的力量偏强
例：日柱正五行为金，纳音为火（火克金）
    →  金这一党虚一分，制财的力量偏弱
```

**三点纪律：**

```plain
纪律一  纳音不单独成断
    它只修正「多少」，不决定「有无」
    做功方向仍由正五行的生克制化定

纪律二  校正幅度要小
    纳音是微调系数，不是翻盘依据
    正五行显示「有做功」，纳音最多让它变强或变弱

纪律三  不要与「古法禄命」混为一谈
    唐宋古法禄命以年柱纳音为论命主轴
    盲派的纳音兼论只是计数的校正技法
    两者名字相近、用法不同
```

> 这条区分很关键：古法禄命（以《五行精纪》《兰台妙选》为代表）是「年柱纳音 + 神煞」的早期体系；本库的纳音兼论只是效率表的一个补充校正项，属于两套不同的东西。

## 2_4 微案例：效率表是拿来查的，不是拿来背的

### 示范盘

```plain
乾造：庚寅  辛巳  庚申  己卯

        年柱      月柱      日柱      时柱
天干    庚        辛        庚 ★      己
地支    寅        巳        申        卯
藏干    甲丙戊    丙戊庚    庚壬戊    乙
```

### 四步走（不动用背诵）

**第1步：日干有合吗？** 庚金日干，五合中庚不与其他天干直接论合（此处只论合正官正财）——没有。

**第2步：日支坐支是什么？** 日支申——**申是庚金的禄**。禄在自家座位上，说明力量在身边。

**第3步：找目标和制的方式。**

```plain
年支寅  =  庚金的偏财（木为金之财）
日支申  =  庚金的禄（体）
申禄冲寅财  →  用自己的禄去冲外面的财
```

**第4步：归类和查表。** 这就定位成了「**禄 / 比劫制财**」的做功方向，不是墓制、不是合化。

### 查表校验

```plain
查到效率表：寅申冲 60%，备注「需一方力量占优」

回头看全局：
    金党 = 庚（年干）+ 辛（月干）+ 庚（日干）+ 申（日支）= 四票
    木财 = 寅（年支）+ 卯（时支）= 两票
    金党明显压过木财  →  「力量占优」这条成立

结论：制财方向可成立
```

### 反设检验

**如果同一组冲出现在两边力量接近的盘上会怎样？**

```plain
金木力量接近  →  「力量占优」不成立
     →  不能单凭寅申冲直接断发财
     →  可能只是「有挣钱的想法，但竞争大、财来财去」
```

表给的是相对力度这一半信息，另一半（力量对比）必须由你回到原局去判断。

## 2_5 入手次序四问

拿到一张盘，按固定顺序问四个问题。**这个顺序本身就是优先级**：越靠前的越直接、越贴身。

```plain
第1步 日干有合吗？      （只论合正官正财）
第2步 无合看有生吗？    （月时干食伤贴身）
第3步 日干无功，看日支坐支是否做功
第4步 再看其他柱的禄神、比劫、印等体之物是否做功
```

**第1步 · 日干有合吗？** 日主合财、合官，意味着**目标主动贴上来**，这是最直接的做功，所以排第一。注意限定：只论合正官正财。

**第2步 · 无合看有生吗？** 没有合，就看有没有食伤贴身生（月干、时干的食伤）。食伤是日主生出来的产出，能不能变现是第二直接的路径。

**第3步 · 日干无功，看日支坐支。** 日主自己没动作，就看它坐的位置。日支是离日主最近的地盘，日支做功 = 在自己最核心的范围内发生作用。

**第4步 · 最后看其他柱的体。** 年、月、时柱上的禄、比劫、印等「体」之物是否参与做功，这是最外围的一圈。

顺序不能乱，因为它遵循「**由贴身到外围、由主到次**」。按这个顺序排查，能保证不会漏掉最关键的那组关系，也不会把次要结构误判成主导结构。

## 2_6 贼捕理论与围制月令

### 贼捕理论

**比喻：** 官杀 / 忌神是「贼」，制它的力量是「捕」。

```plaintext
制去忌神（贼）时  →  得忌神之喜
捕神旺，喜贼神出现  →  有贼可捕，立功
有捕无贼  →  反凶（空有一身本领无处使）
```

**成立条件（修正版）：**

```plain
第1步 贼捕需原局成势，岁运引发方验
第2步 若原局贼捕力量悬殊，则为假结构
```

看到「食伤制官杀」不要立刻断贵，先检查：制方（捕）成势了吗？被制方（贼）有根吗？力量悬不悬殊？

### 围制月令之杀（最高配置）

**形式：** 双食伤围攻月令七杀。

```plain
为什么特别？
    月令 = 全局能量最大的位置
    制住月令之杀 = 掌握全局最大能量源 = 权柄核心
    层次：制月令之杀 高于 制他柱之杀
```

### 食伤制官杀：干净 = 贵

```plain
食伤制官杀，制干净  =  贼被捕  =  秩序建立  =  一官清透显贵

成立条件：
    第1条 官星清透不杂（无其他官杀混杂）
    第2条 制方有力
    第3条 但不制过头（制太过则官死，反失其用）
```

「制过头」的临界点值得细品：制杀不是越狠越好——把杀彻底制死，等于把权力来源也消灭了。好的状态是「制住但不制死」，杀还在，但听我的。

### 与子平「食神制杀」的区别

```plain
子平：论生克吉凶，食神制杀 = 吉格
盲派：论做功效率，制的干净程度决定权柄大小
```

子平告诉你「这是贵格」，盲派进一步告诉你「贵到什么程度、权有多大」。

**表达纪律：** 以倾向性表述呈现，不铁断具体职位名称。可以说「有掌权之象、管人之权」，不说「某年当某长」。

## 2_7 废功与层次判断

### 三种废功

```plain
废功一：体弱不能制用
    工具太软，制不动目标，象：心有余力不足
废功二：用神太重制不住
    目标太大，工具不够，象：眼高手低
废功三：制神被坏
    干活的工具自己被打残了，象：中途遭遇变故、功败垂成
```

### 层次判断的四步

```plain
第1步  这个功在原局还是只在岁运？  →  原局有功 = 久功，层次有保障
第2步  制得干不干净？              →  干净 = 大功，不干净 = 小功
第3步  结构串联还是相悖？          →  串联 = 上升，相悖 = 内耗
第4步  制的目标落在宾位还是主位？  →  落主位 = 成果归自己
```

### 快速自查表

| 检查项 | 加分 | 减分 |
| :--- | :--- | :--- |
| 做功方式 | 同柱、合制、双制 | 遥隔、穿制 |
| 力量对比 | 制方明显占优 | 双方接近或被制方更旺 |
| 目标位置 | 用落主位 | 用落宾位且无合 |
| 结构形态 | 串联 | 相悖、废功 |
| 持续性 | 原局有功 | 仅岁运之功 |

## 2_8 盘例对照：库开与不开的差距

这组对照说明「墓制结构」成立与否的关键。三造都有金库（丑）、都透金财，结果却判若云泥。

### 三个正例

```plain
例一  乾：庚戌  丙戌  丁卯  辛丑
    财库丑被戌刑开，应：行丑运，聘任为一家大企业老总
    注：丙旺于丁，丙透合辛财 → 主他为别人创造财富（高级打工者）

例二  乾：甲申  辛未  丁丑  壬子
    坐支财库（丑）被冲开，应：资产几千万
    注：财库不冲则不能富

例三  乾：庚戌  己卯  戊子  癸亥
    年支戌合制卯木官星，官星统摄子水财星，应：房地产巨富
    骨架解析见板块 1，格局解析见板块 9，闭库检查见板块 6
```

### 关键反例

```plain
乾：丙午  庚寅  丁巳  辛丑
    时支丑 = 金库（财库），时干辛金透出
    但丑在原局不逢刑冲，现行运也不刑冲
    应：普通职员，只是收入较高而已
```

### 这一组对照说明了三件事

**第一，「有没有」不等于「得不得」。** 三造都有财库、都透金财，但只有库被打开的那个才发。

**第二，开库的方式要认全。**

```plain
冲开：辰戌冲、丑未冲
刑开：丑戌刑、寅巳申三刑
闭库：被合住（辰酉合闭辰库）、被盖头（壬辰，水盖土库）
```

**第三，财归谁要看透干和宫位。** 例一「丙透合辛财」，财虽开了却被别人合走——所以是企业老总而非老板。完整用法见板块 10。

### 可复用规则（写入笔记的边界栏）

```plain
规则：财官临库，喜刑冲开库则发
边界条件：
  ✓ 必须确认开库方式存在（原局或岁运有刑冲）
  ✓ 库中所藏为喜用（放忌神反招灾）
  ✓ 库未被合闭、未被盖头
  ✓ 财透出后被谁合住 → 决定财归自己还是归别人
反例存档：丙午 庚寅 丁巳 辛丑（有库不开 = 普通职员）
```
