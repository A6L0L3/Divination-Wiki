# 板块9 · 官命、格局与功名
> 本板块讲「权力」这条线：七种官命组合、过河拆桥格、去官去财格、禄与食神格，以及气势与病药。  
> 核心判断：**官的作用对象决定权力大小，制官的方式决定权力性质。**

## 9_1 官命七种组合
### 七种组合总表
| 组合 | 结构 | 主象 |
| :--- | :--- | :--- |
| **1. 官杀配印** | 杀印相生 | 文武兼备，印化杀，主权柄 |
| **2. 官杀配财** | 财生官 | 富而生贵，财为官源，主实权 |
| **3. 官杀配伤官** | 伤官去官 | 执法、改革、技术权威 |
| **4. 官杀配劫刃** | 羊刃驾杀 / 劫刃去杀 | 武职、公检法、高风险行业 |
| **5. 印星配财** | 财制印 | 房地产、财政、审计 |
| **6. 印星配伤食** | 印制食伤 | 文化、教育、学术 |
| **7. 印星配比禄** | 官禄格 | 俸禄、公职、稳定 |

### 逐组拆解与适用条件
#### 组合 1 · 官杀配印（杀印相生）
```plain
结构：印化杀，杀生印，印生身
象：文武兼备、有实权、有庇护
喜忌：喜印，忌财（财坏印则官源断）
```

印化杀的「化」字是核心——杀的压力被印转化成自己的资质与权力。行印运升迁，行财运罢官。

#### 组合 2 · 官杀配财（财生官）
```plain
结构：财生官杀，官杀护财
象：富而生贵、有实权（财是官的来源，权力有资源支撑）
```

与组合 1 的区别：组合 1 的权力来自资质与庇护（印），组合 2 的权力来自资源与财富（财）。前者偏清贵，后者偏实权。

#### 组合 3 · 官杀配伤官（伤官去官）
```plain
结构：伤官制官
象：执法、改革、技术权威
成立条件（三条缺一不可）：
    第1步 官杀必须有根（无根的官，制了也白制）
    第2步 伤官有力
    第3步 伤官不被印制（印克伤官，制官的工具被废）
```

若见财星通关（财泄伤生官），则格局破败，反主贪财坏印。**特殊格局需「纯粹」，杂则不贵。**

#### 组合 4 · 官杀配劫刃（羊刃驾杀）
```plain
结构：羊刃 / 劫刃 制 七杀
象：武职、公检法、外科、高风险行业
```

羊刃本身就是刚猛之物，用它去制七杀，是以暴制暴。所以主武职、手术刀、执法这类需要「下得了手」的行业。

#### 组合 5 · 印星配财（财制印）
```plain
结构：财克印
象：房地产、财政、审计
```

印主房产、文书、资质，财去制它 = 用钱去操作房产与资质 = 房地产、财政、审计这类「管钱管物」的行当。

#### 组合 6 · 印星配伤食（印制食伤）
```plain
结构：印克食伤
象：文化、教育、学术
```

食伤是表达、才华、输出，印去规范它 = 把才华纳入正轨 = 教育、文化传播。

#### 组合 7 · 印星配比禄（官禄格）
```plain
结构：印 + 比劫 / 禄
象：俸禄、公职、稳定
```

这一组主「稳」，不主大贵，但主安定。适合断那些一辈子在体制内平稳晋升的人。

### 七种组合的判断流程
```plain
第1步  找官杀（有官杀才有官命可谈）
第2步  看官杀旁边配的是什么（印？财？伤官？刃？）
第3步  对照七种组合定性
第4步  检查条件是否满足（有根、有力、不被坏）
第5步  看落在宾位还是主位（落主位 = 权归自己）
```


## 9_2 清贵断法：制的干净程度定贵气层次
上一节的七种组合回答「有没有官命」。这一节回答更细的一层：**贵到什么程度？** 结构原型见板块 2_6。

### 核心断语
```plain
食伤制官杀
    制的干净  =  贼被捕  =  秩序建立  =  一官清透显贵
```

关键词是「干净」——不是「制住了」就行，而是制得彻不彻底。

### 成立的三个条件
```plain
第1步 官星清透不杂（全局无其他官杀混杂）
第2步 制方有力，但不制过头（制得住，又没制死）
第3步 全局无其他官杀混杂（与第1步呼应，强调「清」）
```

「制过头」为什么不行？制方太重，把官杀彻底打死，就等于「贼被捕之后又被处死」——得不到官的贵气了。**制住但不制死，才是临界点。**

### 判断四步
```plain
第1步 数官杀位数       →  有几个官？几个杀？
第2步 查有无混杂       →  官杀混杂则不贵
第3步 看制方力量       →  制方有根有生、不逢空亡吗？
第4步 定贵气层级       →  清透得制 = 清贵
```

### 两个实战样本
**样本一 · 双丙围攻月令之杀**

```plain
某造：双丙围攻月令申中庚杀，制的干净
现实：命主任职税务部门执法岗，父亲银行行长掌职权
```

**样本二 · 金水伤官喜见官**

```plain
某造：金水伤官喜见官，时干丁火独发 = 调候兼官星
现实：命主国税局上班，父亲市长
```

两案共同点：都是「制得干净」的正面样本——官星清透、制方有力且不过头。

### 一个必须坦承的边界
```plain
这两案只能证明半边：

    ✓  已验证：清透得制  =  贵气兑现

    ⚠️  待验证：制不干净，或官杀混杂反主口舌官非

后者属同一理论的反面推论
    目前此类实战案例尚不充分
    暂记待验
```

正面有案例不等于反面自动成立——**这种坦率是知识库应有的态度。**

### 可复用规则
```plain
规则：官星清透不杂 + 制方有力不过头 = 清贵

操作：
    第1步 数官杀位数，查有无混杂
    第2步 看制方（食伤）有没有根、有没有生
    第3步 判断是「制住」还是「制死」
    第4步 制住不过头 → 清贵；制死 → 反不得贵

边界：
    ⚠️  反面推论（混杂/无力反主口舌官非）案例不足，标记待验证

纪律：
    ✓  说「有清贵之象」
    ✗  不断具体职位名称
```


## 9_3 过河拆桥格
本节的主角是「借外面的资源成就自己」——财官聚于宾位，被主位制住。

### 模型定义
```plain
核心：财 / 官 聚于宾位（年月），被主位的体制住
    →  「过河拆桥」：借用外面的资源成就自己，
        功成之后桥（被制的一方）就完成了使命
```

### 成立条件
```plain
条件一  财重聚于宾位（年月）
条件二  主位有力量去制它
条件三  制得住（力量占优）
```

### 正例一：房地产巨富
```plain
乾造：庚戌  己卯  戊子  癸亥
大运：庚辰  辛巳  壬午  癸未
现实反馈：房地产巨富，资产数千万
```

> 此造的宾主、体用、做功骨架已在板块 1 演示，此处只讲格局层面。

```plain
卯木官星  →  统摄子水财星，归于宾位
年支戌土  →  合制卯木官星

巳运引动戌土发力
    →  制官得财
    →  应「过河拆桥」之象
```

**核心逻辑：** 官星统摄财星，制住官星就等于把财也拿到了。不是直接去制财，而是制住管财的那个官。

### 正例二：建筑老板
```plain
乾造：壬辰  癸卯  戊辰  壬戌
大运：甲辰  乙巳  丙午  丁未
现实反馈：建筑老板，富贵
```

```plain
辰戌冲  →  开财库
卯木官星合戌  →  制官得财
```

两条线并行：一是辰戌冲开库（墓制），二是卯戌合制官（制用）。两条都指向「取外面的财」。做功结构相似而层次不同，说明做功定「有没有」，调候与官星根气定「有多大」，两条不能互相替代。完整正反对照片见板块 19。

### 反例：财轻则不成立
```plain
坤造：丙辰  辛卯  甲戌  丁未
大运：庚寅  己丑  戊子  丁亥
现实反馈：小生意人，非巨富
```

**为什么不是过河拆桥格？**

```plain
虽见财生官
但：主位财轻，而生宾位官
    →  不符合「财重聚于宾位」的前提

反喜：午火财星合未土印星
    →  做小本经营
    →  非过河拆桥格
```

**关键差异（本板块最重要的一点）：**

```plain
正例：财在宾位  ──被我制──▶  我把外面的钱拿进来
反例：我的财    ──去生──▶  外面的官  我把钱送出去

同样是「财生官」，方向反了，结果天差地别
```

判断时先问：「这个财生官，是外面的财被我制，还是我的财去生外面？」

### 可复用规则
```plain
规则：官星统摄财星时，制官即得财
边界：
  ✓ 财必须聚于宾位，且量重
  ✓ 制方与日主同气或与主位有关联
  ✓ 制得住（力量占优）
  ✗ 主位财去生宾位官则方向相反，不成立
反例存档：丙辰 辛卯 甲戌 丁未（小生意人）
```


## 9_4 去官格与去财格
上节的过河拆桥是「制官得财」，本节看两个更纯粹的「去忌得喜」结构：伤官去官、比劫去财。

### 伤官去官格
```plain
结构：伤官制官，去忌得官
象：掌权、执法、管理
成立条件：
    第1步 官杀必须有根
    第2步 伤官有力
    第3步 伤官不被印制
```

「去忌得官」的含义：官本来是忌神（对我不利），用伤官把它制掉，反而得到了官的好处——这正是「去忌得喜」的逻辑（贼捕理论，见板块 2）。

### 比劫去财格
```plain
结构：比劫制财，去忌得财
象：发横财、风险财
成立条件：
    第1步 财星有根
    第2步 比劫成势
    第3步 不被官杀护财（官杀克比劫，护住财星）
```

比劫制财是靠人多、靠力气、靠竞争硬抢来的，不是稳定经营所得。所以主风险财、暴发。

### 两格的共同点
```plain
都是「去忌得喜」结构
    =  制去忌神时，得忌神之喜

贼捕理论的应用：
    忌神 = 贼
    制它的力量 = 捕
    制住贼 = 得贼之喜
```

「去忌得喜」成立的前提是「确实去得掉」。忌神无根、制方无力，都不能算「去」，只能算「碰了一下」。

### 盘例：去食就印
```plain
乾造：戊申  甲寅  戊午  壬戌
大运：乙卯  丙辰  丁巳  戊午
现实反馈：处级干部，主管城建
```

```plain
寅午戌三合火局  →  印星化杀生身
申金食神在年支被寅冲  →  去食就印
    →  主权力
```

**「去食就印」值得细看：**

```plain
原局：申金食神（技术 / 表达）被寅冲掉
    寅午戌三合火局（印局）

「去食就印」  =  舍技术而取权柄
    →  不走技术路线，走权力路线
    →  应：主管城建的处级干部
```

命局里两条路都在（食神一条、印一条），食神被冲掉，只剩下印这条路，所以走了仕途。**断职业时看哪条路被破坏、哪条路被保留，往往比看哪条路更旺更准。**

## 9_5 以禄当财与内食神格
### 以禄当财
```plain
适用：局中无财、或财无用
做法：以禄神当财看
禁忌（重要）：
    禄不可受损  →  禄破主寿夭或贫
    禄怕财星来坏  →  财坏禄主因财致祸
```

「禄怕财来坏」这条特别反直觉：财是好事，为什么会坏禄？因为当禄被当作财使用时，财星来克它就等于破坏了自己的「财」和「身体」（禄也主身体）。所以这种格局下，财反而是忌。

### 内食神 / 外食神格
| 类型 | 形式 | 主象 |
| :--- | :--- | :--- |
| **内食神格** | 食伤在地支不透，成势泄秀 | 创造财富的企业家（被人吃） |
| **外食神** | 食伤透干 | 口才、技艺、销售（去吃人） |

**区别的记忆法：**

```plain
透干  =  外  →  表现出来给外面看  →  口才、销售、技艺
藏支  =  内  →  在内部酝酿      →  谋划、实业、企业
```

**「被人吃」vs「去吃人」：**

```plain
内食神（藏支）  =  被人吃  =  自己有东西被别人消费
外食神（透干）  =  去吃人  =  主动去获取
```

### 内食神格的喜忌
```plain
喜：行财运（食神生财，财富兑现）
忌：行印运（印制食神，坏局）
```

### 特殊格局的纯粹性要求
```plain
关键：特殊格局需「纯粹」，杂则不贵

例：伤官去官格
    若见财星通关（伤官生财、财生官）
    →  格局破败
    →  反主贪财坏印
```

「杂则不贵」是判断特殊格局的第一原则。看到一个格局像某格，先检查有没有「杂质」（通关、泄气、破格的字）。


## 9_6 气势论与病药说
格局管「有什么结构」，气势论管「这股势往哪走、能不能借」。

### 气势论
```plain
五行失衡时  →  顺势而为

得势之命  →  病神即为成就之源
有势无病  →  反为贱
```

「病神即为成就之源」：某一行极旺（这就是「病」），但如果全局顺着这股势走，这股势反而成了最大的资本。**伟人皆有势，贵在去病。**

「有势无病反为贱」：有势但没病可去，等于有力没处使，反而平庸。

### 病药说
```plain
病  =  命局里失衡的、过剩的、为害的那一行
药  =  能制住 / 化解这个病的字

判断：
    有病有药  →  贵
    有病无药  →  贱
    病重药轻  →  层次受限
    病轻药重  →  过度，反损
```

**气势不可逆：**

```plain
警示：气势不可逆，逆势而行必遭灾
```

一个得势的命局，如果岁运逆着这股势来（全局火旺为势，岁运强水克火），往往就是灾年。

### 病药说的实操
```plain
第1步  定势：哪一行在命局里最强（得令、得地、得党）
第2步  定病：这一行过剩到什么程度、为害不为害
第3步  定药：有没有字能制化它
第4步  看运：岁运是助病还是助药
    助药    →  吉运
    助病    →  凶运
    逆势强攻 →  大凶
```


## 9_7 盘例：官印相生的科级公务员
本例演示「官命七种组合」中较平实的一型，以及「层次有限」时如何用做功效率解释。

### 盘面
```plain
乾造：甲午  丁卯  庚辰  丁丑
大运：丙寅  乙丑  甲子  癸亥
现实反馈：公务员，科级
```

### 第一步：找官杀
```plain
丁火为正官（庚金以火为官）
    双丁透干（月干、时干）
    官星很显眼
```

### 第二步：看官星配什么
```plain
年干甲木  =  偏财，财生官（木生火）→ 官杀配财的雏形

日支辰、时支丑  =  湿土，土生金（生身）
    →  印星（辰丑为湿土生庚金）
    →  官印相生
```

### 第三步：定性与层次
```plain
结构：官印相生 + 辰丑湿土生身
    春金柔弱（庚金生于卯月，木旺金弱）
    赖湿土生扶
    →  官印有情，故有公职之贵

层次为何止于科级？
    第1步 官星双透但根气有限
    第2步 春金本身柔弱，承担的权力有限
    第3步 做功链条较短（官印相生一线，未形成串联）
```

### 可复用规则
```plain
规则：官印相生 + 财生官，主公职之贵
层次判断：
  ✓ 看官星有没有根（无根则权虚）
  ✓ 看日主能不能承受（春金柔弱则层次受限）
  ✓ 看做功能是单线还是串联（单线层次有限）
纪律：
  ✓ 说「有公职、体制内发展有利」
  ✗ 不说「正科级」「某年提副处」
```


## 9_8 盘例：厅级官员——两套体系的互证
本例演示同一个结构在两套体系下的不同读法，以及「做功定有无、平衡定层次」如何配合。

### 盘面
```plain
乾造：庚子  己卯  甲辰  己巳
大运：庚辰  辛巳  壬午  癸未
现实反馈：厅级官员
```

### 盲派读法
```plain
庚子  →  官印带象（庚金官 + 子水印）
    从宾位（年月）拱入主位辰土

大运制住子水印星（官之原神）
    →  制印得权
    →  升职
```

### 子平读法（互证）
```plain
甲木生于卯月，羊刃当令
    庚金七杀透干制刃
    子水印星化杀生身
    →  正格「羊刃驾杀配印」
```

### 两套体系的对照
| 体系 | 说法 | 关注点 |
| :--- | :--- | :--- |
| 盲派 | 制印得权 | 制住印星（官之原神），权力到手 |
| 子平 | 印星护官、杀刃平衡 | 刃、杀、印三者互相制约，形成贵格 |

**升迁之应的实质：** 岁运助起官印、平衡刃杀之功，不是单纯的「制印」，而是整体平衡被激活。

### 可复用规则
```plain
规则：官星制比劫 = 管人的权力
    日干五合正官（乙庚、丙辛）且官星有根 = 体制掌权之象
边界：
  ✓ 官星必须有根（无根则权力虚）
  ✓ 看官星制的是谁（制比劫主管人，制别的另论）
  ✓ 带象必须与主位发生关联
  ✓ 结合岁运：助起官印之年 = 上升之年
```


## 9_9 官命判断的完整流程
```plain
第1步  找官杀，看有没有根
第2步  看官杀配什么（印 / 财 / 伤官 / 刃）→ 对照七种组合
第3步  看宾主：官在宾位还是主位？
    官在宾位被我合 / 制  →  权归我
    官在主位            →  自身有官职之象
第4步  看制的方式与效率（回顾板块 2 效率表）
第5步  检查格局纯粹性（有没有杂质破格）
第6步  看岁运：助官印还是坏官印
第7步  定性与量级
```

### 定性 vs 量级
```plain
能做：「有掌权之象」「管人之权」「体制内发展有利」
不做：「某年当某长」「正处级」

原因：象法给的是方向与倾向，职位名称受时代、地域、
      个人选择等太多非命理因素影响，不可铁断
```

### 官命判断的三个常见误判
```plain
误判一  见官星就断官
    矫正：官星要有根、要有配置，无根之官是虚职

误判二  官杀混杂就断不贵
    矫正：要看有没有制化、有没有去留

误判三  财生官就断有实权
    矫正：要看财是我的还是外面的（见 9_3 正反例）
```
