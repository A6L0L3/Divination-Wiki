#### 0_1_5 落地实操：给自己排一份周计划

拿一张纸，按三步填完即可：

```plain
第1步 定总时长：算出你每周能稳定投入多少小时
       （通勤碎片 + 整块时间分开算，不要算理想值）

第2步 定阶段：对照 0_1_2 的六阶段，确认自己现在在第几阶段
       以及这一阶段的验收标准是什么

第3步 排到周：把该阶段的单元分配到具体周次
       每周只排一个"理解型"单元，记忆型内容塞进碎片时间
```

| 每周可用时间 | 建议节奏 |
| :---: | :--- |
| 5 小时以下 | 两周一个理解型单元，碎片时间只做记忆 |
| 5~10 小时 | 一周一个理解型单元 + 3 次练习 |
| 10 小时以上 | 一周两个单元，但要留出复盘时间 |

#### 0_1_6 案例小故事：在职党的十二周

> 阿May 是名程序员，每天能用的只有通勤一小时和周末两个半天。一开始她很焦虑，觉得这点时间根本不可能学完十个板块。
>
> 后来她把路线图改造成了"双轨制"。
>
> **听觉轨**放在通勤路上：她把十天干特性、地支藏干口诀、纳音口诀自己念一遍录下来，每天来回各听一遍。第一周觉得很傻，第二周开始能跟着念，第三周坐地铁时已经能默背"寅中甲丙戊、申中庚壬戊、巳中丙戊庚、亥中壬甲"。
>
> **动手轨**放在周末半天：一次只攻一个单元，严格执行五步闭环。她给自己定了个规矩——练习只做"普通"档，"困难"档全部攒到月末集中突破。
>
> 她做的最关键的一个取舍是：**在第4步走完之前，坚决不碰"炼狱"和"天堂"档**。她的理由很朴素：多步推导题在基础不牢的时候做，只会一次次强化错误的思考路径，练得越多，错得越熟练。
>
> 事实证明这个判断是对的。第 10 周她回头刷"困难"档，正确率直接从 52% 跳到 84%——因为该补的基础都补上了，那些题突然变得"看得懂"了。
>
> 十二周后，她完成了板块4，并给三位同事各排了一次盘。
>
> **她的具体排期（可直接照抄）**：工作日早通勤 30 分钟只听音频、不动笔；晚通勤 30 分钟默写早上听过的内容，写不出的记进"待补"清单，攒到周末一起补。周末两个半天各锁定一个单元，跑完整五步闭环——一个单元没跑完，绝不开下一个。
>
> **中间也崩过一次**。第 6 周她连着加班两周，双轨制断了，回来时发现前几周背熟的藏干口诀忘了一大半。她没有从头再来，而是只补"待补"清单上的那几条。**这正是清单的价值：它让中断变得可恢复。**
>
> 给三位同事排盘那次，是她第一次被现实"打脸"：其中一位的月柱她排错了，因为对方出生在立春前两天，实际仍属上一年的丑月。她当场修正，也第一次真切体会到"节气才是命理分界"这句话的分量——书上读过三遍的规则，不如亲手排错一次记得牢。
>
> **复盘拆解**：她赢在三件事上——记忆与理解分槽（通勤只记、周末只理解）、难度与阶段对齐（第 4 步之前不碰高难题）、中断后能精准续上（靠"待补"清单而非从头再来）。她在笔记首页写下一句：**"我以前以为慢是因为时间少，后来才知道慢是因为一直用同一种方式处理两种不同的知识。"**

> **可复用的经验**：时间少不是最大障碍，节奏错才是。把记忆和理解分开、把难度和阶段对齐，比单纯堆时间有效得多。

### 0_2 使用建议与边界声明

**使用建议**

- 按编号顺序读，不要跳。板块之间有前置依赖，跳读会在后面反复卡住。
- 每学完一个单元，立刻在一张真实八字上走一遍对应动作，只读不练等于没学。
- 遇到流派分歧（庚壬四化、旺衰取法、神煞取舍），本库已标出所采口径；选定一套用到底，中途不换。
- 每个板块末尾的「易错对照表」与「通关验收」不要跳过，它们决定你是真会还是假会。
- 时间有限时优先读四节：板块0_1（路线）、板块0_3（闭环方法）、板块0_6（笔记法）、板块0_7（验收）。

**边界声明**

本库是中国传统命理（子平术）的整理性教材，内容属民俗术数与文献研读范畴，不具备现代科学意义上的可验证预测效力，不构成医疗、法律、财务、婚恋或职业选择的决策建议。

使用本库时遵守四条：

1. 不预测生死。凡涉及寿元、重大疾病、意外的时间性断言，一律不采信、不转述。
2. 不用绝对化与等级化表述。「克夫」「克妻」「贫贱」「孤寡」「夭折」一类古法用语，只在说明原书口径时引用，实际论述一律降档为「关系张力较大」「资源偏紧」「支持系统较弱」等可讨论的说法。
3. 不作替代性判断。健康交给医生，财务交给专业顾问，法律交给律师。命理分析只提供一种理解处境的视角。
4. 不制造焦虑。分析的目的，是让人更清楚自己能做什么，而不是更担心自己会遭遇什么。

最好的姿态是：把「起例」当规则学，把「论断」当假设验，把「命例」当案例读——既不盲从，也不轻慢。

### 0_3 单元闭环：读、画、练、错、复

#### 0_3_1 为什么"读完了还是不会"

八字是规则密集型的学问：一个单元里可能同时有定义表、口诀、优先级规则和例外条款。这类知识有一个共同特点——**看懂所需的认知量，远小于能独立复现所需的认知量。**

```plain
被动输入（读）  →  眼睛会了
主动输出（画 / 说 / 做）  →  手会了

两者之间那道坎，只能靠"输出"跨过去，不能靠"多读两遍"跨过去。
```

所以本知识库从头到尾只强调一条学习律：**每读进一分，至少要输出一分。** 输出的形式有三种，成本从低到高：

| 输出形式 | 成本 | 暴露盲点的能力 |
| :---: | :---: | :--- |
| 复述（讲给别人听） | 低 | 中——能暴露"说不圆"的地方 |
| 默画（合上书画图列表） | 中 | 高——画不出的格子就是盲点 |
| 做题（现场推导） | 高 | 最高——对错当场判定 |

#### 0_3_2 单元闭环五步法（核心实操）

把每个单元的 30 分钟拆成固定动作，形成肌肉记忆。顺序不要改：

```plain
第1步 读（8 分钟）  读本单元正文，只做一件事：把加粗规则压缩成一句话，
                抄进三栏笔记的"规则"栏
第2步 画（5 分钟）  合上文档，把本单元的逻辑图 / 核心表默画一遍
                 ——画不出的地方，就是真正的盲点，当场用红笔标出
第3步 练（10 分钟） 做本单元的自测题（题目来源见 0_4），
                 只做"简单 + 普通"两档，做完立刻对答案
第4步 错（5 分钟）  错题立刻写"错题四问卡"（见 0_3_6「单元进度表」），不写不算做完
第5步 复（2 分钟）  当天睡前扫一遍当天新增的错题卡，标记"已清 / 未清"
```

**三步为什么不能省：**

```plain
"读"是进货，"画"是盘点，"练"是质检。
只进货不盘点，你不知道自己缺什么；
只盘点不质检，你不知道自己记错了什么。
```

> **给时间紧张者的最小版本**：如果某天只有 10 分钟，只做"读 + 画"。宁可少做三道题，也不要跳过默画——做题的收益建立在"已读"的基础上，默画的收益建立在"发现没读进去"上，后者更根本。

#### 0_3_3 练习的三种题目来源（不必依赖现成的题目集）

很多人卡在"没题可做"。事实上题目有三处来源，质量依次升高：

```plain
来源一 · 书后自测
   本知识库每个单元末尾的「实用验证」，本身就是题目。
   做法：把它抄进本子，隔一天再做一遍，不要边看边答。

来源二 · 自编题（质量最高）
   把刚学的规则换个参数重写一遍。
   例：学了"甲木见丁火为伤官"，就自编"乙木见丙火是什么"。
   能编出题 = 掌握了规则的结构，这是 0_3 错题卡第3问的核心。

来源三 · 真实命例
   从板块3 开始，每排一个盘就是一道综合题。
   真实盘的好处是没有标准答案，逼你写出推导过程。
```

#### 0_3_4 落地实操：把五步法用到今天学的这一节

不需要额外准备，学完任意一节就能立刻跑一遍：

```plain
第1步 读：通读本单元，不抄笔记
第2步 画：合上资料，默画本单元的核心表（画不出来就是没懂）
第3步 练：做 3~5 道对应题目，或自编 2 道
第4步 错：错题进错题本，按"四问卡"填完
第5步 复：当天、第3天、第7天各回看一次
```

**唯一的纪律**：第2步做不出来，不许进入第3步。**默画是唯一不能跳过的环节**——它直接区分了"看过"和"会了"。

> 小陈和小林在同一天入门，用的是同一份教材。
>
> **小陈走的是"慢路线"。** 他老老实实按"板块1 → 板块2 → 板块3"的顺序走，每个单元都完整跑一遍五步闭环。前两周进度很慢，他一度怀疑自己是不是太笨——同期的人已经做完两百道题，他还在一笔一笔默画十天干表。他甚至把默画失败的格子拍下来贴在书桌前，一共十七个。
>
> **小林走的是"快路线"。** 他觉得看书太慢，直接从习题集开始连做三百题，做完对答案，错了看一眼解析就过。头两周他很得意：正确率一度冲到 78%，还在群里分享了"题海才是王道"的经验帖。
>
> **转折发生在第三周。** 题目开始要求现场推导——"日主甲木见丁火是什么十神""日主乙木见庚金是什么十神"。小陈因为反复默写过"我生者，同阴阳为食神、异阴阳为伤官"这条规则链，看到题几乎是条件反射；小林却只能凭前两百题攒下的手感猜。他的正确率一路掉到 41%。
>
> 更糟的是第三周复盘时，小林回头检查自己的错题，才发现前三周错的全是"记忆型"题目——也就是说，他花了三周时间，用错误的方式做了一遍本该背熟的基础。他不得不从板块1 推倒重来，多花了整整两周。
>
> **第五周，两人走到板块4 时的差距已经拉开到一个月。**
>
> 有意思的是差距的性质。小林并不是不努力——他做的题量是小陈的三倍。他缺的是"把知识固化成结构"的那一步：他每道题都靠"眼熟"作答，一旦题目换个皮，眼熟就失效了。而小陈前两周慢下来的那部分时间，其实是在建结构；结构一旦建起来，后面每个单元的吸收速度都会变快。
>
> 小陈后来总结过一句很朴素的话：**"前两周我是在盖地基，看起来没长高；他们在砌墙，看起来很快。但砌到第三层，他们得回来补地基，我不用。"**
>
> **复盘拆解**：两人的差距不在努力程度——小林做的题量是小陈的三倍。差距在于**有没有把知识固化成结构**。小林每道题都靠"眼熟"作答，一旦题目换个皮，眼熟就失效了；小陈前两周慢下来的那部分时间，其实是在建结构。
>
> 结构一旦建起来，后面每个单元的吸收速度都会变快——这就是为什么第三周之后差距反而越拉越大。小陈那句"盖地基 vs 砌墙"的比喻，说的正是这个时间差：**前期看不出高度，但后期不用返工。**
>
> 由此可以定一条自检：**不看资料，能不能把这一节的表画出来、把规则讲给一个外行听懂。** 做不到，就是还停在"读"的阶段，继续做题只是把时间换成爽感。

> **可复用的经验**：即时正确率是"爽感指标"，默画和复述才是"掌握指标"。用前者指导学习节奏，很容易被带偏。**判断自己有没有真懂，最简单的检验是——不看资料，能不能把这一节的表画出来、把规则讲给一个外行听懂。**

#### 0_3_6 笔记法 · 单元进度表

每学完一个单元，在笔记里补一行（这张表本身就是你的学习仪表盘）：

```plain
| 单元 | 学完日期 | 默画通过 | 首次自测正确率 | 错题数 | 复盘日(1/3/7/15) | 状态 |
|------|---------|---------|-----------|--------|------------------|------|
| 2_3  |         |    □    |           |        |  □  □  □  □      | 未开始 |
```

**用法提醒**：这张表不是记录用的，是诊断用的。横向看"默画通过"那一列——**连续三个单元都是空的，说明你已经在用"读"代替"学"了**；纵向看"错题数"——某个板块的错题数明显高于相邻板块，那里就是你的结构性弱点。

#### 0_3_7 实用验证

- **验证 1（5 分钟）**：合上文档，在白纸上默写出"单元闭环五步法"。写不出第四步，说明你还没有开始真正的学习。
- **验证 2**：翻开最近学的一个单元，检查是否留下了"规则栏"笔记。空白，等于这个单元需要重来。
- **验证 3**：随便挑一条刚学的规则，现场自编一道同考点的题并作答。编不出来，说明只记住了例题，没记住规则结构。

### 0_4 练习难度与自查节奏

#### 0_4_1 五档难度全景

练习按五档设计。这张表的作用是让你**知道自己在哪一层，以及该往哪一层使劲**：

| 难度 | 占比 | 适用阶段 | 题型特征 | 目标正确率 |
| :---: | :---: | :---: | :---: | :---: |
| 简单 | 25% | 入门阶段 | 纯记忆、定义、单步判断 | ≥ 95% |
| 普通 | 30% | 基础阶段 | 单一规则应用、一步推导 | ≥ 85% |
| 困难 | 25% | 进阶阶段 | 多规则组合、二步推导 | ≥ 70% |
| 炼狱 | 12% | 高阶阶段 | 综合多维度、三步以上推导 | ≥ 55% |
| 天堂 | 8% | 大师阶段 | 命例实战、需完整思维逻辑 | ≥ 45% |

**怎么读这张表**：

```plain
第1步 占比是"知识体系的难度结构"，不是你每天的练习配比
第2步 新手的每日配比应偏向"简单 + 普通"（建议 6:5:1），
   随着阶段推进再逐步上调难度
第3步 越往上正确率越低是正常的——炼狱档的目标是 55%，
   用简单档的 95% 去要求自己，只会让你不敢碰难题
```

**一条硬纪律**：**在第 4 步（旺衰 + 格局）走完之前，不碰"炼狱"和"天堂"档。** 多步推导题在基础不牢的时候做，只会一次次强化错误的思考路径——练得越多，错得越熟练。

#### 0_4_2 每日练习节奏（可直接照抄）

```plain
每日 20 题（约 25 分钟）
├─ 新题 12 题：简单 6 + 普通 5 + 困难 1
├─ 错题重练 6 题：从错题本按"最老未清"原则抽取
└─ 随机回炉 2 题：已清的旧错题，防止遗忘

每周 1 次（约 40 分钟）
└─ 单元自测：本单元混合 30 题
   自测正确率 < 80% → 该单元重学，不往下走
```

**为什么"错题重练 6 题"占的比重这么高**：因为新题的作用是"暴露问题"，错题的作用是"解决问题"。只做新题不做错题，等于每天体检却从不治疗。

#### 0_4_3 正确率异常诊断表

| 症状 | 可能病因 | 处方 |
| :--- | :--- | :--- |
| 简单档错很多 | 记忆未固化 | 回看口诀，做"默写 + 对答案"三轮 |
| 简单对、普通错 | 规则没理解，只会背 | 回到正文，把规则用自己的话复述一遍 |
| 普通对、困难错 | 缺少多步推导训练 | 做"拆解训练"：把一道困难题拆成三步，分别写清每步依据 |
| 全档位忽高忽低 | 概念混淆（如正财/偏财、墓/库） | 建"易混对照表"，专门记录成对易混概念 |
| 炼狱档长期 0 分 | 阶段未到 | 立即停做，回到第 4 步补旺衰与格局 |

> **诊断表的关键用法**：不要看总分，看**结构**。总分 70% 但简单档错一半，和总分 70% 但简单档全对、困难档全错，是两个完全不同的病——前者要回去背，后者要做拆解训练。

#### 0_4_4 卡关处理三步法

```plain
第1步 · 定位
   连错 3 题，立刻停止。把 3 道题的考点写在纸上，找它们的交集
   ——交集就是你的真实盲点。

第2步 · 回填
   回到对应单元，只读该考点那一段，把规则抄进"规则栏"。
   注意：只补那一块，不要顺手把整个单元重看一遍。

第3步 · 再测
   只做该考点的题 10 道，正确率 ≥ 90% 才算清掉。
```

#### 0_4_5 落地实操：今日练习配比

每天练习照这个比例配，直接用：

```plain
每日 20 题 = 新题 12 + 错题重练 6 + 随机回炉 2
其中新题 12 = 简单 6 + 普通 5 + 困难 1
```

**三条调整规则**：

| 情况 | 调整 |
| :---: | :--- |
| 简单档正确率 < 90% | 说明基础没记牢，全部换成简单档 |
| 普通档正确率 < 70% | 停做困难档，回去重读对应单元 |
| 连续三题错在同一考点 | **立刻停下**，进入"错题切片法"（取十道 → 标考点 → 找交集 → 只补那一块） |

> **核心原则**：**难度要和学习阶段对齐，不要和心情对齐。** 基础不牢时刷高难题，只会把错误的思路练得更熟练。

---

#### 0_4_6 案例小故事：卡在困难档的小赵

> 小赵的基础相当扎实，简单档和普通档的正确率都稳定在 95% 以上。可"困难"档他常年卡在 50% 上下，怎么练都上不去。他很困惑，一度怀疑是自己天赋不够，甚至认真考虑过要不要放弃。
>
> 他尝试过两种办法，都不管用：**一是加量**——每天从 20 题加到 50 题，正确率纹丝不动，人先累垮了；**二是回头重学**——把板块2 整个重看一遍，看的时候觉得都懂，做题还是错。
>
> 后来他按卡关三步法做了一次定位。他把最近连错的十道题摊在桌上，逐题写下考点：
>
> 第 1 题：地支有卯戌合，又有卯酉冲 → 考点"合冲优先级"；第 2 题：寅午戌三合与子午冲并存 → 考点"合冲优先级"；第 3 题：巳申合又相刑 → 还是"合冲优先级"。十道题逐条标完，有八道的考点完全一致。
>
> **病因浮出水面：他不是不会，而是脑子里根本没有"优先级"这根弦。** 看到合就论合，看到冲就论冲，从没想过两者撞在一起时该怎么排序。所以他每次都在"两个都对"的选项里凭运气选一个。
>
> 他回去把"合 > 冲 > 刑 > 害 > 破"的优先级表抄了三遍，重点抄那三条例外（三合三会成立时凌驾一切、合可解冲、特定组合下刑的威力极大）。然后他专门自编了 20 道"合冲并存"的题，做的时候强迫自己**先写优先级判断，再写结论**——哪怕结论错了，优先级那一步也要写在纸面上。
>
> 两周后，他的困难档正确率升到了 76%。又过了一个月，稳定在 80% 以上。
>
> 他把这个方法总结成四步，起名叫"**错题切片法**"：**取最近连错的十道 → 逐题标考点 → 找交集 → 回到正文只补那一块。**
>
> 他说最关键的是最后一步：**"补的时候要忍住，只补那一块。我以前一卡关就把整个板块重看一遍，看着很用功，其实什么都没补上——因为重看的时候，我看到的都是我已经懂的部分，那种'都懂'的感觉恰恰掩盖了那一个真不会的点。"**
>
> 这个方法还顺带治好了他另一个毛病：以前他做题是为了"做完"，现在他做题是为了"暴露问题"。他的原话是：**"以前错一道题我很烦，现在错一道题我挺高兴——又找到一个洞。"**
>
> **复盘拆解**：小赵试过两种办法都不管用，原因在于它们都绕开了"定位"这一步。**加量**是在用更多样本碰运气；**回头重学整个板块**则会撞上一种很隐蔽的自我欺骗——重看时你看到的都是已经懂的部分，那种"都懂"的感觉恰恰掩盖了那一个真不会的点。
>
> 真正起作用的是第三步：**只补那一块。** 他还多做对了一件事——做题时**强迫自己先写优先级判断再写结论**，哪怕结论错了也要把中间那步写在纸面上。这一步把"隐性思路"变成了"可检查的文本"，错误才有地方暴露。
>
> 可以压缩成四步带走：**取最近连错的十道 → 逐题标考点 → 找交集 → 只补那一块。** 最后一步最难，因为要忍住不把整个板块重看一遍。

> **可复用的经验**：卡关时不要在题海里硬耗。连错的题里藏着一个"最大公约数"，把它找出来，比多做两百道题有用。**四步走：取最近连错的十道 → 逐题标考点 → 找交集 → 只补那一块。**

#### 0_4_7 笔记法 · 错题四问卡（全库通用模板）

这是整个知识库最重要的笔记模板。**每道错题都必须填**，缺一问视为未完成：

```plain
┌─────────────────────────────────────────────────────┐
│ 错题四问卡                          编号：4_2-07    │
├─────────────────────────────────────────────────────┤
│ 第1问 我错在哪：把错误答案和当时的思考过程如实写下来│
│    （例：我把丁火当成甲木的食神，因为觉得火是木     │
│      生的，所以一定是食神）                         │
│                                                     │
│ 第2问 正确规则：一句话写出规则出处                  │
│    （例：我生者，同阴阳为食神，异阴阳为伤官）       │
│                                                     │
│ 第3问 同类题：自己编一道同考点的新题并作答          │
│    （例：日主丙火见戊土？→ 同为阳 → 食神）          │
│                                                     │
│ 第4问 复盘日期：第1天 / 第3天 / 第7天 / 第15天      │
│     □     □     □     □                             │
│     四格全打钩，才算"已清"                          │
└─────────────────────────────────────────────────────┘
```

**第3问为什么最关键**：能自己编出一道同类题，说明你掌握了规则的结构，而不是记住了某一道题的答案。这两者有天壤之别——**记住答案的人，题目换个数字就错；掌握结构的人，题目怎么换都对。**

#### 0_4_8 实用验证

- **验证 1**：随机从错题本抽 5 张卡，看第3问（自编同类题）是否都填了。空着的卡，都是假性掌握。
- **验证 2**：统计最近 50 道错题的考点分布。如果某个考点占比超过 30%，说明那里有个系统性漏洞，必须回到单元正文重学。

### 0_5 自测题设计与错题管理

> **本单元解决一个很实际的问题：题从哪来、错题怎么管。** 前面三节讲的是"怎么学和怎么练"，这一节讲的是"练什么、练完留下的东西怎么变成资产"。

#### 0_5_1 为什么要自己出题

现成的题目永远不够用，而且有一个隐蔽的缺点：**它的考点是别人替你挑的**。你自己出题时，会本能地往"我不太确定的地方"出——这个过程本身就是一次自我诊断。

```plain
用现成题：测的是"别人认为重要的点"
自己出题：测的是"我自己心虚的点"
后者更贴近你的真实漏洞
```

#### 0_5_2 出题四式（从易到难）

同一条规则，可以用四种方式变成题目。以"甲木见丁火为伤官"为例：

| 式 | 做法 | 示例 | 考查能力 |
| :---: | :--- | :--- | :--- |
| **填空式** | 挖掉结论 | "甲木日主见丁火是____" | 记忆 |
| **判断式** | 给结论问对错 | "甲木见丁火是食神，对吗？" | 辨认陷阱 |
| **变形式** | 换参数 | "乙木日主见丙火是什么？" | 规则结构 |
| **命例式** | 放进真实八字 | "排出自己的盘，标出全部十神" | 综合运用 |

**四式的配比建议**：

```plain
入门阶段：填空 6 : 判断 3 : 变形 1 : 命例 0
进阶阶段：填空 2 : 判断 2 : 变形 4 : 命例 2
实战阶段：变形 3 : 命例 7
```

> **变形式的价值被严重低估。** 它能一次性区分"记住了这道题"和"学会了这条规则"。判断自己是否真懂，最快的办法就是给自己出三道变形式。

#### 0_5_3 自测的三种组织方式

| 方式 | 频率 | 题量 | 作用 |
| :---: | :---: | :---: | :--- |
| **日测** | 每天 | 20 题（新 12 + 错 6 + 回炉 2） | 保持手感、当天暴露问题 |
| **周测** | 每周 | 本单元混合 30 题 | 判定该单元是否可通关 |
| **阶段测** | 每走完路线图一步 | 用真实命例做 3~5 个完整推导 | 判定能否进入下一阶段 |

**周测的三条纪律**：

```plain
第1步 闭卷——翻书的周测没有意义
第2步 计时——30 题控制在 40 分钟内，训练现场推导速度
第3步 判分后必须做"错题切片"（见 0_4_7「错题四问卡」），不能只记个分数
```

#### 0_5_4 错题本怎么组织才有用

多数人的错题本最终变成废纸，原因只有一个：**它是按"时间"排的，不是按"考点"排的。** 按时间排的错题本只能告诉你"我哪天错了"，按考点排的错题本才能告诉你"我哪里不会"。

**推荐结构（三层）**：

```plain
第一层 · 按板块分册（板块2 一册、板块5 一册、板块7 一册，其余板块依此类推）
第二层 · 册内按考点分组（如"合冲优先级""从格条件""调候优先"）
第三层 · 组内按状态标记（未清 / 复查中 / 已清）
```

**错题的三种状态与流转**：

```plain
  新错（当天）──▶ 未清 ──▶ 第1/3/7/15天四次复盘 ──▶ 已清
                    │                                  │
                    └── 复盘时又错 → 退回"未清"，重新计日
                                        │
                                        ▼
                            已清错题进入"随机回炉"池，防止遗忘
```

**清理规则**：

```plain
第1条 "未清"超过 30 天 → 说明不是错题问题，是规则没学会，回到正文重学
第2条 同一考点累计 5 张以上错题卡 → 这个考点要单独建一张"易混对照表"
第3条 已清错题不丢弃，进入回炉池——遗忘是默认设置，不是意外
```

#### 0_5_5 落地实操：从刚学的规则里出三道题

学完一条新规则，立刻用它出三道题——这是检验"会不会"最快的方法：

```plain
第1道 · 正用：按规则直接出一道标准题，自己作答
第2道 · 变形：换掉其中一个字（换阴阳 / 换位置 / 换月令），
       看结论怎么变
第3道 · 反推：先想一个结论，倒推需要什么样的命局
```

**判断标准**：三道题里，只要有一道编不出来，就说明你记住的是"结论"而不是"结构"——回去重读规则，直到能编出第三道。

| 出题式 | 练的是什么 |
| :---: | :--- |
| 正用题 | 规则记没记住 |
| 变形题 | 边界清不清楚 |
| 反推题 | 结构懂没懂 |

#### 0_5_6 案例小故事：把错题本用成地图的那个人

> 老周的错题本在圈子里很有名，不是因为记得多，而是因为他改过三次结构。
>
> **第一版：流水账。** 他按日期记，每天错什么抄什么。坚持了两个月，攒了四百多道。问题出在第三个月——他想找"所有关于从格的错题"，只能从头翻到尾，翻了半小时放弃。他说那时候的错题本"像一堆收据，每张都是真的，但加不起来"。
>
> **第二版：按板块分册。** 他改成十个分册，找题快了很多。但新的问题来了：同一个考点会在不同板块反复出现（比如"合冲优先级"在板块2 和板块5 都错），他没法一眼看出"这个点我到底错过多少次"。
>
> **第三版：按考点分组 + 状态标记。** 他把每个分册内的错题再按考点分组，每组前面贴一张小标签，写上"本组累计错题数"。这一改，效果立刻出来了——他一眼就能看到：**"从格条件"那一组攒了 11 张卡，"调候优先"那一组 9 张，而其余大多数组只有 1~2 张。**
>
> 他说那一刻的感觉是：**"我终于不是在看'我错了多少题'，而是在看'我不会什么'。这是两件完全不同的事。"**
>
> 接下来他做的事很笨但很有效：把错题数 ≥ 5 的考点列出来，一共七条，然后从板块5 开始，逐条回到正文重学，每条学完立刻自编 10 道题检验。两个月后，那七条里有五条清零了，剩下两条（从格判定、调候与扶抑冲突）他干脆做成了两张 A4 纸贴在墙上，每次排盘前扫一眼。
>
> 他后来带学生时反复讲一句：**"错题本不是记录错误的本子，是一张你自己的弱点地图。地图的价值不在详细，在于能一眼看出哪里是深水区。"**
>
> 他还补充过一个反直觉的观察：**错题数最多的那几条，往往也是考试最常考、实战最要紧的那几条。** "因为难，所以错得多；因为要紧，所以它反复出现。从这个角度看，错题集中不是坏事——它是在替你标出重点。"
>
> **复盘拆解**：老周改了三次结构，每一次改的都是同一个问题——**这本笔记能不能回答"我不会什么"**。
>
> 第一版按日期排，只能回答"我哪天错了"；第二版按板块分册，能回答"哪个板块弱"，但同一个考点散落在不同册里，看不出累计强度；第三版按考点分组 + 状态标记，才第一次让"系统性漏洞"变得**一眼可见**。
>
> 他那个观察值得单记：**错题数最多的那几条，往往也是最要紧的那几条**——因为难，所以错得多；因为要紧，所以它反复出现。从这角度看，错题集中不是坏事，它是在替你标出重点。
>
> 用法也就清楚了：**每月统计一次各组错题数，前两名就是你下个月的学习重点。** 只盯前两名，贪多必失。

> **可复用的经验**：错题本要按**考点**组织，不按日期组织；每张卡要标**状态**，并且按 1/3/7/15 天四次复盘。**每个月统计一次各组错题数，前两名就是你下个月的学习重点。**

**看这张表的两条规则**：

```plain
第1条 只盯前两名——贪多必失，一个月能清掉两个系统性漏洞已经很快
第2条 "状态"列比"错题数"列更重要：
```

#### 0_5_8 实用验证

- **验证 1**：说出出题四式的名称，并任选一条刚学的规则，各出一道。
- **验证 2**：翻开你的错题本，看它是按日期排的还是按考点排的。按日期排的，建议花一小时重排——这是投入产出比最高的一小时。
- **验证 3**：统计本月错题数前两名的考点，说明它们为什么集中（是难，还是没认真学）。

### 0_6 学习记录方法总纲

本知识库统一使用**三套笔记模板**，分别对应三种学习场景。三套模板的分工与协作关系，见总纲「三套通用笔记模板」。

#### 0_6_1 模板一：三栏笔记法（知识点学习场景）

用于阅读本知识库的每一个单元。

| 规则（Rule） | 易错点（Trap） | 命例（Case） |
| --- | --- | --- |
| 客观规则原文，或自己的一句话概括 | 我容易搞混的地方、反直觉的地方 | 真实八字中的体现 |

**三条填写纪律**：

```plain
纪律一：「规则」栏必须压缩到一句话。
        超过两行，说明你没提炼，只是抄书。

纪律二：「易错点」栏是这份笔记的灵魂。
        宁可空着，也不要写"无"——写"无"等于放弃思考。

纪律三：「命例」栏尽量用你见过的真实八字。
        用自己的盘最好，其次是亲友，最后才用书本案例。
```

**填写示例（以十神定义为例）**：

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 我生者：同阴阳为食神，异阴阳为伤官 | 比肩/劫财、食神/伤官这两对的阴阳规则，与其余三对**恰好相反** | 甲木日主见丁火 → 伤官（不是食神） |

#### 0_6_2 模板二：错题四问卡（自测与练习场景）

完整模板见 0_3_6。两个不可让步的要点：**必须自编同类题、必须四次间隔复盘**。

#### 0_6_4 复习节奏：间隔重复四拍

```plain
第 1 天：学完当天（睡前 2 分钟扫一遍错题卡）
第 3 天：快速重做错题，仍错的标红
第 7 天：只做标红题
第 15 天：全部错题过一遍，清完即归档
```

**为什么是这四个点**：命理知识以记忆型为主，1 / 3 / 7 / 15 天的间隔刚好卡在遗忘曲线的几个拐点上，投入产出比最高。间隔太密是浪费时间，太疏等于重学。

#### 0_6_5 落地实操：今晚就把三套模板建起来

不用等"学完再整理"，现在就建，之后往里填：

```plain
第1步 建三个文件（或三个笔记本分区）：
       第1件 三栏笔记（规则 / 易错点 / 命例）
       第2件 错题四问卡（错在哪 / 正确规则 / 自编同类题 / 复盘日期）
       第3件 命例档案卡（旺衰 → 格局 → 用神 → 神煞 → 大运 → 六亲 → 断语）

第2步 每学完一个单元，只往第1件里加一行

第3步 每错一道题，往第2件里加一张卡

第4步 每排一个盘，往第3件里加一页
```

**一条纪律**：三栏笔记的「易错点」栏**宁可空着，也不要写"无"**。写"无"等于放弃了这个模板里最有价值的一栏。

#### 0_6_6 案例小故事：笔记在半年后救了一次判断

> 老郑有个习惯：每个单元的三栏笔记都认真填，尤其是「易错点」那一栏。他不追求记下所有规则，只记"我在哪里栽过跟头"。
>
> 学了半年后，他的「易混对照表」积了六十多条，包括"正印/偏印""墓/库""从强/从旺""劫财/羊刃""合而不化/真化"等等。有些条目后面还附着当时那道错题的编号。
>
> 有一次他分析一个"日主极弱但似乎有微根"的命例。七个字里五个是克泄耗，看上去完全符合从格的描述，他几乎就要下"从杀格"的结论了。
>
> 下笔前他习惯性翻了翻笔记，看到一条自己写的易错点：**"有根不从，除非根极弱且远隔。"**
>
> 他重新检查四柱，发现日主在时支藏着一个余气根，位置虽然偏远，但谈不上"极弱且远隔"。按这条规则，这个命局不能论从，只能判"身极弱"。
>
> 结论一改，取用方向就完全相反了：从格要顺势用官杀，身极弱则要生扶。他按后者给出了建议。
>
> 半年后命主反馈，那几年的经历完全符合"身极弱待生扶"的走势——尤其是在一步印运里明显好转，而如果按从格论，印运本该是灾难。
>
> **复盘拆解**：这个案子的价值在于它展示了笔记**真正起作用的时刻**——不是在记的当下，而是在半年后某一次"翻到"。
>
> 老郑有个习惯值得抄：**他不追求记全规则，只记"我在哪里栽过跟头"。** 规则书上有、教程里有，抄一遍意义不大；而"我当时为什么会错"这件事，全世界只有你自己知道，也只有它能救你第二次。
>
> 所以三栏笔记里最该下功夫的是「易错点」那一栏，而不是「规则」栏。检验方法也现成：**翻开笔记，统计「易错点」为空的单元数量。超过 20%，说明这份笔记已经流于形式了。**
>
> 顺带一提，那个命例本身也是个好例子：**"有根不从，除非根极弱且远隔"**——余气根虽弱，但位置不属"远隔"，就不能论从。

> **可复用的经验**：笔记的价值不在于记录当下，而在于半年后的某一次"翻到"。记"我错在哪"，比记"规则是什么"有用得多。

#### 0_6_7 实用验证

- **验证 1**：翻开笔记，统计「易错点」栏为空的单元数量。超过 20%，说明笔记流于形式。
- **验证 2**：随机抽一张命例档案卡，不看记录重新推一遍旺衰，看结论是否与卡片一致。不一致，说明当时的推导有水分。

### 0_7 阶段验收与实用验证

#### 0_7_1 四级验收体系

| 级别 | 触发时点 | 验收方式 | 通过线 |
| --- | --- | --- | --- |
| 单元级 | 每学完一个单元 | 默画 + 单元测试 30 题 | 默画通过 且 正确率 ≥ 80% |
| 板块级 | 每学完一个板块 | 板块综合测 + 复述主线 | 正确率 ≥ 75% 且 能复述主线 |
| 阶段级 | 每走完路线图一步 | 阶段产出物（见 0_2 表格） | 产出物达标 |
| 综合级 | 走完全部六步 | 3 份完整命例解读 | 结构完整 + 推导可追溯 |

各板块的具体验收清单，见每个板块文件末尾。

#### 0_7_2 识破"假懂"的三个测试

```plain
测试一 · 费曼口试法
   找一个完全不懂八字的家人，用 3 分钟讲清"什么是十神"。
   讲的过程中卡壳、需要用术语绕过去的地方，就是你的真实盲点。

测试二 · 逆推法
   随便拿一个学过的结论，追问自己"为什么"。
   例：为什么甲木生于卯月是"羊刃格"？
   能答到"卯为甲之帝旺位，阳干帝旺即刃"才算真懂；
   只答"书上是这么写的"，不算。

测试三 · 变形法
   把学过的规则换个形式用。
   例：学了"日主甲木见庚金为七杀"，
       能否立刻答出"日主乙木见庚金是什么"？（正官，异性相克）
   变形做不出，说明你只是在背题，不是在掌握规则。
```

#### 0_7_3 三个测试分别抓什么

| 测试 | 抓住的问题 | 典型表现 |
| --- | --- | --- |
| 费曼口试法 | 概念没内化，只会用术语自洽 | 讲给外行听时，满口"因为它是我克者" |
| 逆推法 | 只记结论不记原理 | 知道结果，说不出依据 |
| 变形法 | 记住了题，没记住规则结构 | 原题会做，改一个字就错 |

#### 0_7_4 落地实操：给当前板块打一次分

照下面这张清单逐条打勾，七条里过五条才算通关：

```plain
□ 1. 能默画本板块的核心表（不是看着画，是合上资料画）
□ 2. 能说出本板块每一单元解决什么问题
□ 3. 本板块的单元测试正确率达标
□ 4. 错题本里本板块的条目已清零
□ 5. 能用费曼口试法讲一遍（讲给外行听，卡壳点记下来）
□ 6. 「易错点」栏已填满，不是"无"
□ 7. 能说出本板块与前后板块的接口
```

**打分之后怎么补**：缺哪条补哪条，**不要整个板块重看**——重看时你看到的都是已经懂的部分，那种"都懂"的感觉会掩盖真正不会的那个点。

#### 0_7_5 案例小故事：一次失败的板块验收

> 小唐学完板块5（日主旺衰判断），单元测试正确率 82%，超过了 75% 的通过线。他挺高兴，填了验收表，兴冲冲奔向板块6。
>
> 结果在格局论命里处处碰壁。最明显的是从格——他分不清"身强"和"极旺"，也把握不住什么情况下该论从，导致涉及特殊格局的题几乎全军覆没。他一度以为是板块6 太难。
>
> 回头补做板块级验收清单，问题立刻暴露了。七条清单里，他漏了两条：
>
> 一是没默画"四维权重表"——他能说出得令最重要，但说不出 45/30/15/10 的具体比例，所以遇到"失令但有强根"的题就凭感觉；
> 二是「易错点」栏只填了 2 条，而且没有一条是关于"从格条件"的——也就是说，从格这块他根本没栽过跟头，不是因为懂，而是因为当时题目简单、恰好没考到。
>
> 他花了三天回炉，把"从格五条件"抄了五遍，并重做了 30 道从格专项题，把每一道的判断过程都写下来。这次再进板块6，顺畅了很多。
>
> **那七条清单他到底漏了什么**：除了"没默画四维权重表"和"易错点栏只填两条"，老师还当场追问了三个问题——"从格五条件说得出吗？""真从和假从的取用差在哪？""失令但有禄根该判什么？"三问他只答对了一问。也就是说，他那 82% 是在"恰好没考到从格"的前提下拿到的。
>
> **老师给的诊断最扎心**：**"你的 82% 是样本指标，不是覆盖指标。它说明你做过的题你多半会，不说明这个板块你都会。"** 单元测试抽的是你练过的题型，验收清单查的是这个板块的全部能力点——两者根本不是一回事。
>
> 回炉那三天他做对了一件事：不是重刷一百道题，而是把 30 道从格专项题**每一道的判断过程写出来**——五条里哪条满足、哪条不满足、结论是什么。写到第 20 道时他才发现，自己之前的判断全凭"看起来弱不弱"。
>
> **复盘拆解**：他把验收清单当成"已经学完的证据"，而它其实是"还没掌握的清单"。正确顺序应当是——**先跑清单，再填验收表；清单上还有缺口，验收就不算通过。** 更省事的做法是反过来：把清单当预习提纲，学之前先看一遍要过哪几关，学的时候才知道劲往哪使。

> **可复用的经验**：验收清单是一道闸门，不是一张装饰表格。跳过它省下的三天，往往要在后面花三周还回来。

#### 0_7_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 验收清单是"还没掌握的清单"，不是"已学完的证据" | 跳过清单直接填验收表 | 82% 正确率仍可能整块盲区 |
| 单元测试是样本指标，验收清单是覆盖指标 | 拿正确率当覆盖度 | 恰好没考到从格 → 误判已掌握 |
| 卡壳就补，不重看整个板块 | 一卡关就从头重读 | 重读只看到已懂的部分 |

#### 0_7_7 实用验证

- **验证 1**：用费曼口试法讲一遍最近学的一个单元，把卡壳点记进「易错点」栏。
- **验证 2**：对照板块级验收清单，给当前正在学的板块打分（满分 7 项）。低于 5 项，建议回炉。

### 0_8 延伸阅读与自查

#### 0_8_1 进阶阅读（建议学完全库之后再开始）

传统典籍中，进阶阶段优先读这三部，顺序即如下：

1. **《子平真诠》**——先把格局的骨架立住，最适合在学完板块6 之后读
2. **《滴天髓》**——旺衰与用神的深层逻辑，配合板块5、板块7 读
3. **《渊海子平》**——作为原始资料库随时翻阅

另有 **《穷通宝鉴》**（五行调候、十天干生于十二月取用）与 **《三命通会》**（神煞、六亲、格局的集大成之作）可作专项查阅。

**阅读提醒**：

```plain
第1条 古籍成书年代早，术语与现代教学口径有出入
第2条 建议以本知识库的体系为主干，古籍用于印证与深化
第3条 基础未稳时不要直接啃古籍
   ——不同流派的说法会互相打架，很容易把刚建起来的框架冲垮
```

#### 0_8_2 学习中的三个坑

| 坑 | 典型表现 | 避坑方法 |
| --- | --- | --- |
| **流派混用** | 今天学"扶抑取用"，明天拿"调候优先"推翻自己 | 先把一个流派学通，再横向比较。本库统一以扶抑为主干、调候为修正（见板块7_8 优先级） |
| **神煞喧宾夺主** | 一上来就背桃花驿马，忘了旺衰格局 | 神煞永远依附格局与旺衰，定位是"加减分"，权重约 10%（见板块8_7） |
| **断语绝对化** | "见伤官见官必离婚" | 任何断语都要过三关：喜忌、宫位、旺衰（见板块4_3 意象运用三要点） |

#### 0_8_3 遇到分歧时的处理原则

命理体系中存在大量流派分歧（六亲口径、子时分界、三会三合孰强等）。遇到时：

```plain
第1步：承认分歧客观存在，不要急着判谁对谁错
第2步：选定一套口径，在同一份分析里贯彻到底
第3步：若两派结论冲突，以"星宫同看 + 实际经历校验"为准
第4步：向他人说明时，如实交代"此处有不同做法"
```

本知识库已对常见分歧统一了口径，清单见总纲「术语口径统一」。

#### 0_8_4 落地实操：建一个"口径本"

拿一页纸或建一个文档，遇到分歧就记一条，格式固定：

```plain
| 分歧点 | 甲派说法 | 乙派说法 | 我采用 | 理由 |
```

**记完之后做一件事**：等攒够十条，回头标红——**只标那些会改变结论的口径**（如大运顺逆判定干、女命父母星、子时分界），其余的只作了解。

| 会改变结论的（标红） | 不影响结论的（了解即可） |
| :---: | :--- |
| 大运顺逆看年干还是日干 | 三会与三合谁更强（多数情况下结论一致） |
| 女命母亲看正印还是偏印 | 某神煞的查法差异 |
| 子时日柱分界 23:00 还是 0:00 | 格局命名的细微差别 |

> **一句话**：**遇到分歧，先记录、先选用，不急着裁决。** 真正需要你统一的，只有那几条会改变结论的。

---

#### 0_8_5 案例小故事：被三种说法绕晕的那半年

> 小冯学完基础后开始给人看盘，很快就撞上了一件让他崩溃的事——同样一个问题，不同地方的说法完全不同。
>
> 最典型的是女命的父亲该看哪个星。他在一处看到"偏财为父"，在另一处看到"正财为父"。两种说法都有理有据，都举了例子，他看了整整两天也没分出对错。
>
> 更要命的是，这种事不止一桩。子时到底算哪一天？三会和三合谁更强？用神该不该随大运变？每一个问题都有两派，每一派都言之成理。
>
> 那半年他基本没再排新盘，因为他发现自己"每下一个断语，心里都在打鼓"。
>
> 后来一位前辈跟他说了一段话，他记了很久：
>
> **"分歧是这门学问的常态，不是你的问题。你要做的不是找出唯一真理，而是选定一套、用熟它。等你用熟了一套，再回头看其他派别，会发现它们不是互相否定，很多时候只是看问题的角度不同。"**
>
> 前辈给了他一个很实用的做法：**准备一个"口径本"**，每遇到一处分歧，就把两派的说法各写一行，然后在旁边标注"我采用哪一派、为什么"。遇到分歧就记一条，不急着解决。
>
> 半年后他攒了二十多条。他发现其中绝大部分分歧，在实际分析中根本不影响结论——真正会改变结论的，只有少数几条（比如六亲口径、子时分界）。
>
> 他把那几条单独标红，其余的只作了解。从那以后，他下断语时再没打过鼓。
>
> **复盘拆解**：小冯那半年"每下一个断语心里都在打鼓"，根源不是他学得差，而是他误以为**分歧需要被裁决**。前辈那句话点破了：分歧是这门学问的常态，你要做的不是找出唯一真理，而是**选定一套、用熟它**。
>
> "口径本"这个做法之所以有效，是因为它把"要不要解决"这个焦虑问题，转化成了"记一笔、标个选择"这个可执行动作。半年后他发现的事实更有价值：**绝大部分分歧在实际分析中根本不影响结论**——真正会改变结论的只有少数几条。
>
> 那几条恰恰就是本库总纲那张口径表的由来。**所以正确顺序是：先记录、先选用，不急着裁决；用熟一套之后，再回头看其他派别，往往会发现它们只是角度不同，而不是互相否定。**
>
> 需要单独标红的，就是本库反复强调的这几条：大运顺逆的判定干（年干 vs 日干）、女命父母星（正印为母 vs 偏印为母）、子时日柱分界（23:00 vs 0:00）。

> **可复用的经验**：**遇到分歧，先记录、先选用，不急着裁决。** 你真正需要统一的，只有那几条会改变结论的口径。

#### 0_8_6 本板块的三句话总结

```plain
学习路径  →  解决"往哪走"
难度体系  →  解决"走多快"
笔记模板  →  解决"走没走实"
验收清单  →  解决"到没到"
四者缺一，知识体系就有缺口。
```

#### 0_8_7 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 分歧是常态，不是你学得差 | 急着裁决出唯一真理 | 各派只是角度不同 |
| 先记录、先选用，不急着解决 | 遇到分歧就卡住不动 | 口径本记一笔，继续往前学 |
| 只统一会改变结论的那几条 | 每条分歧都要争出对错 | 顺逆判定干、父母星、子时分界需标红 |

### 0_9 易错对照表

> 本板块不教命理规则，但学习方法本身也有容易混淆的地方。这张表用于自检"我是不是在用错误的方式努力"。

| 易混对 | 关键区别 | 一句话记法 |
| :---: | :---: | :--- |
| 看懂 vs 掌握 | 看懂是被动输入，掌握是能主动复现（默画、讲给别人听） | 眼睛会了 ≠ 手会了 |
| 记忆型知识 vs 理解型知识 | 口诀、藏干、纳音靠重复；旺衰、用神、格局靠推导 | 记忆放通勤，理解放整块时间 |
| 简单档正确率 vs 真实水平 | 正确率是样本指标，验收清单才是覆盖指标 | 82% 也可能有整块盲区 |
| 刷得多 vs 练得对 | 卡关时加量无效，要先定位"最大公约数" | 连错三题就停，找交集 |
| 按日期记错题 vs 按考点记错题 | 按日期只方便复盘，按考点才能看出系统性漏洞 | 错题本按考点分册 |
| 自编同类题 vs 重做原题 | 做对原题可能是记住了答案，编出新题才是掌握结构 | 四问卡第3问最关键 |
| 笔记记规则 vs 笔记记易错点 | 规则书上有，易错点只有你自己有 | 「易错点」栏是笔记的灵魂 |
| 单元级 vs 板块级验收 | 单元级查单个单元，板块级查整个板块的能力点 | 单元测试过了，板块验收仍可能不及格 |
