# 板块2 · 天干地支体系
> **本板块定位**：八字的"字母与单词"。天干地支是命理推演的最小单位，藏干是干支沟通的桥梁，合冲刑害是字与字之间的化学反应。
**通关产出**：一张默画版藏干表 + 一张"合冲刑害优先级"决策图 + 六十甲子纳音前 20 组记忆。
**建议用时**：4~5 周（2_1~2_2、2_7 纯记忆；2_3、2_3_5、2_4~2_6 需理解）
**边界说明**：本板块讲"字与字之间的作用规则"；这些规则如何用于旺衰判定，属于板块5；如何用于格局与应期，属于板块6、板块9。
>

**六个单元分两段：前两个认字，后四个讲字与字之间的关系**：

```plain
【认字阶段】
2_1 十天干     →  天干是什么、各有什么性格
2_2 十二地支   →  地支是什么、方位季节生肖

【关系阶段】
2_3 藏干       →  地支里面还藏着天干（干支沟通的桥梁）
2_4 合化       →  字与字"合"在一起
2_5 刑冲克害   →  字与字"冲"在一起
2_6 纳音       →  干支组合的辅助属性
```

**为什么藏干要排在合化之前？** 因为合化的本质是藏干之间的作用——比如"寅亥合木"，靠的正是亥中所藏的甲木被引动。不理解藏干，合化就只能靠死记。

**为什么刑冲要排在合化之后？** 因为实战中要判优先级（合 > 冲 > 刑 > 害 > 破），先学会"合"再学"冲"，才能建立正确的排序直觉。

一句话串起来：**先认字（2_1~2_2），再看字里藏着什么（2_3），然后看字与字怎么合（2_4）、怎么冲（2_5），最后补一层辅助信息（2_6）。**

### 四、天干四冲
```plain
甲庚冲 │ 乙辛冲 │ 丙壬冲 │ 丁癸冲
```

> **特点**：同性相斥，冲击力更强。天干相冲的本质是"阳克阳、阴克阴"的相克关系（如甲庚：庚金克甲木），因为同性，所以克得更直接、更无情。
>

### 八、案例小故事：同一个上司，两种活法
> 公司里有两个木日主的员工，一个甲木，一个乙木，同期入职，能力相当，连工位都挨着。
>
> 凑巧的是，他们的直属上司是个金旺的人——说话直接、要求严苛、容不得异议。对下属来说，这就是"官杀重"的环境：金克木，压力直接压在日主身上。
>
> 三年之后，两人的处境天差地别。
>
> **甲木那位（大树）选择了硬扛。** 上司提出不合理的方案，他当面据理力争；流程有问题，他写邮件抄送全组；会议上被否定，他当场拿出数据反驳。三年里他换了四个部门，每一次调动的原因都一样——跟上级顶上了。
>
> 最后他辞职创业，走的时候说了句："我受不了被人修剪。"
>
> 有意思的是，他创业后反而做得不错——没有上级管着他，那种"宁折不弯"的劲头成了执行力。
>
> **乙木那位（藤蔓）选择了绕行。** 同样是面对不合理的方案，他先执行，但在执行中悄悄加入自己的调整；他会把成果包装成上司想要的样子，再顺势提出自己的建议；被否定时不争辩，隔一周换个角度再提一次。
>
> 五年后，他成了那位上司的接班人。上司退休时只说了一句："他最让我省心。"
>
> 后来两人一起吃饭聊起这事，甲木那位感慨："我这辈子就是学不会绕。"
>
> 乙木那位回了一句："我也学不会你的那种硬。"
>
> **复盘拆解**：两人面对的是同一个上司、同一种"官杀重"的环境，结果一个是"掀桌子走人"，一个是"接了班"。**差别不在能力，也不在谁更能忍，而在"对抗方式"是否匹配自己的结构。**
>
> 甲木的结构决定了硬扛就是它的默认反应，所以正确解法不是"学会低头"（那是跟结构对着干），而是**换一个不需要低头的位置**——他去创业正是对的。乙木的结构允许绕行，所以正确解法不是"硬气一点"，而是**继续借势，只要根还在**。
>
> 这给出一条通用思路：**性格建议不能违反结构。** 劝甲木"学会绕"、劝乙木"学会硬"，都是在要求对方改成另一种天干，注定失败。正确做法是顺着结构选环境——**改环境比改性格容易得多。**

> **可复用的经验**：甲木喜庚金雕琢而成器，但忌强金砍伐——所以甲木人在压力型环境里容易两极化：要么被压制得动弹不得，要么干脆掀桌子走人，换个没人管的地方反而能成事。乙木柔韧能屈能伸，最忌的是"被连根拔起"（根被冲），只要根还在，弯一弯腰不算什么。
>
> 所以**天干特性不是性格标签，而是"这个人在压力下会怎么反应"的说明书**。用这条去选环境——甲木人适合能自己说了算的位置，乙木人适合在大体系里借势生长——比劝甲木"学会低头"、劝乙木"硬气一点"有用得多。
>

### 补充 · 天干特性的四个实战用法
记住十天干的类象只是第一步，更要紧的是知道它用在哪。天干特性在实战中共四个用处：

| 用法 | 怎么查 | 注意 |
| --- | --- | --- |
| 断性格底色 | 看日主是哪个天干，取其核心意象 | 阳干偏外向施与，阴干偏内敛承受 |
| 断"压力下的反应" | 看日主天干 + 克它的那个字有多大力量 | 甲木硬扛、乙木绕行，不是优劣而是策略差异 |
| 断输出方式 | 看透出的食伤是阳干还是阴干 | 阳透主爆发、阴透主持久（详见 1_1） |
| 断合作与用人 | 看伙伴、下属的天干特性 | 甲木适合自己说了算的位置，乙木适合在大体系里借势 |

> **一条易错**：天干特性不等于吉凶。甲木的"宁折不弯"在创业里是执行力，在层级森严的体系里就是持续的冲突源——**同一个特性，换个环境，评价完全反过来。** 所以断性格时一定要带上"在什么环境下"这个限定，否则就是把特点说成了优缺点。

### 六、案例小故事：三会局的爆发与代价
> 某命例地支为寅、卯、辰三字齐全且紧贴，构成东方木局，日主又恰是甲木。
>
> 三十五岁之前，此人只是个普通的公司职员，能力不差但一直没机会。三十五岁那年他进入一步水运——水生木，木局被彻底激活。
>
> 接下来的三年，他像换了个人：从普通职员一路做到区域负责人，连跳三级。用他自己的话说："那三年我几乎感觉不到累，每天都有使不完的劲。"
>
> 但代价也来得很快。第三年体检，肝胆指标全线亮红灯，医生问他最近是不是长期熬夜加高强度工作。他这才意识到——木过旺成病，正是板块1 讲的"亢则为病"。
>
> 老师给他的建议很朴素：**三会局一旦成立，力量远超其他组合，既是大机遇，也是大消耗。水运补水激活了木局，就要主动给这股力量找出口——多运动（泄）、多输出（泄），而不是一味地干。**
>
> 更关键的是下一步。老师没有让他"注意休息"就完事，而是给了具体方案：**木旺的出口有两个——"泄"（输出、运动、创作）和"克"（用金来修剪，也就是给自己设规矩、找强约束的上级）。** 对身强木旺的人来说，硬憋着不出是下策，主动找出口才是上策。
>
> 他后来养成了一个习惯：每天固定一小时高强度运动，把多余的"木气"用掉；同时给自己找了一位要求极严的合伙人——不是请人来帮忙，而是请人来"管"。几年下来，事业继续走高，体检指标也恢复了正常。
>
> 他事后说了一句很实在的话：**"那三年不是身体出了问题，是我只进不出。"**
>
> **复盘拆解**：这个案子的关键转折不在"木局被激活"，而在**之后他给那股能量找了出口**。三会局成立只是把能量集中起来，能量本身不管方向——不管它，它就会往身体上走（木旺克土、肝胆负荷）。
>
> 他做的两件事，恰好对应木的两个出口：**运动与输出是"泄"**（让能量流出去），**找严苛的合伙人是"克"**（给能量加约束）。两条一起用，才把那三年的透支状态扳回来。
>
> 所以看到三会三合成局，标准的后续动作是两句：**先判断这股能量是用神还是忌神**（用神则放手用，忌神则要制化），**再替它找一个出口**（泄或克）。**只说"要发了"就停住，是这个格局最常见的误读。**

> **可复用的经验**：力量越强，越需要出口。看到三会三合成立，第一反应不该是"要发了"，而是"这股能量往哪儿去"。**成局 = 能量集中，但能量本身不管方向——你得替它找方向。**
>

### 补充 · 三组地支的实战含义（四正 / 四生 / 四库）
把十二地支分成三组，不只是为了方便记藏干，更因为三组的"行为模式"本身不同：

| 组别 | 成员 | 行为特征 | 实战提示 |
| --- | --- | --- | --- |
| 四正 | 子 午 卯 酉 | 气专而纯，藏干单一 | 成格时清透，破格时也干脆；逢冲反应剧烈 |

## 2_3 地支藏干
### 一、为什么要有藏干
地支是"载体"，天干是"表现"。每个地支内部藏有 1~3 个天干，称为"人元司令"，代表该地支内部真实存在的五行成分。

**核心意义**：地支藏干是天干与地支沟通的桥梁。没有藏干，天干就"悬空"了——一个天干若在地支找不到同五行的藏干，它的力量就大打折扣。

### 三、通根与根气强弱
**通根**：天干在地支找到同五行的藏干，就叫"得根"。

| 根的类型 | 强度 | 说明 |
| --- | --- | --- |
| 本气根（临官 / 帝旺位） | ★★★★★ | 最强的根 |
| 本气根（长生 / 墓位） | ★★★★ | 强根 |
| 中气根 | ★★★ | 中等根 |
| 余气根 | ★★ | 弱根（也叫"假根"） |
| 远隔地支的根 | ★ | 微根（距离越远越弱） |

**根的位置权重**：

```plain
日支根（★★★★★）最重要，紧贴日主
   ↓
月支根（★★★★）得令且有根
   ↓
时支根（★★★）稍远但有用
   ↓
年支根（★★）力量最弱
```

### 四、盖头与截脚
| 术语 | 定义 | 例子 | 影响 |
| --- | --- | --- | --- |
| **盖头** | 天干克坐下的地支 | 庚寅（庚金克寅木） | 地支力量受损，根气打折 |
| **截脚** | 地支克上面的天干 | 甲申（申金克甲木） | 天干力量受损，虚浮无根 |

> **实操要点**：看到"盖头截脚"的组合，不能简单按五行数量加减分，必须打折计算。
>

### 五、落地实操：通根检查四步
```plain
第1步：确定日主五行（例：甲木）
第2步：逐支检查藏干中有无"木"（甲或乙），年支→月支→日支→时支逐个过
第3步：确认找到的是本气、中气还是余气
第4步：确认位置（日支最近、年支最远），给出根的等级
```

**示例**：

```plain
四柱：   年      月      日      时
天干：   壬      庚      甲      丙
地支：   申      戌      辰      寅

日主甲木，逐支检查：
  年支申：藏 庚壬戊 → 无木 → 无根
  月支戌：藏 戊辛丁 → 无木 → 无根
  日支辰：藏 戊乙癸 → 有乙木（中气）→ 中气根，位置最近 ★★★
  时支寅：藏 甲丙戊 → 有甲木（本气）→ 本气根，稍远     ★★★★

结论：日主得中气根（日支）+ 本气根（时支），根气不弱；
      只是不得令（戌月土旺）。
```

### 六、案例小故事：一根之差，格局改写
> 某命例庚金日主，天干一片火土，火土叠见，看上去金被火克得死死的。几位初学者看完都判"从杀格"，取用方向是顺官杀之势。
>
> 老师翻到时柱，指着时支"申"问："这个申里藏着什么？"
>
> 有人答："庚壬戊。"
>
> "庚是什么？"
>
> 有人小声答："是日主本人。"
>
> 老师点点头："这就是庚金的本气根。位置虽然在时支，偏远，但根气真实存在。**有根就谈不上从**，只能论'身极弱'。身极弱要生扶，从格要顺势——这两个取用方向，几乎是相反的。"
>
> 后来行运到金运，此人一路上升，事业、财运都有明显起色。如果当初按从格论，金运本该是"还原"的凶运，断语会完全颠倒。
>
> **当时那位初学者的反驳值得一提**。他追问："申在时支，离日主这么远，这个根还能算数吗？"老师的回答是：**"远根也是根。它决定不了你现在有多强，但它决定你能不能被论'从'——这是一票否决项，不是加分项。"**
>
> 后来行到金运，此人事业与财运同步起色，印证了"身极弱待生扶"的判断。若当初按从杀格论，金运恰恰是"还原"之凶运，所有建议都会反着给：该收缩的年份让他进攻，该进攻的年份让他收缩。
>
> **复盘拆解**：这个案子真正的教训不是"要看仔细"，而是**分清楚两类规则**——一类是加减分项（根近不近、印有力没有力），一类是一票否决项（有没有根、能不能从）。加减分项可以凭经验估，一票否决项必须逐条查。判断从格时，把四个地支的藏干各查一遍，这两分钟省不得。

> **可复用的经验**：判断从格时，宁可保守。翻一遍四个地支的藏干，确认到底有没有根——这一步省不得。
>

### 补充 · 藏干力量的量化参考
藏干不是"有就行"，本气、中气、余气的力量差别很大。下面这组比例是常用的经验参考值（**用于比较，不是精确计算**）：

| 层级 | 大致力量占比 | 说明 |
| :---: | :---: | :--- |
| **本气** | 约 60%~70% | 该地支的主气，力量最强 |
| **中气** | 约 20%~30% | 次之气，明显弱于本气 |
| **余气** | 约 10% 以下 | 残留之气，只能算"有根" |

**力量的三个修正项**：

```plain
第1条 位置修正：日支 > 月支 > 时支 > 年支（离日主越近，越能为我所用）
第2条 盖头截脚：天干克支（盖头）或支克天干（截脚）时，该柱力量打 5~7 折
第3条 冲合修正：被冲则力量受损或释放（视对象而定），被合则被牵制、打折扣
```

**通根判断的"够不够"标准**（实战常用）：

```plain
本气根（临官 / 帝旺位）  →  足以自立，一般不论从
中气根                  →  多半自立，但底气不足
余气根 + 紧贴日主        →  勉强自立，遇强运易被动摇
余气根 + 远隔（年支）    →  力量难及日主，可视为"微根"
```

> **这一层是板块5_6"从格五问"的直接依据**——判断"有没有根"能不能成立，靠的就是这张量级表。

## 2_3_5 透干（藏干透出）
> **本单元定位**：2_3 讲"地支里藏着什么"，本单元讲"藏着的字有没有浮到天干上来"。两件事必须连着看——**藏而不透是"有实力没名气"，透出天干才是"摆到台面上"。**
>

### 一、什么是透干
某个地支的藏干，恰好也出现在四柱的天干上，就叫这个藏干**透出**（也叫"透干""发动"）。

```plain
例：月支寅（藏 甲木本气、丙火中气、戊土余气）
   天干见甲 → 甲木透出（本气透干，力量最足）
   天干见丙 → 丙火透出（中气透干）
   天干见戊 → 戊土透出（余气透干）
   天干上甲丙戊都没有 → 三者皆不透，力量闷在地支里
```

**透干的三个层级**（按力量递减）：

| 层级 | 含义 | 力量 |
| :---: | :---: | :--- |
| **本气透干** | 地支本气出现在天干 | 最足，等同天干本字 |
| **中气透干** | 地支中气出现在天干 | 中等，有根但力度次之 |
| **余气透干** | 地支余气出现在天干 | 最弱，有名无实居多 |

### 二、透干的三条实战意义
| 意义 | 说明 | 应用 |
| :---: | :---: | :--- |
| **第1条 定格局的前提** | 八格以"月令本气透干"为主要定格依据 | 不透则不成正格（见板块6_1） |
| **第2条 决定力量能否"明用"** | 透出的字参与天干之间的生克制化，作用力直接可见 | 用神透出 > 用神只藏于支 |
| **第3条 决定意象是否外显** | 透干主"别人看得见"，藏而不透主"内里有" | 财透干 = 会赚钱被人知；财藏支 = 低调有实财 |

### 三、三条易错
```plain
第1条 以为"透出就强"
   透出只解决"能不能被看见"，不解决"有没有力"
   透出但无根 = 虚浮，看着有，实际使不上劲
   （"透"与"有根"是两件事，不要混为一谈）

第2条 忽略透出的位置
   透在月干、时干（紧贴日主）影响大；透在年干影响相对小
   同是财星透干：透时干主"自己赚的"，透年干主"家里带来的"

第3条 把"藏干里的字"直接当十神用
   藏干参与的是"得地、通根"的计算
   要参与天干生克，必须先透出来
```

### 四、落地实操：透干检查四步
拿到一个八字，按这四步把"藏"与"透"的关系理清楚：

```plain
第1步 逐支列出藏干（本气 / 中气 / 余气各是什么）
第2步 对照四柱天干，看哪些藏干透出来了
第3步 标出透干的位置（年 / 月 / 日 / 时）——位置决定影响范围
第4步 判断透出的字是否有根——有根则有力，无根则虚浮
```

> **这一步与定格局直接相连**：第2步做完，就已经知道月令本气透没透；透则入正格，不透则退看中气余气（见 6_1 定格五步法）。

### 五、案例小故事：透与不透，差一个世界
> 两个命局都是"月支藏有正官"，天干却一个是透、一个不透，人生呈现完全相反的状态。
>
> **第一位：官星透于月干。** 他从小就是那种"被看见的人"——班干部、学生会的、单位里最早被提拔的那一批。他自己也说不清为什么，只是"每次机会来的时候，我恰好在名单上"。
>
> **第二位：官星藏于月支，天干不透。** 能力公认地强，部门里最难的活都是他接，可十年过去，职位纹丝不动。他自己总结："我干的活和别人一样，但好像没人知道是我干的。"
>
> 两人一度在同行交流会上碰面，聊起各自的处境都很感慨。
>
> 排盘师后来点破了差别：**"不是能力差，是'显不显'。官星透干，你的成绩天然在台面上；官星藏支，成绩是真的，但需要你自己端出来。"**
>
> 给第二位的建议不是"更努力"，而是**换动作**：主动做汇报、把成果写成可见的东西、争取公开场合的曝光——用行为去补"不透"这个结构缺口。
>
> 两年后他升了一级。他的反馈很朴素：**"活还是那些活，只是我开始让它被看见了。"**
>
> **复盘拆解**：这个案子最容易被误读成"第二个命局不如第一个"。其实两人的官星力量相当，差别只在**显隐**——透干主"他人可见"，藏支主"内里有实"。
>
> 由此可以得到一条很实用的建议原则：**不透的人不是要更努力，而是要"端出来"。** 努力是在补力量，端出来是在补显隐——补错了方向，越努力越憋屈。
>
> **可复用的经验**：**藏干管"有没有"，透干管"显不显"。** 判断任何一个字的实际影响力，两件事都要问：它藏在哪儿？它透出来了吗？
>

### 六、笔记法
| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 藏干透出天干 = 透干 | 以为透出就等于有力 | 官透干但无根 = 虚名 |
| 本气透 > 中气透 > 余气透 | 一律同等看待 | 寅中甲透 vs 寅中戊透 |
| 透在月时（贴日主）影响大 | 只看透没透，不看透在哪 | 财透时干 vs 财透年干 |

### 七、实用验证
+ **验证 1**：给任意一个八字列出四支藏干，并标出哪些透出、透在哪一柱。
+ **验证 2**：说出一个"透出但虚浮"的命局特征，以及它对断语的影响。
+ **验证 3**：解释"藏而不透"该给出什么样的建议（提示：补显隐，不是补力量）。

## 2_4 天干地支合化
### 一、天干五合（表 + 条件）
| 合 | 化 | 名称 | 条件要点 |
| --- | --- | --- | --- |
| 甲己 | 土 | 中正之合 | 需土月或土透 |
| 乙庚 | 金 | 仁义之合 | 需金月或金透 |
| 丙辛 | 水 | 清明之合 | 需水月或水透 |
| 丁壬 | 木 | 淫昵之合 | 需木月或木透 |
| 戊癸 | 火 | 无情之合 | 需火月或火透 |

### 二、合化的三种结果（核心判断）
```plain
┌───────────────────────────────────────────────────┐
│ 第1种 合化成功（真化）—— 少数情况                 │
│    条件：月令支持 + 紧贴 + 无破 + 有引化          │
│    结果：两干皆变，以所化之五行论                 │
│                                                   │
│ 第2种 合而不化 —— 大多数情况（默认判断）          │
│    结果：仍以原五行论，但有羁绊牵制之力           │
│    表现：该字被"拖住"，作用力打折、有心无力       │
│                                                   │
│ 第3种 合多不化 —— 如两甲合一己                    │
│    结果：争合反而不化，双方都被牵制               │
└───────────────────────────────────────────────────┘
```

> **实操原则**：**默认按"合而不化"处理**，只有四个条件全部满足时才判真化。这是安全且高效的判断策略——绝大多数初学者犯的错，恰恰是"一见合就当化"。
>

### 三、地支六合
| 六合 | 合化 | 特点 |
| --- | --- | --- |

### 五、落地实操：合化判断五步
```plain
第1步：找出命局中所有的"合"（天干五合、地支六合、三合、三会）
第2步：逐一检查四条件（相邻？月令支持？无破？有引化？）
第3步：满足条件 → 判"化"；不满足 → 判"合而不化"
第4步：对"合而不化"的字，标记为"被牵制"，力量打折
第5步：把合化的结果代入后续的旺衰与格局分析
```

### 六、案例小故事：争合的四年
> 一位女士来问婚姻。她的命局天干是两甲夹一己，形成"两甲合一己"。
>
> 若按"甲己合化土"直接论，似乎土旺有财，婚姻该是顺遂的。但按"合多不化"的规则，两甲争一己，谁也合不成，己土被两边同时拉扯——主感情上的犹疑与竞争。
>
> 实际情况正是如此。她当时在两段关系之间反复摇摆了四年：一位是交往多年的男友，稳定但平淡；一位是工作中认识的，热烈但不确定。她每个月都在"选哪个"之间反复，两位也都知道对方的存在，局面越来越僵。
>
> 咨询时老师没给她"该选谁"的答案，只说了句："你命局里两甲争一己，这四年不是你在选，是这个结构在拖着你。要么现在做个了断，要么再拖四年，结果也一样。"
>
> 她当时反问了一句："那我怎么知道该选哪个？"
>
> 老师的回答很有意思：**"命理不替你做选择。它只能告诉你——你现在的状态是'卡住'，不是'权衡'。真正的权衡会有进展，卡住不会。既然是卡住，那么随便哪一个都行，但必须选一个。"**
>
> 半年后她做了决定，结束了其中一段。她说那句话把她骂醒了："我一直以为是我太慎重，其实是我根本不敢承担选择的后果。"
>
> 老师后来复盘这个案例时补了一句要紧的：**"争合的本质是'两股力量互相抵消'。它最典型的现实表现不是'选项多'，而是'长期悬而不决'——当事人往往把这当成性格问题，其实是结构问题。"**
>
> **复盘拆解**：这个案子真正的价值在于那句"被合住不等于消失"。四年的停滞不是没有进展，而是力量被牵制着使不出来——这在断语上有个很重要的对应：**"合住"的应期是"冲开或岁运解合之年"**，而不是"永远不会动"。
>
> 排盘师没说"你这个格局废了"，说的是"要等引动"，这就是把静态结论翻译成了时间信息。
>
> 还有一层：**争合与妒合的区别在于"有没有字来解"。** 有解则只是迟到，无解则长期牵制。判断时看两件事——被合的字有没有被冲，岁运有没有来合走其中一个。

> **可复用的经验**：合是好事，但"争合"是内耗。遇到争合，先论牵制，再论吉凶——不要急着往"合化成功"上靠。判断标准也很简单：**同样的犹豫如果持续超过一年还没有进展，那多半不是慎重，是争合。**
>

| 生地半合力量 > 墓库半合 | 忽略半合也有强弱之分 | 申子 > 子辰 |

### 补充 · 合化的四类常见误判
"一见合就论化"是最普遍的错误。下面四类误判占初学者合化错误的九成：

| 误判 | 典型表现 | 正确判断 |
| :---: | :---: | :--- |
| **误判一：见合即化** | 看到甲己就当"合化成土" | 默认按**合而不化**处理，四条件全中才论真化 |
| **误判二：忘了看月令** | 甲己合在寅月，也论化土 | 化土需辰戌丑未月（或土透有力），寅月不化 |
| **误判三：忽略争合** | 两甲夹一己，论"甲己合土" | 争合反而不化，双方都被牵制 |
| **误判四：不管隔位** | 年干与时干相合，也当紧贴论 | 合化须**紧贴**，隔位只论"有合意"，力量大减 |

**合而不化时，该怎么论？** 这是最容易被跳过的一层——不化不代表没影响：

```plain
合而不化 = 两字互相牵绊
  · 该字的作用力打折（想生克，但心有余力不足）
  · 该字的意象带"纠缠、犹豫、放不下"
  · 若所合之神是忌神 → 反而是好事（忌神被拖住）
  · 若所合之神是用神 → 用神被羁绊，发力受阻
```

**一个实用判断顺序**：

```plain
第1步：找出命局中所有的合
第2步：逐个检查四条件，判定"化 / 不化 / 争合不化"
第3步：不化的标为"被牵制"，力量打折
第4步：特别标注"用神被合"与"忌神被合"——这两条直接影响吉凶
```

### 七、案例小故事：同样是子午冲，一个失一个得
> 两个命局里都有"子午冲"，而且都发生在关键位置。奇怪的是，两人在那一年的人生走向完全相反。
>
> **第一个命局：日主身弱，子水是印星，也是用神。**
>
> 印星主什么？母亲、学业、靠山、庇护。对身弱的人来说，印星是唯一在托着自己的那股力量。而那一年，子水被午火冲去——等于"生扶自己的力量"被连根拔起。
>
> 结果：那一年他母亲查出重病，长期住院；他自己正在读研的关键阶段，被迫中断学业出来工作。用他的话说：**"那年我一下失去了所有依靠。"**
>
> 这正是"冲走用神为凶"。
>
> **第二个命局：日主身强，子水恰恰是忌神。**
>
> 他的子水不是普通的印星，而是"枭印夺食"——偏印克食神。落到生活里，是长期的精神内耗：想太多、做不动、明明有能力却总卡在起跑线上。这个忌神跟了他很多年。
>
> 同样是子午冲，同样是子水被午火冲走。结果却完全相反：那一年他摆脱了困扰多年的焦虑，思路一下子打开了。他形容那种感觉：**"像脑子里有块压了很久的石头被搬走了。"** 同年他考上了研究生。
>
> 这正是"冲走忌神为吉"。
>
> **两人是在一次学习活动上认识的。** 聊起各自的经历，都感慨"那年变化特别大"——但一个变差，一个变好。旁边有位初学者听完更糊涂了，忍不住问："那子午冲到底是好是坏？"
>
> 老师没直接回答，反问了一句：**"你觉得'搬走'这件事，是好事还是坏事？"**
>
> 见他答不上来，老师接着说："那要看搬走的是什么。搬走垃圾是好事，搬走家具是坏事。**冲就是'搬走'——它只负责让事情发生变化，不负责决定这个变化是好是坏。**"
>
> **复盘时老师补了两层，这两层才是这个故事真正值钱的地方：**
>
> **第一层：冲有四种结果，不是只有"冲走"。** 悬殊则"冲去"（本案例属于这种）、均衡则"冲动"、遇库则"冲开"、有根受伤则"冲败"。判断之前先定是哪一种。
>
> **第二层：断大运流年时，凡是"冲"，都要先做一次用忌判定。** 跳过这一步直接背口诀（"子午冲主血光""寅申冲主奔波"），十有八九会断反——因为口诀给的是"象"，吉凶是被冲对象的性质决定的。
>
> **复盘拆解**：两人的差别不在于"有没有冲"，而在于**被冲走的字在命局里扮演什么角色**。子水在第一个局里是唯一的支撑，在第二个局里是长期的内耗源——同一个字，两种身份，冲的结果自然相反。
>
> 由此可以推出一条普适规则：**任何作用关系（冲、合、刑、害、破），判吉凶前都必须先过"用忌"这一关。** 冲只是"变动"这个动作，吉凶是被变动对象的性质决定的。
>
> 老师那个"搬走"的比喻之所以好用，是因为它把"动作"和"对象"拆开了——**动作是中性的，对象才分吉凶。** 记住这一层，就能避开绝大多数"口诀式断吉凶"的坑。

> **可复用的经验**：看到冲，永远先问一句——**被冲走的这个字，是用神还是忌神？** 冲的本质是"变动"，吉凶取决于变动的对象。顺着这条还能推出一层：同样的逻辑适用于冲、合、刑——**任何作用关系，都要先过"用忌"这一关，再谈吉凶。**
>
> 顺着这条还能推出一层：断大运流年时，凡是"冲"，都要先做一次用忌判定，再谈吉凶。跳过这一步直接背口诀（"子午冲主血光""寅申冲主奔波"），十有八九会断反。
>

### 补充 · 冲的四种结果
很多人只记得"冲则散"，其实冲有四种不同的结果，吉凶判断完全不一样：

| 结果 | 含义 | 触发条件 | 吉凶 |
| :---: | :---: | :---: | :--- |
| **冲去** | 弱的一方被冲掉，力量消失 | 双方力量悬殊 | 冲走忌神为吉，冲走用神为凶 |
| **冲动** | 双方都旺，谁也冲不掉，只是被激活 | 势均力敌 | 主变动、折腾、不安定 |
| **冲开** | 冲开墓库，库中物释放 | 辰戌冲、丑未冲遇库 | 看库中物是用是忌 |
| **冲败** | 冲而根气受损，该字"伤而不去" | 有根但根被伤 | 主该字代表的人事出问题但不消失 |

**判断口诀**：

```plain
先看强弱 —— 悬殊则"去"，均衡则"动"
再看对象 —— 去的是用神则凶，去的是忌神则吉
最后看库 —— 四库之冲要额外检查"开了没有"
```

**四条实战提醒**：

```plain
第1条 紧贴之冲力量最大，隔位之冲大减，遥冲常常只是"有点不安分"
第2条 合可解冲（贪合忘冲），冲可破合（冲多不合）
第3条 三合三会成立时凌驾于冲之上——先论局，再论冲
第4条 大运流年之冲是「引动器」：
   原局本来就有冲，流年再冲 → 应事强烈
   原局无冲，流年单冲 → 多为环境变动，未必成灾
```

### 六、案例小故事：纳音不是万能钥匙
> 一位年轻人来问合婚，一进门就焦急地说："我是海中金，她是炉中火，火克金，是不是我们俩不能在一起？家里人也是这么说的。"
>
> 他没有直接用纳音回答，而是先排了两人的八字。
>
> 排完发现：两人用神互补——他命局火土偏旺需要水木，她恰好水木充足；她的用神是金，他的八字里金并不缺。再看日支，两人是六合。大运方面，接下来十年两人都处在上升段。
>
> 他把这些一项项讲完，才回头谈纳音："纳音相克在合婚里确实是个参考项，但权重很低。它给的是一个画面感，不是判决书。真正要紧的是五行是否互补、用神是否相容、日支关系如何、大运是否同步。"
>
> 年轻人听完松了一大口气。后来两人顺利结婚，几年后还一起来谢过一次。
>
> 老师后来用这个案例讲了一堂很重要的课：**"纳音、生肖、星座这类东西有个共同特点——好记。它们把复杂的东西压成一个词，所以传播得最快。"**
>
> **"但你要记住一条规律：越是一听就懂的判断，在完整体系里的权重就越低。命理的判断力，恰恰体现在你能不能在那个'一听就懂的答案'之外，再多问几层。"**
>
> 他给的实操顺序是：**遇到任何单一维度的吉凶说法，先问三句——它在整个体系里占多大权重？有没有更优先的维度被忽略了？如果两者冲突，以哪个为准？**
>
> **复盘拆解**：这个案子最值得记住的是最后那句"权重"。纳音相克在合婚里确实存在，但它是**低权重项**——真正决定的是五行互补、用神相容、日支关系、大运同步这四项。
>
> 判断任何一个"一听就懂"的说法，按三问走：**一问它在体系里占多大权重**（纳音约在最末），**二问有没有更高优先级的维度被它盖住了**（本例是用神互补），**三问两者冲突时以谁为准**（永远以旺衰格局用神为准）。
>
> 还有个实用提醒：**不要急着否定对方的民俗说法。** 直接说"那是迷信"，对方只会觉得被冒犯；把它放回权重序列里讲清楚，对方自己会调整。

> **可复用的经验**：纳音、生肖这类"一听就懂"的说法流传最广，也最容易被误当成结论。**遇到单一维度的吉凶判断，先问问它在整个体系里占多大权重。** 一般规律是：旺衰格局用神 > 神煞 > 纳音生肖。
>

## 2_7 干支体象
> **本单元定位**：体象是干支的"外形与气质"——它长什么样、给人什么感觉。类象回答"对应什么事物"，体象回答"像什么样子"。体象是类象的底层，记熟体象，类象不用死背。
>

### 一、体象与类象：两个层次
```plain
体象 → 形象层：这个干支"看起来是什么"
   例：甲木 = 参天大树、直、硬、向上

类象 → 应用层：这个干支"对应现实中的什么"
   例：甲木 = 肝胆、仁慈、东方、教育、出版

体象是根，类象是枝叶。
记住"甲木像大树"，肝胆、仁慈、东方这些类象都能自己推出来。
```

**为什么要单学体象**：因为类象表越背越长，而体象只有 22 个（十干 + 十二支）。**记住 22 个体象，等于给所有类象找到了记忆锚点。**

### 二、十天干体象
| 天干 | 体象 | 一句话气质 |
| :---: | :---: | :--- |
| **甲** | 参天大树、栋梁之材 | 直、硬、向上、宁折不弯 |
| **乙** | 藤萝、花草、禾苗 | 柔、韧、依附、能屈能伸 |
| **丙** | 太阳、烈火、闪电 | 猛烈、外放、普照、来得快去得也快 |
| **丁** | 灯烛、炉火、星光 | 温和、持久、内聚、细水长流 |
| **戊** | 高山、厚土、堤坝 | 厚重、稳固、承载、慢 |
| **己** | 田园、湿土、泥土 | 温润、包容、可塑、细致 |
| **庚** | 刀剑、顽铁、矿石 | 刚锐、肃杀、需锻炼方成器 |

**三组规律（帮你少背一半）**：

```plain
第1条 四正（子午卯酉）气专——体象纯粹，一种气质到底
第2条 四生（寅申巳亥）主动——体象带"变化、开端、奔波"
第3条 四库（辰戌丑未）主藏——体象带"容纳、封闭、待开"
```

### 四、落地实操：体象联想法（三步）
```plain
第1步 定体象：这个字"看起来是什么"
   例：庚金 → 刀剑、顽铁

第2步 推性质：这种东西有什么特性
   例：刀剑 → 锋利、需打磨、能伤人也能护人

第3步 落到人事：把性质翻译成人的特征或事的状态
   例：庚金日主 → 有棱角、吃软不吃硬、经得起打磨
       庚金为用 → 适合规则明确、需要决断的岗位
```

> **关键在第2步。** 跳过性质直接背"庚金 = 义气"，很快就忘；从"刀剑"推到"锋利需打磨"，再推出人的特征，这条链是活的，用一次就记住了。

### 五、案例小故事：一句话点醒了两个人
> 有两位辛金日主的客户，前后脚来咨询，问题都是"我适合做什么"。
>
> 排盘师没讲十神，也没讲格局，只说了一句：**"辛金是珠玉，不是顽铁。"**
>
> **第一位听完若有所思。** 她在一家大厂做了五年运营，一直是"哪里需要补哪里"的角色，评价永远是"靠谱、能扛"。她说自己最大的困惑是："我什么都能干，但说不清自己是谁。"
>
> 排盘师接着说："珠玉的特点是——**它不需要变成刀才有价值，它需要的是被放到对的地方、被看见。** 你现在的岗位是把你当铁在用。"
>
> 她后来转去做品牌与视觉方向，三年做到负责人。
>
> **第二位的情况正好相反。** 他是工匠出身，做金属加工十几年，手艺极好但一直是个工人。排盘师对他说的是另一半：**"珠玉也要经过打磨才成器。你的问题不是位置不对，是还没被人看见——作品要有署名。"**
>
> 他开始给自己的作品落款、拍照、发到行业社群。两年后，他成了小有名气的独立手艺人。
>
> 同一句"辛金是珠玉"，两个人听到了完全不同的两半——**一个缺的是"被放对地方"，一个缺的是"被看见"。**
>
> **复盘拆解**：体象的用处在这里体现得很清楚——它把抽象的干支变成了一个**可以联想的画面**，而画面能自然生出不同的解读角度。
>
> 排盘师做的不是"套体象"，而是**先看对方缺什么，再从体象里挑对应的那一半**。同一个体象，能给出完全不同的建议，取决于对方当下的处境。
>
> **可复用的经验**：**体象不是答案，是联想的起点。** 用的时候先看清对方缺的是什么，再从体象里取对应的一面——否则就变成了一句漂亮但没用的话。
>
