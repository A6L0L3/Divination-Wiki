```plain
1_1 阴阳   →  给万物"分类"：这个字是刚是柔？
```

### 1_1 阴阳学说

#### 1_1_1 核心概念

> **阴阳最初来自古人对日光的观察——向日为阳，背日为阴。** 后来引申为一套通用的二分法：凡具"明亮、温热、向上、运动、外显、刚健"属性的归**阳**；凡具"晦暗、寒凉、向下、静止、内敛、柔顺"属性的归**阴**。

**一句话定位**：**阴阳不是两种东西，而是同一个东西的两种状态、两种面向。** 它是一套"分类 + 关系"的模型——先把万物分成两类（分类），再说明这两类如何互相作用（关系）。八字里所有关于刚柔、动静、强弱、显隐的判断，根子都在这里。

**阴阳对立统一类象表（完整版）**：

| 维度 | 阳 | 阴 | 维度 | 阳 | 阴 |
| :---: | :--- | :--- | :---: | :--- | :--- |
| 天体 | 天 | 地 | 时间 | 昼 | 夜 |
| 光热 | 明、热 | 暗、寒 | 运动 | 动、进 | 静、退 |
| 方向 | 上、外 | 下、内 | 性质 | 刚、健 | 柔、顺 |
| 性别 | 男 | 女 | 数理 | 奇（1/3/5/7/9） | 偶（2/4/6/8/10） |
| 季节 | 春、夏 | 秋、冬 | 方位 | 东、南 | 西、北 |
| 状态 | 开、显、实 | 合、隐、虚 | 生命 | 生、旺 | 衰、死 |
| 形体 | 气、表 | 血、里 | 中医 | 腑 | 脏 |

> **这张表不用背，要会用。** 用途只有一个：需要判断某个事物"偏阳还是偏阴"时，先找到它的对照项。比如"教育"——主生长、主外显、主给予，偏阳；"研究"——主收藏、主内敛、主深入，偏阴。**判断顺序永远是：先定性（阴阳），再定行（五行）。**

**阴阳的四大关系（本节核心）**：

```plain
第1条 阴阳对立制约
   阴阳是相互对立的两个方面，同时又在对立中彼此约束
   例：寒与热互相制约——没有"寒"也就无所谓"热"

第2条 阴阳互根互用
   阴中有阳，阳中有阴；孤阴不生，独阳不长
   例：没有"静"就显不出"动"，二者互为存在的前提

第3条 阴阳消长平衡
   此消彼长，动态平衡——不是静止的五五开
   例：从春到夏，阳长阴消；从秋到冬，阴长阳消

第4条 阴阳相互转化
   物极必反，重阳必阴，重阴必阳
   例：暑极生寒、寒极生热；命理中"旺极则衰"即此理
```

**阴阳的三个特性**：

```plain
第1条 普遍性：阴阳存在于一切事物之中，没有例外

第2条 相对性：阴阳的划分是相对的、有条件的
   同一事物换了参照系，阴阳属性就可能改变
   例：正午对上午为阳，对盛夏的烈日又为阴
       命理中同理——"身强"是相对全局而言，
       换一步大运，强弱结论就可能改变（见 7_6 行运用神）

第3条 可分性（无限可分）：阴阳之中还可再分阴阳
   例：白昼为阳，其中上午为阳中之阳、下午为阳中之阴
       黑夜为阴，其中前半夜为阴中之阴、后半夜为阴中之阳
```

> **为什么"可分性"对八字重要**：它解释了为什么命理里总有中间状态。日主不是简单的"强或弱"，而是"极旺 / 偏强 / 中和 / 偏弱 / 极弱"五个等级（板块5）；格局也不是"成或破"二选一，而是"上格 / 中格 / 下格"三个层次（板块6）。**阴阳这套模型从一开始就拒绝非黑即白——这也是命理里几乎没有"绝对断语"的底层原因。**

#### 1_1_2 在八字中的体现

```plain
十天干分阴阳
  阳干：甲 丙 戊 庚 壬   （序号 1 / 3 / 5 / 7 / 9）
  阴干：乙 丁 己 辛 癸   （序号 2 / 4 / 6 / 8 / 10）

十二地支分阴阳
  阳支：子 寅 辰 午 申 戌 （序号 1 / 3 / 5 / 7 / 9 / 11）
  阴支：丑 卯 巳 未 酉 亥 （序号 2 / 4 / 6 / 8 / 10 / 12）
```

**四条落地规则**：

```plain
第1条 定"阳男 / 阴女 / 阴男 / 阳女"这四个称呼 —— 看【年干】阴阳，不看日干
   年干为阳 + 男命 → 阳男（顺排大运）
   年干为阴 + 女命 → 阴女（顺排大运）
   年干为阴 + 男命 → 阴男（逆排大运）
   年干为阳 + 女命 → 阳女（逆排大运）
   （这个称呼直接决定大运顺逆排法，详见板块3_4）

第2条 同性作用力强：如甲木见丙火，同性相斥又相生，力量刚猛

第3条 异性亲和力强：如甲木见丁火，异性相吸，化泄更柔顺持久

第4条 阴阳属性只由序号奇偶决定，与五行属性无关
```

> **口径校准（重要）**：这四个称呼在市面资料里有**两套口径**——本库统一以**年干**判定，因为大运顺逆的排法源于"年干阴阳 + 性别"（见板块3_4）。另有部分流派以**日干**判定，本库全程不采用，也不混用。**若你在别处看到"日干定阳男阴女"的说法，那不是错误，只是口径不同；关键在于同一份分析里必须从头到尾只用一套。**

#### 1_1_3 判阴阳三步法（实操）

```plain
第1步：看它在天干 / 地支序列中的序号
第2步：奇数为阳，偶数为阴
第3步：交叉验证——五行相同的一对干支，序号奇的是阳、偶的是阴
        例：甲乙同属木，甲(1) 阳、乙(2) 阴  ✓
            子亥同属水，子(1) 阳、亥(12) 阴  ✓
```

> **易错提示**：子属水却是阳支，亥属水却是阴支——**阴阳与五行无关，只与序号奇偶有关**。这是新手最常混淆的一点，请务必记牢。

#### 1_1_4 落地实操：阴阳速判自检表

拿到任意一个八字，按这张表逐项过一遍，两分钟内能填完：

```plain
□ 日主是哪个天干？序号几？→ 奇阳 / 偶阴
□ "阳男 / 阴女 / 阴男 / 阳女"是哪个？→ 看【年干】+ 性别
□ 四柱天干各自的阴阳：__ / __ / __ / __
□ 四柱地支各自的阴阳：__ / __ / __ / __
□ 生我、克我、我克三对（异性为正）能标出来吗？
□ 我生、同我两对（同性为正）能标出来吗？
```

**自检的关键一条**：日主阴阳与"阳男阴女"称呼**经常不一致**（一个看日干、一个看年干）。填完两栏后确认它们不是同一个字——这是本单元最高频的错误点。

#### 1_1_5 案例小故事：同一条"木生火"，两种人生

> 有两位甲木日主的客户，八字结构非常相近，都是"木生火"的泄秀格局——也就是说，两人的才华都靠"输出"来体现。
>
> 区别只有一个：**一个天干透丙火，另一个透丁火。**
>
> 就这一个字的阴阳之差，两人活成了完全不同的样子。
>
> **透丙火的那位**（甲丙同为阳，同性相斥）：才华外露得极其张扬。他做演讲、搞创作，感染力极强，场场爆满，属于那种一进会议室就能把气氛点燃的人。但爆发力强却不持久——三十岁前连开两家公司，都是起势极猛、两年之内把资源和热情一起烧完，最后不了了之。
>
> 他自己形容那段日子："像一直在放烟花，好看是好看，就是留不下什么。"
>
> **透丁火的那位**（甲阳丁阴，异性相吸）：同样有才华，但完全是另一种形态。他写得一手好专栏，读者不算多却极稳定，十几年下来出了四本书，收入持续而平稳。他不爱抛头露面，但圈内人提起他都认。
>
> 他自己的说法是："文火慢炖。"
>
> 后来两人在一次活动上碰巧坐到一起，聊起各自的经历，都很感慨——明明是同一条规则，怎么过成了两种人生。
>
> 老师听完只说了一句话：**"你们俩的才华是一样的，只是输出方式不同。一个往外炸，一个往外渗。问题从来不是'哪种更好'，而是'你知不知道自己是哪种'。"**
>
> 丙火那位真正的问题，不是"张扬"本身，而是他一直按丁火的方式规划自己——报长期班、做十年计划、逼自己坐冷板凳，每一次都半途而废，还以为是自制力差。想通之后，他改成了项目制：接短期、高曝光、能快速收尾的活儿。反而顺了。
>
> **复盘拆解**：这个案子值得记的有三层。**第一层**，"才华一样"是真的——木生火这个结构没变，变的只是阴阳；**第二层**，"输出方式不同"决定了人生节奏该怎么安排，而不是决定了高下；**第三层**也是最实用的一层——丙火那位真正的亏损，来自**按别人的节奏规划自己**。他不是能力问题，是"项目制的人硬做十年计划"。
>
> 所以判完阴阳，紧接着要落到一句可执行的话：**我该按"爆发—收尾"的节奏排，还是按"持续—积累"的节奏排？** 阴阳给的不是评价，是节奏建议。

> **可复用的经验**：同一条"木生火"的规则，因为阴阳搭配不同，呈现的能量形态可以完全不同。**判完五行，一定要再看阴阳。** 更进一步的用法是：知道自己"输出快"还是"输出久"，比知道自己"有没有才华"更能决定该怎么安排人生节奏。

#### 1_1_6 笔记法 · 三栏笔记示例

| 规则 | 易错点 | 命例 |
| --- | --- | --- |

| 同性作用力强，异性亲和力强 | 甲见丙是"生"，甲见丁也是"生"，但力道性质不同 | 甲木透丙 vs 甲木透丁 |

#### 1_1_8 阴阳在实战中的四个用法

学完判阴阳，要立刻知道它用在哪。阴阳不是独立知识点，它渗透在后面每一步分析里，共四个用法：

| 用法 | 具体作用 | 出处 |
| :---: | :--- | :--- |
| **第1步 定十神的正偏** | 生我、克我、我克三对：异性为正、同性为偏；我生、同我两对恰好相反 | 板块4_1 |
| **第2步 定作用力的性质** | 同性相斥，力量刚猛而直接；异性相吸，力量柔顺而持久 | 本单元 |
| **第3步 定大运的顺逆** | 年干阴阳 + 性别 → 阳男阴女顺排、阴男阳女逆排 | 板块3_4 |
| **第4步 定性格的底色** | 阳干偏外向、施与、刚；阴干偏内敛、承受、柔 | 板块2_1 |

**第四条的实际价值常被低估。** 同样是"有才华"，阳干透出的人倾向于把才华往外放（演讲、创业、抛头露面），阴干透出的人倾向于把才华往外渗（写作、研究、长期积累）。**断性格时，五行说的是"有没有这份能"，阴阳说的是"这份能往哪个方向流"。**

**一个容易混淆的点**：

```plain
阴阳只由序号奇偶决定，与五行属性无关。
  子（水）是阳支，亥（水）是阴支  ——同为水，一阳一阴
  甲（木）是阳干，乙（木）是阴干  ——同为木，一阳一阴
所以"水属阴""木属阳"这类说法是错的，必须落到具体的字上判断。
```

#### 1_2_3 两种特殊关系

| 类型 | 定义 | 经典例证 |
| --- | --- | --- |
| **反克（侮）** | 正常被克的一方反过来压制主克方 | 木坚金缺（木太硬，斧头卷刃）、水多土流（水太大，堤坝冲垮） |
| **反生** | 正常生的一方反而使被生者受损 | 金多水浊（金太多，水反浑浊）、火多木焚（火太大，木被烧尽） |

**实操意义**：反克与反生是"量变引起质变"的预警——**任何生克关系，在力量极端失衡时都会反转**。这正是后面判断"某五行过旺是否为病"的理论基础（详见板块7_4 病药用神）。

#### 1_2_4 五种作用关系（本单元核心）

以日主为"我"，五行之间共有五种作用关系。这是判断旺衰与取用神的起点。

| 关系 | 定义 | 以木为我举例 | 力量性质 |
| --- | --- | --- | --- |
| **生**（生扶） | 生我者，给我力量，使我成长 | 水生木，木得水之生而荣 | 最温和的增益 |
| **泄**（泄气） | 我生者，泄我之气，使我转化 | 木生火，火泄木之气 | 不是单纯消耗，而是能量的输出与转化 |
| **助**（比助） | 同我者，互相增益，使我壮大 | 木见木 | 最直接、最迅速的力量来源 |
| **克**（克制） | 克我者，制约于我，使我收敛 | 金克木，木受金之雕琢 | 压力也是规矩，适克成器、重克成灾 |
| **耗**（耗力） | 我克者，耗我之力，使我付出 | 木克土，土耗木之力 | 克制对方需要自身投入能量 |

**一句话总纲**：

> **生我者为生，同我者为助，我生者为泄，克我者为克，我克者为耗。**

**五行作用五句话（背诵版）**：

```plain
生扶得助身渐强，泄气转化亦寻常；
比助同心增气势，克制压身莫逞强；
耗我之财虽可用，过耗则弱要提防。
```

#### 1_2_6 案例小故事：同为身强，病因不同

> 两位客户都被判为"身强"，前后脚来咨询，问题一模一样："我该往哪个方向发展？"
>
> 老师没有直接回答，而是先让他们各自看自己的"力量账本"。
>
> 第一位：加分项里水（印星）和木（比劫）占了绝大多数。也就是说，他的"强"来自**生扶太多**——从小被照顾得太好，资源充足但缺乏锤炼。取用方向是"泄"和"耗"：用火来泄（输出才华）、用土来耗（务实经营），走"食伤生财"的路子，靠本事和经营取财。
>
> 第二位：加分项同样多，但结构完全不同——他的水木并不多，问题是**金（官杀）极少**，等于几乎没人管得住他，克不动就没有雕琢。取用方向恰恰相反：一旦大运补上官杀（金），反而能成器，走仕途、管理更合适；若按第一位那样"泄耗"，只会让他更散。
>
> 半年后两人反馈：第一位开了家设计工作室，收入稳定；第二位竞聘上了部门负责人，虽然累但干得顺。
>
> 复盘这个案例时，老师点出了关键：**"两位的毛病都叫'身强'，但一个是'补药吃太多'，一个是'没人管'。前者要疏通，后者要约束。方向给反了，越努力越糟。"**
>
> 这也是"力量账本"这个工具存在的意义——**它记录的不是"强或弱"这个结论，而是"强在哪里、弱在哪里"这个结构。** 结论可以一句话说完，但取用方向只能从结构里推出来。
>
> **复盘拆解**：两位客户的问题字面完全相同（"我该往哪个方向发展"），结论字面也相同（"身强"），但答案完全相反。**这说明"身强"两个字本身几乎不含信息量**——它只是个总分，构成才是处方。
>
> 可以把这个差别简化成一句判断：**加分项集中在"生扶"（印比多）→ 要疏通；加分项集中在"缺少制约"（官杀少）→ 要约束。** 前者像营养过剩，需要消耗；后者像没人修剪，需要外力。
>
> 这也解释了为什么"力量账本"必须逐项记：只有记下每一项是加还是减、加在哪一行，才看得出这个"强"到底是什么性质的强。

> **可复用的经验**：同一个"身强"的结论，因为力量账本的构成不同，取用方向可以完全相反。**必须算账，不能凭感觉下结论。** 拿到任何一个旺衰结论之后，下一步永远是打开账本看构成——看加分项集中在"生扶"还是集中在"缺少制约"。

#### 1_2_9 生克作用的"距离"与"位置"效应

同样一组生克关系，出现在不同位置，效果可以差很多。这一层在旺衰判断（板块5）之前必须建立直觉。

**距离效应（三条）**：

```plain
第1条 紧贴最强：相邻两柱的天干直接作用，力量几乎全额体现
第2条 隔位减弱：中间隔了一柱，作用力大约打七折
第3条 远隔最弱：年柱与时柱遥遥相对，有作用但常常"有心无力"
```

**位置效应（四条）**：

| 位置 | 特点 | 断语含义 |
| :---: | :---: | :--- |
| **天干** | 明现于外，力量"看得见" | 主外在、公开、他人能感知到的部分 |
| **地支** | 深藏于内，力量"沉在底下" | 主内在、根基、实质状态 |
| **同柱干支** | 干支一体，互相影响最直接 | 盖头截脚就在这一层发生 |
| **异柱之间** | 需看是否与日主发生关系 | 十神、宫位在这一层展开 |

**一个实用推论**：

```plain
天干透出的字，即使无根，也会"表现"出来——它主的是"别人看到的你"
地支藏干，即使有力，也偏"实际拥有"——它主的是"你真正的底子"

所以常见一种人：天干财星虚浮，看着风光、出手大方（外面有财象）；
地支无根无库，实际存不住钱（里面没底子）。
断语要说清这两层，不能只说一句"有财"或"没财"。
```

### 1_3 五行类象

#### 1_3_1 什么是类象

> **生克是五行的"语法"，类象是五行的"词汇"。**
> 生克告诉你力量的流向，类象告诉你这股力量在现实中对应什么人、什么事、什么物。

#### 1_3_2 核心类象速查表

| 类别 | 木 | 火 | 土 | 金 | 水 |
| --- | --- | --- | --- | --- | --- |
| 方位 | 东 | 南 | 中 | 西 | 北 |
| 季节 | 春（正月至三月） | 夏（四月至六月） | 四季末（辰未戌丑月） | 秋（七月至九月） | 冬（十月至十二月） |

| 五脏 | 肝 / 胆 | 心 / 小肠 | 脾 / 胃 | 肺 / 大肠 | 肾 / 膀胱 |
| 五味 | 酸 | 苦 | 甘 | 辛 | 咸 |
| 五官 | 目 | 舌 | 口 | 鼻 | 耳 |

#### 1_3_3 行业类象（断事业方向时最常用）

```plain
木 ──▶ 园林、木材、纺织、教育、出版
火 ──▶ 能源、餐饮、电子、演艺、传媒
土 ──▶ 建筑、房地产、农业、陶瓷、仓储
金 ──▶ 金融、机械、珠宝、法律、军警
水 ──▶ 航运、物流、贸易、饮料、水产
```

> **使用提醒**：行业是古代类象的现代延伸，不可用得太死。比如"教育"属木，但在线教育同时带火（传媒）属性。实操中先取**用神五行的大方向**，再结合具体岗位特性微调。

#### 1_3_4 落地实操：类象联想法（三步）

类象条目繁多，死背效率极低。用"链式联想"来记：

```plain
第1步 · 定核心意象（一句话画面）
   木 = 一棵向上生长的树
   火 = 一团向上跳跃的火苗
   土 = 一片承载万物的土地
   金 = 一把锋利的刀
   水 = 一股向下流动的水

第2步 · 从画面推出性质
   树 → 生长、条达、正直 → 仁慈、直率、春、东、青、酸、肝、目
   火 → 炎热、向上、明亮 → 热情、急躁、夏、南、红、苦、心、舌
   土 → 承载、化育、厚重 → 稳重、诚信、四季末、中、黄、甘、脾、口
   金 → 肃杀、收敛、刚硬 → 果断、刚毅、秋、西、白、辛、肺、鼻
   水 → 润下、流动、寒冷 → 聪慧、灵活、冬、北、黑、咸、肾、耳

第3步 · 遇到新条目，归入最近的画面
   例："五音之角属木"
       → 角音清扬向上，如草木萌发 → 归入木  ✓
```

#### 1_3_5 案例小故事：类象让断语落地

> 一位初学者给朋友看盘，算出用神是火。他憋了半天说："你适合火相关的行业。"朋友听得云里雾里，追问："什么叫火相关？烧烤？"
>
> 后来他把火的类象整个展开，重新讲了一遍：
>
> "火的类象是——方位在南，颜色红，行业在能源、餐饮、电子、演艺、传媒这一带；性情上主热情、急躁、爱表现；身体对应心与小肠；季节在夏。
>
> 串起来的意思是：你适合往南方发展，做需要曝光度和表现力的工作，传媒、演艺、餐饮都算；性格上你热情但有冲劲，要注意心血管和睡眠；一年里夏天是你的发力期，重要的事尽量排在那个时段。"
>
> 朋友当场就说："这就对上了，我在广告公司做创意，每年夏天提案最多也最顺。"他还补了一句："我确实每年入夏就睡得少，冬天反而容易低沉。"
>
> 那位初学者后来总结：他第一次说的"适合火相关的行业"，其实不能算错——但它停留在五行层面，没有落到任何一个可以执行的动作上。类象的作用，就是**把"五行"这层抽象代码，翻译成"方位、行业、性格、身体、时间"这五个可落地的维度**。
>
> 他给自己定了一个规矩：**每次给出"用神是某五行"之后，必须至少展开三个维度的类象，否则这句话就不算说完。**
>
> **复盘拆解**：那句"适合火相关的行业"其实不算错，它的毛病是**停在了抽象层**。五行是一套代码，类象才是解码器——不解码，代码对接收者毫无意义。
>
> 他后来给自己定的"至少展开三个维度"是个很实用的下限。三个维度建议固定为：**方位（去哪）、行业（做什么）、时间（什么时候发力）**。这三个都能直接转成动作；性格与身体那两个维度适合放在后面作为补充提醒。
>
> 顺带一提，朋友那句反馈（"每年夏天提案最多也最顺""入夏就睡得少"）本身就是最有效的校验——**断语给了具体维度，对方才能拿经历来核对；只给一句"适合火"，对方连怎么核对都不知道。**

> **可复用的经验**：同一条"用神为火"，前一种说法是废话，后一种是服务。**差别就在类象——它把抽象的五行翻译成了可执行的建议。** 判断一条断语有没有用，最简单的检验：对方听完知不知道明天该做什么。

#### 1_3_8 类象的三层读法

类象条目背得再多，直接搬用到断语上也会失准。正确用法是分三层读，一层比一层具体：

```plain
第一层 · 五行本象
   读"这个五行本身是什么"——方位、颜色、季节、行业、脏腑
   例：火 = 南、红、夏、能源/传媒、心与小肠

第二层 · 十神角色
   读"这个五行在命局里扮演什么角色"——印？财？官？食伤？
   例：同样是火，是日主的印星（靠山、学识），还是财星（钱、机会），
       决定了这股火"以什么身份"出现

第三层 · 宫位与喜忌
   读"它应什么事、是吉是凶"——在哪一柱？是用神还是忌神？
   例：火在时柱且为用 → 晚年靠作品或声誉立身
       火在月柱且为忌 → 青年期事业压力大、易有心血管负担
```

**三层读完才能落成断语。** 只做第一层的断语（"你适合火相关的行业"）是废话；三层都过一遍的断语（"你适合往南方发展，做需要曝光度的工作，夏天是你的发力期，但要注意别把节奏绷太紧"）才是服务。

**一条检验标准**：

```plain
断语说完，对方知不知道明天该做什么？
知道 → 类象落到实处了
不知道 → 还停在五行层面，需要再往下读一层
```

```plain
第1点 辰戌丑未四个月不是"木火金水的延续"，而是土当令
   三月（辰）不跟着正月二月论木旺，而是土旺
   这是四季转换的"缓冲带"

第2点 寅月与卯月状态相同，巳月与午月状态相同

   真正要区分开来的，是"四正月"与"四库月"
```

> **四库土的特殊性**：辰为**水库**（湿土，立春前 18 天土旺）、未为**木库**（燥土，立夏前 18 天土旺）、戌为**火库**（燥土，立秋前 18 天土旺）、丑为**金库**（寒土，立冬前 18 天土旺）。
>

>
> 四库土燥湿不同，直接影响力量的发挥——**辰丑为湿土（能晦火生金），未戌为燥土（能脆金助火）**。判断身强身弱、取用神时，这一点常被忽略。

#### 1_4_6 落地实操：旺衰判断的"起手式"

拿到任何一个八字，第一件事永远是这四步：

```plain
第1步：看月支（月令），定当令五行
       寅卯月 → 木   巳午月 → 火   申酉月 → 金
       亥子月 → 水   辰戌丑未月 → 土

第2步：查上表，给日主五行定状态
       例：甲木日主生于酉月 → 秋金当令 → 木的状态是"死"

第3步：给其余七个字也定状态（这一步常被跳过，但很重要）
       例：同命局中天干有壬水 → 秋金生水 → 水为"相" → 生扶有力

第4步：初步结论
       日主"死"而印星"相" → 虽不得令，但有强印生扶
       → 不可轻言身弱
```

> **关键提醒**：旺相休囚死看的是**地支月令**，不是天干月干。很多初学者在这里翻车。

#### 1_4_7 三大应用方向

```plain
第1步 养生：根据出生季节与命局五行偏枯，调整脏腑养护重点，顺时调养
第2步 命理：判断八字五行强弱，定位身强 / 身弱并调候
第3步 取用：旺衰判断是取用神的基础前提（板块5 → 板块7 的主线）
```

> **与板块5 的分工**：本单元讲"某个季节下，五种五行各自的普遍状态"；板块5_1 讲"日主与月令的具体关系、以及它在旺衰判定中占多少权重"。前者是查表工具，后者是判定流程。

#### 1_4_8 案例小故事：被"死"字吓到的新手

> 小吴是自学入门的。学到"旺相休囚死"这一节时，他做的第一件事是给自己排盘——甲木日主，生于酉月。
>
> 他翻到四季五行气数表，顺着"秋"那一行往右找：金旺、水相、土休、火囚、**木死**。
>
> 他看到的不是"木在秋天力量弱"，而是"死"这一个字。他把书一合，整整四天没再打开，还跟朋友说了句"我这命可能不太好"。
>
> 第五天他还是忍不住，拿着盘去找老师。
>
> **老师没有安慰他，也没解释"死"字不吓人，而是让他做一件事：把八个字一个一个查完。**
>
> 师生俩一项项过：
>
> + **月支酉** —— 秋金当令，木在这里确实是"死"地。这一项没错，**失令**。
> + **时支亥** —— 亥是甲木的长生之地，日主在时支有根。这是**得地**。
> + **天干透癸水** —— 癸是甲木的正印；而秋金当令时水是"相"地，也就是说印星正处次旺，生扶有力。这是**得生**。
> + **年支寅** —— 寅是甲木的禄位，又一个根。
>
> 老师这才把表推回他面前："失令，但有根、有印生扶。你自己说，这是不是一个'死'字能概括的？"
>
> 小吴一项项查下来，越查越不好意思。这个命局的准确结论是"偏弱偏中和"，跟凶命完全不沾边——他丢掉的只是 45% 的"得令"分，而"得地"和"得生"两项又把分数拿了回来。
>
> **复盘时老师点出了他犯的两个错，这两个错比"被吓到"本身更值得记：**
>
> **第一个错，是把相对状态当成了吉凶判决。** 旺相休囚死描述的是"这一个字在当前季节处在什么位置"，跟命好不好没有关系。
>
> **第二个错，是查完日主就停了。** 他只查了日主甲木一个字，其他七个字一个没查。命理里几乎没有"只看一个字"就能下的结论——日主弱，但印星旺，那是另一回事；日主弱，印星也弱，才是真的弱。
>
> 那天之后，小吴给自己定了个规矩，后来一直没改：**查完任何一张表，都要把八个字全部过一遍，再允许自己写结论。**
>
> 他在笔记里写下了一句被反复引用的话：**"旺相休囚死是相对状态，不是吉凶判决。单独看一个字的状态毫无意义，要看八个字的合力。"**
>
> **复盘拆解**：除了那两个错，这个案子还藏着一条更普遍的规律——**"吓人的字"几乎都来自把术语当成日常用语**。命理里有一批字是从日常生活借来的（死、墓、绝、囚、空、孤、寡），它们在这里是技术状态名，不是人生判决。
>
> 处理办法很机械：**看到这类字，先把它翻译回定义**（"死"= 我克者在这个季节最弱），翻译完情绪就消失了。
>
> 另外那条规矩值得抄下来：**查完任何一张表，把八个字全部过一遍，再允许自己写结论。** 这条对板块5 尤其重要——旺衰判断的绝大多数错误，都是因为只看了日主就下结论。

> **可复用的经验**：查表查到"死""囚"不要慌，先做两件事——**一是把其余七个字也逐个定状态（尤其看印星和比劫是否得令）；二是记住"失令 ≠ 身弱"**，得地与得生常常能把一个失令的日主救回中和。这也是板块5 要展开的核心内容。

#### 1_4_9 笔记法 · 三栏笔记示例

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 当令者旺、我生者相、生我者休、克我者囚、我克者死 | 看的是**月支**不是月干 | 甲木生于酉月 → 死 |
| 旺相休囚死是相对状态 | 单独一个字的状态不构成吉凶结论 | 甲木死于秋，但亥根 + 癸印可救 |
| 辰戌丑未四个月是**土当令**，不是四季五行的延续 | 三月跟着正月二月论木旺 | 辰月土旺、金相、火休、木囚、水死 |
| 四库土燥湿有别：辰丑湿土、未戌燥土 | 四库土一律同论 | 辰丑能晦火生金，未戌能脆金助火 |

#### 1_4_10 实用验证

#### 1_4_11 旺相休囚死的四个常见误用

这张表是"起手式"，也是出错率最高的地方。四个误用必须提前排掉：

| 误用 | 错在哪 | 正确做法 |
| :---: | :---: | :--- |
| **把"死"当凶** | 以为日主处于"死"地就是命不好 | 旺相休囚死是**相对状态**，只描述这一个字在当前季节的位置；吉凶取决于八个字的合力 |
| **看月干不看月支** | 用月柱天干的五行去查表 | **只看月支（月令）**，月干不参与定季节 |
| **只算日主** | 查完日主状态就下结论 | 其余七个字也要逐个定状态——尤其印星、比劫是否得令，直接决定生扶力度 |
| **四库月跟着上一季走** | 以为辰月（三月）接着寅卯月论木旺 | 辰戌丑未四月是**土当令**，是季节转换的缓冲带 |

**四库月的燥湿还要再分一层**：

```plain
辰、丑 → 湿土：能晦火、能生金（晦火 = 减弱火的力量）
未、戌 → 燥土：能脆金、能助火（脆金 = 削弱金的力量）

举例：同样是"土旺克水"，
   辰丑之水易被收住（湿土蓄水），
   未戌之土则偏向把水熬干（燥土吸水）。
取用神时这一点常被忽略，导致用神取对、力度却判错。
```

#### 1_5_7 落地实操：类象的"三不原则"

使用类象断事时，守住三条底线：

```plain

```

#### 1_5_8 案例小故事：一条被用错的类象

> 一位刚学完类象的学习者，给同事看盘时看到"水极旺"，脱口而出："你肾脏有严重问题，得赶紧去查。"同事当场就慌了，第二天请假去做了一整套检查。
>
> 结果一切正常。同事虽然没说什么，但此后对他一直客客气气地保持距离。
>
> 复盘时，老师指出他犯了三个错：
>
> 第一，没看喜忌。这个命局水恰恰是**用神**，旺而为福，不是病。
> 第二，没看宫位。水旺在**年支**，年柱主祖上与幼年，不主命主自身的健康。
> 第三，把"倾向"当成了"结论"。五行偏枯提示的是敏感度，不是疾病。
>
> 正确的说法应该是：**"命局水旺，先天肾气与泌尿系统相对敏感，秋冬注意保暖和作息，但不代表有病，体检按常规做就行。"**
>
> 后来这位学习者给自己立了一条规矩，叫**"三检查"**：说出任何健康类类象之前，先在心里过三关——一查喜忌（这个五行是用神还是忌神，旺而为福还是旺而成病）；二查宫位（它落在哪一柱，主自身还是主祖上、子女）；三查程度（只是偏旺，还是极旺且叠了冲克）。
>
> 半年后他又遇到一个"金极旺"的盘。这回按三关走了一遍：金为忌神、落在日支、且带酉酉自刑——三条都指向"确实值得提醒"。他的说法是：**"命局金气偏旺又自刑，呼吸系统和皮肤相对敏感，秋冬干燥季容易不舒服，建议室内加湿、少辛辣，体检按常规做即可。"** 对方听完说："我每年秋天都咳两个月。"——这次说中了，而且没有吓到人。
>
> **复盘拆解**：同样是"五行极旺"，前一次连踩三个坑，后一次走通三关。**差别不在类象记得多不多，而在有没有先过喜忌、宫位、程度这三道闸。** 也可以这样自检：说完一句健康类断语后，问自己"对方听完会不会立刻想去医院"——会，就说明说过了。

> **可复用的经验**：类象是加法，不是判决。尤其是涉及健康，分寸感比准确性更重要。

### 1_6 易错对照表

> 这张表汇总本板块最容易混淆的成对概念。**填三栏笔记时，「易错点」栏可以直接从这里取材。**

| 易混对 | 关键区别 | 一句话记法 |
| :---: | :---: | :--- |
| 阴阳 vs 五行 | 阴阳由序号奇偶定，与五行属性无关 | 子（水）是阳支，亥（水）是阴支 |
| 生 vs 泄 | 生我者为生（给我），我生者为泄（我给） | 方向相反，一个是进账一个是输出 |
| 耗 vs 克 | 我克者为耗（我主动付出），克我者为克（压力加身） | 耗是花钱，克是被管 |
| 反克（侮） vs 反生 | 反克是被克方反压主克方；反生是生方反使被生者受损 | 木坚金缺 vs 火多木焚 |
| 旺 vs 相 | 旺是当令者；相是被当令者所生 | 一个自己是主角，一个是主角生的 |
| 休 vs 囚 | 休是生当令者（泄气退隐）；囚是克当令者（反被压制） | 一个累了歇着，一个反抗被按住 |
| 旺相休囚死 vs 十二长生 | 前者是"季节对五行"的影响；后者是"五行在地支"的生命周期 | 前者看月令，后者看地支（板块3_6） |
| 辰丑湿土 vs 未戌燥土 | 辰丑能晦火生金；未戌能脆金助火 | 湿土养金，燥土助火 |
| 四库月 vs 四季延续 | 辰月不是"跟着寅卯论木旺"，而是土当令 | 三月土旺，不跟着春天走 |
| **日主阴阳 vs 年干阴阳** | 日主阴阳用于**判十神正偏**（看日干）；"阳男阴女"用于**定大运顺逆**（看年干） | 判十神看日干，定顺逆看年干 |
| 同性作用 vs 异性作用 | 同性相斥、力量刚猛直接；异性相吸、力量柔顺持久 | 同性猛，异性久 |
| 五行类象 vs 疾病诊断 | 类象只提示先天体质倾向 | 只给养生提醒，不给疾病诊断 |

> **关于"阳男 / 阴女 / 阴男 / 阳女"的口径**：这四个称呼**看年干**，不看日干，因为它们直接决定大运顺逆的排法（板块3_4）。另有流派以日干判定，本库不采用。**年干与日干阴阳不同时，两套口径给出的大运方向完全相反，整条运势链镜像翻转**——所以同一份分析里必须锁死一套，不能中途换。
