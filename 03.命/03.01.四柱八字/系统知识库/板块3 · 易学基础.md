### 补充 · 纳音该怎么用（定位与边界）
纳音是辅助信息，用好了能增色，用错了会喧宾夺主。三条定位原则：

```plain
第1条 纳音只做"辅助画像"，不参与旺衰与取用的计算
   ——日主强弱、用神取用一律不纳入音

第2条 纳音最适合用在两个地方：
   · 合婚时看两柱纳音是否相生（辅助参考，非决定项）
   · 给断语增加画面感（"剑锋金"主锐利，"大林木"主宽厚）

第3条 纳音与干支五行的结论冲突时，一律以干支五行为准
```

> **记忆建议**：先记前 20 组（本单元已列全），后 40 组用到再查。纳音每两组共用一个名字（甲子、乙丑同为海中金），所以实际只需记 30 个名字，而不是 60 组。**把纳音当成"形容词"，不要当成"论据"。**

## 3_1 六十甲子序号与干支纪年
### 一、核心知识点
```plain
第1点 六十甲子是最小的干支周期
   ——10 天干 × 12 地支，最小公倍数 = 60

第2点 干支纪年从甲子开始，到癸亥结束，六十年为一"甲子"

第3点 太岁：当年的年干支，即流年地支

第4点 大运 / 流年的干支需要通过查表或公式推算
   （六十甲子纳音与序号对照见板块2_6）
```

### 二、序号速查
```plain
开头：甲子 = 1 号    乙丑 = 2 号    丙寅 = 3 号    丁卯 = 4 号
      （序号按六十甲子顺序逐组递增）
结尾：壬戌 = 59 号   癸亥 = 60 号

完整六十组的序号、干支与纳音对照，见板块2_6
```

**已知序号查干支**：

```plain
序号 ÷ 10 的余数 → 定天干
   余 1 = 甲、余 2 = 乙、余 3 = 丙、余 4 = 丁、余 5 = 戊
   余 6 = 己、余 7 = 庚、余 8 = 辛、余 9 = 壬、余 0 = 癸

序号 ÷ 12 的余数 → 定地支
   余 1 = 子、余 2 = 丑、余 3 = 寅、余 4 = 卯、余 5 = 辰
   余 6 = 巳、余 7 = 午、余 8 = 未、余 9 = 申
   余 10 = 酉、余 11 = 戌、余 0 = 亥
```

### 三、落地实操：双向换算（必须双向验算）
```plain
【例一】序号 37 是什么干支？
   37 ÷ 10 余 7  → 第 7 位天干 = 庚
   37 ÷ 12 余 1  → 第 1 位地支 = 子
   → 庚子（壁上土）

【例二】甲午是第几号？
   甲 = 天干第 1 位；午 = 地支第 7 位
   在 1~60 中，找满足"÷10 余 1 且 ÷12 余 7"的数
   → 31 号（砂中金）

【验算】把得到的干支再反推回序号，确认一致。
```

### 四、案例小故事：一个序号错误，错位十年
> 小郑手工推算大运，把"甲午"的序号算成了 30（正确是 31）。他没当回事，因为只差一位。
>
> 但大运是十年一步，错一位就是整条运势链全部错位。他拿着这份排盘给朋友讲："你 25 到 35 岁走的是水运，那十年应该比较压抑。"
>
> 朋友听完一脸茫然："不对啊，我那十年明明在南方做餐饮，生意好得不行。"——餐饮属火，南方属火，跟"水运"完全相反。
>
> 小郑回去从头复算，才发现是序号错了一位。改过来之后，那十年确实是火运，全部对上了。
>
> 他后来在笔记第一页写了一行字：**"序号换算必须双向验算。算出干支后，再反推回序号核对一遍。"**
>
> 这件事还有个后续。他养成双向验算的习惯后，又发现了一类更隐蔽的错误：**不是算错，而是"余数处理错"**。比如序号 40，40 ÷ 10 余 0——余数 0 对应癸，不是对应甲；40 ÷ 12 余 4，对应卯。如果按"余 0 无解"或者"余 0 记 10"来处理，干支就全错了。
>
> 他把这条也记进了笔记，还专门做了张对照表贴在桌上：**天干余 0 = 癸，地支余 0 = 亥。** 除此之外，他还给自己加了一道保险——凡是手算的结果，都用软件排盘对一遍，连续对上二十次才允许自己在正式场合用手算。
>
> **复盘拆解**：大运链错一位，后果之所以严重，是因为**它是"整条链平移"，不是"某一年错了"**。每一步运都跟着往前挪一格，十年一换的节奏也整体错位——而对不上的人往往察觉不到，因为"错位十年"的断语读起来依然通顺。
>
> 这正是必须双向验算的原因：**单向推算的错误不会自己暴露。**
>
> 还有一层经验：手算与工具对不上时，**不要默认工具是对的，也不要默认自己是对的**，而是重新独立算一遍——第三次计算是裁判。多数情况下，错的是"余数 0"那一格。

> **可复用的经验**：手工推算里，"差一位"是最不起眼也最致命的错误。凡是换算，都要反向验一次。三条防线缺一不可：**双向验算（干支→序号→干支）、余数 0 单独处理、与软件结果交叉核对。**
>

### 五、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 序号 ÷ 10 定天干、÷ 12 定地支 | 余数为 0 时对应末尾（癸 / 亥），不是"无" | 序号 60 = 癸亥 |

### 六、实用验证
+ **验证 1**：报出序号 1、31、60 分别是什么干支（甲子、甲午、癸亥）。
+ **验证 2**：报出"戊戌"的序号（35）。
+ **验证 3**：把序号 45 换算成干支，再反推验证（戊申，大驿土）。

### 补充 · 序号换算的三条防线
手工推算干支序号看着简单，却是全库高频失分点。三条防线缺一不可：

```plain
防线一 · 双向验算
   序号 → 干支 → 再反推回序号，两次结果必须一致
   例：37 → 庚子 → 庚(7) 子(1)；37÷10 余 7、37÷12 余 1 ✓

防线二 · 余数 0 单独处理
   天干余 0 = 癸（不是"无"，也不是甲）
   地支余 0 = 亥（不是"无"，也不是子）
   例：40 → 40÷10 余 0 = 癸；40÷12 余 4 = 卯 → 癸卯

防线三 · 与工具结果交叉核对
   手算结果连续对上 20 次，才可在正式场合单独使用手算
```

**为什么差一位就致命**：大运十年一步，序号错一位 = 整条运势链全部错位。更麻烦的是，"错位十年"的断语往往看起来也说得通，极难自查——这正是必须双向验算的原因。

### 二、五条关键规则（必背）
```plain
第1条 立春是一年的开始，不是元旦；也是正月（寅月）的开始

第2条 每月的"节"才是月份的分界线，不是初一

第3条 例：惊蛰之前仍是寅月，惊蛰之后才是卯月

第4条 北半球：夏至白昼最长，冬至白昼最短

第5条 节气交节时刻每年略有浮动，需查万年历确认到"几点几分"
```

> **最致命的误解**：以为农历正月初一就是寅月。**错！** 立春到惊蛰之间才是寅月。春节在立春之前出生的人，年柱、月柱都要按上一年算。
>

### 四、月令人元司令分日（进阶·旺衰精细化的关键）
前面解决了"月支是哪个"，但同一个月支内部，力量并不是均匀的。**每个月令地支所藏的天干，会按天数"轮流值班"**——这就是"人元司令分日"。

> **为什么必须懂？** 同是寅月，立春后七日内是戊土司权，此时月令虽为寅木，但**土气当权**，不能直接以木旺论。不懂分日，旺衰判断就会在最关键的一步上失准。
>

| **寅月** | 戊土 7 日 | 丙火 7 日 | 甲木 16 日 |
| **卯月** | 甲木 10 日 | 乙木 20 日 | — |

**三条使用纪律**：

```plain
第1条 分日只用于"精细判断"，不推翻月令的基本定性
   寅月总体上仍是木旺，只是前 7 日土气较重

第2条 分日主要影响三类判断：
   · 日主是否真"得令"
   · 天干是否真"透出有根"
   · 格局用神是否真"当权"

第3条 初学时先用月令定性，熟练后再加入分日做微调
   不要在第一步就把自己绕进去
```

> **边界说明**：分日表各流派天数略有出入（尤其辰戌丑未四月）。本表采用通行版本，**用于精细判断时作参考，不要拿它去否定月令的大方向。**

### 五、落地实操：定月支三步
```plain
第1步：查万年历，确认出生日的公历日期与交节时刻
第2步：判断出生日落在哪个"节"到哪个"节"之间
第3步：对照上表定月支
第4步（进阶）：确认出生日在该月令的第几日，查出当权天干
```

**特别提醒**：若出生日恰好是交节当天，必须精确到**交节时刻（时分）**。交节前属上月，交节后属下月。

### 六、案例小故事：差两小时，换了一个命盘
> 一位求测者一直以为自己是"寅月"生人，理由很充分——他出生在农历正月初三，怎么都是正月。
>
> 排盘师没有直接排，而是先查了那一年的万年历：那一年的立春，在正月初五。
>
> 也就是说，他出生在立春**之前**，实际仍是上一年的丑月。更巧的是，他出生在交节那天的凌晨两点，而交节时刻是当天凌晨四点——**差两小时，月柱从寅变丑，年柱也跟着换了一轮**。
>
> 重排之后，日主由"得令"变成"失令"。这个变化是连锁的：旺衰等级从"偏强"掉到"中和偏弱"，取用方向从"克泄耗"转到"生扶"，断语几乎全部改写。
>
> 排盘师把两份盘并排给他看，说："你拿第一份盘去问十个人，会得到十套互相矛盾的建议。不是他们不准，是盘错了。"
>
> 他沉默了很久，说了句："我一直觉得自己跟'身强'这个说法对不上，原来问题在这儿。"
>
> **这个案子还有个后续**。他回去把家里人的盘都重排了一遍，发现母亲也是立春前出生——按民俗口径属蛇，按命理口径属龙，生肖一直算错了。他开玩笑说："我们家两口人的属相错了三十年。"
>
> 更重要的是那次修正带来的连锁反应：月柱从寅变丑之后，**年柱也跟着换了一轮**（立春同时也是年的分界），等于四柱里两柱同时改动。取用方向由"克泄耗"转为"生扶"之后，他过去几年"越努力越别扭"的体验才终于说得通——他一直在按身强的方案硬撑，而实际需要的是补。
>
> **复盘拆解**：年初出生的八字必须走两步——**第一步查立春在哪一天**（同时定年柱与月柱），**第二步查交节精确到时分**（若出生在交节当天）。两分钟的检查，能避免整盘错误。

> **可复用的经验**：**农历初一是民俗分界，节气才是命理分界。** 遇到年初出生的八字，第一件事就是查立春在哪一天。
>

### 七、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 立春为一年之始、寅月之始 | 误用农历初一或公历 1 月 1 日作分界 | 正月初三但立春在初五 → 仍属丑月、上一年 |
| 交节当天要精确到时分 | 只看到日期就下结论 | 凌晨 2 点 vs 4 点交节，结果不同 |
| 月令内部藏干按日轮值（人元司令分日） | 整月一律按本气论 | 寅月前 7 日戊土司权，非甲木 |
| 分日只做微调，不推翻月令定性 | 用分日去否定月令 | 寅月总体仍以木旺论 |

### 八、实用验证
+ **验证 1**：默写出"四立"（立春、立夏、立秋、立冬）与"两分两至"（春分、秋分、夏至、冬至）。
+ **验证 2**：说出"清明到立夏"是哪个月（辰月）。
+ **验证 3**：查一次自己出生日的交节时刻，确认月柱是否排对。
+ **验证 4**：查出自己出生日在月令分日表中属于哪一段、当权天干是哪个，并说明它对你的得令判断有无影响。

### 补充 · 交节时刻怎么查，以及三个高频坑
**查询方法**：任一万年历工具都能查到交节的"年月日时分"。查时有两点要注意——**一是确认输入的是公历（阳历）日期**，**二是确认该年份有没有夏令时**（历史年份需单独核对）。

三个高频坑：

| 坑 | 表现 | 怎么避 |
| :---: | :---: | :--- |
| **坑一 · 用农历日期直接对节气** | 拿"正月初三"当寅月 | 先把农历换算成公历，再查交节 |
| **坑二 · 只看到日期，没看到时刻** | 出生在交节当天却按整天算 | 交节当天必须精确到时分 |
| **坑三 · 只改月柱，忘了年柱** | 立春同时是年与月的分界 | 立春前出生，年柱月柱一起改 |

> **一句话纪律**：**年初（立春前后）出生的八字，年柱月柱一起查；交节当天出生的八字，精确到时分。** 这两类占了排盘错误的绝大多数。

## 3_3 四柱八字概述
### 一、四柱结构
| 柱 | 别称 | 对应人事 | 记忆 |
| --- | --- | --- | --- |
| 年柱 | 根 | 祖上 / 父母 / 根基 | 根 |
| 月柱 | 苗 | 兄弟 / 事业 / 父母 | 苗 |
| 日柱 | 花 | 自己 / 配偶 | 花 |
| 时柱 | 果 | 子女 / 晚年 / 归宿 | 果 |

### 二、八字结构图示
```plain
    年柱      月柱      日柱      时柱
   [天干]    [天干]   [日主★]   [天干]
   [地支]    [地支]    [地支]    [地支]
     ↑         ↑         ↑         ↑
    根基      兄弟      自己      子女

八字 = 四柱 × 每柱 2 字 = 8 个字

   年干、年支 │ 月干、月支 │ 日干（日元/日主）、日支 │ 时干、时支
```

### 三、日主：整个八字的中心
> **日干（日主）是整个八字的中心，所有十神都以日主为参照。**
>

这是八字最重要的一个设定。同一个"庚金"字——

```plain
在甲木日主的命局里 → 七杀（克我，同性）
在乙木日主的命局里 → 正官（克我，异性）
在庚金日主的命局里 → 比肩（同我，同性）
```

**离开日主谈十神，毫无意义。**

### 四、落地实操：四柱速读五步
拿任意八字，按固定顺序"读"一遍，形成习惯：

```plain
第1步：圈出日主（日柱天干），标 ★
第2步：看月支（月令），定当令五行
第3步：看日支（配偶宫）
第4步：看其余天干与地支
第5步：在心里默念：年 = 根、月 = 苗、日 = 花、时 = 果
```

### 五、案例小故事：年柱被忽略的代价
> 一位初学者分析命例时，习惯从日主看起，年柱基本扫一眼就过。他觉得年柱离自己最远，影响应该最小。
>
> 有次他给一位中年人看盘，看完日柱和月柱，断了一句："事业发展平平，一路靠自己。"
>
> 对方笑了："我三十岁前就接手家里的企业了，怎么算'靠自己'？"
>
> 他回去重新看——这个命局的年柱非常强旺，且年干为用神。按"年柱看起点"的读法，这是典型的**根基深厚型**：出身给了他平台和起点，只是他本人对此习以为常，从不觉得这是"命"。
>
> 修正后的读法是：**年柱看"起点"，月柱看"奋斗"，日柱看"自身与配偶"，时柱看"归宿与子女"——四柱是一条完整的时间线，不能只读后半段。**
>
> 他后来才发现，类似的错误他犯过不止一次：时柱也经常被他跳过。有一次他断一位老人"晚年平淡"，结果对方时柱为用神且旺——那人退休后反而成了行业顾问，六十岁之后比六十岁之前忙。
>
> 两次下来，他给自己立了条规矩：**排完盘先写一遍"四柱速描"，每柱一句话，不许空着。** 年柱写起点，月柱写奋斗，日柱写自身与配偶，时柱写归宿与子女。写不出来的那一柱，就是还没看懂的那一柱。
>
> 这个习惯带来的另一个好处是：**它强迫你在进入细节之前，先对命局有一个整体印象。** 很多人一上来就扎进十神和生克里，算了一大堆，最后说不出这个人的一生大概是什么形状。
>
> **复盘拆解**：年柱被忽略的根源，是很多人把它当成了"只有生肖有用"。实际上年柱主**根基与出身**——祖上、幼年环境、家族资源，以及一个人"从哪里出发"。
>
> 这个案子里，年柱恰好是唯一能解释"机会从哪来"的那一柱：**年上正印为用，说明资源与助力来自长辈或既有体系**，而不是他自己打出来的。忽略这一柱，就会把"借势"误读成"全靠自己"，后续的取用建议自然也跟着偏。
>
> 由此可以定一条规矩：**四柱逐柱过一遍，每柱至少写一句"它管什么、现在状态如何"。** 跳过任何一柱，都会丢掉一段人生。

> **可复用的经验**：四柱是一个时间序列，"远"不等于"不重要"。年柱决定起点，时柱决定归宿，跳过任何一柱都会丢掉一段人生。**排完盘先做"四柱速描"——每柱一句话，写不出来就是没看懂。**
>

### 补充 · 四柱之间的"距离"与"流向"
四柱不只是一个时间序列，柱与柱之间的"距离"直接决定力量传递的效率：

```plain
紧贴（相邻两柱）  → 作用力最强
隔一柱            → 力量约打七折
隔两柱（年到时）  → 力量微弱，多论意象不论实质

例：日主甲木，时干癸水生扶 → 紧贴，生扶有力
    日主甲木，年干癸水生扶 → 远隔，生扶有限
```

**"流向"怎么看**：

```plain
年 → 月 → 日 → 时   是一条由远及近的流向
   年柱 = "来的地方"（根基、出身）
   时柱 = "去的地方"（归宿、子女）
所以同一个十神，在年柱多主"先天带来的"，在时柱多主"后天走向"

反过来读同样成立：
   看一个人"从哪来" → 重年柱
   看一个人"往哪去" → 重时柱
```

> **一条实用提醒**：初学者最容易只分析日柱和月柱，把年柱、时柱当成"离得远所以不重要"。**远不等于不重要——年柱决定起点，时柱决定归宿，跳过任何一柱都会丢掉一段人生。**

## 3_4 排盘方法
### 一、排盘核心规则（顺逆）
```plain
阳男阴女：顺排大运（从月柱往下排）
阴男阳女：逆排大运（从月柱往上排）
```

**判定方法**（本库以**年干**为准）：

```plain
第1点 年干为阳干 + 男命 → 阳男 → 顺排
第2点 年干为阴干 + 女命 → 阴女 → 顺排
第3点 年干为阴干 + 男命 → 阴男 → 逆排
第4点 年干为阳干 + 女命 → 阳女 → 逆排
```

> **口径说明**：部分流派以日干判定顺逆。本知识库统一以年干为准，全程不换口径（见 README 第六节）。
>

#### 为什么本库取"年干"而不是"日干"
这不是随意选的，理由是三条：

```plain
第1步 大运源于月柱，而月柱由年干起（五虎遁）。
   顺逆既然是"从月柱往前 / 往后排"，判定的起点自然应回到年干。

第2步 古法排运本以年干论。《渊海子平》《三命通会》系统的起运法
   均以年干阴阳配合性别定顺逆，日干定顺逆是后出的简化口径。

第3步 年干是全局最先确定的一字，用它定顺逆，
   排盘流程可以"从上到下"一次走完，不必中途回头改口径。
```

#### 两套口径会造成什么后果
这不是学术之争，是实打实的排盘差异：

| 情形 | 年干口径 | 日干口径 | 后果 |
| :---: | :---: | :---: | :--- |
| 年干与日干**同阴阳** | 顺 | 顺 | 两套结果一致，无差异 |
| 年干与日干**异阴阳** | 顺 | 逆 | **整条大运链镜像翻转** |

> **注意第二行**：年干与日干阴阳不同时，两套口径给出的方向完全相反。按年干顺排得到「甲子、乙丑、丙寅」这样的序列，按日干逆排就是「癸亥、壬戌、辛酉」这样方向完全相反的序列——**每一步运的干支、五行、吉凶全部不同，十年一换的节奏也整体错位。**
>
> 所以它的代价不是"略有偏差"，而是**整份人生时间表重排**。这正是必须在一开始就锁死口径、并全程不换的原因。

#### 三步自查（排完大运必做）
```plain
第1步 确认用年干：问自己"我用的是年干还是日干？"——本库答案是年干
第2步 确认组合：年干阴阳 + 性别 → 落到四个称呼中的一个
第3步 反向校验：拿三段真实经历去对每步运的体感（顺 / 扛）
       对不上，多半是前两步里有一处错了
```

### 二、月起时起：五虎遁与五鼠遁
排盘的四个天干里，年干和日干靠万年历查，但**月干和时干是有口诀可以推的**——这就是五虎遁与五鼠遁。

#### 1. 五虎遁（起月干）
> **口诀**：
**甲己之年丙作首，乙庚之年戊为头，**
**丙辛之岁寻庚起，丁壬壬寅顺水流，**
**戊癸何方发，甲寅之上好追求。**
>

意思是：逢甲年或己年，正月的月干是丙（即丙寅月），然后按月顺推。

| 年干 | 正月（寅月）天干 | 二月（卯） | 三月（辰） | 四月（巳） | 五月（午） | 六月（未） |
| --- | --- | --- | --- | --- | --- | --- |
| 甲、己 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 |
| 乙、庚 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
| 丙、辛 | 庚 | 辛 | 壬 | 癸 | 甲 | 乙 |
| 丁、壬 | 壬 | 癸 | 甲 | 乙 | 丙 | 丁 |
| 戊、癸 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 |

| 年干 | 七月（申） | 八月（酉） | 九月（戌） | 十月（亥） | 冬月（子） | 腊月（丑） |
| --- | --- | --- | --- | --- | --- | --- |
| 甲、己 | 壬 | 癸 | 甲 | 乙 | 丙 | 丁 |
| 乙、庚 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 |
| 丙、辛 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 |
| 丁、壬 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
| 戊、癸 | 庚 | 辛 | 壬 | 癸 | 甲 | 乙 |

> **示例**：甲年三月 → 甲己之年丙作首，正月丙寅，顺推三月为**戊辰月**。
>

#### 2. 五鼠遁（起时干）
> **口诀**：
**甲己还加甲，乙庚丙作初，**
**丙辛从戊起，丁壬庚子居，**
**戊癸何方发，壬子是真途。**
>

意思是：逢甲日或己日，子时的时干是甲（即甲子时），然后按时顺推。

| 日干 | 子时 | 丑时 | 寅时 | 卯时 | 辰时 | 巳时 |
| --- | --- | --- | --- | --- | --- | --- |
| 甲、己 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 |
| 乙、庚 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 |
| 丙、辛 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
| 丁、壬 | 庚 | 辛 | 壬 | 癸 | 甲 | 乙 |
| 戊、癸 | 壬 | 癸 | 甲 | 乙 | 丙 | 丁 |

| 日干 | 午时 | 未时 | 申时 | 酉时 | 戌时 | 亥时 |
| --- | --- | --- | --- | --- | --- | --- |
| 甲、己 | 庚 | 辛 | 壬 | 癸 | 甲 | 乙 |
| 乙、庚 | 壬 | 癸 | 甲 | 乙 | 丙 | 丁 |
| 丙、辛 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 |
| 丁、壬 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 |
| 戊、癸 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |

> **示例**：丁日酉时 → 丁壬庚子居，子时庚，顺推酉时为**己酉时**。
>

#### 3. 四柱排法总表
| 柱 | 天干怎么来 | 地支怎么来 | 分界线 |
| --- | --- | --- | --- |
| **年柱** | 万年历 | 万年历 | 以**立春**为界（非春节） |
| **月柱** | 五虎遁（看年干） | 看节气落在哪一月 | 以**节**为界（非初一） |
| **日柱** | 万年历 | 万年历 | 以 **23:00** 为日柱分界 |
| **时柱** | 五鼠遁（看日干） | 看真太阳时落在哪一辰 | 以**真太阳时**为准 |

> **实操建议**：现在排盘多用软件，五虎遁五鼠遁看似"用不上"。但**必须会**——因为软件排错的唯一发现方式，就是你能手工核对。至少要做到"看到月干时干，能立刻判断它是否排对"。
>

### 三、真太阳时校正（最容易被忽略的一步）
```plain
第1步 八字以地方太阳时为准（真太阳时），不是北京时间
第2步 经度差异：每差 1 度约 4 分钟时差
第3步 北京时间基于东经 120°，各地需按当地经度换算
第4步 例：成都（东经约 104°）比北京晚约 64 分钟
```

**校正公式**：

```plain
真太阳时 = 北京时间 -（120° - 当地经度）× 4 分钟
```

> **实操影响**：我国东西跨度约 62 度，最大时差可达 4 小时以上，足以让时柱跨越两个时辰（一个时辰 = 2 小时）。时柱一变，时干随之改变，格局可能完全不同。
>

### 四、起运岁数算法
```plain
第1条 从出生日数到下一个（顺排）或上一个（逆排）"节"的天数
第2条 三天折一年，一天折四个月，一时辰折十天
第3条 顺排往后数，逆排往前数
```

| 情况 | 计算过程 | 起运 |
| --- | --- | --- |
| 距下一个节气 18 天 | 18 ÷ 3 = 6 | 约 6 岁起运 |
| 距下一个节气 3 天零 8 个时辰 | 3 天 = 1 年；8 时辰 = 80 天 ≈ 8 个月 | 约 1 岁 8 个月起运 |

> **完整的排运步骤、起运岁数计算表与实例，见板块9_1 与 9_2。**
>

### 五、图解：排盘全流程
```plain
第1步 采集信息：公历年月日时分 + 性别 + 出生地经度
        ↓
第2步 真太阳时校正：按经度换算
        ↓

        ↓

        ↓
```


### 八、案例小故事：被"北京时间"改变的两个时辰
> 一位新疆朋友的母亲很确定地说，孩子是"辰时"生的——出生证明上白纸黑字写着上午 8 点多。按北京时间排，时柱是辰时，这一点似乎没有争议。
>
> 排盘师没有马上排，先问了一句："出生地在哪？"答：乌鲁木齐。
>
> 乌鲁木齐的经度约为东经 87°。代入校正公式：
>
> **真太阳时 = 北京时间 -（120 - 87）× 4 分 = 北京时间 - 132 分钟 ≈ 减 2 小时 12 分。**
>
> 也就是说，出生证明上那个"上午 8 点多"，在当地实际的太阳时是早上 6 点多——**是卯时，不是辰时。**
>
> 时柱一改，时干随之改变（时干由日干按五鼠遁推出，时支变了，时干跟着变）。连锁反应出现了：
>
> + 按**辰时**排：时柱为食神，格局是**食神格**——温和、有福气、才华外露但不扎人。
> + 按**卯时**排：时柱为伤官，格局是**伤官格**——锐利、敢说、有创造力但也爱挑刺。
>
> 食神温和、伤官锐利，两个格局描述的性格与事业走向差别不小。
>
> 排盘师没有直接宣布哪个对，而是把两份盘都讲了一遍，然后问那位母亲几个具体问题：孩子小时候是不是特别爱顶嘴？是不是眼睛很尖、总能挑出别人的错？
>
> 母亲听完愣了一下，说："你这么一说——他从小就是那种特别敢说、也特别能挑刺的孩子，老师都拿他没办法。"顿了顿又补一句："伤官这个说法才对。"
>
> **复盘时排盘师讲了三层，这三层比公式本身更重要：**
>
> **第一层：为什么新疆、西藏一带几乎必然要校正？** 我国东西跨度约 62 度，最大时差可达 4 小时以上。而一个时辰只有 2 小时——也就是说，极端情况下时柱会整整错位两个时辰。
>
> **第二层：出生证明上的时间是什么时间？** 是**北京时间**（东经 120° 的标准时），不是当地太阳时。这是最容易被默认忽略的一层——很多人看到"白纸黑字"就不敢怀疑。
>
> **第三层：怎么验证校正对了没有？** 排两套盘，用已发生的事实去校验（性格、过往经历、重大事件年份）。理论有争议时用事实校验，这是最可靠的做法。
>
> **复盘拆解**：这个案子展示了真太阳时校正的完整链路——**出生地经度 → 时差 → 时柱改变 → 时干跟着变（五鼠遁）→ 格局改变 → 断语改变**。任何一环漏掉，都会停在半路。
>
> 特别要注意"时干跟着变"这一环：很多人以为只改地支就够了，忘了时干是按时支推出来的，支一变干必变。
>
> 三条经验：**一是西部出生者默认要校正**（东经 120° 以西每差 15° 就是一小时）；**二是验证靠事实**（两套盘讲完，用已发生的事核对）；**三是口径要说明**（子时还有 23:00 与 0:00 两派分界，本库取 23:00）。

> **可复用的经验**：**西部地区的八字，不校正真太阳时几乎必然排错。** 看到出生地在新疆、西藏、甘肃、青海一带，第一反应就该是"先校正"；东部地区也不是可以省略——成都（东经约 104°）也要减 64 分钟，足以跨过一个时辰的边界。
>

### 九、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 真太阳时 = 北京时间 -（120 - 经度）× 4 分 | 直接用北京时间排盘 | 新疆出生者，时柱常排错一个时辰 |
| 三天折一年、一天折四月、一时辰折十天 | 数错方向（顺数下一个节、逆数上一个节） | 顺排却往前数，起运岁数全错 |
| 年柱以立春为界，月柱以节为界 | 按农历初一换年柱月柱 | 立春前出生 → 年柱算上一年 |
| 五虎遁看年干起月干，五鼠遁看日干起时干 | 两个口诀的"看谁"记反 | 月起看年干，时起看日干 |
| 日柱以 23:00 为界（子时早子晚子之分） | 按 0:00 换日柱 | 23:30 出生 → 日柱算次日 |

### 十、实用验证
+ **验证 1**：说出顺逆排的两条规则，以及本库采用的判定干。
+ **验证 2**：计算东经 104° 地区与北京时间的时差（64 分钟）。
+ **验证 3**：背出五虎遁与五鼠遁口诀，并推出"甲年三月"和"丁日酉时"的干支。
+ **验证 4**：手工排出一个完整八字（含大运与起运岁数），再与工具结果核对。

### 补充 · 排盘五大易错的复核清单
排盘是全库容错率最低的环节——错一处，后面全错。每次排完盘，用这张清单逐条过一遍：

| # | 易错点 | 复核动作 |
| :---: | :---: | :--- |
| **1** | **未过立春就算了新年** | 查出生日是否已过当年立春；未过则年柱用上一年 |
| **2** | **按农历初一换月柱** | 月柱以"节"为界（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），不是农历初一 |
| **3** | **直接用北京时间定时柱** | 必须做真太阳时校正：北京时间 -（120 - 当地经度）× 4 分钟 |
| **4** | **交节当天只看日期** | 出生在交节当日，必须精确到交节时刻（时分） |
| **5** | **23:00 后仍按当日日柱** | 日柱以 23:00 为界，过了 23:00 归次日 |

**两张不能省的核对表**：

```plain
【年柱核对】出生日 ≥ 当年立春时刻？  → 是：本年年柱；否：上一年年柱
【月柱核对】出生日在哪个"节"之后？  → 对照：
   立春→惊蛰 寅月   惊蛰→清明 卯月   清明→立夏 辰月
   立夏→芒种 巳月   芒种→小暑 午月   小暑→立秋 未月
   立秋→白露 申月   白露→寒露 酉月   寒露→立冬 戌月
   立冬→大雪 亥月   大雪→小寒 子月   小寒→立春 丑月
```

**手工排盘的交叉验证**：

```plain
第1步 月干用五虎遁反推一遍（看年干）
第2步 时干用五鼠遁反推一遍（看日干）
第3步 干支序号用"÷10 定天干、÷12 定地支"双向验算一次
第4步 最后与排盘软件对一遍（软件是校验工具，不是免检凭证）
```

## 3_5 墓库
### 一、四墓库总表
| 墓库 | 五行 | 所墓 / 所库 | 特点 |
| --- | --- | --- | --- |
| 辰 | 土 | 水 | 水库，湿土 |
| 戌 | 土 | 火 | 火库，燥土 |
| 丑 | 土 | 金 | 金库，寒湿土 |
| 未 | 土 | 木 | 木库，燥土 |

### 二、墓 vs 库：同一个字，两种命运
| 状态 | 含义 | 触发条件 |
| --- | --- | --- |
| **库（吉）** | 五行有余而归库储存，待时而用 | 身旺遇之 |
| **墓（凶）** | 五行衰绝而入墓收藏，困顿不开 | 身弱遇之 |

> **核心理解**：辰戌丑未这四个字本身没有吉凶。是命局的整体状态，决定了它当下是"仓库"还是"坟墓"。
>

### 三、墓库开启的三个条件
```plain
第1条 冲开：辰戌冲、丑未冲可开库 / 开墓
第2条 刑开：辰辰自刑、丑戌刑等
第3条 钥匙：所墓之五行透出天干，即为"钥匙"，可开库
        例：辰为水库，天干透壬癸水 → 水库开
```

### 四、实战要点
```plain
第1点 入墓者力量减弱但不消失（除非再被冲开）
第2点 库中藏干丰富，冲开后能量释放巨大
第3点 日主入墓：性格内向、怀才不遇、大起大落
第4点 用神入墓：用神暂时失效，待冲开之年月应吉
```

### 五、落地实操：墓库检查三步
```plain
第1步：找出命局中的辰戌丑未
第2步：判断该字当下是"墓"还是"库"（身旺为库、身弱为墓）
第3步：检查是否开启（有无冲 / 刑 / 透干钥匙）
       已开 → 库中物可用，力量释放
       未开 → 库中物封存，暂不参与生克
```

### 六、案例小故事：一把钥匙，等了三十年
> 某命局日主身旺，地支有戌。此命火为财，戌正是火库。但原局天干不透一点火，库门紧闭。
>
> 这个人前三十年的状态很典型：有能力、也肯干，做成了几件事，但钱就是攒不下来——不是大亏，而是总有各种事把钱花掉。他自己形容："像手上有个漏口袋。"
>
> 三十一岁那年，他进入一步新大运，大运天干透出丙火。
>
> 排盘师看到这一步，跟他说了句："钥匙来了。"
>
> 此后三年，他创业成功，资产翻了几倍。回头看，那些做成的事还是同样的事，只是这一次钱留住了。
>
> 他后来说过一句话被反复引用：**"不是我突然变能干了，是之前的东西一直锁着。"**
>
> **"漏口袋"那三十年值得细看**。他不是没赚到钱——做成的事有几件，收入在同龄人里也不算低。问题是钱总留不住：不是大亏，而是家人住院、朋友周转、店铺装修这类"正当且紧急"的开销一件接一件。用他自己的话说："不是没钱，是钱从来没有'剩下'这个状态。"
>
> 这正是库门紧闭的典型表现：**东西做得出来（食伤有力），成果也换成了钱（财星有源），但钱进不了库（戌为火库，天干不透火，无钥匙）。**
>
> 三十一岁那步大运透出丙火，等于钥匙插进了锁孔。此后三年做的事和前三十年其实是同一类事，唯一的区别是这一次钱留住了。
>
> **复盘拆解**：判断四库，要问三个问题而不是一个——**有没有库？库门开了没有？什么时候开？** 中间那一问最容易被跳过，而它恰恰决定这个库是"资产"还是"摆设"。

> **可复用的经验**：库的价值在于——**锁着的时候看不见，开了就是一大笔**。看到四库，重点不是"有没有"，而是"开了没有、什么时候开"。
>

### 七、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 身旺遇辰戌丑未为库，身弱遇之为墓 | 一律论凶 | 身旺者戌为火库，冲开大发 |
| 开库三途：冲、刑、透干钥匙 | 以为有冲就一定开 | 冲而无力（隔位）则开不了 |

### 八、实用验证
+ **验证 1**：说出辰戌丑未各自所藏五行及燥湿属性。
+ **验证 2**：判断"辰为水库，天干透壬"是否被开（是，透干即钥匙）。
+ **验证 3**：给任意八字做"墓库检查三步"。

### 补充 · 四墓库的实操细则
墓库是初学者的高频失分项，四条细则要单独记住：

```plain
细则一 · 辰戌丑未的本气都是土，但它们"库"的东西不同
   辰 = 水库（湿）   戌 = 火库（燥）
   丑 = 金库（寒湿） 未 = 木库（燥）

细则二 · 墓与库的判定只看命局状态，不看这个字本身
   身旺遇之 → 库（仓库，待时而用）
   身弱遇之 → 墓（坟墓，困顿不开）

细则三 · 开库有三途，但"冲"不等于一定能开
   第1步 冲开：辰戌冲、丑未冲（须紧贴有力，隔位冲则开不了）
   第2步 刑开：辰辰自刑、丑戌未三刑
   第3步 钥匙：所库之五行透出天干（如辰为水库，天干透壬癸即为有钥匙）

细则四 · 入墓 ≠ 消失
   入墓者力量减弱但依然存在；一旦被冲开或遇钥匙，力量释放往往很集中
   所以"用神入墓"的断语要加一句时间：
   "用神暂不发力，待冲开或透出之年应吉"
```

**四库土参与生克时的特殊性**：

```plain
辰丑湿土：能晦火（减火之力）、能生金
未戌燥土：能脆金（削金之力）、能助火
土本身克水：湿土蓄水、燥土熬水，力度与表现都不同
```

> **与板块2_3 的分工**：板块2_3 讲四库的**藏干**（辰中戊乙癸等）；本单元讲四库的**开合规则与吉凶**。两者配合起来才是完整的墓库判断。

### 六、案例小故事：绝处逢生的十年
> 一位命主日主壬水，大运走到"绝"地（巳）。他自己先查了查十二长生的含义，看到"绝：完全断绝，一无所有"，吓得连着几晚没睡好，来找排盘师时第一句话就是"是不是完了"。
>
> 排盘师没有直接回答，而是让他把十二长生的顺序念一遍。
>
> 他念到"衰、病、死、墓、绝、胎、养、长生"这一串时，自己停住了。
>
> 排盘师说："对，绝的下一步是胎，胎的下一步是养，养之后又是长生。这是一个圆圈，不是一条下坡路。'绝'不是终点，是'旧的彻底断绝'这个动作本身。"
>
> 那十年，他确实做了一件在旁人看来很激进的事：关掉经营多年、勉强维持的线下门店，全部转向线上。当时所有人都觉得他疯了。
>
> 结果是，绝运之后的胎运、养运里，他的新业务慢慢起来了，规模超过了原来的门店。
>
> **他关店那一步，事后看是关键**。那家线下门店开了八年，不赚不亏，占着他大半的时间和现金流。他不是因为算准了才关的——恰恰相反，他是在最迷茫时做的决定，事后才对上"绝"这个阶段。
>
> 排盘师给了他一句更实在的话：**"'绝'运不是让你等，是让你把该断的断了。"** 绝的本质是"旧的彻底断绝"，所以它最怕拖——拖着不放，等于把本该在一个阶段完成的清算拉长到两个阶段，代价翻倍。
>
> 胎运、养运那几年，他的线上业务一点点起来：先是把老客户转到线上，接着新客开始增长，第三年规模超过了原来的门店。他后来总结：**"那家店我早该关，我是在绝运里被迫做了件对的事。"**
>
> **复盘拆解**：十二长生给的是"阶段感"，不是"判决书"。拿到一个阶段名，做两件事——**先看它在圆圈里的位置**（前后各是什么），**再问这个阶段该做什么动作**（绝=断舍、墓=收存、胎养=蓄力、长生=起步）。

> **可复用的经验**：**十二长生是循环，不是终点。** 看到"绝""死""墓"不要慌，先看它在循环里的位置，以及下一步是什么。
>

| 火土同宫：丙 = 戊、丁 = 己 | 给土单算一套 | 戊土长生在寅，与丙火同 |

+ **验证 2**：报出甲、丙、庚、壬四阳干的长生位（亥、寅、巳、申）。
+ **验证 3**：报出乙、丁、辛、癸四阴干的长生位（午、酉、子、卯）。

### 补充 · 十二长生的三大实战用法
十二长生常被当成"背了就完"的知识点，其实它有三个非常实用的用途：

**用法一 · 辅助判断旺衰（补充"得地"）**

```plain
日主在地支遇到自己的长生、冠带、临官、帝旺位 → 得地有力
遇到衰、病、死、绝位 → 即便有根，根气也偏弱

例：庚金日主见巳（长生）、酉（帝旺） → 根气有力
    庚金日主见寅（绝）、卯（胎）     → 有名无实
```

**用法二 · 判断某个十神的状态**

```plain
看六亲时，不仅看十神星有没有力，还要看它落在什么阶段：
   父星（偏财）坐长生 → 父亲有能力、寿命与状态较好
   父星坐死绝         → 缘分淡薄或助力有限
这一步是"星宫同参"之外的一层补充（见板块10_1）。
```

**用法三 · 理解大运流年的"阶段感"**

```plain
十二长生是一个圆圈，不是一条下坡路：
   衰 → 病 → 死 → 墓 → 绝 → 胎 → 养 → 长生
"绝"之后是"胎"，"胎"之后是"养"，养完又是长生。
所以大运走到"绝"地，含义是"旧的彻底断绝"，
不是"一切完蛋"——它同时是新一轮循环的起点。
```

**四条规律复习（帮你少背一半）**：

```plain
第1点 阳干顺行，阴干逆行
第2点 火土同宫：丙戊同位（寅午戌），丁己同位（酉巳丑）
第3点 阳干长生位即三合局的长生位：甲在亥、丙戊在寅、庚在巳、壬在申
第4点 临官 = 禄位，帝旺 = 刃位（阳干）——这两条直通板块6_3 与板块8_3
```

## 3_7 大运与流年（概念）
> **本单元是概述。** 大运的顺逆排法与起运岁数的精确算法，见板块9_1、9_2；流年应期的具体判断，见板块9_4。此处只建立四个概念及其关系。
>

### 一、四个基本概念
| 概念 | 定义 | 比喻 |
| --- | --- | --- |
| **原局（命盘）** | 出生时刻的四柱八字，一生不变 | 地基 |
| **大运** | 十年一步的运势周期 | 环境 |
| **流年** | 每一年的太岁干支 | 天气 |
| **流月** | 每月的干支，细化到月 | 短期天气 |

> **经典比喻**：**大运是"环境"，原局是"地基"，流年是"天气"。**
>

### 二、四种组合
```plain
好命 + 好运 + 好流年 = 大吉大利
好命 + 坏运 + 坏流年 = 怀才不遇
坏命 + 好运 + 好流年 = 时来运转
坏命 + 坏运 + 坏流年 = 艰难困苦
```

### 三、大运与流年的基本规则（简述）
```plain
大运：阳男阴女顺排、阴男阳女逆排；每柱管十年
起运：从出生日数到最近的节，三天折一年、一天折四月、一时辰折十天
流年：即当年的太岁（年柱干支）
流年作用于原局和大运之间，引发的事件通常在当年体现
```

### 四、落地实操：标出你当前的大运与流年
学完概念，立刻用它对自己的盘做一次定位：

```plain
第1步 排出自己的四柱（用板块3_4 的方法）
第2步 定顺逆：年干阴阳 + 性别 → 阳男阴女顺、阴男阳女逆
第3步 从月柱起排，每柱十年，标出自己现在在第几步
第4步 标出今年流年干支，写在对应那一步大运下面
```

| 原局 | 大运 | 流年 |
| :---: | :---: | :--- |
| 命（地基） | 运（环境，十年一换） | 岁（天气，一年一换） |

> **这一步的意义**：后面所有"应期"判断，都是在这个时间轴上做的。**先把轴画出来，再谈什么时候发生什么事。**

### 五、案例小故事：同一年，三种命运
> 有一年流年为丙午（火旺）。三个人先后来看盘，问的都是同一件事："今年我怎么样？"
>
> 甲的用神是火。那一年他升了职，还因为一个行业奖项上了榜单——火主名声、主显扬，全都应上了。
>
> 乙的忌神是火。那一年他投资失利，钱像流水一样出去。他自己形容："不是被人骗，是我自己每次都觉得'这个项目能成'。"——火主耗散，正是"耗"这个字的写照。
>
> 丙的用神是水。火旺则耗水，那一年他累得半死，加班到凌晨是常态，但成果平平，年底复盘时几乎拿不出像样的成绩。
>
> 三个人聊起这一年，都很感慨："怎么我们过的不是同一年？"
>
> 旁边有位初学者听完问了个很实在的问题："那丙午年到底是好年还是坏年？"
>
> 老师笑了：**"你这个问题本身就问错了。年份没有好坏，只有'对你而言'。就像同一场雨——久旱的田地盼着它，刚播完种的人怕它，屋顶漏水的人恨它。雨还是那场雨。"**
>
> 他接着给了个很实用的判断顺序：**看到任何流年干支，第一件事不是查它主什么事，而是先在命局里给它定性——用神、忌神，还是闲神。定性之后再谈"会应什么事"，顺序不能颠倒。**
>
> 顺着这条还有一层：**同一个流年干支，对不同的人是吉是凶不同；对同一个人的不同事项，也可能不同。** 比如丙午年对甲是吉，但火主耗散，他那一年虽然升职，开销也大增——升职和花钱是同一件事的两面。
>
> **复盘拆解**：同年同运，三种结果——这个案子回答的是"同年同运为什么不同命"。差别在于**原局不同，同一股流年力量落到不同的结构上，触发的事就不同**。
>
> 可以把它记成一个公式：**流年力量 × 原局结构 = 具体事件。** 流年只提供"外界给的那一下子"，原局决定"这一下子打在哪里、打出什么"。
>
> 所以断流年时，**先看原局有没有这个"因"**（原局有财被冲的象，流年冲才会应破财；原局没有，流年冲只是环境变动）。这也正是板块9_4 要展开的"原局没种，流年不结果"。

> **可复用的经验**：**流年干支本身没有绝对吉凶，只有"对你是吉是凶"。** 判断任何年份，第一句永远是"这个干支在你的命局里是用还是忌"。第二句才是"它会引动什么事"。
>

### 六、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 原局 = 地基、大运 = 环境、流年 = 天气 | 孤立地看流年吉凶 | 丙午年：用火者吉、忌火者凶 |
| 每柱大运管十年，顺逆由阳男阴女定 | 排错方向 | 阳男顺排，从月柱下一柱起 |

### 七、实用验证
+ **验证 1**：说出原局、大运、流年、流月四者的比喻与关系。
+ **验证 2**：默写出四种组合（好命好运、好命坏运等）。
+ **验证 3**：说出起运年龄的换算比例（三天一年、一天四月、一时辰十天）。

## 3_8 日主与身强弱（概述）
> **本单元是概述。** 四维权重的完整判定流程、旺衰五级标准、从格体检，见板块5。此处只需建立正确的直觉。
>

### 一、什么是日主
```plain
第1条 日柱的天干称为"日主"（也叫日元、日干、命主）
第2条 日主是整个八字的中心参照点
第3条 所有十神的命名，都基于日主与其他七个字的关系
```

### 二、身强与身弱
| 类型 | 定义 | 表现 | 取用方向 |
| --- | --- | --- | --- |
| **身强（旺）** | 日主得到足够帮扶（印星、比劫），力量充沛 | 自信、主动、抗压能力强 | 喜克泄耗（官杀、食伤、财星） |
| **身弱（衰）** | 日主帮扶不足，力量薄弱 | 谨慎、被动、依赖性强 | 喜生扶（印星、比劫） |

### 三、初步判断三问
```plain
第1步 得不得令：日主是否生于自己旺盛的季节？
第2步 有没有根：日支和其他地支是否有同五行藏干？
第3步 有没有帮：天干有没有同类（比劫）和生扶（印星）？
```

### 四、落地实操：拿自己的盘走一遍三问
拿到任意八字，用这三问先给个粗略结论：

```plain
第1问 得不得令：日主是否生于自己旺盛的季节？
第2问 有没有根：日支和其他地支是否有同五行藏干？
第3问 有没有帮：天干有没有同类（比劫）和生扶（印星）？
```

| 三问答对几个 | 初步结论 | 取用方向 |
| :---: | :---: | :--- |
| 3 个"是" | 身强 | 喜克泄耗 |
| 2 个"是" | 偏强 / 中和 | 看具体权重 |
| 1 个"是" | 偏弱 | 喜生扶 |
| 0 个"是" | 极弱，需查从格 | 另论（见 5_6） |

> **本单元只是概述。** 精确的四维权重计算在板块5，这里只求"先有个方向"，不要在这里下最终结论。

### 五、案例小故事：身强不等于命好
> 很多人一听"身强"就高兴，觉得是好命。有位客户拿到"身强"的结论后，当场就问："那我是不是可以放手干了？"
>
> 排盘师反问了他一个问题："你过去三年，是不是经常觉得憋着一股劲，但不知道往哪儿使？"
>
> 他愣了一下，说"是"。
>
> "这就是身强无制的典型状态。身强若无制化，就像一个人精力过剩却无处发泄——表现出来就是冲动、破财、跟人起冲突。你那三年换了三份工作，每一次都是跟上司闹翻，对吧？"
>
> 他苦笑着点头。
>
> 排盘师接着说："真正的'好'，是身强**且有官杀来制、有食伤来泄、有财星来耗**——能量有出口。反过来，身弱若得印星生扶，就像体质偏弱但有人照应，反而能走得稳、走得远。"
>
> **排盘师给他的建议很具体**：既然身强无制，就别再往"更自由、没人管"的方向找工作——那只会让他更散。恰恰相反，他需要的是**主动给自己加约束**：选流程严整、有强上级的环境，把"被管"当成外部骨架来用。
>
> 他照做了：从一家松散的创业公司跳进一家流程严整的中型企业，还主动申请了一个需要按月交付的岗位。半年后他自己说："奇怪，被管着反而舒服了。"
>
> 另一层更贴切的比喻是：**身强像力气大的人。** 力气大本身是好事，但如果没有要搬的东西，力气就会变成烦躁、冲突和破坏。所以"身强该怎么发展"的答案，不在"要不要更强"，而在"有没有值得你使力的事"。
>
> **复盘拆解**：拿到旺衰结论，紧接着必须做两个动作——**一问有没有出口**（官杀制、食伤泄、财星耗，三者有没有一个有力），**二问出口通不通**（链条有没有断，见 4_2）。这两问不过，旺衰结论就只是一句空话。

> **可复用的经验**：**旺衰是中性词，吉凶看的是"有没有出口"。** 拿到身强身弱的结论后，紧接着要问的是"这股力量往哪儿去"。
>

### 六、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 身强喜克泄耗，身弱喜生扶 | 以为身强 = 命好 | 身强无制，反主冲动破财 |
| 三问：得令？有根？有帮？ | 只看天干数量，忽略地支根气 | 天干个个克我，但日支有强根 → 不可轻言弱 |

### 七、实用验证
+ **验证 1**：说出身强身弱各自的取用方向。
+ **验证 2**：对任意八字完成"初步判断三问"。
+ **验证 3**：解释为什么"身强不等于命好"。

## 3_9 用神与忌神（概述）
> **本单元是概述。** 扶抑、调候、通关、病药四种取用方法，以及多法冲突时的优先级，见板块7。此处只掌握四个名词的定义。
>

### 一、四个基本定义
| 术语 | 定义 | 比喻 |
| --- | --- | --- |
| **用神** | 对日主最有利的那个字（或五行） | 命局的"药方" |
| **忌神** | 对日主最不利的字 | 用神的敌人 |
| **仇神** | 生助忌神、克制用神的字 | 帮凶 |
| **闲神** | 对格局影响不大，可有可无的字 | 路人 |

### 二、简单理解
```plain
身强 → 用神是克泄耗日主的五行
身弱 → 用神是生扶日主的五行
```

### 三、落地实操：给自己的盘标出四个神（概述级）
不用算，先按定义粗标一遍，建立直觉：

```plain
用神 = 对日主最有利的字（药方）
喜神 = 生助用神的字（帮手）
忌神 = 克用神的字（敌人）
仇神 = 生忌神的字（帮凶）
```

**粗标三步**：

| 步骤 | 动作 |
| :---: | :--- |
| 第1步 | 先判身强身弱（用 3_8 的三问） |
| 第2步 | 身强则克泄耗为用、身弱则生扶为用 |
| 第3步 | 剩下的字按定义归入喜 / 忌 / 仇 / 闲 |

> **本单元不要求算准。** 真正的取用要走板块7 的四法与优先级；这里只要求你能说出四个名词的定义，并给自己的盘做一次粗标。

### 四、案例小故事：补了三年的水，全是白补
> 一位命主听人说自己"八字缺水"，从此开始了长达三年的补水工程。
>
> 家里客厅摆了个大鱼缸，卧室放了加湿器；穿衣多选黑色和深蓝；找工作时刻意往北方靠，连社交软件上的昵称都改成带水的字。
>
> 折腾了三年，事业不但没起色，反而越来越差：项目一个接一个黄，人也越来越疲惫，晚上睡不踏实，白天提不起劲。他不明白——"我明明照着做了一切，怎么反而更糟了？"
>
> 后来找到老师重新排盘，问题一下子清楚了。
>
> **他日主是壬水，本就身强。** 水在他命局里是比劫，属于**忌神**——也就是说，他命里最不缺的就是水。
>
> 他真正缺的是"土"（官杀，用来制身）和"火"（财星，用来耗身）：需要有人管得住他、有事情让他投入，力量才有出口。
>
> 也就是说，那三年他做的所有"补水"动作，等于**给一个本就吃撑了的人继续加餐——越补越滞。** 比劫过旺的典型表现正是"忙忙碌碌却留不住成果、竞争者多、钱来了又走"，跟他这三年的遭遇完全对得上。
>
> 调整方向后，他撤掉了鱼缸，改往火土类的行业靠（互联网、地产相关），并且主动给自己找了一个强约束的工作节奏——加入一个要求极严的团队，让"官杀"真正发挥作用。
>
> 两年就有了明显起色。他后来跟朋友说：**"我那三年不是不努力，是努力反了方向。"**
>
> 老师后来拿这个案例当反面教材，加了一句更重要的提醒：
>
> **"八字里'缺'和'需要'是两回事。缺，是命局里没有这个字；需要，是这个字能让你平衡。很多时候你缺的恰恰是你不需要的——因为命局把它去掉，本身就是一种平衡。"**
>
> **复盘拆解**：三年补水无效，不是因为"补错了方向"，而是因为**根本没有先算账**。他跳过了最关键的一步——判断日主到底是强是弱，直接按"命里缺水"去补。
>
> 这里有个很常见的误解需要澄清：**"八字里没有某个五行"≠"需要补这个五行"。** 缺只是"没有"，需不需要要看日主的强弱与格局所需。身强再补印比，是火上浇油；身弱再补克泄，是雪上加霜。
>
> 正确顺序永远是：**先判旺衰 → 再定格局 → 最后才谈取用。** 跳到第三步的人，无论补什么都像在碰运气。

> **可复用的经验**：**"八字缺什么就补什么"是最流行、也最害人的误区。** 缺的不一定是需要的，需要的也不一定缺。取用神是八字里最需要谨慎的一步，方向错了，努力越多越糟。
>

### 五、笔记法
| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 用神 = 药方、忌神 = 敌人、仇神 = 帮凶、闲神 = 路人 | 把"缺什么补什么"当取用原则 | 壬水身强再补水 → 越补越糟 |
| 身强用克泄耗，身弱用生扶 | 忽略调候、通关、病药三种取用法 | 寒冬命局需先调候，再论扶抑 |

### 六、实用验证
+ **验证 1**：说出用神、忌神、仇神、闲神的定义。
+ **验证 2**：说出身强身弱的取用方向。
+ **验证 3**：解释为什么"八字缺什么就补什么"是错误观念。

### 五、落地实操：区分民俗说法与命理分析
遇到"属什么就怎样""正月出生如何"这类说法，用三步处理：

```plain
第1步 先肯定：民俗说法有它的社会功能，不要直接否定对方

第2步 讲框架：八字是四柱八个字的合力，生肖（年支）只占其一

第3步 指代价：以一字概括八字，必然失真
       另外提醒：民俗的正月以农历初一为界，命理的正月以立春为界
```

| 民俗口径 | 命理口径 |
| :---: | :--- |
| 生肖看年（农历初一为界） | 年柱以立春为界 |
| "属羊命不好" | 年支只占八字之一，且主祖上幼年 |
| 星座、血型论性格 | 属于另一套分类法，不参与八字计算 |

### 六、案例小故事：被"常识"救回来的一次咨询
> 有位客户来问事业，聊到一半忽然问了个看似不相干的问题："我老家有说法，属羊的人命不好，是真的吗？"
>
> 咨询师没有直接回答"是"或"不是"，而是把生肖这件事从头讲了一遍：
>
> "羊对应的地支是未，未只是十二地支中的一个位置。八字要分析的是年、月、日、时四柱共八个字之间的五行生克关系——年支（也就是你的生肖）只占这八个字里的一个，而且它主管的是祖上与幼年运势，权重有限。"
>
> 客户又问："那民间为什么会有这种说法？"
>
> "因为生肖是最好记的一个字。要讲清八个字的生克制化很难，但要说'属什么的命好'很容易——所以流传最广的说法，往往是最简化的那个。"
>
> 客户听完笑了："我妈念叨了三十年，我今天算是明白了。"
>
> 有意思的是，咨询师后来又补了一句："而且民俗里讲的正月，是以农历初一为界；命理里讲的正月，是以立春为界。这两个'正月'经常不在同一天，很多人的生肖其实一直算错了。"
>
> 客户当场查了自己的出生日期——果然，他出生在立春之前，按命理口径，他的"属相"和身份证上填的那一栏并不一致。
>
> **咨询师最后补的那句最有价值**：他没说"民俗是错的"，而是说"民俗是简化版"。这个说法既没否定对方母亲三十年的念叨，又把完整框架立住了——**遇到民俗说法，反驳是最低效的应对，讲清框架才是。**
>
> 还有一层容易被忽略：生肖（年支）虽然只占八个字中的一个，却并非没有用。它主祖上与幼年运势，在看"出身"和"早年环境"时确有参考价值。真正的问题不是"年支有没有用"，而是**"能不能用一个字去概括八个字"**。
>
> 客户后来把这段讲给母亲听，母亲的反应出乎意料："那我以后不说属相了，我说不清楚。"
>
> **复盘拆解**：应对简化说法的标准动作有三步——**先肯定对方的经验**（民俗有它的社会功能）、**再讲清完整框架**（八字是八个字的合力）、**最后指出简化的代价**（以一字概括八字，必然失真）。

> **可复用的经验**：**民俗说法是简化版，命理分析是完整版。** 遇到"属什么就怎样"这类说法，不必反驳，只需把完整的分析框架讲清楚即可。
>

### 七、笔记法
| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 民俗分界是农历初一，命理分界是立春 | 用农历初一换年柱 | 立春前出生，年柱月柱都要改 |
| 生肖 = 年支，只占八字之一 | 用生肖概括一生 | 年支主祖上幼年，不主命主 |
| 应对民俗说法：先肯定，再讲框架 | 直接否定对方 | "民俗是简化版，命理是完整版" |

### 四、落地实操：两套工具的边界检查
当你想"用卦验证八字"或"用八字回答某件事的结果"时，先做这张检查：

| 说法 | 问题 | 修正 |
| :---: | :---: | :--- |
| "你适合技术，但最近要变动" | 没分来源与尺度 | "按八字看，你适合技术路线（长期）；按卦象看，近期有变动（三个月内）" |
| "你今年要注意" | 没说注意什么、来自哪套工具 | 补上工具来源与具体动作 |

### 五、案例小故事：两套工具，别混着用
> 一位学习者同时学了八字和六爻（一种起卦占卜的方法）。学完之后，他养成了一个习惯：给人看八字时，看着看着就起一卦来"验证"一下。
>
> 有一次他给朋友分析事业，八字看完的结论是"适合技术路线，中年后靠专业立身"。他觉得不够确定，又起了一卦，卦象显示"近期有变动"。
>
> 于是他把两个结论混在一起说："你适合做技术，但最近会有变动，可能要换工作。"
>
> 朋友听完就纠结了：到底该不该换？纠结了三个月，最后在犹豫中错过了一个很好的内部转岗机会。
>
> 后来老师指出问题所在：
>
> **"八字回答的是'你是什么样的人、适合走哪条路'，六爻回答的是'这一件具体的事结果如何'。这两套工具的提问方式、时间尺度、判断逻辑都不一样，混在一起用，等于把长期趋势和短期事件的信号叠加，只会让对方更糊涂。"**
>
> 老师的建议是：两套工具都要学，但**用的时候分开**——看人生方向和阶段运势用八字，问某件具体的事用占卜。而且给答案时，要清楚说明"这个结论来自哪套工具"。
>
> 他后来照做了，反而觉得两套工具互相印证，比混用清晰得多。
>
> **朋友错过那个转岗机会，才是真正的代价**。八字给的"适合技术路线"是长期方向，六爻给的"近期有变动"是短期事件——两者本来并不冲突，甚至可以互补：长期走技术路线，短期正好有个内部转岗，也是技术岗。
>
> 问题出在他说的时候没分源：朋友不知道哪句是长期、哪句是短期，只能自己拼，结果拼出一个自相矛盾的信号，于是选择"不动"。**而不动，恰恰是所有选择里最贵的那个。**
>
> 老师后来给了他一条可执行的规矩：**给结论时，每句都要带"有效期"。** "你适合技术路线"的有效期是十年；"近期有变动"的有效期是三个月。带上有效期之后，两套工具不但不打架，还能互相定位。
>
> **复盘拆解**：多工具混用的风险不在工具多，而在**结论不带来源和尺度**。解法极简单：说话时给每个结论标上"来自哪套工具 + 管多长时间"。

> **可复用的经验**：**工具越学越多之后，最重要的是分清各自的适用边界。** 混用产生的信息噪音，往往比信息本身更多。
>

### 六、笔记法
| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 八字答"是什么样的人"，占卜答"这件事结果如何" | 两套工具混着用 | 长期方向 + 短期事件叠加 = 对方更糊涂 |
| 每个结论都要带来源与有效期 | 只给结论不给尺度 | "适合技术"（十年）vs"近期变动"（三个月） |
| 八卦：乾兑离震巽坎艮坤 | 与五行生克混为一谈 | 卦象不参与八字计算 |

+ **验证 3**：用自己的话解释"为什么不要在八字分析中套用卦象"。

### 三、落地实操：选工具前的三问
遇到任何问题，先问完这三句再决定用什么：

```plain
第1问 我到底在问什么？（是什么 / 会怎样 / 怎么办）
第2问 这个问题归哪一把尺子管？（山 / 医 / 命 / 相 / 卜）
```

| :---: | :--- |

| "这一件具体的事结果如何" | 卜（六爻、奇门） |
| "身体怎么治" | 医 |

### 四、案例小故事：五术是五把不同的尺子
> 有人问过一个很典型的问题："八字和紫微斗数，哪个更准？"
>
> 被问的这位老师两套都通，他没有直接比较，而是打了个比方：
>
> **"你要量一段布，用尺子；要称一袋米，用秤；要测温度，用温度计。你不会问'尺子和秤哪个更准'——因为它们量的根本不是同一个东西。"**
>
> 他接着把五术逐一对应：
>
> **山**，是养生与修行，管的是"怎么养好自己"；
**医**，是诊疗，管的是"身体的病怎么治"；
**命**，是八字紫微，管的是"一生的结构与阶段趋势"；
**相**，是面相、风水形峦，管的是"人与环境的外在呈现"；
**卜**，是六爻奇门，管的是"某一件具体的事会如何"。
>
> 五把尺子，五个问题。
>
> 他特别提醒了一句：**"最怕的是拿卜的方法去答命的问题，或者拿命的结论去指导医的判断。比如有人八字显示健康有隐患，就自己抓药吃——那就是拿命的尺子去量医的布，会出事的。"**
>
> 问的人听完说："所以学八字，是为了回答'我是什么样的人'，不是回答'我明天该做什么'。"
>
> "对，"老师说，"把这两个问题分开，你就入了门。"
>
> **"拿命的尺子量医的布"这句提醒值得展开**。八字能提示的是"先天体质倾向"——比如某五行偏弱，对应脏腑相对敏感。这是倾向，不是诊断。倾向的正确用法是指导生活方式（作息、饮食、体检频率），而不是替代诊疗。
>
> 那位老师还举了个反例：有人看八字说"今年健康有隐患"，于是整年惶惶不可终日，结果体检一切正常，白白焦虑了一年。**这同样是把"倾向"当成了"结论"，只不过方向相反。**
>
> 所以五术的边界可以简化成一句自问：**"我这个问题，问的是'是什么''会怎样''怎么办'里的哪一个？"** ——"我是什么样的人"问命；"这件事结果如何"问卜；"身体怎么治"问医。问对了再选工具。
>
> **复盘拆解**：五术不是五个答案，是五个问题。**先问清自己在解决什么问题，再决定用哪把尺子**——这比纠结"哪个更准"重要得多。

> **可复用的经验**：**先问"我在解决什么问题"，再选工具。** 工具选错了，再准的答案也是错的。
>

### 五、笔记法
| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 山医命相卜是五把不同的尺子 | 问"哪个更准" | 尺子和秤量的不是同一个东西 |
| 先问解决什么问题，再选工具 | 拿卜的方法答命的问题 | 八字提示健康隐患就自己抓药 |
| 八字只提示体质倾向，不作诊断 | 把倾向当结论 | "相对敏感" ≠ "你有病" |

### 六、实用验证
+ **验证 1**：说出"山医命相卜"各自的内容。
+ **验证 2**：说明八字与紫微斗数的核心差异。

| 墓 vs 库 | 身弱遇之为墓（困顿）；身旺遇之为库（储存） | 同一个字，两种命运 |
| 入墓 vs 消失 | 入墓是力量减弱封存，非消失；冲开或透干即释放 | 锁着，不是没了 |
| 十二长生"绝" vs 终结 | 绝之后是胎、养、长生，是圆圈不是终点 | 绝处逢生 |
| 人元司令分日 vs 月令定性 | 分日只做微调，不推翻月令大方向 | 寅月总体仍以木旺论 |
