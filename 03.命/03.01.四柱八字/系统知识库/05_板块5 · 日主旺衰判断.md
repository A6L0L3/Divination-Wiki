## 板块5 · 日主旺衰判断

> **本板块定位**：八字分析的第一道分水岭。旺衰判断错了，格局和用神一定跟着错。这一板块的核心不是"背结论"，而是建立一套**可复算、可验证**的判断流程。
> **通关产出**：一张四维权重表（默画版）+ 20 个命例的旺衰判定练习 + 一份"从格体检清单"。
> **建议用时**：4~5 周（5_1~5_4 大量练习，5_5~5_6 进阶）
> **边界说明**：本板块讲"日主强弱的判定流程"。季节对各五行力量的普遍影响见板块1_4（查表工具），基础概念见板块3_8（概述）。

### 5_0 本板块地图

| 单元 | 主题 | 重要度 |
| --- | --- | --- |
| 5_1 | 得令（月令） | ★★★★★ 权重约 45% |
| 5_2 | 得地（通根） | ★★★★★ 权重约 30% |
| 5_3 | 得生得助（印比） | ★★★★ 权重合计约 25% |
| 5_4 | 综合旺衰判断 | ★★★★★ 本板块核心 |
| 5_5 | 旺衰边缘案例（假从） | ★★★★ |
| 5_6 | 极旺极弱与从格 | ★★★★★ |

**六个单元是"拆开练 → 合起来 → 处理极端"的三段结构**：

```plain
【第一段：拆开练三个维度】5_1 ~ 5_3
  5_1 得令（约45%）  →  月令帮不帮日主？（权重最大）
  5_2 得地（约30%）  →  地支有没有日主的根？
  5_3 得生得助（约25%）→  天干有没有印星、比劫帮身？

【第二段：合起来定结论】5_4
  5_4 综合判断  →  四维加权，定出旺衰等级

【第三段：处理极端情况】5_5 ~ 5_6
  5_5 边缘案例  →  似从不从的"假从"怎么处理？
  5_6 极旺极弱  →  真正的从格有哪些、条件多严？
```

**为什么必须先拆开练？** 因为直接看全盘，很容易被"某处有个强根"或"天干透了个比劫"这类显眼的信息带跑。三个维度各自单独练到能秒判，合起来时才不会互相干扰。

**权重是相对的，不是公式。** 45/30/15/10 这组数字是经验参考，不是计算器——它真正的作用是告诉你**先看什么、后看什么**：月令说了算的大多数情况下，得令一项就能定个大方向；月令不明显时，才需要往后两项找依据。

**5_5 和 5_6 为什么放最后？** 因为从格是全库最容易误判的地方。很多人看到"日主很弱"就断从格，其实差得远——**从格的条件极其严格，"身极弱"和"从格"是两回事。** 这两节必须在你已经能稳定判断普通旺衰之后再碰，否则一定会滥用。

#### 5_0_1 十神强弱 vs 日主旺衰（分工与互检）

两者用的是同一套方法，判断对象不同，容易混淆：

| 维度 | 日主旺衰（板块5） | 十神强弱（本单元） |
| :---: | :---: | :--- |
| 判断对象 | 日主自己有多强 | 某一个十神有多强 |
| 判断要素 | 得令、得地、得生、得助 | 月令、根气、生扶、冲克、合化、空亡 |
| 用途 | 决定取用大方向（扶抑） | 决定某个十神的意象能否兑现 |

**互检用法**：

```plain
第1条 用十神强弱反过来验证旺衰
   例：判日主身弱，却发现官杀也无根、财星也虚浮
       → 这不是"身弱被克"，而是"全局都弱"，需重新审视

第2条 用旺衰结论限定十神强弱的解释
   例：财星旺，但日主极弱
       → 财星旺不是"有钱"，而是"担不动财"（身弱财旺反为累）
```

> **一句话**：**日主旺衰决定"能不能接住"，十神强弱决定"有多大"。** 两者相乘才是最终结果——一个再旺的十神，若日主接不住，也兑现不了。

### 5_1 得令（权重约 45%）

#### 5_1_1 定义

> **得令 = 日主五行与月令（月支本气）相同或得月生扶。**
> 得令是判断旺衰的**第一权重**，约占 40%~50%。

#### 5_1_2 得令对照表

| 日主五行 | 得令月份 | 对应地支 |
| --- | --- | --- |
| 木 | 春 | 寅、卯 |
| 火 | 夏 | 巳、午 |
| 土 | 四季月 | 辰、戌、丑、未 |
| 金 | 秋 | 申、酉 |
| 水 | 冬 | 亥、子 |

**不得令（失令 / 衰）**：日主生于克、泄、耗自己五行的季节。

#### 5_1_3 月令力量细分

同一个月支里，本气、中气、余气的力量并不相同：

```plain
月令本气（最强）：如寅月，木气最旺
月令中气（中等）：如寅月，丙火为中气
月令余气（较弱）：如寅月，戊土为余气
```

**判断要点**：日主与月支**本气**的关系决定是否得令；与中气、余气的关系决定"是否有根"（见 5_2）。

> **查表工具**：某个季节下五种五行各自的旺相休囚死状态，见板块1_4 的核心表。本单元关注的是"日主与月令的关系"，属于判定的第一步。

#### 5_1_4 特殊情况：失令但有根

```plain
日主虽不当令，但月支藏有日主同五行（有余气根）
→ 判定：不得令，但有根

例：甲木生于辰月（土月），辰中藏乙木余气
    → 失令，但有弱根
```

#### 5_1_5 落地实操：得令判定三步

```plain
第1步：看月支，查其本气五行
第2步：比对日主五行
       相同或月令生日主 → 得令
       月令克 / 泄 / 耗日主 → 失令
第3步：若失令，再查月支藏干有无日主同五行
       → 有，则判"失令有根"
```

#### 5_1_6 案例小故事：得令却翻车的命局

> 甲木生于寅月——标准的"得令"，也是所有教材里第一个举的例子。按理该判身强。
>
> 一位初学者正是这么判的，并且据此给出了"宜克泄耗"的建议。
>
> 但他漏看了一件事：这个命局的地支是寅、午、戌——**寅午戌三合火局成立**，火势极旺，而火正是木的"泄"。日主甲木虽然得令，却被旺火一点一点泄得干干净净，天干还透出丙火食神，四柱里没有一点水木帮身。
>
> 这就像一棵树长在春天（得令），但脚下是一片正在燃烧的草地——它自身的生长力再强，也架不住持续被抽走。
>
> 最终判定应该是：**得令但偏弱**，取用方向是"水木生扶"，与初学者的结论正好相反。
>
> 后来按修正后的方向给了建议（补水木、避火土），反馈才对上。
>
> **这个命局的关键在于"泄"的量**。初学者记得"木生火为泄"，却没算过泄的规模：寅午戌三合火局成立，意味着火不是"一点"，而是成建制的一整片；再加上天干透出丙火食神，泄的通道是敞开的。
>
> 排盘师后来打了个比方：**"得令说的是'这棵树长在春天'，管的是季节对不对；泄太过说的是'脚下这片草地在烧'。季节再对，也架不住持续被抽走。"**
>
> 更值得记的是修正后的效果：按"水木生扶"给建议，反馈才对上；之前那套"克泄耗"的方案，等于往火里再添柴。
>
> **复盘拆解**：得令权重约 45%，但它不是一票决定项。判完得令必须接着走完三项——**得地（有没有根）、得生（印星有没有力）、得助（比劫有没有力）**。任何一项被"成建制的克泄耗"抵消，结论就要往回拉。

> **可复用的经验**：**得令只是权重最高的一项，不是唯一一项。** 得令却被泄太过，照样身弱。判完得令，一定要接着看得地和得生助。

#### 5_1_7 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 得令看月支本气 | 误看月干或年支 | 甲木生于辰月（土）→ 失令，非得令 |
| 失令但月支有日主余气 → 失令有根 | 一刀切判"无根" | 甲木生辰月，辰中乙木为弱根 |

#### 5_1_8 实用验证

- **验证 1**：说出五行各自的得令月份。
- **验证 2**：判断"庚金生于午月"是否得令（否，火克金）。
- **验证 3**：判断"甲木生于辰月"的得令状态（失令，但有乙木余气根）。

#### 5_1_9 得令判定的三个细节

"得令"三个字看着简单，实战中有三个细节最容易出错：

```plain
细节一 · 看得是月支本气，不是月干，也不是中气余气
   例：甲木生于辰月，辰的本气是戊土 → 失令
       （辰中虽藏乙木余气，那属于"得地"，不属"得令"）

细节二 · "月令生日主"也算得令，不只是"同五行"
   例：甲木生于亥月（水），水生木 → 得令
   所以得令 = 同五行 或 月令生我；失令 = 月令克我 / 我生月令 / 我克月令

细节三 · 失令不等于无根，两件事要分开判
   失令但月支藏有日主同五行 → 判"失令有根"
   例：甲木生辰月，辰中乙木为余气根 → 失令、有弱根
```

**四库月特别提醒**：辰戌丑未四个月是**土当令**，不是木火金水的延续。三月（辰）不跟着正月二月论木旺，这是四季转换的缓冲带，也是失分高发区。

### 5_2 得地 / 通根（权重约 30%）

#### 5_2_1 定义

> **得地 = 日支或其他地支藏有与日主同五行的天干 = 通根。**
> 根气给日主提供实实在在的力量支撑。

#### 5_2_2 根的分级与位置（回顾 + 本板块视角）

> **完整的分级表与藏干查询见板块2_3。** 此处只保留判定动作，不再重复表格。

**根的五档（速记）**：

```plain
本气根（临官 / 帝旺）★★★★★  ＞  本气根（长生 / 墓）★★★★
  ＞  中气根 ★★★  ＞  余气根（假根）★★  ＞  远隔微根 ★
```

**位置的四档（速记）**：

```plain
日支 ★★★★★（紧贴日主，最重）  ＞  月支 ★★★★  ＞  时支 ★★★  ＞  年支 ★★
```

**本板块新增的一层：根如何换算成旺衰得分**

```plain
第1条 本气根在日支  →  得地一项近乎满分（约 26~30 / 30）
第2条 本气根在时支  →  约 18~24 / 30（位置偏远，打折）
第3条 中气根在日支  →  约 15~20 / 30
第4条 余气根        →  约 3~8 / 30，只够"有根"，不足以自立
第5条 年支余气根    →  约 1~3 / 30，常常只是"不算无根"
```

**盖头截脚的打折规则（本板块视角）**：

| 术语 | 定义 | 例子 | 对本板块的影响 |
| :---: | :---: | :---: | :--- |
| **盖头** | 天干克坐下的地支 | 庚寅（庚金克寅木） | 地支根气受损，得地分数打折 |
| **截脚** | 地支克上面的天干 | 甲申（申金克甲木） | 天干虚浮，得生得助分数打折 |

> **实操**：看到盖头截脚，该柱的力量按 **5~7 折**计入。这是"失令却有根"与"有根却无力"两种命局的分水岭。

#### 5_2_4 案例小故事：一根定乾坤

> 两个八字，天干格局几乎一样——都是日主被克泄耗包围，看上去都是偏弱的架势。
>
> 但地支一查，差距就出来了。
>
> 第一个：日主在时支有个**本气根**（如甲木见寅）。虽然位置偏远，但那是实实在在的本气根——有根可依，虽弱但有底气，行运补上印比就能起。
>
> 第二个：四个地支的藏干里，完全找不到日主五行。这是真正的无根虚浮——只能论从，或论极弱。
>
> 两人后来的轨迹也确实如此。前者中年之后稳步上升，事业家庭都算平顺；后者大起大落，行运一变就翻盘，五十岁前后经历了两次重大的方向调整。
>
> 有意思的是，后者年轻时反而更风光——无根的人往往更敢赌，因为没有"根"的牵绊；而前者走得慢，但每一步都踩得实。
>
> **两人的差别，在行运那一步才真正显出来**。第一位中年行印比运时稳步上升——因为他有根，运一来就能接住；第二位在同样的运里反而更动荡——因为他没有根，运来时只能被推着走，行运一变就翻盘。
>
> 有意思的是年轻时的反差：第二位反而更风光。无根的人往往更敢赌，因为没有"根"的牵绊；第一位走得慢，但每一步都踩得实。老师点评：**"有根的人前期吃亏在'放不开'，后期赢在'倒不了'。"**
>
> **复盘拆解**：查根按固定四步走——**确定日主五行 → 逐支查藏干（年 月 日 时依次过）→ 确认是本气/中气/余气 → 确认位置权重**。四个地支各查一遍，这一步在判从格时尤其不能省（见 5_6）。

> **可复用的经验**：**"有没有根"是旺衰判断里最硬的一条线**，因为它直接决定"能不能从"。判旺衰时，地支藏干这一遍不能省。

#### 5_2_5 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 根分本气 / 中气 / 余气，位置分日 / 月 / 时 / 年 | 只要见同五行就算强根 | 年支余气根 ≈ 微根 |
| 盖头截脚要打折计力 | 忽略这一层 | 甲申：甲木截脚，根气大减 |

#### 5_2_6 实用验证

- **验证 1**：说出五档根的等级与四档位置权重。
- **验证 2**：判断"甲木日主，时支寅"的根气（本气根，位置 ★★★）。
- **验证 3**：给任意八字填一次"通根盘点表"。

#### 5_2_7 根气怎么换算成旺衰得分

"有根"是定性，"根有多强"要落到分上。下面这套换算用于填 5_4 的作业表：

| 根的类型 | 位置：日支 | 月支 | 时支 | 年支 |
| :---: | :---: | :---: | :---: | :--- |
| **本气根（临官 / 帝旺）** | 26~30 分 | 22~26 分 | 18~22 分 | 12~15 分 |
| **本气根（长生 / 墓）** | 20~24 分 | 18~22 分 | 15~18 分 | 10~12 分 |
| **中气根** | 12~16 分 | 10~14 分 | 8~11 分 | 5~8 分 |
| **余气根** | 5~8 分 | 4~7 分 | 3~5 分 | 2~3 分 |

**两条修正**：

```plain
第1条 盖头 / 截脚：该字力量打 5~7 折计入
   盖头 = 天干克坐下地支（庚寅）；截脚 = 地支克上面天干(甲申)
第2条 根被冲：紧贴之冲可拔根，隔位之冲只减力不除根
```

> **用法说明**：这套分数是练习用的"权重感"工具，不是精确公式。熟练之后可直接定性判断——**重要的是记住"本气根 > 中气根 > 余气根""日支 > 月支 > 时支 > 年支"这两个排序。**

### 5_3 得生得助（权重合计约 25%）

#### 5_3_1 得生（印星，约 15%）

```plain
定义：天干上有印星（正印 / 偏印）生扶日主
条件：印星有力（有根、不被克破）才能有效生扶
```

#### 5_3_2 得助（比劫，约 10%）

```plain
定义：天干上有比肩 / 劫财帮助日主
条件：比劫有根才算有效帮助（虚浮的比劫帮力有限）
```

#### 5_3_3 生助力量评估（四条比较规则）

```plain
第1条 紧贴的生助  >  远隔的生助
第2条 有根的生助  >  无根（虚浮）的生助
第3条 单一印星生  >  单一比劫助（印星生力更大）
第4条 多个比劫    >  单个印星（人多力量大）
```

#### 5_3_4 无效 / 弱效生助的三种情况

```plain
第1条 印星 / 比劫被克合（合去、克去 = 失去作用）
第2条 印星 / 比劫本身无根（虚浮无力）
第3条 印星 / 比劫远离日主（中间隔着其他天干）
```

#### 5_3_5 落地实操：生助有效性三问

```plain
看到天干有印星或比劫，先别急着加分，问三个问题：

  Q1 它有根吗？        无根 → 只加 0.5 分
  Q2 它被合去 / 克去吗？ 是  → 加 0 分
  Q3 它离日主近吗？     隔位 → 打 7 折
```

#### 5_3_6 案例小故事：三个比劫，不如一个印

> 一位初学者看到命局天干有三个比劫帮身，立刻在表格里加了三分，判"身强"。
>
> 老师让他逐一看这三个比劫的状态：
>
> 第一个，虚浮无根。
> 第二个，也虚浮无根。
> 第三个，坐禄，是真有根的——但旁边有个合，被合住了。
>
> "所以真正能帮上忙的，只有第三个，而且还是打了折的。"
>
> 再对比另一个八字：只有一个正印，但这个印星坐月支本气、有强根，而且紧贴日主。
>
> 老师问："你觉得三个虚浮的比劫，和一个有力的正印，哪个管用？"
>
> 这正是"有根的生助 > 无根的生助"和"单一印星 > 单一比劫"两条规则的实际应用——**一个有力的印星，胜过一个虚浮的比劫群**。
>
> 后来初学者养成了一个习惯：看到印比，先在旁边标注"有根？被合？位置？"，三个问题过完再加分。
>
> **那位初学者后来改了记分方式**。以前看到印比就加一分，现在先标三个小记号：**"有根？被合？位置？"** ——三个记号都过才加分，只过一个加半分。
>
> 用这个方式重算那三个比劫：第一个无根（0 分）、第二个也无根（0 分）、第三个坐禄有根但被合住（0.5 分），合计 0.5 分。而另一个八字的那个正印：坐月支本气、有强根、紧贴日主，三个记号全过，加 1.5 分。
>
> 结果反转：**三个比劫加起来，还不如一个正印。**
>
> **复盘拆解**：生助不是数人头，是看质量。判生助有效性按三问走——**它有根吗？它被合去或克去了吗？它离日主近吗？** 三问全过才算"有效生助"，否则最多算半个。

> **可复用的经验**：**生助不是数人头，是看质量。** 十个虚浮的帮手，不如一个站得住的。

#### 5_3_7 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 生助须有根、不被合克才有效 | 见印比就加分 | 三比劫虚浮 < 一正印坐禄 |
| 印星生力 > 比劫助力 | 以为人多一定力量大 | 见 5_3 四条比较规则 |

- **验证 1**：说出四条生助力量比较规则。
- **验证 2**：说出三种无效 / 弱效生助。
- **验证 3**：给一个八字做"生助有效性三问"。

#### 5_3_9 印星与比劫的三种失效形态

"天干有印比"只是表面现象，真正决定加不加分的是它有没有失效。除了前面那三种，还有三种形态最容易被漏掉：

```plain
形态一 · 印星过旺，日主受生太过（生多为克）
   印星太多，日主被"闷"住，反而不受生
   表现：依赖、被动、想得多做得少
   判断：印星三个以上且日主本身有根 → 不是加分，是负担

形态二 · 比劫坐空亡（有名无实）
   天干有比劫，但所坐地支落空亡 → 帮力减半甚至落空
   判断：比劫 + 空亡（见板块8_4）→ 按 0.5 分计

形态三 · 印星被财星紧贴而坏（财星坏印）
   印星旁边紧贴财星，财克印 → 印星自顾不暇
   判断：印星虽有根，但被紧贴之财克住 → 生扶之力大打折扣
```

**一张对照表，直接照着打分**：

| 印星 / 比劫的状态 | 计分 | 说明 |
| :---: | :---: | :--- |
| 有强根 + 紧贴日主 + 不被合克 | 1.5 分 | 最有效的生助 |
| 有根但隔位，或根弱 | 1 分 | 有效但打折 |
| 虚浮无根 | 0.5 分 | 有名无实 |
| 被合去 / 克去 / 坐空亡 | 0 分 | 形同虚设 |
| 印星过旺（三个以上） | 反向扣分 | 生多为克，反成负担 |

> **一句话**：**数印比的个数只完成了一半，另一半是逐个查它们"有没有效力"。** 打分表里那五种状态过一遍，得生得助这一项才算算完。

### 5_4 综合旺衰判断（本板块核心）

#### 5_4_1 四维综合判断法

| 维度 | 权重 | 判断标准 |
| --- | --- | --- |
| 得令（月令） | ~45% | 日主是否当令 |
| 得地（地支根） | ~30% | 根气的数量和质量 |
| 得生（印星） | ~15% | 印星的有力和远近 |
| 得助（比劫） | ~10% | 比劫的数量和质量 |

#### 5_4_2 旺衰程度五级

| 等级 | 描述 | 取用方向 |
| --- | --- | --- |
| **极旺** | 得令 + 得强根 + 多生助，力量极强 | 喜克泄耗（从强 / 从旺） |
| **偏强** | 得令或有强根，总体偏旺 | 喜克泄耗为主 |
| **中和（平衡）** | 有得有失，大致平衡 | 视格局而定 |
| **偏弱** | 失令或根少，总体偏弱 | 喜生扶为主 |
| **极弱** | 完全失令 + 无根 + 无助 | 可能从弱 / 从杀 / 从财 |

#### 5_4_3 图解：旺衰判断流程

```plain
┌────────────────────────────────────────────────┐
│  起点：确定日主与月令                          │
└──────────────────┬─────────────────────────────┘
                   ↓
        第1步 看月令 → 得令 / 失令？        权重 45%
                   ↓
        第2步 看地支 → 有无根？根多根少？根强根弱？ 30%
                   ↓
        第3步 看天干 → 有无比劫？有无印星？有力无力？ 25%
                   ↓
        第4步 综合四维 → 定旺衰等级（五级）
                   ↓
        第5步 特殊检查 → 有无从格迹象？（见 5_6）
                   ↓
        输出：旺衰结论 + 取用方向
```

#### 5_4_5 案例小故事：一次完整的旺衰推演

> **命例**：日主甲木，生于酉月（秋金当令）。
>
> **第1条 得令？** 酉月金旺，金克木 → **失令**（0 分 / 45）
>
> **第2条 得地？**
>
> + 日支是寅——寅是甲的禄位，本气根，且位置最优（紧贴日主）→ 26 分
> + 时支是未——未中藏乙木余气 → 弱根，+3 分
> + 小计：29 分 / 30
>
> **第3条 得生？** 天干透癸水（正印），癸坐丑有根 → 印星有力 → 12 分 / 15
>
> **第4条 得助？** 天干没有甲乙比劫 → 0 分 / 10
>
> **第5条 修正：** 年支与月支酉形成酉戌害，影响不大；日支寅未被冲 → 不打折
>
> **总分约 41 分** → 判定：**偏弱**
>
> **从格检查：** 有本气禄根 + 有印星 → **不从**
>
> **取用方向：** 水木生扶（印比为用），忌金土
>
> 这个案例的关键在于：虽然失令（丢掉了最大的 45 分），但"禄根 + 正印"两件事把它从"极弱"拉回了"偏弱"。如果只看失令就判极弱，或者忽略印星，取用方向都会偏。
>
> **这个案子最容易被误判的地方在第一步**。酉月金旺、金克木，日主失令——很多人走到这儿就停了，直接判"极弱"。但失令只丢掉了那 45 分，后面还有 55 分没算。
>
> 后面三项一算：日支寅是甲木禄位（本气根，位置最优）得 26 分，时支未中藏乙木余气得 3 分，天干癸水正印坐丑有根得 12 分，比劫 0 分——合计约 41 分，落在"偏弱"。
>
> **41 分和 0 分的差别，是取用方向完全相反**：判极弱要考虑从格、顺势用金土；判偏弱则是水木生扶、忌金土。前者让他"顺势承压"，后者让他"补自己"，两条路走出来的建议几乎南辕北辙。
>
> **复盘拆解**：**失令不等于弱。** 判完得令，后面三项必须走完——尤其是根和印星，它们经常能把一个失令的日主从"极弱"拉回"偏弱"。反过来也成立：**得令也不等于强**（见 5_1）。

> **可复用的经验**：**失令不等于弱。** 判完得令，一定要把后面三项走完——尤其是根和印星，它们经常能"救回"一个失令的日主。

| --- | --- | --- |
| 四维权重：得令 45 / 得地 30 / 得生 15 / 得助 10 | 平均看待四要素 | 失令但有禄根 + 正印 → 偏弱非极弱 |
| 固定流程：月令 → 地支 → 天干 → 综合 → 从格检查 | 跳步、凭感觉 | 见 5_4 流程图 |

#### 5_4_8 旺衰结论的四条交叉校验

旺衰是全库最容易"自以为对"的判断。下结论之前，用这四条反向校验一遍：

```plain
校验一 · 反证法
   假设结论反过来，能不能成立？
   判"身强"→ 试着论证"身弱"，若论据同样充分，说明你没抓住主要矛盾

校验二 · 结构法
   加分项集中在哪？是"生扶太多"（补药吃多了），还是"缺少制约"（没人管）？
   两者的取用方向可能完全相反（见 1_2 案例）

校验三 · 从格排除
   判"极弱"之前，必须过一遍 5_6 的从格五问
   五问不全中，一律退回"正格身弱"

校验四 · 事实校验
   用命主已发生的经历反推：
   身强的人通常在压力运中反而起得来；身弱的人在印比运中明显转好
   对不上，就要回头检查得令 / 得地 / 得生 / 得助哪一项算错了
```

**最常见的三个算错点**：

| 算错点 | 典型表现 | 修正 |
| :---: | :---: | :--- |
| **把"有根"算成"强根"** | 见年支余气根就加满 30 分 | 余气 + 远隔 ≈ 微根，只能加几分 |
| **忽略盖头截脚** | 天干有比劫就满额加分 | 截脚者力量打 5~7 折 |
| **只看日主不看印星** | 失令即判身弱 | 印星得令（相地）时生扶力度很大 |

### 5_5 旺衰边缘案例（假从格）

#### 5_5_1 假从格的特征

```plain
日主看似极弱，但仍有微根或印星
├─ 若根 / 印被冲克掉 → 成真从格
└─ 若根 / 印仍在     → 只是身极弱，不能从
```

#### 5_5_2 判断要点

```plain
第1点 从格的条件极其严格：
   无根（或根被彻底拔除）+ 无助（或比劫被合去）

第2点 "假从"在实际运用中，更多当作"极弱"来论

第3点 大运流年若补足根 / 印，假从可还原为正格
```

#### 5_5_3 三大常见误区（必记）

```plain
✗ 误区一：见几个克泄耗就从
   → 必须满足严格的从格条件，不是"被克得多"就能从

✗ 误区二：有根但从
   → 有根就不算从（除非根极弱且远隔）

✗ 误区三：身弱就一定喜生扶
   → 不一定，要看弱的程度（极弱可能要顺势）
```

#### 5_5_4 落地实操：边缘案例三问

```plain
Q1 有根吗？—— 有根到什么程度？
   本气根         → 不从
   中气根         → 多半不从
   余气根 + 远隔  → 可能是假从

Q2 有印比吗？—— 被合去 / 克去了吗？
   有且有效 → 不从
   有但被合去 → 视为无

Q3 全局气势统一吗？
   绝大多字符合同一趋势 → 倾向从
   气势分散、有反对力量 → 不从
```

#### 5_5_5 案例小故事：假从的两种命运

> 两个都是"假从财格"的命局——日主都极弱，都有微根，看起来几乎一样。
>
> 但微根的位置不同。
>
> **第一位：微根在年支（远隔）。** 三十岁前走财运，一路顺遂，完全符合从财格的表现——敢投、敢闯，也能赚到钱。那个远在天边的微根，几乎没有发挥过作用。
>
> **第二位：微根在日支（紧贴）。** 早年走印比运，微根被大运激活，从格"还原"成了正格。结果财运不但没来，反而因为"身弱担不动财"而连续破财——他投什么亏什么，最惨的一年把积蓄赔掉大半。
>
> 两人是在一次聚会上认识的，聊起各自的经历都笑了："我们命盘差不多，命运差挺多。"
>
> 老师后来拿这个案例讲了关键的一层：**"假从最怕的不是'不像真从'，而是'不知道自己什么时候会还原'。真从格的人一生顺着气势走，逻辑清晰；假从格的人，人生是分段的——没被激活的年份像从格，被激活的年份突然变成身弱正格，取用方向整个反过来。"**
>
> **"所以假从格的人最容易犯的错误，是拿前二十年的经验去套后二十年。"** 第一位就是典型——他三十岁前"敢投敢赚"养成的习惯，在微根被激活之后就成了灾难。
>
> 判断的方法也很明确，两条：**一看微根的位置**（年支远隔，力量难及日主，多半不发挥作用；日支、月支紧贴，随时可能被激活）；**二看大运的走向**（印比运是激活信号，财官食伤运是维持从势）。
>
> 把这两条按大运逐年排一遍，就能标出"哪几步运可能还原"——那几步就是需要改变策略的年份。
>
> **复盘拆解**：假从格之所以难，是因为它**不是一个固定状态，而是一段会变化的状态**。真从格顺着走就是了；假从格有牵挂，一旦大运给了根气或印星，就会"还原"成正格——取用方向因此整个反过来。
>
> 所以拿到假从的结论，必须多做一步：**把大运里"还原风险期"标出来**（印运、比劫运就是还原期）。这一步不做，等于只给了一半答案。
>
> 判断口诀可以压缩成一句：**"有根不从，微根假从，假从看运。"** 前两句定性质，第三句定后续动作。

> **可复用的经验**：**假从是一个动态状态，不是一个标签。** 判断假从时，重点看两件事——微根在哪里（远隔还是紧贴）、大运会不会把它激活。**拿到"假从"结论之后，下一步必须排一遍大运，把可能还原的年份标红。**

#### 5_5_6 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 假从当作"极弱"论更安全 | 一判从就按从格取用 | 假从行财运反主破财 |
| 有根不从（除非根极弱且远隔） | 见克泄耗多就判从 | 日支余气根 → 不从 |

#### 5_5_7 实用验证

- **验证 1**：说出三大常见误区。
- **验证 2**：给一个"日主极弱但有微根"的命局做边缘案例三问。
- **验证 3**：解释为什么"假从"是一个动态状态。

#### 5_5_8 假从格的"还原风险运"标注法

拿到"假从"的结论，只算完成一半。另一半是**把大运里可能还原的年份标出来**——因为假从的人最容易栽在"拿前二十年的经验去套后二十年"。

**四步标注法**：

```plain
第1步 找出"牵挂"在哪
   微根在哪一柱？印星在哪一柱？
   → 年支远隔（最不容易被激活）
   → 月支、日支紧贴（随时可能被激活）

第2步 逐运检查激活信号
   印运、比劫运 = 激活信号（日主得根得生）
   财官食伤运 = 维持从势（不激活）

第3步 标红风险运
   把命局里所有"印运 / 比劫运"圈出来
   尤其注意与"牵挂"所在支形成合、会、值的年份

第4步 写明打法切换
   维持从势的运：顺势、敢进、可押注
   还原风险运：收缩、守成、减少长周期投入
```

**一张速查表**：

| 大运性质 | 假从的状态 | 打法 |
| :---: | :---: | :--- |
| 财 / 官杀 / 食伤运 | 维持从势 | 顺势而为，可主动出击 |
| 印运 | **高还原风险** | 收缩，减少投入，不押长周期 |
| 比劫运 | **高还原风险** | 同上，且注意合作与分利 |
| 交脱运前后 | 状态不稳 | 观望，只做准备不做决策 |

> **为什么必须写出来**：从格之人的一生逻辑是"顺势"，最危险的运恰恰是别人眼里"帮你"的印比运。不把它标出来，对方会照着前二十年的成功经验继续猛打——而那正是环境已经变了的时刻。**标红这一步，是假从格断语里最有价值的一条。**

### 5_6 极旺极弱与从格

#### 5_6_1 五种从格类型

| 格名 | 条件 | 取用 |
| --- | --- | --- |
| 从强格 | 日主极旺，全局皆比劫印星 | 喜比劫印星（顺势） |
| 从旺格 | 类似从强，更强调气势专一 | 喜同五行 |
| 从杀格 | 日主极弱，全局皆官杀 | 喜官杀（顺势） |
| 从财格 | 日主极弱，全局皆财星 | 喜财星 |
| 从儿格 | 日主极弱，全局皆食伤 | 喜食伤（从儿即从食伤） |

#### 5_6_2 从格成立的五个严格条件

```plain
第1条 日主完全失令（月令不是日主同类五行）
第2条 日主在地支毫无根气（或仅有极弱的余气根且远隔）
第3条 天干无比劫（或比劫被合去 / 克去）
第4条 天干无印星（或印星被合去 / 克去）
第5条 全局气势统一（绝大多数字都是同一五行或同一趋势）
```

> **五条必须全部满足，缺一不可。** 这也是为什么真从格在实战中并不常见——大多数看着像从的，其实只是"极弱"。

#### 5_6_3 真假从格辨别

| 类型 | 判定 |
| --- | --- |
| **真从格** | 五个条件全部满足 |
| **假从格** | 基本满足，但有一丝牵挂（如远处有一弱根） |
| **不从格** | 有明显根 / 印存在，只是身弱而已 |

#### 5_6_4 从格的动态变化

```plain
从格在大运流年遇到补救（根 / 印出现）→ 可能还原
还原后按正格重新论
这就是"真从假从"的动态变化
```

#### 5_6_5 图解：从格体检清单

```plain
┌─────────────────────────────────────────────┐
│ 从格体检（五问全"是"，方可论从）            │
├─────────────────────────────────────────────┤
│ □ 1. 日主完全失令？                         │
│ □ 2. 地支毫无根气？（或仅极弱余气且远隔）   │
│ □ 3. 天干无比劫？（或被合去 / 克去）        │
│ □ 4. 天干无印星？（或被合去 / 克去）        │
│ □ 5. 全局气势统一？                         │
├─────────────────────────────────────────────┤
│ 全"是"    → 真从格，顺势取用                │
│ 4 个"是"  → 假从格，按极弱论，警惕还原      │
│ ≤3 个"是" → 不从，按正格身弱论              │
└─────────────────────────────────────────────┘
```

#### 5_6_6 落地实操：从格判定的四条安全策略

```plain
策略一：五问不全满足 → 一律按正格论（宁可判"极弱"）

策略二：判假从时，取用上留余地
        ——既考虑顺势，也保留生扶的可能

策略三：断大运时，特别标注"印比运"
        ——这是最容易还原的运势段

策略四：断语中明确说明"此为假从，行运变化较大"
        ——避免绝对化
```

#### 5_6_7 案例小故事：从杀格的两种读法

> **第一个命局：日主极弱，满盘官杀，五问全中 —— 真从杀格。**
>
> 逐条核对：完全失令 ✓、地支毫无根气 ✓、天干无比劫 ✓、天干无印星 ✓、全局气势统一 ✓。五问无一遗漏，从格成立。
>
> 按从格取用：喜官杀、喜财星（财生官杀），忌印比。行运走到官杀、财运时，此人一路升迁，在体制内做到了相当级别——完全符合"从杀格主武职权威"的描述。他自己也说：**"我这种人就是在有压力的环境里才出活，一闲下来反而浑身不舒服。"**
>
> **第二个命局：同样官杀满盘，被一位初学者判成了从杀格。**
>
> 那位初学者给出的建议也很顺理成章："顺官杀之势，多接挑战，多扛压力。"
>
> 但细看——**日主在时支有个本气根。** 时支虽然偏远，根气却是真实的。有根就不从，这是硬规则，没有例外。正确判法应该是"身极弱、官杀重"，取用方向是**印星化杀生身**（用学识、资质、贵人来化解压力），而不是顺势硬扛。
>
> 结果那个人真的去接了大量高压项目。一年内进了两次医院，还跟合作方闹到差点打官司。他后来跟人说："我当时以为是咬牙就能过去的事。"
>
> **复盘时老师讲了三层，这三层比"判错一次"本身更重要：**
>
> **第一层：从格判错的代价是不对称的。** 判保守（本可论从而论身弱），最多是断语偏软；判激进（本不该从而论从），取用方向整个反过来，所有断语全盘皆错。所以原则只有一条：**宁可保守，不可激进。**
>
> **第二层：为什么真从格远比想象中少？** 因为五问要全中很难——尤其是第二问"地支毫无根气"。很多人只看天干（天干确实没有比劫印星）就判从，忘了翻四个地支的藏干。**时支、年支的余气根最容易漏掉。**
>
> **第三层：发现问题的方法很固定。** 拿到"似乎很弱"的命局，就用五问逐条打勾，写在纸上。**四问"是"也不能论从——只要有一问答"否"，就退回正格。**
>
> **复盘拆解**：除了"宁可保守不可激进"，这个案子还有一层值得记：**从格判错的代价是不对称的。** 判保守（本可从而论身弱），断语会偏软，但方向不反；判激进（本不该从而论从），取用整个反过来，所有断语全盘皆错。
>
> 所以安全策略只有一条：**五问不全中，一律退回正格。**
>
> 另外要记住漏网之鱼在哪：**时支与年支的余气根最容易漏看。** 很多人只查天干（确实没有比劫印星）就下结论，忘了翻四个地支的藏干。逐支查一遍，两分钟，能挡掉绝大多数误判。

> **可复用的经验**：**真从格远比想象中少。** 五问里只要有一问答"否"，就退回正格——这样最多判保守，不会判反。判断时尤其要翻遍四个地支的藏干，时支余气根是最常见的漏网之鱼。

### 5_7 易错对照表

| 易混对 | 关键区别 | 一句话记法 |
| :---: | :---: | :--- |
| 得令 vs 得地 | 得令看月支本气（是否当令）；得地看四支藏干（有没有根） | 一个看季节，一个看地支 |
| 得生 vs 得助 | 得生是印星生我；得助是比劫帮我 | 印星生力 > 比劫助力 |
| 有根 vs 强根 | 余气根、远隔根只是"有根"，不等于有力 | 有根 ≠ 有力 |
| 身弱 vs 从格 | 身弱有根有印 → 正格；从格须五问全中 | 有根不从 |
| 真从 vs 假从 | 真从五问全中；假从有一丝牵挂（微根或远印） | 假从按极弱论更安全 |
| 假从 vs 身极弱 | 假从是动态状态，行运可能还原 | 拿到假从，下一步必排大运 |
| 从强 vs 从旺 | 从强是全局比劫印星；从旺更强调气势专一 | 两者取用相近 |
| 偏弱 vs 极弱 | 偏弱尚有根或印；极弱完全失令无根无助 | 极弱才需要检查从格 |
| 中和 vs 说不清 | 中和是"有得有失大致平衡"，不是"判断不出来" | 判不出就回到四维权重逐项打分 |
