## 板块7 · 用神体系

> **本板块定位**：整套八字体系的"临门一脚"。前面所有分析——旺衰、格局、十神——最终都要收敛到"用神是什么"这个结论上。用神就是命局的药方。
> **通关产出**：一份"取用五步决策流程" + 20 个命例的用神推导 + 一张多法冲突时的优先级表。
> **建议用时**：4~5 周（7_1~7_5 系统学习，7_6~7_8 综合运用）
> **边界说明**：用神、忌神等四个名词的**定义**见板块3_9（概述），本板块讲的是**取法**；格局层面的救应见板块6_2，本板块 7_4 是完整的病药体系。

**七个单元是"一主三辅 + 动态 + 收口"的结构**：

```plain
【主干方法】7_1
  7_1 扶抑  →  身强就克泄耗，身弱就生扶（默认入口）

【三种修正】7_2 ~ 7_4
  7_2 调候  →  太寒太燥时，先解决冷暖（优先级常高于扶抑）
  7_3 通关  →  两军对垒时，先找中间人化解
  7_4 病药  →  有明显病灶时，先对症下药

【动态与对立面】7_6 ~ 7_7
  7_6 变化  →  大运变了，用神会不会跟着变？
  7_7 忌神  →  用神的反面是谁？（忌神、仇神、闲神）

【收口】7_8
  7_8 实战  →  多法冲突时按什么优先级取舍
```

**为什么扶抑（7_1）是默认入口？** 因为它最直接——身强身弱的结论从板块5 直接拿过来就能用。多数命局用扶抑就能定下方向。

**那为什么还要学另外三种？** 因为扶抑只看"力量平衡"，而有些命局的问题不在力量：寒冬腊月出生的命局，先要"取暖"（调候）；两种五行硬顶的命局，先要"疏通"（通关）；某一行过旺成病的命局，先要"治病"（病药）。**这三种是修正项，不是可选项。**

**学到 7_8 之前请记住一条**：四种方法不是互相排斥的，而是"先用谁"的排序问题。7_8 会给出完整的优先级表——**在那之前，如果多法结论打架，不必焦虑，这是正常的，先按 7_1 走完流程再说。**

#### 7_0_1 格局评断的四个常见偏差

用"格局综合评断表"打分时，有四个偏差会系统性地拉低准确度：

| 偏差 | 表现 | 纠正办法 |
| :---: | :---: | :--- |
| **偏差一 · 只看纯粹度** | 一见"有杂"就降分 | 有杂但有制化，不算破；杂而无力才算破 |
| **偏差二 · 忽略日主承受力** | 格局漂亮就直接判上格 | 日主担不起，格局再好也打折（财格身弱 = 担不动财） |
| **偏差三 · 把"有病"当减分** | 看到破格就降层次 | **有病有药反比无病无药更有层次**（见 6_2） |
| **偏差四 · 把层次当判决书** | 报"中格"让对方误会 | 补两句：说明它意味着什么、不意味着什么 |

**一条收口原则**：**格局看的是"结构与稳定性"，用神看的是"吉凶调节"。** 两者不可互相替代——上格也需好运配合，中格若用神得力，同样能过得很好。

### 7_1 扶抑用神

#### 7_1_1 基本原则

```plain
身强 → 用克泄耗（官杀 / 食伤 / 财星）
身弱 → 用生扶（印星 / 比劫）
身中和 → 视格局而定
```

#### 7_1_2 扶抑法的本质

> **通过加减日主的力量使其达到平衡。就像天平：左边太沉就在右边加码，右边太沉就在左边加码。**

#### 7_1_3 具体取法

```plain
第1步：先判旺衰（板块5 的结论）
第2步：身偏强 → 取克泄耗为用神
第3步：身偏弱 → 取生扶为用神
第4步：若有多种可选 → 取最有利格局的那种
```

#### 7_1_4 示例

```plain
甲木日主，生于寅月（得令），地支又有卯木根 → 身强
可用之神（三选一）：
  庚辛金（官杀克身）→ 走仕途、管理、规则路线
  丙丁火（食伤泄身）→ 走才华、技艺、表达路线
  戊己土（财星耗身）→ 走经营、求财、务实路线

→ 最终选哪个？看格局需要（见第4步与 7_8）
```

#### 7_1_6 案例小故事：三个候选，选哪一个

> 一位客户的命局：甲木身强，官杀、食伤、财星三个方向都可以用。三个方向对应三种人生，选错了就是南辕北辙。
>
> 排盘师先问了格局：月令透出的是正官，是正官格。正官格的用神取向是"护官、生官"——所以首选财星（财能生官），次选官杀本身。
>
> 再看有力与否：此命局中财星虚浮无根，而官杀却有强根。
>
> 两条规则一碰，结论就出来了：**有力者优先**——取官杀，兼扶财星。
>
> 断语是："适合在规则明确的体系内发展，靠业绩与资历晋升，中年后财随官来。"
>
> 客户听完说："我现在是自由职业，一直在考虑要不要考个证进体制。"
>
> 排盘师说："按这个命局，进体系是对的路。但你现在的问题是财星无根——进了体系之后别急着搞副业，先把手上的事做扎实。"
>
> 三年后客户反馈：考进了某事业单位，晋升顺利，确实没再折腾副业。
>
> **这个案子的关键不在"选了官杀"，而在"为什么没选财星"**。按正官格的要求，财星生官本是首选；但此命局财星虚浮无根，等于"想生官却生不动"。而官杀本身有强根，力量是实的。**有力者优先**——这条规则在这里压过了"格局偏好"。
>
> 还有一层容易被漏掉：取官杀之后，断语里仍保留了"兼扶财星"。因为财星虽然当下无力，却是格局链条上的一环，遇到财星得根的大运就能补上。客户后来的经历正印证了这一点——进体系后的第三年，一次岗位调整带来了稳定的项目收入。
>
> **复盘拆解**：三选一不是拍脑袋，是三重过滤——**第一重看格局要求**（定方向）、**第二重看有力与否**（定可行性）、**第三重看链条完整性**（定后续）。少一层，结论就会偏。

> **可复用的经验**：**取用不是三选一，而是"候选排序 + 有力性筛选 + 格局要求"三重过滤。** 少一层，结论就会偏。

| 多种可选时取"有力且利格局"者 | 三选一时凭感觉 | 见 7_1 案例 |

#### 7_1_9 "有力性"检验的三条标准

扶抑给出候选用神后，必须逐个验"有没有力"。三条标准，缺一不可：

```plain
标准一 · 有根：候选用神在地支藏干中有同五行（本气 > 中气 > 余气）
标准二 · 不被合去 / 克去：合去则变质，克去则失效
标准三 · 位置靠近日主：紧贴最验，隔位打七折
```

**三条都不满足的用神，等于"药轻病重"**——写在结论里看着完整，实际兑现不了。这时有两个选择：

| 情况 | 处理 |
| :---: | :--- |
| 候选用神无力，但大运能补 | 取为用神，并注明"待某运补足后方可发力" |
| 候选用神无力，且大运也不补 | 换一个有力的候选用神，或改用通关 / 病药思路 |

> **一条易错**：**"用神虚浮"不等于"没有用神"，而是"这个用神现在使不上劲"。** 断语要相应地从"必然"改成"倾向"，并给出发力的时间窗口。

### 7_2 调候用神

#### 7_2_1 调候的概念

> **调节命局的寒暖燥湿，使五行之气适中。**
> 这是调候派的核心理念，解决的是"环境温度"问题，而非"力量大小"问题。

#### 7_2_2 十天干调候总览

| 日主 | 生于寒月（秋冬） | 生于暖月（春夏） |
| --- | --- | --- |
| 甲 / 乙木 | 喜火（丙）调候暖局 | 喜水（癸）润局防燥 |
| 丙 / 丁火 | 喜木（甲）生火助燃 | 喜湿土（辰）晦火降燥 |
| 戊 / 己土 | 喜火（丙）暖局 | 喜水（癸）滋润 |
| 庚 / 辛金 | 喜火（丁）暖金炼金 | 喜湿土（辰丑）生金 |
| 壬 / 癸水 | 喜火（丙）调候暖局 | 喜木（甲）泄水引流 |

#### 7_2_3 调候优先原则

```plain
第1条 在寒冬腊月出生的命局，调候（取暖）往往是第一用神
第2条 在酷暑炎夏出生的命局，调候（降温）同样重要
第3条 调候用神可能与扶抑用神冲突，需权衡取舍（见 7_8）
```

#### 7_2_4 图解：调候 vs 扶抑

```plain
┌────────────────────────────────────────────────┐
│  扶抑法问的是："日主够不够力？"                │
│      → 加减日主的力量                          │
│                                                │
│  调候法问的是："命局环境适不适合生存？"        │
│      → 调节寒暖燥湿                            │
│                                                │
│  打个比方：                                    │
│     扶抑 = 给一个人的饭量做调整                │
│     调候 = 给一个人的房间温度做调整            │
│                                                │
│  人饿了要吃饭，房间冷了要取暖——两件事都要顾，  │
│  但冷到极点时，得先取暖，饭才吃得下去。        │
└────────────────────────────────────────────────┘
```

#### 7_2_5 落地实操：调候检查两步

```plain
第1步：看月令是否处于极端寒暖
       极寒：亥、子、丑月（冬）
       极暖：巳、午、未月（夏）

第2步：查上表，写出该日主的调候用神
       → 与扶抑用神比对
          一致 → 强化，取用明确
          冲突 → 进入 7_8 的优先级裁决
```

#### 7_2_6 案例小故事：寒冬里的那把火

> **命局**：庚金日主，生于子月（寒冬），身偏强。
>
> **按扶抑法推：** 身强宜克泄耗。水（泄）、火（克）、木（耗），三个方向都能用。
>
> 一位初学者的选择是"水"——理由是金生水，泄秀主才华，听起来很顺。
>
> **但问题出在环境温度上。** 子月是寒冬，天寒地冻，金寒水冷。这个命局真正缺的不是"泄"，而是"暖"。此时最需要的恰恰是**火**来暖局——按调候法，庚金生于冬月，调候用神是丙丁火。
>
> **两条线索一碰，结论就出来了：** 火在扶抑候选里本来也存在（火克金，为官杀），调候也指向火。两条路指向同一个答案，取用非常确定。
>
> **最终取用：火。**
>
> **后来的验证：** 这位命主进了能源行业做管理，一路顺遂——能源在五行类象里正属火。他自己的感受很朴素："我这个人一到暖和的地方就状态好，冬天特别容易丧。"
>
> **回头看初学者的那个选择：** 如果按扶抑取了"水"来泄金，寒冬再加水，就是雪上加霜——金更冷、水更寒，整个人会越来越沉。他有才华，但才华发挥不出来（水寒则滞），而且情绪长期偏低。
>
> **这个案例最值得记住的是两层：**
>
> **第一层：四种取用法的优先级不是摆设。** 调候排在扶抑之前，理由很朴素：**环境不对的时候，力量再平衡也没用。** 打个比方——一个人冻得发抖，你给他再精准的营养配比，也不如先给他一件棉袄。
>
> **第二层：多法指向同一答案时，取用最确定。** 调候说要火，扶抑也允许火（官杀），那这个用神就非常可靠。反过来，**如果多法结论打架**（比如调候要火、扶抑要水），就要回到 7_8 的优先级表做裁决，而不是凭感觉选一个。
>
> **复盘拆解**：这个案子证明了优先级不是摆设。两条理由值得单记：**一是"环境不对，力量再平衡也没用"**——冻得发抖的人，给再精准的营养配比也不如先给一件棉袄；**二是多法指向同一答案时取用最确定**，反过来若调候与扶抑打架，就要回到优先级表裁决，而不是凭感觉挑一个。
>
> 还有一层很实用：**冬夏生人先查调候，这一步最便宜、也最容易被跳过。** 拿到任何盘，先问一句"它生于寒冬还是酷暑"，成本几乎为零，收益却可能是整个取用方向。

> **可复用的经验**：**环境不对的时候，力量再平衡也没用。** 拿到任何命局，先问一句"它生于寒冬还是酷暑"——这是最便宜、也最容易被跳过的一步。

### 7_3 通关用神

#### 7_3_1 通关的概念

```plain
命局中两种相克的五行势均力敌，形成僵局
   ↓
引入第三种五行来"疏通"两者关系
   ↓
这个第三方就是"通关用神"
```

#### 7_3_2 五种常见通关模式

| 战局 | 通关用神 | 原理 |
| --- | --- | --- |
| 金木交战（金克木） | 水（印星） | 水生木、泄金，两边都照顾 |
| 水火不容（水克火） | 木（食伤） | 木生火、泄水 |
| 火金相克（火克金） | 土（财星） | 土生金、泄火 |
| 木土相战（木克土） | 火（食伤） | 火生土、泄木 |
| 土水相克（土克水） | 金（食伤） | 金生水、泄土 |

#### 7_3_3 通关成功的三个标志

```plain
第1条 两种敌对的五行都能接受这个中介
第2条 原来的冲突被化解为流转
第3条 命局整体气势变得通畅
```

#### 7_3_4 图解：通关原理

```plain
不通关时：
    金 ══克══▶ 木        （两军对垒，互相消耗）

通关后：
    金 ──生──▶ 水 ──生──▶ 木
   （金的杀气被水泄掉，转而滋养木）

关键：中介五行必须能同时"泄掉攻方"且"生助守方"
      水泄金（金生水）+ 水生木 = 两边都说得通
```

#### 7_3_5 落地实操：通关三步

```plain
第1步：找出命局中最激烈的对抗
       （哪两种五行势均力敌且相克？）

第2步：查通关表，找中介五行

第3步：验证中介是否有力（有根、不被克去）
       有力 → 通关成立，取为用神
       无力 → 通关失败，改用扶抑或病药
```

#### 7_3_6 案例小故事：一场持续十年的金木之战

> 某命局庚金（七杀）与甲木（日主）紧贴相战，两股力量旗鼓相当，形成僵局。
>
> 命主来找排盘师时的原话是："从三十到四十岁，我一直在跟上级斗、跟规则斗，赢了也累，输了更累。十年下来，我也不知道自己到底得到了什么。"
>
> 他的通关用神是水（印星）——水生木、泄金，把"金克木"的死结变成"金生水、水生木"的流转。
>
> 四十一岁那年，他进入一步水运（印运）。
>
> 那十年他做了一件改变一切的事：**去读了两个学位，转行做教育与咨询。**
>
> 印主学识、师长、庇护。他没有再去跟人硬碰硬，而是把对抗的能量转成了学习——以前用来吵架的劲，现在用来啃书。
>
> 他后来总结："以前是硬碰硬，后来是把力气用到别处。**金还是那块金，但不再砍我了，它变成了我的资源。**"
>
> **他转行那一步，本质上是"换了个战场"而不是"打赢了对手"**。三十到四十岁那十年，他一直在"金克木"这个结构里打——跟上级争、跟规则争，赢了也累。通关用神水的意义不是让金消失，而是**给金和木之间开一条渠：金生水、水生木，原本砍他的那股力量变成了滋养他的资源。**
>
> 有意思的是他自己的感受："以前是硬碰硬，后来是把力气用到别处。**金还是那块金，但不再砍我了。**"
>
> **复盘拆解**：遇到两军对垒，先别问"谁能赢"，先问"谁能做中介"。中介要同时满足两个条件——**能泄掉攻方、又能生助守方**。找到之后再验一句：**这个中介有根吗？** 虚浮的中介等于纸上谈兵，通关不成立，需退回扶抑或病药。

> **可复用的经验**：**通关的本质不是消灭冲突，而是给冲突找一条出路。** 遇到命局中两股力量死磕，先想"谁能做中介"，而不是"谁能赢"。

#### 7_3_7 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 通关 = 找中介五行，泄攻方、生守方 | 中介选错，变成帮凶 | 金木交战用水，不用火（火克金但泄木） |
| 中介必须有力才成立 | 纸上通关，实际无力 | 水通关但水虚浮 → 通关失败 |

- **验证 2**：判断"土水相克"的通关用神（金）。
- **验证 3**：给 3 个有激烈对抗的命例做"通关三步"。

#### 7_3_9 通关失败的三种情况

通关不是每次都成立。三种情况下，通关用神会出现"纸上有效、实际无效"：

| 失败类型 | 表现 | 处理 |
| :---: | :---: | :--- |
| **中介无力** | 中介五行虚浮无根，两边都接不住 | 退回扶抑或病药 |
| **中介被克** | 中介被第三个字克住，自身难保 | 先救中介，或换思路 |
| **只有一方接受** | 中介能泄攻方，却生不到守方（或反之） | 中介选错，重新查通关表 |

**一条自查**：通关成立后，命局应当出现"气势变通畅"的感觉——原本死磕的两股力量开始有流向。如果推演完仍然堵着，说明通关没成立，**不要硬套**。

> **与病药的区别**：通关解决的是"两股力量对撞"（双方都不弱）；病药解决的是"某一行过旺成病"（一方独大）。**势均力敌用通关，一方独大用病药。**

### 7_4 病药用神

#### 7_4_1 病与药的定义

```plain
病 = 命局中最突出的毛病 / 缺陷
     可能是某五行过旺（亢则为病）
     也可能是某五行过缺（缺也为病）

药 = 能治这个病的那个五行 / 十神
     药要对症：旺者抑之，缺者补之
```

#### 7_4_2 常见病药对应表

| 病（问题） | 药（解决方案） |
| --- | --- |
| 官杀太旺克身 | 印星化杀生身 / 食神制杀 |
| 比劫太旺夺财 | 官杀制比劫 / 食伤泄比劫 |
| 食伤太旺泄身 | 印星克食伤 / 比劫帮身 |
| 财星太旺坏印 | 比劫夺财 / 官杀护印 |
| 印星太旺夺食 | 财星破印 / 食伤强旺 |
| 某五行太缺 | 补该五行，或补其生扶之五行 |

#### 7_4_3 病药的三个层次

```plain
第一层病：明显的五行失衡（一眼可见）
第二层病：隐性的格局缺陷（需要深入分析）
第三层病：大运引发的临时病症（动态变化）
```

#### 7_4_4 落地实操：找病四步

```plain
第1步：扫全局——哪个五行最旺？哪个最缺？

第2步：最旺的那个，有没有造成实质伤害？
       （它克了谁？压了谁？）
       有 → 它就是"病"，抑制它的五行是"药"

第3步：最缺的那个，是不是日主需要的？
       是 → 缺也是病，补之

第4步：药要有力——有根、不被合克
       有力 → 药到病除
       无力 → 病重药轻，效果打折
```

#### 7_4_5 案例小故事：比劫夺财，该开哪味药

> 一位客户三次合伙创业，三次被伙伴坑。钱没赚到，朋友也没了。他来的时候已经有点怀疑人生："是不是我这人就是太容易信别人？"
>
> 看命局：比劫重重，财星孤立——典型的"比劫夺财"。
>
> 病很清楚。药有两个选项：
>
> **选项一：官杀制比劫**——用规则和压力去压制。
> **选项二：食伤泄比劫**——用才华和技艺去转化。
>
> 选哪个？看哪个有力。
>
> 一查：官杀在此命局中虚浮无力，等于"想用规则管住别人，但自己没有那个权威"；而食伤却有根，意味着他确实有一技之长可以倚仗。
>
> **选有力之药——食伤。**
>
> 给的建议很具体：不合伙，做独立的技术型个体（食伤主技艺、表达），靠个人作品变现；同时所有合作一律走书面合同，用制度弥补"不设防"的性格。
>
> 三年后他成了独立开发者，收入超过之前三次创业的总和。他说最大的改变不是赚到钱，而是"不用再猜别人在想什么了"。
>
> **他三次被坑的模式几乎一模一样**：都是熟人介绍、都是口头约定、都是"先把事做起来再说钱"。排盘师把这三条和他的命局对上了——比劫重重对应"熟人圈密集"，财星孤立无根对应"钱的事没有制度化"。
>
> 药有两味，选的是有力那一味。官杀（规则、权威）在此局虚浮，意味着"他想用规矩管住别人，却没有那个权威"；食伤（技艺、作品）有根，意味着他确实有一技之长可以倚仗。**于是方向定为：不靠管人，靠作品。**
>
> 三年后他说最大的改变不是赚到钱，而是**"不用再猜别人在想什么了"**——这句话正好点出比劫夺财的深层代价：不是钱的问题，是长期处在"要不要设防"的内耗里。
>
> **复盘拆解**：开方的顺序是——**先找病**（哪个五行/十神过旺或过缺）、**再列药**（所有能治它的选项）、**最后筛有力者**（药必须能兑现）。**病重药轻，等于没开方。**

> **可复用的经验**：**药往往不止一味，只选"有力的那一味"。** 病重药轻，等于没开方。

#### 7_4_6 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 旺者抑之、缺者补之 | 只治"旺"，不治"缺" | 缺用神五行也是病 |
| 药必须有力 | 纸上开方，无力见效 | 比劫夺财：官杀虚浮则改用食伤 |

#### 7_4_7 实用验证

- **验证 1**：默写出六条病药对应。
- **验证 2**：说出病药的三个层次。
- **验证 3**：给 5 个命例做"找病四步"。

#### 7_4_8 取用的五个常见失误

用神是整套体系的收口，也是错误集中的地方。五个失误按出现频率排序：

| 失误 | 表现 | 修正 |
| :---: | :---: | :--- |
| **失误一：缺什么补什么** | 命局缺金就补金 | 补之前先看日主旺衰——身强再补印比是火上浇油 |
| **失误二：只用扶抑** | 一律按"身强克泄耗、身弱生扶"取用 | 冬夏生人先查调候，两军对垒先查通关，明显病灶先查病药 |
| **失误三：取了无力的用神** | 用神虚浮无根 | 候选用神必须过"有力性"检验，无力则降级 |
| **失误四：忽略格局要求** | 取用与格局方向相反 | 成格者优先考虑格局用神（第四优先级） |
| **失误五：一步运一换用神** | 每步大运都重新取用 | 原局用神轻易不变；只有旺衰等级跨越一级以上才考虑行运用神 |

**取用后的自检三问**：

```plain
第1步 这个用神有力吗？（有根、不被合克）
第2步 它与格局要求冲突吗？
第3步 它能不能落到具体动作上？（方位、行业、行为、时间）
三问全过，才算取完。
```

> **第三问最容易被忽略。** 取出的用神如果无法翻译成"对方明天能做什么"，说明还停在五行层面，需要再用类象展开（见板块1_3 五行类象）。

### 7_5 从势用神

> **本单元定位**：前面四法（扶抑、调候、通关、病药）都建立在"日主是正格"的前提上。若命局已判为**从格**（见板块5_6、板块6_4），取用逻辑要整个换掉——这就是从势用神。

#### 7_5_1 核心原则

```plain
从格不谈"平衡"，只谈"顺从"。
日主已经弱到无法自立，就不要再想着扶它，
而是顺从全局最旺的那股气势，顺势而为。
```

**为什么必须换逻辑**：扶抑法的前提是"日主能担得起"。一个弱到无从自立的日主，再怎么扶也扶不起来，硬扶反而逆了全局气势——**这就像让一个站不起来的人去扛重物，方向本身就是错的。**

#### 7_5_2 五类从格的取用方向

| 从格类型 | 全局气势 | 喜用 | 忌 |
| :---: | :---: | :---: | :--- |
| **从财格** | 财星独旺 | 财星、食伤（生财） | 印星、比劫（还原） |
| **从杀格** | 官杀独旺 | 官杀、财星（生官杀） | 印星、比劫（还原） |
| **从儿格** | 食伤独旺 | 食伤、财星（泄秀生财） | 印星（克食伤）、比劫 |
| **从强格** | 比劫印星独旺 | 比劫、印星 | 官杀、财星（破格） |
| **从势格** | 两行以上并旺，无一行独大 | 顺其旺势，取其中流通者 | 逆势之五行 |

#### 7_5_3 三条与正格的根本差别

```plain
第1条 日主越弱越好
   正格见身弱要补；从格见身弱反而是"从得干净"，层次更高

第2条 印比是忌不是喜
   正格身弱喜印比；从格遇印比 = 日主得势 = 还原风险（见板块6_4）

第3条 不看平衡看纯粹
   正格求"中和"；从格求"纯粹"
   从格命局里夹杂的逆势五行越少，层次越高
```

#### 7_5_4 落地实操：从势取用三步

```plain
第1步 确认从格成立（五问全中，见板块5_6）
   不全中 → 退回正格，本单元不适用

第2步 找出全局最旺的那一行，定为"势"
   独旺 → 从财 / 从杀 / 从儿 / 从强
   并旺 → 从势，取其中能流通的一行

第3步 标出还原风险运
   从格怕印比运（还给日主根气）
   专旺怕官杀财运（破专一之势）
   把这几步运圈出来，写明打法切换
```

#### 7_5_5 案例小故事：从财格的两个十年

> 一位从财格的命主，前二十年顺得让人羡慕：敢投、敢闯，也确实赚到了钱。他自己总结的成功经验就四个字——**"敢下重注"**。
>
> 三十八岁那年，他进入一步印运。
>
> 按他的经验，那两年有两个大项目，他都照旧重注押了进去。结果是两次都砸了，第二次几乎赔光了前十年积累的一半。
>
> 他来问："我是不是运气用完了？"
>
> 排盘师没回答运气的事，而是给他看了两步运的性质：**前面二十年是财食伤运，全局顺势，所以'敢下重注'是对的；现在这一步是印运，日主得根，从格开始还原——打法必须切换。**
>
> 他愣了一下："那我前面那套是错的？"
>
> "不是错，是**过期了**。"排盘师说，"打个比方：顺风的时候扬帆最快，转了风向还扬满帆，翻的就是你。"
>
> 后来的两年，他把动作全改了：不做长周期押注、把资产换成可携带的形式、重大决策往后推。损失止住了。
>
> 他事后说了一句很到位的话：**"我不是失败了，我是在换季的时候还穿着夏天的衣服。"**
>
> **复盘拆解**：从格之人最容易栽在**路径依赖**上——前二十年顺，是因为打法刚好和环境匹配；环境换了打法没换，这才是真正的坑。
>
> 所以断从格大运时，**除了标红风险年份，更重要的是明确告诉对方"这几年的打法要从进攻切到收缩"**。只说"这几年要小心"，对方多半听不进去——因为他前二十年就是靠猛打过来的。
>
> **可复用的经验**：**正格求平衡，从格求顺从。** 而从格最危险的一步运，恰恰是别人眼里"帮你"的那一步。取用之前先确认自己面对的是哪一种，这比后面所有计算都重要。

#### 7_5_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 从格顺势取用，不求平衡 | 用扶抑法给从格取用 | 从财格补印比 = 逆势 |
| 从格遇印比运 = 还原风险 | 以为印比是帮自己的 | 从财格行印运反主破财 |
| 从格求纯粹，不求和 | 按"中和"标准评从格层次 | 夹杂越多层次越低 |

#### 7_5_7 实用验证

- **验证 1**：说出五类从格各自的喜用与忌。
- **验证 2**：解释为什么"从格身越弱越好"。
- **验证 3**：给一个从格命局标出还原风险运，并写出打法切换建议。

### 7_6 用神变化

#### 7_6_1 核心观念

> **原局用神 ≠ 永久用神。**

#### 7_6_2 用神变化的三种场景

```plain
第1条 大运改变旺衰状态
   原本身弱，行好运后变强 → 用神可能反转

第2条 大运引发新的矛盾
   原来不突出的问题，在新运中凸显

第3条 流年引发临时需求
   某一年特别需要某种五行
```

#### 7_6_3 判断原则（三条纪律）

```plain
第1条 原局用神是大原则，轻易不变

第2条 只有当大运从根本上改变了命局力量对比时，才考虑变化

第3条 变化后的用神称为「行运用神」或「流年用神」
```

#### 7_6_4 落地实操：用神是否该变的三问

```plain
Q1 新大运是否改变了日主的旺衰等级？
   （如从偏弱 → 中和）
   是，且跨越一级以上 → 考虑变化

Q2 新大运是否把某个原本无力的十神变有力？
   是 → 该十神可能成为行运用神

Q3 新大运是否冲克了原用神？
   是 → 原用神暂时失效，需另寻替代

三问皆否 → 原局用神不变（默认结论）
```

#### 7_6_5 案例小故事：三十年后反转的用神

> 某命局日主偏弱，原局用神是印比（水木）。前三十年走水木运，一路顺遂——读书顺、就业顺、成家也顺，几乎没遇到什么大坎。
>
> 四十岁后，他进入一部火土旺运。
>
> 这一步运带来的变化是根本性的：日主由弱转强（大运补足了力量）。原来的用神"印比"反而成了多余的负担——一个人已经吃饱了，再给他塞饭，只会积食。用神随之转向"财官"（火土）。
>
> 那十年他做了两个调整：从技术岗转向管理岗（官杀），并开始做投资（财星）。事业和财富都上了一个台阶。
>
> 有意思的是，他的一个同事跟他命局相近，但因为一直死守"我喜水木"的说法，拒绝了所有管理岗的机会，那十年几乎是原地踏步。
>
> 两人后来聊过一次。同事说："我找人算过，说我喜水木，所以我就一直待在技术岗。"
>
> 他说："我也喜水木啊——只是那一步运不喜了。"
>
> 这句话点出了"行运用神"最容易被人忽略的地方：**原局用神和行运用神不是二选一，而是"原局定底色、大运做调整"。** 原局用神管的是一辈子的大方向，行运用神管的是这十年的具体策略。多数时候两者一致，但当大运从根本上改变了力量对比时，就会分叉。
>
> 老师后来给了一个很干脆的判据：**"只有当大运把日主的旺衰等级抬升或降低了整整一级以上，才需要考虑换用神。差半级的不算——那只是微调，换用神反而会把事情搞复杂。"**
>
> 他还提醒了一句：**"换用神不等于否定原局用神。原局用神仍然是你舒服的状态，只是那十年你得按新的规则打。过了那步运，还会回来。"**
>
> **复盘拆解**：这个案子最容易被误读成"用神会变来变去"，其实恰恰相反——**它说明的是用神不该轻易变。**
>
> 三十年后"反转"的那一步，是因为大运从根本上改变了力量对比（旺衰跨了一级），属于 7_6 的三种场景之一，而不是"每隔几年就该重取一次用神"。多数人的多数时候，原局用神是稳定的。
>
> 记住两条纪律：**原局用神管一辈子底色，行运用神管这十年策略**；**只有旺衰跨一级以上，才考虑行运用神。** 差半级就换用神，反而把简单的事搞复杂了。

> **可复用的经验**：**用神是动态的。** 如果一步大运把日主的旺衰等级抬升了一级以上，就该重新审视用神——这就是"行运用神"这个概念的价值。判据是"整整一级以上"，操作上是"原局定底色、大运做调整"，两者不是替代关系。

#### 7_6_6 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 原局用神轻易不变，大运可产生"行运用神" | 每步大运都换用神 | 见 7_6 三问检查 |
| 旺衰等级跨越一级以上才考虑变化 | 稍有变化就改取用 | 偏弱 → 中和，才需重新审视 |

#### 7_6_7 实用验证

- **验证 1**：说出用神变化的三种场景。
- **验证 2**：说出三条判断纪律。
- **验证 3**：给自己或熟悉的人，检查当前大运是否需要调整行运用神。

#### 7_6_8 行运用神的判定流程

原局用神管一辈子的大方向，行运用神管这十年的具体策略。判定按四步走：

```plain
第1步 定当前大运的干支
第2步 判这一步运是否把日主旺衰等级抬升 / 降低了整整一级以上
       （偏弱 → 中和、中和 → 偏强，都算跨一级；差半级不算）
第3步 若跨级 → 重新审视用神；若不跨级 → 沿用原局用神
第4步 检查这一步运是否冲克了原用神
       冲克 → 原用神暂时失效，需另寻替代
```

**三条纪律**：

| 纪律 | 含义 |
| :---: | :--- |
| **原局用神轻易不变** | 它是底色，不是每步运都要换 |
| **跨一级以上才考虑变** | 差半级只是微调，换用神反而把事搞复杂 |
| **换用神 ≠ 否定原局用神** | 原局用神仍是你舒服的状态，那十年按新规则打，过后还会回来 |

> **一句话**：**原局定底色、大运做调整。两者不是替代关系，是"底色 + 当期策略"的关系。**

### 7_7 忌神与闲神

#### 7_7_1 忌神的识别

```plain
克制用神的十神就是忌神

例：用神是印星 → 财星是忌神（财坏印）
例：用神是官杀 → 伤官是忌神（伤官见官）
```

#### 7_7_2 忌神的危害（三档）

```plain
第1条 忌神出现在命局中 → 削弱用神的作用
第2条 大运流年遇忌神 → 不利的时间段
第3条 忌神越旺、离用神越近 → 危害越大
```

#### 7_7_3 闲神的识别

```plain
对用神和忌神都不产生重大影响的十神
既不太帮用神，也不太帮忌神
闲神在一定条件下可能转化为用神或忌神
```

#### 7_7_4 仇神（比忌神更隐蔽的危害）

```plain
定义：生助忌神、克制用神的十神
例：用神 = 印星，忌神 = 财星，仇神 = 食伤（食伤生财）
```

#### 7_7_5 图解：五神关系

```plain
      喜神（生用神者）
          │ 生
          ▼
      用神 ◀── 克 ── 忌神
                      ▲
                      │ 生
                      │
                   仇神

      闲神：站在一旁，可左可右，条件变化时会转化
```

#### 7_7_6 落地实操：四神标注法

拿到八字，把七个字（除日主外）按"用 / 喜 / 忌 / 仇 / 闲"五色标注，这是最直观的分析工具：

```plain

│ 年干：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 年支：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 月干：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 月支：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 日干：___  （日主）                    │
│ 日支：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 时干：___  神性：□用 □喜 □忌 □仇 □闲   │
│ 时支：___  神性：□用 □喜 □忌 □仇 □闲   │
└────────────────────────────────────────┘
```

**标注纪律（顺序不能乱）**：

```plain
先定用神 → 再定忌神（克用神者）
        → 再定仇神（生忌神者）
        → 再定喜神（生用神者）
        → 剩下的归闲神
```

#### 7_7_7 案例小故事：被忽略的仇神

> 某命局用神是印星，忌神是财星（财坏印）。
>
> 这位命主很懂行，知道自己"忌财"，所以一直很注意：不做投机、不合伙借钱、不给人担保。几年下来财务上确实没出过大问题。
>
> 但有一年，他突然破了一大笔财。
>
> 回头看那年的流年天干——是食伤。**食伤生财，是仇神。**
>
> 仇神不直接克用神，它是通过"给忌神供血"来间接造成伤害。就像敌人没有直接攻击你，而是源源不断地给对手运送补给。
>
> 那一年的实际情况是：他接了大量应酬和享乐型消费（食伤的意象：口福、享乐、玩乐），钱在不知不觉中就花出去了。而这些花销又挤占了他原本用于学习和进修的投入（印星受损）。
>
> 他事后复盘："我一直盯着'不能乱投资'，没想到钱是从'玩'这个口子漏掉的。"
>
> **他漏掉的那一环，是所有自学者最容易漏的一环**。他防的是忌神——不做投机、不合伙借钱、不给人担保，三条守得很牢。但他没防仇神：食伤生财，等于源源不断地给忌神供血。
>
> 那一年的实际情况是：他接了大量应酬和享乐型消费（食伤的意象：口福、享乐、玩乐），钱在不知不觉中花出去；而这些花销又挤占了他原本用于学习和进修的投入（印星受损）。**忌神没破他的防线，仇神绕过去了。**
>
> 他事后复盘："我一直盯着'不能乱投资'，没想到钱是从'玩'这个口子漏掉的。"
>
> **复盘拆解**：四神标注必须标全，不能只标用忌。按固定顺序走——**先定用神 → 再定忌神（克用神者）→ 再定仇神（生忌神者）→ 再定喜神（生用神者）→ 剩下的归闲神**。防线优先级是：**先防忌神，再防仇神**——前者正面攻击，后者侧翼供血，两个口子都要堵。

> **可复用的经验**：**防忌神，也要防"给忌神供血"的仇神。** 很多人守住了明处的防线，却漏在了暗处。

#### 7_7_8 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 忌神 = 克用神者；仇神 = 生忌神者 | 只标忌神，忽略仇神 | 用印忌财，食伤（生财）为仇神 |
| 闲神可转化 | 把闲神当永久中立 | 闲神在大运得力 → 转为用或忌 |

#### 7_7_10 四神标注的顺序与三类常见错

四神标注是最直观的分析工具，但顺序一乱就全错。固定顺序：

```plain
先定用神 → 再定忌神（克用神者）→ 再定仇神（生忌神者）
        → 再定喜神（生用神者）→ 剩下的归闲神
```

三类常见错：

| 错误 | 表现 | 纠正 |
| :---: | :---: | :--- |
| **错一 · 只标用忌** | 标完用神忌神就停，仇神闲神空白 | 仇神是暗口，必须标 |
| **错二 · 把克我者当忌神** | 见"克日主"就标忌 | 忌神是**克用神**者，不是克日主者；用神是官杀时，克官杀的伤官才是忌神 |
| **错三 · 把闲神当永久中立** | 标了闲神就不管了 | 闲神在大运得力可转为用神或忌神，要随运复查 |

> **一条实用提醒**：**仇神比忌神更隐蔽，因为它不直接克用神。** 防线的正确顺序是"先堵正面（忌神），再堵侧翼（仇神）"——只堵正面的人，多半会漏在暗处。

### 7_8 用神综合实战

#### 7_8_1 多维度用神冲突时的优先级

```plain
第1条 调候 > 扶抑：寒冬 / 酷暑命局，先调候
第2条 通关 > 单纯扶抑：有激烈对抗时先通关
第3条 病药 > 一般扶抑：有明显病灶时先治病
第4条 格局 > 用神：格局要求有时凌驾于一般用神之上
```

**五大取用法完整排序**（把"格局用神"也纳入进来）：

| 优先级 | 用神类型 | 核心思路 | 适用场景 |
| --- | --- | --- | --- |
| 第1条 | **调候用神** | 寒局用火暖、燥局用水润 | 寒冬 / 酷暑命局优先 |
| 第2条 | **通关用神** | 两行交战时引入第三方疏通 | 金木战 → 水通关；水火战 → 木通关 |
| 第3条 | **病药用神** | 找出命局最大毛病，对症下药 | 有明显病灶时优先 |
| 第4条 | **格局用神** | 月令透出之神，定格局方向 | 成格者优先取格 |
| 第5条 | **扶抑用神** | 身旺喜克泄耗，身弱喜生扶 | 无特殊格局时的通用法则 |

> **为什么这个顺序是这样的？** 因为它遵循一条朴素的逻辑：**先救命，再治病，最后才谈进补。**
>
> 寒暖失调是"活不活得下去"的问题（调候）；两军对垒是"堵不堵得住"的问题（通关）；明显病灶是"要不要动手术"的问题（病药）——这三项都属于"有紧急问题必须先处理"。
>
> 格局用神是"这个命局本来该往哪走"（格局），扶抑用神是"日常怎么保养"（扶抑）——这两项是"没有紧急问题时的常规操作"。
>
> 所以**越是常见的命局，越往下走；越是特殊的命局，越往上走。**

**扶抑速查**（第五优先级，但用得最多）：

| 日主状态 | 喜用（补什么） | 忌神（避什么） |
| --- | --- | --- |
| **身强 / 旺** | 官杀（克）、食伤（泄）、财星（耗） | 印星、比劫 |
| **身弱 / 衰** | 印星（生）、比劫（扶） | 官杀、食伤、财星 |
| **中和** | 视格局而定 | 视格局而定 |

> **边界说明**：本表与板块7_1~7_4 是同一套方法的两种表达——**那四节讲"怎么取"，这一节讲"打架时听谁的"。** 学到 7_8 之前，多法结论冲突是正常的，先按 7_1 走完流程再说。

#### 7_8_2 实战决策五步流程（本板块的收官工具）

```plain
第1步 · 看全局
   命局最大的问题是什么？
   □寒暖  □强弱  □冲克  □缺失

第2步 · 定方向
   确定主要矛盾：
   □调候  □扶抑  □通关  □病药

第3步 · 选方案

第4步 · 验证
   这个用神是否与其他方面冲突？

第5步 · 定案
   综合考虑后的最终用神 + 喜神 + 忌神
```

#### 7_8_5 案例小故事：一次完整的取用推演

> **命局**：丁火日主，生于亥月（冬）；天干透壬水（正官）、癸水（七杀）；地支亥子丑会水局；日主无根，仅年支未中藏一点丁火余气。
>
> **第1点 看全局**：水势滔天，日主丁火几乎被熄灭。最大问题有三——寒、弱、官杀重。
>
> **第2点 定方向**：亥月寒冬 → 调候优先（喜木生火、喜火暖局）；同时官杀太旺克身 → 病药（印星化杀生身）。两条线并行。
>
> **第3条 候选方案**：
>
> + A. 木（印星）：化杀生身 + 生火暖局，**一箭双雕**。若命局有根则有力。
> + B. 火（比劫）：助身暖局，但直接抗水，费力。
> + C. 土（食伤）：能制水，但泄火，身弱不宜。
>
> **第4条 验证**：取木与格局（七杀格）冲突吗？不仅不冲突——杀印相生正是贵格。
>
> **第5条 定案**：
>
> + 用神 = 木（印星）
> + 喜神 = 火（比劫）
> + 忌神 = 水（官杀）
> + 仇神 = 金（财星，生官杀）
>
> **断语方向**：此命宜以学识、资质、长辈贵人为依仗（印），在中年后木火之运发力；不宜硬抗压力，宜"化压力为资历"。
>
> 反馈：此人在教育系统工作，一路靠学历和职称晋升，四十岁后进入木火之运，事业明显提速。他自己的体会是："我不是那种能扛事的人，但我特别会考试。"
>
> **复盘拆解**：这个案子展示了"取用"真正的工作量——**不是猜一个五行，而是把四种方法都过一遍，再裁决。** 跳过任何一法，都可能漏掉关键线索；但四法都过完又容易打架，所以必须有优先级。
>
> 优先级可以这样压缩记忆：**先看寒暖（调候）→ 再看对垒（通关）→ 再看病灶（病药）→ 再看格局 → 最后才是扶抑。** 越靠前越"紧急"，越靠后越"常规"。
>
> 最后一道关永远是用神有力性：**取出来的用神若虚浮无根，就要么等运补，要么换一个。** 写在报告里但不能兑现的用神，只是让结论看起来完整而已。

> **可复用的经验**：**四法不是互斥的，它们经常指向同一个答案。** 当你发现调候、通关、病药三条线都指向同一个五行时，取用就非常确定了。

| 用神 vs 喜神 | 用神是主角；喜神是生助用神者 | 喜神是帮用神的 |
| 忌神 vs 仇神 | 忌神克用神；仇神**生忌神**（间接伤害） | 仇神是给敌人送补给的 |
| 闲神 vs 无用 | 闲神是暂时中立，条件变化会转化 | 闲神不是永久中立 |
| 原局用神 vs 行运用神 | 原局管一辈子底色；行运管这十年策略 | 原局定底色，大运做调整 |
| 取用神 vs 补五行 | 取用是系统判断，不是缺什么补什么 | 补之前先看旺衰 |
