#### 10_1_3 六亲星的判断原则：星宫同看

```plain
星（十神）→ 看质量好坏
宫（地支）→ 看发生位置
星宫同看最为准确
```

> **实操心法**：星好比"这个人本身的能力与状态"，宫好比"他出现在你人生的哪个位置"。只看星，不知道应验在谁身上；只看宫，不知道这件事的性质。**星宫同参，才能落地。**

#### 10_1_4 流派差异与取舍（重要）

本知识库内部存在两套六亲口径，需要明确处理：

| 差异点 | 板块4_3 体系（本库主用） | 另一派口径 |
| --- | --- | --- |
| 女命父亲 | 偏财 | 正财 |
| 女命母亲 | 正印 | 偏印 |

> **为什么会有这个分歧？** 根源在于"六亲星是按'阴阳配对'推，还是按'角色对应'推"。
>
> 按阴阳配对推：偏财（与日主阴阳相同）为父 → 无论男女，父皆为偏财。
> 按角色对应推：男命以正财为妻，则女命以正财为父（同为"我克之异性"）→ 女命父 = 正财。
>
> 两派都能自圆其说，**分歧本身没有对错，只有"用不用得惯"。**

**四条处理原则**：

```plain
第1条 本知识库统一采用板块4_3 的体系
   （女命：父 = 偏财、母 = 正印）

第2条 自测与复盘时按主用体系作答，避免混用

第3条 实战中若两派结论冲突，以"星宫同看 + 实际反馈"为准

第4条 遇到他人用另一派口径时，理解其来源，不必强行争对错
```

> **最实用的一条**：**六亲判断的准确率，主要来自"星宫同看"，而不是来自选对哪一派。** 父亲看偏财还是正财，影响的是你从哪个十神切入；真正决定结论的，是这个星有没有力、宫位有没有被冲、与日主的关系如何。**口径之争的权重，远低于星宫分析。**

#### 10_1_5 落地实操：六亲分析四步

```plain
第1步：定六亲星（例：男命看父亲 → 偏财）
第2步：看星的强弱（有力？受克？空亡？）
第3步：看宫位（该星在哪个柱？宫位是否被冲？）
第4步：星宫合参，给出结论
```

**示例**：男命，偏财（父星）在年柱，但被比劫紧贴克之 → "父亲能力不错（星在年柱有气），但一生多受竞争与破财之扰（比劫夺财），或与命主关系较疏离（年柱被克）。"

> **可复用的经验**：遇到六亲断语与事实不符，先检查是不是**换了口径**，再检查是不是判断有误。这两件事的表现很像，但原因完全不同。

#### 10_1_9 星宫同参的四步细化

"星看质量、宫看位置"是原则，落到操作上是四步：

```plain
第1步 定星：这个六亲对应哪个十神（用本库口径，全程不换）
第2步 查星：有力吗？受克吗？空亡吗？为用还是为忌？
第3步 查宫：这个星落在哪一柱？该柱宫位有没有被冲、被刑？
第4步 合参：星与宫的结论一致则加强；不一致则分层表述
```

**星宫不一致时的表述方法**（最常见也最容易说错）：

| 情况 | 表述 |
| :---: | :--- |
| 星好、宫被冲 | "本人有能力，但与你的关系易有波折 / 聚少离多" |
| 星弱、宫稳 | "助力有限，但关系平稳、少冲突" |
| 星好、宫好 | "有能力且关系亲密，是重要助力" |
| 星弱、宫冲 | "助力有限，且关系疏离或易有变故" |

> **一句提醒**：**六亲判断的准确率主要来自"星宫同看"，而不是来自选对哪一派口径。** 把四步走完，比争论用偏财还是正财有用得多。

#### 10_2_6 案例小故事：日支坐忌神，未必是坏事

> 一位初学者看到"日支坐忌神"，立刻断："配偶给你带来压力，婚姻不顺。"
>
> 客户是个四十多岁的男士，听完笑着说："我老婆确实强势，家里大事小事她说了算。但我们结婚十八年了，没红过几次脸。"
>
> 细看命局：日支虽是忌神，但**被合住**（合可解冲、合能转化），而且配偶星（男命正财）为用神且有力。
>
> 也就是说——妻子性格强（忌神在宫的表现），但能力极强，是这个家庭的经济支柱（配偶星为用）。命主自己的原话是："吵归吵，但这个家离不开她。"
>
> 修正后的断语：**"配偶性格较强势，生活中可能有摩擦，但对方的能力与资源对你帮助很大。重点不在'顺不顺'，而在'你能不能接住这份强势'——建议你把决策权分工明确，别在每一件事上都争。"**
>
> 客户听完点头："这个说法我服。"
>
> **"吵归吵，但这个家离不开她"——这句话把案子的两层结构都说清楚了**。日支坐忌神，对应"配偶性格强势、生活中有摩擦"；配偶星（男命正财）为用且有力，对应"对方的能力与资源对家庭帮助很大"。两层并存，所以是"有摩擦但有助力"，而不是"婚姻不幸"。
>
> 初学者漏掉的还有第三条：日支虽为忌神，但**被合住**。合能转化、合可解冲——这是"忌神有没有被制化"的判断，也是 4_6 的组合思路在婚姻分析里的应用。
>
> 修正后的断语之所以让客户点头，是因为它落到了动作上：**"把决策权分工明确，别在每一件事上都争。"**
>
> **复盘拆解**：断婚姻按五问走——**配偶星是哪个？有力吗？为用为忌？配偶宫稳定吗（有无冲刑）？星与宫协调吗？** 五问里只要有一问被跳过，结论就可能整个反过来。尤其"日支坐忌神 ≠ 婚姻不幸"，是最高频的误判。

> **可复用的经验**：**日支坐忌神 ≠ 婚姻不幸。** 要看忌神有没有被制化，以及配偶星本身的喜忌。两个条件一结合，结论常常完全不同。

#### 10_2_9 婚姻断语的分寸

婚姻是最容易说伤人的领域。三条分寸纪律：

```plain
纪律一 · 不说"必离""克夫克妻"
   改用"摩擦点在哪""需要留意什么"
   例："日支逢冲，两人生活节奏差异较大" ≠ "你们会离婚"

纪律二 · 负面必须配动作
   ✗ "你官杀混杂，感情复杂。"
   ✓ "你在感情上选择面较宽，建议在确认关系前把边界说清楚，
      避免长期悬而不决。"

纪律三 · 不替对方做决定
   命理不负责回答"该不该离婚""该选哪一个"
   它只能说明：现在的状态是"卡住"还是"在推进"
```

**关于"克"的说明**：民间说的"克夫""克妻"，在命理里通常对应的是"配偶星受克"或"配偶宫逢冲"，含义是**关系中的压力与变数**，不涉及谁伤害谁。**遇到这类说法，先把它翻译成具体结构，再谈应对。**

### 10_3 子女运判断

> **本单元定位**：子女是全库六个分项里信息量最小、也最容易说错的一项。先把边界立住：**八字能看"子女缘分与数量倾向"，不能替代医学判断，也不该被用来推断性别。**

#### 10_3_1 判断要点（四看）

| 看什么 | 怎么看 | 含义 |
| :---: | :---: | :--- |
| **一看子女星** | 男命：官杀为子女星；女命：食伤为子女星 | 星的强弱主缘分深浅与助力 |
| **二看子女宫** | 时柱为子女宫 | 宫位被冲、被刑 → 与子女的聚散波折 |
| **三看喜忌** | 子女星为用神 → 子女有成、助力明显；为忌 → 操心较多 | 与旺衰无关，只看喜忌 |
| **四看时柱状态** | 时柱干支的生克、空亡、墓库 | 空亡主缘分淡或来得晚；入库主晚得 |

#### 10_3_2 三条纪律（务必守住）

```plain
第1条 不推断胎儿性别
   命理不用于性别判断，也不应被用来指导生育选择

第2条 数量只说倾向，不说定数
   现代环境（避孕、生育政策、医疗）已大幅改变数量
   只能说"缘分深浅、来得早晚"，不能说"你会有几个"

第3条 子女缘分淡 ≠ 不好
   缘分淡可能表现为来得晚、聚少离多、或关系偏松散
   不必然是坏事，也不构成对任何人的人生评价
```

#### 10_3_3 常见误读纠正

| 误读 | 纠正 |
| :---: | :--- |
| "子女星弱 = 没有子女" | 弱只是缘分浅或助力有限，也可能应于"来得晚" |
| "时柱逢冲 = 与子女无缘" | 冲主变动与聚散，可能是异地、留学、晚聚 |
| "食伤旺 = 子女多" | 食伤旺主才华与输出能力强，与数量无直接对应 |

#### 10_3_4 落地实操：子女运三问

```plain
第1问 子女星是哪个、有力吗、为用为忌？
第2问 子女宫（时柱）稳不稳？有没有被冲、被刑、落空亡？
第3问 星与宫的结论一致吗？
   一致 → 加强表述；不一致 → 分层表述（星看能力，宫看关系）
```

#### 10_3_5 案例小故事："我命里是不是没有孩子"

> 一位女士时柱落空亡，又在别处看到"食伤为子女星"的说法，发现自己命局食伤也不旺，越查越慌，来咨询时第一句话就是："我是不是命里没有孩子？"
>
> 排盘师没有直接回答，而是先问了三个问题：结婚几年、有没有计划、家里长辈催得急不急。
>
> 听完才说：**"你这个问题，八字回答不了。八字能说的是缘分深浅和来得早晚，说不了'有没有'。"**
>
> 然后他逐项解释：
>
> **第一，食伤不旺不等于无子女。** 食伤主才华与输出，也主子女缘分——不旺只说明缘分来得偏晚或与子女的互动偏淡，推不出"没有"。
>
> **第二，时柱空亡是"打折"不是"归零"。** 空亡的含义是"这一柱的力量打折、待激活"，不是"这一柱不存在"。
>
> **第三，也是最要紧的一条**——她当时三十岁，生育相关的判断牵涉到医学、时机、个人选择，命理不该在这里下结论。
>
> 排盘师最后给的建议很实在：**"如果你在计划，去做个体检，比看盘有用。命理能帮你看的是'你和孩子的相处模式'——比如你将来可能和孩子聚少离多，或者教育观念上容易起冲突，这些才是该提前想的。"**
>
> 她后来有了孩子，也确实遇到"聚少离多"的问题——因为工作原因，孩子有几年放在老家。她说那次咨询最有用的是最后那句，让她提前做了安排。
>
> **复盘拆解**：这个案子展示了子女这一项最重要的能力——**知道什么不该说**。
>
> 三个技术动作值得记：**一是把"有没有"翻译成"深浅早晚"**；**二是把"空亡"翻译成"打折待激活"**；**三是把话题从"能不能有"转到"怎么相处"**——后者才是命理真正能帮上忙的地方，也是对方真正需要的。
>
> **可复用的经验**：**子女这一项，说倾向、不说定数；讲缘分、不论性别。** 遇到涉及生育的焦虑，先承认边界，再把话题引到可操作的那一面。分寸比准确更重要。

#### 10_3_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 子女星：男看官杀、女看食伤 | 一律用食伤论子女 | 男命官杀才是子女星 |
| 时柱 = 子女宫 | 用日柱看子女 | 时柱逢冲主聚散 |
| 星看能力，宫看关系 | 星弱就断"无缘" | 星弱宫稳 = 助力小但关系平稳 |

- **验证 1**：说出男女命各自的子女星，以及子女宫是哪一柱。
- **验证 2**：解释为什么"子女星弱"不能直接断"无子女"。
- **验证 3**：把一句"你没有子女命"改写成分寸得体的说法。

#### 10_4_5 案例小故事：财星为忌的人该怎么赚钱

> 一位客户的命局里，财星是忌神。按"财星为忌 = 求财辛苦、易破财"，似乎财运很差。他很焦虑，问："我是不是这辈子都不该想着赚钱？"
>
> 但细看：此人是食神格，食伤旺而为用，且有"食神生财"的链条。
>
> 问题出在"财星为忌"这个判断的含义上——它意味着**不宜以"求财"为直接目标**。越盯着钱，越累；钱来了，也留不住。
>
> 真正适合他的路径是"以技艺为本"（食伤为用），**钱是副产品**，不是目标本身。
>
> 给的建议很具体：不做纯商业经营（那会让他整天盯着数字），做技术型、作品型的独立工作；报价时不要反复纠结，定好标准就执行。
>
> 几年后他成了独立设计师，收入远超从前，而且状态轻松。他自己的总结是：**"以前我每天算账，越算越穷；现在我只管把东西做好，钱自己就来了。"**
>
> **他问的那句"我是不是这辈子都不该想着赚钱"，本身就是误解的产物**。财星为忌的真实含义是"不宜以赚钱为直接目标"，不是"没钱"，更不是"不该赚钱"。
>
> 关键在食神格那一条：食伤旺而为用，且有"食神生财"的链条。钱在他的结构里是**副产品**，不是目标本身——越盯着钱越累，钱来了也留不住。
>
> 所以给的建议是换路径而不是换力度：**不做纯商业经营**（那会让他整天盯着数字），做技术型、作品型的独立工作；报价定好标准就执行，不反复纠结。几年后他成了独立设计师，收入远超从前，状态还轻松了。
>
> **复盘拆解**：财星为忌的处理方式是**绕开"财"这一环，去补能生财的那一环**（食伤或官杀）。顺序是——**一查财星为忌的真实含义**（不宜直追，不是没钱）、**二找能生财的环节**、**三把力气放在那一环上。**

> **可复用的经验**：**财星为忌不是"没钱"，是"不能直接追钱"。** 找到那个能生出财的环节（食伤、官杀），把力气花在那儿。

| 财星为忌 ≠ 没钱，是"不宜直追" | 财星为忌就断贫困 | 食伤生财为用 → 靠技艺变现 |

#### 10_4_8 事业建议的落地三要素

"你适合火相关的行业"是一句废话——它没落到任何一个可执行动作上。完整的建议必须含三个要素：

```plain
要素一 · 方向：用神五行对应的行业大类（见板块1_3）
要素二 · 角色：格局决定的位置（管理？创业？技术？艺术？）
要素三 · 时机：哪十年适合全力冲刺（大运发力期）
```

**对照示例**：

| 只给方向 | 三要素齐全 |
| :---: | :--- |
| "你适合金相关的行业。" | "用神为金，方向在金融、法律、机械一带（方向）；你是正官格，适合在规则明确的体系内做管理岗（角色）；当前这步运官星得力，是全力冲刺的十年（时机）。" |

**一条检验标准**：**对方听完知不知道明天该做什么。** 不知道，说明建议只给到了第一层，还得往下落两层。

#### 10_4_9 学业学历判断

> **本单元定位**：学业是现代咨询里问得最多的一项，但八字里并没有一个专门叫"学历"的十神。它是**几个维度叠加出来的结果**，不能单点直断。

##### 10_4_9_1 四个判断维度

| 维度 | 看什么 | 有利信号 |
| :---: | :---: | :--- |
| **第1条 印星** | 正印、偏印的状态 | 印星为用、有根、不被财坏 → 坐得住、学得进 |
| **第2条 食伤** | 食神、伤官的状态 | 食伤有力 → 理解力、表达力好（尤其伤官配印） |
| **第3条 官杀** | 正官、七杀的状态 | 官杀为用 → 自律、能承压，应试型选手 |
| **第4条 文昌 / 学堂** | 神煞（见板块8_1） | 文昌为用且非空亡 → 考试运加分 |

##### 10_4_9_2 四种典型结构

```plain
印星为用 + 官杀有制  →  传统意义上的"读书命"，正统学历路径顺
伤官配印             →  有才气且有根基，适合专业深造、研究生路径
食伤旺而印弱         →  聪明但坐不住，适合实践型、技能型学习
印星为忌或财星坏印   →  读书期间易分心，宜走"边做边学"的路径
```

> **"财星坏印"要单独留意**：财星紧贴克印星，主"被外务分心"——常见于读书期间就想着赚钱、或家境变故影响学业。遇到这个结构，建议往往是"先定下心，别同时追两件事"。

##### 10_4_9_3 三条纪律

```plain
第1条 学历高低受时代与环境极大影响
   同一命局，在不同年代、不同教育机会下，学历可以差很多
   所以只说"适合哪类学习路径"，不说"能读到什么程度"

第2条 考试年份比"有没有读书命"更实用
   与其判断学历高低，不如标出考试运好的年份
   （印星 / 食伤得力之年、文昌填实之年，见板块8_1）

第3条 不要给"你考不上"这类结论
   命理给的是倾向与时机，不是判决
   负面一律改写成路径建议（"你更适合实践型路径"）
```

##### 10_4_9_4 落地实操：学业判断三步

```plain
第1步 查印星：有力吗？为用为忌？被财坏了吗？
       → 印星决定"坐不坐得住"

第2步 查食伤与官杀：谁更有力？
       食伤有力 → 理解力强，适合钻研型
       官杀有力 → 自律强，适合应试型
       → 这一步决定"适合哪类学习路径"

第3步 查文昌等考试神煞，并标出考试运好的年份
       → 这一步给出"什么时候发力"
```

##### 10_4_9_5 案例小故事：被误判成"不是读书的料"

> 一位母亲带着高二的儿子来问："孩子成绩一直在中游，是不是不是读书的料？要不要考虑走职业教育的路？"
>
> 排盘师看了盘，先说了三个字："坐不住。"
>
> 这个命局食伤很旺、印星偏弱——食伤主聪明、主表达、主想得多，印星主静、主坐得住。两者一比，问题不在智商，而在**持续专注的能力**。
>
> 排盘师接着问了一句："他是不是作业能写完，但从不复习？上课听得懂，考试就掉链子？"
>
> 母亲愣了一下："你怎么知道？"
>
> "食伤旺的人靠理解力吃饭，一听就懂，所以不爱重复。但考试考的就是重复。"
>
> 但这个孩子不能被简单归为"不是读书的料"。排盘师指出另外两点：**一是他官杀为用且有力**，说明他一旦被放到有纪律的环境里，是能承压的；**二是他二十八岁后进入印星得力的运**，那才是真正适合深造的窗口。
>
> 给出的建议因此是分两段的：**眼下靠制度补短板**（固定作息、强制复习、报有督学机制的班），**长期把深造排在印运那几年**，而不是现在硬拼。
>
> 后来孩子考上了本科，工作四年后又回去读了研——正好落在印星得力的那步运里。
>
> **复盘拆解**：这个案子的关键，在于把"不是读书的料"这个笼统判断拆成了三个可操作的信息：**短板在哪（坐不住）、优势在哪（能承压）、什么时候发力（印运）**。
>
> 笼统的"能读 / 不能读"给不出任何动作。拆解之后，母亲知道眼下该做什么，孩子也不必背上一个"我不是读书的料"的标签。
>
> **可复用的经验**：**看学业，不要找"学历星"，要找印星、食伤、官杀三者的组合。** 并且优先给出"适合什么路径 + 哪几年发力"，而不是"能读到什么程度"——后者既不准，也没用。

##### 10_4_9_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 印星主坐得住，食伤主理解力 | 只看印星，忽略食伤 | 食伤旺印弱 = 聪明但坐不住 |
| 官杀为用 = 应试型选手 | 以为官杀只主压力 | 有纪律环境下反而出成绩 |
| 考试运看大运与文昌填实 | 只看原局定终身 | 印运深造远胜于早年硬拼 |

- **验证 1**：说出判断学业的四个维度。
- **验证 2**：给一个"食伤旺、印星弱"的命局写出两条具体建议。
- **验证 3**：解释为什么说"考试年份比学历判断更实用"。

### 10_5 健康疾病判断

#### 10_5_1 五行与脏腑对应

| 五行 | 脏（阴） | 腑（阳） | 身体部位 |
| --- | --- | --- | --- |
| 木 | 肝 | 胆 | 四肢、筋、眼 |
| 火 | 心 | 小肠 | 血液、舌、面 |
| 土 | 脾 | 胃 | 肌肉、唇、腹 |
| 金 | 肺 | 大肠 | 皮毛、鼻、喉 |
| 水 | 肾 | 膀胱 | 骨骼、耳、腰 |

> 完整的五行类象体系见板块1_3。

#### 10_5_2 健康信号（六条）

```plain
第1条 某五行过旺 → 该五行对应的脏腑功能亢进 / 炎症
第2条 某五行过弱 → 该五行对应的脏腑功能不足 / 虚弱
第3条 冲克严重   → 受冲的五行部位容易受伤 / 手术
第4条 羊刃逢冲   → 血光之灾（外伤 / 手术）
第5条 水火不平衡 → 心血管 / 血液循环问题
第6条 金木交战   → 肝胆 / 呼吸系统问题
```

#### 10_5_3 两条不可逾越的底线

```plain
第1条 八字看健康只能作为参考，不能替代医学诊断
第2条 更多是提示先天体质倾向和需要注意的方向
```

**表达纪律**：

```plain
✗ "你肾有问题。"
✓ "命局水偏弱，先天肾气与泌尿系统相对敏感，
   建议秋冬注意保暖、规律作息，定期检查。"
```

#### 10_5_4 落地实操：健康分析三步

```plain
第1步：看五行是否严重偏枯（某行过旺或过弱）
第2步：看有无严重冲克（尤其是日支、月支被冲）
第3步：对照脏腑表，给出 1~2 条"养生提醒"
       ——不是"疾病诊断"
```

#### 10_5_5 案例小故事：一句"你有肝病"的代价

> 一位初学者看到命局木过旺，直接对客户说："你肝不好，要注意肝病。"
>
> 客户当场紧张起来，第二天就去医院做了一整套检查。结果一切正常。但人被吓得不轻，此后对命理产生了明显的反感，还跟朋友说"那东西不能随便听"。
>
> 复盘时，老师指出问题所在：木过旺确实提示"肝的负担偏重"，但**体质倾向 ≠ 疾病**。
>
> 正确的做法是给生活方式建议，而不是给疾病标签。
>
> 老师示范了修正后的表述：
>
> **"你命局木气偏旺，肝主疏泄，容易在压力大、情绪压抑时出状况。建议保持规律作息、少熬夜、适度运动，情绪上避免长期憋闷。体检按常规做即可。"**
>
> 客户听完明显放松了，还追问了几条具体的生活建议。
>
> **客户第二天的那套检查，是这个案子真正的代价**。检查费、请假、几天的焦虑——而结果是一切正常。更长远的代价是：此后他对命理产生了明显反感，还跟朋友说"那东西不能随便听"。**一句狠话，丢掉的不只是一位客户。**
>
> 老师的修正表述里有三个关键技术动作：一是**把"有问题"改成"相对敏感"**（程度降下来）；二是**补上触发条件**（"在压力大、情绪压抑时"）；三是**落到生活方式**（作息、运动、情绪，而不是疾病标签）。
>
> 客户听完明显放松，还追问了几条具体的生活建议——**同样是"说中了"，一种说法让人想逃，一种让人想听。**
>
> **复盘拆解**：健康类断语的三步改写——**第一步降程度**（有病 → 相对敏感）、**第二步加条件**（在什么情况下容易出状况）、**第三步给动作**（作息、饮食、体检频率）。**在健康这件事上，分寸感比准确性更重要。**

> **可复用的经验**：**分寸感是命理从业者最重要的职业素养之一。** 尤其在健康这件事上，宁可说得保守，也不要用一句狠话换取"算得准"的名声。

#### 10_5_6 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 给"养生提醒"，不给"疾病诊断" | 直接说某脏腑有病 | 木旺 → 提示作息与情绪，不说"肝病" |
| 偏枯 + 冲克才需要重点提醒 | 稍有偏旺就大谈健康 | 需综合过旺 / 过弱与冲克判断 |

#### 10_5_7 实用验证

- **验证 1**：默写出五行与脏腑、身体部位的对应。
- **验证 2**：说出六条健康信号。
- **验证 3**：把一个"恐吓式"健康断语改写成"建设性"表述。

#### 10_5_8 五行偏枯的判断标准

不是所有"偏旺偏弱"都值得提醒。三条标准决定要不要说：

```plain
标准一 · 偏到什么程度：只是略偏 → 不必提；明显偏枯 → 可提
标准二 · 有没有叠加信号：偏枯 + 冲克 / 自刑 → 值得提
标准三 · 是用神还是忌神：忌神偏旺 → 值得提；用神偏旺 → 反是好事
```

**三条都满足才说，且必须配养生建议。** 常见对应关系：

| 五行 | 相对敏感的方向 | 日常建议 |
| :---: | :---: | :--- |
| 木偏旺 | 肝、胆、情绪疏泄 | 少熬夜、适度运动、避免长期憋闷 |
| 火偏旺 | 心、血液循环、睡眠 | 避免长期高压、规律作息 |
| 土偏弱 | 脾、胃、消化 | 饮食规律、少生冷 |
| 金偏旺 | 肺、呼吸道、皮肤 | 秋冬保湿、少辛辣 |
| 水偏弱 | 肾、泌尿系统、腰 | 秋冬保暖、避免过劳 |

> **底线重申**：**八字只能提示先天体质倾向，不能替代医学诊断。** 说的时候一律用"相对敏感""建议""按常规体检"，不用"你有病"。

#### 10_6_5 案例小故事：被"食伤旺"耽误的会计

> 某命局食伤极旺——按板块10_6 的天赋对照，这是标准的"艺术 / 表达型"配置：食伤主才华、表达、创作、输出。
>
> **但此人做了十年会计。**
>
> 不是他自己选的。家里觉得会计稳定、体面、越老越吃香，他就听了。十年里他每天对着数字，工作不出错，收入也还行，但人越来越沉默。同事对他的印象是"话很少，从不主动发言"。发展到后来，他去看了心理医生。
>
> 医生问他的第一句话是："你平时有没有什么想做但没做的事？"他答不上来。
>
> **排盘师给的建议不是"辞职去搞艺术"。** 这一点很关键——他的命局里财星也在，会计这份工作能养活他，一拍脑袋辞职，等于把自己最稳定的那一块也扔了。
>
> 建议是这样的两条：
>
> **第一，保留会计作为"稳定现金流"。** 不辞职，不折腾。
>
> **第二，必须给食伤找出口。** 食伤旺的人如果长期不输出，那股能量不会消失，会转成内耗——表现为提不起劲、情绪低落、说不清哪里不对。出口不拘形式：写作、教学、演讲，什么都行，重点是"开始往外给"。
>
> 他选了一个很小众的切入点：**在业余时间写财税科普。** 理由很实际——他懂财税（专业优势），又需要"说"（食伤出口），两者正好叠在一起。
>
> 他自己也没想到，那些把专业内容讲得通俗易懂的文章很受欢迎。一年后他成了小有名气的博主；再过一年，干脆转型做财税培训。
>
> 收入没降，状态却完全不一样了。他的总结很精准：**"我做的还是同一件事，只是开始'说'了。"**
>
> **复盘时排盘师点了三层：**
>
> **第一层：天赋被憋住的表现不是"没本事"，是"提不起劲"。** 很多人以为天赋没发挥只是可惜，其实长期被憋住会转化成具体的情绪问题。所以当一个人长期低落又说不出原因时，值得看看他最旺的那个十神是不是没有出口。
>
> **第二层：出口不必是职业。** 换工作是成本最高的方案，而且风险大。更好的做法常常是"保留主业 + 给天赋开一个副业通道"，等通道跑通了再说。
>
> **第三层：出口最好与已有资源叠加。** 他没有去学画画（那要从零开始），而是写财税科普（专业已经有了）。**"最强天赋 × 已有资源"的交集，才是成本最低的出口。**
>
> **复盘拆解**：天赋被憋住的表现不是"没本事"，而是**"提不起劲"**。这是很重要的一条识别线索——很多人以为天赋没发挥只是可惜，其实长期被憋住会转化成具体的情绪问题。
>
> 给出路时有两个原则：**一是出口不必是职业**（换工作成本最高，风险最大），更好的做法常常是"保留主业 + 给天赋开一个副业通道"，跑通了再说；**二是出口最好与已有资源叠加**（他写财税科普而不是去学画画，因为专业已经有了）。
>
> 一句话概括：**"最强天赋 × 已有资源"的交集，才是成本最低的出口。**

> **可复用的经验**：**天赋不是"要不要"的问题，是"有没有出口"的问题。** 当一个人长期抑郁、提不起劲，先看看他最旺的那个十神是不是被憋住了；给出路时优先找"天赋 × 已有资源"的交集，而不是劝人从头开始。

### 10_7 综合命例分析

#### 10_7_1 完整命例解读模板（七步）

> **边界说明**：本模板是**报告写作**的七步（用于产出一份可交付的文档）；总纲「实战论命七步法」给出的是**快速看盘**的七步法（用于自己核对思路）。两者角度不同，前者要求写出推导过程，后者只求快速定性。
```plain
【基本信息】
  性别、出生时间（公历 / 农历）、出生地点（含经度）

【排盘】
  年柱、月柱、日柱（日主★）、时柱

【第一步：日主旺衰】
  得令 / 得地 / 得生 / 得助 → 旺衰结论

【第二步：定格局】
  月令定格、格局成败

【第三步：取用神】
  扶抑 / 调候 / 通关 / 病药 → 最终用神

【第四步：看神煞】
  主要神煞及其位置

【第五步：大运分析】
  每步大运的吉凶

【第六步：六亲】
  父母 / 配偶 / 子女的信息

【第七步：综合论断】
  · 性格特征
  · 事业方向
  · 财运概况
  · 婚姻感情
  · 健康注意
  · 各大运流年重点
```

#### 10_7_2 落地实操：报告写作五条纪律

```plain
第1步 每一步都要写"推导过程"，不能只给结论

第2步 断语要分层次：确定的 / 倾向的 / 可能的

第3步 涉及负面信息，必须配"可操作建议"

第4步 健康类只给养生提醒，不给疾病诊断

第5步 结尾要有"发力期提示"（哪几年适合主动出击）
```

#### 10_7_3 案例小故事：从 200 字到 2000 字

> 一位初学者交上来的第一份报告只有 200 字：
>
> "日主甲木，身强，用神金，适合做金融，中年发达。"
>
> 老师没改，只问了七个问题，让他自己回去补：
>
> + 身强到什么程度？依据是什么？（旺衰推导）
> + 什么格局？成还是破？（格局分析）
> + 用神为什么是金？有没有考虑调候和通关？（取用理由）
> + 金的哪个行业？什么岗位？（类象落地）
> + 中年是哪几年？依据什么大运？（时间定位）
> + 有什么风险点？（忌神、冲克、交脱运）
> + 具体该做什么？（可操作建议）
>
> 他回去改了三遍，最后交上来 2000 多字。改完之后他自己说了一句话："我发现前面那 200 字里，其实只有一句是能用上的。"
>
> **老师问的那七个问题，其实是一张检查清单**：身强到什么程度（依据）、什么格局成或破、用神为什么是它（有没有考虑调候通关）、金的哪个行业什么岗位（类象落地）、中年是哪几年（大运依据）、有什么风险点（忌神、冲克、交脱运）、具体该做什么（可操作建议）。
>
> 七个问题对应七个板块：旺衰、格局、用神、类象、大运、风险、建议。**一份报告的厚度，本质上就是这七个问题回答得有多细。**
>
> 他改了三遍，交上来 2000 多字，自己说了句："我发现前面那 200 字里，其实只有一句是能用上的。"
>
> **复盘拆解**：报告五条纪律里最容易违反的是第一条"每一步都要写推导过程"。**结论谁都会给，推导过程才是专业与业余的分界线**——因为只有写了依据，对方才能检验你，你自己也才能在半年后复查当时的判断是否成立。

> **可复用的经验**：**命理分析的价值密度，取决于推导的颗粒度。** 结论谁都会给，推导过程才是专业与业余的分界线。

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 报告要写推导过程，不只给结论 | 只给结论，无法验证 | "身强"必须附四维依据 |
| 断语分层：确定 / 倾向 / 可能 | 全部说成"必然" | 用"更可能""倾向于"等留有余地 |

#### 10_7_6 断语写作的三档措辞

同一条判断，措辞不同，效果天差地别。全库统一使用三档措辞：

| 档位 | 适用条件 | 措辞示例 |
| :---: | :---: | :--- |
| **确定** | 原局明现 + 大运支持 + 流年触发 | "这两年确实是你发力的窗口期，可以主动推进" |
| **倾向** | 原局有此结构，但时机未到 | "你有这方面的潜质，但要等进入某运才会真正显现" |
| **可能** | 单一信号，需其他条件配合 | "如果再有某某配合，可能会出现某类情况" |

**三档之外，还有三条硬性纪律**：

```plain
纪律一 · 负面信息必须配解法
   ✗ "你劫财旺，冲动鲁莽又挥霍，容易破财。"
   ✓ "你的行动力很强，但大额决策前最好给自己设 24 小时冷静期，
      重要合作一律走书面合同。"

纪律二 · 健康类只给提醒，不给诊断
   ✗ "你肝不好。"
   ✓ "命局木气偏旺，容易在压力大、情绪压抑时出状况。
      建议规律作息、少熬夜、适度运动，体检按常规做即可。"

纪律三 · 结尾必须有发力期
   任何一份报告的最后，都要回答"哪几年适合主动出击"。
   没有发力期的报告，等于没给 actionable 的结论。
```

**一个自检问题**：

```plain
写完一段断语，问自己一句：
"对方听完，明天知道该做什么吗？"
不知道 → 这段断语需要重写
```

```plain
└────────────────────────────────────────────────┘
```

#### 10_8_5 案例小故事：不是"克"就不能在一起

> 一对情侣来合婚。男方的母亲听说"女方日支冲男方日支"，坚决反对，原话是"相冲不能结婚，结了也要散"。
>
> 排盘师把两人的盘都排在桌上，逐项看：
>
> **日支确实相冲**——这一点没说错。冲主性格与生活习惯的摩擦，两人在一起确实容易在小事上起争执。
>
> 但另外三项：**五行互补度很高**（男方缺的，女方恰好有；反之亦然）；**用神相生**（不互为忌神）；**大运同步度极佳**（未来十年的上升段高度重合）。
>
> 这是个"有摩擦但能互补、运势又同步"的组合。
>
> 排盘师给出的建议不是"不能结"，而是两条：
>
> 一是**大事决策前充分沟通**——冲主急变，最忌在情绪上头时做决定；
> 二是**利用好运同步期一起做重要规划**——两人运势同步，意味着一起发力的效率远高于单打独斗。
>
> 三年后两人反馈：确实常吵架，但也确实一起把事业做起来了。
>
> **男方母亲那句"相冲不能结婚"，是把单一信号当成了一票否决**。日支相冲确实主性格与生活习惯的摩擦，但它只是五项里的第四项。
>
> 排盘师逐项看完：日支相冲（有摩擦）、五行互补度很高（互相补得上）、用神相生（不互为忌神）、大运同步度极佳（未来十年上升段高度重合）。**五项里有三项是明确的正分。**
>
> 给出的两条建议因此不是"能不能结"，而是"怎么相处"：一是**大事决策前充分沟通**（冲主急变，最忌情绪上头做决定），二是**利用好运同步期一起做重要规划**（运势同步，一起发力效率远高于单打独斗）。
>
> **复盘拆解**：**合婚的目的不是判"能不能在一起"，而是告诉你们"该怎么相处"。** 任何单一维度都不构成一票否决——**相冲不等于不合，它只是描述了相处的难点。**

> **可复用的经验**：**合婚的目的不是"判能不能在一起"，而是"告诉你们该怎么相处"。** 相冲不等于不合，它只是描述了相处的难点。

#### 10_8_8 择吉的三层校验

选日子不能只看黄历，三层都要过：

```plain
第一层 · 通用黄历：避开明显不宜之日（基础过滤）
第二层 · 个人用神：所选日子的干支是否为本人用神 / 喜神
        （黄历上的"黄道吉日"，若干支恰是你的忌神，仍需谨慎）
第三层 · 事项匹配：不同事项看不同的神
   结婚 → 看日支与双方日柱的关系、有无红鸾天喜
   开业 → 看财星与官星是否得力
   签约 → 看有无冲破、空亡
   搬迁 → 看驿马与日支冲合
```

**两条提醒**：

| 提醒 | 说明 |
| :---: | :--- |
| **通用 ≠ 个人** | 黄历是通用口径，个人择吉必须结合自己的八字用神 |
| **择吉是加分项，不是决定项** | 好日子锦上添花，救不了一个时机未到的计划；先确认"该不该做"，再挑"哪天做" |

> **一句话**：**择吉解决的是"在哪一天发力更顺"，解决不了"这件事该不该做"。** 顺序不能颠倒。

#### 10_9_4 特殊时辰（子时问题）

```plain
子时整体为 23:00 ~ 次日 1:00，以 0:00 为界分两段：
  夜子时（晚子时）：23:00 ~ 0:00（零点前）
  早子时（正子时）：0:00 ~ 1:00（零点后）

日柱分界线为 23:00，过了 23:00 即归属次日日柱
（这是《渊海子平》以来的主流观点）

主流派：23:00 后日柱、时柱均按次日推算，不单独区分早晚子时
少数派：认为夜子时日柱用当日、时柱用次日，或日均用当日
        —— 此说缺乏古籍支撑，未成共识
```

#### 10_9_5 落地实操：疑难问题的应答三原则

```plain
原则一：先确认信息
   出生时间是否精确？是否做过真太阳时校正？是否在交节当日？

原则二：说明流派差异
   遇到有争议的问题（如子时、六亲口径），如实说明存在不同做法

原则三：给出主用方案 + 备选方案
   "按主流做法是这样；若按另一派，则会是那样。
    实践中建议以____为准，你也可以用实际经历验证。"
```

#### 10_9_6 案例小故事：23:30 出生的难题

> 一位求测者出生在 23:30，正好卡在子时的分界线上。
>
> 按主流派（23:00 为界），日柱、时柱都按次日算；
> 按少数派（0:00 为界，夜子时日柱用当日），日柱算当日、时柱算次日。
>
> 两种排法得出的命局差异不小——一种是七杀格，一种是正官格。两种格局描述的性格与事业走向完全不同。
>
> 排盘师没有急着下结论，而是做了一件很实在的事：**两套都排出来，然后跟命主一起核对过去的重大经历。**
>
> 他问了几个时间节点：升学在哪一年、第一份工作什么时候、有没有过比较大的转折。
>
> 一项项对下来，主流派的排法与命主的经历高度吻合——尤其是几个关键年份的应事，几乎一一对应。
>
> 排盘师说："理论有争议的时候，就用事实校验。这是最可靠的做法。"
>
> **排盘师做的那件事，是处理流派分歧的标准动作**：两套都排出来，然后跟命主一起核对过去的重大经历——升学在哪一年、第一份工作什么时候、有没有过比较大的转折。
>
> 一项项对下来，主流派的排法与命主的经历高度吻合，尤其是几个关键年份的应事几乎一一对应。
>
> 这个做法的价值在于：它把"谁说得对"从理论之争变成了**事实验证**。而且两套都排，本身就是诚实的表现——**强行给唯一答案，才是真正不专业的做法。**
>
> **复盘拆解**：遇到流派分歧，按三原则应答——**原则一先确认信息**（出生时间是否精确、有没有做真太阳时校正、是否在交节当日），**原则二如实说明存在不同做法**，**原则三给出主用方案 + 备选方案，并用实际经历校验。**

> **可复用的经验**：**遇到流派分歧，不要强行给唯一答案。** 排两套，用实际经历去验证——既专业，也诚实。

#### 10_11_1 疑难问题的信息采集清单

疑难场景之所以难，八成是因为信息不全。接手任何疑难盘之前，先把这张清单问完：

```plain
□ 出生公历（阳历）年月日 —— 确认不是农历
□ 出生时间精确到分 —— 只说"早上""傍晚"不够
□ 出生地（省 / 市）—— 需查经度做真太阳时校正
□ 是否夏令时 —— 历史年份需单独核对
□ 性别 —— 决定大运顺逆
□ 是否在交节当日 —— 是则需精确到交节时刻
□ 时间来源是出生证明还是家人口述 —— 后者需标注"存疑"
□ 双胞胎：性别是否相同、排行第几、出生间隔几分钟
□ 海外出生：当地经度与出生时区（同样适用真太阳时原则）
```

**信息存疑时的处理**：

```plain
第1条 不要硬排一个盘就下结论
第2条 把两种可能都排出来，用已发生的重大经历校验
第3条 在结论里注明"基于 XX 时间，若时间有偏差则结论需调整"
```

> **一条职业素养**：**信息不全时如实说明，比给出一个看似确定的答案更专业。**
