## 板块6 · 格局论命

> **本板块定位**：八字分析的第二道分水岭。格局决定命局的"层次与框架"，用神决定"吉凶调节"。两者不可偏废——**格局看层次，用神看吉凶**。
> **通关产出**：一份"定格五步法"作业卡 + 15 个命例的格局判定 + 一张特殊格局识别图。
> **建议用时**：5~6 周（6_1~6_2 大量练习；6_3~6_6 进阶；6_7 了解即可；6_8~6_9 收口）
> **边界说明**：从格的**判定条件**见板块5_6，本板块 6_4 只讲"从格一旦成立如何论命"；天干合化的**基本原理**见板块2_4，本板块 6_5 只讲化气格的成立条件与论法；救格的**系统病药理论**见板块7_4。

**为什么建禄月刃（6_3）夹在正格和变格之间？** 因为它是一个"过渡形态"——日主得令得地、身已经很旺，但月令本气就是日主自己，没有明确的格局用神。它既不是标准的正格，也还没到从格那种极端，正好承上启下。

**为什么 6_4 从格只讲"怎么论命"而不讲"怎么判定"？** 因为判定条件（五问）在板块5_6 已经讲透了。这里直接接着讲"既然成立了，那该怎么断"——**如果跳过板块5_6 直接看这一节，容易把假从当成真从，结论会全错。**

一句话串起来：**先学会定格（6_1），判断成破（6_2），处理特殊月令（6_3），再学两种极端形态（6_4~6_5），最后综合评断层次（6_9）。**

#### 6_0_1 从格五问的逐条解释

从格五问（见 5_6_2）看着清楚，实战中每一问都有具体的判定标准：

| 问 | 判定标准 | 常见误判 |
| :---: | :---: | :--- |
| **1. 完全失令？** | 月令本气不是日主同类，也不生日主 | 把"月令有余气根"当成得令 |
| **2. 地支毫无根气？** | 四支藏干中找**不到**日主五行；若只有余气根且远隔，算"极弱余气" | 见到一点点余气就判"有根不从" |
| **3. 天干无比劫？** | 无比劫，或比劫被合去 / 克去而失效 | 只看到比劫被合，没确认是否真失效 |
| **4. 天干无印星？** | 无印星，或印星被合去 / 克去而失效 | 印星虚浮无力却仍算"有助" |
| **5. 全局气势统一？** | 绝大多数字同属一行或同一趋势 | 只有两个字成势就判"气势统一" |

**三条安全边界**：

```plain
第1条 五问全"是" → 真从格，顺势取用
第2条 四问"是"   → 假从格，按极弱论，并标注还原风险运
第3条 三问及以下 → 不从，退回正格身弱论
宁可判保守，不可判激进——从格判错，所有断语全盘皆反。
```

### 6_1 八格基础（正格）

#### 6_1_1 八格总表（以月令本气透出定格）

| 格名 | 判定 | 核心 | 特点 |
| --- | --- | --- | --- |
| 正官格 | 月令透出正官 | 以正官为提纲 | 贵气、正统、有规矩 |
| 七杀格 | 月令透出七杀 | 以七杀为提纲 | 威严、魄力、有危机感 |
| 正印格 | 月令透出正印 | 以正印为提纲 | 学识、涵养、有靠山 |
| 偏印格 | 月令透出偏印 | 以偏印为提纲 | 独特、偏门、有领悟力 |
| 正财格 | 月令透出正财 | 以正财为提纲 | 务实、稳健、重感情 |
| 偏财格 | 月令透出偏财 | 以偏财为提纲 | 活泼、慷慨、善经营 |
| 食神格 | 月令透出食神 | 以食神为提纲 | 温和、有福、有才艺 |
| 伤官格 | 月令透出伤官 | 以伤官为提纲 | 聪明、叛逆、有创造力 |

#### 6_1_2 定格五步法（核心实操）

```plain
第1步：看月令（月支）本气是什么
第2步：本气在天干是否"透出"？（透 = 出现在年干 / 月干 / 时干）
第3步：透出了 → 以透出之物定格
第4步：本气不透 → 看月支中气 / 余气是否透
第5步：都不透 → "不成格"，取他法论命
              （转特殊格局检查，或看全局最旺之势）
```

#### 6_1_3 关键提醒：格名取决于十神关系

> **格名的确定，取决于该透干相对于日主的十神关系，而不取决于这个字本身。**

**示例**（月令寅，本气甲木，天干透甲木）：

```plain
若日主是丙火 → 甲木是丙火的偏印 → 偏印格
若日主是丁火 → 甲木是丁火的正印 → 正印格
若日主是甲木 → 甲木是日主的比肩 → 比肩（建禄类，见 6_3）
若日主是戊土 → 甲木是戊土的七杀 → 七杀格
```

同一个甲木透干，四种日主，四种格局。**这就是为什么必须先定日主再定格。**

#### 6_1_5 案例小故事：一个透干，四条路

> 有四个人，月令都是寅，天干都透甲木——按定格规则，本气透出就该定格。但四个人走出的人生完全不同。
>
> **丙火日主（偏印格）**：走的是学术与技术的偏门路线。他选了一个极冷门的研究方向，熬了十年，现在是那个细分领域里绕不开的人。
>
> **丁火日主（正印格）**：走的是正统教育路线。做了二十年教师，桃李满天下，学生里有不少已经成了同行。
>
> **戊土日主（七杀格）**：进了高压行业，做危机公关。天天救火，但也越做越强，四十岁就成了合伙人。
>
> **甲木日主（建禄格）**：自主经营，靠自己一路打拼。没有捷径，也没有靠山，用他自己的话说："我这个人，就是什么都得自己扛。"
>
> 四个人后来在一次行业论坛上碰面，聊起各自的经历都很感慨。
>
> **四个人聚在一起那次，聊出了一个共同点**：他们各自的路径，恰好都是自己格局里"最省力的那条"。偏印格那位说自己"选冷门方向根本没犹豫，就是觉得有意思"；正印格那位说"我从小就想当老师"；七杀格那位说"我就喜欢救火，太平的日子反而难受"；建禄格那位说得最直接："我试过给人打工，两年就不行了。"
>
> 排盘师后来总结：**"格局不是标签，是'这个命局用什么方式发力'的描述。四个人没有谁高谁低，差别在于发力方式完全不同——一个靠深耕冷门，一个靠正统积累，一个靠扛压力，一个靠自己扛全部。"**
>
> **复盘拆解**：定完格局，紧接着必须问一句——**"这个格局意味着什么样的发力方式？"** 只答出格名就停住，等于把地图当成了目的地。定格五步走完，这一步才是真正开始论命的地方。

> **可复用的经验**：**格局不是标签，是"这个命局用什么方式发力"的描述。** 定格之后，紧接着要问的是"这个格局意味着什么样的发力方式"。

#### 6_1_8 定格的三个特殊情况

五步定格法覆盖了大多数情况，但有三类命局会卡住，需要单独处理：

| 情况 | 表现 | 处理 |
| :---: | :---: | :--- |
| **一、月令本气不透** | 月支藏干一个都没透到天干 | 退而看中气、余气是否透；仍不透 → **不成格**，转特殊格局检查（6_4~6_5） |
| **二、透出两个以上** | 月令本气与中气同时透干 | 以**本气**所透为主格；中气所透为兼格，作辅助参考 |
| **三、月令即日主本气** | 如甲木日主生于寅月 | 月令无用神（是自己人）→ 转**建禄格 / 月刃格**（见 6_3） |

**"不成格"怎么办？** 不成格不是没法论，只是换一套方法：

```plain
不成格 → 按"扶抑 + 病药"论命（板块7）
        取用看全局最旺之势与日主所需，不再依赖月令透出之神
```

> **一条重要提醒**：**格局只决定"层次与发力方式"，不决定吉凶。** 不成格的命局照样可以很好，只是它的成就路径不那么"典型"。不要用"不成格"三个字吓人。

### 6_2 格局成败判断

#### 6_2_1 成格三条件

```plain
第1条 格局用神（月令透出之神）有保护（有生、有合、有护卫）
第2条 格局用神不被严重冲克
第3条 日主有能力担得起这个格局
```

#### 6_2_2 破格 / 败格四条件

```plain
第1条 格局用神被严重冲克（尤其是紧贴之冲）
第2条 格局用神被合去（合化为别的五行）
第3条 日主太弱，无法胜任格局
第4条 忌神太旺，压制格局
```

#### 6_2_3 格局三层次

| 层次 | 特征 |
| --- | --- |
| **上格** | 格局纯粹、有情、不杂，日主中和能担 |
| **中格** | 格局有成有破，好坏参半 |
| **下格** | 格局破损严重，或日主太弱 / 太旺无法配合 |

#### 6_2_4 救格方法：用药去病

> **核心思路**：找出格局的"病"（问题所在），用对应的"药"来治。

| 病 | 药 |
| --- | --- |
| 正官格被伤官克 | 印星来通关（印克伤官，护住正官） |
| 财格身弱 | 比劫帮身担财 |

> **更完整的病药对应体系，见板块7_4。** 本单元只处理"格局层面"的救应。

#### 6_2_6 落地实操：格局体检四问

```plain
Q1 格局用神是什么？在哪个位置？
Q2 它有没有护卫？（谁生它？谁护它？）
Q3 它有没有受伤？（被冲？被克？被合去？）

```

#### 6_2_7 案例小故事：破了又救的官格

> 某命局是正官格——月令透出正官，格局本该清正。但天干又透出伤官，紧贴正官，形成"伤官见官"。
>
> 这是教科书级别的破格之象，书上直断"丢官罢职、是非不断"。
>
> 一位初学者看到这个组合，脸色都变了，跟客户说："你这个格局破了，职场上恐怕不太顺。"
>
> **客户却笑了：**"我做了十五年管理，确实跟上级红过几次脸，但每次都有人出面帮我说话，职位一路在升，去年还进了班子。"
>
> 初学者回去重新看盘——原来年干有个正印，而且紧贴着伤官。**印星克伤官，等于把那个"惹事的字"摁住了，正官被护住了。** 病在伤官，药在印星，药到病除。
>
> **更妙的是后续。** 客户自己承认："每次出事，事后看都是好事。"这不是客套——他三次与上级的冲突，事后都成了他晋升的转折点：因为每次冲突都被更高层看到，而且每次他都有理有据。
>
> 那位初学者后来问："那怎么判断'有没有药'？不能每次都靠事后验证吧。"
>
> **老师给了个很实用的顺序，三条缺一不可：**
>
> **一看药在不在命局里** —— 有没有能制住这个"病"的十神。本例的病是伤官，能制伤官的是印星，命局里恰好有正印。
>
> **二看药有没有力** —— 有没有根、有没有被克。如果印星虚浮无根，等于有方子没药材。
>
> **三看药离病近不近** —— 紧贴最有效，隔得远效力大减。本例的印星紧贴伤官，所以救应成立。
>
> 老师总结了一句：**"这三条都过了，才算真有救应。药在命局里但虚浮无根，等于有方子没药材；药有力但远隔，等于远水救近火。"**
>
> 他后来把这三条记成了口诀：**"有药、有力、有近 —— 三有齐全才算救。"**
>
> **这个案例还有个反直觉的推论值得记住：**
>
> **命局层次高不高，不看有没有病，而看病有没有药。** 一个四平八稳、无病无药的命局，往往只是平庸——没有压力，也就没有需要动用能力的时刻；一个有明显病灶但药到病除的命局，反而能成就事业——因为"病"是压力，"药"是解决压力的能力，两者兼备的人，恰恰是能扛事的人。
>
> 这一点在断语上很重要：**看到破格，第一件事不是断凶，而是找药。** 找到药，这个"破"反而是层次高的证据；找不到药，才是真的破。
>
> **复盘拆解**：除了"三有齐全才算救"，这个案子还有个更妙的推论容易被忽略：**客户说"每次出事事后看都是好事"，不是客套，而是"有病有药"结构的必然表现。** 每一次冲突都被更高层看到，每一次他都有理有据——这就是"药"在起作用。
>
> 由此可以定一条断语的写法：**看到破格，第一句不是断凶，而是找药；找到药，这个"破"反而是层次高的证据；找不到药，才是真的破。**
>
> 补一句用药次序：**优先用命局里已有的药**（现成、有力、紧贴），命局没有再看大运能否补。药在远方等于远水，不能算救应。

> **可复用的经验**：**看到破格不要急着断凶，先找有没有救应的"药"。** 有病有药的命局，往往比四平八稳的命局更有层次。判断药是否管用，按"有药、有力、有近"三有去查。

#### 6_2_10 破格与救应的完整对照

格局有病不可怕，可怕的是有病无药。下面这张表把常见的"病—药"配对一次列全：

| 格局 | 病（破格因素） | 药（救应之神） | 救应成立条件 |
| :---: | :---: | :---: | :--- |
| 正官格 | 伤官克官（伤官见官） | **印星**（制伤官、护正官） | 印星有根、紧贴、不被财坏 |
| 七杀格 | 七杀无制（攻身） | **食神制杀** 或 **印星化杀** | 制化之神有力且不被合去 |
| 财格 | 身弱担不动财 | **比劫**（帮身担财）或**印星**（生身） | 比劫有根、不被官杀克尽 |
| 财格 | 比劫夺财 | **官杀**（制比劫）或**食伤**（泄比劫生财） | 取其中有力者 |
| 印格 | 财星坏印 | **比劫**（夺财护印）或**官杀**（泄财生印） | 官杀最好，能通关 |
| 食神格 | 枭印夺食 | **财星**（破印）或食神自身强旺 | 财星有根方能有效破印 |
| 伤官格 | 伤官无制（锋芒过露） | **印星**（制伤官，即"伤官配印"） | 印星有力，不反被伤官耗 |
| 建禄 / 月刃 | 比劫无制（刚而无制） | **官杀**（最佳，主贵）、食伤（泄秀）、印星（化） | 官杀有力方成"羊刃驾杀" |

**救应是否成立的三条检查（"三有"）**：

```plain
第1条 有药——命局里有没有能制住这个"病"的十神
第2条 有力——药有没有根、有没有被克
第3条 有近——药离"病"近不近（紧贴最验，隔位大减）

三条全过，才算真有救应。
药在命局里但虚浮无根 = 有方子没药材；
药有力但远隔 = 远水救近火。
```

**一个反直觉的推论**：

```plain
命局层次高不高，不看有没有病，而看病有没有药。
四平八稳、无病无药的命局，往往只是平庸；
有明显病灶但药到病除的命局，反而能成就事业——
因为"病"是压力，"药"是解决压力的能力，两者兼备的人，恰恰是能扛事的人。
```

#### 6_3_1 建禄格

> **定义**：日主居于月令临官位（禄位）。

| 甲 | 寅月 |

```plain
第1点 日主得令得地，身不弱
第2点 但月令没有明确的格局用神
   ——因为月令本气就是日主同类
第3点 需要从其他位置寻找格局用神
```

#### 6_3_2 月刃格（阳刃格）

> **定义**：日主居于月令帝旺位的**阳干**。

| 日主（阳干） | 刃位（月令） |
| --- | --- |
| 甲 | 卯月 |
| 丙、戊 | 午月 |
| 庚 | 酉月 |
| 壬 | 子月 |

**四个特点**：

```plain
第1点 阳刃 = 劫财处于极旺之地
第2点 个性刚烈、冲动、有爆发力
第3点 喜见官杀（尤其七杀）来制衡 → "羊刃驾杀"为武贵
第4点 不喜再遇比劫（更加暴躁破财）
```

#### 6_3_3 建禄 vs 月刃：一张表看清

| 维度 | 建禄格 | 月刃格 |
| --- | --- | --- |
| 位置 | 月令临官位 | 月令帝旺位（仅阳干） |
| 力量 | 得令得地，身不弱 | 更旺，偏极 |
| 关键问题 | 月令无用神，需他处找 | 太刚易折，需制化 |
| 喜 | 视全局寻找用神 | 喜官杀（七杀最佳）制之 |
| 忌 | — | 再遇比劫、逢冲 |

#### 6_3_4 落地实操：两类格局的取用思路

```plain
【建禄格】
  第1步 先确认身旺（几乎必然）
  第2步 月令本气是比劫，不能为格神 → 往中气、余气找
  第3步 中气余气也不透 → 看他柱最旺且有力的十神定用
  第4步 取用方向：以克泄耗为主（官杀、食伤、财星）

【月刃格】
  第1步 确认阳刃（阳干 + 帝旺月令）
  第2步 优先找官杀（七杀最佳）→ 羊刃驾杀，武职之贵
  第3步 无官杀则看食伤泄秀 → 化刚为用
  第4步 检查有无冲刃（逢冲 = 血光之灾信号）
```

#### 6_3_5 案例小故事：羊刃驾杀的两种结局

> 两位庚金日主，都生于酉月——都是阳刃格。
>
> **第一位**：天干透丙火七杀，紧贴制刃，标准的"羊刃驾杀"。他从军校出来，一路做到中层指挥。下属对他的评价是"严，但服气"——性格刚烈却极有章法，从不为难人，但从不含糊。
>
> **第二位**：命局里满盘比劫帮身，七杀弱而受制，等于"刃无制"。他脾气火爆，三次与人冲突进了派出所；四十岁那年一场大手术，躺在病床上两个月才收敛。
>
> 有意思的是，第二位年轻时反而更"风光"——出手大方、朋友多、谁都给他面子，走到哪儿都是中心。只是这种风光经不起时间：那些"朋友"在他出事之后一个都没露面。
>
> 他后来自己也反思过：**"我那时候以为脾气大是有性格，现在才明白那只是没闸门。"**
>
> 后来有人问第一位："你脾气不暴吗？"他说："暴，但我知道往哪儿使。"
>
> 老师说这两句话正好点出了阳刃的本质：**"刃是力量，杀是闸门。没有闸门的力量，强大和危险是同一个意思。"**
>
> 落到实操上，阳刃格（以及所有比劫过旺的命局）要看的就一件事：**有没有有效的制。** 制有三种——官杀制（最正，主贵）、食伤泄（主才华转化）、印星化（主以德服人）。三者都没有，才是"刃无制"。
>
> 判断"有没有效"同样用前面那三条：**制神在不在命局、有没有力、离刃近不近。** 第二位的七杀不是没有，而是弱而受制——按这三条一查就知道，等于形同虚设。
>
> **复盘拆解**：羊刃驾杀的两种结局，差别不在"有没有羊刃"，而在**杀有没有力、能不能制住刃**。同样是刃，有杀制则成武贵，无杀制则成血光——**刃是力量，不是吉凶；决定吉凶的是这股力量有没有被引导。**
>
> 所以看到羊刃（以及任何比劫过旺的局），只查一件事：**有没有有效的制。** 制有三条路——官杀制（最正，主贵）、食伤泄（化刚为用）、印星化（以德服人）。三条都没有，才是无制。
>
> 判断制是否管用，还是那三问：**在不在、有没有力、近不近。** 三问不全，就仍按"刃无制"论。

> **可复用的经验**：**同样是阳刃，有杀制则贵，无杀制则祸。** 这就是"制化"的价值——力量本身不是问题，有没有约束才是。查制化是否管用，按"在不在、有没有力、近不近"三条走。

| 戊己土随火：戊禄巳、己禄午 | 给土单算禄位 | 戊土生于巳月 = 建禄 |

#### 6_3_8 建禄与月刃的取用检查顺序

这两类格局因为"月令无用神"，最容易在定用神时卡住。按固定顺序查：

```plain
【建禄格】
  第1步 确认身旺（建禄几乎必然身不弱）
  第2步 月令本气是比劫，不能为格神 → 往中气、余气找
  第3步 中气余气也不透 → 看他柱最旺且有力的十神定用
  第4步 取用方向：以克泄耗为主（官杀、食伤、财星）

【月刃格】
  第1步 确认阳刃（阳干 + 帝旺月令）
  第2步 优先找官杀（七杀最佳）→ 羊刃驾杀，武职之贵
  第3步 无官杀则看食伤泄秀 → 化刚为用
  第4步 检查有无冲刃（逢冲 = 血光之灾信号，见板块8_3）
```

**一条关键判断**：**制化是否管用，按"在不在、有没有力、近不近"三条查。** 制神在命局里但虚浮无根，等于有方子没药材；制神有力但远隔，等于远水救近火。三者不全，就还是"刃无制"。

### 6_4 特殊格局 · 从格类

> **判定条件见板块5_6（从格五问）。** 本单元的重点是：**从格一旦成立，该如何论命。**

#### 6_4_1 从格的共同特征

```plain
第1条 日主孤立无援，全局气势一边倒
第2条 不能用普通正格的方法论命
第3条 顺势力而为：全局什么旺，就跟着什么走
```

#### 6_4_2 从格的变化风险

```plain
行运遇到日主同类（比劫 / 印星）→ 可能还原
原格越真，越不容易还原
假从格极易还原
```

#### 6_4_3 落地实操：从格论命三步

```plain
第1步：确认从的是什么
       从财？从杀？从儿？从强？从旺？

第2步：取用 = 顺势（全局什么旺，就用什么）
       从财    → 喜财星、食伤（食伤生财）
       从杀    → 喜官杀、财星（财生官杀）
       从儿    → 喜食伤、财星（食伤生财）
       从强/旺 → 喜比劫、印星

第3步：标注"还原风险运"
       从格遇到印比运 → 标红，提示变化
```

#### 6_4_4 案例小故事：从财格的富贵与陷阱

> 某命局日主极弱，满盘财星，五问全中——真从财格。
>
> 前二十多年走到财运和食伤运（食伤生财），一路顺遂：做生意风生水起，人脉广、机会多，完全符合"顺财之势则富"的描述。他自己也说："那二十年我做生意几乎没失过手。"
>
> 四十五岁后进入一步印运。印星生扶日主，从格有了"还原"之势。
>
> 恰恰在那几年，他把全部资金押在了一个长周期项目上——他的判断逻辑还是"我以前做什么成什么"，但环境已经变了。结果资金链断裂，几乎赔进去大半身家。
>
> 事后复盘时，老师跟他说了一句话：**"从格之人的一生逻辑是'顺势'。最怕的不是不得势，而是'得势'——日主一得势，就与全局气势相抗，反而动辄得咎。"**
>
> 他追问："那是不是说，从格的人遇到印比运就只能等着？"
>
> "不是等，是换打法。"老师说，**"从格行印比运，核心策略是'收缩'：减少大额投入、不做长周期押注、把主动权交给别人。你之前二十年靠的是'敢下注'，那几年恰恰要反过来——能不做决定就不做决定。"**
>
> 老师还补了一条更实用的：**"从格的人最容易栽在'路径依赖'上。前二十年顺，是因为那二十年你的打法刚好和环境匹配；环境换了，打法没换，这才是真正的坑。"**
>
> 他听完苦笑："我就是觉得以前都成了，这次也该成。"
>
> 后来他把这条写进了自己的复盘笔记，还加了一句给自己看的话：**"顺的时候要想清楚'我为什么顺'——是想对了，还是运气好刚好对上。这两者的区别，要到环境变了才看得出来。"**
>
> **复盘拆解**：从格的核心风险可以压缩成一句话：**从格之人最容易栽在"路径依赖"上。** 前二十年顺，是因为打法刚好和环境匹配；环境换了打法没换，这才是真正的坑。
>
> 所以断从格大运时，除了标红风险年份，更重要的是**明确告诉对方"这几年的打法要从进攻切到收缩"**。只说"这几年要小心"，对方多半听不进去——因为他前二十年就是靠猛打过来的。
>
> 判断风险期的口诀：**从格怕印比（还给日主根气），专旺怕官杀财（破专一之势）。** 记住这两句，风险运就能自己标出来。

> **可复用的经验**：**从格命局最危险的运，恰恰是别人眼里"帮你"的运。** 断从格大运时，印比运一定要标红——那几步的打法要从"进攻"切到"收缩"，减少投入、避免长周期押注、警惕路径依赖。

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 从格取用 = 顺势 | 按正格扶抑取用 | 从财格用印比 = 逆势，主不顺 |
| 印比运是还原风险期 | 断运时忽略 | 从财格行印运 → 资金链断裂 |

#### 6_4_7 从格的"还原风险运"怎么标

从格最危险的运，恰恰是别人眼里"帮你"的运。断运时必须把这类年份标出来：

```plain
从财格 → 印运、比劫运 = 还原风险期
从杀格 → 印运、比劫运 = 还原风险期
从儿格 → 印运、比劫运 = 还原风险期
从强 / 从旺 → 官杀运、财运 = 破格风险期
```

**风险期的操作建议（按吉凶分两头给）**：

| 风险类型 | 特征 | 建议动作 |
| :---: | :---: | :--- |
| **从格遇印比运** | 日主得势，与全局气势相抗 | 收缩：减少大额投入、不做长周期押注、把主动权交给别人 |
| **专旺格遇克运** | 主导五行被克制 | 收缩规模、减少固定资产、把资源转成可携带的形式（经验、人脉） |

> **一条必须提醒客户的话**：**从格之人最容易栽在"路径依赖"上。** 前二十年顺，是因为打法刚好和环境匹配；环境换了打法没换，这才是真正的坑。所以断从格大运时，除了标红年份，还要明确告诉对方"这几年的打法要从进攻切到收缩"。

### 6_5 特殊格局 · 化格与专旺格

#### 6_5_1 天干五合化格（化气格）

> **天干五合的基本原理见板块2_4。** 此处专讲"化气格"作为格局时的成立条件。

**成立四条件**：

```plain
第1条 月令必须是化神当令（如甲己合化土，需土月）
第2条 两干必须紧贴（相邻）
第3条 天干不能再有化神之克星
第4条 日主参与合化时尤为特殊
```

**举例**：

```plain
甲己合化土格：甲日主或己日主，天干甲己紧贴合化
需辰戌丑未月（土月）支持
论命以土的属性为中心
```

#### 6_5_2 专旺格（五种）

| 专旺名 | 五行 | 条件 | 特点 |
| --- | --- | --- | --- |
| 曲直格 | 木 | 地支全木（寅卯辰亥未）或木气过旺 | 仁寿之格，忌金来破 |
| 炎上格 | 火 | 地支全火（巳午未寅戌）或火气过旺 | 礼急之格，忌水来破 |
| 稼穑格 | 土 | 地支全土（辰戌丑未）或土气过旺 | 信重之格，忌木来破 |
| 从革格 | 金 | 地支全金（申酉戌丑巳）或金气过旺 | 义刚之格，忌火来破 |
| 润下格 | 水 | 地支全水（亥子丑申辰）或水气过旺 | 智慧之格，忌土来破 |

**专旺格四条件**：

```plain
第1条 该五行之气占据绝对主导地位
第2条 其他五行极弱或不显
第3条 日主通常属于该主导五行
第4条 喜生助主导五行，忌克制主导五行
```


#### 6_5_5 案例小故事：润下格的水性智慧

> 某命局地支亥、子、丑三会北方水局，天干透壬癸，日主壬水——润下格成立。
>
> 按专旺格取用：喜水、喜金（金生水），忌土（土克水）。
>
> 此人做了二十年航运物流，跑遍全球港口。回头看，这几乎是水的类象的完美映射——航运、流动、贸易，全是水。他说自己"一坐办公室就浑身不自在，在码头上反而踏实"。
>
> 五十岁那年，他进入一步土运（忌神当道）。公司遭遇重大政策调整，几个大客户同时流失。
>
> 他做了一件让所有人意外的事：没有硬撑，而是果断收缩业务，把公司转成顾问模式。两年后行业回暖，他靠积累的经验和人脉活得比很多硬撑下来的同行都好。
>
> 他后来说：**"专旺格最怕的就是破格之运。提前知道那几年不好过，反而能提前准备——这就是看盘的意义。"**
>
> **他收缩业务那一步，是提前两年就知道的**。五十岁进入土运之前，排盘师就提醒过他"专旺格怕破格之运"。所以政策调整来临时，他不是被动应对，而是在一个已经想清楚的框架里做选择。
>
> 他后来对比过同行的反应：有人硬撑，把现金流耗在等回暖上；有人恐慌抛售，把多年积累的客户关系一次性断掉。他选的是第三条——**转成顾问模式，把固定资产变成可携带的经验和人脉。** 两年后行业回暖，他靠这两样重新起来，比很多硬撑下来的同行都好。
>
> **复盘拆解**：专旺格的价值在于"提前知道什么时候该收"。拿到专旺格的结论，下一步必须做——**把克制主导五行的那些年份标出来**（润下格遇土运、炎上格遇水运、稼穑格遇木运等），提前两年做准备：收缩规模、减少长周期投入、把资产转为可携带的形式。

> **可复用的经验**：**专旺格怕"破格之运"（克制主导五行的运）。** 知道它什么时候来，就是最大的价值。

#### 6_5_6 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 专旺格喜生助主导五行，忌克制之 | 按扶抑法取用 | 润下格见土运 = 破格之运 |
| 化气格需月令支持 + 紧贴 + 无克星 | 见合就论化 | 甲己合在木月 → 合而不化，不成格 |

### 6_6 杂气格

> **本单元定位**：月令落在辰戌丑未四库时，本气是戊己土，而土一般不成格。这时要从库中所藏的中气、余气里找格神——这样定出来的格局就叫**杂气格**。

#### 6_6_1 什么是杂气格

```plain
正格：月令本气透出 → 以本气定格（如寅月透甲 → 建禄/比肩类）
杂气：月令是四库，本气为土，土不成格
      → 改看库中藏干（中气、余气），哪个透出就以哪个定格
```

**四库各藏什么**（回顾 2_3）：

| 月令 | 本气 | 中气 | 余气 | 可成之格 |
| :---: | :---: | :---: | :---: | :--- |
| **辰** | 戊土 | 乙木 | 癸水 | 杂气财格（癸）、杂气官格（乙，对己土日主） |
| **戌** | 戊土 | 辛金 | 丁火 | 杂气印格（丁）、杂气食伤格（辛，对己土日主） |
| **丑** | 己土 | 癸水 | 辛金 | 杂气财格（癸）、杂气食伤格（辛） |
| **未** | 己土 | 丁火 | 乙木 | 杂气印格（丁）、杂气官格（乙） |

> **"杂气"二字的来历**：库中所藏之气不纯，故称"杂"。这也决定了杂气格的一个天然特点——**格局本身就带杂，纯粹度天生不如正格。**

#### 6_6_2 杂气格的两个特殊条件

杂气格比正格多两道关，这也是它容易"看着成格、实际不成立"的原因：

```plain
第1条 必须透出
   库中藏干要透出天干，才算"拿出来用了"
   不透 → 库门未开，格神闷在里头，不成格（退看 2_3_10 透干）

第2条 库宜冲开，但冲有吉凶
   库被冲 → 库门开，格神得以发挥作用
   但冲本身是"变动"，冲得动则发，冲不动则损
   判断：紧贴之冲有力可开；隔位之冲常开不了（见 3_5 开库三途）
```

#### 6_6_3 杂气格的取用思路

```plain
第1步 定格神：库中哪个藏干透出了，就以它定格
第2步 查格神有力与否：透出且有根 → 有力；透出无根 → 虚浮
第3步 查库有没有开：透了干即为有钥匙，逢冲则开得更彻底
第4步 取用：与正格同法——护格神、制忌神，兼顾日主能否担得起
```

#### 6_6_4 落地实操：杂气格检查四问

```plain
第1问 月令是不是辰戌丑未？不是 → 本单元不适用

第2问 库中藏干有没有透出天干？
   没透 → 不成杂气格（库门紧闭）

第3问 透出的那个字有根吗？为用为忌？

第4问 库有没有被冲开（或透干这把"钥匙"是否到位）？
   开了 → 格局发力；没开 → 待时而动
```

#### 6_6_5 案例小故事：锁了三十年的库

> 一位命主月令是戌，戌中藏辛金（中气）——对己土日主来说，辛金是食神，可论"杂气食神格"。但辛金在四柱天干上并未透出。
>
> 前三十年的状态很典型：他手艺极好，做机械加工出身，厂里最难的活都归他。可一直是工人，带过几个徒弟，也没能往上走。他自己说："我会的东西不少，就是没换成别的。"
>
> 三十一岁那年，他进入一步辛金透出的大运——**天干来了这把钥匙。**
>
> 此后三年，他被一家技术公司请去做技术顾问，还带了团队。手艺还是那门手艺，但这一次它被"端出来"了。
>
> 有意思的是他自己的感受："我这三十年好像没白干，就是一直锁着。"
>
> **复盘拆解**：杂气格最容易被误判的地方，是**把"库里有"当成"已经得到"**。
>
> 库里藏着的格神，在没有透出、没有被冲开之前，只能算"潜力"，不能算"资产"。所以断杂气格，问的不是"有没有"，而是**"透出来了吗""库开了吗""什么时候开"**——中间这两问最容易被跳过，而它们恰恰决定这个格局是"资产"还是"摆设"。
>
> **可复用的经验**：**见四库月，先别急着定格，先查透与开。** 不透不开的杂气格，是"锁着的本事"——它一直在，只是还没轮到它上场。

#### 6_6_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 四库月从库中藏干定格 | 用本气戊己土定格 | 辰月透癸 → 杂气财格 |
| 杂气格必须透出才成立 | 库里有就算成格 | 戌中辛不透 → 不成格 |
| 库宜冲开，但冲要紧贴有力 | 见冲就当库开 | 隔位冲开不了 |

#### 6_6_7 实用验证

- **验证 1**：说出辰戌丑未四库各藏什么，以及各自可成哪些格。
- **验证 2**：解释为什么杂气格"必须透出"这一条比正格更严格。
- **验证 3**：给一个四库月的命局做"杂气格检查四问"。

### 6_7 特殊格局（狭义外格 / 杂格）

> **本单元定位**：正八格之外的格局统称"外格"或"杂格"，多由特定的干支组合直接判定，不以月令透干为依据。**这类格局名目繁多、口径不一，本库按"了解为主、谨慎使用"处理。**

#### 6_7_1 外格与正格的根本区别

| 维度 | 正格（八格） | 外格（杂格） |
| :---: | :---: | :--- |
| **定格依据** | 月令透出之神 | 特定的干支组合 |
| **是否看月令** | 是，核心依据 | 多数不看月令 |
| **体系地位** | 子平主流，权重最高 | 辅助参考，权重较低 |
| **结论稳定性** | 高 | 较低，各派口径差异大 |

#### 6_7_2 常见外格一览（了解即可）

| 格局 | 判定 | 传统说法 |
| :---: | :---: | :--- |
| **魁罡格** | 庚辰、庚戌、壬辰、戊戌四日出生 | 主刚烈、有决断，忌见财官破格 |
| **金神格** | 乙丑、己巳、癸酉三组（时柱论为主） | 主刚毅，喜火制 |
| **日贵格** | 丁酉、丁亥、癸巳、癸卯四日 | 主端庄、有贵人缘 |
| **六阴朝阳格** | 辛日逢戊子时 | 主贵，喜水木 |
| **井栏叉格** | 庚申、庚子、庚辰日见申子辰 | 主清贵 |
| **壬骑龙背格** | 壬辰日多见辰 | 主贵，喜寅 |
| **虎午奔巳格** | 庚日见午多、巳时 | 主权柄 |

> **注意**：上表只是代表性列举。**外格的名目在古籍中多达数十种，且各家收入标准不一**——本库不主张死记这些格局名。

#### 6_7_3 使用纪律（本单元最重要的一节）

外格最容易犯的错是"喧宾夺主"。三条纪律必须守住：

```plain
第1条 先判正格，再谈外格
   任何八字都先走完正格流程（6_1 定格五步法）
   正格成立 → 以正格为主，外格只作辅助描述
   正格不成立 → 才考虑外格与特殊格局

第2条 外格不能推翻旺衰与用神结论
   外格是"描述"，不是"判决"
   它改变不了日主强弱，也改变不了取用方向

第3条 名目冲突时，取有典籍依据、且能与全局印证的那一条
   多个外格同时成立时，不叠加使用
   选一条与全局气势最吻合的即可
```

#### 6_7_4 落地实操：遇到"命带某格"的说法怎么办

```plain
第1步 确认这个格是怎么判定的（哪几个字？哪一柱？）
第2步 看它与正格结论冲突不冲突
   冲突 → 以正格为准
第3步 看它有没有"破格"条件（多数外格都有明确的破格条款）
第4步 把它翻译成性格或事件倾向，而不是当成层次判决
```

#### 6_7_5 案例小故事：一句"魁罡格"引发的误会

> 一位初学者看到客户是庚戌日生，立刻说："你是魁罡格，性格刚烈，主贵，但婚姻不顺。"
>
> 客户当场就质疑了："我性格一点都不刚烈，结婚十五年也没什么不顺。"
>
> 复盘时老师指出三个问题：
>
> **第一，没先判正格。** 这个命局月令透出正财，是标准的正财格。正格成立在先，魁罡只能作补充描述，不能盖过正格。
>
> **第二，把"传统说法"直接当成断语。** "魁罡主刚烈"是古书对这一类日的概括性描述，不等于"这个人一定刚烈"。庚金日主若见火制、见水泄，表现出来的完全可能是另一种气质。
>
> **第三，忽略了破格条件。** 魁罡格忌见财官破格——这个命局恰恰财星透出，按传统说法属于"破格"，此时魁罡的特性本就大打折扣。
>
> 老师示范了另一种说法：**"庚戌日生，古籍称魁罡，传统上认为这类人骨子里有决断力、做事不喜欢拖泥带水。但你命局财星透出，这份刚烈被化掉了不少，表现出来更多是干脆和有分寸。婚姻上不用特别担心，倒是要注意别把工作里的果断带回家。"**
>
> 客户听完点头："这个说得对。"
>
> **复盘拆解**：同样一个"魁罡格"，前一句被质疑，后一句被认可。差别在于——**前者把格局名当结论，后者把格局名当线索，并且过了正格、喜忌、破格这三关。**
>
> 外格的正确用法可以压缩成一句：**它是形容词，不是判决书。** 用来给断语增加一层细节可以，用来下定性结论不行。
>
> **可复用的经验**：**先正格，后外格；外格只作辅助，不推翻前面的结论。** 遇到"命带某某格"的说法，先问三句：正格是什么？这个格破没破？它和全局气势对得上吗？

#### 6_7_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 外格先判正格，只作辅助 | 见外格就当主格论 | 正财格 + 庚戌日 → 以正财格为主 |
| 外格多有破格条件 | 只记格局名，不记破格条款 | 魁罡见财官则破 |
| 外格是描述，不是判决 | 把"主刚烈"直断给人 | 需过喜忌与全局后再说 |

#### 6_7_7 实用验证

- **验证 1**：说出外格与正格在定格依据上的根本区别。
- **验证 2**：说出使用外格的三条纪律。
- **验证 3**：把一句"你是魁罡格，性格刚烈"改写得分寸得体。

### 6_8 象（结构）

> **本单元定位**："象"是指干支之间因为特定的排列组合而呈现出来的**结构性画面**。它不参与旺衰计算，也不改变格局结论，但能让断语变得具体、有画面感。

#### 6_8_1 什么是"象"

```plain
五行  →  回答"是什么"（金木水火土）
十神  →  回答"扮演谁"（财官印食）
格局  →  回答"什么框架"（正格、从格）
象    →  回答"长什么样"（画面、姿态、关系）
```

**象与神煞的区别**：神煞是"查表得来的标签"，象是"看结构读出来的画面"。前者靠记忆，后者靠观察。

#### 6_8_2 六种常见结构象

| 名称 | 结构 | 画面 | 常用读法 |
| :---: | :---: | :---: | :--- |
| **天覆地载** | 天干生地支（如甲午：甲木生午火） | 上面护着下面 | 根基稳，内外协调 |
| **盖头截脚** | 天干克地支（盖头）/ 地支克天干（截脚） | 上下相拧 | 力量打折，内外不一致 |
| **干支一气** | 天干地支同五行（如甲寅、乙卯） | 表里如一 | 力量纯粹，但也固执 |
| **上下通气** | 同柱干支相生，且地支藏干与天干同 | 气脉贯通 | 该柱力量完整可用 |
| **夹拱** | 两柱之间夹着某个地支（如寅辰夹卯） | 中间藏着个东西 | 有暗中之力，待引而发 |
| **连珠** | 相邻两柱干支相生（如年柱生月柱） | 一路顺下来 | 流通好，事情推进顺 |

> **记忆法**：**象看的是"姿态"——是顺的、拧的、纯的、还是藏的。** 拿到一柱，先问它上下是什么关系，画面就出来了。

#### 6_8_3 读象三原则

```plain
第1条 象不参与计算
   象不改变旺衰分数，也不改变用神结论
   它只负责"把结论说具体"

第2条 象要过喜忌关
   同一个"干支一气"，为用则纯粹有力，为忌则固执偏激
   不过喜忌这一关，象就只是漂亮话

第3条 象要服务于断语，不能替代断语
   ✗ "你命局有夹拱，所以你很厉害。"
   ✓ "你日时两柱夹拱，主中年后有一段暗中积累的助力，
      大约在某运被引动——那几年可以放心投入。"
```

#### 6_8_4 落地实操：读象三步

```plain
第1步 逐柱看干支关系：生？克？同气？
   先给每一柱定一个"姿态"

第2步 看柱与柱之间：连珠？夹拱？隔位相生？
   找出结构性的画面

第3步 挑出最突出的 1~2 个象，过喜忌关后写成断语
   不要罗列所有象——象多了等于没象
```

#### 6_8_5 案例小故事：一句"拧着"说到了痛处

> 一位客户来问事业，前面旺衰、格局、用神都推完了，结论是"身强、食伤生财，适合靠专业变现"。
>
> 排盘师说到最后，加了一句：**"不过你日柱是盖头截脚——天干和地支拧着。你有没有这种感觉：想的和做的不一致，或者表面顺、底下一直在拧？"**
>
> 客户愣了几秒，说："你怎么知道？我在一家公司待了六年，一直干得不错，但我从来没喜欢过这份工作。每天上班前都要在车里坐十分钟。"
>
> 这就是"盖头截脚"在人事上的典型表现：**天干是外在表现（别人看到的、自己做出来的），地支是内在根基。** 两者相拧，外在顺遂、内在拧巴就是常态。
>
> 排盘师给的建议不是"换工作"，而是分层处理：**"你的能力结构没问题，问题在于外在角色和内在需求错位。不必立刻推翻重来——先在现有岗位上找到一件和你内在需求对得上的事，把它做成你的主线。"**
>
> 他后来在公司内部转去做培训（食伤主表达、主输出），那份拧巴感明显减轻了。
>
> **复盘拆解**：这个案子说明象的真正价值——**它能补足旺衰和格局说不出来的那一层。**
>
> 旺衰说的是"有没有力"，格局说的是"什么框架"，这两层都说不出"他每天要在车里坐十分钟"。而象可以。
>
> 但要注意象的用法边界：**排盘师不是靠象下的结论，而是在结论之后用象加了最后一层细节。** 顺序反了，就会变成"看图说话"。
>
> **可复用的经验**：**象负责把断语说具体，不负责下结论。** 用在最后一步做补充，效果最好；用在第一步做依据，最不牢靠。挑 1~2 个最突出的象，过喜忌关后写成画面感强的句子，不要罗列。

#### 6_8_6 笔记法

| 规则 | 易错点 | 命例 |
| :---: | :---: | :--- |
| 象看干支姿态：顺 / 拧 / 纯 / 藏 | 把象当计算依据 | 盖头截脚不改变旺衰分 |
| 象必须过喜忌关 | 只描述象，不判吉凶 | 干支一气为用 vs 为忌 |
| 挑 1~2 个最突出的象 | 罗列所有象 | 象多了等于没象 |

#### 6_9_6 案例小故事：中格也能过好一生

> 一位求测者拿到"中格"的评断，当场就有点失落："是不是比上格差很多？"
>
> 排盘师没直接回答，而是给他看了两个真实案例。
>
> 第一个是上格：正官格纯粹、日主中和、有印星护卫——标准的贵格。但此人一生平稳到近乎平淡，四十年待在同一个单位，做到退休，没有大起也没有大落。
>
> 第二个是中格：格局有破也有救。此人创业两次，一次成一次败；写过一本书；走过十几个国家；五十岁后又换了个完全陌生的行业重新开始。
>
> 排盘师说："格局层次说的是**命局的成色与稳定性**，不是人生的精彩程度。上格的人往往一生平顺，中格有破，意味着有波折，但也意味着有故事、有转机、有重新洗牌的机会。"
>
> 求测者听完想了很久，说："那我宁愿要后面那种。"
>
> **排盘师后来补了一层更实在的解释**：格局层次评的是"命局的成色与稳定性"，不是"人生的精彩程度"。**上格的特点是"稳"**——结构纯粹、少有破绽，所以人生波动小，但也少有戏剧性的转机；**中格的特点是"有破有救"**——波折是有的，但每一次破都跟着一次救，所以有起落也有转机。
>
> 那位求测者听完说"那我宁愿要后面那种"，其实已经答对了——他的性格和诉求本身就偏"要故事"。**格局评断要和人匹配着看，不能只报一个分数。**
>
> **复盘拆解**：给格局打分之后一定要补两句——**一句说明这个层次意味着什么**（是稳，还是有起落），**一句说明它不是什么**（不是人生成败的判决书）。只报"中格"两个字，对方多半会往坏处想。

> **可复用的经验**：**评断格局是为了理解结构，不是为了给人分等级。** 中格不是"次品"，它只是"起落明显"而已。

#### 6_9_7 笔记法

| 规则 | 易错点 | 命例 |
| --- | --- | --- |
| 格局看层次、用神看吉凶 | 用格局代替用神，或用用神否定格局 | 上格也需好运配合 |
| 中格 ≠ 命不好 | 把格局层次当人生成败判决书 | 中格有破有救 = 起落但有转机 |

### 6_10 易错对照表

| 易混对 | 关键区别 | 一句话记法 |
| :---: | :---: | :--- |
| 正格 vs 特殊格 | 正格由月令本气透干定；特殊格是极端或合化形态 | 先查正格，不成再查特殊 |
| 建禄 vs 月刃 | 建禄在月令**临官**位（甲生寅月）；月刃在**帝旺**位且限阳干（甲生卯月） | 一个是禄，一个是刃 |
| 从格 vs 专旺格 | 从格是日主极弱顺势；专旺是日主极旺气势专一 | 一个顺人，一个顺己 |
| 化气格 vs 合而不化 | 化气格须月令支持 + 紧贴 + 无克星；否则只是合而不化 | 见合未必成格 |
| 破格 vs 下格 | 破格是用神受伤；下格是日主担不起或破损严重 | 破格有药可救，下格层次低 |
| 兼格 vs 变格 | 兼格是同时具备两格；变格是大运导致格局转化 | 一个并存，一个转变 |
| 格局 vs 用神 | 格局看层次与发力方式；用神看吉凶调节 | 格局看层次，用神看吉凶 |
| 上格 vs 命好 | 上格主"成色与稳定性"，不等于人生精彩或顺遂 | 中格也能过好一生 |
