## 板块1 · 一句话总纲

> **"八字用神，专求月令。"**

整本书只研究一件事——**八字格局如何成立**。它以月令为纲，以十神为经纬，以格局成败定人生层次。

**论命主线（全书灵魂链条）**：

```plain
五行 → 干支 → 十神 → 用神 → 相神 → 格局 → 行运

```

## 板块3 · 第一部分：基础筑基（第1–7章）

### 3_1 第1章 · 论十干十二支

+ **宇宙观**：天地之间，一气而已。惟有动静，遂分阴阳。有老少，遂分四象。
+ 十干是**五种气的不同状态**，非五种实物。
+ 干支是五行时空的载体。

### 3_2 第2章 · 论阴阳生克

+ 核心追求：**中和**。
+ 生克是五行关系的根本，不可偏废。

### 3_3 第3章 · 论阴阳生死（十二长生）

+ 沈氏**重新解释**阴阳长生，驳斥坊间片面口诀。
+ 重点：长生论法**用阳不用阴**（如甲乙日只用庚金长生巳酉丑顺数，不用辛金逆数子申辰）。

### 3_4 第4章 · 论十干配合性情

+ 天干五合：甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火。
+ 合化有条件，非见合即化。

### 3_5 第5章 · 论十干合而不合

六种"合而不合"的情况：

1. **隔克之合**（中间有克合之字）
2. **遥合**（有合之意，无合之实）
3. **两杀合一**（合一留一，反清）
4. **日主相合**为"合来"，年月时合为"合去"
5. **争合妒合**（情不专）
6. **两甲合一己**，隔位则不争

### 3_6 第6章 · 论十干得时不旺失时不弱

+ 旺衰判断**不能只看月令**，要综合全局。
+ 古人旺衰判断条理清晰、操作简单，远胜现代"打分评旺衰"。

### 3_7 第7章 · 论刑冲会合解法

+ **会合可以解冲刑**（三合局、六合能化解刑冲）。
+ 二卯不刑一子；遇戌合反刑。
+ **以刑冲解刑冲**：另位之刑冲可解月令之刑冲，优先对用神有利。

## 板块4 · 第二部分：核心理论之"体"（第8–22章）—— ⭐全书精髓

### 4_1 第8章 · 论用神（全书第一关键章）

> **"八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。"**

#### 4_1_1 取用五法

| 方法 | 要旨 |
| --- | --- |
| **扶抑** | 日主强则抑（官杀克、食伤泄），弱则扶（印生、比劫助） |
| **病药** | 以扶为喜，伤扶者为病；以抑为喜，去抑者为病。除病即为药 |
| **调候** | 金水生于冬令、木火生于夏令，以调和气候为急 |
| **专旺** | 四柱气势偏于一方，不可逆，顺其气势（从格、化格） |
| **通关** | 两神对峙、强弱均平，取中间五行调和 |

#### 4_1_2 用神善恶与顺逆法则（全书灵魂）

| 类型 | 十神 | 取法 | 核心原则 |
| --- | --- | --- | --- |
| **善用神（四吉）** | 正官、正财、正印、食神 | **顺用**：生之护之 | 财喜食生、官护财；官喜财生、印护官；印喜官杀生、劫财护印；食喜身旺、财护食 |
| **恶用神（四凶）** | 七杀、伤官、阳刃、劫财 | **逆用**：制之化之 | 杀喜食制、忌财资杀；伤官喜印制、生财化伤；刃喜官杀制、忌全无；劫喜透官制、用财透食化 |

> **核心口诀**：当顺而顺，当逆而逆，配合得宜，皆为贵格。

### 4_2 第9章 · 论用神成败救应

#### 4_2_1 八格之成

| 格局 | 成格条件 |
| --- | --- |
| **官格** | 官逢财印，无刑冲破害 |
| **财格** | 财旺生官 / 财逢食生且身强带比 / 财格透印而位置妥适 |
| **印格** | 印轻逢杀 / 官印双全 / 身印两旺用食泄秀 / 印多逢财而财透根轻 |
| **食神格** | 食神生财 / 食神带杀无财 / 弃食就杀透印 |
| **七杀格** | 身强七杀逢制 |
| **伤官格** | 伤官生财 / 伤官配印且伤旺印有根 / 伤旺身弱透杀印 |
| **阳刃格** | 刃透官杀而露财印，不见伤官 |
| **建禄月劫格** | 透官逢财印 / 透财逢伤官 / 透杀遇伏制 |

#### 4_2_2 八格之败

| 格局 | 败格条件 |
| --- | --- |
| **官格败** | 官逢伤克刑冲 / 透官又逢合 |
| **财格败** | 财轻比重 / 财又透七杀 |
| **印格败** | 印轻逢财 / 身强印重而透杀 |
| **食神格败** | 食神逢枭 / 生财露杀 |
| **七杀格败** | 七杀逢财无制 |
| **伤官格败** | 非金水伤官见官 / 生财带杀 / 配印而伤轻身旺 |
| **阳刃格败** | 阳刃无官杀 |
| **建禄月劫格败** | 无财官，透印杀 |

#### 4_2_3 救应法则

> **成中有败，必是带忌；败中有成，全凭救应。**

+ 正官逢伤 → 有印制伤 → **合伤存官** → 转败为成
+ 财旺生官逢伤 → 透印制伤 → 格局复成
+ 七杀逢食制又逢印 → 印夺食 → 破格（救应失败）

### 4_3 第10章 · 论用神变化

月令因会合而改变五行属性，则以**变化后**的五行取用定格。

| 类型 | 举例 | 说明 |
| --- | --- | --- |
| **变之而美** | 辛生寅月，不透甲而透丙 → 化财格为官格 | 变化后更清纯 |
|  | 丙生寅月，午戌会局 → 化印为劫 | 变化后反不佳 |
| **变之而不善** | 丙生申月，透壬会子辰 → 化财为杀 | 变坏 |
| **变而不失本格** | 辛生寅月，透丙化官又透甲 → 正官格兼正财格 | 本格仍在 |

> **"八字非用神不立，用神非变化不灵。"**

### 4_4 第11章 · 论用神纯杂

| 类型 | 定义 | 举例 |
| --- | --- | --- |
| **纯** | 互用而两相得 | 辛生寅月，甲丙并透，财官相生 |
| **杂** | 互用而两不相谋 | 壬生未月，乙己并透，官伤相克 |

> 纯者吉，杂者凶。纯杂之理，不出变化。

### 4_5 第12章 · 论用神格局高低 ⭐

> **格局高低，全在"有情"与"有力"之间。**

| 层次 | 特征 | 举例 |
| --- | --- | --- |
| **最高格** | 有情而兼有力 | 甲用酉官，壬合丁清官且壬水根深 |
| **次高格** | 有力而兼有情 | 乙用酉杀，辛逢丁制，同根月令 |
| **中等格** | 有情但力不足 | 甲用酉官，透丁逢癸，癸克不如壬合 |
| **低格/无用** | 无情无力 | 印用七杀，身强印旺透杀孤贫 |

**关键八字**：有情 > 单纯有力；有情 + 有力 = 极贵。

### 4_6 第13章 · 论用神因成得败、因败得成

> 成格之中暗藏败因，败格之中暗藏成机。

+ 化伤为财 → 本为成 → 然辛生亥月透丁，卯未会财 → 反以党杀 → **因成得败**
+ 需随时观理，一字可定千钧。

### 4_7 第14章 · 论用神配气候得失

+ 调候重要，但**不能压倒格局**。
+ 先看格局是否成立，再看气候是否失衡。
+ 金水冬生需暖、木火夏生需润。

### 4_8 第15章 · 论相神紧要 ⭐⭐（全书重中之重）

> **"伤用甚于伤身，伤相甚于伤用。"**

| 概念 | 定义 | 举例 |
| --- | --- | --- |
| **用神** | 月令定格之十神（格局核心） | 正官格中的"官星" |
| **相神** | 辅助用神成格之物（护卫格局） | 官格中的"财生官"或"印护官" |
| **喜神** | 生助用神或相神之物 | 官格用印护官，印为相；财生官，财为喜 |
| **忌神** | 破格之物（不一定克用神，一定破格） | 官格见伤官，伤官即为忌 |

**相神配合示例**：

+ 官格 → 财生官（财为相）/ 印护官（印为相）
+ 杀格 → 食神制杀（食为相）/ 印化杀（印为相）
+ 财格 → 食生财（食为相）
+ 印格 → 官生印（官为相）

> 只有**相喜兼备**的八字，才能构成上等格局。

### 4_9 第16章 · 论杂气如何取用（辰戌丑未）

**取用总则**：

1. **先取透干**（月令藏干透出者优先为用）
2. **多透取旺强**（透出二干或三干，取本气藏干）
3. **不透取本气**（均不透时取月令本气藏干）
4. **变化取所变之干**（月令因会合变属性，以变化后取用）

> **重要观点**：辰戌丑未**不必强行冲开**，"财库必冲方发"是俗论谬说。

### 4_10 第17章 · 论墓库刑冲之说

+ 驳斥"墓库必须刑冲才能打开"的民间说法。
+ 墓库之论，当以格局喜忌为准，不可一概而论冲开。

### 4_11 第18章 · 论四吉神能破格

> 吉神也能破格——关键在于**是否得宜**。

+ 正官格，官多成杀 → 反为浊
+ 正印格，印多身旺 → 孤寒
+ 食神格，食多身弱 → 泄气太过

---

### 4_12 第19章 · 论四凶神能成格

> 凶神也能成格——关键在于**制化得宜**。

+ 七杀有食制 → 权威显赫
+ 伤官配印 → 才华贵气
+ 阳刃有官杀制 → 武职功名

---

### 4_13 第20章 · 论生克先后分吉凶

> **先后程序为"活法"**——同一组干支，因排列顺序不同，吉凶迥异。

+ 先财后伤 → 伤官生财 → 吉
+ 先伤后财 → 财党杀 → 凶

---

### 4_14 第21章 · 论星辰无关格局

> **神煞只可为参考，无关格局成败。**

沈氏有意将神煞、纳音等排除在核心推演体系之外，使命理分析从"模糊看强弱"变为"清晰逻辑推导"。

---

### 4_15 第22章 · 论外格用舍

+ 外格（特殊格局）只在**月令无用**时才取用。
+ 若月令自有用神，不可另寻外格。
+ 外格包括：从格、化气格、专旺格（曲直、炎上、稼穑、从革、润下）等。

### 5_1 第23章 · 论宫分用神配六亲

#### 5_1_1 宫分法（地支定位）

| 宫位 | 对应 |
| --- | --- |
| 年支 | 祖基 |
| 月支 | 父母 |
| 日支 | 妻宫 |
| 时支 | 子孙宫 |

> 喜用聚于年月支 → 祖基丰厚；聚于日支 → 妻得力；聚于时支 → 子孙得力。

#### 5_1_2 十神配六亲

| 六亲 | 十神 | 原理 |
| --- | --- | --- |
| 母 | 正印 | 生我者 |
| 父 | 偏财 | 母之正夫（正印的正官） |
| 妻 | 正财 | 我克者，妻从夫 |
| 子女 | 官杀 | 财所生（妻所生） |
| 兄弟 | 比肩 | 同气 |

> "命中吉凶，于人愈近，其验益灵。"——妻财子禄与本身利害相关，最为显著。

### 5_2 第24章 · 论妻子

#### 5_2_1 论妻

+ **妻宫**（日支）+ **妻星**（天干之财），二者结合看。
+ 妻宫坐财官 → 吉；坐伤官 → 凶（但财格/杀格逢之反美）。
+ 妻星透干成局为喜用 → 主内助；妻星透而破格 → 防刑克。

#### 5_2_2 论子息

+ 看**时支**与**时干子星**（官杀），配合喜忌。
+ 熟读《长生沐浴歌》：

> 长生四子中旬半，沐浴一双保吉祥，

冠带临官三子位，旺中五子自成行，
衰中二子病中一，死中至老没儿郎，
除非养取他之子，入墓之时命夭亡。

+ 不可执着歌诀数量，应以**喜用生旺衰败**断多少，以**成败救应**决有无。

---

### 5_3 第25章 · 论行运（大运总纲）

> **"富贵定于命，穷通系乎运。"**

+ 取运与看命无二法，运以方为重，十年并论。
+ **喜运**：助命中喜神、用神、相神。
+ **忌运**：逆命中喜神、损伤用神相神。
+ 岁重天干，运重地支。

---

### 5_4 第26章 · 论行运成格变格

+ 大运可改变原局格局成败。
+ 原局成格 → 忌运破局则败；原局败格 → 喜运补救则成。

---

### 5_5 第27章 · 论喜忌干支有别

+ **岁（流年）重天干**，天干之力更显。
+ **运（大运）重地支**，地支之气更厚。

---

### 5_6 第28章 · 论支中喜忌逢运透清

+ 地支中的喜忌之性，逢大运引透到天干时，方才显露作用。

---

### 5_7 第29章 · 论时说拘泥格局

+ 批判民间命师**死守格局教条**，不知变通。
+ 月令无用方寻外格，不可盲目套用。

---

### 5_8 第30章 · 论时说以讹传讹

+ 批判民间流传的**错误口诀和片面说法**。
+ 强调回归五行生克本质，不可迷信歌诀。

### 6_5 七杀格（第39–40章）⭐

#### 6_5_1 成格条件

> 七杀为恶神，**必须制化**，无制则凶。

| 类型 | 成格条件 | 取运喜忌 |
| --- | --- | --- |
| **杀用食制** | 杀旺、食强、身旺 → **极等之贵** | 喜助食/助杀/助身（看谁轻）；忌正官混杂、忌印绶夺食、忌财资杀 |
| **杀用印化** | 杀印同根月令 | 喜伤官运（泄秀）、印绶身旺运；忌财运 |
| **杀用财（救应）** | 财去印存食 | 喜伤食财杀运；忌劫财、印运 |
| **财滋弱杀** | 杀弱财旺 | 喜食印比运；财弱喜财杀运 |
| **杀用阳刃** | 杀刃配合 | 杀重用食伤制，刃重助杀；忌官运 |
| **弃命从杀** | 杀重身无根 | 喜财官杀运；忌印比运 |

#### 6_5_2 杀格成败要诀

+ 杀用食制 → **天干不可明见财**（财转食生杀）
+ 若透财 → 必须"**财先食后**"（财在前食在后），否则因财致祸
+ 若透印 → 食神必须在地支多根（2个以上）

## 板块10 · 全书核心思想一句话总结

> **"八字之贵，不在五行多少，而在格局是否清纯流通。"**
