> 这是全书论命的**底层逻辑**——把十天干比拟为具体事物，借助物理常识判断命格高低。

| 天干 | 实物比喻 | 核心需求 | 记忆口诀 |
| :---: | --- | --- | --- |
| **甲木** | 栋梁之木 | 需庚金（斧子）砍伐方成材 | 甲要庚砍才成材 |
| **乙木** | 花草之木 | 需癸水（雨露）滋润 + 丙火（阳光）照暖 | 乙要癸润丙温暖 |
| **丙火** | 太阳之火 | 需壬水（江湖）映衬方光彩焕然 | 丙要壬映才光辉 |
| **丁火** | 人间炉火 | 需甲木（燃料）劈开后方可光明永驻 | 丁要甲木做燃料 |
| **戊土** | 堤岸高亢之土 | 需丙火暖 + 甲木疏劈 + 癸水润泽 | 戊要丙甲癸全备 |
| **己土** | 田园之土 | 需丙火温暖 + 癸水滋润 | 己要丙暖癸滋润 |

### 2_1 五大技术系统

由"十干实物说"衍生出五个技术层面：

1. **甲庚丁循环系统**：甲木→庚金砍→丁火炼庚→甲木生丁火（循环生克）
2. **丙辛用壬系统**：丙火需壬水映衬，辛金需壬水淘洗
3. **乙用癸丙系统**：乙木依赖癸水滋润、丙火照暖
4. **戊己共用甲丙癸系统**：土类共用甲木疏、丙火暖、癸水润
5. **壬癸用戊辛丙复杂系统**：水类用戊土筑堤、辛金发源、丙火暖局

## 板块3 · 五行四时通用宜忌

### 3_1 🌳 木行总诀

```plain
春木余寒，丙火为先，癸水为辅；无丙寒木不发，无水木枯无荣。
夏木火炎，癸水第一，庚金次之；火旺木焚，无水必枯。
秋木金旺，先丙暖局，后癸润根；金克木旺，丙火制金为急。
冬木严寒，庚劈甲引丁火，丁暖寒枝为首要；水多木漂，戊土制水救命。

```

**要点**：

+ 春木：喜火温暖 + 水滋润 → 水火既济
+ 夏木：最怕火炎，急须癸水
+ 秋木：金旺克木，须丙火制金
+ 冬木：严寒冻木，须丁火暖枝

### 3_2 🔥 火行总诀

```plain
丙太阳、丁灯烛，春火中和壬水辅；
夏火炎上壬水调候，戊土切忌遮光；
秋火气弱甲木生扶，丙丁相辅暖局；
冬火绝灭喜木生火，土来制水方能存身。

```

**要点**：

+ 丙火：太阳之火，最喜壬水（江湖映日）辅佐
+ 丁火：灯烛之火，最喜甲木（燃料）引燃

### 3_3 🏔️ 土行总诀

```plain
戊土厚土，四季看燥湿：
  春土湿寒丙火解冻，甲木疏土；
  夏土燥热癸水润燥，丙火适度；
  秋土金泄气弱，丙火暖土为先；
  冬土冰冻丙火第一，无丙万物不生。
己土湿柔，夏用癸润燥，冬用丙解冻，
  土厚喜木疏，土薄喜火生。

```

### 3_4 ⚔️ 金行总诀

```plain
庚金顽硬，八月最刚，丁火锻甲木引，丙火佐用；
  有丁无甲常人，有甲无丁平庸，甲丁两透功名显赫。
辛金柔弱，夏火煅金忌猛，壬水润土泥沙己土共生；
  夏辛壬己并用，方显秀气。
秋金喜火锻，夏金怕火熔需水救，冬金寒冻丙火暖局。

```

### 3_5 🌊 水行总诀

```plain
水赖金生流长远，土筑堤防止泛滥；
水火既济最为贵，水土混杂浊乱凶；
四时忌火多水涸，土重水滞不流通；
金死水困，木旺水耗；
阳水身弱穷苦，阴水身弱反贵。

```

## 板块9 · 全书评价与学习建议

### 9_1 ✅ 优点

+ **体系简明**：以日干×月令为经纬，查表式论命，入门门槛低
+ **紧扣自然**：以气候寒暖燥湿为判断依据，符合天人合一思想
+ **实用性强**：直接给出"某日干生于某月，需要什么"的配方式结论

### 9_2 ⚠️ 局限

+ **忽略全局**：对八字整体结构、刑冲合会考虑不足
+ **流于教条**：部分配方过于绝对，需灵活变通
+ **需综合参看**：建议配合《滴天髓》（气势格局）+《子平真诠》（格局法）使用

### 9_3 📚 学习路径建议

```plain
第一阶段：熟读"十干实物说" → 理解十天干本性
第二阶段：背诵"调候总纲口诀" → 掌握四季调候规律
```
