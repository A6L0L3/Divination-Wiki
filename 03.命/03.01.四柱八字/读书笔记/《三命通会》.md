### 2_3 四柱八字排盘框架（卷二）

#### 2_3_1 四柱定位与人生对应关系

| 柱 | 天干 | 地支 | 人生领域 |
| :---: | :---: | :---: | :--- |
| **年柱** | 祖上/童年 | 根基 | 祖业、父母、早年运 |
| **月柱** | 兄弟/门户 | **提纲（最关键）** | 家庭、性格、青年运 |
| **日柱** | **日干=我** | 配偶宫 | 自身、配偶、中年运 |
| **时柱** | 子女 | 归宿 | 子女、晚年运 |

**记忆口诀**：

> 年为根，月为苗，日为花，时为果。

年看祖业月看兄，日看自己时看子。

#### 2_3_2 大运起法

| 性别\年干阴阳 | 阳干年（甲丙戊庚壬） | 阴干年（乙丁己辛癸） |
| :---: | :---: | :---: |
| **男命** | 顺行 | 逆行 |
| **女命** | 逆行 | 顺行 |

+ 大运以**月柱**为起点
+ 每**十年**一运，干支各管五年
+ 起运年龄 = 出生日到下一个（或上一个）节气的天数 ÷ 3

**流年**：每年太岁，天干地支各管半年，以天干为主看吉凶。

#### 2_3_3 胎元与命宫

+ **胎元**：受胎之月，对应该月的干支（一般月柱天干进一位、地支进三位）
+ **命宫**：以生时和生月推算，相当于"命的居所"

## 板块3 · 第二层：十神体系（卷五·核心推演框架）

### 3_1 十神定义（以日干为中心）

> **核心原则**：日干 = "我"，其他七个字与"我"的生克关系 = 十神

| 关系 | 同性（偏/七） | 异性（正） | 含义 |
| :---: | :---: | :---: | :--- |
| **生我** | 偏印（枭神） | 正印 | 庇护、学业、母亲 |
| **我生** | 伤官 | 食神 | 才华、表达、子女 |
| **克我** | 七杀（偏官） | 正官 | 事业、压力、丈夫 |
| **我克** | 偏财 | 正财 | 财富、父亲、妻子 |
| **同我** | 比肩 | 劫财 | 兄弟、朋友、竞争 |

**速记法**（以甲木日主为例）：

```plain
生我：壬水（偏印）癸水（正印）
我生：丙火（食神）丁火（伤官）
克我：庚金（七杀）辛金（正官）
我克：戊土（偏财）己土（正财）
同我：甲木（比肩）乙木（劫财）

```

**通用规律**：

> 同性相生/克 = 偏（无情、激烈）

异性相生/克 = 正（有情、温和）

### 3_2 十神性格与命运特征

| :---: | :--- | :--- | :--- |

| **七杀** | 果断、魄力、威权 | 暴躁、偏激、凶险 | 武职、竞争对手 |

| **正财** | 勤俭、踏实、稳定 | 吝啬、保守 | 妻子、薪水、正业 |
| **偏财** | 慷慨、灵活、人缘 | 浮华、不稳定 | 父亲、投资、横财 |

| **劫财** | 热情、行动力 | 冲动、夺财 | 兄弟姐妹、竞争者 |

### 3_3 十神组合格局（卷五·卷六）

#### 3_3_1 正格（六格为主）

| 格局 | 成立条件 | 成败关键 |
| :---: | :--- | :--- |
| **正官格** | 月令正官透干，日主有气 | 忌伤官、忌刑冲、喜财印辅佐 |
| **七杀格** | 月令七杀，须有制化 | 食神制杀最美，杀印相生次之 |
| **正财格** | 月令正财，身强能任 | 喜食伤生财，忌比劫夺财 |
| **偏财格** | 月令偏财，身旺为佳 | 喜官星护财，忌劫财 |
| **印绶格** | 月令正印，身弱最喜 | 忌财星破印，喜官星生印 |
| **食神格** | 月令食神，身强有财 | 食神生财为上，忌偏印夺食 |

#### 3_3_2 重要变格

| 变格 | 核心特征 |
| :---: | :--- |
| **从格**（从强/从弱） | 日主极旺或极弱，弃命从势 |
| **化气格** | 天干合化成功，日主变性 |
| **专旺格** | 一方之气极盛（曲直、炎上、从革、润下、稼穑） |
| **飞天禄马** | 特殊取贵方式，以冲合得禄 |
| **倒冲禄** | 无禄而冲出禄神 |

#### 3_3_3 格局成败的"病药论"

> **有病方为贵，无伤不是奇。**

格局有"病"（缺陷），有"药"（救应）反成大格。
如：官星被伤 → 有印星制伤官 → 伤官佩印 → 大贵之格。
