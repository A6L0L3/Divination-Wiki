## 板块1 · 书籍定位与核心价值

《千里命稿》是民国命理大师**韦千里**（1911—1988）于1935年完成的代表作。成书时他年仅24岁，已名噪上海命理界，与袁树珊、徐乐吾并称"民国命学三大家"。

这本书原本是韦千里主讲八字培训班的讲义，语言通俗、体系完整，被公认为**命理入门与进阶的必读经典**。韦千里在自序中开宗明义：本书旨在解决传统命理典籍"艰深难懂、体系混乱"的痛点，将纷繁复杂的五行、十神、格局、神煞等概念进行归纳整理，形成一套由浅入深、逻辑连贯的知识体系。

他主张命理是"科学而非玄学"，强调通过五行生克的理性分析来揭示命运的规律性，而非依赖神秘主义。

**这本书的真正价值不在于"算命"，而在于它提供了一套分析人生格局、性格倾向与时机节奏的系统方法论。**

### 1_1 韦千里其人：命理大师的自我印证

韦千里本人的命格即是一个极佳的研究案例。据分析，他的八字属于"润下格"，全局水势极旺。
水旺之人通常聪明、转数快、善于变通，这与他后来从事命理师职业高度契合——润下格的人口才好、善传播，韦千里不仅替人批命，还开班授徒、著书立说，将命理知识发扬光大，完全发挥了"水"那种流动与传播的特质。
他的八字用神取舍清晰，水木相生、伤官配印，所以写出的命理文章深入浅出，不故弄玄虚，极其"贴地气"，这也是《千里命稿》广受欢迎的内在原因。

### 1_2 历史的验证：名人命例的实证精神

韦千里在书中收录了蒋介石、梅兰芳、吴佩孚、阎锡山、宋子文、章太炎、杜月笙、孙传芳、荣宗敬等近百位名人命例，理论与实证并重。
以蒋介石为例，其八字为庚金日主，生于秋季，金气特别旺盛，命格为"庚金伤官"。韦千里分析其大运走势：早年己酉、戊申两运金太旺，火的力量被压制，蒋感怀才不遇；
丁未运（1911—1920）火势始萌，正是"潜龙勿用"的积累期；丙午运（1921—1930）火势大爆发，金火达到平衡，蒋迎来人生巅峰——北伐成功、统一南北；
甲辰运（1941—1950）出现"伤官见官"的忌讳，1949年失去大陆政权退守台湾，命理与历史轨迹高度吻合。

这种"以史验证命理"的实证态度，是《千里命稿》区别于其他命理书籍的核心品质。

## 板块3 · 核心理论深度解析

### 3_1 四柱八字：命盘的底层架构

八字论命以**出生日的天干（日元/日主）**为论命中心，其余七字皆围绕日元展开生克关系。四柱构成如下：

+ **年柱**：出生年份的干支（以立春为分界）
+ **月柱**：出生月份的干支（以节气为分界，非农历初一）
+ **日柱**：出生日期的干支
+ **时柱**：出生时辰的干支

> **关键提醒**：月柱的推算不以农历月份为准，而是以**节气**为分界线。比如正月建寅，但必须过了"立春"才算寅月。这是初学者最容易出错的地方。韦千里在"起例问答"中反复强调：排盘第一步不是看日历，而是查节气表。

#### 3_1_1 推月法详解

韦千里在"起月法"中给出了完整的五虎遁口诀：

| 年干规律 | 正月天干 | 口诀 |
| --- | --- | --- |
| 甲己之年 | 丙寅 | 甲己之丙作首 |
| 乙庚之年 | 戊寅 | 乙庚之岁戊为头 |
| 丙辛之年 | 庚寅 | 丙辛必定寻庚起 |
| 丁壬之年 | 壬寅 | 丁壬壬位顺行流 |
| 戊癸之年 | 甲寅 | 更有戊癸何方觅，甲寅之上好追求 |

**月柱取法的三个关键判断**：

1. 在本月节令后生者 → 以本月所遁干支排月柱
2. 在本月节令前生者 → 以上月所遁干支排月柱
3. 在本月下一节令前生者 → 以下月所遁干支排月柱

**十二月节令对照表**：

| 月份 | 节令 | 月份 | 节令 |
| --- | --- | --- | --- |
| 正月 | 立春 | 七月 | 立秋 |
| 二月 | 惊蛰 | 八月 | 白露 |
| 三月 | 清明 | 九月 | 寒露 |
| 四月 | 立夏 | 十月 | 立冬 |
| 五月 | 芒种 | 十一月 | 大雪 |
| 六月 | 小暑 | 十二月 | 小寒 |

> **实操案例**：癸卯年三月初九日卯时生，万年历载明该年三月初九日**辰时**清明，卯时在辰时之前，犹未清明，应以二月所遁干支排月柱，即**乙卯月**，而非丙辰月。这种"差一个时辰定错月柱"的错误，是实战中最常见的低级失误。

### 3_2 十天干：阳刚阴柔的气质密码

韦千里在《天干篇》中开宗明义，对传统命理中将天干简单类比为具体物象的做法提出质疑："甲为栋梁，乙为萝藤，丙为太阳，丁为灯烛……不可信也。"他认为十干的核心区别在于**"阳刚阴柔，阳健阴顺"**——阳干气旺而难从，阴干质坚而易化。

### 3_3 十二地支与人元藏干：天干在地支中的家

地支不是简单的"容器"，而是天干能量的储藏所和发源地。韦千里在《人元篇》中指出："人元者，地支所藏之天干也。"天干为天元，地支为地元，地支中所藏天干之气，便是人元。

**三类地支的本质区别**：

+ **四正位**（子午卯酉）：帝旺之地，气最专一，只藏本气一干（午稍特殊，兼藏己土）
+ **四生位**（寅申巳亥）：长生之处，生气流动，各藏三干（本气+长生之气+余气）
+ **四库位**（辰戌丑未）：墓库之地，万物归藏，各藏三干（本气+墓气+余气）

> **实战要点**：判断日元强弱时，地支藏干的根气权重不同——本气根最强，中气根次之，余气根最弱。一个甲木日主，地支见寅（本气甲木）为"禄根"，力量最强；见亥（中气甲木）为"长生根"，力量次之；见未（余气乙木）为"微根"，力量最弱。三者的帮扶力度天差地别。

### 3_4 十神系统：人际与性格的密码本

十神是五行生克关系的"代名词"，以日元为参照，根据阴阳属性的不同，分为十种关系：

| 关系 | 阳见阳/阴见阴 | 阳见阴/阴见阳 |
| --- | --- | --- |
| **生我者** | 偏印（枭神） | 正印 |
| **我生者** | 食神 | 伤官 |
| **克我者** | 七杀 | 正官 |
| **我克者** | 偏财 | 正财 |
| **同我者** | 比肩 | 劫财 |

**十神不是抽象符号，而是性格与行为的映射：**

+ **正官+正印**：正直守规矩，适合体制内发展
+ **伤官+劫财**：叛逆创新，但易冲动破财
+ **食神制杀**：以才华驾驭压力，成就事业
+ **财星破印**：学历或健康易受损

#### 3_4_1 十神性格深度解读

| 十神 | 正面特质 | 负面特质 | 现代职业映射 |
| --- | --- | --- | --- |
| **正官** | 正直、责任感、自律 | 保守、刻板、怕担责 | 公务员、法官、行政管理 |
| **七杀** | 果断、魄力、执行力 | 暴躁、冲动、不计后果 | 军警、创业、高压行业 |
| **正印** | 慈爱、稳重、好学 | 依赖、迟钝、缺乏变通 | 教师、学者、宗教人士 |
| **偏印** | 专注、钻研、洞察力 | 孤僻、偏执、不合群 | 研发、冷门学科、技术专家 |
| **正财** | 踏实、节俭、稳重 | 吝啬、保守、缺乏冒险精神 | 会计、金融、传统商业 |
| **偏财** | 慷慨、灵活、社交能力强 | 挥霍、投机、不够踏实 | 投资、贸易、销售 |
| **食神** | 温和、创意、享受生活 | 懒散、放纵、缺乏进取心 | 艺术、餐饮、创意产业 |
| **伤官** | 聪明、叛逆、创新能力 | 傲慢、口舌、不服管教 | 设计、演艺、自由职业 |

| **劫财** | 热情、仗义、行动力强 | 冲动、好斗、破财风险 | 竞争性行业、销售 |

### 3_5 日元强弱：整个命理分析的基石

韦千里将日元强弱分为**三个层次**，判断标准极为清晰，这是全书最具操作性的部分之一。

**身强的三种程度：**

+ **最强**：得令（月令旺相）+ 多帮扶（四柱多同五行）
+ **中强**：不当令，但多帮扶；或仅得令而少帮扶
+ **次强**：不当令、少帮扶，但地支得气（临官、帝旺等）

**身弱的三种程度：**

+ **最弱**：失令 + 多克泄
+ **中弱**：当令但多克泄，或失令但少克泄
+ **次弱**：不失令、少克泄，但地支无气

**身强喜"抑"，身弱喜"扶"：**

```plain
身强 → 喜受克（官杀）、被泄（食伤）、被分（财星）、气衰
身弱 → 喜受生（印星）、得助（比劫）、气盛

```

> **实操要点**：判断强弱时，韦千里特别强调"得时、得地、得势"三要素。得时看月令，得地看地支根气，得势看天干帮扶。三者权重不同——**月令为纲，权重最大**。具体来说：月令决定日主当前季节的"基本面"，地支根气决定日主的"储能"，天干帮扶决定日主的"外力支援"。三者俱备为最强，三者皆无为最弱，中间组合则对应中强、次强、中弱、次弱。

### 3_6 用神选取：命局的"药"与"靶"

用神是《千里命稿》全书最核心的概念。韦千里说："用神者，命中最需要之物也。"用神的本质是**平衡命局五行的那个关键元素**——日主太冷需要火来暖，太热需要水来润，太弱需要印比来扶，太强需要官杀来抑。

#### 3_6_1 三大用神法则

| 用神类型 | 适用场景 | 举例 |
| --- | --- | --- |
| **扶抑用神** | 日主过强或过弱，需平衡 | 身强用官杀克，身弱用印比帮 |
| **调候用神** | 命局寒暖燥湿失衡 | 冬生（水旺寒冷）需火暖局，夏生（火旺燥热）需水润局 |
| **通关用神** | 两五行对峙相克 | 木土交战用水通关，火金相克用土通关 |

#### 3_6_2 调候用神深度体系

调候是八字命理中一个极为重要的高阶论断体系，以《穷通宝鉴》为集大成之作。其核心在于分析命局整体的"寒、暖、燥、湿"状态，并找出能为全局带来生机的关键五行。命理界有句铁律：**"调候为急，格局次之，平衡为后。"** 天气都不合适，再谈富贵都是空谈。

| 气候状态 | 对应月令 | 主要问题 | 核心调候用神 |
| --- | --- | --- | --- |
| **寒** | 冬季（亥、子、丑月） | 天寒地冻，万物收敛 | 火（丙火为首选） |
| **热** | 夏季（巳、午、未月） | 火炎土燥，万物枯槁 | 水（壬水为首选） |
| **燥** | 秋季（戌月）、夏季（未月） | 金燥土烈，缺乏生机 | 水（癸水为首选） |
| **湿** | 春季（辰月）、冬季（丑月） | 水冷土湿，阳光不暖 | 火（丙丁火并用） |

**调候取用实战口诀：**

+ 冬生（亥子丑）：首选丙火（太阳普照），次取丁火（炉火暖身），再次为地支巳午火
+ 夏生（巳午未）：首选壬水（江河湖海），次取癸水（雨露甘霖），再次为地支亥子水
+ 春季木旺水多：若无火暖局除湿，则需以火为调候用神
+ 秋季金旺土燥：若全局缺水，则需以水为调候用神

**十二月调候用神速查表**：

| 月份 | 调候需求 | 首选用神 | 说明 |
| --- | --- | --- | --- |
| 寅月 | 犹寒，需火暖局 | 丙火 | 初春余寒未尽 |
| 卯月 | 渐暖，仍需火 | 丙火 | 仲春木旺 |
| 辰月 | 土旺，需甲木疏土 | 甲木+癸水 | 季春 |
| 巳月 | 火旺，需水调候 | 壬水 | 初夏 |
| 午月 | 极热，急需水 | 壬水 | 仲夏最热 |
| 未月 | 燥热，需水润土 | 癸水 | 季夏 |
| 申月 | 渐凉，需火暖金 | 丙火 | 初秋 |
| 酉月 | 金旺，需火炼金 | 丙火 | 仲秋 |
| 戌月 | 燥土，需水润泽 | 壬水 | 季秋 |
| 亥月 | 初寒，需火暖局 | 丙火 | 初冬 |
| 子月 | 寒极，急需火 | 丙火 | 仲冬最寒 |
| 丑月 | 湿寒，需火暖土 | 丙火+戊土 | 季冬 |

> **实战洞察**：金和木是对温度变化最敏感的五行。庚金生于冬月，水冷金寒，若无火炼金，再旺的财官也担不起来；甲木生于夏月，火炎木燥，若无水解炎，再多的水（印星）也只是一潭死水。调候用神有时甚至超越格局用神——一个调候得宜的普通格局，往往比调候失衡的"好格局"活得舒坦。

#### 3_6_3 用神"健全度"评判体系

韦千里在"八格取用补缀"中提出了用神健全度的概念，这是很多初学者忽略的关键细节：

**用神之需要（七个条件）**：

1. **有势有务**：如用甲木，适当春月（得时令之势）
2. **有授助**：如用甲木，见乙木或癸水之助（有同类或生我者帮扶）
3. **在干得气**：如用甲木，支见寅卯（地支有根）
4. **在干不见克合**：如用甲木，无庚克己合（不被破坏）
5. **在支得干生助**：如用巳火，得甲木资生、丙火帮助
6. **在支无刑冲合害**：如用巳火，不见亥冲寅刑
7. **既见冲克，而有解救**：如用甲木受庚克，幸有乙木合庚，或丙火克庚

**用神之区别（三个层次）**：

+ **健全用神**：用神无克合刑冲，坐禄旺之地，力量充沛
+ **相神**：用神力量不足时，生助用神的字叫相神；用神受刑冲克合时，解救用神的字也叫相神。相神与用神有同等重要性
+ **格局相兼**：如以财为格，用神也属财，格局与用神合二为一，其重要性更甚

#### 3_6_4 八格取用速查表

| --- | --- | --- |
| **正官格** | 印星化官生身 | 财星生官，或食伤制官过旺 |
| **七杀格** | 印星化杀，比劫帮身 | 食神制杀 |
| **正印格** | 印本身为用 | 财星破印 |
| **偏印格** | 偏印可为用 | 财星制枭 |
| **正财格** | 比劫帮身担财 | 食伤生财 |
| **偏财格** | 比劫分财 | 食伤生财 |
| **食神格** | 印星制食护身 | 财星流通 |
| **伤官格** | 印星制伤（伤官佩印） | 财星泄伤 |

#### 3_6_5 八格"太过"与"不及"对照表

韦千里在格局篇中详细分析了每种格局在什么情况下会"太过"或"不及"，这是判断格局层次高低的关键：

| 格局 | 太过（偏枯） | 不及（受损） |
| --- | --- | --- |
| **正官格** | 官星得令且众多，日主衰弱不堪 | 遇刑冲破害，官星被伤 |
| **七杀格** | 杀太重，身太轻，不见食伤 | 日干弱，财党杀而无制 |
| **正印格** | 印重又得令，日弱而财轻 | 遇刑冲破害 |
| **偏正财格** | 财得令而又众多，日主衰弱 | 财旺身弱，又多伤食泄身 |
| **伤食格** | 伤食太重，日主太轻无印 | 身强杀浅，制杀太过无财解 |

> **深度警告**：韦千里特别强调——上述表格只是框架，绝非死板公式。他原话是"一命有一命之情形，非权衡通变不为功。拘泥拗执，则不免毫厘千里之弊"。用神必须结合全局五行流通、干支配合、大运走势综合判断，切忌机械套用。比如同样是"正官格身弱"，有的需要印星化官生身，有的却需要比劫帮身抗官——关键在于看命局中哪个五行是真正的"瓶颈"。

### 3_7 格局体系：命局的整体架构

韦千里将格局分为**正格（八格）**与**外格（变格）**两大类。

#### 3_7_1 正格取格优先级

正格以月令为纲取格：

1. 月支本气透于天干 → 取为本格
2. 本气未透，透出月支所藏之神 → 取该神为格
3. 本气与藏神均未透 → 以月内人元轻重较量，择一有力者为格
4. 比劫不能取格（禄刃不在八格之内）

#### 3_7_2 外格（变格）详解

外格不拘月令，以全局气势取用，核心特征是"从"：

**弃命从格（三种）**：

+ **从财格**：满局财星，日主无根 → 喜食伤生财、财运，忌比劫印星
+ **从杀格**：满局七杀，日主无根 → 喜财杀运，忌比劫食伤印星
+ **从儿格**（从食伤）：满局食伤 → 喜食伤财运，忌印星

**专旺格（五种）**：

+ **曲直格**（木旺）：寅卯辰会木或甲乙木极旺
+ **炎上格**（火旺）：巳午未会火或丙丁火极旺
+ **润下格**（水旺）：亥子丑会水或壬癸水极旺
+ **稼穑格**（土旺）：辰戌丑未土极旺
+ **从革格**（金旺）：申酉戌会金或庚辛金极旺

**化气格（五种）**：

+ 甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火
+ 成立条件极苛刻：合化双方要有根气，地支要有化神的旺位，且不能有克制化神的五行

> **外格口诀**："从则吉，逆则凶。"判断关键看日主是否还有一丝生扶——若有微根微印，便不从，是为"假从"，最是苦恼。假从格的人往往"想从从不了，想自立立不住"，人生充满纠结和反复。

### 3_8 大运与流年：时间的维度

这是《千里命稿》最具实操价值的部分。韦千里指出："命好不如运好。"

#### 3_8_1 大运推算规则

+ 男命年干为阳、女命年干为阴 → 大运**顺行**
+ 男命年干为阴、女命年干为阳 → 大运**逆行**
+ 起运年龄：从出生日到最近"节"的天数，每三日折合一岁（零头按一日折合四个月推算）

#### 3_8_2 大运与流年的分工

+ **大运定基调**：十年一运，决定这十年的大方向
+ **流年定应期**：具体哪一年发生什么事，由流年引动
+ **月建定微应**：具体哪个月份应验，由月建决定

> **实操技巧**：大运天干主导前五年，地支主导后五年。判断吉凶的核心逻辑是——**大运流年扶助用神则吉，克制用神则凶**。

#### 3_8_3 流年断法三条核心法则

韦千里在《流年篇》中给出了判断流年吉凶的方法：

1. **看流年是否触动大运**：流年与大运天干相克，或地支有冲合刑穿，往往会激发大运力量，吉凶加倍
2. **看流年引动命局何物**：命局中有藏而待用的天干，大运没引出来，流年却引出来了，这件事就在这一年发生
3. **看流年是否命、运、岁三者同途**：如果命局、大运、流年三者都偏向同一五行方向，这一年就是"应期"，好事成真，坏事爆发

> **韦千里的比喻**：大运如江河，流年如波涛。河水向东，是总方向（大运基调）；但水面有浪，忽高忽低（流年变化）。运吉年凶，如逆水行舟，小波折而已；运凶年吉，如暗夜烛光，片刻温暖，难改大局。

#### 3_8_4 "岁运并临"的深度解析

当流年干支与大运干支完全相同时，称为"岁运并临"。古人有"岁运并临，不死自己死他人"的说法，但韦千里的实证精神告诉我们：**吉凶全凭命局喜忌而定**。

+ 若并临干支为命局**喜用神** → 双喜临门，升职添丁，重大成功
+ 若并临干支为命局**忌神** → 凶险倍增，破财伤身
+ 若并临干支为**闲神** → 影响较轻，但仍有伏吟之象

**岁运并临落在不同宫位的应事**：

+ 并临年柱：祖业变动、长辈大运、根基动摇
+ 并临月柱：事业环境剧变、父母重灾（月令为提纲，最怕冲破）
+ 并临日柱：婚姻感情剧烈波动、自我认知重塑
+ 并临时柱：子女重大转折、晚年运势颠覆

#### 3_8_5 经典案例：孙传芳的用神溃败

韦千里在"应运篇"中收录了军阀孙传芳的命造（乙酉 庚辰 壬寅 巳酉），这是一个极具教学价值的案例：

+ 日主壬水，生于辰月，取用神为丙火
+ 20—30岁走丁丑运（火土旺），1905年起用神得助，派赴日本陆军学习，一路升迁
+ 35—40岁走丙子运，丙运火势正旺，1922—1925年称雄东南，拥兵十余万
+ 40—45岁子运水旺灭火，1926年败于北伐军，一蹶不振
+ 50岁后走亥运，亥运合寅夺丙，1935年乙亥年逢十月亥建，**三亥交攻，用神溃败**，11月13日卒

这个案例完美诠释了"用神有力则兴，用神溃败则亡"的核心逻辑。

#### 3_8_6 经典案例：程霖生的"时效性"

另一个精彩案例是民国地产大亨程霖生（乙木日主，巳月伤官格）。原局火土虽旺，但日干被癸亥印星包围，印星有力又亲近日干，家庭出身好，自己也在地产与收藏领域大获成功。
丁酉大运、丁卯年之前，几乎所向披靡。但42岁进入戌运后，财重身轻，投机黄金失败，三年间破产清算，58岁进己亥大运同年去世。
韦千里评曰："明哲保身，程君正可如孔子之知命，而永自韬养矣。"——这就是格局的"时效性"，好运不会永远持续，知命才能保身。

#### 3_8_7 经典案例：夭折婴儿的"气浊神枯"

韦千里还收录了一个令人警醒的案例：某婴儿出生后一个月即夭折。命局正印三透天干，五行土多达六个却不成局，完全没有木来疏土。韦千里指出："重重厚土埋，藏脆嫩之金。五行无木，未得疏扬之利。一重午火，缺木之生，多土之晦，更夫能为力。《滴天髓》所谓**气浊神枯**者是也。"第一个流年戊辰，小运己亥，土上加土，旺上加旺，难免夭折。

> **深度启示**：这个案例告诉我们，五行严重失衡的命局，即使有"杀印相生"的表象，本质仍是"气浊神枯"。判断命局好坏，不能只看表面组合，更要看五行是否流通有情。

### 3_9 评断九步法：完整的论命流程

韦千里在《评断篇》中给出了实战论命的完整步骤，这也是全书的方法论精华：

```plain
第一步：排盘定式 → 八字排定，大运起好，检查有无遗漏
第二步：看月令定格 → 月支本气透出什么，定普通格局
第三步：看日主强弱 → 得时、得地、得势，判强弱虚实
第四步：找用神 → 格局立定，择通关/调候/扶抑之字
第五步：看用神是否有力 → 是否坐禄旺，有无冲克合化
第六步：看配合有情 → 十神组合是否得当，五行是否流通
第七步：看大运走势 → 大运扶用神还是帮忌神
第八步：看流年应期 → 大运定基调，流年定事发，月建定微应
第九步：综合论断 → 涵盖富贵贫贱、六亲婚姻等

```

> **韦千里的评断标准原文**："看强弱以日干为主，以多寡、盛衰、失时、得令为标准；定格局以月支为标准；取用神以助强扶弱为标准；论喜忌以用神为标准；查岁运以喜忌为标准；推六亲以四柱六神为标准；评性情以五行用神为标准；断事业以用神及喜忌为标准。"

### 3_10 实战案例拆解：正官格的完整分析

韦千里在评断篇中给出了一个完整的示范案例（陆姓乾命：癸未 甲子 丙戌 己亥）：

**第一步·看强弱**：丙火死于冬，亥子癸三水既得其令又兢来克，未戌己土虽能制水，但本身先泄丙火之气，只有月上甲木生丙。全局抑者太多、扶者太少，故以**弱**论。

**第二步·定格局**：丙生子月，干透癸水，为**正官格**。

**第三步·取用神**：丙既弱，必须生扶。月上甲木泄水之有余、生火之不足，取甲木为用神，即"**官格用印**"。

**第四步·论喜忌**：既用甲木，自喜木火助用助身，不畏土之泄火、水之克火（盖土有木制、水有木当），但亦非所喜。最忌**金**——金生水助虐，且克木伤用。

**第五步·排岁运**：

+ 1岁癸亥运（忌神运，一派水乡）→ 稚年多病
+ 11岁壬戌运（忌神用神各半）→ 平平无奇
+ 21岁辛酉运（忌神运，用神甲木受克）→ 蓬飘萍泛，南北东西
+ 31岁庚申运（忌神运）→ 奔波劳碌
+ 41岁己未运（伤官得旺，破格）→ 部分年份有起色
+ 51岁戊午运（午冲月令子水）→ 小有作为但须谨慎

这个案例展示了从排盘到论断的完整逻辑链，每一步都有明确的依据，没有任何"玄学跳跃"。

### 3_11 实战案例拆解：女命正官格的取用

韦千里还给出了一个女命案例（王姓坤命：己亥 癸酉 甲辰 丙寅）：

**强弱**：甲生酉月失令，又多火土之克泄，本当以弱论。然长生于亥，胎于酉，得禄于寅，地支有气，尚非至弱者也。

**格局**：甲生酉月，为正官之格。

**用神**：官印财食俱全，惟己年癸月，地位接近，财印相克，为美中不足，故取酉中辛金正官以为用。盖财生官，官生印，五行六神，因此不悖矣。

**岁运**：三岁起运，初走甲戌乙亥，庇阴丰裕，故童境不恶。二十岁戊干流年，偏财帮夫，于归极利。二十三岁丙子运，丙为食神，子为正印，迭获弄璋之庆，家道日昌。三十三岁行丁火伤官运，幸有印以制之，然辛未年夫病越七月，亦云险矣。三十八岁丑运为财，门庭焕彩，夫子皆辉。

> **深度解读**：这个女命案例展示了"财印相克"的微妙处理。年干己土（财）与月干癸水（印）紧贴相克，是美中不足。但取正官为用，形成"财生官、官生印"的流通链条，化解了财印直接交战的矛盾。这正是韦千里"权衡通变"思想的精髓——不是简单地"财坏印"就断凶，而是看全局能否形成良性循环。

## 板块4 · 补充精要：刑冲合害

《补充篇》是韦千里对干支互动关系的精要总结，这部分看似简单，实则是判断"用神是否真有力"的关键。

### 4_1 天干五合

| 合化 | 条件 |
| --- | --- |
| 甲己合土 | 需辰戌丑未月 |
| 乙庚合金 | 需巳酉丑申月 |
| 丙辛合水 | 需亥申子辰月 |
| 丁壬合木 | 需亥卯未寅月 |
| 戊癸合火 | 需寅午戌巳月 |

> 合化成功需"两干紧贴 + 地支有化神旺位"，否则只论"合绊"（双方均减力）。比如甲己合土，如果地支没有辰戌丑未土旺之地，甲己只是"绊住"彼此，并没有真正化成土。

### 4_2 地支六合、三合、三会

+ **六合**：子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合土 → 主和合、牵绊
+ **三合**：申子辰合水、亥卯未合木、寅午戌合火、巳酉丑合金 → 力量集结，比六合更强
+ **三会**：寅卯辰会木、巳午未会火、申酉戌会金、亥子丑会水 → 比三合更强的"联合作战"

### 4_3 地支六冲

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲 → 主变化、破散、冲动

> **实用判断**：用神逢冲不利，忌神逢冲反吉。比如用神是午火，遇到子年子月，午火被冲，这一年必然不顺；但如果忌神是子水，遇到午年反而是"冲去忌神"，反而转好。这就是"冲"的两面性——不能一见冲就断凶，关键看冲的是谁。

### 4_4 地支相刑

+ **三刑**：寅巳申三刑（无恩之刑）、丑戌未三刑（恃势之刑）、子卯相刑（无礼之刑）
+ **自刑**：辰辰、午午、酉酉、亥亥自刑

> **刑的实战意义**：刑比冲更"暗"，冲是明面上的冲突，刑是暗中的消耗和折磨。用神遇刑，往往是慢性问题——健康慢慢变差、人际关系暗中恶化、事业逐步受阻。

## 板块5 · 神煞体系：点睛之笔

韦千里在《神煞篇》中精选了最具实用价值的几大神煞。他强调：**神煞只是加分扣分项，格局清、用神有力，此命已有七八分，神煞锦上添花或减分而已。**

### 5_1 天乙贵人：逢凶化吉的守护星

**口诀**：甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢虎马，此是贵人方。

| 日干/年干 | 贵人地支 |
| --- | --- |
| 甲、戊、庚 | 丑、未 |
| 乙、己 | 子、申 |
| 丙、丁 | 亥、酉 |
| 壬、癸 | 卯、巳 |
| 辛 | 寅、午 |

> **实战要点**：天乙贵人是最尊贵的吉神，主人缘佳、遇困难有贵人相助。但贵人若恰好是命局中的忌神，反主因他人之事受牵累——"好心办坏事"型的贵人。

### 5_2 驿马：奔波与机遇的风向标

**口诀**：申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳。

| 年支/日支 | 驿马地支 |
| --- | --- |
| 申、子、辰 | 寅 |
| 寅、午、戌 | 申 |
| 巳、酉、丑 | 亥 |
| 亥、卯、未 | 巳 |

> **实战要点**：驿马逢冲（如申为马星，再见寅），奔波劳碌，动中求财。驿马逢合（如申马见巳），想动也难。驿马带财官，动中得利；带七杀，动中有险。

### 5_3 桃花（咸池）：情缘与审美放大器

**口诀**：寅午戌见卯，申子辰见酉，巳酉丑见午，亥卯未见子。

| 年支/日支 | 桃花地支 |
| --- | --- |
| 寅、午、戌 | 卯 |
| 申、子、辰 | 酉 |
| 巳、酉、丑 | 午 |
| 亥、卯、未 | 子 |

> **实战要点**：桃花坐正财正官，主因婚姻致富，容颜秀丽；桃花坐比劫，则多因酒色破财；桃花在时柱，称"墙外桃花"，异性缘重，晚年须防情劫。韦千里特别指出：桃花须看喜忌，若桃花为用神且得位，反主才艺超群，靠人缘成功。

### 5_4 阳刃（羊刃）：极端力量的化身

**查法**：以日干为主，专看阳干。

| 日干 | 阳刃地支 |
| --- | --- |
| 甲 | 卯 |
| 丙、戊 | 午 |
| 庚 | 酉 |
| 壬 | 子 |

> **实战要点**：阳刃是日干帝旺之地，力量极猛。身弱遇刃，如虎添翼；身旺逢刃无制，血光破财。阳刃逢冲（如卯刃见酉），最为凶险，主意外血光。

### 5_5 神煞应用三阶心法

1. **快速定位**：先看命局有无天乙、文昌、阳刃、桃花等标志性神煞，预判天赋、贵人、性格刚柔及感情倾向
2. **结合岁运**：观测神煞被引动的具体应期。如流年地支与命局神煞产生合、冲，往往该年发生相关主题事件
3. **融入格局**：神煞与格局体系融合判断。例如"建禄格+阳刃驾杀"成格，其富贵层次远超单一神煞论

> **核心原则**：神煞为喜用是"锦上添花"，为忌神是"好心办坏事"。吉神落空亡绝地，能量微弱；凶煞为喜用，也可能是"以毒攻毒"。

## 板块6 · 六亲论断：人伦关系的命理映射

韦千里在《六亲篇》中开宗明义："人伦关系，皆在干支生克中显现。"他特别指出旧论六亲对应多有谬误，并提出了自己的修正体系。

## 板块8 · 富贵吉寿与贫贱凶夭：终极评判标准

全书最后两篇《富贵吉寿篇》与《贫贱凶夭篇》是韦千里的终极归纳。学完格局、行运、神煞、六亲，最终要给出一句判断：这个命好不好？

### 8_1 好命的根本条件

韦千里将好命标准归纳为八个字：**"用神有力，配合有情。"**

+ **用神有力**：通关调候那个字，在命局中坐禄旺之位，不受冲克，不被合化
+ **配合有情**：十神之间形成好的组合——官印相生、财官相生、食神生财、杀印相生……五行流通，一气呵成

### 8_2 富贵的标志

**富的条件**（财为养命之源）：

+ 财要有源头（食伤生财）、有护卫（官星护财或有库收财）
+ 财星透干有库，多主大富；财藏支无伤，主稳中有积
+ 身旺财旺，有伤食或有官杀

**贵的标志**（官为荣身之本）：

+ 官星清透（一位最好）、有印护官、不受伤
+ 官星坐禄，官有根基；印星护官，官有威严
+ 官杀混杂而无取清者，贵气减损

### 8_3 吉寿的根基

**吉**（平安顺遂）：命局五行平衡，寒暖燥湿适中，无冲无战。吉命不一定大富大贵，但一生少灾少难，平安是福。

**寿**（根基稳固）：核心在印星与日主之根。印星为生气之本，凡长寿之人，多是印星不伤或有根气贯通；日主有根，不致虚浮。

### 8_4 贫贱凶夭的根源

| 类型 | 核心特征 |
| --- | --- |
| **贫** | 财为忌神无制，或财星被比劫夺尽，或财星无源枯竭 |
| **贱** | 官星受破损，格局不清；官杀混杂无制，伤官见官而无救 |
| **凶** | 格局中有不可解的刑冲，或七杀无制攻身，意外灾祸 |
| **夭** | 日主无根，印星受损严重，或命局中冲战激烈，精气神耗散 |

> **韦千里的结语**："富贵贫贱，吉凶寿夭，皆命局五行配合之结果。知命者，知天命而尽人事。命佳者当努力以副天心，命蹇者当修德以回造化。"

## 板块9 · 现代延伸：如何落地应用

### 9_1 自我认知工具

将《千里命稿》的十神体系作为**性格分析框架**，而非宿命论标签：

+ **分析日元强弱** → 了解自己的抗压能力与决策风格（身强的人适合正面硬刚，身弱的人适合借力打力）
+ **分析十神配置** → 识别天赋优势与行为盲点（伤官旺的人适合创意行业但需注意口舌，正官旺的人适合管理岗位但需注意保守）
+ **分析用神喜忌** → 找到适合的发展方向与环境（用神为火的人适合南方、适合火热行业）

### 9_3 学习路径建议

结合多位命理师的学习经验，推荐以下四阶段进阶路线：

#### 9_3_1 第一阶段：筑基与排盘（1—3个月）

+ **核心教材**：《千里命稿》"起例问答"和"天干地支篇"
+ **任务**：手排100个八字（严禁依赖软件），对刑冲合害形成肌肉记忆
+ **检验标准**：拿到任意出生时间，能在10分钟内手排出四柱和大运

#### 9_3_2 第二阶段：格局框架植入（3—6个月）

+ **核心教材**：《子平真诠》（沈孝瞻著，徐乐吾评注本）
+ **辅助教材**：《中国命理学史论》（陆致极著，用于理解古人的逻辑原点）
+ **任务**：学会定格局、论成败、辨高低
+ **避坑**：此阶段严禁看《穷通宝鉴》，容易乱了阵脚

#### 9_3_3 第三阶段：气血灌注与调候（6—12个月）

+ **核心教材**：《滴天髓》（任铁樵注本）——先读"天道""地道""人道"三章建立哲学观，再挑案例看
+ **辅助教材**：《穷通宝鉴》（徐乐吾评注本）——在《滴天髓》之后介入，学会看寒暖燥湿
+ **任务**：从"看图识字"进阶到"看动画片"，理解五行流通与气势

#### 9_3_4 第四阶段：实战积累（持续终身）

+ 从自身和亲友八字入手，建立命例档案库
+ 积累100例以上后再尝试对外论断
+ 参考《三命通会》当辞典翻阅，查神煞和杂格

### 9_4 风险提示

+ **避免机械套用**：书中每个应验结论前必有数步推导，跳过原理直抄案例等于"只记答案不学公式"
+ **避免宿命论陷阱**：韦千里本人强调"命为先天格局，运为后天轨迹"，命理是参考工具而非人生枷锁
+ **重视动态性**：大运流年与原局的互动是动态的，仅凭日主强弱下结论是最常见错误
+ **警惕"万能论命"**：没有任何一个命理师能100%准确，命理提供的是概率性的趋势参考，不是确定性预言

## 板块10 · 精华摘录与深度点评

> **"凡人秉命，必有一格。八字之有格局，如人之有姓名。"**

点评：格局不是"好不好"的标签，而是命局的结构性描述。有格者未必富贵，无格者未必贫贱，关键在于**格局是否成、用神是否有力**。就像一个人有名有姓不代表有成就，关键看他怎么活。

> **"用神者，命中最需要之物也。"**

点评：用神是命局的"药"。病（偏枯）找到了，药（用神）选对了，命局就平衡了。选错用神，全盘皆错。韦千里进一步强调，用神不仅要"选对"，还要"有力"——一个被冲克合害的用神，就像一颗被虫子蛀了的种子，再好的品种也发不了芽。

> **"从则吉，逆则凶。"**

点评：外格的逻辑与正格完全相反——正格追求平衡，外格追求顺从。当某种五行气势强大到不可逆转时，越平衡越倒霉，越顺从越好运。这其实蕴含着一种深刻的人生智慧：**当大势不可违时，顺势而为比逆势挣扎更明智。**

> **"日干旺甚无依，若不为僧即道。"**

点评：这是韦千里在喜忌篇中的论断。身旺无依的人，要么大富大贵（有依托），要么出家修道（无所求）。现实生活中，很多身旺无依的人选择了"极简生活"或"献身某种信仰/事业"，其实都是这种命理逻辑的现代表达。

## 板块11 · 总结

《千里命稿》之所以能成为命理学的"教科书式"著作，在于它做了三件前人没有做好的事：

1. **体系化**：从基础概念到实战技巧一气呵成，奠定了现代命理书的"看强弱→定格局→取用神→论岁运"标准范式
2. **通俗化**：摒弃旧籍晦涩文风，条理清晰、深入浅出，零基础也能读懂
3. **实证化**：收录近百位名人命例，理论与实证并重，每一个论断都有完整的推导链条

### 11_1 读书的三重境界

+ **术**：掌握推算技法（排盘、十神、格局）——这是"知其然"
+ **道**：领悟"天人合一"的平衡智慧——这是"知其所以然"
+ **德**：以命理知识助人利他，而非制造焦虑——这是"知其何以用"

### 11_2 最后的思考

韦千里在书中反复强调一个观点：**知命不是为了认命，而是为了更好地趋吉避凶、把握时机**。他用蒋介石的例子说明"潜龙勿用"的阶段需要积蓄力量，用孙传芳的例子说明"用神溃败"时要懂得急流勇退，用程霖生的例子说明"明哲保身"才是大智慧，用夭折婴儿的案例说明"气浊神枯"的命局无力回天。

正如韦千里所言，命理学的终极意义不在于"预知未来"，而在于**帮助人们更好地认识自己、适应环境，在认清自身命理特点的基础上，积极把握后天机遇**。这本书教给我们的，与其说是一套算命技术，不如说是一套**认识自我、理解时机、做出决策的系统性思维框架**——这，才是它穿越近九十年时光，依然值得反复研读的真正价值。
