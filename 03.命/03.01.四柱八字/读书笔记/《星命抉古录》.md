## 板块2 · 核心理论深度解析

### 2_1 对"阴阳生死"的颠覆性批判

这是全书最勇猛也最具学术价值的部分——**直接批判后世子平法的"阴阳生死"理论**：

> "其言壮，即后世所謂帝旺也；其言老，即后世所謂墓也。覈其定名，切確而雅，非如帝旺与墓之俗且陋也。不此之信，而信后人阴生阳死阳死阴生之說，是何足与语星命乎？"

**核心论点：**

| 古法（本书主张） | 后世子平法（批判对象） | 止止居士的态度 |
| --- | --- | --- |
| 壮 = 帝旺 | 阳干顺行帝旺 | "帝旺"名称俗且陋 |
| 老 = 墓 | 阴生阳死、阳生阴死 | "是何足与语星命" |
| 生 = 长生 | 阳干长生在寅/午/酉/子/辰 | 古法更精确 |
| 胎 = 养 | 阴干长生位置不同 | 古法更雅致 |

**对"癸长生于卯"等说法的批判：**

> "且如后人之謂癸长生于卯、乙长生于子、丁己长生于酉、辛长生于子，则子午卯酉皆有长生，试问沐浴在何支乎？"

**逻辑反击：**

+ 如果子午卯酉"都是长生" → 那"沐浴"位在哪里？
+ 十二长生宫需要**十二个地支各占一位**
+ 把子午卯酉都塞满"长生" → 后面的沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养全没地方放了

**深度解读：** 这是古法派对子平派最有力的学术反击之一。**十二长生宫是一个"循环系统"，每个地支必须有且只有一个"身份"**。子平法为了"简化"而把阳干阴干的生死颠倒，导致系统逻辑崩溃。

### 2_2 四败四死四刃四胎系统（全书独创）

止止居士复原了古法的**十六宫系统**（取代后世的"十二长生"）：

| 类别 | 木 | 金 | 火 | 水土 |
| --- | --- | --- | --- | --- |
| **四败地（沐浴）** | 子（水败） | 午（火败） | 卯（木败） | 酉（金败） |
| **四死地** | 午（火死） | 子（水死） | 酉（金死） | 卯（木死） |
| **四刃地（阳刃）** | 卯（木刃） | 酉（金刃） | 午（火刃） | 子（水土刃） |
| **四胎地（飞刃）** | 酉（木胎） | 卯（金胎） | 子（火胎） | 午（水土胎） |

**推导逻辑（以木为例）：**

+ 木长生在亥 → 沐浴在子（败）→ 冠带在丑 → 临官在寅 → 帝旺在卯（刃）→ 衰在辰 → 病在巳 → 死在午 → 墓在未 → 绝在申 → 胎在酉 → 养在戌 → 回到亥（长生）
+ 金长生在巳 → 沐浴在午（败）→ 冠带在未 → 临官在申 → 帝旺在酉（刃）→ 衰在戌 → 病在亥 → 死在子 → 墓在丑 → 绝在寅 → 胎在卯 → 养在辰 → 回到巳（长生）
+ 火长生在寅 → 沐浴在卯（败）→ 冠带在辰 → 临官在巳 → 帝旺在午（刃）→ 衰在未 → 病在申 → 死在酉 → 墓在戌 → 绝在亥 → 胎在子 → 养在丑 → 回到寅（长生）
+ 水土长生在申 → 沐浴在酉（败）→ 冠带在戌 → 临官在亥 → 帝旺在子（刃）→ 衰在丑 → 病在寅 → 死在卯 → 墓在辰 → 绝在巳 → 胎在午 → 养在未 → 回到申（长生）
+ 所以：木的败=子、死=午、刃=卯、胎=酉；金的败=午、死=子、刃=酉、胎=卯；火的败=卯、死=酉、刃=午、胎=子；水土的败=酉、死=卯、刃=子、胎=午

**使用法则：**

| 法则 | 含义 | 实战应用 |
| --- | --- | --- |
| **单见不利** | 一个败/死/刃/胎出现 → 凶 | 柱中只见一个子（水之败）→ 不吉 |
| **双见反吉** | 两个相同的败/死/刃/胎 → 凶煞逢冲反吉祥 | 两子一午（水之败）→ 冲而反吉 |
| **对宫互换** | 败↔死、刃↔胎互为对宫 | 子（败）的对宫是午（死） |

**深度解读：** 这套系统的底层逻辑是**"物极必反"** —— 一个"败"是衰败，但两个"败"互相冲击，反而**冲出了生机**。这和《易经》"无平不陂，无往不复"的思维完全一致。

### 2_3 双包格（全书精华格局）

> "如两子一午、两午一子；两卯一酉、两酉一卯；或两子两午、两卯两酉：作双包论，不作冲论。"

**双包格条件与吉凶完整表：**

| 组合 | 名称 | 吉凶 | 加禄条件 | 深层含义 |
| --- | --- | --- | --- | --- |
| 两子一午 | 双包格 | 吉（不作冲论） | 壬癸丙丁朝元更贵 | 水火既济 |
| 两午一子 | 双包格 | 吉 | 同上 | 火水交融 |
| 两卯一酉 | 双包格 | 吉 | 甲乙庚辛朝元 | 金木交辉 |
| 两酉一卯 | 双包格 | 吉 | 同上 | 木金相成 |
| 两子两午 | 双包格（重） | 大吉 | 朝元得力 | 水火极济 |
| 两卯两酉 | 双包格（重） | 大吉 | 朝元得力 | 金木极成 |
| 三子一午 | 非双包 | 凶（冲太过） | 无 | 冲力过猛 |
| 一子三午 | 非双包 | 凶 | 无 | 火力过猛 |

**"朝元"的含义：**

+ 天干与地支纳音"朝归本元"
+ 如壬子（桑柘木）见癸丑（桑柘木）→ 朝元得力
+ 如甲子（海中金）见癸酉（剑锋金）→ 金气朝元
+ 朝元 = 纳音归位 = 自得其所

### 2_4 灾煞系统复原

### 4_2 验证逻辑示例

**以"段祺瑞"命造（书中引用）为例：**

> "乙丑 己卯 乙亥 癸未 → 曲直仁寿格 → 双包验证 → 纳音生克 → 大运走水木 → 大贵"

**古法分析路径：**

1. 年柱乙丑（海中金）→ 本命为金
2. 日时见己亥（平地木）→ 木多金缺？
3. 但卯未半合木局 → 木极旺
4. 双包验证 → 有无两卯一酉等
5. 灾煞白虎 → 金命见午为白虎 → 是否在致命位？
6. 结论：木多金缺但有水化（亥中壬水）→ 非凶格

## 板块5 · 精华摘录与点评

### 5_1 摘录一

> "其言壮，即后世所謂帝旺也；其言老，即后世所謂墓也。覈其定名，切確而雅，非如帝旺与墓之俗且陋也。"

**点评：** 全书最锋利的一句话。**古法的"壮"和"老"比后世的"帝旺"和"墓"更精准、更雅致**。"壮"是生命力的巅峰，"老"是生命的归宿——多么诗意的命名。

### 5_2 摘录二

> "不此之信，而信后人阴生阳死阳死阴生之說，是何足与语星命乎？"

**点评：** 止止居士的愤怒溢于言表。**十二长生宫是一个精密的循环系统，不容篡改**。把阳干阴干的生死颠倒，就像把钟表的正反转混——整个系统就乱了。

### 5_3 摘录三

> "如两子一午、两午一子、两卯一酉、两酉一卯，或两子两午、两卯两酉，作双包论，不作冲论。"

**点评：** 全书最实用的格局创新。**"双包"的本质是"两个相同的力量包围一个对立力量"**——但不是"冲克"，而是"包容转化"。这和《易经》"包荒"卦象一脉相承。

### 5_4 摘录四

> "如子年生人，年月日时中见壬癸，即为倒戈阳刃。此即阳刃朝元也，其力更大，其凶更甚。惟见杀足以解之。"

**点评：** 最凶的格局需要最凶的解法——**以毒攻毒**。"杀"本身就是凶神，但在此处反而成了"解药"。这是命理学中"以凶制凶"的高级技法。

### 5_5 摘录五

> "且如后人之謂癸长生于卯、乙长生于子、丁己长生于酉、辛长生于子，则子午卯酉皆有长生，试问沐浴在何支乎？冠带在何支乎？临官在何支乎？"

**点评：** 最犀利的逻辑反问。子平法把子午卯酉都塞满"长生"，那"沐浴"位往哪放？**一个系统如果自相矛盾，就必须回到源头重新审视**。

## 板块7 · 总结

《星命抉古录》是一部**带着愤怒写就的学术檄文**。

止止居士不是"算命先生"，而是一个**古法遗产的守护者**。他做了一件极其重要的事——**把即将失传的古法星命系统，用清晰的"九论"框架抢救了下来**。

他的三大贡献：

1. **批判了后世子平法的逻辑漏洞**（十二长生宫的系统崩溃）
2. **复原了古法的十六宫系统**（四败四死四刃四胎）
3. **发明了实用的新格局**（双包格、倒戈阳刃）

读此书最大的收获不是"学会算命"，而是**学会用"系统思维"看任何复杂理论**——当有人说"阴阳生死各不同"时，你要问：**你的系统还自洽吗？**

这才是止止居士留给我们最深的智慧。
