> _"命中至理，只存用神，不拘财、官、印绶、比劫、食伤、枭杀，皆可为用，勿以名之美者为佳，恶者为憎。果能审日主之衰旺，用神之喜忌，当抑则抑，当扶则扶，所谓去留舒配，取裁确当，则运途否泰，显然明白，祸福灾祥，无不验矣。"_

### 2_2 🔵 两条主线

1. **上篇《通神论》**—— 理论总纲（天道 → 干支本性 → 格局结构 → 辩证范畴）
2. **下篇《六亲论》**—— 实战落地（六亲 → 人生万象 → 变局从化 → 岁运贞元）

### 2_3 🟢 三大辩证灵魂（贯穿全书的方法论）

+ **流通 vs 阻滞** → 源流、通关
+ **清纯 vs 混杂** → 清气、浊气、真神、假神
+ **顺势 vs 逆势** → 顺逆、从化、刚柔

1. **识干支**—— 十天干性情 + 十二地支特性（字母表）

#### 3_3_1 第7章·天干（全书最长、最具文采的一章）

**总纲两句**：

> **"五阳皆阳丙为最，五阴皆阴癸为至"** —— 丙火是阳干极致（阳中之阳），癸水是阴干极致（阴中之阴）。

**"五阳从气不从势，五阴从势无情义"** —— 阳干守气节不屈服于强势，阴干随局势而变不拘泥固执。

| **阳支动且强，速达显灾祥；阴支静且专，否泰每经年** | 阳支（子寅辰午申戌）主动强，吉凶立显；阴支（丑卯巳未酉亥）主静专，祸福缓见 |
| **生方怕动库宜开，败地逢冲仔细推** | 寅申巳亥（长生方）忌冲动（两败俱伤）；辰戌丑未（四库）宜冲开（用神喜土时）；子午卯酉（四败/专气）冲合须活看 |

+ 一支多藏（本气+中气+余气），论地支必先论本气，再及其余
+ 寅必先甲后丙，申必先庚后壬，余支皆然
+ 阳支性动而强，阴支性静而弱，在局在运皆以此消息

| **天地顺遂而精粹者昌，阴阳乖悖而混乱者亡** | 天覆地载、干支相生则昌；干支反克、天地不交则亡 |
| **天全一气，不可使地德莫之载** | 天干纯一（如四甲），必须有地支承载（寅卯亥子），不可"天清地克"（如四甲见四申） |
| **地全三物，不可使天道莫之容** | 地支三会/三合（如寅卯辰），必须有天干呼应（甲乙透干），不可"地旺天克"（如寅卯辰见庚辛） |
| **阳乘阳位阳气昌，最要行程安顿** | 五阳居阳位（子寅辰），若是旺神，最要行运安顿得所 |
| **阴乘阴位阴气盛，还须道路光亨** | 五阴居阴位（酉亥丑），若是旺神，最要行运光亨通畅 |
| **天合地者，地旺喜静** | 天生地、地合天之类，地支旺相则喜静而不喜冲 |

**章间逻辑**：天干（十种性格）→ 地支（十二种环境）→ 干支总论（性格与环境如何互动），三层递进，完备"字母表"。

> 💡 **记忆口诀**：**天干是性格，地支是环境，干支总论是人际互动。**

### 3_4 ➤ 板块四：格局与结构论（第10–17章）—— 给命局"定性定位"

| 序号 | 章节 | 原文首句 | 核心要义 |
| --- | --- | --- | --- |
| 十 | **形象** | 两气合而成象，象不可破也；五气聚而成形，形不可害也 | 专旺（独象，如曲直仁寿）、全象（三物成象），各有喜忌：独象喜行化地，全象喜行财地，形全损有余，形缺补不足 |
| 十一 | **方局** | 方是方兮局是局，要得方，莫混局 | 三会方（寅卯辰）vs 三合局（亥卯未），方纯局杂；成方透元神、成局透官星，各有喜忌 |
| 十二 | **八格** | 财官印绶分偏正，兼论食伤八格定 | 正官、七杀、正财、偏财、正印、偏印、食神、伤官为**八正格**；比肩劫财不论格；飞天合禄等"影响遥系"之格**不足为凭** |
| 十三 | **体用** | 道有体用，不可以一端论也，要在扶之抑之得其宜 | **日主为体，提纲为用**（正法之一）；提纲为体，喜神为用（正法之二）；体用之用≠用神之用，须斟酌轻重 |
| 十四 | **精神** | 人有精神，不可以一偏求也，要在损之益之得其中 | 全局最要紧的一字为"精"，辅助滋养为"神"；有精神则命局鲜活，无精神则枯槁 |
| 十五 | **月令** | 月令乃提纲之府，譬之宅也，人元为用事之神，宅之定向也 | 月令是"宅"——定用神的第一参照，人元透干与否决定格局真伪 |
| 十六 | **生时** | 生时乃归缩之地，譬之墓地，人元为用事之神，基之定方也 | 时柱是"墓地"——看归宿与结局，时上生根则晚年安泰 |
| 十七 | **衰旺** | 能知衰旺之真机，其于三命之奥，思过半矣 | **全书枢机之章**：衰旺不看死记长生沐浴，而看**理气进退**；旺中有衰者存不可损，衰中有旺者存不可益 |

+ 体用·精神·月令·生时 = **分析维度**（从哪些角度切入）
+ 衰旺 = **总收一网**，把结构+维度统摄到"旺衰真机"之下

### 3_5 ➤ 板块五：核心辩证范畴（第18–34章）—— 全书精华所在 ⭐

这是《滴天髓》区别于一切命理书的**灵魂部分**，由**九对核心辩证 + 五组辅助范畴**构成：

#### 3_5_1 ║  第一对：中和（第18章）—— 总纲中的总纲

> 原文：**"既识中和之正理，而于五行之妙，有全能焉。"**

+ 中和 ≠ 五行数量均等，而是**各司其职、动静相宜、流通有情**
+ 任铁樵点睛：**"八字贵乎天干地支顺而不悖也。顺者接续相生，悖者反克为害。是以人之八字，最宜四柱流通，五行生化；大忌四柱缺陷，五行偏枯。"**
+ **核心十六字真言**（全书方法论总纲）：

> **"旺则抑之，如不可抑，反宜扶之；弱则扶之，如不可扶，反宜抑之。"**

    - 旺极者抑之反激 → 宜**从其强而扶之**（从旺/从强格）
    - 弱极者扶之徒劳 → 宜**从其弱而抑之**（从弱/从势格）

#### 3_5_2 ║  第二对：源流（第19章）—— 看"气"的来龙去脉

> 原文：**"何处起根源，流到何方住，机括此中求，知来亦知去。"**

+ 不拘当令不当令，**取全局最旺最多之气为"源头"**
+ 看源头流到何方：流到**喜神方住** → 大吉；流到忌神方或被阻 → 凶
+ **比喻**：把命局想象成一条河——找源头、看去路、察阻点

#### 3_5_3 ║  第三对：通关（第20章）—— 化解交战的金钥匙

> 原文：**"关内有织女，关外有牛郎，此关若通也，相邀入洞房。"**

+ 两五行相战（如金木相克），找**中间五行**化解（金→**水**→木）
+ 通关一字，便是全局"解药"
+ **任氏发挥**：木土而要火，火金而要土，土水而要金，金木而要水，水火而要木
+ **口诀**：普通人看生克，高手只看通关

#### 3_5_4 ║  第四对：清气 vs 浊气（第23–24章）—— 格局层次的分水岭

> 清：**"一清到底有精神，管取生平富贵真。澄浊求清清得去，时来寒谷也回春。"**

浊：**"满盘浊气令人苦，一局清枯也苦人。半浊半清犹是可，多成多败度晨昏。"**

|  | 清 | 浊 |
| --- | --- | --- |
| **表现** | 用神专一、护卫纯粹、闲神不搅局、五行有情 | 用神驳杂、忌神掺杂、敌我混战、五行无情 |
| **结果** | 富贵真 | 贫贱苦 |
| **关键** | "澄浊求清"——得一神有力扫其浊气，亦能富贵 | 浊气又难去、清气又不真 → 多成多败 |

#### 3_5_5 ║  第五对：真神 vs 假神（第25–26章）—— 用神有没有"根"

> 真：**"令上寻其聚得真，假神休要乱真神。真神得用平生贵，用假终为碌碌人。"**

假：**"真假参差难辨论，不明不暗受邅迍。提纲不与真神照，暗处寻真也有真。"**

+ **真神**：月令当权、透干、有根气、不受冲合破损 → 得用则贵
+ **假神**：虚浮无根、被合绊冲克、看似可用实则形同虚设 → 用假则碌碌
+ 真假参差难辨时，须看"提纲是否与真神照"，暗处寻真亦有真

#### 3_5_6 ║  第六对：顺逆（第28章）—— 常理与变法的分界

> 原文：**"顺逆不齐也，不可逆者，其气势而已矣。"**

+ **正局常理**：旺抑弱扶，追求中和
+ **从势变法**：全局专旺已成，必须**顺势而从**，逆势克制必招灾
+ 原注列举四种不可逆之势：「1」刚柔之道可顺不可逆 「2」昆仑之水可顺不可逆 「3」其势已成可顺不可逆 「4」权在一人/二人同心可顺不可逆
+ 这是判断**从格**成立与否的根本依据

#### 3_5_7 ║  第七对：寒暖（第29章）—— 调候的优先性

> 原文：**"天道有寒暖，发育万物，人道行之，不可过也。"**

+ 阴支为寒、阳支为暖；西北为寒、东南为暖；金水为寒、木火为暖
+ **得气之寒，遇暖而发；得气之暖，逢寒而成**
+ 冬生（亥子丑）先取火暖局，夏生（巳午未）先取水润局
+ **调候优先级有时高于旺衰**——寒无火、燥无水，气机死寂

#### 3_5_8 ║  第八对：燥湿（第30章）—— 与寒暖并列的调候维度

> 原文：**"地道有燥湿，生成品汇，人道得之，不可偏也。"**

+ 过于湿者，**滞而无成**；过于燥者，**烈而有祸**
+ 水有金生遇寒土而愈湿，火有木生遇暖土而愈燥
+ 木火伤官要湿（配水润），金水伤官要燥（配土暖）
+ 任铁樵首次把辰戌丑未**分为燥土（戌未）和湿土（辰丑）**，影响后世三百年

#### 3_5_9 ║  第九对：隐显（第31章）+ 众寡（第32章）—— 透藏与多寡

> 隐显：**"吉神太露，起争夺之风；凶物深藏，成养虎之患。"**

众寡：**"抑强扶弱者常理，用强舍弱者元机。"**

+ **隐显**：喜神透干为"显"（明用），藏支为"隐"（暗用）；忌神深藏不露反成隐患
+ **众寡**：强众敌寡者势在去其寡，强寡敌众者势在成乎众；与"顺逆"配合判断该去该留

#### 3_5_10 辅助范畴（第21–22、27、33–34章）

| 序号 | 章节 | 原文要句 | 核心要义 |
| --- | --- | --- | --- |

## 板块6 · 任铁樵的四大核心贡献（阐微之"微"）

任铁樵在刘基原注基础上，做了四件影响命理学三百年的事：

### 6_1 1️⃣ 确立"日主旺衰平衡法"

以日元为中心，其余七字围绕日元打转，取用神、定喜忌，形成"身强身弱取用神"的范式。这是全书的方法论基石。

### 6_2 2️⃣ 辩证论命：旺极宜从，弱极宜泄

打破"身旺必克、身弱必扶"的刻板公式，提出**十六字真言**：

> **旺者宜克，旺极宜泄，弱者宜生，弱极宜克**

这就是后世"扶抑、顺势、从强、从弱"四格的雏形，也是李涵辰等新派命理的理论源头。

### 6_3 3️⃣ 以"清浊真假"替代"奇格异局"

力斥神煞、纳音、固定贵格，把格局层次评判标准从"名目"转向"气机"：

+ 不在叫什么格，而在**用神是否清纯有力、有根无根**
+ 首次把辰戌丑未**分为燥土与湿土**，深化了调候理论

### 6_4 4️⃣ 512个命例的实证体系

每立一论必引亲身推验之命造为证，或阐发成法，或匡正时讹，使全书成为**有理论、有证伪、有验证**的思辨体系。对比相似八字而运途迥异之例，揭示理气进退之机。

## 板块7 · 阶梯式学习路径（六步登堂入室）

任铁樵在书中暗含了修习次第，整理为**六步阶梯**：

### 7_1 第一阶：识字——背熟十天干 + 十二地支

+ 十天干性情（甲刚乙柔丙烈丁温…）
+ 十二地支特性（阳动阴静、生方怕动库宜开…）
+ 地支藏干（本气→中气→余气）
+ **目标**：看到任何干支组合，立刻反应出其"脾气"

### 7_2 第二阶：懂法——搞透衰旺与中和

+ 理气进退（相→旺→休→囚的循环）
+ 中和真义（不是五行均等，而是流通有情）
+ 十六字真言（旺抑·旺极扶·弱扶·弱极克）
+ **目标**：能判断任何命局的"旺衰真机"

### 7_3 第三阶：明格——掌握格局与结构

+ 形象方局（专旺、三会三合）
+ 八格取用（财官印绶食伤的喜忌）
+ 体用精神（日主为体、提纲为用）
+ **目标**：能给任何命局"定性定位"

### 7_4 第四阶：通辩——精研九对辩证范畴 ⭐ 核心

+ 源流（找源头、看去路）
+ 通关（化解交战）
+ 清浊（纯杂之分）
+ 真假（根气有无）
+ 顺逆（从势变法）
+ 寒暖燥湿（调候优先）
+ 隐显众寡（透藏多寡）
+ **方法**：逐章拆解任氏命例，体会"何时用何法"

### 7_5 第五阶：致用——六亲落地与何知八问

+ 何知章八句（富门户、贵理会…）
+ 六亲活看法（财官印比各有所主）
+ 性情疾病出身地位（五行配人生）

### 7_6 第六阶：贯通——变局岁运与贞元

+ 从象化象假从假化（变局识别）
+ 顺局反局战局合局（局式判断）
+ 君臣母子象（伦理喻五行）
+ 岁运盖头截脚（应期精断）
+ 贞元循环（全书收束，天地大道）

> 💡 **徐乐吾评价**：_"仆研习命理有年，生平最服膺者为《子平真诠》《穷通宝鉴》《滴天髓》三书。"_

💡 **方重审评价**：_"后之言命学者，千言万语，不能越其范围，如江河日月，不可废者。倘能合天才、学识、经验三者俱全，于斯道庶几入圣矣！"_
