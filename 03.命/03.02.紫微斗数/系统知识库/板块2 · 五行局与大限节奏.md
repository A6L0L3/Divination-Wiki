# 板块2 · 五行局与大限节奏

> 五行局决定每十年走一个大限宫的实际年数，是排盘的关键枢纽。

这一步最常被忽略，却对应期的影响最大。

---

## 2_1 五行局是什么：决定换运速度的齿轮

五行局由命宫干支的纳音决定，共五种：水二局、木三局、金四局、土五局、火六局。数字即**每走一个大限宫所对应的实际年数**。

| 局 | 水二局 | 木三局 | 金四局 | 土五局 | 火六局 |
| --- | --- | --- | --- | --- | --- |
| 每限年数 | 2 年 | 3 年 | 4 年 | 5 年 | 6 年 |

**实战含义**

+ **水二局**：换运极快（两年一换），人生节奏密集，适应力强，但容易"什么都只做两年"，难深耕。
+ **木三局**：节奏偏快，学习与转型周期短。
+ **金四局**：中等节奏，是最常见的类型之一。
+ **土五局**：节奏沉稳，一件事做得比较久，转向慢。
+ **火六局**：一运六年，节奏最慢，深耕型，但转向成本最高。

> **看大限时务必确认局数**。同样"走到第四大限"，水二局的人在十几岁就走完了，火六局的人可能才刚开始——这就是为什么"同一个宫位、不同的局数"，时间与体感完全不同。

## 2_2 主法：纳音定局

以命宫干支查六十甲子纳音，取纳音五行对应局数：

| 纳音五行 | 金 | 木 | 水 | 火 | 土 |
| --- | --- | --- | --- | --- | --- |
| 局数 | 金四局 | 木三局 | 水二局 | 火六局 | 土五局 |

### 纳音归类速查（记住六组名称即可反查）

| 五行 | 纳音名称（六组） |
| --- | --- |
| 金 | 海中金、剑锋金、白蜡金、沙中金、金箔金、钗钏金 |
| 木 | 大林木、杨柳木、松柏木、平地木、桑柘木、石榴木 |
| 水 | 涧下水、泉中水、长流水、天河水、大溪水、大海水 |
| 土 | 路旁土、城头土、屋上土、壁上土、大驿土、沙中土 |
| 火 | 炉中火、山头火、霹雳火、天上火、山下火、覆灯火 |

**使用方式**：查出命宫干支的纳音名称 → 看它属于哪一行 → 对应局数。
例：命宫甲子，甲子乙丑"海中金" → 金 → **金四局**。

## 2_3 辅法：天干组 × 地支组顺行

无纳音表时使用。地支分六组：子午、丑未、寅申、卯酉、辰戌、巳亥。以命宫天干所属组别确定"起点五行"，从命宫地支所在组开始按固定顺序顺数五格，落在哪一格即为何局。

| 命宫天干 | 顺行顺序（循环） |
| --- | --- |
| 甲乙 | 金 → 水 → 火 → 土 → 木 |
| 丙丁 | 水 → 火 → 土 → 木 → 金 |
| 戊己 | 火 → 土 → 木 → 金 → 水 |
| 庚辛 | 土 → 木 → 金 → 水 → 火 |
| 壬癸 | 木 → 金 → 水 → 火 → 土 |

**完整示例**：命宫己酉。

```latex
第 1 步：己属"戊己"组 → 起点顺序为 火 → 土 → 木 → 金 → 水
第 2 步：酉属"卯酉"组 → 从卯酉组开始顺数
第 3 步：卯酉（火）→ 辰戌（土）→ 巳亥（木）→ 子午（金）→ 丑未（水）
第 4 步：酉属卯酉组，落在第一格"火"
结论：火六局

```

**两种方法必须互验**：纳音法查一次，辅法再推一次。结果不一致，说明命宫干支查错了或纳音记错了——这是最值得花的两分钟。

## 2_4 排大限：顺逆与起运

### 顺逆规则

```latex
阳男阴女 → 顺行（按地支顺时针走）
阴男阳女 → 逆行（按地支逆时针走）

```

其中"阳/阴"指**出生年干的阴阳**：甲丙戊庚壬为阳干，乙丁己辛癸为阴干。

| 年干 | 性别 | 大限走向 |
| --- | --- | --- |
| 阳干（甲丙戊庚壬） | 男 | 顺行 |
| 阳干 | 女 | 逆行 |
| 阴干（乙丁己辛癸） | 男 | 逆行 |
| 阴干 | 女 | 顺行 |

### 起运年龄与每限年数

第一大限从命宫起。**每限年数 = 局数**，这一点没有争议：水二局 2 年一换、木三局 3 年、金四局 4 年、土五局 5 年、火六局 6 年。

起运年龄各流派算法略有出入，常见做法是**以局数为起运岁数**（水二局约 2 岁起运，火六局约 6 岁起运，其余类推）。换算公式：

```latex
第 n 大限的年龄区间 ≈ 起运年龄 + 局数 × (n − 1)  ～  起运年龄 + 局数 × n − 1

```

**实操建议**：起运年龄请以自己所用的排盘工具为准，并把该工具的起运岁数记录在盘旁。同一张盘在不同工具下可能相差一两年，这个差值会传导到所有应期判断上。

### 大限与人生阶段（按大限序，年龄须按局数换算）

| 大限序 | 常见主题 |
| --- | --- |
| 第一大限（命宫 / 童限） | 童年体质、家庭环境、早期性格塑造 |
| 第二大限 | 学业、自我认同、原生家庭分离 |
| 第三大限 | 职业起步、婚恋、独立 |
| 第四大限 | 事业定型、家庭责任、中年转折 |
| 第五大限 | 事业高峰或转型、子女成长 |
| 第六大限及以后 | 收成、健康、晚年安顿 |

> **重要提醒**：同一"大限序"在不同局数下对应的年龄相差极大。水二局的人可能在很年轻时就已经换过好几轮大限，火六局的人走完同样数量的大限则要多花数倍时间。**先确认局数，再谈第几大限落在几岁。**

## 2_5 小限与斗君（排盘环节只需记住起法）

排大限的同时，还有两个"短周期"指针需要定下来，它们属于排盘动作，用法在板块 16 展开。

+ **小限**：一岁一宫，男顺女逆，按生年地支三合局定起点（寅午戌年生从辰宫起 1 岁，申子辰年从戌宫，巳酉丑年从未宫，亥卯未年从丑宫）。
+ **斗君**：以太岁宫起正月，顺数至生月，再以该宫起子时逆数至生时定宫，作为流年的起运点。属进阶技术，初学可暂缓。

**排盘时只需要做一件事**：把小限起点与斗君所在宫记在盘旁，不要在这里就急着解读。它们与流年如何互参、四种组合分别是什么体感，见板块 16。

## 2_6 故事：两位"同盘"客户，为什么一个快一个慢

**背景**。两位客户来咨询，生辰同年同月同日同时，出生地相距数百公里。他们都从事同一行业，都问"我什么时候该转型"。

**盘面差异**。由于经度不同，真太阳时存在差异，导致命宫错开一位；五行局也因此不同。

```latex
A：命宫在卯，木三局 → 每限 3 年，换运频繁
B：命宫在辰，金四局 → 每限 4 年，节奏较慢

```

**推演**。两人都要走到"官禄宫"这个大限，但因为局数不同，走到它的时间相差很大：

```latex
A：木三局，每限 3 年 → 换运快，走到官禄宫的年纪明显更早
B：金四局，每限 4 年 → 换运慢，走到同一个宫位要多等若干年
   → 同样的"官禄宫"议题，两人的窗口相差数年

```

具体差多少，取决于各自工具的起运岁数，但方向是确定的：**局数越大，同一个宫位来得越晚；局数越小，人生节奏越密集。**

**两人的实际经历**

+ A 在三十二岁那年主动换了赛道，前半年收入下降，第三年做到新领域的主管。他说："我本来就待不住，三年一换反而舒服。"
+ B 在同一岗位上深耕到四十岁，四十一岁才被推到一个管理岗位。他说："我前面那些年总觉得慢，后来才知道我的运本来就是六年一格的节奏。"

**如果搞反了会怎样**：假如让 B 按 A 的节奏在三十二岁裸辞转型，他会在自己"大限没开门"的时候做了一次高成本动作；反过来让 A 按 B 的节奏死守，他会在最需要变动的年份里耗光耐心。

**方法论小结**

```latex
这就是古人说"同年、同月、同日、同时而生，则有贫贱、富贵、寿夭之异"的现代解释——
差异往往不在星曜，而在真太阳时与局数带来的节奏差。
断"什么时候"，第一件事永远是确认局数。

```
