# 板块0 · 学习路径与训练地图

> 学斗数最容易犯的错，是"还没会排盘就开始背格局"。

本板块给出能力分层、验收标准、四周训练表、误区纠偏、三种笔记法与三层验证法。没达标就不要往下走。

---

## 0_1 五阶段能力模型

| 阶段 | 能力目标 | 核心内容 | 验收标准（能独立做到） | 参考周期 |
| --- | --- | --- | --- | --- |
| 一阶·搭盘 | 会造盘 | 十二宫、命身宫、五行局、安星、四化、大限 | 给任意生辰，能手排出紫微落宫、十四正曜、四化、大限起运 | 1–2 周 |
| 二阶·读数 | 会标盘 | 庙旺利陷、空宫借星、宫位权重、六条线 | 拿到一张盘，5 分钟标完全部主星亮度与空宫 | 2–3 周 |
| 三阶·解盘 | 会断人 | 十四主星人格、辅煞作用、四化象意 | 就任一张盘，说出性格、能力结构、三个明显短板 | 1–2 月 |
| 四阶·断事 | 会断事 | 分域断法（财官婚疾）、大限流年叠加、应期 | 就某一年，说清"主战场在哪个宫、吉凶从哪来" | 2–3 月 |
| 五阶·成局 | 会论格 | 格局入格验格、主宾动静、古赋断语取舍 | 判断一张盘的上限在哪、哪十年是黄金期、风险点在哪 | 3–6 月 |

**三个关键认知**

1. **理解优先于记忆**。星曜一百多颗，靠背很快遇到瓶颈。先吃透"五行 + 化气 + 庙陷"这条主线，其余星曜都是它的变体。
2. **渐进式构建**。命盘结构 → 星曜 → 庙陷 → 四化 → 飞星 → 实战解盘，每一层没扎实就不进下一层。跳层的后果是"看得懂每句话，连不成一条结论"。
3. **以盘养学**。每学一个知识点，立刻回到自己手上的盘验证一条。学一百条不如验证十条。

| 第 2 周 | 星与庙陷 | 每日精读 2 颗主星；给每张盘标亮度 | 十四主星全部标完，且能说出每颗的庙、陷宫位 |

## 0_3 三项硬基本功与自测题

### 基本功一：排盘（手排能力）

手排不是复古癖好，而是建立"盘感"的唯一途径。至少手排出以下五步：

1. 定命宫、身宫（口诀：寅起正月，顺数至生月，逆数生时为命宫；顺数生时为身宫）
2. 定五行局（纳音 → 局数）
3. 定紫微、天府（紫府必在对宫）
4. 布南北斗十四正曜 + 主要辅煞
5. 起生年四化 + 排大限

**自测题**：给"农历八月十五午时，男"手排出命宫。

**推演**：寅起正月，顺数八月 → 酉宫；酉宫起子时，逆数到午时 → 卯宫。**命宫在卯**。身宫：午时属"子午"组 → 身宫与命宫同宫，即也在卯。

**双重校验**：查命宫速查表（见板块 1），午时行、八月列的交叉点正是卯宫，与口诀推算一致。

**常见错点**：顺逆方向搞反（命宫逆数、身宫顺数）；把农历月当成节气月；忽略真太阳时。

### 基本功二：庙旺利陷（亮度）

这是全库的读数基础。**先看亮度，再谈吉凶**——同一颗星，庙旺和落陷可能是两个人。
**训练法**：打印十张空盘图，只标主星庙陷，练到 3 分钟一张。

**自测题**：太阳在午、在子分别是什么状态？
**答案**：午为庙（日丽中天），子为陷（日沉深渊）。若命主是夜晚出生，还要再减一档；白天出生则增力。

### 基本功三：四化（变化机制）

四化是把静态盘变成动态故事的发动机。必须做到：见天干即出四化星。

**记忆口诀（按甲至癸）**

```latex
甲廉破武阳，乙机梁紫阴，丙同机昌廉，丁阴同机巨，
戊贪阴右机，己武贪梁曲，庚阳武阴同，辛巨阳曲昌，
壬梁紫辅武（原典作「壬梁紫**府**武」，府 = 天府），癸破巨阴贪。

```

**自测题**：庚年干四化是什么？
**答案**：太阳化禄、武曲化权、太阴化科、天同化忌（梁派；另有流派作"庚阳武府相"）。

**流派提醒**：庚、壬两干的四化在流派间存在差异。解盘前先固定一个版本，中途不要切换，否则前后结论会打架。这也是复盘时"盘没排错但结论错"的常见原因之一。

## 0_4 十二个高频误区与纠偏

| 误区 | 真相 | 纠偏动作 |
| --- | --- | --- |
| 紫微坐命就一定好 | 紫微须庙旺 + 三方吉拱才有威力，否则"孤君无辅" | 先看紫微亮度，再看左右魁钺是否到位 |
| 煞星一定坏 | 七杀在寅申为朝斗仰斗，火星在旺地为富论 | 每颗煞星问一句：它得令吗？有制化吗？ |
| 吉星越多越好 | 吉星落陷是"吉处藏凶"，文昌陷地反主虚浮 | 数吉星时只算庙旺得地的 |
| 空宫就没用 | 空宫借对宫星曜论，对宫吉则吉，且主"易受环境影响" | 借星时庙陷以**原宫**为准，不随借入宫改变 |
| 流年遇煞必灾 | 原局强可化解，"行限逢乎弱地未必为灾" | 先判原局底盘，再判流年冲击 |
| 用八字的思路解斗数 | 斗数不看日主强弱、不用神、不排大运干支 | 一切回到"宫位 + 星曜 + 四化"三位一体 |
| 只看命宫 | 命宫是根，但三合才是"用" | 按本 60% / 对 40% / 合 20% / 邻 10% 加权 |
| 邻宫凶很可怕 | 邻宫权重最轻，"两邻相侮岂为灾" | 只有本宫凶才是"自伐" |
| 化禄就是发财 | 化禄主"缘起与顺畅"，落点宫位决定应什么事 | 化禄入财帛才是财，入夫妻是感情顺 |
| 化忌就是灾 | 化忌主"执念与结果"，是能量聚焦处，也主专长 | 看化忌落点 + 是否有禄权科解 |
| 男女命看法一样 | 男重财官迁，女重命身福德夫（可时代化理解） | 按板块 14、15 的分域处理 |
| 背下格局就能断命 | 格局须"入格 + 无破 + 大限配合"三条件同时满足 | 用板块 11 的入格三验逐条核对 |

## 0_5 命盘日志：每次解盘填一张

```latex
【基本信息】生辰 / 性别 / 命宫地支 / 五行局 / 紫微落宫 / 身宫位置
【底盘】命宫主星与亮度 / 身宫 / 三方四正 / 有无空宫 / 四化落点
【第一印象】一句话概括这个人的能量结构
【三强】最强的三个宫位及理由
【三弱】最弱的三个宫位及理由
【当前大限】第几大限 / 走哪个宫 / 大限四化
【今年主题】流年叠宫 + 流年四化 → 主战场
【验证记录】命主反馈（事后回填，这是最宝贵的部分）

```

**日志使用三条规矩**

1. 每次解盘前先填"基本信息 + 底盘"，**不要先看以前的结论**，避免自我暗示。
2. "第一印象"必须是一句话，写长了说明你还没看清结构。
3. 验证记录事后回填，回填时注明"应 / 未应 / 部分应"，并写清自己判断错在哪一层。

## 0_6 复盘三问与错层定位

```latex
第 1 问：我说对了什么？为什么对？
         把正确的推理路径固化成自己的套路，写进"我的断法库"。

第 2 问：我说错了什么？错在哪一层？
         分层定位：盘排错 / 亮度标错 / 宫位权重错 / 断语理解错 / 时机判错。
         定位到层才好补，笼统说"水平不够"没有意义。

第 3 问：有没有更简洁的判法？
         好断法是"三步出结论"，不是"二十步绕一圈"。

```

**错层定位表**（复盘时对照打钩）

| 出错层 | 典型症状 | 补法 |
| --- | --- | --- |
| 盘层 | 事件完全对不上 | 重排：时辰、真太阳时、流派 |
| 亮度层 | 性格描述反了 | 重标庙陷 + 日夜修正 |
| 权重层 | 说得出好坏、说不准程度 | 重算本对合邻加权 |
| 断语层 | 明明有此星却没应 | 查断语成立条件（是否庙旺、是否被破） |
| 时机层 | 事情发生了但年份差很远 | 重看大限开门与流年扳机是否同时命中 |

## 0_7 三种笔记法：把知识变成自己的

### 笔记法一：星曜卡（一星一卡）

```latex
【星名】紫微        【五行】阴土   【化气】尊
【庙陷】庙午 / 陷子
【正面】领导力强、格局大、贵人运旺、决策果断
【反面】固执多疑、人缘差、决策反复（落陷时）
【关键搭档】左辅右弼（有权）、天魁天钺（有机遇）
【怕什么】空劫（看破红尘）、无辅（孤君）
【我验证过的案例】________（填真实反馈，不要填书本例句）

```

### 笔记法二：宫位象义卡（一宫一卡）

```latex
【宫位】财帛宫
【第一层】收入与赚钱能力
【第二层】理财方式、现金流管理
【第三层】价值观、资源调度能力
【对宫】福德宫（钱能否带来满足感）
【三合】命宫、迁移宫（能力 + 外部机会）
【我的断语库】
  · 武曲庙旺 + 化禄 → 靠专业能力挣钱，现金流稳
  · 空劫同宫 → 财来财去，宜资产化而非持有现金
【验证记录】☐应 ☐未应 ☐部分应

```

### 笔记法三：断语库（按"组合 → 结论 → 验证"三段记）

```latex
组合：巨门在子午入庙坐命
结论：早年辛苦、中晚年靠口才发达
验证：☐ 应  ☐ 未应  ☐ 部分应   备注：________

```

**断语库的组织原则**：按"星曜组合"索引，不按"赋文篇名"索引。因为断盘时脑子里先跳出来的是组合，不是篇名。

## 0_8 三层验证法：怎么知道自己真的会了

```latex
第 1 层 · 自证
  用自己与至亲的盘。反馈最真、验证最快。
  要求：至少找出 3 条"只有这个盘才说得准"的细节。

第 2 层 · 旁证
  用公开生平的公众人物。可核对大限应事（哪十年起、哪十年落）。
  要求：只看大限趋势，不要去猜具体私密事件。

第 3 层 · 盲测
  陌生盘，先出结论再听反馈。
  要求：结论写下来再对答案，禁止事后圆场。

```

### 一条断语的及格线

| 等级 | 标准 |
| --- | --- |
| 不合格 | 说得玄乎，事后怎么都能圆（例如"你最近是不是有点累"） |
| 及格 | 能指出星曜依据，且事件方向对 |
| 良好 | 能同时说清"为什么"和"大概什么时候" |
| 优秀 | 能给出可执行的下一步，且命主真的用上了 |

## 0_9 故事：一张被误判了三年的盘

**背景**。一位学习者拿家人的盘来问财运。他一眼看到财帛宫里坐着地空地劫，当场下了结论："财运很差，钱留不住。"据此建议家人保守、别投资。**三年里，家人错过了两次买房窗口。**

**三年后的复盘**。他把这张盘重新摊开，按权重法重算：

```latex
本宫 财帛宫：空劫同宫           → -10 × 0.6 = -6.0
对宫 福德宫：天同庙旺 + 化禄     → +15 × 0.4 = +6.0
三合 命宫  ：天府庙旺           → +10 × 0.2 = +2.0
三合 迁移宫：太阴旺             → +8  × 0.2 = +1.6
邻宫 官禄宫：天相庙旺           → +10 × 0.1 = +1.0
邻宫 子女宫：天机平             → +2  × 0.1 = +0.2
────────────────────────────────────────
合计 ≈ +4.8  → 财帛宫实际是"中偏上"

```

**三个被漏掉的地方**

1. **只看本宫，没加权**：本宫 60% 确实是负分，但对宫福德宫有化禄，按 40% 权重往回补了一大截。
2. **没看田宅宫**：田宅宫天府入庙，守财与置产能力其实很强，属于"现金留不住、但资产守得住"的类型。
3. **把空劫当成"没有钱"**：空劫在财帛宫的真实含义更接近"钱不以现金形式停留"，而不是"赚不到"。

**改判后的结论与动作**：现金流会波动，但资产端是稳的，宜强制资产化；且因为福德宫化禄，钱花在提升生活品质上反而应了格局。家人后来改为"收入到账即转资产"，两年内积累了此前从未有过的资产规模。

**方法论小结**

```latex
单宫断吉凶 = 只用 60% 的信息下 100% 的结论。
一条断语要落地，至少要过"本宫 → 对宫 → 关联宫"三关。
这个错误的代价，是命主真实错过的两次买房机会。

```
