## 17_2 斗数骨髓赋：格局的骨架

**核心命题**：命有格局，不可一概而论。先看格局，再看星曜；先明命身，再推穷通。

### 三条可落地要点

1. **同年同月同日同时不同命的解释力**：斗数比八字更精细——同八字的人很多，但精确到时辰的星曜分布几乎不重复；加上命宫身宫双核结构，同盘不同命的解释空间更大。
2. **命身二宫是双核，缺一不可**：
    - 命宫无正曜（空宫）+ 三方无吉拱 + 煞破刑冲 → 先天不足，须后天加倍努力。
    - 命宫、身宫、大限三层皆吉 → 到老荣昌；两层吉 → 中上；一层吉 → 需努力方能有成。
3. **五行宫位与地支类别联动**：命宫落四生之地（寅申巳亥）+ 遇长生、临官星曜 → 开创有基；落四墓（辰戌丑未）→ 守成积累型；落四败（子午卯酉）→ 桃花与变动型。

### 原文要句与操作化

| 原文 | 白话 | 操作化落点 |
| --- | --- | --- |
| 太极星曜，乃群宿众星之主 | 紫微统领全盘 | 排盘后第一眼看紫微落在哪一宫、庙旺还是落陷 |
| 在天则运用无常，在人则命有格局 | 天象动态，命盘固定成格局 | 星曜会变，但格局是相对稳定的结构 |
| 先明格局，次看众星 | 先看格局，再看星曜 | 断盘顺序：结构 → 星曜 → 庙陷 → 四化 |
| 立命可知贵贱，安身便晓根基 | 命宫定贵贱，身宫定根基 | 命身双核，缺一不可 |
| 命无正曜，复无吉拱，煞破刑冲，夭折孤贫 | 空宫 + 三方无吉 + 煞冲 | **须降档**：现代理解为空宫 + 三方皆凶的极端情况 |
| 命好、身好、限好，到老荣昌 | 三层皆吉才荣昌 | 断"层次"的三层模型 |
| 定看五行之宫位。五行即金木水火土，如寅申巳亥为四生之地，子午卯酉为四败，辰戌丑未为四墓 | 地支类别决定气质 | 命宫落点 → 开创型/桃花型/守成型 |

> **本赋涉及的格局清单（石中隐玉、明禄暗禄、三奇嘉会、将星得地、日照雷门、明珠出海、紫微辰戌遇破军、贪武墓中居、君臣庆会、财印夹命、日月夹财）已完整整合进板块 11，此处不重复列出。**

**需要降档处理的断语**：本赋较为中正，少有极端断语。唯一要注意的是"命无正曜，复无吉拱，煞破刑冲，夭折孤贫"——现代应理解为空宫 + 三方皆凶的**极端情况**，绝大多数空宫者只是"适应力强、主观性弱"，远不至于孤贫。

## 17_3 斗数发微论：三方四正实战手册

**核心命题**：四正吉星定为贵，三方杀拱少为奇。**吉星入垣则为吉，凶星失地则为凶。**

### 总纲三条

1. **庙陷优先于吉凶**——这是全盘第一铁律。拿盘第一步不是看"有什么星"，而是看"星在哪个宫、庙旺还是落陷"。
2. **四正与三方各司其职**：四正是"线"（命、迁、财、官构成的十字），强调互动；三方是"面"（本宫 + 三合宫），强调支撑。
3. **行限逢弱地未必为灾，立命在强宫必能降福**——原局是"本钱"，运限是"波动"。本钱厚，波动再大也伤不到根本。

## 17_4 十喻歌：权重分配法则

**核心命题**：吉凶最要细分明，本对合邻有重轻。

**原文全文**

```latex
吉凶最要细分明，本对合邻有重轻。
四面楚歌终必败，千祥云集自然亨。
自强才是好人家，邻舍惟添锦上花。
若到逢源真境地，春风只可感相差。
两邻相侮岂为灾，自伐才教大可哀。
易躲当头一棍棒，难防左右袭兵来。

```

**一句话总结**：**本宫为根（60%），对宫如镜（40%），三合为援（20%），邻宫辅助（10%）。**

> **完整的十喻对照表、加权打分法与"两邻相侮 vs 左右袭兵"的辨析，已在板块 6 完整展开，此处不重复。** 本板块只补充两点：

### "十喻"这个数字怎么来的

常见传本为六句十二短句，篇幅极短；另有十句本流传，内容一致。"十喻"指的**不是十句话，而是十种状态组合**：

```latex
本方吉 / 本方凶 —— 2 喻
对方吉 / 对方凶 —— 2 喻
合方吉 / 合方凶 —— 2 喻
邻方吉 / 邻方凶 —— 2 喻
方宫皆吉 / 方宫皆凶 —— 2 喻
合计 10 喻

```

## 17_5 故事：一句"兄弟无义"引发的误会

**背景**。有人看到自己兄弟宫有巨门，古诀说"巨到二宫，必是兄弟无义"，于是焦虑地问："我和我哥是不是注定不和？"

**按降档公式重读（三步）**

```latex
第 1 步 · 找出结构：
  巨门（主口舌、探究、疑）落在兄弟宫（平辈关系、合伙人）

第 2 步 · 写出张力模式（不是结果，是倾向）：
  沟通中容易"挑问题"、容易把话说重、容易起口舌

第 3 步 · 补一条可执行建议：
  与平辈合作时把分工与权责写成文字；争执缓一天再回话；
  亲兄弟尽量不做合伙人

```

**命主的反馈**：确实是，兄弟俩感情其实不错，但每次合伙做事都会因为"沟通方式"吵架。

**如果直接照搬古文会怎样**：他会把"兄弟无义"理解成"我们兄弟感情注定不好"，可能因此减少往来——**断语就从工具变成了伤害**。

**方法论小结**

```latex
古断语的价值在于指出"张力在哪里"，不在于预言结果。
把"必是兄弟无义"读成"沟通方式需要注意"，
断语就从恐吓变成了工具。

```

## 17_6 笔记法：断语卡与降档练习

### 断语卡（按组合索引，不按篇名索引）

```latex
【组合】巨门在兄弟宫
【出处】斗数发微论（古诀"巨到二宫"）
【原文】必是兄弟无义
【张力模式】沟通中易挑问题、说话重、起口舌
【降档表述】与平辈沟通需注意表达方式
【建议】权责写清楚 / 争执缓一天回话 / 亲兄弟不做合伙人
【验证】☐应 ☐未应 ☐部分应

```

### 降档练习（每周五条）

```latex
挑五句古断语，按三步改写：
  第 1 步：找出这个断语的"结构"（哪颗星、落哪一宫）
  第 2 步：写出它描述的"张力模式"（不是结果，是倾向）
  第 3 步：补一条可执行建议
改写不出第三步，说明你还没真正理解这句断语。

```
