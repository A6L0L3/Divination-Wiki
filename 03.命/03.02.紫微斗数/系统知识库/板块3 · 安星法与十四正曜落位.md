# 板块3 · 安星法与十四正曜落位

> 把紫微钉进盘里，再把十四正曜铺开。

本板块的重点不是背诵，而是**学会校验**——排错一步，后面全错。

---

## 3_1 安紫微：先用局数定位，再用生日推宫

### 古诀与起点

```latex
六五四三二，酉午亥辰丑

```

这十个字说的是**五行局数 → 紫微起点宫的固定对应**：

| 五行局 | 火六局 | 土五局 | 金四局 | 木三局 | 水二局 |
| --- | --- | --- | --- | --- | --- |
| 局数 n | 6 | 5 | 4 | 3 | 2 |
| 起点宫 | 酉 | 午 | 亥 | 辰 | 丑 |

**记忆技巧**：口诀倒着读回来自"酉午亥辰丑"，对应"六五四三二"。记住"火六起酉、水二起丑"两个端点，中间自然顺下来。

### 推算步骤（四步）

```latex
第 1 步：由五行局查出起点宫 S，记下局数 n
第 2 步：取农历生日数 d
第 3 步：求余数 r = d ÷ n 的余数；若能整除，则 r = n
第 4 步：从 S 起「初一」，顺时针顺数 (r − 1) 格 → 即紫微落宫

```

### 三个完整示例

```latex
示例一 · 水二局（n=2，S=丑），农历初二生
  r = 2 ÷ 2 余 0 → 取 r = 2 → 从丑起初一，顺数 1 格 → 紫微在寅

示例二 · 火六局（n=6，S=酉），农历初八生
  r = 8 ÷ 6 余 2 → 从酉起初一，顺数 1 格 → 紫微在戌

示例三 · 金四局（n=4，S=亥），农历十六生
  16 ÷ 4 整除 → r = 4 → 从亥起初一，顺数 3 格
  亥(初一) → 子(初二) → 丑(初三) → 寅(初四) → 紫微在寅

```

**整除时的处理是高频错点**：能整除时余数取 n（不是取 0），这一步错了紫微就会退一格。

## 3_2 紫微落宫与同宫星对照表（最强校验器）

| 紫微落宫 | 同宫星 | 常见格局俗称 |
| --- | --- | --- |
| 子 / 午 | 紫微独坐 | 极向离明（午，入庙） |
| 丑 / 未 | 紫微 + 破军 | 紫破 |
| 寅 / 申 | 紫微 + 天府 | 紫府同宫 |
| 卯 / 酉 | 紫微 + 贪狼 | 紫贪 |
| 辰 / 戌 | 紫微 + 天相 | 紫相 |
| 巳 / 亥 | 紫微 + 七杀 | 紫杀 |

**这张表是最强的校验器**：紫微定出来后，看它的同宫星是否符合上表。不符合，一定是紫微宫推错了或局数错了。

**顺带得到的第二条校验**：紫微在寅申时，天府与紫微同宫——此时"紫府对冲"不成立（因为同宫）。初学者常在这里误判为排错，需特别注意。

## 3_3 十四正曜的两系排布原则

十四正曜分两系，排布方向相反：

| 星系 | 成员 | 排布方向 | 气质 |
| --- | --- | --- | --- |
| **北斗（紫微星系）** | 紫微、天机、太阳、武曲、天同、廉贞 | 逆行 | 主动、外放、开创 |
| **南斗（天府星系）** | 天府、太阴、贪狼、巨门、天相、天梁、七杀、破军 | 顺行 | 主静、内敛、承载 |

**两条铁律**

```latex
铁律 1：紫微与天府永远在对宫（寅申两宫例外，此时紫府同宫）。
铁律 2：紫微系六星逆行布，天府系八星顺行布，
        两系星曜在盘上形成固定的同宫组合。

```

### 同宫组合自检清单

十四正曜在盘上只以固定组合出现，不存在随意搭配。安完星后逐宫核对，出现表中不存在的搭配（例如"廉贞 + 天机同宫"），说明安星有误，立即回查紫微落宫。

| 星系 | 常见同宫搭配 |
| --- | --- |
| 紫微系 | 紫府（寅申）、紫贪（卯酉）、紫相（辰戌）、紫杀（巳亥）、紫破（丑未）、紫微独坐（子午） |
| 天机系 | 机阴（寅申）、机巨（卯酉）、机梁（辰戌）、天机独坐（子午等） |
| 太阳系 | 日月（丑未）、阳巨（寅申）、阳梁（卯酉）、太阳独坐（子午、辰戌、巳亥） |
| 武曲系 | 武府（子午）、武贪（丑未）、武相（寅申）、武杀（卯酉）、武破（巳亥）、武曲独坐（辰戌） |
| 天同系 | 同阴（子午）、同巨（丑未）、同梁（寅申）、天同独坐（卯酉、辰戌、巳亥） |
| 廉贞系 | 廉府（辰戌）、廉贪（巳亥）、廉相（子午）、廉杀（丑未）、廉破（卯酉）、廉贞独坐（寅申） |

> 说明：安星口诀在各流派间存在细微差异，日常实战建议以成熟排盘软件生成盘面，再用"紫府对冲表"与"同宫搭配表"做双重校验。手排的价值在于建立盘感，不在于替代工具。

## 3_4 星系记忆法与派系分组

**记忆口诀**

```latex
北斗（紫微星系）：紫机阳武同廉
  → 紫微、天机、太阳、武曲、天同、廉贞

南斗（天府星系）：府阴贪巨相梁杀破
  → 天府、太阴、贪狼、巨门、天相、天梁、七杀、破军

```

**派系分组（实战极常用）**

| 组合名 | 成员 | 共同特质 | 典型人生脚本 |
| --- | --- | --- | --- |
| **杀破狼** | 七杀、破军、贪狼 | 变动、开创、破立 | 一生大起大落，宜动不宜静，中年后方可定 |
| **机月同梁** | 天机、太阴、天同、天梁 | 谋定、服务、稳健 | 适合体制、专业服务、顾问，宜守不宜急 |
| **紫廉武同（北）** | 紫微、廉贞、武曲、天同 | 主导、执行 | 有主导欲与行动力 |
| **府相梁（南）** | 天府、天相、天梁 | 稳定、辅佐、荫庇 | 宜做二把手、管理者、守成者 |

**为什么要分组看**：单看一颗星是"性格"，看一组星是"人生脚本"。命宫落杀破狼的人，跟他讲"稳定压倒一切"收效甚微——他的能量结构就是要动；命宫落机月同梁的人，让他去搏一把风口，他也拿不住。

## 3_5 空宫：安星层面的规则

本宫无十四正曜，即为**空宫**（又称"无正曜"）。空宫不是"没有"，而是"借"。

**四条硬规则**

1. 空宫须借**对宫**全部星曜来论（包括主星、辅星、煞星一并借入）。
2. 借入星曜的**庙旺等级以原宫位为准**，不随借入宫改变。例：天机在卯宫庙旺，借入酉宫后仍以庙旺论。
3. 空宫的本质象义是**易受环境与他人影响**、主观性弱、适应力强但易摇摆。
4. 空宫若三方四正有众吉拱照，可作"虚而待实"论——潜力大，靠外部资源成就；若三方亦凶，则主漂泊无依。

**常见误用**

+ 误：空宫＝该宫无力。正：空宫＝该宫"借用他人之力"，力量来源在外。
+ 误：借星后按借入宫重新判庙陷。正：庙陷看原宫，这是铁律。
+ 误：空宫一定不好。正：空宫遇吉拱反主灵活通达，许多成功的顾问、中介、整合型人才都是空宫格。

**空宫的高发位置**：由于十四正曜的固定排布，某些宫位天然更容易成为空宫。安星完成后，先把所有空宫圈出来并借好星，再进入读盘——这是最省时间的顺序。

## 3_6 故事：一次"整除取余数"造成的全盘偏移

**背景**。一位学习者给家人手排盘，农历十六出生，命宫干支查纳音为金，定**金四局**。他算紫微时这样处理：16 ÷ 4 = 4 余 0，于是"余数 0 = 不移位"，直接把紫微放在起点宫亥。

**排完之后，同宫搭配表先报了错**

```latex
亥宫若坐紫微，按 3_2 的对照表，同宫星必须是"七杀"（紫杀）。
但他盘上亥宫是紫微独坐，七杀被排到了别的宫。
→ 搭配不合法，说明紫微宫位有问题。

```

**回查发现是"整除"这一步错了**

```latex
口诀规定：能整除时，余数取 n（不是取 0）。
正确算法：16 ÷ 4 整除 → 取 r = 4
  从亥起初一，顺数 (4 − 1) = 3 格
  亥(初一) → 子(初二) → 丑(初三) → 寅(初四)
  → 紫微在寅

```

**紫微落到寅之后，两项校验一起对上了**

```latex
第 1 项 · 同宫搭配：寅宫是"紫微 + 天府"（紫府同宫）→ 与 3_2 表一致
第 2 项 · 紫府关系：寅申两宫是"紫府同宫"的法定例外，
                    此时二星同宫而非对冲，属正常，不是排错

```

**为什么这个错误值得单说**：它不会触发"紫府不对冲"的警报——因为天府本来就是跟着紫微推的，紫微错了天府跟着错，二者仍然对冲。**真正抓住它的是"同宫搭配表"。**

**他后来总结的三句话**

```latex
· 能整除时余数取 n 而不是 0，这是安紫微最高频的一步错。
· 紫府不对冲要查紫微；紫府对冲也不代表盘一定对。
· 紫微定完之后，必须用"同宫搭配表"逐宫核一遍，而不是只看紫府关系。

```

这三句话让他后续的排盘错误率几乎降到零——因为他把**校验顺序固定下来了**，而不是每次从头乱查。

**方法论小结**

```latex
排盘错误是有"因果链"的：
局数错 → 起点宫错 → 紫微错 → 全盘错。
顺着因果链往前查，比从头乱查快十倍；
而"同宫搭配表"能抓住那些对冲检查抓不住的错。

```

## 3_7 手排练习与软件校验

### 手排八天进阶（每天排一张）

```latex
第 1 天：只排命宫、身宫、五行局
第 2 天：加排紫微与天府（用起点宫 + 生日推）
第 3 天：加排紫微系六星（逆行）
第 4 天：加排天府系八星（顺行）
第 5 天：加排禄存、羊陀、魁钺
第 6 天：加排生年四化
第 7 天：加排大限（注意局数决定的年数与顺逆）
第 8 天起：每天完整排一张，并与软件盘对比，记录差异

```

### 校验对照表（手排 vs 软件，逐项打钩）

```latex
☐ 命宫一致   ☐ 身宫一致   ☐ 五行局一致   ☐ 紫微一致
☐ 天府在紫微对宫（寅申除外）   ☐ 十四正曜同宫搭配全部合法
☐ 禄存位置正确   ☐ 羊陀夹禄存   ☐ 魁钺位置正确
☐ 生年四化四星齐全   ☐ 大限年数与顺逆正确

```

**差异处理原则**：手排与软件不一致时，不要直接相信软件。先用手排的四项铁律（紫府对冲、同宫合法、羊陀夹禄、四化齐全）判断谁对；仍无法判断，则回到生辰与真太阳时核对。

**第三张盘最容易漏，但最有价值**：软件盘直接读 → 用四项铁律**反向校验软件是否正确**。软件也会因为输入错误而排错盘，学会反向校验，才是真正掌握安星。
