## 22_1 一阶 · 搭盘（自测题）

```latex
题 1：写出十二地支的顺时针顺序。
题 2：写出六组对冲与四组三合。
题 3：某人生于农历五月午时，命宫在哪一宫？身宫在哪一宫？
题 4：命宫干支为甲子，纳音属什么？五行局是几局？每限几年？
题 5：水二局、农历初五生，紫微在哪一宫？
题 6：庚年生的人，禄存在哪一宫？天魁天钺在哪两宫？
题 7：出生年干为阳干的女性，大限是顺行还是逆行？

```

**答案要点**

```latex
题 1：子丑寅卯辰巳午未申酉戌亥
题 2：对冲——子午、丑未、寅申、卯酉、辰戌、巳亥
      三合——申子辰、亥卯未、寅午戌、巳酉丑
题 3：寅起正月顺数五月 → 午宫；午宫起子时逆数到午时 → 子宫
      命宫在子；身宫：午时属"子午"组 → 身宫在命宫（也在子）
题 4：甲子乙丑海中金 → 金 → 金四局 → 每限 4 年
题 5：水二局起点丑。5 ÷ 2 余 1 → 从丑起初一，顺数 0 格 → 紫微在丑
题 6：禄存在申；魁钺在丑未
题 7：阳干女性 → 逆行（阳男阴女顺行，其余逆行）

```

## 22_2 二阶 · 读数（自测题）

```latex
题 8：太阳在午、在子分别是什么状态？还要加什么修正？
题 9：命宫是空宫，借对宫星曜时，庙陷按哪个宫判定？
题 10：给财帛宫打分：本宫武曲庙旺（+10）、对宫天同陷（-5）、
       两合宫各 +5、邻宫各 +5，请算加权总分。
题 11：列出吉星清单与凶星清单各五颗。
题 12：太阳、太阴的日夜修正方向分别是什么？
题 13：一个落陷的星，被吉星前后夹制，与落陷被煞星前后夹制，
       结论有什么不同？

```

**答案要点**

```latex
题 8：午为庙（日丽中天）、子为陷（日沉深渊）；
      须加日夜生人修正（白天生增力、夜晚生减力）
题 9：按原宫判定（铁律）
题 10：10×0.6 + (-5)×0.4 + 5×0.2 + 5×0.2 + 5×0.1 + 5×0.1
       = 6 - 2 + 1 + 1 + 0.5 + 0.5 = 7 分（中偏强）
题 11：吉星——紫微、天府、太阳、太阴、天同、天梁、左辅、右弼
       凶星——七杀、破军、贪狼、廉贞、巨门、擎羊、陀罗、火星
题 12：太阳白天增力、夜晚减力；太阴夜晚增力、白天减力（互反）
题 13：前者"落陷 + 有吉拱"→ 可救，主后天补足；
       后者"落陷 + 有煞夹"→ 受制严重，是人生短板

```

## 22_3 三阶 · 解盘（自测题）

```latex
题 14：命宫七杀庙旺、福德宫天同落陷，这个人的内外状态如何？给一条建议。
题 15：财帛宫吉、田宅宫凶，属于财富四型中的哪一型？给一条建议。
题 16：夫妻宫廉贞落陷 + 天相庙旺，如何中性表述？
题 17：迁移宫强于官禄宫，事业上给什么建议？
题 18：身宫在财帛宫，人生重心是什么？给一条建议。
题 19：昌曲魁钺四宿全见，但被四煞冲破，说明什么？
题 20：命宫主星落陷，但迁移宫有紫微庙旺照命，说明什么？

```

**答案要点**

```latex
题 14：外在强硬、内心脆弱的"硬撑型" → 学会示弱与求助
题 15：能赚不守型 → 强制资产化，把现金变资产
题 16：感情中"体面与激烈情绪并存"，重点是修补情绪表达方式；
       不用"克""不和"等判决词
题 17：宜外出发展、异地创业、外向型业务
题 18：财务安全感是人生主旋律 → 早做资产规划
题 19：有才华的表象而无实质，且易生嫉妒反复（断人品的关键一条）
题 20：命宫弱、迁移强 → "在外比在家好"，宜外出发展

```

## 22_4 四阶 · 断事（自测题）

```latex
题 21：流年命宫叠本命官禄宫，说明什么？
题 22：大限没开门、流年有扳机，会怎样？
题 23：只有叠宫、没有四化引动，会怎样？
题 24：问"什么时候结束"，该找化禄还是化忌？
题 25：化忌入某宫，第一件事要查什么？
题 26：大限凶、小限吉，这一年该怎么过？
题 27：今年化禄入官禄、化忌入财帛，该怎么断？

```

**答案要点**

```latex
题 21：该年事业是主战场
题 22：事情会发生，但进不去 / 留不下（门没开）
题 23：只是心里想着这件事，不会有实质变化
题 24：找化忌（忌主结果、结束、清算）
题 25：查附近有没有化科（科解忌）
题 26：今年有喘息机会，可用，但不宜做长期承诺
题 27：事业上有机会，但代价是短期钱财压力 →
       "可以做，但要准备好现金流"

```

## 22_5 五阶 · 成局（自测题）

```latex
题 28：入格三验是什么？还要加什么条件？
题 29：官禄宫吉 vs 财帛宫吉，分别断"贵"还是"富"？
题 30：秀而不实的建议应该是"更努力"还是"换环境"？
题 31："七杀临于陷地，流年必见死亡"如何降档？
题 32：主强宾弱、主弱宾强分别对应什么行动策略？
题 33："巨到二宫，必是兄弟无义"如何降档为三步？
题 34：根源三宫是哪三宫？各自对应什么？

```

**答案要点**

```latex
题 28：结构成立 + 主星得地 + 无煞冲破；再加"大限配合"
题 29：官禄吉 → 贵；财帛胜官禄 → 富
题 30：换环境（问题不在能力，在环境）
题 31：高危年份，宜全面体检、避免高危活动、减少长途驾驶与剧烈运动
题 32：主强宾弱 → 保守经营等风来；主弱宾强 → 见好就收，
       把运气换成能力/资产
题 33：结构（巨门在兄弟宫）→ 张力（沟通中挑问题、说话重、起口舌）
       → 建议（权责写清楚 / 争执缓一天回话 / 亲兄弟不做合伙人）
题 34：福德宫（福气厚度）、田宅宫（家族积累）、交友宫（周围人的层次）

```

> 说明：自测题的答案是"判断路径"，不是唯一标准答案。若你的答案依据不同但能指出星曜依据，同样成立。

## 22_6 三十天固化训练表

| 阶段 | 天数 | 每日动作 | 验收 |
| --- | --- | --- | --- |
| 搭盘 | 第 1–5 天 | 每天手排一张盘，做四项交叉校验 | 5 张盘全部通过校验 |
| 读数 | 第 6–12 天 | 每天标一张盘的庙陷 + 四化 | 3 分钟内标完十四正曜 |
| 解人 | 第 13–19 天 | 每天断一个人的性格，用访谈三问确认 | 3 份访谈记录 |
| 断事 | 第 20–26 天 | 每天断一年的流年（叠宫 + 扳机） | 7 份流年简报 |
| 成局 | 第 27–30 天 | 完成 2 份完整的九步断盘 | 2 份一页纸结论 + 回填 |

### 每日十五分钟模板

```latex
前 5 分钟：标盘（庙陷 / 四化 / 夹制）
中 5 分钟：写结论（一句话总评 + 三强三弱）
后 5 分钟：写建议（三条可执行动作）+ 记入日志

```

## 22_7 三种验证动作（贯穿全程）

```latex
一 · 禄忌对赌（每年一次）
  年初写下当年"禄入哪一宫、忌入哪一宫"，
  预判两件具体的事（一件得、一件失）。年底回填。

二 · 逐域对赌（每年一次）
  针对最关心的两个领域，各写一条具体预判。年底回填。

三 · 引动记录（每年一次）
  记录今年中了几重引动（四化 / 叠宫 / 星曜），
  预判"必应 / 有迹象 / 只是念头"。年底回填。

```

**三者共同的要求**：预判必须写成**可验证的事件**（例如"今年会因为合作方产生一笔损失"），不能写成"今年要注意人际"——后者永远"对"，但毫无价值。

## 22_8 毕业自检

学完全部二十三个板块，真正的分水岭不在于记住了多少断语，而在于三件事：

```latex
1. 拿到盘知不知道第一眼看哪里
   → 五步优先级（板块 13）

2. 说得出依据还是只说得出结论
   → 每条断语都能指出星曜依据（板块 13 的纪律）

3. 给的是宿命还是下一步
   → 每条短板配一条可执行建议（板块 19 的伦理）

```

```latex
毕业清单：
☐ 我不再用"一定/必然/注定"
☐ 我不再只看命宫就下结论
☐ 我不再把煞星一律当坏东西
☐ 我不再跳过"大限开门"直接断流年
☐ 我的每条短板后面都跟着一条建议
☐ 我遇到极端结论会先查盘
☐ 我有一本写满真实验证的断语库
☐ 我最近一次断盘，命主说"这个我能试"

```

### 案例小故事：遮住答案再做一遍

一个人做完练习册的自测题，对了八成，很高兴，觉得自己基本掌握了。

带他的人让他把答案全部遮住，隔一周重做同一套题。这次只对了五成。

差别在哪？第一次做的时候，四个选项里"看着像"的那个，他会顺着往下推，越推越觉得对；第二次没有选项可依，才发现自己其实说不清为什么选它。

后来他把这条写进了自己的学习规则：**每份自测至少做两遍，第二遍必须隔一周、且不看第一遍的答案**。

**落点**：自测的分数不重要，隔一周不看答案重做才重要。能识别答案的人，和能推出答案的人，是两种水平。

## 22_9 最后一课

命盘揭示的是**性格倾向、能量结构、时机节奏**——它是自我认知的工具与决策的参考系，不是剧本。

```latex
命盘是底牌，打法在人。
知道自己的底盘与时机，然后做出更清醒的选择，
这才是学命的意义。

```

**三条收尾提醒**

```latex
· 格局好不代表可以不努力，格局差不代表没有机会。
· 断语的价值在于"知道之后怎么做"。
· 凡是让人更加无力、更加恐惧的表述，都是失败的咨询。

```
