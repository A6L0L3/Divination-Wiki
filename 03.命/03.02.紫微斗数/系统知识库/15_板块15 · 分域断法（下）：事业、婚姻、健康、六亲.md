## 15_1 事业：官禄 + 迁移 + 命宫

| 宫位 | 看什么 | 吉象 | 凶象 |
| --- | --- | --- | --- |
| **官禄宫** | 事业、成就、工作模式 | 紫微、太阳、天相庙旺；化权、化科 | 巨门化忌、天刑 + 煞、空劫 |
| **迁移宫** | 外部舞台、公众形象 | 太阳庙旺、吉星拱照 | 火铃、巨门陷、化忌冲 |
| **命宫** | 能力底盘 | 主星庙旺 | 落陷、空宫无吉拱 |
| **夫妻宫**（必看） | 夫官线牵动 | — | 感情动荡常伴事业波动 |

### 富 / 贵的判定法

+ 官禄宫佳吉 → 以**贵**断（地位、权力、专业声望）
+ 财帛宫胜于官禄宫 → 以**富**断（经商、资产）
+ 财官二宫皆吉美 → 富贵双全（**但必须命盘入格，否则不可妄测**）

> 这是古人极精确的一条：**富和贵是两个不同的宫位在主导，要分开看**。很多人笼统地说"又富又贵"，其实盘上往往只有一边强。

### 事业形态判断

| 组合特征 | 适合的事业形态 |
| --- | --- |
| 命宫杀破狼 + 官禄化权 | 创业、开拓型岗位，宜动不宜静 |
| 命宫机月同梁 + 官禄化科 | 体制、专业服务、顾问、教育 |
| 命宫紫府 + 左右 | 管理岗、企业高管、资源整合型 |
| 官禄文昌文曲 | 文职、教育、内容、品牌 |
| 官禄太阳庙旺 | 公众性、需要"被看见"的工作 |
| 官禄天梁 | 医疗、教育、公益、监察、保险 |
| 官禄武曲 + 七杀 | 金融、技术、军警、外科 |
| 迁移宫强于官禄宫 | 宜外出发展、异地创业、外向型业务 |
| 官禄宫强于迁移宫 | 宜守在原地深耕、内部晋升路线 |

**"迁移宫 vs 官禄宫"这一条最实用**：它直接回答了"该不该去外地发展"。迁移强的人，守在原地会憋屈；官禄强的人，盲目外派反而折腾。

## 15_2 婚姻与感情：夫妻宫 + 官禄宫 + 福德宫

**夫妻宫是本位，但必须看夫官线**（夫妻宫 ↔ 官禄宫）。事业动荡与感情波动常互为因果。

| 宫位 | 看什么 | 吉象 | 凶象 |
| --- | --- | --- | --- |
| **夫妻宫** | 配偶特质、感情模式 | 紫微、天府、天同、太阴庙旺；化禄 | 七杀、破军、巨门、廉贞落陷；化忌；左右；煞星 |
| **官禄宫** | 夫官线牵动 | — | 官禄化忌常伴感情压力 |
| **福德宫** | 感情中的真实需求 | 天同、天梁 | 空劫 + 煞（精神难以满足） |
| **子女宫** | 桃花缘分、感情产出 | — | 桃花过旺或过弱 |

### 常见格局的现代解读

| 传统断语 | 现代解读 | 建设性建议 |
| --- | --- | --- |
| 夫妻宫遇杀星 | 感情中冲突多、要求高 | 学习沟通技巧，选心智成熟的伴侣 |
| 夫妻宫见左右 | 感情中易有"第三方因素"介入 | 明确关系边界，警惕工作侵占亲密关系 |
| 夫妻宫化忌 | 对感情执念深、放不下 | 课题是"学会放手与自我完整" |
| 武曲在夫妻宫 | 配偶务实刚硬，感情偏理性 | 需要增加情感表达，不宜只看条件 |
| 太阴在夫妻宫（男命） | 配偶温柔细腻 | 注意对方情绪需求 |
| 廉贞在夫妻宫 | 感情浓烈，爱恨分明 | 需建立边界，忌极端化处理矛盾 |

### 婚姻时机判断（三段式）

```latex
· 有没有（缘分结构）：夫妻宫本宫 + 对宫
· 什么时候（时机）：大限开门 + 流年扳机 + 红鸾天喜
· 好不好（质量）：福德宫是否满足 + 夫官线是否稳定

```

**时机判断的具体信号**：流年命宫叠本命夫妻宫、流年四化（尤其化禄、化科）飞入夫妻宫、红鸾天喜入命身——三者任一出现即为婚恋机会年，多者同现则概率大增。

## 15_3 健康与意外：疾厄 + 父母 + 命宫

| 宫位 | 看什么 | 提示 |
| --- | --- | --- |
| **疾厄宫** | 后天体质、疾病类型 | 主星五行提示薄弱环节（如天同水旺主肾/泌尿、廉贞火主血/心） |
| **父母宫** | 先天遗传、体质来源 | 父疾线同参，看遗传倾向 |
| **命宫** | 元气强弱 | 命宫落陷 + 煞星 → 元气不足 |
| **迁移宫** | 外出意外 | 火铃、七杀在迁移 → 出行需谨慎 |

### 高危信号清单（出现即提示，不作诊断）

```latex
· 羊陀守疾厄     → 血光、手术，眼目之疾（尤其羊陀在卯酉）
· 巨暗在身命疾厄 → 身形瘦弱、消化系统弱
· 天同陷 + 煞    → 免疫力弱、易疲劳
· 廉贞陷 + 煞    → 血、心、免疫相关
· 太阴陷 + 煞    → 内分泌、睡眠
· 火铃在迁移     → 出行意外、异地孤立

```

**表述红线**：疾厄宫的断语只能提示"薄弱环节与体检方向"，**必须明确建议就医**，不作任何医学诊断，不预测重大疾病或死亡。

## 15_4 六亲：兄弟、子女、父母、交友

| 宫位 | 核心 | 现代延伸 | 弱陷表现 |
| --- | --- | --- | --- |
| 兄弟宫 | 兄弟姐妹 | 母亲、合伙人、短期现金流 | 手足缘薄、合作易散 |
| 子女宫 | 子女 | 学生、部属、创意产出、桃花 | 子缘薄、创意受阻、投资失利 |
| 父母宫 | 父母 | 上司、文书、学历、相貌 | 与长辈缘薄、文书出问题 |
| 交友宫 | 朋友 | 下属、同事、客户群 | 助力少、下属不给力 |

**古赋断语的现代改写**

| 古断语 | 原意 | 现代改写 |
| --- | --- | --- |
| 巨到二宫，兄弟无义 | 巨门在兄弟宫 | 与平辈/合伙人之间口舌多，宜把规则写清楚 |
| 刑杀守子宫，子难奉老 | 凶星在子女宫 | 子缘较薄或关系需主动经营；也可能应在"创意产出/下属"上 |
| 相貌加刑杀，刑克难免 | 凶星在父母宫 | 与长辈/上司缘薄，或文书契约易出问题 |
| 恶星应八宫，奴仆无助 | 凶星在交友宫 | 下属与客户关系需制度化，不宜依赖人情 |

## 15_5 男女命的"要宫"差异

|  | 男性重点宫位 | 女性重点宫位 |
| --- | --- | --- |
| **核心要宫** | 命、身、财、官、迁、福（六宫） | 命、身、福、夫妻（四宫） |
| **延伸宫位** | 妻、仆、兄弟 | 子女、父母、兄弟 |

**实操要点**：看女命时，夫妻宫的权重极高，仅次于命身福三宫。而男命更看重事业线（官禄 + 迁移 + 财帛）。

> **时代化说明**：这套权重源自古代社会结构，现代使用时应理解为"**议题集中度**"而非"命运决定项"。男命也可以把关系放在第一位，女命也完全可以在事业上发力——盘上的权重说的是"这个结构下哪些议题更容易成为人生主线"，不是"应该做什么"。

**女命四宫检验法**

```latex
第一宫：命宫   → 性格、禀赋、自我定位
第二宫：身宫   → 后天走向、自我实现
第三宫：福德宫 → 精神世界、福气厚度
第四宫：夫妻宫 → 亲密关系质量、伴侣特质

```

## 15_6 故事：该不该接那个外地岗位

**背景**。有人拿到一个外地分公司的机会，薪资涨三成，但要举家搬迁。他来问："该不该去？"

**第一步：比较迁移宫与官禄宫**

```latex
官禄宫：天相庙旺 + 天魁      → 强（在现有体系里有人、有位置）
迁移宫：太阳庙旺 + 化禄      → 更强（外出得利、人缘佳、遇贵人）
对宫检查：
  官禄的对宫是夫妻宫 —— 天同平（感情平稳，无大阻碍）
  迁移的对宫是命宫   —— 天府庙旺（自身底盘稳，撑得住变动）

```

**结论**：**迁移宫强于官禄宫 → 宜外出发展**。这不是"要不要冒险"的问题，而是"哪个舞台更适合他"的问题。

**第二步：看时机（不能只看宫位强弱）**

```latex
当前大限：走在迁移宫 → 这十年的门开在"外部"
今年流年：叠本命迁移宫 + 流年化禄入迁移
→ 大限开门 + 流年扳机 → 两重命中，是真正的窗口年

```

**第三步：看代价**

```latex
夫妻宫天同平（不是凶）→ 搬迁不会伤到关系，但需要提前沟通
田宅宫有破军         → 置产上会"先破后成"，
                       卖房买房的过程中有波折，宜早做规划

```

**给的建议（三条，都可执行）**

```latex
1. 去。迁移宫强于官禄宫，且大限流年双重命中，这是窗口。

2. 田宅宫破军提示：不要"先卖后买"的紧凑操作，
   留出至少半年的过渡期，避免两头挤压。

3. 夫妻宫虽平，但搬迁是关系事件——
   提前与伴侣谈清楚"去几年、什么时候回来"，
   不要等到了外地再谈。

```

**后来的反馈**。他去了，第一年确实遇到置产波折（卖房时买家临时变卦），但因为留了过渡期，没有两头挤压。第三年升任分公司负责人。他说："当时最纠结的是'要不要冒险'，其实真正该问的是'哪个舞台更适合我'。"

**方法论小结**

```latex
"该不该去外地"不是勇气问题，是盘面问题：
· 迁移宫强于官禄宫 → 宜外出
· 官禄宫强于迁移宫 → 宜深耕

宫位强弱定方向，大限流年定时间，对宫与关联宫定代价。
三者都看了，才能给出"去 + 怎么去"的完整答案。

```
