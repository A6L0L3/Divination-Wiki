# 板块19 · 表述伦理与咨询边界

> 同样一条断语，说对了是帮助，说错了是伤害。

本板块解决"怎么把古人的话安全地说出口"。

---

## 19_1 五条红线（不可逾越）

1. **不预测死亡**。任何情况下都不对任何人（尤其婴幼儿、老人、病人）作出死亡或重大灾祸的预测。古赋中的"夭折""灾亡"类断语，必须转化为健康提醒。
2. **不作医学诊断**。疾厄宫的断语只能提示"薄弱环节与体检方向"，必须明确建议就医。
3. **不替代重大决策**。婚姻、生育、投资、择业、手术——命理可以提供视角，不能替人做决定。正确的说法是"从盘上看，这个方向的阻力/助力在哪里"，而不是"你应该离婚/辞职/投资"。
4. **不制造焦虑**。断语的价值在于"知道之后怎么做"。凡是让人更加无力、更加恐惧的表述，都是失败的咨询。
5. **不使用侮辱性与等级性词汇**。"下贱""寡宿""淫佚""为奴为仆"等，一律改写为中性的人格特质描述。

---

## 19_2 三条表述原则

1. **倾向而非定论**：用"倾向于""更容易""需要注意的是"，不用"一定""必然""注定"。
2. **结构而非宿命**：讲清"为什么"（星曜依据），比给结论更重要。命主理解了结构，才可能真正改变行为。
3. **每条短板配一条建议**：指出问题的同时必须给出可执行的下一步。只诊断不开方，是失职。

---

## 19_3 古断语的降档公式

```latex
古代断语 → 现代表达

"必主XX灾"        → "这个领域需要格外留意，建议提前预防"
"克夫/克子"        → "亲密关系中存在张力，需要主动经营"
"贫贱/下贱"        → "该结构下宜以技能立身，不宜依赖运气"
"好淫/邪淫"        → "情感与欲望能量偏强，宜以事业/才艺疏导"
"夭折/灾亡"        → "健康需要重点关注，建议定期体检"
"三嫁而心不足"     → "感情中要求较高、易不满足，宜先厘清自己的需求"
"为奴为仆"         → "易处于被支配位置，宜提升专业话语权"
"眼目昏盲"         → "注意眼部与用眼健康"
"兄弟无义"         → "平辈/合作中口舌偏多，宜把规则写清楚"
"子难奉老"         → "子缘较薄或关系需主动经营"
"奴仆无助"         → "下属与客户关系需制度化，不宜依赖人情"
"刑克难免"         → "与长辈缘薄，或文书契约易出问题"
"泛水桃花"         → "才华横溢而漂泊，宜以才艺与事业疏导"
"风流刑杖"         → "感情边界要清晰，忌暧昧关系"
"终身鼠窃"         → "投机心重，宜立规矩、设止损"
"沿途丐求"         → "财务极端保守期，优先保证现金流"

```

**降档的三条原则**

1. **保留结构，去掉判决**：断语描述的是"张力模式"，不是"必然结果"。
2. **把等级词换成特质词**："下贱" → "该结构下的行为倾向"，不评价人格。
3. **每条断语配一条建议**：降档之后必须能接上"所以你可以做某个具体动作"，否则降档没意义。

## 19_4 降档三步法（标准操作流程）

```latex
第 1 步 · 找出"结构"
  这句断语说的是哪颗星、落在哪一宫？

第 2 步 · 写出"张力模式"
  它描述的是什么样的互动倾向？（不是结果，是倾向）

第 3 步 · 补一条"可执行建议"
  命主明天能做的一个动作是什么？

```

**改写不出第三步，说明你还没真正理解这句断语。** 这是检验降档是否到位的唯一标准。

## 19_5 高危领域的专门话术

### 健康类（最容易越界）

| 不要这样说 | 应该这样说 |
| --- | --- |
| 你疾厄宫很凶，会得大病 | 疾厄宫这个结构提示你的消化系统（举例）是相对薄弱的环节，建议把它列入常规体检项目 |
| 你今年有血光之灾 | 今年羊陀在疾厄，注意用眼与用刀安全，建议做一次常规体检 |
| 你寿命不长 | 不作任何寿命判断。改为："这个盘的元气偏弱，健康上宜早做规划、定期检查" |

### 婚姻类（最容易伤人）

| 不要这样说 | 应该这样说 |
| --- | --- |
| 你克夫 | 你在亲密关系里要求比较高，也容易把注意力放在对方身上，课题是学会先安顿好自己 |
| 你会三嫁 | 你在感情中容易不满足，建议先厘清自己真正要的是什么，再进入关系 |
| 你婚姻注定不顺 | 夫妻宫这个结构意味着亲密关系中的摩擦偏多，课题是沟通方式与边界感 |

### 财务类（最容易制造恐慌）

| 不要这样说 | 应该这样说 |
| --- | --- |
| 你今年要破大财 | 今年财帛宫有破耗结构，宜推迟大额投资、不做担保、预留应急金 |
| 你一辈子没钱 | 这个盘的财富特征是"能赚不守"（举例），宜强制资产化 |
| 你注定穷 | 该结构下宜以技能立身，不宜依赖运气性收入 |

### 事业类（最容易给反建议）

| 不要这样说 | 应该这样说 |
| --- | --- |
| 你事业不行 | 你的官禄宫三方被煞冲破（举例），问题不在能力而在环境，宜换平台 |
| 你该创业 | 从盘上看你的底盘适合变动（举例），但今年忌在财帛，宜先备足现金流再动 |

## 19_6 咨询自检表（说完一段话后自问）

```latex
☐ 我用了"一定/必然/注定"吗？      → 有则改写
☐ 我说了死亡、重病、灾祸吗？      → 有则改为提醒
☐ 我替命主做了决定吗？            → 有则改为"阻力/助力在哪里"
☐ 我用了等级性或侮辱性词汇吗？    → 有则改为特质描述
☐ 我每条短板都配了建议吗？        → 没有则补
☐ 命主听完更有力了，还是更无力了？ → 后者必须重说

```

## 19_7 故事：一句"改了三次"的话

**背景**。有个学习者给人断盘，前后说了三个版本，第三个版本才真正起作用。

**第一版**："你夫妻宫有煞，婚姻注定不顺。"
犯了四个错：用了"注定"、下了判决、没有结构解释、没有建议。命主听完就沉默了。

**第二版**："你夫妻宫有煞星，感情中容易有冲突。"
好一点，但还是没有结构、没有建议，且"容易有冲突"仍然空泛。命主问"那我该怎么办"，他答不上来。

**第三版**："你夫妻宫是廉贞落陷加擎羊同宫，你的感情模式是'爱恨分明、说话直接'，这在亲密关系里容易造成激烈摩擦。建议你和伴侣约定一个'争执不隔夜、但争执时先缓半小时再说话'的规则——这不是性格问题，是表达方式的问题。"

**第三版做对了什么**

```latex
1. 指出星曜依据（廉贞陷 + 擎羊）→ 可追溯
2. 把"凶"翻译成"模式"（爱恨分明、说话直接）→ 中性化
3. 把"模式"翻译成"具体行为规则" → 可执行
4. 明确说"这不是性格问题" → 不给宿命判决

```

**命主听完说**："这个我能试。"

**方法论小结**

```latex
判断表述好坏的唯一标准：
命主能不能把它变成明天的一个动作。

"你婚姻不顺"      → 命主什么也做不了，只会更焦虑
"争执缓半小时再说" → 命主今晚就能开始

```

## 19_8 笔记法：话术打磨三步

```latex
第 1 步：写下第一版结论（通常是"XX宫有XX星，所以XX"）
第 2 步：加一层结构（"因为XX，所以你在XX情况下会XX"）
第 3 步：加一个动作（"建议你XX，具体做法是XX"）
三版都写下来，对比哪一句最容易被执行。

```
