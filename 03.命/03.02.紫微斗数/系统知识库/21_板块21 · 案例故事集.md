# 板块21 · 案例故事集

> 本板块是全库所有推演故事的**总索引**。全库共 23 个故事，每个都写在它所属的知识点旁边——因为故事离开上下文就只剩情节，失去教学价值。
>
> 因此本板块不复述完整情节，而是给每张故事做一张**推演卡片**：背景一句话、盘面条件、推演链条、结论、教训。想看完整叙述，按"所在板块"回查即可；想快速复习推理路径，读卡片就够了。
>
> 所有案例均为**教学用简化示例**，用于演示推理链条，不代表任何真实命盘。

## 21_2 入门段故事（起盘与节奏）

### 卡片 1 · 一张被误判了三年的盘（板块 0）

```latex
背景：学习者看到家人财帛宫坐地空地劫，断"财运很差"，建议保守别投资。
      三年间家人错过两次买房窗口。
盘面：财帛空劫（-10×0.6）但福德天同庙旺化禄（+15×0.4）、
      命宫天府庙旺、迁移太阴旺，加权后 ≈ +4.8（中偏上）
链条：本宫负分 → 对宫化禄补回 → 田宅天府入庙（守得住）→ 改判
结论：现金留不住，但资产端很稳 → 宜强制资产化
教训：单宫断吉凶＝只用 60% 的信息下 100% 的结论；
      空劫在财帛是"钱不以现金形式停留"，不是"赚不到"

```

### 卡片 2 · 同一个"午时"，两张错开的盘（板块 1）

```latex
背景：两位学习者生辰只差一天，都是午时，命宫都落在辰，于是互抄结论。
盘面：命宫相同，但命宫干支差一组纳音
      → 金四局（每限 4 年） vs 土五局（每限 5 年）
链条：同宫位、同大限序 → 因局数不同，时间窗口差数年
结论：一人把计划提前，正好踩在官禄化权上；另一人按原节奏，也未错失
教训：准的不是断语，是局数带来的时间差被算对了；
      宁可花十分钟核对生辰，不要花十小时圆场

```

### 卡片 3 · 两位"同盘"客户，一快一慢（板块 2）

```latex
背景：同年同月同日同时生，出生地相距数百公里，都问"什么时候转型"。
盘面：真太阳时差异 → 命宫错开一位 → 木三局 vs 金四局
链条：木三局每限 3 年 → 走到官禄宫早；金四局每限 4 年 → 明显更晚
结论：A 主动换赛道，第三年做到主管；B 深耕到四十岁后被推上管理岗
教训：同盘不同命的现代解释——差异不在星曜，在真太阳时与局数；
      断"什么时候"，第一件事永远是确认局数

```

### 卡片 4 · 一次"整除取余数"造成的全盘偏移（板块 3）

```latex
背景：农历十六生、金四局，他把 16÷4 余 0 当成"不移位"，紫微定在起点亥。
盘面：亥宫紫微独坐，但对照表要求亥宫必须是"紫杀" → 搭配不合法
链条：同宫搭配表报错 → 回查口诀"整除时余数取 n" → 重推得 r=4
      → 从亥起初一顺数 3 格 → 紫微在寅 → 寅宫"紫府同宫"，对上
结论：紫微错一格，十四正曜全盘偏移
教训：紫府对冲不代表盘一定对——天府跟着紫微走，会一起错；
      能抓住这类错的是"同宫搭配表"

```

### 卡片 5 · 一次"贵人全无"的假象（板块 4）

```latex
背景：学习者发现自己命宫三方四正一颗吉星都没有，以为"一辈子没贵人"。
盘面：四项校验全过（庚年禄存在申、羊陀夹禄、四化齐全、魁钺在丑未）
链条：先查盘 → 盘是对的 → 再看宫位本身
      → 魁钺落在丑未，不在命宫三方，但在夫妻宫与福德宫的三方
结论：贵人不在主线上，在"关系宫"与"精神宫"这两条线上
教训：遇到"全盘无吉"这类极端结论，第一反应是查盘不是算命；
      "命宫三方无吉" ≠ "整盘无吉"

```

## 21_3 读盘段故事（读数与解人）

### 卡片 6 · 一句"父母宫有煞"引发的误会（板块 5）

```latex
背景：看到父母宫有煞，问"是不是与父母缘分薄，注定疏远"。
盘面：第一层（父母）核对——与父母同住、关系尚可 → 没对上
链条：转到第二层（上司/权威）→ 两年换三次领导，每次理念不合
      转到第三层（文书契约）→ 租房合同条款漏洞、学历认证被退回
结论：不是与父母缘薄，是"权威关系"与"文书契约"同期集中出问题
教训：断语对不上第一层，先看第二、三层；
      十二宫的多义性是避免误判的第一道保险

```

### 卡片 7 · 四面楚歌的官禄宫，出路在对面（板块 6）

```latex
背景：六年换三任领导，每次"快出成果就被人摘走"，问是不是事业宫没救。
盘面：本宫巨门落陷 + 擎羊（-6.0）但夫妻宫天同庙旺 + 天魁（+4.8）、
      迁移宫太阳庙旺、田宅天府入庙 → 加权 ≈ +2.8
链条：本宫确实弱 → 但对宫极强（夫官线：阻力在关系处理）
      → 邻宫迁移宫强（在外比在内好）
结论：不是忍，也不是提升业务能力，而是"书面确认归属 + 换地方"
教训：四面楚歌说的是此宫自身支持接近零，不等于没救；
      本宫定"行不行"，对宫定"卡在哪"，邻宫定"往哪走"

```

### 卡片 8 · 同样"能力强"，两种不同的苦（板块 7）

```latex
背景：两位同事都被评价"能力强"，三年后一个升高管，一个频繁跳槽。
盘面：A 紫微在午入庙 + 左右天魁会照（有人接得住的强）
      B 七杀落陷 + 三方无吉拱、对宫无紫微朝照（硬撑出来的强）
链条：主星定能量形状 → 星组定人生脚本 → 庙陷定能量好不好用
结论：A 该守平台养团队；B 该选"单兵突破"型岗位
教训：同样是"能力强"，一个人该守，一个人该走；
      对杀破狼说"稳一点"收效甚微

```

### 卡片 9 · 一颗"火星"的两种命运（板块 8）

```latex
背景：两张盘都有火星，都在"旺"位，体验却天差地别。
盘面：A 火星在官禄宫庙旺 + 贪狼同宫、三方无空劫
      B 火星在迁移宫落陷 + 逢地空
链条：煞星三问——得令吗 / 有制吗 / 被用在哪
      A 三问全正面 → 爆发力；B 三问全负面 → 意外与孤立
结论：A 适合打突击战；B 宜改成"本地深耕 + 偶尔出差"
教训：煞星一定坏是最害人的误区；煞星是未被驯服的能量，不是判决书

```

### 卡片 10 · 一场"来了又走"的合作（板块 9）

```latex
背景：来问一笔合作能不能成。
盘面：天盘官禄化禄 + 地盘大限官禄化权 + 流年化禄入官禄、化忌入交友
链条：禄在官（机会进来）+ 忌在交友（合作环节出问题）= 得失同源
结论：会成，但会在合作环节出问题 → 合同加违约条款、分阶段付款
教训：只看禄漏风险，只看忌漏机会，禄忌同看才说得出完整结构

```

### 卡片 11 · 被"落陷"两个字吓到的人（板块 10）

```latex
背景：看到命宫主星落陷，当场问"是不是这辈子完了"。
盘面：得垣受制四步——落陷，但同宫有天魁、无煞，前后两宫文昌禄存吉夹，
      对宫还有紫微庙旺照命
链条：查亮度 → 查同宫 → 查夹制 → 查对宫 → 定结论
结论：落陷 + 有吉拱 + 吉夹 → "先天不足，后天可补"
教训：落陷说的是这股能量不好用，不是这股能量不存在；
      被吉星夹和被煞星夹，是天壤之别

```

## 21_4 论断段故事（断事与应期）

### 卡片 12 · 一个"入格"却没发达的盘（板块 11）

```latex
背景：盘被判"三奇嘉会格"，命主四十多岁事业平平，问是不是错过了什么。
盘面：验 1 结构成立（通过）；验 2 主星得地（化禄星、化科星落陷，不过）
      验 3 无煞冲破（化权星同宫有擎羊，不过）；验 4 大限配合（不过）
链条：三条只中第一条 → 不是三奇嘉会，是"三奇破格"
结论：不要再等格局兑现，上限要靠专精；财务强制资产化
教训：格局名只是标签，三验才是内容；
      看到组合就喊格局，等于看到食材就宣称是一道菜

```

### 卡片 13 · 为什么"好运"没兑现（板块 12）

```latex
背景：流年化禄入官禄、化科入命，为此推掉另一个机会专心等待，结果落空。
盘面：原局命宫主星落陷、官禄宫有煞（底盘弱）
      大限走闲陷之宫，四化未触及官禄（门没开）
      流年禄入官禄、科入命（扳机响了）
链条：三层只有一层 → 机会来了但能力资源不具备
结论：那年只是"有人介绍"，不是"大事必应"
教训：流年只是扳机，大限才是门，原局才是底子；
      扳机响了但门没开＝有机会但进不去

```

### 卡片 14 · 一次完整的九步断盘（板块 13）

```latex
背景：来问"该不该换工作"。
盘面：命宫杀破狼庙旺、身宫在官禄；生年禄在官禄、大限化权入官禄、
      流年化禄入官禄 + 化忌入财帛；未构成经典富贵格但有开创结构
链条：第 2、3、6 步得出"可以换"；第 5、7 步得出"但要准备现金流"
结论：可以换，但预留现金、选能带走的技能方向、避免同年置业
教训：只说"可以换"会让人裸辞，只说"忌在财帛"会让人错过机会；
      两层缺一，建议就是残缺的

```

### 卡片 15 · 一个"有钱不快乐"的盘（板块 14）

```latex
背景：收入不错但总觉得不踏实，"赚到了但好像没赚到"，已做过三次财务规划。
盘面：财帛武曲庙旺化禄（能赚）+ 田宅天府入庙禄存（能守）
      + 福德天同落陷地空（享受不到）
链条：先排除"钱不够" → 定位缺口在福德宫 → 对照财福线（财吉福凶）
结论：停手财务规划、补非金钱满足源、设一条"够用线"
教训：单宫只能给一个答案，三线合看能给三个动作；
      先证明"钱不够"是假问题，否则命主会第四次找错方向

```

### 卡片 16 · 该不该接那个外地岗位（板块 15）

```latex
背景：外地分公司机会，薪资涨三成但要举家搬迁。
盘面：官禄天相庙旺 + 天魁（强）；迁移太阳庙旺 + 化禄（更强）
      大限走迁移宫、流年叠迁移宫 + 化禄入迁移（两重命中）
      田宅有破军（置产先破后成）
链条：宫位强弱定方向 → 大限流年定时间 → 关联宫定代价
结论：去；但置产留半年过渡期，搬迁前先与伴侣谈清"去几年"
教训：这不是勇气问题，是盘面问题；
      真正该问的是"哪个舞台更适合我"，不是"要不要冒险"

```

### 卡片 17 · 一场被"提前半年"化解的破财（板块 16）

```latex
背景：流年"大耗 + 破军"会照财帛宫且有化忌入财帛，问是不是要破大财。
盘面：大限命宫紫微庙旺 + 化权（大限整体吉）
链条：先看大限背景 → 大限吉则流年凶可减 → 分层表述
结论：有破耗结构但不伤根本 → 推迟大额投资、预留现金、分阶段付款
教训：高危断语 + 大限背景 = 分层表述；
      有效趋避＝把大损失变成小损失，而不是变成没有损失

```

## 21_5 收口段故事（古赋、伦理与工具箱）

### 卡片 18 · 一句"兄弟无义"引发的误会（板块 17）

```latex
背景：看到兄弟宫有巨门，对照"巨到二宫，必是兄弟无义"，问是否注定不和。
盘面：巨门（口舌、探究、疑）落在兄弟宫（平辈、合伙人）
链条：降档三步——结构（巨门在兄弟宫）
      → 张力模式（沟通中挑问题、说话重、易起口舌）
      → 建议（权责写清楚 / 争执缓一天回话 / 亲兄弟不做合伙人）
结论：兄弟感情其实不错，但每次合伙做事都因沟通方式吵架
教训：古断语的价值在于指出张力在哪里，不在于预言结果；
      直接照搬古文，断语就从工具变成伤害

```

### 卡片 19 · 一位女企业家的"寡宿"（板块 18）

```latex
背景：三十多岁女性创业者看到"武曲之宿为寡宿"，问是不是注定婚姻不好。
盘面：武曲（阴金、化气为财、主刚决执行）独坐命宫
链条：结构 → 张力模式（务实理性、直奔结果、忽略情绪铺垫、独立性强）
      → 建议（每周一次不谈正事的对话 / 有需求直接说 / 选能欣赏独立的伴侣）
      → 时代化改写（"寡宿" → "独立能干、关系偏理性"）
结论：在古代是"寡宿"，在今天可能是一位创业者的核心底盘
教训：女命断语改写两步——去等级词、换坐标系；
      断语没变，变的是我们用什么尺子量它

```

### 卡片 20 · 一句"改了三次"的话（板块 19）

```latex
背景：学习者给人断夫妻宫，前后说了三个版本，第三个才起作用。
盘面：夫妻宫廉贞落陷 + 擎羊同宫
链条：一版"注定不顺"（判决、无结构、无建议 → 命主沉默）
      二版"容易有冲突"（稍好，但仍空泛 → 命主问怎么办，答不上来）
      三版"廉贞陷加擎羊＝爱恨分明、说话直接 → 约定争执先缓半小时"
结论：第三版做对了四件事：指出星曜依据、把凶译成模式、
      把模式译成行为规则、明确不当性格问题讲
教训：判断表述好坏的唯一标准——命主能不能把它变成明天的一个动作

```

### 卡片 21 · 要不要辞职创业（板块 20）

```latex
背景：来问要不要辞职创业。
盘面：命宫紫府 + 左右（管理整合型底盘）；大限走田宅宫 + 田宅化禄；
      流年化禄入财帛、化忌入官禄
链条：底盘适合"管好已有资源"而非从零开创
      → 十年门开在"守成与资产"，不在"开创"
      → 禄在财但忌在官：钱来自"工作变动"，不是"新事业做成"
结论：不宜裸辞创业；若要动，优先内部创业或依托现有平台的新业务
教训：结论不是"创或不创"，而是"在什么条件下创、以什么形式创"

```

### 卡片 22 · 为什么他赚得到却存不住（板块 20）

```latex
背景：收入很高但资产始终攒不下来。
盘面：财帛武曲庙旺化禄（能赚）+ 田宅破军地劫（守不住）
      + 福德天同落陷火星（情绪性消费）
链条：赚 ✓ / 守 ✗ / 享受 ✗ → 归入"能赚不守型"
结论：强制资产化、设 72 小时决策冷却期、主动规划一次置业、不碰投机
教训：财务问题的第一刀要切在赚／守／享受哪一段；
      切错了对"守而不赚"的人说"强制储蓄"，只会让他更保守

```

### 卡片 23 · 这段关系该继续吗（板块 20）

```latex
背景：来问一段关系该不该继续。
盘面：夫妻宫廉贞落陷 + 天相庙旺；对宫官禄化忌；福德天同庙旺；
      流年化忌入夫妻宫 + 流年命宫叠本命夫妻宫
链条：本宫（体面与激烈情绪并存）→ 夫官线化忌（事业压力投射到感情）
      → 福德天同庙（要的是安心，不是戏剧性）→ 流年化忌（了结性质）
结论：今年是"结算年"；判断标准是这段关系让内心需求更满足还是更消耗
教训：不替命主做决定，给判断框架——核心需求是什么、
      关系是满足还是消耗、不要在什么状态下做决定

```

## 21_7 怎么使用这些故事

```latex
第 1 步 · 按 21_6 的场景表挑一个与你当前问题最接近的故事
第 2 步 · 只读它的"链条"部分，把推理路径抄一遍
第 3 步 · 换上自己手上的盘，走同样的步骤，写出自己的结论
第 4 步 · 与卡片里的结论对照，看差异出在哪一层

```

**故事的价值不在情节，在可复用的推理路径。** 抄三遍别人的链条，比读三十遍断语有用。
