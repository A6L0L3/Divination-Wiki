## 20_1 推演示范 A：要不要辞职创业？（事业决策）

> 说明：以下为**教学用简化示例**，仅演示推理链条，星曜配置为示意，不代表任何真实命盘。

**已知条件**

+ 命宫：紫微 + 天府结构，会左辅右弼 → 底盘是"管理整合型"，擅长把已有的事做好
+ 当前大限：大限命宫走入本命田宅宫 → 这十年的主战场在"守成与资产"
+ 大限四化：田宅宫化禄 → 这十年利于置产与积累
+ 明年流年：流年命宫叠本命官禄宫，流年四化：化禄入财帛、化忌入官禄

**推演链条**

```latex
第 1 重（底盘）：紫府 + 左右 = 管理整合型
  → 这类底盘的优势是"把已有的资源管好、放大"
  → 从零创业恰恰不是它的强项（缺的是破局型的开创星）

第 2 重（大限开门）：大限走田宅宫 + 田宅化禄
  → 这十年的门开在"守成与资产"，不在"开创新事业"

第 3 重（流年扳机）：化禄入财帛 + 化忌入官禄
  → 禄在财 = 这一年有钱进来
  → 忌在官 = 但代价落在事业/工作这个位置上
  → 组合象：会因"工作上的变动"而产生钱财上的变化

```

**冲突信号与解读**

```latex
表面看：化禄入财帛像是"创业能赚钱"
完整看：忌在官禄 → 这个钱来自"放弃/变动现有工作"，
        而不是来自"新事业做成"

```

**结论与建议**

+ 结论：**不宜裸辞创业**。这个盘的十年门开在"守成"，不是"开创"；流年虽有钱进来，但来源是"工作变动"而非"事业起步"。
+ 建议：
    1. 若要创业，优先选择**内部创业 / 依托现有平台的新业务**，而不是从零开始；
    2. 把今年的"化禄入财帛"用在**资产配置**上（呼应大限田宅化禄），而不是全部投入项目；
    3. 若要动，等到大限走进官禄宫或迁移宫再启动，届时门才真正打开。

**这个示范的方法论**：结论不是"创"或"不创"，而是"**在什么条件下创、以什么形式创**"。底盘定"适合什么形态"，大限定"十年门开在哪"，流年定"今年的钱从哪来、代价落哪"。

## 20_2 推演示范 B：为什么他赚得到却存不住？（财务结构）

**已知条件**

+ 财帛宫：武曲庙旺 + 化禄 → 赚钱能力很强
+ 田宅宫：破军 + 地劫 → 守财与资产积累环节有破
+ 福德宫：天同落陷 + 火星 → 精神上难以安定，消费有冲动性

**推演链条**

```latex
财帛宫（赚钱）：强 → 能赚
田宅宫（守财）：破军 + 空劫 → 资产端有漏洞，钱进来会漏出去
福德宫（享受/落袋）：天同陷 + 火星 → 情绪性消费、冲动决策

结论：能赚不守型
问题不在"开源"，在"节流"与"资产化"

```

**结论与建议**

+ 结论：**典型的"能赚不守"结构**。命主的问题从来不是赚不到，而是留不住。
+ 建议（针对性、可执行）：
    1. **强制资产化**：收入到账即按比例转入不易动用的账户/资产，把"现金"变成"资产"。
    2. **设置决策冷却期**：福德宫天同陷 + 火星，主情绪驱动型消费，任何超过一定金额的非必需支出，强制 72 小时冷静期。
    3. **把破军的"破"用在正确的地方**：破军在田宅主"先破后成"——主动规划一次置业（而非被动破财），反而应了格局。
    4. **不碰高风险投机**：空劫在田宅，投机性资产的损耗概率高。

**方法论**：财务问题的第一刀要切在"赚 / 守 / 享受"哪一段。三段切错，建议就是反的——对"守而不赚"的人说"强制储蓄"，只会让他更保守。

## 20_3 推演示范 C：这段关系该继续吗？（感情判断）

**已知条件**

+ 夫妻宫：廉贞 + 天相，廉贞落陷，天相庙旺
+ 夫妻宫对宫（官禄）：化忌
+ 福德宫：天同庙旺
+ 当前流年：流年化忌入夫妻宫，流年命宫叠本命夫妻宫

**推演链条**

```latex
第 1 步（本宫）：廉贞落陷 + 天相庙旺
  廉贞陷：感情中爱恨分明、情绪浓烈、容易走极端
  天相庙：有体面、有分寸、重承诺的一面
  组合象：这段关系里，"体面"与"激烈的情绪"并存

第 2 步（对宫/夫官线）：官禄宫化忌
  夫官一线，事业的执念投射到感情，或感情影响事业判断
  提示：命主可能因为事业压力而迁怒于关系

第 3 步（福德宫）：天同庙旺
  内心深处渴望安稳与温柔，与廉贞的激烈形成反差
  关键信号：命主要的是"安心"，不是"戏剧性"

第 4 步（流年）：流年化忌入夫妻宫 + 叠宫
  今年感情是重点课题，且是"了结/清算"性质（化忌主结果）

```

**结论与建议**

+ 结论：**今年是这段关系的"结算年"**——化忌入夫妻宫主结果的显现，不是新开始。是否继续，取决于一个判断：这段关系是让福德宫（内心需求）更满足，还是更消耗？
+ 建议（不替命主做决定，给判断框架）：
    1. 命主的核心需求是"安稳"（福德天同庙），而廉贞陷带来的正是"不安稳"。**问自己：这段关系里，安心的时候多，还是戏剧性的时候多？**
    2. 夫官线化忌提示：不要在事业高压期做感情的重大决定，容易把外部压力误判为关系问题。
    3. 若选择继续：重点修补的是"情绪表达方式"（廉贞陷的功课），而非换人。
    4. 若选择结束：今年适合"了结"，但要避免在情绪峰值时做决定。

**方法论**：感情问题不替命主做决定，而是给出**判断框架**（你的核心需求是什么 + 现在的关系满足还是消耗 + 不要在什么状态下做决定）。

## 20_4 高频问题 Q&A

**Q1：紫微坐命就一定好吗？**
不一定。紫微是帝星，需要"臣"来辅。必须有左辅右弼、天魁天钺等吉星拱照，且紫微自身庙旺，才能发挥。紫微落陷或三方无吉，是"孤君无辅"——有架子没实力，人缘与执行力都成问题。

**Q2：命盘里有煞星是不是很惨？**
恰恰相反，很多成大事者盘上都有明显的煞星。关键看三件事：是否得令（庙旺）、是否有制（有无吉星同宫）、是否被用在合适的地方（职业匹配）。火星在旺宫为富论，羊陀得令成魄力。**煞星是未被驯服的能量，不是判决书。**

**Q3：空宫是不是很不好？**
空宫 = 借对宫星曜来论，本质是"易受环境影响、适应力强、主观性弱"。空宫遇吉拱反主灵活通达，适合顾问、中介、整合型工作。空宫最怕的是三方四正也无吉星，那才是真的虚。

**Q4：化忌是不是灾星？**
化忌是"执念、聚焦、结果"。它放哪里，哪里就是一生的课题，也是可能钻得最深的领域。化忌的严重程度看四件事：星的善恶、落的宫位、有没有化科解、冲哪里。**化忌 ≠ 灾，化忌 = 你要用一生去修的功课。**

**Q5：同盘的人命运一样吗？**
不一样。即使同年同月同日同时生，出生地经纬度不同会导致真太阳时差异，命宫可能就错开一位。更不用说后天的家庭、教育、选择、时代环境——**命盘是底牌，打法在人**。

**Q6：流年说我今年有灾，怎么办？**
第一步是查三件事：原局给不给这个能力（大限开没开门）、流年四化落在哪（扳机在哪）、有没有化科解。**绝大多数"灾"的实际表现是一次破财、一场小病、一段关系紧张。** 高危年的正确姿势是：降杠杆、增储备、缓决策、查身体、早处理隐患。

**Q7：我应该信命吗？**
更准确的问法是：我该怎么用命盘？命盘揭示的是**性格倾向、能量结构、时机节奏**——它是自我认知的工具与决策的参考系，不是剧本。知道自己的底盘与时机，然后做出更清醒的选择，这才是学命的意义。

**Q8：断语说"克夫""克子""贫贱"，是真的吗？**
这类断语是古代社会结构与统计经验的产物，现代必须全面降档。它们描述的是**关系中的张力模式**（如"武曲为寡宿"实为独立刚硬、婚姻需要主动经营），不是对他人的伤害。改写方式见板块 19。

**Q9：为什么我按断语去断，常常不灵？**
最常见的原因是三层里只中了一层：只有流年扳机、大限没开门；或只有叠宫、没有四化引动。其次是漏了日夜修正、漏了夹制、漏了对宫权重。**先查盘，再查层，最后才怀疑断语本身。**

**Q10：流派之间说法不一样，该信哪个？**
固定一套，全程不切换。流派差异主要集中在庚壬两干四化、部分主星庙旺宫位。中途换标准的后果是前后结论打架——**一致性比"哪个更对"更重要。**

## 20_6 我的断法库

### 断法库模板（按问题类型索引）

```latex
【问题类型】要不要换工作
【判断结构】命宫是否开创型 → 大限是否开门 → 流年禄忌落点
【关键信号】
  · 禄在官 + 忌在财 → 可以换，但要准备现金流
  · 忌在官 + 叠迁移 → 不宜主动变动，宜守
【话术】________
【验证】☐应 ☐未应 ☐部分应

```

**断法库的组织方式**：按"命主会问的问题"索引（换工作、要不要结婚、今年财运、合作能不能成），而不是按"星曜"或"宫位"索引。因为实际咨询时，入口永远是问题。

### 常用问题类型清单

```latex
事业类：要不要换工作 / 该不该创业 / 去不去外地 / 今年能不能升
财务类：今年财运如何 / 该不该投资 / 钱为什么留不住
感情类：这段关系该不该继续 / 什么时候有正缘 / 为什么总吵架
健康类：需要注意哪个系统 / 今年要不要体检
六亲类：与合伙人合不合 / 与上司关系
时机类：哪一年是窗口 / 哪一年要保守

```

### 案例小故事：讲了四十分钟，对方只记住一句

一位新手刚配齐工具箱，第一次给人断盘，兴奋地把断法库、格局清单、宫位权重挨个套了一遍，讲了四十分钟，从性格讲到六亲再讲到流年。

结束后他问对方有什么收获，对方想了半天说："你今年要注意"——那是他随口说的一句套话，恰恰是全场最没有信息量的一句。

第二次他改了做法：先问对方到底想解决哪一件事，然后只围绕这件事讲三条，十分钟讲完。对方当场记下了三条，一周后还发消息来反馈。

**落点**：工具箱是备查的，不是逐条念的。信息量不等于信息密度——对方能带走的，才是有效的。
