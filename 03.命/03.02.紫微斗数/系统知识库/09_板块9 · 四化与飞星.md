# 板块9 · 四化与飞星

> 四化是把静态盘变成动态故事的发动机。没有四化，命盘只是一张星曜分布图；有了四化，它才变成"什么时候发生什么"的剧本。

---

## 9_1 四化的四个动词

四化不是"吉凶标签"，而是四个**动作**。理解成动词，判断立刻清晰。

| 四化 | 动词 | 象意 | 时间属性 | 心理体验 |
| --- | --- | --- | --- | --- |
| **化禄** | 给、起、顺 | 缘起、资源、顺畅、吸引力、享受 | 开始、来 | 舒服、想要更多 |
| **化权** | 掌、争、固 | 掌控、扩张、主导、争夺、强化 | 发展、长 | 有力量、想说了算 |
| **化科** | 名、解、缓 | 名声、化解、贵人、条理、文凭 | 过程、化 | 体面、缓和 |
| **化忌** | 收、执、结 | 执念、结果、结束、匮乏、聚焦 | 结束、去 | 纠结、放不下 |

**核心理解**：化禄是"因"，化忌是"果"；化权是"过程"，化科是"调节"。禄忌是一对（一起一结），权科是一对（一进一调）。断盘时看**禄忌落点**，就知道这件事"从哪来、到哪去"。

```latex
速记口诀：
禄 = 开始（东西来了）      忌 = 结束（事情收了）
权 = 过程（越做越大）      科 = 调节（有人/有名来缓和）

```

## 9_2 四化在各宫的落点象意

同一颗星化禄，落在不同宫应不同事。这是四化落地的关键。

| 落宫 | 化禄 | 化权 | 化科 | 化忌 |
| --- | --- | --- | --- | --- |
| **命宫** | 人缘好、乐观、易得资源 | 主观强、主导欲、能扛事 | 温和有礼、名声好 | 固执、自我纠结、想得多 |
| **兄弟宫** | 手足有助、短期财顺 | 兄弟强势、主导平辈关系 | 平辈关系和谐 | 兄弟缘薄、合作易散 |
| **夫妻宫** | 感情顺、配偶条件好 | 配偶强势、感情中争夺主导 | 配偶体面、感情温和 | 感情执念、波折、放不下 |
| **子女宫** | 子女缘佳、投资有回报 | 对子女/投资控制欲强 | 子女有教养、创意受认可 | 子女缘薄、投资失利 |
| **财帛宫** | 财源广、赚钱轻松 | 主动求财、扩张财务 | 理财有条理、财务清白 | 财务纠结、破耗、守财难 |
| **疾厄宫** | 体质尚可、病有良医 | 身体硬撑、爆发力强 | 病得良医、化解 | 疾病焦点、体质弱点 |
| **迁移宫** | 外出得利、人缘佳 | 在外强势、主动开拓 | 外在形象佳、遇贵人 | 外出多阻、对外不顺 |
| **交友宫** | 朋友多助、客户旺 | 掌控人际圈、下属强势 | 人脉清雅、得助力 | 人际消耗、下属背叛 |
| **官禄宫** | 事业顺、工作愉快 | 掌权、升迁、事业扩张 | 学业顺、名声好 | 工作不顺、事业执念 |
| **田宅宫** | 家宅丰、置产顺 | 主导家业、房产扩张 | 家庭和谐、家宅清雅 | 家宅不宁、置产波折 |
| **福德宫** | 精神满足、享受生活 | 内心要强、争强好胜 | 心境平和、有修养 | 精神内耗、想不开 |
| **父母宫** | 长辈有助、文书顺 | 与长辈争主导、文书强势 | 学历顺、上司认可 | 与长辈缘薄、文书出问题 |

**落点比星性更重要**：很多人纠结"哪颗星化禄好"，其实先要看落在哪一宫——化禄入财帛才是财，入夫妻是感情顺，入疾厄可能只是"病了有人照顾"。

## 9_3 三层四化：天盘、地盘、人盘

四化有三个层级，力量从持久到猛烈、时间从长到短：

| 层级 | 天干来源 | 影响时长 | 力量 | 性质 | 断法定位 |
| --- | --- | --- | --- | --- | --- |
| **生年四化（天盘）** | 出生年天干 | 终生 | 最持久 | 定底色与因果 | 回答"这个人天生带什么" |
| **大限四化（地盘）** | 大限宫位天干 | 十年 | 中等偏强 | 定环境与趋势 | 回答"这十年开哪扇门" |
| **流年四化（人盘）** | 流年天干 | 一年 | 最强烈但最短 | 定扳机与应期 | 回答"哪一年被引爆" |

**核心原则：三环相扣**

```latex
先看原局给没给这个能力（天盘上限）
  → 再看大限这十年开没开这扇门（地盘封顶）
    → 最后看流年把它引爆在哪一年（人盘扳机）

```

**跳过前两层直接吹流年，就是"说得天花乱坠却什么都没发生"的根源。**

**示例**：命盘财帛宫本无财星（天盘不给），大限也没走到财宫（地盘没开门），那么流年财帛化禄最多主一笔小钱，不可能暴富。反过来，天盘财帛有禄、大限又走到财宫、流年再化禄入财帛——三层同现，才是真正的大财年。

## 9_4 十天干四化表（含流派提示）

**记忆口诀（按甲至癸）**

```latex
甲廉破武阳，乙机梁紫阴，丙同机昌廉，丁阴同机巨，
戊贪阴右机，己武贪梁曲，庚阳武阴同，辛巨阳曲昌，
壬梁紫辅武，癸破巨阴贪。

```

| 天干 | 化禄 | 化权 | 化科 | 化忌 |
| --- | --- | --- | --- | --- |
| 甲 | 廉贞 | 破军 | 武曲 | 太阳 |
| 乙 | 天机 | 天梁 | 紫微 | 太阴 |
| 丙 | 天同 | 天机 | 文昌 | 廉贞 |
| 丁 | 太阴 | 天同 | 天机 | 巨门 |
| 戊 | 贪狼 | 太阴 | 右弼 | 天机 |
| 己 | 武曲 | 贪狼 | 天梁 | 文曲 |
| 庚 | 太阳 | 武曲 | 太阴 | 天同 |
| 辛 | 巨门 | 太阳 | 文曲 | 文昌 |
| 壬 | 天梁 | 紫微 | 左辅（**原典作天府**） | 武曲 |
| 癸 | 破军 | 巨门 | 太阴 | 贪狼 |

**流派提示**：庚、壬两干的四化在流派间存在差异（例如有流派作"庚阳武府相"）。解盘前先固定一个版本，全程不切换——**中途换流派，前后结论必然打架**。这也是复盘时"盘没排错但结论错"的常见原因之一。

> **原典对照**：《紫微斗数全书》卷二「安禄权科忌四星变化诀」原文为
> 「甲廉破武阳为伴，乙机梁紫月交侵，丙同机昌廉贞位，丁月同机巨门寻，戊贪月弼机为主，
> 己武贪梁曲最平，庚日武阴同为首，辛巨阳曲昌至临，**壬梁紫府武宿是**，癸破巨阴贪狼停。」
> 其中「**府**」指**天府**——即**原典壬干化科为天府，非左辅**。
> 本库采用的"左辅"为后世某派改定。两者并存时须写明所从，不可混用。

**自测标准**：见天干即出四化星。练到"庚"能立刻反应"太阳禄、武曲权、太阴科、天同忌"，才算过关。

## 9_5 飞星基础：宫干飞化

飞星是四化的进阶用法：以某宫的天干起四化，飞入其他宫，看"谁影响谁"。

| 术语 | 含义 | 判断方向 |
| --- | --- | --- |
| **宫干四化** | 以某宫的天干飞出的四化 | 该宫"给出"什么 |
| **化禄入某宫** | 该宫把好处给到某宫 | 因这个宫而得利 |
| **化忌入某宫** | 该宫把执念/压力给到某宫 | 因这个宫而损耗 |
| **禄入忌出 / 忌冲** | 化忌在对宫冲本宫 | 冲击最强，主剧烈变化 |
| **自化** | 某宫天干化出的星又落回本宫 | 自我消耗或自我生发，主"该宫自己消化" |

### 四化飞星的三条实操规则

1. **化忌冲宫，比化忌入宫更剧烈**。化忌在对宫冲本宫，主该宫"被外力撞击"，事件来得急。
2. **禄忌同宫或对拱要一起看**。同一宫既见化禄又见化忌，主"得失同源"——得到的同时也在失去，是人生纠结处。
3. **看四化先看落在哪一宫，再问是谁飞来的**。"谁飞来的"决定了事情的原因方。例：夫妻宫化忌入命宫，主因感情而自我消耗；命宫化忌入夫妻宫，主自己把执念投射到感情上。**方向不同，责任方不同。**

### 飞星的方向感训练

```latex
A宫 化禄 入 B宫  → 因为 A 的事，让 B 得到好处
A宫 化忌 入 B宫  → 因为 A 的事，让 B 付出代价

例：官禄宫化禄入财帛 → 因为工作而赚钱（正财）
例：夫妻宫化忌入官禄 → 因为感情而拖累事业
例：命宫化忌入福德   → 自己跟自己过不去（内耗）

```

**练习法**：拿自己那张盘，把命宫、财帛宫、官禄宫三个宫的干支各飞一次四化，写出"谁给谁"的链条。写出六条以后，飞星就不再是玄学。

## 9_6 化忌的再认识：执念、缺口与专长

化忌被误解最深。它不是"灾星"，它是**能量聚焦处**。

### 化忌的三张面孔

1. **执念面**：放不下、想不开、反复纠结的领域。例：命宫化忌者，一生最大的课题是与自己相处。
2. **缺口面**：先天不足、需要补课的地方。例：财帛化忌者，天生对金钱安全感不足，反而会更努力赚钱。
3. **专精面**：因为放不下，所以钻得深。许多专家、匠人、研究者的盘上，化忌正落在他们成就的宫位上（官禄化忌者常是行业里的"钻家"）。

### 化忌严重程度四问

```latex
第 1 问：化忌的星是哪颗？（凶星化忌更凶，吉星化忌主"好东西留不住"）
第 2 问：化忌落在哪一宫？（落在用神宫位影响大，落在闲宫影响小）
第 3 问：化忌有没有解？（同宫或三方有化科可解，谓之"科解忌"）
第 4 问：化忌冲哪里？（冲命、冲财、冲官最需注意）

```

**科解忌**是四化体系里最实用的一条化解规律：化科能缓和化忌，主"有人调解、有名分、有条理地化解"。解盘时遇到化忌，**第一件事就是在盘上找化科落点**。

### 化忌的现代改写（避免惊悚表述）

| 古式说法 | 现代改写 |
| --- | --- |
| 化忌入夫妻，克夫/克妻 | 感情中的执念深，课题是"学会放手与自我完整" |
| 化忌入财帛，破财 | 对金钱安全感不足，宜建立强制储蓄机制 |
| 化忌入疾厄，重病 | 该部位是体质弱点，宜列入常规体检项目 |
| 化忌入官禄，事业凶 | 事业心重、易钻牛角尖，宜设"止损线" |

## 9_7 四化实战流程（六步）

```latex
第 1 步：标生年四化（天盘）
  用出生年天干查表，标出四颗化星落宫
  → 定"先天配置"：你天生在哪方面顺、在哪方面执

第 2 步：标大限四化（地盘）
  用当前大限所在宫的天干查表
  → 看这十年新增的禄忌落在哪，定"十年主战场"

第 3 步：标流年四化（人盘）
  用流年天干查表，看飞入本命何宫
  → 定"今年引爆什么"

第 4 步：找交集（三重锁定）
  某宫同时被生年、大限、流年四化照射 → 必应事
  → 交集越多，事件越大

第 5 步：定性质
  禄多于忌 → 该年是"得"年
  忌多于禄 → 该年是"舍"年
  禄忌同宫 → 得失同源，谨慎决策

第 6 步：找化解
  化忌落点附近有无化科？有则主可解
  无解之忌 → 提示命主在该领域降低预期、早做预案

```

## 9_8 故事：一场"来了又走"的合作

**背景**。有人来问一笔合作能不能成。盘上是这样的：

```latex
天盘（生年）：官禄宫化禄 → 他天生在事业上有资源、有人缘
地盘（大限）：当前大限官禄宫化权 → 这十年确实在扩张
人盘（流年）：流年化忌入交友宫，同时流年化禄也入官禄宫

```

**初看**：化禄入官禄，像是事业有好事。很多人到这里就下结论了："今年事业有贵人，合作能成。"

**完整看下来**

1. 禄在官禄（事业有机会进来）——对。
2. 忌在交友（合作方/下属/客户出问题）——这是关键。
3. 禄忌同时出现，属于"得失同源"：**事情会来，但会在合作环节出问题**。

**后来的实际结果**：合作谈成了，对方却中途变卦，项目推倒重来，钱花了但成果归零。

**复盘要点**

```latex
· 只看禄不看忌 → 会断成"好事"，漏掉风险
· 只看忌不看禄 → 会断成"不成"，漏掉机会
· 禄忌同看 → 才能说出"会成，但会在合作环节出问题"

```

**给命主的建议也变得具体**：合同加违约条款、合作方做背景调查、分阶段付款而不是一次性投入。

**方法论小结**

```latex
四化的实操价值，不在于告诉你"凶吉"，
而在于告诉你事情的结构——
机会从哪来（禄）、代价落在哪（忌）、
谁给谁（飞星方向）、什么时候收（忌主结果）。
说出结构，才能说出可执行的动作。

```

## 9_9 笔记法：四化追踪表与禄忌对赌

### 四化追踪表（一张盘一张）

```latex
【天盘·生年四化】年干__
  禄__入__宫 → 天生顺的领域：________
  权__入__宫 → 天生要强的领域：______
  科__入__宫 → 天生有人帮的领域：____
  忌__入__宫 → 一生的课题：__________

【地盘·大限四化】第__大限 / 限宫干__
  禄入__ / 忌入__ → 这十年：__________

【人盘·流年四化】流年干__
  禄入__ / 忌入__ → 今年引爆：________

【三重交集】被两层以上四化照射的宫位：____
【化解检查】化忌落点附近有无化科：☐有 ☐无
【预判】________   【实际】________  ☐应 ☐未应 ☐部分应

```

### 验证动作：禄忌对赌练习

```latex
每年年初，写下自己盘上当年"禄入哪一宫、忌入哪一宫"，
并预判两件具体的事（一件得、一件失）。
年底回填对照，记录准确率。
连续三年，你会得到属于自己的"四化体感数据库"——
这比背任何口诀都值钱。

```

**记录要点**：预判必须写成**可验证的事件**（例如"今年会因为合作方产生一笔损失"），不能写成"今年要注意人际"——后者永远"对"，但毫无价值。
