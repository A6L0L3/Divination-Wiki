## 13_1 五步优先级：看盘的正确顺序

| 优先级 | 看什么 | 权重 | 判断内容 |
| --- | --- | --- | --- |
| **第一** | 命宫落在何地、与何星同宫 | ★★★★★ | 主星是什么？庙旺还是落陷？有无煞星同宫？ |
| **第二** | 身宫及同宫星曜 | ★★★★ | 后天着力点在哪？与命宫配合如何？ |
| **第三** | 命身宫的三方四正 | ★★★★ | 有无吉星拱照？有无羊陀火铃四煞冲破？ |
| **第四** | 夹拱情况（前后宫夹命） | ★★★ | 是吉夹（如财印夹命）还是凶夹（羊陀夹命）？ |
| **第五** | 财帛、官禄、迁移、福德四宫 | ★★★ | 四大功能宫的吉凶，决定具体领域表现 |

**为什么是这五步**：前三步定"这个人是谁"，第四步定"外部环境推他还是压他"，第五步定"具体在哪个领域兑现"。跳步的后果是——你能说出很多正确的细节，但拼不出一句有用的结论。

## 13_2 六宫检验法与打分制

**六宫检验顺序**：命宫 → 身宫 → 财帛宫 → 官禄宫 → 迁移宫 → 福德宫。

| 项目 | 满分条件 | 分值 |
| --- | --- | --- |
| 命宫 | 主星庙旺 + 无煞冲破 | 25 |
| 身宫 | 落在生旺之宫 + 有吉星 | 15 |
| 财帛宫 | 财星庙旺 + 化禄 | 15 |
| 官禄宫 | 官星庙旺 + 化权/化科 | 15 |
| 迁移宫 | 吉星拱照 | 15 |
| 福德宫 | 有天同、天梁等福星 | 15 |
| **合计** |  | **100** |

| 得分区间 | 判定 | 建议 |
| --- | --- | --- |
| 80–100 | 上等命格 | 可主动争取大机会，承担风险能力强 |
| 60–79 | 中等命格 | 稳中求进，选对赛道比努力更重要 |
| 40–59 | 中下命格 | 以专精立身，避免广撒网 |
| 40 以下 | 下等命格 | 守成为主，重点是减少错误而非追求大胜 |

**打分只是辅助**：分数提供横向比较的刻度，真正断盘仍要回到宫位内容本身。切勿用分数替代对具体星曜组合的分析。

```latex
使用提醒：
分数相同，内容可以完全不同。
同样是 65 分，一个人是"事业强、感情弱"，
另一个人是"感情稳、事业平"——给的建议必须不同。
分数只用来排序，不用来下结论。

```

## 13_3 秀而不实：命好 ≠ 有用

古赋最精辟的洞见：**"命宫纵有吉星守垣，而三方有吉亦有煞曜拱冲，则谓秀而不实。"**

**"秀"与"实"的区分**

+ **秀** = 命宫好看（吉星多、主星庙旺），是"表面分数"。
+ **实** = 三方四正也吉（财帛、官禄、迁移皆可用），是"实际产出"。

秀而不实的典型画像：学历高、资质好、人聪明，但工作环境中全是小人与阻碍，最终难有成就。**问题不在能力，在环境。**

**三方被煞的具体后果**

| 煞星落入 | 后果 | 现代解读 |
| --- | --- | --- |
| 入财帛 | 财损 | 赚钱困难、意外破耗、现金流不稳 |
| 入官禄 | 官吝 | 事业受阻、升迁无望、怀才不遇 |
| 入迁移 | 出门多咎 | 外出发展不利、异地多波折、公众形象受损 |

**秀而不实自检表**

```latex
☐ 命宫吉星多吗？          → 是（秀）
☐ 财帛宫有煞星吗？        → 是（财不实）
☐ 官禄宫有煞星吗？        → 是（官不实）
☐ 迁移宫有煞星吗？        → 是（路不实）

```

三条全中 → 典型的"秀而不实"，此时给命主的建议不应是"提升自己"，而是**换环境、换圈子、换赛道**。

**这是断盘中最容易给反的一条建议**：对"秀而不实"的人说"你要更努力"，等于让一个在漏水的船上拼命划桨的人再用力一点。

## 13_4 上格、中格、下格的判定标准

### 上等命格（三个条件同时满足）

1. 命身二宫有南北斗星曜**庙旺**守值
2. 三方四正得众吉**庙旺**拱照
3. 无四煞（羊陀火铃）或空劫刑囚耗忌之交会冲合或夹持

满足这三条，**不论命身落在哪个宫位，皆作美论**。若再合局入格，更得众吉拱与吉夹，则是"美上加美，秀实之最"。

### 中格（美玉瑕玷）

命身及财迁官福六宫皆强，但大限走在闲陷刑囚耗忌或四煞之中 → 原局好而运不配合，得分大减，断为中格。

### 下格

命宫落陷 + 三方有煞 + 大限不配合。此时断命的重点不是"你能成就什么"，而是**如何减少损失、守住基本盘**。

**关键提醒**：**原局定上限，大限定下限。** 原局再好，大限一直走凶，人生也会大打折扣。

| 层级 | 判定 | 断命的语气 |
| --- | --- | --- |
| 上格 | 三条件 + 大限配合 | 谈"能到多高、什么时候发力" |
| 中格 | 原局好、大限不配合 | 谈"等待窗口、积累筹码" |
| 下格 | 命陷 + 三方煞 + 限不配合 | 谈"减少错误、守住基本盘" |

## 13_5 断盘 SOP：九步完整流程

```latex
第 1 步 · 核盘
  确认历法、时辰、真太阳时、流派版本 → 盘错则全错

第 2 步 · 定基调
  命宫主星 + 亮度 + 身宫位置 → 一句话概括这个人的能量结构

第 3 步 · 看三方四正
  按 60/40/20/10 权重扫命宫的本、对、合、邻 → 判"自强"还是"自伐"

第 4 步 · 数吉凶
  吉星总分 vs 凶星总分（庙旺计分、落陷加倍）→ 30 秒初判底盘等级

第 5 步 · 标四化
  生年四化（底色）→ 大限四化（十年门）→ 流年四化（今年扳机）
  → 找三重交集，锁定"必应宫位"

第 6 步 · 验格局
  对照格局表核对构成 → 验主星得地 → 查有无煞破 → 判断是否真入格

第 7 步 · 分域诊断
  财 / 官 / 婚 / 疾 / 六亲 逐项走一遍（见板块 14、15）

第 8 步 · 定时机
  当前大限主题 → 今年叠宫 → 高危领域（见板块 16）

第 9 步 · 出建议
  给"可执行的下一步"，而不是给"宿命结论"

```

**每一步的产出物**（建议写在纸上，不要只在脑中过）

```latex
第 1 步 → 一个确认：盘对不对
第 2 步 → 一句话总评
第 3 步 → 自强 / 自伐 的判断
第 4 步 → 底盘等级（上/中/下）
第 5 步 → 三重交集宫位清单
第 6 步 → 是否入格 + 验格结果
第 7 步 → 五个领域的强弱排序
第 8 步 → 今年主战场 + 高危领域
第 9 步 → 三条可执行建议

```

## 13_6 输出话术模板

```latex
【一句话总评】
（例）这是一个"开局平稳、中年发力"的盘：底盘稳，但爆发点在中年后。

【三个优势】
1. 命宫 ×× 星庙旺 → 对应的能力优势
2. 三方 ×× 吉星拱照 → 外部环境助力
3. ×× 宫化禄 → 这个领域天然顺畅

【三个短板】
1. ×× 宫落陷 → 需要后天补足的能力
2. ×× 宫被 ×× 夹制 → 易反复出问题的领域
3. 化忌在 ×× 宫 → 一生的执念与课题

【当前大限（第 X 大限）】
主题：（走哪个宫、四化如何、十年主战场是什么）
建议：（进取 / 保守 / 转型 / 积累）

【今年（流年）】
叠宫：（流年命宫叠本命何宫 → 今年重心）
扳机：（流年四化飞入何宫 → 引爆什么事）
提示：（高危领域 + 趋避建议）

【给命主的一句话】
（把命理语言翻译成一个具体行动建议）

```

**话术的三个要求**

1. **优势要说"能力"，不说"命好"**：命宫庙旺要翻译成"你在这方面的能力是某一种具体能力"。
2. **短板要说"功课"，不说"灾"**：化忌要翻译成"这是你要修的功课，具体表现是某一类反复出现的困扰"。
3. **建议要说"动作"，不说"心态"**：避免"保持乐观"，要给"预留 6 个月现金缓冲"这类可执行的动作。

## 13_7 断盘的三条纪律

1. **先说结构，后说事件**。没有结构支撑的事件断语是空中楼阁。
2. **每一条断语都要能指出星曜依据**。说不出依据的判断，就是臆测。
3. **结论必须落到行动**。断命的价值在于"知道之后怎么做"，否则只是心理按摩。

```latex
自检三问（说完一段话后立刻自问）：
· 我说的这句话，依据是哪颗星、落在哪一宫？
· 如果命主追问"为什么"，我能答到第几层？
· 我给的建议，命主明天能做吗？

```

## 13_8 故事：一次完整的九步断盘

**背景**。某人来问"该不该换工作"。

```latex
第 1 步 核盘：时辰确认过，真太阳时已校正 → 盘可用
第 2 步 定基调：命宫杀破狼结构，主星庙旺，身宫在官禄宫
        → 一句话："开创型底盘，人生重心天然在事业上"
第 3 步 三方四正：命宫本宫强，对宫迁移宫有煞但可避，
        三合官禄宫吉 → 判"自强"
第 4 步 数吉凶：吉星略多于凶星，且凶星多在得令位置 → 中上底盘
第 5 步 标四化：生年禄在官禄；当前大限化权入官禄；
        今年流年化禄入官禄、化忌入财帛
第 6 步 验格局：未构成经典富贵格，但"杀破狼 + 官禄化权"
        属事业开创结构，不入格但有结构性优势
第 7 步 分域：事业强 / 财帛中（化忌）/ 感情平 / 健康需留意迁移宫
第 8 步 定时机：当前大限走官禄宫，今年叠迁移宫 →
        主战场在"事业 + 外部变动"
第 9 步 出建议：
        · 可以换，但要准备好现金流（化忌入财帛 = 短期收入下降）
        · 优先选择"能带走原有人脉/技能"的方向
        · 避免同年做重大置业决策

```

**这个案例的关键**：结论"可以换"来自第 2、3、6 步（底盘适合动），而"但要准备好现金流"来自第 5、7 步（忌在财帛）。**两者缺一，建议就是残缺的**——只说"可以换"会让命主裸辞；只说"忌在财帛"会让命主错过机会。

**后来的反馈**。命主按建议预留了八个月现金，换到了一个能带走原客户资源的岗位。前四个月收入确实下降，第五个月起反超。他说："如果当时没留那笔钱，我第四个月就会慌，可能又跳一次。"

## 13_9 笔记法：一页纸结论与断盘计时

### 一页纸结论模板（每次断盘必须产出）

```latex
【盘主】____  【日期】____  【耗时】__分钟

一句话总评：____________________________

三强：1. ____  2. ____  3. ____
三弱：1. ____  2. ____  3. ____

大限主题：____   今年主战场：____   今年扳机：____
高危领域：____   趋避动作：____

三条建议：
1. ____（可执行的动作）
2. ____
3. ____

【依据检查】上面每句话，是否都能指出星曜依据？☐是 ☐否
【回填】实际反馈：____  ☐应 ☐未应 ☐部分应

```

### 断盘计时训练

```latex
目标：从拿盘到出一页纸结论
  初学：60 分钟内完成九步
  进阶：30 分钟内完成，且依据可追溯
  熟练：15 分钟内抓住结构与主战场

```

**计时的意义**：不是求快，而是逼自己建立"优先级"。时间不够时，你会被迫先做权重最高的事——这正是断盘的核心能力。
