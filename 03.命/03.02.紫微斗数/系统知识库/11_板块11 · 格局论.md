# 板块11 · 格局论

> 从"一堆星曜"到"结构"。

背一百个格局名却不会用，问题在没搞清**入格的条件**。

---

## 11_1 什么是格局：入格的三个条件

格局不是"星曜组合的名字"，而是**一种稳定的结构性能量**。

**入格三验（三条全中才算真入格）**

1. **结构成立**：格局要求的星曜必须到位（同宫、对宫或三方四正会照，缺一不可）。
2. **主星得地**：格局中的关键主星必须**庙旺**——同一组合，主星庙旺是格，落陷是空架子。
3. **无煞冲破**：不被羊陀火铃空劫冲破，不被化忌冲破。一见冲破，格局即破或降格。

**还要加一条时间条件**：原局入格，还需要**大限配合**才能兑现。"命好身好限好，到老荣昌"——三层皆吉才是真荣昌。原局入格而大限走在闲陷刑囚耗忌之上，谓之**"美玉瑕玷"**，虽美不足，只能断中格。

```latex
一句话：
结构是骨架，庙旺是血肉，无破是皮肤，大限是衣服。
四样齐全，这个格局才穿得出去。

```

## 11_3 凶格与破格预警

凶格的作用是**提前预警**，不是宣判。发现凶格，第一反应是给出趋避建议，而不是吓人。

| 凶格 | 构成 | 表现 | 趋避建议 |
| --- | --- | --- | --- |
| **四面楚歌** | 本宫 + 对宫 + 两合宫皆凶 | 该宫几无可用之地 | 该领域降低预期，寻求外部支援 |
| **秀而不实** | 命宫有吉星，但三方被煞冲破 | 好看不中用，学历高但发展受阻 | 主动改善环境/圈子，比提升自己更急迫 |
| **马头带剑** | 擎羊在午宫守命 | 刚烈、刑伤、成败剧烈 | 宜武职、技术，忌投机；注意安全 |
| **极居卯酉** | 紫微在卯或酉 + 遇劫空 | 思想超脱，疏离世俗成就 | 宜学术、宗教、艺术，不必强求商场成就 |
| **刑忌夹印** | 天相被化忌与天刑前后夹制 | 信誉危机，契约出问题 | 文书契约务必谨慎，宜法务把关 |
| **泛水桃花** | 贪狼在子（或亥子） | 才华横溢而漂泊不定，感情缘多而难定 | 以才艺与事业疏导桃花能量 |
| **风流彩杖** | 贪狼 + 天刑 | 因桃花惹是非甚至官非 | 感情边界要清晰，忌暧昧关系 |
| **巨暗同垣** | 巨门 + 暗曜在身命疾厄 | 身体瘦弱多病 | 注意消化系统与情绪健康 |
| **伤刑其面** | 凶星交会于父母宫与迁移宫 | 面部破相、外伤 | 注意出行安全与意外防护 |
| **重羊逐禄存** | 禄存被多重羊陀夹制 | 求财辛苦、财来财去 | 宜固定储蓄机制，忌高风险投机 |
| **片火焚天马** | 火星与天马同宫 | 奔波劳碌、不得安定 | 接受"动"是常态，把动变成优势（出差型工作） |
| **耗居败地** | 大耗在落陷之宫 | 极端破耗、财务困难期 | 极度保守的财务策略 |
| **杀居绝地** | 七杀落陷 + 无救 | 体能与意志的极端消耗 | 健康第一，忌硬撑 |
| **断桥截路** | 大限小限逢空亡截路 | 此路不通，事事受阻 | 该运宜守不宜攻，换赛道要谨慎 |

**预警话术转换**：凶格不要说"你有这个凶格"，要说"这个结构下需要注意某个具体事项"。同样的信息，前者制造焦虑，后者产生行动。

## 11_4 格局的现代职业翻译

古诀讲的是"贵/富/贫/贱"，现代人需要翻译成职业语言。这张表让断语可以直接用于职业咨询。

| 古诀 | 现代翻译 | 适合领域 |
| --- | --- | --- |
| 子午巨门，石中隐玉 | 靠口才与专业能力逆袭，晚成型 | 法律、传媒、销售、咨询、教育 |
| 贪武墓中居，三十才发福 | 前十年积累经验，三十后爆发 | 技术专家、创业者、专业服务 |
| 日照雷门 | 需要"被看见"的职业 | 公众人物、演讲、教师、品牌、自媒体 |
| 明珠出海 | 幕后策划型、研究型 | 研究、智囊、策划、编辑、分析 |
| 将星得地 | 执行与决断变现 | 金融、军警、工程、外科、竞技 |
| 火贪/铃贪暴发 | 高风险高回报 | 投资、创业、销售激励型岗位 |
| 禄马交驰 | 动中求财 | 贸易、物流、跨境、外派、出差型业务 |
| 机月同梁 | 服务与顾问 | 咨询、人力、教育、医护、体制内 |
| 杀破狼 | 开创与变革 | 创业、变革管理、开拓型业务 |
| 府相朝垣 | 守成与管理 | 运营管理、财务、行政、资产管理 |
| 文桂文华 / 衣锦惹天香 | 文名与专业声誉 | 文化、教育、艺术、出版、内容创作 |

**翻译的三条原则**

1. 把"贵/富"翻译成**职业类型**，不是翻译成"当官/有钱"。
2. 把"发福年龄"翻译成**积累期与爆发期**，不是翻译成"等着就行"。
3. 把"凶"翻译成**风险点与趋避动作**，不是翻译成"你完了"。

## 11_5 故事：一个"入格"却没发达的盘

**背景**。有张盘被判为"三奇嘉会格"（化禄、化权、化科在三方四正会照），按古诀是"富贵双全之上格"。但命主四十多岁，事业平平，来问："是不是我错过什么了？"

**按入格三验逐条核对**

```latex
第 1 验 · 结构成立：禄权科确实在三方四正 → 通过
第 2 验 · 主星得地：化禄的星落陷，化科的星也落陷 → 不通过
第 3 验 · 无煞冲破：化权那颗星同宫有擎羊 → 不通过
时间条件 · 大限配合：当前大限走在闲陷之宫 → 不配合

```

三条里只中了第一条。**不是三奇嘉会格，是"三奇破格"**——结构在，但能量用不上。

**再看一层**。命主的化禄星落陷在财帛宫，财帛宫又被空劫会照。所以真实情况是"有赚钱的想法和机会，但钱来了就走"。

**改判后的建议（三条，都可执行）**

```latex
1. 不要再等"格局兑现"。这个盘的上限要靠"专精"而不是靠格局。
   具体动作：选定一个细分方向，五年内不换。

2. 财务上采取强制资产化（因为空劫在财帛）。
   具体动作：收入到账即按比例转入不易动用的账户。

3. 把化权的那颗星（同宫有擎羊）用在需要魄力的岗位上，
   而不是需要精细协作的岗位。
   具体动作：争取"对外谈判/开拓"类职责，避开"内部协调"类职责。

```

**后来的反馈**。命主放弃了"等大运"的想法，转而在自己做了十年的细分领域里深挖，第三年被推为技术负责人。他说："以前总觉得该有个大转折，现在知道我这个盘是靠熬出来的。"

**方法论小结**

```latex
格局名只是一个标签，三验才是内容。
看到组合就喊格局，等于看到食材就宣称是一道菜——
还得看火候（庙旺）、看有没有烧糊（冲破）、
看什么时候上桌（大限）。

```

## 11_6 笔记法：格局卡与验格表

### 格局卡（一卡一格）

```latex
【格局名】三奇嘉会
【构成】化禄、化权、化科在三方四正会照
【验格三关】结构☐  主星得地☐  无煞冲破☐
【现代翻译】才华与机运并至，宜专业/创业
【破格条件】一化落陷或被冲破
【我见过/验证过的案例】________

```

### 验格表（每次断格局填一次）

```latex
盘编号：____  疑似格局：____
验 1 结构成立：☐是 ☐否   缺什么：____
验 2 主星得地：☐是 ☐否   哪颗星落陷：____
验 3 无煞冲破：☐是 ☐否   被什么冲破：____
验 4 大限配合：☐是 ☐否   当前大限走哪个宫：____
结论：☐真入格  ☐降格（中格） ☐破格（不成立）

```

### 验证动作：格局反查练习

```latex
Step 1：找 3 个事业有成者的盘，反查他们是否入格
Step 2：找 3 个"看起来入格但事业平平"的盘，做验格三关
Step 3：对比两组，写出"真入格"与"假入格"的差异点

```

**你会发现的规律**：真入格的盘，三关全过；假入格的盘，通常卡在"主星得地"或"大限配合"。这也是断格局时最容易偷懒的两关。

## 11_7 格局自查清单

拿到任何一张盘，按这个顺序走：

```latex
☐ 命宫主星是否庙旺？（不庙旺，一切格局打折）
☐ 三方四正吉星是否占多数？（数量对比）
☐ 有无特殊格局？（对照 11_2 表格核对构成条件）
☐ 该格局的主星是否得地？（验格第二关）
☐ 有无煞星冲破？（验格第三关）
☐ 财帛宫与官禄宫孰强？（定富还是贵）
☐ 大限走势是否配合？（定兑现时间）
☐ 有无明显凶格需要预警？（对照 11_3）

```

**评分参考**：满足 6 项以上 → 入格（上等）；3–5 项 → 中格；0–2 项 → 下格，宜以稳为主、以专取胜。
