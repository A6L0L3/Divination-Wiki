# 《紫微斗数系统知识库 · 从起盘到断事》

> 一套把"看懂古文"变成"能断一张盘"的训练手册。

全库按能力进阶编排：先会造盘，再会标盘，再会解人，再会断事，最后会论格、会落地。

---

## 0_1 这套知识库解决什么问题

学斗数最常见的失败姿势，是"还没会排盘就开始背格局"。背了一百个格局名，拿到一张盘依然不知道第一眼看哪里——因为**缺的不是知识，是判断顺序**。

本库把完整能力拆成 23 个板块（板块 0 至板块 22），每块解决一个具体问题、配一套笔记模板与验证动作、附至少一个完整推演故事。所有故事均为教学用简化示例，用于演示推理链条。

| 你现在的困扰 | 去哪个板块 |
| --- | --- |
| 拿到生辰不知道怎么起盘 | 板块 1、2、3、4 |
| 星曜排出来了，不知道好坏 | 板块 10、9 |
| 知道好坏，不知道说的是什么事 | 板块 5、7、8 |
| 能说出性格，说不准哪年发生 | 板块 12、16 |
| 断语说得出来，但连不成结论 | 板块 13、20 |
| 古文断语看不懂、不敢用 | 板块 17、18 |
| 想看别人是怎么一步步推的 | 板块 21、22 |

## 0_4 四条使用纪律

1. **理解的优先级高于记忆**。星曜一百多颗，靠背很快遇到天花板。先吃透"五行 + 化气 + 庙陷"这条主线，其余星曜都是它的变体。
2. **先看亮度，再谈吉凶**。同一颗星，庙旺和落陷可能是两个人。
3. **每一条断语都要能指出星曜依据**。说不出依据的判断就是臆测，写在日志里也要打问号。
4. **结论必须落到行动**。断盘的价值是"知道之后怎么做"，不是给宿命结论。每条短板必须配一条可执行建议。

## 0_6 使用须知

```latex
· 命盘分析是概率倾向的描述，不是命运定论。
· 格局好不代表可以不努力，格局差不代表没有机会。
· 星曜组合揭示的是性格倾向与行为模式，个人选择才是关键。
· 不预测死亡、不作医学诊断、不替代重大决策、不制造焦虑、
  不使用侮辱性或等级性词汇。

```

遇到古人断语中的"夭折""下贱""克夫""邪淫"一类词，一律按板块 17、18 的降档表与板块 19 的降档公式改写后再使用。

**关于流派差异**：庚、壬两干四化、部分主星的庙旺宫位、破军的旺宫归属，在不同文献与流派间存在出入。本库在相应位置已标注差异，实战建议**固定一套、全程不切换**——中途换标准，前后结论必然打架。
