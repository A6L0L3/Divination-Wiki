# 板块6 · 宫位权重与打分法

> 断一个宫位的好坏，本宫、对宫、三合宫、邻宫，谁说了算？

这就是《十喻歌》要解决的"权重分配"问题——本库把它做成可计算的工具。

---

## 6_1 十喻歌原文与核心命题

```latex
吉凶最要细分明，本对合邻有重轻。
四面楚歌终必败，千祥云集自然亨。
自强才是好人家，邻舍惟添锦上花。
若到逢源真境地，春风只可感相差。
两邻相侮岂为灾，自伐才教大可哀。
易躲当头一棍棒，难防左右袭兵来。

```

**核心命题**：吉凶最要细分明，**本对合邻有重轻**。

---

## 6_2 本对合邻：四类影响力的权重

| 类型 | 含义 | 权重 | 喻称（吉/凶） | 判断要诀 |
| --- | --- | --- | --- | --- |
| **本**（本方） | 本宫自身星曜 | **60%** | 由内自强 / 从根自伐 | 本宫吉＝自我强大；本宫凶＝自断其根，最难救 |
| **对**（对方） | 对宫星曜 | **40%** | 迎面春风 / 当头恶棒 | 冲击力最直接，但"易躲当头一棒"——可回避 |
| **合**（合方） | 三合宫星曜 | **20%** | 左右逢源 / 左右受敌 | 决定"实不实用"，是助力来源 |
| **邻**（邻方） | 左右邻宫 | **10%** | 两邻相扶 / 两邻相侮 | 锦上添花或落井下石，权重最轻 |

### 完整十喻对照表

| 条件 | 喻称 | 含义 | 权重 |
| --- | --- | --- | --- |
| 本方吉 | 由内自强 | 本宫吉星 → 自我强大，根本稳固 | 60% |
| 本方凶 | 从根自伐 | 本宫凶星 → 自断其根，最难救 | 60% |
| 对方吉 | 迎面春风 | 对宫吉星 → 直接受益 | 40% |
| 对方凶 | 当头恶棒 | 对宫凶星 → 冲击强但可避 | 40% |
| 合方吉 | 左右逢源 | 三合宫吉 → 外部助力 | 20% |
| 合方凶 | 左右受敌 | 三合宫凶 → 孤立无援 | 20% |
| 邻方吉 | 两邻相扶 | 邻宫吉星 → 锦上添花 | 10% |
| 邻方凶 | 两邻相侮 | 邻宫凶星 → 干扰但不足为灾 | 10% |
| 方宫皆吉 | 千祥云集 | 本对合邻全吉 → 该宫能量最大化 | 100% |
| 方宫皆凶 | 四面楚歌 | 本对合邻全凶 → 该宫几无可用 | 100% |

## 6_3 三条实战结论

1. **本宫永远是第一位**。"自强才是好人家，邻舍惟添锦上花"——本宫吉，邻宫凶不足为患；本宫凶，再好的邻宫也救不了。
2. **对宫凶可避，本宫凶难逃**。对宫是"外部冲击"（易躲当头一棒），本宫是"内部衰败"（自伐才叫大可哀）。
3. **邻宫单独为凶不严重，双双为凶才棘手**。"两邻相侮岂为灾"，但"难防左右袭兵来"——两个邻宫同时有煞夹击，就形成夹制，压力陡增。

### 看似矛盾处的关键辨析

```latex
矛盾一：
"两邻相侮岂为灾"（邻宫凶不重）
  vs "难防左右袭兵来"（邻宫凶难防）
辨析：单个邻宫有凶，不足为灾；
      两个邻宫同时有凶形成夹制，就升级为难防的结构性压力。

矛盾二：
"易躲当头一棒"（对宫凶可避）
  vs "当头恶棒"（对宫凶冲击强）
辨析：对宫冲击猛烈但可回避（不在本宫，是外部压力）；
      本宫凶才是内部衰败，避无可避。

```

**一句话总结**：**本宫为根（60%），对宫如镜（40%），三合为援（20%），邻宫辅助（10%）。**

## 6_4 宫位权重打分法

把权重变成可计算的分数，用于横向比较十二宫的强弱。

```latex
宫位吉凶得分 = 本宫分×0.6 + 对宫分×0.4 + 三合宫得分×0.2 + 邻宫得分×0.1

基础分（星性 × 亮度）：
  吉星庙旺 = +10 分      吉星平陷 = +5 分
  煞星庙旺 = -5  分      煞星落陷 = -10 分
  空宫     = 借对宫星曜评分（庙陷按原宫）

四化修正（在基础分上加减）：
  化禄 / 化权 = +3 ～ +5 分（能量显著上升）
  化科       = +2 分
  化忌       = -3 ～ -5 分（表达被扭曲、能量聚焦成执念）
  同宫星多   = 取主星分 + 次星分的一半，不超过 ±20

```

**为什么要有四化修正**：不修正会出现明显误判。例如"天同庙旺 + 化禄"实际强于"天府庙旺"无四化，若都记 +10 就分不出高下。本库后续示例中出现的 +15、+12、+8 等分数，都是"基础分 + 四化修正"之后的结果。

### 完整打分示例：看财帛宫

```latex
Step 1 · 本宫（财帛宫，权重 60%）
  武曲庙旺 + 禄存 → 本宫得分 +20 → 加权 +12.0

Step 2 · 对宫（福德宫，权重 40%）
  天同落陷 + 火星 → 对宫得分 -8  → 加权 -3.2

Step 3 · 三合宫（命宫 + 迁移宫，权重各 20%）
  命宫紫微庙旺 +10 → +2.0
  迁移宫太阳旺  +8 → +1.6

Step 4 · 邻宫（官禄宫 + 子女宫，权重各 10%）
  官禄天相庙旺 +10 → +1.0
  子女宫天机平  +2 → +0.2

合计 ≈ +13.6 → 财帛宫属于"强"档
  但注意：对宫福德宫为负 → 主"赚得到但享受不到"

```

### 打分的三条纪律

1. 分数是**横向比较的刻度**，不是结论。分数高但内容说不清，等于没断。
2. 打分前必须完成"标亮度"（板块 10），否则分数全是错的。
3. 邻宫分数永远不超过 ±2。看到邻宫分数影响很大，说明你把权重用错了。

## 6_6 极端格局：千祥云集与四面楚歌

| 格局 | 条件 | 含义 | 应对 |
| --- | --- | --- | --- |
| **千祥云集** | 本宫、对宫、两合宫全吉 | 该宫能量最大化，是人生强项 | 把主要资源投在这个领域 |
| **四面楚歌** | 本宫、对宫、两合宫全凶 | 该宫几无可用之地 | 该领域降低预期，寻求外部支援 |

**"四面楚歌"不是宣判**：它说的是"这个宫位自身能提供的支持接近于零"，应对方式是**从其他宫借力**，而不是硬扛。例如事业宫四面楚歌，但迁移宫很强，那么出路是"换地方发展"而不是"在原地死磕"。

## 6_7 故事：四面楚歌的官禄宫，出路在对面

**背景**。有人来问事业，说自己在同一家公司待了六年，换了三任领导，每次都是"快出成果就被人摘走"，问是不是"事业宫太差，没救了"。

**先看官禄宫本身（本宫 60%）**

```latex
本宫 官禄宫：巨门落陷 + 擎羊同宫 → -10 × 0.6 = -6.0
对宫 夫妻宫：天同庙旺 + 天魁      → +12 × 0.4 = +4.8
三合 命宫  ：天机平               → +2  × 0.2 = +0.4
三合 财帛宫：武曲旺               → +8  × 0.2 = +1.6
邻宫 迁移宫：太阳庙旺             → +10 × 0.1 = +1.0
邻宫 田宅宫：天府入庙             → +10 × 0.1 = +1.0
────────────────────────────────────────
合计 ≈ +2.8（中偏弱，但远不是"没救"）

```

**单看本宫，结论会是"事业宫四面楚歌"**——巨门落陷主口舌，加擎羊更硬，确实符合他"总被摘果子"的体感。

**但加完权重，出现了两个关键信息**

```latex
1. 对宫夫妻宫极强（天同庙旺 + 天魁）
   → 夫官一线：他的事业阻力，与"关系处理"高度相关
   → 不是能力问题，是"成果归属的沟通"出了问题

2. 邻宫迁移宫有太阳庙旺（虽只有 10% 权重，但方向明确）
   → 迁移宫强 = 在外比在内好
   → 出路不在"换个领导"，而在"换个地方"

```

**改判后的建议**

```latex
· 不是"再忍一忍"（本宫确实弱，硬扛只会继续被消耗）
· 也不是"提升业务能力"（他的财帛宫武曲旺，能力不是短板）
· 而是两条：
  1. 把工作成果的归属写清楚——周报、阶段汇报、书面确认（针对巨门陷 + 擎羊）
  2. 优先申请异地/跨部门岗位，而不是在原团队里争（针对迁移宫强）

```

**后来的反馈**。他申请调去了外地分公司，同样的业务，在新环境里反而顺了。他说："原来不是我能力不行，是我一直在需要'抢功'的环境里待着。"

**方法论小结**

```latex
"四面楚歌"说的是这个宫自身能提供的支持接近于零，
但不等于"这事没救了"——
对宫和邻宫的方向，往往就是出路所在。
本宫决定"这里行不行"，对宫决定"卡在哪"，邻宫决定"往哪走"。

```

### 一周专项训练

```latex
第 1 天：只练命宫的本对合邻打分（1 张盘）
第 2 天：只练财帛宫（3 张盘）
第 3 天：只练官禄宫（3 张盘）
第 4 天：只练夫妻宫（3 张盘）
第 5 天：同一张盘，十二宫全部打分，排出强弱顺序
第 6 天：拿打分结果与命主自述对照，看强弱排序是否吻合
第 7 天：复盘——哪些宫打分与实际情况不符？为什么？

```

**验证标准**：十二宫打分排序出来后，让命主自己排序"我人生中最顺和最不顺的三件事"。两者吻合度超过七成，说明权重法用对了。
