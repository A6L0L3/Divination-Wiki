# 板块10 · 庙旺利陷与星曜能量

> 断盘的读数基础：**先看亮度，再谈吉凶**。同一颗星，庙旺和落陷可能是两个人。

---

## 10_1 七级亮度与评分标准

星曜落不同宫位，能量差别极大。七级亮度及评分：

| 等级 | 含义 | 分数 | 特征 |
| --- | --- | --- | --- |
| **庙** | 星光最亮 | 91–100 | 吉星能力全开；凶星煞气收敛 |
| **旺** | 次优 | 81–90 | 正面能力充足，小波折可控 |
| **得地** | 得其所 | 71–80 | 稳定发挥，中规中矩 |
| **利益** | 有利 | 61–70 | 尚可用，但助力有限 |
| **平** | 平常 | 51–60 | 平庸，需外力加持 |
| **不得地/闲** | 失所 | 31–50 | 能力打折，须努力补足 |
| **陷** | 无光 | 0–30 | 吉星吉处藏凶；凶星凶性毕露 |

**实战简化**：不必死磕七级，用三档即可——**庙旺为「强」、平闲为「中」、陷为「弱」**。判断时以"强/中/弱"三档加权，效率与准确率都优于硬套七级。

```latex
三档对照：
强 = 庙、旺（得地可视情况归入强）
中 = 利益、平、不得地
弱 = 陷

```

## 10_2 得垣与受制：判断的核心技术

古赋：**"重在看星得垣受制，方可论人祸福穷通。"**

| 概念 | 含义 | 判断方法 |
| --- | --- | --- |
| **得垣（入庙）** | 星曜在庙旺宫位，能量充分释放 | 查庙旺表，看该星是否在自己的"主场" |
| **受制（落陷/被制）** | 星曜在落陷宫位，或被其他星曜克制夹制 | 落陷 + 被煞星夹制 = 力量大打折扣 |

**关键辨析**：斗数的"受制"**不是**五行生克的"宫位克星曜"（那是八字思维），而是——**星曜落陷后容易被煞曜乘虚而入**。落陷本身不一定凶，落陷且被煞星夹制才是真凶；庙旺的星即使遇到煞星，也有抵抗能力。

### 得垣受制判断流程（四步）

```latex
第 1 步：查亮度
  该星是庙旺、平闲还是陷？

第 2 步：查同宫
  同宫有没有煞星？有没有吉星？
  吉星同宫可扶起落陷之星（"凶不皆凶"）
  煞星同宫可拖垮庙旺之星（"吉无纯吉"）

第 3 步：查夹制
  前后两宫（邻宫）有没有凶星夹击？
  被羊陀夹、被火铃夹、被空劫夹 → 受制程度加深

第 4 步：定结论
  庙旺 + 无煞 → 满分发挥
  庙旺 + 有煞 → 打折，但底子在
  落陷 + 有煞夹 → 受制严重，该宫是人生短板
  落陷 + 有吉拱 → 可救，主"后天补足"

```

**一句话记忆**：**庙旺不怕煞，落陷最怕夹。** 一个庙旺的星，配一两颗煞星，往往只是"有个性"；一个落陷的星被煞星前后夹住，才是真正需要警惕的结构。

## 10_3 亮度修正因子

同一亮度等级，还会受以下因素微调。这些是最容易被忽略、却最见功力的细节。

| 修正因子 | 影响的星 | 修正规则 |
| --- | --- | --- |
| **日夜生人** | 太阳、太阴 | 太阳：白天生增力，夜晚生减力；太阴：夜晚生增力，白天生减力（日月互反） |
| **季节** | 依星曜五行 | 春木旺（天机、贪狼得助）、夏火旺（太阳、廉贞）、秋金旺（武曲、七杀）、冬水旺（太阴、破军） |
| **空宫借星** | 借入之星 | 庙陷以**原宫**为准，不随借入宫改变 |
| **四化加临** | 被化之星 | 化禄/化权显著提升该星能量（约 +1 档）；化忌削弱并扭曲其表达 |
| **对宫照射** | 全部 | 对宫星曜按 40% 权重影响本宫，庙旺的对宫吉星能"照亮"本宫 |

**修正因子的使用顺序**：先定基础亮度 → 再看日夜（日月两星）→ 再看四化 → 最后看对宫照射。**不要一次叠加太多修正**，否则会陷入无尽的微调。

**最常见的漏项**：日夜修正。一个夜晚生的太阳落陷盘，和一个白天生的太阳落陷盘，实际表现可以差一个档次——这是"同一张盘、断语对不上"的高频原因。

## 10_5 吉凶星数量速判法（30 秒初判）

这是《重补斗数彀率》的总纲落地：**"诸星吉多逢凶也吉，诸星恶多逢吉也凶。"**

```latex
Step 1｜标亮度
  庙旺的吉星  ✓ 计满分
  落陷的吉星  ✓ 计半分（吉处藏凶）
  落陷的凶星  ✓✓ 计双倍（凶性毕露）
  庙旺的凶星  计半分（煞气收敛）

Step 2｜算总分
  吉星得分总和  VS  凶星得分总和

Step 3｜定格局
  吉 > 凶  → 上等底盘：逢凶限也不会有大问题
  凶 > 吉  → 下等底盘：逢吉限也难有大作为
  势均力敌 → 看庙旺落陷与四化定胜负

```

**吉星清单**：紫微、天府、太阳、太阴、天同、天梁、左辅、右弼、天魁、天钺、文昌、文曲、禄存。
**凶星清单**：七杀、破军、贪狼、廉贞、巨门、擎羊、陀罗、火星、铃星、地空、地劫。

> **重要提醒**：这一步只是**初判**，不是结论。初判之后必须进入"得垣受制"和"宫位权重"两步，否则容易误伤——许多大成就者的盘上凶星数量并不少，关键在于"凶星得制、吉星得垣"。

**为什么初判会误伤**：一个创业者的盘上常见杀破狼 + 火铃，按数量算是"凶多"。但这些星恰恰是他突破的能量来源。**数量法只告诉你"底盘厚不厚"，不告诉你"这股能量用在哪"。**

## 10_6 星曜能量自检清单

拿到盘，逐宫过一遍：

```latex
☐ 十四正曜的亮度全部标出（强/中/弱三档）
☐ 六吉星、六煞星是否入庙或落陷
☐ 命宫主星亮度如何？有无同宫煞星？有无吉星扶持？
☐ 命宫是否被凶星夹制（前后两宫）？
☐ 太阳、太阴是否按日夜生人修正过？
☐ 空宫是否已借星？借入星的庙陷是否按原宫判定？
☐ 化禄、化权、化忌落在哪些宫？这些宫的能量是否被改写？
☐ 全盘吉星总分 vs 凶星总分，初判结论是什么？

```

## 10_7 三分钟标盘训练法

```latex
第 1 周：只标十四正曜庙陷，目标 3 分钟 / 张
第 2 周：加标六吉六煞，目标 5 分钟 / 张
第 3 周：加标日夜修正与四化，目标 8 分钟 / 张
第 4 周：加标夹制（前后两宫），目标 10 分钟 / 张

```

**训练工具**：打印十张空盘图，每天标一张，标完与标准表核对，记录错误星数。错误数从两位数降到个位数，就可以进入下一步。

### 错题库模板

```latex
日期 | 盘编号 | 标错的星 | 正确答案 | 错因（记错/看错/概念错）

```

**错因分类很重要**：如果是"记错"，回板块 7 补星曜卡；如果是"看错"（找错宫位），练盘面方位；如果是"概念错"（例如把落陷当庙旺），重读本板块 10_2。

## 10_8 故事：被"落陷"两个字吓到的人

**背景**。有人拿到盘，看到命宫主星落陷，当场脸色就变了，问："是不是这辈子完了？"

**按得垣受制四步走一遍**

```latex
第 1 步 · 查亮度：命宫主星确实落陷（弱档）
第 2 步 · 查同宫：同宫有天魁（吉星），且无煞星同宫 → 有扶
第 3 步 · 查夹制：前后两宫是文昌、禄存 → 吉夹，不是凶夹
第 4 步 · 定结论：落陷 + 有吉拱 + 吉夹 → 主"先天不足，后天可补"

```

再看对宫：迁移宫有紫微庙旺照命（按 40% 权重回填一大截）。

**真实情况**。这个人确实比同龄人起步慢，工作前几年一直觉得自己"不够好"，但三十岁以后靠持续积累慢慢追上来，四十岁前后反而在专业领域做出了名气。

**三条教训**

```latex
1. 落陷 ≠ 没救。
   落陷说的是"这股能量不好用"，不是"这股能量不存在"。

2. 要看夹制。
   被吉星夹和被煞星夹，是天壤之别。
   很多人只查本宫，忽略了前后两宫。

3. 对宫能补。
   命宫弱、迁移宫强的人，往往"在外比在家好"，宜外出发展——
   这就是断语变成建议的地方。

```

**给他的最终建议**：不是"认命"，而是"把主场放到外面去"——选择需要对外沟通、出差、跨部门协作的岗位，而不是坐在工位上死磕。
