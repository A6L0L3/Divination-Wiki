# 板块14 · 分域断法（上）：性格与财富

> 断完"这个人是谁"之后，下一步是回答具体领域的问题。

本板块处理两组：性格三层结构、财富三线合看。分域断法的共同原则是——**每个领域至少看三个宫**，只看本宫一定片面。

---

## 14_1 性格与自我：命宫 + 身宫 + 福德宫

三个宫位构成"自我三层结构"：

| 层次 | 宫位 | 回答的问题 | 断法要点 |
| --- | --- | --- | --- |
| **表层** | 命宫 | 我是什么样的人 | 主星 + 亮度 + 同宫星 |
| **中层** | 身宫 | 我把力气用在哪 | 身宫所在宫 + 该宫星曜 |
| **深层** | 福德宫 | 我真正想要什么 | 福德宫星曜，是潜意识与真实需求 |

### 命身福德三者不一致时的三种组合

| 组合 | 表现 | 建议 |
| --- | --- | --- |
| 命刚 + 福柔（如七杀命 + 天同陷福德） | 外在强硬、内心脆弱的"硬撑型" | 学会示弱与求助 |
| 命柔 + 福刚 | 表面随和、内心有主见的"内秀型" | 主动表达自己的判断 |
| 命身分离（身宫不在命宫） | 重心在外，表里不一 | 把力气用在身宫所在的领域 |

**实操提示**：很多人问"我到底适合做什么"，答案往往不在命宫，而在身宫。命宫说明你是什么样的人，身宫说明你把力气花在哪——**后者更接近职业方向**。

### 性格断法的三步

```latex
第 1 步 · 说形状：命宫主星决定能量的形状
  （例：七杀 = 单兵突破；天机 = 分析策划）

第 2 步 · 说亮度：庙陷决定这股能量好不好用
  （庙旺 = 用起来顺；落陷 = 费劲且易变形）

第 3 步 · 说落差：命宫与福德宫是否一致
  （一致 = 内外统一；不一致 = 存在内耗，建议要针对这个落差给）

```

**第三步最容易被跳过，却最出彩**。一个"外在强硬、内心脆弱"的人，真正需要的不是"再强一点"，而是"允许自己求助"。说中这一层，命主通常会当场愣一下——因为这是他自己知道但没说出口的部分。

## 14_2 财富：财帛 + 田宅 + 福德三线合看

单看财帛宫会误判，财富能力是三个宫的合力。

| 宫位 | 看什么 | 吉象 | 凶象 |
| --- | --- | --- | --- |
| **财帛宫** | 赚钱能力、现金流 | 武曲、天府、太阴庙旺，化禄 | 空劫、大耗、化忌 |
| **田宅宫** | 资产积累、守财能力 | 天府、太阴、禄存入庙 | 破军、空劫 |
| **福德宫** | 能否享受、财的"落袋率" | 天同、天梁、化禄 | 空劫 + 煞星、化忌 |

### 财富四型判断

| 类型 | 特征 | 财务建议 |
| --- | --- | --- |
| **能赚能守** | 财帛吉 + 田宅吉 | 宜长期资产配置，复利思维 |
| **能赚不守** | 财帛吉 + 田宅凶（如破军、空劫在田宅） | 强制储蓄、购置不动产、交给专业机构管钱 |
| **守而不赚** | 财帛平 + 田宅吉 | 宜稳健理财，不宜冒险投资 |
| **赚守皆弱** | 财帛凶 + 田宅凶 | 以技能变现为主，极度保守，优先保证现金流 |

**给建议时的关键区分**：同样是"钱的问题"，能赚不守型和守而不赚型的建议完全相反——前者要"强制资产化"，后者要"提升开源能力"。**不问清结构就给理财建议，是最容易出错的地方。**

### 三条特殊提示

+ 财帛宫化禄 ≠ 一定有钱，要看化禄的星是哪颗、有没有被忌冲。
+ 禄存被羊陀夹是常态（"重羊逐禄存"），主求财辛苦，但守得住。
+ 财帛宫与福德宫对照：**财吉福凶 = 有钱不快乐**；**财凶福吉 = 钱不多但心态好**。

## 14_3 财帛宫主星与收入类型

财帛宫的主星决定"钱是怎么来的"，这比"有没有钱"更可操作——**知道钱的来路，才能给它配上正确的动作**。

| 财帛宫主星 | 收入类型 | 财务特征 | 适配动作 |
| --- | --- | --- | --- |
| **武曲** | 正财、专业变现 | 靠硬技能挣钱，现金流稳，不喜投机 | 提升专业定价能力；忌杠杆投机 |
| **天府** | 守成、资源运营 | 善管钱，宜做存量增值 | 长期资产配置；忌频繁换手 |
| **太阴** | 积累、长线 | 靠时间与复利，细水长流 | 定投与长线持有；忌短线 |
| **贪狼** | 偏财、人脉 | 机会多但杂，易贪多 | 限定主战场；设止损线 |
| **天机** | 智财、多源 | 收入来源多，但不稳 | 把多条收入收敛成一主一辅 |
| **破军** | 变动之财 | 大进大出，宜"先破后成" | 主动规划一次大额置产，而非被动破财 |
| **太阳** | 名声之财 | 收入与曝光度绑定 | 做个人品牌；忌只做幕后还期待高收入 |
| **天同** | 安稳之财 | 够用即可，动力不足 | 用自动储蓄代替意志力 |
| **廉贞** | 局面之财 | 与权力/场面相关，易大起大落 | 设上限，忌为面子投入 |
| **巨门** | 口舌之财 | 靠专业口碑与谈判挣钱 | 把口碑资产化（内容、课程、出版） |
| **空宫** | 随环境起伏 | 财随外部波动，主观性弱 | 留足弹性，不做刚性财务承诺 |

**怎么用它**：先判收入类型，再给动作。对"天机型多源收入"的人说"要专注"，他会觉得你在否定他的生存方式；正确的说法是"保留一条主线，其余作为副线"。

### 静财与动财（辅星决定钱的"动还是静"）

```latex
禄存（静财）→ 宜守、宜存、宜置产
天马（动财）→ 宜动、宜异地、宜流通
禄存 + 天马（禄马交驰）→ 动中求财，宜贸易、外派、出差型业务
天马 + 空劫      → 动而无获，先定方向再动

```

## 14_4 财富断法的四步流程

```latex
第 1 步 · 看财帛宫（能不能赚）
  主星是什么？庙旺还是落陷？有无化禄/化忌？有无空劫大耗？

第 2 步 · 看田宅宫（能不能守）
  有无天府、太阴、禄存？有无破军、空劫？

第 3 步 · 看福德宫（能不能享受）
  有无天同、天梁、化禄？有无空劫 + 煞？

第 4 步 · 定类型并给建议
  归入财富四型之一，给出该型对应的具体动作

```

**第 4 步的关键**：不要只说"你财运不错/不好"，要说"你是能赚不守型，所以要资产化"——**类型 + 动作**，才是完整建议。

## 14_5 流年财运：钱什么时候会动

原局财帛宫回答"你天生怎么挣钱"，流年回答"哪一年钱会动"。两者不可混为一谈。

```latex
第 1 看 · 大限有没有开门
  大限命宫是否走到财帛宫 / 田宅宫？
  大限四化的禄或忌是否飞入财帛宫？
  → 没开门的年份，流年再热闹也只是一笔小钱

第 2 看 · 流年扳机落在哪
  化禄入财帛 → 有钱进来
  化忌入财帛 → 钱财收紧、结算、损耗
  禄忌同入   → 得失同源，进一笔的同时出一笔

第 3 看 · 与田宅宫联动
  流年同时引动田宅宫 → 这笔钱与房产、家庭大额支出有关

```

**最常见的误判**：把"流年化禄入财帛"直接说成"今年发财"。正确的说法要带三层条件——原局财帛宫给不给这个量级、大限开没开门、化禄的星是哪一颗。**三层都说了，才不会让命主产生错误期待。**

## 14_6 故事：一个"有钱不快乐"的盘

**背景**。一位四十岁出头的女性来问财运，开场第一句话是："我收入不错，但我总觉得不踏实，好像赚到了又好像没赚到。"她已经做过三次财务规划，每次做完都安心几天，然后焦虑照旧。

**按财富三线看**

```latex
财帛宫：武曲庙旺 + 化禄 → 赚钱能力很强（能赚）
田宅宫：天府入庙 + 禄存  → 守财与资产积累强（能守）
福德宫：天同落陷 + 地空  → 精神上难以满足（享受不到）

```

**第一步：先排除"钱不够"这个假设**

```latex
能赚（武曲庙旺化禄）+ 能守（天府 + 禄存）
→ 她的问题不在收入端，也不在资产端
→ 三次财务规划之所以无效，是因为它们都在解决一个不存在的问题

```

**第二步：定位真正的缺口在福德宫**

```latex
天同落陷 + 地空
→ 天同主"满足感"，落陷则"够了"这个感觉迟迟不来
→ 地空主"永远不够"，会把已有的东西在感受上抹掉
→ 组合象：账面在增长，体感在原地

```

**第三步：对照财福线**

```latex
财帛宫 ↔ 福德宫 是一条对冲线
财吉福凶 = 有钱不快乐（正是这一个盘）
→ 所以"多赚钱"的方向本身就是错的，钱越多，落差越明显

```

**如果只是看财帛宫**，会得出"财运很好"的结论。她听了只会觉得"你说的都对，但没用"——事实上她前面三次咨询听到的应该都是这类话。三线合看之后，建议才变得具体：

```latex
1. 财务层面可以停手了。
   具体动作：不再新增任何财务规划，现有的已经够用；
             把每季度看一次账户改成每半年看一次。

2. 福德宫的问题需要"非金钱的满足源"。
   具体动作：固定一项不产生收益、但能带来成就感的事
            （带新人、做公益、长期爱好），每周不少于两小时。

3. 设一条"够用线"。
   具体动作：明确写下"到了这个数字我就不再为钱焦虑"，
             写下来之后，达到即停止追加目标。
             用具体数字对抗地空带来的"永远不够"感。

```

**后来的反馈**。她真的写下了那个数字，写的时候才发现自己早就超过了。她原话是："写下来那一刻我才意识到，我焦虑的不是钱，是我从来没定义过'够了'。"三个月后她开始带两个新人，说"这事不挣钱，但我每周都盼着"。

**方法论小结**

```latex
分域断法的价值，在于把同一个问题拆到不同宫位上，
从而给出不同层面的建议。

单宫断法只能给一个答案："你财运很好"。
三线合看能给三个动作："停手 / 补非金钱满足源 / 设够用线"。

更关键的是——它先证明了"钱不够"是个假问题，
否则命主会在错误的方向上继续投入第四次、第五次。

```

## 14_7 笔记法：分域卡与逐域对赌

### 分域卡（一域一卡）

```latex
【领域】财富
【主看】财帛宫（赚）
【辅助】田宅宫（守） / 福德宫（享受）
【四型】能赚能守 / 能赚不守 / 守而不赚 / 赚守皆弱
【收入类型】财帛宫主星 = ____ → 适配动作：____
【我的断语库】
  · 财吉福凶 → 有钱不快乐，宜补非金钱满足源，而不是多赚钱
  · 财帛空劫 → 财来财去，宜资产化
  · 田宅破军 → 先破后成，宜主动规划置业
【验证记录】☐应 ☐未应 ☐部分应

```

### 逐域对赌（每年一次）

```latex
针对命主最关心的两个领域，各写一条具体预判：
  例如"今年事业上会有一次岗位/职责的扩张"
      "今年财务上会因为合作方产生一笔额外支出"
年底回填，记录应 / 未应 / 部分应，并写清漏看了哪一层。

```

**分域断法最容易犯的错**：把"领域"和"宫位"一一对应后就停住。记住每个领域都要看**至少三个宫**（本宫 + 对宫 + 关联宫），否则建议一定片面。

### 三类"钱的问题"的鉴别表（复盘用它定位错层）

| 命主的说法 | 真正该看的宫 | 常见误判 |
| --- | --- | --- |
| 赚不到钱 | 财帛宫 + 官禄宫 | 只看财帛，忽略了"事业没起来所以没钱" |
| 留不住钱 | 田宅宫 + 福德宫 | 只看财帛，误以为是收入问题 |
| 赚到了但不快乐 | 福德宫 | 继续在财务规划上加码，越加越焦虑 |
