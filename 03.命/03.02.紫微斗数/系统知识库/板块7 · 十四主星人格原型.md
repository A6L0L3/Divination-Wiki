# 板块7 · 十四主星人格原型

> 正曜是骨架。断人的准确度，八成取决于你对这十四颗星的理解深度。

---

## 7_0 阅读模板说明

每颗星按同一套模板讲：

```latex
【庙陷】落在哪些宫算强、哪些宫算弱（第一优先级）
【正面】庙旺时的行为模式
【反面】落陷时的问题表现
【关键词】这颗星的本质动作（用于快速联想）
【现代画像】翻译成今天的职业与人格语言
【职业指向】适合什么类型的工作
【自处建议】这颗星最需要主动补的功课
【重要规律】容易被忽略的修正条件（日夜、季节、搭配）

```

> **关于庙旺落陷的流派差异**：十四主星的庙旺落陷在不同文献、不同流派中记载略有出入（例如天机、破军的庙旺宫位均有两说）。实战建议：**固定一套表，全程不切换**；遇到冲突时，以"是否得地得令"的大原则为主。完整对照总表见板块 10。

## 7_1 北斗六星详解

### 紫微（阴土 · 化气为尊）

+ **庙陷**：庙在午；旺在寅、申、卯、巳、未、酉；平（得地）在辰、戌、丑；陷在子（部分流派亦论卯、亥）。
+ **庙旺**：领导力强，格局大，贵人运旺，决策果断，有统御力。
+ **落陷**：固执多疑，人缘差，决策反复，易成"孤君"。
+ **关键词**：尊、主、贵、中心。
+ **现代画像**：天生的管理者与整合者。喜欢掌控全局，不擅长执行细节。
+ **职业指向**：管理岗、企业主、资源整合型岗位。
+ **自处建议**：紫微必须配左辅右弼才能真正"有权"，否则只是"有架子"。紫微坐命者要主动补执行力与团队，否则一生困于"想得多、做得少"。
+ **重要规律**：紫微无脑富贵是误区。须庙旺 + 三方吉拱方显威力；逢空劫主"看破红尘"，思想超脱而疏离世俗成就。

### 天机（阴木 · 化气为善）

+ **庙陷**：庙在子、午；旺在卯、酉；得在寅、申；陷在丑、未。
+ **庙旺**：脑子极快，策划能力强，善变通，学习力惊人。
+ **落陷**：思虑内耗，多疑纠结，聪明反被聪明误，易"多学少成"。
+ **关键词**：变、智、谋、动。
+ **现代画像**：军师型、顾问型、分析型。擅长设计系统与流程，不擅长长期坚守一个位置。
+ **职业指向**：策划、研发、咨询、数据分析、产品。
+ **自处建议**：天机的敌人是"想太多"。建立"设定截止时间"的决策习惯，是天机坐命者最重要的修行。
+ **重要规律**：天机落陷 + 劫杀，古诀称"多学少成"——不是不聪明，是注意力被切得太碎。

### 太阳（阳火 · 化气为贵）

+ **庙陷**：庙在午（日丽中天）；旺在卯（日出扶桑）、辰、巳；得在寅；陷在子（日暗）、亥、酉。
+ **庙旺**：人缘好，名声旺，乐于付出，有公众影响力。
+ **落陷**：操劳费心，出力不讨好，情绪压抑，易"为他人做嫁衣"。
+ **关键词**：明、贵、声名、付出。
+ **现代画像**：天生的发光体——教师、演讲者、公众人物、品牌型人物。
+ **职业指向**：教育、传媒、公关、销售、服务业、公共事务。
+ **重要规律**：**太阳亮度关联日夜**——白天生人太阳增力，夜晚生人太阳减力。这是最容易被忽略的修正因子。太阳喜东升（寅至午）不喜西坠（酉、戌、亥、子）。

### 武曲（阴金 · 化气为财）

+ **庙陷**：庙在辰、戌；旺在丑、未；得在寅、申；陷在卯、酉（部分流派）。
+ **庙旺**：执行力超强，赚钱能力硬，守得住财，决断明快。
+ **落陷**：固执冲动，易破财，刚愎自用，人际关系硬。
+ **关键词**：财、刚、决、行。
+ **现代画像**：正财星。靠专业能力与硬打硬拼挣钱，不喜投机。
+ **职业指向**：金融、财务、工程技术、技术工种、军警、制造业。
+ **自处建议**：武曲的短板是"刚而少柔"。补一点人情世故与沟通柔度，是武曲坐命者放大财富的关键。

### 天同（阳水 · 化气为福）

> **原典五行**：《紫微斗数全书》作「**天同属水金**」。本库取"阳水"为现代通行口径，原典则金水并属。

+ **庙陷**：庙在子、亥；旺在卯、酉；平在辰、戌、丑、未；陷在寅、申（部分流派）。
+ **庙旺**：福气深厚，性格随和乐观，贵人运强，懂生活。
+ **落陷**：懒散不上进，贪图安逸，遇事逃避，抗压弱。
+ **关键词**：福、安、和、知足。
+ **现代画像**：天生的生活家。共情力强，适合服务与疗愈类工作，但需外力推动才肯吃苦。
+ **职业指向**：心理咨询、教育、医护、文创、客户服务。
+ **自处建议**：天同需要"外力推动"，宜主动把自己放进有进度压力的环境。
+ **重要规律**：天同十二宫皆"福"，但福气需要"先苦后甜"来兑现——十二宫中唯有天同在特定宫位（如戌、未）须经磨砺方得安逸。

### 廉贞（阴火 · 化气为囚）

+ **庙陷**：庙在寅、申；旺在丑、未；得在辰、戌；平/陷在卯、酉、巳、亥；陷在子。
+ **庙旺**：情商高，能文能武，有魄力，场面掌控力强。
+ **落陷**：脾气暴躁，爱钻牛角尖，口舌是非多，感情反复。
+ **关键词**：囚、欲、原则、感情。
+ **现代画像**：次桃花兼政星。是"欲望与原则的拉扯者"——既能八面玲珑，也可能因执念自困。
+ **职业指向**：公关、法务、纪检、演艺、销售管理。
+ **自处建议**：廉贞化禄时，阴火由暴烈转为温暖内敛，是最佳状态；廉贞化忌则一生难得安宁，感情与是非不断。廉贞的核心是"守住边界"。

## 7_2 南斗八星详解

### 天府（阳土 · 化气为令）

+ **庙陷**：庙在丑、未、辰、戌；旺在寅、申、巳、亥；得在卯、酉。
+ **庙旺**：稳重靠谱，有格局，善守财聚财，资源管理能力强。
+ **落陷**：小气抠门，优柔寡断，担不起事。
+ **关键词**：库、令、稳、守。
+ **现代画像**：守成型管理者。擅长把已有的东西管好，不擅长从零开创。
+ **职业指向**：财务、行政、运营管理、资产管理、体制内管理岗。
+ **自处建议**：天府宜找"能开创的人"搭档，自己负责守住与放大。
+ **要点**：天府最怕地空地劫——"府库有破"，反主虚有其表。

### 太阴（阴水 · 化气为富）

+ **庙陷**：庙在酉（月朗天门）、戌；旺在申、亥；得在子；平在辰、丑；陷在卯、巳、午。
+ **庙旺**：温柔细腻，理财能力强，心思缜密，审美佳。
+ **落陷**：情绪化敏感，钱财留不住，失眠多虑，内耗重。
+ **关键词**：富、静、敛、母性。
+ **现代画像**：积蓄型人格。擅长长线积累与精细化运营，不擅长短兵相接。
+ **职业指向**：财务、投资、设计、文创、房地产、后勤。
+ **重要规律**：**太阴亮度关联月相，与太阳日夜互反**——夜晚生人太阴增力，白天生人太阴减力。

### 贪狼（阳木 · 化气为桃花）

> **原典五行**：《紫微斗数全书》作「**贪狼属水木**」，希夷先生曰「**其气属木，体属水**，故化气为桃花」。
> 本库取"阳木"只保留了"气"的一半；**"体属水"是"泛水桃花"（贪狼居子）一格的五行依据**，读格局时须记取。

+ **庙陷**：庙在辰、戌；旺在寅、申；平在子、午、卯、酉；陷在巳、亥。
+ **庙旺**：情商极高，多才多艺，偏财机遇多，社交能力强。
+ **落陷**：欲望失控，好逸恶劳，易涉酒色财气，投机心重。
+ **关键词**：欲、才、交际、偏财。
+ **现代画像**：第一桃花星。欲望即动力——既能成为多才多艺的艺术家，也能因贪多嚼不烂而一事无成。
+ **职业指向**：销售、公关、娱乐、投资、餐饮、一切需要人脉的领域。
+ **自处建议**：贪狼需要"一个主战场"，把散在多处的欲望收敛到一件事上。
+ **要点**：贪狼遇火铃在辰戌丑未为"火贪格""铃贪格"，主暴发；贪狼居子为"泛水桃花"，才华横溢而漂泊；贪狼遇天刑，桃花转成是非官非。

### 巨门（阴水 · 化气为暗）

+ **庙陷**：庙在子、午；旺在卯、酉；得在寅、申；平/陷在辰、戌、丑、未。
+ **庙旺**：口才出众，分析力强，逻辑严密，适合靠嘴与脑子吃饭。
+ **落陷**：是非不断，说话伤人，多疑善变，易招口舌。
+ **关键词**：暗、口、疑、探究。
+ **现代画像**：深究型人格。擅长发现问题的本质，也容易陷在怀疑与批判里。
+ **职业指向**：法律、传媒、咨询、教育、研究、销售谈判、医疗诊断。
+ **自处建议**：巨门要学会"把疑问变成问题清单"，而不是变成怀疑。
+ **要点**：巨门在子午入庙坐命为"石中隐玉"——早年辛苦，中晚年靠口才与专业能力发达。

### 天相（阳水 · 化气为印）

+ **庙陷**：庙在丑、未、辰、戌；旺在寅、申、巳、亥；得在卯、酉；陷在子、亥（部分流派）。
+ **庙旺**：稳重得体，有服务精神，公正可信，适合辅佐之位。
+ **落陷**：缺乏主见，容易被利用，优柔依附。
+ **关键词**：印、辅、信、体面。
+ **现代画像**：最佳二把手。忠诚、可靠、讲体面，但需要一位明主才发光。
+ **职业指向**：秘书、助理、人力资源、法务、品牌、中介、服务设计。
+ **要点**：天相最怕"刑忌夹印"——被化忌与天刑前后夹制，印星受损，主信誉危机。

### 天梁（阳土 · 化气为荫）

+ **庙陷**：庙在子、寅、申；旺在辰、戌；平/陷在卯、酉、巳、亥。
+ **庙旺**：稳重慈祥，有化解灾难的能力，原则性强，适合公益与专业服务。
+ **落陷**：清高孤傲，好管闲事，爱说教，易招怨。
+ **关键词**：荫、寿、解厄、清高。
+ **现代画像**：庇护者。是"逢凶化吉"之星，也是"爱操心的长辈"。
+ **职业指向**：医疗、教育、公益、监察、保险、命理咨询、法律顾问。
+ **要点**：天梁的"荫"意味着**先有灾而后有解**，不是不遇灾。天梁坐命者一生多有几次"险中得救"的经历。

### 七杀（阴金 · 化气为将）

> **原典五行与化气**：《紫微斗数全书》卷二作「**七杀属火金**南斗降星遇帝为权」，卷四论七杀作「**七杀火金，南斗将星，遇帝为权，其余诸宫皆杀**」。
> 即原典五行属**火金**（非纯金）；且**原典未言七杀"化气"**，只说"南斗将星、遇帝为权"——本库"化气为将"系由"将星"转出。

+ **庙陷**：庙在寅、申、子、午；旺在辰、戌、丑、未；平/陷在卯、酉、巳、亥。
+ **庙旺**：有魄力，敢闯敢拼，适合开拓性事业，领导力强。
+ **落陷**：冲动鲁莽，易有血光，孤立无援。
+ **关键词**：将、杀、决、孤。
+ **现代画像**：开拓型将才。适合从零打江山、临危受命，不擅长守成与日常运营。
+ **职业指向**：军警、创业、竞技、外科、工程开拓、变革型管理。
+ **自处建议**：七杀宜主动选择"单兵突破"型的岗位，而不是在需要长期协作的体系里硬碰硬。
+ **要点**：七杀在寅申庙旺、紫微在对宫朝照，为"七杀朝斗 / 仰斗"，主可富贵一时；但古赋明确提醒"终必不美"，须防盛极而衰。不入格的七杀坐命，则主性情刚僻、孤立无援。

### 破军（阴水 · 化气为耗）

+ **庙陷**：庙旺在子、午（英星入庙，另一说亦重亥、子）；落陷多在辰、戌、未、申等宫（流派记载有出入）。
+ **庙旺**：破旧立新的开创力，敢于推倒重来，先破后成，晚运多亨通。
+ **落陷**：破败流离，变动失控，投入多而回收少，人际与财物皆易有破损。
+ **关键词**：破、耗、变、开创。
+ **现代画像**：颠覆者。不破不立，天生适合做"从 0 到 1"的事，最难的是"从 1 到 100"。
+ **职业指向**：创业、变革管理、开拓型业务、军事、竞技、重组整合类岗位。
+ **自处建议**：破军的"耗"需要被引导——把破坏力用在"主动破旧"上（主动转型、主动重构），而不是被动承受破损。
+ **要点**：破军遇禄存、或入田宅宫，主"先破后成"——先有破损后有成就，宜长线看待。古诀"昌曲破军逢，刑克多劳碌"提示：才华与魄力不匹配时，最容易怀才不遇。

## 7_4 星组与人生脚本

单看一颗星是"性格"，看一组星是"人生脚本"。断人时先判星组，再判主星。

| 星组 | 成员 | 共同特质 | 典型人生脚本 | 给命主的建议 |
| --- | --- | --- | --- | --- |
| **杀破狼** | 七杀、破军、贪狼 | 变动、开创、破立 | 一生大起大落，宜动不宜静，中年后方可定 | 主动规划变动（换赛道、创业），别等被动变动 |
| **机月同梁** | 天机、太阴、天同、天梁 | 谋定、服务、稳健 | 适合体制、专业服务、顾问，宜守不宜急 | 深耕专业，靠资历与口碑积累 |
| **紫廉武同** | 紫微、廉贞、武曲、天同 | 主导、执行 | 有主导欲与行动力 | 补团队与执行力 |
| **府相梁** | 天府、天相、天梁 | 稳定、辅佐、荫庇 | 宜做二把手、管理者、守成者 | 找到明主/好平台，比单打独斗重要 |

**用法**：命宫主星属于哪一组，决定了对这个人说"建议"时的语气。对杀破狼说"稳一点"收效甚微，要说"把变动规划好"；对机月同梁说"搏一把"反而害人。

## 7_5 故事：同样"能力强"，两种不同的苦

**背景**。公司里有两位同事，都被评价为"能力很强"。但三年后，一个做到高管，一个频繁跳槽、始终没站稳。

**第一位：紫微在午入庙的盘**

```latex
命宫：紫微在午入庙（极向离明的结构）
三方：左辅、右弼、天魁会照 → 君臣庆会的结构
他的"强"是有人接得住的强——决策有人执行，资源有人补充。

```

他苦的地方在于：一旦离开平台，会发现自己的"强"有相当部分来自位置与团队。他自己也隐约感觉到这一点，所以从不轻易动。

**第二位：七杀落陷的盘**

```latex
命宫：七杀落陷
三方：无吉星拱照，对宫也无紫微朝照
他的"强"是硬撑出来的强——敢冲敢扛，但没人兜底。

```

他苦的地方在于：每次快到成果时都会出意外，而且容易与同事起冲突。三年里换了四次岗，每次都是"快出成绩了就走人"。

**同样的"能力强"，断法必须不同**

```latex
第一位 → 建议：守住平台、养团队，避免为了证明自己而离开体系
         关键词：他的风险是"高估自己的独立能力"

第二位 → 建议：主动选择需要"单兵突破"的岗位（开拓、外派、创业），
         而不是在需要协作的体系里硬碰硬
         关键词：他的风险是"在错误的战场消耗自己"

```

**后来的反馈**。第一位在第四年升了高管，团队也带起来了。第二位去了外地做区域开拓，半年后回来，说："这次没人和我抢功劳，也没人拖我后腿，我一个人反而顺了。"

**方法论小结**

```latex
主星给出的是"能量的形状"，
星组给出的是"人生脚本"，
庙陷给出的是"这股能量现在好不好用"。
三者缺一，建议就会落空——
同样是"能力强"，一个人该守，一个人该走。

```

## 7_6 笔记法：星曜卡与访谈验证

### 星曜卡（一星一卡，十四张起步）

```latex
【星名】____  【五行】__  【化气】__
【庙陷】庙__ / 旺__ / 陷__
【正面】____________________
【反面】____________________
【关键搭档】________（谁让它更强）
【怕什么】________（谁/什么破它）
【我验证过的案例】________（真实反馈，不抄书本例句）

```

### 访谈三问（断性格时让命主确认）

```latex
问题 1（确认能量形状）：你做决定时，通常是最快做决定的人，还是想很久的人？
   → 天机重的人会犹豫；七杀/武曲重的人很快

问题 2（确认庙陷）：你觉得自己这些年，是"越来越顺"还是"一直很费劲"？
   → 庙旺者通常体感顺；落陷者常有"费劲但没结果"的体感

问题 3（确认星组）：过去五年，你的变化是被迫的还是主动的？
   → 杀破狼 + 主动 → 能量用对了
   → 杀破狼 + 被迫 → 能量在被动消耗

```

**记录要求**：把命主**原话**记下来，不要记成自己的转述。原话里往往藏着更准的星曜线索。
