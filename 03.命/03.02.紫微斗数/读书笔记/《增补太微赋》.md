## 板块2 · 完整原文与逐段精解

### 2_1 第一段：总纲——吉多凶少 vs 凶多吉少

> **原文：** 前后两凶神为两邻，加会尚可撑持，同室与谋最难堤防。片火焚天马，重羊逐禄存。劫空亲戚无常，权禄行藏靡定。

**白话直译：** 前后两个凶神作为两邻，加会还可以撑持得住，同室图谋最难堤防。一点火星焚烧天马，重重擎羊追逐禄存。劫空让亲戚缘分无常，权禄让行藏变化不定。

**深度解读：** 开篇先补充了《玄微论》中"两邻加侮"的论述，然后展开四个关键判断：

+ **片火焚天马** → 火星虽小，遇到天马（五行火）则引动奔波
+ **重羊逐禄存** → 擎羊陀罗夹住禄存，求财艰难
+ **劫空** → 入六亲宫则亲戚缘薄
+ **权禄** → 行藏不定，变化多端

### 2_2 第二段：君子小人之辩

> **原文：** 君子哉魁钺，小人哉羊铃。凶不皆凶，吉无纯吉。主强宾弱可保无虞，主弱宾强凶危立见。主宾得失两相宜，运限命身当互见。

**白话直译：** 君子啊是魁钺，小人啊是羊铃。凶不全然凶，吉不纯然吉。主强宾弱可保无虞，主弱宾强凶危立刻显现。主宾得失两相适宜，运限和命身应当互相对照。

**深度解读：** 与《玄微论》呼应，再次强调主宾论的核心法则。

### 2_3 第三段：身命最嫌羊陀七杀

> **原文：** 身命最嫌羊陀七杀，遇之未免为凶。二限甚忌贪破巨廉，逢之定然作祸。命遇魁昌常得贵，限逢紫府定财多。

**白话直译：** 身命最嫌弃羊陀七杀，遇到难免为凶。大限小限甚忌贪狼破军巨门廉贞，遇到定然作祸。命遇魁昌常得贵，限逢紫府定然财多。

**深度解读：**

+ 身命遇羊陀七杀 → 必有凶险
+ 二限（大限+小限）遇贪破巨廉 → 定然作祸
+ 命宫遇天魁文昌 → 常得贵气
+ 大限遇紫微天府 → 定然财多

### 2_4 第四段：男女命的不同看法

> **原文：** 凡观女人之命，先观夫子二宫。若值杀星，定三嫁而心不足；或逢羊孛，虽啼哭而泪不干。若观男命，始以福财为主，再审迁移何如。二限相因，吉凶同断。

**白话直译：** 凡看女人之命，先看夫妻宫和子女宫。若遇到杀星，定然三嫁而心不满足；或逢擎羊（孛），虽然啼哭而眼泪不干。若看男命，以福德财帛为主，再审查迁移宫如何。二限相因，吉凶同断。

**深度解读：** 与《玄微论》内容一致但更详细——"羊孛"即擎羊，孛为古代对擎羊的别称。

### 2_5 第五段：限逢吉曜 vs 命坐凶乡

> **原文：** 限逢吉曜，平生动用和谐；命坐凶乡，一世求谋龃龉。

**白话直译：** 大限遇到吉曜，平生动用和谐；命宫坐在凶乡，一世求谋艰难不顺。

**深度解读：** "龃龉"（jǔ yǔ）指上下牙齿对不上，比喻不顺利、有阻碍。命宫凶则一生求谋艰难。

### 2_6 第六段：廉禄临身与同梁守命

> **原文：** 廉禄临身，女得纯阴贞洁之德；同梁守命，男得纯阳中正之心。君子命中，亦有羊陀火铃；小人命内，岂无科禄权星。要看得垣失垣，专论入庙失庙。

**白话直译：** 廉贞化禄临身宫，女子得纯阴贞洁之德；天同天梁守命，男子得纯阳中正之心。君子命中也有羊陀火铃；小人命内难道没有科禄权星？要看得垣失垣，专论入庙失庙。

**深度解读：** 再次强调"凶不皆凶，吉无纯吉"的核心思想。星曜的吉凶不在名号，而在庙陷。

### 2_7 第七段：小儿命的特殊性

> **原文：** 若论小儿，详推童限。小儿命坐凶乡，二五岁必然夭折，更有限逢恶杀，五七岁必主灾亡。文昌文曲天魁秀，不读诗书也可人。

**白话直译：** 若论小儿，详细推演童限。小儿命坐凶乡，二五岁必然夭折；更有限逢恶杀，五七岁必主灾亡。文昌文曲天魁主秀气，不读诗书也可人。

**深度解读：** 补充了具体年龄——"二五岁"即2-5岁，"五七岁"即5-7岁。童限（第一大限在命宫）如果凶，对幼儿极为不利。

### 2_8 第八段：多学少成与为人好讼

> **原文：** 多学少成，只为擎羊逢劫杀。为人好讼，盖因太岁遇官符。

**白话直译：** 多学少成，只因为擎羊逢劫杀。为人好打官司，因为太岁遇官符。

**深度解读：**

+ 擎羊+劫杀 → 学习难以坚持，半途而废
+ 太岁+官符 → 容易卷入官司诉讼

### 2_9 第九段：贵格四则

> **原文：** 紫微在命辅弼同垣，其贵必矣。财印夹命，日月夹财，其富何疑？荫福临，不怕凶冲。日月会不如合照。

**白话直译：** 紫微在命宫，辅弼同垣，其贵必然。财印夹命，日月夹财，其富何须怀疑？荫福临照，不怕凶冲。日月相会不如合照。

**深度解读：**

| 格局 | 构成 | 判定 |
| --- | --- | --- |
| 紫微+辅弼同垣 | 紫微坐命 + 左辅右弼同宫或会照 | 贵不可言 |
| 财印夹命 | 武曲（财）+ 天相（印）夹命宫 | 财富丰厚 |
| 日月夹财 | 太阳+太阴夹财帛宫 | 富贵无疑 |
| 荫福临 | 天梁（荫）+ 天同（福）同宫 | 不怕凶冲 |
| 日月会不如合照 | 日月同宫不如三方互照 | 合照力量更大 |

### 2_10 第十段：桃花格局的辩证

> **原文：** 贪狼居子，乃为泛水桃花。天刑遇贪，必主风流刑杖。

**白话直译：** 贪狼居于子宫，乃是泛水桃花。天刑遇到贪狼，必主风流刑杖。

**深度解读：**

+ **贪狼在子**（或亥子二宫） → 泛水桃花格 → 主才华横溢但也漂泊不定
+ **贪狼遇天刑** → 风流彩杖格 → 因桃花惹是非甚至官非

### 2_11 第十一段：文曜与官禄

> **原文：** 紫微坐命库，则曰金舆捧栉辇；临官安文曜，号为衣锦惹天香。太阴合文曲于妻宫，翰林清异；太阳会文昌于官禄，金殿传胪。

**白话直译：** 紫微坐在命库，叫做金舆捧栉辇；官禄宫安放文曜，号为衣锦惹天香。太阴合文曲在夫妻宫，主翰林清异；太阳会文昌在官禄宫，主金殿传胪。

**深度解读：**

| 格局 | 构成 | 现代对应 |
| --- | --- | --- |
| 金舆捧栉辇 | 紫微在午宫 + 吉星 | 帝王之象，大贵 |
| 衣锦惹天香 | 官禄宫有文昌文曲 | 名士风度，才华出众 |
| 翰林清异 | 太阴+文曲在夫妻宫 | 文艺气质，配偶有才 |
| 金殿传胪 | 太阳+文昌在官禄宫 | 学业优异，事业有成 |

### 2_12 第十二段：穷通寿夭的极端对比

> **原文：** 耗居败地，沿途丐求；贪会旺宫，终身鼠窃。杀居绝地，生成三十二之颜回；日在旺宫，可学八百年之彭祖。

**白话直译：** 大耗居于败地，沿途乞讨；贪狼会于旺宫，终身做鼠窃之事。七杀居于绝地，生成三十二岁的颜回；太阳在旺宫，可学八百年的彭祖。

**深度解读：**

| 条件 | 结果 | 说明 |
| --- | --- | --- |
| 大耗在败地 | 沿途丐求 | 乞丐之命 |
| 贪狼在旺宫无制 | 终身鼠窃 | 小偷小摸 |
| 七杀在绝地 | 颜回之寿（32岁） | 短命 |
| 太阳在旺宫 | 彭祖之寿（800岁） | 长寿 |

### 2_13 第十三段：凶星交会的后果

> **原文：** 巨暗同垣于身命疾厄，羸瘦其躯；凶星交会于相貌迁移，伤刑其面。

**白话直译：** 巨门暗曜同垣于身命疾厄，使身躯羸瘦；凶星交会于相貌（父母宫）迁移，伤害刑克其面容。

**深度解读：**

+ **巨门+暗曜** 在身命疾厄 → 身体瘦弱多病
+ **凶星交会** 在父母宫（相貌）+ 迁移宫 → 面部破相、外伤

### 2_14 第十四段：流年凶星速查

> **原文：** 七杀临于陷地，流年必见死亡；耗杀忌逢破军，火铃嫌逢太岁。奏书博士并流禄，以尽乎吉祥；力士将军与青龙，以显其威福。

**白话直译：** 七杀临于陷地，流年必见死亡；大耗七杀忌讳逢破军，火铃嫌逢太岁。奏书博士并流禄，尽显吉祥；力士将军与青龙，以显威福。

**深度解读：**

| 流年组合 | 吉凶 | 应事 |
| --- | --- | --- |
| 七杀 + 陷地 | ★★★★★凶 | 生命危险 |
| 大耗 + 七杀 + 破军 | ★★★★凶 | 重大损失 |
| 火星/铃星 + 太岁 | ★★★★凶 | 突发灾祸 |
| 奏书 + 博士 + 流禄 | ★★★吉 | 吉祥顺遂 |
| 力士 + 将军 + 青龙 | ★★★吉 | 权势增长 |

### 2_15 第十五段：童子限与老人限

> **原文：** 童子限弱，水上浮泡；老人限衰，风中燃烛。遇杀必惊，流年最紧。

**白话直译：** 童子限弱，如水上浮泡；老人限衰，如风中燃烛。遇到杀星必惊，流年最紧要。

**深度解读：**

+ **童子限**（第一大限命宫）弱 → 如水上浮泡，脆弱易破（小孩难养）
+ **老人限**（晚年大限）衰 → 如风中残烛，岌岌可危
+ **遇杀必惊** → 流年遇杀星要特别警惕

### 2_16 第十六段（结尾）

> **原文：** 人生发达，限元最怕浮沉；一世迍邅，命限逢乎驳杂。论而至此，允矣玄微。

**白话直译：** 人生要发达，大限最怕浮沉不定；一世困顿，因为命限逢到驳杂。论述到这里，确实是玄微奥妙啊。
