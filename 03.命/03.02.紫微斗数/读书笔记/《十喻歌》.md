## 板块1 · 原文概览

《十喻歌》是紫微斗数中论述宫位吉凶判断逻辑的核心歌诀。全篇仅10句、80字，却精准地回答了斗数论命中最核心的操作问题：

> **看一个宫位的好坏，本宫、对宫、三合宫、邻宫，到底谁重要？谁影响大？**

这就是《十喻歌》要解决的"权重分配"问题。本篇依据多个权威注本，将原文逐句补全，并构建完整的"十喻"体系。

## 板块3 · 逐句精解

### 3_1 第一喻：本宫为根（本方吉→由内自强）

> **吉凶最要细分明，本对合邻有重轻。**

**白话直译：** 吉凶最要仔细分明，本宫、对宫、合宫、邻宫各有轻重。

**核心逻辑：** 判断任何一个宫位的吉凶，必须区分四种影响力的权重：

| 类型 | 含义 | 影响力权重 | 比喻 |
| --- | --- | --- | --- |
| **本**（本方） | 本宫自身的星曜 | ★★★★★（最重，占60%） | 树的根 |
| **对**（对方） | 对宫的星曜 | ★★★★（次重，占40%） | 镜子 |
| **合**（合方） | 三合宫的星曜 | ★★★（中等，占20%） | 左右手 |
| **邻**（邻方） | 左右邻宫的星曜 | ★★（最轻，占10%） | 邻居 |

**实操要点：** 本宫永远是第一位的。本宫吉 = 自我强大；本宫凶 = 自断其根。

### 3_2 第二喻：对宫如镜（对方吉→迎面春风 / 对方凶→当头恶棒）

> **四面楚歌终必败，千祥云集自然亨。**

**白话直译：** 如果四方都凶，就像四面楚歌终必败亡；如果千祥云集，自然亨通。

**深度解读：** "四面楚歌"指本宫、对宫、两个三合宫全部是凶星——这是最差的格局。"千祥云集"则相反，四方皆吉。

对宫和本宫在一条线上（如命宫对迁移宫），一阴一阳、一里一表，**息息相关**：

+ **对宫吉** → 迎面春风，本宫受益
+ **对宫凶** → 当头一棒，本宫受损

**实操要点：** 对宫的凶有时可避（因为不在本宫），但冲击力是直接而强烈的。

### 3_3 第三喻：三合宫为援（合方吉→左右逢源 / 合方凶→左右受敌）

> **自强才是好人家，邻舍惟添锦上花。**

**白话直译：** 自己强大才是好人家，邻居只是添锦上花。

**深度解读：** 前半句强调"本宫自强"是第一位的。后半句说邻宫只是辅助。但这里还隐含了"合方"的重要性——合方（三合宫）的力量介于对宫和邻宫之间。

三合宫 = 本宫 + 左右两个三合位（如申子辰三合）。

+ **合方吉** → 左右逢源，有人帮扶
+ **合方凶** → 左右受敌，被人欺负

### 3_4 第四喻：邻宫为助（邻方吉→两邻相扶 / 邻方凶→两邻相侮）

> **若到逢源真境地，春风只可感相差。**

**白话直译：** 如果到了左右逢源的真境地，那春风般的感受是不可同日而语的。

**深度解读：** "逢源"指的是三合宫（会合宫）的力量。当三合宫都吉时，那种助力是巨大的，和邻宫的"锦上添花"完全不在一个量级。

### 3_5 第五喻：极端情况（方宫皆吉→千祥云集 / 方宫皆凶→四面楚歌）

> **两邻相侮岂为灾，自伐才叫大可哀。**

**白话直译：** 两个邻居相欺侮怎么能算灾呢？自己砍伐自己（本宫凶）才真正可悲。

**深度解读：** 再次强调本宫的重要性。邻宫再凶也"岂为灾"——因为邻宫不是本宫的核心力量，只是辅助。但如果是本宫自己凶（自伐），那就是根本性的伤害。

### 3_6 第六喻：对宫凶可避 vs 邻宫凶难防

> **易躲当头一棍棒，难防左右袭兵来。**

**白话直译：** 容易躲开当头的一棍棒，难以防备左右袭来的兵马。

**深度解读：** 这是对"对宫凶"和"邻宫凶"的辩证补充——

+ **对宫凶**（当头一棒）→ 虽然猛烈，但容易躲避（因为在对面，不是内部）
+ **邻宫凶**（左右袭兵）→ 虽然单次伤害不大，但防不胜防（因为左右夹击）

⚠️ **注意：** 这和前面"邻宫岂为灾"看似矛盾，实则互补——邻宫凶单独看不严重，但如果两个邻宫都有凶星夹击，就变成"左右袭兵"了。

## 板块5 · 网络补充：十喻歌的现代实操应用

### 5_1 看任何宫位的"标准流程"

以"看财帛宫"为例：

```plain
Step 1：看财帛宫本身（本方，权重60%）
  → 主星是什么？庙旺还是落陷？有无煞星？

Step 2：看对宫（福德宫，权重40%）
  → 福德宫吉 → 赚钱有福气加持
  → 福德宫凶 → 赚钱辛苦，有钱也不快乐

Step 3：看三合宫（命宫+迁移宫，权重20%）
  → 命宫吉 → 自身有能力赚钱
  → 迁移宫吉 → 外出求财顺利

Step 4：看邻宫（官禄宫+子女宫，权重10%）
  → 吉 → 锦上添花
  → 凶 → 影响不大，但需注意

Step 5：综合判断
  → 十喻中符合几条？得出财运等级

```

### 5_2 各宫位的"对宫关系"速查表

| --- | --- | --- |
| 命宫 | 迁移宫 | 内在自我 vs 外在表现 |
| 兄弟宫 | 交友宫（奴仆宫） | 平辈关系的两面 |
| 夫妻宫 | 官禄宫 | 婚姻 vs 事业，相互影响 |
| 子女宫 | 田宅宫 | 后代 vs 家业 |
| 财帛宫 | 福德宫 | 物质 vs 精神 |
| 疾厄宫 | 父母宫 | 身体 vs 遗传/根基 |

### 5_3 实战案例解析

**案例：判断一个人是否适合创业**

| 检查项 | 吉（适合创业） | 凶（不适合创业） |
| --- | --- | --- |
| 命宫（本方60%） | 七杀、破军庙旺 | 天同陷地、空宫 |
| 财帛宫（三合20%） | 武曲+禄存 | 地空地劫 |
| 官禄宫（三合20%） | 紫微+化权 | 巨门+化忌 |
| 迁移宫（对宫40%） | 太阳庙旺 | 太阴陷地 |
| 福德宫（财帛对宫） | 天同+天梁 | 擎羊+火星 |

**判断逻辑：** 按十喻歌的权重，先看命宫（本方60%），再看财帛和官禄（三合20%），然后看迁移（对宫40%），最后看邻宫辅助。多数条件满足则为"千祥云集"，适合创业。

### 5_4 "权重打分法"实操工具

根据十喻歌的权重比例，可以量化任何宫位的吉凶：

```plain
宫位吉凶得分 = 本宫得分×0.6 + 对宫得分×0.4 + 三合宫得分×0.2 + 邻宫得分×0.1

其中：
  吉星庙旺 = +10分
  吉星平陷 = +5分
  煞星庙旺 = -5分
  煞星落陷 = -10分
  空宫 = 借对宫星曜评分

```

### 5_5 常见误区

+ "对宫凶就一定坏" → 对宫凶有时可避，不如本宫凶影响大
+ "邻宫凶很可怕" → 邻宫凶"岂为灾"，影响最轻
+ "只看本宫就够了" → 本宫吉但三合全凶 = 秀而不实
+ "三方四正随便看" → 十喻歌明确告诉你：有重轻次序

## 板块6 · 总结

《十喻歌》用80个字解决了斗数论命中最大的操作难题——**权重分配**：

> **本宫为根最重要（60%），对宫如镜次重要（40%），三合为援第三层（20%），邻宫辅助最轻微（10%）。四方皆吉千祥云集，四方皆凶四面楚歌。**

学会十喻歌，你就掌握了"看盘先看哪里"的优先级。这是斗数入门后迈向精通的关键一步。
