## 板块1 · 原文概览与题解

"彀率"（gòu lǜ）意为**张满弓弩的技法与标准**，《重补斗数彀率》就是斗数断命的"精准射击手册"。

"重补"说明这是后学弟子对前文（太微赋、玄微论等）的**补充修订版**——它与太微赋大量重叠，但更加精炼，可以看作是所有前文赋文的**"速查精炼版"**。

本篇依据《紫微斗数全书》原文，逐段补全精解，并补充大量现代实操内容。

## 板块2 · 完整原文与逐段精解

### 2_1 第一段：总纲——吉多vs凶多的数量法则

> **原文：** 诸星吉多逢凶也吉，诸星恶多逢吉也凶。星更躔度，数分定局。

**白话直译：** 众星中吉星多，即使遭遇凶星也吉利；凶星多，即使遇到吉星也凶险。星曜更迭运行，命数分定格局。

**深度解读：** 这条法则极其简明有力——

+ **吉星数量 > 凶星数量** → 即使走凶限也不会有大问题
+ **凶星数量 > 吉星数量** → 即使走吉限也不会太顺利

**星更躔度** = 星曜经过运行落入不同宫位
**数分定局** = 人生命运格局由此定下

**实操要点：** 拿到命盘，先数吉星和凶星的数量。这是最快的"初判法"，30秒出结果。

### 2_2 第二段：得垣受制——判断的核心技术

> **原文：** 重在看星得垣受制，方可论人祸福穷通。

**白话直译：** 重点在于看星曜是否得垣受制，才可以论断人的祸福穷通。

**深度解读：**

| 概念 | 含义 | 判断方法 |
| --- | --- | --- |
| **得垣** | 星曜在庙旺的宫位 | 查庙旺表，看星曜是否在自己"喜欢"的宫位 |
| **受制** | 星曜在落陷宫位，或被其他星曜克制 | 落陷 + 被煞星夹制 = 力量大打折扣 |

**关键洞见：** "受制"不是指星曜五行被宫位五行克制（这是八字思维），而是指**星曜落陷后容易被煞曜乘虚而入**。

### 2_3 第三段：身命为柄，根源为机

> **原文：** 大概以身命为祸福之柄，以根源为穷通之机。

**白话直译：** 大抵以身宫命宫为祸福的柄杖，以根源为穷通的机要。

**深度解读：**

+ **身命为柄** → 命宫、身宫是判断祸福的"手柄"（关键所在）
+ **根源为机** → 福德宫、田宅宫、交友宫是判断穷通的"机要"

**"根源"的新概念：** 它不像身命那样直指"你是谁"，而是指向"你从哪来"——

+ **福德宫** → 福气厚度（精神层面的富足）
+ **田宅宫** → 家族积累（物质层面的根基）
+ **交友宫** → 周围人的层次（社会关系的质量）

### 2_4 第四段：贵格四则

> **原文：** 紫微在命辅弼同垣，其贵必矣。财印夹命，日月夹财，其富何疑？荫福临，不怕凶冲。日月会不如合照。

**白话直译：** 紫微在命宫，辅弼同垣，其贵必然。财印夹命，日月夹财，其富何须怀疑？荫福临照，不怕凶冲。日月相会不如合照。

**逐句解读：**

| 口诀 | 构成条件 | 判定 |
| --- | --- | --- |
| 紫微+辅弼同垣 | 紫微坐命 + 左辅右弼同宫或会照 | 贵不可言 |
| 财印夹命 | 武曲（财）+ 天相（印）夹命宫 | 财富丰厚 |
| 日月夹财 | 太阳+太阴夹财帛宫 | 富无疑问 |
| 荫福临 | 天梁（荫）+ 天同（福）同宫坐命 | 不怕凶冲 |
| 日月会不如合照 | 日月同宫不如日月三方互照 | 合照力量 > 同宫 |

**实操要点：** "日月会不如合照"是因为日月同宫时**必有一颗落陷**，而三方互照时两颗星可以同时庙旺。

### 2_5 第五段：桃花格局的辩证

> **原文：** 贪狼居子，乃为泛水桃花。天刑遭贪，必主风流刑杖。

**白话直译：** 贪狼居于子宫，乃是泛水桃花。天刑遭遇贪狼，必主风流刑杖。

**深度解读：**

+ **贪狼在子**（或亥子二宫） → 泛水桃花 → 才华横溢但也漂泊不定
+ **贪狼遇天刑** → 风流彩杖 → 因桃花惹是非甚至官非

**现代解读：** 泛水桃花 = 艺术家气质、多才多艺、四海为家。不一定坏，要看有无空劫制化。

### 2_6 第六段：文曜与官禄

> **原文：** 紫微坐命库，则曰金舆捧栉辇；临官安文曜，号为衣锦惹天香。太阴合文曲于妻宫，翰林清异；太阳会文昌于官禄，金殿传胪。

**白话直译：** 紫微坐在命库，叫做金舆捧栉辇；官禄宫安放文曜，号为衣锦惹天香。太阴合文曲在夫妻宫，主翰林清异；太阳会文昌在官禄宫，主金殿传胪。

**深度解读：**

| 格局 | 构成 | 现代对应 |
| --- | --- | --- |
| 金舆捧栉辇 | 紫微在午宫 + 吉星 | 帝王之象，大贵 |
| 衣锦惹天香 | 官禄宫有文昌文曲 | 名士风度，才华出众 |
| 翰林清异 | 太阴+文曲在夫妻宫 | 文艺气质，配偶有才 |
| 金殿传胪 | 太阳+文昌在官禄宫 | 学业优异，事业有成 |

### 2_7 第七段：穷通寿夭的极端对比

> **原文：** 耗居败地，沿途丐求；贪会旺宫，终身鼠窃。杀居绝地，生成三十二之颜回；日在旺宫，可学八百年之彭祖。

**白话直译：** 大耗居于败地，沿途乞讨；贪狼会于旺宫，终身做鼠窃之事。七杀居于绝地，生成三十二岁的颜回；太阳在旺宫，可学八百年的彭祖。

**深度解读：**

| 条件 | 结果 | 说明 |
| --- | --- | --- |
| 大耗在败地 | 沿途丐求 | 乞丐之命 |
| 贪狼在旺宫无制 | 终身鼠窃 | 小偷小摸 |
| 七杀在绝地 | 颜回之寿（32岁） | 短命 |
| 太阳在旺宫 | 彭祖之寿（800岁） | 长寿 |

### 2_8 第八段：凶星交会的后果

> **原文：** 巨暗同垣于身命疾厄，羸瘦其躯；凶星交会于相貌迁移，伤刑其面。

**白话直译：** 巨门暗曜同垣于身命疾厄，使身躯羸瘦；凶星交会于相貌（父母宫）迁移，伤害刑克其面容。

**深度解读：**

+ **巨门+暗曜** 在身命疾厄 → 身体瘦弱多病
+ **凶星交会** 在父母宫（相貌）+ 迁移宫 → 面部破相、外伤

### 2_9 第九段：大耗会廉贞与官符会刑杀

> **原文：** 大耗会廉贞于官禄，枷杻囚徒；官符会刑杀于迁移，离乡远配。

**白话直译：** 大耗会廉贞于官禄宫，主枷锁囚徒；官符会刑杀于迁移宫，主离乡远配。

**深度解读：**

+ **大耗+廉贞** 在官禄宫 → 因事业/工作惹上官司，沦为囚徒
+ **官符+刑杀** 在迁移宫 → 因外出/迁移惹祸，被流放远方

### 2_10 第十段：流年凶星与吉星

> **原文：** 七杀临于陷地，流年必见死亡；耗杀忌逢破军，火铃嫌逢太岁。奏书博士并流禄，以尽乎吉祥；力士将军与青龙，以显其威福。

### 2_11 第十一段：童子限与老人限

> **原文：** 童子限弱，水上浮泡；老人限衰，风中燃烛。遇杀必惊，流年最紧。

**白话直译：** 童子限弱，如水上浮泡；老人限衰，如风中燃烛。遇到杀星必惊，流年最紧要。

### 3_1 "数吉凶"三步速判法

```plain
Step 1：标注所有星曜的庙旺落陷
  → 庙旺的吉星 ✓，落陷的吉星减半
  → 落陷的凶星 ✓✓（更凶），庙旺的凶星减半

Step 2：数数量
  → 吉星得分总和 vs 凶星得分总和

Step 3：定等级
  → 吉 > 凶 → 上等命（逢凶也吉）
  → 凶 > 吉 → 下等命（逢吉也凶）
  → 势均力敌 → 看庙旺落陷决定

```

### 3_5 批判性思考

《重补斗数彀率》中有些断语过于极端（如"沿途丐求""终身鼠窃"），现代解读应注意：

+ 这些是**格局倾向**的描述，不是绝对的命运定论
+ 时代背景不同，古代"乞丐"在现代可能是"经济困难期"
+ 星曜组合是"概率倾向"，不是"必然结果"

## 板块4 · 总结

《重补斗数彀率》是紫微斗数所有赋文的**"终极精炼版"**：

> **诸星吉多逢凶也吉，诸星恶多逢吉也凶。重在看星得垣受制，以身命为祸福之柄，以根源为穷通之机。**

它用最少的文字，浓缩了最多的判断法则。学会这篇，你就拥有了斗数断命的"精准射击术"——快速、准确、一击中的。
