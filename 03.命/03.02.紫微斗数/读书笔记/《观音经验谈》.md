## 板块2 · 完整原文逐段精解

### 2_1 看盘的优先级：命→身→三方→夹拱→六宫

> **原文：** 安妥命盘，只见满盘数十星曜，善恶兼有时，以命宫所落何地即与何星同垣为主要，次则观审身宫及同垣之曜，三则看命及身宫其三方四正有何吉曜之拱照，抑或有无羊陀火铃其四煞之冲破，然后再观夹拱如何，其财帛、官禄、迁移与福德又如何。

**白话直译：** 安好命盘后，看到满盘数十颗星曜善恶兼有，首先以命宫落在何地、与何星同宫为主要判断依据；其次观察身宫及同宫星曜；第三看命宫和身宫的三方四正有何吉曜拱照，或者有无擎羊陀罗火星铃星四煞冲破；然后再看夹拱情况如何；最后看财帛、官禄、迁移与福德四宫又如何。

**深度解读：** 这是全篇最有实操价值的段落，给出了看盘的五步优先级：

| 优先级 | 看什么 | 权重 | 原因 |
| --- | --- | --- | --- |
| 第一优先 | 命宫落何地、与何星同垣 | ★★★★★ | 命宫是命盘的核心，决定先天禀赋 |
| 第二优先 | 身宫及同垣星曜 | ★★★★ | 身宫决定后天走向 |
| 第三优先 | 命身宫的三方四正吉凶 | ★★★★ | 三方四正决定环境助力 |
| 第四优先 | 夹拱情况（前后宫位夹命） | ★★★ | 夹宫有重要影响但非核心 |
| 第五优先 | 财帛、官禄、迁移、福德四宫 | ★★★ | 四大功能宫位决定具体领域 |

**实操要点：** 不要拿到盘就"满盘乱看"。按这个优先级从上到下，逐层判断，效率最高、准确率最好。

### 2_2 上等命格的判定标准

> **原文：** 命、身二宫至为紧要。若得南北二天之星曜庙旺守值，而三方又得众吉庙旺拱照，且无四煞或空劫刑囚耗忌之交会冲合或夹持，勿论命身坐落何宫，皆作美论。

**白话直译：** 命宫身宫二宫最为紧要。如果得到南斗北斗的星曜庙旺守值，而三方又得到众多吉星庙旺拱照，并且没有四煞或空劫刑囚耗忌的交会冲合或夹持，不论命身坐落在哪个宫位，都作美好的论断。

**深度解读：** 上等命格 = 三个条件同时满足：

1. **南北二天星曜庙旺守值** → 紫微（北斗主）和天府（南斗主）都在庙旺位置
2. **三方众吉庙旺拱照** → 三合宫全是吉星且庙旺
3. **无四煞空劫刑囚耗忌** → 没有擎羊、陀罗、火星、铃星、地空、地劫等凶星干扰

满足这三个条件，**不论命身落在哪个宫位，都是好命**。

### 2_3 美上加美：合局入格

> **原文：** 再若合局入格，更得众吉拱与吉夹，应系美上加美，秀实之最。

**白话直译：** 如果再合局入格，更得到众多吉星拱照与吉夹，那就是美上加美，最为秀实。

**深度解读：** "秀实"是南北山人独创的评判标准——"秀"是表面好看（命宫吉星多），"实"是实质有用（三方四正也吉）。秀而不实是很多命盘的通病。

### 2_4 富贵双全的精确判断

> **原文：** 若是命、身皆强，而财迁官三宫亦见众吉齐凑，则此命必非凡品，成人者可作富贵兼有。（注：官禄宫佳吉，则以贵断。财帛宫若是胜于官禄宫，则以富断。若是财、官二宫皆为吉美，则以富贵双全断。惟富贵双全之命，其命务必入格，如"三奇嘉会格"、"将星得地格"、"明珠出海格"、"日照雷门格"、"雄星朝垣格"等是，否则不可妄测），少年者可作来日发达之断。

**白话直译：** 如果命身都强，而财帛、迁移、官禄三宫也见众多吉星齐凑，则此命必非凡品。官禄宫佳吉则以贵断；财帛宫胜于官禄宫则以富断；财官二宫皆吉美则以富贵双全断。但富贵双全的命，务必入格，否则不可妄测。

**深度解读：** 这是非常精确的"富贵判断法"：

+ **官禄宫佳吉** → 以"贵"断（当官、有权）
+ **财帛宫胜于官禄宫** → 以"富"断（经商、有钱）
+ **财官二宫皆吉美** → 以"富贵双全"断
+ **富贵双全必须满足** → 命务必入格

**实操要点：** 很多人笼统地说"又富又贵"，但原文告诉你——**富和贵是两个不同的宫位在主导**，要分开看。

### 2_5 美玉瑕玷：大限不配合的折损

> **原文：** 然而亦有者命、身及财迁官福六宫皆强，而有力之大限均值闲陷之刑囚耗忌空劫或逢遇四煞，则告美玉瑕玷，虽美不足，得数为之大减，而务必断以中格之情。

**白话直译：** 但也有命身及财迁官福六宫都强，而大限却走在闲陷的刑囚耗忌空劫或四煞之中，这就好比美玉有瑕疵，虽然美好但不够完美，得分大打折扣，务必断为中格。

**深度解读：** 原局好但大限走得不配合 → 美玉瑕玷。这告诉我们：**原局定上限，大限定下限**。原局再好，如果大限一直走凶，人生也会大打折扣。

### 2_6 秀而不实：命宫吉但三方有煞

> **原文：** 但若是命宫纵有吉星守垣，而三方有吉亦有煞曜拱冲，则谓"秀而不实"（注：见一煞或空劫亦然），则主其人与命宫同坐平闲之煞曜并无二致。盖三方仅为财迁官三者而已，均不可为煞所值，入财则财损，入官则官吝，入迁移则主出门多咎，直接有损财、官（或事业）之获也。

**白话直译：** 但如果命宫虽然有吉星守垣，而三方有吉也有煞曜拱冲，这就叫"秀而不实"，主这个人和命宫同坐平闲煞曜没什么两样。因为三方仅仅是财帛、迁移、官禄三者而已，都不可被煞星占据——入财则财损，入官则事业受阻，入迁移则出门多咎。

**深度解读：** 这是非常精辟的见解——**命宫本身好，但三方被煞星冲破，等于"好看但不实用"**。就像一个人学历很高（命宫吉），但工作环境中全是小人（三方煞曜），最终也难有成就。

**三方煞星的具体影响：**

+ 煞入财帛 → 财损（赚钱困难、破财）
+ 煞入官禄 → 官吝（事业受阻、升迁无望）
+ 煞入迁移 → 出门多咎（外出不利、远行有灾）

### 2_7 七杀坐命的深度分析

> **原文：** 惟男女之命身及福德、迁移均不宜坐守七杀。倘命入七杀位于朝斗仰斗之地而合局入格，男者固可富贵于一世，然则终必不美（注：如袁世凯即乃正宗"七杀朝斗格"，暴殁于五十八岁亦系一例）。而凡不入格者尤其不为美论，无煞冲合则主性情怪僻、刚愎逾常、厚己苛人，终遭灾悔遽临。有煞交会者主贫贱孤寡，亦主奸佞张狂，与人不睦，一生不得发达。

**白话直译：** 男女的命身及福德迁移都不宜坐守七杀。如果命入七杀位于朝斗仰斗之地而合局入格，男子固然可以富贵一时，但终究不美（如袁世凯就是正宗七杀朝斗格，暴毙于五十八岁）。而不入格的更不美，无煞冲合则主性情怪僻、刚愎自用、厚己苛人，终遭灾悔突然降临。有煞交会的则主贫贱孤寡，也主奸佞张狂，与人不睦，一生不得发达。

**深度解读：** 七杀是一把双刃剑：

+ **七杀朝斗格**（七杀在寅申庙旺 + 紫微在对宫朝照）→ 可富贵一时
+ **但终必不美** → 袁世凯就是典型（正宗七杀朝斗格，暴殁于58岁）
+ **不入格的七杀坐命** → 性情怪僻、刚愎自用、贫贱孤寡

**实操要点：** 七杀坐命的人，即使格局好也要提醒"盛极必衰"的道理，注意人生高峰后的急转直下。

### 2_8 男命与女命的"要宫"差异

> **原文：** 男性之要宫，为命、身、财、官、迁、福、妻、仆、兄弟其九宫，惟以命、身、财、官、迁、福六宫为最要。女性者以命、身、福、夫妻、子女、父母、兄弟为着重，但以命、身、福、夫四宫为至要。

**白话直译：** 男性的重要宫位，是命身财官迁福妻仆兄弟这九宫，但其中以命身财官迁福六宫为最重要。女性以命身福夫妻子女父母兄弟为着重，但以命身福夫四宫为至要。

**深度解读：**

|  | 男性重点宫位 | 女性重点宫位 |
| --- | --- | --- |
| 核心要宫 | 命、身、财、官、迁、福（六宫） | 命、身、福、夫妻（四宫） |
| 延伸宫位 | 妻、仆、兄弟 | 子女、父母、兄弟 |

**实操要点：** 看女命时，夫妻宫的权重极高，仅次于命身福三宫。而男命更看重事业线（官禄+迁移+财帛）。

### 2_9 昌曲魁钺的才华判断

> **原文：** 观其人有否才识之福，则看命身是否俱见昌曲魁钺，最喜四宿皆得，见一二仅主聪敏而已。昌曲之魁钺守照命身，须观有无四煞冲破，乃至其地生克如何。盖凡遭煞刑或遇地克，则文星受害，多无实学之有，反主其人矫虚狡诈，善嫉好妒反复无常矣。

**白话直译：** 看一个人有没有才识之福，要看命身是否都见到昌曲魁钺，最喜欢四宿都得到，只见到一二颗仅主聪明而已。昌曲魁钺守照命身，必须观察有无四煞冲破，以及地支生克如何。凡是遭到煞刑或遇到地克，文星受害，多无实学，反而主其人矫虚狡诈，善嫉好妒反复无常。

**深度解读：**

+ 文昌+文曲+天魁+天钺 **四星全见** → 才华横溢、才识过人
+ 仅见1-2颗 → 聪明而已，不算大才
+ 昌曲遇煞冲破 → 文星受害，反而主矫虚狡诈、善妒反复

### 2_10 武贪火铃的特殊格局

> **原文：** 命逢武贪火铃于庙旺而无空劫刑囚耗忌之交会，男主军旅成功，富贵兼享，女则代夫行权，亦主才识双美，志胜须眉。

**白话直译：** 命宫遇到武曲贪狼火星铃星在庙旺之地，而没有空劫刑囚耗忌的交会，男子主在军旅中成功，富贵兼享；女子则代夫行权，也主才识双美，志向胜过男子。

**深度解读：** 武曲贪狼火星铃星都是"刚猛"之星，在庙旺时反而能成大事——适合军警、武职、高风险高回报行业。

## 板块3 · 网络补充：现代命盘分析框架

### 3_1 命盘分析的"六宫检验法"

根据《观音经验谈》的逻辑，现代看盘可以归纳为：

```plain
第一步：命宫（先天基因）
  ├─ 主星是什么？庙旺or落陷？
  ├─ 有无煞星同宫？
  └─ 空宫则借对宫

第二步：身宫（后天走向）
  ├─ 与命宫配合如何？
  └─ 有无吉凶星曜？

第三步：财帛宫（财富能力）
  ├─ 主星吉凶？
  └─ 与官禄宫比较 → 富or贵or双全？

第四步：官禄宫（事业成就）
  ├─ 主星吉凶？
  └─ 有无化禄化权？

第五步：迁移宫（外出运势）
  ├─ 吉星→外出顺利
  └─ 煞星→出门多咎

第六步：福德宫（精神福气）
  ├─ 吉星→福厚德深
  └─ 煞星→福薄德浅

```
