## 板块8 · 化曜与神煞：后天叠加层的加法与减法

> **本板块的位置**：前面七个板块处理的是"先天层"——星曜本体、庙旺、恩难。板块 8 叠加"后天层"：十干化曜与神煞。
>
> 这一层最容易被滥用，所以本板块的原则是**加法与减法并行**：化曜要认真加，神煞要敢于删。

### 8_1 十干化曜：天干给星曜"换身份"

同一颗星曜，在不同年干（或日干）下会**转换为另一套身份与性情**——这是天官派区别于一般星命书的独到之处，也是《乾元秘旨》"变五行"的核心。

**核心口诀（十干化曜歌，《果老星宗》系）**：

```latex
甲火乙孛丙属木，丁是金星戊土求；
己人太阴庚是水，辛气壬计癸中罗；
十干化曜须牢记，气孛罗计四余游；
七政四余同参断，吉凶祸福此中求。

```

**完整对应表（化曜星 + 变曜名 + 十神 + 吉凶 + 所主）**：

| --- | --- | --- | --- | --- | --- |
| 甲 | 火星 | 天禄 | 比肩 | 吉（禄） | 官禄 |
| 乙 | 月孛 | 天暗 | 劫财 / 阳刃 | 凶（暗） | 相貌 |
| 丙 | 木星 | 天福 | 食神 | 吉（福） | 财帛、福德、迁移 |

### 8_2 阴阳翻转：为什么同一颗曜有时吉有时凶

变曜吉凶遵循"**阳干从正、阴干从反**"：

+ **五阳干（甲丙戊庚壬）**：以正财为荫、劫财为权；
+ **五阴干（乙丁己辛癸）**：相反——"阴柔不能主事，要依赖劫财的阳性来做决断"。

《星学大成》卷一的精要说明：

> 化暗者，五阳干皆是阳刃，五阴干皆是其伤官；

化耗者，五阳干皆是伤官，五阴干皆是正财；
化印者，五阳干皆是正官，五阴干皆是正印；
化权者，五阳干皆是正印，五阴干皆是比肩。

**《乾元秘旨》的补充**：五阳各与正财合、五阴各与正官合——"**戊甲丙庚壬为五阳，五阳各与正财合；癸辛丁乙己为五阴，五阴各与正官合**"，以此见"合之为义大，而化禄之体精用博"。并有"**化禄之合，适以相成；化禄之冲，实以相亏**"——把天干合化与宫位冲合纳入同一框架。

> ▲实操：解盘时把十干化曜当成"第二层五行"叠加。举例：甲年生人，火星化"天禄"入官禄——若火星庙旺且与命度主相生，则"官禄有禄"之象成立；若火星陷弱又化禄，则是"禄而无实"。
>
> **化曜不改写星曜力量，只改写它的"社会身份"。**

### 8_4 神煞的减法：舒继英最值得学的一笔

这是《乾元秘旨》全书最具现代理性色彩的部分，也是方法论层面最该被继承的遗产。

**舒继英明确削除的神煞**：卦气、斗柄、贵人、文昌、马元、禄元、寿元、的杀、阴杀、大杀、天雄、地雌、大耗、小耗等——理由是"**按之于命十不一验，故并削之**"。

**对"催官、科甲"二名的批判**（尤为尖锐）：

> "既曰催官，何以甲年人官在，而催官乃在金？直伤官矣，漫云催乎？"
>
> 果老云"与元禄相催克"——与元禄**相催**谓之催官可也，与元禄**相克**亦谓之催官，则紊乱不可从。

**这一"减法原则"的普适价值**：星命推断应抓住**七政四余、正变五行、日月限度**三大主干，"穿凿支离"的神煞体系当果断舍弃，否则"用之则顾此失彼，殊为紊乱"。**先立主干，再议枝叶**——这条原则对任何研习传统术数者都适用。

> ⚠避坑：《星学大成》采取的是相反路线——"鸠集众说，多术家不传之本"，三十卷包罗万象，四库馆臣也批评其"所录驳杂""有芳有秽"。**两书定位不同**：《星学大成》是**资料库**，《乾元秘旨》是**方法论**。用《星学大成》查资料，用《乾元秘旨》学取舍。

### 8_7 琴堂虚实：空亡的完整判读

琴堂派以"空亡"为最要，主张**身命二星须逢生曜、坐实地、占高强之地**。

> 琴堂之法独取空，**坐实逢生主高强**。旬空之地莫安身，四柱填实则荣昌。

**空亡三种形态**（《星学大成·杂诗》空亡三诀）：

| 类型 | 判断标准 | 吉凶 |
| --- | --- | --- |
| **真空** | 无拱夹、无贴衬，孤零零 | 凶（真没有） |
| **假空** | 有拱夹、有贴衬 | 吉（看似空实则满，"空处不空"） |
| **冲空** | 空亡被流年冲实 | 凶（空被填满反坏事） |

**四条核心口诀**：

1. "**空处不空分拱夹，更将贴衬有无推**"——空不空，看左右邻居；
2. "**用宿若空冲得实，凶星空了怕冲来**"——用神落空被冲实反为祸，凶星落空是好事但怕被冲出；
3. "**不空不实名来局**"——不空也不算真有，要看是否成局；
4. "**流旬空法有神通，此法名为御史空**"——流年旬空一到，纵有吉星居贵地也"欠从容"。

**空亡对十二宫的影响**（据窦陶氏答与杂诗整理，各本异文较多，宜以所习流派为准）：

| 宫位 / 星神 | 遇空亡之象 |
| --- | --- |
| 马（驿马）遇空 | 奔波无成，走动而无所获 |
| 禄遇空 | 禄薄，有名而实不足 |
| 贵人遇空 | 虽有若无，助力落不到实处 |
| 财帛遇空 | 财来财去，虚花不聚 |
| 官禄遇空 | 虚名，或职轻权责不符 |
| 田宅遇空 | 居处不定，或与祖基缘薄 |
| 妻妾遇空 | 缘分偏薄，或相处疏淡 |
| 男女遇空 | 子息偏迟，或互动较少 |
| 疾厄遇空 | 凶煞遇空反减凶（此为特例） |
| 相貌遇空 | 外缘淡泊，不重形迹 |

> **总原则**：**吉神遇空则减力，凶煞遇空则减凶。** 这是判断空亡吉凶的第一原则——空亡本身不分吉凶，分吉凶的是"落在空里的是谁"。
>
> ▲实操：空亡的判读顺序 —— 先定是否旬空 → 再看有无拱夹贴衬（真空 vs 假空）→ 最后看流年是否冲实（冲空）。**三步走完才敢说"这个宫到底有没有"。**

### 8_8 小故事：两份简历，同一颗金星

#### 古人的两组对照命例

《乾元秘旨》给出两组对照命例，是训练"活看"能力的最佳教材。

**案例一**：一甲年四月生人与一壬年二月生人，**同行戌宫奎木度、奎木上同坐金星**。

+ 甲生人：以金为**伤官** → 仕途屡跌；
+ 壬年人：以金为**正财** → 官级联升。

**案例二**：一辛年十一月生人与一辛年十月生人，**同行丑宫斗木度（度为天官）**。

+ 十一月生人：正财火星在斗、太阳在尾火度，**与太阳通** → 即入翰林；
+ 十月生人：正财火星在箕、太阳虽在尾而**火度与太阳不通** → 仅中进士。

```latex
同一颗星、同一度数，只因年干不同：

  甲年生：金 = 伤官  ──►  克官  ──►  仕途屡跌
  壬年生：金 = 正财  ──►  生官  ──►  官级联升

  差别不在"金在不在度上"，而在"金对这个人是什么身份"

```

#### 一次自己的验证

有位研习者读完这两组案例后，心里其实是不太信的——"真的只差一个年干，就能差这么多？"于是他回头翻自己存的两张盘，恰好找出一对可作对照：两人出生时间相近，**金星同宫同度**，但年干不同。

他当时的记录是这样的：

| 项目 | A | B |
| --- | --- | --- |
| 金星落点 | 同宫同度 | 同宫同度（完全一致） |
| 年干 | 甲 | 壬 |
| 金在盘中的十神身份 | 伤官（克官） | 正财（生官） |
| 与官禄主的关系 | 相克 | 相生 |
| 金星自身评分 | 庙旺 + 得令 ≈ +5 | 庙旺 + 得令 ≈ +5（几乎一样） |
| 实际职业轨迹 | 两次主动离职，职称长期未解决 | 平稳升迁，职务逐步落实 |

关键是最后两行的对照：**两颗金星自身的强弱几乎完全一样**（同样的宫、同样的度、同样的庙旺与得令），真正的分岔只发生在"这颗金星在各自命局里算什么身份"这一层。

他在笔记里写了一句总结：**"看星是看它有多强，看化曜是看它对你是谁。两件事。"**

后来他把这条经验写进了自己的批盘流程，位置在"评分"之后、"下断语"之前——先算力量，再叠加身份，两步分开做。

#### 这个故事的四条教训

1. **力量与身份是两层**：庙旺评分告诉你"它有多强"，十干化曜告诉你"它对你是谁"。合起来才敢下断语。
2. **"通"与"不通"比"有与没有"更重要**——火星在不在度上是一回事，与太阳通不通气是另一回事（见案例二）。
3. **遇到古代案例，最好的态度是拿自己的盘去验证它**。验证通过的，写进流程；验证不过的，记进困惑清单。
4. 结论仍是那句：**"移步换形，不可胶柱鼓瑟。"**

### 8_9 笔记方法：化曜叠加三步与神煞"保留清单"

> ▲实操：化曜叠加三步
>
> 1. **定干**：确定年干（主）与日干（辅），两干都写进盘面；
> 2. **换身份**：把化曜星对应的变曜名标到该星旁边（如甲年 → 火星 = 天禄）；
> 3. **判虚实**：看这颗化曜星本身庙旺与否 —— 庙旺则"禄有实"，陷弱则"禄而无实"。
>
> ⚠ 记住：**化曜不改写力量，只改写身份**。先算力量，再叠加身份。

> ▲实操：给自己的盘建一份"神煞保留清单"，规则如下：
>
> + 清单**不超过十项**；
> + 每一项都要写明"为什么保留"（哪一条实务经验支持）；
> + 凡与星曜本体结论冲突者，**一律弃用并注明弃用理由**。
>
> 这份清单写一次，长期沿用。它的价值不在"选对了哪些"，而在**逼你为每一个保留项给出理由**。

### 8_10 本板块小结

+ 十干化曜是**第二层五行**，改写星曜的"社会身份"而非力量；
+ 阴阳翻转（阳干从正、阴干从反）解释了"同一颗曜有时吉有时凶"；
+ 舒继英的**减法原则**：主干是七政四余、正变五行、日月限度，神煞当删则删；
+ 神煞保留**控制在十项以内**，与星曜结论冲突者弃用；
+ 空亡总原则：**吉神遇空减力、凶煞遇空减凶**；三步判读：是否旬空 → 有无拱夹贴衬 → 是否冲实。
