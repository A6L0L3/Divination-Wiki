## 板块3 · 二十八宿与躔度喜忌：全书最核心的查表数据

> **本板块的位置**：板块 2 解决"每颗星是什么脾气"，板块 3 解决"它落在哪一宿、哪一度、状态是好是坏"。

### 3_1 二十八宿是什么：四象七宿的恒星坐标尺

二十八宿是中国古代的恒星参照系，把黄道（及赤道附近）划分为二十八个不等宽的星区，分属四象：

| 四象 | 七宿 | 五行倾向 |
| --- | --- | --- |
| 东方青龙 | 角、亢、氐、房、心、尾、箕 | 木 |
| 北方玄武 | 斗、牛、女、虚、危、室、壁 | 水 |
| 西方白虎 | 奎、娄、胃、昴、毕、觜、参 | 金 |
| 南方朱雀 | 井、鬼、柳、星、张、翼、轸 | 火 |

每一宿都有自己的**主星与五行**（角木蛟属木、亢金龙属金、氐土貉属土、房日兔属日、心月狐属月、尾火虎属火、箕水豹属水——**每象七宿皆按"木、金、土、日、月、火、水"同序循环**：角木蛟 → 木、亢金龙 → 金、氐土貉 → 土、房日兔 → 日、心月狐 → 月、尾火虎 → 火、箕水豹 → 水；其余三方七宿同序循环——北方：斗木獬 → 木、牛金牛 → 金、女土蝠 → 土、虚日鼠 → 日、危月燕 → 月、室火猪 → 火、壁水貐 → 水；西方：奎木狼 → 木、娄金狗 → 金、胃土雉 → 土、昴日鸡 → 日、毕月乌 → 月、觜火猴 → 火、参水猿 → 水；南方：井木犴 → 木、鬼金羊 → 金、柳土獐 → 土、星日马 → 日、张月鹿 → 月、翼火蛇 → 火、轸水蚓 → 水），这决定了**度主**——即"命度落在这一宿，就以该宿五行之星为度主"。

> **为什么宿度如此重要**：宫是约 30 度的粗略区间，宿是恒星背景，度是精确落点。本体系"以度为主"，宿度精度直接决定论断可靠性。"度数错则全盘皆错"，说的就是这一层。

### 3_5 断躔位全表：本知识库唯一权威罗列处

**断躔**指星曜行至该宿度时能量断绝，即使坐庙旺也大打折扣，如人被断了粮草。

| 星曜 | 断躔之宿度 |
| --- | --- |
| 太阳 | 毕 9° |
| 太阴 | 氐 6° |
| 木星 | 亢（全宿）、昴 4° |
| 火星 | 昴 / 毕 17° |
| 土星 | 奎 17° |
| 金星 | 房（全宿）、奎 7°、娄 2° |
| 水星 | 奎 17°、胃 2°、柳（全宿） |
| 紫炁 | 昴、亢 |
| 月孛 | 角 5°、奎 17°、娄 |
| 罗睺 | 毕 3°、壁 7° |
| 计都 | 奎、井、心房、箕 |

> ▲实操：扫断躔口诀（便于记忆与逐曜核对）
>
> 拿到盘后**第一件事不是看庙旺，而是扫一遍有没有星落在断躔度**。断躔是"打折符"，不是"加分项"——它不会让凶星变吉，只会让好星变虚。

### 3_6 小故事：被"断躔"改写的那一年

阿岚在年初给自己推流年，判断是："今年行金度，金星在我盘上入庙，又是我的恩星，应该是顺遂的一年。"

结果那一年她换了两次工作，中间还住了一次院。年末回看，她一度以为自己整套方法都错了。

后来她做了一次逐层回溯，把失误定位到了具体环节：

| 回溯层 | 有没有错 | 结论 |
| --- | --- | --- |
| 排盘层（真太阳时、命宫命度） | 没错 | 盘是对的 |
| 庙旺层（金星是否入庙） | 没错 | 确实入庙 |
| **断躔层** | **漏了** | 那一年行到的几度，压在金星断躔区间里 |
| 行限层（太岁作用） | **漏了** | 太岁冲了她的限宫，属"冲动则生变" |

三层叠加后，正确的结论从"顺遂的一年"，改成了"**有名无实的顺遂年，且伴随一次结构性变动**"。

她在复盘表"失误原因"那一栏只写了六个字：**"没扫断躔就断。"**

但故事还有后半段。第二年她又推了一次，这回她先把断躔扫了一遍，发现当年行到的度上有余奴划过——她按"划度"提示写成"关口年，宜守成"。那一年确实平稳，但她后来说：**"平稳不是因为我算得准，是因为我提前把那一年的预期调低了，做事就谨慎了。"**

**这个故事的四条教训**：

1. 庙旺是**静态分数**，断躔是**动态折扣**，行限是**兑现时机**。三者是乘法关系，不是加法；
2. 复盘时按"排盘 → 庙旺 → 断躔 → 行限"的顺序找错，八成能找到漏在哪一层；
3. 一次漏检不致命，致命的是**不知道自己漏在哪一层**；
4. 断语的价值一部分在于**调整预期**——把"关口年"讲清楚，本身就是有用的。

### 3_7 笔记方法：宿度批注三步与"扫断躔"硬规矩

> ▲实操：拿到一张新盘，按三步批注宿度：
>
> 1. **标宿度**：把十一曜的"宫 + 宿 + 度"全写出来（不要只写宫）；
> 2. **查状态**：对照 3_3 大表，标出每颗星的庙旺乐喜平闲陷怒困忌；
> 3. **扫断躔**：对照 3_5 全表逐曜核对，命中者用红笔圈出并注明"×0.5"。
>
> 三步走完，再进入能量分级（板块 6）。

> ▲实操：给自己定一条硬规矩——**任何一颗星，不查断躔就不许写"庙旺有力"这五个字**。这条规矩执行三个月，解盘准确率会有肉眼可见的变化。

### 3_8 本板块小结

+ 二十八宿是**恒星坐标尺**，宿度决定度主，是"以度为主"的落点；
+ 3_3 大表是本知识库最核心的查表数据，已整合各曜全部二十八宿状态，建议打印；
+ 状态术语有轻重之分：庙殿最强，忌恶断漂埋最凶，晦为月之无光；
+ **3_5 是断躔位的唯一罗列处**，批盘时在此查对；
+ 批盘三步：标宿度 → 查状态 → 扫断躔。
