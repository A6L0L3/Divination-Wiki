## 板块7 · 恩用仇难：满盘敌友一张图

> **本板块的位置**：板块 6 给出的是每颗星力量的**绝对值**；但七政四余真正的核心是**关系值**——同一颗金星，对甲是仇星，对乙可能完全无害。
>
> 关系的圆心只有一个：**命度主**。命度主一变，满盘敌友全换。

### 7_1 四字定义：一切围绕"命度主"展开

**命度主一变，满盘敌友全换——这是七政四余的命根子。**

| 角色 | 定义 | 人事象征 | 论断要点 |
| --- | --- | --- | --- |
| **恩星** | **生**命度主者 | 贵人、滋养、逢凶化吉 | 恩星守命或落三方四正，主得扶持、顺遂 |
| **用星** | 与命度主**同五行**（比和） | 自身能力的强化、同类帮扶 | 强旺则根基稳、本事硬 |
| **仇星** | **克**命度主者（明面的克） | 阻碍、竞争、压制 | 看是否有制化 |
| **难星** | **克恩星**者（砍你的救命绳） | 暗算、背后使绊 | 最精微，亦最易被忽略 |

**举例**（命度主为木）：

+ 恩星：水星、月孛（水生木）
+ 用星：木星、紫炁（同属木）
+ 仇星：金星（金克木）
+ 难星：土星、计都（土克水孛，即克恩星）

> **仇 vs 难的精髓**：仇星是"明敌"，当面跟你过不去；难星是"暗算"，不冲你来，专砍你的救命绳。
>
> 古诀云"**恩难较切，尚可兼观；仇用更宽，不妨偏废**"——《乾元秘旨》主张重恩难、轻仇用。实务中不必被四组关系同时牵制，**先抓恩与难这组主要矛盾**。

---

### 7_2 恩难判读的三条活法

**活法一：恩难并行时看"化"。**
化难生恩，则难从恩论；仇来破恩生难，则恩从难论。**须先于身命二主星所躔定其轻重**——同样是"难星在旁"，落在身命主所躔之度与落在闲宫，轻重天差地别。

**活法二：吉断的条件。**
**恩星司令、阳星昼现、阴曜夜逢**，又躔生旺之乡，朗照身命田财官福 → 以吉断，**虽有难星不为我害**。

**活法三：凶断的条件。**
**难星司令、阴星昼现、阳曜夜逢**，又躔刃煞之乡，侵犯身命田财官福 → 以凶断，**虽有恩星不为我福**。

> **两条补充原则**（《乾元秘旨》精华）：
>
> 1. "煞忌党，其刚凶多验；于刃兼之，**气尽则身尽，官竭则命竭**"——倒限不都因难星，天官严重受克无气之限度亦会倒限；
> 2. "引从者吉则外贵乎空，挈提者凶则内喜乎善；**吉凶扶阳势，余奴亦足敌杀**"——吉星伴太阳则得力而吉，凶星伴太阳则得力而凶；难星克命时，余奴星相伴反能护卫命主。**得意的运势不一定都来自恩星。**

### 7_3 尽三法：三步断命的标准流程

**第一步：看命宫及其三方四正。**
本宫 + 对宫 + 与本宫三合的两个宫，共四个宫位。先看命宫有什么星，再看三方四正有什么星。

**第二步：看命主星与身度主星。**
看命度主星、身度主星**所落宫位的**三方四正。命度主代表"我"的本质，身度主代表"我"的后天状态。

**第三步：看月身。**
看月亮这颗星，及其所落宫位的三方四正。月主情绪、体质、后天福气。

**星体先后见规则**（决定"谁作用谁"）：

1. 先见第一步的星体 → 后见第二步 → 再后见第三步 → 最后见命身度上所落的星体；
2. 每一步内：**先本宫 → 后对宫 → 再三合宫**；
3. 同一宫位内：**度数大者为先见，度数小者为后见**；
4. 基础规则：**后见的星体作用于先见的星体，先见者不作用于后见者**。

> ⚠避坑：这条"先后见"规则是七政四余独有的精细设定，多数教程不讲。忽略它，会把"甲星克乙星"的方向搞反——**方向一反，吉凶全反**。

```latex
先后见顺序示意：

  [第一步] 命宫三方四正之星        ← 最先见
       │
       ▼
  [第二步] 命主星 / 身度主星所在宫之星
       │
       ▼
  [第三步] 月亮及其所在宫之星
       │
       ▼
  [最后]  命身度上所落之星          ← 最后见

  作用方向：后见 ──► 作用于 ──► 先见

```

### 7_4 三方四正与合冲拱夹

| 关系 | 定义 | 断法 |
| --- | --- | --- |
| **三合（三方）** | 与本宫成 120° 的两宫 | 吉星三合，力量倍增 |
| **对冲（四正）** | 与本宫成 180° 的宫 | 凶星对冲，灾祸立见 |
| **拱** | 星在命宫左右各一宫，成拱卫之势 | 日月拱命、金水拱驾为吉 |
| **夹** | 星紧贴命宫两侧 | 金水夹月、火罗夹日，吉凶视星性 |

> 口诀：**"三方拱照互为用，四正冲破皆相攻。三合得吉增福力，对冲见煞祸难容。"**

**宫位互动六法则**：

1. 命身喜在三方见吉星；
2. 官福贵登四正之宫；
3. 对宫引动本宫——对宫之星会"射"入本宫；
4. 空宫借对宫；
5. 飞星穿度——流年星"穿"过某度时，该度主星被引动；
6. 强弱宫之分——强宫放大、弱宫衰减（见板块 5_2）。

### 7_5 余奴犯主：暗线危机的识别与化解

四余是七政的"奴"，余奴与主星争地盘即"犯主"：

| 相犯方式 | 表现 | 凶性 |
| --- | --- | --- |
| **同宫同度** | 主奴同躔一宿度（如木气同在奎度） | 最典型，"争座位"之象 |
| **同宫前后** | 主奴同宫不同度（如"孛前水后"） | 看先后定轻重 |
| **三方 / 对宫** | 主奴在三合或对冲宫呼应（如土在寅、计在戌） | 较隐晦，行限时方显 |

**成立条件**：余奴与正星须同宫同度（或极近），**且正星非庙旺状态**。正星庙旺有力，则余奴犯主之力大减。

**人事象征与四组典型**：

| 组合 | 象征 |
| --- | --- |
| 月孛犯太阴 | "替代品"——副职多年不转正、感情中总有影子 |
| 罗睺犯火星 | 冲动加倍，亦易出急智型人才 |
| 紫炁犯木星 | 清高变孤僻、仁德变迂腐 |
| 计都犯土星 | 阻滞变顽固、稳重变迟钝 |

**化解之法**（以木度被紫炁犯为例）：

1. 同度有**水星 / 月孛** → 水生木，主星得救，凶减；
2. 同度有**金星** → 金克木（制气），奴星被制，凶化；
3. 主星得令、根基强实 → "奴主相扶"反可转吉。

> **"划度"是生死关口**：行限走到主星之度时，余星恰好划过此度（"限至木度，谓之余奴犯主"），往往对应重大转折乃至生死关口，须特别警惕（详见板块 10_6）。
>
> ⚠避坑：倒限、划度之说属古代术数推演，**绝不可用于任何现实的健康与生死决策**，宜读作"风险升高的阶段提示"。

### 7_6 制化通关：把相克变成相生

> **通关法**：仇星为金克我木，若得**水星**通关，则金生水、水生木，**化凶为吉**。

**《乾元秘旨》的"正五行辩证"**——旺与制的互相转化：

> 木正旺则畏金，太旺又借金以成其器；火正旺则怯于水孛，太旺又借水孛以杀其威；土、金、水各如其例。

即：**弱时怕克，旺时反喜克**。这是"不可胶柱鼓瑟"在生克层面的具体体现。

```latex
通关示意：

  金（仇）──克──► 木（我）
      │
      └─ 若有水 ──► 金生水 ──► 水生木  ──►  化克为生

  前提：水星有力（不能被土计克死），否则通关不成

```

### 7_8 小故事：救命绳被砍的那三年

阿哲复盘自己最低谷的一段时期。那三年他换了行业、搬了两次家、几段关系也散了。事后看盘，问题出在一条很清楚的链上：

```latex
命度主：水星
恩星（救命绳）：金星 —— 原本在三方拱照，是他一路走来最大的助力
难星：火星、罗睺 —— 火克金，专砍他的救命绳

那三年行限走到了火星之度：
  火星被引动 → 克金 → 恩星失力 → 水星（我）失去滋养

```

更麻烦的是，那几年流年太岁又填到了难星上，属于"填凶则凶"。

他后来总结了一句很准确的话：**"那几年不是我变差了，是原本托着我的那只手突然抽走了。"**

这句话里藏着一个关键区分——**仇星**和**难星**不是一回事：

| 类型 | 作用方式 | 他的体会 |
| --- | --- | --- |
| 仇星（明敌） | 直接克你 | "有对手、有压力，但我知道自己该防谁" |
| 难星（暗算） | 克你的恩星 | "说不出哪里不对，就是什么都不顺了" |

他的低谷属于后者，所以特别难受：**不是被打了一下，是支撑没了。**

而转机出现在行限走出火星之度、进入金星之度之后——恩星重新当道，事情开始慢慢回来。有意思的是，转机的起点不是"凶星走完"的那一刻，而是"恩星之度开始"的那一年，两者差了一段时间。

**这个故事的四个要点**：

1. **难星不是直接害你，是害你的恩星**。所以"没有恩星"和"恩星被克"是两回事，后者更隐蔽也更致命；
2. 判断一条链的走势，要按"**行限 → 限主 → 限主与恩难的关系**"推，不能只看静态盘；
3. 转机往往不在"凶星走完"，而在"**恩星之度开始**"——两者的时间点不是同一个；
4. 复盘时把"最该防的是谁"写成一句话，比写十句吉凶断语有用。他写在图上那句是："**我的救命绳是金，最该防的是火罗，转机在水度。**"

### 7_9 笔记方法：敌友图的三个检查动作

> ▲实操：画完敌友图后，强制做三个检查动作：
>
> 1. **救命绳检查**：恩星有没有被难星克？有通关星吗？
> 2. **暗线检查**：有没有余奴犯主？同度还是三方？解救者是谁？
> 3. **方向检查**：先后见顺序排了吗？谁作用于谁？
>
> 三个动作做完，才在图上写那句"我的救命绳是____，最该防的是____，转机在____"。
>
> 这张图建议每盘一张、编号存档。做满二十张后，你会发现自己的读盘速度明显变快——因为你已经有了"模式识别"的库存。

### 7_10 本板块小结

+ 四角色全部围绕**命度主**展开，命度主一变，满盘敌友全换；
+ **仇是明敌、难是暗算**，重恩难、轻仇用；
+ 先后见规则决定作用方向，**方向反则吉凶反**；
+ 余奴犯主有三解：生主、制奴、主星自强；
+ 通关法能把相克变**相生**，前提是通关星自身有力。
