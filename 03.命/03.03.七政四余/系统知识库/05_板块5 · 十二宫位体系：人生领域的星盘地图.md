# 板块5 · 十二宫位体系：人生领域的星盘地图

> **本板块的位置**：盘排好（板块 4）之后，第一件事不是急着看吉凶，而是先给十二个"人生领域"定位。
>
> 宫位是本体系的**舞台**：同一颗星，站在官禄宫与站在奴仆宫，说的话完全不同。

## 5_1 十二宫含义与解读抓手

| 宫序 | 宫名 | 人生领域 | 判断抓手（看什么） |
| --- | --- | --- | --- |
| 1 | **命宫** | 性格、天赋、容貌、一生格局根基 | 命宫主星 + 命度主星（全盘分析原点） |

| 5 | **男女** | 子女缘分、创造力、投资运 | 宫主与太阴（母星）关系 |

## 5_2 七强五弱：吉星要落强宫，凶星宜落弱宫

古籍有两种分法，实质一致，可合并理解：

| 强弱等级 | 宫位 | 实务含义 |
| --- | --- | --- |
| **四正高强** | 命宫、官禄、田宅、夫妻 | 吉星落此，力量倍增；凶星落此，为祸亦烈 |
| **次强 / 近强** | 男女、福德、财帛（迁移为近强） | 吉星落此主福，凶星落此减凶 |
| **次弱** | 兄弟、闲极、疾厄、游行（迁移） | 吉星落此打折 |
| **恶弱 / 陷害宫** | 奴仆、相貌 | 最下之品，吉星落此几近无用 |

```latex
力量放大 / 衰减示意：

  强宫（命、官、田、妻）   ──►  吉星 ×1.5，凶星 ×1.5
  次强（男、福、财）       ──►  吉星 ×1.2，凶星 ×0.8
  次弱（兄、疾、迁）       ──►  吉星 ×0.8
  恶弱（奴、相）           ──►  吉星 ×0.3（几近无用）

```

> ▲实操用法：**强宫是"放大器"，弱宫是"衰减器"。** 恩星落强宫＝贵人得力；恩星落奴仆相貌＝有力使不上。反过来，凶星落恶弱宫，凶性大减——这是"凶星在弱宫反不为大害"的实务依据。

> ⚠避坑（重要特例）：《星学大成》指出"凡星辰加居闲极，为弱，**惟太阴临之为福**"——太阴喜居第三闲极宫，反主添福德，是唯一例外，须记住。

## 5_3 度主为经、宫主为纬：不二法门

+ **度主**（经）：命度所属宿度的五行之星 → 主**内在本质、能力内核**；
+ **宫主**（纬）：命宫地支所属之星 → 主**外在处境、表现形式**。

**当宫主与度主不一致时（绝大多数情况如此），以度主为先。** 理由很简单：度主精确到度，宫主只精确到宫。

```latex
解一宫的三层顺序：

  第一层：度主是谁？（精确到度，断内在本质）
      │
      ▼
  第二层：宫主是谁？（精确到宫，断外在处境）
      │
      ▼
  第三层：宫里住了谁？（宫内星曜，断具体事件与人事）

```

> ▲实操：解任何一宫，都按"**先度主、后宫主、再看宫内所住之星**"的三层顺序。跳过第一层直接看宫主，是解盘失准的第二大原因（第一大是没校真太阳时）。

## 5_4 一宫多象：同一宫可从多个星曜角度读

这是七政四余比八字更细腻之处：

| 议题 | 第一视角 | 第二视角 | 第三视角 |
| --- | --- | --- | --- |
| **父亲** | 太阳（主） | 田宅宫主星 | 日之恩难 |
| **母亲** | 太阴（主） | 田宅宫兼看 | 月之拱夹 |
| **妻子（男命）** | 太阴 | 夫妻宫主 | 金星（财与妻同源） |
| **丈夫（女命）** | 太阳 | 夫妻宫主 | — |
| **健康** | 疾厄宫主 | 火星（血光、急性）、土计（慢性、沉疴） | 命度主受克情况 |
| **子女** | 男女宫主 | 太阴（母星） | 宫主与太阴生克 |

> ⚠避坑：一宫多象不等于"随便挑一个讲得通的"。正统做法是**多视角互参后取交集**——父亲看太阳与田宅主，若二者一致（皆旺 / 皆衰）则断语坚定；若矛盾，则以太阳为主、田宅为辅，并如实说明"两象不一，主亲子缘分存在张力"。

## 5_5 宫位互参：六组对冲与三组联动

**六组对冲（四正）**：

| 对冲 | 含义 |
| --- | --- |
| 命宫 ↔ 官禄 | 自我与事业的冲突 / 呼应 |
| 财帛 ↔ 福德 | 财富与福气的矛盾 / 互补 |
| 兄弟 ↔ 迁移 | 手足与远行的牵扯 |
| 田宅 ↔ 疾厄 | 家宅与健康的关联 |
| 男女 ↔ 奴仆 | 子嗣与下属的互动 |
| 夫妻 ↔ 相貌 | 婚姻与父母的联系 |

**三组常用联动**：

1. **财官互参**：财帛与官禄同看，断富贵层次；
2. **田迁互参**：田宅与迁移对冲，断定居 vs 远行；
3. **命身互参**：命宫与身宫（太阴宫）是否相生、是否互垣。

> ▲实操：每次解盘至少做一组"互参"。单看一宫容易得出片面的结论，一组的对照能把"这人如何"变成"这人在什么张力下如何"。

## 5_6 空宫借对宫：命宫无星怎么办

命宫无主星时，**借对宫（第七宫）之星来看**——此与紫微斗数同理。

> ▲实操：

```latex
命宫空
  │
  ├─ 第一步：借对宫（夫妻宫）—— 看里面住了谁
  │
  ├─ 第二步：对宫也无 —— 退看三方（三合宫）
  │
  └─ 第三步：三方也无 —— 专看命度主落何处、状态如何
                           ↑
             命度主永远是你的最后锚点，它不会因为命宫空而失效

```

## 5_7 小故事：被"宫位"救回来的一句话

小林刚学到"十二宫"那一周，给朋友看盘。他看到朋友的**官禄宫主落陷**，就脱口而出："你事业上大概不太顺。"

朋友愣了一下，说："还行吧，我去年刚升了职。"

这句话让小林很受挫。他回去把那张盘重新拆了一遍，发现问题出在**他只看了一层**：

| 层次 | 看到的事实 | 他的处理 |
| --- | --- | --- |
| 宫主层（外在处境） | 官禄宫主落陷 | 他只看了这一层，就下了结论 |
| 度主层（内在本质） | 官禄宫的度主庙旺，且与命度主相生 | **漏了** |
| 行限层（兑现时机） | 那年正走在官禄主的三合限，属"官星填起" | **漏了** |

三层合起来，正确的说法应该是：

> **"你的事业底盘不算厚（宫主落陷），但你本人的专业能力是被撑住的（度主庙旺且与命度主相生），所以早期要靠硬本事吃饭，遇到对的年份（官星填起）会有一次明显的跃升。"**

同一张盘，从"不太顺"变成"底盘薄但能力硬、有跃升窗口"——信息量翻了几倍，而且说中了。

朋友听完补充了一句很关键的反馈："对，我确实一直是靠技术吃饭，管理上一直不太顺手。"这句话反过来印证了"宫主落陷＝外在处境（职位、平台）确实有短板"这一层。

**这个故事的三条教训**：

1. 一宫要解三层：**度主（本质）→ 宫主（处境）→ 宫内星（事件）**；
2. 断语要说**结构和条件**，不要只说吉或凶——"底盘薄但能力硬"比"不太顺"有用得多；
3. "盘上明明是吉格，人生却平平"或反过来，问题多半出在**只看了一层**。

## 5_9 本板块小结

+ 十二宫是**人生领域**，不是西洋星座；
+ 强宫放大、弱宫衰减，惟太阴居闲极反为福；
+ 解宫三层：**度主 → 宫主 → 宫内星**；
+ 一宫多象要**取交集**，矛盾时如实说明；
+ 空宫借对宫，命度主是最后锚点。
