## 板块9 · 星格与互垣：把零件装成整机

> **本板块的位置**：到板块 8 为止，我们完成的是"静态解盘"的全部零件。板块 9 要做的是**把零件装成整机**——看格局与互垣。
>
> 提醒一句：绝大多数盘只成立一到两个格局，一个都不成立才是常态。**没有格局不等于命不好，只是无特殊加成。**

### 9_1 格局观：先立主干，再议枝叶

格局是"整机级"的判断，但它必须建立在前面所有零件都检查过的基础上。**跳过庙旺、恩难直接谈格局，是空中楼阁。**

> **舒继英的减法精神同样适用于格局**：抓住七政四余、正变五行、日月限度等主干，神煞与奇巧格局当审慎取舍。
>
> 四库馆臣对《星学大成》"乔庙"之说的批评正是此意——"不知五行之理，惟主生克，若乃冬火坐水乡、春土居木位，岂可目为乔庙而定其吉乎？"**脱离五行生克追求奇巧格局，是后世星命学走向玄虚的病根。**

```latex
解盘的正确顺序（不可跳步）：

  排盘 → 庙旺 → 断躔 → 恩用仇难 → 十二宫 → 化曜神煞 → 【格局】
                                                          ↑
                                                  整机判断在这一步

```

### 9_3 富格的判断五要素

古籍富格条目流传较散（如"母依日月，身坐田财"——恩星与日月并行，主得亲友恩助或祖基横财；太阴坐田财宫有吉星助主富）。比背条目更可靠的是掌握**判断财富的五个抓手**：

| 抓手 | 看什么 | 吉象 | 凶象 |
| --- | --- | --- | --- |
| **财帛宫主** | 强弱、庙陷、得令否 | 落强宫、得令、有恩星照 | 落恶弱宫、失令、断躔 |
| **田宅主** | 与财帛主是否互垣 | 财田互垣（"千仓万箱多蓄积"） | 田宅被煞星居 |
| **恩星** | 是否生财帛主 | 恩星拱财 | 难星克恩 |
| **是否有库** | 财星入墓库之地 | 入库主能积聚 | 财星被冲散 |
| **有无漏财象** | 天耗、劫煞、阳刃是否临财 | 无 | 财临阳刃（守财奴）、财落兄弟宫（散于朋友） |

> **《星学大成·杂诗》财帛三断**：
>
> 1. "**财临阳刃守财奴**"——有钱舍不得花；
> 2. "**财落三宫好用徒**"——财在兄弟宫，钱花在朋友身上；
> 3. "**身命二星闲极见，津津和气百无拘**"——身命入闲极宫，随和自在但不聚财。

### 9_4 身命互垣：全书最实用的"操作手册"

《星学大成·杂诗》"身命互垣论"是可以直接照搬的断语库。**互垣**（命主入某宫、该宫主又入命宫）则吉凶加倍。

| 飞入关系 | 断语 | 吉凶 |
| --- | --- | --- |
| **命主入身 / 身入命** | "互垣须是福来当，管取一生长吉庆" | 大吉 |
| **财帛主、田宅主与身命相遇** | "若无暗耗与刑囚，当与石崇斗豪富" | 大富 |
| **身命主入田宅** | "千仓万箱多蓄积"；田宅迁入命身来 → "贮积金珠无破克" | 吉 |
| **身命主入子孙** | "母来救子岂无情"；子主顾母 → "官高禄厚更荣尊" | 吉 |
| **身命主入奴仆** | "纵有吉星也劳碌，又被小人多反复" | 凶 |
| **身命主入妻宫** | "资财昌盛福兴隆"；凶星居七位 → "克妻克子必为凶" | 视星性 |
| **身命主入八煞（疾厄）** | "官禄少年须早发"；煞星入命 → "疾厄缠身那可脱" | 双刃 |
| **身命主入迁移** | "过房出祖定无疑，也须奴养庶生儿" | 主离祖 |
| **官禄主入命 / 命主居官禄** | "互垣必是拜三公" | **最高规格之一** |
| **福德主入命 / 命主居福德** | "互垣须是拜三台" | **最高规格之一** |
| **身命主入相貌** | "相貌堂堂身更长"；被煞星暗克 → "破相为人貌不扬" | 视星性 |
| **闲极主入命宫** | "命居闲极总成空，不知衣禄在何从" | 凶（无所成） |

> ▲实操：拿到盘先查两组互垣——**命主 ↔ 官禄主**（事业天花板）、**命主 ↔ 福德主**（福气厚薄）。这两组一旦互垣且星性纯正，格局层次立刻提升一档。

```latex
互垣检查顺序（先看这两组）：

  第1步 命主 ──► 官禄主？    官禄主 ──► 命宫？    （事业天花板）
  第2步 命主 ──► 福德主？    福德主 ──► 命宫？    （福气厚薄）

  若成立且星性纯正 → 格局层次 +1 档

```

### 9_5 拱夹、引从、天空蓦越

| 名称 | 位置 | 断法 |
| --- | --- | --- |
| **天空** | 岁驾前一位 | "驾前一位号天空，百煞逢之不作凶"——凶煞遇之被空化；**但用神飞到天空则坏**（"限宫无照却嫌穷"） |
| **蓦越** | 岁驾后一位 | "诸星遇着减精华"——大多星曜打折；**惟宜日月居前后** → "淤泥出异葩"，恶劣环境中脱颖而出 |
| **引从** | 太阳在前为引（宜远），在后为从（宜近） | 吉星在日前喜逆（气转亲），在日后忌逆；凶星反是 |
| **疏中 / 外辅** | 星居日前后为"内夹"，居日列最前最后为"外辅"，"必值四余乃止" | 吉星夹辅太阳多主公卿侍从 |

> **《乾元秘旨》太阳论精要**："太阳者，君象也，用天下之星，而不为诸星之用，无远弗届，无幽弗烛。"**凡星伴太阳则"得力"——吉星伴日则更吉，凶星伴日则更凶**。"吉凶扶阳势，余奴亦足敌杀"正是此意。

### 9_6 特殊星格举要

以下为常见且逻辑清晰、可验证的特殊星格（断格时须与五行生克一致，不可单独成立）：

| 星格 | 构成 | 含义 |
| --- | --- | --- |
| **日月合璧** | 日月同宫或相望得地 | 主贵显、名声 |
| **五星连珠** | 五星聚于一方或数宫相连 | 大格，须看聚于强宫还是弱宫 |
| **木火通明** | 木火相生得时得地 | 主文采、科名 |
| **金水相生** | 金水同宫或三合，且为恩用 | "金水为恩拱驾行，为官定执法司权" |
| **官印相生** | 官星与印星相生（窦陶氏第十问） | "官贵之命，有官有印，官印相生，方为权柄" |
| **金水清高** | 金水高强 | "只是受荫" |
| **木炁高强** | 木与紫气高强 | "正科必定"（正途科第） |
| **罗孛高强** | 罗睺月孛高强 | "只膺武品"（武职） |

> **窦陶氏第十问的精华补充**：

"印强官弱，**掌财之命**；官强印弱，**虚名不正**。"——官印的配比决定实权还是虚名，这是判断"官"之真伪的关键。

### 9_7 官贵之命的三层判定

| 层次 | 条件 | 断语 |
| --- | --- | --- |
| **真权柄** | 有官有印，**官印相生** | 方为权柄 |
| **管财** | 印强官弱 | 掌财之命（无实权） |
| **虚名** | 官强印弱 | 虚名不正 |

> 补充："官星空了三分实，限苦逢之必降除"——官星虚浮（三分实七分空）又遇苦限，主降职免官。

### 9_8 格局判断的三条纪律

1. **格局服从生克**：任何奇巧格局，若与五行生克、庙旺结论冲突，以生克庙旺为准（四库馆臣批评乔庙之说的核心理由）；
2. **格局服从行限**："各星俱合格，限度无贵气所属，终难大伸；各星俱陷落，限度非戾气所归，何至大屈？"（耶律楚材）——**格局好而限不好，是"有材无运"**；
3. **格局不孤立成立**：须有拱夹、得时、无重犯煞为条件，否则只是"形似"。

### 9_9 小故事：一次"互垣"救回的判断

阿棠给一位朋友看盘，刚看完前几步时心里是失望的：**命宫主星平，官禄宫主陷**，怎么看都不像一张"有事业"的盘。他差点就要写下"事业上大概比较平淡"。

在写之前，他按流程做了一次互垣检查，结果发现了两件事：

1. **官禄主虽然陷在自己宫里，却飞入了命宫**——命宫里有官禄主；
2. **命宫主星虽然平，却飞入了官禄宫**——官禄宫里有命主。

这就是"**官禄主入命 / 命主居官禄**"的互垣，古诀称为"**互垣必是拜三公**"。

再往下看行限：朋友当时正走在官禄宫的三合限上，属于"官星填起"的阶段。

三层合起来，他把断语改写成了：

> **"你的官禄主本身不旺（底盘薄），但它和命宫互垣（你的人和你的事业是绑在一起的），所以事业不会缺席；真正的窗口期在官星被填起的那些年。"**

后来朋友确实在一个"官星填起"的年份拿到了一次关键机会。更耐人寻味的是朋友自己的反馈："我确实不是那种一路顺的人，但每次到了节骨眼上，总会有个机会冒出来。"——这句反馈正好对应了"底盘薄 + 互垣 + 窗口期"的结构。

阿棠后来把这张盘记进了复盘表，并在"失误环节"一栏写了四个字：**"差点漏互垣"**。

**这个故事的三条教训**：

+ **星在本宫陷，不代表它没用**——要看它飞到哪里去了；
+ 互垣是"整机级"信号，能救回许多"零件级"看起来不好的盘；
+ 但互垣也要服从行限：**互垣是潜力，行限是兑现**。没有行限引动的互垣，只是"有可能"。

### 9_11 本板块小结

+ 格局是**整机级**判断，必须建立在庙旺、恩难之后；
+ 查格局从**力量排行榜前四名**倒推，不逐条套；
+ **没有格局是常态**，不等于命不好；
+ 身命互垣先看两组：命主 ↔ 官禄主、命主 ↔ 福德主；
+ 格局服从生克、服从行限、不孤立成立。
