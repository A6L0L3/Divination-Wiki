## 板块13 · 门派合参与跨体系对照

> **本板块的位置**：到这里，主干（果老派）已经立住。板块 13 处理两件事：**一是三派何时可以合参，二是与其他命理体系（八字、紫微）如何对照。**
>
> 一句话提醒：**不是越多越好，而是知道什么时候该分。**

### 13_1 三派辨析：定位、代表文献与学习次序

| 流派 | 方法论 | 核心 | 代表文献 | 建议次序 |
| --- | --- | --- | --- | --- |
| **果老派** | "纯星论命" | 只重星盘；**以度主为主、宫主为辅**；"遇卯安命" | 《张果星宗》 | **1. 先学**（资料最完整、逻辑最线性） |
| **天官派** | "干化曜配五星" | 取年干十神所化星曜；**定命专论宫、行限专论度**；"络贯串填冲守钓"八字真言 | 《乾元秘旨》（清 · 舒继英） | **2. 再学**（精度放大器） |
| **琴堂派** | "星禄合参" | 四柱结合星盘；**天地人三盘并立**；以宫主为主，重空亡虚实 | 《星学大成》卷八、九"琴堂虚实五星" | **3. 后学**（交叉验证工具） |

> **天官派八字真言**：**络、贯、串**三字贯通二十八宿经纬，**填、冲、守、钓**四字处理星曜作用关系。这七字（"络贯串填冲守钓"）是天官派的操作总纲，可与果老派的"遇卯安命"对读。

> **琴堂派的历史意义**：据传，唐代琴堂五星术正是后来紫微斗数的前身。其"地盘定十二宫不动、天盘以卯加命宫转出、人盘叠加十神化曜"的三盘结构，与紫微斗数的宫干四化有方法论上的亲缘关系。

```latex
三派选择顺序：

  果老派 ──► 建立主干（度主为核心）
     │
     ▼  主干稳了
  天官派 ──► 加精度（十干化曜 + 宫度分工）
     │
     ▼  熟练后
  琴堂派 ──► 交叉验证（三盘 + 空亡虚实）

```

### 13_2 合参的三条红线

1. **不同时上三派**：果老学到能独立批盘，再上天官化曜；天官熟练后，再碰琴堂三盘；
2. **不混用冲突参数**：果老"日午月未"与《星学大成》入垣歌"日月戌方云入庙"，**只取其一**，并在笔记中注明所取体系；
3. **结论冲突时的优先级**：**星曜本体（庙旺生克）> 化曜身份 > 神煞**。这一优先级是《乾元秘旨》减法精神与"重而用之、轻而弃之"原则的共同结论。

```latex
冲突时的优先级（从高到低）：

  第1步 星曜本体：庙旺、生克、断躔      ← 最可靠
  第2步 化曜身份：十干化曜改写社会身份   ← 次可靠
  第3步 神煞：只在与上面一致时加重       ← 最易滥用

```

### 13_3 与八字的对照：星平合参

| 维度 | 八字（子平） | 七政四余 |
| --- | --- | --- |
| 观测对象 | 天干地支（符号系统） | 真实天体 + 虚点（十一曜） |
| 时间精度 | 时辰（两小时） | **分钟级 + 经纬度** |
| 坐标 | 节气 + 干支 | 十二宫 + 二十八宿 + 古度 |
| 论命主轴 | 五行生克 + 十神 | 十一曜躔度 + 二十八宿 + 五行 |
| 强弱判断 | 得令、得地、得势 | 庙旺 + 得令 + 得时 + 运行状态 |
| 动态 | 大运 + 流年 | 大限 + 度限 + 流年 |

> **合参思路**：八字长于**格局定性与十神人事**（六亲、财官关系的符号表达清晰），七政四余长于**精度与时机**（把人生锚定到真实天体位置，度限可收窄到年）。明代万民英一人兼著《三命通会》与《星学大成》，四库馆臣称二者"**星平双璧，并行不悖**"——这正是"星平合参"的经典范式。

### 13_4 与紫微斗数的对照

| 维度 | 紫微斗数 | 七政四余 |
| --- | --- | --- |
| 十二宫 | 同源（命宫、财帛、兄弟、田宅、男女、奴仆、妻妾、疾厄、迁移、官禄、福德、相貌） | 同源 |
| 星曜 | 虚设星曜（紫微、天机等） | 真实天体 + 四余 |
| 天干系统 | 四化（禄权科忌） | 十干化曜（十神化曜） |
| 命宫定法 | 依生月生时顺逆数 | **遇卯安命**（生时加太阳宫） |
| 空宫处理 | 借对宫 | 亦借对宫（同理） |

> ⚠避坑：**紫微"四化"与七政四余"化曜"是两套并行的"天干气化"传统**，虽然共享"天干气化、随干改易"的方法论精神，但星曜与化法完全对应不上，**不可互相套用**。有紫微基础者学七政四余，最大的障碍往往就是"用紫微的四化去理解化曜"。

### 13_5 郑氏星案研读法：向古人学"断盘手感"

《张果星宗》后半部收录明代郑希诚四十余个真实星命案例（郑氏星案），是全书的实战范本，也是最好的"案例教材"。

> ▲实操：倒推法三步研读
>
> 1. **遮住结论**：只看盘面数据（命度、十一曜分布、行限），自己先断一遍，写在纸上；
> 2. **对照原文**：看郑氏断的是什么（他是抓了哪颗星、哪一度、哪一组关系？）；
> 3. **复盘差异**：我漏了什么？我多抓了什么？他为什么先说这一条？
>
> 每周精读一个案例，坚持四十周，你的"盘感"会有质变。**郑氏原注明言书中有"数条不验"之处——读到不验处，正是你学会"通变"的起点。**

```latex
倒推法流程：

  盘面数据 ──► 我自己先断一遍（写下断语）
                    │
                    ▼
              对照郑氏断语
                    │
                    ▼
          差异复盘：漏了什么 / 多抓了什么 / 他为何先说这条

```

### 13_6 观星要诀：以八条为纲

《果老星宗》"观星要诀二十四法"是全书的精华操作手册，其中八条构成主干：

| 条目 | 原文要义 | 实务转化 |
| --- | --- | --- |
| **看三主** | 身主不傍鬼、不冥晦；宫度二主得局不泄气，不迟留伏逆于恶地；朝元升殿垣局居生我之度 | 三主（命宫主、命度主、身度主）是全盘第一检查项：是否入垣？是否泄气（躔我生之度）？是否迟留伏逆在恶地？ |
| **论四时** | 春木、夏火、秋金、冬水、四季月土为令星 | 得令加分、失令减分（见板块 6_3） |
| **分昼夜** | 昼生喜日木炁土计水孛于阳宫阳度；夜生爱太阴火金罗于阴宫阴度 | 昼夜是"微调变量"，决定吉星是否真发力（见板块 6_4） |
| **辨阴阳** | 初一至初五、廿六至三十的特定时辰生人，日月俱晦 | 晦则能力难发挥，兼刑煞主孤独（见板块 6_5） |
| **推迟留** | 疾、迟、留、伏、逆五种运行状态 | 留则凶不散、疾则事来去皆快（见板块 6_6） |
| **考伏逆** | 伏逆在庙旺受生之地、在君前，反能为吉；在克泄鬼制之宫、在君后死绝之地，大凶 | **伏逆非一律为凶**——看位置 |
| **明禄贵** | 宫身度主坐禄贵马乡，或禄贵拱夹 | 禄勋、天贵、玉贵、驿马为四大吉神 |
| **利生旺** | 身命度主要居长生、帝旺之乡；命立败宫、身度主飞入死绝，主贫贱 | 十二长生状态模拟阶层与成败 |

> 其余条目（如看拱夹、看引从、看划度、看倒限等）散见各卷，宜在八条主干熟透后，对照原本逐条过一遍，不必一次求全。

### 13_7 小故事：两套体系的"打架"

小许同时学了果老和琴堂，结果在给一个盘定"太阳入垣"时卡住了：

+ **果老派**：太阳入垣在**午**；
+ **《星学大成》入垣歌**：太阳入垣在**戌**。

他一开始想"调和"，把两宫都算作有利。结果同一张盘出现了两套自相矛盾的结论——一会儿说太阳得力，一会儿说不得力，越解越乱。他形容那段时间："**每看一颗星都要重新吵一架。**"

后来他按 13_2 的红线二处理：**只取其一，并在笔记中注明所取体系**。具体做法是，盘面备注栏固定写三行：

```latex
所取体系：果老派
庙旺表：日午 / 月未 / 木寅亥 / 火卯戌 / 土子丑 / 金辰酉 / 水巳申
备注：另一套（日月戌方云入庙）记在备注，暂不采用，待体系稳固后再作比较

```

从此他的盘不再打架。半年后他已经能独立批盘，才回头做两派的比较研究——这时候比较才有意义，因为**他已经知道自己在比较什么**：他开始能看出两派背后的宫位划分逻辑差异，而不是只看"哪一宫更吉"。

**这个故事的三条教训**：

+ 冲突参数不是"取平均"，而是**明确选边并留档**；
+ 比较研究是**进阶动作**，不是入门动作——主干未稳就做比较，得到的只是混乱；
+ 三派混学之所以是初学第一大忌，正因为"同一颗星在三派里身份不同"，同时学会当场错乱。

### 13_9 本板块小结

+ 三派次序：**果老 → 天官 → 琴堂**，不可同时上手；
+ 合参三条红线：**不同时上、不混参数、冲突时有优先级**；
+ 星平合参：八字长于**定性**，七政四余长于**精度与时机**；
+ 紫微四化与七政化曜**不可互套**；
+ 郑氏星案用**倒推法**练盘感，读到"不验处"正是学会通变的起点。
