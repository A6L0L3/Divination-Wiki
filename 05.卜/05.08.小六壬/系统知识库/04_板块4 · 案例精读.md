### 4_1 失物与行人

#### 要点：场景特点

失物是小六壬最宜练手的题材——东西找没找到，一翻就知道，反馈最快。

「失物」与「行人」常并为一类，因为两者都在问「**东西/人在哪、动没动**」。

#### 六宫直读（只列取句要点，断辞原文见板块1）

| 宫 | 东西/人在哪 | 怎么找 |
|---|---|---|
| 大安 | 没丢远，在近处 | 原地附近找；重点是「没被移动过」 |
| 留连 | 往南找；或在别人手上 | **主动开口讨**（急讨方遂心） |
| 速喜 | 在路上、经人之手 | **问人比翻东西重要**（逢人路上寻） |
| 赤口 | 被移动过，往西 | **立刻去找**，迟则难寻（失物急去寻） |
| 小吉 | 坤方：西南、低处、承载之物 | 找矮柜、盒子、托盘一类（失物在坤方） |
| 空亡 | 寻不见 | 别耗太多精力，留个联系方式等消息 |

行人同表：

| 宫 | 人在哪/状态 | 建议 |
|---|---|---|
| 大安 | 还没动身（行人身未动） | 别等，他还没出发 |
| 留连 | 还没踏上归途（去者未回程） | 会拖，保持联系 |
| 速喜 | 有消息来（行人有音信） | 消息先到，人后到 |
| 赤口 | 在外受惊（行人有惊慌） | 主动联系确认安全 |
| 小吉 | 快到了（行人即便至） | 准备接 |
| 空亡 | 音信渺茫 | 主动联系，必要时求助 |

#### 实操：静动二分：先定「找法」，再定「方位」

```
静组（大安、留连、空亡）→ 东西/人基本没动
   找法：在「最后一次见到的地方」的半径内找

动组（速喜、赤口、小吉）→ 东西/人被移动过
   找法：沿动线找，且【问人】优先于【翻东西】
```

**顺序不能反**：先分静动（决定找法），再谈方位（缩小范围）。只给方位不给找法，对方会闷头乱翻。

#### 追问三句（把范围缩到可行动）

```
第1问 最后一次见到/使用是什么时候、在哪？
第2问 那天走过哪些地方？（列动线）
第3问 有没有可能被别人动过？（同事、家人、保洁、店员）
```

按落宫匹配：

```
大安 → 不在动线上，在「最后一次使用地」附近
速喜、赤口 → 在动线上，且经过人手
留连 → 在别人手上，需要开口讨
小吉 → 西南方位 + 低处 + 承载类物件
空亡 → 先别耗，留联系方式等消息
```

#### 方位取象的展开法

断辞给的是「南方」「坤方」这类大方向，要展开成具体位置才好找：

```
坤方（西南）→ 西南方位 + 低处 + 承载类物件（柜、盒、托盘、地面层）
南方        → 南边 + 明亮处（速喜）／水边一带（留连属水）
路上        → 动线 + 他人经手（前台、失物处、同事抽屉）
```

#### 案例小故事：一个钱包，十分钟

同事午饭后发现钱包不见了，急得脸都白了，来问「还能找回来吗」。

掐出 **月赤口 / 日小吉 / 时小吉**。

按三宫主次读：

```
时宫小吉（主答案）：能找回，落点是「和合」
   → 断辞取「失物在坤方」：西南、低处、承载之物
日宫小吉（过程） ：过程也是和合，说明不是被恶意拿走
月宫赤口（背景） ：环境里有「移动、惊动」
   → 东西被人动过，而且动的时候带点慌张
```

三宫串成一句话：**东西被好心人动过（月赤口），过程没有恶意（日小吉），落在西南方向的某处（时小吉）。**

给她的三个寻找点，按可能性排序：

```
第1处 前台或失物处（被好心人收走的概率最高）
第2处 食堂座位（最后用餐的地方）
第3处 食堂回工位的动线
```

并强调一句关键的话：**先问人，别先翻东西。**

她去了前台，开口问了一句。前台说：「有人捡到交过来了。」钱包就在抽屉里。前后不到十分钟。

对照复盘：

```
月宫赤口  → 被人动过 ✓（捡到的人交给了前台）
日宫小吉  → 和合、无恶意 ✓（是好心人交还）
时宫小吉  → 坤方 ✓（前台恰在公司西南角，方位也巧）
```

她后来总结：最有用的那句不是方位，而是**「先问人，别先翻东西」**。如果她闷头在食堂翻半小时，钱包其实一直躺在前台。

这个案例还有一层：**「失物在坤方」这句断辞，如果不展开就会用错。** 「坤」不只是西南，还是「地」「承载」「低处」。若只告诉她「往西南找」，她大概会把家里西南角的柜子翻一遍；展开成「西南 + 低处 + 承载之物（柜台抽屉）」，才找对。

#### 笔记与验证

失物类记录是最好的练习材料（反馈快）。记录字段：

```
失物：____
落宫：月X / 日X / 时X
读法：能不能找到？在哪？建议找法？
实际：在哪找到？用了多久？
命中项：能否找到 ✓/✗　方位 ✓/✗　静动判断 ✓/✗
```

验证方式：分别统计「能否找到」「静动判断」「具体方位」三项的命中率。多数人会发现**「能否找到」最准、「具体方位」最不准**——这提示你：方位只作参考，别当坐标用。

### 4_2 谋事与出行

#### 要点：场景特点

「谋事」问的是一件事能不能推进、该怎么推进；「出行」问的是这一趟顺不顺。两者都涉及「动」，所以放在一起练。

#### 六宫直读

**谋事（求财、办事、推进项目）**

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 稳，但不动 | 守成；不宜扩张，不宜求「快」 |
| 留连 | 拖，时机未到 | 缓一缓；涉及「要东西」的，主动去讨 |
| 速喜 | 快，消息快 | 趁早动；快在消息，不等于事已成 |
| 赤口 | 硬碰硬 | 防条款、防口舌；不宜硬来 |
| 小吉 | 和合，小成 | 去谈、去商量；**带上「小」字** |
| 空亡 | 抓不住 | 别投入；做别的准备 |

**出行**

| 宫 | 态势 | 提醒 |
|---|---|---|
| 大安 | 平稳，或因事未成行 | 无惊喜也无风险 |
| 留连 | 有阻滞、会变 | 留缓冲时间，别赶 |
| 速喜 | 顺利，宜速行 | 趁早走 |
| 赤口 | 有冲撞 | **检查车况**，防口角，留凭证 |
| 小吉 | 顺利，路上好谈事 | 宜边走边谈 |
| 空亡 | 去不成，或去了白去 | **出发前再确认一次** |

#### 实操：谋事：先答方向，再答量级

```
方向：能不能推进？（看时宫宫义）
量级：多大？（看「小吉」的「小」、「大安」的「守成」等）
动作：该主动还是该等？（看静动与断辞里的动作句）
```

**最常见的失误不是方向错，是量级没说。** 只说「能成」，对方会自动脑补一个乐观的版本。

量级词清单：

```
小成 / 适中 / 规模有限 / 不是大获
打折 / 持平 / 超额
部分 / 全部
```

#### 出行：把不顺的课转成排查清单

```
赤口 → 检查车况（胎压、油量、刹车）；重要约定书面确认；少争执
留连 → 留缓冲时间；行程可能变，别把时间卡死
空亡 → 出发前再跟对方确认一次；准备备选方案
```

#### 案例小故事：同一件事，两个时刻的两个课

老李有个合作方在犹豫，他问：「要不要主动再推一把？」

**第一次**（两周前）掐出**留连**。

当时给的读法是：留连主拖，对方内部还没定，这时候推是白费劲。建议他先别动，把方案再打磨一下。

他忍住了，没推。

**第二次**（两周后）他又来问同一件事，掐出 **月留连 / 日小吉 / 时速喜**。

三宫串读：

```
月宫留连：背景还是拖的（对方内部慢，这一层没变）
日宫小吉：眼下是和合——可以谈了
时宫速喜：落点是快
```

读法完全变了：

```
不是「能不能推」，而是「现在就推」。
速喜主快，窗口就在这两三天；
小吉主和合，用商量的姿态，别用催促的口气。
```

给他的动作建议：

```
第1步 今天下午就发消息约面谈，别拖过这周
第2步 面谈时把具体方案带上，别空手谈
第3步 语气是「一起看看怎么弄」，不是「你们定下来了吗」
```

他当天下午发了消息，对方秒回：「正好，我也想找你聊聊。」三天后签了意向。

**这一课的精髓是对比**：

```
两周前 · 留连 → 环境没动，推了也白推
两周后 · 小吉+速喜 → 可以谈了，而且得快
```

同样是「主动推一把」，时机不同，结果天差地别。**这就是小六壬最实用的地方：它回答的不是「成不成」，而是「眼下往哪走、该不该动」。**

顺带说明一个常见疑问：**同一件事隔一段时间再起课，算不算「反复起课」？**

```
不算。「不反复起课」指的是同一时刻掐了又掐、挑一个想要的答案；
时过境迁、情况变化后再起课，是正常用法。
但要在记录里标明「同一事件的第 N 次起课」，便于日后对比。
```

#### 笔记与验证

谋事类记录加两个字段：

```
第1项 是否推进（推进了 / 没推进 / 部分推进）
第2项 量级是否符合读法（偏大 / 符合 / 偏小）
```

出行类加一个字段：

```
出行：成行了 / 取消 / 延期
```

验证方式：统计「方向对但量级没说」的比例。这个数字通常很高，是提升空间最大的地方。

### 4_3 官非口舌

#### 要点：场景特点

包括：合同纠纷、劳动争议、邻里纠纷、被人投诉、会不会被起诉等。

这一题材**边界最硬**：术数只作思路参考，具体事务走专业渠道。

#### 六宫直读

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 平稳，可调解 | 宜和解，别把事闹大 |
| 留连 | 拖很久 | 宜缓不宜急（官事只宜缓）；但要防对方拖死你 |
| 速喜 | 有转机 | 宜主动解决（官事有福德） |
| 赤口 | 是非大 | 切忌硬碰；全程留痕（官非切要防） |
| 小吉 | 和合 | 找中间人调解，协商优于诉讼 |
| 空亡 | 不利 | 早做止损准备；**问「会不会被起诉」→ 空亡 = 不会** |

#### 实操：三条通用动作（无论落哪一宫）

```
第1条 留痕：沟通用文字，保留聊天记录、邮件、书面凭证
第2条 不激化：不与对方发生言语冲突，不在公开场合表态
第3条 找专业：合同、劳动、侵权类问题，咨询律师或相关部门
```

> **口径说明**：本单元内容不构成任何法律意见。涉及具体权利义务的判断，请以专业人士与相关部门的结论为准。

#### 落宫对应的预案

```
赤口 → 检查合同有没有漏洞；补齐书面材料；避免单独会面
留连 → 设时间节点（如「两周没进展就走正式渠道」），别无限拖
速喜 → 抓紧窗口，主动提解决方案
小吉 → 找一个双方都信得过的中间人
空亡 → 评估最坏结果，做止损方案
大安 → 维持现状，不主动升级
```

#### 案例小故事：留连的「缓」字两面

学员的朋友遇到劳动纠纷，问「能不能拿到补偿」。掐出 **月大安 / 日留连 / 时赤口**。

三宫串读：

```
月宫大安：环境是稳的（公司还在，不是跑路那种）
日宫留连：眼下是拖 —— 这正是劳动纠纷的常态
时宫赤口：落点是冲 —— 最后会有硬碰硬，可能要撕破脸
```

学员最初的读法是「留连主拖，慢慢等吧」。我提醒他注意留连那一句断辞的后半：**「急讨方遂心」**——留连不是让你躺平，是让你**主动去讨**，只是讨的过程会拖。

再加上时宫赤口「官非切要防」，给的读法是：

```
第1步 能拿到，但要主动主张，不能等公司良心发现
第2步 过程会拖，做好「两三个月」的心理准备
第3步 落点是赤口，最后大概率要走到正式渠道（仲裁/协商会硬碰硬）
第4步 全程留痕：所有沟通用文字，不打电话
```

具体动作：

```
· 不走极端（不闹、不激化、不在公开场合表态）
· 但设明确节点：两周内没进展，就走正式渠道
· 全程书面沟通，保留记录
· 咨询一位劳动法律师，把材料提前备齐
```

结果：拖了两个月，最后在协商会上拿到了补偿。对方一开始想拖到他自己放弃，看他不松口、材料又齐，就谈了。

**留连在官非里的正确用法，不是「等」，是「用耐心换筹码」。**

断辞说「官事只宜缓」，缓的是**情绪与节奏**，不是放弃主张。这位学员最初读成「慢慢等」，就漏掉了「急讨方遂心」那半句。

复盘时他自己总结：最有价值的不是「能不能拿到」的答案，而是**「设时间节点」那条建议**——留连如果不设节点，就真的会无限拖下去。

#### 笔记与验证

官非类记录加一个字段：

```
是否咨询专业人士：是 / 否
```

验证方式：**这一项应该做到全部为「是」。** 如果出现了「否」，说明那一次的处理存在风险——翻出来，在备注里补上「应建议走专业渠道」。

另外统计「我给出的预案里有没有留痕建议」。官非类断语里，「留痕」是成本最低、收益最稳的一条，不该漏。

### 4_4 感情与家庭

#### 要点：场景特点

感情与家庭是最容易**自我实现**的领域：你说会分，对方可能就不努力了；你说能成，对方可能就松懈了。**这一题材对措辞的要求最高。**

#### 六宫直读

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 稳定平淡 | 不会散，但也热不起来；适合过日子 |
| 留连 | 纠缠反复，分分合合 | 短期难有定论；不逼对方表态 |
| 速喜 | 进展快 | 趁热打铁；速喜后劲不足，别拖 |
| 赤口 | 争吵多 | **管住嘴**；少争辩，重要事用文字 |
| 小吉 | 和合，有人撮合 | 能成，靠人和；平淡温馨型 |
| 空亡 | 抓不住 | 不强求；**问「会不会散」→ 空亡表示眼下散不了** |

#### 反转读法（问分离时要特别小心）

```
问「能不能成」 → 空亡 = 抓不住
问「会不会散」 → 空亡 = 散不了（坏事不来）
```

**判断标准**：先问自己「对问事人来说，这是好事还是坏事」，再定方向。

#### 实操：提问改写

```
✗ 「我跟他有未来吗？」          → 太大，无法验证
✓ 「这个月内他会主动联系我吗？」
✓ 「这次争执之后，一周内关系能缓和吗？」
```

#### 措辞模板

```
✗ 「你俩注定要散」
✓ 「眼下这个阶段有拉扯之象，短期内难有定论。
   如果你想继续，建议先别逼对方表态，
   给彼此一点空间，一段时间后再看。」

✗ 「他会回来找你的」
✓ 「卦上看近期有联系的可能，但我不建议你干等——
   该做什么做什么，别把自己的生活停摆。」
```

#### 三条守则

```
第1条 不替对方做决定（「你该分手」这类话不说）
第2条 不用「注定」「一定」这类宿命词
第3条 读出不顺的课，必须配上「如果想挽回，可以做什么」
```

#### 案例小故事：一句话，两个结局

学员给朋友读感情，问「最近总吵架，会不会散」。掐出 **月速喜 / 日小吉 / 时速喜**。

三宫串读：

```
月宫速喜：环境里有「快」的东西——可能是升温，也可能是爆发
日宫小吉：眼下是和合——关系本身有缓和的基础
时宫速喜：落点是快——近期会有转机
```

这是一个**相当好**的课：三宫里两个吉，落点也是吉。分不了。

但学员脱口而出的是：「你俩要吵崩了。」

朋友当场哭了，当天晚上跟对象大吵一架——她觉得「反正卦上说要崩」，说话就没收着。本来只是小摩擦，真闹到了要散的程度。

复盘时指出三个问题：

```
第1个 落宫读反了
   时宫明明是速喜，为什么会读成「要崩」？
   → 因为他把注意力放在「吵架」这件事上，
     看到冲撞的影子就往坏处读
   → 教训：先看落宫，再看场景；别让场景情绪盖过落宫

第2个 措辞绝对化
   「要崩了」→ 应改为「近期口舌多，注意沟通方式」

第3个 没给规避方案
   读出不顺，就该说「防什么、能做什么」
```

后来重新读了一次，说法改成：

```
「这两周你们容易在言语上起冲突，但都不是原则性问题。
 建议你：有情绪先缓十分钟再说，重要的事用文字沟通，
 别在气头上做决定。过了这两周会好。」
```

朋友照做了。那两周确实吵了两次，但都及时刹住了车。

**同一课，一句话能拆散一对，一句话能救回一对。**

这个案例后来成了我们讲「措辞边界」的标准例子。它说明一件事：在感情领域，**你怎么说话，比你怎么掐指更重要**——因为你的话会变成事件的一部分。

#### 笔记与验证

感情家庭类记录，加一个专用字段：

```
我的读法是否影响了当事人的行为：无 / 轻微 / 明显
```

验证方式：如果「明显」的比例很高，就要格外注意措辞——你的话已经成了事件的一部分。这时更要遵守三条守则：不下定论、不替人决定、不顺必配方案。

### 4_5 综合纠偏

#### 要点

本单元做两件事：**一、把前四个题材里最容易犯的错集中纠一遍；二、给出完整的占验记录与验证方法。**

高频误读是「知不知道」，记录与验证是「做没做到」。前者读完就懂，后者要练成习惯——本单元的重点其实在后者。

#### 一、四类高频误读（汇总）

| 误读 | 错在哪 | 正确读法 |
|---|---|---|
| 把「静」读成「成」 | 大安是静，问进展时往往是「暂时不动」 | 「不是不成，是没动」 |
| 把「难」读成「绝」 | 留连难在迟，不在绝 | 「会拖，要主动讨」 |
| 把「快」读成「成」 | 速喜快在讯息，不保证结果 | 「有消息了，事情还在后头」 |
| 把「空」读成「凶」 | 空亡是「没有」，不是「坏」 | 问好事＝抓不住；问坏事＝不会来 |

另有两条结构性错误：

```
错误五 · 只答方向不答量级
   「能成」→ 对方脑补成「成我想要那么大」
   应加量级词：小成 / 适中 / 规模有限

错误六 · 只答态势不给取向
   「这事不成」→ 然后呢？
   应给动作：别投入 / 主动去讨 / 出发前再确认 / 等书面齐了再动
```

#### 实操

上一节说的是「错在哪」，这一节说的是「怎么记、怎么验」。先给模板，再给方法。

#### 二、占验记录完整模板

初期可用极简五字段（见 `0_4`）；读课数量上来后，用下面的完整版。

```
┌───────────────────────────────────────────────────┐
│ 第1项   编号  ：连续序号，不重复                 │
│ 第2项   时间  ：公历 + 农历月日时（双写）        │
│ 第3项   问题  ：一句话，眼前一件具体事           │
│ 第4项   落宫  ：月宫 / 日宫 / 时宫              │
│ 第5项   取句  ：我取了哪一句断辞                │
│ 第6项   读法  ：态势 / 取向 / 提醒（三件套）     │
│ 第7项   反馈  ：实际发生了什么                  │
│ 第8项   判定  ：对上了 / 没对上 / 部分对上       │
│ 第9项   复核  ：三宫掐对了吗？取句取对了吗？     │
│ 第10项  备注  ：闰月、跨时辰、被打断等特殊情况   │
└───────────────────────────────────────────────────┘
```

**纸质速写模板**

```
┌────────────────────────────────────┐
│ 编号：___  农历：__月__日 __时      │
│ 公历：____年__月__日 __:__          │
├────────────────────────────────────┤
│ 问题：                              │
│ ______________________________      │
│ 落宫： 月____  日____  时____       │
│ 取句：________________________      │
├────────────────────────────────────┤
│ 【态势】______________________      │
│ 【取向】______________________      │
│ 【提醒】______________________      │
├────────────────────────────────────┤
│ 反馈（事后回填）：                  │
│ ______________________________      │
│ 判定：□对上 □没对上 □部分对上       │
│ 复核：三宫□对□错  取句□贴切□取错    │
└────────────────────────────────────┘
```

#### 三、三条记录纪律

```
纪律一 · 读法栏永不回填
   读法必须在起课当场写下（或口述录音留时间戳）
   事后只填「反馈」，绝不修改「读法」

纪律二 · 时间要带时刻
   只写日期不写时刻，无法复核三宫，也无法做统计

纪律三 · 反馈写「发生了什么」，不只写「对上/没对上」
   半年后回看，只写「对上」的一条毫无价值
   写下具体情节，才能提炼经验
```

#### 四、验证方法

**方法一 · 准确率统计**

```
准确率 = 对上条数 ÷ 有效条数

有效条数 = 总条数
         - 三宫掐错的
         - 问题不是具体事的
         - 反馈未回填的
```

> 「部分对上」建议按半条计，或另设「完全对上率」与「含部分对上率」两个数，分开看。

**方法二 · 先看复核，再看准确率**

```
统计顺序：
  第一步：剔除三宫掐错的（这是操作问题，不是读课问题）
  第二步：剔除提问越界的（这是提问问题）
  第三步：剩下的才是「读课准确率」
```

**很多人会发现，剔除之后自己的准确率明显上升**——因为早期记录里混杂了大量操作失误。这也说明：**先练掐准，再谈读准。**

**方法三 · 分组对照（找强弱项）**

```
按题材分组：失物 / 行人 / 谋事 / 出行 / 官非 / 感情
   → 找出最擅长与最不擅长的题材

按落宫分组：大安 / 留连 / 速喜 / 赤口 / 小吉 / 空亡
   → 找出最容易读错的宫

按问题性质分组：求成 / 避险
   → 检查空亡的反转读法是否掌握
```

**方法四 · 双盲练习**

```
做法（一个人也能做）：
  第1步 对未来一周的若干件可验证的事分别起课，写下读法
  第2步 密封存证（发一封定时邮件给自己，或用带时间戳的录音）
  第3步 事后来开箱核对
```

**作用**：消除「知道结果后回头解释」的空间。写得越具体，越难事后附会：

```
✗ 「会比较慢」            → 可以附会成任何一种慢
✓ 「眼下不动，一周内不会有动静」 → 无法附会
```

#### 五、六种记录偏差

上面四种方法能解决「不会算」，但解决不了「算得漂亮却不真实」。下面六种偏差都会让准确率**虚高**——它们不产生错误的答案，只产生让你舒服的答案。

| 偏差 | 症状 | 对统计的影响 | 解药 |
|---|---|---|---|
| 事后附会 | 结果出来后回头「重新理解」读法 | 严重虚高 | 当场记录 + 时间戳 + 写具体 |
| 选择性记录 | 只把有把握的课记进来 | 虚高 | 起了课就记，无例外 |
| 只记对上的 | 忘了读错的那些 | 虚高 | 记录本身（全记则自动消失） |
| 自我实现 | 读法影响了自己的行为 | 虚高 | 记录「我的读法是否影响了我的行为」 |
| 确认偏误 | 只看支持自己读法的部分 | 虚高 | 反馈栏写完整情节 |
| 样本太小 | 十几条就下结论 | 结论不可靠 | 三十条以下不下结论 |

#### 六、从记录到个人读法库

```
三十条后  → 按题材整理，挑出最常应验的说法
一百条后  → 做分组对照表，找出强弱项
两百条后  → 写「个人修正条目」，形成自己的读法口径
```

个人读法库条目示例：

```
┌────────────────────────────────────────────┐
│ 【宫】速喜                                  │
│ 【题材】问消息                              │
│ 【本库读法】快在讯息                        │
│ 【我的版本】                                │
│   · 应「消息」远多于应「结果」              │
│   · 凡问「能不能成」，速喜只答「在动」      │
│ 【样本量】n=__  【准确率】__%               │
└────────────────────────────────────────────┘
```

**维护原则**：每条标注样本量，样本量太小的标为「待验证」，不作依据；定期回顾，跌破平均水平的条目删掉。

#### 案例小故事：一次诚实的统计

有位同学做了三个月记录，累计九十六条，兴冲冲来报：「准确率七成八！」

我没先恭喜他，而是把他的表格翻了一遍。翻到一半，两个问题浮了出来。

```
问题一：「判定」栏里大量是「部分对上」
   → 他把「部分对上」按整条算进了分子
   → 等于把「方向对、细节偏」当成了全对

问题二：他的问题高度集中在「这事会不会拖」上
   → 九十六条里有四十一条是这一类
   → 而现实里，大部分事情本来就会拖
   → 他断「会拖」的比例超过七成，命中率自然高
```

第二点最要命。打个比方：如果一个人天天猜「明天会不会堵车」，而这座城市本来就天天堵，那他猜「会堵」的正确率一定高得惊人——**但这不是预测能力，这是常识基线。**

于是重算了两遍：

```
第1步 「部分对上」改按半条计，重新算一遍总数
第2步 把「问会不会拖」这一类（共四十一条）单独拆出，
   与其余五十五条分开统计
```

结果：

```
「会不会拖」类（41 条）：83%   ← 但常识基线本来就高
其余各类（55 条）     ：58%
```

真相是：**七成八是被「问拖延」这一类撑起来的。** 去掉这一类，真实水平是百分之五十八——不算差，但离他自己以为的七成八差得远。

他有点失落，问我：「那我这三个月是不是白练了？」

恰恰相反，这是三个月来最有价值的一天：

```
第1点 发现了一个真实优势：在「判断事情会不会拖」上很准
   → 可以刻意在这一类上多练，把它做成专长

第2点 看到了真实短板：其他题材只有五成八
   → 这就是接下来的训练方向，不用再瞎练

第3点 最重要的是，有了真实的基线
   → 之后的每一次进步都能被测量
```

**一次诚实的统计，胜过十次「感觉挺准」的喜悦。** 前者给你方向，后者只给你安慰。

后来他还做了一件事：把自己的错题按错因分类，做成待改进清单。

```
待改进清单（他的）
  第1类  取句取错（拿了不相关的那句）   █████
  第2类  把吉凶当结论                   ███
  第3类  只答方向不答量级               ████
  第4类  三宫掐错                       ██
```

**正常课例让你熟练，错题让你进步。** 这份清单他每周都看，也是他后来进步最快的原因。

#### 笔记与验证

建立月度盘点表，每月一行：

```
月份 | 新增 | 有效 | 对上 | 部分 | 没对上 | 准确率 | 最大错因
```

每月更新。这张表既是成绩单，也是路线图——**准确率不涨的那个月，就去看「最大错因」那一栏**。

#### 全课收尾三句话

```
第1句 小六壬回答的是「态势与取向」，不是「成不成」
第2句 掐指只要三分钟，掐准需要三周
第3句 不做记录的读课只是一次娱乐；做了记录，才是学习
```

*全课完。读课这件事，真正拉开差距的从来不是掐指的速度，而是记录下来的那几百条反馈。*
