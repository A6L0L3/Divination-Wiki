# 小六壬系统知识库 · 分卷索引

## README · 导览

> 一套按「板块 — 单元」组织的小六壬学习系统。
> 从六宫掌诀到三步起课，从三宫读到案例精读，全部按可落地的方式拆开。

### README_1 这套知识库是什么

小六壬是一套**以农历月、日、时三个数，在六宫之间循环定位**的占断法。它的全部操作只有一件事：**数**。

从大安起正月，数到月份落在哪一宫；再从那一宫起初一，数到日子落在哪一宫；再从那一宫起子时，数到时辰落在哪一宫。三个宫位一出来，课就起完了。没有排盘、没有装卦、没有层层推演——会数数就能起课。

它的别名很多：六壬时课、诸葛马前课、掐指神算。本库统一用「**小六壬**」。

**简单不等于浅。** 六宫的性情、三宫的主次、生克与同气的分寸，都要在案例里慢慢磨。

#### 与其他术法的分工

```
八字（命术）    → 一生格局与运势大势，看长期基调
六爻（纳甲）    → 一件具体事的吉凶与应期
小六壬（掌诀）  → 眼前一事的态势与取向，用月日时三个数掐指即得
```

三门各管一段，**是分工不是高低**。同一件事不必用另一门去「验算」，也不要用一门否决另一门。完整的对比表见 `0_1`。

> **最容易搞混的一点**：小六壬取的月日时是**起课那一刻**的时间，不是出生时间。换一时间再起课，输入变了、三宫也就变了——这正是它不能用来断一生格局的原因。

### README_2 口径说明（请先读）

- 本库内容是**传统文化知识体系与教学整理**，不是可证明的因果科学。宫义、断辞与三宫读法用于帮助理解思路。
- **吉凶是「象的倾向」，不是「事情的结论」。** 大安主稳不等于事情一定成，空亡主落空不等于一定失败。
- **断辞是象，不是清单。** 只取与所问之事对应的句子，不把整首诗逐句往问题上套。
- **配数仅作象数标记**，本库不用于断卦，不作为应期依据。
- **涉及疾病、祭祀、鬼神之句，均为古籍原文的文献引录**，不代表提倡任何仪式、法术或替代医疗。身体不适请及时就医。
- 本库以**三宫古法**为唯一口径。当代衍生的扩展派系（加六亲、加四宫等）与本库起课逻辑不同，了解可以，**不混用**。

### README_4 学习路径

```
第 1 步 · 板块1（六宫与掌诀）
   认六宫 → 背掌诀 → 逐宫读断辞

第 2 步 · 板块2（起课法）
   会三步起课，定出月宫 / 日宫 / 时宫

第 3 步 · 板块3（三宫读法）
   分三宫主次，看生克、同气与空亡

第 4 步 · 板块4（案例精读）
   按题材练读法 → 综合纠偏
```

#### 三条学习提醒

1. **吉凶是象的倾向**，不是事情的结论。
2. **断辞是象**，只取与所问之事对应的句子。
3. **病句作文献引录**，不代表提倡仪式、法术或替代医疗，身体不适请及时就医。

#### 每单元的收尾动作

```
第1步 背：六宫顺序与掌位（手比脑子快）
第2步 掐：用当天农历月日时随手起一课
第3步 写：按「月 → 日 → 时」各写一句象，再回断辞对照
第4步 记：把断语与后来的实际结果写进占验记录
第5步 查：读错的课回到对应单元重读
```

### README_5 笔记与验证：本库的隐形主线

学小六壬最容易停在「能掐出结果」，然后就没有然后了——因为没有回头看过自己读得对不对。

本库把**占验记录**放在与起课同等重要的位置：每个单元末尾都有「笔记与验证」段，板块4_5 给出完整模板与统计方法。核心动作只有三个：

```
第1步 起课当下就记：问题 / 农历月日时 / 三宫落点 / 取了哪句断辞 / 我的读法
第2步 结果出来后回填：实际发生了什么 / 哪句对上了 / 哪句没对上
第3步 定期盘点：最容易读错的宫、最容易犯的误断
```

不做这三步，学再久也只是把口诀念熟；做了这三步，才能形成属于自己的读数手感。

### README_7 快速上手（三分钟版）

```
第1步 记顺序：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡（循环）

第2步 起月宫：从大安起正月，顺时针数到当前农历月

第3步 起日宫：从月宫起初一，顺时针数到当前农历日

第4步 起时宫：从日宫起子时，顺时针数到当前时辰

第5步 读结果：先看时宫（落点），再回看日宫（事体）与月宫（背景）
```

这三步的完整演示、链路图与十道自测题见 `2_3`。

> 掐指只要三分钟，掐准需要三周。想用顺手，请从板块0 开始按路径走。
