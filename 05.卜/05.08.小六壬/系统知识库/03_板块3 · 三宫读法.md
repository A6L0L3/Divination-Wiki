## 板块3 · 三宫读法

> 三宫分工与主次 · 生克与同气 · 空亡与特殊读法

> 本板块 3 个单元。六宫宫义与断辞原文见板块1，此处不重复；本板块只讲「三个宫位放在一起怎么读」。

### 3_1 三宫分工与主次

#### 要点：一、三宫各管一段

三步起课掐出来的三个宫，不是三个答案，而是**一件事的三个层次**：

```
┌──────────────────────────────────────┐
│  月宫 · 背景层                        │
│    这件事所处的环境、外部条件          │
│    他人、时机、事情的来路              │
├──────────────────────────────────────┤
│  日宫 · 事体层                        │
│    这件事本身当下的状态                │
│    事情走到哪一步、卡在哪              │
├──────────────────────────────────────┤
│  时宫 · 落点层                        │
│    这件事最终往哪去                    │
│    读课的主答案在这里                  │
└──────────────────────────────────────┘
```

> **口径说明 · 三宫名目**：本库只用「月宫 / 日宫 / 时宫」，不采「天/人/地」或「初/中/末」等名目。三个名字对应三个输入（月、日、时），名实一致，不容易混。

#### 二、主次怎么分

```
主：时宫（落点）—— 回答「往哪去」，是读课的主答案
次：日宫（事体）—— 回答「眼下怎样」，补充过程
辅：月宫（背景）—— 回答「环境如何」，说明条件
```

**常见的错误**：把三宫当成三个并列的吉凶标签，挑一个「最像」的来读；或者把三宫平均用力，读完不知道重点在哪。

正确的顺序是：

```
先读时宫 → 定基调
再读日宫 → 补过程
后读月宫 → 看条件
最后三宫串成一句话
```

#### 三、先读单宫，再读三宫

```
第一步 · 单宫：每一宫各自是什么象？
   按板块1 的宫义与断辞，各读一句

第二步 · 三宫：三层串起来讲了一个什么故事？
   背景如何 → 眼下怎样 → 最终往哪
```

**不要跳过第一步。** 三宫串读是在单宫读准的基础上做的；单宫读错了，串出来的故事再顺也是错的。

#### 实操：三宫读取流程

```
        掐出三宫
             │
             ▼
    ┌─────────────────┐
    │ 读时宫（主答案） │
    └─────────────────┘
             │
             ▼
    ┌─────────────────┐
    │ 读日宫（过程）   │
    └─────────────────┘
             │
             ▼
    ┌─────────────────┐
    │ 读月宫（环境）   │
    └─────────────────┘
             │
             ▼
    三宫串成一句话剧情
             │
             ▼
    输出：态势 + 取向（该怎么做）
             │
             ▼
    当场记入占验记录
```

#### 四种典型的三宫形态

**形态一 · 一路顺（月吉 → 日吉 → 时吉）**

```
例：月大安 / 日速喜 / 时小吉
读：环境安稳 → 眼下消息快 → 落点是和合
串：事情底子稳，眼下在动，最后谈得拢
断：能推进，但小吉带「小」字，规模有限
```

**形态二 · 先难后易（月不顺 → 日平 → 时吉）**

```
例：月空亡 / 日留连 / 时速喜
读：背景虚 → 眼下拖 → 落点快
串：开头没着落，中间磨一阵，最后会快起来
断：别急，等一等；等到了就别再拖
```

**形态三 · 虎头蛇尾（月吉 → 日吉 → 时不顺）**

```
例：月大安 / 日速喜 / 时空亡
读：环境稳 → 眼下热闹 → 落点抓不住
串：看着挺顺，最后落空
断：过程顺利不等于结果有；留个心眼，别提前投入
```

**形态四 · 从头卡到尾（月不顺 → 日不顺 → 时不顺）**

```
例：月留连 / 日赤口 / 时空亡
读：环境拖 → 眼下冲 → 落点空
串：一路不顺，越走越紧
断：缓一缓，或另择时机；硬来只会更糟
```

#### 三宫矛盾时怎么处理

最常见也最难受的情况：**月吉时凶**或**月凶时吉**。

```
原则：以时宫为主答案，月宫作条件说明

月吉 + 时凶 → 「环境不错，但落点抓不住。别被表面的顺骗了」
月凶 + 时吉 → 「环境不利，但落点是好的。能成，但过程不好受」
```

**月宫是路况，时宫是终点。** 路况好不等于到得了，路况差不等于到不了——但路况会影响到不了的方式。

#### 只用一宫行不行

```
新手期：可以先只看时宫，先把「掐准 + 读懂单宫」练熟
进阶后：必须三宫全读，否则信息浪费严重
```

理由：三宫提供的不是三种答案，而是**一条线索**。只读落点，你就不知道该在哪个环节使劲。

#### 案例小故事：offer 那三宫

朋友拿到一个大公司的录用意向，来问「该不该接」。掐出 **月大安 / 日速喜 / 时空亡**。

他先看了前两宫：大安（稳）、速喜（快），高兴地说「稳了」。

我让他再看第三宫：空亡。

三宫串起来的故事是这样的：

```
月宫大安 → 公司看着很稳，外部环境没问题
日宫速喜 → 流程推得很快，人事很热情，意向很快就发
时宫空亡 → 落点抓不住
```

完整读法：**过程顺利，结果落空**——典型的「虎头蛇尾」形态。

这一课如果只看前两宫，他会栽跟头；如果只看时宫，他会一头雾水（明明一切顺利啊）。三宫连起来，才看得出「**流程走得很顺，但最后一步会出问题**」这个特定剧情。

于是给他的建议不是「别接」，也不是「接吧」，而是落到动作上：

```
第1步 意向照接，但不要立刻辞掉现在的工作
第2步 入职时间往后推一周
第3步 等所有书面材料齐了再动：
   薪资结构、岗位、汇报线的正式文件
```

结果：意向发了，入职前一周，那家公司内部架构调整，岗位被取消。他因为没辞职，**损失为零**。

**这一课的价值，在于断语落到了动作上**：

```
没用的断语：「这事不成」
有用的断语：「意向照接，但等书面齐了再辞职」
```

后来他把这一课记下来，加了一句备注：「凡是月吉 + 时凶的组合，一律加一句『别提前投入』」。

#### 笔记与验证

记录里的「落宫」栏要求三宫全写，并在旁边用一句话串起来：

```
月X / 日X / 时X
一句话串读：______________________
```

**这个「一句话串读」是训练三宫读法最有效的练习**——强迫你把三个符号翻译成一个连贯的剧情。

验证方式：翻出自己最早的二十条记录，看有没有「只记了时宫、没记三宫」的。有，就补记（若还记得的话）；补不了的，标记为「记录不完整」。

### 3_2 生克与同气

#### 要点：一、生克是什么

生克是五行之间的两条基本关系，用来读**态势的传递方向**。

```
相生（顺）：木 → 火 → 土 → 金 → 水 → 木
相克（逆）：木 → 土 → 水 → 火 → 金 → 木
```

记忆法：

```
相生 = 滋养：木燃火、火化土、土藏金、金凝水、水养木
相克 = 制约：木破土、土挡水、水灭火、火熔金、金砍木
```

#### 二、只看两段关系

三宫之间只看两段：

```
月宫 → 日宫：背景对事体的作用
日宫 → 时宫：事体向落点的转化
```

**不看月宫直接对时宫。** 隔一层的关系不读——这是本库的边界，多读一层就会开始编故事。

#### 三、五种关系怎么读

以「后者」为参照：

| 关系 | 含义 | 读法 |
|---|---|---|
| 生我 | 前宫生后宫 | 得助，有人推一把 |
| 我生 | 后宫生前宫（前宫泄气） | 泄气，在付出、在消耗 |
| 克我 | 前宫克后宫 | 受压，有阻碍 |
| 我克 | 后宫克前宫 | 可得，但要费力 |
| 比和 | 五行相同 | 同类相应，特征加强 |

六种五行对照（复习，不展开宫义）：

```
大安 = 木   留连 = 水   速喜 = 火
赤口 = 金   小吉 = 木   空亡 = 土
```

#### 四、双木同气（必记）

**大安与小吉同属木。三宫中若同时出现二者，它们之间不作生克论，只作「同类相应」看。**

```
边界：双木同气只免除【这两宫之间】的生克，
      不免除它们与第三宫的生克。

例：大安 / 小吉 / 赤口
    大安与小吉 → 双木同气，不论生克
    赤口金 克 双木 → 仍然成立
```

#### 五、生不一定吉，克不一定凶

> **口径说明 · 关键**：**生克不是吉凶判断。** 生不一定吉，克不一定凶，必须结合宫义与断辞。

```
生不一定吉：
  日宫生时宫，看似顺畅——但若时宫是空亡，
  「生」只是把能量送进了空处，过程是顺的，结果是空的

克不一定凶：
  时宫克日宫，看似受阻——但若时宫是速喜，
  「克」可能就是「快刀斩乱麻」，事情反而被推着走完
```

#### 六、与八字旺衰划清界限

> **口径说明 · 边界**：三宫生克只用来读**态势的传递方向**（月→日、日→时），**不是五行力量的旺衰比较**。八字的「用神旺衰」是另一套逻辑，不要把八字的生克思维平移过来——那样会算出一堆本库根本不用的强弱结论。

具体说，本库**不读**这些内容：

```
✗ 某宫「旺」还是「衰」
✗ 某宫「得令」「失令」
✗ 某宫力量强弱打分
✗ 用生克反推吉凶强弱
```

#### 实操：生克关系速查

```
以「我」为准：
  生我者（前宫生我） → 得助
  我生者（我生后宫） → 泄气
  克我者（前宫克我） → 受压
  我克者（我克后宫） → 可得但费力
  同我者（五行相同） → 比和 / 同气
```

#### 生克的三步使用法

```
第一步：扫三宫有没有双木（大安 + 小吉）
        有 → 这两宫之间不论生克
第二步：算 月→日 这一段的五行关系
第三步：算 日→时 这一段的五行关系
        两段合起来，就是态势的传递方向
```

#### 三条防过度解读的规则

```
规则一 · 生克不翻转宫义
   时宫空亡，谁生它都是「抓不住」
   时宫小吉，谁克它都是「小成」

规则二 · 生克只调整过程与程度
   不改变「态势往哪走」这个主答案

规则三 · 断辞优先
   生克推出来的结论与断辞冲突时，以断辞为准

限制 · 生克分析不超过三行
   超过三行，多半是在用分析逃避下结论
```

#### 常见组合读法示例

```
第1例 月留连(水) → 日速喜(火)
   水克火 → 背景压制事体
   读：环境里有拖的东西在压着，眼下想快也快不起来

第2例 日速喜(火) → 时空亡(土)
   火生土 → 事体生落点（泄气）
   读：事情的能量流向了空处——过程热闹，落点抓不住

第3例 月大安(木) → 日速喜(火)
   木生火 → 背景生事体
   读：环境在推着事情走，眼下动得起来

第4例 日小吉(木) → 时赤口(金)
   金克木 → 落点克事体（事体受压）
   读：和合的过程最后撞上硬碰硬——谈得拢，收尾有硬坎

第5例 月小吉(木) → 日大安(木)
   双木同气 → 不论生克，同类相应
   读：背景与事体都是木气，这件事从头带着「生发、和合」的底色
```

#### 案例小故事：分析了一整页，忘了回答问题

有位学员学生克之后，读课开始变得极复杂。他觉得「光看宫义太浅」，于是每课都要把五行关系写一遍，再配上六神、再配上方位。写得不亦乐乎，就是不给结论。

一次他读一个「这合同能不能签」的课，写了满满一页：

```
月宫赤口金，日宫大安木，时宫小吉木
金克木，月克日，说明环境压制事体
但日时皆木，双木同气，说明事体与落点是同一类
金克木，说明有外部压力
木克土，但这里没有土，这一段无从谈起
六合主和合，说明谈得拢
白虎主刚烈，说明对方强硬
```

我打断他：「所以，能不能签？」

他愣住了，说不出答案。过了几秒才说：「我再算算？」

**这就是过度解读的典型症状：分析了一整页，忘了回答问题。**

有意思的是，他这一页里其实没有一句是错的——金克木没错，双木同气也没错。错在**没有一句落到实处**。术语越堆越多，离「签还是不签」反而越来越远。来问合同的朋友要的是一句话，不是一篇论文。

让他按三步重来：

```
第一步：扫双木 → 日宫大安(木) + 时宫小吉(木) = 双木同气
        → 这两宫之间不论生克，读作「过程到落点都是和合的底色」
第二步：月→日 → 赤口(金) 克 大安(木)
        → 背景压制事体：环境里有硬的东西在压着
第三步：落点是小吉 → 和合、小成
```

三行，答案就出来了：

```
能签（落点小吉），但对方条件会硬（月宫克日宫），
而且最终只是小成（小吉带「小」字），别指望大赚
```

后来他给自己定了条规矩：**生克分析不超过三行。** 超过三行，就说明你在用分析逃避下结论——而不下结论的读课，等于没读。

这个案例还有第二层价值：它提醒我们**生克是「调味」，不是「主菜」**。主菜永远是宫义与断辞，生克只用来读「态势怎么从这一步传到下一步」。

#### 笔记与验证

记录里加两个字段（进阶后用）：

```
月→日关系：生 / 克 / 比和 / 同气
日→时关系：生 / 克 / 比和 / 同气
```

验证方式：统计「用了生克」与「没用生克」两组课例的读课准确率。**如果用了生克反而更差，立刻停用**——很多人在自己手上是减分项，因为生克引入了过多的主观解释空间。

### 3_3 空亡与特殊读法

#### 要点：一、空亡落在不同宫位，意思不同

宫义见 `1_7`，此处只讲「落在哪一宫」的差别：

```
空亡在月宫 → 背景落空
   这件事的外部环境本身就是虚的：
   对方没定、制度未明、事情还没有实质基础

空亡在日宫 → 事体落空
   事情本身没有实质内容：
   看着在办，其实没有进展、没有内核

空亡在时宫 → 落点落空
   最终抓不住（最常关注的一处）：
   投入归零、事情消失、结果没有
```

#### 二、空亡的反转读法（详见 1_7）

问法不同，读法相反：问「好事能不能成」，空亡是抓不住；问「坏事会不会来」，空亡是落空（对问事人反而是好事）。完整口诀与两个例子见 `1_7 空亡`，此处不重复。

#### 三、吉凶不是结论（总纠偏）

这条在 `1_1` 讲过，这里再从「纠偏」的角度补一层——**它是六条误读里最常见、也最难自觉的一条**。

同一宫，问法不同读法不同：

```
问「稳不稳」     → 大安是稳
问「进不进」     → 大安往往是「暂时不动」
问「有没有转机」 → 空亡往往是「眼下抓不住」，不是「永远没有」
```

把吉凶当结论用，是小六壬最常见的误用。

#### 四、四种常见误读

```
误读一 · 把「静」读成「成」
   大安 = 静。问「会不会有进展」，答「会成」就错了

误读二 · 把「难」读成「绝」
   留连 = 拖。问「能不能办成」，答「没戏」就错了

误读三 · 把「快」读成「成」
   速喜 = 快在讯息。问「能不能成」，答「成了」就错了

误读四 · 把「空」读成「凶」
   空亡 = 没有。问「会不会出事」，答「要出事」就错了
```

#### 实操：特殊读法的三步检查

```
第一步：这一宫有没有「双木」？（决定生克怎么论）
第二步：我这一课的空亡落在哪一宫？（决定「空」的是什么）
第三步：我问的是好事还是坏事？（决定空亡的吉凶方向）
```

#### 完整读课的输出格式

```
【态势】这件事眼下像什么（一句话）
【取向】该怎么做（一个动词开头的具体动作）
【提醒】防什么 / 别做什么
```

**三条缺一不可。** 只答态势不给取向，等于把翻译工作推给了问事的人——而对方不懂六宫，翻译出来的往往是自己想要的那个版本。

#### 断语措辞的边界

```
第1条 说倾向，不说定论
   ✗ 「这事一定不成」
   ✓ 「这事大概率抓不住，建议你做别的准备」

第2条 不顺的课必须配规避方案
   ✗ 「不顺，小心」
   ✓ 「赤口主冲撞。这次出门前检查车况，重要谈话留书面记录」

第3条 三条硬边界
   医疗：不说「你没病」「你会好」，一律「以医生诊断为准」
   法律：不说「一定赢/输」，说「宜和解 / 宜准备材料」
   财务：不说「一定会赚/亏」，说「风险偏高，建议控制投入」
```

#### 案例小故事：一句「你没病」

有位学了几个月小六壬的爱好者，给邻居阿姨读课。阿姨说最近胃不舒服，他掐出**大安**，看到断辞「病者主无妨」，就说：「没事，卦上说你没病。」

阿姨信了，没去体检。三个月后确诊，是早期病变，拖了三个月。

复盘一下错在哪：

```
错误一 · 断辞理解错误
   「病者主无妨」是古人对「病势不凶险」的描述，
   不是「没有病」的医学结论

错误二 · 越界使用
   断辞里涉及「病」的部分，是民间经验的粗略归纳，
   完全没有诊断能力

错误三 · 措辞绝对化
   即便要读，也应该是「卦上看凶险程度不高，
   但仍建议您尽快做个检查」
```

后来他给自己定了条铁律，也写进了自己的笔记：

```
凡是涉及身体、法律、大额钱财的问事，
断语一律以「请走专业渠道」收尾，术数部分只作思路提示
```

这不是推卸责任，是对边界的尊重——**一把用来读「眼前顺不顺」的小折刀，不该拿去做手术。**

补充一个正面的例子：另一位学员遇到邻居问「最近总是头晕，要不要紧」。她掐出**空亡**。按断辞这是最不顺的一宫，但她的读法是：

```
「卦上看这个情况不太明朗，有『查不出原因』的意思。
 我不懂医，但这个结果提示你应该去做个全面一点的检查，别拖。
 如果第一家医院说没问题，建议换个医院再看看。」
```

邻居去做了全面检查，发现是血压问题，及时控制了。

**空亡在这个场景里的价值，不是「凶」，而是「别满足于一次查不出就放心」。** 这个读法既守住了边界，又真的帮到了人。

#### 笔记与验证

记录里加一个字段：**问题性质（求成 / 避险）**。

```
求成：问好事能否成、能否推进
避险：问坏事会不会来、会不会出问题
```

验证方式：分别统计两组的准确率。**如果避险类明显偏低，说明你还没掌握空亡的反转读法**——回 `1_7` 重读「空亡的反转读法」。
