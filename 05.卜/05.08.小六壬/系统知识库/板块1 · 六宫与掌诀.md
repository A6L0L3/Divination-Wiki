## 1_1 小六壬总表与掌诀

### 要点

### 一、小六壬是什么

小六壬是一套**以月、日、时三个数在六宫之间循环定位**的占断法。它的全部操作只有一件事：数。

从「大安」起正月，数到月份落在哪一宫；再从那一宫起初一，数到日子落在哪一宫；再从那一宫起子时，数到时辰落在哪一宫。三个宫位一出来，课就起完了。

没有排盘、没有装卦、没有五行旺衰的层层推演。**它是五术里入门门槛最低的一门**——会数数就能起课。

也正因为它简单，容易被人看轻。但简单不等于浅：六宫之间的生克、三宫之间的先后关系、每一宫断辞里藏着的分寸，都要慢慢磨。

### 二、名字与来历：先把「小」说清楚

小六壬又叫「六壬时课」「诸葛马前课」「掐指神算」。本库正式名用「小六壬」。

关于来历，常见两说：

- 一说脱胎于古代择日术的「六曜」符号；
- 一说是大六壬的民间简化版。

**两说均待考。** 本教材不把「简化版」当定论，也不因为名字里有个「小」字，就把它说成「残缺版」。名字是民间通名，不是学术判定。

> 三个别名来源不同：「六壬时课」多与李淳风传统绑定（底本即题「李淳风六壬时课」）；「诸葛马前课」属另一条托名传说，成书较晚；「掐指神算」是民间俗称。三名并置只表示民间流通中常被混称，**不代表同源**。

### 三、六宫的名称与顺序

六宫依次是：

**大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡**

这个顺序**固定不变**。数到第六宫之后回到第一宫，如此循环。

记住这个顺序，是学小六壬的第一件事。后面所有的起课、所有的推算，都建立在这个循环上。

### 四、六宫总表

| 宫 | 五行 | 方位 | 六神 | 吉凶 | 核心象 |
|---|---|---|---|---|---|
| 大安 | 木 | 东 | 青龙 | 吉 | 稳、静、守成 |
| 留连 | 水 | 北 | 玄武 | 不顺 | 拖、暗、牵连 |
| 速喜 | 火 | 南 | 朱雀 | 吉 | 快、讯息、动静 |
| 赤口 | 金 | 西 | 白虎 | 不顺 | 冲、口舌、硬碰硬 |
| 小吉 | 木 | — | 六合 | 吉 | 和合、谈得拢 |
| 空亡 | 土 | 中 | 勾陈 | 不顺 | 落空、迟滞、抓不住 |

> **口径说明 · 小吉的方位**：宫位常配里不单列方位。断辞里的「失物在坤方」是**失物这一句的取象**，不是小吉的固定方位。不要把断辞里的方位当成宫位常配。

### 五、五行只有五个，六宫却有六个

五行只有五个，六宫却有六个，所以必然有一行重复。在小六壬里，重复的是**木**——大安与小吉同为木。

这不是笔误，也不是哪一家的私改。六宫配五行本来就是象数上的安排，不是五行均分。

由此得到一条必须记住的规则：

**双木同气**：三宫中若同时出现大安与小吉，二者同属木，**不作生克论**，只作「同类相应」看。

注意边界：**双木同气只免除这两宫之间的生克，不免除它们与第三宫的生克。** 例如三宫为大安、小吉、赤口，大安与小吉之间不论生克，但赤口金对双木的克仍然成立（金克木）。

### 六、吉凶三分：象的倾向，不是判决书

六宫按倾向分三吉、三不顺：

- **三吉**：大安、速喜、小吉
- **三不顺**：留连、赤口、空亡

> **口径说明 · 要紧的一句**：**吉凶是「象的倾向」，不是「事情的结论」。**

大安主稳，不等于事情一定成；空亡主落空，不等于一定失败。六宫给的是**这件事当下的态势像什么**，不是判决书。

同一个宫，问法不同，读法也不同：

- 问「稳不稳」，大安是稳；
- 问「进不进」，大安往往是「暂时不动」；
- 问「有没有转机」，空亡往往是「眼下抓不住」，不是「永远没有」。

把吉凶当结论用，是小六壬最常见的误用。

### 七、六神：宫义为主，六神为辅

六神是六宫的另一个标签，用来提示该宫的「性情」：

- **青龙**主生发、主正——大安的稳，是往好里稳；
- **玄武**主暗昧、主隐——留连的拖，常拖着说不清的东西；
- **朱雀**主口舌、主讯息——速喜的快，多半快在消息上；
- **白虎**主刚烈、主伤——赤口的凶，凶在冲撞；
- **六合**主和合——小吉的吉，吉在「谈得拢」；
- **勾陈**主迟滞、主纠缠——空亡的空，是抓不住。

**六神不是独立判据，是帮你体会那一宫的性情。** 断课时宫义为主，六神为辅。不要看到白虎就说「一定受伤」，也不要看到六合就说「一定成」。

### 实操

### 八、掌诀：把六宫装到手上

小六壬最方便的地方，是它**不需要纸笔**。六宫的位置定在手上，掐指一数就出来。

以左手为例，六宫分布在食指、中指、无名指上：

| 宫 | 位置 |
|---|---|
| 大安 | 食指根 |
| 留连 | 食指尖 |
| 速喜 | 中指尖 |
| 赤口 | 无名指尖 |
| 小吉 | 无名指根 |
| 空亡 | 中指根 |

```
              左 手 掌 诀 图（掌心朝己，指尖朝上）

              食指        中指       无名指
            ┌───────┐   ┌───────┐   ┌───────┐
            │ 留连  │   │ 速喜  │   │ 赤口  │
            │  第2  │   │  第3  │   │  第4  │
            ├───────┤   ├───────┤   ├───────┤
            │ 大安  │   │ 空亡  │   │ 小吉  │
            │  第1  │   │  第6  │   │  第5  │
            └───────┘   └───────┘   └───────┘
             指根       指根       指根

   拇指、小指不参与掐算
   顺时针一圈：第1大安 → 第2留连 → 第3速喜 → 第4赤口 → 第5小吉 → 第6空亡 → 回到第1
```

**掐算方向**：食指根 → 食指尖 → 中指尖 → 无名指尖 → 无名指根 → 中指根 → 回食指根，**顺时针一圈**。

> **口径说明 · 两套坐标，各管一段**：六宫在手上的位置是掐算的**物理落点**，**不等同于十二地支掌的支位**——不要把地支掌的「寅位」「卯位」套到六宫上，也不要用六宫位置去反推地支。小六壬只认「大安→留连→速喜→赤口→小吉→空亡」这个顺序，不给六宫与地支的逐宫对应表。宫位总表里的「东/南/西/北/中」是五行—六神系统下的常配方位。二者不是同一层——不要把「留连在食指尖」读成「留连方位在东南」，也不要拿总表的「北」去和掌诀位置对账。

三个记忆要点：

```
1. 三根手指，六个点——每根手指取根、尖两处
2. 三吉大致在「角」上：大安（食指根）、速喜（中指尖）、小吉（无名指根）
3. 顺序是顺时针一圈，不是跳着数
```

记不住的时候，默念「**大留速赤小空**」六字，手跟着走一遍。走熟了，手比脑子快。

### 九、读断辞的三条规矩

```
1. 先读宫义，再读断辞
   断辞是象，不是 checklist；不要拿整首诗逐句往问题上套

2. 只取与所问之事对应的句子
   问失物看「失物」，问行人看「行人」，问口舌看「官非/口舌」；
   不问病，就不要拿「病者」句来断

3. 断辞有异文
   本库取定本口径；遇到异文在「待考与异文」里说明，
   不把一句诗说成绝对结论
```

### 十、断辞总注（先读这条）

> **口径说明**：六宫断辞中涉及疾病、祭祀、鬼神之语——大安「病者主无妨」、速喜「病者无祸侵」、赤口「恐怕染瘟殃」、小吉「病者祈上苍」、空亡「病人逢暗鬼，禳解可安康」——均为**古籍原文的文献引录**，不代表本库提倡任何仪式、法术或替代医疗。**身体不适请及时就医。**

「禳」是古代祭祷消灾之俗。收录原文是为了文献完整；加这条总注，是为了不让人把「禳解」读成「建议你去做仪式」。两者不冲突：字要准，话要说清。

> 总注逐宫列明，不用「如某某等」这种概括写法：漏掉一条就等于漏一半。赤口「恐怕染瘟殃」涉疫病，是六宫中第二高危的一句，不能被一个「等」字略过。

### 十一、待考与异文

| 项 | 说明 |
|---|---|
| 起源 | 两说并列：一说脱胎于古代择日术「六曜」符号；一说为大六壬的民间简化版。**两说均待考**，不把「简化版」当定论 |
| 大安首句 | 「求谋在东方」（本库正文取此，见于民间「小六壬时课」抄本系统）／「求财在坤方」（另一系统通行本多作此）。两说并存，本库暂不改正文 |
| 空亡首句 | 「事不祥」（本库正文取此，民间抄本系统）／「事不長」（多种整理本作此）／「事不禅」为再传异写。三说并存，本库暂从「事不祥」 |
| 赤口字形 | 「咀咒」（本库正文取此）／「咒诅」（通行整理本多见）——字形异文，各本互见，不影响宫义 |
| 速喜失物 | 「失物申未午」一作「失物申午未」；本库取「申未午」，并按**方位义**读 |
| 留连急讨 | 「急讨方遂心」一作「急寻方心明」；本库取「急讨方遂心」 |
| 空亡末句 | 「禳解可安康」一作「析解可安康」；本库取「禳解」 |
| 六宫五行 | 留连「水/土」、小吉「木/水」、空亡「土/水」各派有别；本库取「留连水、小吉木、空亡土」 |
| 别名归属 | 三个别名来源不同，**不代表同源**（见本节二） |
| 三宫名目 | 本库只用「月宫/日宫/时宫」，不采「天/人/地」或「初/中/末」 |
| 配数 | 仅象数标记；一说用于应期，说法不一，**不作为断卦依据**（详见 `2_1`） |

### 十二、本单元要点

```
· 六宫顺序固定：大安→留连→速喜→赤口→小吉→空亡，循环不息
· 五行六宫必有重复，本库取「木重出」（大安、小吉）
· 双木同气：大安与小吉之间不作生克，与第三宫仍论生克
· 吉凶是象的倾向，不是结论；同一宫问法不同，读法不同
· 断辞是象，只取与所问之事对应的句子；病句为文献引录，不作医疗判断
· 掌诀位置是物理落点，不与地支掌混用
```

### 案例小故事：一课出了两个木

有同学掐出一课：月宫大安、日宫小吉、时宫赤口。他兴冲冲地来报：「大安属木，小吉也属木，那大安对小吉是生还是克？木生木，这怎么论？」

这一课正好撞上了「双木同气」的规则。他的困惑是典型的——拿到两宫，第一反应就是找生克关系，找不到就卡住了。

正确的处理分两步：

```
第一步：看这两宫是不是双木
   大安 = 木，小吉 = 木 → 是双木 → 二者之间【不作生克论】
   读作：同类相应——背景与事体都是「木气」，
        即这件事从环境到本体都带着「生发、和合」的底色

第二步：再看第三宫
   时宫赤口 = 金，金克木 → 赤口对双木的克【仍然成立】
   读作：落点上有冲克——事情最终会撞上硬碰硬的东西
```

串起来的读法：这件事从头到尾都是温和的路子（双木），但结果撞上了冲撞（赤口克木）——**过程好说好商量，收尾却有一道硬坎**。

他问的是「跟合作方谈条款顺不顺」，这一课的读法就很贴切：谈的过程很和气，但到最后签的时候，对方会在某一两个条款上硬来。

后来的实际情况：谈了三轮都很顺利，签合同前一天，对方在付款周期上突然改口，要求从三十天改成六十天，态度很硬。

**如果他当初按「大安生小吉」去找生克关系，这一课就读废了。** 双木同气这条规则的作用，恰恰是告诉你：这两宫之间不用找关系，直接看它们与第三宫的关系。

这个案例还有第二层价值：它说明了为什么「吉凶不是结论」。这一课三宫里有两个吉（大安、小吉），看上去是好课，但落点是赤口——**过程好不等于结果好**。

把下面这张表抄进笔记首页，作为你读课时的第一道检查：

```

```

## 1_2 大安

### 要点

本单元只读一宫：**大安**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**木 · 东 · 青龙 · 吉**

「安」字是这一宫的纲。安是稳、是不动、是守住现有的东西。

### 断辞与逐句释义

**大安事事昌，求谋在东方，失物去不远，宅舍保安康，行人身未动，病者主无妨，将军回田野，仔细更推详。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 大安事事昌 | 总纲。事情整体是顺的 | 「昌」是兴旺、太平，**不是大获全胜**。大安给的是平安，不是大利 |
| 求谋在东方 | 方位提示 | 谋事往东。方位只作提示，不作唯一依据 |
| 失物去不远 | 东西没丢远 | 就在近处，不必往远处找 |
| 宅舍保安康 | 家宅平安 | 这是大安最本色的地方，问家宅最为贴切 |
| 行人身未动 | 问行人，人还没动身 | 大安「不动」之性最直接的体现 |
| 病者主无妨 | 问病无大碍 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |
| 将军回田野 | 解甲归田之象 | 功成身退、由动转静 |
| 仔细更推详 | 收尾提醒 | 大安虽吉也要细看，不能一句「昌」就了事 |

### 大安的误断

**见「大安」就说「很好、没问题」。**

大安是「静」，问「事情会不会有进展」时，大安往往意味着**暂时不动**。静是安，也可能是停滞。要看问的是什么。

```
问「稳不稳」 → 大安是稳（贴切）
问「进不进」 → 大安往往是「暂时不动」
问「有没有危险」 → 大安是无碍
```

### 实操

### 读大安的三步

```
第一步：定性——这是「静」象，不是「成」象
第二步：取句——问什么取什么句，不拿整首诗套
第三步：留口——「仔细更推详」提醒你：单宫不够，要看三宫
```

### 与其他宫的对照

```
大安（静） vs 速喜（快）
   同为吉，一动一静。问「什么时候动」，速喜快、大安不动

大安（守成） vs 小吉（和合）
   同为吉，大安是守住现有的，小吉是谈得拢的
```

### 案例小故事：一句「很好」耽误了两周

有位同事问：「我投的那个内部岗位，这周会有消息吗？」掐出时宫**大安**。

帮忙读课的同学看了「大安事事昌」，顺口说：「吉，很好，等着吧。」

于是同事真的就等着了。两周过去，一点动静都没有。他再来问，重掐一次——这次时宫是**速喜**。

同一件事，两个不同时刻的课，读法完全不同：

```
第一次（大安）：事情眼下不动 —— 正确的读法是「这周不会有消息，别干等」
第二次（速喜）：消息来得快   —— 正确的读法是「快了，主动去问一句」
```

他后来真的发了封邮件去问，当天下午就收到了面试安排。

回头看，那次误断的根源不在「大安是吉还是凶」的判断，而在**把「静」读成了「成」**：

```
错误链条：
  大安 → 吉 → 很好 → 等着就行
正确链条：
  大安 → 静 → 眼下不动 → 这周不会有消息 → 别干等，该做什么做什么
```

大安的断辞里其实早就写明了这一层——「**行人身未动**」。人还没动身，怎么会来消息？这句断辞他根本没取，因为他的注意力被开头的「事事昌」三个字抓走了。

**这就是「先读宫义，再读断辞」的意义**：宫义（静）是纲，断辞是象。纲拿错了，取哪句都会偏。

后来他在自己的笔记里写了一条备忘：

```
大安 = 静。凡问「会不会动 / 什么时候动 / 有没有进展」，
      大安一律先读「暂时不动」，再补一句「不是不成，是没动」
```

### 笔记与验证

大安课的记录，重点记两个字段：

```
第1项 我问的是「稳不稳」还是「进不进」？（决定读法）
第2项 我取了哪一句断辞？（「昌」还是「不动」还是「去不远」）
```

验证方式：翻出所有大安课，检查有没有把「静」读成「成」的。凡是问进展而答「会成」的，标记为误读，回本单元重读「大安的误断」。

## 1_3 留连

### 要点

本单元只读一宫：**留连**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**水 · 北 · 玄武 · 不顺**

「留」是滞留，「连」是牵连。这一宫的关键词是**拖**。

### 断辞与逐句释义

**留连事难成，求谋日未明，官事只宜缓，去者未回程，失物南方见，急讨方遂心，更须防口舌，人事且平平。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 留连事难成 | 直接说破：事情难成 | 是「难成」，**不是「必败」** |
| 求谋日未明 | 谋事时天还没亮，时机未到 | 信息不全，还有你看不见的环节 |
| 官事只宜缓 | 官司、纠纷宜缓不宜急 | 硬来会更糟 |
| 去者未回程 | 走的人还没回来 | 问归期：还没踏上归途 |
| 失物南方见 | 失物往南找 | 方位取象，南方优先 |
| 急讨方遂心 | 想要的东西得赶紧去讨 | **主动讨，拖了就没了** |
| 更须防口舌 | 要防口舌是非 | 少争辩，留痕 |
| 人事且平平 | 人情往来平平 | 不好不坏，无大碍也无惊喜 |

### 留连的误断

**见「难成」就判死。**

留连的「难」难在**迟**，不是难在**绝**。玄武主暗昧，很多事是「说不清、推不动」，不是「办不成」。缓一缓、等一等，往往是留连的正解。

```
错误：留连 → 事难成 → 没戏了 → 放弃
正确：留连 → 拖 → 推不动、说不清 → 缓一缓 / 主动去讨
```

注意「急讨方遂心」这一句：它是留连里**唯一带动作指令**的一句。留连虽然主拖，但不是让你躺平——想要的东西得主动去讨，只是讨的过程会拖。

### 实操

### 读留连的三步

```
第一步：定性——这是「拖」象，不是「绝」象
第二步：判断——是「说不清」还是「推不动」？
        说不清（玄武主暗昧）→ 先补信息
        推不动（留连主滞留）→ 先缓，别硬来
第三步：取动作——涉及「要东西 / 要答复」的，取「急讨方遂心」，主动去讨
```

### 五行口径

> **口径说明 · 五行**：本库从底本作「**水**」；坊间另有「火」「四角土」等排布，各有所本，**不取**——详见 `1_1`「待考与异文」。

### 案例小故事：两万块的四个月

同事老周借给朋友两万块，说好一个月还。两个月过去，一点动静都没有，发消息也只回「最近手头紧」。他来问：「这钱还能要回来吗？」

起课时是农历六月十四，申时。掐出来：**月宫小吉 / 日宫留连 / 时宫留连**。

他只扫了一眼日宫和时宫，看到两个「留连」，脸色就变了：「留连事难成，那是要不回来了？」

我们先按宫义重读一遍：

```
留连 = 拖，不是绝
   → 钱不是没了，是卡住了
   → 「求谋日未明」：对方那边有你看不见的情况（可能确实周转不开）
   → 「急讨方遂心」：想要回来，得主动去讨，拖着不动就真没了
```

再补上他漏看的月宫——小吉：

```
月宫小吉 → 背景是「和合」
   → 对方不是存心赖账，关系还有得谈
   → 这也意味着：别一上来就撕破脸，商量比施压有效
```

三宫连起来是：关系没破裂（月小吉），但眼下卡着（日留连），而且还会继续卡（时留连）——**会拖很久，但不是死账。**

于是给他的读法和动作是分开的两件事：

```
读法（态势）：这笔钱会拖，短期内不会自动回来
动作（取向）：你自己开口去讨，而且要做好讨三次以上的准备
```

具体建议：

```
第1步 别等对方主动，你先开口
第2步 态度温和，但要求要明确，不要用「方便的时候再说」这类含糊说法
第3步 全程用文字（微信），不打电话，留痕
第4步 每次讨完给一个明确的时间点，下次按那个点再问
第5步 「更须防口舌」——不要在情绪上跟对方起冲突
```

结果：他第一次开口，对方说「下个月」；一个月后转了五千；第三次讨，转了一万；最后一笔又拖了一个月才还清。前后四个多月，中间确实有过两次不愉快——「更须防口舌」也验了。中途他还一度想找共同朋友去施压，被拦住了：月宫是小吉，一撕破脸就把「和合」的底子打掉了，反而更难收。

**这一课的教训有三条**：

```
一、留连 ≠ 不成
   如果当初读了「没戏」而放弃，这两万块就真没了。
   「难成」说的是过程难，不是结果绝。

二、留连的「拖」是双向的
   你拖着不讨，它就一直拖；你按「急讨方遂心」主动去要，
   它才会一格一格往前挪。

三、别只读落点
   他一开始只看了日宫和时宫，把月宫跳过了。
   而恰恰是月宫的小吉在说「这事还谈得拢」——
   这一条决定了整套动作的调子：商量，而不是施压。
```

老周后来说，最有价值的不是「能不能要回来」这个答案，而是那句「要做好讨三次以上的准备」——**有了这个预期，他就没在第一次碰壁时放弃。**

### 笔记与验证

留连课的记录，加两个专用字段：

```
第1项 最终结果：成了 / 没成 / 部分成（留连常应「拖很久最后成」）
第2项 拖了多久：____（留连最该统计的就是时间）
```

验证方式：统计自己所有留连课里「最终成了」的比例。很多人会发现这个比例远高于自己最初的预期——这正是「难成≠必败」的证据。

## 1_4 速喜

### 要点

本单元只读一宫：**速喜**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**火 · 南 · 朱雀 · 吉**

「速」是快，「喜」是喜讯。这一宫的关键词是**消息来得快**。

### 断辞与逐句释义

**速喜喜来临，求财向南行，失物申未午，逢人路上寻，官事有福德，病者无祸侵，田宅六畜吉，行人有音信。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 速喜喜来临 | 喜事将至 | 主「将至」，不是说已成 |
| 求财向南行 | 求财往南 | 方位提示 |
| 失物申未午 | 失物往**南至西南**一带找 | 申、未、午是地支，此处取**方位**义：午为正南，未、申为西南 |
| 逢人路上寻 | 在路上问人，能问到 | 重点是「问人」，不是「翻东西」 |
| 官事有福德 | 官司有转机 | 宜主动解决 |
| 病者无祸侵 | 问病无凶 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |
| 田宅六畜吉 | 家业、六畜都吉 | 问家宅、问宠物，吉 |
| 行人有音信 | 问行人，有消息来 | **消息先到，人未必立刻到** |

> **判据 · 为什么「申未午」取方位**：同一组断辞里，留连作「失物**南方**见」、小吉作「失物在**坤方**」，用的都是方位词；速喜这一句用干支，当与同组一致取方位。若按时辰解，则与其余五宫的写法脱节。这是本库取义，不是唯一古法。

### 速喜的误断

**把「快」当「成」。**

速喜主**讯息快、动静快**，事情确实在动，但动得快不等于成得稳。朱雀主口舌，速喜的「喜」常伴随「说」——**消息来了，事情本身还在后头**。

```
错误：速喜 → 喜来临 → 成了
正确：速喜 → 快 → 消息快、动静快 → 事情在动，但还在路上
```

### 实操

### 读速喜的三步

```
第一步：定性——这是「快」象，快在【讯息】与【动静】
第二步：分清楚——是「消息快」还是「事情快」？
        速喜首先验的是消息（行人有音信、逢人路上寻）
        事情本身成不成，要看三宫，不能只凭这一宫
第三步：配动作——速喜主「速」，遇到它宜早不宜迟
```

### 与其他宫的对照

```
速喜（快） vs 大安（静）
   同为吉，一动一静。问「什么时候有消息」，速喜快、大安不动

速喜（讯息） vs 小吉（和合）
   同为吉，速喜快在消息，小吉吉在谈得拢
```

### 案例小故事：消息来了，事情还在后头

朋友小陈投了一份简历，等了一周没回音，来问：「这两天会有消息吗？」掐出时宫**速喜**。

帮忙读课的同学说：「速喜，喜来临，稳了。」

小陈很高兴，跟家里说「差不多定了」。结果第二天确实收到了一封邮件——**是一封系统自动发的「已收到简历」确认信**，不是面试邀约。他空欢喜一场。

这一课其实读得很准，只是读的人把「快」读成了「成」：

```
正确的读法链条：
  速喜 → 讯息快 → 「会有消息」→ 消息是【音信】，不一定是【结果】

断辞里写得很清楚：
  「行人有音信」——是音信，不是人到
  「逢人路上寻」——在路上，是过程，不是终点
```

后来我们重新按三宫读了一遍：

```
月宫留连：背景是拖的（这家公司的招聘流程本来就慢）
日宫速喜：眼下消息快（会有回音）
时宫速喜：落点也是快
```

完整的读法应该是：**这两天会有消息，但那是流程上的回应，不是最终结果；真正的决定还得等一阵，因为背景是留连。**

小陈补了一句关键动作——既然「逢人路上寻」，那就主动去找人问。他托一位在那家公司工作的学长内推了一下，两周后拿到了面试。

**这一课的价值在于区分了「消息」与「结果」**：

```
速喜验的是：消息来得快、事情有动静
速喜不验的是：事情一定成
```

小陈后来在自己的笔记里给速喜写了一句备忘：

```
速喜 = 快，快在【消息】。
      凡问「有没有回音 / 什么时候有动静」，速喜最灵；
      凡问「能不能成」，速喜只答「在动」，不答「成了」
```

这个区分让他在后来的读课里少犯了很多错——因为他不再把「有消息」当成「有结果」了。

### 笔记与验证

速喜课的记录，加一个专用字段：

```
第1项 应的是「消息」还是「结果」？
   消息（有回音 / 有动静 / 有线索）
   结果（事情成了 / 办完了）
```

验证方式：统计自己速喜课里「应消息」与「应结果」的比例。多数人会发现「应消息」远多于「应结果」——这正是「快在讯息」的证据，也提醒你别把速喜当「成」来读。

## 1_5 赤口

### 要点

本单元只读一宫：**赤口**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**金 · 西 · 白虎 · 不顺**

「口」是口舌，「赤」是血色。这一宫的关键词是**冲撞**。

### 断辞与逐句释义

**赤口主口舌，官非切要防，失物急去寻，行人有惊慌，鸡犬多作怪，病者出西方，更须防咀咒，恐怕染瘟殃。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 赤口主口舌 | 口舌是非是这一宫的本色 | 少说少争 |
| 官非切要防 | 官司、纠纷要防 | 合同凭证补齐 |
| 失物急去寻 | 东西丢了赶紧找，晚了就没了 | **速度是关键**，不是慢慢找 |
| 行人有惊慌 | 问行人，人多半受了惊 | 主动联系确认安全 |
| 鸡犬多作怪 | 家宅不宁之象 | 引申：器物、设备易出状况 |
| 病者出西方 | 古法以西方为病象 | **文献引录，不构成就医方向建议**，身体不适请及时就医 |
| 更须防咀咒 | 古法对背后口舌、暗算的取象 | **不作诅咒实指** |
| 恐怕染瘟殃 | 古法对传染、牵连的警示语 | 文献引录，不作疾病预测 |

### 赤口的误断

**见「口舌」就以为只是吵架。**

赤口属金、配白虎，主的是**硬碰硬的冲撞**——不只是说话难听，也可能是争执、诉讼、外伤。断的时候要看问的是什么事。

```
问「会不会吵架」    → 口舌（吵架）
问「出行顺不顺」    → 冲撞（事故、车辆故障）
问「这事能不能谈成」→ 硬碰硬（对方态度强硬）
问「会不会受伤」    → 刚烈主伤（外伤之象，不作判断，注意安全）
```

### 实操

### 读赤口的三步

```
第一步：定性——这是「冲」象，硬碰硬，不是拌嘴
第二步：看问的是什么事——同一宫，问不同事，取的象不同
第三步：配规避——赤口是三不顺里最「可防」的一宫，务必给出防什么
```

### 赤口的规避清单（实用）

```
防口舌 → 少说话，重要沟通用文字，留痕
防官非 → 合同条款补齐，不签模糊条款，不做口头约定
防冲撞 → 出行前检查车况，慢行，避开高峰
防器物 → 重要设备、数据提前备份与检查
防暗算 → 不把关键底牌一次亮完
```

**赤口的价值就在规避**：它不是告诉你「要倒霉」，而是告诉你「防什么」。

### 案例小故事：一份没检查的合同

朋友开了家小工作室，接了个单子，对方发来合同让他签。他掐了一课，时宫**赤口**。

帮忙读课的同学说：「赤口主口舌，小心跟对方吵架。」

他听进去了，整个沟通过程都很客气，一句重话没说。合同也签了。半年后出问题——合同里有一条「验收标准由甲方单方认定」，对方据此扣了三成尾款。

回头看，那条口舌根本不在沟通里，而在**合同条款**里。

正确的读法应该是按「问的是什么事」来取象：

```
问的是「这合同能不能签」
  → 赤口的首要象不是「吵架」，而是「官非切要防」
  → 官非要防什么？防的是条款漏洞、防的是模糊表述
  → 动作：把合同逐条看一遍，特别是验收标准、付款条件、违约责任
```

而这一课的断辞里其实给了两条线索：

```
「官非切要防」  → 防的是规则层面的东西（合同）
「失物急去寻」  → 有东西在流失，要赶紧处理
```

如果当初按这两句读，他会在签之前把合同过一遍，那条「单方认定」大概率会被发现。

**这一课的教训**：赤口是三不顺里最具体的一宫，它的每一句断辞都指向一类可以提前防的事。把它简化成「小心吵架」，等于把六句断辞砍成了一句。

他后来给自己做了一张赤口排查表，凡是掐到赤口，就照着过一遍：

```
赤口排查表
  □ 合同 / 条款看过了吗？
  □ 重要沟通留痕了吗？
  □ 车况 / 设备检查了吗？
  □ 数据备份了吗？
  □ 这两天有没有要硬碰硬的场合？（有则缓一天）
```

这张表后来帮他躲过几次小麻烦。

### 笔记与验证

赤口课的记录，加一个专用字段：

```
第1项 我给出规避建议了吗？（有 / 无）
第2项 实际发生的，是「口舌」还是别的象（冲撞 / 官非 / 器物）？
```

验证方式：统计自己赤口课里「实际发生的象」的分布。如果你发现绝大多数都记成「口舌」，说明你可能只读了第一句——回去重读「赤口的误断」。

## 1_6 小吉

### 要点

本单元只读一宫：**小吉**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**木 · 六合 · 吉**

「小」是规模，「吉」是方向。这一宫的关键词是**和合、谈得拢**。

> **口径说明 · 方位**：宫位常配里**不单列方位**。断辞里的「失物在坤方」是失物这一句的取象，不是小吉的固定方位（见 `1_1`）。

### 断辞与逐句释义

**小吉最吉昌，路上好商量，阴人来报喜，失物在坤方，行人即便至，交易甚是强，凡事皆和合，病者祈上苍。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 小吉最吉昌 | 吉，但有个「小」字 | 是「吉昌」，不是「大获」。规模有限 |
| 路上好商量 | 出行吉，路上谈事易成 | 宜面谈、宜协商，不宜硬来 |
| 阴人来报喜 | 有女性一方带来好消息 | 留意来自女性角色的信息 |
| 失物在坤方 | 失物往西南、低处、承载之物找 | **这是失物句的取象，不是小吉的固定方位** |
| 行人即便至 | 问行人，人快到了 | 归期近 |
| 交易甚是强 | 买卖、谈判有利 | 宜成交，规模适中 |
| 凡事皆和合 | 以和为贵 | 协商优于强攻 |
| 病者祈上苍 | 问病需调养 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |

### 小吉的误断

**把「吉」字单独拿出来用。**

小吉的吉，是**有条件的吉**：条件就是「和」与「小」。

```
错误：小吉 → 吉 → 能成、能赚、能拿下
正确：小吉 → 和合 + 小 → 谈得拢、能成但规模有限
```

两个常见的偏差：

```
偏差一：只说方向不说规模
   「能成」→ 对方会脑补成「成我想要那么大」
   应说：「能成，但只是小成」

偏差二：把「和合」读成「自动成」
   小吉的吉在「谈得拢」，前提是你去谈
   不谈，和合就没有着力点
```

### 实操

### 读小吉的三步

```
第一步：定性——这是「和」象，吉在谈得拢
第二步：带上「小」字——断语里必须出现量级，别只说吉
第三步：配动作——「路上好商量」「凡事皆和合」都指向【协商】，
        所以动作是：去谈、去商量、找中间人
```

### 与其他宫的对照

```
小吉（和合） vs 大安（守成）
   同为吉，同属木（双木同气）。
   大安是守住现有的，小吉是谈拢新增的

小吉（渐进） vs 速喜（快速）
   同为吉，速喜快在消息，小吉慢在商量
```

### 案例小故事：那个「小」字值三分之一

个体店主老徐问：「这批货我能不能吃下来？打算把流动资金全压上。」掐出时宫**小吉**。

帮忙读课的同学说：「小吉最吉昌，能吃！」

老徐很高兴，准备全额吃下。临付款前，他多问了一句：「能赚多少？」

这一问，读课的人才注意到断辞开头那个「小」字：

```
「小吉最吉昌」——吉昌不假，但宫名就叫「小吉」
  → 能成，规模有限
  → 利润不会是爆发式的
  → 全额压上的风险与「小成」的回报不匹配
```

于是改了建议：

```
第1步 可以吃，但只吃一半
第2步 留足周转金
第3步 不要为凑量去借贷
第4步 「交易甚是强」「凡事皆和合」——跟供货商好好谈，
   争取分批提货、先付一部分
```

老徐听了，只进了一半的货，并且跟供货商谈成了分两批付款。

结果：货确实卖了，但卖了两个月才清完，利润比预期少了近四成——**如果当初全额压上，资金链会非常紧张。**

这一课的教训很典型：

```
断对了方向（能成）  ✓
没断量级（只是小成） ✗  ← 差点酿成实际的资金问题
```

老徐后来总结了一句很实在的话：**「能成」和「成多大」是两个问题，我只问了第一个。**

读课的人也补了一条规矩：凡是断语里有吉凶判断的，必须跟一个量级词。

```
量级词清单（小吉适用）：
   小成 / 适中 / 规模有限 / 不是大获
```

**这里还有第二层**：小吉的吉在「和合」。老徐跟供货商谈成分批付款，正是「路上好商量」「凡事皆和合」的用法——**小吉的吉，是你谈出来的，不是等来的**。

### 笔记与验证

小吉课的记录，加两个专用字段：

```
第1项 是否成（成 / 不成）
第2项 量级是否符合「小成」？（偏小 / 适中 / 偏大）
```

验证方式：统计「方向对了但量级没说」的比例。这个比例通常会很高，是提升空间最大的地方。每次读小吉，强迫自己带上量级词。

## 1_7 空亡

### 要点

本单元只读一宫：**空亡**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**土 · 中 · 勾陈 · 不顺**

这一宫的关键词是**落空、迟滞、抓不住**。

### 断辞与逐句释义

**空亡事不祥，阴人多乖张，求财无利益，行人有灾殃，失物寻不见，官事有刑伤，病人逢暗鬼，禳解可安康。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 空亡事不祥 | 事情没有好结果 | 先按「抓不住」论断，不是「一定失败」 |
| 阴人多乖张 | 有不明朗、有变数 | 信息不全，事情里有你没看到的部分 |
| 求财无利益 | 投入无回报 | 不宜投入、不宜担保 |
| 行人有灾殃 | 外出的人不顺，音信渺茫 | 主动联系确认安全 |
| 失物寻不见 | 找不到 | 不要在这件事上耗太多精力 |
| 官事有刑伤 | 官司不利 | 早做止损准备 |
| 病人逢暗鬼 | 问病不明朗 | **文献引录，不作医疗判断**；实用读法：做全面检查，别满足于一次查不出 |
| 禳解可安康 | 古法化解之语 | **文献引录，不代表提倡仪式**；实用读法：做风险预案 |

> **口径说明 · 首句异文**：首句「事不祥」，另有「事不長」「事不禅」等写法并存，本库暂从「事不祥」（见 `1_1` 待考表）。「祥」言吉凶，「長」言久暂——取法不同，第一句读法的侧重也不同，但宫义不变。

### 空亡的误断

**把「空」读成「凶」。**

空亡的核心是**没有**，不是**坏**。

```
赤口 = 出了坏事（有损失、有冲撞）
空亡 = 什么都没发生（投入归零、事情消失）
```

```
问投资：赤口 → 亏了（钱有去有回，回得少）
        空亡 → 落空（项目黄了，或根本没启动）

问出行：赤口 → 路上出状况
        空亡 → 去不成（取消、改期、白准备）
```

### 空亡的反转读法

**问法不同，读法相反**——这是空亡最重要的一条：

```
问「好事能不能成」   → 空亡 = 抓不住、不成
问「坏事会不会来」   → 空亡 = 落空、不会来（对问事人而言是好的）
```

```
例一：问「这单能签吗」      → 空亡：签不成
例二：问「对方会起诉我吗」  → 空亡：不会起诉，这事落空
```

**判断标准**：先问自己「对问事人来说，这是好事还是坏事」，再定吉凶方向。

### 实操

### 读空亡的三步

```
第一步：定性——这是「空」象，是【没有】，不是【坏】
第二步：看问题性质——问好事还是问坏事？（决定吉凶方向）
第三步：配动作——空亡最有用的动作是「别投入」与「做预案」
```

### 空亡在不同宫位的差别

```
空亡在月宫 → 背景落空：这件事的外部环境本身就是虚的
空亡在日宫 → 事体落空：事情本身没有实质内容
空亡在时宫 → 落点落空：最终抓不住（最常关注的一处）
```

### 案例小故事：一句「会出事吗」

学员小吴出差前一天问：「明天这趟顺利吗？」掐出时宫**空亡**。

他一看「大凶」，紧张地问：「会不会出车祸？」

这就是典型的把「空」读成「凶」。我们按宫义重读：

```
空亡 = 没有、落空
   在出行这个场景里，最常见的应法是：
   第1种 这趟去不成（取消、改期）
   第2种 去了也白去（对方不在、事情没办成）
   而不是「路上出事」
```

给他的动作建议是：

```
第1步 出发前再跟客户确认一次时间地点
第2步 如果对方临时改期，别硬去
第3步 别为这趟做太多前置投入（别提前垫付大额费用）
```

结果：客户临时出差，行程取消。小吴本人毫发无损，只是白准备了一场。

他在复盘里写了一句很到位的话：**「我断『不顺利』，实际是『根本没发生』。虽然都算我说中了不好，但感受完全不同——我没遇到任何麻烦，只是空忙了一场。」**

半年后他又遇到一次空亡，这次问的是别人：朋友想投一个项目，问「能回本吗」。他掐出空亡，这次他直接说：

```
「卦上看这事会落空，不是亏，是白忙。
 我的建议是别投，如果实在想参与，只用极小额试水，
 而且要拿到书面协议。」
```

朋友没投。后来那个项目出了问题，投进去的人全亏。

**同样是空亡**，前一次是「出行取消」，后一次是「别进场」。两次都读对了，因为两次都抓住了「空 = 没有」这个核心，而不是「空 = 凶」。

他后来给空亡写了一条备忘：

```
空亡 = 没有
  问好事 → 抓不住，别投入
  问坏事 → 不会来，可以放心
  问出行 → 可能去不成，出发前再确认
  问病   → 不明朗，去做全面检查（不作医疗判断）
```

### 笔记与验证

空亡课的记录，加一个专用字段：

```
第1项 问题性质：求成（问好事能否成） / 避险（问坏事会不会来）
```

验证方式：分别统计「求成类」与「避险类」的命中率。**如果避险类明显偏低，说明你还没掌握空亡的反转读法**——回本单元重读「空亡的反转读法」。
