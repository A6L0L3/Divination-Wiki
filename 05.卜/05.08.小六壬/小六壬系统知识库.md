## 一、这套知识库是什么

小六壬是一套**以农历月、日、时三个数，在六宫之间循环定位**的占断法。它的全部操作只有一件事：**数**。

从大安起正月，数到月份落在哪一宫；再从那一宫起初一，数到日子落在哪一宫；再从那一宫起子时，数到时辰落在哪一宫。三个宫位一出来，课就起完了。没有排盘、没有装卦、没有层层推演——会数数就能起课。

它的别名很多：六壬时课、诸葛马前课、掐指神算。本库统一用「**小六壬**」。

**简单不等于浅。** 六宫的性情、三宫的主次、生克与同气的分寸，都要在案例里慢慢磨。

### 与其他术法的分工

```
八字（命术）    → 一生格局与运势大势，看长期基调
六爻（纳甲）    → 一件具体事的吉凶与应期
小六壬（掌诀）  → 眼前一事的态势与取向，用月日时三个数掐指即得
```

三门各管一段，**是分工不是高低**。同一件事不必用另一门去「验算」，也不要用一门否决另一门。完整的对比表见 `0_1`。

> **最容易搞混的一点**：小六壬取的月日时是**起课那一刻**的时间，不是出生时间。换一时间再起课，输入变了、三宫也就变了——这正是它不能用来断一生格局的原因。

## 五、笔记与验证：本库的隐形主线

学小六壬最容易停在「能掐出结果」，然后就没有然后了——因为没有回头看过自己读得对不对。

本库把**占验记录**放在与起课同等重要的位置：每个单元末尾都有「笔记与验证」段，板块4_5 给出完整模板与统计方法。核心动作只有三个：

```
第1步 起课当下就记：问题 / 农历月日时 / 三宫落点 / 取了哪句断辞 / 我的读法
第2步 结果出来后回填：实际发生了什么 / 哪句对上了 / 哪句没对上
第3步 定期盘点：最容易读错的宫、最容易犯的误断
```

不做这三步，学再久也只是把口诀念熟；做了这三步，才能形成属于自己的读数手感。

## 0_1 小六壬是什么与学习路径

### 要点

小六壬是一套**以月、日、时三个数在六宫之间循环定位**的占断法。全部操作只有一件事：数——正月从大安起，月上起日，日上起时，三步走完，月宫、日宫、时宫就定出来了。

它属于传统「五术」里的「**卜**」：针对眼前一件具体的事，回答**态势与取向**。不排盘、不装卦、不推五行旺衰，入门门槛低。

**术法定位：民间掌诀速断。**

```
输入：起课那一刻的农历月、日、时（不采集生辰）
输出：月宫 / 日宫 / 时宫 三个落点
读法：宫义为主、断辞为象、三宫分主次
```

### 与八字、六爻的分工

| 对比维度 | 八字（命术） | 六爻（纳甲） | 小六壬（掌诀） |
|---|---|---|---|
| 起课输入 | 出生年月日时 | 所问之事＋摇卦 | 农历月、日、时（不采集生辰） |
| 回答的问题 | 一生格局与运势大势 | 具体一事的吉凶与应期 | 眼前一事的态势与取向 |
| 断法核心 | 日主旺衰、格局、用神 | 用神旺衰、动爻变爻、日月作用 | 三宫分工、宫义断辞、生克同气 |
| 入门门槛 | 需先打干支与五行基础 | 需学纳甲装卦 | 会数数即可起课 |
| 适合的问题 | 「我这几年适合转型吗」 | 「这周投的标能不能中」 | 「这件事眼下顺不顺、往哪走」 |

> **口径说明**：表里的「农历月、日、时」是**起课那一刻**的时间，不是出生时间。同一件事换个时间再起课，输入变了、三宫也就变了——这正是小六壬不能用来断一生格局的原因：它取的是一时的态势，不是一个人固定的命局。

> **口径说明**：三门术法各管一段：八字看长期基调，六爻问一件具体事，小六壬用掌诀快速看眼前态势。输入不同、问题不同，是分工不是高低；同一件事不必用另一门去「验算」，也不要用一门否决另一门。

### 实操

### 提问前的一道检查

小六壬只回答「眼前一件具体事的态势与取向」。起课之前，先拿三个问题筛一遍你的提问：

```
检查一 · 是不是一件具体事？
   ✗ 「我今年运势怎么样」
   ✓ 「这周五的面试，眼下是什么态势」

检查二 · 是不是问「态势与取向」？
   ✗ 「我这辈子能不能发财」
   ✓ 「这笔投入眼下该不该进场」

检查三 · 能不能在可预期的时间内验证？
   ✗ 「我跟他有没有缘分」
   ✓ 「这个月内他会不会主动联系我」
```

三问全过，再起课。过不了的，多半是把小六壬当八字用了——那不是它管的范围。

### 这套知识库怎么用

每个单元都按同一套四段式展开，读的时候顺着走，不要跳段：

```
要点          → 这一单元必须记住的硬知识
实操          → 怎么做、注意什么、常见错在哪
案例小故事    → 用一个完整场景把规则演一遍
笔记与验证    → 这一条怎么记、怎么验收
```

四段的分工是：前两段负责「懂」，后两段负责「会用」。很多人只读前两段就往下走，结果学完能掐、不会读——**跳过故事和笔记，等于跳过从知识到能力的那一步。**

### 案例小故事：把小六壬当八字用的那位

有位同学刚学完三步起课，很兴奋，跑来问：「我用我自己的出生时间起了一课，落大安，是不是说明我这辈子挺安稳的？」

问题出在输入上。小六壬取的是**起课那一刻**的月日时，不是出生时间。用出生时间起出来的课，回答的是「你出生那一刻的态势像什么」，跟「你这一生如何」没有关系。

他真正想问的是「我今年适不适合换工作」，这个问题本该这样处理：

```
第1步 在某个他真正在犹豫的时刻起课（比如刚开完会、心里冒出这个念头的那一刻）
第2步 取当时的农历月、日、时
第3步 掐出三宫，读「这件事眼下往哪走」
```

后来他重新起了一课，落**留连**。他问：「是不是换不成？」

我们按宫义读：留连的核心是**拖**——事情推不动、说不清、时机未到，「急讨方遂心」说明得主动去争取才有结果。于是给他的读法是：不是换不成，是现在推不动；先把简历和作品集准备好，主动去谈，别等着机会自己来。

两个月后他拿到了一个内部转岗的机会——不是靠等来的，是主动谈来的。

**这件事说明两件事**：一是输入搞错，整套读法就废了；二是即便输入对了，读法也得落在「态势与取向」上，而不是「成不成」的判决书上。

### 笔记与验证

在本单元结束时，把下面三条写进你的笔记首页：

```
第1条 我起课用的是【起课那一刻】的农历月日时，不是生辰
第2条 小六壬回答的是【态势与取向】，不是格局、不是判决
第3条 八字 / 六爻 / 小六壬是分工关系，不互相验算、不互相否决
```

验证方式：翻看日后自己的占验记录，检查有没有哪一课的提问方式跑出了「眼前一件具体事」的范围（例如问一生运势、问长期大势）。有，就标记为「提问越界」，不计入有效统计。

## 0_2 新手入门顺序与准备

### 要点

### 五步入门顺序

```
第一步：背六宫——顺序固定为
        大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡，
        数到第六宫回第一宫，循环不息。

第二步：记掌诀——六宫定在左手食指、中指、无名指上，每指取根、尖两处；
        食指根起，顺时针一圈。

第三步：练三步起课——正月从大安起，月上起日，日上起时。

第四步：学三宫分工——月宫背景、日宫事体、时宫落点；先读单宫，再读三宫。

第五步：进案例——按失物与行人、谋事出行、官非口舌、感情家庭等题材练读法，
        最后做综合纠偏。
```

五步有先后，**不要跳**。最常见的跳法是第二步没练熟就急着掐指，结果手比脑子慢，数到一半忘了起点在哪。

### 生克放在哪一步

**生克不是入门第一课。** 先把六宫宫义与三宫分工读顺，再回来学生克。生克的基本边界：

```
只看起出来的三宫，主看 月→日、日→时；
大安与小吉同属木，双木同气不作生克；
生不一定吉、克不一定凶，必须结合宫义与断辞。
```

> **口径说明 · 边界**：三宫生克只用来读**态势的传递方向**（月→日、日→时），不是五行力量的旺衰比较。完整边界见 `3_2`。

### 不需要准备什么

**不需要出生时间，也不需要采集生辰。** 起课只用农历月、日、时三个数；手上记熟六宫位置，随时可以掐指起课。

```
可以准备（都是可选）：
  · 一个能显示农历的日历（手机自带即可）
  · 一个记占验的本子或电子表格
  · 纸笔（初学画链路图用，熟了就丢掉）
不需要准备：
  · 生辰八字
  · 铜钱、蓍草、签筒等道具
  · 任何排盘工具（本库不排盘）
```

### 怎么查农历月、日、时

起课只用三个数：农历月、农历日、时辰。时辰看钟点（对照表见 `2_3`），农历月日要查一下。

```
查法一 · 手机自带日历
  多数系统可在设置里打开「显示农历」，或在日历里切到农历视图

查法二 · 万年历 App 或网页
  搜「万年历」即可，输入公历日期查对应农历

查法三 · 黄历类工具
  一张黄历日历，每格直接显示农历日、干支与宜忌
```

**注意大小月**：农历月有三十天也有二十九天，日子只能数到当月实际有的那一天（详见 `2_2`）。

### 实操

### 五步各自的过关标准

五步环环相扣，前一步没过关就往下走，后面每一步都会卡。标准很简单：

```
第一步 背六宫    → 任意起头，3 秒内正背完一轮
第二步 记掌诀    → 报任意宫名，2 秒内在手上点出位置
第三步 三步起课  → 给一个农历时间，60 秒内掐出三宫且无错
第四步 三宫分工  → 掐完能说出「背景 / 事体 / 落点」各是什么
第五步 进案例    → 读一课能给出「态势 / 取向 / 提醒」三件套
```

达不到就回到那一步重来，不要靠「大概会了」往下推。

### 每日练习建议

```
第1步 每天默背一遍六宫顺序与掌诀位置，做到「手比脑子快」
第2步 用当天的农历月、日、时随手起一课，按「月 → 日 → 时」各写一句象，
   再回到断辞对照
第3步 每学完一个单元，按单元末尾的「笔记与验证」自测一遍，
   读错的回单元重读
第4步 一次只问一件具体事，不反复起课凑一个自己想要的答案
```

> **口径说明 · 三条学习提醒**：第1，吉凶是「象的倾向」，不是事情的结论；第2，断辞是象，只取与所问之事对应的句子；第3，断辞里涉及疾病、祭祀、鬼神之语是古籍原文的文献引录，不代表提倡任何仪式、法术或替代医疗，身体不适请及时就医。

### 案例小故事：顺序背了，位置没背

两个同学一起入门。

A 的第一步做得很扎实：六宫顺序背得滚瓜烂熟，正背倒背都行。第二步他觉得「不就是六个位置嘛」，扫了一眼就往下走，直接开始练三步起课。

结果他每掐一课都要停下来想：「留连在哪个指头？」——一节课掐下来要一分多钟，而且经常数错。

B 的顺序相反：她顺序背得磕磕绊绊，但把六个位置在手上按了三十遍，闭着眼也能点准。她掐一课只要十几秒，只是偶尔要说错宫名。

两周后两人的差距很明显：B 已经能用当天的月日时随手起课、读断辞了；A 还在跟指头较劲。

问题出在哪？**六宫顺序是「逻辑」，掌诀位置是「肌肉」。** 逻辑可以靠理解，肌肉只能靠重复。小六壬号称「掐指速断」，速就速在手上——手不熟，再懂原理也快不起来。

后来 A 补了这一课：不看顺序，只在手上按，从食指根开始顺时针一圈，边按边念宫名，一天二十遍。三天后补上了。

**教训**：`第一步`和`第二步`看着都是「背」，但背的东西不一样。顺序背的是循环关系，位置练的是手指动作，两者不能互相替代。

### 笔记与验证

入门阶段，每天一条「随手课」记录即可，字段极简：

```
日期 / 农历月日时 / 三宫 / 我读的一句象 / 后来应了没有
```

五字段里最后一栏最容易空着，而它恰恰是**反馈栏**——前面的都只是记录，只有它是验证。

两周后回看一次：如果「后来应了没有」整栏空白，说明这两周你只练了掐，没练读。掐指是手上功夫，读课才是这门的本体。操作是否达标，看本单元「五步各自的过关标准」。

## 0_3 自测与练习设计

### 要点

学完一个单元，怎么知道自己真的会了？靠自测。

自测题按难度分五档，这个分档沿用通行的五级体系：**简单、普通、困难、炼狱、天堂**。分档依据不是题目本身绕不绕，而是**需要调动多少层知识**：

| 难度 | 需要的能力 | 适用阶段 |
|---|---|---|
| 简单 | 纯记忆、定义、单步判断 | 入门阶段 |
| 普通 | 单一规则应用、一步推导 | 基础阶段 |
| 困难 | 多规则组合、二步推导 | 进阶阶段 |
| 炼狱 | 综合多维度、三步以上推导 | 高阶阶段 |
| 天堂 | 跨单元综合、实战级场景 | 巅峰阶段 |

### 实操

### 五档题长什么样

用同一批知识点出题，五档的区别一目了然：

| 难度 | 示例 |
|---|---|
| 简单 | 六宫顺序是什么？留连配哪个六神？大安在左手哪个位置？ |
| 普通 | 农历四月初八午时，时宫落哪一宫？ |
| 困难 | 月宫大安、日宫小吉，二者作生克论吗？为什么？ |
| 炼狱 | 三宫为留连、速喜、空亡，问「这笔款能否收回」，怎么读？ |
| 天堂 | 给出一段完整问事场景，判断该取哪句断辞、三宫如何分主次、误断风险在哪 |

### 难度必须与进度绑定

```
简单、普通  → 边学边做，配合单元进度
困难        → 学完一个板块再做
炼狱、天堂  → 全课学完后回头做
```

> **提示**：题太超前，做错往往不是能力问题，而是「这一章还没学到」。炼狱、天堂提前做，错因里会堆满没学过的章节，看着吓人，其实没用。

### 怎么给自己出题

没有现成的题也能练。三个来源，按优先级排：

```
来源一 · 单元末尾的「笔记与验证」
   每个单元都写了自测项与验证方式，照着做即可

来源二 · 自己掐的课
   起一课，先把读法写下来，事后再核对。
   这是最真实的题——有反馈、有后果

来源三 · 改造旧题
   把做过的题换个条件：换个宫位、换个问法、换个题材，
   看读法要怎么变
```

板块2_3 附了十道起课自测题与完整过程，板块1_1 双木同气的案例也可当题做。

### 四类错因，处理方式不同

练完之后，错题要分类——**不同错因的处理方式完全不同，混在一起重做是浪费时间**：

```
错因 A · 没记住（顺序、掌位、宫义）
   处理：回到单元重背，三天后重做

错因 B · 没理解（生克、同气、三宫主次）
   处理：回单元读「要点」与「案例小故事」，再重做

错因 C · 没学到（属于后面的单元）
   处理：标记「待学」，学完对应单元再回来

错因 D · 看错条件（把「月宫」看成「时宫」）
   处理：当场改掉即可，不必反复重做
```

**只有 A、B 两类值得反复重做。** C 类做再多也没用——你缺的不是熟练度，是知识；D 类做一遍就够。

### 案例小故事：自测卷里的「没学过」

有位同学性子急。学到 `1_3 留连` 那天，他刚背完断辞，觉得「六宫都差不多了」，就翻到板块3 的内容自测。

第一组十道，错了七道；第二组十道，错了七道。正确率不到三成。他很沮丧，跑来说：「小六壬是不是太难了？我明明都背下来了。」

我让他别急着做下一组，先把这十四道错题摊开，一道一道归类。

```
错因 C（没学到）：不知道三宫怎么分主次，属于 `3_1`  → 7 题
错因 B（没理解）：宫义认得，但套不到场景上        → 6 题
错因 D（看错条件）：把月宫看成了时宫              → 1 题
```

分类一做完，数字就说话了：十四道里占大头的是 C 类——**不是不会，是没学到。**

他有点不好意思：「那我这七成的错，其实跟我聪不聪明没关系？」

对，没关系。这就是难度必须与进度绑定的原因：**难度梯度是按知识点的先后排的，不是按题目绕不绕排的。** 板块3 的题之所以算「困难」，不是因为它拐了三个弯，而是因为它用到了你还没学到的三宫主次。超前做，错因里堆的不是薄弱点，是没学过的章节——C 类错因再多，重做也没用。

后来他改了策略，核心只有一条：**先判错因，再决定要不要重做。**

```
C 类（没学到）→ 标记「待学 + 所属单元」，先不做
B 类（没理解）→ 回单元读「要点」与「案例小故事」，三天后重做
D 类（看错条件）→ 当场改掉，不进重做清单
```

变化立竿见影。待重做的题从「一堆」变成「三两道」，而且每一道都有明确的回看位置——不再是「我怎么又错了」，而是「这一道属于 `3_1`，等学完再看」。

两周后他学完板块3，回头把那七道标记「待学」的题翻出来重做，对了六道。剩下那一道，他一眼就看出自己错在哪。

**错题的价值不在数量，在于每一条都能指回一个具体的单元。** 指不回单元的错题，只是噪声。

### 笔记与验证

维护两张小表：

```
【进度表】
板块 | 单元 | 是否已学 | 自测结果 | 是否已按要求记过课

【错因表】
错题 | 所属单元 | 错因（未学 / 未记 / 误读 / 算错） | 回看位置
```

**错因里「未学」占比超过一半，说明你练超前了**，退回当前单元。

## 0_4 笔记方法

### 要点

小六壬的知识点不多，六宫、三个数、三步掐算，一张纸写得完。真正拉开差距的是**笔记**——更准确地说，是能不能把每一次读课和它的结果连起来。

本单元讲三件事：笔记分哪几本、每本记什么、最少要记哪些字段。

### 实操

### 三本笔记，各有分工

```
┌────────────┬──────────────────┬────────────────────┐
│   笔记      │    记什么         │      怎么用         │
├────────────┼──────────────────┼────────────────────┤
│ 单元笔记    │ 宫义、断辞、要点  │ 学的时候写，复习用  │
│ 错课记录    │ 读错的课与错因    │ 定期回看，找到惯性错│
│ 占验记录    │ 真实起课与反馈    │ 回填结果，定期盘点  │
└────────────┴──────────────────┴────────────────────┘
```

三者不要合并：单元笔记是**知识**，错课记录是**薄弱点**，占验记录是**实测数据**。混在一本里，最后三类信息都会失效——你想查「我起过的课」，翻出来全是宫义抄写。

### 口径提醒（记在笔记首页）

> 本库以**三宫古法**为口径。当代衍生出不少扩展派系（四宫、六宫加六亲、六神另配等），各派在五行归属、六神对应、应期法则上并不统一。遇到别的说法，先回本库单元确认口径，**不混用**——这不是否决别派，而是防止口径混用导致自己读错。

### 占验记录的最小格式

刚开始不用复杂，每条只记五样：

```
第1项 时间：公历 + 农历月日时
第2项 问题：一句话，必须是眼前一件具体事
第3项 落宫：月宫 / 日宫 / 时宫
第4项 读法：我取了哪句断辞、我怎么读的
第5项 反馈：后来实际发生了什么、哪句对上了
```

**第 2 项和第 5 项是灵魂**：问题不是具体事，这条记录就是废的；不回填反馈，这条就是死的。

### 记的时候守住一条

五字段里，**第 4 项读法必须在起课当场写下，事后只补第 5 项反馈**——绝不回过头去改读法。改过一次的读法，这条记录就失去了验证价值。

完整版模板（十字段）、三条记录纪律与统计方法见 `4_5`。

### 案例小故事：三本笔记分开之后

有位同学起初只用一本笔记本，什么都在里面写：今天学的宫义、读错的课、路上随手起的一课、后来的结果。

两个月后他想统计一下自己读得准不准，翻了半天翻不出来——因为知识、错题、实战全混在一起，一条一条看过去，根本分不清哪条是「我起过的课」。

我让他拆成三本（三个电子表格也行）：

```
第一本「单元笔记」：只写学到的东西，按单元编号
第二本「错课记录」：只写读错的课 + 错因 + 回看位置
第三本「占验记录」：只写真实起课，一行一课，带反馈栏
```

拆完第三天，他就把占验记录统计出来了：47 条，其中「取了断辞且对上了」的有 31 条。

更重要的是，他立刻发现了一个规律：**凡是问「能不能成」的课，他读得特别差；凡是问「眼下往哪走」的课，他读得不错。**

这正好印证了 `0_1` 的定位——小六壬回答的是**态势与取向**，不是成不成。他之前读得差，不是技术不行，是提问方式跑偏了。

拆开笔记，这个规律才浮出来。混在一起，永远看不见。

### 笔记与验证

把记录格式固定下来（写在笔记首页，不再改）：

```
【我的记录五字段】
时间（公历+农历） / 问题 / 三宫 / 读法（取了哪句） / 反馈
```

验证方式：一周后回看，检查是否有「反馈」栏为空的记录。空着的，说明问题问得太模糊、或者忘了回填——前者改提问方式，后者设提醒。

## 0_5 参考文献与延伸阅读

### 要点

### 本教材底本

- **底本（原典）**：《玉匣记·李淳风六壬时课》，版本为广盛堂藏版《增补选择通书广玉匣记》。
- 六宫的宫名、顺序与断辞原文均以此为准；**本教材只有一个底本**。
- **校勘参照（不作第二底本）**：郑同校注《绘图全本玉匣记》（华龄出版社）。它只用来旁证「不同版本确有差异」，本库断辞仍从底本。

> **口径说明**：书目分三层——**底本**只列原典、不改；**校勘参照**用于说明异文来源、不替代底本；**延伸阅读**放源流考述与现代流变。民间转引的其他书名、作者，未经核实不写入。遇到异文，按板块1_1 的「待考与异文」处理，不把一句诗说成绝对结论。

### 延伸阅读（不作依据）

- 《协纪辨方书》论「上兀下兀」时有一句「上兀下兀乃俗传小六壬之留连赤口」（转引，原文待核）。它证明的是清代已见「小六壬」之名，且原书语气是**贬斥**（后接「尤为荒陋」），不是官方背书。
- 小六壬在当代衍生出多种扩展派系（增加六亲、六神等维度），起课逻辑与三宫古法不同；**本库不取**，仅作了解当代流变的参考。

### 实操

### 回读底本的时机

底本不必一开始就啃。学完板块1 到板块4，六宫的宫义在心里有了位置，再回去读原文会顺很多。

### 读古籍的四种读法

```
第1条 先读宫义，再读断辞
   断辞是象，不是逐句对照的清单

第2条 只取与所问之事对应的句子
   问失物看「失物」，问行人看「行人」，不问病就不拿病句来断

第3条 记异文，不把一句诗当定论
   有异文时在「待考与异文」里说明，以审定口径为准

第4条 病句作文献引录
   涉及疾病、祭祀、鬼神之语不代表提倡任何仪式、法术或替代医疗，
   身体不适请及时就医
```

回读时按「**宫义—断辞—案例**」三层对照：先认这一宫是什么性情，再看原文怎么取象，最后拿一件自己真实的事试读一遍。遇到不同流派的说法先记下差异，不急着强行统一。

> **口径说明**：延伸阅读只放已核过书名与版本的书目；未经核实的转引不写入——宁可少写，不写错。

### 案例小故事：一句「事不祥」和一句「事不長」

有位同学在网上查小六壬资料，发现空亡的首句有两个版本：一处写「空亡事不祥」，另一处写「空亡事不長」。他来问哪个对。

这正好是「异文」的典型情形。处理办法不是二选一，而是分层：

```
第一层：本库底本作「事不祥」，正文从底本
第二层：另一写法记入「待考与异文」，注明来源与性质
第三层：不因为见了异文就改正文，也不因为坚持正文就说别本错
```

他接着问：「那两个字差别大吗？」

差别不在字义，在**态度**。「祥」是吉凶之兆，「長」是久暂之象——前者说这事不吉，后者说这事不长。作为宫义的注脚，两者都能通，但取哪个，会影响你在实战里的第一句读法。

本库取「事不祥」，理由是底本如此；但把「事不長」记在待考表里，读者明白有此一说。

**这就是「记异文，不把一句诗当定论」的实际操作**：不是和稀泥，是把「我取哪个」和「还有哪些说法」两件事分开。日后若核得底本另作他字，改正文即可，异文表本来就在。

后来他养成了习惯：凡见到与正文不同的说法，不急着争论，先记进自己的异文栏，注明出处。半年下来，他那份异文表成了最有价值的一份私人资料。

### 笔记与验证

在笔记末页留一栏「**我见到的异文**」，格式：

```
宫位 | 正文取法 | 我见到的另一说法 | 出处（能写就写） | 是否影响宫义
```

**「是否影响宫义」这一列最重要**：多数异文只是字形差异（如「咀咒」与「咒诅」），不影响宫义，记一笔即可；少数涉及取象方向（如方位词、动词），要标红，读课时格外留意。

*本板块为导论，讲的是方法与口径。*


# 板块1 · 六宫与掌诀

> 六宫总表、掌诀与逐宫断辞

## 1_1 小六壬总表与掌诀

### 要点

### 一、小六壬是什么

小六壬是一套**以月、日、时三个数在六宫之间循环定位**的占断法。它的全部操作只有一件事：数。

从「大安」起正月，数到月份落在哪一宫；再从那一宫起初一，数到日子落在哪一宫；再从那一宫起子时，数到时辰落在哪一宫。三个宫位一出来，课就起完了。

没有排盘、没有装卦、没有五行旺衰的层层推演。**它是五术里入门门槛最低的一门**——会数数就能起课。

也正因为它简单，容易被人看轻。但简单不等于浅：六宫之间的生克、三宫之间的先后关系、每一宫断辞里藏着的分寸，都要慢慢磨。

### 二、名字与来历：先把「小」说清楚

小六壬又叫「六壬时课」「诸葛马前课」「掐指神算」。本库正式名用「小六壬」。

关于来历，常见两说：

- 一说脱胎于古代择日术的「六曜」符号；
- 一说是大六壬的民间简化版。

**两说均待考。** 本教材不把「简化版」当定论，也不因为名字里有个「小」字，就把它说成「残缺版」。名字是民间通名，不是学术判定。

> 三个别名来源不同：「六壬时课」多与李淳风传统绑定（底本即题「李淳风六壬时课」）；「诸葛马前课」属另一条托名传说，成书较晚；「掐指神算」是民间俗称。三名并置只表示民间流通中常被混称，**不代表同源**。

### 三、六宫的名称与顺序

六宫依次是：

**大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡**

这个顺序**固定不变**。数到第六宫之后回到第一宫，如此循环。

记住这个顺序，是学小六壬的第一件事。后面所有的起课、所有的推算，都建立在这个循环上。

### 四、六宫总表

| 宫 | 五行 | 方位 | 六神 | 吉凶 | 核心象 |
|---|---|---|---|---|---|
| 大安 | 木 | 东 | 青龙 | 吉 | 稳、静、守成 |
| 留连 | 水 | 北 | 玄武 | 不顺 | 拖、暗、牵连 |
| 速喜 | 火 | 南 | 朱雀 | 吉 | 快、讯息、动静 |
| 赤口 | 金 | 西 | 白虎 | 不顺 | 冲、口舌、硬碰硬 |
| 小吉 | 木 | — | 六合 | 吉 | 和合、谈得拢 |
| 空亡 | 土 | 中 | 勾陈 | 不顺 | 落空、迟滞、抓不住 |

> **口径说明 · 小吉的方位**：宫位常配里不单列方位。断辞里的「失物在坤方」是**失物这一句的取象**，不是小吉的固定方位。不要把断辞里的方位当成宫位常配。

### 五、五行只有五个，六宫却有六个

五行只有五个，六宫却有六个，所以必然有一行重复。在小六壬里，重复的是**木**——大安与小吉同为木。

这不是笔误，也不是哪一家的私改。六宫配五行本来就是象数上的安排，不是五行均分。

由此得到一条必须记住的规则：

**双木同气**：三宫中若同时出现大安与小吉，二者同属木，**不作生克论**，只作「同类相应」看。

注意边界：**双木同气只免除这两宫之间的生克，不免除它们与第三宫的生克。** 例如三宫为大安、小吉、赤口，大安与小吉之间不论生克，但赤口金对双木的克仍然成立（金克木）。

### 六、吉凶三分：象的倾向，不是判决书

六宫按倾向分三吉、三不顺：

- **三吉**：大安、速喜、小吉
- **三不顺**：留连、赤口、空亡

> **口径说明 · 要紧的一句**：**吉凶是「象的倾向」，不是「事情的结论」。**

大安主稳，不等于事情一定成；空亡主落空，不等于一定失败。六宫给的是**这件事当下的态势像什么**，不是判决书。

同一个宫，问法不同，读法也不同：

- 问「稳不稳」，大安是稳；
- 问「进不进」，大安往往是「暂时不动」；
- 问「有没有转机」，空亡往往是「眼下抓不住」，不是「永远没有」。

把吉凶当结论用，是小六壬最常见的误用。

### 七、六神：宫义为主，六神为辅

六神是六宫的另一个标签，用来提示该宫的「性情」：

- **青龙**主生发、主正——大安的稳，是往好里稳；
- **玄武**主暗昧、主隐——留连的拖，常拖着说不清的东西；
- **朱雀**主口舌、主讯息——速喜的快，多半快在消息上；
- **白虎**主刚烈、主伤——赤口的凶，凶在冲撞；
- **六合**主和合——小吉的吉，吉在「谈得拢」；
- **勾陈**主迟滞、主纠缠——空亡的空，是抓不住。

**六神不是独立判据，是帮你体会那一宫的性情。** 断课时宫义为主，六神为辅。不要看到白虎就说「一定受伤」，也不要看到六合就说「一定成」。

### 实操

### 八、掌诀：把六宫装到手上

小六壬最方便的地方，是它**不需要纸笔**。六宫的位置定在手上，掐指一数就出来。

以左手为例，六宫分布在食指、中指、无名指上：

| 宫 | 位置 |
|---|---|
| 大安 | 食指根 |
| 留连 | 食指尖 |
| 速喜 | 中指尖 |
| 赤口 | 无名指尖 |
| 小吉 | 无名指根 |
| 空亡 | 中指根 |

```
              左 手 掌 诀 图（掌心朝己，指尖朝上）

              食指        中指       无名指
            ┌───────┐   ┌───────┐   ┌───────┐
            │ 留连  │   │ 速喜  │   │ 赤口  │
            │  第2  │   │  第3  │   │  第4  │
            ├───────┤   ├───────┤   ├───────┤
            │ 大安  │   │ 空亡  │   │ 小吉  │
            │  第1  │   │  第6  │   │  第5  │
            └───────┘   └───────┘   └───────┘
             指根       指根       指根

   拇指、小指不参与掐算
   顺时针一圈：第1大安 → 第2留连 → 第3速喜 → 第4赤口 → 第5小吉 → 第6空亡 → 回到第1
```

**掐算方向**：食指根 → 食指尖 → 中指尖 → 无名指尖 → 无名指根 → 中指根 → 回食指根，**顺时针一圈**。

> **口径说明 · 两套坐标，各管一段**：六宫在手上的位置是掐算的**物理落点**，**不等同于十二地支掌的支位**——不要把地支掌的「寅位」「卯位」套到六宫上，也不要用六宫位置去反推地支。小六壬只认「大安→留连→速喜→赤口→小吉→空亡」这个顺序，不给六宫与地支的逐宫对应表。宫位总表里的「东/南/西/北/中」是五行—六神系统下的常配方位。二者不是同一层——不要把「留连在食指尖」读成「留连方位在东南」，也不要拿总表的「北」去和掌诀位置对账。

三个记忆要点：

```
1. 三根手指，六个点——每根手指取根、尖两处
2. 三吉大致在「角」上：大安（食指根）、速喜（中指尖）、小吉（无名指根）
3. 顺序是顺时针一圈，不是跳着数
```

记不住的时候，默念「**大留速赤小空**」六字，手跟着走一遍。走熟了，手比脑子快。

### 九、读断辞的三条规矩

```
1. 先读宫义，再读断辞
   断辞是象，不是 checklist；不要拿整首诗逐句往问题上套

2. 只取与所问之事对应的句子
   问失物看「失物」，问行人看「行人」，问口舌看「官非/口舌」；
   不问病，就不要拿「病者」句来断

3. 断辞有异文
   本库取定本口径；遇到异文在「待考与异文」里说明，
   不把一句诗说成绝对结论
```

### 十、断辞总注（先读这条）

> **口径说明**：六宫断辞中涉及疾病、祭祀、鬼神之语——大安「病者主无妨」、速喜「病者无祸侵」、赤口「恐怕染瘟殃」、小吉「病者祈上苍」、空亡「病人逢暗鬼，禳解可安康」——均为**古籍原文的文献引录**，不代表本库提倡任何仪式、法术或替代医疗。**身体不适请及时就医。**

「禳」是古代祭祷消灾之俗。收录原文是为了文献完整；加这条总注，是为了不让人把「禳解」读成「建议你去做仪式」。两者不冲突：字要准，话要说清。

> 总注逐宫列明，不用「如某某等」这种概括写法：漏掉一条就等于漏一半。赤口「恐怕染瘟殃」涉疫病，是六宫中第二高危的一句，不能被一个「等」字略过。

### 十一、待考与异文

| 项 | 说明 |
|---|---|
| 起源 | 两说并列：一说脱胎于古代择日术「六曜」符号；一说为大六壬的民间简化版。**两说均待考**，不把「简化版」当定论 |
| 大安首句 | 「求谋在东方」（本库正文取此，见于民间「小六壬时课」抄本系统）／「求财在坤方」（另一系统通行本多作此）。两说并存，本库暂不改正文 |
| 空亡首句 | 「事不祥」（本库正文取此，民间抄本系统）／「事不長」（多种整理本作此）／「事不禅」为再传异写。三说并存，本库暂从「事不祥」 |
| 赤口字形 | 「咀咒」（本库正文取此）／「咒诅」（通行整理本多见）——字形异文，各本互见，不影响宫义 |
| 速喜失物 | 「失物申未午」一作「失物申午未」；本库取「申未午」，并按**方位义**读 |
| 留连急讨 | 「急讨方遂心」一作「急寻方心明」；本库取「急讨方遂心」 |
| 空亡末句 | 「禳解可安康」一作「析解可安康」；本库取「禳解」 |
| 六宫五行 | 留连「水/土」、小吉「木/水」、空亡「土/水」各派有别；本库取「留连水、小吉木、空亡土」 |
| 别名归属 | 三个别名来源不同，**不代表同源**（见本节二） |
| 三宫名目 | 本库只用「月宫/日宫/时宫」，不采「天/人/地」或「初/中/末」 |
| 配数 | 仅象数标记；一说用于应期，说法不一，**不作为断卦依据**（详见 `2_1`） |

### 十二、本单元要点

```
· 六宫顺序固定：大安→留连→速喜→赤口→小吉→空亡，循环不息
· 五行六宫必有重复，本库取「木重出」（大安、小吉）
· 双木同气：大安与小吉之间不作生克，与第三宫仍论生克
· 吉凶是象的倾向，不是结论；同一宫问法不同，读法不同
· 断辞是象，只取与所问之事对应的句子；病句为文献引录，不作医疗判断
· 掌诀位置是物理落点，不与地支掌混用
```

### 案例小故事：一课出了两个木

有同学掐出一课：月宫大安、日宫小吉、时宫赤口。他兴冲冲地来报：「大安属木，小吉也属木，那大安对小吉是生还是克？木生木，这怎么论？」

这一课正好撞上了「双木同气」的规则。他的困惑是典型的——拿到两宫，第一反应就是找生克关系，找不到就卡住了。

正确的处理分两步：

```
第一步：看这两宫是不是双木
   大安 = 木，小吉 = 木 → 是双木 → 二者之间【不作生克论】
   读作：同类相应——背景与事体都是「木气」，
        即这件事从环境到本体都带着「生发、和合」的底色

第二步：再看第三宫
   时宫赤口 = 金，金克木 → 赤口对双木的克【仍然成立】
   读作：落点上有冲克——事情最终会撞上硬碰硬的东西
```

串起来的读法：这件事从头到尾都是温和的路子（双木），但结果撞上了冲撞（赤口克木）——**过程好说好商量，收尾却有一道硬坎**。

他问的是「跟合作方谈条款顺不顺」，这一课的读法就很贴切：谈的过程很和气，但到最后签的时候，对方会在某一两个条款上硬来。

后来的实际情况：谈了三轮都很顺利，签合同前一天，对方在付款周期上突然改口，要求从三十天改成六十天，态度很硬。

**如果他当初按「大安生小吉」去找生克关系，这一课就读废了。** 双木同气这条规则的作用，恰恰是告诉你：这两宫之间不用找关系，直接看它们与第三宫的关系。

这个案例还有第二层价值：它说明了为什么「吉凶不是结论」。这一课三宫里有两个吉（大安、小吉），看上去是好课，但落点是赤口——**过程好不等于结果好**。

把下面这张表抄进笔记首页，作为你读课时的第一道检查：

## 1_2 大安

### 要点

本单元只读一宫：**大安**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**木 · 东 · 青龙 · 吉**

「安」字是这一宫的纲。安是稳、是不动、是守住现有的东西。

### 断辞与逐句释义

**大安事事昌，求谋在东方，失物去不远，宅舍保安康，行人身未动，病者主无妨，将军回田野，仔细更推详。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 大安事事昌 | 总纲。事情整体是顺的 | 「昌」是兴旺、太平，**不是大获全胜**。大安给的是平安，不是大利 |
| 求谋在东方 | 方位提示 | 谋事往东。方位只作提示，不作唯一依据 |
| 失物去不远 | 东西没丢远 | 就在近处，不必往远处找 |
| 宅舍保安康 | 家宅平安 | 这是大安最本色的地方，问家宅最为贴切 |
| 行人身未动 | 问行人，人还没动身 | 大安「不动」之性最直接的体现 |
| 病者主无妨 | 问病无大碍 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |
| 将军回田野 | 解甲归田之象 | 功成身退、由动转静 |
| 仔细更推详 | 收尾提醒 | 大安虽吉也要细看，不能一句「昌」就了事 |

### 大安的误断

**见「大安」就说「很好、没问题」。**

大安是「静」，问「事情会不会有进展」时，大安往往意味着**暂时不动**。静是安，也可能是停滞。要看问的是什么。

```
问「稳不稳」 → 大安是稳（贴切）
问「进不进」 → 大安往往是「暂时不动」
问「有没有危险」 → 大安是无碍
```

### 实操

### 读大安的三步

```
第一步：定性——这是「静」象，不是「成」象
第二步：取句——问什么取什么句，不拿整首诗套
第三步：留口——「仔细更推详」提醒你：单宫不够，要看三宫
```

### 与其他宫的对照

```
大安（静） vs 速喜（快）
   同为吉，一动一静。问「什么时候动」，速喜快、大安不动

大安（守成） vs 小吉（和合）
   同为吉，大安是守住现有的，小吉是谈得拢的
```

### 案例小故事：一句「很好」耽误了两周

有位同事问：「我投的那个内部岗位，这周会有消息吗？」掐出时宫**大安**。

帮忙读课的同学看了「大安事事昌」，顺口说：「吉，很好，等着吧。」

于是同事真的就等着了。两周过去，一点动静都没有。他再来问，重掐一次——这次时宫是**速喜**。

同一件事，两个不同时刻的课，读法完全不同：

```
第一次（大安）：事情眼下不动 —— 正确的读法是「这周不会有消息，别干等」
第二次（速喜）：消息来得快   —— 正确的读法是「快了，主动去问一句」
```

他后来真的发了封邮件去问，当天下午就收到了面试安排。

回头看，那次误断的根源不在「大安是吉还是凶」的判断，而在**把「静」读成了「成」**：

```
错误链条：
  大安 → 吉 → 很好 → 等着就行
正确链条：
  大安 → 静 → 眼下不动 → 这周不会有消息 → 别干等，该做什么做什么
```

大安的断辞里其实早就写明了这一层——「**行人身未动**」。人还没动身，怎么会来消息？这句断辞他根本没取，因为他的注意力被开头的「事事昌」三个字抓走了。

**这就是「先读宫义，再读断辞」的意义**：宫义（静）是纲，断辞是象。纲拿错了，取哪句都会偏。

后来他在自己的笔记里写了一条备忘：

```
大安 = 静。凡问「会不会动 / 什么时候动 / 有没有进展」，
      大安一律先读「暂时不动」，再补一句「不是不成，是没动」
```

### 笔记与验证

大安课的记录，重点记两个字段：

```
第1项 我问的是「稳不稳」还是「进不进」？（决定读法）
第2项 我取了哪一句断辞？（「昌」还是「不动」还是「去不远」）
```

验证方式：翻出所有大安课，检查有没有把「静」读成「成」的。凡是问进展而答「会成」的，标记为误读，回本单元重读「大安的误断」。

## 1_3 留连

### 要点

本单元只读一宫：**留连**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**水 · 北 · 玄武 · 不顺**

「留」是滞留，「连」是牵连。这一宫的关键词是**拖**。

### 断辞与逐句释义

**留连事难成，求谋日未明，官事只宜缓，去者未回程，失物南方见，急讨方遂心，更须防口舌，人事且平平。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 留连事难成 | 直接说破：事情难成 | 是「难成」，**不是「必败」** |
| 求谋日未明 | 谋事时天还没亮，时机未到 | 信息不全，还有你看不见的环节 |
| 官事只宜缓 | 官司、纠纷宜缓不宜急 | 硬来会更糟 |
| 去者未回程 | 走的人还没回来 | 问归期：还没踏上归途 |
| 失物南方见 | 失物往南找 | 方位取象，南方优先 |
| 急讨方遂心 | 想要的东西得赶紧去讨 | **主动讨，拖了就没了** |
| 更须防口舌 | 要防口舌是非 | 少争辩，留痕 |
| 人事且平平 | 人情往来平平 | 不好不坏，无大碍也无惊喜 |

### 留连的误断

**见「难成」就判死。**

留连的「难」难在**迟**，不是难在**绝**。玄武主暗昧，很多事是「说不清、推不动」，不是「办不成」。缓一缓、等一等，往往是留连的正解。

```
错误：留连 → 事难成 → 没戏了 → 放弃
正确：留连 → 拖 → 推不动、说不清 → 缓一缓 / 主动去讨
```

注意「急讨方遂心」这一句：它是留连里**唯一带动作指令**的一句。留连虽然主拖，但不是让你躺平——想要的东西得主动去讨，只是讨的过程会拖。

### 实操

### 读留连的三步

```
第一步：定性——这是「拖」象，不是「绝」象
第二步：判断——是「说不清」还是「推不动」？
        说不清（玄武主暗昧）→ 先补信息
        推不动（留连主滞留）→ 先缓，别硬来
第三步：取动作——涉及「要东西 / 要答复」的，取「急讨方遂心」，主动去讨
```

### 五行口径

> **口径说明 · 五行**：本库从底本作「**水**」；坊间另有「火」「四角土」等排布，各有所本，**不取**——详见 `1_1`「待考与异文」。

### 案例小故事：两万块的四个月

同事老周借给朋友两万块，说好一个月还。两个月过去，一点动静都没有，发消息也只回「最近手头紧」。他来问：「这钱还能要回来吗？」

起课时是农历六月十四，申时。掐出来：**月宫小吉 / 日宫留连 / 时宫留连**。

他只扫了一眼日宫和时宫，看到两个「留连」，脸色就变了：「留连事难成，那是要不回来了？」

我们先按宫义重读一遍：

```
留连 = 拖，不是绝
   → 钱不是没了，是卡住了
   → 「求谋日未明」：对方那边有你看不见的情况（可能确实周转不开）
   → 「急讨方遂心」：想要回来，得主动去讨，拖着不动就真没了
```

再补上他漏看的月宫——小吉：

```
月宫小吉 → 背景是「和合」
   → 对方不是存心赖账，关系还有得谈
   → 这也意味着：别一上来就撕破脸，商量比施压有效
```

三宫连起来是：关系没破裂（月小吉），但眼下卡着（日留连），而且还会继续卡（时留连）——**会拖很久，但不是死账。**

于是给他的读法和动作是分开的两件事：

```
读法（态势）：这笔钱会拖，短期内不会自动回来
动作（取向）：你自己开口去讨，而且要做好讨三次以上的准备
```

具体建议：

```
第1步 别等对方主动，你先开口
第2步 态度温和，但要求要明确，不要用「方便的时候再说」这类含糊说法
第3步 全程用文字（微信），不打电话，留痕
第4步 每次讨完给一个明确的时间点，下次按那个点再问
第5步 「更须防口舌」——不要在情绪上跟对方起冲突
```

结果：他第一次开口，对方说「下个月」；一个月后转了五千；第三次讨，转了一万；最后一笔又拖了一个月才还清。前后四个多月，中间确实有过两次不愉快——「更须防口舌」也验了。中途他还一度想找共同朋友去施压，被拦住了：月宫是小吉，一撕破脸就把「和合」的底子打掉了，反而更难收。

**这一课的教训有三条**：

```
一、留连 ≠ 不成
   如果当初读了「没戏」而放弃，这两万块就真没了。
   「难成」说的是过程难，不是结果绝。

二、留连的「拖」是双向的
   你拖着不讨，它就一直拖；你按「急讨方遂心」主动去要，
   它才会一格一格往前挪。

三、别只读落点
   他一开始只看了日宫和时宫，把月宫跳过了。
   而恰恰是月宫的小吉在说「这事还谈得拢」——
   这一条决定了整套动作的调子：商量，而不是施压。
```

老周后来说，最有价值的不是「能不能要回来」这个答案，而是那句「要做好讨三次以上的准备」——**有了这个预期，他就没在第一次碰壁时放弃。**

### 笔记与验证

留连课的记录，加两个专用字段：

```
第1项 最终结果：成了 / 没成 / 部分成（留连常应「拖很久最后成」）
第2项 拖了多久：____（留连最该统计的就是时间）
```

验证方式：统计自己所有留连课里「最终成了」的比例。很多人会发现这个比例远高于自己最初的预期——这正是「难成≠必败」的证据。

## 1_4 速喜

### 要点

本单元只读一宫：**速喜**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**火 · 南 · 朱雀 · 吉**

「速」是快，「喜」是喜讯。这一宫的关键词是**消息来得快**。

### 断辞与逐句释义

**速喜喜来临，求财向南行，失物申未午，逢人路上寻，官事有福德，病者无祸侵，田宅六畜吉，行人有音信。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 速喜喜来临 | 喜事将至 | 主「将至」，不是说已成 |
| 求财向南行 | 求财往南 | 方位提示 |
| 失物申未午 | 失物往**南至西南**一带找 | 申、未、午是地支，此处取**方位**义：午为正南，未、申为西南 |
| 逢人路上寻 | 在路上问人，能问到 | 重点是「问人」，不是「翻东西」 |
| 官事有福德 | 官司有转机 | 宜主动解决 |
| 病者无祸侵 | 问病无凶 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |
| 田宅六畜吉 | 家业、六畜都吉 | 问家宅、问宠物，吉 |
| 行人有音信 | 问行人，有消息来 | **消息先到，人未必立刻到** |

> **判据 · 为什么「申未午」取方位**：同一组断辞里，留连作「失物**南方**见」、小吉作「失物在**坤方**」，用的都是方位词；速喜这一句用干支，当与同组一致取方位。若按时辰解，则与其余五宫的写法脱节。这是本库取义，不是唯一古法。

### 速喜的误断

**把「快」当「成」。**

速喜主**讯息快、动静快**，事情确实在动，但动得快不等于成得稳。朱雀主口舌，速喜的「喜」常伴随「说」——**消息来了，事情本身还在后头**。

```
错误：速喜 → 喜来临 → 成了
正确：速喜 → 快 → 消息快、动静快 → 事情在动，但还在路上
```

### 实操

### 读速喜的三步

```
第一步：定性——这是「快」象，快在【讯息】与【动静】
第二步：分清楚——是「消息快」还是「事情快」？
        速喜首先验的是消息（行人有音信、逢人路上寻）
        事情本身成不成，要看三宫，不能只凭这一宫
第三步：配动作——速喜主「速」，遇到它宜早不宜迟
```

### 与其他宫的对照

```
速喜（快） vs 大安（静）
   同为吉，一动一静。问「什么时候有消息」，速喜快、大安不动

速喜（讯息） vs 小吉（和合）
   同为吉，速喜快在消息，小吉吉在谈得拢
```

### 案例小故事：消息来了，事情还在后头

朋友小陈投了一份简历，等了一周没回音，来问：「这两天会有消息吗？」掐出时宫**速喜**。

帮忙读课的同学说：「速喜，喜来临，稳了。」

小陈很高兴，跟家里说「差不多定了」。结果第二天确实收到了一封邮件——**是一封系统自动发的「已收到简历」确认信**，不是面试邀约。他空欢喜一场。

这一课其实读得很准，只是读的人把「快」读成了「成」：

```
正确的读法链条：
  速喜 → 讯息快 → 「会有消息」→ 消息是【音信】，不一定是【结果】

断辞里写得很清楚：
  「行人有音信」——是音信，不是人到
  「逢人路上寻」——在路上，是过程，不是终点
```

后来我们重新按三宫读了一遍：

```
月宫留连：背景是拖的（这家公司的招聘流程本来就慢）
日宫速喜：眼下消息快（会有回音）
时宫速喜：落点也是快
```

完整的读法应该是：**这两天会有消息，但那是流程上的回应，不是最终结果；真正的决定还得等一阵，因为背景是留连。**

小陈补了一句关键动作——既然「逢人路上寻」，那就主动去找人问。他托一位在那家公司工作的学长内推了一下，两周后拿到了面试。

**这一课的价值在于区分了「消息」与「结果」**：

```
速喜验的是：消息来得快、事情有动静
速喜不验的是：事情一定成
```

小陈后来在自己的笔记里给速喜写了一句备忘：

```
速喜 = 快，快在【消息】。
      凡问「有没有回音 / 什么时候有动静」，速喜最灵；
      凡问「能不能成」，速喜只答「在动」，不答「成了」
```

这个区分让他在后来的读课里少犯了很多错——因为他不再把「有消息」当成「有结果」了。

### 笔记与验证

速喜课的记录，加一个专用字段：

```
第1项 应的是「消息」还是「结果」？
   消息（有回音 / 有动静 / 有线索）
   结果（事情成了 / 办完了）
```

验证方式：统计自己速喜课里「应消息」与「应结果」的比例。多数人会发现「应消息」远多于「应结果」——这正是「快在讯息」的证据，也提醒你别把速喜当「成」来读。

## 1_5 赤口

### 要点

本单元只读一宫：**赤口**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**金 · 西 · 白虎 · 不顺**

「口」是口舌，「赤」是血色。这一宫的关键词是**冲撞**。

### 断辞与逐句释义

**赤口主口舌，官非切要防，失物急去寻，行人有惊慌，鸡犬多作怪，病者出西方，更须防咀咒，恐怕染瘟殃。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 赤口主口舌 | 口舌是非是这一宫的本色 | 少说少争 |
| 官非切要防 | 官司、纠纷要防 | 合同凭证补齐 |
| 失物急去寻 | 东西丢了赶紧找，晚了就没了 | **速度是关键**，不是慢慢找 |
| 行人有惊慌 | 问行人，人多半受了惊 | 主动联系确认安全 |
| 鸡犬多作怪 | 家宅不宁之象 | 引申：器物、设备易出状况 |
| 病者出西方 | 古法以西方为病象 | **文献引录，不构成就医方向建议**，身体不适请及时就医 |
| 更须防咀咒 | 古法对背后口舌、暗算的取象 | **不作诅咒实指** |
| 恐怕染瘟殃 | 古法对传染、牵连的警示语 | 文献引录，不作疾病预测 |

### 赤口的误断

**见「口舌」就以为只是吵架。**

赤口属金、配白虎，主的是**硬碰硬的冲撞**——不只是说话难听，也可能是争执、诉讼、外伤。断的时候要看问的是什么事。

```
问「会不会吵架」    → 口舌（吵架）
问「出行顺不顺」    → 冲撞（事故、车辆故障）
问「这事能不能谈成」→ 硬碰硬（对方态度强硬）
问「会不会受伤」    → 刚烈主伤（外伤之象，不作判断，注意安全）
```

### 实操

### 读赤口的三步

```
第一步：定性——这是「冲」象，硬碰硬，不是拌嘴
第二步：看问的是什么事——同一宫，问不同事，取的象不同
第三步：配规避——赤口是三不顺里最「可防」的一宫，务必给出防什么
```

### 赤口的规避清单（实用）

```
防口舌 → 少说话，重要沟通用文字，留痕
防官非 → 合同条款补齐，不签模糊条款，不做口头约定
防冲撞 → 出行前检查车况，慢行，避开高峰
防器物 → 重要设备、数据提前备份与检查
防暗算 → 不把关键底牌一次亮完
```

**赤口的价值就在规避**：它不是告诉你「要倒霉」，而是告诉你「防什么」。

### 案例小故事：一份没检查的合同

朋友开了家小工作室，接了个单子，对方发来合同让他签。他掐了一课，时宫**赤口**。

帮忙读课的同学说：「赤口主口舌，小心跟对方吵架。」

他听进去了，整个沟通过程都很客气，一句重话没说。合同也签了。半年后出问题——合同里有一条「验收标准由甲方单方认定」，对方据此扣了三成尾款。

回头看，那条口舌根本不在沟通里，而在**合同条款**里。

正确的读法应该是按「问的是什么事」来取象：

```
问的是「这合同能不能签」
  → 赤口的首要象不是「吵架」，而是「官非切要防」
  → 官非要防什么？防的是条款漏洞、防的是模糊表述
  → 动作：把合同逐条看一遍，特别是验收标准、付款条件、违约责任
```

而这一课的断辞里其实给了两条线索：

```
「官非切要防」  → 防的是规则层面的东西（合同）
「失物急去寻」  → 有东西在流失，要赶紧处理
```

如果当初按这两句读，他会在签之前把合同过一遍，那条「单方认定」大概率会被发现。

**这一课的教训**：赤口是三不顺里最具体的一宫，它的每一句断辞都指向一类可以提前防的事。把它简化成「小心吵架」，等于把六句断辞砍成了一句。

他后来给自己做了一张赤口排查表，凡是掐到赤口，就照着过一遍：

```
赤口排查表
  □ 合同 / 条款看过了吗？
  □ 重要沟通留痕了吗？
  □ 车况 / 设备检查了吗？
  □ 数据备份了吗？
  □ 这两天有没有要硬碰硬的场合？（有则缓一天）
```

这张表后来帮他躲过几次小麻烦。

### 笔记与验证

赤口课的记录，加一个专用字段：

```
第1项 我给出规避建议了吗？（有 / 无）
第2项 实际发生的，是「口舌」还是别的象（冲撞 / 官非 / 器物）？
```

验证方式：统计自己赤口课里「实际发生的象」的分布。如果你发现绝大多数都记成「口舌」，说明你可能只读了第一句——回去重读「赤口的误断」。

## 1_6 小吉

### 要点

本单元只读一宫：**小吉**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**木 · 六合 · 吉**

「小」是规模，「吉」是方向。这一宫的关键词是**和合、谈得拢**。

> **口径说明 · 方位**：宫位常配里**不单列方位**。断辞里的「失物在坤方」是失物这一句的取象，不是小吉的固定方位（见 `1_1`）。

### 断辞与逐句释义

**小吉最吉昌，路上好商量，阴人来报喜，失物在坤方，行人即便至，交易甚是强，凡事皆和合，病者祈上苍。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 小吉最吉昌 | 吉，但有个「小」字 | 是「吉昌」，不是「大获」。规模有限 |
| 路上好商量 | 出行吉，路上谈事易成 | 宜面谈、宜协商，不宜硬来 |
| 阴人来报喜 | 有女性一方带来好消息 | 留意来自女性角色的信息 |
| 失物在坤方 | 失物往西南、低处、承载之物找 | **这是失物句的取象，不是小吉的固定方位** |
| 行人即便至 | 问行人，人快到了 | 归期近 |
| 交易甚是强 | 买卖、谈判有利 | 宜成交，规模适中 |
| 凡事皆和合 | 以和为贵 | 协商优于强攻 |
| 病者祈上苍 | 问病需调养 | **古籍文献引录，不作医疗判断**，身体不适请及时就医 |

### 小吉的误断

**把「吉」字单独拿出来用。**

小吉的吉，是**有条件的吉**：条件就是「和」与「小」。

```
错误：小吉 → 吉 → 能成、能赚、能拿下
正确：小吉 → 和合 + 小 → 谈得拢、能成但规模有限
```

两个常见的偏差：

```
偏差一：只说方向不说规模
   「能成」→ 对方会脑补成「成我想要那么大」
   应说：「能成，但只是小成」

偏差二：把「和合」读成「自动成」
   小吉的吉在「谈得拢」，前提是你去谈
   不谈，和合就没有着力点
```

### 实操

### 读小吉的三步

```
第一步：定性——这是「和」象，吉在谈得拢
第二步：带上「小」字——断语里必须出现量级，别只说吉
第三步：配动作——「路上好商量」「凡事皆和合」都指向【协商】，
        所以动作是：去谈、去商量、找中间人
```

### 与其他宫的对照

```
小吉（和合） vs 大安（守成）
   同为吉，同属木（双木同气）。
   大安是守住现有的，小吉是谈拢新增的

小吉（渐进） vs 速喜（快速）
   同为吉，速喜快在消息，小吉慢在商量
```

### 案例小故事：那个「小」字值三分之一

个体店主老徐问：「这批货我能不能吃下来？打算把流动资金全压上。」掐出时宫**小吉**。

帮忙读课的同学说：「小吉最吉昌，能吃！」

老徐很高兴，准备全额吃下。临付款前，他多问了一句：「能赚多少？」

这一问，读课的人才注意到断辞开头那个「小」字：

```
「小吉最吉昌」——吉昌不假，但宫名就叫「小吉」
  → 能成，规模有限
  → 利润不会是爆发式的
  → 全额压上的风险与「小成」的回报不匹配
```

于是改了建议：

```
第1步 可以吃，但只吃一半
第2步 留足周转金
第3步 不要为凑量去借贷
第4步 「交易甚是强」「凡事皆和合」——跟供货商好好谈，
   争取分批提货、先付一部分
```

老徐听了，只进了一半的货，并且跟供货商谈成了分两批付款。

结果：货确实卖了，但卖了两个月才清完，利润比预期少了近四成——**如果当初全额压上，资金链会非常紧张。**

这一课的教训很典型：

```
断对了方向（能成）  ✓
没断量级（只是小成） ✗  ← 差点酿成实际的资金问题
```

老徐后来总结了一句很实在的话：**「能成」和「成多大」是两个问题，我只问了第一个。**

读课的人也补了一条规矩：凡是断语里有吉凶判断的，必须跟一个量级词。

```
量级词清单（小吉适用）：
   小成 / 适中 / 规模有限 / 不是大获
```

**这里还有第二层**：小吉的吉在「和合」。老徐跟供货商谈成分批付款，正是「路上好商量」「凡事皆和合」的用法——**小吉的吉，是你谈出来的，不是等来的**。

### 笔记与验证

小吉课的记录，加两个专用字段：

```
第1项 是否成（成 / 不成）
第2项 量级是否符合「小成」？（偏小 / 适中 / 偏大）
```

验证方式：统计「方向对了但量级没说」的比例。这个比例通常会很高，是提升空间最大的地方。每次读小吉，强迫自己带上量级词。

## 1_7 空亡

### 要点

本单元只读一宫：**空亡**。先看宫义、五行与六神，再逐句读断辞；断辞是象，不是判决书。

**土 · 中 · 勾陈 · 不顺**

这一宫的关键词是**落空、迟滞、抓不住**。

### 断辞与逐句释义

**空亡事不祥，阴人多乖张，求财无利益，行人有灾殃，失物寻不见，官事有刑伤，病人逢暗鬼，禳解可安康。**

| 句 | 释义 | 实操读法 |
|---|---|---|
| 空亡事不祥 | 事情没有好结果 | 先按「抓不住」论断，不是「一定失败」 |
| 阴人多乖张 | 有不明朗、有变数 | 信息不全，事情里有你没看到的部分 |
| 求财无利益 | 投入无回报 | 不宜投入、不宜担保 |
| 行人有灾殃 | 外出的人不顺，音信渺茫 | 主动联系确认安全 |
| 失物寻不见 | 找不到 | 不要在这件事上耗太多精力 |
| 官事有刑伤 | 官司不利 | 早做止损准备 |
| 病人逢暗鬼 | 问病不明朗 | **文献引录，不作医疗判断**；实用读法：做全面检查，别满足于一次查不出 |
| 禳解可安康 | 古法化解之语 | **文献引录，不代表提倡仪式**；实用读法：做风险预案 |

> **口径说明 · 首句异文**：首句「事不祥」，另有「事不長」「事不禅」等写法并存，本库暂从「事不祥」（见 `1_1` 待考表）。「祥」言吉凶，「長」言久暂——取法不同，第一句读法的侧重也不同，但宫义不变。

### 空亡的误断

**把「空」读成「凶」。**

空亡的核心是**没有**，不是**坏**。

```
赤口 = 出了坏事（有损失、有冲撞）
空亡 = 什么都没发生（投入归零、事情消失）
```

```
问投资：赤口 → 亏了（钱有去有回，回得少）
        空亡 → 落空（项目黄了，或根本没启动）

问出行：赤口 → 路上出状况
        空亡 → 去不成（取消、改期、白准备）
```

### 空亡的反转读法

**问法不同，读法相反**——这是空亡最重要的一条：

```
问「好事能不能成」   → 空亡 = 抓不住、不成
问「坏事会不会来」   → 空亡 = 落空、不会来（对问事人而言是好的）
```

```
例一：问「这单能签吗」      → 空亡：签不成
例二：问「对方会起诉我吗」  → 空亡：不会起诉，这事落空
```

**判断标准**：先问自己「对问事人来说，这是好事还是坏事」，再定吉凶方向。

### 实操

### 读空亡的三步

```
第一步：定性——这是「空」象，是【没有】，不是【坏】
第二步：看问题性质——问好事还是问坏事？（决定吉凶方向）
第三步：配动作——空亡最有用的动作是「别投入」与「做预案」
```

### 空亡在不同宫位的差别

```
空亡在月宫 → 背景落空：这件事的外部环境本身就是虚的
空亡在日宫 → 事体落空：事情本身没有实质内容
空亡在时宫 → 落点落空：最终抓不住（最常关注的一处）
```

### 案例小故事：一句「会出事吗」

学员小吴出差前一天问：「明天这趟顺利吗？」掐出时宫**空亡**。

他一看「大凶」，紧张地问：「会不会出车祸？」

这就是典型的把「空」读成「凶」。我们按宫义重读：

```
空亡 = 没有、落空
   在出行这个场景里，最常见的应法是：
   第1种 这趟去不成（取消、改期）
   第2种 去了也白去（对方不在、事情没办成）
   而不是「路上出事」
```

给他的动作建议是：

```
第1步 出发前再跟客户确认一次时间地点
第2步 如果对方临时改期，别硬去
第3步 别为这趟做太多前置投入（别提前垫付大额费用）
```

结果：客户临时出差，行程取消。小吴本人毫发无损，只是白准备了一场。

他在复盘里写了一句很到位的话：**「我断『不顺利』，实际是『根本没发生』。虽然都算我说中了不好，但感受完全不同——我没遇到任何麻烦，只是空忙了一场。」**

半年后他又遇到一次空亡，这次问的是别人：朋友想投一个项目，问「能回本吗」。他掐出空亡，这次他直接说：

```
「卦上看这事会落空，不是亏，是白忙。
 我的建议是别投，如果实在想参与，只用极小额试水，
 而且要拿到书面协议。」
```

朋友没投。后来那个项目出了问题，投进去的人全亏。

**同样是空亡**，前一次是「出行取消」，后一次是「别进场」。两次都读对了，因为两次都抓住了「空 = 没有」这个核心，而不是「空 = 凶」。

他后来给空亡写了一条备忘：

```
空亡 = 没有
  问好事 → 抓不住，别投入
  问坏事 → 不会来，可以放心
  问出行 → 可能去不成，出发前再确认
  问病   → 不明朗，去做全面检查（不作医疗判断）
```

### 笔记与验证

空亡课的记录，加一个专用字段：

```
第1项 问题性质：求成（问好事能否成） / 避险（问坏事会不会来）
```

验证方式：分别统计「求成类」与「避险类」的命中率。**如果避险类明显偏低，说明你还没掌握空亡的反转读法**——回本单元重读「空亡的反转读法」。

*六个宫读完，手上这把尺子就有了刻度。刻度要用起来，还得先拿到三个数。*

## 2_1 起课的输入：月、日、时与配数

### 要点

### 一、起课只要三个数

```
月数：正月至十二月   → 1 ~ 12
日数：初一至三十     → 1 ~ 30（遇小月只到廿九）
时数：子时至亥时     → 1 ~ 12
```

这三个数是**起课那一刻**的时间，不是出生时间，也不是你想到要起课的那一天的任意时刻。

**取数时刻**：以起心动念那一刻为准。动念与掐指通常相隔几秒，落在同一时辰内，无差别；若正好跨在时辰边界上（例如动念在十二点五十八分、掐指已过十三点），本库口径是**按动念那一刻**——小六壬取的是「感」在念起时。

### 二、不用什么

```
✗ 不用生辰八字
✗ 不用问事人的生肖、性别、姓名
✗ 不用铜钱、蓍草、签筒
✗ 不用排盘
```

只要三个数。手上记熟六宫位置（见 `1_1`），随时可以掐指起课。

### 三、配数：象数标记，不作断卦依据

民间传承里，六宫各配一组数字，称为「配数」：

| 宫 | 配数 |
|---|---|
| 大安 | 一、五、七 |
| 留连 | 二、八、十 |
| 速喜 | 三、六、九 |
| 赤口 | 四、七、十 |
| 小吉 | 一、五、七 |
| 空亡 | 三、六、九 |

> **口径说明 · 重要**：配数**仅作象数标记**。一说可用于应期，但说法不一，**本库不作为断卦依据**（见 `1_1` 待考表）。

那么，「什么时候」「多久」这一类问题怎么读？**从宫义读，不从数字读**：

```
速喜 → 快（讯息快、动静快）
留连 → 迟（拖延、滞留）
大安 → 不动（暂时没有动静）
赤口 → 急（突发、来得急）
小吉 → 渐（商量着来，一步一步）
空亡 → 无（抓不住、没有结果）
```

**宫义给的是「态势的时间感」，不是具体天数。** 想要更细的时间判断，本库不提供——宁可少说，不硬给数字。

### 四、变通取数法

正统取数是农历月、日、时三数。民间另有变通：用任意三个数代替月、日、时（如请对方随口报三个数），推算过程完全相同。

```
本库口径：
  正统取数（月日时）为默认口径
  变通取数可用，但须在笔记中标明「报数起课」
  两种口径的记录分开统计，不混算
```

使用变通法时有一条硬要求：**报数要随口，不能挑**。人心会自动挑吉利的数，一挑，取数就不再是「那一刻的气机」，课也就没有意义了。

### 实操

### 起课前的三项确认

```
┌──────────────────────────────────────────────┐
│ 第1项  农历月数：____月                      │
│        正月1 二月2 三月3 四月4 五月5 六月6   │
│        七月7 八月8 九月9 十月10 冬月11 腊月12│
│                                              │
│ 第2项  农历日数：____日                      │
│        初一1 初二2 初三3 初四4 初五5 初六6   │
│        初七7 初八8 初九9 初十10 十一11 十二12│
│        十三13 十四14 十五15 十六16 十七17    │
│        十八18 十九19 二十20 廿一21 廿二22    │
│        廿三23 廿四24 廿五25 廿六26 廿七27    │
│        廿八28 廿九29 三十30                  │
│                                              │
│ 第3项  时辰序号：____时                      │
│        子1 丑2 寅3 卯4 辰5 巳6               │
│        午7 未8 申9 酉10 戌11 亥12            │
│                                              │
│ 三个数【同时确认、写下来】，再开始掐         │
└──────────────────────────────────────────────┘
```

**不要边查边掐。** 查一个掐一步，中途一打断，数字就忘了；然后你会「凭印象」重查，出错率极高。

### 常见取数错误

| 错误 | 后果 | 预防 |
|---|---|---|
| 拿公历月日直接数 | 全错 | 起课前先默念「农历X月初X」 |
| 把「冬月」「腊月」数错 | 月宫错 | 冬月=十一月，腊月=十二月 |
| 日子数到三十，但该月只有廿九天 | 日宫错 | 查当月是大月还是小月（见 `2_2`） |
| 时辰按「几点」而不是「第几时辰」 | 时宫错 | 用对照表（见 `2_3`） |
| 中途被打断后凭印象续数 | 落宫错 | 全部重掐，不续数 |

### 案例小故事：公历与农历差了一个月

一位学员第一次实战，是在一场客户谈判前。他问「今天这单能不能签」，掐出**空亡**。

他一看「落空」，心里就凉了。整场谈判他都在想「反正签不成」，报价时没敢坚持，客户压价他也没还嘴，最后对方说「再考虑考虑」，单子黄了。

回来复盘，他把当时的数字报出来：公历八月五日，他把「8 月 5 日」直接当成了月数 8、日数 5。

查一下那天：是**农历六月廿二**。

按正确的数重掐：

```
月：大安(正)→留连(二)→速喜(三)→赤口(四)→小吉(五)→空亡(六)  → 六月落空亡
日：从空亡起初一，数到廿二
     拆圈 22 = 6+6+6+4，从空亡数 4 格 → 留连
时：从留连起子时，数到谈判那一刻的时辰
```

结果根本不是他当时读到的那一课——**他把公历当农历，第一步就错了，后面两步全跟着错。**

这件事有两层教训：

```
第一层 · 技术：公历农历必须换算，这一步没有捷径
        差一个月，月宫就差一整圈

第二层 · 心理：一个错误的结果，会通过影响你的状态而「自我实现」
        他因为读成「落空」而消极，谈判自然谈不好
        ——课没能算准事情，却实实在在影响了做事的人
```

第二层尤其要紧。这一课的讽刺之处在于：**他读出的「落空」最后居然应验了，但那是他自己造成的。** 如果那天他读成「速喜」，多半会拼一把，结果可能完全不同。

这也是本库反复强调的那句话：**读出不顺，是提醒你调整策略，不是让你躺平。**

后来他养成了个习惯：起课前，先把农历月日时三个数写在纸上，掐完再核一遍纸质记录。他说这一步花不了十秒，但让他再也没犯过同样的错——**写下来，是防错最便宜的办法。**

### 笔记与验证

笔记的「时间」栏要求**公历与农历双写**：

```
公历：____年__月__日 __:__
农历：__月__日 __时（时辰第__）
```

双写的好处：复盘时能一眼看出有没有发生公农历混淆。检查方法：翻出自己最早的十条记录，逐条核对农历是否写错。

## 2_2 农历月日与大小月

### 要点

### 一、月份从「正月」数起

```
正月1　二月2　三月3　四月4　五月5　六月6
七月7　八月8　九月9　十月10　冬月11　腊月12
```

口语里的别名要能立刻换算：

```
冬月 = 十一月
腊月 = 十二月
```

### 二、日子用「初一、初二」这一套说法

```
初一1　初二2　初三3　初四4　初五5　初六6　初七7　初八8　初九9　初十10
十一11　十二12　十三13　十四14　十五15　十六16　十七17　十八18　十九19　二十20
廿一21　廿二22　廿三23　廿四24　廿五25　廿六26　廿七27　廿八28　廿九29　三十30
```

「廿」读 niàn，即二十。「廿三」就是二十三。

### 三、大小月：日子只能数到当月实际有的那一天

**农历月有三十天，也有二十九天。**

```
大月 → 三十天，可以数到三十
小月 → 二十九天，最多只能数到廿九
```

如果那天是廿九，而该月只有廿九天，那它就是该月最后一天，直接按 **29** 算——**不存在「三十」这一天，硬数就会错一位**。

### 四、怎么查

```
方案一（推荐）：手机自带日历，设置里打开「显示农历」
方案二：万年历 App 或网页，输入公历日期查对应农历
方案三：黄历类工具，日历每格直接显示农历日、干支与宜忌
```

查的时候**一次把月、日两个数都记下来**，再进入下一步。

### 五、闰月的处理

农历置闰时会多出一个月（如「闰四月」）。本库口径：

```
以所用历书标注的月份为准起课；
遇闰月时在笔记中标注「闰」字，便于日后单独复核。
```

> 这样做的原因：闰月的取数口径在民间传承中说法不一，本库不擅自立一条规矩。**标出来、单独看**，比硬选一种说法更稳妥。等你自己积累到足够多的闰月课例，再决定要不要单独统计。

### 实操

### 三步查数卡

```
┌──────────────────────────────────────────────────┐
│ 第1步  查今天农历是几月几日？  → __月__日        │
│ 第2步  这个月是大月还是小月？  → 大(30) / 小(29) │
│ 第3步  日子有没有超出？        → 若写「三十」而  │
│        当月是小月，说明查错了，重查              │
└──────────────────────────────────────────────────┘
```

### 常见错误清单

| 错误 | 症状 | 校正 |
|---|---|---|
| 公历当月日 | 结果全错 | 先换算，写下来 |
| 冬月腊月没换算 | 月宫差 | 冬月=11，腊月=12 |
| 小月数到三十 | 日宫差一位 | 核对当月天数 |
| 只查日期不查月份 | 月宫错 | 月、日一起查 |
| 闰月未标注 | 复盘时无法复核 | 记「闰」字 |

### 案例小故事：小月里的一天

有位同学记日期很仔细，每一课的农历都写得整整齐齐。但连着三课读下来都说不通——问的是「这周能不能定下来」，读出来的却全是「落空」，而实际事情一直在推进。

翻他的记录，问题不在读法，在日期。

那个月是小月，只有廿九天。他查到「廿九」之后，第二天想当然地接着写了「三十」——而那一天其实已经是**下一个月的初一**。

```
他记的：  六月三十
实际的：  七月初一
```

差一天，月宫和日宫各差一位，整课的落点就跟着偏了。他把三课重新掐了一遍，落宫全都对不上原来记的那三个。

为什么会犯这种错？因为**公历的月份长度是固定的**，四月就是三十天，手会习惯性地往下数；而农历的月末是会变的——这个月廿九就到底了，下个月可能三十才到底。用公历的手感去数农历，月末这两天几乎必错。

我让他做一件事：查日期的时候，**顺手看一眼下一天是什么**。

```
查完今天，顺带看明天：
  明天是初一 → 今天就是月末（可能是廿九，也可能是三十）
  明天是别的 → 今天不是月末，照常记
```

这个笨办法立刻解决了问题。他后来把它写进查数卡，还加了一条：**月末这两天起课，写完之后再核一次农历**——因为这两天是错误率最高的地方。

后来他复盘说，那三课之所以读得离谱，是因为他信了自己记的落宫。落宫错了，后面读得再认真也是在给一个错的图配故事。**取数这一步错了，后面全白做。**

### 笔记与验证

笔记里加两个字段：

```
月份天数：大(30) / 小(29)
是否闰月：是 / 否
```

验证方式：每月底翻一次记录，核对当月的天数是否与历书一致；如果有「三十」出现在小月里，把那一课标记为「取数有误」，不计入有效统计。

### 要点

### 一、十二时辰对照表

|---|---|---|---|---|---|
| 1 | 子 | 23:00 – 01:00 | 7 | 午 | 11:00 – 13:00 |
| 2 | 丑 | 01:00 – 03:00 | 8 | 未 | 13:00 – 15:00 |

| 4 | 卯 | 05:00 – 07:00 | 10 | 酉 | 17:00 – 19:00 |
| 5 | 辰 | 07:00 – 09:00 | 11 | 戌 | 19:00 – 21:00 |
| 6 | 巳 | 09:00 – 11:00 | 12 | 亥 | 21:00 – 23:00 |

### 二、必背的三个锚点

```
子时：23:00 – 01:00   ← 跨日，最易错
午时：11:00 – 13:00   ← 中午，最常用
卯时：05:00 – 07:00   ← 早晨
```

再加三个凑成完整节奏感：

```
辰时 07–09（上班路上）
未时 13–15（下午开工）
酉时 17–19（下班）
```

背熟这六个，其余六个（丑、寅、巳、申、戌、亥）自然能推出来。

### 三、边界时刻

正好踩在整点怎么办？例如十三点整。

```
13:00 属【未时】，不属午时
规则：时辰区间为 [起点, 终点)，起点计入，终点不计入
```

即午时到 12:59:59 为止。**边界影响极小**（你几乎不会正好在整点起课），但口径要统一，否则统计时会出现说不清的偏差。

### 四、三步起课法

**口诀：大安起正月，月上起日，日上起时。**

```
第一步 · 起月宫
   从大安起正月，顺时针数到当前农历月

第二步 · 起日宫
   从【月宫】起初一，顺时针数到当前农历日

第三步 · 起时宫
   从【日宫】起子时，顺时针数到当前时辰
```

**关键机制**：**每一轮的起点，都是上一轮的落点。**

```
大安 ──(数月)──> 月宫 ──(数日)──> 日宫 ──(数时)──> 时宫
```

> 最常见的错误：把三步各起各的，每一轮都从大安重新开始。记住——只有**起月**从大安起，起日、起时都是从上一轮的落点起。

### 实操

### 标准演示：农历三月初五，辰时

```
【第一步 · 月】大安(正月) → 留连(二月) → 速喜(三月)
                                              ↑ 落点
                                        月宫 = 速喜

【第二步 · 日】从速喜起初一：
               速喜(初一) → 赤口(初二) → 小吉(初三)
               → 空亡(初四) → 大安(初五)
                                ↑ 落点
                          日宫 = 大安

【第三步 · 时】从大安起子时，辰时是第 5 个时辰：
               大安(子) → 留连(丑) → 速喜(寅)
               → 赤口(卯) → 小吉(辰)
                              ↑ 落点
                        时宫 = 小吉

结果：月宫速喜 / 日宫大安 / 时宫小吉
```

链路图（初学建议画在纸上）：

```
【月】大安 →(1)留连 →(2)速喜                     ← 三月落速喜
                      │
                      ▼
【日】速喜 →(1)赤口 →(2)小吉 →(3)空亡 →(4)大安   ← 初五落大安
                                    │
                                    ▼
【时】大安 →(1)留连 →(2)速喜 →(3)赤口 →(4)小吉   ← 辰时落小吉

              最终结果：时宫 = 小吉
```

> 注意：链路上的 (1)(2)(3) 编号是**每一轮各自重新编号**（每轮都从该轮起点数 1），不是连续编号。这是画链路图时最容易搞混的地方。

### 进阶演示：农历八月十七，辰时（日数超过十二）

```
【月】大安(正)→留连(二)→速喜(三)→赤口(四)
     →小吉(五)→空亡(六)→大安(七)→留连(八)
     月宫 = 留连

【日】从留连起初一，数到十七
     拆圈法：17 = 6 + 6 + 5
       数 6 格 → 回到留连（第一圈完，剩 11）
       数 6 格 → 回到留连（第二圈完，剩 5）
       数 5 格 → 留连(1)速喜(2)赤口(3)小吉(4)空亡(5)
     日宫 = 空亡

【时】从空亡起子时，辰时是第 5 个时辰：
     空亡(子)→大安(丑)→留连(寅)→速喜(卯)→赤口(辰)
     时宫 = 赤口

结果：月宫留连 / 日宫空亡 / 时宫赤口
```

**拆圈法**：任何超过六的数，先减掉六的倍数，再数剩下的。日数常常是十几、二十几，这招最实用。

### 校验三法

```
校验一 · 倒推
   从时宫倒着数回去：时宫 →(倒数时辰数)→ 日宫
                    →(倒数日数)→ 月宫 →(倒数月数)→ 大安
   倒不回大安，说明中间错了

校验二 · 拆圈复核
   大数用拆圈法重数一遍，看是否与第一次一致

校验三 · 互掐
   两人同时掐同一时间，比对结果
```

### 常见掐算错误与处方

| 错误 | 症状 | 处方 |
|---|---|---|
| 每轮都从大安起 | 结果偏固定，总与大安相关 | 记住「起点=上轮落点」 |
| 跳格、滑格 | 落宫总差一位 | 念出声 + 拇指按压力度确认 |
| 大数绕晕 | 十几、二十几错 | 拆圈法 |
| 中途被打断 | 忘了数到几 | 全部重掐，不续数 |
| 时辰换算慢 | 报个钟点要想半天 | 背熟对照表，做够五十次成条件反射 |

### 熟度标准

```
入门级：任意给一个农历时间，2 分钟内掐出三宫
合格级：60 秒内掐出三宫
熟练级：30 秒内掐出三宫，且十次无错
```

达到「合格级」就可以开始读课；「熟练级」是日常使用的门槛。

### 案例小故事：被电话打断的那一课

学员正在掐一课，数到日宫第十七格时，电话响了。接完电话，他「记得自己数到过赤口」，就从赤口接着往下数。

结果当然错了。这类错误的特点是：**你不会觉得自己错了**——因为你是凭印象续的，印象里自己没数错。

解决只有一条硬性规定：

```
起课过程中被打断 → 全部重来，不许续数
```

有人会问：「重起一次，气机不就变了吗？」确实，严格说第二次起念与第一次不同。但比起一个错误的结果，**重起一课的代价更小**。

更好的办法是起课前给自己十秒钟安静：

```
第1步 手机静音
第2步 确认三个数，写下来
第3步 一口气掐完
第4步 立刻记录
```

整个流程不超过三十秒。养成这个习惯，能消灭九成的「莫名其妙的错课」。

他后来做了一件事：把自己的错题按类型统计，找出惯性错误。

```
错误类型统计（他的情况）
  大数绕晕    ████
  时辰换算    ██
  跳格        █
```

**掐算错误不是随机的，每个人都有自己的惯性错误。** 有人总在时辰上错，有人总在大数上错，有人总是跳格。找出你的那一类，专攻它，比盲目练一百遍有用得多。

### 笔记与验证

每条记录加一个字段：**起课状态（顺畅 / 被打断后重掐 / 中途续数）**。

```

  每月统计一次「顺畅课」与「重掐课」的读课准确率
  若两者接近 → 说明重掐无害，放心重掐
  若差异明显 → 起课过程需要更严格的保护（静音、先写数、一口气掐完）
```

另外，把掐出的三宫写成一行，便于快速核对：

```
农历X月X日X时 → 月X / 日X / 时X

```

*三个数拿得准，课就起得准；起得准，才有资格谈读得准。*

## 3_1 三宫分工与主次

### 要点

### 一、三宫各管一段

三步起课掐出来的三个宫，不是三个答案，而是**一件事的三个层次**：

```
┌──────────────────────────────────────┐
│  月宫 · 背景层                        │
│    这件事所处的环境、外部条件          │
│    他人、时机、事情的来路              │
├──────────────────────────────────────┤
│  日宫 · 事体层                        │
│    这件事本身当下的状态                │
│    事情走到哪一步、卡在哪              │
├──────────────────────────────────────┤
│  时宫 · 落点层                        │
│    这件事最终往哪去                    │
│    读课的主答案在这里                  │
└──────────────────────────────────────┘
```

> **口径说明 · 三宫名目**：本库只用「月宫 / 日宫 / 时宫」，不采「天/人/地」或「初/中/末」等名目。三个名字对应三个输入（月、日、时），名实一致，不容易混。

### 二、主次怎么分

```
主：时宫（落点）—— 回答「往哪去」，是读课的主答案
次：日宫（事体）—— 回答「眼下怎样」，补充过程
辅：月宫（背景）—— 回答「环境如何」，说明条件
```

**常见的错误**：把三宫当成三个并列的吉凶标签，挑一个「最像」的来读；或者把三宫平均用力，读完不知道重点在哪。

正确的顺序是：

```
先读时宫 → 定基调
再读日宫 → 补过程
后读月宫 → 看条件
最后三宫串成一句话
```

### 三、先读单宫，再读三宫

```
第一步 · 单宫：每一宫各自是什么象？
   按板块1 的宫义与断辞，各读一句

第二步 · 三宫：三层串起来讲了一个什么故事？
   背景如何 → 眼下怎样 → 最终往哪
```

**不要跳过第一步。** 三宫串读是在单宫读准的基础上做的；单宫读错了，串出来的故事再顺也是错的。

### 实操

### 三宫读取流程

```
        掐出三宫
             │
             ▼
    ┌─────────────────┐
    │ 读时宫（主答案） │
    └─────────────────┘
             │
             ▼
    ┌─────────────────┐
    │ 读日宫（过程）   │
    └─────────────────┘
             │
             ▼
    ┌─────────────────┐
    │ 读月宫（环境）   │
    └─────────────────┘
             │
             ▼
    三宫串成一句话剧情
             │
             ▼
    输出：态势 + 取向（该怎么做）
             │
             ▼
    当场记入占验记录
```

### 四种典型的三宫形态

**形态一 · 一路顺（月吉 → 日吉 → 时吉）**

```
例：月大安 / 日速喜 / 时小吉
读：环境安稳 → 眼下消息快 → 落点是和合
串：事情底子稳，眼下在动，最后谈得拢
断：能推进，但小吉带「小」字，规模有限
```

**形态二 · 先难后易（月不顺 → 日平 → 时吉）**

```
例：月空亡 / 日留连 / 时速喜
读：背景虚 → 眼下拖 → 落点快
串：开头没着落，中间磨一阵，最后会快起来
断：别急，等一等；等到了就别再拖
```

**形态三 · 虎头蛇尾（月吉 → 日吉 → 时不顺）**

```
例：月大安 / 日速喜 / 时空亡
读：环境稳 → 眼下热闹 → 落点抓不住
串：看着挺顺，最后落空
断：过程顺利不等于结果有；留个心眼，别提前投入
```

**形态四 · 从头卡到尾（月不顺 → 日不顺 → 时不顺）**

```
例：月留连 / 日赤口 / 时空亡
读：环境拖 → 眼下冲 → 落点空
串：一路不顺，越走越紧
断：缓一缓，或另择时机；硬来只会更糟
```

### 三宫矛盾时怎么处理

最常见也最难受的情况：**月吉时凶**或**月凶时吉**。

```
原则：以时宫为主答案，月宫作条件说明

月吉 + 时凶 → 「环境不错，但落点抓不住。别被表面的顺骗了」
月凶 + 时吉 → 「环境不利，但落点是好的。能成，但过程不好受」
```

**月宫是路况，时宫是终点。** 路况好不等于到得了，路况差不等于到不了——但路况会影响到不了的方式。

### 只用一宫行不行

```
新手期：可以先只看时宫，先把「掐准 + 读懂单宫」练熟
进阶后：必须三宫全读，否则信息浪费严重
```

理由：三宫提供的不是三种答案，而是**一条线索**。只读落点，你就不知道该在哪个环节使劲。

### 案例小故事：offer 那三宫

朋友拿到一个大公司的录用意向，来问「该不该接」。掐出 **月大安 / 日速喜 / 时空亡**。

他先看了前两宫：大安（稳）、速喜（快），高兴地说「稳了」。

我让他再看第三宫：空亡。

三宫串起来的故事是这样的：

```
月宫大安 → 公司看着很稳，外部环境没问题
日宫速喜 → 流程推得很快，人事很热情，意向很快就发
时宫空亡 → 落点抓不住
```

完整读法：**过程顺利，结果落空**——典型的「虎头蛇尾」形态。

这一课如果只看前两宫，他会栽跟头；如果只看时宫，他会一头雾水（明明一切顺利啊）。三宫连起来，才看得出「**流程走得很顺，但最后一步会出问题**」这个特定剧情。

于是给他的建议不是「别接」，也不是「接吧」，而是落到动作上：

```
第1步 意向照接，但不要立刻辞掉现在的工作
第2步 入职时间往后推一周
第3步 等所有书面材料齐了再动：
   薪资结构、岗位、汇报线的正式文件
```

结果：意向发了，入职前一周，那家公司内部架构调整，岗位被取消。他因为没辞职，**损失为零**。

**这一课的价值，在于断语落到了动作上**：

```
没用的断语：「这事不成」
有用的断语：「意向照接，但等书面齐了再辞职」
```

后来他把这一课记下来，加了一句备注：「凡是月吉 + 时凶的组合，一律加一句『别提前投入』」。

### 笔记与验证

记录里的「落宫」栏要求三宫全写，并在旁边用一句话串起来：

```
月X / 日X / 时X
一句话串读：______________________
```

**这个「一句话串读」是训练三宫读法最有效的练习**——强迫你把三个符号翻译成一个连贯的剧情。

验证方式：翻出自己最早的二十条记录，看有没有「只记了时宫、没记三宫」的。有，就补记（若还记得的话）；补不了的，标记为「记录不完整」。

## 3_2 生克与同气

### 要点

### 一、生克是什么

生克是五行之间的两条基本关系，用来读**态势的传递方向**。

```
相生（顺）：木 → 火 → 土 → 金 → 水 → 木
相克（逆）：木 → 土 → 水 → 火 → 金 → 木
```

记忆法：

```
相生 = 滋养：木燃火、火化土、土藏金、金凝水、水养木
相克 = 制约：木破土、土挡水、水灭火、火熔金、金砍木
```

### 二、只看两段关系

三宫之间只看两段：

```
月宫 → 日宫：背景对事体的作用
日宫 → 时宫：事体向落点的转化
```

**不看月宫直接对时宫。** 隔一层的关系不读——这是本库的边界，多读一层就会开始编故事。

### 三、五种关系怎么读

以「后者」为参照：

| 关系 | 含义 | 读法 |
|---|---|---|
| 生我 | 前宫生后宫 | 得助，有人推一把 |
| 我生 | 后宫生前宫（前宫泄气） | 泄气，在付出、在消耗 |
| 克我 | 前宫克后宫 | 受压，有阻碍 |
| 我克 | 后宫克前宫 | 可得，但要费力 |
| 比和 | 五行相同 | 同类相应，特征加强 |

六种五行对照（复习，不展开宫义）：

```
大安 = 木   留连 = 水   速喜 = 火
赤口 = 金   小吉 = 木   空亡 = 土
```

### 四、双木同气（必记）

**大安与小吉同属木。三宫中若同时出现二者，它们之间不作生克论，只作「同类相应」看。**

```
边界：双木同气只免除【这两宫之间】的生克，
      不免除它们与第三宫的生克。

例：大安 / 小吉 / 赤口
    大安与小吉 → 双木同气，不论生克
    赤口金 克 双木 → 仍然成立
```

### 五、生不一定吉，克不一定凶

> **口径说明 · 关键**：**生克不是吉凶判断。** 生不一定吉，克不一定凶，必须结合宫义与断辞。

```
生不一定吉：
  日宫生时宫，看似顺畅——但若时宫是空亡，
  「生」只是把能量送进了空处，过程是顺的，结果是空的

克不一定凶：
  时宫克日宫，看似受阻——但若时宫是速喜，
  「克」可能就是「快刀斩乱麻」，事情反而被推着走完
```

### 六、与八字旺衰划清界限

> **口径说明 · 边界**：三宫生克只用来读**态势的传递方向**（月→日、日→时），**不是五行力量的旺衰比较**。八字的「用神旺衰」是另一套逻辑，不要把八字的生克思维平移过来——那样会算出一堆本库根本不用的强弱结论。

具体说，本库**不读**这些内容：

```
✗ 某宫「旺」还是「衰」
✗ 某宫「得令」「失令」
✗ 某宫力量强弱打分
✗ 用生克反推吉凶强弱
```

### 实操

### 生克关系速查

```
以「我」为准：
  生我者（前宫生我） → 得助
  我生者（我生后宫） → 泄气
  克我者（前宫克我） → 受压
  我克者（我克后宫） → 可得但费力
  同我者（五行相同） → 比和 / 同气
```

### 生克的三步使用法

```
第一步：扫三宫有没有双木（大安 + 小吉）
        有 → 这两宫之间不论生克
第二步：算 月→日 这一段的五行关系
第三步：算 日→时 这一段的五行关系
        两段合起来，就是态势的传递方向
```

### 三条防过度解读的规则

```
规则一 · 生克不翻转宫义
   时宫空亡，谁生它都是「抓不住」
   时宫小吉，谁克它都是「小成」

规则二 · 生克只调整过程与程度
   不改变「态势往哪走」这个主答案

规则三 · 断辞优先
   生克推出来的结论与断辞冲突时，以断辞为准

限制 · 生克分析不超过三行
   超过三行，多半是在用分析逃避下结论
```

### 常见组合读法示例

```
第1例 月留连(水) → 日速喜(火)
   水克火 → 背景压制事体
   读：环境里有拖的东西在压着，眼下想快也快不起来

第2例 日速喜(火) → 时空亡(土)
   火生土 → 事体生落点（泄气）
   读：事情的能量流向了空处——过程热闹，落点抓不住

第3例 月大安(木) → 日速喜(火)
   木生火 → 背景生事体
   读：环境在推着事情走，眼下动得起来

第4例 日小吉(木) → 时赤口(金)
   金克木 → 落点克事体（事体受压）
   读：和合的过程最后撞上硬碰硬——谈得拢，收尾有硬坎

第5例 月小吉(木) → 日大安(木)
   双木同气 → 不论生克，同类相应
   读：背景与事体都是木气，这件事从头带着「生发、和合」的底色
```

### 案例小故事：分析了一整页，忘了回答问题

有位学员学生克之后，读课开始变得极复杂。他觉得「光看宫义太浅」，于是每课都要把五行关系写一遍，再配上六神、再配上方位。写得不亦乐乎，就是不给结论。

一次他读一个「这合同能不能签」的课，写了满满一页：

```
月宫赤口金，日宫大安木，时宫小吉木
金克木，月克日，说明环境压制事体
但日时皆木，双木同气，说明事体与落点是同一类
金克木，说明有外部压力
木克土，但这里没有土，这一段无从谈起
六合主和合，说明谈得拢
白虎主刚烈，说明对方强硬
```

我打断他：「所以，能不能签？」

他愣住了，说不出答案。过了几秒才说：「我再算算？」

**这就是过度解读的典型症状：分析了一整页，忘了回答问题。**

有意思的是，他这一页里其实没有一句是错的——金克木没错，双木同气也没错。错在**没有一句落到实处**。术语越堆越多，离「签还是不签」反而越来越远。来问合同的朋友要的是一句话，不是一篇论文。

让他按三步重来：

```
第一步：扫双木 → 日宫大安(木) + 时宫小吉(木) = 双木同气
        → 这两宫之间不论生克，读作「过程到落点都是和合的底色」
第二步：月→日 → 赤口(金) 克 大安(木)
        → 背景压制事体：环境里有硬的东西在压着
第三步：落点是小吉 → 和合、小成
```

三行，答案就出来了：

```
能签（落点小吉），但对方条件会硬（月宫克日宫），
而且最终只是小成（小吉带「小」字），别指望大赚
```

后来他给自己定了条规矩：**生克分析不超过三行。** 超过三行，就说明你在用分析逃避下结论——而不下结论的读课，等于没读。

这个案例还有第二层价值：它提醒我们**生克是「调味」，不是「主菜」**。主菜永远是宫义与断辞，生克只用来读「态势怎么从这一步传到下一步」。

### 笔记与验证

记录里加两个字段（进阶后用）：

```
月→日关系：生 / 克 / 比和 / 同气
日→时关系：生 / 克 / 比和 / 同气
```

验证方式：统计「用了生克」与「没用生克」两组课例的读课准确率。**如果用了生克反而更差，立刻停用**——很多人在自己手上是减分项，因为生克引入了过多的主观解释空间。

## 3_3 空亡与特殊读法

### 要点

### 一、空亡落在不同宫位，意思不同

宫义见 `1_7`，此处只讲「落在哪一宫」的差别：

```
空亡在月宫 → 背景落空
   这件事的外部环境本身就是虚的：
   对方没定、制度未明、事情还没有实质基础

空亡在日宫 → 事体落空
   事情本身没有实质内容：
   看着在办，其实没有进展、没有内核

空亡在时宫 → 落点落空
   最终抓不住（最常关注的一处）：
   投入归零、事情消失、结果没有
```

### 二、空亡的反转读法

**问法不同，读法相反**：

```
问「好事能不能成」   → 空亡 = 抓不住、不成
问「坏事会不会来」   → 空亡 = 落空、不会来（对问事人而言是好的）
```

```
例一：问「这单能签吗」       → 空亡：签不成
例二：问「对方会起诉我吗」   → 空亡：不会起诉，这事落空
```

**判断标准**：先问自己「对问事人来说，这是好事还是坏事」，再定吉凶方向。

### 三、吉凶不是结论（总纠偏）

这条在 `1_1` 讲过，这里再从「纠偏」的角度补一层——**它是六条误读里最常见、也最难自觉的一条**。

同一宫，问法不同读法不同：

```
问「稳不稳」     → 大安是稳
问「进不进」     → 大安往往是「暂时不动」
问「有没有转机」 → 空亡往往是「眼下抓不住」，不是「永远没有」
```

把吉凶当结论用，是小六壬最常见的误用。

### 四、四种常见误读

```
误读一 · 把「静」读成「成」
   大安 = 静。问「会不会有进展」，答「会成」就错了

误读二 · 把「难」读成「绝」
   留连 = 拖。问「能不能办成」，答「没戏」就错了

误读三 · 把「快」读成「成」
   速喜 = 快在讯息。问「能不能成」，答「成了」就错了

误读四 · 把「空」读成「凶」
   空亡 = 没有。问「会不会出事」，答「要出事」就错了
```

### 实操

### 特殊读法的三步检查

```
第一步：这一宫有没有「双木」？（决定生克怎么论）
第二步：我这一课的空亡落在哪一宫？（决定「空」的是什么）
第三步：我问的是好事还是坏事？（决定空亡的吉凶方向）
```

### 完整读课的输出格式

```
【态势】这件事眼下像什么（一句话）
【取向】该怎么做（一个动词开头的具体动作）
【提醒】防什么 / 别做什么
```

**三条缺一不可。** 只答态势不给取向，等于把翻译工作推给了问事的人——而对方不懂六宫，翻译出来的往往是自己想要的那个版本。

### 断语措辞的边界

```
第1条 说倾向，不说定论
   ✗ 「这事一定不成」
   ✓ 「这事大概率抓不住，建议你做别的准备」

第2条 不顺的课必须配规避方案
   ✗ 「不顺，小心」
   ✓ 「赤口主冲撞。这次出门前检查车况，重要谈话留书面记录」

第3条 三条硬边界
   医疗：不说「你没病」「你会好」，一律「以医生诊断为准」
   法律：不说「一定赢/输」，说「宜和解 / 宜准备材料」
   财务：不说「一定会赚/亏」，说「风险偏高，建议控制投入」
```

### 案例小故事：一句「你没病」

有位学了几个月小六壬的爱好者，给邻居阿姨读课。阿姨说最近胃不舒服，他掐出**大安**，看到断辞「病者主无妨」，就说：「没事，卦上说你没病。」

阿姨信了，没去体检。三个月后确诊，是早期病变，拖了三个月。

复盘一下错在哪：

```
错误一 · 断辞理解错误
   「病者主无妨」是古人对「病势不凶险」的描述，
   不是「没有病」的医学结论

错误二 · 越界使用
   断辞里涉及「病」的部分，是民间经验的粗略归纳，
   完全没有诊断能力

错误三 · 措辞绝对化
   即便要读，也应该是「卦上看凶险程度不高，
   但仍建议您尽快做个检查」
```

后来他给自己定了条铁律，也写进了自己的笔记：

```
凡是涉及身体、法律、大额钱财的问事，
断语一律以「请走专业渠道」收尾，术数部分只作思路提示
```

这不是推卸责任，是对边界的尊重——**一把用来读「眼前顺不顺」的小折刀，不该拿去做手术。**

补充一个正面的例子：另一位学员遇到邻居问「最近总是头晕，要不要紧」。她掐出**空亡**。按断辞这是最不顺的一宫，但她的读法是：

```
「卦上看这个情况不太明朗，有『查不出原因』的意思。
 我不懂医，但这个结果提示你应该去做个全面一点的检查，别拖。
 如果第一家医院说没问题，建议换个医院再看看。」
```

邻居去做了全面检查，发现是血压问题，及时控制了。

**空亡在这个场景里的价值，不是「凶」，而是「别满足于一次查不出就放心」。** 这个读法既守住了边界，又真的帮到了人。

### 笔记与验证

记录里加一个字段：**问题性质（求成 / 避险）**。

```
求成：问好事能否成、能否推进
避险：问坏事会不会来、会不会出问题
```

验证方式：分别统计两组的准确率。**如果避险类明显偏低，说明你还没掌握空亡的反转读法**——回 `1_7` 重读「空亡的反转读法」。

另外，把下面这张检查表抄进笔记首页，每次读课过一遍：

```
┌──────────────────────────────────────────────┐
│ 读课三检                                     │
│  第1项  双木同气扫过了吗？                   │
│  第2项  空亡落在哪一宫？我问的是好事还是坏事？│
│  第3项  我有没有把吉凶当结论用？             │
│                                              │
│ 输出三件套                                   │
│  态势 ✓   取向 ✓   提醒 ✓                   │
└──────────────────────────────────────────────┘
```

*三宫读法到位，剩下的就是在真实的事情上反复磨。*

## 4_1 失物与行人

### 要点

### 场景特点

失物是小六壬最宜练手的题材——东西找没找到，一翻就知道，反馈最快。

「失物」与「行人」常并为一类，因为两者都在问「**东西/人在哪、动没动**」。

### 六宫直读（只列取句要点，断辞原文见板块1）

| 宫 | 东西/人在哪 | 怎么找 |
|---|---|---|
| 大安 | 没丢远，在近处 | 原地附近找；重点是「没被移动过」 |
| 留连 | 往南找；或在别人手上 | **主动开口讨**（急讨方遂心） |
| 速喜 | 在路上、经人之手 | **问人比翻东西重要**（逢人路上寻） |
| 赤口 | 被移动过，往西 | **立刻去找**，迟则难寻（失物急去寻） |
| 小吉 | 坤方：西南、低处、承载之物 | 找矮柜、盒子、托盘一类（失物在坤方） |
| 空亡 | 寻不见 | 别耗太多精力，留个联系方式等消息 |

行人同表：

| 宫 | 人在哪/状态 | 建议 |
|---|---|---|
| 大安 | 还没动身（行人身未动） | 别等，他还没出发 |
| 留连 | 还没踏上归途（去者未回程） | 会拖，保持联系 |
| 速喜 | 有消息来（行人有音信） | 消息先到，人后到 |
| 赤口 | 在外受惊（行人有惊慌） | 主动联系确认安全 |
| 小吉 | 快到了（行人即便至） | 准备接 |
| 空亡 | 音信渺茫 | 主动联系，必要时求助 |

### 实操

### 静动二分：先定「找法」，再定「方位」

```
静组（大安、留连、空亡）→ 东西/人基本没动
   找法：在「最后一次见到的地方」的半径内找

动组（速喜、赤口、小吉）→ 东西/人被移动过
   找法：沿动线找，且【问人】优先于【翻东西】
```

**顺序不能反**：先分静动（决定找法），再谈方位（缩小范围）。只给方位不给找法，对方会闷头乱翻。

### 追问三句（把范围缩到可行动）

```
第1问 最后一次见到/使用是什么时候、在哪？
第2问 那天走过哪些地方？（列动线）
第3问 有没有可能被别人动过？（同事、家人、保洁、店员）
```

按落宫匹配：

```
大安 → 不在动线上，在「最后一次使用地」附近
速喜、赤口 → 在动线上，且经过人手
留连 → 在别人手上，需要开口讨
小吉 → 西南方位 + 低处 + 承载类物件
空亡 → 先别耗，留联系方式等消息
```

### 方位取象的展开法

断辞给的是「南方」「坤方」这类大方向，要展开成具体位置才好找：

```
坤方（西南）→ 西南方位 + 低处 + 承载类物件（柜、盒、托盘、地面层）
南方        → 南边 + 明亮处（速喜）／水边一带（留连属水）
路上        → 动线 + 他人经手（前台、失物处、同事抽屉）
```

### 案例小故事：一个钱包，十分钟

同事午饭后发现钱包不见了，急得脸都白了，来问「还能找回来吗」。

掐出 **月赤口 / 日小吉 / 时小吉**。

按三宫主次读：

```
时宫小吉（主答案）：能找回，落点是「和合」
   → 断辞取「失物在坤方」：西南、低处、承载之物
日宫小吉（过程）  ：过程也是和合，说明不是被恶意拿走
月宫赤口（背景）  ：环境里有「移动、惊动」
   → 东西被人动过，而且动的时候带点慌张
```

三宫串成一句话：**东西被好心人动过（月赤口），过程没有恶意（日小吉），落在西南方向的某处（时小吉）。**

给她的三个寻找点，按可能性排序：

```
第1处 前台或失物处（被好心人收走的概率最高）
第2处 食堂座位（最后用餐的地方）
第3处 食堂回工位的动线
```

并强调一句关键的话：**先问人，别先翻东西。**

她去了前台，开口问了一句。前台说：「有人捡到交过来了。」钱包就在抽屉里。前后不到十分钟。

对照复盘：

```
月宫赤口  → 被人动过 ✓（捡到的人交给了前台）
日宫小吉  → 和合、无恶意 ✓（是好心人交还）
时宫小吉  → 坤方 ✓（前台恰在公司西南角，方位也巧）
```

她后来总结：最有用的那句不是方位，而是**「先问人，别先翻东西」**。如果她闷头在食堂翻半小时，钱包其实一直躺在前台。

这个案例还有一层：**「失物在坤方」这句断辞，如果不展开就会用错。** 「坤」不只是西南，还是「地」「承载」「低处」。若只告诉她「往西南找」，她大概会把家里西南角的柜子翻一遍；展开成「西南 + 低处 + 承载之物（柜台抽屉）」，才找对。

### 笔记与验证

失物类记录是最好的练习材料（反馈快）。记录字段：

```
失物：____
落宫：月X / 日X / 时X
读法：能不能找到？在哪？建议找法？
实际：在哪找到？用了多久？
命中项：能否找到 ✓/✗　方位 ✓/✗　静动判断 ✓/✗
```

验证方式：分别统计「能否找到」「静动判断」「具体方位」三项的命中率。多数人会发现**「能否找到」最准、「具体方位」最不准**——这提示你：方位只作参考，别当坐标用。

## 4_2 谋事与出行

### 要点

### 场景特点

「谋事」问的是一件事能不能推进、该怎么推进；「出行」问的是这一趟顺不顺。两者都涉及「动」，所以放在一起练。

### 六宫直读

**谋事（求财、办事、推进项目）**

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 稳，但不动 | 守成；不宜扩张，不宜求「快」 |
| 留连 | 拖，时机未到 | 缓一缓；涉及「要东西」的，主动去讨 |
| 速喜 | 快，消息快 | 趁早动；快在消息，不等于事已成 |
| 赤口 | 硬碰硬 | 防条款、防口舌；不宜硬来 |
| 小吉 | 和合，小成 | 去谈、去商量；**带上「小」字** |
| 空亡 | 抓不住 | 别投入；做别的准备 |

**出行**

| 宫 | 态势 | 提醒 |
|---|---|---|
| 大安 | 平稳，或因事未成行 | 无惊喜也无风险 |
| 留连 | 有阻滞、会变 | 留缓冲时间，别赶 |
| 速喜 | 顺利，宜速行 | 趁早走 |
| 赤口 | 有冲撞 | **检查车况**，防口角，留凭证 |
| 小吉 | 顺利，路上好谈事 | 宜边走边谈 |
| 空亡 | 去不成，或去了白去 | **出发前再确认一次** |

### 实操

### 谋事：先答方向，再答量级

```
方向：能不能推进？（看时宫宫义）
量级：多大？（看「小吉」的「小」、「大安」的「守成」等）
动作：该主动还是该等？（看静动与断辞里的动作句）
```

**最常见的失误不是方向错，是量级没说。** 只说「能成」，对方会自动脑补一个乐观的版本。

量级词清单：

```
小成 / 适中 / 规模有限 / 不是大获
打折 / 持平 / 超额
部分 / 全部
```

### 出行：把不顺的课转成排查清单

```
赤口 → 检查车况（胎压、油量、刹车）；重要约定书面确认；少争执
留连 → 留缓冲时间；行程可能变，别把时间卡死
空亡 → 出发前再跟对方确认一次；准备备选方案
```

### 案例小故事：同一件事，两个时刻的两个课

老李有个合作方在犹豫，他问：「要不要主动再推一把？」

**第一次**（两周前）掐出**留连**。

当时给的读法是：留连主拖，对方内部还没定，这时候推是白费劲。建议他先别动，把方案再打磨一下。

他忍住了，没推。

**第二次**（两周后）他又来问同一件事，掐出 **月留连 / 日小吉 / 时速喜**。

三宫串读：

```
月宫留连：背景还是拖的（对方内部慢，这一层没变）
日宫小吉：眼下是和合——可以谈了
时宫速喜：落点是快
```

读法完全变了：

```
不是「能不能推」，而是「现在就推」。
速喜主快，窗口就在这两三天；
小吉主和合，用商量的姿态，别用催促的口气。
```

给他的动作建议：

```
第1步 今天下午就发消息约面谈，别拖过这周
第2步 面谈时把具体方案带上，别空手谈
第3步 语气是「一起看看怎么弄」，不是「你们定下来了吗」
```

他当天下午发了消息，对方秒回：「正好，我也想找你聊聊。」三天后签了意向。

**这一课的精髓是对比**：

```
两周前 · 留连 → 环境没动，推了也白推
两周后 · 小吉+速喜 → 可以谈了，而且得快
```

同样是「主动推一把」，时机不同，结果天差地别。**这就是小六壬最实用的地方：它回答的不是「成不成」，而是「眼下往哪走、该不该动」。**

顺带说明一个常见疑问：**同一件事隔一段时间再起课，算不算「反复起课」？**

```
不算。「不反复起课」指的是同一时刻掐了又掐、挑一个想要的答案；
时过境迁、情况变化后再起课，是正常用法。
但要在记录里标明「同一事件的第 N 次起课」，便于日后对比。
```

### 笔记与验证

谋事类记录加两个字段：

```
第1项 是否推进（推进了 / 没推进 / 部分推进）
第2项 量级是否符合读法（偏大 / 符合 / 偏小）
```

出行类加一个字段：

```
出行：成行了 / 取消 / 延期
```

验证方式：统计「方向对但量级没说」的比例。这个数字通常很高，是提升空间最大的地方。

## 4_3 官非口舌

### 要点

### 场景特点

包括：合同纠纷、劳动争议、邻里纠纷、被人投诉、会不会被起诉等。

这一题材**边界最硬**：术数只作思路参考，具体事务走专业渠道。

### 六宫直读

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 平稳，可调解 | 宜和解，别把事闹大 |
| 留连 | 拖很久 | 宜缓不宜急（官事只宜缓）；但要防对方拖死你 |
| 速喜 | 有转机 | 宜主动解决（官事有福德） |
| 赤口 | 是非大 | 切忌硬碰；全程留痕（官非切要防） |
| 小吉 | 和合 | 找中间人调解，协商优于诉讼 |
| 空亡 | 不利 | 早做止损准备；**问「会不会被起诉」→ 空亡 = 不会** |

### 实操

### 三条通用动作（无论落哪一宫）

```
第1条 留痕：沟通用文字，保留聊天记录、邮件、书面凭证
第2条 不激化：不与对方发生言语冲突，不在公开场合表态
第3条 找专业：合同、劳动、侵权类问题，咨询律师或相关部门
```

> **口径说明**：本单元内容不构成任何法律意见。涉及具体权利义务的判断，请以专业人士与相关部门的结论为准。

### 落宫对应的预案

```
赤口 → 检查合同有没有漏洞；补齐书面材料；避免单独会面
留连 → 设时间节点（如「两周没进展就走正式渠道」），别无限拖
速喜 → 抓紧窗口，主动提解决方案
小吉 → 找一个双方都信得过的中间人
空亡 → 评估最坏结果，做止损方案
大安 → 维持现状，不主动升级
```

### 案例小故事：留连的「缓」字两面

学员的朋友遇到劳动纠纷，问「能不能拿到补偿」。掐出 **月大安 / 日留连 / 时赤口**。

三宫串读：

```
月宫大安：环境是稳的（公司还在，不是跑路那种）
日宫留连：眼下是拖 —— 这正是劳动纠纷的常态
时宫赤口：落点是冲 —— 最后会有硬碰硬，可能要撕破脸
```

学员最初的读法是「留连主拖，慢慢等吧」。我提醒他注意留连那一句断辞的后半：**「急讨方遂心」**——留连不是让你躺平，是让你**主动去讨**，只是讨的过程会拖。

再加上时宫赤口「官非切要防」，给的读法是：

```
第1步 能拿到，但要主动主张，不能等公司良心发现
第2步 过程会拖，做好「两三个月」的心理准备
第3步 落点是赤口，最后大概率要走到正式渠道（仲裁/协商会硬碰硬）
第4步 全程留痕：所有沟通用文字，不打电话
```

具体动作：

```
· 不走极端（不闹、不激化、不在公开场合表态）
· 但设明确节点：两周内没进展，就走正式渠道
· 全程书面沟通，保留记录
· 咨询一位劳动法律师，把材料提前备齐
```

结果：拖了两个月，最后在协商会上拿到了补偿。对方一开始想拖到他自己放弃，看他不松口、材料又齐，就谈了。

**留连在官非里的正确用法，不是「等」，是「用耐心换筹码」。**

断辞说「官事只宜缓」，缓的是**情绪与节奏**，不是放弃主张。这位学员最初读成「慢慢等」，就漏掉了「急讨方遂心」那半句。

复盘时他自己总结：最有价值的不是「能不能拿到」的答案，而是**「设时间节点」那条建议**——留连如果不设节点，就真的会无限拖下去。

### 笔记与验证

官非类记录加一个字段：

```
是否咨询专业人士：是 / 否
```

验证方式：**这一项应该做到全部为「是」。** 如果出现了「否」，说明那一次的处理存在风险——翻出来，在备注里补上「应建议走专业渠道」。

另外统计「我给出的预案里有没有留痕建议」。官非类断语里，「留痕」是成本最低、收益最稳的一条，不该漏。

## 4_4 感情与家庭

### 要点

### 场景特点

感情与家庭是最容易**自我实现**的领域：你说会分，对方可能就不努力了；你说能成，对方可能就松懈了。**这一题材对措辞的要求最高。**

### 六宫直读

| 宫 | 态势 | 取向 |
|---|---|---|
| 大安 | 稳定平淡 | 不会散，但也热不起来；适合过日子 |
| 留连 | 纠缠反复，分分合合 | 短期难有定论；不逼对方表态 |
| 速喜 | 进展快 | 趁热打铁；速喜后劲不足，别拖 |
| 赤口 | 争吵多 | **管住嘴**；少争辩，重要事用文字 |
| 小吉 | 和合，有人撮合 | 能成，靠人和；平淡温馨型 |
| 空亡 | 抓不住 | 不强求；**问「会不会散」→ 空亡表示眼下散不了** |

### 反转读法（问分离时要特别小心）

```
问「能不能成」 → 空亡 = 抓不住
问「会不会散」 → 空亡 = 散不了（坏事不来）
```

**判断标准**：先问自己「对问事人来说，这是好事还是坏事」，再定方向。

### 实操

### 提问改写

```
✗ 「我跟他有未来吗？」          → 太大，无法验证
✓ 「这个月内他会主动联系我吗？」
✓ 「这次争执之后，一周内关系能缓和吗？」
```

### 措辞模板

```
✗ 「你俩注定要散」
✓ 「眼下这个阶段有拉扯之象，短期内难有定论。
   如果你想继续，建议先别逼对方表态，
   给彼此一点空间，一段时间后再看。」

✗ 「他会回来找你的」
✓ 「卦上看近期有联系的可能，但我不建议你干等——
   该做什么做什么，别把自己的生活停摆。」
```

### 三条守则

```
第1条 不替对方做决定（「你该分手」这类话不说）
第2条 不用「注定」「一定」这类宿命词
第3条 读出不顺的课，必须配上「如果想挽回，可以做什么」
```

### 案例小故事：一句话，两个结局

学员给朋友读感情，问「最近总吵架，会不会散」。掐出 **月速喜 / 日小吉 / 时速喜**。

三宫串读：

```
月宫速喜：环境里有「快」的东西——可能是升温，也可能是爆发
日宫小吉：眼下是和合——关系本身有缓和的基础
时宫速喜：落点是快——近期会有转机
```

这是一个**相当好**的课：三宫里两个吉，落点也是吉。分不了。

但学员脱口而出的是：「你俩要吵崩了。」

朋友当场哭了，当天晚上跟对象大吵一架——她觉得「反正卦上说要崩」，说话就没收着。本来只是小摩擦，真闹到了要散的程度。

复盘时指出三个问题：

```
第1个 落宫读反了
   时宫明明是速喜，为什么会读成「要崩」？
   → 因为他把注意力放在「吵架」这件事上，
     看到冲撞的影子就往坏处读
   → 教训：先看落宫，再看场景；别让场景情绪盖过落宫

第2个 措辞绝对化
   「要崩了」→ 应改为「近期口舌多，注意沟通方式」

第3个 没给规避方案
   读出不顺，就该说「防什么、能做什么」
```

后来重新读了一次，说法改成：

```
「这两周你们容易在言语上起冲突，但都不是原则性问题。
 建议你：有情绪先缓十分钟再说，重要的事用文字沟通，
 别在气头上做决定。过了这两周会好。」
```

朋友照做了。那两周确实吵了两次，但都及时刹住了车。

**同一课，一句话能拆散一对，一句话能救回一对。**

这个案例后来成了我们讲「措辞边界」的标准例子。它说明一件事：在感情领域，**你怎么说话，比你怎么掐指更重要**——因为你的话会变成事件的一部分。

### 笔记与验证

感情家庭类记录，加一个专用字段：

```
我的读法是否影响了当事人的行为：无 / 轻微 / 明显
```

验证方式：如果「明显」的比例很高，就要格外注意措辞——你的话已经成了事件的一部分。这时更要遵守三条守则：不下定论、不替人决定、不顺必配方案。

## 4_5 综合纠偏

### 要点

本单元做两件事：**一、把前四个题材里最容易犯的错集中纠一遍；二、给出完整的占验记录与验证方法。**

高频误读是「知不知道」，记录与验证是「做没做到」。前者读完就懂，后者要练成习惯——本单元的重点其实在后者。

### 一、四类高频误读（汇总）

| 误读 | 错在哪 | 正确读法 |
|---|---|---|
| 把「静」读成「成」 | 大安是静，问进展时往往是「暂时不动」 | 「不是不成，是没动」 |
| 把「难」读成「绝」 | 留连难在迟，不在绝 | 「会拖，要主动讨」 |
| 把「快」读成「成」 | 速喜快在讯息，不保证结果 | 「有消息了，事情还在后头」 |
| 把「空」读成「凶」 | 空亡是「没有」，不是「坏」 | 问好事＝抓不住；问坏事＝不会来 |

另有两条结构性错误：

```
错误五 · 只答方向不答量级
   「能成」→ 对方脑补成「成我想要那么大」
   应加量级词：小成 / 适中 / 规模有限

错误六 · 只答态势不给取向
   「这事不成」→ 然后呢？
   应给动作：别投入 / 主动去讨 / 出发前再确认 / 等书面齐了再动
```

### 实操

上一节说的是「错在哪」，这一节说的是「怎么记、怎么验」。先给模板，再给方法。

### 二、占验记录完整模板

初期可用极简五字段（见 `0_4`）；读课数量上来后，用下面的完整版。

```
┌───────────────────────────────────────────────────┐
│ 第1项   编号   ：连续序号，不重复                 │
│ 第2项   时间   ：公历 + 农历月日时（双写）        │
│ 第3项   问题   ：一句话，眼前一件具体事           │
│ 第4项   落宫   ：月宫 / 日宫 / 时宫              │
│ 第5项   取句   ：我取了哪一句断辞                │
│ 第6项   读法   ：态势 / 取向 / 提醒（三件套）     │
│ 第7项   反馈   ：实际发生了什么                  │
│ 第8项   判定   ：对上了 / 没对上 / 部分对上       │
│ 第9项   复核   ：三宫掐对了吗？取句取对了吗？     │
│ 第10项  备注   ：闰月、跨时辰、被打断等特殊情况   │
└───────────────────────────────────────────────────┘
```

**纸质速写模板**

```
┌────────────────────────────────────┐
│ 编号：___  农历：__月__日 __时      │
│ 公历：____年__月__日 __:__          │
├────────────────────────────────────┤
│ 问题：                              │
│ ______________________________      │
│ 落宫： 月____  日____  时____       │
│ 取句：________________________      │
├────────────────────────────────────┤
│ 【态势】______________________      │
│ 【取向】______________________      │
│ 【提醒】______________________      │
├────────────────────────────────────┤
│ 反馈（事后回填）：                  │
│ ______________________________      │
│ 判定：□对上 □没对上 □部分对上       │
│ 复核：三宫□对□错  取句□贴切□取错    │
└────────────────────────────────────┘
```

### 三、三条记录纪律

```
纪律一 · 读法栏永不回填
   读法必须在起课当场写下（或口述录音留时间戳）
   事后只填「反馈」，绝不修改「读法」

纪律二 · 时间要带时刻
   只写日期不写时刻，无法复核三宫，也无法做统计

纪律三 · 反馈写「发生了什么」，不只写「对上/没对上」
   半年后回看，只写「对上」的一条毫无价值
   写下具体情节，才能提炼经验
```

### 四、验证方法

**方法一 · 准确率统计**

```
准确率 = 对上条数 ÷ 有效条数

有效条数 = 总条数
         - 三宫掐错的
         - 问题不是具体事的
         - 反馈未回填的
```

> 「部分对上」建议按半条计，或另设「完全对上率」与「含部分对上率」两个数，分开看。

**方法二 · 先看复核，再看准确率**

```
统计顺序：
  第一步：剔除三宫掐错的（这是操作问题，不是读课问题）
  第二步：剔除提问越界的（这是提问问题）
  第三步：剩下的才是「读课准确率」
```

**很多人会发现，剔除之后自己的准确率明显上升**——因为早期记录里混杂了大量操作失误。这也说明：**先练掐准，再谈读准。**

**方法三 · 分组对照（找强弱项）**

```
按题材分组：失物 / 行人 / 谋事 / 出行 / 官非 / 感情
   → 找出最擅长与最不擅长的题材

按落宫分组：大安 / 留连 / 速喜 / 赤口 / 小吉 / 空亡
   → 找出最容易读错的宫

按问题性质分组：求成 / 避险
   → 检查空亡的反转读法是否掌握
```

**方法四 · 双盲练习**

```
做法（一个人也能做）：
  第1步 对未来一周的若干件可验证的事分别起课，写下读法
  第2步 密封存证（发一封定时邮件给自己，或用带时间戳的录音）
  第3步 事后来开箱核对
```

**作用**：消除「知道结果后回头解释」的空间。写得越具体，越难事后附会：

```
✗ 「会比较慢」            → 可以附会成任何一种慢
✓ 「眼下不动，一周内不会有动静」 → 无法附会
```

### 五、六种记录偏差

上面四种方法能解决「不会算」，但解决不了「算得漂亮却不真实」。下面六种偏差都会让准确率**虚高**——它们不产生错误的答案，只产生让你舒服的答案。

| 偏差 | 症状 | 对统计的影响 | 解药 |
|---|---|---|---|
| 事后附会 | 结果出来后回头「重新理解」读法 | 严重虚高 | 当场记录 + 时间戳 + 写具体 |
| 选择性记录 | 只把有把握的课记进来 | 虚高 | 起了课就记，无例外 |
| 只记对上的 | 忘了读错的那些 | 虚高 | 记录本身（全记则自动消失） |
| 自我实现 | 读法影响了自己的行为 | 虚高 | 记录「我的读法是否影响了我的行为」 |
| 确认偏误 | 只看支持自己读法的部分 | 虚高 | 反馈栏写完整情节 |
| 样本太小 | 十几条就下结论 | 结论不可靠 | 三十条以下不下结论 |

### 六、从记录到个人读法库

```
三十条后  → 按题材整理，挑出最常应验的说法
一百条后  → 做分组对照表，找出强弱项
两百条后  → 写「个人修正条目」，形成自己的读法口径
```

个人读法库条目示例：

```
┌────────────────────────────────────────────┐
│ 【宫】速喜                                  │
│ 【题材】问消息                              │
│ 【本库读法】快在讯息                        │
│ 【我的版本】                                │
│   · 应「消息」远多于应「结果」              │
│   · 凡问「能不能成」，速喜只答「在动」      │
│ 【样本量】n=__  【准确率】__%               │
└────────────────────────────────────────────┘
```

**维护原则**：每条标注样本量，样本量太小的标为「待验证」，不作依据；定期回顾，跌破平均水平的条目删掉。

### 案例小故事：一次诚实的统计

有位同学做了三个月记录，累计九十六条，兴冲冲来报：「准确率七成八！」

我没先恭喜他，而是把他的表格翻了一遍。翻到一半，两个问题浮了出来。

```
问题一：「判定」栏里大量是「部分对上」
   → 他把「部分对上」按整条算进了分子
   → 等于把「方向对、细节偏」当成了全对

问题二：他的问题高度集中在「这事会不会拖」上
   → 九十六条里有四十一条是这一类
   → 而现实里，大部分事情本来就会拖
   → 他断「会拖」的比例超过七成，命中率自然高
```

第二点最要命。打个比方：如果一个人天天猜「明天会不会堵车」，而这座城市本来就天天堵，那他猜「会堵」的正确率一定高得惊人——**但这不是预测能力，这是常识基线。**

于是重算了两遍：

```
第1步 「部分对上」改按半条计，重新算一遍总数
第2步 把「问会不会拖」这一类（共四十一条）单独拆出，
   与其余五十五条分开统计
```

结果：

```
「会不会拖」类（41 条）：83%   ← 但常识基线本来就高
其余各类（55 条）      ：58%
```

真相是：**七成八是被「问拖延」这一类撑起来的。** 去掉这一类，真实水平是百分之五十八——不算差，但离他自己以为的七成八差得远。

他有点失落，问我：「那我这三个月是不是白练了？」

恰恰相反，这是三个月来最有价值的一天：

```
第1点 发现了一个真实优势：在「判断事情会不会拖」上很准
   → 可以刻意在这一类上多练，把它做成专长

第2点 看到了真实短板：其他题材只有五成八
   → 这就是接下来的训练方向，不用再瞎练

第3点 最重要的是，有了真实的基线
   → 之后的每一次进步都能被测量
```

**一次诚实的统计，胜过十次「感觉挺准」的喜悦。** 前者给你方向，后者只给你安慰。

后来他还做了一件事：把自己的错题按错因分类，做成待改进清单。

```
待改进清单（他的）
  第1类  取句取错（拿了不相关的那句）   █████
  第2类  把吉凶当结论                   ███
  第3类  只答方向不答量级               ████
  第4类  三宫掐错                       ██
```

**正常课例让你熟练，错题让你进步。** 这份清单他每周都看，也是他后来进步最快的原因。

### 笔记与验证

建立月度盘点表，每月一行：

```
月份 | 新增 | 有效 | 对上 | 部分 | 没对上 | 准确率 | 最大错因
```

每月更新。这张表既是成绩单，也是路线图——**准确率不涨的那个月，就去看「最大错因」那一栏**。

### 全课收尾三句话

```
第1句 小六壬回答的是「态势与取向」，不是「成不成」
第2句 掐指只要三分钟，掐准需要三周
第3句 不做记录的读课只是一次娱乐；做了记录，才是学习
```

*全课完。读课这件事，真正拉开差距的从来不是掐指的速度，而是记录下来的那几百条反馈。*
