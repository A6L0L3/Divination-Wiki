## 板块1 · 先搞懂这本书在干什么

《卜筮正宗》是清初王洪绪（王维德）辑成的六爻扛鼎之作。它不像《周易》本经那样以卦辞爻辞说事，也不像后世一些术数书堆砌神煞；它做的是一件极其"工程化"的事：

**把问事人的一个问题，翻译成一张六爻卦，再通过五行生克、旺衰动静、世应关系，推出"成不成、什么时候成、卡在哪"。**

所以这本书的本质，不是玄学幻想，而是一套**以卦为模型的现实事件推演系统**。与它并称"六爻双璧"的是《增删卜易》，两书互为表里：一本重体系，一本重案例。

读《卜筮正宗》最容易踩的坑，是把它当文学来读、当哲理来品。错了。这本书的正确打开方式是——**边读边在纸上起卦、装卦、断卦**，把它当成一本"六爻操作手册"来练。

## 板块2 · 全书的"三纲领"：生克、旺衰、动静

王洪绪在书中把断卦逻辑凝练成三条主线，这三条线贯穿后续所有章节：

1. **生克定吉凶**——用神被生扶则吉，被克泄则凶。这是定性。
2. **旺衰定程度**——同样是用神得生，旺相者事成力强，休囚者纵有生扶也乏力。这是定量。
3. **动静定应期**——事情在什么时候发生、以多快的速度推进，由动爻、变爻、冲合来决定。这是定时。

> 一句话记住：**生克答"是不是"，旺衰答"有多强"，动静答"何时发生"**。

这三条纲领不是并列的，而是**由粗到精的过滤层**：先用生克筛掉明显吉凶，再用旺衰细化程度，最后用动静锁定时间。

---

**示例**：一卦中世爻旺、用神衰，按「旺衰为纲」应先看用神受制，而非世爻表面之旺。

## 板块3 · 起卦：以钱代蓍法（原书核心起卦法）

古人原本用蓍草起卦，繁复耗时。王洪绪在书中明确收录"以钱代蓍法"，这也是后世最通行的起卦方式。

### 3_1 工具与心态

+ 工具：三枚铜钱（清制钱币满文面为阳、汉文面为阴；现代硬币可规定"背为阳、字为阴"）
+ 心态：**一事一占、问清问细、心念专一**。忌"我最近运气如何"这种泛问，要问"本月某项目能否签下"这种定点问题。

### 3_2 摇卦记录规则

抛掷三枚铜钱，自下而上记录六次：

| 钱面情况 | 爻性 | 记号 |
| --- | --- | --- |
| 一背二字 | 少阳（静爻） | 单 `—` |
| 二背一字 | 少阴（静爻） | 拆 `--` |
| 三背 | 老阳（动爻） | 重 `○`（阳动变阴） |
| 三字 | 老阴（动爻） | 交 `×`（阴动变阳） |

六次掷完，从初爻到上爻排成本卦；老阳变阴、老阴变阳，得出变卦。

> 只有"重"和"交"是动爻，才是断卦的真正枢纽。静卦并非不能断，但动卦信息量远大于静卦。

---

**示例**：三枚铜钱掷六次，两正一反记阳爻……六次成卦，即「以钱代蓍」的一次完整操作。

## 板块4 · 装卦：给本卦"通电"的四步操作

空卦只是符号，装卦之后它才变成可计算的模型。原书与后世实操统一为以下步骤：

### 4_1 纳甲（安地支）

按八纯卦的固定口诀，从初爻向上装地支。**阳卦顺行、阴卦逆行**，只纳同阴阳性的地支：

+ **乾/震**：子、寅、辰、午、申、戌
+ **坤**：未、巳、卯、丑、亥、酉
+ **坎**：寅、辰、午、申、戌、子
+ **艮**：辰、午、申、戌、子、寅
+ **巽**：丑、亥、酉、未、巳、卯
+ **离**：卯、丑、亥、酉、未、巳
+ **兑**：巳、卯、丑、亥、酉、未

天干按"乾甲壬、坤乙癸、震庚、巽辛、坎戊、离己、艮丙、兑丁"配入。

### 4_2 定世应

世爻代表"我"（求测者），应爻代表"对方/环境/所问之事"。世应位置由卦的世数决定：

+ 八纯卦：世在上爻，应落三爻
+ 一世到五世：世在初爻到五爻，应与世隔两位
+ 游魂卦：世在四爻
+ 归魂卦：世在三爻

记忆口诀：**"天同二世，地异四世，人同三位，游魂四世，归魂三世"**（初学者可直接用排盘软件反查，熟练后再背）。

### 4_3 排六亲

以**本卦所在卦宫的五行**为"我"，按五行生克给六个爻位贴上六亲标签：

| 六亲 | 五行关系 | 现实类象 |
| --- | --- | --- |
| **父母** | 生我者 | 文书、契约、长辈、房屋、车、学业 |
| **官鬼** | 克我者 | 工作、官职、疾病、官司、压力、小人 |
| **妻财** | 我克者 | 钱财、物品、妻子、资源 |
| **子孙** | 我生者 | 子女、福气、医药、快乐、解忧 |
| **兄弟** | 同我者 | 同辈、朋友、竞争、破财 |

八宫五行：乾兑属金，震巽属木，坎属水，离属火，坤艮属土。

### 4_4 布六神（六兽）

按起卦日的天干，从初爻向上排青龙、朱雀、勾陈、螣蛇、白虎、玄武：

+ 甲乙起青龙，丙丁起朱雀/螣蛇……（实际排法：青龙→朱雀→勾陈→螣蛇→白虎→玄武循环）
+ 六神是**辅助断象**：青龙主喜庆、朱雀主口舌、勾陈主田土纠缠、螣蛇主虚惊、白虎主凶伤、玄武主暗昧。
+ 王洪绪在书中强调：**神煞只是辅助，不能脱离五行生克**。这一点至关重要，初学者最常犯的错就是把六神当主断。

> 装卦完成后，卦面上应当有：地支、五行、六亲、世应标记、动爻标记（○/×）、日月干支（写在卦上方）。

## 板块5 · 定用神：诸占以用神为主

《卜筮正宗》最关键的一句话："**诸占以用神为主**"。用神找错，后面全错。

### 5_1 常见问事的用神取法

| 所问之事 | 取用神 |
| --- | --- |
| 求财、生意、物品 | 妻财爻 |
| 求职、升迁、官司、病灾 | 官鬼爻 |
| 考试、文书、房屋、车辆、长辈 | 父母爻 |
| 婚姻（男问） / （女问） | 妻财爻 / 官鬼爻 |
| 子女、医药、解忧 | 子孙爻 |
| 兄弟、朋友、合伙、竞争 | 兄弟爻 |
| 自己安危、自身运势 | 世爻 |
| 对方态度、外部环境 | 应爻 |

### 5_2 用神不现怎么办

卦中若无用神爻，则去该宫的"伏神"里找——即在同卦宫的本宫卦中取用神，藏在对应的爻位之下。伏神需得日月或动爻生扶，方可"出伏"成事；若伏神被飞神（上位爻）压制，则事难成。

### 5_3 多用神的处理

卦中出现两个及以上同类的用神时，取**旺相、发动、临世应**的那一枚为主。

---

**示例**：问财取妻财爻为用神；若卦中无妻财，则看伏神或变爻，不可错取兄弟。

## 板块6 · 断卦四步法（原书与实操的融合）

这是全书最值钱的部分，也是网络教程里被反复咀嚼的"干货内核"。按以下顺序走，不会漏：

### 6_1 第一步：审用神根基（看月建、日辰）

用神与月建、日辰的关系，决定它的"根"扎得深不深：

+ 用神**得月建生扶或临月建** → 根基强旺
+ 用神**被月建克或逢月破**（与月建地支相冲） → 根基损伤
+ 用神**得日辰生扶或临日辰** → 当日得时
+ 用神**被日辰克或逢日破** → 当日无力

口诀：**"月建为树之根干，日辰为树之华叶。根深叶茂，方为成事之象。"**

> 月建主"旺相休囚死"的大趋势（管一个月），日辰主"生克合冲"的当下状态（管一天）。**近期事重日辰，长远事重月建**。

### 6_2 第二步：察动变（看动爻与变爻）

动爻是卦之枢纽，"动为始，变为终"。看三层：

1. **动爻与用神的关系**：动爻生合用神→外力相助；动爻克害用神→外力阻碍。
2. **动爻自身的化变**：
    - 化回头生（如午火动变寅木，木生火）→ 后续力量增强
    - 化回头克（如午火动变子水，水克火）→ 先吉后凶
    - 化进神（寅化卯、巳化午）→ 事态发展
    - 化退神（卯化寅、午化巳）→ 事渐衰减
3. **特殊动象**：
    - **暗动**：静爻旺相被日辰冲，力量仅次于明动，主暗中发力
    - **反吟**：卦变或爻变导致反复，主折腾、动荡
    - **伏吟**：卦变或爻变导致压抑，主忧愁、停滞

### 6_3 第三步：综观特殊（合冲墓空）

+ **合**：用神被日、月、动爻合住 → 事有羁绊，应期推迟
+ **冲**：用神或忌神被日、月、动爻冲开 → 事有变动、加速
+ **入墓**：用神入墓库（如午火入戌墓）→ 受困，事难成
+ **旬空**：用神落空亡 → 落空，不成；需待出空填实方应事

### 6_4 第四步：综合定应期

吉凶已定，最后锁时间。原书应期法则：

+ **动而逢值逢合**：动爻所临地支或与之相合的地支之时为应期（如子爻动，应在子日或丑日）
+ **静而逢值逢冲**：静爻所临地支或被日月冲的地支之时为应期
+ **太旺者逢墓库**：用神过旺，入墓之期应事
+ **衰弱者逢生旺**：用神衰弱，得生扶临旺之时为应期
+ **出空填实**：用神空亡，出空或填实空亡地支之时应事
+ **逢冲逢合互解**：被合者逢冲解，被冲者逢合解

## 板块7 · 旺衰生克的"优先级"（极易忽略的关键）

《卜筮正宗》与《增删卜易》都强调一个**力量层级**，初学者常在这里翻车：

```plain
月建、日辰  >  动爻  >  变爻（仅作用于原动爻）  >  静爻

```

具体规则：

1. **月建和日辰**可生克卦中所有爻，但爻无法反作用于月日。这是绝对权威。
2. **动爻**可生克静爻；**变爻**仅作用于它所对应的那个原动爻（如变爻酉金回头克原动爻卯木）。
3. 旺相之爻可压制衰弱之爻；但若衰弱爻得日月生扶，可逆转局势。
4. 动爻若被日辰合住（如寅动遇亥日），则**暂时失去生克权**。

> 这个层级决定了你看生克关系时的"权重"。同样是两个爻相克，月建参与的克 vs 动爻参与的克，份量完全不同。

---

**示例**：日辰克用神、月建生用神，按「日月为纲、动变为机」的层级，先论日月再论动爻。

## 板块8 · 世应：判断"我"与"对方"的关系

世应是六爻最实战的维度之一，几乎所有人际类占问都离不开它：

+ **世爻**：求测者本人、核心立场
+ **应爻**：对方、环境、所问之事

判断逻辑：

| 关系 | 含义 |
| --- | --- |
| 应生世 | 对方帮助你 |
| 应克世 | 对方压制你 |
| 世旺应衰 | 自己掌控局面 |
| 世应相生 | 合作有成 |
| 世应相克 | 阻力重重 |
| 世应比和 | 势均力敌，可成但费力 |

特殊情况下"用神克世"反为吉：如求财时妻财爻克世，叫"财来就我"，主得财。

## 板块9 · 分类断法：原书的"案例库"怎么用

《卜筮正宗》后半部是分类占法，相当于古代社会的大数据案例库。每一类都给出了：

+ 取什么用神
+ 看什么关系
+ 哪些组合代表吉，哪些代表凶

举几个高频场景：

### 9_1 求财

+ 用神：妻财爻
+ 妻财旺相、得日生扶、子孙爻（原神）发动生财 → 财源滚滚
+ 兄弟爻（忌神）发动克财 → 破财、竞争夺财
+ 妻财克世 → 财来就我，吉

### 9_2 婚姻

+ 男问取妻财爻，女问取官鬼爻
+ 世应相生、用神旺相 → 良缘
+ 用神休囚、世应相冲 → 离散
+ 六合卦主稳定，六冲卦主变动

### 9_3 疾病

+ 用神：官鬼爻为病，子孙爻为医药
+ 官鬼旺而子孙衰 → 病重药轻
+ 子孙发动克官鬼 → 药到病除
+ 近病逢六冲易愈（冲散病气）；久病逢六冲反凶（冲散元气）

### 9_4 失物

+ 用神：妻财爻（财物本身）
+ 妻财旺相、得生扶 → 可寻
+ 妻财休囚、入墓、空亡 → 难觅
+ 看妻财爻所在爻位定方向（初爻在下、上爻在远）

### 9_5 出行/行人

+ 用神：出行以父母爻（交通工具）或世爻；行人以六亲对应
+ 世爻发动 → 出行顺利
+ 归魂卦 → 外出者不出疆界（主不动或早归）
+ 用神发动值三合 → 行人立回

### 9_6 官司

+ 用神：官鬼爻
+ 世旺应衰 → 我胜
+ 世应相生 → 和解
+ 官鬼爻受制 → 官司消解

> 分类断法的真正价值，不在于死记硬背"某爻主某吉"，而在于**理解古人为什么这样对应**——背后是五行生克的逻辑，而非迷信。

## 板块10 · 十八论与《通玄赋》：原书的"心法篇"

《卜筮正宗》中的"十八论"系统阐述了占卜的根本原理：

+ **论用神**：找准用神是断卦前提
+ **论原神忌神**：生用神者原神，克用神者忌神
+ **论世应**：世为主、应为客，决定主客格局
+ **论动静**：动爻为事之发端，"动变生克"优先
+ **论生克**：五行相生相克定吉凶
+ **论旺衰**：月建定旺衰大纲，日辰定具体应期
+ **论合冲**：三合局强化力量，六合主牵绊，六冲主散
+ **论进神退神**：化进事态发展，化退事渐衰
+ **论反吟伏吟**：反吟主反复，伏吟主忧愁
+ **论月破**：爻与月建冲，极衰
+ **论旬空**：落空亡，需出空方应
+ **论飞神伏神**：用神不现则寻伏神
+ ……

《通玄赋》则是一篇浓缩的断卦口诀，开篇即点明：

> "易爻不妄成，神爻岂乱发。始须论用神，次必看原神。"

这给断卦定了**先后次序**：先看用神，再看原神/忌神，然后看三合、空亡、世应、六神。这个次序不能乱——乱了就是"舍本逐末"。

---

**示例**：「用神多现」时取临世、临动、临日月者，这是十八论给出的取舍实例。

## 板块11 · 心法要诀：王洪绪真正想告诉你的事

读完《卜筮正宗》全书，剔除所有技术细节，真正的心法只剩四条：

**1. 万事皆五行关系**
人与人、人与事，本质是能量关系。六爻是把复杂现实压缩成"五行关系博弈"的工具。

**2. 吉凶来自动态变化**
不是"固定命运"，而是"生克变化中的趋势"。所以"动爻"才是断卦的灵魂。

**3. 时间比结果更重要**
六爻真正高级的地方，不只是算"会不会"，而是算"什么时候发生"。应期推算的精度，是区分高手与新手的分水岭。

**4. 卦是时空切片的信息投影**
卦不是神秘力量，而是求占那一刻时空能量的模型。所以"心念专一、一事一占"不是仪式感，而是**保证模型准确的前提**。

> 王洪绪在书中反复强调：**"重理而轻象，用象阐幽微"**。先以五行生克之理断准吉凶大局，再用六神、爻位等象来丰富细节。切忌本末倒置——这是初学者最容易栽的跟头。

---

**示例**：一卦既成，先问「用神安在」，再问「旺衰如何」，正是心法「先定靶心」的落地。

## 板块12 · 避坑指南（网络教程很少明说，但实战必踩）

### 12_1 坑 1：神煞至上

很多江湖派喜欢堆驿马、桃花、贵人、华盖……但《卜筮正宗》明确：**神煞只是辅助，不能脱离五行生克**。脱离生克看神煞，必失之毫厘谬以千里。

### 12_2 坑 2：死记用神

用神不是死的。代占时（如母亲代占儿子婚姻），需要**坐标转换**——以子孙爻为"我"，重新定义六亲关系。死守"男看财、女看官"会全盘皆错。

### 12_3 坑 3：忽视月破与日破

月破之爻极衰，纵有其他生扶也难成事；日破则当日无力。这两个状态必须在断卦第一步就标出来。

### 12_4 坑 4：动爻被日合而"假动"

动爻若被日辰合住，暂时失去生克权——这是"动而未动"。不少初学者看到动爻就断"事必有变"，却忽略了它被合住的事实。

### 12_5 坑 5：应期推算过于机械

"动而逢值逢合"只是大原则。实战中应期要综合：旺衰（太旺逢墓、衰弱逢生）、空亡（出空）、冲合（逢冲逢合互解）、进退神等多重因素。**应期是算出来的区间，不是单点**。

### 12_6 坑 6：一卦多问

"我这次投资能不能成？顺便看看婚姻？"——一卦只答一事。多问则用神混乱，卦不妄成。

### 12_7 坑 7：忽视"卦不妄成"

王洪绪借《通玄赋》提醒：**"易爻不妄成，神爻岂乱发"**。不是所有问题都值得起卦，不是所有卦都值得深断。心不诚、念不清、事不切，卦象自乱。

## 板块13 · 21 天实操训练计划

光读不懂，必须练。以下是把《卜筮正宗》读活的建议路径：

### 13_1 第一周：基础夯实

+ **Day 1-2**：背熟八纯卦纳甲口诀、六亲取法、世应定位规则
+ **Day 3-4**：用手摇法起 10 卦，每卦完整装卦（纳甲+世应+六亲+六神）
+ **Day 5-7**：用已装好的卦练"定用神"——随便给一个场景，写出取哪个爻为用神，为什么

### 13_2 第二周：断卦四步法

+ **Day 8-10**：每日起一卦（问当日小事，如"今日能否收到账款"），按"审用神→察动变→综特殊→定应期"四步走，写出推理过程
+ **Day 11-12**：把断语记下来，**事后验证**。这是关键——不验证的六爻永远是玄学
+ **Day 13-14**：专项练"旺衰判断"和"动变化断"（进神退神、回头生克）

### 13_3 第三周：分类断法与综合实战

+ **Day 15-17**：按原书分类占法，每天专攻一类（求财、婚姻、疾病、出行、失物），各起 3 卦
+ **Day 18-19**：练"应期推算"——找 5 个已发生的事，倒推当时若起卦，应期是否吻合
+ **Day 20-21**：综合实战，给自己或朋友的真实问题起卦断卦，**全程记录推理链**

> 练满 21 天、起卦超过 60 卦并做验证，才算真正"读过"《卜筮正宗》。否则只是读过它的字面。

## 板块14 · 与《增删卜易》的对读建议

两书并称六爻双璧，但侧重不同：

+ **《卜筮正宗》**：体系严密、规则清晰，适合打基础、建框架
+ **《增删卜易》**：野鹤老人案例集，300 多个真实占例，适合练手感、学应变

建议读法：**先《卜筮正宗》立骨，后《增删卜易》活血**。只读一本都会有偏——只读《正宗》容易死于句下，只读《增删》容易不得其门。

## 板块15 · 附录：断卦检查清单（打印贴在案头）

起卦装卦完成后，按此清单逐项过：

- [ ] 用神取对了？（问什么取什么，代占需转坐标）
- [ ] 用神与月建关系？（得生/受克/月破）
- [ ] 用神与日辰关系？（得生/受克/日破/旬空）
- [ ] 原神（生用神者）状态？忌神（克用神者）状态？
- [ ] 动爻有几个？动爻与生克用神的关系？
- [ ] 动爻化变是什么？（进/退/回头生/回头克）
- [ ] 世应关系？（相生/相克/比和）
- [ ] 有无特殊象？（暗动、反吟、伏吟、入墓、合冲）
- [ ] 六神附着情况？（辅助断象，不作主）
- [ ] 综合吉凶判断？
- [ ] 应期推算？（动值、静冲、出空、逢墓、生旺）

过完这张清单，一卦的断语自然浮现。

---

> **读《卜筮正宗》的最终体悟**：

它教的不是"算命"，而是**如何在不确定中建立确定性**——通过一套严密的符号系统，把模糊的焦虑转化为清晰的"用神旺衰动静"。卦是死的，人是活的；规则是固定的，世事是流动的。真正读懂这本书的人，最后算的不是卦，是自己的心——知道自己问的是什么、怕的是什么、要的是什么。

**示例**：每次断卦后照单核对「用神、旺衰、动变、应期」四项，缺一项则回补。
