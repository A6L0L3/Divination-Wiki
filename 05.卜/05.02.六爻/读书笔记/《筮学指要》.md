## 板块2 · 关于本书：它到底在讲什么

《筮学指要》十卷，清·吴隆誉（毗陵人）撰，乾隆三十五年（1770）经鲈香居士鉴定刊印。全书以阴阳五行为根基，以八卦纳甲为入门，以六亲、世应、用神、生克为核心，以大量歌诀、案例、断语为支撑，由浅入深，将复杂深奥的六爻筮法化繁为简。

**核心定位**：这不是一本"算命秘籍"，而是一部**传统六爻筮法的系统化教科书**。它相当于把古人"察阴阳、明进退、知取舍、修德行"的一套认知模型，整理成了有理论、有规则、有程序、有逻辑的可操作体系。

### 2_1 十卷结构速览

| 卷次 | 内容 | 性质 |
| --- | --- | --- |
| 卷一 | 卦象、干支、五行、八卦次序、装卦法、世应、六亲、六神、用神、飞伏 | **基础工具** |
| 卷二 | 月将、日辰、月破、旬空、旺相休囚、生旺墓绝、三合局、三刑、进神退神 | **判断规则** |
| 卷三 | 黄金策、天玄赋、六爻诸占定位、反吟伏吟、游魂归魂、何知章、应事日期 | **断卦方法论** |
| 卷四 | 天时 | **专题应用** |
| 卷五 | 家宅、迁移、修造动土、坟墓 | 专题应用 |
| 卷六 | 终身、寿元、疾病、医药、鬼神 | 专题应用 |
| 卷七 | 婚姻、胎孕、产育、进人口 | 专题应用 |
| 卷八 | 功名、仕宦、学馆、谒贵、出行、行人、音信 | 专题应用 |
| 卷九 | 求财、借贷、开张、买卖、蚕桑、六畜 | 专题应用 |
| 卷十 | 词讼、趋避、贼盗、逃亡、失脱、十八问答 | 专题应用 |

> **关键认知**：卷一至卷三是"方法论"，卷四至卷十是"场景库"。真正要掌握的是前三卷的逻辑框架，后面的专题是框架在具体场景中的展开。

## 板块3 · 底层逻辑：筮学的本质是一套认知模型

### 3_1 阴阳五行不是迷信，是能量属性与运动方式

《筮学指要》开篇从阴阳、五行、八卦起步，这不是故弄玄虚，而是在建立一个**分类与关系系统**：

+ **阴阳**：宇宙最基本的对立统一规律。动为阳，静为阴；刚为阳，柔为阴。万物负阴而抱阳。
+ **五行**：不是五种物质，而是五种**能量属性与运动方式**——木主生发、火主炎上、土主承载、金主收敛、水主润下。
+ **五行生克**：构成系统内在动力。相生（木→火→土→金→水→木），相克（木克土→土克水→水克火→火克金→金克木）。

**实操要点**：这套系统的核心不是"金克木所以凶"，而是**看能量流动的方向和平衡状态**。生克本身无吉凶，关键看对"用神"是有利还是不利。

### 3_2 八卦是宇宙万物的高度概括

乾（天）、坤（地）、震（雷）、巽（风）、坎（水）、离（火）、艮（山）、兑（泽）——八卦并非简单符号，而是对自然现象、社会结构、人性规律的抽象表达。八卦相重而成六十四卦，每卦六爻，象征事物发展的六个阶段。

### 3_3 筮的本质：模拟变化，映射趋势

> "筮无定法，唯变所适；占不妄断，以德为本。"

筮，本质上是通过一套严谨的符号推演程序，模拟天地阴阳的变化，从而映射人事的吉凶悔吝。它不是"神示天启"，而是以象数为工具进行的**逻辑推演、趋势判断与风险评估**——与现代人通过数据分析、模型推演来判断市场趋势、制定决策，在思维方式上是同源的。

**核心洞见**：卦象显示的不是"注定的结果"，而是"当前的趋势"；占卜得出的不是"不可更改的命运"，而是"需要调整的方向"。

## 板块4 · 起卦实操：从工具到成卦的完整流程

### 4_1 方法一：蓍草法（正统古法）

**工具**：50根蓍草（或竹签、筷子）。

**步骤**：

1. 取出1根置一旁（象征太极），余49根。
2. 每一爻需"三变"，每变含**分二、挂一、揲四、归奇**四营：
    - **分二**：将49根随意分为两堆（象两仪）。
    - **挂一**：从右堆取1根夹于指间（象三才）。
    - **揲四**：左右两堆分别以4根一组计数，取余数。
    - **归奇**：余数夹于指间（象闰）。
3. 三变之后，剩余蓍草数 ÷ 4 = 6/7/8/9：
    - **6 = 老阴**（-- ×，可变）→ 阴极将变
    - **7 = 少阳**（—，不变）→ 阳之稳态
    - **8 = 少阴**（--，不变）→ 阴之稳态
    - **9 = 老阳**（— ○，可变）→ 阳极将变
4. 重复六次（十八变），自下而上排成六爻。

> **实操提示**：老阴（6）老阳（9）为"变爻"，需画出变卦。变爻是本卦中能量最活跃、变化最剧烈的位置。

### 4_2 方法二：铜钱法（简化实用法，六爻最常用）

**工具**：三枚铜钱（或硬币）。需统一约定：字面为阴，花面为阳。

**规则**：

| 结果 | 名称 | 画法 | 属性 |
| --- | --- | --- | --- |
| 三枚皆阳面 | 老阳（重） | — ○ | 阳，可变 |
| 两阳一阴 | 少阳（单） | — | 阳，不变 |
| 两阴一阳 | 少阴（拆） | -- | 阴，不变 |
| 三枚皆阴面 | 老阴（交） | -- × | 阴，可变 |

**操作流程**：

1. 双手合扣铜钱，默念所问之事（**一心一念，不可杂想**）。
2. 抛掷六次，自下而上记录。
3. 有变爻则画出变卦。

### 4_3 起卦的三大前提（朱熹五要精简版）

1. **诚**：心不诚则卦不灵。问卦时心中只装一件事，专注而敬畏。
2. **正**：动机纯正。不卜阴谋诡计，不卜好奇戏谑之事。
3. **静**：环境安静，心神安定，放下偏见与执念。

> **拓展补充**：现代心理学视角看，这三点本质上是**排除认知偏差、进入心流状态**的条件。占卜的准确度，很大程度上取决于提问者能否清晰、冷静地聚焦问题。

## 板块5 · 装卦体系：把卦象变成可分析的模型

装卦是将原始卦象填入干支、六亲、世应、六神等信息的过程，相当于给一张空白图纸标注坐标和数据。

### 5_1 纳甲装卦（六爻的地支配置）

**核心规则**：阳四卦（乾、震、坎、艮）取阳支顺行；阴四卦（坤、兑、离、巽）取阴支逆行。

**记忆口诀（纳甲歌）**：

```plain
乾金甲子外壬午，坎水戊寅外戊申。
艮土丙辰外丙戌，震木庚子外庚午。
坤土乙未外癸丑，兑金丁巳外丁亥。
离火己卯外己酉，巽木辛丑外辛未。

```

**实操步骤**：

1. 确定内外卦（下卦为内，上卦为外）。
2. 依据八宫各卦的纳甲规则，自下而上填入地支。
3. 阳卦顺行（子→寅→辰→午→申→戌），阴卦逆行（亥→酉→未→巳→卯→丑）。

### 5_2 定世应：找到卦的"主视角"

**世应概念**：世爻代表问卦者（己），应爻代表所问之事或对方（人）。

**寻世诀（本书核心捷法）**：

```plain
天同二世天变五，地同四世地变初。
本宫六世三世异，人同游魂人变归。

```

**解读**：

+ 比较上下卦的天爻（三爻 vs 六爻）、人爻（二爻 vs 五爻）、地爻（初爻 vs 四爻）阴阳异同。
+ "天同"=上下卦天爻阴阳相同 → 世在二爻。
+ "天变"=上下卦天爻阴阳不同 → 世在五爻。
+ "地同" → 世在四爻；"地变" → 世在初爻。
+ "本宫"=八纯卦（乾兑离震巽坎艮坤）→ 世在六爻。
+ "三世异"=天地人三才皆异 → 世在三爻。
+ "人同" → 游魂卦，世在四爻。
+ "人变" → 归魂卦，世在三爻。

**认宫诀**：

```plain
一二三六外卦宫，四五游魂内变更。
归魂内卦是本宫。

```

> **实操提示**：世应关系是断卦的骨架。世爻旺相则自身有力，应爻生合世爻则事易成。世应俱空（旬空），则"得卦无准"。

### 5_3 配六亲：建立关系网络

**六亲** = 以卦宫的五行属性为"我"，对照各爻地支五行得出的五种关系：

| 六亲 | 定义 | 象征 |
| --- | --- | --- |
| 父母 | 生我者 | 长辈、文书、房屋、学业 |
| 兄弟 | 同我者 | 同辈、竞争、破财 |
| 子孙 | 我生者 | 晚辈、福气、医药、解忧 |
| 妻财 | 我克者 | 财富、妻子、物品 |
| 官鬼 | 克我者 | 事业、官职、疾病、忧患 |

**配法**：先确定卦宫五行（乾兑=金，震巽=木，坤艮=土，坎=水，离=火），再将六爻地支逐一比对。

**例**：乾宫卦（属金），则：

+ 地支属土者 → 父母（土生金）
+ 地支属金者 → 兄弟（金同金）
+ 地支属水者 → 子孙（金生水）
+ 地支属木者 → 妻财（金克木）
+ 地支属火者 → 官鬼（火克金）

### 5_4 安六神：辅助判断

六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）按日干循环排列，附着于六爻，提供情绪、性质方面的辅助信息。六神本身不直接定吉凶，而是**修饰和细化**六亲的含义。

## 板块6 · 断卦核心：用神——整个体系的灵魂

### 6_1 取用神：一切分析的起点

> "用神是卦的灵魂，所有的生克、旺衰、冲合、刑害，都围绕用神展开。"

**取用规则**：

| 所问之事 | 用神 |
| --- | --- |
| 父母、长辈、文书、学业 | 父母爻 |
| 兄弟、朋友、同辈 | 兄弟爻 |
| 子孙、子女、医药 | 子孙爻 |
| 妻财、财物、妻子 | 妻财爻 |
| 功名、官职、疾病（忧患） | 官鬼爻 |
| 自身吉凶 | 世爻 |
| 他人之事 | 应爻 |

**多重用神的处理**：有些事涉及多个六亲，需取"主用神"+"辅助用神"。如占疾病：官鬼为主（病症），子孙为辅（医药）。

### 6_2 旺衰判断：日月为卦之主宰

这是全书最关键的技术环节。

**两大主宰**：

+ **月建**：司一月之权。决定爻的旺相休囚。
+ **日辰**：司四时之令。决定爻的生克力量。

**旺衰十二宫**（生旺墓绝）：

| 状态 | 含义 |
| --- | --- |
| 长生 | 始生，有发展潜力 |
| 沐浴 | 初露，尚需培养 |
| 冠带 | 渐成，初具规模 |
| 临官 | 当令，正值旺位 |
| 帝旺 | 极盛，力量最大 |
| 衰 | 由盛转弱 |
| 病 | 有损，功能受阻 |
| 死 | 无力，几近消亡 |
| 墓 | 收藏，潜藏不显 |
| 绝 | 穷尽，彻底无力 |
| 胎 | 重新孕育 |
| 养 | 培育待发 |

**实操要点**：

+ 用神得日月**生扶**则旺 → 吉。
+ 用神被日月**克伐**则衰 → 凶。
+ 用神**月破**（被月建冲克）→ 大凶，如同根基被毁。
+ 用神**旬空**（不在当旬）→ 暂时无力，出空则恢复。

### 6_3 生克冲合：关系的四种基本形态

| 关系 | 含义 | 断法 |
| --- | --- | --- |
| **生** | 相生助益 | 元神生用神 → 吉 |
| **克** | 相克制约 | 忌神克用神 → 凶 |
| **合** | 相合和好 | 合则成、则缓、则解 |
| **冲** | 相冲散乱 | 冲则散、则急、则变 |

**进阶概念**：

+ **元神**：生用神之爻。元神旺动 → 大吉。
+ **忌神**：克用神之爻。忌神旺动 → 大凶。
+ **仇神**：克元神之爻（间接伤用）。
+ **飞伏神**：伏神藏而不现，需飞神来引拔。
+ **三合局**：申子辰合水局、亥卯未合木局等，三爻齐动则成局，力量倍增。
+ **三刑**：寅巳申、丑戌未、子卯等，主伤残、纠纷。
+ **进神/退神**：化进则吉（如寅化卯），化退则凶（如卯化寅）。

### 6_4 断卦的完整思维链

```plain
起卦 → 装卦 → 取用神 → 判旺衰 → 看生克 → 察冲合 → 审动爻 → 定吉凶 → 推应期

```

**《碎金赋》精要断语**（可直接使用）：

> + "子孙发动伤官鬼，占病求医身便痊" → 占病见子孙动，病可愈。
> + "财爻发动克文书，应举求名总是虚" → 占考试见财爻动，名落孙山。
> + "世应相生则吉，世应相克则凶" → 问合作、交易，看世应关系。
> + "兄弟持世，必然破财" → 问财见兄弟持世，多有损耗。
> + "官鬼持世，忧患随身" → 问平安见官鬼持世，多有烦忧。

## 板块7 · 应期推断：什么时候发生

这是六爻预测中最难也最实用的部分。

### 7_1 基本原则

+ **用神旺相，逢值逢冲** → 断其发生。
+ **用神休囚，逢生逢扶** → 待时而动。
+ **动爻逢值逢合** → 应验之期。
+ **静爻逢冲** → 冲则动，动则有应。
+ **旬空出空** → 填空之日月。
+ **月破填实** → 逢合之期。

### 7_2 具体方法

以地支对应日期：

+ 用神为子水 → 应期在子日、丑日（逢合）、午日（逢冲）。
+ 用神动爻化出寅木 → 应期在寅月、寅日。
+ 旬空者（如甲子旬中戌亥空）→ 出旬（甲戌旬）或逢戌亥日填实。

> **实操提醒**：应期推断需结合具体情境灵活变通。初学者不宜过度追求精确日期，先掌握"旺则用、衰则待、空则出、破则填"的大方向。

## 板块8 · 专题应用速查（卷四~卷十精华提炼）

### 8_1 天时（卷四）

以**父母爻**为用（父母主日月星辰、阴晴雨雪）。父母爻旺相发动 → 有雨；妻财爻旺相 → 晴朗；子孙爻旺 → 风和日丽；官鬼爻旺 → 雷电阴霾。

### 8_2 家宅（卷五）

以**父母爻**为用（主家宅、房屋）。父母旺相 → 家宅安宁；官鬼动 → 有灾；兄弟动 → 口舌破财；妻财旺 → 富足。

### 8_3 疾病（卷六）

以**官鬼爻**为病，**子孙爻**为药。官鬼旺而子孙衰 → 病重难治；子孙旺动克官鬼 → 药到病除。用神（官鬼）入墓 → 病情沉疴；用神逢冲 → 病情反复。

### 8_4 婚姻（卷七）

男占以**妻财爻**为用，女占以**官鬼爻**为用。用神旺相、世应相生 → 婚成；用神休囚、世应相克 → 难成。兄弟动 → 有人争夺；父母动 → 有长辈阻挠。

### 8_5 求财（卷九）

以**妻财爻**为用。妻财旺相得生扶 → 财来；妻财休囚被克 → 无财。子孙为财源（生财），兄弟为劫财（克财）。财爻发动化子孙 → 财源广进；财爻化兄弟 → 财来财去。

### 8_6 功名（卷八）

以**官鬼爻**为用（官鬼主功名、官职）。官鬼旺相 → 有希望；官鬼休囚 → 无望。父母爻（文书）辅助 → 考试需文书得力。

### 8_7 词讼（卷十）

以**官鬼爻**为主（主官非、诉讼）。官鬼旺 → 官事缠身；子孙旺动克官鬼 → 诉讼可解。世爻代表自己，应爻代表对方。世克应 → 我胜；应克世 → 我败。

## 板块10 · 祛魅与正见：正确打开筮学的三种态度

### 10_1 反对宿命论

书中反复强调：卦象显势，不显命；占卜知机，不知定。吉卦如果骄纵妄为，必转为凶；凶卦如果修身改过、顺势而为，必转为吉。**事在人为，德可转命**。

### 10_2 反对鬼神论

全书所有推演，都基于阴阳五行、生克制化的自然规律，不依赖鬼神崇拜。"官鬼爻"象征的是忧患、疾病、官非、约束，并非真实的鬼神。祸福无门，唯人自召。

### 10_3 反对投机论

占以决疑，不占以侥幸；筮以慎行，不筮以妄为。占卜的目的是在犹豫不决时帮助人冷静思考、认清趋势、做出正确选择，而非让人坐等好运、投机取巧。

## 板块11 · 可落地的实操清单

### 11_1 日常练习五步法

1. **每天一卦**：就当日或近期最关切的一件事起卦，记录本卦、变卦、用神。
2. **严格装卦**：按纳甲→世应→六亲→六神的顺序完整装填，不跳步。
3. **定点分析**：只看用神的旺衰、生克、动静，写下一句判断。
4. **事后复盘**：事情发生后，回头验证判断的对错，积累经验。
5. **对照经典**：复盘时用《黄金策》《天玄赋》《何知章》的断语验证。

### 11_2 断卦自查清单

在给出结论前，依次检查：

- [ ] 用神是否明确？（一事一用，不可多头）
- [ ] 用神是否旺相？（看月建、日辰生克）
- [ ] 用神是否月破或旬空？
- [ ] 元神是否发动？（生用则吉）
- [ ] 忌神是否发动？（克用则凶）
- [ ] 世应关系如何？（相生/相克/比和）
- [ ] 动爻如何影响用神？（生/克/合/冲/化）
- [ ] 变卦趋势如何？（由凶转吉/由吉转凶）
- [ ] 应期大概在何时？（逢值/逢冲/出空/填实）
- [ ] 是否符合常理？（不违背现实逻辑）

### 11_3 常见误区警示

| 误区 | 正见 |
| --- | --- |
| 只看一爻定吉凶 | 必须兼顾全局，综合分析 |
| 歌诀照搬套用 | 歌诀是经验，需结合具体情境 |
| 一见克就断凶 | 克用神才凶，克忌神反吉 |
| 忽视日月力量 | 日月为卦之主宰，权重最高 |
| 脱离现实乱断 | 以理为主，结合实际 |
| 一事多占 | 心念不专，卦象混乱 |

## 板块12 · 总结：筮学指要的现代价值

《筮学指要》的真正价值，不在于"预测未来"的神秘感，而在于它提供了一套**结构化思考不确定性的思维框架**：

1. **系统观**：任何事情都可以拆解为要素（六亲）和关系（生克冲合），在动态中把握平衡。
2. **趋势观**：吉凶不是固定的结论，而是当前的能量状态，可以通过调整改变。
3. **决策观**：在信息不充分、未来不确定时，通过结构化分析辅助决策——这与现代风险评估、决策树分析异曲同工。
4. **心理观**：起卦—静心—解卦的过程，本质是一个**冷静反思、自我觉察、心理调适**的过程。从现代心理学看，这是一种极佳的情绪调节与认知重构方式。

> **最后一句**：古人云"善易者不卜"。真正读懂《筮学指要》的人，最终会发现——最好的卦象，不在铜钱蓍草之间，而在明理、修身、顺势而为的日常之中。
