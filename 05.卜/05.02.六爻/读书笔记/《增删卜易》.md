## 板块1 · 先搞懂：《增删卜易》到底在解决什么问题

很多人把《增删卜易》当成"算命口诀集"，这是误读。全书的核心命题其实是五个：

1. **这件事能不能成？**
2. **什么时候成？**
3. **为什么会失败？**
4. **谁对我有利、谁在制约我？**
5. **后续会怎么演变？**

野鹤老人借"卦"完成的，是一套**气机推演**——人起念时，意念已经与当下天地气机相感应，卦象不过是把这种信息"翻译"成可见的阴阳五行结构。所以卦不是神灵给答案，而是**你所处局势的结构化映射**。

这一底层认知决定了全书的取舍：

+ **增**的是：变通取用、活看动变、应期推演
+ **删**的是：繁杂神煞、牵强卦身、空洞天道空谈

全书理论可以压缩为四大支柱：**世用为纲、动静为机、旺衰定基、空冲分久暂**。

## 板块2 · 筑基：八卦、八宫、纳甲——把"卦"变成可计算结构

### 2_1 八卦：不是符号，是人伦万物的压缩包

八卦章开篇即言："乾为父、震为长男、坎为中男、艮为少男，俱属阳；坤为母、巽为长女、离为中女、兑为少女，俱属阴。" 野鹤老人一上来不讲卦画先讲人伦，是因为**六爻占的核心是人事**，八卦是世间万物与人伦关系的浓缩。

新手必背的三组属性：

| 卦 | 象形口诀 | 五行 | 人伦 | 自然象 |
| --- | --- | --- | --- | --- |
| 乾 ☰ | 乾三连 | 金 | 父 | 天 |
| 坤 ☷ | 坤六断 | 土 | 母 | 地 |
| 震 ☳ | 震仰盂 | 木 | 长男 | 雷 |
| 巽 ☴ | 巽下断 | 木 | 长女 | 风 |
| 坎 ☵ | 坎中满 | 水 | 中男 | 水 |
| 离 ☲ | 离中虚 | 火 | 中女 | 火 |
| 艮 ☶ | 艮覆碗 | 土 | 少男 | 山 |
| 兑 ☱ | 兑上缺 | 金 | 少女 | 泽 |

> ⚠️ 阴阳划分是定世应、分宫位的基础；五行属性是所有生克的根本。**这两点记不牢，后面全错。**

### 2_2 八宫：六十四卦的"家谱"

八宫以八个纯卦为统领，每宫 8 卦，按"八纯 → 一世 → 二世 → 三世 → 四世 → 五世 → 游魂 → 归魂"排序。

**世爻定位口诀**（新手必背）：

```plain
八卦之首世六当，以下初爻轮上扬；
游魂八位四爻立，归魂八位三爻详。

```

翻译：八纯卦世在第六爻；一世到五世卦，世爻分别在初爻到五爻；游魂卦世固定在四爻；归魂卦世固定在三爻。

**应爻**：与世爻永远隔两位。世在初则应在四，世在二则应在五，世在三则应在上，世在四则应在初，世在五则应在二，世在上则应在三。

### 2_3 浑天甲子（纳甲）：给爻装上地支

纳甲口诀：

```plain
乾金甲子外壬午，坎水戊寅外戊申
艮土丙辰外丙戌，震木庚子外庚午
巽木辛丑外辛未，离火己卯外己酉
坤土乙未外癸丑，兑金丁巳外丁亥

```

口诀前半为内卦（下三爻）纳甲，后半为外卦（上三爻）。实战中**天干几乎不用，只看地支**——因为定五行生克的核心在地支。

地支五行务必滚瓜烂熟：**子亥水、寅卯木、巳午火、申酉金、辰戌丑未土**。

## 板块3 · 起卦：三枚铜钱，把"念"变成"卦"

### 3_1 标准操作

1. 净手静心，三枚铜钱合掌，**专注默念所问之事**
2. 摇落，看"背"的数量：
    - **一背两字** → 少阳（静爻）
    - **两背一字** → 少阴（静爻）
    - **三背无字** → 老阳（动爻，阳变阴）
    - **三字无背** → 老阴（动爻，阴变阳）
3. **从下往上**画六爻：第一次摇出的是初爻，第六次是上爻

> ⚠️ 新手 90% 的错都在"从上往下画"。卦画反了，后续世应、六亲、旺衰全盘皆错。这是最基础也最致命的错误。

### 3_2 起卦四戒

+ **一事一占**：不反复问同一件事
+ **问清问细**：问题越具体，卦越精准
+ **不占邪妄**：心术不正，卦亦不正
+ **子时慎占**：子时为两日之交，气机不稳

## 板块4 · 灵魂：六亲与用神——卦里的人事分类法

### 4_1 六亲推导规则

以**卦所在本宫的五行**为"我"：

```plain
生我者父母，我生者子孙；
克我者官鬼，我克者妻财；
比和者兄弟。

```

例：乾宫卦属金，"我"即为金。土生金 → 土为父母；火克金 → 火为官鬼；金克木 → 木为妻财；金生水 → 水为子孙；金与金同 → 兄弟。

### 4_2 六亲类象（断卦的"字典"）

| 六亲 | 人事 | 事物 |
| --- | --- | --- |
| 父母 | 父母、长辈、师长、贵人 | 房屋、车辆、文书、合同、学业、考试、证件 |
| 兄弟 | 兄弟姐妹、朋友、同辈、竞争者 | 竞争、阻隔、破财、口舌 |
| 子孙 | 子女、晚辈、下属、客户 | 医药、福神、财源、解忧、娱乐 |
| 妻财 | 妻子、女友、下属 | 钱财、货物、资产、珠宝、粮食 |
| 官鬼 | 领导、上级、丈夫、小人 | 功名、事业、官司、疾病、灾祸 |

### 4_3 用神速查表（断卦第一刀）

| 所问之事 | 用神 | 辅助参考 |
| --- | --- | --- |
| 求财、生意、物品 | 妻财爻 | 子孙爻（生财之源） |
| 事业、升职、功名 | 官鬼爻 | 父母爻（工作单位） |
| 考试、文书、房产 | 父母爻 | — |
| 感情（男问） | 妻财爻 | 应爻（对方） |
| 感情（女问） | 官鬼爻 | 应爻（对方） |
| 疾病、医药 | 官鬼爻为病，子孙爻为药 | 世爻（自身） |
| 竞争、合伙、破财 | 兄弟爻 | — |
| 子女、宠物、技术 | 子孙爻 | — |
| 自己 | 世爻 | — |
| 对方、环境 | 应爻 | — |

> 📌 野鹤老人反复强调：**用神取错，全盘皆错**。真正的高手第一件事不是断卦，而是"先定用神"。

### 4_4 用神要"活看"，不能死心眼

《增删卜易》里有个经典卦例：一人自占病，得**官鬼持世**。按常理，官鬼是病，持世岂不大凶？但野鹤老人一看，卦中**子孙爻强旺发动来克世爻官鬼**——这竟是"去病"之象，断为吉，后果然痊愈。

**启示**：当用神本为"忌神"时，若有强大制化，反为吉兆。这就是"增删"二字真义——增的是变通，删的是教条。

## 板块5 · 断卦五步法：野鹤老人的标准作业程序

### 5_1 第一步：定用神

所问之事对应何爻。这一步错了，后面全错。

### 5_2 第二步：看旺衰（日月为纲）

**月建为提纲，日辰为主宰**。

+ **月建**司一月之权，类似"时代背景"
+ **日辰**司一日之权，类似"现实执行层"

**旺衰判定**：

| 用神状态 | 月建 | 日辰 | 结论 |
| --- | --- | --- | --- |
| 最旺 | 临月建 | 临日辰 | 旺上加旺 |
| 旺 | 临月建 | 日生 | 有根有力 |
| 相 | 月扶 | 临日辰 | 得时得地 |
| 休囚 | 月克 | 日克 | 无根无助 |
| 有救 | 月克 | 日生 | 休囚有气 |
| 大凶 | 月破 | 日克 | 衰败已极 |

**生旺墓绝**（用神入墓则事难成，待冲墓之日月可解）：

+ 金：长生巳、帝旺酉、墓丑、绝寅
+ 木：长生亥、帝旺卯、墓未、绝申
+ 水：长生申、帝旺子、墓辰、绝巳
+ 火：长生巳、帝旺午、墓戌、绝亥
+ 土：长生申、帝旺子、墓辰、绝巳

> 💡 口诀："**旺相不拘于墓绝，休囚最怕入墓乡**"。用神本身旺相，入墓也只是暂时受阻；用神休囚，再入墓就是雪上加霜。

### 5_3 第三步：查动变（吉凶生乎动）

**"神兆机于动"**——动爻是整件事的开关。不动不看，重点看动爻。

**3.1 进神与退神**

进神组合（旺相大吉）：

+ 亥化子、寅化卯、巳化午、申化酉
+ 辰化未、戌化丑、丑化辰、未化戌

退神组合（休囚大凶）：

+ 子化亥、卯化寅、午化巳、酉化申
+ 辰化卯、戌化未、丑化戌、未化辰

断语：**旺相化进，事事亨嘉；休囚化退，般般败退**。

**3.2 回头生克（重中之重）**

| 动变类型 | 吉凶 | 断语 |
| --- | --- | --- |
| 回头生 | 大吉 | 化出之爻生本爻，生机绵绵 |
| 回头克 | 大凶 | 化出之爻克本爻，十有九死 |
| 化去 | 平 | 本爻克变爻，我去克他，不为凶 |
| 化来 | 凶 | 变爻克本爻，他来克我，祸不轻 |

> 💡 野鹤名言："**凡遇卦化回头克者，不论用神之衰旺，皆以凶推**"。

### 5_4 第四步：辨格局（冲合、空亡、反吟伏吟）

**空亡**：甲子旬中戌亥空，依此类推。爻逢空则力减。

**月破**：爻地支与月建相冲。

**六合与六冲**：

+ **六合**主成、主稳
+ **六冲**主散、主变

**六冲卦**共十卦：八纯卦（乾为天、坎为水、艮为山、震为雷、巽为风、离为火、坤为地、兑为泽）+ 天雷无妄 + 雷天大壮。

> 📌 野鹤老人的实用区分：**短期琐事、近病、临时纠纷，用神逢空、卦逢六冲，主灾厄消散，无需医治调解**；久病、长远之事，逢空逢冲则主凶。

**反吟与伏吟**：

+ **反吟**：主反复、阻滞（爻变冲克本位）
+ **伏吟**：主忧愁、呻吟（爻变相同地支）

### 5_5 第五步：断吉凶与应期

**应期推断法则**：

+ 用神旺 → **逢值、逢合**应事
+ 用神衰 → **生扶之日**应事
+ 用神空 → **出空、填实**应事
+ 用神冲 → **逢合**应事
+ 暂时不应，多是"合住" → 待冲开之时
+ 长久不应，多是"空亡" → 待填实之时
+ 动而逢合则迟，静而逢冲则速

## 板块6 · 野鹤老人的"三把刀"：砍掉学卦路上的三大误区

### 6_1 第一刀：吉凶只从"动"中求

很多人看卦先挨个分析六亲、六神，野鹤老人直接告诉你：**先看动爻指向哪里**。

+ 问财运，子孙爻发动去生妻财 → 根基就有了
+ 兄弟爻发动克妻财 → 外面看着再热闹，内在也是破耗

这一刀砍掉的是"贪多求全"。

### 6_2 第二刀：用神要"活看"

前文"官鬼持世"的病卦案例即是明证。**当用神本为忌神时，若有强大制化，反为吉兆**。

这一刀砍掉的是"死背公式"。

### 6_3 第三刀：应期就在"逢合逢冲"

能断对结果却断不对时间，是新手常态。增删里给了一个极简法则：

+ **暂时不应**，多是"合住" → 待冲开之时
+ **长久不应**，多是"空亡" → 待填实之时
+ **动而逢合则迟，静而逢冲则速**

这一刀砍掉的是"只断吉凶，不问时机"。

## 板块8 · 实操演练：一个完整案例

**问**：近期求财如何？

**起卦**：得《火天大有》变《山天大畜》

**装卦结果**：

+ 世爻：九三（辰土兄弟）
+ 应爻：上九（巳火官鬼）
+ 用神：初九（子水妻财），**发动**
+ 动爻：九三辰土 → 变爻丑土

**断卦要点**：

1. **定用神**：求财看妻财爻，本卦初九子水妻财为用神，且发动——财动主财源有变动
2. **看旺衰**：子水妻财得月建生扶，旺相有力
3. **查动变**：
    - 用神妻财子水发动，本为吉兆
    - 世爻兄弟辰土发动化丑土（进神），主竞争加剧、同行争夺
    - 应爻官鬼巳火生世爻辰土，有贵人/官方助力
4. **辨格局**：子水妻财月建生扶，无空破
5. **综合判断**：
    - **财运可期**（用神旺相发动）
    - **但需防竞争**（兄弟爻动化进神劫财）
    - **有贵人相助**（应爻官鬼生世）
    - **应期**：妻财子水旺相，逢子日或丑日（填实/合住解除）财可入账

## 板块9 · 新手修炼路径（三个月入门计划）

### 9_1 第一个月：筑基

+ 背熟八卦卦画、五行、八宫世应口诀
+ 用三枚硬币每天练习起卦 3-5 次，做到"从下往上画"形成肌肉记忆
+ 用六爻排盘软件（如易师汇等）辅助装卦，但要求自己能手动验算

### 9_2 第二个月：用神与旺衰

+ 精读《增删卜易》卷一原文（从八卦章到归魂游魂章）
+ 手抄六亲类象表、用神速查表
+ 每天取 1 个真实小事起卦（如"今日出行顺否"、"下午会议结果"），断完后记录，事后核对

### 9_3 第三个月：动变与应期

+ 重点攻克进神退神、回头生克、空破冲合
+ 研读《增删卜易》中"反吟伏吟"、"旬空月破"等专章
+ 建立自己的卦例笔记本，每卦记录：本卦、用神、旺衰、动变、应期推断、事后验证

> 📌 **修炼心法**：很多人说六爻难学，其实难的不是卦理，是人心浮躁，总想找捷径。野鹤老人删掉的那些繁文缛节，恰恰是后人偷懒的借口。**老老实实从八卦背起，从摇卦练起，三个月必见成效**。

## 板块10 · 常见误判与纠正

| 误判 | 真相 |
| --- | --- |
| 一见官鬼持世就断凶 | 需看官鬼是用神还是忌神；求功名官鬼持世反为吉 |
| 逢空即废 | "动不为空"——动爻逢空只待冲空、填实之日应验，并非全然无用 |
| 神煞决定吉凶 | 野鹤老人弃繁杂神煞不用，只以五行生克为正理 |
| 死守卦身 | 全书彻底舍弃繁杂卦身概念，以世爻、用神二元为核心 |
| 只断吉凶不问时机 | 应期是《增删卜易》实战价值极高的部分，必须通过日月动变合冲推断 |

## 板块11 · 进阶心法：把卦当成"事态分析模型"

跳出"算命"视角，《增删卜易》其实提供了一套通用的**事态分析框架**：

+ **用神** = 你要分析的核心对象
+ **世爻** = 你自己 / 内部条件
+ **应爻** = 对方 / 外部环境
+ **月建** = 行业大势 / 时代背景
+ **日辰** = 当下实时条件
+ **动爻** = 正在发生的关键变化
+ **动变** = 变化的趋势与结局
+ **生克冲合** = 各要素间的相互作用

带着这个视角重读《增删卜易》，你会发现它不只是一本占筮书，更是一本**教你结构化思考"一件事能不能成"的决策手册**。这也是为什么它能跨越三百年，至今仍是六爻实战派的案头书。

> ✨ 学卦的最终目的，不是预知未来，而是**看清当下**——看清自己处在什么位置、面临什么力量、关键变量在哪里变动。卦只是镜子，照见的始终是你与这个世界的关系。
