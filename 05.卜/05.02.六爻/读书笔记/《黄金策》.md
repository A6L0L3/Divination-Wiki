# 黄金策断卦心法手册：从《总断千金赋》到分类占的全链路实操

> 《黄金策》题名明·刘基（刘伯温）著，学界普遍认为可能是明代术士整理前人成果、假托刘基之名传世，但无论作者是谁，都无损它在六爻领域的巅峰地位。它是火珠林纳甲法的集大成之作，《卜筮全书》完整收录、《卜筮正宗》大半篇幅为其作注、《增删卜易》核心口诀多化用于此——后世六爻书几乎都是在这部典籍的理论地基上做发挥。
>
> 全书分为两大板块：开篇《总断千金赋》是全书灵魂，短短数百句讲透六爻底层逻辑；其后二十余个分类占专题（天时、年时、国朝、征战、身命、婚姻、求财、疾病、家宅、出行、功名、失物等），把古人生活方方面面纳入占断框架。
>
> 本笔记以《总断千金赋》为经，以分类占与网络教程的实操补丁为纬，重构成一份能直接上手的"断卦作战手册"——而不是对原文的目录式复述。

## 板块1 · 先正认知：《黄金策》在六爻体系里的真实位置

很多人学六爻先读《增删卜易》，看重里面大量实战卦例。但老易家常说：不懂《黄金策》，断卦很难上台阶。

两者的关系可以这样理解：

+ **《黄金策》是内功心法总纲**：确立以五行生克为核心的断卦逻辑，把月建、日辰、旺衰、动静、空破、生克冲合作了系统梳理
+ **《增删卜易》是实战招式**：用大量卦例验证这套逻辑

在《黄金策》之前，六爻混杂大量卦辞、卦象、神煞，判断标准很乱。这本书的价值在于：**把断卦从"天马行空"变成"可复制的推理逻辑"**。

> 关键认知：《黄金策》的核心思想是"以五行生克用神为本，其他为辅"。优先看旺衰、动静，再参考神煞卦象，不要本末倒置。很多人断卦不准，就是主次颠倒，抓小丢大。

## 板块2 · 《总断千金赋》七大心法：断卦的底层逻辑

### 2_1 心法一：一理融贯

> 原文：动静阴阳，反复迁变。虽万象之纷纭，须一理而融贯。

卦由动/静、阴/阳组成，变化万千；但万变不离其宗——**五行生克制化**。这是整部《黄金策》的总纲。

### 2_2 心法二：贵在中和

> 原文：夫人有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。

卦贵中和：

+ **用神太旺（太过）**：需克泄方成事
+ **用神太弱（不及）**：需生扶方有利

这条原则是"病药说"的源头——后文详述。

### 2_3 心法三：生克喻象

> 原文：生扶拱合，时雨滋苗；克害刑冲，秋霜杀草。

+ **生、扶、拱、合**：吉，如时雨润苗
+ **克、害、刑、冲**：凶，如秋霜杀草

### 2_4 心法四：日月为纲

> 原文：日辰为六爻之主宰，月建乃万卦之提纲。

+ **日辰**：定爻之生克、空破、墓绝，如宰相，一年当中可以多次值日司权
+ **月建**：定爻之旺衰，一月之权，如皇帝

断卦时，**先看日辰与月建对用神的作用**，这是判断旺衰的第一抓手。

### 2_5 心法五：世应定位

> 原文：世为己，应为人，大宜契合；动为始，变为终，最怕交争。

+ **世爻**：代表自己
+ **应爻**：代表他人/事
+ **世应相生相合吉，相冲相克凶**
+ **动爻**：事之始；**变爻**：事之终，忌动变相冲

延伸断语：

+ 应位遭伤 → 不利他人之事
+ 世爻受制 → 岂宜自己之谋
+ 世应俱空 → 人无准实
+ 内外竞发 → 事必翻腾

### 2_6 心法六：用神决断

> 原文：用神有气无他故，所作皆成；主象徒存更被伤，凡谋不遂。

+ **用神旺相无伤** → 万事可成
+ **用神休囚受克** → 谋事难成

### 2_7 心法七：神煞为辅

> 原文：是故吉凶神煞之多端，何如生克制化之一理。

这是《黄金策》最具革命性的论断——**神煞之权重，轻于五行之权重**。

+ 青龙动固吉也，若临所忌之爻刑冲克害用神，则何益于事（难掩其为凶）
+ 白虎动固凶也，若临所喜之爻生扶拱合世身，则何损于吾（不害其为吉）
+ 朱雀虽主口舌，然非兄弟併临，则不能成口舌
+ 玄武虽主盗贼，若非官爻併临，则不能称盗贼

> 现代启示：六神、神煞只能"推其性情形状"，吉凶得失当**专以六亲生克为主**。

---

**示例**：「动静阴阳，反复迁变」落到一卦，即看动爻如何打破原本的静态格局。

## 板块3 · 病药学说：断卦的核心方法论

《黄金策》最实用的隐性框架，是"**寻病 → 查药 → 定吉凶**"：

### 3_1 什么叫"病"

卦中不和谐、导致凶险或问题的关键矛盾点：

+ 用神衰败
+ 被忌神动克
+ 逢月破日冲
+ 入墓、化绝、化死

### 3_2 什么叫"药"

能够解决这个矛盾、化凶为吉的解救因素：

+ 原神发动生扶
+ 忌神被制服
+ 用神逢合解冲
+ 绝处逢生（如酉动化寅，酉金绝于寅木；若未日或戌日测卦，则土去生金，用神得救）

### 3_3 病药组合的四种结局

| 病药状态 | 吉凶判定 |
| --- | --- |
| 有"病"无"药" | 凶 |
| 有"病"有"药" | 先凶后吉或无妨 |
| "病"重"药"轻 | 坎坷 |
| "病"轻"药"重 | 顺利 |

> "有伤须救，无故勿空"——用神被克又得救，事情先难后易、先凶后吉；用神旬空，只要还有气，出空时仍然有用。

---

**示例**：用神受克为「病」，得动爻生扶为「药」；有药则凶中转吉，无药则病重难救。

## 板块4 · 用神、原神、忌神、仇神：角色定位体系

分析卦象的基石，是给每个爻分配"角色"：

```plain
仇神 → 生 → 忌神 → 克 → 用神 ← 生 ← 原神

```

以用神为妻财土为例：

+ **用神**：妻财土（所占之事的核心）
+ **原神**：火（火生土，是用神的助力）
+ **忌神**：木（木克土，是用神的阻力）
+ **仇神**：水（水生木，是忌神的帮凶）

断卦时，四者都要看，但优先级是：**用神 > 原神 > 忌神 > 仇神**。

## 板块5 · 旺衰与动静：判断能量状态

### 5_1 旺衰来源

+ **月建**：掌管一月之权，如皇帝。爻临月建或得月建生扶为旺
+ **日辰**：掌管一日之权，如宰相，影响力仅次于月建

例：寅月木旺，用神为妻财土，则土被月建木克，为"衰"。

### 5_2 动静之别

+ **静爻**：安静不动，力量弱，处于被动状态
+ **动爻**：发动变化，是整件事的开关

动爻的变爻对本动爻的作用：

+ **化回头生、化长生、化进神** → 变好
+ **化回头克、化回头冲、化墓、化绝** → 变坏

### 5_3 空亡妙用

> 原文：空逢冲而有用，合遭破以无功。自空化空，必成凶咎。

+ **空爻逢冲** → 暗动，有用
+ **合局被冲破** → 合局无效
+ **空化空** → 真空，大凶
+ **旬空之爻如果本身旺相** → 不以旬空论

## 板块6 · 分类占断：五大高频场景的实操要点

《黄金策》后二十余章是分类占，下面提炼最常用的五个场景：

### 6_1 场景一：求财

**核心口诀**："财星旺相，必得千钟之粟；兄如发动，须防减俸除粮。"

判定要点：

+ **用神**：妻财爻
+ **原神**：子孙爻（生财之源）
+ **忌神**：兄弟爻（劫财之神）
+ 财星旺相 → 财源丰厚
+ 兄弟发动 → 破财、减俸
+ 子孙发动生妻财 → 财有源头，根基稳固

### 6_2 场景二：婚姻

**核心要点**：

+ **男问**：用神妻财爻，应爻为对方
+ **女问**：用神官鬼爻，应爻为对方
+ 阴阳皆动 → 宜为良缘
+ 应阴世阳 → 最吉祥
+ 世爻居内卦 → 团圆百年昌
+ 辰午酉亥爻 → 破相，夫妻相攻
+ 游魂、八纯 → 再嫁娶
+ 上吉卦：泰、节、咸、恒 → 永遂通

### 6_3 场景三：疾病

**核心要点**：

+ **官鬼爻为病**，子孙爻为药
+ 子孙爻来克世 → 药到病除
+ 官鬼持世 → 除非是公职，否则当做鬼爻，应当去除
+ 用爻入墓 → "墓中人，不冲不发"，需冲开墓库
+ 天喜临用神 → 病易愈；若临凶煞 → 必生悲

### 6_4 场景四：功名/求官

**核心口诀**："父爻旺相，文成掷地金声；鬼位兴隆，家报泥金喜捷。"

判定要点：

+ **父母爻为文书**（功名之凭）
+ **官鬼爻为功名**（得官之象）
+ 父母爻旺相 → 文书称意，文采斐然
+ 官鬼爻兴隆 → 必得功名
+ 父母爻空亡 → "父亡而事无头绪"，主事无头绪

### 6_5 场景五：出行

**核心要点**：

+ **用神克世** → 在外之人回家心切，即日将回（物来寻我，不能一概以凶断）
+ **用神被克** → 出行不利
+ **往亡煞** → 出行最怕，"出行最怕往亡，如系吉神终获利"
+ 世爻发动 → "世或交重，两目顾瞻于马首"，主心意徘徊

## 板块7 · 应期推断：断卦的"时间之锁"

应期推断是《黄金策》实战价值极高的部分。《卜筮正宗》对其做了经典论述，综合网络教程的实操补丁，整理如下：

### 7_1 核心法则

**第一定律：合冲待变**

+ 用神被合 → 待冲破之日应验
+ 用神被冲 → 待逢合之日应验

**第二定律：空亡待实**

+ 用神旬空安静 → 出旬逢冲之日应验
+ 用神旬空发动 → 出旬值日应验
+ 用神旬空发动逢冲（冲实） → 本日应验

**第三定律：墓库待冲**

+ 用神入墓 → 待冲墓、冲用月日应验

**第四定律：衰旺待时**

+ 用神休囚 → 必待生旺之期成事
+ 用神太旺（过旺） → 当以墓库日月断之（损之斯成）

**第五定律：动变寻机**

+ 用神有气发动 → 以合日断之
+ 动爻化进神 → 逢值逢合为应期
+ 动爻化退神 → 逢破逢冲为应期

### 7_2 应期推断速查表

| 用神状态 | 应期判定 |
| --- | --- |
| 用神合住 | 冲破之期 |
| 用神休囚 | 生旺之期 |
| 用神旺相不动 | 冲动月日 |
| 用神有气发动 | 合日 |
| 用神受制 | 制煞日月 |
| 用神入墓 | 冲墓、冲用月日 |
| 用神旬空安静 | 出旬逢冲之日 |
| 用神旬空发动 | 出旬值日 |
| 用神旬空发动逢冲 | 本日 |
| 用神化进神 | 逢值逢合 |
| 用神化退神 | 逢破逢冲 |
| 用神绝于日辰或化绝 | 长生之日 |

> **终极心法**："神兆机于动"——所有应期推断的终极心法。独发之爻是象数模型的信号灯，应期往往与此爻的冲合值墓密切相关。忌神动处是应凶之期，原神动处是应吉之期。

## 板块8 · 断卦九步法：从起卦到应期的标准作业

把《黄金策》的心法转化为可操作的流程：

### 8_1 第一步：起卦凝念

三枚铜钱，从下往上画六爻。一事一占，念须专一。"筮必诚心"——这是《黄金策》的终极告诫。

### 8_2 第二步：装卦定基

+ 定八宫、安世应
+ 纳甲（装干支）、配六亲
+ 排六神

### 8_3 第三步：定用神

按所占之事取用神（妻财、官鬼、父母、子孙、兄弟）。**用神取错，全盘皆错**。

### 8_4 第四步：查日月定旺衰

+ 看月建：用神临月建或得月建生扶为旺
+ 看日辰：日辰定爻之生克、空破、墓绝
+ 看十二长生：用神临长生、帝旺为吉地；入死、墓、绝、空为凶地

### 8_5 第五步：寻"病"

+ 用神是否衰败？
+ 是否被忌神动克？
+ 是否逢月破日冲？
+ 是否入墓、化绝、化死？

### 8_6 第六步：查"药"

+ 原神是否发动生扶？
+ 忌神是否被制服？
+ 用神是否逢合解冲？
+ 是否有"绝处逢生"之机？

### 8_7 第七步：看动变

+ 动爻是事之始，变爻是事之终
+ 化回头生/长生/进神 → 变好
+ 化回头克/冲/墓/绝 → 变坏
+ "神兆机于动"——独发之爻是应期的关键

### 8_8 第八步：六神与神煞参考

**仅作辅助**，不可凌驾于生克制化之上：

+ 青龙临喜用 → 锦上添花
+ 白虎临忌神 → 雪上加霜
+ 朱雀需配兄弟方成口舌
+ 玄武需配官鬼方成盗贼

### 8_9 第九步：推应期

按"合冲待变、空亡待实、墓库待冲、衰旺待时、动变寻机"五大法则推断。

---

**示例**：问婚姻→取妻财/官鬼→看世应→察旺衰→辨冲合→定应期，九步依序不跳步。

## 板块11 · 进阶心法：《黄金策》的现代意义

跳出术数视角，《黄金策》提供的是一套**结构化的问题分析方法**：

+ **用神** = 你要分析的核心对象
+ **原神/忌神/仇神** = 核心对象的助力与阻力系统
+ **日月** = 时代背景与当下条件
+ **世应** = 主体与客体的互动关系
+ **动爻** = 正在发生的关键变化
+ **病药** = 问题诊断与解决方案
+ **应期** = 时间轴上的关键节点

这套方法与现代管理学中的"SWOT 分析 + 利益相关者分析 + 时间序列分析"有异曲同工之妙。刘伯温（或其背后的明代术士群体）的天才之处在于：把复杂的世事判断**结构化、符号化、可计算化**。

> 学《黄金策》的真正价值，不在于占验准不准，而在于理解**中国古人如何把"天、地、人"三才压缩进六十四卦的符号系统里，并给出可操作的判断流程**。这种"一理融贯万象"的结构化思维，对今天处理复杂问题仍有深刻的启发。
