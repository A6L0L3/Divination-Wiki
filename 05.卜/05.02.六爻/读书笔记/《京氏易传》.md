## 板块1 · 先建立认知：《京氏易传》到底在做什么

读《京氏易传》最大的门槛，是它**根本不是用来"读"的，而是用来"演"的**。

全书三卷按八宫卦序排列：上卷乾、震、坎、艮四宫；中卷坤、巽、离、兑四宫；下卷杂论卜筮、纳甲、二十四气候配卦等。每一卦的讲解都固定包含一组"标准字段"：

+ **纯阳/纯阴用事**——点明本卦阴阳主气
+ **象配某、属某**——配八卦之象、五行之属
+ **与某为飞伏**——标明飞伏关系
+ **几世居世**——定世爻位置与居世身份（元士、大夫、三公、诸侯、天子、宗庙）
+ **某为应**——定应爻
+ **建某至某**——建候（接入节气时序）
+ **积算起某至某**——积算（吉凶之兆的积年/月/日/时起法）
+ **五星从位起某**——配五星（星象）
+ **某宿从位降某**——配二十八宿
+ **降入某卦**——指明下一卦的流转

这套字段告诉我们：京房的易学是**宇宙论 + 历法 + 星象 + 阴阳消长 + 占验**的一体化模型，而非单纯的占卜口诀。

> 关键认知：后世《增删卜易》《卜筮正宗》等六爻书，只是抽取了京氏体系中的"八宫 + 世应 + 纳甲 + 六亲 + 飞伏"这一部分，并把"建候积算、五星、二十八宿"等删繁就简。所以学《京氏易传》不能只按现代六爻的套路去套，要先回到汉易"卦气"与"象数"的本源。

## 板块2 · 八宫体系：六十四卦的"家谱"

### 2_1 八宫排序

京房把六十四卦分为八宫，每宫以八纯卦为宗主：

| 宫 | 本宫纯卦 | 一世 | 二世 | 三世 | 四世 | 五世 | 游魂 | 归魂 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 乾宫 | 乾 | 姤 | 遁 | 否 | 观 | 剥 | 晋 | 大有 |
| 震宫 | 震 | 豫 | 解 | 恒 | 升 | 井 | 大过 | 随 |
| 坎宫 | 坎 | 节 | 屯 | 既济 | 革 | 丰 | 明夷 | 师 |
| 艮宫 | 艮 | 贲 | 大畜 | 损 | 睽 | 履 | 中孚 | 渐 |
| 坤宫 | 坤 | 复 | 临 | 泰 | 大壮 | 夬 | 需 | 比 |
| 巽宫 | 巽 | 小畜 | 家人 | 益 | 无妄 | 噬嗑 | 颐 | 蛊 |
| 离宫 | 离 | 旅 | 鼎 | 未济 | 蒙 | 涣 | 讼 | 同人 |
| 兑宫 | 兑 | 困 | 萃 | 咸 | 蹇 | 谦 | 小过 | 归妹 |

> **八宫排序口诀**：乾震坎艮、坤巽离兑（乾父率三男，坤母率三女）。

### 2_2 爻变规则（八宫生成的底层逻辑）

从本宫纯卦出发，严格按"由初至五、再返四、再复下"的规则变出七卦：

```plain
本宫纯卦
  ↓ 变初爻
一世卦
  ↓ 变二爻
二世卦
  ↓ 变三爻
三世卦
  ↓ 变四爻
四世卦
  ↓ 变五爻
五世卦
  ↓ 返变四爻（退一爻）
游魂卦
  ↓ 下卦三爻整体恢复本宫
归魂卦

```

**以乾宫为例**：

+ 本宫：乾 ☰☰
+ 一世：初爻变阴 → 姤 ☴☰
+ 二世：二爻再变阴 → 遁 ☶☰
+ 三世：三爻再变阴 → 否 ☷☰
+ 四世：四爻再变阴 → 观 ☷☴
+ 五世：五爻再变阴 → 剥 ☷☶
+ 游魂：五世退四爻（四爻由阴返阳）→ 晋 ☷☲
+ 归魂：晋之下卦三爻整体恢复乾 ☰ → 大有 ☲☰

> **铁律**：上爻（第六爻）为宗庙爻，永远不变。所有卦变只在初至五爻变动。

### 2_3 世爻定位（必背口诀）

```plain
本宫世在上，一世世在初
二世世在二，三世世在三
四世世在四，五世世在五
游魂世在四，归魂世在三

```

世应永远相隔两位：世在初则应在四，世在二则应在五，世在三则应在上，世在四则应在初，世在五则应在二，世在上则应在三。

### 2_4 天易、人易、地易、鬼易

京房把八宫卦按世次分为四类，对应阴阳消长的四种境界：

| 类别 | 包含卦次 | 象征 |
| --- | --- | --- |
| **天易** | 五世卦、八纯（上世） | 六阳/六阴之极致 |
| **人易** | 三世卦、四世卦 | 阴阳各半，人居其中 |
| **地易** | 一世卦、二世卦 | 一阴一阳之始 |
| **鬼易** | 游魂卦、归魂卦 | 魂魄游离、回归本位 |

这一分类不只是标签，它直接关联"起月例"——

### 2_5 起月例：卦次与节气的对应

| 卦次 | 阳卦主月 | 阴卦主月 |
| --- | --- | --- |
| 一世 | 十一月（子） | 五月（午） |
| 二世 | 十二月（丑） | 六月（未） |
| 三世 | 正月（寅） | 七月（申） |
| 四世 | 二月（卯） | 八月（酉） |
| 五世 | 三月（辰） | 九月（戌） |
| 八纯 | 四月（巳） | 十月（亥） |
| 游魂 | 与四世同 | 与四世同 |
| 归魂 | 与三世同 | 与三世同 |

这张表是京氏"卦气说"的骨干——**每一卦都对应特定的节气时空坐标**，这是后世六爻简化版里被丢掉的核心。

## 板块3 · 纳甲纳支：给每一爻装上"身份证"

### 3_1 纳干口诀

```plain
乾纳甲壬，坤纳乙癸
震纳庚，巽纳辛
坎纳戊，离纳己
艮纳丙，兑纳丁

```

原理：乾父坤母为阴阳之始，故配天干首尾（甲壬阳始末、乙癸阴始末）；震巽坎离艮兑为乾坤六子，按长男到少女的次第配庚辛戊己丙丁。

### 3_2 纳支规则

阳卦（乾震坎艮）纳阳支，阴卦（坤巽离兑）纳阴支。各宫纳支如下：

| 卦 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 |
| --- | --- | --- | --- | --- | --- | --- |
| 乾 | 子水 | 寅木 | 辰土 | 午火 | 申金 | 戌土 |
| 坤 | 未土 | 巳火 | 卯木 | 丑土 | 亥水 | 酉金 |
| 震 | 子水 | 寅木 | 辰土 | 午火 | 申金 | 戌土 |
| 巽 | 丑土 | 亥水 | 酉金 | 未土 | 巳火 | 卯木 |
| 坎 | 寅木 | 辰土 | 午火 | 申金 | 戌土 | 子水 |
| 离 | 卯木 | 丑土 | 亥水 | 酉金 | 未土 | 巳火 |
| 艮 | 辰土 | 午火 | 申金 | 戌土 | 子水 | 寅木 |
| 兑 | 巳火 | 卯木 | 丑土 | 亥水 | 酉金 | 未土 |

### 3_3 六亲推导

以**本宫卦的五行**为"我"：

```plain
生我者 → 父母
我生者 → 子孙
克我者 → 官鬼
我克者 → 妻财
同我者 → 兄弟

```

**以乾宫为例**（乾属金）：

+ 初爻子水 → 金生水 → **子孙**
+ 二爻寅木 → 金克木 → **妻财**
+ 三爻辰土 → 土生金 → **父母**
+ 四爻午火 → 火克金 → **官鬼**
+ 五爻申金 → 同属金 → **兄弟**
+ 上爻戌土 → 土生金 → **父母**

《京氏易传》原文对乾卦的表述正是："水配位为福德（甲子水是乾之子孙），木入金乡居宝贝（甲寅木是乾之财），土临内象为父母（甲辰土是乾之父母），火来四上嫌相敌（壬午火是乾之官鬼），金入金乡木渐微（壬申金同位伤木）"。这一段就是六亲系统的源头。

## 板块4 · 飞伏：京氏易学的灵魂

### 4_1 什么是飞伏

"飞"是显现于外的爻，"伏"是隐藏在飞爻之下的对立面。**阳飞则阴伏，阴飞则阳伏**。

飞伏的深意：卦中所见未必是全部，隐藏的"伏神"往往才是事情的关键。后世六爻"卦中无财看伏神"的用法即源于此。

### 4_2 飞伏的分类（五种情况）

**第一类：八纯卦之间，以错卦为飞伏**

+ 乾 ↔ 坤
+ 坎 ↔ 离
+ 艮 ↔ 兑
+ 震 ↔ 巽

例如《京氏易传》原文："乾……与坤为飞伏"、"姤……与巽为飞伏"。

**第二类：一世、二世、三世卦，与本卦之内卦为飞伏**
以乾宫为例：

+ 一世姤（☴☰）：外乾内巽 → 与**巽**为飞伏
+ 二世遁（☶☰）：外乾内艮 → 与**艮**为飞伏
+ 三世否（☷☰）：外乾内坤 → 与**坤**为飞伏

**第三类：四世、五世卦，与本卦之外卦为飞伏**
以坎宫为例：

+ 四世革（☱☲）：外兑内离 → 与**兑**为飞伏
+ 五世丰（☳☲）：外震内离 → 与**震**为飞伏

**第四类：游魂卦，与本宫五世卦之外卦为飞伏**
以巽宫游魂颐（☶☳）为例：巽宫五世卦为噬嗑，噬嗑之外卦为离，故颐与**离**为飞伏。

**第五类：归魂卦，与本宫五世卦之内卦为飞伏**
以艮宫归魂渐（☶☴）为例：艮宫五世卦为履，履之内卦为兑，故渐与**兑**为飞伏。

### 4_3 爻之飞伏与干支对应

飞伏不只论卦，更论爻。以乾宫一世姤为例：姤之下体为巽（飞），初爻辛丑（飞爻）；而其伏爻仍用乾初爻甲子（伏爻）。这就是"姤下体巽飞为巽，初辛丑伏仍用乾初甲子"的真实含义。

> 飞伏的实战价值：当你在某卦中用神不显（如求财却不见妻财爻），就要去查伏神——用神可能"伏"在飞爻之下，只是未显现而已。

## 板块5 · 建候积算：把卦接入时间流

这是《京氏易传》最具特色、却被后世六爻最大化的部分。

### 5_1 建候

每一卦都对应一段起始节气。以乾宫为例：

+ 乾：建子（十一月冬至起）至建巳（四月）
+ 姤：建午（五月）起坤宫初六
+ 遁：建辛未为月
+ 否：建壬申至丁丑（七月立秋至十二月大寒）
+ 观：建癸酉至戊寅
+ 剥：建甲戌至己卯（寒露至春分）
+ 晋（游魂）：建己卯至甲申（春分至立秋）
+ 大有（归魂）：建庚辰至乙酉

### 5_2 积算

"积算起某至某，周而复始"——把干支循环作为吉凶推演的时间轴。例如否卦"积算起丁丑至丙子，周而复始"，晋卦"积算起甲申金至癸未土，周而复始"。

### 5_3 星宿配卦

每一卦还配五星（岁星、荧惑、镇星、太白、太阴）与二十八宿。例如乾卦"五星从位起镇星，参宿从位起壬戌"；姤卦"五星从位起太白，井宿从位入辛丑"。

> 这部分内容在现代六爻中被大幅简化，但在《京氏易传》原典中是核心体例。理解它，才能理解京房为何说"卦以象告，象以数明"。

## 板块6 · 实操手册：拿到一卦，八步装成

下面这套流程，是把《京氏易传》的体例转化为可操作的"装卦 SOP"：

### 6_1 第一步：定内外卦

分出上卦（外卦）、下卦（内卦）。内卦为"我"、为近、为本；外卦为"事"、为远、为末。

### 6_2 第二步：归八宫

+ 若是八纯卦（乾震坎艮坤巽离兑），直接归本宫
+ 否则按"八宫卦表"查表归宫
+ 记忆诀窍：先看下卦是哪一经卦，优先从属下卦本宫；若不是本宫纯卦，按京房爻变逆推，找回本宫宗主卦

### 6_3 第三步：定世次

按"八宫卦表"查该卦是几世卦、游魂还是归魂。

### 6_4 第四步：安世应

按世爻口诀安世爻，与世爻相隔两位安应爻。

### 6_5 第五步：纳干支

按本宫纯卦的纳干支规则，从初爻到上爻依次装入。

### 6_6 第六步：配六亲

以本宫五行"我"，按生克推出父母、子孙、官鬼、妻财、兄弟。

### 6_7 第七步：取飞伏

按飞伏五分类法，确定本卦的飞伏关系。若是用神不显，查伏神补缺。

### 6_8 第八步：接入卦气

按"起月例"确定本卦对应的节气方位，作为判断时机的背景坐标。

## 板块7 · 以乾宫乾卦为例：完整演卦示范

**本卦**：乾为天（䷀）

**1. 归宫**：乾宫本宫卦（八纯）

**2. 世次**：本宫，世在六爻（上九）

**3. 世应**：世在六爻，应在三爻（九三）

**4. 纳干支**：

+ 初九：甲子水
+ 九二：甲寅木
+ 九三：甲辰土
+ 九四：壬午火
+ 九五：壬申金
+ 上九：壬戌土

**5. 六亲**（乾属金）：

+ 初爻子水 → 子孙
+ 二爻寅木 → 妻财
+ 三爻辰土 → 父母
+ 四爻午火 → 官鬼
+ 五爻申金 → 兄弟
+ 上爻戌土 → 父母

**6. 飞伏**：与坤为飞伏。乾纯阳用事，内伏纯阴之坤。

**7. 卦气**：建子（十一月冬至）起，至建巳（四月）极；积算起巳巳火至戊辰土，周而复始。

**8. 星宿**：五星从位起镇星，参宿从位起壬戌。

**9. 居世身份**：宗庙居世（上九为宗庙爻），三公为应（九三）。

这一套下来，乾卦在京氏体系中的全貌就立体呈现了——它不只是"刚健中正"，而是一个**处于子月到巳月、阳气从潜到亢、与坤互为隐显、积算火土循环**的动态能量结构。

## 板块8 · 京氏易学的四层修炼路径

### 8_1 第一层：记诵筑基（1-2 个月）

+ 背熟八宫卦表（六十四卦归宫）
+ 背熟纳干支口诀与六亲推导
+ 背熟世爻定位口诀
+ 每日手写一宫的装卦结果（如乾宫八卦），与原文对照

### 8_2 第二层：读通原典（2-3 个月）

+ 精读《京氏易传》卷上乾宫八卦原文
+ 逐卦对照"建候—积算—星宿—飞伏—六亲"五字段
+ 重点理解：为啥一世卦阴主五月、阳主十一月？为啥游魂"魂魄游离"？为啥归魂"叶落归根"？

### 8_3 第三层：卦气接入（3-4 个月）

+ 把六十四卦与二十四节气—节气—干支循环对接
+ 理解"卦气说"：京房以十二辟卦主十二月，每卦主一节气，每爻主六日八十分日之七
+ 尝试用卦气解释现实节令中的阴阳消长

### 8_4 第四层：飞伏活用（4-6 个月）

+ 练习"用神不显查伏神"的实操
+ 研究游魂、归魂卦的特殊性（游走不定 vs 回归本位）
+ 把京氏原典与后世《增删卜易》对照，看出"源"与"流"的差异

## 板块9 · 常见误区与正误对照

| 误区 | 正解 |
| --- | --- |
| 把《京氏易传》当现代六爻书读 | 京氏重卦气、星象、建候积算，现代六爻只取其八宫世应纳甲六亲飞伏的框架 |
| 以为"飞伏"只是"用神不显查伏神" | 飞伏首先是卦与卦之间的错卦关系，其次才是爻层面的显隐 |
| 忽略"上爻永远不变"的铁律 | 所有卦变只动初至五爻，上爻为宗庙，恒定不动 |
| 把八宫顺序记成"乾兑离震巽坎艮坤" | 京房八宫顺序是"乾震坎艮、坤巽离兑"（乾父率三男、坤母率三女） |
| 以为世应只是"我和他" | 世应本是政治哲学隐喻：宗庙居世反应三公、天子居世反应大夫、诸侯居世反应元士、三公居世反应宗庙 |
| 忽略"天易人易地易鬼易"的分类 | 这是理解卦次与节气、阴阳消长对应关系的关键 |

---

**示例**：把「飞伏」直接当成吉凶结论套用，是误区；飞伏只提示隐显关系，须结合世应与旺衰再断。

## 板块10 · 进阶心法：京氏易学的现代转化

跳出占卜视角，《京氏易传》提供的是一套**时空—能量—结构**三位一体的分析模型：

+ **八宫** = 事物的八个基本场域/类别
+ **爻变** = 事物从本源状态向外演化、再回归本源的完整生命周期
+ **世应** = 主体与客体的互动关系
+ **飞伏** = 显性状态与隐性势能的并存
+ **纳甲** = 给每个节点标注时空坐标（干支）
+ **建候积算** = 把事物演进接入时间轴
+ **六亲** = 把抽象五行关系转化为人伦角色，便于判断

带着这个视角重读《京氏易传》，它不再是一本"晦涩难懂"的占筮书，而是一部**把《周易》从哲学文本转化为可计算模型的奠基之作**。京房的天才之处在于：他发现了"卦"不只是符号，而是可以装载干支、五行、星象、节气的**结构化数据容器**。

> 学《京氏易传》的真正价值，不在于占验准不准，而在于理解**中国古人如何把宇宙节律、社会结构、个体命运压缩进六十四卦的符号系统里**。这套思维方式，至今对我们在复杂系统中做结构化分析仍有启发。

> 记住：八宫顺序是**乾震坎艮、坤巽离兑**，不是先天八卦序，也不是后天八卦序。这是京房依"乾坤生六子"的人伦逻辑重排的。

**示例**：拿到「姤」卦，查本表知属乾宫、一世卦，即可定其世爻在初爻、应爻在四爻。
