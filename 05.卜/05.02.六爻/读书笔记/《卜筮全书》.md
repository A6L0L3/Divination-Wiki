## 板块1 · 关于本书：先定位，再阅读

《卜筮全书》是明代卜筮文化的集大成之作，由姚际隆（字百愚，吴门人）在崇祯年间删补旧本而成，凡例阐明"贵在融通、戒占险渎"，并删削旧刻河洛蓍室诸图，仅存八卦方位图以明八宫分野。书名虽古，实则是**纳甲筮法（俗称"六爻"）从零散口诀走向体系化**的关键节点。

需要说明两点，避免读歪：

+ **作者归属**：书前题"明诚意伯刘基（伯温）先生著"，实为托名，学界与藏书目录均认定为姚际隆辑著、明清术士层层增益的集体成果。谁写的并不重要，重要的是它把前人成果"删芜补秘"整理成了一部可教学的教材。
+ **核心地位**：全书最重者在卷八至卷十三的《黄金策》，而《黄金策》开篇的《总断千金赋》又被后世《卜筮正宗》《增删卜易》反复收录、逐句注解，堪称六爻的"总纲中的总纲"。因此本笔记的重心不在逐卦翻译，而在**提炼这套总纲背后的判断逻辑**。

### 1_1 推荐阅读顺序（反常规，但更高效）

原书按"基础→卦象→理论→歌诀→分类"排布，但学的时候若从头死磕，极易在前两卷的歌诀海洋里劝退。建议按以下顺序：

| 阶段 | 读什么 | 目标 |
| --- | --- | --- |
| 「1」 立骨架 | 卷八《总断千金赋》全文 | 先记住"病药说"一句话 |
| 「2」 打地基 | 卷一《启蒙节要》 | 纳甲、世应、六亲、装卦 |
| 「3」 学招式 | 卷三《通玄妙论》、卷四《阐奥歌章》 | 掌握"无鬼无气""绝处逢生"等单元技法 |
| 「4」 练实战 | 卷五《阐奥歌章》下 + 卷六/七《天玄赋》 | 按求财、婚姻、疾病等专题套用 |
| 「5」 通专题 | 卷九至卷十三《黄金策》分章 | 分领域深化 |
| 「6」 辨边界 | 卷十四《神煞歌例》 | 明白"神煞为辅、生克为主" |

一句话：**先看结论，再补工具，最后练专题**。这与原书"由浅入深"的体例相反，却是学习任何复杂技能的有效路径。

## 板块2 · 全书结构重梳：六层递进，而非十四卷平铺

原书十四卷内容可重构成清晰的六层逻辑，每一层解决一个不同的问题：

```plain
第一层  符号地基（卷一·启蒙节要）
       阴阳 / 五行 / 天干地支 / 八卦 / 六十甲子 / 纳甲 / 世应 / 六亲
                    ↓ 解决"怎么把卦装出来"
第二层  文本依据（卷二·卦爻呈象）
       六十四卦逐卦爻辞 + 纳甲法
                    ↓ 解决"本卦讲什么"
第三层  理论核心（卷三·通玄妙论 + 卷八·千金赋）
       无鬼无气、绝处逢生、合处逢冲、随官入墓……
       以及全书总纲"病药说"
                    ↓ 解决"凭什么这么断"
第四层  歌诀速断（卷四·阐奥歌章）
       《碎金赋》《断易通玄赋》+ 诸爻持世诀、六亲发动歌等
                    ↓ 解决"经验怎么压缩成口诀"
第五层  分类应用（卷五·阐奥下 / 卷六-七·天玄赋 / 卷九-十三·黄金策）
       天时、身命、婚姻、求财、疾病、词讼、出行……二十余专题
                    ↓ 解决"具体事怎么断"
第六层  边界与慎戒（卷十四·神煞歌例 + 全书凡例）
       神煞、长生沐浴、三合成局 + "筮必诚心""断易勿泥神煞"
                    ↓ 解决"什么不可信、什么不能占"

```

**这个重构的价值在于**：原书把"理论、口诀、专题"穿插编排，读者容易把它们当成并列知识一块块背。实际上它们是**不同层级**——理论是纲，口诀是压缩包，专题是应用场景。纲不清，口诀越背越乱；纲一立，口诀自然归位。

---

**用法示例**：按「符号地基→理论核心→歌诀速断→实战流程→应期→专题」六层顺序读，每层解决一个问题，不跳层。

## 板块3 · 第一层：符号地基——装卦不求人

六爻的"语言"由五套符号叠加而成。这一层不追求理解，追求**熟练到自动化**。

### 3_1 五要素速查

| 要素 | 含义 | 速记 |
| --- | --- | --- |
| 阴阳 | 爻的两种状态：—（阳）、--（阴） | 三爻成卦 |
| 五行 | 金木水火土生克 | 相生：金→水→木→火→土→金；相克隔一 |
| 天干地支 | 纳甲的基础 | 干支配六十甲子 |
| 八卦（八宫） | 乾兑离震巽坎艮坤，分属五行 | 乾兑金、震巽木、坎水、离火、艮坤土 |
| 六亲 | 以"我"（卦宫五行）为基准推导 | 见下 |

**六亲定位**——全书最常用的抓手，务必背熟：

```plain
生我者   → 父母    （文书、长辈、学业、房屋、车辆）
我生者   → 子孙    （晚辈、下属、福气、医药、娱乐）
克我者   → 官鬼    （事业、功名、灾祸、疾病、盗贼）
我克者   → 妻财    （财运、妻子、财物）
比和者   → 兄弟    （同辈、朋友、竞争、破财）

```

> **拓展干货（网络教程高频强调）**：六亲是**相对"卦宫"而言**，不是相对摇卦人。同一爻在不同卦宫里六亲不同——这是新手最容易踩的坑。装卦时先定卦宫，再定六亲，顺序不能反。

### 3_2 以钱代蓍：起卦实操

原书保留了"以钱代蓍法"，即用三枚铜钱摇六次成卦，这是从《周易》蓍草法简化而来的关键革新：

```plain
每摇一次：
  3 正（背） → 老阳（○，阳动，变爻）
  3 背      → 老阴（X，阴动，变爻）
  2 正 1 背 → 少阳（—，静爻）
  2 背 1 正 → 少阴（--，静爻）

从初爻（最下）到上爻（最上），摇六次，得一卦 + 若干动爻。
动爻阴变阳、阳变阴 → 得到"变卦"。

```

**可落地要点**：

+ 自下而上记录，**初爻在下、上爻在上**，别记反；
+ 只有"老阴、老阳"才动，**动爻是断卦的灵魂**（"动为始，变为终"）；
+ 现代可直接用排盘工具，但**初学者应手装 10–20 卦**，以理解纳甲、世应、六亲的生成逻辑——跳过低层，后面永远似懂非懂。

### 3_3 纳甲与世应：给卦"装上零件"

原书卷一列有大量歌诀（纳甲歌、安放世应歌、飞伏神歌、游魂归魂歌等）。核心是：

+ **纳甲**：把十天干十二地支装入八卦六爻，使每个爻都带"地支"，从而能谈生克冲合；
+ **世应**：每卦有固定的"世爻"（求测者/我）与"应爻"（对方/事/环境）。歌诀"八纯世位，归魂游魂"可查表记忆；
+ **飞伏**：用神不上卦（伏藏）时，到本宫八纯卦里找，伏者为"伏神"，本位之爻为"飞神"。

> **干货提示**：世应口诀不必死背，排盘软件会自动标注。**真正要练的是"看到世应后，立刻能说出谁代表谁"**——这是后面所有分析的定位前提。

## 板块4 · 第二层：理论核心——《千金赋》与"病药说"

这是全书的灵魂。理解了它，后面所有歌诀和专题都只是它的展开。

### 4_1 一句话总纲

> **"天机尽泄于有病之间，断法总在于医药之处。"**

这句话被后世奉为六爻第一义。翻译成白话：

**卦象的玄机，全部藏在"有病"的地方；断卦的方法，全部落在"找药"的动作上。**

所谓"病"，是卦中不和谐、导致凶险的关键矛盾——用神衰败、被忌神动克、逢月破日冲等；所谓"药"，是能化解这矛盾、化凶为吉的因素——原神发动生扶、忌神被制服、用神逢合解冲等。

于是断卦流程被压缩成三步：**寻病 → 查药 → 定吉凶**。

| 组合 | 结论 |
| --- | --- |
| 有"病" 无"药" | 凶，无解 |
| 有"病" 有"药" | 先凶后吉 / 无妨（救得过来） |
| "病"重 "药"轻 | 坎坷，勉强 |
| "病"轻 "药"重 | 顺利，过度 |

**这就是全书最高效的思维模型：把"吉凶判断"转化为"矛盾识别 + 资源匹配"。** 它本质上是一种**辩证思维**，反对死板教条——这也是《卜筮全书》高于一般占筮书的根本原因。

### 4_2 《千金赋》纲领逐条拆解

《总断千金赋》全文虽仅数百字，却浓缩了全部断卦法则。下面摘录并解析其中最关键的十余句（原文据《卜筮正宗》本，维基文库有全文载录）：

#### 4_2_1 「1」 总起：一理融贯

> **"动静阴阳，反复迁变。虽万象之纷纭，须一理而融贯。"**

万象虽多，只凭"阴阳动静生克制化"这一条理贯通。**寓意：先抓主线索，别被细节带跑。**

> **"夫人有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。"**

卦和人一样，有过与不及两种偏失。**太旺要损、太弱要补**——这正是"病药说"的中道基础，也是应期的逻辑起点（太旺逢墓、衰弱逢旺）。

#### 4_2_2 「2」 旺衰：生扶 vs 克害

> **"生扶拱合，时雨滋苗。克害刑冲，秋霜杀草。"**

四组吉、四组凶。"拱、合"是暗中相助，"刑、冲"比普通克害更烈。**记忆锚点：吉的都带"生"，凶的都带"克"。**

> **"长生帝旺，争如金谷之园。死墓绝空，乃是泥犁之地。"**

十二长生诀（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）是判断爻之能量的精细刻度。**用神临长生、帝旺则吉；临死、墓、绝、空则凶。**

#### 4_2_3 「3」 日月建：权力的分工（重点，易混淆）

> **"日辰为六爻之主宰……月建乃万卦之提纲。"**

这是断卦的**第一优先级**，务必分清：

|  | 月建 | 日辰 |
| --- | --- | --- |
| 比喻 | 皇帝（掌一月之权） | 宰相（掌一日之权） |
| 作用 | 定旺衰、定**月破** | 生克冲合、定**旬空** |
| 口诀 | "爻得月建为苗壮" | "爻得日辰为根重" |

+ **月建**：衡量爻的旺相休囚，爻临月建或得月生扶为旺；爻被月建冲克为"月破"（最严重的衰）。
+ **日辰**：影响力仅次于月建，**能冲起静爻、能克制动爻、能合住动爻**，所谓"日辰为六爻之主宰"。

> **"爻伤日，徒受其名；日伤爻，真罹其祸。"** ——爻去克日辰（等于凡人冲撞皇帝），有名无实；日辰来伤爻，才是真灾。这条常被忽略，却是判断"凶到什么程度"的关键。

> **关键辨析（网络教程普遍强调）**：月建主"旺衰与时长"（如占病，官鬼临月建病缠一月以上），日辰主"当下与一日之吉凶"（临日辰多为突发、近事）。**先论月建定级别，再论日辰定快慢。**

#### 4_2_4 「4」 世应：主客定位

> **"世为己，应为人，大宜契合。动为始，变为终，最怕交争。"**

+ **世爻 = 我（求测者）**，**应爻 = 对方 / 事 / 环境**；
+ 世应相生相合 → 事易成；相克刑冲 → 艰难；
+ **动爻 = 事之开始，变爻 = 事之结局**，"最怕交争"指变爻回头克动爻（如主事爻临子水动、变出未土来克我），纵用神旺相也难称心。

> **"应位遭伤，不利他人之事；世爻受制，岂宜自己之谋。"**——代占以应为主，自占以世为主。这条解决了"谁受伤对谁不利"的定位问题。

> **"世应俱空，人无准实。"**——双方皆无诚意，谋事必有阻节；安静卦中世应空合，多为"失约无诚信"。

#### 4_2_5 「5」 用神：主事之爻

> **"用爻有气无他故，所作皆成；主象徒存更被伤，凡谋不遂。"**

用爻（主事爻）即按占事取定的六亲：占文书取父母、求财取妻财、求官取官鬼、占子息取子孙。**用神有气又无他爻克害，为上吉；用神无气又被日辰动爻克害，为大凶。**

> **"有伤须救。"**——用神受克（如用临申金被午火动克），若有日辰"未"合住午、或"子"冲散午、或"亥"制伏午，即为有救。这正是"药"的具体表现形式。

#### 4_2_6 「6」 空、合、墓：三种特殊状态

| 原文 | 含义 |
| --- | --- |
| "无故勿空；空逢冲而有用" | 用神不宜无故落空；空爻被日辰冲 → 空而有用 |
| "合遭破以无功" | 合局被破 → 白搭 |
| "动值合而绊住" | 动爻被合 → 被绊住，事不成 |
| "静得冲而暗兴" | 静爻得日辰冲 → 暗中发动 |
| "入墓难克；带旺匪空" | 爻入墓则难被克；旺相则不真空 |
| "贪生贪合，刑冲克害皆忘" | 有"生、合"可贪时，刑冲克害暂时失效 |

> **"并不并，冲不冲，因多字眼；刑非刑，合非合，为少支神。"**——字面是并/冲/刑/合，实际要看地支是否齐全（如三合缺一、六冲不成），**不可见字面就断**。这是防止"教条断卦"的醒脑句。

#### 4_2_7 「7」 伏神与飞神

> **"伏居空地，事与愿违。伏无提拔终徒尔，飞不推开亦枉然。"**

用神不上卦（伏藏），需有"提拔"（值日、冲飞神、临月建）才能起作用；飞神（伏神之上本位的爻）不推开，伏神终无用。**"空下伏神，易于引拔"**——伏神居于旬空之爻下，反而容易引拔出来。

#### 4_2_8 「8」 特殊格局收束

> **"墓中人，不冲不发；身上鬼，不去不安。"**——用神入墓，须待冲墓之日方发；官鬼持世（身上鬼），不去之不安宁。
>
> **"用爻变动，忌遭死墓绝空。"**——用神动而化出死、墓、绝、空，是转吉为凶的大忌。
>
> **"动逢冲而事散，绝逢生而事成。"**——动爻逢冲则散（事不成），用神绝处逢生则成。

### 4_3 角色关系图：原神·忌神·仇神

这是"病药说"的角色化表达，分析卦象的基石：

```plain
        仇神
        ↑ 生
    忌神        原神
        ↑ 克       ↑ 生
        用神 ←──────────（所求之事）
        ↑ 代表
      占问的人/事/物

```

| 角色 | 定义 | 举例（用神＝妻财土） |
| --- | --- | --- |
| 用神 | 所占总的人/事/物 | 妻财土 |
| 原神 | 生用神者（助力、根源） | 火（火生土） |
| 忌神 | 克用神者（阻力、敌人） | 木（木克土） |
| 仇神 | 生忌神者（帮凶） | 水（水生木） |

**实战含义**：判断一件事，先锁定用神，再看"谁帮它（原神）、谁克它（忌神）、谁帮敌人（仇神）"，整件事的力量对比一目了然。**这正是"病药说"的量化版。**

### 4_4 生克制化中的两个"优先权"（易错点）

+ **贪生忘克**：A 既能生 B 又能克 C，若 B 出现，A 会优先去生 B，而"忘了"克 C。这是"药"起作用的一种典型形式。
+ **贪合忘生 / 贪合忘克**：合的优先级极高，一旦成合，生克暂时让位。

> **警示**：这两条是"有条件的例外"，不是普遍规则。判断顺序应是：**先看合冲，再看生克，最后看刑害**——对应《千金赋》"别衰旺以明克合，辨动静以定刑冲"。

## 板块5 · 第三层：歌诀速断——把经验压缩成口诀

卷四《阐奥歌章》把上述理论编成便于背诵的歌诀。这里提炼最有实战价值的三组（均出自原书）：

### 5_1 诸爻持世诀（世爻是何六亲）

| 持世 | 含义 | 宜 | 忌 |
| --- | --- | --- | --- |
| 父母持世 | 辛苦劳碌 | 求名、求官 | 求财（消耗） |
| 官鬼持世 | 事难安 | 求名、官司 | 占病、平常事 |
| 妻财持世 | 主财 | 求财 | 占身防健康、求名需财动 |
| 子孙持世 | 无忧 | 避祸、享乐 | 求名（克制官鬼） |
| 兄弟持世 | 竞争 | 助身 | 求财（破财） |

### 5_2 六亲发动诀（动爻是何六亲）

| 发动 | 核心信号 |
| --- | --- |
| 父母动 | 文书、消息、辛劳、房屋变动 |
| 官鬼动 | 事业、功名、灾祸、疾病 |
| 妻财动 | 财运、资金流动、求财方向 |
| 子孙动 | 无忧、解忧、医药、生财 |
| 兄弟动 | 竞争、破财、同辈介入 |

**拓展（网络教程高频补充的"化出"判断）**：

```plain
财动化子 → 投资有回报，财源滚滚
财动化官 → 花钱消灾（钱用来解决问题）
财动化兄 → 破财，钱被分走
子动化财 → 靠创意、技术生财（最吉组合）
子动化官 → 乐极生悲，玩乐惹麻烦
官动化子 → 忧患得解（病得药）

```

> **要点**：动爻的"化出"比动爻本身更能说明**事情的最终走向**，这是"动为始、变为终"的直接应用。

### 5_3 用神取舍的优先级（网络教程精华，原书分散各处）

当卦中出现多个同类爻（如两个妻财）时，按此顺序定用神：

```plain
「1」 动爻优先（发动者最能代表事态）
「2」 临世应者优先（与求测者/对方直接相关）
「3」 临月建/日辰者优先（得时旺者为主）
「4」 旺相者优先（能量强者为主）
「5」 上卦（外卦）优先于下卦（近事取外）
「6」 无上述差别时，取离世爻近者

```

> **反例警示**：初学者常"哪个爻吉利就取哪个"，这是大忌。**用神一旦取错，全盘皆错**——断卦的第一步不是看吉凶，而是确认用神。

## 板块6 · 第四层：实战流程——九步断一卦

把前面所有知识整合成一套**可直接对照卦盘执行的流程**。建议打印出来，每卦照走一遍。

```plain
┌─────────────────────────────────────────┐
│  Step 0  起卦 · 诚心、专注、一卦一问      │
│  Step 1  装卦 · 纳甲、定世应、布六亲      │
│  Step 2  定问题 · 把占问写成一句话        │
│  Step 3  取用神 · 按六亲 + 优先级         │
│  Step 4  看旺衰 · 月建 → 日辰 → 十二长生  │
│  Step 5  察动变 · 动爻、变爻、回头生克    │
│  Step 6  看世应 · 主客、动静、是否契合    │
│  Step 7  理路线 · 找"病"、找"药"、量药力 │
│  Step 8  判吉凶 + 定应期                 │
└─────────────────────────────────────────┘

```

**逐步说明与常见错误**：

+ **Step 0**：一卦只问一事，问题越具体越好（"这个月能否谈成 A 客户的单"优于"我财运如何"）。原书凡例强调"筮必诚心"，实则是**排除杂念以保证问题清晰**——这比迷信层面更重要。
+ **Step 1**：用排盘工具可省去手工装卦，但需**核对世应、六亲是否正确**，避免工具误判卦宫。
+ **Step 2**：**写下来**。这一步逼着你区分"想要的答案"和"真正的问题"，是防止事后附会的关键。
+ **Step 3–5**：按"用神 → 旺衰 → 动变"顺序，**先静态后动态**。
+ **Step 6**：世应相对独立，是"关系维度"的补充校验。
+ **Step 7**：这是全书的灵魂一步，详见下一节。
+ **Step 8**：吉凶与应期分开判断——**先断成不成，再断什么时候**。

### 6_1 关键心法：Step 7 的"病药"四问

走到这一步，面对一张复杂的卦，用四个问题收束：

1. **病在哪？** 用神是否衰弱？是否被忌神动克？是否逢月破、旬空、入墓、绝处？
2. **药在哪？** 有无原神发动生扶？忌神是否被制服（克、冲、合、入墓）？用神是否逢合解冲？
3. **药力够不够？** 药（原神）本身旺不旺？是得月生还是仅靠日辰？药力与被克程度相比如何？
4. **有无"回头"？** 动爻化出的变爻是回头生（吉）还是回头克（凶）？用神化进神（吉）还是退神（凶）？

> **口诀收束**（网络教程通行版）：

_一看空，二看冲，三看刑合衰旺中；四看化出进退死，五看神煞凶不凶；六看用爻之位置，七看伏神出牢笼；八看反伏吟流泪，九看外应十观容。_

这十条是"检查清单"，用于**查漏**，而非断卦顺序。建议在 Step 7 之后照此过一遍，确保没有遗漏。

## 板块7 · 第五层：应期——"断准吉凶易，断准应期难"

原书与后世口诀都把"定应期"视为最难的部分。其核心逻辑其实仍来自病药说：**用神若有病，治好病的那一刻即为应期；若无病，则按"冲、合、值、空、墓"的对应关系推导**。

### 7_1 总纲口诀

> **"动待合，静待冲；衰待旺，旺待墓；冲待合，合待冲；空待出，墓待破；伏待引，吟待冲。"**
>
> **"静而逢值逢冲，动而逢合逢值。太旺者逢墓逢冲，衰绝者遇生遇旺。"**

### 7_2 应期速查表（近应日时、远应年月）

| 用神状态 | 应期 |
| --- | --- |
| 用神旺相不动 | 逢 **值** 之日（用神地支当值） |
| 用神休囚发动 | 逢 **旺** 之日（得生扶之月日） |
| 用神月破 | **出月** 填实 / 逢合之日 |
| 用神旬空 | **出空**（出旬）之日 |
| 用神被合 | 逢 **冲** 之日（冲开合爻） |
| 用神逢冲 | 逢 **合** 之日 |
| 用神伏藏 | **引拔** 之日（出现 / 冲飞神 / 合日） |
| 用神入墓 | 逢 **冲墓** 之日 |
| 用旺静 | 逢 **冲** 之日（冲起） |
| 用休囚 | 逢 **生旺** 之期 |
| 化进神 | 逢值、逢合 |
| 化退神 | 忌值、忌冲 |

**实战案例**（据网络教程体例改编）：

+ **问求职**（官鬼为用）：官鬼午火动 → 应期在 **午日**（逢值）或 **子日**（冲午）；
+ **问合作**（应爻为对方）：兄弟爻动主竞争 → 兄爻值日之期见分晓；
+ **用神卯木静旺**：应期在 **卯日/卯月**（逢值），或 **酉日**（逢冲）。

> **进阶心法**（网络教程普遍强调）：
>
> + **日月齐来生扶用神**（如月建生 + 日辰生）→ 危重亦可转机；
> + **日月同克用神** → 大势已去；
> + **吉凶定方向，应期定时点**：先确定"成不成"，再用上表找"何时"。顺序颠倒极易出错。

## 板块8 · 第六层：专题应用——以"疾病占"为例的完整示范

原书卷五、卷十有大量专题（天时、身命、婚姻、求财、疾病、词讼、出行等），限于篇幅，这里以最具方法论代表性的**疾病占**做完整示范，其余专题可依同样框架迁移。

### 8_1 疾病占的角色设定

| 卦中角色 | 对应 |
| --- | --- |
| 世爻 / 用神（病人本体） | 患者 |
| **官鬼** | **病根、病灶**（致病之源） |
| **子孙** | **药神**（医药、方案、自愈力） |
| 父母 | 医院、文书处方 |
| 妻财 | 饮食、营养 |
| 兄弟 | 耗损、反复 |

**核心法则**：**官鬼为病，子孙为药**——这本身就是"病药说"在疾病领域的最直接映射。

### 8_2 断病三步

**第一步：定病位**（官鬼所临五行 + 爻位）

| 官鬼临 | 常见指向 |
| --- | --- |
| 木 | 肝胆、神经、筋骨 |
| 火 | 心脑血管、炎症、发热 |
| 土 | 脾胃、消化、浮肿 |
| 金 | 肺、呼吸、皮肤 |
| 水 | 肾、泌尿、血液 |

爻位亦可参考：初爻为足、二爻为胫股、三爻为腹、四爻为胸、五爻为颈面、上爻为头。

**第二步：量病势**（官鬼旺衰）

+ 官鬼旺相发动 → 病势重；临月建（病缠一月以上）、临日辰（突发急病）更重；
+ 官鬼化进神、化长生 → 加重；化退、化空、化破、化绝、化回头克 → 减轻；
+ 官鬼两重夹世爻 → 病重，多凶。

**第三步：看药效**（子孙力量对比）

+ 子孙旺相发动 → 药到病除；得日辰月建生扶 → 疗效显著；
+ 子孙化进神 / 化回头生 → 药效持续增强；
+ 子孙衰弱伏藏 → 药力不济，需换药或另寻方案；
+ **子孙与官鬼力量相当 → "病药相持"**，须看卦中其他组合定吉凶。

### 8_3 完整卦例（据网络教程体例整理）

> **背景**：申月丙辰日，占母疾。得"地风升"变"水风井"。
>
> **解析**：
>
> + 官鬼酉金 **临月建**（申月，金旺）→ 病势深重，病根深固；
> + 子孙午火发动克鬼（有"药"）→ 看似可救；
> + 但午火在 **申月休囚**（火于申月不得令）→ **药力不足**；
>
> **结论**：**病重药轻** → 需加大剂量或更换名医。

**反馈**：初治无效，转院后得愈。——与"药力不足、需增强"的判断吻合。

**这个卦例的方法论价值**：它展示了"病药说"的**量化思维**——不是"有药就好"，而是**比较病与药的相对力量**。这正是全书最值得提取的干货。

### 8_4 其他专题的一句话入口（迁移框架）

| 专题 | 用神 | 关键看 |
| --- | --- | --- |
| 求财 | 妻财 | 财爻旺衰 + 子孙（财源） |
| 婚姻 | 男看妻财 / 女看官鬼 | 世应是否契合、有无刑冲 |
| 求名/仕途 | 官鬼 | 官鬼旺衰、父母（文书） |
| 出行 | 世爻 + 应爻 | 世爻安否、途中忌神 |
| 词讼 | 世应 + 官鬼 | 谁受伤、有无贵人 |
| 失物 | 用神（物对应六亲） | 伏藏否、何方 |

**规律**：所有专题都遵循"**取用神 → 看旺衰 → 找病药 → 定应期**"同一套流程，区别只在**用神选取**。这就是体系化教材的价值——学会一个，通吃全部。

## 板块9 · 进阶辨析：三个最容易踩的坑

### 9_1 坑一：反吟 / 伏吟的"内外卦"区分

很多教程笼统说"反吟主反复、伏吟主呻吟"，其实要分清层级：

| 类型 | 定义 | 主 |
| --- | --- | --- |
| 爻反吟 | 动爻与变爻地支相冲 | 该爻所主之事反复 |
| 卦宫反吟 | 上下卦宫相冲（乾巽、震兑、艮坤、离坎） | 格局动荡、内外不宁 |

+ **反吟**：事"成而败、败而成，得而失、失而得"，**不等于必凶**——关键看动变对世/用是生还是克；
+ **伏吟**：爻与变爻地支相同，主"忧虑、呻吟、进退两难、停滞"；
+ **缓解因素**：三合、六合可缓解反吟冲击；空亡常使反复延迟或减弱。

**应期**：动爻与相冲地支值日/月/年应之；伏吟以"冲"之日月应。

### 9_2 坑二：真假空亡的判断

不是所有"空"都一样：

+ **用神空**：所求虚幻、对方无诚意、事终落空 → 多凶；
+ **忌神空**：灾祸落空、克害不成 → **反而是吉**；
+ **带旺匪空**：旺相之爻逢空，**不真空**，力量仍在；
+ **空逢冲而有用**：空爻被日辰冲 → 激发有用；
+ **自空化空**：用神自空又化空 → 必成凶咎。

> **口诀**：_空分喜忌——空忌神吉，空用神凶；旺不为空，动不为空，日辰冲之不为空。_

### 9_3 坑三："神煞为辅，生克为主"

原书卷十四集中讲神煞（天乙贵人、三刑、六冲、六合、三合成局、长生沐浴等），历代注家又不断叠加。**《阐奥歌章》里专门有一首《断易勿泥神煞歌》**——书名本身就提示：**不要泥于神煞**。

> **《千金赋》结句点题**：_"是故吉凶神煞之多端，何如生克制化之一理。"_

**正确态度**：神煞作辅助参考（如天喜临病、往亡临出行），**最终吉凶一律回归"生克制化 + 病药"**。凡是只靠神煞断吉凶的，基本都不可靠。

---

**示例**：见「反吟」即断「事必反复」，却不分是卦反吟还是爻反吟，正是第一个坑。

## 板块10 · 批判性思考：这套东西到底能信多少？

读书笔记若只讲"怎么用"，不讲"边界在哪"，是不负责任的。这里给出四个必须清醒认识的点：

### 10_1 「1」 "病药说"是思维模型，不是神秘力量

剥离"爻、卦"的外壳，"病药说"其实就是：**识别系统的主要矛盾 → 寻找能解决矛盾的资源 → 评估资源是否足够**。这是通用的决策分析框架，其价值在于**强迫你结构化地看问题**，而非预测未来的准确率。

### 10_2 「2」 占验记录存在严重的"幸存者偏差"

古籍中的"应验"案例，本质是**选择性记录**：说中的留下，没说中的不写。加上卦象的模糊性（一卦多解），事后总能找到解释。**任何声称"准确率极高"的说法，都应视为营销而非事实。**

### 10_3 「3」 "重理轻象"是把双刃剑

《黄金策》侧重五行生克制化的"理"，而非《周易》古经的卦象爻辞。这使体系更整齐、更易教学，但也**牺牲了《周易》象思维的开放性**。若想更深，建议回头补读《周易》本经。

### 10_4 「4」 绝对边界：不可替代专业判断

+ **医疗**：卦象可辅助梳理思路，但**诊断与用药必须交给医生**；
+ **法律**：决策可参考，**行为须合规、咨询专业律师**；
+ **重大决策**（投资、婚育、职业）：卦象最多作为**多视角之一**，最终责任在自己；
+ **凡涉及人身安全、违法违规，一律以现实规则为准**。

> **原书的自我约束值得尊重**：凡例明确"戒占险渎"，即**不占险恶、不渎神明**。翻译成现代语就是——**不用来做有害、越界、逃避责任的事**。这条比任何技法都重要。

## 板块11 · 可迁移的思维模型：去掉"爻卦"外壳的万能四件套

把全书提炼为四个可在任何决策场景复用的模型：

### 11_1 模型一 · 病药分析器（核心）

```plain
现状 → 找主要矛盾（病）→ 找可用资源（药）
       → 评估资源强度 → 判断能否化解 → 定方案

```

**适用**：项目管理、个人困境、关系修复、商业决策。

### 11_2 模型二 · 旺衰能量审计

对每个关键因素问：它**得不得时、有没有助力、是否被克害、处于生旺还是墓绝**？
**适用**：评估一个想法/产品/关系的"生命力"。

### 11_3 模型三 · 主客动静定位

+ **主（世）**：我方目标与立场；
+ **客（应）**：对方/环境；
+ **动**：正在变化的变量；
+ **静**：稳定的前提。
**适用**：谈判、竞合、任何涉及"我与他"的场景。

### 11_4 模型四 · 先框架后细节（"勿泥神煞"）

先建整体结构（用神、旺衰、病药），再看辅助细节（神煞、六神、爻位）。**细节不能推翻框架，框架必须用细节校验**——这是防"只见树木不见森林"的通用原则。

### 11_5 收束六问（每次决策前自问）

1. 我到底在问什么？（**一卦一问，写下来**）
2. 谁是"用神"？（核心变量是谁？）
3. 它旺还是衰？（得时？有援？被克？）
4. "病"在哪？（主要矛盾是什么？）
5. "药"在哪、够不够？（资源是否足以化解？）
6. 什么时候见分晓？（时间节点 / 验证条件）

---

**示例**：把「用神—忌神」换成「核心指标—风险因素」，即可用于项目决策，壳换了、理不变。

## 板块13 · 结语：这本书真正的价值

《卜筮全书》的价值，不在于它"算得准"，而在于它用一套高度结构化的语言，逼着使用者做到三件事：

1. **把模糊的焦虑，翻译成清晰的问题**（一卦一问、取用神）；
2. **把复杂的局面，拆成可分析的角色与力量**（六亲、世应、原神忌神仇神）；
3. **把"吉凶"从静态结论，变成动态的"矛盾 + 资源"判断**（病药说、旺衰、应期）。

它的方法论内核——**中道（太过者损、不及者益）、辩证（活泼泼地，勿泥教条）、结构化（先框架后细节）**——是剥离时代外衣后依然成立的智慧。

而它的边界也同样清晰：**任何工具都不该替你承担判断与责任**。诚心发问、理性验证、勇敢承担——这或许才是"筮必诚心"在今天的真正含义。

---

**用法示例**：全书读完，回看那句「病药说」——任何一卦先找「病」再找「药」，即是把书读薄的那根线。
