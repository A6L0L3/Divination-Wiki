# 郭璞《洞林秘诀》演卦全书：从卦名、来意到飞伏、升降、六神与应期的完整占断链路

> **本书定位**：《洞林秘诀》并非一本完整传世的"原书"，而是后人从郭璞《洞林》（一名《易洞林》《郭氏洞林》《周易洞林》）佚文，以及《断易天机》《卜筮全书》等后世六爻典籍的引文中，逐步辑录、重构而成的一套占断体系。郭璞（276—324），字景纯，河东闻喜人，《晋书》称其得《青囊中书》九卷，遂洞五行、天文、卜筮之术，"虽京房、管辂不能过也"。
>
> 原书《洞林》三卷，摹仿古易《连山》而作，收录郭璞生平筮验六十余事，原书早佚。今存者主要为：《玉函山房辑佚书》等辑佚本、《断易天机》引文、明代丁丑抄本《洞林决》，以及散见于《太平御览》《太平广记》《初学记》等古籍中的筮例残文。
>
> 本书所做的，不是"还原郭璞原貌"——这已不可能——而是**以现存《洞林秘诀》体系为骨架，以《断易天机》初辑本所收口诀为正文，融合现代六爻教程的实操补丁，重构成一条从起卦到应期的、可直接上手的完整占断链路**。凡属后世引申、教学性补充的内容，均在文中明确标注，不伪托为郭璞原文。
>
> **阅读路径建议**：先通读第一部分"源流正名"，再精读第二部分"五把钥匙"与第三部分"演卦九步法"，然后按第五部分五大场景逐章操练，最后回到第四部分郭璞筮例，体会"五法合一"的占断艺术。口诀全文统一收录于卷末附录，便于背诵。

## 板块1 · 卷首 · 凡例与源流

### 1_1 先正名：你读的从来不是"一本完整的书"

动手演卦之前，必须先认清三个事实，否则会被各种"全集""秘本"误导，把辑本当原书、把引申当口诀。

**（一）原书已佚，今见皆为辑本**

郭璞《洞林》原为三卷，《崇文书目》存一卷，载二十二事。元代胡一桂《周易启蒙翼传》曾从王楚翁处得古抄本，收录最多；
朱震《易丛说》亦引之。至清代，马国翰《玉函山房辑佚书》从《太平御览》《初学记》《艺文类聚》《太平广记》等类书中辑出一部分，加上《断易天机》《卜筮全书》等后世六爻典籍的托名引文，构成了今天能看到的"《洞林秘诀》体系"。
现代心一堂又据嫏嬛馆补校本辑为《易洞林》（三卷，附《补遗》一卷），比《周易洞林》收录更晚、内容更丰，但其性质同样是辑录本，而非郭璞原本。

**（二）现存内容分两条线**

第一条是**卦例线**：保存下来的郭璞本人筮验，如"贲之豫"占嫂病、"晋之剥"占妇梦、"大过之升"占顾球娣、"随卦之升"占行军等，体现"卦象 + 纳甲 + 升降 + 飞伏 + 救应"的综合用法。这些筮例多为三言、四言、七言的韵语，体制大略与焦赣《易林》相似，所谓"林者，自为韵语占卜之辞"。

第二条是**口诀线**：后世六爻书托名或引述的《洞林秘诀》口诀，包括"说来意""过去未来""来情""何知章""期日诀""潜虚诀""统惠诀""六神赋"等。这部分是《洞林秘诀》区别于郭璞原书的主要增量，也是它能被直接用于实操的关键——郭璞原书只记事验，不系统讲方法；方法部分主要由后世实战派补全。

**（三）明代抄本另成系统**

明正德十二年（1517）或万历五年（1577）的丁丑抄本《洞林决》，与《卜筮全书》《断易天机》等同期流传，内容互有增减。这说明《洞林秘诀》在传播中不断被六爻实战派吸收、改写、增补，并非静态文本。因此本书的重构，本质上是在延续这一传统，而非篡改它。

> **凡例三则**

一、凡属郭璞原书或古籍可考的筮例正文，一律以仿宋体或引用块标出，并注明出处，不作改写。
二、凡属《断易天机》初辑本所收口诀（说来意、来情、何知章、期日诀、六神赋、潜虚诀、统惠诀等），以"诀曰"引出，视为体系正传。
三、凡属现代六爻教程的引申与教学性补充，冠以"实操补丁"，明示其为后学发挥，不伪托古人。

### 1_2 本书的逻辑主线：六条线串成一条链

《洞林秘诀》真正的价值，不在某句口诀本身，而在于它提供了一套**从卦名到应期的完整占断链路**。本书将其拆为六条主线，并设计为可操作的先后顺序：

| 顺序 | 主线 | 回答的问题 | 对应的钥匙 |
| --- | --- | --- | --- |
| 1 | **卦名** | 这件事总体上是什么性质、什么走向？ | 定性 |
| 2 | **来意** | 来人究竟想问什么？ | 取问 |
| 3 | **飞伏** | 显象之下隐藏着什么？ | 表里 |
| 4 | **升降** | 事情在往上走还是往下走？ | 趋势 |
| 5 | **六神** | 具体属于哪一类事象（口舌、财物、疾病、盗贼）？ | 细节 |
| 6 | **应期** | 关键节点在什么时日？ | 时间 |

六条主线必须**贯通使用**，只学其一不得其门。现代六爻往往跳过卦名直接看世应六亲，这是丢掉《洞林秘诀》最精华的部分。卦名是"天意的总括"，世应是"人事的分疏"，二者必须合参。

## 板块2 · 核心方法论：五把钥匙

郭璞占法不同于后世纯六爻的最大特点，是**多法并用**：卦名、升降、飞伏、六神、应期，缺一不可。本卷逐把讲透，并给出可落地的判定规则。

### 2_1 钥匙一：卦名为先

《断易天机》引《洞林秘诀》云："**第一先看卦名义**"。这是郭璞占法的首要铁律——起卦先观卦名、卦义，再论世应六亲。

理由在于：卦名是起卦那一刻"天意的总括"，是对整件事的最高层定性；世应六亲则是人事层面的分疏。先看卦名，是先把 compass（罗盘方向）定住，再看细节。

**实战判定示例（占诉讼）**：

+ 遇**大壮**，父母爻持世 → 我方有理，对方不赢
+ 遇**明夷** → 有囚禁之忧
+ 遇**讼**卦 → 圣人经言"讼中吉"，争之不足、谦有余，宜退不宜进
+ 遇**泰、节、咸、恒** → 占婚姻永遂通
+ 遇**游魂、八纯** → 占婚姻主再嫁娶；占家宅主离乡、人丁孤寒

> **要点**：卦名判定须与世应六亲合参，不可单凭卦名定吉凶。卦名定"性质"，世应定"谁胜"，二者叠加才有结论。

### 2_2 钥匙二：升降爻法

"**卦名升降先知得**"（见《初辑本·家宅章》）。升降是郭璞从京房那里继承并发展的独特技法，用于判断事物的上升或下降趋势。

**升降的定义**：

+ **升阳**：阳爻居阳位、阴爻居阴位（得位），或动爻由下往上推进
+ **升阴**：阴爻居阳位、阳爻居阴位（失位），或动爻由上往下退

**核心判定（占家宅）**：

| 所占 | 喜 | 忌 |
| --- | --- | --- |
| 阳宅（活人居） | 升阳，主进文人、家运上升 | 升阴、失度 |
| 阴宅（葬地） | 内生外（内卦生外卦），为上吉 | 升阳（"阴失所"），主凶 |
| 游魂卦 | ——（纵吉亦主离乡发福） | 不离乡不得力 |
| 归魂卦 | ——（虽吉） | 有伤残之象 |
| 八纯卦 | 唯乾位贵堪迁，坤卦尚可 | 多主迁峰岭、人丁孤寒 |

**八卦各定年数（内生外之应期与应象）**：

| 卦 | 年限与所进 |
| --- | --- |
| 乾 | 六年进妙马、文章贵人 |
| 坎 | 一年进妙猪，六年进文人 |
| 艮 | 八年进好狗、厚富人才 |
| 震 | 三年进好马、声誉高人 |
| 巽 | 四年进美女，久远进大位 |
| 坤 | 二年进好马、奇异文章，后进贵人 |
| 兑 | 十年内金玉奇祥、生贵女三公 |

### 2_3 钥匙三：飞伏为魂

"**六爻皆有飞伏神，世下一爻为最要**"。这是《洞林秘诀》最具特色的技法，也是它区别于后世纯世应六亲断法的核心。

**飞伏的本质**：

+ **飞** = 显现于外的爻（有形必有影，世上一片景象皆是飞）
+ **伏** = 隐藏其下的对立面（鬼神无形之事、隐形的人事物，皆属伏）

京房规定：乾与坤、兑与艮、坎与离、震与巽两两互伏。纯卦之外，每一卦的世爻之下，皆伏藏着本宫对应之爻。

**飞伏的实战判定**：

+ **飞克伏** → 克逃亡（显性力量压制隐性力量，事可压服）
+ **伏克飞** → 逃有伤（隐性力量反噬显性力量，事反噬）
+ **相生** → 难寻捉（明暗相生，事主隐匿难查）
+ **伏神为鬼** → 最难除，后遇旺生依旧发（表面平静，内里波涛）
+ **伏神为财** → 先有财，按十二地支生肖推排（如伏神为子，定知准拟在鼠年、鼠人、北方）

**郭璞筮例**：柳道明占"晋之剥"，晋为游魂（游魂主梦），剥卦伏神为壬午火鬼，断其人必梦见火发或乘马走。这正是"飞伏 + 游魂"合参的经典用法——游魂定"梦"的性质，伏神定"梦什么"。

### 2_4 钥匙四：六神配位

《洞林秘诀》的"何知章"和"六神赋"把六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）的运用推向极致。六神按占卦之日天干起例：甲乙起青龙，丙丁起朱雀，依次周流六爻。

| 六神 | 核心象意 | 临用神吉凶（位置决定一切） |
| --- | --- | --- |
| **青龙** | 喜庆、财福、进人口 | 临财旺相 → 进财进宅进口 |
| **朱雀** | 口舌、文书、公事 | 入木口舌当；入火立见灾；入土事消停；入水公事起 |
| **勾陈** | 田地、产业、迟滞 | 勾陈入地、子孙临 → 进田地产业 |
| **螣蛇** | 惊疑、怪异、虚惊 | 入酉鸡乱啼；入戌犬乱吠；入火火烧定 |
| **白虎** | 凶丧、疾病、刑伤 | 临子孙 → 子孙忌；临财（妻位）→ 妻灾；临父母 → 父母忌 |
| **玄武** | 失脱、奸盗、暗昧 | 带鬼防盗贼；临财贼来到；入水落水投河 |

> **铁律**：六神不能单独断吉凶，必须**叠加在用神之上**才有意义。同一个白虎，临子孙则子孙灾，临妻财则妻灾，临父母则父母忌——位置决定一切。

### 2_5 钥匙五：期日诀（应期推断）

《洞林秘诀》的"期日诀"是六爻应期学的源头之一。完整口诀见卷末附录，此处先立核心法则：

**用神所处十二长生状态，决定应期方向**：

+ **用神生旺之时** → 事成、人归、病愈、求官得
+ **用神墓绝之时** → 事了、人散、公事休、病厄
+ **用神空亡** → 出空、填实之日应
+ **用神被合** → 冲开之时应
+ **用神受冲** → 合住之时应

**分事项应期速查**：

| 所占 | 应期 |
| --- | --- |
| 求财 | 长生至帝旺、墓库、同归之时 |
| 六甲（生产） | 帝旺、长生、沐浴之时 |
| 行人 | 生旺、墓库之时；若问归来，合日是期 |
| 病愈 | 子孙生旺之时 |
| 病厄 | 鬼爻墓旺之时 |
| 公事了 | 官鬼墓绝之时 |
| 求官 | 官鬼生旺之时 |
| 晴雨 | 晴看火爻、雨看水爻，生旺之时应 |

## 板块3 · 演卦九步法：从起卦到应期的标准作业

把五把钥匙串成一条可操作的链路，就是下面九步。建议每次起卦严格按顺序走完，不跳步、不预断。

### 3_1 第一步：起卦凝念

三枚铜钱，从下往上画六爻，得本卦；有老阳（三正）则变为少阴，有老阴（三反）则变为少阳，得变卦。一事一占，念须专一。**潜虚诀**云："坐方立物皆成卦，看其爻发在用时；潜虚本逐心生起，自然神悟泄天机。"——起卦贵在心念专一，卦随心生。

### 3_2 第二步：装卦定基

按京房纳甲体系把卦装完整，这是全部判断的共同底盘。装卦一旦偏差，后续旺衰、取用、应期几乎都会连带失真。固定流程如下：

1. **定卦宫**：确定本卦属八宫中的哪一宫（乾、兑、离、震、巽、坎、艮、坤），每宫统领八卦。
2. **纳甲（装干支）**：
    - 纳甲歌诀：**乾纳甲壬，坤纳乙癸，震纳庚，巽纳辛，坎纳戊，离纳己，艮纳丙，兑纳丁**。
    - 具体排布：乾在内（下卦）起甲子、甲寅、甲辰，在外（上卦）起壬午、壬申、壬戌；坎在内起戊寅、戊辰、戊午，在外起戊申、戊戌、戊子；艮在内起丙辰、丙午、丙申，在外起丙戌、丙子、丙寅；震在内起庚子、庚寅、庚辰，在外起庚午、庚申、庚戌；巽在内起辛丑、辛亥、辛酉，在外起辛未、辛巳、辛卯；离在内起己卯、己丑、己亥，在外起己酉、己未、己巳；坤在内起乙未、乙巳、乙卯，在外起癸丑、癸亥、癸酉；兑在内起丁巳、丁卯、丁丑，在外起丁亥、丁酉、丁未。
    - 规律：**阳卦（乾、震、坎、艮）纳阳干阳支、顺行；阴卦（坤、巽、离、兑）纳阴干阴支、逆行**。
3. **安世应**：世爻代表问卦人、事情主体；应爻与世爻相隔两爻，代表对方、外部环境。定世歌诀：**天同二世天变五，地同四世地变初，本宫六世世三异，人同游魂人变归**。即：一世世在初爻，二世在二，三世在三，四世在四，五世在五，游魂世在四，归魂世在三，八纯（本宫）世在上爻。
4. **配六亲**：以**卦宫五行**为"我"，与各爻地支五行论生克——生我者父母，我生者子孙，克我者官鬼，我克者妻财，同我者兄弟。
5. **起六神**：依日干起青龙、朱雀、勾陈、螣蛇、白虎、玄武，从初爻往上依次排布（甲乙起青龙，丙丁起朱雀……）。
6. **查空亡、月破、日破**，标记旺衰。
7. **查伏神**：如用神不显于卦中，依本宫互伏关系找出伏神。

### 3_3 第三步：观卦名，定大势

"**第一先看卦名义**"。起出的卦，其卦名本身就是天意的总括。这一步现代六爻经常省略，但《洞林秘诀》视其为占断总纲。

+ 占婚姻得**咸、恒、节、泰** → 永遂通
+ 占婚姻得**游魂、八纯** → 再嫁娶
+ 占官讼得**大壮** → 我方有理
+ 占官讼得**明夷** → 有囚禁忧
+ 占家宅得**一二三世、归魂** → 兼得相生则降福频
+ 占家宅得**五世、八纯** → 恐人丁少、孤寒

### 3_4 第四步：断来意（说来意诀）

占来意是《洞林秘诀》的独门绝技。**"五行冲克取来情"**——世爻冲克哪一爻，来意就在那一爻的事象上。

**冲克何爻，即占何事**：

| 被冲克之爻 | 所问之事象 |
| --- | --- |
| 冲克父母爻 | 占印契、尊长、屋宅、田园、文章、应举、舟船 |
| 冲克兄弟爻 | 占争门、贪淫、口舌、妻灾、破散 |
| 冲克子孙爻 | 占瑞物、医药、寺观、六畜、皮毛筋角 |
| 冲克妻财爻 | 占求财、铺店、丝绵、阴人、金银铜铁 |
| 冲克官鬼爻 | 占求官、讼事、神祟、走失 |

**来情三法（来情诀）**：

1. **看旺相休囚**："旺相婚姻宜官职，休囚争财口舌来"——用神旺衰直接揭示来意的轻重。
2. **看冲克何爻**："又看世爻冲克处，心中一事破来心"——世爻冲克哪一爻，来意就在那一爻。
3. **看卦中多者**："卦中多者取来情，或向空亡无处寻"——卦中哪一爻最旺、最动、数量最多，来意即指向它；若指向空亡，则来意隐而不明。

### 3_5 第五步：查飞伏，探隐情

"**六爻皆有飞伏神，世下一爻为最要**"。

+ 用神显于卦中 → 直接取用
+ 用神不显 → 查伏神（世下一爻的伏神最关键）
+ 伏神为鬼 → 事有隐忧，最难除，后遇旺生依旧发
+ 伏神为财 → 先有财，按生肖地支推排（子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌犬、亥猪，并配方位与年）
+ 飞克伏 → 克逃亡，事可压服
+ 伏克飞 → 逃有伤，事反噬
+ 飞伏相生 → 难寻捉，事主隐匿

### 3_6 第六步：看升降，判兴衰

依据卦名升降与游归之体判定趋势：

+ 占阳宅：喜升阳，主进文人；阴静升之进武人
+ 占阴宅：忌升阳（"阴失所"），喜内生外（内卦生外卦为上吉）
+ 游魂卦：纵吉也主离乡发福
+ 归魂卦：虽吉也主伤残
+ 八纯卦：多主迁峰岭，人丁孤寒（唯乾位贵堪迁，坤卦尚可）
+ 五世卦：恐人丁少

### 3_7 第七步：六神叠加，断细节

把六神叠加到用神之上，断具体事象：

+ 朱雀入木 → 口舌当
+ 朱雀入火（鬼爻） → 立见灾祸
+ 朱雀入土 → 事消停、大赦放归乡
+ 朱雀入水 → 公事起、口舌临身
+ 白虎临子孙 → 子孙灾
+ 白虎临妻财 → 妻灾
+ 白虎临父母 → 父母忌
+ 白虎临兄弟 → 不久入泉乡
+ 玄武带鬼 → 盗贼
+ 玄武临财 → 贼来到、退财
+ 螣蛇入酉 → 鸡乱啼；入戌 → 犬乱吠；入火 → 火烧定
+ 青龙临财旺相 → 进财进口

### 3_8 第八步：断吉凶

综合卦名、用神旺衰、飞伏、动爻、六神、冲合刑害，给出吉凶判定。

**核心口诀**："**刑克杀神为凶兆，相合泽马是欢声**"。

具体抓手：

+ **化出进退死**：看动爻所化，进神（寅化卯、巳化午、申化酉、亥化子）主进，退神主退
+ **神煞凶不凶**：天喜、驿马、龙德、太岁等吉神，与白虎、勾陈、螣蛇等凶煞，须分旺衰轻重
+ **伏神出牢笼**：用神不显必查伏，伏神得出（值、冲、合）方有应
+ **反伏吟**：卦变反吟、伏吟，主反复、流泪、事多阻

### 3_9 第九步：推应期（期日诀）

按"生旺墓绝"推断应期，规则见钥匙五。此步必须建立在第七、八步的用神判定之上——**用神找错，应期必错**。

> **统惠诀（现代整合为"六爻速断十步法"）**：

一看空、二看冲，三看刑合衰旺中；
四看化出进退死，五看神煞凶不凶；
六看用爻之位置，七看伏神出牢笼；
八看反伏吟流泪，九看外应十观容。

> 这是对《洞林秘诀》"统惠诀"的现代简化，原诀云："大凡动则观其变，正卦见在后观变……六神叠带吉凶深，只独一重作轻断。"

## 板块4 · 郭璞筮例拆解：从"源码"体会五法合一

《洞林秘诀》保存的郭璞本人筮例，是最珍贵的"源码"。本卷拆解三则，均取自古籍可考的正文。

### 4_1 案例一：占嫂病（贲之豫）

**出处**：古籍辑录本（见《断易天机》所引"贲之豫"条）。

**背景**：丞相掾桓茂伦嫂病困，虑不能济，令郭璞占卦，得**贲之豫**。

**郭璞断词**：

> "时阴在初，卦失度。卜时四月，降阴在初，而见阳爻，此为失度。杀阴为刑鬼入墓，四月杀阴在申，申为木鬼，与杀阴并；又身为卯，变入乙未，未是木墓，建未之月，难得度。"

**拆解占法**：

1. **定时空**：占时为四月（巳月），建未之月为应期背景。
2. **看卦失度**：降阴在初爻，却见阳爻，违反升降常理 → "卦失度"。
3. **查杀阴**：四月杀阴在申，申为木鬼，与杀阴并临。
4. **看身爻**：身为卯（世爻或身爻），变入乙未。
5. **入墓判定**：未是木墓，木鬼入墓，主病难起。
6. **救应之法**："冯马之师，乃寡妪"——马午，午为火；冯亦马，申是杀阴，以火姓消之；巽为寡妇，自然奇救；宜飧兔，兔属卯，所谓"破墓出身"。
7. **处置与应验**：茂伦求得兔，令嫂食之，便心痛不可堪，病愈。

**核心技术**：

+ 卦象 + 纳甲 + 升降 + 飞伏 + 卦气 + 救应，六法合一
+ 不只断吉凶，还给出具体的**化解之法**（飧兔破墓）
+ 应期精确到"建未之月"

> 这是《洞林秘诀》区别于后世纯六爻的关键——**它不仅占断，还给出"化解方案"**。这是郭璞作为风水堪舆祖师的一贯风格。

### 4_2 案例二：占娣病（大过之升）

**出处**：《太平广记》卷二百一十七引《搜神记》（《太平御览》亦载）。

**背景**：扬州别驾顾球娣，生十年便病，至年五十余，令郭璞筮之，得**大过之升**。

**郭璞辞曰**：

> "大过卦者义不嘉，冢墓枯杨无英华。振动游魂见龙车，身被重累婴天邪。法由斩树杀灵蛇，非己之咎先人瑕。案卦论之可奈何——"

**郭璞断后处置**：球乃访迹其家事，知先世曾伐大树，得大蛇杀之，女遂病。后有群鸟数千回翔屋上，人皆怪之；有县农行过舍边，仰视见龙牵车，五色晃烂，甚大非常，有顷遂灭。

**拆解占法**：

+ **卦名**：大过，义不嘉，主"过越、失度"。
+ **卦象**："冢墓枯杨无英华"——取象于枯杨（大过九二"枯杨生稊"之反），主冢墓之事、先人之咎。
+ **游魂**："振动游魂见龙车"——游魂主梦、主异象，龙车即后文所见"龙牵车"。
+ **救应逻辑**：病因在"先世斩树杀灵蛇"，属先人瑕，非己之咎，故须通过赎救（查访、改葬、解禳）化解。
+ **应验**：群鸟回翔、龙牵车之异象，正是游魂卦象的外应显现。

> **要点**：此例展示了《洞林秘诀》"**卦象 → 追因 → 救应 → 外应验证**"的完整闭环，与案例一"飧兔破墓"同出一辙。

### 4_3 案例三：占行军（随之升、同人之某）

**出处**：《艺文类聚》引《周易洞林》梁元帝序及筮辞。

**同人之某辞曰**：

> "朱雀西飞，白虎东起，奸猾衔璧，敌人束手。占行得此，是谓无咎。"

**随之升辞曰**：

> "虎在山右，马过其左，驳为功曹，猾为主者，垂耳而潜，不敢来下，爰升虚邑，遂释魏野。"

**拆解占法**：

+ **六神定方位与事象**：朱雀西飞、白虎东起——以六神配方位断敌情动向。
+ **卦象断吉凶**："奸猾衔璧，敌人束手"——取"衔璧"（面缚乞降之象）断敌人将降。
+ **游归与升降**：升卦属升进之象，"爰升虚邑"明示进取可得。

> **要点**：此例说明《洞林秘诀》的用神系统可扩展至**军事、敌情、行军**等宏观事态，并非仅用于人事占断。梁元帝萧绎在《周易洞林序》中自述"河東郭生，纔能射覆，兼而兩之，竊自許矣"，正是以此类筮例为范本。

### 4_4 筮例总结：郭璞占法的三个共性

把三则筮例放在一起看，可以提炼出郭璞占法的稳定结构：

1. **先立卦名卦象**：以卦义、卦象定性质与总体走向（大过义不嘉、贲失度、升进）。
2. **次入纳甲、升降、飞伏**：把卦象落实到干支、世应、伏神层面，精确定位病因、方位、生肖。
3. **终落救应与外应**：不只断吉凶，必给出化解动作（飧兔、改葬、查访），并以可见的外应（群鸟、龙车、敌人束手）验证。

这三点，正是后世纯六爻普遍缺失、而《洞林秘诀》刻意保留的古法精髓。

## 板块5 · 分占实操：五大场景的断法要点

本卷按实际占问场景分章，每章均给出"核心口诀 + 判定要点 + 吉凶分界"，可直接对照使用。

### 5_1 场景一：占来意（说来意诀）

**核心口诀**："时下来意占生成，前人虽然未曾明。"

**三步法**：

1. **看旺相休囚**：旺相婚姻宜官职，休囚争财口舌来。
2. **看冲克何爻**：世爻冲克哪一爻，来意就在那一爻的事象上（详见第二卷第四步"来意五表"）。
3. **看卦中多者**：哪一六亲爻最多、最动、最显，来意即指向它；若指向空亡，"或向空亡无处寻"，来意隐而不明。

**过去未来诀**（判断所问属过去还是未来）：

> "爻在卦前言未来，爻在卦后言过去。六爻先以卦为身，然后看其爻发处。"

即：以卦身（或世爻）为基准，所问之事对应的爻在卦身之前（较上位的爻）主未来，在卦身之后主过去；再观动爻所发之处，定其应现之时。

**实战例子**：

+ 世爻冲克妻财 → 来占求财、铺店、阴人之事
+ 世爻冲克官鬼 → 来占求官、讼事、神祟
+ 世爻冲克父母 → 来占文书、尊长、屋宅、田园

### 5_2 场景二：占家宅（家宅章）

**核心判定**：

+ **内生外** → 上吉（阴宅最宜）
+ **外克内** → 有伤克
+ **八纯卦** → 多主迁峰岭，人丁孤寒（唯乾位贵堪迁，坤卦将宜象）
+ **五世卦** → 恐人丁少
+ **游魂** → 纵吉也主离乡发福
+ **归魂** → 须吉也有伤残
+ **伏神入墓** → 有伏尸
+ **财父重叠** → 库藏盈

**宅内六爻配位**：

| 爻位 | 所主 |
| --- | --- |
| 父母爻 | 堂 |
| 官鬼爻 | 厅 |
| 兄弟爻 | 门楼、墙 |
| 妻财爻 | 厨下 |
| 子孙爻 | 廊厢 |

**八卦定方位（宅外形势）**：

+ 乾近祠堂，坎近水，坤为平野宽田地
+ 艮为山石与岩崖，震象森森罗列寻
+ 离近窑岩炉冶傍，兑近深溪慈塔位
+ 巽居池畔向尖峰，旺则奇祥、休没瑞

**八卦定房份**：

+ 乾坤为父母房 → 吉
+ 震巽为长房 → 推
+ 坎离为中房 → 论
+ 艮兑为末房 → 看祥禧

**八卦定山形**：

| 卦 | 山形如 |
| --- | --- |
| 乾 | 似马及龙奔（凤凰乾马象其论） |
| 坤 | 平坦如牛势 |
| 巽 | 如蛇迢递远 |
| 坎 | 矫揉多溪涧 |
| 兑 | 如羊队队纷 |
| 艮 | 多石青翠秀 |
| 震 | 如龙马去飞云 |

### 5_3 场景三：占婚姻（婚姻章）

**核心口诀**："占婚本要阴与阳，动时皆动宜为良。"

**吉断要点**：

+ 阴阳皆动 → 宜为良缘
+ 应阴世阳 → 最吉祥
+ 世爻居内卦 → 团圆百年昌
+ 本宫内卦旺 → 我方家厚
+ 外卦旺 → 对方家丰
+ 鬼旺 → 夫雅静；财旺 → 美女

**凶断要点**：

+ 辰午酉亥爻 → 破相，夫妻相攻
+ 游魂、八纯 → 再嫁娶
+ 四五世 → 穷孤
+ 阴阳偏失 → 无成就

**上吉卦**：泰、节、咸、恒 → 永遂通。

### 5_4 场景四：占生产（生产章）

**核心判定**：

+ 乾、兑、坎、离在内卦 → 易养顺生儿

## 板块6 · 进阶心法与修炼路径

### 6_1 网络教程的干货补充（实操补丁）

结合现代六爻教程中对《洞林秘诀》口诀的引申，补充以下实操要点，均为后世发挥，不伪托郭璞。

**（一）何知章的现代应用**

《洞林秘诀》的"何知章"是六爻"何知"体口诀的源头，其价值在于**用"果"推"因"**——看到卦中某个征象，就能反推当事人家中发生了什么事。补充条目（详见卷末附录"何知章补遗"）：

+ 何知人家父母疾 → 白虎临爻兼刑克
+ 何知人家有子孙 → 青龙福德爻中轮
+ 何知人家妻有孕 → 青龙财临天喜神
+ 何知人家大豪富 → 财爻旺相又居库
+ 何知人家多公事 → 朱雀入木口舌当
+ 何知人家遭贼徒 → 玄武官鬼动临身

**（二）飞伏的现代应用**

《洞林秘诀》论飞伏的"伏神为鬼最难除，后遇旺生依旧发"，在现代六爻中演化为完整的伏神取用法：

+ 用神不显 → 必查伏神，不查则断事必漏
+ 伏神为鬼 → 事有隐患，表面平静内里波涛
+ 伏神为财 → 财虽未见，按地支生肖可寻（子鼠北方、午马南方……）
+ 伏神得出之期 → 值（临值）、冲（被冲）、合（得合）、临月建日辰之时
+ 飞克伏 → 事可压服；伏克飞 → 事反噬；相生 → 难寻捉

**（三）旺衰判定的现代细化**

古诀只言"旺相休囚"，现代教程细化为"四时旺相"：当令者为旺，我生者为相，生我者为休，克我者为囚，我克者为死。并结合月建、日辰、动爻三重权重，避免单看卦象。

**（四）外应与观容**

统惠诀"九看外应十观容"，是现代六爻对《洞林秘诀》"潜虚本逐心生起"的发展：起卦瞬间的所见所闻（外应）、来人的神态气色（观容），均可作为卦象的补充验证。此为高阶用法，初学先掌握前八步，再逐步加入。

### 6_2 三个月上手计划

**第一个月：筑基**

+ 熟背"说来意诀""来情诀""期日诀""过去未来诀"
+ 精读家宅、婚姻、生产、科举、仕宦五章
+ 每日用三枚铜钱起卦，练习"观卦名 → 定来意"的基本功
+ 达标线：任意给出一卦，能在三十秒内报出卦名卦义与来意

**第二个月：飞伏与升降**

+ 精研"论飞伏"章："六爻皆有飞伏神，世下一爻为最要"
+ 掌握升降爻法：阳宅喜升阳、阴宅忌升阳
+ 研读郭璞筮例"贲之豫""大过之升""晋之剥"，体会"卦象 + 纳甲 + 飞伏 + 救应"的综合用法
+ 达标线：用神不显时能迅速找出伏神，并判定飞伏生克

**第三个月：六神与分占**

+ 熟背"何知章"与"六神赋"
+ 按"占来意、占家宅、占婚姻、占生产、占官讼"五大场景分别练习
+ 建立自己的卦例笔记，每卦记录：卦名、来意、飞伏、六神、应期、事后验证
+ 达标线：完整走通演卦九步法，并有一至三例事后验证的记录

> **修炼心法**：《洞林秘诀》的精髓不在口诀多，而在**五法合一**——卦名、升降、飞伏、六神、应期，缺一不可。只学其一，不得其门；五法贯通，方入郭璞之室。

### 6_3 现代意义：一套多维度的态势分析方法

跳出术数视角，《洞林秘诀》提供的是一套**结构化的态势分析方法**：

| 《洞林》要素 | 对应分析维度 |
| --- | --- |
| 卦名 | 事件的性质与总体走向（定性） |
| 升降 | 事物的发展趋势（上升 / 下降） |
| 飞伏 | 显性状态与隐性势能（表象与本质） |
| 六神 | 事件的属性与细节（口舌、财物、疾病、盗贼） |
| 六亲 | 人事关系网络（我、配偶、子女、父母、兄弟、官鬼） |
| 应期 | 时间轴上的关键节点（生旺墓绝） |

这套方法与现代管理学中的"SWOT 分析 + 利益相关者分析 + 时间序列分析"有惊人的相似之处。郭璞的天才之处在于：他早在 1700 年前，就把复杂的世事判断**结构化、符号化、可计算化**了。

> 学《洞林秘诀》的真正价值，不在于占验准不准，而在于理解**中国古人如何把"天、地、人"三才压缩进六十四卦的符号系统里，并给出可操作的判断流程**。这种结构化思维，对今天处理复杂问题仍有深刻的启发。

### 7_9 附录九 · 六神赋（六神分宫详断）

> **仕宦**：驿马龙德与青龙，最旺加迁禄位荣；飞伏六爻宜细取，须知四直用心攻；更须印绶并诸德，生旺值时必显通；昔日道明剥之晋，癸酉无期丙子逢；鬼爻旺相无刑克，若遇扶持高显得；杀神世动克官凶，虚费身心求不获。
>
> **词讼**：第一先看卦名义，兄弟持世休论理；卦里有财可争财，天喜生内为胜宜；子孙解杀解官刑，伏神为鬼争不止；鬼动克应他有刑，世应比和终须美；坎为狱门兼血光，子午血光同此意；卯酉破皮丑未逃，震足为鬼防刑治；巽为绳索吊牵连，坤离文章明顺义；兑乾鬼杀旺金伤，无气休囚轻不至；一鬼一司三鬼三，坤卦能顺艮能止；圣人经言讼中吉，争之不足谦有余；贵己不至见终凶，不费资财胜了渠。
>
> **疾病**：鬼杀刑克主灾疾，游魂入墓死亡推；若占亲人爻要有，若还无有主倾危；虎刑一杀深为惧，其余别恶尽堪禳；鬼爻持世须求鬼，若逢服药进灾殃；卦有子孙鬼不犯，便须服药得安康；我若克他先呕逆，他还克我泻为伤；忌食鬼爻生肖肉，子孙能解却无妨。
>
> **六畜**：六畜牛马生肖奇，为财为鬼便推之；生肖要看哪爻动，初爻鸡鸭二犬猫；三猪四羊五牛地，六爻为马可推之；以远先推乾震马，鸡居巽卦雉居离；兑卦为羊艮为狗，坤卦为牛离兼之；坎为豚豕看财鬼，若值无财绝不宜；有财之卦畜财旺，卦若无财六畜衰；占畜忌逢刀砧卦，刀居砧上不通医；离为屠杀归铛镬，乾坤亦主破分离；更加六神时下看，占畜余皆仿此推。
>
> **田禾**：土卦土爻为稼穑，利坤艮卦兼财得；木旺动来禾损伤，金动旺克扶万一；坎卦多水离多旱，子孙为苗母田段；土爻为鬼是官田，父母化鬼同此断；土宫土卦更逢升，定主连年添产贯；水动多霖火旱枯，木动今春桑叶贵，土动虫伤更有灾，金动切防官事至。
>
> **天时**：水爻为雨火爻日，皆是卜推时下冲；朱雀有气火爻同，玄武有水凶；远论晴时离作日，坎卦为雨旺须疾；乾象青天兑象云，坤艮平晴止雨毕；巽象为风震象雷，六神六爻入卦出；细详休旺分重轻，若不空亡断无失；巽卦杀动风伤物，震卦杀动雷伤人；坎卦动时中雹子，卯辰巳午亦同申；动时前后分轻重，静则休旺见知亲。

## 板块9 · 参考与说明

**本书所据主要材料**：

1. 《周易洞林》，郭璞撰，《汉魏遗书钞》本，维基文库收录（含梁元帝序及同人、随、豫、既济、否等筮辞）。
2. 《郭璞传》，《晋书》卷七十二，唐太宗御撰。
3. 《太平广记》卷二百一十七《卜筮一·郭璞》，引《搜神记》（"大过之升"占顾球娣）。
4. 《太平御览·筮下》，引《续搜神记》等。
5. 《断易天机》，筮法类书，其所辑《洞林秘诀》口诀（说来意、来情、何知章、期日诀、六神赋、潜虚诀、统惠诀、分占各章）为本书体系骨架。
6. 清·马国翰《玉函山房辑佚书》，辑《易洞林》佚文。
7. 现代辑本《易洞林》（三卷附补遗，心一堂据嫏嬛馆补校本整理）。
8. 现代六爻教程中的演卦流程、旺衰细化、十步法等内容，均作"实操补丁"处理。

**两点说明**：

+ 第一，本书为**学习重构本**，不是古籍点校本。口诀文字在流传中多有异文（如"弟兄 / 友朋""祸福 / 口舌灾"），本书择善而从并出注，不求版本校勘之精审。
+ 第二，六爻占断属传统文化研究范畴，本书的价值在于理解其**结构化思维方法**，而非鼓励迷信占验。读者宜以学术、文化之眼光读之。

---

**写在最后**：本书刻意避开了对《洞林秘诀》的目录式复述，而是把它拆解为"卦名 →来意→ 飞伏→升降 →六神→ 应期"六条主线，并给出可操作的演卦九步法与五大场景断法。建议读者先熟背说来意诀、来情诀、期日诀、过去未来诀四大口诀，再回到郭璞筮例体会"五法合一"的占断艺术——唯有在"演"的过程中，郭景纯的占筮世界才会真正向你打开。
