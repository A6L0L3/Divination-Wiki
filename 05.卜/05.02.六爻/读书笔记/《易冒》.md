## 板块1 · 先认清这本书：它到底是什么，不是什么

### 1_1 版本与定位

+ **作者**：程良玉，字元如，清代新安（今安徽歙县）人。五岁因天花失明，先学医，十岁以"医主望闻问切，既不能望，术能神乎"弃医从卜。
+ **成书**：先集旧闻、承师说，成《筮类》五十篇；康熙己卯（1699）遇"枯匏老人"，复究先贤阐《易》之书数十种，增立法四十一篇，凡**九十一章，分编十卷**，占题**三百七十余问**。四十岁背发疽，闭门三年成书，书成而卒。
+ **体例**：卷一至卷四为**理论总纲**（占法底层），卷五至卷十为**分事占断**（五十类三百七十余问）。建议读本：世界知识出版社2011年版（金志文译注），446页。

### 1_2 它在六爻谱系里的真实位置

| 维度 | 《增删卜易》 | 《卜筮正宗》 | **《易冒》** | 《易隐》 |
| --- | --- | --- | --- | --- |
| 强项 | 实战案例、口诀 | 规范系统、可教学 | **理法辨析、条件限定** | 包罗万象 |
| 风格 | 通俗上手快 | 筮法教科书 | **讲"为什么"多于"怎么办"** | 象数庞杂 |
| 独有贡献 | 大量应验例 | 系统化的断卦流程 | **八节建旺/阴阳升降、卦验章、真伪辨析** | 融合斗数八字太乙 |

**一句话定位**：如果说《增删卜易》是"菜谱"、《卜筮正宗》是"教科书"，那《易冒》是**"底层原理 + 边界条件注释"**。它的核心价值不在"给你一句断语"，而在**告诉你这句断语什么时候成立、什么时候会失效**。

### 1_3 必须正视的硬伤（否则会误用）

《四库全书总目》的批评并非无的放矢，主要集中在：

+ **"家宅"章**：以六爻兼断六亲荣枯（兄弟旺则劫财、父母旺则克子、官鬼旺则灾病）——**"谬固难通"**。用固定公式推断他人吉凶，逻辑链条过脆。
+ **"鬼神""诸星"章**：**"穿凿支离，尤无理解"**。神煞体系在今天已难验证。
+ **"婚姻"章**：部分断法不究五行生克、不察用神旺衰，**仅凭卦名美恶定吉凶**——这是全书最需要警惕的取向。

**阅读策略**：理论辨析部分（卷一至四）精读；分占部分（卷五至十）**只取"取用法则"与"真伪辨析"，不照搬具体断语**；家宅、鬼神、诸星三章**浏览即可**。

## 板块2 · 作者的方法论：一个失明者的"被迫优势"

这一节是全书的**总纲**，也是最容易被当成自传、一眼带过、实则必须吃透的部分。

### 2_1 "专则纯，纯则精，精乃入神"

程良玉随星元先师五年后仍"犹若茫然"，一度分心音律棋艺。师诫之曰：

> 学易之道，**专则纯，纯则精，精乃入神**；分则杂乱，杂乱则疏，疏乃不入。

**解读**：他"五年茫然"不是愚钝，而是**把五六家日者的杂学都装进来了**。迷茫的真正原因是"输入过载 + 没有单一主线"。一旦"十八岁始悟用爻"，一切就贯通了。

> **对现代读者的实操含义**：学六爻（或任何一门术数/技能），**第一原则是"一段时间内只跟一个体系"**。同时看《增删》《易冒》《易隐》三种风格的书，等于同时学三种方言——看起来博，实则永远在翻译，无法形成"条件反射式"的判断力。建议：**先《卜筮正宗》立骨架，再《增删》练手感，最后用《易冒》纠偏与深化**。

### 2_2 "用爻"是全书的开关

> 天下之事亿兆纷纭，何以得一理贯通其吉凶而后不惑？年登十八，**始悟用爻**……**惟一用爻，而求诸吉凶乃得其柄**。

关键在于——**用神不是按"年龄/身份标签"取的，而是按"关系结构"取的**。这是全书最容易误解、也最有现代价值的一点：

| 事体 | 取用之"反常"处 | 背后的关系逻辑 |
| --- | --- | --- |
| 老奴占幼主 | 用**父母**（非子孙） | 奴视主如子，**关系定义用神** |
| 少主占衰仆 | 用**妻财**（非官鬼） | 仆是"我所役使的财产性存在" |
| 词讼 | 凭**官**而后看世应 | 胜负取决于"听讼者（官）" |
| 寿命 | 凭**用**而后看父母 | "用"是命主自身元气 |
| 科目（乡会试） | **先文（父母/文书）后官** | 先有文章，后有功名 |
| 廷试（殿试） | **先官后文** | 廷对重"对君之言"，官鬼为先 |

**实操心法（这是全书最可落地的干货）**：

> **不要问"这个事一般用哪个用神"，要问"在这个具体关系里，谁是主、谁是从、谁是被作用者"**。宁可在起卦前花 3 分钟把关系写清楚，也不要起完卦后凭口诀硬套。

### 2_3 全书总纲：三层结构与四个动词

原文这段是**全书说明书**，必须逐句拆：

> 用神所系……或以卦、或以爻、或以内外、或以世应、或以五行六亲、或以八卦六神……**以年月日时经之，飞伏互变纬之**，旺相建生空破散绝进退刑害**消息**之……大抵**舍静求动、舍衰求旺、舍病而求不病**。

+ **经之（经线）**：年月日时——**时间维度**，旺衰的尺子。
+ **纬之（纬线）**：飞伏互变——**结构维度**，卦内的隐藏层。
+ **消息之**：旺相建生 / 空破散绝 / 进退刑害——**动态调节**。
+ **三个"舍—求"**：动 > 静、旺 > 衰、**"不病" > "病"**——注意"病"这个字，它是全书判断吉凶的**底层隐喻**：吉凶 = 用神是否处于"无病"的状态。

**"先辨卦，后辨爻"**——这是《易冒》区别于多数六爻书的第二大特征：

> 卦用有八：一内外、二冲合、三反伏、四墓绝、五归游、六卦候、七卦义、八卦验。

意思是：**先看整个卦的"大气候"（卦用八法），再看具体爻位的"小天气"（爻用）**。很多读者一上来就抓用神旺衰，恰恰是本末倒置——原书明确说"卜者常泥于用神而失之"。

## 板块3 · 卷一至卷四理论总纲：占法底层（精读区）

### 3_1 卷一：起卦与基础（第1–10章）

甲子、成爻、成卦、纳甲、五行、六亲、六神、世应、身法、间爻。

**重点不在背诵，而在理解"每一层是干什么的"**：

| 要素 | 角色 | 一句话功能 |
| --- | --- | --- |
| 纳甲（干支入爻） | 坐标系 | 让爻能与"时间"发生生克关系 |
| 六亲 | 关系网 | 把五行生克翻译成"人事角色" |
| 六神 | 气质/状态 | 青龙=生发吉庆，白虎=刑伤，玄武=暗昧，勾陈=阻滞，螣蛇=怪异虚惊，朱雀=口舌文书 |
| 世应 | 主客 | 世=我方/主体，应=对方/环境 |
| 间爻 | 中介 | 世应之间的爻，主"中间人、过程、明堂" |

**实操要点**：六神不要单独论吉凶，**一定要结合旺衰与所临之爻**。青龙临官鬼发动，未必是吉；白虎临子孙，未必是凶。

### 3_2 卷二：卦象的复杂形态（第11–20章）

变互、飞伏、反伏、归游、升降、进退、有无、墓绝、卦候、干化。

**这一卷是全书的"技术高峰"，重点抓四个概念**：

#### 3_2_1 飞伏：看见"看不见的爻"

伏神 ≠ 不存在，而是**伏于飞神之下**。用法：用神不上卦（卦中无此六亲）时，取其伏神。

**真伪之辨**（原书重点）：

+ 伏神**得日月生扶、或飞神空破** → 有用，可出而作用。
+ 伏神**被飞神克压、又无援** → 真伏无用，主"事在而有阻，终难得"。

**实操口诀**：伏神要"值、临、冲、合、飞神空破"才能引拔。**凡断伏神，先问一句"它有没有被放出来的通道"**，没有通道，伏神再旺也是"抽屉里的钱"。

#### 3_2_2 反伏（反吟 / 伏吟）：全书最凶的"卦象级"信号

+ **反吟**：主卦与变卦**六爻纳甲相同、六亲相对**（本质是爻位不动、五行翻覆）。主"反复、悖逆、事多反转"。
+ **伏吟**：主卦与变卦**完全相同**（占法上指八纯卦世在六爻，动而不变新卦）。主"气分而不通，事情停滞、内心忐忑"。

**重点**：这是"先看卦"的典型——**卦象级的反伏，优先级高于用神旺衰**。用神旺而逢反伏，吉事也多波折；用神衰而逢伏吟，凶事难解。

#### 3_2_3 归游：归魂 vs 游魂

+ **游魂**：主"无定、心神不宁、出行、居无定所"（**主不出、行远**）。
+ **归魂**：主"回归、安定、守旧、不出远门"。

**实操**：占出行/迁徙遇游魂反而是"会动"的信息；占久居/守业遇归魂为吉。注意**与事体反向取义**。

#### 3_2_4 升降（阴阳升降）——本书独有，重点理解

> 升，犹生也、长也、进也、来也；降，犹死也、消也、退也、往也。

**核心规则（最易被误读）**：

1. **"升降务以占时言，毋以卦体言也"**——升降由**占卦时的节气（中气）**决定，**不是由卦本身决定**。
2. 取**十二辟卦**（复临泰大壮夬乾姤遁否观剥坤）配十二月**中气**：冬至起复卦初爻升阳。
3. **真升 / 真降**的判定：临**阳爻**为真升阳、真降阴 → **旺盛**；临**阴爻**或临变爻阴爻 → **假升/反度 → 衰败**。
4. 口诀：**升阳降阴入空亡之爻 = 卦气入爻，爻不为空（反旺）；升阴降阳入空亡 = 衰气入爻，更衰**。

**落地简化版**（现代实占不必死抠卦气）：把"升降"理解为**"爻是否在当令的上升通道上"**——用它来**调节**旺衰判断的细微差别，而不是另立一套体系。若已熟练月建日辰，**升降可仅作"加分/减分项"**，避免多套标准打架。

### 3_3 卷三：时间维度（第21–30章）

岁君、月将、日主、时辰、月破、旬空、日冲、遇时、独发、两现。

**这一卷是全书的"尺度表"——你必须先搞清楚谁大谁小**：

#### 3_3_1 时间要素权重排序

> 原书："**卦旺三气，亦有一候之余旺；支司六候，亦有一候之先司**"——意即月令（三气/节气）是大尺子，但日辰、时辰也有各自的管辖范围，不能只用月建一刀切。

**核心结论（务必记住）**：

| 要素 | 角色 | 关键规则 |
| --- | --- | --- |
| **日主（日辰）** | **最重** | "日惟散、日重绝"；用神临日辰 = 尽善（逢散不散、逢空不空——_注意此句在后世有争议，见下_） |
| **月将（月建）** | 次之 | "月惟破、月重克"；**卦旺三气**的根基 |
| 岁君（太岁） | 远应 | 主一年以上之事、大局 |
| 时辰 | 近应 | 断应期细节 |

**关键辨析——"临日辰逢空不空"的争议**：

李我平在《增删卜易》笔记里尖锐指出：《易冒》说"爻临日辰，莫能空之、莫能散之"，但**动爻逢日冲本就为散（日破）**，若此爻正是"临日"之爻，逻辑上自相矛盾（一个爻不可能既临日又被日冲，除非换了一个"日"）。

**正确的理解方式（实操修正）**：

> "临日不为空、不为散"这句，**应严格限定为"用神静爻临日辰"这一种情况**。动爻被日冲 = 散/破，是另一条铁律，**二者不冲突，冲突的是表述不严谨**。读古书务必如此"顶门上一只眼"——**规则要带条件，不要当绝对真理**。

#### 3_3_2 四个"真假"辨析（卷三、卷四的核心价值）

原书最大贡献，是把前人当"铁律"的话，**都加了反例**：

| 铁律（前人） | 《易冒》的修正 |
| --- | --- |
| 随鬼入墓 = 凶 | 亦有**不凶**（须看用神根基、墓中是否有救） |
| 助鬼伤身 = 凶 | 亦有**不凶**（仇神被制时反成吉） |
| 绝处逢生 = 吉 | 亦有**不吉**（原神虚浮、生之无力） |
| 旬空 / 月破 / 化绝 / 冲散 | 皆有**真假之分** |
| 伏神不论旬空 | 非"不空"，而是**轻重与空否无关** |

**这是全书最可落地的方法论**：**任何一条断语，在使用前先问三个问题——「1」 这是真还是假？「2」 谁是元神、谁是忌神、谁是仇神？「3」 有没有"反例条件"？** 养成这个习惯，断卦准确率的上限才会被打开。

### 3_4 卷四：生克与卦象直断（第31–40章）

长生、官鬼、绝生、合冲、随墓、助伤、局会、刑害、诸星、卦验。

#### 3_4_1 十二长生：只抓四个位

> "法不以胎为始而以长生为始者，以其未现形象也"……"其所取用者，**莫重于生、绝**"。

+ **只看：长生、临官（禄）、帝旺、墓、绝、死**。**沐浴、冠带、衰、病、胎、养这六位"不胜五行之生克"**——主次要分清，别死背十二位。
+ **日重绝、月重克**；**爻在日辰上的生绝 > 在月建上的生绝**（"日重而月轻"）。
+ **伏爻的生绝看飞爻，动爻的生绝看变爻**——类比于"日"的用法。

#### 3_4_2 卦验章（第40章）——全书最具争议、也最见作者个性的一章

> 以爻取占应者，谓之用神；**以卦取占应者，谓之卦验。卦验专于卦而不专于爻也**。

**核心观点**：有一类占事，**整卦的卦名/卦象本身就是答案**，不用去抠用神旺衰。

**必须先看卦的五种情况**（原书"先卦而后爻"）：

1. **婚姻忌三冲**（卦冲、爻冲、日月冲）→ 不用看用神旺衰。
2. **邦畿征伐忌内卦反伏** → 不凭子孙、官鬼。
3. **迁居忌外卦反伏** → 不凭官鬼静。
4. **占病**：主属（病人对应之爻）**化墓、化绝** → 即用神旺亦凶。
5. **风水（茔葬）**：巽（风）、坎（水）、乾（石）、兑（沙）、离（蚁）、蛊（虫）、井（泉）、明夷（伏尸）——**此八卦为"风水卦忌"，即世与子孙皆旺亦不为吉**。

**卦验的"参考库"（可当作模式识别素材，非铁律）**：

| 事体 | 吉卦 | 凶卦 |
| --- | --- | --- |
| 天时（晴雨） | 乾、离 = 晴 | 坎、兑 = 雨 |
| 求财 | — | 萃 = 亏本 |
| 出行 | — | 节、艮、坎、明夷 = 不吉 |
| 狱讼 | 大壮、夬 = 得理 | 坎、蹇、明夷 = 有囹圄 |
| 疾病 | — | 明夷、既济、丰、节 + 土鬼独发 = 死 |
| 婚姻 | 咸、恒、节、泰（变冲则凶） | 睽、革、解、离（化合亦凶） |

**八卦验的经典句式**（用于"因卦象取义"）：

+ 噬嗑（日中为市）→ 宜贾肆；涣（木在水上）→ 利江河；
+ 离 → 佃鱼；随 → 驾马；益 → 农田；艮、离、咸、蛊 → 蚕有收。

**但——这里必须打一个大大的修正标记**：

> 原书自己也说："**兼察用象更确**"、"**不宜执一而断也**"、"**然与金钱筮义，断亦少殊**"。

现代实占者的共识是：**卦验只能作为"提示/加权项"，绝不能凌驾于用神旺衰之上**。比如"婚姻忌三冲"——占到八纯卦（六冲）确实多有不顺，但**六冲化六合、爻冲亦可成婚**；关键看用神是否有救、是否化进。

**实操底线（务必遵守）**：

> **用神为主，卦验为次；动爻为主，卦名为辅。凡卦名断语与用神旺衰相冲突时，一律从用神。** 卦验章的价值在于"让你多一个观察维度"，而不是"给你一张可以直断的对照表"。

#### 3_4_3 八节建旺（卦候章 + 升降章）——本书独有，简要理解

把**二十四节气**与卦爻旺衰挂钩，等于在"月建、日辰"之外加了一层**"节令能量"**维度。现代实占中**多数人只用到月建**即可，**卦候/升降可当进阶选修**——不必为追求"完备"而把判断标准叠成五套，结果互相打架。

### 4_3 三类典型占事精读示例

#### 4_3_1 示例A：疾病（疾病章 + 医药章 + 官鬼章）

**取用**：病人对应之爻（自己占 = 世爻/用爻；代占 = 对应六亲）为主，**官鬼 = 病邪**，**子孙 = 医药/克病之力**。

**核心断法**：

1. **主属化墓、化绝** → 凶，"即用神旺亦凶"（先卦后爻）。
2. **随鬼入墓**（用神入官鬼之墓库）→ 凶；但**须辨真假**：用神有根、墓中得生则不验。
3. **助鬼伤身**（子孙（克鬼者）被克伤，反而助长了鬼）→ 凶；**但有反例**（仇神被制）。
4. **医药**：子孙爻旺相、不受克 → 药石有效；子孙临空破 → 治不对症或延误。

**现代迁移（重点）**：把"疾病章"当作**"状态诊断框架"**而非算病——

+ 官鬼旺 = "问题的压力源很强势"；
+ 子孙 = "解决方案/专业助力"；
+ 墓绝 = "陷入、停滞"；
+ 进退 = "在恶化还是好转"。

**这一套语言可以直接迁移到"项目健康度诊断""身体亚健康管理"上**（详见第六章）。

#### 4_3_2 示例B：茔葬 / 风水（茔葬章）——理解"静"这个字

**取用**：**世爻 = 主穴**，**子孙 = 后嗣**。

> "世为主穴，而不可虚也；子孙为祭祀，而不可衰也。"

**吉的条件（原文精炼版）**：

> **不遇卦忌 + 不遇三冲 + 不遇世墓 + 世爻实 + 子孙旺 = 尽善尽美。**

+ 子孙旺而官父得地 = 贵；子孙旺而财得地 = 富；
+ 子孙旺而遇帝旺 = 多男；遇长生 = 多寿；遇羊刃白虎 = 出武夫。

**"风水卦忌"八卦**（巽风、坎水、乾石、兑沙、离蚁、蛊虫、井泉、明夷伏尸）——**即世与子孙皆旺亦不为吉**。

**六神配形势**（可当作"空间结构描述法"，极有启发性）：

| 神/位 | 状态 | 对应形势 |
| --- | --- | --- |
| 青龙 | 空 | 左凹 |
| 白虎 | 动 | 右凸 |
| 玄武 | 陷 | 后虚（无靠） |
| 朱雀 | 冲 | 前杂 |
| 间爻 | 旺 | 明堂宽 |
| 上爻 | 空 | 水口缺 |
| 勾陈 | 实 | 来龙端 |
| 螣蛇 | 冲 | 去路裂 |

**现代实操修正**：

+ **六神配空间这套方法，可以原样迁移到"住宅/办公空间诊断"**——把"风水"换成"环境心理学 + 动线合理性"即可。左凹右凸、后无靠、前有冲，本就是**空间感上的不安定因素**。
+ 但**"子孙旺 = 后人贵富"这类因果断言，不可采信**。保留"世爻实、用神旺、无冲无墓"这个**结构判断标准**，丢弃其神秘归因。

#### 4_3_3 示例C：词讼（词讼章）——取用最见功力

> "**词讼凭官，而后世应**"——胜负取决于**听讼者（官鬼爻）**，世应只论"我方 vs 对方"。

**可迁移点**：任何"第三方裁决型"问题（仲裁、考试评分、审批、融资尽调、官司、竞标评审）——**用神不是"我"，而是"那个做决定的人/机构"**。这是"用爻"思想最锋利的应用。

### 4_4 占诫章（第91章，卷末）：必读的方法论护栏

原书最后的"戒"——放在今天依然是**认知护栏**：

1. **一事一占**：不要为同一事反复起卦直到得到想要的结果（"再三渎，渎则不告"）。
2. **诚心、慎断**：卜者以诚，断者宜慎。
3. **不可挟私、不可破坏他人吉地**（"谋人之成穴，破人之吉地……鬼神所不告也"）——**术的伦理边界**。
4. **吉凶有"德"的维度**：原书自序引"泰豫本吉，而筮者志凶则吉凶反应"——**强调"心志/德行"对结果的调节作用**（这是哲学层，可保留为"信念-行动"的自我实现机制）。

## 板块5 · 把《易冒》"翻译"成可复现的断卦流程（SOP）

> 这是全书最落地的产出。下面这套流程**严格对应原书"先辨卦 → 后辨爻 → 以年月日时经之 → 飞伏互变纬之 → 消息之 → 舍静求动"的总纲**，可直接用于实占练习。

### 5_1 步骤 0：起卦前（约 3 分钟，最关键）

- [ ] **写清楚问题**：一句话，含"主体 + 动作 + 对象 + 时间范围"。
    - "我（创业者）能否在 2026 Q4 前拿到下一轮融资"
    - "我能不能成功"（太泛，无法取用）
- [ ] **确定用神**（用原书"关系结构法"）：
    - 问自己："这件事里，**谁是主、谁是从、谁是被作用者**？"
    - 查 4.2 取用速查表，定**主用神**。
- [ ] **定分类**：属于卷五至十的哪一类？要不要"先卦后爻"（参考卦验章的五种情况）？

### 5_2 步骤 1：成卦（铜钱三枚，三摇一爻，六摇成卦）

+ 记：本卦、动爻、变卦、**纳甲干支、世应、六亲、六神**。
+ **新手常见错**：漏记世应或六神——后面一定会回头补，不如一次记全。

### 5_3 步骤 2：先看卦（卦用八法，原书"先辨卦"）

按顺序快速过一遍，**任一项命中即记录**：

| 优先级 | 检查项 | 判据 | 影响 |
| --- | --- | --- | --- |
| 1 | **卦冲/卦合** | 八纯六冲卦？六合卦？ | 全局基调 |
| 2 | **反伏** | 反吟（六亲相对）/ 伏吟（八纯世六） | 多凶，反复/停滞 |
| 3 | **归游** | 游魂 / 归魂 | 出行喜游魂、守业喜归魂 |
| 4 | **墓绝** | 本卦/变卦化墓化绝 | 凶（尤其病、身命、住基） |
| 5 | **内外** | 内卦 vs 外卦 | 占家：内=人、外=宅 |
| 6 | **卦候/升降** | 占时节气对应升降爻 | 旺衰微调（进阶） |
| 7 | **卦义/卦验** | 是否属于"先卦后爻"五类？ | **仅作加权，不凌驾用神** |

### 5_4 步骤 3：再看爻（用神旺衰，原书"后辨爻"）

**3.1 找用神**：主用神 + 备选（如疾病：用爻 + 官鬼 + 子孙）。

**3.2 用神两现 → 独发章/两现章规则**：

+ 卦中有两个同样六亲 → 取**动爻者、临日月者、不空破者、与世应相近者**。

**3.3 旺衰打分（四层尺子，从大到小）**：

```plain
旺衰 = 月建(最大) → 日辰(最重) → 动爻生克 → 伏神/变爻

```

+ **临月建/得月建生** → 旺；**临日辰** → 尽善（逢散不散、逢空不空，_限静爻_）
+ **月破、旬空、日冲散、化绝** → 衰（**但要辨真假**）
+ **十二长生**：只看**长生、禄、帝旺、墓、绝、死**

**3.4 生克链（三神系统）**：

```plain
元神（生用神者）→ 用神 → 忌神（克用神者）
                         ↑
                    仇神（克元神者，间接助忌）

```

+ 元神旺 = 有源头、可持续；忌神动 = 直接威胁；仇神动 = 断援。
+ **"助鬼伤身"** = 仇神伤元神，反而帮了忌神 → 凶。

**3.5 真假辨析清单（原书核心价值，务必逐项过）**：

- [ ] 空亡：是**真空**（无气、无援）还是**假空**（有日辰生扶、动爻化实）？
- [ ] 月破：破爻是否**发动**、是否**化进/化回头生**？
- [ ] 化绝：是**化进神**（有用）还是**化去**（无用）？
- [ ] 随墓：用神入墓，墓中**有救**还是**无援**？
- [ ] 飞伏：伏神**有通道**（值、临、冲飞神、飞神空破）吗？

### 5_5 步骤 4：纬之——飞伏互变

+ **变卦**：动爻变出 → 看**化进 / 化退 / 化回头生 / 化回头克**。
+ **互卦**（三四五爻）：**过程、隐情**。
+ **伏神**：用神不上卦时取；判断"能否引拔"。

### 5_6 步骤 5：合参定结论 + 定应期

+ **三个"舍求"定吉凶**：舍静求动、舍衰求旺、舍病求不病。
+ **结论 = 卦象基调 × 用神旺衰 × 生克链 × 真假辨析**——四者冲突时，**从用神，不从卦名**。
+ **应期**：用神**值、临、冲、合、入库、出空**之时；结合月建、日辰、动爻数。

### 5_7 步骤 6：复盘（决定你能不能进步的一步）

+ 记录：**问题、卦象、你的判断、理由（每一条规则都注明出处章节）、实际结果**。
+ **三个月后回看**：哪类判断准、哪类不准 → 修正的是**你的取舍权重**，不是卦本身。

> **配套练习路径**（3 个月）：
>
> + 第 1 月：只看"身命、年运、疾病、理财"四类，各占 10 卦，练**取用**。
> + 第 2 月：专练"真假辨析"（空破绝散），同一卦用"真/假"两种假设各推一遍。
> + 第 3 月：加入卦验章作为**加权项**，验证"卦名"在实际中验与不验的比例（你会得到自己的经验阈值）。

## 板块6 · 跨界迁移：把"用爻 + 真假辨析"用到非占卜场景

> **这一节是全笔记最"干货"的部分**——《易冒》的真正价值，不在"算得准"，而在**它提供了一套"识别核心变量 + 判断真假信号"的思维框架**。下面四个迁移，全部可直接上手。

### 6_1 迁移 1：复杂决策 —— "取用神" = 找到真正的约束变量

原书："词讼凭官而后世应"、"科目先文而后官"。

**方法**：任何复杂决策，先问"这件事的决定权在谁/什么手上"，**把它设为"用神"**，其他都是"世应/元神/忌神"。

**案例：要不要换工作？**

+ 常规思路：列一堆优缺点 → 越列越乱。
+ 《易冒》式思路：
    - **主用神** = 你真正最在意的那一个变量（钱？成长？稳定？——只能选**一个**当"世爻"）
    - **官鬼** = 新公司/行业的风险与压力
    - **妻财** = 直接的薪资收益
    - **父母** = 资质、履历、背书
    - **子孙** = 自由、创造力、长期可持续性（也主"克官鬼"= 过度自由反伤事业）
    - **断法**：主用神旺 + 元神（生用神者）有力 → 可做；主用神衰 + 忌神（官鬼）动克 → 暂缓。

**可落地模板**（决策日记）：

```plain
决策主题：______
主用神（核心诉求，1个）：______
辅助变量：元神= / 忌神= / 仇神=
旺衰判断（对主用神的净作用）：+
结论：进/退/待时

```

### 6_2 迁移 2：问题诊断 —— "三神系统" = 因果链建模

```plain
元神(因/资源) → 用神(果/目标) → 忌神(阻/压力)
                         ↑
                    仇神(断援者)

```

**案例：一个项目为什么停滞？**

+ 用神（项目本身）衰：进度慢、质量降
+ 找元神：资源/团队/现金流 → 是否被克伤？
+ 找忌神：竞品、政策、内部阻力 → 是否在动？
+ 找仇神：那个"本来该帮你、却在帮倒忙"的角色——**往往是问题的真实所在**（对应"助鬼伤身"）

**"随鬼入墓"的现代翻译**：**陷入一个看似安全、实则消耗的死循环**（比如一份"稳定但毫无成长"的工作、一段"不吵但已死"的关系）。判断标准：用神入"墓"= 能量被封存、无法流动 → **出路在"冲墓、开墓"（外部刺激、主动打破）**。

### 6_3 迁移 3："真假辨析" = 避免被表面信号误导

原书对"空破绝散、随墓助伤"全部加了**反例条件**——这其实是**批判性思维的古代版本**。

**可迁移的通用原则**：**任何一条看起来成立的判断，都先问"它的成立条件是什么？有没有反例？"**

应用到投资/信息判断：

+ "市场情绪极悲观" = 表面"凶" → 但如果是**假空**（有基本面支撑、有资金流入）→ 反而是机会（绝处逢生）。
+ "数据很好看" = 表面"旺" → 但如果是**太过**（透支、泡沫）→ "**太过者损之斯成**"（原书卷五引用《黄金策》），过旺反需要"损"，不是"吉"。

> **原书金句**："**太过者损之斯成，非云吉凶，断事之成合时也**"——**吉凶不是静态标签，而是"合不合时宜"**。这条放到今天的投资、职业规划里，依然锋利。

### 6_4 迁移 4："先辨卦后辨爻" = 先做系统诊断，再做细节优化

**错误做法**：一上来就优化某个局部（换工具、改话术、熬夜加班）。
**《易冒》做法**：先看**整个系统的"卦象"**（行业趋势、团队氛围、健康状态、现金流周期），再看**具体爻位**（某次沟通、某个功能、某项开支）。

**落地成习惯**：

> 遇到任何"出问题"，**强制先花 10 分钟在系统层（卦用八法）扫一遍**，问自己：
>
> + 是不是"反吟"？（在反复、来回拉扯——需要定方向）
> + 是不是"伏吟"？（停滞不动——需要外力/换环境）
> + 是不是"游魂"？（心神不宁、无定所——需要先锚定一个落点）
> + 是不是"归魂"？（过度守旧——需要适度走出去）
>
> 扫完再进入细节。**绝大多数低效努力，都败在跳过了这一步**。

## 板块7 · 与其他经典的互读对照（避免陷入单一体系）

| 主题 | 《易冒》怎么说 | 《增删卜易》怎么说 | 怎么取舍 |
| --- | --- | --- | --- |
| 用神 | **一准于用爻，按关系取** | 分门别类列用神，重旺衰 | **以《易冒》的"关系结构法"定用神，《增删》的旺衰细则来打分** |
| 空亡 | 有真假之分 | 真空/假空、日辰可填 | 两书一致，以"有无援"为准 |
| 动逢日冲 | 临日不为散 | **动逢日冲为散（日破）** | **从《增删》**——《易冒》此句表述有自相矛盾（见 3.3 辨析） |
| 卦名断吉凶 | 专设"卦验章"，但自云"不宜执一" | 几乎不用，纯重用神 | **以《增删》为主，卦验仅加权** |
| 飞伏 | 七世伏本宫 + 游魂飞伏不相侔，以验为准 | 用神不上卦取伏神 | 两书互补，以"伏神能否引拔"为判 |
| 神煞（诸星） | 专章系统论述 | 简化 | **现代实占可基本不用**，保留"贵人/驿马"等少数常用即可 |
| 卦候/升降 | 独有，配节气 | 无 | **进阶选修**，不熟月建日辰者先不碰 |

**核心结论**：**《易冒》的最佳用法，是当"校正器"和"深化器"，而不是入门书**。先有《卜筮正宗》的规范骨架 + 《增删卜易》的实战手感，再来读《易冒》的"真伪辨析"，你才会意识到——**原来那些你以为的铁律，都是有边界的**。这就是程良玉五岁失明、五年茫然、十八岁始悟用爻换来的认知深度。

## 板块9 · 核心原文摘录（含白话，供精读对照）

> 以下原文均出自《易冒》自序与各章正文，**是必须能背下来的"骨架句"**。

**「1」 用爻总纲（自序）**

> 原文：天下之事亿兆纷纭，何以得一理贯通其吉凶而后不惑？年登十八，始悟用爻……**惟一用爻，而求诸吉凶乃得其柄**。

白话：天下事千头万绪，如何用"一个道理"贯通吉凶、不再困惑？我十八岁时才悟到"用爻"——**只要抓住这一个用爻，吉凶就抓住了把手**。

**「2」 取舍原则（类总章）**

> 原文：词讼凭官而后世应，寿命凭用而后父母，科目先文而后官，廷试先官而后文，**各有所重**。

白话：不同事体，**取用的优先级不同**——重点在"各有所重"这四个字。

**「3」 主次之辨（自序）**

> 原文：随墓助伤本（有）凶而有弗凶也，绝生本吉而亦有弗吉也，**空破绝散有真伪之分，飞伏互变有轻重之取，岂执一义而尽之与**！

白话：**哪能只靠一条死规矩就包办一切呢！**——全书的方法论宣言。

**「4」 太过之戒（卷五引《黄金策》）**

> 原文：**太过者损之斯成，非云吉凶，断事之成合时也**。若曰用爻太过为不吉，则生扶拱合之语非矣。

白话：太过，是要"减损"才能成——**这不是吉凶问题，而是"合不合时宜"的问题**。如果一概说"用爻太过就是不吉"，那"生扶拱合"（旺相为吉）的话岂不自相矛盾？

**「5」 先卦后爻（卦验章）**

> 原文：婚姻忌三冲，则不索用神之旺衰；邦畿征伐忌内反伏而不凭子官……**此皆先卦而后爻也**。

白话：这五种情况，**先看整个卦（卦象级信号），再论具体爻位**——但要注意，这只是"五类例外"，不是普遍规则。

**「6」 卦象 vs 用神（卦验章注）**

> 原文：以卦名而断吉凶，昔贤所讥，然古又有以卦义断而验者，**不可违也**……**兼察用象更确**。

白话：单凭卦名断吉凶是被前人讥讽的，但古人确有靠卦义断而灵验的，**不能一概否认**——只是要**兼看用神才更确切**。

**「7」 学易之诫（自序）**

> 原文：学易之道，**专则纯，纯则精，精乃入神**；分则杂乱，杂乱则疏，疏乃不入。

白话：**专注 → 纯粹 → 精通 → 入神**。这是全书的方法论底色，也是给现代读者的第一忠告。

**「8」 占诫（占诫章，卷末）**

> 原文：卜者以诚，断者宜慎……**若谋人之成穴，破人之吉地，地理得而天心怒，鬼神所不告也**。

白话：**心存敬畏、不挟私、不破坏他人**——术的伦理底线。

---

**示例**：读「专则纯，纯则精，精乃入神」一句，对照自己断卦时「杂取多神」的毛病，即知该收束。

## 板块10 · 阅读路径建议（按读者类型分）

### 10_1 A. 零基础 / 想了解思想

1. 本笔记第一、二、六、十章（= 全书精华的 40%）
2. 原书**自序**（必读，全书方法论都在这篇自传里）
3. 卦验章（第40）、占诫章（第91）——**各读一遍即可**

### 10_2 B. 有六爻基础 / 想提升断卦深度

1. 原书**卷一至卷四通读一遍**（重点：卷二飞伏反伏、卷三日主月将、卷四真假辨析）
2. 配读《增删卜易》对应章节做**交叉验证**（尤其"动逢日冲"这类分歧点）
3. 按第五章 SOP **实占 50 卦 + 复盘**

### 10_3 C. 研究者 / 写论文

1. 对照《四库全书总目·易冒十卷》的批评，**逐条验证**（家宅、鬼神、诸星、婚姻四章）
2. 重点研究：**八节建旺与阴阳升降**（本书独有，是区别于其他六爻书的核心创新点，也是研究价值最高的部分）
3. 版本校勘：世界知识出版社 2011 整理本 vs 华龄出版社 2016《校正全本易冒》

### 10_4 通用提醒

+ **不要从头到尾线性读**。《易冒》是"类书"结构（分事立目），**按主题跳读效率更高**。
+ **每章只读"原文 + 注"，跳过大部分"补遗/阐幽"的层层叠加**——原书后人增补的部分正是被批评"穿凿支离"的来源。
+ **手边备三样**：六爻卦象图、十二长生表、天干地支五行表。缺工具硬读 = 读不懂自己负责。

## 板块11 · 结语：这本书真正教的是什么

程良玉五岁失明、十年学卜、五年茫然、十八岁始悟用爻、四十岁闭门三年成书、书成而卒。

**《易冒》真正教给后人的，不是三百七十余问的断语，而是三件事**：

1. **抓主变量的能力**（用爻）：任何复杂系统，都能找到**那一个**决定全局关系的核心变量。**找到它，比分析它更重要**。
2. **给判断加条件的习惯**（真假辨析）：**任何铁律都有反例，任何反例都指向一条边界**。真正的高手不是知道更多规则，而是**清楚每条规则的适用边界**。
3. **专注到极致的治学态度**（专则纯，纯则精，精乃入神）：在信息过载的时代，这是唯一能让你从"知道"抵达"入神"的路径。

最后一句实话：**《易冒》里能"算准"的部分，永远无法被科学验证；但"取用神、辨真假、先看系统再看细节"这三层思维，在任何领域都是可复现、可练习、可提升的决策能力。** 这才是这本书值得你花时间的地方。
