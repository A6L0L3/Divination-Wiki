# 板块17 · 修炼体系与复盘精进

> 技术学会只要三个月，判断力练出来要三年。

这一块讲的是技术之外的东西：**怎么练、怎么纠偏、怎么守住边界**。

## 17_1 总框架回顾：三层过滤与四大支柱

**三条纲领**（由粗到精的三层过滤，完整展开见 README 第三节）：生克定吉凶、旺衰定程度、动静定应期。

**四大支柱**：**世用为纲、动静为机、旺衰定基、空冲分久暂。**

```plain
三纲领的过滤顺序
┌──────────────────────────────────────┐
│ 第一层过滤：生克 → 筛掉明显吉凶      │
│ 第二层过滤：旺衰 → 细化程度          │
│ 第三层过滤：动静 → 锁定时间          │
└──────────────────────────────────────┘

```

**这套过滤顺序在修炼上的意义**：新手最容易跳层——还没用生克定性，就急着断日子。练到能**自觉按顺序走完三层**，才算真正入门。

## 17_2 修炼视角的四句话

前四句是"技术上的心法"（见 README 第五节），这里补上**修炼上**的四句：

1. **先求断对，再求看深**——一卦一断还没练熟，就去练一卦多断，只会两头落空。
2. **宁可给区间，不要编日子**——应期断不准是常态；给"近期 / 中期 / 远期"，比硬报一个日期诚实得多。
3. **反例比正例值钱**——断对的卦让你自信，断错的卦让你进步。**失败的卦例一定要单独归档**。
4. **边界比准确率重要**——疾病卦若导致延迟就医，断得再准也是严重误用。

## 17_3 五个成长阶段与各自的瓶颈

| 阶段 | 特征 | 典型瓶颈 | 突破方法 |
| --- | --- | --- | --- |
| **第一阶段：装卦期** | 还在查表，世应六亲常错 | 卦画反、六亲按人推不按宫推 | 手装 20 卦，形成肌肉记忆 |
| **第二阶段：套诀期** | 能装卦，开始背断语 | 见空断凶、见官鬼持世断凶 | 学"给断语加条件"，背反例 |

### 案例小故事：断对的卦让人高兴，断错的卦让人进步

**背景**：一位学六爻一年多的爱好者，陆陆续续断了近三十卦，自感"时准时不准"，准确率一直卡在一半上下，怎么也上不去。他一度怀疑是"自己没有天赋"，也试过换书、换流派，收效都很小。

**转折点**：有人问他一个问题——"你这三十卦，**回填了几卦**？"他翻翻档案，发现只有断对的卦被他记住了（因为高兴，会跟人讲），断错的卦大多丢在一边，连卦象都没留全。也就是说，**他一直在用一半的样本做自我评估，而且还是被"好事记牢、坏事遗忘"偏好的那一半**。

**他做的改变**：给自己定了三条硬规矩——

1. **断错的卦优先回填**，断对的卦只记一行。因为断对可能只是蒙对，断错才一定暴露真问题。
2. 每卦回填走三步：**验结果**（实际发生了什么）、**验取用**（用神是不是该这么取）、**验权重**（是不是把低层级的力量当成了高层级）。
3. 每月把失误归一次类，写进"**错误分类账**"。

**三个月后的发现**：把二十几个失误摆在一起看，分布其实非常集中——

| 失误类型 | 占比 | 典型表现 |
| --- | --- | --- |
| 用神取错 / 取偏 | 约六成 | 按身份标签取用，没有先画关系图 |
| 旺衰层级误判 | 约两成 | 把"三个休囚静爻生我"当成有力，忽略了临月建的忌神 |
| 应期硬编日子 | 约一成半 | 只取一条线索，不给区间 |
| 其他 | 约半成 | 情绪化起卦、一卦多问 |

**真正的收获**：他原本以为自己是"什么都学得不扎实"，需要从头再读一遍典籍。看完分类账才发现，**六成的失分集中在同一个动作上**——起卦后没有花时间确认用神，而是凭第一印象开断。他针对性地给自己加了一条前置流程：起卦后先写下"这件事里谁是主、谁是从、谁是被作用者"，写完再谈旺衰动变。

**应验**：这个改动不需要多读一本书，也不需要换流派。半年后他的自评准确率从五成上下升到七成以上，更重要的是——**他终于知道自己为什么会错**。

**要点提炼**：

+ **没有回填的卦，等于没断。** 断完不回填，得到的是一次情绪体验；断完回填，得到的才是一条可复用的经验。
+ 人的记忆天然偏心：断对的记得牢，断错的爱忘。**用制度对抗偏见**，这就是档案的意义。
+ 失误不是均匀分布的，往往集中在**一两个动作**上。找到那个动作，比多读十本书有效。
+ 复盘追问的终点永远是一句话：**"我当时为什么那么想？"** 而不是"卦为什么不灵"。

## 17_5 常见误判总表（贴在桌前，全库最完整版；板块 10_6 为其八条精简版）

| 常见误判 | 错在哪 | 正确做法 |
| --- | --- | --- |
| 见空就断凶 | 没分真假空 | 动空、旺空、填空、临日月 — 皆不作真空 |
| 见月破就断无解 | 把"最衰"当成"无救" | 破而有生扶、出月逢合可解 |
| 见官鬼持世就断凶 | 忘了查"药" | 子孙旺动克之，反为去病之吉 |
| 一上来就抓用神旺衰 | 跳过了卦象级信号 | 先看反伏、游归、六冲合，再看爻 |
| 卦名好就断吉 | 卦验凌驾于用神 | 用神为主，卦名为辅；冲突时从用神 |
| 六神定吉凶 | 修饰层当主断 | 六神需配六亲方成事象 |
| 数生克的个数定吉凶 | 只看数量不看链路 | 画路线图，看力量来源与权重 |
| 用神取了多个 | 一卦多问 | 一卦一事、一卦一用神 |
| 出行卦见"用神克世"断凶 | 不懂"物来寻我" | 出行卦中，用神克世主速归 |
| 求财只看财爻旺衰 | 忽略财源与损耗 | 财源（子孙）+ 损耗（兄弟）一起看 |
| 求职只看官鬼 | 忽略父母（文书） | 官鬼为职、父母为文，官父关系是关键 |
| 一卦多断当定论 | 层次混乱 | 主断从真六亲，延伸标明"参考" |
| 动卦去找互卦 | 顺序搞反 | 有动看变卦，六爻皆静才取互卦 |
| 每卦都找伏神 | 滥用扰主线 | 飞神不空不破，不必更取伏神 |
| 每卦都找卦身 | 备胎当常规 | 世爻不空，不看身爻 |
| 同一事反复摇卦 | 违背"渎言不占" | 一卦一结论，新变化才再问 |

## 17_7 三条边界：技术之上的约束（操作化清单见板块 0_2）

**边界一：不替代专业判断**

+ 健康问题，第一选择永远是就医；卦象只作"要不要再看医生"的辅助参考。**对方提到具体病症时，唯一正确的断语是建议就医。**
+ 法律纠纷，请咨询专业律师；六爻只作心理与策略层面的参考。
+ 金融决策，六爻可用于"投入此项目的风险与可能性"评估，**不能用于预测单只股票的明日涨跌**。

**边界二：不占邪妄、不窥隐私**

+ 不测违法、损人、窥探他人隐私之事。
+ **不占生死**，不替他人作重大医疗决策。
+ 代他人占问须明确"为谁问、问什么"，且心念专一；占的是"他这件事的走向"，不是窥探他的私事。

**边界三：不问不该问的**

+ 同一事反复占问（"再三渎，渎则不告"）。
+ 心神混乱、情绪激动、酒后不占。
+ 急到根本无法执行结果时别问——问了也不听，不如不问。

## 17_9 最后一句

卦象显示的是**当前趋势**，不是注定的结果；占卜给出的是**需要调整的方向**，不是不可更改的命运。

> 吉卦骄纵亦转凶，凶卦修德可转吉。

这套知识库能给你的，不是"预知未来"的能力，而是——**在信息不完整时，仍能结构化地拆解局面、识别矛盾、匹配资源、锁定时间节点**的思维方式。这既是古人留下的东西，也是今天仍然有用的东西。
