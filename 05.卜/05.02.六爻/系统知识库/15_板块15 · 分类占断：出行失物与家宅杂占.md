## 板块15 · 分类占断：出行失物与家宅杂占

> 本块收尾剩下的高频场景，并补上"天时、音信"等杂占速查。

共同原则不变：**先定用神 → 看旺衰动变 → 病药定论 → 定应期 → 记档案**。

---

### 15_1 出行与行人

**取用**：按出行者的六亲身份取用神（占丈夫归期取官鬼，占父母取父母，占子女取子孙）；父母爻为车船文书、行程凭证；世爻为出行者本人。

| 组合 | 断语 |
| --- | --- |
| 世爻发动 | 心意已决，出行顺利（"世或交重，两目顾瞻于马首"） |
| 父母爻旺相 | 交通工具、行程安排顺利 |
| **用神克世** | **"物来寻我"**——在外之人回家心切，即日将回（不可一概断凶） |
| 用神被克、入墓、旬空 | 出行不利、行人迟滞 |
| 游魂卦 | 主会动、出行在外 |
| 归魂卦 | 主不出疆界、不动或早归 |
| 用神在外卦（四五六爻） | 人在外地；在内卦（一二三爻）则人在本地 |
| 用神发动值三合 | 行人立回 |
| 遇节、艮、坎、明夷 | 出行不吉之卦 |
| 往亡煞 | 出行最忌；"出行最怕往亡，如系吉神终获利" |

**音信消息**：以父母爻为书信、朱雀为消息。**"雀动音书至"**——父母爻临朱雀发动，消息通知将至。若父母临朱雀化子孙（子孙克官鬼），则有"消息来拒绝"之象。

**应期**：用神生旺、墓库之时；问归来则**合日为归期**；用神克世则即日将回。

> **关键辨析**：出行卦里"用神克世"常被误断为凶。实际上这是"物来寻我"——对方（或行人）主动向我而来，恰恰是**速归之象**。场景不同，同一组合的吉凶完全相反。这正是"卦随事转"的典型例证（同类辨析见板块 10_6）。

### 15_2 失物与盗贼

**取用**：妻财爻为失物本身；官鬼爻为盗贼；子孙爻为搜寻破解之力。

| 组合 | 断语 |
| --- | --- |
| 妻财旺相、得生扶 | 可寻回 |
| 妻财休囚、入墓、旬空 | 难觅 |
| 妻财在初爻 / 内卦 | 物在近处、低处、家中 |
| 妻财在上爻 / 外卦 | 物在远处、高处、外边 |
| 官鬼发动 + 玄武临官鬼 | 主盗贼（**玄武需配官鬼方成盗贼**） |
| 妻财伏而飞神旺克 | 物被藏、难出 |
| 伏神空亡 | "空下伏神，易于引拔"，反易找到 |

**方向推断**（配合卦象类象与爻位，三重交叉）：

```plain
按妻财爻所在爻位，配合八卦方位推定：
  乾=西北  坎=正北  艮=东北  震=正东
  巽=东南  离=正南  坤=西南  兑=正西

```

**应期**：妻财出空、逢合、被冲开之时。

#### 案例小故事：用神克世，为什么反而是"马上就回"

**背景**：一位女士的丈夫去邻市出差，原定三天，结果第五天还没回来，电话也打得少——打过去有时通有时不通，说"在忙"，没说几句就挂了。她心里发慌，担心路上出事，起卦问"丈夫何时归来"。

**卦象**：按六亲身份取用神——占丈夫归期，取**官鬼**为用神（女测婚以官鬼为夫）。卦中官鬼爻**克世爻**。

**第一反应（错的）**：用神克世，按一般理解是"用神来伤我"，这是凶象。她一听就慌了，以为丈夫出了什么事，当天下午又想去报警。

**正确的推演**（三层）：

1. **辨场景**：这是**出行 / 行人卦**，不是疾病卦、不是官非卦。同一个"用神克世"，落在不同场景里含义完全不同。断卦第一步是"审卦定坐标"（板块 10_2），这一步错了，后面全白搭。
2. **记断语**：古诀对行人卦有专门一条——"**用神克世，物来寻我，即日将回**"。意思是：对方（行人）主动向我而来，这恰恰是**速归之象**，不能一概以凶断。
3. **看佐证**：卦中用神在**外卦**（人在外地 ✓ 与事实相符），且临日辰，说明"当下即得时"；父母爻（车船、行程）旺相不受克，说明行程本身没有阻碍，不是"被困在路上"。

**结论**：不是凶，是**即日将回**——人已经在路上，或当天就会有消息。断卦者还加了一句：如果晚上八点前没到家，那就是路上耽搁了（比如堵车、绕路），但仍不是凶象。

**应验**：当天傍晚丈夫就到家了。原因是返程那天邻市下雨，高速封了一段，他改走国道绕远，手机在山区信号断断续续，所以既晚归又联系不上。人没事，车也没事。

**要点提炼**：

+ 这条反直觉的规则说明——**同一组合，场景不同，吉凶完全相反**。这正是"卦随事转"的典型例证。
+ "用神克世"在疾病卦可能主病来伤身，在**行人卦却是"物来寻我、速归"**。
+ 断卦时，**先定卦种（问的是什么事）** 是第一步。
+ 断卦者那句"晚上八点前没到就是路上耽搁"，把结论变成了一个**可验证的判断**，而不是一句安慰——这正是应期推断该有的样子。
+ 反过来看：如果这一卦被误断为"凶"，她当天下午去报警，那就是**由误读引发的错误行动**。

### 15_3 词讼与官非

**取用**：官鬼爻为官方、法官、裁决方；世爻为我方；应爻为对方。

| 组合 | 断语 |
| --- | --- |
| 世旺应衰 | 我胜 |
| 世应相生 | 可望和解 |
| 官鬼生世克应 | 官方倾向我方 |
| 官鬼受制、墓绝 | 官司消解 |
| 遇大壮、夬 | 得理 |
| 遇坎、蹇、明夷 | 有囹圄之忧 |
| 遇讼卦 | 宜退不宜进，争之不足、谦有余 |

**应期**：官鬼墓绝、受制之时为事了之期。

> **理性边界**：真正的法律纠纷，请咨询专业律师。六爻在此只作**心理与策略层面的参考**（见板块 0_2、17_7）。

### 15_4 家宅与坟墓

**取用**：父母爻为房屋、宅舍；**二爻为宅爻**；妻财为家财；官鬼为灾病纠纷；子孙为福气人丁。

| 组合 | 断语 |
| --- | --- |
| 父母旺相、生合世爻 | 家宅安宁 |
| 官鬼发动克世 | 宅有不宁、灾病或纠纷 |
| 二爻受克 | 房屋本身有问题 |
| 游魂、八纯 | 主离乡、人丁孤寒 |

**风水卦忌**（纵世与子孙皆旺亦不为吉）：

```plain
巽（风）  坎（水）  乾（石）  兑（沙）
离（蚁）  蛊（虫）  井（泉）  明夷（伏尸）

```

> **提醒**：古书"家宅章"中"以六爻兼断六亲荣枯"（兄弟旺则劫财、父母旺则克子之类），逻辑链条过脆，历来有争议。**实操只取"宅爻受克""官鬼动克世"等主干判断，不照搬六亲荣枯公式。**

### 15_5 天时与其他杂占速查

| 所占 | 取用 | 要点 |
| --- | --- | --- |
| **天时晴雨** | 父母爻（云雨遮蔽）为雨，子孙爻（晴）为晴，另参火爻 / 水爻 | 晴看火爻生旺、雨看水爻生旺；乾、离主晴，坎、兑主雨 |
| **音信消息** | 父母爻（书信）、朱雀 | "雀动音书至"；父母临朱雀化子孙 → 消息来拒绝 |
| **借贷** | 妻财（能否收回）、应爻（借方） | 财空破 + 应克世 → 难收 |
| **学业考试** | 父母爻（成绩文书）、官鬼（功名） | 父旺官兴则成；父空则"事无头绪" |
| **六甲生产** | 子孙爻 | 应期看子孙的帝旺、长生、沐浴、胎养之地 |
| **六畜田禾** | 子孙爻（禽畜）、妻财（收成） | 子孙旺则兴旺，兄弟动则损耗 |
| **趋谒求事** | 应爻（对方）、官鬼（掌权者） | 应生世则见得着、办得成 |

### 15_6 场景笔记方法：出行、失物、词讼、家宅的专用记录模板

**出行 / 行人卦档案**（追加在通用档案之后，通用档案见板块 10_5）：

```plain
──── 出行行人专项 ────
问事类型：□我出行 □等人归来 □找人
用神（按身份取）：______  所在：□内卦（本地） □外卦（外地）
用神克世检查：□是（物来寻我，主速归） □否
父母爻（车船文书）：□旺相 □受克
卦性：□游魂（会动） □归魂（不动/早归）
忌卦检查：□节 □艮 □坎 □明夷
应期推断：合日为归期 / 用神生旺之时
实际结果：______________（事后回填）

```

**失物卦档案**：

```plain
──── 失物专项 ────
失物类别：__________
妻财（失物）：□旺相 □休囚 □入墓 □旬空
位置：□初爻/内卦（近处低处家中） □上爻/外卦（远处高处外边）
方位（八卦）：______方
是否伏藏：□否 □是 → 飞神：□克伏（难出） □生伏/空（易引拔）
盗贼象：□官鬼动 + 玄武临官鬼 □无
应期推断：出空 / 逢合 / 被冲开之时
实际结果：______________（事后回填）

```

**词讼卦档案**：

```plain
──── 词讼专项 ────
我方（世）：□旺 □衰   对方（应）：□旺 □衰
官鬼（官方）：□生世克应（倾向我方） □受制墓绝（可消解） □旺克世
卦名参考：□大壮/夬（得理） □坎/蹇/明夷（囹圄） □讼（宜退）
边界提示：本卦仅作策略参考，法律问题务必咨询律师。
实际结果：______________（事后回填）

```

**家宅卦档案**：

```plain
──── 家宅专项 ────
问事类型：□宅运 □搬迁 □修造 □坟茔
父母（房屋）：□旺相生世 □受克
宅爻（二爻）：□受克（房屋本体有问题） □安
官鬼：□发动克世（不宁） □安静
卦性：□游魂/八纯（离乡孤寒） □其他
风水忌卦检查：□巽 □坎 □乾 □兑 □离 □蛊 □井 □明夷
实际结果：______________（事后回填）

```

### 15_7 杂占场景的验证要点

**出行卦**：验证"用神克世 = 速归"这条反直觉规则是否在你手上成立；统计游魂 / 归魂的命中率。

**失物卦**：验证"伏神空亡易引拔"是否应验；统计方位推断的偏差有多大（这一项通常最难，建议只作参考而非定论）。

**词讼卦**：验证"官鬼生世"与实际裁决倾向的相关性；**务必记录是否守住"咨询律师"的边界**。

**家宅卦**：验证"二爻受克 = 房屋本体问题"的命中率；对"六亲荣枯"类公式保持怀疑，单独标注。

> **通用验证法**：每类场景积累到 **10 卦以上**再做统计，样本太小时的任何"规律"都可能是巧合。
