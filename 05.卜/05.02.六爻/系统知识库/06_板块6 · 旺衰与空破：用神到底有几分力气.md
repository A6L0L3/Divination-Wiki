## 板块6 · 旺衰与空破：用神到底有几分力气

> 用神取定之后，第一件事不是看生克，而是看它**有没有力气**。

一个旺相的用神被克，可能只是波折；一个休囚的用神得生，也可能只是"扶不起"。

---

### 6_1 日月为纲：月建与日辰的分工

| 维度 | 月建（月令） | 日辰 |
| --- | --- | --- |
| 比喻 | 皇帝，掌一月之权 | 宰相，掌一日之权 |
| 主要职能 | 定旺相休囚、定**月破** | 定生克冲合、定**旬空**、定墓绝 |
| 时间尺度 | 一个月（长期、大趋势） | 一天（近期、当下） |
| 口诀 | "爻得月建为苗壮" | "爻得日辰为根重" |
| 经典表述 | "月建乃万卦之提纲" | "日辰为六爻之主宰" |

**权重排序**（综合各家）：**日辰最重，月建次之**；岁君（太岁）主一年以上远应，时辰主近应细节。

关于"日重还是月重"，各派有细微差异。**实操建议**：

+ **月建定旺衰级别**（它是长期基调，"司一月之权"）
+ **日辰定当下状态**（它能生克冲合、能救能破，"定一日之夺予"）
+ **近期事重日辰，长远事重月建**

**判定原则**：

```plain
用神得月建或日辰生扶 → 旺，有力，事易成
用神被月建或日辰克伐 → 衰，无力，多阻难成
用神生月建或日辰     → 泄气，略衰（我在消耗自己）
用神克月建或日辰     → 徒劳无功，平（"爻伤日，徒受其名"）

```

> **一句极关键的断语**："**爻伤日，徒受其名；日伤爻，真罹其祸。**"——爻去克日辰（等于凡人冲撞皇帝），有名无实；日辰来伤爻，才是真灾。这条常被忽略，却是判断"凶到什么程度"的关键。

**一个高频情形**：月令生合用神，而日建克制用神，这叫"月生日常"——事情在月内虽有波折，但最终能成。此时的应期，应选在**日建转而生旺用神**的时日。

### 6_2 力量层级：谁的话更算数

这是初学者最常翻车的地方。同样是两个爻相克，参与的"层级"不同，分量完全不同：

```plain
月建、日辰  >  动爻  >  变爻（仅作用于其原动爻）  >  静爻

```

**四条规则**：

1. **月建日辰可生克卦中所有爻，但爻无法反作用于月日**。这是绝对权威。
2. **动爻可生克静爻，静爻不能生克动爻**。主动权在动的一边——"静受动伤，静难制动"。
3. **变爻只作用于它所对应的那个原动爻**（回头生、回头克），不直接作用于其他爻。
4. **旺相之爻可压制衰弱之爻**；但若衰弱之爻得日月生扶，可以逆转局势。

**一个极易忽略的细则**：动爻若被日辰合住（如寅木动而遇亥日，寅亥合），则**暂时失去生克权**，需待冲开之日方能发力——这既是"事被绊住"的象，也是应期的关键线索。

```plain
力量权重示意（画路线图时用来决定线条粗细）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  月建 / 日辰    ══════  粗线（绝对权威）
  动爻           ──────  中线
  变爻（回头）    ┈┈┈┈┈  虚线（只作用于原动爻）
  静爻           ······  细线（被动）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```

### 6_3 旺相休囚死：五档判定

以月建（月令）五行为基准：

| 状态 | 定义 | 与月建的关系 | 力量 |
| --- | --- | --- | --- |
| 旺 | 当令 | 爻与月建五行相同 | 最强 |
| 相 | 被月建生 | 月建生爻 | 次强 |
| 休 | 生月建 | 爻生月建（泄气） | 中 |
| 囚 | 克月建而被耗 | 爻克月建（费力不讨好） | 弱 |
| 死 | 被月建克 | 月建克爻 | 最弱 |

> 五档与板块 1_2"四时旺衰速查表"是同一套标准的两种写法，可互查。

**配合日辰的简易四档判定表**（实操速用）：

| 用神状态 | 月建 | 日辰 | 结论 |
| --- | --- | --- | --- |
| 最旺 | 临月建 | 临日辰 | 旺上加旺 |
| 旺 | 临月建 | 日生 | 有根有力 |
| 相 | 月扶 | 临日辰 | 得时得地 |
| 休囚 | 月克 | 日克 | 无根无助 |
| 有救 | 月克 | 日生 | 休囚有气，先难后易 |
| 大凶 | 月破 | 日克 | 衰败已极 |

**实操简化法（粗筛三档）**：**旺相主多、休囚主少、空绝主无**。初学时先用这三档粗筛，不必一上来就陷入精细计算。

### 6_4 十二长生在旺衰中的实操

只抓**长生、临官（禄）、帝旺**三个旺位，与**死、墓、绝**三个衰位（完整表格见板块 1_5，此处不重复）。

**三条实用规则**：

1. **日重绝、月重克**：爻在日辰上的生绝，权重大于在月建上的生绝。
2. **伏爻的生绝看飞爻，动爻的生绝看变爻**——类比于"日"的用法。
3. **"旺相不拘于墓绝，休囚最怕入墓乡"**：用神旺相，入墓只是暂时受阻；用神休囚又入墓，是真困境。

### 6_5 月破、日破与旬空

**月破**：爻的地支与月建地支相冲。

> **原文校准**：《增删卜易·月破章》：「**月建冲之为月破**，逐月之破日，是也。」
> 同章引《易林补遗》：「如临月破之爻，**不拘衰旺，概作凶推**。」
> 即原典定义**不含"休囚无气"这一附加条件**，且明确"不拘衰旺"。
> 本库此前所加的"且该爻休囚无气"无原文依据，现删去。

```plain
月破对照：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
例：寅月占卦，卦中申金之爻即为月破

```

月破是"最严重的衰"，如同根基被毁。但**不是绝对无解**——古法"月破无解"过于苛刻，正确标准是：破而有生扶、待出月或逢合可解；若同时入墓、化绝、真空，才是真破。

**日破**：**衰弱之静爻**被日辰冲，为日破，主该爻无用、事难成。

> **原文校准**：《增删卜易·日辰章》：「**冲旺相之静爻，即为暗动，冲衰弱之静爻，则为日破**。
> 爻旺而动，冲之愈动；**爻衰而动，冲之则散**。」
> 原典把"日破"（衰弱**静**爻被冲）与"散"（衰弱**动**爻被冲）**分列两事**。
> 本库此前把日破定义为"动爻被冲"，与原文不符，现据原典改正。

**旬空**：爻的地支落在当旬空亡之中（旬空推算见板块 1_4）。

```plain
用神逢空 → 暂时无力，待出空、填实应事
忌神逢空 → 不凶（坏事落空反而是好事）

```

**不作空论的情形**（极重要，很多人见空就断凶）：

+ 月建值旬空（建空）——月建不为空
+ 日辰相冲（冲实、填空）
+ 动爻值空（动空、动不为空）
+ 旺相有生扶（填实）
+ 伏神旬空反易引拔（"空下伏神，易于引拔"）

### 6_6 真假空、真假破：给断语加条件

这一节是把前人当铁律的话**都加上反例**。这是提升准确率上限的核心方法：

| 前人铁律 | 修正后的理解 |
| --- | --- |
| 随鬼入墓 = 凶 | 亦有**不凶**（须看用神根基、墓中是否有救） |
| 助鬼伤身 = 凶 | 亦有**不凶**（仇神被制时反成吉） |
| 绝处逢生 = 吉 | 亦有**不吉**（原神虚浮、生之无力） |
| 月破无解 | 破而有生扶、待出月逢合可解 |
| 旬空即无用 | 有真假之分，动空、填空、旺空皆不作真空 |
| 伏神不论旬空 | 非"不空"，而是轻重与空否无关 |
| 爻临日辰逢空不空 | 应严格限定为"用神**静爻**临日辰"这一种情况 |

**三条自检提问（养成这个习惯，准确率上限才会被打开）**：

1. 这是**真**还是**假**？（真空 vs 假空、真破 vs 假破）
2. 谁是元神、谁是忌神、谁是仇神？
3. 这条断语有没有**反例条件**？

> **读古书务必带"顶门上一只眼"**——规则要带条件，不要当绝对真理。

#### 案例小故事：同样"用神旬空"，两个相反的结果

**背景**：旬空是六爻里最容易"一刀切"的地方——很多人记住一句"空 = 没有 = 不成"，见空就断凶。下面两卦，用神都旬空，结局却完全相反。差别不在"空不空"，而在**空的是什么状态的空**。

**例一：货款能收回（假空）**

某人问一笔货款能否收回。对方是一家合作过三次的老客户，这次拖了两个月。卦中妻财爻旬空。细看：**妻财发动**，且得日辰生扶。

按"不作空论"的清单逐条核对——动爻值空（动不为空）✓、旺相有生扶（填实）✓。判定为**假空**，出空则应。

**应验**：后果于出空之月收回货款，对方一次性结清了本金，只是抹掉了一小笔尾数。

**例二：投资打了水漂（真空）**

另一人问一笔投资的回报。他把钱投给一位朋友做短视频代运营，约定按季度分红。卦中妻财爻同样旬空。但细看：**妻财安静休囚**，又被月建克。

按清单核对——不动 ✗、休囚 ✗、无生扶 ✗，且被月克。判定为**真空**，难成。

**应验**：后果然投资失败，第一季度的"分红"是朋友自掏腰包垫付的，第二季度项目停摆，本金也只退回一部分。

**差别在哪**：前者是"动空 + 旺空"，后者是"静空 + 衰空"。同样是"空"字，用神的**动静**与**旺衰**决定了这个空是"暂时的"还是"根本的"。

**要点提炼**：

+ **见空就断凶，是新手最常见的教条错误**。
+ 判断空的口诀只有一句：**动空不为真空，旺空不为真空，临日月不为真空，被冲实不为真空。**
+ 反过来，静爻 + 休囚 + 无生扶 + 被月克，才是真真空。
+ 判断顺序固定为"**先查动静、再查旺衰、最后查有无解救**"，不要一上来就给结论。

### 6_7 旺衰不是数数：四条反直觉的判定

1. **生我的多，不一定吉**。要看用神与世爻的**联动关系**，而不是简单统计生克的数量。
2. **量变引起质变**：火多可以水干，土重可以木折，金多可以火熄，水多可以土荡，木多可以金缺。帮手过多反而"太过"，需损之方成。
3. **太过与不及是同一枚硬币**："夫人有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。" 用神太旺要克泄，太弱要生扶——这既是断卦原则，也是应期的逻辑起点。
4. **卦气纯不纯影响应期**（现代人最容易忽略）：有些卦虽然用神旺相，但卦中杂气太多（忌神、仇神交错），这叫"气不纯"。气不纯则事必拖延，此时的应期必须等到杂气被肃清（即忌神受制）的时候。

### 6_8 旺衰速判流程图

```plain
第一步：看月建
  ├ 用神临月建 / 得月生 → 旺
  ├ 用神被月克         → 衰
  ├ 用神与月建相冲     → 月破（大凶，查有无解救）
  └ 用神生月建         → 泄气

第二步：看日辰
  ├ 用神临日辰         → 得时，最实
  ├ 日辰生用神         → 有救（月衰日生，先难后易）
  ├ 日辰克用神         → 雪上加霜
  ├ 日辰冲用神（静爻旺相） → 暗动，反而有用
  └ 日辰冲用神（衰弱静爻） → 日破，事不成
  └ 日辰冲用神（衰而动）   → 冲散，事不成

第三步：看旬空
  ├ 用神旬空 + 旺相/发动/临日月 → 假空，出空则应
  └ 用神旬空 + 休囚无气         → 真空，难成

第四步：看卦气纯杂
  └ 忌神仇神是否交错为患 → 气不纯则事拖延

第五步：综合定档
  旺 / 相 / 休囚 / 空破  →  写入断卦记录

```

### 6_9 旺衰实操演练

**演练题**：问本月报价能否签下。卦中妻财爻为酉金，起卦于**卯月、巳日**。

```plain
第一步 看月建
  卯月，酉金与卯相冲 → 酉金月破！
  且卯月木旺金衰，酉金不得月令 → 根基已损

第二步 看日辰
  巳日，巳火克酉金 → 日辰克用神
  但巳与酉无冲，巳酉丑三合（丑不在卦中则不成局）
  判定：月破 + 日克 → 大凶之象

第三步 看旬空
  巳日属甲辰旬？查出旬空为寅、卯 → 酉不空
  判定：不空

第四步 找"药"
  卦中若有丑土或辰土发动生酉金 → 有救（土生金）
  若有巳火动而合酉（巳酉丑三合） → 合中有情，但合也主绊
  若财爻化退神 → 更凶

第五步 结论
  病：财爻月破 + 日克（病重）
  药：视卦中是否有土爻发动生金、或日辰流转至生金之时
  若无药 → 此单难成，或需大幅让价
  应期：月破者，出月或逢合之期（酉与辰合，辰月/辰日）

```

> **演练要点**：旺衰判断不是孤立地"数生克"，而是**把月、日、空三层叠加后定档**，然后立刻去找"药"。**定档和找药是连着做的两件事**，不要等定完档再回头找。
