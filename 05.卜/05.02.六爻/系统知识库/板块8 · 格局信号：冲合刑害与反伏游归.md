# 板块8 · 格局信号：冲合刑害与反伏游归

> 用神旺衰是"小天气"，格局是"大气候"。

先看卦，后看爻——遇到卦象级信号，它的优先级高于用神旺衰。

---

## 8_1 六合与六冲：成与散的两种基调

| 关系 | 含义 | 断法 |
| --- | --- | --- |
| **合** | 相合和好、牵绊、聚拢 | 合则成、则缓、则解；但也可指"被绊住" |
| **冲** | 相冲散乱、对立、变动 | 冲则散、则急、则变；但也可指"冲开解救" |

**六合**：子丑、寅亥、卯戌、辰酉、巳申、午未
**六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥

**六冲卦共十卦**（实操必须记住）：

```plain
八纯卦：乾为天、坎为水、艮为山、震为雷、巽为风、离为火、坤为地、兑为泽
另加：天雷无妄、雷天大壮

```

**六冲的双向解读**（关键，不可一概断凶）：

| 情形 | 六冲的含义 |
| --- | --- |
| 短期琐事、近病、临时纠纷 | **吉**——冲散了病气、是非、阻碍 |
| 久病、长远之事、求合作 | **凶**——冲散了元气、缘分、基础 |
| 用神被冲 | 散、急、变；若用神旺相，冲反为动 |
| 忌神被冲 | **吉**——坏事被冲散 |
| 六冲化六合 | 先散后成，先难后易 |
| 六合化六冲 | 先成后散，合作易破裂 |

**合的三种形式**：

+ **日月合爻**：日辰或月建合住某爻，该爻被"绊住"，暂时不能发挥作用（动爻被合则失去生克权）。
+ **爻与爻合**：两爻相合，主纠缠、牵绊、结合。
+ **动爻化合**：动而化出与自身相合之爻，主"被合住"，事有羁绊、应期推迟。

**核心断语速记**：

```plain
"合遭破以无功"      → 合局被冲破，白搭
"动值合而绊住"      → 动爻被合住，事不成、事被拖
"静得冲而暗兴"      → 静爻旺相被日冲，暗中发动
"空逢冲而有用"      → 空爻被冲实，反而有用
"自空化空，必成凶咎" → 真空，大凶
"墓中人，不冲不发"  → 用神入墓，待冲墓之日方发
"身上鬼，不去不安"  → 官鬼持世，不去之不安宁

```

## 8_2 三合局：成局则力量倍增

**四组三合局**：

```plain
申子辰 → 合水局
亥卯未 → 合木局
寅午戌 → 合火局
巳酉丑 → 合金局

```

**成局条件**（三条缺一不可）：

1. 三个地支**齐全**（卦中有、或动爻化出、或日月补上）
2. 其中至少有**一个动爻**
3. 不被冲破、不被刑伤

**断法要点**：

+ 三合局成，**力量倍增**，主导全卦吉凶走向。
+ 合局生用神 → 大吉；合局克用神 → 大凶。
+ 三合局也常用于**定应期**：成局之期，或局中某一支值日之时。
+ **缺一不成局**："并不并，冲不冲，因多字眼"——字面看着像，实际地支不齐全，就不能按合局断。

## 8_3 三刑与六害

**三刑**：

```plain
寅巳申 → 无恩之刑
丑戌未 → 恃势之刑
子卯   → 无礼之刑
辰午酉亥 → 自刑（辰见辰、午见午、酉见酉、亥见亥）

```

**六害**：子未、丑午、寅巳、卯辰、申亥、酉戌

**断法要点**：

+ 三刑主伤残、纠纷、官司、内部消耗。刑比普通克更烈，带有"纠缠、折磨"的性质。
+ 六害主暗损、阻碍、小人、不顺利，力量弱于三刑。
+ **刑害是辅助判断**，不能凌驾于生克之上。用神旺相，纵有刑也只是波折；用神休囚又逢刑，才是真凶。

## 8_4 反吟与伏吟：卦象级的凶险信号

这是最需要优先处理的"卦象级"信号，优先级**高于用神旺衰**。

| 类型 | 定义 | 象意 | 典型表现 |
| --- | --- | --- | --- |
| **伏吟** | 动爻化出**相同**地支（子化子、丑化丑）；或同类两卦相见 | 凝滞、呻吟、胶着难进 | 占病缠绵难愈、占讼久拖不决、求财无门、内心忐忑 |
| **反吟** | 动爻化出**相冲**地支（子化午、丑化未）；或内外卦相冲 | 反复、倾覆、动荡不安 | 占出行半途而返、占事业升迁反复、占事反复折腾 |

**卦犯 vs 爻犯**（关键区分）：

+ **卦犯反吟**：内外卦相冲，共四组——乾↔巽、坎↔离、艮↔坤、震↔兑。
+ **爻犯反吟**：动爻化出相冲地支。
+ **爻犯重于卦犯**：古诀云"此八卦皆内外反吟也，其祸犹轻；惟独变出反吟，其凶最重"。伏吟同理，爻犯更重。

**四条实操规则**：

1. **反吟伏吟一律论凶，不论吉**——但凶的程度看用神是否有救。
2. **用神旺而逢反伏**：吉事也多波折，事成而反复。
3. **用神衰而逢伏吟**：凶事难解，事情停滞不前。
4. **先看卦，后看爻**：遇到反吟伏吟，先处理这个卦象级信号，再谈用神旺衰。

> **现代类比**：伏吟主"静而不发"（郁），反吟主"动而反复"（乱）——恰好对应项目管理里的两种失败模式：**卡死 vs 来回摇摆**。

## 8_5 游魂与归魂：动与守的两种卦性

| 卦性 | 世爻位置 | 象意 | 占断要点 |
| --- | --- | --- | --- |
| **游魂卦** | 世在四爻 | 无定、心神不宁、出行、居无定所 | 占出行、迁徙遇游魂，反而是"会动"的信息 |
| **归魂卦** | 世在三爻 | 回归、安定、守旧、不出远门 | 占久居、守业遇归魂为吉；占出行则主不动或早归 |

**八宫游魂归魂卦一览**（完整八宫表见板块 2_3）：

| 宫 | 游魂卦 | 归魂卦 |
| --- | --- | --- |
| 乾 | 晋 | 大有 |
| 震 | 大过 | 随 |
| 坎 | 明夷 | 师 |
| 艮 | 中孚 | 渐 |
| 坤 | 需 | 比 |
| 巽 | 颐 | 蛊 |
| 离 | 讼 | 同人 |
| 兑 | 小过 | 归妹 |

**关键提醒：注意与事体"反向取义"**。游魂卦占出行是吉（会动），占久居是凶（不安定）；归魂卦占守业是吉，占出行是凶（走不成）。把"游魂=凶、归魂=吉"简单化，是错的。

```plain
判断句式（照着套就不会反）
  这件事需要"动"吗？
    需要（出行、跳槽、搬迁）→ 游魂吉、归魂凶
  这件事需要"定"吗？
    需要（守业、久居、等结果）→ 归魂吉、游魂凶

```

## 8_6 四个经典名目的真伪辨析

古籍反复讨论的四个名目，是断卦中最容易"一招错"的地方。每一个都有反例：

| 名目 | 定义 | 通行断法 | 反例与条件 |
| --- | --- | --- | --- |
| **随鬼入墓** | 用神（或世爻）为官鬼，且入墓 | 凶，主困顿、难脱身 | 若用神根基旺相、墓中有救（有动爻冲墓、有日月生扶），**亦有不凶** |
| **助鬼伤身** | 忌神生官鬼，官鬼克世 | 凶，主雪上加霜 | 若仇神（生忌神者）被制，忌神无力生鬼，**亦有不凶** |
| **绝处逢生** | 用神化绝，但得他爻生扶 | 吉，主绝处逢生 | 若原神虚浮无力、生之不动，**亦有不吉** |
| **合处逢冲** | 用神被合，又被冲破 | 凶，主已成之事被破坏 | 若合为忌神之合，冲开反而是**吉** |

**通用解法**：遇到这四个名目，不要直接套断语，先做三问——

1. 用神本身的**根基**如何（旺还是衰）？
2. 生扶或克制的**力量来源**是什么（日月、动爻还是静爻）？
3. 有没有**解救因素**（冲墓、制忌、出空、逢合）？

### 案例小故事：郭璞"晋之剥"占妇梦

**背景**：郭璞为一位妇人占梦。妇人自称连日梦见怪异景象——梦里有光、有响动，醒来后心神不宁，怕是冲撞了什么，求占吉凶。起卦得**晋之剥**（本卦晋，变卦剥）。

**推演四层**：

1. **卦性定性质**：晋是**游魂卦**（乾宫游魂）。游魂主梦、主心神外驰、主不安定——这一层先定下了"梦"的性质，说明此梦并非外界实祸，而是心神层面的扰动，不是"被什么东西缠上了"。
2. **卦名定象**：晋有"进、日出地上"之象，是光明上升之卦。说明梦中景象虽怪，但性质不凶，且有"火、光、上升"的意象。
3. **飞伏定内容**：剥卦的伏神为**壬午火鬼**——**火象**，且是官鬼（主怪异、忧患）。
4. **地支类象佐证**：午在十二地支生肖中为**马**，火性炎上，主"行、走、升"。

**三层合参**：游魂定"这是梦"，晋卦定"火、光、上升"，伏神午火鬼定"梦中出现火"——

**结论**：断其人必梦见**火发，或乘马走**。

**应验**：郭璞《洞林》所收皆为其生平**筮验**之事，此例得以留存，正因其断语与妇人所梦相合——梦中景象确实落在"火"与"行"上。这也说明：**游魂卦主梦，这一条不是玄谈，而是可以在实占中反复核对的经验规则**。

**迁移到今天的用法**：遇到"说不清是什么性质的怪事"时，按这条链路走一遍——

```plain
第1步 卦性（游魂/归魂/八纯）→ 定"这件事属于哪一类"
第2步 卦名卦义             → 定"它的基本形象是什么"
第3步 飞伏                 → 定"具体是什么东西/什么内容"
第4步 世应六亲             → 定"对谁有利、应在谁身上"

```

**要点提炼**：

+ 这一例把"卦性（游魂）+ 卦名（晋）+ 伏神（午火鬼）"三层叠用，正是"**先看卦、后看爻、再查伏**"的完整演示。
+ 若一上来只抓世应六亲，是断不出"梦见火或马"这种具体内容的。
+ **卦象给"性质"，伏神给"具体内容"**——这是象法与理法配合的典型。
+ 结局也值得注意：断为梦境，不是灾祸，妇人不必去"做法事"——**卦象的第一价值常常是"先把性质定对，避免做错动作"**。

## 8_7 特殊格局的优先级总表

当一张卦同时出现多个特殊信号时，按以下顺序处理：

```plain
第1步 反吟 / 伏吟（卦象级，最优先）
第2步 游魂 / 归魂（卦性级）
第3步 六冲卦 / 六合卦（卦体级）
第4步 三合局成局（力量倍增）
第5步 月破 / 真空（用神根基级）
第6步 入墓 / 化绝 / 化退（用神趋势级）
第7步 三刑 / 六害（辅助级）
第8步 六神 / 神煞（修饰级，最后参考）

```

**这条优先级表是断卦卡住时的收敛工具**。回头按这个顺序过一遍，通常能找到被忽略的主线。

> 使用方式：不是每卦都要从1.查到8，而是**当你发现多条线索互相打架、断不下去时**，按这个顺序重新排序，取最高层级那条作主线。

## 8_8 格局自检清单

| 检查项 | 自问 |
| --- | --- |
| 合冲 | 卦中有没有六合、六冲？是不是六冲卦？ |
| 三合 | 有没有三合局？地支齐全吗？有动爻吗？ |
| 刑害 | 三刑六害需不需要参考？（用神旺则只作波折论） |
| 反伏 | 有没有反吟 / 伏吟？卦犯还是爻犯？ |
| 游归 | 是游魂还是归魂？与所问之事是顺取还是反取？ |
| 名目 | 有没有随鬼入墓、助鬼伤身、绝处逢生、合处逢冲？反例条件查了吗？ |
| 优先级 | 多个信号同时出现时，按优先级表排过序了吗？ |
