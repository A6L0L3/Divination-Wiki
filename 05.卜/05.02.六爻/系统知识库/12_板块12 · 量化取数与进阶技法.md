## 板块12 · 量化取数与进阶技法

> 前十一块解决"成不成、何时成"。这一块解决两个进阶问题：

**一是"有多少"（取数法），二是"还能看出什么"（一卦多断、真假六亲、互卦、升降、卦身）。**

---

### 12_1 取数法：从"能赚钱"到"赚多少"

取数法是传世典籍中透露最多的量化技法。学会它，才能从"能赚钱"进步到"赚多少"。

**干支五行先天数口诀**（必背）：

```plain
甲己子午九，乙庚丑未八
丙辛寅申七，丁壬卯酉六
戊癸辰戌五，巳亥常加四

```

即：甲/己/子/午 = 9，乙/庚/丑/未 = 8，丙/辛/寅/申 = 7，丁/壬/卯/酉 = 6，戊/癸/辰/戌 = 5，巳/亥 = 4。

**实操步骤（以"贫富章"为例）**：

```plain
1. 取财爻纳甲：以本宫出现的财爻为主；不现则取伏财；卦有二财则兼取
2. 财爻干支数字相加
   例：乾卦二爻甲寅为财 → 甲九 + 寅七 = 16
3. 依旺衰定倍数（见下表）
4. 加减调节项（见下）

```

**倍数层级表**（以基数 16 为例）：

| 层级 | 进位规则 | 以 16 为例 |
| --- | --- | --- |
| 大富 | 十进千、六进百 | 一万六千 |
| 中富 | 十进百、六进十 | 一千六百 |
| 下富 | 十进十 | 一百六十 |
| 小户 | 按一水二火三木四金五土之数，一进十 | 如寅木财为木三数 → 三十 |

**关键调节项**：

+ **旺相加倍，休如数，囚死减半**
+ 太岁贵马福禄聚于财爻 → 更益一倍；月建聚 → 更益半
+ 太岁刑破财爻 → 减半；月建刑破 → 减三分之一
+ 爻与宫俱空破死绝 → 纵有厚积，亦将散尽

**现代迁移**：取数法的真正价值不在"算钱"，而在提供**"量"的维度**。可迁移到合同金额区间、工期天数、人数、距离等一切量化场景。

> **务必先用旺衰定"量级"（十 / 百 / 千 / 万），再算具体数**。量级错了，具体数算得再准也没意义。

#### 附：把取数法迁移到现代场景

古籍的量级档位是为其时代的经济规模设定的，直接照搬会失真。迁移时要做两步转换：**先把档位换算成"量级"，再由事体性质校准单位**。

```plain
迁移三步
第1步 定基数：财爻纳甲干支数相加（口诀见上）
第2步 定量级：由旺衰与生克链路决定档位（大富 / 中富 / 下富 / 小户）
           ——兄弟发动、父母旺动、官鬼耗财，每有一项就下调
第3步 定单位：按事体性质把档位翻译成现代量级

```

| 档位 | 古籍进位 | 现代量级参考（需按事体校准） |
| --- | --- | --- |
| 大富 | 十进千、六进百 | 千万级（大型项目、企业年度利润） |
| 中富 | 十进百、六进十 | 百万级（中型合同、项目净利） |
| 下富 | 十进十 | 十万级（小项目、个人年度结余） |
| 小户 | 五行数一进十 | 万级以下（单笔小额、个人月结余） |

**三条使用纪律**：

1. **同一档位在不同事体里单位不同**。问"这个工程赚多少"与问"我这个月提成多少"，同为中富档，前者可能是百万、后者可能是几千——**先问清楚事体的量级常识，再选单位**。
2. **只输出"量级 + 区间"，不输出精确数**。正确说法是"这个单子在十万量级，上下浮动三成"，而不是"能赚二十三万四千"。
3. **量级必须先用生克链路校验**（兄弟克财、父母耗财、官鬼泄财都在削可用之数），链路没算就套口诀，是取数法的头号误用。

**可迁移的量化场景**（不只用于钱）：

| 场景 | 取用 | 量级输出示例 |
| --- | --- | --- |
| 合同金额 | 妻财 | "这个单子在百万量级，不是千万量级" |
| 工期天数 | 父母（文书、工程）或按事体取 | "工期在三个月量级，不会拖到半年" |
| 参与人数 | 兄弟（同辈、同事） | "需要五到八个人，不是两个人能扛" |
| 距离 / 方位 | 结合爻位与八卦方位（板块 2_5） | "在三十公里量级，不是跨省" |
| 库存 / 产量 | 妻财、子孙 | "备货在百件量级，别按千件压" |

#### 案例小故事：取数法的正确打开方式

**背景**：一位做工程承包的老板，接了一个厂房改造的活儿。合同还没签，他先起卦问"这笔工程能赚多少"。卦中妻财爻旺相，按取数法算得基数二十余，粗看落在"中富"档。断卦者直接报出"能赚二十三万"。

**实际结果**：工程做完后结算，扣掉人工、材料、设备租赁和各项杂费，只赚了三万多。老板觉得被误导了。

**复盘：问题出在哪**（三步）：

1. **量级定错了**。财爻虽旺，但卦中**兄弟爻发动**（有分利者——这个工程他分包了两块给别的班组，还有一位居间介绍人拿了点数），**父母爻旺动**（成本项：材料涨价、设备租赁、前期垫资的利息都很高）。这两项都在削可用之财。
2. **漏了调节项**。按取数法的规则，"旺相加倍"的前提是财爻**不受忌神动克**。兄弟发动克财，就不能简单套"旺相加倍"。
3. **忘了先定量级后算尾数**。二十余这个基数本身没错，错的是把它放在了"中富"档；实际应从"中富"下调一到两档，落在"下富"甚至"小户"档。

**修正后的推演**：基数不变（二十余），但量级下调两档——结果落在三万上下，与实际吻合。

**要点提炼**：

+ 取数法是**先定量级、后算尾数**，且必须先把生克链路的影响计入。
+ 跳过链路直接套口诀，等于用公式算命——公式没错，输入错了。
+ 现代迁移的正确用法：用它给**区间和量级**（"这个项目在十万量级，不在百万量级"），而不是给精确到个位的数字。
+ 给量级还有一个实用价值：**帮人发现"这单能不能接"**——若算出量级远低于投入，宁可不接。

### 12_2 一卦多断与真假六亲

**核心问题**：六爻固定以"我"为中心定六亲——生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟。但当一卦要同时看**多个人、多件事**时，以谁为"我"？

古书提出：

> 卦中六亲，有有者、有无者、有真者、有假者，有真中之假、有假中之假。

**实操心法**：

+ **主断用神，仍以卦宫为准**——这是"真六亲"。
+ **延伸看他人他事时**，需临时变换参照点，重新推一套"假六亲"。例如看对方的情况，就以"对方"为"我"再推一次六亲。
+ **假六亲只能作辅助参考**，吉凶大势仍以真六亲断。

```plain
一卦多断的操作顺序
┌─────────────────────────────────────┐
│ 1. 先用真六亲断主事（用神旺衰动变） │
│ 2. 再按需要变换参照点，看他人他事   │
│ 3. 每一层都要回到"生克"上验证      │
│ 4. 层次越多，可信度越低，需标明    │
└─────────────────────────────────────┘

```

**示例**：男测婚，妻财为妻（真六亲，以"我"为参照）。若想同时看"岳母的身体"，就要把参照点换成妻子——以妻为"我"，则生妻者为妻之父母，即卦中原本的**父母爻**在特定条件下可作岳母看。这一层属"假六亲"，只能参考。

> **提醒**：一卦多断是高阶技法，地基不稳时使用，极易把简单卦搞复杂。**建议先练熟"一卦一断"，再尝试延伸。**

### 12_3 互卦：过程观察层

**互卦的取法**：主卦去初爻、上爻，以二三四爻组成下互卦，以三四五爻组成上互卦。

```plain
  上爻  ┐
  五爻  ├── 三四五 → 上互卦
  四爻  ┘
  三爻  ┐
  二爻  ├── 二三四 → 下互卦
  初爻  ┘（去掉）

```

**使用规则（极重要）**：

+ **有动爻 → 看变卦**；**六爻皆静、无变 → 才取互卦**。这是初学者最常错的一步，一上来就找互卦是大忌。
+ 互卦**只取体用**（乾兑金、震巽木、坤艮土、坎水、离火），不受本卦动爻所伤——它是独立的"过程观察层"。
+ 互卦看的是**中间过程、隐藏环节**，相当于现代分析里的"过程变量"。

古诀："**卦静无之方取互，世空无主却凭身。**"

### 12_4 阴阳升降：卦气趋势法

升降是用于判断事物**上升或下降趋势**的技法。

**基本定义**：

+ **升阳**：阳爻居阳位、阴爻居阴位（得位），或动爻由下往上推进
+ **升阴**：阴爻居阳位、阳爻居阴位（失位），或动爻由上往下退

> 升，犹生也、长也、进也、来也；降，犹死也、消也、退也、往也。

**核心规则（最易被误读）**：

1. **"升降务以占时言，毋以卦体言也"**——升降由**占卦时的节气（中气）**决定，**不是由卦本身决定**。
2. 取**十二辟卦**（复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤）配十二月中气。
3. **真升 / 真降**的判定：临**阳爻**为真升阳、真降阴 → **旺盛**；临**阴爻** → **假升 / 反度 → 衰败**。
4. 口诀：**升阳降阴入空亡之爻 = 卦气入爻，爻不为空（反旺）；升阴降阳入空亡 = 衰气入爻，更衰**。

**落地简化版**（现代实占不必死抠卦气）：把"升降"理解为**"爻是否在当令的季节旺位上"**——得令则为升，失令则为降。

**占家宅时的升降喜忌**：

| 所占 | 喜 | 忌 |
| --- | --- | --- |
| 阳宅（活人居） | 升阳，主进文人、家运上升 | 升阴、失度 |
| 阴宅（葬地） | 内生外（内卦生外卦），为上吉 | 升阳（"阴失所"），主凶 |

### 12_5 卦身与世身：备用参照点

**使用条件极严**：

+ **世爻不空不破，无须论身爻**。
+ 只有**世爻空亡**时，才看"卦身 / 世身"作为备用参照。

> **落地提示**：卦身是"备胎"，不是常规配置。很多初学者每卦都找卦身，反而扰乱主线。记住一句话——**世爻不空，不看身爻**。

### 12_6 进阶技法的优先级与风险

| 技法 | 优先级 | 主要风险 | 建议 |
| --- | --- | --- | --- |
| 取数法 | 吉凶已定后使用 | 量级定错 | 先定量级，后算尾数 |
| 互卦 | 静卦才用 | 动卦误用 | 有动看变，无动看互 |
| 一卦多断 | 高阶 | 层次混乱 | 先练熟一卦一断 |
| 真假六亲 | 高阶 | 参照点错乱 | 真假分明，主断用真 |
| 阴阳升降 | 中阶 | 脱离节气乱套 | 简化为"得令/失令" |
| 卦身 | 备用 | 滥用扰主线 | 世空才看 |
