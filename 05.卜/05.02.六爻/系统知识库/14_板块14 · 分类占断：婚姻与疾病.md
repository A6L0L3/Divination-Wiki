# 板块14 · 分类占断：婚姻与疾病

> 这两类是人问得最多、也最容易"断出事"的场景。

婚姻牵涉他人、疾病牵涉健康——**边界必须比技术更早讲清楚**。

---

## 14_1 婚姻感情：取用与吉凶组合

**取用**：男问取妻财爻，女问取官鬼爻；应爻为对方态度；世爻为自己。

**吉凶组合**：

| 组合 | 断语 |
| --- | --- |
| 用神旺相 + 世应相生相合 | 良缘，双方有意 |
| 用神休囚 + 世应相冲 | 离散、不成 |
| 世应俱空 | 双方皆无诚意（"世应俱空，人无准实"） |
| 阴阳皆动 | 宜为良缘 |
| 应阴世阳 | 最吉祥 |
| 卦逢六合 | 主稳定、可成 |
| 卦逢六冲（尤其八纯卦） | 主变动、不顺；但六冲化六合则先难后易 |
| 游魂、八纯 | 主再嫁娶、心神不定 |
| 辰午酉亥自刑 | 夫妻相攻 |
| 上吉卦 | 咸、恒、节、泰（变冲则凶） |
| 不宜之卦 | 睽、革、解、离（化合亦凶） |

**"忌三冲"原则**：婚姻忌卦冲、爻冲、日月冲三者叠加。若遇三冲，**不用看用神旺衰，先论不顺**。

**应期**：用神旺相、世应相合之时；合住则待冲，冲则待合。**测婚姻往往还要参看父母爻**，因婚姻一般需得父母首肯。

> **重要提醒**：古籍"婚姻章"中有"仅凭卦名美恶定吉凶、不究五行生克"的取向，是全书最需警惕的部分。**实操一律从用神与世应，卦名只作参考**（总原则见板块 10_3）。

**婚姻卦速断流程**：

```plain
┌────────────────────────────────────┐
│ 1. 先看是否三冲（卦冲/爻冲/日月冲）│
│ 2. 取用神：男财女官，看旺衰       │
│ 3. 看世应：相生相合 vs 相冲相克   │
│ 4. 看六合六冲：六合成、六冲散     │
│ 5. 参父母爻：长辈是否首肯         │
│ 6. 参卦性：游魂不定、八纯再嫁娶   │
└────────────────────────────────────┘

```

**边界声明（务必遵守）**：

+ 六爻可用于"这段关系当前的状态与走向"，**不可用于"操控他人感情""断定他人心意"**。
+ 二选一式的提问（"这两个人哪个是正缘"）本身不成立，必须拆成单独两个问题（见板块 0_4）。
+ 涉及他人隐私的占问，属于"阴邪不占"的范畴（见板块 0_2）。

### 案例小故事：卦名吉利，却断出离散

**背景**：一对恋人相处三年，感情一直不错，到了谈婚论嫁的阶段。女方家在一个三线城市，男方在省会工作，两人都三十出头。女方家人关心这段婚姻能不能成，于是起卦问。起卦得**咸卦**。

**第一层：卦名的诱惑**。古诀以咸、恒、节、泰为上吉卦，咸卦更是"感应、相和"之象——少男少女相感，主"永遂通"。按卦名直断，这是天作之合。断卦者一开始也倾向于此，甚至已经准备说些吉利话。

**第二层：爻象的细看**。但翻开爻象——

1. **用神**：女问取官鬼为用神。官鬼**休囚**，不得月令。
2. **世应**：世爻与应爻**相冲**。世应代表双方，相冲说明立场对立、现实阻力大，不是感情不好，而是"各有各的非守不可的东西"。
3. **卦变**：本卦六合，但**化六冲**——六合化六冲，主"先成后散"。

**第三层：卦名与用神冲突时的取舍**。按古法底线："**用神为主，卦验为次；凡卦名断语与用神旺衰相冲突时，一律从用神。**"

**结论**：两人感情本身是好的（咸卦之和，双方确实相处融洽），但**现实阻力（世应相冲）会导致最终不成**——问题不在人，在"位置"。

**应验**：两人确实相处融洽，双方父母也都满意，婚礼的日子都看好了。但因为工作地分隔两城：女方是当地一所中学的在编教师，编制难动；男方的公司在省会，刚升了部门主管，也不愿放弃。谁也不愿迁就，一拖两年，最后和平分手。

**要点提炼**：

+ 古诀说"咸卦吉"，指的是卦象本身的性质（感情相和）；但**卦名断语与用神旺衰冲突时，一律从用神**。
+ 卦验是**参考维度**，不是判决依据。把它当对照表直断，是最常见的误用。
+ 这一卦最有价值的信息，其实是"六合化六冲"——**先合后散**，恰好对应了"谈婚论嫁 → 分隔两城 → 分手"的全过程。
+ 如果断卦者只报"吉"，女方家可能会催着办婚礼，反而更尴尬；报出"阻力在现实条件、不在感情"，才是可执行的信息。

## 14_2 疾病与医药：取用与吉凶组合

**取用**：官鬼爻为病症；子孙爻为医药（解忧、克制官鬼之力）；世爻为病人元气。

**吉凶组合**：

| 组合 | 断语 |
| --- | --- |
| 子孙旺相发动克官鬼 | 药到病除（"子孙发动伤官鬼，占病求医身便痊"） |
| 官鬼旺而子孙衰 | 病重药轻 |
| 官鬼持世 | 忧患随身（非公职者多主病患缠身） |
| 用爻（世爻）化墓、化绝 | 即用神旺亦凶 |
| 近病逢六冲 | 易愈（冲散病气） |
| 久病逢六冲 | **反凶**（冲散残余生机） |
| 世爻入墓 | "墓中人，不冲不发"，需冲开墓库方有转机 |
| 官鬼入墓、墓绝 | 病气收敛，向愈 |
| 天喜临用神 | 病易愈；若临凶煞 → 必生悲 |

**病灶定位**（按官鬼所在爻位；爻位总表见板块 2_2）：

```plain
官鬼在初爻 → 足伤、湿疹、下焦
官鬼在二爻 → 腿膝、腹腔
官鬼在三爻 → 腰肌劳损、肠胃炎
官鬼在四爻 → 心肺、胸背
官鬼在五爻 → 头痛、眼疾、五官
官鬼在上爻 → 头部、脑、远处旧疾

```

**应期**：痊愈看子孙生旺之时、官鬼墓绝之时；病厄看官鬼墓旺之时。**近病逢冲则愈，久病逢冲则危**。

## 14_3 疾病卦的三条红线

> **现代转译与边界**：
>
> + 官鬼爻 = 病症、压力、病理因素，**不是鬼神**。
> + **六爻绝不替代医疗诊断**。遇到健康问题，第一选择永远是就医。
> + 卦象只能作为"要不要再找医生看看""这个治疗方案是否对症"的辅助参考。

**疾病卦的正确提问方式**：

| 错误问法 | 正确问法 |
| --- | --- |
| 我这是什么病？ | 我这个症状，是否需要尽快做进一步检查？ |
| 我还能活多久？ | 这个治疗方案，近期对我的恢复是否有帮助？ |
| 我是不是被什么东西缠上了？ | 近期困扰我的这个身体不适，主要诱因可能是什么？ |
| 我要不要停药？ | 我是否需要就当前用药方案再咨询一位医生？ |

> **红线（对讲解者同样适用）**：**对方提到具体病症时，唯一正确的断语是建议就医。** 任何卦象结论若与医生诊断冲突，**一律以医生为准**。用卦象替代就医，是误用，也是危险。

## 14_5 场景验证：婚姻与疾病卦的复盘要点

**婚姻卦复盘三问**：

1. 我当时有没有被卦名带偏？（卦名 vs 用神冲突时，是否从了用神）
2. 世应关系判断对了吗？（这是婚姻卦最容易漏的一层）
3. 父母爻（长辈意见）参看了吗？事后看，长辈因素是否真的是变量？

**疾病卦复盘三问**：

1. 我是不是把"官鬼"当成了鬼神而非病理因素？
2. 病灶定位（爻位）事后是否与实际情况对得上？
3. **有没有越界**？卦象结论是否影响了对就医的及时性？（这一条比准确率更重要）

> **特别提示**：疾病卦的复盘，**准确率不是第一指标，是否守住边界才是**。任何一卦若导致延迟就医，就是严重误用，应单独标记并引以为戒。
