# 板块4 · 装卦六步 SOP

> 空卦只是符号，装卦之后它才变成可计算的模型。

本块给出一套**固定顺序、不可颠倒**的操作流程，并配完整演练。

---

## 4_1 六步 SOP 总览

```plain
第1步 画卦定体   → 第2步 归宫定世   → 第3步 纳甲装支
      ↓
第4步 排六亲     → 第5步 布六神     → 第6步 标日月（空亡、月破、旺衰）

```

**为什么顺序不能乱**：

+ 六亲是相对**卦宫五行**推出来的，所以必须先定宫再排六亲。
+ 世应由卦的世次决定，而世次来自八宫。
+ 旬空月破由起卦的日月干支决定，最后标注。

**第1步 画卦定体**：分清内卦（下三爻，为"我"、为近、为本）与外卦（上三爻，为"事"、为远、为末）。

**第2步 归宫定世**：查八宫卦表，确定本卦属哪一宫、第几世，据此安世爻与应爻。

**第3步 纳甲装支**：按本宫纯卦的纳支规则，自初爻至上爻装入地支。

**第4步 排六亲**：以卦宫五行为"我"，与各爻地支五行论生克，逐爻定六亲。

**第5步 布六神**：按起卦日天干，从初爻起排青龙、朱雀、勾陈、螣蛇、白虎、玄武。

**第6步 标日月**：在卦上方写下月建、日辰干支，标出旬空地支，逐爻检查是否月破。

装卦完成后，一张标准卦面应包含：**地支、五行、六亲、世应标记、动爻标记（○/×）、变卦、六神、月建日辰干支、旬空提示**。

```plain
标准卦面示意（自上而下书写）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  月建：寅      日辰：甲午      旬空：辰、巳
  ┌───────────────────────────────────┐
  │ 上六  戌土 父母  ──  玄武  应     │
  │ 五爻  申金 兄弟  ── ○ 白虎        │  ← 动爻
  │ 四爻  午火 官鬼  ──  螣蛇         │
  │ 三爻  卯木 妻财  -- × 勾陈  世    │  ← 动爻
  │ 二爻  巳火 官鬼  --  朱雀         │
  │ 初爻  未土 父母  --  青龙         │
  └───────────────────────────────────┘
  变卦：申金化酉金（比和之化）；卯木化寅木（退神）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```

## 4_2 纳甲速查与记忆法

**纳干口诀**：

```plain
乾纳甲壬，坤纳乙癸；震纳庚，巽纳辛；
坎纳戊，离纳己；艮纳丙，兑纳丁。

```

原理：乾坤为父母，配天干首尾；六子按长男到少女次第配庚辛戊己丙丁。

**纳支全表**（必须练到能默画）：

| 卦 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 |
| --- | --- | --- | --- | --- | --- | --- |
| 乾（金） | 子水 | 寅木 | 辰土 | 午火 | 申金 | 戌土 |
| 震（木） | 子水 | 寅木 | 辰土 | 午火 | 申金 | 戌土 |
| 坎（水） | 寅木 | 辰土 | 午火 | 申金 | 戌土 | 子水 |
| 艮（土） | 辰土 | 午火 | 申金 | 戌土 | 子水 | 寅木 |
| 坤（土） | 未土 | 巳火 | 卯木 | 丑土 | 亥水 | 酉金 |
| 巽（木） | 丑土 | 亥水 | 酉金 | 未土 | 巳火 | 卯木 |
| 离（火） | 卯木 | 丑土 | 亥水 | 酉金 | 未土 | 巳火 |
| 兑（金） | 巳火 | 卯木 | 丑土 | 亥水 | 酉金 | 未土 |

**四条记忆法**：

1. **阳卦顺行**（乾震坎艮），**阴卦逆行**（坤巽离兑）。阳支序列：子寅辰午申戌；阴支序列：未巳卯丑亥酉。
2. **乾震同序**：乾与震的纳支完全相同（子寅辰午申戌），只是六亲不同（乾属金、震属木）。
3. **坤巽同序**：坤与巽的纳支为同一组循环（未巳卯丑亥酉），只是起点不同。
4. **纳甲歌**（背熟即可覆盖全部八宫）：

```plain
乾金甲子外壬午，坎水戊寅外戊申。
艮土丙辰外丙戌，震木庚子外庚午。
巽木辛丑外辛未，离火己卯外己酉。
坤土乙未外癸丑，兑金丁巳外丁亥。

```

前半为内卦（下三爻）起始干支，后半为外卦（上三爻）起始干支，中间按阳顺阴逆推。

> **实战提示**：实际断卦中**天干几乎不用，只看地支**——因为定五行生克的核心在地支。地支五行务必滚瓜烂熟：**子亥水、寅卯木、巳午火、申酉金、辰戌丑未土**。

## 4_3 排六亲：推导规则与三个易错点

**推导规则**（以卦宫五行为"我"）：

```plain
生我者 → 父母   我生者 → 子孙
克我者 → 官鬼   我克者 → 妻财   同我者 → 兄弟

```

**以乾宫为例**（乾属金）：

```plain
初爻子水 → 金生水 → 子孙      四爻午火 → 火克金 → 官鬼
二爻寅木 → 金克木 → 妻财      五爻申金 → 同属金 → 兄弟
三爻辰土 → 土生金 → 父母      上爻戌土 → 土生金 → 父母

```

典籍原文对乾卦的表述正是这一逻辑的源头："水配位为福德（甲子水是乾之子孙），木入金乡居宝贝（甲寅木是乾之财），土临内象为父母（甲辰土是乾之父母），火来四上嫌相敌（壬午火是乾之官鬼），金入金乡木渐微（壬申金同位伤木）"。

**三个必错点**：

1. **六亲是相对"卦宫"而言，不是相对摇卦人**。同一个地支在不同卦宫里六亲不同。例如申金在乾宫是兄弟，在坎宫（坎属水，金生水）就是父母。装卦时**先定卦宫，再定六亲，顺序不能反**。
2. **内外卦各爻都要逐一比对**，不能只比一个。
3. **伏神的六亲也按卦宫定**，不按伏神所在卦定。

### 附：变卦怎么装配（变爻的六亲、世应怎么定）

本卦装完之后，还要处理动爻变出的那一卦。这一步教材里常常一句带过，却是新手装盘时次高发的错误区。

**四条规则**：

1. **变卦由动爻阴阳互变而来**：老阳变阴、老阴变阳，静爻原样照搬。无动爻则无变卦（六爻皆静的卦叫"静卦"，见板块 7_7 附）。
2. **变爻的六亲仍按本卦宫五行推，不按变卦的卦宫推**。例如坎宫（水）卦中二爻丑土官鬼发动化出未土，未土在坎宫里仍是"土克水 → 官鬼"；不会因为变卦变成了别的宫而改称兄弟。
3. **变卦沿用本卦的世应**，不重新安世应。世应定位来自八宫世次（板块 2_4），卦变之后世次不变。
4. **变卦一般不重新纳甲、不重新布六神**。实务中真正要读的只有"动爻化出了什么"——即变爻的地支、五行、六亲，以及它与原动爻之间的回头生克（板块 7_2）。变卦整体只在观察"事情终局走向"时作参考。

```plain
装配顺序（完整版，在原六步之后追加第七步）
第1步~第6步 装本卦（画卦、归宫定世、纳甲、六亲、六神、标日月）
     ↓
第7步 处理动爻：标出变爻地支 → 按本卦宫定变爻六亲 → 判回头生克/进退/墓绝
     ↓
第8步 用神不现时，查伏神（板块 9）

```

> **最常见的错**：拿变卦的卦宫去给变爻排六亲。记住——**一卦只有一个"我"，就是本卦的卦宫五行**；本卦、变卦、伏神，三处六亲都以它为参照点。这条与 4_3 的"三个必错点"是同一条铁律的三种表现。

## 4_4 布六神：起例、类象与三条铁律

**起例**（按起卦日天干，从初爻往上排）：

```plain
甲乙日 → 初爻起青龙    丙丁日 → 初爻起朱雀
戊日   → 初爻起勾陈    己日   → 初爻起螣蛇
庚辛日 → 初爻起白虎    壬癸日 → 初爻起玄武

```

六神按**青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武**的固定次序循环，从初爻排到上爻。

**六神类象（含现代拓展，全库唯一完整表）**：

| 六神 | 五行 | 人物 | 身体 / 心理 | 传统事项 | 现代类象拓展 |
| --- | --- | --- | --- | --- | --- |
| 青龙 | 木 | 贵人、正直者、喜庆之人 | 肝、左胁 | 喜庆、财福、进人口、酒色 | 好消息、签约、升职、庆典、团队扩张 |
| 朱雀 | 火 | 文人、口才者、争吵者 | 心、口舌 | 口舌、文书、公事、信息 | 消息通知、邮件、舆论、争论、客服 |
| 勾陈 | 土 | 熟人、中间人、农人 | 脾胃、肌肤 | 田土、产业、迟滞、纠缠 | 房产纠纷、流程拖沓、反复拉扯 |
| 螣蛇 | 土 | 虚诈者、怪异之人 | 经络、惊悸 | 惊疑、怪异、虚惊、缠绕 | 系统故障、数据异常、反复折腾、焦虑 |
| 白虎 | 金 | 凶暴者、武职、医者 | 肺、骨、血光 | 凶丧、疾病、刑伤、血光 | 事故、手术、强监管、硬约束、急性病 |
| 玄武 | 水 | 盗贼、暧昧者、隐者 | 肾、耳目 | 失脱、奸盗、暗昧、隐私 | 数据泄露、暗箱操作、被骗、信息不透明 |

**三条使用铁律**：

1. **六神不能单独定吉凶**，必须叠加在六亲与用神之上才有意义。同一个白虎，临子孙则子孙灾，临妻财则妻灾，临父母则父母忌——**位置决定一切**。
2. **六神需配六亲方成事象**：朱雀虽主口舌，然非兄弟并临，则不能成口舌；玄武虽主盗贼，若非官鬼并临，则不能称盗贼。
3. **六神是修饰层**，权重远轻于五行生克。古籍论断："吉凶神煞之多端，何如生克制化之一理。"吉凶得失当专以六亲生克为主，六神只能"推其性情形状"。

## 4_5 装卦实操演练（完整走一遍）

**演练题**：某人问"我本月提交的报价方案能否签下"，摇得**水火既济**卦，二爻、五爻动。起卦时间为寅月甲午日。

```plain
第一步 画卦定体
  既济 = 坎（上/外） + 离（下/内）
  六爻：初九、六二、九三、六四、九五、上六
  动爻：二爻、五爻

第二步 归宫定世
  查八宫表：既济属坎宫三世卦
  三世 → 世在三爻，应在上爻

第三步 纳甲装支（内卦离、外卦坎，按各宫纳支）
  内卦离：初爻卯、二爻丑、三爻亥
  外卦坎：四爻申、五爻戌、上爻子

第四步 排六亲（坎宫属水，"我"为水）
  初爻卯木 → 水生木 → 子孙
  二爻丑土 → 土克水 → 官鬼    ← 动爻
  三爻亥水 → 同属水 → 兄弟    ← 世爻
  四爻申金 → 金生水 → 父母
  五爻戌土 → 土克水 → 官鬼    ← 动爻
  上爻子水 → 同属水 → 兄弟    ← 应爻

第五步 布六神（甲午日，甲日初爻起青龙）
  初爻青龙、二爻朱雀、三爻勾陈、四爻螣蛇、五爻白虎、上爻玄武

第六步 标日月
  月建：寅    日辰：甲午
  寅月：申金被寅冲 → 四爻申金为月破
  甲午日属甲午旬 → 辰、巳空亡；卦中无辰巳，故无爻落空

```

**装完卦的第一眼印象**（这一步很关键，装卦不是机械填空）：

+ 问"签单"属求财 → 取妻财为用神。
+ **卦中六爻竟无妻财**（只有子孙、官鬼、兄弟、父母）——用神不现。
+ 下一步必须查伏神：坎宫属水，"我克者"为火，故妻财为火爻。去坎宫本宫卦（坎为水）中找火爻——坎卦纳支为寅、辰、午、申、戌、子，其中**午火**即为坎宫之妻财，伏于本卦对应爻位之下（详见板块 9）。
+ 两个官鬼爻（二爻、五爻）皆动 → 客户方 / 审批方的动作非常明显，这是全卦的题眼。
+ 世在三爻兄弟亥水，应在上爻兄弟子水 → 世应比和，双方关系不算对立。

> **演练的意义**：装卦不是机械填空，每填一步脑子里都要同步跑一句"这说明什么"。装完卦，**第一印象（用神有无、动爻在哪、世应关系）就应该已经浮出来了**。带着这个印象进入板块 5 的取用神，效率会高得多。

### 案例小故事：装卦顺序反了，一步错步步错

**背景**：一位学六爻三个月的初学者，替朋友占问"这个订单能不能签下来"。朋友是一家小五金厂的老板，对方是本地一家装配厂，订单金额不算大但利润尚可，已经报过两轮价，就等对方最后拍板。他坚持手装，摇得**天风姤**卦。装卦时他图省事，跳过了"归宫"这一步，直接看着卦画排六亲——因为姤卦的下卦（内卦）是巽，他就顺手把这一卦当成了**巽宫**卦。

**他的装法（错的）**：以巽宫属木、"我"为木来排六亲——

```plain
初爻丑土 → 木克土 → 妻财
二爻亥水 → 水生木 → 父母
三爻酉金 → 金克木 → 官鬼
四爻午火 → 木生火 → 子孙
五爻申金 → 金克木 → 官鬼
上爻戌土 → 木克土 → 妻财

```

**他得出的结论**：卦中**有两个妻财**（初爻丑土、上爻戌土），求财用神现成，且丑土还得月建生扶——于是他告诉朋友"这单能成，放心跟"，朋友便没再主动跟进，也没给对方去电话确认。

**错在哪一层**：问题不在六亲算法，而在**他跳过了"先定卦宫、再排六亲"这条铁律**。姤卦是**乾宫一世卦**（上乾下巽，以八宫世次论属乾宫），不是巽宫卦。六亲是相对**卦宫五行**推出来的，卦宫一定错，后面每一爻的六亲就全部错位。

**纠正后的装法**（乾宫属金，"我"为金）：

```plain
初爻丑土 → 土生金 → 父母
二爻亥水 → 金生水 → 子孙
三爻酉金 → 同属金 → 兄弟
四爻午火 → 火克金 → 官鬼
五爻申金 → 同属金 → 兄弟
上爻戌土 → 土生金 → 父母

```

**真相完全不同**：乾宫金，"我克者"为木，妻财是**木爻**——而这一卦六个爻里**根本没有木**。也就是说，**用神不现**，必须去查伏神（去本宫乾卦中取寅木为伏财）。再一看伏神被飞神克制、又无日月引拔，是"抽屉里的钱"——看得见，拿不出来。

**应验**：朋友照他的乐观判断放松了跟进，既没有在报价上给一点灵活空间，也没有在对方犹豫的那几天去现场跑一趟。结果两周后订单被同行以更低报价截走。事后复盘，正确的卦象其实早就把答案摆在那儿了：**财不上卦，伏而受克，求而难得**——只是被一个"定错宫"的操作错误彻底遮住了。

**要点提炼**：

+ 装卦六步的顺序**不能颠倒**：**归宫定世 → 纳甲装支 → 排六亲**。六亲依赖卦宫，卦宫没定就排六亲，等于先写答案再出题。
+ 判断卦宫看的是**八宫世次**（姤是乾宫一世），不是"下卦是什么就是什么宫"——这是新手最高频的一次翻车。
+ 同一个地支在不同卦宫里六亲不同：丑土在巽宫是妻财，在乾宫是父母。**地支本身没有固定的六亲身份**，身份是卦宫给的。
+ 记住这条自检：**装完卦先问一句"我这个'我'到底属什么五行"**。答不上来或答错了，后面全废。
+ 装卦错误**自己看不出来**——因为它内部自洽。所以学完本板块一定要做验证题或请人核对，不能只靠自查。

## 4_6 装卦自检清单

| 检查项 | 自问 |
| --- | --- |
| 卦画方向 | 是从下往上画的吗？动爻标了吗？变卦对了吗？ |
| 卦宫 | 归宫对了吗？纳支是按该宫规则装的吗？ |
| 世应 | 世应位置对吗？谁代表谁说清楚了吗？ |
| 六亲 | 是按卦宫五行推的吗？六个爻全对了吗？ |
| 六神 | 起例日干查对了吗？循环顺序对了吗？ |
| 日月 | 月建（按节气）日辰干支记对了吗？旬空是哪两个字？ |
| 月破 | 逐爻检查过与月建相冲的爻了吗？ |
| 用神 | 用神在不在卦里？不在的话，准备查伏神了吗？ |
