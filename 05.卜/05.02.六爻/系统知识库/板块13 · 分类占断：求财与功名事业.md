# 板块13 · 分类占断：求财与功名事业

> 本板块按"**取用 → 关键爻 → 吉凶组合 → 应期 → 笔记与验证**"五段式展开。

分类占断的共同原则：**先定用神，再套场景；所有古诀都是"有条件的结论"。**

## 13_1 求财：角色分工与总纲

**取用**：妻财（资金、利润、收益）为主用神；子孙（客源、订单、流量、财源）为原神；兄弟（竞争、分利、损耗）为忌神；父母（房租、设备、成本）为仇神兼成本项；官鬼（政策、监管、行业风险）另参。

**核心口诀**：

> "财星旺相，必得千钟之粟；兄如发动，须防减俸除粮。"

**角色分工的经济含义版**（六亲角色的通用定义见板块 7_4，此处只列经济场景的对应物）：

| 角色 | 六亲 | 经济含义 |
| --- | --- | --- |
| 用神 | 妻财 | 资金、利润、收益、有价资产 |
| 原神 | 子孙 | 财源：客源、订单、流量、利好消息、本金、核心竞争力 |
| 忌神 | 兄弟 | 破财：市场竞争、交易成本、利空、伙伴背叛、决策失误 |
| 仇神 | 父母 | 成本：房租、设备、货款、运营投入（父母生兄弟） |
| 另参 | 官鬼 | 政策风险、监管、行业管控（官鬼可制兄弟，亦泄财） |

```plain
求财卦的力量链路
  父母（成本）──生──► 兄弟（竞争/损耗）──克──► 妻财（利润）◄──生── 子孙（客源）
      仇神                    忌神                用神              原神

```

> **注意这条链路的方向**：父母（成本）生兄弟（损耗），所以"成本上升"会推高"损耗压力"——这是实体生意最常见的死法，也是只看财爻旺衰绝对看不出来的。

## 13_2 求财六大细分场景

| 场景 | 吉象 | 凶象 |
| --- | --- | --- |
| **固定工资 / 稳定主业** | 财爻旺相、有子孙生扶 → 薪资稳定，逐年涨薪 | 财爻衰弱 + 官鬼持世 → 工资微薄、压力大；财爻旬空入墓 → 拖欠、奖金延迟 |
| **实体开店** | 子孙旺动生财 + 世爻得财生 → 客源稳定，营收上涨 | 父母旺动克子孙 → 房租设备成本吞噬利润；官鬼旺动耗财 → 监管、投诉、纠纷消耗；兄弟发动 → 同行内卷 |
| **合伙生意** | 世应相生、财爻与世应相合 → 同心协力，分红稳定 | 世应相冲相克 + 兄弟发动 → 合伙反目、账目不清、极易散伙；**应爻临玄武克财 → 对方隐瞒账目、暗中私吞** |
| **投资** | 子孙旺相发动生财 → 财源稳定且可持续 | 兄弟持世或发动克财 → 破财；兄弟临玄武发动 → 防诈骗或合伙纠纷 |
| **借贷回款** | 财爻旺相、应爻生世 → 能收回 | 财爻空破、应爻克世 → 难收；兄弟发动 → 被消耗 |
| **副业 / 摆摊** | 子孙旺 + 财爻有气 + 世爻得财生 → 有小利 | 财多克世 → 过度投入反成压力 |

### 进阶技巧：投资的"顺逆花费"判断

兄弟爻、官鬼爻发动都主花钱，但要区分**计划内（顺）**与**计划外（逆）**：

```plain
看兄弟爻、官鬼爻是生世还是克世
  生世 → 顺：计划内的花费，如买房、买车、投资做生意
             钱花出去了，但获得了相应的物品、服务或回报
  克世 → 逆：计划外的破耗，如疾病、官灾、被骗

```

**再结合所临六神判断具体花钱缘由**（六神类象见板块 4_4）：

```plain
临朱雀       → 因口舌官司花钱
临螣蛇、玄武 → 被骗、被盗而破财
临青龙       → 酒色成灾
临白虎       → 疾病灾祸

```

**投资之象的识别**：当卦中出现"兄弟爻临财库或子孙库而发动克财爻""兄弟爻发动化财爻或子孙爻""兄弟爻临青龙克财爻"，都属**投资之象**——此时成败要看子孙爻的旺衰。

## 13_3 求财应期与风险边界

**应期**：

+ 妻财旺相之时、子孙生旺之时、财爻逢值逢合之日
+ 财动化子孙则应在子孙爻值日
+ **财爻克世（财来找我）则应期极快，当日可见**
+ 财爻逢空则出空之后

**风险提示（务必遵守）**：

> 六爻可评估"投入此项目获利的可能性和风险点"，属于风险管理工具，**不能用于预测单只股票的明日涨跌**。用它做短线投机，是典型误用。

### 案例小故事：两兄弟同问生意，一个发财一个亏本

**背景**：一户人家的两兄弟，同在一年之内各起一卦问生意前景。两人做的是同一行——开饲料店，连供货渠道都是同一家厂，进货价也差不多。老家的亲戚都说"兄弟俩做一样的生意，肯定都赚"。

**兄之卦**：妻财旺相，子孙爻发动来生财，兄弟爻安静休囚。

**推演**：

+ 财爻自己旺 → 利润空间在（不是薄利到没法做）。
+ 子孙发动生财 → **客源在持续进来**（财有源头，不是一次性买卖）。
+ 兄弟爻安静又休囚 → **竞争压力没有被激活**（没人跟他抢这一片）。

**断语**：财有源头，竞争者无力，吉。

**应验**：兄的店开在县城主街，临着农贸市场，养殖户来赶集顺便就买了；客流稳定，回头客多，当年盈利，第二年又开了一个货架做兽药。

**弟之卦**：妻财也旺相——表面看和兄一模一样。但细看：**兄弟爻发动克财**，且**父母爻旺动生兄弟**。

**推演**：

+ 兄弟发动 → 有分利者、有同行压价，损耗是**活的**，不是潜在的。
+ 父母旺动生兄弟 → 父母是成本项（房租、设备、货款），**成本在推高竞争压力**。也就是说，不是单纯有人抢生意，而是"成本高 + 有人抢"同时发生：店租贵，必须卖得多才够本，一着急就容易跟着降价。
+ 财爻虽旺，但被两头夹击——一头是成本，一头是压价。

**断语**：表面有财，实则有分利者与成本压力，凶。

**应验**：弟的店开在新开发区，规划图上写着"未来三年入住五千户"，实际当时只住了几百户，人流一直没起来；店租却是主街的八成（因为新区的商铺招商时给了"首年优惠"，第二年开始按原价）。加上同行低价倾销抢客，他跟着降价，越卖越亏，撑了十一个月后转让。

**要点提炼**：

+ 关键差别不在财爻本身（两人财爻都旺），而在**财源的持续性（子孙）与损耗的活跃度（兄弟）**，以及成本项（父母）是否在给损耗"供能"。
+ **财爻旺只是"看着有钱"，子孙生财才是"钱能长出来"，兄弟发动才是"钱在漏"。**
+ 断求财卦，至少要同时看四个爻：财（利润）、子孙（财源）、兄弟（损耗）、父母（成本）。只看财爻，等于只看营业额不看成本和竞争。
+ 两人做的是同一行、进的是同一家的货——**差别全在店址与竞争格局**，而卦象恰好把这两点分别呈现为"兄弟安静"与"兄弟发动 + 父母生兄弟"。

## 13_4 功名、事业与求职应聘

**取用**：官鬼（职位、用人单位、面试官、权力）为主用神；父母（简历、offer、合同、笔试成绩、资质）为次用神；妻财（薪资）另参；兄弟（竞争者）为忌；子孙（克官鬼）为求职忌神。

**核心口诀**：

> "父爻旺相，文成掷地金声；鬼位兴隆，家报泥金喜捷。"

"官鬼为职，父母为文。官旺父兴，其谋必成；官空父破，枉自奔波。"

**求职卦的九个关键组合**：

| 组合 | 断语 |
| --- | --- |
| 官鬼旺相生世爻，父母爻不空破 | **高概率录用**：面试官认可，资质齐全 |
| 官鬼动化进神 / 回头生，世爻得日辰扶 | 转岗成功，竞争虽多但最终胜出 |
| **父母生官鬼**（印绶生官） | **大吉**：资历与文书得力，录用希望极大 |
| **父母克官鬼** | 大凶：资历过强或文书有误，反损机遇 |
| 官鬼休囚空亡，或父母爻入墓 | 失败信号：岗位已内定或简历未达标 |
| 官鬼克父母 | 职位要求与资历不匹配，或竞争激烈 |
| 世应相冲克 + 官鬼临白虎发动 | 薪资预期不符或与面试官气场不合 |
| 子孙持世或发动 | **不利求职**：自身排斥或主动失去机会 |
| 兄弟旺相临日月或临应爻 | 竞争者强，需通过兄弟爻反推结果 |

> **注意**：**在职看官鬼为主，应聘看父母兼看官鬼**——两者侧重不同，需综合判断。

**科目与廷试的取用差别**（体现"关系结构"取用，原理见板块 5_5）：

| 事体 | 取用先后 | 逻辑 |
| --- | --- | --- |
| 乡会试（科目） | **先父母（文章）后官鬼** | 先有文章，后有功名 |
| 廷试（殿试） | **先官鬼后父母** | 廷对重"对君之言"，官鬼为先 |

## 13_5 功名事业应期

**应期**：官鬼、父母临值或逢合之日；父母爻主通知消息，**父母临朱雀发动则"雀动音书至"，消息将至**。

```plain
求职卦速断流程
┌───────────────────────────────────┐
│ 1. 官鬼旺不旺？（岗位/面试官态度）│
│ 2. 父母空不空？（简历/offer 文书）│
│ 3. 官父关系？（父生官吉、父克官凶）│
│ 4. 兄弟强不强？（竞争者）        │
│ 5. 子孙动不动？（自身是否排斥）  │
│ 6. 世应关系？（双方是否契合）    │
└───────────────────────────────────┘

```

## 13_6 场景笔记方法：求财与事业卦的专用记录模板

## 13_7 场景验证：如何判断自己的场景库是否可靠

**三条验证标准**：

1. **同场景同结论**：同一类问题（如连续问五个开店卦），你的判断逻辑是否一致？如果每次换一套标准，说明还没形成套路。
2. **反例是否被记录**：失败的卦例有没有单独归档？**只记成功不记失败，会产生严重的幸存者偏差**。
3. **关键爻命中率**：统计"当时认定的主要矛盾"事后是否真的是主因。若长期偏低，说明**权重判断有误**，需回头重看板块 6 与板块 7。
