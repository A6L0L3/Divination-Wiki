# 板块7 · 动变与生克：事情正在往哪个方向走

> "神兆机于动""爻不乱发，动必有因"。

动爻是整件事的开关。断卦的第一刀，永远是——**先看动爻指向哪里**。

---

## 7_1 动爻的三重意义

1. **方向**：动而生谁、克谁，就是事情正在往哪个方向使劲。
2. **过程**：动为始，变为终。动爻是事情的起点，变出之爻是事情的结局。
3. **时间**：动爻的冲合值墓，往往是应期的钥匙。

**断卦的第一刀**：很多人拿起卦就挨个分析六亲、六神，这是"贪多求全"。正确做法是——**先看动爻指向哪里**。问财运，子孙爻发动去生妻财，根基就有了；兄弟爻发动克妻财，外面看着再热闹，内里也是破耗。

```plain
动爻解读三连问
┌──────────────────────────────────┐
│ 1. 它是谁？（用神？原神？忌神？） │
│ 2. 它去干嘛？（生谁？克谁？合谁？）│
│ 3. 它变成啥？（回头生克？进退？） │
└──────────────────────────────────┘

```

---

## 7_2 变爻的五种作用

| 类型 | 含义 | 吉凶 |
| --- | --- | --- |
| **回头生** | 变爻生动爻 | 大吉，生机绵绵 |
| **回头克** | 变爻克动爻 | 大凶，"不论用神之衰旺，皆以凶推" |
| **化进神** | 动爻化出地支为进（如寅化卯） | 吉，越来越好 |
| **化退神** | 动爻化出地支为退（如卯化寅） | 凶，走下坡路 |
| **化墓化绝化空** | 动而化入死、墓、绝、空 | 转吉为凶的大忌 |

**进神全表**（旺相大吉）：

```plain
亥化子、寅化卯、巳化午、申化酉
辰化未、戌化丑、丑化辰、未化戌

```

**退神全表**（休囚大凶）：

```plain
子化亥、卯化寅、午化巳、酉化申
辰化卯、戌化未、丑化戌、未化辰

```

**断语**：**旺相化进，事事亨嘉；休囚化退，般般败退。**

> 进退神的力量也要看旺衰：休囚化进，只是"想变好但力气不够"；旺相化退，也可能只是"高位回调"。口诀说的是典型情形，不是绝对。

**化出六亲的组合速断**（高频实用）：

```plain
财动化子 → 投资有回报，财源滚滚（最吉）
财动化官 → 花钱消灾（钱用来解决问题）
财动化兄 → 破财，钱被分走，先得后失
财动化父 → 求财先易后难（父母克子孙，断财源）
子动化财 → 靠创意、技术生财（最吉组合）
子动化官 → 乐极生悲，玩乐惹麻烦
官动化子 → 忧患得解（病得药）
官动化父 → 职位落实、调令文书到手
父动化子 → 文书落空、学业受阻

```

## 7_3 两条单向法则：动变关系的底层规则

这两条不懂，动爻一多就彻底乱套：

**法则一：变能生克于动爻，动不能制扶于变象。**

```plain
变爻 → 可以生克 → 动爻   ✓
动爻 → 不能生克 → 变爻   ✗

```

即单向作用：后来者（变）能作用于先前者（动），先前者不能作用于后来者。

**法则二：静受动伤，静难制动；柔遭刚克，柔岂伐刚。**

```plain
动爻 → 可以克 → 静爻   ✓（主动权在动的一边）
静爻 → 难以克 → 动爻   ✗

```

**判断优先级**：**变爻 > 动爻 > 静爻**。遇到复杂卦，先处理变爻对动爻的回头作用，再看动爻对全卦的作用，最后才看静爻之间的静态生克。

## 7_4 元神、忌神、仇神：画出力量链路

以用神为中心，给每个爻分配"角色"：

```plain
        仇神
          │ 生
          ↓
忌神 ──克──→ 用神 ←──生── 原神

```

| 角色 | 定义 | 举例（用神为妻财土） |
| --- | --- | --- |
| **用神** | 所占之事的核心 | 妻财土 |
| **原神** | 生用神者（助力、根源） | 火（火生土） |
| **忌神** | 克用神者（阻力） | 木（木克土） |
| **仇神** | 生忌神、克原神者（帮凶） | 水（水生木、水克火） |

**判断优先级**：**用神 > 原神 > 忌神 > 仇神**。

**元神忌神的四句要诀**：

+ 元神旺动生用神 → 大吉，根本助力
+ 忌神旺动克用神 → 大凶，主要阻力
+ 忌神动而化退、化空、被制 → 凶力有限（"凶中有救"）
+ 仇神动而生忌神 → 阻力被加强，事情难解

> **经济场景的角色对照**（求财、开店等场景里这些角色分别对应什么，见板块 13_1 的完整表格与链路图）。

## 7_5 三条"贪"字诀：生克的优先级

这是生克判断中的"例外条款"，也是"药"起作用的典型形式：

| 名称 | 含义 | 例子 |
| --- | --- | --- |
| **贪生忘克** | A 既能生 B 又能克 C，若 B 出现，A 优先去生 B，暂忘克 C | 忌神贪生忘克 → 用神暂得喘息 |
| **贪合忘生** | 有合可贪时，暂不履行生扶之责 | 原神被合住 → 助力暂时失效 |
| **贪合忘克** | 有合可贪时，暂不履行克制之责 | 忌神被合住 → 阻力暂时解除 |

**判断顺序**：**先看合冲，再看生克，最后看刑害**。对应古诀"别衰旺以明克合，辨动静以定刑冲"。

> **警示**：这三条是"有条件的例外"，不是普遍规则。必须先确认合局真实成立（地支齐全、不被冲破），再谈贪合。古诀早有提醒："**并不并，冲不冲，因多字眼；刑非刑，合非合，为少支神。**"——字面看着像，实际地支不齐全，就不能按合局断。

### 案例小故事：忌神被合住，反倒救了用神

**背景**：一位做建材批发的商人，年中进了一批螺纹钢压在仓库里，占了大半个货位，资金也压住了。他问这批货能否顺利出手、价格会不会被压。

**卦象**：问求财，取妻财为用神。卦中**兄弟爻（忌神，主竞争压价、同行抛货）旺相发动**，本该克财——这是个明确的凶象：有人要抛货，价格要跌。

**转机**：但起卦的日辰地支，恰好与兄弟爻的地支**相合**。兄弟爻被日辰合住。

**推演**：按"贪合忘克"的原理，兄弟爻有合可贪，暂时不履行克制妻财的职责。也就是说——**同行的抛货压力暂时不会释放**。但这只是暂时的：一旦日辰流转、合被冲开，兄弟爻脱绊就会立刻克财，届时价格必跌。

**结论**：短期两个月内（合住期间）行情尚可，需**尽快出货**；两个月后价格必跌。断卦者给的不是"能不能赚钱"这个结论，而是一个明确的时间窗口。

**应验**：这位商人在第一个月内加紧出货——他把手上的老客户关系挨个走了一遍，能现结的让一点价也出，把库存清了大半。次月，同类商品果然因同行集中抛货而价格下滑，他因为出得早，避开了这一轮，虽然单吨利润薄了些，但整体没亏，资金也盘活了。

**要点提炼**：

+ 动爻不是孤立生效的，它会被日月**绊住**或**放出**。**看动爻，永远要连着日月一起看。**
+ "贪合忘克"是**有时间窗口**的救应，不是永久解除——合住期间是行动窗口期，窗口一过，压力照旧。
+ 断卦者给出的"尽快出货"这个建议，比"能不能赚钱"这个结论更有价值。**卦给的是时间窗口，行动才是关键。**
+ 反过来看：如果他是"财爻旺、兄弟安静"的卦，那就不必急着让价——**同样的"出货"动作，在不同卦里对应完全不同的紧迫度**。

## 7_6 暗动：静爻也能发力

**定义**：静爻旺相，被日辰相冲，则为"暗动"。

**要点**：

+ 暗动的力量**仅次于明动**，主暗中发力、暗中有人推动。
+ 暗动只在被日辰冲时成立；被月建冲破则是月破，不是暗动。
+ 古诀："静得冲而暗兴""空逢冲而有用"。

**实操意义**：很多"看不出原因"的变化，往往藏在暗动里。断卦时若发现事情有隐性推动力，回头检查哪个旺相静爻被日辰冲了。

> **两现取用时的提醒**：暗动之爻优先于纯静之爻（见板块 5_6 六步阶梯第二步）。实践中经常遇到两个用神都不明动，但其中一个被日辰冲动而暗动——那个才是真正的主用神。

## 7_7 独发、独静、两动、多动的处理

**独发**（只有一个动爻）：信息最纯净，这个动爻就是全卦的题眼。应期往往与它的冲合值墓紧密相关——**独发之爻，以该爻所临地支为应期，或以合该爻的时间为应期**。

**独静**（五爻皆动，只有一个静爻）：与独发对仗的一条经验——此时以**独静之爻所纳地支**为应期。这是极易被忽略的一条。

**两动**（两个动爻）：看两个动爻之间的关系——是连续相生（一路助力），还是互相交战（内部消耗），还是一吉一凶（好事坏事并存）。

**多动**（三个以上动爻）：按以下顺序收敛：

```plain
1. 先看动爻中有无用神或忌神 → 有则以此为主
2. 再看动爻之间能否构成三合局 → 成局则力量倍增，为全卦主导
3. 最后看动爻的化出有无回头克 → 有回头克者，纵旺也先败

```

### 附：六爻皆静（静卦）怎么办

摇出一卦六个爻全不动，叫**静卦**。新手遇到静卦常会慌——没有动爻，"神兆机于动"这条就用不上了。其实静卦有它自己的一套读法：

```plain
静卦四步读法
1. 看旺衰 → 用神旺相则事有可为，休囚空破则难成（权重最高）
2. 看静爻之间的生克 → 静爻之间仍有生克关系，只是"不动"＝不变、不加速
3. 看日月 → 静卦中月建日辰的分量被放大（它们本来就是最高层级，现在没有动爻与之竞争）
4. 看格局 → 六冲卦、六合卦、反伏游归等卦象级信号照旧优先（板块 8）

```

**三条实操要点**：

1. **静卦主"不动、拖延、维持现状"**——问"什么时候动"，静卦往往意味着"暂时不会动"；问"这件事会不会变"，静卦意味着"短期内不变"。
2. **静卦的应期多在"逢冲"**：静则待冲（板块 11_1）。用神旺相安静，待冲动之月日；用神休囚安静，则待生旺之期。
3. **六爻皆静才取互卦**（板块 12_3）：互卦是"过程观察层"，只在无变卦时才登场。**有动爻时看变卦，别去找互卦**——这是静卦最容易被误用的一条。

> **断语分寸**：静卦不是"没信息"，而是"信息在静态结构里"。此时更要靠旺衰与格局说话，切忌因为"没动爻"就随便报一个日子。

## 7_8 生克路线图绘制法：把卦变成一张图

这是本知识库推荐的核心实操工具。每断一卦，**在纸上画一遍这张图**，思路立刻清晰：

```plain
【第一步】写下用神，画一个方框
【第二步】从用神向左画箭头，标出"谁生它"（原神）与"谁克它"（忌神）
【第三步】从忌神再向左，标出"谁生忌神"（仇神）
【第四步】标出每个生克者是动是静、旺还是衰
【第五步】在箭头上标注权重：日月参与的画粗线，动爻画中线，静爻画细线
【第六步】看用神一侧与忌神一侧的总力量对比，得出结论

```

**示例**（用神为妻财土）：

```plain
午火（原神，动，临日） ══生══► 【妻财土：用神，月克日生】 ◄──克── 寅木（忌神，静，休囚）
                                        ▲
                                        │ 比和
                                   世爻（土，静）

判断：忌神休囚又静，克力有限；原神旺相发动生用。
   → 吉，但需待原神得力之时（午火值日/值月）。

```

**这张图的价值**：它把"数生克"升级为"看链条"。同样是三个生、两个克，链路不同，结论可能完全相反——用神被一路相生到日月，是真正的有力；用神孤立无援，即使没被克，也只是"不动而已"。

**多重要素权衡法**（当生克同时存在时）：

| 权衡维度 | 判断要点 |
| --- | --- |
| 力量对比 | 生财力量 vs 克财力量，谁占优 |
| 位置分析 | 直接作用（相邻爻）vs 间接作用（隔爻） |
| 动静区分 | 动爻作用远大于静爻 |
| 时间因素 | 当前作用 vs 变化趋势（化进化退） |
| 旺衰调节 | 旺爻作用强，衰爻作用弱 |

## 7_9 动变自检清单

每处理完动变部分，自检五项：

| 检查项 | 要点 |
| --- | --- |
| 回头作用 | 每个动爻的变爻是否回头生克，都检查过了吗 |
| 进退 | 有无化进、化退的组合 |
| 特殊化 | 有无化墓、化绝、化空、化回头冲 |
| 暗动 | 有无旺相静爻被日辰冲动而暗动 |
| 全局 | 动爻之间是否构成三合局，是否互相交战 |
| 绊住 | 动爻是否被日月合住而暂时失效（贪合忘生/忘克） |

## 7_10 动变实操演练

**演练题**：问一个重要项目的投标结果。卦中情形如下：

+ 官鬼（主裁判方、招标方）发动，化出父母爻（文书、中标通知）
+ 子孙爻（克官鬼）安静休囚
+ 兄弟爻（竞争者）发动，但化退神
+ 世爻得日辰生扶

```plain
第一步 找动爻
  官鬼动、兄弟动 → 两个动爻，按多动收敛顺序处理

第二步 逐个解读
  官鬼动化父母 → "官动化父：职位落实、调令文书到手"
     → 招标方动作指向"给出文书"，大吉之象
  兄弟动化退 → 竞争者发动但化退
     → 有人竞争，但竞争之势在衰减

第三步 看单项法则
  官鬼化父母，是回头生还是回头克？
    按五行看：父母生官鬼 → 回头生，大吉
  兄弟化退，退则力减 → 忌神自衰

第四步 看静爻与日月
  子孙安静休囚 → 无力克官鬼，不构成阻碍
  世爻得日辰生 → 自身条件不弱

第五步 画路线图
  世（得日生）◄── 官鬼（动化父，回头生）──► 中标文书
  兄弟（动化退）─ 克财/争位 ─ 力量递减

第六步 结论
  病：有竞争者（兄弟发动）
  药：竞争者化退 + 官鬼动化父母回头生
  判定：有病有药，且病轻药重 → 顺利，中标概率高
  应期：官鬼化父母，应期在父母爻值日或逢合之日

```

> **演练要点**：动变分析的顺序永远是"**先回头（变对动）、再对外（动对他爻）、最后静爻**"。跳步就会乱。
