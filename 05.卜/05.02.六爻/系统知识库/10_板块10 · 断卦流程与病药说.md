> 这一块是全体系的核心交付：把前面九块的知识，压成一套**照着走就不会漏**的标准流程。

### 10_1 病药说：断卦的核心方法论

典籍中最精炼的一句：

> **"天机尽泄于有病之间，断法总在于医药之处。"**

**翻译**：卦象的玄机，全部藏在"有病"的地方；断卦的方法，全部落在"找药"的动作上。

+ **病**：卦中不和谐、导致凶险的关键矛盾——用神衰败、被忌神动克、逢月破日冲、入墓化绝化死、被合住、伏藏不出。
+ **药**：能化解这矛盾、化凶为吉的因素——原神发动生扶、忌神被制服、用神逢合解冲、绝处逢生、出空填实、冲开墓库。

**于是断卦流程被压缩成三步**：

```plain
寻病 → 查药 → 定吉凶

```

**病药组合的四种结局**：

| 组合 | 结论 | 现实对应 |
| --- | --- | --- |
| 有病 无药 | 凶，无解 | 问题致命且无解 |
| 有病 有药 | 先凶后吉，或无妨 | 有问题但能解决 |
| 病重 药轻 | 坎坷，勉强 | 问题大、资源少 |
| 病轻 药重 | 顺利，甚至过度 | 问题小、助力足 |

```plain
病药天平示意
        病                    药
   ┌─────────┐          ┌─────────┐
   │ 用神月破 │          │ 原神动生 │
   │ 忌神发动 │   VS     │ 忌神被制 │
   │ 入墓化绝 │          │ 冲开墓库 │
   └─────────┘          └─────────┘
      ████                  ████████
      病轻                    药重
              → 顺利

```

> **现代转译**：病药说本质上是一套"诊断—处方"结构。任何决策分析，都逃不开这三步：当前核心矛盾是什么？有哪些可用资源？资源够不够解决矛盾？

**应期推断也遵循病药原则**：卦中阻碍为"病"，解除阻碍的时空为"药"。**找到病处，配好药法，应期自然浮现**——这是把吉凶判断与应期推断统一起来的关键。

### 10_2 九步断卦 SOP

#### 第一步：审卦定坐标

+ 记录起卦时间（农历、干支）、卦名、卦宫、世应位置
+ 装好地支、六亲、六神
+ **先定"卦种"（问的是什么事）**——这一步错了，后面全白搭

#### 第二步：定世应，分主客

+ 世爻 = 自己，应爻 = 对方或环境
+ 世应相生相合 → 主客顺畅；相克相冲 → 立场对立
+ 检查：世应是否旬空（"世应俱空，人无准实"）
+ 确认：自占看世，代占看应

#### 第三步：取用神，锁定靶心

+ 按事类取用，**一事一用神**
+ 用神两现 → 走六步候选阶梯（板块 5_6）
+ 用神不现 → 查日月 → 查伏神（板块 9_3）

#### 第四步：察旺衰，判基础盘

+ 看月建、日辰对用神的作用（旺 / 相 / 休囚 / 空破）
+ 检查月破、旬空，并判断真假（板块 6_6）
+ 评估卦气纯杂（杂气多则事拖延）

#### 第五步：辨动静，找关键变量

+ 有动看变卦；六爻皆静才取互卦（板块 12_3）
+ 动爻生用神 = 助力；动爻克用神 = 阻碍
+ 检查反吟伏吟、进退神、回头生克、暗动

#### 第六步：明生克，画作用路线图

+ 理清用神—世爻—原神—忌神—仇神关系（板块 7_4、7_8）
+ 应用"变能克动、动难克变""静难制动"两条单向法则
+ 检查贪生忘克、贪合忘生（板块 7_5）

#### 第七步：查飞伏与空破，补隐性信息

+ 用神不现 → 查伏神能否出头（六能五不能，板块 9_4）
+ 旬空月破 → 判断是否真空真破

#### 第八步：综断吉凶，下结论

**判断顺序（这是优先级，不要乱）**：

```plain
1. 用神旺不旺？       → 旺则有成事能力
2. 用神动不动？       → 动则有进展
3. 元神帮不帮？       → 帮则有贵人助力
4. 忌神攻不攻？       → 攻则有阻碍
5. 世爻状态如何？     → 世衰则自身能力不足
6. 用神与世爻关系如何？ → 关系好则事对自己有利

```

#### 第九步：定应期

按板块 11 的七类断应技术推断（合冲待变、空亡待实、墓库待冲、衰旺待时、动变寻机）。

```plain
九步流程全图
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 第1步 审卦定坐标 → 第2步 定世应 → 第3步 取用神
        ↓
 第4步 察旺衰 → 第5步 辨动静 → 第6步 明生克（画路线图）
        ↓
 第7步 查飞伏空破 → 第8步 综断吉凶（病药定论）→ 第9步 定应期
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 10_3 断卦前先看"大气候"：卦象级信号优先

古书明确说："**卜者常泥于用神而失之。**" 很多人一上来就抓用神旺衰，恰恰是本末倒置。

**正确顺序：先看整个卦的"大气候"，再看具体爻位的"小天气"。**

**必须先看卦的五种情况**：

1. **婚姻忌三冲**（卦冲、爻冲、日月冲）→ 不用看用神旺衰，先论不顺
2. **征伐竞争忌内卦反伏** → 不凭子孙、官鬼
3. **迁居忌外卦反伏** → 不凭官鬼静
4. **占病**：主属（病人对应之爻）化墓、化绝 → 即用神旺亦凶
5. **风水（茔葬）**：巽（风）、坎（水）、乾（石）、兑（沙）、离（蚁）、蛊（虫）、井（泉）、明夷（伏尸）为忌卦

**卦验的参考库**（模式识别素材，非铁律）：

| 事体 | 吉卦 | 凶卦 |
| --- | --- | --- |
| 天时晴雨 | 乾、离 = 晴 | 坎、兑 = 雨 |
| 求财 | — | 萃 = 亏本 |
| 出行 | — | 节、艮、坎、明夷 = 不吉 |
| 狱讼 | 大壮、夬 = 得理 | 坎、蹇、明夷 = 有囹圄 |
| 疾病 | — | 明夷、既济、丰、节 |
| 婚姻 | 咸、恒、节、泰（变冲则凶） | 睽、革、解、离（化合亦凶） |

**八卦验的经典句式**（因卦象取义）：

```plain
噬嗑（日中为市）→ 宜贾肆      涣（木在水上）→ 利江河
离 → 佃鱼                      随 → 驾马
益 → 农田                      艮、离、咸、蛊 → 蚕有收

```

**卦验使用的底线（务必遵守）**：

> **用神为主，卦验为次；动爻为主，卦名为辅。凡卦名断语与用神旺衰相冲突时，一律从用神。**

卦验章的价值在于"让你多一个观察维度"，而不是"给你一张可以直读的对照表"。古籍自己也说"兼察用象更确""不宜执一而断也"。

### 10_4 六神与神煞的正确位置

**最具革命性的论断**：

> "是故吉凶神煞之多端，何如生克制化之一理。"

**三条使用规则**：

1. **神煞之权重，远轻于五行生克**。六神只能"推其性情形状"，吉凶得失当专以六亲生克为主。
2. **六神必须叠加在用神之上**才有意义。朱雀需配兄弟方成口舌，玄武需配官鬼方成盗贼（六神类象表见板块 4_4）。
3. **按事类取煞，不遍查**。占婚姻用红鸾类，占官运用三台八座类，占行人用信息类神煞——神煞上百种，各取所需，而不是每卦全部查一遍。

**神煞的真假之分**：

+ **真神煞**（能应验）：旺相有气、重叠多现、不犯旬空
+ **假神煞**（不能应验）：休囚无气、旬空月破

**四直之力分层次**：年之力 > 月 > 日 > 时。

#### 案例小故事：官鬼持世，到底是凶还是吉

**背景**：《增删卜易》记载了一个经典卦例。一人**自占病**，起卦得**官鬼持世**。此人并非公职人员，患病已有一段时日，症候迁延，自己心里没底，于是起卦问吉凶。

**常规判断**：官鬼在疾病卦中代表病症，现在官鬼落在世爻上——世爻是病人自己，病症缠身，这不是大凶之象吗？按持世口诀"官鬼持世，非公职者多主病患缠身"（板块 5_8），确实偏凶。

**断卦者的细看**（四步）：

1. **定病**：官鬼持世，确实是"病在身"之象，这是卦中的"病"。
2. **找药**：但再看全卦——卦中**子孙爻强旺，且发动**。在疾病卦里，子孙是医药、是克制官鬼的力量（子孙克官鬼）。
3. **看作用**：子孙旺动，直接来克世爻上的官鬼。这就是"**药在克病**"。
4. **病药定论**：有病（官鬼持世），有药（子孙旺动克之），且药力充足 → **先凶后吉，可愈**。

**结论与应验**：断为吉，并告以"药对症，不必更医"（古人原断如此；今日的对应做法是：遵医嘱完成当前治疗，不必因焦虑频繁更换方案）。后果然痊愈。

**要点提炼**：

+ 当用神本为"忌神"时，若有强大制化，反为吉兆。这就是"增删"二字的真义——**增的是变通，删的是教条**。
+ 如果只记住"官鬼持世 = 凶"这一句口诀，这一卦就断反了。
+ 这正是病药说的价值：**先找病（官鬼持世），再找药（子孙旺动克之），然后才定吉凶（有病有药 → 吉）**。顺序不能颠倒。
+ **今日的边界提醒**：这一卦的"子孙旺动=医药对症"是古法象意，落实到现在，它的作用是提示"治疗方向对、可安心配合"，**绝不等于可以据此停药或拒绝就医**（板块 14_3 红线）。

### 10_6 高频误判八条（完整总表见板块 17_5）

| 常见误判 | 错在哪 | 正确做法 |
| --- | --- | --- |
| 见空就断凶 | 没分真假空 | 动空、旺空、填空、临日月 — 皆不作真空（板块 6_6） |
| 见月破就断无解 | 把"最衰"当成"无救" | 破而有生扶、出月逢合可解 |
| 见官鬼持世就断凶 | 忘了查"药" | 子孙旺动克之，反为去病之吉（10_4） |
| 一上来就抓用神旺衰 | 跳过了卦象级信号 | 先看反伏、游归、六冲合，再看爻（10_3、板块 8_7） |
| 卦名好就断吉 | 卦验凌驾于用神 | 用神为主，卦名为辅；冲突时从用神 |
| 六神定吉凶 | 修饰层当主断 | 六神需配六亲方成事象 |
| 数生克的个数定吉凶 | 只看数量不看链路 | 画路线图，看力量来源与权重 |
| 用神取了多个 | 一卦多问 | 一卦一事、一卦一用神 |

### 10_7 断卦实战演练（完整走一遍九步）

**题目**：某人问"我投的这个岗位，能否拿到录用通知？"

**装盘结果**（简化）：

+ 卦宫：离宫，卦宫五行属火
+ 月建：巳；日辰：酉；旬空：辰、巳
+ 世爻在三爻（己亥水，官鬼持世）；应爻在上爻（己巳火，兄弟）
+ 动爻：五爻（己未土，父母）发动，化戌土；初爻（己卯木，子孙）安静

```plain
第一步 审卦定坐标
  离宫火，卦种 = 求职应聘

第二步 定世应
  世在三爻（我，官鬼持世）；应在上爻（对方/环境，兄弟）
  世应关系：亥水克巳火 → 世克应，我方主动，对方被动
  注意：应爻巳火恰落旬空 → 对方（岗位方）诚意不足或岗位有变数

第三步 取用神
  求职 → 官鬼为职位/面试官；父母为简历/offer
  官鬼持世且旺相？亥水在巳月被冲（巳亥冲）→ 月破！
  父母未土在巳月得生 → 旺相，且发动

第四步 察旺衰
  用神官鬼亥水：月破 + 日辰酉金生之（金生水）→ 有救
  判断：病在月破，药在日生 → 有病有药，但病重

第五步 辨动静
  父母未土发动化戌土 → 未戌不属进退组合，为比和之化
  但父母旺动 → 资质文书有力
  子孙安静 → 不克官鬼，无阻碍

第六步 明生克
  路线图：
    日辰酉金 ──生──► 官鬼亥水（世）
    父母未土（动）──► 土克水，父母克官鬼！
    关键：求职卦中"父母克官鬼"是凶象
             （资历过强或文书有误，反损机遇）

第七步 查飞伏空破
  旬空辰、巳 → 官鬼亥水不空
  应爻巳火空 → 对方（应）旬空 → 岗位方态度不明

第八步 综断吉凶
  病：官鬼月破 + 父母动而克官鬼 + 应爻旬空
  药：日辰酉金生官鬼
  判定：病重药轻 → 坎坷，希望不大，且对方态度不明

第九步 定应期
  官鬼月破 → 出月或逢合之期（亥与寅合，寅月/寅日）
  建议：若寅月之前无消息，则此岗基本无望

```

> **演练要点**：这一卦最容易被"父母旺动"误导成吉。实际上求职卦里**父母克官鬼是明确的凶象**（资历与岗位不匹配 / 简历有问题），加上应爻旬空，整体是"病重药轻"。断卦时，**每一条生克关系都要放回"这件事"的语境里解释**，不能只记"旺 = 吉"。

### 10_8 完整卦例：从提问到回填（端到端示范）

前面两节是"拆开练"，这一节给一张**从摇卦到回填的完整卦例**，用来对照自己的档案格式。

**背景**：一家小型五金配件厂的老板，去年给一家整机厂供了两批货，验收合格、发票已开，但合同约定的尾款（含 5% 质保金）拖了近三个月。对方对接人每次都说"财务在排期"，既不说不给，也不给具体日期。他想知道这笔钱近期能不能到账、要不要走正式催款函。

**提问（原话照录）**："我给这家整机厂供的货，尾款在三个月内能不能到账？"

> 这个问题符合"一卦一事、时间明确、对象明确"三条（板块 0_4）。他没有问"我要不要起诉"（那是另一卦），也没有问"对方财务到底卡在哪"（那是窥探他方内部，属边界之外）。

**摇卦记录**（铜钱法，口径 A：背为阳、字为阴）：

```plain
时间：公历 X 年 X 月 X 日 巳时    农历 X 月 X 日
月建：寅（按节气）    日辰：甲申    旬空：午、未
所问：尾款三个月内能否到账？
摇卦（自下而上）：
  第一次 两背一字 → 少阴 --   初爻
  第二次 一字两背 → 少阳 一   二爻
  第三次 两背一字 → 少阴 --   三爻
  第四次 三背     → 老阳 一○ 四爻（动）
  第五次 一背两字 → 少阳 一   五爻
  第六次 两背一字 → 少阴 --   上爻

```

**装盘结果**：

```plain
本卦：泽地萃（兑宫二世卦，卦宫五行属金）
  上爻  未土 父母  --   玄武
  五爻  酉金 兄弟  --   白虎    ← 应爻（对方）
  四爻  亥水 子孙  -- ○ 螣蛇    ← 动爻，化子水（进神）
  三爻  卯木 妻财  --   勾陈    ← 用神
  二爻  巳火 官鬼  --   朱雀    ← 世爻（我）
  初爻  未土 父母  --   青龙（午未空，此爻落旬空）
世在二爻（二世卦），应在五爻

```

> 六神按甲日起青龙自初爻顺排；午未空，初爻、上爻两个父母爻落空。

**九步推演**：

```plain
第1步 审卦定坐标：兑宫金，卦种 = 求财 / 回款
第2步 定世应：世在二爻（我，官鬼持世），应在五爻（对方，兄弟酉金）
第3步 取用神：问钱 → 妻财卯木（三爻）为用神
第4步 察旺衰：
   月建寅（木旺）→ 卯木临月气，旺相
   日辰甲申 → 申金克卯木，但金在寅月囚，克力有限
   → 定档：旺相
第5步 辨动静：四爻子孙亥水发动，化子水（亥化子为进神）
   子孙亥水 → 水生木 → 原神发动生财，且化进 → 助力持续增强
第6步 明生克（路线图）：
   子孙亥水（动化进）══生══►【妻财卯木：旺】◄ ─克─ 日辰申金（囚）
   应爻兄弟酉金（囚、安静）─ ─ 有夺财之心而无夺财之力
   世爻官鬼巳火 ← 财生官 → 自身在消耗（精力、催款成本）
第7步 查飞伏空破：用神卯木不空不破；初上两父母爻落空（文书/票据暂无动静）
第8步 综断吉凶：
   病：日辰克财 + 应爻兄弟（对方有拖欠倾向）+ 官鬼持世（自身有损耗）
   药：财临月建旺 + 原神子孙发动化进生财 + 忌神兄弟安静且囚
   → 病轻药重，可收回，但需主动催，且会被分掉一部分
第9步 定应期：子孙动而化进（亥化子）→ 逢值逢合
   近期：子日前后（最快）
   中期：子月（最晚）
   财爻旺相不动，亦待冲动之期（酉日 / 酉月）为备选

```

**给问卦人的话（结论四件套）**：

```plain
结论：能收回，但不会全额、也不会自动到账。
原因：财爻本身旺（钱在），原神发动化进（催款动作会推动事情）；
      但对方（应爻兄弟）有拖欠与分利的倾向，且官鬼持世说明这个过程会消耗你。
时间：最快子日前后，最晚拖到子月；给区间，不承诺某一天。
行动：本周内发出书面催款函并留痕（对应"原神发动"——要动才有生）；
      对质保金部分提前做好扣减预期（对应"兄弟为分利者"）。

```

**事后回填**：

```plain
实际结果：子月中旬到账，金额为合同尾款的 82%
          （对方扣除了 5% 质保金，另扣一笔"验收整改费")
时间核验：应期命中（子月），卦象给的"子日—子月"区间成立
偏差复盘：
  第1步 验结果：吉凶对、区间对；金额打折这条卦里有提示（兄弟为分利者），
     但当时只说"会被分掉一部分"，没敢说"会扣质保金之外的费用"——
     下次遇到应爻兄弟安静而不空，应直接提示"对方会在金额上做文章"
  第2步 验取用：妻财为用神正确；辅助看应爻（对方）与子孙（催款动作）也对
  第3步 验权重：当时把"日辰克财"看得偏重，实际克力有限（金囚于寅月），
     真正的变量是"原神发动化进"——是我方的催款动作推动了回款
下次改什么：判断"克力"时必须先判施克者的旺衰，不能只看有没有克

```

> **这一卦最值得学的一点**：卦里的"药"（子孙发动化进）不是天上掉下来的，它对应的是**问卦人去发函、去催**这个动作。断卦者把"药"翻译成具体行动，比只说"能收回"有用得多——**卦给条件，行动兑现条件**。

### 10_9 断卦的交付格式：结论四件套

断完不等于交付完。给问卦人的话，按这四件写，缺一件都会让对方"听完不知道该怎么办"：

| 件套 | 写什么 | 反例（不要这样写） |
| --- | --- | --- |
| **结论** | 成 / 不成 / 先难后易，一句话定调 | "卦象比较复杂，吉凶参半" |
| **原因** | 病是什么、药是什么，用卦象语言说清 | "官鬼持世，不太好" |
| **时间** | 给区间与快慢两点，不硬编日子 | "初八一定到" |
| **行动** | 卦里的"药"对应现实中哪个具体动作 | "顺其自然就好" |

**三条表达纪律**：

1. **凶卦要给出口**：断凶时一并给出"什么条件下会转好"（出空、出月、逢合、忌神受制），否则对方只会躺平。
2. **吉卦要给提醒**：断吉时提示"靠什么成的"（原神动＝要主动、财临月建＝窗口在本月），否则对方只会空等。
3. **涉及医疗、法律、金额时收口**：卦象只作参考，明确提示就医、咨询律师、按合同办事（板块 0_2 五条边界）。
