> 从摇卦到决断：一套可拆解、可复盘、可纠偏的事态推演体系。

### README_1 这套知识库在做什么

六爻，学名**纳甲筮法**，因一卦由六爻组成而得名。它通过摇卦得到一个六画卦象，再往六条爻上装配天干地支、六亲、世应、六神等要素，据此分析所问之事的吉凶趋势与应验时机。

它的运作机制可以这样理解：

> 人在起念的那一刻，问题已经与你所处的现实处境绑定；卦象做的，是把这个处境"翻译"成一张阴阳五行结构图，再通过五行生克、旺衰动静、世应关系，推演"能不能成、什么时候成、卡在哪里"。

因此它的真实身份，是**一套以卦为模型的现实事态推演系统**——与现代决策分析在思维方式上高度同构。

它属于传统"五术"（山医命相卜）中的"**卜**"：针对一件具体的事起卦发问，回答的是"这件事的趋势与时机"，而不是给一个人的一生下总判断。

### README_3 三条纲领：由粗到精的三层过滤

1. **生克定吉凶**——用神被生扶则吉、被克泄则凶。答"**是不是**"。
2. **旺衰定程度**——同样得生，旺相者力强、休囚者乏力。答"**有多强**"。
3. **动静定应期**——动爻、变爻、冲合决定何时发生。答"**什么时候**"。

这三条不是并列的，而是**由粗到精的过滤层**：先用生克筛掉明显吉凶，再用旺衰细化程度，最后用动静锁定时间。新手最容易跳层——还没用生克定性，就急着断日子。

### README_4 四大支柱

### README_5 心法四句

1. **理法是骨架，象法是血肉**——只学一个，永远断不准。理法给你"能不能成"，象法给你"是什么、在哪、怎么样"。
2. **断语是结论，生克是原因**——所有古诀都有前提条件，先推导后参考。看到断语先问"为什么"，推不出来就别用。
3. **卦随事转，神随境移**——用神按"关系结构"取，不按死标签取；同一组合在不同场景里吉凶可以完全相反。
4. **少断多验，复盘成才**——高手是复盘练出来的，不是天生的。

### README_7 核心方法论：病药说（精要版，展开见板块 10）

典籍中最精炼的一句：

> **"天机尽泄于有病之间，断法总在于医药之处。"**

**翻译**：卦象的玄机，全部藏在"有病"的地方；断卦的方法，全部落在"找药"的动作上。

+ **病**：卦中不和谐、导致凶险的关键矛盾——用神衰败、被忌神动克、逢月破日冲、入墓化绝化死、被合住、伏藏不出。
+ **药**：能化解这矛盾的因素——原神发动生扶、忌神被制服、用神逢合解冲、绝处逢生、出空填实、冲开墓库。

```plain
寻病 → 查药 → 定吉凶

  有病无药 → 凶，无解
  有病有药 → 先凶后吉，或无妨
  病重药轻 → 坎坷，勉强
  病轻药重 → 顺利，甚至过度

```

**现代转译**：病药说本质上是一套"诊断—处方"结构。任何决策分析，都逃不开这三步：当前核心矛盾是什么？有哪些可用资源？资源够不够解决矛盾？

### README_8 九步断卦 SOP（速记版，展开见板块 10）

```plain
第1步 审卦定坐标  → 第2步 定世应  → 第3步 取用神
        ↓
第4步 察旺衰 → 第5步 辨动静 → 第6步 明生克（画路线图）
        ↓
第7步 查飞伏空破 → 第8步 综断吉凶（病药定论）→ 第9步 定应期

```

**第八步判断吉凶的优先级顺序**（不要乱）：

1. 用神**旺不旺**？→ 旺则有成事能力
2. 用神**动不动**？→ 动则有进展
3. 元神**帮不帮**？→ 帮则有贵人助力
4. 忌神**攻不攻**？→ 攻则有阻碍
5. 世爻**状态如何**？→ 世衰则自身能力不足
6. 用神与世爻**关系如何**？→ 关系好则事对自己有利

### README_9 力量层级（极易忽略，展开见板块 6）

```plain
月建、日辰  >  动爻  >  变爻（仅作用于原动爻）  >  静爻

```

+ 月建日辰可生克卦中所有爻，但**爻无法反作用于月日**——"爻伤日，徒受其名；日伤爻，真罹其祸"。
+ 动爻可生克静爻，**静爻不能生克动爻**——"静受动伤，静难制动"。
+ 变爻只作用于它所对应的那个原动爻（回头生、回头克）。
+ **动爻若被日辰合住，则暂时失去生克权**，需待冲开之日方能发力。

### README_11 应期速记口诀（展开见板块 11）

```plain
静旺逢冲衰逢值，动逢值合变爻期。
空出填实冲空应，月破出月合破时。
入墓冲墓冲用应，伏藏冲飞值伏宜。
化进逢进退逢退，回头生克看变支。
太旺墓库休囚生，合处逢冲冲逢合。
吉应生扶制忌日，凶应忌旺用受克。

```

两条总原则：**病药原则**（阻碍为病，解除阻碍的时空为药）、**动静优先**（动则待合，静则待冲）。

**两条铁律**：

1. **一段时间内只跟一个体系**。同时看三种风格的书，等于同时学三种方言——看起来博，实则永远在翻译，无法形成条件反射式的判断力。
2. **每卦必回填**。断十卦不回填，不如断一卦回填十次。

**三条实用读法**（对应不同目标，详见板块 0_6）：

+ **想最快上手**：板块 1+2（能起卦）→ 3+4（能装盘）→ 5~7（取用、旺衰、动变）→ 10（断卦总纲）→ 11、13~15（应期与分类）。注意 5~7 不能跳，10 本身就是这三条的总装。
+ **想学得扎实**：按 0→17 顺走，每步做完立刻用真实卦例练习；答错的地方回单元重读，比通读三遍有用。
+ **已有命理基础**：可略过板块 1~2 的符号复习，但**必须过板块 3+4**——全课最常见的卡点不在分析，而在装卦：装盘错了后面全错，而自己往往看不出来。

### README_13 理性边界声明（总纲，操作化清单见板块 0_2，修炼约束见板块 17_7）

六爻属于中国传统民俗文化与术数体系。本知识库将其定位为"**以卦象为模型的事态推演与决策分析框架**"，供文化研究、思维训练与自我思辨参考，不构成现实决策的唯一依据，请勿用于高风险投机，更不得替代医疗、法律、金融等专业判断。

**三条不可逾越的红线**：

+ **健康问题**：第一选择永远是就医，卦象只作辅助参考。
+ **法律纠纷**：请咨询专业律师，六爻只作心理与策略层面的参考。
+ **金融决策**：可用于评估投入某项目的风险与可能性，**不能用于预测单只股票的明日涨跌**。

**祛魅三原则**：

+ **反对宿命论**：吉卦骄纵亦转凶，凶卦修德可转吉。
+ **反对鬼神论**：官鬼爻是忧患、约束、疾病、官方力量的符号，不是真实的鬼神。
+ **反对投机论**：筮以决疑，不占以侥幸；同一件事反复摇卦，信息必然失真。

卦象显示的是**当前趋势**，不是注定的结果；占卜给出的是**需要调整的方向**，不是不可更改的命运。

### README_14 本库的自我要求

1. **断卦是经验技艺**：规则本身是确定性的，但"把卦断准"需要大量实卦记录与复盘校验，绝非学几条口诀就能未卜先知。切勿把单一规则或卦例当成普遍结论。
2. **不提供代占服务**：本库教的是方法，不是替人决断。代占他人之事的传统取用法（板块 5_5、15_1）属于学习内容，不等于鼓励窥探他人隐私。
3. **一切断语带条件**：凡"必凶""无解""必成"式的绝对句式，本库都会补上"它在什么条件下不成立"。
