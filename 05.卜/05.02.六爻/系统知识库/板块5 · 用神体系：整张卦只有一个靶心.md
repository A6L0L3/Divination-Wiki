# 板块5 · 用神体系：整张卦只有一个靶心

> 用神取错，后面算得再精细也是"精确的浪费"。

这是高手与新手的第一个分水岭：高手起卦后第一件事不是断卦，而是**花时间确认用神**。

---

## 5_1 用神的本质：断卦的第一性原理

用神，就是**你所问之事在这张卦里对应的那个爻**。

古法的核心命题"**卦定根源，六亲为主**"，说的就是这件事。清代盲人筮师程良玉直到十八岁才真正悟透这一层：

> 天下之事亿兆纷纭，何以得一理贯通其吉凶而后不惑？年登十八，始悟用爻。**惟一用爻，而求诸吉凶乃得其柄**。

**为什么用神是第一位的**：整张卦有六个爻、五种六亲、六种六神、若干动变，信息量极大。没有用神，这些信息就是一团乱麻；有了用神，所有信息立刻分成三类——

```plain
        帮我的（原神 / 元神）
              │
              ▼
        【用神：靶心】
              ▲
              │
        害我的（忌神 / 仇神）

   其余爻 = 无关信息（可搁置）

```

## 5_2 六亲类象全表：断卦的字典（全库唯一完整表）

六亲不只是"父母兄弟"五个词，它们是**人事与事物的分类系统**。类象越具体，断出来的细节越丰富。

| 六亲 | 核心定义 | 人事 | 事项 | 身体 / 地理 | 现代类象拓展 |
| --- | --- | --- | --- | --- | --- |
| **父母** | 生我者 | 父母、长辈、师长、贵人、文人、司机、劳务人员 | 工作、文化、学历、调动、信息、通讯、劳动、保障、信号 | 头、面、胸腹、背；房、田地、地产、医院、单位、学校、店面、建筑物 | 合同文本、学历学位、房产证、公司资质、培训、印章审批、票据、知识产权、手机电脑、考试成绩 |
| **官鬼** | 克我者 | 领导、上级、丈夫（女测）、小人、官方、面试官 | 官职、功名、事业、疾病、官司、盗贼、压力、灾祸 | 雷电、尸体；公章 | KPI 考核、甲方、监管、诉讼风险、慢性病、职位竞争、政府审批、政策调控 |
| **妻财** | 我克者 | 妻子、女友（男测）、情人、下属、被管理者 | 钱财、货物、资产、珠宝、粮食、饮食、欲望、掌控 | 工资卡、盆栽、饮食 | 现金流、应收账款、库存、投资标的、薪资报酬、有价值的一切资源 |
| **子孙** | 我生者 | 子女、学生、晚辈、宠物、僧道、九流术士 | 医药、福气、解忧、娱乐、财源、技艺、装饰、酒食 | 药品、短视频、空调 | 医疗方案、技术能力、创意、客户（生财之源）、休闲、解困的人或办法 |
| **兄弟** | 同我者 | 兄弟姐妹、朋友、同事、同辈、竞争者 | 竞争、阻隔、破财、口舌、分割、分配、帮扶 | 门窗、手臂、篱笆、健身器材 | 同行竞争、合伙纠纷、价格战、预算超支、分利润者、拦路环节 |

**理解六亲的底层逻辑**（不要死背，要会推）：

```plain
父母 = 生我者 → 保护我、滋养我的一切 → 长辈、房子、文书、知识、资质
官鬼 = 克我者 → 约束我、消耗我的一切 → 上级、疾病、官司、压力、监管
妻财 = 我克者 → 被我掌控、可支配的一切 → 钱财、物品、下属、收益
子孙 = 我生者 → 由我生出、能帮我泄忧的一切 → 子女、技艺、医药、客户
兄弟 = 同我者 → 与我同类、分我资源的一切 → 同辈、竞争者、合作分利者

```

按这个逻辑推，遇到没背过的现代事物也能现场归类。例如"软件著作权"——保护性、凭证性的无形资产，归父母；"竞争对手的低价策略"——分我市场，归兄弟。

> **一条通用判据**：**凡具有承载、保护、抚育、滋养、保障、容纳性质的人事物，都以父母爻为用**。这条原则可以覆盖绝大多数新事物。

## 5_3 六亲的喜忌：应吉应凶的条件

同一个六亲，在不同占问里是"喜"还是"忌"，取决于它对用神的作用。通用判断框架：

```plain
第1步 该爻临"喜支"且旺相无伤、不空    → 应吉
第2步 该爻临"忌支"但休囚无气或受制    → 应吉（害不了人）
第3步 该爻临"忌支"且旬空              → 应吉（坏事落空）
第4步 该爻临"忌支"旺相无伤，但世爻空  → 应吉（我虚不受害）
第5步 除以上情形外                    → 应凶

```

**实操简化版**（不必死记五条，抓核心两句）：

+ **对用神起好作用的爻，越旺越吉**；
+ **对用神起坏作用的爻，越衰越吉**（衰则无力为害，空则坏事落空）。

## 5_5 用神按"关系结构"取，不按身份标签取

这是最有现代价值的一点：用神不是按"年龄 / 身份标签"取的，而是按**这件事里的关系结构**取的。

| 事体 | 取用之"反常"处 | 背后的关系逻辑 |
| --- | --- | --- |
| 老奴占幼主 | 用**父母**（非子孙） | 奴视主如子，关系定义用神 |
| 少主占衰仆 | 用**妻财**（非官鬼） | 仆是"我所役使的财产性存在" |
| 词讼 | 凭**官**而后看世应 | 胜负取决于听讼者（官方） |
| 寿命 | 凭**用**而后看父母 | "用"是命主自身元气 |
| 乡会试（科目） | **先文（父母）后官** | 先有文章，后有功名 |
| 廷试（殿试） | **先官后文** | 廷对重"对君之言"，官鬼为先 |

**实操心法**：

> 不要问"这个事一般用哪个用神"，要问"在这个具体关系里，**谁是主、谁是从、谁是被作用者**"。宁可在起卦前花三分钟把关系写清楚，也不要起完卦后凭口诀硬套。

**现代迁移示例**：

+ 占"我能不能拿下这个客户" → 客户是生财之源，取子孙爻；同时看妻财（合同金额）与世应（双方关系）。
+ 占"我的专利申请能否通过" → 专利是文书凭证，取父母爻；审查方是官方，参看官鬼爻。
+ 占"这项政策对我的影响" → 政策是约束性力量，取官鬼爻；看它生世还是克世。
+ 占"我要不要跟这个平台签约" → 平台是承载方，取父母爻（合同 + 平台资质）；收益看妻财。

### 案例小故事：老奴占幼主，为什么用父母不用子孙

**背景**：清代《易冒》记载了一个反直觉的取用法。一位在府中服侍了几十年的老仆，给年仅十岁的小主人占病。小主人连日低热不退，府里请了两位大夫，说法不一，老仆心中无底，于是自己起了一卦。

**常规思路的陷阱**：小主人是"晚辈"，按六亲类象，晚辈属"子孙"（我生者）。若按身份标签取用，应当看子孙爻。老仆自己也是这么想的——他一看子孙爻休囚，当场就慌了，以为小主人凶多吉少。

**关系结构的分析**：程良玉指出，六亲按**关系结构**定，不按年龄标签定。在这段关系里——

+ 老仆是被**供养、庇护**的一方：他住府里的屋、吃府里的粮，几十年的生计都系于这个家。
+ 小主人家是**供养者**：对老仆而言，小主人是"生我者"——提供衣食、庇护、生计来源。
+ "生我者"在六亲中正是**父母**。

**结论**：老奴占幼主，用**父母爻**为用神——按父母爻看，这一爻旺相有气，病可愈。后来小主人按第二位大夫的方子调理，旬日而愈。

**对偶的另一半**：反过来，年轻的主人给年老的仆人占，用**妻财**——因为在主人眼里，仆人是"我所役使、可支配的财产性存在"，是"我克者"，正是妻财。

**自测：怎么验证这条规则真的内化了**：这条规则不是背下来就算会的，可以用两个办法自测——

1. **反向自测**：随便挑三件现代事（例如"我要不要跟这个平台签约""这项政策对我影响如何""我能不能拿下这个客户"），先不许查表，只画关系图推用神，推完再对照 5_2 与 5_4。若三次都对，说明"关系结构取用"已经内化；若还要靠查表，说明仍在标签阶段。
2. **事后回填**：凡是你用"关系结构"取用过用神的卦例，回填时多记一栏——"**如果按身份标签取，会取成什么？结论会差多少？**"。积累十卦以上，你会亲眼看到"取错用神"到底有多致命（据板块 17_4 的统计，用神取错约占全部失误的六成）。

**要点提炼**：

+ 这个案例逼你放弃"查表式取用"，转为"**先画关系图，再定用神**"。
+ 关系图的三问：**谁是主？谁是从？谁是被作用者？**
+ 养成这个习惯，遇到古籍没写过的新事物（专利、平台签约、政策影响、客户关系）才不会卡住。
+ 老仆那一卦的教训还有一层：**取错用神会直接导致情绪性误判**（他当场就慌了），而情绪一旦上来，后面所有旺衰动变都会跟着跑偏。

## 5_6 用神两现的六步候选阶梯

卦中同一六亲出现两个（如两个妻财爻），叫"用神两现"。这是断卦的关键难点。

**先解决一个历史争论**：古籍对两现取用的主张看似矛盾——

> 古法："用神两现，舍其休囚，用其旺相；舍其静爻，而用动爻；舍其月破，而用不破；舍其旬空，用其不空；舍其被伤，用其不伤。"

实战派补："余得其验者，应乎旬空月破，舍其不空，而用旬空；舍其不破，而用月破。"

看似自相矛盾，实则**二者分工不同**：

+ **古法重"无病可用"**：以旺相、无破伤之爻定**吉凶大势**，这是断事的根本。
+ **实战派补"有病可取"**：空破之爻藏**应期玄机**，这是断细节与应期的关键。

**结论：二者相辅相成，不是非此即彼。用旺相无病之爻断吉凶，用空破有病之爻断应期与阻碍细节。**

**六步候选阶梯**（按次序走，停在第一个能明确分出胜负的步骤）：

```plain
第一步  查旬空  → 优先取不空之爻（定吉凶时）
第二步  查暗动  → 优先取暗动之爻，而非纯静之爻
第三步  查明动  → 优先取明动之爻，而非静爻
第四步  查强弱  → 比较时令强度、月破状态及其他爻位条件
第五步  看月建  → 仍未定时，取坐月建者
第六步  看世位  → 仍未定时，取坐世爻者（或离世爻近者）

```

> **次序很要紧**：不要在查旬空与暗动之前就跳到动爻，也不要在查强弱与月建之前先取世位。

**三条补充规则**：

1. **占他人他事，以离应爻近者为主**；占自身之事，以离世爻近者为主。
2. **若两个用神地支完全相同**，则按**爻位**或所临**六神**定夺。例如问家宅，二爻有父母爻则取二爻（二爻为宅爻）。
3. **一空一破、一动一空时需兼断**——月破、旬空与动爻一样都有含义，不能舍去不看，而应"一看吉凶、一看应期"。

**变卦中的用神如何处理**：**用神原则上从本卦中选取**。变卦中动爻化出的用神，代表的是**未来的情况**（如"现在成功后未来还有一个""现在没成功但未来有另一个""现在成功但岗位有变化"），不能拿化出的未来工作去反推现在的成败。

## 5_7 用神不现与多重用神

**用神不现时的三步走**（概览，完整操作见板块 9_3）：

```plain
第一步：看月建、日辰
   └ 若月建或日辰的地支正是用神所属五行/地支
     → 可直接以日月为用，应期往往就在当月或当日

第二步：查伏神
   └ 去本宫八纯卦中找对应的用神爻
     → 看它伏在本卦哪一爻之下（飞神是谁）

第三步：判断伏神能否"出头"
   └ 伏神再旺，若被飞神压死、无冲无引
     → 等于"抽屉里的钱"，看得见用不上

```

**多重用神：主用神 + 辅助用神**

| 占问 | 主用神 | 辅助用神 | 判断逻辑 |
| --- | --- | --- | --- |
| 求职 | 官鬼（职位 / 面试官） | 父母（简历 / offer） | 官为主，父母为辅；官旺父不空则成 |
| 疾病 | 官鬼（病症） | 子孙（医药）、世爻（元气） | 子孙克官鬼则愈；世爻不可衰 |
| 求财 | 妻财（利润） | 子孙（财源） | 有财无源则不可持续 |
| 婚姻 | 妻财 / 官鬼（对方） | 应爻（态度）、父母（长辈意见） | 用神旺 + 世应相合方为良缘 |
| 出行 | 按身份取的六亲 | 父母（车船）、世爻（本人） | 用神克世为"物来寻我"，反主速归 |

> **一卦一用神原则**：一卦多问、同时取多个主用神，是初学者最典型的死法。辅助用神可以看，但**主靶心只能有一个**。

## 5_8 持世格局速断

用神恰好落在世爻上（持世），是极高频的情形：

| 持世 | 基本断语 | 求财 | 求官 | 疾病 | 婚姻 |
| --- | --- | --- | --- | --- | --- |
| **父母持世** | 辛苦劳碌，主文书、长辈、房屋 | 求财费力（父母克子孙，断财源） | 文书有利 | 不宜（克子孙药） | 长辈干预多 |
| **官鬼持世** | 忧患随身，主压力、职位、病 | 不利（泄财） | 得位之象 | **主病症缠身**（非公职者） | 女测有利，男测不利 |
| **妻财持世** | 有利可图，主财帛、物资 | **大吉**（财来就我） | 不利（财克父，文书受损） | 饮食不节 | 男测有利 |
| **子孙持世** | 无忧无虑，主福气、医药、技艺 | 吉（子孙生财） | **不利**（子孙克官鬼） | 吉（克病） | 不利（克夫星/妻星之源） |
| **兄弟持世** | 破财阻隔，主竞争、分利 | **大凶**（夺财） | 竞争多 | 一般 | 阻碍多 |

> **注意**：持世只是"第一印象"，**必须结合旺衰与动变**。例如官鬼持世占病本凶，但若卦中子孙爻强旺发动来克世爻官鬼，反是"去病之象"，断吉（完整案例见板块 10_4）。

## 5_9 用神与世爻的六种关系：这件事对"我"好不好

用神旺衰说明"事成不成"，世爻状态说明"我扛不扛得住"。真正决定"这件事对我是不是有利"的，是**两者之间的关系**。九步 SOP 第八步的最后一条就是它，这里展开成六种组合。

| 关系 | 象意 | 断法 | 典型场景 |
| --- | --- | --- | --- |
| **用神生世** | 事来就我、物来寻我 | **最吉**，不费力而自成 | 求财财生世＝钱自己找上门；求职官生世＝对方主动认可 |
| **用神克世** | 事来伤我、或"物来寻我" | **分场景**：一般主压力、被迫；出行行人卦中反主速归 | 疾病卦官鬼克世＝病来伤身；行人卦用神克世＝即日将回（板块 15_1） |
| **世生用神** | 我在付出、我在追 | 可成但费力，需主动投入 | 求财世生财＝要垫资、要投入才能换来 |
| **世克用神** | 我能掌控、但也消耗 | 可得而费劲，或"得到了也留不住" | 求财世克财＝能赚但辛苦；问病世克官＝自己扛得住 |
| **世用比和** | 同类、平行 | 平顺但无助力，需外力推动方成 | 合作双方对等，成败看动爻 |
| **用持世** | 事在我身 | 直接套"持世格局"（5_8），再验旺衰动变 | 官鬼持世占病、妻财持世求财 |

**三条使用提醒**：

1. **先看关系，再看旺衰**。用神生世但用神休囚，是"有心无力"，吉的程度打折；用神克世但用神休囚，是"凶不成凶"。
2. **"用神克世"是最容易一刀切的地方**——出行、行人、失物类卦中，它往往表示"对方/物件主动向我而来"，反而是速成之象（完整案例见板块 15_1）。**先定卦种，再定吉凶**。
3. **世爻自身不能太衰**。用神生世而世爻旬空，是"我虚不受生"——好事来了接不住。这与板块 5_3 的第4.条（忌神旺而世空反吉）是同一枚硬币的两面。

## 5_10 用神取定自检四问

每卦取完用神，务必自问这四句再往下走：

1. **我用的是"关系结构"还是"身份标签"？**（老奴占幼主式的反常情形有没有漏）
2. **卦里有几个同类爻？** 若两现，六步阶梯走到第几步停的？
3. **用神在不在卦里？** 不在的话，日月建上有没有？伏神是谁、飞神是谁？
4. **世爻是用神吗？** 若是，持世格局的断语套对了没有？旺衰与动变有没有跟上？
5. **用神与世爻是什么关系？** 生克比和四选一，按 5_9 的六格表解释过了吗？
