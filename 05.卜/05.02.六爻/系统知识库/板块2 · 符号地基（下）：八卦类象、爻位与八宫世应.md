**类象的推导心法（三步走，遇到没背过的事物也能现场推）**：

```plain
第一步：抓卦性（一个字）
  乾=健  兑=悦/缺  离=丽/附  震=动
  巽=入  坎=陷     艮=止     坤=顺/载

第二步：问"它像不像"
  快递：流动、运送、快 → 震（动）
  防火墙：挡住、不让过 → 艮（止）
  短视频：发声、传播、悦人 → 兑（口、悦）+ 离（屏幕、光）

第三步：叠加验证（至少两条独立线索指向同一答案才下断语）
  单条线索只能给"可能"，两条以上交叉才能给"就是"

```

> **学习提示**：类象不要死背，按"卦性 → 类象"推。震的核心是"动"，所以车辆、快递、声响、雷、舆情爆发都归它；艮的核心是"止"，所以门、山、阻挡、保安、防火墙都归它。

### 案例小故事：射覆里的"牝鸡为怪"

**背景**：射覆是古人猜隐藏之物的游戏，也是检验类象功力的试金石——物件就在眼前，看不到，全凭卦象还原。某次射覆，得**风雷益**卦，世爻之下伏一酉金官鬼。参与者需要说出"所藏为何物"。

**卦象拆解**（拿到卦先看清三层结构）：

```plain
风雷益 = 巽（上/外） + 震（下/内）
世爻之下，伏藏一爻：酉金官鬼

```

**推演五层**：

1. **理法（卦象）**：益卦下体为巽，**巽为鸡**；酉金在十二地支生肖中亦为**鸡**。两条独立线索都指向"鸡"。
2. **象法（阴阳）**：巽为阴宫（巽为长女），酉为阴金（酉为阴支）——**阴宫阴金**，指向"雌性"。
3. **爻位**：官鬼伏在**世爻之下**，说明这是与问卦人自身密切相关、且尚未显露的事物（伏神为隐、为将来，见板块 9）。
4. **六亲**：官鬼主怪异、忧患、不安——说明这只鸡带来的不是寻常之象，而是"作祟"。
5. **卦义佐证**：益卦有"增益、动而有益"之意，说明此事虽怪，但对问卦人有实际影响，不是无关紧要的闲事。

**结论**：断曰"**牝鸡为怪**"——即母鸡作祟。

**应验**：开覆核对，所藏之物果然落在"鸡"上，且是雌性——正是卦象（巽）、地支（酉）、阴阳（阴宫阴金）、爻位（伏于世下）、六亲（官鬼）五层同时指向的那一个。

**要点提炼**：

+ 这一例把"卦象（巽）+ 地支（酉）+ 阴阳（阴宫阴金）+ 爻位（伏于世下）+ 六亲（官鬼）"五层信息叠在一起用，是类象活用的范本。
+ 单一线索只能给出"可能是鸡"，五层交叉才能给出"母鸡作祟"。**类象的价值在于叠加验证，不在于单点联想。**
+ 若一上来只抓世应六亲，是断不出"牝鸡为怪""梦见火或马"这类细节的。象法给"是什么"，理法给"成不成"，两者缺一不可。

## 2_2 六爻爻位类象：一张时空全息表

这是极容易被忽略、却极其实用的一张表。同一个六亲落在不同的爻位，含义天差地别。

| 爻位 | 空间 | 身体 | 家宅 | 社会 | 事物阶段 |
| --- | --- | --- | --- | --- | --- |
| **上爻** | 屋顶、虚空、远处 | 脑、头发 | 梁柱 | 宗庙、远地、国外 | 事之终局 |
| **五爻** | 道路、中心 | 头、五官、面容 | 神位、主人房 | 君主、领导、核心 | 事之鼎盛 |
| **四爻** | 大门、户外 | 心、肺、胸背 | 大门、客厅 | 大臣、中层 | 事之转折 |
| **三爻** | 门窗、床 | 腰、肠胃、生殖 | 卧室 | 诸侯、部门主管 | 事之反复 |
| **二爻** | 宅、房屋本体 | 腿、膝、生殖器 | 厨房（**宅爻**） | 官吏、基层 | 事之显现 |
| **初爻** | 地基、足下、近处 | 足、脚趾 | 井、灶 | 平民、开始 | 事之发端 |

```plain
  上爻 ─── 远 / 终局 / 头
  五爻 ─── 核心 / 领导 / 面
  四爻 ─── 转折 / 大门 / 胸      ← 外卦（事、远、末）
 ═══════════════════════════
  三爻 ─── 反复 / 卧室 / 腰
  二爻 ─── 宅爻 / 房屋本体 / 腿   ← 内卦（我、近、本）
  初爻 ─── 发端 / 地基 / 足

```

**内外卦的分工**（判断"我"与"事"、"近"与"远"的总纲）：

```plain
内卦（初、二、三爻）：我、近、本、家里、本地、事情的开端与内部
外卦（四、五、上爻）：事、远、末、外面、外地、事情的结果与外部环境

```

**应用示例**：

+ 占疾病：官鬼在初爻 → 足伤、湿疹；在五爻 → 头痛、眼疾；在三爻 → 腰肌劳损、肠胃炎（完整对照见板块 14_2）。
+ 占家宅：**二爻为宅爻**，二爻受克则房屋本身有问题。
+ 占失物：妻财在初爻 → 物在近处、低处、家中；在上爻 → 物在远处、高处、外边。
+ 占出行：用神在外卦（四五六爻）→ 人在外地；在内卦（一二三爻）→ 人在本地。
+ 用神两现且地支完全相同时，**按爻位取用**：如问家宅，二爻有父母爻，则取二爻父母（宅爻当位）。

**爻位 + 六亲的组合速断范例**（把两张表叠起来用）：

| 组合 | 断法示例 |
| --- | --- |
| 官鬼在五爻 | 领导层的压力、头面部的病、核心岗位的竞争 |
| 妻财在二爻 | 家中财务、房屋相关的钱（房租、装修款、卖房款） |
| 父母在初爻 | 基层文书、起步阶段的手续、地基/井灶之事 |
| 兄弟在三爻 | 同级的内部竞争、卧室/部门内部的摩擦 |
| 子孙在上爻 | 远方的晚辈、事到终局有解、远处传来的好消息 |

**八宫五行**：乾兑金、震巽木、坎水、离火、坤艮土。这是排六亲时的"我"。

**爻变规则**（八宫生成的底层逻辑）：从本宫纯卦出发，严格按"由初至五、再返四、再复下"的规则变出七卦。

```plain
本宫纯卦
  ↓ 变初爻
一世卦
  ↓ 变二爻
二世卦
  ↓ 变三爻
三世卦
  ↓ 变四爻
四世卦
  ↓ 变五爻
五世卦
  ↓ 返变四爻（退一爻）
游魂卦
  ↓ 下卦三爻整体恢复本宫
归魂卦

```

**以乾宫为例**：

+ 本宫：乾 ☰☰
+ 一世：初爻变阴 → 姤 ☴☰
+ 二世：二爻再变阴 → 遁 ☶☰
+ 三世：三爻再变阴 → 否 ☷☰
+ 四世：四爻再变阴 → 观 ☷☴
+ 五世：五爻再变阴 → 剥 ☷☶
+ 游魂：五世退四爻（四爻由阴返阳）→ 晋 ☷☲
+ 归魂：晋之下卦三爻整体恢复乾 ☰ → 大有 ☲☰

> **铁律**：上爻（第六爻）为宗庙爻，永远不变。所有卦变只在初至五爻变动。

**八宫排序口诀**：乾震坎艮、坤巽离兑（乾父率三男，坤母率三女）。

## 2_4 世应：卦里的"主视角"

世爻代表"我"（求测者），应爻代表"对方 / 环境 / 所问之事"。

**世爻定位口诀**（必背）：

```plain
本宫世在上，一世世在初
二世世在二，三世世在三
四世世在四，五世世在五
游魂世在四，归魂世在三

```

应爻永远与世爻相隔两位：

```plain
世在初 → 应在四      世在四 → 应在初
世在二 → 应在五      世在五 → 应在二
世在三 → 应在上      世在上 → 应在三

```

**寻世捷法**（按上下卦三才异同推，用于快速校验）：

```plain
天同二世天变五，地同四世地变初。
本宫六世三世异，人同游魂人变归。

```

+ 比较上下卦的天爻（三爻 vs 六爻）、人爻（二爻 vs 五爻）、地爻（初爻 vs 四爻）阴阳异同。
+ **天同**（上下卦天爻阴阳相同）→ 世在二；**天变** → 世在五。
+ **地同** → 世在四；**地变** → 世在初。
+ **本宫**（八纯卦）→ 世在六；**三世异**（天地人三才皆异）→ 世在三。
+ **人同** → 游魂卦，世在四；**人变** → 归魂卦，世在三。

**寻世捷法演练**（以水火既济为例）：

```plain
既济 = 坎（上） + 离（下）
  天爻：上六阴 vs 三爻阳 → 异（天变）
  人爻：九五阳 vs 二爻阴 → 异（人变）
  地爻：六四阴 vs 初九阳 → 异（地变）
三才皆异 → 三世卦 → 世在三爻，应在上爻
（与查表结果一致：既济为坎宫三世卦）

```

**认宫诀**（用于确定卦属哪一宫）：

```plain
一二三六外卦宫，四五游魂内变更。
归魂内卦是本宫。

```

> **注意**：认宫看的是**八宫世次规则**，不是"下卦是什么就属什么宫"——这是新手最高频的一次翻车（完整案例见板块 4_5）。

**世应的三种关系与含义**：

| 关系 | 含义 | 断法 |
| --- | --- | --- |
| 相生相合 | 主客顺畅 | 事易成，双方有诚意 |
| 相克相冲 | 立场对立 | 艰难，多阻节 |
| 世应俱空 | 双方皆无诚意 | "人无准实"，谋事必有阻节 |

> **关键断语**："应位遭伤，不利他人之事；世爻受制，岂宜自己之谋。"——**代占以应为主，自占以世为主**。这条解决了"谁受伤对谁不利"的定位问题。

> **实操提示**：世应位置可以在初学阶段用排盘软件反查，但**真正要练的是"看到世应后，立刻能说出谁代表谁"**——这是后面所有分析的定位前提。

## 2_5 八卦方位（用于失物、出行、家宅的方位推断）

        坎（北）

| --- | --- | --- | --- |
