## 板块16 · 典籍精要与读书地图

> 学六爻最大的陷阱是"同时跟三个师傅"。

这一块告诉你每本书**该读什么、该跳过什么、什么时候读**。

---

### 16_1 阅读路径总图

```plain
《卜筮正宗》立骨架  →  《增删卜易》练手感与活看
        ↓
《易林补遗》通流程（反伏吟、飞伏的系统化）
        ↓
《黄金策》提心法（病药说、七大心法）
        ↓
《易冒》纠偏与深化（条件限定、真伪辨析）
        ↓
《易隐》看深（一卦多断、飞伏立体化、取数）
        ↓
《断易天机》《洞林秘诀》补象法与文献
        ↓
《京氏易传》溯源八宫、世应、飞伏、卦气

```

**三阶段读书法**：

1. **立骨架（1–2 个月）**：主读《卜筮正宗》，辅读《增删卜易》。**只读这两本，不碰其他**。
2. **通心法 + 练流程（2–3 个月）**：主读《黄金策·总断千金赋》与《易林补遗》。分占部分只取"取用法则"，不照搬断语。
3. **纠偏与深化（持续）**：读《易冒》学"给断语加条件"，读《易隐》学飞伏与取数，溯源《京氏易传》理解八宫飞伏的来历。

### 16_2 十二部典籍逐本拆解

#### 京氏易传 —— 底层代码

+ **角色**：西汉京房建立的象数易学体系，后世六爻纳甲筮法的源头。全书三卷按八宫卦序排列：上卷乾、震、坎、艮四宫；中卷坤、巽、离、兑四宫；下卷杂论卜筮、纳甲、二十四气候配卦等。
+ **每卦的标准字段**：纯阳/纯阴用事、象配某属某、与某为飞伏、几世居世、某为应、建某至某、积算起某至某、五星从位起某、某宿从位降某、降入某卦。
+ **核心内容**：八宫卦序、纳甲纳支、世应、飞伏、建候积算、卦气、五星二十八宿。
+ **硬伤与提醒**：偏天道卦气，几无民间断卦案例。后世六爻只抽取了"八宫 + 世应 + 纳甲 + 六亲 + 飞伏"，把"建候积算、五星、二十八宿"删繁就简。**学它不能只按现代六爻的套路去套，要先回到汉易"卦气"与"象数"的本源。**
+ **读法**：溯源时查阅，不作为入门教材。

#### 火珠林 —— 骨架填肉

+ **角色**：首次明确"**卦定根源，六亲为主**"，定下铜钱摇卦模式（以钱代蓍）。
+ **价值**：后世一切六爻书都在它框架上扩充。
+ **读法**：原文简短，需配后世注本；核心记住"六亲为主"这一句即可。

#### 洞林秘诀 —— 象法源头

+ **角色**：郭璞体系的辑录本，提供"卦名 → 来意 → 飞伏 → 升降 → 六神 → 应期"的完整占断链路。
+ **五把钥匙**：
    - **卦名为先**（"第一先看卦名义"）——起卦先观卦名、卦义，再论世应六亲。卦名是"天意的总括"，世应六亲是"人事的分疏"。
    - **升降爻法**——判断事物上升或下降趋势（板块 12_4）。
    - **飞伏为魂**（"六爻皆有飞伏神，世下一爻为最要"）。
    - **六神配位**——何知章、六神赋把六神运用推向极致。
    - **期日诀**——应期推断。
+ **六条主线**：卦名（定性）→ 来意（取问）→ 飞伏（表里）→ 升降（趋势）→ 六神（细节）→ 应期（时间）。**六条必须贯通使用，只学其一不得其门。**
+ **硬伤与提醒**：原书已佚，今见皆为辑本；口诀线多为后世实战派补全，**不可把辑本当原书、把引申当口诀**。
+ **读法**：学"卦名为先"与飞伏合参的思路，取其象法，不迷信其出处。

#### 断易天机 —— 文献合集

+ **角色**：明代万历年间刊行的汇编总集，辑录《天玄赋》《通玄妙论》《阐奥歌章》《洞林秘诀》《卜筮元龟》《海底眼》《鬼谷辨爻法》《丘寺丞易鉴》等难得文献。
+ **结构**：卷一起卦装卦与基础理论，卷二断卦法则与实战案例，卷三卷四六十四卦逐卦详解，卷五卷六分门占断——**从"工具"到"字典"到"索引"的三级结构**。
+ **总纲**：贯穿"德合刑冲克旺墓空"，主张"**爻不乱发，动必有因**"。
+ **独有贡献**："鬼谷辨爻法"这种六亲爻位对应方法，首次出现在汇编体系里，为预测分析拓展了信息维度。
+ **硬伤与提醒**：是"汇编"不是"原创"；神煞体系极为庞大（吉神凶煞数十种），需谨慎取用。现代通行的白话图解本把原本六卷重拆为"上篇 + 下篇 + 附录"，**并非原书的天然分卷**。
+ **读法**：卷一卷二当教材精读，卷三卷四当工具书查阅，卷五卷六当问题索引速查。

#### 卜筮全书 —— 集大成教材

+ **角色**：明代姚际隆删补旧本而成，完整收录《黄金策》。凡例阐明"贵在融通、戒占险渎"。
+ **六层递进结构**：符号地基（启蒙节要）→ 文本依据（卦爻呈象）→ 理论核心（通玄妙论 + 千金赋）→ 歌诀速断（阐奥歌章）→ 分类应用（天玄赋 + 黄金策）→ 边界慎戒（神煞歌例 + 凡例）。
+ **阅读顺序建议（反常规但高效）**：**先看结论（《总断千金赋》），再补工具（启蒙节要），最后练专题**。从头死磕极易在前两卷的歌诀海洋里劝退。
+ **硬伤与提醒**：卷帙浩繁；书前题名多为托名，**谁写的不重要，重要的是它把前人成果整理成了可教学的教材**。

#### 黄金策 —— 内功心法

+ **角色**：六爻的"总纲中的总纲"，被后世反复收录、逐句注解。
+ **七大心法**：
    1. **一理融贯**——"动静阴阳，反复迁变。虽万象之纷纭，须一理而融贯。"
    2. **贵在中和**——"夫人有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。"
    3. **生克喻象**——"生扶拱合，时雨滋苗；克害刑冲，秋霜杀草。"
    4. **日月为纲**——"日辰为六爻之主宰，月建乃万卦之提纲。"
    5. **世应定位**——"世为己，应为人，大宜契合；动为始，变为终，最怕交争。"
    6. **用神决断**——"用神有气无他故，所作皆成；主象徒存更被伤，凡谋不遂。"
    7. **神煞为辅**——"是故吉凶神煞之多端，何如生克制化之一理。"
+ **最革命的论断**：青龙动固吉，若临所忌之爻刑冲克害用神，则何益于事；白虎动固凶，若临所喜之爻生扶拱合世身，则何损于吾。**神煞之权重，轻于五行之权重。**
+ **读法**：《总断千金赋》需逐句拆解、配合注解；分占部分按需查阅。

#### 易林补遗 —— 操作手册

+ **角色**：明代盲人术士张世宝所著，按事类分断的操作手册。张世宝号星元居士，明代礼部冠带术士，幼年失明，中年后周游卖卜。
+ **总纲**："**凡事取用爻为主，动变为凭。**"——不要静态看"这个卦吉不吉"，而要看**事情处在什么阶段、向哪个方向变**。
+ **三原则**：事有大小始终缓急，各审其因；旺相主多、休囚主少、空绝主无；伏神管将来、飞神主过去。
+ **独有贡献**：首次系统纳入反吟伏吟；提出"爻爻有伏有飞，伏无不用"；明确"**变能生克于动爻，动不制扶于变象**""**静受动伤，静难制动**"（本库板块 7_3 即本此）。
+ **四层卦象结构**：主卦（现状快照）、变卦（预测路径）、互卦（过程变量）、伏神/飞神（隐性因子）。
+ **硬伤与提醒**："月破之爻无解救"等观点过苛，需修正（板块 6_5、6_6）。
+ **读法**：学它的"分类 + 规则 + 口诀"的专家系统思维。

#### 卜筮正宗 —— 学院派教科书

+ **角色**：清初王洪绪辑成，体系最规范、最适合教学。
+ **三纲领**：**生克定吉凶**（定性）、**旺衰定程度**（定量）、**动静定应期**（定时）——即本库 README 的三层过滤。
+ **断卦四步法**：审用神根基（看月建日辰）→ 察动变 → 综观特殊（合冲墓空）→ 综合定应期。
+ **力量层级**：月建日辰 > 动爻 > 变爻 > 静爻（本库板块 6_2 同）。
+ **硬伤与提醒**：禁忌观偏严苛；分类断法需理解背后逻辑而非死记。
+ **读法**：**入门首选**，配合《增删卜易》练手感。

#### 增删卜易 —— 实战派标杆

+ **角色**：野鹤老人原著、李文辉增删，历代实战派称为"六爻入室敲门砖"。
+ **四大支柱**：**世用为纲、动静为机、旺衰定基、空冲分久暂**（本库 README 第四节）。
+ **"增删"二字的真义**：**增的是变通取用、活看动变、应期推演；删的是繁杂神煞、牵强卦身、空洞天道空谈**。
+ **两大实用区分**：
    - 六冲卦在短期琐事（近病、临时纠纷）主灾厄消散，在久病长远之事主凶。
    - 用神两现时，古法取旺相无病之爻断吉凶，实战派补"空破之爻"藏应期玄机（板块 5_6）。
+ **硬伤与提醒**：理论系统性弱于《正宗》，需配合其他书补足骨架。
+ **读法**：**边读边起卦**，把它当操作手册练。

#### 易冒 —— 原理与边界

+ **角色**：清代盲人筮师程良玉所著，九十一章十卷，占题三百七十余问。讲"为什么"多于"怎么办"。
+ **总纲三层**：以年月日时经之（时间维度），飞伏互变纬之（结构维度），旺相建生空破散绝进退刑害消息之（动态调节）。
+ **三个"舍—求"**：**舍静求动、舍衰求旺、舍病而求不病。**
+ **卦用八法**：内外、冲合、反伏、墓绝、归游、卦候、卦义、卦验——**先辨卦，后辨爻**（本库板块 10_3 同）。
+ **独有贡献**：把前人当铁律的话**都加了反例**（随鬼入墓亦有不凶、月破亦可解等，本库板块 6_6、8_6 即本此）；提出用神按"关系结构"取（老奴占幼主用父母等，见板块 5_5）。
+ **硬伤与提醒**：家宅、鬼神、诸星三章逻辑过脆，历代批评中肯，**浏览即可**。
+ **读法**：理论辨析部分精读；分占部分只取"取用法则"与"真伪辨析"，不照搬具体断语。

#### 易隐 —— 高阶看深

+ **角色**：清初曹九锡辑录、其子曹璿推演补全，象数杂合的高阶体系，"上究连山归藏，下逮京焦占法，旁通壬甲，广采占歌"，参考历代占书百余种而成。
+ **独有工具**：太极丸起卦（保留京房古法，见板块 3_1）、飞伏立体化（阴阳互伏、有变伏本宫无变伏对宫，见板块 9_2）、真假六亲（一卦多断，见板块 12_2）、取数法（板块 12_1）。
+ **核心洞见**："**飞为已往，伏为将来**"；"若卦内飞神不空不破，不必更取伏神，唯六爻不见用象者，方取伏神推之"；"空下伏神，易于引拔"（本库板块 9 的三条支柱）。
+ **占戒六不占**：昏德不占、渎言不占、烦琐不占、阴邪不占、躁急不占（另补子时不占）——本质是**控制变量、保证信息纯净度**（见板块 3_3）。
+ **鲜明立场**："诚则必应，不拘子不问卜及六戊不占之说"——明确反对机械的禁忌日迷信，只重一个"诚"字。
+ **硬伤与提醒**：**不是入门书，而是查用工具书**。象数杂合，初学者极易迷失真途；全书不附六十四卦全图，默认读者会排卦识卦。
+ **读法**：有基础后再查用；无差别"爻爻找伏"只会把简单卦搞复杂。

#### 筮学指要 —— 系统教材

+ **角色**：清代吴隆誉撰，十卷由浅入深的系统化教科书。
+ **结构**：卷一基础工具（卦象、干支、五行、装卦法、世应、六亲、六神、用神、飞伏），卷二判断规则（月将、日辰、月破、旬空、旺相休囚、生旺墓绝、三合局、三刑、进神退神），卷三断卦方法论（黄金策、天玄赋、反吟伏吟、游魂归魂、何知章、应事日期），卷四至卷十专题应用（天时、家宅、终身、疾病、婚姻、功名、求财、词讼等）。
+ **核心定位**：不是"算命秘籍"，而是把古人"察阴阳、明进退、知取舍、修德行"的认知模型整理成**有理论、有规则、有程序、有逻辑**的可操作体系。
+ **独特视角**："筮无定法，唯变所适；占不妄断，以德为本。"——卦象显示的不是"注定的结果"，而是"当前的趋势"。
+ **硬伤与提醒**：偏普及，深度不及《易冒》《易隐》。
+ **读法**：作为通读教材，或作为场景库的补充索引。

### 16_4 读古籍的四个通用原则

1. **带"顶门上一只眼"**：所有断语都是**有前提条件的结论**。看到"某某必凶""某某无解"这类绝对句式，先在心里补一句"它在什么条件下不成立"，再去自己的卦例里验证。
2. **分清"纲"与"目"**：理论是纲，口诀是压缩包，专题是应用场景。**纲不清，口诀越背越乱；纲一立，口诀自然归位。**
3. **一段时期只跟一个体系**：同时看三种风格的书，等于同时学三种方言。
4. **边读边起卦**：古籍是操作手册，不是文学。读的时候手边必须有卦例，读到一条断语就回去翻自己的卦例验证。

#### 案例小故事：程良玉的"专则纯"

**背景**：清代盲人筮师程良玉，五岁因天花失明，先学医，十岁以"医主望闻问切，既不能望，术能神乎"为由弃医从卜。他跟随星元先师学易，学了整整五年，仍然"犹若茫然"——卦能装出来，断语也背了不少，但一到实占就懵，不知道该用哪一条。他一度分心去学音律、棋艺，想换个东西"开开窍"。

**老师的点醒**：星元先师诫之曰——

> 学易之道，**专则纯，纯则精，精乃入神**；分则杂乱，杂乱则疏，疏乃不入。

**他自己的诊断**：程良玉后来总结，五年茫然不是因为愚钝，而是**把五六家日者的杂学都装进来了**——这一家的口诀、那一家的取用法，彼此打架，输入过载，且没有单一主线。遇到一卦，脑子里同时冒出三种说法，哪一种都不敢确信。

**转机**：十八岁那年，他"始悟用爻"——一旦抓住了"用神"这个总开关，五年里堆在脑子里的零散口诀瞬间各归其位：哪一条是在讲用神旺衰，哪一条是在讲动变，哪一条只是某类场景的特例，一下子分得清清楚楚。此后一通百通，最终写出九十一章、三百七十余问的《易冒》。

**结果**：他四十岁时背发疽，闭门三年，成书而卒。一部书耗尽了一个盲人的后半生——而这本"底层原理 + 边界条件"的著作，今天仍在替读者回答同一个问题：**这句断语，到底在什么条件下才成立？**

**要点提炼（落到今天的读法上）**：

+ 选定《卜筮正宗》做主线，读到某条断语有疑问，再去《易冒》查反例、去《易隐》查深解——**主线只有一条，其他都是支线查询**。
+ 反过来，若主线有三条，就永远在翻译，无法形成条件反射式的判断力。
+ 这个"悟"不是突然变聪明，而是**终于找到了那根能串起所有珠子的线**。对今天的读者，这根线就是"用神 + 病药说"。
+ 他"分心去学音律棋艺"这一段也值得注意：**输入过载时，再加新东西只会更乱**，正确做法是减少输入、回到主线。
