# 板块9 · 飞伏与伏神：隐象层与隐性资源

> 卦中看得见的是飞，看不见的是伏。

飞伏的本质，是判断"**隐性资源能否被激活**"——在管理决策里，就是"备用方案有没有启动条件"。

---

## 9_1 飞伏的本质：显隐、表里、因果、时间

+ **飞神**：显现于外的爻，卦中可见。
+ **伏神**：隐藏在飞神之下的爻，卦中不可见，需要从本宫卦中取出。

**四层结构**（理解了这四层，才真正懂飞伏）：

| 维度 | 飞神（明） | 伏神（隐） |
| --- | --- | --- |
| 表里 | 表象 | 根源 |
| 明暗 | 公开的人事 | 隐藏的因素 |
| 因果 | 果（或互为因果） | 因 |
| **时间** | **已往** | **将来** |

> **"飞为已往，伏为将来"——这是全体系中最被低估的一句。** 它解释了为什么飞伏可以用来断"隐事、暗疾、陈年旧账、暗处的贵人与小人"。

**阴阳互伏的底层原理**：八卦阴阳互伏，故乾伏坤、坤伏乾，震巽互伏，坎离互伏，艮兑互伏。

```plain
  乾 ☰（纯阳）  翻转  →  坤 ☷（纯阴）
  坎 ☵          翻转  →  离 ☲
  艮 ☶          翻转  →  兑 ☱
  震 ☳          翻转  →  巽 ☴

```

纯阳之乾翻转即纯阴之坤——**阴阳互补，相对而存**。这是"爻爻有伏"得以成立的理由。

## 9_2 京氏飞伏的五种取法

**第一类：八纯卦之间，以错卦（对宫）为飞伏**

```plain
乾 ↔ 坤    坎 ↔ 离
艮 ↔ 兑    震 ↔ 巽

```

**第二类：一世、二世、三世卦，与本卦的内卦为飞伏**

以乾宫为例：

+ 一世姤（巽下乾上）→ 与巽为飞伏
+ 二世遁（艮下乾上）→ 与艮为飞伏
+ 三世否（坤下乾上）→ 与坤为飞伏

**第三类：四世、五世卦，与本卦的外卦为飞伏**

以坎宫为例：

+ 四世革（离下兑上）→ 与兑为飞伏
+ 五世丰（离下震上）→ 与震为飞伏

**第四类：游魂卦，与本宫五世卦的外卦为飞伏**

以巽宫游魂颐（震下艮上）为例：巽宫五世卦为噬嗑，噬嗑之外卦为离，故颐与离为飞伏。

**第五类：归魂卦，与本宫五世卦的内卦为飞伏**

以艮宫归魂渐（艮下巽上）为例：艮宫五世卦为履，履之内卦为兑，故渐与兑为飞伏。

**爻之飞伏的对应示例**（以乾宫一世姤为例）：姤之下体为巽（飞），初爻辛丑（飞爻）；而其伏爻仍用乾初爻甲子（伏爻）。

> **实操简化**：现代实占不必死记五类。核心操作只有一句——**用神不上卦时，去本宫八纯卦里找到该用神所在的那一爻，把它伏在本卦对应爻位之下**。

**以乾宫的推演口诀为例**（可用于理解"有变伏本宫、无变伏对宫"）：

| 乾宫卦 | 外卦（有无变动） | 内卦（有无变动） | 伏卦取用 |
| --- | --- | --- | --- |
| 姤、遁、否 | 外无变 → 伏对宫（坤） | 内有变 → 伏本宫（乾） | 上坤下乾 |
| 观、剥、晋 | 外有变 → 伏本宫（乾） | 内无变 → 伏对宫（乾） | 上乾下乾 |
| 大有 | 外有变 → 伏本宫（乾） | 内无变 → 伏对宫（坤） | 上乾下坤 |
| 纯乾 | — | — | 乾伏坤（标准互伏） |

## 9_3 什么时候该查伏神

**核心原则**：

```plain
若卦内飞神不空不破，不必更取伏神。
唯六爻不见用象者，方取伏神推之。

```

**这句话直接解释了后世伏神理论为何"只论用神"**：飞神代表已在运行之事，既然所求之事已在推进，就立足当下；只有当用神不现（所求尚未显象），才需要看伏神——伏代表"将来能否成就"。

**用神不现的三步走**（本板块的完整操作版）：

```plain
第一步：看月建、日辰
   └ 若月建或日辰的地支正是用神所属五行/地支
     → 可直接以日月为用，应期往往就在当月或当日
     → 例：求财而财不上卦，但日辰正好是财爻五行，则"财在日上"，应期极近

第二步：查伏神
   └ 去本宫八纯卦中找对应的用神爻
     → 看它伏在本卦哪一爻之下（飞神是谁）
     → 例：乾宫卦求财，乾属金，"我克者"为木，去乾卦纳支中找木爻（寅木）为伏财

第三步：判断伏神能否"出头"
   └ 伏神再旺，若被飞神压死、无冲无引
     → 等于"抽屉里的钱"，看得见用不上
   └ 按 9_4 的"六能五不能"逐条核对

```

## 9_4 伏神的取舍：六能五不能

**伏神能"出头"（有用）的六种情形**：

1. 月建、日辰生伏神
2. 伏神本身旺相
3. 飞神生扶伏神（如飞为寅木、伏为巳火，木生火 = 吉）
4. 动爻生伏神
5. 日月或动爻**冲克飞神**（去掉压制 = 伏神得伸）
6. 飞神空亡、月破、休囚、入墓、绝

**伏神"虽有如无"的五种情形**：

1. 伏神休囚
2. 伏神受日辰、月建冲克
3. 飞神旺相克害伏神
4. 伏神墓绝于日、月、飞神
5. 伏神值旬空、月破

> **一句话记忆**：伏神要"**旺 + 被生 + 飞神弱/被冲**"才能用；伏神"衰 + 被克 + 飞神强"则等于没有。

**飞伏生克吉凶口诀**：

```plain
伏克飞 = 出暴（伏神有力而出）
飞克伏 = 伤身（伏神受压制）
伏生飞 = 泄气
飞生伏 = 叨生（得暗中扶持）
飞伏比和 = 相助而吉

```

**伏神空破的特殊处理**：

> "**空下伏神，易于引拔。**"

伏神居于旬空之位时，反而容易"引出"——旬空意味着该爻未实、可动，一旦出空值月，伏神便得显现。这给"应期"提供了精准抓手。

> **落地提示**：飞伏不是让你每卦都用。正确顺序是——**先用飞神（明）断现状，只有"用神不现、事涉隐秘、需推将来"时才取伏神**。无差别"爻爻找伏"只会把简单卦搞复杂。

## 9_5 伏神应期

伏藏之用神，其应期有三条主要路径：

```plain
1. 冲飞神之时 → 压制被去掉，伏神得伸
2. 伏爻逢值之时 → 伏神自身临值
3. 伏爻得出（出空、出墓、被生旺）之时

```

对应板块 11 的口诀："**伏藏冲飞值伏宜**"。

### 案例小故事：伏在旬空之下，反而最容易找回来

**背景**：一位女士丢了一条常戴的项链——是她母亲留下的旧物，平日一直戴着，洗澡才摘。那天她整理家务，摘下来随手一放，第二天发现不见了。翻遍梳妆台、床头柜、衣帽间都没找到，家里人也都问过了，都说没看见。她起卦问失物在哪、能不能找回。

**卦象**：问失物，取妻财为用神（板块 15_2）。卦中妻财不现，需查伏神。查下来——**伏神恰在旬空之位**，且伏于内卦近初爻的位置，所在之卦为巽。

**第一反应（错的）**：伏神本来就"看不见"，又落旬空，按"空 = 没有"的直觉，这东西似乎彻底没戏了。家人也劝她"别找了，可能丢在外面了"。

**正确的推演**（四步）：

1. **规则核对**：古诀明确说"**空下伏神，易于引拔**"——伏神居于旬空之爻下，反而容易被引出来。因为旬空意味着该爻未实、可动，一旦出空值月，伏神便得显现。**这一条直接推翻了"空=找不回"的直觉。**
2. **位置定位**：妻财伏于内卦、近初爻的位置。按爻位表，内卦主"家中"，初爻主"近处、低处"——东西在家里，而且是在低处。
3. **卦象类象**：伏神所在卦为巽，巽主"入、藏、通道、缝隙"，配合"低处"，指向柜底、抽屉深处、杂物格一类地方。
4. **应期判断**：出空之日即为引拔之时。

**结论**：物在家中近处低矮之处，出空后可寻；重点找柜子底部、抽屉深处，尤其是平时放杂物的那一格，而不是梳妆台（她一直在找的地方）。

**应验**：后果于出空当日，在自家玄关鞋柜的最底层——她平时放购物袋、雨伞的一格——找到了项链。是前一天打扫时顺手塞进去的，外面还压着一个布袋。

**要点提炼**：

+ 这条反直觉的规则说明——**同一个"空"字，作用在不同对象上含义完全不同**：空伏神是"可引出"，空用神才是"暂时无力"。
+ 空亡不是单一的凶辞，要看它落在**用神、忌神、飞神、伏神**中的哪一个身上。
+ 失物卦的定位，是"**爻位（高低远近）+ 卦象（藏于何处）+ 八卦方位**"三重交叉的结果。这一卦里三重都指向"家中低处的收纳格"，所以断得准。
+ 她此前之所以找不到，是因为一直在"它该在的地方"（梳妆台）找——而卦象指出的是"它实际在的地方"（杂物格）。**断方位的价值在于改变搜索策略，而不只是给一个吉凶。**

## 9_6 飞伏自检清单

| 检查项 | 自问 |
| --- | --- |
| 是否需要查 | 用神在卦里吗？飞神是否不空不破？（不空不破就不必取伏） |
| 日月代用 | 月建或日辰上有没有用神五行？有则可先用日月为用 |
| 伏神是谁 | 去本宫八纯卦找到用神爻了吗？伏在哪一爻之下？ |
| 飞神是谁 | 飞神是生伏、克伏、还是比和？ |
| 能否出头 | 六能五不能逐条核对了吗？空下伏神是否易引拔？ |
| 应期 | 冲飞、值伏、出空，三条路径都算过了吗？ |
