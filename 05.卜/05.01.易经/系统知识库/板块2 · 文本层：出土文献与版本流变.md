## 板块2 · 文本层：出土文献与版本流变

> 20 世纪以来的出土文献，让我们看到了汉初甚至战国《周易》的真实样貌。

**它们的实用价值在于：当你解卦遇到"某字古义不通"时，可能不是你理解错了，而是传本不同。**

---

### 2_1 四批关键出土材料

| 出土文献 | 时间 | 关键价值 |
| --- | --- | --- |
| **上博藏战国楚竹书《周易》** | 战国 | **现存最早的《周易》文本**，涉 34 卦共 1806 字；为易学"九六之争"画上句号——证明先秦已有"九六"之名，不是汉人加的 |
| **马王堆帛书《周易》** | 汉文帝初年 | 卦序与通行本**完全不同**（纵向乾艮坎震坤兑离巽、横向天地山泽水火雷风相叠）；附《二三子问》《系辞》《易之义》《要》《缪和》《昭力》等传世本未见的篇章 |
| **阜阳汉简《周易》** | 汉 | 残片 3119 字，可能是蓍龟家术数之学的代表 |
| **郭店楚简** | 战国 | 无专门易学文献，但《太一生水》等篇可考易学思想源流 |

**其中最重要的一条**：帛书《要》篇记载孔子答子贡质疑时说——

> **"《易》，我后其祝卜矣！我观其德义耳也。"**

又说："予非安其用，而乐其辞。"

这句话是整部《易传》的精神种子，其诠释学意义详见板块10。

---

### 2_2 帛书卦序带来的震撼

马王堆帛书出土后，学者发现汉初《周易》的卦序与通行本完全不同——它按八卦相重的方阵排列，而不是通行本的"二二相耦、非覆即变"。

```latex
   通行本卦序（序卦传解释的对象）        帛书卦序（方阵排列）
 ┌──────────────────────────┐      ┌──────────────────────────┐
 │ 乾 → 坤 → 屯 → 蒙 → 需 …  │      │ 乾 艮 坎 震（纵向）        │
 │ 一条因果链，一卦接一卦     │      │ 坤 兑 离 巽              │
 │ 有天地然后万物生焉        │      │ 八经卦两两相叠成方阵       │
 └──────────────────────────┘      └──────────────────────────┘
   讲"过程"                          讲"结构"

```

这解释了为什么有些卦在《序卦传》里的因果链看起来牵强：**《序卦传》解释的是通行本的卦序，而通行本的卦序只是多种排序中的一种。**

> **读法建议**：把《序卦传》当作"一条理解六十四卦的思路"，而不是"唯一的原始结构"，心态会从容很多。

### 2_3 版本流变：从简帛到通行本

| 时期 | 关键事件 | 文本形态 |
| --- | --- | --- |
| **先秦—汉初** | 出土简帛（上博楚简、马王堆帛书、阜阳汉简） | 经与传完全分离，各自成篇；卦序、卦名、用字与后世差异较大 |
| **汉魏** | 费直开创"以传附经"，郑玄承袭，王弼完成《周易注》 | 经传合编，"王弼本"成型 |
| **唐** | 孔颖达奉诏撰《周易正义》，融合南北经学 | "王弼、韩康伯注 + 孔颖达疏"成为官方标准，即《十三经注疏》所用的本子 |
| **宋** | 朱熹主张恢复"古周易"，撰《周易本义》 | 经传重新分开（吕祖谦《古周易》本），形成另一大版本体系 |
| **清至今** | 阮元校刻《十三经注疏》；现代整理本大量出版 | 现代通行读本以阮刻《十三经注疏》本《周易正义》为底本，校以简帛本 |

**宋代刻本的三大类**（版本学常识）：

1. **经注本**：单刻王弼、韩康伯注文（如抚州公使库本、建阳坊刻本）；
2. **注疏合刻本**：南宋两浙东路茶盐司"八行本"首开先河，元代"十行本"流行，是后世《十三经注疏》的祖本；
3. **纂图互注重言重意本**：建阳书坊为科举士子编印的"备考资料"，附图、附不同注解。

> **给现代读者的实用结论**：入门读白文，先读一遍不带注解的经文，建立自己的第一印象，再看注疏。想看古本面貌，可翻阅帛书《周易》的整理本，了解"汉初《易》长什么样"。

### 2_4 案例小故事：出土文献改写的三处理解

**故事一 · "丧牛于易"的千年误读**

《旅》卦上九有一句怪辞："鸟焚其巢，旅人先笑后号咷，丧牛于易，凶。"

从汉代起，注家大多把"易"解成"容易"，于是整句读成"丢了牛是很容易的事"，上下文完全断裂——前面说鸟巢被烧、旅人先笑后哭，后面突然跳到丢牛，谁也讲不清为什么凶。一位清代学者苦思不得，甚至在注里怀疑这句辞有衍文，主张删掉"丧牛于易"四字。

直到近现代，王国维、顾颉刚从甲骨卜辞里钩出殷人先祖**王亥客居有易氏、被杀而牛羊被夺**的史实，这句辞才豁然贯通：它不是在讲丢牛，而是在讲一个**漂泊者因失去根基而招致灭顶之灾**的古老故事——先笑（受到款待）后号咷（遭遇祸难），正是这个典故的完整情绪曲线。

**启示**：卦爻辞里有相当一部分是"记事之辞"（见板块9）。当你读不通时，先怀疑自己缺背景，而不是怀疑经文写错了。

**故事二 · 帛书《要》篇改写了孔子的形象**

传世文献里，孔子与《易》的关系只有两条记载：一是"韦编三绝"的勤奋，二是《史记》说他"序《彖》《系》《象》《说卦》《文言》"。至于他为什么读《易》、读的时候在想什么，一直语焉不详。后人于是两极化：术数家说孔子在传筮法，理学家说孔子在传义理，各执一词，都没有直接证据。

马王堆帛书《要》篇出土后，一段对话浮出水面：弟子子贡质疑孔子晚年好《易》是否沦于卜筮，孔子回答"**我后其祝卜矣！我观其德义耳也**"，又说"予非安其用，而乐其辞"。

这句话填补了关键一环——**孔子不是在研究占卜技术，他是在读卦爻辞里承载的德义**。整部《易传》的诠释学底线，就建立在这句话上。

**启示**：出土文献的价值不在"证明古人更聪明"，而在**补上传世文本里缺失的那一环推理**。

**故事三 · 上博楚简终结"九六之争"**

易学史上曾有一桩长期公案：爻辞里的"九""六"（如"初九""上六"）到底是先秦就有的名称，还是汉人后来加上去的？争论持续很久，因为传世的所有版本都是汉以后的，谁也拿不出更早的证据。

1994 年入藏的上博藏战国楚竹书《周易》给出了答案：这批抄写于战国的竹简上，已经出现"九六"之名。争论就此终结——**先秦已有九六，不是汉人所加**。

这批竹简也是现存最早的《周易》文本，涉及三十四卦、共一千八百余字，同时让我们看到了战国时代卦名、用字与后世通行本的诸多差异。

**启示**：很多看似无解的义理之争，其实是**材料不足**造成的。遇到僵持不下的解释，先问一句：有没有更早的材料？——这也是为什么读《易》要留一只眼睛看出土文献。

### 2_5 本板块的笔记方法与验收

**笔记方法：异文对照卡（读注本遇到"某字不通"时用）**

```latex
┌────────────────────────────────────────────┐
│  卦名 / 爻位：__________                     │
│  通行本用字：__________                      │
│  传世注释的解释：__________                   │
│  是否怀疑是传本差异？□ 是 □ 否               │
│  （若是）我打算查哪一批出土材料：              │
│  □ 上博楚简 □ 马王堆帛书 □ 阜阳汉简          │
└────────────────────────────────────────────┘

```

**关键动作**：不要一遇到读不通就强行引申义理。**先排除文本问题，再做义理解读**——这是读原典的基本纪律。

**验收（四个可检查的动作）**：

- [ ] 能说出四批出土文献的名称与各自最关键的贡献。
- [ ] 能背出帛书《要》篇那句关键话，并说明它解决了什么问题。
- [ ] 能解释帛书卦序与通行本卦序的差异，以及这对读《序卦传》意味着什么。
- [ ] 能说清从简帛到阮刻《十三经注疏》的版本流变主线，并说出宋代刻本的三大类。
