## README · 易学操作系统：从卦象符号到处境判断

> **一句话定位**

《易经》不是一本"结果查询表"，也不是一本算命手册。它是一套**用符号模拟处境、用爻位校准分寸、用变化倒逼行动、用德义收拢人心**的操作系统。
本知识库按**文本层 → 符号层 → 结构层 → 文辞层 → 判断层 → 应用层**六层重新组织，把《易经》古经、《易传》十翼、《东坡易传》三份文本打通，并补齐象数、版本、出土文献、注本谱系等外围知识，最终全部落回"人在变化中如何自处"。

### 三、四种进入方式

+ **想系统学**：从板块0的路线图开始，一路读到板块33，约十二周。
+ **想查某卦**：上经翻板块15，下经翻板块17；卦与卦的因果看板块16。
+ **想解决当下处境**：翻板块19、20、21，八张情境卡直接对照。
+ **想学解卦**：翻板块24（问题与起卦）与板块25（解卦七步与卦例）。

**一条底线建议**：无论走哪条路，**前三个月只攻义理，不碰术数**。先把"时、位、中、正"四个字练成肌肉记忆，再去学占筮。顺序反了，卦象给你再多信息，你也只会读出自己想听的话。

### 四、三条心法

1. **不追求吉，追求无咎。**
不犯致命错误，就已经赢过大多数人。追求"吉"让人贪婪冒进，追求"无咎"让人冷静克制。
2. **吉凶生于动，成败决于时。**
不动没有吉凶，但不看时机而动，必有悔吝。先定"卦时"，再定"爻位"，最后才谈行动。
3. **易者，变也；不变者，变之道也。**
守住那条不变的"道"（中正之德），然后大胆地在变化中行动。

### 五、三条易被忽略的前提

1. **三份文本是三个时代的产物**，不能混成一锅读（详见板块0）。
2. **十翼不是孔子一人一时之作**，接受"层累形成"，比纠结作者更有价值（详见板块10）。
3. **《易》的价值在人事判断与德性修养**，不在于预测物理世界，也不存在任何"独家秘传"（详见板块32）。
