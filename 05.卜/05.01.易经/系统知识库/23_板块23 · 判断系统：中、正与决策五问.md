## 板块23 · 判断系统：中、正与决策五问

> 本板块是核心算法的下半部分：分寸感、底线，以及把四字压缩成的**决策五问**。

---

### 23_1 中：分寸感是最高能力

二爻与五爻多吉，因为它们居中。**"中"即无过无不及。**

《易》极重"中"——**得中的爻即便不当位，也多有回旋余地**。这是因为"中"代表了调整能力：**不至于极端，所以永远有余地。**

**中的三个实操含义**：

| 含义 | 表现 | 反面 |
| --- | --- | --- |
| **程度上的中** | 不过分、不不及 | 过激 / 不及 |
| **时间上的中** | 不早不晚 | 过早（急躁）/ 过晚（错失） |
| **关系上的中** | 不偏不倚 | 站队 / 骑墙 |

**阴阳利弊清单**（"中"的训练工具，重大决策前强制填写）：

```latex
事项：_____________
阳面（机会／收益／主动力）：
  1. ______  2. ______  3. ______
阴面（风险／成本／阻力）：
  1. ______  2. ______  3. ______
阴阳相推：如果阳面因素 1 增强，会推动阴面因素 __ 往哪走？
我的"中"点在哪（做到什么程度就停）：______

```

> **关键提醒**：清单最后一行最重要。很多人列了利弊却仍然过度，是因为**从未定义"做到什么程度就停"**。

### 23_2 正：底线不参与权衡

"正"兼指当位与守正道。爻辞中的"贞"字，基本义是"正固、坚守"。

**最容易误读的一点**：《易》从不无条件赞美坚持。"贞吉"是守正才吉，"**贞凶**"是**一味固执则凶**。
判断标准：**如果环境已经变了，你的"坚持"就不再叫守正，叫刻舟求剑。**

**"正"的三层清单**（把底线具体化，别只说"我要做个好人"）：

| 层级 | 内容 | 特征 |
| --- | --- | --- |
| **绝对底线** | 违法的事、伤害无辜的人、违背自己核心承诺 | 永不交易 |
| **重要原则** | 不说谎、不背后攻击、不占小便宜 | 尽量不破 |
| **可变策略** | 方法、节奏、合作对象、表达方式 | 随时调整 |

> **关键提醒**：很多人的痛苦来自把"策略"当成了"原则"——明明是方法问题，却用"我做人就是这样"来拒绝调整。**分清楚这三层，是"正"的真功夫。**

```latex
   判断流程：
   这件事触碰绝对底线了吗？ → 是 → 拒绝，不论收益
                            → 否
                            ▼
   这件事破了重要原则吗？   → 是 → 尽量避免，破了要补救
                            → 否
                            ▼
   这只是策略问题           → 随意调整，不必自责

```

### 23_3 四字合用：决策五问

把"时位中正"压缩成每次面临重要选择时过一遍的五个问题：

| # | 问 | 对应 | 不合格时的动作 |
| --- | --- | --- | --- |
| 1 | **时**：现在是"屯"是"泰"是"否"？该止、该行还是该守？ | 时 | 时机不对 → 强制冷却，等待 |
| 2 | **位**：我的位置与我的能力匹配吗？该做的事我做没做？ | 位 | 越位 → 收回；失位 → 补上 |
| 3 | **中**：我是否偏激了？做到什么程度就该停？ | 中 | 过度 → 减损；不及 → 加强 |
| 4 | **正**：这件事触碰我的绝对底线了吗？ | 正 | 触碰 → 拒绝，不论收益 |
| 5 | **损**：如果"损"掉这件事，我会失去真正重要的东西吗？ | 损益 | 不失去 → 果断损掉 |

**使用建议**：写下来，不要只在脑子里过。**书写会强迫你把模糊的判断变成清晰的句子**——而大多数决策错误，都是因为判断太模糊。

```latex
┌──────────────────────────────────────────────┐
│  决策五问 · 速写版（打印贴在桌上）              │
├──────────────────────────────────────────────┤
│  1. 时：该止 / 该行 / 该守？ → ______          │
│  2. 位：越位了还是失位了？   → ______          │
│  3. 中：过了还是不够？       → ______          │
│  4. 正：碰底线了吗？         → ______          │
│  5. 损：损掉会失去什么？     → ______          │
├──────────────────────────────────────────────┤
│  结论：我在 ____ 之前，做 ____，停止 ____       │
└──────────────────────────────────────────────┘

```

### 23_4 五档结果预期管理

| 判词 | 现实中的对应状态 | 正确心态 |
| --- | --- | --- |
| **吉** | 结果向好 | 感恩，同时准备下一步（吉不长久） |
| **无咎** | 没犯错、平稳度过 | **喜悦**：这是《易》最推崇的状态 |
| **悔** | 意识到错了，可以回头 | **庆幸**：能悔说明判断力还在，立刻改 |
| **吝** | 路越走越窄，还没醒悟 | **警惕**：这是最需要外部提醒的状态 |
| **凶** | 明确不利 | **止损**：不要试图"赢回来" |

> **《易》真正推崇的状态，从来不是"大吉大利"，而是"没有过失"。**不犯致命错误，就已经赢过大多数人。追求"吉"让人贪婪冒进，追求"无咎"让人冷静克制。

### 23_5 案例小故事：四字算法的三次现场

**故事一 · 一场谈崩的加薪**

一位在公司做了三年的员工去谈加薪，直接提出涨幅百分之五十，理由是"市场价就是这样"——他确实做过调研，同岗位的市场中位数比他现在的薪资高四成多。

老板认为不合理（内部平衡会被打破），谈判僵住，最后不欢而散。他觉得老板不识货，老板觉得他不体谅，此后两个月两人的关系都很僵。

用"中"来看：他的问题不是诉求不合理，而是**程度上的过**——他把诉求定在了自己能接受的最高点，既没给自己留余地，也没给对方留台阶，更没有定义"中"点在哪里。中的反面不是软弱，是极端。

调整后的做法是：他重新约了一次，提出百分之三十的明确数字，并加了一个绩效对赌条款——**如果下一季度完成某两个明确指标，再补到百分之四十五**。

这就是"中"：**有明确主张，但留了可调整的空间**；有坚定，但不僵硬。

结果当场谈成。老板后来私下说，他其实本来准备给到百分之二十五，但"百分之三十加对赌"这个结构让他觉得"这个人知道自己在做什么"。

**启示**：中不是和稀泥，是有分寸的坚定。判断"中"的具体方法是问一句：**做到什么程度就该停？**——这个问题答不出来，就说明你还没找到中点。

**故事二 · 把策略当原则的人**

一位有十年经验的资深设计师坚持"绝不改稿"，说这是他的原则。客户提出修改意见时，他的标准回复是"这是我专业判断的结果，改了就不好了"。

两年内他失去了三个长期客户，其中一个合作了六年。客户流失后他仍然认为"是客户不懂"，甚至在一次行业分享里说"设计师的尊严就是不妥协"。

用"正"的三层清单看：**"不改稿"是策略，不是原则。**

他的绝对底线应该是"**不做违背专业判断的劣质设计**"——这一条永不交易；而"改不改稿"是达成这个目标的**方法**，方法是完全可以调整的，甚至可以成为服务的一部分。

分清楚之后，他改成了"**前两稿免费改，之后按次收费，每次附一页专业说明**"：说明为什么原方案更好，但尊重客户的最终选择。

结果出乎他的意料：客户开始认真读他的说明，改稿次数反而从平均五次降到两次——因为那页说明让客户理解了方案的逻辑，很多"修改意见"其实是误解。一年后他的客户数不但回升，还超过了之前的水平，而且他一次也没有违背过自己的专业判断。

**启示**：很多人的痛苦来自把策略当原则，然后用"我做人就是这样"来拒绝调整。分清楚"绝对底线 / 重要原则 / 可变策略"三层，是"正"的真功夫——**你守住的是底线，不是姿势。**

**故事三 · 决策五问的一次完整使用**

一位女士同时收到两个 offer，犹豫了一周，越想越乱，甚至开始失眠：

+ **A 公司**：薪资高百分之四十，行业风口，但加班严重（前员工说平均每天十一点下班），团队成立不到一年；
+ **B 公司**：薪资与现在持平，业务成熟，团队稳定，但成长空间看起来有限。

她坐下把决策五问写了一遍（重点：写下来，不是在脑子里过）：

1. **时**：我刚经历一次 burnout，休养了三个月才恢复。现在处于"**冬藏**"季节 → 该守不该冲。
2. **位**：两个职位都是执行岗，我的能力都够 → 都不越位，这一问无差别。
3. **中**：A 的加班强度已经超过我能持续的程度——我试过一次，代价是三个月 → **过**。
4. **正**：两个 offer 都不碰底线（没有违法、没有欺骗） → 无差别。
5. **损**：如果放弃 A 的高薪，我会失去什么？答案是"**存款增长速度**"，而不是"真正重要的东西"（健康与恢复）。

五问写完，答案已经很清楚。她选了 B。一年后身体完全恢复，第二年在 B 公司内部转到了一个更有挑战的岗位，还拿到了一个外部机会——薪资比 A 当初给的更高。

她后来说：**五问的价值不在于给我答案，而在于让我发现——我其实早就知道答案，只是不敢承认。**而"写下来"这个动作，让那个被藏起来的答案无处躲藏。

**启示**：写下来，不要只在脑子里过。书写会强迫你把模糊的判断变成清晰的句子——**大多数决策错误，都是因为判断太模糊。**

### 23_6 本板块的笔记方法与验收

**笔记方法：决策五问日志（每次重要决策必写，三个月后回填）**

```latex
┌──────────────────────────────────────────────┐
│  决策事项：____________________  日期：____    │
├──────────────────────────────────────────────┤
│  1. 时：现在是 □屯 □泰 □否 □其他 → ____        │
│     该 □止 □行 □守？                          │
│  2. 位：我在第几爻？□越位 □失位 □当位           │
│  3. 中：□过激 □不够 □恰当（做到什么程度停）      │
│  4. 正：□碰绝对底线 □破重要原则 □只是策略问题    │
│  5. 损：损掉它会失去什么？____________          │
├──────────────────────────────────────────────┤
│  结论：__________________________________      │
│  我在 ____ 之前，做 ____，停止 ____            │
├──────────────────────────────────────────────┤
│  【三个月后回填】                               │
│  实际结果：______________________________      │
│  当时的判断哪一条错了：__________________      │
└──────────────────────────────────────────────┘

```

**关键动作**：最后一栏"三个月后回填"必须真的回填。**没有回填的决策日志，只是自我安慰的文字。**

**验收（五个可检查的动作）**：

- [ ] 能说出"中"的三个含义（程度、时间、关系），并各举一反例。
- [ ] 能填写阴阳利弊清单，并写出"做到什么程度就停"。
- [ ] 能把自己的底线写成三层清单（绝对底线 / 重要原则 / 可变策略）。
- [ ] 能用决策五问处理一次真实决策，并写出"我在某时之前，做某事，停止某事"。
- [ ] 能说出五档预期管理各自对应的正确心态，并说出《易》的终极目标。
