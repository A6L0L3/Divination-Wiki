## 板块1 · 文本层：三易、书名与经传结构

> 学《易》的第一道门槛，不是卦象难懂，而是你手上的"《易经》"到底指哪一样。

先把文本层理清楚，后面所有解读才不会张冠李戴。

---

### 1_1 书名辨析：三种"易"不是一回事

日常说的"《易经》"，其实混指了三样东西，先分清楚：

| 名称 | 所指 | 说明 |
| --- | --- | --- |
| **《连山》《归藏》《周易》** | 传说中的"三易" | 《连山》以艮为首、《归藏》以坤为首，均已亡佚（或有辑佚）；《周易》以乾为首，是唯一完整流传的 |
| **《易经》（狭义）** | 卦象 + 卦辞 + 爻辞 | 西周早期成型的占筮底本，是"经" |
| **《周易》（广义）** | 经 + 传（十翼） | 今天通行本的完整形态 |

**"周易"二字的两种解释**：一说是"周代之易"（朝代），一说是"周普、周遍、周而复始之易"（义理）。两说并行不悖，不必强择其一——**一个指向它的出处，一个指向它的性格。**

```latex
   《连山》─ 以艮为首（山）  ─ 已亡佚
   《归藏》─ 以坤为首（地）  ─ 已亡佚
   《周易》─ 以乾为首（天）  ─ 唯一完整流传

   今日通行本《周易》 = 经（卦爻辞）+ 传（十翼）

```

---

### 1_2 作者：一个"层累形成"的答案

传统说法（"人更三圣，事历三古"）与现代研究差异很大，正确态度是**接受层累，放弃单线**：

| 环节 | 传统说法 | 现代共识 |
| --- | --- | --- |
| **八卦** | 伏羲画卦 | 符号系统经历长期演化，托名伏羲 |
| **六十四卦** | 或说伏羲重卦、或说文王重卦 | 重卦早于文王，非一人一时 |
| **卦辞** | 老阳周文王作 | 西周卜史之官集体编纂，文王是代表符号 |
| **爻辞** | 或说周公作 | 西周早期筮辞汇编，成于众手 |
| **十翼** | 孔子作 | 均非孔子手笔（详见板块10） |

**关键认知**：把《周易》理解为**西周卜史集团编纂、经孔子后学哲学化、再经汉魏注家定型**的层累文本，比纠结"到底谁写的"更有价值——因为每一层都在往里加东西，而你要学的是全部三层。

```latex
  第一层（西周）        第二层（战国—秦汉）      第三层（汉魏以降）
 ┌──────────────┐     ┌────────────────┐     ┌────────────────┐
 │ 卜史集团编纂  │ ──▶ │  孔门后学哲学化 │ ──▶ │  注家定型       │
 │ 卦象·卦辞·爻辞│     │  十翼（传）      │     │ 王弼·朱熹·程颐  │
 │  → 处境样本   │     │  → 解释框架      │     │  → 版本与读法   │
 └──────────────┘     └────────────────┘     └────────────────┘

```

### 1_3 经与传：骨与肉的两层结构

**《经》的部分**（每一卦由四个元件构成）：

| 元件 | 说明 | 例（乾卦） |
| --- | --- | --- |
| **卦画** | 六爻组成的符号 | ䷀ |
| **卦名** | 卦的题目 | 乾 |
| **卦辞** | 断一卦整体的文辞 | 元，亨，利，贞 |
| **爻辞** | 断每一爻的文辞 | 初九，潜龙勿用 |
| **用九 / 用六** | 乾、坤两卦独有的第七条辞 | 乾"用九：见群龙无首，吉"；坤"用六：利永贞" |

**"用九""用六"为什么只有乾坤有**：乾卦六爻皆阳、坤卦六爻皆阴，两卦存在"全变"的可能——乾全变则成坤，坤全变则成乾。这两条辞就是为"全体皆变"这种极端情况准备的补充说明，其余六十二卦阴阳夹杂，不存在全体皆变，故无此辞。

**《传》的部分（十翼）**：七种十篇——彖上下、象上下、文言、系辞上下、说卦、序卦、杂卦。各篇的详细功能与读法见板块10，此处只列名称，避免重复。

### 1_4 "以传附经"的演变

这段历史决定了你今天买的书长什么样：

| 时期 | 关键事件 | 文本形态 |
| --- | --- | --- |
| 西汉 | 费直开创"以传附经" | 经传开始合编 |
| 东汉 | 郑玄承袭费氏 | 合编传统延续 |
| 曹魏 | 王弼完成《周易注》，晋韩康伯补注 | 经传合编正式成型，"王弼本"确立 |
| 宋代 | 朱熹不满合编，撰《周易本义》，用吕祖谦《古周易》定本 | 经传重新分开，形成另一大系统 |

> **所以你今天买到的注本，有的经传合排（王弼系统），有的经传分排（朱熹系统），不是印错了，是传统不同。**

### 1_5 群经之首：地位是怎么来的

《周易》从唐代开始稳居"六经之首"的地位，从未受到挑战。随着儒家经典体系从"五经""七经""九经""十二经"扩展到"十三经"，《周易》自然从六经之首升擢为**群经之首**。

**原因不难理解**：

1. **它最古老**——源头可上溯至西周甚至更早的卜筮传统；
2. **它最抽象**——符号系统可以容纳任何时代的解释，具有无限的再阐释空间；
3. **它最跨界**——儒家看到仁义、道家看到自然、术数家看到推演、科学家看到二进制结构。

**但也正因为"什么都能装"，它最容易被人往里乱装东西。**这是读《易》要特别警惕的一点，也是板块32要专门讲避坑的原因。

### 1_6 案例小故事：文本层的三次误会

**故事一 · 你买的书为什么和别人的不一样**

赵启明是一位中学历史老师，想认真读一遍《周易》。他先在网上按销量买了一本，翻开发现"彖曰""象曰"夹在卦辞和爻辞中间，一段经文后面跟着好几段传文，读起来被反复打断。他以为买到了劣质排印本，退货。

他又买了一本，这一本把《彖》《象》全部另起一编，经文干干净净，可他读到"初九，潜龙勿用"想知道为什么，就得翻到书后半部分去找解释，来回翻更费劲。连退两次之后，他差点放弃。

后来一位学古典文献的朋友告诉他：这两本都没印错。前者是**王弼—孔颖达系统（以传附经、经传合排）**，从西汉费直开创、东汉郑玄承袭、曹魏王弼完成，便于对照卦辞看解释；后者是**朱熹—吕祖谦系统（古周易、经传分排）**，朱熹不满合编，主张恢复经传分离的原貌，便于体会"经是经、传是传"。

赵启明最后的选择是：用合排本精读（方便对照），用分排本通读（建立原典感）。半年后他说：**搞清楚两个系统的差别，比多读两本注本有用**——因为你会知道自己在读哪一层。

**启示**：遇到"读不通"，先怀疑是不是版本传统不同，而不是怀疑自己或怀疑书。

**故事二 · "文王作卦辞"的执念**

一位自学者坚信"卦辞是周文王一个人写的"。他读到《明夷》卦"明夷于飞，垂其翼。君子于行，三日不食"，又读到《睽》卦"见豕负涂，载鬼一车"，百思不得其解：同一个人的文风怎么会从庄重的格言跳到荒诞的画面，跨度这么大？

他试着用"文王被囚羑里而演易"的故事去解释每一句，越解释越牵强，最后不得不承认自己读不懂。

后来他接受"西周卜史集团集体编纂、成于众手"的现代共识，问题迎刃而解——**这些辞句本就不是一人一时之作**，它们来自不同时期、不同卜官的筮辞汇编，风格本就不可能统一。

他由此改了一句读书原则：**遇到文本不一致，先怀疑"层累"，再怀疑"自己没读懂"。**

**启示**：《周易》是西周卜史集团编纂、经孔子后学哲学化、再经汉魏注家定型的层累文本。接受层累，不是放弃作者，而是让自己能同时读全三层。

**故事三 · 用九、用六的一次误读**

有人读乾卦，数来数去只有六条爻辞，却在书里看到第七条"用九：见群龙无首，吉"，以为是后人妄加的衍文，直接跳过不读。

他错过的恰恰是乾卦最锋利的一句。乾卦六爻全阳，六爻全变则成坤——用九讲的正是**刚而能柔**：群龙各司其职、谁也不争首领的位置，反而大吉。

这不是文字游戏，而是乾卦的收官之笔。乾卦前六爻讲的是一个人（或一件事）从潜藏到鼎盛再到过盛的完整周期，到了上九"亢龙有悔"已经是警告；用九给出的是**超越这个周期的出路**——不是不飞，而是飞起来之后还能不争。

后来他读到苏轼解乾，又读到"群龙无首"在后世被误用为贬义（本义其实是褒义，详见板块30），才明白自己跳过的不是衍文，而是整卦的结论。

**启示**：乾、坤两卦的第七条辞不是附录，是**全卦的超越性总结**，不可跳过。同理，坤卦"用六：利永贞"讲的是柔而能长久守正——柔不是权宜之计，是长期战略。

### 1_7 本板块的笔记方法与验收

**笔记方法：文本层三栏卡（每读一卦先开三栏）**

```latex
┌──────────────┬──────────────┬──────────────┐
│  经文（骨）    │  传文（肉）    │  我的处境（血） │
├──────────────┼──────────────┼──────────────┤
│ 卦画 / 卦名    │ 《彖》的主旨   │ 现在的我在哪   │
│ 卦辞 / 爻辞    │ 《象》的准则   │ 这一卦提醒什么 │
│ 用九 / 用六    │ 《系辞》的总纲 │ 我要做什么     │
└──────────────┴──────────────┴──────────────┘

```

**关键动作**：第三栏必须写满。只抄经文和传文，那是誊书，不是读书。

**验收（四个可检查的动作）**：

- [ ] 能说清"《易经》狭义"与"《周易》广义"的区别，并各举一个使用场合。
- [ ] 能说出《经》的四个元件，并解释为什么乾、坤两卦会有"用九""用六"。
- [ ] 能解释为什么你手上的注本经传合排（或分排），并说出这是哪一家的传统。
- [ ] 能说出"层累形成"的三层结构，并解释为什么接受层累比纠结作者更有价值。
