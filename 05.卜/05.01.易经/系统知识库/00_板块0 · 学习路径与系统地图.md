## 板块0 · 学习路径与系统地图

> 本板块解决一个前置问题：**你到底要用《易》做什么，以及按什么顺序走下去。**

学《易》半途而废的人，九成不是因为难，而是因为目标错位——想求答案的人翻开了哲学书，想学哲学的人掉进了术数坑。

---

### 0_1 先决定你要用《易》做什么

对号入座，再选路径。四条路径的周投入与三个月后的可验证产出如下：

| 你的真实诉求 | 主修板块 | 周投入 | 三个月后你能做到（可验证） |
| --- | --- | --- | --- |
| **决策与自省**（遇事不慌、看清局势） | 板块6、7、8、22、23、24、25 | 3 小时 | 面对选择能自己判断"该进该退、该显该藏"，并能写下理由 |
| **读懂原典与文化**（打通儒道、读懂成语典故） | 板块1、2、10、11、15、17、30 | 4 小时 | 能读白文卦爻辞，能说清"亢龙有悔""否极泰来"的来处与本义 |
| **义理与修身**（把易理落到为人处世） | 板块9、11、12、13、14、26、27、31 | 3 小时 | 建立一套稳定的"时—位—中—正"自省框架并持续运行三个月 |
| **象数与占筮**（研究筮法体系） | 板块4、8、24、25、28、29 | 5 小时 | 掌握大衍、金钱卦、梅花易数三种起卦法与基本断法 |

> **底线建议**：无论走哪条路，前三个月只攻义理，不碰术数。顺序若颠倒，卦象给出的信息越多，你越容易从中挑出符合自己心意的那一条。

### 0_2 三份文本的分工：别把《经》《传》《东坡易传》混成一锅

这是最容易搞混、也最影响学习效率的一点。三份文本是三个不同时代的产物，功能完全不同：

| 文本 | 年代 | 性质 | 一句话功能 | 正确读法 |
| --- | --- | --- | --- | --- |
| **《易经》（古经）** | 西周早期成型 | 筮辞汇编 | 六十四组**处境样本**与判词 | 当"情境卡片"读，别当预言读 |
| **《易传》（十翼）** | 战国至秦汉，孔门后学层累 | 哲学阐释 | 给处境样本装上的**解释框架** | 当"使用说明书"读，先读《系辞》《说卦》 |
| **《东坡易传》** | 北宋，苏洵起意、苏轼主笔、苏辙补注 | 义理派实战解经 | 把易理**压回人事**的宋代代表作 | 当"案例研讨"读，读一卦对照自己的处境 |

```latex
          ┌───────────────────────────────────────┐
          │  一卦的完整读法（三段式，不可跳段）      │
          └───────────────────────────────────────┘
   骨 · 经            肉 · 传               血 · 义理发挥
 卦画 / 卦名       《彖》定卦旨           《东坡易传》/程颐
 卦辞 / 爻辞       《象》立人道准则        压回人事、落到行动
 用九 / 用六       《系辞》给总纲

```

### 0_3 三阶段学习路径

#### 第一阶段 · 装系统（第 1—4 周）

1. 背熟八卦取象歌：**乾三连，坤六断；震仰盂，艮覆碗；离中虚，坎中满；兑上缺，巽下断**
2. 背熟《六十四卦卦序歌》，能顺背上下经
3. 精读《系辞传》上下，把"一阴一阳之谓道""生生之谓易""穷则变，变则通，通则久""时止则止，时行则行"四句抄下来贴墙
4. 精读乾、坤两卦的经文与《文言传》

#### 第二阶段 · 建模型（第 5—12 周）

1. 掌握爻位六层含义、当位 / 得中 / 中正 / 应 / 比（板块6、7）
2. 掌握卦主、卦时与本卦—之卦—互卦—错卦—综卦六镜（板块8）
3. 顺着《序卦传》顺序，每周精读 4—6 卦，用板块31的模板输出笔记
4. 开始用"决策五问"（板块23）处理真实决策

#### 第三阶段 · 内化（第 13 周起，长期）

1. 每月做一次"乾卦六爻定位"自评
2. 建个人卦例库，每遇重大决策记录"问题—卦象—解读—行动—实际结果—复盘"
3. 精读一部注本（王弼或程颐），再回头重读《系辞》
4. 每年重读一遍《系辞》，常读常新

```latex
  第1-4周           第5-12周             第13周起
 ┌────────┐       ┌──────────┐        ┌──────────────┐
 │ 装系统  │  ──▶  │  建模型   │  ──▶  │    内化       │
 │八卦·系辞│       │爻位·六镜  │        │卦例库·年复盘  │
 │乾坤文言 │       │卦序精读   │        │注本精读       │
 └────────┘       └──────────┘        └──────────────┘
   认得符号         解得出结构           遇事自动调用

```

### 0_5 新手入门顺序与七条戒律

**正确顺序**（前人踩坑总结）：

```latex
白文卦爻辞 → 《系辞》《说卦》打底 → 乾坤二卦《文言》 → 顺《序卦传》逐卦读
→ 回头重读《系辞》 → 参看注本（王弼 / 程颐） → 最后接触占筮，且只当局势参考

```

**七条戒律**（违反任何一条，学习效率减半）：

1. **不查字典式读书**：遇到一个卦就去翻"这一卦是什么意思"，那是查答案，不是学思维。
2. **不跳着读**：六十四卦有因果链，跳读等于看连续剧只看第 3 集和第 58 集。
3. **不背六十四卦**：你只需要看懂三样——现在在哪（本卦）、什么在变（动爻）、要去哪（之卦）。
4. **不反复占同一件事**：占到"顺耳"为止，那是自欺，不是占筮。
5. **不问"会不会成功"**：要问"以我现在的状态，该怎么调整才能增加可能性"。问题越具体，卦象越有落点。
6. **不把卦象当命令**：卦是象征性启示，决策责任永远在你自己。
7. **不混入玄学自媒体话术**：遇到"秘传""泄露天机""必看"类内容直接关掉，回到原典与正经注本。

**三级自检**（判断自己到哪一档）：

+ **入门档**：能默出八卦象意，能说出乾卦六爻的爻辞，能解释"潜龙勿用"的字面意思。
+ **会解档**：拿到任意一卦，能指出动爻、判断当位与否、说出二五爻的意义、写出一句贴合自身处境的解读。
+ **能用档**：面对真实抉择，能不起卦就启动"时位中正"四问，说出该止、该行还是该守，且能给出理由。

### 0_7 案例小故事：三个人的三条路

**故事一 · 想求答案的人，翻开了哲学书**

陈默在杭州经营一家做家居用品的电商公司，做了六年，从年销三千万做到天花板：流量成本翻了三倍，复购率连续四个季度下滑。他在一个失眠的夜里翻开《易经》，想找一个"该不该转行做跨境"的答案。

他翻到"潜龙勿用"，觉得丧气——是不是说自己不行；翻到"飞龙在天"，又觉得安慰——是不是说熬一熬就起来了。一夜下来，他什么也没决定，只记住了两句情绪化的口号，第二天照旧焦虑。

他的困境不在不够虔诚，而在**把处境样本当成了结果查询表**。六十四卦是六十四种处境的素描，不是六十四个答案。

后来他换了路径：先花两周学"时位中正"四问，再回头读卦。同样是屯卦，他读出的不再是"别动"，而是三条具体动作——**止**：用三周时间回答"我到底要解决谁的什么问题"；**建**：搭出最小可行架构，把选品、投放、客服三块的职责边界写清楚；**托**：把最弱的客服模块整体外包。

三个月后他没有转行，而是关掉了两个亏损的品类、把客服外包、把资源集中到复购最高的那条产品线。当年利润反而回升了。他后来说：**屯卦没有告诉我"该不该转行"，它告诉我"现在还不到谈方向的时候，先把结构搭起来"。**

**故事二 · 想学哲学的人，掉进了术数坑**

林一是中文系在读研究生，论文题目涉及宋代思想，本想读懂"一阴一阳之谓道"到底在说什么。她上网找资料，一脚踏进纳甲、世应、六神、旬空、月破、暗动这一整套术语。

她的笔记写了整整三十页，全是术语表和口诀，没有一句落到自己身上。三个月后她彻底放弃，跟导师说"《易经》太玄了，没法做研究"。

她的误区是**顺序反了**：术数是一套精密工具，但没有义理打底，工具只会告诉你一堆你无法解释、也无法行动的信息。就像一个人还没学会看地图，就先背下了经纬度的换算公式。

后来她按本知识库的路径重排——先花六周把乾卦六爻变成个人成长的六面镜子，写成六张自检卡，再读《系辞》。三个月后才回过头看象数，理解速度快了一倍，而且她能说清每个术语解决的是什么问题。

她自己的总结很精辟：**先有判断框架，术语才有地方挂。**

**故事三 · 走对路的人**

周颖是一家医疗器械公司的市场部主管，手下九个人，跨部门协作极多。她给自己定的规矩极低：每周只读一卦，但必须用"一卦一悟"模板写满六栏，尤其写最后那句"我在某时之前，会做某事，并停止某事"。

半年下来，她没有占过一卦，却建起了二十四则卦例笔记，每则都有一句行动承诺。她说最有用的是第五栏"避坑预警"——逼着自己先想"这个卦象里藏着什么陷阱"。

年中一次跨部门冲突：研发部未经沟通就砍掉了她团队提的一个功能，她在群里差点和对方吵起来。她没有立刻争辩，而是翻出自己写的讼卦卡片，按"止讼三问"先问事实（到底改了什么、什么时候改的）、再问自己的真实诉求（其实是要"后续有知情权"）、最后问对方的真实诉求（研发排期压力大，怕被反复打断）。

她带着这个判断去找对方，开口第一句是"我理解你们排期紧，我只想要一件事：以后动我们提的需求，提前两天告诉我"。一场可能升级的冲突，二十分钟就化解了。

她说最大的收获是：**现在遇到事，脑子里会自动跳出"这件事在第几爻"这个问题。**——这正是本知识库所说的"能用档"。

> 三个人的差别，不在智商，也不在投入时间，而在两件事：有没有先选定路径，以及有没有把笔记写成行动承诺。

### 0_8 本板块的笔记方法与验收

**笔记方法：把路线图变成一张贴墙的进度表**

1. 把 0_4 的十二周周表抄在一张 A4 纸上，每完成一周就打勾，并写下"本周唯一记住的一句话"。
2. 每完成一个阶段，在纸的背面写三行：**我原本以为 / 现在发现 / 下一步要改**。
3. 七条戒律抄在便签上贴在电脑边，每月对照一次，看自己最近犯了哪一条。
4. 三级自检每季度做一次，只记分不记感受。

**验收（三个可检查的动作）**：

- [ ] 能在 3 分钟内默写出八卦取象歌，并说出任意一卦的上下卦结构。
- [ ] 能说清《经》《传》《东坡易传》三份文本的分工，且能举例说明"为什么不能只读其中一份"。
- [ ] 能不看书写出"时、位、中、正"四个字，并各举一个自己生活中的例子。
- [ ] 能说出七条戒律中的任意五条，并指出自己最近违反了哪一条。
