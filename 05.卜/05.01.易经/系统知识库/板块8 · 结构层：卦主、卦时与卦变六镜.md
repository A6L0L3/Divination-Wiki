## 板块8 · 结构层：卦主、卦时与卦变六镜

> 一卦不止一个面相。

本板块讲两件事：如何抓住一卦的纲（卦主与卦时），以及如何用六个角度照开一件卡住的事。

---

### 8_1 卦主：一卦之纲

王弼《周易略例·明彖》提出：

> "**一卦之体，必由一爻为主，则指明一爻之美，以统一卦之义。**"

意思是：一卦六爻，往往有一爻是"主爻"（卦主），整卦的意义集中体现在它身上。**找到卦主，就抓住了这一卦的纲。**

**确定卦主的三条规则**（按优先级）：

| 规则 | 说明 | 例 |
| --- | --- | --- |
| **1. 以寡统众** | 五阳一阴则**阴为主**；五阴一阳则**阳为主**。物以稀为贵 | 师卦九二（五阴一阳）、夬卦上六（五阳一阴）、小畜六四、大有六五 |
| **2. 以静制动**（取中爻） | 阴阳呈 3-3 或 2-4 分配时，取二爻或五爻 | 乾卦九五、坤卦六二、讼卦九二或九五 |
| **3. 就卦义定** | 以上两法不适用时，按卦的整体意义定 | 明夷卦上六（最黑暗的一爻） |

王弼还补充："**卦体不由乎一爻，则全以二体之义明之**"——有些卦的意义不在某一爻，而在上下两体的关系（如归妹卦：震上兑下，"少女承长阳，说以动，嫁妹之象"）。

```latex
   找卦主的决策顺序：
   先看阴阳比例（以寡统众）
        │ 不适用
        ▼
   取中爻（二或五，以静制动）
        │ 不适用
        ▼
   按卦义定（如明夷上六）
        │ 仍不适用
        ▼
   看上下两体的关系（如归妹卦）

```

### 8_2 卦时：先认大势，再看位置

王弼说"**夫卦者，时也；爻者，适时之变者也。**"

+ **卦 = 时**：每一卦代表一种大的**时势**（如屯是"初创艰难之时"，泰是"通达之时"，否是"闭塞之时"）；
+ **爻 = 适时之变**：每一爻代表**处在这个时势中的不同应对方式**。

> **所以读卦的正确顺序是：先认"时"（这一卦讲什么大势），再看"爻"（我在这个时势里的哪一步、该怎么应对）。**

**常见卦的"时"速记**：

| 卦 | 卦时（大势） |
| --- | --- |
| 屯 | 初创艰难之时 |
| 需 | 等待时机之时 |
| 泰 | 通达交融之时 |
| 否 | 闭塞不通之时 |
| 剥 | 层层剥落之时 |
| 复 | 一阳来复之时 |
| 蹇 | 险阻难行之时 |
| 革 | 势在必变之时 |
| 既济 | 事已完成之时 |
| 未济 | 事未完成之时 |

### 8_3 卦变六镜

**第1步 本卦（正卦）**：起卦得到的原始卦，代表**当前处境与问题的本质**。

**第2步 之卦（变卦）**：把动爻翻转后得到的新卦，代表**当前变动若持续发展，局面所趋向的方向**。

> 关键认知：**之卦不是"预言的结果"，而是"趋势的地图"。**它告诉你"如果什么都不改，会走向哪里"——所以它可以被你的行动改变。

**第3步 互卦**：由本卦的二、三、四爻组成下卦，三、四、五爻组成上卦，形成的新卦，代表**事情内部的隐情与发展过程**。

比如问"合作能不能成"：本卦看双方现状，之卦看结局，互卦看**中间会发生什么、对方心里真正在想什么**。

**第4步 错卦（旁通）**：把本卦每一爻阴阳全反过来。代表**站在对立面看同一件事**，是"换位思考"的卦象版。

**第5步 综卦（覆卦、反卦）**：把本卦整个倒过来看（旋转 180 度）。代表**换一个立场、换一个层级看同一件事**。

**第6步 爻变之卦（"之某卦"）**：只看某一个爻的变化所指向的卦，用于细化分析（如"乾之姤"表示乾卦初爻动）。

```latex
    本卦              之卦              互卦
  ┌────────┐       ┌────────┐       ┌────────┐
  │ 上爻    │       │ 翻转后  │       │ 三四五爻│
  │ 五爻    │  ──▶  │ 的新卦  │       │ 组成上卦│
  │ 四爻 ○动│       │        │       ├────────┤
  │ 三爻    │       │        │       │ 二三四爻│
  │ 二爻    │       │        │       │ 组成下卦│
  │ 初爻    │       │        │       └────────┘
  └────────┘       └────────┘
   现在在哪          要去哪里          内部隐情

    错卦              综卦
  ┌────────┐       ┌────────┐
  │ 阴阳全反│       │ 倒转180 │
  │ 对立面看│       │ 换立场看│
  └────────┘       └────────┘

```

### 8_4 实操：六镜提问法（一件事卡住时用）

| 镜 | 提问 | 回答示例（以"要不要跳槽"为例） |
| --- | --- | --- |
| **本卦** | 我现在真实的状态是什么？ | 看似有机会，实则信息不足 |
| **之卦** | 照这样下去会走到哪里？ | 若不补齐信息就决定，会陷入反复 |
| **互卦** | 事情内部有什么是我没看见的？ | 对方团队的真实流动率 |
| **错卦** | 如果站在完全对立面，会怎么看？ | 现公司会怎么挽留我 |
| **综卦** | 站到更高一层 / 对方立场，会怎么看？ | 新老板看中的是我的哪一点 |
| **卦主** | 这一卦最关键的那个点在哪？ | 关键不在变动处，在我已有的核心能力 |

**使用纪律**：

1. **六镜必须全部走完**，不能只挑顺眼的一两镜看；
2. **本卦永远优先**，跳过本卦直接看之卦，等于只看了结论没看理由；
3. 六镜照完，把答案压缩成一句行动指令，格式：**我在某时之前，做某事，停止某事。**

### 8_5 完整读卦流程图

```latex
  第1步 看卦名卦象    →  整体定性（这一卦是什么处境）
            │
            ▼
  第2步 看上下卦关系  →  内 vs 外（内部状态 vs 外部环境是否交通）
            │
            ▼
  第3步 定卦时        →  大势判断（这一卦代表什么样的时代/环境）
            │
            ▼
  第4步 找卦主        →  抓纲（全卦意义集中在哪一爻）
            │
            ▼
  第5步 找动爻        →  定位（哪个阶段正在变化）
            │
            ▼
  第6步 查当位·得中·有应·亲比  →  评分（结构是否支撑你）
            │
            ▼
  第7步 看之卦·互卦   →  延展（趋势与隐情）
            │
            ▼
  第8步 落回三才      →  归因（是底层条件问题、努力问题，还是大势问题）

```

> 第8.步最容易被跳过，也最有价值：**很多"努力没用"的痛苦，本质是你在用人道的方式解决天道的问题。**

### 8_6 案例小故事：抓纲与六镜的实战

**故事一 · 师卦的卦主**

一位 CEO 问"该不该重用一个业绩明星"，占到师卦。他没有急着看爻辞，而是先按三条规则找卦主：师卦五阴一阳，按**"以寡统众"**，唯一的阳爻九二就是卦主。

九二的爻辞是"在师中，吉，无咎，王三锡命"——关键在"**中**"字：刚健而居中，不偏不倚，能节制也能服众。卦辞讲**"以律为本**"，《彖》说"**刚中而应**"。整卦的纲就落在这一爻上。

对照现实：那位业绩明星个人能力极强（刚），但独断、不愿与人协作、带过的三人陆续离职（不中）。

结论很清楚：问的是"该不该重用"，而师卦给出的用人标准恰恰是"刚中而应"——问题不在业绩，在"不中"。

后来这个人被安排到一个独立攻坚的岗位：单人负责、目标清晰、不需要协作（用其刚，避其不中）。他在这个位置上做出了公司当年最好的一个产品模块，团队也稳定了。

**启示**：卦主是全卦意义的集中点。找错卦主，整卦的解读都会跑偏；找对卦主，六爻会自己归位。

**故事二 · 六镜照开一场谈了三次没谈成的合作**

一位做 SaaS 的创业者与一位潜在合伙人谈了三次。对方每次都说"很有兴趣"，但一到条款就含糊其辞。他觉得"对方态度暧昧"，却说不清问题在哪。

用六镜一照：

+ **本卦**（现状）：我有技术与产品，他有渠道与客户，看似完美互补；
+ **互卦**（内部隐情）：从过程看，对方每次见面都在问"如果我们做不起来，我的客户怎么办"——他在同时接触另外两家，我的优先级并不高；
+ **错卦**（完全对立面）：站在他那边看，我给的条件里缺少"退出的清晰规则"，他担心一旦绑死，抽身成本极高；
+ **综卦**（更高一层）：站到行业层面看，这类技术与渠道的合作，失败的常见原因不是利益分不均，而是"没写清楚怎么分手"；
+ **之卦**（趋势）：若继续这样含糊地谈下去，会走向消耗战，双方都投入沉没成本后不欢而散。

他据此做了一件事：**主动把退出机制写进条款**——包括什么情况下可以退出、客户资源怎么交接、知识产权归谁（这正是讼卦"谋始"的智慧）。一周后签约。

**启示**：卡住的事，往往不是缺诚意，而是**缺一个对方没说出口但很在意的条款**。互卦与错卦就是用来找这个东西的。

**故事三 · 综卦的一次顿悟**

一位运营主管抱怨新来的下属"执行力差"：交代的事总要反复确认、做出来的东西偏离预期。他试过批评、换人、改流程、加考核，一直没有解法。

后来有人让他用综卦的方法：把整个卦倒过来看——**站在下属的立场，把这件事重述一遍**。他硬着头皮写了一页："如果我是他，我每天面对的是什么？我收到的指令是什么？"

写完后他发现：自己给的目标每周都在变——周一说做拉新，周三改成做留存，周五又说要做转化。下属不是执行差，是**无法执行**。

他做的调整极其简单：**目标锁定两周不变，任何变更需走书面流程并注明原因。**一个月后，同一个下属的交付质量进入了团队前列。

**启示**：综卦不是玄学，是**强制换位**。很多"对方有问题"的判断，翻转视角后就变成了"我的输入不稳定"。

**故事四 · 卦时的误判**

有人占到"否"卦，第一反应是"完了，要倒霉"，于是消极等待，既不争取也不准备，连手上的项目都停了。三个月后，一个本可以抓住的机会真的错过了。

问题在于他把"否"理解成了**结果**，而"否"描述的是**时势**：环境闭塞、上下不交、君子道消。卦时给出的从来不是判决，而是**处境说明 + 应对提示**。否卦的正确动作是"识时—守德—待变"（见板块20）：看清环境、不与乱象缠斗、收紧开支沉淀能力、养精蓄锐等气机流通。

**启示**：先认"时"，再定"位"，最后才谈行动。把卦时当判决，是把处境说明误读成了命运宣判——这是解卦最常见的一种自伤。

### 8_7 本板块的笔记方法与验收

**笔记方法：六镜一页纸（每月做一次，选一件最卡的事）**

```latex
┌──────────────────────────────────────────────────┐
│  卡住的事：__________________________________      │
├──────────────────────────────────────────────────┤
│  本卦（现在）：______________________________      │
│  之卦（趋势）：______________________________      │
│  互卦（隐情）：______________________________      │
│  错卦（对立面怎么看）：______________________      │
│  综卦（更高层/对方立场）：___________________      │
│  卦主（关键点）：第 ___ 爻，依据规则 ________      │
├──────────────────────────────────────────────────┤
│  行动指令：我在 ____ 之前，做 ____，停止 ____       │
└──────────────────────────────────────────────────┘

```

**验收（五个可检查的动作）**：

- [ ] 能说出确定卦主的三条规则，并说出师卦、夬卦、小畜卦的卦主。
- [ ] 能解释"卦者，时也；爻者，适时之变者也"，并说出五个常见卦的卦时。
- [ ] 能说清本卦、之卦、互卦、错卦、综卦各自回答什么问题。
- [ ] 能按八步流程图完整读一卦，并写出第8.步（三才归因）。
- [ ] 能用六镜提问法把一件卡住的事照完六面，并写出一条行动指令。
