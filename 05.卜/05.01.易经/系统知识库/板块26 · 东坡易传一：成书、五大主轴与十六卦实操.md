## 板块26 · 东坡易传一：成书、五大主轴与十六卦实操

> 一部在贬谪路上磨出来的书。它不教你如何成功，而教你**如何在失意中仍然把"人"站稳**。

---

### 26_1 一部在贬谪路上磨出来的书

北宋元丰三年（1080），苏轼因"乌台诗案"被贬黄州，任八品团练副使，俸禄取消、行动受限，实质上是个被监管的政治犯。他在此期间开始撰写《易传》；绍圣四年（1097）再贬儋州（今海南），于桄榔庵中反复修订，直至元符三年北归。**前后历时近二十年。**

**成书过程**：苏洵晚年着手撰述未竟而卒，临终嘱苏轼、苏辙"述吾志"；苏轼在黄州写主体，吸收苏辙对《蒙卦》的注解，在儋州统稿成书九卷。这是一部**父子三人接力的著作**。

**这意味着什么**：《东坡易传》不是书斋里的解经，而是**一个被时代碾过一遍的人，在绝境中借《周易》重新确认"人该如何立身"的答案**。

**历代评价的两极**：

+ 南宋朱熹批评它"杂以佛老""杳冥恍惚"，但也承认其对物理人事"常有独见"；
+ 《四库全书总目》的评价更公允：**"弼之说惟畅玄风，轼之说多切人事。其文辞博辨，足资启发。"**

> **正确的读法**：把它当作一位饱经沧桑的长者，在告诉你"**变化时怎样不慌、低位时怎样不失、高位时怎样不昏**"。它的干货不在占卜，而在人事。

```latex
   元丰三年（黄州）── 开始撰写 ──┐
   绍圣四年（儋州）── 反复修订 ──┼── 前后近二十年
   元符三年（北归）── 统稿成书 ──┘

   苏洵起意 → 苏轼主笔 → 苏辙补注（蒙卦）

```

### 26_2 五大思想主轴

**第1步 性情一体：性出于天，情出于人**

> "刚柔者，性之所有；而吉凶者，情之所生也。性出于天，情出于人。"

天性本于天道，无私无善恶；人情出于人心，有私故有善恶取舍。
**实操**：遇到情绪起伏、吉凶得失时，先分清这是"性"（本然）还是"情"（私欲）。**凡事先问：这是天道本然，还是我的私欲在判断？**能分清这一层，大半的内耗就消失了。

**第2步 变化唯时：唯变所适，反对偏执**

> "夫道何常之有？唯变所适。同者未必是，异者未必非。"

这是全书最具现代性的洞见——**包容差异，因异以通天下之志**。

**第3步 刚柔相济：不偏刚、不偏柔**
解乾："圣人之刚，非务刚也，务以刚为德"；解坤："顺非阿谀苟合之谓，循理而应物"。
**刚与柔都不是目的，合乎"理"才是目的。**

**第4步 易简无心：乾坤惟无心，故一**

> "乾坤惟无心，故一，一故有信。"

圣人之所以为圣人，不是因为他有更多道德，而是因为他"**无心**"——**不把自己的私意强加于物，让事物各得其天理**。

**第5步 以史证人：借三代至汉唐典故论卦爻**
解《乾》爻辞引周公摄政为例，解其它卦亦多引史事。这使得《东坡易传》不是抽象义理，而是**有血有肉的人事哲学**。

```latex
   第1步 性情一体 ─ 分清楚"性"与"情"
   第2步 变化唯时 ─ 唯变所适，不偏执
   第3步 刚柔相济 ─ 合乎"理"才是目的
   第4步 易简无心 ─ 不把私意强加于物
   第5步 以史证人 ─ 用史事把义理落到实处

```

### 26_3 东坡特色卦解十六卦实操表

| 卦 | 东坡的独特解读 | 当代落地实操 |
| --- | --- | --- |
| **乾** | "亢龙有悔，夫处此者，岂能无悔哉？"不局限于君臣之说，结合自身贬谪经历，指出君子处逆境当隐忍守志 | 处于业绩巅峰时，主动做一件"向下"的事：复盘风险、感谢基层、储备接班人 |
| **坤** | "坤之为道，以不为而自成者也"；"顺非阿谀苟合之谓，循理而应物" | 面对强势方，找到"理"所在的位置站稳，以柔道化之 |
| **屯** | "屯难之世，盘桓不进"；"勿用有攸往，利建侯" | 止—建—托三段式（详见板块19） |
| **蒙** | 吸收苏辙注解，强调启蒙不是灌输而是**养正** | 带新人或孩子：少给结论，多设问 |
| **需** | 待时不是消极，是审时度势的蛰伏 | 重大决策 48 小时冷却期 + 时机评估表 |
| **讼** | "上刚下险，险而健"揭示争端之源，强调谋始与中正止讼 | 合作前写清退出机制；争执时过"止讼三问" |
| **师** | 以律为本，反对侥幸奇胜；德位相配；小人纵有寸功亦不可用 | 纪律先于能力；提拔先看德位是否相配 |
| **比** | 诚信为本、择人而比、适时而比 | 每季度审视核心圈子；再筮慎从 |
| **否** | "否，君子退而穷处，乃所以致泰也"——否境不是淘汰君子，是筛选君子 | 识时—守德—待变（详见板块20） |
| **谦** | 谦不是自我贬低，是对"盈必溢"的客观认知 | 成功后主动损盈：散财、让功、让位 |
| **睽** | "同者未必是，异者未必非。天下之理，未尝不通于异"——全书最核心名句 | 团队刻意引入异见者；每年接触一个你本能排斥的领域；决策设"魔鬼代言人" |
| **损/益** | "损人以利己，小人之事；损己以利人，君子之事。损之在我，则益在天下" | 信息减损、物质减损、欲望减损 |
| **蹇/解** | 蹇时需止、解时需断 | 卡点时先"止"回基本面；转机出现时果断切割沉没成本 |
| **鼎** | "择之太详，求之太备，则天下无完人" | 招聘、择偶、交友：只严卡"必须有"3 项和"不能有"3 项 |
| **革/鼎** | 变革须顺天应人；守成须稳健 | 变革问"天"与"人"；变革中"豹变"；变革后入鼎稳守 |
| **未济** | 事未济——万事没有真正完成之时 | 给每件事留"未济接口"（详见板块18） |

### 26_4 五大主轴的现代翻译

| 主轴 | 一句话 | 现代问句 |
| --- | --- | --- |
| 性情一体 | 分清本然与私欲 | 这是天道本然，还是我的私欲在判断？ |
| 变化唯时 | 不偏执于某一道理 | 我是否在用三年前的标准要求今天的事？ |
| 刚柔相济 | 合乎"理"才是目的 | 我这次是顺着"理"，还是顺着"人"？ |
| 易简无心 | 不把私意强加于物 | 我的方案是让事物各得其理，还是让它符合我的想法？ |
| 以史证人 | 用史实检验义理 | 这个道理在真实的历史或案例里成立吗？ |

> **"无心"的现代解释最容易被误读**：它不是"没有想法"，而是**不把自己的私意强加于物，让事物各得其天理**。对应到管理，就是"让专业的人按专业的方式做事"，而不是"让所有人按我的方式做事"。

### 26_5 案例小故事：东坡的三个人生卦

**故事一 · 黄州的"潜龙"**

元丰三年（1080），苏轼因"乌台诗案"被贬黄州，任八品团练副使——一个没有实权的虚职，俸禄取消、行动受限，实质上是个被监管的政治犯。一家二十余口人挤在临皋亭，朋友不敢通信，他连喝酒都要限量（"每日饮酒不过五合"）。

他没有日日上书自辩，也没有沉沦。他做的是初九"潜龙勿用"该做的事：**积累与观察**。

具体做了什么？他在东坡开荒种地（"东坡"之号由此而来），跟农夫学种稻；他写《易传》，开始于这一时期；他练书法，日课不辍；他研究烹饪，留下了后来被称作"东坡肉"的做法；他在雪堂里接待愿意来的客人——无论对方是道士、农夫还是贬官。

四年后，中国文学史上最好的一批作品诞生在他最低的爻位上：《赤壁赋》《后赤壁赋》《念奴娇·赤壁怀古》《寒食帖》，以及《东坡易传》的主体。

他自己在给朋友的信里写："某现在东坡种稻，劳苦之中亦自有乐。"——这句话里没有一个字是抱怨。

后来他在《易传》里解"潜龙勿用"，不局限于传统的君臣之说，而是结合自己的处境指出：**君子处逆境，当隐忍守志、蓄势待发。**这不是注释，这是自述。

**启示**：潜龙勿用不是躺平，是审时度势的蛰伏。在错误的时机用正确的力气，是最常见的浪费——而判断"用"与"勿用"的标准，不在你的能力，在你的位置。

**故事二 · 儋州的"损益"**

绍圣四年（1097），六十二岁的苏轼再贬儋州——当时的海南是"非人所居"的蛮荒之地。他在给朋友的信里列了六个"无"：**食无肉、病无药、居无室、出无友、冬无炭、夏无寒泉**。

他带的书很少，却在桄榔庵（用桄榔叶搭的茅屋）里反复修订《易传》。写完那一串"无"之后，他紧接着写的是："然亦未易悉数，大率皆无尔。**尚有此身，付与造物者，听其运转。**"

这句话是理解东坡的关键。他不是乐观，是**完成了损益的计算**：外在的一切（物质、地位、社交、舒适）都已被损掉，无法再损；而"尚有此身"——还剩这一件可以做的事，那就把《易传》写完。

这就是损益之道：**损掉的是外在的一切，益的是那一件长期的事。**从黄州起意到儋州统稿，前后近二十年，父子三人接力——苏洵晚年着手撰述未竟而卒，临终嘱苏轼、苏辙"述吾志"；苏轼在黄州写主体，吸收苏辙对《蒙卦》的注解，在儋州统稿成书九卷。

**启示**：当你无法增加什么时，减损本身就是一种增益。损之在我，则益在天下——先减损，才有空间增益。

**故事三 · 睽卦的"异中求通"**

苏轼一生与王安石政见相左。他反对新法，因此屡遭贬谪，其中一次直接导致他被外放出京。

但王安石退隐金陵后，苏轼专程去看他。两人同游钟山，谈诗论佛，**不谈政争**。苏轼后来写道："**从公已觉十年迟**"——跟您交往，我才觉得晚了十年。

他解睽卦说"**同者未必是，异者未必非。天下之理，未尝不通于异**"——他不是说说而已，他真的在政敌身上实践了这句话。

这件事的分量在于：他们不是没有分歧（政见分歧依然存在，两人都没有妥协），而是**在分歧之外找到了可相通之处**。这正是睽卦"以同而异"的要义：不是消灭差异，是在差异中求同、因异以通。

**启示**：异不是威胁，是通道。一个只能容纳同类的系统，是不会生长的——团队如此，个人认知也如此。

**故事四 · 现代的"性情二分"**

一位管理者因为下属开会迟到十分钟大发雷霆，事后自己也很困惑："我平时不是这么小气的人，十分钟的迟到我从来不介意。"

用东坡的"性情二分"一问：这是"性"（本然）还是"情"（私欲在判断）？

他诚实地回答了：是"情"。他真正在意的是"**权威被挑战**"——那天会议室里坐着其他部门的几个人，他觉得当众被轻视了。而那十分钟的迟到本身，其实有合理原因。

分清这一层之后，他的处理方式完全变了：从发火变成沟通。他单独找那位下属了解了迟到的原因（家里老人生病，早上要送医），并一起调整了考勤安排——把必须到场的会议排在下午，上午允许弹性。

后来那位下属成了团队里最稳定的一个人。而他说：**如果当时我只是发了火然后过去，这件事会变成一个持续的芥蒂——我会一直觉得他"不守时"，他会一直觉得我"不讲理"。**

**启示**：大半的内耗，来自分不清"这件事本身"和"我的私欲"。凡事先问一句"这是天道本然，还是我的私欲在判断"，能分清这一层，大半的内耗就消失了。

### 26_6 本板块的笔记方法与验收

**笔记方法：东坡式对照笔记（读一卦，对照自己的处境）**

```latex
┌──────────────────────────────────────────────┐
│  卦名：____                                    │
├──────────────────────────────────────────────┤
│  东坡的解读（一句话）：__________________      │
│  他的人生经历与此卦的关联：______________      │
├──────────────────────────────────────────────┤
│  我的处境对照：                                 │
│  - 我现在的处境与这一卦的哪一点吻合？____      │
│  - 这是"性"（本然）还是"情"（私欲）？____      │
├──────────────────────────────────────────────┤
│  落地：我在 ____ 之前，做 ____，停止 ____       │
└──────────────────────────────────────────────┘

```
