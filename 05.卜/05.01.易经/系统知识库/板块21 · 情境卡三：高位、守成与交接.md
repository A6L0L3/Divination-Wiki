## 板块21 · 情境卡三：高位、守成与交接

> 成功之后的处境，往往比低谷更危险。

本板块覆盖三张卡：身居高位、守成有待、功成交接。

---

### 21_1 情境七：高位与成功（升职、爆红、财富增长、影响力扩大）

**对应卦组**：乾·九五（飞龙在天）、大有（丰盛）、丰（极盛）、谦（损盈）、既济（成功后的隐患）

| 卦 | 处境 | 关键动作 |
| --- | --- | --- |
| **乾·九五** | 处于鼎盛 | 以德配位，广纳贤才，培养接班人 |
| **大有** | 丰盛富有 | 遏恶扬善——富有之后第一件事是划清善恶边界 |
| **丰** | 极盛之时 | 日中则昃：在正午就开始准备日落 |
| **谦** | 成功的自我保护 | 主动损盈：让功、让利、让位 |
| **既济** | 事已成功 | 思患而豫防之：成功后立刻想下一个隐患 |

**成功期的"损盈"清单**（不是道德表演，是物理规律）：

+ **散财**：捐出一定比例（哪怕 1%），打破"这些都是我应得的"幻觉；
+ **让功**：公开场合把功劳分给具体的人，越具体越有效；
+ **让位**：培养一个能替代你的人——**让自己变得"不被需要"才是真安全**；
+ **听异**：刻意引入一个会反对你的人。

**亢龙预警（三选一即自警）**：

- [ ] 最近是否听不进反对意见？
- [ ] 是否把功劳全归自己？
- [ ] 是否开始享受别人没有的待遇？

```latex
   盈 ──（不损）──▶ 溢 ──▶ 悔
   盈 ──（主动损）──▶ 平 ──▶ 可持续

   "盈必溢"是物理规律，不是道德说教

```

### 21_2 情境八：守成与交接（功成之后、交棒、长期维持）

**对应卦组**：既济（成功后防患）、未济（留接口）、恒（持久之道）、节（节制有度）、艮（止于当止）

| 卦 | 处境 | 关键动作 | 陷阱 |
| --- | --- | --- | --- |
| **既济** | 事已成，结构完美 | 思患而豫防之：立刻想下一个隐患 | 功成而骄，终止则乱 |
| **未济** | 需要继续生长 | 留下"未济接口"：下一个目标、待验证假设 | 以为已经结束 |
| **恒** | 需要长期维持 | 立不易方：不变的是方向，可变的是方法 | 把固执当恒心 |
| **节** | 需要制度化 | 制数度，议德行：把规则量化 | 苦节不可贞——节制过度反成伤害 |
| **艮** | 需要边界 | 思不出其位：不做不该做的 | 该止不止；把停滞当静止 |

**交接三件事清单**（功成身退前必须完成）：

- [ ] **文档化**：把只在自己脑子里的东西写下来，包括判断逻辑，不只是流程；
- [ ] **带一个接班人**：不是"找人接"，是"带出来"——至少共同决策三个月；
- [ ] **主动让出决策权**：交接后前三个月不干涉，这是最难也最关键的一步。

> **恒卦的关键提醒**：**立不易方**——确定不变的是"方向"，可以变的是"方法"。

很多人把两者搞反：方向年年改，方法十年不变。

### 21_4 案例小故事：成功期的四次考验

**故事一 · 大有卦的"遏恶扬善"**

一位创业者的公司估值做到十亿后，第一件事不是换办公室、不是买车，而是做了一次内部审计：把过去三年里所有"打擦边球"的业务全部列出来——灰色渠道推广、投放数据的口径美化、给渠道的隐性回扣。

这些业务加起来贡献了三成营收。团队不理解："现在正在冲规模，为什么要停？"

他的依据是**大有卦的"遏恶扬善"——富有之后第一件事是划清善恶边界**。他的判断很冷静：**规模越大，"擦边"的代价越高。**一年营收五千万时，一次数据造假的代价是罚款；营收十个亿时，同样的动作可能导致上市失败、客户集体解约、创始人对赌赔偿。

早一年划清边界，代价小十倍——因为那时候你损失的只是三成营收，而不是整个公司。

停掉这些业务的那一年，营收增速从百分之一百二十降到百分之四十，投资人很不满意。一年后同行因数据造假被重罚、几家头部公司被迫退市，他们安然无恙，还因为合规记录良好拿到了两家大客户的加分。

**启示**：富有之后的第一个动作不是扩张，是**划边界**。遏恶扬善不是道德洁癖，是风险管理。

**故事二 · 丰卦的日中则昃**

一家连锁烘焙店在第三年达到巅峰：十四家店，家家排队，周末上午十点前就卖完。创始人准备再开十家，连商场的位置都谈好了。

一位老友提醒他看丰卦："**日中则昃，月盈则食**——在正午就开始准备日落。"丰卦的陷阱是"在极盛时看不见阴影"。

他做了个反直觉的决定：**暂停扩张一年，把利润全部投入供应链和人才培养。**

这一年他做了两件在爆红期看起来毫无必要的事：一是自建中央厨房与冷链（当时每家店都是前店后厂，产能已经吃緊，但还能撑）；二是把每个店的副店长送到总部轮训三个月，储备了二十个能独立开店的人（当时根本不需要那么多店长）。

同行在同期快速扩张，一年开了三十家店。

一年后行业遇冷：原材料涨价、消费降级、商场客流下滑。一批快速扩张的品牌集中关店，而他因为供应链成本低两成、店长储备充足，反而在下行期并购了三家位置很好的店铺——价格是巅峰期的三分之一。

**启示**：极盛时最该做的不是扩张，是准备。而且准备必须做在还有钱、还有余裕的时候——下行期你既没有钱，也没有时间。

**故事三 · 一次失败的交接**

一位创始人决定退休，把公司交给了自己带了八年的副总。交接只用了一周：开了一次全员会、发了一封邮件、把公章和几个重要账号的密码移交。

三个月后，创始人开始担心——新 CEO 的第一个大决策（砍掉一条产品线）他不同意。于是他开始每天给副总打电话"指导"，后来干脆每周回公司开一次会。

半年后副总辞职，理由是"我没有一天真正做过决策"。公司陷入混乱，两位核心高管先后离职，创始人不得不回来重新掌舵，但此时市场已经变了。

用交接三件事对照：

+ **文档化**没做——所有判断逻辑都在创始人脑子里，包括"为什么我们不做低端市场""哪些客户必须亲自维护"这些关键决策的依据；
+ **接班人没"带出来"**——副总八年里只做过执行，从未独立做过一次重大决策，也从未为自己拍板的结果负过责；
+ **决策权没让出**——创始人天天干预，等于把"交"和"不交"混在一起，这比不交更糟。

另一位创始人做得不同：他花了半年写"决策手册"（不只写结论，主要写判断逻辑与历史上踩过的坑），然后与接班人**共同决策三个月**（他只听、只问，不拍板），最后**出国三个月，完全不联系**。回来时公司运转良好，而且接班人做出了两个他原本不会做的、事后证明正确的决定。

**启示**：交接的难点不在"交"，在"接不住还想抓"。让出决策权的唯一可信证明，是你真的消失了三个月。

**故事四 · 恒卦的方向与方法**

一位自媒体人做了六年内容，数据逐年下滑。他的应对是更努力地写：从每周两篇增加到每天一篇，选题会开得更长，标题改得更多遍。但方向始终不变——泛资讯，什么热写什么。

恒卦说"**立不易方**"——不变的是**方向**，可变的是**方法**。他把两者搞反了：方向（泛资讯）早就不适应了却死守（该变的不变），方法（更新频率）却拼命加码（该优化的没优化，只在量上加码）。

泛资讯这个方向为什么会失效？因为平台的推荐机制变了、用户的关注点细化了，"什么热写什么"带来的读者没有黏性，也不产生信任。他越努力，只是在一条失效的路上跑得更快。

后来他调整：**方向改为垂直领域的深度内容**（变方向），**方法改为每周一篇但做深**（变方法：一篇稿子从两天改成两周，加入一手采访与数据），**保持不变的是"为读者提供真信息"这个初心**（立不易方）。

第一年数据继续下滑（深度内容的初始传播量远小于泛资讯），他差点放弃；第二年数据回升，单篇的商业价值翻了几倍，而且开始有机构客户主动找上门。

**启示**：分清"方向"与"方法"，才知道什么该恒、什么该变。恒于错误的事，比不恒更危险——因为你把坚持用错了地方。

**故事五 · 既济之后的"思患"**

一位销售总监带着团队连续四个季度超额完成任务，第五个季度他做了一件同事看来很扫兴的事：在庆功会上，他要求每个人写下"下一个季度最可能出问题的一个客户、一个环节、一个人"，只写一条，当场收上来。

团队写得很敷衍，但他从十二张纸里看出了三条真问题：最大的一个客户已经连续两个季度压价（利润在悄悄变薄）、两位主力销售的提成结构在超额后已经失去激励作用、团队里所有人都把精力放在老客户维护上，新客户开发已经空了三个月。

第六个季度，最大的那个客户转投竞品（果然），但因为提前三个月就在做准备，团队用两个新客户补上了七成的缺口。而提成结构的问题，他在超额时就申请了调整，避免了两位主力在拿到高额提成后的惯性离职。

**启示**：既济卦的卦辞是"**初吉终乱**"，它的"该做"是"**思患而豫防之**"——成功后立刻想下一步的隐患。成功的最大风险，是它会自动隐藏问题：超额的时候，没有人会去问"哪里在变坏"。

### 21_5 本板块的笔记方法与验收

**笔记方法：亢龙预警自查 + 交接准备清单**

```latex
┌──────────────────────────────────────────────┐
│  季度亢龙自查（三选一即自警）                  │
│  □ 听不进反对意见                              │
│  □ 功劳全归自己                                │
│  □ 开始享受别人没有的待遇                      │
├──────────────────────────────────────────────┤
│  本季损盈动作：                                │
│  □ 散财 ___  □ 让功（点名：____）              │
│  □ 让位（培养：____）  □ 听异（引入：____）    │
└──────────────────────────────────────────────┘

```

1. 每季度做一次亢龙自查，命中任一条就写下一个"损盈动作"。
2. 若准备交接，提前半年开始三件事清单，并给自己定"交接后不干涉三个月"的硬约束。
3. 用恒卦的"方向/方法"二分，检查自己是否在用"更努力"掩盖"方向错了"。

**验收（五个可检查的动作）**：

- [ ] 能说出高位情境的五个卦及其关键动作。
- [ ] 能完成亢龙预警三问，并写出一个具体的"损盈动作"。
- [ ] 能说出交接三件事，并解释为什么"交接后三个月不干涉"最关键。
- [ ] 能区分"立不易方"里的"方向"与"方法"，并用它检查一件正在做的事。
- [ ] 能为一次成功写下"既济之后的隐患"（思患而豫防之）。
