## 板块31 · 个人操作系统：模板与周期复盘

> 光读懂不够，关键是内化。本板块提供一套**可直接复制的模板与周期习惯**，把《易》从"读过的书"变成"运行的系统"。

---

### 31_1 日常决策五问（打印贴在桌上）

每次面临重要选择，过一遍这五问：

1. **时**：现在是"屯"是"泰"是"否"？该止、该行还是该守？
2. **位**：我的位置与能力匹配吗？该我做的事我做没做？
3. **中**：我是不是偏激了？做到什么程度就该停？
4. **正**：这件事触碰我的绝对底线了吗？
5. **损**：如果损掉这件事，我会失去真正重要的东西吗？

> **使用建议**：写下来，不要只在脑子里过。书写会强迫你把模糊的判断变成清晰的句子。

### 31_2 四种周期性复盘

**每日（5 分钟）：一卦一思**
每天随机或按序取一卦，问自己："今天我遇到了这一卦的哪种处境？"

**每周（30 分钟）：常德行，习教事**
出自《象传下·坎》："君子以常德行，习教事。"

+ **常德行**：本周在品德修养上，哪一件事做到了"恒久"？哪一件事偏离了？
+ **习教事**：本周学到了什么？教给了别人什么？（教与学一体两面）
+ **加一问**：本周我处于乾卦哪一爻？下一步该进还是该退？

**每月（1 小时）：乾卦六爻定位 + 人际盘点**

1. 用乾卦六爻坐标，给工作、健康、关系、财务四个维度分别定位爻位；
2. **人际盘点**（比卦实操）：谁在让你变得更好？谁在消耗你？本月的"比"对了吗？
3. **损益清单**：本月要损掉什么（信息／物质／欲望）？要增益什么？

**每年（半天）：年度卦 + 未济接口**

1. 年初起一卦作为"年度卦"（或用《易》的方式设定年度主题）；
2. 年末复盘：把这一年的经历与卦象对照；
3. **留未济接口**：写下"还有什么没完成，并且我打算继续"（详见板块18）。

```latex
  每日 5 分钟 ──▶ 一卦一思（今天遇到这一卦的哪种处境？）
  每周 30 分钟 ─▶ 常德行 · 习教事 · 我在哪一爻
  每月 1 小时 ──▶ 六爻定位 · 人际盘点 · 损益清单
  每年 半天 ────▶ 年度卦 · 对照复盘 · 未济接口

```

### 31_3 一卦一悟笔记模板（可直接复制）

```markdown

## 第 X 卦【卦名】  日期：____

### 一、卦象速写

- 卦名与编号：
- 结构（上/下卦）：
- 卦时（这一卦代表什么大势）：
- 卦主（第几爻，依据哪条规则）：
- 核心意象（一句话画面）：
- 卦辞原句：
- 我关注的爻（及爻辞）：

### 二、结构分析

- 动爻在第几爻？处于什么阶段？
- 当位？得中？有应？亲比还是敌比？
- 之卦是什么？互卦是什么？错卦／综卦给我什么新视角？

### 三、断辞拆解

- 断辞等级（元吉/吉/无咎/悔/吝/厉/咎/凶）：
- 条件是什么（要做到什么）：
- 结论是什么：

### 四、核心启示（一卦一悟）

- 当前处境：这个卦在暗示我正处于什么状态？
- 行动指南：最该做的一件事 / 最不该做的一件事
- 避坑预警：这个卦里藏着什么陷阱？

### 五、生活联想

- 对应现实场景（职场晋升期／感情磨合期／项目停滞期）：
- 与《东坡易传》的解读对照：
- 相关成语与它的本义：

### 六、行动承诺

- 我在 ____ 之前，会做 ____，并停止 ____

```

> **模板使用要点**：第六栏必须写满。**只写前五栏的笔记，是读书笔记；写满第六栏的，才是操作系统。**

### 31_5 三种思维升级的验收标准

读完整个知识库、走完十二周计划，真正内化的应是这三种思维方式：

**第1步 变易思维**

+ 未达标：遇到变化感到恐惧，试图让一切回到从前
+ 达标：**顺境时守收敛之心，逆境时存进取之志**；能主动识别"穷"（极限）并提前求变

**第2步 整体关联思维**

+ 未达标：孤立看问题，只看眼前这一件事
+ 达标：解决问题时能放进**时、位、人、势的整体坐标系**；能看到卦与卦之间的因果链

**第3步 辩证中庸思维**

+ 未达标：非黑即白，要么内卷要么躺平
+ 达标：理解"中"即中正和平、无过无不及；**能在两个极端之间找到当下最合适的那个点**

```latex
  变易思维：认得"穷"，敢提前变
  整体关联：放进时·位·人·势的坐标系
  辩证中庸：在两个极端之间找到当下的点

```

### 31_6 案例小故事：系统是长出来的，不是买来的

**故事一 · 半年三十六则笔记**

一位做了五年财务的姑娘，从零开始学《易》。她给自己定的规矩很轻：每周一卦，用"一卦一悟"模板写满六栏，写完不超过二十分钟。

半年下来她写了三十六则笔记（中间有两周漏了，她没有补，也没有自责）。她没有占过一卦。

变化发生在第四个月。当时公司要决定是否外包一条业务线，会上争论很久，她忽然问了一句：**"我们现在是在'屯'还是在'革'？"**——如果是在屯（初创艰难），那就不该急着定方案，该先厘清方向；如果是在革（势在必变），那就要先确认天与人是否都到了。

这一句话把会议从"要不要外包"拉回到"我们现在处在什么阶段"，后面二十分钟就有了结论。

她说：**我脑子里不是记住了屯卦的卦辞，而是多了一个问题——"这件事在第几爻"。**这正是"内化"的标志：不是记住了知识，而是获得了**提问的能力**。

**故事二 · 只写前五栏的人**

另一位读者也用同一个模板，写了三十多则笔记。每则都很工整：卦象速写、结构分析、断辞拆解、核心启示、生活联想——五栏俱全，而且文笔很好，有几则被他发在社交平台上，收获不少点赞。

唯独第六栏"行动承诺"（"我在某时之前，会做某事，并停止某事"）常年空白。他后来承认：**"那栏我不知道写什么，写出来感觉很幼稚。"**

半年后他复盘，发现自己能讲出很多道理——讲屯卦的三段式、讲睽卦的异中求通、讲损益之道——但行为模式一点没变：仍然在该止的时候冲（接了一个明知做不了的项目），在该说的时候沉默（一次本该争取的晋升没开口）。

**启示**：前五栏是"理解"，第六栏是"改变"。没有第六栏的笔记，只是把《易》当成了一门知识，而不是一套操作系统——而且前五栏写得越漂亮，这种自欺越隐蔽。

**故事三 · 人际盘点的一次发现**

一位管理者按月度复盘做"比卦人际盘点"：谁在让你变得更好？谁在消耗你？她要求自己写出具体名字，不写"某类人"。

名单列完，她自己很意外——**最消耗她的不是那个难缠的大客户（那位客户虽然麻烦，但每次沟通都有明确产出），而是一个每周都要通话三小时的旧友。**每次通话的内容高度重复：抱怨婆媳关系、抱怨工作、抱怨身体；而她每次都要花同样的力气去安慰、分析、给建议，对方从不采纳，下周照旧。

她做的不是断交（那太粗暴，也不必要），而是**调整结构**：把通话频率从每周改为每月，每次明确一小时；同时主动增加两个"让她变好"的连接——一位同行的每月交流、一位健身搭子。

三个月后她发现自己精力明显回升，而且那位旧友并没有因此疏远——关系的质量反而因为频率降低而改善了。

**启示**：比卦讲"择人而比，诚信为本"——不是谁来亲近都接受，也不是什么时候都亲近。人脉不在于广，在于"比"得对。而且调整"比"的方式，往往不是断交，而是**改频率与改结构**。

**故事四 · 年度卦的一次对照**

一位工程师在年初起了一卦作为年度卦，卦象指向"有变动但不至于伤筋动骨"。年末对照时发现：那一年他经历的最大变动是一次被动的岗位调整（部门合并，他被划到一个新团队），与卦象所指的方向吻合——而他在当时完全没有意识到这是一次"变动"，只当是行政流程。

他说这次对照给他最大的改变不是"信卦"，而是养成了一个习惯：**每年末写一页"今年真正发生的事"，与年初的预期对照。**

三年后他总结了一句很妙的话：**对照的价值不在于验证卦象准不准，而在于发现自己的预期有多不可靠。**——三年里，他年初列的三件"最重要的事"，每年都有一件在第二年看来完全不重要。

**启示**：年度复盘的重点不是"完成了什么"，而是**"我的预期与现实差在哪里"**。这个差值，才是你真正能学到的东西。

### 31_7 本板块的笔记方法与验收

**笔记方法：模板落地三步骤**

1. **复制模板**：把 31_3 的模板存成文件，每次新建笔记直接复制；
2. **固定时间**：每日、每周、每月、每年的复盘时间写进日历，不靠记忆；
3. **季度审计**：每季度检查一次——模板的第六栏有多少则写满了？卦例库有多少则回填了？

**验收（五个可检查的动作）**：

- [ ] 能把决策五问写在纸上，并用它处理一次真实决策。
- [ ] 能建立个人知识库目录，并按编号命名至少十则卦象笔记。
- [ ] 能连续四周完成周复盘（常德行 / 习教事 / 我在哪一爻）。
- [ ] 能用"一卦一悟"模板写完一则**六栏俱全**的笔记。
- [ ] 能说出三种思维升级的达标标准，并对自己做出判断。
