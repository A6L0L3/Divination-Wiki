## 板块7 · 结构层：当位、中、正、应与比

> 《易》判断一爻好坏，靠的不是感觉，而是一张**五坐标评分卡**。

本板块把"吉凶悔吝"从玄学判断变成可操作的评分流程。

---

### 7_1 当位（得位 / 失位）：能力与位置是否匹配

**规则**：**初、三、五为阳位，二、四、上为阴位**。阳爻居阳位、阴爻居阴位 = 当位；反之 = 失位。

```latex
   上（阴位）── 阴爻居此 = 当位
   五（阳位）── 阳爻居此 = 当位
   四（阴位）── 阴爻居此 = 当位
   三（阳位）── 阳爻居此 = 当位
   二（阴位）── 阴爻居此 = 当位
   初（阳位）── 阳爻居此 = 当位

   记忆法：奇数为阳位（初·三·五），偶数为阴位（二·四·上）

```

**含义**：当位表示"能力与位置匹配"。让外向的人做销售（当位）、让内向的人做销售（失位）——失位不是不能做，而是**更费力、更易出错**。

**重要补充**：当位并非绝对好。有些爻因"知不足而谨慎"反而得吉；当位而自满反致凶。**《易》的判断永远是条件判断，不是标签判断。**

**一个特例**：乾卦上九"**贵而无位**"，坤卦上六"**其道穷也**"——上爻虽是阴位，但已到尽头，当位与否已不重要。

---

### 7_2 中（得中）：分寸感是最高能力

**规则**：下卦中爻是**二爻**，上卦中爻是**五爻**。居此二位称"得中"。

**含义**："中"即无过无不及、不偏不倚。**得中的爻即便不当位，也多有回旋余地。**

二爻是"臣位之中"，五爻是"君位之中"——**二五相应，是《易》里最理想的搭档结构**。

> **现代翻译**：**中就是分寸感。**能力再强，过激即失中；忍让再好，过度即懦弱。

**为什么"中"比"当位"更宽容**：当位讲的是"配不配"，得中讲的是"过不过"。不配可以补，过了则难以挽回——所以《易》给"中"留了更多余地。

---

### 7_3 正（贞）：底线，以及"坚持"的边界

"正"兼指当位与守正道。爻辞中的"**贞**"字，基本义是"正固、坚守"，也可训为"问"（占问）。

**关键句式辨析**：

| 句式 | 含义 | 现代翻译 |
| --- | --- | --- |
| 利贞 | 宜坚守 | 这条路可以长期走 |
| **贞吉** | 守正才吉 | 只有守住底线才吉 |
| **贞凶** | 一味固执则凶 | 环境已变，你的坚持成了硬扛 |
| 利永贞 | 宜长期坚守 | 柔不是权宜，是长期战略 |

> **警惕**：**"贞凶"的存在说明《易》从不无条件赞美坚持。**环境已变时，坚持就成了"用旧方法硬扛新环境"。

**判断标准（可执行）**：如果这个方法在三年前有效、现在无效，它大概率不是"正道"，是"惯性"。

---

### 7_4 应、比、承、乘：关系维度

**第1步 应**：初与四、二与五、三与上，两两相应。
**若一阴一阳 = 有应**（得援）；**若同阴或同阳 = 无应**（孤立）。

```latex
   上爻 ●━━━━━━━━━━● 三爻
   五爻 ●━━━━━━━━━━● 二爻
   四爻 ●━━━━━━━━━━● 初爻

   一阴一阳 → 有应（得外部助力）
   同阴同阳 → 无应（得靠自己）

```

**第2步 比**：相邻两爻的关系。异性相邻为"亲比"（相助），同性相邻为"敌比"（相斥）。

**第3步 承乘**：阴爻在阳爻之下为"**承**"（柔承刚，顺吉）；阴爻在阳爻之上为"**乘**"（柔乘刚，逆，多吝）。

**第4步 一个重要原则**：王弼《周易略例》说"**近不必比，远不必乖**"——相邻未必亲近（屯六二守贞不从初九），相隔也未必背离（六二远应九五，十年乃字）。
**看关系不能只看物理距离，要看阴阳是否相求。**

> **现代用法**：办公室里坐在你旁边的人未必是盟友，跨部门那个肯帮你说话的人才是"有应"。判断支持系统，看的是**需求是否互补**，不是距离远近。

### 7_5 实操：五坐标速判表

拿到一爻，五步走完：

| 步骤 | 自问 | 判断 |
| --- | --- | --- |
| 1 | 这一爻当位吗？ | 当位 → 基础盘稳；失位 → 需要额外努力 |
| 2 | 得中吗（二或五）？ | 得中 → 有容错空间 |
| 3 | 有应吗？ | 有应 → 有外部助力；无应 → 得靠自己 |
| 4 | 与邻爻亲比还是敌比？ | 亲比 → 环境友好；敌比 → 提防身边阻力 |
| 5 | 是承还是乘？ | 承 → 顺；乘 → 逆，多吝 |

**完整版六问**（加上卦时与卦主，推荐日常使用）：

```latex
   第1步 卦时：这一卦描述的是什么大势？（见板块8）
   第2步 卦主：全卦的意义集中在哪一爻？（见板块8）
   第3步 当位：能力与位置匹配吗？
   第4步 得中：分寸感够吗？
   第5步 有应：有没有外部助力？
   第6步 亲比 / 承乘：身边环境是助力还是阻力？

```

### 7_6 案例小故事：五坐标的三次救命

**故事一 · 有应与无应**

许静是一家消费品公司的区域经理，业绩连续两年排名第一，却两次晋升落空。她一度怀疑是"公司不识货"，甚至开始考虑跳槽。

用五坐标一查她的处境：她所在的岗位**无应**——她的直接上级最需要的是能补位做资源协调与跨部门沟通的人，而她擅长的是执行与落地，两人诉求不互补（同为"阳"，无应）；同时**敌比**——相邻的两位同级区域经理能力结构与她高度相同，天然竞争有限的资源与曝光机会。

结论很清楚：**她的业绩是在一个没有支持系统的位置上取得的，这不是可持续状态**，靠个人能力硬撑出来的第一名，撑不了第三次。

她做的调整不是更努力地干活，而是**主动建立一个"有应"的结构**：她找到一位资源极强、但落地能力弱的同级，主动提出帮对方做执行，换取对方帮她连接总部资源。半年后局面改观——她第一次拿到跨区域项目的主导权。

**启示**：很多人把"无应"的困境归结为自己不够好，其实问题在**关系结构**，不在能力。能力决定你能跑多快，结构决定你能不能一直跑。

**故事二 · "贞凶"的现代版**

一位做传统实木家具的老板，坚守"真材实料、绝不降价"二十年，这曾是他成功的根本——在本地市场，他的口碑是靠这一条建起来的。

行业转向性价比与快速迭代后，他仍然坚持不降价、不改产品线，理由是"我不能骗人"。三年内市场份额掉了七成，工厂被迫关停一条生产线。

他以为自己在守正，其实是在**"贞凶"**——用旧方法硬扛新环境。《易》从不无条件赞美坚持：环境变了，坚持就成了刻舟求剑。

后来他想通了一件事：**"真材实料"是他表达价值主张的方式（属于可变策略层），"不欺骗客户"才是他的绝对底线。**他把产品线拆成两条：一条保留高端定制，全实木、手工、长交期（守住初心与老客户）；一条做标准化平价产品，用板材与模块化设计，但所有材质在合同里写得清清楚楚（顺应市场，同时不骗人）。

两年后工厂恢复盈利，老客户没有流失。

**启示**：分清楚"绝对底线 / 重要原则 / 可变策略"三层，才知道什么是"贞吉"，什么是"贞凶"。多数人的痛苦，来自把策略当成了原则。

**故事三 · 亲比与敌比的一次团队诊断**

一个新组建的产品项目组，五个人都是各自领域的好手，履历漂亮，却在两个月内只交付了一个小版本，会议不断、互相否决，效率极低。

组长用五坐标做了一次结构诊断：五个成员的能力结构高度同质——都是强执行、强判断、弱协调的"阳"，彼此相邻皆是"敌比"（同性相斥），无人互补；且五个人都想做决策者，没有一个人稳定在五爻的位置上。

他做的不是团建，也不是换人，而是**调整结构**：调出一位执行者到另一个项目，换入一位擅长协调与资源整合的成员；同时明确一人为最终决策者（五爻），其余为配合者，分歧时由决策者拍板并记录理由。

一个月后效率明显提升，交付节奏回到了正常水平。他总结：**一群同样优秀的人凑在一起，不一定是强队，可能只是"敌比"的集合。**

**启示**：团队的问题，先看阴阳配比与亲比敌比，再看个人能力。结构对了，平庸的人也能出活；结构错了，优秀的人会互相消耗。

### 7_7 本板块的笔记方法与验收

**笔记方法：一爻一评分（每周至少做三次）**

```latex
┌──────────────────────────────────────────────┐
│ 卦名：____  我关注的爻：第 ___ 爻（九/六 ___）   │
├──────────────────────────────────────────────┤
│ 1. 当位：□ 当位  □ 失位                        │
│ 2. 得中：□ 得中  □ 不得中                      │
│ 3. 有应：□ 有应  □ 无应                        │
│ 4. 比  ：□ 亲比  □ 敌比                        │
│ 5. 承乘：□ 承（顺） □ 乘（逆）                 │
├──────────────────────────────────────────────┤
│ 结构评分（1-5）：___                            │
│ 这一爻告诉我的一个动作：________________        │
└──────────────────────────────────────────────┘

```

**验收（五个可检查的动作）**：

- [ ] 能说出阳位与阴位分别是哪三爻，并判断任意一爻当位与否。
- [ ] 能解释"得中"为什么比"当位"更宽容，并说出二、五爻的特殊意义。
- [ ] 能说出"贞吉"与"贞凶"的区别，并解释《易》为什么不无条件赞美坚持。
- [ ] 能说出应的配对规则（初四、二五、三上），并判断任意两爻有应与否。
- [ ] 能解释"近不必比，远不必乖"，并说出一个职场中的对应现象。
