## 板块15 · 上经三十卦速查

> 上经三十卦不是三十个独立卦，是**一部连续剧**。

使用说明：**处境** = 这一卦描述的是什么样的局面；**该做** = 最该做的一件事；**陷阱** = 这个局面里最容易犯的错。

### 15_1 上经的结构逻辑（先理解这个，再查表）

《序卦传》给出的链条是——

**有天地（乾坤）然后万物生（屯）→ 生而蒙昧（蒙）→ 需要养育等待（需）→ 资源不足起争（讼）→ 争而至兵（师）→ 战后亲附（比）→
小有积蓄（小畜）→ 定分守礼（履）→ 通达（泰）→ 闭塞（否）→ 破闭塞而同心（同人）→ 同心则大丰（大有）→
丰而能谦（谦）→ 谦则安乐（豫）→ 乐则有人追随（随）→ 久随生弊（蛊）→ 弊则需临治（临）→ 治成可观（观）→
观而后有合（噬嗑）→ 合而后有文饰（贲）→ 饰极则剥落（剥）→ 剥极而复（复）→ 复则不妄（无妄）→ 不妄则可大畜（大畜）→
畜而后可养（颐）→ 养而不已则过（大过）→ 过则陷（坎）→ 陷必有所丽（离）。**

```latex
乾坤（天地）→ 屯蒙需讼（生·蒙·待·争）→ 师比（兵·附）
    │
    ▼
小畜履（积·礼）→ 泰否（通·塞）→ 同人大有（同心·丰盛）
    │
    ▼
谦豫随（谦·乐·从）→ 蛊临观（弊·治·示范）→ 噬嗑贲（合·饰）
    │
    ▼
剥复（剥·复）→ 无妄大畜（不妄·蓄）→ 颐大过（养·过）
    │
    ▼
坎离（陷·丽）

```

这条链条的本质是：**天地开辟 → 万物初生 → 蒙昧启蒙 → 需求等待 → 争执诉讼 → 军队约束 → 小有积累 → 守礼行事 → 泰否交替 → 合作丰盛 → 谦退守成 → 盛极而衰 → 剥落复生**。

> **不要跳着读。**跳读等于看连续剧只看第 3 集和第 58 集。

### 15_4 案例小故事：上经里的三卦现场

**故事一 · 履卦：踩着老虎尾巴走路**

一位三十岁的空降主管，需要在两位资历比他老十岁的下属之间推动一次流程改革。这两位一位是公司的开国元老，一位手上握着最大的客户。他明白，任何一步走错，改革就会变成"新老之争"。

他把这个处境读成履卦——**"履虎尾"**：踩着老虎尾巴走路，老虎不咬你，不是因为老虎温顺，而是因为你踩的位置和姿态对。履卦的"该做"是守礼而行、柔履刚之后；"陷阱"是越位、失礼、在危险中掉以轻心。

他做了三件事：

第一，**所有改动先走正式流程**（守礼）——他没有在微信群里打招呼，而是在部门会议上发了正式的方案文档，抄送了相关方，给了十天的反馈期。

第二，**私下先与两位老下属各谈一次**（柔履刚）——每次一小时，只问两个问题："这个流程里你现在最痛的是什么？""如果必须改，你最不能接受的是什么？"

第三，**方案里保留了他们的核心职责**（不越位）——他没有借流程改革重新划分地盘，反而明确写明客户归属不变、审批权限不变。

半年后改革平稳落地。他说：**履卦教我的不是"小心"，是"用礼和柔去履险"**。同样的改革内容，如果第一周就在群里发一句"从今天起按新流程走"，大概率会翻车。

**启示**：在危险处境里，"态度"不是软实力，是硬变量。履卦的判断标准只有一条：你有没有越位、有没有失礼。

**故事二 · 贲卦：包装过度**

一款厨房小家电，功能平平——加热速度慢、噪音偏大、清洁麻烦，但外观设计极好，营销也做得漂亮：请了知名博主、拍了电影质感的短片、主打"厨房里的艺术品"。首月销量冲到品类前三，团队开香槟。

三个月后退货率超过四成，差评集中在"好看但不好用"，口碑崩塌，第二年的渠道进货量腰斩。

贲卦讲"文饰"。它的"该做"是**"适度修饰，白贲无咎——饰极返素"**：装饰到极致要回到素朴；它的"陷阱"是**"过度包装，文胜于质"**。

团队复盘时承认：他们在立项时的资源分配是——研发三成、外观与营销七成。也就是说，"质"从一开始就落后于"贲"，后面所有的营销，都是在放大一个不达标的产品。

后来他们砍掉一半营销预算，全部投入产品迭代，把研发资源占比提到六成，并把外观团队并入研发流程（让"贲"服务于"质"，而不是替代"质"）。一年后复购率回到健康水平，退货率降到百分之八。

**启示**：贲是必要的形式——产品需要被看见、被理解。但**文饰不能替代实质**，而且"饰极必须返素"：包装到顶之后，唯一能救你的就是回到产品本身。

**故事三 · 大过：非常之时行非常之事**

一家做企业服务的公司，突然遭遇核心客户破产，该客户占其营收六成。常规做法是"逐步开发新客户"，但账上现金只够撑两个月，而新客户的平均成交周期是五个月。

这是典型的**大过**卦处境：栋梁弯曲，过甚之象。大过的"该做"是**"非常之时行非常之事；独立不惧"**；"陷阱"恰恰是**"用常规手段应对非常局面"**（另一面是过于刚猛折断）。

他们做的决定是三件事，每一件在平时都算"激进"：

一是**立刻裁撤三条非核心产品线**，把二十人的团队缩到九人，按法定标准补偿，当天谈完；二是**把全部资源集中到两个高毛利的存量客户**上，把他们的需求做到极致；三是**创始人亲自下场做销售**，不再管内部事务。

两个月后现金流转正，两个存量客户因为服务升级都续了约并扩了单。一年后团队回到十五人，但营收结构从"六成靠一家"变成"最大的客户占三成"。

**启示**：非常之时不能用常规节奏。判断标准很简单——**如果按常规节奏走，你的时间够不够？不够，那就不是大过之时该做的事。**

### 15_5 本板块的笔记方法与验收

**笔记方法：上经因果链手绘图 + 每周四卦**

1. 手绘一张上经因果链图（按 15_1 的链条画成流程图），贴在墙上，每读一卦就在链上标个记号。
2. 每周精读 4—6 卦，每卦用板块31的"一卦一悟"模板写一则笔记，重点写"当前处境"与"行动指南"两栏。
3. 每卦必须写"我生活中哪件事对应这一卦"——写不出锚点的卦，说明还没读懂。

**验收（五个可检查的动作）**：

- [ ] 能背出《六十四卦卦序歌》的上经部分（乾坤屯蒙需讼师，一直到大过坎离三十备）。
- [ ] 能说出上经三十卦中任意一卦的"处境 / 该做 / 陷阱"（抽查五卦）。
- [ ] 能说出上经三段划分及其主题。
- [ ] 能把《序卦传》的因果链讲通（从乾坤到坎离）。
- [ ] 能为上经中至少五卦各配一个自己生活中的现实锚点。
