## 板块6 · 结构层：爻、爻位与三才

> 如果说八卦是《易》的字母表，爻位就是它的语法。

**拿到一卦，第一个动作永远是：这件事在第几爻。位置一定，该做什么就不言自明了。**

---

### 6_1 爻：卦的最小单位与命名规则

一个六爻卦从下往上数，依次是初爻、二爻、三爻、四爻、五爻、上爻。

**命名规则**：

+ 阳爻称"**九**"，阴爻称"**六**"；
+ 位置 + 阴阳 = 爻名。乾卦初爻是阳爻 → **初九**；坤卦初爻是阴爻 → **初六**；
+ **第一爻叫"初"不叫"一"，第六爻叫"上"不叫"六"**（初是时间概念，上是空间概念：第一爻强调"初始"，第六爻强调"上位"）。

```latex
   上爻  ─────────  上九 / 上六      （第六爻）
   五爻  ─────────  九五 / 六五
   四爻  ─────────  九四 / 六四
   三爻  ─────────  九三 / 六三
   二爻  ─────────  九二 / 六二
   初爻  ─────────  初九 / 初六      （第一爻）

   从下往上读，永远如此。任何结果都是一点一点从底层长出来的。

```

**爻的本质**：《系辞》说"**爻者，言乎变者也**"——爻是"效"，是模仿万物的变化。所以爻辞讲的永远是**正在变化的东西**，不是静止的状态。

> **由此可得一条读卦纪律**：读到爻辞，先把它理解成"这个阶段正在发生什么变化"，而不是"这个人是什么样的人"。

---

### 6_2 爻位：六个位置对应事物发展的六个阶段

这是解卦最实用的一张表。六个爻位**从下往上读**：

| 爻位 | 阶段含义 | 人事类比 | 常见处境 |
| --- | --- | --- | --- |
| **初爻** | 发端、根源、潜藏 | 新人、种子期、项目立项 | 力量未足，宜积累不宜张扬 |
| **二爻** | 崭露头角、初见成效 | 骨干、小有成绩 | 开始被看见，需要贵人 |
| **三爻** | 下卦之极，危险过渡带 | 中层、爬坡期、瓶颈 | 凶险与机遇并存，宜警惕 |
| **四爻** | 进入上卦，近君之位 | 高管、核心圈边缘 | 伴君如伴虎，宜谨慎柔顺 |
| **五爻** | 上卦之中，尊位 | 一把手、鼎盛期 | 权力与责任顶点，宜中正 |
| **上爻** | 终极、过度、退位 | 退休、尾声、过剩 | 能量耗尽，宜收敛不宜再进 |

**《系辞》的三条统计规律**：

1. **二多誉，五多功**：二爻居中且应五，五爻居中且尊位，两者爻辞多吉。
2. **三多凶，四多惧**：三爻处下卦之极、进退两难；四爻近五爻之君，动辄得咎。
3. **初难知，上易知**：初爻是苗头，难以判断；上爻是结局，一目了然。

```latex
   上  易知（结局已定）· 宜收敛
   五  多功（鼎盛尊位）· 宜中正
   四  多惧（近君）    · 宜柔顺
   三  多凶（下卦之极）· 宜警惕
   二  多誉（初见成效）· 宜借势
   初  难知（苗头）    · 宜积累

```

### 6_3 实操：给自己的处境"定位"

面对任何事，先问："我这件事，在第几爻？"

| 现实情境 | 对应爻位 |
| --- | --- |
| 新项目立项 | 初爻 |
| 做出成绩被领导看见 | 二爻 |
| 卡在中层上不去 | 三爻 |
| 进了核心决策圈 | 四爻 |
| 独当一面 | 五爻 |
| 功成名就想着退路 | 上爻 |

**定位之后的三步动作**：

1. **确认阶段**：我在这件事上，客观处于第几爻？（注意：不是"我希望在第几爻"）
2. **查该爻的通行策略**：初宜积累、二宜借势、三宜警惕、四宜柔顺、五宜中正、上宜收敛。
3. **写下不匹配的地方**：如果我在初爻却按五爻的方式做事（抢功、越级、急着定战略），这就是风险本身。

### 6_4 三才：六爻的整体读法

一个六爻卦可以切成三层，每层两爻，叫**三才**：

+ **初、二爻 = 地道**（基础、资源、底层条件）
+ **三、四爻 = 人道**（努力、选择、人际互动）
+ **五、上爻 = 天道**（时势、大环境、不可逆因素）

《说卦传》总纲："**立天之道曰阴与阳，立地之道曰柔与刚，立人之道曰仁与义。**"

```latex
   上爻 ┐
        ├─ 天道：时势 · 大环境 · 不可逆因素
   五爻 ┘
   ─────────────────────────────────────
   四爻 ┐
        ├─ 人道：努力 · 选择 · 人际互动
   三爻 ┘
   ─────────────────────────────────────
   二爻 ┐
        ├─ 地道：基础 · 资源 · 底层条件
   初爻 ┘

```

**归因三问**（三才的可执行版）：

1. 这件事的困难，主要出在**地道**（资源 / 基础不够）吗？→ 补资源、练基本功；
2. 还是出在**人道**（方法 / 协作不对）吗？→ 改方法、调关系；
3. 还是出在**天道**（大势 / 时机不对）吗？→ 守、等、转，不要用勤奋硬扛。

> **第 3 问最容易被跳过，也最有价值**：很多"努力没用"的痛苦，本质是**你在用人道的方式解决天道的问题**。大环境已变（天道），再怎么加班（人道）也无用。

### 6_5 案例小故事：爻位与三才的四次现场

**故事一 · 在三爻用二爻的打法**

李维原是公司的技术骨干，代码写得好、交付从没延误过。被提拔为部门经理后，他处在典型的**三爻**位置——下卦之极、上下交界、进退两难，是"三多凶"的地带。

他却沿用做骨干时的打法：亲力亲为，最难的需求自己扛；凡事冲在最前面，有问题先自己解决再说。三个月后，团队没有成长（下属没机会上手），他自己累到住院，上级的评价是"业务能力强，但不会带人"。

这是典型的**爻位错位**：三爻的策略是"警惕与过渡"（终日乾乾、夕惕若），不是"冲锋与展现"（那是二爻的打法）。他该做的是把执行交给下面，自己转向协调、资源争取与风险预判。

后来他做了一件事：把每周的"我做"改成"我看谁做"，并建立了一张风险清单，每周只盯三条。半年后团队产出翻倍，他也第一次休了一个完整的假。

**启示**：能力没有变，位置变了，打法必须变。用旧爻位的方法解决新爻位的问题，是《易》里最常见的一种"凶"。

**故事二 · 在初爻急着飞**

战国时的苏秦，早年出游数载、一无所成，回到家中"妻不下纴，嫂不为炊，父母不与言"。他后来的成功常被讲成励志故事，但《易》的视角更冷静：**他早年的失败，是因为在初爻（资历未足、资源未备、方向未明）就用了九五的动作**——直接去游说当时最强的秦国，谈的是最顶层的天下格局。

初爻该做的事是"潜龙勿用"：打磨本事、观察规则、积累可被验证的小成绩。他后来"读书欲睡，引锥自刺其股，血流至足"，补的正是初爻的功课——**积累与观察**。等到对列国形势的判断与自身的储备都到位，才有了佩六国相印的那一天。

**启示**："潜龙勿用"不是劝你躺平，是**告诉你现在还不是用的时候**。判断"用"与"勿用"的标准不在你的野心有多大，而在你处在第几爻。

**故事三 · 天道与人道的错配**

一位教培机构的主管，在行业政策变化后的那一年加倍努力：每天工作十四个小时、开发三倍数量的课程、把销售话术打磨到极致、亲自下场做直播。一年后，公司仍然关了。

用三才归因：他的困难**不在人道**（他已经足够努力，甚至过度努力），**也不全在地道**（教学基本功扎实、团队稳定），而**在天道**——行业大势已变，这不是努力能改变的变量。

《易》的判断很明确：**天道的问题，用天道的解法——守、等、转。**勤奋可以解决人道的问题，解决不了天道的问题。很多"努力没用"的痛苦，本质都是这一层错配。

两年后，他用同样的教学能力转做企业内训，活了下来，而且收入结构比原来更健康。他后来说：**我早该在第三个月就问一句"这是哪一层的问题"。**

**启示**：遇到"怎么努力都没用"时，先做三才归因，再决定要不要继续努力。

**故事四 · 上爻的知止**

一位做企业软件的创业者，把公司做到行业第二。投资人劝他趁热打铁，再融一轮、扩三条产品线、把团队从一百五十人扩到四百人——也就是在**上爻继续加码**。

他却做了三件反向的事：把一部分股权分给管理层、培养了能接班的 COO、自己从 CEO 退到董事长位置，只管战略与人事。

同行笑他"没冲劲"，说他错过了做老大的机会。两年后行业进入下行周期，那批继续加码的公司大多陷入困局——产品线拉太长、现金流断裂、创始人被投资人架空；他的公司因为决策链条短、人才梯队完整、账上现金充裕而活了下来，还在下行期收购了两家友商的核心团队。

**启示**：上九"亢龙有悔"的警示不是"别成功"，而是**"成功后要主动损盈"**——让功、让利、让位（详见板块21）。

### 6_6 本板块的笔记方法与验收

**笔记方法：六爻定位卡（每周用一次）**

```latex
┌────────────────────────────────────────────────┐
│  本周六爻定位卡                                   │
├────────────────────────────────────────────────┤
│  1. 工作这件事，我处于第 ___ 爻（理由：____）      │
│  2. 该爻的通行策略是：______________________      │
│  3. 我实际在做的事：_______________________      │
│  4. 不匹配的地方（这就是风险）：____________      │
│  5. 下周要调整的一件事：____________________      │
├────────────────────────────────────────────────┤
│  三才归因：□ 地道 □ 人道 □ 天道（勾一个主因）      │
│  对应解法：□ 补资源 □ 改方法 □ 守·等·转            │
└────────────────────────────────────────────────┘

```

**升级用法**：把这张卡同时用在"工作、健康、关系、财务"四个维度上，你会发现四个维度往往不在同一个爻位——**这正是你精力冲突的来源**。

**验收（五个可检查的动作）**：

- [ ] 能说出六爻的名称（初、二、三、四、五、上），并解释为什么第一爻叫"初"、第六爻叫"上"。
- [ ] 能背出"二多誉、五多功、三多凶、四多惧"，并各举一个人事类比。
- [ ] 能对当前一件重要的事定位爻位，并说出该爻的通行策略与自己做法之间的差距。
- [ ] 能说出三才如何划分六爻，并用归因三问判断一件"努力无效"的事的主因。
- [ ] 能举出自己生活中一次"爻位错位"的经历（用旧爻位的方法解决新爻位的问题）。
