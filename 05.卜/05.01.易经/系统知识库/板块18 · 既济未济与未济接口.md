## 板块18 · 既济未济与未济接口

> 六十四卦终于"未济"，是整部《易》最有哲学意味的安排。

本板块专讲这一组对照，以及它给现代人最实用的一条做法：**给每件事留一个未济接口。**

---

### 18_1 既济与未济：一组反常识的对照

+ **既济（63）**：六爻全部当位（阳在阳位、阴在阴位），结构完美，事情完成；
+ **未济（64）**：六爻全部失位，结构全乱，事情未完成。

常识会问：为什么把"完美"排在"混乱"前面？

**因为"完成"就是"终结"，而终结即死亡。**

```latex
   既济 ䷾：六爻皆当位 → 结构完美 → 完成 → 终结（终止则乱）
   未济 ䷿：六爻皆失位 → 结构全乱 → 未完成 → 仍有可为

   《易》的选择：宁可停在未济。
   变化不息，君子终日乾乾。

```

**既济卦的爻辞提示**：卦辞说"亨，小利贞，初吉终乱"——开始是吉的，最终会乱。《象传》说得更直白："**君子以思患而豫防之**"。
一个六爻全部当位的完美结构，为什么反而"终乱"？因为**完美意味着没有调整的余地**。结构一旦不能再变，就走向僵化。

**未济卦的提示**：《象传》说"**君子以慎辨物居方**"——重新定位，继续前行。它的"陷阱"是"以为已经结束；或无方向地继续"。

---

### 18_2 为什么这个安排重要

| 视角 | 停在既济（完成） | 停在未济（未完成） |
| --- | --- | --- |
| 结构 | 全部当位，无调整空间 | 全部失位，处处可调整 |
| 状态 | 冻结 | 流动 |
| 风险 | 终止则乱 | 需要防"无方向地继续" |
| 隐喻 | 终结即死亡 | 变化即生机 |

> **这正是东坡易学精神的隐喻**：变化不息，学无止境，君子终日乾乾。

---

### 18_3 实操：给每件事留一个"未济接口"

**三条具体做法**：

1. **项目结束时，强制留下一个"未完成"的部分**——下一个版本的种子、一份待验证的假设。不要把所有事情都做"完"。
2. **达到目标后，24 小时内写下"下一个目标是什么"**。没有下一个目标的成功，是既济，是停滞的开始。
3. **年度复盘时，不要写"完成了什么"，写"还有什么没完成，并且我打算继续"**。

```latex
┌──────────────────────────────────────────────┐
│  未济接口清单                                  │
├──────────────────────────────────────────────┤
│  已完成的事：__________________________        │
│  留下的未完成部分（种子/假设）：________        │
│  下一个目标（24 小时内写下）：__________        │
│  我打算继续的是：______________________        │
└──────────────────────────────────────────────┘

```

### 18_4 "慎辨物居方"：未完成时应有的姿态

未济卦给的不是"随便继续"，而是两件事：

+ **辨物**：分清哪些事已经做对、哪些还没做对——未完成不等于一团乱，需要重新分辨；
+ **居方**：给每样东西重新定位——下一步的资源、精力、方向放在哪里。

```latex
   未济的两个动作：
   第1步 辨物（分辨：什么对了，什么还没对）
   第2步 居方（定位：下一步把资源放哪）

   陷阱：以为已经结束（停止）／无方向地继续（乱动）

```

### 18_5 案例小故事：完成与未完成的四次对照

**故事一 · 写完最后一稿的那一天**

一位作家写完一本书的最后一稿，当晚没有庆祝，而是列下了下一本书的三个选题，每个选题后面写一行"我为什么要写它"。她说这是从"未济"学来的：**完成是终结，未完成才是生机。**

她的朋友同期完成了一部重要作品——一本写了四年的非虚构，出版后反响很好。之后两年他没有新作，形容自己"像被抽空了"，每次想动笔都觉得"上一本还没消化完""不能写得比上一本差"。

两人后来聊起这件事，朋友才意识到问题在哪：他把上一本书当成了一个**完成**（既济），而不是**一个阶段的结束、下一个阶段的开始**。

他后来试了一个很小的动作：在下一本书动笔之前，先写三页"我这次想搞清楚但上一本没搞清楚的问题"。这三页让他从"要超越上一本"的压力里解脱出来——他不再是接着上一本走，而是接着一个未解决的问题走。一年后他的新书开笔了。

**启示**：没有下一个目标的成功，是既济，是停滞的开始。六十四卦终于未济，不是巧合，是《易》对"完成"这件事的态度。

**故事二 · 一个"完美"系统的崩塌**

一家公司花两年时间建成了一套极其完善的流程体系：每个环节都有 SOP、每个决策都有审批链、每个岗位都有考核表、每个项目都有模板。上线时全员叫好，管理层把它当作核心资产。

一年后问题显现：市场变了，竞争对手把交付周期压缩了一半，而他们改一条 SOP 要走三层审批，平均耗时五周。等流程改完，机会已经过去了。销售团队开始绕开流程自己干，流程体系名存实亡。

用卦象说，这是一个"六爻皆当位"的**既济**结构——完美，但没有调整空间。既济的卦辞早就说了四个字："**初吉终乱**"。

他们后来做了一次"故意留缺口"的改造：把百分之二十的环节设为"可临时突破"，并授权一线人员在紧急情况下跳过审批（事后二十四小时内补录并说明原因）。同时规定，每一次"临时突破"都要在月度会上复盘，如果同类突破出现三次，就说明流程本身需要改。

公司重新有了弹性，而且这套"突破—复盘—改流程"的机制，让流程体系开始自己进化。

**启示**：完美的结构往往是最脆弱的结构。留一点"失位"，才有调整余地——这既是对既济的警告，也是未济之所以排在最后的理由。

**故事三 · 未济接口救了一个开源项目**

一位工程师每年末写复盘。过去他总写"今年完成了什么"：上线了三个项目、优化了两次架构、读了五本书。写完总有种空虚感，好像一年到此为止了，下一年要从零开始。

后来他改成写"**还有什么没完成，并且我打算继续**"。第一年他写下的"未完成"是一个搁置了很久的开源小工具——一个帮运维同学自动生成巡检报告的东西，当时写了三分之一就停了。

因为被写进了清单，他第二年真的把它做完了，还挂到了开源社区。三年后，这个工具成了他职业转型的跳板——新公司正是因为看到这个项目才向他发出邀请，面试官说"我们看到的不只是代码，是你把一个东西做完的能力"。

他后来把这个习惯固化成一条规则：**每年末的复盘里，"未完成且打算继续"这一栏不能为空，而且不能超过三条。**

**启示**：完成是终结，未完成才是生机。给每件事留一个"未济接口"——项目结束时留下一个未完成的部分，达到目标后二十四小时内写下下一个目标，年度复盘时不写"完成了什么"而写"还有什么没完成"。

**故事四 · 慎辨物居方的一次转岗**

一位做了十年市场的中层被优化后，投了三个月简历无果。她开始怀疑自己"整个职业方向都错了"，一度想转行去做完全不同的事（她甚至报了一个心理咨询的培训班）。

朋友建议她先别急着动，用未济卦的两个动作做一次定位：**辨物**（分清哪些能力已经验证有效、哪些只是平台光环）和**居方**（下一步的资源放哪里）。

她花了两天列了两张清单。

有效且可迁移的：用户洞察（做过二十多场用户访谈，方法自成体系）、内容策划（主导过三个从零到百万级的内容项目）、活动执行（带过三十人以上的跨部门团队）。

属于平台光环的：**每年两千万的预算规模、成熟品牌的天然知名度、现成的渠道关系**。

结论很清楚：她该换的是行业，不是职能。她把简历全部投向消费品行业，把个人介绍里"负责某品牌全年市场预算"改成"从零搭建用户洞察体系并驱动产品迭代"。两周内拿到三个面试。

**启示**：未完成时的正确动作不是"乱动"，也不是"停住"，而是**先辨物，再居方**——先分清你能带走什么，再决定把资源投向哪里。

### 18_6 本板块的笔记方法与验收

**笔记方法：未济接口清单（每完成一件事就写一张）**

1. 完成一件事的当天，写下"留下的未完成部分"（种子或假设）。
2. 24 小时内写下"下一个目标"。
3. 年度复盘只写"还有什么没完成，并且我打算继续"，不写"完成了什么"。
4. 遇到停滞时，用"辨物 / 居方"两步重新定位。

**验收（五个可检查的动作）**：

- [ ] 能解释为什么《易》终于"未济"而不是"既济"。
- [ ] 能说出既济卦辞"初吉终乱"的含义，并解释为什么完美结构反而脆弱。
- [ ] 能说出未济卦《象传》"慎辨物居方"的两个动作各自是什么。
- [ ] 能为刚完成的一件事写下"未济接口"（未完成部分 + 下一个目标）。
- [ ] 能用"辨物 / 居方"两步，对一次停滞或转折重新定位。
