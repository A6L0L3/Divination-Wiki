## 板块1 · 这本书凭什么读一千年？

《毕法赋》成书于南宋理宗年间（1224—1264），作者凌福之。它的地位在壬学里约等于《黄金策》之于六爻、《烟波钓叟歌》之于奇门——是纲领性文件，不是入门趣味读物。

清朝六壬名家程树勋的评价一针见血：**"因用邵彦和《断案》而作，而复参以心得，故其书从考验中来"**。换句话说，这不是书斋里的玄想，而是凌福之把邵彦和《六壬断案》上千个实战课例（邵是南北宋之交的壬学集大成者）逐条压缩、抽象、提炼，才凝结成这100句七言口诀。史称"诸法咸备，至平至当"。

**读懂这句话，就读懂了读这本书的正确姿势：**

> 每一句口诀都不是"结论"，而是"压缩包"。它背后藏着一个完整课例、一套生克逻辑、一类应期判断。你背下"金日逢丁凶祸动"只需要三秒，但拆开这个压缩包要花三天。

## 板块2 · 先搞懂框架，再谈记忆

### 2_1 结构解剖：它为什么是"100句"而不是"100条"

赋文共100句，每句5字（少数6字），一句一法，故称"百法"。但**它的内在逻辑不是线性的100条，而是"总纲 → 六大门类"的树状结构**。原书分上、中、下三卷，若按占断功能重组，可归为六大模块：

| 模块 | 法数 | 核心问题 | 代表口诀 |
| --- | --- | --- | --- |
| **A. 局势基调类** | 1–10 | 这事整体是吉是凶、宜动宜静 | 前后引从、六阳六阴、旺禄临身 |
| **B. 生克制化类** | 11–16 | 凶神能不能被制、吉神会不会反噬 | 众鬼虽彰、狐假虎威、传财太旺 |
| **C. 进退取舍类** | 17–34 | 该进该退、该守该变 | 进茹空亡、有始无终、苦去甘来 |
| **D. 人我关系类** | 35–50 | 人与人之间、人与宅之间 | 人宅受脱、交车相合、贵人系统 |
| **E. 神将灾祥类** | 51–76 | 天将（蛇虎贵玄）如何发力 | 魁度天门、虎乘遁鬼、病符克宅 |
| **F. 空亡与终局类** | 77–100 | 事之真假、迟速、应期、边界 | 喜惧空亡、非占现类、已灾凶逃 |

### 2_2 两个地基概念（不弄清这个，后面全白搭）

+ **四课 = 主客内外关系图**：日干（我/事主）上下两课 + 日支（对方/事体/家宅）上下两课。看的是"我与外界、内与外"的结构。
+ **三传 = 事件时间轴**：初传（起/始）→ 中传（过程）→ 末传（归/终）。**初吉末凶 = 乐里悲；初凶末吉 = 苦去甘来。**

**核心洞察**：毕法赋100法，本质上就是在反复回答三句话——

1. 四课里，**谁生谁、谁克谁**？（内外关系）
2. 三传里，**从初到末是向好还是向坏**？（时间演化）
3. 凶神来了，**有没有东西能制它、能不能空掉**？（转化与消解）

掌握了这三问，你根本不用死记100句，看到任何一句都能现场推出来。

## 板块3 · 逐模块拆解：原文重点 + 可落地解读

> 说明：每模块先给**原文重点**（讲清楚法理），再给**落地要点**（讲清楚你怎么用）。标注"⚠️"的是网络教程里反复踩坑、最容易被误读的地方。

### 3_1 模块 A｜局势基调：先定"这事整体什么调子"

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 前后引从升迁吉 | 初传在日干前=引、末传在日干后=从，前后拱护。引从**天干**→升职；引从**地支**→迁宅修屋 |
| 首尾相见始终宜 | 干上有旬尾、支上有旬首（周而复始格），事不脱、谋皆成；**但不宜占"释放、解散"类** |
| 帘幕贵人高甲第 | 昼占取夜贵、夜占取昼贵（贵人藏在地支下=暗中相助），科考专视此神 |
| 催官使者赴官期 | 日鬼乘白虎加日干/年命=催官，值**空亡则是虚信** |
| 六阳数足须公用 | 课传全落阳支→气场光明，**只宜公事、公开，不宜私谋** |
| 六阴相继尽昏迷 | 全阴→晦暗，宜私密，**易信息闭塞、受人蒙蔽** |
| 旺禄临身徒妄作 | 禄神又是旺神临干→**守住别动**，舍此别谋=白折腾 |
| 权摄不正禄临支 | 禄神加支辰→**不自尊大，受屈于他人**，或"借宅上之禄" |

**落地要点**

+ **"引从"是最优先看的吉格之一**：判断仕途、晋升、项目落地，先看初末是否拱干。实操时把"引从"记成一句口诀：**天干拱→人升，地支拱→宅动**。
+ ⚠️ **"首尾相见"的反面必须记住**：周而复始格占"求成、求合、求婚"大吉，但占"释放、解脱、散伙"反而**事不脱、难解散**。这是典型的"同格异断"，取决于你问的是什么动词。
+ ⚠️ **"旺禄临身徒妄作"是被误读最多的一句**：它不是"躺着不动"的消极哲学，而是"**你已经处在最优位置，向外谋求的都是空的**"——很多课里你舍了旺禄去追初传的财、中末的生，结果发现那些全是旬空。→ **实操铁律：看到禄临干，先查其他传是否空亡，再决定是否守成。**
+ **六阳/六阴 = 决策环境判据**：现代应用里，这俩口诀可以转化为——**阳格适合公开谈判、竞标、对外发文；阴格适合私下沟通、密谈、内部调整**。不是吉凶，是"场域匹配"。

### 3_2 模块 B｜生克制化：凶神来了怎么办（全书最精华部分）

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 众鬼虽彰全不畏 | 三传全是日鬼（极凶），但**干上有制鬼之物**（如寅木敌戌丑辰之土），鬼不能为害 |
| 虽忧狐假虎威仪 | 丁火畏子水，但**依赖支上未土制水**护住丁干，狐借虎威得免 |
| 鬼贼当时无畏忌 | 春占三传木局为日鬼，但木当令贪荣旺，**无意克土，待夏秋其祸乃发** |
| 传财太旺反财亏 | 三传皆财、又逢财旺之月→财贪生旺，**不肯来就我**；待身旺财衰方可取 |
| 脱上逢脱防虚诈 | 干生上神、上神又生天将=层层泄耗，虚诈不实 |
| 空上乘空事莫追 | 干上旬空又乘天空=**指空划空，全无实象** |

**落地要点**

这是《毕法赋》真正的"技术含量"所在，六条全是**反直觉**的：

1. **"众鬼虽彰全不畏"——凶局的解药在干上。** 看到满盘鬼爻先别慌，立刻检查干上是否有制鬼之神。→ 实操：**凶神先看"有没有制"，再看"空不空"**，顺序不能反。
2. **"鬼贼当时无畏忌"——祸会延迟，不是消失。** 当令之鬼贪旺不克，但时令一转（夏秋）就发作。→ **这条直接给出"应期"：凶在将来时令**。占病占讼，当下没事≠没事，要问"什么时候转坏"。
3. **"传财太旺反财亏"——太旺的东西得不到。** 财旺到只顾自己生长，反而不能被我所用。⚠️ 这是"取财时机"口诀：**身旺财衰时取，财太旺时别硬拿**。求财占遇此，正确动作是"等"，不是"冲"。
4. **"狐假虎威"与"众鬼不畏"是同一逻辑的AB面**：一个有靠山（依赖他神制敌）、一个有本钱（自身有制化）。**共同心法：永远寻找"第三股力量"。**
5. **"脱上逢脱"的现代转译**（这是网络教程里最被低估的一条）：古本断"尽被脱耗"，现代占断中**不应只断失窃**，**更多时候应类比为大额消费、被平台抽佣、投资回报被层层剥皮**。→ 判断"这事会不会白花钱"，先看有没有脱上脱结构。

### 3_3 模块 C｜进退取舍：人生决策的核心算法

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 避难逃生须弃旧 | 三传皆无益（空/鬼/脱），**唯干上逢吉**→弃三传、守干上 |
| 朽木难雕别作为 | 斫轮课中卯逢空=朽木，**宜改科易业、别作营生** |
| 进茹空亡宜退步 | 进连茹三传皆空→**退守**，看支干上能否依托 |
| 踏脚空亡进用宜 | 退连茹三传皆空→**既退遇空，宜进不宜退** |
| 有始无终难变易 | 初传长生、末传墓=开头好结局坏；反之为"先难后易" |
| 苦去甘来乐里悲 | 末传子孙克初传之鬼=**先苦后甘**；干支见鬼、传见子孙=先乐后悲 |

**落地要点**

+ **"避难逃生"和"进茹/踏脚空亡"构成一套完整的"进退决策表"**：

| 局面 | 判断 | 动作 |
| --- | --- | --- |
| 三传皆凶，干上有吉 | 避难逃生 | **弃旧守干** |
| 进连茹，三传皆空 | 往前是空 | **宜退步** |
| 退连茹，三传皆空 | 后退是空 | **宜进用** |

⚠️ **关键辨析**：进茹空亡 = 向前三步都空 → 退；踏脚空亡 = 向后退步都空 → 进。**方向相反，极易搞混**。记忆锚点：_"脚下踩的都空了，只能往前走"_。

+ **"有始无终 / 苦去甘来"——末传定吉凶。** 这是把三传当时间轴最典型的用法。→ **实操：任何占断，末传是最终落点，初传是表面开局。** "别被好的开局迷惑"（初吉末凶）和"熬过开头就好"（初凶末吉）都是这条的推论。
+ **"乐里悲 / 苦去甘来"的判定关键在于"子孙爻"**：末传子孙能克初传之鬼 → 转危为安。**找"救神"是毕法赋的通用动作**，不只在这条。

### 3_4 模块 D｜人我关系：干支、交车、贵人系统

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 交车相合交关利 | 第一课与第三课交叉看生克刑害（长生/财/脱/害/空/刑/克/冲/合，共十等） |
| 上下皆合两心齐 | 干上神作六合、地盘干支亦作六合→双方同心 |
| 彼求我事支传干 | 初传起支、末归干=**别人来求我**，吉凶皆成 |
| 我求彼事干传支 | 初传起干、末归支=**我求人**，俯仰由人、受抑勒 |
| 眷属丰盈居狭宅 | 三传生干、反脱支=人旺宅窄，**切忌迁居** |
| 屋宅宽广致人衰 | 三传脱干、反生支=宅广人稀→**速宜迁居** |
| 三传递生人举荐 | 三传层层生日干=有人上位举荐 |
| 三传互克众人欺 | 三传层层克=被人围攻欺凌 |

**落地要点**

+ **"支传干 vs 干传支"是判断"谁主动"的唯一标准**：方向决定主动权。⚠️ **这条在合作、谈判、求职里极其好用**——"我求彼"格局下，正确策略是降低预期、准备被压价；"彼求我"格局下，可以守住条件。
+ **"眷属丰盈 / 屋宅宽广"是一对反向居住口诀**：人旺宅小=别搬家（造化使然）；宅大人少=赶紧搬。**核心原理：系统平衡，强行打破反而招灾。** 现代转译：买房不要"一步到位买太大"，人多住大房、人少住小房才是吉配。
+ **"三传递生 vs 互克"——人际生态诊断**：递生=有人一路举荐（贵人链），互克=被人多方围攻。**实操：判断要不要做某件事，先看三传是递生还是互克，比看单神吉凶可靠得多。**

### 3_5 模块 E｜神将灾祥：天将如何改变定性

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 魁度天门关隔定 | 戌（河魁）加亥（天门）=关隔，诸事不通 |
| 罡塞鬼户任谋为 | 辰（天罡）加寅（鬼户）=闭塞鬼门，**诸谋可成** |
| 两蛇夹墓凶难免 | 两螣蛇夹墓神=凶险难避 |
| 虎视逢虎力难施 | 白虎重重=力量难施 |
| 太阳照武宜擒贼 | 太阳临玄武=**贼可擒、失物可获**（现代：追讨、维权有利） |
| 后合占婚岂用媒 | 天后+六合=婚姻**不用媒妁自合**（现代：闪婚、自由恋爱成） |
| 干乘墓虎无占病 | 干上墓+白虎=占病大凶 |
| 支乘墓虎有伏尸 | 支上墓+白虎=宅有伏尸（房屋阴气、旧疾） |
| 受虎克神为病症 | 被白虎所克之神=病位 |
| 制鬼之位乃良医 | **能制鬼之处=治病之方**（以克论治） |
| 虎乘遁鬼殃非浅 | 白虎乘遁干鬼=灾殃深重 |
| 鬼临三四讼灾随 | 日鬼临三、四课=**讼病随来** |

**落地要点**

+ **贵人系统是一组"求人"的细分法则**（帘幕、催官、昼夜贵、贵人差迭、两贵受克、二贵皆空）：核心就一句——**贵人多了反而坏事，一处到位即可**。⚠️ "课传俱贵转无依""昼夜贵加求两贵""贵人差迭事参差"都在说同一件事：**多头求助=无人真帮**。→ 实操：求贵人，**锁定一位，别广撒网**。
+ **"制鬼之位乃良医"——这是全书最具实操价值的一句，也是"易学治病思路"的精髓**：哪里能克制那个"鬼（致病之因）"，哪里就是解药/治方。占病、占危机、占困境都通用。**找"制"就是找"解决方案"**。
+ **"虎乘遁鬼殃非浅"** 与 **"鬼临三四讼灾随"** 是疾病/官司的**双红线**：看到白虎+遁鬼、日鬼临三四课，立刻升级为"高危"，不可轻断。

### 3_6 模块 F｜空亡与终局：真假、迟速、边界

**原文重点**

| 口诀 | 法理本质 |
| --- | --- |
| 喜惧空亡乃妙机 | **吉神空=虚喜，凶神空=免祸**——空亡是双向的，这是"妙机" |
| 旬内空亡逐类推 | 空亡按旬（类神）逐条类推 |
| 三六合万事喜忻 | 三合、六合=和合，凡事喜悦 |
| 合中犯杀蜜中砒 | 合中带克=**蜜里藏砒，表面好内里毒** |
| 初遭夹克不由己 | 初传被上下夹克=身不由己，受制于人 |
| 任信丁马须言动 | 值丁、驿马=**必有动向**（丁主变动，马主行程） |
| 来去俱空岂动宜 | 来去皆空=**不宜动**（与"丁马言动"相反相成） |
| 非占现类勿言之 | **没问到的类神别乱断**（占病不说财，占婚不说官） |
| 常问不应逢吉象 | 无事来占却逢吉象=**反常，必有隐情** |
| 已灾凶逃返无疑 | 已遭灾逢凶=**逃不掉的确认**（应期已定） |

**落地要点**

+ ⚠️ **"喜惧空亡"是理解全书的一半钥匙**：初学者一见"空亡"就当凶，大错。**空亡的本质是"气不至、事不实"——它让凶事落空，也让吉事落空。** 所以：**凶神空亡 = 转危为安（好事）；吉神空亡 = 虚喜一场（坏事）。** 看到任何凶格，第一步永远是"查空亡"。
+ **"丁马"与"来去俱空"构成"动 vs 静"的决策对**：有丁、有驿马 → 必动（出差、搬家、变动）；来去皆空 → 不动。**矛盾时怎么办？看哪个力量更旺、是否空亡。**
+ **"非占现类勿言之" + "常问不应逢吉象" = 占断的职业伦理与边界**：

→ 这两条合起来，就是"**守住边界，警惕反常**"，放到任何咨询场景都适用。

    - 前者：对方没问的类，**不要擅自发挥**（避免"什么都断一点"的江湖病）；
    - 后者：**无事来占却得吉象，往往是"事在隐瞒"的信号**，要反问对方真正想问什么。

## 板块4 · 把《毕法赋》还原成一套"判断流程"（可直接照做）

网络教程里最被忽略的，是**赋文之间不是并列关系，而是有先后次序的**。结合《六壬大全》《断案》的断课范式，可以整理出一条**固定检查清单**——按顺序走，覆盖70%以上的常见占断：

```plain
第1步：定局势基调（模块A）
  → 先看 引从/首尾/六阳六阴/旺禄临身
  → 问：这事整体是吉调还是凶调？宜动还是宜静？

第2步：查四课内外（模块D的干支部分）
  → 干上神生克干？支上神生克支？
  → 问：外部有没有助力？内部有没有隐患？

第3步：走三传时间轴（模块B/C）
  → 初→中→末，是向好还是向坏？
  → 问：有没有"有始无终/苦去甘来"？末传是归宿。

第4步：找制化与空亡（模块B/F的关键动作）★★★最核心
  → 凶神有没有被制？（制鬼之位乃良医）
  → 凶神是不是空亡？（喜惧空亡乃妙机）
  → 吉神是不是空亡？（虚喜一场）

第5步：看天将发力（模块E）
  → 贵人/白虎/螣蛇/玄武在哪儿？发用还是临干？
  → 问：贵人一处到位？还是贵人差迭？

第6步：定应期与边界（模块F）
  → 丁马→动，来去空→静
  → 鬼临三四→速，鬼当时无畏忌→待时令
  → 非占现类勿言之

```

**这套流程的价值**：它把"背100句"变成了"走6步"。实战中，往往走完前4步就已经能定七八成吉凶，**完全不需要逐条套用全部口诀**。

## 板块5 · 网络教程拓展：几条"书里不会明说"的干货

以下来自当代壬学实战者的经验总结与课例辨析，属于"读活"的部分：

**1. 批判性继承：不能直接搬的口诀**

+ "**帘幕贵人高甲第**"：现代考试占，**应以朱雀为主要类神**，参考父母爻 + 帘幕贵人，单看贵人不够。
+ "**人宅受脱俱招盗**"：不应只断"失窃"，**更多类推为买房、大额消费、被大额抽佣等破耗之事**。
+ "**后合占婚岂用媒**"：现代可对应**闪婚、自由恋爱、网恋成婚**，不必拘泥"媒妁"。

**2. 课体通象，不宜死拘**

+ 看到"登三天"（三传寅巳申之类）**多不吉**这类格局口诀，要结合**所占事类**灵活断。同一格局，问升官能断吉，问疾病可能断凶。
+ **"观大象不拘小节"**：把握课象总体吉凶后，不必过度纠缠单神单煞的细枝末节。**方向 > 细节。**

**3. 类神优先原则（"妄用三传灾福异"的引申）**

+ 三传是框架，但**真正定吉凶要看"类神"**。⚠️ "初遭夹克不由己"一见"夹克"就断凶是读浅了——**要看被克的是谁（财？身？鬼？亲？），性质不同吉凶迥异**。受克者为财=破财可控；受克者为日鬼=反而是制凶。

**4. 现代占断的常见误区清单**

+ ❌ 把"阴"一律当凶、"阳"一律当吉 → 应是**场域匹配**。
+ ❌ 把"空亡"一律当凶 → 应是**凶空则吉、吉空则虚**。
+ ❌ 见贵人就断"有人帮" → **课传俱贵反无依，多头求助无人帮**。
+ ❌ 忽略占事类别套用断语 → **必须结合现代情境变通（婚恋、财产、职场均比古人复杂）**。

**5. 一个完整课例体会"法理"（庚寅日占宅，邵彦和《断案》原案）**
张九翁占宅，戊申年九月庚寅日辰将未时。干支皆受上神来生（表面吉），但末传亥**脱今日之干、生今日之支**——生宅脱我=**先兴旺后衰败**。再加亥数四、寅数七→应期十一年。
→ 要点：**"干支俱受生而互受脱"这个结构，就是"乐里悲"的住宅版**。学赋文一定要回到这种"结构识别"，而不是背断语。

## 板块6 · 核心心法提炼：七句话带走

1. **四课看结构，三传看时间，神将看发力点。**
2. **末传定归宿**——开局吉不算吉，结局吉才算。
3. **凶神先看制，再看空**——有制则化，有空则消。
4. **空亡是双向的**：凶空则免，吉空则虚。
5. **制鬼之位，即是良医**——解药的方位 = 克病因的方位。
6. **贵在一处，不在多处**——多头求人 = 无人真帮。
7. **观大象不拘小节，非占现类勿言之**——方向对，边界清。

## 板块7 · 学习方法与进度建议

| 阶段 | 时间 | 任务 | 检验标准 |
| --- | --- | --- | --- |
| **一、通读** | 1周 | 读原文+注释，不求甚解，只求成诵 | 100句能背 |

**几条硬建议：**

+ **每学一句，必须回到至少一个真实课例**，否则只是背了一句话。
+ **现代应用务必"去伪存真"**：理解法理，按所占事类和时代背景**灵活取象**，绝不生搬硬套。
