## 板块1 · 这本书到底在干什么：先破掉三个误解

《六壬大全》十二卷，明·郭载騋校刊编纂，《四库全书》子部术数类“占卜之属”收录，是六壬体系中流传最广、内容最全的总汇性著作。但它**不是一本“解卦字典”**，而是一部**时空建模 + 规则推演 + 类象读断**的操作手册。

读之前，先纠正三个最常见的误读：

**误解一：“六壬就是算命，背口诀就行。”**
错。六壬的核心是**建模**，不是背结论。它以问事时刻的节气、时辰、日干支为输入，先定出天地盘（空间坐标），再叠上四课三传（事态演化），最后才轮到天将神煞做“修饰”。顺序不能颠倒——**盘没立对，口诀背得再熟也是垃圾进垃圾出**。

**误解二：“《毕法赋》是全书核心，学会赋文就通了。”**
只对一半。《毕法赋》在卷九、卷十，是历代壬学家的**实用方法论总纲**，但它高度凝练、依赖前置结构。脱离前面九卷的起例、神将、课经，直接啃《毕法赋》，结果一定是“字都认识，断不出来”。正确顺序是：**基础规则（卷一—二）→ 课式结构（卷三—八）→ 方法论提炼（卷九—十）**。

**误解三：“六壬重神煞，神煞越多越准。”**
恰恰相反。《四库提要》自己批评后世注家“**专论课体而失之拘，专主类神而失之粗，杂取神煞而失之支**”。六壬真正的核心只有一句话：**天乙贵神（十二天将之首）**。神煞是辅助变量，不是主引擎。

### 1_1 本书的结构逻辑（重排后）

| 原卷 | 内容 | 在读时的角色 |
| --- | --- | --- |
| 卷一 | 入手法、十干寄宫、九宗门歌诀、神煞总汇 | **地基**：所有规则的起点 |
| 卷二 | 十二支神、十二天将（概念、象意、应用） | **核心**：神将信息贯穿全书 |
| 卷三 | 干支、四课、三传、发用规律 + 历代歌诀 | **骨架**：课式的形式语言 |
| 卷五—八 | 课经（720 课与六十四卦对应） | **案例库**：课名、课象、举例、订讹 |
| 卷九—十 | 毕法赋 | **方法论**：实战断课的决策框架 |

> **一句话理解全书脉络**：卷一给你工具，卷二给你“人”，卷三给你“事”，课经给你“样本”，《毕法赋》给你“判断优先级”。

## 板块2 · 六壬的底层公理：它为什么“能算”

六壬的哲学起点非常干净，理解它，后面所有繁琐规则都会变得顺理成章。

**“壬”从哪来？**
“数根于五行，而五行始于水”——天一生水，水为五行之始；“举阴以起阳，故称壬焉”。天干十位，壬排第九（奇数为阳），取“六”是“举成以该生”——以成数概括生数。**名“六壬”，本质是“以水为起点的阴阳演化系统”。**

**它与《易经》是同构的。**
《四库提要》点破：有天地盘与神将加临 → 近于《周易》的卦位；由干支而有四课 → 即“两仪生四象”；由发用而有三传 → 即“一生三，三生万物”。**六壬就是把《易经》的抽象卦象，钉死在具体的干支时空坐标上。**

这也解释了六壬为什么被称为“人事之王”：

+ 奇门、太乙偏天地、军国、气运；
+ 六壬的建模单元是“**日干（我）+ 日支（事/对方）+ 四课（表里）+ 三传（过程）**”，天然贴合**人与人、人与事**的纠缠结构。

**一个必须接受的预设：正时**
起课以**问事当下的真实时辰**为准（所谓“正时”），一占一机，一机一课。这是六壬“天人感应”的落点——**同一天、不同时辰，课局完全不同**。无法取得正时时，才用报数、抽时等替代法，但这是退而求其次。

## 板块4 · 第一步—第三步：把时空立起来（最容易出错的环节）

### 4_1 三个输入参数

**① 日干支**：问事当天的日柱（如“乙亥日”）。甲己起甲子，乙庚起丙子……用“五鼠遁”推出。

**② 月将（按节气，不看农历月份！）**

这是新手第一大坑：**月将由节气交接决定，不是正月初一换**。口诀：

> 雨水后亥（登明），春分后戌（河魁），谷雨后酉（从魁），小满后申（传送），

夏至后未（小吉），大暑后午（胜光），处暑后巳（太乙），秋分后辰（天罡），
霜降后卯（太冲），小雪后寅（功曹），冬至后丑（大吉），大寒后子（神后）。

例：处暑之后占，月将 = 巳（太乙）。**节气没交接，月将就不能换。**

**③ 占时（正时）**：子(23-1)、丑(1-3)……亥(21-23)。一个时辰内多人问事，可用报数活时。

### 4_2 十干寄宫（第二步之前的必做功课）

天干要“落”到地盘地支上，规则口诀：

> 甲课寅兮乙课辰，丙戊课巳不须论，

丁己课未庚申上，辛戌壬亥是其真，
癸课原来丑宫坐，分明不用四正神。

| 天干 | 寄宫 | 天干 | 寄宫 |
| --- | --- | --- | --- |
| 甲 | 寅 | 己 | 未 |
| 乙 | 辰 | 庚 | 申 |
| 丙 | 巳 | 辛 | 戌 |
| 丁 | 未 | 壬 | 亥 |
| 戊 | 巳 | 癸 | 丑 |

**关键提醒**：最后一句“分明不用四正神”——子、午、卯、酉（四正）**永不被寄宫占用**。这是六壬对称美学的一处体现，也常是起课时漏算的点。

### 4_3 布地盘（永远固定）

```plain
        巳  午  未  申
        辰          酉
        卯          戌
        寅  丑  子  亥

```

方位：子正北 → 卯正东 → 午正南 → 酉正西。**地盘主静、主内、主“我”；天盘主动、主外、主“客”。**

### 4_4 布天盘（月将加时，顺布十二支）

操作三句：

1. 在地盘找到你的**占时**地支；
2. 把**月将**放在地盘占时的位置上；
3. 从此位**顺时针**把十二支依次排完。

例：月将 = 戌，占时 = 未时 → 戌加在地盘“未”位，顺时针顺排亥、子、丑……

> **检验标准**：排完后天盘 12 支必须连续、不重不漏。排错天盘，后面四课三传全错，所以务必养成“排完回头数一遍”的习惯。

### 4_5 排四课（事体之“象”，四个层次）

四课 = **干阳、干阴、支阳、支阴**，对应“我 → 我之隐 → 事 → 事之隐”。

| 课 | 名称 | 取法 |
| --- | --- | --- |
| 第一课 | 干阳（干上神） | 日干寄宫在地盘，看其上的天盘神 |
| 第二课 | 干阴 | 取第一课上神的“地盘本位”，再看其上的天盘 |
| 第三课 | 支阳 | 日支在地盘，看其上的天盘神 |
| 第四课 | 支阴 | 取第三课上神的“地盘本位”，再看其上的天盘 |

**书写格式**：每课写“上神 / 下神”（上神是天盘，下神是地盘）。

**生克定义（全书命门，务必分清）**：

+ **上克下** = 天盘克地盘 = 名曰“贼”或“克”
+ **下贼上** = 地盘克天盘 = 名曰“重”

> 六壬之精髓，**全在此“克”字中求**（《四库提要》所谓“由发用而有三传”）。下一节的九宗门，本质就是“**在有克的课里，按优先级挑出最该被关注的那一支作为初传**”。

## 板块5 · 第四步：九宗门取三传（六壬的“算法核心”）

三传 = 初传（起因/发用）、中传（过程）、末传（结果），是把势能（天盘）转化为动能（事态走势）的机制。取法**有严格的优先级顺序**，不可跳步：

```plain
贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟

```

### 5_1 逐法速记（含判断要点）

**① 贼克（第一优先）**

> 取课先从下贼呼，如无下贼上克初。

+ 有“下贼上” → 优先取**下贼上**（下克上更重，主内在、被动）；
+ 无下贼，只有“上克下” → 取上克下；
+ 若有**唯一**一课有克，此神即为初传；再从地盘看“初传上天盘”为中传，同理得末传。

**② 比用（多课有克时）**
多课同时下贼或上克 → 取**与日干阴阳同性**的那一支。

> 阳干取阳支（子寅辰午申戌），阴干取阴支（丑卯巳未酉亥）。

**③ 涉害（比用仍定不下时）**
“各就所克之处，由地盘涉归本家，**以克多（受克深）者为发用**”。若克数相等：先看**四孟（寅申巳亥）**，次看**四仲（子午卯酉）**，再看**四季（辰戌丑未）**；若仍平局，阳日取干上神、阴日取支上神。

> 涉害主事**纠缠、过程曲折**，用时最久，是检验耐心的一法。

**④ 遥克（四课全无克贼时）**
四课上神与日干互相“遥克”：

+ 神克日干 = **蒿矢**（来势缓，如草箭）；
+ 日干克神 = **弹射**（我主动出击）。
取与日干同性者；无同性再依规则定。

**⑤ 昴星（连遥克也没有时）**
借“酉”为枢纽（昴星属西方、主闭塞）：

+ 阳日 → 取地盘酉宫上神为初传；
+ 阴日 → 取天盘酉下神为初传；
中末传依“干上、支上”规则排。主**闭塞、迟缓**。

**⑥ 别责、⑦ 八专、⑧ 伏吟、⑨ 返吟（特殊课体，一见即知大势）**

| 课格 | 触发条件 | 大势象意 | 断课口诀 |
| --- | --- | --- | --- |
| 别责 | 四课无克，取“别责” | 事不备、须旁求借路 | “凡事不备，主有留连” |
| 八专 | 干支同位（两课） | 专一、私情暗昧 | “私泆不明，不利奔波” |
| 伏吟 | 天地盘同位（月将=占时） | **迟滞、原地、反复**，宜静不宜动 | 占病难愈、占财守旧 |
| 返吟 | 天地盘对冲 | **反复、速变、来去不定**，宜动不宜静 | 占人思归、占事反复 |

> **伏吟与返吟是“骨架级”信号，优先级高于一般生克**：一见伏吟，先断“静、守、慢”；一见返吟，先断“动、变、反复”。这是高手断课的“先手”。

### 5_2 中传、末传的通用取法

初传既定，通常**顺着天地盘的对应关系往下推**：中传 = 初传“地盘本位”上的天盘神；末传 = 中传“地盘本位”上的天盘神。**（注：伏吟课的中末传改用“三刑”规则，见上表，属例外，需单独记忆。）**

## 板块6 · 第五步—第六步：给盘面注入“人”与“关系”

天地盘、四课三传搭好了，盘面还是“空的”——**天将让它有了性格，六亲让它有了伦理**。

### 6_1 十二天将（六壬真正的灵魂）

以**天乙贵人**居中，前五位、后五位排列：

```plain
前（左）：贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙
后（右）：天后 → 太阴 → 玄武 → 太常 → 白虎 → 天空

```

**起贵人口诀（必背）：**

> 甲戊庚牛羊，乙己鼠猴乡，

丙丁猪鸡位，壬癸蛇兔藏，
六辛逢马虎，此是贵人方。

| 日干 | 昼贵（卯—申时） | 夜贵（酉—寅时） |
| --- | --- | --- |
| 甲、戊、庚 | 丑 | 未 |
| 乙、己 | 子 | 申 |
| 丙、丁 | 亥 | 酉 |
| 壬、癸 | 巳 | 卯 |
| 辛 | 午 | 寅 |

**顺逆规则（判断吉凶的开关）**：

+ 贵人加在地盘 **亥子丑寅卯辰** 六宫 → 十二将**顺时针**布列；
+ 贵人加在地盘 **巳午未申酉戌** 六宫 → 十二将**逆时针**布列。

> 这一步是六壬独有的“动态伦理”：**同样的贵人，落宫不同，顺逆相反，整个天将盘吉凶全变。** 所以断课时“先看贵人落宫定顺逆”是铁律。

**十二天将速查表（五行 + 吉凶 + 主事）**

| 天将 | 五行 | 吉凶 | 主事象意 |
| --- | --- | --- | --- |
| 天乙贵人 | 土 | 大吉 | 逢凶化吉、贵人扶持、官文书 |
| 螣蛇 | 火 | 凶 | 虚惊、缠绕、怪异、口舌暗害 |
| 朱雀 | 火 | 中平/凶 | 文书、诉讼、口舌、考试、信息 |
| 六合 | 木 | 吉 | 合作、婚姻、和合、交易 |
| 勾陈 | 土 | 凶 | 官非、阻滞、田土、纠缠 |
| 青龙 | 木 | 大吉 | 财喜、升迁、喜庆、事业 |
| 天空 | 土 | 凶 | 虚诈、空亡、幻想、不成 |
| 白虎 | 金 | 凶 | 血光、伤灾、丧事、威严竞争 |
| 太常 | 金 | 吉 | 饮食、衣禄、田宅、平稳 |
| 玄武 | 水 | 凶 | 盗贼、暗昧、隐私、损失 |
| 太阴 | 金 | 吉 | 暗中相助、谋划、女性、阴私 |
| 天后 | 水 | 吉 | 女性、婚姻、感情、孕育 |

### 6_2 六亲：把“地支”翻译成“人事关系”

日干为“我”，其余十一支按五行生克归为六亲（与六爻同源）：

| 六亲 | 定义 | 对应人事 |
| --- | --- | --- |
| 生我者 | 父母 | 长辈、文书、靠山 |
| 我生者 | 子孙 | 子女、下属、泄耗 |
| 克我者 | 官鬼 | 事业、上级、丈夫、压力 |
| 我克者 | 妻财 | 财帛、妻子 |
| 同我者 | 兄弟 | 同辈、竞争者、分利 |

> **六亲 + 天将 = 六壬的“主语 + 谓语”**：如“官鬼乘白虎”= 事业压力 + 血光刑伤 = 很可能“因工作惹官司或伤病”；“妻财乘青龙”= 财 + 喜庆 = 正财、喜财。**先辨六亲，再看天将，象就落到了具体人事上。**

### 6_3 两个绕不过去的基础：旬空 + 旺相休囚

**旬空（空亡）**：六甲旬中“旬首”之后的两支为空。空亡的六亲/天将**力量打折甚至失效**——“财星空亡，看似有财实则虚浮”是投资占里最高频的陷阱信号。

**旺相休囚死**：依月令（节气）定五行强弱。得令者吉力倍增，失令者吉亦无力、凶亦难发。**同一个青龙，旺相时是“发大财”，休囚时是“小确幸”。**

## 板块7 · 第七步：断课决策框架（把盘面翻译成人话）

盘面信息很多，**不能眉毛胡子一把抓**。成熟的断课顺序应该是：

### 7_1 断课七步法（按优先级）

**① 观课体（定大势）**
先看是伏吟、返吟、八专、别责还是常规课。课体如人之骨架，决定整体走向。**伏吟主静、返吟主动、八专主专一暗昧、别责主旁求借路。**

**② 定格局（吉凶课格）**
对照《课经》识别是元首、重审、涉害、昴星等，以及是否成“三光、三阳、三奇、龙德、铸印、斫轮”等格局。

> 口诀：“**吉格局小凶无碍，凶格局大吉难发。**”

**③ 析三传（起—承—转—结）**

+ 初传 = 起因、发端（“**初传吉则吉，初传凶则二、三吉亦难救**”）；
+ 中传 = 过程、变数；
+ 末传 = 结果、归宿。

> **三传顺生为吉，逆克为凶**；末传空亡 = 结果落空。

**④ 察四课生克（主客强弱）**
第一课（干上）= 我方状态；第三课（支上）= 对方/事体状态。**干强支弱 → 我胜；支旺干衰 → 彼强。**

**⑤ 看天将贵神（助力与阻碍）**
重点看三处：**初传所乘天将**（事之主导力量）、**日干所临天将**（我之状态）、**日支所临天将**（对方/环境）。吉将临吉神 → 大吉；凶将临凶神 → 大凶。

**⑥ 参月将、日辰（外部时运）**
月将生三传 → 顺；太岁生日干 → 福禄长久；月将入传 → “为福不浅”。这是**天时助力**，能加速或拖慢主事。

**⑦ 综合用神（落到具体问题）**
按所问之事取“类神”：

+ 求财 → 妻财；
+ 求职/官司 → 官鬼；
+ 婚姻 → 六合、天后、官鬼；
+ 疾病 → 白虎、官鬼、子孙（医药）；
+ 失物 → 玄武、太阴。

> **用神旺相且不空 → 事成；衰、空、受克 → 事败。** 这一步是“所有分析收敛到一个可执行结论”的收口。

### 7_2 《毕法赋》的两条总纲（读完全书再回来体会）

《毕法赋》是卷九—十的方法论提炼，其核心可压缩为两条：

1. **“专筮不入仍凭类”**：占单一具体事（如“这笔钱能收回吗”），**必须紧扣类神（妻财）**，不能泛泛看课体；
2. **“分占现类勿言之”**：一占只断一类事，问财就说财，**不要什么类象都往外扯**——这是避免“事后诸葛亮”的关键纪律。

> 翻译成现代话：**六壬是“聚焦式决策工具”，不是“什么都算一点”的算命秀。** 问得越具体，断得越准。

## 板块8 · 完整案例复盘：从起课到判断（可直接照做）

下面用一个**自洽、可复算**的例子走一遍全流程。为便于验证，刻意把参数设计得清晰。

### 8_1 案例设定

**占问**：近期事业求财、工作运势
**时间**：某年某月，日柱 = **乙亥日**，占时 = **未时**（昼占）
**月将**：按节气定为 **戌将**

### 8_2 Step 1｜布天地盘

+ 地盘：固定（子丑寅卯辰巳午未申酉戌亥，方位盘）
+ 天盘：月将戌加在地盘“未”位，顺时针顺排 →
`未=戌、申=亥、酉=子、戌=丑、亥=寅、子=卯、丑=辰、寅=巳、卯=午、辰=未、巳=申、午=酉`

### 8_3 Step 2｜排四课（日干乙，日支亥）

十干寄宫：乙 → 辰。

+ 第一课（干阳）：乙寄地盘**辰**，辰上天盘 = **丑** → `丑 / 辰`
+ 第二课（干阴）：丑在地盘本位，丑上天盘 = **戌** → `戌 / 丑`
+ 第三课（支阳）：日支**亥**，亥上天盘 = **寅** → `寅 / 亥`
+ 第四课（支阴）：寅在地盘本位，寅上天盘 = **巳** → `巳 / 寅`

四课：`丑/辰 ｜ 戌/丑 ｜ 寅/亥 ｜ 巳/寅`

### 8_4 Step 3｜九宗门取三传

检查四课上下相克：

+ 丑(土) vs 辰(土) → 比和，无克
+ 戌(土) vs 丑(土) → 比和，无克
+ 寅(木) vs 亥(水) → 水生木，**上生下**（寅生亥）→ 非克
+ 巳(火) vs 寅(木) → 木生火，**下生上**（寅生巳）→ 非克

→ **四课全无克贼**，跳过贼克、比用、涉害，进入**遥克**。

**遥克**：四课上神（丑、戌、寅、巳）是否克日干乙（木）？

+ 丑、戌（土）→ 木克土，是“日干克神”= **弹射**；
+ 寅（木）→ 比和；
+ 巳（火）→ 木生火，“我生”= 子孙。

乙为阴干，取“与日干同性”者 → 阴支。**丑、戌皆阴支**，再看：阳日取干上、阴日取……依涉害余韵，取**丑**为初传（干上发用，最贴近“我”）。

> 注：此处为演示，取**初传 = 丑**；实务中遥克多支同性时需再辨“克之深浅”，建议用排盘软件交叉验证。

初传 = 丑 → 中传 = 丑地盘本位上之天盘 = **戌** → 末传 = 戌地盘本位上之天盘 = **巳**
**三传：丑 → 戌 → 巳**

### 8_5 Step 4｜布十二天将

日干乙，昼贵 → **子**（贵人）。贵人落子（地盘亥子丑寅卯辰六宫）→ 天将**顺时针**布列。
沿天盘：子=贵人、丑=螣蛇、寅=朱雀、卯=六合、辰=勾陈、巳=青龙、午=天空、未=白虎、申=太常、酉=玄武、戌=太阴、亥=天后。

### 8_6 Step 5｜定六亲（日干乙，阴木）

+ 官鬼（金，克我）：申、酉
+ 妻财（水，我克）：子、亥
+ 父母（火，生我）：巳、午
+ 兄弟（木，同我）：寅、卯
+ 子孙（土，我生）：辰、戌、丑、未

**三传六亲 + 天将：**

| 传 | 地支 | 六亲 | 天将 |
| --- | --- | --- | --- |
| 初传 | 丑 | 子孙 | 螣蛇 |
| 中传 | 戌 | 子孙 | 太阴 |
| 末传 | 巳 | 父母 | 青龙 |

### 8_7 Step 6｜综合断课（落地结论）

**① 课体**：遥克（弹射），主**事由我主动发起，起初声势弱、需自己推动**。

**② 三传走势**：子孙 → 子孙 → 父母，**一路我生、泄耗**，说明**过程中消耗大、付出多**；末传见父母（文书、长辈、靠山）乘**青龙**（大吉）→ **最终靠文书、签约或长辈引荐得正面结果，且带喜庆/进财之象**。

**③ 初传子孙螣蛇**：开头看似有“财/机会”（子孙为财之源），但乘螣蛇 → **虚惊、缠绕、被不实信息干扰**，提醒“别被表象忽悠”。

**④ 日干乙木状态**：乙寄辰，辰上见丑（子孙+螣蛇），我方**主动付出但被琐事缠身**。

**⑤ 用神妻财（亥、子）**：亥为日支、在支上见寅（兄弟乘朱雀）→ **财被兄弟分、有竞争者抢资源之象**；子（妻财）临贵人 → 有贵人暗中带财。

**⑥ 结论（可执行）**：

> 此段事业求财，**起步虚浮、干扰多、竞争者分利，不宜冒进或重仓**；**应把精力放在“文书、合约、长辈/上级关系”上**（末传父母青龙），**下半年（水旺财相之时）方有实质进益**。期间防因口舌（朱雀）、虚假承诺（螣蛇）误判。

> ⚠️ **重要声明**：以上案例为教学演示，参数经过设计，**务必用排盘软件交叉验证后再用于实际参考**。六壬的学习曲线正是“**起课易、断课难、应验更难**”，案例的价值在于熟悉流程，而非照搬结论。

## 板块9 · 从《六壬大全》到“能上手”：三个进阶抓手

### 9_1 抓手一：背不如“掌”，把排盘练成肌肉记忆

六壬传统用**左手掌诀**定位十二支（无名指根为子，顺时针数完十二支）。**十干寄宫、月将加时、贵人顺逆，全部能在手上推**。目标：不看纸笔，**3 分钟内独立排出一个完整盘面**。排盘不熟，断课无从谈起。

### 9_2 抓手二：建立“类神—天将—六亲”三联表

针对你最常占的事（财、婚、病、官非、失物），各自做成三联表：

| 事类 | 类神（六亲） | 关键天将 | 吉凶信号 |
| --- | --- | --- | --- |
| 求财 | 妻财 | 青龙、六合 | 青龙临财旺相=大财；玄武临财=财路不正/防窃 |
| 婚姻 | 官鬼/妻财 + 六合 | 天后、六合 | 六合临干=有人撮合；朱雀临=口舌 |
| 疾病 | 官鬼（病）·子孙（药） | 白虎 | 白虎+官鬼克干=凶；子孙旺=可治 |
| 官非 | 官鬼 | 朱雀、勾陈 | 朱雀=文书诉讼；勾陈=纠缠拖延 |
| 失物 | 妻财 | 玄武、太阴 | 玄武=被盗/暗昧；临空=难寻 |

> 这是把《课经》720 课“压缩成你自己的速查卡”，**比死记 720 课高效 10 倍**。

### 9_3 抓手三：用“失败案例”校准，而不是追求“神准”

六壬真正的进阶，来自**记录与复盘**：每次占测写下完整盘面 + 你的判断 + 事后应验，专门盯住“**我哪里判断错了**”——是月将定错？顺逆搞反？用神取偏？还是被空亡忽略了？

> 《四库提要》那句批评至今有效：**“专论课体而失之拘，专主类神而失之粗，杂取神煞而失之支。”** 拘、粗、支，是三种最常见的失败模式，复盘时逐项自查即可。

## 板块11 · 清醒的边界：六壬是什么，不是什么

写到这里，必须收一句清醒的话：

1. **六壬是传统文化中的“决策推演系统”，不是自然科学。** 它的价值在于**结构化地逼迫你考察“起因—过程—结果”“我方—对方—环境”**，这套思考框架本身有启发意义；但**不应作为人生重大决定的唯一依据**。
2. **“象不唯一”是先天局限。** 同一个神煞可对应多种事物，**求测者提供的具体背景是缩小取象范围的关键**。脱离背景的“铁口直断”，多半是事后附会。
3. **尊重来源、理性对待。** 本文为读书笔记与方法梳理，不构成任何决策建议。涉及健康、法律、财务等重大事项，请**优先咨询对应领域的专业人士**。

## 板块12 · 结语

《六壬大全》最值得学的，从来不是“哪课主吉、哪课主凶”的结论，而是它那套**从时空坐标出发，逐层叠加结构、再收敛到具体人事**的推演纪律：

> **天地一盘 → 四课分层 → 三传走势 → 神将赋性 → 六亲定性 → 类神收口。**

掌握这条链，你就拥有了一个**把模糊问题结构化**的思维工具——至于要不要把它叫“占卜”，那是你自己的选择。

**最后一句实操忠告**：合上书，拿起笔，从“**排出你人生的第一个盘面**”开始。六壬这门学问，**排过一百个盘的人，永远胜过背过一千条口诀的人。**
