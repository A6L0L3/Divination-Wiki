## 板块1 · 前言：为什么三百年来这本书始终绕不开

《大六壬指南》成书于清顺治九年（1652年），由陈公献（字良谟，扬州将门之后）、程翔云（徽州富商）、庄公远（程氏门客）数人合纂，最后由陈公献定稿。全书五卷，约七万字，收录125则占验课案，时间跨度从明万历三十五年（1607年）至清顺治八年（1651年）。

《清史稿·艺文志》著录"六壬指南五卷，程起鸾撰"。历来壬学者视之为经典——它是继宋代邵彦和《六壬断案》之后，又一部集六壬大成的巨著。

但问题的关键在于：**《指南》的原文高度凝练，陈公献断语"顾东言西、藏头露尾"，读者往往稀里糊涂似书童，作者侃侃而谈如神仙。** 自问世三百多年来，江湖褒贬不一：珍惜者捧为圭臬却吃不透，漠视者曰其无物也说不清。

这本笔记的目的，就是**把这本书"拆解—重构—内化"**，不只复述原文，而是搭建一套可复用的实操框架。

| 卷五 | 神煞指南 | 庄公远 | **神煞百科全书**——分类歌诀 | ⑤ 作为工具书随时查 |

### 2_2 五卷的内在逻辑链

```plain
卷一（心印）= 哲学基础 → 卷二（指掌）= 推演规则 → 卷三（会纂）= 分类模板
                                              ↓
                                        卷四（占验）= 实战验证
                                              ↓
                                        卷五（神煞）= 精细化工具箱

```

**核心认知：卷一与卷二是"体用关系"——心印讲理（体），指掌讲窍（用）。** 不能背了心印赋就以为懂了，它是所有技法的"原理总论"；也不能只练指掌赋的操作而不明理，否则沦为机械套用。

### 2_3 成书背景的关键信息

+ **陈公献**：广陵人，武将世家，精武技、兵法、黄老之术，潜究六壬，寒暑不辍。这解释了《指南》中大量**兵事、仕宦**占例的高水准——他用兵法思维解壬学。
+ **程翔云**：顺治庚寅年（1650年）遇陈公献，折服于其术，出资刊刻。这是典型的" practitioner + patron "模式。
+ **庄公远**：编写了第五卷神煞指南，把各种神煞分门别类，编成歌诀。

## 板块3 · 第二部分：卷一《心印赋》——壬学的"第一性原理"

### 3_1 原文精析：从宇宙观到操作链

《心印赋》开篇即确立六壬的完整推演链条：

#### 3_1_1 核心原文一：「六壬如人，先明日辰」

**解析：** "日辰"是整个体系的锚点。日干为天干，日支为地支。亥子丑应北方，寅卯辰应东方，巳午未应南方，申酉戌应西方——这就是**地盘**，固定不变。

**实操要点：**

+ 日干 = 主体（求占者、"我方"）
+ 日支 = 客体（所占之事、对方、"环境"）
+ **一切判断都从日干日支出发**，六亲、旺衰、生克全以日干为基准。

#### 3_1_2 核心原文二：「以月将加占时之上」

**解析：** 这是六壬最核心的操作——**月将加时**。月将是太阳躔度的天盘表征，按中气换将（不是农历月份！）：

| 中气 | 月将 | 名称 | 中气 | 月将 | 名称 |
| --- | --- | --- | --- | --- | --- |
| 雨水 | 亥 | 登明 | 处暑 | 巳 | 太乙 |
| 春分 | 戌 | 河魁 | 秋分 | 辰 | 天罡 |
| 谷雨 | 酉 | 从魁 | 霜降 | 卯 | 太冲 |
| 小满 | 申 | 传送 | 小雪 | 寅 | 功曹 |
| 夏至 | 未 | 小吉 | 冬至 | 丑 | 大吉 |
| 大暑 | 午 | 胜光 | 大寒 | 子 | 神后 |

**月将加时口诀：**

> 正月雨水后亥（登明），二月春分后戌（河魁），三月谷雨后酉（从魁），四月小满后申（传送），五月夏至后未（小吉），六月大暑后午（胜光），七月处暑后巳（太乙），八月秋分后辰（天罡），九月霜降后卯（太冲），十月小雪后寅（功曹），十一月冬至后丑（大吉），十二月大寒后子（神后）。

**实操步骤：**

1. 在地盘找到"占时"地支
2. 把月将放在地盘占时的位置上
3. 从此位开始，顺时针把十二地支依次排完 → **天盘完成**

#### 3_1_3 核心原文三：「视阴阳为四课之分」

**解析：** 四课是"太极生两仪，两仪生四象"的具体呈现：

| 课次 | 名称 | 取法 | 含义 |
| --- | --- | --- | --- |
| 第一课 | 干阳（阳中之阳） | 日干寄宫地盘上的天盘神 | "我"的外显状态 |
| 第二课 | 干阴（阳中之阴） | 第一课上神地盘所对应的天盘 | "我"的隐伏状态 |
| 第三课 | 支阳（阴中之阳） | 日支地盘上的天盘神 | 事/对方的外显 |
| 第四课 | 支阴（阴中之阴） | 第三课上神地盘所对应的天盘 | 事/对方的隐伏 |

**十干寄宫口诀（必背）：**

> 甲课寅兮乙课辰，丙戊课巳不须论。

丁己课未庚申上，辛戌壬亥是其真。
癸课原来丑宫坐，分明不用四正神。

即：甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。

**关键洞察：** "不用四正神"——阳干居禄神所在，阴干居禄神前一位。这不是随意规定，而是"正位不敢当"的礼制隐喻，背后是阴阳尊卑的哲学。

#### 3_1_4 核心原文四：「贼克为初用之始，相因作中末之身」

**解析：** 这是九宗门取三传的总纲。四课排好后，从中取三传（初传、中传、末传），代表事物发展的**起因→过程→结果**。

### 3_2 九宗门完整体系（卷一+卷二共同构建）

九宗门是取三传的九种规则，按优先级排列：

#### 3_2_1 第一法：贼克课（含元首、重审）

| 类型 | 条件 | 取法 |
| --- | --- | --- |
| **元首** | 四课中只有一课上克下（无下贼） | 取该上克下之神为初传 |
| **重审** | 四课中有下贼上（地盘克天盘） | 优先取"下贼上"者，有几课取几课 |

**口诀：** "取课先从下贼呼，如无下贼上克初。"

**深层含义：**

+ 元首 = "别无下克而亭亭然有首出庶物之象" → **百事宜，顺理成章**
+ 重审 = "重复审详" → **需反复斟酌，谋为不利**

#### 3_2_2 第二法：比用课（知一）

**条件：** 四课中有二三课同时克贼，无法单选。

**规则：** 取与日干**阴阳相同**者。甲丙戊庚壬为阳日，取阳支（子寅辰午申戌）；乙丁己辛癸为阴日，取阴支（丑卯巳未酉亥）。

**含义：** "知一者必二三事也" → 主**祸福成双、狐疑、近事**。

#### 3_2_3 第三法：涉害课（见机、察微）

**条件：** 比用后仍无法确定（俱比或俱不比）。

**规则：** 各就所克之处，由地盘涉归本家，以**克多者**为发用。

+ 克数相等 → 取四孟（寅申巳亥）上者 → **见机课**
+ 无四孟 → 取四仲（子午卯酉）上者 → **察微课**

**深层含义：**

+ 见机 = "有害者不可不见机，明哲保身之义" → 需**因时制宜**
+ 察微 = "见于明者不可不究其精微，履霜坚冰至之意" → 需**未萌而预计**

#### 3_2_4 第四法：遥克课（蒿矢、弹射）

**条件：** 四课全无上下克。

**规则：**

+ 神克日干 → **蒿矢**（彼伤我，力绵如蒿） → 取该神为初传
+ 日干克神 → **弹射**（我能伤彼，力薄如弹） → 取该神为初传

**含义：** 遥克主**远方之事、虚惊**，气势较弱。

#### 3_2_5 第五法：昴星课

**条件：** 四课无克、无遥克。

**规则：**

+ 阳日 → 取地盘酉宫上神为初传 → **虎视**（仰首）
+ 阴日 → 取天盘酉下神为初传 → **冬蛇**（俯首）

中末传：阳日以支上神为中传、干上神为末传；阴日反之。

**深层含义：** "杀气至酉而盛"——从至阴处讨出消息，主**闭塞、暗中窥探**之象。

#### 3_2_6 第六法：别责课

**条件：** 四课不备（只有三课，首尾相同）。

**规则：**

+ 阳日 → 取天干合位上乘之神（甲己合、乙庚合等）
+ 阴日 → 取地支三合前一位（如酉日用丑，丑日用巳）

**含义：** "如花待时" → 主**倚仗他人、借径而行、事有待时**。

#### 3_2_7 第七法：八专课

**条件：** 四课中干支同位（阴阳不分）。

**规则：** 取干上神发用。

**含义：** "士女怀春，一名不修帏箔" → 主**男女混杂、公私不分、不知对手为谁**。

#### 3_2_8 第八法：伏吟课

**条件：** 月将与占时相同，天地盘同位（子加子、午加午之类）。

**规则：**

+ 有克者照常取克
+ 无克者：阳日自干上发传，阴日自辰上发传，迤逦三刑为三传

**含义：** "伏吟任信用刑而事多反复" → 主**静守、停滞、内部事**。

#### 3_2_9 第九法：返吟课

**条件：** 天盘地盘对冲（子午卯酉互加）。

**规则：** 取课中克贼为用；无克则取支神旁射。

**含义：** 主**反复、动荡、远去事**。

### 3_3 三传的深层解读

| 传位 | 别名 | 含义 | 断法要点 |
| --- | --- | --- | --- |
| 初传 | 发用、事发端 | 事情的起因、动机 | **最重**——"克处是动机" |
| 中传 | 移易门 | 过程、转折 | 初凶中吉可转凶为吉，反之亦然 |
| 末传 | 归计门 | 结果、归宿 | 末传克初传 → 凶消；初传克末传 → 凶成 |

**三传走势判断口诀：**

> 三传递生为吉（顺风顺水），三传递克为凶（阻力重重）。

初传克末传为凶，末传克初传则灾祸自消。
三传合局（三合/六合）→ 事有定局，牵连多人。
三传入墓 → 事被埋没，宜藏不宜显。
三传逢冲 → 事有变动，宜快不宜迟。

## 板块4 · 第三部分：卷二《指掌赋》——判断的"操作心法"

### 4_1 核心原文精析

#### 4_1_1 原文：「六壬通万变之机，大为国而小为家。日辰定动静之位，日为人而辰为事。」

**解析：** 这是整个壬学判断的总纲——**日为人、辰为事**，日定动静之位。

**实操延伸：**

+ 论家国大事 → 从地盘分野处看
+ 论家宅 → 只从日支上看
+ 日上神 = 太阳（外境），日阴 = 少阳（内隐）
+ 辰上神 = 太阴（事态），辰阴 = 少阴（事之隐伏）

#### 4_1_2 原文：「生主和而克发用，义法三才。」

**解析：** "盖不杀不成其为生，而取克正所以观五行相生之妙也。"

**这是六壬最反直觉但最关键的一句话：吉凶的端倪不在生合比和处，而在相克处。**

+ 生合比和 → 吉凶不露（"和"是默认状态）
+ 相克 → 杀机一逗，事象遂见形

**实操法则：** 拿到任何一课，**第一步不是看哪里生，而是看哪里克。** 克处就是"发机"之处。

#### 4_1_3 原文：「用在日前事情已过，用居日后事起将来。」

**解析：** 应期的核心法则之一。

**以日干寄宫为基准：**

+ 发用在"日前"（寄宫之前，如甲在寅，则丑、子位）→ **事已过去**
+ 发用在"日后"（寄宫之后，如卯、辰位）→ **事在未来**
+ 发用在日辰上 → **应今时**

#### 4_1_4 原文：「吉神旺相事皆吉，凶神旺相事必凶。」

**旺相休囚死五气断：**

> 旺气求官吉，争财相气亲，

死言丧祸起，囚动见官刑，
休来忧病患，五气仔细寻。

**实操要点：** 同一吉神，旺相则大吉，休囚则无力；同一凶神，旺相则大凶，休囚则减轻。

#### 4_1_5 原文：「三传如君，四课如臣。」

**解析：** 三传是"动态发展线"，四课是"静态结构面"。判断时要**体用结合**：

+ 四课看"有什么"（结构、资源、矛盾点）
+ 三传看"怎么变"（走向、转折、结局）

#### 4_1_6 原文：「将克神为外战，灾自外来；神克将为内战，祸由内起。」

**解析：** "将" = 月将，"神" = 天将（贵神）。

+ 将克神（月将克天将）→ **外战**，灾自外来（因彼而有克）
+ 神克将（天将克月将）→ **内战**，祸由内起

**经验法则：** 内战多见，外战少验。

### 4_2 日辰交加的十六种格局（卷二核心干货）

这是《指掌赋》中最实用的"判断矩阵"，将日干与日支的生克关系分为十六种情况：

| 格局 | 条件 | 含义 | 断语要点 |
| --- | --- | --- | --- |
| **乱首** | 日临辰而受克 | 悖逆之道 | 行悖逆之事 |
| **赘婿** | 辰临日而受克 | 不能自立 | 受人制约 |
| **自在** | 辰临日而生日 | 恢宏之志 | 他来就我 |
| **俯就** | 日临辰而受生 | 荣显之机 | 我去就他 |
| **历虚** | 日临辰而生辰 | 无措之语笑 | 我去生他 = 脱气 |
| **归福** | 辰临日而受生 | 履来之崇 | 他来生我 = 福 |
| **同谐** | 同类相加 | 和合 | 比肩之妙，详禄刃之别 |
| **脱骨** | 日辰交生 | 彼我舒情 | 互相信任但有损耗 |
| **无涉** | 日辰交克 | 内外疑忌 | 互相猜忌生离 |
| **斩关** | 日辰见辰戌又发用 | 逃亡伏匿 | 阳逃亡、阴伏匿 |
| **天心** | 三传皆在年月日时 | 忧不成忧喜中加喜 | 天地大化不离 |
| **回环** | 三传不离四课 | 吉不全吉凶不全凶 | 不宜占讼散事 |

**实操记忆法：** 以上十六格可以归纳为四大类——

1. **日生辰/辰生日** → 看谁生谁（俯就 vs 归福）
2. **日克辰/辰克日** → 看谁克谁（乱首 vs 赘婿）
3. **日辰交生/交克** → 双向关系（脱骨 vs 无涉）
4. **特殊格局** → 斩关、天心、回环等

### 4_3 四上克、四下贼的极端格局

| 格局 | 条件 | 断语 |
| --- | --- | --- |
| **幼度厄** | 三上克 | "腐绳维巨室之象" → 幼者、下属有厄 |
| **长度厄** | 三下克 | "越海无舟楫之形" → 长者、上级有厄 |
| **无禄** | 四上克 | 主孤单，得救神亦能免祸 |
| **绝嗣** | 四下贼 | 主贫苦，虽吉将到底成空 |

**救神法则：** 三传、年命中有一处**生干**即为救神。

## 板块5 · 第四部分：卷三《会纂指南》——分类占的"速查手册"

### 5_1 会纂的结构

卷三以**七言歌诀**形式，涵盖以下分类（据目录）：

> 天时、阳宅、阴地、迁移、香火、婚姻、孕产、疾病、出行、行人、趋谒、选举、武事、仕宦、求财、买卖、占讼、隐遁、逃亡、贼盗、田蚕、六畜

### 5_2 实操选读：几个高频场景的判断模板

#### 5_2_1 天时占（以卷三+占验为例）

**核心口诀：**

> 天象先占大角星，指阴主雨指阳晴。

贵登绛明（亥子二宫）时雨沛，预卜阴晴此法精。
风雨之主看龙虎，风雨之期寻羊鼠。

**实操步骤：**

1. 先看**青龙**（水神）的位置和旺衰 → 龙入庙（加寅）主晴，升天（临辰巳午未）主雨
2. 看**白虎**（风神）→ 虎出山林（加寅卯）有烈风
3. 看**贵神**是否登天阙（亥）或绛宫（子）→ 贵登天阙多雨
4. 看**三传**中有无亥子壬癸等水神 → 有则雨
5. 看**神煞**：风伯（未）、雨师（丑）、风杀等
6. **衰旺空刑须细辨**：克日有气 → 滂沱大雨；无气空亡 → 微雨

**实战案例拆解（占验第一）：**

> 戊寅三月己巳日乙丑时，天气亢旱，占何日有雨。遥克、玄胎，戌亥空、未申落空。

**断曰：** "巳午之日先有狂风起，出旬甲日小雨，乙日大雨。盖斗罡加未为风伯，发用功曹劫杀克日，故主有狂风。又贵登天门，龙神飞天，皆行雨之象。因中末亥申空亡，故言出旬有验。"

**逆向学习法：** 遮盖断语，自己先分析，再对照陈公献的思路，寻找差距。

#### 5_2_2 阳宅占

**核心口诀：**

> 支来干位宅就人，干来支位人入宅。

刑冲破害生旺看，否则二者有损益。
三传脱支生日干，人多屋少从此断。
三传盗干生支辰，屋旺人衰何必算。

**实操步骤：**

1. **日支 = 宅**，看支上神旺衰 → 判断宅的吉凶状态
2. **日干 = 人**，看干上神旺衰 → 判断人的状态
3. **三传与日干日支的关系** → 判断人宅互动：
    - 三传生日克支 → 人旺宅衰，卖屋偿债
    - 三传生支克日 → 宅旺人衰，迁居或疾病
    - 三传脱支生日 → 人多屋少
    - 三传盗日生支 → 屋旺人衰

#### 5_2_3 求财占

**核心判断要素：**

1. **财爻** = 日干所克之神（我克者为财）
2. **青龙** = 财喜之将，青龙临财爻 → 大吉
3. **太常** = 饮食财帛之将
4. **子孙爻** = 生财之源（我生者），子孙旺相 → 财源不断
5. **忌**：财爻空亡、财临鬼、财被劫煞冲破

#### 5_2_4 疾病占

**核心判断要素：**

1. **白虎** = 疾病凶丧之将（最忌）
2. **腾蛇** = 惊恐、怪异
3. **鬼爻** = 克日干之神 → 病根
4. **子孙爻** = 医药（克鬼之神）
5. **天医、地医** = 月煞，主得良医
6. **生死判断口诀：**

> 要知存亡看蛇虎，阴阳二神分宾主。

阳命阴伤必死亡，阴命阳伤必哀举。
白虎天后与腾蛇，克日须当病转加。

### 5_3 会纂的学习方法

**会纂是"铁口直断"的模板库。** 最佳学习策略：

1. 把歌诀**分类整理**成表格（如"天时类""求财类""疾病类"）
2. 每条歌诀后**标注对应的占验课例编号**（如天时章对应占验第1-6例）
3. 反复背诵 + 实际起课验证

## 板块6 · 第五部分：卷四《占验指南》——125则案例的"逆向工程"

### 6_1 占验案例的标准结构

每则占例通常包含以下要素：

```plain
① 时间信息（年+月+日+时/占时）
② 背景说明（谁问什么事）

⑤ 四课三传排盘

⑦ 应验结果（事后验证）

```

### 6_2 案例逆向学习法（核心训练法）

**步骤一：遮盖断语**
读案例时，遮住"断曰"部分，自己先独立分析。

**步骤二：独立分析框架**
按以下顺序逐步推演：

1. 定日干旺衰 → 自身状态
2. 取用神（根据所问之事）→ 事情的核心符号
3. 看发用（初传）→ 事之起因
4. 顺三传 → 发展过程
5. 看末传 → 最终结局
6. 参神煞 → 补充细节
7. 综合判断 → 吉凶成败

**步骤三：对比陈公献的断语**
重点思考三个问题：

+ **他为什么首先关注这个点？**（某个神、某个煞、某个传）
+ **他是如何将心印/指掌的原理应用到具体情境的？**
+ **他的判断主次、轻重是如何权衡的？**

### 6_4 占验案例的核心洞察

**陈公献断课的四大特征：**

1. **以克为先** —— 永远先看哪里有克，克处就是发机之处
2. **以类象为骨** —— 青龙主财、白虎主病、朱雀主文书……但不会机械对应，而是**组合取象**
3. **以神煞为眼** —— "三传吉凶有狐疑，全凭煞到解心迷"——关键时刻靠神煞定乾坤
4. **以旺衰为尺** —— 同一符号，旺相则力大，休囚则力微

### 7_3 神煞的使用原则

**原则一：神煞不是根本，五行理气才是**

> "莫把神煞当根本，五行理气是真传。"

**原则二：吉凶由神（月将），克应由煞（神煞）**

+ 月将 = 定吉凶的大方向
+ 神煞 = 精确化细节、确定应期

**原则三：神煞叠加才有力量**
单一神煞力量有限，**多个神煞叠加在同一地支**时才具有决定性。例如：

+ 驿马 + 丁神 → 急速变动
+ 太岁 + 贵人 → 尊贵提拔
+ 白虎 + 劫煞 → 血光凶灾

**原则四：神煞必须结合旺衰**
神煞临旺相之地则力大，临休囚之地则力微。

## 板块8 · 第七部分：完整起课实操指南（七步法）

> 以下是根据网络教程拓展整理的**标准化起课流程**，可直接照做。

### 8_1 第一步：定基础条件（4个参数）

| 参数 | 取法 | 示例 |
| --- | --- | --- |
| 日干支 | 占问当天的干支 | 己未日 |
| 月将 | 根据当天所处中气确定 | 处暑后 → 巳（太乙） |
| 占时（正时） | 问事时辰（23-1子、1-3丑……） | 午时 |
| 十干寄宫 | 口诀确定日干寄宫 | 己寄未 |

### 8_2 第二步：布地盘（永远固定）

```plain
巳 午 未 申
辰       酉
卯       戌
寅 丑 子 亥

```

### 8_3 第三步：布天盘（月将加时）

**操作：** 把月将放在地盘"占时"的位置上，顺时针依次排完十二支。

**示例：** 月将 = 亥，占时 = 午

+ 天盘亥 → 地盘午位
+ 天盘子 → 地盘未位
+ 天盘丑 → 地盘申位
+ ……以此类推

### 8_4 第四步：排四课

```plain
第一课（干阳）：日干寄宫的地盘位 → 对应的天盘神
第二课（干阴）：第一课上神的地盘位 → 对应的天盘神
第三课（支阳）：日支的地盘位 → 对应的天盘神
第四课（支阴）：第三课上神的地盘位 → 对应的天盘神

```

**格式：** 每课写"上神/下神"，上神是天盘，下神是地盘。

### 8_5 第五步：九宗门取三传

按优先级依次尝试：

1. 贼克（元首/重审）→ 2. 比用 → 3. 涉害 → 4. 遥克 → 5. 昴星 → 6. 别责 → 7. 八专 → 8. 伏吟 → 9. 返吟

### 8_6 第六步：布天将（十二天将）

**贵人起法口诀：**

> 甲戊庚牛羊，乙己鼠猴乡，

丙丁猪鸡位，壬癸蛇兔藏，
六辛逢马虎，此是贵人方。

**昼夜贵：** 占时为卯辰巳午未申 → 昼贵；酉戌亥子丑寅 → 夜贵。

**顺逆规则：**

+ 贵人落亥子丑寅卯辰（地盘）→ **顺布**
+ 贵人落巳午未申酉戌（地盘）→ **逆布**

**十二天将固定顺序：** 贵人→螣蛇→朱雀→六合→勾陈→青龙→天空→白虎→太常→玄武→太阴→天后

### 8_7 第七步：排六亲 + 判吉凶

以日干为基准：

+ **生我者** = 父母（庇护、文书、长辈）
+ **我生者** = 子孙（福佑、子女、医药）
+ **克我者** = 官鬼（压力、疾病、上级）
+ **我克者** = 妻财（财物、妻子、收益）
+ **比和者** = 兄弟（同辈、竞争者）

### 8_8 断课标准流程（七看）

```plain
① 看课体 → 九宗门格局（大势）
② 看日干旺衰 → 自身底气
③ 取用神 → 所问之事的核心符号
④ 看三传走势 → 初→中→末（发展脉络）
⑤ 看四课生克 → 主客关系
⑥ 看天将神煞 → 细节补充
⑦ 定应期 → 出结论

```

### 8_9 应期推断法则

| 法则 | 说明 |
| --- | --- |
| 发用在日前 | 事已过去 |
| 发用在日后 | 事在未来 |
| 发用在日辰上 | 应在今时 |
| 发用为某季之神 | 应在该季（如见寅卯应在辰月辰日辰时） |
| 空亡填实 | 事应在填空之时 |
| 冲空 | 冲开空亡之时应验 |

## 板块9 · 第八部分：占断核心禁忌与心法

### 9_1 四不占

| 禁忌 | 含义 |
| --- | --- |
| **不诚不占** | 心不诚、意念不专 → 占则不准 |
| **不渎不占** | 同一事反复占 → 亵渎天机，越占越乱 |
| **不邪不占** | 违法乱纪、损人利己之事 → 不可占 |
| **不妄断** | 拿不准的事不说死，留有余地 |

### 9_2 十干寄宫深层理解

"甲课寅兮乙课辰"的背后逻辑：

+ **阳干寄禄位**：甲禄在寅、丙戊禄在巳、庚禄在申、壬禄在亥
+ **阴干寄禄前一位**：乙禄在卯→寄辰、丁己禄在午→寄未、辛禄在酉→寄戌、癸禄在子→寄丑

这是因为"正位不敢当"——阳干谦逊，阴干更是退一位。

### 9_4 高级心法：组合取象

**《指南》最精妙之处在于"组合取象"，而非单点对应。** 例如：

+ **青龙 + 太常** → 财婚之象（青龙主财 + 太常主酒食婚庆）
+ **螣蛇 + 朱雀** → 口舌是非（蛇主虚惊 + 雀主文书口舌）
+ **白虎 + 劫煞** → 血光凶灾（虎主刑伤 + 劫主劫夺）
+ **贵人 + 禄马** → 升迁之象（贵人解厄 + 禄主俸禄 + 马主动迁）

**组合取象的方法论：**

1. 先取**单神本象**（青龙 = 财）
2. 再看**天将叠加**（青龙 + 临财爻 = 财上加财）
3. 再看**地支关系**（财爻与日干是否相生、有无刑冲）
4. 最后看**神煞叠加**（财爻上见天喜 = 喜庆之财）

## 板块10 · 第九部分：拓展干货——网络教程中的实用补充

### 10_1 六壬的"三才"架构

| 层次 | 组成 | 功能 |
| --- | --- | --- |
| **天时** | 月将、节气、占时 | 确定宇宙时空坐标 |
| **地利** | 地盘、天盘、分野 | 确定空间方位 |
| **人和** | 日干、日支、年命、行年 | 确定人事主体 |

### 10_2 年命与行年的关键作用

+ **本命** = 出生年地支（固定不变）→ "命为身之应"
+ **行年** = 流年地支（逐年变换）→ "行年为用事之助"
+ **太岁** = 当年岁支 → "一岁之君，众神之主"

**核心法则：** 三传虽凶，年命上有救 → 可转祸为福。年命是课体信息的**最终落脚点**。

### 10_3 空亡的深层运用

| 类型 | 含义 | 判断要点 |
| --- | --- | --- |
| **旬空** | 地盘空亡（真正的空） | 力量七分 |
| **游行空亡** | 天盘落于空亡地 | 力量三分 |

**空亡断事法则：**

+ 吉事落空 → 不吉（好事不成）
+ 凶事落空 → 不凶（坏事消解）
+ 财爻空亡 → 求财不得
+ 病逢空亡 → 可能痊愈（凶事空则吉）

### 10_4 应期的综合判断

**多维度交叉验证法：**

1. **以发用定大方向** → 用神在日前/日后
2. **以传墓定节点** → 末传入墓之时
3. **以冲空定应期** → 冲开空亡之日
4. **以填实定时机** → 填实旬空之时
5. **以神煞定精确** → 天喜、驿马等所临之日

## 板块12 · 结语：从"术"到"道"的跨越

《大六壬指南》表面上是一部占卜手册，实质上是一套**完整的决策思维体系**：

1. **时空建模**（天地盘）→ 确定问题发生的时空坐标
2. **结构分析**（四课）→ 识别主客、显隐、内外关系
3. **动力推演**（三传）→ 追踪事物发展的起因→过程→结果
4. **符号解读**（天将、神煞）→ 精细化判断的性质与程度
5. **综合权衡**（旺衰、生克、组合）→ 得出最终决策

**陈公献在序中说："精而研之，理入牛毛，响应桴鼓。又奚必泛求诸篇，以滋惑也耶？"**

这句话的深意是：**与其泛泛而读百本书，不如精研一本经典到极致。** 一本《指南》，配上正确的学习方法，足以构建完整的壬学体系。
