## 板块1 · 导言：这是一套"知识工程"，不是神秘秘本

翻开《大六壬心镜》，最容易掉进两个坑：一是把它当"占卜速查手册"，背几句吉凶断语就想断事；二是被作者、年代的争议劝退，觉得无从下手。

这本书真正值得读的，是它把原本散乱的六壬知识，编成了**可诵、可查、可按事项检索的歌诀系统**。它的价值不在"预言多灵验"，而在于一套古人组织复杂决策信息的思维方式——用课体分类、用三传追踪过程、用天将描摹情态、用类神落到具体事项。

因此本手记不复述原文，而是按"**先辨文本层 → 再拆课式逻辑 → 最后落到可复现操作**"的顺序重构。读完后你应能：

1. 说清《心镜》成书、版本的来龙去脉；
2. 分清哪些是《心镜》独有贡献、哪些是大六壬通用理论；
3. 独立完成一次起课与断课，并保留完整推导链。

> **理性使用声明**：六壬属于中国传统术数与象数文化范畴，可作为思维训练与文化研究材料，不能预测随机事件的唯一结果，更不能替代医疗、法律、金融、安全等专业意见。本文所有占例仅为演示排盘逻辑，不作现实决策依据。

## 板块2 · 先辨文本层：今天我们读到的，是唐至清多层校辑的结果

**《心镜》不是一本可以认定"宋仁宗颁定"的单一宋刊本，而是一部层层叠加的术数文献。** 读书的第一步，就是分清"文献证据"与"后世追述"。

### 2_1 版本流传的四个节点

| 节点 | 可核验记录 | 对读者的意义 |
| --- | --- | --- |
| 宋代流传层 | 清人转录的嘉祐年间占边事、建炎年间邵彦和占病，均明确引用《心镜》歌句 | 至少证明宋人已将相关歌诀命名为《心镜》，宋际流传可证 |
| 四库著录层 | 《六壬心镜要》三卷、《后集》一卷，浙江巡抚采进本 | 确认官方目录系统，但与明清总集的"八卷"结构并存 |
| 清代校辑层 | 程树勋、郑天民等据多个写本校辑 | 解释今本为何保留原注、郇注、程按及兵占补辑痕迹 |
| 近现代刻本 | 光绪二年泰县程氏家刻本《大六壬心镜》八卷 | 公开书录较清楚的近现代刻本节点 |
| 当代整理本 | 华龄出版社《四库存目三式汇刊（五）：大六壬心镜》，2020，ISBN 9787516917305 | 适合作为入门工作本 |

### 2_2 作者与年代：两套证据，不必强行统一

《四库全书总目》题"宋徐道符"；清代校勘序文则转述《心镜》自序，称其为唐肃宗时人，号"无欲子（一说不欲子）"，东海人。网络转录又见"乾元""乾符"等年号异文，跨度百余年。

这些异文可能来自传抄、避讳或后人附加，现有材料不足以把作者、年代、序文一一对应。读书时最稳妥的表述是：

> 《心镜》托名或署名徐道符，传统归为唐代歌诀整理传统；四库题"宋"；具体生卒、成书年份均不可考。

**注意**："宋仁宗"更适合作为传播史锚点——若嘉祐年间占例确曾引用其歌句，只能证明相关歌诀在嘉祐前已存在，不能推出仁宗下令编定全书。

### 2_3 八卷结构是清代校辑的系统

现代常见的八卷、一百八十一篇结构，主要由清代校辑塑造，不宜直接当作唐代原始目录：

| 卷次 | 主要门类 | 内容特征 |
| --- | --- | --- |
| 卷一 | 释课元微门、宗首九科门、淫泆门 | 起课、发用及课体命名 |
| 卷二 | 新孕、隐匿、乖别 | 人事与隐伏之事 |
| 卷三 | 凶否、吉泰 | 凶课与吉课的象义展开 |
| 卷四 | 杂神、杂将、三宫时 | 神将、时法与基本占具 |
| 卷五 | 占宅、修造、婚姻、产育、田蚕 | 家庭、营造与农事 |
| 卷六 | 商贾、官职、亡盗、官讼 | 生计、身份、纠纷 |
| 卷七 | 疾病、行人、天时、杂课 | 个体处境与外部变化 |
| 卷八 | 兵占、渡河涉水等 | 行军、察敌及军事行动 |

这种"先课式、后门类"的编排，说明它本质是**可检索的实务系统**，而非抽象心法。

### 2_4 读这一层的关键动作

清人校记区分了"经云"原注、郇应清补注、郑天民校记、程树勋按语。研究时应分别标记为【原歌】【原注】【郇注】【程按】【清人补辑】，绝不可把清代校者的判断误认作唐人原意。

> **小结**：版本考据不是外围工作。越清楚文本层，越不需要用"神秘""必验"来补足说服力。

## 板块3 · 原文重点解析：厘清"《心镜》独有"与"壬学通用"

**《心镜》的核心贡献是"拟经作歌、排门定类"——把课式、课名、神将、事类编成相互索引的歌诀体系，而不是独占某项基本技术。**

### 3_1 歌诀化的课式组织

卷一首组"释课元微门"依次列出九种发传条件：

1. 克贼　2. 比用　3. 涉害　4. 遥克　5. 昴星　6. 别责　7. 伏吟　8. 返吟　9. 八专

随后"宗首九科门"给出元首、重审、知一、见机、蒿矢、虎视、信任、无依等基础课名。这种"先列发用条件、再列课体命名"的结构，是《心镜》系统的重要痕迹。

今本卷一转录保留的"克贼第一"数语，最能说明其语脉：

> 四课之中一克下，便是初传立用神……上克下名曰克，下克上名曰贼。独有一上克下，便是用神；如又有下贼上，即无取上克，便取下贼上为用。

这段文字能证明《心镜》以"四课克贼"确立发用，并与后世"贼克法"相接；但公开转录并非可逐页核验的影印本，**不能据此宣称已恢复全文**。

### 3_2 必须分层的四类内容

| 层级 | 主要内容 | 不能直接推出的结论 |
| --- | --- | --- |
| 课体层 | 元首、重审、知一等 | 不能直接得出具体人事吉凶 |
| 结构层 | 四课、三传、发用 | 不能脱离类神与事项解释 |
| 情态层 | 十二天将 | 不能仅凭神将名称作绝对判断 |
| 条件层 | 神煞、旺衰、刑德、旬空 | 不能忽略版本与适用边界 |

单一课名只负责分类，不自动生成结论。进入不同门类后，才由类神、天将、旺衰、刑德和事项条件共同限定——**"见机"不等于任何事都宜速动，"重审"也不等于谋事皆凶**。

### 3_3 "四课—三传"是技术骨架，非《心镜》独家发明

四课由日干、日支各取"上神"和"阴神"构成：

| 课位 | 构成 | 主要观察 |
| --- | --- | --- |
| 第一课 | 干阳 | 自身、主动方的表层状态 |
| 第二课 | 干阴 | 自身、主动方的内部或后续状态 |
| 第三课 | 支阳 | 对方、环境与所问之事 |
| 第四课 | 支阴 | 更深一层的结构与变化 |

三传由初传、中传、末传依次展开，通常对应起因、过程、趋向。天将、神煞、六亲起辅助辨识作用。这些规则跨《龙首经》《玄女经》《六壬大全》反复出现，严谨写法应是"六壬通用，而《心镜》将其编入门类"，而非"唯《心镜》所创"。

### 3_4 原文与通用理论对照表

| 项目 | 《心镜》可核验线索 | 大六壬通用理论 | 推荐写法 |
| --- | --- | --- | --- |
| 九法框架 | 今本卷一列克贼至八专九项 | 《六壬大全》定型歌诀 | "今本承袭、通法定型" |
| 贼克优先 | "克贼第一"及上下克命名 | 下贼、上克次序为共同基础 | "《心镜》明言；壬家共法" |
| 比用 | 阳日以阳神为比，阴日以阴神为比 | 以阴阳比和决多克 | "与通用法一致，待宋元文本比对" |
| 涉害 | 今本列"涉害第三" | 孟仲季、归家计数有版本异说 | "只列所用版本，不宣称唯一正解" |
| 天盘、月将、贵人 | 卷四杂神杂将传统 | 式盘共同基础 | "技术基底通用；歌诀解释可属《心镜》" |

> **小结**：通用理论成熟早于《心镜》，后世又继续演化（《毕法赋》《六壬指南》《壬归》）。把明清概念全塞给唐代徐道符，是典型的历史倒置。

## 板块4 · 基础构件精解：天地盘、月将、寄宫、天将

**起课的准确性，取决于基础构件每一步都可复核。** 这一层是"四课—三传"的地基，任何一处错位都会沿链条放大，因此值得单独拆开讲透。

### 4_1 地盘固定、天盘随"月将加时"旋转

+ **地盘**：子丑寅卯辰巳午未申酉戌亥，方位相对固定（子北午南卯东酉西），代表地球、方位、地气，是时空底盘，**永远不动**。
+ **天盘**：以当月月将（太阳所在星次）加在"占时"地支之上，**顺时针**依次排完十二支，代表天道、太阳气机、周天流转。

口诀："**月将加时，顺布天盘；天旋地静，阴阳相交。**"月将即太阳，为天盘唯一源头；无月将则无天盘，无天盘则无四课三传，全课不立。

### 4_2 月将：按"中气"换将，而非农历月份

月将是太阳沿黄道十二星次的行宫，换将节点是**二十四节气中的"中气"**（雨水、春分、谷雨……），不是农历月首，也不是"节气"。中气未到，永用上月旧将；中气一过，即时换用新将。

| 中气区间 | 月将（地支·星次） | 中气区间 | 月将（地支·星次） |
| --- | --- | --- | --- |
| 雨水后 | 亥·登明（娵訾） | 处暑后 | 巳·太乙（鹑尾） |
| 春分后 | 戌·河魁（降娄） | 秋分后 | 辰·天罡（寿星） |
| 谷雨后 | 酉·从魁（大梁） | 霜降后 | 卯·太冲（大火） |
| 小满后 | 申·传送（实沈） | 小雪后 | 寅·功曹（析木） |
| 夏至后 | 未·小吉（鹑首） | 冬至后 | 丑·大吉（星纪） |
| 大暑后 | 午·胜光（鹑火） | 大寒后 | 子·神后（玄枵） |

辅助记忆口诀：

> 雨水登明春分魁，谷雨从魁小满传；夏至小吉大暑胜，处暑太乙秋分罡；霜降太冲小雪功，冬至大吉大寒神。

**月将 ≠ 月建**：月建以"节令"（立春、惊蛰……）换，主地气、地支旺衰、人事月令；月将以"中气"换，主天气、天道纯阳、全局气机、天盘枢纽。二者不可混淆。排盘时务必注明所用历书与中气交节时刻——节气交节的"临界点"一旦判断错误，月将、天地盘、贵人顺逆全盘跟着错。

### 4_3 十干寄宫：天干如何落进地盘

六壬式盘只显十二地支，而人事推演离不开十天干，于是把天干"寄"进地盘某支，用该支代表天干。口诀（阳干寄禄、阴干寄冠带）：

> 甲课寅兮乙课辰，丙戊课巳不需论；丁己课未庚申上，辛戌壬亥是其真；癸课原来丑宫坐，分明不用四正神。

即：甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。**子午卯酉为四正，不设寄宫**——这是四课出现"三课""两课"（别责、八专）的根源。

### 4_4 十二天将：顺序固定，顺逆由贵人落宫决定

十二天将的固定顺序是：

> **贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后**

顺序永不变，变的只是顺排还是逆排。贵人是枢纽：先按日干与昼夜定贵人所在地支，再看贵人落在哪一段决定顺逆。

**贵人起法口诀（旦暮分阴阳贵）：**

> 甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸蛇兔藏，六辛逢马虎，此是贵人方。

以歌中"上字"为昼（阳）贵、"下字"为夜（阴）贵。昼夜划分以当地日出日落为准：大致卯时至申时用昼贵，酉时至寅时用夜贵。

**顺逆规则**（以贵人落"地盘"宫位为准）：

+ 贵人落在 **亥子丑寅卯辰** 六宫 → 天将**顺**行；
+ 贵人落在 **巳午未申酉戌** 六宫 → 天将**逆**行。

| 天将 | 基本情态 | 使用提醒 |
| --- | --- | --- |
| 贵人 | 逢迎、爵命、贵人 | 需看所临地支与类神，分昼夜贵 |
| 螣蛇 | 虚惊、变化、缠绕 | 主变动不定 |
| 朱雀 | 文书、口舌、信息 | 与沟通、合约相关 |
| 六合 | 和合、交易、媒介 | 婚姻、合作常用 |
| 勾陈 | 迟滞、争竞 | 主阻滞 |
| 青龙 | 财喜、施为 | 受克、空亡则转虚花 |

| 白虎 | 威权、伤害、急迫 | 可用于警惧、果断，也可主病伤 |
| 太常 | 宴享、衣禄、平常 | — |

### 4_5 六亲：以日干为中心的五行关系

六亲是五行生克的代名词，"我"指**日干**：

> **生我者＝父母，我生者＝子孙，克我者＝官鬼，我克者＝妻财，与我同类者＝兄弟。**

例：日干甲木，见子亥水（水生木）为父母，见巳午火（木生火）为子孙，见辰戌丑未土（木克土）为妻财，见寅卯木为兄弟，见申酉金（金克木）为官鬼。

六亲无绝对吉凶：父母主得助，却克子孙；子孙主消耗脱气，却是官鬼的克星（"有鬼克我，见子孙反为救神"）；妻财需我费力争取，财太旺而日干衰反"控制不住"。**吉凶要看旺衰与具体事项，不能单看名称。**

## 板块5 · 断课的四层结构：从单句歌诀走向可检查的判断

**四层结构的作用，是让每一项证据都经过验证，而不是增加符号数量。** 只有四层相互支持，判断才具可检查性；任一层出现冲突，都应成为修正解释的线索。

### 5_1 第一层：课体定位——先看属于何种起法

对元首、重审、知一、见机、蒿矢、弹射、昴星、伏吟、返吟等，先记录其发用规则与结构特征，**不急于贴吉凶标签**。

+ 伏吟、返吟未必一概凶，只是分别提示"静守/反复"与"冲激/变动"；
+ 蒿矢、弹射描述的是发用关系，不直接等于事件结果；
+ **四课是否"全"本身就是信息**：四课不全（三课、两课）主事不圆满、信息有缺，如占孕产常主不足月——这是比单句断语更基础的判断。

### 5_2 第二层：三传追踪——追问"起因—过程—结果"

初传显示当前触动，中传显示转移、阻碍或转机，末传显示趋向。要用五行、旺衰、生克、刑冲、旬空校正：

> 若出现"初生中、中被末克"，就不能只取初传的生象，而应解释为利好在中段受阻、难以延续。

某神受克，可能只是条件受限；若在衰位再逢空、刑、冲，限制才更显著。一处吉神也不该自动抵消整体传局。还可借助《毕法赋》这类"课格索引"快速定位关键特征，例如：

+ **前后引从**：初传居干前为"引"、末传居干后为"从"→ 引干主进职、引支主迁宅；
+ **拱贵格**：两贵人或三传拱卫日干 → 得主上提携成事；
+ **回还格**（三传在四课之中）→ 宜守旧不宜动作。

这类课格是"检索线索"而非结论，仍须回四层结构验证。

### 5_3 第三层：天将辨析——描摹情态，而非贴吉凶标签

天将更接近**行为方式、社会角色与情态参数**，切忌"贵人一定吉、凶将一定凶"。同一青龙可临财，也可因受克、空亡转成虚花。脱离情境判断天将，最容易把"性情"误读为"结局"。

贵人又有昼贵、夜贵之分，落宫决定十二神顺逆——**顺行主时空顺、逆行主时空逆**，直接影响对事态快慢、顺逆的判断，不可漏算。

### 5_4 第四层：类神验证——回到具体问题

类神要最后才介入，且需回查前三层是否一致：

| 占事 | 一级类神 | 核验重点 |
| --- | --- | --- |
| 求财 | 财爻、财神、日干 | 日干能否任财；三传是否引动；财是否空亡 |
| 婚姻 | 官鬼、妻财、六合、男女年命 | 生合与刑冲；双方状态是否对应 |
| 疾病 | 日干、症状神、医药神 | 受克、旺衰、天将情态及类神一致性 |
| 寻人 | 行人、驿马、天门、地户、初末传 | 动向、迟速、有无阻碍 |

**若类神与三传、天将相互矛盾，正确做法是记录冲突并降低确定性，而非强行统一。**

## 板块6 · 可落地实操：起课的规范六步

**起课的关键不在背口诀，而在固定"时、将、盘、课、传、将、煞"的顺序。** 每一步都保留日干支、时辰、节气、寄宫、顺逆及所用歌诀，最好手写或拍照留档——结果不符时能定位规则错误，而不是事后改课。

### 6_1 步骤 1：固定占时与占日

采用明确日期、时辰与历法口径。古法以"月令、节气、时辰"推排，不以现代钟表小时机械替代。核心不是追求"最古"，而是**保证同一占例可复核**——时辰一变，月将、天地盘、贵人顺逆及部分克应都可能随之改变。

### 6_2 步骤 2：依中气定月将，再"月将加时"排天盘

按 3.2 的中气对照表取月将，将月将置于占时地盘位置，其余十一支顺时针排列，即得活动天盘。**务必注明所用历书与中气交节时刻。**

### 6_3 步骤 3：按十干寄宫列四课

按 3.3 口诀把日干寄进地盘某支，然后逐层推出四课：

+ 第一课：日干寄宫在**天盘**中的上神；
+ 第二课：第一课的上神落入地盘后，再取其天盘上神（干阴）；
+ 第三课：日支的上神；
+ 第四课：日支上神的阴神。

四课不是四个孤立地支，而是"地支在天盘中映射"逐层推出的链条。

### 6_4 步骤 4：按九宗门取得三传

初传确定后，通常以其所落地支在天盘中的上神为中传，再以中传地支在天盘中的上神为末传（昴星、别责、伏吟、返吟有特殊中末传规定，依底本歌诀执行）。

### 6_5 步骤 5：依昼夜、日干布十二天将

先按 3.4 定昼夜贵、贵人落宫，再据贵人在地盘上的顺逆区间排列十二神将。**顺逆一旦出错，天将与十二支整体错位，后续解释随之失效**，务必写明"采用何本"。

### 6_6 步骤 6：最后加入神煞、六亲和类神

六亲以日干为中心（生我＝父母，我生＝子孙，克我＝官鬼，我克＝妻财，同我＝兄弟）。

神煞以类取用，**不应先挂一大串神煞再找解释**。规范流程是先完成课体与三传，再根据事项选择性启用类神，核查其与主结构是否一致。

## 板块7 · 九宗门速查：带优先级的逐层排除

**九宗门不是九种任意选择的起课术，而是一套带优先级的检核流程。** 前法条件满足，通常不跳过后法；只有当前层条件不足，才进入下一层。口诀总纲：

> 取课先从下贼呼，如无下贼上克初……（贼克）

常将天日比神用，阳日用阳阴用阴……（比用）
涉害行来本家止，路逢多克为用取；孟深仲浅季当休，复等柔辰刚日宜……（涉害）

| 优先级 | 法门 | 何时使用 | 初传记忆法 | 常见误区 |
| --- | --- | --- | --- | --- |
| 1 | 贼克 | 四课有上下克 | 先下贼上，无贼才取上克下 | 把天地盘克的方向弄反 |
| 2 | 比用 | 多克且可比较 | 阳日取阳神，阴日取阴神 | 只比天盘支，忽略与日干的阴阳关系 |
| 3 | 涉害 | 俱比或俱不比 | 先固定孟仲季或归家法 | 混用不同底本规则 |
| 4 | 遥克 | 四课无上下克 | 先神遥克日（蒿矢），再日遥克神（弹射） | 把遥克与四课内上下克混淆 |
| 5 | 昴星 | 无克、无遥克 | 阳日从酉上神，阴日从酉下神 | 中末传仍套常规 |
| 6 | 别责 | 仅三课且无克、无遥 | 刚日取干合上神，柔日取支合 | 视为普通遥克 |
| 7 | 八专 | 两课且无克 | 阳日日阳顺三，阴日辰阴逆三 | 忽略干支同宫条件 |
| 8 | 伏吟 | 天地盘同位 | 有克以克发用，无克按刚柔取干/辰，中末取刑 | 把伏吟直接等同于凶 |
| 9 | 返吟 | 天地盘相冲 | 有克以克发用，无克按井栏（取支驿马） | 自动解释成"远行必归" |

对应的基础课名：**贼克→元首/重审，遥克→蒿矢/弹射，昴星→虎视/冬蛇掩目，伏吟→不虞/自任/自信/杜传，返吟→无依/井栏**。

### 7_1 重点提醒：涉害法的版本分歧

涉害最容易造成"同盘不同传"，分歧在第一步"涉害深浅"：

+ **孟仲季法**：先取四孟（寅申巳亥）上神，无孟取仲（子午卯酉），**不取季**；深浅相同再按刚柔、干支取先见者。邵彦和、陈公献等壬学大家多采此法，即《黄帝金匮玉衡经》所谓"在孟为机（忧深），起季仲为微（忧浅）"。见机格＝孟上发用，察微格＝仲上发用，缀瑕（复等）格＝俱比俱孟时刚日取干上、柔日取支上。
+ **涉归本家法**：《六壬大全》入手法诀"涉害行来本家止，路逢多克为用取"，要求涉归地盘本家，数所受克次数，多者为用。

清人刘赤江《六壬粹言·辨非十则》"涉害第六"辨析：古法以归家受克深者为用，深浅相等再取孟位，今诸家鲜用之。经推算，**仅丁卯、甲申、甲辰、癸酉、庚辰五日**季上神涉归本家所得贼克深于孟上神，其余诸日两种方法结果完全一致。

> **结论**：这类分歧不能靠占验偏好解决。学习者必须写明采用何种底本（推荐注明"从《指南》例用孟仲法"或"从《大全》例用归家法"）；若需比较版本，把不同结果并列即可，不必把某一种称为唯一正解。

## 板块8 · 完整占例：训练规则一致性，而非预言

**以下两例仅用于展示"如何排盘、如何留痕"，不预测任何现实事件。** 干支、时辰、月将、贵人、中气规则均须先固定；规则版本不同，结果可以不同——这是正常现象，不应通过事后改课来维持结论。

### 8_1 占例 A（方法演示）：癸亥日、午时、小满后取申将

**背景**：某人问"是否宜主动接洽合作"。此例用于检查四课生克与发用，不作为现实决策。

**① 时、将、盘**

+ 日干癸寄丑，日支亥；
+ 小满后取申将（传送）；
+ 午时以申加午，顺时针排列天盘。

> 方法演示中不必给出逐位核验的完整天盘表；正式排盘应使用软件或式盘，记录时区、节气交节时刻与月将口径。

**② 四课原则**

| 课位 | 构成 |
| --- | --- |
| 第一课 | 丑上天盘 |
| 第二课 | 第一课的上神再取天盘 |
| 第三课 | 亥上天盘 |
| 第四课 | 第三课的上神再取天盘 |

**③ 三传原则**：先检查四课上下克 → 有克进贼克或比用 → 无上下克再查遥克 → 确定初传后依次取中传、末传。

**④ 解释框架**：初传＝接洽的触发；中传＝沟通、条件或第三方；末传＝后续趋向。

> 若末传指向合作类神，只能提示"存在相应条件"，不能写成"必成"；若末传受克或空亡，应表述为"条件、文书或对方回应可能阻滞，建议补足信息后分阶段推进"。

**重点是每一步都有来源，而不是吉凶结论。** 跳过月将起例、天盘逐位结果或初传规则，判断就无法复核。

### 8_2 占例 B（公开可核日期）：2025年6月20日12时，乙丑日、午时

**公开日历可核**：2025年6月20日约为农历五月廿五前后，此处取教学日干支**乙丑**、时支**午**。真实学习须用权威历书核对是否已过夏至换将（**夏至后为未将小吉，此处必须写明采用的是"换将前申将"还是"换将后未将"——这就是中气临界点的重要性**）。

**① 天地盘假设（仅教学演示）**

| 项目 | 假设值 |
| --- | --- |
| 月将 | 申将（需以实际交节核实） |
| 天盘起点 | 申加午 |
| 天盘序列 | 申午、酉未、戌申、亥酉、子戌、丑亥、寅子、卯丑、辰寅、巳卯、午辰、未巳 |

实际占例必须由式盘重新核算，不能把"假设"当排盘结果。

**② 四课**：日干乙寄辰 → 第一课为辰上天盘 → 第二课为第一课所在支再上推 → 第三课为日支丑上天盘 → 第四课为丑上神再上推。

**③ 发用**：检查一至四课上下克 → 有克按贼克或比用定初传 → 中末传由初传继续推出。

**④ 文化解释**：发用见官鬼＝规则、上级或压力进入议题；传见妻财＝资源、报酬或交易成本；空亡、刑冲明显＝信息不全、合同与沟通风险。

最终只形成条件性判断：

> 该议题存在 X 类约束，Y 条件尚未落实；宜先做核验，再分阶段行动。

**不能说"合作必成或必败"。**

> **两例共同说明**：占例训练的目的不是增强预言感，而是训练规则一致性。课盘、规则、解释链任一处缺失，结论都不具备可复核性；可复核性丧失后，所谓"应验"也无法区分来自规则、事后解释还是偶然匹配。

## 板块9 · 学习路线图与书单

**合理路径是"术语 → 排盘 → 课体 → 门类 → 版本"，而不是一开始追求灵验。** 过早进入复杂占例，只会把规则错误、抄写错误和主观解释混在一起。

| 阶段 | 建议材料与任务 | 验收标准 |
| --- | --- | --- |
| 入门 | 华龄整理本《心镜》；《六壬大全》入手法；式盘或可靠排盘工具 | 能无提示排天地盘、四课，说明干支寄宫 |
| 课体 | 《心镜》卷一目录；对比《六壬大全》课经、赋象 | 能解释九宗门触发条件及元首、重审、见机等结构 |
| 断法 | 《心镜》杂占门类；《毕法赋》《壬归》《六壬指南》选读 | 会做四层表格，不以单煞定吉凶 |
| 版本 | 清程树勋序跋、光绪家刻书目、《四库总目》 | 能区分原歌、郇注、程按及补辑 |
| 研究 | 敦煌、宋元书目与传世本比较；神煞起例校勘 | 对争议问题并列版本，不伪称定本 |

### 9_1 推荐书单（避免"秘本崇拜"）

1. **华龄整理本《大六壬心镜》**——现代阅读首选，使用前核查前附底本说明；
2. **《四库全书总目》**——目录、作者及《六壬大全》关系考辨；
3. **《六壬大全》**——规则总汇与通用教学（含入手法、九宗门、毕法赋）；
4. **清程氏家刻本影印或复制件**——版本比较；
5. **《毕法赋》《六壬指南》《壬归》**——宋元以后断法史，尤宜"逆向工程"式研读：遮盖断语、独立分析、再对照古人判断。

### 9_2 拓展自学建议（来自网络教程的高频共识）

综合多个网络教程的入门路径，可概括为"**死记口诀 → 活排式盘 → 慢断一课**"三阶段：

+ **先背熟四组口诀**：十干寄宫、贵人起法（甲戊庚牛羊……）、月将中气换将、天将顺序（贵螣朱六勾青龙空白常玄阴后）；
+ **排盘务必"手算"过关**：先用纸笔+式盘走完贼克、比用两门，再碰涉害；软件只作校验，不能直接抄结果；
+ **断课"逆向工程"**：把《六壬指南》占验案例分类，遮盖陈公献断语，自己先分析再对照，重点追问"他为何先看这一点"；
+ **从单一事项练起**：先专攻一类（如求财或疾病），把类神、六亲、天将的固定组合吃透，再扩展到其他门类。

### 9_3 常见误区清单（对照自查）

+ ❌ 用"贵人"直接替代全部三传分析；
+ ❌ 神煞越多，越觉得结论精确；
+ ❌ 把伏吟、返吟自动判凶；
+ ❌ 只取最吉或最凶一处，忽略整体传局；
+ ❌ 把明清概念说成唐代原文；
+ ❌ 以事后结果反改课式，制造"应验"；
+ ❌ **贵人顺逆算错**（天将整体错位，全盘皆废）；
+ ❌ **中气临界点判断错**（月将一错，天地盘、贵人全错）。

**有效训练要主动制造可证伪条件**：同一课式由不同底本分别推导并并排比较；同一占例由不同人独立完成排盘；解释先写结构、再写事项，不以结论倒推规则。

## 板块10 · 结语：明确边界，反而更能看见价值

《大六壬心镜》最值得研究的，是"歌诀化的术数知识工程"，而非未经核验的神秘预言。它把课式、课名、神将、占验编成可诵、可查、可按事项检索的系统；清代校辑又使其从散乱传抄进入较稳定的八卷形态。

本手记始终强调一条原则：**原文独有与通用理论持续分栏**。卷一门目、四课发用语脉、门类编排、"拟经作歌、排门定类"的编纂方式，属《心镜》可直接讨论的贡献；天地盘、三传、天将、神煞、九宗门，则先归入六壬共同技术史。明确边界之后，反而更能看清《心镜》如何整理旧知、后世总集又如何重塑旧知。
