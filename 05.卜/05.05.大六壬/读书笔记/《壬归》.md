## 板块1 · 先定坐标：这是一本讲「怎么想」的书，不是讲「怎么算」的书

《壬归》书名即主旨——"壬"是大六壬，"归"是旨归、归宿。全书回答的其实只有一个问题：**面对一盘纷纭的课传，思绪该从哪里下口，沿着什么顺序走，才能不惑于象、不溺于数**。因此它极少罗列吉凶断语，而把力气花在搭框架、定次序、立取舍标准上。理解了这一点，才不会把它读成又一本神煞大全。

### 1_1 版本与文本的清醒认知

| 项目 | 说明 |
| --- | --- |
| 通行结构 | 七卷：卷一《提纲例约》、卷二《壬占易简例约》、卷三《谋望门》、卷四《婚姻门》、卷五《农事门》、卷六《出行门》、卷七《三才门》 |
| 常见整理本 | 《大六壬总归》（华龄/九州，据四卷本系统）、《壬归校译释论》（于公，据七卷抄本系统）、《六壬经典汇要》（徐伟刚点校，与《六壬指南》《壬学琐记》合刊） |
| 作者考 | 题宋郭子晟撰；近人据序文、避讳与"《时宪历》"等内证，多判为后人从郭氏《新编日用涓吉奇门壬归要略》中**摘出六壬部分**重编而成，主体思想属宋明壬学脉络 |
| 库内底本 | 息壤网络全文镜像，卷一至卷七俱全。**原文卷三至卷七未立 `##` 级标题**——"卷之三 谋望门""卷之四 婚姻门""卷之五 农事门""卷之六 出行门""卷之七 三才门"等字样连缀于正文之中，检索时须以此五处字样为分卷之界 |
| 读法建议 | **读七卷本，只读卷一至卷三**，卷四以后当作类象词典查阅，不必通读 |

**实操要点**：下载或购书时认准"七卷本 + 繁转简 + 有原文句读"的版本（推荐《六壬经典汇要》或校译释论本）。四卷本掺入清代择吉内容，初学容易误把择吉规则当占断法则。**务必选择带原文断句的版本**——本书价值全在原文长句的逻辑转折（"然""盖""故""是故"），断句一错，方向全反。

### 1_2 它在壬学体系里的真实位置

壬学经典按功能可分三类：

+ **《心镜》《六壬大全》**：告诉你"盘怎么排、神将叫什么、有哪些课体"——**工具书**
+ **《毕法赋》《课经》**：把古圣先贤的经验压缩成可背诵的条目——**规则库**
+ **《壬归》**：告诉你拿到一盘后**先看什么、后看什么、哪个服从哪个**——**方法论**

打个比方：前两类是字典和成语词典，这一本是"怎么写出通顺句子的语法书"。所以几乎所有学习路线都把它安排在**基础已通、断课仍乱**的这个阶段，而不是入门第一本。它的作用是把你已经知道的碎片连成决策链。

### 1_3 全书一句话与总纲五步

卷一《提纲例约》五篇，就是全书的决策流水线，顺序**不可颠倒**：

> **观四课之加临 → 察用神之生克 → 明三传始终 → 定贵神吉凶 → 判八煞吉凶**

原文收束语最见其野心：

> "类本象分，象因类著，理以气应，占以理求，壬占之法，尽之矣。宁不易简乎？"

而卷二给出的实战承诺更狠——把整盘壬课压缩成**两句话**：

> **"吾身之与万类，得气则吉，不得气则凶，两言决耳。"**（卷二《壬占易简例约·理气象类说》）

这不是偷懒。这是说：所有神将、六亲、神煞、课体、长生十二气，最终都要汇入两个判断维度——**性质（吉/凶）**与**能量（旺/休）**，二者交叉成四象限，断语自然落位：

|  | 旺相（得气、有势） | 休囚（失气、无力） |
| --- | --- | --- |
| **吉神吉象** | 成，且速、且实 | 能成，但迟、且薄 |
| **凶神凶象** | 祸重，急发，难躲 | 祸轻，可救，或虚惊 |

这条四象限，是全篇最值得抄在起课纸顶端的一句话。**它解决的是"信息打架时听谁的"这个核心难题。**

## 板块2 · 卷一拆解：占断流水线五道工序

### 2_1 第一道：观四课之加临——先辨"体"

四课是地盘不动、天盘旋转之后，以日干日支为两个锚点各取上下两课。它的作用不是找用神，而是**定"体"**——这件事现在处在什么结构里。

| 课位 | 壬家称谓 | 信息指向 |
| --- | --- | --- |
| 第一课（干上） | 干阳、外课 | 我之表现、事态的外显 |
| 第二课（干上之阴） | 干阴 | 我之隐情、背后真实 |
| 第三课（支上） | 支阳、内课 | 对方、家宅、环境 |
| 第四课（支上之阴） | 支阴 | 对方之隐、内里根源 |

**核心原文逻辑**："日动为我，辰静为人"——干代表主动方、求谋者；支代表被动方、所占对象与环境。四课上下相生相克、相刑相冲相害，先把"我与对方的关系结构"读出来。

**实操清单**：

1. 先读**干上神对日干**是生是克——我当下是得势还是受压；
2. 再读**支上神对日支**是生是克——对方/环境当下状态；
3. 再读**干上神与支上神之间**的关系——这是"我→对方"的互动主轴（生合则通，战克则阻，刑则不投，冲则难合，害则有阻，破则无成）；
4. **最后看阴神**：干阴决定"我真正的动机与顾虑"，支阴决定"对方背后是否有人撮合或作梗"；
5. 四课见空亡 = 该侧面信息残缺、力量落空，**不可据空位断实有其事**。

> **常见误读**：把四课当四个并列信号平均用力。正确顺序是"干上 → 支上 → 双方关系 → 两阴神"，层层递进，越往后越接近真相。

### 2_2 第二道：察用神之生克——再定"机"

"用神"在此专指**初传发用之神**（注意：不是六爻里那个"用神"概念）。它代表事之机、动之始。

**原文要点归纳**：

+ "发用之神，主事之吉凶成败，以旺化决之"——吉凶看性质，**程度看旺衰与化传**；
+ **用在干两课** = 外事、主远、主动、主去；**用在支两课** = 内事、主近、主来；
+ **上克下（贼）**：卑幼灾，事从外来，占利男子，兵利先起；
+ **下克上（克）**：尊长危，事从内起，占利女人，兵利后应；
+ **应期直尺**（最实用的一段）：

> 用得太岁→事在年中；用得月建→事在本月；用得旬首→事在本旬；用得节气中立之首→事在半月；用得本日之干→事在本日；用得气首→事在五日。

+ **长生十二气定成败状态**：发用临**死**则事止，临**败**则事败，临**绝**则事结/人信至/病死，临**墓**则事隐晦；
+ **发用与日辰的冲刑破害** → 自不安 / 家不宁；
+ **发用克日**忧己身、身动、公讼；**克支**忧妻妾卑下、家内不安；克太岁、月建、行年、本命各有分野。

**实操清单**：

1. 起出三传，先圈**初传**；
2. 问自己三个问题：在干课还是支课？（定内外方向）上克下还是下克上？（定事态性质）临十二气的哪一位？（定成败形态）
3. 再用"太岁→月建→旬首→节气→本日→气首"这套尺子**量出应期区间**；
4. 看发用是否冲刑破害日干日支——这是"隐患警报"，有则必言之，无则不必生造。

### 2_3 第三道：明三传始终——最后看"流"

初、中、末三传是**时间轴与因果链**，不是三个并列的吉凶点。

| 传位 | 角色 | 关键原文 |
| --- | --- | --- |
| 初传（发用） | 起因、开端、动机 | "休咎之机，关于发用" |
| 中传 | 转折、变化、枢纽 | "转移之妙，乃属中传" |
| 末传（归计） | 结局、归处 | "末为底止之乡" |

**推导规则（可直接上手的几条）**：

+ **递生链**：初生中、中生末、末生日干 → 凡事有成，且"不惟从力相扶，而且财在末也"——**越往后越有利**；
+ **出处异途**：自支上发用、传出干上而生合日干 → **人来就我**，守即可；自干上发用、传入支上而与之生合 → **我往就彼**，主动为宜；
+ **救应结构**：凶在初传，若末传见子孙制克、或父母爻化泄、或干上子孙克制 → **先凶后吉**；末传空亡 → 鬼传向空，**虚惊无实祸**；
+ **旺衰定迟速**：发用乘吉气旺、别无伤损 → 吉且速；囚死乘凶、又遭战克 → 凶且迟。"气旺故速，气休故迟"——**旺衰在这里直接换算成时间**；
+ **空亡是断路**：空则"靡象，吉凶无成"，此项直接作废，不必勉强附会。

**一个高频结构务必记住**：**初鬼—末子孙/空亡 = 先难后解**。这是壬课里"凶事有救"最典型的形态，卷三谋望、卷四婚姻反复使用。

### 2_4 第四道：定贵神吉凶——类象的"主帅"

十二天将（天乙贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后）是《壬归》取类的**第一优先序**。原文明言：

> "凡占必以天官为万类之主。"

| 所问之事 | 正类（首选天将） | 扩展类（变通位） |
| --- | --- | --- |
| 盗贼、逃亡、走失 | 玄武 | 河魁（戌）、天罡（辰） |
| 求财、财帛、文职功名 | 青龙 | 太常、功曹（寅）、小吉（未） |
| 文书、口舌、词讼、信 | 朱雀 | 午、登明（亥） |
| 干贵、谒见、尊长 | 天乙贵人 | 大吉（丑） |
| 怪异、惊恐、噩梦 | 螣蛇 | 巳 |
| 争斗、勾连、田土 | 勾陈 | 辰、卯 |
| 疾病、道路、死丧 | 白虎 | 申、丧门、吊客 |
| 婚姻、交易、媒保、子孙 | 六合 | 卯 |
| 饮食、赏赐、俸禄、尊长财 | 太常 | 小吉（未） |
| 奴婢、虚诞、上书通启 | 天空 | 戌 |
| 阴私、婢妾、金银 | 太阴 | 酉 |
| 妇女、望恩泽封诰 | 天后 | 子 |

**原文里最锋利的三条**：

1. **"类虽以发见为主，见则所求易得也"**——类神出现在四课三传中，此事才"显象"、才真切；课传无类，只能看其本位方位，**力度降一档**；
2. **"阳现其象，情归于阴"**（卷一《提纲例约·定贵神吉凶》；卷二求财例重申"凡类上之神，谓之阴神而曰类阴，阴者事之主，天之心也"）——**类神（阳神，即天将所乘之神）现其象**，**类上之神（阴神／类阴）主其事之情**。阳看"事象是什么"，阴看"内情、动机、根子在哪"。看类神只看一半；
3. **吉将临刑克之地则不吉，凶将临受刑克之地则更凶**——典型如天乙贵人：临刑（巳加寅）、临害（子加未，未又克子）→ 为患非轻；**坐辰戌 = 贵人入狱**（履狱），干贵必受辱；**临空亡 = 虚喜无功**；惟**临日干 = 贵人临身**，最吉。白虎临死、墓、绝地 → 为祸更深。

**这一段的最大价值是破除迷信**：吉神凶神不是标签，而是**"本体 × 落位 × 阴神"**三者运算的结果。青龙落在受克受刑之地，一样求财无门。

### 2_5 第五道：判八煞吉凶——最后的校准层

八煞 = **德、合、鬼、墓、破、害、刑、冲**。它不在五道工序里另起炉灶，而是**给前面每一步做加权修正**：

+ **德（日德、天德、月德）**：救应、逢凶化吉，优先级最高；
+ **合（六合、三合、干合）**：成事、和合，但"合"也可能是绊住不动；
+ **鬼（官鬼、日鬼、遁鬼）**：克我之凶，需子孙制或空亡化解；
+ **墓（十二气之墓）**：事隐、人困、物藏，主迟滞；
+ **破、害、刑、冲**：原文八字定诂——**"破知损坏，害见侵凌，刑分强弱，冲不安宁"**（卷一《提纲例约·判八杀吉凶》，原文作"支藏破害刑冲"）。四者各有所主，**原文并未排定轻重次序**；"冲最猛"是后世读法经验，非原文明文。

**校准顺序建议**：先用八煞看**发用与类神**有没有被破害刑冲，再看**年命**有没有被伤（"日用不可伤残，命年最宜和好"），最后看**三传首尾**是否被太岁、月建所克。**八煞是用来解释"为什么明明吉却不成 / 明明凶却没事"的**，不是另立一套断语。

## 板块3 · 卷二拆解：理气象类四层与「两言决耳」

卷二是全书的哲学内核，提出**理气—类象**二元结构。真正需要吃透的是下面这张"分层表"，而不是原文的华丽辞藻。

### 3_1 理、气、象、类、数——五个字各自管什么

| 层次 | 含义 | 一句话提问 | 对应判断 |
| --- | --- | --- | --- |
| **数** | 天地盘、四课三传、干支定位 | 结构摆对了吗？ | 排盘校验 |
| **象** | 支神、天将、六亲、神煞各自之象 | 每个符号说什么？ | 取象清单 |
| **类** | 把"象"归集到"所问之事"上 | 哪一个是这件事的主人？ | **取类定主** |
| **气** | 旺相休囚死、十二长生、得气不得气 | 它有力吗？能兑现吗？ | **旺衰定成败迟速** |
| **理** | 事理人情、因果常情 | 这事在人世上讲得通吗？ | **最终裁决** |

**《壬归》的元规则**："理以气应，占以理求"——**气是理兑现的阀门**。原文讲得很透：事物有"当然之理"（本来该这样），但不一定有"必然之气"（眼下时机与力量到位）。**气不应，则象类空悬**——类象再漂亮，也只是画在空中的饼。这就是为什么它强调"舍象言理不可，舍理言象更不可"，必须**理先象后**。

**实操纪律**：每一条象意结论，都要过两关——

1. **气关**：旺相还是休囚？临四吉地（长生、冠带、临官、帝旺）还是八凶地？
2. **理关**：放到具体人事里，讲得通道理吗？（例：占求财见"三传皆财"看似大吉，但若**日上财遁旬中干鬼**，则为"因财致祸、因妻致讼"——理上不通，象上再吉也要打折。）

### 3_2 旺衰不是形容词，是四组可查的尺子

《壬归》反复说"得气""无气"，"气"具体指四组，查起来毫不模糊：

**（1）五气（旺相休囚死）**：按五行当令。春木旺、火相、水休、金囚、土死，余类推。**旺相则可成可进，休囚则宜守宜退。**

**（2）十二长生**：**长生、冠带、临官、帝旺 = 四吉**；沐浴、衰、病、死、墓、绝、胎、养 = **八凶**。这是"类神所临地盘"的吉凶表，卷二求财占用了整整一大段。**凡神将既和、又下临吉地，方成财象；神将不和、又临凶地，财则无象**——求之何益。

**（3）得气 / 无气（内外战）**：这是最容易落地也最容易被忽略的一条。以类将（如青龙）与其**乘神（地盘支）**相较：

+ **内外不战 = 神与将和 = 得气 = 吉**；
+ **内战其将（地盘支克类将）= 忧重**；**外战其神（上神克类将）= 忧轻**；
+ **"轻犹可图，重则难望"**——同样是凶，**内战比外战严重得多**，因为伤在根本。

**（4）空亡 = 断路**：落空则"有财尚当防损，况本无财而欲往求乎"。**惟有一种例外**："神生其将，而神自作空者，尚有出旬之可望"——出旬填实，犹可望。这是空亡处理的重要细则，卷二反复用到。

### 3_3 「两言决耳」四象限：把整盘课压成一句话

把所有信息汇入这个矩阵，是《壬归》最可操作的产出：

```plain
            旺相（得气、临四吉地、有救应）
            ┌──────────────────────┬──────────────────────┐
            │   吉神得位 → 成且速  │  凶神得势 → 祸重急发 │
  能量轴    └──────────────────────┼──────────────────────┤
            │  吉神失位 → 成而迟薄 │  凶神失势 → 祸轻可救 │
            └──────────────────────┴──────────────────────┘
             性质轴：吉 ─────────────────────────────── 凶

```

**应用步骤**：

1. 定**类神**（一件事只取一个正类，见下节"专类重于泛类"）；
2. 判**性质**：类神在课传中是生我、我克、克我、还是比和？
3. 判**能量**：得气否？临四吉还是八凶？有救应（德、合、子孙制鬼）还是有克害？
4. 落象限 → 一句话结论（成/不成 + 速/迟 + 实/虚）。

### 3_4 占例一"求财"——标准动作示范（可直接套用）

原文把求财拆成一张检查表，这就是**可复用的 SOP**：

| 步骤 | 检查项 | 判定 |
| --- | --- | --- |
| ① | 先取**青龙**为主（正类） | 无龙则取变通位（太常/功曹/小吉） |
| ② | 俯仰视之：**乘神与将**相较，有无内外战 | 不战 = 神与将和 = 得气 |
| ③ | **类神所临之地 = 十二气** | 临四吉 → 财强；临八凶 → 财弱 |
| ④ | **类神的阴神**（所临地盘之上神） | 看内情、根子 |
| ⑤ | **遁干**（旬干） | 明吉遁凶→防暗损；明凶遁吉→尚有默益 |
| ⑥ | 是否落**空亡** | 空则防损；神自作空→待出旬 |
| ⑦ | 三传有无**财化鬼、财坐鬼乡、财遁鬼** | 有 → "鬼财"，取财生祸，不可妄求 |

**关键洞察——"长期求财看父母，短期求财看妻财"（壬家通法，原文卷二求财例未作长短期之分）**：

这是壬家求财与六爻思路的分野。六爻求财专看妻财兼看子孙（财源）；壬家长期经营（开店、生意、生计）则**重父母爻**——因为父母是"生我者"，代表**对方主动给予、可持续的利益**，得来轻松，不耗自身；妻财是"我克者"，代表**要凭自身五行之力去克取、去争**的利益，需要付出精力。

原文卷二求财例的落点其实更朴素：只立**"青龙为财将 → 明暗财神 → 所求物类"**三层（见上表⑦），六亲只是"较取"之辅助——卷一《提纲例约·明三传始终》明言"凡三传所属五行，皆当与日干较取六亲"。下列三条即由此衍生的**后世壬家通法**：

+ **财旺身弱** → 自身担不住财，反为财累（原文卷二："财旺，必须身强，身弱财强，财虽满前，无力可取；须待生旺吾身之时，方才可必"）；
+ **财克父母** → "贪财坏印"：为眼前之财破坏了长远事业根基，**占生计大忌**；
+ **父母爻旺相** → 生意兴旺、前途无限；父母**陷空** → 生意成虚；
+ **子孙爻** → 财源、救神：有官鬼时克鬼为吉；无官鬼时只是**脱气、耗损**，占病占官皆不利。

> **注**：上三条（父母／子孙论长短、"贪财坏印"等）出自壬家通法，**非《壬归》原文**。原文卷二的落脚点是**身与财两相较量**："财旺，必须身强……财弱身强，我志虽雄，财犹恍惚，亦须待生旺财神之候，始可言求。对待之象，不可不知。"引而用之，须知其所出。

**延伸：官鬼不是一律凶**

官鬼"克我者"，主一切损我、祸我、害我之人事物；**但占功名、仕宦、女性占夫，反喜见之**。判断标准是**旺衰 + 能否被制**：

+ 凶性减轻的条件：旬空、陷空、**夹克**、坐地受制、**贪恋生处**、遁闭口；
+ 凶性加重的条件：乘白虎（最烈）、遁暗鬼（明暗两鬼）、带**丁神、驿马**（凶祸速动）；
+ 化解结构：干上有鬼而辰克去之、辰上有鬼而干克去之，**皆为吉占**——"自有制化"。

### 3_5 占例二"琐占约云"与占例三"叩门占"

卷二收三例：占例一求财（见 3_4）、占例二"琐占约云"（总括求财口诀）、占例三"扣门占"（占来人善恶）。

> **订正**：旧版笔记把"**类神三传**"变通法系于卷二占例之下，属**卷次误置**。该法实际出自**卷七《三才门·三才易简例约》**——"即类以定三传，即三传以言休咎，情形自露，不必徒求课体，即所谓易简也"。它解决的正是**课传里找不到正类天将时怎么办**：

> 占贵人 → 视天乙之三传；占文字口舌 → 视朱雀之三传；占婚姻交易子孙 → 视六合之三传……**即类以定三传，即三传以言休咎**，情形自露，**不必徒求课体**——所谓"易简"也。

**变通规则（神即将，将即神）**：

+ 占财本应责青龙，课传无青龙 → 见**功曹（寅）**则视功曹之乘临与三传；仍无 → 见**太常**则责太常之三传；
+ **"惟类自作空，不以空论"**——类神本位自空，不作空亡断（区别于落空亡），这点极易误读。

叩门占（来人何事、何人）的定位法，原文是**"以日干为扣门之人（来人），以行年上神为我"**——

> "凡以日干为扣门之人，而视其上神，以观其之善恶。盖日干主动，动者为客；日上神将有善有恶……凡以行年上神为我，而与日上之神较论休咎。行年者，吾身之年运也。日上既属扣门之人，则年固属我，为休为咎，相关最切。"（卷二《壬占易简例约·占例三》）

辨来人身份则兼看所乘天官与所遁之干，原文："若更究其所乘之天官，所遁之天干，则喜恶之故，与夫衣饰行状皆可悉也。"这是射覆、测来意的入门路径。

> **订正**：旧版笔记作"以干为我、以支为来人"，与原文**方向相反**（原文日干属来人、行年属我，且此处并不责支），今据原文改正。

## 板块4 · 卷三至卷七：从「成象」到「引伸」的四级跳

卷三《谋望门》是全书中**最具普适价值**的一卷，因为它把"怎么断一件事"抽象成了四个层级。其余各门（婚姻、农事、出行、三才）都是这个框架的具体填充。

### 4_1 第一级：成象——双方关系结构

> "成象之端，先于日辰，而用传年命则又扶救始终之通象也。"

"成象"就是卷一四课加临的落地版，专用于"人我对待"之事（干贵、求财、谋事、交涉）：

+ **日动为我（谋望者），辰静为人（所谋对象）**；
+ 辰上神生合日干 → 对方有情；将吉气吉 → 更吉；
+ 战克 → 凶；相刑 → 不投；相冲 → 难合；相害 → 有阻；相破 → 无成；
+ **辰阴（对方背后）**生制辰阳 → 对方有相为之心，但**阴神制之 → 虽有心而畏忌不果，不可恃**；辰阴所乘天官 = 其所畏之人、所忌之事（乘太常→畏父母尊长；乘天后→畏妇女；乘勾陈→忌争斗；乘朱雀→忌口舌）；
+ 辰阴生比辰阳、又与日干作合 → **彼中必有暗中撮合之人**，可恃；撮合人即视其所乘天官。

**这是《壬归》最独特、也最被低估的一块**：**阴神 = 背后的人与动机**。断谋望、婚姻、交涉，不看阴神只看表面生克，准确率天花板很低。

### 4_2 第二级：通象——三传与年命的扶救

> "休咎之几，关于发用；转移之妙，乃属中传；末为底止之乡，式中所系……**扶救虽有三传，紧关则由年命**。"（卷三《谋望门》）

"通象"解决的是**救应问题**——成象已凶，有没有翻盘可能？

+ **年命优先级极高**："日用不可伤残，命年最宜和好"；"日年交制，自启乖违；命被辰伤，却非我利"；**命制类 → 可言财；类制命年 → 当同鬼论**；
+ 年主**当前气运**，命主**生平根基**，年命现于课传则事情更准更显；
+ 三传的"出入之异、去就攸分"：支发用传出生合干 → 人来就我；干发用传入生合支 → 我往就彼；
+ **专类重于泛类**（见下）：救应也要对应到正确的类上，否则是无效救应。

### 4_3 第三级：推类——类象与成象的交叉验证

> "事涉干求，可否虽操于象内；情关得失，吉凶更出于类中。**象吉类凶，象难全恃；类吉象凶，类亦难凭。相需并用，占法斯全。**"

这段话是全书的**校验法则**：四课三传（象）说得通、类神（类）却凶 → 不能全信吉；类神吉、象却凶 → 类也不能单独作凭。**必须两者互相印证**。

原文给出的**取舍细则**（实操性极强）：

+ **类神出现于课传** → 以类神为主；
+ **类神不出课传** → 以课传（成象）判断；
+ 但**某些占类（如占行人、占来意）即使类神不出，也必须以类神为主**——这是特例，需单独记；
+ **"有吉无凶，主堪进取"**：吉凶可否，岂易言哉——只有当救应结构清晰、凶神有制时，才可断"可进"。

### 4_4 第四级：引伸——规则的边界与"权变"

> "苟能握其关键，悉其肯綮，则一纲举而万目张……引伸触类，其在人乎？"

"引伸"是方法论的最后一层：**承认规则有边界，把裁量权交还给使用者**。它包含三个要点——

1. **专类与泛类**：干贵以天乙为**泛类**，具体事项的**专类**更优先，"专类重于泛类"（如求文职功名，青龙即专类）；
2. **变通取位**：正类不现，依次取变通位（青龙→功曹→太常），"将即神、神即将"；
3. **遁干的明暗双层**：卷三《谋望门》末只立**总则**一句——"明吉而遁凶，是必防其暗损；明凶而遁吉，尚有与其默益"。下列八条组合（财遁鬼、鬼遁鬼、父遁鬼……）为**后世壬家遁干通法，原文未逐条列举**，用时须知其所出：
    - 妻财遁鬼 → 财藏鬼（鬼财），取财有祸；
    - 官鬼遁鬼 → 明暗鬼，凶甚；
    - 父母遁鬼 → 生中有鬼，明生暗克；
    - 兄弟遁鬼 → 明助暗损（背后鬼）；
    - 子孙遁鬼 → 救中藏祸（子化鬼）；
    - 妻财遁兄弟 → 明得暗失（暗劫）；
    - 妻财遁财 → 明暗财，求财丰富；
    - 官鬼遁父母 → 凶中藏吉（暗生）；
    - 官鬼遁财 → 鬼化财（鬼财），取之有祸。

> **核心口诀**："**明吉而遁凶，是必防其暗损；明凶而遁吉，尚有与其默益。**"（卷三《谋望门》末）
>
> **关于空亡**：原文只立两条——**"惟类自作空，不以空论"**（卷七《三才门》，类神本位自空不作空亡断）与**"若日年落空，百事无成"**。**"遁干亦不以空论"及"庚午日戌亥旬空、戌遁甲为日财，求财必得"之例，出自后世注解，原文无此明文。**
>
> 这条细则正是《壬归》里最容易被现代注解讲错、也最能拉开断课水平的地方——用时宜分别原文与通法，勿混为一谈。

### 4_5 卷四至卷七：框架已备，按类查表即可

| 卷 | 门类 | 可取的结构（不必通读） |
| --- | --- | --- |
| 卷四 | 婚姻门 | **干支正象 → 用传变象 → 类神定象 → 品貌根源 → 命年关系 → 成后迟速始终琐象 → 古今占验**：一套完整的分类占模板，**可复制到其他门类** |
| 卷五 | 农事门 | 农圃定象、类神定象、象类约略、蚕桑象类、加临定象、吉凶琐象——**类象词典**，按所问查 |
| 卷六 | 出行门 | **十三占例**：总象、动静、迟速、吉凶、水陆、阴晴风雨、伴侣、赀本行李、投宿、启行、见闻有疑、期会、家内吉凶——**把一件事拆成十三个子问题**的分治思维值得学 |
| 卷七 | 三才门 | 天地人三才之用，归到"仰观天心、俯察地气、中通人事" |

**卷四以后正确的使用方式**：**不要从头读，要当词典查**。你占什么，就去对应门类里找"该类如何取类、如何定象、如何看变象"。它的价值在于**示范了一套可复制的模板**（卷四的结构几乎可原样套用到任何新门类），而不在于新增原理。

## 板块5 · 实操手册：一张纸走完一盘壬课

下面这张清单是全书方法的结构化落地，**打印出来贴在起课纸旁，按序执行，不跳步**。

### 5_1 Step 0｜起课前的纪律（决定课可不可信）

1. **一事一问**，问题具体化、时间窗口短（日内、旬内、月内最佳）；
2. 手工起课（九宗门），不要直接依赖软件——**手工排盘过程中你会提前"看见"结构**；
3. 校验：天地盘、四课、三传、天将、昼夜贵人、旬空、遁干，逐项核对一遍（软件最常见的错是贵人口诀与昼夜分界）；
4. **先问事理，再起课**：这件事在人世上"可能怎样的三种走向"先想清楚，课是用来**裁决与细化**的，不是用来凭空造故事的。

### 5_2 Step 1｜定体（对应"观四课之加临"）

- [ ] 干上神 vs 日干：生/克 → 我得势/受压
- [ ] 支上神 vs 日支：生/克 → 对方/环境状态
- [ ] 干上神 vs 支上神：生合/战克/刑冲害破 → **互动主轴**
- [ ] 干阴、支阴：→ **双方背后动机**（"情归于阴"）
- [ ] 四课空亡位：→ 信息残缺，不据此断实

### 5_3 Step 2｜定机（对应"察用神之生克"）

- [ ] 圈初传发用 → 在干两课（外/远/去）还是支两课（内/近/来）？
- [ ] 上克下 / 下克上 → 事态性质
- [ ] 发用临十二气的哪一位 → 死/败/绝/墓 = 止/败/结/隐
- [ ] 用太岁—月建—旬首—节气—本日—气首尺子 → **应期区间**
- [ ] 发用冲刑破害日/辰 → 隐患警报

### 5_4 Step 3｜定流（对应"明三传始终"）

- [ ] 初传 = 起因；中传 = 转折；末传 = 归计（**"休咎之机关于发用，转移之妙属中传"**）
- [ ] 有无递生链 → 末生日干 = 越后越利
- [ ] 出处异途 → 支发用传出生合干 = 人来就我（守）；干发用传入生合支 = 我往就彼（进）
- [ ] 凶在初传 → 末传有无子孙制克 / 父母化泄 / 干上克制 → **先凶后吉**
- [ ] 末传空亡 → 鬼传向空，虚惊无实
- [ ] 旺衰定迟速：旺吉 → 速；囚凶 → 迟

### 5_5 Step 4｜定类（对应"定贵神吉凶" + "推类"）

- [ ] 一事只取**一个正类**（先天将，再六亲，再支神）
- [ ] **专类重于泛类**（具体事项类神 > 天乙等泛类）
- [ ] 正类不现 → 取**变通位**（青龙→功曹→太常……"将即神，神即将"）
- [ ] 类神在课传中 = 事已显象、易成；课传无类 → 看本位方位，力度降档
- [ ] **类神的阴神** = 内情、根子（阳现其象，情归于阴）
- [ ] **象吉类凶 / 类吉象凶 → 必须交叉验证，不可单凭**

### 5_6 Step 5｜定旺衰（对应"理气"——全书成败关键）

对**类神**依次过四把尺：

- [ ] **五气**：旺相休囚死 → 当令否
- [ ] **十二长生**：临四吉（长生/冠带/临官/帝旺）→ 强；临八凶 → 弱
- [ ] **内外战**：乘神与将相较，战 = 不和 = 无气；**内战其将 = 忧重，外战其神 = 忧轻**
- [ ] **空亡**：落空 → 断路；**神自作空 → 待出旬**；**惟类自作空不以空论**

### 5_7 Step 6｜明暗双层校验（"明吉遁凶"法则）

- [ ] 排出类神的**遁干（旬干）**
- [ ] 对照八条遁干规则（财遁鬼/鬼遁鬼/父母遁鬼/兄弟遁鬼/子孙遁鬼/财遁兄弟/财遁财/鬼遁父母）→ 找"明吉遁凶"的暗损
- [ ] **惟类自作空，不以空论**（卷七）；日年落空则百事无成。遁干是否论空，原文未明，属后世通法

### 5_8 Step 7｜八煞校准

- [ ] 德（救应）、合（成事/绊住）、鬼（克我）、墓（隐滞）、破害刑冲（破坏递增）
- [ ] 优先看**发用、类神、年命**三处是否被伤

### 5_9 Step 8｜年命紧关（最后一道闸门）

- [ ] 日干不可伤残，命年最宜和好
- [ ] **命制类 → 可言财；类制命年 → 当同鬼论**
- [ ] 日年交制 → 自启乖违；命被辰伤 → 非我利
- [ ] 日年落空 → 百事无成

### 5_10 Step 9｜落四象限，一句话出断

```plain
成 / 不成（性质） + 速 / 迟（能量） + 实 / 虚（空亡、遁干校验）

```

**模板**：「类神得气临四吉、三传递生、年命无伤 → **事可成，且速且实**；但遁干见财遁鬼，故**成中防暗损**，宜取之有道。」

> 一句话里**同时包含"成/不成"与"隐患"**，才算合格的壬课断语。**只断吉凶两端、不给出"但书"的，都是未完成品。**

## 板块6 · 把壬法翻译成通用决策法（这是本书真正值钱的地方）

抛开术数外壳，《壬归》描述的是一套**几乎可以照搬到任何决策场景**的思维流程。这一段是对原文最高级的"不简单复述"。

### 6_1 五层结构 = 一份决策备忘录

| 《壬归》层次 | 通用决策对应 | 你要回答的问题 |
| --- | --- | --- |
| 四课（体） | **利益相关方地图** | 我、对方、环境各自的状态与关系结构是什么？ |
| 用神（机） | **触发点与导火索** | 这件事是被什么事件点燃的？起因为在哪一方？ |
| 三传（流） | **时间轴推演** | 起初怎样、中途如何转折、最终归向何处？ |
| 类神（主） | **核心KPI / 单一主指标** | 这件事真正由哪一个指标定义成败？ |
| 旺衰（气） | **资源与时机** | 各方当下能量、筹码、时机到位了吗？ |

### 6_2 四条方法论，越界依然成立

**（1）先定体，再定用——先看结构，再找导火索**
创业、谈判、求职，第一件事永远是**把关系结构画出来**（谁需要谁、谁克谁、谁背后还有谁），而不是急着找"机会点"。**先问结构，再问机会**——这一条能避免绝大多数"看到一个利好就冲进去"的错误。

**（2）一事一类——给复杂问题设一个主指标**
"专类重于泛类"翻译成管理语言就是：**一个决策只能有一个主 KPI**。用"提升效率"去覆盖"控制风险"，结果一定是两头落空。**先把主指标钉死，其余全部作为约束条件**，这是分类占法最深刻的现代价值。

**（3）象吉类凶则象难全恃——主线与信号必须互证**
数据分析里叫"指标交叉验证"：宏观向好（象吉）但核心指标恶化（类凶），不能凭宏观下注。任何**单一信号决策**都是脆弱的；至少要有**一条主信号 + 一条独立来源验证**。

**（4）明吉遁凶，是必防其暗损——永远找第二层**
"阳现其象，情归于阴"。财报好看（明吉）但现金流结构恶化（遁凶）→ 不能投；合同条件优惠（明吉）但违约责任不对等（遁凶）→ 不能签。**任何决策都要主动去搜"反证"**：这件事在什么条件下会翻车？**找不到暗损的，往往是还没找到。**

### 6_3 旺衰定迟速 → 时机量化

"发用乘吉气旺 → 速；囚死乘凶 → 迟"这条，**在现代决策里就是"资源 × 时机 = 速度"**。同样的正确方向：

+ 团队到位、资金到位、窗口期打开（旺）→ 可以快；
+ 力量不足、时机未到（休囚）→ **慢就是优势**。

"理有当然，而气不必应"——**正确的事，不一定现在就该做**。这是"理以气应"给决策者最温柔也最关键的提醒：**判断正确，不等于时机正确；时机不到，就等。**

### 7_2 必记必背的最小知识集（不熟不要往下学）

1. **十二天将**象意 + **昼夜贵人**排布口诀；
2. **十二长生**（临官、帝旺、墓、绝、胎养）一眼能断；

### 7_3 避坑清单（来自文本与历代批注）

+ **坑一：空亡见解有误**。原书部分空亡论述被后世批为初级甚至有误（如"惟类自作空不以空论""神自作空待出旬"这类细则，与通行说法有出入）。**以《指南》《断案》案例为准校正，不盲从原文。**
+ **坑二：能断大方向，断不细**。本书强在框架，**弱在精细取象**，细节需补《心镜》《指南》会纂与占验。
+ **坑三：当择吉书用**。四卷本系统掺清代择吉内容，**不要把择吉规则混进占断**。
+ **坑四：贪多神煞**。本书精神恰恰相反——**"类本象分，象因类著"**，一类一事，神煞只做校准。**神煞超过三十个就是负担。**
+ **坑五：舍理言象**。"理先象后"是全书总纲，见象就断、不问事理人情，是新手最常见也最难自愈的病。
+ **坑六：逆序操作**。五道工序顺序即权重：**体 > 机 > 流 > 类 > 旺衰 > 遁干 > 八煞 > 年命**。跳到"取类"就急着断，必然惑于象。
+ **坑七：直接啃《断案》**。《断案》省略推导过程，基础未牢会读懵、进而放弃——**它是出口，不是入口。**
+ **坑八：无事来问 / 一题多问**。事不专一、时间窗口过长（如"小学生问何时出国留学"），课传必然答非所问——**六壬处理的是近机，不是终身算命。**

## 板块8 · 本书最大的三个洞见（我的判断）

**其一，"两言决耳"不是简化，是降噪。**
壬课信息密度极高，新手被神煞淹没、老手被自作聪明淹没。《壬归》把所有信号压缩成"性质 × 能量"一个矩阵，逼你做**加权裁决**而非**罗列吉凶**。这是它最现代、也最反人性的一点——**人天然喜欢多说，它要求你少说而准。**

**其二，"阳现其象，情归于阴"是全书最锋利的方法。**
任何天将、任何类神，都要去看它的阴神（地盘上神）。**表象是车，内情是驾驶员**。放到读人、读组织、读市场，这句话几乎可以作为座右铭：公告是阳，资金流向是阴；表态是阳，利益结构是阴。**永远去查第二层。**

**其三，"理以气应，占以理求"把主观体验关进了客观边界。**
它承认：我的判断再正确（理），若时机与力量不到位（气不应），事情照样不成。**这意味着术数（或任何分析模型）的上限，是它对"人世常情、事理逻辑"的拟合度，而不是它的符号系统有多精巧。** 同理反向成立：一个对人情世故一塌糊涂的人，学再多壬法也断不准——**阅历是这项技艺的地基，公式只是上面的房子。**
