## 板块2 · 先说结论：这本书的真正价值在哪里

《大六壬探原》，清末民初命理大家袁树珊（1881—1962）所著。袁树珊出身扬州医卜世家，精研六壬四十余年，荟萃《六壬寻原》《六壬经纬》《六壬大全》《毕法赋》等三十余种家藏古籍之精华，撰成此书，后收入《润德堂丛书》。

这本书最难得的一点，不在"秘传"，而在**祛魅**。

壬学向来的毛病是：治斯学者多非士人，纵然深明数理，下笔却"笔无机绪，辞不违旨"，把人看得一头雾水。袁树珊以家学为底、以士人笔法重写，全书力求"浅显浏亮，不务艰深"——**学者无须师承口授，自可一览会通**。这是全书的立意，也是我们今天读它的正确姿势：**把它当成一套"可复现、可校验"的推演系统来学，而不是当成咒语来背。**

全书分三篇，逻辑是一条完整的链路：

| 篇目 | 职能 | 一句话定位 |
| --- | --- | --- |
| **推演篇** | 搭建模型（起课） | "怎么把一盘正确地排出来" |
| **论断篇** | 分析判断（断课） | "怎么从一盘里读出吉凶" |
| **集说篇** | 理论升华 + 源流 | "古人怎么想、有哪些课体格局、背后的人生态度" |

理解了这个三分法，整本书就不会读乱：**先有术，再有断，最后有道**。下面按这条线重构讲解。

## 板块3 · 总纲：起课与断课的两阶段模型

全书所有技法，可以压缩成一个两阶段模型。掌握这个模型，后面细节再多也不致迷失。

```plain
【第一阶段：起课（搭建时空模型）】
   定占时 → 定月将 → 排天地盘 → 十干寄宫 → 排四课 → 九宗门取三传
   → 排十二天将 → 配六亲 → 查年命、空亡
                    ↓
【第二阶段：断课（分析判断）】
   看课体 → 读类象 → 辨六亲 → 察生克刑害 → 定应期 → 出结论

```

**核心心法（入门总诀）**：

> 月将加时立地盘，四课分明主客辨；

取传先寻克处动，六亲定下用神现；
三传始终看走向，旺衰生克断凶吉；
**莫把神煞当根本，五行理气是真传。**

最后一句是全书的眼睛：**神煞是辅助，五行生克理气才是根本**。初学者最容易犯的错，就是死记"青龙主财、白虎主凶"之类的标签，却忘了看生克旺衰——那是舍本逐末。

---

**示例**：起课段（定时→布盘→四课→三传）产出「盘」，断课段（旺衰→类神→应期）产出「断」，两段分离。

## 板块4 · 推演篇精讲：把一盘正确地排出来

推演篇的章节次序即是起课的操作次序：**占时 → 月将 → 干支 → 四课 → 三传（附七百二十课三传对照表）→ 遁干 → 十二天将 → 五行生克定名 → 年命**。下面把每一步的重点、易错点、实操要点拆开讲。

### 4_1 占时：天机发于动，不可刻意挑

> 原文要旨：凡推演六壬，先定地盘。地盘即子丑寅卯辰巳午未申酉戌亥之十二占时。取法有三：有人口报时者，有雷击枣木制盒摇珠者，有筹置桶中抽取者。**六壬最重占时，如来人当面报时，不假思索，随口而出，天机活泼，其灵异常；稍一迟疑，则为人欲所蔽，断难命中。**

实操要点：

1. **优先"正时"**：以问事当下真实的时辰为准（北京时间转地方时，按地支取：23—1点为子，依次类推）。正时不明或多人同占，才用"活时"（报数、抽时、抓阄）。
2. **核心原则：天机发于动**。占时要随机、自然，不可刻意挑选。同一个时辰多人来占，用报数法（报数除十二取余数为占时）。
3. **纪律约束**：一占一事、一事不占再占。**不诚不占、不渎不占、不邪不占**——心不诚、反复占、问违法损人之事，都不可占。这是方法论，不是迷信：反复占会让"动"的信息被污染。

### 4_2 月将：中气换将，不是农历月份

月将是太阳在黄道十二宫的位置，位居天盘，随占时而顺布，**每交中气立即变更**。这是全篇最容易错的地方——**看的是"中气"，不是农历月份，也不是节气当天才换。**

**月将歌（必背）**：

| 中气之后 | 月将（神名） |  | 中气之后 | 月将（神名） |
| --- | --- | --- | --- | --- |
| 雨水后 | 亥（登明） |  | 处暑后 | 巳（太乙） |
| 春分后 | 戌（河魁） |  | 秋分后 | 辰（天罡） |
| 谷雨后 | 酉（从魁） |  | 霜降后 | 卯（太冲） |
| 小满后 | 申（传送） |  | 小雪后 | 寅（功曹） |
| 夏至后 | 未（小吉） |  | 冬至后 | 丑（大吉） |
| 大暑后 | 午（胜光） |  | 大寒后 | 子（神后） |

> 例：处暑之后，月将就是巳。直接查当日所在中气区间即可，不用管农历几月。

### 4_3 排天地盘：一个固定，一个转动

+ **地盘（永远固定）**：子丑寅卯辰巳午未申酉戌亥，对应方位子北、午南、卯东、酉西。袁树珊特别强调：**"地盘千载不移，天盘随时流转"**，地盘不熟就讲天盘，必致上下不分。
+ **天盘（月将加时，顺排十二支）**：
操作三步：「1」在地盘找到占时地支；「2」把月将放到地盘占时的位置上；「3」从此位顺时针把十二地支依次排完。

> **例**：月将亥，占时午 → 天盘亥加在地盘午位，顺排：午=亥、未=子、申=丑……依次一圈。

核对标准：地盘固定不动，天盘随地盘一一对应，排完逐位核对，不可错位。**这一步错，全盘皆错。**

### 4_4 十干寄宫与四课：主客、表里、显隐

**十干寄宫口诀（必背）**：

> 甲课寅兮乙课辰，丙戊课巳不须论；

丁己课未庚申上，辛戌壬亥是其真；
癸课原来丑宫坐，**分明不用四正神**。

即：甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑。注意阳干寄禄地、阴干寄冠带，**子午卯酉四正之位不寄**（这就是为什么叫"不用四正神"）。

**排四课**（四课：干阳、干阴、支阳、支阴）：

| 课 | 取法 | 象征 |
| --- | --- | --- |
| 第一课（干阳） | 日干寄宫地盘上的天盘神 | 我、外、显 |
| 第二课（干阴） | 第一课上神地盘上的天盘神 | 我之隐、内在 |
| 第三课（支阳） | 日支地盘上的天盘神 | 彼、事、内 |
| 第四课（支阴） | 第三课上神地盘上的天盘神 | 事之隐、环境 |

四课格式"上神/下神"，下神是地盘、上神是天盘。"下贼上"=地盘克天盘；"上克下"=天盘克地盘。

> **论断篇原文要旨**：第一课为日之阳神，第二课为日之阴神，第三课为辰之阳神，第四课为辰之阴神。**阳神占出现，阴神占伏藏，总以两阳为主，而阴次之。** 四课全者，事正顺而易；四课不全者，事不正逆而难。大抵见生、合、德、禄、旺、相者言吉；见克、害、刑、冲、空、墓者言凶。

这里的"不全"指四课上下神有重复（不备），意味着信息有缺、条件未齐，需待时补足——这是"不备课"的实操含义。

**干支关系的速断框架**（袁树珊原文精炼，极实用）：

| 关系 | 含义 |
| --- | --- |
| 支加干**生**干 | 彼就我、助我（吉） |
| 干加支**受生** | 我就彼、彼助我 |
| 支加干**克**干 | 彼就我、欺我（凶） |
| 干加支**受克** | 我就彼、受欺 |
| 支加干**比**干 | 彼就我、培我 |
| 干上神生支、支上神生干 | 彼此相生，两家顺利 |

再叠加旺衰、墓、败、绝、空亡，即可得到完整吉凶。袁树珊的高明处在于：**先限定"我/彼"二元框架，再层层叠加条件**，而不是一上手就堆神煞。

### 4_5 九宗门取三传：初、中、末即始、变、终

三传是全书的核心动力学结构：**初传=发端（起点），中传=移易（变化），末传=归计（结局）**。

九宗门优先级（依次尝试，命中即止）：

**贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟**

前四法最常用，务必吃透：

1. **贼克（第一法，优先）**：四课有上下克时，**下克上（贼）优先**；无贼再用上克下（克）。口诀："取课先从下贼呼，如无下贼上克初。"
2. **比用**：多克并存时，取与日干**阴阳同性**之克发用。
3. **涉害**：同克同气难以分辨时，取**受克次数多（涉害深）**者。袁树珊在凡例中特别指出"涉害课最难发用……《六壬大全》所载古歌甚是"，并依古歌浅深之法——这是原书**纠正古书讹误**的一处。
4. **遥克**：四课无上下克而有遥克（课中神与神之间相隔相克）时取用。

**中传、末传的取法**：初传定后，中传取"初传天盘对应地盘上的天盘神"，末传取"中传天盘对应地盘上的天盘神"——即顺着天盘链条一路取下去（这是"连茹"等课体的来源）。

**发用（初传）速断**：发用是矛盾炸开的那一点，代表事最直接的推手。发用逢贵人、青龙且得生，即使后传稍凶也能翻盘；发用逢螣蛇、白虎且来克日干，即便末传尚可也要防暗中出问题。**问病时发用坐病符来克，第一件事是查对应部位，不要拖。**

### 4_6 三传的几条核心吉凶法则（论断篇精要）

这是全书最值得反复咀嚼的一段，原文摘录+白话重构如下：

> **"课为体，传为用。传吉课凶，事终吉；传凶课吉，事少成。"**

—— 三传是动态走向，比静态的四课更决定结局。

| 法则 | 含义 |
| --- | --- |
| 初传神将比和、上下相生、逢德禄 | 举事称心，虽危有救 |
| 初凶中吉 → 移凶为吉；初吉中凶 → 移吉为凶 | 中传是"变"的枢纽 |
| 母传子（生进）则顺；子传母（生退）则逆 | 三传相生为顺 |
| 鬼（官鬼）主事坏；墓主事止 | 末传见鬼见墓，事难成 |
| 害为折腰、破为中辍、空为断桥 | 中传逢之，事体不成 |
| 初传=日之长生、末传=日之墓库 → 有始无终 | 始终对比看格局 |
| 初墓末长 → 先难后易 | 反之上句 |
| **末传克初传（终来克始）** | 远行万里、入水不溺，**转凶为吉之象** |

**三传与干支的相对位置**（判断"谁求谁"）：

+ **朝枝格**：三传自干上发用、传归支上 → 我去求人干事，不得自由。
+ **朝日格**：自支上发用、传归干上 → 人来托我干事，易于成合。
+ **如珠走盘**：三传不离四课 → 谋事成，吉则吉、凶则凶；但**忌占病讼、忧产**。
+ 三传不离干支 → 求物得、谋事遂、行人回。

**天将的"内战/外战"**：将克神（天将克地盘神）= 外战，忧轻、虽凶可解；神克将（地盘神克天将）= 内战，忧重、虽吉有咎。**判断吉凶时，要先看是"内"还是"外"。**

**空亡法则**：三传皆空，事了无一实；两传空、一传实又见天空，亦作三传空论；初、中传空以末传为主，中、末空以初传为主。

### 4_7 十二天将、六亲、年命：完成盘面

**十二天将**（顺序、昼夜顺逆以贵人为准）：

> 贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后

贵人取法：昼贵、夜贵依日干定（阳贵、阴贵），再据占时顺逆排完十二将。**天将看"性情与性质"，地盘神看"本体"**，二者组合生克才出吉凶——切勿单看天将标签。

**六亲**（以**日干**为基准，这是最容易错的地方）：

> 生我者父母，我生者子孙，克我者官鬼，我克者妻财，比和者兄弟。

**年命**：行年所到之宫 + 人受生之年（本命）的干支。男一岁起丙寅、女一岁起壬申（遵《六壬大全》"天开于子、地辟于丑、人生于寅"之序）。**年命是断课的第二条纲领——每次判断前，首先看空亡，其次紧扣年命。** 本命入式，优先取本命为类神。

## 板块5 · 论断篇精讲：怎么从一盘读出吉凶

论断篇自"论占时"到"论次客"共二十余章，逻辑是一条**由主到次、由体到用**的判断链。下面把它重构成一套**可复用的断课七步法**，这是本书最可落地实操的部分。

### 5_1 断课七步法（实操标准流程）

**第1步：看日干旺衰 —— 定自身"底气"**
日干代表求测者。先看日干在月令的旺相休囚死（见下），旺相则有支撑，休囚则自身无力。**"旺禄临身徒妄作"**：日干临旺禄得旺，说明状态安稳，不必瞎折腾，折腾反坏事。

**第2步：定类神、取用神 —— 事情"有没有"**
根据所问事项，确定核心类神（见 4.3）。类神不入课传，所占事难成——这是一条硬判据。

**第3步：看四课 —— 现状、表里、主客**
干为外/我，支为内/事；阳神为显、阴神为伏藏。看干支上下神的生克、刑冲合害。**"干上神生干，大吉；干上神克干，大凶；干生上神，虚耗百出；干克上神，阻隔重逢。"**

**第4步：看三传 —— 始、中、末的走向**
初传发端、中传移易、末传归计。**顺着三传看发展**，重点看发用与末传对日干的生克：末传生扶日干则结局好，末传克害日干则结局差；末传归干（落到自己）、归支（落到对方）、归空亡（一场空）。

**第5步：看天将 + 神煞 —— 吉凶性质与关键节点**
天将看性情，神煞看特殊节点（驿马主动、丁神主变、德主解救、墓主停止）。**神将组合**是读象的核心来源。

**第6步：看旺衰 + 墓库 + 空亡 —— 力度与虚实**
四课看表里人心，三传看始末走势，神将看吉凶性质，**长生/墓/空/旺衰决定力度虚实**。这一步是把前面的"定性"量化为"多强、多久"。

**第7步：出结论、给指引 —— 落地为行动**
不只用"吉/凶"二字收尾，而要给出可执行建议：

+ **能成的事**：何时成、注意什么、怎么借力；
+ **不成的事**：问题在哪、为何不成、要不要等、如何规避；
+ **有风险的事**：风险点在哪、如何化解、要不要放弃。

> 大忌：**拿不准的事不说死，留有余地，不危言耸听。**

### 5_2 旺相休囚死：判断力度的尺子

| 状态 | 判定（以月令为准） | 力量 |
| --- | --- | --- |
| 旺 | 与月建同五行（如寅月木旺） | 最足 |
| 相 | 月建所生之气（木月火相） | 次强 |
| 休 | 生月建之气（木月水休） | 偏弱 |
| 囚 | 克月建之气（木月金囚） | 被压 |
| 死 | 月建所克之气（木月土死） | 耗尽 |

**实操法则**：

+ 落宫（地盘十二长生）旺相 + 月令旺相 = 锦上添花；落宫死墓绝败 + 月令休囚 = 雪上加霜。
+ **旺相放大吉凶，休囚削弱吉凶，死绝根基破碎难挽回。**
+ 用神落宫旺相、月令旺相 → 好上加好；落宫不好而月令旺相 → 眼下不至于太凶；月令休囚而落宫旺相 → 待时令旺时方发。
+ **"旺气发用为现在事，相气发用为未来事，休囚发用为过去事"**（徐养浩《六壬金铰剪》引述，与《探原》理法一致）。所以"旺相者多应，休囚者多散"。

**墓库**：墓分"收藏吉"与"束缚凶"；**冲墓才能动，不冲则积压不动**。

**空亡（五类空亡口诀）**：

> 金空则鸣，火空则发，土空则通，木空则朽，水空则枯。

空亡统一减半力量，吉变弱、凶变淡；完全落空为"极空"，事了无一实。填实规则：本旬空亡（如甲子旬戌亥空）较难填实，须旺相气足方可；落地空亡则无论旺衰极易填实。**初传空则气数往下传，末传再往下传，最多传两下。**

### 5_3 类神取法：问什么，取什么象

类神取自**六亲、天将、月将、神煞**四大类象，规则如下（网络教程拓展，与《探原》理法相合）：

**取象优先级**：**正象（六亲为主）> 偏象（天将/月将/神煞）> 支辰（盘中寻找）**。正偏象并为一神时，应事最准（如占婚财爻又乘天后）。

| 所问事项 | 类神（正象为主） |
| --- | --- |
| 求财 | 妻财爻 + 青龙（财临干=财来找我；干临财=我去求财；财入传=可求；财空=虚财） |
| 婚姻（男） | 妻财 + 天后；女占：官鬼 + 青龙 |
| 考试功名 | 官鬼 + 朱雀、父母（文书） |
| 疾病 | 白虎（病符）+ 天医（解） |
| 出行 | 驿马 + 丁神 + 道路（申）+ 门户（卯） |
| 官非 | 勾陈 + 朱雀 + 刑害 |
| 子孙/小孩 | 子孙爻 + 六合 |

**核心原则**：类神**必须入课传**方有验；正象偏象俱不入式，方可以支辰为类。**类神是判断应期的钥匙**（见 4.4）。

### 5_4 应期：事情什么时候发生

这是最实用也最难的部分。《探原·论断篇》论应期 + **《中黄歌》** + 历代心法，可归纳为**五法**：

**底层逻辑：类神是关键，空亡是开关，合冲是扳机。**

**「1」 类神所临地支法（最直接）**：看类神天盘所加临的地盘地支。

> 口诀：财临午上，午月午日见财；官临寅上，寅月寅日得职。

近事以日断、远事以月断、再远以年断。

**「2」 空亡填实法（悬而未决的落点）**：

> 口诀：空亡必待填实，或待冲空而出。

+ offer 迟迟不到，官鬼空亡在"未" → 未日/未月填实，消息必来；或逢丑日冲空，也能打破僵局。
+ 找东西找不到，类神空亡 → 东西没丢，填实之日自然出现。
+ 若空亡爻恰是日干禄神或财爻，填实之日往往伴随进财。

**「3」 合冲法（事态的扳机）**：合则聚、冲则散。

> 占好事：逢冲则散、逢合则成；占坏事：逢合则滞、逢冲则解。

**「4」 《中黄歌》法（发用下位推）**：

> 先别木金火水土，即将下位上神推。

用神为亥子 → 寻天盘丑所临之神；
用神归寅卯 → 寻天盘辰（天罡）所立；
用神巳午 → 寻天盘未位……（依次类推，午神用丑下、未神用寅下，循环取"发用下一位"）。

**「5」 课体大局法**：

+ 用起太岁 → 应一年内；用起月建 → 本月内；用起日干 → 即日；用起旬首 → 本旬内；用起四立之日 → 本季内；用起正时 → 当下。
+ **伏吟以冲为应期，返吟以合为应期**（伏吟不动故待冲，返吟反复故待合）。
+ 三合课各以墓为期；三合缺一，缺字为应期。

**迟速、远近的辅助判断**（出自《集说篇·论迟速/远近》）：

+ **速**：干支在贵人前、发用在贵人前、干支入传、斩关课、传见占时/丁神/驿马/贵人顺行、发用在日辰前。
+ **迟**：伏吟、涉害、传见空/墓、贵人逆行、发用在日辰后。
+ **远近**：发用类神临干为近，临干阴次之，隔一二三位渐远，七位极远，逾七位反近；以衰旺言，休囚为近、旺相为远。

### 5_5 神将组合速断（读象干货，网络教程拓展）

读象的诀窍是"象不唯一"，**必须结合求测人提供的背景缩小取象范围**。几组高频组合：

| 组合 | 含义 |
| --- | --- |
| 贵人 + 朱雀 | 贵人管文书，公职人员升迁有戏；但签合同时多核细节 |
| 白虎 + 劫煞 | 易有突发血光；若在末传，凶劲大减可转 |
| 太阴 + 桃花 | 隐秘情事，结合干支三合可推方向 |
| 青龙 + 禄/财 | 财运亨通、喜庆 |
| 朱雀临日干 | 口舌是非；朱雀生干则文章得力 |
| 地支藏干透出 | 看背后藏象：申藏壬，逢玄武 → 暗中有钱财流动；未藏丁，逢朱雀 → 文书可能被动过 |

**五行通关（死局能破）**：三传全来克日干时，若日干一方有通关之神，可破凶局。例：三传寅卯辰木局克戊土日干，若有火在中通关（木生火、火生土），则凶转吉。

## 板块6 · 集说篇精讲：课体、格局与壬学之道

集说篇收录古人名论、课体纲要、源流考证，并附先贤传略。它把前面零散的技法**上升到"格局"层面**，是"由术入道"的一级。

### 6_1 《毕法赋》精选：拿来就能用的断事公式

《毕法赋》一百句，被《四库全书》评为"独为精当"。精选最核心十余句，**每句对应一类格局，碰到了直接用**：

**格局与吉凶**

| 口诀 | 含义 |
| --- | --- |
| 前后引从升迁吉 | 初末传引从日干/支 → 贵人提携，求官迁居吉 |
| 首尾相见始终宜 | 旬首加日干、旬尾加日支 → 事有始终，宜长线 |
| 六阳数足须公用 | 三传纯阳 → 利公事，宜公开不宜密谋 |
| 六阴相继尽昏迷 | 三传纯阴 → 晦暗不明，宜静守不宜动 |
| 万事喜忻三六合 | 三合六合主喜庆 |
| 合中犯杀蜜中砒 | 合中带刑害 → 吉中藏凶 |
| 三传递生人举荐 | 传生干 → 有人推荐、层层提拔 |
| 三传互克众人欺 | 传克干 → 众人欺压、处处碰壁 |

**财与官**

| 口诀 | 含义 |
| --- | --- |
| 传财化鬼财休觅 | 财生鬼 → 求财反招灾，钱未到麻烦先来 |
| 传鬼化财钱险危 | 鬼生财 → 险中求财，后患大 |
| 传财太旺反财亏 | 三传全财又太旺 → 物极必反，反主破财 |
| 权摄不正禄临支 | 禄在支上 → 代理职务、职权不正 |
| 彼求我事支传干 | 支→干 → 他人来求我（被动成事） |
| 我求彼事干传支 | 干→支 → 我求他人（主动谋为） |

**疾病与其他**

| 口诀 | 含义 |
| --- | --- |
| 虎临干鬼凶速速 | 白虎临官鬼克干 → 凶事速发 |
| 龙加生气吉迟迟 | 青龙临生气 → 吉事迟缓 |
| 干乘墓虎无占病 | 日干乘墓虎 → 病重 |
| 后合占婚岂用媒 | 天后、六合入课 → 婚姻可成，无需媒人 |
| 上下皆合两心齐 | 干支上下相合 → 合作顺利、心意相通 |
| 干支皆败事倾颓 | 干支坐沐浴败地 → 人宅颓废 |
| 旺禄临身徒妄作 | 日干旺禄得旺 → 守成即可，勿妄动 |

**读象活法（重点）**：**"进茹空亡宜退步，退茹空亡进用宜"**——进茹课逢空，往前冲是坑，反该退；退茹课逢空，退也退不了，反该进。**这就是"活看"，不能死套格局。** 任何口诀都要回到"五行理气"这一根本。

### 6_2 《课体纲要》与十二天将乘神生克

课体（如元首、伏吟、返吟、稼穑、斩关、游子、回环等）是**对三传四课结构的分类命名**，每类有固定吉凶倾向：

+ **反吟**：事有反复、速动（占病：近病速愈、久病速凶）。
+ **伏吟**：不动、迟缓，以冲为应期。
+ **稼穑**（三传辰戌丑未无丁神）：宜静不宜动。
+ **斩关/游子**（三传辰戌丑未见丁神）：宜动。
+ **回环**：事在熟悉环境展开。

**天将乘神生克法则**：将克神=外战（轻、可解）；神克将=内战（重、有咎）。判断时先看"内外"，再看吉凶。

### 6_3 《集说篇》的"二十论"：一套完整的认知框架

集说篇后半部以"论显晦、论虚实、论向背、论进退、论存亡、论男女、论老少、论新旧、论贵贱、论亲疏、论左右、论高低、论胜负、论动静、论迟速、论远近、论方所"等二十余个"论"字诀，**把人事的所有维度都纳入了壬学判断**。这是全书的"元模型"——它告诉我们：断课的本质是**对"关系"做结构化分析**。举几例：

+ **论动静**：干支主静，三传主动。"干枝有生意宜动，若传见凶将则宜静；干枝见恶煞宜静，若传见扶助则宜动。" 斩关、游子宜动；稼穑、墓、合宜静。
+ **论显晦**：阳神为显、阴神为晦；神将得气为显，落空陷为晦。
+ **论向背**：天将临生旺为有气向我（向），临死绝为空亡背我（背）。
+ **论方所**：子为江湖、寅卯为山林、午为市道路、申为园场道路……"盖木主曲直，水为大溪也"——**读象要随五行本性类推，触类旁通，未可执一**。

> 例：寅卯为山林，得木火旺相入课传 → 林中时新果品；被克 → 破林断木；休囚 → 枯朽林木；乘天空 → 林下多尿粪；加亥子 → 丛林大溪。**同一个"寅卯"，因旺衰、生克、天将而象完全不同。**

### 6_4 源流、凡例与先贤传略：为学之态度

集说篇末附司马季主、严君平传略及"星卜家事迹""卖卜格言""占卜一斑录"等，并非闲笔，而是**借古人风骨立"术者之德"**：

+ **《卜筮论》《卖卜格言》主旨**：卜筮之用，"**知来藏往**"而已；术者当心存敬畏、不以术敛财欺人。**"不诚不占、不渎不占、不邪不占"** 是贯穿全书的伦理底线。
+ **《琐记》《问答》**：袁树珊对《六壬大全》等古书的辨疑与补正，如涉害课发用之浅深法、贵人顺逆遵《寻原》与《协纪辨方书》、月将遵《协纪辨方书》交中气始换等——**这是他"荟萃诸家、去伪存真"的具体实践。**

3. **空亡统一减半力量**；吉变弱、凶变淡，完全落空为极空。
4. **旺相放大吉凶，休囚削弱吉凶**，死绝根基破碎难挽回。
5. **不可单看长生吉、死绝凶**，必须搭配天将、三传整体格局。
6. **月将看中气，不是农历月**；换将在中气交节那一刻。
7. **地盘不熟不要排天盘**；天盘错则全盘错。
8. **类神不入课传，事难成**——这是硬判据。
9. **不把神煞当根本，五行理气是真传**；口诀要活看，不能死套。
10. **一占一事、不反复占**；不诚、不渎、不邪不占。

---

**示例**：十二长生误用地支自定而不以日干为基，是新手高频错误。

## 板块10 · 进阶指引：从《探原》走向深入

《探原》的定位是**"由浅即深、登堂入室"的阶梯**。袁树珊在凡例中说："《课经》《毕法》，议论精深，乃壬学之圭臬，惜卷帙浩繁，初学读之……"——所以他做了删繁就简的工作。一旦把《探原》吃透，可顺势进阶：

1. **《毕法赋》全本** + 《课经》（《六壬大全》卷三）：补齐 64 课格与完整口诀体系。
2. **《大六壬指南》（陈公献）**：以"占验"为本，学真实断案的取舍逻辑——**"用在日前事情已过，用居日后事起将来"** 等应期心法即出于此。
3. **《六壬金铰剪》（徐养浩）**：旺衰、空亡、应期的系统化深化。
4. **《六壬大全》《六壬寻原》**：袁树珊编纂《探原》的主要参考书，可回查他删改取舍的原始依据。

**最重要的学习方法**：用《探原》的七百二十课三传对照表做校验，每起一课，先对照表格核三传是否正确，再独立断一遍，最后用事后结果复盘。**"可复现、可校验"才是把壬学讲通的正路。**

## 板块11 · 结语

袁树珊写《大六壬探原》，做的其实是一件朴素的事：**把一套被神秘化、被口授化的系统，用清晰的秩序重新讲一遍。** "次序鳞列"四个字，就是全书的编纂哲学——按占时、月将、干支、四课、三传、遁干、天将、六亲、年命的顺序，一步不乱。

读懂这本书的关键，不在记住多少口诀，而在于掌握那条贯穿始终的逻辑线：

> **定时空（天地盘）→ 立主客（四课）→ 明走向（三传）→ 配性质（天将六亲）→ 量力度（旺衰空墓）→ 断应期（类神合冲）→ 出行动（落地指引）**

术的尽头是道，道的落脚是**知行合一的判断力**。正如《毕法赋》所教：**同样一句口诀，不同的人、不同的事，解读完全不同。真正的本事，是结合实际情况，看透背后的人性与利益纠葛。** 这，或许才是"探原"二字最深的含义——**探其本原，归于理性。**

**用法示例**：袁树珊把口授系统「用清晰次序重讲一遍」——读完后你能手排一盘、按七步断一课，即是「次序」二字的兑现。
