## 板块1 · 全书总纲：三境论与"辨非"的底层逻辑

### 1_1 三境分层：适道 → 与立 → 与权

刘赤江在自序中借孔子"学有适道、与立、与权"之分，为全书定了调：

| 境界 | 对应内容 | 实质 | 研习定位 |
| --- | --- | --- | --- |
| **适道** | 《毕法补谈》 | 规矩、法则、入门正路 | 掌握"正确的方法" |
| **与立** | 《指南汇笺》 | 成例、格局、标准范式 | 建立"判断的坐标" |
| **与权** | 陈公献、郭御青占验 | 变通、灵活运用 | 达到"神明存乎其人" |

**关键解读**：六壬之术"不外乎此矣"。这告诉我们——**先求"适道"之正，再求"与权"之变**。跳过规矩直接求神妙，是绝大多数初学者的通病。本书的体系化价值，正在于把"权变"建立在扎实的"道"与"立"之上。

### 1_2 "辨非十则"：不是枝节考据，而是地基工程

卷一"辨非十则"辨析了月将、十干贵人、旦暮贵人、五行十干生墓等十个争议规则。表面上是对前人谬误的纠弹，实质上是在回答一个根本问题：

> **当各家说法矛盾时，以何为据？**

作者的回答清晰有力：**以中气（太阳过宫）为准，以实例验证为归**。

#### 1_2_1 重点辨析及实操含义

**（1）月将：从中气，不从月令合神，更不取河图生成数**

+ **原误**：有用"月令合神"者（自我作古，似是而非）；有姚广孝用"河图生成之数"超接者（荒唐不可从）。
+ **正法**：每月**中气**为太阳过宫躔辰，其法"至精至确"。
+ **实操落地**：起课定月将，**严格按二十四节气的中气切换**，绝不可用农历月份或"正月起亥"之类死板口诀硬套。

| 月将 | 对应节气区间（中气为准） | 古名 |
| --- | --- | --- |
| 登明（亥） | 雨水 → 春分 | 正月将 |
| 河魁（戌） | 春分 → 谷雨 | 二月将 |
| 从魁（酉） | 谷雨 → 小满 | 三月将 |
| 传送（申） | 小满 → 夏至 | 四月将 |
| 小吉（未） | 夏至 → 大暑 | 五月将 |
| 太乙（巳） | 处暑 → 秋分 | 七月将 |
| 天罡（辰） | 秋分 → 霜降 | 八月将 |
| 太冲（卯） | 霜降 → 小雪 | 九月将 |
| 功曹（寅） | 小雪 → 冬至 | 十月将 |
| 大吉（丑） | 冬至 → 大寒 | 十一月将 |
| 神后（子） | 大寒 → 雨水 | 十二月将 |

> **记忆口诀**：雨水亥、春分戌、谷雨酉、小满申、夏至未、大暑午、处暑巳、秋分辰、霜降卯、小雪寅、冬至丑、大寒子。

**（2）十干贵人：甲戊庚俱用丑未**

+ **争议**：《通龟》《订讹》主张甲戊庚用丑未、六辛用寅午；《曾门》《金匮》则庚辛皆用寅午。
+ **正法**：以《协纪》及子平天乙贵人相参，**甲戊庚同用丑未**，"确乎其不可易"。
+ **实操落地**：贵人起法口诀务必记准：

```plain
甲戊庚牛羊，乙己鼠猴乡，
丙丁猪鸡位，壬癸蛇兔藏，
六辛逢马虎，此是贵人方。

```

**（3）旦暮贵人：以六时分界，不刻舟求剑**

+ **正法**：得卯辰巳午未申六时用**阳贵**；得酉戌亥子丑寅六时用**阴贵**。
+ **反例批判**：若"日占即用日贵、夜占即用夜贵"，则日占者多、夜占者少，偏而不全；又有人以日出日落定旦暮，属"刻舟求剑"。
+ **实操落地**：**直接按占时地支所属六时定阴阳贵**，简单明确，无需考虑日出日落等复杂因素。

**（4）五行十干生墓：六壬不用子平法**

+ **辨析**：起长生、日墓之法有"五行"（不论阴阳，一例顺行）与"十干"（分阴阳顺逆）之别。临官即日禄，**但此法乃子平家所用，六壬向无此类**。
+ **实操含义**：切勿把八字命理的"十干长生"体系混进六壬，这是典型的"误用别家之法"。

## 板块2 · 起课全流程：七步标准化操作（可直接照做）

> 以下流程整合了本书卷二"立课"、卷三"经课"之法与网络教程的实操经验，形成一套**可复用、可校验**的标准步骤。

### 2_1 第 0 步：明确前提与禁忌

| 原则 | 说明 |
| --- | --- |
| 一事一占 | 同一件事反复占（不渎），越占越乱 |
| 心念专一 | 意念不专则"神不告"（实为自心之神不现） |
| 随机取时 | 占时取当下真实时辰（正时），不可刻意挑选 |
| 择象贴合 | 一课万象，择贴切于事者用之，散漫无稽者略之 |

### 2_2 第 1 步：定四要素

1. **日干支**：占问当天的干支（查万年历）。
2. **占时**：当下时辰地支（子—亥）。
3. **月将**：依上表，按当月**中气**确定（核心，务必准确）。
4. **十干寄宫**：天干落入地盘的位置。

```plain
甲课寅兮乙课辰，丙戊课巳不须论，
丁己课未庚申上，辛戌壬亥是其真，
癸课原来丑宫坐，分明不用四正神。

```

| 天干 | 寄宫 | 天干 | 寄宫 |
| --- | --- | --- | --- |
| 甲 | 寅 | 己 | 未 |
| 乙 | 辰 | 庚 | 申 |
| 丙 | 巳 | 辛 | 戌 |
| 丁 | 未 | 壬 | 亥 |
| 戊 | 巳 | 癸 | 丑 |

> 规律：**阳干寄禄，阴干寄冠带**（阳干→帝旺位，阴干→冠带位）。

### 2_3 第 2 步：布天地盘

+ **地盘（永远固定）**：

```plain
        巳 午 未 申
        辰       酉
        卯       戌
        寅 丑 子 亥

```

+ **天盘**：**月将加占时**——把月将放到地盘"占时"位上，顺时针顺排十二支。

> **校验技巧**：天盘排完后，地盘固定、天盘随地盘一一对应，务必核对"孟对孟、仲对仲、季对季"（寅巳申亥为孟，子卯午酉为仲，丑辰未戌为季），可快速自查对错。

### 2_4 第 3 步：立四课（明主客、阴阳、显隐）

以**日干为主体、日支为客体**：

| 课序 | 名称 | 取法 |
| --- | --- | --- |
| 第一课 | 干阳（干上） | 干宫（日干寄宫）地盘上的**天盘神** |
| 第二课 | 干阴 | 取第一课上神地盘，再看其上天盘 |
| 第三课 | 支阳（支上） | 日支地盘上的**天盘神** |
| 第四课 | 支阴 | 取第三课上神地盘，再看其上天盘 |

+ 格式：上神 / 下神，共四组。
+ **下克上 = 贼**（地盘克天盘）；**上克下 = 克**（天盘克地盘）。
+ **阳神主象（显），阴神主情（隐）**——这是断课的深层抓手（详见后文"阴神落处"）。

### 2_5 第 4 步：取三传（九宗门定脉络）

按优先级依次判断（**先贼克，后比用，再涉害……**）：

```plain
贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟

```

**九宗门速记与要点**：

| 法门 | 适用情形 | 取用要点 |
| --- | --- | --- |
| **贼克** | 四课有下克上（优先）或上克下 | 取克处为初传 |
| **比用** | 克多（二三处） | 与日干阴阳**相比**者取用 |
| **涉害** | 俱比，取孟位（见机）→ 仲位（察微） | "有害不可不见其机，不可不察其微" |
| **遥克** | 四课无克，有遥克 | 蒿矢（遥克轻微）、弹射 |
| **昴星** | 四课无克无遥 | 阳日取地盘酉上（仰）、阴日取天盘酉下（俯） |
| **别责** | 不备课（阴阳缺一） | 阳日取干五合上、阴日取支三合前位 |
| **八专** | 干支同位 | 顺逆布三神 |
| **伏吟/返吟** | 天地盘相同 / 冲克 | 特殊课体，主静守或反复 |

> **关键**：初传为**发用**（事情开端），中传为过程，末传为结局。三传既定，"入式之法第一"。

### 2_6 第 5 步：布天将（十二神）

1. 依贵人起法（第1步口诀）定贵人。
2. 贵人**顺逆分行**：看贵人所落地支，辨其顺行或逆行。
3. 十二天将依次排列：**贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后**。

> **核心原则**：天将本身吉凶是次要的，**天将所乘之神的生克关系才是根本**——吉神落受克之地则吉转凶，凶神落受克之地则凶险加倍（见卷四"要将"）。

### 2_7 第 6 步：配六亲、定用神、察旺衰

以**日干为基准**配六亲：

```plain
生我者 = 父母    我生者 = 子孙
克我者 = 官鬼    我克者 = 妻财    比和者 = 兄弟

```

+ **按占问事项定核心用神**：

| 占类 | 核心用神 | 辅助用神 |
| --- | --- | --- |
| 事业/求官 | 官鬼 | 贵人、禄、青龙 |
| 求财 | 妻财 | 青龙、丁马 |
| 考试 | 朱雀、魁罡、驿马 | 官鬼、贵人 |
| 婚姻 | 妻财（男）/ 官鬼（女） | 龙、后、六合 |
| 孕产 | 胎神、子孙 | 后、合、生气 |
| 疾病 | 官鬼、白虎、病符 | 天地二医、墓绝 |
| 盗贼/失物 | 玄武、官鬼 | 勾陈、脱气 |

+ **旺衰判断**：结合**月令（为主）、日辰、年命**综合判断——旺相休囚死。

> **进阶心法**（参考金口诀旺衰体系）：
>
> + **实旺**：课内得势 + 得时令帮扶 → 最强
> + **虚旺**：课内旺但不得时令 → 外强中干
> + **实弱**：课内衰弱 + 不得时令 → 最弱
> + **虚弱**：课内弱但得时令生扶 → 尚有转机

### 2_8 第 7 步：综合论断，输出可行动结论

**断课顺序**（层层递进，不可颠倒）：

```plain
① 日干旺衰（自身底气）
    ↓
② 用神虚实（事情有无）
    ↓
③ 三传走势（初→中→末，起承转合）
    ↓
④ 神将配合 + 刑冲合害（细节与风险）
    ↓
⑤ 年命变体（同一课因人而异的关键）
    ↓
⑥ 应期推断（数目增减、太岁月建、天罡加临）
    ↓
⑦ 落地建议（能成：何时、借何力；不成：何因、如何规避）

```

> ⚠️ **铁律**：结论必须落地为**具体行动指引**，而非只说吉凶。这是区分"占卜"与"咨询"的关键。

## 板块3 · 核心占断法则深度解析（卷八"占法"精要）

### 3_1 旺衰为纲：得进格 vs 失时格

> **原文要义**：旺相休囚死对应"当下、将来、过去"。以旺为当下，相主将来，休属过去。所谓"进气、退气"由此观之。

**实操应用**：

| 格局 | 判定 | 含义 | 行动指引 |
| --- | --- | --- | --- |
| **得进格** | 干支发用或三传合局得旺气 | 事在兴起，方兴未艾 | 宜进取、推进 |
| **失时格** | 用神居休囚死地 | 事已过盛，强行动则费力 | 宜守、宜待 |
| **将来格** | 用神在相地（将旺未旺） | 时机未到 | 等待、准备 |
| **既往格** | 用神在休地 | 事已过去 | 不必再提 |

> **实例**（书中法）：《丁丑日子时申将占，巳加酉发用。巳为旺火、酉为死金，上强下弱，凡事易行；甲寅日辰时亥将占，酉加寅发用，酉虽囚气，但甲寅为月建、支神为德禄，下得势，故不受制。"生金不畏死火"——**不可执一而论，须灵活参详**。

### 3_2 迟速判断：前后行来、撞干撞支

| 法则 | 断法 |
| --- | --- |
| **干发用** | 速 |
| **支发用** | 迟 |
| **贵顺** | 速 |
| **贵逆** | 迟 |
| **日、用在贵前** | 速 |
| **日、用在贵后** | 迟 |
| **撞干/撞支** | 急速（干前一位为关，支前一位为格） |
| **传出** | 事散漫而缓 |
| **传入** | 能量集中而急 |

> **实操提示**：务必**综合参断**——贵人顺逆 + 发用干支位置 + 三传顺逆，三者互参，不可仅凭一条下结论。

### 3_3 夹定、回环、不入：三类特殊课体

**（1）三传夹定格**

+ **夹定**：日辰前后夹定三传在内 → 凡事进退不由人。
+ **夹不住 / 虚一**：看空缺处何神将，即断何事。
+ **夹定中有空陷**：仍以**不空**断（重要例外！）。

**（2）三传回环格**

+ 三传全在四课之中，变化甚微 → **宜守旧，不可轻举妄动**。
+ 干支相会（不备中自作三合）→ 吉则吉成，凶则凶就。

**（3）别处发用（不入格）**

+ 昴星16课、别责9课、八专16课、无依6课（返吟井栏格）。
+ **核心含义**：克贼发用有力，遥克力微，**别处发用更弱** → 主"借他人之力成事，或事为他人所成，或见端于此而成就于彼"。

> 这是极具实操价值的判断：**别处发用 = 此事不由我主导**，在事业、合作占中断此，可直接得出"宜借力、不宜单打独斗"的策略。

### 3_4 救应体系：患门有救，事有两歧

> **核心逻辑**：发用为凶，得**干支上神**或**末传**为救。

| 救应层次 | 力量 | 速度 |
| --- | --- | --- |
| **末传之救** | 最强 | 最速 |
| **干支上神之救** | 中 | 较缓 |
| **年命变体之救** | 最弱 | 最迟 |

> **实操意义**：于万般凶险中，稍得一救扶即可"苟延残喘，他日逢令旺可重整旗鼓"。**断课务必找"救神"**——这是从"判死刑"到"给出路"的关键思维转变。

### 3_5 神将易与阴神：断课的深层维度

**（1）吉凶变化神将易（三层）**

1. 将虽凶，乘神**生我** → 反凶为吉；
2. 神虽生我，乘将**凶** → 吉有减，或"吉自凶中来"；
3. 十二神将**加临**之吉凶变易。

> **书中例证**：乙丑日干上申，三传酉丑巳，金局克干。昼占虎入末传，凶最甚；夜占初传酉为蛇克，中传丑为龙克，末传巳为元克，金局无力伤干，干上申为贵人能伏诸煞——**昼夜不同，天壤之别**。

**（2）阴神落处务参稽**

+ **阳神主象，阴神主情**（《壬归》云："阳显其象，情归于阴"）。
+ 神主吉凶，**将**主其事。

> **例证**：占文书视朱雀。甲寅日干上亥，昼卯乘雀，与干神不相生克，但卯上乘子为朱之阴神，又系旬空 → 主文书不成。
>
> **例证**：占盗贼视勾阴。乙亥日干上戌夜占，子乘勾陈虽克巳之玄武，奈勾阴乘午，反被元阴所克 → "阳虽捕捉，阴则释放"，或始获而终纵。

> **实操要求**：**每断一事，必看相关天将的阴神（地盘落处）**，否则只知表象，不明内情。

**（3）遁干加处细详察**

+ 旬干、五子元干幽微，最要兼看。
+ 暗鬼（遁鬼）尤其关键：**明处看似无碍，遁干藏鬼则隐患深**。

> **例证**：财乘暗鬼（遁鬼）→ 官讼起；财克生爻 → 悍侮情。

### 3_6 年命变体：课同占异的根本原因

> **这是全书最具现代"个性化"思维的部分**——同一课，占者年命不同，吉凶截然相反。

+ **本命**：看地盘本命位上神与天盘上神生克。得吉神吉将则吉，凶神凶将则否。
+ **行年**：男一岁起丙寅顺行，女一岁起壬申逆行；看行年所落地盘之神与天盘生克。

> **经典案例**（陈公献占讼）：丁未日未时辰将，三传亥辰辰，三奇发用，中末干支为月将青龙——**本属吉课**。然盛某得脱罪、相国不免。为何？**盛命寅上乘亥为贵德长生，周命丑上乘戌为日墓，行年申上乘巳为三刑**。——同一课、同一事，因年命而异，其思过半矣。

### 3_7 应期推断四法

| 方法 | 操作 |
| --- | --- |
| **数目增减** | 大衍数（子午甲己九之类）与河图数（水一火二）；少者取河图，多者取先天；以旺相休囚增减。如酉加巳为用，酉六巳四，合十，折半为五。 |
| **太岁加临月建** | 太岁已过月建=已往；未过=将来；正值=当时。 |
| **天罡加临日干** | 在天罡前=事已过；在后=未过；正临=目前。 |
| **星宫分野** | 占行人看行年加临何宫知其所在；占仕看禄马加临何方知其官之何方。 |

## 板块5 · 进阶心法：从"会断"到"断得准"

### 5_1 三传顺逆与经课格局（卷三）

| 类型 | 课体 | 含义 | 宜忌 |
| --- | --- | --- | --- |
| **顺茹（进）** | 亥子丑龙潜→…→酉戌亥革故 | 相连递进 | 宜进（得进格） |
| **逆退** | 戌酉申返驾→…→子亥戌重阴 | 逆行而退 | **宜退、静守** |
| **进间** | 间一位顺行 | 阴阳分动静 | 审动静 |
| **退间** | 间一位逆行 | 奇偶别公私 | 审公私 |
| **三合局** | 曲直（木）、炎上（火）、从革（金）、润下（水）、稼穑（土） | 五行专气 | 结合时令 |
| **关格** | 四仲相加 | 关隔 | 主阻隔 |

> **宜进/不宜进、宜退/不宜退**须结合**神将吉凶**综合判断——吉则重重，凶亦累累。

### 5_2 "莫把神煞当根本，五行理气是真传"

> 这是贯穿全书的**核心方法论**，也是初学者最容易犯的错。

**正确理解神煞的定位**：

+ ✅ 神煞是**辅助维度**，用于"补充细节与风险"。
+ ❌ 神煞不是**根本依据**，不能脱离五行生克单凭神煞断吉凶。

**正确断课优先级**：

```plain
五行生克（根本）> 旺衰（气之强弱）> 三传走向（事之脉络）
    > 天将配合（助力/阻力）> 神煞（细节修饰）> 应期（时间定位）

```

### 5_3 "择象贴合"原则

> 一课排出，万象纷呈。**择其贴切于事者而用之，其散漫无稽者而略之。**

**实操含义**：

+ 占婚姻 → 只看财、官、龙、后、六合，**不相关的神将略过**；
+ 占失物 → 只看玄武、官鬼、勾陈；
+ **切忌"什么都断、什么都沾"**——那不是高明，是混沌。

### 5_4 昼夜区分的重要性

> 全书多处强调**昼占/夜占天壤之别**（贵人顺逆、天将不同、遁干变化）。

**实操铁律**：

+ 起课前**必须明确昼/夜**（据占时定阴阳贵）；
+ 同一课式，昼夜不同 → **结论可能完全相反**；
+ 务必在断语中标注"昼占""夜占"，避免混淆。

## 板块6 · 完整实操案例演示

> 以下为按本书体系还原的标准操作流程（数据为示例）。

**占问**：2025年某日（假设乙丑日）辰时，问近期事业是否有升迁机会？

### 6_1 Step 1：定要素

+ 日干支：乙丑
+ 占时：辰时
+ 月将（依中气）：假设清明后 → 从魁（酉）
+ 十干寄宫：乙寄辰

### 6_2 Step 2：布天地盘

+ 月将"酉"加地盘"辰"位，顺时针顺排十二支 → 得天盘。

### 6_3 Step 3：立四课

+ 干宫（辰）上得天盘神 → 第一课（干阳）
+ 取干阳上神地盘再看天盘 → 第二课（干阴）
+ 支宫（丑）上得天盘神 → 第三课（支阳）
+ 取支阳上神地盘再看天盘 → 第四课（支阴）

### 6_4 Step 4：取三传（九宗门）

+ 查四课有无"下贼上"→ 有则取贼克；无则依次比用、涉害……
+ 定初传 → 取中传 → 取末传

### 6_5 Step 5：布天将

+ 乙日：乙己鼠猴乡 → 阳贵"子"、阴贵"申"
+ 辰时为昼占 → 用阳贵"子"
+ 定贵人顺逆 → 顺排十二天将

### 6_6 Step 6：配六亲、定用神

+ 事业用神 = **官鬼**（职位、上级）
+ 辅助：贵人、禄、青龙
+ 察官鬼旺衰、是否入课传、与日干生克关系

### 6_7 Step 7：综合论断

按"日干旺衰 → 用神虚实 → 三传走势 → 神将配合 → 年命 → 应期 → 行动建议"七层输出结论。

> **结论示例框架**：
>
> + "日干乙木得月建生扶，**身旺可担官**；"
> + "官鬼爻临旺地且入三传，**升迁有望**；"
> + "初传青龙、末传贵人，**过程顺畅且有贵人提携**；"
> + "应期在**官星当令之月（申酉月）**；"
> + "建议：**主动争取、借贵人助力推进，宜进不宜守**。"

## 板块7 · 本书的方法论启示（超越术数层面）

### 7_1 "辨非"精神的现代价值

刘赤江对月将、贵人、生墓等争议的逐一辨析，体现的其实是**科学精神**：

> 不盲从权威（即便姚广孝也敢批"荒唐不可从"），**以理验证、以例佐证**。

这种"**先立规矩、再通权变**"的思维，完全可以迁移到任何需要判断力的领域。

### 7_2 "三境"进阶模型

```plain
适道（掌握正确方法）
   ↓
与立（建立判断标准）
   ↓
与权（灵活运用、神明变化）

```

**任何技能的学习都可套用**：先学规则 → 再积累范式 → 最终融会贯通、随机应变。

### 7_3 "救应思维"与风险管理

本书反复强调"**患门有救**"——即便发用凶险，只要末传、干支、年命有一处救应，便有转机。

> 这本质上就是**风险管理思维**：不追求"无风险"，而是**确保任何最坏情况下都有逃生通道**。

### 7_4 "择象贴合"与认知效率

> 一课万象，择贴切于事者用之。

**认知效率的本质就是"选择性注意"**——从海量信息中筛选与当前决策最相关者，忽略噪声。这在信息过载的时代尤为珍贵。

```plain
甲课寅兮乙课辰，丙戊课巳不须论，
丁己课未庚申上，辛戌壬亥是其真，
癸课原来丑宫坐，分明不用四正神。

```

### 9_5 E. 贵人起法口诀

```plain
甲戊庚牛羊，乙己鼠猴乡，
丙丁猪鸡位，壬癸蛇兔藏，
六辛逢马虎，此是贵人方。

```

---

> **结语**：《六壬粹言》的价值，在于它把六壬从"口诀神秘主义"提升为"**有规矩、有层次、有权变**"的完整方法论。刘赤江七年三易其稿的心血，最终凝结为一句话：
>
> **"适道以致其知，与立以固其守，与权以通其变。"**
>
> 对今日读者而言，这本书真正值得学习的，不只是占术本身，更是那种**辨伪存真、循序渐进、灵活变通**的思维方式——这，才是"粹言"二字的真义。
