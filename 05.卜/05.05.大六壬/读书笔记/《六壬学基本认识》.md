## 板块1 · 总览：先建立"全景地图"，再钻细节

六壬与太乙、奇门并称"三式"，又以占验人事最为精妙，被历代推为"占卜之王"。它的全部奥妙，可以压缩成一句话：

> **用天地盘锁定"此时此地"的时空坐标，用四课呈现当下静态关系，用三传推演事情始—中—终的完整轨迹，再叠加天将、六亲、神煞来"人事化"和"吉凶化"。**

如果把六壬盘比作一台戏剧，那么：

| 要素 | 在戏剧中的角色 | 回答的问题 |
| --- | --- | --- |
| 天地盘 | 舞台与灯光（时空坐标） | 这件事发生在何时、何地、何种能量场 |
| 四课 | 人物关系网 | 我方、对方、事态当前的显隐状态 |
| 三传 | 三幕剧情 | 起因 → 转折 → 结局 |
| 天将 | 角色性格 | 这件事带有什么样的人事色彩 |
| 六亲 | 利害关系 | 对我有利、有害、还是耗泄 |
| 神煞 | 特殊道具 | 何处有变数、应期、风险点 |

**关键认知**：初学者最容易犯的错，是一上来就背《毕法赋》《课经》，结果被几百条法则绕晕。**正确的学习顺序是"先骨架、后血肉"**——先把"起盘 → 取象 → 断局"这条主线走通，再回头填细节。

> **一句话原则**：理定其常，气权其变；紧要处不离"生、克"二字。神煞是辅助，五行理气才是真传。

## 板块2 · 核心骨架（一）：天地盘——锁定时空坐标

### 2_1 原文要点解析

天地盘是六壬一切推演的起点，本质是"两层转盘"模拟天地关系：

+ **地盘**：永远固定。十二地支按四方排布——子居正北、午居正南、卯居正东、酉居正西。掌诀图（或方盘）务必烂熟于心：

```plain
    巳 午 未 申
    辰       酉
    卯       戌
    寅 丑 子 亥

```

+ **天盘**：随"占时"转动。方法是 **月将加占时、顺时针顺排十二支**。同一时辰，不同月将，天盘完全不同。

**月将** = 太阳所在之宫，代表一年中太阳运行的轨迹，用十二地支表示（注意它是**逆节气而行**，别和十二月支顺行搞混）。**逢每月"中气"换将**，这是最容易被误用的点：

| 中气起点 | 月将 | 神将名 |  | 中气起点 | 月将 | 神将名 |
| --- | --- | --- | --- | --- | --- | --- |
| 雨水 | 亥 | 登明 |  | 处暑 | 巳 | 太乙 |
| 春分 | 戌 | 河魁 |  | 秋分 | 辰 | 天罡 |
| 谷雨 | 酉 | 从魁 |  | 霜降 | 卯 | 太冲 |
| 小满 | 申 | 传送 |  | 小雪 | 寅 | 功曹 |
| 夏至 | 未 | 小吉 |  | 冬至 | 丑 | 大吉 |
| 大暑 | 午 | 胜光 |  | 大寒 | 子 | 神后 |

> ⚠️ 常见误区：把"农历月份"当成月将。正确做法是**查当前处于哪个中气区间**。例如处暑之后、秋分之前，月将就是巳（太乙）。

### 2_2 网络教程拓展：占时怎么取？

起课四要件：年、月、日、时干支 + 月将 + 占时。其中"占时"最灵活，有两种取法：

+ **正时**（最常用）：问事当下的真实时辰。古人尤重"来人脱口而出"的时辰，认为最得天然之机。
+ **活时**（辅助）：一时辰内多人问事、或时辰不明时，用抽签、滚珠、报数取时（所报之数除以12，余数对应十二时辰）。

**24小时 ****↔**** 地支时辰对照**（务必记熟）：

| 时间 | 时辰 |  | 时间 | 时辰 |
| --- | --- | --- | --- | --- |
| 23–1 | 子 |  | 11–13 | 午 |
| 1–3 | 丑 |  | 13–15 | 未 |
| 3–5 | 寅 |  | 15–17 | 申 |
| 5–7 | 卯 |  | 17–19 | 酉 |
| 7–9 | 辰 |  | 19–21 | 戌 |
| 9–11 | 巳 |  | 21–23 | 亥 |

### 2_3 实操训练（可直接照做）

**练习1：手绘地盘**。每天在纸上画一次地盘方盘，直到不假思索写出十二支方位。

**练习2：月将加时布天盘**。口诀：**"月将加时，顺排十二支"**。

> 例：月将为 **巳**，占时为 **戌**。把天盘"巳"放在地盘"戌"上，然后顺时针依次排：地盘亥→天盘午、地盘子→天盘未……全部排完。最终每个地支上"盖"一个天盘支，记作"X上Y"。

**自检标准**：同一组"月将+占时"，你的天盘与他人（或软件）完全一致，才算过关。

## 板块3 · 核心骨架（二）：四课——当下关系网

### 3_1 原文要点解析

四课是从天地盘中"提取信息"的关键一步。核心是 **十干寄宫**——十个天干必须落到地盘十二支上（阳干寄禄、阴干寄冠带，不用"子午卯酉"四正神）：

> **甲寄寅、乙寄辰、丙戊寄巳、丁己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑**

四课的生成规则（从右至左排列，记忆顺序：**干阳 → 干阴 → 支阳 → 支阴**）：

1. **第一课（干阳）**：日干寄宫地盘上，所乘的天盘支 = 上神；日干寄宫 = 下神。
2. **第二课（干阴）**：以第一课上神为"下神"，看它地盘上所乘天盘支 = 上神。
3. **第三课（支阳）**：日支地盘上所乘天盘支 = 上神；日支 = 下神。
4. **第四课（支阴）**：以第三课上神为"下神"，取其地盘上所乘天盘支 = 上神。

**一句话口诀**：下神是地盘，上神是天盘；"下贼上"=地盘克天盘，"上克下"=天盘克地盘。

> 本质理解：**四课 = 干（我方）两课 + 支（对方/事体）两课**，每课分"阳（显）"与"阴（隐）"，共四面镜子折射一件事。

### 3_2 网络教程拓展：四课速判心法

排完四课，先别急着取传，做以下"体检"能直接读出很多信息：

| 观察点 | 断语方向 |
| --- | --- |
| 干上神（我方外境） | 生我=助力，克我=压力，比和=同类 |
| 支上神（事态） | 生我=有利，克我=受害，合=可成 |
| 干上克支上 | 我求彼事，易受制于人 |
| 支上克干上 | 彼来求我，我占主动 |
| 干上见空/脱气 | 事虚浮、易落空，防诈伪 |
| 支上见墓/困 | 事停滞、难推进，宜守不宜攻 |
| 四课全克 | 无禄/绝嗣之象，主凶 |
| 四课无克 | 遥课，事在远方/外应，宜静候 |

### 3_3 实操训练

**练习3：十干寄宫默写**。随机说一个日干（如"戊"），0.5秒内答出寄宫（巳）。要求正反面都熟。

**练习4：完整排四课**。

> 例：戊辰日、戌时，月将未。戊寄巳，巳上天盘=寅，寅上天盘=亥；辰（日支）上天盘=丑，丑上天盘=戌。四课即：
>
> + 一课：戊 / 寅
> + 二课：寅 / 亥
> + 三课：辰 / 丑
> + 四课：丑 / 戌

**自检**：四课永远"上下成对、共四组"，格式统一为"上神/下神"。格式错了立刻重排。

## 板块4 · 核心骨架（三）：三传——事件的三幕剧

### 4_1 原文要点解析（九宗门）

三传是四课中"发动之气"的推演，是六壬断事的核心动线。初、中、末传分别对应：

+ **初传（发用 / 发端门）**：起因、导火索、当下吉凶源头。
+ **中传（移易门）**：发展、转折、阻碍或贵人。
+ **末传（归计门）**：归宿、最终结果。

取初传的九种法则统称 **九宗门**（优先级严格递进）：

> **贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟**

确定初传后，中末传一般按 **"相因"法则** 顺推：中传 = 初传在地盘落宫上所承的天盘神；末传 = 中传在地盘落宫上所承的天盘神（伏吟、返吟等特殊课另有取法）。

### 4_2 九宗门逐层拆解（落地版）

| 次序 | 名称 | 何时使用 | 取用规则 | 主象 |
| --- | --- | --- | --- | --- |
| 1 | **贼克** | 四课有上下克 | 先取"下贼上"（重审），无则取"上克下"（元首） | 事发突然、矛盾尖锐 |
| 2 | **比用**（知一） | 多课同时有克 | 阳日用阳神、阴日用阴神（与日干比和） | 同类竞争、权衡 |
| 3 | **涉害** | 比用仍无法定 | 看各神受克深浅，取涉害最深者（或用孟仲季法） | 事纠缠、过程曲折 |
| 4 | **遥克** | 四课无上下克 | 神克干=蒿矢，干克神=弹射 | 远方之事、气势弱 |
| 5 | **昴星** | 连遥克也无 | 阳日取地盘酉上神，阴日取天盘酉下神 | 闭塞、暗中潜伏 |
| 6–9 | 别责/八专/伏吟/返吟 | 特殊课体 | 各有专法 | 借径/混杂/静守/反复 |

**贼克取用口诀**（必背）：

> 取课先从下贼呼，若无下贼上克初；初传本位明中次，中上因加是末居。

**特殊课的速判**（初学者高频遇到，务必区分）：

| 课体 | 识别特征 | 吉凶倾向 |
| --- | --- | --- |
| 伏吟 | 天地盘相同，静而不动 | 主静守、停滞、内部事 |
| 返吟 | 天地盘冲克，动荡反复 | 主反复、动荡、远去 |
| 八专 | 干支同位，阴阳不分 | 主男女混杂、公私不分 |
| 别责 | 课不备（只有三课）且无克 | 主借径而行、倚仗他人 |

### 4_3 三传断局的核心技法（干货重点）

三传排好后，**看"走势"比看"单点"更重要**：

1. **传变生克（能量传递）**
    - **顺生局**（初生中、中生末）：大吉，层层得力，事易成。
    - **逆克局**（初克中、中克末）：大凶，步步受阻。
    - **首尾相见**（初=末）：事反复纠缠，难彻底了结。
    - **初末相克**：虎头蛇尾，结果悖离初衷；末克初为"反噬"。
2. **传进与传退（节奏快慢）**
    - **进连茹**（如寅→卯→辰）：势如破竹，发展迅速；占病则主恶化快。
    - **退连茹**（如辰→卯→寅）：节节败退，日趋萎缩。
3. **空亡陷阱**（最忌）
    - 初传空：发端即虚，开局落空。
    - 中传空：中途断链。
    - 末传空：忙活一场，终无实质结果（竹篮打水）。

> **核心口诀**：**初传看起因吉凶，末传定最终成败**。哪怕初中皆凶，末传生扶日干，最终仍能安稳收场；反之开头一路顺，末传带刑克，最后易落空后悔。

### 4_4 实操训练

**练习5：给三传"贴标签"**。拿到任意一课的三传，30秒内答出：顺生/逆克？传进/传退？有无空亡？末传生克日干？

**练习6：手工起三传全流程**（建议前2个月坚持手工，再转软件辅助）。目标：从定占时到写出三传，10分钟内完成且零差错。

## 板块5 · 血肉填充（一）：十二天将——赋予"人事色彩"

### 5_1 布将法则

十二天将以 **天乙贵人** 为首，顺序固定：

> **贵、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后**

**起贵人口诀**：

> 甲戊庚牛羊，乙己鼠猴乡；丙丁猪鸡位，壬癸兔蛇藏；六辛逢马虎，此是贵人方。

+ 前一个是**阳贵（昼贵）**，后一个是**阴贵（夜贵）**。
+ **昼夜分界**：卯时至申时用阳贵（昼），酉时至寅时用阴贵（夜）。
+ **顺逆规则**：贵人落"亥至辰"六宫 → 顺排；落"巳至戌"六宫 → 逆排。

> 关键理解：天将"乘"在天盘十二支上，五行**随所乘之神变化**。例如贵人本属土，若乘申酉则按金论生克。**"生我之日为吉，克我之日为凶"——吉将喜生扶、忌克制；凶将反之。** 所以不存在"青龙永远吉、白虎永远凶"的机械判断。

| 螣蛇 | 火 | 凶 | 焦虑、诈骗、虚惊、变故 |
| 朱雀 | 火 | 凶中带信 | 合同、邮件、文书、口舌、官司 |
| 六合 | 木 | 吉 | 合作、婚姻、中介、交易 |
| 勾陈 | 土 | 凶 | 官司、拖延、房地产、竞争对手 |
| 青龙 | 木 | 大吉 | 财富、升迁、喜庆、奖金 |
| 天空 | 土 | 凶（虚） | 虚假信息、空谈、不实 |
| 白虎 | 金 | 大凶 | 意外、手术、血光、竞争压力 |
| 太常 | 土 | 吉 | 宴席、礼仪、衣食、平稳 |
| 玄武 | 水 | 凶（盗） | 盗骗、暗昧、内贼、暧昧 |
| 太阴 | 金 | 吉 | 暗中谋划、女性、秘密贵人 |
| 天后 | 水 | 吉 | 女性、恩泽、家庭、保护 |

### 5_3 实操训练

**练习7：贵人定位**。随机给"日干+昼夜"，秒答阳贵/阴贵落在何支。如"戊日、夜" → 阴贵在"未"。

**练习8：天将顺逆排布**。找到贵人后，按顺/逆把十二将完整排一圈。**吉将喜旺相、凶将宜休囚**——这是判断力度的关键。

## 板块6 · 血肉填充（二）：六亲、类神与神煞

### 6_1 六亲（以日干为"我"的基准）

> 生我者**父母**、我生者**子孙**、克我者**官鬼**、我克者**妻财**、比和者**兄弟**。

结合月令（节气）判断旺衰：**旺相有力、休囚无力、空亡落空**。

### 6_2 类神：一事一象，象合则应

断课真正的"抓手"是 **类神**——根据所问之事，找准对应符号。这是把抽象课传"翻译"成具体答案的桥梁：

| 占问事项 | 核心类神 | 辅助天将 |
| --- | --- | --- |
| 事业工作 | 官鬼、父母爻 | 贵人、青龙 |
| 财运求财 | 妻财爻 | 青龙（正财）、防玄武/螣蛇（暗耗诈骗） |
| 姻缘情感 | 男看妻财、女看官鬼 | 六合（粘合）、天后（深浅） |
| 疾病健康 | 克我者为病 | 白虎、子孙爻（医药）、天医/地医 |
| 出行远行 | 驿马、丁神 | 青龙、传送；忌魁罡、伏吟 |
| 考试升学 | 朱雀、文昌 | 帘幕贵人、印绶 |
| 官讼是非 | 官鬼 | 朱雀、勾陈、贵人 |
| 失物寻物 | 玄武 + 物之专神（如钥匙看戌、手机看酉） | 临六合多为被遮盖或亲朋收起 |

> **干货技巧**：类神若**空亡**，落空感极强——面试类神空亡，offer易没下文；寻物类神空亡，多半没真丢，就在原地打转。

### 6_3 神煞：锦上添花，非根本

常用且高价值者：驿马、桃花（咸池）、孤寡、空亡、禄、羊刃、劫煞。**原则是"叠加验证"**——当五行生克已定吉凶后，神煞用来补充细节、锁定应期（如"驿马逢丁，主快速变动；羊刃逢刑，主极大伤害"）。

> ⚠️ 提醒：神煞系统庞杂，初学者切忌本末倒置。**先把五行生克、三传走势吃透，神煞是最后的精修。**

## 板块7 · 完整断课标准流程（七步法，可直接套用）

这是把前面所有知识串成一条"可复制生产线"的操作手册：

### 7_1 第1步：定基础（年、月、日、时 + 月将 + 占时）

+ 换算干支，确定月将（查中气）、占时（优先正时）。
+ **原则**：天机发于动，占时要随机自然，不可刻意挑选。

### 7_2 第2步：排天地盘

+ 月将加时、顺时针排天盘；核对"地盘固定、天盘一一对应"，不可错位。

### 7_3 第3步：立四课（辨主客）

+ 干阳、干阴、支阳、支阴。干=我方，支=对方/事体；分清阴阳显隐。

### 7_4 第4步：取三传（定脉络）

+ 按九宗门优先级取初传 → 顺推中末传。标注"初=起因、中=转折、末=结果"。

### 7_5 第5步：配六亲 + 定用神

+ 以日干为基准配六亲；按占事取**核心类神 + 辅助类神**；结合月令判旺衰。

### 7_6 第6步：观格局、断吉凶

依次检查（**顺序很重要**）：

1. **课体**：伏吟/返吟/重审等，定事之大势；
2. **日干旺衰**：自身底气；
3. **三传走势**：顺生/逆克、传进/退、空亡；
4. **四课生克**：干支关系、主客强弱；
5. **天将吉凶**：吉将生扶、凶将克制；
6. **神煞、刑冲合害**：补细节、定应期。

### 7_7 第7步：出结论、给指引（落地关键）

+ **不只说吉凶，要给行动建议**：
    - 能成的事：何时成、注意什么、如何借力；
    - 不成的事：问题在哪、为何不成、要不要等、如何规避；
    - 有风险的事：风险点在哪、怎么化解、要不要放弃。

> **综合判断口诀**：三传生扶日干则吉，克泄日干则凶；传中有"救神"（如子孙制官鬼）则虽凶可解。吉事落空则不吉，凶事落空则不凶。

**入门总诀（建议背诵）**：

> 月将加时立地盘，四课分明主客辨；

取传先寻克处动，六亲定下用神现；
三传始终看走向，旺衰生克断凶吉；
莫把神煞当根本，五行理气是真传。

## 板块8 · 断课核心禁忌（"不占"清单）

这些是历代壬家反复强调的操守，比技法更先决：

1. **不诚不占**：心不诚、意念不专，占则不准。
2. **不渎不占**：同一件事反复占，亵渎天机，越占越乱。
3. **不邪不占**：违法乱纪、损人利己之事，不可占。
4. **不妄断**：拿不准的事不说死，留有余地，不危言耸听。

## 板块9 · 学习路径与必读书单（分级推荐）

> 核心建议：**先白话入门 → 再啃理气经典 → 最后用实战案例打通**。切忌一上手就死磕古籍。

### 9_1 入门筑基（建立框架）

+ 《图解六壬大全》《六壬金针》（北海闲人，通俗论点多、体系清）
+ 《大六壬精解》《大六壬指南诠解》

### 9_2 理气进阶（打通原理）

+ **《壬归》**（首选）：开篇即立"理→气→象→类→占"闭环，七卷覆盖基础到应用，是体系化标杆。
+ 《大六壬说约》（张鋐）：删繁就简，主张"吉凶根本在生克二字"，破玄虚之说。

### 9_3 断课法则（可套用）

+ **《毕法赋》**（凌福之，据邵彦和《断案》归纳100条法则）：实战中70%以上课传大势可直接套用，至平至当。
+ 《课经集》《大六壬心境》

### 9_4 实战天花板（复盘范本）

+ **《大六壬断案》**（邵彦和，223则课例）：理气与取象完美融合，是"开窍之书"——学会抓类神、辨旺衰、析传变。
+ **《大六壬指南》**（陈公献等）：五卷"理→法→占→验"完整链条，125则课例是模仿绝佳范本。
+ 《六壬粹言》《壬学琐记》（考辨精详，进阶必备）

> **推荐节奏**：按上述四级顺序，每级精读1–2本，配合手工起课 + 射覆测来意练习，**约2个月可初步断课**（准确度后续再磨）。重点是：**基础滚瓜烂熟前，不要急着看《毕法》《课经》**，否则极易劝退。

## 板块10 · 实战案例演示（一条龙走完全流程）

为了让框架"落地可见"，这里用一个**简化示例**（只演示思路，不作真实验证）：

**设定**：公历某日，乙亥日、未时问"近期事业求财"。

### 10_1 起课拆解（示意）

1. **定基础**：日干=乙（阴木），日支=亥，占时=未，月将按中气确定。
2. **天地盘**：月将加未、顺排天盘（略，实操需手排核对）。
3. **四课**：乙寄辰 → 干阳、干阴；亥为日支 → 支阳、支阴（略）。
4. **三传**：按九宗门取初传 → 顺推中末传（略）。
5. **六亲**：乙为阴木 → 官鬼=申酉、妻财=子亥、父母=巳午、兄弟=寅卯、子孙=辰戌丑未。
6. **天将**：按日干昼夜起贵人，顺/逆排十二将。

### 10_2 断局（套用七步法）

+ **抓类神**：求财 → 看妻财爻 + 青龙；事业 → 看官鬼 + 贵人。
+ **析三传**：看顺生/逆克、传进/退、有无空亡、末传是否生扶日干。
+ **辨旺衰**：妻财爻是否旺相、是否空亡、是否被玄武/螣蛇环绕（防暗耗）。
+ **综合定局**：
    - 若妻财旺相、青龙临之、末传生扶日干 → **财可求，留意应期（旺相月、填实之时）**；
    - 若妻财空亡、玄武临之 → **多为虚财或暗耗，建议稳守、勿冒进**。

> 说明：以上为**方法演示**，真实占断需完整排盘 + 逐条验证。建议读者用起课软件生成盘面后，**严格按七步法手写断语**，再与软件/古籍参考对照修正——这是最快的提升路径。

## 板块12 · 结语：六壬的真正价值

六壬之妙，在于 **"象、理、数"三位一体**——它用一套严密的形式化模型，把模糊的疑问转成清晰、立体的"象"，再通过生克、旺衰、传变推演出轨迹。**它不只是术数，更是一套训练"系统观察 + 动态推演 + 综合决断"思维的框架。**

对现代人而言，不必执着于"每占必验"，更有价值的恰恰是这套 **"先锁定坐标 → 看清当下关系 → 推演发展链条 → 抓关键变量 → 给出行动方案"** 的思考习惯——它能迁移到决策、规划、风险判断的方方面面。

正如历代壬家所言：

> **"课有千般，理归一贯；触类旁通，随机应变。"**

勤习、多验、常复盘，方得其髓。
