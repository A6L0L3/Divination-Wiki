## 板块8 · 类神与年命：把抽象课传翻译成具体答案

> 有了语言（板块4、板块4）、角色（板块6）和力度（板块7、板块7），还差两样东西才能落到"人"身上：一是这件事的主人（类神），二是这个人本身（年命）。缺前者，课是抽象的；缺后者，课是通用的。

---

### 8_1 类神取法三原则

1. **取象优先级**：**正象（六亲为主）> 偏象（天将 / 月将 / 神煞）> 支辰（盘中寻找）**。正偏象并为一神时，应事最准（如占婚，财爻又乘天后）。
2. **专类重于泛类**：一件事只取**一个正类**。类多了等于没类。
3. **类神必须"发见"**：类神入四课三传，此事显象、真切；课传无类，只能看本位方位，力度降一档，所占事难成。

> **一条硬判据**：**类神不入课传，所占事难成。** 这是断"有没有"的第一关。

**为什么"专类重于泛类"**：一件事同时取三个类神，等于给三个裁判各投一票，结果必然是"看哪个都能说通"。**取类的目的是让判断可证伪**——只取一个正类，断错了你才知道错在哪；取三个，你永远能对上号。

| --- | --- | --- | --- |
| **求财** | 妻财爻 | 青龙（正财）、太常；防玄武、螣蛇（暗耗诈骗） | 日干能否任财；财是否空亡；有无"鬼财"（财化鬼、财遁鬼） |

| **婚姻** | 男看妻财、女看官鬼 | 六合（粘合）、天后（深浅） | 生合与刑冲；双方年命是否对应 |
| **疾病** | 克我者为病（官鬼） | 白虎、病符；子孙爻（医药） | 受克、旺衰、白虎所临、制鬼之位 |

| **失物 / 盗贼** | 玄武 + 物之专神（钥匙看戌、手机看酉） | 勾陈（捕捉）、太阴 | 临六合多为被遮盖或亲朋收起；玄武旺相主内贼近处 |

| **宅墓** | 日支（支上神） | 青龙、太常、白虎 | 干支谁生谁；三传归支还是归干 |

### 8_3 现代问法到传统占类的翻译表

六壬的分类占是为农耕与仕宦社会设计的，今天用得最多的几类问题，需要先"翻译"回传统占类，才能取对类神：

| 现代问法 | 归入何类 | 取什么类神 |
| --- | --- | --- |
| 投简历、等录用通知、面试结果 | 官禄 + 文书（考试） | 官鬼、朱雀、帘幕贵人、印绶 |
| 项目立项、投标、能不能签下这单 | 谋望 / 交易 | 六合、财爻、青龙；看交车与三传走势 |
| 要不要跳槽、调岗 | 官禄 + 出行 | 官鬼、禄、驿马、丁神 |
| 合伙开店、股权分配 | 求财（长期） + 交易 | 父母爻（营生根基）、财爻、六合、劫煞 |
| 租房、买房、装修 | 宅墓 | 日支、支上神、青龙太常、白虎墓神 |
| 追讨欠款、维权、投诉 | 官讼 + 失盗 | 官鬼、朱雀、勾陈、玄武、太阴 |
| 能否挽回关系、感情走向 | 婚姻 | 六合、天后、太阴、男女年命 |
| 体检异常、要不要手术 | 疾病 | 日干、官鬼、白虎、子孙（医药）、天医 |
| 投资、理财、借贷 | 求财（短期） | 财爻、青龙；防玄武、破碎、劫煞 |
| 找丢失的手机、宠物走失 | 失盗 / 亡盗 | 玄武、物之专神、勾陈、太阴 |

> **翻译错了，后面全错。** 例："能不能签下这单"本质是**交易谋为**（看六合与交车），不是"求财"——把合同类问题当求财断，会漏掉"合中犯杀蜜中砒"这层风险。

### 8_4 用神虚实三步判

用神（即所占之事的核心类神）到手后，依次问三个问题：

```latex
第1步 用神在不在课传？（不在 → 事难成，或需待时）
      ↓
第2步 用神旺不旺？（月令旺相 + 落四吉地 → 有力；休囚 + 落八凶地 → 无力）
      ↓
第3步 用神空不空、受不受克？（空 → 虚；受克无制 → 败；有制或得救 → 仍有转机）

```

**用神旺相不空则事成；衰、空、受克则事败。**
这是全部断课中最高频、也最没有例外的一条判据。

### 8_5 年命变体：同一课，为什么两个人问结果相反

> **这是最具"个性化"思维的一层，也是最多人跳过的一层。**

#### 推法（详见板块3）

| 项目 | 推法 | 观察内容 |
| --- | --- | --- |
| **本命** | 生年地支 | 看地盘本命位上神与天盘上神之生克 |
| **行年** | 男一岁起丙寅顺行，女一岁起壬申逆行（亦有"男起寅顺推、女起申逆推"的表述，择一后固定使用） | 看行年所落地盘之神与天盘生克 |

#### 经典范式

同一日、同一时、同一件事，两人同占。课式是吉课，结果却一脱罪一不免——差别全在年命：

| 人 | 年命上的象 | 结果 |
| --- | --- | --- |
| 甲 | 本命上乘贵人、德神、长生 | 脱罪 |
| 乙 | 本命上乘日墓，行年上乘三刑 | 不免 |

> **实操动作**：读每一则课例、断每一个真实占问，**先把本命、行年标在课式旁边**，再看断语或下判断。你会发现"原来如此"的次数，比想象中多得多。

### 8_6 多人同占与"次客"：一盘能不能断好几件事

古代占例中，"一课多断"是常态（一个时辰所起的课局，可以应付多个来人的不同问题）；本知识库则主张**一占一事**为入门纪律。两者看似矛盾，实则分层：

| 情形 | 处理原则 |
| --- | --- |
| **同一人、同一事** | 严守一占一事，不反复占 |
| **同一人、多件事（同一次来问）** | 可以一课多断——换类神不换盘。每问一事，重新取该类神，重新走一遍七步法 |
| **同一时辰、多人来问** | **不换将、不换时**，只以各人年命区分（控制变量） |
| **同一人、事后又来问别的事** | 另起一课。旧课的信息已经"用完"，不可沿用 |

#### "次客"的处理

古法在同一时辰内第二、三位来占者，有"换时不换将""换将换时""只以年命分"三种处理，历代争议不断。**最稳妥的是邵彦和一派的做法**：

> 以正将正时为最；其次换时不换将；再其次不换将也不换时，**惟以各人年命为主**——课虽同而理则异，区别悬殊。

#### 一课多断的两条纪律

1. **每断一事，必须重新声明类神**。不要指望"一盘包打天下"——同一课里，求财看青龙财爻，问病看白虎官鬼，两者毫不相干，混着说必然出错。
2. **类神不现的那一问，宁可说"象不显，难断"**。一课多断最容易犯的错，就是强行给每一问都编出个答案。

### 8_7 案例小故事：找手机，与没下文的通知

**故事一 · 找手机**

**背景**：有人占手机丢了，翻遍了家里和办公室都没找到。

**经过**：取物之专神（酉）与玄武同看，发现**类神不入课传**。

**转折点**：他没有硬编一个方位——类神不入课传时，硬编方位是最容易出错的动作。

**判断**：他直说"象不显，难断，多半没真丢，就在原地打转——常是夹在什么里、落在某个常去的角落，或被家人顺手收起来了"。

**结果**：手机在沙发缝里。而他此前因为"没找到"已经准备补办号码——如果当时硬编一个方位让人去某处翻，反而会多绕一圈。

**可复制动作**：类神不入课传时，最忌讳的是硬编方位。**宁可说"象不显，难断，建议先翻一遍常去的地方"，这才是准确的判断。**

**故事二 · 面试**

**背景**：某人占一次很看重的面试结果。

**经过**：取官鬼与朱雀为类神。课上官鬼虽见，但恰落空亡，朱雀亦临空。

**判断**：不是"被拒"，而是"**没有下文**"——事情不是失败，是悬着。

**反馈**：面试过程很愉快，对方说"等通知"，此后三个月没有任何回音。

**结果**：他据此判断"可以再跟进一次"，于是发了一封礼貌的询问邮件。对方回复说岗位编制冻结了——这正应了"悬着、没有下文"，而不是"被拒绝"。

**可复制动作**：区分两种"不成"——**受克而无制等于明确被否**（要另寻出路）；**空亡等于拖着、没着落**（还可以主动跟进一次）。两种不成给人的行动建议完全不同。

### 8_8 案例小故事：一句「赘婿」，六年之后家破屋拆

**出处**：邵彦和《大六壬断案》，叶助教占宅（戊申年正月辛卯日）。

**背景**：求占人报上年命行年，邵公先看四课，再见末传丑（辛日之墓）临太岁，太岁入宅克宅，宅又走回日上为日所克。

**断语**：支来就干、为干所制，名「**赘婿**」——太岁入宅克宅，宅来就人，又被人克。**「六年中家破屋拆，遂成墓地，必葬尊长在内。」**

**类神在哪里**：他并不泛说"家宅不利"，而是把三件事各自钉死在一个位置上——

| 断出的内容 | 类神定位 |
| --- | --- |
| 家破屋拆 | 支（宅）上神被干克，宅不留则屋不存 |
| 必葬尊长在内 | 末传丑为庚辛之墓、为尊长葬埋之处，丑又临太岁，故葬者是长辈 |
| 不出六年 | 卯数六；又戊申至癸丑恰为六年 |
| 门户分张、外姓僧人入挠 | 卯上见玄武；申为僧，辛申同类，为还俗僧 |

**事实反馈**：同年癸丑（正是第六年）其叔去世，殡于宅内；叔有三子、其一曾为僧，还族归分家产，经官判定诸子分家，与叔共五子，求占人亦得一分，遂作六分分讫——**「六年」「尊长」「僧人」「分家」四项一一对上**。

**可复制动作**：

1. 年命不是装饰：同课换一个人来占，六年的起算点与"应到谁头上"都会变。
2. 断宅要看"宅愿不愿意留人"——支上被干克、宅又无生路，才敢说"屋不存立"。
3. 年限断语必须写清依据（卯数六 + 太岁至丑年六载），两条独立算出同一个数，才敢下"六年"。

### 8_9 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **写正类** | 每断一事，先在纸上写"这件事的正类是什么" | 断语开始聚焦，不再东拉西扯 |
| **先翻译** | 现代问法先翻译回传统占类 | 类神不再取错 |
| **三步判** | 严格按 8_4 的三步走，写出三行 | 30 秒内完成 |
| **标年命** | 课式右侧固定写本命、行年 | 十课之后能解释"同课异断" |
| **敢说难断** | 类神不现时，练习说"象不显，难断" | 断语的准确率反而上升 |
