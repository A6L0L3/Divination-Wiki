## 板块10 · 断法百则：局势、生克、进退、人我、神将、终局

> 这一板块收录六壬断法的百则口诀，源出南宋凌福之《毕法赋》：一百句七言，一句一法，是从上千个实战课例中压缩出来的"经验压缩包"。清人程树勋评价它"因用邵彦和《断案》而作，而复参以心得，故其书从考验中来"，史称"诸法咸备，至平至当"。
>
> **每一句口诀都不是结论，而是压缩包**——背后藏着一个完整课例、一套生克逻辑、一类应期判断。全篇按六大门类归位，不按原文顺序罗列。

---

### 10_1 读法：先搞懂框架，再谈记忆

百则共 100 句，每句五字（少数六字），一句一法。但**它的内在逻辑不是线性的 100 条，而是"总纲 → 六大门类"的树状结构**。

| 模块 | 核心问题 | 代表口诀 | 在流程中的位置 |
| --- | --- | --- | --- |
| **A · 局势基调** | 这事整体吉凶、宜动宜静 | 前后引从、六阳六阴、旺禄临身 | 第 1 步 |
| **B · 生克制化** | 凶神能否被制、吉神是否反噬 | 众鬼虽彰、狐假虎威、传财太旺 | 第 4 步（最核心） |
| **C · 进退取舍** | 该进该退、该守该变 | 进茹空亡、有始无终、苦去甘来 | 第 5 步 |
| **D · 人我关系** | 人与人、人与宅 | 人宅受脱、交车相合、贵人系统 | 第 4 步（四课部分） |
| **E · 神将灾祥** | 天将如何发力 | 魁度天门、虎乘遁鬼、制鬼之位乃良医 | 第 6 步 |
| **F · 空亡终局** | 事之真假、迟速、应期、边界 | 喜惧空亡、非占现类、已灾凶逃 | 第 7 步 |

> **最重要的一句话**：百则之间**不是并列关系，而是有先后次序的**。理解了次序，100 句就变成了"走 6 步"。

#### 断课三问：不记得口诀时，用它现场推

| 三问 | 问什么 | 对应哪一模块 |
| --- | --- | --- |
| **一问内外** | 四课里谁生谁、谁克谁？（日干为我、日支为彼） | A、D |
| **二问时序** | 三传从初到末，是向好还是向坏？ | C、F |
| **三问转化** | 凶神来了，有没有东西能制它、能不能空掉？ | B、E |

> 三问的顺序不能颠倒：**先看关系，再看走向，最后才看有没有救**。掌握了三问，看到任何一句生僻口诀都能现场推出来。

### 10_2 模块 A：局势基调——先定"这事整体什么调子"

| 口诀 | 法理本质 | 落地要点 |
| --- | --- | --- |
| **前后引从升迁吉** | 初传在日干前为引，末传在日干后为从，前后拱护 | 记成一句话：**天干拱则人升；地支拱则宅动**（迁宅修屋）。判断仕途、晋升、项目落地，先看初末是否拱干 |
| **首尾相见始终宜** | 干上有旬尾、支上有旬首（周而复始格），事不脱、谋皆成 | 反面必须记住：占"求成、求合、求婚"大吉，占"释放、解散、散伙"反而事不脱、难解散。典型的"同格异断" |
| **帘幕贵人高甲第** | 昼占取夜贵、夜占取昼贵（贵人藏在地支下，主暗中相助） | 科考专视此神 |
| **催官使者赴官期** | 日鬼乘白虎加日干或年命，为催官 | **值空亡则是虚信**，不可当真 |
| **六阳数足须公用** | 课传全落阳支，气场光明 | 现代转译：**阳格适合公开谈判、竞标、对外发文**；只宜公事，不宜私谋 |
| **六阴相继尽昏迷** | 全阴则晦暗 | 宜私密、密谈、内部调整；易信息闭塞、受人蒙蔽 |
| **旺禄临身徒妄作** | 禄神又是旺神临干 | **被误读最多的一句**：不是"躺平哲学"，而是"你已在最优位置，向外谋求的都是空的"。实操铁律：看到禄临干，先查其他传是否空亡，再决定守成 |
| **权摄不正禄临支** | 禄神加支辰 | 不自尊大、受屈于他人，或"借宅上之禄" |

> **六阳 / 六阴 = 决策环境判据**：这不是吉凶，是"场域匹配"。阳格适合公开动作，阴格适合私下动作。**用错场域，吉课也会打折。**

### 10_3 模块 B：生克制化——六条全是反直觉

| 口诀 | 法理本质 | 落地要点 |
| --- | --- | --- |
| **众鬼虽彰全不畏** | 三传皆鬼（极凶），但干上有制鬼之物，鬼不能为害 | **凶局的解药在干上**。看到满盘鬼爻先别慌，立刻检查干上是否有制鬼之神 |
| **虽忧狐假虎威仪** | 丁火畏子水，但依赖支上未土制水护住丁干 | 与"众鬼不畏"是同一逻辑的 AB 面：**一个是自身有本钱，一个是靠山帮忙** |
| **鬼贼当时无畏忌** | 当令之鬼贪旺不克，但时令一转即发 | **祸是延迟，不是消失**。占病占讼，当下没事不等于没事，要问"什么时候转坏"。这条**直接给出应期：凶在将来时令** |
| **传财太旺反财亏** | 三传皆财又逢财旺之月，财贪生旺不肯来就我 | 取财时机口诀：**身旺财衰时取，财太旺时别硬拿**。遇此，正确动作是"等"，不是"冲" |
| **脱上逢脱防虚诈** | 干生上神、上神又生天将，层层泄耗 | **被最严重低估的一条**：现代不应只断失窃，**更多应类比为大额消费、被平台抽佣、投资回报被层层剥皮** |
| **空上乘空事莫追** | 干上旬空又乘天空 | 指空划空，全无实象，事不必追 |

#### 模块 B 的共同心法

> **永远寻找"第三股力量"。** 凶来了，不要只盯凶，要去找能制它的那一股。

**顺序铁律**：凶神来了，先看"有没有制"，再看"空不空"，最后才看旺衰。**顺序不能反**——先看旺衰，你会在最凶的地方浪费时间；先看"制"，你往往三步之内就找到出路。

### 10_4 案例小故事：旺禄临身的人，与舍禄求财的人

**背景**：某人有一份稳定且待遇不错的工作（禄临身之象），却因为初传见财、中传见生，动了跳槽去做生意的念头。

**课象分析**：若只按字面读"初传财旺"，这是个该动的课。但按百则的次序先查一遍会发现：初传之财、中传之生，皆落旬空——**看上去很美的那一段，全是空的**。

**这正是"旺禄临身徒妄作"要说的**：不是让你躺平，而是**你已经处在最优位置，向外谋求的那部分才是空的**。

**经过**：他把初传之财、中传之生逐一查了一遍，发现两段皆落旬空。也就是说，课里那点"看起来更好"的东西，其实是没有内容的。

**转折点**：真正让他定下心的，是反过来确认了一次——禄神临干且旺，是实的。一边是实的现成之利，一边是空的许诺，这一比就不用犹豫了。

**结果**：他没动。两年后原单位调整，他因资历完整而被提拔；同期跳出去的人，多数在空掉的财上打了转。

**可复制动作**：

1. 这条口诀给的操作铁律：**看到禄临干，先查其他传是否空亡，再决定守成。**
2. **"守"不是消极，是因为课里能拿的东西已经在手里了。**
3. 判断顺序：先确认"禄临干"是真（禄神又旺），再查其他传是否空，最后才下"守"的结论。

### 10_5 案例小故事：当令之鬼，祸是延迟不是消失

**背景**：有人占一场纠纷，课上见鬼，但鬼正当令。

**课象分析**：按"鬼贼当时无畏忌"，当令之鬼贪旺不克——它正忙于自己生长，暂时无意克我。

**经过**：有人据前半句断"当下没事"，于是既没有做准备，也没有设观察点。事态平息了一阵，看上去判断没错。

**转折与误判风险**：若据此断"没事"，就完全读反了。这条口诀的后半句是"**待夏秋其祸乃发**"——时令一转，鬼失其旺而恢复克性，祸就发作了。

**正确的断法**：当下确实不至于爆发，但**要问"什么时候转坏"**。这条直接给出应期：凶在将来时令（鬼失旺、或我失令之时）。

**结果**：后来这场纠纷果然在一个节点上集中爆发，时间点正落在鬼失其旺、我方又失令的那一段。若当初只按"当下没事"处理，就不会提前做任何准备。

**可复制动作**：

1. 遇到"当下看着没事"的凶课，先查鬼是不是当令。当令 = 暂缓，不等于消失。
2. 占病、占讼尤其要问"什么时候转坏"，而不是"现在有没有事"。
3. 把这句口诀的完整版记牢：**鬼贼当时无畏忌，待时令转则其祸乃发**。只记前半句的人，会断出完全相反的结论。

### 10_6 模块 C：进退取舍——人生决策的核心算法

| 口诀 | 法理本质 |
| --- | --- |
| **避难逃生须弃旧** | 三传皆无益（空 / 鬼 / 脱），唯干上逢吉 |
| **朽木难雕别作为** | 斫轮课中卯逢空为朽木 |
| **进茹空亡宜退步** | 进连茹三传皆空 |
| **踏脚空亡进用宜** | 退连茹三传皆空 |
| **有始无终难变易** | 初传长生、末传墓 |
| **苦去甘来乐里悲** | 末传子孙克初传之鬼为先苦后甘；干支见鬼、传见子孙为先乐后悲 |

> 这六条的**判据与动作**（弃三传守干上、宜退、宜进、早做退路、坚持、见好就收）见板块9，此处不重复。

#### 三句必须记住的推论

1. **末传定吉凶**：任何占断，**末传是最终落点，初传是表面开局**。
2. **"别被好的开局迷惑"**与"熬过开头就好"是同一条的两种应对，取决于末传是好是坏。
3. **进茹与踏脚方向相反**，极易搞混。记忆锚点：**"脚下踩的都空了，只能往前走"**。

> 完整的进退决策表见板块9。

### 10_7 模块 D：人我关系——干支、交车、贵人系统

| 口诀 | 含义 | 落地 |
| --- | --- | --- |
| **交车相合交关利** | 第一课与第三课交叉看生克刑害（长生、财、脱、害、空、刑、克、冲、合，共十等） | 合作、交易首看此 |
| **上下皆合两心齐** | 干上神作六合、地盘干支亦作六合 | 双方同心 |
| **彼求我事支传干** | 初起支、末归干，别人来求我 | 可以守住条件 |
| **我求彼事干传支** | 初起干、末归支，我求人 | 俯仰由人、受抑勒，**正确策略是降低预期、准备被压价** |
| **眷属丰盈居狭宅** | 三传生干、反脱支，人旺宅窄 | **切忌迁居** |
| **屋宅宽广致人衰** | 三传脱干、反生支，宅广人稀 | **速宜迁居** |
| **三传递生人举荐** | 三传层层生日干 | 有人一路举荐（贵人链） |
| **三传互克众人欺** | 三传层层相克 | 被人多方围攻欺凌 |

#### 三条现代转译

1. **"支传干 vs 干传支"是判断"谁主动"的唯一标准**：在合作、谈判、求职里极其好用——"我求彼"格局下，正确策略是降低预期、准备被压价；"彼求我"格局下，可以守住条件。
2. **"眷属丰盈 / 屋宅宽广"**：买房不要"一步到位买太大"，人多住大房、人少住小房才是吉配。**核心原理是系统平衡，强行打破反而招灾。**
3. **"三传递生 vs 互克"是人际生态诊断**：判断要不要做某件事，先看三传是递生还是互克，比看单神吉凶可靠得多。

### 10_8 模块 E：神将灾祥——天将如何改变定性

| 口诀 | 含义 | 落地 |
| --- | --- | --- |
| **魁度天门关隔定** | 戌（河魁）加亥（天门） | 关隔，诸事不通 |
| **罡塞鬼户任谋为** | 辰（天罡）加寅（鬼户） | 闭塞鬼门，**诸谋可成** |
| **两蛇夹墓凶难免** | 两螣蛇夹墓神 | 凶险难避 |
| **虎视逢虎力难施** | 白虎重重 | 力量难施 |
| **太阳照武宜擒贼** | 太阳临玄武 | 贼可擒、失物可获（现代：追讨、维权有利） |
| **后合占婚岂用媒** | 天后加六合 | 不用媒妁自合（现代：自由恋爱成） |
| **干乘墓虎无占病** | 干上墓加白虎 | 占病大凶 |
| **支乘墓虎有伏尸** | 支上墓加白虎 | 宅有伏尸（房屋阴气、旧疾） |
| **受虎克神为病症** | 被白虎所克之神 | 即病位 |
| **制鬼之位乃良医** | 能制鬼之处 | **治病之方（以克论治）** |
| **虎乘遁鬼殃非浅** | 白虎乘遁干鬼 | 灾殃深重 |
| **鬼临三四讼灾随** | 日鬼临三、四课 | **讼病随来** |

#### 两句最值得记的

> **"制鬼之位乃良医"——这是百则中最具实操价值的一句，也是"易学治病思路"的精髓**：哪里能克制那个"鬼（致病之因）"，哪里就是解药或治方。占病、占危机、占困境都通用。**找"制"就是找"解决方案"。**

**双红线**：**"虎乘遁鬼殃非浅"** 与 **"鬼临三四讼灾随"** 是疾病与官司的高危信号——看到白虎加遁鬼、日鬼临三四课，立刻升级为"高危"，不可轻断。

### 10_9 模块 F：空亡与终局——真假、迟速、边界

| 口诀 | 含义 | 落地 |
| --- | --- | --- |
| **喜惧空亡乃妙机** | 吉神怕空、凶神喜空 | 空亡双向：凶空则祸散，吉空则喜虚。**先分清是吉神还是凶神，再断吉凶** |
| **旬内空亡逐类推** | 空亡按旬（类神）逐条类推 | 哪一类神空，就断哪一类事虚 |
| **三六合万事喜忻** | 三合、六合主和合 | 凡事喜悦 |
| **合中犯杀蜜中砒** | 合中带克 | **蜜里藏砒，表面好内里毒** |
| **初遭夹克不由己** | 初传被上下夹克 | 身不由己，受制于人 |
| **任信丁马须言动** | 值丁、驿马 | **必有动向**（丁主变动，马主行程） |
| **来去俱空岂动宜** | 来去皆空 | **不宜动**（与"丁马言动"相反相成） |
| **非占现类勿言之** | 没问到的类神别乱断 | 占病不说财，占婚不说官 |
| **常问不应逢吉象** | 无事来占却逢吉象 | **反常，必有隐情**，要反问对方真正想问什么 |
| **已灾凶逃返无疑** | 已遭灾逢凶 | **逃不掉的确认**（应期已定） |

#### 三组对照，最易记混

| 对照 | 一条 | 另一条 |
| --- | --- | --- |
| **动与静** | 有丁、有驿马 → 必动 | 来去俱空 → 不动 |
| **合的两面** | 三合六合 → 和合喜悦 | 合中犯杀 → 蜜里藏砒 |
| **空的两面** | 凶神空 → 转危为安 | 吉神空 → 虚喜一场 |

> **矛盾时怎么办**：丁马与来去俱空同见，看哪个力量更旺、是否空亡。

### 10_10 占断的边界与职业伦理

> **"非占现类勿言之" + "常问不应逢吉象" = 占断的职业伦理与边界**

| 条文 | 含义 | 作用 |
| --- | --- | --- |
| 非占现类勿言之 | 对方没问的类，不要擅自发挥 | 防止"什么都断一点"的江湖病 |
| 常问不应逢吉象 | 无事来占却得吉象，往往是"事在隐瞒"的信号 | 要反问对方真正想问的是什么 |

这两条合起来，就是"**守住边界，警惕反常**"，放到任何咨询场景都适用。

### 10_11 案例小故事：一张"合中犯杀"的合同

**背景**：有人占一笔合作能不能签。课中第一课与第三课交车相合，表面看是"交关利"，双方都有诚意，条款也谈得差不多。

**经过**：他起初只看到"交车相合"，便按"交关利"断吉，准备签。

**转折点**：往细处再看一层——这个"合"里带着刑，正是"**合中犯杀，蜜里藏砒**"。合不是不好，但这个合里藏着一处不对等：对方在合的掩护下，把风险转嫁到了某一项条款上。

**判断**：能签，但签完之后会有一个持续的麻烦，麻烦不在价格，在责任划分。

**结果**：合作顺利启动，一年后因责任归属产生纠纷，麻烦点正是合同里那句被"合"模糊掉的表述。

**可复制动作**：见合先停一步，问"这个合里有没有刑冲破害"；把"合中犯杀"写进合同类占断的必查项。

### 10_12 案例小故事：被误读的"旺禄临身"（反面版）

**背景**：与 10_4 的正例相对，这里看一个误读的反面。有人把"旺禄临身徒妄作"理解成"课里见禄就该按兵不动"，于是凡见禄临干一律劝人别动。

**经过**：有一课，禄虽临干，但三传走势明显向好，末传生干且不空。他仍劝对方"守住别动"，对方听从，错过了一次明确的晋升机会。

**转折点**：复盘时他发现自己漏掉了这条口诀的后半截动作——"**看到禄临干，先查其他传是否空亡，再决定是否守成**"。这一课三传不空、末传生干，属于"禄虽临身但外传亦实"，本该动，不该守。

**结果**：机会被别人拿走。这次误判让他记住：**把条件式口诀当一刀切用，比不记这条口诀更有害**。

**可复制动作**：禄临干 + 其他传空 = 守；禄临干 + 其他传实且吉 = 可动。凡给"守"的建议，必须写出依据（外传皆空？末传克干？），写不出依据的"守"多半是误读。

### 10_13 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **三问自推** | 遇到记不全的口诀，用 10_1 的三问现场推：谁生谁克？初末走向？有没有制与空？ | 不再依赖死记 |
| **六模块定位** | 每读一句口诀，标注它属于哪一模块、对应七步法的第几步 | 100 句变成"走 6 步" |
| **找第三股力量** | 每遇凶格，写下一句"谁能制它" | 断凶也能给出路 |
| **查禄先看空** | 见禄临干，先查其他传是否空亡，再判"守"或"动" | 不再把"旺禄临身"一刀切 |
| **问转坏时间** | 见当令之鬼，必问"什么时候转坏" | 不再把暂缓当消失 |
| **写动词** | 断课先把问句动词写下来，再解释格局 | 不再踩"同格异断"的坑 |
| **查合中犯杀** | 见合先问：合里有没有刑冲破害 | 合同类占断不再漏掉暗藏风险 |
| **守边界** | 每次输出前检查：有没有超出对方所问的类 | 断语更聚焦，也更安全 |
