## 板块14 · 课例精析与逆向训练法

> 前面所有板块讲的是"怎么断"，这一板块讲的是"怎么练"。区别在于：**靠灵感的人断对了说不出为什么，练出来的人断错了能定位错在哪一步。**

---

### 14_1 邵氏断法的四个特征（可直接照做的操作规范）

| 特征 | 内容 | 反例与正例 |
| --- | --- | --- |
| **1. 课体为纲，格局为目，三传为用，四课为体** | 先看整体气势，再看格局是否坐实，最后才点课名 | **反例**：一排盘就翻"铸印乘轩格等于升官"，直接下结论。**正例**：先问"干支谁旺、三传顺逆、发用何神、末传归处"，格局只是最后贴的标签 |
| **2. 理气定吉凶，象法断细节** | 理气答"吉凶成败"；象法答"什么事、在哪、应到谁" | 只用象法等于联想游戏；只用理气则只能说好坏、说不出细节。**两者必须同框** |
| **3. 年命是"变体门"，不是装饰** | 本命、行年上神参与生克、定吉凶、定应期、定"应到谁头上" | 不标年命的课例，往往正是读不懂的那几例 |
| **4. 应期等于旺衰乘以空亡乘以神煞，三者合参** | 三者指向同一处则确定；互相矛盾则**只说趋势** | 宁可不给精确应期，也不硬凑 |

> **格局使用纪律**：**格局是验证工具，不是起点。** 只有当格局的核心条件在课中真实出现，才引用；否则宁可不提。

### 14_2 五则经典课例：把省略的链条补出来

#### 例一 · 天时：太守占祈雪

**课式要点**：三传巳、戌、卯，正是铸印课全传。

**断语摘要**：明日天色必变，巳时风起转寒，未时有雨，亥时作雪，厚有七寸。凡铸印课，占天时必大雨雪。

| 步骤 | 依据 |
| --- | --- |
| 1. 格局坐实 | 三传巳戌卯正是铸印课全传；且立刻点出它的**天时专项**——必大雨雪。这是"格局加事类"精确匹配，不是泛称吉格 |
| 2. 气机对流 | 火伏于下、水升乎上等于天地不交而欲交，正是成雨雪的**理气条件** |
| 3. 贵人权柄在空处 | 夜贵加空亡，等于"空中降下"，把"下雪"具体到"从天而降，非由地生" |
| 4. 分时应时辰 | 巳时风（巳发用）、未时雨（未为太常主雨食）、亥时雪（亥子水旺之刻）——**应期精确到时辰，靠的是传神所临地盘的时位** |
| 5. 象法补色 | 末传卯作白虎，与申皆是白色，成雪色之象 |

**可复制动作**：占天时先找五行专格 → 看龙虎定风雨 → 看水神旺衰定大小 → 看传临地盘定时分 → **用实际天气回填验证**。

#### 例二 · 疾病：蒋公占病（情志致病的范本）

**课式**：三交卦。初传卯（螣蛇、财、落空），中传午（勾陈、鬼），末传酉（白虎、兄）。

**断语**：其患有三。若能如愿，尚可活七八年，否则情死定死矣。

**反馈**：心中躁怒得病，喜食酸咸。诸子从其言娶回该女，病渐减，七年后方终。

| 步骤 | 依据 |
| --- | --- |
| 1. 定病因类别 | 三交加空亡加六合，等于"不正之合"，病由情欲、非由外感 |
| 2. 初传卯空（财空） | 所欲不得、情不得遂，故烦躁 |
| 3. 行年在末传 | 带禄居火上，为鬼所弄，故贪食生冷酸咸（象法定症状细节） |
| 4. "若能如愿，尚可活七八年" | 邵公给出的不是死判，而是**行动指引**：遂其心愿则病减、延年 |

**可复制动作**：占病先定病因类别（外感、情志、旧疾）→ 找病位 → 找制鬼之位 → 查救神 → **结论必须给行动指引，且明确建议就医**。

#### 例三 · 宅墓：三翁占宅

**课式**：干上卯（天后、财），干阴戌（勾陈、印）；支上申（天空、比），支阴卯（天后、财）。三传：卯 → 申（空亡）→ 丑。

**断语摘要**：此课乃妻为主。妻本兄之妻而汝得之，日后只得九年相守。第八年因作生地，与兄弟不足。目下主丧妻，缘是磨压东门，所以有再娶之患也。

| 邵公结论 | 象数依据 |
| --- | --- |
| 妻为主、妻为长 | 干上卯为财（妻财爻）且乘天后；日干主动就财 |
| 妻本兄之妻 | 财爻卯与支上申（兄弟或比肩位）相合，且传中比肩空亡 |
| 九年相守 | 类神数术配合旺衰年限。**这类"几年"断语必须结合本命行年复核，单看课式推不出** |
| 第八年因作生地生是非 | 末传丑为墓库或生地象，应到"作生坟、动土"之年 |
| 磨压东门 | 卯为门户、为正东；勾陈临之，成"磨压"之象 |

**可复制动作**：占宅先看干支谁生谁 → 三传归支则事落宅中 → 宅中方位一律用地支定 → **涉及年限的断语必须回查年命**。

#### 例四 · 抓类神：科举中五人

**课式要点**：伏吟课。青龙临辰。

**断语**：当中五人。旁人（嫌青龙内战、朱雀空亡）俱未敢许，迨榜发竟应。

**补链条**：科举取象，青龙为升迁腾飞之神——青龙临辰；戊癸辰戌合化之数为**五**，土亦为五数，辰正应"五"，故断五人。

> **这条课例教的是方法论**：当多数人纠缠于"青龙内战、朱雀空亡"的生克分析时，断者**直取象之对应**。这就是"**先取象，后论克；先找类，再谈吉**"的纯粹形态。
>
> **边界提示**：这种"纯粹的象"需要类神与事类高度贴合且无强冲突信号。若课中另有强克象，仍须回到四层结构验证。**象与生克不是对立的，是表与里的关系。**

#### 例五 · 盗贼：始获而终纵

**课式要点**：勾陈乘子，子水克玄武所乘之巳火。

| 层次 | 判断 |
| --- | --- |
| 阳（神将本身） | 勾陈克玄武，能捕获 |
| 阴（阴神落处） | 勾陈之阴神被玄武之阴神所克，获而复纵 |
| 综合 | 抓得到，但留不住——证据不足、不了了之，或被放掉 |

**可复制动作**：断任何一位天将，笔尖必须往后再走一步，看它的阴神。

### 14_3 逆向训练法四步（核心训练法）

```latex
第1步 只看案由与课式，遮住断语
      ↓
第2步 自己断：写出课体、走势、用神、救神、应期、结论（不少于 200 字）
      ↓
第3步 翻开古人的断语，逐条比对：断对了什么？漏了什么？断反了什么？
      ↓
第4步 补链条：重点追问"他那一步，是从盘上哪个位置看出来的"

```

#### 训练节奏建议

| 周期 | 数量 | 重点 |
| --- | --- | --- |
| 第 1 个月 | 每两周 1 则（共 2 则） | 慢做，把链条补到不能再补 |
| 第 2 个月 | 每周 1 则（共 4 则） | 开始关注"漏了什么" |
| 第 3 个月起 | 每周 1 至 2 则 | 建立自己的常错清单 |

> **关键动作**：第 4 步最值钱。断对了不重要，**知道他为什么对**才重要。看到"朱雀临空"就写下"文书不成"这一条映射，下次你自己就能用。

### 14_4 "补链条"练习的五种追问

每则课例精析完，用这五个问题自查：

| 追问 | 内容 |
| --- | --- |
| 1. 类神是谁？ | 这件事的正类取对了吗？入课传了吗？ |
| 2. 它在哪一步被锁定？ | 是旺衰锁定的，还是象法锁定的，还是两者合参？ |
| 3. 有没有救神？ | 凶课里，古人有没有指出路？指出在哪？ |
| 4. 应期怎么来的？ | 旺衰、空亡、神煞三者是否指向同一处？ |
| 5. 年命起了什么作用？ | 若去掉年命，这则课例能不能看懂？ |

> 第 5 问是分水岭：**读不懂的古课，八成答案在年命上。**

### 14_5 案例小故事：遮住断语之后

**背景**：有人读古课，习惯直接看断语，看完叹一句"真准"，翻下一页。读了半年，断课水平毫无长进。

**经过**：后来他改用逆向法：拿一张纸盖住断语，先自己断。第一次自断时，他发现自己连"这件事该取什么类神"都要想十分钟——**原来他半年来只是在欣赏别人的结论，从未自己走过一遍流程。**

**转折点**：遮住断语的第三周，他第一次在"补链条"环节发现：古人的一句断语，其实是从三个不同位置各取一条信息交叉验证出来的（旺衰加类象加年命）。他自己断的时候只用了一个位置，所以断得粗。

**结果**：这个发现让他此后每断一课都习惯性地问：**我这条结论，有几个独立信号支撑？** 一个信号则存疑；两个则倾向；三个以上则确定。这正是可信度分级的由来。

**可复制动作**：

1. 逆向训练的核心不是"猜对"，而是**看见自己的断点**。
2. 每则课例精析完，用 14_4 的五个追问自查。
3. 建立"象—断语"映射卡片：学到一条就记一张，积累 50 条后，断课开始有话可说。

### 14_6 课例材料的两段式读法：《断案》四段式与《指南》卷四
《大六壬断案》每例固定四段，结构极其朴素：

| 段 | 内容 | 层次 |
| --- | --- | --- |
| 1. 案由 | 某人生年 + 岁数 + 所问之事 + 占时（年、月、日、月将、时辰） | 输入层 |
| 2. 课式 | 天地盘、四课、三传、十二天将、六亲、课名 | 结构层 |
| 3. 断语 | 邵彦和当场说出口的话 | **结论层** |
| 4. 析曰 / 验 | 事后补写的推演逻辑与事实反馈 | **证据层** |

第 3、4 层之间，往往隔着一条完整的象数推理链，**这条链才是全书真正的内容**。把它当成"神算故事集"来读，读完三遍水平也停在"知道邵公厉害"；把链补出来（方法见 14_3、14_4），它才从故事变成方法。

《大六壬指南》成书于清顺治九年，陈公献（字良谟，扬州将门之后）定稿，全书五卷，卷四《占验指南》收 125 则占验课案，是继《断案》之后最好的逆向工程素材。**卷四的用法与 14_3 的四步完全一样**——遮断语、写判据、对照、补链条。

**卷与卷之间是体用关系，不要单读卷四**：卷一《心印赋》讲原理（体），卷二《指掌赋》讲操作（用），卷三《会纂》是分类模板。读一句心印，就在卷二里找对应的操作句，再拿卷四的一则课例去印证，三段一组。卷三的模板只告诉你这一类事通常看哪些位，**具体吉凶仍要回到旺衰、类神、年命上判**。

> **为什么陈公献的断语难读**：他常常只写结论，不写过程，或者只点一个象、省略其余，所谓"顾东言西、藏头露尾"。这正是训练的价值所在——你必须自己把链条补全，才叫读懂了一例。
