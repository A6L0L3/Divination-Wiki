## 板块3 · 起课工程（下）：贵人天将、六亲、旬空、年命

> 起课工程的最后一段。四课与三传已在板块2完成，本篇把天将、六亲、旬空、年命补齐，一课至此排完。

---

### 3_1 起贵人：十二天将的起点

#### 贵人起例（必背）

> 甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸蛇兔藏，六辛逢马虎，此是贵人方。

（上字为昼 / 阳贵，下字为夜 / 阴贵）

| 日干 | 阳贵（昼贵） | 阴贵（夜贵） |
| --- | --- | --- |
| 甲、戊、庚 | 丑 | 未 |
| 乙、己 | 子 | 申 |
| 丙、丁 | 亥 | 酉 |
| 壬、癸 | 巳 | 卯 |
| 辛 | 午 | 寅 |

#### 昼夜分界与顺逆

| 项目 | 规则 |
| --- | --- |
| **昼夜分界** | 得卯辰巳午未申六时用**阳贵**；得酉戌亥子丑寅六时用**阴贵**。按占时地支所属六时定，不按日出日落 |
| **顺逆** | 贵人临地盘亥子丑寅卯辰六位时**顺行**；临巳午未申酉戌六位时**逆行** |

> **最易错点**：贵人的"落宫"（在地盘哪一支）与"顺逆"是两件必须分别确定的事，缺一不可。漏掉顺逆，十二天将整体镜像，后面所有天将断语全错。

### 3_2 布十二天将

#### 十二天将顺序（固定，循环排布）

```latex
贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙
     → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后

```

**排法**：贵人起在地盘某支上，按顺或逆依次把十二将排入天盘十二位——即从贵人所在之支起，按顺行或逆行方向，把十二将依次加在天盘各支上。

| 排布方向 | 条件 |
| --- | --- |
| 顺行 | 贵人落在地盘亥、子、丑、寅、卯、辰六位 |
| 逆行 | 贵人落在地盘巳、午、未、申、酉、戌六位 |

**排完之后要标四处**：初传乘何将、中传乘何将、末传乘何将、干上与支上各乘何将。这四处是断课时用得最多的位置。

### 3_3 配六亲

以日干为基准，对课传中每一位神定六亲：

> 生我者父母，我生者子孙，克我者官鬼，我克者妻财，比和者兄弟。

| 六亲 | 判定 | 在断课中的角色 |
| --- | --- | --- |
| **父母** | 生日干 | 文书、资质、店面、长辈、营生根基 |
| **子孙** | 日干所生 | 医药、福神、制鬼之物、消耗我之神 |
| **官鬼** | 克日干 | 病、祸、官司、职位（视事类而定吉凶） |
| **妻财** | 日干所克 | 钱财、短期收益、男命之妻 |
| **兄弟** | 与日干比和 | 同辈、竞争者、分利之人 |

> 六亲定完之后，**类神才有伦理归属**。同一位神，在求财课里是"妻财"，在疾病课里可能就是"官鬼"——取类的方法见板块8。

### 3_4 查旬空

以日干支所在旬为准（同旬论空亡），查出空亡的两支，标在课式上。

| 旬 | 空亡 |
| --- | --- |
| 甲子旬 | 戌亥 |
| 甲戌旬 | 申酉 |
| 甲申旬 | 午未 |
| 甲午旬 | 辰巳 |
| 甲辰旬 | 寅卯 |
| 甲寅旬 | 子丑 |

**操作要求**：任何一位神将、类神、初传、中传、末传，都要问一句"它空不空"。空亡的双向性质与判据见板块7。

### 3_5 排年命

| 项目 | 推法 | 观察内容 |
| --- | --- | --- |
| **本命** | 生年地支 | 看地盘本命位上所乘的天盘神与天将，及其与日干的生克 |
| **行年** | 男一岁起丙寅顺行，女一岁起壬申逆行（另有"男一岁起寅顺推、女一岁起申逆推"的表述，择一后固定使用，不临时更换） | 看行年所落地盘之神与天盘生克 |

**实操动作**：把本命、行年标在课式旁边。年命如何参与生克、如何造成"同课异断"，见板块8。

**两条易错提醒**：

1. **行年推法有两套表述**（男起寅顺推、女起申逆推；以及男一岁起丙寅顺行、女一岁起壬申逆行）。二者只是起点命名不同，顺逆方向一致。**选定一套后固定使用**，不要在这一课用甲说、下一课用乙说。
2. **本命看的是地盘本命位**，不是天盘。看地盘本命位上所乘的天盘神与天将，以及它们与日干的生克关系。

### 3_6 遁干：明处无碍，暗藏隐患

遁干是天盘支上所藏的天干，用于查"遁鬼"——明面看不出的隐患。

| 用法 | 说明 |
| --- | --- |
| **查遁鬼** | 若某位神明处为财，遁干却为官鬼，即"财遁鬼"，主因财生祸 |
| **明暗对照** | 明吉遁凶 → 防暗损；明凶遁吉 → 尚有默益 |
| **必查场景** | 求财、疾病、官讼三类，遁干是必查项 |

> 多数排盘软件会标出遁干，但手排时最易漏。建议在起课纸上单列一栏"遁干"，排完即填。

### 3_7 起课顺序的固化清单

```latex
□ 查日辰（跨子时换日？闰月核对？）
□ 取占时（正时？真太阳时校正？）
□ 定月将（中气区间？）
□ 月将加时排天盘（偏移量校验？）
□ 立四课（第二课用了第一课的上神？）
□ 查贼克、走九宗门取三传
□ 起贵人（昼夜？落宫？顺逆？）
□ 布十二天将（初末干支四处都标了？）
□ 配六亲
□ 查旬空
□ 标遁干
□ 排本命、行年

```

> 顺序不许颠倒。**占时没定就排月将，是新手最常见的顺序混乱**；四课没排完就取传，是第二常见。

### 3_8 案例小故事：贵人顺逆排反的那一课

**背景**：有人排课一向顺利，某日却遇到一课怎么都读不通：明明课式结构清楚，但天将一读进去，处处矛盾——该主文书的朱雀落在了完全没有文书象的位置，该主凶的白虎却落在一个无关紧要的角落。

**经过**：他先怀疑是自己旺衰判错，又怀疑类神取错，反复核对了三四遍，课式与三传都没有问题。

**转折点**：最后他把注意力放到天将上，重新看贵人的落宫与顺逆——发现他定了落宫，却**忘了判顺逆**，直接按顺行排了十二将。而这一课的贵人恰好落在逆行区间，于是整排天将镜像翻转：朱雀跑到了太常的位置，白虎跑到了六合的位置。

**结果**：改正顺逆之后，整课豁然贯通——朱雀回到文书位且旺相生干，正是"文章显"的象，与来意完全吻合。

**可复制动作**：

1. **贵人落宫与顺逆是两件事**，必须在起课纸上分两栏写，不能合并成一步。
2. 若遇到"课式清楚但天将处处读不通"，**第一怀疑对象就是顺逆**。这是天将层最常见的错误，比旺衰判错的概率高得多。
3. 排完天将后，抽查一位天将（如朱雀）是否落在你预期的位置上，可以三秒发现镜像错误。

### 3_9 案例小故事：答案不在四课三传，在行年上
《大六壬断案》占宅例中，有一课的结论看着无从下手，原文却把依据写得明明白白。

**背景**：刘将仕庚午生四十岁占宅，己酉年五月戊申日未将卯时。邵公断他"即恋一旧妾，又讨一新妾，精气衰耗，渐不支持"。

**经过**：课式里的线索不少——三传皆财，是"家贼所偷"；宅上子作螣蛇，主子息非理废用；子作沟渠、上加辰作元武，故沟渠为土淤塞。但"两妾"这个具体到人的结论，是从哪一位看出来的？

**转折点**：原文自己给了答案："**盖因酉作勾陈，加行年，又在日上，是有两婢也。**"

关键不在四课，也不在三传——**在行年**。酉（婢妾之类）乘勾陈，恰好加在求占人的行年之上，同时又临日干之上，两处同指，所以断为两人。

**结果**：刘将仕"果有亲旧二宠"。这一课后续的应期（丁巳年退八分、庚申年退尽、辛酉年四月脏毒死）也一路与行年、太岁的推移相扣。

**可复制动作**：

1. **每课必标本命与行年，并且单独写一行**——许多断语的"为什么"，只在年命上找得到。
2. 年命上神既要参与生克，也要参与取象：它落在哪里、乘什么将，往往决定"这件事应到谁头上、以什么形态出现"。
3. 生年与生日的边界要核实（古籍中就有"未交生日"导致生年相差一轮的校记），行年偏一岁，断语就对不上。

### 3_10 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **秒答贵人** | 随机报"日干 + 时辰"，立刻答出阳贵 / 阴贵落宫与顺逆 | 10 组全对 |
| **标四处天将** | 每课必标初传、中传、末传、干上、支上各乘何将 | 断课时不再临时回查 |
| **填遁干栏** | 起课纸上单列遁干一栏，排完即填 | 求财、疾病、官讼三类课不再漏查 |
| **固化顺序** | 按 3_7 的十二项清单逐项打钩 | 连续 10 课零差错 |
