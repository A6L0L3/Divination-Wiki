## 板块4 · 盘面语言：天地盘、四课与三传怎么读

> 起课三篇解决"排得对"，从本篇开始解决"看得懂"。盘面是一套语言：天地盘是语法，四课是词汇，三传是句子。先学会读，才谈得上断。

---

### 4_1 天地盘：主客、内外、动静的总开关

|  | 地盘 | 天盘 |
| --- | --- | --- |
| 动静 | 静、固定 | 动、随时流转 |
| 象征 | 地、方位、地气、内、我 | 天、太阳气机、外、客 |
| 排法 | 固定方盘 | 月将加时顺排 |
| 断法含义 | "落宫"：此神落在何处，即受该处地支影响 | "加临"：来势、主动方 |

> **口诀**：天旋地静，阴阳相交；**月将加时，顺布天盘**。无月将则无天盘，无天盘则无四课三传，全课不立。

**实操含义**：读到任何一个神将，都要问两句——

1. 它**乘**（加临）在哪一支上？（来势、外显）
2. 它**落**（地盘本位）在哪一宫？（处境、根基）

这就是后面要反复用到的"**阳现其象，情归于阴**"。

---

### 4_2 四课：四面镜子的阅读顺序（顺序不能乱）

四课的作用不是找用神，而是**定"体"**——这件事现在处在什么结构里。

```latex
第1步 干上神对日干：生我等于得助，克我等于受压，比和等于同类
      ↓
第2步 支上神对日支：对方或环境当下状态如何
      ↓
第3步 干上神与支上神之间的关系：这是"我到对方"的互动主轴
      生合则通，战克则阻，刑则不投，冲则难合，害则有阻，破则无成
      ↓
第4步 两阴神：干阴为我真正的动机与顾虑；支阴为对方背后是否有人撮合或作梗
      ↓
第5步 四课见空亡：该侧面信息残缺、力量落空，不可据空位断实有其事

```

#### 干支关系速断框架

| 关系 | 含义 |
| --- | --- |
| 支加干而生干 | 彼就我、助我（吉） |
| 干加支而受生 | 我就彼、彼助我 |
| 支加干而克干 | 彼就我、欺我（凶） |
| 干加支而受克 | 我就彼、受欺 |
| 支加干而与干比和 | 彼就我、培我 |
| 干上神生支、支上神生干 | 彼此相生，两家顺利 |

> **常见误读**：把四课当四个并列信号平均用力。正解是"干上 → 支上 → 双方关系 → 两阴神"，逐层深入，越往后越接近真相。

---

### 4_3 阴神：读四课最容易漏的一层

> **"阳现其象，情归于阴。"**

| 项目 | 告诉你什么 |
| --- | --- |
| **阳神**（某位本身） | 事象是什么（表象） |
| **阴神**（该位所临地盘上的上神） | 内情、动机、根子在哪 |

四课中第二课是干阴、第四课是支阴；此外，**任何一位天将也都有自己的阴神**（天将所临地盘位上的上神），这一点在板块6会详述。

**实操要求**：读四课必须读到第二、第四课，读天将必须读到阴神。只读阳神，你只看到一半。

---

### 4_4 空亡在四课上的特殊含义

| 情形 | 断法 |
| --- | --- |
| 干上神空亡 | 我方这一面信息残缺、底气落空，不可据此处断实有其事 |
| 支上神空亡 | 对方或事体本身虚浮，事难落实 |
| 干阴空亡 | 我的真实动机是虚的，或我自己也没想清楚 |
| 支阴空亡 | 对方背后无人真正推动 |

> 四课见空，第一反应不是"凶"，而是**"这一面的信息不可靠"**——断课时这一面要降权，不能作为主判据。

---

### 4_5 案例小故事：被支阴神改写的合作判断

**背景**：有人占一笔合作，看四课的前三层都很好：干上神生干（我得助力），支上神不克干（对方不欺），干上支上相合（双方投契）。他据此断"合作可成且顺"，准备签。

**经过**：签完之后，合作推进得异常艰难——对方对接人态度一直很好，但每一次需要拍板时都推说"要请示"，请示之后再无下文。三个月后项目不了了之。

**转折点**：复盘时他补读了第四层——**支阴神**。支阴上乘天空，又落旬空。支阴代表"对方背后是否有人真正推动"，天空加空亡，正是**对方背后没人、上层未真正点头**的象。

**结果**：前三层看到的"投契"是真的，但那只是对接人层面的投契；支阴告诉他，这件事在对方内部根本没有实权支撑。

**可复制动作**：

1. **四课必须读到第四课**。只读到"干上支上相合"就下结论，等于只看了表面关系。
2. **支阴落空或乘天空**，在合作、谈判类占断中是一个独立的红灯——它说的是"对方这边没有人真正兜底"。
3. 涉及签约、合伙这类需要对方内部推动的事，把"支阴"列为必查项，写进场景检查表。

### 4_6 案例小故事：婢女为什么还会回来
阴神这一层，古籍里有一则几乎是为它量身定做的课例。

**背景**：《大六壬断案》占宅例，任三翁庚午生三十九岁占宅，戊申年十一月壬寅日丑将申时。邵公断："因婢妾相争，遂出其婢，而后再归，却与宅有合。"

**经过**：先看表面——婢妾相争，被撵出去了。事情到这里就该结束了。可邵公接着断了第二句：**她还会回来**。

**转折点**：原文交代了依据："**何以知婢再归？盖天盘酉之阴神，却乃寅加酉，又是宅也。** 兼酉加辰与辰合，天将勾陈夹住，勾陈为牙人，故主辰日其婢再还也。"

拆开看：酉为婢，酉本身只给出"被逐"之象；**酉的阴神**却落到寅，而寅加酉又是宅位——阴神指向"回到宅中"，于是断"再归"。又因酉与辰合、勾陈为牙人（中间人），所以断"经人撮合，辰日回来"。

**结果**："果一一如占。"

**可复制动作**：

1. 看到一位天将或一个类神，笔尖必须**再往后走一步**，看它的阴神。
2. 阴神决定**背后的真实**：阳神是表现，阴神是内情。"撵走"是阳神，"还会回来"是阴神。
3. 断"会不会再发生"，重点不在本神，而在阴神落处——落回宅则归，落空亡则不至，落他处则另有去向。

### 4_7 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **五步读法** | 严格按 4_2 的顺序读，不许跳步 | 每课都能说出"干上 → 支上 → 互动 → 阴神"四句话 |
| **必读阴神** | 每课写完第二课、第四课的象义 | 断语开始出现"对方背后有没有人"这类判断 |
| **空亡降权** | 四课见空，在笔记上标注"此面信息不可靠" | 不再拿空位当主判据 |
| **乘落两问** | 读到任何神将都问：它乘在哪、落在哪 | 形成固定的两句自问 |

### 4_8 三传：事之三幕剧

| 传位 | 别名 | 角色 | 断法要点 |
| --- | --- | --- | --- |
| 初传 | 发用、发端门 | 起因、导火索、当下吉凶源头 | **最重**："克处是动机"，休咎之机关乎发用 |
| 中传 | 移易门 | 发展、转折、阻碍或贵人 | 初凶中吉可转凶为吉，反之亦然 |
| 末传 | 归计门 | 结果、归宿、最终落点 | 末传生扶日干则结局好；克害日干则结局差 |

> **一句话原则**：**初传看起因，末传定成败。** 任何占断，末传是最终落点，初传是表面开局。"别被好的开局迷惑"和"熬过开头就好"都是这条的推论。

### 4_9 三传与干支的归属（判断"谁求谁"的核心）

| 格局 | 条件 | 含义 |
| --- | --- | --- |
| **朝日格** | 自支上发用、传归干上 | **人来托我干事**，易于成合，守即可 |
| **朝枝格** | 自干上发用、传归支上 | **我去求人干事**，不得自由，受抑勒 |
| **回还格（如珠走盘）** | 三传不离四课 | 变化甚微，**宜守旧不可轻举妄动**；忌占病讼、忧产 |
| 三传不离干支 | — | 求物得、谋事遂、行人回 |

> **在合作、谈判、求职里极好用**："我求彼"格局下，正确策略是降低预期、准备被压价；"彼求我"格局下，可以守住条件。

---

### 4_10 三传的四种走势（拿到课先判走势）

| 走势 | 判定 | 断法 |
| --- | --- | --- |
| **顺生** | 初生中、中生末，或三传层层生日干 | 事情顺着走，有人一路扶持（贵人链） |
| **递克** | 初克中、中克末，或三传层层相克 | 事情层层受阻，或被多方围攻欺凌 |
| **进连茹** | 三传顺行相连（如辰巳午） | 势如破竹，主快；若三传皆空则宜退 |
| **退连茹** | 三传逆行相连（如午巳辰） | 节节败退，主快；若三传皆空则宜进 |

> **进茹与退茹的关键辨析**：进茹空亡等于往前三步都是空，宜退；退茹空亡等于向后退步都是空，宜进（记忆锚点：**脚下踩的都空了，只能往前走**）。这一组判断详见板块9。

---

### 4_11 三传见空的三种断法

| 情形 | 断法 |
| --- | --- |
| **初传空** | 起因虚浮，事情开头就落空，或来意不实 |
| **中传空** | 过程中断，中间环节脱节 |
| **末传空** | 结果落空。若为凶传，则"鬼传向空"，虚惊无实祸（好事）；若为吉传，则虚喜一场（坏事） |

> 末传空吉凶相反，取决于这条传本身是凶还是吉——这正是"喜惧空亡"的双向性，详见板块7。

---

### 4_12 末传的四项判定（断课收尾必做）

```latex
第1步 末传对日干：生干则安，克干则败，脱干则耗，比和则平
第2步 末传是否空亡：空则结果落空（凶传空则转危为安）
第3步 末传是否入墓：入墓则事藏而不出，待冲方动
第4步 末传是否构成救应：末传子孙能克初传之鬼，则先凶后吉

```

### 4_13 三传与四课的关系：传出与传入

| 情形 | 断法 |
| --- | --- |
| **传出**（三传超出四课范围） | 事散漫而缓，能量外散 |
| **传入**（三传向四课内收拢） | 能量集中而急 |
| **回还**（三传不出四课） | 变化甚微，宜守 |

> 这一组判断在应期的迟速上要用，见板块11。

### 4_14 案例小故事：被好开局骗了的那一次

**背景**：有人占一个新项目要不要接。初传见财、且财旺相，他当下判断"开局就有钱进账"，兴致勃勃接了下来。

**经过**：项目启动确实顺利，第一笔款也如期到账。但此后一路下行——中传见鬼，末传为墓，且末传克干。第二季度开始问题集中爆发：客户追加需求不付钱，团队连续加班，他自己垫进去了不少。半年后项目收尾，算总账是亏的。

**转折点**：复盘时他发现，自己当时只读了初传，没读末传。课上的结构是**初传长生、末传墓**——正是《毕法赋》里"有始无终难变易"的典型形态：开头好、结局坏。

**结果**：如果当时读了末传，正确的动作不是不接，而是**接的时候就把退路设计好**——在合同里约定追加需求的价格、设定止损线、控制投入上限。

**可复制动作**：

1. **拿到任何一课，先判走势，再看末传**。初传再好看，末传是墓、是克干、是空亡，结论就要改写。
2. "初吉末凶"的正确应对不是放弃，而是**早做退路**；"初凶末吉"的正确应对是**熬过开头**。这两种应对完全不同，取决于末传。
3. 把"末传四项判定"（见 4_12）写成检查清单，每课必过。

### 4_15 案例小故事：三传一片水，八子无一存
《大六壬断案》里有一则读起来很沉重的占宅，它的结论几乎全部来自三传。

**背景**：邵巡检癸亥生四十六岁占宅，戊申年六月庚辰日午将寅时。

**经过**：邵公开口第一句就是："**金日得水局，三传日辰皆子孙爻**，脱处见青龙，生处见元武，临官上见螣蛇——一生被子息作吵，一个死了，一个又来，且生得好，取尽父母气力了方休，家计亦被子孙磨灭。"

**转折点**：这一课的关键全在三传：庚辰日，三传辰、申、子，合成**润下（水）局**；而对庚金来说，水正是**脱气**（子孙爻）。三传从初到末一路脱下去，等于"一路被消耗"。更糟的是——脱处乘青龙，生处乘元武，临官上又见螣蛇，三个凶象都叠在同一条消耗链上。

注意这里最容易读错的一处：**青龙是吉将，但落在脱气上，不是来救，而是把消耗放大。**

**结果**：邵巡检"前后生八子，或三岁、二岁、一岁即死；及婢生三子亦然；再纳一妾，又生二男一女"，"前后委被子息坏尽精气"。三传的方向，就是这件事的走向。

**可复制动作**：

1. 读三传先看**方向**：顺生、递克、还是合成某一局。局成则力量集中，吉凶都被放大。
2. 再看三传对日干的**六亲属性**：生我、我生，还是脱我。本课三传皆"脱"，所以是消耗不是收益。
3. 三传上的天将只是**加权**：脱气见青龙，不等于吉神来救。先看关系，再看乘将，顺序不能反。
