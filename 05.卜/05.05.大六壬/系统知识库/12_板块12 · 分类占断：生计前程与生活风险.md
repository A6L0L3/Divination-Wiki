### 12_2 求财占（最容易"看着有"的一类）

**类神**：妻财爻（短期、投机）、青龙（正财）；**长期经营重父母爻**。

> **关键洞察——长期求财看父母，短期求财看妻财**：这是六壬与六爻思路最大的分野。六爻求财专看妻财兼看子孙（财源）；六壬长期经营（开店、生意、生计）却重父母爻，因为父母是"生我"之本、是营生的根基（店面、资质、客源、口碑）。

#### 求财七步 SOP

| 步骤 | 检查项 | 判定 |
| --- | --- | --- |
| 1. | 取**青龙**为主（正类） | 无龙则取变通位（太常、功曹、小吉） |
| 2. | 俯仰视之：乘神与将相较，有无内外战 | 不战等于神与将和，得气 |
| 3. | 类神所临之地属十二气哪一位 | 临四吉则财强；临八凶则财弱 |
| 4. | 查类神之阴神 | 看内情、根子 |
| 5. | 查遁干 | 明吉遁凶则防暗损；明凶遁吉则尚有默益 |
| 6. | 是否落空亡 | 空则防损；神自作空则待出旬 |
| 7. | 三传有无财化鬼、财坐鬼乡、财遁鬼 | 有则为**"鬼财"，取财生祸，不可妄求** |

#### 四条红线

1. **传财太旺反财亏**（财贪旺不来就我，宜等不宜冲）
2. **财遁鬼**（因财致讼）
3. **财星空亡**（虚浮，投资占里最高频的陷阱）
4. **脱上逢脱**（回报被层层剥皮）

#### 动作卡

取青龙 → 查内外战 → 查十二气 → 查阴神 → 查遁干 → 查空亡 → 查鬼财。七步走完再下结论。

### 12_3 官禄仕进占

**类神**：官鬼（职位）、贵人、禄、青龙、帘幕贵人（科考）、催官使者。

#### 判据

| 判据 | 断法 |
| --- | --- |
| **前后引从** | 初末拱**天干**则升迁；拱**地支**则迁宅 |
| **帘幕贵人** | 昼占取夜贵、夜占取昼贵，主科考高第 |
| **催官** | 日鬼乘白虎加日干或年命为催官，**值空亡则只是虚信** |
| **三传递生** | 有人举荐 |
| **三传互克** | 受人欺压 |
| **干传支** | 求职中处于被动，宜降低预期 |

#### 动作卡

定类神（官鬼 + 禄）→ 看引从 → 看三传递生还是递克 → 看贵人是一处到位还是差迭 → 看应期（类神临支取字面）。

#### 红线

催官值空、官星空亡，都是"虚信"，不可据此做重大决定。

### 12_6 案例小故事：漏看遁干的一笔投资

**背景**：有人占一笔投资，课上财爻旺相、青龙得位，他断"可投"。

**经过**：钱投进去，回报远低于预期，还拖了很久。

**转折点**：复盘时发现，他漏看了三步中的两步。

1. **没查遁干**：财爻明处是吉，遁干却藏着鬼——正是"财遁鬼"，因财生扰的象。
2. **没查脱气结构**：干生上神、上神又生天将，层层泄耗——回报被中间环节剥掉了一层。

**结果**：他没看错财爻旺相，他只是**漏看了两道打折**。

**可复制动作**：

1. 财旺不等于能拿到手。"能拿到多少"要过三关——**遁干、空亡、脱气**。
2. 把"求财七步 SOP"写成随身卡片，每次占财逐条打钩。
3. 这张卡片挡掉的，正是这类"看着对、实际漏"的误判。

### 12_7 案例小故事：降预期，反而谈成了

**背景**：有人占一次求职谈判，课中初起干、末归支——正是"我求彼事干传支"的格局。

**课象含义**：我去求人，俯仰由人、受抑勒。**正确策略是降低预期、准备被压价。**

**经过**：他原本准备在薪资上坚持一个较高的数字。看了课之后，他调整策略：不再在薪资上硬碰，转而争取其他条件（入职时间、培训资源、明确的晋升节点），并主动表达了对职位本身的重视。

**转折点**：谈判桌上，对方果然在薪资上寸步不让——正如课里"我求彼"的格局所示，主动权不在他这边。但因为他事先准备的是"次要条款清单"，每被压一次薪资，他就换一项条件回来。

**结果**：薪资确实低于他最初的预期，但其他条件基本都拿到了，整体比硬碰的结果好。他后来总结：这一课没让他"赢"，但让他知道该在哪里让步。

**可复制动作**：

1. **"干传支"不是"不成"的信号，是"姿态"的信号**——它告诉你在这一局里没有主动权，硬碰会吃亏。
2. 正确应对：降低在主要条款上的预期，把筹码转移到对方不太在意的次要条款上。
3. 反过来，若是"支传干"（彼求我），则可以守住条件，不必过早让步。

### 12_9 疾病占（红线最多的一类）

**类神**：日干（病人）、官鬼（病）、白虎（凶象）、子孙爻（医药）、天医地医。

#### 判据（四条硬判据）

1. **受虎克神为病症**——被白虎所克之神即病位
2. **制鬼之位乃良医**——能克制致病之鬼的方位或方法即治疗思路
3. **干乘墓虎无占病**——干上墓加白虎，占病大凶
4. 三传初鬼末子孙 → 先凶后吉；末传空 → 虚惊无实祸

#### 情志致病的识别

三交 + 空亡 + 六合 → "不正之合"，病由情欲、非由外感。**这是定病因类别，不是定吉凶。**

#### 红线（出现即升级为高危）

1. 干乘墓虎
2. 虎乘遁鬼
3. 鬼临三四
4. 日干入墓绝之地又无救

#### 动作卡

定病因类别（外感 / 情志 / 旧疾）→ 找病位（白虎所克之神）→ 找制鬼之位 → 查救神（子孙、德、空亡）→ **明确建议就医，不以占断替代医疗**。

### 12_10 宅墓占

**类神**：日支（宅）、支上神；青龙太常（吉）、白虎墓神（凶）。

#### 判据（三条硬规则）

1. **干受支生 = 利宅不利人；支受干生 = 为人耗宅**
2. **三传归支** = 事落宅中、牵连家宅；**归干** = 事归于己
3. 支上墓 + 白虎 → 宅有伏尸（阴气、旧疾）

#### 方位断法（地支定宅中位置）

卯为东门、巳为灶、亥为厕、戌为猪圈。

#### 动作卡

先看干支谁生谁 → 看三传归支还是归干 → 看支上墓虎 → 方位用支辰定。

#### 红线

支乘墓虎（宅有伏尸）出现，涉及居住健康时要建议专业检测，不以占断替代。

### 12_15 天时占（最好的训练场）

**类神**：青龙（水神 / 雨）、白虎（风神）、贵神、水神（亥子壬癸）、风伯（未）、雨师（丑）。

#### 判据

| 判据 | 断法 |
| --- | --- |
| 龙入庙（加寅） | 主晴 |
| 龙升天（临辰巳午未） | 主雨 |
| 虎出山林（加寅卯） | 有烈风 |
| 贵登天阙（亥）、绛宫（子） | 多雨 |

### 12_16 其余门类的通用处理原则

传统分类占除上述七类外，还有胎产子息、六畜、终身、流年、杂占等门类。现代问得较少，但处理方法相通，可按下表"翻译"后套用本板块的通用判据：

| 门类 | 正类 | 判据要点 | 现代对应 |
| --- | --- | --- | --- |
| **胎产子息** | 胎神、子孙；天后、六合、生气 | 胎神旺衰定安否；有无刑克定险夷；产期看子孙出空或填实 | 生育计划、备孕时机 |
| **行人音信** | 与出行同：驿马、丁神 | 马动则来；伏吟主不来；类神临干支上则速 | 等消息、等人到 |
| **六畜** | 按物之专神取（如牛看丑、羊看未） | 看专神旺衰与是否受克；受克则损 | 宠物健康、走失（可并入失盗占） |
| **终身** | 日干为本命，看干上神与三传归宿 | 干上得吉将、末传生干，则一生有托；末传克干或入墓则晚景需早备 | 长期规划、人生阶段判断 |
| **流年** | 以行年为主，兼看太岁 | 行年上神生干则岁吉；行年被克则岁内有阻 | 年度运势、年度计划 |
| **一课二事** | 换类神不换盘，每事各走一遍流程 | 两问若类神相同则不可分辨，须另起一课 | 一次来问两件事 |
| **杂占** | 先翻译到最接近的门类，再取该类类神 | 翻译不了就直接说"象不显，难断" | 一切非常规问题 |

> **处理总原则**：**门类不过是类神的索引**。任何新问题，先翻译到最接近的传统门类，取该门类的正类，然后照走板块9的七步法——流程是通用的，变的只有类神。

### 12_17 案例小故事：三交加空亡，病由情志起

**背景**：古课中有一则占病课。课式是三交卦，初传卯（螣蛇、财、落空），中传午（勾陈、鬼），末传酉（白虎、兄）。

**断语**：其患有三——一主思前妻，二主恋一少妇不在眼前，多方烦躁，遂致下部流利不实；三主长子非横因成病。若能如愿，尚可活七八年，否则情死定死矣。

**转折点**：这则课例对占病最要紧的是它的第一层推演——**三交加空亡加六合，等于"不正之合"，病由情志而起，不是外感**。病因类别定错，后面找病位、找制鬼之位就全部落空。

**结果**：更值得注意的是那句"若能如愿，尚可活七八年"——病情的走向随一个具体行动而改变。断语给出的是**可执行的选项**，不是一个不可更改的判决。

> 这则课例的完整四步推演（定病因类别 → 初传空 → 行年在末传 → 行动指引）与事后反馈，见板块14 例二，此处只谈它对占病场景的启示。

**可复制动作**：

1. 这则课例最值得学的不是"准"，而是两件事：**一是把象法定到病因类别上（情志还是外感），二是结论给出行动指引而非判决。**
2. 占病如此，占其他事也应如此——**断凶必须指出路**。
3. 涉及医疗，必须明确建议就医，不以占断替代。

### 12_18 案例小故事：三个月的天气记录

**背景**：有人按建议，把天时占当作入门训练场，每天占一次次日天气，坚持三个月。

**经过**：前两周几乎全错——他只会看"三传见亥子壬癸则有雨"，但不知道还要看水神的旺衰与空亡。有一次课里明明有亥子，第二天却是大晴天。

**转折点**：他把每一次的课式和实际天气都记下来，逐条比对。第三周开始发现规律：**有水神但水神休囚或落空，雨就小或没有；水神旺相且克日，雨才大。**

**结果**：到第二个月，他的天时判断准确率明显上升；更重要的是，这套"看旺衰与空亡"的手感，被他迁移到了其他场景的断课上。

**可复制动作**：

1. **天时占是最好的训练场**，因为它每天都有真实答案，反馈周期最短。
2. 记录格式要固定：课式（水神在哪、旺衰、空否）+ 预测 + 实际。
3. 训练目标不是"成为天气预报员"，而是**用最短的反馈周期练会"旺衰 × 空亡"这一层判断**。
