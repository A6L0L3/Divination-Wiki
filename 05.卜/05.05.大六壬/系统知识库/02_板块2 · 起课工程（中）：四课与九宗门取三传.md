## 板块2 · 起课工程（中）：四课与九宗门取三传

> 接板块1。时空坐标立好之后，本篇完成"立四课"与"取三传"——这是起课链条的中段，也是九宗门决策树的主战场。

### 2_1 四课：四面镜子折射一件事

四课 = **干（我方）两课 + 支（对方 / 事体）两课**，每课分"阳（显）"与"阴（隐）"。

| 课位 | 取法 | 象征 |
| --- | --- | --- |
| 第一课（干阳） | 日干寄宫在地盘，看其上的**天盘神** | 我之表现、外显状态 |
| 第二课（干阴） | 以第一课的上神为"下神"，看其地盘上的天盘 | 我之隐情、内在动机 |
| 第三课（支阳） | 日支在地盘，看其上的天盘神 | 对方 / 事体之外显 |
| 第四课（支阴） | 以第三课的上神为"下神"，看其地盘上的天盘 | 事之根基、内里根源 |

#### 书写与术语

每课写"上神 / 下神"（上神是天盘，下神是地盘）。

| 术语 | 含义 |
| --- | --- |
| **下贼上** | 地盘克天盘（下克上） |
| **上克下** | 天盘克地盘（上克下） |

> **最容易出错的一步**：第二课、第四课不会取。记住一句话——**把上一课的上神（上字）拿下来，再看那个字在地盘上所乘的天盘**。这一步错，四课只剩一半，后面全废。

#### 四课速判体检表

排完四课，先别急着取传，做以下"体检"能直接读出很多信息：

| 观察点 | 断语方向 |
| --- | --- |
| 干上神（我方外境） | 生我等于助力，克我等于压力，比和等于同类 |
| 支上神（事态） | 生我等于有利，克我等于受害，相合等于可成 |
| 干上克支上 | 我求彼事，易受制于人 |
| 支上克干上 | 彼来求我，我占主动 |
| 干上见空或脱气 | 事虚浮、易落空，防诈伪 |
| 支上见墓或困 | 事停滞、难推进，宜守不宜攻 |

### 2_2 九宗门：取三传的九种规则（严格按优先级）

九宗门是四课排好之后取三传的九种规则，**顺序不许跳步**：

```latex
贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟

```

#### 第一法：贼克（含元首、重审）

| 类型 | 条件 | 取法 |
| --- | --- | --- |
| **元首** | 四课中只有一课上克下，且无下贼上 | 取该上克下之神为初传 |
| **重审** | 四课中有下贼上 | 优先取下贼上之神为初传（贼先于克） |

> **总纲句**："取课先从下贼呼，如无下贼上克初；初传本位明中次，中上因加是末居。"

意思是：先找下贼上，没有再找上克下；初传取到后，**初传在地盘上所乘的天盘神即中传，中传在地盘上所乘的天盘神即末传**。

#### 第二法：比用（知一课）

四课中出现两课或三课同时有克（或两个下贼、或两个上克），则看所克之神的阴阳：**与日干阴阳相同者（比）取为初传**。阳日取阳支之克，阴日取阴支之克。

#### 第三法：涉害（见机课）

比用仍不能决（如两课皆与日干同比，或皆不比），则比较"涉害深浅"：从各个克处出发，顺着天盘十二支逐一历数，看谁先遇上"克害"（地盘克它）的次数多，**涉害深者为初传**。若涉害深浅相同，则孟上神优先（寅申巳亥位上的优先取）。

#### 第四法：遥克（蒿矢、弹射）

四课上下全无克贼，则看**四课上神与日干是否遥相克**：

| 类型 | 条件 | 含义 |
| --- | --- | --- |
| **蒿矢** | 四课无克，取"上神克日干"之神为用 | 如以蒿草为箭，力弱难中 |
| **弹射** | 无神克日干，取"日干克上神"之神为用 | 如以弹丸弹射，我主动而力不足 |

#### 第五法：昴星

四课全无克、又无遥克，则取昴星（酉）。

| 类型 | 条件 | 取法 |
| --- | --- | --- |
| **阳日昴星** | 四课无克无遥克，日干为阳 | 取地盘酉上之天盘神为初传，中传取支上神，末传取干上神 |
| **阴日昴星** | 日干为阴 | 取天盘酉所临地盘之下神为初传，中传取干上神，末传取支上神 |

#### 第六法：别责

四课**不备**（只有三课）且无克，为别责课。阳日取干上神所合之神为初传；阴日取支上神之三合首为初传。中传、末传皆归干上神。

#### 第七法：八专

四课**只有两课**（干上神即支上神，两课相同），为八专课。取法：阳日从干上神顺数三位为初传；阴日从支上神逆数三位为初传；中传、末传皆归干上神。

#### 第八法：伏吟

天盘与地盘完全相同（月将即占时），四课无克可取。

| 情形 | 取法 |
| --- | --- |
| 有克 | 仍按贼克法取 |
| 无克 | 阳日取干上神为初传，中传取初传所刑，末传取中传所冲；遇自刑结构则中末归于初传 |

#### 第九法：返吟

天盘与地盘**对冲相冲**（月将与占时相冲）。

| 情形 | 取法 |
| --- | --- |
| 有克 | 仍按贼克法取 |
| 无克 | 取"驿马"为初传，中传取支上神，末传取干上神 |

> **九宗门口诀卡片**：贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟。能不看书写完这九个词，才算过了立盘关。

### 2_3 三传：取到之后要标什么

| 传位 | 别名 | 角色 |
| --- | --- | --- |
| 初传 | 发用、发端门 | 起因、导火索、当下吉凶源头 |
| 中传 | 移易门 | 发展、转折 |
| 末传 | 归计门 | 结果、归宿、最终落点 |

取到三传后，立刻标四件事：

```latex
第1步 走势：□ 顺生   □ 逆克   □ 进茹   □ 退茹   □ 首尾相见
第2步 空亡：初 □     中 □     末 □
第3步 归属：□ 朝日（支传干）  □ 朝枝（干传支）  □ 回还（三传不出四课）
第4步 末传对日干：□ 生干   □ 克干   □ 脱干   □ 比和

```

### 2_4 完整起课演练：从头到尾走一遍

下面用一课作完整示范，只为演示排盘链条，不作断课依据。

```latex
【设定】甲子日，辰时占，月将为巳（太乙）

第1步 布天盘：地盘辰位上写巳，顺时针排满
        地盘：子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥
        天盘：丑 寅 卯 辰 巳 午 未 申 酉 戌 亥 子
        校验：十二支连续、不重不漏；每一宫相对地盘均顺移一位
              （偏移量 = 月将巳 − 占时辰 = 一位，全盘一致即正确）

第2步 立四课（甲寄寅；日支为子）
   第一课（干阳）：寅上天盘为卯  →  卯 / 寅
   第二课（干阴）：卯上天盘为辰  →  辰 / 卯
   第三课（支阳）：子上天盘为丑  →  丑 / 子
   第四课（支阴）：丑上天盘为寅  →  寅 / 丑

第3步 查贼克
   第一课 卯 / 寅：木与木，比和，无克
   第二课 辰 / 卯：地盘卯木克天盘辰土 → 下贼上（取天盘辰）
   第三课 丑 / 子：天盘丑土克地盘子水 → 上克下
   第四课 寅 / 丑：天盘寅木克地盘丑土 → 上克下
   → 有下贼上，贼先于克，取辰为初传

第4步 取三传
   初传 = 辰
   中传 = 地盘辰上所乘天盘 = 巳
   末传 = 地盘巳上所乘天盘 = 午
   三传：辰 → 巳 → 午（顺行相连，为进连茹）

第5步 起贵人、布天将（详见板块3）
   甲日：阳贵丑、阴贵未。辰时属卯辰巳午未申六时，用阳贵丑。
   天盘丑落在地盘子位，贵人临子；子属亥子丑寅卯辰六位，顺行。
   顺排：子起贵人、丑螣蛇、寅朱雀、卯六合、辰勾陈、巳青龙、
        午天空、未白虎、申太常、酉玄武、戌太阴、亥天后。

第6步 配六亲（以甲木日干为基准）
   初传辰属土，我克者为妻财 → 妻财
   中传巳属火，我生者为子孙 → 子孙
   末传午属火，我生者为子孙 → 子孙

第7步 查旬空、标本命行年
   甲子日属甲子旬，旬空在戌亥；本例三传辰巳午皆不空。
   求占者本命、行年标于课式右侧。

```

> 演练的价值在于**暴露断点**。你能在哪一步卡住，就说明那一步的规则还没真正掌握——这正是手排胜过软件的理由。

### 2_5 案例小故事：卡在第二课的三个月

**背景**：有人自学排盘三个月，四课永远只排得出两课。他以为是古籍讲错了，反复换书、换教程、换软件，依然排不全。

**经过**：他排出来的课，第一课和第三课总是对的，第二课和第四课永远空着。他怀疑是"不备课"——因为古籍里确实提到四课不全的情形——于是接受了现状，把两课当四课用，断出来的东西自然全不对。

**转折点**：后来他对着排盘图逐字核对，才发现问题的根源：他一直把"第一课的下神"当成下神去取第二课，而不是把**第一课的上神**拿下来当新的下神。

规则只有一句话——**把上一课的上字拿下来，再去看那个字的天盘**——但因为他在第一课写的是"卯 / 寅"，误以为下神"寅"才是要延续的那个字，于是第二课又回到寅上取，取出来和第一课一模一样。

**结果**：改正之后，四课一次排全，三传跟着就通了。三个月的时间，其实只差这一句话。

**可复制动作**：

1. **术语的方向感**（上神是天盘、下神是地盘）必须建立在肌肉记忆上。建议每排一课，口里念一遍"上神是天盘、下神是地盘"。
2. **卡住时不要换书，要回到最小步骤逐字核对**。排盘是链条，断点永远只在某一个具体动作上。换书只会让你在别的地方继续错。

### 2_6 案例小故事：同一张课，邵公当场纠正了取传
《大六壬断案》里有一则占宅，邵彦和在第一句就替后人纠了一个错。

**背景**：邵秀才癸丑年生五十七岁，占宅及父母。己酉年二月乙巳日戌将亥时。这一课四课俱无克。

**经过**：四课无克，本该退到九宗门里更靠后的门法。邵公逐一排查：第一课卯加辰，卯木、辰内所藏乙亦木，不克；第二课寅加卯、第三课辰加巳，俱不克；第四课卯加辰——**乙巳已为日干先据，不能重复取用**。

**转折点**：于是他点名批评了另一种做法："术人多以第四课发用为元首，**传用已差，占何得应？** 皆由用术不精，反云六壬不灵，岂不诬哉？"

也就是说：同一个盘，取传取错了一位，后面再怎么算都不会应；而这个错误最后被记到了"六壬不灵"的账上。

**结果**：改以"日遥克"为用，课名**弹射**，重新断：初传辰自宅上传出、中传仍归卯位，是"夺父之财禄"；三传不离支干，乙以卯为禄、寅为同类，必有兄弟出去后复归；占者与父母各居十六七年，至五十九、六十行年到亥子、上见父母，则有服。后来"分毫不爽"。

**可复制动作**：

1. 九宗门是**决策树，不是选项菜单**：贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟，严格按优先级，不许跳步。
2. 四课不备时（如本课"乙巳已为干先据"），**不可重复取用**，要退到下一级门法。
3. 断不准时先怀疑**取传**，再怀疑断法——邵公这句话说得最重：传用一差，"占何得应"。
