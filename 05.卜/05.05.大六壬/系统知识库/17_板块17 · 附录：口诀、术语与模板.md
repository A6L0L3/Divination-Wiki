### 17_1 必背口诀汇编

#### 十干寄宫

> 甲课寅兮乙课辰，丙戊课巳不须论；丁己课未庚申上，辛戌壬亥是其真；癸课原来丑宫坐，分明不用四正神。

#### 月将（中气换将）

> 雨水登明春分魁，谷雨从魁小满传；夏至小吉大暑胜，处暑太乙秋分罡；霜降太冲小雪功，冬至大吉大寒神。

#### 贵人起例

> 甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸蛇兔藏，六辛逢马虎，此是贵人方。

（上字为昼或阳贵，下字为夜或阴贵）

#### 九宗门优先级

> 贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、返吟

#### 贼克取用

> 取课先从下贼呼，如无下贼上克初；初传本位明中次，中上因加是末居。

#### 十二天将顺序

> 贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后

#### 六亲

> 生我者父母，我生者子孙，克我者官鬼，我克者妻财，比和者兄弟。

#### 五类空亡

> 金空则鸣，火空则发，土空则通，木空则朽，水空则枯。

#### 应期六字诀

> 静待冲，动待合；冲待合，合待冲；空待出旬与填实，墓待破。

#### 应期远近尺

> 用起太岁，一岁之中；用起月建，一月之中；用起旬首，十日之中；用起日干支，即日；用起正时，目下。

#### 入门总诀

> 月将加时立地盘，四课分明主客辨；取传先寻克处动，六亲定下用神现；三传始终看走向，旺衰生克断凶吉；**莫把神煞当根本，五行理气是真传。**

#### 断课三问（任何时候都能现场推）

> 一问四课：谁生谁、谁克谁？（内外关系）

二问三传：从初到末，是向好还是向坏？（时间演化）
三问凶神：有没有东西能制它？能不能空掉？（转化与消解）

### 17_2 术语速查

| 术语 | 含义 |
| --- | --- |
| **天地盘** | 地盘固定（方位、内、我）；天盘月将加时顺布（来势、外、客） |
| **四课** | 干阳、干阴、支阳、支阴；阳神主象（显），阴神主情（隐） |
| **三传** | 初传（发端、起因）、中传（移易、过程）、末传（归计、结局） |
| **下贼上 / 上克下** | 地盘克天盘 / 天盘克地盘 |
| **发用** | 初传，矛盾炸开之处，"克处是动机" |
| **不备课** | 四课上下神重复，成三课或两课；信息有缺，待时补足 |
| **朝日格 / 朝枝格** | 支传干（人来求我）/ 干传支（我去求人） |
| **回还格** | 三传不离四课，宜守旧 |
| **内战 / 外战** | 神克将（祸由内起，忧重难解）/ 将克神（灾自外来，忧轻易解） |
| **阴神** | 某神所临地盘位上的上神；主内情、动机、根子 |
| **类神** | 所占之事的核心符号；专类重于泛类，类不入传则事难成 |
| **救神** | 末传、干支上神或年命中能制化凶神者 |
| **遁鬼（暗鬼）** | 遁干所藏之鬼，明处无碍、暗藏隐患 |
| **进连茹 / 退连茹** | 三传顺行相连（势如破竹）/ 逆行相连（节节败退） |
| **夹定 / 回环** | 日辰夹定三传（进退不由人）/ 三传不出四课（宜守） |
| **虚一待用** | 三合局缺一字，所缺之字出现之年、月、日、时即应期 |
| **别处发用** | 昴星、别责、八专等非由四课克贼发用；主此事不由我主导，宜借力 |
| **闭口课** | 旬尾加旬首或旬首加旬尾；主秘而不宣、消息不通（与毕法"首尾相见"同构异断） |
| **真太阳时** | 按当地经度与均时差校正后的地方时，为取正时的物理依据 |
| **不备 / 芜淫** | 四课不全；信息有缺、事体残缺 |
| **旺相休囚死** | 五行在月令的五种能量状态 |
| **十二长生四吉八凶** | 长生、冠带、临官、帝旺为吉；余八位为凶 |

### 17_5 最后三句话（贴在起课纸顶端）

> **1. 紧要在"克"字中求。** 拿到一课，第一步不是看哪里"生"，而是看哪里"克"。克处就是发机之处。
>
> **2. 先取象，后论克；先找类，再谈吉。** 类神没定就论旺衰，等于在算空气。
>
> **3. 吉旺则吉，凶休则凶，两言决耳。** 信息打架时，回到"性质乘以能量"这一个十字路口。

### 17_8 案例小故事：起课纸上一栏空白，整节课就废了

**背景**：有人手排半年，自认为流程已经定型。有一次替朋友占一份合作，排完觉得"课象平平"，只写了一句"可成，谨慎"。半年后合作告吹，他翻出旧稿复盘，才发现那张课纸上有一栏是空的——**月将没有核对中气区间**。

**经过**：那天正是节气前后两三天。他按日历上"已交节"的印象取了新将，实际交节在当日晚间，占时仍在旧将区间内。

**后果**：月将一错，天盘整体偏移一位；天盘错，四课的上神全错；四课错，取传的门路跟着错。**后面所有精细的分析，都建在一个错的地基上。**

**转折点**：他把这件事写进档案的"复盘"栏时，发现自己根本没法判断"如果月将没错会怎样"——因为错位的盘已经无从还原。这让他意识到：**起课纸的每一栏不是形式，它是你事后唯一能追责的证据**。

**结果**：他此后把 17_3 的起课纸打印成册，每课一页，交付前把"输入"与"校验"两栏逐项打勾。一年后统计，因排盘失误导致的断错从十之三四降到几乎为零。

**可复制动作**：

1. 起课纸的"校验"栏必须当场打钩，**不要凭记忆补勾**。
2. 节气前后三天内占问，一律回查交节的准确时刻。
3. 每份档案保留原稿（手写或截图），事后复盘只认原稿，不认回忆。

### 17_9 案例小故事：一张口诀卡的用法

**背景**：有人把本页的口诀全部抄在了一张 A4 纸上，贴在书桌前。朋友笑他"都什么年代了还抄卡片"。

**经过**：接下来一个月，他每次排课都不再翻书——十干寄宫、月将中气表、贵人起例、九宗门优先级，全在眼前。手排一课的时间从二十分钟降到八分钟，而且因为不用在书页间来回翻找，注意力不再被打断，出错率也降了。

**转折点**：第二个月，他把卡片上的口诀按使用频率重排了一遍——最常用的三样（寄宫、月将、九宗门）放在最上面，贵人口诀次之，应期六字诀放在右下角。这一改又省了一些时间。

**结果**：三个月后，这些口诀他已经完全记住，卡片不再需要看，但一直贴在原地——因为每次断课卡住时，扫一眼就能想起"是不是漏了哪一步"。

**可复制动作**：

1. **口诀卡的价值不在"背"，而在"不用翻书"**。它保护的是你的注意力，不只是记忆。
2. 卡片要按使用频率排布，不是按书本顺序。
3. 卡片上还应该有一句"断课三问"和"最后三句话"——它们在你卡住的时候最有用。
