# 大六壬系统知识库 · 分卷索引

## README · 大六壬操作系统：从立盘到决断

> 这不是又一本口诀汇编。六壬真正难的地方，从来不是"记住多少条断语"，而是**面对一盘纷纭的课传，先读什么、后读什么、两个信号打架时听谁的**。
>
> 本知识库把壬学的方法重构成一条可以照做、可以校验、可以复盘的流水线：
>
> **起课（建模型）→ 读盘（学语言）→ 断课（走流程）→ 应期（定时点）→ 复盘（建档案）**
>
> 全篇共 18 个板块（板块0 至板块17），分六编。

### README_1 使用声明

大六壬属于中国传统象数文化与术数范畴，可作为思维训练、文献研究与决策推演的参考材料。**它不能预测随机事件的唯一结果，更不能替代医疗、法律、金融、安全等专业意见。** 书中所有课例仅用于演示推演逻辑，不构成现实决策依据。

### README_2 三条硬纪律

| 纪律 | 内容 | 违反的后果 |
| --- | --- | --- |
| **不诚不占、不渎不占、不邪不占** | 心不诚、同一事反复占、问违法损人之事，都不占 | 反复占的实质不是"天谴"，而是"动"的信息被污染，模型输入失效 |
| **非占现类勿言之** | 对方没问的类不要擅自发挥，占病不说财，占婚不说官 | 说得越多、错得越多，从"咨询"退化成"江湖" |
| **每断必记，每记必验** | 断完立刻登记，事后回填事实 | 没有反馈闭环，练十年也只是原地打转 |

### README_3 六编推进逻辑

```latex
【第一编 · 总纲】板块0
     先知道这台机器靠什么运转，
     再决定按什么顺序下功夫。
              ↓
【第二编 · 立盘】板块1 — 板块3
     再求"演得对"。盘错 → 课错 → 传错 → 断错，
     任何一处错位都会沿链条放大。
              ↓
【第三编 · 读盘】板块4 — 板块6
     然后求"看得懂"。天地盘是语法，四课是词汇，
     三传是句子，天将是角色性格，课体是骨架信号。
              ↓
【第四编 · 断课】板块7 — 板块11
     再求"断得准"。旺衰、类神、七步法、
     四象限裁决、断法百则与应期，逐层精修。
              ↓
【第五编 · 分类】板块12
     把通用流程落进具体场景，
     求财、官禄、疾病、婚姻各有各的类神与红线。
              ↓
【第六编 · 源流与训练】板块13 — 板块17
     最后求"断得出所以然"与"能复盘"。书目地图、
     课例逆向工程、占验档案、错误清单、附录速查。

```

**一句话总纲**：先求"适道"之正（规矩），再求"与立"之范（成例），最后才是"与权"之变（变通）。跳过规矩直接求神妙，是绝大多数人走弯路的起点。

### README_5 三首开工必背的口诀

在翻开任何板块之前，先把这三首抄在卡片上。它们不是知识，是每天都要用的工具。

**十干寄宫**

> 甲课寅兮乙课辰，丙戊课巳不须论；丁己课未庚申上，辛戌壬亥是其真；癸课原来丑宫坐，分明不用四正神。

**月将（中气换将）**

> 雨水登明春分魁，谷雨从魁小满传；夏至小吉大暑胜，处暑太乙秋分罡；霜降太冲小雪功，冬至大吉大寒神。

**九宗门优先级**

> 贼克 → 比用 → 涉害 → 遥克 → 昴星 → 别责 → 八专 → 伏吟 → 返吟

完整口诀汇编、术语速查与起课模板纸，见板块17。

### README_6 可以立刻开始的三件事

1. **手绘地盘，每天一次**。子正北、午正南、卯正东、酉正西，画到不假思索。地盘不熟就讲天盘，必致上下不分。
2. **建一个占验档案**。从今天起，每一课都登记：问什么事（含动词）、你断什么、事后事实是什么。三个月后，这份档案比任何一本秘籍都值钱。登记表见板块15。
3. **找一个最简单的训练场**。天时占是最好的起点——每天都有真实答案回填，反馈周期最短。见板块12。

### README_7 本知识库的三个写作原则

| 原则 | 说明 |
| --- | --- |
| **解析先于复述** | 每一节先讲"原文到底在说什么"，再给"你拿到手怎么操作"，不做古籍白话翻译 |
| **纪律先于神妙** | 宁可断得平，不可断得奇。古人云"求奇反不奇" |
| **边界先于结论** | 每一条断法都标明它的适用条件与失效边界，不给你一把万能钥匙 |
