1. **谁生谁**：俯就、归福
2. **谁克谁**：乱首、赘婿
3. **交生交克**：脱骨、无涉、同谐
4. **特殊格局**：芜淫、闭口、游子、三交、斩关、天心、回环

### 5_2 "闭口"与"首尾相见"：同构异断的典型

这两条取的是**同一个结构**（旬首旬尾相加），却给出方向相反的断语：

| 口诀 | 出处 | 问"成"时 | 问"散 / 说 / 追"时 |
| --- | --- | --- | --- |
| **首尾相见始终宜** | 《毕法赋》 | 事不脱、谋皆成（吉） | 事不脱、难解散（对求脱身者反为不吉） |
| **闭口** | 课经 | — | 消息不通、说不出口、追不着人（凶） |

> 两者并不矛盾——**同一结构，问"能不能成"则吉，问"能不能说、能不能散、能不能追"则凶**。

**实操铁律**：判断前务必先看清对方问的那个动词。这一条在板块0已出现过一次，这里给出它的机制来源。

### 5_4 特殊课体：一见即知大势的"骨架级信号"

伏吟与返吟是**骨架级信号，优先级高于一般生克**：

| 课体 | 第一断语 | 现代转译 |
| --- | --- | --- |
| **伏吟** | 静、守、慢、反复 | 事情原地打转，宜守不宜攻；占病主迁延，占行人主不来 |
| **返吟** | 动、变、反复、冲 | 事情反复、来去不定；占事多成而复败，或败而复成 |
| **八专** | 干支同气，内外不分 | 主独、主私、主无分彼此；占婚多主不正之合 |
| **别责** | 四课不备，信息有缺 | 事体残缺，须待时补足；谋事由人不由己 |
| **昴星** | 无克而取酉 | 主暗中、主迟；占事多"不能自主" |
| **遥克（蒿矢 / 弹射）** | 力弱 | 蒿矢（上神克干）：外来小扰；弹射（干克上神）：我用力而难及 |

> **使用纪律**：一见伏吟，先断"静、守、慢"；一见返吟，先断"动、变、反复"。这两句是骨架级的，先落这一句，再谈生克细节。

### 5_5 格局使用的三条纪律

1. **格局是验证工具，不是起点**。只有当格局的核心条件在课中真实出现（如铸印课的巳、戌、卯三传全备），才引用；否则宁可不提。
2. **课名只负责分类，不自动生成人事吉凶**。"见机"不等于任何事都宜速动，"重审"也不等于谋事皆凶。
3. **吉格局小凶无碍，凶格局大吉难发**。格局只定大势，具体吉凶仍要看类神旺衰与年命。

**三条纪律的共同指向**：课体是"骨架级信号"，它先给你一句方向性的话（静、动、缺、独），然后就交棒给后面的生克、类神、旺衰。**把骨架当成全身，是读盘最常见的越权。**

**使用顺序建议**：

```latex
第1步 先判课体（伏吟 / 返吟 / 八专 / 别责 / 昴星 / 遥克）→ 落一句骨架断语
第2步 再判干支交加十六格 → 补一句关系判断
第3步 最后才进入生克、类神、旺衰的细算

```

前两步只给方向，不给结论；结论必须由第3.步的细算产出。

### 5_6 案例小故事：把"见机"当"速动"的人

**背景**：有人读到"见机"这个课名，望文生义，理解为"见到机会、宜速动"。

**经过**：此后凡遇此课，他一律建议对方尽快出手。连续几次碰壁——有两次对方刚行动就遇到阻力，有两次根本没等到机会。

**转折点**：他回头查课名的成立条件，才发现**"见机"是涉害课的一种课名**，本义是"由涉害深浅择取发用"，描述的是**取传方式**，不是行动建议。

**结果**：他给自己定了条规矩——**凡引用课名，必须先写出该课名的成立条件**。条件不备，宁可不提课名。此后断语的"望文生义"错误大幅减少。

**可复制动作**：

1. 课体层只负责分类，不自动生成人事吉凶。真正的吉凶要看类神旺衰、三传走势、年命参与——这三层走完才能说话。
2. 建议建一张"课名—成立条件"对照卡，每引用一个课名，先在卡片上核一遍条件。
3. 遇到不确定的课名，宁可只描述结构（如"三传顺行相连"），也不硬套课名。

### 5_7 课经与歌诀：样本库与索引，不是答案库
《六壬大全》卷五至卷八的课经部分（七百二十课与六十四卦对应）是**样本库**，它记录的是"某一类结构通常表现为什么"，而不是"见到这个课名就输出这句话"。

**正确顺序：先断，后对。** 先按完整流程走完，把课体、走势、用神、救神写清楚，最后才去课经里"对样本"。引用课经断语前，先写出该课名的成立条件（做法见 5_6）。

> **一句话纪律**：课经是验证工具，不是起点。

《大六壬心镜》把壬学编成"**先课式、后门类**"的歌诀系统，这个结构本身就说明了一件事——**门类歌诀是索引，不是结论**。

歌诀之所以容易被误用，是因为它通常分前后两段：前半段讲"这一门的课该怎么取类、看哪几位"（条件），后半段才给象义（断语）。只抄后半段，等于把工具书降格成签文。

#### 案例小故事：把歌诀当断语抄的人

**背景**：有人读《心镜》，被那些朗朗上口的歌诀吸引，于是按事项分栏抄成一本"断语手册"——问宅抄宅门、问讼抄讼门、问病抄病门。

**经过**：用了一阵，他发现同样的歌句在不同课里时灵时不灵。有一次占宅，歌句明明说吉，实际却连连出问题。他起初以为是"心不诚"，于是更认真地照抄、照念。

**转折点**：后来他注意到，各门类的歌诀前半段往往还有一段"课式条件"——先讲这一门的课该怎么取类、看哪几位，然后才给象义。他此前只抄了后半段的断语，把前半段的条件整个跳过了。

**结果**：补上条件之后，那些歌句开始有了区别：有的课符合前提，有的课根本不符——不符合前提时，歌句自然不应。

**可复制动作**：

1. 抄歌诀必须连"条件"一起抄，只抄断语等于把工具书降格成签文。
2. 遇到不确定的课名，宁可只描述结构（如"三传顺行相连"），也不硬套课名。

### 5_8 案例小故事：一句「赘婿」，为什么会应成家破屋拆
《大六壬断案》有一则占宅，把"先判关系、后贴格局名"的顺序演示得很清楚。

**背景**：叶助教戊午生五十一岁占宅，戊申年正月辛卯日子将未时。

**经过**：邵公断："此课**支来就干，为干所制，名曰赘婿**。太岁入宅克宅，宅来就人，又被人克，六年中家破屋拆，遂成墓地，必葬尊长在内。"

**转折点**：注意他的顺序——**先判干支关系，再找坐实的条件**。支（辰）来就日干、又被日干所克，这是"赘婿"的本义，格局因此成立；但他没有停在这里，而是继续找加重项：末传丑是辛日之墓神，临在太岁上，太岁被墓，于是来宅上克宅；宅被克，走回日上，又被日干所克。两处夹击，"六年"才敢出口。

**结果**：后癸丑年其叔死，遂殡于宅内；叔有子为僧，还俗归分家产，助教不肯，经官断定作诸子分家，与叔共五子，助教亦得一分，作六分分。戊申至癸丑恰六年；当年又死一男一女——正是太岁克宅之故。

**可复制动作**：

1. **先判关系，后贴格局名**。格局名只是标签，真正推动结论的是"支临日而受克"这个结构事实。
2. 格局必须**坐实**：本课坐实的证据有两处——支来就干受克（格局条件），太岁墓神临宅（加重力）。缺一处就退一档。
3. 年限类断语（"六年"）要回到数术与旺衰复核，不能只凭格局名就报数字。

| **骨架优先** | 先判伏吟 / 返吟 / 八专 / 别责，落下第一句断语 | 拿到任何课都能先说出一句话 |
