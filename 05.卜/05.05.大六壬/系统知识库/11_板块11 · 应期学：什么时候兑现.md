## 板块11 · 应期学：什么时候兑现

> 应期是六壬最容易"翻车"也最容易"炫技"的地方。**邵彦和的做法比后人克制得多**：三个独立锁定若指向同一处，结论极其确定；若互相矛盾，**宁可不给精确应期，只说趋势**。这一点值得学。

---

### 11_1 应期三维：旺衰 × 空亡 × 神煞

| 维度 | 定什么 | 操作 |
| --- | --- | --- |
| **旺衰** | 季节、月份 | 神将旺相则事速而重，休囚则迟而轻；**月令休囚而落宫旺相 → 待时令旺时方发** |
| **空亡** | 待填 | 出空、填空、冲空之时即应期（空亡非空，冲合则通） |
| **神煞** | 节点 | 驿马、天马定"动之期"；丧车、死神定"凶之期"；天罡、河魁定方位与时限 |

三者若指向同一处（如都在申酉月），结论就极其确定；**若互相矛盾，宁可不给精确应期，只说趋势**。

---

### 11_2 用神所值定应期区间（一把现成的尺子）

> 用得太岁 → 事在年中；用得月建 → 事在本月；用得旬首 → 事在本旬；用得节气中立之首 → 事在半月；用得本日之干 → 事在本日；用得气首 → 事在五日。

#### 另外三条常用尺子

1. **十二长生定位**：某神行到某地（某长生位），应期即出。断语中出现"长生之地""死地""墓库"，立刻对照长生表定位（表见板块7）。
2. **旺衰对应时态**：旺气发用为现在事，相气发用为未来事，休囚发用为过去事。
3. **日前日后**：以日干寄宫为基准——发用在"日前"（如甲寄寅，则丑、子位）→ **事已过去**；发用在"日后"（卯、辰位）→ **事起将来**；发用在日辰上 → **应今时**。

### 11_3 应期六字诀（背下来就能用）

```latex
静待冲，动待合；冲待合，合待冲；空待出旬与填实，墓待破。

```

| 状态 | 等待什么 | 例 |
| --- | --- | --- |
| 课静不动（伏吟、无马） | 待**冲** | 事迟迟不动，逢冲之日月而动 |
| 课动（有马、有丁、返吟） | 待**合** | 事已在动，逢合之日月而止、而成 |
| 类神被冲 | 待**合** | 冲散者，合则聚，事成 |
| 类神被合（绊住） | 待**冲** | 合住者，冲则开，事解 |
| 类神空亡 | 待**出旬 / 填实 / 冲空** | 空亡为未，则未日未月填实，或丑日丑月冲空 |
| 类神入墓 | 待**冲破** | 墓不开则事不出，冲墓之期即应期 |

### 11_4 四大取法

#### 取法一：类神所临地支法（最直接）

看类神（或其阴神）天盘所加临的**地盘地支**，该支即为应期的"字面"。

> 口诀：财临午上，午月午日见财；官临寅上，寅月寅日得职。

例：问面试结果，官鬼爻临申，则申月或申日有消息；问欠款，财爻临亥，则亥月或亥日到账。

**远近取舍**：近事以**日**断（三日内见申日），远事以**月**断（三个月内见申月），再远以**年**断。具体远近看三传的缓急。

#### 取法二：以本日地支顺数（定"第几天"）

岁月节候均不发用时，以本日地支为起点顺数初传所临：

> 如丑日占，寅为初传 → 应在第二日；卯为初传 → 第三日；辰 → 第四日。**出四位则不取**（超过四天就不再用此法）。

#### 取法三：虚一待用（三合缺一，待所缺之字）

课传中见三合局之**两字**，所缺的第三字即为应期之机：

| 三合局 | 课传所见 | 待什么 |
| --- | --- | --- |
| 寅午戌（炎上） | 见午、戌 | 待**寅**年月日时 |
| 亥卯未（曲直） | 见亥、卯 | 待**未** |
| 申子辰（润下） | 见申、子 | 待**辰** |
| 巳酉丑（从革） | 见巳、丑 | 待**酉** |

> **细则**：所缺之字若逢**月破、日冲、空亡、受制**，则需待"填实、合破、出空"之后，方可言成。远则应年，近则应日时。

#### 取法四：合期与散期

+ 以**初传所合**为成期（事成之日）
+ 以**末传所冲**为散期（事了散去之日）
+ 或以发用之**墓、绝**为应期

### 11_5 数目取舍：定"几人、几件、几日"

| 方法 | 用法 |
| --- | --- |
| **大衍数** | 子午甲己九之类，用于取大数 |
| **河图数** | 水一、火二、木三、金四、土五，用于取小数 |
| **先天数** | 多者取先天 |
| **通例** | **少者取河图，多者取先天**，再以旺相休囚增减 |

> 例：占科举中几人，取青龙为类神，青龙临辰；戊癸辰戌合化之数为五，土亦为五数，辰正应"五"，断五人，榜发果应。**这是"抓类神取象定数"的纯粹形态**：不问生克，直取象之对应。

### 11_6 迟速判断（先定快慢，再定具体）

| 法则 | 断法 |
| --- | --- |
| 干发用 | **速** |
| 支发用 | 迟 |
| 贵顺 | 速 |
| 贵逆 | 迟 |
| 日、用在贵前 | 速 |
| 日、用在贵后 | 迟 |
| 撞干 / 撞支（干前一位为关，支前一位为格） | **急速** |
| 传出 | 事散漫而缓 |
| 传入 | 能量集中而急 |

#### 再叠加四条课体级速断

| 法则 | 断法 |
| --- | --- |
| 课体 | **伏吟主慢、反吟主快**；进连茹、退连茹皆主快 |
| 驿马位置 | 三传见马主快；**马在初传最快**，中传居中，末传较慢 |
| 发用门路 | **涉害、遥克、昴星、别责、阴日八专**皆主慢 |
| 发用旺衰与位置 | 天乙顺行 + 发用旺相 + 发用在一二课 → **速**；天乙逆行 + 发用休囚 + 在三四课 → **迟** |

#### 类神位置定迟速（最实用的一条）

> **类神见于干支上 → 应最速；见于初传 → 次之；见于中末传 → 更迟；类神不入课传 → 无缘之象，难言应期。**

> **务必综合参断**：贵人顺逆 + 发用干支位置 + 课体顺逆 + 类神位置，四者互参，不可仅凭一条下结论。

### 11_7 应期实操六步 + 三条纪律

```latex
第1步 定类神 → 它旺不旺？（旺则速，休囚则迟）
第2步 查类神落在哪、临什么地支 → 取"字面"（月 / 日）
第3步 查空亡 → 出空、填空、冲空在何时？
第4步 查合冲与墓 → 静待冲、动待合、空待填、墓待破
第5步 查神煞与三合虚一 → 丁马、驿马落在哪个节点？三合缺哪一字？
第6步 多方合参 → 指向同一处 → 给精确应期；互相矛盾 → 只说趋势

```

#### 三条纪律

| 纪律 | 内容 |
| --- | --- |
| **宁粗勿伪** | 三个维度不一致时，给趋势不给日期。硬凑出来的精确应期，是最大的信誉杀手 |
| **远近分层** | 近事断日，中事断月，远事断年，不混着说 |
| **回填验证** | 每给一次应期，事后必须回填事实，写进占验档案。三个月后你就知道自己的应期偏差通常落在哪个方向 |

### 11_8 案例小故事：一场雪，落在哪个时辰

**背景**：古籍中有一则著名的祈雪课。某太守祈雪，课上三传为巳、戌、卯，正是**铸印课全传**。

**断语**：把时间切到了时辰——**巳时风起转寒，未时有雨，亥时作雪，厚有七寸**。后来全部应验。

**经过**：初读这则课例的人，多半只惊叹"连时辰都断准了"，然后把它当成神迹。但换个角度问——为什么敢断到时辰？——答案才浮现出来。

**转折点**：它不是靠某一招断出时辰的，而是四层证据指向同一处。

**这条课例值得学的不只是"准"，而是它的分层锁定**：

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| **格局层** | 铸印课全传坐实 → 一定有大雨雪 | 定性质与量级 |
| **理气层** | 火伏于下、水升乎上 = 天地不交而欲交 → 成雨雪的条件成立 | 定原理 |
| **传神临位层** | 巳发用 → 巳时风；未为太常主雨食 → 未时雨；亥子水旺之刻 → 亥时雪 | 定时辰 |
| **象法层** | 末传卯作白虎，与申皆是白色 → 雪色之象 | 补细节 |

**四层指向同一处，所以敢断到时辰。** 若只有一层支撑，就只能说"近日有雨雪"。

**反过来看我们自己断应期时的毛病**：常常只凭"类神临申"就断"申月申日"，却没查它是不是空亡、是不是入墓、是不是被合住。**少查一步，应期就偏一步。**

**结果**：这则课例之所以敢断到"时辰"，不是因为断者胆大，而是因为四层证据指向同一处——格局、理气、传神临位、象法补色，缺一层就退一档。这正是应期分层的由来。

**可复制动作**：

1. 应期结论要标明它由几层支撑：一层 → 只说趋势；两层 → 可断到月；三层以上 → 可断到日。
2. 每次给应期前，走完 11_7 的六步，不跳步。
3. 事后必须回填，找出自己的系统性偏差（偏早还是偏晚）。

### 11_9 案例小故事：一句「午月寅日」，链条反过来推

**出处**：王剑霞《六壬粹言》卷十四「慕农占验集」。

**背景**：李介庵占新任荆门刺史郎牧云何日到任（壬午二月甲辰日申时戌将）。

**断语**：起程之后先受阻隔，「**必午月寅日到**」，而且中间还有一段"来而又去"的反复。

**链条怎么走出来的**：

| 层次 | 盘上依据 | 推出什么 |
| --- | --- | --- |
| 该不该动 | 斩关发用，又得龙、合，白虎入传 | 理应起程而来 |
| 为什么先不动 | 发用坐空 | 始有阻隔 |
| 阻隔是什么 | 辰前一位巳乘勾陈 | 因案件稽留 |
| 会不会白跑 | 格合回环、用神离门限甚远 | 来而又去，一时到不了任 |
| 到底哪一天 | 末传白虎、天马加临午位 | 午月；寅日为合期 |

**结果**：「果一一如占」。

**这一例最值得学的地方**：四个维度里，前三个都在回答"**会不会**"，只有最后一个在回答"**哪天**"。很多人拿到课，跳过了前三个直接去找那个字，于是把"卡住的午月"当成了"顺利的午月"。

**可复制动作**：

1. 先判"事到底动不动"，再定时间。事不动的课，日期再准也没用。
2. 时间信号优先取**末传**（归计门）——本例"午月寅日"全在末传上，不在初传。
3. 同一课里"阻隔"与"成期"是两条线：勾陈、空亡管前者，天马、合期管后者，不要混成一条。
