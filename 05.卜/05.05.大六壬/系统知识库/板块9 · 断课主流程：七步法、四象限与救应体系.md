## 板块9 · 断课主流程：七步法、四象限与救应体系

> 前面十一个板块都是零件，这一板块是把零件装成生产线。**顺序不可颠倒，跳过任何一步都可能漏掉关键信息。**

---

### 9_1 主流水线的七步法

```latex
【第 1 步】观课体，定大势
   → 伏吟 / 返吟 / 八专 / 别责 / 昴星 / 遥克？是元首、重审还是涉害？
   → 骨架级信号优先：伏吟先断"静守慢"，返吟先断"动变反复"
   → 吉格局小凶无碍，凶格局大吉难发

【第 2 步】看日干旺衰，定自身底气
   → 日干在月令的旺相休囚死；干上神是生是克
   → 旺相则有支撑，休囚则自身无力（旺禄临身则不必妄作）

【第 3 步】定类神、取用神，问"事情有没有"
   → 按占问事项取正类；类不入课传则事难成
   → 用神旺相不空则事成；衰空受克则事败

【第 4 步】看四课，辨主客表里
   → 干上 → 支上 → 干支互动 → 两阴神
   → 干强支弱则我胜；支旺干衰则彼强

【第 5 步】走三传，看始终走向
   → 顺生 / 逆克？进茹 / 退茹？首尾相见？初中末谁空？
   → 初传看起因，末传定成败；末传生干则安，克干则败

【第 6 步】看天将与神煞，定吉凶性质与节点
   → 天将是主帅：本体 × 落位 × 阴神（见板块6）
   → 内战外战？贵人一处到位还是差迭？有无白虎遁鬼、鬼临三四？
   → 神煞只作校准：驿马丁马定"动"、禄刃德医定"性质"

【第 7 步】查旺衰、墓库、空亡，定力度与虚实
   → 这一步把"定性"量化为"多强、多久"
   → 凶神有没有被制？凶神是不是空亡？吉神是不是空亡？

```

---

### 9_2 第 4 步的核心补充动作：找到制化与空亡

> 看到任何凶格，动作顺序永远是：**先查有没有"制"，再查"空不空"，最后看旺衰**。顺序不能反。

| 顺序 | 动作 | 依据 |
| --- | --- | --- |
| 第一步 | 凶神有没有被制？ | **"制鬼之位乃良医"**，哪里能克制它，哪里就是解决方案 |
| 第二步 | 凶神是不是空亡？ | 空则虚惊无实祸 |
| 第三步 | 吉神是不是空亡？ | 空则虚喜一场 |
| 第四步 | 才看旺衰 | 旺相放大吉凶，休囚削弱吉凶 |

> **为什么顺序不能反**：先看旺衰，你会在最凶的地方浪费时间；先看"制"，你往往三步之内就找到出路。

### 9_3 完整演练：一课走完七步（示范）

```latex
【假设情境】某人问"这份工作机会要不要去"。

第1步 课体：重审课，非伏吟返吟
   → 事有反复之象，宜审而后动，不宜冒进

第2步 日干：日干在月令休囚，干上神生干
   → 自身底气一般，但当下有助力

第3步 类神：官鬼为职位，禄为俸禄。官鬼入三传，旺相不空
   → 事情是"有"的

第4步 四课：干上生支上（我去生他，脱气）；支上神克干上（对方态度强硬）
   → 这是"我求彼"的格局，主动权在对方手里，要准备被压条件

第5步 三传：初传见鬼（起步有压力），末传见子孙（能制鬼）
   → 先难后易

第6步 天将：初传乘白虎，末传乘青龙；白虎虽凶，末传青龙生干
   → 先凶后吉。白虎所临之神为压力所在，制之位即缓解之道

第7步 旺衰空亡：初传鬼旺而不空（压力是真的，不是虚惊）；
   末传子孙旺相（有解）
   → 结论力度：确定级

【输出】
能成，但属"先难后易"。去可以，但要接受前期的压力与受制于人的条件；
压力点在白虎所临之处（对应具体部门或环节），
化解办法是借末传青龙之方（对应能生扶我的人或资源）。
建议：谈条件时不要硬碰，先进入再图后势。
注意：此课不宜反复占，亦不宜同时问其他类，若问薪酬另起一课。

```

> 注意这个输出的三个特点：**有方向（去 / 不去）、有理由（哪一步看出来的）、有动作（怎么谈）**。只说"吉"或"凶"的断语，等于没断。

### 9_4 输出结论的规范（区分"占卜"与"咨询"的关键）

**铁律**：结论必须落地为**具体行动指引**，而非只说吉凶。三分支输出模板：

| 情形 | 输出内容 |
| --- | --- |
| **能成的事** | 何时成、注意什么、怎么借力（贵人在哪、哪个方向、哪个月份） |
| **不成的事** | 问题卡在哪、为何不成、要不要等、如何规避 |
| **有风险的事** | 风险点在哪、如何化解（制鬼之位在哪）、要不要放弃 |

#### 三条输出纪律

1. **拿不准的事不说死**，留有余地，不危言耸听；
2. **非占现类勿言之**——没问的类不擅自发挥；
3. 涉及疾病、官讼等高风险判断，**明确提示寻求专业意见**。

---

### 9_5 可信度分级（建议每断必标）

| 级别 | 判据 | 表述方式 |
| --- | --- | --- |
| **确定** | 三个以上独立信号指向同一结论（象、气、传、年命俱合） | 直接断言，给出时间与动作 |
| **倾向** | 主信号明确，但有次要信号冲突 | "倾向于某种结果，但需注意某处" |
| **存疑** | 信号互相矛盾，或类神不现 | "象不一，暂难定论；建议先观察" |

---

### 9_6 案例小故事：从"说吉凶"到"给动作"的转变

**背景**：有人断课一向只说结论——"能成""不成""有阻"。对方听完常常追问"那我该怎么办"，他答不上来。

**经过**：有一次他给亲戚断一笔投资，只说了句"财旺，能做"，亲戚投了，结果被套。复盘时他发现，课里其实有"传财太旺反财亏"的结构——财旺不等于能拿到手。他当时看见了财旺，就停止了分析。

**转折点**：他改用三分支输出模板，强迫自己每次必须写出"动作"一栏。第一周很不习惯，因为要写动作就必须先想清楚"卡在哪"。

**结果**：三个月后，他的断语从一句话变成了三段话——结论、理由、动作。对方的追问明显减少，因为该说的他已经说完了。

**可复制动作**：

1. **写不出动作，就说明你还没断透**。这是一个很好的自检信号。
2. 三分支模板必须在断课当天写完，不能等结果出来再补。
3. 每断必标可信度（确定 / 倾向 / 存疑），三个月后统计各档命中率，你会知道自己在哪一档容易过头。

### 9_7 《壬归》五步：与七步法是同一件事的两种粒度
《壬归》卷一《提纲例约》给出的是一条更短的流水线，只有五步：

```latex
观四课之加临  →  察用神之生克  →  明三传始终  →  定贵神吉凶  →  判八煞吉凶

```

它和本板块的七步法并不矛盾，只是粒度不同——**七步法回答"每一步看什么"，五步回答"哪几步是主干"**：

| 《壬归》五步 | 对应七步法 | 关键提醒 |
| --- | --- | --- |
| 观四课之加临 | 第 4 步 | 干阳、干阴、支阳、支阴的读法见板块4 |
| 察用神之生克 | 第 1、3 步 | 此处"用神"专指**初传发用之神**，与"类神"不是一回事 |
| 明三传始终 | 第 5 步 | 末传定吉凶：末生干则安，末克干则败 |
| 定贵神吉凶 | 第 6 步 | 看贵人落在何处、有没有力（临辰戌入狱、临空无力、临干最吉） |
| 判八煞吉凶 | 第 2、7 步 | 德、合、鬼、墓、破、害、刑、冲，详见板块7 |

**两个容易混的概念**：壬归的**用神**是"发用之神"，代表事之机、动之始；本知识库说的**类神**是"这件事的正类"。断一课，两个都要看——类神定"这件事有没有"，发用定"机从哪里起"。

**八煞是加权修正层，不是主引擎。** 前三道工序定"是什么"与"成不成"，八煞定"为什么不完全符合预期"。

#### 案例小故事：五步走完，才知道自己跳了哪一步

**背景**：有人读《壬归》，觉得"观四课、察用神、明三传、定贵神、判八煞"这五步太简单——排完盘谁不是这么看？于是他照旧按自己的习惯断：先看最扎眼的那个神，觉得是什么就说什么。

**经过**：有一课他断错了，事后怎么都想不通。课看起来很平常，他的断语也不算离谱，但结果完全对不上。

**转折点**：他强迫自己按五步**逐条写笔记**，不许跳。写到第三步"明三传始终"时，他发现末传克干——这一条他此前根本没看。他之前的习惯是"初传最重，看了初传就够"，于是整整跳过了决定结局的末传。

**结果**：补上末传之后，那课的结论立刻翻了过来。他这才明白五步的意义不在"内容"，而在**强制性**——它逼你把每一层都过一遍，不让任何一个显眼的神把注意力全抢走。

**可复制动作**：

1. **流程的价值是防漏，不是炫技**。越是"一看就懂"的流程，越要用笔记的形式强制自己走完。
2. 每一步都要留下**一行字**，写不出来就说明这一步没做。
3. 五步之间若出现矛盾，回到本篇的四象限落位——那是最后一道裁决。

### 9_9「两言决耳」四象限：信息打架时听谁的

所有神将、六亲、神煞、课体、长生十二气，最终都要汇入两个维度——**性质（吉 / 凶）**与**能量（旺 / 休）**：

|  | **旺相**（得气、临四吉地、有救应） | **休囚**（失气、落八凶地、无援） |
| --- | --- | --- |
| **吉神吉象** | **成，且速、且实** | 能成，但迟、且薄 |
| **凶神凶象** | **祸重，急发，难躲** | 祸轻，可救，或虚惊 |

> **"吉旺则吉，凶休则凶，两言决耳。"**

这条四象限，是全篇最值得抄在起课纸顶端的一句话。**它解决的是"信息打架时听谁的"这个核心难题。**

#### 四步应用法

1. 定**类神**（一件事只取一个正类）
2. 判**性质**（生我 / 我克 / 克我 / 比和）
3. 判**能量**（得气否？四吉还是八凶？有救应否？）
4. 落象限，出一句完整结论（成 / 不成 + 速 / 迟 + 实 / 虚）

### 9_10 救应体系：从"判死刑"到"给出路"

> 于万般凶险中，稍得一救扶即可"苟延残喘，他日逢令旺可重整旗鼓"。**断课务必找"救神"。**

#### 三类救神（力量与速度）

| 救应层次 | 力量 | 速度 |
| --- | --- | --- |
| **末传之救**（末传子孙制初传之鬼、末传生干） | 最强 | 最速 |
| **干支上神之救**（干上有制鬼之神、干上得吉将） | 中 | 较缓 |
| **年命变体之救**（年命上神制化） | 最弱 | 最迟 |

#### 寻找救神的四种通用动作（挨个找）

1. **子孙制鬼**：末传或课传见子孙爻，能克初传之鬼，先凶后吉
2. **鬼化空亡**：鬼传向空，虚惊无实祸
3. **德神解救**：日德、天德、月德临处，逢凶化吉，优先级最高
4. **干上有制**：干上有能克制凶神之物，凶不能为害（"众鬼虽彰全不畏"）

> **高频结构务必记住**：**初鬼 → 末子孙或末空亡 = 先难后解**。这是壬课里"凶事有救"最典型的形态。

### 9_11 进退取舍决策表（人生决策的核心算法）

| 局面 | 判据 | 动作 |
| --- | --- | --- |
| **三传皆无益（空 / 鬼 / 脱），唯干上逢吉** | 避难逃生 | **弃三传、守干上**，弃旧图新 |
| **进连茹，三传皆空** | 往前三步都是空 | **宜退步** |
| **退连茹，三传皆空** | 向后退步都是空 | **宜进用** |
| **初传长生、末传墓** | 有始无终 | 开头好结局坏，宜早做退路 |
| **初传墓、末传长生** | 先难后易 | 熬过开头即好 |
| **末传子孙克初传之鬼** | 苦去甘来 | 先苦后甘，坚持 |
| **干支见鬼、传见子孙** | 乐里悲 | 先乐后悲，见好就收 |
| **斫轮课中卯逢空（朽木难雕）** | 朽木不可雕 | 宜改科易业、别作营生 |

> **关键辨析**：进茹空亡 = 向前空 → 退；踏脚空亡 = 向后空 → 进。方向相反，极易搞混。记忆锚点：**"脚下踩的都空了，只能往前走"**。

### 9_12 案例小故事：信息打架时，听谁的

**背景**：有人断一课，越断越乱：青龙旺相（该有财），财爻却落空亡（该没有）；课体是个吉格（该成），初传却见鬼（该有阻）。四条信号两两打架，他写了两页分析，最后谁也没说服谁。

**经过**：他试图把四条信号"综合"起来，写了两页分析，结果是每条都打折、每条都说不清，最后谁也没说服谁。

**转折点**：用四象限的办法重断——不是综合，而是**先排序**：正类只有一个，其余都是辅助。

1. **先定类神**：问的是求财，正类只有一个——财爻（青龙是辅助象）。
2. **判性质**：财爻对日干是"我克"，属财，性质为吉。
3. **判能量**：财爻空亡、又不得时令，失气、无援，落在"休囚"一侧。
4. **落象限**：吉象 + 休囚 → "能成，但迟、且薄"；又因为落空，实际是"看着有，到手少"。

**结果**：结论一句话——**事是有的，但这一段是虚的，要等出空或填实才有实质**。至于课体吉格与初传见鬼，前者只是结构分类（不自动生成吉凶），后者说明起步有阻力，两者都不构成对核心判断的推翻。

**可复制动作**：

1. **关键在于"一件事只取一个正类"**。他此前之所以乱，是因为同时把青龙、财爻、课体、初传都当成了"主人"。**类多了等于没类。**
2. 落象限的四步必须按顺序走：定类神 → 判性质 → 判能量 → 出结论。跳步就会重新陷入混乱。
3. 把四象限抄在起课纸顶端，每次断课都能看见。

### 9_13 案例小故事：该舍的不是局部，是这条旧路

**背景**：某人占"要不要把已经亏掉的项目继续投下去"。

**课象**：课中见"避难逃生"之象——三传皆无益（或空、或鬼、或脱），唯干上逢吉。

**判断**：弃三传、守干上。**该舍的不是局部，是这条旧路本身。**

**经过**：他停手了，把剩下的资源转到另一件事上。做决定那几天很犹豫——已经投进去的部分让他舍不得，而"再坚持一下"的念头几乎每天都冒出来。

**转折点**：让他最终停手的，是课里那句判断——**三传是路径，干上是自身**。路径全空而自身有吉，说明问题出在路径上，不在他身上。换路不是认输，是换一条能走的路。

**结果**：一年后新事有了起色，而原来的项目在又拖了半年后彻底终止。回看那一课，"弃三传、守干上"这六个字，替他省下了半年时间和继续投入的成本。

**可复制动作**：

1. 这正是"避难逃生须弃旧"的现代用法——**当整条路径都是空的，正确动作不是坚持，是换路**。
2. 判断标准很明确：**三传皆无益，唯干上逢吉**。三传是路径，干上是自身。路径全空而自身有吉，说明问题出在路径上。
3. 这一条与"先难后易"容易混淆：先难后易是**末传转好**（可坚持），避难逃生是**三传皆无益**（要换路）。区别在末传。

### 9_14 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **落象限** | 每课用吉凶 × 旺休出一句完整结论 | 30 秒内完成，不再模棱两可 |
