## 板块15 · 占验档案、笔记法与统计验证

> 这一板块回答一个问题：**怎么把"练习"变成"能力"。** 答案是三件事——记下来、验回去、统计出来。缺了任何一件，练十年也只是在重复第一年。

---

### 15_1 三栏笔记法：每次占问只写三栏

断课笔记最容易犯的毛病是"写成读后感"——大段引经据典，事后回看不知道自己当时到底断的是什么。三栏笔记法解决的就是这个：

```latex
┌──────────────┬──────────────────────┬──────────────────┐
│ 第一栏：盘面   │ 第二栏：判据            │ 第三栏：结论        │
├──────────────┼──────────────────────┼──────────────────┤
│ 课体：        │ 1. 类神是什么，入传否？   │ 成 / 不成 / 有风险  │
│ 日干旺衰：    │ 2. 类神旺相还是休囚？     │ 应期：            │
│ 三传走势：    │ 3. 空不空？受不受克？     │ 行动建议：        │
│ 末传生克干：  │ 4. 有无救神？在哪？       │ 可信度：确定/倾向/存疑│
│ 年命：        │ 5. 应期三维度是否一致？   │ 越界提示：        │
└──────────────┴──────────────────────┴──────────────────┘

```

**为什么是三栏**：第一栏是事实（不容争辩），第二栏是推导（可复查），第三栏是输出（可验证）。事后回填时，你能一眼看出到底是"盘面看错了"还是"推导漏了步"。

### 15_2 占验档案登记表（每占必填）

```latex
【占验档案】编号：____
─────────────────────────────────────
一、输入
日期（公历 / 农历）：____   日干支：____
占时：____（□正时 □活时）  中气区间：____  月将：____
求占人：本命 ____  行年 ____
所问（含动词，一句话）：______________________
─────────────────────────────────────
二、课式摘要
课体：____   三传：__ → __ → __
类神：____   □入课传 □不入   □旺相 □休囚   □空亡
救神：____   应期（预测）：____   可信度：□确定 □倾向 □存疑
─────────────────────────────────────
三、我的断语（原文照抄，事后不许修改）
_____________________________________
─────────────────────────────────────
四、事后回填（结果出现后填写）
事实：______________________________
实际发生时间：____   与预测差：____（早 / 准 / 晚 / 未发生）
─────────────────────────────────────
五、复盘
哪个判据应验了：____________
哪个判据看错了：____________
漏看了哪一步：______________
─────────────────────────────────────

```

> **铁律**：第三栏"我的断语"必须**原文照抄、事后不许修改**。改一个字，这份档案就失去了意义。

### 15_3 复盘四问：结果出现后必答

| 问 | 内容 | 常见答案模式 |
| --- | --- | --- |
| **1. 应了没有？** | 成、不成、拖着、意外 | — |
| **2. 哪个判据应验了？** | 旺衰？类神？三传走势？救神？ | 记下"这条判据在我手里可靠" |
| **3. 哪个判据看错了？** | 具体指出 | 记下"这条判据我常过度使用" |
| **4. 漏看了哪一步？** | 是不是忘了查空亡、忘了看年命、忘了找救神 | 这是最值钱的一栏 |

> **第 4 问是核心**。多数误判不是"判断错"，而是"漏看一步"。漏看的步骤会重复出现，写下来才能打断它。

### 15_4 统计验证：三个必须统计的数字

坚持三个月、满 12 例之后，开始统计：

| 统计项 | 怎么算 | 用途 |
| --- | --- | --- |
| **总体命中率** | 结论方向正确（成或不成）的例数除以总例数 | 知道自己现在在哪一格 |
| **分场景命中率** | 按求财、官禄、疾病、婚姻等分类统计 | 找出自己擅长的与不擅长的场景 |
| **应期偏差方向** | 偏早、准、偏晚各占多少 | 校准自己的应期习惯（多数人会系统性偏早） |

#### 应期偏差的常见原因

| 偏差 | 常见原因 |
| --- | --- |
| **偏早** | 只取了类神临支的字面，没查空亡、没查合绊、没查入墓 |
| **偏晚** | 把"待时令旺"的远期信号当近期用了 |
| **完全不应** | 类神取错，或起课输入层有误（尤其是月将与真太阳时） |

> **统计的意义不是打分，而是定位**。命中率低不可怕，可怕的是不知道低在哪一步。

### 15_5 建立个人规则表（把经验固化下来）

统计到一定量之后，你会得到两张只属于你自己的表。

#### 表一：我的可靠判据（绿色清单）

| 判据 | 适用条件 | 已验证例数 |
| --- | --- | --- |
| 例：类神旺相不空且入传，事成 | 短期、事类明确 | 8 例，7 中 |
| 例：类神空亡，悬而未决、没下文 | 求职、消息类 | 6 例，5 中 |

#### 表二：我的常错清单（红色清单）

| 常错项 | 表现 | 修正动作 |
| --- | --- | --- |
| 例：一见空亡就断凶 | 该免的祸没看出、该虚的喜反当真 | 先问是吉神还是凶神 |
| 例：忽略年命 | 同课异断解释不了 | 每课必标本命、行年 |
| 例：神煞堆砌 | 断语互相打架 | 神煞只作最后精修 |

> **这两张表，才是你学六壬真正的产出。** 书上的口诀是别人的经验表，这两张是你自己的。

### 15_6 案例小故事：一份档案救回的准确率

**背景**：有人练了半年，感觉"时准时不准"，说不清问题在哪。后来他开始写占验档案，坚持四个月，攒了 20 例。

**经过**：他给自己定了三条：每占必登记、断语写完不许改、结果出现后必须回填。前两周很别扭——因为要写下来，才发现自己许多断语其实是模糊的，落笔时根本写不出明确的"成"或"不成"。

**统计结果**：

1. **凡是"求财"类的课，命中率特别低**。逐例回看，发现他每次都把"青龙"当主类，而忽略了长期经营应重父母爻这一条——**方向性错误，不是水平问题**。
2. **他的应期系统性偏早**。15 例里 11 例偏早，回看全是同一个原因：取了类神临支的字面，却没查它是不是落空亡、是不是被合住。

**转折与结果**：改掉这两点之后，命中率明显上升。他说了一句很实在的话：**"我不是变厉害了，我只是知道自己哪里笨。"**

**结果**：他并没有因此变成高手，但从那以后，每一次断课失误都能被定位到具体的一步——是漏查遁干、还是漏查空亡、还是取错类神。错误开始可修复，命中率才开始可提升。

**可复制动作**：

1. 档案的价值不给你能力，它给你**定位**。
2. 满 12 例之后一定要做一次统计，不要凭感觉。
3. 统计要分类——分场景、分可信度档位、分应期偏差方向，笼统的"命中率"没有指导意义。

### 15_7 《壬学琐记》的准入标准：三次实测，才准记下来
《壬学琐记》为清代程树勋（字伟堂，号爱函，安徽歙县人）所撰。作者自己在开篇就讲透了这本书的定位：

> 「予资拙而多健忘，凡有见闻及屡试屡验者，随笔记之，不能分其门类，聊当怀中记事珠云尔。」

这句话有三层信息，决定了该怎么读它：

| 信息 | 含义 |
| --- | --- |
| **「屡试屡验」是准入门槛** | 它不是辑录型类书，而是经验筛选后的留存 |
| **「不能分其门类」是结构特征** | 全书无章节体系，源流、考辨、课例、古籍评点杂糅穿插，按原文顺序读极易散掉 |
| **「记事珠」是阅读姿态** | 它不是要你崇拜，而是要你**核对** |

所以它适合在"已经能起出一张课"之后读，用来校准**哪些环节最容易导致误判**，而不是当入门教材。原书的零散编排，可以用四条主线替代：

| 主线 | 核心问题 | 对实操的价值 |
| --- | --- | --- |
| **甲 · 源流与地位** | 六壬从哪来、凭什么可信 | 建立"为何值得投入"的底层信念 |
| **乙 · 关键争议的技术考辨** | 月将、贵人、正时、遁干——地基怎么打 | **最可落地**的部分，直接决定课式对错 |
| **丙 · 断课的方法论** | 象与生克谁为主、怎么"看一张课" | 形成自己的断课决策流程 |
| **丁 · 实战校验与局限** | 理论到底灵不灵 | 反证 + 边界意识 |

四条主线是递进的：**先信（甲）→ 再对（乙）→ 后会用（丙）→ 最后知道它的边界（丁）**。

其中主线甲有一段因果链，值得记住：

> 唐时功令，以奇门、雷公（即太乙）、六壬为三式。唐时禁奇门、雷公不传，惟六壬便于民用，不涉兵事，故不之禁，传其歧多，精者独鲜。

「传其歧多，精者独鲜」八个字道尽了六壬传承的真相：**流传广不等于水平高**。流派岔路太多，反而稀释了真传。

#### 程树勋式准入标准

> 任何你打算记下来的断法、口诀，必须先有 **三个以上你自己实测或严格复核过的案例**支撑。书里的说法也要分级：标"屡试屡验"的优先，标"未敢以为必然""未尝试"的一律降级为"待验证假说"。

这条标准直接决定 15_5 那两张表（绿色清单、红色清单）里能写进什么——**不够三例的判据，只能进"待验证"，不能进"可靠"**。

#### 案例小故事：一次「八月有凶」的预见

**背景**：程树勋自述其叔父承家学之传，在某次动乱之前预见"八月有凶"，致书亲友，至期果验，乡里始服。

**转折点**：这则记载最容易被读成"某人算准了一次"，于是注意力全在"灵不灵"上。但真正值得看的是它被**完整记录**下来——判断依据、给出时间、事后是否应验，三项俱全。

**这则记载值得注意的三点**：

1. **它是家学长期积累的产物**，不是某条秘诀的一次性显灵。
2. **它给出了明确的时间**（八月）——说明应期判断是有方法的，不是含糊其辞。
3. **它被记录下来并传播**——这就是"校验日志"的价值：一条判断，经过记录与复核，才能变成可传承的经验。

**反过来看我们自己**：**断对的课如果不按 15_2 的档案登记，等于没断过**。三个月后你只记得"我断准过一次"，却不记得是哪一步准的——那这次经验就无法复制。

### 15_8 案例小故事：两次「后果如所占」

**出处**：王剑霞《六壬粹言》卷十三「慕农占验集」。

**背景**：同一位求占者来问两次，隔了大半年。第一次问"今年可升迁否"，第二次问"申报疾痊、示复原缺"。

**第一次**（辛巳正月丙子日申时亥将，任淑渠刺史占今年可升迁否）：

**断语**：「今年未能，明年春定得升迁。」

**依据摆得很整齐**：财官驿马递互相生、中传月将乘贵人又系天诏——**该升**；但初中空陷——**今年不成**；明岁行年在亥，乘皇书驿马，生其日干与龙神——**明春必升**。

**结果**：「次年正月升安陆府知府。」——月份都对上了。

**第二次**（同年九月己卯日戌时戌将）：课得铸印、格合天心、太岁发用生干、朱阴生太岁，部复必准；但太岁受上下夹克，故今年不发，要等「**开正岁建月建与朱雀作三合**」方得部文；又命上驿马夹克、干上幕贵临年，故断「**恐前程未能远到**」。

**结果**：「后部复，果旋有请告之事。」——批文下来了，人却随即告退。

**把两次并排看，才是这一节要教的东西**：

| 层次 | 第一次 | 第二次 |
| --- | --- | --- |
| 事能不能成 | 能（明年春） | 能（开正之后） |
| 什么时候 | 用行年、贵神、驿马定 | 用岁建月建与朱雀三合定 |
| 成到什么程度 | 未及 | **明写"未能远到"** |

**同一门课，同一个人的两次占问，答案的颗粒度完全一致：能成 / 何时成 / 成多深。** 少说其中任何一项，这个答案都是残的。

**可复制动作**：

1. 每次断课固定三段输出：**能否 / 何时 / 到什么程度**，与 15_1 三栏笔记的第三栏对齐。
2. "成"与"成多深"是两件事。第二例若只说"部复必准"，求占人就会以为前程大好——古人不这么断。
3. 同一个人的历次占问要归到同一个档案号下，**前后对照，偏差立刻显形**。

### 15_9 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **三栏笔记** | 每次占问当场写满三栏 | 笔记能一眼看出"盘面、推导、输出" |
| **原文照抄** | 断语写完不许改 | 档案真实可信 |
| **复盘四问** | 结果出现后必答四问 | 每例都有"漏看了哪一步"这一栏 |
| **季度统计** | 满 12 例后统计三项数字 | 知道自己偏早还是偏晚、擅长哪类场景 |
| **两张表** | 建绿色清单与红色清单 | 半年后各满 10 条，形成个人规则 |
