## 板块16 · 择吉与运筹：从预测到主动运用

> 这是被严重低估的部分。多数人只用它"问吉凶"，但它真正的高级用法是**主动选择时间、方位与姿态**——满足条件时，你可以主动做什么。

从"占断"到"运筹"，是从被动预测走向主动决策的跃升。

---

### 16_1 择吉的核心取舍原则

古人给出的取舍逻辑，放在今天依然成立：

1. **会合为上吉**：吉门 + 三奇 + 吉星同宫最佳。
2. **有门无奇犹可用，有奇无门当另择**：**门（行动路径）比奇（时机加持）更优先**。
3. **衰旺 > 名义吉凶**：开门吉但临春夏木火则金衰，不能算吉——**一切以得时得地为准**。
4. **专项用门可破常规**：只要得时得地，凶门亦可为专项所用（捕猎用伤门、逃亡用杜门、吊唁用死门）。

> **重要限制（成熟度标志）**：古人自承"欲求其纯吉无凶者甚难也"，真实择吉往往要反复推求。因此**接受"够用就好"的近似最优，是实操成熟度的标志**——追求纯吉纯凶，反而一事无成。

### 16_3 九遁：从占断到主动运用的跃升

九遁是全书最具操作性的部分。**它不是预测，而是告诉你满足条件时，你可以主动做什么**。

**核心逻辑**：**三吉门（开、休、生）+ 三奇（乙、丙、丁）+ 特定星/神组合 = 某种"遁"**，据此可以择方、择时、布局。

#### 先记《烟波钓叟歌》的原始三遁（这是正本）

歌诀把三遁的**门、奇、神**都指定死了，不是"三吉门任选其一"：

> 生门六丙合六丁，此为**天遁**自分明。
> 开门六乙合六己，**地遁**如斯而已矣。
> 休门六丁共太阴，欲求**人遁**无过此。
> 要知三遁何所宜，藏形遁迹斯为美。

| 遁法 | 《烟波钓叟歌》的组合 | 主要用途 |
| --- | --- | --- |
| **天遁** | **生门** + 丙奇 + 丁奇 | 遁迹隐形、文书奏对、求官升学 |
| **地遁** | **开门** + 乙奇 + 己 | 设伏、谋为、起造、藏匿、置业 |
| **人遁** | **休门** + 丁奇 + **太阴** | 和合、财喜、词讼得理、谈判公关 |

#### 后世扩展的九遁（进阶）

《遁甲演义》卷二另立九遁，把三吉门泛化、并补出风、云、龙、虎、神、鬼六遁：

| 遁法 | 组合条件（简化） | 主要用途 |
| --- | --- | --- |
| 天遁／地遁／人遁 | 见上表原始定义 | 见上表 |
| **风遁** | 三吉门 + 乙奇临六辛落巽宫 | 祭风、火攻 |
| **云遁** | 三吉门 + 乙奇临六辛 | 祈云、求雨 |
| **龙遁** | 三吉门 + 天心/壬/六合临坎宫 | 祈雨、水战 |
| **虎遁** | 开门 + 庚下临兑宫 | 祭风、镇邪、攻险 |
| **神遁** | 开门 + 乙奇合心/禽临九天 | 施计、祭祀 |
| **鬼遁** | 休门 + 天辅/六辛下临丁奇 | 探路、间谍、布谣言 |

> **两说怎么用**：日常择吉用**原始三遁**就够了，它的组合条件明确、可核验。**九遁属扩展体系**，条件更细、流派出入更大，主要用于专项布局，不必作为入门必背。

> **实操要点（必记）**：**九遁是"有条件的吉"。一旦乘上白虎、玄武，则"主灾病、损失"，细事不得全吉。所以判断时永远要先看"有没有凶神叠加"，再看格局名称。**

古人亦强调"九遁凡用事谋为，惟最忌奇墓刑迫"——**先查四害，再论九遁**。
**学习优先级**：九遁属进阶内容，**日常占验不必优先掌握**，主要用于择吉、布局、专项谋为。

### 16_4 方位运筹：把"吉"翻译成坐标

**核心原则**：古人强调"**作用贵乎时方，必须较准真正方位**"——算出吉方在正东震宫，就必须真正朝向正东，**偏几分就"毫厘之差，攸关祸福"**。这是把抽象判断落到行动的关键一步。

**可落地的运筹动作**：

1. **谈事朝向**：重要谈判/签约，朝向用神吉门所在方位（如生门在艮 → 面朝东北）
2. **办公与收银布局**：求财类布局，把办公位/收银台设在生门方；事业类设在开门方
3. **择时启动**：重要行动挑三吉门当值的时辰启动
4. **避开凶方**：庚所在方位、五不击方位，不作为主攻方向
5. **空亡的主动转化**：用神落空不是死局，可**选定填实对应的时辰 + 调整行事方位**来转化

### 16_5 兵占思维的现代迁移

这是它最古老的用武之地，**其博弈结构完全可以迁移到现代竞争决策**：**把"方位"转译为"发力点"，把"出兵"转译为"采取行动"**。

| 兵占原义 | 现代迁移 |
| --- | --- |
| 出兵选开/休/生三吉门 | 重要行动挑吉门方位与时辰启动 |
| **分主客**、背击、孤虚 | 谈判/竞标先分己方（主）与对方（客），定主动或等待 |
| **趋三避五**（胜在三、衰在五） | 行动避开"五"的宫位与时机 |
| **五不击**（太岁、月建、旺气所临等） | **避免正面冲击强势方/高峰期** |
| 五阳时为客（先举）、五阴时为主（后动） | 抢先手 or 等待时机的策略选择 |
| 三胜宫（天乙宫、九天宫、生门宫） | 选择最优发力方向 |
| "春不东伐，秋不西征"（旺气所在宜避） | **不要在对手最强的时间点、最擅长的领域硬碰** |

> 古籍中还有一类"军中应验"体裁，把抽象规则固化为**数十种可直接套用的作战模板**。其价值不在逐条背诵，而在于它示范了一种思路：**把判断规则模板化，遇到同类局面可直接调用**。这正是"体系完备"的真正含义——也是本知识库把场景整理成母模板（板块12）的来源。

**最适合的应用场景**：谈判、竞标、市场进入时机、竞争博弈类决策。

**核心动作三步**：

1. **判阳时/阴时**（主动或等待）；
2. **找生门方**（最优发力方向）；
3. **避五不击**（不碰的方位与时机）。

> **暗线提醒**：现代竞争中，"暗干"的思维同样适用——明面上对方态度友好（明干相生），背后可能有别的算盘（暗干临庚）。重要合作除看明面格局外，应额外做一次背调或条款设防。

### 16_6 现代应用场景总表

| 领域 | 取用思路 |
| --- | --- |
| **商业/投资** | 生门（利润）、开门（事业）、戊（资本）；日干与时干生克定"投不投" |

| **择吉/布局** | 借九遁条件择方位、择时辰，布置办公/收银方位 |
| **竞争博弈** | 兵占迁移：主客、阳时阴时、生门方、避五不击 |

### 16_7 案例小故事：一场谈判的"朝向"实验

**背景**

一位做设备销售的学习者记录过一次完整的运筹实践。他要在周三与一家大客户谈年度框架协议。对方是行业里的大公司，议价能力强，他担心被压价。

**他做的三件事**

**第一件：判主客**

客户是**主动邀约方** → 按主客论，**他为客、我为主**。古法"利主"，意味着不宜抢先亮底牌，宜后发制人。

于是他把谈判策略从"我准备了一个很有诚意的报价"改成了"先听对方的框架"。

**第二件：找发力方**

盘上生门落在艮宫（东北）→ 谈判时**面朝东北**就座。

为了做到这一点，他提前半小时到会议室，调整了座位。这个动作带来一个副作用：他比对方更早进入状态，桌上材料也摆得更整齐。

**第三件：避凶方**

庚落正西 → 他把"价格底线"这个话题**从开场挪到了后半段**，开场只谈交付标准与服务方案。

**实际结果**

对方先报了条件，他按"后发"策略接招，最终在回款周期上争取到了更好的条款。

**他在复盘备注里写得很克制**

> 不能证明是方位起了作用。但它确实改变了我的行为——我因为要"面朝东北"而提前半小时到场布置，因为"后发"而忍住了先报价的冲动。

**这句话恰好说明了运筹的真实机制**

+ 它不制造奇迹，它**制造纪律**；
+ 择方、择时、择姿态，本质上是强行给一次行动加上"**准备、节奏、方向**"三个约束条件；
+ 而这三个条件，本身就是决策质量的一部分。

**这条经验怎么用**：运筹的价值有一半是**心理与行为层面**的——它逼你提前到场、逼你想清楚节奏、逼你不要在情绪上头时开口。即便完全不讨论"方位是否真有影响"，这套约束本身也已经改善了结果。
