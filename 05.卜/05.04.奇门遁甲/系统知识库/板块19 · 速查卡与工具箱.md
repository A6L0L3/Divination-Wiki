### 19_2 时间校准速查

| 步骤 | 操作 |
| --- | --- |
| 扣夏令时 | 减去拨快的 1 小时 |
| 经度时差 | （当地经度 − 120°）× 4 分钟 |
| 均时差 | 查当年真平太阳时差表（约 −14 ~ +16 分钟） |

```plain
真太阳时 = 标准时（已扣夏令时）+（当地经度 − 120°）× 4 分钟 + 均时差

```

> 本卡只抄公式，供排盘时随手取用；**公式每一步的来由、常见误用与城市示例见板块5**，初学时至少精读一遍再靠卡片提速。

**四柱分界**：年以**立春**为界；月以**节令**（精确到时分）为界；日以 **23:00 换日**（夜子时归次日）；时以**真太阳时**为准。

**定三元**：子午卯酉 → 上元；寅申巳亥 → 中元；辰戌丑未 → 下元。

**五虎遁（年上起月）**：甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬位顺行流，戊癸何方发，甲寅之上好追求。

**五鼠遁（日上起时）**：甲己还起甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。

### 19_6 落地的六条行动清单

1. **起局只信节气**：建立自查清单——是否查了精确交节时刻？阴阳遁判对了吗？三元符头算准了吗？这三项是"校准前提"，错一项全盘皆错。
2. **固定一套定局法**：在拆补与置闰中选一种并始终坚持。混用即乱。
3. **建立"四害优先"的检查顺序**：每次断局先扫入墓、击刑、门迫、空亡，再论吉凶格。把这句古训变成一张检查表，贴在排盘纸旁。
4. **用神取准后，先横看生克，再竖看一宫**：先看"我"与"事"的关系（主客、生克），再看局部细节（星门神）。**顺序不能颠倒**，否则容易陷入细节而失掉大局。
5. **永远给出方位 + 时辰的可执行建议**：把"吉"翻译成"几点、朝哪个方向、做什么"；把"凶"翻译成"避开什么、何时再议"。**方位必须精确到真正朝向**。
6. **敬畏反吟与伏吟**：遇反吟伏吟，吉格也要降档处理。反吟利客（主动应变），伏吟利主（守成待时）——这是古法给出的最明确的"行动指令"，比任何具体断语都实用。

### 19_7 排盘工具与阅读顺序

**排盘工具使用原则**：

+ 入门阶段用软件**看懂逻辑**，但**必须手排 10 局以上**搞清符号来源。
+ 选工具时优先支持：**真太阳时自动修正、转盘/飞盘可选、四害标红、拆补/置闰可切换、暗干显示**。
+ 下载走官方应用商店，警惕"破解版"与"付费看完整盘"套路；排盘功能本身应当免费。
+ **软件只给盘面，不给判断**；不要盲信软件自带的"自动解盘"。

**阅读顺序（从易到难）**：

| 层次 | 类型 | 说明 |
| --- | --- | --- |
| **入门** | 现代通行教程 | 通俗、重原理、案例多，适合零基础建立框架 |
| **进阶** | 现代变通类著作 | 聚焦变通思维，跳出"死套断语" |
| **实战** | 现代案例分析类 | 案例丰富，贴合生活场景 |
| **古籍** | 历代汇编与注本 | **有基础再看**，溯源固本 |

> **高效路线**：先用现代教程建立框架，再回到古籍原文逐句对照——**先懂"今人怎么用"，再读"古人怎么讲"**，效率远高于硬啃古籍。

### 19_8 一页流程：从拿到时间到给出建议

```plain
拿到一个时间
   |
   +-- 1. 校时间：真太阳时（经度时差 + 均时差）-> 四柱
   |
   +-- 2. 定阴阳：查交节时刻（到时分）-> 阳遁 / 阴遁
   |
   +-- 3. 定局数：符头定三元 -> 节气查局数 -> 阳遁 N 局 / 阴遁 N 局
   |
   +-- 4. 布地盘：几局从几宫起戊 -> 阳顺阴逆排完 -> 验纵横十五
   |
   +-- 5. 找符使：时柱推旬首 -> 旬首落宫 -> 值符星 / 值使门
   |
   +-- 6. 叠四盘：值符随时干 / 值使随时支 / 小符随大符
   |
   +-- 7. 做补标：空亡、驿马、击刑 -> （进阶）暗干
   |
   +-- 8. 审大局：伏吟 / 反吟 -> 四害 -> 五不遇时
   |        有硬伤 -> 直接给结论（等 / 守 / 放弃），不必细断
   |
   +-- 9. 立用神：主用神 1 个 + 辅助 1-2 个
   |
   +-- 10. 判旺衰：月令 > 宫位 > 状态（九星用专用口诀）
   |
   +-- 11. 查生克：用神宫 与 日干宫 的五种关系
   |
   +-- 12. 合格局：吉格 / 凶格 / 九遁
   |
   +-- 13. 定应期：内快外慢、反快伏慢、空亡待填实
   |
   +-- 14. 出结论：何时 + 何方 + 做什么 + 避什么
   |
   +-- 15. 记卡片：局型卡 -> 事后回填 -> 复盘归因

```

> 前七步是**排盘**（板块5-7），第八步往下是**断局**（板块8-11），最后一步是**沉淀**（板块17）。

### 19_9 案例小故事：一张清单救回的一局

**背景**

一位学习者把 19_5 的检查清单打印出来，贴在书桌旁。起初他觉得这张清单有点"多余"——十六条里大部分他都会做，何必逐条打钩？

**转折发生在一次夜间起局**

那天晚上十一点半，朋友打电话问一件事，他顺手起了局。排完准备断时，他瞥了一眼清单，随手从第一条开始对：

+ 第 1 条：真太阳时校正了吗？——做了；
+ 第 2 条：交节时刻查了吗？——查了；
+ 第 3 条：定局法一致吗？——一致；
+ 第 4 条：纵横十五验算了吗？——验了；
+ 第 5 条：旬首找对了吗？——他停住了。

他重新推了一遍旬首，发现**推错了**——把时柱往前数的时候，跨过了甲，数到了下一旬。

**如果没走这张清单会怎样**

旬首错 → 值符值使错 → 天盘人盘神盘三层全错，而盘面看起来依然完整。他会在一张完全错误的盘上，给朋友一个言之凿凿的结论。

**还有一条差点漏掉的**

清单最后几项里，"第 10 条：代占他人时，太极点换了吗？"也提醒了他——这次问的是朋友的事，不是他自己的事，太极点应当换到对应的符号，而不是用自己的日干。

**他的反思**

> 清单的价值不在于教你做事，而在于**拦住你已经会做、但这次忘了做的事**。

他后来把用法又改进了一步：不是排完盘后核对，而是**在排盘过程中就逐条打钩**——每完成一步立即勾掉，这样错误在发生时就被发现，而不是在最后才被追回。

**这条经验怎么用**：熟练的人最容易犯的不是"不会做"，而是"跳步"。而跳步是没有感觉的——你只会觉得"这次排得挺快"。清单是对抗熟练度带来的自满的唯一工具。
