## 板块3 · 符号系统（中）：八门

> 八门是断"**该不该行动、往哪个方向行动**"的核心，主管人事层面。

一句话定性：**八门是"路径属性"，不是"结果属性"**——它描述这条路好不好走，而不是终点在哪。

---

### 3_2 用门口诀：不同事对应不同的最佳门

| 你想做的事 | 看哪个门 |
| --- | --- |
| 做大事、开创、求职、上官 | **开门** |
| 求财、签约、营造 | **生门** |
| 休养、见贵、谈判、婚恋 | **休门** |
| 考试、文书、宣传 | **景门** |
| 躲灾、保密、潜伏 | **杜门** |
| 讨债、竞技 | **伤门** |

> 三吉门（开、休、生）是最常被选用的"好门"，但**"最常用"不等于"必然吉"**——见 3_3。

---

### 3_3 断门三项检查（本板块最重要的方法论）

**吉凶不在门名，而在"门 + 星 + 旺衰"的组合。**

死门在旺相时可断"武臣侯伯"，休门在休囚时一样"人怕有灾危、财忧有得失"。**永远不能说"开休生三吉门，遇之百事吉"——那是歌诀的简化，不是完整意思。**

**断门三项检查**：

1. **门本身的属性**（宜什么、忌什么）；
2. **所临之星**（吉星扶、凶星破）；
3. **旺相休囚**（得令与否）。

三项合一才下结论。**单看门名下断，是新手最典型的错误。**

**旺衰总纲**：须以**月令为纲**——**休囚之门克不动旺相之宫，旺相之门方能克休囚之宫**。

> 门与宫之间的五行生克还有一种特殊形态叫"门迫/宫迫"（吉门被迫则吉事不成，凶门被迫则凶灾尤甚），属于全局判据，详见板块9。

---

### 3_4 专项用门可破常规

**判断标准是"是否利于成事"，而非符号字面含义。** 吉门只是"阻力小、能量顺"，凶门代表"阻力大、需调整策略"。

| 专项 | 用门 | 为什么 |
| --- | --- | --- |
| 捕猎、讨债、竞技 | **伤门** | 需要冲击力，宜动不宜静，此时"损伤"之性正合用 |
| 逃亡、藏匿、技术攻关 | **杜门** | 需要闭塞不露，"阻塞"反而是保护 |
| 吊唁、收尾、埋伏 | **死门** | 需要终结与沉静，"终结"恰是目的 |
| 揭发、诉讼 | **惊门** | 需要把事情"说破"，"口舌"是工具 |

只要"得时得地"，凶门亦可为专项所用。这条原则在板块16 择吉时还会再次出现——它是"从预测走向运筹"的钥匙。

---

### 3_5 八门在盘面上的两层身份

八门出现在两个地方，容易混淆：

| 身份 | 说明 |
| --- | --- |
| **本位门** | 某宫"原本"是哪一宫的门（休在坎1、死在坤2、伤在震3、杜在巽4、开在乾6、惊在兑7、生在艮8、景在离9），用于**定值使** |
| **转动门** | 人盘排完之后，此刻落在哪一宫的门，用于**断人事** |

**举例**：本位是"坎宫属休门"，但排完人盘后休门可能落在离九宫。断局时看的是**后者**——休门此刻在哪一宫，就说明那个方位/那件事处于"休养、贵人"的状态。

> 定值使用的是本位门，断局用的是转动门。两者不可混（排盘步骤详见板块7）。

### 3_6 案例小故事：同一个开门，两种结局

**背景**

有两位求测者，盘面上都看到"开门"落在自己问事的宫位。按歌诀，这都属于三吉门之一，看起来是同样的好兆头。

**第一位：问事业晋升**

断局者按三项检查走了一遍：

1. **门的属性**——开门主开创、事业、通达，与所问之事高度对题；
2. **所临之星**——临吉星，无冲破；
3. **旺衰**——开门属金，时值秋令金旺，又落本宫乾金，**得时得地**。

再查生克：**开门生日干**。结论："职位可求，且有官方或上级助力，可主动争取。"

他据此准备材料、主动沟通，三个月后岗位落定。

**第二位：问新店开业**

她的盘上开门落在巽四宫，时值仲春。同样三项检查：

1. **门的属性**——开门主开创，对题；
2. **所临之星**——无吉星扶；
3. **旺衰**——开门属金，春令木旺金囚，金气大衰；且落巽木之宫被耗。

这就是典型的**"开门有名无实"**：名字是吉门，实际无力。断局者当时给出的建议是"推迟到秋令再启，或先做小规模试运营"。

她没有采纳，照原计划开了业，客流冷淡，撑了半年转租。

**复盘**

同一个符号，结论相反，差别只在两步：**旺衰 + 是否得地**。这正应了古人凡例反复强调的那句"**最重衰旺休囚**"。

第二位把自己的教训写成了局型卡的第一条备注，只有一句话：

> **"见吉门，先问得令不得令。"**

**这条经验怎么用**：吉凶标签是**名义值**，旺衰才是**实际值**。任何时候看到一个"吉"符号，第一反应不该是高兴，而应该是问一句"它现在有力气吗"。

### 3_7 原典验案：两次"凶门当值"，一次应丧、一次应胜

《奇门遁甲元灵经》卷二"八门值事"里，作者（旧题刘基）留下两则**第一人称的亲历记录**，都写在八门条文下面作为"应候"的实证。这两则很珍贵——奇门古籍绝大多数是"假如某时某局"的教学设例，像这样写清人物、事由、断语与事后结果的纪实条目极少。

#### 验案一：死门应候——出西门，果见殡丧

原文：

> 地气下降，为西南二黑，有**死门**主之。阴气太盛，只宜刑戮葬吊。远行主病，再逢凶星应必遇患人或哭声。**如闰四月二十九日癸亥日丙辰时，在芒种下元，甲寅为符头，天禽为值符，死门为值使，皆到七宫，正西坤之神。余自城南向西走至半路，果见殡丧，是应候也。**凡遭官讼，大忌出此门。

拆开来看它怎么用上了本板块的三层内容：

| 环节 | 盘上依据 | 用的是本板块哪一条 |
| --- | --- | --- |
| 定局 | 芒种下元，甲寅符头 | 符头定元（见板块6_2） |
| 值符值使 | 天禽为值符、**死门为值使**，皆到七宫 | 7_2 的符使定位 |
| 门的名义 | 死门：终结、疾病、收藏，"只宜刑戮葬吊" | 3_1 门的属性 |
| 方位 | 七宫为正西 | 1_2 九宫方位 |
| **定性** | 死门当值 + 出行 → 原文判"远行主病，再逢凶星应必遇患人或哭声" | 3_3 断门三项 |
| **应验** | 自城南向西走至半路，**果见殡丧** | — |

**这一则最值得学的**：它不是"算准了吉凶"，而是**把门、宫、方位三者叠成一个可验证的具体事件**——死门（丧）＋ 七宫（正西）＋ 值使（当下当值），于是断语不是"不吉"，而是"往西去会遇上丧事"。断语越具体，事后越容易复盘；**断语含糊的课，事后是无法验证的**。

#### 验案二：伤门为星，宜出东方——夜大破之

原文：

该条原文完整如下（为便于对照，起局与应验部分加粗）：

> 震居兰台之宫，雷霆发泄之处，春和大布，阳气正通，甲乙正位，盛茂森森。金遇之则伤，水遇之则润，火遇之则焚，土遇之则培。为东方三碧，有**伤门**主之。宜出师执擒报仇、讨叛、渔猎，出此门见火光或伐木人则凶，逢盗贼。**如崇祯辛巳四月十八日，大寇数万掠莱芜吐子口安营，众乡绅举义兵拒之，未胜。夜使人问我出兵之策。时癸亥日亥时，在立夏下元，阳七局，是甲寅符头，至亥时得冲伤门为星，宜出东方，果如所言，夜大破之，余党悉平。**要知九星各有所宜，不拘伏吟。

| 环节 | 内容 |
| --- | --- |
| 事由 | 大寇数万掠莱芜吐子口，乡绅义兵拒之未胜，夜问出兵之策 |
| 时间与局 | 崇祯辛巳四月十八日癸亥日亥时，立夏下元，**阳遁七局**，甲寅符头 |
| 所用符号 | 至亥时**得冲（天冲）、伤门为星** |
| 断语 | **宜出东方** |
| 应验 | "果如所言，**夜大破之，余党悉平**" |

**这一则演示的正是 3_4「专项用门可破常规」**：伤门在 3_1 的吉凶分组里属**三凶门**（死、惊、伤），但此课问的是出兵破寇，恰恰需要冲击力——**"宜出师执擒报仇、讨叛"，此时"损伤"之性正合用**。若死守"凶门不能用"，这一课就断不出来。

原典自己加的那句收尾也很有分量："**要知九星各有所宜，不拘伏吟。**"——符号各有各的适用场域，不要被"伏吟"这类大局硬伤一票否决掉全部判断。

#### 两则合起来看

| | 验案一 | 验案二 |
| --- | --- | --- |
| 门 | 死门（凶门） | 伤门（凶门） |
| 问的事 | 出行 | 出兵 |
| 结论 | **避**——不宜出此门 | **用**——宜出东方 |
| 分野在哪 | 事的"性质"与门的"性质"不匹配，且无专项用途可依托 | 事的"性质"与门的"性质"正好对上，属于专项用门 |

> **同一个"凶门"标签，一个避、一个用，差别不在门，在"所问之事是否与门性相合"。** 这就是 3_4 那张"专项用门"表的由来，也是"吉凶是名义值"的另一面：**凶名之下，也可能正是你要找的工具。**
