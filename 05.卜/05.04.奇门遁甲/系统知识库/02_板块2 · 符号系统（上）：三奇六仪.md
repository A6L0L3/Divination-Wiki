## 板块2 · 符号系统（上）：三奇六仪

> 上一个板块给了坐标系，从本板块开始往里填"字"。

三奇六仪是盘的**骨架干支**——它们既构成地盘的底色，又随天盘转动形成格局。理解了这一层，后面读十干克应（板块8）才不会无从下手。

---

### 2_1 甲为什么要遁：整套设计的出发点

十天干里"甲"是统帅，但它不直接出现在盘面上，而是**隐遁在六仪之下**。这不是文字游戏，而是整套模型的第一个设计决策。

> 原典："遁甲为兵而设，为阴象，为诡道，故取诸遁，谓其遁于六仪之下而不见其形也。"

三层含义：

1. **兵者诡道**：主帅不能暴露，暴露则被针对。所以"藏"本身就是策略。
2. **六仪是甲的仪仗**：甲虽不出面，但它所在的位置由六仪标记，看到六仪就知道甲在哪一旬。
3. **甲宜生扶不宜克制**：凡是克甲、损甲的力量，天然站在"敌"的位置上。

**这条设计直接决定了后面三件事**：

+ 排盘时"找旬首"为什么那么关键——因为那是定位甲的坐标；
+ 庚为什么是第一凶干——因为庚克甲；
+ 三奇为什么是吉——因为乙丙丁是甲的同气与子嗣，负责在外护卫。

**记忆要点**：

+ **乙丙丁为三奇**，是"吉祥变量"，盘里最想遇到的能量；
+ **戊己庚辛壬癸为六仪**，是甲的仪仗与阵营，各带倾向；
+ 三奇中的丙丁同属火，乙独属木；六仪中戊己属土、庚辛属金、壬癸属水。

### 2_4 永定排列顺序（宪法级规则）

不管阴遁阳遁、不管转盘飞盘，这条队列**永远不变**：

> **戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙**

```plain
  戊  己  庚  辛  壬  癸  丁  丙  乙
  +---------------------+ +---------+
    六仪                     三奇

```

**两个易错点**：

1. **乙丙丁永远排在最后三位**。很多人按天干自然顺序（甲乙丙丁戊己庚辛壬癸）去排，一上手就错。
2. **六仪在前、三奇在后**。记住这个顺序，就记住了"甲先布阵（六仪），再放护卫（三奇）"的逻辑。

> 这是排地盘的"宪法级"规则，值得单独抄写十遍——**记错一个位置全盘皆错**。

### 2_5 两个实操抓手：盯庚、用丁

#### 抓手一：庚是全书最要盯紧的天干

庚代表**阻碍、变动、对立面**（敌方、竞争对手）。庚的落宫与状态，是判断"阻力从哪来、有多大"的第一线索，不可略过。

为什么是庚？

+ 五行上**庚金克甲木**，它天然是甲的敌人；
+ 庚同时具备"阻碍 + 变动"双重身份——意味着**局面在动，而且是朝对你不利的方向动**；
+ 古人几乎把"时加六庚"单列为大凶信号。

**实操动作**：拿到一张盘，先圈出庚在哪一宫，再问三句——庚落宫是用神宫吗？庚克谁？庚被谁克？

#### 抓手二：丁奇最灵

原典判定："丁昼夜皆明，尤旺于星夜，故曰惟丁奇最灵。"

实操中涉及**文书、信息、暗助**类的事，应优先关注丁奇。问考试、问签约、问消息能否送达，丁奇的旺衰与落宫往往比三奇中的另外两个更"贴题"。

> **组合总纲**：三奇遇吉门吉星，多为大吉之格；六仪里庚最重要——**几乎每个格局的判断都要先看庚在哪里、被谁克。**

### 2_6 天地两盘的干：格局是怎么生成的

盘面上同一个宫里，会出现**两个天干**：

+ **地盘干**：布地盘时按队列固定排入，代表**现状根基、静态底色**；
+ **天盘干**：随九星转动而来，代表**外来事态、动态变化**。

上下一照，就形成"格局"——这就是十干克应（板块8）的生成原理。

```plain
+--------------------------+
| 天盘干 = 外来事态        |   <- 随九星转动而来
+--------------------------+
| 地盘干 = 现状根基        |   <- 布地盘时固定排入
+--------------------------+

```

理解这一点有什么用？**当你忘了某条格局断语时，可以从两个天干的五行生克现场推回来。** 这也是板块8 反复强调"原理比背诵重要"的原因。

### 2_7 案例小故事：只盯着"吉格"名字的一次误判

**背景**

一位学习者接过一个问合作的盘。他扫了一眼，看到用神宫里有丙奇，立刻想到"三奇主吉"，又看到临吉门，于是断为："可成，而且顺利。"

**后来的结果**

合作谈成了，但执行过程中对方三次变更条款，最后利润被压到几乎无利可图。求测者的原话是："你说的'可成'是对的，但你没说它会变成这样。"

**复盘**

他把盘重新摊开，这次按规矩先做了一件事——**找庚**。结果发现庚落在与用神宫相冲的位置，且庚未被制。

对照原理：

+ 丙奇确实代表光明、权威、突破——是吉；
+ 但庚代表**阻碍与变动**，它落在关键位置意味着"局面会反复动"；
+ 他漏掉的不是格局，而是**格局的层次**：三奇的"吉"描述的是**能量性质**，庚的"凶"描述的是**阻力来源**，两者不在一个层面上，不能互相抵消。

正确的读法应当是：

> **"事能成（三奇 + 吉门），但过程会反复、条款会被改（庚动而不制）。"**

对应的落地建议也就完全不同——不是"放手推进"，而是"把变更条款写进合同、设违约金、分阶段验收"。

**他给自己补的一条规则**

拿到盘先圈庚，再论吉神。用他的话说：

> "三奇告诉你这件事'好不好'，庚告诉你它'顺不顺'——这两个问题都得回答。"

**这条经验怎么用**：吉格与凶干常常同时存在，它们描述的是**不同维度**，不能用"吉多于凶"来加减。断局时要分别回答"性质"与"阻力"，而不是合成一句"还不错"。
