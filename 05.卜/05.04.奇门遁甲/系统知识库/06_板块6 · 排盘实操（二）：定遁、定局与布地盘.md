## 板块6 · 排盘实操（二）：定遁、定局与布地盘

> 上一步拿到了校准后的四柱，本板块要把它变成**一个明确的局数**（如"阳遁三局"），再据此布出地盘。

本板块的输出物：**一张三奇六仪分布正确、通过纵横十五校验的九宫底图**。

---

### 6_1 定阴阳遁

+ 冬至 → 夏至（含芒种）：**阳遁，顺排**
+ 夏至 → 冬至（含大雪）：**阴遁，逆排**

**检查动作**：查该日前后**精确到时分**的二十四节气交节时刻，确认求测时刻落在哪一侧。临界日（冬至、夏至前后）尤其要查到分钟。

**为什么顺逆如此重要**：顺逆不是装饰，它决定了"**时间箭头**"的方向——阳遁代表生发、向外、进取；阴遁代表收敛、向内、守藏。所有排盘动作（布地盘、转天盘、飞八门、排八神）都遵循"阳顺阴逆"这一条总原则。

---

### 6_2 定三元

每个节气分上、中、下三元，每元约五日。以**符头地支**定：

| 符头地支 | 元 |
| --- | --- |
| 子、午、卯、酉 | **上元** |
| 寅、申、巳、亥 | **中元** |
| 辰、戌、丑、未 | **下元** |

> **符头**：六十甲子分六旬，每旬以甲或己开头的那一天即为该旬符头。拆补法以"凡天干遇甲或己即为符头"为判定依据。

---

### 6_3 定局法：三种口径，选定一种全程不改

地球公转约 365.24 天，而这套模型以 360 天演 72 局，余下约 5.24 天需处理，由此产生三种定局口径。

| 方法 | 核心逻辑 | 特点 | 适用 |
| --- | --- | --- | --- |
| **拆补法** | 节气一到立即换局，用下元余日填补上元缺日，动态平衡 | 重节气同步，**最省事** | **新手首选，现代主流** |
| **置闰法** | 符头（甲己日）优先，超神接气；超神逾九日且逢**芒种/大雪**时重复三元以归零 | 重干支自洽，需算超神接气与置闰 | 传统古法 |
| **茅山法** | 交节即起上元，每 60 时辰换元，不用符头 | 最简洁 | 用者少 |

> **致命警示**：

第1步 **两套系统不可混用**。混用会导致同一时辰排出不同局数，事后无法复盘，经验永远积累不起来。**禁止"平时用拆补、遇到对不上就临时换置闰"。**
第2步 **网上流传的"局数 =（年支 + 月 + 日 + 时支）÷ 9 取余"是错误简化**。局数由"节气 + 三元"共同决定，与年柱、时柱数字无直接算术关系。

---

### 6_4 超神、接气与置闰（置闰法核心）

节气（天文）与符头（干支）不会永远同步，这个误差需要专门处理。

+ **超神**：符头日早于节气交节 → 符头"超"前了 → 提前用未来节气的局。
+ **接气**：节气已到但符头未到 → 以符头为主，沿用前一局，等符头到了再接。
+ **置闰**：超神超过九日以上，且在**芒种或大雪**这两个阴阳转换节点 → 重复该节气三元以归零累积误差。

**关键约束**：

+ 置闰**只发生在芒种、大雪**，绝不发生在其他节气。原因：芒种→夏至是阳遁终转阴遁始，大雪→冬至是阴遁终转阳遁始，只有这两个阴阳大序的转换点能"清零"。
+ "宁可多二三时，不可少"——补齐优先。
+ 古法另有"**超不过十，接不过五**"，符头先到七日即当置闰。

> 初学者**不必一开始就啃置闰**。推荐路径：直接用拆补法定局，把精力放在用神与断局上；定局规则熟练后再回头深究——这是效率最高的学习顺序。

### 6_6 为什么只有十八局（元认知：它是有限循环）

古法叙述是一条"删减链"：

```plain
一年 360 天 × 12 时辰 = 4320 局
        ↓ 四时分判，层层去重
黄帝始制 1080 局 → 姜太公删为 72 局 → 张良定为 18 局（阳九、阴九）

```

它的数学本质是**去重**：因四时分判存在重复，层层约简至 18 局（每局再分四，即 72 局；配合节气三元展开为 4320 局的盘面全集）。

**这一处是最重要的"元认知"**：

+ 它不是无限随机的，而是**有限局数的循环查表**；
+ 同一节气、同一元、同一时辰 → 局数必然相同；
+ 所谓"断卦经验"，大部分是**对固定局型的记忆与归类的熟练度**；
+ 因此"**多断、多验、多记局**"的价值，远高于空谈"灵感"。

> 这也直接决定了板块17 为什么要强调记笔记：**既然是有限循环，经验就可以沉淀。**

### 6_7 布地盘：排三奇六仪

**规则**："几局"就从几宫起戊，按阳顺阴逆把 `戊己庚辛壬癸丁丙乙` 排入九宫。

+ **阳遁**：顺九宫数（1→2→3→4→5→6→7→8→9）
+ **阴遁**：逆九宫数（9→8→7→6→5→4→3→2→1）
+ 中五宫的天干**寄于坤二宫**（转盘主流做法）

**地盘恒定不动，是整个局的空间基准。**

#### 阳遁一局示例

```plain
   巽四(辛)    离九(乙)    坤二(己)
   震三(庚)    中五(壬)    兑七(丁)
   艮八(丙)    坎一(戊)    乾六(癸)
   （中五宫壬寄坤二宫）

```

排布过程：

```plain
坎1 起戊 → 坤2 己 → 震3 庚 → 巽4 辛 → 中5 壬 → 乾6 癸 → 兑7 丁 → 艮8 丙 → 离9 乙

```

#### 阴遁九局示例

```plain
离9 起戊 → 艮8 己 → 兑7 庚 → 乾6 辛 → 中5 壬 → 巽4 癸 → 震3 丁 → 坤2 丙 → 坎1 乙

```

#### 自检

排完立刻验算**纵横十五**——横、竖、斜三宫数字之和是否皆为 15。这个动作只需 10 秒，却能拦住绝大多数布盘错误。

### 6_8 案例小故事：省掉的那一步，让半年白干

**背景**

一位学习者自述走过一段弯路：他学排盘时觉得"定局"太麻烦，于是采用了一条网上传播很广的速算法——**局数 =（年支 + 月 + 日 + 时支）÷ 9 取余**。

**前半年的状况**

他每天排一两局，速度很快，自我感觉良好。但渐渐地他发现一件事：他断的事**几乎没有一例能跟实际对上**，而且错得毫无规律——有时方向对、有时方向反，有时连用神落宫都对不上。

**转折点**

他拿自己排的一局去和一款主流软件对照，发现局数不一样。他以为是软件错了，于是又找了第二个软件——两个软件给出的局数一致，与他不同。

**问题定位**

他用的那条速算法**根本不是这套模型的规则**。局数由"节气 + 三元"共同决定，与年柱、时柱的数字**没有任何算术关系**。那条速算法之所以能在少数情况下"碰对"，纯粹是偶然。

**后果有多严重**

局数错 → 起戊的宫错 → 整个地盘干全部错位 → 旬首落宫错 → 值符值使错 → 四盘全错。

也就是说，**他半年里排的每一局都是无效的**，而且因为盘面看起来完整，他一直没察觉。

**他后来的做法**

1. 老老实实背定局歌诀，直到能默写出二十四节气局数表；
2. 改用手排 + 软件双校验，连续两周每天一局，直到一致率超过 90%；
3. 在常去的论坛里专门发了一条帖，提醒别人别用那条速算法。

**这条经验怎么用**：这条速算法之所以有市场，是因为**它承诺了一条捷径**。而这套模型里凡是承诺"不用懂原理就能算对"的捷径，几乎都会在最关键的一步上断掉。捷径可以走，但必须走在你已经知道正确路径长什么样之后。
