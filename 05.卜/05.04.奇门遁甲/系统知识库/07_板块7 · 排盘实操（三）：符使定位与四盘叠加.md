## 板块7 · 排盘实操（三）：符使定位与四盘叠加

> 前两步拿到了时间校准的四柱和一张地盘。本板块要在这张静态底图上，把天盘、人盘、神盘三层依次叠上去，并补标空亡、驿马、击刑、伏吟反吟与暗干。

本板块的输出物：**一张四层齐全、标注完整的九宫图**。

### 7_1 找旬首：六甲旬首表与推法

时柱干支往前推，找到所属六甲旬首。**这一步错了，后面全盘错位——它是"钥匙中的钥匙"。**

#### 六旬完整对照

| 旬首 | 所遁六仪 | 该旬所辖十个时辰 |
| --- | --- | --- |
| 甲子 | 戊 | 甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉 |
| 甲戌 | 己 | 甲戌、乙亥、丙子、丁丑、戊寅、己卯、庚辰、辛巳、壬午、癸未 |
| 甲申 | 庚 | 甲申、乙酉、丙戌、丁亥、戊子、己丑、庚寅、辛卯、壬辰、癸巳 |
| 甲午 | 辛 | 甲午、乙未、丙申、丁酉、戊戌、己亥、庚子、辛丑、壬寅、癸卯 |
| 甲辰 | 壬 | 甲辰、乙巳、丙午、丁未、戊申、己酉、庚戌、辛亥、壬子、癸丑 |
| 甲寅 | 癸 | 甲寅、乙卯、丙辰、丁巳、戊午、己未、庚申、辛酉、壬戌、癸亥 |

**推法**：把时柱干支在六十甲子中往前数，数到最近的"甲"开头那一柱，即为旬首。

> 例：戊戌时 → 往前推至**甲午** → 甲午旬 → 旬首甲午辛，所遁六仪为**辛**。

速记：**甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸**。

### 7_3 排天盘（九星）：值符随时干

**口诀：值符随时干。**

把值符星移到**地盘时干**所在之宫，其余八星按固定环序跟随排布，**永远顺时针**。

**九星环序（天盘转动序）**：

> **蓬 → 任 → 冲 → 辅 → 英 → 芮(禽) → 柱 → 心**

**注意两条序列不可混记**：

| 序列 | 内容 | 用途 |
| --- | --- | --- |
| **本位序** | 蓬、芮、冲、辅、禽、心、柱、任、英 | 定"某宫原本是哪颗星" |
| **环序** | 蓬、任、冲、辅、英、芮(禽)、柱、心 | 定"转动时谁跟在谁后面" |

**天盘干随星走**：天盘干 = 该星本位宫所携带的地盘干，随星一起转动。

> 时干为"甲"时，用旬首仪代替；落中五则寄坤二。

---

### 7_4 排人盘（八门）：值使随时支

**口诀：值使随时支。**

从旬首本宫起算，按时辰在旬内的序数，**阳遁顺数、阴遁逆数**（走九宫顺序），落宫即值使门位置。其余七门按固定环序**永远顺时针**对齐。

**八门环序（人盘转动序）**：

> **休 → 生 → 伤 → 杜 → 景 → 死 → 惊 → 开**

**注意**：转盘体系中**八门不入中五宫，直接跳过**；飞盘体系用"间宫法"（阳遁从中跳到乾六，阴遁跳到巽四）。

---

### 7_5 排神盘（八神）：小值符随大值符

**口诀：小符随大符。**

把八神的"值符"放在**天盘值符星同宫**，其余七神按固定顺序排布，**阳遁顺时针、阴遁逆时针**。

> **值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天**

**八神不参与五行生克，只作吉凶加成**（此为主流口径；八神名目另有"勾陈、朱雀"一式，且有"八神可论五行"的异说，详见板块4_4）。

### 7_7 暗干（隐干 / 飞干）：进阶的隐性一层

暗干藏于**人盘八门之内**，代表**人心私念、幕后操作、隐藏矛盾、未说出口的内情**。

+ **明干看明面事态**（对方说了什么、台面上在发生什么）；
+ **暗干看底层动机**（对方没说出口的算盘、合作背后的真实顾虑）。

**典型用法**：

+ 求财见**暗干临庚** → 表面生意红火，私下欠款损耗不断；
+ 合作见暗干与明干方向相反 → 对方表态与实际意图不一致，需追加核实。

> 暗干属进阶内容。入门阶段可以先不排，等六步流程跑顺之后再加这一层。

### 7_8 排盘总诀与完整演练

**排盘总诀**：

> 阴阳二遁分顺逆，三奇六仪地盘立；

值符值使随时转，九星八门布人天；
八神加临辨吉凶，用神先把日干牵。
（续）伏吟反吟空亡看，应期方得事周全。

**三大铁律**：

1. **值符随时干**
2. **值使随时支**
3. **小符（神盘值符）随大符（天盘值符星）**

### 7_9 案例小故事：旬首找错，四层连锁错位

**背景**

一位学习者断过一局"求职"，得到"开门生日干，职位可成"，结果等了一个月毫无音讯。

**复盘第一步：重排**

他把那一局原样重排了一遍，与软件对照——排盘流程本身没问题，地盘也对。

**复盘第二步：查旬首**

问题出在这里：他把时柱往前推旬首时**少推了一位**，把某甲辰旬的时辰当成了甲午旬。

**连锁反应完整展开**

| 环节 | 正确 | 他用的 | 后果 |
| --- | --- | --- | --- |
| 旬首 | 甲辰壬 | 甲午辛 | 六仪落宫不同 |
| 值符 | 天辅 | 天芮 | 天盘整体错位 |
| 值使 | 杜门 | 死门 | 人盘整体错位 |
| 神盘值符 | 随天辅落宫 | 随天芮落宫 | 跟着错 |

四层里错了三层，但盘面"看起来"依然是完整的九宫——没有一个格子是空的，天干、星、门、神全都填满了。这正是最危险的地方：**肉眼看不出任何破绽**。

**他的领悟**

他后来说，那一刻他意识到一件事：**排盘错误不会表现为"缺东西"，只会表现为"所有东西都在，但都在错的格子里"。**

**他给自己加的强制工序**（写在流程的第一行）：

```plain
排完盘，先回答三句话，再进入断局：
1. 值符在哪一宫？
2. 值使在哪一宫？
3. 值符宫与用神宫是什么关系？

```

**效果**

从那以后，他断错的局里**几乎没有一例是排盘错误导致的**——剩下的偏差全部出在判断层面。而判断层面的偏差是**可以复盘、可以改进的**，排盘错误则完全是浪费时间。

**这条经验怎么用**：一个流程的可靠性，取决于它有没有**自检点**。这三句话就是排盘流程的自检点——成本极低（几秒钟），却能在错误扩散之前把它拦住。
