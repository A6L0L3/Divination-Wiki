## 板块1 · 先破题：奇门遁甲到底是什么

很多人卡在"玄奥"二字上，其实奇门的核心极其朴素——**它是一个时空模型，不是迷信**。

把起局的那一刻换算成干支四柱，再把天、地、人、神四层信息投影到洛书九宫上，就得到了一张"奇门局"。这张盘模拟的是：**在此时、此地、此事下，天时、地利、人和、神助各自的能量状态**。历史上它被称为"帝王之学""三式之首"，擅长的是时空统筹与运筹决策。

一句话记住全貌：

> **天时（九星）+ 地利（九宫八卦）+ 人和（八门）+ 神助（八神）+ 格局（三奇六仪）= 一张奇门盘**

"奇门遁甲"四个字也可以拆开理解，这是全书的钥匙：

| 字 | 对应 | 含义 |
| --- | --- | --- |
| 奇 | 乙、丙、丁（三奇） | 天上的三颗"吉贵之神" |
| 门 | 休、生、伤、杜、景、死、惊、开（八门） | 人事、行为的吉凶趋势 |
| 遁甲 | 甲（统帅）隐于六仪之下 | 核心不露，"藏"的兵法思想 |

**"遁甲"是这个体系最妙的设计**：甲是统帅，不能直接暴露，于是分别遁藏在戊、己、庚、辛、壬、癸六仪之下——即"六甲六仪"：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。理解了这一点，后面"找旬首、定值符值使"就不会乱。

### 1_1 入门的三条铁律（先立规矩，再谈技巧）

1. **先学预测逻辑，别一上来就学化解、改运、法术奇门。** 地基不牢，一切白搭。
2. **理解"时空 + 方位 + 人事"模型，别死记硬背断语。** 死套公式永远学不会变通。
3. **先用软件排盘看懂逻辑，再回头手排。** 入门阶段把精力放在"读懂"而不是"算对"。

## 板块2 · 第一层基石：必须先啃下来的底层知识

奇门的符号看似庞杂，其实只有四大板块。任何一块不熟，后面排盘都会卡壳。

### 2_1 阴阳五行：所有推演的底层逻辑

+ **阴阳**：对立、互根、消长、转化（动与静、昼与夜、吉与凶）。
+ **五行**：木、火、土、金、水。
    - 相生：木 → 火 → 土 → 金 → 水
    - 相克：木 → 土 → 水 → 火 → 金
+ **旺衰（旺相休囚死）**：决定一个符号"有没有力气"，是判断能量强弱的核心尺子。

> 旺衰口诀：**"同我者旺，我生者相，生我者休，克我者囚，我克者死。"**

用神得月令生扶 = 旺（事易成）；被月令克制 = 衰（有心无力）。这是断局的第一权重。

### 2_2 天干地支：时间与空间的编码系统

**十天干（甲→癸）**：分阴阳五行，需懂化合（甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火）与冲（甲庚、乙辛、丙壬、丁癸）。

**十二地支（子→亥）**：记生肖时辰，学三合（申子辰水、亥卯未木、寅午戌火、巳酉丑金）、六合、六冲（子午、卯酉、寅申、巳亥、辰戌、丑未）、刑害。

> 核心提醒：**奇门里的天盘、地盘、人盘，全部由干支推演而来。** 干支不熟，盘面就是天书。

### 2_3 后天八卦 + 洛书九宫：排盘的空间骨架

奇门用的是**后天八卦配洛书九宫**，这是固定不变的核心框架。必须背到形成肌肉记忆：

**九宫速记心诀：戴九履一，左三右七，二四为肩，六八为足，五居中央。**

| 宫数 | 八卦 | 方位 | 五行 | 关键象意（节选） |
| --- | --- | --- | --- | --- |
| 1 | 坎 ☵ | 北 | 水 | 中男、肾、耳 |
| 2 | 坤 ☷ | 西南 | 土 | 母、腹、脾胃 |
| 3 | 震 ☳ | 东 | 木 | 长男、肝、足 |
| 4 | 巽 ☴ | 东南 | 木 | 长女、肱、股 |
| 5 | 中 | — | 土 | 中宫（奇门中寄坤二宫或艮八宫） |
| 6 | 乾 ☰ | 西北 | 金 | 父、头、骨 |
| 7 | 兑 ☱ | 西 | 金 | 少女、口、肺 |
| 8 | 艮 ☶ | 东北 | 土 | 少男、脾、手 |
| 9 | 离 ☲ | 南 | 火 | 中女、心、目 |

> 学习建议：先背洛书九宫数字图，再记后天八卦方位，然后拿笔手绘"天干地支生克关系图"。每天花 10 分钟推演一组关系（如"寅卯月木旺，木克土则土死"），半月即可建立直觉。

## 板块3 · 第二层符号：盘面 64 个符号的实战取象

基础打牢后，进入奇门专属的符号系统。这一层是断局的"词汇表"，**光背吉凶不够，要背"象意"——因为一个符号会随所问之事变换身份**。

### 3_1 三奇六仪（天干层）

三奇为吉，六仪各带倾向。庚为全盘最重要的"凶干"，代表阻碍、对手、变动，**见庚多受阻**。

|  | 丁（星奇） | 文昌、灵感、信息、暗助 |

|  | 庚 | 甲申隐处，**阻碍、敌人、变动（第一凶干）** |
|  | 辛 | 甲午隐处，错误、瑕疵、变革 |
|  | 壬 | 甲辰隐处，流动、奔波、变动 |

八门是断"该不该行动、往哪个方向行动"的核心。口诀：**休生开吉，死惊伤凶，杜景中性。**

九星有固定本位（蓬坎、任艮、冲震、辅巽、禽中、心乾、柱兑、芮坤、英离）。**天禽居中宫特殊，排盘中恒寄于坤二宫，随天芮同宫转动。**

## 板块4 · 第三层排盘：七步起出一张规范局

排盘是入门最大的门槛。核心规则一句话：**地盘不动，天盘、人盘整体旋转；九星八门的相对顺序永不改变，仅阴阳遁决定起运方向。**

### 4_1 流派选择：新手选"时家奇门 · 转盘 · 拆补法"

奇门分年/月/日/时家，入门用**时家奇门**（精确到时辰，最常用）。排法分转盘与飞盘：

+ **转盘**（新手友好）：按宫位顺序转，九星八门恒顺时针轮转，仅八神随阴阳遁变方向。**排盘软件默认即为转盘。**
+ **飞盘**（高阶）：按宫位数字飞布（阳顺阴逆），九星独立落宫（含天禽），用"九神"体系。

以下流程以**转盘法**为准。

### 4_2 七步标准起局流程

#### 4_2_1 第 1 步：定时间，辨阴阳

明确求测的具体时刻（**取正时，意念专一，不可刻意挑时辰**），换算成干支四柱。注意：

+ 年柱以**立春**为界，月柱以**节令**精确时刻为界；
+ 日柱 **23:00 换日**（晚子时归次日）；
+ 时柱按**五鼠遁**推算（见下）。

**阴阳遁判定**：冬至 → 夏至用**阳遁（顺排）**；夏至 → 冬至用**阴遁（逆排）**。

> **五鼠遁歌诀**（日干 → 时干）：

甲己还起甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。

#### 4_2_2 第 2 步：定局数（拆补法）

按节气 + 日干支定上/中/下三元，再查**阴阳遁九局起例歌**得局数。核心：以实际节气交接时刻为准，符头（天干遇甲或己）定元。

> 阳遁九局起例歌（节选）：冬至惊蛰一七四，小寒二八五同推，春分大寒三九六……

阴遁九局起例歌（节选）：夏至白露九三六，小暑八二五之间，大暑秋分七一四……

**也有简化的局数公式（民间常用，可作校验）**：
`局数 = (年支序数 + 月数 + 日数 + 时支序数) ÷ 9 的余数`

#### 4_2_3 第 3 步：布地盘（排三奇六仪）

按局数，在九宫起"戊"。**顺序永远固定为：戊己庚辛壬癸丁丙乙**——不论阴阳遁，仅方向不同。

+ 阳遁：顺排（局数宫 → 数字递增方向）
+ 阴遁：逆排（局数宫 → 数字递减方向）

地盘恒定不动，是整个局的空间基准。中五宫的天干**寄于坤二宫**（主流做法）。

#### 4_2_4 第 4 步：找旬首，定值符值使

看**时柱**属于哪一"旬"（六甲），旬首落宫之**原地盘九星 = 值符**，**原地盘八门 = 值使**。

> **六甲旬首对照**：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。

例：戊戌时 → 甲午旬 → 旬首为甲午辛。

**原始星门本位表（必背）**：

| 宫 | 本位星 | 本位门 |
| --- | --- | --- |
| 坎 1 | 天蓬 | 休门 |
| 坤 2 | 天芮（含天禽） | 死门 |
| 震 3 | 天冲 | 伤门 |
| 巽 4 | 天辅 | 杜门 |
| 中 5 | 天禽 | — |
| 乾 6 | 天心 | 开门 |
| 兑 7 | 天柱 | 惊门 |
| 艮 8 | 天任 | 生门 |
| 离 9 | 天英 | 景门 |

#### 4_2_5 第 5 步：排天盘（九星）— "值符随时干"

把值符星移到**地盘时干所在宫**，其余八星按固定环序 **蓬 → 任 → 冲 → 辅 → 英 → 芮(禽) → 柱 → 心** **永远顺时针**跟随排布。天盘干随星所携带的地盘干一并转动。

> 时干为甲时，用旬首仪代替，落中五则寄坤二。

#### 4_2_6 第 6 步：排人盘（八门）— "值使随时支"

从旬首本宫起算，按**时辰在旬内的序数**，阳遁顺数、阴遁逆数（走九宫顺序，含中宫），落宫即值使门位置。其余七门按 **休 → 生 → 伤 → 杜 → 景 → 死 → 惊 → 开** **永远顺时针**对齐。

#### 4_2_7 第 7 步：排神盘（八神）— "小值符随大值符"

值符神落**值符星同宫**，其余七神按固定顺序：**阳遁顺时针、阴遁逆时针**排布。八神不参与五行生克。

## 板块5 · 第四层断局：从"读懂盘面"到"给出指引"

排盘是手段，断局才是目的。很多人排得出来却无从下手，问题就出在**没有标准的断局顺序**。按下面六步走，就不会乱章法。

### 5_1 断局六步标准流程

**第 1 步：定用神（断事第一关键，选错全盘皆错）**

用神 = 盘面中代表"求测人 / 所求之事"的符号。核心法则：**以事定神、以人定位、主客分明、多神互证**。

**第 2 步：看用神旺衰（决定事情力量大小）**

优先级：**月令旺衰 > 宫位五行生克 > 九星旺衰**。"旺则事成，衰则事败；得地则兴，失地则亡。"

**第 3 步：看用神与日干的生克关系（事对我有利还是有害）**

| 关系 | 含义 |
| --- | --- |
| 用神 **生** 日干 | 事来找我，不劳而获，顺利 |
| 日干 **生** 用神 | 我去求事，主动付出，费力 |
| 用神 **克** 日干 | 事来克我，压力、凶险 |
| 日干 **克** 用神 | 我能掌控，费力可成 |
| 同宫比和 | 平稳、和顺、中等 |

**第 4 步：查格局（定事情本质吉凶）**

优先看四凶格、青龙返首、飞鸟跌穴、伏吟反吟。格局决定事情"性质"：格局吉，纵然衰弱也有转机；格局凶，纵然旺相也必有波折。

**第 5 步：看星门神煞，补充细节**

用吉门吉星吉神修正大势，用凶门凶星凶神提示风险点。

**第 6 步：出结论，给指引（落地可执行，而非只说吉凶）**

+ 能成的事：**利在何方、吉在何时、怎么借力、注意什么**
+ 不成的事：**问题在哪、阻碍是什么、要不要等、怎么规避**
+ 两难的事：**对比不同方向利弊，给出最优建议**

### 5_2 用神速查表（实战大全，建议抄下来）

> **三大取用总法则**：① 四值六亲法（日干=我，年干=长辈/上级，月干=同辈，时干=晚辈/事体）；② 专用事类法（测什么用什么符号）；③ 年命定位法（**大事看年命，小事看日干**——婚姻、事业、生死、升学，年命为君、日干为臣）。

| 事项 | 核心用神 | 辅助用神 | 速断要点 |
| --- | --- | --- | --- |
| **自身** | 日干 / 年命 | 值符 | 日干旺 + 吉门吉星 = 顺 |
| **事业求职** | 开门 | 年干、值符、戊 | 开门生日干 = 事业顺；值符生扶 = 有贵人 |
| **求财** | 戊（本金）、生门（利润） | 日干、白虎 | 生门生日干 = 盈利；白虎临 = 防破财 |
| **婚姻感情** | 乙（女）、庚（男）、六合 | 日干、年命、丙丁 | 乙庚相生 + 六合旺 = 婚稳；丙丁 = 第三方 |
| **健康** | 天芮星（病）、日干（人） | 天心、乙丙丁（医药） | 天芮休囚 = 病轻；日干旺相 = 抵抗力强 |
| **官司** | 惊门、景门 | 白虎、值符、开门 | 开门生值符 = 原告胜；景门旺 = 诉状有理 |
| **出行** | 日干、开门 | 九天、马星、伤门 | 开门临日干 = 利出行；九地宜留守 |
| **学业考试** | 丁奇、天辅 | 景门、值符 | 丁 + 天辅旺 = 成绩好 |
| **失物/走失** | 时干 | 玄武、杜门 | 时干旺可寻；玄武主被盗 |
| **合作合伙** | 六合 | 日干（我）、时干（对方） | 六合旺 + 日时相生 = 可成 |

> **用神铁律**：一卦不超过 3 个核心用神，多则乱、杂则偏。抓最关键 1~2 个即可。

吉门吉星 + 吉格 + 生旺 + 内盘 = 大吉；凶门凶星 + 凶格 + 克泄 + 外盘 = 大凶；半吉半凶则看组合与旺衰权衡。

### 5_4 断局禁忌（不诚不占，妄断招祸）

1. **不诚不占**：心不诚、意念不专，占则不准。
2. **不渎不占**：同一件事反复起局，越占越乱。
3. **不邪不占**：违法乱纪、损人利己之事不可占。
4. **不妄断**：拿不准的事不说死，留有余地，不危言耸听。

## 板块6 · 实操演练：拿一个真实时间完整走一遍

**时间**：2022 年 3 月 9 日 20:15（公历）
**四柱**：壬寅年、癸卯月、辛酉日、戊戌时

**① 辨阴阳**：3 月 9 日在冬至—夏至之间 → **阳遁**。

**② 定局数**（用简化公式校验）：(年支寅=3 + 月数 2 + 日数 7 + 时支戌=11) ÷ 9 = 23 ÷ 9 余 5 → **阳遁五局**。

**③ 布地盘**：阳遁顺排，"戊己庚辛壬癸丁丙乙"从五宫起。戊落中五寄坤二，依次顺排（中五无门无神，符号皆寄坤二）。

**④ 找旬首**：戊戌时 → **甲午旬** → 旬首为**甲午辛**。

**⑤ 定值符值使**：地盘辛落**艮八宫** → 艮八本位星**天任星**= 值符，本位门**生门**= 值使。

**⑥ 排天盘**：时干为"戊"，戊在地盘落坤宫（寄二）→ 值符天任星落坤二，其余九星顺时针跟随。

**⑦ 排人盘**：值使生门随时支转。甲午旬内从艮八起算，阳遁顺数至戊戌时所在宫（震三）→ 值使生门落震三，其余七门顺时针对齐。

**⑧ 排神盘**：阳遁顺时针，值符落坤二 → 螣蛇、太阴、六合……依次顺排。

**⑨ 标重点**：甲午旬 → **辰巳空（巽宫）**；戌时（寅午戌马在坤）→ **马星在坤宫**。

> 最终结果：**阳遁五局 | 值符天任星 | 值使生门 | 空亡巽宫 | 马星坤宫**。

实战中建议直接用排盘软件生成，再按上述逻辑逐条核对——**看懂逻辑比手算更重要**。

## 板块7 · 延伸干货：把知识变成能力

### 7_1 转盘 vs 飞盘：核心差异一览

| 维度 | 转盘（新手推荐） | 飞盘（高阶） |
| --- | --- | --- |
| 九星排布 | 顺时针转盘，天禽寄坤二 | 按宫位数字飞，天禽独立落宫 |
| 八门排布 | 顺时针转盘 | 阳顺阴逆飞布 |
| 八神 | 八神 | 九神（加太常） |
| 定局逻辑 | 节气定局、符头定元（完全一致） | 同左 |

> 记住：**从定时开始直到取符取使、定符使宫位的步骤，转盘与飞盘完全一样；差异只在排盘环节。**

### 7_2 定局法的三种口径

地球公转 365.24 天，奇门 360 天演 72 局，余下约 5.24 天用以下方法处理：

+ **置闰法（超神接气）**：集中处理，用符头（甲己）对齐节气。
+ **拆补法（主流推荐）**：分散处理，直接用实际万年历节气为准，符头定上中下元。**新手首选拆补法。**
+ **茅山法（无闰法）**：前 60 时辰上元、中 60 时辰中元、之后下元，不用符头。

### 7_3 常见疑问

+ **Q：用出生时间还是求测时间？** A：终身局用生辰，具体事用**求测时刻**。建议先记对方询问的那一刻。
+ **Q：伏吟反吟怎么看？** A：伏吟 = 原地打转、宜守不宜动；反吟 = 反复变动、利先发制人。
+ **Q：要不要学化解、改运？** A：**入门阶段不要。** 先把预测逻辑吃透。

## 板块8 · 结语：一张盘的边界

奇门遁甲最迷人的地方，在于它把"天时地利人和"压缩成了一张可推演的图。**但它不是万能的答案，而是一种训练有素的思考方式**——训练你同时观察时间、空间、人事与格局，并给出有依据的判断。

入门的真正标志，不是背下多少口诀，而是能对着一张盘，清晰地说出三句话：

1. **用神在哪里、旺不旺；**
2. **它和我（日干）是什么关系；**
3. **落到具体这件事上，我该往哪个方向、在什么时候行动。**

把这三句话说清楚，你就已经跨过了"入门"这条线。剩下的，交给日复一日的实盘打磨。
