## 板块1 · 导言：这本书真正在卖什么

序文里有一句被多数注本轻轻放过的话：

> "是书之刻，言归于正理……皆足以前民用而辅易道之所未备。至于书符诵咒，似非正道，概从略焉。"

这句话决定了全书的性格。**"前民用"三字是核心**：它是写给要做事的人看的，所以凡是无法落地的部分（符咒、神秘主义操作）一律删去，凡是"占某事"的具体条目则铺到极致。这也解释了书名中"元灵"二字的真实指向——**不是玄灵感应，而是元初、灵验，即"从根本原理到实际应验"**。

全书有一条清晰的分工链，理解这条链就不会在 133 种占法里迷路：

| 层级 | 卷次 | 它解决的真正问题 |
| --- | --- | --- |
| 原理层 | 卷一 奇门起例 | 盘从哪来、怎么定局、用神怎么取 |
| 符号层 | 卷二 | 八门、九星、十干、九遁、天盘加地盘各自说什么 |
| 速断层 | 卷三 | 不用排盘的"捷径"口诀（九星克应、中宫值日） |
| 应用层 | 卷四—二十四 | 133 种分类占验，每条都是"问题 → 符号 → 结论" |

**一个关键提醒**：后世很多"奇门速成课"把《元灵经》当成歌诀抄本，只背卷三的"门中逢一白……"。这是**只学速断、不学原理**，一旦遇到歌诀没覆盖的问题就完全无法迁移。正确顺序必须反过来：**先卷一、卷二，卷三才是提速工具。**

## 板块2 · 第一部分 原理层：奇门不是算命，是一张"时空状态表"

### 2_1 先破除一个误解：局数 = 甲子戊落宫数

全书的地基是洛书九宫与节气。原文的根脉在《烟波钓叟歌》开篇：

> "先须掌上排九宫，纵横十五在其中。次将八卦论八节，一气统三为正宗。"

"纵横十五"是洛书的校验和（横竖斜皆 15），也是排盘的手算自检工具——**排完地盘，九宫数字之和若不为 15，说明排错了**。这是卷一"奇门起例"里最容易被当成废话、实则最实用的细节。

节气与八卦的对应关系（即"奇门节气八卦图"）是全书的时轴：

| 八卦 | 节气组 | 阴阳遁归属 |
| --- | --- | --- |
| 坎 | 冬至、小寒、大寒 | 阳遁起点 |
| 艮 | 立春、雨水、惊蛰 | 阳遁 |
| 震 | 春分、清明、谷雨 | 阳遁 |
| 巽 | 立夏、小满、芒种 | 阳遁 |
| 离 | 夏至、小暑、大暑 | 阴遁起点 |
| 坤 | 立秋、处暑、白露 | 阴遁 |
| 兑 | 秋分、寒露、霜降 | 阴遁 |
| 乾 | 立冬、小雪、大雪 | 阴遁 |

口诀只有八个字，但必须刻进手感：**冬阳夏阴，顺阳逆阴**。

> **实操含义**：冬至到夏至用阳遁（三奇六仪顺布），夏至到冬至用阴遁（逆布）。这不是"吉凶"的区分，而是**天体运行方向在术数模型里的投射**。很多人断错局的第一个原因，就是节气边界没判准——**一定要用节气，不要用农历月份**。

### 2_2 一千八十局如何压缩成十八局

原文的叙述逻辑是"删减法"：

> 黄帝始制一千八十局 → 姜太公删为七十二局 → 张良定为十八局（阳九、阴九）。

它的数学本质是**去重**：一年 360 天 × 12 时辰 = 4320 局，因四时分判存在四倍重复，层层约简至 18 局。

**这一处是全书最重要的"元认知"**：奇门不是无限随机的，它是**有限局数的循环查表**。所以：

+ 同一节气、同一元、同一时辰 → 局数必然相同；
+ 所谓"断卦经验"，大部分是**对固定局型的记忆与归类的熟练度**；
+ 因此"多断、多验、多记局"的价值，远高于空谈"灵感"。

**可落地建议**：建立自己的"局型卡"。每断一局，记录 `[节气-元-时辰] → 局数 → 用神落宫 → 生克 → 实际结果`。积到两三百张，断卦速度会质变。这是把《元灵经》"分类占验"结构内化的唯一途径。

### 2_3 三奇六仪：不是"神名"，是十天干的分工

卷一"三奇""六仪""奇仪顺逆"三条连续排列，不是偶然：

+ **甲（元帅）隐而不现**，遁于六仪之下——这就是"遁甲"二字的本义；
+ **乙、丙、丁为三奇**（日奇、月奇、星奇），是甲的辅佐；
+ **戊、己、庚、辛、壬、癸为六仪**，是甲的仪仗与阵营。

六甲与六仪的对应关系必须背熟，因为**定值符就是靠它**：

| 六甲 | 所遁六仪 |
| --- | --- |
| 甲子 | 戊 |
| 甲戌 | 己 |
| 甲申 | 庚 |
| 甲午 | 辛 |
| 甲辰 | 壬 |
| 甲寅 | 癸 |

**固定队列（永远不变）**：戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙。

> **实操含义**：排地盘时，"是哪一局就从哪一宫起戊"，然后按此队列布完九宫。阳遁顺九宫数（1→9），阴遁逆（9→1）。**这个队列记错一个位置，全盘皆错**——它值得单独抄写十遍。

### 2_4 值符与值使：全局的"开关"

> "九宫逢甲为直符，八门值使自分明。符上之门为直使，十时一位堪凭据。"

这一段是《钓叟歌》里操作性最强的一句，也是卷一"值符""值使"两条的理论来源。动作拆解如下：

1. 由**时辰**定旬首（时干支属于哪一六甲管辖）；
2. 该六甲所遁的六仪落宫 → 其本位星即为**值符**；
3. 该宫本位门即为**值使**；
4. **值符随时干**：值符落宫 = 时干所在宫；
5. **值使随时宫**：值使按时辰顺逆飞布。

**实操含义**：值符、值使是从"静态盘"到"动态盘"的桥梁，也是断局的**第一优先级**。卷二"九宫值符、值使"单列一节，用意在此——**一张盘上先找值符落宫，那里是全局能量的聚焦点**。很多断语之所以冲突，就是因为没先看值符，直接去抠某个次要宫位。

> **自检清单**：排完盘先问三件事——「1」值符在哪宫？「2」值使在哪宫？「3」值符宫与用神宫是什么关系？这三问能筛掉一半以上的错误结论。

### 2_5 用神：全书的方法论中心，也是被误读最深的地方

卷一有"定用神诀""伏身诀""先天定六亲诀"三项连续内容，**这是原书独有的结构贡献**，通行注本往往轻描淡写。

核心原则（需自己提炼，原书只给诀）：

> **先立"我"，再立"事"，再看二者关系。**

+ **日干** = 求测者本人（主体）；
+ **时干** = 所问之事（客体）；
+ **专项用神** = 事的属性（开门主事业、生门主财、天芮主病……）；
+ **年命** = 当事人出生年干，用于锁定"具体这个人"，避免只看日干被同类混淆。

所谓"六亲"，就是把日干当"我"，按五行生克推出：生我者父母、我生者子孙、克我者官鬼、我克者妻财、同我者兄弟。**这是把六爻体系接入奇门的接口**，用于人事关系类占验（卷十婚姻、卷十三词讼）极为顺手。

> **可落地建议（通用取用神表）**：

| 所问之事 | 主用神 | 辅助用神 |
| --- | --- | --- |
| 自身 | 日干 / 年命 | 时干（事之走向） |
| 财运 | 生门 + 戊（甲子戊为财星） | 日干 |
| 事业 / 官职 | 开门 | 年干、值符 |
| 婚姻 | 乙（女）庚（男）六合 | 值使门 |
| 疾病 | 天芮星 + 日干 | 死门、伤门 |
| 出行 | 日干 + 所去方之宫 | 驿马、开门 |
| 官司 | 惊门 | 天柱、白虎 |
| 失物 | 时干（失物） + 日干（失主） | 玄武、杜门 |

**这一条必须警醒**：取用神**宁可少，不可多**。初学者常犯的错是"全盘点亮"——每个符号都想解释，结果互相矛盾。正确做法是：**主用神一个，辅助用神一至两个，其余只作旁证**。原文"定用神诀"单列成节，正是在强调"**先定才能断**"。

### 2_6 定局之争：置闰与拆补，必须自己选一边

卷一"三元符头"引出的是全书最容易被卡住的技术分歧。原理差异如下：

| 维度 | 置闰法（原书主流） | 拆补法（今人常用） |
| --- | --- | --- |
| 判定优先 | 符头（甲、己日）优先 | 实际节气优先 |
| 三元结构 | 必须完整上-中-下循环 | 允许残元、拆补 |
| 误差处理 | 集中在芒种、大雪后置闰 | 分散到每个节气 |
| 判定规则 | 子午卯酉=上，寅申巳亥=中，辰戌丑未=下 | 同上，但可越过节气边界 |
| 难度 | 高（需算超神接气、时差） | 低（节气到即用） |
| 结果一致性 | 与拆补法约 70%–80% 相同 | 同上 |

原书序与"超神接气"体系一致，**主张置闰**，且明确规定：**置闰只能在芒种、大雪二节之后**，"超不过十，接不过五"，符头先到七日即当置闰。

> **可落地建议**：两条路都能走，但**不可混用**。混用会导致同一时辰排出不同局数，事后无法复盘，经验永远积累不起来。
>
> + 走**严谨传统路线**：学置闰，接受复杂度；
> + 走**实务效率路线**：选拆补，但全程一致；
> + **禁止**：平时用拆补、遇到对不上的局就临时换置闰。

无论哪种，**定局六步不可省**：定时辰干支（校正真太阳时）→ 定符头 → 定节气 → 定元（上中下）→ 定阴阳遁局 → 排地盘。

## 板块3 · 第二部分 符号层：每个符号只做一件事，组合起来才有判断

### 3_1 八门：吉凶的"门径"，但从来不是绝对的

卷二"八门值事"是全书的精华段落之一。八门各有本位宫，关键在于**它是"路径属性"，不是"结果属性"**：

| 门 | 本位 | 主事 | 原文提示的关键限制 |
| --- | --- | --- | --- |
| 开门 | 乾六 | 远行、征讨、求官 | 至震巽主口舌 |
| 休门 | 坎一 | 修造、谒贵、谋望 | 旺见富贵人，休囚见贫人或交争 |
| 生门 | 艮八 | 求财、营造、谒贵 | **不宜侵伐**（主受天刑） |
| 伤门 | 震三 | 出师、报仇、渔猎 | 逢盗贼、至坤为宫迫 |
| 杜门 | 巽四 | 隐遁、逃避、藏匿 | 逃亡难追，路逢凶人 |
| 景门 | 离九 | 选兵献策、破阵 | 远行主中道夭亡 |
| 死门 | 坤二 | 刑戮、葬吊（**只宜凶事**） | 凡遭官讼大忌出此门 |
| 惊门 | 兑七 | 启闭攻敌、擒讼 | **吉事则危，凶事则贞** |

**这一处是全卷最有价值的方法论**（原文"门中逢五黄"一段反复印证）：

> **吉凶不在门名，而在"门 + 星 + 旺衰"的组合。**

死门在旺相时可断"武臣侯伯、文昌状元"，休门在休囚时一样"人怕有灾危、财忧有得失"。**因此永远不能说"开休生三吉门，遇之百事吉"——这是歌诀的简化，不是原文的完整意思。**

> **可落地建议**：断门先看三项——「1」 门本身的属性（宜/忌什么）；「2」 所临之星（吉星扶、凶星破）；「3」 旺相休囚（得令与否）。三项合一才下结论。**单看门名下断，是新手最典型的错误。**

### 3_2 门迫与宫迫：吉事不成、凶灾尤甚的具体判据

卷二"天盘加地盘吉凶"的基础，是**门与宫的五行生克**。原文区分两种"迫"：

+ **门迫（宫制其门）**：宫克门，如吉门被迫则吉事不成；
+ **宫迫（门制其宫）**：门克宫，凶门被迫则凶灾尤甚。

常用对照（吉门被迫示例）：

+ 开门临三、四宫（乾金门克震巽木宫）
+ 休门临九宫（坎水门克离火宫）
+ 生门临一宫（艮土门克坎水宫）
+ 景门临六、七宫（离火门克乾兑金宫）

> **实操含义**：**门迫是"能量被锁死"的信号**，比单纯的凶门更值得警惕——因为凶门至少是"明的障碍"，门迫是"本来该成的路子被卡住了"。断求财、求官时，若用神落宫正好构成门迫，**先断"过程受阻"，再论其他**。这是从"天盘加地盘吉凶"表里能直接提取的高频判据。

### 3_3 九星：核心是"旺衰"，不是"吉凶标签"

九星本位与五行：

| 星 | 本位 | 五行 | 阴阳 |
| --- | --- | --- | --- |
| 天蓬 | 坎一 | 水 | 阳 |
| 天芮 | 坤二 | 土 | 阴 |
| 天冲 | 震三 | 木 | 阳 |
| 天辅 | 巽四 | 木 | 阳 |
| 天禽 | 中五 | 土 | 阳 |
| 天心 | 乾六 | 金 | 阴 |
| 天柱 | 兑七 | 金 | 阴 |
| 天任 | 艮八 | 土 | 阳 |
| 天英 | 离九 | 火 | 阴 |

原文的旺衰算法由《钓叟歌》承接，用**月令**而非年份：

> "与我同行即为相，我生之月诚为旺。废于父母休于财，囚于鬼兮真不妄。"

例：天蓬属水 → 旺于冬季（亥子月）、相于秋季（申酉月，金生水）、休于春季（木泄水）、囚于夏季（火克水，囚于鬼）。

**吉凶层级的完整表述**（《三元经》系）：

+ **上吉**：天辅、天禽、天心
+ **次吉（小吉）**：天冲、天任
+ **大凶**：天蓬、天芮
+ **小凶**：天英、天柱

**但原文紧接着给了最重要的修正**：

> **"大凶无气变为吉，小凶无气亦同之。"**

即凶星若处休囚废没（无气），凶性大幅减弱。**这意味着"天蓬 = 盗贼、天芮 = 疾病"这类标签，只在旺相时才成立；在衰位，天芮反而可断"疾病易愈"，天蓬反而可断"竞争得利"。**

> **可落地建议**：九星判断强制走两步——「1」 定旺衰（用月令，套"旺相休囚死"口诀）；「2」 再贴吉凶标签。**颠倒顺序必错**。

### 3_4 十干、九遁、天盘加地盘：卷二是"查表层"

卷二后半的"十干吉凶宜忌""九遁吉凶宜忌""天盘加地盘吉凶"三项，本质是**三张查表**，而不是需要理解的原理。实操态度应当是：

+ **十干宜忌** → 记乙、丙、丁三奇的特殊性，庚的"阻隔"属性；
+ **九遁**（天、地、人、风、云、龙、虎、鬼、神） → 卷二给定义，卷二十"烧丹""祷祀"类事项才真正用得上，**日常占验不必优先掌握**；
+ **天盘加地盘** → **这是断卦的核心武器库**，务必熟记典型格。

必须记死的几组（**吉格**）：

| 格局 | 组合 | 含义 |
| --- | --- | --- |
| 青龙返首 | 甲 + 丙（天盘甲加地盘丙） | 动作大利 |
| 飞鸟跌穴 | 丙 + 甲（天盘丙加地盘甲） | 百事吉 |
| 青龙耀明 | 甲 + 丁 | 宜谒贵求官 |
| 三奇得使 | 乙/丙/丁逢值使门 | 诸事顺遂 |

**凶格**（原文强调"百事逢之莫措手"）：

| 格局 | 组合 | 含义 |
| --- | --- | --- |
| 青龙逃走 | 乙 + 辛 | 主财失逃亡 |
| 白虎猖狂 | 辛 + 乙 | 大凶，主损失 |
| 朱雀投江 | 丁 + 癸 | 文书口舌、凡事破伤 |
| 螣蛇夭矫 | 癸 + 丁 | 虚惊不安 |

> **可落地建议**：把上表做成排盘软件的标注清单。**格局判断的优先级高于单符号**——一旦盘中出现了明确的大吉格或大凶格，结论基本可以直接落定，不必再纠结生克细节。这是《元灵经》"捷径"思想的精髓：**能靠格断的，不绕路。**

### 3_5 伏吟、反吟：两种"不办事"的全局信号

卷三"奇门捷径秘诀"与《钓叟歌》"就中伏吟为最凶"一脉相承：

+ **伏吟**：天盘与地盘相同（星不动），主**停滞、反复、宜静不宜动**；
+ **反吟**：天盘与地盘对冲（如天蓬加天英），主**急变、反复、事多不成**。

> **实操含义**：**开局先扫一眼是否伏吟/反吟，可以省掉 80% 的细部分析**。若是伏吟，结论直接指向"等、守、不要动"；若是反吟，指向"事将变、且反复"。这是最高层级的"大势判断"，应在取用神之前完成。

## 板块4 · 第三部分 速断层：卷三为什么有效，以及它的边界

### 4_1 "门中逢 X 黑/碧/绿"系列：九宫飞星断法

卷三"奇门捷径秘法"用的是**九宫数字配洛书九星**（一白贪狼、二黑巨门、三碧禄存、四绿文曲、五黄廉贞、六白武曲、七赤破军、八白左辅、九紫右弼），与卷二九星是**两套系统，不可混称**。

它的操作逻辑极其简洁：**只看"门 + 九宫飞星数"，不看完整盘**，例如：

+ "门中逢一白，天地人皆吉……死伤莫出兵，休景横逢食" → 一白所临，大体吉，但忌临死门、伤门；
+ "门中逢二黑，常见云迷日……若临劫杀宫，夜夜防盗贼" → 二黑主晦暗、失财、盗；
+ "门中逢五黄，事有喜非常……纵其死伤地，连绵庆泽长" → **五黄遇死伤反吉**，这是最反直觉的一条，也是原文被反复举证的重点。

> **边界警示（重要）**：这套口诀是**单宫断**，只能用于"来不及排全盘的场合"或"对全盘的快速校验"。它**不能替代卷一、卷二的完整分析**。网上很多教程把它当主力，属于本末倒置——歌诀是提速工具，不是地基。

### 4_2 九星克应诀：出门"几里见何人"的经验数据库

"门中见太乙（贪狼）……出门三五里，著皂辨阴阳"、"门中见摄提，百事必迟疑"……

这类口诀的**真实价值不在占卜，而在训练"象的联想"**：星 → 事件性质 → 远行所见之象（衣色、人物、动静）。它是古人的**田野记录**，用于：

+ 练习把抽象符号翻译成具象画面；
+ 作为"应验后的回溯校验"，积累自己的应期经验。

> **实操含义**：不必逐句背诵，但**要读懂它的结构**——每一段都是 `[星] → [事] → [相生/相克修正] → [远行所见之象]`。这个"星-事-象"三段式，正是卷四以后所有分类占验的母模板。

### 4_3 中宫值日九星歌诀：日维度的快速择吉

"一白太乙号贪狼，用事求谋大吉昌……五黄廉贞恐有迎，宁静安居莫出行……"

**这是对"哪一天适合做什么"的日格判断**，属择吉范畴。它的位置在卷三末尾，恰好起到**从"占验"过渡到"行动指引"**的作用——全书后二十卷的终极目的，正是给出"该不该做、何时做、往哪做"的答案。

> **可落地建议**：把此歌诀做成日历标注。每月初按"一白至九紫"排定每日值星，**只做三件事**：「1」 五黄、二黑、三碧日不做重大决策；「2」 六白、八白、一白日优先安排求财、出行、签约；「3」 七赤日防火烛、是非。**一周即可见效，是全书最容易落地的一小段。**

## 板块5 · 第四部分 应用层：133 种占法的三个"母模板"

卷四至二十四看似庞杂，实则可压缩为**三种判断模板**。学会套用，133 种条目不再需要逐条死记。

### 5_1 模板 A：气象与收成类（卷四、卷五、卷二十）

代表条目：占天时、占晴雨、占晴、占雨、占雪、占岁时丰歉、占田禾、占蝗蝻、占蚕利。

**它的方法论是"象的组合"，不是生克**：原文以九遁配云色，如"天蓬飞入艮宫来，东北乌云一朵栽"、"芮禽若也到休门，北起红黄东淡云"。

以"占晴雨"为例，规则极清晰：

| 条件 | 结论 |
| --- | --- |
| 阳门阳星飞临阳宫 + 火土星同宫 | 久晴 |
| 阴星阴门 + 水金星 + 壬癸休门，飞临阴宫，且相生沐浴 | 大雨如注 |
| 景门 + 土宿飞临 | 雨时有时无、或日中下雨 |
| 阴星阳门入阴宫 / 阴星阴门加阳宫 | 半阴半晴 |
| 壬癸 + 甲子辰日时 + 天蓬、休门 | 主有雨 |
| 水星冲合 | 当有大雨 |

**可落地建议**：这类占法**应期在"星所临之宫对应何干支"**，且"与值符近则速，远则迟"。要用的话，正确做法是**连续多日对照实际天气做校准**，把"局数-天气"做成自己的对照表——因为原书的气象结论建立在特定地域气候经验上，**不可直接套用于今天任意地区**，只宜作趋势参考。

### 5_2 模板 B：人事类（卷七至卷十九，占比最大）

代表条目：家宅、起造、婚姻、胎孕、生产、疾病、词讼、出行、行人、求财、贸易。

**方法论核心是"专项用神 + 生克 + 旺衰"**，即第一部分 1.5 的用神表。这里以三条高频条目演示如何"拆"原文：

#### 5_2_1 占求财（卷十六）—— 原文最详尽的条目之一

> "分体用以生门主之，以生门所落之宫向为体，以生门天盘所乘之星为用。用生体则吉，体生用则不吉。"

拆解成可执行步骤：

1. **取用神**：生门落宫（财之"体"）+ 生门天盘所乘之星（财之"用"）+ 甲子戊（财星）；
2. **判生克**：用生体 = 吉（财来就我）；体生用 = 不吉（我去求财，费力）；
3. **看旺衰**：体旺用衰 → 难被克伤，无大害；用旺体衰 → 体难克用，不为大吉；
4. **查格局**：上下二盘吉格吉星 → 所求如意；有一不吉 → 所求减半；休囚 → 全无；
5. **定应期**：时干在地盘为"内"（快），在外为"外"（慢，半年以上）；甲子戊与生门同宫 + 合吉门 → 得财极速；伏吟、反吟 → 反复不得。

> **实操含义**：这是全书**最完整的一条方法论示范**。它的价值不在于"能不能算准财运"，而在于给出了一个可复用的判断链：**用神 → 体用生克 → 旺衰 → 格局 → 应期**。其余 132 条占法，基本都是这条链在不同场景的特例。

#### 5_2_2 占疾病（卷十二）

> "以天芮为病神，以生死二门看。再审病者本命年干落宫，得生门不死，死门难愈。"

步骤：

1. 天芮星 = 病（性质、部位）；
2. 日干 / 年命 = 病人；
3. **生门 = 不死，死门 = 难愈**（这是原文的硬判据）；
4. 年干休囚废没 + 凶星凶格 → 大凶；
5. **愈期 = 天芮废没之月**；
6. 凶星加奇门、上下二干相救 → "死中求活"，可愈。

**眼疾**专看离宫（离为目）；**寿数**则用天冲（生气）与死门，以九宫每宫十年为率逆推。

> **必须声明**：疾病判断关系重大，此条**仅作古籍结构分析，绝不可用于实际健康决策**。身体问题一律以现代医学诊断为准。

#### 5_2_3 占婚姻（卷十）

取用神：乙奇（女）、庚（男）、六合（媒合/关系状态）、值使门（关系进展）。

+ 乙庚相生相合 → 可成；
+ 乙庚相冲相克 → 难成；
+ 六合生日干 → 有人促成；
+ 乙或庚入墓、空亡 → 感情不实或阻滞。

> **可落地建议**：人事类占验的**统一断法**（四步，顺序不可乱）：
>
> 「1」 **审局**（伏吟/反吟？值符值使？马星/空亡？）

↓
「2」 **立用神**（主用神一个 + 辅助一两个）
↓
「3」 **观门星**（吉门吉星 + 旺衰 → 大势）
↓
「4」 **查生克 + 合格局**（定最终结果与应期）

> 终断 = 用神旺衰 × 门星吉凶 × 生克关系 × 特殊格局。**任何一步都不能跳过，尤其是「1」**——开局的大势判断一旦错过，后面越分析越偏。

### 5_3 模板 C：兵占与权谋类（卷二十四）

代表条目：占贼盗敌兵去来、虚实、伏兵、攻城、守城、援兵、胜败、闻报虚实、行军无水、行迷路。

这是奇门最古老的用武之地，原文结合了大量阵法与神煞（五符造天关、三胜宫、五不击、五阳时/五阴时等）。

**关键区分（极易误用）**：

> **五阳时为客（先举、主动），五阴时为主（后动、待敌）。**

甲乙丙丁戊为阳时，己庚辛壬癸为阴时——这不是吉凶，而是**先手后手的策略选择**。配合"三胜宫"（天乙宫、九天宫、生门宫）与"五不击"，构成的是一套**战场决策模型**：占的是"此时该主动还是该等待"。

> **实操含义（现代转译）**：这套思维**最适合用于竞争博弈类决策**——谈判、竞标、市场进入时机。核心动作是：「1」 判阳时/阴时（主动或等待）；「2」 找生门方（最优发力方向）；「3」 避五不击（不碰的方位与时机）。**把"方位"转译为"发力点"，把"出兵"转译为"采取行动"，古籍的博弈结构完全可以迁移到现代决策中。**

## 板块6 · 第五部分 实操训练方案：把二十四卷压缩成 30 天

### 6_1 阶段一：打地基（第 1–7 天）

**每日任务**：

+ 手抄洛书九宫一遍，验算纵横十五；
+ 背诵三奇六仪固定队列（戊己庚辛壬癸丁丙乙）；
+ 背诵六甲遁六仪对应表；
+ 默写节气-八卦对应（坎冬至、离夏至……）。

**里程碑**：不看资料，能说出"阳七局"意味着戊从哪一宫起、顺逆如何。

### 6_2 阶段二：能排盘（第 8–14 天）

+ 选定一种定局法（置闰或拆补），**全程不改**；
+ 用手排 + 排盘软件双轨对照，**连续 7 天，每天 3 局**；
+ 重点练：值符随时干、值使随时宫、八神阳顺阴逆。

**里程碑**：手排结果与软件一致率 > 90%。

### 6_3 阶段三：会断局（第 15–23 天）

按"第四部分模板 B"的四步断法，每天精断 1 局，写断语 + 后续验证。**优先练三类高频事项**：求财（生门/戊）、事业（开门）、人际（六合/乙庚）。

**必须养成的三个习惯**：

1. **先扫伏吟/反吟**，再取用神；
2. **用神宁少勿多**，主用神只取一个；
3. **每局写"应期"**，事后回填结果——这是准确率提升的唯一真实来源。

### 6_4 阶段四：提速（第 24–30 天）

+ 引入卷三"九星克应""门中逢 X"作快速校验；
+ 建立**个人歌诀库**：只保留自己验证过的 20–30 条，删掉不准的；
+ 尝试盲断（只看关键宫位下结论），再展开全盘点校。

### 6_5 避坑清单（新手高频错误）

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 节气边界用农历月 | 局数判错 | 严格用节气 |
| 混用置闰与拆补 | 同局不同盘，无法复盘 | 选定一种，全程一致 |
| 单看八门吉凶 | 结论绝对化 | 门 + 星 + 旺衰三者合断 |
| 凶星一律断凶 | 忽略"无气变吉" | 先用月令定旺衰 |
| 用神取太多 | 符号互相矛盾 | 主用神一个，辅助 1–2 个 |
| 忽略门迫/宫迫 | 漏掉"成事被卡" | 断前先查生克关系 |
| 只看吉格不看大势 | 见吉格就断吉 | 先伏吟/反吟，再论格局 |
| 不记应期与结果 | 准确率永远不提升 | 每局必写，事后回填 |

## 板块7 · 第六部分 批判性结论：这本书能给你什么，不能给你什么

### 7_1 三点真正的价值

1. **结构价值最高**。二十四卷把"原理—符号—速断—应用"四层拆得清清楚楚，是奇门领域**最完整的分类占验体系**。学奇门若只读一本应用书，应读它而非零散歌诀。
2. **"前民用"的实用主义**。删符咒、重条目，使得全书可以**直接对应到具体决策**（该不该出行、何时得财、能不能成）。这种"问题驱动"的组织方式，本身就是方法论遗产。
3. **方法论可迁移**。体用生克、旺衰优先、先大势后细节、局型积累——这些**完全脱离术数语境也能用于一般决策分析**（先判趋势，再抠细节；先定主体，再看关系）。

### 7_2 四点必须清醒认识

1. **它是 19 世纪的文本，不是上古秘传**。作者许松如是清人，"删符咒"本身是**理性化整理的结果**，不必给它套上"黄帝—张良"的神秘谱系光环。
2. **分类占验建立在古代社会结构与气候经验上**。卷五的田禾、蚕利，卷二十四的兵占，其**象的对应关系与现代生活并不自动适配**，需要自己重新校准，不能直接套用结论。
3. **可验证性薄弱**。现有资料未提供系统性的对照验证记录，**任何"断语"都应视为待验证假设，而非确定性结论**。这也是为什么本书的训练方案把"写应期、回填结果"放在核心位置——它要求你用自己的数据说话。
4. **健康、法律、财务等重大决策，绝不可用占验替代专业判断**。古籍的结构与方法可学，**具体结论不可用于高风险场景**。

### 7_3 全书重构后的逻辑主线（一句话版）

> **用洛书与节气把时空编号（卷一）→ 用门、星、干、遁给每个时空点贴上属性（卷二）→ 用歌诀与格局实现快速查表（卷三）→ 把这套查表系统套进 133 个具体问题（卷四至二十四）→ 最终输出"该不该做、何时做、往哪做"的行动答案。**

理解到这一层，你就不再是在"读奇门"，而是在**读一套决策分析框架的古典实现**。

## 板块9 · 附录 B：核心原文摘录与白话拆解（按书序）

**「1」 序**

> "遁甲之说，论者谓始于黄帝，删于吕望、张良……至于书符诵咒，似非正道，概从略焉。"

+ 白话：遁甲一术源流久远，但本书只取可通的动静、吉凶、生克、制伏之理，符咒一概不录。
+ **关键点**：确立"实用主义"选材标准。

**「2」 卷一引《烟波钓叟歌》**

> "先须掌上排九宫，纵横十五在其中。次将八卦论八节，一气统三为正宗。阴阳二遁分顺逆，一气三元人莫测。五日都来换一元，超神接气为准则。"

+ 白话：先排洛书九宫（自校验用），再按八节分阴阳遁，每节气统三元（上中下），五日换一元，超神接气为定局准则。
+ **关键点**：定局六步的总纲。

> "九宫逢甲为直符，八门值使自分明。符上之门为直使，十时一位堪凭据。直符常遣加时干，直使逆顺遁宫去。"

+ 白话：逢甲的宫位定值符，符上之门为值使；值符随时干落宫，值使按十时一易之规顺逆飞布。
+ **关键点**：动盘的桥。

> "六甲元号六仪名，三奇即是乙丙丁。阳遁顺仪奇逆布，阴遁逆仪奇顺行。"

+ 白话：六甲隐于六仪之下，三奇为乙丙丁；阳遁六仪顺布、三奇逆布，阴遁反之。
+ **关键点**：排布方向的唯一依据。

> "吉门偶尔合三奇，值此须云百事宜。更合从旁加检点，余宫不可有微疵。"

+ 白话：吉门偶合三奇固佳，但仍须旁查其余宫位，不可有细微瑕疵。
+ **关键点**：**反对单看吉门**——这与卷二"门星合断"完全一致，是全书的判断基调。

> "三奇得使诚堪使，六甲遇之非小补。乙逢犬马丙鼠猴，六丁玉女骑龙虎。"

+ 白话：三奇得使（乙逢犬马、丙逢鼠猴、丁逢龙虎）为大吉；六甲遇之亦有大补。
+ **关键点**：三奇得使的应期指向（犬马=戌午，鼠猴=子申，龙虎=辰寅）。

> "三为生气五为死，胜在三兮衰在五。能识游三避五时，造化真机须记取。"

+ 白话：三为生气、五为死气，宜趋三避五。
+ **关键点**：择吉的方位/时序硬规则。

> "就中伏吟为最凶，天蓬加着地天蓬。天蓬若到天英上，须知即是返吟宫。"

+ 白话：伏吟最凶（如天蓬加本宫天蓬），天蓬到天英为返吟。
+ **关键点**：全局信号优先。

**「3」 卷二 八门值事（节选）**

> "坎为一气始生之地……为正北一白，有休门主之。阳气升布，万物滋生。修造吉，治兵、行军、谋望、远行、谒贵皆为亨道。阳日出此门得逢阳贵，阴日出此门得逢阴贵……若到离宫，是上克其下，谓之大凶迫。"

+ 白话：休门主滋养、谒贵，但至离宫则为宫迫（大凶）。
+ **关键点**：同一门的吉凶**随所临之宫而反转**。

> "震居兰台之宫……为东方三碧，有伤门主之。宜出师执擒报仇、讨叛、渔猎……如崇祯辛巳四月十八日……时癸亥日亥时，在立夏下元，阳七局……得冲伤门为星，宜出东方，果如所言，夜大破之。"

+ 白话：伤门宜讨叛用兵，并附实战例证。
+ **关键点**：**原文大量使用"事验"佐证**，这是它区别于纯理论书的根本特征——也说明它本就是拿来对照验证的。

**「4」 卷三 九星克应诀（节选）**

> "门中见摄提，百事必迟疑。相生犹自可，相克有灾危。远行多不利，耕种损牛犁。死门若相遇，老幼哭悲啼。"

+ 白话：摄提（二黑巨门类）主迟疑阻滞，逢相生尚可，逢相克则灾；若叠加死门，主凶丧。
+ **关键点**：克应诀的结构 = 星 + 事 + 生克修正 + 所见之象。

**「5」 卷十六 占求财（核心段，详见 4.2）**

> "凡占求财，其说不一。分体用以生门主之，以生门所落之宫向为体，以生门天盘所乘之星为用。用生体则吉，体生用则不吉……大抵专看生门所落之宫……吉格吉星，所求如意，有一不吉，所求仅半。休囚不吉，所求全无。"

+ **关键点**：这是全书方法论最完整的示范段，**务必逐句拆解**。

**「6」 卷十二 占疾病（详见 4.2）**

> "占疾病以天芮为病神，以生死二门看。再审病者本命年干落宫，得生门不死，死门难愈。若年干休囚废没，再有凶星、凶格，大凶。"
