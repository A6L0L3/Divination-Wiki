## 板块2 · 为什么这本书值得"重构"着读

### 2_1 它的真正价值：一套可复用的决策模型

奇门遁甲被誉为"三式之最""帝王之学"，本质是一套融合天文、历法、阴阳、五行、八卦的**时空决策模型**。它把"天、地、人、神"四个维度装进一个九宫格里，让你在面对复杂局面时，能同时看到：

+ **天时**（九星）— 这股势能是顺风还是逆风
+ **地利**（九宫、三奇六仪）— 哪个方位、哪个领域有利
+ **人和**（八门）— 此刻该进、该守、该隐
+ **隐态**（八神）— 有无贵人、暗扰、欺骗

《秘笈大全》的价值不在"故事"，而在"读者能用它做什么"。全书从源流、起局、格局，一路落到数百种分类占断场景，是一套**"从规则到模板"的完备系统**——它甚至把抽象规则固化为 72 种可直接套用的军中验证模板（《七十二局军中应验神符经》），这正是"大全"二字的含金量。

### 2_2 全书结构的三个关键转折点

理解全书，抓住三个**知识架构的里程碑**即可，其余都是它们的展开：

| 节点 | 位置 | 作用 | 本质 |
| --- | --- | --- | --- |
| **理论奠基** | 总序 + 《烟波钓叟歌》 | 确立传承谱系与宇宙观 | 合法性的起点 |
| **功能性跃升** | 九遁体系（约卷六/卷七） | 从基础规则到高级应用 | 连接理论与实战的枢纽 |
| **实践闭环** | 七十二局经（末卷） | 72 种可套用作战模板 | 体系的完备收官 |

> **阅读策略**：入门者不必从头死磕。建议"总序定世界观 → 起局法则练手 → 九遁与吉凶格局吃透 → 再回到分类占断找对应场景"。

## 板块3 · 原文核心：四个纲领性文本的解读

### 3_1 《总序》：正本清源的宇宙观

原文以"黄帝战蚩尤于涿鹿，梦天神授符，而命风后演就奇门"开篇，把传承谱系定位为 **黄帝 → 姜太公 → 张良 → 诸葛亮**，确立其"天府石室之秘文，运筹决胜之神算"的神圣性。

**重点不在神话，而在立意**："察天地四时、辅国安危、辨吉凶祸福"——奇门从来不是用来算命消遣的，它是**辅国安危、临机决策**的工具。这一立意决定了它"重实用、轻玄谈"的取向。

### 3_2 《烟波钓叟歌》：一首歌记住整套系统

这是全书的"总纲歌诀"，几乎每一句都是操作指令。核心句解读：

+ **"阴阳顺逆妙难穷，二至还乡一九宫"**：冬至起阳遁从坎一宫（一局）出发，夏至起阴遁从离九宫出发。**"二至"是整套术数的总开关**——冬至后阳遁顺排，夏至后阴遁逆排。
+ **"认取九宫分九星，八门又逐九宫行"**：九星、八门都依托九宫运转，宫是骨架，星门是血肉。
+ **"九宫逢甲为值符，八门值使自分明"**：逢"甲"的宫位定出"值符、值使"，这是整盘动态的转轴。
+ **"天乙之神所在宫，大将宜居击对冲"**：值符所临之宫为吉，宜居、宜击对冲之方——这是兵占的总原则。

### 3_3 《十干尅应诀》：宫中两个天干"对照"成格

地盘宫中有一个奇仪，天盘飞过来又一个天干，上下一照，便形成格局。**这是奇门判断"吉凶细节"的核心技术**：

+ 同类相加（如戊加戊、壬加壬）→ **伏吟**，凡事闭塞，静守为吉。
+ 特定组合 → 有专属名称与断语（见后文格局表）。

掌握尅应诀，等于拿到了"从盘面到断语"的字典。

### 3_4 《九遁变化法》：从占断到"主动运用"

这是全书最具操作性的部分。九遁不是"预测"，而是**告诉你满足什么条件时，你可以主动做什么**。核心逻辑是：**三吉门（开、休、生）+ 三奇（乙、丙、丁）+ 特定星/神组合 = 某种"遁"**，据此可以择方、择时、布局。

| 遁法 | 组合条件（简化） | 主要用途 |
| --- | --- | --- |
| **天遁** | 开休生 + 丙奇下临丁奇 | 遁迹隐形、文书奏对、呼风唤雨 |
| **地遁** | 开休生 + 乙奇下临六合/九地/太阴 | 设伏、谋为、起造、藏匿 |
| **人遁** | 开休生 + 三奇下临六合 | 和合、财喜、词讼得理 |
| **风遁** | 开休生 + 乙奇临六辛落巽宫 | 祭风、火攻 |
| **云遁** | 开休生 + 乙奇临六辛 | 祈云、求雨 |
| **龙遁** | 开休生 + 天心/壬/六合临坎宫 | 祈雨、水战 |
| **虎遁** | 开门 + 庚下临兑宫 | 祭风、镇邪、攻险 |
| **神遁** | 开门 + 乙奇合心/禽临九天 | 施计、祭祀 |
| **鬼遁** | 休门 + 天辅/六辛下临丁奇 | 探路、间谍、布谣言 |

> **实操要点**：九遁是"有条件的吉"。一旦乘上白虎、玄武，则"主灾病、损失"，细事不得全吉。**所以判断时永远要先看"有没有凶神叠加"，再看格局名称。**

## 板块5 · 可落地的起局断局标准流程（七步法）

参考现代教程的标准化步骤，我把全书起局法则重构为一套**"照着走就不会乱"的七步流程**。不管问什么事，都通用。

### 5_1 先定时间、辨阴阳（第 0~1 步）

+ 把阳历"年月日时"换算成干支历（万年历或《五鼠遁》《五虎遁》歌诀）。
+ **判阴阳遁**：冬至后 → 阳遁顺排；夏至后 → 阴遁逆排。
+ **分三元**：每个节气分上、中、下三元（每元 5 天），结合符头定局数。
+ **核心原则**：时辰取"正时"，天机发于动，**不可刻意挑选时辰**。

### 5_2 第 1 步：排地盘，布三奇六仪

按"**戊→己→庚→辛→壬→癸→丁→丙→乙**"固定顺序，"几局就从几宫起戊"，阳顺阴逆填完九宫。

> 例：阳遁 1 局，从坎一宫起戊，顺排至离九宫。地盘恒定不动，是整个局的空间基准。

### 5_3 第 2 步：定值符星、值使门

+ 按时辰干支查**旬首**（六十甲子分六旬，每旬以甲开头）。
+ 旬首所落地盘宫的**九星 = 值符**，**八门 = 值使**。

> 例：旬首在地盘巽四宫，巽宫本位天辅星、杜门 → 值符天辅、值使杜门。

### 5_4 第 3 步：转天盘（九星）

**值符随时干**：把值符星加到"地盘时干所在宫"，其余九星依次顺排。天盘干随星走。

### 5_5 第 4 步：转人盘（八门）

**值使随时支**：把值使门从本宫起算，按阳顺阴逆数到"用时地支"所在宫，其余七门依次排开。

### 5_6 第 5 步：排神盘（八神）

八神阳遁顺排、阴遁逆排，**小值符永远追随大值符**（从值符落宫开始排）。八神只做吉凶加成，不参与五行生克。

### 5_7 第 6 步：定用神，断吉凶

按"由大到小、由宏观到细节"的顺序：

1. **看日干旺衰** → 定自身底气
2. **找对应用神** → 定事情的有无、虚实
3. **看生克关系** → 用神生日干（易成）、日干生用神（要付出）、相克（难成）
4. **看格局吉凶** → 吉格、凶格、伏吟、反吟，定顺不顺
5. **看星门神煞** → 补充细节与风险点
6. **对应事项** → 给出吉凶结论

### 5_8 第 7 步：出结论，给指引（关键！）

**把结果落地成可执行建议，而不只说吉凶**：

+ **能成的事**：利在何方、吉在何时、怎么借力、注意什么
+ **不成的事**：问题在哪、阻碍是什么、要不要等、怎么规避
+ **两难的事**：对比不同方向利弊，给出最优建议

> **入门总诀**：阴阳二遁分顺逆，三奇六仪地盘立；值符值使随时转，九星八门布人天；八神加临辨吉凶，用神先把日干牵。

### 5_9 起局三大易错点

① 干支换算精准（错则全盘皆错）；② 阴阳遁、局数、顺逆不混淆；③ 值符、值使定位无偏差。把控这三点，出错率直降八成。

## 板块6 · 从占断到主动：主客论与"用神"取用

### 6_1 主客论：先分清"谁动"

《卷七·主客占验论》是全书的判断总纲，也是最容易被忽略的精华：

> "奇门之应验，时有先后，应有主客，以彼此人我而推之。大凡**奇神应物之初，星应事之中，门应事之末**。"

**主客判定**：我去寻人 → 我为客他为主；他来寻我 → 他为客我为主。判断时**看天盘（客/动方）与地盘（主/静方）的生克**：

+ 他生我 → 益在我；我生他 → 益在他
+ 他克我 → 损在我；我克他 → 损在他
+ 比和 → 无损益

**不同事项的首重不同**（这是原书最实用的"权重"思想）：

| 事项 | 首重 | 理由 |
| --- | --- | --- |
| 占吉凶 | **九星**（天盘） | 吉凶由天 |
| 出行趋避 | **八门**（人盘） | 吉凶由自取 |
| 造葬迁移 | **九宫**（地盘） | 由地而起 |

### 6_2 用神速查：不同问题取什么

| 事项 | 核心用神 | 辅助用神 |
| --- | --- | --- |
| 求财、合作 | 生门 | 日干、月干、甲子戊（资本） |
| 事业、求职、开业 | 开门 | 日干、值符（贵人） |
| 考试、文书 | 景门、天辅 | 日干 |
| 疾病 | 天芮星 | 日干、时干 |
| 婚姻 | 六合、日干/时干（双方） | 休门、生门 |
| 诉讼 | 开门（法官）、惊门（律师） | 六合（证据）、景门（诉状） |
| 出行、寻人 | 时干、所往之方 | 日干 |
| 兵战 | 值符（主帅）、天冲（武士）、六庚（攻方）、天禽（守方） | — |

## 板块7 · 吉凶格局：必须记牢的核心"字典"

原书卷三至卷六铺陈了数十种格局，此处提炼**最高频、最实用**的一组，配合判断口诀：

### 7_1 常用吉格

| 格局 | 组合 | 含义 |
| --- | --- | --- |
| **青龙回首** | 戊加丙（甲子戊加丙奇） | 大吉，谋事可成 |
| **飞鸟跌穴** | 丙加戊 | 大吉，百事亨通 |
| **三奇得使** | 乙/丙/丁临值符、三吉门 | 得贵人助力 |
| **玉女守门** | 丁奇临值使门 | 宜隐私、守静 |

### 7_2 常用凶格（务必警惕）

| 格局 | 组合 | 含义 |
| --- | --- | --- |
| **伏吟** | 干加同类（戊加戊等） | 闭塞，静守为吉，动则不利 |
| **反吟** | 对冲加临 | 反复、事多变动 |
| **玄武偷营** | 壬加丁等（玄武临生门） | **主欺诈、偷盗，勿借款** |
| **太白擒蛇** | 壬加庚 | 事难进展 |
| **青龙逃走 / 白虎猖狂** | 庚加乙 / 辛加乙等 | 主损失、破败 |

### 7_3 两个"全局性"判据

+ **门宫关系**：门克宫吉，宫克门凶（伤人事故凶）。
+ **星门关系**：星克门吉，门克星凶。
+ **空亡与马星**：空亡主"不实、落空"；马星主"动、快、远行"。

> **口诀化记忆**：先看伏吟反吟（全局顺不顺），再看门宫星门（受力方向），最后看具体格局（细节吉凶）。

## 板块8 · 实战案例：把流程跑一遍

### 8_1 案例 A：合作求财（生门 + 日干）

**问题**：做建材的，明天去和装修公司谈供货合作，能成吗？

**步骤拆解**：

1. **定用神**：核心用神 = 生门（合作求财）；辅助 = 日干（自己）、月干（对方）、甲子戊（货款）。
2. **看旺衰**（月令 + 日令 + 宫位）：
    - 生门属土 → 落艮宫（土宫，得地利），综合"衰中带旺"。
    - 日干落本宫，看是否被克。
3. **看生克定趋势**：核心逻辑——**核心用神生日干则易成**；日干生用神则要付出代价；相克则难成。
4. **看格局与神**：临值符 → 有贵人，能谈成；临螣蛇 → 心里有顾虑；临六合 → 对方有诚意。
5. **给指引**：谈得成，但条件对自己不利（用神克日干），对方会压价。**运筹建议**：守住底线价格，用"分期结算"化解风险，借值符贵人位（西北乾方）争取话语权。

### 8_2 案例 B：跳槽决策（四维坐标法）

**问题**：这次跳槽合适吗？目标公司在正北方。

1. **看位置（地盘）**：正北 → 坎宫。
2. **看人事（人盘）**：坎宫对应休门 → "休息期"，适合静养积蓄，**不适合强行变动**。
3. **看天时（天盘）**：坎宫本位天蓬 → 冒险、风险，不确定性偏高。
4. **看外力（神盘）**：若落玄武 → 欺骗、虚隐，提示信息不透明，**需多核实（背调、问清楚薪酬条款）**。
5. **结论**：不是好时机，**建议先不动，或拿到书面 offer、核实清楚后再定**。

> **案例 B 的精髓**：只用"四张表"就做出决策，这正是奇门作为**"决策工具"而非"算命术"**的价值——它帮你把模糊的犹豫，拆成四个可分析的维度。

### 8_3 案例 C：民间借贷（避坑型）

**场景**：朋友借款承诺高息。**断局关键**：生门（本金安全）+ 玄武（欺诈）+ 时干（借款）。若**玄武临生门 + 凶格（如"壬加丁"玄武偷营）**，则主"有去无回"。

**运筹**：以"资金周转困难"为由婉拒，避免往来。**结论不是"你会倒霉"，而是"给出明确行动——不借"。**

## 板块9 · 现代应用场景拓展

奇门本质是**监测 + 运筹系统**，现代可迁移到：

| 领域 | 取用思路 |
| --- | --- |
| **商业/投资** | 生门（利润）、开门（事业）、日干与时干生克定"投不投" |
| **管理/谈判** | 主客论定强弱，六合定合作诚意，值符定贵人方位 |
| **健康** | 天芮（病灶）、日干（自身）、生克定调养方向（仅作决策辅助，非替代医疗） |
| **婚姻/人际** | 六合、休生二门、双方日时干 |
| **择吉/布局** | 借九遁条件择方位、择时辰，布置办公/收银方位 |

> ⚠️ **重要声明**：奇门是传统文化中的**决策思维模型**，可用于拓展视角、辅助思考，但**不构成对事实的必然预言**。重大事项（医疗、法律、投资）务必以专业现实依据为准。

## 板块10 · 核心禁忌与心法

原书及后世传承一致强调的"四不占"：

1. **不诚不占**：心不诚、意念不专，占则不准。
2. **不渎不占**：同一件事反复起局，越占越乱（"不渎"）。
3. **不邪不占**：违法乱纪、损人利己之事，不可占。
4. **不妄断**：拿不准的事不说死，留有余地，不可危言耸听。

**心法一句话**：奇门的最高境界不是"算得准"，而是**"知时势、明进退、避凶趋吉"**——用多维视角看清局面，再做出顺势而为的选择。

## 板块11 · 总结：一张图记住全书

```plain
                    ┌─ 天时（天盘·九星）── 顺风/逆风
                    │
   《秘笈大全》 ── 四盘模型 ─┼─ 地利（地盘·九宫·奇仪）── 方位/基础
    "大全" =      │
    规则+模板     ┼─ 人和（人盘·八门）── 该进/该守

   操作流程：定时间辨阴阳 → 排地盘 → 定值符值使
            → 转天盘 → 转人盘 → 排神盘
            → 定用神 → 断吉凶 → 给指引

   应用升维：占断（吉凶）──→ 九遁（主动运用）──→ 择吉/运筹
```
