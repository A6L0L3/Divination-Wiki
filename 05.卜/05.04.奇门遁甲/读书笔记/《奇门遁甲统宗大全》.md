## 板块1 · 导论：一本书的野心，是把分歧收归为可执行的法度

书名「统宗」二字，是全书的题眼。奇门之学流传至明清，「人树一帜，敝帚千金」，同一条规则常有两三说。编者做的核心工作不是另创一派，而是**汇总各派分歧、把起例、排盘、用神、占断、兵占、日用编成一套闭环**。因此读此书的正确姿势，不是逐句背诵口诀，而是抓住三条主线：

1. **它如何用「盘」描述世界**（九宫为体，三奇六仪为骨，八门九星八神为用）；
2. **它如何把任意时间点装进盘里**（定局、起局、找值符值使）；
3. **它如何把盘上的符号翻译成行动指引**（用神 → 旺衰 → 生克 → 格局 → 应期）。

原书十二卷可重构为四大板块：

| 板块 | 对应卷次 | 核心功能 |
| --- | --- | --- |
| 原理与定局 | 卷一 | 阴阳顺逆、超接置闰、奇门四十格 |
| 排盘与类象 | 卷二 | 三奇六仪、八门九星八神、旬首取符使 |
| 兵占与克应 | 卷三 | 主客、背击、孤虚、各类克应断语 |
| 阳九局+阴九局 | 卷四至卷九 | 4320 局的盘面全集 |
| 赋文总断 | 卷十至卷十二 | 《玄机赋》通论吉凶 |

本书最广为人知的原文，是卷首那句总纲：

> 「遁甲为兵而设，为阴象，为诡道，故取诸遁，谓其遁于六仪之下而不见其形也。」

这句话决定了全书的底层逻辑：**「甲」是至尊之神，必须藏起来**——藏而不露、和而不乖、宜生扶不宜克制。乙丙丁三奇是它的「同气」与「子嗣」，负责在外部护卫。理解了「甲为何要遁」，后面所有看似繁复的排盘，才有了统一的解释。

## 板块2 · 第一部分：底层原理——先把「世界模型」想清楚

### 2_1 九宫是骨架：戴九履一，不是玄学是坐标

全书运算建立在洛书九宫之上：

```plain
四(巽)  九(离)  二(坤)
三(震)  五(中)  七(兑)
八(艮)  一(坎)  六(乾)

```

中宫寄坤（天禽随天芮同动），这是贯穿全书的一个关键约定。**九宫本质上是一个时空坐标系**：既代表方位（离南坎北），也代表节气流转的次序。所以原文说「配以八门，八神列矣；加以三盘，三才正矣；重以三奇，三光耀矣」——三盘即天、地、人（九星、六仪、八门），三才各司其职。

### 2_2 阴阳遁是引擎：二至还乡一九宫

全书最提纲挈领的口诀在卷二：

> 「阴阳顺逆妙难穷，二至还乡一九宫。若能了达阴阳理，天地都在一掌中。」

+ **冬至一阳生 → 阳遁**：从坎一宫起，顺排（一二三四五六七八九）；
+ **夏至一阴生 → 阴遁**：从离九宫起，逆排（九八七六五四三二一）。

顺逆不是装饰，**它决定了「时间箭头」的方向**：阳遁代表生发、向外、进取；阴遁代表收敛、向内、守藏。所有排盘动作都遵循「阳顺阴逆」这一条总原则。

### 2_3 三奇六仪是语言：六甲为何要藏起来

六仪：戊己庚辛壬癸；三奇：乙丙丁。固定排列序列为：

```plain
戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙

```

关键在于**六甲隐于六仪之下**：

| 旬首 | 所遁六仪 |
| --- | --- |
| 甲子 | 戊 |
| 甲戌 | 己 |
| 甲申 | 庚 |
| 甲午 | 辛 |
| 甲辰 | 壬 |
| 甲寅 | 癸 |

这正是「遁甲」二字的字面含义。而**庚是全书最要盯紧的天干**——它代表阻碍、变动、对立面（敌方、竞争对手），所以卷一总赋里几乎把「时加六庚」单列为大凶信号。

> **实操要点**：庚的落宫与状态，是判断「阻力从哪来、有多大」的第一线索，不可略过。

### 2_4 定局规则：起局的地基，也是最易出错处

原书卷一用大量篇幅讲「超神接气、置闰法、拆补法」，因为**局数定错，全盘皆错**。三种主流方法：

| 方法 | 核心逻辑 | 特点 |
| --- | --- | --- |
| 置闰法 | 以甲子、己卯、甲午、己酉为上元符头 | 重干支自洽，有超神、接气、正授 |
| 拆补法 | 凡天干遇甲或己即为符头 | 重节气同步，**新手最省事** |
| 茅山法 | 节气交节即起上元，60 时辰换元 | 最简洁，但用者少 |

**推荐路径**：初学者直接用拆补法或软件定局，先把精力放在用神与断局上，定局规则熟练后再回头深究置闰——这是效率最高的学习顺序。

定局口诀（前六句阳遁，后六句阴遁），例如「冬至惊蛰一七四」即：冬至上元阳遁一局、中元七局、下元四局。记熟这一组，局数即可由「节气 + 上中下三元」唯一确定。

## 板块3 · 第二部分：排盘全流程——把时间变成一张九宫图

原书卷二把排盘拆成「地盘 → 天盘 → 人盘 → 神盘」四层。以下用**标准七步**重构，确保可照做：

### 3_1 第一步：定时间、辨阴阳

记录求测的年、月、日、时干支（时辰取正时，**不可刻意挑选时辰**——「天机发于动」）。依节气判阴阳遁，依符头定上中下元，得「阳/阴遁几局」。

### 3_2 第二步：排地盘、布六仪

「几局」就从几宫起戊，按阳顺阴逆把 `戊己庚辛壬癸丁丙乙` 排入九宫。**地盘恒定不动，是整个局的空间基准。**

### 3_3 第三步：找旬首、定值符值使（核心钥匙）

时柱干支往前推，找到所属六甲旬首。口诀：

> 甲子戊，甲戌己，甲申庚，甲午辛，甲辰壬，甲寅癸。

**旬首所落宫的地盘九星 = 值符星，地盘八门 = 值使门。** 这一步错了，后面全盘错位——所以它是「钥匙中的钥匙」。

### 3_4 第四步：排天盘（九星 + 天盘干）

口诀：**值符随时干**。把值符星加到「地盘时干」所在宫，其余八星按固定顺序 `蓬→任→冲→辅→英→芮(禽)→柱→心`，阳顺阴逆一圈铺完。天盘干 = 九星原宫位携带的地盘干。

### 3_5 第五步：排人盘（八门）

口诀：**值使随时宫**。从值使本宫起，阳顺阴逆数到当前时支所在宫，落定后其余七门按 `休→生→伤→杜→景→死→惊→开` 顺布。**八门不入中五宫，直接跳过。**

### 3_6 第六步：排神盘（八神）

口诀：**小符随大符**。把八神的「值符」放在天盘值符星同宫，其余按 `值符→螣蛇→太阴→六合→白虎/勾陈→玄武/朱雀→九地→九天`，阳顺阴逆排布。**八神不参与五行生克，只作吉凶加成。**

### 3_7 第七步：补标局外信息

标出**旬空（空亡）、驿马、伏吟/反吟、五不遇时**。一张完整的奇门局至此立成。

> **排盘记忆总诀（整合原文口诀）**：

阴阳二遁分顺逆，三奇六仪地盘立；
值符值使随时转，九星八门布人天；
八神加临辨吉凶，用神先把日干牵；
伏吟反吟空亡看，应期方得事周全。

**现代实操建议**：起局阶段直接用排盘工具/软件，把时间换成干支即可出盘。手工排盘只在初学阶段练手——本书的价值在「断」不在「排」，把时间留给判断。

## 板块4 · 第三部分：符号解码——每个元素到底在说什么

原书卷二后半与卷三，本质是一部「类象词典」。这里只保留**断局最常用的核心含义**，便于快速查用。

### 4_1 八门：人事行动的路径（三吉、三凶、两平）

| 门 | 五行 | 吉凶 | 核心含义 | 最佳用途 |
| --- | --- | --- | --- | --- |
| 开门 | 金 | **吉** | 开创、事业、通达 | 开业、求职、上官 |
| 休门 | 水 | **吉** | 休养、贵人、安稳 | 谈判、见贵、休息 |
| 生门 | 土 | **吉** | 财运、生机、发展 | 求财、创业、营造 |
| 伤门 | 木 | 凶 | 损伤、争斗 | 讨债、竞技、渔猎 |
| 杜门 | 木 | 平 | 阻塞、隐匿、保密 | 躲藏、防守、保密 |
| 景门 | 火 | 平 | 文书、消息、显化 | 考试、宣传、文书 |
| 死门 | 土 | 凶 | 终结、阴私 | 收尾、吊唁 |
| 惊门 | 金 | 凶 | 惊恐、口舌、官司 | 诉讼、捕盗 |

> **落地要点**：开、休、生为三吉门，是最常被选用的方位；但**吉门也要看旺衰**——开门属金，秋令落乾兑为真吉，春夏临木火则金气大衰，不能算吉。这正是原书凡例反复强调的「最重衰旺休囚」。

### 4_2 九星：天时气运的流转（四吉、四凶、一居中）

| 星 | 五行 | 倾向 | 核心象意 |
| --- | --- | --- | --- |
| 天蓬 | 水 | 凶 | 盗贼、风险、智谋 |
| 天芮 | 土 | 凶 | 疾病、问题、求学 |
| 天冲 | 木 | 吉 | 冲动、果断、行动 |
| 天辅 | 木 | 吉 | 文昌、贵人、辅佐 |
| 天禽 | 土 | 中 | 中正、稳重（寄坤） |
| 天心 | 金 | 吉 | 医药、谋略、领导 |
| 天柱 | 金 | 凶 | 口舌、破败 |
| 天任 | 土 | 吉 | 敦厚、承担、财禄 |
| 天英 | 火 | 凶 | 虚华、是非、文书 |

口诀：**辅心任禽为大吉，蓬芮柱英看时令**。天禽居中宫，阳遁阴遁俱寄坤宫。

### 4_3 八神：隐性力量的加持（不参与五行生克）

顺序固定：`值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天`

+ **吉**：值符（贵人权威）、太阴（暗中谋划）、六合（合作和合）、九地（稳固守成）、九天（高远进取）
+ **凶**：螣蛇（虚惊反复）、白虎（凶险压力）、玄武（欺诈盗贼）

> **实操提醒**：值符是最尊贵的神，用神临值符即有「贵人/官方庇护」之象；玄武临用神，必查欺瞒与破财。

## 板块5 · 第四部分：断局方法论——把盘面翻译成结论

原书卷三的「十干类神、十二支类神、六亲克应、八卦克应、六神克应」看似是罗列，实则是**多源交叉验证**的方法论。现代实操可提炼为**五步断局法**：

### 5_1 第一步：审大局（先看盘面有没有「硬伤」）

依次检查：

+ **伏吟**（星门不动，主拖延、守旧）→ 计划难推进；
+ **反吟**（星门对冲，主突发变动）→ 事快但有反复；
+ **五不遇时**（时干克日干，阳克阳、阴克阴）→ 大方向上问什么什么难成；
+ **空亡、击刑、入墓**→ 力量打折或藏而不显。

> 若开局就逢伏吟 + 五不遇时，基本可判定「时机未到」，无需再细断。

### 5_2 第二步：立用神（断事第一关键，**用神错则全盘错**）

原书「凡例」强调「静则止查值符值使时干，动则专看方向」——即**动静分用**。用神速查：

| 问事类别 | 核心用神 | 辅助用神 |
| --- | --- | --- |
| 自身 | 日干 / 年命 | 时干（所问之事） |
| 求财 | 生门 + 戊 | 日干、时干 |
| 事业 | 开门 | 日干、值符 |
| 婚姻 | 乙（女）庚（男） | 六合、天乙 |
| 疾病 | 天芮星 | 日干、天心（医） |
| 官司 | 惊门、景门 | 白虎（法官） |
| 出行 | 日干 + 方位宫 | 驿马、九天/九地 |

> **关键原则**：求测人优先取日干，他人取年命；**问得越具体，用神越精准**。笼统地问「我财运怎样」远不如「这笔货款能收回吗」可断。

### 5_3 第三步：判旺衰（力量大小的打分）

权重顺序：**月令 > 宫位五行 > 十二长生状态**。

+ 用神得月令生扶 = 旺 = 事有根基；
+ 被月令克制 / 落休囚宫 = 衰 = 事多虚浮。

口诀：**旺则事成，衰则事败；得地则兴，失地则亡。**

### 5_4 第四步：看生克（我与事的关系）

以日干宫为「我」，用神宫为「事」：

| 关系 | 含义 |
| --- | --- |
| 用神宫生我宫 | 事就于我，不劳而获 |
| 我宫生用神宫 | 我求于事，需主动付出 |
| 用神宫克我宫 | 事来克我，对我有害 |
| 我宫克用神宫 | 我能制事，费力可成 |
| 同宫比和 | 事我同心，合作有利 |

### 5_5 第五步：合格局 + 定应期（最终结论）

四步合断公式：

> **终断 = 用神旺衰 × 门星吉凶 × 生克关系 × 特殊格局**

**吉格**（好）：青龙返首（戊+丙）、飞鸟跌穴（丙+戊）、三奇得使、玉女守门；
**凶格**（坏）：白虎猖狂（辛+乙）、青龙逃走（乙+辛）、螣蛇夭矫（癸+丁）、朱雀投江（丁+癸）、六仪击刑、庚加日干（伏干格）。

**应期推断**（原书克应思想的落地）：

+ **空亡**→ 待填实/冲空之日应验（如午未空，逢午未日或子丑冲之日）；
+ **驿马**→ 马星地支对应的时日应事（寅午戌马在申，申日申时应）；
+ **旺衰**→ 用神旺相者应期近且快，休囚入墓者迟或落空；
+ **内外盘**→ 阳遁内盘（一三四八宫）主近快，外盘（九二七六宫）主远慢，阴遁相反。

> **原书活诀提醒**：「龙走雀投凶矣，为主者不害；虎狂蛇矫凶矣，为客者不害」——**吉凶不能脱离主客立场**。先动为客、后应为主，断局前必须先分主客，否则结论相反。

## 板块6 · 第五部分：实战案例——方法论的真实运行

### 6_1 案例一：合作能谈成吗（生门 + 旺衰 + 生克）

**问题**：建材商谈供货合作能否成功。
**核心用神**：生门（合作求财）、日干（求测人）、月干（对方）、戊（货款资本）。

**分析路径**：

1. 生门属土，落艮宫（土宫，得地利），但月令寅木克土 → 休囚；日令巳火生土 → 略助。**综合：衰中带旺**；
2. 日干落坎宫（水宫得地），被日令火克、月令木泄 → **日干衰**；
3. 月干（对方）落震宫，月令寅木相助 → **旺相**；
4. 生克关系：**生门克日干**（合作条件对自己不利）、**月干克生门**（对方会压价提要求）。

**结论与指引**：合作能成（生门未空、临吉神），但**成交条件对己方不利**——因此落地动作应是「借贵人（值符）之力守住底线、提前把价格与回款条款谈死」，而不是「能不能成」的二选一。

> 这正是原书「凡例」所说的标准：**占断的终点不是吉凶判断，而是给出可执行的趋避动作**。

### 6_2 案例二：对方为何没了下文（专专用神 + 格局）

**问题**：双方已表达合作意向，两个月无下文。
**关键用神**：时干（对方 + 此事）、六合（合作专用神）。

**分析路径**：

1. 时干落震宫，处「沐浴」位（败地）→ 意向漂亮但热力薄弱、难持久；
2. 格局为「丙加庚」（太白加荧/火入金乡）→ 主「贼将去」，问合作则合作散去；
3. 六合落巽宫，遇「乙加己」（日奇入墓，被土暧昧），且临**死门**。

**结论**：人事遇死门 = 双方无法产生实质关系；对方私下考察后认为不对等，已无推进意愿。**指引**：不必再等，应主动收尾或转向新对象，避免在死局上持续投入。

### 6_3 案例三：一个常被误读的局（伏吟 + 击刑）

**问题**：投资某项目是否赚钱。
**盘面硬伤**：九星伏吟 + 八门伏吟 + 六仪击刑。

**分析路径**：

1. 星门俱伏吟 → 天时、人和皆不利，**宜收敛不宜动**；
2. 投资（戊）落宫逢击刑（甲午辛加离九宫，午午自刑）→ 「此刑极凶，百事不利」；
3. 戊（资本）克生门（利润）→ 亏本结构；
4. 日干又临死门 + 天芮 → 求测人判断脱离实际。

**结论**：明确不建议投资。**结果**：求测人坚持投入，最终赔钱。

> **复盘价值**：此例说明「**先看大局硬伤**」的重要性——有了伏吟 + 击刑，后面旺衰细节已无关大局，可直接下结论。

## 板块7 · 第六部分：兵占与择吉——本书的「原生应用层」

原书卷三至卷九主体服务于**行兵布阵与择吉**，现代可迁移的部分如下。

### 7_1 兵占迁移：主客分胜的核心原则

| 兵占原义 | 现代迁移 |
| --- | --- |
| 出兵选开/休/生三吉门 | 重要行动挑吉门方位与时辰启动 |
| 分主客、背击、孤虚 | 谈判/竞争先分己方（主）与对方（客） |
| 趋三避五（胜在三、衰在五） | 行动避开「五」的宫位与时机 |
| 五不击（太岁、月建、旺气所临等） | 避免正面冲击强势方/高峰期 |

原书「凡例」特别注明：「春不东伐，秋不西征」——即**旺气所在宜避**。对应到现代：不要在对手最强的时间点、最擅长的领域硬碰。

### 7_2 民用择吉：三合为上吉的取舍逻辑

原书的核心取舍原则，放在今天依然成立：

1. **会合为上吉**：吉门 + 三奇 + 吉星同宫最佳；
2. **有门无奇犹可用，有奇无门当另择**：门（行动路径）比奇（时机加持）更优先；
3. **衰旺 > 名义吉凶**：开门吉但临春夏木火则金衰，不能算吉——**一切以得时得地为准**；
4. **专项用门可破常规**：捕猎用伤门、逃亡用杜门、吊唁用死门——只要「得时得地」，凶门亦可为专项所用。

**快速择吉对照**：

| 事项 | 首选门/星 | 方位参考 |
| --- | --- | --- |
| 开业、求职 | 开门 + 天辅/天心 | 开门方 |
| 求财、签约 | 生门 + 天任 | 生门方 |
| 谈判、见贵 | 休门 + 六合 | 休门方 |
| 考试、文书 | 景门 + 天辅 | 景门方 |
| 避灾、保密 | 杜门 + 太阴 | 杜门方 |

> **重要限制**：原书自承「欲求其纯吉无凶者甚难也」，真实择吉往往要「算至十余年而后得」。因此**接受「够用就好」的近似最优，是实操成熟度的标志**——追求纯吉纯凶，反而一事无成。

## 板块8 · 第七部分：避坑指南与学习路径

### 8_1 五个最致命的误区

1. **用神选错**：这是「全盘皆错」的第一根源。务必问得具体，按上表精准定位；
2. **不看旺衰只看吉凶**：开门临木火、生门临秋冬，名义吉而实际衰，结论会完全相反；
3. **忽略主客立场**：同一凶格，为主者不害、为客者不害，立场错则判断反；
4. **脱离动静分用**：静事查值符值使时干，动事（闻南方事、鸦鸣某方）专看对应方位宫——不可「胶柱鼓瑟」；
5. **同一事反复起局**：越占越乱，原书「凡例」明确反对渎占。

### 8_2 四项「反迷信」的操作纪律

+ **时辰取正时**：不刻意挑吉时起局，否则自欺；
+ **同一事不过三**：反复占则信息失真；
+ **断语留有余地**：拿不准不说死，忌危言耸听；
+ **结论必须落到动作**：「能成」要说清利在何方、吉在何时、怎么借力；「不成」要说明问题在哪、要不要等、如何规避。

### 8_3 推荐学习路径（3 阶段约 12 个月）

| 阶段 | 时长 | 目标 | 重点 |
| --- | --- | --- | --- |
| 入门 | 1–3 月 | 熟悉元素、会看盘 | 九宫、三奇六仪、八门九星八神 |
| 进阶 | 3–6 月 | 会选用神、能断事 | 旬首取符使、旺衰生克、主客 |
| 熟练 | 6–12 月 | 融会贯通、准确率高 | 格局、伏吟反吟、应期推断 |

**配套书目**：入门可读张志春《神奇之门》建立现代框架，再回到《统宗》原文逐句对照——先懂「今人怎么用」，再读「古人怎么讲」，效率远高于硬啃古籍。

## 板块9 · 结语：这本书真正的价值，是「决策纪律」

《奇门遁甲统宗大全》常被神化为「帝王之学」，但若剥离神秘外衣，它其实是一套**高度结构化的决策训练**：

+ 它强迫你**先定时间边界**（正时、不挑时）；
+ 再**把复杂信息分层装盘**（天地人神四盘）；
+ 然后**按优先级逐层判断**（大局 → 用神 → 旺衰 → 生克 → 格局 → 应期）；
+ 最后**必须输出可执行动作**，且**结论附带条件**（旺衰、主客、动静）。

这套「**建模 → 分层 → 加权 → 输出**」的纪律，才是「统宗」二字的真义，也是它能跨越兵占、民用、择吉，始终成立的底层价值。至于符咒、反闭、孤虚之类，原书已自承「似为不经」——**取其生克制伏近于理者用之，余者存而不论**，这本身就是最清醒的读法。
