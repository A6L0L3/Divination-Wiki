## 板块1 · 导读：先搞懂"奇门遁甲"四个字在说什么

全书的核心，其实藏在书名里。抓住这四个字，后面的几百个符号才不会越学越乱。

| 字 | 实质 | 一句话解读 |
| --- | --- | --- |
| **奇** | 三奇：乙、丙、丁 | 三个"吉祥变量"，是盘里最想要的能量 |
| **门** | 八门：休、生、伤、杜、景、死、惊、开 | 代表"人事"，一件事落到人的行为层面是吉是凶 |
| **遁** | 隐藏 | 关键角色"甲"不当值、不出面 |
| **甲** | 十天干之首，统帅 | 统帅藏起来，由"六仪"替它站岗 |

**核心机制一句话**：十天干里，"甲"是统帅，但它**隐遁在六仪之下**（这就是"遁甲"）。剩下的九个天干分成"三奇"和"六仪"。所以奇门遁甲的本质，是**用一个隐藏的统帅 + 三奇八门，来模拟某一时刻天时、地利、人和、神助的完整状态**，再据此判断吉凶、选择行动方案。

> **读书方法论（贯穿全文）**：奇门不是"算命口诀集"，而是一套**时空决策模型**。学习时始终问自己三个问题：「1」这个符号代表什么？「2」它落在哪个宫、和谁组合？「3」这个组合对"我"所问的那件事意味着什么？——能答完这三问，才算读懂，而不是背过。

---

**示例**：「奇」为三奇、「门」为八门、「遁」为隐甲、「甲」为六甲，四字拆开即全书骨架。

## 板块2 · 底层地基：九宫与洛书（必须先记住）

所有符号都要落进"九宫"里排布。九宫 = 后天八卦 + 中宫，是奇门的**坐标系**。没记住九宫，后面排盘无从谈起。

| 宫 | 方位 | 洛书数 | 五行 | 本宫含义（记忆锚点） |
| --- | --- | --- | --- | --- |
| 坎 | 北 | 一 | 水 | 险陷、起始 |
| 坤 | 西南 | 二 | 土 | 承载、母、收藏 |
| 震 | 东 | 三 | 木 | 动、起始发展 |
| 巽 | 东南 | 四 | 木 | 入、进退不果 |
| **中** | 中央 | 五 | 土 | 寄宫（详见后文） |
| 乾 | 西北 | 六 | 金 | 健、父、领导 |
| 兑 | 西 | 七 | 金 | 悦、口舌 |
| 艮 | 东北 | 八 | 土 | 止、阻隔 |
| 离 | 南 | 九 | 火 | 丽、文明、文书 |

**关键规则**：中五宫**无门、无神**，天干与天禽星一律**寄于坤二宫**（主流寄宫法）。这是排盘与断局最常见的"例外"，务必提前记住。

> **实操口诀**：「**戴九履一，左三右七，二四为肩，六八为足，五居中央**」——把洛书数字背熟，后面"阳遁顺排、阴遁逆排"才有依托。

## 板块3 · 符号系统：四层盘的"词汇表"

奇门盘由**地盘、天盘（九星）、人盘（八门）、神盘（八神）**四层叠加而成。先分别认字，再学怎么组合。

### 3_1 三奇六仪——盘的"骨架干支"

甲统帅隐遁，其余九个天干分布天地两盘：

| 分类 | 天干 | 五行 | 核心含义（记忆锚点） |
| --- | --- | --- | --- |
| **三奇** | 乙·日奇 | 木 | 柔顺、文书、女贵人 |
|  | 丙·月奇 | 火 | 光明、权威、刚猛 |
|  | 丁·星奇 | 火 | 文昌、玉女、谋略、暗助 |
| **六仪** | 戊（甲子隐此） | 土 | 资本、财产、本金 |
|  | 己（甲戌隐此） | 土 | 阴私、坟墓 |
|  | 庚（甲申隐此） | 金 | **阻碍、敌人、变动**（最需关注） |
|  | 辛（甲午隐此） | 金 | 错误、罪罚 |
|  | 壬（甲辰隐此） | 水 | 流动、奸诈 |
|  | 癸（甲寅隐此） | 水 | 暗昧、天网 |

**六甲遁藏**（必背）：`甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸`。

> **实操要点**：三奇遇吉门吉星，多为大吉之格；**六仪里"庚"最重要**——它代表阻碍与变动，几乎每个格局的判断都要先看庚在哪里、被谁克。

**永定排列顺序**（不管阴遁阳遁，永远不变）：

> **戊 → 己 → 庚 → 辛 → 壬 → 癸 → 丁 → 丙 → 乙**

这是排地盘的"宪法级"规则，务必刻进肌肉记忆。

### 3_2 八门——代表"人事"

八门分**三吉、三凶、两平**，是判断"人该怎么做"的核心。

| 门 | 五行 | 吉凶 | 含义 | 典型用事 |
| --- | --- | --- | --- | --- |
| 开门 | 金 | 吉 | 开创、事业、领导 | 开业、升迁、求官 |
| 休门 | 水 | 吉 | 休养、贵人、安逸 | 求贵人、休养、谈判 |
| 生门 | 土 | 吉 | 生意、房产、发展 | **求财首选** |
| 伤门 | 木 | 凶 | 伤害、争斗 | 竞技、打猎（宜动不宜静） |
| 杜门 | 木 | 平 | 隐藏、防守、保密 | 隐匿、技术、拖延 |
| 景门 | 火 | 平 | 文书、考试、策略 | 考试、谋划、血光 |
| 死门 | 土 | 凶 | 死亡、丧事、收藏 | 钓鱼、埋伏、终结 |
| 惊门 | 金 | 凶 | 惊恐、官讼、口舌 | 是非、争讼 |

**用门速记**：做大事看**开门**，求财看**生门**，求贵人休养看**休门**。开、休、生为最常选用的"好门"。

### 3_3 九星——代表"天时"

| 星 | 五行 | 吉凶 | 含义 |
| --- | --- | --- | --- |
| 天蓬 | 水 | 凶 | 盗贼、暗昧、智谋 |
| 天芮 | 土 | 凶 | **疾病、小人**（测病主星） |
| 天冲 | 木 | 吉 | 勇猛、果断、行动 |
| 天辅 | 木 | 吉 | **文昌、学业** |
| 天禽 | 土 | 中 | 中正、镇守（恒寄坤二宫） |
| 天心 | 金 | 吉 | **医药、领导、谋略** |
| 天柱 | 金 | 凶 | 毁折、口舌、隐退 |
| 天任 | 土 | 吉 | 忠厚、慈善、土地 |
| 天英 | 火 | 凶 | 虚华、是非、文书 |

**吉凶口诀**：`辅、心、任、禽` 为四吉星；`蓬、芮、柱、英` 为四凶星。**但凶星不可一概而论**——如天蓬临吉门亦可用，天英在文书、文化事上反为得用。判断要看**旺衰 + 所问之事**。

**九星本位（固定）**：蓬坎、芮坤、冲震、辅巽、禽中、心乾、柱兑、任艮、英离。

### 3_4 八神——代表"看不见的神助"

| 神 | 吉凶 | 含义 |
| --- | --- | --- |
| 值符 | **大吉** | 领导、贵人、权威、主事者（最尊贵） |
| 螣蛇 | 凶 | 虚幻、惊恐、缠绕、怪异 |
| 太阴 | 吉 | 阴贵人、暗助、隐蔽、女性 |
| 六合 | 吉 | **和合、中间人、交易、婚姻** |
| 白虎 | 凶 | 凶险、疾病、军警、丧事 |
| 玄武 | 凶 | **盗贼、暗昧、欺诈** |
| 九地 | 平 | 厚重、稳定、潜伏（宜守） |
| 九天 | 吉 | **刚健、远大、高扬**（宜进攻、远行） |

> **八神顺序（永定）**：值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天。

### 3_5 四层盘的一句总括

> **地盘 = 地利（固定），天盘 = 天时（九星），人盘 = 人和（八门），神盘 = 神助（八神）。**

断局就是把"天时、地利、人和、神助"四件事放在同一坐标里交叉比对。

## 板块4 · 排盘实战：纸上起局的九步法

理论不落地，等于没学。以下为**转盘奇门**主流纸上起局流程（参照张志春《神奇之门》体系），建议手排至少 10 局再依赖软件。

### 4_1 完整九步

**第一步 · 定时定局**

+ 把公历时间换算为**干支四柱**（年、月、日、时），注意校正**真太阳时**；
+ 依节气判定阴阳遁：**冬至 → 夏至用阳遁，夏至 → 冬至用阴遁**；
+ 按"拆补法"（现代常用）或"置闰法"确定具体局数，如"阳遁三局"。

**第二步 · 布地盘**

+ 依局数，在洛书九宫从"戊"起布，**阳遁顺排、阴遁逆排**，顺序固定为 `戊己庚辛壬癸丁丙乙`；
+ 中五宫天干寄坤二宫。

**第三步 · 定符使**

+ 查时柱所属**旬首**（六甲中哪一甲值班）；
+ **旬首落宫的原地盘九星 = 值符，原地盘八门 = 值使**。

**第四步 · 排天盘（九星）**

+ 遵循 **"值符随时干"**：把值符星移到"地盘时干"所在宫；
+ 其余八星按固定顺序 `蓬、任、冲、辅、英、芮禽、柱、心` **永远顺时针**跟随排布。

**第五步 · 排人盘（八门）**

+ 遵循 **"值使随时支"**：从旬首本宫起算，**阳遁顺数、阴遁逆数**至时支对应宫落值使门；
+ 其余七门按 `休、生、伤、杜、景、死、惊、开` **永远顺时针**跟随。

**第六步 · 排神盘（八神）**

+ 小值符落天盘值符星同宫；
+ 其余七神按序，**阳遁顺时针、阴遁逆时针**排布。

**第七步 · 排空亡（旬空）**

+ 由时柱旬首确定**旬空**的两个地支（如甲子旬，戌亥空）。

**第八步 · 找驿马**

+ 按"申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳"定驿马星。

**第九步 · 寄宫与核对**

+ 天禽星恒随天芮星同宫（寄坤二）；中五宫无门无神；
+ 逐宫核对天、地、人、神 + 三奇六仪是否齐全。

### 4_2 核心规则速记表

| 项目 | 规则 |
| --- | --- |
| 三奇六仪序 | 戊→己→庚→辛→壬→癸→丁→丙→乙（永定） |
| 九星序 | 蓬·任·冲·辅·英·芮禽·柱·心（永顺转） |
| 八门序 | 休·生·伤·杜·景·死·惊·开（永顺转） |
| 八神序 | 值符→螣蛇→太阴→六合→白虎→玄武→九地→九天 |
| 旋转逻辑 | 九星、八门相对顺序**永不改变**，恒顺时针；仅八神排布方向随阴阳遁（阳顺阴逆） |
| 两大铁律 | **值符随时干；值使随时支** |

> **实操建议**：

「1」 初学务必**手排 10 局以上**，搞清楚每个符号从哪来，否则只会看软件结果、不懂盘面生成逻辑；
「2」 寄宫（天禽随芮、中宫寄坤）是新手最常出错处，每次排完专门复查；
「3」 起局后先标出**旬空、驿马、值符**，这三项决定后续判断优先级。

## 板块5 · 格局：古人留给我们的"吉凶公式"

格局，是古人根据奇仪、星、门的五行生克制化，归纳出的**固定吉凶格式**。它相当于数学公式——忘了具体含义时，也能从五行属性现场推回来。基本原则：

> **吉门 + 吉星 + 三奇 ≈ 吉格；庚辛壬癸 + 凶门凶星 ≈ 凶格。**

### 5_1 顶级吉格（建议背熟）

| 格局 | 组合 | 主象 | 适用 |
| --- | --- | --- | --- |
| **青龙返首** | 戊 + 丙 | 百事大吉 | 求职、求财、主动出击 |
| **飞鸟跌穴** | 丙 + 戊 | 最吉 | 合作、投资、贵人扶持 |
| **三奇得使** | 乙/丙/丁 + 吉门（开休生）+ 吉神 | 奇力尽显 | 谋事、贵人相助 |
| **天遁** | 丙 + 生门 + 丁 | 百事兴旺 | 求官、事业、升学 |
| **地遁** | 乙 + 开门 + 己 | 稳固 | 置业、修造、安葬 |
| **人遁** | 丁 + 休门 + 太阴 | 人和 | 谈判、公关、婚恋、隐匿 |

### 5_2 高频凶格（必须识别）

| 格局 | 组合 | 主象 |
| --- | --- | --- |
| **青龙逃走** | 乙 + 辛 | 人财两失、女逃男、婚败 |
| **白虎猖狂** | 辛 + 乙 | 家破人亡、口舌官非 |
| **朱雀投江** | 丁 + 癸 | 文书失效、音信全无、官司败 |
| **螣蛇夭矫** | 癸 + 丁 | 文书纠纷、是非缠绕 |
| **太白入荧** | 庚 + 丙 | 贼来破财、防小人 |
| **荧入太白** | 丙 + 庚 | 主动破耗、事多阻碍 |
| **五不遇时** | 时干克日干（须同性相克） | 百事不顺、宜静不宜动 |

### 5_3 特殊格局：伏吟与反吟（全书重点）

这是全书的"战略级"判断，直接决定**该动还是该静**。

|  | 伏吟 | 反吟 |
| --- | --- | --- |
| **定义** | 星/门/奇仪落回**原位**（本宫） | 星/门/奇仪落**对冲宫** |
| **时间** | 主慢、主迟 | 主快、主速 |
| **空间** | 主近、本地、内部 | 主远、外地、外部 |
| **事物** | 停滞、守旧、重复 | 反复、变动、冲突 |
| **战略** | **利主，宜后发制人** | **利客，宜先发制人** |
| **宜** | 收敛财货、讨债、守成 | 主动出击、侦查破案、寻人 |
| **忌** | 妄动（动则破财耗失） | 被动守成（事多半途而废） |

**细化判断（实战关键）**：

+ **伏吟**：六甲之时（天显时格）虽为伏吟却反吉，利求官、出行、上任；一般伏吟多遭遗失破财。其"救应"在**冲**——可待冲克之日破局（如坎宫伏吟，待午日午时来冲）。
+ **反吟**：需辨**新久**——新病遇反吟易愈，久病遇反吟大凶；测合作中途生变、测婚姻反复拉锯、测出行频生枝节。其"救应"在**合**——逢吉门吉神可稍解。
+ **遇奇门则有救**：伏吟、反吟虽总体偏凶，但逢三奇、吉门、吉神护持，凶性大减，不可一见即断"大凶"。

### 5_4 四害（能量受阻的信号）

| 害 | 识别方法 | 含义 |
| --- | --- | --- |
| **入墓** | 天干五行入墓库宫（如丙火入乾六宫） | 能量被埋，事难成 |
| **击刑** | 奇仪所藏地支与落宫地支相刑 | 受损、刑罚 |
| **空亡** | 用神落旬空之宫 | 事多虚假、拖延不成；**冲空填实则落地** |
| **门迫** | 门克宫（吉门克宫吉不就，凶门克宫祸重重） | 吉事难成、凶事更凶 |

> **旺衰总纲**：须以**月令为纲**，分辨门与宫的旺衰——休囚之门克不动旺相之宫，旺相之门方能克休囚之宫。

### 5_5 格局速记口诀

> 吉格：`龙回首、鸟跌穴、三奇得使、九遁昌`

凶格：`龙逃走、虎猖狂、朱雀投江、蛇夭矫`
特殊：`伏吟迟、反吟乱、五不遇、天显吉`

## 板块6 · 解盘核心：用神怎么取、怎么断

排好盘只是第一步。**取不准用神，等于靶子都没立起来**。这是新手断不准的最大通病。

### 6_1 取用神总原则

1. **一事一用神**：一问只抓一个核心符号，其余星仪只作辅佐，不可一堆符号混在一起乱生克；
2. **用神要活不要僵**：同一符号多象，须贴合问事场景灵活切换（如天芮，问病是病灶，问交友则是顽劣之人）；
3. **先看干支，再看六亲，最后看星门神**，多维度交叉，不可单线程。

### 6_2 常用用神表（建议收藏）

**人物用神**

| 测事对象 | 用神 | 说明 |
| --- | --- | --- |
| 本人 | 日干 / 年命 | 求测者自己（日干为第一用神） |
| 对方 | 时干 / 对宫 | 与自己对立之人 |
| 长辈、领导 | 年干 / 值符 / 开门 | 上级 |
| 同辈、朋友 | 月干 / 六合 | 兄弟、合作 |
| 配偶 | 乙（女）、庚（男）/ 六合 | 另一半 |
| 小人 | 玄武 / 螣蛇 | 暗中害人者 |
| 贵人 | 太阴 / 天心 | 帮助自己者 |

**事物用神**

| 问事 | 核心用神 | 辅助用神 |
| --- | --- | --- |
| 事业、求职 | 开门 | 日干、值符 |
| 财运、求财 | **生门 + 戊** | 日干、甲子戊 |
| 投资理财 | 生门 + 天蓬（风险） | 戊（本金） |
| 婚姻恋爱 | 乙庚 + 六合 | 日干、太阴 |
| 学业考试 | 天辅 / 文昌 | 开门 |
| 疾病健康 | **天芮 + 日干** | 天心（医药）、乙奇（医生） |
| 官司口舌 | 惊门 / 天柱 | 庚格 |
| 寻人找物 | 时干 + 玄武 | 杜门（阻滞） |
| 出行 | 驿马 + 九天 | 开门、所去方位宫 |
| 合作竞争 | 六合 | 伤门（竞争） |

### 6_3 用神取用法诀（便于记忆）

> **日干为我时干事，生门求财开门官；**

**乙庚合处看姻缘，天芮死门问病端；**
**出行先看马与方，失物时干杜门看；**
**惊门景门断官司，用神一立全局判。**

### 6_4 断局五步法（实战操作清单）

这是把一盘"读成结论"的标准动作，建议每次断局照单走一遍：

**第一步 · 审局（看大势）**

+ 值符值使落宫 = 全局关键；
+ 有无吉凶格局、是否逢马星/空亡、是伏吟还是反吟。

**第二步 · 立用神（定太极）**

+ 问自身看日干/年命，问事看时干或专项用神（财看生门、官看开门）；
+ 用神所落之宫即事体根本：**用神宫旺相 → 事有根基；休囚 → 事多虚浮**。

**第三步 · 观门星（判吉凶）**

+ 看用神宫所临之门、之星、之神；
+ 吉门吉星吉神 → 顺遂；凶门凶星凶神 → 阻滞。此为**大势第一观感**。

**第四步 · 查生克（看我与事的关系）**
以日干宫为"我"、用神宫为"事"：

| 关系 | 含义 |
| --- | --- |
| 用神宫 **生** 我宫 | 事就于我，不劳而获 |
| 我宫 **生** 用神宫 | 我求于事，需主动付出 |
| 用神宫 **克** 我宫 | 事来克我，对我有害 |
| 我宫 **克** 用神宫 | 我能制事，费力可成 |
| **同宫比和** | 事我同心，合作有利 |

**第五步 · 合格局（定最终结果）**

> **终断 = 用神旺衰 × 门星吉凶 × 生克关系 × 特殊格局**

四项相乘（综合），而非简单相加。吉格逢吉门吉星、用神旺相、得生 → 大吉；凶格逢凶门凶星、用神休囚、受克 → 大凶；半吉半凶则看组合与旺衰孰为主导。

**两大实战铁律**：

1. **急事看值符**：突发情况直接看值符落宫（当下核心能量与贵人）；
2. **缓事看九星**：中长期规划重点看九星（天时与长远趋势）。

## 板块7 · 实战案例拆解：把方法串成一条线

> 以下案例结构为示范框架（时间取典型设定），重点在**展示思考链路**，而非断言结果。

**问事**：「我去谈一个供货合作，能成吗？」（具体、有指向性——好问题；若只问"我合作运怎样"则无法取用神）

**Step 1 · 定问题**：合作求财 → 核心用神 = **生门**，辅助 = 日干（我）、月干（对方）、戊（资本货款）。

**Step 2 · 取用神**：生门（合作财）、日干（己方）、月干（对方公司）、六合（合作关系）。

**Step 3 · 看旺衰**：结合月令、日令、落宫五行判断——生门属土落艮宫得地利，再看月令是生是克、日令是助是被克，得出"衰中带旺/旺中带衰"的具体结论。

**Step 4 · 查生克 + 格局**：

+ 生门（财）与日干（我）的生克关系，决定"成事的代价"；
+ 月干（对方）与生门的关系，反映对方态度（压价/诚意）；
+ 临值符 → 有贵人助力；临螣蛇 → 心有顾虑；临六合 → 有合作诚意。

**Step 5 · 综合结论**：生克 + 格局 + 旺衰合并判断，给出"能否成、条件如何、何时利行动"的 actionable 建议，而非一句"大吉/大凶"。

> **实操提醒**：软件只给盘面，不给判断。**真正的功力在 Step 3–5 的综合**——旺衰、生克、格局任何一项都不能单独定论。

## 板块8 · 全书重构：一张图看懂逻辑链

原文多为分章平铺，本文重排为**"由静到动、由符号到决策"**的单线结构：

```plain
九宫坐标（地基）
   ↓
符号词汇表：三奇六仪 / 八门 / 九星 / 八神（认字）
   ↓
排盘九步：定局 → 地盘 → 符使 → 天盘 → 人盘 → 神盘 → 空亡 → 驿马（组句）
   ↓
格局系统：吉格 / 凶格 / 伏吟反吟 / 四害（理解语境）
   ↓
解盘四层：审局 → 立用神 → 观门星 → 查生克 → 合格局（读懂句子）
   ↓
决策输出：该动 / 该静 / 何时 / 何方（落地）

```

**这一重构的价值**：把"背符号"和"做判断"两件事分开训练，再在断局阶段合并——避免新手一边起盘一边断、越看越乱。

## 板块9 · 常见误区与纠偏清单

| 误区 | 纠偏 |
| --- | --- |
| 起盘全靠软件，不懂符号来源 | 手排 10 局，弄清每个符号从哪来 |
| 一盘多象、主次不分 | **一事一用神**，其余只作辅佐 |
| 见凶格即断大凶 | 须合旺衰、生克、门星，且**伏吟反吟遇奇门则有救** |

| 用神落空即断"无" | 空亡主拖延虚假，**冲空填实则落地** |
| 忽视月令旺衰 | **以月令为纲**辨门宫旺衰 |
| 寄宫处理随意 | 天禽随芮、中宫寄坤，每次复查 |
| 问题模糊就起盘 | 先**把问题具体化**，否则无法取用神 |

## 板块12 · 附：避坑提示

1. **流派差异**：转盘与飞盘（九神 vs 八神）、寄宫法（寄坤 vs 寄艮）、定局法（置闰 vs 拆补）均存在口径差异。入门选定一家体系学透，**切勿混用**；
2. **旺衰为纲**：所有吉凶判断都以月令旺衰为最高优先级依据，脱离旺衰谈格局容易失真；
3. **理性定位**：奇门遁甲属传统术数文化，本文为知识整理与思维方法笔记。其结论**不具备科学验证基础**，不宜用于重大人生、医疗、法律、投资的唯一决策依据；
4. **真太阳时**：起局换算时间务必校正真太阳时，否则局数可能整盘错位。
