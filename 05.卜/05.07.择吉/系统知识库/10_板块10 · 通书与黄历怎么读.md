## 板块10 · 通书与黄历怎么读

> 黄历不是择吉的答案，是择吉的索引。它按"日"给结论，而择吉要的是"事加人加方加日时"四件套的匹配结果。
> 会用的人拿它做粗筛，不会用的人拿它当命令。这一板块把一页黄历逐栏拆开，说清楚每栏能信多少、信到哪一步为止。

---

### 10_1 一页黄历的构成：逐栏拆开看

市面上的黄历（日历、通书、手机黄历）版式各异，栏目大同小异。先把栏目认清，再谈怎么用。

| 栏目 | 它是什么 | 怎么看 | 常犯的错 |
| --- | --- | --- | --- |
| **公历 / 农历** | 两套日期对照 | 只看作定位，不参与吉凶判断 | 拿农历月当干支月，这是坐标层最常见的错（详见板块1） |
| **干支（年月日时）** | 择吉真正的时间坐标 | 一切推算的起点，先看它 | 只看日柱，忽略年柱月柱，年家月家大煞全漏 |
| **节气 / 月建** | 干支月的分界 | 过节气才算换月，不是过初一 | 月初但不交节，仍算上月 |
| **宜 / 忌** | 通书的成品结论 | 作粗筛，不作终判 | 把"宜"当命令，把"忌"当禁令 |
| **吉神 / 凶煞** | 宜忌的推导依据 | 比宜忌栏更值得看 | 只看宜忌不看成因，遇到打架无从判断 |
| **建除十二神** | 建除满平定执破危成收开闭 | 看当日"底色"，黄黑道同看 | 单看"破日"就判凶，不看成日开日与用事的配合 |
| **二十八宿** | 井鬼柳星张翼轸等二十七或二十八宿值日 | 多数通书并列，作参考项 | 把宿曜吉凶当成主要判据 |
| **九星（紫白）** | 一白到九紫，入中顺飞 | 看方位配合时用，须有坐向 | 无坐向就谈九星，等于悬空 |
| **彭祖百忌** | 如"甲不开仓财物耗散"之类日干日支禁忌 | 民俗层面的小提醒 | 当成硬规则逐条执行 |
| **冲煞** | 日支冲何生肖 | 看主事人生年是否犯冲 | 只查生肖不查完整生年四柱 |
| **值神（黄黑道）** | 青龙明堂金匮天德玉堂司命为黄道，余六神为黑道 | 看当日值班之神 | 黄道日一概吉，不看值神与用事是否相配 |
| **胎神** | 传说中胎儿相关的方位禁忌 | 民俗项，安床、修造避之 | 把民俗禁忌当技术判据 |
| **五行（纳音）** | 如"剑锋金""大林木"之类 | 正五行择日用的是干支本气五行，不是纳音 | 用纳音五行去论生克，体系错 |

> **口径说明**：本库用**正五行**（干支本气：甲乙木、丙丁火、戊己土、庚辛金、壬癸水）论生克补扶，不以纳音五行为主。纳音在择吉中多作辅助描述，不是生克判据。

### 10_2 三栏必须先看的坐标：日期、干支、节气

翻开黄历，先别看宜忌。先看这三栏，因为它们是后面所有栏目的地基。

```latex
第1栏  公历与农历      → 定位，确认你看的是哪一天
第2栏  干支四柱        → 择吉的正式时间坐标
第3栏  节气与月建      → 判断干支月是否已经切换

三栏对不上（例如农历已入新月初一、节气未交），
一律以"节气"为准定干支月，不以农历月为准。
```

这一点看起来琐碎，实际是黄历使用者出错频率最高的一处：**农历月初一到三十，与干支月的初一（交节日）并不同步**。黄历上写的"六月"，与干支历的"未月"可能差着十来天。

### 10_3 宜忌栏：它是怎么算出来的

宜忌不是天启，它是通书编者按一套规则推出来的成品。理解这一点，你就不会再把它当命令。

```latex
通书生成"宜忌"的流程（简化）：

   当日干支
      ↓
   起出各家神煞（年神、月神、日神、建除、黄黑道、二十八宿）
      ↓
   按"用事类别"分别权衡（嫁娶、营造、安葬、出行、开市各有侧重）
      ↓
   吉能压凶 → 记为"宜"
   凶能压吉 → 记为"忌"
      ↓
   遇到大煞，直接记"诸事不宜"或"大事勿用"
```

**看懂这个过程，就能推出两条实操结论**：

1. **宜忌是"用事类别"的函数**。同一天，宜安葬不一定宜嫁娶，黄历上分列得清楚，看的时候要对号入座，不能只看"今天好不好"。
2. **宜忌背后是神煞**。两本黄历的宜忌打架，根源一定在它们起出来的神煞名目不同、轻重取舍不同。**所以遇到打架，翻到"吉神凶煞"那一栏去比对，而不是在"宜忌"两个字上争论。**

### 10_4 四套并行的日辰标尺：建除、黄黑道、二十八宿、九星

黄历上常常同时摆着四套"今日值什么"的说法。它们不是四个人说了四件事，而是四把刻度不同的尺子。

| 标尺 | 刻度依据 | 层级 | 主要用途 |
| --- | --- | --- | --- |
| **建除十二神** | 月建之支上起建，顺行十二辰，遇节气重一日 | 日神层（详见板块3） | 看当日的"底色"，定大范围用事倾向 |
| **黄黑道六神** | 按月建起的十二神，分黄道六吉与黑道六凶 | 日神层 | 与建除合看，判断当日值班之神 |
| **二十八宿** | 按历法轮值，二十七或二十八宿值日 | 日神层（属天星系统） | 参看，天星派更重（详见板块11） |
| **九星（紫白）** | 年月日时各有入中之星，按洛书轨迹飞布 | 需配合方位 | 有坐向才有意义，用于方位择吉 |

```latex
四把尺子打架时的处理顺序：

   第一步：先看建除与黄黑道（日神层的基础标尺）
   第二步：再看二十八宿（天星照临，作加分项）
   第三步：九星须待坐向确定后才有意义
   第四步：仍打架，回到"以事为纲、分级取舍"（详见板块0）
```

> **口径说明**：四套标尺分属不同的历史层，起源不一、用法不一。通书把它们并列在一页上，是"陈列"而非"综合"——并列不等于可以混算。

### 10_5 小栏目各自的用途：彭祖百忌、冲煞、值神、胎神

这些栏目的共同特点是：**有用，但都不是决定项**。

| 栏目 | 该怎么定位它 | 边界 |
| --- | --- | --- |
| **彭祖百忌** | 民俗层面的日用提醒，如"甲不开仓""子不问卜"之类 | 属于民俗文化，不作技术判据；与正五行取舍冲突时，让位于正课 |
| **冲煞（生肖冲）** | 快速自查主事人生年是否与日支相冲 | 只看生肖会漏掉"刑""害"，也会漏掉日干一层；正式择课必须看完整生年干支 |
| **值神** | 当日黄道或黑道值班之神，与建除合看更稳 | 黄道日遇大煞照样不可用，黄道不是免死金牌 |
| **胎神** | 传统民俗中的方位禁忌，涉及安床、修造动土 | 民俗项；涉及孕产的事项一律以医生意见为唯一依据 |
| **五行（纳音）** | 描述性栏目 | 正五行择日不用纳音论生克（详见10_1 口径说明） |

**一句话定位**：这些栏目提供的是"提醒"，不是"判决"。真正决定能不能用的，是年家月家的大煞、坐山的吉星照临、以及主命与日课的匹配——这三层，黄历一页纸装不下。

### 10_6 通书与官定历书：两回事

这是很多人混淆的一对概念。**官定历书**是朝廷颁行的历日，**通书**是民间坊刻的择日日用书，二者性质不同。

| 对比项 | 官定历书 | 民间通书 |
| --- | --- | --- |
| **性质** | 奉敕编修，官方定本 | 坊间编纂，商业流通 |
| **代表** | 《协纪辨方书》（清乾隆四年 1739 年奉敕编修，梅毂成等主持，三十六卷，取"敬天之纪、敬地之方"为名）、《星历考原》、《钦定选择历书》 | 《鳌头通书》《象吉通书》《永吉通书》《玉匣记》之类 |
| **目的** | 统一口径，裁断各家异同 | 便于民用，按日用事查阅 |
| **特点** | 逐条辨正神煞起例，注明取舍理由 | 重实用、重速查，往往不注依据 |
| **增删情况** | 相对稳定 | 各坊本递相增删，名目时有出入 |

```latex
一句话区分：

   官定历书 = 立法（定规则、辨异同）
   民间通书 = 应用（按日查用事）

   清代以《协纪辨方书》为官方定本，
   后世通书的编纂多以其为典范与依据。
```

**为什么要分清**：当你看到两本通书说法不一，正确的做法是回到官定定本去查"这一条神煞的起例到底是什么"，而不是在两本坊刻本之间二选一。**详见板块12 的书目地图。**

### 10_7 黄历的局限：它只能作粗筛

这一节是板块10 最重要的部分。

```latex
择吉的完整输入：事 + 人 + 方 + 年月日时
                          ↑        ↑
黄历能处理的：            日神层   日辰干支
黄历处理不了的：          人（八字） 方（坐山）
```

**通用黄历的三条硬局限**：

| 局限 | 说明 | 后果 |
| --- | --- | --- |
| **不含主事人八字** | 黄历只写"冲某生肖"，不处理整个命局 | 黄历说宜，却与主命相冲相刑 |
| **不含坐山方位** | 黄历没有坐向，无法判断三煞方、五黄方 | 黄历说宜动土，动的方向正犯三煞 |
| **只到"日"层** | 多数黄历时辰栏很粗 | 择时这一层基本缺失 |

所以正确的分工是：

```
黄历  → 粗筛（排除明显犯大煞的日子，圈出可用范围）
择课  → 精筛（在可用范围内，按人按方排出四柱成课）
```

**把黄历的"宜嫁娶"直接当作结婚日的决定依据，等于跳过了择吉的全部主干。** 这一点在板块0 已列为"新手三个坑"的第一条，此处不再重复展开。

> **边界提醒**：涉及医疗（尤其是生育与手术）、法律、重大财务与工程安全的决定，一律以专业意见为准。黄历与择吉都不进入这些领域的决策链。

### 10_8 为什么不同版本的黄历宜忌打架

板块0 的案例里，三本黄历给了三个答案。这里给出打架的四个具体原因。

| 原因 | 具体表现 | 怎么应对 |
| --- | --- | --- |
| **采用的体系不同** | 有的重建除，有的重黄黑道，有的重二十八宿，有的重天星照临 | 先问它采用的是哪一家（详见板块11） |
| **取舍宽严不同** | 同一神煞，有的本子记"忌"，有的本子记"不忌"；小煞尤其如此 | 按"大煞避之，中煞制之，小煞不必制"自行定夺（详见板块4） |
| **通书递相增删** | 坊刻本为便于销售，增补名目、删削繁琐部分 | 回到官定定本核起例 |
| **排版与校勘讹误** | 转抄翻刻中的错字、错日、错干支 | 用干支与节气自行复核一遍 |

```latex
遇到两本黄历打架的三步处理法：

   第一步  翻到"吉神凶煞"栏，比对两者列出的神煞名目
   第二步  找出差异项，判断它属大煞、中煞还是小煞
   第三步  大煞从严，小煞从宽；差异无法裁断时，换一个两者都说宜的日子
```

**第三步最实用**：与其裁断两本谁对，不如避开争议日。择吉的选项从来不是只有一天。

### 10_9 怎么挑一本可信的黄历或通书

买之前翻一下，看四项。四项里有两项不合格，就不用买。

| 核查项 | 具体看什么 | 不合格的后果 |
| --- | --- | --- |
| **一 · 是否注明神煞起例** | 有没有"某煞从某起、顺行或逆行"的说明 | 只给结论不给算法，无法复核，也无法学到东西 |
| **二 · 是否标出依据** | 关键取舍有没有注明出处，尤其是否引《协纪辨方书》一类官定定本 | 无依据的宜忌，等于编者拍脑袋 |
| **三 · 是否有版本沿革** | 序跋或凡例里有没有说明据何本翻刻、增删了什么 | 不知是据何本，就无法判断它的名目是否有出入 |
| **四 · 干支与节气能否自核** | 随手抽几天，自己推一遍干支，看对不对得上 | 干支都错的本子，其余不必看 |

```latex
一条速判经验：

   把书的"凡例"或"起例"部分翻开——
   有凡例、有起例、有引据        → 可买
   只有一页页的宜忌表格，别无说明 → 只配当日历，不配当择日依据
```

### 10_10 常见错：两个最典型的误用

**误用一：把"宜 / 忌"当命令**

| 项目 | 内容 |
| --- | --- |
| **表现** | 看到"宜嫁娶"就定日子，看到"忌出行"就取消行程 |
| **后果** | 忽略了人与方两层；也忽略了同一天对不同人的差异 |
| **改法** | 把宜忌当"粗筛结果"，再走一遍"避大煞、取吉神、配主命、定坐山、制成课"的完整链 |

**误用二：把"诸事不宜"当洪水猛兽**

| 项目 | 内容 |
| --- | --- |
| **表现** | 一见"诸事不宜"就整月不敢安排任何事 |
| **后果** | 一年三百六十日，可用的日子被砍掉一大半；越择越焦虑 |
| **改法** | 先问这个"不宜"由哪条神煞推出，属大煞中煞还是小煞；小煞口径造成的"诸事不宜"，按"小煞不必制"处理（详见板块4） |

补一条常被忽略的：**"诸事不宜"往往是编者的保守口径，不是天条。** 它的价值在于提醒你"这一天需要人工复核"，而不是"这一天被封印了"。

#### 案例小故事：同一天，两份黄历，两种说法

**背景**：有人要安床，翻了手机上的黄历，显示"宜安床"。另一本纸质通书对同一天却写"忌安床"。他不知道听谁的，来问。

**经过**：我让他把两本的"吉神凶煞"栏分别拍给我。一比对，差异出在一个神煞上：手机黄历没有收这一条，纸质通书收了。再查这一条的起例与层级，属**中煞**，而且当日有吉神同到。

**转折点**：问题不在于两本谁对，在于他一开始问错了问题。他问"哪本对"，正确的问法是"**这一条煞对我的事、我的人、我的方位影响有多大**"。安床要看卧室方位与主命，这两项他一项都没提供。

**结果**：按本库的链重走一遍——先查年家月家大煞（无犯），再查日神（中煞一条，有吉神可压），再看主命（生年与日支不冲不刑），最后定方位（不犯本年三煞方与五黄方）。结论是**可用，但需避开当日某两个时辰**。两份黄历的"宜"与"忌"，其实都没有说错，只是各自停在了日神层，没有往下走。

**落点**：黄历给的是"日神层"的粗筛结论，它天然不处理人与方。遇到不同版本打架，不要在"宜忌"两个字上争对错，要到"神煞栏"去比对差异，再按等次取舍。**黄历是索引，不是判决；把它当判决的人，会把择吉做成查表。**
