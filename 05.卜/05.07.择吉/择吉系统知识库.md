# 择吉系统知识库
## README · 导览

> 择吉最难的地方，从来不是"记不住神煞"——神煞有两百多个，本来就记不住。
> 真正难的是：**同一天既有吉神又有凶煞、不同流派给出相反结论、通书与师傅说法还打架时，你听谁的**。
>
> 本知识库把择吉的方法重构成一条可以照做、可以复核、可以复盘的流水线：
>
> **定事（办什么事）→ 定人（谁办）→ 定方（在哪儿办）→ 避大煞 → 取吉神 → 制成课（四柱成格）→ 出课与登记**
>
> 全篇共 15 个板块（板块0 至板块14），分五编。

---

### README_1 使用声明

择吉（选择术、择日、看日子、涓吉、诹吉）属于中国传统象数文化与民俗范畴，是古人"顺时而动"的经验系统。**它不能改变事件的客观结果，更不能替代医疗、法律、金融、工程、安全等专业意见。** 本库所有日课示例仅用于演示取舍逻辑，不构成任何现实决策依据。

> **特别声明**：本库涉及的"剖腹生产择吉"内容属于命理文化现象的记录与讨论。**任何生育相关的医疗决定，必须以产科医生的专业意见为唯一依据**，择吉不作任何医学建议，也不构成选择分娩方式的理由。

### README_2 三条硬纪律

| 纪律 | 内容 | 违反的后果 |
| --- | --- | --- |
| **大煞避之，中煞制之，小煞不必制** | 神煞分三等处理，不是见凶就躲 | 见凶即避，一年三百六十日几无可办之日；见凶不避，大煞无制反噬更烈 |
| **以事为纲，以神为目** | 先定办什么事、谁办、在哪儿办，再看神煞 | 脱离用事空谈吉日，吉日也可能冲主命 |
| **吉足胜凶则从宜，凶胜于吉则从忌** | 取舍有明确的总原则，不是凭感觉 | 凭感觉取舍，等于没有标准 |

## 板块0 · 学习路径和建议

> 学择吉最常见的挫败有两种：一种是**记了两百多个神煞名字，拿到日子还是不会选**；另一种是**翻开三本通书，发现三本说的都不一样，于是彻底放弃**。
>
> 本篇先解决这两件事：择吉到底在算什么、它和命理风水怎么分工、以及按什么顺序下功夫。

---

### 0_1 学习路径：五步走

```
第1步 · 板块1（坐标）
   历法、干支、节气、月建
   过关标准：给一个公历日期，能推出年月日时四柱与月建、节气在不在月内

第2步 · 板块2—4（神煞）
   年神月神 → 日神时神与建除黄黑道 → 凶煞分级
   过关标准：能给任意一天列出"年/月/日/时"四层主要神煞，并标出轻重等次

第3步 · 板块5—6（取舍）
   制煞化煞 → 补龙扶山相主
   过关标准：面对一个具体用事，能说出"这个煞该避、该制还是可以不理"

第4步 · 板块7—8（成课）
   日课四柱成格 → 分类择日
   过关标准：能排出一课四柱，并说明它为什么成格、为什么适合这件事

第5步 · 板块9—14（致用）
   造命与边界 → 通书怎么读 → 派别地图 → 书目 → 自检与速查
```

**不要跳到第 4 步。** 绝大多数"会择日"的误区，都是因为跳过了第 2、3 步，直接拿通书的"宜忌"当结论。

### 0_2 使用建议与边界声明

这三条是从《协纪辨方书》一路下来的官方口径，必须背下来：

| 原则 | 原文口径 | 白话 |
| --- | --- | --- |
| **以事为纲，以神为目** | 先定用事，再查神煞 | 事没定清楚，神煞无从取舍 |
| **吉足胜凶，从宜不从忌** | 吉能压过凶，按"宜"办 | 不必因小凶而废大吉 |
| **吉不抵凶，则从忌不从宜** | 吉压不过凶，按"忌"办 | 也不要因小吉而犯大凶 |

补一条实操中更常用的分级口诀：

> **大煞避之，中煞制之，小煞不必制。制煞不如化煞，化煞不如避煞。**

**边界声明（三条）**：

1. **性质**：择吉属古人“顺时而动”的经验系统与民俗整理，日课吉凶属传统象数话语，未经现代科学检验；本库只作口径引录与取舍演示。
2. **效力**：它不能改变事件的客观结果，只能就“何时宜动、何时宜静”给出传统口径下的取舍建议。
3. **用途**：不构成医疗、法律、金融、工程与安全等专业判断的替代；生育相关决定尤须以产科医生的意见为唯一依据（详见 `README_1 使用声明`）。

### 0_3 择吉在算什么

择吉的输入与输出非常清楚：

```latex
输入：一件要办的事 + 办事的人（生辰）+ 办事的方位/山向
      ↓
加工：查这一天的年/月/日/时四层神煞，
      看它们与"事、人、方"是冲是合、是扶是克
      ↓
输出：这个时空点"宜 / 忌 / 权宜可用"，
      以及可用的话要注意什么
```

**择吉的核心不是"选一个好日子"，而是"选一个与你的人、你的事、你的方位相匹配的日子"。** 同一个"黄道吉日"，对甲是吉、对乙可能就是冲——这是择吉与"翻黄历"最本质的区别。

### 0_4 择吉与八字、风水的分工

| 维度 | 八字（命） | 风水（相） | 择吉（择） |
| --- | --- | --- | --- |
| **问的问题** | 我是什么格局、哪步运好 | 这个地方好不好、怎么布置 | 什么时候办这件事合适 |
| **输入** | 出生年月日时 | 山川形势、宅向方位 | 事 + 人 + 方 + 年月日时 |
| **时间尺度** | 十年一大运、一年一流年 | 二十年一运（三元九运） | 一日一时 |
| **能否改变** | 不能改命 | 可调整 | **可主动选择**（这是择吉唯一的优势） |

三者是**接力关系，不是竞争关系**：

```
八字告诉你"你是什么"
风水告诉你"在哪儿办"
择吉告诉你"什么时候办"
```

> **最容易搞混的一点**：择吉不预测吉凶。它做的是**匹配**——把这个时空点的干支五行，与人的八字、事的五行属性、方位的山向做匹配。匹配得好叫"吉课"，匹配不好叫"凶课"，中间地带有大量"可用但须注意"的课。

### 0_5 择吉的三层结构

把择吉拆成三层，学的时候一层一层装：

| 层 | 内容 | 作用 | 主讲板块 |
| --- | --- | --- | --- |
| **第一层 · 坐标** | 历法、干支、节气、月建 | 没有这一层，日子都定位不准 | 板块1 |
| **第二层 · 神煞** | 年月日时四层神煞、建除、黄黑道 | 给每个日子贴上"标签" | 板块2—5 |

### 0_6 新手的三个坑

| 坑 | 表现 | 怎么避 |
| --- | --- | --- |
| **坑一：拿通用黄历当择吉** | 翻手机黄历看到"宜嫁娶"就定日子 | 通用黄历只处理"日神"层，不处理人的八字与方位；真正的择课必须落到"人" |
| **坑二：见凶即避** | 一看到凶煞名目就换日子 | 神煞分三等。**大煞避之，中煞制之，小煞不必制**，有吉星同到自能压伏（详见板块4） |
| **坑三：混用派别** | 丛辰家的煞配上奇门的时，再加天星的宿 | 各家体系自洽，混用则不伦不类。先选定一家，贯通之后再旁参（详见板块11） |

### 0_7 案例小故事：三本通书，三个答案

有位朋友要为家里老人做寿宴，翻了三本黄历，得到三个答案：

- A 本：宜宴会
- B 本：忌宴会
- C 本：诸事不宜

他来问，哪本对。

我让他先别急着选日子，先回答三个问题：

```
第1问：办的是什么事？
   → 寿宴，属于喜庆聚会，不是嫁娶，也不是营造

第2问：谁办？老人的生年是什么？
   → 他报了老人的生年干支

第3问：在哪儿办？有没有方位讲究？
   → 家里院子，坐向大致清楚
```

三个问题一答完，分歧立刻缩小了：三本通书的差异，主要出在**它们各自采用的神煞体系不同**——有的重建除，有的重黄黑道，有的重二十八宿。而这三套只有在"事、人、方"都确定的前提下才能比较优劣。

按本库的取舍链走：

1. **先避大煞**：查该日是否犯岁破、三煞、月破——不犯，可用；
2. **再看主命**：该日日支与老人生年不冲不刑——合；
3. **再看用事**：寿宴属喜庆，取天德、月德、天恩、成日、开日之类——该日得月德，可用；
4. **最后看时**：选一个不犯日破、不犯五不遇时的时辰。

至于那本写"诸事不宜"的 C 本，它采用的是另一套更严格的小煞口径——按"小煞不必制"的原则，**可以放下**。

**这件事说明两件事**：一是择吉的输入从来不只是"日子"，而是**事 + 人 + 方 + 日时**四件套；二是碰到不同说法打架，正确的做法不是二选一，而是**回到"以事为纲、分级取舍"这条链上重走一遍**。

### 0_8 笔记与验证

建议固定三张表：

```
【出课登记表】
用事 / 主事人生年 / 方位山向 / 年月日时四柱 / 避开了什么 / 取了什么吉 / 断语

【回填表】
事后实际情况 / 有无不顺 / 哪条规则成立、哪条落空 / 备注

【口径表】
术语或神煞 / 本库取法 / 我见到的另一说法 / 出处 / 是否影响取舍
```

**第二张表是关键。** 择吉的反馈周期比占卜长（以月、年计），但不回填就等于没有验证。半年后回看一次：如果"哪条规则成立"一栏几乎全空，说明你只是把流程走完了，没有真正验证过。

> **边界提醒**：任何涉及医疗（尤其是生育与手术）、法律、重大财务与工程安全的决定，一律以专业意见为准。择吉只作文化与心理层面的参考，不承担决策责任。

## 板块1 · 坐标系统：历法、干支、节气与月建

> 择吉的第一步不是查神煞，是**把日子定位准**。同一天，用公历、农历、干支历来读，会得到三个不同的"年"和"月"，神煞也就跟着全变。
>
> 本篇只做一件事：校准择吉所用的时间坐标，并指出四个最容易出事故的坐标错误。坐标错一层，后面全部作废。

---

### 1_1 三种历法，择吉只认其中一本

| 历法 | 基准 | 岁首 | 月首 | 择吉中的角色 |
| --- | --- | --- | --- | --- |
| **公历**（阳历） | 太阳回归年 | 1 月 1 日 | 每月 1 日 | 只作为输入格式与节气换算的起点，**不参与推算** |
| **农历**（阴阳合历） | 朔望月定月，闰月协调回归年 | 正月初一 | 朔日（初一） | 民俗层面沿用；**择吉推算不以它的月份为干支月** |
| **干支历**（节气历） | 二十四节气 | 立春 | 交节日 | **择吉推算以此为准，全部神煞建立在它之上** |

为什么必须是干支历：神煞的本质是五行在时空中的状态（详见板块2），而干支月的五行属性由节气决定——寅月之所以属木，是因为它从立春起、到惊蛰止，是阳气初生、木气当令的那一段。农历的"四月"是朔望月，与木火金水的当令毫无对应关系，拿它配三合局、配月德，必然错位。

> **一句话记住**：**择吉用干支历，以节气为月界，不是农历初一。** 日常说"看日子"用农历，是民俗；动手排课，一律先换算到干支历。

### 1_2 干支的来路：四种纪法不是同时出现的

干支不是一次性发明的一套东西，纪年、纪月、纪日、纪时各有各的起点，越往后越晚：

| 单位 | 起点 | 说明 |
| --- | --- | --- |
| **纪日** | 殷商已通行；公认连续不断的起点是春秋鲁隐公三年（公元前 720 年）二月己巳日食 | 六十日一周，两千七百余年未中断 |
| **纪年** | 东汉建武三十年（公元 54 年）起官方正式施行 | 此前用岁星纪年、太岁纪年；太岁之名即由此转入择吉，成为年神之首 |
| **纪月** | 十二支纪月（月建）始于先秦；十干配月完整化较晚 | 十干配月靠"五虎遁"从年干推出，见 1_4 |
| **纪时** | 十二辰分昼夜汉代已成体系；**以十干配十二支完整纪时最晚，唐代以后才定型** | 十干配时靠"五鼠遁"从日干推出，见 1_4 |

```latex
纪日（最早，殷商）
     ↓ 加岁星/太岁系统
纪年（东汉建武三十年，54 年）
     ↓ 十二支纪月早已存在，十干配月后补
纪月（五虎遁）
     ↓
纪时（最晚，唐代定型，五鼠遁）
```

这段来路有个实用含义：纪时定型最晚，说明**时辰这一层在古典择吉里的权重本来就是最低的**。后世通书把"吉时"抬得很高，与这个历史次序并不相合（详见板块3）。

### 1_3 六十甲子

十天干：甲、乙、丙、丁、戊、己、庚、辛、壬、癸
十二地支：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥

十与十二的最小公倍数是六十，阳干配阳支、阴干配阴支，故成六十甲子，不至于一百二十。六十甲子既是纪时单位，也是**纳音与五行属性的载体**——这一点在制煞时要用（年克山家用纳音，详见板块5）。

```latex

甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未
甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳

```

**旬与空亡**：六十甲子分六旬，每旬十日，旬内有两个地支轮空，即空亡。甲子旬中戌亥空，甲寅旬中子丑空，依此类推。空亡在择吉里主要用于判断神煞有无着力点（吉神落空则其力减，凶煞落空亦减）。

### 1_6 月建：月支随节气换，不随初一换

**月建**就是当月的地支。正月建寅、二月建卯，故称"建"。规则只有一条：

> **从立春起入寅月，每过一个"节"换一个月支。与农历初一无关，与闰月无关。**

闰月不另设月建。逢闰四月，该月仍按节气所处的月支（巳月）计算，不因为是"闰"而多出一个支。

```latex
农历日期 ──查当年交节时刻──> 落在哪个节之后 ──> 定出月支
                                                  ↓
                                        月建定 → 五虎遁配天干 → 月柱
                                                  ↓
                                        建除、月德、月煞、月三煞全部由此起
```

月建在择吉里至少管四件事，链条是这样串下来的：

| 由月建起的东西 | 用途 | 主讲 |
| --- | --- | --- |
| 月柱干支 | 四柱之一，扶山相主要看它 | 板块6、7 |
| 建除十二神的起点 | 月建之支上起"建" | 板块3 |
| 月德、月德合 | 三合局本气之阳干 | 板块2 |
| 月煞、月刑、月害、月破 | 月家凶煞 | 板块2、4 |

### 1_7 节气交接时刻、子时换日与真太阳时

节气是**太阳到达某一黄经的瞬间**，是一个精确时刻，不是一整天。比如某年立春在 2 月 4 日 10 时 42 分，那么此前一分钟仍属丑月，此后一分钟已入寅月。

**四个必须明确的口径**：

| 问题 | 争议 | 本库处理 |
| --- | --- | --- |
| 交节当天算哪月 | 按整天算还是按时刻算 | **按时刻算**。交节时刻之前属前月，之后属后月 |
| 子时换日 | 23 点即换日，还是 0 点（子正）换日 | 见下方口径说明 |
| 用北京时间还是地方时 | 东经 120° 平太阳时 vs 当地真太阳时 | 见下方口径说明 |
| 真太阳时（均时差） | 是否再加均时差修正 | 择吉一般不加；天星、七政四余派另计 |

> **口径说明（子时）**：一派主张 23 点即入次日，换日即换干，通书多从此；另一派主张以 0 点（子正）为界，23 点至 1 点为"夜子时"，天干仍用当日。**本库取"23 点换日、换日即换干"的通行做法**，但在 23 点前后出课，必须在课单上注明所用口径。

> **口径说明（地方时）**：通书、黄历一律按北京时间（东经 120° 平太阳时）排。经度每偏西 1°，地方时晚约 4 分钟；乌鲁木齐与北京相差约 2 小时，拉萨约 1 小时 40 分。**本库处理**：节气与月建用官方北京时间为准（便于与通书互校），但**日柱的换日按当地地方时复核**——在西部省份，北京时间 23 点半出生或行事，当地实际尚未到子时，日柱可能仍属前一日。

### 1_8 五组基础关系：择吉的运算符号

后面的三煞、月破、阴府、官符，全部由这五组关系推出来。先记住，再谈神煞。

| 关系 | 内容 | 择吉中的用处 |
| --- | --- | --- |
| **三合局** | 申子辰水、亥卯未木、寅午戌火、巳酉丑金 | 三煞、月德、驿马、制煞三合局，全靠它 |
| **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 不将日、六合日、合煞 |
| **六冲** | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 岁破、月破、日破，冲主命为大忌 |
| **三刑** | 无恩之刑寅巳申、恃势之刑丑戌未、无礼之刑子卯、自刑辰午酉亥 | 冲之外的一层伤害，刑轻于冲 |
| **六害** | 子未、丑午、寅巳、卯辰、申亥、酉戌 | 相害主暗损、阻隔，择吉中忌害主命 |

三合局的另一个用处：**三煞方 = 与该年三合局相冲的那个三合局所占之方**。申子辰水局，与之相冲的是寅午戌火局（南方），故申子辰年三煞在南（详见板块2）。

#### 旺相休囚与十二长生：判断"有没有根"

择吉里判断一个神煞、一个制神有没有力，用的是这两把尺子。

**旺相休囚死**（一律以月令为准）：与月建同五行为**旺**，月建所生为**相**，生月建者为**休**，克月建者为**囚**，月建所克者为**死**。

| --- | --- | --- | --- | --- | --- |
| 木 | 亥 | 卯 | 未 | 午 | 申 |
| 火 | 寅 | 午 | 戌 | 酉 | 亥 |
| 金 | 巳 | 酉 | 丑 | 子 | 寅 |
| 水 | 申 | 子 | 辰 | 卯 | 巳 |
| 土 | 寅 | 午 | 戌 | 酉 | 亥 |

#### 案例小故事：一个"巳月"，排错了三张表

有位朋友的亲戚要修灶，他自己在手机上排了个日子，跑来让我复核。他报的是"农历四月初八，巳月，月德在庚"，要取庚日。

我做的第一件事不是看他选的庚日对不对，而是问他：**那年立夏是农历几号？**

他愣了一下，说"四月不就是巳月吗"。我把日历调出来：那年闰二月，导致农历整体后移，立夏落在农历四月十二。**四月初八还在清明之后、立夏之前，是辰月，不是巳月。**

一个月的差别，连锁错了三张表：

```
第1错 · 月建：辰月（不是巳月），月柱天干随之改变
第2错 · 月德：申子辰月在壬，他按巳月取庚（巳酉丑月在庚），取错了
第3错 · 月三煞：随月建而变，他要动工的方位恰好落在辰月的煞方上
```

他自己只核对了"日神"那一层（庚日、成日、黄道），完全没过"月建"这一关。更要紧的是第三条：修灶属动土修方，月家煞方比日神紧要得多（分级次序详见板块4）。

**后来怎么处理的**：把日子推到立夏之后，重新按巳月排月柱、重取月德，方位避开该月煞方。同一件事，改的只是"往前挪四天"。

**复盘**：他出错的根源不是不懂神煞，而是**跳过了坐标层直接查神煞**。农历月份和干支月份在多数年份里大致重合，正因为大致重合，错了也不容易被发现——只有闰月年、或者节气恰好卡在月中的日子，才会暴露出来。

**落点**：拿到任何一个日子，先做一步不可逆的动作——查出它在哪个节之后，把月支写下来，再去查神煞。月支没写下来，后面查什么都是空中楼阁。

## 板块2 · 神煞学（上）：年神与月神

> 神煞不是住在天上的某位神灵，它是**五行在特定时空条件下所呈现的变化状态，被冠以的一个名称**。这一点没想清楚，学神煞就变成了背名单。
>
> 本篇讲年神与月神两层——它们是择吉里分量最重的两层。日神时神见板块3，凶煞分级见板块4。

### 2_1 神煞的本质：名号，不是实体

《协纪辨方书》立下的一条根本口径，必须原样记住：

> **论命论课，必先之以五行生克，次论神煞吉凶，以较量祸福之轻重而已。**

这句话拆成三层：

| 层 | 含义 |
| --- | --- |
| **第一层：五行生克** | 决定"有没有、成不成"，是主引擎 |
| **第二层：神煞吉凶** | 只做"较量祸福之轻重"，是加权项 |
| **次序不可颠倒** | 课体五行已经破了，再多吉神也救不回来 |

所以神煞的正确用法是：**先看这一课的干支五行、这一方的山向五行、这个人的年命五行是不是相合，再拿神煞来加减分。** 反过来，一上来就拿神煞清单去套日子，是绝大多数初学者走错的第一步。

```latex
五行生克（主） → 神煞加减（从） → 轻重分级（判） → 制化或避让（断）
```

### 2_2 四大系统与力量层级

神煞按周期分年、月、日、时四层，力量依次递减：

| 系统 | 辖期 | 力量 | 主要影响 | 主讲 |
| --- | --- | --- | --- | --- |
| **年神** | 一年 | 最大 | 方位（坐山、朝向）、一年之大局 | 本篇 |
| **月神** | 一月 | 次之 | 修方、动土、营造的当月宜忌 | 本篇 |
| **日神** | 一日 | 再次 | 用事当日的宜忌 | 板块3 |
| **时神** | 一时辰 | 最轻 | 落成的那一刻 | 板块3 |

为什么年神最大：**它管的时间最长，且多数落在"方"上**。年神不挑日子，它一年到头停在某几个方位上，你只要在那一年动那个方位，就撞上了。日神只在某一天起作用，时神只在两个小时内起作用——躲得开。

> **由此得出一条实操原则**：**先看年、月两层的大煞在不在你那个方位上**。这两层过关了，再谈日时。顺序颠倒，会出现"挑了个黄道吉日，却正好坐三煞"的荒唐结果。

### 2_4 太岁本身并无吉凶

这是年家最要紧的一条，也是民间误解最深的一条。

> **太岁者，岁之君也。其本身并无吉凶：叠吉星则吉，叠凶星则凶。**

```latex
太岁 + 岁德/岁支德/博士/奏书  →  吉，可修可坐
太岁 + 岁破/三煞/白虎/大耗      →  凶，避之
太岁 + 无吉无凶                →  平常，可坐不可向
```

民间的两句话——**"若要贵，修太岁"**与**"太岁头上不可动土"**——并不矛盾。前者说太岁叠吉神时修之可得贵气，后者说太岁叠凶神时动之必招祸。判断的关键不在"是不是太岁方"，而在**太岁这一方上叠的是什么**。

配套的一条方位原则，两句要连着记：**太岁可坐不可向，三煞可向不可坐。**

| 神 | 坐 | 向 |
| --- | --- | --- |
| 太岁 | **可坐**（坐之得岁君之气） | 不可向（向之如面君而争） |
| 三煞 | 不可坐（坐之受肃杀之气） | **可向**（向之为我之气所向） |

### 2_5 三煞：绝、胎、养三位

三煞由**劫煞、灾煞、岁煞**三者合于一方而成，来源是三合五行局的**绝、胎、养**三位。

| 年支三合局 | 劫煞（绝位） | 灾煞（胎位） | 岁煞（养位） | 三煞方 |
| --- | --- | --- | --- | --- |
| 申子辰（水局） | 巳 | 午 | 未 | **南方** |
| 寅午戌（火局） | 亥 | 子 | 丑 | **北方** |
| 亥卯未（木局） | 申 | 酉 | 戌 | **西方** |
| 巳酉丑（金局） | 寅 | 卯 | 辰 | **东方** |

推导（以申子辰水局为例）：水长生在申，顺行十二长生，至巳为绝、午为胎、未为养。绝胎养是五行之气最微弱、最不稳定的三段，古人认为这三段上蕴着肃杀之气，故列为煞。

```latex
水局：长生申 →（顺行十二位）→ 墓辰 → 绝巳 → 胎午 → 养未
                              ↑      ↑      ↑
                            劫煞   灾煞   岁煞   （合为南方三煞）
```

**一条更快的记法**：**三煞方 = 与该年三合局相冲的那个三合局所占之方**。申子辰水局，相冲的是寅午戌火局，火在南方，故三煞在南。四句口诀就是这么来的：

> 申子辰年煞在南方巳午未，寅午戌年煞在北方亥子丑，
> 亥卯未年煞在西方申酉戌，巳酉丑年煞在东方寅卯辰。

三煞的分量：**它是年家第一等大煞，属"避"不属"制"**（详见板块4、5）。造葬、修方、动土，坐山犯三煞为大忌，向方犯之则轻。

### 2_6 五黄与戊己都天

**五黄**：九宫飞泊中的中宫之星，属土，为九星中最凶。年五黄飞临之方宜静不宜动——不动土、不修造、不安床、不开大门，动则主灾病凶死。与三煞、岁破并列为年家大凶之方。

**戊己都天**：取法为**以年干起五虎遁，顺数至戊、己所配的地支，即戊己都天之方**。戊己属土，气重浊，所临之方忌修造动土，犯之主损人丁、退财。

| 年干 | 五虎遁起月 | 戊所临支 | 己所临支 | 都天方 |
| --- | --- | --- | --- | --- |
| 甲、己 | 丙寅 | 辰 | 巳 | 东南 |
| 乙、庚 | 戊寅 | 寅 | 卯 | 东 |
| 丙、辛 | 庚寅 | 戌 | 亥 | 西北 |
| 丁、壬 | 壬寅 | 申 | 酉 | 西 |
| 戊、癸 | 甲寅 | 午 | 未 | 南 |

例如丁年，丁壬起壬寅，顺推至申月得戊申、酉月得己酉，故丁年都天在申酉（西方），该年西方忌动土。五虎遁推法见板块1。

#### 案例小故事：坐山与向方，差一个字

有位熟人给父亲择安葬地，找了位先生看好一处，定的坐向是**午山子向**（坐南向北）。那年是子年，我一看年支就问他：这一局你打算怎么过三煞。

他没反应过来。我给他排：

```
子年 → 申子辰水局 → 三煞在南方巳午未
他定的坐山是午 → 坐山正在三煞方 → 坐三煞（大忌）
同年太岁在子 → 向方是子 → 向太岁（太岁可坐不可向）
```

一个坐向，同时犯了两条：**坐了三煞，又向了太岁**。

他回去跟先生吵了一架，先生说"我看了通书，这日子是吉日"。问题恰恰在这——**通书写的是"日"，犯的是"年"和"方"**。日神再吉，也压不住年家坐山犯三煞。

后来改的方案很简单：**坐子向午**。太岁在子，坐之即为"坐太岁"——可坐不可向，反而得岁君之气；三煞在南方午位，此时落在"向"上——可向不可坐。两个问题一并解决，一字未改，只是调了方向。

他还有一层犹豫：民间有句"若要发，修三煞"，他问是不是该硬上。我的回答是：**这句话在择吉界内确实流传，但它不属于《协纪辨方书》一系的官方口径，且历来争议极大**（本库的态度见板块5）。造葬是大事，大事从严，不该拿一句民间俗语去压一件不可逆的事。

**复盘**：他前后请了两拨人，第一拨只看了日神，第二拨看了年神与方位。差别不在谁记的神煞多，而在**有没有按"年、月、日、时"这个次序往下走**。年神那层没过关，后面三层做得再细也是白做。

**落点**：拿到一个坐向，先问两句话——这一年的太岁在哪一支？三煞在哪一方？这两句答不上来，日子就不用看了。

## 板块3 · 神煞学（中）：日神、时神与建除黄黑道

> 年神月神管的是"这一年、这一月、这一方"，落到具体的某一天某一时，靠的是日神、时神，以及两套最容易搞混的日历标签——**建除十二神**与**黄道黑道**。

> 本篇是日常翻黄历、挑日子时真正用得上的一层。但要记住：这一层在四层系统里排第三、第四，**它能微调，不能翻案**。

| **归忌** | 主出门难归 | 忌出行、回门、远行 |
| **死神** | 主死丧 | 忌问病、安葬 |
| **孤辰** | 主孤 | 忌嫁娶 |
| **往亡** | 主去而不返 | **忌出行、赴任、求财、出兵** |
| **大败** | 主破败 | 忌开市、求财、立券 |
| **咸池** | 桃花煞，主淫佚 | 忌嫁娶、忌正经大事 |
| **行狠、了戾** | 主遭凶狠、乖戾不和 | 忌出行、交涉 |
| **反支** | 主反复 | 忌上表、陈情、出行 |

> **一条通用判据**：日神恶者分两类。一类是"**忌特定事**"（八风忌行船、血忌忌针刺、五离忌嫁娶），一类是"**诸事不宜**"（四废、四绝、致死）。前者只要避开对应用事即可，后者才需要换日。混为一谈，会导致一年里几乎无日可用。

### 3_3 天赦日与四组"四"

**天赦日**：春戊寅、夏甲午、秋戊申、冬甲子。

天赦是日家最特殊的一个吉日，其取法是**四季的"干支同气而生"之日**：春木旺，戊寅（寅为木之禄地，戊土受生）；夏火旺，甲午；秋金旺，戊申；冬水旺，甲子。天赦主**赦过宥罪、解冤释结**，古人用于上表章、修造、祈福、化解旧怨。

| 组 | 内容 | 性质 |
| --- | --- | --- |
| **四绝** | 立春、立夏、立秋、立冬的**前一日** | 四时之气断绝，诸事忌 |
| **四离** | 春分、秋分、夏至、冬至的**前一日** | 阴阳分离，诸事忌 |
| **四废** | 春庚申辛酉、夏壬子癸亥、秋甲寅乙卯、冬丙午丁巳 | 当令五行所克之干支，气废无用 |
| **四忌、四穷** | 四时穷尽之日（日辰见板块14） | 主贫穷无成 |

四废的取法逻辑值得记住：**以该季第一个月的地支为准，看哪一五行"绝"于此支**——绝者气尽，故名为废。春自寅月起，金绝于寅，故春月金废（庚申、辛酉）；夏自巳月起，水绝于巳，故夏月水废（壬子、癸亥）；秋自申月起，木绝于申，故秋月木废（甲寅、乙卯）；冬自亥月起，火绝于亥，故冬月火废（丙午、丁巳）。

### 3_4 建除十二神

**建、除、满、平、定、执、破、危、成、收、开、闭**，十二神循环。

**起例**：以月建之支为"建"，顺行十二辰。即**日支与月支相同者为"建"，次日为"除"，依次顺推**。举例：寅月（立春后）见寅日为建、卯日为除、辰日为满，至丑日为闭，下一个寅日又为建。

| 神 | 常见取用 | 备注 |
| --- | --- | --- |
| **建** | 一月之首；宜上任、出行、求官；忌动土、开仓 | 各家取用不一 |
| **除** | 除旧布新；宜扫舍、疗病、出行 | |
| **满** | 圆满亦主溢；宜开市、祈福；**忌服药**（满日服药病不愈） | |
| **平** | 平稳；宜铺路、行船、修饰墙垣 | |
| **定** | 安定；宜定盟、入学、安床；忌出行、词讼 | |
| **执** | 执守、捕捉；宜捕捉、造屋；忌开市交易 | |
| **破** | 冲破，凶；宜破屋坏垣；**忌嫁娶、开市、出行** | 月破即此位 |
| **危** | 危险；忌登高、行船 | 亦有以危日安床为吉者 |
| **成** | 成就，吉；宜开市、嫁娶、入学、动土 | 最常用 |
| **收** | 收获；宜纳财、进人口、栽种；忌出行安葬 | |
| **开** | 开通，吉；宜开市、入学、动土、求医 | 最常用 |
| **闭** | 闭塞；宜筑堤、安葬、埋穴；忌开市出行 | |

> **口径说明（一）**：建除的吉凶**各家取用不一**。《协纪辨方书》按十二神各自所宜逐条分列，并不作简单的"吉/凶"二分；民间通书则常简化为"成、开、定、危"为吉，"破、闭、收、满"为凶。**本库取《协纪》一系：按用事逐条对照，不以吉凶二字概括。**

> **口径说明（二）**：建除的排法有两套。一是**支对应法**（日支与月支同者为建，顺行），本库用此；二是**日序法**（自交节日起顺排十二辰），遇节气交界则**重复一日**。两套在多数日子结果一致，个别日期会差一位。采用日序法者须留意：节气当天要查出交节时刻，落在前月还是后月，差一天就整月错位（月界定法见板块1）。

### 3_5 黄道黑道

黄道黑道是另一套十二神，与建除**不是一回事**。

| 类别 | 六神 | 吉凶 |
| --- | --- | --- |
| **黄道六神** | 青龙、明堂、金匮、天德、玉堂、司命 | 吉 |
| **黑道六神** | 白虎、天刑、朱雀、天牢、玄武、勾陈 | 凶 |

十二神的固定次序（从青龙起顺行）：

```latex
1 青龙（黄）  2 明堂（黄）  3 天刑（黑）  4 朱雀（黑）
5 金匮（黄）  6 天德（黄）  7 白虎（黑）  8 玉堂（黄）
9 天牢（黑） 10 玄武（黑） 11 司命（黄） 12 勾陈（黑）
```

**起例（时家）**：以日支定青龙起于何时，顺行十二神。

| 日支 | 青龙起时 | 日支 | 青龙起时 |
| --- | --- | --- | --- |
| 子、午 | 申时 | 卯、酉 | 寅时 |
| 丑、未 | 戌时 | 辰、戌 | 辰时 |
| 寅、申 | 子时 | 巳、亥 | 午时 |

**起例（日家）**：以月支定青龙起于何日，顺行十二神。

| 月支 | 青龙起日 | 月支 | 青龙起日 |
| --- | --- | --- | --- |
| 寅、申 | 子日 | 巳、亥 | 午日 |
| 卯、酉 | 寅日 | 子、午 | 申日 |
| 辰、戌 | 辰日 | 丑、未 | 戌日 |

用法举例：寅月，青龙起于子日，则子日为青龙（黄道）、丑日为明堂（黄道）、寅日为天刑（黑道）、卯日为朱雀（黑道）、辰日为金匮（黄道），依此顺推即可。

> **口径说明（三）**：黄道黑道的起例，各通书有以"寅月起青龙于子"者，亦有他法。**本库采用上表（青龙起于"月支退二位"）的通行排法**，选定后固定使用，不在同一课中混用两套。

### 3_6 建除与黄黑道：两套标签，不要混为一谈

```latex
建除十二神：建 除 满 平 定 执 破 危 成 收 开 闭   （按月建之支顺行）
黄黑道十二神：青龙 明堂 天刑 朱雀 金匮 天德 白虎 玉堂 天牢 玄武 司命 勾陈
              （按月支或日支起青龙顺行）

两者是两套独立的排法，同一天可以既是"开日"又值"天牢（黑道）"
```

| 混用方式 | 表现 | 后果 |
| --- | --- | --- |
| **把"开日"当成"黄道吉日"** | 见"开"字就以为黄道 | 可能撞上黑道六神 |
| **把黄黑道当建除用** | 用青龙明堂去判断宜忌条目 | 黄黑道只分吉凶，不分宜忌 |
| **两套取吉叠加** | 既要成日又要青龙日 | 条件过窄，一年无几日 |

> **本库的处理**：建除用它的**宜忌条目**（哪神宜什么事），黄黑道用它的**吉凶属性**（黄道可作加分，黑道作减分）。两者并列参照，不互相替代。

### 3_7 时神：最后一层，只做微调

时神以日干支起例，作用时间只有两个小时，是四层里最轻的一层。

### 3_8 常见错

| 错 | 表现 | 后果 |
| --- | --- | --- |
| **建除与黄黑道混为一谈** | 见"开""成"就当黄道吉日 | 撞黑道而不自知 |
| **把时神当主力** | 用吉时去救凶日 | 日课不成立，吉时白取 |
| **只看日不看年** | 翻黄历见"宜"就定 | 日吉而犯岁破三煞 |
| **建除重复日漏算** | 交节日未重算 | 全月错位一位 |
| **日神恶者一概当凶** | 见"血忌"就换日 | 血忌只忌针刺，与开市无关 |

> **边界提醒**：本板块涉及"天医""血忌""求医服药"等条目，属于传统历法文化的记录。**任何医疗决定（手术时间、服药、针灸、分娩）一律以执业医师的专业意见为准**，择吉不作医学建议，也不构成选择治疗时机的理由。

#### 案例小故事：通书写"宜开市"的那一天

一个开便利店的朋友要定开业日，自己翻手机黄历挑了一天，兴冲冲跑来告诉我："你看，开日，宜开市，还是吉日。"

我问了他三个问题，一个比一个难回答。

**第一问：你属什么？** 属鸡，酉年。而那一天的日支是卯——**卯酉相冲，日支冲主命**。这是择吉里最基础的一条：日子再好，冲了办事人的本命，就等于把课建在别人的对立面上。

**第二问：你打算几点开门？** 他说上午九点开业，图个吉利。九点到十一点是巳时，问题不大；但他接着说要提前在**酉时（17-19 点）**摆货试营业、正式通电。酉时正是当日的**日破时**（日支卯，冲在酉）。

**第三问：那天值什么黄道？** 他说"开日不就是黄道吗"。我按 3_5 的起例排：那个月青龙起于某日，顺推到他选的这一天，值的是**天牢**——黑道六神之一。他以为"开日"等于"黄道吉日"，正是把两套标签当成了一套。

```
他掌握的：开日（建除）  +  宜开市（通书宜忌）
他漏掉的：日支卯冲主命酉  +  酉时犯日破  +  当日值天牢（黑道）
          ↑ 年、日、时三层各漏一项
```

**后来的处理**：把日子推后三天，换了一个与主命不冲、日支与月支相合的日子，正式营业改在巳时，酉时只做内部整理不通电。改动很小，但三层都对上了。

**复盘**：他手里的信息其实不算错——那天确实是"开日"，通书确实写"宜开市"。问题在于**通用黄历只处理"日神"这一层，它不知道办事人属什么，也不知道你要几点开门**。日神那层给出的"宜"，是脱离人、脱离时的宜。择吉真正要做的，是把年、月、日、时四层串起来，再与"人"对一遍（取舍次序详见板块4）。

**落点**：看到通书写"宜"，先别高兴，先补两句——这一日支冲不冲我？我要用的那个时辰，是不是这一日的日破时？这两句补上，比多背一百个神煞名目管用。

## 板块4 · 神煞学（下）：凶煞体系与轻重层级

> 择吉里最要命的两个毛病，一是**见凶即避**——一年三百六十日几无可办之日；二是**见凶不避**——大煞无制，反噬更烈。两个毛病同源：不知道煞有轻重。
>
> 本篇就是那把尺子：凶煞分三等，取舍分四级，用事分宽严。

---

### 4_1 三等分法：大煞避之，中煞制之，小煞不必制

《协纪辨方书》一系的官方口径，把神煞按轻重分为三等：

| 等次 | 代表神煞 | 处置原则 |
| --- | --- | --- |
| **大凶** | 岁破、三煞、大将军、重丧 | **大凶宜远避，不可轻言制化** |
| **中煞** | 阴差阳错、四离四绝 | **中煞审事之轻重** |
| **小忌** | 三娘煞、杨公忌、龙虎俗忌 | **有吉星同到即可压伏** |

三等分法的依据不是"名气大小"，而是三条更硬的标准：

| 标准 | 大煞 | 中煞 | 小煞 |
| --- | --- | --- | --- |
| **所本** | 天地之气（三合局、太岁、九宫） | 干支运算所得 | 民间俗传、历家附会 |
| **能否计算** | 可精确推导，各家一致 | 可推导，起例略有出入 | 多无五行依据 |
| **能否制化** | 只能避，不能制 | 可制，但要看月令 | 不必制，吉星同到即解 |

```latex
凶煞来袭
   ├─ 大煞（岁破、三煞、五黄、戊己都天、重丧）→ 避
   ├─ 中煞（大小月建、阴府、官符）            → 审事之轻重，可制
   └─ 小煞（俗传忌日）                        → 有吉星同到即可放下
```

> **最实用的一句话**：分辨一个煞属于哪一等，最快的方法是问——**它能不能从干支、三合、九宫里推出来**。推得出来的是体系内的煞，推不出来、只靠口诀流传的，多半是俗忌。

---

### 4_2 大神煞：只能避，不能制

四位年家大煞，逐个记住它们落在哪里、犯之主何：

| 煞 | 所在 | 犯之主何 | 本库处置 |
| --- | --- | --- | --- |
| **三煞** | 年三合局之绝胎养三方 | 损人丁、官非横祸 | 坐山犯之必避；向方犯之较轻 |
| **岁破** | 太岁之冲方 | 破败、伤主 | 避，不谈制 |
| **五黄** | 九宫飞泊，年五黄所临之方 | 灾病、凶死 | 该方当年不动土、不修造、不开门 |
| **戊己都天** | 年干五虎遁至戊己之方 | 损丁、退财 | 忌修造动土 |
| **大将军** | 岁之将星对冲方 | 兵祸、争斗 | 避 |
| **重丧** | 按月日干支重见丧气 | 丧事连绵 | 造葬首避（见 4_4 口径说明） |

> **大凶宜远避，不可轻言制化。** 这八个字是本库对大煞的唯一态度。理由见板块5：制煞的前提是"煞衰而我旺"，大煞是天地肃杀之气，一年到头盘踞在固定的方位上，你很难找到一个"它衰而我旺"的月份去对付它。

**一个常见的自我欺骗**：有人说"我用三奇贵人、用太阳到山就能制三煞"。太阳到山、贵人禄马确实是吉神中的重器，但它们是**加分项**，不是**免罪符**。吉神重重聚会可以稍减其威，不能彻底消弭——这是《协纪》一系对大煞的定调。

### 4_3 中神煞：审事之轻重

| 煞 | 所主 | 处置要点 |
| --- | --- | --- |
| **大月建** | 月建飞泊之煞，占一方，主损丁口 | 忌修方；小事可避日 |
| **小月建** | 月建之煞，主小儿灾、口舌 | 忌修方，尤忌修中宫 |
| **正阴府** | 年干化气克坐山纳音（正配） | 双干无制必避；单干双制可解 |
| **旁阴府** | 年干化气克坐山纳音（旁配） | 双干双制；单干单制 |
| **天官符、地官符** | 主官非、口舌、吏议 | 忌修方；可择其死月死日修之 |
| **阴差阳错** | 主差错、反复、不成 | 嫁娶首避 |
| **四离四绝** | 节气断绝分离之日 | 大事避，小事可从宽 |

#### 阴府的制化规则（重点）

阴府的取法是**年干化气克坐山之纳音五行**：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火，若此化气之五行克坐山纳音，即为阴府。分正、旁，又分双干、单干，规则如下：

| 情形 | 规则 | 能否用 |
| --- | --- | --- |
| **正阴府 · 双干** | 无制 | **不可用，必避** |
| **正阴府 · 单干** | 双制（用两个克制之干） | 可解 |
| **旁阴府 · 双干** | 双制 | 可解 |
| **旁阴府 · 单干** | 单制（用一个克制之干） | 可解 |

"双干"指日课四柱中出现两个该化气之干，"单干"指只出现一个；"双制""单制"指用日时天干去克制它的数量。**正阴府双干无制这一条是本库的硬线**——它属于中煞里最重的一档，实操中按大煞处理。

> **中煞的完整处置口诀**：**中煞审事之轻重。** 同样是犯大月建，造葬（大事）必改期，砌一道矮墙（小事）可以选个吉日、避开它的旺日了事。不审事之轻重，就会把小事搞得办不成、把大事办得没规矩。

---

### 4_4 小神煞：有吉星同到即可压伏

| 煞 | 所主 | 处置 |
| --- | --- | --- |
| **病符** | 疾病、旧疾复发 | 有天德月德、天医同到即可 |
| **巡山罗睺** | 主眼目之疾、官非 | 修造忌；有吉星同到可解 |
| **灾退** | 退财 | 小事不忌 |
| **重丧** | 丧事连绵 | **按事分级，见下方口径说明** |
| **归忌** | 出门难归 | 忌远行、回门；近处不忌 |
| **往亡** | 去而不返 | 忌出行求财赴任；居家诸事不忌 |
| **天温（天瘟）** | 疫气、瘟气 | 忌栽种、纳畜、修造 |
| **天贼** | 失盗 | 忌出行、纳财；居家防盗即可 |

> **口径说明（重丧）**：重丧在《协纪辨方书》中列入大凶，但它的凶性**只在丧葬一类用事上成立**——犯之主丧事连绵，即家中短期内再有丧事。若当日所办的不是丧葬事（如嫁娶、开市），重丧按中下等论，有吉星同到即可放下。这是"**因事分级**"最典型的一例，不能一见重丧就一票否决。

> **小煞的总原则**：**有吉星同到即可压伏。** 所谓吉星，主要指天德、月德、天德合、月德合、天恩、天赦一类月家日家的德神。一课之中若有两三件德神照临，小煞可以不再计提。

### 4_5 取舍优先级：四级次序，不可颠倒

真正到出课的时候，按下面这个次序往下走，**上一步没过关，不要往下走**：

```latex
第一级 · 主命与主事
   主事人年命与坐山、日辰有无相冲、相害、相刑
   → 有冲害：直接换日，后面不用再看
          ↓ 过关
第二级 · 年家大煞
   岁破、三煞、五黄、戊己都天、大将军
   → 犯之：避。不谈制，不谈吉神
          ↓ 过关
第三级 · 月令日辰中型凶煞
   月破、大月建、小月建、阴府、天地官符
   → 犯之：审事之轻重，能制则制（制法见板块5）
          ↓ 过关
第四级 · 民间俗传小忌
   三娘煞、杨公忌、龙虎俗忌
   → 有吉星同到即可放下；无吉星则小事可从宽
```

**为什么第一级是主命**：择吉讲的是匹配，不是吉凶（详见板块0）。一个再标准的黄道吉日，只要日支冲了办事人的年支，对这个人就不是一个好日子。这一级最容易被跳过去，因为它不在通书里。

**为什么次序不能颠倒**：把第四级放在第一位，会一年无日可用；把第一级放在第四位，会挑出"对别人吉、对我不吉"的日子。两种颠倒的后果完全不同，但都是错的。

---

### 4_6 按用事类型取舍：大事从严，小事从宽

| 用事 | 首避 | 次避 | 可从宽 |
| --- | --- | --- | --- |
| **阴宅造葬** | **重丧、三煞、岁破** | 复日、四离四绝、巡山罗睺 | 俗传小忌 |
| **婚嫁** | **阴差阳错、三娘煞** | 无禄、四离四绝、归忌、孤辰 | 杨公忌（有吉星可扶） |
| **修造奠基** | **杨公十三忌、埋儿杀、三煞、五黄** | 大月建、小月建、阴府、官符 | 病符、灾退之类小煞 |
| **开市立券** | 大败、破日、往亡 | 天贼、五虚 | 一般俗忌 |
| **出行赴任** | 往亡、归忌、四离四绝 | 八风、触水龙、天贼 | 其余小忌 |
| **买卖访友闲游** | 除极大凶煞外 | 无 | **诸般小忌可放下** |

> **一条总口径**：**大事从严，小事从宽。** 何谓大事——不可逆的、涉及人身安全的、代价高的一次性事件（造葬、嫁娶、奠基、开业、手术）。何谓小事——可重复的、可重来的、代价低的日常事务（拜访、采买、出游、签小单）。同一本通书，办大事时取其严格口径，办小事时取其宽松口径，这是正理，不是取巧。

---

### 4_7 吉凶相抵六条

同一天既有吉神又有凶煞，是常态。《协纪辨方书》给出相抵的原则，本库归纳为六条：

| 条 | 情形 | 处置 | 说明 |
| --- | --- | --- | --- |
| **一** | **吉足胜凶** | 从宜不从忌 | 吉神多而有力，小凶不必计较 |
| **二** | **吉凶相敌，而事属德喜** | 从忌 | 德喜之事（喜庆、祭祀）反要更严 |
| **三** | **吉凶相敌，而凶煞有制** | 从宜 | 凶煞被制住，等于减一等 |
| **四** | **吉凶相敌，而吉神无根** | 从忌 | 吉神落空、休囚，等于没有 |
| **五** | **吉不胜凶** | 从忌不从宜 | 凶重吉轻，不可用 |
| **六** | **大煞当前** | 不论相抵，直接避 | 本库补：相抵只适用于中煞、小煞 |

```latex
   吉 > 凶  ──────────────→  从宜
   吉 = 凶  ─┬─ 德喜之事 ───→  从忌
             ├─ 凶煞有制 ───→  从宜
             └─ 吉神无根 ───→  从忌
   吉 < 凶  ──────────────→  从忌
   大煞     ──────────────→  不适用相抵，避
```

> **"吉神无根"这一条最容易被忽略。** 一个吉神要真正起作用，需要它在月令上得时、在四柱中有气。天德落在休囚的月份，或贵人落空亡，就是"有名无实"，此时不能拿它去抵凶煞。判断有没有根，方法见板块1的旺相休囚与空亡。

### 4_8 常见错

| 错 | 表现 | 后果 |
| --- | --- | --- |
| **不分轻重，一概畏惧** | 见"杨公忌"就换日 | 一年无几日可用，事办不成 |
| **不分轻重，一概轻视** | 以"小煞不必制"为由犯岁破 | 大凶无救 |
| **次序颠倒** | 先看日神小忌，后查年家大煞 | 挑中吉日却坐三煞 |
| **拿小煞当大煞来制** | 认真"制"三娘煞 | 白费功夫，还容易制出副作用 |
| **只看煞，不看事** | 不问办什么事，一律从严或一律从宽 | 该严的不严，该宽的不宽 |

> **边界提醒**：本板块涉及造葬、修造、开业、医疗时机等事项。凡涉及**人身安全、建筑工程、结构改动、公共卫生、医疗决定**的，一律以专业机构与执业人员的意见为唯一依据，择吉只作文化与心理层面的参考，不作决策依据。

#### 案例小故事：把轻重弄反了的那半年

有位做生意的朋友，半年里找我两次，两次都跟"轻重"有关，而且恰恰弄反了。

**第一次，是给院子砌一道矮墙。** 他连着订了三次日子，三次都临时取消，前后拖了两个月。取消的理由都一样：通书上那一日标着"杨公忌"。我问他：这道墙多高、多长、动几天土？他说一米多高，两三天完事。我说这是小事，杨公忌是俗传小忌，按"小事从宽"，找一个不犯月破、日支不冲你的日子就能干。他半信半疑地定了日子，三天砌完，什么事也没有。**这两月他反复折腾的成本，远远大于那道墙。**

**第二次，是给父亲选坟。** 这回他反倒很快定了，理由是"师傅说那天是黄道吉日，通书上宜安葬"。我按四级次序给他过了一遍：

```
第一级 · 主命：该日日支与父亲年支相害      → 未过关
第二级 · 年煞：该年三煞方，坐山正好落在其中  → 未过关
第三级 · 月煞：小月建临方                  → 未过关
第四级 · 小忌：无                          → 过关了，可这一级最不重要
```

四级里头三级都没过，唯一过的那一级恰恰是最不该看重的。我把结果给他看，他沉默了半晌，说了一句："我以为黄道吉日就是最好的日子。"

**后来**：坟地另择了坐向，避开三煞方；日子重选，日支与年支不冲不害。他后来跟我说，最难受的不是多花了钱，是想到如果当时按原方案下葬，往后每年清明都会想起那个"没查年煞"的下午。

**复盘**：这两件事放在一起看，问题一模一样——**他手里只有"吉日/凶日"这一个维度，没有"轻重"这个维度**。没有轻重，就只能要么全怕，要么全不怕；砌墙时全怕，选坟时全不怕。而择吉真正的技术含量，恰恰在于先判轻重、再定宽严。

**落点**：拿到一个日子，先别问"这是不是吉日"，先问"我要办的这件事算大事还是小事"。答案不同，同一本通书会给你两个完全相反的结论，而且两个都对。

## 板块5 · 制煞与化煞：五行制化的规则与前提

> 择吉里最动听、也最危险的一句话是"这个煞我可以制"。制煞是有前提的：**凶煞衰、制神旺**。前提不成立，制煞就变成了"以卵击石"。
>
> 本篇讲三件事：制与化有什么区别、制煞的六条规则与一个月令前提、以及在什么情况下**根本不该谈制**。

---

### 5_1 制煞与化煞：以力服人 vs 以德服人

古人对这两件事的区别说得极透：

> **制煞犹如以力服人，万一力不能胜，反张其凶焰；化煞犹如以德服人，凶顽格心即为善良。**

| 路数 | 手段 | 风险 | 适用 |
| --- | --- | --- | --- |
| **制煞** | 以五行相克硬克（金克木、水克火） | 力不胜则反噬，凶焰更张 | 中煞，且煞衰我旺时 |
| **化煞** | 以相生、相亲、相合化解其气 | 较温和，但见效慢、力量弱 | 中煞、小煞 |
| **避煞** | 换方位、换日子、换月份 | 无风险 | 大煞，以及一切没有把握的煞 |

三条由此而来的口诀，必须按顺序念：

```latex
制煞不如化煞高       —— 硬克不如化解稳妥
    ↓
化煞不如避煞         —— 能避就避，避是最彻底的解法
    ↓
大凶之煞，可避不可制  —— 大煞不进"制"这个环节
```

> **一句话总结**：**能避则避，避不了再谈化，化不了且煞已衰时，才谈制。** 三步走反了，就是拿自己的课去赌。

---

### 5_2 制煞六条规则

制煞不是随便拿一个相克的五行去克，它有严格的对应关系——**煞从哪一路来，就从哪一路制回去**。

| 规则 | 适用神煞 | 做法 | 例 |
| --- | --- | --- | --- |
| **干犯干制** | 阴府、天金神 | 煞在天干，就用天干制之 | 阴府甲己属土，以丁壬木制之 |
| **支犯支制** | 地官符 | 煞在地支，就择该支的死月死日修之 | 地官符在寅卯（木），取申酉月日（金旺木死） |
| **三合犯三合制** | 三煞、打头火、天官符 | 煞成三合局，就用对冲的三合局制之 | 三煞在巳午未（火方），用申子辰水局制之 |
| **纳音犯纳音制** | 年克山家 | 煞以纳音论，就用纳音制之 | 年纳音克山家纳音，取能克年纳音者 |
| **化气犯化气制** | 阴府 | 煞由化气而生，就以化气制之 | 甲己化土，以丁壬（化木）制之，木克土 |
| **飞宫犯飞宫制** | 月家打头火 | 煞由飞宫而来，就取同宫的吉星制之 | 以月家一白水星，或壬癸水德制之 |

六条的共同逻辑是**"对路"**：天干的事归天干，地支的事归地支，三合的事归三合，纳音的事归纳音，飞宫的事归飞宫。用天干去制地支煞、用地支去制天干煞，都是"不对路"，制了也是白制。

> **一条实操提醒**：六条里"三合犯三合制"用得最多也最险——三煞正是三合局之煞，所以古书确实有"以三合局制三煞"的制法，但**那属于中煞制法中的高难动作**，本库不主张对三煞使用（见 5_6）。

---

### 5_3 制煞全看月令：这是唯一的前提

古人对制煞的前提讲得斩钉截铁：

> **制煞全看月令。必须凶煞衰月、制神旺月，切不可用煞之生旺。**

举例说明这句的意思：

> **煞属木者，忌春令，并忌亥卯未日时；用午字则木煞死，用申子则木煞绝。**

拆开来看：木煞在春天（寅卯辰月）当令而旺，此时去制它，等于在它最强的时候上门挑衅；到了午月（或午日午时），木行到"死"位，气已尽；到了申月（或申日申时），木行到"绝"位，气已断——这时候动手，才叫制煞。

| 煞之五行 | 忌用（煞之生旺） | 宜用（煞之死绝） |
| --- | --- | --- |
| **木煞** | 春令寅卯辰月；亥卯未日时 | **午**（木死）、**申子**（木绝） |
| **火煞** | 夏令巳午未月；寅午戌日时 | **酉**（火死）、**亥**（火绝） |
| **金煞** | 秋令申酉戌月；巳酉丑日时 | **子**（金死）、**寅**（金绝） |
| **水煞** | 冬令亥子丑月；申子辰日时 | **卯**（水死）、**巳**（水绝） |
| **土煞** | 四季辰戌丑未月；午月 | **酉**（土死）、**亥**（土绝） |

```latex
   判断次序：煞属何行 → 它在哪个月当令（避）→ 它在哪个月死绝（取）
                                              ↓
                            再取制神旺相之月（扶）→ 两者重合者即用
```

> **口径说明**：土煞的死绝位有两说。取"火土同宫"者，土长生在寅、帝旺在午，**死于酉、绝于亥**；取"水土同宫"者，**死于寅、绝于巳**。**本库取火土同宫**（与板块1的十二长生表保持一致），选定后不在同一课中改用另一说。

**制神也要有根**。光有"午"字不够，还要看这个午在当月是否得令、在四柱中是否有同类相扶。孤立一个制神去制一个成局的煞，是制不住的——这就是下面 5_7 里"制神无根"那条错。

---

### 5_4 化煞三法

化煞不走相克一路，走的是"让它不来克我"：

| 法 | 原理 | 做法 | 例 |
| --- | --- | --- | --- |
| **五行相生化煞** | 以食神子孙泄之 | 让煞之气有地方去，不再攻我 | 煞属金，用水泄之（金生水，水为金之子孙） |
| **五行相亲化煞** | 同类亲和、比护 | 以同类之气引化，或以比肩护主 | 煞与我同类，则以比助扶起我身而受之 |
| **五行相合化煞** | 以合化之，使其忘克 | 用天干五合把煞"合走" | 煞在己，以甲合之（甲己合土）；煞在庚，以乙合之 |

三法的共同点是**不与煞正面冲突**：泄之、亲之、合之，都是让它"不把注意力放在我身上"。这也正是"制煞不如化煞高"的由来——硬克有可能激起反扑，化解则没有这个风险。

> **化煞的局限**：化煞力量温和，对**中煞、小煞**有效，对大煞无效。大煞是天地肃杀之气，不是一个可以被"合走"的对象。

---

### 5_5 以吉星压伏

另一条软路子是"不制不化，直接请吉星压住"。常用的是这四类：

| 吉星 | 作用 | 说明 |
| --- | --- | --- |
| **太阳到山、到向** | 太阳为诸星之首，所到之处诸煞退避 | 造葬修方最重 |
| **三合照山** | 三合局旺气照临坐山 | 与坐山成三合者为佳 |
| **紫白到山** | 一白、六白、八白、九紫四吉星 | 九宫飞泊取吉星临方 |
| **禄马贵人到山到向** | 日禄、驿马、天乙贵人临方 | 主得助、得利、得人 |

古诀把这层意思说得最形象：

> **煞在山头更若何，贵人禄马喜相过；三奇诸德能降煞，吉制凶神发福多。**

**怎么用**：通常要求**两三件吉星照临**才算压得住，单靠一件不足以定课。压伏之后仍要回填（事后记录是否平顺），因为压伏不是消弭——它降低的是概率，不是把煞从世界上抹掉。

> **口径说明**：吉星压伏适用于**中煞与小煞**。对三煞、岁破一类大煞，古人的定调是"吉神重重聚会方可稍减其威，不能彻底消弭"。把压伏当免罪符，是实操中最常见的越界。

---

### 5_6 边界：大凶之煞，可避不可制

这是本篇最要紧的一节，也是本库态度最明确的一处。

> **大凶煞如三煞、岁破、重丧，乃天地肃杀之气，非寻常法器、吉时所能驯服；唯吉神重重聚会，方可稍减其威，不能彻底消弭。**

三条由此而来的硬口径：

| 煞 | 性质 | 本库处置 |
| --- | --- | --- |
| **三煞** | 三合局绝胎养之肃杀气 | 避。坐山犯之必改；向方犯之可从轻 |
| **岁破** | 太岁对冲之破败气 | 避，不谈制化 |
| **重丧** | 丧葬事上的连绵之气 | 造葬必避（详见板块4） |
| **五黄、戊己都天** | 土气重浊之凶方 | 该方当年不动土，不谈制化 |

> **口径说明（"若要发，修三煞"）**：民间另有"若要发，修三煞"之说，主张主动修造三煞方以求骤发，与之相对的还有"若要贵，修太岁"。这两句在择吉界内**流传甚广但争议极大**，不属于《协纪辨方书》一系的官方口径，历代术家多有驳议。**本库的态度是：以避为主，不主张硬制。** 理由是：修三煞所求的是"发"，而犯三煞所失的是"人丁与安全"，二者不对称；且古来主张此说者，多同时要求极其苛刻的配套条件（特定月令、特定吉星聚会、特定用事），这些条件在实操中极难同时满足。**读者若遇到持此说的师傅，应当要求其说明配套条件与出处，并自行判断是否承担相应风险。**

---

### 5_7 常见错

| 错 | 表现 | 后果 | 怎么避 |
| --- | --- | --- | --- |
| **煞旺月去制** | 春天制木煞、夏天制火煞 | 反张其凶焰 | 先查月令，煞当令之月一律不动 |
| **制神无根** | 孤立一个庚字去制卯木煞 | 制不住，反被煞伤 | 制神要在当月得令、四柱有扶 |
| **制错路子** | 天干煞用地支制、地支煞用天干制 | 白费功夫 | 对照 5_2 六条，先定"哪一路" |
| **以为制过就万事大吉** | 制了中煞，却冲了主命 | 按下葫芦浮起瓢 | 制完之后重走板块4的四级次序 |
| **对大煞谈制** | "我用吉星压三煞" | 越界，风险不可控 | 大煞只避（见 5_6） |

### 5_8 动"制"这个念头之前的四问

| 问 | 内容 | 不过关怎么办 |
| --- | --- | --- |
| **一问等级** | 这个煞属大、属中、属小 | 大煞直接改判为"避"，不进制化环节 |
| **二问路子** | 干、支、三合、纳音、化气、飞宫，属哪一路 | 路子不对，重定制法 |
| **三问月令** | 煞在哪月死绝？制神在哪月旺相？ | 两者不重合，就改期 |
| **四问后手** | 制完之后，主命、坐山、日辰还过不过关 | 回看板块4的四级次序重走一遍 |

> **边界提醒**：制煞化煞涉及动土、修造、动火作业、电气与燃气线路改动等情形时，**一律以施工单位、消防、燃气、结构与安全专业人员的意见为准**。择吉不作为开工、停业整改、设备改动的依据，也不构成任何安全承诺。

#### 案例小故事：赶在旺季开业的那家餐馆

朋友开了家小餐馆，装修完了要定开张日。坐向是**子山午向**，那年的三煞在南方午位——落在向方上。按"三煞可向不可坐"，这一条本来过得去。真正卡住的是另一件：那个月的**月家打头火**飞临向方，属火煞，是飞宫一路的中煞。

我给他的方案是两条：一是**改期到亥月**（水旺，火绝），二是取**壬癸水德的日时**以水制火，用的是"飞宫犯飞宫制"那条（以月家一白水星或壬癸水德制之）。

他两条都没采纳，理由是三条：

```
理由一：旺季不能等   → 当时正值巳月（夏令），火煞当令
理由二：有人能压住   → 请人挂了化煞物件，说"吉星可以压"
理由三：民间那句话   → "若要发，修三煞"，向方犯三煞正好发财
```

三条理由，条条都踩在 5_7 的错上：**煞旺月去制**（夏令制火煞）、**以为制过就万事大吉**（挂了物件就不管月令）、**对大煞谈制**（用一句俗语给自己壮胆）。

**结果**：开张后两个月内，后厨出了两次小火情（一次油锅起火，一次线路过热），油烟被楼上投诉两次，被迫停业整改一周。整改完重新定日子，这次他同意改到亥月，取壬癸日的亥子时重开，并把后厨的动火区调整到不在飞宫火煞临方的位置。重开之后一年多没再出事。

**复盘时他自己说了两点**，我觉得比我说什么都准：

1. **"我以为制煞是加法，其实是条件。"** 他原以为"找个师傅 + 挂个物件"就等于制住了，实际上制煞的前提是月令——煞衰我旺这个条件不成立，后面做多少加法都是零。
2. **"我不是信那句话，我是用那句话给自己的贪心找台阶。"** 他后来承认，真正让他不肯改期的不是"三煞能发财"，是怕错过旺季。那一周的停业损失，加上整改的费用，比旺季多赚的那点钱多得多。

**落点**：动"制"这个念头之前，先答三个问题——这个煞属哪一行？它在哪个月死绝？我的制神在那个有没有根？三个答案凑不齐，正解就只有一个字：**等**。

## 板块6 · 正五行择日三大纲领：补龙、扶山、相主

> 择吉到了成课这一层，就不再是神煞清单的加减法了：一个能用的日课，必须同时过三关——对得起来龙、对得起坐山、对得起主人。
> 《协纪辨方书》把这三层称作造命之法，原文只有三句，却把整个正五行择日的骨架定死了。
> 本篇把三关拆开讲：每一关看什么、怎么补、怎么扶、怎么相，以及三者打架时先让谁。

---

### 6_1 造命之法的原文：三句话定骨架

《协纪辨方书》卷三十三造命一篇，把择日的步骤压缩成三看：

```
一看来龙宜何局以补之
二看山向何煞宜避，何煞可制，以何法制之，取何吉星照之
三看主人本命宜何如以扶之。三者俱得而后举，事吉无不利矣
```

把这三句译成操作语言：

| 原文 | 操作语言 | 处理对象 | 关键词 |
| --- | --- | --- | --- |
| 一看来龙宜何局以补之 | 来龙入首一节属何五行，四柱要生旺它 | 龙（入首脉气） | **补龙** |
| 二看山向何煞宜避，何煞可制 | 坐山向口有哪些煞，避不了的用什么法制 | 山（坐山与向） | **扶山、制煞** |
| 三看主人本命宜何如以扶之 | 主事人生年与日课不冲不刑，且得禄马贵 | 人（本命） | **相主** |

> **口径说明**：这里的造命，是**造一个好日课**的意思，与港台命理界择期剖腹生产造一个好八字的造命是两回事。后者详见板块9，两者不要混为一谈。

三者的关系不是并列打分，而是**有先后顺序的否决链**：

```
第1关：犯冲否（冲主命、冲坐山、冲太岁、冲龙）
       犯了，后面不用看，直接换日
第2关：犯大煞否（三煞、岁破、戊己都天、阴府、克山运）
       犯了，能避则避，避不了看能否制
第3关：补龙、扶山、相主到位几条，决定这一课的成色
第4关：四柱本身成不成格、吉星够不够，详见板块7
```

---

### 6_2 补龙：补的是入首一节，不是整条山脉

**先说清楚补的对象。** 龙从祖山起，剥换起伏，行度数十里，正五行择日不管整条，只管**入首一节**，即穴位后束气入首处的那一节脉。理由是：气在入首处收敛成形，这一节的五行属性才直接决定穴位所受之气。

二十四山的正五行归属：

| 五行 | 二十四山 |
| --- | --- |
| 水 | 亥、壬、子、癸 |
| 木 | 寅、甲、卯、乙、巽 |
| 火 | 巳、丙、午、丁 |
| 金 | 申、庚、酉、辛、乾 |
| 土 | 辰、戌、丑、未、坤、艮 |

判定来龙入首属哪一行，靠的是**峦头**：看入首星峰的形状（贪狼木、巨门土、禄存土、文曲水、廉贞火、武曲金、破军金、左辅金、右弼水，即九星变体），再与二十四山正五行互校。

> **口径说明**：九星形体五行与二十四山正五行有时会不一致，例如立艮山而入首星峰作木体。多数正五行家以**二十四山正五行为主、星体五行为参考**；另有以洪范五行、双山五行定龙者，取法不同，结论也不同。本库以正五行为主线，他家详见板块11。

**补的手法**，常用的五种：

| 手法 | 做法 | 举例（木龙） |
| --- | --- | --- |
| 三合局 | 四柱地支凑成龙之三合局，三字全为上，二字为半局 | 亥卯未三合木局，四柱见亥卯未 |
| 生旺之位 | 四柱地支落在龙之长生、临官、帝旺位 | 木长生于亥，临官帝旺在卯 |
| 纳音相生 | 四柱纳音生龙之纳音，或与龙纳音同类 | 木龙取纳音水（生）或木（比） |
| 天干一气 | 四柱天干同气不杂，取纯粹 | 四甲、四乙之属，配木龙 |
| 月令得令 | 用事之月令与龙五行同气或相生 | 木龙取春月，或取水生之冬月 |

**补的反面是泄与克，这两种要避开：**

```
生入（四柱生龙）＝ 补，吉
比和（四柱同龙）＝ 助，吉
克入（四柱克龙）＝ 煞，忌
生出（龙生四柱）＝ 泄，减力
克出（龙克四柱）＝ 龙气耗于制他，减力
```

**自检口诀**：补龙只问一句——**这一课下去，龙的五行是变旺了还是变弱了。** 变旺就是补，变弱就是泄。

---

### 6_3 扶山：与制煞是一体两面

坐山即穴场或宅基所坐之方，其五行同样按上表二十四山正五行定。

**扶山的两条路径**，一是四柱扶起坐山，二是吉星照临坐山：

| 类型 | 名目 | 要点 |
| --- | --- | --- |
| 四柱扶山 | 生入、比和 | 四柱干支五行生坐山，或与坐山同气 |
| 四柱扶山 | 临官帝旺 | 坐山五行在四柱得临官、帝旺之支 |
| 吉星照山 | 太阳到山到向 | 太阳照山最尊，能压诸煞；太阴、天帝次之 |
| 吉星照山 | 紫白九星 | 一白、六白、八白为三吉，九紫主喜庆 |
| 吉星照山 | 岁德、天德、月德 | 德能解煞，到山到向皆吉 |
| 吉星照山 | 禄、马、贵飞临坐山 | 主命之禄马贵落在本山，称为扶起 |

**与制煞的关系。** 第二看原文里何煞宜避、何煞可制，是扶山的另一半：

| 情形 | 处理 | 说明 |
| --- | --- | --- |
| 煞占坐山，如三煞临山 | **避** | 坐山被占，此年此向不作修造安葬，改年或改向 |
| 煞占向、占方 | **视可否制** | 有的可制，用五行相克之法或太阳照之；有的只能避 |
| 煞轻而有吉星同到 | **不制亦可** | 德星、太阳到位，小煞自伏 |

可制与不可制的判定标准，以及制的五行手法，见板块5，本篇不重复。

**扶山最忌的一条叫克山运**，亦称克山家：

```
山运 ＝ 本年洪范五行或斗首五行所属之运
四柱纳音若克此运，即为克山运
口诀：年克山家为大忌，月克次之，日克又次之，时克更轻
```

> **口径说明**：山运的推法各家不同，洪范五行一派、斗首五行一派、正五行一派各有算法，同一年同一山会算出不同的运。这是择吉里最混乱的一块，本库只提示克山运属大煞层级，须查所用流派的表再定，不作统一结论。流派差异见板块11。

---

### 6_4 相主：主事人的本命要扶得起

主事人是谁，要看用事：

| 用事 | 主事人取谁 |
| --- | --- |
| 造葬 | 以亡人本命者为一派，以孝子本命者为一派，两派并存 |
| 修宅 | 宅主，即家长 |
| 嫁娶 | 新郎、新娘二人，兼看双方父母 |
| 开市 | 店主、法人 |
| 出行赴任 | 出行者本人 |

> **口径说明**：造葬以亡人为主还是以孝子为主，是明清以来一直没断过的争论。取亡人者认为阴宅安的是亡者，取孝子者认为泽被的是活人。实务中常见做法是**两者都看、都不冲**，宁可窄一点。

**相主的四条硬要求：**

```
1. 不冲：日课四柱不可冲主事人生年支，日支尤其紧要
         子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
2. 不刑：不犯三刑，寅巳申无恩之刑、丑戌未恃势之刑、子卯无礼之刑、辰午酉亥自刑
3. 不犯本命空亡与本命的极凶煞
4. 得扶：得禄、得贵、得马，或四柱天干与本命天干相合
```

**禄、贵、马的查法**，以主事人生年干支为体，看四柱是否到位：

| 项目 | 口诀 | 用法 |
| --- | --- | --- |
| 禄 | 甲禄在寅、乙禄在卯、丙戊禄在巳、丁己禄在午、庚禄在申、辛禄在酉、壬禄在亥、癸禄在子 | 四柱见本命天干之禄，为得禄 |
| 贵人 | 甲戊庚牛羊，乙己鼠猴乡；丙丁猪鸡位，壬癸兔蛇藏；六辛逢虎马 | 四柱地支见本命天干之贵人，为得贵 |
| 驿马 | 申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳 | 本命年支之马星见于四柱，出行赴任尤重 |
| 天干合 | 甲己合、乙庚合、丙辛合、丁壬合、戊癸合 | 日课天干与本命天干相合，谓之有情 |

**相主最容易漏的一条是冲，冲是硬否决，不是可以打折的一项：**

```
日支冲主命生年支 → 换日，不议
时支冲主命      → 换时，尚可补救
年柱冲主命      → 换年，实务中常以不冲坐山、不冲太岁优先妥协
```

---

### 6_5 三者打架时的裁决顺序

三条纲领不可能常常圆满。**冲突时的顺序是硬性的**，不能凭感觉挑：

| 次序 | 关卡 | 处理 | 让位的理由 |
| --- | --- | --- | --- |
| 第一 | **避冲** | 主命冲、坐山冲、太岁冲即岁破、龙脉冲，一律换 | 冲是结构性破坏，不是力量大小问题，扶补补不回来 |
| 第二 | **避大煞** | 三煞占山、戊己都天、阴府、克山运、月破、五黄到山 | 大煞是能不能办的问题，不是办得好不好的问题 |
| 第三 | **扶山** | 煞避净了，再看坐山有无吉星照临、四柱有无生入 | 山是当下这一局的根，山不扶，龙补了也落不住 |
| 第四 | **补龙** | 山稳了再谈补龙 | 龙是远脉，其力缓，可让位于山 |
| 第五 | **相主** | 主命得禄马贵为加分，不冲为底线 | 不冲的底线已在第一关过了，得扶是锦上添花 |
| 第六 | **成格与吉星** | 四柱成格、吉神汇聚 | 详见板块7 |

一句话记法：**先避冲，再避煞，后论扶补；山急于龙，龙急于人，人急在冲。**

```
可妥协的：补龙不足、不得禄马贵、四柱不成格、小煞未制
不可妥协的：冲主命、冲坐山、三煞占山、岁破方动土、克山运
```

> **边界提醒**：这是本库内部的取舍顺序，**它不产生任何法律效力或工程效力**。动土、上梁、拆改、封顶等一切施工行为，以规划许可、施工许可、结构设计、地质勘察与现场安全规范为唯一依据；安葬以殡葬管理与土地管理法规为准。择吉给出的宜忌不参与上述任何一项判断。

---

### 6_6 峦头为体，时日为用

这是正五行择日最要紧的一条体用关系，也是最容易被人忘掉的一条：

> **龙真穴的，砂环水抱，纵时日略有瑕疵，福泽不失；若山川破败、宅形歪斜，纵使千万吉神齐聚，亦难转祸为祥。**

把这句话拆成三层意思：

| 层次 | 含义 |
| --- | --- |
| 体（峦头） | 龙脉是否真、穴位是否的、砂是否环、水是否抱、宅形是否端正，这是**基数** |
| 用（时日） | 日课是在这个基数上做**增益**，加减的是零头，不是本金 |
| 关系 | 体坏用再好，等于在漏水的桶里加水；体好用略差，桶还在 |

实操上的两个推论：

```
推论一：见到一个吉课就敢用在很差的地或歪斜的宅上，是择吉最大的误用
推论二：地好宅正而日课只能得七八分，可以用，不必苦等完美课
```

这也解释了为什么古籍反复强调**不得真龙，择日无益**：日课扶的是已有的气，造不出本来没有的气。

### 6_7 出课前的三纲领自检

出课之前，把这张表填完再落笔：

```
【补龙】入首五行：____  补法（三合/临官/纳音/天干一气）：____
        龙是被生、被比，还是被泄、被克：____
【扶山】坐山五行：____  照临吉星（太阳/太阴/紫白/德/禄马贵）：____
        煞情：占山否____ 占向否____ 可制否____ 犯克山运否____
【相主】主事人生年干支：____  冲否____ 刑否____  得禄/得贵/得马/天干合：____
```

判定口径：

| 三条的成色 | 判定 | 处置 |
| --- | --- | --- |
| 三条全得 | 上吉 | 直用 |
| 得二条，缺的一条只是不足而非犯 | 可用 | 记明缺什么，回填时验证 |
| 缺的那条是犯，如龙被克、山被煞占、命被冲；或三条都勉强 | 不用 | 换课，宁可改期，不可硬凑 |

### 6_8 案例小故事：一课三关，卡在相主

有位朋友的祖坟要迁，托人择了一课，四柱排出来很漂亮：天干一气、地支三合、纳音相生，还有太阳到山。拿给我看，问能不能用。

我先问了三个问题：

```
问：入首一节是什么脉？
    答不上来，择课的人没到现场，是照着图纸定的坐山
问：坐山是什么？今年三煞在哪一方？
    坐乾，今年巳酉丑年三煞在东方寅卯辰，不占山
问：主事人是谁，生年什么？
    孝子，生年庚申
```

三关一过，问题出来了：

1. **补龙这一关，根本没做。** 择课的人不知道入首脉属什么五行，所谓天干一气是照着通书的吉格套的，没有补的对象。这一关的正确答案是缺，不是得；
2. **扶山这一关，过了。** 乾属金，四柱土金相生，太阳到山，三煞不占，无克山运；
3. **相主这一关，卡住了。** 课中日支是寅，庚申年生人，寅申正冲，这是硬否决，不是打分问题。

按 6_5 的裁决顺序走：相主里的不冲属于第一序列的避冲项，优先于任何扶补与成格。所以结论很干脆：**换日，不议。**

后来改了一课，四柱成色不如原来漂亮，天干不是一气，地支只凑了半合，但补龙、扶山、相主三条都落了实：入首是金脉，四柱土金补之；坐乾得太阳与月德照临；日支换成与庚申不冲不刑之支，课中还得庚金之禄。

**落点**：三大纲领的价值，不在于它能帮你挑出一个漂亮的课，而在于它给了一套**强制性的检查顺序**，先问有没有犯冲、有没有犯大煞，再论龙补没补、山扶没扶、人扶没扶。那张漂亮的四柱之所以不能用，不是因为它不够好，而是因为它在没有对象的条件下套了一个好格式，又踩了唯一不能踩的那条线。补龙扶山相主，缺哪一条都可以记下来、回填验证；唯独冲这一条，没有商量余地。

## 板块7 · 日课四柱：成格成局的取法

> 板块6讲的是日课对外要满足的三个条件：补龙、扶山、相主。本板块讲的是日课对自己要满足的条件：年、月、日、时四柱排在一起，本身要站得住、要成格局。
> 这一步最容易被跳过，因为神煞清单看起来已经够用了。但四柱自相冲克的课，就像一个内部互相拆台的班子，外面挂多少吉神都撑不起来。
> 本篇给出常见课格的取法、四柱内部的自检清单，以及一条最要紧的实操原则：大纯小疵即可用。

---

### 7_1 什么叫成格成局

先分清两件事：

| 名称 | 指什么 | 问的问题 |
| --- | --- | --- |
| **成格** | 四柱干支之间构成某种约定的好格式，如天干一气、地支一气 | 这一课长得像不像样子 |
| **成局** | 四柱地支凑成三合、三会等五行之局，力量聚于一方 | 这一课的力量聚不聚 |

格是外形，局是内力。**有格无局，好看而力散；有局无格，有力而形杂；格局两全，才是上课。**

四柱的位置含义也先固定下来：

```
年柱 ── 太岁所在，不可选，是这一课的"天时底色"
月柱 ── 月建与月令，决定五行旺衰，是这一课的"季节底盘"
日柱 ── 用事之日，是这一课的主体，也是受煞最多的一柱
时柱 ── 用事之时，是这一课的收口，也是最后可调节的一柱
```

> **口径说明**：年柱不可选，这是择日与八字排盘最大的不同。八字四柱全是给定的，择日里只有月、日、时三柱可动（年柱由用事年份定死）。所以"四柱天干一气"这类课格，实务上往往是**三柱同气而年柱不杂**，并非四字全同。见下文 7_2 的口径分歧。

---

### 7_2 课格一：天干一气与地支一气

**天干一气**：四柱天干同属一行，取纯粹不杂之意。

| 课格 | 天干 | 五行 | 适用 |
| --- | --- | --- | --- |
| 四甲 | 甲甲甲甲 | 阳木 | 补木龙、扶木山 |
| 四庚 | 庚庚庚庚 | 阳金 | 补金龙、扶金山，兼制木煞 |
| 四壬 | 壬壬壬壬 | 阳水 | 补水龙，兼制火煞 |
| 四丙 | 丙丙丙丙 | 阳火 | 补火龙，兼制金煞 |

> **口径说明**：严格派要求四柱天干**同字**（四甲、四庚）；宽派只要求**同气**（甲与乙混见，丙与丁混见，仍算一气）。同字课极少，数十年难遇一课；同气课则每月可求。两派的分歧不在吉凶判断，而在"够不够格"的门槛。本库实操取宽派口径，并在出课登记时注明是同字还是同气。

**地支一气**：四柱地支同属一行，或四支全同。

```
四支全同（四寅、四卯、四申之类）：极罕见，力量极纯，然过刚易折
三会同气（寅卯辰、巳午未、申酉戌、亥子丑）：力量聚于一方，为常用
三合半局（亥卯、卯未、亥未之类）：二字亦成一局之力，弱于三字全
```

> **口径说明**：地支一气课力量虽纯，但古籍亦有"纯则无制、过刚则折"的告诫。四柱地支全同的课，若不配德星、太阳之类，反不如三合局的生旺墓齐全。这是"好看"与"好用"的差别。

---

### 7_3 课格二：三合局与生旺墓

三合局是最常用、也最稳妥的一类课格，因为三合本身就包含**生、旺、墓**三个环节，气的来路去路都齐全：

| 三合局 | 三支 | 长生 | 帝旺 | 墓库 | 所补五行 |
| --- | --- | --- | --- | --- | --- |
| 木局 | 亥卯未 | 亥 | 卯 | 未 | 木 |
| 火局 | 寅午戌 | 寅 | 午 | 戌 | 火 |
| 金局 | 巳酉丑 | 巳 | 酉 | 丑 | 金 |
| 水局 | 申子辰 | 申 | 子 | 辰 | 水 |

**取法要点：**

```
1. 三字全为上格：四柱中见三字，力量完整
2. 二字为半局：仍可用，须看是否带旺位（带帝旺的半局优于带墓的半局）
3. 一字不成局：仅一字且有他支冲之者，反凶
4. 局之五行必须与龙、山、主命的需求一致，
   若补木龙却凑了金局，是补反了，成格也凶
```

**生旺墓的方位意义**（与补龙直接挂钩）：

| 环节 | 意义 | 补龙时怎么用 |
| --- | --- | --- |
| 长生 | 气之初生 | 龙气初旺，宜于开基、奠基 |
| 临官、帝旺 | 气之极盛 | 龙气最旺，宜于上梁、封顶、安葬 |
| 墓库 | 气之收敛 | 宜于安葬、入殓、封藏；不宜开市、出行 |

> **口径说明**：有人认为墓库课发福迟缓，有人主张葬事必须用墓库以收气。分歧的根源在于对阴宅与阳宅的用法不同，安葬收气宜墓，阳宅发用宜旺。本库按此分。

---

### 7_4 课格三：纳音相生与纳音一气

纳音是另一套五行系统，与干支正五行并行使用，在补龙、扶山时尤重。

```
纳音相生：四柱纳音依次相生，如年纳音水生月纳音木，
          月纳音木生日纳音火，日纳音火生时纳音土
纳音一气：四柱纳音同属一行，如皆为大海水、皆为沙中金
纳音生龙：四柱纳音生来龙入首之纳音
纳音克龙：四柱纳音克来龙入首之纳音，大忌
```

| 用法 | 判断 | 处置 |
| --- | --- | --- |
| 四柱纳音生龙之纳音 | 补，吉 | 直用 |
| 四柱纳音与龙纳音同类 | 助，吉 | 直用 |
| 龙纳音生四柱纳音 | 泄，减力 | 可用而不佳 |
| 四柱纳音克龙纳音 | 克，忌 | 换课 |

纳音与正五行打架时怎么办：

> **口径说明**：纳音与正五行是两套坐标，同一课可能出现"正五行生龙、纳音克龙"的情形。多数正五行家以**正五行为主、纳音为辅**，纳音用来印证而非推翻；斗首家则反以纳音与番化五行为主。选定一家后贯通使用，不要在一课之内两处各取一半。详见板块11。

---

### 7_5 课格四：星格与特殊课

除干支本身的格式外，还有一类以吉星临照为骨架的课：

| 课格 | 构成 | 要点 |
| --- | --- | --- |
| **太阳到山课** | 太阳（或太阴）到坐山、到向 | 太阳为诸星之尊，能压诸煞，造葬修方皆宜 |
| **乌兔太阳课** | 天元乌兔九星法推太阳、太阴、金水、紫气临山向 | 天星一派的核心课法，口径自成一家 |
| **三奇贵人课** | 天上三奇甲戊庚、地下三奇乙丙丁、人中三奇壬癸辛，顺次见于四柱天干 | 取天干顺序不逆，逆则为伪 |
| **德合课** | 天德、月德、岁德到日或到山，且日干与之相合 | 德能解煞，德合更强 |
| **天赦课** | 春戊寅、夏甲午、秋戊申、冬甲子 | 专用以赦过宥罪，旧时多于讼事、解冤用之 |
| **六合课** | 四柱地支两两六合，或日时与月建六合 | 主和合、主亲睦，嫁娶、合伙尤宜 |
| **禄马贵课** | 主命之禄、马、贵聚于四柱 | 与相主配合，出行赴任最重驿马 |

取星格的一条硬规矩：**先有干支之格，再有星曜之格。**

```
只有吉星而干支散乱 → 力虚，吉星落不住
只有格局而无一星照 → 可用而少助，属中平课
格局与吉星两全   → 上课
```

---

### 7_6 四柱内部的自检清单

课格讲完了，接下来是更重要的一步：把四柱自己查一遍。这份清单必须在出课前逐条过：

| 检查项 | 查什么 | 命中怎么办 |
| --- | --- | --- |
| **干支相战** | 四柱天干互克、地支互冲（如年月支冲、日时支冲） | 换课，内部冲战是最硬的毛病 |
| **纳音相克** | 四柱纳音互克，尤其时柱纳音克日柱纳音 | 换课 |
| **月破** | 日支冲月建之支 | 大忌，换日 |
| **日时相冲** | 时支冲日支 | 换时 |
| **五不遇时** | 时干克日干，且阴阳同性 | 换时 |
| **旬空** | 日柱旬中空亡之支见于四柱，尤其时支空亡 | 减力，能避则避 |
| **十恶大败** | 日柱为甲辰、乙巳、丙申、丁亥、戊戌、己丑、庚辰、辛巳、壬申、癸亥 | 大忌，换日 |
| **四废** | 春庚申辛酉、夏壬子癸亥、秋甲寅乙卯、冬丙午丁巳 | 换日 |
| **四离四绝** | 二分二至前一日为四离，四立前一日为四绝 | 大忌，换日 |
| **回头贡煞** | 日课回头克坐山、克主命 | 换课 |

几个容易记混的，单独说明：

```
四离：春分、秋分、夏至、冬至的前一日
四绝：立春、立夏、立秋、立冬的前一日
四废：日干支五行在当令季节处休囚死绝之地，
      春月金废（庚申辛酉）、夏月水废（壬子癸亥）、
      秋月木废（甲寅乙卯）、冬月火废（丙午丁巳）
十恶大败：禄入空亡之日，日柱为准
```

> **口径说明**：四废的取法，有以日干支为准者，有兼看四柱天干是否临绝者；十恶大败亦有只忌日柱与兼看年月时两说。本库取"以日柱为准、兼顾时柱"的从严口径，理由是这类凶日一旦误用无可补救，宁严勿宽。

---

### 7_7 大纯小疵即可用

这是本板块最要紧的一条实操原则，也是择吉能不能落到生活里的关键：

> **大纯小疵即可用。** 实际生活中不必一一做到，能大纯即可择用。

**什么是大纯，什么是小疵：**

| 层级 | 内容 | 态度 |
| --- | --- | --- |
| **大纯**（必须有） | 不犯大煞、不冲主命与坐山、四柱内部不冲克、龙与山不被克 | 缺一即换课 |
| **中平**（尽量有） | 补龙或扶山至少得一条、四柱成半局或同气、有一二吉星照临 | 得之加分，不得可用 |
| **小疵**（不必管） | 天干不成一气、纳音不甚相生、小煞未制、不得禄马贵 | 记下即可，不换课 |

为什么必须立这条原则：

```
若要求四柱全美 —— 天干一气、地支三合、纳音相生、
                   太阳到山、德星合日、禄马贵全 ——
则数年未必得一课，而婚期、工期、丧期等不得人。
择吉是为人服务的规矩，不是给人添堵的规矩。
```

**对应的操作口径**：

```
第1步：先定一个可用区间（如婚后三月内、孕期满三十七周后、
       工程许可生效期内）
第2步：在区间内按大纯的四条硬标准筛，剩下几日算几日
第3步：在剩下的日子里挑中平条件最好的一日
第4步：时辰在这一日内挑不犯日破、不犯五不遇时的
第5步：都不犯大纯，就定，不反复改
```

> **边界提醒**：可用区间本身由**专业意见**给出，不由择吉给出。婚期受双方工作安排与登记流程约束；工期受许可、气候、材料与施工安全约束；孕产相关的时间窗只能由产科医生给出。择吉只在区间内排序，绝不反向要求区间让步。

---

### 7_8 常见错

| 错法 | 表现 | 为什么错 | 怎么改 |
| --- | --- | --- | --- |
| **只堆吉神不看成格** | 数一数这一天有多少吉神，多的就是好日子 | 吉神是散点，四柱是结构；散点再多，结构自冲仍是凶课 | 先查 7_6 的自检清单，再看吉神 |
| **四柱内部自相冲克** | 年月支相冲、日时支相冲，还觉得"吉神多不怕" | 内部相战是无解的毛病，吉神压不住自己的冲 | 换课，不议 |
| **照抄通书吉格而不问对象** | 看到"天干一气大吉"就套，不问补哪条龙、扶哪座山 | 课格是工具，离开补龙扶山的对象就没有意义 | 先按板块6定对象，再选课格 |
| **只择日不择时** | 挑了个好日子，时辰随手定 | 时柱是收口，日好时坏整课破功 | 日与时一起筛 |
| **为一课之美而改期** | 因找不到完美课，把工程或婚期一推再推 | 违背大纯小疵原则，也违背现实约束 | 定区间，在区内取最优，不反复改 |
| **纳音与正五行各取一半** | 正五行说生、纳音说克，就挑对自己有利的那个用 | 两套坐标混用，等于没有坐标 | 选定一家，贯通使用 |

### 7_9 案例小故事：一课换了三次，越换越差

有人要上梁，自己排了三课来问哪一课好。我把三课摊开，先不看吉神，只看四柱内部：

```
第一课：甲子年 丙寅月 甲戌日 甲子时
        天干三甲一丙，甲木得寅月之禄，地支寅戌半合火
        毛病：日支戌与月支寅虽半合，然戌为火墓，
              上梁宜旺不宜墓；且日时子戌无冲，可算可用

第二课：甲子年 丙寅月 庚辰日 丙戌时
        毛病：日支辰与时支戌正冲，日时自冲；
              又日干庚与时干丙火克金，时克日
              内部两处相战，这一课直接出局

第三课：甲子年 戊辰月 壬午日 丙午时
        毛病：日支午与年支子冲，年月跨柱相冲；
              时干丙与日干壬又成水火交战
              比第二课更乱
```

他排这三课的依据是"吉神个数"：第三课的吉神最多，所以他认为第三课最好。而按 7_6 的自检清单，第二、第三课都属于**内部自相冲克**，是硬毛病，吉神再多也救不回来；第一课虽不成什么漂亮格局，却四柱无冲无战，甲木得禄，属于**大纯小疵**。

后来第一课按上梁的要求微调了时辰，避开日破与五不遇时，再用板块6的三关核了一遍：木龙得寅月禄旺，坐山得太阳照临，主命不冲不刑，成色到中平偏上，就定了。

**落点**：日课四柱的评判顺序是**先内后外**——先看这一课自己站不站得住（有没有自冲自克、有没有犯十恶大败四废四离四绝），再看它长得像不像样子（成不成格），最后才数外面挂了多少吉神（有没有太阳、德、禄马贵）。把顺序倒过来，就会出现"吉神最多的那一课其实是三课里最差的一课"这种结果。大纯小疵是一条务实原则，但它的前提是**大纯必须真纯**：内部冲战、犯大煞、冲主命这一类，从来不在小疵的范围里。

## 板块8 · 分类择日：嫁娶、营造、安葬、出行、开市

> 板块6、7给出的是通用骨架：三纲领、四柱成格。到了具体事务上，还要再加一层场景规则，因为**不同的事，怕的煞不一样，要的吉也不一样**。
> 安葬重的是收气与避重丧，开市重的是成开满而忌破闭，两者几乎不共享任何一条宜忌。把一处的规矩搬到另一处，是择吉最常见的误用。
> 本篇给五类常见事务各自的红线、宜取与权变，并给出一条总原则：大事从严，小事从宽。

---

### 8_1 为什么必须分类：同一天，五件事五个结论

择吉的输入是**事加人加方加日时**四件套，其中"事"是第一项。同一个日子：

| 用事 | 可能结论 | 原因 |
| --- | --- | --- |
| 嫁娶 | 可用 | 得三合、不将，不犯新郎新娘本命 |
| 安葬 | 不可用 | 犯重丧，或日辰为复日 |
| 营造动土 | 不可用 | 三煞占山，或犯土符 |
| 开市 | 可用 | 值成日，且不犯月破 |
| 出行 | 不可用 | 犯往亡 |

**所以"这天是吉日还是凶日"这句话本身就是错的问法。** 正确的问法是：这天对某人办某事，在某方位，可用不可用。

分类择日的操作顺序：

```
第1步：定事（属于哪一类，有没有子类，如上梁与动土不同）
第2步：查这一类专属的红线（首避）与次避、宜取
第3步：回看板块6的三纲领（补龙、扶山、相主）
第4步：回看板块7的四柱自检与成格
第5步：都过了，出课并登记
```

---

### 8_2 嫁娶

**这一类最特殊的地方是：主命有两个。** 新郎、新娘两人生年都要不冲不刑，双方父母亦须兼看。这是嫁娶择日比其他事务窄得多的根本原因。

| 层级 | 名目与要求 |
| --- | --- |
| **首避** | 月破、厌对、往亡、阴差阳错、三娘煞；日支冲新郎或新娘生年支；日支与新郎或新娘生年支相刑 |
| **次避** | 四离四绝、受死日、披麻煞；女方本命的禁婚年（如子午相冲之年一类，各家算法不一） |
| **宜取** | 天喜、红鸾、三合、六合、不将；天德、月德；成日、开日、定日 |
| **可用权变** | 吉星不足之处，以德星、天喜、三合补之；小煞未制而有太阳、天德同到，可不避 |

几个名目的说明：

```
不将：干支阴阳相配而不偏，阳将伤夫、阴将伤妇，
      阴阳俱将者夫妇俱伤，阴阳不将者吉
阴差阳错：丙子、丁丑、戊寅、辛卯、壬辰、癸巳、丙午、丁未、戊申、辛酉、壬戌、癸亥，共十二日
三娘煞：每月初三、初七、十三、十八、廿二、廿七
厌对：月厌所冲之日，月厌逐月逆行十二辰，其冲即为厌对，主夫妻不和，嫁娶大忌
```

> **口径说明**：三娘煞一说出自民间传说（三娘因月老不为她牵线而报复），不见于《协纪辨方书》等官修选择书，属于**民俗性凶煞**。相信者避之，不信者不必避。本库列为次避，不列首避。是否采用，应在出课前与事主说明并登记。

---

### 8_3 营造

营造是一大类，内部还要分：**动土（破土开工）、奠基、上梁、封顶、入宅、修方**。动土与上梁的红线略有不同，其中动土最忌土煞，上梁最忌冲山。

| 层级 | 名目与要求 |
| --- | --- |
| **首避** | 三煞方、岁破方、戊己都天、月建（月建日不可动土）、土符；坐山被占、被冲 |
| **次避** | 杨公十三忌、埋儿杀、土瘟、土禁、地囊；四离四绝 |
| **宜取** | 太阳到山到向、天德、月德、月恩；成日、开日、定日；坐山得临官帝旺 |
| **可用权变** | 煞占向而不占山者，视可否制；小煞有太阳、德星照临可不制（制法见板块5） |

几个名目的说明：

```
三煞：申子辰年煞在南方巳午未，寅午戌年煞在北方亥子丑，
      亥卯未年煞在西方申酉戌，巳酉丑年煞在东方寅卯辰
      坐三煞方为大忌，向三煞方次之，可议制
戊己都天：戊己属土，为都天煞，动土修造犯之主损人口，
          口诀各派不同，须按所用通书之表逐年查
土符：逐月不同，正月丑、二月巳、三月酉之类，
      土符日动土主土气不和，属次避
杨公十三忌：正月十三、二月十一、三月初九、四月初七、五月初五、六月初三、
            七月初一与廿九、八月廿七、九月廿五、十月廿三、十一月廿一、十二月十九
```

> **口径说明**：杨公十三忌托名杨筠松，明清官修选择书并不收录，属民间传承。与三娘煞一样，本库列为次避，不列首避。真正不能碰的是三煞、岁破、戊己都天这一类，各家通说皆忌。

> **边界提醒**：营造择吉**完全不参与工程判断**。是否具备开工条件，取决于施工许可、图纸审查、地质勘察结论、结构安全评估、现场防护与气候条件；是否具备使用条件，取决于竣工验收与消防、规划等部门的核验。上梁、封顶等关键工序的安全与技术要求，一律以施工方与监理的专业意见为准。任何因"日子好"而压缩工期、跳过验收、抢在不利气候条件下施工的做法，都是本库明确反对的。

---

### 8_4 安葬

安葬（包括入殓、破土、安葬、立碑）是择吉里规矩最密的一类，也是**最不该由普通人自行操作**的一类，原因见 8_4 末尾的边界提醒。

| 层级 | 名目与要求 |
| --- | --- |
| **首避** | 重丧、三煞、岁破；日支冲亡人或孝子生年支 |
| **次避** | 复日、四离四绝、月破、收日；克山运、阴府 |
| **宜取** | 太阳到山、太阴到山；天德、月德；鸣吠日、鸣吠对日；坐山得生旺墓之气 |
| **可用权变** | 停柩待期者用权变法；急葬者另有权变口诀（见 8_7） |

几个名目的说明：

```
重丧：主丧事重来，口诀大致为正七月逢甲庚、二八月逢乙辛、
      三九与六十二月逢戊己、四十月逢丙壬、五十一月逢丁癸，各家略有出入
复日：与本季旺气重复之日，主事有反复，安葬忌之。
      各月所值不同，须按通书之表查
鸣吠：金鸡鸣、玉犬吠之类，为安葬专用吉日，
      取金玉之声以安亡灵，属民俗性吉神
```

> **口径说明**：重丧与复日的具体所值之日，各家通书所列差异较大，有的相差一两日。这是择吉里少有的"连名目所值都未统一"的一块。本库的处理是：若两家通书给出不同结果，**取两家之并集从严避之**；若因此无日可选，则走权变法。

> **边界提醒**：安葬相关的一切时间节点，首先受**殡葬管理法规、死亡证明与注销登记流程、墓地管理方规定、遗体保存条件**的约束。停柩期限、火化与安葬的时间要求，按民政部门与殡葬服务机构的规定执行。择吉不参与其中任何一项判断，也不构成延长停柩期限的理由。

---

### 8_5 出行赴任

出行赴任是五类里最轻的一类，规矩最少，权变空间最大。

| 层级 | 名目与要求 |
| --- | --- |
| **首避** | 往亡、归忌、四离四绝；日支冲出行者生年支 |
| **次避** | 月破、受死、白虎、天贼 |
| **宜取** | 天马、驿马、成日、开日、定日；出行者本命之禄马贵到日时 |
| **可用权变** | 行程已定而日有小疵者，择吉时出发即可；时辰可完全化解此类的多数小忌 |

几个名目的说明：

```
往亡：主出门不返或去而不利，逐月不同，另有气往亡一说
归忌：主归期受阻，逐月不同，与往亡并为出行两大忌
驿马：申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳，
      出行赴任取马星，取其动而能达
```

**这一类的实操要点：时辰的可调性最高。** 出行不像动土那样受方位与坐山的强约束，也不像嫁娶那样涉及双方家族，只要日子不犯首避，时辰挑一个不与日支相冲、不犯五不遇时的即可。

> **边界提醒**：出行择吉不参与交通与安全判断。是否出行，取决于天气预警、道路与航班状况、车辆状况、身体健康与目的地安全形势。因"日子不好"而取消必要行程，或"日子好"而在恶劣天气、疲劳状态下强行出行，都是对择吉的误用。

---

### 8_6 开市开业

开市开业（含签约、挂牌、剪彩、上新）属于"求财求兴"一类，宜取的是**成、开、满**这三个建除神，忌的是**破、闭**。

| 层级 | 名目与要求 |
| --- | --- |
| **首避** | 破日、闭日、月破；日支冲店主或法人本命 |
| **次避** | 四离四绝、劫煞、灾煞、五虚 |
| **宜取** | 成日、开日、满日；天德、月德、月恩、五富、禄库；店主本命之禄马贵 |
| **可用权变** | 值除日、定日、危日者可用而不佳；吉星不足者以成开满之建除补足 |

建除十二神与开市的对应：

| 建除 | 开市用法 | 建除 | 开市用法 |
| --- | --- | --- | --- |
| 建 | 平 | 危 | 平，可权用 |
| 除 | 平，可权用 | 成 | **上吉** |
| 满 | **吉** | 收 | 平 |
| 平 | 平 | 开 | **上吉** |
| 定 | 平，可权用 | 闭 | **忌** |
| 执 | 平 | 破 | **大忌** |

> **口径说明**：建除十二神的吉凶分配，各家通书有细微差别，尤其"危日"一说是凶是平，分歧较大。本库从《协纪辨方书》一路下来的主流口径：危日用于安床、祭祀尚可，用于开市属中平，不列忌。

> **边界提醒**：开业择吉不参与任何经营判断。是否具备开业条件，取决于营业执照与行业许可、消防与卫生核验、场地安全、资金安排与供应链准备。因"日子好"而在证照未齐、消防未验、人员未训的状态下开业，是真实且常见的风险，与本库的立场完全相悖。

---

### 8_7 权变法四则

所谓权变，指的是**在无可选择或事情紧急的情况下，用以替代常规择日的变通办法**。四则权变法点到为止，完整的口诀与适用条件见板块10（通书怎么读）与板块12（书目地图）。

| 权变法 | 适用场景 | 核心思路 | 注意 |
| --- | --- | --- | --- |
| **诸事不宜权变法** | 通书标诸事不宜，而事非办不可 | 以德星、天赦、太阳等大吉神压之；或另择吉时以时救日 | 诸事不宜往往是通书的从严口径，先判断是不是小煞口径造成的 |
| **建房权变法** | 工期紧迫，无法等到理想课 | 先避首避（三煞、岁破、戊己都天），其余以吉时与制煞补 | 权变不豁免首避，这一点没有商量 |
| **安葬权变法** | 停柩已到期，或急葬 | 用急葬法、鸣吠日、太阳到山等替代常规课 | 见 8_4 的边界提醒，法规期限优先 |
| **嫁娶权变法** | 婚期不可改，如双方行程与登记已定 | 以不将日、天喜、德星优先，冲犯以吉时与本命化解 | 首避中的月破、厌对、往亡不因权变而豁免 |

**权变的三条底线**：

```
1. 权变只能放宽次避与小煞，绝不豁免首避
2. 权变优先在"时"上做文章，其次才是"日"
3. 用了权变的课，必须在出课登记表上注明"权变"二字，
   并写明放宽了哪一条，事后回填验证
```

---

### 8_8 大事从严，小事从宽

这条原则决定了一个人能不能把择吉长期用下去而不被它拖累：

> **大事从严，小事从宽。** 寻常买卖、访友、闲游，除极大凶煞外，诸般小忌皆可放下。

| 事务量级 | 举例 | 口径 |
| --- | --- | --- |
| **大事** | 嫁娶、安葬、动土奠基、上梁、入宅、开市、赴任、手术择期 | 三条纲领全查，四柱自检全过，首避绝不豁免 |
| **中事** | 签约、搬家、出行远门、入学、开光、立契约 | 查首避与相主，四柱查有无自冲，成格可不计 |
| **小事** | 寻常买卖、访友、闲游、理发、扫舍、一般聚餐 | 不犯月破、岁破一类极大凶煞即可，余者不问 |

为什么必须分：

```
若小事也从严：一年三百六十日几无可办之日，人将困于择日而废事
若大事也从宽：择吉就失去它唯一的价值，沦为心理安慰
```

**判断量级的一条实用标准**：这件事做错了，**能不能重来**。安葬、动土、嫁娶这类不可重来或重来代价极大的，从严；买菜、访友这类随时可以改期的，从宽。

### 8_9 常见错

| 错法 | 表现 | 为什么错 | 怎么改 |
| --- | --- | --- | --- |
| **把阴宅规矩套到民俗活动** | 办个社区活动、开个店铺，也要查重丧、克山运、鸣吠 | 重丧、复日、鸣吠是安葬专属，与开业、聚会毫无关系 | 先定事类，只查该类的表 |
| **把嫁娶宜忌套到开市** | 开市要看不将、天喜、红鸾、三娘煞 | 不将与三娘煞是嫁娶专属，开市要的是成开满与五富禄库 | 同上 |
| **把动土规则套到入宅** | 入宅也去避土符、杨公十三忌 | 土符土禁是破土动土之事；入宅属移徙，看的是成开与不冲主命 | 细分子类，营造内部也要再分 |
| **不分轻重，见忌就换** | 通书写诸事不宜就换日子 | 违反大煞避之、中煞制之、小煞不必制 | 按 8_7 判断是不是小煞口径 |
| **只查日不查时** | 日子挑得极细，时辰随便 | 出行、开市这类轻事务，时辰的可调性恰恰最大 | 日与时一起定 |
| **跨类照抄吉神表** | 拿一本通书的通用吉神表，套用所有事 | 通用吉神表只处理日神层，不处理事类差异 | 事类专属表优先 |

### 8_10 案例小故事：两套规矩，撞在同一天

同一天，两位朋友先后来问，问的是两件完全不同的事。

```
朋友甲：要给店里办开市，两年一次的扩店，
        装修与消防核验都已通过，执照也办好了，
        问这天能不能开
朋友乙：家里老人过世，要在同一天安葬，
        殡仪那边排期也正好是这天
```

查下来，这一天的情况是：

| 项目 | 这一天的情形 | 对开市 | 对安葬 |
| --- | --- | --- | --- |
| 建除 | 值成日 | 上吉 | 平，可用 |
| 神煞 | 得月德、五富 | 宜 | 宜 |
| 日辰 | 不犯月破、不犯四离四绝 | 可用 | 可用 |
| 重丧 | 该月重丧日之一 | **无关** | **首避，犯** |
| 冲 | 不冲甲的店主本命 | 可用 | 不冲亡人与孝子，可用 |

结论很干脆：**甲可以用，乙不能用。**

甲这件事：成日加月德加五富，店主本命不冲，属于开市里相当好的一课，按 8_6 的表一路走下来没有任何一条首避被犯。他问"要不要再等等看有没有更好的"，我让他直接定，理由是：执照与消防核验已过，扩店停业每一天都是成本，按"大纯小疵即可用"（详见板块7），不必为一个更漂亮的课再拖。

乙这件事：犯重丧。这是安葬首避里排在第一位的名目，不因任何权变而豁免。后来改期两日，殡仪那边也调得开，重排一课，取太阳到山、鸣吠日，孝子本命不冲，就定了。

**落点**：分类择日的意义，就在于**同一天可以有相反的两个结论，而两个结论都对**。甲的可用与乙的不可用，不矛盾，因为它们根本不在同一张表上。判断的第一步永远是"这是哪一类事"，而不是"这天好不好"。那位朋友乙如果只看了"成日、月德、五富"这几个通用吉神就定下来，就会踩上安葬最不该踩的那条线；反过来，甲要是照安葬的规矩去查重丧、复日，也会被一堆无关名目吓住，白白错过一个本来很好的开业日。规矩要先分类，再套用，顺序不能倒。

## 板块9 · 造命：剖腹生产择吉与它的边界

> 造命这个词，在传统选择术里指的是造一个好日课，在当代港台命理界指的是择期剖腹生产造一个好八字。两个含义差得很远，却共用一个名字，这是择吉领域最容易造成误解的一处。
> 本篇先把两个含义掰开，再记录后者的操作流程与文献形态，然后把最多的篇幅留给边界：医学、伦理、技术、统计、法律五道界线，一条一条落到实处。
> 本库的立场在最后：这一支作为命理文化现象予以记录与研究，不作任何实践推荐。

---

### 9_1 两种造命，必须先分清

这是本篇的第一件事，也是很多人一开口就错的地方：

| 项 | 造命含义一 | 造命含义二 |
| --- | --- | --- |
| **出处** | 明清官修选择书，以《协纪辨方书》卷三十三为代表 | 二十世纪后期港台命理界的实务用语 |
| **造的是什么** | **造一个好日课**（年月日时四柱） | **造一个好八字**（婴儿的出生时间） |
| **动作主体** | 择日师，为造葬修方之事选课 | 命理师，为尚未出生的婴儿选出生时刻 |
| **原文** | 一看来龙宜何局以补之，二看山向何煞宜避，三看主人本命宜何如以扶之 | 无古典依据，属现代衍生用法 |
| **本库位置** | 板块6 已讲 | 本篇 9_3 起 |

**一句话区分**：含义一是**给事情选时间**，含义二是**给人选时间**。前者选的是事的时空坐标，后者选的是一个生命来到世界的第一口气的时刻，两者涉及的风险完全不是一个量级。

> **口径说明**：凡见"造命之法"，指的几乎都是含义一；凡见"剖腹生产造命""造命择时"，指的是含义二。本库此后凡指含义二，一律写作"剖腹生产择吉"，不再单独使用造命二字。

### 9_2 含义一：传统选择术的造命

《协纪辨方书》卷三十三造命一篇，通篇讲的是造葬修方如何取课，与生育毫无关系。其步骤即板块6的三看：

```
一看：来龙宜何局以补之                  补龙
二看：山向何煞宜避，何煞可制，取何吉星照之  扶山兼制煞
三看：主人本命宜何如以扶之                相主
      三者俱得而后举，事吉无不利矣
```

### 9_3 含义二：剖腹生产择吉在做什么

基本思路是：既然八字由出生年月日时决定，而剖宫产的出生时刻可以人为约定，那么就可以**先选一个好八字，再倒推回去定手术时间**。

这一支的若干前提假设，必须先说清楚，因为它们本身就是可争议的技术问题：

| 前提假设 | 内容 | 争议点 |
| --- | --- | --- |
| 八字决定命运 | 出生时刻的四柱决定一生命运 | 无可验证的证据，见 9_8 |
| 出生时刻可控且可界定 | 手术时间能精确到时辰；出生以娩出、断脐、第一声哭或自主呼吸为准 | 实际排程受医院、麻醉、医师安排约束；界定口径术数内部不统一，见 9_8 |
| 剖腹产与自然产的命同等 | 人为取出的婴儿与自然分娩者效力相同 | 术数内部亦有反对意见 |
| 造得出来就有用 | 选出的八字真的会应验 | 属信念而非事实，见 9_8 |

**这一支与正统选择术的关系**：它借用了择吉的术语（日课、吉时、神煞、格局），但**不处理龙、山、向、方位**，也不处理主事人与方位的匹配，本质上更接近八字命理的逆向应用，而不是选择术的分支。不能因为它用了择吉的词汇，就把它算作择吉。

### 9_5 剖腹生产择吉的一般流程

以下按书中所载思路整理，作为对这一支方法论的**客观记录**，不作推广，也不构成任何建议：

```
第1步 · 定可用区间：由产科医生给出医学上允许的孕周窗口
第2步 · 逐日逐时排盘：把区间内每一日、每一时辰的八字排出
        （一日十二时辰；书中有一日十三命造之说，涉及时辰交界与早子时晚子时的处理）
第3步 · 逐课筛选：按格局、用神、日主强弱、六亲、大运顺逆、神煞吉凶逐层筛
第4步 · 定课：取筛选后最优者作为目标时间
第5步 · 与医院排程对齐：能否落到目标时刻，取决于医院安排
```

**这一流程最大的问题不在第 2 步到第 4 步，而在第 1 步与第 5 步**：区间由医学给出而不由命理给出，落点由医院排程决定而不由择日决定。命理判断只在中间那一段起作用，而这一段恰恰是全部环节中**唯一与真实风险无关**的一段。

### 9_6 医学边界：这是最硬的一条

**剖宫产是外科手术。** 有无医学指征、何时手术、采用何种术式，只能由产科医生决定。择吉不构成选择分娩方式的理由，也不构成提前或推迟手术的理由。

具体的医学风险逐条说明，不留模糊：

| 风险对象 | 风险内容 |
| --- | --- |
| **新生儿（早产相关）** | 无医学指征的择期剖宫产，按产科通行共识一般不建议早于三十九孕周施行。三十七至三十八周出生的早期足月儿，与三十九周后出生者相比，呼吸系统并发症与新生儿重症监护入住率更高；三十四至三十六周的晚期早产儿，远期神经发育与学习障碍风险随之上升 |
| **新生儿（术式相关）** | 剖宫产儿未经产道挤压与宫缩应激，湿肺、短暂性呼吸急促的发生率高于阴道产；医源性早产若胎龄评估有误，风险成倍增加 |
| **产妇（近期）** | 出血、输血、切口感染、子宫内膜炎、尿路感染、静脉血栓、麻醉相关并发症、邻近脏器损伤，发生率均高于阴道分娩 |
| **产妇（远期）** | 子宫瘢痕，再次妊娠面临子宫破裂、前置胎盘、胎盘植入、瘢痕妊娠等风险；盆腹腔粘连，再次手术难度增大；剖宫产次数越多，风险累积越高 |

三条不可逾越的界线：

```
界线一：是否存在剖宫产指征，由产科医生判断，不由任何人择日得出
界线二：手术时机由产科医生根据孕周、胎儿成熟度、母体状况与医院条件决定，
        择日不参与这一决定
界线三：因择吉提前手术等于人为制造医源性早产，因择吉推迟手术可能错过干预窗口
```

> **边界提醒**：本库在此明确表态，**任何以择吉为由要求提前或推迟剖宫产、或以择吉为由选择剖宫产而非阴道分娩的做法，本库一律反对**。上述风险是真实的、有统计支持的，不是理论上的可能。一切生育相关的决定，请以产科医生的专业意见为唯一依据。

### 9_7 伦理边界

剖腹生产择吉涉及的不是一个人的身体，而是**两个人**：产妇与婴儿。

| 伦理问题 | 具体说明 |
| --- | --- |
| **产妇的身体自主** | 剖宫产对产妇而言是重大手术。若为迎合一个命理结论而接受手术，产妇的知情同意是否建立在充分的医学信息之上，值得追问 |
| **婴儿的身体自主** | 婴儿无法表达意愿，也无法对这场为它而做的手术作出同意。由他人代为决定其出生方式与出生时刻，涉及代际的伦理责任 |
| **决策顺序的颠倒** | 正常顺序是医学评估在前、时间选择在后。剖腹生产择吉的顺序是先定命理结论、再找医学配合，这是顺序的颠倒 |
| **资源挤占与风险不对称** | 命理上的好日子往往只有有限的几天，择期手术在这些日期扎堆，挤占本已紧张的产科排程与床位；而承担风险的是产妇与婴儿，作出选择的是他人 |

> **边界提醒**：伦理边界与医学边界是两条不同的线。即便某个机构或某地对非医学指征择期剖宫产不作限制，伦理上的追问依然成立：**把一个无法表达意愿者的手术时机，交给一套无可验证的技术来决定，这个决定是否正当。**

---

### 9_8 技术边界：八字命理本身站不站得住

即便暂且放下医学与伦理，单就技术层面，剖腹生产择吉也面临一系列无法回避的问题：

| 问题 | 说明 |
| --- | --- |
| **八字命理的可验证性存疑** | 八字推命至今没有通过严格的、可重复的实证检验。它是一套自洽的解释系统，不是一套可验证的预测系统 |
| **造出来的八字能否决定命运，无证据** | 没有任何可验证证据表明，人为选定的出生时刻会决定一个孩子的一生命运 |
| **同八字不同命** | 同一时刻出生的婴儿数以千计。以年出生人口计，同一时辰（两小时）内出生者可达数千人，命运显著不同 |
| **出生时刻如何界定** | 以胎儿完全娩出、脐带结扎、第一声哭或自主呼吸建立为准，四种口径可相差数分钟，跨时辰则整盘皆变 |
| **真太阳时与子时交界** | 八字以地方太阳时为本，中国横跨五个时区，统一用北京时间须作经度校正，夏令时期间的出生记录还需还原；二十三点至一点为子时，跨日与早子时晚子时的处理各家不一，术数内部至今无定论 |
| **后天因素的权重** | 一个人的成长受家庭、教育、健康、地域、时代、机遇等大量因素影响，这些因素的权重远超出生时刻这一变量 |

**同八字不同命这一条，值得单独展开：**

```
同一家医院、同一分钟出生的两个婴儿，八字完全相同，
一个成长于资源充足的家庭，一个成长于困境之中，
一个健康，一个有先天疾病，他们的一生会显著不同。
若八字决定命运，如何解释这一差异？
命理学的常见回应是引入父母八字、风水、姓名、行善等因素加以补充，
而一旦需要引入这么多补充变量，出生时刻决定命运这个前提本身就被稀释了。
```

> **口径说明**：术数内部对同八字不同命有多种解释，包括引入出生地风水、父母八字、姓名、胎教（本书第一篇即强调胎教造命六大原则）、个人修行等。这些解释在术数体系内部自洽，但在体系之外不构成可验证的说明。本库记录这些解释，不作采纳。

### 9_9 统计边界：那些范例说明了什么

《造命金丹》第一篇中有历年来公布于各刊物吉日吉时造命范例一章。这类范例是理解这一支方法论最直接的入口，也是其证据链最薄弱之处：

| 问题 | 说明 |
| --- | --- |
| **选择性样本** | 范例只会收录被认为成功或值得展示的案例。未按范例出生的孩子、按范例出生但后来平淡或坎坷的孩子，不会出现在书里 |
| **缺少对照与失败案例** | 没有同期、同人群、未按范例出生的对照数据；一部以范例呈现的书天然不包含失败案例，而失败案例恰恰是判断有效性的关键 |
| **评价标准由作者给出** | 范例中命好、发福之类的评语出自作者本人判断，缺乏独立评判与客观指标 |
| **无长期随访** | 八字论命讲的是一生，而范例中的孩子出书时往往年幼，缺乏足够长的观察期 |
| **事后归因** | 先有结果后有解释，是命理案例最常见的归因方式 |

**什么性质的问题**：假如有人每年公布十个吉日吉时，二十年下来公布两百个。这二十年里按这些时刻出生的孩子数以万计（同一时刻出生者远不止一人），其中必然有人得意、有人失意。只把得意的挑出来写成范例，看上去证据充分，实际上什么也没有证明。

> **边界提醒**：本库不否认这些范例作为**民俗文献与流派史料**的价值——它们真实反映了二十世纪末港台命理界的实务形态与话语方式。但这个价值是史料价值，不是有效性证据。把范例当作有效的证明，是统计上的根本错误。

### 9_10 法律边界

| 层面 | 说明 |
| --- | --- |
| **国内** | 剖宫产属手术，须有医学指征并履行知情同意程序，知情同意书须如实载明指征与风险，以非医学理由决定手术时机可能影响其合法性与有效性。《母婴保健法》及医疗机构管理的有关规定要求医疗行为遵循医学原则，无医学指征的择期剖宫产，医疗机构有权不予实施 |
| **医师执业规范** | 医师实施手术须基于医学判断。在无医学指征情况下按非医学理由实施手术，与执业规范相悖 |
| **台港等地** | 台湾地区对非医学必要的剖宫产亦有相关规范与健保给付限制；香港公营医疗体系对无医学指征的择期剖宫产同样设有限制 |
| **国际共识** | 世界卫生组织等机构的立场是，剖宫产应在有医学指征时实施，不鼓励非医学必要的剖宫产 |

> **边界提醒**：上述内容是对一般情况的概述，**不构成法律意见，也未必与各地现行规定完全一致**。具体规定以当地卫生健康行政部门与就诊医疗机构的现行制度为准；如有疑问，请向医疗机构或法律专业人士咨询。

| 论剖腹生产造人才 | 看其核心论证，注意其前提是未经证成的 |
| 造命须知与吉日吉时造命范例 | 看其实务流程并对照 9_5、9_6 的边界；范例当作样本读，不当作证据读，对照 9_9 |

---

### 9_12 常见错

| 错法 | 表现 | 为什么错 | 怎么改 |
| --- | --- | --- | --- |
| **把造命当成可以改命的技术** | 认为选个好八字，孩子一生就定了 | 无证据支持；后天因素权重远超出生时刻 | 把出生时刻视为一个变量，不是决定项 |
| **用择日去压医学指征** | 为赶一个吉时要求提前手术，或为择日拒绝必要的剖宫产 | 这是本篇全部边界中最严重的一条，涉及两条人命 | 医学决定优先，择日不参与 |
| **混淆两种造命** | 引《协纪辨方书》的造命之法，去论证剖腹生产择吉有古典依据 | 两者同名异实，古籍里的造命讲的是日课 | 按 9_1 的表格分清 |
| **把这一支算作择吉的分支** | 认为学了补龙扶山就能做剖腹产择日 | 它不处理龙、山、向、方位，属八字命理的逆向应用 | 认清其归属 |
| **把范例当作有效性证据** | 书里有那么多成功范例，总不会都是巧合 | 选择性样本，缺对照、缺失败案例、无随访 | 按 9_9 的六条逐一检验 |
| **忽略出生时刻的技术细节** | 直接用钟表时间排盘 | 真太阳时、经度校正、夏令时、子时交界、娩出与断脐的界定，每一条都能改变整盘 | 先处理这些前提，再谈论命 |

### 9_13 案例小故事：一对夫妻来问剖腹产择日

有一对夫妻来找过我，妻子已足月，产检一直顺利，医生评估可以阴道试产。他们听人说可以选个好八字，想请我择个吉时剖腹。我没有先谈八字，先问了三个问题：

```
问一：医生有没有给出剖宫产指征？没有，医生说可以顺，是他们自己想选个时间
问二：孕周多少？医生对胎儿成熟度怎么评估？三十八周多一点，医生说过可以再等等
问三：医院接不接受无指征的择期剖宫产？还没问过
```

三个问题的答案已经决定了我的回答。我跟他们说了四件事：

1. **这一课的区间不由我给，也不由任何择日师给。** 三十八周多，按产科通行共识，无医学指征的择期剖宫产一般不建议早于三十九孕周。为赶一个时辰而提前，等于人为制造医源性早产，新生儿呼吸系统并发症的风险是真实存在的。
2. **剖宫产是有长期代价的手术。** 这一胎的子宫瘢痕，会影响下一次妊娠与分娩方式的选择，这个代价要算进去。
3. **造出来的八字能不能决定命运，没有证据。** 同一时刻出生的孩子数以千计，命运各异。为一个无可验证的收益，去承担两项有统计支持的真实风险，这个交换不划算。
4. **如果医生评估后确实有剖宫产指征，那就在医生给出的时间窗内做。** 这个窗是医学给出的，我可以在窗内帮他们看看有没有心理上更安定的日子，但那是安慰层面的事，不是改变医学结论的事。

后来他们顺产，孩子很健康。半年后遇到，妻子说当时最有用的其实是第三点，因为没人跟他们讲过同一时刻出生的孩子有多少。

**落点**：剖腹生产择吉这一支，本库作为命理文化现象予以记录，作为流派史料予以研究，但**不作实践推荐，且明确反对用它去干预分娩决策**。它的边界不是一处模糊的提示，而是五道具体的线：医学上，剖宫产是手术，指征与时机由产科医生决定；伦理上，决策者与风险承担者不是同一人；技术上，八字命理的可验证性存疑，同八字不同命这一事实至今无解；统计上，书里的范例是选择性样本，不能作为有效性证据；法律上，多地医疗机构对非医学指征的择期剖宫产设有明确限制。择吉这门学问的价值，在于它帮人在给定的约束里找到安心的落点，而不是让人为了一个落点去改变约束。当择吉开始要求现实为它让路的时候，它就已经不是择吉了。

## 板块10 · 通书与黄历怎么读

> 黄历不是择吉的答案，是择吉的索引。它按"日"给结论，而择吉要的是"事加人加方加日时"四件套的匹配结果。
> 会用的人拿它做粗筛，不会用的人拿它当命令。这一板块把一页黄历逐栏拆开，说清楚每栏能信多少、信到哪一步为止。

---

### 10_1 一页黄历的构成：逐栏拆开看

市面上的黄历（日历、通书、手机黄历）版式各异，栏目大同小异。先把栏目认清，再谈怎么用。

| 栏目 | 它是什么 | 怎么看 | 常犯的错 |
| --- | --- | --- | --- |
| **公历 / 农历** | 两套日期对照 | 只看作定位，不参与吉凶判断 | 拿农历月当干支月，这是坐标层最常见的错（详见板块1） |
| **干支（年月日时）** | 择吉真正的时间坐标 | 一切推算的起点，先看它 | 只看日柱，忽略年柱月柱，年家月家大煞全漏 |
| **节气 / 月建** | 干支月的分界 | 过节气才算换月，不是过初一 | 月初但不交节，仍算上月 |
| **宜 / 忌** | 通书的成品结论 | 作粗筛，不作终判 | 把"宜"当命令，把"忌"当禁令 |
| **吉神 / 凶煞** | 宜忌的推导依据 | 比宜忌栏更值得看 | 只看宜忌不看成因，遇到打架无从判断 |
| **建除十二神** | 建除满平定执破危成收开闭 | 看当日"底色"，黄黑道同看 | 单看"破日"就判凶，不看成日开日与用事的配合 |
| **二十八宿** | 井鬼柳星张翼轸等二十七或二十八宿值日 | 多数通书并列，作参考项 | 把宿曜吉凶当成主要判据 |
| **九星（紫白）** | 一白到九紫，入中顺飞 | 看方位配合时用，须有坐向 | 无坐向就谈九星，等于悬空 |
| **彭祖百忌** | 如"甲不开仓财物耗散"之类日干日支禁忌 | 民俗层面的小提醒 | 当成硬规则逐条执行 |
| **冲煞** | 日支冲何生肖 | 看主事人生年是否犯冲 | 只查生肖不查完整生年四柱 |
| **值神（黄黑道）** | 青龙明堂金匮天德玉堂司命为黄道，余六神为黑道 | 看当日值班之神 | 黄道日一概吉，不看值神与用事是否相配 |
| **胎神** | 传说中胎儿相关的方位禁忌 | 民俗项，安床、修造避之 | 把民俗禁忌当技术判据 |
| **五行（纳音）** | 如"剑锋金""大林木"之类 | 正五行择日用的是干支本气五行，不是纳音 | 用纳音五行去论生克，体系错 |

> **口径说明**：本库用**正五行**（干支本气：甲乙木、丙丁火、戊己土、庚辛金、壬癸水）论生克补扶，不以纳音五行为主。纳音在择吉中多作辅助描述，不是生克判据。

---

### 10_2 三栏必须先看的坐标：日期、干支、节气

翻开黄历，先别看宜忌。先看这三栏，因为它们是后面所有栏目的地基。

```latex
第1栏  公历与农历      → 定位，确认你看的是哪一天
第2栏  干支四柱        → 择吉的正式时间坐标
第3栏  节气与月建      → 判断干支月是否已经切换

三栏对不上（例如农历已入新月初一、节气未交），
一律以"节气"为准定干支月，不以农历月为准。
```

这一点看起来琐碎，实际是黄历使用者出错频率最高的一处：**农历月初一到三十，与干支月的初一（交节日）并不同步**。黄历上写的"六月"，与干支历的"未月"可能差着十来天。

---

### 10_3 宜忌栏：它是怎么算出来的

宜忌不是天启，它是通书编者按一套规则推出来的成品。理解这一点，你就不会再把它当命令。

```latex
通书生成"宜忌"的流程（简化）：

   当日干支
      ↓
   起出各家神煞（年神、月神、日神、建除、黄黑道、二十八宿）
      ↓
   按"用事类别"分别权衡（嫁娶、营造、安葬、出行、开市各有侧重）
      ↓
   吉能压凶 → 记为"宜"
   凶能压吉 → 记为"忌"
      ↓
   遇到大煞，直接记"诸事不宜"或"大事勿用"
```

**看懂这个过程，就能推出两条实操结论**：

1. **宜忌是"用事类别"的函数**。同一天，宜安葬不一定宜嫁娶，黄历上分列得清楚，看的时候要对号入座，不能只看"今天好不好"。
2. **宜忌背后是神煞**。两本黄历的宜忌打架，根源一定在它们起出来的神煞名目不同、轻重取舍不同。**所以遇到打架，翻到"吉神凶煞"那一栏去比对，而不是在"宜忌"两个字上争论。**

---

### 10_4 四套并行的日辰标尺：建除、黄黑道、二十八宿、九星

黄历上常常同时摆着四套"今日值什么"的说法。它们不是四个人说了四件事，而是四把刻度不同的尺子。

| 标尺 | 刻度依据 | 层级 | 主要用途 |
| --- | --- | --- | --- |
| **建除十二神** | 月建之支上起建，顺行十二辰，遇节气重一日 | 日神层（详见板块3） | 看当日的"底色"，定大范围用事倾向 |
| **黄黑道六神** | 按月建起的十二神，分黄道六吉与黑道六凶 | 日神层 | 与建除合看，判断当日值班之神 |
| **二十八宿** | 按历法轮值，二十七或二十八宿值日 | 日神层（属天星系统） | 参看，天星派更重（详见板块11） |
| **九星（紫白）** | 年月日时各有入中之星，按洛书轨迹飞布 | 需配合方位 | 有坐向才有意义，用于方位择吉 |

```latex
四把尺子打架时的处理顺序：

   第一步：先看建除与黄黑道（日神层的基础标尺）
   第二步：再看二十八宿（天星照临，作加分项）
   第三步：九星须待坐向确定后才有意义
   第四步：仍打架，回到"以事为纲、分级取舍"（详见板块0）
```

> **口径说明**：四套标尺分属不同的历史层，起源不一、用法不一。通书把它们并列在一页上，是"陈列"而非"综合"——并列不等于可以混算。

---

### 10_5 小栏目各自的用途：彭祖百忌、冲煞、值神、胎神

这些栏目的共同特点是：**有用，但都不是决定项**。

| 栏目 | 该怎么定位它 | 边界 |
| --- | --- | --- |
| **彭祖百忌** | 民俗层面的日用提醒，如"甲不开仓""子不问卜"之类 | 属于民俗文化，不作技术判据；与正五行取舍冲突时，让位于正课 |
| **冲煞（生肖冲）** | 快速自查主事人生年是否与日支相冲 | 只看生肖会漏掉"刑""害"，也会漏掉日干一层；正式择课必须看完整生年干支 |
| **值神** | 当日黄道或黑道值班之神，与建除合看更稳 | 黄道日遇大煞照样不可用，黄道不是免死金牌 |
| **胎神** | 传统民俗中的方位禁忌，涉及安床、修造动土 | 民俗项；涉及孕产的事项一律以医生意见为唯一依据 |
| **五行（纳音）** | 描述性栏目 | 正五行择日不用纳音论生克（详见10_1 口径说明） |

**一句话定位**：这些栏目提供的是"提醒"，不是"判决"。真正决定能不能用的，是年家月家的大煞、坐山的吉星照临、以及主命与日课的匹配——这三层，黄历一页纸装不下。

---

### 10_6 通书与官定历书：两回事

这是很多人混淆的一对概念。**官定历书**是朝廷颁行的历日，**通书**是民间坊刻的择日日用书，二者性质不同。

| 对比项 | 官定历书 | 民间通书 |
| --- | --- | --- |
| **性质** | 奉敕编修，官方定本 | 坊间编纂，商业流通 |
| **代表** | 《协纪辨方书》（清乾隆四年 1739 年奉敕编修，梅毂成等主持，三十六卷，取"敬天之纪、敬地之方"为名）、《星历考原》、《钦定选择历书》 | 《鳌头通书》《象吉通书》《永吉通书》《玉匣记》之类 |
| **目的** | 统一口径，裁断各家异同 | 便于民用，按日用事查阅 |
| **特点** | 逐条辨正神煞起例，注明取舍理由 | 重实用、重速查，往往不注依据 |
| **增删情况** | 相对稳定 | 各坊本递相增删，名目时有出入 |

```latex
一句话区分：

   官定历书 = 立法（定规则、辨异同）
   民间通书 = 应用（按日查用事）

   清代以《协纪辨方书》为官方定本，
   后世通书的编纂多以其为典范与依据。
```

**为什么要分清**：当你看到两本通书说法不一，正确的做法是回到官定定本去查"这一条神煞的起例到底是什么"，而不是在两本坊刻本之间二选一。**详见板块12 的书目地图。**

---

### 10_7 黄历的局限：它只能作粗筛

这一节是板块10 最重要的部分。

```latex
择吉的完整输入：事 + 人 + 方 + 年月日时
                          ↑        ↑
黄历能处理的：            日神层   日辰干支
黄历处理不了的：          人（八字） 方（坐山）
```

**通用黄历的三条硬局限**：

| 局限 | 说明 | 后果 |
| --- | --- | --- |
| **不含主事人八字** | 黄历只写"冲某生肖"，不处理整个命局 | 黄历说宜，却与主命相冲相刑 |
| **不含坐山方位** | 黄历没有坐向，无法判断三煞方、五黄方 | 黄历说宜动土，动的方向正犯三煞 |
| **只到"日"层** | 多数黄历时辰栏很粗 | 择时这一层基本缺失 |

所以正确的分工是：

```
黄历  → 粗筛（排除明显犯大煞的日子，圈出可用范围）
择课  → 精筛（在可用范围内，按人按方排出四柱成课）
```

**把黄历的"宜嫁娶"直接当作结婚日的决定依据，等于跳过了择吉的全部主干。** 这一点在板块0 已列为"新手三个坑"的第一条，此处不再重复展开。

> **边界提醒**：涉及医疗（尤其是生育与手术）、法律、重大财务与工程安全的决定，一律以专业意见为准。黄历与择吉都不进入这些领域的决策链。

---

### 10_8 为什么不同版本的黄历宜忌打架

板块0 的案例里，三本黄历给了三个答案。这里给出打架的四个具体原因。

| 原因 | 具体表现 | 怎么应对 |
| --- | --- | --- |
| **采用的体系不同** | 有的重建除，有的重黄黑道，有的重二十八宿，有的重天星照临 | 先问它采用的是哪一家（详见板块11） |
| **取舍宽严不同** | 同一神煞，有的本子记"忌"，有的本子记"不忌"；小煞尤其如此 | 按"大煞避之，中煞制之，小煞不必制"自行定夺（详见板块4） |
| **通书递相增删** | 坊刻本为便于销售，增补名目、删削繁琐部分 | 回到官定定本核起例 |
| **排版与校勘讹误** | 转抄翻刻中的错字、错日、错干支 | 用干支与节气自行复核一遍 |

```latex
遇到两本黄历打架的三步处理法：

   第一步  翻到"吉神凶煞"栏，比对两者列出的神煞名目
   第二步  找出差异项，判断它属大煞、中煞还是小煞
   第三步  大煞从严，小煞从宽；差异无法裁断时，换一个两者都说宜的日子
```

**第三步最实用**：与其裁断两本谁对，不如避开争议日。择吉的选项从来不是只有一天。

### 10_9 怎么挑一本可信的黄历或通书

买之前翻一下，看四项。四项里有两项不合格，就不用买。

| 核查项 | 具体看什么 | 不合格的后果 |
| --- | --- | --- |
| **一 · 是否注明神煞起例** | 有没有"某煞从某起、顺行或逆行"的说明 | 只给结论不给算法，无法复核，也无法学到东西 |
| **二 · 是否标出依据** | 关键取舍有没有注明出处，尤其是否引《协纪辨方书》一类官定定本 | 无依据的宜忌，等于编者拍脑袋 |
| **三 · 是否有版本沿革** | 序跋或凡例里有没有说明据何本翻刻、增删了什么 | 不知是据何本，就无法判断它的名目是否有出入 |
| **四 · 干支与节气能否自核** | 随手抽几天，自己推一遍干支，看对不对得上 | 干支都错的本子，其余不必看 |

```latex
一条速判经验：

   把书的"凡例"或"起例"部分翻开——
   有凡例、有起例、有引据        → 可买
   只有一页页的宜忌表格，别无说明 → 只配当日历，不配当择日依据
```

### 10_10 常见错：两个最典型的误用

**误用一：把"宜 / 忌"当命令**

| 项目 | 内容 |
| --- | --- |
| **表现** | 看到"宜嫁娶"就定日子，看到"忌出行"就取消行程 |
| **后果** | 忽略了人与方两层；也忽略了同一天对不同人的差异 |
| **改法** | 把宜忌当"粗筛结果"，再走一遍"避大煞、取吉神、配主命、定坐山、制成课"的完整链 |

**误用二：把"诸事不宜"当洪水猛兽**

| 项目 | 内容 |
| --- | --- |
| **表现** | 一见"诸事不宜"就整月不敢安排任何事 |
| **后果** | 一年三百六十日，可用的日子被砍掉一大半；越择越焦虑 |
| **改法** | 先问这个"不宜"由哪条神煞推出，属大煞中煞还是小煞；小煞口径造成的"诸事不宜"，按"小煞不必制"处理（详见板块4） |

补一条常被忽略的：**"诸事不宜"往往是编者的保守口径，不是天条。** 它的价值在于提醒你"这一天需要人工复核"，而不是"这一天被封印了"。

---

#### 案例小故事：同一天，两份黄历，两种说法

**背景**：有人要安床，翻了手机上的黄历，显示"宜安床"。另一本纸质通书对同一天却写"忌安床"。他不知道听谁的，来问。

**经过**：我让他把两本的"吉神凶煞"栏分别拍给我。一比对，差异出在一个神煞上：手机黄历没有收这一条，纸质通书收了。再查这一条的起例与层级，属**中煞**，而且当日有吉神同到。

**转折点**：问题不在于两本谁对，在于他一开始问错了问题。他问"哪本对"，正确的问法是"**这一条煞对我的事、我的人、我的方位影响有多大**"。安床要看卧室方位与主命，这两项他一项都没提供。

**结果**：按本库的链重走一遍——先查年家月家大煞（无犯），再查日神（中煞一条，有吉神可压），再看主命（生年与日支不冲不刑），最后定方位（不犯本年三煞方与五黄方）。结论是**可用，但需避开当日某两个时辰**。两份黄历的"宜"与"忌"，其实都没有说错，只是各自停在了日神层，没有往下走。

**落点**：黄历给的是"日神层"的粗筛结论，它天然不处理人与方。遇到不同版本打架，不要在"宜忌"两个字上争对错，要到"神煞栏"去比对差异，再按等次取舍。**黄历是索引，不是判决；把它当判决的人，会把择吉做成查表。**

## 板块11 · 派别地图：丛辰、建除、天星、斗首、奇门

> 择吉从来不是一家之言。两千多年前，七家被同时召到皇帝面前问同一件事，给出七个答案，最后由皇帝一锤定音。
> 这一板块先讲这段记载，再把今天仍在流传的各派逐家摆开，回答一个实际问题：**它们能不能混用，本库为什么选这一家。**

---

### 11_1 一段决定性的记载：汉武帝聚诸家占娶妇

《史记·日者列传》记下这么一段：

> 孝武帝时，聚会占家问之，某日可取妇乎？
> 五行家曰可，堪舆家曰不可，建除家曰不吉，丛辰家曰大凶，
> 历家曰小凶，天人家曰小吉，太一家曰大吉。
> 辩讼不决，以状闻。制曰：**避诸死忌，以五行为主。**

```latex
七家判词：五行家 可 / 堪舆家 不可 / 建除家 不吉 / 丛辰家 大凶
          历家 小凶 / 天人家 小吉 / 太一家 大吉
```

| 结论 | 说明 |
| --- | --- |
| **一、派别分歧自古如此，不是学艺不精** | 同一天、同一件事，七家给出七个答案。这不是某一派算错了，而是各家"看的那一层"本就不同 |
| **二、裁断的办法是"取交集、定主脑"** | "避诸死忌"取各家公认的凶，"以五行为主"定一个主脑 |

> **口径说明**："诸死忌"指各家公认的大凶之日，是各家共同避忌的那一部分，不是某一个具体神煞的名字。裁断逻辑是"先取共识、再定主脑"，不是"少数服从多数"。

这两条今天依然适用：碰到本库之外的说法，先看它是不是公认的大煞；不是，就回到五行生克这个主脑上来裁断。

---

### 11_2 七家对应今天的哪些支派

| 古七家 | 判词 | 今天大致对应的支派 |
| --- | --- | --- |
| **五行家** | 可 | 正五行择日（补龙、扶山、相主），本库主干 |
| **堪舆家** | 不可 | 方位山向一系，与风水理气接壤 |
| **建除家** | 不吉 | 建除十二神 |
| **丛辰家** | 大凶 | 神煞法（年月日时四层神煞） |
| **历家** | 小凶 | 历法与历忌一系 |
| **天人家** | 小吉 | 天人感应一系，后世多并入神煞或天星 |
| **太一家** | 大吉 | 太一（太乙）一系，演为太乙神数一路 |

> **口径说明**：古今派别的对应关系是通行理解，不是严格的师承谱系。古七家中有的后世失传，有的并入他派，有的名称沿用而内涵已变。此表用于建立"分歧自古存在"的认识，不作考据结论。

### 11_3 丛辰家：神煞法的老根

以年月日时四层神煞为主要判据的一派，是择吉里最庞大、最常用的部分。

| 项目 | 内容 |
| --- | --- |
| **渊源** | 最早可溯至战国楚地。九店楚简《日书》、睡虎地秦简《日书》中已有类似丛辰的记载；汉代宫廷设有丛辰家 |
| **核心方法** | 按干支起出各类神煞，看当日有哪些神在值、吉凶如何 |
| **层级** | 年神、月神、日神、时神四层（详见板块2、板块3） |
| **长处** | 名目细密、检索方便，与通书结合最紧 |
| **短处** | 神煞繁多，若不分级则见凶即避，一年几无可办之日 |

> **丛辰家的正确用法不是"数神煞"，而是"给神煞分等"：大煞避、中煞制、小煞不必制。** 分等规则详见板块4，制化规则详见板块5。

---

### 11_4 建除家：十二神一支

以建除十二神值日为判据的一派，黄历上最常见的一栏。

| 项目 | 内容 |
| --- | --- |
| **十二神序** | 建、除、满、平、定、执、破、危、成、收、开、闭 |
| **起法** | 月建之支上起"建"，顺行十二辰；遇节气交界则重复一日（详见板块3） |
| **性质** | 属日神层，给当日定"底色" |
| **常用判据** | 成日、开日多吉；破日、闭日多忌 |
| **短处** | 只到日层，不含人与方；单独使用容易过度简化 |

> **口径说明**：建除十二神在本库中作为日神层的基础标尺使用，与黄黑道六神合看，不作为最终判据。它解决"这一天的底色"，不解决"这一天对你合不合"。

### 11_5 堪舆家：方位山向一系

| 项目 | 内容 |
| --- | --- |
| **核心关切** | 在哪儿办——坐山朝向、方位吉凶 |
| **与择吉的接口** | 三煞方、岁破方、五黄方、太岁方等方位大煞 |
| **在择吉中的位置** | 造葬、修方、动土、安床一类有事方位的用事，方位层不可缺 |
| **短处** | 只谈方位不谈日课四柱，不能单独成课 |

**本库的处理**：方位层不单列为一派，并入正五行择日的"**扶山**"一纲（详见板块6）。坐山这一层，任何一派都不能绕开。

### 11_6 五行家：正五行择日，本库主干

以五行生克为唯一主脑的一派，正是《史记》记载中"以五行为主"的那一支。

| 项目 | 内容 |
| --- | --- |
| **核心方法** | 以干支本气五行（甲乙木、丙丁火、戊己土、庚辛金、壬癸水）论生克旺衰 |
| **三大纲领** | **补龙、扶山、相主**（详见板块6） |
| **长处** | 有明确主脑，各家分歧时可回到生克裁断；可复核、可复盘 |
| **短处** | 需要完整四柱与坐向信息，起手门槛高于翻黄历 |

```latex
正五行择日的三问：
   一问龙：入首来龙的气脉，这个课补不补得住
   二问山：坐山朝向，这个课扶不扶得起
   三问主：主事人的生年，这个课相不相得
   三问皆合，再看神煞；三问不合，吉神再多也是空架子。
```

### 11_7 天星派：照临一系

以二十八宿、七政四余等天象运行为判据的一派。

| 项目 | 内容 |
| --- | --- |
| **核心关切** | 天体（日月五星、二十八宿）在某一时刻照临何方 |
| **技法特点** | 需要推步天象，技法繁复，起手门槛高 |
| **适用场景** | 传统上多用于重大决策，如造葬、营建、出行择方 |
| **本库用法** | 取其"照临"一层作加分项：太阳、紫白、禄马贵人是否照临坐山 |
| **短处** | 推步繁难，非专业者难以独立复核；现代整理本多有讹误 |

> **口径说明**：本库兼取天星之照临，不采用完整的七政四余推步。理由是照临一层可用简表核对、可复核；完整推步依赖天文数据与专业训练，超出本库的使用边界。

### 11_8 三元派：三元九运与玄空飞星

| **时间框架** | 三元九运，二十年一运 |
| **空间框架** | 玄空飞星，按洛书轨迹飞布九宫 |

### 11_9 斗首派：番化五行一支

以年月日时干支的化气五行，与坐山所属番化五行论生克的一派。

| 项目 | 内容 |
| --- | --- |
| **核心方法** | 天干化气（甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火），配五星名目 |
| **五星名目** | 元辰、贪狼、廉贞、武曲、破军 |
| **算法特点** | 简明，一望而知生克，民间流传较广 |
| **短处** | 化气五行与正五行本气不是同一套坐标，结论常与正五行相反 |

> **口径说明**：斗首五星的具体配法（元辰、贪狼、廉贞、武曲、破军各对应生克中的哪一格）在不同传本中配法不一，坊本互有出入。**本库不采用斗首判据**，此节仅作派别地图的标记，不作操作依据。若要用斗首，须先固定一个传本，并从头到尾只用它。

| --- | --- |
| **核心神** | 天乙贵人（甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢虎马） |
| **用法** | 看贵人是否临日、临方、临主命 |
| **本库用法** | 贵人作为吉星照临的一项，并入坐山与日课的加分项，不单独立派 |

### 11_11 奇门择时：用奇门盘择吉时吉方

| 项目 | 内容 |
| --- | --- |
| **核心方法** | 排奇门盘，按用事取吉门、吉星、吉神、吉方与吉时 |
| **特点** | 盘式自成体系，时间与方位一体处理 |
| **与择吉的关系** | 属借用他术的盘式，不是择日的原生体系 |
| **本库立场** | **不采用**。奇门盘式与本库的干支神煞体系不在同一坐标系，混用则两套结论无法比较 |

> **为什么"能不能混用"如此要紧**：同一件事，用甲派判吉、用乙派判凶，你无法知道哪一派判错了，因为你没有第三个标准来裁断它们。而裁断标准的唯一来源，是"你到底在用哪一套坐标"。

### 11_12 能不能混用：先通一家，再旁参

结论：**各家自洽，混用则不伦不类。**

| 混法 | 问题 |
| --- | --- |
| 丛辰的煞 + 奇门的时 | 两套坐标系，吉凶定义不通约 |
| 正五行的课 + 斗首的判 | 本气五行与化气五行结论常相反 |
| 建除的日 + 玄空的方 | 日层标尺与运盘飞星不在同一层 |

```latex
正确路径：
   第1步  选定一家，从头到尾只用它的判据
   第2步  贯通这一家：从坐标到神煞到成课，走通至少十课
   第3步  建立回填记录，知道它在哪些事上准、哪些事上不稳
   第4步  再旁参他派：只作参考，不把别派判据并入本派判据链
```

第 3 步最容易被跳过，也最要紧。没有回填记录就旁参他派，等于自己的规则还没验证过时，又引进了一套没验证的规则。

---

### 11_13 本库立场

```latex
主干：正五行择日（补龙、扶山、相主）
兼取：丛辰之神煞（四层分等）· 建除之标尺（日神层底色）
      天星之照临（太阳、紫白、禄马贵人临方）
不取：奇门盘式 · 斗首番化 · 三元玄空（坐标系不同，不作主干）
```

**为什么选正五行为主干**，三条理由：

1. **它有一个主脑**。《史记》记载的裁断办法就是"以五行为主"，各家分歧时回到生克，这是历史上被官方认可过的裁断路径。
2. **它可复核**。干支、节气、旺衰都是可以自行推算的量，不像某些神煞的起例各本不一。
3. **它可复盘**。四柱与坐向都记录在案，事后回填时可逐项检查当初的判断成立与否。

---

### 11_14 常见错：东拼西凑与判据搬家

| 错法 | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| **东拼西凑** | 这家的吉神配那家的吉时，再借第三家的吉方 | 结论无法复核、无法复盘 | 固定一家，把判据链写进出课模板 |
| **判据搬家** | 把别派的神煞当成本派的判据 | 体系错，不是算错 | 每用一条神煞，问一句"它是哪一家的、起例是什么" |
| **以派别数量取胜** | 认为多派都说吉就更吉 | 各派本就独立，多派一致不增加证据强度 | 看派别之前，先看这一派在此类事上的回填记录 |

> **分辨"算错"与"体系错"**：算错可以改正，改完还能用；体系错是判据本身不属于你正在用的那一套，改不了，只能推倒重来。板块13 的错误清单里，体系错被列为最昂贵的一类。

---

#### 案例小故事：一个"三派都说吉"的日子

**背景**：有人要择造葬的日子，自己做了功课：查了通书（丛辰一路）、排了奇门盘、又对照了玄空飞星。三派都说吉，于是定了日子。

**经过**：事办得并不顺。事后他拿这个课来复盘，问我"三派都说吉，怎么会这样"。

**转折点**：我把三派的判据逐条列出来，问他一句：**"这三派里，有没有哪一派算过坐山的五行，以及它与日课四柱的生克关系？"** 答案是：没有。通书那一派只到日神层，奇门那一派看的是门星神，玄空那一派看的是运盘飞星——三者都没有做"补龙、扶山、相主"这一层。

**结果**：这一课的日神层确实干净，但日课四柱与坐山之间是一组明显的克泄关系，主命也未见相得。三派都说吉，是因为它们看的是三件不同的事，而真正决定造葬成败的那一层，谁都没看。

**落点**：派别数量的增加，不带来证据强度的增加。本库选正五行择日为主干，正是因为它把"补龙、扶山、相主"放在第一位，而这一层恰恰是其他各派都不处理的。**先通一家，再旁参；旁参是参考，不是合并。**

## 板块12 · 经典书目地图、读法与版本核查

> 择吉的书分四层：官方定本、民间通书、集大成与专题、现代整理。四层各有各的用法，也各有各的坑。
> 这一板块给出每层的定位与读法，以及买书或下载之前必查的四项版本核查。

---

### 12_1 四层书目地图

```latex
【第一层 · 官方定本】
   《星历考原》 → 《钦定选择历书》 → 《协纪辨方书》
     作用：定规则、辨异同、裁断各家
              ↓
【第二层 · 民间通书】
   《鳌头通书》《象吉通书》《永吉通书》《玉匣记》
     作用：按日查用事，日用速查
              ↓
【第三层 · 集大成与专题】
   《选择求真》《择吉汇要》，以及《协纪辨方书》的《利用》《公规》等卷
     作用：把规则落到具体操作
              ↓
【第四层 · 现代整理】
   今人重编、校注、专题整理本，含本库所收《造命金丹》
     作用：入门与专题参考，须带边界意识
```

**为什么必须分层**：四层的性质不同。**官方定本是"立法"（定规则、辨异同），通书是"应用"（按日查用事）。** 拿通书当立法用，是绝大多数"择日越择越乱"的根源——详见板块10 的 10_6。

> **顺序纪律**：先读官方定本，再翻通书。反过来读，你会把坊本的增删名目当成定例，之后再难校正。

### 12_7 阅读路线：三遍法

择吉的书不适合通读，适合三遍法。

```latex
第一遍 · 搭框架（快，不求甚解）
   目标：知道这本书解决什么问题、分几块、核心判据是什么
   做法：读序跋、凡例、目录；正文中只读每节的第一段
   产出：一页纸的框架图

第二遍 · 带问题回原文（慢，逐条核）
   目标：把框架里的每一条，回到原文找到依据
   做法：每次只带一个问题，例如"月德到底怎么起"，
         把书中所有相关段落找齐，比对异同
   产出：一张"我用的起例 + 出处"对照表

第三遍 · 用自己的话复述（最难，也最有用）
   目标：不看原文，能把这条规则讲给别人听
   做法：合上书，写出这条规则的适用条件与失效边界
   产出：一版属于你自己的笔记
```

**三遍之间的检查点**：

| 检查点 | 不合格的表现 | 说明 |
| --- | --- | --- |
| 第一遍结束 | 说不出这本书解决什么问题 | 框架没搭起来，别进第二遍 |
| 第二遍结束 | 抄了原文，但没做"我用的起例 + 出处"对照表 | 等于没核，只是誊了一遍 |
| 第三遍结束 | 写不出"失效边界" | 你只是记住了结论，没理解规则 |

> **为什么第三遍必须写"失效边界"**：法有边界，书上通常不写边界。**能写出一条规则什么时候不成立，才算真的读了这一条。**

### 12_8 版本核查四项

买书、下载、引用之前，必查这四项。择吉书籍的讹误密度远高于一般古籍，因为它是坊刻重灾区。

| 核查项 | 具体看什么 | 不合格的后果 |
| --- | --- | --- |
| **一 · 繁简转换造成的讹字** | 竖排繁体本转横排简体时，形近字与异体字的机械替换 | 干支、神煞名、方位字错一处，整条规则失效 |
| **二 · 神煞起例的异文** | 同一神煞在不同本子中的起法是否一致 | 起例不同，结论必然不同；混用两个起例等于两套体系 |
| **三 · 通书增删造成的名目混乱** | 坊本为便销而增补或删削，名目与官定定本不符 | 把坊本独有的名目当通用神煞 |
| **四 · 现代整理本掺入他派内容** | 整理者是否把别派的判据并入了本派的规则 | 体系错，不是算错（详见板块11 的 11_14） |

```latex
四项里，第二项最致命，第四项最难发现：

   第二项：起例是神煞的定义。定义不同，名字相同也是两回事。
           核查办法：同一个神煞，拿两个本子各起一遍，看结果是否一致。

   第四项：他派内容往往以"补充""附录""附考"的名义混入。
           核查办法：每见一条判据，问"它是哪一家的、起例是什么"。
```

补两条与电子本有关的核查：

**补充两条与电子本有关的核查**：扫描识别质量（PDF 由扫描件识别而来时，表格与口诀最易错位，竖排繁体本尤甚）；是否标注页码与卷次（无页码无卷次的电子本无法引用，也无法复核）。

#### 案例小故事：同一个神煞，两本书起了两个方向

**背景**：有人学"月德"这一神，手边两本书：一本是某现代整理本，一本是《协纪辨方书》的影印本。同一年同一月，两本书起出来的月德不在同一个天干上。

**经过**：他第一反应是"现代整理本印错了"，因为影印本看起来更权威。但带着这个疑问回到原文，发现两本书的起例文字几乎一字不差，差别出在**对某一句起例的断句与理解不同**——一处是"从某月起顺行"，另一处被理解成了"从某月起顺行至某止"。

**转折点**：他做了一件事：拿两本书各起十二个月的月德，列成两列对照。一对照就清楚了——两列在前几个月一致，从某一月起分岔。也就是说，**两本书用的是同一句起例，但对它的适用范围理解不同**。这不是印刷错误，是起例异文（12_8 核查项二）。

**结果**：他把两列都记进了自己的"起例对照表"，注明各自出处，然后**只选一套写进出课模板**，另一套标为"待验证"。此后出课一贯用同一套，回填时才有了可比性。

**落点**：择吉书籍的讹误，多数不是错字，而是**起例的理解分歧**。遇到两本不合，不要急于判定谁印错了——先把两本各起十二个月列出来对照，看是"从哪一月起分岔"。**分岔点就是分歧所在，而你的出课模板上只能写一套。**

> 这是全篇的刹车装置。择吉的错分两类：一类是算错，改完还能用；一类是体系错，只能推倒重来。
> 这一板块先把六类高频错误逐条列出（表现、后果、改法），再给一张十三项的出课前自检表，建议打印贴在案头。

### 13_1 坐标错：地基一错，后面全废

坐标层的错误最隐蔽，因为它不报错——你会得到一个看起来完整的课，只是它属于另一天。

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **拿农历月当干支月** | 月柱错一位，月家神煞全错 | 一律以节气定干支月，不以农历初一（详见板块1） |
| 2 | **跨节气未重算** | 同一天的上下午可能分属两月 | 查出用事当日交节的准确时刻，过界即全部重排 |
| 3 | **用北京时间未校地方时** | 时柱错一位，时家神煞与择时全错 | 按经度校正真太阳时，西部必校、东部可免 |
| 4 | **子时未换日** | 日柱错一整天 | 23 时之后日干支已换新的一天 |
| 5 | **闰月与日柱未核对** | 相差一整旬 | 排完四柱回查一遍农历与日柱是否吻合 |

```latex
坐标层的三条自检口诀：

   月看节气不看初一
   日看子时看换日
   时看经度看地方
```

> **为什么坐标错排在最前**：神煞是"标注"，四柱是"坐标"。标注贴错可以撕下来重贴，坐标错了，你连自己标的是哪一天都不知道。板块0 说过，依赖关系是单向的：**坐标错，神煞全错；神煞没分轻重，成课无从取舍。**

### 13_2 神煞错：层级与性质的误判

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **年神、月神、日神、时神混层** | 拿日煞当年煞，或反之，轻重立刻失真 | 出课表按年、月、日、时四层分列，逐层单独查（详见板块2、板块3） |
| 2 | **把太岁当凶神** | 无故回避整年，一年无日可用 | 太岁是值年之君，宜**坐不宜向**、宜**顺不可逆**；犯之在"向"与"动"，不在"值"本身 |
| 3 | **同一神煞混用两个起例** | 等于同时使用两套体系 | 每学到一条神煞，固定一个起例并注明出处（详见板块12） |
| 4 | **把别派的神煞当本派判据** | 体系错，不是算错 | 每用一条神煞，问一句"它是哪一家的、起例是什么"（详见板块11） |
| 5 | **只查日神不查年月** | 大煞漏网 | 日神层干净不代表可用；年家月家的大煞才是先查项 |

**关于太岁，多说一句**：

```latex
太岁的正确理解：

   太岁是值年之神，不是凶煞。
   它管的是"方位"与"动土"，不是"这一整年都不好"。

   犯太岁，犯在两处：
     一是在太岁方动土（修方、营造、安葬须避）
     二是坐山或向首冲犯太岁

   不犯这两处，"太岁当头"不构成避用理由。
```

> **口径说明**：民间通书中常把太岁与诸多凶煞并列，是坊本为便于日用而作的简化处理，非官定定本的本义。太岁的层级与用法详见板块2。

### 13_3 轻重错：不分等次就无从取舍

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **见凶即避** | 一年三百六十日几无可办之日；越择越焦虑 | 按"大煞避之，中煞制之，小煞不必制"分等处理（详见板块4） |
| 2 | **把小煞当大煞** | 白白放弃好日子 | 先查等次再谈取舍；等次表见板块4 与板块14 的速查表 |
| 3 | **把大煞当小煞** | 该避未避，后果最重 | 年家大煞（三煞、岁破、五黄、戊己都天）逐项打勾，不凭印象 |
| 4 | **只看煞不看是否有吉神同到** | 低估了可用的日子 | 吉足胜凶则从宜（详见板块0 的三条总原则） |
| 5 | **以神煞数量多少定吉凶** | 数量不是证据强度 | 看等次，不看条数 |

```latex
一句话速记：

   先分等，再取舍。
   等次没定就谈吉凶，等于没定标准。
```

### 13_4 制化错：制煞是有前提的

制煞化煞是工具箱，不是万能钥匙。用错了，反噬更烈。

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **在煞旺的月份去制它** | 制不住，反被煞伤 | 制煞须趁**煞衰之月**、用**制神旺相之月**（详见板块5） |
| 2 | **以为制过就万事大吉** | 忽略了制化只针对某一条煞 | 制化是"点对点"的，制了甲煞不等于乙煞消失 |
| 3 | **对三煞、岁破一类硬制** | 大煞只能避，不能硬制 | 三煞、岁破、五黄一类属**避之**的层级，不作制化对象 |
| 4 | **制化之后不再看成课** | 有制无扶，课不成格 | 制化是清障，成课才是主体，两步不能互相替代 |
| 5 | **忘记"制不如化、化不如避"** | 舍易求难 | 优先级：**避 > 化 > 制**，能用避的不要用制 |

```latex
制化的三个前提，缺一不可：

   前提一  煞在衰月（不得令）
   前提二  制神在旺月（得令有力）
   前提三  制化之后，四柱仍能成格、仍能相主
```

> **口径说明**：制煞化煞的具体规则、适用条件与失效边界，统一见板块5。本篇只列"用错了会怎样"，不重述规则本身。

### 13_5 成课错：堆吉神不等于成课

这是从"查表"跨到"择课"时最常掉进去的坑。

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **只堆吉神，不看成格** | 吉神再多，四柱散乱不成局 | 先定格局，再看吉神；成格成局的取法见板块7 |
| 2 | **四柱内部自相冲克** | 课自战，力量内耗 | 排出四柱后先查内部：天干有无冲克、地支有无刑冲 |
| 3 | **忘了相主** | 课再好，与主命不合也是白搭 | 三大纲"补龙、扶山、相主"缺一不可（详见板块6） |
| 4 | **只补龙不扶山** | 有坐向的用事必出问题 | 造葬、修方、安床一类，扶山一项单独打勾 |
| 5 | **择时不看日破与五不遇时** | 日吉而时凶 | 时辰层单独过一遍，不看"大概这个时段挺好" |
| 6 | **用事写得太粗** | 判据对不上号 | 用事必须带动词，例如"安床"不是"搬家" |

```latex
成课的四步自检：

   第一步  四柱是否成格（有主有辅、有生有扶）
   第二步  四柱内部是否自战（干支有无互冲互克）
   第三步  是否补龙、扶山、相主三面俱到
   第四步  择时是否与日相配（不犯日破、不犯凶时）
```

### 13_6 边界错：越界比算错严重得多

| # | 表现 | 后果 | 改法 |
| --- | --- | --- | --- |
| 1 | **用择日压医学判断** | 延误治疗，后果不可逆 | 涉及生育与手术的决定，一律以医生意见为唯一依据（详见板块9） |
| 2 | **用择日压工程与安全判断** | 现实风险 | 工期、结构、安全规范由专业方定，择日只在可选窗口内作参考 |
| 3 | **用择日压法律与合同判断** | 现实风险 | 签约、诉讼、合规以法律意见为准 |
| 4 | **断语说成"一定成"** | 把参考变成了承诺 | 断语只落"宜、忌、权宜可用 + 注意事项"，并标可信度 |
| 5 | **替别人做决定** | 越界 | 给出取舍与理由，决定权交给当事人 |

> **边界提醒**：择吉给的是"这个时刻合不合用"，不是"办了就一定成"。**任何涉及医疗、法律、重大财务与工程安全的决定，一律以专业意见为准。** 这一条不是免责声明，是使用说明。

### 13_7 出课前自检清单（十三项，建议打印贴在案头）

```latex
════════════════════════════════════
【择吉出课前自检表】  编号：______
────────────────────────────────────
□  1. 用事是否写清楚（含动词，例如"安床"不是"搬家"）
□  2. 主事人生年干支是否已登记
□  3. 方位 / 坐山是否已定
□  4. 年月日时四柱是否按干支历推得、节气是否过界
□  5. 年家大煞（三煞、岁破、五黄、戊己都天）是否逐项查过
□  6. 月家（月建、月破、月三煞、大小月建、阴府）是否查过
□  7. 日家（四离四绝、四废、十恶大败、往亡、受死）是否查过
□  8. 主命与日课是否相冲相刑
□  9. 坐山是否得吉星照临（太阳、紫白、禄马贵人）
□ 10. 四柱是否成格、内部是否自战
□ 11. 若用制化：煞是否衰月、制神是否旺月
□ 12. 断语是否落到"宜 / 忌 / 权宜可用 + 注意事项"，而不是"一定成"
□ 13. 是否已登记进出课登记表、预留回填栏
════════════════════════════════════
```

**十三项的用法，三点说明**：

1. **第 1 至第 3 项是输入，第 4 至第 11 项是加工，第 12 至第 13 项是输出。** 输入不全就不要开始加工——用事、主命、方位三者缺一，后面十项查得再细也落不到实处。
2. **第 5 至第 7 项必须逐项打勾，不许凭印象**。这三层是大煞的所在，凭印象等于没查。
3. **第 13 项最容易被跳过，也最要紧**。没有回填栏，这课就永远无法验证；无法验证，你的规则成立率永远是零。

```latex
一项否决规则（任一命中，本课不出）：

   命中 第5项 年家大煞未避  → 不出课
   命中 第8项 主命相冲相刑  → 不出课
   命中 第12项 断语写成"一定成" → 改写后再出
```

### 13_8 断语的可信度分级（每课必标）

| 级别 | 判据 | 表述 |
| --- | --- | --- |
| **可用** | 大煞已避、主命相合、坐山有吉星照临、四柱成格 | 宜用，并注明注意事项 |
| **权宜可用** | 大煞已避，但有中煞未制或吉照不足 | 可用，须在某处加以规避（如避开某方位、某时辰） |
| **不宜** | 犯大煞，或主命相冲，或四柱自战 | 另择；并说明是卡在哪一项 |

**每一课的断语必须包含四件东西**：

```latex
第1步 结论：宜 / 忌 / 权宜可用（三选一，不许模棱两可）
第2步 理由：卡在哪一层、取得哪一层（最多两条）
第3步 注意事项：时辰、方位、或需要规避的具体事项
第4步 可信度：可用 / 权宜可用 / 不宜
```

### 13_9 落地动作卡

| 动作 | 做法 | 检验点 |
| --- | --- | --- |
| **打印自检表** | 十三项打印贴在案头 | 每课出课前逐项打勾，不凭记忆补勾 |
| **坐标三查** | 节气、子时、经度，每次排完四柱回查一遍 | 三个月内不再出现月柱与时柱错误 |
| **大煞逐项打勾** | 年家、月家、日家三层分开查 | 不再出现"凭印象没犯" |
| **预留回填栏** | 每课登记表留空栏，事后填实际情况 | 半年后能统计自己的规则成立率 |

---

#### 案例小故事：一次"漏查一项"的复盘

**背景**：有人替一位朋友择安床的日子。流程走得很顺：用事写清楚了，主命登记了，年月日的神煞逐项查了，四柱也成了格。他出了一课，断语是"宜用"。

**经过**：事情办完之后，他按规矩做回填，翻出当时的出课登记表逐项复核。复核到第六项"月家"时，停住了——那一栏只打了勾，没有写查了哪几项。他凭着登记表的空白回想，想不起来当时到底查过"大小月建"没有。

**转折点**：他回去重查。这一年这一月，安床所在的方位正犯**大月建**。安床属修方一类，方位层是硬项。也就是说，他当时很可能跳过了这一项，而这一项恰恰是本次用事的关键。

**结果**：事后反馈，那位朋友那段时间睡眠确实不好，家里也出了些琐碎的口舌。这类反馈不能作为神煞应验的证据——**但可以作为"流程有漏洞"的证据**。他把这件事记进了回填表，备注栏写了八个字：**打了勾，不等于查过。**

**可复制动作**：

1. **把"月家"这一类合并项拆成子项打勾**。只写一个"月家已查"的勾，等于什么都没记。改成：月建、月破、月三煞、大小月建、阴府，五项各一个勾。
2. **登记表上每一栏都要有内容，不能只有一个勾**。勾只证明你走过，内容才证明你查过。
3. **回填时按表逐项复核，不凭记忆**。那一栏之所以想不起来，正是因为当初只打了勾。
4. **漏查一项的代价，不体现在当天，体现在半年后你无法复盘**。这一条是十三项里第 13 项存在的理由。

**落点**：错误清单上的六类错，真正致命的不是算错，而是**你以为查过了其实没查**。十三项自检表的价值，不在于它列得全，而在于它逼你把每一层都留下痕迹——**痕迹是你事后唯一能追责的证据。**

### 14_4 回填与统计

#### 出课登记表的最小字段

登记表不必复杂，但下面七个字段一个都不能少：

```latex
编号 / 用事 / 主事人生年 / 方位坐山 / 四柱 /
避开了什么 / 取了什么吉 / 断语 / 回填（事后填）
```

| 字段 | 为什么不能省 |
| --- | --- |
| **编号** | 检索与统计的唯一键 |
| **用事** | 没有它，无法按事类统计 |
| **主事人生年** | 相主一项的凭据 |
| **方位坐山** | 扶山一项的凭据 |
| **四柱** | 事后复核的唯一依据 |
| **避开了什么 / 取了什么吉** | 记录你当初的取舍，否则无法判断哪条规则成立 |
| **回填** | 没有它，规则成立率永远是零 |

#### 半年盘点怎么做

```latex
半年盘点四步：

   第1步  把所有登记表按"用事类别"分组
          （嫁娶、营造、安葬、出行、开市各一组）

   第2步  逐条看回填栏，判定三档：
          成立 / 落空 / 无法判定
          "无法判定"必须单独记，不许并入"成立"

   第3步  按事类算规则成立率（公式见下）

   第4步  把"落空"的条目按 板块13 的六类错误归类，
          看你是错在坐标、神煞、轻重、制化、成课还是边界
```

#### 规则成立率怎么算

```latex
规则成立率 = 判定为"成立"的条数
             ÷ （总条数 − 无法判定的条数）

要点：
   一、分子分母都要剔除"无法判定"，否则比例失真
   二、必须分事类算，混在一起算没有意义
   三、样本少于二十条时，只记录、不下结论
   四、真正有用的不是那个百分数，
       而是"落空"那一栏里重复出现的错误类型
```

> **统计的意义不在数字，在归因**。半年盘点做完，你要能回答一句："我最常错在哪一类。" 答不出来，说明回填栏填得太简——多半只写了"顺利"或"不顺利"四个字。

### 14_5 贴在案头的三句话

> **1. 先择人，次择方，再择日，最后择时。** 顺序一颠倒，吉课也会变成凶课。
>
> **2. 大煞避之，中煞制之，小煞不必制。** 等次没定就谈吉凶，等于没定标准。
>
> **3. 打了勾，不等于查过。** 模板上每一栏都要有内容，内容才是你事后唯一能追责的证据。

#### 案例小故事：一张模板用了两年之后

**背景**：有人把上面这张出课纸打印成一叠，从第一年到第二年，用完了一本。

**经过**：第一年他只是照着填，觉得繁琐——尤其是第三栏，年家月家日家时家加起来十几个子项，每课要勾一遍。有几次他偷懒，只在大项上打了个勾。

**转折点**：第二年上半年做盘点，他发现一件有意思的事：**凡是第三栏每个子项都单独勾过的课，回填时"成立"与"落空"分得清清楚楚；凡是只打了一个大勾的课，回填栏几乎都写着"说不清"。** 不是那些课真的说不清，是他当初没留下可复核的痕迹。

**结果**：第二年下半年他改了做法，把第三栏的子项拆得更细，还加了一栏"本课的存疑项"。到第二年年末，他手里有了六十多课的记录，第一次能按事类算出规则成立率，也第一次看清了自己的错误分布——**错得最多的不是神煞，是坐标层：有五课的月柱是卡在节气交界处搞错的**。

**可复制动作**：

1. **模板的价值不在于出课那半小时，在于半年后你还能不能复盘**。留不下的痕迹，等于没走过流程。
2. **偷懒的勾，代价在半年后支付**。这不是比喻，是那本出课纸上实实在在的对比。
3. **统计的意义是归因，不是打分**。他最后真正受用的不是那个百分数，而是"错得最多的原来是坐标层"这一句话——知道错在哪，才知道下功夫下在哪。

**落点**：口诀与速查表解决"查得快"，模板与回填解决"能复盘"。这两件事里，后者才是把择吉从查表变成手艺的那一步。**一张模板用两年，它给你的不是两百个结论，而是一个你自己的错误分布图。**
