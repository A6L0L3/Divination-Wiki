## 板块5 · 主客四将与算数：主算主大将主参将、客算客大将客参将

> 前面排出来的太乙、文昌、始击，都只是位置。位置本身不产生胜负，把位置折算成数字，太乙才真正开始说话。
>
> 这个数字叫"算"。主客各有一算，一算再拆出两将，于是主方有主大将主参将、客方有客大将客参将，合称四将。
>
> **算数是力量，四将是力量的落点。** 这一板块要做的，是把这两个数字和四个位置算准，因为后面所有判断都长在这上面。

---

### 5_1 为什么"算"是太乙的核心量化指标

太乙与六壬、遁甲最大的区别，在于它手里有一根尺子。

```latex
六壬： 类神 + 课体 + 旺衰  →  定性为主，"多强"靠旺相休囚去估
遁甲： 门宫星神 + 生克     →  定性为主，"多强"靠临宫状态去估
太乙： 主算 / 客算         →  先量出"有多少"，再谈"谁胜谁负"
```

这根尺子有三个不可替代的作用：

| 作用 | 说明 | 失效后果 |
| --- | --- | --- |
| **可比** | 主算与客算同单位、同口径，可以直接比大小，不必靠感觉 | 各自描述势态，永远说不清谁强 |
| **可复核** | 算数是加出来的，任何人按同一口径重算一遍，结果必须相同 | 两个人推同一局推出两个数，无法对质 |
| **可派生** | 四将的落宫全由算数拆出，一处错则整条链都错 | 盘面看起来完整，实际上将位全是错的 |

> **一句话**：太乙的"势"最终被压缩成两个整数——主算与客算。**格局管"能不能用"，算数管"有多少"。** 没有算数，太乙就退化成一堆名词。

---

### 5_2 主算：把目到太乙的距离，折算成一个数

#### 算法原理

主算量的东西很朴素：**文昌（天目）要到太乙跟前，得走过哪几个宫、这些宫合起来值多少。**

每走过一个宫，就把该宫的宫数加上去。走过的路越长、经的宫数越大，累计出来的主算就越大。所以主算既包含"路有多远"，也包含"路上有多重"——这就是它为什么能当力量指标。

```latex
【主算三步】

第1步  定起点：文昌（天目）所在之宫
          ↓
第2步  定方向：按太乙行宫次序
          阳遁顺行：一 → 二 → 三 → 四 → 六 → 七 → 八 → 九 →（一）
          阴遁逆行：九 → 八 → 七 → 六 → 四 → 三 → 二 → 一 →（九）
          俱不入中五（详见板块2）
          ↓
第3步  定终点：累加至"太乙所在宫的前一宫"为止
          起点宫计入，终点宫计入，太乙本宫不计入
          ↓
        沿途宫数之和 = 主算
```

#### 取值规则（本库口径）

| 项目 | 本库取法 |
| --- | --- |
| 累加单位 | 八宫之宫数（一乾、二离、三艮、四震、六兑、七坤、八坎、九巽），中五不计 |
| 间辰 | 本库并入所属之宫，不另计一位（详见 5_7 口径说明） |
| 起止 | 文昌所在宫计入，太乙前一宫计入，太乙本宫不计 |
| 取值范围 | 最小为一，最大为四十（八宫宫数之和为四十） |
| 满环情形 | 文昌与太乙同宫时，按绕满一周计，得四十 |

#### 例题

```latex
【已知】太乙在 一宫（乾），阳遁顺行；文昌在 四宫（震）

行宫次序：一 → 二 → 三 → 四 → 六 → 七 → 八 → 九 →（一）
太乙在一，故"太乙前一宫" = 九宫

自文昌（四）起，沿顺行方向累加至九：
        四 + 六 + 七 + 八 + 九 = 三十四

        → 主算 = 三十四
```

### 5_3 主大将与主参将：把一个算拆成两截

算数是一个整数，四将是两个位置。**拆法就是取位：十位给大将，个位给参将。**

```latex
主算 三十四
    ↓ 拆分
十位 = 三  →  主大将居 三宫（艮）
个位 = 四  →  主参将居 四宫（震）
```

#### 拆位对照表

| 主算 | 十位 | 个位 | 主大将 | 主参将 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 一 | 无 | 一 | 一宫 | 一宫 | 单算，大将与参将同宫 |
| 九 | 无 | 九 | 九宫 | 九宫 | 单算，大将与参将同宫 |
| 十六 | 一 | 六 | 一宫 | 六宫 | |
| 二十五 | 二 | 五 | 二宫 | 中五 | 个位逢五，参将居中 |
| 三十四 | 三 | 四 | 三宫 | 四宫 | |
| 二十 | 二 | 零 | 二宫 | 参将不出 | 个位为零，无宫可居 |
| 四十 | 四 | 零 | 四宫 | 参将不出 | 满环之算 |

三条取值细则（本库口径）：**算不满十**则大将随个位、与参将同宫；**个位为零**则参将不出；**个位为五**则落于中五，太乙不居，记为"在中"。

> **口径说明**：四将取位之法，各家分歧集中在三点——其一，十位与个位谁配大将（本库取十位于大将，另有反之者）；其二，单算时大将有无专宫（本库取"大将随参将同宫"，另有取"大将不出"者）；其三，个位为零或五时如何处理（本库取"不出"与"在中"，另有寄坤、入中之说）。**这三种口径在常见古本中都能见到，本库不主张其中任何一种为唯一正解，但要求你在一局之内全程只用一种，并把它记在笔记的"口径"栏里。**

### 5_4 客算与客大将、客参将

客算的求法与主算完全同构，只把起点从文昌换成**始击（地目）**，终点仍是太乙前一宫。

```latex
【主算】文昌（天目）──累加宫数──→ 太乙前一宫
【客算】始击（地目）──累加宫数──→ 太乙前一宫
```

拆分规则也完全相同：

```latex
客算 二十四  →  十位二 → 客大将居 二宫（离）
                个位四 → 客参将居 四宫（震）
```

> **为什么两端都指向"太乙前一宫"**：太乙是当令之位，双方都朝着它走。终点统一，两个算才同单位、才可比较。**若把主算数到太乙、客算数到太乙前一宫，两数就不可比了**——这是最隐蔽也最常见的一类错。

#### 全例演示

```latex
【已知】太乙在 一宫（乾），阳遁顺行
        文昌在 四宫（震），始击在 七宫（坤）

主算：四 + 六 + 七 + 八 + 九 = 三十四
        主大将 → 三宫（艮）      主参将 → 四宫（震）

客算：七 + 八 + 九 = 二十四
        客大将 → 二宫（离）      客参将 → 四宫（震）

比较：主算三十四 长于 客算二十四 → 主力厚于客
```

**这一步做完，四将全部落位，盘面才算排完。** 后面谈格局、谈胜负，都以这一页为底本。

### 5_5 四将的定位：大将是主帅，参将是副将

四将不是四个并列的神，而是**两主两副、分属两方**：

| 将 | 身份 | 管的范围 | 在盘面上回答的问题 |
| --- | --- | --- | --- |
| **主大将** | 主方主帅 | 主力、正面、决策 | 主方的主力摆在哪儿 |
| **主参将** | 主方副将 | 侧翼、后备、执行 | 主方的接应摆在哪儿 |
| **客大将** | 客方主帅 | 主力、正面、攻势 | 客方的主力摆在哪儿 |
| **客参将** | 客方副将 | 侧翼、后备、续力 | 客方的接应摆在哪儿 |

#### 四将落宫的四类读法

| 落宫状态 | 对应宫 | 读法 |
| --- | --- | --- |
| **临当令之宫** | 太乙所在宫 | 得气最厚，但也最招眼，易被掩迫（详见板块7） |
| **临和宫** | 三（艮）、七（坤） | 安稳，能守，不易生变 |
| **临绝地** | 一（绝阳）、九（绝阴）、四与六（绝气） | 失气，兵虽在而不能用 |
| **临易气之宫** | 二（离）、八（坎） | 变动，或用或去，局势不稳 |

> **大将与参将要分开读**：大将看"正面扛不扛得住"，参将看"有没有后手"。常见情形是主大将强而主参将不出——这种局面叫**有将无援**，能打一仗，打不了持久。

### 5_6 算长算短：力强与力弱的分界

八宫宫数之和为四十，故**二十为中分**。

| 分界 | 判定 | 势态 |
| --- | --- | --- |
| **长算** | 满二十及以上 | 力厚、资源足、可持续；但兵多难聚，调度慢 |
| **短算** | 不满二十 | 力薄、资源少；但贴身轻捷，反应快 |

长算兵多粮足，利持久、利守成；短算兵少轻锐，利速决、利奇袭，经不起消耗。所以判读时不是"谁长谁赢"，而是**看这一局打的是持久战还是遭遇战**：

| 局面 | 谁占优 |
| --- | --- |
| 主算长、客算短 | 主力厚，主方顶得住消耗，主胜面大 |
| 主算短、客算长 | 客力厚，客方能耗得起，客胜面大 |
| 两算相当（相差在二以内） | 势均力敌，转看格局（板块7）与定算（板块6） |
| 一算满环（四十） | 极长而散，名曰遍八方，实则力分而不聚 |

> **口径说明**：长短之分界，古本说法不一。有以十为界者，有以"单算为短、双位算为长"者，亦有径以二十为中分者。本库取二十为界，理由是八宫宫数之和为四十，二十为其半，分界有据、可复核。**若你另有所本，请固定一种并在笔记中写明，切勿在一局之内换用两种分界。**

### 5_7 常见错：含不含间辰、无算与算为一

#### 错一：间辰计不计一位

间辰（四维之位）在环上位于两宫之间。求算时计不计，直接改变得数。

```latex
口径A（本库）：间辰并入所属之宫，不另计一位
口径B（另一派）：间辰单列，环上每一位各计一宫数

同一局，A 与 B 得数不同 → 四将落宫随之全变
```

> **口径说明**：间辰是否单列，是太乙算数最大的一处流派分歧，古本并载两说。**本库取 A，取其可与八宫宫数直接对账；** 取 B 者须自行在笔记中登记，且不可与 A 的结论互相引用。判断自己有没有踩这个坑，办法很简单：**把所得之算减去沿途各宫宫数，看是否恰好等于沿途宫数之和**——若不相等，一定是混用了两种口径。

#### 错二：无算、算为一、个位为零

| 特殊值 | 本库处理 | 其他口径 |
| --- | --- | --- |
| **无算** | 本库口径下最小为一，不存在零算 | 按间隔计数者，目与太乙相邻则间隔为零，称"无算"，主四将不出 |
| **算为一** | 至短之算，大将与参将同居一宫 | 有流派以"一"为阳数之始，另作吉论 |
| **个位为零** | 该方参将不出 | 有寄坤、入中之说 |
| **目与太乙同宫** | 本库按绕满一周计，得四十 | 有流派直接记"算不成" |

#### 错三：起止点取反

最隐蔽的一类错：主算数到太乙本宫、客算数到太乙前一宫，或反过来。**两端必须同止于太乙前一宫**，否则二算不可比。

#### 错四：把整个算数当宫号

见"主算三十四"就写"主大将三十四宫"——九宫只有一到九，宫号不可能超过九。**算数是数字，不是宫号；要先拆位，再落宫。**

### 5_8 复核动作清单

| 序 | 动作 | 做法 | 检验点 |
| --- | --- | --- | --- |
| 1 | **核太乙** | 确认太乙所在宫与遁法（详见板块2） | 与积年入局结果一致 |
| 2 | **核二目** | 确认文昌、始击所在宫（详见板块4） | 二者可与他人对账 |
| 3 | **核方向** | 阳遁顺行、阴遁逆行，方向写下来 | 行宫次序不含中五 |
| 4 | **核起止** | 起于目、止于太乙前一宫，太乙本宫不计 | 主客两端止点相同 |
| 5 | **核加总** | 沿途宫数逐个相加，列出算式 | 得数在一至四十之间 |
| 6 | **核拆位** | 十位归大将、个位归参将，落宫不超九 | 单算则大将随参将 |
| 7 | **核四将** | 四将各落一宫，无遗漏、无重复 | 与算数可互推 |
| 8 | **记口径** | 间辰、单算、零位三处的取法记入笔记 | 事后复盘时口径可追溯 |

> **第 8 条最容易被跳过**，而它恰恰是三个月后你能知道自己错在哪一步的唯一凭据。

### 5_9 案例小故事：算数抄对了，将却落错了宫

有个人推一局，求得主算三十四。他记下"主算三十四"，然后顺手写："主大将三十四宫。"

写到这一步他自己也觉得不对——九宫只有一到九，哪来的三十四宫？但他没有停下来，而是把三十四硬塞进盘里，在九宫外画了一个位置。接着排客算二十七，他又写："客大将二十七宫。"整张盘画完，四将全在盘外。

他拿去给人看，对方第一句话是："你这两个数是对的，后面全错了。"

问题出在**他漏了"拆位"这一步**。算数是从位置折算出来的总量，四将是要落回位置的，中间必须经过一次"拆成十位与个位"的转换。他看得见三十四这个数，却没看见三十四里面装着"三"和"四"。

改法只有一行：三十四拆为十位三、个位四，主大将落三宫、主参将落四宫。四将立刻回到盘内，整局判读也才有了落点。

他后来在笔记本扉页写了一句话，每次排盘前看一眼：**"算数不是宫号，先拆位，再落宫。"**

**落点**：算数是"总量"，四将是"位置"，二者之间隔着一个固定动作——拆位。跳过这个动作，你得到的将是一堆盘外的坐标，看起来排完了，实际上一个字都读不出来。
