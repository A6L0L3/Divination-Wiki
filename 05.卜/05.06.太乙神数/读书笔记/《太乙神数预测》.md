## 板块1 · 先定坐标：这是一本什么书，它解决了什么问题

《太乙神数预测绝学》书名即定位——"太乙神数"是对象，"预测"是功能，"绝学"是作者对其稀缺性的判断。全书真正回答的只有一个问题：**拿到一个时间点，怎么把它变成一局可判读的势，并从这局势里读出主与客谁占上风**。

### 1_1 版本与文本的清醒认知

| 项目 | 说明 |
| --- | --- |
| 结构 | 两大部分。第一部分「太乙神数基础」四章；第二部分「太乙神数运算与运用」七章 |
| 出版性质 | 香港出版的现代整理/著述本，作者自述"累积二十余年研究心得" |
| 作者其他著作 | 《奇门堪舆学》《奇门遁甲高级预测学》《大六壬高级预测学》《大六壬现代应用学》《紫微斗数预测学》《铁板神数应用学》《七政四余现代应用学》《周易纳甲现代应用学》等，属同一套"现代术数丛书"体系 |
| 库内底本 | PDF 电子本，无点校本 |
| 读法建议 | **把它当"现代整理本"读，不当"原典"读**。凡涉及起例规则（如十六神名目、算数是否含间辰、计神顺逆），一定要回到唐宋原典（《太乙金镜式经》《太乙统宗宝鉴》系统）去核，或直接以本库系统知识库板块1—8 所标口径为准 |

**实操要点**：这本书最大的价值是**结构清晰、条目齐全**——它把太乙拆成了可查的二十四节运式与十目格局，对自学者极其友好。它最大的风险也在这里：**条目化会掩盖分歧**。太乙的许多起例在古本中本就众说纷纭，条目化之后变成一条"标准答案"，读者容易照单全收。

> **口径说明**：本笔记凡遇到"作者给出唯一规则、而古本实有多说"之处，一律加注说明，**不把一家之言说成定论**。

### 1_2 它在太乙体系里的真实位置

太乙相关文献按功能可分三类：

+ **《太乙金镜式经》《太乙统宗宝鉴》**：立积年、定九宫、排神将——**工具书与规则源**
+ **《太乙淘金歌》及各类歌诀**：把规则压成可背诵的韵语——**口诀库**
+ **《太乙神数预测绝学》一类现代整理本**：把上面两类重新编排、补齐例子、加上身命应用——**现代教材**

打个比方：前两类是零件图和装配口诀，这一本是**装配说明书**。所以正确的读法是：拿它搭框架，拿原典核规则，两者不可互相替代。

### 1_3 全书一句话与两大部分的骨架

```
第一部分「基础」：把时间点变成一局
   第一章 机理      → 这台机器为什么这么转
   第二章 计算规则  → 积年、四计、十六神、阴阳数
   第三章 格局      → 掩迫关囚击格对提挟、四郭固杜
   第四章 运式      → 太乙、文昌、主算、主大将、主参将、始击、客算、客大将、客参将、定目、定算、定大将、定参将、君基、臣基、民基、五福、大游、小游、四神、天乙、地乙、直符、飞符（共二十四节）
        ↓
第二部分「运用」：把一局落到人身上
   第一章 身命四宫与限曜  → 命宫、身宫、日宫、时宫、飞禄飞马、化曜、空亡
   第二章 十六星神临十二宫
   第三章 十六神临乾艮巽坤四维宫
   第四章 二至三星同宫
   第五章 十六星临女人身命日时
   第六章 十六神三等判断
   第七章 太乙七大法
```

这两部分的分量并不相等。**第一部分是主干，第二部分是分支。** 学太乙的人若从第二部分入手，会把太乙读成另一套紫微斗数——这是本书读者最容易踩的坑。

## 板块2 · 第一部分拆解：基础层四章

### 2_1 第一章 太乙神数预测机理及作用

这一章回答"为什么可以这么算"。太乙的机理建立在三层想象上：

| 层 | 内容 | 落到操作上 |
| --- | --- | --- |
| **天文层** | 北极（太乙）为体，北斗为用，北斗绕极而行 | 太乙行八宫而不入中五 |
| **数理层** | 积年折算成局数，五元六纪成 360 年大周期 | 时间点 → 局数 |
| **对局层** | 主与客两套人马，各有目、有将、有算 | 局 → 主客胜负 |

**作者在这里的立场值得留意**：他把太乙定位为"预测"之学。这个定位比古本更"重"——古本太乙（《金镜式经》系统）的语气更接近"推演天运转式、考治八宫"，是**态势评估**而非事件预报。

> **口径说明**：本库系统知识库在板块0 中把太乙的输出界定为"势"，不是"事"。读本书时请保留这一层距离：**机理支持"评估"，不足以支持"预报"。**

### 2_2 第二章 基础知识与计算规则（全书最硬的一章）

八节，逐节都是硬骨头：

| 节 | 内容 | 要点 |
| --- | --- | --- |
| 第一节 | **太乙四计** | 年计、月计、日计、时计。四计是同一副零件的四个档位，换的是起算基准与遁法分界 |
| 第二节 | **年计** | 以积年入局为主，周期最长，用于大势 |
| 第三节 | **月计** | 以月建为界，用于年内分段的走势 |
| 第四节 | **日计** | 用于具体日期的取向 |
| 第五节 | **时计** | 周期最短，用于即时取向，反馈也最快 |
| 第六节 | **太岁、合神、计神** | 太岁为一年之主宰；计神为岁星之使，是二目之首、四将之源 |
| 第七节 | **太乙十六神** | 十二支神 + 四维神，构成十六宫位 |
| 第八节 | **太乙阴阳数** | 阴阳二数是算之母，不明阴阳数则算无从起 |

**这一章必须逐节手算一遍。** 看一遍和算一遍是两回事——太乙的绝大多数错误都发生在"以为是明白了"的关节上，尤其是：

1. 积年换算时上元起点取法不一（各本差一年）
2. 入局数算完之后没有用"除 72"自查
3. 阴阳遁的判定各本说法不同
4. 计神的起例顺逆有异文
5. 十六神名目（尤其乾位）有异文

> 完整推导、算例与口径表见系统知识库**板块1—板块3**，本笔记不重复罗列。

### 2_3 第三章 太乙格局十目

十目依次为：**掩、迫、关、囚、击、格、对、提挟、四郭固、四郭杜**。

这一章的读法不是"背名词"，而是建立一张**三梯队的优先级表**：

| 梯队 | 目 | 共同点 | 用法 |
| --- | --- | --- | --- |
| 第一梯队（伤本体） | 击、掩、迫、囚 | 直接作用于太乙或主目本身 | 出现即须先处理 |
| 第二梯队（牵制四将） | 关、格、对、提挟 | 作用于主客将之间 | 在算数相当时才成为决定性 |
| 第三梯队（环境态） | 四郭固、四郭杜 | 描述四隅通塞 | 修饰结论，不单独定胜负 |

**为什么必须分梯队**：一局里同时出现三个格局是常事，若不分轻重，读者会陷入"三个都算、三个都不算"的泥潭。分完梯队，判断链才有次序。

> 十目的定义、判定条件与速查表见系统知识库**板块7**，裁决次序见**板块8**。

### 2_4 第四章 太乙运式：二十四节神将一览

第四章是全书的"零件清单"，二十四节依次为：

> 太乙、文昌、主算、主大将、主参将、始击、客算、客大将、客参将、定目、定算、定大将、定参将、君基、臣基、民基、五福、大游、小游、四神、天乙、地乙、直符、飞符

可以把它们归成四组记：

| 组 | 成员 | 作用 |
| --- | --- | --- |
| **一台** | 太乙 | 定当令之方 |
| **二目** | 文昌（天目/主目）、始击（地目/客目） | 定主客各自看什么 |
| **八将** | 主大将、主参将、客大将、客参将、定大将、定参将（六将）+ 主算、客算、定算（三算） | 定双方兵力与裁判 |
| **十精** | 君基、臣基、民基、五福、大游、小游、四神、天乙、地乙、直符、飞符 | 叠加层，加减不翻案 |

**记忆要点**：十精是**叠加层，不是主力判据**。作者把这二十四节平铺并列，读者容易误以为它们同等重要——事实上先定主客算、再看十精加减，次序不能倒。

## 板块3 · 第二部分拆解：应用层七章

### 3_1 第一章 身命四宫与限曜

十四节：确立命宫、确立身宫、确立日宫和时宫、飞禄飞马大小限法则、出生年干化曜、日干化曜、空亡、十二宫居空亡判断、看命宫步骤、论身宫、论时元、论贵福贫贱命、身命合格判断、二三和局兴衰。

这一章的结构是"**先立四宫，再飞星曜，最后判格**"：

```
第1步 立四宫：命宫、身宫、日宫、时宫（对应出生的年、月、日、时）
第2步 飞限曜：飞禄、飞马、大限、小限
第3步 起化曜：出生年干化曜、日干化曜
第4步 查空亡：十二宫居空亡的判断
第5步 判格局：看命宫、论身宫、论时元、论贵福贫贱、身命合格、二三和局
```

**必须说明的边界**：这一套在形式上非常接近紫微斗数与七政四余的"星曜临十二宫"体系，但它**不是太乙的本位用法**。太乙的本位是"以局论势"，身命推法是太乙在明清以后吸收星命学而形成的分支。

> **口径说明**：本库系统知识库**板块10**已明确把身命推法定位为"分支应用"而非主干，其可验证性远低于太乙本位的局与势推演。读这一章时请带着这层意识：**它是"太乙的一家应用"，不是"太乙的主体"。**

### 3_2 第二章 十六星神临十二宫判断

十六节，逐神讲临十二宫：五福、君基、臣基、民基、文昌、计神、小游、主大将、客大将、主参将、客参将、始击、飞符、四神、天乙、地乙。

这一章是全书中**篇幅最重、也最像星命学**的一章。它的价值在于给出了一张完整的"神 × 宫"对照矩阵；它的风险在于**条目越细，越容易被当成查表即得**。

**正确的用法**：把这一章当**参考词典**，不贯通读。真正要判断时，先有主客算的结论，再拿这一章做加减，而不是反过来。

### 3_3 第三章 十六神临乾艮巽坤四维宫 + 第四章 二至三星同宫

- 第三章：十六神在四维宫（乾、艮、巽、坤）上的判断。四维在太乙里是"间辰"之位，主两可之交与门户，与十二支神的读法不同
- 第四章：二星同宫、三星同宫格。多星同宫时如何裁并——这是本书处理得比较细致的一处

### 3_4 第六章 十六神三等判断

把十六神按三等（上、中、下）归类，并给出"太乙十六神三等总汇表"。

> **待核**：公开目录显示本章按五福、君基、臣基、民基、文昌、计神、小游、主大将、客大将、主参将、客参将、始击、飞符、四神、天乙、地乙的顺序逐神分等，末附「太乙十六神三等总汇表」；**三等的具体判准与各神所属等次在库内 PDF 之外未核到原文**，故本笔记不列出具体分等内容，只记录其结构。读者请以原书为准，并注明所据版本。

### 3_5 第七章 太乙七大法

目录所见前三术为：**临津问道术、狮子反踯术、白云卷空术**。

> **待核**：公开目录仅列出此三术，**其余四术之名未见**，故本笔记不作补全。凡"七大法"的完整名录与内容，须回原书核查，不得据他书推测填空。

**这一章的读法**：七大法属作者归纳的"高级技法"层，处在全书的末端。按本库的学习路径，**它应在能独立排完十局之后才碰**，在此之前读它只会增加名词负担。

## 板块4 · 实操手册：一张纸走完一局太乙

```
第0步 定档位：这一局用年计、月计、日计还是时计？先写下来
第1步 求积年：按上元起点换算到所求年
第2步 定入局：积年累除 360 → 余数累除 72 → 不满余数即入局数
       自查：入局数必小于 72
第3步 定太乙：按阴阳遁行八宫，定太乙所在宫（不入中五）
第4步 填盘面：排十六神、标间辰、定太岁合神计神
第5步 立二目：文昌（十八累除）、始击（计神加和德艮）
第6步 取算数：主算、客算，并注明"是否含间辰"这一口径
第7步 定四将：主大将主参将、客大将客参将
第8步 平局裁判：主客相差在二以内时，启用定目定算定大将定参将
第9步 过格局：十目逐目过一遍，按三梯队排出次序
第10步 看十精：叠加层，只做加减，不翻案
第11步 出断语：落到"主胜/客胜 + 内外 + 和与不和"，并给出依据三条
第12步 登记：局式、断语、依据、预留回填栏
```

**一条硬规矩**：第 11 步的断语**必须落在主客关系上**，不要写成"吉/凶"。写成"吉凶"就丢掉了太乙最独特的输出。

## 板块5 · 把太乙翻译成通用决策法（这是本书真正值钱的地方）

剥掉神煞与算术的外壳，太乙的骨架是一套**态势评估的结构化方法**，越界依然成立：

| 太乙的部件 | 通用决策里的对应物 | 说明 |
| --- | --- | --- |
| 积年入局 | **确定观察窗口** | 先说清楚你在评估哪一段时间 |
| 太乙所在宫 | **确定主战场** | 力量集中在哪儿 |
| 文昌 / 始击 | **双方视角** | 不只站自己这边看，也要站对方那边看一遍 |
| 主算 / 客算 | **力量对比** | 量化，而不是形容词 |
| 格局十目 | **约束条件** | 有哪些地形、规则、意外在限制双方 |
| 和与不和、内外 | **对抗烈度** | 是打得起来，还是各走各路 |
| 十精 | **环境变量** | 影响大小，但不改变基本面对比 |
| 出断语 | **结论 + 依据三条** | 没有依据的结论不算结论 |

**这套结构最值得抄走的一条**：**"有无"先于"多少"。** 太乙的裁决次序是"格局（有无约束）> 算数（多少力量）> 十精（环境变量）"。放到任何决策里都成立——先看有没有硬约束，再看资源多少，最后才看环境变量。

---

**示例**：把「主客算长短」换成「我方与对方的资源对比」，太乙的胜负框架即可用于竞争分析。

## 板块6 · 学习路线与避坑清单

### 6_1 推荐路径（三遍法，非从头读到尾）

```
第一遍：板块1—2（本笔记）→ 只搭框架，不求记全
       同时手算积年入局，算到自己不假思索

第三遍：才进第二部分（身命推法），且始终记住它是分支
```

### 6_2 必记必背的最小知识集（不熟不要往下学）

1. 五元六纪：72 年一元、60 年一纪、360 年一大周期
2. 太乙九宫的宫序与分野（一乾二离三艮四震六兑七坤八坎九巽，不入中五）
3. 十六神的顺序与主事
4. 文昌、始击二目的求法

### 6_3 避坑清单

| 坑 | 表现 | 改法 |
| --- | --- | --- |
| **坑一：从身命入手** | 觉得第二部分"更像算命"，先读它 | 掉头。先能独立排完十局 |
| **坑二：把条目当定论** | 照抄作者的唯一规则 | 凡起例必查异文，一局之内只用一套口径 |
| **坑三：断语写成吉凶** | "这一局大吉" | 改成"主算长、客受掩，主胜"，并给依据三条 |

## 板块7 · 本书最大的三个洞见（我的判断）

**洞见一 · 太乙的价值在"结构化"，不在"预测"。**
本书最有用的是第二、四章——它把一台散落在各种歌诀里的机器，装成了一份完整零件清单（二十四节）。这份清单本身就是贡献。至于"预测"二字，读者宜自行降低预期。

**洞见二 · 条目化既是优点也是陷阱。**
二十四节、十目格局、十六神三等——条目化让自学成为可能，但也把古本中本就存在的分歧压成了一条"标准答案"。**读这本书的正确姿势是：拿它搭结构，拿原典核规则。**

**洞见三 · 第二部分暴露了太乙的定位张力。**
身命推法在形式上与紫微斗数、七政四余高度相似。这提示我们一件事：**一门术法在流传中会不断吸收邻近术法来扩展自己的适用范围**，扩展往往带来流行，也往往稀释了它原本最独特的东西。太乙最独特的是"以局论势、以算论力"，不是"星曜临宫"。

---

**示例**：太乙值钱在「结构化评估」，不在「算准」——一次只取其框架、不取其断语的用法。

**最后一句提醒**：这本书给你的是一份**装配说明书**，不是一台已经装好的机器。说明书的价值在于告诉你有哪二十四个零件、它们怎么咬合；但每个零件的尺寸（起例规则）必须回原典去核，一局之内只能用一套口径。至于它能"预测"什么——请务必把它放在自己的实践里、用现代常识与事理去校验，取其"如何结构化地评估一个复杂对局"的硬核骨架，去其依附于时代的旧壳。
