# 梅花易数系统知识库
## README · 导览

> **副标题**：从取象到断卦的完整闭环——一套"机 → 数 → 卦 → 象 → 理"的可落地实操手册

---

### README_1 本库是什么

这不是《梅花易数》的原文摘抄，而是一次结构性重建。原书条目松散、版本混杂、后人增益甚多，初学者极易陷入"背了一堆口诀、断卦依然卡壳"的困境。

本库按**"先走对路 → 打地基 → 学核心技术 → 上心法 → 练应用 → 复盘案例 → 避坑 → 由术入道"**的顺序重排，共 14 个板块（板块0—板块13）。每一节都只回答三个问题：

```latex
第1步 这一步怎么做
第2步 做完得到什么
第3步 常见错误是什么

```

本库另有三块系统化的实操补充，是原书零散、一般教程少见的内容：

+ `4_6` 先天起卦与后天起卦的分野
+ `5_6`—`5_8` 爻位、卦象直读、错卦综卦三件进阶工具
+ `9_5` 射覆训练场

### README_2 三条主线

读完全库你会发现，所有技术细节都挂在这三条主线上。抓住主线，就不会迷失在口诀里。

#### 主线一：机 → 数 → 卦 → 象 → 理（技术主干）

```latex
【机】触发占问的那个"异常"（不动不占）
   ↓
【数】把"机"量化（年月日时、数目、物数、笔画）
   ↓
【卦】数成卦（卦以八除，爻以六分 → 本卦 / 互卦 / 变卦）
   ↓
【象】卦还原为万物（八卦万物类象 + 场景嫁接）
   ↓
【理】象组合成判断（常理、情理、五行生克之理）

```

原书最要紧的一句叮嘱：**"推数必须推理。"** 只推数不推理，是学不到家的。

#### 主线二：以物观物（心法主线）

> **"以物观物，性也；以我观物，情也。性公而明，情偏而暗。"**

断卦时心里先有了"我希望它吉"的预设，卦就会被主观带偏——这就是"以我观物"的弊端。本库把"以物观物"作为贯穿始终的隐性主线：

| 环节 | "以物观物"的具体要求 |
| --- | --- |
| 起卦 | 取第一念，不挑选、不重算 |
| 断卦 | 先参爻辞、次看体用（原典顺序），不让好恶介入 |
| 取外应 | 等它来，而不是去找它 |
| 应期 | 数算出来后用常理校正，不硬套数字 |
| 日常 | 换成"给最好的朋友提建议"的立场 |

#### 主线三：从术到道（境界主线）

板块0 至板块11 是"术"（可训练的手艺），板块12、板块13 是"道"（《皇极经世》的观物心法与落地工具）。

> **卦象是死的，当下之机是活的，断卦的人心是枢纽。**

### 0_2 使用建议与边界声明

这一节必须写在最前面，而不是放在附录里。

#### 能力边界：它是"取象推理训练"，不是科学预测工具

《梅花易数》的价值，在于**锻炼观察力、结构化联想力、以及在信息不全时做出自洽判断的能力**。它的推演机制不具备可重复的实证基础，"应验"存在极强的选择性叙事与事后解释空间。

因此：

| 场景 | 建议 |
| --- | --- |
| 日常小事、趋势思考、创意启发 | 可练可用，当作思维体操 |
| 重大人生决策（择业、婚姻、搬迁） | 可作**参考视角之一**，绝不可作唯一依据 |
| 投资、医疗、法律、人身安全 | **禁止**使用。这些领域有专业方法论，用占卜替代是拿命运赌博 |

#### 伦理红线：易为君子谋，不为小人谋

历代易家明确不取的四类占问：

1. 未经同意占问第三方隐私；
2. 占问作奸犯科之事的成败；
3. 占问赌博、投机暴富的时机；
4. 以占卜挑拨他人关系、制造恐惧牟利。

> **一条底线判断法**：如果这件事你不愿意当着当事人的面说出来，就不要起这个卦。

#### 关于宿命论：卦是地图，不是牢笼

梅花揭示的是"**若按此轨迹发展，将得此结果**"，目的在于**趋吉避凶**，而不是"卦说不行就不行"。

> 古人说"易为君子谋"，谋的是"看清形势后怎么行动"，不是"坐等结果降临"。路怎么走，仍在自己脚下。

> **小故事·为什么死磕第一天**

有个初学者，第一天就卡住了。他问："乾卦到底是什么？"
他翻了三本书，得到的答案加起来有几十种：天、君、父、马、金玉、圆物、头、骨、肺、首都、钟表、轿车，一路列下去没完。越看越乱。等到自己断卦时，脑子里塞满了象，反而一个都抓不住，最后干脆放弃取象，每次只敢说"吉"或"凶"两个字——**断是断了，等于没断。**
后来有人教了他一个办法：**先只记死一条线——"乾 = 天 = 君父 = 头 = 刚健贵重"，其余一律用到再查。**
他将信将疑地照做了两周。第三周他忽然发现，再遇到"马""金玉""圆物"时，根本不用翻书——它们都从"刚健、贵重、圆满"这条气质线上自然长出来，看一眼就知道该不该往这边想。
更意外的是，他开始能自己发明类象了：看到一辆高档轿车，他脱口而出"乾"，理由是"贵重、金属、在上、有动力"——**他没背过这一条，是他自己推出来的。**
**道理**：核心三象是锚，其余是枝叶。锚稳了，枝叶自然挂得上；锚不稳，背一百个象也只是散钱一串。先立气质，再长枝叶，这才是"活"的取象。

### 0_5 学习纪律：三条铁律与"一事不二占"

#### 起卦三条铁律（贯穿全部实操）

1. **不动不占，不因事不占。**
没有触发、没有契机，就不要起卦。观梅占之所以成立，前提是"二雀争枝坠地，怪也"——先有异常，后有占问。没有问题硬起卦，是把自己往随机噪声里扔。
2. **取当下第一念，不反复换法。**
数一出来，卦就立住了。起卦时犹豫、换方法、重算，卦气必乱。
3. **一人一卦；同场多人须加变量区分。**
多人同占同一件事时，嵌入姓氏笔画、方位、服色、声数等变量，让卦分途。

#### "一事不二占"及其例外

同一件事，短期内反复起卦直到算出吉卦为止——这是最常见的自欺。**第一次心念一动所起之卦为"先天之机"；刻意强求、反复占问，属于人为干扰，参考价值极低。**

实操约定：

+ 同一问题再次起卦，须另有机缘；原书未设固定间隔（"七日"之说无原文依据）；
+ 若确实重占，必须在卦例本中注明"重占第 N 次，前次结论为 X"，并把两次结论的差异当作**信息**而非噪音——差异本身往往说明"事态在变化"或"你的心不定"。

#### 三条练习纪律

+ **只测可验证的小事**：明天的会是否顺利、本周快递哪天到、丢的钥匙在哪。不测"我这一生能否发财"这类无法证伪的问题。
+ **一次只问一事**：把"我该不该跳槽"与"跳了之后感情怎么办"拆成两卦。
+ **事后诚实记录**：断错了就写断错，不许事后圆卦。

> **小故事·重卦的代价**

有位商人问一笔生意能不能成，第一次起卦得"用克体"，心里不舒服。隔了十分钟，他换个数字重起，这回得"用生体"，于是大喜，放心投钱，结果亏了不少。
事后复盘，他犯的错根本不是"卦不准"——第一次那个"用克体"才是真信号。他的问题是**"以我观物"**：心里先有了"我希望它成"的预设，再去找一个支持自己的卦。
这就像一个人去问医生，第一位医生说"你这病得治"，他不爱听，换到第二位医生听到"没事，多喝水"就安心走了。**卦是给你看真相的，不是给你做心理按摩的。** 换个卦问，问的不是天意，是自己的欲望。

在动手起卦之前，必须先搞清楚这套东西"算"的究竟是什么。这一层没打通，后面所有技术都会变成没有灵魂的口诀背诵。

### 1_1 源流与真伪：托名邵雍，但思想是真的

《梅花易数》全称《邵康节先生观梅拆字数全书》，**托名北宋邵雍（1011—1077，字尧夫，谥康节）**。学界通行看法是：此书并非邵雍亲笔，而是**明代人整理、增益、托名而成**，传本繁杂（通行本、增补本、家传本各有出入）。

但需要区分两件事：

| 层面 | 结论 |
| --- | --- |
| **作者与成书** | 托名邵雍，成书约在明代，部分内容系后人增益，不必逐字当真 |
| **思想内核** | **完全继承邵雍的先天之学**：先天八卦数、加一倍法、体用框架、"以物观物"的认识论——这些都能在邵雍《皇极经世》的体系中找到根源 |
| **实操价值** | 与作者真伪无关。方法骨架自洽，是可训练、可复用的思维工具 |

**为什么书名里有"梅花"？** 因为开篇那个著名的案例：辰年十二月十七日申时，邵雍观梅，见二雀争枝坠地，觉得"怪也"，遂起卦，断"明晚有女子折花，被园丁惊逐，坠地伤其右股"，次日夜果然应验。这一占起于赏梅，后世遂称"梅花易数"（完整拆解见 `10_1`）。

> **一句话**：不必纠结"是不是邵雍写的"。**方法骨架自洽、可训练、可复用**，这就够了。正如一把刀好不好用，取决于刀刃快不快，不取决于铸刀匠的名字。

### 1_2 底层逻辑：机 → 数 → 卦 → 象 → 理

全书没有一个字教你摆弄鬼神。它的底层逻辑只有一条：

> **万物皆可化为数，数可成卦，卦可生象，象可推理。**

拆成五段链条，这就是全书的主干：

```latex
【机】触发占问的"异常"  → 识别"不动不占"的那个"动"
   ↓
【数】把"机"量化        → 年月日时、数目、物数、笔画
   ↓
【卦】数成卦            → 卦以八除，爻以六分（本卦 / 互卦 / 变卦）
   ↓
【象】卦还原为万物      → 八卦万物类象 + 场景嫁接
   ↓
【理】象组合成判断      → 常理、情理、五行生克之理

```

| 环节 | 是什么 | 关键动作 | 常见失败点 |
| --- | --- | --- | --- |
| **1. 机** | 触发占问的那个异常 | 识别"不动不占"的"动" | 无事硬占，机不真 |
| **2. 数** | 把"机"量化 | 年月日时、数目、物数、笔画 | 数算错、用公历代替农历 |
| **3. 卦** | 数成卦（本、互、变） | 卦以八除，爻以六分 | 余 0 处理错、互卦取错 |
| **4. 象** | 卦还原为万物 | 八卦万物类象 + 场景嫁接 | 类象死记硬套 |
| **5. 理** | 象组合成判断 | 常理、情理、五行生克之理 | **只推数不推理** |

#### 原书那句最要紧的叮嘱："推数必须推理"

> **小故事·冬夜借斧**

一个冬日的晚上，邵雍已经准备歇息，忽然听见敲门声。开门前，他先就"有人叩门借物"这件事起了一卦。
卦象显示："**金短木长**"之器。
按数字推，这是农具的象，最贴切的答案是"**锄**"。
但邵雍没有急着断。他想了一层：此刻天已经全黑，又是寒冬，谁会在半夜借一把锄头下地？锄头是白天干农活用的，夜里借锄，于理不通。
那冬天夜里，人们借东西最可能是做什么？——**劈柴生火取暖**。
于是他在"金短木长"这个范围内重新选了一个象：**斧**。
开门一问，邻居果然是来借斧头的。
**这一卦的关键不在数，而在最后那一步"于理不通"的自我追问。** 卦象给出的是可能性，常理才给出答案。

```latex
卦象结论 = 锄（金短木长）
   ↓ 常理校验
天已黑 + 冬日天寒 → 借锄下地？于理不通
   ↓ 在卦象范围内重选
劈柴生火 → 斧
   ↓ 开门验证
果然借斧（应验）

```

> **一句话记住**：不是"卦说我会怎样"，而是"**当下这个机，通过这个象，要告诉我什么义**"。

### 1_3 三组必须分清的核心关系

#### 第一组：先天数与后天位（最易混用）

|  | 先天八卦数 | 后天八卦方位 |
| --- | --- | --- |
| **用在何处** | **起卦**（把数变成卦） | **断事**（方位、失物、寻人、坐端） |
| **内容** | 乾1 兑2 离3 震4 巽5 坎6 艮7 坤8 | 乾西北 坎正北 艮东北 震正东 巽东南 离正南 坤西南 兑正西 |
| **口诀** | 乾兑离震巽坎艮坤，一二三四五六七八 | 乾西北、坎正北、艮东北、震正东、巽东南、离正南、坤西南、兑正西 |

> **血泪教训**：用先天数去断方位、用后天位去起卦，是新手第一号错误，且**错了自己发现不了**，因为两个体系都能算出结果——算出来的数都有对应的卦，看起来"有答案"，但答案是错的。

原书的表述是"**用后天卦方位，先天卦数**"——这句话就是答案：**方位看后天，数字看先天**。

#### 第二组：本卦、互卦、变卦（时间轴）

| 卦 | 取法 | 代表 |
| --- | --- | --- |
| **本卦** | 起出的原卦 | 事情起始、当下状态 |
| **互卦** | 二三四爻为下互、三四五爻为上互 | 中间过程、隐情、暗流 |
| **变卦** | 动爻阴阳互换后所成之卦 | 最终结果、趋势走向 |

```latex
【时间轴】
起始 ─────────→ 过程 ─────────→ 结局
本卦              互卦              变卦
（当下）        （中段暗流）      （最终走向）

```

**互卦的关键提醒**：互卦**本身不再分体用**，只看它对体卦的生克作用。

#### 第三组：体与用（全书灵魂）

+ **体卦** = 本卦中**无动爻**的那一半 → 我、主体、根本、当下
+ **用卦** = 本卦中**有动爻**的那一半 → 对方、所问之事、外部环境

口诀：**"动爻所在便为用，安静之卦体来充。"**

铁律：**我/求测者 = 体，彼/所问之事 = 用，永不颠倒。**

### 1_4 五大认知误区：先破后立

| 误区 | 真相 |
| --- | --- |
| **1. 它是一本算命书** | 它是"取象—推理"的思维训练。占验的本质是把一次偶然事件翻译成结构化符号，再用五行生克推演趋势 |
| **2. 同一个卦永远对应同一件事** | 原书自问自答：「今日观梅得革兆，断女子折花；异日复得革兆，亦断女子折花，可乎？」——**不可**。决定具体指向的是"当下之机 + 万物类象 + 情理"三者合参 |
| **3. 起卦需要对方配合** | 与摇钱、报八字不同，梅花占**主动出击**：不须抛钱币、不须报生辰，"根据其一行一动、一言一句"即可取卦。技艺纯熟者声色不动 |
| **4. 体用生克就是全部** | 体用是起点不是终点。原书中"今日动静如何"一卦，体用显示为凶，邵雍却断"有酒食之乐"——靠的是旺衰校正 + 卦象组合（见 `10_5`） |
| **5. 梅花不论干支、不用冲合** | 这是"替懒惰找借口"。古本虽不以干支为主，但**占断离不开时空，干支就是打开时空的钥匙**。至少地支序数、月令、日支必须掌握 |

#### 关于误区2.的详解：什么叫"心易"

本书又叫"**梅花心易**"。"心易"二字，是全书之眼——**以心契易、以理驭数、以变破执**。

原书那句自问自答值得再读一遍：

> 「今日观梅得革兆，断女子折花；异日复得革兆，亦断女子折花，可乎？」

意思是：今天看梅花得到"革"卦，断出女子折花；改天又得"革"卦，也断女子折花，行吗？——当然不行。

同一个"革"卦，换个场景可以对应完全不同的事。兑为少女，难道兑卦一出现就只有女子？乾为马，难道乾卦一出现就一定有匹马？

> **决定具体指向的，不是卦本身，而是"当下之机 + 万物类象 + 情理"三者的合参。数死理活，把活法教死，就全错了。**

### 1_5 与《皇极经世》的分工：宏观周期与微观占断

邵雍的思想体系有两部代表作，二者是**同一套"体用"框架的两种尺度**，不可混为一谈：

| 维度 | 《皇极经世》 | 《梅花易数》 |
| --- | --- | --- |
| **问题** | 宇宙与历史的整体走向是什么？ | 眼前这件事会怎样？ |
| **时间尺度** | 元会运世：1 元 = 129600 年 | 一日、一月、一年之内 |
| **工具** | 元会运世周期 + 先天六十四卦方圆图 | 先天八卦数 + 体用生克 |
| **性质** | 宇宙论、历史哲学、周期模型 | 占断术、取象推理 |
| **共同根** | **加一倍法**（一分为二的生成语法）、**先天之学**（心法）、**体用不二** | 同左 |

#### 最值得带走的一条交叉启发

《皇极经世》讲"以物观物"——

> **"以物观物，性也；以我观物，情也。性公而明，情偏而暗。"**

这恰恰是梅花易数断卦时的心法要求：**把"我"从判断里拿掉，让卦象自己说话**。断卦时心里先有了"我希望它吉"的预设，卦就会被主观带偏——这就是"以我观物"的弊端。

因此，本库把"以物观物"作为贯穿始终的隐性主线：

| 环节 | 落地做法 |
| --- | --- |
| 起卦 | 取第一念，不挑选 |
| 断卦 | 先看体用后看爻辞，不让好恶介入 |
| 外应 | 等它来，而不是去找它 |

> **读法建议**：若想先追思想源头，可跳读板块12（《皇极经世》的观物心法）；若想先学手艺，继续往下走板块2。

### 1_6 全书的五层骨架：你要爬的这座楼长什么样

在往下走之前，先把整座楼的五层结构看一眼——知道自己站在第几层，才不会在某一层里打转。

原书传本繁杂（通行本、增补本、家传本各有出入），条目看似松散。按其内在逻辑，可重构成清晰的五层：

| 层级 | 内容 | 作用 | 对应板块 |
| --- | --- | --- | --- |
| **第一层：地基** | 先天数、后天位、五行、八卦万物类象 | 数→象的翻译字典 | 板块2、板块3 |
| **第二层：起卦** | 时间、报数、物象、声音、文字等起卦法 | 把机化为卦 | 板块4 |
| **第三层：断卦** | 体用总诀、生克、卦气旺衰、互变 | 判断吉凶趋势 | 板块5、板块6 |
| **第四层：分类占** | 天时、人事、婚姻、求名、失物等十余占 | 把吉凶落到具体事 | 板块8、板块9 |
| **第五层：心法** | 三要十应、触机、动静、坐端 | 让卦"活"起来 | 板块7、板块10 |

**前四层是"术"，第五层是"道"。**

> **一条极有用的自检**：多数人卡在第三层（断卦），但问题往往出在**第一层和第五层没打通**——要么硬知识没背熟，要么外应用错了。卡住时先别钻断卦技巧，回头查这两头。

---
#### 案例小故事：先问它算什么，再问它准不准

有人第一次接触梅花易数，开口就问：能不能算出彩票号码？

这个问法本身就暴露了误解。梅花易数处理的是**一件已经动念的事，在当下的形势、阻力与时机**——它的输入是"机"，输出是"势"。

如果一件事没有任何信息可供起卦（比如一个纯随机的号码），那就没有"机"，也就谈不上卦。同一套方法，用来看"这个合作能不能成"，就能给出可验证的结构判断；用来猜号码，它就只是装饰。

**落点**：先把"它算什么"问清楚，再问"它准不准"。多数"不准"的抱怨，其实是问错了对象。

### 2_3 八卦五行归属【必背】

| 五行 | 卦 |
| --- | --- |
| **金** | 乾、兑 |
| **木** | 震、巽 |
| **水** | 坎 |
| **火** | 离 |
| **土** | 坤、艮 |

**记忆法**：只有坎（水）、离（火）是"独苗"，其余六卦两两配对——乾兑金、震巽木、坤艮土。

#### 乾金与兑金的区别（卦理层面的关键）

这是初学者最容易忽略、却极其要命的一条：

+ **乾金** = 贵重、圆润、刚健之物：金玉、珠宝、钟鼎、高档器物
+ **兑金** = 损坏、破损、开口之物：缺口器皿、刀刃、金属碎屑

> 不知卦理，就分不清"同样是金，为什么这里断首饰、那里断破铜烂铁"。**死记类象而不懂卦理，是学不到家的。**

> **小故事·两件都是金，结果却相反**

同一天，两个人来问事，卦上出现的都是"金"。
第一位是丢东西来问的，用卦为**兑金**。断卦的人说："东西恐怕已经破损了，或者掉在一个有缺口的容器旁。"——因为兑为破损、为开口、为毁折。后来他在阳台的破花盆边找到了那只摔裂的杯子。
第二位是问能不能买到心仪的物件，用卦为**乾金**。断卦的人说："能买到，而且是贵重、精致的好东西。"——因为乾为贵重、圆润、刚健。后来他果然抢到了那支限量款。
旁观者困惑：都是金，一个断凶一个断吉，凭什么？
凭的是**卦理**。兑是"开口破损之金"，乾是"贵重圆润之金"。同样是金，一个是缺口器皿，一个是金玉钟鼎。
**死记类象而不懂卦理，就会在这里卡住**：你只知道"这是金"，却不知道"这是什么金"。而断卦恰恰是靠后者分出吉凶的。

### 2_4 五行生克、反克与通关【必背】

```latex
【相生环】金 → 水 → 木 → 火 → 土 → 金
【相克环】金 → 木 → 土 → 水 → 火 → 金

```

**生克含义速记表**：

| 关系 | 定义 | 在断卦中的含义 |
| --- | --- | --- |
| **生我** | 他生我 | 得助、得力、有依靠 |
| **我生** | 我生他 | 付出、消耗、泄气 |
| **克我** | 他克我 | 受压、受阻、被制约 |
| **我克** | 我克他 | 掌控、费力、能成但劳 |
| **比和** | 同类 | 同频、平顺、无阻力 |

#### 反克（量变引起质变）

五行生克不是死公式，量级悬殊时会**反克**：

+ **金克木，但木坚金缺**：斧头砍不动硬木，反卷刃
+ **木克土，但土重木折**：根须扎不进顽石
+ **水克火，但火旺水干**：杯水车薪反被蒸干
+ **火克金，但金多火熄**：一堆湿灰压灭火苗
+ **土克水，但水多土流**：洪水冲垮堤坝

> **断卦应用**：体卦旺相时，用卦来克往往是"克不动"，凶性大减；体卦休囚又遇旺克，才是真凶。

#### 通关：克局的化解之法【重要干货】

**这是断卦中最实用的一条进阶技巧**：当体用相克时，若互卦或外应中出现一个"中间五行"，能建立"生—生"的桥梁，则**凶局有解，甚至转吉**。

| 克局 | 通关五行 | 通关链条 |
| --- | --- | --- |
| 金克木 | **水** | 金生水 → 水生木 |
| 木克土 | **火** | 木生火 → 火生土 |
| 土克水 | **金** | 土生金 → 金生水 |
| 水克火 | **木** | 水生木 → 木生火 |
| 火克金 | **土** | 火生土 → 土生金 |

**断卦口诀**：**体用相克，立刻看互卦；互中见通关，凶中有救。**

**记忆窍门**：通关五行 = "**克我者所生的那个五行**"。比如金克木，金生水、水生木，水就是通关。

### 2_5 卦气旺衰：旺相休囚死全表【必背】

> **体例说明（原文校准）**：《梅花易数》卷一只设**「卦气旺」「卦气衰」两档**——
> 「震、巽木旺于春。离火旺于夏。乾、兑金旺于秋。坎水旺于冬。坤、艮土旺于辰戌丑未月。」
> 「春坤、艮。夏乾、兑。秋震、巽。冬离。辰戌丑未坎。」（后者即各季之衰）
> **"旺、相、休、囚、死"五档出自六爻与命理体系，非《梅花易数》原文。**
> 本表保留五档，是因为它更精细、便于定量；但须知道这是**后世补入的刻度**，
> 用时应与本卦体用生克合参，不可反客为主。

**这是全书最容易漏、漏了就断不准的关键。同一个生克关系，旺卦与衰卦，吉凶轻重天差地别。**

#### 万能口诀

> **当令者旺，我生者相，生我者休，克我者囚，我克者死。**

#### 全表

| 时节 | 旺 | 相 | 休 | 囚 | 死 |
| --- | --- | --- | --- | --- | --- |
| **春**（寅卯辰月） | 木 | 火 | 水 | 金 | 土 |
| **夏**（巳午未月） | 火 | 土 | 木 | 水 | 金 |
| **秋**（申酉戌月） | 金 | 水 | 土 | 火 | 木 |
| **冬**（亥子丑月） | 水 | 木 | 金 | 土 | 火 |
| **四季末**（辰戌丑未月） | 土 | 金 | 火 | 木 | 水 |

> **一处易生疑惑的地方**：辰月既出现在"春"行，又出现在"四季末"行，是否矛盾？

**不矛盾，这恰恰是五行的真实状态**——辰月是春季的末月，**木的余气尚存，而土气已经渐旺**。同理：未月（夏末，火有余气）、戌月（秋末，金有余气）、丑月（冬末，水有余气）。
**实操取法**：优先按"四季末"取**土旺**；但若卦中木象明显、且所问与木相关，辰月可给木留一分余地。其余三个末月同理。

#### 记忆窍门（故事法）

以春天为例，把五行想象成一个朝廷：

```latex
旺（木）= 皇帝   → 春天木当家，自己是皇帝，权势最盛
相（火）= 太子   → 我生的，次旺（木生火）
休（水）= 老臣   → 生我的，活干完了去休息（水生木）
囚（金）= 囚徒   → 克我的，想造反被镇压（金想克木，春天克不动）
死（土）= 处决   → 我克的，最惨（木克土）

```

#### 量化参考分值（便于加权计算）

| 状态 | 旺 | 相 | 休 | 囚 | 死 |
| --- | --- | --- | --- | --- | --- |
| **分值** | 10 | 8 | 5 | 3 | 1 |

> 这个分值是**经验参考值，用于帮助体会"轻重"，不是精确公式**。真实断卦中不必算出分数，但要有"旺衰差几档"的直觉。

#### 实操要点

+ **用卦旺相**，生体之力大；**用卦休囚死**，虽生亦力微——好比一个病弱的贵人想帮你，心有余而力不足
+ **体卦休囚死再被克**，才是真凶险
+ **体卦旺相**，即使用卦来克，也往往"克不动"，只是小波折

#### 进阶：月令与日辰——两把尺子，权重不同

只按月令断旺衰，只完成了一半。断卦的天时其实有**两把尺子**：

|  | **月令（月建）** | **日辰（日建）** |
| --- | --- | --- |
| **性质** | 中长期趋势、大环境气候、基本面能量 | 短期波动、当下契机、临门一脚的力量 |
| **作用** | 决定卦"有没有根"、是否得时 | 决定卦在"当下"是否得势、吉凶能否速显 |
| **影响力** | 持续、深厚、基础性 | 即时、尖锐、事件性 |
| **权重** | 无原典定量 | 无原典定量 |

> **原文校准**：《梅花易数》全书**无"月令权重 60%—70%、日辰 30%—40%"之说**，
> 亦无"月建""日建"之名——这两个概念出自六爻体系（如《增删卜易》："月将即是月建，
> 又为月令，日辰为六爻之主宰"）。梅花原书只用**四时卦气**（见上文卦气旺衰）。
> 下表可作实操参考，但记为**借自六爻的辅助刻度**，不要当作梅花本门规则引用。

> **口诀**：**月令管一月之权，日辰管一日之令。**

**体卦衰弱，得日辰生扶，如久旱逢甘霖；体卦强旺，受日辰克制，如烈日遇暴雨。**

#### 日辰的四种作用（短期占断必看）

| 作用 | 含义 |
| --- | --- |
| **日建生体** | 体卦虽在月令休囚，得日辰相生 → **绝处逢生**，由衰转旺，事可为 |
| **日建克体** | 体卦虽在月令旺相，被日辰相克 → **旺而受损**，当天压力大、有突发阻碍 |
| **日建冲体（日破）** | 体卦衰弱被冲 → 彻底散架；体卦极旺被冲 → 反为"暗动"，可能有突发之喜 |
| **日建填实** | 体卦衰弱时，等到其五行值日或受生之日 → 往往就是**应期** |

#### 什么时候主要看哪一把？

| 事的时间跨度 | 主看 | 举例 |
| --- | --- | --- |
| **测长期趋势**（年运、长远发展） | **月令为主**，日辰只作插曲 | 今年事业整体走向 |
| **测中期事**（数月，婚姻、事业） | **月令定基调，日辰看转折** | 这个季度能否成事 |
| **测短期急事**（当天或数日内） | **日辰权重高于月令** | 今天这笔生意能成吗、现在等人能等到吗 |

> **例**：秋天占得体卦震木（月令木死，大环境不利），但当天是**亥日或子日**（水生木）→ 体卦得日辰生扶，事情仍有可为，只是需要借力。

> **小故事·冬天的炭火**

有人冬天来问病，得用卦离火、体卦坤土。火生土，按表一查是"用生体"，看起来是吉兆。
但**冬月火休囚**。一堆将熄的炭火，暖不了大地。生是生了，力道却很弱。

> **体例说明（原文校准）**：此例为**教学演示**，用于说明"生克要参旺衰"这一原则，
> **并非《梅花易数》原书所载占例**——原书无"冬天火生土问病"之案，
> 亦无"论卦不论气，则局于象，昧于时"一语（全书检索无此句）。
> 本库此前误标为邵雍所断并引该句，现据原典改正，并改以中性表述保留其教学价值。

**这一例真正要记住的**：只看卦名生克、不看时令旺衰，等于看一个人的体检报告却不看他今年几岁。

> **四题全对，进入板块3。错一题，回头把对应小节再过一遍。**

#### 案例小故事：把先天数背熟之后，他还是断错了

一个人把先天八卦数背得滚瓜烂熟：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。起卦从不出错。

但他断卦常常不准。有一次他断一桩求财的事，卦数、体用都没错，结论却是反的。复盘时才发现，他只记住了数，没记住卦气——那一卦的体卦正当衰令，他算出来的体克用，实际上克不动。

他后来给自己加了一条：起完卦先写两个数——**数是什么、气是什么**。两个数都写出来了，才允许往下断。

**落点**：六组硬知识是六张网，不是六个数字。数、卦气、体用、互变、旺衰、类象，缺一张网，鱼就从那个洞里漏走。

### 3_1 类象的本质：为什么八卦能代表万物

起卦容易断卦难。三分钟能出一个卦，但出了卦之后怎么断？八成新手卡在这里。

**断卦靠三样东西：万物类象（八卦对应什么）、体用生克（你和事情的关系）、外应（此刻环境说了什么）。**

类象的来源，是《易传》说的"**近取诸身，远取诸物**"——先哲观察天地万物，把具有相似"气质"的事物归到同一个卦下。所以类象不是任意规定，而是**按性质聚类**：

+ 乾为天，所以凡**刚健、在上、圆满、贵重**之物皆归乾：君、父、首、金玉、马、圆物
+ 坤为地，所以凡**柔顺、承载、在下、方正**之物皆归坤：母、腹、布帛、牛、田野
+ 坎为水，所以凡**陷、隐、流动、险**之物皆归坎：沟渎、盗贼、耳、酒、弓轮

理解了这个原理，遇到古代没有的东西（手机、飞机、电梯）也能**按性质归类**，而不是死记硬背——这正是"卦理"高于"死象"的地方。

#### 八卦家庭关系口诀（断人物身份时用）

> **乾父坤母，震长男，巽长女，坎中男，离中女，艮少男，兑少女。**

#### 近取诸身 / 远取诸物（两组最常用口诀）

```latex
【身】乾头、坤腹、震足、巽股、坎耳、离目、兑口、艮手
【物】乾马、坤牛、震龙、巽鸡、坎豕、离雉、艮狗、兑羊

```

### 3_4 取象三原则：不硬套，才叫活

类象死记硬背、一成不变，是第二大常见错误（第一是体用颠倒）。原书明确反对"乾一定代表父亲"这类死板用法。

#### 原则一：先看求测什么事——问题决定取哪个象

同一个乾卦，在不同问题下取完全不同的象：

| 所问 | 乾取何象 |
| --- | --- |
| 问事业 | 领导、权力、职位 |
| 问求财 | 金玉、钱财、贵重物品 |
| 问健康 | 头、骨、肺 |
| 问人物 | 父亲、老人、领导 |
| 问失物 | 金属、圆形物、高处、西北方 |

> **一个卦有几十种类象，只选和问题最相关的三到五种。** 全用等于没用。

#### 原则二：看旺衰——卦旺取吉象，卦衰受克取凶象

| 卦的状态 | 取象方向 |
| --- | --- |
| 旺相 | 取其尊、贵、成、全之象（乾为珠宝、为领导） |
| 休囚死 | 取其衰、残、缺、废之象（乾为老翁、为寒凉、为无用之金属） |
| 受克 | 取其受损之象（离受水克 → 文书受损、眼睛疾病、光明受阻） |

**实例**：占求职，本卦用生体本是吉；但起卦瞬间看见**枯萎树木**（木之衰象，泄气之兆），则断"能入职，但薪资低、工作压抑"，并非大吉。

#### 原则三：上下两卦组合取象——单卦信息有限，两卦叠加才读出场景

这是从"会背类象"到"会断卦"的关键一跃。

| 组合 | 叠加出的场景 |
| --- | --- |
| 上乾下坤（天地否） | 天在上、地在下，二气不交。问合作 → 难成；问稳固 → 安泰 |
| 上坤下乾（地天泰） | 地气上升、天气下降，交泰通达 → 通顺、和合 |
| 上坎下离（水火既济） | 水上火下，相交为用 → 事可成，但"初吉终乱" |
| 上离下坎（火水未济） | 火上水下，不相为用 → 事未成，尚在变化中 |
| 上兑下巽（泽风大过） | 泽灭木 → 过度、负担过重，需变通 |
| 上艮下坤（山地剥） | 山附于地，剥落 → 衰败、守正待时 |

**练习**：取"上离下坎（未济）"，问"项目能否推进"，试着用叠加法说出三层含义：

```latex
第1步 火水不交，力量使不到一处
第2步 离为文书宣传、坎为险陷 → 宣传遇阻
第3步 未济非不可成，是时机未到

```

> **小故事·同一个乾卦，三个答案**

三个人同一天来问，卦上都出现了乾。
第一位问**升职**，断"有贵人，是位有权威的长辈在推你"——乾取"领导、权威人物"。
第二位问**丢的钥匙在哪**，断"在金属器物旁，或家里高处、西北角"——乾取"金属、高处、西北方"。
第三位问**父亲的体检报告**，断"重点看头部与骨骼"——乾取"头、骨"。
三个人拿到的是同一个卦，答案完全不同。**同一个乾卦有几十种类象，只选和"所问何事"最相关的那三五个。** 全用等于没用。

### 3_5 现代事物的归类训练

古代没有手机、电脑、电梯、飞机。若只会死背古象，遇到现代事物就断不了。**归类方法是：按气质归，不按形制归。**

#### 归类三步法

```latex
第1步 问性质：它是动的还是静的？硬的还是软的？发光的还是盛物的？
第2步 问功能：它做什么用？沟通？承载？切割？照明？
第3步 问位置：它在高处还是低处？室内还是室外？随身还是固定？

```

#### 常见现代事物归类参考

| 事物 | 归卦 | 理由 |
| --- | --- | --- |
| 手机 | 离（主）/ 巽 | 离为发光、为信息显示；巽为通讯、为入、为信号 |
| 电脑 | 离 / 乾 | 离为屏幕、文书；乾为贵重、为高端科技 |
| 电梯 | 巽 / 坎 | 巽为升降、为入；坎为升降之井、为险 |
| 飞机 | 乾 / 巽 | 乾为天、为在高处；巽为风、为飞行 |
| 高铁 | 震 | 震动、声响、疾行 |
| 摄像头 | 离 | 目之延伸、为光明与影像 |
| 网络/信号 | 巽 | 风行无形、无处不入 |
| 空调 | 巽 / 坎 | 巽为风；坎为寒凉、为水（制冷） |
| 银行卡 | 乾 / 坤 | 乾为金玉财物；坤为布帛、为承载（账户） |
| 快递包裹 | 坤 / 艮 | 坤为包裹承载；艮为块状、为门阙（收件） |
| 手术 | 兑 / 离 | 兑为刀刃、为破损；离为血、为火（消毒） |
| 合同文书 | 离 / 巽 | 离为文书；巽为契约、为绳直 |
| 直播/短视频 | 离 | 明丽、展示、虚荣、面向大众 |
| 充电桩 | 离 / 震 | 离为电；震为动、为能量启动 |

> **训练法**：每天挑 3 件身边物品，按三步法归类，并写出"我还可以把它归为哪个卦，为什么"。**一个物品能归多个卦，正是类象"活"的体现**——具体取哪个，由"所问何事"决定。

**自测**：试着给"无线耳机"归类，并说出两种可能的卦及理由。

```latex
参考思路：
离 —— 播放声音、有光显、贴在耳上随身的电子设备
巽 —— 无线信号"入"耳、细长轻软之物
取哪个，取决于你问的是"耳机能不能修好"（离，看电子器件）
还是"信号会不会断"（巽，看连接是否通畅）

```

#### 案例小故事：取错了象：从"坤为母"到"坤为承载"

有人问合作能不能成，卦中见坤，他翻类象表：坤为母、为布、为釜、为吝啬，一条条套下去，越套越乱，最后什么也没断出来。

换一个取法就通了：坤的**关系属性**是柔顺、承载、迟缓、由对方主导。放进"合作"这件事里，读作"能成，但节奏慢、主导权在对方"。

事后反馈：合作确实成了，但谈判拖了两个月，条件基本由对方给。

问题不在类象太少，在他取的是"名物清单"而不是"关系属性"。

**落点**：万物类象要取**关系属性**（刚柔、动静、显隐、迟速），不要取**名物清单**。清单是背的，属性是用的。

### 4_1 总纲：卦以八除，爻以六分

全书起卦法虽多，总原则只有八个字：

> **卦以八除，爻以六分。**

#### 取余规则（必须先搞清楚，否则全盘皆错）

| 计算 | 取余规则 | 余数 0 的处理 |
| --- | --- | --- |
| **求卦**（上卦/下卦） | 数 ÷ 8，取余数 | **余 0 → 取 8（坤卦）** |
| **求动爻** | 数 ÷ 6，取余数 | **余 0 → 取 6（上爻动）** |

> **这是无数初学者最常见的基础性错误**：把"余 0"当成 0 或无卦。一旦错，全盘卦象全部颠倒，而且你**自己发现不了**。

**实例**：48 ÷ 8 = 6 余 0 → 下卦为**坤（8）**，不是"没有卦"。
**实例**：42 ÷ 6 = 7 余 0 → **上爻（第六爻）动**，不是"不动"。

### 4_2 时间起卦法（年月日时起卦·最正统）

#### 公式

```latex
上卦 =（年数 + 月数 + 日数）÷ 8，取余数
下卦 =（年数 + 月数 + 日数 + 时数）÷ 8，取余数
动爻 =（年数 + 月数 + 日数 + 时数）÷ 6，取余数

```

#### 取数规则

| 项 | 取法 | 说明 |
| --- | --- | --- |
| **年数** | 农历**地支序数**（子1丑2…亥12） |**不是公历年份！** 丙午年取午=7，不是年份数字 |
| **月数** | 农历月数（正月=1，腊月=12） |  |
| **日数** | 农历日数（初一=1，廿三=23） |  |
| **时数** | 十二时辰序数（子1…亥12） | 23:00 后按次日子时算 |

#### 完整演算：观梅占

> **原文**：辰年十二月十七日申时，二雀争枝坠地。

```latex
上卦 = 5（辰）+ 12（十二月）+ 17（十七日）= 34
       34 ÷ 8 = 4 余 2 → 2 = 兑，【上卦】
下卦 = 34 + 9（申时）= 43
       43 ÷ 8 = 5 余 3 → 3 = 离，【下卦】
动爻 = 43 ÷ 6 = 7 余 1 → 【初爻动】
成卦 = 上兑下离 = 泽火革，初爻动

```

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 上卦 | 5 + 12 + 17 = 34；34 ÷ 8 = 4 余 **2** | 2 = **兑**，上卦 |
| 下卦 | 34 + 9（申时）= 43；43 ÷ 8 = 5 余 **3** | 3 = **离**，下卦 |
| 动爻 | 43 ÷ 6 = 7 余 **1** | **初爻动** |
| 成卦 | 上兑下离 = **泽火革**，初爻动 |  |

**练习**：把自己的农历生日（年月日时）起一卦，全程手算。再按 `4_1` 检查余 0 处理是否正确。

### 4_3 数字起卦法（最常用、最灵活）

适合：对方报数、手机号、门牌号、订单号、页码、随机想到的数。

#### 三种情形

| 情形 | 上卦 | 下卦 | 动爻 |
| --- | --- | --- | --- |
| **报两个数** | 第一数 ÷ 8 取余 | 第二数 ÷ 8 取余 | （两数之和）÷ 6 取余 |
| **报三个数** | 第一数 ÷ 8 取余 | 第二数 ÷ 8 取余 | 第三数 ÷ 6 取余 |
| **多位数**（如 13812345678） | 前后对半拆，前半各位数之和 ÷ 8 取余 | 后半各位数之和 ÷ 8 取余 | 全部各位数之和 ÷ 6 取余 |

> **注意**：报三个数时，第三个数若大于 8，是先除以 8 取余再除以 6 吗？——**不是**。第三个数直接 ÷ 6 取余即可，因为它只用于定动爻。

#### 演算示例

**例 1（报两个数）**：报 23、17

```latex
上卦：23 ÷ 8 = 2 余 7 → 艮
下卦：17 ÷ 8 = 2 余 1 → 乾
动爻：（23+17）= 40；40 ÷ 6 = 6 余 4 → 四爻动
成卦：山天大畜，四爻动

```

**例 2（多位数）**：手机号后八位 87654321

```latex
前半 8765 → 8+7+6+5 = 26；26 ÷ 8 = 3 余 2 → 兑（上卦）
后半 4321 → 4+3+2+1 = 10；10 ÷ 8 = 1 余 2 → 兑（下卦）
全数：26+10 = 36；36 ÷ 6 = 6 余 0 → 余 0 取 6，上爻动
成卦：兑为泽（比和卦），上爻动

```

此例正好演示了"余 0 取 6"的规则。若误判为"无动爻"，整个断法就错了。

### 4_4 物象方位起卦法（后天端法·最见功力）

**这是最能体现"万物皆可占"的一法**：不用求测者任何配合，**见物即占**。

#### 固定公式

```latex
上卦 = 所见事物（或人物）对应的卦
下卦 = 该事物所处的方位卦（后天八卦方位）
动爻 =（上卦数 + 下卦数 + 时辰数）÷ 6，取余数

```

> **注意**：此法**必须加时辰数**（与纯数字起卦不同），因为"象"本身不带时间信息，靠时辰把卦锚定在当下。

#### 演算示例

**例**：午时，见一只鸡在正南方鸣叫。

```latex
鸡 → 巽（5）→ 上卦
正南方 → 离（3）→ 下卦
动爻：5 + 3 + 7（午时）= 15；15 ÷ 6 = 2 余 3 → 三爻动
成卦：火风鼎，三爻动

```

#### 人物起卦对照（端法中最常用）

| 人物 | 归卦 | 依据 |
| --- | --- | --- |
| 老年男性 | 乾 | 乾为父、为老 |
| 老年女性 | 坤 | 坤为母、为老妇 |
| 中年男性 | 坎 | 坎为中男 |
| 中年女性 | 离 | 离为中女 |
| 青年男性（长男） | 震 | 震为长男 |
| 青年女性（长女） | 巽 | 巽为长女 |
| 少年男性 | 艮 | 艮为少男 |
| 少女 | 兑 | 兑为少女 |

**口诀**：乾父坤母、震长男、巽长女、坎中男、离中女、艮少男、兑少女。

> **观人起卦的关键**：不只看年龄性别，还要看**气色与举止**——老人有忧色（异常）才值得占；少年有喜色（异常）才值得占。**异常才是"机"。**

### 4_5 声音、文字、丈尺起卦法

#### 声音起卦

```latex
上卦 = 声音次数 ÷ 8 取余
下卦 =（声音次数 + 时辰数）÷ 8 取余
动爻 =（声音次数 + 时辰数）÷ 6 取余

```

适用：叩门声、鸟鸣次数、车鸣笛、器物撞击声。

**例**：申时闻犬吠 7 声 → 上卦艮（7）、下卦坤（16÷8 余 0 取 8）、四爻动 → 山地剥。

> **要点**：**突发异响为重兆，常态环境音不算。** 车流声、空调声是背景，不构成"机"。
>
> **注**：此处时辰数是"参与构成下卦"的原料，而非外加取爻项，所以声音占仍属**先天起卦法**（细则见 `4_6`）。

#### 文字起卦（拆字）

| 字数 | 上卦 | 下卦 | 动爻 |
| --- | --- | --- | --- |
| **一字** | 左右或上下拆，左（上）半 | 右（下）半 | 总笔画 ÷ 6 取余 |
| **两字** | 前字笔画 ÷ 8 | 后字笔画 ÷ 8 | 两字总笔画 ÷ 6 |
| **三字** | 第一字笔画 ÷ 8 | 后两字笔画和 ÷ 8 | 三字总笔画 ÷ 6 |
| **四字以上** | **不必数画数**，只以平仄声音调之：平声 1、上声 2、去声 3、入声 4 | 同左 | 四声数之和 ÷ 6 |
| **独体字（无法拆）** | 总笔画一半 ÷ 8 | 总笔画一半 ÷ 8 | 总笔画 ÷ 6 |

**四声取数法**：平声 1、上声 2、去声 3、入声 4。

> **原文校准**：《梅花易数·字占》明言「**又四字以上，不必数画数，只以平仄声音调之**」。
> 本库此前记"四字以上按字数平分求笔画和"，与原文相反，现据原典改正。
> 今普通话无入声，实操可用"阴平阳平归平声、上声、去声"三类处理，并在起课纸上写明所采口径。

#### 丈尺起卦

+ 丈数 → 上卦；尺数 → 下卦
+ 动爻：（丈数 + 尺数）÷ 6 取余
+ **寸数不用**

> **原文校准**：《梅花易数·丈尺占》原文为「丈尺之物，以丈数为上卦，尺数为下卦。
> 合丈尺之数取爻。**寸数不用。**」本库此前另列"尺数为上卦、寸数为下卦"一式，
> 与原文"寸数不用"冲突，现据原典删除该式。

> 现代可用厘米数折算，但要**先定单位口径**（如"米为丈、分米为尺"），一次一法，不可中途更换。

### 4_6 先天起卦与后天起卦：两套体系，四条硬区别

前面 `4_2` 至 `4_5` 讲了五种具体起卦法。但原书真正的分类只有**两大类**：**先天起卦法**（先得数，后起卦）与**后天起卦法**（先得象，后起卦）。

这个区分不是学术分类游戏——**它直接决定三件事：动爻要不要加时辰、断卦要不要看爻辞、应期怎么定**。搞错这一步，后面全错。

#### 一张表看清全部区别

| 维度 | **先天起卦法**（先得数） | **后天起卦法**（先得象） |
| --- | --- | --- |
| **逻辑** | 数 → 卦。由可量化的信息算出卦 | 象 → 卦。由当下所见的人、物、方位直接对应成卦 |
| **包含方法** | 时间起卦、数字起卦、声音起卦、文字拆字 | 物象方位起卦（端法）、人物占、颜色占、动静物占 |
| **取动爻** | **不额外加时辰数**。用起卦过程已有的总数 ÷ 6 取余 | **必须额外加时辰数**：（上卦数 + 下卦数 + 时辰数）÷ 6 取余 |
| **断卦依据** | 主要看**体用生克比合**，不常看爻辞 | **体用生克 + 爻辞卦辞**并用 |
| **定应期** | 主要看**卦气旺衰**（如乾兑应庚辛日、申酉日；震巽应甲乙日、寅卯日） | 主要看**卦数加时数**，再结合**行、立、坐、卧**定快慢 |
| **适用场景** | 时间敏感、有明确求测目标、远程占（网络报数、字数占） | 环境复杂、无明确指向、突发场景（有人来访未说明来意、见两狗相斗） |
| **难度** | 流程固定、规则标准，**对初学者友好** | 需要精通万物类象 + 社会阅历 + 观察力，**难精** |

#### 四条硬区别的记忆法

```latex
第1步 先天"数在前"，后天"象在前"
第2步 先天取爻不加时，后天取爻必加时
第3步 先天重卦气定应期，后天重卦数定时
第4步 先天多不看爻辞，后天要参爻辞

```

#### 一处容易混淆的细则：声音占、字占到底加不加时辰？

原书体例里，**声音占**是："声数为上卦，声数 + 时辰数为下卦，总数 ÷ 6 取动爻"——看起来"加了时辰"，但它与端法有本质区别：

|  | 声音占（先天） | 端法（后天） |
| --- | --- | --- |
| **时辰加在哪** | 加在**下卦**上（声数 + 时数） | 加在**动爻**上（上 + 下 + 时） |
| **总数性质** | 时辰是"原料之一"，参与构成卦 | 时辰是"外加项"，只用于定爻 |
| **判断口诀** | 时辰**参与成卦** → 先天 | 时辰**只用于取爻** → 后天 |

> **判断心法**：看时辰数是"参与构成卦体"还是"外加来定爻"。**参与成卦的（时间法、声音占）属先天；外加取爻的（端法、人物占、颜色占）属后天。**

若实在分不清，就记住一条实用的：**动爻总数里若额外多出一个"时辰数"，就是后天法。**

> **一句话**：**先天为体，后天为用。** 先天数是骨架（不变的法则），后天位是应用（万变的呈现）——这与"起卦用先天数、方位看后天位"是同一条原则的两个侧面。

#### 实操抉择：什么时候用哪种？

| 情况 | 选择 | 理由 |
| --- | --- | --- |
| 对方报了数 / 我看到一个现成数字 | **先天** | 数已经在那儿了，不必再找象 |
| 我注意到"就是此刻"这件事有意义 | **先天（时间法）** | 时间本身就是数 |
| 网上有人发来一句话、一个词 | **先天（字数/笔画）** | 远程，无法取象 |
| 我正看着一个人或物从某方向来 | **后天（端法）** | 象已经撞进来了，最贴近当下之机 |
| 突然一声异响、一个突发场景 | **后天** | 这是"机"最鲜活的形式 |
| 完全没头绪、只是心动 | **先天（时间法）** | 先天法不受时空限制，最稳 |

**练习**：把 `4_2` 至 `4_5` 的五种方法，逐个标注"先天 / 后天"，并说明取动爻时加不加时辰。

### 4_7 起卦法决策树：什么场景用哪种

面对一个具体的"机"，按下面这棵树选方法，**选定后不再更换**。

```latex
【起点】是否有一个明确的"异常触发"？
   │
   ├─ 否 → 不起卦（不动不占）
   │
   └─ 是 → 触发的形式是什么？
             │
             ├─ 我注意到"此刻的时间"本身有意义
             │    （如：某事恰好发生在此刻）→ 【时间起卦法】
             │
             ├─ 对方报数 / 我看到一个数字 / 有个现成号码
             │    → 【数字起卦法】
             │
             ├─ 我看到一个人或物从某个方向来，或停在某方位
             │    → 【物象方位起卦法】（最常用，最灵活）
             │
             ├─ 触发是"声音"（敲门、鸟鸣、器物响）
             │    → 【声音起卦法】
             │
             ├─ 触发是"文字"（一个字、一句话、一个招牌）
             │    → 【文字起卦法】
             │
             └─ 触发是"尺寸"（问器物大小、远近）
                  → 【丈尺起卦法】

```

#### 选择的三条经验法则

1. **有什么用什么**——触发以什么形式出现，就用对应的方法。见老人自东南来，就用端法，不要改成时间起卦。
2. **一事一法，不混用**——同一卦内不叠加两种取数逻辑（如物象法算完又用时间法校验，等于起了两卦）。
3. **先天数与后天位的分工**——**起卦一律用先天数，方位一律看后天位**。这是硬约束。

### 4_8 起卦三条铁律与六类常见错误

#### 三条铁律（贯穿全部实操）

| 铁律 | 实操含义 |
| --- | --- |
| **不动不占，不因事不占** | 没有异常触发不起卦。观梅占的正当前提是"二雀争枝坠地，怪也"——先有异常，后有占问 |
| **取当下第一念，不反复换法** | 数一出来卦就立住。犹豫、换方法、重算，卦气必乱。同一问题再占，最短间隔 7 天 |
| **一人一卦；同场多人须加变量区分** | 多人同占，嵌入姓氏笔画、方位、服色、声数，让卦分途 |

#### 六类常见错误（起卦环节）

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **1** | **年份用公历数字**（如年份直接 ÷ 8） | 上卦全错 | 只用农历**地支序数**：子1…亥12 |
| **2** | **余 0 当 0 或无卦** | 下卦/动爻全错，**且自查发现不了** | 求卦余 0 → 取 **8（坤）**；求爻余 0 → 取 **6（上爻动）** |
| **3** | **动爻用上下卦数之和直接当** | 动爻错 | 动爻 = 第三个数 ÷ 6 取余；无第三数则用两数之和或加时辰数 |
| **4** | **端法起卦忘加时辰数** | 动爻错 | 先得象（端法）→ **必须**加时辰；先得数（数字法）→ 不加 |
| **5** | **起卦后反复重算** | 卦气杂乱，失去参考价值 | 一事不二占；同问题至少间隔 **7 天** |
| **6** | **用先天数断方位 / 用后天位起卦** | 方位全错 | 起卦用**先天数**；方位看**后天位** |

> **小故事·两个数字之差**

有个自学者练了三个月，总觉得自己的卦"偶尔准、经常不搭调"。他怀疑是自己类象不够熟，于是又去背了一大堆万物类象，情况却没改善。
后来一位前辈只问了他一句："你时间起卦，年份取的是几？"
他答："就取年份数字啊。"
问题就在这里。时间起卦的**年数必须用农历地支序数**（子1、丑2，一直排到亥12），不是年份本身的数字。他一直用后者，算出来的上卦几乎次次都偏。
他回去把近三个月的卦全部按正确取法重算了一遍，发现**有近一半的卦，上卦根本不是当初那个卦**。
最可怕的是：这三个月里，他从来没觉得"算错了"。因为用错误的数字照样能除出余数、照样能配出卦、照样能讲出一套道理。
**这类错误不会报错。** 两个体系都自洽，都能得出"答案"，只是其中一个是假的。所以每次起卦后，请务必逐条过一遍上面的六类错误清单——这 30 秒，比多背三百个类象管用。

---
#### 案例小故事：先写一句话，再报两个数

一人来问事，随手报了两个数起卦。卦象出来后怎么读都不顺，一会儿像成，一会儿像不成。

起卦的人问他：你刚才心里想的那件事，能写成一句完整的话吗？他憋了半天，说其实想的是另一件——嘴上问的是工作，心里动念的是家里那笔钱。

于是让他把真正的问题写成一句话，重新报数起卦。这一次卦象立刻清晰了：体用关系、互卦指向都对得上他描述的情境。

**落点**：起卦的前提是"机"——机是**真正动念的那一瞬**，不是随手报出的数字。心口不一，卦一定别扭。

### 5_1 排本卦、互卦、变卦

#### 本卦

起出的原卦，六个爻。代表事情**起始、当下状态**。

#### 互卦（关键，八成新手会取错）

```latex
下互卦 = 本卦的 2、3、4 爻
上互卦 = 本卦的 3、4、5 爻

```

即：**去掉初爻和上爻**，中间四爻"剥"出两个三爻卦——下面三个（234）成下互，上面三个（345）成上互。

> **记忆法**：互卦是本卦"剥出来的内核"，掐头去尾，中间的四个爻两两共用第 3、4 爻。

#### 变卦

动爻的阴阳互换后得到的新卦。代表**最终结果、趋势走向**。

> **前提提醒**：取互卦、变卦都要逐爻推演，而八卦符号**一律从下往上数**（乾☰阳阳阳、坤☷阴阴阴，其余六卦见 `2_1`）。最易记反的两对是兑☱（阳阳阴）与巽☴（阴阳阳）、震☳（阳阴阴）与艮☶（阴阴阳）。

#### 演算示例：泽火革，初爻动（即观梅占，务必手推一遍）

```latex
本卦 泽火革 = 上卦兑☱（九四阳、九五阳、上六阴）＋ 下卦离☲（初九阳、六二阴、九三阳）
本卦六爻自下而上：阳、阴、阳、阳、阳、阴

【变卦】初爻动 → 初九由阳变阴 → 下卦离☲（阳阴阳）变为 艮☶（阴阴阳）
       → 变卦 = 上兑下艮 = 泽山咸

【互卦】下互 = 2、3、4 爻 = 六二阴、九三阳、九四阳 = 阴阳阳 = ☴ 巽
       上互 = 3、4、5 爻 = 九三阳、九四阳、九五阳 = 阳阳阳 = ☰ 乾
       → 互卦 = 上乾下巽 = 天风姤（即古案所说"互见乾、巽"）

```

> **核对观梅占**：古籍原文正是"互见乾、巽"。巽为股，被乾金、兑金夹克，这才是"伤股"的象源。若误取为"互见乾、兑"，类象链条就断了。
>
> **实操铁律**：取互卦时**先把本卦六爻从下到上逐爻写出来**，再掐头去尾取中间四爻。不要凭符号印象直接跳到结果。

#### 互卦的三条使用规则

1. 互卦代表**中间过程、隐情、暗流**
2. 互卦**不再分体用**——只看它对**体卦**的生克作用
3. 体卦在上卦时，上互为"体互"、下互为"用互"；体卦在下卦时则反过来。**体互最紧，用互次之**

### 5_2 定体用（最关键的一步，错则满盘皆输）

#### 基本口诀

> **"动爻所在便为用，安静之卦体来充。"**

| 动爻位置 | 用卦 | 体卦 |
| --- | --- | --- |
| **1、2、3 爻动** | 下卦 | 上卦 |
| **4、5、6 爻动** | 上卦 | 下卦 |

#### 记忆法

> 动爻在一二三（下卦三爻）→ **下卦动 → 下卦为用**；

动爻在四五六（上卦三爻）→ **上卦动 → 上卦为用**。

**最常见的错误**：以为"上卦永远是体卦"。**错。动爻在哪卦，哪卦就是用。**

起卦后应第一时间确认动爻位置，然后**默念一遍"动爻在某卦，某卦为用"**，确认无误再往下走。

#### 特殊情况处理表

| 情况 | 体用判定 | 出处 |
| --- | --- | --- |
| **静卦（六爻皆不动）** | 自测心事：上卦为体，下卦为用。测他人外物：下卦为体，上卦为用。完全依靠五行生克 + 旺衰 + 外应判断，**不需要动爻** | **后世通行推法** |
| **上下卦皆动**（多爻动） | 问自身：内卦（下卦）为体、外卦（上卦）为用。问他人：外卦为体、内卦为用 | **后世通行推法** |

> **原文校准**：《梅花易数》的「卦以八除／爻以六除」恒得**单一动爻**，
> 原文只说「若一爻动，则看此一爻，是阳爻则变阴爻，阴爻则变阳爻」，
> **未设"静卦"与"多爻动"的条文**。上表两行是后世为处理边缘情况补入的通行推法，
> 可参用，但应记作**补法而非原典**。若严格按原典操作，梅花体系不应出现静卦。

**体用判定的两条优先规则**：

| 情况 | 体用判定 |
| --- | --- |
| **主客关系明确时** | **以主客为准，铁律优先**：我 / 求测者 = 体；彼 / 所问之事 = 用 |
| **代他人占** | 以"所问的那个人"为体，不以自己为体 |

> **静卦的含义**：六爻安静，不是"卦无效"，而是**事情当下格局稳定、短期内不会发生大变动**。这是一个确定的信息，不是没有信息。

> **小故事·一句默念，救回一整卦**

有人问自己这次资格考试能不能过。卦起出来，动爻在第 5 爻，他想当然地把上卦当成了体——上卦被下卦所克，于是他垂头丧气地断："悬，怕是要挂。"
幸好他前一天刚学过一条规矩：**起卦后必须先默念一遍"动爻在某卦，某卦为用"**。他念了一遍，猛然发现：动爻在 5 爻，属于上卦三爻，**上卦才是用**，下卦才是体。
改正之后重断：**体克用**——能成，但要下苦功夫啃，不是轻松过。
应期落在体卦当旺的时日，正好是他备考冲刺能见效的那段时间。他照着那个节奏复习，最后压线通过。
事后他在卦例本上写了一行字：**"卦没错，是我把主客念反了。"**
体用一颠倒，吉凶正好反过来。这一步不费脑子，费的是**愿不愿意多念那三秒钟**。

### 5_3 体用生克五格局（定性）

以**体卦**为中心，看用卦对它的五行作用。

| 关系 | 含义 | 吉凶 | 现实比喻 |
| --- | --- | --- | --- |
| **用生体**（事生我） | 外力相助、顺遂省力 | **有进益之喜** | 贵人主动找上门，推着你走 |
| **体用比和**（同五行） | 同心协力、无阻力 | **百事顺遂** | 同频共振，水到渠成 |
| **体克用**（我克事） | 能成但需费力克服 | **诸事吉**（辛苦成） | 你得亲自上山打虎，打得赢但累 |
| **体生用**（我生事） | 付出、耗神耗财 | **有耗失之患** | 你不断往里贴钱贴时间 |
| **用克体**（事克我） | 阻力大、被压制 | **诸事凶** | 逆水行舟，处处受阻 |

#### 原典原文（《梅花易数·体用总诀》）

> **体克用，诸事吉；用克体，诸事凶。体生用，有耗失之患；用生体，有进益之喜。体用比和，则百事顺遂。**

> **原文校准**：原典只分"吉 / 凶 / 耗失 / 进益 / 顺遂"五义，**未分"大吉／小吉"等级**。
> 本库此前把"体克用"降为"小吉"、"体生用"降为"小凶"，是后世的细化，
> 原典对"体克用"的判词是**「诸事吉」**，不含"小"义。现按原典改正，等级差异另见旺衰定量一节。

#### 一句话总诀

> **生我者吉，克我者凶，我生者耗，我克者劳。**

#### 精简速记版

```latex
生我则顺，我生则虚；
我克稍顺，克我多阻；
比和无事，中正相宜。

```

#### 进阶：紧缓次序（权重排序）

原书明确指出：**用卦最紧，互卦次之，变卦又次之。**

```latex
即时应  ← 用卦（当下直接作用）
中间应  ← 互卦（过程与隐情）
终  应  ← 变卦（最终走向）

```

**看互卦时再分一层**：体互最紧，用互次之。

### 5_4 参旺衰（定量：给吉凶"加权重"）

**生克只定"性质"，旺衰定"轻重"。** 这是从"会断"到"断准"的分水岭。

#### 判断步骤

```latex
第1步 确定起卦时的月令（季节五行）
第2步 查旺衰表，得出体卦的旺相休囚死
第3步 同样查出用卦的旺相休囚死
第4步 按加权对照表加权

```

#### 加权对照表（务必逐条对照）

| 基本关系 | 本为 | 加旺衰后 |
| --- | --- | --- |
| **用生体** | 吉 | 用旺相 → **吉上加吉**；用休囚死 → **虽吉不大**（病弱贵人，心有余力不足） |
| **体生用** | 小凶 | 体旺 → **泄而无大碍**（富翁施舍，散点财）；体衰 → **大凶**（贫病交加再献血） |
| **体克用** | 小吉 | 体旺用衰 → **克之轻松，大吉**；体衰用旺 → **病夫撼山，吉转凶** |
| **用克体** | 凶 | 用旺体衰 → **克力最猛，大凶**；用衰体旺 → **凶中有救** |
| **比和** | 吉 | 体用皆旺 → 顺畅有力；皆衰 → 平淡无成，守成而已 |

#### 时间尺度的选取

| 事之长短 | 看什么 |
| --- | --- |
| 长期事（数年） | 看**年令** |
| 中期事（婚姻、事业，数月） | 看**月令** |
| 当日事（招标、签约、会面） | 看**日令** |
| 一时之事（即刻、一小时） | 看**时令** |

#### 一个必须记住的反例（旺衰可以推翻生克）

冬天有人问病，得**用卦离火、体卦坤土**，火生土，"用生体"看起来是吉。但邵雍断**不吉**——因为**冬月火死，生土无力，如炭火将熄，难暖大地**。后果然病重。

```latex
体 = 坤土，用 = 离火
生克关系：火生土 → 用生体 → 表面"吉"
旺衰校正：冬月 → 火"死" → 生土无力
最终结论：不吉（炭火将熄，难暖大地）

```

> **这就是"论卦不论气，则局于象，昧于时"**——只看卦名生克，不看时令旺衰，是第三大常见盲区。

### 5_5 看互变：过程、结局与通关救应

#### 互卦：看中段

+ 互卦中**有生体之卦** → 中途有人暗中相助
+ 互卦中**有克体之卦** → 中途有暗阻、隐忧
+ **体互最紧，用互次之**

#### 变卦：看结局

+ 变卦**生体、比和** → 终吉
+ 变卦**克体** → 末后有不吉
+ 本卦吉但变卦克体 → **先好后坏**
+ 本卦一般但变卦生体或比和 → **坚持可好转**

#### 通关救应

**体用相克时，立刻看互卦：互中若出现通关五行，凶局有解。**

**实例**：体乾金，用离火（火克金，本凶）。若互卦见坤或艮土，则火生土、土生金，转克为生，**凶中有救**。

这正是观梅占"**伤股而不至于死**"的精确分寸所在。

> **小故事·克我的那个人，其实是来帮我的**

有人问一个重要合作能不能谈成，卦上是"用克体"——按表一查，阻力大、被压制，看着就不妙。他当场脸就白了，以为这事要黄。
带他复盘的人没有急着下结论，而是按规矩往互卦里看了一眼：**互卦里出现了一个土**。
用卦是火，体卦是金。火克金，本来是死局。但火生土、土生金——这"一土"夹在中间，把克局接成了生局。
于是断语改了：**有阻力，但阻力会被中途一个环节化解，最终能成，只是过程绕。**
后来的实情是：对方的法务部门（那道"火"）确实把方案打回来两次，但最终是对方一位中间协调人（那道"土"）出面，把条款重拟了一遍，合同签了下来。
他事后感慨："那道'火'是真的，那道'土'也是真的。要是我只看第一眼就放弃，这笔合作就真的黄了。"
**体用相克，先别急着判死刑——看一眼互卦有没有通关。这一眼，往往就是"凶"和"凶中有救"的分界线。**

#### 生克链的"真"与"假"

同样要看量级：

| 情况 | 判断 |
| --- | --- |
| 秋天兑金克震木（金旺木死） | **真克**，凶性实 |
| 春天兑金克震木（木旺金囚） | **假克**，克不动，小波折而已 |
| 体卦旺相遇克 | 有惊无险 |
| 体卦休囚遇克 | 真凶险 |

### 5_6 看爻位：动爻落在哪一层

前面四节解决了"吉凶如何、轻重如何、过程如何"。但还有三个问题没答：**这事发生在哪？跟谁有关？发展到哪一步了？**——答案在**爻位**里。

爻位就是给卦里六个角色排的"座位表"。**六爻中，下卦（内卦）是一二三爻，上卦（外卦）是四五六爻**，自下而上对应三个维度：

| 爻位 | 空间 / 身体 | 人物 / 身份 | 事情的发展阶段 |
| --- | --- | --- | --- |
| **初爻** | 地基、脚下、本地、农村、足部 | 百姓、平民、小孩、新入职员工、子孙 | **萌芽期**：刚开始、还在酝酿、力量微弱 |
| **二爻** | 宅内、厨房、腿膝、乡镇 | 乡绅、科级或处级、家中主妇（宅主） | **发展期**：崭露头角，开始行动 |
| **三爻** | 门口、床边、大腿腰腹、县市级 | 县市主官、中层干部、兄弟（竞争之位） | **转折 / 瓶颈期**："三多凶"，进退两难 |
| **四爻** | 大门外、胸腹、省城、外地 | 大臣、高管、副总、近君之臣 | **扩张期**：进入新环境，伴君如伴虎 |
| **五爻** | 路上、道路、颈面、京城 | 君王、老板、一把手、顶梁柱 | **鼎盛期**："五多功"，最辉煌阶段 |
| **上爻** | 屋顶、远处、边疆、海外、头部 | 退休老领导、顾问、祖先、宗庙 | **衰退 / 结束期**：物极必反，该收尾了 |

#### 动爻断事诀（可直接背）

```latex
一爻初动势初起，根基未固莫强行。
二爻微动局势明，稳步开展路方平。
三爻多阻生反复，中途停滞事难舒。
四爻迁变离本位，改弦易辙方有为。
五爻主事临尊位，大势已成扬美誉。
六爻终动势收官，功成身退避盈亏。

```

#### 三条实战用法

| 场景 | 看法 |
| --- | --- |
| **测升职** | 动爻在**五爻**且生克吉利 → 老板（五爻）看重你，事可成 |
| **测阻力来源** | 动爻在**三爻**且克体 → 直接上司或平级同事在使绊子 |
| **测阶段** | 动爻在**上爻** → 一个阶段已到尽头，该总结、该退场、该换路（不一定是坏结果，但一定是"到这里了"） |

> **与体用的关系**：爻位**不改变**体用生克定下的吉凶，它只回答"**在哪、跟谁、到了哪一步**"。先定性，再用爻位细化，顺序不能颠倒。

### 5_7 卦象直读：一针见血的捷径

有些卦一出来就能直接读出答案，**连体用旺衰都不用排**。这不是玄，是三条固定的直读路径。

#### 路径一：把组合卦整体类比某个经卦（大象）

| 组合卦 | 直读成 | 理由 |
| --- | --- | --- |
| 雷山小过 | **大坎** | 中间两个阳爻被上下阴爻包围，像"阳陷阴中" |
| 山雷颐 | **大离** | 外实中空，像离之"外刚内虚" |
| 地泽临 | **大兑** | 上坤下兑，泽在地上，开口之象放大 |
| 风泽中孚 | **大离** | 中空之象 |

#### 路径二：把组合卦类比某个常见物体

+ **火风鼎**：卦形就像古代的鼎
+ **风地观 / 山地剥**：像山洞、桥洞、门洞
+ **山火贲**：山下有火，像被照亮、被装饰的外表，引申为"文饰、包装"

#### 路径三：以卦意叠加类比事物（用得最多）

| 组合 | 直读 | 拆解 |
| --- | --- | --- |
| 泽天夬 | **缺钱** | 兑为缺 + 乾为钱 |
| 雷火丰 | **文书动** | 震为动 + 离为文书 |
| 泽火革 | **喝红酒** | 兑为喝 + 离为红 |
| 泽火革 | **烧鸡 / 火锅** | 兑为鸡、为锅 + 离为火 |
| 天山遁 | **手脚有伤 / 出走** | 乾为骨、艮为手、遁为逃 |

> **一个主卦能读出多层细节**：问午饭得"泽火革"，可依次直读出"喝红酒""吃烧鸡""吃火锅"——三层都成立，因为兑（喝/鸡/锅）与离（红/火）的组合本就有多种合理叠加。

#### 两条使用注意

1. **不要刻意追求直读**。有些卦可以直读，有些必须回到体用套路。**能直读就用，读不出就老实排体用。**
2. **先入为主**。同一卦能直读出许多象，**第一个冒出来的那个最接近真相**——这与外应的"第一念"是同一条心法。

### 5_8 错卦与综卦：换角度看问题（备用视角）

当本卦信息模糊、指向不明时，还有两个备用视角可用。**它们不占独立的吉凶层级，只是"换个角度看同一件事"。**

#### 定义

|  | **错卦**（对卦、旁通卦） | **综卦**（覆卦、反卦） |
| --- | --- | --- |
| **做法** | 六爻**全部阴阳互换** | 整个卦**旋转 180 度**（上下颠倒） |
| **例** | 乾↔坤、坎↔离、雷风恒↔风雷益 | 屯↔蒙、姤↔夬、雷山小过↔风泽中孚 |
| **含义** | 站在**对立面**看这件事（对方怎么想、反面是什么） | 把事情**倒过来看**（换位、时序反转） |

#### 用法

正断不明时，起一个错卦看"**对方的立场**"，起一个综卦看"**如果我是对面会怎样**"。

> **重要边界**：二者是辅助视角，**不改变本卦体用定下的吉凶**。它们是"换个角度想问题"的工具，不是第二个结论来源。

### 5_9 断卦主干七步与优先级

#### 主干七步（实操必背流水线）

```latex
第1步 排本互变 → 第2步 参爻辞（原典断吉凶之首）
→ 3. 定体用 → 第4步 断生克（定性主干）
→ 5. 参卦气旺衰（定量）→ 6. 看互变（过程与结局）
→ 7. 取类象（落到人事）→ 8. 参克应（外应）→ 9. 定应期

备用视角（非《梅花易数》原文，借自六爻与易学旁支）：爻位 / 卦象直读 / 错卦综卦

```

#### 断卦优先级（冲突时以此为准）

```latex
第1步 参爻辞 → 第2步 体用生克 → 第3步 卦气旺衰
→ 4. 互变（过程与结局）→ 5. 万物类象 → 6. 克应（外应）→ 7. 应期

备用视角（不占层级）：爻位 / 卦象直读 / 错卦综卦

```

> **体例说明（原文校准）**：《梅花易数·占卜总诀》原文为「成卦之后**先看《周易》爻辞，以断吉凶**。**次**看卦之体用，以论五行生克。**又次**看克应——如闻吉说、见吉兆则吉，闻凶说、见凶兆则凶；见圆物事易成，见缺物事终毁之类——**必须以易卦为主，克应次之**」。本库此前把爻辞置于最末，与原典相反，现按原典改正。

> **关于"爻位""错卦""综卦"**：《梅花易数》全书未设此三法（原书无"爻位""错卦""综卦"条目）。
> 它们出自六爻体系（如《易隐》的"鬼谷分爻""黄金策分爻"）与一般易学。**可作为旁参，但不入原典层级**；
> 用时须自记"此为旁参"，不要与原典七步混为一谈。

> **最常见的顺序错误**：先看爻辞，后看体用。爻辞只补细节，**永远不要让它盖过体用生克**。

#### 走一遍完整例子

**问自身健康，得「风火家人」三爻动**：

```latex
第1步 三爻在下卦 → 下卦离为用，上卦巽为体 → 体巽木、用离火
第2步 离火泄巽木 → 体生用，小凶（自身精气被耗）
第3步 再参月令：若占于秋（金旺木死），体卦巽木正处"死"地，凶性加重
第4步 结论：需重点调养肝胆（巽为股胆）

```

#### 案例小故事：骨架对了，还得看有没有力气

一人断卦：体克用，按"体克用诸事吉"断了"能成、很快"。结果事情拖了半年才落。

复盘时发现问题不在体用，在他跳过了卦气旺衰：当时体卦正值衰令，克是克，但**克不动**。

**落点**：体用是骨架，旺衰是力气。判完生克必须追一句：**这个克，克不克得动？**

## 板块6 · 应期：事情什么时候发生

> **这是梅花易数公认最难、也最考验功力的一环。**

原则是：先按方法算出基数，再用"常理"校正。

---

### 6_1 成卦之数法（最基础）

"成卦之数"就是起卦过程中那个**总算数**。但古案里实际存在**两种口径**，混用必然算错——必须先分清。

#### 口径 A：卦数 + 时辰数（用于端法 / 后天起卦）

```latex
成卦之数 = 上卦先天数 + 下卦先天数 + 时辰数

```

| 古案 | 上卦数 | 下卦数 | 时辰数 | 成卦之数 | 断应期 |
| --- | --- | --- | --- | --- | --- |
| **老人有忧色占** | 乾 1 | 巽 5 | 卯 4 | **10** | 行则减半 → 5 日（果验） |
| **少年有喜色占** | 艮 7 | 离 3 | 午 7 | **17** | 取全数 → 17 日内（果验） |

#### 口径 B：年月日时总和（用于时间起卦 / 先天起卦）

```latex
成卦之数 = 年数 + 月数 + 日数 + 时辰数

```

| 古案 | 计算 | 成卦之数 | 断应期 |
| --- | --- | --- | --- |
| **观梅占** | 辰 5 + 12 + 17 + 申 9 | **43** | 按数该 43 日，但**花期只有朝夕 → 变通**为次日 |
| **牡丹占** | 巳 6 + 3 + 16 + 卯 4 | **29** | 同理变通，改取**变卦离 → 午时** |

> **两个口径给出的数完全不同**：观梅占按口径 A 是 2+3+9=**14**，按口径 B 是 **43**。这不是矛盾，而是**起卦法不同，基数就不同**。

**规则**：你用哪种方法起的卦，就用哪个口径的基数。端法用 A，时间法用 B，**绝不混用**。

#### 另两个补充基数（特定场景）

| 基数 | 用法 |
| --- | --- |
| **上卦数 + 下卦数 + 动爻数** | 常用于占病、占器物（本互变全数） |
| **本卦 + 互卦 + 变卦的卦数之和** | 测长期事、大病时取"全数" |

> **无论用哪种，都要在卦例本里注明口径**——否则三个月后你根本无法复盘自己当初是怎么算的。

---

### 6_2 动静决迟速（最实用）

原书反复强调：**吉凶悔吝，生乎动者也。** 占者自身的状态直接影响应期快慢。

#### 系数表

| 占者状态 | 系数 | 含义 |
| --- | --- | --- |
| **行 / 走**（动） | 成卦之数 **÷ 2** | 应验快 |
| **立**（半动半静） | 成卦之数 **× 1**（直接用） | 不迟不速 |
| **坐**（静） | 成卦之数 **× 2** | 应验慢 |
| **卧**（极静） | 成卦之数 **× 3 或更多** | 愈迟 |

#### 古案校验

**老人有忧色占**：成卦之数 10，占者"**在途行**"（行走）→ 10 ÷ 2 = **5** → 断"五日内"。果五日应验。

**少年有喜色占**：成卦之数 17，按"**立**"或"行"的变通处理 → 取全数 **17** → 断"十七日内"。果如期定亲。

#### 卦内动静（补充维度）

+ **内卦动静**：体卦、互卦为**静**；用卦、变卦为**动**
+ **外卦动静**：天时地理之应为**静**；人事、器物为**动**
+ **动则应速，静则应迟**；动而吉者应吉速，动而凶者应凶速

---

### 6_3 卦气当令法（最核心）

**这是逻辑最硬的一条**：事情会在"推动它的那股力量最旺的时候"发生。

#### 吉事（生体）——应期在"生体之卦"当令之时

```latex
第1步 找出哪个卦生扶体卦
第2步 看它属什么五行
第3步 该五行当令的月 / 日 / 时，就是吉应之期

```

**例**：体卦乾（金），用卦坤（土），坤土生乾金 → 吉。应期大概率在**属土**的时日：**辰、戌、丑、未**的年月日时（土当令）。

#### 凶事（克体）——应期在"克体之卦"当令之时

**例**：体卦震（木），用卦兑（金），兑金克震木 → 凶。应期大概率在**属金**的时日：**申、酉**的年月日时（金当令），此时金气最盛，克木最猛。

#### 各生克关系的应期取向

| 关系 | 应期取向 |
| --- | --- |
| **用生体** | 生体之五行当旺之时，或体卦当旺之时 |
| **体克用** | 体卦当旺之时（能克动），或用卦当旺之时（得财/得物） |
| **用克体** | 用卦当旺之时（灾至）；若体卦得救，则在**生体之五行**当旺之时 |
| **体生用** | 体卦当旺之时（有气可泄），或用卦当旺之时（泄尽） |
| **比和** | 本卦五行当旺之时 |

### 6_5 五种补充定应期法

#### 方法一：卦数定应期（简版）

用卦的先天数直接当日或月：

+ 卦气**旺相** → 应期较快，应 1、2、3 等**小数**
+ 卦气**休囚** → 应期较慢，应 10、20、30 等**大数**，或 1、2、3 月/年

**例**：用卦震（4）、体卦坎（6）。事急 → 应 4 日或 6 日；事缓 → 应 4 月或 6 月。

#### 方法二：动爻定应期

动爻数直接当日或时数。三爻动 → 应 3 日或 3 时。

#### 方法三：外应定应期

外应出现的时间或性质即应期。

**例**：起卦时见群鸟飞归 → 应**酉时**（鸟归巢之时）。

#### 方法四：冲合定应期（进阶）

| 情形 | 应期 |
| --- | --- |
| **逢合待冲** | 用神被合住 → 事情拖延 → 应期在**冲开**之日或月（如子丑合，午日冲子、未日冲丑） |
| **逢冲待合** | 用神被冲散 → 事情不稳 → 应期在**合住**之日或月（如子午冲，丑日合子、未日合午） |
| **入墓待冲** | 用神入墓（如木入未墓）→ 应期在**冲墓**之日（丑日冲未） |
| **旬空待填** | 用神旬空 → 应期在**出空（填实）或冲空**之日 |

> 此法需要干支基础，属进阶内容。初学可跳过，待地支六合六冲熟悉后再用。

#### 方法五：生体之卦的位置定快慢

+ 生体之卦在**用卦** → 事**即成**
+ 生体之卦在**互卦** → 事**渐成**
+ 生体之卦在**变卦** → 事**稍迟**

### 6_6 事物属性与应期单位换算（常被忽略的干货）

同一个数字，用在不同的事上，单位完全不同。**这是"推数必须推理"在应期上的体现。**

#### 按事物材质与性质换算

| 事物类型 | 成卦之数的单位 | 例（成卦之数 30） |
| --- | --- | --- |
| **金石材质**（耐久） | 以**年**计 | 30 年 |
| **草木材质**（有生命周期） | 以**月**计 | 30 月 |
| **纸质 / 易损之物** | 以**日或时**计 | 30 日或 30 时 |

#### 按事之大小换算

| 事 | 单位 |
| --- | --- |
| 非常之事（婚姻、置业、迁居） | 年 / 月 |
| 平常之事（器物、疾病、失物） | 月 / 日 |
| 一时之事（会见、消息、当日结果） | 日 / 时 |

#### 原书的"变通"警告

原书在讲完动静之法后，立刻加了一句极重要的补充：

> **"虽然如是，又在变通。如占牡丹及观梅之类，则二日花皆朝夕之故，岂特成数之久也。"**

**意思**：观梅占成卦之数 43，即便按"行则减半"也有 21 日；但梅花花期只有朝夕之短，花根本等不到那一天。所以邵雍断为**次日**。

```latex
成卦之数 = 43
行则减半 = 21 日
但：梅花花期只有朝夕 → 花等不到 21 日
变通 → 断"次日"

```

> **这是全书最该记住的一条应期原则**：**数算出来的是"参考基数"，最后必须用常理校正。物性、事理、人情，永远优先于数字。**

> **小故事·等不到的二十一天后**

观梅占的成卦之数是 43。有位初学者严格照搬公式：占者当时在园中行走，按"行则减半"，43 ÷ 2 ≈ 21，于是他郑重其事地断"二十一天后，会有女子来折花"。
结果**第二天晚上事情就发生了**——邻家女来折梅，被园丁追赶，失足跌伤了右大腿。
如果他还守着"第二十一天"等下去，那他这辈子都等不到，因为**梅花早就谢了**。
原书之所以在这一卦后面紧跟着加一句"虽然如是，又在变通"，正是为了防止后人把数当成死理：花期只有朝夕，事情根本不会按 21 天的节奏发生。
同一个道理也适用于今天：你问"快递哪天到"，卦数算出来三十——但快递不可能三十个月才到，单位只能是"日"或"时"。
**数字是参考基数，不是判决书。物性、事理、人情，永远优先于数字。**

### 6_7 应期冲突时的取舍规则

当不同方法给出不同答案时，按下面的顺序取舍：

```latex
第1步 常理校正   ← 最高优先：物性、事理不允许的答案，直接排除
      ↓
第2步 卦气当令   ← 次高：逻辑最硬，事情在推动力最旺时发生
      ↓
第3步 动静系数   ← 调整快慢：行立坐卧
      ↓
第4步 成卦之数   ← 给出基数
      ↓
第5步 卦数 / 动爻 / 外应  ← 交叉印证或微调

```

#### 三条实操心法

1. **先算后校，绝不先猜后凑**。算出数字后问自己：这件事按常理可能这么久吗？
2. **给区间，不给死数**。断"五日至十日之间"比断"初七"更专业，也更诚实。
3. **记录并回验**。应期是唯一能被明确证伪的环节，也是进步最快的环节。**每次都记，每次都验。**

---
#### 案例小故事：断"三日"却等到第十天

一人断"三日内有消息"，用的是卦数。结果第十天才来消息。他一度以为应期法不准。

复盘发现三处可查：一是他只取卦数，没看当时体卦旺衰（衰则应迟）；二是这件事本身属"公文流程"一类，天生比"口信"慢；三是他把"有消息"和"有结果"混为一谈。

三条交叉后重算：卦数给的是基数，旺衰给的是修正（衰则加倍），事类给的是单位（公文以旬计）。三者合起来，十日并非离谱。

**落点**：应期不是单查一个数，是**卦数 ＋ 旺衰 ＋ 事之缓急**三条交叉。只取其一，必然时有不验。

## 板块7 · 外应心法：三要与十应

> **这一层是全书的"灵魂开关"。**

前几层给你骨架（吉凶方向），心法给你血肉（具体细节与微调）。
**多数人卡在断卦，八成问题出在"地基不牢"和"外应用错"这两头。**

---

### 7_1 外应的本质：是"感"，不是"找"

#### 核心区别

|  | **找** | **感** |
| --- | --- | --- |
| 方向 | 由外向内：眼睛扫描 → 筛选信号 → 套到卦上 | 由内向外：心念清净 → 信号自然呈现 |
| 过程 | 找到一个外应，然后分析它"代表什么" | 它出现的一瞬，本心已经"知道"了 |
| 结果 | 找到的全是"你认为像"的信号，是大脑的逻辑游戏 | 不需要分析，直接是信息 |

> **判断标准**：如果你还需要"分析"这个外应代表什么，说明你根本没"感"到。

#### 外应三阶（自检你在哪一阶）

| 阶次 | 特征 | 问题 |
| --- | --- | --- |
| **第一阶：刻意找** | 起卦后四处张望，寻找异常动静，套口诀强行解读 | 全是主观投射 |
| **第二阶：静待** | 不起身、不张望。起卦后静坐，保持心念清净 | 正确起步 |
| **第三阶：随处是** | 不刻意找也不刻意等，心念至诚后本心与天地无隔 | 高阶 |

> 三阶的本质是**心诚程度的升级**。心有多诚，感应就有多深。

#### 三秒原则（最重要的操作标准）

> **外应是"撞进来的"，不是"找出来的"。三秒内自然注意到的才算，三秒后刻意想的，是你大脑加戏。**

> **小故事·那只"算出来"的乌鸦**

有人起完卦，觉得吉凶难分，就抬头满世界找外应。找了半天，看见窗外树上有只乌鸦，心里一喜：乌鸦主凶，这卦我断凶！
结果事情后来进展得很顺利。
问题出在哪？——那只乌鸦他盯了半分钟才注意到，而且**是他先想断凶、后找乌鸦来印证**。顺序反了。
真正的外应长什么样？是你在起卦那一瞬，**还没来得及想**，耳朵已经听见杯子碎了、眼睛已经瞥见有人摔了一跤。它撞进来，不需要你分析"这代表什么"，你当下就知道它不寻常。
**三秒内自然注意到的，才算。三秒后刻意想的，是你大脑加戏。**

### 7_3 十应：外应的标准化归类

十应是对三要捕捉到的异象做易理分类，**须与本卦体用合参，缺一不可**。

《占卜十应诀》原典十应为：**正应、互应、变应、方应、日应、刻应、外应、天时应、地理应、人事应**。

| # | 原典十应 | 含义 | 与本卦的关系 |
| --- | --- | --- | --- |
| 1 | **正应** | 本卦自身之应 | 体用生克，为断卦主干 |
| 2 | **互应** | 互卦之应 | 事之中间过程 |
| 3 | **变应** | 变卦之应 | 事之最终结局 |
| 4 | **方应** | 方位之应 | 来人方位、坐落方位 |
| 5 | **日应** | 日辰之应 | 当日干支对卦气的作用 |
| 6 | **刻应** | 时刻之应 | 起卦时辰的即时影响 |
| 7 | **外应** | 外来异象之应 | 见闻感触，须与本卦合参 |
| 8 | **天时应** | 天气、四时旺衰 | 天时变则卦气随之 |
| 9 | **地理应** | 环境形势 | 山川城郭、居处场所 |
| 10 | **人事应** | 人事动态 | 旁人行为、言语、身份 |

> **权重总原则（原典口径）**：《占卜总决》明言「**必须以易卦为主，克应次之**」——
> 十应（克应）**永远从属于本卦体用**，不是独立判据，更不是"天时最高"。
> 原典另在《十应目论》列出"外卦十应之目"共**十一类**（天时、地理及写字等），
> 本库原表的人品、言语、声色、文字、器物、草木禽兽等，即出自这十一类之目，
> 属"外应"之下的细分，可参用，但不应与原典十应并列。

#### 原书的一条精微提醒

> 「黄金白银，为世之宝，"三要"得之，必以为祥；"十应"之诀，遇金有不吉者。利刃锐兵，世谓凶器，"三要"得之，亦以为凶；"十应"之说，遇兵刃反有吉者。」

**意思**：同一个东西，在三要里可能是吉，在十应里可能变凶，反之亦然。**这就是"妙乎三要"——不能机械对号入座，必须结合卦体合参。**

### 7_4 真生真克之辨（区分"死断"与"活断"的分水岭）

原书特别提醒：外应生克须分"**真**"与"**形色**"。

> **真火能克金，形色之红紫不能克金；**

**快刀巨斧能克木，钗钏金箔不能克木；**
**真水能克火，黑湿血色之坎属，克力轻。**

#### 对照表

| 情形 | 判断 |
| --- | --- |
| 乾兑为体，遇**炉中火、窑灶烈焰** | **真火** → 真不吉 |
| 乾兑为体，仅见**红紫之色、一盏灯烛** | **形色** → 小不利或不顺而已 |
| 木为体，遇**快刀巨斧** | **真金** → 真克 |
| 木为体，遇**钗钏金箔** | 形色之金 → 克力微弱 |
| 土能生金，但遇**瓦器** | 不能生 |
| **树木柴薪**生火之捷；**未伐之树**生炎之迟 | 同为木，生力相差巨大 |

> **这一条是"死断"与"活断"的分水岭。** 死断者见红即断火克金、见白即断金克木；活断者先问：**这个"金"是真的金还是像金？它有多大的力？**

> **小故事·一盏红灯与一场大火**

两个人问事，卦上都是体卦乾金，都遇到了"火"的外应之象。
第一位：断卦时桌上亮着一盏红色的台灯。红色属火，火克金——但那只是"形色之火"，一盏灯而已。**克力极微，几乎可以忽略**，断语只加一句"有点小不顺"。
第二位：断卦时厨房灶上正开着大火，锅都烧红了。这是**真火**——炉中烈焰，实实在在克金。断语加重：此事有真阻力，须防破财。
**同样是"火克金"，一个是灯，一个是灶，力道天差地别。** 死断者见红就喊"火克金"，活断者先问：这火有多大？

以**所坐之处为中宫**，八方位配八卦，察各方有无生克之兆，定"爻位"吉凶。

                离（正南）·中女·文书
        巽                       坤
   （东南·长女）            （西南·母）
        震                       兑
   （正东·长男）            （正西·少女）
        艮                       乾

### 7_6 外应的三种实战用法

#### 用法一：在卦象吉凶难分时，一锤定音（最核心用途）

**场景**：本卦体用比和、吉凶对半、生克对冲，无法下定论 → **外应是关键裁决依据**。

**例**：占合作，本卦体用比和，吉凶难分；起卦时听见**玻璃杯碎裂**（兑金外应，主口舌破损）→ 断：合作中途闹矛盾、破财散伙。

#### 用法二：微调吉凶程度（区分小吉/大吉、小凶/大凶）

**例**：占求职，本卦用生体，本是吉；但起卦瞬间看见**枯萎树木**（衰木外应，泄气之象）→ 断：能入职，但薪资低、工作压抑，**并非大吉**。

#### 用法三：无起卦，单用三要直断（心易活占）

**场景**：不动纸笔，仅凭当下视听心念直接断事——这是古本观梅占、牡丹占的核心用法。

**例**：有人刚开口问婚姻，门外恰好走过**一对牵手新人** → 目要取喜庆人事应 → 直断：姻缘近期有成。

### 7_7 外应的优先级与四条禁忌

#### 核心原则（永不颠倒）

> **卦象是本体框架，决定材质、大类、本质；**

**三要是瞬间天机，校正气质、动静、完整度；**
**十应是多层筛选，排除错误、锁定细节、收敛答案。**

|  | 正确 | 错误 |
| --- | --- | --- |
| 主次 | **卦定大类，十应定细节；卦定材质，三要定状态** | 看见外应就改卦、抛开卦理硬猜 |
| 关系 | 外应**细化**卦理 | 外应**推翻**卦理 |

> **一句话**：外应不能推翻卦理，只能细化卦理。外应贴合卦象则准，外应冲突则**舍外应从卦理**。

#### 四条禁忌

1. **不刻意制造异象**——主动摔东西、刻意看人、刻意听声，不算真外应
2. **不逐条硬找**——邵雍说的是"**至诚感通，十应皆备**"，心诚了信号自然呈现，不需挨个采集
3. **不过度解读**——一个有效的断卦只需抓住 3—4 个关键信息点：体用生克、互卦变化、变卦结局、最显著的一个外应
4. **不以后脑补**——三秒外的不算；事后回想起来的不算

---
#### 案例小故事：茶杯落地之后，他改了断语

一人替朋友断一桩合同，卦象读到一半卡住了：成与不成，两边证据差不多，正犹豫着要不要含糊过去。

就在这时，邻桌的茶杯被人碰落，摔碎在地。他没有忽略这个——把"破而后立"当作外应加权，改断：合同会先作废，再重签，重签的条件对朋友更有利。

两周后朋友反馈：对方果然推翻了第一版，另起一份，其中的付款条款确实比原来好。

但同一位断者也承认：如果那次卦象本身已经一边倒，他不会用外应去翻盘。

**落点**：外应的用法是**在卦象两可处加权**，不是**代替卦象**。卦象明确时，外应只能作旁证，不能作主证。

## 板块8 · 分类占（上）：通用法则与人事类占断

> 前面所有技术（起卦、断卦、应期、外应）最终都要落到"**具体问的这件事**"上。

分类占就是把吉凶接到具体人事的接口。

---

### 8_1 通用断语公式（所有分类占共用）

> **体为所问之家/人，用为所应之事。**

**用生体 → 进益；体克用 → 可成但迟；用克体 → 不成；体生用 → 有耗；比和 → 称意。**

#### 通用加权规则

| 关系 | 通用断语 | 应期倾向 |
| --- | --- | --- |
| **用生体** | 事易成，有外力相助 | 速（生体之卦当令时） |
| **体克用** | 可成但需努力、有迟滞 | 中（体卦当旺时） |
| **体生用** | 有耗损，费力或少得 | 中偏迟 |
| **用克体** | 不成，或有害 | 凶（克体之卦当令时） |
| **比和** | 顺遂、称意、平稳 | 平（本卦五行当旺时） |

#### 分类占的三步法

```latex
第1步 定体用：谁为体（所问之主体）、谁为用（所问之事）
      ↓
第2步 断生克 + 旺衰：定性 + 定量
      ↓
第3步 嫁类象：把八卦类象接到具体场景上（人、物、方位、时间）

```

> **关键提醒**：三步法中，**第1.步定体用错了，后面全废**。代他人占时，以"所问的那个人"为体，不以自己为体。

### 8_2 天时占（唯一"不分体用"的一类）

**天时占不分体用**，全观诸卦五行：

| 卦多现 | 天象 |
| --- | --- |
| **离**多 | 晴 |
| **坎**多 | 雨 |
| **坤** | 阴晦 |
| **乾** | 晴明 |
| **震**多 | 春雷 |
| **巽**多 | 四时风烈 |
| **艮**多 | 久雨必晴 |
| **兑**多 | 不阴亦雨 |

> **且须结合四时，不可执一理**：

**夏占离多而无坎** → 亢旱
**冬占坎多而无离** → 雨雪

**为什么天时占不分体用？** 因为天的运行不以"我"的意志为转移，没有主体与客体的对立，只看卦气本身的多寡消长。这是全部分类占里唯一的例外，记住它，其余一律分体用。

### 8_3 人事 / 谋望占

+ **体为主、用为宾**
+ **用克体** → 不宜（谋事受阻）
+ **体克用** → 吉（可控，但费力）
+ **用生体** → 有进益
+ **体生用** → 有失耗
+ **比和** → 谋为喜利

#### 类象嫁接要点

| 问什么 | 看什么 |
| --- | --- |
| 事能否成 | 体用生克 + 变卦 |
| 谁在帮我 / 谁在阻我 | 生体之卦的类象 / 克体之卦的类象 |
| 何时成 | 生体之卦当令之时 |
| 有无暗中的变数 | 互卦（体互最紧） |

> **实操心法**：问"谁在帮我/阻我"时，直接看**生体 / 克体之卦的类象**。比如生体之卦为乾 → 贵人是领导、父亲辈、权威人物；克体之卦为兑 → 阻力来自口舌、破损，或者一个能说会道的人。

> **小故事·到底是谁在使绊子**

有人问项目推进不顺，卦上克体的是兑卦。他第一反应："是不是财务那边卡我？"
再看兑的类象：口、口舌、破损、毁折、少女、销售人员。
他忽然想起，上周例会上有个同事当众质疑了他的方案，之后好几个部门就开始观望。
——**阻力不是流程问题，是"口舌"问题**。兑卦已经把加害者的画像画出来了：不是制度，是某张嘴。
后来他找那位同事单独沟通了一次，事情就顺了。
**克体之卦的类象，往往直接指出"阻力源"是谁、是什么形态。**

### 8_4 婚姻 / 感情占

+ **体** = 所占之家（我方）
+ **用** = 所婚之家（对方）

| 关系 | 断语 |
| --- | --- |
| **用生体** | 婚易成（对方主动、对方家庭支持） |
| **体克用** | 可成但迟（需我方推动，周折后成） |
| **用克体** | 不可成 |
| **体生用** | 单方付出，情难久 |
| **比和** | 良配无疑 |

#### 容貌推法（仅作参考，不可执死）

| 卦 | 容貌特征 |
| --- | --- |
| 乾 | 端正而长 |
| 兑 | 高长而白 |
| 离 | 短赤，性情不常 |
| 坤 | 貌丑、大腹而黄 |
| 震 | 高大、声响 |
| 巽 | 身长、发少、额宽 |
| 坎 | 黑、圆脸 |
| 艮 | 矮小、敦实 |

> **提醒**：这是古人经验总结，现代应用须结合具体情境，**绝不可用来评判他人外貌**。

> **小故事·"我很爱他"不等于吉**

一位女士问感情，卦上是"体生用"。她读了解释后很委屈："体生用是不是代表我很爱他？爱得多难道不好吗？"
答案是——**体生用在卦理上是"我不断往外掏"**。它描述的是能量流向，不是感情深浅。
也就是说，这段关系里只有她在持续付出：时间、精力、金钱、情绪。卦上没有一个"生体"的回流。
她沉默了一会儿说："确实，这两年都是我在迁就。"
**爱得多不多，不看生克；关系能不能久，看的是有没有回流。** 一段感情若只有单方面输出，卦已经把答案写在脸上了——体生用，情难久。

---

### 8_5 求名 / 求财占

#### 求名

| 关系 | 断语 |
| --- | --- |
| **体克用** | 名可成但迟 |
| **用生体** | 名易成，且因名有得 |
| **用克体** | 名不可成 |

#### 求财（书中"体生用"之辨极精妙）

**核心**：若卦是"**体生**"，乃泄己之气，其财**空望**。

**三步推法**：

```latex
第1步 看有无生体之卦 → 有则可求，无则难
第2步 看生体之卦属何物 → 定得财的来源
第3步 结合旺衰 → 定得财的多少

```

| 生体之卦 | 得财来源 |
| --- | --- |
| **乾、兑** | 金玉、钱财、金属相关 |
| **震、巽** | 草木、木材、贸易、文书 |
| **坤、艮** | 田土、房产、农业 |
| **坎** | 水边鱼酒、流通业 |
| **离** | 文书、文化、电子、火电类 |

#### 求财速查口诀

```latex
用生体利易得，体生用利难聚；
体克用利迟至，用克体有损耗；
比和求财安稳，正财稳守勿贪。

```

> **为什么"体生用"求财是空望**：体生用 = 我不断往外掏。做生意若只有投入没有回流，账面再热闹也是虚的。

**这一条对现代人的启示**：看一个项目能不能赚钱，先看"**有没有生体的力量回流**"，而不是看"我投入了多少热情"。热情是"体生用"，回流才是"用生体"。

---
#### 案例小故事：求职卦里的"中间人"

有人问求职能不能成。卦中体用比和，互卦又见生——按通用法则，这是"能成且过程顺"的象。

但断的人多问了一句：这类事的结构是什么？求职是三方结构——我、对方、中间人。于是他顺着"用"去追，果然在变卦里读出了"有人代为引荐"的象。

事后反馈：录用是录用了，但确实不是他直接投的简历，是前同事内推的。

如果只按通用法则断一句"能成"，这次也算准；但把"中间人"断出来，才真正用上了这一类事的结构。

**落点**：分类占的关键，是把通用法则落到**这一类事独有的结构**上。求职的结构是三方，问病的结构是正邪，问讼的结构是两造——结构不同，取用不同。

### 9_1 失物 / 寻人占

**重点用后天方位。**

#### 推法

| 维度 | 方法 |
| --- | --- |
| **物品属性** | 看**体卦**类象（何物） |
| **藏处方位** | 看**用卦** + 方位；内卦动 → 在家内；外卦动 → 在外，看方向与环境 |
| **能否找回** | 参旺衰：体旺用衰 → 可寻回；用克体且旺 → 难寻 |
| **所去方向** | **用卦的变卦**往往是所去的方向 |
| **环境特征** | 用卦类象 + 方位类象（如"坎 + 北" → 近水处、阴暗处、地下室） |

#### 方位与藏处速查

| 方位 | 卦 | 可能的藏处 |
| --- | --- | --- |
| 西北 | 乾 | 高处、柜顶、金属容器、书房 |
| 正北 | 坎 | 近水处、卫生间、地下室、阴暗角落 |
| 东北 | 艮 | 门后、墙角、柜中、土石处 |
| 正东 | 震 | 车马处、木器中、声响处（音响旁） |
| 东南 | 巽 | 长条物中、绳线处、通风处 |
| 正南 | 离 | 文书堆中、电器旁、明亮处 |
| 西南 | 坤 | 布帛中、箱包里、平整处 |
| 正西 | 兑 | 开口容器中、破损处、金属旁 |

> **常理校正的例子**：问"失物在哪"，卦象指向"水边"，但当事人从不去水边 → 应改为"近水的类比场所"（卫生间、地下室、厨房水槽旁），而不是硬套"河边"。**这就是"推数必须推理"在失物占上的落地。**

> **小故事·不在河边的"水边"**

有人丢了钱包，卦上用卦是坎，坎为水、方位正北。断卦人一口咬定："掉河边了，去河边找。"
那人住二十楼，小区附近根本没河，绕了半天一无所获。
后来换了个思路：坎是"水"，但城市里什么最像"水边"？——**卫生间、厨房水槽、地下室、洗衣机旁**。
他回家一想，昨晚确实在卫生间洗手时把钱包搁在台面上，之后顺手塞进了洗衣篮旁的柜子。
**卦说的是"水边"，不是"河边"。** 常理不允许的答案，要换成常理允许的那个同构答案——这就是失物占里最常踩的坑。

| 看什么 | 方法 |
| --- | --- |
| **顺不顺** | 体用生克 + 旺衰 |
| **途中何事** | 用卦、变卦的类象 |
| **何时归** | 应期法（见板块6） |
| **方向吉凶** | 后天方位与体卦的生克关系 |

**例**：问远行，起卦时听见雷鸣大风（震木），体为土 → 木克土 → 中途堵车、颠簸、遇争执。

### 9_3 疾病占

| 要素 | 方法 |
| --- | --- |
| **病位** | 克体之卦的类象（身体部位） |
| **轻重** | 体卦旺衰 + 克体之力 |
| **吉凶** | 体旺有救；体衰用旺克体 → 凶 |
| **应期** | 测病以**本互变全数**定应期 |
| **医药** | 看生体之卦（何物、何方、何人可助） |

**例**：问长辈病情，体卦为木；抬头看见院内**枯树抽新芽**（震木生气外应）→ 外应生扶体卦 → 断病情好转，生机渐现。

> **伦理红线**：疾病属于专业领域。占断只能作为"参考视角之一"，**绝不可据此替代就医**。投资、医疗、法律、人身安全四类一律禁止以占卜替代专业判断。

### 9_4 官讼 / 是非占

| 要素 | 方法 |
| --- | --- |
| **有无官非** | 看是否有克体之旺卦 + 乾（官）、兑（口舌）类象 |
| **胜负** | 体旺用衰 → 我胜；体衰用旺 → 我败 |
| **有无和解** | 看有无**通关五行**（和解之象） |
| **口舌来源** | 兑卦类象（口舌、破损、毁折） |

> **外应速判**：起卦时见**官员** → 制度介入；见**争吵** → 防合作破裂；见**吏卒叫嚣** → 忌官讼。

### 9_5 射覆：最好的类象训练场

**射覆**就是把东西盖起来让人猜——"射"是猜，"覆"是盖。这是汉代就流行的游戏，正史里记载的高手都是易学大家。原书也有"占物类例"一节专讲此法。

#### 为什么值得专门练

| 理由 | 说明 |
| --- | --- |
| **绝对可验证** | 猜中就是中，猜错就是错，**没有给自己圆卦的空间**——这是它比占人事更适合训练的地方 |
| **心理负担小** | 占的是一件已知之物，不涉及他人吉凶祸福 |
| **直击核心能力** | 训练"取象 + 五行 + 排除"的完整链条，与断卦用的是同一套肌肉 |

#### 五步流程（直接套用）

```latex
第1步 静心凝神，专注藏物，用时间/数字起卦
      ↓
第2步 本卦 → 定物品大类、五行、基础形态
      ↓
第3步 互卦 → 补颜色、质地、结构、气味等内部细节
      ↓
第4步 变卦 → 定用途、状态、使用场景
      ↓
第5步 结合季节、环境、出题人身份，用排除法剔除相似项，锁定唯一答案

```

#### 体用在射覆中的分工

| 位置 | 对应 |
| --- | --- |
| **体卦** | 事物的**性质、本质、材质、内部**情况 |
| **用卦** | **外形、功用、外部**特征 |
| **上卦** | 多主**颜色** |
| **下卦** | 多主**质地** |

> 也不必死守体用——可以把全卦当成一个整体，找出**最突出的那个象**，再结合背景综合判断。

#### 六种常用取象法

| # | 方法 | 要点 |
| --- | --- | --- |
| 1 | **按八卦类象断** | 基础中的基础，万物类象必须熟 |
| 2 | **按五行断** | 金=坚硬金属；木=生发、条状；水=流动、无形；火=能量、光彩、文化；土=敦厚、老旧、块状 |
| 3 | **按卦名爻位断** | 一般不单凭卦名直断，但卦名 + 卦意 + 爻位在**排除法**里极好用 |
| 4 | **观察全卦** | 找最突出的五行、最明显的特征之象 |
| 5 | **按生克组合断** | 金克木 → 雕琢过的木器；火克金 → 熔铸过的金属 |
| 6 | **卦与时间的关系** | **卦旺**取该象的正面特质（乾旺 = 贵重圆润）；**卦弱**取反面特质（乾衰 = 老旧的金属） |

#### 实战演示：一支口红是怎么推出来的

> **前提**：出题人是女生，藏了一件小东西。

**得卦**：火泽睽 → 变山泽损。

| 轮次 | 推理 | 反馈 |
| --- | --- | --- |
| **第一轮** | 上离下兑：兑为开口容器、有"气"之象，开口处冒火 → **打火机** | 不对 |
| **第二轮** | 重取：兑为口、为吃；用克体，但变卦艮生兑（由克转生）→ 难吃却对身体有益 → **药物** | 不对 |
| **第三轮** | 再重取：体卦兑为**少女**，用卦离为**美丽**，互卦下卦也是离 → **化妆品类** | 很接近 |
| **收窄** | 互卦坎水克离火，代表过程中被消耗；变卦**山泽损** = 损耗 → 是**消耗品**；对女生而言"美丽的消耗品" = 化妆品 | 对 |
| **定色** | 本卦兑为白、离为红 → 颜色与白或红有关 | 与红色有关 |
| **定形** | 兑为口，离在外，变卦艮为手 → 手持某物擦拭口部，且会损耗 | **口红** |

> **这个案例最值钱的地方**：前两轮都错了，但每一轮都**用反馈缩小范围**——这就是射覆的"排除法"本质，也是它训练价值最高的原因。

第一轮推出"打火机"，虽然错了，但"开口容器 + 冒火"这个组合被保留下来；第二轮推出"药物"，又排除了"入口之物"里的一大类；到第三轮才把范围收进"化妆品"。
**射覆从来不是一次命中，而是三轮收敛。**

#### 三条新手误区

1. **切忌单卦断物**——单卦类象多达数十种（乾可为金属、圆球、首饰、器物），**必须本、互、变三卦叠加筛选**。
2. **脱离生活事理**——卦象是死的，生活是活的。同样的卦，换个季节、换个场景，对应的物品完全不同。
3. **心念杂乱起卦**——射覆讲究"静心感物"，杂念多则卦气混乱。

#### 评分标准（重要，别给自己太大压力）

> **射覆不一定要说出确切物品名。**

比如藏物是一块磁铁，你能说出"**含金属、整体偏黑、有吸附作用**"——**特性说对了，这次射覆就算成功**。
很多时候我们明明知道物品的各种属性，就是想不起名字。能说出特性，说明取象链条是通的；能说出具体物品，那是加分。

**训练建议**：每天做 1—3 组。让家人朋友随手盖一件小东西，你起卦推断，**一次性写出完整断语**（不要挤牙膏式地"看到一点说一点"），写完后统一揭晓对照。

### 10_1 观梅占（得名之占·时间起卦）

#### 场景

一个冬末春初的日子，邵雍在自家花园里赏梅。梅花开得正好，他正看着，忽然两只麻雀为一根树枝争了起来，扑腾间**双双坠地**。

#### 观机

邵雍说了一句很关键的话：

> **"不动不占，不因事不占。今二雀争枝坠地，怪也。"**

麻雀打架本不稀奇，但"两只鸟为争枝而双双坠地"，这个画面不对劲——**这就是"机"**。没有这个"怪"，就不起这一卦。

#### 起卦

时间是**辰年十二月十七日申时**。

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 上卦 | 5（辰）+ 12（十二月）+ 17（十七日）= 34；34 ÷ 8 = 4 余 **2** | 2 = **兑**，上卦 |
| 下卦 | 34 + 9（申时）= 43；43 ÷ 8 = 5 余 **3** | 3 = **离**，下卦 |
| 动爻 | 43 ÷ 6 = 7 余 **1** | **初爻动** |
| 成卦 | 上兑下离 = **泽火革**，初爻动 |  |

再排互卦与变卦：

```latex
本卦六爻自下而上：阳、阴、阳、阳、阳、阴
初爻动（阳变阴）→ 下卦离☲（阳阴阳）变艮☶（阴阴阳）
变卦 = 上兑下艮 = 泽山咸
互卦 = 二三四爻（阴、阳、阳）= 巽，三四五爻（阳、阳、阳）= 乾
     → 上乾下巽 = 天风姤（古案原文："互见乾、巽"）

```

#### 推演

| 环节 | 内容 | 用到哪一层 |
| --- | --- | --- |
| **1. 触发** | 二雀争枝坠地，"怪也" → 不动不占，有了"机" | 心法·动静 |
| **2. 起卦** | 时间起卦法，得泽火革初爻动 | 时间起卦法 |
| **3. 成卦** | 本卦泽火革；互见乾、巽；变卦泽山咸 | 排本互变 |
| **4. 分体用** | 动爻在**下卦** → 用 = 离（火）；体 = 兑（金） | 体用 |
| **5. 断生克** | 离火克兑金 → **用克体，凶** | 体用生克 |
| **6. 取类象** | 兑 = **少女**；离 = 花、美丽 → **折花**；互中**巽 = 股**，被乾金、兑金所克 → **伤股** | 万物类象 |
| **7. 参互卦** | 互中乾金克巽木 → 被**惊逐**（乾 = 园丁、奔跑；巽 = 进退、惊惧） | 三要十应 |
| **8. 看变卦** | 变出**艮土**，土生兑金 → **凶中有救，不至于危** | 卦气旺衰 |
| **9. 应期** | 成卦之数 43；但梅花花期只有朝夕 → **变通**，断"明晚" | 应期·变通原则 |

#### 断语与应验

> **断**：明晚有少女来折花，被园丁惊逐，失足坠地，**伤其右股**。

**验**：次日夜，邻家女来折梅，园丁逐之，失足跌伤右大腿。

#### 关键洞察（这一例最值钱的地方）

如果**只读生克**（用克体 = 凶），结论会是"女子有大灾"。但**变卦艮土生兑金**——
原典的表述是「**幸变为艮土，兑金得生**，知女子但被伤，而不至凶危也」。

> **原文校准**：本库此前把这一救应解释为"火生土、土生金的通关"，与原文机理不同。
> 原文说的是**变卦之土直接生体卦之金**（变卦生体），不是靠"通关"转圜。
> "通关"是五行生克的通用说法，《梅花易数》全书未立此名目，本书保留该词作一般释义，
> 但**观梅占的救应机制当以原文"变为艮土，兑金得生"为准**。

所以分寸是"**伤股而不至于死**"。

```latex
体 = 兑金，用 = 离火 → 火克金（凶）
互卦见巽（股） → 伤在股
变卦艮土 → 兑金得生（变卦生体）→ 凶中有救
结论：伤股而不至于死

```

> **只推数不推理，是不得也。** 这正是全书最想教的事。

#### 应期的变通（必记）

原书在此案后立刻补充：

> "虽然如是，又在变通。如占牡丹及观梅之类，则二日花皆朝夕之故，岂特成数之久也。"

**成卦之数 43，按数该应 43 日；但梅花花期只有朝夕，故断次日。**——常理永远优先于数字。

### 10_2 老人有忧色占（端法起卦·应期到日）

#### 场景

己丑日卯时，邵雍走在路上。迎面来了一位老人，往东南方向去。奇怪的是，老人脸上有**明显的忧色**。

邵雍上前问："您有什么忧心事吗？"老人回答："没有。"

#### 观机

这里有三重"怪"：

1. 老人**往巽方（东南）**而行
2. 老人面**有忧色**
3. 问之**曰无** —— 明明脸上有忧色，却说没有，情理不合

三重异常叠在一起，机已成。

#### 起卦与推演

| 环节 | 内容 |
| --- | --- |
| **1. 触发** | 老人往巽方 + 有忧色 + 问而不答（情理不合）→ 三重"怪" |
| **2. 起卦** | 老人属**乾** → 上卦；巽方 → 下卦 → **天风姤** |
| **3. 动爻** | 乾 1 + 巽 5 + 卯时 4 = 10；10 ÷ 6 余 **4** → **九四爻动** |
| **4. 分体用** | 四爻在**上卦** → 用 = 乾（金）；体 = **巽（木）** |
| **5. 断生克** | 乾金克巽木 → **用克体，凶** |
| **6. 看互卦** | 互见**重乾**（姤卦中四爻皆阳）→ 三个乾金齐克体，**并无生气** |
| **7. 参爻辞** | 姤卦九四："**包无鱼，起凶**" → 爻辞亦不吉，且直指"鱼" |
| **8. 定应期** | 成卦之数 = 1+5+4 = **10**；占者"**在途行**"（动）→ **10 ÷ 2 = 5** → 五日 |
| **9. 断语** | "汝于**五日内**谨慎出入，恐有重祸" |

#### 应验

> 果五日，此老**赴吉席，因鱼骨鲠而终**。

#### 这一例的四条教学点

1. **端法起卦**：人物（乾）+ 方位（巽）→ 卦，是"先得象后得数"
2. **气色即外应**：老人"有忧色"是起卦前就存在的天机信号，比卦更早
3. **应期公式的实战**：成卦之数 10，行则减半 = 5
4. **爻辞的补充作用**："包无鱼"提示了"鱼"——**爻辞是加分项，不是主项**（主项仍是体用 + 旺衰）

> **重要提醒**：此例断的是**生死**，属于极高风险的判断。现代社会**绝不可据此对他人作出此类断言**。此例的价值在于方法论演示，不在于可复制性。

> **值得注意的一处细节**：断语只说"五日内谨慎出入，恐有重祸"，并没有直接说"你会死"。占者给出的是**警示与建议**，而不是判决。这也是历代易家"易为君子谋"的分寸所在。

### 10_3 少年有喜色占（体用不吉，却断吉）

#### 场景

壬申日午时，一位少年从南方（离方）过来，**满脸喜色**。

邵雍问："你有什么喜事？"少年答："没有。"

#### 观机

又是"情理不合"：明明喜形于色，却说没有——异常。

#### 起卦与推演

| 环节 | 内容 |
| --- | --- |
| **1. 触发** | 少年从离方来 + 喜形于色 + 问而无喜（情理不合） |
| **2. 起卦** | 少年属**艮** → 上卦；离方 → 下卦 → **山火贲** |
| **3. 动爻** | 艮 7 + 离 3 + 午时 7 = 17；17 ÷ 6 余 **5** → **六五爻动** |
| **4. 分体用** | 五爻在**上卦** → 用 = 艮（土）；体 = **离（火）** |
| **5. 断生克** | 火生土 → **体生用**（泄耗，本不吉！） |
| **6. 看互变** | 互见**震、坎**；变卦**风火家人**（上巽下离，木生火）→ **互变俱生体** |
| **7. 参爻辞** | 贲六五："**贲于丘园，束帛戋戋，吝，终吉**" → 爻辞已吉，且"束帛"直指聘礼 |
| **8. 参外应** | **少年有喜色** → 三要之目要，最强的第一手天机 |
| **9. 定应期** | 成卦之数 **17** → 断"十七日内" |

#### 断语与应验

> **断**："子于**十七日内**，必有**币聘之喜**。"

**验**：至期，果然定亲。

#### 这一例的教学价值（本库最想强调的一条）

**按体用关系，用卦艮土不生体卦离火，反而是"体生用"（泄耗），本该断不吉。但邵雍断吉，靠的是三层合力：**

```latex
第1步 外应（少年有喜色）—— 目要直取，第一手天机
第2步 互变俱生体 —— 过程与结局都在生扶
第3步 爻辞"束帛戋戋，终吉" —— 细节印证

```

原书的总结原话：

> "盖少年有喜色，占则略知其有喜，而《易》辞又有'束帛戋戋'之吉，是两者俱吉，互变俱生，愈见其吉矣。**虽用不生体，不吉，不为其害也。**"

> **这就是断卦优先级的实战出处**（见 `5_9`）：体用生克是定性起点，但**不是唯一依据**。当互变、外应、爻辞三者一致指向另一端时，要以合力为准。

### 10_4 牛哀鸣占（凶局的完整形态）

#### 场景

癸卯日午时，邵雍听见坎方（北方）传来牛的叫声，**声音极其悲切**。

#### 观机

牛叫常见，但"**其声极悲**"不常见——异常。

#### 起卦与推演

| 环节 | 内容 |
| --- | --- |
| **1. 触发** | 牛鸣 + 声极悲（异常）+ 在坎方 |
| **2. 起卦** | 牛属**坤** → 上卦；坎方 → 下卦 → **地水师** |
| **3. 动爻** | 坎 6 + 坤 8 + 午时 7 = 21；21 ÷ 6 余 **3** → **三爻动** |
| **4. 分体用** | 三爻在**下卦** → 用 = 坎（水）；体 = **坤（土）** |
| **5. 断生克** | 坤土克坎水 → 体克用（表面小吉？**错，要看互变**） |
| **6. 看互变** | 变卦**地风升**（上坤下巽，木克土）；互卦见**坤、震**（木克土）→ **互变俱克体，并无生气** |
| **7. 参爻辞** | 师六三："**师或舆尸，凶**" → 凶，且"舆尸"直指搬运尸体 |
| **8. 结论** | 牛**当杀** |

#### 教学点：为什么"体克用"反而凶？

**关键在互变。**

本卦体克用（土克水），表面是我能掌控。但**变卦、互卦全部反过来克体**（木克土）——说明**掌控只是暂时的，结局是被压制**。

```latex
本卦：土克水（我能掌控）→ 表面小吉
互变：木克土（结局被压制）→ 真凶
结论：先好后坏

```

> **这条规则的普适形式**：本卦看起始，变卦看结局。**本吉而变凶 = 先好后坏**。断卦必须看完整条时间轴（本 → 互 → 变），只看本卦就下结论，等于看电影只看开头。

### 10_5 "今日动静如何"占（体用凶，却断"有酒食之乐"）

#### 场景

有人来问："**今日动静如何？**"——就是问今天会有什么事发生。起卦得**地风升**。

#### 推演

| 环节 | 内容 |
| --- | --- |
| **1. 体用** | 体 = 坤（土）；用 = 巽（木）→ **木克土，用克体** |
| **2. 表面结论** | 用克体 → **凶** |
| **3. 旺衰校正** | 时值**秋天**：坤土得令（秋金旺、土相），土不弱；巽木在秋天**休囚**，**克不动** |
| **4. 卦象组合** | 坤为地、为**众人**；巽为风、为**入**；互卦见**震（动）、兑（悦）** |
| **5. 综合意象** | 众人相请 → 动而喜悦 → **酒食之乐** |

#### 断语与应验

> **断**：今日有**人相请，有酒食之乐**。

**验**：果然。

#### 教学点（这是"体用不是全部"的最强证据）

```latex
体用生克  →  定性（用克体 = 凶）        ← 起点
     ↓
月令旺衰  →  校正（秋：体旺、用衰 → 克不动，凶性不成立）
     ↓
卦象组合  →  重新定性（坤众人 + 巽入 + 震动 + 兑悦 = 相请之喜）

```

**换个说法你就懂了**：卦上说"有人要克我"，但一看时令，那人是个虚弱的老头，根本推不动我；再一看卦象组合，众人、入门、动、喜悦——原来不是来克我的，是来请我吃饭的。

> **邵雍在原书中从来没有"只靠体用生克"就断卦。** 梅花易数之所以不是"数学题"，全在旺衰校正与卦象组合这两步。

> 注：此案例在流传版本中存在异文，此处取其通行的解读逻辑——**重点不在结论，而在"旺衰 + 卦象组合可以推翻表面体用"这一方法**。

### 10_6 夕晚借物占（"推数必须推理"的教科书）

#### 场景

一个冬日的傍晚，天已经黑了。有人敲门，说是来借东西。

#### 推演

| 环节 | 内容 |
| --- | --- |
| **1. 卦象** | 金短木长 → 类似"锄"的农具 |
| **2. 数字结论** | 该断"**锄**" |
| **3. 常理校正** | **天已黑，借锄下地不合常理**；冬日天寒，此时借物必为**劈柴生火** |
| **4. 改断** | **斧** |
| **5. 应验** | 开门一问，果然借斧 |

#### 教学点

这是全书最短、也最锋利的一例。它说明：

> **卦象只是一种"可能性提示"，不是答案。最终的答案，必须用常理去校验。**

**可迁移的实操规则**：

| 情形 | 处理 |
| --- | --- |
| 卦象结论 + 常理成立 | 直接采用 |
| 卦象结论 + 常理不通 | **以常理为准**，重新在卦象范围内选择另一个合理的象 |
| 卦象结论 + 多种可能 | 用**时间、地点、人物身份**排除不可能项 |

> 例如：问"失物在哪"，卦象指向"水边"，但当事人从不去水边 → 应改为"近水的类比场所"（卫生间、地下室、厨房水槽旁），而不是硬套"河边"。

### 10_7 牡丹占（应期精准到时辰）

#### 场景

巳年三月十六日卯时，邵雍与客人同往司马光家观赏牡丹。花开得极盛，客人问：

> **"花盛开如此，亦有数乎？"**（花开得这么好，也有定数吗？）

邵雍答：**"莫不有数。"**（万物莫不有数。）于是当场起卦。

#### 推演

| 环节 | 内容 |
| --- | --- |
| **1. 起卦** | 巳年 6 + 三月 3 + 十六日 16 = 25；25 ÷ 8 余 **1** → 乾（上）；25 + 卯时 4 = 29；29 ÷ 8 余 **5** → 巽（下）→ **天风姤** |
| **2. 动爻** | 29 ÷ 6 余 **5** → 五爻动 |
| **3. 变卦** | 上卦乾（☰）五爻动变离（☲）→ **火风鼎** |
| **4. 分体用** | 五爻在上卦 → 用 = 乾（金）；体 = **巽（木，即花）** |
| **5. 断生克** | 乾金克巽木 → **用克体** → 花将被毁 |
| **6. 取类象** | **乾 = 马** → 毁花者是马 |
| **7. 定应期** | 变卦为**离**，离为**日中、午时** → 应于**午时** |
| **8. 断语** | 此花**明日午时，当为马所践毁** |

#### 应验

> 次日午时，果然有贵客骑马而至，马惊践毁牡丹。

#### 教学点

1. **应期精确到时辰**：变卦（离）→ 午时，这是"卦象定时"的经典用法（见 `6_4` 卦象时序表）
2. **克体之卦的类象直接指出"加害者"**：乾为马 → 被马所践
3. **再次印证"变通"**：牡丹花期短，故不用成卦之数 29，而取变卦之时

### 10_8 七案共通心法提炼

把七个案例放在一起，可以提炼出五条贯穿始终的方法：

| # | 心法 | 出处 |
| --- | --- | --- |
| **1** | **不动不占**：所有案例的起点都是"怪"——异常才是机 | 观梅、老人、少年、牛鸣 |
| **2** | **体用是起点，不是终点**：必须过旺衰、互变、卦象组合三关 | 少年占、动静占、牛鸣占 |
| **3** | **变卦生体决定"程度"**：有救则"伤而不死"，无救则"并无生气" | 观梅占、老人占 |
| **4** | **克体之卦的类象指出"加害者/阻力源"** | 牡丹占（乾为马）、牛鸣占（木克土者） |
| **5** | **常理永远优先于数字**：花期、昼夜、人情，都可以推翻成卦之数 | 观梅占、牡丹占、借物占 |

#### 一句话总结

这七案反复演示的其实是同一件事——

```latex
先按方法算出结果 → 再用常理校正
数给你可能性，理给你确定性

```

| 案例 | 数怎么说 | 理怎么校正 |
| --- | --- | --- |
| 观梅占 | 43 日 | 花期只有朝夕 → 断次日 |
| 牡丹占 | 29 日 | 同理 → 取变卦离，断午时 |
| 借物占 | 锄 | 天黑不合常理 → 改断斧 |
| 动静占 | 用克体，凶 | 秋月木衰克不动 → 转成酒食之乐 |
| 少年占 | 体生用，耗 | 外应喜色 + 互变生体 → 转成吉 |

#### 把古案搬到今天：一个现代练习

> **小故事·现代版的"借斧"**

有人问"丢的耳机在哪"，卦上用卦是坎，坎为水、为暗处、方位正北。
他第一反应是"是不是掉在水边了"，可他这几天根本没去过河边、湖边。
这时候他想起了借斧那一卦——**邵雍在冬夜改"锄"为"斧"，靠的就是一句"于理不通"。**
于是他在坎的类象里重新挑：城市里什么最像"水边"和"暗处"？——洗衣机旁、卫生间台面、床头柜夹层、深色衣物口袋。
顺着这条线找，耳机最后在**洗衣机旁的收纳篮**里找到了，前一天洗澡前随手一放。
卦从头到尾没变，变的是他把"水边"翻译成了生活里真实存在的那个"水边"。
**古案的价值从来不在"复刻一个答案"，而在"学会那一步校正"。** 你遇到的问题不会是折梅、借斧、牛鸣，但你一定会遇到"卦说的和现实对不上"——那一刻，就是借斧卦重演的时候。

### 11_1 起卦环节的六个错误

> 这六条与 `4_8` 的清单相同，此处汇总是为了让你**集中回看**——建议每断十卦扫一遍这张表。

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **1** | **年份用公历数字**（如年份直接 ÷ 8） | 上卦全错 | 只用农历**地支序数**：子1…亥12 |
| **2** | **余 0 当 0 或无卦** | 下卦/动爻全错，**且自查发现不了** | 求卦余 0 → 取 **8（坤）**；求爻余 0 → 取 **6（上爻动）** |
| **3** | **动爻用上下卦数之和直接当** | 动爻错 | 动爻 = 第三个数 ÷ 6 取余；无第三数则用两数之和或加时辰数 |
| **4** | **端法起卦忘加时辰数** | 动爻错 | 先得象（端法）→ **必须**加时辰；先得数（数字法）→ 不加 |
| **5** | **起卦后反复重算** | 卦气杂乱，失去参考价值 | 一事不二占；心不诚、机不明则不占，重占须另有机缘 |

> **原文校准**：《梅花易数》全书**无"再占须间隔七日"之规定**。另需注意：六爻一系的《增删卜易》反而力主"多占之法"（即时再占、合两卦而决）。两体系口径相反，用时须先选定所从之体系，不可混用。
| **6** | **用先天数断方位 / 用后天位起卦** | 方位全错 | 起卦用**先天数**；方位看**后天位** |

### 11_2 断卦环节的八个错误

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **7** | **体用搞反**（以为上卦永远是体） | **满盘皆错** | 默念："动爻在某卦，某卦为用"。1/2/3 爻动→下卦为用；4/5/6 爻动→上卦为用 |
| **8** | **给互卦强行分体用** | 吉凶逻辑混乱 | **只有本卦分体用**。互卦只看它对体卦的生克 |
| **9** | **忽略互卦** | 缺少"过程分析" | 互卦 = 二三四爻（下互）+ 三四五爻（上互） |
| **10** | **只看生克，不看旺衰** | 定性对、定量错 | 生克定性质，旺衰定轻重。体旺不怕克，用衰生不力 |
| **11** | **只论卦名，不审卦气** | "局于象，昧于时" | 卦名不变而气随时转，必须按时审气 |
| **12** | **只看体用，不看爻辞** | 丢失原典第一道判据 | 原典优先级：**爻辞 → 体用生克 → 卦气旺衰 → 互变 → 类象 → 克应 → 应期**。爻辞为断吉凶之首，体用为定性主干 |
| **13** | **只看本卦，忽略互变** | 看不到过程与结局 | 本（始）→ 互（过程）→ 变（结局），三卦合参 |
| **14** | **过度解读** | 信息量过大，反而不敢断 | 一次只抓 3—4 个关键点：体用、互卦、变卦、最显著的一个外应 |

### 11_3 心法环节的六个错误

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **15** | **外应满世界去找** | 全是主观投射 | 外应是"**撞进来**"的，三秒内自然注意到的才算 |
| **16** | **外应硬套**（见鸟叫就往离卦靠） | 结论荒唐 | 先想类象再套，不要拿结论倒推。鸟叫属**兑**（声音），鸟飞属**震**（动） |
| **17** | **类象死记硬背** | 遇到现代事物就断不了 | 取象三原则：问什么取什么、看旺衰、两卦叠加 |
| **18** | **象大于五行，不谈生克** | 舍本逐末 | 生克定吉凶，类象定细节；**生克优先于类象** |
| **19** | **宿命论**（卦说不行就不行） | 放弃主观努力 | 梅花揭示的是"**若按此轨迹发展，将得此结果**"，目的在于**趋吉避凶** |
| **20** | **刻舟求剑**（一套口诀打天下） | 同卦不同人、不同时，解读应不同 | 因人而异、因事而异、因时而异 |

### 11_4 六大学习盲区（进阶者也会中招）

| 盲区 | 表现 | 正解 |
| --- | --- | --- |
| **1. 只重卦象，不看卦理** | 背了一堆类象，不知何以如此 | 不知卦理就无法推衍类象。**乾兑皆金，乾是贵重圆润，兑是破损开口** |
| **2. 只论卦名，不审卦气** | 见"泰"就吉、见"否"就凶 | 卦名不变，气随时转 |
| **3. 象大于五行，不谈生克** | 沉迷取象，忘了断吉凶靠生克 | 生克是骨架，类象是血肉 |
| **4. 大道至简，空中楼阁** | 以"梅花不论干支"为借口，不学基础 | 干支是打开时空的钥匙，至少掌握地支序数、月令、日支 |
| **5. 重术轻理** | 会起卦断卦，不懂为何 | 回到《皇极经世》的体用框架与"以物观物"（见板块12） |
| **6. 以准为荣，以验为能** | 追求"算得准"，忽略思维训练价值 | 真正的收获是观察力、结构化联想力、以及在不确定中做判断的能力 |

### 11_5 断完卦必问的八个问题（自查清单）

每次下断语之前，把这八条过一遍：

```latex
□ 1. 动爻位置确认了吗？"动爻在某卦，某卦为用"——默念过吗？
□ 2. 余 0 的地方处理对了吗？（取 8 / 取 6）
□ 3. 互卦取对了吗？我有没有给它强行分体用？
□ 4. 旺衰查了吗？体卦在当月的旺相休囚死是什么？
□ 5. 变卦看了吗？本吉变凶 / 本凶变吉，结论改了吗？
□ 6. 有没有通关五行？克局是不是有救？
□ 7. 类象是不是只取了和问题最相关的 3—5 个？
□ 8. 最后一步：这个结论符合常理吗？（不合就要重来）

```

> **第 8 条是最重要的。** 一个不符合常理的结论，99% 是中间某一步错了，而不是"卦太玄妙"。

> **小故事·被第 8 条拦下来的断语**

有人问一笔款子下个月能不能到账，卦算下来是"用克体"，他心里一沉，正准备说"恐怕要不回来"。
话到嘴边，他想起自查清单的第 8 条：**这个结论符合常理吗？**
他停住了——对方是合作多年的老客户，上个月的款子都是准时结的，说"要不回来"实在说不通。
于是他从头复核，一路查到动爻：动爻落在第 3 爻，属于下卦三爻，**下卦才是用**。而他从一开始就把上卦当成了体——**体用整个搞反了。**
改正后重断：不是"用克体"，而是"用生体"，事易成，且对方会主动配合。后来那笔款子如期到账。
他事后在卦例本上写："**第 8 条救了我一卦。** 如果不是它逼我停下来问一句'这说得通吗'，我就把一个吉卦说成了凶卦。"
八问清单真正的价值，不在于"提醒你别出错"，而在于**给你一个停下来重算的理由**。多数断错的卦，都错在断得太快。

---

### 11_6 最致命的三条（新手必记）

所有错误里，最致命的是这三条——

```latex
第1步 体用搞反
第2步 余 0 处理错（当成 0 或无卦）
第3步 用公历年份代替农历地支序数

```

它们的共同特点是：**自己发现不了**。三条都会给出一个"看起来完整"的答案，照样能讲出一套道理，所以错了也不知道。

> **一句话防线**：每次断卦前，先花 30 秒默念这三条，比什么都管用。

---
#### 案例小故事：对了九卦，错在第十卦

一人连着断了十卦，前九卦都对，于是他开始觉得自己"上手了"。第十卦错得很彻底，方向整个反了。

复盘那一次，他发现问题不在技术：卦还没起，他心里已经有了答案——因为当事人是他朋友，他希望事情成。

于是从起卦那一步开始，他就只盯着支持"能成"的象看，反对的象被他一路解释成了"暂时阻碍"。前九卦之所以准，是因为那九个人他不在乎。

**落点**：最高频的错误不是技术错误，是**先有答案再倒推**。断卦前先自查一句：这件事，我希望它是什么结果？

## 板块12 · 观物心法：《皇极经世》的思想源头

> **从"术"回到"道"**

前十一块是可训练的手艺。但要真正读懂梅花易数，必须回到邵雍的另一部代表作——**《皇极经世》**。梅花易数只是这套宏大世界观在"一件事"上的微观应用。

---

### 12_1 书名解码：四个字里藏着整本书的纲领

《皇极经世》凡十二卷，前六卷讲宇宙时间（元会运世）与律历，后六卷（《观物篇》）讲观物心法与治道——由天道而人事，由数理而心性，层层收束，最终落在一个"观"字上。

| 字 | 本义溯源 | 邵雍体系中的含义 | 对应层次 |
| --- | --- | --- | --- |
| **皇** | 甲骨文象"发光的灯"，指光明本源 | 创生万物、照亮一切的宇宙本源——太极 | 宇宙本体论 |
| **极** | 树状分形的系统架构法则 | 从太极→两仪→四象→八卦的可推导、可演算的生成语法，即宇宙的"数据结构" | 象数方法论 |
| **经** | 织布的纵线，核心动作是"贯穿、编织" | 用"皇极"这根金线，将纷繁世象编织成有规律、可理解的图景 | 历史与万物的整合 |
| **世** | 时间线上的所有事件与空间中的一切存在 | 被编织的对象——历史、万物、人事 | 应用与验证 |

合而观之：**"皇极"是宇宙的生成法则（是"体"），"经世"是把这套法则用于理解与编织人间世事（是"用"）。** 体用合一，即是书名真义。

#### 四个"导航锚点"

先记住它们再往下读：

```latex
元会运世 —— 时间的分形单位（讲"何时"）
皇帝王霸 —— 权力的四种形态（讲"如何治"）
先天后天 —— 体用与认知的双重框架（讲"何为根本"）
以物观物 —— 全书最终的落脚心法（讲"如何看"）

```

#### 一句话点破全书宗旨

> **以宇宙本源（皇）的生成法则（极），贯通并编织整个人类历史与世间万象（经世）。**

---

### 12_2 与梅花易数的接口：同一套体用框架的两种尺度

《梅花易数》与《皇极经世》共享同一个思想源头——**邵雍的先天之学**。理解这一点，梅花易数就从"占卜术"升级为"一套完整的世界观在微观场景的应用"。

| 共同根基 | 在《皇极经世》中 | 在《梅花易数》中 |
| --- | --- | --- |
| **加一倍法** | 太极→两仪→四象→八卦→六十四卦→万物；与二进制不谋而合 | 卦以八除、爻以六分的**可计算性**来源 |
| **先天之学** | "先天之学，心法也"；先天主对待、后天主流行 | **先天数**（起卦）与**后天位**（断方位）的分工 |
| **体用不二** | "先天为体，后天为用"；体用合一方是全书真义 | **体卦 / 用卦**：体为我、用为事，体用合一即断卦 |
| **内象内数 vs 外象外数** | 内数是不变的法则，外数是万变的呈现 | **卦象（不变的结构）** 与 **外应（万变的呈现）** |
| **元会运世的分层** | 一元十二会、一会三十运，大周期套小周期 | **本卦 → 互卦 → 变卦**：起始 → 过程 → 结局的时间分层 |

> **最值得带走的一条**：《皇极经世》的核心是"**把变化周期化、把时间分层**"，梅花易数的"本互变"正是这个思路在**一件事**上的微观版本。

---

### 12_3 加一倍法与"以四言"：宇宙的生成语法

#### 加一倍法：万物皆从一个"一"演化而来

邵雍的宇宙生成论，逻辑链条只有一条：

> **道（无极）→ 太极 → 阴阳（两仪）→ 四象 → 八卦 → 六十四卦 → 万物**

"道生天地，则天地亦万物也"——天地在道面前同样是"物"，这就把宇宙彻底对象化、可建模化了。

而生成的方法，是邵雍独创的**"加一倍法"**：

> **一生二、二生四、四生八，如此层层翻倍。**

这便是后世熟知的**先天六十四卦方圆图**的生成逻辑。更令人惊叹的是：当德国数学家莱布尼茨在公元 1701 年收到这张图，把阳爻（—）译为 1、阴爻（--）译为 0 时，他发现——这套九百年前的中国图谱，竟与他自己发明的**二进制**完全吻合。

#### 方图与圆图的分工

+ **圆图**象天体运行，主"时间"，流转不息
+ **方图**象地理结构，主"空间"，定位不动
+ 一时一空、一圆一方，把整个宇宙装进了一张图里

> **核心洞见**：邵雍真正厉害之处，不是"会算卦"，而是**把《易经》从一本占卜手册，升级成了一套可以计算的宇宙模型**。这是中国思想史上罕见的"数理宇宙观"传统，其精神内核与现代科学用数学模型理解复杂系统（经济、气候、生态）完全一致。

#### "凡事以四而言"：一套普遍的分类语法

邵雍思想的另一个系统性特征，是**"凡事以四而言"**。这不是随意的数字偏好，而是一套分类语法：

| 维度 | 四象 |
| --- | --- |
| 天 | 日、月、星、辰 |
| 地 | 水、火、土、石 |
| 物 | 走、飞、草、木 |
| 治道 | 皇、帝、王、霸 |
| 时间 | 元、会、运、世 |
| 认识论 | 目、心、理（+ 性/命） |

这套"以四言"的结构，说明邵雍不满足于零散感悟，而是要构建一个**能穷尽万物的分类框架**。它本质上是古代的"数据结构"思想——先把世界切分成正交维度，再组合推演。

#### 内象内数 vs 外象外数

这是读懂象数部分的一把钥匙：

+ **内象内数**：先天象数之图，结构规则、变化有序，对应历法中的"历理"
+ **外象外数**：内象内数的应用——上部推运气兴衰、下部测声律变化，对应历法中日月五星的实际运行

> **简言之：内数是不变的法则，外数是万变的呈现。** 这一区分，正是"体用"思想在象数层面的落实——也正对应梅花易数里"**卦象是不变的结构，外应是万变的呈现**"。

### 12_4 元会运世：四级嵌套周期模型

这是全书最著名、也最具现代启发的部分。邵雍把时间做成了**四级嵌套的进制系统**：

```latex
1 元 = 12 会 = 360 运 = 4320 世 = 129600 年
   └── 1 会 = 30 运 = 360 世 = 10800 年
         └── 1 运 = 12 世 = 360 年
               └── 1 世 = 30 年

```

**换算口诀**：**"一元十二会，一会三十运，一运十二世，一世三十年。"**

这套单位与"日月星辰"相配：日以**元**为单位（太阳一年绕天一周），月以**会**为单位（一年十二次朔望），星以**运**为单位（一年约 360 度），辰以**世**为单位（一日十二时辰）。元会运世互相统率，如同**年→月→日→时**的嵌套。

> **一个震撼的细节**：129600 年，恰好约合岁差五周，算得的周期约 25820 年，与现代测定的岁差周期（约 25700—25800 年）惊人接近。这说明邵雍的体系并非信手杜撰，而是建立在严密的天文律历观测之上——治学之严谨，远超"民间算命术"的想象。

#### 十二会：宇宙的"春夏秋冬"

一元分十二会，配十二地支与十二消息卦，描述宇宙从开天到闭物、再循环的重演全过程：

| 会 | 地支 | 卦象 | 阶段 | 含义 |
| --- | --- | --- | --- | --- |
| 子 | 子 | 复 | 一阳生 | 开天，天地初分 |
| 丑 | 丑 | 临 | 二阳长 | 辟地，万物萌芽 |
| 寅 | 寅 | 泰 | 三阳开泰 | **生人**，人类出现（开物） |
| 卯—辰—巳 |  | 大壮—夬—乾 |  | 文明初兴 → 发展 → 渐盛 |
| **午** | 午 | **姤** | **阳极盛** | **文明鼎盛——我们正处午会** |
| 未—申—酉 |  | 遁—否—观 |  | 阳极阴生 → 衰退 → 式微 |
| 戌—亥 | 戌—亥 | 剥—坤 |  | 将尽 → **闭物**，重归混沌 |

**历史锚点**：以**唐尧即位（甲辰年）**为午会第七运起点，将华夏历史（尧舜→三代→秦汉→唐宋→五代）纳入周期框架，逐运、逐世、逐年配卦，推演治乱兴衰。

#### 超越字面：这套模型真正想说什么

必须清醒地指出：**元会运世的具体历史预言，缺乏实证支撑，不能作为"科学预测"采信。** 但如果在字面预测上止步，就等于买椟还珠。

这套模型真正值钱的，是三层方法论启示：

1. **周期是复杂系统的普遍特征**。经济有康波周期、行业有生命周期、技术有 S 曲线——任何事物都有春夏秋冬，看懂"季节"比盲目努力重要得多。这正是邵雍周期观的现代等价物。
2. **大周期嵌套小周期**。一元之中有会运世，正如一年之中有春夏秋冬、一月之中有朔望晦弦。分析任何问题，先看它在哪个层级的"季节"里，这是邵雍教给我们的**分层思维**。
3. **卦象配时 = 建立"时间—状态"坐标系**。用"运卦→世卦→年卦"层层细化，本质上是用一套符号系统给时间做编码——这种"给复杂事物建立可计算的时空坐标"的思路，与现代系统建模如出一辙。

> **一句话记住**：元会运世不是算命公式，而是一套"**把时间分层、把变化周期化**"的思维工具。

### 12_5 先天与后天：全书最重要的"体用"框架

如果说全书只能记住一个概念，那就应该是**"先天后天"**。它既是宇宙论（理与气），又是易学（卦之体用），更是**人生境界的判据**——三个层面叠加，是理解邵雍的枢纽。

#### （一）宇宙论层——造化之序

|  | 先天 | 后天 |
| --- | --- | --- |
| 状态 | 万物未分、未形之前的太极本体 | 天地既分、万物化生之后的气化运行 |
| 对应 | 老子"道生一"、孔子"易有太极"、数理（加一倍法） | 老子"一生二生三"、有形有象的世界、历法物理人事 |
| 邵雍语 | "未有其物而先有其理" | "既有其物而有其序" |

**先天是造化的"所以然"（理、数），后天是造化的"所当然"（象、气）。先天主宰后天，后天不离先天。**

#### （二）易学象数层——卦之体用

|  | 先天八卦（伏羲） | 后天八卦（文王） |
| --- | --- | --- |
| 方位 | 乾南坤北、离东坎西 | 震东春、离南夏、兑西秋、坎北冬 |
| 本质 | **对待（相错）**：乾⇔坤、坎⇔离，完全对称 | **流行（相生）**：顺时针循环，合四时运行 |
| 主 | 宇宙本体之理，"为体不动而含万化" | 气化流行的实用方位，"为用随气而变" |

邵雍总结：**"先天主对待（数之理），后天主流行（气之运）。"** 并用《周易·乾文言》"先天而天弗违，后天而奉天时"来印证——伏羲画卦暗合天道本体（天弗违），文王演易顺承气化流行（奉天时）。

> 这正是梅花易数"**先天数起卦、后天位断事**"的总源头——数字属于"对待之理"（先天），方位属于"流行之气"（后天）。

#### 必须破除的三大误解

| 常见误解 | 正解 |
| --- | --- |
| 先天八卦比后天八卦"更高级、更灵验" | 错。二者是**体用关系**，无后天则先天不显，无先天则后天无本，须合用 |
| 伏羲八卦在时间上早于文王八卦 | 错。不是历史先后，而是**逻辑先后**：理在气先、体在用先 |
| 这是纯玄学，与现代无关 | 错。它恰恰是现代"**区分第一性原理与具体应用**"的古老版本 |

#### 从体用到人生：定数与修为的辩证

**"先天"是人生的定数框架**：你生于何等门第、得何种禀赋、拥怎样的容颜体魄，皆为天地气化所成，是"气数"所定的**先天之体**——出身、天赋、时代大势，人力难改。

**"后天"则是人的选择与修为**：面对先天定数，如何看淡世事、修心养性、顺势而为，方是对自己最好的成全。**先天之体虽定，后天之用却由己掌。**

这正是邵雍"体用不二"的真谛，也是他留给后人最通透的人生智慧——**不是宿命论，而是"知命而不认命"**：

> 大事不可逆，人事犹可为；看清周期低谷则蛰伏，处高峰而知进退，永远不与天道硬碰硬。

> **关键心法**：邵雍说"先天之学，心也；后天之学，迹也"。这里"心"不是七情六欲的私心，而是包容天地、与太极同体的**宇宙本心**。认知上分清"体用"，实践上做到"体用合一"，这是读通全书的门槛。

### 12_6 观物三境与"以物观物"

《观物内篇》是《皇极经世》的灵魂，而"观物"则是灵魂的心脏。邵雍把"看世界的方式"分成了层层递进的三境——这是中国古代认识论的一座高峰。

> **"夫所以谓之观物者，非以目视之也，非观之以目而观之以心也，非观之以心而观之以理也。"**

| 境界 | 认识工具 | 看到什么 | 相当于 | 典型状态 |
| --- | --- | --- | --- | --- |
| **以目观物** | 感官（眼） | 表象、颜值、当下得失 | 形 | 被 K 线、新闻、表象牵着走 |
| **以心观物** | 心思（心） | 因果、趋势、人情 | 情 | 能控制情绪、三思后行，但仍有"我的滤镜" |
| **以理观物** | 天理（理） | 本质与规律 | 性 | 放下私心偏见，站在天地规律看万事 |

```latex
以目观物 ──────→ 以心观物 ──────→ 以理观物
 （庸人）          （智者）          （圣人）
   形               情               性

```

第一层是庸人，第二层是智者，第三层是圣人——邵雍毕生追求的境界。

#### "以物观物" vs "以我观物"：全书最锋利的一刀

> **"以物观物，性也；以我观物，情也。性公而明，情偏而暗。"**

+ **以我观物**：站在"我想要什么"的立场看，看到的不是事物本身，而是自己的投射。心理学叫它**确认偏误**（confirmation bias）。
+ **以物观物**：站在事物本身的规律上看，立场来自对事物本身的观察，而非"我想要什么"。

#### 一个绝佳的自我检验法

> **"假如是你最好的朋友来问你这件事，你会给他什么建议？"**

你替朋友分析时，自动就会看行业趋势、发展空间、成本收益对比，而不会说"我觉得你应该走/留"。**那个客观的建议，就是"以物观物"的答案。** 你给朋友能做到，给自己也该做到。

邵雍的"以物观物"与古罗马爱比克泰德的"人不是被事物困扰，而是被对事物的看法困扰"方向一致——但邵雍更狠：**他不只是说"别被情绪困"，而是说"换到事物那边去"**。这不是安慰，是方法。

> **小故事·同一件事，三层看法**

公司公布晋升名单，一个比他晚来两年的同事升了，他没有。
**以目观物**：他看到的只有"名单上没有我"。接下来一整周，他反复琢磨的是凭什么、公不公平、领导是不是有偏见——**只见表象与得失，情绪被牵着走。**
**以心观物**：过了几天他冷静下来，开始推因果：那位同事接了哪些项目、在哪些场合露过面、跟哪些部门建立了关系。**他看得出趋势了，但滤镜还在**——他想的是"我要怎么超过他"，而不是"这件事本身是什么"。
**以理观物**：再往后，他换了个问题：这个岗位真正需要的是什么能力？公司当下最缺的是什么？我手上的积累，和这个缺口之间差多少？
到这一层他才看清：那位同事恰好补上了公司新业务最缺的那块能力，而他自己的积累在另一条线上——不是他不行，是**供需不匹配**。
于是他做了两件事：一是补起那条新业务的底层能力，二是把手上的积累往能产生复利的方向挪。
**同一件事，三层看法，导出三个完全不同的行动。** 以目的人怨一周，以心的人谋划一周，以理的人重新定位自己。
邵雍说"非观之以目而观之以心也，非观之以心而观之以理也"——**不是让你不看，是让你往上走一层。**

> 这一思想直接启发了宋明理学的认识论走向，为"格物致知"提供了思维工具，也是陆王心学"心即理"的重要前奏。

### 12_7 皇帝王霸：权力的四种形态

邵雍把人类社会的治理形态，精炼为四种，对应一个文明从诞生到衰亡的序列：

| 等次 | 主体 | 核心 | 方式 | 对应 | 特征 |
| --- | --- | --- | --- | --- | --- |
| **皇** | 三皇 | **道** | 以道化民（化） | 春天·种子期 | 无为而治，与道合一 |
| **帝** | 五帝 | **德** | 以德教民（教） | 夏天·生长期 | 德性彰显，教化流行 |
| **王** | 三王 | **功** | 以功劝民（劝） | 秋天·成熟期 | 建立礼法，功业鼎盛 |
| **霸** | 春秋五伯 | **力** | 以力率民（率） | 冬天·收敛期 | 权术智诈，武力角逐 |

邵雍明言：**"天下将治，则人必尚义也；天下将乱，则人必尚利也。"** 治乱根本不在制度，而在统治者的心性与社会整体的价值导向。这最终回归到儒家的"**内圣外王**"——唯有修养心性、通达天道，方能天下大治。

#### 这不是简单的"退化论"

需要为邵雍"正名"：皇→帝→王→霸并非一味悲观的退化，而是**一个文明从诞生到衰亡的完整生命周期模型**。它揭示的是复杂系统难以逃避的**熵增规律**——从高度有序的"道"，逐步走向需要巨大能量维持的"力"。这是一种带着悲悯的宇宙洞察，而非简单的复古怀旧。

它的现代等价物，正是组织生命周期理论、制度衰变理论——任何系统都会从"文化驱动"走向"制度驱动"再走向"强权驱动"，识别自己所在的位置，才能对症施治。

### 12_8 思想史坐标与速读路线图

#### 思想史坐标：一座承前启后的孤峰

把邵雍放回思想史长河，才能看清他的独特价值：

+ **与北宋五子的关系**：周敦颐（太极图）、张载（气学）、二程（义理）、邵雍（象数）——**邵雍独辟"以象数贯通天人"一径**，与程朱的义理易学、司马光的史学路径鼎足而立
+ **对朱熹的影响**：朱熹吸纳其"天人相应"逻辑，将"修心修身"纳入"格物致知"体系，提出"穷理以尽性，尽性以知天"；并把先天图收入《周易本义》卷首，成为宋明易学标准范式
+ **对陆王心学的伏笔**：邵雍"心为太极""先天之学，心法也"的命题，被后人首称为"心学"；陆九渊、王阳明的思想亦可追溯至此
+ **对文人精神世界**：司马光变法失意后筑"独乐园"效仿邵雍"安乐窝"；明代"独抒性灵"、清代"难得糊涂"，皆是"身安心乐"修养境界的流风余韵

> **孤峰之评**：在中国思想史上，极少有一部著作试图为整个宇宙、全部历史编写一套统一的"操作系统"。《皇极经世》正是这样一座孤峰——**它的具体推演可以商榷，但它"用理性为复杂世界建立秩序"的雄心与方法，至今仍值得敬重。**

#### 案例小故事：元会运世能断个人吉凶吗

有人读完"元会运世"，立刻想把它用在个人占断上，问：我这一生处在哪个"运"？

这个用法是错位的。《皇极经世》的元、会、运、世是**宏观历史周期**的刻度，一"运"就是三百六十年，用来理解大势可以，用来断一个人的流年，刻度根本对不上。

它对梅花易数的作用在另一处：它提供了"观物"的立场——**以物观物**，即尽量不带私意、不把自己摆进结论里去看。这是心法，不是技法。

**落点**：观物是立场，不是技法。《皇极经世》教你的是"怎么不带私意地看"，不是"多了一套可以断事的尺"。

### 13_1 当决策训练：三层观物清单

抛开占验成分，梅花易数的训练对**日常决策**有三重真实价值：

| 训练 | 对应能力 | 日常怎么用 |
| --- | --- | --- |
| **三要训练**（耳、目、心） | 对偶然信息的敏感度 | 会议中捕捉"没被说出口的信息"：谁迟疑了、谁叹气了 |
| **体用生克** | 结构化的关系思维 | 任何决策先分清：什么是主体（我/我方），什么是环境（不可控因素），二者是生助还是压制 |
| **本互变时间轴** | 过程思维 | 不问"这事成不成"，改问"起始如何 → 中途会有什么变数 → 结局走向哪里" |

#### 决策前的三层自检表（可直接用）

| 层次 | 必答问题 | 常见陷阱 |
| --- | --- | --- |
| **看形（数据层）** | 我手上有哪些硬数据？（报表、薪资、合同条款） | 只看支持自己想法的数据（确认偏误） |
| **看情（动机层）** | 我的真实动机是什么？是恐惧、不甘，还是热爱？ | 把"沉没成本"当理由 |
| **看性（规律层）** | 如果最理性的朋友处在我的位置，他会怎么选？这件事 3 年后还重要吗？ | 用情绪代替规律 |

> **铁律**：三层答案冲突时，**以第三层的答案为准**。第一层易被表象骗，第二层易被情绪骗，唯有第三层接近"理"。

### 13_2 四季诊断法：判断任何事物的周期位置

**原理**：任何系统都有春夏秋冬——这是元会运世周期观的等价转换（思想源头见 `12_4`）。

**操作步骤**（适用于行业、公司、个人技能、关系）：

```latex
第1步 拿出一张纸，列出你关注的系统（如"我所在的行业"）
第2步 按四问定位季节
第3步 根据季节定策略

```

| 季节 | 特征 | 策略 |
| --- | --- | --- |
| **春天（爆发期）** | 需求刚起、规则未定、增长陡峭 | **抢占位置、大胆试错** |
| **夏天（鼎盛期）** | 格局成型、龙头确立、精细化 | **精耕细作、做深壁垒** |
| **秋天（衰退期）** | 增速放缓、头部内卷、利润变薄 | **停止扩张、储备粮草** |
| **冬天（沉寂期）** | 需求萎缩、普遍亏损、无明确方向 | **不折腾、专注学习、等待下一春** |

> **核心提醒**：**不要在冬天里付出夏天的努力**——那会累死还没结果。
>
> **定位季节时，务必用"以物观物"（看客观指标：增速、利润率、头部动向），而非"以我观物"（"我感觉这个行业还有机会"）。**

> **小故事·在冬天里过夏天**

一位做传统零售的朋友，行业已经连年下滑、头部都在关店，他却坚持"再撑一撑，加大投入就能翻身"，把积蓄全投进去装修新店。
结果新店开了不到一年就关了。
复盘时他才承认：当时所有客观指标（客流、客单价、同行关店数）都在往下走，**是他自己"感觉还有机会"**——这正是"以我观物"。
他的行业当时已经进入**冬天**。冬天的策略是"不折腾、专注学习、等待下一春"，而不是"抢占位置、大胆试错"。
**用夏天的打法过冬天，不是勇气，是浪费。** 看懂季节，比盲目努力重要一万倍。

### 13_3 "以物观物"决策协议：四步去自我化

**原理见 **`12_6`（认识论层面）。这一节是它的**操作化展开**——把"把我看掉"这件事变成四个可以照着做的动作。

把"以物观物"变成可执行的流程：

```latex
第1步 写下来
   把决策写在纸上（强迫从"脑内剧场"转到"客观对象"）
      ↓
第2步 角色互换
   假设你是你最好的朋友，替他分析这件事，写下建议
      ↓
第3步 证据反查
   列出"支持我做此事"和"反对我做此事"的证据各 5 条
   问自己：如果结论相反，这些证据会改变吗？
   （检验证据是否只是自我投射）
      ↓
第4步 时间透视
   这件事 3 天后还重要吗？
   3 个月后会影响我的生活吗？
   3 年后我还会记得它吗？

```

> 在人生的大尺度下，当下让你崩溃的事，绝大多数都不值一提。**这个方法专治焦虑型决策。**

> **小故事·给朋友提建议时，你从不说"我觉得你应该"**

有个很准的观察：朋友来问你该不该跳槽，你会怎么答？
你会问行业趋势、发展空间、薪资结构、通勤成本、家庭安排，然后说："从这些条件看，留下来对你更有利。"
你几乎不会说："我觉得你应该走。"
但同样的问题放在自己身上，很多人脱口而出就是"我觉得""我想要"——**因为自己站在"我"里面，朋友站在"我"外面**。
邵雍的办法极其朴素：**把自己换成自己的朋友，问一遍。**
那个客观的建议，就是"以物观物"的答案。你给朋友做得到，给自己也该做得到。

### 13_4 "先天—后天"可控性拆解表

**原理**：先天之体虽定，后天之用由己掌——体用框架的人生应用，哲理依据见 `12_5` 的"定数与修为"。哲理依据见 `12_5` 的"定数与修为"，这一节是它的表格化落地。

**操作**：面对任何困境，先做"可控性拆解"：

| 先天（定数·不可改） | 后天（变数·可为） |
| --- | --- |
| 出身、时代大势、禀赋、已发生的过去 | 选择、努力、修为、当下起的反应 |
| 行业周期位置、宏观经济 | 在哪个细分深耕、如何提升能力 |
| 他人的性格与选择 | 自己如何回应、设何种边界 |

**用法**：把焦虑的事一项项填入。

+ 凡落入**左栏**者 → **接纳、顺势、不硬碰**
+ 凡落入**右栏**者 → **立刻行动、全力而为**

> **多数人痛苦的根源，正是把"后天"的事当成"先天"认命，或把"先天"的事当成"后天"白费力气硬扛。**

> **小故事·两栏都填错了**

有人因为同事一句难听的话，整整一周睡不好，反复琢磨"他为什么要这样对我"。
把这件事丢进拆解表：**他人的性格与选择**在左栏，"自己如何回应、设何种边界"在右栏。
他痛苦了一整周的那件事，其实一直在左栏——别人的嘴，他改不了。而他本该做的事（右栏：要么沟通、要么设边界、要么无视），一件都没做。
反过来也有另一种人：出身普通、行业下行，却把所有精力用来抱怨"大环境不好"。这也是填错了栏——大环境确实在左栏，但"在哪个细分深耕、如何提升能力"在右栏，他一件都没动。
**分清两栏，焦虑至少减一半。**

### 13_5 "皇帝王霸"识人矩阵：一眼看透领导与组织

**原理**：皇帝王霸是权力的四种形态，也是领导风格的四种类型。

把你的上级、团队负责人、合作对象对号入座：

| 类型 | 特征 | 你的策略 |
| --- | --- | --- |
| **皇（魅力·道）** | 无为而治，靠愿景与人格引领，团队自驱 | 值得长期追随，珍惜空间、主动担责 |
| **帝（制度·德）** | 建立体系与文化，重视规范与成长 | 可长期发展，按规则做事、借体系成长 |
| **王（务实·功）** | 结果导向、赏罚分明、仁义有度 | 用实力说话，交付结果换取回报 |
| **霸（压榨·力）** | 画饼甩锅、权术操控、只讲输赢 | **尽早规划离开**，或用业绩换报酬、不谈理想 |

> 这个工具不只用于"看领导"，更用于**自省**：你自己在带团队时，正处在哪一档？从"霸"向"王"、再向"帝""皇"演进的路径，就是领导力的修炼方向。

### 13_6 观物日常微习惯：把心法变成肌肉记忆

邵雍之学不玩虚的，全部能落地日常生活：

+ **看人看结果，不看态度**："我感觉他不错"是"以我观物"；"他能不能把事做成"是"以物观物"
+ **遇问题先问"哪里错、为什么、怎么改"**，而非"谁气我、怪谁"
+ **学习中以"讲得清、能举一反三"为会**，而非"书看完了""我很努力"。**眼观、心观、理观三层，落在第三层才算真会**
+ **顺境知退、逆境知守**：处高峰则备退路（阳极阴生之理），处低谷则积厚（一阳来复之机）

> **进阶心法（邵雍《即事吟》）**："就新须果敢，从善莫因循。"——既有顺应时势的魄力（后天之用），又有不随波逐流的定力（先天之体）。在"变"与"守"的动态平衡中，方能抵达"安处是行身"的从容。

### 13_7 速查手册（建议打印随身）

> **说明**：本小节是全库**唯一刻意保留的重复**。前面的正文负责"讲透"，这八张卡片负责"查得快"——按设计就是要能打印成 A4 双面、塑封随身。前期必须靠查，查多了自然记住。

#### 卡一：起卦与取余

```latex
卦以八除，爻以六分
求卦：÷8 取余，余 0 → 取 8（坤）
求爻：÷6 取余，余 0 → 取 6（上爻动）

时间起卦：上=(年+月+日)÷8 余
          下=(年+月+日+时)÷8 余
          爻=(年+月+日+时)÷6 余
          ※ 年用农历地支序数，月用农历月，时用十二时辰序数

端法起卦：上=人物/物象之卦；下=方位之卦；爻=(上数+下数+时数)÷6 余
数字起卦：前数上卦，后数下卦，两数和÷6 为动爻（报三数则第三数直接÷6）

```

#### 卡二：先天数与后天位

| 卦 | 乾 | 兑 | 离 | 震 | 巽 | 坎 | 艮 | 坤 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **先天数** | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

#### 卡三：五行生克与通关

```latex
相生：金→水→木→火→土→金
相克：金→木→土→水→火→金

通关：金克木→水 │ 木克土→火 │ 土克水→金 │ 水克火→木 │ 火克金→土

> **体例说明**："通关"是五行生克的通用化解说法，**《梅花易数》原书未立此名目**。
> 原书对克局有救的表述是**看变卦能否生体**（如观梅占「幸变为艮土，兑金得生」）。
> 本卡保留"通关"作一般五行释义，但断卦时当以"变卦是否生体"为据。

```

### 13_9 三条可以随身携带的原则

对今天的读者而言，最珍贵的遗产不是那些具体的卦气推演，而是这三条：

```latex
第1步 分清体用 —— 区分什么是根本（先天 / 第一性原理），
                什么是应用（后天 / 具体方法），永远先立其体，再用其用

第2步 识得周期 —— 任何事物都有春夏秋冬，看清季节比盲目努力重要一万倍

第3步 以物观物 —— 把"我"从判断里拿掉，让事物的本来面目自己说话

```

这三条原则，横跨宇宙论、历史哲学与日常决策，正是"皇极经世"四字在当代的真正回响。

#### 案例小故事：三年之后，他回到了最初三条

一位研习者学了三年，工具箱塞得满满的：卦气、互变、十应、外应、克应、应期、射覆，能用上的他都用了一遍。

有一次他被人问：你现在断一卦，脑子里第一个动作是什么？他想了很久，答：看卦象。第二个？看旺衰。第三个？才轮到应期和克应。

他意识到，这三年加进来的所有方法，都没改变那个优先级——**卦象 → 旺衰 → 细节**，只是把最后那一层填得更满了。

他后来说：从术到道不是加更多方法，是把优先级刻进本能。方法多而顺序乱，比方法少而顺序清更危险。

**落点**：融会贯通的标志，不是"会的方法变多"，而是"优先级不再需要回想"。顺序清楚，方法才有意义。

#### 结语：数里有理，理外无心

《梅花易数》最容易被误读成一本"对表查吉凶"的密码本，但它的精髓恰恰相反——

**卦象是死的，当下之机是活的，断卦的人心是枢纽。**

+ **先天数**给你秩序
+ **万物类象**给你词汇
+ **体用生克**给你语法
+ **三要十应、动静坐端**要你真正"在场"

所谓"在场"，是三件事：

```latex
第1步 对眼前偶然保持敏感（耳、目、心三个通道常开）
第2步 对自身直觉保持诚实（第一念就是第一念，不事后修饰）
第3步 对结论保持不执着（卦说的是"若按此轨迹发展"，不是"命中注定"）

```

> **数里有理，理外无心，心上无执——这才是"心易"二字真正的落点。**

> **最后的提醒**：本库宜"得其意而忘其象"。若陷入具体卦气、声音律吕的数字迷宫，反而离邵雍的真意越来越远。**观物之要，在观其理，不在数其爻。**
