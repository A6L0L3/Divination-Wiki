## 板块3 · 万物类象：断卦的词汇库

> **类象是词典，体用是语法，外应是语气。**

三样都熟了，断卦就像说话一样自然。

---

### 3_1 类象的本质：为什么八卦能代表万物

起卦容易断卦难。三分钟能出一个卦，但出了卦之后怎么断？八成新手卡在这里。

**断卦靠三样东西：万物类象（八卦对应什么）、体用生克（你和事情的关系）、外应（此刻环境说了什么）。**

类象的来源，是《易传》说的"**近取诸身，远取诸物**"——先哲观察天地万物，把具有相似"气质"的事物归到同一个卦下。所以类象不是任意规定，而是**按性质聚类**：

+ 乾为天，所以凡**刚健、在上、圆满、贵重**之物皆归乾：君、父、首、金玉、马、圆物
+ 坤为地，所以凡**柔顺、承载、在下、方正**之物皆归坤：母、腹、布帛、牛、田野
+ 坎为水，所以凡**陷、隐、流动、险**之物皆归坎：沟渎、盗贼、耳、酒、弓轮

理解了这个原理，遇到古代没有的东西（手机、飞机、电梯）也能**按性质归类**，而不是死记硬背——这正是"卦理"高于"死象"的地方。

#### 八卦家庭关系口诀（断人物身份时用）

> **乾父坤母，震长男，巽长女，坎中男，离中女，艮少男，兑少女。**

#### 近取诸身 / 远取诸物（两组最常用口诀）

```latex
【身】乾头、坤腹、震足、巽股、坎耳、离目、兑口、艮手
【物】乾马、坤牛、震龙、巽鸡、坎豕、离雉、艮狗、兑羊

```

### 3_2 八卦核心三象速记法【必背】

每个卦先只记三个最有代表性的象：**天文 / 人物 / 身体部位**。这三象熟了，其余慢慢扩充。

| 卦 | 天文（气质） | 人物（身份） | 身体（部位） | 一句话气质 |
| --- | --- | --- | --- | --- |
| **乾 ☰** | 天 | 君、父、领导 | 头 | 刚健、贵重、圆、在上 |
| **兑 ☱** | 泽 | 少女 | 口 | 喜悦、破损、开口、口舌 |
| **离 ☲** | 火、日 | 中女、文人 | 目 | 光明、虚荣、中空、文书 |
| **震 ☳** | 雷 | 长男 | 足 | 动、惊、声响、启动 |
| **巽 ☴** | 风 | 长女 | 股 | 入、顺、细长、进退不定 |
| **坎 ☵** | 水、月 | 中男 | 耳 | 险、陷、隐伏、流动 |
| **艮 ☶** | 山 | 少男 | 手 | 止、静、阻滞、隆起 |
| **坤 ☷** | 地 | 母、众人 | 腹 | 柔顺、承载、方正、虚 |

### 3_4 取象三原则：不硬套，才叫活

类象死记硬背、一成不变，是第二大常见错误（第一是体用颠倒）。原书明确反对"乾一定代表父亲"这类死板用法。

#### 原则一：先看求测什么事——问题决定取哪个象

同一个乾卦，在不同问题下取完全不同的象：

| 所问 | 乾取何象 |
| --- | --- |
| 问事业 | 领导、权力、职位 |
| 问求财 | 金玉、钱财、贵重物品 |
| 问健康 | 头、骨、肺 |
| 问人物 | 父亲、老人、领导 |
| 问失物 | 金属、圆形物、高处、西北方 |

> **一个卦有几十种类象，只选和问题最相关的三到五种。** 全用等于没用。

#### 原则二：看旺衰——卦旺取吉象，卦衰受克取凶象

| 卦的状态 | 取象方向 |
| --- | --- |
| 旺相 | 取其尊、贵、成、全之象（乾为珠宝、为领导） |
| 休囚死 | 取其衰、残、缺、废之象（乾为老翁、为寒凉、为无用之金属） |
| 受克 | 取其受损之象（离受水克 → 文书受损、眼睛疾病、光明受阻） |

**实例**：占求职，本卦用生体本是吉；但起卦瞬间看见**枯萎树木**（木之衰象，泄气之兆），则断"能入职，但薪资低、工作压抑"，并非大吉。

#### 原则三：上下两卦组合取象——单卦信息有限，两卦叠加才读出场景

这是从"会背类象"到"会断卦"的关键一跃。

| 组合 | 叠加出的场景 |
| --- | --- |
| 上乾下坤（天地否） | 天在上、地在下，二气不交。问合作 → 难成；问稳固 → 安泰 |
| 上坤下乾（地天泰） | 地气上升、天气下降，交泰通达 → 通顺、和合 |
| 上坎下离（水火既济） | 水上火下，相交为用 → 事可成，但"初吉终乱" |
| 上离下坎（火水未济） | 火上水下，不相为用 → 事未成，尚在变化中 |
| 上兑下巽（泽风大过） | 泽灭木 → 过度、负担过重，需变通 |
| 上艮下坤（山地剥） | 山附于地，剥落 → 衰败、守正待时 |

**练习**：取"上离下坎（未济）"，问"项目能否推进"，试着用叠加法说出三层含义：

```latex
第1步 火水不交，力量使不到一处
第2步 离为文书宣传、坎为险陷 → 宣传遇阻
第3步 未济非不可成，是时机未到

```

> **小故事·同一个乾卦，三个答案**

三个人同一天来问，卦上都出现了乾。
第一位问**升职**，断"有贵人，是位有权威的长辈在推你"——乾取"领导、权威人物"。
第二位问**丢的钥匙在哪**，断"在金属器物旁，或家里高处、西北角"——乾取"金属、高处、西北方"。
第三位问**父亲的体检报告**，断"重点看头部与骨骼"——乾取"头、骨"。
三个人拿到的是同一个卦，答案完全不同。**同一个乾卦有几十种类象，只选和"所问何事"最相关的那三五个。** 全用等于没用。

### 3_5 现代事物的归类训练

古代没有手机、电脑、电梯、飞机。若只会死背古象，遇到现代事物就断不了。**归类方法是：按气质归，不按形制归。**

#### 归类三步法

```latex
第1步 问性质：它是动的还是静的？硬的还是软的？发光的还是盛物的？
第2步 问功能：它做什么用？沟通？承载？切割？照明？
第3步 问位置：它在高处还是低处？室内还是室外？随身还是固定？

```

#### 常见现代事物归类参考

| 事物 | 归卦 | 理由 |
| --- | --- | --- |
| 手机 | 离（主）/ 巽 | 离为发光、为信息显示；巽为通讯、为入、为信号 |
| 电脑 | 离 / 乾 | 离为屏幕、文书；乾为贵重、为高端科技 |
| 电梯 | 巽 / 坎 | 巽为升降、为入；坎为升降之井、为险 |
| 飞机 | 乾 / 巽 | 乾为天、为在高处；巽为风、为飞行 |
| 高铁 | 震 | 震动、声响、疾行 |
| 摄像头 | 离 | 目之延伸、为光明与影像 |
| 网络/信号 | 巽 | 风行无形、无处不入 |
| 空调 | 巽 / 坎 | 巽为风；坎为寒凉、为水（制冷） |
| 银行卡 | 乾 / 坤 | 乾为金玉财物；坤为布帛、为承载（账户） |
| 快递包裹 | 坤 / 艮 | 坤为包裹承载；艮为块状、为门阙（收件） |
| 手术 | 兑 / 离 | 兑为刀刃、为破损；离为血、为火（消毒） |
| 合同文书 | 离 / 巽 | 离为文书；巽为契约、为绳直 |
| 直播/短视频 | 离 | 明丽、展示、虚荣、面向大众 |
| 充电桩 | 离 / 震 | 离为电；震为动、为能量启动 |

> **训练法**：每天挑 3 件身边物品，按三步法归类，并写出"我还可以把它归为哪个卦，为什么"。**一个物品能归多个卦，正是类象"活"的体现**——具体取哪个，由"所问何事"决定。

**自测**：试着给"无线耳机"归类，并说出两种可能的卦及理由。

```latex
参考思路：
离 —— 播放声音、有光显、贴在耳上随身的电子设备
巽 —— 无线信号"入"耳、细长轻软之物
取哪个，取决于你问的是"耳机能不能修好"（离，看电子器件）
还是"信号会不会断"（巽，看连接是否通畅）

```

#### 案例小故事：取错了象：从"坤为母"到"坤为承载"

有人问合作能不能成，卦中见坤，他翻类象表：坤为母、为布、为釜、为吝啬，一条条套下去，越套越乱，最后什么也没断出来。

换一个取法就通了：坤的**关系属性**是柔顺、承载、迟缓、由对方主导。放进"合作"这件事里，读作"能成，但节奏慢、主导权在对方"。

事后反馈：合作确实成了，但谈判拖了两个月，条件基本由对方给。

问题不在类象太少，在他取的是"名物清单"而不是"关系属性"。

**落点**：万物类象要取**关系属性**（刚柔、动静、显隐、迟速），不要取**名物清单**。清单是背的，属性是用的。
