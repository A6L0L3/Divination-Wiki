## 板块5 · 断卦引擎：体用生克与完整流水线

> **起卦只是"翻译"，真正的功夫在断。这一板块是全库的心脏。**

---

### 5_1 排本卦、互卦、变卦

#### 本卦

起出的原卦，六个爻。代表事情**起始、当下状态**。

#### 互卦（关键，八成新手会取错）

```latex
下互卦 = 本卦的 2、3、4 爻
上互卦 = 本卦的 3、4、5 爻

```

即：**去掉初爻和上爻**，中间四爻"剥"出两个三爻卦——下面三个（234）成下互，上面三个（345）成上互。

> **记忆法**：互卦是本卦"剥出来的内核"，掐头去尾，中间的四个爻两两共用第 3、4 爻。

#### 变卦

动爻的阴阳互换后得到的新卦。代表**最终结果、趋势走向**。

> **前提提醒**：取互卦、变卦都要逐爻推演，而八卦符号**一律从下往上数**（乾☰阳阳阳、坤☷阴阴阴，其余六卦见 `2_1`）。最易记反的两对是兑☱（阳阳阴）与巽☴（阴阳阳）、震☳（阳阴阴）与艮☶（阴阴阳）。

#### 演算示例：泽火革，初爻动（即观梅占，务必手推一遍）

```latex
本卦 泽火革 = 上卦兑☱（九四阳、九五阳、上六阴）＋ 下卦离☲（初九阳、六二阴、九三阳）
本卦六爻自下而上：阳、阴、阳、阳、阳、阴

【变卦】初爻动 → 初九由阳变阴 → 下卦离☲（阳阴阳）变为 艮☶（阴阴阳）
       → 变卦 = 上兑下艮 = 泽山咸

【互卦】下互 = 2、3、4 爻 = 六二阴、九三阳、九四阳 = 阴阳阳 = ☴ 巽
       上互 = 3、4、5 爻 = 九三阳、九四阳、九五阳 = 阳阳阳 = ☰ 乾
       → 互卦 = 上乾下巽 = 天风姤（即古案所说"互见乾、巽"）

```

> **核对观梅占**：古籍原文正是"互见乾、巽"。巽为股，被乾金、兑金夹克，这才是"伤股"的象源。若误取为"互见乾、兑"，类象链条就断了。
>
> **实操铁律**：取互卦时**先把本卦六爻从下到上逐爻写出来**，再掐头去尾取中间四爻。不要凭符号印象直接跳到结果。

#### 互卦的三条使用规则

1. 互卦代表**中间过程、隐情、暗流**
2. 互卦**不再分体用**——只看它对**体卦**的生克作用
3. 体卦在上卦时，上互为"体互"、下互为"用互"；体卦在下卦时则反过来。**体互最紧，用互次之**

### 5_2 定体用（最关键的一步，错则满盘皆输）

#### 基本口诀

> **"动爻所在便为用，安静之卦体来充。"**

| 动爻位置 | 用卦 | 体卦 |
| --- | --- | --- |
| **1、2、3 爻动** | 下卦 | 上卦 |
| **4、5、6 爻动** | 上卦 | 下卦 |

#### 记忆法

> 动爻在一二三（下卦三爻）→ **下卦动 → 下卦为用**；

动爻在四五六（上卦三爻）→ **上卦动 → 上卦为用**。

**最常见的错误**：以为"上卦永远是体卦"。**错。动爻在哪卦，哪卦就是用。**

起卦后应第一时间确认动爻位置，然后**默念一遍"动爻在某卦，某卦为用"**，确认无误再往下走。

#### 特殊情况处理表

| 情况 | 体用判定 | 出处 |
| --- | --- | --- |
| **静卦（六爻皆不动）** | 自测心事：上卦为体，下卦为用。测他人外物：下卦为体，上卦为用。完全依靠五行生克 + 旺衰 + 外应判断，**不需要动爻** | **后世通行推法** |
| **上下卦皆动**（多爻动） | 问自身：内卦（下卦）为体、外卦（上卦）为用。问他人：外卦为体、内卦为用 | **后世通行推法** |

> **原文校准**：《梅花易数》的「卦以八除／爻以六除」恒得**单一动爻**，
> 原文只说「若一爻动，则看此一爻，是阳爻则变阴爻，阴爻则变阳爻」，
> **未设"静卦"与"多爻动"的条文**。上表两行是后世为处理边缘情况补入的通行推法，
> 可参用，但应记作**补法而非原典**。若严格按原典操作，梅花体系不应出现静卦。

**体用判定的两条优先规则**：

| 情况 | 体用判定 |
| --- | --- |
| **主客关系明确时** | **以主客为准，铁律优先**：我 / 求测者 = 体；彼 / 所问之事 = 用 |
| **代他人占** | 以"所问的那个人"为体，不以自己为体 |

> **静卦的含义**：六爻安静，不是"卦无效"，而是**事情当下格局稳定、短期内不会发生大变动**。这是一个确定的信息，不是没有信息。

> **小故事·一句默念，救回一整卦**

有人问自己这次资格考试能不能过。卦起出来，动爻在第 5 爻，他想当然地把上卦当成了体——上卦被下卦所克，于是他垂头丧气地断："悬，怕是要挂。"
幸好他前一天刚学过一条规矩：**起卦后必须先默念一遍"动爻在某卦，某卦为用"**。他念了一遍，猛然发现：动爻在 5 爻，属于上卦三爻，**上卦才是用**，下卦才是体。
改正之后重断：**体克用**——能成，但要下苦功夫啃，不是轻松过。
应期落在体卦当旺的时日，正好是他备考冲刺能见效的那段时间。他照着那个节奏复习，最后压线通过。
事后他在卦例本上写了一行字：**"卦没错，是我把主客念反了。"**
体用一颠倒，吉凶正好反过来。这一步不费脑子，费的是**愿不愿意多念那三秒钟**。

### 5_3 体用生克五格局（定性）

以**体卦**为中心，看用卦对它的五行作用。

| 关系 | 含义 | 吉凶 | 现实比喻 |
| --- | --- | --- | --- |
| **用生体**（事生我） | 外力相助、顺遂省力 | **有进益之喜** | 贵人主动找上门，推着你走 |
| **体用比和**（同五行） | 同心协力、无阻力 | **百事顺遂** | 同频共振，水到渠成 |
| **体克用**（我克事） | 能成但需费力克服 | **诸事吉**（辛苦成） | 你得亲自上山打虎，打得赢但累 |
| **体生用**（我生事） | 付出、耗神耗财 | **有耗失之患** | 你不断往里贴钱贴时间 |
| **用克体**（事克我） | 阻力大、被压制 | **诸事凶** | 逆水行舟，处处受阻 |

#### 原典原文（《梅花易数·体用总诀》）

> **体克用，诸事吉；用克体，诸事凶。体生用，有耗失之患；用生体，有进益之喜。体用比和，则百事顺遂。**

> **原文校准**：原典只分"吉 / 凶 / 耗失 / 进益 / 顺遂"五义，**未分"大吉／小吉"等级**。
> 本库此前把"体克用"降为"小吉"、"体生用"降为"小凶"，是后世的细化，
> 原典对"体克用"的判词是**「诸事吉」**，不含"小"义。现按原典改正，等级差异另见旺衰定量一节。

#### 一句话总诀

> **生我者吉，克我者凶，我生者耗，我克者劳。**

#### 精简速记版

```latex
生我则顺，我生则虚；
我克稍顺，克我多阻；
比和无事，中正相宜。

```

#### 进阶：紧缓次序（权重排序）

原书明确指出：**用卦最紧，互卦次之，变卦又次之。**

```latex
即时应  ← 用卦（当下直接作用）
中间应  ← 互卦（过程与隐情）
终  应  ← 变卦（最终走向）

```

**看互卦时再分一层**：体互最紧，用互次之。

### 5_4 参旺衰（定量：给吉凶"加权重"）

**生克只定"性质"，旺衰定"轻重"。** 这是从"会断"到"断准"的分水岭。

#### 判断步骤

```latex
第1步 确定起卦时的月令（季节五行）
第2步 查旺衰表，得出体卦的旺相休囚死
第3步 同样查出用卦的旺相休囚死
第4步 按加权对照表加权

```

#### 加权对照表（务必逐条对照）

| 基本关系 | 本为 | 加旺衰后 |
| --- | --- | --- |
| **用生体** | 吉 | 用旺相 → **吉上加吉**；用休囚死 → **虽吉不大**（病弱贵人，心有余力不足） |
| **体生用** | 小凶 | 体旺 → **泄而无大碍**（富翁施舍，散点财）；体衰 → **大凶**（贫病交加再献血） |
| **体克用** | 小吉 | 体旺用衰 → **克之轻松，大吉**；体衰用旺 → **病夫撼山，吉转凶** |
| **用克体** | 凶 | 用旺体衰 → **克力最猛，大凶**；用衰体旺 → **凶中有救** |
| **比和** | 吉 | 体用皆旺 → 顺畅有力；皆衰 → 平淡无成，守成而已 |

#### 时间尺度的选取

| 事之长短 | 看什么 |
| --- | --- |
| 长期事（数年） | 看**年令** |
| 中期事（婚姻、事业，数月） | 看**月令** |
| 当日事（招标、签约、会面） | 看**日令** |
| 一时之事（即刻、一小时） | 看**时令** |

#### 一个必须记住的反例（旺衰可以推翻生克）

冬天有人问病，得**用卦离火、体卦坤土**，火生土，"用生体"看起来是吉。但邵雍断**不吉**——因为**冬月火死，生土无力，如炭火将熄，难暖大地**。后果然病重。

```latex
体 = 坤土，用 = 离火
生克关系：火生土 → 用生体 → 表面"吉"
旺衰校正：冬月 → 火"死" → 生土无力
最终结论：不吉（炭火将熄，难暖大地）

```

> **这就是"论卦不论气，则局于象，昧于时"**——只看卦名生克，不看时令旺衰，是第三大常见盲区。

（此案的完整故事见 `2_5` 的"冬天的炭火"，此处作为"旺衰推翻生克"的标准范例保留。）

### 5_5 看互变：过程、结局与通关救应

#### 互卦：看中段

+ 互卦中**有生体之卦** → 中途有人暗中相助
+ 互卦中**有克体之卦** → 中途有暗阻、隐忧
+ **体互最紧，用互次之**

#### 变卦：看结局

+ 变卦**生体、比和** → 终吉
+ 变卦**克体** → 末后有不吉
+ 本卦吉但变卦克体 → **先好后坏**
+ 本卦一般但变卦生体或比和 → **坚持可好转**

#### 通关救应

**体用相克时，立刻看互卦：互中若出现通关五行，凶局有解。**

**实例**：体乾金，用离火（火克金，本凶）。若互卦见坤或艮土，则火生土、土生金，转克为生，**凶中有救**。

这正是观梅占"**伤股而不至于死**"的精确分寸所在。

> **小故事·克我的那个人，其实是来帮我的**

有人问一个重要合作能不能谈成，卦上是"用克体"——按表一查，阻力大、被压制，看着就不妙。他当场脸就白了，以为这事要黄。
带他复盘的人没有急着下结论，而是按规矩往互卦里看了一眼：**互卦里出现了一个土**。
用卦是火，体卦是金。火克金，本来是死局。但火生土、土生金——这"一土"夹在中间，把克局接成了生局。
于是断语改了：**有阻力，但阻力会被中途一个环节化解，最终能成，只是过程绕。**
后来的实情是：对方的法务部门（那道"火"）确实把方案打回来两次，但最终是对方一位中间协调人（那道"土"）出面，把条款重拟了一遍，合同签了下来。
他事后感慨："那道'火'是真的，那道'土'也是真的。要是我只看第一眼就放弃，这笔合作就真的黄了。"
**体用相克，先别急着判死刑——看一眼互卦有没有通关。这一眼，往往就是"凶"和"凶中有救"的分界线。**

#### 生克链的"真"与"假"

同样要看量级：

| 情况 | 判断 |
| --- | --- |
| 秋天兑金克震木（金旺木死） | **真克**，凶性实 |
| 春天兑金克震木（木旺金囚） | **假克**，克不动，小波折而已 |
| 体卦旺相遇克 | 有惊无险 |
| 体卦休囚遇克 | 真凶险 |

### 5_6 看爻位：动爻落在哪一层

前面四节解决了"吉凶如何、轻重如何、过程如何"。但还有三个问题没答：**这事发生在哪？跟谁有关？发展到哪一步了？**——答案在**爻位**里。

爻位就是给卦里六个角色排的"座位表"。**六爻中，下卦（内卦）是一二三爻，上卦（外卦）是四五六爻**，自下而上对应三个维度：

| 爻位 | 空间 / 身体 | 人物 / 身份 | 事情的发展阶段 |
| --- | --- | --- | --- |
| **初爻** | 地基、脚下、本地、农村、足部 | 百姓、平民、小孩、新入职员工、子孙 | **萌芽期**：刚开始、还在酝酿、力量微弱 |
| **二爻** | 宅内、厨房、腿膝、乡镇 | 乡绅、科级或处级、家中主妇（宅主） | **发展期**：崭露头角，开始行动 |
| **三爻** | 门口、床边、大腿腰腹、县市级 | 县市主官、中层干部、兄弟（竞争之位） | **转折 / 瓶颈期**："三多凶"，进退两难 |
| **四爻** | 大门外、胸腹、省城、外地 | 大臣、高管、副总、近君之臣 | **扩张期**：进入新环境，伴君如伴虎 |
| **五爻** | 路上、道路、颈面、京城 | 君王、老板、一把手、顶梁柱 | **鼎盛期**："五多功"，最辉煌阶段 |
| **上爻** | 屋顶、远处、边疆、海外、头部 | 退休老领导、顾问、祖先、宗庙 | **衰退 / 结束期**：物极必反，该收尾了 |

#### 动爻断事诀（可直接背）

```latex
一爻初动势初起，根基未固莫强行。
二爻微动局势明，稳步开展路方平。
三爻多阻生反复，中途停滞事难舒。
四爻迁变离本位，改弦易辙方有为。
五爻主事临尊位，大势已成扬美誉。
六爻终动势收官，功成身退避盈亏。

```

#### 三条实战用法

| 场景 | 看法 |
| --- | --- |
| **测升职** | 动爻在**五爻**且生克吉利 → 老板（五爻）看重你，事可成 |
| **测阻力来源** | 动爻在**三爻**且克体 → 直接上司或平级同事在使绊子 |
| **测阶段** | 动爻在**上爻** → 一个阶段已到尽头，该总结、该退场、该换路（不一定是坏结果，但一定是"到这里了"） |

> **与体用的关系**：爻位**不改变**体用生克定下的吉凶，它只回答"**在哪、跟谁、到了哪一步**"。先定性，再用爻位细化，顺序不能颠倒。

### 5_7 卦象直读：一针见血的捷径

有些卦一出来就能直接读出答案，**连体用旺衰都不用排**。这不是玄，是三条固定的直读路径。

#### 路径一：把组合卦整体类比某个经卦（大象）

| 组合卦 | 直读成 | 理由 |
| --- | --- | --- |
| 雷山小过 | **大坎** | 中间两个阳爻被上下阴爻包围，像"阳陷阴中" |
| 山雷颐 | **大离** | 外实中空，像离之"外刚内虚" |
| 地泽临 | **大兑** | 上坤下兑，泽在地上，开口之象放大 |
| 风泽中孚 | **大离** | 中空之象 |

#### 路径二：把组合卦类比某个常见物体

+ **火风鼎**：卦形就像古代的鼎
+ **风地观 / 山地剥**：像山洞、桥洞、门洞
+ **山火贲**：山下有火，像被照亮、被装饰的外表，引申为"文饰、包装"

#### 路径三：以卦意叠加类比事物（用得最多）

| 组合 | 直读 | 拆解 |
| --- | --- | --- |
| 泽天夬 | **缺钱** | 兑为缺 + 乾为钱 |
| 雷火丰 | **文书动** | 震为动 + 离为文书 |
| 泽火革 | **喝红酒** | 兑为喝 + 离为红 |
| 泽火革 | **烧鸡 / 火锅** | 兑为鸡、为锅 + 离为火 |
| 天山遁 | **手脚有伤 / 出走** | 乾为骨、艮为手、遁为逃 |

> **一个主卦能读出多层细节**：问午饭得"泽火革"，可依次直读出"喝红酒""吃烧鸡""吃火锅"——三层都成立，因为兑（喝/鸡/锅）与离（红/火）的组合本就有多种合理叠加。

#### 两条使用注意

1. **不要刻意追求直读**。有些卦可以直读，有些必须回到体用套路。**能直读就用，读不出就老实排体用。**
2. **先入为主**。同一卦能直读出许多象，**第一个冒出来的那个最接近真相**——这与外应的"第一念"是同一条心法。

### 5_8 错卦与综卦：换角度看问题（备用视角）

当本卦信息模糊、指向不明时，还有两个备用视角可用。**它们不占独立的吉凶层级，只是"换个角度看同一件事"。**

#### 定义

|  | **错卦**（对卦、旁通卦） | **综卦**（覆卦、反卦） |
| --- | --- | --- |
| **做法** | 六爻**全部阴阳互换** | 整个卦**旋转 180 度**（上下颠倒） |
| **例** | 乾↔坤、坎↔离、雷风恒↔风雷益 | 屯↔蒙、姤↔夬、雷山小过↔风泽中孚 |
| **含义** | 站在**对立面**看这件事（对方怎么想、反面是什么） | 把事情**倒过来看**（换位、时序反转） |

#### 用法

正断不明时，起一个错卦看"**对方的立场**"，起一个综卦看"**如果我是对面会怎样**"。

> **重要边界**：二者是辅助视角，**不改变本卦体用定下的吉凶**。它们是"换个角度想问题"的工具，不是第二个结论来源。

### 5_9 断卦主干七步与优先级

#### 主干七步（实操必背流水线）

```latex
第1步 排本互变 → 第2步 参爻辞（原典断吉凶之首）
→ 3. 定体用 → 第4步 断生克（定性主干）
→ 5. 参卦气旺衰（定量）→ 6. 看互变（过程与结局）
→ 7. 取类象（落到人事）→ 8. 参克应（外应）→ 9. 定应期

备用视角（非《梅花易数》原文，借自六爻与易学旁支）：爻位 / 卦象直读 / 错卦综卦

```

#### 断卦优先级（冲突时以此为准）

```latex
第1步 参爻辞 → 第2步 体用生克 → 第3步 卦气旺衰
→ 4. 互变（过程与结局）→ 5. 万物类象 → 6. 克应（外应）→ 7. 应期

备用视角（不占层级）：爻位 / 卦象直读 / 错卦综卦

```

> **体例说明（原文校准）**：《梅花易数·占卜总诀》原文为「成卦之后**先看《周易》爻辞，以断吉凶**。**次**看卦之体用，以论五行生克。**又次**看克应——如闻吉说、见吉兆则吉，闻凶说、见凶兆则凶；见圆物事易成，见缺物事终毁之类——**必须以易卦为主，克应次之**」。本库此前把爻辞置于最末，与原典相反，现按原典改正。

> **关于"爻位""错卦""综卦"**：《梅花易数》全书未设此三法（原书无"爻位""错卦""综卦"条目）。
> 它们出自六爻体系（如《易隐》的"鬼谷分爻""黄金策分爻"）与一般易学。**可作为旁参，但不入原典层级**；
> 用时须自记"此为旁参"，不要与原典七步混为一谈。

> **最常见的顺序错误**：先看爻辞，后看体用。爻辞只补细节，**永远不要让它盖过体用生克**。

#### 走一遍完整例子

**问自身健康，得「风火家人」三爻动**：

```latex
第1步 三爻在下卦 → 下卦离为用，上卦巽为体 → 体巽木、用离火
第2步 离火泄巽木 → 体生用，小凶（自身精气被耗）
第3步 再参月令：若占于秋（金旺木死），体卦巽木正处"死"地，凶性加重
第4步 结论：需重点调养肝胆（巽为股胆）

```

#### 案例小故事：骨架对了，还得看有没有力气

一人断卦：体克用，按"体克用诸事吉"断了"能成、很快"。结果事情拖了半年才落。

复盘时发现问题不在体用，在他跳过了卦气旺衰：当时体卦正值衰令，克是克，但**克不动**。

骨架（体用生克）告诉你"关系往哪走"，旺衰告诉你"这股关系有没有力气"。两者缺一，断语就会"方向对、节奏错"——而节奏错，在当事人看来就是不准。

**落点**：体用是骨架，旺衰是力气。判完生克必须追一句：**这个克，克不克得动？**
