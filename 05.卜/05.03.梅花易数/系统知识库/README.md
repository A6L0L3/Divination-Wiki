# 梅花易数系统知识库 · 分卷索引

## README · 导览

> **副标题**：从取象到断卦的完整闭环——一套"机 → 数 → 卦 → 象 → 理"的可落地实操手册

### README_1 本库是什么

这不是《梅花易数》的原文摘抄，而是一次结构性重建。原书条目松散、版本混杂、后人增益甚多，初学者极易陷入"背了一堆口诀、断卦依然卡壳"的困境。

本库按**"先走对路 → 打地基 → 学核心技术 → 上心法 → 练应用 → 复盘案例 → 避坑 → 由术入道"**的顺序重排，共 14 个板块（板块0—板块13）。每一节都只回答三个问题：

```latex
第1步 这一步怎么做
第2步 做完得到什么
第3步 常见错误是什么

```

本库另有三块系统化的实操补充，是原书零散、一般教程少见的内容：

+ `4_6` 先天起卦与后天起卦的分野
+ `5_6`—`5_8` 爻位、卦象直读、错卦综卦三件进阶工具
+ `9_5` 射覆训练场

### README_2 三条主线

读完全库你会发现，所有技术细节都挂在这三条主线上。抓住主线，就不会迷失在口诀里。

#### 主线一：机 → 数 → 卦 → 象 → 理（技术主干）

```latex
【机】触发占问的那个"异常"（不动不占）
   ↓
【数】把"机"量化（年月日时、数目、物数、笔画）
   ↓
【卦】数成卦（卦以八除，爻以六分 → 本卦 / 互卦 / 变卦）
   ↓
【象】卦还原为万物（八卦万物类象 + 场景嫁接）
   ↓
【理】象组合成判断（常理、情理、五行生克之理）

```

原书最要紧的一句叮嘱：**"推数必须推理。"** 只推数不推理，是学不到家的。

#### 主线二：以物观物（心法主线）

> **"以物观物，性也；以我观物，情也。性公而明，情偏而暗。"**

断卦时心里先有了"我希望它吉"的预设，卦就会被主观带偏——这就是"以我观物"的弊端。本库把"以物观物"作为贯穿始终的隐性主线：

| 环节 | "以物观物"的具体要求 |
| --- | --- |
| 起卦 | 取第一念，不挑选、不重算 |
| 断卦 | 先参爻辞、次看体用（原典顺序），不让好恶介入 |
| 取外应 | 等它来，而不是去找它 |
| 应期 | 数算出来后用常理校正，不硬套数字 |
| 日常 | 换成"给最好的朋友提建议"的立场 |

#### 主线三：从术到道（境界主线）

板块0 至板块11 是"术"（可训练的手艺），板块12、板块13 是"道"（《皇极经世》的观物心法与落地工具）。

> **卦象是死的，当下之机是活的，断卦的人心是枢纽。**

### README_4 使用约定

1. **二级编号贯穿全文**：写作"板块_序号"，如 `2_5`，可直接当目录跳转。
2. **带 ✍️ 标记的是必须动手做的练习**——看懂不算会，做对才算。
3. **标注【必背】的硬知识**必须形成肌肉记忆；未标注的可查表使用。
4. **所有表格、模板、清单均可直接抄用**。
5. **图版一律用代码块（ASCII）呈现**，可在语雀、Typora 等 Markdown 环境直接加载。
6. **关于重复**：各板块内容尽量不重复叙述。唯一刻意保留重复的是板块13 的速查手册——它按设计就是"可打印随身"的卡片，与正文形成"详解 + 速查"的分工。

### README_5 能力边界与伦理红线（必读）

《梅花易数》的价值，在于**锻炼观察力、结构化联想力，以及在信息不全时做出自洽判断的能力**。它的推演机制不具备可重复的实证基础，"应验"存在极强的选择性叙事与事后解释空间。

| 场景 | 建议 |
| --- | --- |
| 日常小事、趋势思考、创意启发 | 可练可用，当作思维体操 |
| 重大人生决策（择业、婚姻、搬迁） | 可作参考视角之一，绝不可作唯一依据 |
| 投资、医疗、法律、人身安全 | **禁止**使用。这些领域有专业方法论 |

**伦理红线**：易为君子谋，不为小人谋。历代易家明确不取四类占问——未经同意占问第三方隐私；占问作奸犯科之事的成败；占问赌博、投机暴富的时机；以占卜挑拨他人关系、制造恐惧牟利。

> **一条底线判断法**：如果这件事你不愿意当着当事人的面说出来，就不要起这个卦。

### README_7 一句话总纲

先读板块10 建立"断卦是怎么想出来的"的实感，再回头啃板块2、板块3 的地基，然后用板块5、板块6 练技术，最后以板块13 的速查手册随身查漏补缺——这条路径，是穿过这部"天书"最高效的捷径。

> **最后的提醒**：本库宜"得其意而忘其象"。若陷入具体卦气、声音律吕的数字迷宫，反而离真意越来越远。**观物之要，在观其理，不在数其爻。**
