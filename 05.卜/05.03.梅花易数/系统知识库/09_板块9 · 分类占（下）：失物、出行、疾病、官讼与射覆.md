## 板块9 · 分类占（下）：失物、出行、疾病、官讼与射覆

> 这一块把吉凶接到"物"与"身体、是非"上，并给出全库最好的类象训练场——射覆。

---

### 9_1 失物 / 寻人占

**重点用后天方位。**

#### 推法

| 维度 | 方法 |
| --- | --- |
| **物品属性** | 看**体卦**类象（何物） |
| **藏处方位** | 看**用卦** + 方位；内卦动 → 在家内；外卦动 → 在外，看方向与环境 |
| **能否找回** | 参旺衰：体旺用衰 → 可寻回；用克体且旺 → 难寻 |
| **所去方向** | **用卦的变卦**往往是所去的方向 |
| **环境特征** | 用卦类象 + 方位类象（如"坎 + 北" → 近水处、阴暗处、地下室） |

#### 方位与藏处速查

| 方位 | 卦 | 可能的藏处 |
| --- | --- | --- |
| 西北 | 乾 | 高处、柜顶、金属容器、书房 |
| 正北 | 坎 | 近水处、卫生间、地下室、阴暗角落 |
| 东北 | 艮 | 门后、墙角、柜中、土石处 |
| 正东 | 震 | 车马处、木器中、声响处（音响旁） |
| 东南 | 巽 | 长条物中、绳线处、通风处 |
| 正南 | 离 | 文书堆中、电器旁、明亮处 |
| 西南 | 坤 | 布帛中、箱包里、平整处 |
| 正西 | 兑 | 开口容器中、破损处、金属旁 |

> **常理校正的例子**：问"失物在哪"，卦象指向"水边"，但当事人从不去水边 → 应改为"近水的类比场所"（卫生间、地下室、厨房水槽旁），而不是硬套"河边"。**这就是"推数必须推理"在失物占上的落地。**

> **小故事·不在河边的"水边"**

有人丢了钱包，卦上用卦是坎，坎为水、方位正北。断卦人一口咬定："掉河边了，去河边找。"
那人住二十楼，小区附近根本没河，绕了半天一无所获。
后来换了个思路：坎是"水"，但城市里什么最像"水边"？——**卫生间、厨房水槽、地下室、洗衣机旁**。
他回家一想，昨晚确实在卫生间洗手时把钱包搁在台面上，之后顺手塞进了洗衣篮旁的柜子。
**卦说的是"水边"，不是"河边"。** 常理不允许的答案，要换成常理允许的那个同构答案——这就是失物占里最常踩的坑。

### 9_2 出行占

| 看什么 | 方法 |
| --- | --- |
| **顺不顺** | 体用生克 + 旺衰 |
| **途中何事** | 用卦、变卦的类象 |
| **何时归** | 应期法（见板块6） |
| **方向吉凶** | 后天方位与体卦的生克关系 |

**例**：问远行，起卦时听见雷鸣大风（震木），体为土 → 木克土 → 中途堵车、颠簸、遇争执。

### 9_3 疾病占

| 要素 | 方法 |
| --- | --- |
| **病位** | 克体之卦的类象（身体部位） |
| **轻重** | 体卦旺衰 + 克体之力 |
| **吉凶** | 体旺有救；体衰用旺克体 → 凶 |
| **应期** | 测病以**本互变全数**定应期 |
| **医药** | 看生体之卦（何物、何方、何人可助） |

**例**：问长辈病情，体卦为木；抬头看见院内**枯树抽新芽**（震木生气外应）→ 外应生扶体卦 → 断病情好转，生机渐现。

> **伦理红线**：疾病属于专业领域。占断只能作为"参考视角之一"，**绝不可据此替代就医**。投资、医疗、法律、人身安全四类一律禁止以占卜替代专业判断。

### 9_4 官讼 / 是非占

| 要素 | 方法 |
| --- | --- |
| **有无官非** | 看是否有克体之旺卦 + 乾（官）、兑（口舌）类象 |
| **胜负** | 体旺用衰 → 我胜；体衰用旺 → 我败 |
| **有无和解** | 看有无**通关五行**（和解之象） |
| **口舌来源** | 兑卦类象（口舌、破损、毁折） |

> **外应速判**：起卦时见**官员** → 制度介入；见**争吵** → 防合作破裂；见**吏卒叫嚣** → 忌官讼。

### 9_5 射覆：最好的类象训练场

**射覆**就是把东西盖起来让人猜——"射"是猜，"覆"是盖。这是汉代就流行的游戏，正史里记载的高手都是易学大家。原书也有"占物类例"一节专讲此法。

#### 为什么值得专门练

| 理由 | 说明 |
| --- | --- |
| **绝对可验证** | 猜中就是中，猜错就是错，**没有给自己圆卦的空间**——这是它比占人事更适合训练的地方 |
| **心理负担小** | 占的是一件已知之物，不涉及他人吉凶祸福 |
| **直击核心能力** | 训练"取象 + 五行 + 排除"的完整链条，与断卦用的是同一套肌肉 |

#### 五步流程（直接套用）

```latex
第1步 静心凝神，专注藏物，用时间/数字起卦
      ↓
第2步 本卦 → 定物品大类、五行、基础形态
      ↓
第3步 互卦 → 补颜色、质地、结构、气味等内部细节
      ↓
第4步 变卦 → 定用途、状态、使用场景
      ↓
第5步 结合季节、环境、出题人身份，用排除法剔除相似项，锁定唯一答案

```

#### 体用在射覆中的分工

| 位置 | 对应 |
| --- | --- |
| **体卦** | 事物的**性质、本质、材质、内部**情况 |
| **用卦** | **外形、功用、外部**特征 |
| **上卦** | 多主**颜色** |
| **下卦** | 多主**质地** |

> 也不必死守体用——可以把全卦当成一个整体，找出**最突出的那个象**，再结合背景综合判断。

#### 六种常用取象法

| # | 方法 | 要点 |
| --- | --- | --- |
| 1 | **按八卦类象断** | 基础中的基础，万物类象必须熟 |
| 2 | **按五行断** | 金=坚硬金属；木=生发、条状；水=流动、无形；火=能量、光彩、文化；土=敦厚、老旧、块状 |
| 3 | **按卦名爻位断** | 一般不单凭卦名直断，但卦名 + 卦意 + 爻位在**排除法**里极好用 |
| 4 | **观察全卦** | 找最突出的五行、最明显的特征之象 |
| 5 | **按生克组合断** | 金克木 → 雕琢过的木器；火克金 → 熔铸过的金属 |
| 6 | **卦与时间的关系** | **卦旺**取该象的正面特质（乾旺 = 贵重圆润）；**卦弱**取反面特质（乾衰 = 老旧的金属） |

#### 实战演示：一支口红是怎么推出来的

> **前提**：出题人是女生，藏了一件小东西。

**得卦**：火泽睽 → 变山泽损。

| 轮次 | 推理 | 反馈 |
| --- | --- | --- |
| **第一轮** | 上离下兑：兑为开口容器、有"气"之象，开口处冒火 → **打火机** | 不对 |
| **第二轮** | 重取：兑为口、为吃；用克体，但变卦艮生兑（由克转生）→ 难吃却对身体有益 → **药物** | 不对 |
| **第三轮** | 再重取：体卦兑为**少女**，用卦离为**美丽**，互卦下卦也是离 → **化妆品类** | 很接近 |
| **收窄** | 互卦坎水克离火，代表过程中被消耗；变卦**山泽损** = 损耗 → 是**消耗品**；对女生而言"美丽的消耗品" = 化妆品 | 对 |
| **定色** | 本卦兑为白、离为红 → 颜色与白或红有关 | 与红色有关 |
| **定形** | 兑为口，离在外，变卦艮为手 → 手持某物擦拭口部，且会损耗 | **口红** |

> **这个案例最值钱的地方**：前两轮都错了，但每一轮都**用反馈缩小范围**——这就是射覆的"排除法"本质，也是它训练价值最高的原因。

第一轮推出"打火机"，虽然错了，但"开口容器 + 冒火"这个组合被保留下来；第二轮推出"药物"，又排除了"入口之物"里的一大类；到第三轮才把范围收进"化妆品"。
**射覆从来不是一次命中，而是三轮收敛。**

#### 三条新手误区

1. **切忌单卦断物**——单卦类象多达数十种（乾可为金属、圆球、首饰、器物），**必须本、互、变三卦叠加筛选**。
2. **脱离生活事理**——卦象是死的，生活是活的。同样的卦，换个季节、换个场景，对应的物品完全不同。
3. **心念杂乱起卦**——射覆讲究"静心感物"，杂念多则卦气混乱。

#### 评分标准（重要，别给自己太大压力）

> **射覆不一定要说出确切物品名。**

比如藏物是一块磁铁，你能说出"**含金属、整体偏黑、有吸附作用**"——**特性说对了，这次射覆就算成功**。
很多时候我们明明知道物品的各种属性，就是想不起名字。能说出特性，说明取象链条是通的；能说出具体物品，那是加分。

**训练建议**：每天做 1—3 组。让家人朋友随手盖一件小东西，你起卦推断，**一次性写出完整断语**（不要挤牙膏式地"看到一点说一点"），写完后统一揭晓对照。
