## 板块8 · 分类占（上）：通用法则与人事类占断

> 前面所有技术（起卦、断卦、应期、外应）最终都要落到"**具体问的这件事**"上。

分类占就是把吉凶接到具体人事的接口。

---

### 8_1 通用断语公式（所有分类占共用）

> **体为所问之家/人，用为所应之事。**

**用生体 → 进益；体克用 → 可成但迟；用克体 → 不成；体生用 → 有耗；比和 → 称意。**

#### 通用加权规则

| 关系 | 通用断语 | 应期倾向 |
| --- | --- | --- |
| **用生体** | 事易成，有外力相助 | 速（生体之卦当令时） |
| **体克用** | 可成但需努力、有迟滞 | 中（体卦当旺时） |
| **体生用** | 有耗损，费力或少得 | 中偏迟 |
| **用克体** | 不成，或有害 | 凶（克体之卦当令时） |
| **比和** | 顺遂、称意、平稳 | 平（本卦五行当旺时） |

#### 分类占的三步法

```latex
第1步 定体用：谁为体（所问之主体）、谁为用（所问之事）
      ↓
第2步 断生克 + 旺衰：定性 + 定量
      ↓
第3步 嫁类象：把八卦类象接到具体场景上（人、物、方位、时间）

```

> **关键提醒**：三步法中，**第1.步定体用错了，后面全废**。代他人占时，以"所问的那个人"为体，不以自己为体。

### 8_2 天时占（唯一"不分体用"的一类）

**天时占不分体用**，全观诸卦五行：

| 卦多现 | 天象 |
| --- | --- |
| **离**多 | 晴 |
| **坎**多 | 雨 |
| **坤** | 阴晦 |
| **乾** | 晴明 |
| **震**多 | 春雷 |
| **巽**多 | 四时风烈 |
| **艮**多 | 久雨必晴 |
| **兑**多 | 不阴亦雨 |

> ⚠️ **且须结合四时，不可执一理**：

**夏占离多而无坎** → 亢旱
**冬占坎多而无离** → 雨雪

**为什么天时占不分体用？** 因为天的运行不以"我"的意志为转移，没有主体与客体的对立，只看卦气本身的多寡消长。这是全部分类占里唯一的例外，记住它，其余一律分体用。

### 8_3 人事 / 谋望占

+ **体为主、用为宾**
+ **用克体** → 不宜（谋事受阻）
+ **体克用** → 吉（可控，但费力）
+ **用生体** → 有进益
+ **体生用** → 有失耗
+ **比和** → 谋为喜利

#### 类象嫁接要点

| 问什么 | 看什么 |
| --- | --- |
| 事能否成 | 体用生克 + 变卦 |
| 谁在帮我 / 谁在阻我 | 生体之卦的类象 / 克体之卦的类象 |
| 何时成 | 生体之卦当令之时 |
| 有无暗中的变数 | 互卦（体互最紧） |

> **实操心法**：问"谁在帮我/阻我"时，直接看**生体 / 克体之卦的类象**。比如生体之卦为乾 → 贵人是领导、父亲辈、权威人物；克体之卦为兑 → 阻力来自口舌、破损，或者一个能说会道的人。

> **小故事·到底是谁在使绊子**

有人问项目推进不顺，卦上克体的是兑卦。他第一反应："是不是财务那边卡我？"
再看兑的类象：口、口舌、破损、毁折、少女、销售人员。
他忽然想起，上周例会上有个同事当众质疑了他的方案，之后好几个部门就开始观望。
——**阻力不是流程问题，是"口舌"问题**。兑卦已经把加害者的画像画出来了：不是制度，是某张嘴。
后来他找那位同事单独沟通了一次，事情就顺了。
**克体之卦的类象，往往直接指出"阻力源"是谁、是什么形态。**

### 8_4 婚姻 / 感情占

+ **体** = 所占之家（我方）
+ **用** = 所婚之家（对方）

| 关系 | 断语 |
| --- | --- |
| **用生体** | 婚易成（对方主动、对方家庭支持） |
| **体克用** | 可成但迟（需我方推动，周折后成） |
| **用克体** | 不可成 |
| **体生用** | 单方付出，情难久 |
| **比和** | 良配无疑 |

#### 容貌推法（仅作参考，不可执死）

| 卦 | 容貌特征 |
| --- | --- |
| 乾 | 端正而长 |
| 兑 | 高长而白 |
| 离 | 短赤，性情不常 |
| 坤 | 貌丑、大腹而黄 |
| 震 | 高大、声响 |
| 巽 | 身长、发少、额宽 |
| 坎 | 黑、圆脸 |
| 艮 | 矮小、敦实 |

> **提醒**：这是古人经验总结，现代应用须结合具体情境，**绝不可用来评判他人外貌**。

> **小故事·"我很爱他"不等于吉**

一位女士问感情，卦上是"体生用"。她读了解释后很委屈："体生用是不是代表我很爱他？爱得多难道不好吗？"
答案是——**体生用在卦理上是"我不断往外掏"**。它描述的是能量流向，不是感情深浅。
也就是说，这段关系里只有她在持续付出：时间、精力、金钱、情绪。卦上没有一个"生体"的回流。
她沉默了一会儿说："确实，这两年都是我在迁就。"
**爱得多不多，不看生克；关系能不能久，看的是有没有回流。** 一段感情若只有单方面输出，卦已经把答案写在脸上了——体生用，情难久。

### 8_5 求名 / 求财占

#### 求名

| 关系 | 断语 |
| --- | --- |
| **体克用** | 名可成但迟 |
| **用生体** | 名易成，且因名有得 |
| **用克体** | 名不可成 |

#### 求财（书中"体生用"之辨极精妙）

**核心**：若卦是"**体生**"，乃泄己之气，其财**空望**。

**三步推法**：

```latex
第1步 看有无生体之卦 → 有则可求，无则难
第2步 看生体之卦属何物 → 定得财的来源
第3步 结合旺衰 → 定得财的多少

```

| 生体之卦 | 得财来源 |
| --- | --- |
| **乾、兑** | 金玉、钱财、金属相关 |
| **震、巽** | 草木、木材、贸易、文书 |
| **坤、艮** | 田土、房产、农业 |
| **坎** | 水边鱼酒、流通业 |
| **离** | 文书、文化、电子、火电类 |

#### 求财速查口诀

```latex
用生体利易得，体生用利难聚；
体克用利迟至，用克体有损耗；
比和求财安稳，正财稳守勿贪。

```

> **为什么"体生用"求财是空望**：体生用 = 我不断往外掏。做生意若只有投入没有回流，账面再热闹也是虚的。

**这一条对现代人的启示**：看一个项目能不能赚钱，先看"**有没有生体的力量回流**"，而不是看"我投入了多少热情"。热情是"体生用"，回流才是"用生体"。

### 案例小故事：求职卦里的"中间人"

有人问求职能不能成。卦中体用比和，互卦又见生——按通用法则，这是"能成且过程顺"的象。

但断的人多问了一句：这类事的结构是什么？求职是三方结构——我、对方、中间人。于是他顺着"用"去追，果然在变卦里读出了"有人代为引荐"的象。

事后反馈：录用是录用了，但确实不是他直接投的简历，是前同事内推的。

如果只按通用法则断一句"能成"，这次也算准；但把"中间人"断出来，才真正用上了这一类事的结构。

**落点**：分类占的关键，是把通用法则落到**这一类事独有的结构**上。求职的结构是三方，问病的结构是正邪，问讼的结构是两造——结构不同，取用不同。
