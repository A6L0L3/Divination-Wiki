## 板块11 · 避坑清单：高频错误与纠偏

> **这一板块建议每断十卦就回看一次。**

断不准，八成不是"卦不灵"，而是下面二十条里中了某一条。

---

### 11_1 起卦环节的六个错误

> 这六条与 `4_8` 的清单相同，此处汇总是为了让你**集中回看**——建议每断十卦扫一遍这张表。

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **1** | **年份用公历数字**（如年份直接 ÷ 8） | 上卦全错 | 只用农历**地支序数**：子1…亥12 |
| **2** | **余 0 当 0 或无卦** | 下卦/动爻全错，**且自查发现不了** | 求卦余 0 → 取 **8（坤）**；求爻余 0 → 取 **6（上爻动）** |
| **3** | **动爻用上下卦数之和直接当** | 动爻错 | 动爻 = 第三个数 ÷ 6 取余；无第三数则用两数之和或加时辰数 |
| **4** | **端法起卦忘加时辰数** | 动爻错 | 先得象（端法）→ **必须**加时辰；先得数（数字法）→ 不加 |
| **5** | **起卦后反复重算** | 卦气杂乱，失去参考价值 | 一事不二占；心不诚、机不明则不占，重占须另有机缘 |

> **原文校准**：《梅花易数》全书**无"再占须间隔七日"之规定**。另需注意：六爻一系的《增删卜易》反而力主"多占之法"（即时再占、合两卦而决）。两体系口径相反，用时须先选定所从之体系，不可混用。
| **6** | **用先天数断方位 / 用后天位起卦** | 方位全错 | 起卦用**先天数**；方位看**后天位** |

### 11_2 断卦环节的八个错误

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **7** | **体用搞反**（以为上卦永远是体） | **满盘皆错** | 默念："动爻在某卦，某卦为用"。1/2/3 爻动→下卦为用；4/5/6 爻动→上卦为用 |
| **8** | **给互卦强行分体用** | 吉凶逻辑混乱 | **只有本卦分体用**。互卦只看它对体卦的生克 |
| **9** | **忽略互卦** | 缺少"过程分析" | 互卦 = 二三四爻（下互）+ 三四五爻（上互） |
| **10** | **只看生克，不看旺衰** | 定性对、定量错 | 生克定性质，旺衰定轻重。体旺不怕克，用衰生不力 |
| **11** | **只论卦名，不审卦气** | "局于象，昧于时" | 卦名不变而气随时转，必须按时审气 |
| **12** | **只看体用，不看爻辞** | 丢失原典第一道判据 | 原典优先级：**爻辞 → 体用生克 → 卦气旺衰 → 互变 → 类象 → 克应 → 应期**。爻辞为断吉凶之首，体用为定性主干 |
| **13** | **只看本卦，忽略互变** | 看不到过程与结局 | 本（始）→ 互（过程）→ 变（结局），三卦合参 |
| **14** | **过度解读** | 信息量过大，反而不敢断 | 一次只抓 3—4 个关键点：体用、互卦、变卦、最显著的一个外应 |

### 11_3 心法环节的六个错误

| # | 错误 | 后果 | 纠偏 |
| --- | --- | --- | --- |
| **15** | **外应满世界去找** | 全是主观投射 | 外应是"**撞进来**"的，三秒内自然注意到的才算 |
| **16** | **外应硬套**（见鸟叫就往离卦靠） | 结论荒唐 | 先想类象再套，不要拿结论倒推。鸟叫属**兑**（声音），鸟飞属**震**（动） |
| **17** | **类象死记硬背** | 遇到现代事物就断不了 | 取象三原则：问什么取什么、看旺衰、两卦叠加 |
| **18** | **象大于五行，不谈生克** | 舍本逐末 | 生克定吉凶，类象定细节；**生克优先于类象** |
| **19** | **宿命论**（卦说不行就不行） | 放弃主观努力 | 梅花揭示的是"**若按此轨迹发展，将得此结果**"，目的在于**趋吉避凶** |
| **20** | **刻舟求剑**（一套口诀打天下） | 同卦不同人、不同时，解读应不同 | 因人而异、因事而异、因时而异 |

### 11_4 六大学习盲区（进阶者也会中招）

| 盲区 | 表现 | 正解 |
| --- | --- | --- |
| **1. 只重卦象，不看卦理** | 背了一堆类象，不知何以如此 | 不知卦理就无法推衍类象。**乾兑皆金，乾是贵重圆润，兑是破损开口** |
| **2. 只论卦名，不审卦气** | 见"泰"就吉、见"否"就凶 | 卦名不变，气随时转 |
| **3. 象大于五行，不谈生克** | 沉迷取象，忘了断吉凶靠生克 | 生克是骨架，类象是血肉 |
| **4. 大道至简，空中楼阁** | 以"梅花不论干支"为借口，不学基础 | 干支是打开时空的钥匙，至少掌握地支序数、月令、日支 |
| **5. 重术轻理** | 会起卦断卦，不懂为何 | 回到《皇极经世》的体用框架与"以物观物"（见板块12） |
| **6. 以准为荣，以验为能** | 追求"算得准"，忽略思维训练价值 | 真正的收获是观察力、结构化联想力、以及在不确定中做判断的能力 |

### 11_5 断完卦必问的八个问题（自查清单）

每次下断语之前，把这八条过一遍：

```latex
□ 1. 动爻位置确认了吗？"动爻在某卦，某卦为用"——默念过吗？
□ 2. 余 0 的地方处理对了吗？（取 8 / 取 6）
□ 3. 互卦取对了吗？我有没有给它强行分体用？
□ 4. 旺衰查了吗？体卦在当月的旺相休囚死是什么？
□ 5. 变卦看了吗？本吉变凶 / 本凶变吉，结论改了吗？
□ 6. 有没有通关五行？克局是不是有救？
□ 7. 类象是不是只取了和问题最相关的 3—5 个？
□ 8. 最后一步：这个结论符合常理吗？（不合就要重来）

```

> **第 8 条是最重要的。** 一个不符合常理的结论，99% 是中间某一步错了，而不是"卦太玄妙"。

> **小故事·被第 8 条拦下来的断语**

有人问一笔款子下个月能不能到账，卦算下来是"用克体"，他心里一沉，正准备说"恐怕要不回来"。
话到嘴边，他想起自查清单的第 8 条：**这个结论符合常理吗？**
他停住了——对方是合作多年的老客户，上个月的款子都是准时结的，说"要不回来"实在说不通。
于是他从头复核，一路查到动爻：动爻落在第 3 爻，属于下卦三爻，**下卦才是用**。而他从一开始就把上卦当成了体——**体用整个搞反了。**
改正后重断：不是"用克体"，而是"用生体"，事易成，且对方会主动配合。后来那笔款子如期到账。
他事后在卦例本上写："**第 8 条救了我一卦。** 如果不是它逼我停下来问一句'这说得通吗'，我就把一个吉卦说成了凶卦。"
八问清单真正的价值，不在于"提醒你别出错"，而在于**给你一个停下来重算的理由**。多数断错的卦，都错在断得太快。

### 11_6 最致命的三条（新手必记）

所有错误里，最致命的是这三条——

```latex
第1步 体用搞反
第2步 余 0 处理错（当成 0 或无卦）
第3步 用公历年份代替农历地支序数

```

它们的共同特点是：**自己发现不了**。三条都会给出一个"看起来完整"的答案，照样能讲出一套道理，所以错了也不知道。

> **一句话防线**：每次断卦前，先花 30 秒默念这三条，比什么都管用。

### 案例小故事：对了九卦，错在第十卦

一人连着断了十卦，前九卦都对，于是他开始觉得自己"上手了"。第十卦错得很彻底，方向整个反了。

复盘那一次，他发现问题不在技术：卦还没起，他心里已经有了答案——因为当事人是他朋友，他希望事情成。

于是从起卦那一步开始，他就只盯着支持"能成"的象看，反对的象被他一路解释成了"暂时阻碍"。前九卦之所以准，是因为那九个人他不在乎。

**落点**：最高频的错误不是技术错误，是**先有答案再倒推**。断卦前先自查一句：这件事，我希望它是什么结果？
